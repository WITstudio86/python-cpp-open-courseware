## 📖 算法讲解

### 一、递归分治回顾——从"大事化小"到"小事化了"

在前面的课程中，我们已经学习了递归和分治的基本思想。这里做一个简要回顾：

**递归（Recursion）** 是一种编程技巧，指函数直接或间接地调用自身。递归的核心是找到问题的**递归结构**——大问题可以分解为结构相同的小问题。每个递归函数必须包含两个要素：
- **递归终止条件（Base Case）：** 问题足够小，可以直接求解
- **递归关系（Recurrence Relation）：** 将大问题转化为小问题

**分治（Divide and Conquer）** 是一种算法设计策略，将原问题分解为若干个规模较小的子问题，递归求解这些子问题，然后将子问题的解合并为原问题的解。分治的经典三步是：
- **分解（Divide）：** 将原问题划分为若干子问题
- **解决（Conquer）：** 递归求解各个子问题
- **合并（Combine）：** 将子问题的解合并

两者的关系是：**分治策略通常通过递归来实现**，递归是分治思想的编程载体。

### 二、"幂次方表示"问题——递归分解的经典案例

#### 问题背景

任何一个正整数都可以表示为 **2 的幂次方之和**。例如：
- 7 = 4 + 2 + 1 = 2² + 2¹ + 2⁰
- 137 = 128 + 8 + 1 = 2⁷ + 2³ + 2⁰

但问题要求更进一步：**指数本身也要用同样的方式表示**，即把指数也分解为 2 的幂次方之和。最终，数字只能由 `2`、`0` 和括号组成。

例如 137 的完整表示是：`2(2(2)+2+2(0))+2(2+2(0))+2(0)`

#### 递归分解思路

这个问题的核心在于**递归嵌套**。我们不仅要把原数分解为 2 的幂次方之和，还要对指数递归地做同样的分解。

具体步骤如下：

```
函数 solve(n) 的递归过程：

1. 如果 n == 0：返回 "0"
2. 如果 n == 1：返回 ""（因为 2(0) 表示 2^0 = 1）
3. 将 n 转换为二进制，找到所有为 1 的位
   - 例如：137 的二进制是 10001001
   - 第 7、3、0 位是 1（从低位开始编号，0-indexed）
   - 表示 137 = 2^7 + 2^3 + 2^0
4. 对于每个非零指数 e：
   - 如果 e == 1：输出 "2"（即 2^1）
   - 否则：输出 "2(" + solve(e) + ")"（递归分解指数）
5. 各项之间用 "+" 连接
```

下面用一个具体的例子演示：

```
以 137 为例的分解过程：

  137 的二进制：10001001 → 第7位、第3位、第0位为1
  137 = 2^7 + 2^3 + 2^0

  ┌─ 2^7：指数 = 7
  │    7 的二进制：111 → 第2位、第1位、第0位为1
  │    7 = 2^2 + 2^1 + 2^0
  │    → 2(2(2) + 2 + 2(0))
  │          ↑    ↑    ↑
  │    2(2(2)) 即 2^(2^2)     // 2的指数是2，2又展开为2(2)
  │    2 即 2^1                // 指数为1时，省略括号
  │    2(0) 即 2^0             // 指数为0，直接写0
  │
  ├─ 2^3：指数 = 3
  │    3 的二进制：11 → 第1位、第0位为1
  │    3 = 2^1 + 2^0
  │    → 2(2 + 2(0))
  │
  └─ 2^0：指数 = 0
       → 2(0)

  最终拼接：2(2(2)+2+2(0)) + 2(2+2(0)) + 2(0)
```

下面是完整的递归调用树，可以帮助理解嵌套递归的过程：

```
                    solve(137)
                        │
         ┌──────────────┼──────────────┐
      2^7 = 2(solve(7))   2^3=2(solve(3))   2^0=2(0)
            │                  │
         solve(7)          solve(3)
            │                  │
      ┌─────┼─────┐      ┌─────┼─────┐
   2^2    2^1    2^0    2^1    2^0
   =2(2)  =2     =2(0)  =2     =2(0)
    │
  solve(2)
    │
   2^1
   =2
```

#### 为什么这是"分治"？

虽然幂次方表示问题看起来不像传统的分治（没有"等分为两半"），但它体现了分治的核心思想：**将原问题转化为规模更小的同类子问题**。每次我们处理指数 e 时，递归地对 e 做同样的分解，直到指数为 0 或 1 时终止——这正是"分解→解决→合并"的分治模式。

### 三、"FBI树"问题——根据01串构造二叉树

#### 问题描述

FBI 树是一种特殊的二叉树，由长度为 2^n 的 "01" 串构造而成。构造规则如下：

1. 根节点对应整个字符串 S
2. 如果字符串长度大于 1，将字符串从中间对半分，左半部分构造左子树，右半部分构造右子树
3. 每个节点的类型根据其对应字符串来判断：
   - 全为 '0' → **B 节点**（Bomb，炸弹）
   - 全为 '1' → **I 节点**（Intelligence，情报）
   - 既有 '0' 又有 '1' → **F 节点**（FBI，联邦调查局）

构造完成后，对 FBI 树进行**后序遍历**（左子树 → 右子树 → 根节点），输出每个节点的类型。

#### 递归构建过程图解

以输入字符串 `"10001011"`（n=3，长度为 2^3=8）为例：

```
原始字符串：10001011

第1层（整串）："10001011" → 既有0又有1 → F
        ┌─────────────────┴─────────────────┐
第2层（左半）："1000" → 混合 → F      第2层（右半）："1011" → 混合 → F
      ┌──────┴──────┐                  ┌──────┴──────┐
第3层："10"→F   "00"→B            第3层："10"→F   "11"→I
    ┌──┴──┐   ┌──┴──┐               ┌──┴──┐   ┌──┴──┐
第4层: "1"→I "0"→B "0"→B "0"→B    "1"→I "0"→B "1"→I "1"→I

后序遍历输出：I B F B B B F I B F I I I F F
                                   ↑         ↑
                              左子树     右子树     根
```

#### FBI树的判断逻辑

判断一个节点是 B、I 还是 F，我们需要检查对应子串是否全为 '0' 或全为 '1'：

```cpp
// 判断函数
char fbiType(const string& s) {
    bool hasZero = false;  // 是否包含 '0'
    bool hasOne  = false;  // 是否包含 '1'
    for (char c : s) {
        if (c == '0') hasZero = true;
        if (c == '1') hasOne  = true;
    }
    if (hasZero && hasOne)  return 'F';  // 混合 → F
    if (hasZero)            return 'B';  // 全0 → B
    return 'I';                          // 全1 → I
}
```

### 四、递归分治的综合思维

这两个例题展示了递归分治在不同场景下的应用：

| 对比维度 | 幂次方表示 | FBI树 |
|---------|-----------|-------|
| 分解方式 | 按二进制位分解 | 字符串对半拆分 |
| 子问题关系 | 指数递归分解 | 左右子树递归构建 |
| 合并方式 | 字符串拼接（用+连接） | 后序遍历输出 |
| 分治类型 | 非等分（按二进制位） | 等分（二分） |

尽管分解方式不同，两者都遵循"找到递归结构 → 递归求解子问题 → 合并结果"的统一范式。掌握这种思维模式，你就能应对大多数递归分治问题。

## 💻 代码实现

### 幂次方表示的递归解法

```cpp
#include <iostream>
#include <string>
using namespace std;

// 递归函数：返回数字 n 的幂次方表示字符串
string powerRepresent(int n) {
    if (n == 0) return "0";           // 基数情况：指数为0
    if (n == 1) return "";            // 2^1 只写 "2"，不写 2(1)
    
    string result = "";
    // 将 n 转为二进制，找到所有为 1 的位
    // 从高位向低位处理，保证输出的顺序正确
    bool first = true;                // 标记是否是第一项（控制+号）
    
    for (int i = 15; i >= 0; i--) {   // 假设 n ≤ 20000，15位足够
        if (n & (1 << i)) {           // 检查第 i 位是否为 1
            if (!first) result += "+";
            first = false;
            
            if (i == 0) {
                result += "2(0)";     // 2^0
            } else if (i == 1) {
                result += "2";        // 2^1，省略括号
            } else {
                // 2^i，指数 i 需要递归分解
                result += "2(" + powerRepresent(i) + ")";
            }
        }
    }
    return result;
}
```

## 📊 复杂度分析

**幂次方表示：**
- 时间复杂度：O(log n * log log n)。每次递归将数字按二进制分解，二进制位数约为 log n。指数递归的深度约为 log log n（因为指数不断变小）。总体操作次数有限。
- 空间复杂度：O(log n)，主要消耗在递归调用栈和返回字符串的存储上。

**FBI树：**
- 时间复杂度：O(N log N)，其中 N = 2^n 是字符串长度。树的每一层需要遍历所有字符来判断节点类型，共有 log N 层（树的高度），每层总字符数为 N。因此总操作量约为 N × log N。
- 空间复杂度：O(N)，递归调用栈深度为 log N，输出字符串长度为 N。

## 🏋️ 经典例题

### 例题1：幂次方表示

**题目描述**：任何一个正整数都可以用 2 的幂次方表示。例如：137 = 2^7 + 2^3 + 2^0。同时约定次方用括号来表示，即 a^b 可表示为 a(b)。由此可知，137 可表示为 2(7) + 2(3) + 2(0)。

进一步要求：指数也要用同样的方式表示。即 7 = 2^2 + 2^1 + 2^0（2¹ 用 2 表示），3 = 2^1 + 2^0。所以最后 137 可表示为：

`2(2(2)+2+2(0))+2(2+2(0))+2(0)`

输入一个正整数 n（1 ≤ n ≤ 20000），输出其幂次方表示。

**输入格式**：一行一个正整数 n。

**输出格式**：一行一个字符串，表示 n 的幂次方表示（符合题目约定的格式）。

**样例输入**：
```
137
```

**样例输出**：
```
2(2(2)+2+2(0))+2(2+2(0))+2(0)
```

**解题思路**：

1. **核心递归：** 定义一个递归函数 `solve(n)`，返回 n 的幂次方表示字符串。
   - 当 n == 0，返回 `"0"`（用于表示指数 0）
   - 当 n == 1，返回 `""`（因为 2^1 约定简写为 `2`）
2. **二进制分解：** 将 n 按二进制位展开。例如 n=137，二进制为 10001001，第 7、3、0 位为 1。
3. **项的处理：**
   - 第 0 位（2^0）：输出 `"2(0)"`
   - 第 1 位（2^1）：输出 `"2"`（省略(1)）
   - 第 i 位（i ≥ 2）：输出 `"2(" + solve(i) + ")"`，指数 i 递归分解
4. **连接：** 各项之间用 `+` 连接。
5. **注意事项：** 二进制分解需要从高位到低位处理，确保输出顺序正确。对于 n 本身（而非指数），不需要在最外层加括号——直接输出 `solve(n)` 的结果即可。

**完整代码**：

```cpp
#include <iostream>
#include <string>
using namespace std;

// 递归函数：返回整数 n 的幂次方表示字符串
// 注意：这个函数返回的是"指数部分"的表示，
// 外层调用时需要自己加上 "2(...)" 或 "2"
string powerRepr(int n) {
    if (n == 0) return "0";
    if (n == 1) return "";         // 2^1 简写为 2，所以返回空字符串
    
    string result = "";
    bool first = true;              // 控制 "+" 的输出
    
    // 从高位到低位扫描二进制位
    // 20000 < 2^15 = 32768，所以扫描 15~0 位即可
    for (int i = 15; i >= 0; i--) {
        if (n & (1 << i)) {         // 第 i 位为 1
            if (!first) result += "+";
            first = false;
            
            if (i == 0) {
                result += "2(0)";
            } else if (i == 1) {
                result += "2";
            } else {
                result += "2(" + powerRepr(i) + ")";
            }
        }
    }
    return result;
}

int main() {
    int n;
    cin >> n;
    cout << powerRepr(n) << endl;
    return 0;
}
```

### 例题2：FBI树

**题目描述**：我们可以把由 "0" 和 "1" 组成的字符串分为三类：全 "0" 串称为 B 串，全 "1" 串称为 I 串，既含 "0" 又含 "1" 的串称为 F 串。

FBI 树是一种二叉树，它的节点类型也包括 F 节点、B 节点和 I 节点三种。由一个长度为 2^N 的 "01" 串 S 可以构造出一棵 FBI 树 T，递归的构造方法如下：

1. T 的根节点为 R，其类型与串 S 的类型相同
2. 若串 S 的长度大于 1，将串 S 从中间分开，分为等长的左右子串 S1 和 S2；由左子串 S1 构造 R 的左子树 T1，由右子串 S2 构造 R 的右子树 T2

现在给定一个长度为 2^N 的 "01" 串，请用上述构造方法构造出一棵 FBI 树，并输出它的**后序遍历**序列。

**输入格式**：
- 第一行一个整数 N（0 ≤ N ≤ 10）
- 第二行一个长度为 2^N 的 "01" 串

**输出格式**：一行一个字符串，为 FBI 树的后序遍历序列。

**样例输入**：
```
3
10001011
```

**样例输出**：
```
IBFBBBFIBFIIIFF
```

**解题思路**：

1. **递归构建：** 定义函数 `buildFBI(l, r)`，处理字符串的 `[l, r]` 区间。
2. **判断节点类型：** 遍历区间内的字符，判断是 B（全0）、I（全1）还是 F（混合）。
3. **递归构建子树：** 如果区间长度大于 1（即 `l < r`），将区间对半分为 `[l, mid]` 和 `[mid+1, r]`，分别递归构建左右子树。
4. **后序遍历输出：** 按照 **左子树 → 右子树 → 根节点** 的顺序输出节点类型。这是 FBI 树的核心——先递归处理子树，再输出当前节点的类型。
5. **终止条件：** 当 `l == r`（区间长度为 1）时，直接判断并输出该节点的类型（B 或 I）。

**完整代码**：

```cpp
#include <iostream>
#include <string>
using namespace std;

string s;  // 存储输入的01串

// 递归构建 FBI 树并输出后序遍历
// 参数 l, r：当前处理的字符串区间 [l, r]
void buildFBI(int l, int r) {
    // 如果区间长度大于1，先递归处理左右子树
    if (l < r) {
        int mid = (l + r) / 2;
        buildFBI(l, mid);         // 后序遍历：先左子树
        buildFBI(mid + 1, r);     // 再右子树
    }
    
    // 判断当前节点 [l, r] 的类型
    bool hasZero = false, hasOne = false;
    for (int i = l; i <= r; i++) {
        if (s[i] == '0') hasZero = true;
        if (s[i] == '1') hasOne = true;
    }
    
    // 后序遍历：最后输出根节点
    if (hasZero && hasOne) cout << 'F';  // 混合
    else if (hasZero)      cout << 'B';  // 全0
    else                   cout << 'I';  // 全1
}

int main() {
    int N;
    cin >> N >> s;
    buildFBI(0, s.length() - 1);
    cout << endl;
    return 0;
}
```

```cpp
#include <iostream>
#include <string>
using namespace std;

// 练习1：递归二分查找
int binarySearch(int arr[], int left, int right, int x) {
    if (left > right) return -1;                     // 终止条件：未找到
    int mid = left + (right - left) / 2;             // 分：取中点
    if (arr[mid] == x) return mid;                   // 治：找到
    if (arr[mid] > x)
        return binarySearch(arr, left, mid - 1, x);  // 递归左半
    else
        return binarySearch(arr, mid + 1, right, x); // 递归右半
}

// 练习2：递归求数组元素之和（分治）
int arraySum(int arr[], int left, int right) {
    if (left == right) return arr[left];             // 终止条件
    int mid = (left + right) / 2;
    return arraySum(arr, left, mid) + arraySum(arr, mid + 1, right);  // 治+合
}

// 练习3：幂次方表示
string powerRepr(int n) {
    if (n == 0) return "0";
    if (n == 1) return "";
    string result = "";
    bool first = true;
    for (int i = 15; i >= 0; i--) {
        if (n & (1 << i)) {
            if (!first) result += "+";
            first = false;
            if (i == 0) result += "2(0)";
            else if (i == 1) result += "2";
            else result += "2(" + powerRepr(i) + ")";
        }
    }
    return result;
}

// 练习4：FBI树
void fbiTree(const string &s, int l, int r) {
    if (l < r) {
        int mid = (l + r) / 2;
        fbiTree(s, l, mid);       // 左子树
        fbiTree(s, mid + 1, r); // 右子树
    }
    bool has0 = false, has1 = false;
    for (int i = l; i <= r; i++) {
        if (s[i] == '0') has0 = true;
        if (s[i] == '1') has1 = true;
    }
    if (has0 && has1) cout << 'F';
    else if (has0) cout << 'B';
    else cout << 'I';
}

// 练习5：整数划分
int partition(int n, int m) {
    if (n == 0) return 1;
    if (m == 0 || n < 0) return 0;
    return partition(n, m - 1) + partition(n - m, m);
}

int main() {
    int arr[] = {1, 3, 5, 7, 9};
    cout << "二分查找 7: " << binarySearch(arr, 0, 4, 7) << endl;      // 3
    cout << "数组元素和: " << arraySum(arr, 0, 4) << endl;             // 25
    cout << "幂次方表示 7: " << powerRepr(7) << endl;                  // 2(2)+2+2(0)
    cout << "FBI树后序遍历: "; fbiTree("1001", 0, 3); cout << endl;   // IBFBFF
    cout << "4的划分数: " << partition(4, 4) << endl;                 // 5
    return 0;
}
```

## 📝 本课小结

本节课我们综合运用递归与分治思想，解决了两道经典的算法题——**幂次方表示**和**FBI树**。这两道题目虽然应用场景不同，但都体现了递归分治的核心范式：找到问题的递归结构，将大问题分解为同构的子问题，递归求解后再合并结果。

幂次方表示问题展示了**递归嵌套**的思维模式：不仅原数需要分解，指数本身也要递归分解。这提醒我们，递归的关键在于识别问题中的"自相似结构"——当一个问题的子问题与原问题具有相同的形式时，递归就是自然的解法。

FBI树问题则是**二叉树递归构建**的典型案例。通过将字符串不断二分，我们构建了一棵完整的 FBI 树。后序遍历的输出顺序（左→右→根）天然地适合递归实现——先递归处理子树，再输出当前节点。这种模式在树的遍历中反复出现，值得牢记。

通过这两道题目的练习，相信你对递归分治有了更深刻的理解。递归不是魔法，而是一种**将复杂问题转化为简单问题**的思维方式。找到递归终止条件（最简单的情况），找到递归关系（如何缩小问题规模），你就能用递归解决一大类问题。继续加油！
