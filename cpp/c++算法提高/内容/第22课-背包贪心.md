# 第22课：背包贪心——部分背包

## 🎯 学习目标
- 理解 0/1 背包与部分背包（分数背包）的核心区别
- 掌握"性价比排序"贪心策略，理解为什么部分背包可以用贪心求解
- 能够用贪心算法解决"金银岛"问题——选取单位价值最高的物品
- 掌握"最优装载"问题——按重量从小到大装载，最大化物品数量
- 理解贪心算法的适用条件：局部最优选择能导致全局最优解

## 📖 算法讲解

### 一、从 0/1 背包到部分背包

在算法世界里，背包问题是一个庞大的家族。我们之前可能听说过"0/1 背包"——你面前有 N 件物品，每件物品要么全拿，要么不拿（不能拿半件），在背包容量有限的情况下，如何选择使总价值最大？0/1 背包需要用到动态规划，因为它不能用简单的贪心策略解决。

但今天我们要学习的是背包家族中的另一个重要成员——**部分背包**（Fractional Knapsack），也叫分数背包。它与 0/1 背包最大的区别在于：**物品可以分割**。你可以拿走一件物品的一部分，比如半块黄金、三分之一袋金沙。这个看似微小的改变，却让问题的解法发生了翻天覆地的变化——从复杂的动态规划，变成了简单优美的贪心算法。

为什么可以贪心呢？让我们用一个生活中的例子来理解。假设你去超市购物，背包装不下所有想买的东西。如果所有商品都是密封包装不能拆的（0/1背包），你就需要精打细算，考虑各种组合；但如果商品可以散装称重（部分背包），你的策略就变得非常简单：先拿单位价格最贵的，再拿次贵的，直到背包装满为止。这个"先拿最划算的"策略，就是贪心算法的核心思想。

### 二、性价比排序——部分背包的贪心策略

在部分背包问题中，贪心策略非常简单：**按照单位重量的价值（价值 ÷ 重量，也就是性价比）从高到低排序，依次装入背包**。具体步骤如下：

1. 计算每种物品的"性价比"（单位重量的价值）：ratio = value / weight
2. 将所有物品按照性价比从高到低排序
3. 依次考虑每种物品：
   - 如果背包剩余容量大于等于该物品的全部重量 → 全部装入
   - 如果背包剩余容量小于该物品的全部重量但大于 0 → 装入部分，装满背包，算法结束
   - 如果背包已满 → 结束

这个策略为什么是正确的呢？因为物品可以分割，所以不存在"拿出一个完整的物品来给另一个物品腾空间"的问题。每个单位重量的"背包空间"只关心一件事：谁能给我带来最大的价值？把最值钱的东西优先塞进去，每一步都是当前最优的选择，最终就能得到全局最优解。

数学上可以这样表述：如果存在一个比贪心策略更优的方案，它一定在某些重量单位上选择了性价比更低的物品，而把性价比更高的物品留在了外面。但我们可以把这部分"低性价比物品"换成等重量的"高性价比物品"，总价值只会增加不会减少，所以贪心策略不可能被超越。

### 三、最优装载问题——另一个贪心视角

最优装载问题（Optimal Loading）是另一个经典的贪心问题。问题描述为：有 N 个集装箱，每个集装箱的重量为 w_i，一艘轮船的载重量为 C。目标是**最大化装载的集装箱数量**（不考虑价值，只看数量）。

这个问题的贪心策略也非常直观：**按重量从小到大排序，先装轻的，能装多少装多少**。因为每个集装箱对目标的贡献都是"1 个"，而消耗的资源是"重量"，所以我们应该优先选择消耗资源最少的集装箱。这就好比打包行李箱时，如果我们的目标是尽量多带东西（不管东西贵不贵），那肯定是先往箱子里塞又轻又小的物品。

最优装载问题的贪心策略同样可以用交换论证来证明其正确性：假设最优解中没有选择当前最轻的集装箱，那么将它替换掉最优解中最重的那个，总重量只减不增，数量不变，说明选最轻的不会导致更差的结果。

### 四、部分背包与最优装载的对比

这两个问题虽然都用到了排序+贪心，但排序依据不同：

| 问题 | 排序依据 | 贪心方向 | 目标 |
|------|----------|----------|------|
| 部分背包 | 性价比（价值/重量） | 从大到小 | 最大化总价值 |
| 最优装载 | 重量 | 从小到大 | 最大化物品数量 |

这也说明了一个重要的道理：**贪心的关键在于确定正确的"贪心标准"**。标准不同，结果可能完全不同。选择正确的贪心标准，是贪心算法成功的关键。

## 💻 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <vector>
#include <iomanip>
using namespace std;

// 定义物品结构体（用于部分背包）
struct Item {
    double weight;  // 物品重量
    double value;   // 物品总价值
    double ratio;   // 性价比 = value / weight

    // 构造函数
    Item(double w, double v) : weight(w), value(v) {
        ratio = v / w;
    }

    // 重载小于号，用于按性价比从大到小排序
    bool operator<(const Item& other) const {
        return ratio > other.ratio;  // 性价比高的排在前面
    }
};

// 部分背包——贪心算法
double fractionalKnapsack(vector<Item>& items, double capacity) {
    // 第一步：按性价比从高到低排序
    sort(items.begin(), items.end());

    double totalValue = 0.0;   // 总价值
    double remain = capacity;  // 背包剩余容量

    // 第二步：贪心选择——优先拿性价比最高的
    for (const Item& item : items) {
        if (remain >= item.weight) {
            // 剩余容量够装整个物品 → 全部装入
            totalValue += item.value;
            remain -= item.weight;
        } else if (remain > 0) {
            // 容量不够装整个 → 装入部分
            totalValue += item.ratio * remain;  // 只取能装下的部分
            remain = 0;  // 背包满了
            break;
        }
        // remain == 0 时背包已满，直接结束
    }

    return totalValue;
}
```

## 📊 复杂度分析

**部分背包（分数背包）：**
- 时间复杂度：O(N log N)，主要开销来自对物品按性价比排序。排序之后，贪心选择只需一次线性遍历 O(N)
- 空间复杂度：O(N)，需要存储 N 个物品的信息（重量、价值、性价比）

**最优装载：**
- 时间复杂度：O(N log N)，对 N 个集装箱按重量排序
- 空间复杂度：O(N)，需要存储 N 个重量值

对比 0/1 背包的动态规划解法 O(N × C)，部分背包的贪心解法在时间复杂度上有明显优势，尤其是在背包容量 C 很大时。

## 🏋️ 经典例题

### 例题1：金银岛

**题目描述**：在金银岛上，人们发现了 N 种金属。第 i 种金属的总重量为 w_i（千克），总价值为 v_i（金币）。由于背包容量有限（最多装 C 千克），你可以选择每种金属的一部分带走（金属可以切割）。请问最多能带走多少金币？

**输入格式**：
- 第一行：两个整数 N 和 C，用空格分隔，分别表示金属的种类数和背包容量
- 接下来 N 行，每行两个整数 w_i 和 v_i，表示第 i 种金属的重量和总价值

**输出格式**：
- 一个实数（保留两位小数），表示能获得的最大金币数

**样例输入**：
```
3 50
10 60
20 100
30 120
```

**样例输出**：
```
240.00
```

**样例解释**：
- 三种金属的性价比分别为：60/10=6、100/20=5、120/30=4
- 按性价比排序：金属1(6) > 金属2(5) > 金属3(4)
- 先装金属1：重量10，价值60，剩余容量40
- 再装金属2：重量20，价值100，剩余容量20
- 最后装金属3的部分：只能装20千克，价值20 × 4 = 80
- 总价值 = 60 + 100 + 80 = 240

**题解代码**：
```cpp
#include <iostream>
#include <algorithm>
#include <cstdio>
using namespace std;

// 金属结构体
struct Metal {
    double weight;  // 重量
    double value;   // 总价值
    double ratio;   // 性价比 = 价值 / 重量

    // 按性价比从大到小排序
    bool operator<(const Metal& other) const {
        return ratio > other.ratio;
    }
};

int main() {
    int N;          // 金属种类数
    double C;       // 背包容量
    cin >> N >> C;

    Metal metals[105];  // 最多100种金属
    for (int i = 0; i < N; i++) {
        cin >> metals[i].weight >> metals[i].value;
        metals[i].ratio = metals[i].value / metals[i].weight;
    }

    // 按性价比排序
    sort(metals, metals + N);

    double ans = 0.0;
    double remain = C;

    for (int i = 0; i < N; i++) {
        if (remain >= metals[i].weight) {
            // 全部装入
            ans += metals[i].value;
            remain -= metals[i].weight;
        } else {
            // 只能装一部分
            ans += metals[i].ratio * remain;
            break;  // 背包已满
        }
    }

    // 输出结果，保留两位小数
    printf("%.2f\n", ans);
    return 0;
}
```

### 例题2：最优装载

**题目描述**：一艘货轮的载重量为 C，码头上有 N 个集装箱待装船。第 i 个集装箱的重量为 w_i（吨）。为了提高运输效率，船长希望装载尽可能多的集装箱（不考虑集装箱内货物的价值）。请问最多能装几个集装箱？

**输入格式**：
- 第一行：两个整数 N 和 C，用空格分隔，表示集装箱数量和货轮载重量
- 第二行：N 个整数 w_1, w_2, ..., w_N，表示每个集装箱的重量

**输出格式**：
- 一个整数，表示最多能装载的集装箱数量

**样例输入**：
```
6 50
30 10 15 20 25 5
```

**样例输出**：
```
4
```

**样例解释**：
- 按重量从小到大排序：5、10、15、20、25、30
- 依次装载：5+10+15+20=50，恰好装满，共装4个
- 注意：虽然5+10+15+25=55超过50，而且不能只装集装箱的一部分

**题解代码**：
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int N, C;             // 集装箱数量和载重量
    cin >> N >> C;

    int weights[1005];    // 集装箱重量数组
    for (int i = 0; i < N; i++) {
        cin >> weights[i];
    }

    // 按重量从小到大排序（贪心：先装轻的）
    sort(weights, weights + N);

    int count = 0;        // 已装载数量
    int totalW = 0;       // 已装载总重量

    for (int i = 0; i < N; i++) {
        if (totalW + weights[i] <= C) {
            totalW += weights[i];
            count++;
        } else {
            break;  // 装不下了，不再尝试更重的
        }
    }

    cout << count << endl;
    return 0;
}
```

    cin >> N >> C;
    Item items[10005];

    for (int i = 0; i < N; i++) {
        double w, v, s;
        cin >> w >> v >> s;
        // 将每种物品的 s 件展开为 s 条记录
        for (int j = 0; j < (int)s; j++) {
            items[idx].weight = w;
            items[idx].value = v;
            items[idx].ratio = v / w;
            idx++;
        }
    }
    sort(items, items + idx);

    double ans = 0.0, remain = C;
    for (int i = 0; i < idx; i++) {
        if (remain >= items[i].weight) {
            ans += items[i].value;
            remain -= items[i].weight;
        } else {
            ans += items[i].ratio * remain;
            break;
        }
    }
    printf("%.2f\n", ans);
    return 0;
}

## 📝 本课小结

本节课我们学习了背包贪心中的两个经典问题：**部分背包**和**最优装载**。这两个问题的共同点是都可以用贪心算法求解，但贪心的标准不同。

部分背包的核心策略是**按性价比排序**——优先选取单位价值最高的物品，因为物品可以分割，所以这种简单策略就能得到全局最优解。这与 0/1 背包（物品不可分割，需要动态规划）形成了鲜明对比，帮助我们理解了"问题条件微小的变化可能导致解法巨大的差异"这一重要理念。

最优装载的贪心策略是**按重量从小到大排序**——优先装最轻的集装箱，以最大化装载数量。这个问题告诉我们：贪心标准的选择取决于优化目标——如果目标是数量，就选消耗最小的；如果目标是价值，就选性价比最高的。

记住贪心算法的精髓：**每一步都做出当前看来最好的选择，并且能证明这种局部最优最终能导致全局最优**。在接下来的课程中，我们还将学习如何证明贪心策略的正确性，以及遇到更多巧妙的贪心问题。
