# 第34课：高精度应用与优化

## 🎯 学习目标
- 理解压位存储（万进制）的优化思想：将一个整型变量存储多位十进制数字，减少数组长度和运算次数
- 掌握压位高精度的实现方法：包括万进制下的乘法、减法以及输出时的前导零处理
- 能够运用高精度解决2的N次方、Hanoi双塔等应用问题

## 📖 算法讲解

### 一、为什么要做压位优化？

在前几节课中，我们学习的高精度计算使用的是"一位一存"的方式——数组的每个元素只存储0~9的一个数字。这种方式简单直观，但效率不高。举个例子，如果要计算 2^500，结果有151位十进制数字，那么数组就需要151个元素。每次乘法都要对这151个元素逐一运算，非常耗时。

**压位存储（万进制）** 的核心思想是：让数组的每个元素存储多个十进制数字，而不是只存一位。就像我们把零钱换成大额钞票一样，用更少的"容器"装下同样多的信息。

### 二、普通存储 vs 压位存储

```
普通存储（十进制，每位存一个数字）：
数组索引:  [0] [1] [2] [3] [4] [5] [6] [7]
存储内容:   1   2   3   4   5   6   7   8
表示的数值: 12345678  （需要8个数组元素）

压位存储（万进制，每位存4个十进制数字）：
数组索引:  [0]  [1]
存储内容:  5678 1234
表示的数值: 12345678  （只需要2个数组元素！）
```

可以看到，同样的数值，压位存储将数组长度缩短为原来的 1/4。如果选择基数为 10000（万进制），每个数组元素存储 4 位十进制数字，那么：

- 原来需要 N 个元素的数组，现在只需要约 N/4 个元素
- 每次运算的循环次数减少到原来的 1/4
- 整体效率提升约 4 倍

### 三、为什么选 10000 而不是更大的基数？

选择基数时需要权衡：
- 基数太大 → 乘法运算可能超出 int 范围（int 最大约 2.1×10^9）
- 基数太小 → 压缩效果不明显

以万进制（BASE = 10000）为例，在高精度乘低精度时：最大进位值约为 `BASE × 乘数 + 进位 ≈ 10000 × n + 进位`。如果乘数不超过 20000，结果仍在 int 安全范围内。对于 2 的 N 次方（乘数为 2），完全不用担心溢出问题。

### 四、压位高精度的实现要点

**1. 存储方式**
```cpp
const int BASE = 10000;  // 万进制基数
const int WIDTH = 4;      // 每个元素存储4位十进制数
vector<int> digits;       // digits[0]存低位，digits[size-1]存高位
```

**2. 乘法运算的变化**
```
普通乘法：逐位乘，进位是 / 10 和 % 10
  进位 = (digits[i] * x + carry) / 10
  当前位 = (digits[i] * x + carry) % 10

压位乘法：逐段乘，进位是 / BASE 和 % BASE
  进位 = (digits[i] * x + carry) / BASE
  当前段 = (digits[i] * x + carry) % BASE
```

**3. 输出时的前导零处理**
这是压位高精度最容易出错的地方！每个元素存储4位数字，但输出时如果某一段的数字不足4位，需要用前导零补齐。

```
例如：数值 10002 在万进制下存储为 [2, 1]
     输出时 digit[1]=1 直接输出 "1"
           digit[0]=2 需要补齐为 "0002"
     最终输出："10002"  ← 正确！
     如果忘记补零："12"     ← 错误！
```

### 五、Hanoi双塔问题的数学推导

Hanoi双塔问题是经典汉诺塔的变体：有 A、B、C 三根柱子，A 柱上有 2n 个圆盘，每种大小的圆盘有 2 个（完全相同）。移动规则不变，求最少移动次数。

**推导过程：**

普通汉诺塔（n 个不同大小的圆盘）的最少移动次数为：
```
H(n) = 2^n - 1
```

对于双塔问题，有 2n 个圆盘，但由 n 种不同的"大小级别"组成，每种大小有 2 个相同圆盘。可以这样思考：

1. 先把上面 2(n-1) 个圆盘移到 B 柱：需要 H_double(n-1) 步
2. 把最大的 2 个圆盘（大小相同）从 A 移到 C：由于大小相同，它们之间没有顺序限制，需要 2 步（A→B, A→C 然后 B→C，实际上是 2 步）
3. 把 B 柱上 2(n-1) 个圆盘移到 C 柱：需要 H_double(n-1) 步

得到递推公式：
```
H_double(n) = 2 × H_double(n-1) + 2
H_double(1) = 2
```

展开求解：
```
H_double(n) = 2^(n+1) - 2
```

验证：n=1 时，2^(1+1)-2=2，需要2步（两个相同圆盘直接放到C柱即可）。n=2 时，2^(2+1)-2=6，与样例输出一致。

## 💻 代码实现

```cpp
#include <iostream>
#include <vector>
#include <iomanip>
using namespace std;

const int BASE = 10000;  // 万进制基数
const int WIDTH = 4;      // 每个元素显示的宽度

struct BigInt {
    vector<int> digits;  // 低位在前，高位在后

    // 初始化：将整数 n 转为万进制
    BigInt(int n = 0) {
        while (n > 0) {
            digits.push_back(n % BASE);
            n /= BASE;
        }
        if (digits.empty()) digits.push_back(0);
    }

    // 高精度乘低精度
    void multiply(int x) {
        int carry = 0;
        for (int i = 0; i < (int)digits.size(); i++) {
            long long cur = (long long)digits[i] * x + carry;
            digits[i] = cur % BASE;
            carry = cur / BASE;
        }
        while (carry > 0) {
            digits.push_back(carry % BASE);
            carry /= BASE;
        }
    }

    // 高精度减2
    void subtract2() {
        int borrow = 2;
        for (int i = 0; i < (int)digits.size() && borrow > 0; i++) {
            if (digits[i] >= borrow) {
                digits[i] -= borrow;
                borrow = 0;
            } else {
                digits[i] = digits[i] + BASE - borrow;
                borrow = 1;
            }
        }
        // 去除前导零
        while (digits.size() > 1 && digits.back() == 0) {
            digits.pop_back();
        }
    }

    // 输出高精度数（处理前导零）
    void print() {
        // 先输出最高位（不需要补前导零）
        cout << digits.back();
        // 其余每位用 setw 和 setfill 补足4位
        for (int i = (int)digits.size() - 2; i >= 0; i--) {
            cout << setw(WIDTH) << setfill('0') << digits[i];
        }
        cout << endl;
    }
};

// 快速计算 2^n
BigInt pow2(int n) {
    BigInt result(1);
    for (int i = 1; i <= n; i++) {
        result.multiply(2);
    }
    return result;
}
```

## 📊 复杂度分析

**压位高精度乘低精度：**
- 时间复杂度：O(N/B)，其中 N 为十进制位数，B 为压缩位数（万进制下 B=4）。相比普通高精度乘法的 O(N)，效率提升约 4 倍
- 空间复杂度：O(N/B)，同样节省约 4 倍空间

**计算 2^n：**
- 结果有约 log10(2^n) = n × log10(2) ≈ 0.301n 位十进制数字
- 压位乘法需要执行 n 次，每次处理约 n/13 个万进制段
- 总时间复杂度约为 O(n²/13)
- 当 n=500 时，结果约151位，在万进制下只需要约38个元素，运算量完全可以接受

**Hanoi双塔（2^(n+1) - 2）：**
- 先计算 2^(n+1)，再减2
- 时间复杂度和空间复杂度同上

## 🏋️ 经典例题

### 例题1：2的N次方

**题目描述**：输入一个正整数 n（1 ≤ n ≤ 500），计算 2^n 的精确值。

**输入格式**：一个整数 n。

**输出格式**：2^n 的精确值。

**样例输入1**：
```
64
```

**样例输出1**：
```
18446744073709551616
```

**样例输入2**：
```
100
```

**样例输出2**：
```
1267650600228229401496703205376
```

**题解思路**：
1. 使用压位高精度（万进制），将 2 作为乘数，执行 n 次乘法
2. 每次乘法：将 BigInt 的每个万进制段乘以 2，处理进位
3. 输出时注意：最低位之外的所有段需要用前导零补齐到4位

**完整题解代码**：
```cpp
#include <iostream>
#include <vector>
#include <iomanip>
using namespace std;

const int BASE = 10000;
const int WIDTH = 4;

void solvePow2() {
    int n;
    cin >> n;

    vector<int> digits;
    digits.push_back(1);  // 初始值：2^0 = 1

    // 乘以 2，执行 n 次
    for (int k = 1; k <= n; k++) {
        int carry = 0;
        for (int i = 0; i < (int)digits.size(); i++) {
            int cur = digits[i] * 2 + carry;
            digits[i] = cur % BASE;
            carry = cur / BASE;
        }
        if (carry > 0) {
            digits.push_back(carry);
        }
    }

    // 输出结果
    cout << digits.back();  // 最高段，不补零
    for (int i = (int)digits.size() - 2; i >= 0; i--) {
        cout << setw(WIDTH) << setfill('0') << digits[i];
    }
    cout << endl;
}

int main() {
    solvePow2();
    return 0;
}
```

### 例题2：Hanoi双塔问题

**题目描述**：汉诺双塔问题：有 A、B、C 三根柱子，A 柱上有 2n 个圆盘，由 n 种不同大小组成，每种大小的圆盘有 2 个（完全相同）。要求将所有圆盘从 A 柱移动到 C 柱，移动规则与普通汉诺塔相同（每次只能移动一个圆盘，且大盘不能压在小盘上面）。输入 n，求最少移动次数。

**输入格式**：一个整数 n（1 ≤ n ≤ 200）。

**输出格式**：最少移动次数。

**样例输入**：
```
2
```

**样例输出**：
```
6
```

**公式推导**：
```
H_double(n) = 2^(n+1) - 2
```

**题解思路**：
1. 先使用压位高精度计算 2^(n+1)
2. 再从结果中减去 2（高精度减法）
3. 输出结果

**完整题解代码**：
```cpp
#include <iostream>
#include <vector>
#include <iomanip>
using namespace std;

const int BASE = 10000;
const int WIDTH = 4;

void solveHanoiTwin() {
    int n;
    cin >> n;

    // 计算 2^(n+1)
    vector<int> digits;
    digits.push_back(1);

    for (int k = 1; k <= n + 1; k++) {
        int carry = 0;
        for (int i = 0; i < (int)digits.size(); i++) {
            int cur = digits[i] * 2 + carry;
            digits[i] = cur % BASE;
            carry = cur / BASE;
        }
        if (carry > 0) {
            digits.push_back(carry);
        }
    }

    // 减去 2
    int borrow = 2;
    for (int i = 0; i < (int)digits.size() && borrow > 0; i++) {
        if (digits[i] >= borrow) {
            digits[i] -= borrow;
            borrow = 0;
        } else {
            digits[i] += BASE - borrow;
            borrow = 1;
        }
    }

    // 去除前导零
    while (digits.size() > 1 && digits.back() == 0) {
        digits.pop_back();
    }

    // 输出结果
    cout << digits.back();
    for (int i = (int)digits.size() - 2; i >= 0; i--) {
        cout << setw(WIDTH) << setfill('0') << digits[i];
    }
    cout << endl;
}

int main() {
    solveHanoiTwin();
    return 0;
}
```

### 练习题参考答案

```cpp
#include <iostream>
#include <vector>
#include <iomanip>
using namespace std;

const int BASE = 10000;   // 万进制基数
const int WIDTH = 4;       // 每段宽度

struct BigInt {
    vector<int> digits;  // 低位在前

    BigInt(int n = 0) {
        while (n) { digits.push_back(n % BASE); n /= BASE; }
        if (digits.empty()) digits.push_back(0);
    }

    void multiply(int x) {
        int carry = 0;
        for (int i = 0; i < (int)digits.size(); i++) {
            long long cur = (long long)digits[i] * x + carry;
            digits[i] = cur % BASE;
            carry = cur / BASE;
        }
        while (carry) {
            digits.push_back(carry % BASE);
            carry /= BASE;
        }
    }

    void subtract2() {
        int borrow = 2;
        for (int i = 0; i < (int)digits.size() && borrow > 0; i++) {
            if (digits[i] >= borrow) {
                digits[i] -= borrow;
                borrow = 0;
            } else {
                digits[i] = digits[i] + BASE - borrow;
                borrow = 1;
            }
        }
        while (digits.size() > 1 && digits.back() == 0)
            digits.pop_back();
    }

    void print() {
        cout << digits.back();
        for (int i = (int)digits.size() - 2; i >= 0; i--)
            cout << setw(WIDTH) << setfill('0') << digits[i];
    }
};

// 练习1：2的N次方
BigInt pow2(int n) {
    BigInt result(1);
    for (int i = 1; i <= n; i++) result.multiply(2);
    return result;
}

// 练习3：Hanoi双塔
BigInt hanoiTwin(int n) {
    BigInt result(1);
    for (int i = 1; i <= n + 1; i++) result.multiply(2);
    result.subtract2();
    return result;
}

// 练习4：3的N次方
BigInt pow3(int n) {
    BigInt result(1);
    for (int i = 1; i <= n; i++) result.multiply(3);
    return result;
}

// 练习5：阶乘（压位优化）
BigInt factorial(int n) {
    BigInt result(1);
    for (int i = 2; i <= n; i++) result.multiply(i);
    return result;
}

int main() {
    cout << "2^10 = ";
    pow2(10).print();
    cout << endl;

    cout << "Hanoi双塔 n=3: ";
    hanoiTwin(3).print();
    cout << endl;

    cout << "3^10 = ";
```

## 📝 本课小结

本节课我们学习了高精度计算的压位优化技术。压位存储（万进制）通过让每个数组元素存储4位十进制数字，将计算量和存储空间都缩减为原来的约1/4，在高精度计算中非常实用。我们掌握了压位乘法、压位减法以及输出时前导零处理等关键实现细节。通过 2 的 N 次方和 Hanoi 双塔问题两个应用实例，验证了压位高精度的正确性和高效性。压位思想不仅适用于万进制，也可以扩展到更大基数（如亿进制 BASE=100000000），读者可以根据实际需求灵活选择。
