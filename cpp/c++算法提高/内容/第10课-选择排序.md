# 第10课：选择排序——选最小放前面

## 🎯 学习目标
- 理解选择排序的核心思想：每一轮从未排序部分选出最小值，放到已排序部分的末尾
- 掌握选择排序的实现方法，包括最小值的查找和元素的交换
- 能够用选择排序解决第k小的数等拓展问题

## 📖 算法讲解

### 一、生活中的选择排序

同学们，你们有没有玩过扑克牌？假设你手里有一把洗乱了的扑克牌，要把它从小到大排好。有一种很自然的做法：先扫一眼所有牌，找出最小的那张（比如方块2），把它放到最左边；然后从剩下的牌里再找出最小的，放到第二张的位置；接着再从剩下的找最小，放到第三张……重复这个过程，直到所有牌都排好。

这个"每次都从剩下的牌里挑最小的一张，放到前面去"的过程，就是**选择排序（Selection Sort）**的核心思想。

```
初始： [64, 25, 12, 22, 11]
        ↑────────────────↑  未排序区 = 整个数组

第1轮：在 [64, 25, 12, 22, 11] 中找最小值 → 11
       将 11 与第1个位置(64)交换
       [11, 25, 12, 22, 64]
         ↑   ↑───────────↑  已排序区 = [11]，未排序区 = [25,12,22,64]

第2轮：在 [25, 12, 22, 64] 中找最小值 → 12
       将 12 与第2个位置(25)交换
       [11, 12, 25, 22, 64]
         ↑───↑   ↑───────↑  已排序区 = [11,12]，未排序区 = [25,22,64]

第3轮：在 [25, 22, 64] 中找最小值 → 22
       将 22 与第3个位置(25)交换
       [11, 12, 22, 25, 64]
         ↑───────↑   ↑───↑  已排序区 = [11,12,22]，未排序区 = [25,64]

第4轮：在 [25, 64] 中找最小值 → 25
       25 正好在第4个位置，无需交换
       [11, 12, 22, 25, 64]
         ↑───────────↑   ↑  已排序区 = [11,12,22,25]，未排序区 = [64]

最后一轮只剩一个元素64，它自然就是最大的，已经排好。
最终结果：[11, 12, 22, 25, 64]
```

### 二、选择排序的直观理解

选择排序就像老师给全班同学按身高排队：

1. 老师站在队伍前面，用目光扫过全班同学，找到最矮的那位同学。
2. 让最矮的同学和站在第一个位置的同学交换位置。
3. 第一个位置搞定后，老师在剩下的同学中继续找最矮的，和第二位同学交换。
4. 重复这个过程，直到所有同学都按从矮到高排好。

这个算法的"套路"非常简单：
- **每一轮**，在还没排好的部分里找到最小值
- **找到后**，把它和当前轮次的"目标位置"上的元素交换
- **目标位置**从第0个开始，依次往后移动

```
选择排序的执行过程（数组长度为 n）：

第1轮（i=0）：从 arr[0] 到 arr[n-1] 中找最小值，与 arr[0] 交换
第2轮（i=1）：从 arr[1] 到 arr[n-1] 中找最小值，与 arr[1] 交换
第3轮（i=2）：从 arr[2] 到 arr[n-1] 中找最小值，与 arr[2] 交换
...
第n-1轮（i=n-2）：从 arr[n-2] 到 arr[n-1] 中找最小值，与 arr[n-2] 交换
```

对于有 n 个元素的数组，我们需要进行 **n-1** 轮选择。因为当 n-1 个元素都排好后，最后一个元素自然也就归位了。

### 三、最小值查找的策略

在每一轮中，我们需要在未排序的部分中找到最小值。这本身也是一个算法问题——如何在数组的一部分中找到最小值？答案是：再次使用"逐个比较"的策略。

```
找最小值的过程（以在 arr[2..4] 中找最小值为例）：

假设数组当前为：[11, 12, 25, 22, 64]，需要在索引 2~4 中找最小值

步骤1：设 minIndex = 2（假设第一个就是最小的），minValue = 25
步骤2：比较 arr[3]=22 与 minValue=25，22 < 25，更新 minIndex=3, minValue=22
步骤3：比较 arr[4]=64 与 minValue=22，64 > 22，不更新
步骤4：遍历结束，最小值索引为 3，值为 22
```

关键代码框架如下：

```cpp
// 在 arr[start] 到 arr[n-1] 中找最小值的位置
int minIndex = start;
for (int j = start + 1; j < n; j++) {
    if (arr[j] < arr[minIndex]) {
        minIndex = j;  // 发现更小的，更新位置
    }
}
```

### 四、与冒泡排序的对比

选择排序和上一课学的冒泡排序都是 O(n²) 的排序算法，但它们的思路不同：

| 对比维度 | 冒泡排序 | 选择排序 |
|---------|---------|---------|
| 核心操作 | **相邻交换**：每次比较相邻两个元素，逆序就交换 | **选最小交换**：每次选出未排序区的最小值，换到前面 |
| 每轮结果 | 最大的元素"冒泡"到最后 | 最小的元素"浮"到最前面 |
| 交换次数 | 每次比较都可能交换（最多 n²/2 次） | 每轮最多交换1次（共 n-1 次） |
| 比较次数 | 约 n²/2 次 | 约 n²/2 次 |
| 稳定性 | 稳定（相等元素不交换） | 不稳定（交换可能打乱相等元素的顺序） |
| 适用场景 | 数据基本有序时效率高（可提前终止） | 交换代价高（如交换大文件）时更优 |

举个例子，对于数组 `[5, 3, 5, 2]`（两个5分别是5a和5b）：

- 冒泡排序结果：`[2, 3, 5a, 5b]`，稳定 ✓
- 选择排序：第1轮选到2，和5a交换，得到 `[2, 3, 5b, 5a]`，不稳定 ✗

### 五、选择排序的巧妙应用：找第k小的数

选择排序有一个非常巧妙的应用场景：如果我只想找到数组中**第k小的数**，而不需要对整个数组排序，那么只需要进行 k 轮选择即可！

这是因为选择排序每一轮都把当前未排序部分的最小值找到并放到正确位置。第1轮找到第1小的数，第2轮找到第2小的数……第k轮找到第k小的数。

```
例如：arr = [7, 2, 9, 1, 5]，找第3小的数（k=3）

第1轮：在 [7,2,9,1,5] 中选最小值1，放到第1位 → [1, 2, 9, 7, 5]
第2轮：在 [2,9,7,5] 中选最小值2，放到第2位 → [1, 2, 9, 7, 5]（已在位置）
第3轮：在 [9,7,5] 中选最小值5，放到第3位 → [1, 2, 5, 7, 9]
此时arr[2] = 5，就是第3小的数（k从1开始，对应索引k-1）
```

这种方法的时间复杂度是 O(k × n)。当 k 比较小的时候，它比完整排序 O(n²) 要快。当然，如果需要对整个数组排序，直接用完整的选择排序即可。

### 六、小结

选择排序的核心步骤可以概括为：

```
┌──────────────────────────────────────────────────────┐
│                  选择排序算法框架                       │
├──────────────────────────────────────────────────────┤
│  for (i = 0; i < n-1; i++)           // 外层：轮次    │
│      ↓                                                │
│      在 arr[i..n-1] 中找到最小值的位置 minIndex        │
│      ↓                                                │
│      交换 arr[i] 和 arr[minIndex]                     │
│      ↓                                                │
│      第 i+1 小的数已经归位                             │
└──────────────────────────────────────────────────────┘
```

选择排序虽然效率不算高，但思路清晰、实现简单，是学习排序算法的必经之路。更重要的是，"每次选最小"的思想在后面学习贪心算法、优先队列等知识时还会反复出现，可以说是算法思维的一块基石。

## 💻 代码实现

```cpp
#include <iostream>
using namespace std;

// 选择排序：将数组 arr 按升序排列
// 参数：arr[] - 待排序数组，n - 数组长度
void selectionSort(int arr[], int n) {
    // 外层循环：进行 n-1 轮选择
    // i 表示当前轮次，也是"目标位置"（要把这轮选出的最小值放到 arr[i]）
    for (int i = 0; i < n - 1; i++) {
        // 第1步：在未排序区间 arr[i] ~ arr[n-1] 中找到最小值的索引
        int minIndex = i;               // 先假设 arr[i] 就是最小的
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;           // 发现更小的，更新最小值的索引
            }
        }
        
        // 第2步：将最小值交换到目标位置 arr[i]
        // 如果 minIndex 就是 i，说明 arr[i] 已经在正确位置，无需交换
        if (minIndex != i) {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
}
```

## 📊 复杂度分析

**时间复杂度：O(n²)**

选择排序无论数据初始状态如何，都需要进行完整的比较：
- 外层循环执行 n-1 轮
- 内层循环的比较次数依次为：n-1, n-2, n-3, ..., 2, 1
- 总比较次数 = (n-1) + (n-2) + ... + 2 + 1 = n(n-1)/2 ≈ n²/2
- 因此时间复杂度为 O(n²)

即使数组一开始就是有序的，选择排序仍然会老老实实地进行每一轮比较（因为没有像冒泡排序那样的"提前终止"机制）。这是选择排序的一个特点：**比较次数是固定的，不受数据分布影响**。

**空间复杂度：O(1)**

选择排序只需要常数个额外变量（minIndex, temp 等），不随数据规模的增大而增长。这种不需要额外空间的排序算法称为**原地排序（In-place Sort）**。

**选择排序的优缺点总结：**

| 优点 | 缺点 |
|------|------|
| 思路简单直观，容易理解 | 时间复杂度 O(n²)，数据量大时较慢 |
| 交换次数少（每轮最多1次，总共 n-1 次） | 不是稳定的排序算法 |
| 原地排序，不占用额外空间 | 无论数据是否有序，比较次数一样多 |
| 可用于"只找前k个最小值"的场景 | 不适合链式存储结构（找最小值需要遍历） |

## 🏋️ 经典例题

### 例题1：第k小的数

**题目描述**：给定一个长度为 n 的整数序列，请找出其中第 k 小的数（k 从 1 开始计数）。

例如，序列 `[7, 2, 9, 1, 5]` 中，第 1 小的数是 1，第 3 小的数是 5。

**输入格式**：
- 第一行两个整数 n 和 k（1 ≤ k ≤ n ≤ 1000），用空格隔开。
- 第二行 n 个整数，表示数组元素，用空格隔开。

**输出格式**：一个整数，表示第 k 小的数。

**样例输入**：
```
5 3
7 2 9 1 5
```

**样例输出**：
```
5
```

**思路解析**：
利用选择排序的思想——每一轮把当前未排序部分的最小值放到前面。第 1 轮找到第 1 小的数，第 2 轮找到第 2 小的数……第 k 轮找到第 k 小的数。所以我们只需要执行 k 轮选择，arr[k-1] 就是第 k 小的数。

**题解代码**：
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    
    int arr[1005];  // 数组大小略大于题目上限
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }
    
    // 只进行 k 轮选择排序
    // 第 i 轮会将第 i+1 小的数放到 arr[i]
    for (int i = 0; i < k; i++) {
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        if (minIndex != i) {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
    
    // arr[k-1] 就是第 k 小的数（因为数组索引从 0 开始）
    cout << arr[k - 1] << endl;
    
    return 0;
}
```

**补充说明**：
- 如果 k = 1，就是找最小值，只需要 1 轮
- 如果 k = n，就是找最大值，需要 n 轮（等同于完整的选择排序）
- 本题也可以使用 `sort` 函数直接排序后输出 `arr[k-1]`，但使用选择排序的部分执行思想更能体现算法的灵活应用

### 例题2：选择排序验证

**题目描述**：使用选择排序对一个整数序列进行排序，输出**每一轮选择交换后**的序列状态，以便观察选择排序的逐步过程。

**输入格式**：
- 第一行一个整数 n（1 ≤ n ≤ 100），表示数组长度。
- 第二行 n 个整数，表示数组元素，用空格隔开。

**输出格式**：共 n-1 行，每行输出一轮选择交换后的数组状态（n 个整数用空格隔开）。

**样例输入**：
```
5
64 25 12 22 11
```

**样例输出**：
```
11 25 12 22 64
11 12 25 22 64
11 12 22 25 64
11 12 22 25 64
```

**样例解释**：
- 第1轮：在 [64,25,12,22,11] 中找到最小值 11（索引4），与 arr[0] 交换 → [11,25,12,22,64]
- 第2轮：在 [25,12,22,64] 中找到最小值 12（索引2），与 arr[1] 交换 → [11,12,25,22,64]
- 第3轮：在 [25,22,64] 中找到最小值 22（索引3），与 arr[2] 交换 → [11,12,22,25,64]
- 第4轮：在 [25,64] 中找到最小值 25（索引3），已在正确位置，无需交换 → [11,12,22,25,64]

**题解代码**：
```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int arr[105];
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }
    
    // 进行 n-1 轮选择排序
    for (int i = 0; i < n - 1; i++) {
        // 在未排序区间中找到最小值
        int minIndex = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        
        // 将最小值交换到目标位置
        if (minIndex != i) {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
        
        // 输出本轮交换后的数组状态
        for (int j = 0; j < n; j++) {
            if (j > 0) cout << " ";
            cout << arr[j];
        }
        cout << endl;
    }
    
    return 0;
}
```

**拓展思考**：
- 观察输出结果，你能发现选择排序的规律吗？前 i 个数总是有序的，且都比后面的数小。
- 如果数组中已有部分元素有序，选择排序会少做工作吗？不会，因为每次都要扫描整个未排序区间来找最小值。
- 最后一次输出如果有 n 个元素，该输出多少行？n-1 行（因为当只剩一个元素时它自然归位）。

```cpp
#include <iostream>
```

```cpp
int main() {
    int n, k, arr[1005];

    for (int i = 0; i < n; i++) cin >> arr[i];

            }
        }
        if (minIndex != i) {
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
    
    int sum = 0;
    for (int i = 0; i < k; i++) {
        sum += arr[i];
    }
    cout << sum << endl;
    return 0;
}
```

#### 挑战题 参考代码
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

void twoWaySelectSort(int arr[], int n) {
    int left = 0, right = n - 1;
    
    while (left < right) {
        int minIndex = left, maxIndex = right;
        
        // 在未排序区间 [left, right] 中同时找最小值和最大值
        for (int i = left; i <= right; i++) {
            if (arr[i] < arr[minIndex]) minIndex = i;
            if (arr[i] > arr[maxIndex]) maxIndex = i;
        }
        
        // 将最小值交换到 left
        if (minIndex != left) {
            swap(arr[minIndex], arr[left]);
            // 如果最大值恰好在 left 位置，它被换到了 minIndex
            if (maxIndex == left) maxIndex = minIndex;
        }
        
        // 将最大值交换到 right
        if (maxIndex != right) {
            swap(arr[maxIndex], arr[right]);
        }
        
        left++;
        right--;
    }
}

int main() {
    int n, arr[1005];
    cin >> n;
    for (int i = 0; i < n; i++) cin >> arr[i];
    
    twoWaySelectSort(arr, n);
    
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << arr[i];
    }
    cout << endl;
    return 0;
}
```

## 📝 本课小结

本节课我们学习了选择排序算法。选择排序的核心思想非常直观：每一轮从未排序的部分中选出最小值，放到已排序部分的末尾。就像整理扑克牌时一张一张挑出最小的牌往前面放，整个过程简单明了。我们通过详细的步骤演示理解了选择排序的执行过程，掌握了使用两层循环实现选择排序的方法：外层循环控制轮次，内层循环寻找最小值的索引。

我们还学习了选择排序的一个重要应用——利用"每一轮找到第 i 小元素"的特性，只需执行 k 轮就可以找到第 k 小的数，而不必对整个数组完成排序。这种方法在只需要部分排序结果的场景中非常实用。

最后，我们对比了选择排序和冒泡排序的异同：两者时间复杂度相同，但选择排序交换次数更少。理解不同排序算法的特点，有助于我们在实际问题中选择最合适的算法。
