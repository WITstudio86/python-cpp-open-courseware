# 第17课：二分查找的边界处理——lower_bound与upper_bound

## 🎯 学习目标
- 理解二分查找中边界问题的核心难点：为什么 while(left <= right) 和 while(left < right) 会带来不同的结果？
- 掌握手写 lower_bound 的思路：查找有序数组中第一个 ≥ x 的位置
- 掌握手写 upper_bound 的思路：查找有序数组中第一个 > x 的位置
- 能够利用 lower_bound 与 upper_bound 配合，求出目标元素在数组中的起止范围
- 学会在经典例题"数的范围"中灵活运用边界二分查找解决问题

## 📖 算法讲解

### 一、二分查找为什么要关注"边界"？

在前两节课中，我们学习了最基础的二分查找——在有序数组中判断某个值是否存在。那个版本非常简单：找到中间元素，和目标比较，相等就返回，否则缩小一半范围。但真实的问题往往比"是否存在"更复杂。比如：

- 查找第一个 **大于等于** x 的元素在哪里？
- 查找最后一个 **小于** x 的元素在哪里？
- 查找 x 在数组中出现了多少次？从哪个位置开始，到哪个位置结束？

这些问题的答案都隐藏在"边界"中。要回答它们，我们需要比"相等就返回"更精细的控制。这就要用到二分查找中两个最重要的概念：**lower_bound** 和 **upper_bound**。

### 二、什么是 lower_bound？

**lower_bound** 的含义是：在 **有序数组**（升序）中，找到 **第一个大于或等于** 目标值 x 的元素的位置（下标）。如果所有元素都小于 x，则返回数组的长度 n（表示"不存在"）。

举个具体的例子——假设有一个已经排好序的数组：

```
数组索引： 0   1   2   3   4   5   6   7   8
数组内容： 1   3   3   5   7   9   9   9   11
```

- 查询 x = 3：数组中第0位是1（<3），第1位是3（≥3），所以 lower_bound 返回 **1**
- 查询 x = 4：数组中没有4，但第3位的5是第一个大于4的，所以 lower_bound 返回 **3**
- 查询 x = 9：数组中第5位是第一个9，所以 lower_bound 返回 **5**
- 查询 x = 12：所有元素都小于12，返回 **9**（即数组长度 n）

注意：lower_bound 返回的是"第一个 ≥ x"的位置，即使 x 在数组中不存在，它也会返回"第一个比 x 大"的位置。

### 三、什么是 upper_bound？

**upper_bound** 的含义是：在 **有序数组**（升序）中，找到 **第一个严格大于** 目标值 x 的元素的位置（下标）。如果所有元素都 ≤ x，则返回数组的长度 n。

同样以上面的数组为例：

```
数组索引： 0   1   2   3   4   5   6   7   8
数组内容： 1   3   3   5   7   9   9   9   11
```

- 查询 x = 3：第一个严格大于3的元素是5，位置在索引3，所以 upper_bound 返回 **3**
- 查询 x = 9：第一个严格大于9的元素是11，位置在索引8，所以 upper_bound 返回 **8**
- 查询 x = 11：所有元素都 ≤ 11，返回 **9**（数组长度 n）

### 四、lower_bound 与 upper_bound 的妙用

将 lower_bound 和 upper_bound 结合起来，我们可以解决很多实际问题：

1. **查找 x 在数组中出现的次数** = upper_bound(x) - lower_bound(x)
   - 例如 x = 9：upper_bound(9) = 8，lower_bound(9) = 5，出现次数 = 8 - 5 = **3 次**

2. **查找 x 第一次出现的位置** = lower_bound(x)（但需要额外检查该位置的值是否真的等于 x）

3. **查找 x 最后一次出现的位置** = upper_bound(x) - 1（同样需要检查）

4. **判断 x 是否存在** = (lower_bound(x) != n && a[lower_bound(x)] == x)

### 五、手写 lower_bound 的核心代码与边界细节

手写 lower_bound 时，最容易出错的地方就是 while 循环的条件和 left、right 的更新方式。这里给出一种经典的写法：

```cpp
// 在有序数组 a[0..n-1] 中查找第一个 >= x 的位置
int lower_bound(int a[], int n, int x) {
    int left = 0, right = n - 1;
    int ans = n;  // 默认答案为 n，表示"不存在"
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] >= x) {
            ans = mid;      // 记录当前可能的答案
            right = mid - 1; // 继续往左找，看有没有更靠前的
        } else {
            left = mid + 1;
        }
    }
    return ans;
}
```

**边界细节解析**：

- 为什么用 `left <= right` 而不是 `left < right`？因为当 left == right 时，区间中还有一个元素需要检查。使用 `<=` 确保每个元素都被考虑到。
- 为什么记录 ans？因为我们不是要找"等于 x"，而是要找"第一个 ≥ x"。当 a[mid] ≥ x 时，mid 是一个候选答案，但我们不知道左边是否还有更小的位置也满足条件，所以继续向左搜索。
- 为什么 `left + (right - left) / 2` 而不是 `(left + right) / 2`？防止 left + right 溢出（在 int 范围内通常不会溢出，但这是一个好习惯）。
- ans 初始化为 n：如果循环中从未更新过 ans，说明没有元素满足 ≥ x，此时应返回 n。

### 六、手写 upper_bound 的实现

upper_bound 与 lower_bound 只有一处关键不同：**判断条件从 `>=` 变成 `>`**。

```cpp
// 在有序数组 a[0..n-1] 中查找第一个 > x 的位置
int upper_bound(int a[], int n, int x) {
    int left = 0, right = n - 1;
    int ans = n;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] > x) {
            ans = mid;       // 记录候选答案
            right = mid - 1; // 继续向左找更靠前的位置
        } else {
            left = mid + 1;
        }
    }
    return ans;
}
```

唯一的变化是 `a[mid] >= x` 改成了 `a[mid] > x`。这意味着：lower_bound 找的是第一个"不小于 x"的位置，upper_bound 找的是第一个"大于 x"的位置。

### 七、另一种经典写法（左闭右开区间）

有些同学的教材上可能看到另一种写法，使用左闭右开区间 [left, right)：

```cpp
int lower_bound_v2(int a[], int n, int x) {
    int left = 0, right = n;  // 注意：right = n，不是 n-1
    while (left < right) {    // 注意：left < right，不是 <=
        int mid = left + (right - left) / 2;
        if (a[mid] >= x) {
            right = mid;      // right 是开区间，所以不 -1
        } else {
            left = mid + 1;
        }
    }
    return left;  // left == right，即为答案
}
```

这种写法同样正确，而且 C++ STL 中的 `std::lower_bound` 就是基于这个思路实现的。同学们可以选择自己更容易理解的一种来记忆，但务必把其中一种吃透。

## 💻 代码实现

### lower_bound 完整实现

```cpp
/**
 * lower_bound：在升序数组 a[0..n-1] 中查找第一个 >= x 的位置
 * @param a   升序数组
 * @param n   数组长度
 * @param x   目标值
 * @return    第一个 >= x 的元素下标；若不存在则返回 n
 * 
 * 算法思想：
 *   维护搜索区间 [left, right]，每次取中点 mid。
 *   若 a[mid] >= x，说明 mid 是一个候选答案，
 *   但左边可能还有更小的索引也满足条件，所以 right = mid - 1 继续找。
 *   若 a[mid] < x，说明答案一定在右边，left = mid + 1。
 */
int my_lower_bound(int a[], int n, int x) {
    int left = 0, right = n - 1;
    int ans = n;                    // 默认答案：不存在
    while (left <= right) {
        int mid = left + (right - left) / 2;  // 防溢出
        if (a[mid] >= x) {
            ans = mid;              // 记录候选答案
            right = mid - 1;        // 尝试找更靠左的
        } else {
            left = mid + 1;         // a[mid] < x，去右边找
        }
    }
    return ans;
}
```

### upper_bound 完整实现

```cpp
/**
 * upper_bound：在升序数组 a[0..n-1] 中查找第一个 > x 的位置
 * @param a   升序数组
 * @param n   数组长度
 * @param x   目标值
 * @return    第一个 > x 的元素下标；若不存在则返回 n
 * 
 * 算法思想与 lower_bound 几乎一致，区别仅在于：
 *   判断条件从 a[mid] >= x 变为 a[mid] > x。
 *   这样就能找到"第一个严格大于 x"的位置。
 */
int my_upper_bound(int a[], int n, int x) {
    int left = 0, right = n - 1;
    int ans = n;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] > x) {
            ans = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return ans;
}
```

### C++ STL 中的 lower_bound 和 upper_bound

在实际竞赛中，可以直接使用 STL 提供的函数：

```cpp
#include <algorithm>
// lower_bound(begin, end, x) 返回第一个 >= x 的迭代器
// upper_bound(begin, end, x) 返回第一个 > x 的迭代器
// 转为下标：减去数组首地址即可
int pos1 = lower_bound(a, a + n, x) - a;
int pos2 = upper_bound(a, a + n, x) - a;
```

## 📊 复杂度分析

**时间复杂度**：

lower_bound 和 upper_bound 的核心算法都是二分查找。每次循环将搜索区间缩小一半，因此循环最多执行 log₂(n) 次。每次循环执行常数次比较和赋值操作。

- **时间复杂度：O(log n)**，其中 n 是数组长度
- 对于 n = 10^6（一百万）的数组，只需要约 20 次比较就能找到答案
- 对比线性查找的 O(n)（最坏需要一百万次），二分查找的效率提升是巨大的

**空间复杂度**：

算法只使用了 left、right、mid、ans 等常数个变量，不依赖于输入规模。

- **空间复杂度：O(1)**

### 例题1：查找第一个 >= x 的位置

**题目描述**：

给定一个已经排好序的升序数组（可能存在重复元素），以及 q 次查询。每次查询给出一个整数 x，请输出数组中第一个大于或等于 x 的元素的下标（下标从 0 开始）。如果所有元素都小于 x，则输出 -1。

**输入格式**：

```
第一行：两个整数 n 和 q，分别表示数组长度和查询次数（1 ≤ n, q ≤ 10^5）
第二行：n 个升序排列的整数 a[0], a[1], ..., a[n-1]（-10^9 ≤ a[i] ≤ 10^9）
接下来 q 行：每行一个整数 x，表示一次查询
```

**输出格式**：

对于每次查询，输出一行一个整数，表示第一个 ≥ x 的元素下标。若不存在则输出 -1。

**样例输入**：

```
6 4
1 3 5 7 7 9
3
7
10
0
```

**样例输出**：

```
1
3
-1
0
```

**样例解释**：

- x = 3：a[1] = 3 ≥ 3，输出 1
- x = 7：a[3] = 7 ≥ 7，输出 3（第一个 7 的位置）
- x = 10：所有元素都小于 10，输出 -1
- x = 0：a[0] = 1 ≥ 0，输出 0

**题解代码**：

```cpp
#include <iostream>
using namespace std;

const int MAXN = 100005;
int a[MAXN];

// 手写 lower_bound：查找第一个 >= x 的位置，不存在返回 -1
int lower_bound_pos(int a[], int n, int x) {
    int left = 0, right = n - 1;
    int ans = -1;  // -1 表示不存在
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] >= x) {
            ans = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n, q;
    cin >> n >> q;
    for (int i = 0; i < n; i++) cin >> a[i];
    
    while (q--) {
        int x;
        cin >> x;
        cout << lower_bound_pos(a, n, x) << '\n';
    }
    return 0;
}
```

### 例题2：数的范围

**题目描述**：

给定一个按照升序排列的长度为 n 的整数数组，以及 q 次查询。对于每次查询，返回一个元素 x 的起始位置和终止位置（下标从 0 开始）。

如果数组中不存在 x，则返回 "-1 -1"。

**输入格式**：

```
第一行：两个整数 n 和 q（1 ≤ n, q ≤ 10^5）
第二行：n 个升序排列的整数 a[0], a[1], ..., a[n-1]（-10^9 ≤ a[i] ≤ 10^9）
接下来 q 行：每行一个整数 x，表示一次查询
```

**输出格式**：

共 q 行，每行两个整数，分别表示 x 在数组中第一次出现的位置和最后一次出现的位置。如果 x 不存在，输出 "-1 -1"。

**样例输入**：

```
8 4
1 2 2 3 3 3 5 7
3
4
2
7
```

**样例输出**：

```
3 5
-1 -1
1 2
7 7
```

**样例解释**：

- x = 3：在索引 3、4、5 位置出现，起始 3，终止 5
- x = 4：不存在，输出 "-1 -1"
- x = 2：在索引 1、2 位置出现，起始 1，终止 2
- x = 7：只在索引 7 出现，起始 7，终止 7

**解题思路**：

- **起始位置** = lower_bound(x)：第一个 ≥ x 的位置。如果该位置的值恰好等于 x，那么它就是起始位置；否则 x 不存在。
- **终止位置** = upper_bound(x) - 1：upper_bound 返回第一个 > x 的位置，减 1 就是最后一个 ≤ x 的位置。由于我们已经确认 x 存在，减 1 后的位置一定是 x 的最后一次出现。

**题解代码**：

```cpp
#include <iostream>
using namespace std;

const int MAXN = 100005;
int a[MAXN];

// lower_bound：第一个 >= x 的位置
int my_lower_bound(int a[], int n, int x) {
    int left = 0, right = n - 1;
    int ans = n;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] >= x) {
            ans = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return ans;
}

// upper_bound：第一个 > x 的位置
int my_upper_bound(int a[], int n, int x) {
    int left = 0, right = n - 1;
    int ans = n;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] > x) {
            ans = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n, q;
    cin >> n >> q;
    for (int i = 0; i < n; i++) cin >> a[i];
    
    while (q--) {
        int x;
        cin >> x;
        
        int first = my_lower_bound(a, n, x);    // 第一个 >= x 的位置
        int last = my_upper_bound(a, n, x) - 1;  // 最后一个 <= x 的位置
        
        // 检查 x 是否真的存在
        if (first < n && a[first] == x) {
            cout << first << ' ' << last << '\n';
        } else {
            cout << "-1 -1\n";
        }
    }
    return 0;
}
```

**算法逻辑图示**：

```
以查询 x = 3 为例，数组：1 2 2 3 3 3 5 7

lower_bound(3):
  找到第一个 >= 3 的位置 → 索引 3（a[3] = 3）→ 起始位置

upper_bound(3):
  找到第一个 > 3 的位置 → 索引 6（a[6] = 5）→ upper_bound - 1 = 索引 5 → 终止位置

    索引:   0   1   2   3   4   5   6   7
    数值:   1   2   2   3   3   3   5   7
                      ↑           ↑
                  lower_bound  upper_bound
                   (起始=3)    (终止=5)
```

```cpp
#include <iostream>
using namespace std;

const int MAXN = 100005;
int a[MAXN];

int my_lower_bound(int a[], int n, int x) {
    int left = 0, right = n - 1, ans = n;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] >= x) {
            ans = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, q;
    cin >> n >> q;
```

## 📝 本课小结

本节课我们深入学习了二分查找中最容易出错的"边界处理"问题。核心内容总结如下：

1. **lower_bound**：在有序数组中查找第一个 ≥ x 的位置。当 a[mid] ≥ x 时，记录答案并向左收缩；否则向右搜索。它返回的是 x 的"下界"。

2. **upper_bound**：在有序数组中查找第一个 > x 的位置。实现与 lower_bound 几乎完全一样，唯一区别是判断条件从 ≥ 变为 >。它返回的是 x 的"上界"。

3. **lower_bound + upper_bound 组合技**：利用 `upper_bound(x) - lower_bound(x)` 可以求出 x 的出现次数；利用 `lower_bound(x)` 和 `upper_bound(x) - 1` 可以分别求出 x 的起始和终止位置。

4. **边界细节牢记在心**：
   - while 循环用 `left <= right` 保证每个元素都被检查
   - 用 `ans` 变量记录候选答案，保证即使没找到精确匹配也能返回正确位置
   - mid 用 `left + (right - left) / 2` 计算，养成防溢出好习惯

5. **与 STL 的关系**：C++ 标准库提供了 `std::lower_bound` 和 `std::upper_bound`，原理与本课手写版本一致。理解手写版本后，使用 STL 会更加得心应手。

二分查找看似简单，但其边界细节是许多同学初学时容易栽跟头的地方。建议大家多动手写几遍 lower_bound 和 upper_bound，达到能够"闭眼写出"的熟练程度。下一节课我们将进行查找算法的综合练习，巩固二分查找的灵活运用！
