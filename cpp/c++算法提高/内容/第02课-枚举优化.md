# 第2课：枚举优化——减少搜索空间

## 🎯 学习目标
- 理解为什么要优化枚举算法：减少不必要的计算
- 掌握缩小枚举范围的方法与技巧
- 学会使用 break 和 continue 进行剪枝优化
- 能够用优化后的枚举算法解决完美立方、回文平方数等问题

## 📖 算法讲解

### 一、为什么需要优化枚举？

在上一课中，我们学习了枚举算法的基本思想：把所有可能的情况逐一尝试。但是，当数据规模变大时，枚举算法的效率会急剧下降。

举个例子：如果要找出1到100000之间所有的质数，按照最朴素的枚举方法，对每个数 n，我们需要用 2 到 n-1 的所有数去试除，总共需要约 5×10⁹ 次运算。这在很多题目中是不可接受的。

因此，我们需要在保证"不遗漏任何解"的前提下，**尽量减少不必要的枚举**，这就是枚举优化的核心思想。

### 二、优化策略一：缩小枚举范围

很多时候，我们可以通过数学分析，缩小变量的枚举范围。

```
优化前：gong ∈ [0, 100]    →  枚举101次
优化后：gong ∈ [0, 20]     →  枚举21次（因为5×20=100，再多买不起）
```

**缩小范围的关键思路：**
- 利用变量的约束关系缩小范围（如公鸡最多买 100/5=20 只）
- 利用等式关系推导出一个变量，减少一层循环
- 确定合理的上下界

### 三、优化策略二：剪枝（提前排除）

"剪枝"就是把不可能产生答案的分支提前排除掉，就像修剪树枝一样。

```
枚举过程（树形结构）：
                 初始
            /    |    \
           i=1   i=2   i=3  ...
          /  \         ✂剪掉！（因为i=3不满足某条件）
        j=1  j=2
        ✂    ✓(找到解)
```

在代码中，剪枝通常通过 `continue` 和 `break` 来实现：
- **continue**：跳过当前这一次循环，进入下一次
- **break**：直接跳出当前循环，不再继续

```cpp
// continue 示例：跳过不符合条件的
for (int i = 1; i <= 100; i++) {
    if (i % 2 == 0) continue;  // 跳过偶数，只处理奇数
    // 处理奇数的代码...
}

// break 示例：找到第一个解就停止
for (int i = 1; i <= 1000; i++) {
    if (满足条件(i)) {
        cout << "找到了！" << i << endl;
        break;  // 找到就停止，不再继续搜索
    }
}
```

### 四、优化策略三：减少循环嵌套层数

当变量之间存在明显的数学关系时，可以用等式把其中一个变量用其他变量表示出来，从而减少一层循环。

```
例如：百钱买百鸡问题
gong + mu + xiao = 100  →  xiao = 100 - gong - mu

原本需要三层循环嵌套（100×100×100 = 百万次）
优化后只需要两层（20×33 = 660次）
效率提升超过1000倍！
```

### 五、优化策略四：利用对称性和单调性

有些问题具有对称性或单调性，可以进一步优化：
- **对称性**：如果 a 和 b 是对称的，可以约定 a ≤ b，减少一半枚举
- **单调性**：如果函数是单调的，当超过条件时可以提前终止

例如，在完美立方问题中，可以约定 a > b ≥ c ≥ d，避免重复和无效枚举。

### 六、枚举优化的总体原则

```
┌────────────────────────────────────────────────────────┐
│                  枚举优化原则                          │
├────────────────────────────────────────────────────────┤
│  ☑ 能不枚举的就不枚举（用数学关系推导）               │
│  ☑ 能少枚举的就少枚举（缩小范围）                     │
│  ☑ 能提前结束的就提前结束（剪枝）                     │
│  ☑ 能合并判断的就合并判断（减少条件检查次数）         │
└────────────────────────────────────────────────────────┘
```

## 💻 代码实现

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 判断回文数：正着读和反着读一样的数
bool isPalindrome(int n) {
    int original = n, reversed = 0;
    while (n > 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    return original == reversed;
}

// 验证完美立方：a^3 = b^3 + c^3 + d^3
// 其中 a, b, c, d 均为正整数
void findPerfectCube(int N) {
    // 枚举 a，b，c，d
    // 优化：约定 b ≤ c ≤ d，避免重复
    for (int a = 2; a <= N; a++) {
        int a3 = a * a * a;
        for (int b = 2; b < a; b++) {
            int b3 = b * b * b;
            // 剪枝：如果 b^3 已经太大，跳过
            if (b3 >= a3) break;
            for (int c = b; c < a; c++) {
                int c3 = c * c * c;
                // 剪枝：如果 b^3 + c^3 已经太大，跳过
                if (b3 + c3 >= a3) break;
                for (int d = c; d < a; d++) {
                    int d3 = d * d * d;
                    if (b3 + c3 + d3 == a3) {
                        cout << "Cube = " << a << ", Triple = ("
                             << b << "," << c << "," << d << ")" << endl;
                    }
                    // 剪枝：如果和已超过，无需再增大d
                    if (b3 + c3 + d3 > a3) break;
                }
            }
        }
    }
}

}
```

## 📊 复杂度分析

**完美立方（以N=100为例）：**
- 优化前（naive）：O(N⁴) ≈ 10⁸次，接近超时
- 优化后（剪枝+范围缩小）：实际枚举次数远小于理论值，约10⁵~10⁶次
- 空间复杂度：O(1)

**回文平方数（以1~1000为例）：**
- 时间复杂度：O(N × logM)，其中对每个数需要计算平方和判断回文
- 空间复杂度：O(1)

## 🏋️ 经典例题

### 例题1：完美立方

**题目描述**：形如 a³ = b³ + c³ + d³ 的等式被称为完美立方等式。例如 12³ = 6³ + 8³ + 10³。对于任意给定的正整数 N（N ≤ 100），请找出所有满足 a ≤ N 的完美立方等式，其中 b、c、d 均大于1且 b ≤ c ≤ d。

**输入格式**：一个整数 N（1 ≤ N ≤ 100）

**输出格式**：每行输出一组解，格式为 `Cube = a, Triple = (b,c,d)`

**样例输入**：
```
24
```

**样例输出**：
```
Cube = 6, Triple = (3,4,5)
Cube = 12, Triple = (6,8,10)
Cube = 18, Triple = (2,12,16)
Cube = 18, Triple = (9,12,15)
Cube = 19, Triple = (3,10,18)
Cube = 20, Triple = (7,14,17)
Cube = 24, Triple = (12,16,20)
```

**题解代码**：
```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    
    for (int a = 2; a <= N; a++) {
        int a3 = a * a * a;
        for (int b = 2; b < a; b++) {
            int b3 = b * b * b;
            if (b3 >= a3) break;  // 剪枝1
            for (int c = b; c < a; c++) {  // 利用排序优化
                int c3 = c * c * c;
                if (b3 + c3 >= a3) break;  // 剪枝2
                for (int d = c; d < a; d++) {  // 利用排序优化
                    int d3 = d * d * d;
                    int sum = b3 + c3 + d3;
                    if (sum == a3) {
                        cout << "Cube = " << a 
                             << ", Triple = (" << b << "," 
                             << c << "," << d << ")" << endl;
                    }
                    if (sum > a3) break;  // 剪枝3
                }
            }
        }
    }
    return 0;
}
```

### 例题2：回文平方数

**题目描述**：回文数是指从左向右读和从右向左读都一样的数，比如 12321 就是一个典型的回文数。现在给定一个正整数 N（1 ≤ N ≤ 1000），请找出所有在1到N之间，其平方也是回文数的数。

**输入格式**：一个正整数 N

**输出格式**：每行输出一个符合条件的数及其平方，格式为 `X * X = Y`

**样例输入**：
```
30
```

**样例输出**：
```
1 * 1 = 1
2 * 2 = 4
3 * 3 = 9
11 * 11 = 121
22 * 22 = 484
26 * 26 = 676
```

**题解代码**：
```cpp
#include <iostream>
using namespace std;

bool isPalindrome(int n) {
    int original = n, reversed = 0;
    while (n > 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    return original == reversed;
}

int main() {
    int N;
    cin >> N;
    
    for (int i = 1; i <= N; i++) {
        int square = i * i;
        if (isPalindrome(square)) {
            cout << i << " * " << i << " = " << square << endl;
        }
    }
    return 0;
}
```

**题目描述**：四平方和定理（拉格朗日定理）指出：每个正整数都可以表示为至多四个整数的平方和。给定一个正整数 N，请找出四个非负整数 a、b、c、d（a ≤ b ≤ c ≤ d），使得 a² + b² + c² + d² = N。如果有多个解，输出 a 最小的一组；若 a 相同则比较 b，以此类推。

### 🔍 参考答案

#### 基础题1 参考代码
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    if (n < 2) {
        cout << "No" << endl;
        return 0;
    }
    
    bool isPrime = true;
    // 优化：只试除到 sqrt(n)
    int limit = sqrt(n);
    for (int i = 2; i <= limit; i++) {
        if (n % i == 0) {
            isPrime = false;
            break;  // 剪枝：找到因子即退出
        }
    }
    
    if (isPrime)
        cout << "Yes" << endl;
    else
        cout << "No" << endl;
    return 0;
}
```

#### 基础题2 参考代码
```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 判断回文数
bool isPalindrome(int n) {
    int original = n, reversed = 0;
    while (n > 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    return original == reversed;
}

// 判断质数（优化版）
bool isPrime(int n) {
    if (n < 2) return false;
    int limit = sqrt(n);
    for (int i = 2; i <= limit; i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    int N, cnt = 0;
    cin >> N;
    for (int i = 1; i <= N; i++) {
        if (isPalindrome(i) && isPrime(i)) {
            cnt++;
        }
    }
    cout << cnt << endl;
    return 0;
}
```

#### 提高题1 参考代码
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int N;
    cin >> N;
    
    // 枚举四个数，利用剪枝和缩小范围
    int maxVal = sqrt(N);
    for (int a = 0; a <= maxVal; a++) {
        int a2 = a * a;
        if (a2 > N) break;
        for (int b = a; b <= maxVal; b++) {
            int b2 = b * b;
            if (a2 + b2 > N) break;
            for (int c = b; c <= maxVal; c++) {
                int c2 = c * c;
                if (a2 + b2 + c2 > N) break;
                int rest = N - a2 - b2 - c2;
                int d = sqrt(rest);
                // d 必须是整数，且 d >= c
                if (d * d == rest && d >= c) {
                    cout << a << " " << b << " " << c << " " << d << endl;
                    return 0;
                }
            }
        }
    }
    return 0;
}
```

#### 挑战题 参考代码
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int arr[105];
int n, target;

int main() {
    cin >> n >> target;
    for (int i = 0; i < n; i++) cin >> arr[i];
    
    // 先排序，便于剪枝和输出
    sort(arr, arr + n);
    
    bool found = false;
    // 四重循环枚举，配合剪枝
    for (int a = 0; a < n - 3; a++) {
        if (arr[a] * 4 > target) break;  // 剪枝：最小元素*4已超target
        for (int b = a + 1; b < n - 2; b++) {
            if (arr[a] + arr[b] * 3 > target) break;
            for (int c = b + 1; c < n - 1; c++) {
                if (arr[a] + arr[b] + arr[c] * 2 > target) break;
                for (int d = c + 1; d < n; d++) {
                    int sum = arr[a] + arr[b] + arr[c] + arr[d];
                    if (sum == target) {
                        cout << arr[a] << " " << arr[b] << " " 
                             << arr[c] << " " << arr[d] << endl;
                        found = true;
                    }
                    if (sum > target) break;  // 剪枝
                }
            }
        }
    }
    
    if (!found) cout << "No solution" << endl;
    return 0;
}
```

## 📝 本课小结

本节课我们学习了枚举算法的优化技巧。核心思想是"在保证不遗漏解的前提下，减少不必要的计算"。我们掌握了四种主要的优化策略：缩小枚举范围（通过数学分析确定更紧的上下界）、剪枝（用 break 和 continue 提前终止或跳过）、减少嵌套层数（利用等式关系推导变量）、以及利用问题的对称性和单调性。

通过完美立方和回文平方数两个例题，我们实践了这些优化技巧。特别是完美立方问题中，从 O(N⁴) 的朴素枚举优化到实际运行效率提升上百倍，充分说明了枚举优化的重要性。

优化枚举并不意味着枚举算法本身不好，而是让我们更加聪明地去枚举。正如一句名言所说："聪明的暴力比暴力的聪明更重要。"在后续的课程中，我们将继续学习更高级的枚举形式——排列枚举和子集枚举。
