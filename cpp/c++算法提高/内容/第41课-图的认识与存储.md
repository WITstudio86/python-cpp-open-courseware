## 📖 算法讲解

### 一、什么是图？

图（Graph）是计算机科学中最强大的数据结构之一，由**顶点集 V** 和**边集 E** 组成，记作 G = (V, E)。它可以描述万事万物之间错综复杂的连接关系。

```
        朋友圈关系图（无向图）
        
            [小明] ─────────── [小红]
              │                  │
              │                  │
            [小刚] ─────────── [小丽]
              │
              │
            [小强]

    在这个图中：
    - 顶点 V = {小明, 小红, 小刚, 小丽, 小强}
    - 边 E = {(小明,小红), (小明,小刚), (小红,小丽), (小刚,小丽), (小刚,小强)}
```

现实世界中处处是图：
- **社交网络**：用户是顶点，好友关系是边
- **道路地图**：城市是顶点，公路是边
- **网页链接**：网页是顶点，超链接是边
- **电路板**：元件是顶点，导线是边

### 二、图的分类

图可以分为以下常见类型：

| 类型 | 特点 | 举例 |
|------|------|------|
| **无向图** | 边没有方向，(u,v) 和 (v,u) 是同一条边 | 朋友圈好友关系（互为好友） |
| **有向图** | 边有方向，(u→v) 表示从 u 到 v | 微博关注关系（A关注B不代表B关注A） |
| **带权图** | 边上带有权重 | 城市间距离、网络流量 |
| **无权图** | 边只有存在/不存在两种状态 | 简单的好友关系 |

```
   有向图示例：            带权图示例：
   
   A ──→ B                  北京 ──1200km──→ 上海
   │     │                    │                │
   ↓     ↓                  300km           500km
   C ←── D                    │                │
                            南京 ──300km──→ 杭州
```

### 三、图的存储方式

在编程中，我们需要将图"存进计算机"。最常用的两种方式是邻接矩阵和邻接表。

#### 3.1 邻接矩阵

**邻接矩阵**用一个二维数组表示图：`int graph[MAXN][MAXN]`。

- 对于无权图：`graph[i][j] = 1` 表示顶点 i 到 j 有边，`0` 表示无边
- 对于带权图：`graph[i][j] = w` 表示边的权重，`∞`（或一个大数）表示无边
- 无向图的邻接矩阵是**对称的**：`graph[i][j] == graph[j][i]`

```
    邻接矩阵存储示意图（无向图）
    
    图结构:              邻接矩阵 graph[5][5]:
    
       1 ─── 2             1 2 3 4
        │   ╱            ┌───────┐
        │ ╱            1│0 1 0 1│
        3              2│1 0 1 0│
        │              3│0 1 0 1│
        4              4│1 0 1 0│
                        └───────┘
```

**邻接矩阵的特点**：

| 优点 | 缺点 |
|------|------|
| 实现简单，代码直观 | 空间复杂度 O(V²)，稀疏图浪费严重 |
| 查询 O(1)：直接判断两点是否有边 | 遍历邻居需要 O(V) |
| 修改边方便 | 无法存储重边（多重图） |

#### 3.2 邻接表

**邻接表**为每个顶点维护一个邻居列表：`vector<int> adj[MAXN]`。

```
    邻接表存储示意图（无向图）
    
    图结构:              邻接表:
    
       1 ─── 2           adj[1] = {2, 4}
        │   ╱            adj[2] = {1, 3}
        │ ╱             adj[3] = {2, 4}
        3                adj[4] = {1, 3}
        │
        4
```

**邻接表的特点**：

| 优点 | 缺点 |
|------|------|
| 空间复杂度 O(V + E)，稀疏图友好 | 查询两点是否有边需遍历列表 O(degree) |
| 遍历邻居高效 O(degree) | 删除边稍麻烦 |
| 天然支持重边存储 | 实现稍复杂 |

#### 3.3 链式前向星（进阶）

**链式前向星**是邻接表的一种高效数组实现，常用于算法竞赛：

```cpp
struct Edge {
    int to;      // 边的终点
    int next;    // 下一条边的编号
    int w;       // 边的权重（可选）
} edge[MAXM];
int head[MAXN];  // head[u] 指向 u 的第一条边
int cnt = 0;     // 边的计数器

void addEdge(int u, int v, int w) {
    edge[++cnt].to = v;
    edge[cnt].w = w;
    edge[cnt].next = head[u];
    head[u] = cnt;
}
```

### 四、如何选择存储方式？

| 场景 | 推荐方式 | 原因 |
|------|----------|------|
| 顶点数 ≤ 1000，边稠密 | 邻接矩阵 | O(1) 查询，实现简单 |
| 顶点数大，边稀疏（大多数情况） | 邻接表 | 空间 O(V+E)，遍历快 |
| 经常需要判断两点是否相邻 | 邻接矩阵 | O(1) 快速判断 |
| 只关心遍历/搜索 | 邻接表 | 遍历每条边一次 |
| 算法竞赛、追求极致性能 | 链式前向星 | 常数小，无 vector 开销 |

## 💻 代码实现

### 实现1：邻接矩阵

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 101;

class Graph {
private:
    int adjMat[MAXN][MAXN];  // 邻接矩阵
    int n;                   // 顶点数

public:
    // 构造函数：初始化矩阵
    Graph(int vertices) {
        n = vertices;
        memset(adjMat, 0, sizeof(adjMat));
    }

    // 添加无向边
    void addEdge(int u, int v) {
        if (u < 1 || u > n || v < 1 || v > n) return;
        adjMat[u][v] = 1;
        adjMat[v][u] = 1;   // 无向图对称
    }

    // 添加有向边 u → v
    void addDirectedEdge(int u, int v) {
        if (u < 1 || u > n || v < 1 || v > n) return;
        adjMat[u][v] = 1;
    }

    // 判断 u 和 v 是否相邻
    bool isAdjacent(int u, int v) {
        return adjMat[u][v] == 1;
    }

    // 获取顶点 u 的度数
    int getDegree(int u) {
        int deg = 0;
        for (int v = 1; v <= n; v++) {
            if (adjMat[u][v]) deg++;
        }
        return deg;
    }

    // 打印邻接矩阵
    void printMatrix() {
        cout << "邻接矩阵 (" << n << " × " << n << "):" << endl;
        cout << "   ";
        for (int j = 1; j <= n; j++) cout << j << " ";
        cout << endl << "  ┌";
        for (int j = 1; j <= n; j++) cout << "──";
        cout << "┐" << endl;

        for (int i = 1; i <= n; i++) {
            cout << i << " │ ";
            for (int j = 1; j <= n; j++) {
                cout << adjMat[i][j] << " ";
            }
            cout << "│" << endl;
        }
        cout << "  └";
        for (int j = 1; j <= n; j++) cout << "──";
        cout << "┘" << endl;
    }
};
```

### 实现2：邻接表

```cpp
#include <vector>

const int MAXN = 101;
vector<int> adj[MAXN];   // 邻接表，adj[u] 存储 u 的所有邻居

// 添加无向边
void addEdge(int u, int v) {
    adj[u].push_back(v);
    adj[v].push_back(u);
}

// 打印邻接表
void printAdjList(int n) {
    for (int i = 1; i <= n; i++) {
        cout << i << " → ";
        for (int v : adj[i]) {
            cout << v << " ";
        }
        cout << endl;
    }
}
```

## 📊 复杂度分析

| 操作 | 邻接矩阵 | 邻接表 |
|------|----------|--------|
| 存储空间 | O(V²) | O(V + E) |
| 添加边 | O(1) | O(1)（push_back 均摊） |
| 删除边 | O(1) | O(degree) |
| 查询边 (u,v) | O(1) | O(degree(u)) |
| 遍历 u 的所有邻居 | O(V) | O(degree(u)) |
| 遍历所有边 | O(V²) | O(V + E) |

**结论**：在大多数算法问题中（尤其是 V 较大、E 较稀疏时），邻接表是更优的选择。

## 🏋️ 经典例题

### 例题1：朋友关系存储

**题目描述**：  
输入 N 个人（编号 1~N）和 M 对朋友关系。使用邻接矩阵建立朋友关系图，并输出所有的朋友对（只输出一次，即 u < v）。

**输入格式**：
```
第一行：N M（N 人数，M 关系对数）
接下来 M 行，每行两个整数 u v，表示 u 和 v 是朋友
```

**输出格式**：
```
按顺序输出所有朋友对，每行一对
```

**输入样例**：
```
5 4
1 2
1 3
2 4
3 5
```

**输出样例**：
```
1 2
1 3
2 4
3 5
```

**解答代码**：

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    int N, M;
    cin >> N >> M;

    int graph[101][101];
    memset(graph, 0, sizeof(graph));

    // 读入朋友关系
    for (int i = 0; i < M; i++) {
        int u, v;
        cin >> u >> v;
        graph[u][v] = 1;
        graph[v][u] = 1;  // 无向图
    }

    // 输出所有朋友对（避免重复，只输出 u < v 的情况）
    for (int i = 1; i <= N; i++) {
        for (int j = i + 1; j <= N; j++) {
            if (graph[i][j]) {
                cout << i << " " << j << endl;
            }
        }
    }

    return 0;
}
```

### 例题2：邻接表建立与度数统计

**题目描述**：  
输入一个无向图，使用邻接表存储，并计算每个顶点的度数（与该顶点相连的边的条数）。

**输入样例**：
```
4 5
1 2
1 3
2 3
2 4
3 4
```

**输出样例**：
```
顶点 1 的度数：2
顶点 2 的度数：3
顶点 3 的度数：3
顶点 4 的度数：2
```

**解答代码**：

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 101;
vector<int> adj[MAXN];

int main() {
    int N, M;
    cin >> N >> M;

    // 建图
    for (int i = 0; i < M; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    // 输出每个顶点的度数
    for (int i = 1; i <= N; i++) {
        cout << "顶点 " << i << " 的度数：" << adj[i].size() << endl;
    }

    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

vector<int> adj[105];

int main() {
    int N, M;
    cin >> N >> M;
    for (int i = 0; i < M; i++) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    vector<pair<int, int>> deg;  // (度数, 编号)
    for (int i = 1; i <= N; i++)
        deg.push_back({adj[i].size(), i});

    sort(deg.begin(), deg.end(), [](auto& a, auto& b) {
        if (a.first != b.first) return a.first > b.first;
        return a.second < b.second;
    });

    for (auto& p : deg)
        cout << p.second << " " << p.first << endl;
    return 0;
}
```

#### 练习4参考代码

```cpp
#include <iostream>
using namespace std;

const int MAXN = 1005, MAXM = 10005;

struct Edge {
    int to, next, w;
} edge[MAXM];
int head[MAXN], cnt = 0;

void addEdge(int u, int v, int w) {
    edge[++cnt].to = v;
    edge[cnt].w = w;
    edge[cnt].next = head[u];
    head[u] = cnt;
}

int main() {
    int N, M;
    cin >> N >> M;
    for (int i = 0; i < M; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        addEdge(u, v, w);
    }

    for (int u = 1; u <= N; u++) {
        cout << u << ":";
        for (int e = head[u]; e != 0; e = edge[e].next)
            cout << " (" << edge[e].to << "," << edge[e].w << ")";
        cout << endl;
    }
    return 0;
}
```

## 📝 本课小结

- **图 G = (V, E)** 由顶点集 V 和边集 E 组成，是描述"关系"最自然的数学工具
- **邻接矩阵**：O(V²) 空间，O(1) 查边，适合稠密图和小规模问题
- **邻接表**：O(V+E) 空间，O(degree) 查边，适合稀疏图（大多数实际情况）
- **链式前向星**：邻接表的数组高效实现，是算法竞赛中的常用选择
- 选择存储方式的核心依据：**图的稠密程度**和**需要的操作类型**

图是数据结构与算法的重要基础。掌握了图的存储，我们就能以它为基石，去探索图的遍历、最短路径、最小生成树等更精彩的算法。下一课将学习**图的遍历——DFS 与 BFS**。
