# 第14课：计数排序与sort函数

## 🎯 学习目标

- 理解计数排序的原理：利用"桶"的思想，统计每个值出现的次数
- 掌握计数排序的适用场景和限制条件
- 学会使用C++ STL中的sort函数进行快速排序

## 📖 算法讲解

### 一、排序问题的引入

在日常生活中，我们经常需要对数据进行排序：老师要把考试成绩从高到低排列、体育课按身高站队、图书馆把书按编号摆放……排序是计算机科学中最基础也最重要的问题之一。

我们已经学过了冒泡排序、选择排序和插入排序。它们的共同特点是：通过**两两比较**元素来排序。这类算法的时间复杂度通常是 O(n²)（n 是元素个数）。当数据量很大时（比如 10 万个学生），O(n²) 的算法就会非常慢。

有没有更快的排序方法呢？答案是肯定的！今天我们学习两种新的排序方式：**计数排序**和 **STL 中的 sort 函数**。

### 二、计数排序的核心思想

#### 2.1 一个生活中的例子

假设你是班长，老师让你统计全班 40 个同学的考试成绩（分数范围 0~100），并且按分数从高到低排好队。你会怎么做？

聪明的做法是：在黑板上一行写出 0 到 100 共 101 个数字，然后每念到一个成绩，就在对应数字下面画一个"正"字的一笔。最后，数一数每个分数下面有几个"正"字，就知道每个分数有多少人，排序结果自然就出来了。

这个过程，就是**计数排序**的核心思想！

#### 2.2 "桶"的概念

在计数排序中，我们为每一个可能的数值准备一个"桶"（在程序中是一个数组元素）。每遇到一个数据，就把它扔进对应的桶里，桶里的计数器加 1。

```
数据范围 0~5，待排序数组：[3, 1, 2, 3, 0, 2, 3, 1]

步骤1：准备6个桶（0号到5号）
         ┌───┬───┬───┬───┬───┬───┐
  桶编号: │ 0 │ 1 │ 2 │ 3 │ 4 │ 5 │
         ├───┼───┼───┼───┼───┼───┤
  计数器: │ 0 │ 0 │ 0 │ 0 │ 0 │ 0 │
         └───┴───┴───┴───┴───┴───┘

步骤2：遍历数组，每个数扔进对应桶
  读到 3 → 3号桶 +1
  读到 1 → 1号桶 +1
  读到 2 → 2号桶 +1
  读到 3 → 3号桶 +1
  读到 0 → 0号桶 +1
  读到 2 → 2号桶 +1
  读到 3 → 3号桶 +1
  读到 1 → 1号桶 +1

         ┌───┬───┬───┬───┬───┬───┐
  桶编号: │ 0 │ 1 │ 2 │ 3 │ 4 │ 5 │
         ├───┼───┼───┼───┼───┼───┤
  计数器: │ 1 │ 2 │ 2 │ 3 │ 0 │ 0 │
         └───┴───┴───┴───┴───┴───┘

步骤3：从桶里"倒出"数据（从小到大依次输出）
  0号桶有1个 → 输出 0
  1号桶有2个 → 输出 1, 1
  2号桶有2个 → 输出 2, 2
  3号桶有3个 → 输出 3, 3, 3
  4号桶有0个 → 跳过
  5号桶有0个 → 跳过

排序结果：[0, 1, 1, 2, 2, 3, 3, 3]  ✓
```

#### 2.3 为什么计数排序这么快？

计数排序不需要进行元素之间的比较！它只做三件事：
1. **统计**：遍历一遍原数组，O(n)
2. **输出**：遍历一遍桶数组，O(m)（m 是数据范围大小）

总共 O(n + m) 的时间复杂度。当 m 不太大时（比如成绩 0~750，年龄 0~120），这比 O(n log n) 还快！

#### 2.4 计数排序的应用场景和限制

**适用场景：**
- 数据范围比较小（比如年龄、成绩、分数段等）
- 数据是整数（或可以映射到整数）
- 数据量大但范围小（如 10 万人的年龄排序，范围仅 0~120）

**不适用场景：**
- 数据范围非常大（比如要排序的手机号码，范围是 0~10¹¹）
- 数据是浮点数（如 3.14、2.71），不容易映射到整数下标
- 数据范围比数据量还大（如 100 个学生的学号在 1~10⁹ 之间）
- 需要稳定排序且有附带数据时（带卫星数据的计数排序需要前缀和技巧，入门阶段暂不讨论）

### 三、计数排序的代码实现步骤

1. **找范围**：先找出待排序数组中的最大值 maxVal 和最小值 minVal
2. **开桶**：创建大小为 `maxVal - minVal + 1` 的计数数组，初始化为 0
3. **入桶**：遍历原数组，`count[arr[i] - minVal]++`
4. **出桶**：遍历计数数组，将下标还原回原值填回结果

```
示例：arr = [5, 3, 5, 2, 8]
minVal = 2, maxVal = 8
桶大小 = 8 - 2 + 1 = 7  （下标 0~6 对应值 2~8）

      下标:  0   1   2   3   4   5   6
      对应值: 2   3   4   5   6   7   8
统计后 count: [1,  1,  0,  2,  0,  0,  1]

输出:
  下标0(值2)有1个 → 2
  下标1(值3)有1个 → 3
  下标2(值4)有0个 → 跳过
  下标3(值5)有2个 → 5, 5
  下标4(值6)有0个 → 跳过
  下标5(值7)有0个 → 跳过
  下标6(值8)有1个 → 8

排序结果：[2, 3, 5, 5, 8]
```

### 四、C++ STL 中的 sort 函数

#### 4.1 sort 函数简介

C++ 的 `<algorithm>` 头文件中提供了一个非常强大的排序函数 `sort()`。它的底层使用的是**快速排序 + 插入排序 + 堆排序**的混合算法（IntroSort），时间复杂度为 O(n log n)，已经非常接近最优。

#### 4.2 基本用法

```cpp
#include <algorithm>
#include <vector>

vector<int> arr = {5, 3, 1, 4, 2};
sort(arr.begin(), arr.end());  // 默认从小到大排序
// 结果：[1, 2, 3, 4, 5]
```

**参数说明：**
- `arr.begin()`：排序的起始位置（迭代器）
- `arr.end()`：排序的结束位置（迭代器，不包含）
- 第三个参数可选：比较函数

#### 4.3 从大到小排序

```cpp
sort(arr.begin(), arr.end(), greater<int>());
// 结果：[5, 4, 3, 2, 1]
```

#### 4.4 自定义比较函数

有时我们需要按特殊规则排序，比如按某个属性的值排序，或者按自定义的优先级排序。这时可以写一个**比较函数**：

```cpp
// 比较函数：a 应该在 b 前面时返回 true
bool cmp(int a, int b) {
    return a > b;  // 降序：大的在前
}

sort(arr.begin(), arr.end(), cmp);
```

对于结构体排序，自定义比较函数尤其有用：

```cpp
struct Student {
    string name;
    int score;
};

// 按成绩从高到低排，成绩相同时按名字字典序排
bool cmpStudent(Student a, Student b) {
    if (a.score != b.score) return a.score > b.score;
    return a.name < b.name;
}

sort(students.begin(), students.end(), cmpStudent);
```

#### 4.5 对普通数组使用 sort

```cpp
int arr[] = {5, 3, 1, 4, 2};
int n = 5;
sort(arr, arr + n);  // 注意：数组名是首地址，arr+n 是尾后地址
```

### 五、计数排序 vs sort 函数对比

| 对比维度 | 计数排序 | STL sort |
|---------|---------|----------|
| 时间复杂度 | O(n + m) | O(n log n) |
| 空间复杂度 | O(m) | O(log n) |
| 适用范围 | 整数、范围小 | 任意可比较类型 |
| 是否稳定 | 是（基础版） | 不一定 |
| 编码难度 | 简单 | 非常简单（一行代码） |
| 适用数据量 | n 很大、m 很小 | 通用场景 |

**选择建议：**
- 如果数据范围 m 远小于 n（比如 10 万人的年龄排序），用**计数排序**
- 一般场景下，直接用 `sort()` 就好，方便又可靠
- 比赛中，优先考虑 `sort()`，除非数据特征明显适合计数排序

## 💻 代码实现

### 计数排序完整实现

```cpp
#include <iostream>
#include <vector>
#include <algorithm>  // 为了使用 min、max 等函数
using namespace std;

/**
 * 计数排序函数
 * @param arr  待排序的整数数组（原地修改）
 * @param n    数组长度
 * 
 * 适用条件：
 *   1. 数组中元素都是整数
 *   2. 数据的范围（最大值-最小值）不宜过大
 *      建议范围不超过 10^6 左右（否则计数数组太大）
 */
void countingSort(int arr[], int n) {
    if (n <= 1) return;  // 空数组或单元素无需排序

    // 第一步：找出数组中的最小值和最大值
    int minVal = arr[0], maxVal = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < minVal) minVal = arr[i];
        if (arr[i] > maxVal) maxVal = arr[i];
    }

    // 第二步：创建计数数组（桶）
    // 桶的大小 = maxVal - minVal + 1
    int range = maxVal - minVal + 1;
    vector<int> count(range, 0);  // 全部初始化为 0

    // 第三步：遍历原数组，每个元素入桶
    // arr[i] 对应的桶下标是 arr[i] - minVal
    for (int i = 0; i < n; i++) {
        count[arr[i] - minVal]++;
    }

    // 第四步：从桶里"倒出"数据，回填到原数组
    int idx = 0;  // 原数组的写入位置
    for (int i = 0; i < range; i++) {
        // 第 i 个桶对应的实际值是 i + minVal
        // 这个桶里有 count[i] 个元素
        while (count[i] > 0) {
            arr[idx] = i + minVal;
            idx++;
            count[i]--;
        }
    }
}
```

### STL sort 使用示例

```cpp
#include <algorithm>
#include <vector>
#include <iostream>
using namespace std;

int main() {
    // 示例1：基本排序（升序）
    vector<int> v1 = {5, 2, 8, 1, 9, 3};
    sort(v1.begin(), v1.end());
    // v1 = [1, 2, 3, 5, 8, 9]

    // 示例2：降序排序
    vector<int> v2 = {5, 2, 8, 1, 9, 3};
    sort(v2.begin(), v2.end(), greater<int>());
    // v2 = [9, 8, 5, 3, 2, 1]

    // 示例3：对普通数组排序
    int arr[] = {5, 2, 8, 1, 9, 3};
    int n = 6;
    sort(arr, arr + n);  // arr = [1, 2, 3, 5, 8, 9]

    // 示例4：自定义比较函数
    // 按绝对值从小到大排序
    int arr2[] = {-5, 3, -1, 4, -2};
    sort(arr2, arr2 + 5, [](int a, int b) {
        return abs(a) < abs(b);
    });
    // arr2 = [-1, -2, 3, 4, -5]（绝对值递增）

    return 0;
}
```

## 📊 复杂度分析

### 计数排序

| 项目 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **O(n + m)** | n 为元素个数，m 为数据范围（max - min + 1）。需要遍历原数组 O(n)，再遍历桶数组 O(m) |
| 空间复杂度 | **O(m)** | 需要一个大小为 m 的计数数组作为"桶" |
| 稳定性 | **稳定** | 基础实现中，相同值的元素保持原有顺序（从桶倒出时按顺序） |
| 比较次数 | **0** | 计数排序不进行元素间的比较，这是它快的根本原因 |

### STL sort（IntroSort）

| 项目 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **O(n log n)** | 平均和最坏情况都是 O(n log n)。IntroSort 结合了快速排序、堆排序和插入排序的优点 |
| 空间复杂度 | **O(log n)** | 主要是递归调用栈的深度 |
| 稳定性 | **不稳定** | 相同值的元素可能改变相对顺序。若需稳定排序，使用 `stable_sort()`（也是 O(n log n)） |

### 可视化对比

```
数据量 n = 100000

如果数据范围 m = 100（如 0~100 的成绩）：
  计数排序：100000 + 100 ≈ 100000 次操作     ← 胜出！
  sort()  ：100000 × log₂(100000) ≈ 1700000 次操作

如果数据范围 m = 10000000（如一千万）：
  计数排序：需要开 1000 万个元素的数组，内存爆炸
  sort()  ：照常工作                            ← 胜出！
```

## 🏋️ 经典例题

### 例题1：年龄排序

**题目描述**：某学校进行体检，需要将学生的年龄从小到大排序输出。已知学生年龄在 6-18 岁之间。

**输入格式**：
- 第一行一个整数 n（1 ≤ n ≤ 100000），表示学生人数
- 第二行 n 个整数，表示每个学生的年龄

**输出格式**：
- 一行 n 个整数，按从小到大排序后的年龄，用空格分隔

**样例输入**：
```
8
12 15 8 10 13 8 15 10
```

**样例输出**：
```
8 8 10 10 12 13 15 15
```

**思路分析**：
- 年龄范围很小（6~18，只有 13 种可能的值），完美适合计数排序
- 开一个大小为 13 的桶（对应年龄 6~18），统计每个年龄的人数
- 最后按顺序输出即可

**题解代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    // 年龄范围 6~18，共13个值
    const int MIN_AGE = 6;
    const int MAX_AGE = 18;
    int cnt[MAX_AGE + 1] = {0};  // 计数数组，多开一位方便直接用年龄做下标
    
    // 读入并统计
    for (int i = 0; i < n; i++) {
        int age;
        cin >> age;
        cnt[age]++;  // 对应年龄的桶 +1
    }
    
    // 输出排序结果
    bool first = true;  // 控制空格的输出
    for (int age = MIN_AGE; age <= MAX_AGE; age++) {
        for (int j = 0; j < cnt[age]; j++) {
            if (!first) cout << " ";
            cout << age;
            first = false;
        }
    }
    cout << endl;
    
    return 0;
}
```

### 例题2：成绩统计

**题目描述**：输入 n 个学生的成绩（0~100），请统计每个分数段的人数，并按成绩从高到低输出有学生的成绩及对应人数。

**输入格式**：
- 第一行一个整数 n（1 ≤ n ≤ 100000）
- 第二行 n 个整数，表示成绩

**输出格式**：
- 多行，每行格式为 `成绩: 人数`
- 按成绩从高到低输出
- 只输出有学生考到的成绩

**样例输入**：
```
5
85 92 85 78 92
```

**样例输出**：
```
92: 2
85: 2
78: 1
```

**思路分析**：
- 成绩范围 0~100，非常适合用计数排序的思想来统计
- 开一个大小为 101 的数组统计每个分数的出现次数
- 从 100 到 0 遍历，如果某个分数有人考到就输出

**题解代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int cnt[101] = {0};  // 0~100 共101个分数
    
    // 统计每个分数的人数
    for (int i = 0; i < n; i++) {
        int score;
        cin >> score;
        cnt[score]++;
    }
    
    // 从高到低输出有人的分数
    for (int score = 100; score >= 0; score--) {
        if (cnt[score] > 0) {
            cout << score << ": " << cnt[score] << endl;
        }
    }
    
    return 0;
}
```

#include <iostream>
#include <algorithm>
#include <string>
using namespace std;

struct Student {
    string name;
    int score;
};

bool cmp(const Student &a, const Student &b) {
    if (a.score != b.score) return a.score > b.score;
    return a.name < b.name;
}

int main() {
    int n;
    cin >> n;
    Student stu[100005];
    for (int i = 0; i < n; i++) {
        cin >> stu[i].name >> stu[i].score;
    }
    sort(stu, stu + n, cmp);
    for (int i = 0; i < n; i++) {
        cout << stu[i].name << " " << stu[i].score << "\n";
    }
    return 0;
}

int main() {

            if (!first) cout << " ";
            cout << id;
            first = false;
        }
    }

}

#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

bool cmp(int a, int b) {
    if (abs(a) != abs(b)) return abs(a) < abs(b);
    return a < b;  // 绝对值相同时，负数 < 正数，所以负数在前
}

int main() {
    int n;
    cin >> n;
    vector<int> arr(n);
    for (int i = 0; i < n; i++) cin >> arr[i];
    sort(arr.begin(), arr.end(), cmp);
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << arr[i];
    }
    cout << endl;
    return 0;
}

## 📝 本课小结

本节课我们学习了两种高效的排序方法。**计数排序**通过"桶"的巧妙设计，在数据范围较小时可以做到 O(n + m) 的线性时间复杂度，比所有基于比较的排序算法都要快。它的核心步骤只有三步：找范围、入桶统计、出桶输出。计数排序特别适合年龄、成绩、名次等范围有限的整数数据。

另一方面，C++ 标准库提供的 **`sort()` 函数**是我们的"万能工具"——一行代码就能完成排序，底层优化的 IntroSort 算法保证 O(n log n) 的时间复杂度，适用于绝大多数场景。我们还可以通过自定义比较函数实现各种花式排序。

记住选择策略：数据范围小用计数排序（更快），通用场景用 `sort()`（更方便）。两者结合，你就能从容应对编程竞赛中几乎所有的排序问题了！
