## 📖 算法讲解

### 为什么需要高精度运算？

在 C++ 中，整数类型有固定的存储空间。`int` 类型通常占 4 个字节，能表示的最大值约为 21 亿（2,147,483,647）。`long long` 类型占 8 个字节，最大约为 9.22 × 10¹⁸。当我们需要计算非常大的数时——比如 50 的阶乘（约 3.04 × 10⁶⁴）——long long 也远远不够用。

这时就需要**高精度运算**。高精度运算的思路是：用数组来存储大数的每一位，然后模拟我们小学时学到的手工竖式计算。

**关键设计决策：倒序存储**

在数组中，我们把数字倒过来存：索引 0 存个位，索引 1 存十位，索引 2 存百位，以此类推。这样做的好处是：
- 进位时只需要在数组末尾追加，不需要移动已有元素
- 计算时从索引 0 开始，对应最低位，非常自然
- 方便处理不同长度的数字

例如，数字 12345 在数组中的存储为：`a[0]=5, a[1]=4, a[2]=3, a[3]=2, a[4]=1`。

### 逐位乘法的原理

高精度乘法的核心思想是**模拟竖式乘法**。我们回顾一下小学学过的竖式乘法：

以 123 × 456 为例，竖式计算过程如下：

```
           1  2  3        ← 被乘数 A (3位)
     ×     4  5  6        ← 乘数 B (3位)
     --------------
           7  3  8        ← 123 × 6 = 738
        6  1  5           ← 123 × 5 = 615 (向左移一位)
     4  9  2              ← 123 × 4 = 492 (向左移两位)
     --------------
     5  6  0  8  8        ← 相加结果
```

仔细观察可以发现规律：**A 的第 i 位与 B 的第 j 位相乘，结果会贡献到答案的第 i+j 位**。

用数学语言描述：设结果数组为 `c[]`，则 `c[i+j] += a[i] * b[j]`。

具体步骤分解：

**第一步：逐位相乘并累加**

```
a = [3, 2, 1]    (倒序存储的 123)
b = [6, 5, 4]    (倒序存储的 456)

逐位相乘累加过程：

i=0, j=0: c[0] += a[0]*b[0] = 3×6 = 18
i=0, j=1: c[1] += a[0]*b[1] = 3×5 = 15
i=0, j=2: c[2] += a[0]*b[2] = 3×4 = 12
i=1, j=0: c[1] += a[1]*b[0] = 2×6 = 12  → c[1] 现为 15+12=27
i=1, j=1: c[2] += a[1]*b[1] = 2×5 = 10  → c[2] 现为 12+10=22
i=1, j=2: c[3] += a[1]*b[2] = 2×4 = 8   → c[3] 现为 8
i=2, j=0: c[2] += a[2]*b[0] = 1×6 = 6   → c[2] 现为 22+6=28
i=2, j=1: c[3] += a[2]*b[1] = 1×5 = 5   → c[3] 现为 8+5=13
i=2, j=2: c[4] += a[2]*b[2] = 1×4 = 4   → c[4] 现为 4
```

**第二步：统一处理进位**

逐位相乘后，c 数组中的每个位置可能有超过 9 的值，需要统一处理进位：

```
c[0] = 18  → 保留 8，进位 1 到 c[1]
c[1] = 27 + 1 = 28 → 保留 8，进位 2 到 c[2]
c[2] = 28 + 2 = 30 → 保留 0，进位 3 到 c[3]
c[3] = 13 + 3 = 16 → 保留 6，进位 1 到 c[4]
c[4] = 4 + 1 = 5  → 保留 5
```

最终结果：`c = [8, 8, 0, 6, 5]`，倒过来读就是 56088，即 123 × 456 = 56088。正确！

**算法总结**：

1. 将两个大数以字符串形式读入，倒序存入数组 a[] 和 b[]
2. 双层循环：`c[i+j] += a[i] * b[j]`
3. 统一处理进位：`c[i+1] += c[i] / 10; c[i] %= 10`
4. 去除前导零，输出结果

## 💻 代码实现

### 高精度乘以高精度

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

// 高精度乘法：计算 a * b，返回结果的字符串表示
string high_precision_multiply(const string &num1, const string &num2) {
    // 特殊情况：任何一个数为 0，结果就是 0
    if (num1 == "0" || num2 == "0") return "0";

    int len1 = num1.size(), len2 = num2.size();

    // 倒序存储：索引 0 存个位
    vector<int> a(len1), b(len2);
    for (int i = 0; i < len1; i++) a[i] = num1[len1 - 1 - i] - '0';
    for (int i = 0; i < len2; i++) b[i] = num2[len2 - 1 - i] - '0';

    // 结果数组，最大位数为 len1 + len2
    vector<int> c(len1 + len2, 0);

    // 第一步：逐位相乘并累加
    for (int i = 0; i < len1; i++) {
        for (int j = 0; j < len2; j++) {
            c[i + j] += a[i] * b[j];
        }
    }

    // 第二步：统一处理进位
    for (int i = 0; i < len1 + len2; i++) {
        if (c[i] >= 10) {
            c[i + 1] += c[i] / 10;
            c[i] %= 10;
        }
    }

    // 去除前导零（结果数组末尾的 0）
    int pos = len1 + len2 - 1;
    while (pos > 0 && c[pos] == 0) pos--;

    // 拼接结果字符串（从高位到低位）
    string result;
    for (int i = pos; i >= 0; i--) {
        result += char(c[i] + '0');
    }
    return result;
}
```

// 高精度加法：计算 a + b，返回结果的字符串表示
string high_precision_add(const string &num1, const string &num2) {
    int len1 = num1.size(), len2 = num2.size();
    int maxLen = max(len1, len2);

    // 倒序存储
    vector<int> a(maxLen, 0), b(maxLen, 0);
    for (int i = 0; i < len1; i++) a[i] = num1[len1 - 1 - i] - '0';
    for (int i = 0; i < len2; i++) b[i] = num2[len2 - 1 - i] - '0';

    vector<int> c(maxLen + 1, 0);

    // 逐位相加
    for (int i = 0; i < maxLen; i++) {
        c[i] += a[i] + b[i];
        if (c[i] >= 10) {
            c[i + 1] += c[i] / 10;
            c[i] %= 10;
        }
    }

    // 去除前导零
    int pos = maxLen;
    while (pos > 0 && c[pos] == 0) pos--;

    string result;
    for (int i = pos; i >= 0; i--) {
        result += char(c[i] + '0');
    }
    return result;
}
```

## 📊 复杂度分析

### 时间复杂度：O(n × m)

高精度乘法的时间复杂度主要取决于双层循环。设两个数的位数分别为 n 和 m：

- **逐位相乘**：双层循环需要执行 n × m 次乘法和加法操作，时间复杂度为 **O(n × m)**
- **统一进位**：结果最多有 n+m 位，进位处理需要 O(n+m) 次操作
- **总时间复杂度**：**O(n × m)**，当 n ≈ m 时约为 **O(n²)**

### 空间复杂度：O(n + m)

- 存储两个输入数需要 O(n + m) 空间
- 存储结果数组需要 O(n + m) 空间
- **总空间复杂度**：**O(n + m)**

### 优化思考

虽然 O(n²) 对于 200 位的数字（40,000 次操作）完全够用，但若需要处理上万位的数字，就可以学习**快速傅里叶变换（FFT）**将复杂度降到 O(n log n)。这属于进阶内容，暂时不必深究。

### 例题 1：阶乘之和

**题目描述**：
计算 S = 1! + 2! + 3! + ... + n! 的值，其中 n ≤ 50。由于结果可能非常大，需要使用高精度计算。

**输入格式**：
一行一个整数 n（1 ≤ n ≤ 50）。

**输出格式**：
一个整数，表示阶乘之和的值。

**样例输入**：
```
5
```

**样例输出**：
```
153
```

**样例解释**：
1! = 1, 2! = 2, 3! = 6, 4! = 24, 5! = 120
S = 1 + 2 + 6 + 24 + 120 = 153

**解题思路**：
1. 使用高精度乘法模拟求阶乘
2. 使用高精度加法累加每个阶乘值
3. n 最大为 50，50! 约有 65 位，用 vector<int> 存储绰绰有余
4. 递推计算阶乘：fact(i) = fact(i-1) × i，将 i 转为字符串参与高精度乘法

**完整代码**：

    for (int i = 0; i < len1 + len2; i++) {

        }
    }

    for (int i = pos; i >= 0; i--) result += char(c[i] + '0');

}

string high_precision_add(const string &num1, const string &num2) {
    int len1 = num1.size(), len2 = num2.size();
    int maxLen = max(len1, len2);
    vector<int> a(maxLen, 0), b(maxLen, 0);
    for (int i = 0; i < len1; i++) a[i] = num1[len1 - 1 - i] - '0';
    for (int i = 0; i < len2; i++) b[i] = num2[len2 - 1 - i] - '0';
    vector<int> c(maxLen + 1, 0);
    for (int i = 0; i < maxLen; i++) {
        c[i] += a[i] + b[i];
        if (c[i] >= 10) { c[i + 1] += 1; c[i] -= 10; }

    while (pos > 0 && c[pos] == 0) pos--;

    for (int i = pos; i >= 0; i--) result += char(c[i] + '0');

string int_to_string(int n) {

int main() {

    cin >> n;

#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

// 高精度乘高精度
string multiply(const string &num1, const string &num2) {
    if (num1 == "0" || num2 == "0") return "0";
    int len1 = num1.size(), len2 = num2.size();
    vector<int> a(len1), b(len2);
    for (int i = 0; i < len1; i++) a[i] = num1[len1 - 1 - i] - '0';
    for (int i = 0; i < len2; i++) b[i] = num2[len2 - 1 - i] - '0';
    vector<int> c(len1 + len2, 0);
    for (int i = 0; i < len1; i++)
        for (int j = 0; j < len2; j++)
            c[i + j] += a[i] * b[j];
    for (int i = 0; i < len1 + len2 - 1; i++) {
        c[i + 1] += c[i] / 10;
        c[i] %= 10;
    }
    int pos = len1 + len2 - 1;
    while (pos > 0 && c[pos] == 0) pos--;
    string result;
    for (int i = pos; i >= 0; i--) result += char(c[i] + '0');
    return result;
}

// 高精度加法
string add(const string &num1, const string &num2) {
    int len1 = num1.size(), len2 = num2.size();
    int maxLen = max(len1, len2);
    vector<int> a(maxLen, 0), b(maxLen, 0);
    for (int i = 0; i < len1; i++) a[i] = num1[len1 - 1 - i] - '0';
    for (int i = 0; i < len2; i++) b[i] = num2[len2 - 1 - i] - '0';
    vector<int> c(maxLen + 1, 0);
    for (int i = 0; i < maxLen; i++) {
        c[i] += a[i] + b[i];
        if (c[i] >= 10) { c[i + 1] += 1; c[i] -= 10; }
    }
    int pos = maxLen;
    while (pos > 0 && c[pos] == 0) pos--;
    string result;
    for (int i = pos; i >= 0; i--) result += char(c[i] + '0');
    return result;
}

// 高精度乘低精度
string multiplyInt(const string &num, int x) {
    if (x == 0) return "0";
    vector<int> a;
    for (int i = num.size() - 1; i >= 0; i--) a.push_back(num[i] - '0');
    int carry = 0;
    for (size_t i = 0; i < a.size(); i++) {
        int prod = a[i] * x + carry;
        a[i] = prod % 10;
        carry = prod / 10;
    }
    while (carry > 0) { a.push_back(carry % 10); carry /= 10; }
    string result;
    for (int i = a.size() - 1; i >= 0; i--) result += char(a[i] + '0');
    return result;
}

// int转string
string toStr(int n) {
    if (n == 0) return "0";
    string s;
    while (n) { s = char(n % 10 + '0') + s; n /= 10; }
    return s;
}

// 练习3：阶乘之和
string factorialSum(int n) {
    string fact = "1", sum = "0";
    for (int i = 1; i <= n; i++) {
        fact = multiplyInt(fact, i);
        sum = add(sum, fact);
    }
    return sum;
}

// 练习5：数字根
int digitalRoot(const string &s) {
    int sum = 0;
    for (char c : s) sum += c - '0';
    while (sum >= 10) {
        int temp = 0;
        while (sum) { temp += sum % 10; sum /= 10; }
        sum = temp;
    }
    return sum;
}

int main() {
    cout << "练习1: 123456789 * 9 = " << multiplyInt("123456789", 9) << endl;
    cout << "练习2: 9999999999 * 9999999999 = " << multiply("9999999999", "9999999999") << endl;
    cout << "练习3: 1!+2!+...+5! = " << factorialSum(5) << endl;  // 153
    cout << "练习5: 数字根(123*456) = " << digitalRoot(multiply("123", "456")) << endl;  // 9
    return 0;
}
```

## 📝 本课小结

本课我们学习了高精度乘法的核心思想和实现方法。

**核心要点回顾**：

1. **为什么需要高精度**：C++ 内置整数类型有范围限制（int 约 21 亿，long long 约 9×10¹⁸），无法存储和处理超大整数。

2. **核心原理**：模拟竖式乘法。将大数倒序存入数组（个位在索引 0），利用 `c[i+j] += a[i] * b[j]` 进行逐位相乘累加，最后统一处理进位。

3. **倒序存储的优势**：进位时自然追加到数组末尾，无需移动元素；计算顺序与手工竖式一致，便于理解和实现。

4. **时间复杂度 O(n×m)**：对于 200 位以内的数字完全够用。若需处理超大规模数据，可进一步学习 FFT 优化。

5. **实际应用**：阶乘计算、大数乘法、密码学中的大整数运算等都依赖高精度运算。

**学习建议**：多动手实现几遍高精度乘法，尤其注意进位的处理细节和数组索引的对应关系。可以尝试自己实现高精度减法，为下一课的高精度除法做好准备。高精度运算是算法竞赛中的基础技能，熟练掌握后会让你在解决大数问题时游刃有余。
