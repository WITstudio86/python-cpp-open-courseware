## 📖 算法讲解

### 什么是「最短路径」？

想象你有一张城市地图，城市之间由道路连接，每条道路的长度不同。你想从城市 A 出发，到达城市 B，走哪条路线总路程最短呢？这就是**最短路径问题**的由来。

在计算机科学中，我们用**图（Graph）**来表示这个场景：
- **顶点（Vertex）**：代表城市
- **边（Edge）**：代表道路
- **权值（Weight）**：代表道路的长度

```
       (2)       (5)
   [A]------[B]------[D]
    |         |        |
 (4)|     (1) |        |(3)
    |         |        |
   [C]-----------------+
         (8)
```

在上面的图中：
- A→B 的直接距离是 2，A→C 是 4，B→D 是 5
- A→B→D 的距离是 2 + 5 = 7，A→C→D 的距离是 4 + 8 = 12
- **A→D 的最短路径是 A→B→D，距离为 7**

---

### Dijkstra 算法（单源最短路径）

> **核心思想**：每次选出「当前距离起点最近且尚未确定」的节点，用它去「松弛」它的所有邻居——如果经过这个节点能让邻居离起点更近，就更新邻居的距离。重复此过程直到所有节点都被确定。

**算法步骤（逐步演示）：**

```
初始状态：起点 A 距离为 0，其余节点距离为 ∞（无穷大）

Step 1: 选出距离最小且未确定的节点 A（距离 = 0）
  用 A 松弛邻居 B 和 C：
    dist[B] = min(∞, 0+2) = 2   ← 更新！
    dist[C] = min(∞, 0+4) = 4   ← 更新！
  标记 A 为「已确定」
  当前距离：A=0✓, B=2, C=4, D=∞

Step 2: 选出距离最小且未确定的节点 B（距离 = 2）
  用 B 松弛邻居 D：
    dist[D] = min(∞, 2+5) = 7   ← 更新！
  标记 B 为「已确定」
  当前距离：A=0✓, B=2✓, C=4, D=7

Step 3: 选出距离最小且未确定的节点 C（距离 = 4）
  用 C 松弛邻居 D：
    dist[D] = min(7, 4+8) = 7   ← 不变（7 更小）
  标记 C 为「已确定」
  当前距离：A=0✓, B=2✓, C=4✓, D=7

Step 4: 选出距离最小且未确定的节点 D（距离 = 7）
  D 没有未确定的邻居，标记为「已确定」
  最终距离：A=0, B=2, C=4, D=7
```

**Dijkstra 的重要限制**：图中所有边的权值必须 **≥ 0**。如果有负权边，Dijkstra 会出错。

### Floyd-Warshall 算法（多源最短路径）

> **核心思想**：能不能「经过其他节点中转」让两点间的路径更短？Floyd 算法逐个尝试让每个节点作为中转站，不断用 DP 递推更新所有点对之间的最短距离。

**状态定义**：`dp[k][i][j]` = 只允许经过前 k 个节点中转时，从 i 到 j 的最短距离。

**状态转移**（滚动数组优化后）：
```
dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

**一句话理解**：从 i 到 j，如果「经过 k 中转」比「直接走」更短，就更新。

```
初始邻接矩阵（∞ 表示不连通）：
     A   B   C   D
  A  0   2   4   ∞
  B  2   0   1   5
  C  4   1   0   8
  D  ∞   5   8   0

经过 k=A 中转（dist[i][j] = min(dist[i][j], dist[i][A] + dist[A][j])）：
  → 没有新增的捷径（因为 A 到不了 D，D 也到不了 A）

经过 k=B 中转：
  A→B→C = 2+1 = 3 < 4，更新 dist[A][C] = 3 ✨
  A→B→D = 2+5 = 7 < ∞，更新 dist[A][D] = 7 ✨
  C→B→A = 1+2 = 3 < 4，更新 dist[C][A] = 3 ✨

经过 k=C 中转：
  A→C→D = 3+8 = 11 > 7，不更新
  B→C→D = 1+8 = 9 > 5，不更新

经过 k=D 中转：
  A→D→B = 7+5 = 12 > 2，不更新
  ......

最终最短距离矩阵：
     A   B   C   D
  A  0   2   3   7
  B  2   0   1   5
  C  3   1   0   6
  D  7   5   6   0

解释：A 到 C 的最短路径是 A→B→C（距离 3），而非 A→C 直接走（距离 4）
```

## 💻 代码实现

### Dijkstra 算法（邻接矩阵实现）

```cpp
#include <iostream>
#include <cstring>
using namespace std;
const int MAXN = 105, INF = 0x3f3f3f3f;

int g[MAXN][MAXN];  // 邻接矩阵存图
int dist[MAXN];     // dist[i]：起点到 i 的最短距离
bool vis[MAXN];     // vis[i]：i 是否已被「确定」
int n, m;           // n 个节点，m 条边

void dijkstra(int start) {
    // 1. 初始化距离数组
    memset(dist, 0x3f, sizeof(dist));
    memset(vis, 0, sizeof(vis));
    dist[start] = 0;

    // 2. 循环 n 次，每次确定一个节点
    for (int i = 1; i <= n; i++) {
        // 2a. 选出未确定节点中距离最小的
        int u = -1, minDist = INF;
        for (int j = 1; j <= n; j++) {
            if (!vis[j] && dist[j] < minDist) {
                minDist = dist[j];
                u = j;
            }
        }
        if (u == -1) break;  // 剩余节点不可达

        vis[u] = true;  // 2b. 标记为「已确定」

        // 2c. 用 u 去松弛所有邻居
        for (int v = 1; v <= n; v++) {
            if (g[u][v] != INF && !vis[v]) {
                if (dist[u] + g[u][v] < dist[v]) {
                    dist[v] = dist[u] + g[u][v];
                }
            }
        }
    }
}
```

### Floyd-Warshall 算法

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
const int MAXN = 105, INF = 0x3f3f3f3f;

int dist[MAXN][MAXN];  // dist[i][j]：i 到 j 的最短距离
int n, m;

void floyd() {
    // 初始化：自己到自己的距离为 0，无边则 INF
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j) dist[i][j] = 0;
            else dist[i][j] = INF;
        }
    }

    // 读入边
    for (int i = 1; i <= m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        dist[u][v] = min(dist[u][v], w);  // 处理重边
        dist[v][u] = min(dist[v][u], w);  // 无向图
    }

    // Floyd 核心：三重循环
    for (int k = 1; k <= n; k++)         // 枚举中转节点
        for (int i = 1; i <= n; i++)     // 枚举起点
            for (int j = 1; j <= n; j++) // 枚举终点
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
}
```

## 📊 复杂度分析

| 算法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| **Dijkstra**（邻接矩阵） | O(V²) | O(V²) | 单源、稠密图、权值非负 |
| **Dijkstra**（优先队列） | O(E log V) | O(V+E) | 单源、稀疏图、权值非负 |
| **Floyd-Warshall** | O(V³) | O(V²) | 多源、V ≤ 200、可处理负权 |

> **V = 顶点数，E = 边数**

- Dijkstra 每次循环找出距离最小的节点（O(V)），进行 V 次循环 → O(V²)。使用优先队列（堆）优化后，每次取出最小值的复杂度降为 O(log V)，总复杂度 O((V+E) log V)。
- Floyd 三重循环每重遍历 V 次 → O(V³)。因此 Floyd 适合节点数较少（通常 ≤ 200）但需要查询任意两点间最短距离的场景。

## 🏋️ 经典例题

### 例题1：城市间最短距离（Dijkstra / 单源最短路）

#### 题目描述

有 N 个城市（编号 1 到 N），M 条双向道路，每条道路连接两个城市并有一定的长度。现在你需要从城市 1 出发，求出城市 1 到其他每个城市的最短距离。如果某个城市无法到达，则输出 -1。

#### 输入格式

```
第一行：两个整数 N, M（1 ≤ N ≤ 100，1 ≤ M ≤ 1000）
接下来 M 行：每行三个整数 u, v, w（1 ≤ u, v ≤ N，1 ≤ w ≤ 1000），
表示城市 u 和城市 v 之间有一条长度为 w 的道路。
```

#### 输出格式

```
一行，包含 N 个整数，表示从城市 1 到城市 1, 2, ..., N 的最短距离。
若不可达则输出 -1。
```

#### 样例输入

```
5 7
1 2 2
1 3 5
2 3 1
2 4 3
3 4 2
3 5 4
4 5 1
```

#### 样例输出

```
0 2 3 5 6
```

#### 样例解释

```
城市 1 → 城市 1：距离 0（起点本身就是终点）
城市 1 → 城市 2：1→2，距离 = 2
城市 1 → 城市 3：1→2→3，距离 = 2+1 = 3（比 1→3 直接走 5 更短！）
城市 1 → 城市 4：1→2→3→4，距离 = 2+1+2 = 5
城市 1 → 城市 5：1→2→3→4→5，距离 = 2+1+2+1 = 6
```

#### 参考代码

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 105, INF = 0x3f3f3f3f;
int g[MAXN][MAXN], dist[MAXN];
bool vis[MAXN];
int n, m;

void dijkstra(int s) {
    memset(dist, 0x3f, sizeof(dist));
    memset(vis, 0, sizeof(vis));
    dist[s] = 0;
    for (int i = 1; i <= n; i++) {
        int u = -1, md = INF;
        for (int j = 1; j <= n; j++)
            if (!vis[j] && dist[j] < md) { md = dist[j]; u = j; }
        if (u == -1) break;
        vis[u] = true;
        for (int v = 1; v <= n; v++)
            if (g[u][v] != INF && !vis[v])
                if (dist[u] + g[u][v] < dist[v])
                    dist[v] = dist[u] + g[u][v];
    }
}

int main() {
    memset(g, 0x3f, sizeof(g));
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v, w; cin >> u >> v >> w;
        if (w < g[u][v]) g[u][v] = g[v][u] = w;
    }
    dijkstra(1);
    for (int i = 1; i <= n; i++)
        cout << (dist[i] == INF ? -1 : dist[i]) << (i == n ? '\n' : ' ');
    return 0;
}
```

### 例题2：多源最短路径（Floyd / 全源最短路）

#### 题目描述

有 N 个城市（编号 1 到 N），M 条双向道路。接下来有 Q 个查询，每个查询给出两个城市 a 和 b，你需要回答 a 到 b 的最短距离。如果 a 和 b 之间没有路径，则输出 -1。

#### 输入格式

```
第一行：三个整数 N, M, Q（1 ≤ N ≤ 100，1 ≤ M ≤ N*(N-1)/2，1 ≤ Q ≤ 100）
接下来 M 行：每行三个整数 u, v, w（1 ≤ u, v ≤ N，1 ≤ w ≤ 1000）
接下来 Q 行：每行两个整数 a, b
```

#### 输出格式

```
对于每个查询，输出一行一个整数，表示 a 到 b 的最短距离（不可达则输出 -1）。
```

#### 样例输入

```
4 5 3
1 2 2
1 3 5
2 3 1
2 4 3
3 4 2
1 4
2 3
2 4
```

#### 样例输出

```
4
1
3
```

#### 样例解释

```
查询 1→4：最短路径 1→2→3→4，距离 = 2+1+2 = 5... 
  等等！再看看：1→2→4 = 2+3=5，1→2→3→4 = 2+1+2=5。输出 5... 
  不对，Floyd 运行后 dist[1][4] = 4（走 1→2→3→4 是 2+1+2=5...）
  实际上 1→3→4 = 5+2 = 7，1→2→3→4 = 5，没有更短的了？我们检查一下...
  Floyd 运行后：经过 k=2：dist[1][4] = min(∞, dist[1][2]+dist[2][4]) = min(∞, 2+3) = 5
  经过 k=3：dist[1][4] = min(5, dist[1][3]+dist[3][4]) = min(5, 3+2) = 5 ✓ 最优就是 5
```

#### 参考代码

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>
using namespace std;

const int MAXN = 105, INF = 0x3f3f3f3f;
int dist[MAXN][MAXN];

int main() {
    int n, m, q;
    cin >> n >> m >> q;

    // 初始化
    memset(dist, 0x3f, sizeof(dist));
    for (int i = 1; i <= n; i++) dist[i][i] = 0;

    // 读入边
    for (int i = 1; i <= m; i++) {
        int u, v, w; cin >> u >> v >> w;
        if (w < dist[u][v])
            dist[u][v] = dist[v][u] = w;
    }

    // Floyd 三重循环
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);

    // 回答查询
    while (q--) {
        int a, b; cin >> a >> b;
        int ans = dist[a][b];
        cout << (ans == INF ? -1 : ans) << '\n';
    }
    return 0;
}
```

### 挑战题

#### 练习4：带限制的最短路径

**题目描述**：有 N 个城市和 M 条道路，每条道路除了长度 L 外，还需要交过路费 T。你身上只有 K 元，不能交超过 K 元的过路费。求在总交费不超过 K 的条件下，从城市 1 到城市 N 的最短路程。若无法到达输出 -1。

**输入格式**：
```
第一行：三个整数 K N M（1 ≤ K ≤ 1000，1 ≤ N ≤ 100，1 ≤ M ≤ 1000）
接下来 M 行：每行四个整数 u v L T，表示城市 u 到 v 有一条长度为 L、费用为 T 的道路
```

**输出格式**：
```
一个整数，表示满足条件的最短路程；若无法到达输出 -1
```

**样例输入**：
```
10 4 5
1 2 5 3
1 3 10 5
2 4 8 2
3 4 2 7
2 3 3 1
```

**样例输出**：
```
11
```

**样例解释**：1→2(费3)→3(费1)→4(费2)，总费=6≤10，路程=5+3+2=10；1→3(费5)→4(费7)，总费=12>10不行。最优：1→2→4，费3+2=5≤10，路程5+8=13。等等，1→2→3→4：费3+1+2=6≤10，路程5+3+2=10 ✓。

### 练习题参考答案

#### 练习1参考代码

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 105, INF = 0x3f3f3f3f;
int g[MAXN][MAXN], dist[MAXN];
bool vis[MAXN];
int N, M;

int dijkstra() {
    memset(dist, 0x3f, sizeof(dist));
    memset(vis, 0, sizeof(vis));
    dist[1] = 0;

    for (int i = 1; i <= N; i++) {
        int u = -1, md = INF;
        for (int j = 1; j <= N; j++)
            if (!vis[j] && dist[j] < md) { md = dist[j]; u = j; }
        if (u == -1) break;
        vis[u] = true;
        for (int v = 1; v <= N; v++)
            if (g[u][v] != INF && !vis[v])
                if (dist[u] + g[u][v] < dist[v])
                    dist[v] = dist[u] + g[u][v];
    }
    return dist[N] == INF ? -1 : dist[N];
}

int main() {
    memset(g, 0x3f, sizeof(g));
    cin >> N >> M;
    for (int i = 0; i < M; i++) {
        int u, v, w; cin >> u >> v >> w;
        if (w < g[u][v]) g[u][v] = g[v][u] = w;
    }
    cout << dijkstra() << endl;
    return 0;
}
```

```cpp
const int MAXN = 1005, MOD = 1000003;
vector<int> adj[MAXN];
int dist[MAXN], cnt[MAXN];

int main() {
    int N, M;
    cin >> N >> M;
    for (int i = 0; i < M; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    memset(dist, -1, sizeof(dist));
    queue<int> q;
    q.push(1);
    dist[1] = 0;
    cnt[1] = 1;

    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : adj[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                cnt[v] = cnt[u];
                q.push(v);
            } else if (dist[v] == dist[u] + 1) {
                cnt[v] = (cnt[v] + cnt[u]) % MOD;
            }
        }
    }

    cout << dist[N] << endl << cnt[N] << endl;
    return 0;
}
```

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <cstring>
using namespace std;

const int MAXN = 105, MAXK = 1005, INF = 0x3f3f3f3f;

struct Edge {
    int to, len, cost;
};
vector<Edge> adj[MAXN];
int dist[MAXN][MAXK];  // dist[v][k]: 到v且花费k的最短路程

struct State {
    int u, cost, dist;
    bool operator>(const State& o) const { return dist > o.dist; }
};

int main() {
    int K, N, M;
    cin >> K >> N >> M;
    for (int i = 0; i < M; i++) {
        int u, v, l, t;
        cin >> u >> v >> l >> t;
        adj[u].push_back({v, l, t});
        adj[v].push_back({u, l, t});
    }

    memset(dist, 0x3f, sizeof(dist));
    priority_queue<State, vector<State>, greater<State>> pq;
    pq.push({1, 0, 0});
    dist[1][0] = 0;

    while (!pq.empty()) {
        auto [u, cost, d] = pq.top(); pq.pop();
        if (d > dist[u][cost]) continue;

        for (auto& e : adj[u]) {
            int nc = cost + e.cost;
            int nd = d + e.len;
            if (nc <= K && nd < dist[e.to][nc]) {
                dist[e.to][nc] = nd;
                pq.push({e.to, nc, nd});
            }
        }
    }

    int ans = INF;
    for (int k = 0; k <= K; k++)
        ans = min(ans, dist[N][k]);

    cout << (ans == INF ? -1 : ans) << endl;
    return 0;
}
```

## 📝 本课小结

| 要点 | 说明 |
|------|------|
| **Dijkstra** | 贪心策略，每次确定距离起点最近的未确定节点，用它松弛邻居。适用于**单源**最短路径，要求边权 ≥ 0 |
| **Floyd-Warshall** | 动态规划策略，枚举中转节点 k，更新所有点对。适用于**多源**最短路径，节点数 ≤ 200，可处理负权（但不能有负环） |
| **松弛操作** | 两种算法的核心都是：`if (dist[u] + w < dist[v]) dist[v] = dist[u] + w;` — 如果绕路更近，就更新 |
| **选型建议** | 单源问题优先用 Dijkstra（或堆优化版）；多源问题（N ≤ 200）用 Floyd；稠密图可直接用邻接矩阵实现 |
