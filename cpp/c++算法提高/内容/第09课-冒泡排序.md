# 第9课：冒泡排序——相邻交换

## 🎯 学习目标
- 理解冒泡排序的基本原理：通过相邻元素两两比较和交换，将较大的元素逐步"浮"到数组末尾
- 掌握冒泡排序的优化方法：引入标志变量提前终止循环，减少不必要的比较
- 能够分析冒泡排序的时间复杂度，并解决相关排序问题

## 📖 算法讲解

### 一、什么是冒泡排序？

想象一下，你在一个平静的池塘边，往水里扔了一块石头。石头沉入水底，而水底的气泡会一个接一个地"咕噜咕噜"向上浮起。最大的气泡总是浮得最快、最先到达水面。

冒泡排序正是借用了这个生动的比喻。在数组中，我们把较大的元素看作"大气泡"，较小的元素看作"小气泡"。排序的过程，就是让"大气泡"不断上浮（向右移动），最终让整个数组从小到大排列整齐。

### 二、相邻比较与交换——冒泡排序的核心操作

冒泡排序的核心操作只有一步：**比较相邻的两个元素，如果前面的比后面的大，就交换它们的位置**。

这是什么意思呢？假设我们有一个数组：`arr = [5, 3, 8, 1, 2]`

我们从最左边开始，比较第一对相邻元素 `arr[0]` 和 `arr[1]`：

```
比较：5 和 3 → 5 > 3，需要交换！

交换前：[5, 3, 8, 1, 2]
           ↑  ↑
交换后：[3, 5, 8, 1, 2]
```

接着，我们继续比较下一对相邻元素 `arr[1]` 和 `arr[2]`：

```
比较：5 和 8 → 5 < 8，不需要交换！

保持不变：[3, 5, 8, 1, 2]
              ↑  ↑
```

然后是 `arr[2]` 和 `arr[3]`：

```
比较：8 和 1 → 8 > 1，需要交换！

交换前：[3, 5, 8, 1, 2]
                 ↑  ↑
交换后：[3, 5, 1, 8, 2]
```

最后是 `arr[3]` 和 `arr[4]`：

```
比较：8 和 2 → 8 > 2，需要交换！

交换前：[3, 5, 1, 8, 2]
                    ↑  ↑
交换后：[3, 5, 1, 2, 8]
```

观察一下！经过这一轮完整的扫描（从 `arr[0]` 到 `arr[4]`），最大的元素 `8` 已经像气泡一样"浮"到了数组的最右端。这就是"冒泡"一词的由来。

### 三、完整排序过程演示

一轮冒泡只能将一个最大值归位。那么剩下的元素怎么办？很简单——对前面未排好的部分，再做一轮冒泡就行！

让我们用 `arr = [5, 3, 8, 1, 2]` 完整演示整个过程：

```
初始状态：  [5, 3, 8, 1, 2]

────────────────────────────────────
第 1 轮（扫描 arr[0] ~ arr[4]）：
  比较 5和3 → 交换 → [3, 5, 8, 1, 2]
  比较 5和8 → 不换 → [3, 5, 8, 1, 2]
  比较 8和1 → 交换 → [3, 5, 1, 8, 2]
  比较 8和2 → 交换 → [3, 5, 1, 2, 8]
  第1轮结束，8 已归位 ✓

────────────────────────────────────
第 2 轮（扫描 arr[0] ~ arr[3]）：
  比较 3和5 → 不换 → [3, 5, 1, 2, 8]
  比较 5和1 → 交换 → [3, 1, 5, 2, 8]
  比较 5和2 → 交换 → [3, 1, 2, 5, 8]
  第2轮结束，5 已归位 ✓

────────────────────────────────────
第 3 轮（扫描 arr[0] ~ arr[2]）：
  比较 3和1 → 交换 → [1, 3, 2, 5, 8]
  比较 3和2 → 交换 → [1, 2, 3, 5, 8]
  第3轮结束，3 已归位 ✓

────────────────────────────────────
第 4 轮（扫描 arr[0] ~ arr[1]）：
  比较 1和2 → 不换 → [1, 2, 3, 5, 8]
  第4轮结束，2 已归位 ✓

最终结果：  [1, 2, 3, 5, 8] ← 排序完成！
```

通过这个过程我们可以发现一个规律：**n 个元素的数组，最多需要 (n-1) 轮冒泡**。每完成一轮，最大未归位元素就找到了自己的位置。而且，每轮需要比较的元素个数比上一轮少 1。

### 四、提前终止优化——当数组已经有序时

你有没有注意到，在上面例子的第 4 轮中，我们比较了 `1` 和 `2`，它们没有发生交换。实际上，如果某一轮扫描中**一次交换都没有发生**，说明数组已经全部有序了，后面那些轮就可以跳过了！

这就是冒泡排序的经典优化：**引入一个标志变量 `swapped`（或 `flag`）**。

```
每一轮开始时，设 swapped = false
如果本轮发生了交换，就将 swapped 设为 true
本轮结束时，如果 swapped 仍然为 false，说明数组已有序，提前结束！
```

举个例子。对于数组 `[1, 2, 3, 5, 8]`（已经是升序的），普通冒泡排序会傻傻地执行 4 轮比较。但优化版本只需要执行第 1 轮，发现没有任何交换，立刻就知道"已经排好了"，直接结束，节省了 3 轮无用功。

这个优化在数组"几乎有序"的时候（比如已经排序但错了一两个）效果特别好，时间复杂度可以从 O(n²) 直接降到 O(n)。

### 五、生活类比——理解冒泡排序

为了更好地理解冒泡排序，让我们看几个生活中的例子：

**类比 1：排队按身高调整**

体育课上，老师说："同学们，按身高从矮到高排成一列！"同学们一开始站得乱七八糟。你可以这样调整：从队伍最左边开始，每两个相邻的同学比一比身高，如果左边的人比右边的高，两人就交换位置。一直重复这个操作，直到没有人再交换为止。这不就是冒泡排序吗？

**类比 2：水杯里的气泡**

一杯水里有很多大小不同的气泡，大的气泡受浮力更大，上升更快。气泡自然就会按大小排序——大的在上面，小的在下面。冒泡排序就是模拟了这个过程。

**类比 3：考试成绩排名表**

老师拿到一叠考试卷子，想从低分到高分排列。他拿着最上面两张比较，如果上面那张分数比下面高就交换。反复这样做，最高分的卷子就会慢慢"沉"到最底下。

### 六、冒泡排序的特点总结

| 特点 | 说明 |
|------|------|
| **稳定性** | 冒泡排序是**稳定**的排序算法。当相邻两个元素相等时，我们不交换它们，所以相等元素的相对顺序保持不变。 |
| **原地排序** | 冒泡排序不需要额外的数组空间，直接在原数组上操作，空间复杂度为 O(1)。 |
| **适合小规模数据** | 当 n 较小时（比如 n ≤ 100），冒泡排序简单易懂，完全够用。 |
| **适合教学** | 冒泡排序是最直观的排序算法之一，非常适合用来入门算法学习。 |

## 💻 代码实现

### 基础版冒泡排序

```cpp
#include <iostream>
using namespace std;

// 基础版冒泡排序（升序）
void bubbleSort(int arr[], int n) {
    // 外层循环：控制排序的轮数，共 n-1 轮
    for (int i = 0; i < n - 1; i++) {
        // 内层循环：进行每一轮的相邻比较和交换
        // arr[n-1-i] ~ arr[n-1] 已经是排好的，不需要再比较
        for (int j = 0; j < n - 1 - i; j++) {
            // 如果前面的元素比后面的大，就交换
            if (arr[j] > arr[j + 1]) {
                // 经典的三步交换法
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
        // 本轮结束，最大的未归位元素已经"浮"到了 arr[n-1-i] 位置
    }
}
```

**代码解读：**

- `i` 是外层循环变量，从 0 到 n-2，共 n-1 轮。i 也代表"已经归位的大元素个数"。
- `j` 是内层循环变量，从 0 到 n-2-i。注意范围在收窄——因为每轮都有一个最大元素归位到末尾，下一轮就不用再比较它了。
- `if (arr[j] > arr[j + 1])`：核心判断，如果前面的大于后面的，就交换。如果是 `>=` 就变成不稳定排序了。
- 交换使用临时变量 `temp`，这是 C++ 中最基础的交换方式。也可以用 `swap(arr[j], arr[j + 1])`，效果相同。

### 优化版冒泡排序（带提前终止）

```cpp
// 优化版冒泡排序：引入标志变量 earlyStop
void bubbleSortOptimized(int arr[], int n) {
    // 外层循环：最多 n-1 轮
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;  // 本轮的交换标志，初始为 false，表示"没有交换"

        // 内层循环进行相邻比较
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;  // 发生了交换，将标志设为 true
            }
        }

        // ★ 核心优化：如果本轮一次交换都没发生，说明数组已经排好序了
        if (!swapped) {
            break;  // 提前结束外层循环，后面的轮数不需要了！
        }
    }
}
```

### 使用 swap 函数的简洁版

```cpp
#include <algorithm>  // 包含 swap 函数

void bubbleSortSimple(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);  // C++ 标准库的 swap
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}
```

## 📊 复杂度分析

### 时间复杂度

冒泡排序的时间复杂度需要分情况讨论：

**最坏情况（完全逆序）**：比如 `[5, 4, 3, 2, 1]`，每一对相邻元素都需要交换。外层循环执行 n-1 轮，内层循环分别比较 n-1、n-2、……、1 次。总比较次数 = (n-1) + (n-2) + ... + 1 = n(n-1)/2。这是一个等差数列求和，结果约为 n²/2。

所以最坏时间复杂度为：**O(n²)**。

**最好情况（已经有序）**：比如 `[1, 2, 3, 4, 5]`。优化版在第一轮扫描时，发现没有任何交换，swapped 保持 false，直接 break。只执行了 1 轮比较，共 n-1 次。

所以最好时间复杂度为：**O(n)**。

**平均情况**：经过数学分析，平均时间复杂度也是 **O(n²)**。因为随机数组大约需要 n²/4 次比较和交换。

### 空间复杂度

冒泡排序是**原地排序**（in-place sorting）。它只使用了一个临时变量 `temp` 和一个标志变量 `swapped`，这些都是常数级别的额外空间。

所以空间复杂度为：**O(1)**。

### 复杂度对比表

| 情况 | 时间复杂度 | 说明 |
|------|-----------|------|
| 最好情况 | O(n) | 数组已经有序，优化版只需一轮扫描 |
| 最坏情况 | O(n²) | 数组完全逆序，每对都要比较和交换 |
| 平均情况 | O(n²) | 随机数组的一般情况 |
| 空间复杂度 | O(1) | 原地排序，常数级额外空间 |

### 冒泡排序与其他排序算法的对比

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|------|------|------|------|------|------|
| 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | 不稳定 |

虽然冒泡排序的效率不高，但对于初学者来说，它是最容易理解、最容易实现的排序算法，是学习算法的第一块敲门砖。

#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int score;
};

int main() {
    int n;
    Student stu[1005];
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> stu[i].name >> stu[i].score;
    }
    
    // 冒泡排序：按成绩降序，成绩相同按姓名字典序升序
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            bool needSwap = false;
            if (stu[j].score < stu[j + 1].score)
                needSwap = true;
            else if (stu[j].score == stu[j + 1].score 
                     && stu[j].name > stu[j + 1].name)
                needSwap = true;
            
            if (needSwap) {
                Student temp = stu[j];
                stu[j] = stu[j + 1];
                stu[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
    
    for (int i = 0; i < n; i++) {
        cout << stu[i].name << " " << stu[i].score << endl;
    }
    return 0;
}

#### 挑战题 参考代码
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

void cocktailSort(int arr[], int n) {
    bool swapped = true;
    int start = 0, end = n - 1;
    
    while (swapped) {
        swapped = false;
        
        // 从左到右：把最大值冒泡到 end
        for (int i = start; i < end; i++) {
            if (arr[i] > arr[i + 1]) {
                swap(arr[i], arr[i + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;
        end--;
        
        swapped = false;
        // 从右到左：把最小值冒泡到 start
        for (int i = end; i > start; i--) {
            if (arr[i - 1] > arr[i]) {
                swap(arr[i - 1], arr[i]);
                swapped = true;
            }
        }
        start++;
    }
}

int main() {
    int n, arr[1005];
    cin >> n;
    for (int i = 0; i < n; i++) cin >> arr[i];
    
    cocktailSort(arr, n);
    
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << arr[i];
    }
    cout << endl;
    return 0;
}
```

## 📝 本课小结

本节课我们学习了冒泡排序——一种最基础、最直观的排序算法。冒泡排序的核心思想是：反复扫描数组，每次比较相邻的两个元素，如果顺序不对就交换它们。就像池塘里的气泡，较大的元素会一轮一轮地"浮"到数组末尾。

我们学习了冒泡排序的完整实现，包括基础版和优化版。优化版通过引入 `swapped` 标志变量，可以在数组已经有序时提前结束循环，将最好情况的时间复杂度从 O(n²) 降到 O(n)。

冒泡排序虽然效率不算高（最坏和平均都是 O(n²)），但它是理解排序算法思想的绝佳起点。它的稳定性、原地排序特性，以及简单易懂的实现，让它成为算法入门的经典教材。掌握冒泡排序，你就拿到了进入算法世界的第一把钥匙。下一课，我们将继续学习选择排序，看看另一种简单排序算法的巧妙之处。
