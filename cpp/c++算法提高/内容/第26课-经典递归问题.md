## 📖 算法讲解

### 一、什么是递归？

递归（Recursion）是算法设计中一种极为重要的思想。简单来说，递归就是**一个函数直接或间接地调用自身**，将原问题转化为规模更小的同类型子问题来求解。

我们可以用俄罗斯套娃来理解递归：打开一个套娃，里面还有一个更小的套娃；再打开，又有一个更小的……直到打开最小的那个套娃，里面什么都没有了，整个过程结束。这个"最小的套娃"就是递归的终点，称为**递归终止条件**（Base Case）。

递归的核心包含两个部分：

```
┌─────────────────────────────────────────────────────────────┐
│                    递归三要素                                │
├─────────────────────────────────────────────────────────────┤
│  1. 递归终止条件  →  问题小到什么程度可以直接求解？        │
│  2. 递归关系式    →  大问题的解如何用小问题的解表示？      │
│  3. 问题规模递减  →  每次递归调用，问题规模必须缩小        │
└─────────────────────────────────────────────────────────────┘
```

如果缺少终止条件，递归就会无限调用下去，最终导致栈溢出（Stack Overflow）。因此，**写递归函数的第一件事永远是明确终止条件**。

### 二、汉诺塔问题 —— 递归思想的经典之作

汉诺塔（Tower of Hanoi）是一个经典的递归问题，源自印度的一个古老传说。问题描述如下：

有三根柱子 A、B、C。A 柱上有 n 个大小不同的圆盘，按大小顺序从上到下排列（小的在上，大的在下）。目标是将所有圆盘从 A 柱移动到 C 柱，移动过程中必须遵守以下规则：
1. 每次只能移动最上面的一个圆盘
2. 任何时刻，大盘不能放在小盘上面

**递归思路分析：**

假设我们要将 n 个圆盘从 A 柱移动到 C 柱（B 柱作为辅助）。我们可以这样思考：

```
                          ┌─────────┐
     步骤1：              │ n-1个盘 │  从 A → B（借助 C）
                          └─────────┘

                          ┌─────────┐
     步骤2：              │ 第n个盘 │  从 A → C（直接移动）
                          └─────────┘

                          ┌─────────┐
     步骤3：              │ n-1个盘 │  从 B → C（借助 A）
                          └─────────┘
```

**汉诺塔移动过程图解（以 n=3 为例）：**

```
初始状态：
        A                   B                   C
        |                   |                   |
       [1]                  |                   |
      [ 2 ]                 |                   |
     [  3  ]                |                   |
    =========           =========           =========

第1步：移动盘1（最小盘）从 A → C
        A                   B                   C
        |                   |                   |
        |                   |                  [1]
      [ 2 ]                 |                   |
     [  3  ]                |                   |
    =========           =========           =========

第2步：移动盘2（中盘）从 A → B
        A                   B                   C
        |                   |                   |
        |                   |                  [1]
        |                  [2]                  |
     [  3  ]                |                   |
    =========           =========           =========

第3步：移动盘1 从 C → B
        A                   B                   C
        |                   |                   |
        |                  [1]                  |
        |                 [ 2 ]                 |
     [  3  ]                |                   |
    =========           =========           =========

第4步：移动盘3（最大盘）从 A → C
        A                   B                   C
        |                   |                   |
        |                  [1]                  |
        |                 [ 2 ]              [  3  ]
        |                   |                   |
    =========           =========           =========

第5步：移动盘1 从 B → A
        A                   B                   C
        |                   |                   |
       [1]                  |                   |
        |                 [ 2 ]              [  3  ]
        |                   |                   |
    =========           =========           =========

第6步：移动盘2 从 B → C
        A                   B                   C
        |                   |                   |
       [1]                  |                  [2]
        |                   |                [  3  ]
        |                   |                   |
    =========           =========           =========

第7步：移动盘1 从 A → C（完成！）
        A                   B                   C
        |                   |                   |
        |                   |                  [1]
        |                   |                 [ 2 ]
        |                   |                [  3  ]
    =========           =========           =========
```

可以看到，移动 3 个圆盘共需要 7 步（2³ - 1）。一般地，移动 n 个圆盘最少需要 **2ⁿ - 1** 步。如果 n=64，按照传说，即使每秒移动一次，也需要约 5800 亿年才能完成！这也是为什么递归虽然看起来简洁，但对于过大的 n 实际上是不可行的——它的时间复杂度是指数级的。

**汉诺塔递归的数学表达：**

- 递归终止条件：当 n = 1 时，直接将唯一的圆盘从源柱移动到目标柱
- 递归关系式：
  1. 将上面 n-1 个盘从 A 移动到 B（以 C 为中转）
  2. 将最大的第 n 个盘从 A 移动到 C
  3. 将 n-1 个盘从 B 移动到 C（以 A 为中转）

这就是"先把上面的 n-1 个移走，移动最底下的，再把 n-1 个移过来"的思路，本质上是**分而治之**的思想——把大问题拆成子问题，子问题的结构和原问题完全一样，只是规模更小。

### 三、欧几里得算法（辗转相除法）—— 求最大公约数

欧几里得算法（Euclidean Algorithm）是求两个正整数最大公约数（GCD, Greatest Common Divisor）的经典算法，距今已有 2000 多年的历史。它也是递归思想的一个绝佳范例。

**数学原理：**

设 a 和 b 是两个正整数，且 a ≥ b，则有：

```
gcd(a, b) = gcd(b, a mod b)
```

其中 `a mod b` 表示 a 除以 b 的余数。

**为什么这个等式成立？**

假设 d 是 a 和 b 的任意公约数，那么：
- a 可以表示为：a = b × q + r （其中 q 是商，r 是余数）
- 由于 a 和 b 都能被 d 整除，所以 r = a - b × q 也能被 d 整除
- 这意味着 a 和 b 的公约数集合与 b 和 r 的公约数集合是**完全相同的**
- 因此，它们的最大公约数也相同

**递归过程图解（以 gcd(48, 18) 为例）：**

```
     gcd(48, 18)
        │
        │  48 ÷ 18 = 2 ... 12  （商2，余12）
        │  所以 gcd(48, 18) = gcd(18, 12)
        │
        ▼
     gcd(18, 12)
        │
        │  18 ÷ 12 = 1 ... 6   （商1，余6）
        │  所以 gcd(18, 12) = gcd(12, 6)
        │
        ▼
     gcd(12, 6)
        │
        │  12 ÷ 6 = 2 ... 0    （商2，余0）
        │  余数为 0，递归终止！
        │  此时 gcd(12, 6) = 6
        │
        ▼
     答案：6

验证：
    48 的约数：1, 2, 3, 4, 6, 8, 12, 16, 24, 48
    18 的约数：1, 2, 3, 6, 9, 18
    最大公约数为 6  ✓
```

**辗转相除法"辗转"二字的由来：**

```
    被除数   除数   余数
    ─────   ───   ───
     48  ÷  18  =  12    ← 第一轮
          ┌─────────┘
          ▼
     18  ÷  12  =   6    ← 第二轮：上一轮的除数变成被除数，余数变成除数
          ┌─────────┘
          ▼
     12  ÷   6  =   0    ← 第三轮：余数为0，上一轮的除数 6 就是答案
```

可以看到，除数和余数在不断地"辗转"交换位置——上一轮的除数变成这一轮的被除数，上一轮的余数变成这一轮的除数，直到余数为零。这正是"辗转相除"的名称由来。

**递归终止条件：** 当 b = 0 时，gcd(a, 0) = a。

**递归关系式：** gcd(a, b) = gcd(b, a % b)

由于每次递归余数都严格小于除数（余数的范围是 0 到 b-1），而除数又在不断减小，因此算法必然会在有限步内终止。实际上，欧几里得算法非常高效——可以证明它的时间复杂度为 O(log min(a, b))。

## 💻 代码实现

### 汉诺塔问题的 C++ 实现

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 递归函数：将 n 个圆盘从柱子 src 移动到柱子 dst，柱子 aux 作为辅助
// 参数说明：
//   n   - 当前需要移动的圆盘数量
//   src - 源柱子（开始位置）
//   aux - 辅助柱子（中转位置）
//   dst - 目标柱子（目标位置）
void hanoi(int n, char src, char aux, char dst) {
    // 递归终止条件：只有一个圆盘时，直接移动
    if (n == 1) {
        cout << "将圆盘 " << n << " 从 " << src 
             << " 移动到 " << dst << endl;
        return;
    }
    
    // 步骤1：将上面 n-1 个盘从 src 移到 aux（以 dst 为中转）
    hanoi(n - 1, src, dst, aux);
    
    // 步骤2：将第 n 个盘（最大的）从 src 移到 dst
    cout << "将圆盘 " << n << " 从 " << src 
         << " 移动到 " << dst << endl;
    
    // 步骤3：将 n-1 个盘从 aux 移到 dst（以 src 为中转）
    hanoi(n - 1, aux, src, dst);
}

int main() {
    int n;
    cout << "请输入汉诺塔的圆盘数量：";
    cin >> n;
    
    cout << "\n移动步骤（共需 " << (int)pow(2, n) - 1 
         << " 步）：" << endl;
    cout << "========================================" << endl;
    
    // 将 n 个圆盘从柱子 A 移动到柱子 C，柱子 B 作为辅助
    hanoi(n, 'A', 'B', 'C');
    
    cout << "========================================" << endl;
    cout << "移动完成！" << endl;
    
    return 0;
}
```

### 递归实现示例：最大公约数（GCD）

```cpp
#include <iostream>
using namespace std;

// 递归实现欧几里得算法（辗转相除法）
// 参数要求：a 和 b 为正整数
// 返回值：a 和 b 的最大公约数
int gcd(int a, int b) {
    // 递归终止条件：当 b == 0 时，a 就是最大公约数
    if (b == 0) {
        return a;
    }
    
    // 递归关系式：gcd(a, b) = gcd(b, a % b)
    return gcd(b, a % b);
}

// 迭代实现（for/while 版本，方便对比理解）
int gcd_iterative(int a, int b) {
    while (b != 0) {
        int temp = a % b;  // 计算余数
        a = b;             // 上一轮的除数变成新的被除数
        b = temp;          // 上一轮的余数变成新的除数
    }
    return a;
}

int main() {
    int a, b;
    cout << "请输入两个正整数：";
    cin >> a >> b;
    
    cout << "递归方法：gcd(" << a << ", " << b 
         << ") = " << gcd(a, b) << endl;
    
    cout << "迭代方法：gcd(" << a << ", " << b 
         << ") = " << gcd_iterative(a, b) << endl;
    
    // 验证：使用公式 lcm(a, b) × gcd(a, b) = a × b
    int g = gcd(a, b);
    cout << "\n验算：" << endl;
    cout << "最小公倍数 lcm(" << a << ", " << b 
         << ") = " << a / g * b << endl;
    
    return 0;
}
```

## 📊 复杂度分析

**汉诺塔问题：**
- 时间复杂度：O(2ⁿ)。每次递归调用会分裂成两次子调用（移动 n-1 个盘的两步），递归树是一棵深度为 n 的满二叉树，总节点数（即总移动次数）为 2ⁿ - 1。这个复杂度是指数级的，因此当 n 较大时（比如 n > 30），计算量会急剧膨胀，程序运行时间会变得非常长。
- 空间复杂度：O(n)。递归的最大深度为 n（每次递归 n 减 1，直到 n=1），因此系统调用栈的深度为 O(n)。

**最大公约数（辗转相除法）：**
- 时间复杂度：O(log min(a, b))。每次递归/迭代，余数至少减小一半（实际上是斐波那契数列的相关性质保证了这一点），因此最多执行约 log₂(min(a, b)) 次运算。例如，即使 a 和 b 都在 10¹⁸ 的量级，也只需要约 60 次左右的迭代即可得出结果，效率极高。
- 空间复杂度：O(log min(a, b))（递归版本）或 O(1)（迭代版本）。递归版本每次调用压入一个栈帧，深度与递归次数相同；迭代版本只使用常数个变量。

## 🏋️ 经典例题

### 例题1：汉诺塔问题

**题目描述**：有三根柱子 A、B、C，A 柱上有 n 个大小不同的圆盘，大盘在下、小盘在上。请编写程序，使用递归算法输出将所有圆盘从 A 柱移动到 C 柱的详细移动步骤（B 柱作为辅助）。

**输入格式**：一行一个整数 n（1 ≤ n ≤ 15），表示圆盘的数量。

**输出格式**：第一行输出 `Steps:`，接下来每行输出一步移动，格式为 `#步号: 柱子X -> 柱子Y`，最后一行输出总步数，格式为 `Total: 步数 steps`。

**样例输入**：
```
3
```

**样例输出**：
```
Steps:
#1: A -> C
#2: A -> B
#3: C -> B
#4: A -> C
#5: B -> A
#6: B -> C
#7: A -> C
Total: 7 steps
```

**解题思路**：这是汉诺塔问题的标准形式。我们定义递归函数 `hanoi(n, src, aux, dst)` 表示将 n 个圆盘从 src 移动到 dst（以 aux 为中转）。当 n=1 时直接移动；否则分三步：先将 n-1 个移到中转柱，移动最大的盘，再将 n-1 个移到目标柱。为了便于输出步号和统计总步数，使用一个全局计数器记录当前是第几步。

**题解代码**：
```cpp
#include <iostream>
using namespace std;

int step = 0;  // 全局计数器，记录当前步数

// 递归函数：将 n 个圆盘从 src 移动到 dst，aux 作为辅助柱子
void hanoi(int n, char src, char aux, char dst) {
    if (n == 1) {
        step++;
        cout << "#" << step << ": " << src << " -> " << dst << endl;
        return;
    }
    hanoi(n - 1, src, dst, aux);    // 步骤1
    step++;
    cout << "#" << step << ": " << src << " -> " << dst << endl;  // 步骤2
    hanoi(n - 1, aux, src, dst);    // 步骤3
}

int main() {
    int n;
    cin >> n;
    
    cout << "Steps:" << endl;
    hanoi(n, 'A', 'B', 'C');
    cout << "Total: " << step << " steps" << endl;
    
    return 0;
}
```

### 例题2：最大公约数（GCD）

**题目描述**：输入两个正整数 a 和 b，请使用递归实现的欧几里得算法（辗转相除法）求出它们的最大公约数（Greatest Common Divisor），并同时输出最小公倍数（Least Common Multiple）。

> 提示：两个数的乘积等于它们的最大公约数与最小公倍数的乘积，即 a × b = gcd(a, b) × lcm(a, b)。

**输入格式**：一行两个正整数 a 和 b，用空格分隔（1 ≤ a, b ≤ 10⁹）。

**输出格式**：第一行输出最大公约数，格式为 `gcd(a, b) = 结果`。第二行输出最小公倍数，格式为 `lcm(a, b) = 结果`。

**样例输入**：
```
48 18
```

**样例输出**：
```
gcd(48, 18) = 6
lcm(48, 18) = 144
```

**样例输入 2**：
```
1071 462
```

**样例输出 2**：
```
gcd(1071, 462) = 21
lcm(1071, 462) = 23562
```

**解题思路**：使用欧几里得算法的递归形式 `gcd(a, b) = gcd(b, a % b)`，终止条件为 `b == 0` 时返回 a。由于输入可能 a < b，但经过第一次递归调用后，`a % b = a`（因为 a < b 时 a ÷ b = 0 余 a），所以参数会自动交换到 a ≥ b 的状态，无需手动处理大小关系。求出 gcd 后，用公式 `lcm = a / gcd × b`（先除后乘可以防止溢出）计算最小公倍数。

**题解代码**：
```cpp
#include <iostream>
using namespace std;

// 递归实现欧几里得算法，求最大公约数
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

int main() {
    int a, b;
    cin >> a >> b;
    
    // 保存原始输入值
    int original_a = a, original_b = b;
    
    int g = gcd(a, b);
    
    // 先除后乘，防止 a * b 溢出 int 范围
    long long l = (long long)original_a / g * original_b;
    
    cout << "gcd(" << original_a << ", " << original_b 
         << ") = " << g << endl;
    cout << "lcm(" << original_a << ", " << original_b 
         << ") = " << l << endl;
    
    return 0;
}
```

**题目描述**：现在有**四根**柱子 A、B、C、D（比经典汉诺塔多一根辅助柱），规则与经典汉诺塔相同。输入圆盘数量 n（1 ≤ n ≤ 10），输出最少移动步骤。四柱汉诺塔的最少步数可以通过 Frame-Stewart 算法或递归枚举来计算。对于 n ≤ 10，可以简单地使用公式计算最少步数。

### 挑战题

#### 练习5：递归求多个数的最大公约数

**题目描述**：输入 n 个正整数，使用递归算法求这 n 个数的最大公约数。

**提示**：`gcd(a1, a2, ..., an) = gcd(gcd(a1, a2, ..., a_{n-1}), an)`。利用辗转相除法的递归性质和"分而治之"的思想，将 n 个数的 gcd 问题递归分解为两个部分。

**输入格式**：
- 第一行：一个整数 n（2 ≤ n ≤ 10）
- 第二行：n 个正整数，空格分隔

**输出格式**：一行一个整数，表示这 n 个数的最大公约数。

**样例输入**：
```
3
24 36 60
```

**样例输出**：
```
12
```

### 练习题参考答案

```cpp
#include <iostream>
using namespace std;

// 练习1 & 2：递归求最大公约数
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

// 最小公倍数
long long lcm(int a, int b) {
    return (long long)a / gcd(a, b) * b;  // 先除后乘防溢出
}

// 练习3：汉诺塔
int step = 0;

void hanoi(int n, char src, char aux, char dst) {
    if (n == 1) {
        step++;
        cout << "#" << step << ": " << src << " -> " << dst << endl;
        return;
    }
    hanoi(n - 1, src, dst, aux);
    step++;
    cout << "#" << step << ": " << src << " -> " << dst << endl;
    hanoi(n - 1, aux, src, dst);
}

// 练习5：多个数的最大公约数
int gcd_multi(int arr[], int left, int right) {
    if (left == right) return arr[left];
    int mid = (left + right) / 2;
    return gcd(gcd_multi(arr, left, mid),
               gcd_multi(arr, mid + 1, right));
}

int main() {
    int a, b;
    cin >> a >> b;
    cout << "gcd(" << a << ", " << b << ") = " << gcd(a, b) << endl;
    cout << "lcm(" << a << ", " << b << ") = " << lcm(a, b) << endl;
    return 0;
}
```

## 📝 本课小结

本节课我们学习了递归这一重要的算法思想，并通过两个经典问题进行了深入实践。递归的核心在于"自己调用自己"，将一个复杂的大问题不断分解为结构相同但规模更小的子问题，直到子问题简单到可以直接求解（递归终止条件）。汉诺塔问题展示了递归如何将看似复杂的移动过程归结为三步：把上面的移走、移动最底下的、再把上面的移回来，这正是分治思想的完美体现。欧几里得算法（辗转相除法）则展示了递归在数学计算中的优雅——用极简的代码（仅两三行）就能高效地求出两个数的最大公约数，其时间复杂度仅为对数级别。

在学习递归时，有两点需要特别注意：第一，必须明确递归终止条件，否则程序会陷入无限递归导致栈溢出；第二，递归虽然代码简洁，但并非所有问题都适合用递归解决——当问题规模较大或递归深度过深时，需要考虑使用迭代（循环）替代，以避免性能问题或栈空间不足。希望同学们多加练习，逐步建立起递归思维，这将为后续学习回溯算法、树的遍历、动态规划等高级算法打下坚实的基础。
