# 第13课：归并排序——合并有序序列

## 🎯 学习目标
- 理解归并排序的分治策略：先递归分解，再合并有序子数组
- 掌握合并两个有序数组（merge）的操作
- 能够利用归并排序解决逆序对计数等问题

## 📖 算法讲解

### 一、从一个生活中的例子说起

想象你在整理一副散乱的扑克牌。你面前有52张牌，你想把它们从小到大排好。你会怎么做？

一个聪明的方法是：**把难题拆成小难题**。先把52张牌分成两叠各26张，分别排好。然后，把这两叠已经排好的牌合并成整齐的一叠。26张还是太多？没关系，继续拆——26拆成13、13拆成7和6……一直拆到每一叠只有1张牌。1张牌天然是有序的，不用排。

现在，问题变成了：**如何把两叠已经排好的牌，合并成一叠排好的牌？**

这就像你有两本按字母顺序排列的电话号码簿，你想把它们合并成一本——你只需要同时翻开两本书，比较当前的名字，谁靠前就抄谁到新书里。这就是归并排序的核心操作：**合并两个有序数组**。

### 二、什么是归并排序？

归并排序（Merge Sort）是一种基于**分治策略**的经典排序算法。它的思路可以用三个字概括：

```
      分         →        治         →        合
   ┌──────────────────────────────────────────────┐
   │  把大问题拆    │  递归地把每个    │  把两个有序的    │
   │  成小问题      │  小问题解决掉    │  答案合并起来    │
   └──────────────────────────────────────────────┘
```

具体到排序问题上：

- **分（Divide）**：把待排序的数组从中间切成两半
- **治（Conquer）**：对左半部分和右半部分分别递归地进行归并排序
- **合（Combine）**：把排好序的左半部分和右半部分，合并成一个有序的完整数组

### 三、递归分解过程详解

假设我们要对数组 `[8, 4, 5, 7, 1, 3, 6, 2]` 进行归并排序，分解过程如下：

```
                         [8, 4, 5, 7, 1, 3, 6, 2]
                                  │
                   ┌──────────────┴──────────────┐
                   │                             │
            [8, 4, 5, 7]                  [1, 3, 6, 2]
                   │                             │
           ┌───────┴───────┐             ┌───────┴───────┐
           │               │             │               │
        [8, 4]          [5, 7]        [1, 3]          [6, 2]
           │               │             │               │
       ┌───┴───┐       ┌───┴───┐     ┌───┴───┐       ┌───┴───┐
       │       │       │       │     │       │       │       │
      [8]     [4]     [5]     [7]   [1]     [3]     [6]     [2]
```

当分解到每个子数组只剩1个元素时，每个子数组天然就是有序的（一个元素不需要排序）。这就是递归的**终止条件**。

### 四、合并两个有序数组的详细步骤

这是归并排序最核心的操作。假设我们有两个有序数组：

```
左半部分: [4, 8]     右半部分: [5, 7]
```

我们需要把它们合并成一个有序数组。我们使用**双指针法**：

```
步骤演示（用 i 指左数组，用 j 指右数组，用 k 指向临时数组）：

初始状态：
  左: [4, 8]     i = 0 (指向 4)
  右: [5, 7]     j = 0 (指向 5)
  临时数组: [_]  k = 0

第1步：比较 左[i]=4 和 右[j]=5
       4 < 5，取4放入临时数组
       左: [4, 8]     i = 1 ↑
       临时数组: [4]   k = 1

第2步：比较 左[i]=8 和 右[j]=5
       8 > 5，取5放入临时数组
       右: [5, 7]     j = 1 ↑
       临时数组: [4, 5]  k = 2

第3步：比较 左[i]=8 和 右[j]=7
       8 > 7，取7放入临时数组
       右: [5, 7]     j = 2 ↑ (超出数组范围)
       临时数组: [4, 5, 7]  k = 3

第4步：右数组已经取完了，直接把左数组剩余的元素搬过来
       左: [4, 8]     i = 2 ↑ (超出)
       临时数组: [4, 5, 7, 8]  k = 4

最后：将临时数组 [4, 5, 7, 8] 拷贝回原数组的对应位置
```

合并操作可以用以下伪代码表示：

```
1. 创建一个临时数组 temp，大小等于左半部分 + 右半部分的长度
2. 用 i 指向左半部分的起始位置，j 指向右半部分的起始位置
3. 当 i 和 j 都还没走完时：
   a. 如果 左[i] <= 右[j]，把 左[i] 放入 temp，i 往后移一格
   b. 否则，把 右[j] 放入 temp，j 往后移一格
4. 如果左边还有剩余元素，全部放入 temp
5. 如果右边还有剩余元素，全部放入 temp
6. 把 temp 中的内容拷贝回原数组的对应位置
```

### 五、完整排序过程演示

继续上面的例子，我们从底向上看完整的"分"与"合"过程：

```
阶段1 — 分解到最小（每个子数组只有1个元素）：
       [8] [4] [5] [7] [1] [3] [6] [2]
        个  个  个  个  个  个  个  个

阶段2 — 两两合并：
       [4, 8]    [5, 7]    [1, 3]    [2, 6]
         ↑          ↑          ↑          ↑
      (4<8交换)  (5<7保持)  (1<3保持)  (2<6交换)

阶段3 — 继续合并：
       [4, 5, 7, 8]          [1, 2, 3, 6]
             ↑                      ↑
       合并 [4,8] + [5,7]    合并 [1,3] + [2,6]

阶段4 — 最终合并：
       [1, 2, 3, 4, 5, 6, 7, 8]
                   ↑
          合并左右两个长度为4的有序数组
```

可以看到，归并排序是一个**自底向上**逐渐构建有序序列的过程。先保证每个小段有序，再保证更大的段有序，最终整个数组有序。

### 六、与快速排序的对比

归并排序和快速排序都使用了**分治思想**，但它们的侧重点不同：

| 比较维度 | 归并排序 | 快速排序 |
|---------|---------|---------|
| 核心操作 | 放在"合"——合并两个有序数组 | 放在"分"——根据基准划分数组 |
| 递归顺序 | 先递归，后合并（后序遍历） | 先划分，后递归（前序遍历） |
| 时间复杂度 | 始终 O(n log n) | 平均 O(n log n)，最坏 O(n²) |
| 空间复杂度 | O(n)，需要额外数组 | O(log n)，递归栈空间 |
| 稳定性 | **稳定排序**（相等元素相对顺序不变） | 不稳定 |
| 适用场景 | 数据量大、要求稳定、链表排序 | 内存受限、追求平均速度 |

简单记忆：**快速排序是"先分后排"，归并排序是"先排后合"。**

### 七、归并排序的"副产品"——求逆序对

在合并两个有序子数组的过程中，我们可以顺手统计"逆序对"的数量。

什么情况下会产生逆序对呢？在合并时，当我们发现**右边的某个元素比左边当前元素还要小**，这意味着：左边当前元素及其后面的所有元素，都和这个右边的元素构成逆序对。

```
合并中检测逆序对：
  左: [3, 5, 8]    右: [2, 6, 9]
        ↑                 ↑
       i=0              j=0

比较：3 > 2  → 2比3小！
说明：左数组中从i到末尾的所有元素（3, 5, 8）都和右数组的2构成逆序对
逆序对数量 += 左数组剩余长度 = 3

把2放入temp，j往后移：
  左: [3, 5, 8]    右: [2, 6, 9]
        ↑                 ↑
       i=0              j=1

继续比较：3 < 6，正常放入3，i往后移……
```

这一技巧使得我们可以在 O(n log n) 的时间内求出逆序对的数量，比朴素的 O(n²) 枚举快得多。

## 💻 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// ================================================================
// 函数：合并两个有序子数组
// 参数说明：
//   arr   - 原始数组
//   left  - 左子数组的起始下标
//   mid   - 左子数组的结束下标（左子数组为 [left, mid]）
//   right - 右子数组的结束下标（右子数组为 [mid+1, right]）
//
// 注意：arr 的 [left, mid] 和 [mid+1, right] 两段分别是有序的
//       本函数将它们合并成一个有序段，放回 arr 的 [left, right] 中
// ================================================================
void merge(vector<int>& arr, int left, int mid, int right) {
    // 创建一个临时数组，存放合并结果
    vector<int> temp(right - left + 1);
    
    // i —— 左子数组的指针，从 left 开始
    // j —— 右子数组的指针，从 mid+1 开始
    // k —— 临时数组的指针，从 0 开始
    int i = left;
    int j = mid + 1;
    int k = 0;
    
    // 核心合并逻辑：谁小取谁
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k] = arr[i];  // 左边的小，取左边的
            i++;
        } else {
            temp[k] = arr[j];  // 右边的小，取右边的
            j++;
        }
        k++;
    }
    
    // 左子数组还有剩余，全部搬到 temp 后面
    while (i <= mid) {
        temp[k] = arr[i];
        i++;
        k++;
    }
    
    // 右子数组还有剩余，全部搬到 temp 后面
    // （注意：这两个 while 只有一个会真正执行）
    while (j <= right) {
        temp[k] = arr[j];
        j++;
        k++;
    }
    
    // 将合并好的结果从 temp 拷贝回 arr 的对应位置
    for (int t = 0; t < (int)temp.size(); t++) {
        arr[left + t] = temp[t];
    }
}

// ================================================================
// 函数：归并排序（递归实现）
// 参数说明：
//   arr   - 待排序的数组（引用传递，原地修改）
//   left  - 当前处理区间的左端点
//   right - 当前处理区间的右端点
//
// 递归过程：
//   1. 如果 left >= right（区间长度 ≤ 1），直接返回（已有序）
//   2. 取中间位置 mid = (left + right) / 2
//   3. 递归排序左半部分 [left, mid]
//   4. 递归排序右半部分 [mid+1, right]
//   5. 合并左右两个有序子数组
// ================================================================
void mergeSort(vector<int>& arr, int left, int right) {
    // 递归终止条件：区间长度 ≤ 1，天然有序
    if (left >= right) {
        return;
    }
    
    // 计算中间位置（防止大数溢出，等价于 (left + right) / 2）
    int mid = left + (right - left) / 2;
    
    // 递归：先让左半部分有序
    mergeSort(arr, left, mid);
    
    // 递归：再让右半部分有序
    mergeSort(arr, mid + 1, right);
    
    // 合并：把两个有序子数组合并成一个有序数组
    merge(arr, left, mid, right);
}
```

## 📊 复杂度分析

### 时间复杂度：O(n log n)

归并排序为什么是 O(n log n) 呢？我们从"递归树"的角度来理解：

- **递归深度**：每次把数组一分为二，要多少次才能分成单个元素？—— log₂n 层
- **每层的工作量**：每一层都要对所有的元素做一次合并操作，总共处理 n 个元素
- **总工作量** = 层数 × 每层工作量 = log₂n × n = **n log₂n**

```
递归树的每一层：
第0层            ┌──────── n ─────────┐      合并 n 个元素
第1层        ┌── n/2 ──┐  ┌── n/2 ──┐       合并 n 个元素
第2层     ┌n/4┐ ┌n/4┐ ┌n/4┐ ┌n/4┐           合并 n 个元素
 ...        ...   ...   ...   ...
第log₂n层  [1][1][1]...[1][1][1]            合并 n 个元素
────────────────────────────────────────
总计：n × log₂n 次比较/移动
```

**重要特性**：归并排序的时间复杂度**始终是 O(n log n)**，不管输入数据是什么样的——已经排好序、完全逆序、还是随机排列，都需要同样的时间。这使它成为一种非常"稳定可靠"的排序算法。

### 空间复杂度：O(n)

归并排序需要一个额外的临时数组来存放合并结果。在最坏情况下，这个临时数组的大小和原数组一样大（当合并整个数组时）。因此空间复杂度为 O(n)。

这是归并排序相对于快速排序的一个劣势：它需要额外的内存空间。但这个劣势在某些情况下也可以接受，因为 n 通常不会特别大。

### 稳定性

归并排序是**稳定排序**。在合并过程中，当左数组元素和右数组元素相等时，我们优先取左数组的元素（`arr[i] <= arr[j]` 中的 `<=` 保证了这一点），这样就保持了相等元素的原有相对顺序。

## 🏋️ 经典例题

### 例题1：求逆序对

**题目描述**：对于一个序列 a，如果 i < j 且 a[i] > a[j]，则称 (a[i], a[j]) 为一个逆序对。给定一个长度为 n 的序列，求其中逆序对的数量。

**输入格式**：第一行一个整数 n（1 ≤ n ≤ 100000）。第二行 n 个整数，表示序列 a。

**输出格式**：一个整数，表示逆序对的数量。注意：答案可能超过 int 的范围，需要使用 long long。

**样例输入**：
```
5
3 1 4 2 5
```

**样例输出**：
```
3
```

**样例解释**：序列 [3, 1, 4, 2, 5] 中的逆序对有：
- (3, 1)：i=1, j=2, 3 > 1
- (3, 2)：i=1, j=4, 3 > 2
- (4, 2)：i=3, j=4, 4 > 2
共 3 个逆序对。

**解题思路**：在归并排序的合并过程中统计逆序对。当 `arr[i] > arr[j]` 时，说明左子数组中从 i 到 mid 的所有元素都与 arr[j] 构成逆序对（因为左子数组是有序的，arr[i] 后面的一定都比 arr[j] 大）。此时逆序对数量增加 `mid - i + 1`。

**题解代码**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

typedef long long ll;  // 逆序对数量可能很大，用 long long

// 合并函数，同时统计逆序对
ll mergeAndCount(vector<int>& arr, int left, int mid, int right) {
    vector<int> temp(right - left + 1);
    int i = left;
    int j = mid + 1;
    int k = 0;
    ll count = 0;  // 本次合并过程中发现的逆序对数量
    
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k] = arr[i];
            i++;
        } else {
            // arr[i] > arr[j]，构成逆序对！
            // 左子数组 [i, mid] 全部大于 arr[j]
            temp[k] = arr[j];
            count += (mid - i + 1);  // 关键：累加逆序对
            j++;
        }
        k++;
    }
    
    while (i <= mid) {
        temp[k] = arr[i];
        i++;
        k++;
    }
    while (j <= right) {
        temp[k] = arr[j];
        j++;
        k++;
    }
    
    for (int t = 0; t < (int)temp.size(); t++) {
        arr[left + t] = temp[t];
    }
    
    return count;
}

// 递归排序，同时返回区间内的逆序对总数
ll mergeSortAndCount(vector<int>& arr, int left, int right) {
    if (left >= right) {
        return 0;  // 单个元素，没有逆序对
    }
    
    int mid = left + (right - left) / 2;
    
    // 左半部分的逆序对
    ll leftCount = mergeSortAndCount(arr, left, mid);
    // 右半部分的逆序对
    ll rightCount = mergeSortAndCount(arr, mid + 1, right);
    // 横跨左右两部分的逆序对（在合并时统计）
    ll crossCount = mergeAndCount(arr, left, mid, right);
    
    return leftCount + rightCount + crossCount;
}

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    ll ans = mergeSortAndCount(a, 0, n - 1);
    cout << ans << endl;
    
    return 0;
}
```

### 例题2：归并排序验证

**题目描述**：使用归并排序对 n 个整数从小到大排序。

**输入格式**：第一行一个整数 n（1 ≤ n ≤ 100000）。第二行 n 个整数。

**输出格式**：一行 n 个整数，表示排序后的结果，数之间用空格隔开。

**样例输入**：
```
5
8 4 5 7 1
```

**样例输出**：
```
1 4 5 7 8
```

**题解代码**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

// merge 函数（和前面的实现相同）
void merge(vector<int>& arr, int left, int mid, int right) {
    vector<int> temp(right - left + 1);
    int i = left, j = mid + 1, k = 0;
    
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j])
            temp[k++] = arr[i++];
        else
            temp[k++] = arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    for (int t = 0; t < (int)temp.size(); t++)
        arr[left + t] = temp[t];
}

// mergeSort 函数（和前面的实现相同）
void mergeSort(vector<int>& arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);
    merge(arr, left, mid, right);
}

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    
    mergeSort(a, 0, n - 1);
    
    for (int i = 0; i < n; i++) {
        cout << a[i];
        if (i < n - 1) cout << " ";
    }
    cout << endl;
    
    return 0;
}
```

**题目描述**：给定一个整数数组 nums，对于每个元素 nums[i]，请你统计数组中比它小的右侧元素的数量。即：返回一个数组 counts，其中 counts[i] 是 nums[i] 右侧小于 nums[i] 的元素个数。请利用归并排序的思想在 O(n log n) 时间内完成。

**输入格式**：第一行一个整数 n（1 ≤ n ≤ 100000）。第二行 n 个整数。

**输出格式**：一行 n 个整数，表示每个元素右侧小于它的元素个数，用空格分隔。

**样例输入**：
```
4
5 2 6 1
```

**样例输出**：
```
2 1 1 0
```

**样例解释**：
- 5 的右侧有 2 和 1 比它小，共 2 个
- 2 的右侧有 1 比它小，共 1 个
- 6 的右侧有 1 比它小，共 1 个
- 1 的右侧没有元素，共 0 个

#### 挑战题1：翻转对

**题目描述**：给定一个数组 nums，如果 i < j 且 nums[i] > 2 * nums[j]，我们就将 (i, j) 称作一个**重要翻转对**。请你返回给定数组中的重要翻转对的数量。请利用归并排序思想在 O(n log n) 时间内完成。

**输入格式**：第一行一个整数 n（1 ≤ n ≤ 50000）。第二行 n 个整数。

**输出格式**：一个整数，表示重要翻转对的数量。

**样例输入**：
```
5
2 4 3 5 1
```

**样例输出**：
```
3
```

**样例解释**：重要翻转对有：
- (4, 1)：4 > 2×1
- (3, 1)：3 > 2×1
- (5, 1)：5 > 2×1

```cpp
#include <iostream>
#include <vector>
using namespace std;

void merge(vector<int>& arr, int left, int mid, int right) {
    vector<int> temp(right - left + 1);
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) temp[k++] = arr[i++];
        else temp[k++] = arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    for (int t = 0; t < (int)temp.size(); t++)
        arr[left + t] = temp[t];
}

void mergeSort(vector<int>& arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);
    merge(arr, left, mid, right);
}
```

```cpp
#include <iostream>
#include <vector>

typedef long long ll;

ll mergeAndCount(vector<int>& arr, int left, int mid, int right) {
    vector<int> temp(right - left + 1);
    int i = left, j = mid + 1, k = 0;
    ll count = 0;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            count += (mid - i + 1);
            temp[k++] = arr[j++];
        }
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    for (int t = 0; t < (int)temp.size(); t++)
        arr[left + t] = temp[t];
    return count;
}

ll mergeSortAndCount(vector<int>& arr, int left, int right) {
    if (left >= right) return 0;
    int mid = left + (right - left) / 2;
    ll leftCount = mergeSortAndCount(arr, left, mid);
    ll rightCount = mergeSortAndCount(arr, mid + 1, right);
    ll crossCount = mergeAndCount(arr, left, mid, right);
    return leftCount + rightCount + crossCount;
}

    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
```

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

// 将值和下标绑定
struct Elem {
    int val, idx;
};

void mergeAndCount(vector<Elem>& arr, vector<int>& ans, int left, int mid, int right) {
    vector<Elem> temp(right - left + 1);
    int i = left, j = mid + 1, k = 0;
    int rightCount = 0;  // 统计右侧已经被放入 temp 的元素个数

    while (i <= mid && j <= right) {
        if (arr[i].val <= arr[j].val) {
            ans[arr[i].idx] += rightCount;  // 右侧有 rightCount 个小于它的元素
            temp[k++] = arr[i++];
        } else {
            rightCount++;
            temp[k++] = arr[j++];
        }
    }
    while (i <= mid) {
        ans[arr[i].idx] += rightCount;
        temp[k++] = arr[i++];
    }
    while (j <= right) {
        temp[k++] = arr[j++];
    }
    for (int t = 0; t < (int)temp.size(); t++)
        arr[left + t] = temp[t];
}

void mergeSort(vector<Elem>& arr, vector<int>& ans, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, ans, left, mid);
    mergeSort(arr, ans, mid + 1, right);
    mergeAndCount(arr, ans, left, mid, right);
}

int main() {
    int n;
    cin >> n;
    vector<Elem> arr(n);
    for (int i = 0; i < n; i++) {
        cin >> arr[i].val;
        arr[i].idx = i;
    }
    vector<int> ans(n, 0);
    mergeSort(arr, ans, 0, n - 1);
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << ans[i];
    }
    cout << endl;
    return 0;
}
```

#### 挑战题1 参考代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

typedef long long ll;

// 在合并之前先统计重要翻转对
ll countPairs(vector<int>& arr, int left, int mid, int right) {
    ll count = 0;
    int j = mid + 1;
    for (int i = left; i <= mid; i++) {
        // 找到第一个不满足 arr[i] > 2*arr[j] 的位置
        while (j <= right && arr[i] > 2LL * arr[j]) {
            j++;
        }
        count += (j - (mid + 1));
    }
    return count;
}

void merge(vector<int>& arr, int left, int mid, int right) {
    vector<int> temp(right - left + 1);
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) temp[k++] = arr[i++];
        else temp[k++] = arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    for (int t = 0; t < (int)temp.size(); t++)
        arr[left + t] = temp[t];
}

ll mergeSort(vector<int>& arr, int left, int right) {
    if (left >= right) return 0;
    int mid = left + (right - left) / 2;
    ll count = mergeSort(arr, left, mid) + mergeSort(arr, mid + 1, right);
    count += countPairs(arr, left, mid, right);
    merge(arr, left, mid, right);
    return count;
}

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    cout << mergeSort(a, 0, n - 1) << endl;
    return 0;
}
```

## 📝 本课小结

本节课我们学习了归并排序，一种基于分治思想的经典排序算法。它的核心思想是"先分后合"：先将数组递归地分解为单个元素（天然有序），再通过合并两个有序数组的操作，自底向上地构建出完整的有序序列。

我们重点掌握了三个关键内容：
1. **分治三部曲**：分（Divide）→ 治（Conquer）→ 合（Combine），将大问题拆分为小问题解决
2. **双指针合并法**：用两个指针分别遍历两个有序子数组，谁小取谁，高效完成合并
3. **逆序对统计技巧**：在合并过程中，当发现右边元素小于左边元素时，一次性统计跨区逆序对

归并排序的时间复杂度始终为 O(n log n)，是一种稳定排序。虽然它需要 O(n) 的额外空间，但其稳定性和可预测的性能使它在很多实际场景中非常有用。更重要的是，"归并"的思想本身就是一种强大的思维方式，帮助我们将复杂问题分解为简单问题的组合。
