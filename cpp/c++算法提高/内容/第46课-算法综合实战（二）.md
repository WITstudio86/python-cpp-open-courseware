## 📖 算法回顾

### 动态规划（DP）

动态规划（Dynamic Programming）是一种将复杂问题分解为更小的子问题来求解的算法思想。它的核心在于**记住已经求解过的子问题的答案**，避免重复计算。

DP 的两个核心要素：

1. **最优子结构**：问题的最优解可以由子问题的最优解推导出来。例如，从起点到终点的最短路径，必然包含从起点到中间某个点的最短路径。

2. **无后效性**：某个状态一旦确定，就不受后续决策的影响。换句话说，我们只关心"当前在哪个状态"，而不关心"如何到达这个状态"。

DP 解题四步法：
- **第一步：确定状态**——用什么样的变量来描述当前局面。例如，在数字三角形中，dp[i][j] 表示从顶部走到第 i 行第 j 列的最大和
- **第二步：找出状态转移方程**——当前状态如何由之前的状态推导出来。例如，dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j]
- **第三步：确定边界条件**——初始状态是什么。例如，dp[1][1] = a[1][1]
- **第四步：确定计算顺序**——从小到大还是从大到小递推。通常根据状态转移的依赖关系来决定

常见的 DP 类型包括：线性 DP、背包 DP、区间 DP、树形 DP、状态压缩 DP 等。本节课重点讲解**网格路径类 DP**，这是图论与 DP 结合最紧密的领域。

### 图论基础

图（Graph）是由顶点（Vertex）和边（Edge）组成的结构。在网格路径问题中：
- **顶点**就是网格中的每个格子
- **边**就是格子之间允许的移动方向（如向右、向下）

图论中的"路径"概念与 DP 天然契合：当我们把网格看成一个有向无环图（DAG）时，求最短/最长路径恰恰就是 DP 最擅长的事情。这就是"DP+图论"的核心思想。

## 💻 综合技巧

### DP与图论的结合点

在网格类问题中，每个格子的状态只依赖于它"上方"和"左方"的格子（因为只能向右或向下移动），这恰好构成了一个**有向无环图**。DP 的计算顺序恰好就是图的**拓扑排序**顺序。

### 如何判断是否使用DP？

1. **问题是否具有重叠子问题？** 如果我们发现同一个子问题会被反复计算（如多条路径经过同一个格子），就应该考虑 DP
2. **问题是否具有最优子结构？** 局部的最优解能否推出全局的最优解？
3. **状态空间是否可控？** DP 的状态数量是否在时间和空间限制内？

### DP 两种实现方式的比较

| 方式 | 说明 | 优点 | 缺点 |
|------|------|------|------|
| **自顶向下（记忆化搜索）** | 用递归 + 记忆化数组 | 直观，容易写出 | 递归有栈溢出风险 |
| **自底向上（递推）** | 用循环从最小问题开始递推 | 效率高，无递归开销 | 需要确定正确的计算顺序 |

## 🏋️ 经典例题

### 例题1：数字三角形

#### 题目描述

给定一个 N 行的数字三角形。从顶部出发，在每一节点可以选择移动至左下方或右下方节点，一直走到底层。要求找出一条路径，使路径上的数字之和最大。

```
      7
    3   8
  8   1   0
2   7   4   4
4   5   2   6   5
```

在上面的三角形中，从顶部的 7 出发，走 7 → 3 → 8 → 7 → 5 的路径，和为 30。

#### 输入格式

```
第一行：整数 N（1 ≤ N ≤ 100），表示三角形的行数
接下来 N 行：第 i 行有 i 个整数，表示三角形第 i 层的数字
```

#### 输出格式

```
一个整数，表示最大的路径和
```

#### 样例输入

```
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```

#### 样例输出

```
30
```

#### 参考代码（自底向上DP）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 105;
int a[MAXN][MAXN];   // 存储数字三角形
int dp[MAXN][MAXN];  // dp[i][j]：从底部到(i,j)的最大路径和
int n;

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            cin >> a[i][j];
        }
    }
    
    // 初始化最底层（边界条件）
    for (int j = 1; j <= n; j++) {
        dp[n][j] = a[n][j];
    }
    
    // 从下往上递推
    for (int i = n - 1; i >= 1; i--) {
        for (int j = 1; j <= i; j++) {
            // 状态转移：当前值 + 下方两个邻居的较大值
            dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1]);
        }
    }
    
    cout << dp[1][1] << endl;  // 答案在顶部
    return 0;
}
```

**算法分析**：
- 状态定义：dp[i][j] 表示从底部到第 i 行第 j 列的最大路径和
- 状态转移：dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])
- 时间复杂度：O(N²)，空间复杂度：O(N²)，可优化为 O(N)

### 例题2：最小路径和

#### 题目描述

给定一个 N × M 的网格，每个格子中有一个非负整数。你需要从左上角 (1, 1) 走到右下角 (N, M)，每次只能向右或向下移动一步。请找出一条路径，使得路径上所有数字之和最小。

#### 输入格式

```
第一行：两个整数 N 和 M（1 ≤ N, M ≤ 100）
接下来 N 行：每行 M 个整数，表示网格中每个格子的权值
```

#### 输出格式

```
一个整数，表示最小路径和
```

#### 样例输入

```
3 3
1 3 1
1 5 1
4 2 1
```

#### 样例输出

```
7
```

**样例解释**：路径为 (1,1) → (2,1) → (2,2) → (2,3) → (3,3)，即 1+1+5+1+1=9；或路径 (1,1) → (1,2) → (1,3) → (2,3) → (3,3)，即 1+3+1+1+1=7，后者更小，答案为 7。

#### 参考代码

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>
using namespace std;

const int MAXN = 105;
const int INF = 0x3f3f3f3f;
int grid[MAXN][MAXN];  // 存储网格
int dp[MAXN][MAXN];    // dp[i][j]：到达(i,j)的最小路径和
int n, m;

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> grid[i][j];
        }
    }
    
    // 初始化dp数组为无穷大
    memset(dp, 0x3f, sizeof(dp));
    
    // 边界条件：起点
    dp[1][1] = grid[1][1];
    
    // 逐行逐列递推（这是网格的拓扑排序顺序）
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (i == 1 && j == 1) continue;  // 起点已处理
            
            // 状态转移：从上方或左方（图论中的两条"入边"）转移过来
            int fromUp = (i > 1) ? dp[i-1][j] : INF;
            int fromLeft = (j > 1) ? dp[i][j-1] : INF;
            dp[i][j] = grid[i][j] + min(fromUp, fromLeft);
        }
    }
    
    cout << dp[n][m] << endl;  // 答案在右下角
    return 0;
}
```

**算法分析**：
- 状态定义：dp[i][j] 表示从起点 (1,1) 到达 (i,j) 的最小路径和
- 状态转移：dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
- 图论视角：每个格子有两条"入边"（上方和左方），DP 的递推顺序恰好是图的拓扑排序
- 时间复杂度：O(N × M)，空间复杂度：O(N × M)，可优化为 O(M)

## 📊 复杂度分析

| 题目 | 算法类型 | 状态数 | 转移复杂度 | 总时间复杂度 | 空间复杂度 |
|------|----------|--------|------------|--------------|------------|
| 数字三角形 | 线性DP（三角形） | O(N²) | O(1) | O(N²) | O(N²) / O(N) |
| 最小路径和 | 网格DP（图论+DP） | O(N × M) | O(1) | O(N × M) | O(N × M) / O(min(N,M)) |

- **数字三角形**：有 N(N+1)/2 ≈ N²/2 个状态，每个状态 O(1) 转移，总体 O(N²)
- **最小路径和**：有 N×M 个状态，每个状态 O(1) 转移，总体 O(N×M)
- 两者都可以通过**滚动数组**将空间复杂度优化一个维度

### 练习题参考答案

#### 练习1参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int a[105][105], dp[105][105];

int main() {
    int N;
    cin >> N;
    for (int i = 1; i <= N; i++)
        for (int j = 1; j <= i; j++)
            cin >> a[i][j];

    dp[1][1] = a[1][1];
    for (int i = 2; i <= N; i++) {
        for (int j = 1; j <= i; j++) {
            if (j == 1)
                dp[i][j] = dp[i-1][j] + a[i][j];
            else if (j == i)
                dp[i][j] = dp[i-1][j-1] + a[i][j];
            else
                dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j];
        }
    }

    int ans = 0;
    for (int j = 1; j <= N; j++)
        ans = max(ans, dp[N][j]);
    cout << ans << endl;
    return 0;
}
```

#### 练习3参考代码

```cpp
#include <iostream>
using namespace std;

const int MOD = 1000000007;
int grid[105][105];
long long dp[105][105];

int main() {
    int N, M;
    cin >> N >> M;
    for (int i = 1; i <= N; i++)
        for (int j = 1; j <= M; j++)
            cin >> grid[i][j];

    if (grid[1][1] == 1) { cout << 0 << endl; return 0; }
    dp[1][1] = 1;

    for (int i = 1; i <= N; i++) {
        for (int j = 1; j <= M; j++) {
            if (i == 1 && j == 1) continue;
            if (grid[i][j] == 1) { dp[i][j] = 0; continue; }
            long long fromUp = (i > 1) ? dp[i-1][j] : 0;
            long long fromLeft = (j > 1) ? dp[i][j-1] : 0;
            dp[i][j] = (fromUp + fromLeft) % MOD;
        }
    }
    cout << dp[N][M] << endl;
    return 0;
}
```

#### 练习4参考代码

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <cstring>
using namespace std;

const int MAXN = 1005, INF = 0x3f3f3f3f;

struct Edge {
    int to, w;
};
vector<Edge> adj[MAXN];
int indeg[MAXN], dist[MAXN];

int main() {
    int N, M;
    cin >> N >> M;
    for (int i = 0; i < M; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        adj[u].push_back({v, w});
        indeg[v]++;
    }

    // 拓扑排序
    queue<int> q;
    memset(dist, -0x3f, sizeof(dist));  // 初始化为负无穷
    dist[1] = 0;

    for (int i = 1; i <= N; i++)
        if (indeg[i] == 0) q.push(i);

    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (auto& e : adj[u]) {
            if (dist[u] != -INF)  // 不可达的节点不参与转移
                dist[e.to] = max(dist[e.to], dist[u] + e.w);
            if (--indeg[e.to] == 0)
                q.push(e.to);
        }
    }

    cout << (dist[N] == -INF ? -1 : dist[N]) << endl;
    return 0;
}
```

## 📝 本课小结

1. **动态规划的核心**是将大问题拆解为有重叠的子问题，通过记住子问题的解来避免重复计算。解题时遵循"确定状态 → 转移方程 → 边界条件 → 计算顺序"的四步法
2. **网格路径问题**是 DP 与图论结合的典型场景：网格是一个有向无环图（DAG），DP 的递推顺序就是图的拓扑排序
3. **自底向上递推**比自顶向下递归更高效，且不会出现栈溢出，是竞赛中推荐使用的 DP 实现方式
4. 掌握数字三角形和最小路径和这两个经典问题后，可以轻松应对更复杂的变种（如带障碍物的路径、多起点多终点等）
