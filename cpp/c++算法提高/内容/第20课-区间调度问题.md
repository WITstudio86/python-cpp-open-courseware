# 第20课：区间调度问题——安排尽可能多的活动

## 🎯 学习目标

## 📖 算法讲解

### 一、什么是区间调度问题？

区间调度问题（Interval Scheduling）是贪心算法领域中最经典的问题之一。它的场景非常直观：假设你有一个资源（比如一间教室、一台机器、或者你自己的时间），同一时刻只能被一个活动占用。现在有 N 个活动，每个活动有一个开始时间 s[i] 和一个结束时间 f[i]。你的目标是：**从中选出尽可能多的活动，使得任意两个选出的活动在时间上不重叠。**

打个比方：你是一个忙碌的学生，今天有 N 个社团活动可以参加，但每个活动都有固定的开始和结束时间（有些活动时间重叠，你只能选一个）。你希望参加尽可能多的活动——应该如何选择？

### 二、贪心策略：按结束时间排序

直觉上，我们可能会想到以下几种策略：

1. **按开始时间排序**：每次都选开始最早的活动？不对——如果有一个活动从早上 8 点开到晚上 8 点，虽然它开始最早，但它占满了全天，选了它就不能选别的了。
2. **按持续时间排序**：每次都选最短的活动？也不对——短活动可能卡在中间，把两个本来可以都选的、互不重叠的长活动给破坏了。
3. **按结束时间排序**：每次都选结束最早的活动，选完之后，再从剩下的、开始时间不早于已选活动结束时间的活动中，继续选结束最早的。**这个策略是正确的。**

为什么按结束时间排序是正确的呢？核心原因是：**结束最早的活动，留给后面活动的时间最多。** 换句话说，在任何一个时刻，如果我们希望选出的活动数量最大化，我们应该优先把"占时间少"的活动放进去——而结束最早的活动，在"不浪费未来时间"这个意义上是最优的。

### 三、贪心选择性质

我们可以用"交换论证"来严格证明按结束时间排序的正确性：

假设问题的最优解是集合 OPT，我们贪心算法得到的解是集合 G。如果 OPT 和 G 不同，我们总可以将 OPT 逐步"调整"成 G，且不减少活动数量。

- 第一步：设 OPT 中结束最早的活动是 A，贪心选出的第一个活动是 B。由于 B 是按结束时间排序的全局最早结束的活动，必定有 f[B] ≤ f[A]。
- 第二步：我们在 OPT 中把 A 替换成 B。由于 f[B] ≤ f[A]，B 结束后留给后续活动的时间比 A 更多（或至少一样多），所以替换后的解仍然是可行的，且活动数量不变。
- 第三步：重复这个替换过程，我们可以将 OPT 完全变成 G，且活动数量始终不变。因此贪心解 G 也是最优解。

这种"交换论证"的思想，是证明贪心算法正确性的核心技巧，后续课程中还会反复用到。

### 四、算法步骤

```
┌──────────────────────────────────────────────────────────────┐
│                  区间调度贪心算法步骤                          │
├──────────────────────────────────────────────────────────────┤
│  1. 将所有活动（区间）按"结束时间"从小到大排序                 │
│  2. 初始化：选择第一个活动，记录 lastEnd = 第一个活动的结束时间 │
│  3. 遍历排序后的剩余活动：                                     │
│         如果 当前活动的开始时间 ≥ lastEnd：                     │
│             选择当前活动                                       │
│             更新 lastEnd = 当前活动的结束时间                   │
│  4. 选出的活动数量即为最大不重叠区间数                          │
└──────────────────────────────────────────────────────────────┘
```

时间线可视化：

```
活动按结束时间排序后：
A: [1, 4)           ← 结束最早，首先选中, lastEnd = 4
B:   [3, 5)         ← 开始时间 3 < 4，与 A 重叠，跳过
C:     [4, 6)       ← 开始时间 4 ≥ 4，选中, lastEnd = 6
D:       [5, 7)     ← 开始时间 5 < 6，与 C 重叠，跳过
E:         [6, 9)   ← 开始时间 6 ≥ 6，选中, lastEnd = 9
F:               [10, 12)  ← 开始时间 10 ≥ 9，选中

最终选出：A, C, E, F → 共 4 个活动
```

### 五、注意事项

- 使用 `struct` 将开始时间和结束时间捆绑在一起，方便排序。
- 比较函数应使用结束时间作为排序关键字：`return a.end < b.end;`。
- 如果结束时间相同，一般按开始时间排序（但这不影响最终答案，因为两个结束时间相同的区间，无论选哪个，对后续的影响是一样的）。
- 时间复杂度主要取决于排序：O(N log N)。

## 💻 代码实现

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// 定义区间结构体
struct Interval {
    int start;  // 开始时间
    int end;    // 结束时间
};

// 自定义比较函数：按结束时间从小到大排序
bool cmp(Interval a, Interval b) {
    return a.end < b.end;  // 结束时间早的排在前面
}

// 贪心选择最大不重叠区间数
int maxNonOverlap(Interval arr[], int n) {
    // 第一步：按结束时间排序
    sort(arr, arr + n, cmp);

    // 第二步：贪心选择
    int count = 1;               // 至少选第一个活动
    int lastEnd = arr[0].end;    // 当前已选最后一个活动的结束时间

    for (int i = 1; i < n; i++) {
        // 如果当前活动的开始时间不早于已选活动的结束时间
        if (arr[i].start >= lastEnd) {
            count++;                   // 选中当前活动
            lastEnd = arr[i].end;      // 更新最后结束时间
        }
    }

    return count;
}
```

## 📊 复杂度分析

- **时间复杂度**：O(N log N)，主要开销来自排序。排序完成后，贪心遍历只需要 O(N) 时间。
- **空间复杂度**：O(N)，需要存储 N 个区间的结构体数组。如果允许修改输入，也可以做到 O(1) 额外空间（原地排序）。

相比暴力枚举全部子集（时间复杂度 O(2^N)），贪心算法的效率有了质的飞跃。对于 N = 1000 的情况，暴力枚举完全不可行（2^1000 ≈ 10^301），而贪心算法只需要大约 1000 log₂(1000) ≈ 10000 次操作。

### 例题1：活动选择

**题目描述**：学校有 N 个活动可以申请使用礼堂。每个活动 i 有一个开始时间 s[i] 和结束时间 f[i]（s[i] < f[i]，且均为整数）。礼堂同一时间只能被一个活动使用。请你设计一个算法，在给定的 N 个活动中选择出尽可能多的活动，使得这些活动互不冲突。输出最多可以选择的活动数量。

**输入格式**：
```
第一行：一个整数 N（1 ≤ N ≤ 100000），表示活动的个数
接下来 N 行：每行两个整数 s[i] f[i]（0 ≤ s[i] < f[i] ≤ 10^9），表示第 i 个活动的开始时间和结束时间
```

**输出格式**：
```
一行：一个整数，表示最多可以选择的活动数量
```

**样例输入**：
```
6
1 4
3 5
0 6
5 7
3 8
5 9
```

**样例输出**：
```
3
```

**样例解释**：选择活动 (1,4)、(5,7) 和另一个合适的活动，一共 3 个。实际上按结束时间排序后：(1,4)→(5,7)→(5,9)中选(5,7)，共3个。

**题解代码**：
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Activity {
    int start;
    int finish;
};

// 按结束时间排序
bool cmp(Activity a, Activity b) {
    return a.finish < b.finish;
}

int main() {
    int n;
    cin >> n;
    Activity act[100005];

    for (int i = 0; i < n; i++) {
        cin >> act[i].start >> act[i].finish;
    }

    // 按结束时间从小到大排序
    sort(act, act + n, cmp);

    int count = 1;                    // 第一个活动必选
    int lastFinish = act[0].finish;   // 上一个选中活动的结束时间

    for (int i = 1; i < n; i++) {
        if (act[i].start >= lastFinish) {
            count++;
            lastFinish = act[i].finish;
        }
    }

    cout << count << endl;
    return 0;
}
```

### 例题2：最多不重叠区间

**题目描述**：给定数轴上的 N 个闭区间 [l_i, r_i]（左右端点均为整数，且 l_i < r_i）。请你从中选出尽可能多的区间，使得任意两个被选中的区间互不重叠（即对于任意两个选中的区间 [l_a, r_a] 和 [l_b, r_b]，要么 r_a ≤ l_b，要么 r_b ≤ l_a）。输出最多可以选出的区间个数，以及一种具体的选法（按原输入顺序输出被选中的区间编号）。

**输入格式**：
```
第一行：一个整数 N（1 ≤ N ≤ 100000），表示区间的个数
接下来 N 行：每行两个整数 l_i r_i（0 ≤ l_i < r_i ≤ 10^9），表示第 i 个区间
```

**输出格式**：
```
第一行：一个整数 M，表示最多可以选出的不重叠区间个数
第二行：M 个整数，表示被选中的区间编号（编号从 1 开始，按原输入顺序），用空格分隔
```

**样例输入**：
```
5
1 3
2 4
3 6
5 7
6 8
```

**样例输出**：
```
3
1 3 5
```

**样例解释**：区间按输入顺序编号为 1~5。选出区间 1: [1,3]、区间 3: [3,6]、区间 5: [6,8]，共 3 个不重叠区间。注意区间 [3,6] 和 [1,3] 在端点 3 处恰好相接，不算重叠。

**题解代码**：
```cpp
#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

struct Interval {
    int l, r;      // 左右端点
    int id;        // 原始编号（从1开始）
};

// 按右端点从小到大排序，右端点相同时按左端点排序
bool cmp(Interval a, Interval b) {
    if (a.r != b.r) return a.r < b.r;
    return a.l < b.l;
}

int main() {
    int n;
    cin >> n;
    Interval ivals[100005];

    for (int i = 0; i < n; i++) {
        cin >> ivals[i].l >> ivals[i].r;
        ivals[i].id = i + 1;  // 记录原始编号
    }

    // 按右端点排序
    sort(ivals, ivals + n, cmp);

    vector<int> chosen;              // 存储被选中区间的原始编号
    chosen.push_back(ivals[0].id);   // 第一个区间必选
    int lastR = ivals[0].r;          // 上一个选中区间的右端点

    for (int i = 1; i < n; i++) {
        if (ivals[i].l >= lastR) {   // 当前区间左端点 ≥ 上一个区间的右端点
            chosen.push_back(ivals[i].id);
            lastR = ivals[i].r;
        }
    }

    // 输出结果
    cout << chosen.size() << endl;
    for (int i = 0; i < (int)chosen.size(); i++) {
        if (i > 0) cout << " ";
        cout << chosen[i];
    }
    cout << endl;

    return 0;
}
```

## 📝 本课小结

本节课我们学习了贪心算法中非常经典的**区间调度问题**。核心思想是：**按结束时间从小到大排序，然后贪心地选择不与已选区间重叠的区间**。这个策略之所以正确，是因为结束最早的区间给后续区间留下了最大的选择空间。

我们掌握了以下要点：
1. **贪心策略**：按结束时间排序，每次选结束最早且不与已选区间重叠的区间。
2. **正确性证明**：通过交换论证，可以将任意最优解逐步调整为贪心解而不减少区间数量。
3. **结构体 + sort**：使用 `struct` 存储区间的开始和结束时间，用自定义比较函数 `cmp` 按结束时间排序。
4. **时间复杂度**：O(N log N)，瓶颈在排序；遍历选择只需 O(N)。

区间调度问题是许多后续贪心算法（如区间覆盖、区间选点）的基础。掌握了"按结束时间排序"这一核心思想，你就拥有了解决一大类区间问题的利器。在下一节课中，我们将继续探索区间相关的贪心算法——区间覆盖与选点问题。
