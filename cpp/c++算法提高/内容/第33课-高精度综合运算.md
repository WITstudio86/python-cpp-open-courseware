# 第33课：高精度综合运算

## 🎯 学习目标
- 理解高精度四则运算的整合方法，将加法、减法、乘法、除法封装为统一的数据结构
- 掌握高精度乘法和除法的综合运用，能够灵活组合多种运算解决复杂问题

## 📖 算法讲解

### 一、从分散到整合——高精度运算的统一框架

在前两节课中，我们分别学习了高精度乘法（第31课）和高精度除法（第32课），加上更早学习的加法和减法（第8课），我们已经掌握了高精度四则运算的全部基本操作。但是，之前的写法是把每种运算写成独立的函数，每次都传递 `vector<int>` 数组，代码分散、容易出错。

本节课的目标，是将这四种运算整合到一个统一的数据结构中——我们将定义一个 `BigInt` 结构体，把数字的存储和运算操作封装在一起。这种思路在 C++ 中称为"面向对象编程的初步应用"，虽然我们还没有正式学习类和对象，但结构体 + 函数的组合已经能够让我们体会到"封装"带来的便利。

```
┌─────────────────────────────────────────────────────────────────────┐
│                    高精度运算统一框架 —— BigInt 结构体                │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   存储层                                                            │
│   ┌───────────────────────────────────────────────────────────┐    │
│   │  vector<int> digits;    // 倒序存储，digits[0] 是个位      │    │
│   │  bool isNegative;       // 符号标记（本课以非负整数为主）   │    │
│   └───────────────────────────────────────────────────────────┘    │
│                                                                     │
│   运算层                                                            │
│   ┌──────────────┬──────────────┬──────────────┬──────────────┐    │
│   │  add()       │  subtract()  │  multiply()  │  divide2()   │    │
│   │  高精度加法  │  高精度减法  │  高精度乘法  │  高精除以低精 │    │
│   │  O(n)        │  O(n)        │  O(n×m)      │  O(n)        │    │
│   └──────────────┴──────────────┴──────────────┴──────────────┘    │
│                                                                     │
│   工具层                                                            │
│   ┌───────────────────────────────────────────────────────────┐    │
│   │  print()    // 从高位到低位输出大整数                       │    │
│   │  fromInt()  // 从普通整数构造 BigInt                        │    │
│   │  fromString() // 从字符串构造 BigInt                        │    │
│   └───────────────────────────────────────────────────────────┘    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 二、高精度加法和减法回顾

**高精度加法的核心流程：**

```
从最低位开始，逐位相加，处理进位。

  数字A:  [1, 2, 3]  表示 321（倒序存储）
  数字B:  [4, 5, 6]  表示 654（倒序存储）
            ↓
  逐位加:  1+4=5, 2+5=7, 3+6=9
            ↓
  结果:    [5, 7, 9]  表示 975
```

当某一位相加超过9时，需要进位（carry）。例如：8 + 7 = 15，当前位保留 5，进位 1 加到下一位。

**高精度减法的核心流程：**

```
从最低位开始，逐位相减，处理借位。

前提条件：被减数 A >= 减数 B（保证结果非负）

  数字A:  [5, 2, 1]  表示 125
  数字B:  [7, 9, 0]  表示 097
            ↓
  逐位减:  5-7 不够，向高位借1 → (5+10)-7=8, 借位=1
           2-9-1(借位) 不够，再借 → (2+10)-9-1=2, 借位=1
           1-0-1(借位)=0
            ↓
  结果:    [8, 2, 0]  表示 028 = 28
```

**关键点：** 加法有进位，减法有借位，两者互为逆运算。理解了其中一个，另一个也就容易掌握了。

### 三、高精度乘法

高精度乘法有两种常见形式：
1. **高精度 × 低精度**：一个大整数乘以一个普通 int，逐位乘然后统一处理进位
2. **高精度 × 高精度**：两个大整数相乘，双重循环逐位相乘

```
高精度 × 高精度 的核心思想：

        1   2   3    (A)
    ×   4   5   6    (B)
    ─────────────────
        6   12  18    (A × 6)
    5   10  15        (A × 50)
4   8   12            (A × 400)
─────────────────────
4   13  28  27  18    (逐位累加)

然后从低位到高位处理进位：
18 → 8进1, 27+1=28 → 8进2, 28+2=30 → 0进3, 13+3=16 → 6进1, 4+1=5

结果：56088  ✓ (123 × 456 = 56088)
```

用代码实现时，我们使用一个结果数组 `c[i+j] += a[i] * b[j]`，最后统一处理进位。这种方法比边乘边进位更清晰，不容易出错。

### 四、高精度除法（除以低精度）

高精度除以低精度是模拟"竖式除法"的过程：

```
以 12345 ÷ 6 为例：

    从最高位开始：
    1 ÷ 6 = 0 余 1    → 商 0，余数 1
    12 ÷ 6 = 2 余 0   → 商 2，余数 0（12 = 1×10 + 2）
    3 ÷ 6 = 0 余 3    → 商 0，余数 3
    34 ÷ 6 = 5 余 4   → 商 5，余数 4（34 = 3×10 + 4）
    45 ÷ 6 = 7 余 3   → 商 7，余数 3（45 = 4×10 + 5）

    商：02057 → 去掉前导零 → 2057
    余数：3
```

代码实现的关键是维护一个"当前余数"变量 r，从高位到低位处理每一位：`r = r * 10 + 当前位`，然后 `商 = r / 除数`，`r = r % 除数`。最后需要去除商数组中的前导零。

### 五、高精度阶乘——综合运用

阶乘是乘法综合运用的典型例子。n 的阶乘 n! = 1 × 2 × 3 × ... × n。当 n 较大时（比如 n = 50），结果会远远超出 C++ 中任何整数类型的范围。

```
n = 10 时：
10! = 1 × 2 × 3 × ... × 10 = 3,628,800（普通 int 还能存下）

n = 20 时：
20! = 2,432,902,008,176,640,000（已经超出 unsigned long long 的范围！）

n = 50 时：
50! ≈ 3.04 × 10^64（有 65 位数字！）
```

**高精度阶乘算法流程：**

```
┌──────────────────────────────────────────────────────────────┐
│                   高精度阶乘算法                               │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 初始化 result = 1（BigInt 类型）                          │
│                                                              │
│  2. for i = 2 to n:                                          │
│       result = result × i    ← 高精度 × 低精度               │
│                                                              │
│  3. 输出 result                                              │
│                                                              │
│  关键优化：每次乘法后，及时处理进位，                          │
│  避免中间结果过大影响效率。                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

因为乘数 i 是普通整数（不超过500），我们可以使用"高精度 × 低精度"的乘法，这在实现上比"高精度 × 高精度"简单很多，而且效率也更高。每次将 result 的每一位乘以 i，然后统一处理进位即可。

以计算 5! 为例：

```
初始：result = 1
i = 2: result = 1 × 2 = 2
i = 3: result = 2 × 3 = 6
i = 4: result = 6 × 4 = 24
i = 5: result = 24 × 5 = 120
结果：120 ✓
```

### 六、计算器模拟——运算整合

将四则运算封装到统一的 BigInt 结构体后，我们可以轻松实现一个高精度计算器。计算器的核心逻辑非常简单：

```
┌──────────────────────────────────────────────────────┐
│              高精度计算器模拟流程                      │
├──────────────────────────────────────────────────────┤
│                                                      │
│  输入：运算符 op, 大整数 A, 大整数 B                   │
│                                                      │
│  if op == '+' :  result = A + B   (调用 add)          │
│  if op == '-' :  result = A - B   (调用 subtract)     │
│  if op == '*' :  result = A × B   (调用 multiply)     │
│                                                      │
│  输出 result                                         │
│                                                      │
└──────────────────────────────────────────────────────┘
```

虽然逻辑简单，但要处理的是长达200位的数字——普通的 `int` 或 `long long` 完全无法应对。这正是高精度计算的用武之地。

## 💻 代码实现

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

// ================================================================
// 高精度整数结构体（非负整数）
// ================================================================
struct BigInt {
    vector<int> digits; // 倒序存储：digits[0]是个位

    // 从字符串构造
    void fromString(const string &s) {
        digits.clear();
        for (int i = s.size() - 1; i >= 0; i--) {
            digits.push_back(s[i] - '0');
        }
    }

    // 从整数构造
    void fromInt(long long n) {
        digits.clear();
        if (n == 0) {
            digits.push_back(0);
            return;
        }
        while (n > 0) {
            digits.push_back(n % 10);
            n /= 10;
        }
    }

    // 输出
    void print() const {
        for (int i = digits.size() - 1; i >= 0; i--) {
            cout << digits[i];
        }
    }

    // 高精度加法：this + other
    BigInt add(const BigInt &other) const {
        BigInt result;
        int carry = 0;
        size_t maxLen = max(digits.size(), other.digits.size());

        for (size_t i = 0; i < maxLen; i++) {
            int a = (i < digits.size()) ? digits[i] : 0;
            int b = (i < other.digits.size()) ? other.digits[i] : 0;
            int sum = a + b + carry;
            result.digits.push_back(sum % 10);
            carry = sum / 10;
        }
        if (carry > 0) {
            result.digits.push_back(carry);
        }
        return result;
    }

    // 高精度减法：this - other（假设 this >= other）
    BigInt subtract(const BigInt &other) const {
        BigInt result;
        int borrow = 0;

        for (size_t i = 0; i < digits.size(); i++) {
            int a = digits[i];
            int b = (i < other.digits.size()) ? other.digits[i] : 0;
            int diff = a - b - borrow;
            if (diff < 0) {
                diff += 10;
                borrow = 1;
            } else {
                borrow = 0;
            }
            result.digits.push_back(diff);
        }

        // 去除前导零
        while (result.digits.size() > 1 && result.digits.back() == 0) {
            result.digits.pop_back();
        }
        return result;
    }

    // 高精度乘法：this × other（两个大整数相乘）
    BigInt multiply(const BigInt &other) const {
        BigInt result;
        result.digits.resize(digits.size() + other.digits.size(), 0);

        // 逐位相乘，结果累加到 c[i+j]
        for (size_t i = 0; i < digits.size(); i++) {
            for (size_t j = 0; j < other.digits.size(); j++) {
                result.digits[i + j] += digits[i] * other.digits[j];
            }
        }

        // 统一处理进位
        int carry = 0;
        for (size_t i = 0; i < result.digits.size(); i++) {
            int sum = result.digits[i] + carry;
            result.digits[i] = sum % 10;
            carry = sum / 10;
        }

        // 去除前导零
        while (result.digits.size() > 1 && result.digits.back() == 0) {
            result.digits.pop_back();
        }
        return result;
    }

    // 高精度乘以低精度：this × num（num 是普通整数）
    BigInt multiplyInt(int num) const {
        BigInt result;
        int carry = 0;

        for (size_t i = 0; i < digits.size(); i++) {
            int prod = digits[i] * num + carry;
            result.digits.push_back(prod % 10);
            carry = prod / 10;
        }

        while (carry > 0) {
            result.digits.push_back(carry % 10);
            carry /= 10;
        }
        return result;
    }

    // 高精度除以低精度：this ÷ divisor，返回商，同时通过引用返回余数
    BigInt divide2(int divisor, int &remainder) const {
        BigInt result;
        int r = 0; // 当前余数

        // 从高位到低位处理
        for (int i = digits.size() - 1; i >= 0; i--) {
            r = r * 10 + digits[i];
            result.digits.push_back(r / divisor);
            r = r % divisor;
        }

        // 此时商是按高位到低位存储的，需要反转
        reverse(result.digits.begin(), result.digits.end());

        // 去除前导零
        while (result.digits.size() > 1 && result.digits.back() == 0) {
            result.digits.pop_back();
        }

        remainder = r;
        return result;
    }
};

// 高精度阶乘
BigInt factorial(int n) {
    BigInt result;
    result.fromInt(1);

    for (int i = 2; i <= n; i++) {
        result = result.multiplyInt(i);
    }
    return result;
}
```

## 📊 复杂度分析

| 运算 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 高精度加法 `add()` | O(n) | O(n) | n 为两个数中较大的位数，逐位相加 |
| 高精度减法 `subtract()` | O(n) | O(n) | 与被减数位数成正比 |
| 高精度乘法 `multiply()` | O(n×m) | O(n+m) | n、m 分别为两个乘数的位数，双重循环逐位乘 |
| 高精×低精 `multiplyInt()` | O(n) | O(n) | 只需单层循环，比高精×高精快得多 |
| 高精÷低精 `divide2()` | O(n) | O(n) | 从高位到低位逐位处理 |
| 高精度阶乘 `factorial(n)` | O(n²×d) | O(d) | d ≈ n×log₁₀(n)，约为最终结果的位数。每个 i 做一次 O(d) 的乘法，共 n 次 |

**阶乘复杂度详解：**
- 结果的位数 d ≈ n × log₁₀(n)，对于 n=500，d ≈ 1135 位
- 每次乘法 multiplyInt(i) 的复杂度为 O(d)，d 随着结果增大而增长
- 总共执行 n-1 次乘法，整体复杂度约为 O(n² × log n × 常数)

对于 n ≤ 500，这个复杂度完全可以在 1 秒内完成计算。

### 例题1：高精度计算器模拟

**题目描述**：实现一个简单的高精度计算器，可以处理两个大整数的加法、减法和乘法运算。输入运算符和两个非负大整数（不超过200位），输出计算结果。

**输入格式**：一行，运算符（+、-或*）和两个大整数，空格分隔。

**输出格式**：计算结果（一行）。

**样例输入**：
```
+ 12345678901234567890 98765432109876543210
```

**样例输出**：
```
111111111011111111100
```

**题解代码**：
```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

struct BigInt {
    vector<int> digits; // 倒序存储

    void fromString(const string &s) {
        digits.clear();
        for (int i = s.size() - 1; i >= 0; i--)
            digits.push_back(s[i] - '0');
    }

    void print() const {
        for (int i = digits.size() - 1; i >= 0; i--)
            cout << digits[i];
    }

    // 比较两个 BigInt 的大小：this >= other 返回 true
    bool ge(const BigInt &other) const {
        if (digits.size() != other.digits.size())
            return digits.size() > other.digits.size();
        for (int i = digits.size() - 1; i >= 0; i--) {
            if (digits[i] != other.digits[i])
                return digits[i] > other.digits[i];
        }
        return true; // 相等
    }

    BigInt add(const BigInt &other) const {
        BigInt res;
        int carry = 0;
        size_t len = max(digits.size(), other.digits.size());
        for (size_t i = 0; i < len; i++) {
            int a = (i < digits.size()) ? digits[i] : 0;
            int b = (i < other.digits.size()) ? other.digits[i] : 0;
            int sum = a + b + carry;
            res.digits.push_back(sum % 10);
            carry = sum / 10;
        }
        if (carry) res.digits.push_back(carry);
        return res;
    }

    BigInt sub(const BigInt &other) const {
        BigInt res;
        int borrow = 0;
        for (size_t i = 0; i < digits.size(); i++) {
            int a = digits[i];
            int b = (i < other.digits.size()) ? other.digits[i] : 0;
            int diff = a - b - borrow;
            if (diff < 0) { diff += 10; borrow = 1; }
            else { borrow = 0; }
            res.digits.push_back(diff);
        }
        while (res.digits.size() > 1 && res.digits.back() == 0)
            res.digits.pop_back();
        return res;
    }

    BigInt mul(const BigInt &other) const {
        BigInt res;
        res.digits.resize(digits.size() + other.digits.size(), 0);
        for (size_t i = 0; i < digits.size(); i++)
            for (size_t j = 0; j < other.digits.size(); j++)
                res.digits[i + j] += digits[i] * other.digits[j];
        int carry = 0;
        for (size_t i = 0; i < res.digits.size(); i++) {
            int sum = res.digits[i] + carry;
            res.digits[i] = sum % 10;
            carry = sum / 10;
        }
        while (res.digits.size() > 1 && res.digits.back() == 0)
            res.digits.pop_back();
        return res;
    }
};

int main() {
    char op;
    string sa, sb;
    cin >> op >> sa >> sb;

    BigInt a, b, result;
    a.fromString(sa);
    b.fromString(sb);

    if (op == '+') {
        result = a.add(b);
    } else if (op == '-') {
        // 保证大数减小数，结果非负
        if (a.ge(b)) {
            result = a.sub(b);
        } else {
            cout << "-";
            result = b.sub(a);
        }
    } else if (op == '*') {
        result = a.mul(b);
    }

    result.print();
    cout << endl;
    return 0;
}
```

### 例题2：高精度阶乘

**题目描述**：输入一个正整数 n（1 ≤ n ≤ 500），计算 n 的阶乘（n!）。阶乘的定义：n! = 1 × 2 × 3 × ... × n。特别地，0! = 1。

**输入格式**：一个整数 n。

**输出格式**：n! 的值（一行）。

**样例输入1**：
```
10
```

**样例输出1**：
```
3628800
```

**样例输入2**：
```
50
```

**样例输出2**：
```
30414093201713378043612608166064768844377641568960512000000000000
```

**题解代码**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

// 高精度乘以低精度
void multiply(vector<int> &digits, int num) {
    int carry = 0;
    for (size_t i = 0; i < digits.size(); i++) {
        long long prod = (long long)digits[i] * num + carry;
        digits[i] = prod % 10;
        carry = prod / 10;
    }
    while (carry > 0) {
        digits.push_back(carry % 10);
        carry /= 10;
    }
}

// 高精度阶乘
void factorial(int n) {
    vector<int> digits;
    digits.push_back(1); // 初始值：1

    for (int i = 2; i <= n; i++) {
        multiply(digits, i);
    }

    // 从高位到低位输出
    for (int i = digits.size() - 1; i >= 0; i--) {
        cout << digits[i];
    }
    cout << endl;
}

int main() {
    int n;
    cin >> n;

    if (n == 0) {
        cout << 1 << endl;
    } else {
        factorial(n);
    }

    return 0;
}
```

**算法说明**：
1. 用一个 `vector<int>` 倒序存储结果的每一位（个位在索引0）
2. 初始值设为 1（即 1! = 1）
3. 从 2 到 n 循环，每次将当前结果乘以 i
4. 乘法使用"高精度 × 低精度"的方法：逐位乘，统一处理进位
5. 使用 `long long` 存储中间乘积，避免 `int` 溢出（`digits[i] * num` 最大约为 9 × 500 = 4500，但如果进位很大，`prod` 可能超过 int 范围）

**以 n=50 为例**：
- 结果的位数约为 65 位
- 共执行 49 次乘法
- 每次乘法的复杂度与当前结果位数成正比
- 总运算量极小，可以在瞬间完成

### 挑战题

#### 练习5：高精度组合数 C(n, m)

**题目描述**：输入两个整数 n 和 m（0 ≤ m ≤ n ≤ 100），计算组合数 C(n, m) = n! / (m! × (n-m)!) 的精确值。请使用高精度乘法和除法完成。

**提示**：由于组合数一定是整数，可以边乘边约分来避免大数除法。或者直接计算 (n×(n-1)×...×(n-m+1)) / (m!)，使用高精度乘法和高精度除以低精度。

**输入格式**：一行两个整数 n 和 m，空格分隔。

**输出格式**：一行，C(n, m) 的精确值。

**样例输入**：
```
10 3
```

**样例输出**：
```
120
```

### 练习题参考答案

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

struct BigInt {
    vector<int> digits;  // 倒序存储

    void fromString(const string &s) {
        digits.clear();
        for (int i = s.size() - 1; i >= 0; i--)
            digits.push_back(s[i] - '0');
    }

    void fromInt(long long n) {
        digits.clear();
        if (n == 0) { digits.push_back(0); return; }
        while (n) { digits.push_back(n % 10); n /= 10; }
    }

    string toString() const {
        string s;
        for (int i = digits.size() - 1; i >= 0; i--)
            s += char(digits[i] + '0');
        return s;
    }

    BigInt add(const BigInt &other) const {
        BigInt res;
        int carry = 0;
        size_t len = max(digits.size(), other.digits.size());
        for (size_t i = 0; i < len; i++) {
            int a = (i < digits.size()) ? digits[i] : 0;
            int b = (i < other.digits.size()) ? other.digits[i] : 0;
            int sum = a + b + carry;
            res.digits.push_back(sum % 10);
            carry = sum / 10;
        }
        if (carry) res.digits.push_back(carry);
        return res;
    }

    BigInt mul(const BigInt &other) const {
        BigInt res;
        res.digits.resize(digits.size() + other.digits.size(), 0);
        for (size_t i = 0; i < digits.size(); i++)
            for (size_t j = 0; j < other.digits.size(); j++)
                res.digits[i + j] += digits[i] * other.digits[j];
        int carry = 0;
        for (size_t i = 0; i < res.digits.size(); i++) {
            int sum = res.digits[i] + carry;
            res.digits[i] = sum % 10;
            carry = sum / 10;
        }
        while (res.digits.size() > 1 && res.digits.back() == 0)
            res.digits.pop_back();
        return res;
    }

    BigInt mulInt(int x) const {
        BigInt res;
        int carry = 0;
        for (size_t i = 0; i < digits.size(); i++) {
            int prod = digits[i] * x + carry;
            res.digits.push_back(prod % 10);
            carry = prod / 10;
        }
        while (carry) { res.digits.push_back(carry % 10); carry /= 10; }
        return res;
    }
};

// 练习3：高精度阶乘
string factorial(int n) {
    BigInt res; res.fromInt(1);
    for (int i = 2; i <= n; i++) res = res.mulInt(i);
    return res.toString();
}

// 练习5：高精度组合数 C(n, m)
string combination(int n, int m) {
    if (m > n - m) m = n - m;  // C(n, m) = C(n, n-m)
    BigInt res; res.fromInt(1);
    for (int i = 1; i <= m; i++) {
        res = res.mulInt(n - i + 1);  // 乘分子
        // 除分母：逐位除以 i
        int carry = 0;
        for (int j = res.digits.size() - 1; j >= 0; j--) {
            int cur = carry * 10 + res.digits[j];
            res.digits[j] = cur / i;
            carry = cur % i;
        }
        while (res.digits.size() > 1 && res.digits.back() == 0)
            res.digits.pop_back();
    }
    return res.toString();
}

BigInt a, b, result;

int main() {
    // 练习1：加法
    a.fromString("12345678901234567890");
    b.fromString("98765432109876543210");
    result = a.add(b);
    cout << "加法: " << result.toString() << endl;

    // 练习3：阶乘
    cout << "10! = " << factorial(10) << endl;

    // 练习5：组合数
    cout << "C(10, 3) = " << combination(10, 3) << endl;

    return 0;
}
```

## 📝 本课小结

本节课我们将高精度加法、减法、乘法和除法整合为一个统一的 BigInt 结构体，实现了高精度四则运算的封装与复用。通过计算器模拟和高精度阶乘两个经典例题，我们看到了高精度运算在实际问题中的强大威力。掌握高精度运算不仅是算法竞赛的必备技能，更能帮助我们深入理解计算机中"数"的本质——任何数据类型都有范围限制，而高精度算法让我们突破了这个限制。
