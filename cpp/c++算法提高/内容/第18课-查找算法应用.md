## 📖 算法讲解

### 一、从“查找数字”到“查找答案”

在前几节课中，我们学习了二分查找——在一个有序数组中快速定位某个数字的位置。二分查找的核心是：**每次排除一半的搜索空间**，将 O(n) 的查找时间降到 O(log n)。

但是，二分查找的能力远不止“找数字”这么简单。有一类更强大的应用叫做**二分答案**（Binary Search on Answer）：我们并不在一个已知的数组中查找，而是在一个**可能的答案区间**上进行二分，每一步通过一个 `check()` 函数判断当前猜测的答案是否可行，从而不断缩小答案范围。

打个比方：假如你要猜一个同学的身高。你不知道他的确切身高，但你知道他身高在 100cm 到 200cm 之间。你每次猜一个值，同学会告诉你“高了”还是“矮了”。你通过不断调整猜测范围，最终就能锁定他的身高。这就是二分答案的过程。

### 二、二分答案的适用条件

并不是所有问题都能用二分答案。二分答案需要满足两个重要条件：

1. **单调性（Monotonicity）**：答案所在的区间具有单调性。也就是说，如果答案是 x，那么所有大于 x 的值也一定满足条件（或都不满足条件）。更精确地说，存在一个分界点，分界点一侧全部可行，另一侧全部不可行。

2. **判定函数可高效实现**：我们需要一个 `check(x)` 函数，它能在较短时间内（通常是 O(n)）判断“答案是否 ≤ x”。如果 `check()` 函数本身就是 O(n²) 甚至更复杂，那二分就没有意义。

```
┌──────────────────────────────────────────────────────────────────┐
│                    二分答案的可行性区间                           │
│                                                                  │
│   答案过小 ─────────────────────────────── 答案过大               │
│   ←── 不可行 ──│──── 可行 ──→                                    │
│              分界点 = 最优答案                                   │
│                                                                  │
│   我们的目标：通过二分搜索，找到这个分界点！                      │
└──────────────────────────────────────────────────────────────────┘
```

### 三、“最小化最大值”问题

在算法竞赛中，有一类非常经典的问题叫做**“最小化最大值”问题**。它的典型特征如下：

- 给定一个序列（或集合），需要将其划分成若干段
- 每段有一个“代价”（比如段内元素之和）
- 要求在所有划分方案中，让**最大代价尽可能小**

这类问题的原型在生活中随处可见。比如：工厂要把一批订单分配到 M 台机器上加工，每台机器加工的时间不同，怎样分配订单能使得所有机器中最长的加工时间最短？又比如：要把 N 天的预算分摊到 M 个月中，怎样划分能使得最花钱的那个月的开销尽可能少？

这类“最小化最大值”问题恰好满足二分答案的单调性——如果我们猜测一个上限 T，问“是否存在一种划分方式，使得每段的代价都不超过 T”，那么：

- 如果 T 太小，无论如何划分都做不到 → 不可行
- 如果 T 足够大，一定可以做到 → 可行

因此，我们可以二分枚举 T 的值，并通过贪心策略来判定 T 是否可行。

### 四、贪心验证策略

`check(T)` 函数通常采用贪心验证策略。对于数列分段问题，验证逻辑如下：

```
贪心思想：从左到右扫描序列，尽可能把更多的元素放进当前段，
直到再加入一个元素就会超过上限 T，此时另起一段。
这样得到的段数就是“上限为 T 时所需的最少段数”。

如果 所需段数 ≤ M → T 足够大，可行
如果 所需段数 > M → T 太小，不可行
```

为什么贪心策略能给出最少段数？因为“尽可能塞满当前段”意味着每段都尽量接近上限 T，这样总的段数才会最少。如果这种“尽量塞满”的策略都需要超过 M 段，那其他任何策略只会需要更多段（或同样多）。

### 五、二分答案的代码框架

```cpp
// 二分答案通用框架
long long left = 下界;    // 答案的最小可能值
long long right = 上界;   // 答案的最大可能值
long long ans = right;    // 记录最终答案

while (left <= right) {
    long long mid = left + (right - left) / 2;
    if (check(mid)) {     // mid 可行，尝试更小的答案
        ans = mid;
        right = mid - 1;
    } else {              // mid 不可行，需要更大的答案
        left = mid + 1;
    }
}
cout << ans << endl;
```

这个框架和我们之前学过的二分查找几乎一模一样，唯一的不同在于：每次不是比较 `mid` 与目标值的大小，而是调用 `check(mid)` 来判断 `mid` 是否可行。如果可行，说明答案可以更小，就往左搜；如果不可行，说明答案必须更大，就往右搜。

### 六、check() 函数的设计要点

`check()` 是二分答案的灵魂。一个好的 `check()` 函数需要满足：

1. **正确性**：准确判断给定的上限是否可行
2. **高效性**：通常需要 O(n) 的时间复杂度
3. **简洁性**：逻辑清晰，不易出错

对于数列分段类问题的 `check()` 函数，其典型写法如下：

```cpp
bool check(long long limit) {
    int segments = 1;        // 当前已经划分的段数
    long long sum = 0;       // 当前段的元素和
    for (int i = 0; i < n; i++) {
        if (a[i] > limit) return false;  // 单个元素就超过上限，无解
        if (sum + a[i] > limit) {        // 再加入当前元素会超限
            segments++;                   // 另起一段
            sum = a[i];                   // 当前元素成为新段的首个元素
        } else {
            sum += a[i];                  // 继续往当前段加
        }
    }
    return segments <= m;                 // 段数不超过 M 则可行
}
```

## 💻 代码实现

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 100005;
long long a[MAXN];
int n, m;

// check函数：判断能否在每段和不超过limit的情况下，将序列分成不超过m段
bool check(long long limit) {
    int segments = 1;        // 当前段数（至少1段）
    long long sum = 0;       // 当前段的和
    
    for (int i = 0; i < n; i++) {
        // 如果单个元素就超过了上限，无论如何都不可行
        if (a[i] > limit) return false;
        
        if (sum + a[i] > limit) {
            // 加入a[i]会超过上限，需要新起一段
            segments++;
            sum = a[i];
        } else {
            // 可以继续加入当前段
            sum += a[i];
        }
    }
    // 段数不超过m说明这个上限可行
    return segments <= m;
}

// 二分答案：在[left, right]区间内找到最小的可行上限
long long binarySearch(long long left, long long right) {
    long long ans = right;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;          // mid可行，记录答案并尝试更小的值
            right = mid - 1;
        } else {
            left = mid + 1;     // mid不可行，需要更大的值
        }
    }
    return ans;
}
```

## 📊 复杂度分析

**数列分段 / 月度开销（二分答案 + 贪心验证）：**

- **时间复杂度**：O(n × log S)，其中 n 是元素个数，S 是答案的搜索范围（上界 - 下界）。check() 函数每次需要 O(n) 时间扫描整个序列，二分搜索需要对数级别的迭代次数，总复杂度为 O(n log S)。当 n = 10^5, S = 10^9 时，log S ≈ 30，总操作次数约为 3 × 10^6，完全可以接受。
- **空间复杂度**：O(n)，主要用于存储输入的序列。check() 函数只需要常数级别的额外空间。

**对比暴力枚举：**
- 如果暴力枚举答案从下界到上界，每次调用 check()，复杂度为 O(n × S)，当 S = 10^9 时完全不可行。二分答案将这部分从 O(S) 降至 O(log S)，是质的飞跃。

## 🏋️ 经典例题

### 例题1：数列分段

**题目描述**：

对于给定的一个长度为 N 的正整数数列 A[1..N]，现要将其分成 M（M ≤ N）段，并要求每段连续，且每段和的最大值最小。

请你求出这个最小的最大值是多少。

**输入格式**：
- 第一行包含两个正整数 N 和 M，表示数列的长度和要分成的段数
- 第二行包含 N 个空格隔开的非负整数 A[i]，表示数列中的元素

**输出格式**：
- 一个正整数，表示每段和的最大值的最小可能值

**数据范围**：
- 1 ≤ N ≤ 100,000
- 1 ≤ M ≤ N
- 0 ≤ A[i] ≤ 10,000

**样例输入**：
```
5 3
4 2 4 5 1
```

**样例输出**：
```
6
```

**样例解释**：

数列为 [4, 2, 4, 5, 1]，需要分成 3 段。
- 方案一：[4, 2], [4], [5, 1] → 段和分别为 6, 4, 6，最大值为 6
- 方案二：[4], [2, 4], [5, 1] → 段和分别为 4, 6, 6，最大值为 6
- 方案三：[4, 2], [4, 5], [1] → 段和分别为 6, 9, 1，最大值为 9

最优方案的最大段和为 6。

**题解思路**：

1. **确定二分上下界**：下界 `left` = max(A[i])（单元素最大值，因为一段至少要包含一个元素）；上界 `right` = sum(A[i])（所有元素之和，即只分一段的情况）。

2. **check(mid) 设计**：贪心地从左到右扫描，尽量把元素放进当前段，当累积和超过 mid 时新起一段。统计总段数，判断是否 ≤ M。

3. **二分搜索**：在 [left, right] 中搜索最小的可行上限。

**题解代码**：

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 100005;
long long a[MAXN];
int n, m;

bool check(long long limit) {
    int segments = 1;
    long long sum = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] > limit) return false;     // 单个元素就超限
        if (sum + a[i] > limit) {
            segments++;
            sum = a[i];
        } else {
            sum += a[i];
        }
    }
    return segments <= m;
}

int main() {
    cin >> n >> m;
    long long left = 0, right = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        left = max(left, a[i]);   // 下界：最大元素值
        right += a[i];            // 上界：所有元素之和
    }
    
    long long ans = right;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;
            right = mid - 1;       // 尝试更小的上限
        } else {
            left = mid + 1;        // 需要更大的上限
        }
    }
    cout << ans << endl;
    return 0;
}
```

### 例题2：月度开销

**题目描述**：

农夫约翰是一个精明的会计师。他意识到自己可能没有足够的钱来维持农场的运转了。他计算出并记录下了接下来 N（1 ≤ N ≤ 100,000）天里每天需要的开销。

约翰打算为连续的 M（1 ≤ M ≤ N）个财政周期创建预算案，他把一个财政周期命名为“fajo月”。每个 fajo 月包含一天或连续的多天，每天恰好被包含在一个 fajo 月里。

约翰的目标是合理安排每个 fajo 月包含的天数，使得**开销最多的 fajo 月的开销尽可能少**。

请你帮约翰求出这个最小值。

**输入格式**：
- 第一行包含两个整数 N 和 M，用单个空格隔开
- 接下来 N 行，每行包含一个 1 到 10000 之间的整数，表示接下来 N 天里每天的开销

**输出格式**：
- 一个整数，即最大月度开销的最小值

**数据范围**：
- 1 ≤ N ≤ 100,000
- 1 ≤ M ≤ N

**样例输入**：
```
7 5
100
400
300
100
500
101
400
```

**样例输出**：
```
500
```

**样例解释**：

7 天的开销分别为：100, 400, 300, 100, 500, 101, 400，需要分成 5 个 fajo 月。

最优划分方案：[100, 400], [300, 100], [500], [101], [400]
- 第 1 月：100 + 400 = 500
- 第 2 月：300 + 100 = 400
- 第 3 月：500
- 第 4 月：101
- 第 5 月：400

最大月度开销为 500。

如果尝试让最大月度开销为 400：第 3 天的 500 本身就已经超过了 400（单天开销就超过上限），不可能做到。因此 500 是最优解。

**题解思路**：

这道题与数列分段本质上是同一个问题——都是“将序列分成 M 段，最小化最大段和”。二者唯一的区别在于数据读入方式（数列分段是一行读入，月度开销是每行读入一个数）。

1. **确定二分上下界**：下界 `left` = 单天最大开销（一个 fajo 月至少包含一天）；上界 `right` = 所有天开销之和（全部归入一个 fajo 月）。

2. **check(mid) 设计**：和数列分段完全一样。贪心扫描，当前段和超过 mid 时新起一段。

3. **二分搜索**：在 [left, right] 中寻找最小的可行上限。

**题解代码**：

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 100005;
long long expense[MAXN];
int n, m;

bool check(long long limit) {
    int months = 1;          // 当前已划分的月份
    long long sum = 0;       // 当前月的开销
    
    for (int i = 0; i < n; i++) {
        if (expense[i] > limit) return false;  // 单天开销就超过上限
        if (sum + expense[i] > limit) {
            months++;                          // 新开一个月
            sum = expense[i];
        } else {
            sum += expense[i];
        }
    }
    return months <= m;
}

int main() {
    cin >> n >> m;
    long long left = 0, right = 0;
    for (int i = 0; i < n; i++) {
        cin >> expense[i];
        left = max(left, expense[i]);   // 下界：最大单天开销
        right += expense[i];            // 上界：总开销
    }
    
    long long ans = right;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;
            right = mid - 1;     // 可行，尝试更小的上限
        } else {
            left = mid + 1;      // 不可行，需要更大的上限
        }
    }
    cout << ans << endl;
    return 0;
}
```

        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    cout << ans << endl;
    return 0;
}

#### 挑战题1 参考代码

#include <iostream>
using namespace std;

const int MAXN = 50005;
int L, n, M;
int rock[MAXN];

bool check(int d) {
    int removed = 0;
    int prev = 0;
    for (int i = 1; i <= n; i++) {
        if (rock[i] - prev < d) {
            removed++;
            if (removed > M) return false;
        } else {
            prev = rock[i];
        }
    }
    if (L - prev < d) removed++;
    return removed <= M;
}

int main() {
    cin >> L >> n >> M;
    for (int i = 1; i <= n; i++) cin >> rock[i];

    int left = 1, right = L, ans = 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    cout << ans << endl;
    return 0;
}

## 📝 本课小结

本节课我们系统学习了“二分答案 + 贪心验证”这一重要的算法模式。这是信息学竞赛中处理“最小化最大值”类问题的标准解法，也是二分查找从“查找数值”到“查找答案”的进阶应用。

核心要点回顾：

1. **二分答案的本质**：在答案的可能区间上进行二分搜索，每次通过 `check()` 函数判断当前猜测的答案是否可行，从而逐步缩小范围，最终锁定最优解。

2. **适用条件**：答案必须具有**单调性**——存在一个明确的分界点，分界点一侧全部可行、另一侧全部不可行。同时，`check()` 函数必须能高效实现（通常是 O(n)）。

3. **check() 函数的设计**：对于数列分段类问题，采用**贪心策略**从左到右扫描序列，尽可能填满当前段，统计所需的最少段数，判断是否在允许的段数之内。

4. **数列分段与月度开销**：这两个问题是二分答案的经典入门题，它们的解法几乎完全一致，体现了“同一个算法模式解决不同场景问题”的思维方式。
