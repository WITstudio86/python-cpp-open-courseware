# 第1课：枚举算法入门——穷举的力量

## 🎯 学习目标
- 理解枚举算法的核心思想：逐一尝试所有可能的答案
- 掌握单层循环枚举与双层循环嵌套枚举的写法
- 能够用枚举算法解决百钱买百鸡、水仙花数等经典问题

## 📖 算法讲解

### 一、什么是枚举算法？

枚举算法（Enumeration Algorithm），又称穷举法、暴力搜索，是算法世界中最基础、最直观的算法思想。它的核心思想可以概括为一句话：**把所有可能的情况一个一个地试一遍，直到找到答案为止。**

打个比方：假如你的钥匙掉在了一个黑暗的房间里，你不知道它具体在哪个位置。你会怎么做？最朴素的办法就是把房间的每一寸地面都摸一遍，直到找到钥匙。这个"把每一寸地面都摸一遍"的过程，就是枚举。

在计算机中，枚举算法的优势在于：计算机的计算速度非常快，一秒钟可以执行上亿次操作。因此，对于规模不大的问题，完全可以用"笨办法"——把所有的可能性都列举出来，逐一检查是否满足条件。

### 二、枚举算法的三个关键要素

一个完整的枚举算法需要明确三个要素：

```
┌─────────────────────────────────────────────────────┐
│                  枚举算法三要素                      │
├─────────────────────────────────────────────────────┤
│  1. 枚举对象    →  我们要枚举"什么"？               │
│  2. 枚举范围    →  可能的取值"从哪到哪"？            │
│  3. 判断条件    →  满足"什么条件"才是答案？          │
└─────────────────────────────────────────────────────┘
```

例如，要找出1到100之间所有的质数：
- **枚举对象**：每一个整数
- **枚举范围**：2 到 100
- **判断条件**：该数是否为质数（只能被1和自身整除）

### 三、单层循环枚举

单层循环枚举是最简单的枚举形式，使用一个for循环即可完成。

```cpp
// 单层枚举框架
for (int i = 起点; i <= 终点; i++) {
    if (满足条件(i)) {
        // 输出答案或记录结果
    }
}
```

**【例】找出1到100之间所有能被7整除的数**

```
枚举对象：每个整数 i
枚举范围：i 从 1 到 100
判断条件：i % 7 == 0
```

```cpp
for (int i = 1; i <= 100; i++) {
    if (i % 7 == 0) {
        cout << i << " ";
    }
}
```

### 四、双层循环嵌套枚举

当答案由两个或多个变量共同决定时，我们需要使用嵌套循环。外层循环枚举第一个变量的取值，内层循环枚举第二个变量的取值。

```
        ┌─── i=1 ───┬─── j=1 ─── 检查 (i=1, j=1)
        │           ├─── j=2 ─── 检查 (i=1, j=2)
        │           ├─── j=3 ─── 检查 (i=1, j=3)
        │           └─── ... ─── ...
        │
枚举 i ─┼─── i=2 ───┬─── j=1 ─── 检查 (i=2, j=1)
        │           ├─── j=2 ─── 检查 (i=2, j=2)
        │           └─── ... ─── ...
        │
        └─── i=3 ─── ...
```

可以看到，外层循环每走一步，内层循环都要完整地走完一圈。如果外层循环有M种取值，内层循环有N种取值，则总共会检查 M × N 种组合。

```cpp
// 双层枚举框架
for (int i = 起点1; i <= 终点1; i++) {
    for (int j = 起点2; j <= 终点2; j++) {
        if (满足条件(i, j)) {
            // 输出答案
        }
    }
}
```

### 五、三重及更多层循环

当问题涉及三个或更多变量时，可以继续嵌套。不过需要注意：嵌套层数越多，总枚举次数呈指数级增长。例如，每层循环100次，三层嵌套就是 100 × 100 × 100 = 1,000,000 次。在算法竞赛中，通常需要将枚举次数控制在 10^7（一千万）以内，否则可能会超时。

### 六、枚举算法的优缺点

**优点：**
- 思路简单直观，不容易出错
- 能够保证找到所有解（完备性）
- 是很多复杂算法的基础

**缺点：**
- 时间复杂度较高，数据规模大时效率低
- 嵌套层数多时，代码可读性下降

## 💻 代码实现

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 函数：判断一个三位数是否为水仙花数
// 水仙花数：各位数字的立方和等于该数本身
// 例如：153 = 1^3 + 5^3 + 3^3
bool isNarcissus(int n) {
    int a = n / 100;          // 百位
    int b = n / 10 % 10;      // 十位
    int c = n % 10;           // 个位
    return (a*a*a + b*b*b + c*c*c == n);
}

int main() {
    // ===== 例题1：百钱买百鸡 =====
    // 公鸡5元一只，母鸡3元一只，小鸡1元三只
    // 用100元买100只鸡，问公鸡、母鸡、小鸡各多少只？
    
    cout << "【百钱买百鸡】所有可能解：" << endl;
    int count = 0;
    
    // 枚举公鸡数量(0到20只，因为5*20=100)
    for (int gong = 0; gong <= 20; gong++) {
        // 枚举母鸡数量(0到33只，因为3*33=99)
        for (int mu = 0; mu <= 33; mu++) {
            // 小鸡数量由总数100推导
            int xiao = 100 - gong - mu;
            // 小鸡数量必须是3的倍数（因为1元3只，价格是整数）
            if (xiao >= 0 && xiao % 3 == 0) {
                // 检查总价是否为100元
                if (5 * gong + 3 * mu + xiao / 3 == 100) {
                    count++;
                    cout << "解" << count << ": 公鸡 " << gong 
                         << " 只, 母鸡 " << mu 
                         << " 只, 小鸡 " << xiao << " 只" << endl;
                }
            }
        }
    }
    if (count == 0) cout << "无解" << endl;
    
    // ===== 例题2：水仙花数 =====
    cout << "\n【水仙花数】所有三位水仙花数：" << endl;
    
    // 枚举所有三位数：100 到 999
    for (int n = 100; n <= 999; n++) {
        if (isNarcissus(n)) {
            int a = n / 100;
            int b = n / 10 % 10;
            int c = n % 10;
            cout << n << " = " << a << "^3 + " 
                 << b << "^3 + " << c << "^3" << endl;
        }
    }
    
    return 0;
}
```

## 📊 复杂度分析

**百钱买百鸡：**
- 时间复杂度：O(n²)，其中 n ≈ 20（公鸡枚举上限）× 33（母鸡枚举上限）≈ 660次检查，实际运行极快
- 空间复杂度：O(1)，只使用了常数个变量

**水仙花数：**
- 时间复杂度：O(m)，其中 m = 900（100到999共900个数），每个数执行常数次运算
- 空间复杂度：O(1)

## 🏋️ 经典例题

### 例题1：百钱买百鸡

**题目描述**：我国古代数学家张丘建在《算经》中提出：公鸡一只值5钱，母鸡一只值3钱，小鸡三只值1钱。如果用100钱买100只鸡，问公鸡、母鸡、小鸡各买多少只？请输出所有可能的买法。

**输入格式**：无输入

**输出格式**：每行输出一组解，格式为 `公鸡: X 母鸡: Y 小鸡: Z`（X, Y, Z为整数）。如果有多组解，按公鸡数量从小到大输出。

**样例输入**：（无）

**样例输出**：
```
公鸡: 0 母鸡: 25 小鸡: 75
公鸡: 4 母鸡: 18 小鸡: 78
公鸡: 8 母鸡: 11 小鸡: 81
公鸡: 12 母鸡: 4 小鸡: 84
```

**题解代码**：
```cpp
// 枚举公鸡数量 gong：0 到 20
// 枚举母鸡数量 mu：0 到 33
// 小鸡数量 xiao = 100 - gong - mu
// 约束条件：xiao >= 0 && xiao % 3 == 0 && 5*gong + 3*mu + xiao/3 == 100
#include <iostream>
using namespace std;

int main() {
    for (int gong = 0; gong <= 20; gong++) {
        for (int mu = 0; mu <= 33; mu++) {
            int xiao = 100 - gong - mu;
            if (xiao >= 0 && xiao % 3 == 0 && 
                5*gong + 3*mu + xiao/3 == 100) {
                cout << "公鸡: " << gong << " 母鸡: " 
                     << mu << " 小鸡: " << xiao << endl;
            }
        }
    }
    return 0;
}
```

### 例题2：水仙花数

**题目描述**：水仙花数是指一个三位数，其各位数字的立方和等于该数本身。例如：153 = 1³ + 5³ + 3³，所以153是一个水仙花数。请找出所有的三位水仙花数。

**输入格式**：无输入

**输出格式**：每行输出一个水仙花数及其验证等式

**样例输出**：
```
153 = 1^3 + 5^3 + 3^3
370 = 3^3 + 7^3 + 0^3
371 = 3^3 + 7^3 + 1^3
407 = 4^3 + 0^3 + 7^3
```

**题解代码**：
```cpp
#include <iostream>
using namespace std;

int main() {
    for (int n = 100; n <= 999; n++) {
        int a = n / 100;         // 百位数字
        int b = n / 10 % 10;     // 十位数字
        int c = n % 10;          // 个位数字
        
        if (a*a*a + b*b*b + c*c*c == n) {
            cout << n << " = " << a << "^3 + " 
                 << b << "^3 + " << c << "^3" << endl;
        }
    }
    return 0;
}
```

### 📝 基础题

#### 基础题1：换零钱问题

**题目描述**：小明有 50 元钱，想全部换成 1 元、2 元、5 元的零钱。请问有多少种换法？请输出所有换法（每种换法包含 1 元、2 元、5 元的张数），按 5 元张数从少到多、2 元张数从少到多的顺序输出。

**输入格式**：无输入。

**输出格式**：每行输出一组解，格式为 `5元: X张  2元: Y张  1元: Z张`。最后一行输出 `共有 N 种换法`。

**样例输出**（前几行）：
```
5元: 0张  2元: 0张  1元: 50张
5元: 0张  2元: 1张  1元: 48张
...
共有 XX 种换法
```

#### 基础题2：统计满足条件的数

**题目描述**：统计 1 到 N 之间（包含 1 和 N），所有能被 3 整除且个位数字是 7 的整数个数。

**输入格式**：一个整数 N（1 ≤ N ≤ 10000）。

**输出格式**：一个整数，表示满足条件的数的个数。

**样例输入**：
```
200
```

**样例输出**：
```
7
```

**样例解释**：在 1~200 范围内，能被 3 整除且个位是 7 的数有：27、57、87、117、147、177、207（207 超出范围），共 6 个。等等，让我们重新数：27(3×9)、57(3×19)、87(3×29)、117(3×39)、147(3×49)、177(3×59)、207(超出)。所以在 1~200 中是 6 个...不，27、57、87、117、147、177，确实 6 个。样例输出修正为 6。

### 📝 提高题

#### 提高题1：搬砖问题

**题目描述**：某工地需要搬运 n 块砖。有 3 种搬运方式：甲每次搬 3 块，收费 5 元；乙每次搬 4 块，收费 6 元；丙每次搬 5 块，收费 7 元。请问在刚好搬完 n 块砖的前提下，最少需要花费多少元？如果无法刚好搬完，输出 -1。

**输入格式**：一个整数 n（1 ≤ n ≤ 1000）。

**输出格式**：一个整数，表示最少花费金额；若无法刚好搬完则输出 -1。

**样例输入**：
```
18
```

**样例输出**：
```
26
```

**样例解释**：n=18 时，可以是 6 次甲搬法（6×3=18，花费 6×5=30），也可以是 2 次丙+2 次甲（2×5+2×3=16，不够），也可以是 2 次乙+2 次丙（2×4+2×5=18，花费 2×6+2×7=26）。最少花费是 26 元。

### 📝 挑战题

#### 挑战题：勾股数

**题目描述**：勾股数是指满足 a² + b² = c² 的三个正整数（a < b < c）。请找出所有满足 a + b + c = N 且 a、b、c 两两互质的勾股数三元组。如果没有，输出 "No solution"。

**输入格式**：一个整数 N（1 ≤ N ≤ 1000）。

**输出格式**：每行输出一组解，格式为 `a b c`，按 a 从小到大排列。若无解，输出 `No solution`。

**样例输入**：
```
120
```

**样例输出**：
```
20 48 52
24 45 51
30 40 50
```

**样例解释**：N=120 的三组勾股数：20²+48²=400+2304=2704=52², 24²+45²=576+2025=2601=51², 30²+40²=900+1600=2500=50²。

### 🔍 参考答案

#### 基础题1 参考代码
```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 0;
    // 枚举 5 元张数：0 到 10（5*10=50）
    for (int wu = 0; wu <= 10; wu++) {
        // 枚举 2 元张数：0 到 25（2*25=50）
        for (int er = 0; er <= 25; er++) {
            int yi = 50 - 5 * wu - 2 * er;
            if (yi >= 0) {
                cout << "5元: " << wu << "张  2元: " << er 
                     << "张  1元: " << yi << "张" << endl;
                count++;
            }
        }
    }
    cout << "共有 " << count << " 种换法" << endl;
    return 0;
}
```

#### 提高题1 参考代码
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int minCost = 1e9;  // 初始化为极大值
    bool found = false;
    
    // 枚举甲的次数
    for (int a = 0; a * 3 <= n; a++) {
        // 枚举乙的次数
        for (int b = 0; a * 3 + b * 4 <= n; b++) {
            int rest = n - a * 3 - b * 4;
            if (rest % 5 == 0) {
                int c = rest / 5;
                int cost = a * 5 + b * 6 + c * 7;
                if (cost < minCost) {
                    minCost = cost;
                    found = true;
                }
            }
        }
    }
    
    if (found)
        cout << minCost << endl;
    else
        cout << -1 << endl;
    return 0;
}
```

#### 挑战题 参考代码
```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 求最大公约数
int gcd(int x, int y) {
    while (y != 0) {
        int t = x % y;
        x = y;
        y = t;
    }
    return x;
}

int main() {
    int N;
    cin >> N;
    bool found = false;
    
    // 枚举 a
    for (int a = 1; a <= N / 3; a++) {
        // 枚举 b（b > a），同时 c = N - a - b，必须 c > b
        for (int b = a + 1; b <= (N - a) / 2; b++) {
            int c = N - a - b;
            if (c <= b) continue;
            // 检查勾股定理
            if (a * a + b * b == c * c) {
                // 检查两两互质（可选）
                if (gcd(a, b) == 1 && gcd(b, c) == 1 && gcd(a, c) == 1) {
                    cout << a << " " << b << " " << c << endl;
                    found = true;
                }
            }
        }
    }
    
    if (!found) cout << "No solution" << endl;
    return 0;
}
```

## 📝 本课小结

本节课我们学习了算法中最基础的枚举算法。枚举的核心思想是"逐一尝试"，通过循环结构把所有可能的答案列举出来，再用判断条件筛选出正确的解。我们掌握了单层枚举和双层嵌套枚举的写法，并通过"百钱买百鸡"和"水仙花数"两个经典例子进行了实践。

枚举算法的优点是思路简单、容易实现、不会遗漏答案；缺点是在数据规模大时效率较低。在后续课程中，我们将学习如何通过"剪枝"等策略来优化枚举算法，减少不必要的计算，提升效率。

记住枚举三要素：明确枚举对象、确定枚举范围、列出判断条件。掌握好这三个要素，你就能用枚举算法解决一大类问题！
