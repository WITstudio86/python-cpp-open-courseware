# 第12课：快速排序——分治的威力

## 🎯 学习目标
- 理解快速排序的分治思想：选取基准元素，将数组分为左右两部分，递归排序
- 掌握快速排序的基准选择和分区（partition）操作
- 能够利用快速排序解决第k大的数等问题

## 📖 算法讲解

### 一、从"班长排队"说起——分治思想的引入

同学们，假设体育课上老师让大家按身高从小到大排成一排。如果全班40个人乱糟糟地站在一起，该怎么快速排好呢？

一个聪明的办法是：先找一个同学（比如站在中间的同学）作为"基准"，让比他矮的都站到左边，比他高的都站到右边。然后对左边和右边的同学分别再用同样的方法排队。这就是**快速排序**的核心思想——**分治**。

分治，就是"分而治之"：把一个复杂的大问题，拆分成若干个相似的子问题，分别解决后再合并。快速排序不需要"合并"这一步，因为分区操作本身就已经让数组变得有序了。

快速排序由英国计算机科学家 Tony Hoare 在1960年提出，至今仍是最常用的排序算法之一。大多数编程语言的内置排序（如C++的sort函数）都采用了快速排序或其变种。

### 二、快速排序的三个关键步骤

快速排序可以用以下三步来概括：

```
快速排序(数组 arr, 左边界 left, 右边界 right):
    ┌─ 1. 选择基准 ──────────────────────────────────┐
    │   从 arr[left...right] 中选择一个元素作为 pivot │
    │   常见策略：选第一个、选最后一个、选中间、随机选 │
    └────────────────────────────────────────────────┘
    ┌─ 2. 分区操作 ──────────────────────────────────┐
    │   重新排列数组，使得：                           │
    │   · 所有 < pivot 的元素都在 pivot 左边          │
    │   · 所有 ≥ pivot 的元素都在 pivot 右边          │
    │   并返回 pivot 最终所在的位置 pivotIndex         │
    └────────────────────────────────────────────────┘
    ┌─ 3. 递归排序 ──────────────────────────────────┐
    │   对左半部分：快速排序(arr, left, pivotIndex-1) │
    │   对右半部分：快速排序(arr, pivotIndex+1, right)│
    └────────────────────────────────────────────────┘
```

### 三、基准元素的选择策略

基准元素（pivot）的选择对快速排序的性能有着至关重要的影响。选择不当可能导致算法退化。

1. **固定位置法**（最简单）
   - 总是选择第一个元素或最后一个元素作为基准
   - 优点：实现简单
   - 缺点：当数组已经有序（或逆序）时，性能退化到 O(n²)

2. **随机选择法**
   - 在 [left, right] 范围内随机选一个元素作为基准
   - 优点：期望性能稳定，不易被"卡"数据
   - 缺点：需要生成随机数，略有额外开销

3. **三数取中法**（推荐）
   - 取 arr[left]、arr[mid]、arr[right] 三个数的中间值作为基准
   - 优点：能有效避免最坏情况，实践中表现很好
   - 缺点：实现稍微复杂一点

对于算法竞赛和日常使用来说，**随机选择**和三数取中法都是不错的选择。C++ STL 的 sort 函数内部采用了类似三数取中的优化策略。

### 四、分区操作的详细过程——"双指针法"

分区（Partition）是快速排序中最核心、也最容易出错的操作。我们以"选择最右边元素作为基准"为例，使用双指针法来演示。

**算法思路**：维护两个指针 i 和 j。
- 指针 i 指向"小于基准的区域的最后一个元素"
- 指针 j 用于遍历当前未处理的元素

```
分区前的数组状态：
索引:  0   1   2   3   4   5   6   7
数值: [38, 27, 43, 3,  9,  82, 55, 10]
                                    ↑
                                  pivot=10 (选最右边)

初始化: i = left - 1 = -1 (小于10的区域初始为空)

第1步: j=0, arr[0]=38
  38 >= 10, 不交换
  数组不变: [38, 27, 43, 3, 9, 82, 55, 10]
              ↑                       ↑
              i=-1                   pivot

第2步: j=1, arr[1]=27
  27 >= 10, 不交换
  数组不变: [38, 27, 43, 3, 9, 82, 55, 10]

第3步: j=2, arr[2]=43
  43 >= 10, 不交换

第4步: j=3, arr[3]=3
  3 < 10, i++, swap(arr[0], arr[3])
  交换后: [3, 27, 43, 38, 9, 82, 55, 10]
           ↑          ↑
           i=0        j=3

第5步: j=4, arr[4]=9
  9 < 10, i++, swap(arr[1], arr[4])
  交换后: [3, 9, 43, 38, 27, 82, 55, 10]
              ↑           ↑
              i=1         j=4

第6步: j=5, arr[5]=82
  82 >= 10, 不交换

第7步: j=6, arr[6]=55
  55 >= 10, 不交换

遍历结束! 将 pivot 放到正确位置:
  i++, swap(arr[2], arr[7])
  最终: [3, 9, 10, 38, 27, 82, 55, 43]
              ↑
         pivotIndex=2
         
结果: pivot=10 左边的 [3,9] 都 < 10
             pivot=10 右边的 [38,27,82,55,43] 都 >= 10
```

分区操作完成后，pivot 元素已经处于它最终排好序的位置。接下来只需要对左右两个子数组分别递归调用快速排序即可。

### 五、递归调用过程

```
                    快速排序(0, 7)
                        │
          分区: pivot=10 放到位置 2
                        │
        ┌───────────────┴───────────────┐
        │                               │
  快速排序(0, 1)                  快速排序(3, 7)
        │                               │
  分区: pivot=9                  分区: pivot=43
  放到位置 1                      放到位置 7
        │                               │
   ┌────┴────┐              ┌───────────┴───────────┐
   │         │              │                       │
快速排序  快速排序      快速排序(3, 5)          快速排序(8, 7)
 (0,0)    (2,1)              │                   (递归终止)
   │       (递归终止)   分区: pivot=38              ↑
   │                     放到位置 5               right<left
 (递归终止)                    │
                           ┌──┴──┐
                           │     │
                      快速排序  快速排序
                       (3,4)    (6,5)
                           │    (递归终止)
                      分区: pivot=27
                      放到位置 3
                           │
                       ┌──┴──┐
                       │     │
                  快速排序  快速排序
                   (3,2)    (4,4)
               (递归终止)  (递归终止)

最终排序结果: [3, 9, 10, 27, 38, 43, 55, 82]
```

可以看到，递归的终止条件是 `left >= right`（即子数组只有一个元素或为空）。

### 七、与之前排序算法的对比

| 特性 | 冒泡排序 | 选择排序 | 插入排序 | **快速排序** |
|------|---------|---------|---------|------------|
| 时间复杂度(平均) | O(n²) | O(n²) | O(n²) | **O(n log n)** |
| 时间复杂度(最好) | O(n) | O(n²) | O(n) | O(n log n) |
| 时间复杂度(最坏) | O(n²) | O(n²) | O(n²) | **O(n²)** |
| 空间复杂度 | O(1) | O(1) | O(1) | **O(log n)** |
| 稳定性 | 稳定 | 不稳定 | 稳定 | **不稳定** |
| 核心思想 | 相邻交换 | 选最小 | 插入有序区 | **分治+分区** |

可以看到，快速排序在大多数情况下远快于之前学的三种 O(n²) 排序。但当数据规模很大时，快速排序的最坏情况 O(n²) 需要警惕，好在这种情况可以通过随机化或三数取中来避免。

### 八、快速排序的"亲戚"——快速选择算法

快速选择算法（QuickSelect）是快速排序分区思想的巧妙应用。问题描述：给定一个无序数组，找出其中第 k 大的元素。

常规思路：先排序，再取第 k 个 → O(n log n)
快速选择思路：利用分区操作，每次可以确定 pivot 的最终位置。
- 如果 pivot 的位置恰好就是第 k 大 → 直接返回
- 如果 pivot 的位置偏小 → 只在右半部分继续找
- 如果 pivot 的位置偏大 → 只在左半部分继续找

这样每次只需要递归一边，平均时间复杂度为 O(n)。这是处理"第k大/小"类问题的利器！

## 💻 代码实现

```cpp
#include <iostream>
#include <algorithm>
#include <cstdlib>
#include <ctime>
using namespace std;

const int MAXN = 100005;
int arr[MAXN];

// ================================================================
// partition 函数：分区操作
// 功能：选取基准元素 pivot，将数组 arr[left...right] 分为两部分
//       · 左边部分的所有元素 <= pivot
//       · 右边部分的所有元素 >= pivot
// 返回值：pivot 最终所在的下标位置
// ================================================================
int partition(int arr[], int left, int right) {
    // 随机选取基准元素，避免最坏情况
    int randomIndex = left + rand() % (right - left + 1);
    swap(arr[randomIndex], arr[right]); // 将基准换到最右边
    
    int pivot = arr[right];      // 基准元素
    int i = left - 1;            // i 指向"小于基准区域"的最后一个元素
    
    // 遍历整个区间（除了最右边的基准）
    for (int j = left; j < right; j++) {
        // 如果当前元素小于基准
        if (arr[j] < pivot) {
            i++;                     // 扩大"小于基准区域"
            swap(arr[i], arr[j]);    // 将小元素交换到前面
        }
    }
    
    // 将基准元素放到正确的位置（i+1 就是基准应该在的位置）
    swap(arr[i + 1], arr[right]);
    return i + 1;  // 返回基准的最终位置
}

// ================================================================
// quickSort 函数：递归快速排序
// 参数：
//   arr   - 待排序数组
//   left  - 当前排序区间的左边界（包含）
//   right - 当前排序区间的右边界（包含）
// ================================================================
void quickSort(int arr[], int left, int right) {
    if (left >= right) return;  // 递归终止：区间只有一个元素或为空
    
    // 分区：将数组分为左右两部分
    int pivotIndex = partition(arr, left, right);
    
    // 递归排序左半部分
    quickSort(arr, left, pivotIndex - 1);
    // 递归排序右半部分
    quickSort(arr, pivotIndex + 1, right);
}

// ================================================================
// quickSelect 函数：快速选择算法
// 功能：在 arr[left...right] 中找到排名第 k 的元素（从小到大数，k从1开始）
//       例如：k=1 找最小元素，k=n 找最大元素
// 时间复杂度：平均 O(n)，最坏 O(n²)（可通过随机基准避免）
// ================================================================
int quickSelect(int arr[], int left, int right, int k) {
    if (left == right) return arr[left];  // 只有一个元素
    
    // 分区操作
    int pivotIndex = partition(arr, left, right);
    
    // pivot 在数组中从小到大的排名（从1开始计数）
    int rank = pivotIndex - left + 1;
    
    if (rank == k) {
        // 刚好找到第 k 小的元素
        return arr[pivotIndex];
    } else if (rank > k) {
        // 第 k 小的元素在左半部分
        return quickSelect(arr, left, pivotIndex - 1, k);
    } else {
        // 第 k 小的元素在右半部分
        // 注意：在右半部分中，排名需要减去左半部分和 pivot 的数量
        return quickSelect(arr, pivotIndex + 1, right, k - rank);
    }
}

int main() {
    srand(time(0));  // 初始化随机数种子
    
    // 示例：对数组进行快速排序
    int a[] = {38, 27, 43, 3, 9, 82, 55, 10};
    int n = sizeof(a) / sizeof(a[0]);
    
    cout << "排序前: ";
    for (int i = 0; i < n; i++) cout << a[i] << " ";
    cout << endl;
    
    quickSort(a, 0, n - 1);
    
    cout << "排序后: ";
    for (int i = 0; i < n; i++) cout << a[i] << " ";
    cout << endl;
    
    return 0;
}
```

## 📊 复杂度分析

**时间复杂度：**
- **最好情况**：O(n log n) —— 每次分区都将数组均匀地分为两半。递归深度为 log₂n，每层需要 O(n) 的分区操作。
- **最坏情况**：O(n²) —— 每次分区都极度不均衡（比如数组已经有序且选择第一个元素作为基准）。递归深度变为 n，总操作量 ≈ n+(n-1)+(n-2)+...+1 = n(n+1)/2 = O(n²)。
- **平均情况**：O(n log n) —— 在随机化基准或"三数取中"策略下，期望递归深度为 O(log n)。

**空间复杂度：**
- O(log n) —— 主要来自递归调用栈的深度。在最坏情况下（没有随机化），递归深度可达 O(n)。但通过"先递归较小的子数组"等尾递归优化技巧可以进一步控制栈深度。

**稳定性：**
- 快速排序是**不稳定**的排序算法。因为在分区过程中，相同元素的相对位置可能会被交换打乱。

## 🏋️ 经典例题

### 例题1：第k大的数

**题目描述**：给定一个长度为 n 的整数序列，请找出其中第 k 大的数（k 从 1 开始计数）。例如，k=1 表示最大的数，k=2 表示第二大的数，以此类推。

**输入格式**：
第一行两个整数 n 和 k（1 ≤ k ≤ n ≤ 100000）。
第二行 n 个整数，每个整数在 int 范围内，以空格分隔。

**输出格式**：一个整数，表示第 k 大的数。

**样例输入**：
```
6 2
3 1 4 1 5 9
```

**样例输出**：
```
5
```

**样例解释**：6个数排序为 [1, 1, 3, 4, 5, 9]（从小到大），第2大的数是 5。

**算法分析**：
- 如果先排序再取第 k 大：O(n log n)，对于 n=100000 来说可以接受。
- 但使用**快速选择算法**可以做到平均 O(n) 的时间复杂度，更优。

**核心思路**：
1. 要找"第k大"的数，等价于找"第 (n - k + 1) 小"的数。
2. 利用 partition 函数进行分区，分区后 pivot 有一个确定的排名 rank。
3. 如果 rank == (n - k + 1)，找到答案。
4. 如果 rank > (n - k + 1)，答案在左半部分。
5. 如果 rank < (n - k + 1)，答案在右半部分。

**题解代码**：
```cpp
#include <iostream>
#include <algorithm>
#include <cstdlib>
#include <ctime>
using namespace std;

const int MAXN = 100005;
int arr[MAXN];

int partition(int arr[], int left, int right) {
    int randomIndex = left + rand() % (right - left + 1);
    swap(arr[randomIndex], arr[right]);
    int pivot = arr[right];
    int i = left - 1;
    for (int j = left; j < right; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[right]);
    return i + 1;
}

// 快速选择：在 arr[left...right] 中找第 k 小（k从1开始）
int quickSelect(int arr[], int left, int right, int k) {
    if (left == right) return arr[left];
    int pivotIndex = partition(arr, left, right);
    int rank = pivotIndex - left + 1;  // pivot 在当前区间的排名
    if (rank == k)
        return arr[pivotIndex];
    else if (rank > k)
        return quickSelect(arr, left, pivotIndex - 1, k);
    else
        return quickSelect(arr, pivotIndex + 1, right, k - rank);
}

int main() {
    srand(time(0));
    int n, k;
    cin >> n >> k;
    for (int i = 0; i < n; i++) cin >> arr[i];
    
    // 第k大 = 第 (n - k + 1) 小
    int ans = quickSelect(arr, 0, n - 1, n - k + 1);
    cout << ans << endl;
    
    return 0;
}
```

### 例题2：快速排序实现

**题目描述**：使用快速排序算法对 n 个整数从小到大排序。

**输入格式**：第一行一个整数 n（1 ≤ n ≤ 100000）。第二行 n 个整数，以空格分隔。

**输出格式**：一行 n 个整数，为从小到大排序后的结果，以空格分隔。

**样例输入**：
```
5
38 27 43 3 9
```

**样例输出**：
```
3 9 27 38 43
```

**题解代码**：
```cpp
#include <iostream>
#include <algorithm>
#include <cstdlib>
#include <ctime>
using namespace std;

const int MAXN = 100005;
int arr[MAXN];

int partition(int arr[], int left, int right) {
    int randomIndex = left + rand() % (right - left + 1);
    swap(arr[randomIndex], arr[right]);
    int pivot = arr[right];
    int i = left - 1;
    for (int j = left; j < right; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[right]);
    return i + 1;
}

void quickSort(int arr[], int left, int right) {
    if (left >= right) return;
    int pivotIndex = partition(arr, left, right);
    quickSort(arr, left, pivotIndex - 1);
    quickSort(arr, pivotIndex + 1, right);
}

int main() {
    srand(time(0));
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> arr[i];
    
    quickSort(arr, 0, n - 1);
    
    for (int i = 0; i < n; i++) {
        cout << arr[i];
        if (i < n - 1) cout << " ";
    }
    cout << endl;
    return 0;
}
```

**题目描述**：给定一个只包含 0、1、2 三种数字的数组，请只用一次遍历和常数额外空间，将数组按 0、1、2 的顺序排好（即所有 0 在前面，所有 1 在中间，所有 2 在后面）。

### 📝 挑战题

#### 挑战题：中位数查找

**题目描述**：给定一个长度为 n 的整数序列，请使用快速选择算法在 O(n) 时间内找到中位数。如果 n 为奇数，中位数是排序后第 (n+1)/2 个数；如果 n 为偶数，输出排序后中间两个数的平均值（向下取整）。

**输入格式**：
第一行一个整数 n（1 ≤ n ≤ 100000，n 为奇数）。
第二行 n 个整数，空格隔开。

**输出格式**：一个整数，表示中位数。

**样例输入**：
```
7
3 1 4 1 5 9 2
```

**样例输出**：
```
3
```

**样例解释**：数组排序后为 [1, 1, 2, 3, 4, 5, 9]，中位数是第 4 个数 = 3。

### 🔍 参考答案

#### 基础题1 参考代码
```cpp
#include <iostream>
#include <algorithm>
#include <cstdlib>
#include <ctime>
using namespace std;

const int MAXN = 100005;
int arr[MAXN];

int partition(int arr[], int left, int right) {
    int randomIndex = left + rand() % (right - left + 1);
    swap(arr[randomIndex], arr[right]);
    int pivot = arr[right];
    int i = left - 1;
    for (int j = left; j < right; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[right]);
    return i + 1;
}

void quickSort(int arr[], int left, int right) {
    if (left >= right) return;
    int pivotIndex = partition(arr, left, right);
    quickSort(arr, left, pivotIndex - 1);
    quickSort(arr, pivotIndex + 1, right);
}

int main() {
    srand(time(0));
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> arr[i];
    
    quickSort(arr, 0, n - 1);
    
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << arr[i];
    }
    cout << endl;
    return 0;
}
```

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

void dutchFlagSort(int arr[], int n) {
    int low = 0, mid = 0, high = n - 1;
    
    while (mid <= high) {
        if (arr[mid] == 0) {
            swap(arr[low], arr[mid]);
            low++;
            mid++;
        } else if (arr[mid] == 1) {
            mid++;
        } else {  // arr[mid] == 2
            swap(arr[mid], arr[high]);
            high--;
        }
    }
}
```

## 📝 本课小结

本节课我们学习了算法领域最经典的排序算法之一——快速排序。它的核心思想是**分治**：通过选取基准元素，将数组分为左右两部分，然后递归地对两部分分别排序。分区操作（partition）是快速排序最关键的一步，使用双指针扫描，时间复杂度为 O(n)。

我们还学习了**基准选择策略**：随机选基准可以避免最坏情况，三数取中也是常用的优化方法。基于分区操作，我们推导出了**快速选择算法**，它可以平均 O(n) 时间找到数组中第 k 大/小的元素，这是一种非常高效的"部分排序"技巧。

快速排序的平均时间复杂度为 O(n log n)，是目前实践中使用最广泛的排序算法。掌握快速排序，不仅能够排序，更重要的是理解"分治"这一极其重要的算法思想，它将贯穿我们后续的许多课程。
