## 📖算法讲解

### 什么是分治算法？

分治算法（Divide and Conquer）是一种极其重要的算法设计思想。它的名字非常形象——「分而治之」，意思是：面对一个难以直接解决的大问题，我们把它拆分成若干个规模较小的、结构相同的子问题，分别解决这些子问题，最后将子问题的解合并成原问题的解。

这个思想其实在我们的日常生活中随处可见。比如班长要统计全班同学的考试成绩：他先把任务分给四个小组长（分），每个小组长统计自己组员的成绩（治），最后班长把四个小组的数据汇总到一起（合）。这就是典型的分治策略。

### 分治三步曲

任何一个分治算法都可以清晰地划分为三个阶段：

**第一步：分（Divide）**
将原问题划分为若干个规模较小的子问题，子问题的形式与原问题完全相同，只是规模变小了。这一步的关键是找到合适的划分方式，使得子问题之间尽量独立，且规模大致均衡。

**第二步：治（Conquer）**
递归地求解各个子问题。如果子问题的规模已经足够小（比如只有一个元素），那么就直接给出答案，不再继续划分。这个「足够小」的临界条件，就是我们递归的**边界条件（Base Case）**。

**第三步：合（Combine）**
将各个子问题的解组合成原问题的解。这一步是分治算法中最需要技巧的部分——有些问题的合并不需要额外工作（比如二分查找），有些问题的合并却非常复杂。

```
原始问题（规模为 n）
      │
      ▼
┌─────────────────┐
│  分(Divide)     │  拆分成 k 个规模较小的子问题
└────────┬────────┘
         │
    ┌────┼────┬──────┐
    ▼    ▼    ▼      ▼
  子问题1 子问题2 ... 子问题k
    │    │         │
    ▼    ▼         ▼
┌─────────────────┐
│  治(Conquer)    │  递归求解每个子问题
└────────┬────────┘
         │
    ┌────┼────┬──────┐
    ▼    ▼    ▼      ▼
  解1   解2  ...    解k
    │    │         │
    └────┼─────────┘
         ▼
┌─────────────────┐
│  合(Combine)    │  将子问题的解合并为原问题的解
└────────┬────────┘
         │
         ▼
    原问题的最终答案
```

### 经典例子：归并排序

归并排序是理解分治算法的最佳入门例子。让我们来看看它是如何体现分治三步曲的。

**任务**：将数组 `[38, 27, 43, 3, 9, 82, 10]` 从小到大排序。

**分治过程**（递归树形图）：

```
                    [38, 27, 43, 3, 9, 82, 10]
                    /                         \
                   /           分(Divide)       \
                  /                             \
        [38, 27, 43, 3]                  [9, 82, 10]
         /          \                     /         \
        /            \                   /           \
   [38, 27]        [43, 3]           [9, 82]        [10]
    /    \          /    \            /    \           |
   /      \        /      \          /      \          |
[38]    [27]    [43]    [3]       [9]    [82]       [10]
  \      /        \      /          \      /           |
   \    /          \    /            \    /            |
  治+合 [27,38]   治+合 [3,43]     治+合 [9,82]    治 [10]
         \          /                   \             /
          \        /                     \           /
           \      /       合(Combine)     \         /
        [3, 27, 38, 43]               [9, 10, 82]
                    \                      /
                     \       合(Combine)   /
                      \                  /
                  [3, 9, 10, 27, 38, 43, 82]
```

**分步解析：**

1. **分（Divide）**：每次将数组从中间一分为二，直到每个子数组只剩一个元素。单个元素的数组天然有序——这就是我们的递归边界。

2. **治（Conquer）**：当数组长度为1时，它已经是有序的，直接返回即可。对于长度大于1的数组，继续递归拆分。

3. **合（Combine）**：将两个已经排好序的子数组合并成一个大的有序数组。这是归并排序的核心——**合并两个有序数组**。我们使用双指针法：两个指针分别指向两个子数组的开头，每次比较两个指针所指元素的大小，把较小的那个放入结果数组，然后移动对应的指针。重复这个过程直到其中一个数组为空，再把另一个数组剩余的元素直接追加到结果后面。

### 分治与递归的关系

很多同学会问：「分治和递归是一回事吗？」

答案是：**分治是一种算法设计思想，递归是实现分治的常用手段，但两者并不等价。**

- 分治描述了「如何设计算法」：把大问题拆成小问题，求解后合并。
- 递归描述了「如何编写代码」：一个函数调用自身来解决规模更小的同类问题。

绝大多数分治算法都使用递归来实现，因为子问题的结构与原问题完全一致，递归能够自然地表达这种「自相似」的结构。但反过来，递归并不一定都是分治——比如用递归求阶乘，它没有「合」的过程，所以不是分治算法；而分治也不一定非要用递归，也可以用栈来模拟递归过程（迭代实现）。

判断一个递归算法是不是分治算法，关键看它是否具备完整的三步：**分、治、合**。

```
递归与分治关系：

  递归（Recursion）              分治（Divide and Conquer）
  ┌──────────────┐              ┌────────────────────┐
  │ 函数调用自身  │              │ 分→治→合 设计范式   │
  │ 一种编程技巧  │              │ 一种算法设计思想    │
  └──────┬───────┘              └─────────┬──────────┘
         │                                │
         └──────── 有交集 ────────────────┘
                        │
              ┌─────────┴──────────┐
              │  分治 + 递归       │
              │  例如：归并排序    │
              │  最大子段和        │
              │  快速排序          │
              └────────────────────┘
```

### 分治算法的适用条件

并不是所有问题都适合用分治来解决。一个适合分治的问题通常满足以下条件：

1. **问题可以分解**：原问题能够被拆分成若干个规模较小的同类子问题。
2. **子问题独立**：各个子问题之间不包含公共的子子问题（如果有大量重叠子问题，用动态规划更合适）。
3. **分解后可以合并**：子问题的解能够有效地合并成原问题的解。
4. **规模足够小时可直接求解**：存在一个容易求解的边界条件。

## 💻代码实现

我们先来实现分治法的经典应用：**最大子段和问题**。

> **问题描述**：给定一个长度为 `n` 的整数数组（可能包含负数），找出其中连续子数组的最大和。
>
> 例如：`[-2, 1, -3, 4, -1, 2, 1, -5, 4]` 的最大子段和为 `6`（对应子数组 `[4, -1, 2, 1]`）。

**分治思路**：将数组从中间分成左右两半，最大子段和只有三种可能的位置：
- 完全在左半部分
- 完全在右半部分
- 跨越中点（一部分在左边，一部分在右边）

前两种情况递归求解，第三种情况需要单独计算：从中点向左扫描找最大后缀和，从中点向右扫描找最大前缀和，两者相加即可。

```cpp
#include <iostream>
#include <algorithm>
#include <climits>
using namespace std;

// 计算跨越中点的最大子段和
// arr: 原数组, left: 左边界, mid: 中点, right: 右边界
int crossMaxSum(int arr[], int left, int mid, int right) {
    // 从中点向左扫描，找最大后缀和
    int leftSum = INT_MIN;  // 初始化为最小整数
    int sum = 0;
    for (int i = mid; i >= left; i--) {
        sum += arr[i];
        if (sum > leftSum) {
            leftSum = sum;  // 更新左侧最大和
        }
    }

    // 从中点+1向右扫描，找最大前缀和
    int rightSum = INT_MIN;
    sum = 0;
    for (int i = mid + 1; i <= right; i++) {
        sum += arr[i];
        if (sum > rightSum) {
            rightSum = sum;  // 更新右侧最大和
        }
    }

    // 跨越中点的最大子段和 = 左侧最大后缀 + 右侧最大前缀
    return leftSum + rightSum;
}

// 分治法求解最大子段和
// arr: 数组, left: 左边界索引, right: 右边界索引
int maxSubArray(int arr[], int left, int right) {
    // 边界条件：只有一个元素，直接返回该元素
    if (left == right) {
        return arr[left];
    }

    // 第一步：分(Divide) —— 将数组从中间分成两半
    int mid = left + (right - left) / 2;  // 防止整数溢出

    // 第二步：治(Conquer) —— 递归求解左右两部分
    int leftMax  = maxSubArray(arr, left, mid);       // 左半部分的最大子段和
    int rightMax = maxSubArray(arr, mid + 1, right);  // 右半部分的最大子段和

    // 计算跨越中点的最大子段和
    int crossMax = crossMaxSum(arr, left, mid, right);

    // 第三步：合(Combine) —— 取三者的最大值作为最终结果
    return max({leftMax, rightMax, crossMax});
}

int main() {
    int arr[] = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    int n = sizeof(arr) / sizeof(arr[0]);

    int result = maxSubArray(arr, 0, n - 1);
    cout << "最大子段和为: " << result << endl;  // 输出：6

    return 0;
}
```

**代码解读：**

- `maxSubArray` 函数体现了完整的「分→治→合」流程：先分（计算`mid`并递归），再治（递归求解子问题），最后合（取三个值的最大值）。
- `crossMaxSum` 函数专门处理跨越中点的情况，从中点向两侧扫描，时间复杂度为 `O(n)`。
- 递归边界是 `left == right`，此时子数组只有一个元素，最大子段和就是它本身。

## 📊复杂度分析

分治算法的时间复杂度通常可以用**递推关系式**来分析。

设 `T(n)` 表示解决规模为 `n` 的问题所需的时间。

**对于最大子段和的分治解法：**

1. **分（Divide）**：计算中点 `mid`，花费 `O(1)` 时间。
2. **治（Conquer）**：递归求解两个规模为 `n/2` 的子问题，花费 `2T(n/2)` 时间。
3. **合（Combine）**：计算跨越中点的最大子段和需要扫描整个数组，花费 `O(n)` 时间。

由此得到递推式：

```
T(n) = 2T(n/2) + O(n)，其中 T(1) = O(1)
```

这是一个典型的递推关系，我们可以用**主定理（Master Theorem）**来求解：

- 形式：`T(n) = aT(n/b) + f(n)`
- 这里 `a = 2`（两个子问题），`b = 2`（每个子问题规模减半），`f(n) = O(n)`
- 计算 `log_b(a) = log_2(2) = 1`
- 比较 `f(n) = O(n^1)` 与 `n^{log_b(a)} = n^1`：两者同阶
- 根据主定理情形二：`T(n) = O(n log n)`

**展开验证：**

```
第0层：              T(n) = 2^0 · T(n/2^0) + 0 · O(n)
                     ↘
第1层：    T(n/2)               T(n/2)    合并代价 O(n)
                     ↘
第2层： T(n/4) T(n/4)       T(n/4) T(n/4)    合并代价 O(n) + O(n) = O(n)
                     ↘
...                  每一层的合并总代价都是 O(n)
                     ↘
第k层：2^k 个规模为 n/2^k 的问题，合并代价 O(n)
```

递归树共有 `log_2(n)` 层（层层对半直到规模为1），每一层的合并总代价为 `O(n)`。

**总时间复杂度 = 层数 × 每层代价 = O(log n) × O(n) = O(n log n)**。

相比之下，暴力枚举所有子段需要 `O(n^3)` 或优化后的 `O(n^2)`，而动态规划可以达到 `O(n)`。分治法虽然不如动态规划快，但它在处理「可加性」问题上具有很好的通用性，是学习分治思想的绝佳例题。

## 🏋️经典例题

### 例题1：最大子段和（分治法）

**题目描述**

给定一个包含 `n` 个整数的数组 `a[1..n]`（整数可能为负数），请你找出该数组中**连续非空子数组**的最大和，并输出这个最大和。

**输入格式**

- 第一行：一个整数 `n`（`1 ≤ n ≤ 10^5`），表示数组长度。
- 第二行：`n` 个整数，表示数组中的元素，每个整数的绝对值不超过 `10^4`。

**输出格式**

- 一个整数，表示最大子段和。

**样例输入1**

```
9
-2 1 -3 4 -1 2 1 -5 4
```

**样例输出1**

```
6
```

**样例解释**

和最大的连续子数组是 `[4, -1, 2, 1]`，其和为 `4 + (-1) + 2 + 1 = 6`。

**样例输入2**

```
5
-1 -2 -3 -4 -5
```

**样例输出2**

```
-1
```

**样例解释**

当所有元素均为负数时，最大子段和就是数组中最大的那个单元素。这里 `-1` 是所有元素中最大的。

**解题思路**

1. 采用分治法，将数组从中间 `mid` 分为左右两半。
2. 最大子段和一定属于以下三种情况之一：
   - **完全在左半部分**：`maxSubArray(left, mid)`
   - **完全在右半部分**：`maxSubArray(mid+1, right)`
   - **跨越中点**：从中点向左求最大后缀和 + 从中点向右求最大前缀和
3. 三种情况取最大值返回。
4. 递归边界：区间长度为1时直接返回该元素。

**参考代码**

```cpp
#include <iostream>
#include <algorithm>
#include <climits>
using namespace std;

const int MAXN = 100005;
int a[MAXN];

// 计算跨越中点的最大子段和
long long crossMax(int left, int mid, int right) {
    // 左侧最大后缀和
    long long leftSum = LLONG_MIN;
    long long sum = 0;
    for (int i = mid; i >= left; i--) {
        sum += a[i];
        if (sum > leftSum) leftSum = sum;
    }

    // 右侧最大前缀和
    long long rightSum = LLONG_MIN;
    sum = 0;
    for (int i = mid + 1; i <= right; i++) {
        sum += a[i];
        if (sum > rightSum) rightSum = sum;
    }

    return leftSum + rightSum;
}

// 分治法求 [left, right] 的最大子段和
long long divide(int left, int right) {
    if (left == right) {
        return a[left];  // 边界：只有一个元素
    }

    int mid = left + (right - left) / 2;

    // 分治三选一
    long long ansLeft  = divide(left, mid);       // 情况1：完全在左边
    long long ansRight = divide(mid + 1, right);  // 情况2：完全在右边
    long long ansCross = crossMax(left, mid, right); // 情况3：跨越中点

    return max({ansLeft, ansRight, ansCross});
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    cout << divide(0, n - 1) << endl;
    return 0;
}
```

### 例题2：棋盘覆盖问题

**题目描述**

在一个 `2^k × 2^k`（k ≥ 0）个方格组成的棋盘中，**恰有一个方格**是残缺的（标记为 `-1`）。现在要用 L 形骨牌覆盖棋盘上除了残缺方格之外的所有方格。L 形骨牌由三个方格组成，形状如下：

```
  ██      ██      ██      ██
  ██        ██  ██          ██
  (旋转0°) (旋转90°) (旋转180°) (旋转270°)
```

每种旋转角度的 L 形骨牌都可以使用，且数量不限。任何两个骨牌不能重叠覆盖。

请你输出一个覆盖方案，用不同的正整数编号表示不同的 L 形骨牌（每个骨牌占三个格子，这三个格子用相同的编号标记）。

**输入格式**

- 第一行：整数 `k`（`0 ≤ k ≤ 6`），棋盘大小为 `2^k × 2^k`。
- 第二行：两个整数 `dr dc`，表示残缺方格的行号和列号（均从 0 开始计数）。

**输出格式**

输出一个 `2^k × 2^k` 的矩阵，其中：
- 残缺方格用 `-1` 表示。
- 其余方格用正整数编号表示覆盖它的 L 形骨牌的编号（同一骨牌的三个格子编号相同）。

**样例输入**

```
2
1 1
```

**样例输出**

```
 3  3  4  4
 3 -1  2  4
 5  2  2  6
 5  5  6  6
```

**解题思路**

这是一个经典的分治问题，核心思路是「用一个 L 形骨牌铺在棋盘中心，把一个大棋盘变成四个子棋盘，每个子棋盘恰好有一个残缺方格」。

**分治策略：**

1. **分（Divide）**：将 `2^k × 2^k` 棋盘平分为四个 `2^(k-1) × 2^(k-1)` 的子棋盘。四个子棋盘的交界处是棋盘的正中心。
2. **构造残缺格**：残缺方格只存在于其中一个子棋盘（称为「原本就残缺的象限」）。另外三个子棋盘还没有残缺格——我们在它们交汇的中心位置各取一个格子，用一个 L 形骨牌覆盖这三个格子，使它们分别成为各自子棋盘的「人造残缺格」。这样，四个子棋盘都恰好各有一个残缺格！
3. **治（Conquer）**：递归地对四个子棋盘分别求解。
4. **边界条件**：当 `k = 0` 即棋盘大小为 `1 × 1` 时，唯一的那个格子就是残缺格，不需要覆盖任何骨牌。

**图解（以 k=2，残缺格在 (1,1) 为例）：**

```
原始棋盘 (4×4)                  拆分后覆盖中心L形骨牌
┌───────────┐                  ┌───────────┐
│ ·  ·  ·  ·│                  │ 3 ·  3  · 4│
│ ·  ✗  ·  ·│    ──→           │ ·  ✗  ·  4│
│ ·  ·  ·  ·│                  │ 5 ·  2  · │
│ ·  ·  ·  ·│                  │ 5  5  ·  ·│
└───────────┘                  └───────────┘
  ✗ = 残缺格

四个子棋盘各有一个残缺格后，递归求解即可。
```

**参考代码**

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

const int MAXN = 128;  // 2^6 = 64, 留足余量
int board[MAXN][MAXN];  // 棋盘
int tileNumber = 0;     // 骨牌编号计数器

/**
 * 分治法覆盖棋盘
 * @param tr  当前子棋盘左上角的行号
 * @param tc  当前子棋盘左上角的列号
 * @param dr  当前子棋盘内残缺格的行号
 * @param dc  当前子棋盘内残缺格的列号
 * @param size 当前子棋盘的边长 (2^k)
 */
void chessBoard(int tr, int tc, int dr, int dc, int size) {
    // 边界条件：棋盘大小为 1×1，只有一个格子即残缺格，无需覆盖
    if (size == 1) return;

    int t = ++tileNumber;   // 当前使用的骨牌编号
    int half = size / 2;    // 子棋盘边长的一半

    // ──── 处理左上角子棋盘 ────
    // 判断残缺格是否在左上角子棋盘中
    if (dr < tr + half && dc < tc + half) {
        // 残缺格在左上角，直接递归求解
        chessBoard(tr, tc, dr, dc, half);
    } else {
        // 残缺格不在左上角 → 用人造残缺格填补左上角子棋盘的右下角
        board[tr + half - 1][tc + half - 1] = t;
        // 这个新填的格子就是左上角子棋盘的人造残缺格
        chessBoard(tr, tc, tr + half - 1, tc + half - 1, half);
    }

    // ──── 处理右上角子棋盘 ────
    if (dr < tr + half && dc >= tc + half) {
        // 残缺格在右上角
        chessBoard(tr, tc + half, dr, dc, half);
    } else {
        // 人造残缺格：右上角子棋盘的左下角
        board[tr + half - 1][tc + half] = t;
        chessBoard(tr, tc + half, tr + half - 1, tc + half, half);
    }

    // ──── 处理左下角子棋盘 ────
    if (dr >= tr + half && dc < tc + half) {
        // 残缺格在左下角
        chessBoard(tr + half, tc, dr, dc, half);
    } else {
        // 人造残缺格：左下角子棋盘的右上角
        board[tr + half][tc + half - 1] = t;
        chessBoard(tr + half, tc, tr + half - 1, tc + half - 1, half);
    }

    // ──── 处理右下角子棋盘 ────
    if (dr >= tr + half && dc >= tc + half) {
        // 残缺格在右下角
        chessBoard(tr + half, tc + half, dr, dc, half);
    } else {
        // 人造残缺格：右下角子棋盘的左上角
        board[tr + half][tc + half] = t;
        chessBoard(tr + half, tc + half, tr + half, tc + half, half);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int k, dr, dc;
    cin >> k >> dr >> dc;

    int size = (int)pow(2, k);  // 棋盘边长 = 2^k

    // 标记残缺方格
    board[dr][dc] = -1;

    // 调用分治函数
    chessBoard(0, 0, dr, dc, size);

    // 输出棋盘
    for (int i = 0; i < size; i++) {
        for (int j = 0; j < size; j++) {
            cout << setw(3) << board[i][j];
        }
        cout << endl;
    }

    return 0;
}
```

**代码解读：**

- `chessBoard(tr, tc, dr, dc, size)` 函数负责覆盖以 `(tr, tc)` 为左上角、边长为 `size` 的子棋盘，其中 `(dr, dc)` 是该子棋盘内唯一的残缺格位置。
- 对于四个象限，分别判断残缺格是否在本象限内：
  - **在**：直接递归求解该象限。
  - **不在**：在靠近棋盘中心的位置放置骨牌的一格作为人造残缺格，然后递归求解。
- 由于用一个编号 `t` 的三块分别放在了三个不同象限的角落，恰好形成一个 L 形，覆盖了棋盘中心区域的三个格子。这三个格子就是连接四个子棋盘的「桥梁」。
- 时间复杂度：`T(2^k) = 4T(2^(k-1)) + O(1)`，即 `T(n) = 4T(n/4) + O(1)`，解得 `T(n) = O(n^2) = O(4^k)`。这是最优的，因为总共需要覆盖 `(4^k - 1) / 3` 个骨牌，必须输出这么多格子。

```cpp
#include <iostream>
#include <algorithm>
#include <climits>
using namespace std;

// 练习1：分治法求最大子段和
int crossMaxSum(int arr[], int left, int mid, int right) {
    int leftSum = INT_MIN, sum = 0;
    for (int i = mid; i >= left; i--) {
        sum += arr[i];
        if (sum > leftSum) leftSum = sum;
    }
    int rightSum = INT_MIN; sum = 0;
    for (int i = mid + 1; i <= right; i++) {
        sum += arr[i];
        if (sum > rightSum) rightSum = sum;
    }
    return leftSum + rightSum;
}

int maxSubArray(int arr[], int left, int right) {
    if (left == right) return arr[left];
    int mid = left + (right - left) / 2;
    int leftMax = maxSubArray(arr, left, mid);
    int rightMax = maxSubArray(arr, mid + 1, right);
    int crossMax = crossMaxSum(arr, left, mid, right);
    return max({leftMax, rightMax, crossMax});
}

// 练习2：分治法求最大值
int findMax(int arr[], int left, int right) {
    if (left == right) return arr[left];
    int mid = (left + right) / 2;
    int leftMax = findMax(arr, left, mid);
    int rightMax = findMax(arr, mid + 1, right);
    return max(leftMax, rightMax);
}

// 练习3 & 4：归并排序 + 逆序对统计
long long mergeCount(int arr[], int temp[], int left, int mid, int right) {
    int i = left, j = mid + 1, k = left;
    long long invCount = 0;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
            invCount += (mid - i + 1);  // arr[i..mid] 都大于 arr[j]
        }
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    for (i = left; i <= right; i++) arr[i] = temp[i];
    return invCount;
}

long long mergeSort(int arr[], int temp[], int left, int right) {
    long long invCount = 0;
    if (left < right) {
        int mid = (left + right) / 2;
        invCount += mergeSort(arr, temp, left, mid);
        invCount += mergeSort(arr, temp, mid + 1, right);
        invCount += mergeCount(arr, temp, left, mid, right);
    }
    return invCount;
}

int main() {
    int arr[] = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    int n = sizeof(arr) / sizeof(arr[0]);
    cout << "最大子段和: " << maxSubArray(arr, 0, n - 1) << endl;  // 6
    cout << "最大值: " << findMax(arr, 0, n - 1) << endl;           // 4
    return 0;
}
```

## 📝本课小结

分治算法是算法设计中最重要的思想之一，它的核心可以概括为三个字：**分、治、合**。面对复杂问题时，我们不必试图一次性解决它，而是将它拆解为若干个结构相同、规模更小的子问题逐个击破，最后把结果拼接起来。

在本课中，我们通过归并排序直观地感受了分治的全过程：反复将数组对半分直到只剩一个元素（分），此时天然有序（治），再用双指针法把两个有序数组合并成一个（合）。随后我们用最大子段和问题展示了分治法的另一种典型应用——最大子段和要么在左边、要么在右边、要么跨越中点，三种情况取最优即可。最后，棋盘覆盖问题让我们看到分治法的更多巧思：用一个 L 形骨牌在棋盘中心「制造」出三个残缺格，将一个大问题巧妙地转化为四个结构完全相同的子问题。

需要记住的是，分治算法虽然强大，但有它的适用条件：子问题必须相互独立，且合并子问题的解必须是高效的。当你面对的问题能够自然地「对半分」且子问题与原问题同构时，不妨想一想——**能不能用分治法来解决？** 这往往是你解题的突破口。

在下一课中，我们将继续学习分治思想的另一个经典算法——快速排序，以及它与归并排序的异同，敬请期待！
