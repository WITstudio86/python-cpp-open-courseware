# 第37课：背包问题（一）——01背包

## 🎯 学习目标

1. 理解01背包问题的定义和约束条件：n个物品、容量限制、每个物品只能选一次的核心模型
2. 掌握二维DP状态定义与转移方程，能够手推DP表完成逐步计算
3. 掌握一维优化的滚动数组解法，理解反向遍历的必要性；能够解决采药问题、装箱问题等实际应用

---

## 📖 算法讲解

### 问题描述

给定 n 个物品，第 i 个物品的重量为 w[i]，价值为 v[i]。有一个容量为 C 的背包，每个物品最多只能装入一次（要么取，要么不取，因此称为"01"背包）。问：在不超过背包容量的前提下，能够获得的最大总价值是多少？

这是最经典的动态规划入门问题之一。核心约束是**每个物品只有 0 或 1 两种选择**——要么拿走，要么留下。

### 状态定义

设 `dp[i][j]` 表示：考虑前 i 个物品，在背包容量为 j 的限制下，能够获得的最大总价值。

### 状态转移方程

对于第 i 个物品（重量为 w[i]，价值为 v[i]），当前容量为 j：

- **不选第 i 个物品**：`dp[i][j] = dp[i-1][j]`（直接继承前 i-1 个物品的结果）
- **选第 i 个物品**：（前提是 j ≥ w[i]）`dp[i][j] = dp[i-1][j-w[i]] + v[i]`（用 j-w[i] 容量考虑前 i-1 个物品，然后加上本物品价值）

综合起来：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])    (j ≥ w[i])
dp[i][j] = dp[i-1][j]                                  (j < w[i])
```

### DP 表示例

假设有 3 个物品：(w=2, v=3)、(w=3, v=4)、(w=4, v=5)，背包容量 C=8。

DP 表（行 = 物品编号，列 = 容量）：

```
        j=0  j=1  j=2  j=3  j=4  j=5  j=6  j=7  j=8
        ---------------------------------------------
初始化  |  0    0    0    0    0    0    0    0    0
物品1   |  0    0    3    3    3    3    3    3    3
物品2   |  0    0    3    4    4    7    7    7    7
物品3   |  0    0    3    4    5    7    8    9    9
```

- 物品1（w=2, v=3）：容量 ≥ 2 时，dp = 3
- 物品2（w=3, v=4）：容量=5 时，max(dp[1][5]=3, dp[1][2]+4=7) = 7
- 物品3（w=4, v=5）：容量=8 时，max(dp[2][8]=7, dp[2][4]+5=9) = 9

最终答案：dp[3][8] = 9。（三个物品全选重量为 2+3+4=9 > 8 不可行，最优为选物品 2+3，重量=7，价值=4+5=9）

### 一维优化（滚动数组）

二维 DP 中，dp[i][j] 只依赖于 dp[i-1][...]（上一行），因此可以压缩为一维：

```
dp[j] = max(dp[j], dp[j - w[i]] + v[i])
```

**关键细节——反向遍历**：j 必须从 C 递减到 w[i]，而不是从 w[i] 递增到 C。

为什么必须反向？
- 正序遍历时，dp[j-w[i]] 可能已经被当前物品更新过，相当于在当前轮又用了一次同一个物品，这就退化成了"完全背包"（每个物品无限次取用）。
- 反向遍历确保 dp[j-w[i]] 始终是上一轮（i-1）的结果，不会包含第 i 个物品的贡献，从而保证每个物品最多只被选中一次。

## 💻 代码实现

### 二维DP版本

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 105;    // 最大物品数
const int MAXC = 1005;   // 最大容量

int w[MAXN], v[MAXN];
int dp[MAXN][MAXC];

int knapsack2D(int n, int C) {
    // 初始化：0个物品时价值为0
    for (int j = 0; j <= C; j++) dp[0][j] = 0;

    // 逐个考虑物品
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= C; j++) {
            // 不选第 i 个物品
            dp[i][j] = dp[i-1][j];
            // 如果容量够，考虑选第 i 个物品
            if (j >= w[i])
                dp[i][j] = max(dp[i][j], dp[i-1][j-w[i]] + v[i]);
        }
    }
    return dp[n][C];
}
```

### 一维优化版本（推荐）

```cpp
int knapsack1D(int n, int C) {
    int dp[MAXC] = {0};  // 一维数组，初始化为0

    for (int i = 1; i <= n; i++) {
        // 关键：j 反向遍历！
        for (int j = C; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[C];
}
```

## 📊 复杂度分析

| 版本 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 二维DP | O(n × C) | O(n × C) |
| 一维优化 | O(n × C) | O(C) |

- n 为物品数量，C 为背包容量
- 时间复杂度 O(n × C) 是伪多项式时间——当 C 很大时（如 10^9），这种 DP 不可行
- 空间优化到 O(C) 后，即使 C 达到 10^5 级别也能轻松应对

## 🏋️ 经典例题

### 例题1：采药问题

**题目描述**

山洞里有 n 株草药，每株草药需要 t[i] 时间采摘，价值为 v[i]。总共只有 T 时间，问能够采到的最大总价值。（每株草药只能采一次）

**输入格式**
- 第一行：两个整数 T 和 n（T ≤ 1000，n ≤ 100）
- 接下来 n 行：每行两个整数 t 和 v（采摘时间和价值）

**输出格式**
- 一个整数，表示最大总价值

**样例输入**
```
70 3
71 100
69 1
1 2
```

**样例输出**
```
3
```

**样例解释**：总时间 70。第一株需 71（超容，跳过），第二株需 69（价值 1），第三株需 1（价值 2）。只能选第二株或第三株。选第二株（69,1）后剩余 1 时间不够选第三株（需1）但总价值=1；选第三株（1,2）后剩余 69 时间够但只剩第一株（71，超容）= 价值 2。最优为 1 + 2 = 3？等等——选第二株（69 时间, 价值 1），剩余 1 时间，只能选第三株（1 时间, 价值 2），总价值 = 1 + 2 = 3，总时间 = 70 ≤ 70，正确！

**题解**

这是最标准的 01 背包模板题。直接把采摘时间当作物品重量，草药价值当作物品价值，容量 = T，跑一遍一维 DP 即可。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int dp[1005];

int main() {
    int T, n;
    cin >> T >> n;

    for (int i = 1; i <= n; i++) {
        int t, val;
        cin >> t >> val;
        // 反向遍历，0-1背包
        for (int j = T; j >= t; j--) {
            dp[j] = max(dp[j], dp[j - t] + val);
        }
    }

    cout << dp[T] << endl;
    return 0;
}
```

### 例题2：装箱问题

**题目描述**

有一个箱子容量为 V（正整数，V ≤ 20000），有 n 个物品（n ≤ 30），第 i 个物品体积为 v[i]。要求从 n 个物品中选出若干件装入箱子，使箱子的剩余空间最小。

**输入格式**
- 第一行：一个整数 V（箱子容量）
- 第二行：一个整数 n（物品个数）
- 第三行：n 个整数（各物品体积）

**输出格式**
- 一个整数，表示最小剩余空间

**样例输入**
```
24
6
8 3 12 7 9 7
```

**样例输出**
```
0
```

**题解**

这是一个巧妙的转化题。设物品的体积既是"重量"又是"价值"，即 v[i] = w[i] = val[i]。那么 `dp[j]` 表示容量为 j 时能装的最大体积。最终答案 = V - dp[V]（总容量减去最大能装的体积，就是最小剩余空间）。

为什么这样可以？因为每装入一个物品，消耗的体积（重量）和获得的价值（体积）相等。最大化装进去的总体积，自然就是最小化剩余空间。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int dp[20005];

int main() {
    int V, n;
    cin >> V >> n;

    for (int i = 1; i <= n; i++) {
        int vol;
        cin >> vol;
        // 体积 = 重量 = 价值
        for (int j = V; j >= vol; j--) {
            dp[j] = max(dp[j], dp[j - vol] + vol);
        }
    }

    cout << V - dp[V] << endl;  // 剩余空间最小
    return 0;
}
```

#### 练习4参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int dp[505][505];  // dp[j][k]: 重量j、体积k时的最大价值

int main() {
    int N, C, H;
    cin >> N >> C >> H;

    for (int i = 1; i <= N; i++) {
        int w, d, v;
        cin >> w >> d >> v;
        // 双重反向遍历（二维01背包）
        for (int j = C; j >= w; j--)
            for (int k = H; k >= d; k--)
                dp[j][k] = max(dp[j][k], dp[j - w][k - d] + v);
    }

    cout << dp[C][H] << endl;
    return 0;
}
```

## 📝 本课小结

01 背包是动态规划最经典的入门模型，核心在于每个物品的"选或不选"二择。二维 DP 清晰直观，便于理解状态转移过程；一维优化通过反向遍历保证每个物品最多被选一次，将空间复杂度从 O(n×C) 降至 O(C)。掌握 01 背包后，很多约束选择问题都可以转化为此模型求解，如采药问题的"时间=重量，价值=价值"、装箱问题的"体积=重量=价值"，核心是找到合适的映射关系。
