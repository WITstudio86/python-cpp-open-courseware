## 📖 算法讲解

### 一、什么是回溯算法？

回溯算法（Backtracking Algorithm）是一种**系统地搜索所有可能解**的算法。它的核心思想可以用一句话概括：**像走迷宫一样，遇到死路就退回来，换一条路再走。**

想象一下你在一个巨大的迷宫里寻找出口。你手里有一支粉笔，每走到一个岔路口，你就做一个标记，然后选一条路走下去。如果你发现这条路走不通（比如走到了死胡同），你就沿着粉笔标记退回到上一个岔路口，擦掉标记，再走另一条没试过的路。这个过程反复进行，直到找到出口——或者试完了所有可能的路，确认没有出口。

在计算机算法中，回溯法就是把这个"走迷宫"的过程系统化、程序化。它通过**递归**的方式，在问题的**解空间树**中进行深度优先搜索。

### 二、回溯法的通用框架——四步法

回溯法有一个非常清晰的四步框架，几乎所有回溯问题都可以套用：

```
步骤                   说明                       代码体现
────────────────────────────────────────────────────────
① 选择    在当前状态下，有哪些可行的选择？    枚举所有候选值
② 试探    做出一个选择，进入新的状态           记录选择，更新状态
③ 递归    在新状态下继续搜索                   递归调用自身
④ 撤销    退回当前选择，恢复原状态               回溯（擦除标记）
```

用代码来表达，回溯法的通用模板如下：

```cpp
void backtrack(参数) {
    if (满足终止条件) {
        记录/输出解;
        return;
    }
    
    for (遍历所有候选选择) {
        if (选择合法) {
            做选择;           // ② 试探
            backtrack(新参数); // ③ 递归
            撤销选择;         // ④ 撤销（回溯）
        }
    }
}
```

**为什么需要"撤销选择"这一步？** 这是回溯法区别于普通递归的关键。撤销选择保证了在探索完一条路径后，状态能够**恢复**到决策之前的样子，这样才能正确地尝试下一条分支。就像走迷宫时，你必须擦掉走过的粉笔印，才能在新的岔路口重新开始。

### 三、解空间树——理解搜索过程的可视化工具

回溯法的搜索过程可以用一棵**解空间树**来直观表示。树的每个节点代表问题求解过程中的一个"状态"，从根节点到叶子节点的一条完整路径就对应一个候选解。

以**4皇后问题**（在4×4棋盘上放置4个皇后，互不攻击）为例，它的解空间树如下：

```
                        根节点（空棋盘）
                              │
               ┌──────────────┼──────────────┬──────────────┐
             第1行=0         第1行=1         第1行=2         第1行=3
           [Q···]           [·Q··]           [··Q·]           [···Q]
              │                │                │                │
        ┌─────┼─────┐    ┌─────┼─────┐    ┌─────┼─────┐    ┌─────┼─────┐
     第2行=2 第2行=3  第2行=3  ...    第2行=0 第2行=3  第2行=0 第2行=1
      [Q···] [Q···]   [·Q··]          [··Q·] [··Q·]   [···Q] [···Q]
      [··Q·] [···Q]   [···Q]          [Q···] [···Q]   [Q···] [·Q··]
         │      │         │               │      │         │      │
      第3行   第3行    ✗ 剪枝          第3行   第3行   第3行   第3行
      =1      =2       冲突              =2      =1      =2      =0
     失败    失败                       失败    失败    失败    失败

图例：Q = 皇后  · = 空格  ✗ = 因冲突被剪枝
```

从这棵树可以看出，4皇后问题只有 **2 个解**（对称的）。整个搜索过程尝试了很多分支，但大部分都因为冲突被提前放弃（剪枝）。

对于8皇后问题，解空间树将更加庞大，但回溯法通过剪枝大大减少了实际搜索的节点数。8皇后问题总共有 **92 个解**。

### 四、剪枝优化——提前排除不可能的分支

**剪枝（Pruning）** 是回溯法中最关键的优化手段。它的思想是：**如果在搜索的某个步骤发现当前选择不可能导出合法解，就立即放弃这个分支，不再继续深入搜索。**

剪枝可以大幅减少搜索空间，是把"暴力搜索"变成"高效搜索"的关键。

```
没有剪枝的回溯搜索：              有剪枝的回溯搜索：
       o                                o
     / | \                            / | \
    o  o  o                          o  o  ✗  ← 发现冲突，立即剪掉
   /|\  ...                        /|\
  o o o                           o o o
    ...
（探索所有分支，包括不可能的）    （只探索可能有解的分支）
```

在八皇后问题中，剪枝体现在：当我们放置一个新皇后时，**立即检查**它是否与之前放置的皇后冲突。如果冲突，就直接跳过这种放置方式，不继续往下一行递归。这个"立即检查"避免了大量无用的深层搜索。

### 五、回溯法与深度优先搜索（DFS）的关系

回溯法本质上是对解空间树进行**深度优先搜索（DFS）**。每递归深入一层，就相当于在解空间树中向下走了一步；每回溯一层，就相当于在树中向上退回父节点，然后访问下一个兄弟节点。

两者的细微区别在于：DFS是一种通用的图遍历算法，而回溯法特指在DFS过程中加入了**状态维护和撤销**（做选择→递归→撤销选择）的搜索策略。

### 六、回溯法的应用场景

回溯法适合解决以下类型的问题：

| 问题类型 | 例子 | 特点 |
|---------|------|------|
| 排列问题 | 全排列、N皇后 | 顺序敏感，每个元素用一次 |
| 组合问题 | 组合输出、子集生成 | 顺序不敏感，在候选集中选择 |
| 棋盘问题 | 八皇后、数独求解 | 二维约束条件 |
| 图搜索问题 | 迷宫寻路、哈密顿路径 | 路径相关 |
| 划分问题 | 划分数、集合划分 | 将元素分配到不同组 |

## 💻 代码实现

### 八皇后问题的回溯解法

```cpp
#include <iostream>
#include <cmath>
using namespace std;

const int N = 8;           // 棋盘大小
int pos[N];                // pos[i] = 第i行皇后放在第几列
int solutionCount = 0;     // 解的数量

// 检查在第row行第col列放置皇后是否与前面的皇后冲突
bool isSafe(int row, int col) {
    for (int i = 0; i < row; i++) {
        // 检查同列冲突
        if (pos[i] == col) return false;
        // 检查对角线冲突（行差 = 列差）
        if (abs(row - i) == abs(col - pos[i])) return false;
    }
    return true;
}

// 回溯搜索：尝试在第row行放置皇后
void solve(int row) {
    if (row == N) {                    // 终止条件：8行都放完了
        solutionCount++;               // 找到一个解
        if (solutionCount == 1) {      // 输出第一个解
            cout << "第一个解的棋盘布局：" << endl;
            for (int i = 0; i < N; i++) {
                for (int j = 0; j < N; j++) {
                    cout << (pos[i] == j ? "Q " : ". ");
                }
                cout << endl;
            }
        }
        return;
    }
    
    for (int col = 0; col < N; col++) {   // ① 选择：枚举列
        if (isSafe(row, col)) {           // 剪枝：只探索合法位置
            pos[row] = col;               // ② 试探：放皇后
            solve(row + 1);               // ③ 递归：处理下一行
            // ④ 撤销：pos[row]会被下一轮循环覆盖，无需显式清除
        }
    }
}
```

## 📊 复杂度分析

八皇后问题的时间复杂度分析：

**没有剪枝的情况：** 如果暴力尝试所有可能的放置方式，第一个皇后有8种放法，第二个有7种（不能同列），第三个有6种……总共 8! = 40320 种排列。再加上对角线约束检查，最坏情况下每个排列都要检查。

**有剪枝的情况（实际回溯法）：** 由于每次放置皇后时立即检查列冲突和对角线冲突，大量不可能的排列被提前排除。实际回溯法在8皇后问题中仅探索约 **2057 个节点**，远小于 8! = 40320。

更一般的 N 皇后问题：
- 时间复杂度：**O(N!)** 在最坏情况下，但实际因为剪枝远小于此值
- 空间复杂度：**O(N)**，只需要存储每行皇后的列位置和递归调用栈

回溯法的时间复杂度通常难以精确表达，因为它依赖于剪枝效果和问题本身的结构。常见的表示方式是"指数级"或"阶乘级"，但实际常数因子因问题而异。

## 🏋️ 经典例题

### 例题1：八皇后问题

**题目描述**：在 8×8 的国际象棋棋盘上放置 8 个皇后，使得任意两个皇后都不能在同一行、同一列或同一对角线上。问共有多少种不同的放置方法？请输出解的总数以及第一个解的棋盘布局。

**输入格式**：无输入（固定 n=8）

**输出格式**：
- 第一行输出解的总数
- 然后输出第一个解的棋盘布局（Q 表示皇后，. 表示空格）

**样例输出**：
```
八皇后问题共有 92 种解法。

第一个解的棋盘布局：
Q . . . . . . .
. . . . Q . . .
. . . . . . . Q
. . . . . Q . .
. . Q . . . . .
. . . . . . Q .
. Q . . . . . .
. . . Q . . . .
```

**解题思路**：

1. **数据结构：** 用一个一维数组 `pos[8]`，其中 `pos[i]` 表示第 i 行皇后放在哪一列。这天然保证了每行只有一个皇后。
2. **冲突检查：** 对于新放在第 row 行第 col 列的皇后，检查它是否与前面 row 行已放置的皇后冲突：
   - 同列：`pos[i] == col`
   - 对角线：`abs(row - i) == abs(col - pos[i])`（行差等于列差意味着在同一条对角线上）
3. **回溯搜索：** 从第 0 行开始，逐行放置皇后。每行尝试 0~7 列，如果合法就放置并递归下一行，否则尝试下一列。当 8 行都放满时，找到一个解。
4. **计数与输出：** 用全局变量 `solutionCount` 统计解的数量，找到第一个解时输出棋盘布局。

**完整代码**：

```cpp
#include <iostream>
#include <cmath>
using namespace std;

const int N = 8;
int pos[N];                // pos[i]：第i行皇后的列位置
int solutionCount = 0;     // 解的数量
bool firstPrinted = false; // 是否已输出第一个解

// 检查在(row, col)放皇后是否安全
bool isSafe(int row, int col) {
    for (int i = 0; i < row; i++) {
        if (pos[i] == col) return false;                       // 同列
        if (abs(row - i) == abs(col - pos[i])) return false;   // 对角线
    }
    return true;
}

// 回溯搜索
void solve(int row) {
    if (row == N) {           // 找到一组解
        solutionCount++;
        if (!firstPrinted) {  // 输出第一个解
            firstPrinted = true;
            cout << "第一个解的棋盘布局：" << endl;
            for (int i = 0; i < N; i++) {
                for (int j = 0; j < N; j++) {
                    cout << (pos[i] == j ? "Q " : ". ");
                }
                cout << endl;
            }
            cout << endl;
        }
        return;
    }
    for (int col = 0; col < N; col++) {
        if (isSafe(row, col)) {
            pos[row] = col;
            solve(row + 1);   // 递归下一行
        }
    }
}

int main() {
    solve(0);
    cout << "八皇后问题共有 " << solutionCount << " 种解法。" << endl;
    return 0;
}
```

### 例题2：组合输出

**题目描述**：从 1 到 n 的整数中选出 r 个数，按字典序输出所有可能的组合。例如，从 1~5 中选 3 个数，共有 C(5,3)=10 种组合。

**输入格式**：两个整数 n 和 r（1 ≤ r ≤ n ≤ 20），空格分隔。

**输出格式**：每行输出一种组合，数字之间用空格分隔，按字典序排列。

**样例输入**：
```
5 3
```

**样例输出**：
```
1 2 3
1 2 4
1 2 5
1 3 4
1 3 5
1 4 5
2 3 4
2 3 5
2 4 5
3 4 5
```

**解题思路**：

1. **核心思想：** 用回溯法生成组合。用一个数组 `comb[r]` 存储当前选出的 r 个数。
2. **参数设计：** `dfs(start, depth)` 表示：从 `start` 开始选数，当前已经选了 `depth` 个数。
   - `start` 控制"从哪个数开始选"，保证选择的数递增，从而避免重复组合（如 {1,2,3} 和 {3,2,1} 被视为同一组合）。
   - `depth` 表示已经选了几个数，当 `depth == r` 时输出结果。
3. **剪枝：** 如果剩余可选的数不够凑齐 r 个数，提前返回。即当 `n - start + 1 < r - depth` 时剪枝。
4. **回溯框架：**
   - 选择：从 start 到 n 依次尝试
   - 试探：将当前数放入 comb[depth]
   - 递归：dfs(i+1, depth+1)
   - 撤销：无需显式撤销，因为下一个循环会覆盖 comb[depth]

**完整代码**：

```cpp
#include <iostream>
using namespace std;

int n, r;
int comb[25];  // 存储当前组合

// start: 从哪个数开始选
// depth: 已经选了几个数
void dfs(int start, int depth) {
    // 终止条件：选够了 r 个数
    if (depth == r) {
        for (int i = 0; i < r; i++) {
            cout << comb[i] << (i == r - 1 ? "\n" : " ");
        }
        return;
    }
    
    // 剪枝：剩余的数不够凑齐 r 个
    // 还需要的个数 = r - depth
    // 剩余可选的个数 = n - start + 1
    // 如果剩余可选 < 还需要，则剪枝
    for (int i = start; i <= n; i++) {
        // 剪枝判断
        if (n - i + 1 < r - depth) break;
        
        comb[depth] = i;          // 选择 i
        dfs(i + 1, depth + 1);    // 递归：从 i+1 开始选下一个数
    }
}

int main() {
    n = 5;
    r = 3;
    cout << "从 1~" << n << " 中选 " << r << " 个数的所有组合：" << endl;
    dfs(1, 0);
    return 0;
}
```

#include <iostream>
#include <cmath>
#include <cstring>
using namespace std;

// 练习1：全排列
int n, perm[10];
bool used[10];

void permutation(int depth) {
    if (depth == n) {
        for (int i = 0; i < n; i++)
            cout << perm[i] << (i == n - 1 ? "\n" : " ");
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (!used[i]) {
            used[i] = true;          // 试探
            perm[depth] = i;
            permutation(depth + 1);   // 递归
            used[i] = false;          // 撤销（回溯）
        }
    }
}

    for (int i = start; i <= n; i++) {
        comb[depth] = i;
        combination(i + 1, depth + 1);
    }
}

// 练习3：N 皇后问题
int N, pos[20], countSolutions = 0;

bool isSafe(int row, int col) {
    for (int i = 0; i < row; i++) {
        if (pos[i] == col) return false;                     // 同列
        if (abs(row - i) == abs(col - pos[i])) return false; // 对角线
    }
    return true;
}

void nQueens(int row) {
    if (row == N) {
        countSolutions++;
        return;
    }
    for (int col = 0; col < N; col++) {
        if (isSafe(row, col)) {
            pos[row] = col;
            nQueens(row + 1);
            // pos[row] 会被下一轮覆盖，无需显式撤销
        }
    }
}

    memset(used, false, sizeof(used));
    permutation(0);

    // 测试组合
    cout << "\n组合 n=5, r=3:" << endl;
    n = 5; r = 3;
    combination(1, 0);

    // 测试N皇后
    N = 8; countSolutions = 0;
    nQueens(0);
    cout << "\n8皇后方案数: " << countSolutions << endl;

    return 0;
}

## 📝 本课小结

本节课我们学习了回溯算法——一种通过"试探与回溯"在解空间中系统搜索所有解的算法。回溯法的核心思想是四步法：**选择 → 试探 → 递归 → 撤销**。我们用一个生动的"走迷宫"比喻帮助理解：每到一个岔路口就选一条路走下去，遇到死胡同就退回来换另一条路。

我们通过**解空间树**直观地展示了回溯法的搜索过程，理解了为什么"剪枝"是回溯法效率的关键——提前排除不可能的分支可以大幅减少无效搜索。在八皇后问题中，通过对列冲突和对角线冲突的立即检查，搜索空间从 8! = 40320 减少到了约 2057 个实际探索节点。

通过两个经典例题——**八皇后问题**与**组合输出**——我们将回溯框架付诸实践。八皇后展示了二维约束下的回溯搜索，组合输出展示了如何通过参数控制来生成排列组合。这两种模式是回溯法中最常见的应用场景，掌握它们将为解决更复杂的搜索问题打下坚实基础。

记住回溯法的黄金法则：**大胆试探，果断回溯，及时剪枝。** 下一课我们将综合运用递归与分治的思想，挑战更复杂的算法问题。
