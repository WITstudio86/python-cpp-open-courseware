## 📖 算法讲解

### 高精度除法的两种场景

在学习了高精度加法、减法和乘法之后，除法是最后一块拼图。高精度除法分为两种难度截然不同的情况：

1. **高精度除以单精度**（如 12345678901234567890 ÷ 123）：除数在 int 范围内，算法简单，时间复杂度 O(n)
2. **高精度除以高精度**（如两个 200 位大数相除）：除数也是大数，需要用减法来模拟，时间复杂度 O(n×m)

### 高精度除以单精度

高精度除以单精度的核心是**模拟竖式除法**。我们回顾一下小学学过的竖式除法：

```
计算 12345 ÷ 12 的过程：

          1  0  2  8   ... 余 9
      ┌─────────────────
  12  │ 1  2  3  4  5
        1  2             ← 12×1=12, 够除，商1
        ─────
           0  3          ← 余0，带下3
              0          ← 不够除，商0
           ─────
              3  4       ← 带下4，34÷12=2...余10
              2  4       ← 12×2=24
              ─────
              1  0  5    ← 带下5，105÷12=8...余9
                 9  6    ← 12×8=96
                ─────
                    9    ← 最终余数
```

**算法描述**：

设被除数为大数字符串 s，除数为 int 类型的 d。

1. 初始化余数 r = 0
2. 从左到右遍历被除数的每一位：
   - 当前被除数 = r × 10 + 当前位数字
   - 商位 = 当前被除数 / d（整数除法）
   - 余数 r = 当前被除数 % d
3. 将商位拼接成结果字符串
4. 去除商的前导零

**ASCII 图解**（以 1234 ÷ 5 为例）：

```
被除数: "1234", 除数: 5

i=0: 当前位='1'
     cur = 0*10 + 1 = 1
     1 / 5 = 0（不够除，商0）
     1 % 5 = 1（余数变为1）

i=1: 当前位='2'
     cur = 1*10 + 2 = 12
     12 / 5 = 2（商2）
     12 % 5 = 2（余数变为2）

i=2: 当前位='3'
     cur = 2*10 + 3 = 23
     23 / 5 = 4（商4）
     23 % 5 = 3（余数变为3）

i=3: 当前位='4'
     cur = 3*10 + 4 = 34
     34 / 5 = 6（商6）
     34 % 5 = 4（余数变为4）

商 = "246"（去掉前导零 "0246" → "246"）
余数 = 4
验证：1234 = 5 × 246 + 4 ✓
```

### 高精度除以高精度

高精度除以高精度要复杂得多——除法不能像乘法和加法那样简单地逐位处理。核心思想是**用减法来模拟除法**：

> 除法本质上是"被除数能减去多少个除数"

**算法思路**：

1. 如果被除数 < 除数，商为 0，余数为被除数
2. 否则，反复从被除数中减去除数，每减一次商加 1
3. 为了提高效率，可以**试商**：在减法的每一步，尽可能多地减去除数的倍数

**改进版算法（试商法）**：

1. 从被除数中取出与除数相同位数的前缀
2. 用该前缀除以除数的最高位，得到一个估计商
3. 用高精度乘法验证：除数 × 估计商 ≤ 当前被除数
4. 用高精度减法：当前被除数 = 当前被除数 - 除数 × 估计商
5. 将估计商累加到最终商中
6. 重复直到处理完所有位

**更实用的方法是"减法模拟"**：直接反复减去除数，虽然效率低但直观易懂。对于本课（中小学生水平），我们采用这种方法，通过比较和减法来实现。

**减法模拟除法 ASCII 图解**（以 100 ÷ 7 为例）：

```
被除数 A = "100", 除数 B = "7"

迭代 1: A="100", B="7"
    100 >= 7, 所以 A = A - B = "93", 商+1

迭代 2: A="93", B="7"
    93 >= 7, 所以 A = A - B = "86", 商+1

...（继续减）...

迭代 14: A="2", B="7"
    2 < 7, 停止

商 = 14, 余数 = 2
验证：100 = 7 × 14 + 2 ✓
```

**优化**：直接一位一位地减太慢了。我们可以一次性减去除数的 10 的幂次倍。具体做法是：在除数后面补零，使它与被除数"对齐"，然后逐步减少补零的数量。

```
高精度除法（试商优化版）示意：

被除数 A = "4567", 除数 B = "23"

1. 将 B 扩大到与 A 相近的长度：
   B' = B × 100 = "2300"（在 B 后面补 2 个零）

2. 用减法求商：
   4567 - 2300 = 2267  → 商 += 100
   2267 - 2300 < 0      → 不够减

3. B' = B × 10 = "230"（少补一个零）
   2267 - 230 = 2037    → 商 += 10
   2037 - 230 = 1807    → 商 += 10
   ...（继续减）...
   227 - 230 < 0         → 不够减

4. B' = B = "23"（不补零）
   227 - 23 = 204       → 商 += 1
   ...（继续减）...
   20 - 23 < 0           → 不够减

最终商 = 198, 余数 = 20
验证：4567 = 23 × 198 + 20 ✓
```

## 💻 代码实现

### 高精度除以单精度

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

// 高精度除以单精度：返回商，同时通过引用返回余数
string high_precision_div_single(const string &num, int divisor, int &remainder) {
    if (divisor == 0) {
        cerr << "错误：除数不能为 0！" << endl;
        return "";
    }
    if (num == "0") {
        remainder = 0;
        return "0";
    }

    string quotient;  // 商
    long long cur = 0;  // 当前被除数（使用 long long 防止溢出）

    // 从左到右逐位处理
    for (int i = 0; i < (int)num.size(); i++) {
        cur = cur * 10 + (num[i] - '0');  // 当前被除数 = 上一位余数×10 + 当前位
        quotient += char(cur / divisor + '0');  // 商位
        cur %= divisor;  // 新的余数
    }

    remainder = (int)cur;

    // 去除商的前导零
    int start = 0;
    while (start < (int)quotient.size() - 1 && quotient[start] == '0') {
        start++;
    }

    return quotient.substr(start);
}
```

### 高精度除以高精度（减法模拟）

```cpp
// 比较两个大数（字符串形式）：a > b 返回 1，a == b 返回 0，a < b 返回 -1
int compare(const string &a, const string &b) {
    if (a.size() != b.size()) return a.size() > b.size() ? 1 : -1;
    for (int i = 0; i < (int)a.size(); i++) {
        if (a[i] != b[i]) return a[i] > b[i] ? 1 : -1;
    }
    return 0;
}

// 高精度减法：a - b（保证 a >= b）
string high_precision_subtract(string a, const string &b) {
    // 倒序存储
    vector<int> va(a.size()), vb(a.size(), 0);
    for (int i = 0; i < (int)a.size(); i++) va[i] = a[a.size() - 1 - i] - '0';
    for (int i = 0; i < (int)b.size(); i++) vb[i] = b[b.size() - 1 - i] - '0';

    // 逐位相减
    for (int i = 0; i < (int)a.size(); i++) {
        if (va[i] < vb[i]) {
            va[i] += 10;
            va[i + 1]--;
        }
        va[i] -= vb[i];
    }

    // 转回字符串，去除前导零
    int pos = a.size() - 1;
    while (pos > 0 && va[pos] == 0) pos--;
    string result;
    for (int i = pos; i >= 0; i--) result += char(va[i] + '0');
    return result;
}

// 高精度除以高精度：返回商和余数
void high_precision_div_high(const string &a, const string &b,
                              string &quotient, string &remainder) {
    if (b == "0") {
        cerr << "错误：除数不能为 0！" << endl;
        return;
    }
    if (compare(a, b) < 0) {
        quotient = "0";
        remainder = a;
        return;
    }

    remainder = a;
    quotient = "0";

    // 不断扩大除数（补零），加速减法过程
    while (compare(remainder, b) >= 0) {
        string temp = b;
        string weight = "1";
        // 在 temp 后面补零，使 temp 尽量接近但不超过 remainder
        while (compare(remainder, temp + "0") >= 0) {
            temp += "0";
            weight += "0";
        }
        // 反复减去 temp
        while (compare(remainder, temp) >= 0) {
            remainder = high_precision_subtract(remainder, temp);
            quotient = high_precision_add(quotient, weight);
        }
    }
}
```

## 📊 复杂度分析

### 高精度除以单精度

- **时间复杂度**：**O(n)**，其中 n 是被除数的位数。只需要从左到右遍历一次，每次做常数次运算。
- **空间复杂度**：**O(n)**，存储商和中间结果。
- 这是效率最高的高精度除法形式。

### 高精度除以高精度（减法模拟）

- **时间复杂度**：**O(n × m)**，其中 n 是被除数的位数，m 是除数的位数。
  - 最坏情况下（如 999...9 ÷ 1），需要约 10ⁿ 次减法，但通过补零优化后，实际的减法次数大大减少
  - 加上补零优化后，每次试商大约需要 O(n) 次操作，总共约 O(n × m) 级别
- **空间复杂度**：**O(n)**，存储中间结果。
- 相比 O(n) 的单精度除法，高精度除高精度确实要慢很多。对于竞赛中 200 位以内的数字，优化后的算法足够使用。

### 优化方向

在实际竞赛中，可以通过以下方式进一步优化高精度除高精度：
1. **二分试商**：用二分查找确定每次的商位，减少减法次数
2. **牛顿迭代法**：利用倒数乘法替代除法，复杂度可降到 O(n log n)
3. 但对于本课的教学目标，减法模拟法已足够清晰易懂。

### 例题 1：高精度除以单精度

**题目描述**：
输入一个不超过 1000 位的大整数 A 和一个在 int 范围内的整数 B，输出 A ÷ B 的商和余数。

**输入格式**：
第一行：一个大整数 A（不超过 1000 位）
第二行：一个正整数 B（1 ≤ B ≤ 2×10⁹）

**输出格式**：
第一行：商
第二行：余数

**样例输入**：
```
12345678901234567890
12345
```

**样例输出**：
```
1000055008304914
9580
```

**解题思路**：
直接使用高精度除以单精度的算法。模拟竖式除法，从左到右逐位处理，每次将当前余数乘以 10 加上当前位，然后除以 B 得到商位，取模得到新的余数。注意处理商的前导零。

**完整代码**：

```cpp
#include <iostream>
#include <string>
using namespace std;

void div_single(const string &a, int b, string &q, int &r) {
    q = "";
    r = 0;
    long long cur = 0;

    for (int i = 0; i < (int)a.size(); i++) {
        cur = cur * 10 + (a[i] - '0');
        q += char(cur / b + '0');
        cur %= b;
    }

    r = (int)cur;

    // 去除前导零
    int start = 0;
    while (start < (int)q.size() - 1 && q[start] == '0') start++;
    q = q.substr(start);
}

int main() {
    string a;
    int b;
    cin >> a >> b;

    string quotient;
    int remainder;
    div_single(a, b, quotient, remainder);

    cout << quotient << endl;
    cout << remainder << endl;
    return 0;
}
```

### 例题 2：高精度除以高精度

**题目描述**：
输入两个不超过 200 位的正整数 A 和 B，输出 A ÷ B 的商和余数。

**输入格式**：
第一行：被除数 A（不超过 200 位）
第二行：除数 B（不超过 200 位，B > 0）

**输出格式**：
第一行：商
第二行：余数

**样例输入**：
```
98765432109876543210
1234567890
```

**样例输出**：
```
80000000000
986543210
```

**样例解释**：
98765432109876543210 ÷ 1234567890 = 80000000000 余 986543210

**验证**：
1234567890 × 80000000000 + 986543210 = 98765431200000000000 + 986543210 = 98765432109876543210 ✓

**解题思路**：
使用减法模拟除法。核心思路：
1. 如果 A < B，商为 0，余数为 A
2. 否则，通过不断从 A 中减去 B（或 B 的 10 的幂次倍）来求商
3. 为了加速，先将 B 乘以 10 的幂次（补零），使它与 A 对齐
4. 反复减去对齐后的除数，每减一次商增加对应的权重
5. 逐步减少除数，直到除数回到 B 本身

**完整代码**：

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

// 比较两个大数：a>b 返回1，a==b 返回0，a<b 返回-1
int cmp(const string &a, const string &b) {
    if (a.size() != b.size()) return a.size() > b.size() ? 1 : -1;
    for (int i = 0; i < (int)a.size(); i++)
        if (a[i] != b[i]) return a[i] > b[i] ? 1 : -1;
    return 0;
}

// 高精度减法：a - b（保证 a >= b）
string sub(string a, const string &b) {
    vector<int> va(a.size()), vb(a.size(), 0);
    for (int i = 0; i < (int)a.size(); i++) va[i] = a[a.size()-1-i] - '0';
    for (int i = 0; i < (int)b.size(); i++) vb[i] = b[b.size()-1-i] - '0';
    for (int i = 0; i < (int)a.size(); i++) {
        if (va[i] < vb[i]) { va[i] += 10; va[i+1]--; }
        va[i] -= vb[i];
    }
    int p = a.size() - 1;
    while (p > 0 && va[p] == 0) p--;
    string r;
    for (int i = p; i >= 0; i--) r += char(va[i]+'0');
    return r;
}

// 高精度加法
string add(const string &a, const string &b) {
    int la = a.size(), lb = b.size();
    int m = max(la, lb);
    vector<int> va(m,0), vb(m,0);
    for (int i = 0; i < la; i++) va[i] = a[la-1-i] - '0';
    for (int i = 0; i < lb; i++) vb[i] = b[lb-1-i] - '0';
    vector<int> vc(m+1, 0);
    for (int i = 0; i < m; i++) {
        vc[i] += va[i] + vb[i];
        if (vc[i] >= 10) { vc[i+1] += 1; vc[i] -= 10; }
    }
    int p = m;
    while (p > 0 && vc[p] == 0) p--;
    string r;
    for (int i = p; i >= 0; i--) r += char(vc[i]+'0');
    return r;
}

// 高精度除以高精度
void div_high(string a, const string &b, string &q, string &r) {
    if (cmp(a, b) < 0) { q = "0"; r = a; return; }

    q = "0"; r = a;

    while (cmp(r, b) >= 0) {
        string temp = b;
        string w = "1";
        // 补零扩大除数
        while (cmp(r, temp + "0") >= 0) {
            temp += "0";
            w += "0";
        }
        // 反复减去扩大后的除数
        while (cmp(r, temp) >= 0) {
            r = sub(r, temp);
            q = add(q, w);
        }
    }
}

int main() {
    string a, b;
    cin >> a >> b;

    string q, r;
    div_high(a, b, q, r);

    cout << q << endl;
    cout << r << endl;
    return 0;
}
```

string sub(string a, const string &b) {
    vector<int> va(a.size()), vb(a.size(), 0);
    for (int i = 0; i < (int)a.size(); i++) va[i] = a[a.size()-1-i] - '0';
    for (int i = 0; i < (int)b.size(); i++) vb[i] = b[b.size()-1-i] - '0';
    for (int i = 0; i < (int)a.size(); i++) {
        if (va[i] < vb[i]) { va[i] += 10; va[i+1]--; }
        va[i] -= vb[i];
    }
    int p = a.size() - 1;
    while (p > 0 && va[p] == 0) p--;
    string r;
    for (int i = p; i >= 0; i--) r += char(va[i]+'0');
    return r;
}

// 高精度加法
string add(const string &a, const string &b) {
    int la = a.size(), lb = b.size();
    int m = max(la, lb);
    vector<int> va(m,0), vb(m,0);
    for (int i = 0; i < la; i++) va[i] = a[la-1-i] - '0';
    for (int i = 0; i < lb; i++) vb[i] = b[lb-1-i] - '0';
    vector<int> vc(m+1, 0);
    for (int i = 0; i < m; i++) {
        vc[i] += va[i] + vb[i];
        if (vc[i] >= 10) { vc[i+1] += 1; vc[i] -= 10; }
    }
    int p = m;
    while (p > 0 && vc[p] == 0) p--;
    string r;
    for (int i = p; i >= 0; i--) r += char(vc[i]+'0');
    return r;
}

// 练习3：高精度除以高精度
void divHigh(string a, const string &b, string &q, string &r) {
    if (cmp(a, b) < 0) { q = "0"; r = a; return; }
    q = "0"; r = a;
    while (cmp(r, b) >= 0) {
        string temp = b, w = "1";
        while (cmp(r, temp + "0") >= 0) { temp += "0"; w += "0"; }
        while (cmp(r, temp) >= 0) { r = sub(r, temp); q = add(q, w); }
    }
}

// 练习4：十进制转二进制
string toBinary(string dec) {
    if (dec == "0") return "0";
    string binary = "";
    while (dec != "0") {
        int rem;
        string q;
        divSingle(dec, 2, q, rem);
        binary = char(rem + '0') + binary;
        dec = q;
    }
    return binary;
}

int main() {
    string a = "123456789";
    int b = 7;
    string q; int r;
    divSingle(a, b, q, r);
    cout << a << " / " << b << " = " << q << " 余 " << r << endl;

    int rem;
    cout << "123456789 能被 3 整除? " << (isDivisible("123456789", 3, rem) ? "Yes" : "No") << endl;

    cout << "10 的二进制 = " << toBinary("10") << endl;  // 1010

}

## 📝 本课小结

本课我们完成了高精度四则运算的最后一块拼图——高精度除法。

**核心要点回顾**：

1. **高精度除以单精度（O(n)）**：模拟竖式除法，从左到右逐位处理。核心公式为 `cur = cur * 10 + a[i]`，商位为 `cur / b`，余数为 `cur % b`。算法简洁高效，一次遍历即可得到商和余数。

2. **高精度除以高精度（O(n×m)）**：通过减法来模拟除法。核心思想是"被除数能减去多少个除数"。使用补零优化可以大幅减少减法次数：先将除数扩大到与被除数相近的规模，再逐步缩小。

3. **辅助函数的重要性**：高精度除高精度需要依赖高精度比较、高精度减法等辅助函数。这也体现了高精度四则运算之间的紧密联系——除法需要减法，减法需要比较。

4. **完整的运算体系**：至此我们学完了高精度加、减、乘、除四则运算，可以处理任意大整数的基本运算。这些是算法竞赛中的基础工具。
