# 第15课：线性查找与二分查找

## 🎯 学习目标
- 理解线性查找的原理：从头到尾逐个比较查找目标值
- 掌握二分查找的核心思想和前提条件：数组必须有序
- 能够实现二分查找并理解其 O(log n) 的时间复杂度优势

## 📖 算法讲解

### 一、生活中处处有查找

想象一下，你在图书馆找一本书。如果书架上所有书都是乱放的，你只能一本一本翻看，运气好的话第一本就是，运气不好的话得翻遍整个书架。这就是“查找”——在数据集合中找出某个特定元素。计算机编程中，查找是最常见的操作之一。今天我们就来学习两种最基础也最重要的查找算法：线性查找和二分查找。

### 二、线性查找——最朴素的方法

线性查找（Linear Search），也叫顺序查找，顾名思义就是“按顺序一个一个找”。它的思路非常简单：

```
数组：[ 3, 7, 1, 9, 4, 2 ]  目标：找 9
       ↓
索引0：3 == 9？不是 → 下一个
索引1：7 == 9？不是 → 下一个
索引2：1 == 9？不是 → 下一个
索引3：9 == 9？是！→ 找到了，下标是 3
```

线性查找不需要数组有任何特殊的排列规律，无论数组是乱序还是有序，它都能工作。只要从第一个元素开始，依次判断每个元素是否等于目标值，相等就返回位置，直到末尾还没找到就返回“找不到”。

线性查找的代码非常好写，但问题是：如果数组有 100 万个元素，最坏情况下需要比较 100 万次——实在太慢了！

### 三、二分查找的引入——玩一个猜数字游戏

让我们玩一个经典的智力游戏：我心里想了一个 1 到 100 之间的数字，你来猜。每次猜完后，我会告诉你“大了”还是“小了”。你会怎么猜？

聪明的做法是——每次猜中间！比如：

```
第一轮：范围[1, 100]，猜 50 → 系统说“小了”→ 说明答案在 51~100 之间
第二轮：范围[51, 100]，猜 75 → 系统说“大了”→ 说明答案在 51~74 之间
第三轮：范围[51, 74]，猜 62 → 系统说“小了”→ 说明答案在 63~74 之间
第四轮：范围[63, 74]，猜 68 → 系统说“大了”→ 说明答案在 63~67 之间
第五轮：范围[63, 67]，猜 65 → 系统说“大了”→ 说明答案在 63~64 之间
第六轮：范围[63, 64]，猜 63 → 系统说“小了”→ 说明答案在 64
第七轮：范围[64, 64]，猜 64 → 猜中了！
```

100 以内的数，最多猜 7 次就一定能找到！这比从 1 猜到 100 快了不知道多少倍。这个策略的核心就是——每次排除一半的可能！这就是二分查找的思想。

### 四、二分查找的核心——区间不断缩小

二分查找（Binary Search）的前提是：**数组必须是有序的**（通常是升序）。如果数组乱序，二分查找就失效了——因为你无法通过"大了还是小了"来排除一半的数据。

二分查找的过程可以用“左右指针”来形象理解：

```
初始数组（有序）：[ 1, 3, 5, 7, 9, 11, 13, 15 ]  目标：找 7

初始状态：
    left = 0                         right = 7
    ┌───┬───┬───┬───┬───┬────┬────┬────┐
    │ 1 │ 3 │ 5 │ 7 │ 9 │ 11 │ 13 │ 15 │
    └───┴───┴───┴───┴───┴────┴────┴────┘
      ↑                               ↑
    左指针                          右指针

第一步：mid = (0+7)/2 = 3，arr[3] = 7，找到了！返回下标 3。
```

再看一个需要多次缩小范围的例子：

```
有序数组：[ 1, 3, 5, 7, 9, 11, 13, 15 ]  目标：找 11

第一轮：
    left = 0, right = 7
    mid = (0+7)/2 = 3，arr[3] = 7
    7 < 11 → 大了还是小了？→ 小了！所以答案在右边
    left = mid + 1 = 4
    ┌───┬───┬───┬───┬───┬────┬────┬────┐
    │ 1 │ 3 │ 5 │ 7 │ 9 │ 11 │ 13 │ 15 │
    └───┴───┴───┴───┴───┴────┴────┴────┘
                            ↑         ↑
                          left     right

第二轮：
    left = 4, right = 7
    mid = (4+7)/2 = 5，arr[5] = 11
    11 == 11 → 找到了！返回下标 5。
```

### 五、左闭右闭 vs 左闭右开——二分查找的两种写法

在二分查找的实现中，对“区间”的定义至关重要。常见的有两种写法：

**1. 左闭右闭区间 [left, right]**

这是最直观的写法：左右边界都是包含在查找范围内的。循环条件是 `while (left <= right)`，因为当 `left == right` 时，区间还有一个元素需要检查。

```
初始：left = 0, right = n - 1   → 查找范围包含 arr[left] 到 arr[right]
循环条件：left <= right          → 区间内至少有一个元素
更新左边界：left = mid + 1       → 排除 arr[mid]，左边界右移到 mid+1
更新右边界：right = mid - 1      → 排除 arr[mid]，右边界左移到 mid-1
```

**2. 左闭右开区间 [left, right)**

这种写法中，左边界包含在查找范围内，但右边界不包含。循环条件是 `while (left < right)`。

```
初始：left = 0, right = n        → 查找范围包含 arr[left] 到 arr[right-1]
循环条件：left < right            → 区间内至少有一个元素
更新左边界：left = mid + 1        → 排除 arr[mid]，左边界右移到 mid+1
更新右边界：right = mid           → arr[mid] 已排除，右边界移到 mid
```

两种写法都能正确实现二分查找，但要注意循环条件和边界更新必须配套使用，混用了就容易出 Bug！

### 六、二分查找的多种变体

实际应用中，数组里可能有重复元素，我们需要的不只是“找到任意一个”，而是找到特定的那个：

| 变体 | 含义 | 示例（数组 [1,3,3,3,5,7]） |
|------|------|---------------------------|
| 找第一个等于 target | 返回 target 第一次出现的位置 | target=3，返回 1 |
| 找最后一个等于 target | 返回 target 最后一次出现的位置 | target=3，返回 3 |
| 找第一个大于等于 target | 返回第一个 >= target 的位置（lower_bound） | target=4，返回 4（值为5） |
| 找第一个大于 target | 返回第一个 > target 的位置（upper_bound） | target=3，返回 4（值为5） |

以“找第一个等于 target”为例，关键改动是：**当 arr[mid] 等于 target 时，不要立即返回，而是继续向左找**：

```
arr[mid] == target 时：
    right = mid - 1    → 继续往左边找，看有没有更靠前的相等元素
```

最终 left 指针会指向第一个等于 target 的位置。这是一种非常精妙的写法，值得反复揣摩！

### 七、边界条件与常见陷阱

二分查找看似简单，但“细节是魔鬼”。以下是常见的坑：

1. **整型溢出**：`mid = (left + right) / 2` 在 left 和 right 都很大时，加法可能溢出。推荐写法：`mid = left + (right - left) / 2`。

2. **死循环**：当 `left + 1 == right` 时，如果 `mid` 取整方向与边界更新不匹配，可能造成死循环。使用 `mid = left + (right - left) / 2`（向零取整 / 向下取整）配合 `left = mid + 1` 可以避免。

3. **返回值检查**：二分查找结束后，需要检查找到的位置是否有效（数组下标是否越界，该位置的值是否真的等于 target）。

## 💻 代码实现

### 线性查找（Linear Search）

```cpp
// 线性查找：从头到尾依次比较
// 参数：arr - 数组, n - 数组长度, target - 要查找的目标值
// 返回：找到则返回下标（0开始），找不到返回 -1
int linearSearch(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {   // 遍历数组的每一个元素
        if (arr[i] == target)         // 如果当前元素等于目标值
            return i;                 // 返回当前下标
    }
    return -1;  // 遍历完都没找到，返回 -1
}
```

### 二分查找——迭代版（左闭右闭区间）

```cpp
// 二分查找（迭代）：在有序数组中查找 target
// 前提：数组 arr 已经按升序排列
// 返回：找到则返回任意一个匹配下标，找不到返回 -1
int binarySearch(int arr[], int n, int target) {
    int left = 0, right = n - 1;    // 左右指针，[left, right] 左闭右闭
    while (left <= right) {          // 区间非空时继续查找
        int mid = left + (right - left) / 2;  // 防溢出写法
        if (arr[mid] == target)      // 中间值等于目标：找到！
            return mid;
        else if (arr[mid] < target)  // 中间值比目标小：目标在右边
            left = mid + 1;          // 左边界右移，排除左边一半
        else                         // 中间值比目标大：目标在左边
            right = mid - 1;         // 右边界左移，排除右边一半
    }
    return -1;  // 区间为空，说明没找到
}
```

### 二分查找——递归版

```cpp
// 二分查找（递归）：在有序数组的 [left, right] 范围内查找 target
int binarySearchRecursive(int arr[], int left, int right, int target) {
    if (left > right)                // 递归终止条件：区间为空
        return -1;                   // 没找到
    int mid = left + (right - left) / 2;  // 计算中间位置
    if (arr[mid] == target)          // 找到了
        return mid;
    else if (arr[mid] < target)      // 中间值比目标小
        return binarySearchRecursive(arr, mid + 1, right, target);  // 在右半边找
    else                             // 中间值比目标大
        return binarySearchRecursive(arr, left, mid - 1, target);   // 在左半边找
}
```

### 找第一个等于 target 的位置（lower_bound）

```cpp
// 在有序数组中查找 target 第一次出现的位置（下标从0开始）
// 如果没有找到，返回 -1
int findFirstEqual(int arr[], int n, int target) {
    int left = 0, right = n - 1;
    int ans = -1;        // 记录当前找到的位置
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] >= target) {   // 中间值大于等于目标
            if (arr[mid] == target)  // 记录可能的位置
                ans = mid;
            right = mid - 1;         // 继续往左找，看有没有更靠前的
        } else {
            left = mid + 1;          // 中间值比目标小，往右找
        }
    }
    return ans;  // 返回第一次出现的位置，没找到则是 -1
}
```

## 📊 复杂度分析

### 线性查找

- **时间复杂度**：O(n)
  - 最好情况：第一个元素就是要找的，比较 1 次 → O(1)
  - 最坏情况：要找的元素在最后一个或者不存在，比较 n 次 → O(n)
  - 平均情况：大约比较 n/2 次 → O(n)
- **空间复杂度**：O(1)，只需要几个变量保存下标，不需要额外空间。

### 二分查找

- **时间复杂度**：O(log n)
  - 每次比较都将搜索范围缩小一半
  - 在 100 万个元素中查找，最多只需要比较约 20 次！
  - 推导：n → n/2 → n/4 → ... → 1，约需要 log₂n 步
  - 精确来说，最大比较次数为 ⌊log₂n⌋ + 1
- **空间复杂度**：
  - 迭代版：O(1)，只需几个变量
  - 递归版：O(log n)，因为递归调用会使用调用栈

### 算法对比

| 特性 | 线性查找 | 二分查找 |
|------|---------|---------|
| 前提条件 | 无 | 数组必须有序 |
| 时间复杂度 | O(n) | O(log n) |
| 空间复杂度 | O(1) | O(1) / O(log n) |
| n=100万时的比较次数 | ~100万 | ~20 |
| 代码复杂度 | 简单 | 中等 |

**重要结论**：虽然二分查找很快，但它要求数组有序。如果数组原本无序，需要先排序（排序本身通常需要 O(n log n) 时间）。因此：
- 如果只需要查找**一次**，线性查找 O(n) 反而更优
- 如果需要在同一个数组上**反复查找**多次，先排序再二分划算得多

## 🏋️ 经典例题

### 例题1：找数字位置

**题目描述**：给定一个已从小到大排序的数组和一个目标值 target，找出 target 在数组中第一次出现的位置（下标从0开始）。如果不存在，输出 -1。

**输入格式**：第一行两个整数 n 和 target（1 ≤ n ≤ 100000）。第二行 n 个已排序的整数。

**输出格式**：一个整数，表示第一次出现的位置或 -1。

**样例输入**：
```
6 3
1 2 3 3 5 7
```

**样例输出**：
```
2
```

**题解代码**：

```cpp
#include <iostream>
using namespace std;

const int MAXN = 100005;
int arr[MAXN];

// 在有序数组 arr[0..n-1] 中查找 target 第一次出现的位置
int findFirst(int arr[], int n, int target) {
    int left = 0, right = n - 1;
    int ans = -1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] >= target) {
            if (arr[mid] == target) ans = mid;  // 记录当前位置
            right = mid - 1;  // 继续向左搜索
        } else {
            left = mid + 1;   // 目标在右侧
        }
    }
    return ans;
}

int main() {
    int n, target;
    cin >> n >> target;
    for (int i = 0; i < n; i++) cin >> arr[i];
    cout << findFirst(arr, n, target) << endl;
    return 0;
}
```

**思路解析**：本题不能直接用最基本的二分查找（找到任意位置就返回），因为可能多个 3 连在一起。我们需要“找到第一个”，所以当 `arr[mid] == target` 时，不是直接返回，而是先记录该位置，然后继续往左半部分搜索。最终 ans 中记录的就是最靠前的位置。

### 例题2：猜数游戏

**题目描述**：系统有一个 1 到 100 之间的秘密数字。每次你可以猜一个数字，系统会告诉你猜大了还是猜小了。用二分查找策略，输出猜测过程。

**输入格式**：第一行一个整数 secret（1~100），表示秘密数字。

**输出格式**：每行输出一次猜测，格式为 "第X次猜测：Y，结果：大了/小了/正确！"。

**样例输入**：
```
67
```

**样例输出**：
```
第1次猜测：50，结果：小了
第2次猜测：75，结果：大了
第3次猜测：62，结果：小了
第4次猜测：68，结果：大了
第5次猜测：65，结果：小了
第6次猜测：66，结果：小了
第7次猜测：67，结果：正确！
```

**题解代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int secret;
    cin >> secret;
    
    int left = 1, right = 100;  // 猜数范围 [1, 100]
    int cnt = 0;                // 猜测次数
    
    while (left <= right) {
        cnt++;
        int guess = left + (right - left) / 2;  // 二分策略：猜中间值
        
        cout << "第" << cnt << "次猜测：" << guess << "，结果：";
        
        if (guess == secret) {
            cout << "正确！" << endl;
            break;
        } else if (guess < secret) {
            cout << "小了" << endl;
            left = guess + 1;    // 要猜的数更大，缩小范围
        } else {
            cout << "大了" << endl;
            right = guess - 1;   // 要猜的数更小，缩小范围
        }
    }
    
    cout << "一共猜了" << cnt << "次（1到100最多猜7次）" << endl;
    return 0;
}
```

**思路解析**：这就是二分查找的直接应用！初始范围是 [1, 100]，每次取中间值猜测。根据“大了”还是“小了”调整左右边界，不断缩小范围。最多 7 次就能猜中（因为 log₂100 ≈ 6.64，向上取整是 7）。

#### 挑战题1 参考代码

```cpp
#include <iostream>
#include <vector>
using namespace std;

int search(vector<int>& nums, int target) {
    int left = 0, right = nums.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) return mid;

        // 判断哪一半是有序的
        if (nums[left] <= nums[mid]) {
            // 左半部分有序
            if (nums[left] <= target && target < nums[mid]) {
                right = mid - 1;  // target 在左半部分
            } else {
                left = mid + 1;   // target 在右半部分
            }
        } else {
            // 右半部分有序
            if (nums[mid] < target && target <= nums[right]) {
                left = mid + 1;   // target 在右半部分
            } else {
                right = mid - 1;  // target 在左半部分
            }
        }
    }
    return -1;
}

int main() {
    int n, target;
    cin >> n >> target;
    vector<int> arr(n);
    for (int i = 0; i < n; i++) cin >> arr[i];
    cout << search(arr, target) << endl;
    return 0;
}
```

## 📝 本课小结

本课学习了两大查找算法。线性查找思路直白、代码简单，逐个比较即可，时间复杂度 O(n)，适合无序数组或数据量较小的场景。二分查找则利用了“有序”这一额外信息，每次排除一半数据，时间复杂度仅 O(log n)——在 100 万个元素中只需约 20 次比较，效率惊人。同学们需要重点掌握：二分查找的迭代与递归实现、左闭右闭/左闭右开两种区间定义的配套写法、防溢出的 mid 计算、以及“找第一个等于”、“找第一个大于等于”等变体的写法。最后提醒大家：二分查找的核心不是死记硬背代码，而是理解“不断缩小搜索范围”的思想——这将在未来的分治算法、搜索优化等高级主题中反复出现。
