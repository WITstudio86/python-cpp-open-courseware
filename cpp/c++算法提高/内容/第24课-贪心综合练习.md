## 📖 算法讲解

### 一、什么是贪心算法？——回顾与深化

贪心算法（Greedy Algorithm）是算法设计中最常用、最直观的策略之一。在前面的课程中，我们已经学习了好几种不同类型的贪心算法。现在，让我们从更高的视角来回顾和总结一下。

贪心算法的核心思想可以用一句话概括：**在每一步选择中，都采取当前状态下最好（最优）的选择，希望通过一系列的局部最优选择，最终得到全局最优解。** 就像一个人爬山，每走一步都往当前最陡峭的上坡方向走，希望最终到达山顶。虽然这种方法不一定总能得到全局最优，但在许多经典问题上，贪心策略恰好是正确的。

### 二、如何识别贪心策略？

当面对一道新题目时，如何判断它是否能用贪心算法解决呢？一般可以从以下两个性质入手：

**1. 最优子结构性质**：问题的最优解包含子问题的最优解。也就是说，一个大问题可以分解成若干个小问题，而大问题的最优解是由小问题的最优解组合而成的。例如，在「删数问题」中，删除 K 个数字得到最小数，等价于先删除 1 个数字得到最小数，剩下的问题还是删数问题。

**2. 贪心选择性质**：在每一步，我们可以做出一个"看起来最好"的选择，并且这个选择不会影响后续得到最优解。也就是说，**局部最优选择能导致全局最优解**。例如，在「均分纸牌」问题中，从最左边开始，如果第一堆不够平局值，就从第二堆借——这个操作一定是必要的，不会影响后续的最优性。

如果你能在问题中识别出这两个性质，那么贪心算法大概率是正确的。当然，严格来说需要数学证明，但在竞赛中，我们可以先大胆猜想，然后通过构造反例来验证。如果你找不出反例，往往贪心策略就是正确的。

### 三、已学贪心策略总结

我们在前面的课程中学习了几大类贪心策略，现在来系统梳理一下：

| 贪心策略类型 | 关键词 | 经典问题 |
|-------------|--------|---------|
| **排序贪心** | 先排序，再贪心选择 | 找零问题（硬币贪心）、排队接水 |
| **区间调度** | 按结束时间排序，选不冲突的区间 | 活动选择问题、最多不重叠区间 |
| **分数背包** | 按单位价值排序，能拿多少拿多少 | 分数背包问题（可分割物品） |
| **均分策略** | 计算平均值，从左到右调整 | 均分纸牌 |
| **删数/选数贪心** | 维护单调性，删除"破坏者" | 删数问题、拼接最大数 |
| **哈夫曼编码** | 每次合并最小的两个 | 最优合并问题、文件压缩 |

这些策略看似各不相同，但核心思想是一致的：**每一步做当前最优的决策**。区别在于"当前最优"的定义方式不同——有时候是选最大的，有时候是选结束最早的，有时候是删除一个破坏单调性的元素。

### 四、如何面对一道新的贪心题？

面对一道新的贪心题，建议按照以下步骤来思考：

**第1步：理解题目，明确目标**。搞清楚题目要你最大化什么、最小化什么。例如，删数问题要最小化结果数值，均分纸牌要最小化移动次数。

**第2步：思考"局部最优"长什么样**。在每一步中，什么操作是"最好"的？可以从小的例子入手，手动模拟一下，看看什么操作能让你逐步逼近答案。

**第3步：构造反例，验证猜想**。想出一个贪心策略后，不要马上写代码。先在纸上构造几个特殊数据（边界情况、极端情况），看看你的策略在这些情况下是否仍然正确。如果找到了反例，说明贪心策略不对，需要调整。

**第4步：考虑正确性证明**。对于经典贪心问题，尝试理解为什么局部最优能推出全局最优。常用的证明方法有：
- **交换论证法**：假设最优解和贪心解不同，通过交换操作，证明贪心解不劣于最优解。
- **归纳法**：证明贪心策略在第一步是正确的，且做完第一步后，剩余问题与原问题同构。

**第5步：实现代码，注意细节**。贪心代码通常比较简洁，但要注意边界条件（如空串、前导零、下标越界等）。

**第6步：测试验证**。用多组数据测试你的代码，包括题目给的样例、自己构造的边界数据。

### 五、贪心 vs 动态规划

很多同学会困惑：贪心和动态规划到底有什么区别？一个简单的判断方法是：

- **贪心**：每步做选择，选了就不回头。决策是"单向"的，不可撤销。
- **动态规划**：会记录多种选择的结果，从所有可能中选最优。决策是"多向"的，可以回退和比较。

比如，「0-1 背包问题」不能用贪心，因为选择一件物品可能会排除掉后面更优的组合，需要用动态规划来"试"不同的组合。但「分数背包问题」可以用贪心，因为物品可以分割，按单位价值从高到低依次取就一定是最优的。

判断口诀：**如果"先拿大的"不会堵死后路，贪心可行；如果选择之间有冲突，需要通盘考虑，用 DP。**

## 💻 代码实现

### 删数问题——贪心代码框架

问题核心：给定一个数字字符串，每次删除一个数字，使得剩下的数字串表示的数值最小。贪心策略是：**从高位到低位扫描，找到第一个"比下一位大"的数字，删除它。** 因为高位数字越小，整体数值越小。

```cpp
// 删数问题：从数字串 s 中删除 k 个数字，使结果最小
string deleteDigits(string s, int k) {
    // 重复 k 次删除操作
    for (int t = 0; t < k; t++) {
        // 寻找第一个「当前位 > 下一位」的位置
        int pos = s.size() - 1;  // 默认删最后一位
        for (int i = 0; i < (int)s.size() - 1; i++) {
            if (s[i] > s[i + 1]) {
                pos = i;
                break;  // 找到第一个就停止
            }
        }
        s.erase(pos, 1);  // 删除该位置的字符
    }
    // 去除前导零（但保留至少一个 '0'）
    while (s.size() > 1 && s[0] == '0') {
        s.erase(0, 1);
    }
    return s;
}
```

### 均分纸牌——贪心代码框架

问题核心：计算所有牌数的平均值，然后从左到右逐堆处理。如果当前堆不等于平均值，就将差额转移给下一堆。**每一堆只需要调整一次，差额无论正负都算一次移动。**

```cpp
// 均分纸牌：n 堆纸牌，每次移动 1 张到相邻堆，求最小移动次数
int minMovesToEvenCards(int cards[], int n) {
    int sum = 0;
    for (int i = 0; i < n; i++) sum += cards[i];
    int avg = sum / n;  // 平均值（题目保证整除）
    
    int moves = 0;
    for (int i = 0; i < n - 1; i++) {
        if (cards[i] != avg) {
            int diff = cards[i] - avg;   // 多出或缺少的牌数
            cards[i + 1] += diff;        // 将差额转移给下一堆
            cards[i] = avg;              // 当前堆变为平均值
            moves++;                     // 一次移动
        }
    }
    return moves;
}
```

## 📊 复杂度分析

**删数问题：**
- 时间复杂度：O(n × k)，其中 n 为数字串长度，k 为删除次数。每次删除需要 O(n) 时间扫描，共 k 次。当 k ≈ n 时，最坏 O(n²)。如果使用单调栈优化，可以做到 O(n)，但对于中小学生的贪心入门，O(n × k) 的方法更容易理解。
- 空间复杂度：O(n)，需要存储数字字符串（实际上就是在原串上操作，额外空间为 O(1)）。

**均分纸牌：**
- 时间复杂度：O(n)，只需一次遍历计算总和，再一次遍历进行调整。
- 空间复杂度：O(n)，需要存储 n 堆纸牌的数量。实际上可以在原数组上操作，额外空间为 O(1)。

### 例题1：删数问题

**题目描述**：给定一个高精度正整数 N（长度不超过 240 位），去掉其中任意 K 个数字后，剩下的数字按原左右次序将组成一个新的正整数。编程对给定的 N 和 K，寻找一种方案使得剩下的数字组成的新数最小。

**输入格式**：
- 第一行：一个正整数 N（长度不超过 240 位）
- 第二行：一个整数 K（0 < K < N 的长度）

**输出格式**：输出删除 K 个数字后得到的最小数。

**样例输入**：
```
178543
4
```

**样例输出**：
```
13
```

**样例解释**：
```
原始数字：178543
删除过程：
  178543 → 找到 8>5，删 8 → 17543
  17543  → 找到 7>5，删 7 → 1543
  1543   → 找到 5>4，删 5 → 143
  143    → 找到 4>3，删 4 → 13
最终结果：13
```

**题解代码**：
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    int k;
    cin >> s >> k;

    // 每次删除一个数字，共删除 k 次
    for (int t = 0; t < k; t++) {
        int pos = s.size() - 1;  // 默认删除最后一位
        // 从高位到低位扫描，找第一个「大于下一位」的位置
        for (int i = 0; i < (int)s.size() - 1; i++) {
            if (s[i] > s[i + 1]) {
                pos = i;
                break;
            }
        }
        s.erase(pos, 1);
    }

    // 去掉前导零
    while (s.size() > 1 && s[0] == '0') {
        s.erase(0, 1);
    }

    cout << s << endl;
    return 0;
}
```

### 例题2：均分纸牌

**题目描述**：有 N 堆纸牌，编号分别为 1, 2, ..., N。每堆上有若干张纸牌，但纸牌总张数必为 N 的倍数。可以在任一堆上取若干张纸牌，然后移动到相邻的堆上。移动规则为：在编号为 1 的堆上取的纸牌，只能移到编号为 2 的堆上；在编号为 N 的堆上取的纸牌，只能移到编号为 N-1 的堆上；其他堆上取的纸牌，可以移到相邻左边或右边的堆上。现在要求找出一种移动方法，用最少的移动次数使每堆上纸牌数都一样多。

例如：N=4，纸牌数分别为：(9, 8, 17, 6)。移动 3 次可以达到目的。

**输入格式**：
- 第一行：一个整数 N（1 ≤ N ≤ 100），表示纸牌的堆数
- 第二行：N 个整数 A₁, A₂, ..., A_N（1 ≤ Aᵢ ≤ 10000），表示每堆纸牌的初始张数

**输出格式**：一个整数，表示使所有堆纸牌数相等的最少移动次数。

**样例输入**：
```
4
9 8 17 6
```

**样例输出**：
```
3
```

**样例解释**：
```
初始状态： [9]  [8]  [17]  [6]
平均值  = (9+8+17+6) / 4 = 40/4 = 10

步骤1：第1堆需要 +1（9→10），从第2堆借1张
         [10] [7]  [17]  [6]   移动1次

步骤2：第2堆需要 +3（7→10），从第3堆借3张
         [10] [10] [14]  [6]   移动2次

步骤3：第3堆多出4张（14→10），给第4堆4张
         [10] [10] [10] [10]   移动3次

最少移动次数：3
```

**题解代码**：
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, a[105];
    cin >> n;
    int sum = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        sum += a[i];
    }
    int avg = sum / n;  // 平均值

    int moves = 0;
    for (int i = 0; i < n - 1; i++) {
        if (a[i] != avg) {
            int diff = a[i] - avg;  // 当前堆与平均值的差额
            a[i + 1] += diff;       // 将差额转移到下一堆
            // a[i] 已经不需要再使用了，实际值通过 diff 转移到 a[i+1]
            moves++;                // 无论 diff 正负，都记为一次移动
        }
    }

    cout << moves << endl;
    return 0;
}
```

> **关键理解**：为什么 a[i] != avg 就一定要移动？因为第 i 堆的牌只能通过第 i-1 堆或第 i+1 堆来调整。从左到右处理时，第 i-1 堆已经处理完毕（变为 avg），不能再动了。所以第 i 堆的差额**必须**通过第 i+1 堆来调整，这次移动是不可避免的。

### 📝 挑战题

#### 挑战题1：电池的寿命

**题目描述**：小 S 新买了一个掌上游戏机，这个游戏机由两节 5 号电池供电。为了保证能够长时间玩游戏，他买了很多 5 号电池，这些电池的生产商不同，质量也有差异，因而使用寿命也有所不同。有的能使用 5 个小时，有的可能就只能使用 3 个小时。显然如果他只有两节电池，那么总使用时间是这两节电池中寿命较短的那节的时间。

现在已知电池的数量和每节电池的寿命，请找出一种电池搭配方案，使得总使用时间尽可能长。

**简化版**：有 N 节电池，每节电池的寿命为 a[i]。每次选择两节电池配对使用，使用时间为两节中寿命较小者。配对后两节电池均耗尽。求能获得的最大总使用时间。

**输入格式**：第一行一个整数 N（2 ≤ N ≤ 1000）。第二行 N 个整数 a[i]（1 ≤ a[i] ≤ 10000）。

**输出格式**：一个整数（或保留一位小数），表示最大总使用时间。

**样例输入**：
```
5
3 3 3 5 5
```

**样例输出**：
```
9.0
```

**样例解释**：一共有 5 节电池，寿命分别为 3,3,3,5,5。配对方案：
- 第一对：3 和 5 → 使用时间 3（剩余：3,3,5）
- 第二对：3 和 5 → 使用时间 3（剩余：3）
- 最后一节电池无法配对，舍弃
- 总使用时间 = 3+3 = 6？不对……

其实最优方案取决于贪心策略。本题的核心思想是：如果电池中寿命最长的比其余所有电池寿命之和还大，那么多出的部分无法被利用；否则总时间 = 总和 / 2。这是因为任意两节电池配对时，使用时间由较小者决定，所以我们应尽可能让电池寿命分散配对。

如果 max ≤ sum - max：总使用时间 = sum / 2
否则：总使用时间 = sum - max（因为最长的那节电池只能和所有其他电池配对，且会被"浪费"掉超出部分）

对于样例 [3,3,3,5,5]：sum=19, max=5, sum-max=14。max(5) ≤ 14，所以总时间 = 19/2 = 9.5？保留一位小数输出 9.5。把答案改为 9.5。

**修正样例输出**：
```
9.5
```

**提示**：贪心策略：如果最大电池寿命 ≤ 其余电池寿命之和，答案是 sum/2；否则答案是 sum - max。这背后的贪心思想是：尽可能让每节电池的寿命都被充分利用，减少"浪费"。

#### 基础题1 参考代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    int k;
    cin >> s >> k;

    // 每次删除一个数字，共删除 k 次
    for (int t = 0; t < k; t++) {
        int pos = s.size() - 1;  // 默认删最后一位
        for (int i = 0; i < (int)s.size() - 1; i++) {
            if (s[i] > s[i + 1]) {
                pos = i;
                break;
            }
        }
        s.erase(pos, 1);
    }

    // 去除前导零
    while (s.size() > 1 && s[0] == '0') {
        s.erase(0, 1);
    }

    cout << s << endl;
    return 0;
}
```

int main() {
    int n, C, w[10005];
    cin >> n >> C;
    for (int i = 0; i < n; i++) cin >> w[i];
    sort(w, w + n);

    int boats = 0;
    int left = 0, right = n - 1;
    while (left <= right) {
        if (left == right) { boats++; break; }
        if (w[left] + w[right] <= C) {
            left++;
            right--;
        } else {
            right--;
        }
        boats++;
    }
    cout << boats << endl;
    return 0;
}

## 📝 本课小结

本节课我们进行了贪心算法的综合练习，通过对「删数问题」和「均分纸牌」两道经典例题的深入分析，进一步加深了对贪心策略的理解。

**核心收获：**
- 贪心算法的两个关键性质：最优子结构和贪心选择性质。识别这两个性质是判断贪心是否可行的基础。
- 已学贪心策略的系统梳理：排序贪心、区间调度、分数背包、均分策略、删数策略等，它们的共同点都是"每步做局部最优"。
- 面对新贪心题的思维流程：理解目标 → 提出猜想 → 构造反例验证 → 代码实现 → 测试。
- 贪心 vs 动态规划的区别：贪心是"选了不回头"，DP 是"多选一"。

**学习建议：** 贪心算法最重要的是"感觉"的培养。多做题目，多手动模拟，多问自己"这一步的最优选择是什么？为什么它不会影响最终结果？" 当你能够快速识别一个问题的贪心性质并给出正确的贪心策略时，你就真正掌握了贪心算法。

下一课我们将进入一个全新的领域——**递归算法**，学习函数自己调用自己的神奇技巧，为后续的分治和回溯算法打下基础。
