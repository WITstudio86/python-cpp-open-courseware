## 📖 算法讲解

动态规划（Dynamic Programming，简称 DP）是一种通过把原问题分解为相对简单的子问题来求解复杂问题的方法。它的核心思想是 **记住已经解决过的子问题的答案**，避免重复计算。

一维线性 DP 是 DP 中最基础的形式——`dp[i]` 只依赖于前若干个状态，通常可以用一个一维数组来存储中间结果。

### DP 解题框架

解决 DP 问题通常遵循以下四个步骤：

```
┌─────────────────────────────────────────────────────────┐
│  Step 1: 状态定义 (Define State)                        │
│  ─────────────────────────────────────                  │
│  明确 dp[i] 表示什么含义。                               │
│  例如：dp[i] = 以第 i 个元素结尾的最大子段和             │
├─────────────────────────────────────────────────────────┤
│  Step 2: 状态转移方程 (Transition Equation)             │
│  ─────────────────────────────────────                  │
│  找到 dp[i] 与 dp[j] (j < i) 之间的递推关系。            │
│  例如：dp[i] = max(a[i], dp[i-1] + a[i])                │
├─────────────────────────────────────────────────────────┤
│  Step 3: 初始状态 (Initial State)                       │
│  ─────────────────────────────────────                  │
│  确定递推的起点，即 dp[0] 或 dp[1] 的值。                │
│  例如：dp[0] = a[0]                                     │
├─────────────────────────────────────────────────────────┤
│  Step 4: 计算顺序 (Order of Computation)                │
│  ─────────────────────────────────────                  │
│  从小到大递推，确保计算 dp[i] 时所需的 dp[j] 已算出。     │
│  例如：for i = 1 to n-1 依次计算                        │
└─────────────────────────────────────────────────────────┘
```

### 经典问题一：最大子段和（Maximum Subarray Sum）

**问题描述**：给定一个长度为 `n` 的整数序列，找出一个连续子序列，使得该子序列的和最大。

**状态定义**：
设 `dp[i]` 表示 **以第 i 个元素结尾** 的最大子段和。注意，这里强调“以第 i 个元素结尾”，强制子段必须包含 `a[i]`。

**状态转移方程**：
对于第 `i` 个元素，我们有两个选择：
- 要么独自成段：`a[i]`
- 要么接在前面以 `i-1` 结尾的最大子段后面：`dp[i-1] + a[i]`

取两者的最大值：

```
dp[i] = max( a[i] , dp[i-1] + a[i] )
```

**最终答案**：`max(dp[0], dp[1], ..., dp[n-1])`

**初始状态**：`dp[0] = a[0]`

**可视化示例**：

数组：`[-2, 1, -3, 4, -1, 2, 1, -5, 4]`

逐项推导过程：

```
 i   a[i]   决策过程                    dp[i]  说明
────────────────────────────────────────────────────────
 0   -2   独自成段                      -2    只有一个元素
 1    1   max(1, -2+1) = max(1, -1)     1    另起炉灶更好
 2   -3   max(-3, 1+(-3)) = max(-3,-2) -2   虽为负，但接上更大
 3    4   max(4, -2+4) = max(4, 2)       4   另起炉灶更好
 4   -1   max(-1, 4+(-1)) = max(-1,3)    3   接上更大
 5    2   max(2, 3+2) = max(2, 5)        5   接上更大
 6    1   max(1, 5+1) = max(1, 6)        6   接上更大 ← 最大值!
 7   -5   max(-5, 6+(-5)) = max(-5,1)    1   接上更大
 8    4   max(4, 1+4) = max(4, 5)        5   接上更大
────────────────────────────────────────────────────────
最终答案 = max(dp[0..8]) = 6
对应子段：[4, -1, 2, 1]，和 = 6
```

**空间优化**：
观察状态转移方程，`dp[i]` 只依赖于 `dp[i-1]`，因此我们不需要维护整个 `dp` 数组，只需要用一个变量 `currentMax` 来记录 `dp[i]`，另一个变量 `globalMax` 来记录全局最大值。空间复杂度从 O(n) 优化到 O(1)。

### 经典问题二：最长上升子序列（Longest Increasing Subsequence, LIS）

**问题描述**：给定一个长度为 `n` 的整数序列，找出最长的严格递增子序列的长度（子序列不要求连续）。

**状态定义**：
设 `dp[i]` 表示 **以第 i 个元素结尾** 的最长上升子序列的长度。

**状态转移方程**：
对于每个 `i`，我们枚举所有 `j < i`：
- 如果 `a[j] < a[i]`，则 `a[i]` 可以接在 `a[j]` 后面，形成长度为 `dp[j] + 1` 的上升子序列。

```
dp[i] = max{ dp[j] + 1 }    (对于所有 j < i 且 a[j] < a[i])
```

如果不存在这样的 `j`，则 `dp[i] = 1`（自己单独构成子序列）。

**最终答案**：`max(dp[0], dp[1], ..., dp[n-1])`

**可视化示例**：

数组：`[3, 1, 4, 1, 5, 9, 2, 6]`

逐项推导过程：

```
 i   a[i]   检查 j < i (a[j] < a[i])           dp[j]+1    dp[i]
────────────────────────────────────────────────────────────
 0    3    无前置元素                               —       1
 1    1    无满足 a[j]<1 的元素                     —       1
 2    4    j=0: a[0]=3<4 ✓  dp[0]+1=2              2
           j=1: a[1]=1<4 ✓  dp[1]+1=2              2       2
 3    1    无满足 a[j]<1 的元素                     —       1
 4    5    j=0: a[0]=3<5 ✓  dp[0]+1=2              2
           j=1: a[1]=1<5 ✓  dp[1]+1=2              2
           j=2: a[2]=4<5 ✓  dp[2]+1=3              3
           j=3: a[3]=1<5 ✓  dp[3]+1=2              2       3
 5    9    j=0~4 中 a[j]<9 的最大 dp[j]=3         3+1=4    4
 6    2    j=1: a[1]=1<2 ✓  dp[1]+1=2              2
           j=3: a[3]=1<2 ✓  dp[3]+1=2              2       2
 7    6    j=0: a[0]=3<6 ✓  dp[0]+1=2              2
           j=1: a[1]=1<6 ✓  dp[1]+1=2              2
           j=2: a[2]=4<6 ✓  dp[2]+1=3              3
           j=3: a[3]=1<6 ✓  dp[3]+1=2              2
           j=4: a[4]=5<6 ✓  dp[4]+1=4              4       4
────────────────────────────────────────────────────────────
最终答案 = max(dp[0..7]) = 4
对应子序列：[1, 4, 5, 9] 或 [1, 4, 5, 6]
```

**O(n log n) 优化思路**：
上述 O(n²) 解法在 `n` 较大时效率较低。我们可以用 **贪心 + 二分查找** 来优化：
- 维护一个数组 `tails`，其中 `tails[k]` 表示长度为 `k+1` 的上升子序列的最小末尾元素。
- 遍历数组，对于每个元素 `x`，在 `tails` 中二分查找第一个 `>= x` 的位置，并替换它。
- 最终 `tails` 的长度就是 LIS 长度。时间复杂度 O(n log n)。

## 💻 代码实现

### 最大子段和（O(n)）

```cpp
// 最大子段和 —— O(n) DP 解法
int maxSubarraySum(vector<int>& a) {
    int n = a.size();
    if (n == 0) return 0;
    
    // dp[i] 表示以第 i 个元素结尾的最大子段和
    // 空间优化：只需维护当前值和全局最大值
    int curMax = a[0];   // dp[0]
    int ans = a[0];      // 全局最大值
    
    for (int i = 1; i < n; i++) {
        // 状态转移：要么接上前面的，要么另起炉灶
        curMax = max(a[i], curMax + a[i]);
        ans = max(ans, curMax);
    }
    
    return ans;
}
```

### 最长上升子序列（O(n²)）

```cpp
// 最长上升子序列 —— O(n²) DP 解法
int LIS(vector<int>& a) {
    int n = a.size();
    if (n == 0) return 0;
    
    // dp[i] 表示以第 i 个元素结尾的最长上升子序列长度
    vector<int> dp(n, 1);  // 初始状态：每个元素自身构成长度为 1 的子序列
    int ans = 1;
    
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i]) {           // 严格递增条件
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }
    
    return ans;
}
```

### 最长上升子序列（O(n log n) 优化）

```cpp
// 最长上升子序列 —— O(n log n) 贪心+二分
int LIS_nlogn(vector<int>& a) {
    vector<int> tails;  // tails[k] = 长度为 k+1 的上升子序列的最小末尾
    
    for (int x : a) {
        // 在 tails 中二分查找第一个 >= x 的位置
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) {
            tails.push_back(x);   // x 比所有末尾都大，拓展长度
        } else {
            *it = x;              // 替换，保持末尾尽可能小
        }
    }
    
    return tails.size();
}
```

## 🏋️ 经典例题

### 例题1：最大子段和

**题目描述**：
给定一个长度为 `n` 的整数序列（可能包含负数），找出一个连续子序列，使得该子序列的和最大。输出这个最大和。

**输入格式**：
- 第一行：一个整数 `n`，表示序列长度。
- 第二行：`n` 个整数，表示序列中的元素。

**输出格式**：
- 一个整数，表示最大子段和。

**样例输入**：
```
9
-2 1 -3 4 -1 2 1 -5 4
```

**样例输出**：
```
6
```

**样例解释**：子段 `[4, -1, 2, 1]` 的和为 `6`，是所有连续子段中最大的。

---

**题解**：

设 `dp[i]` 为以第 `i` 个元素结尾的最大子段和。对于每个位置 `i`，我们面临两个选择：

1. 将 `a[i]` 接在 `dp[i-1]` 对应的子段后面，得到 `dp[i-1] + a[i]`。
2. `a[i]` 独自成为一个新的子段。

选择其中较大的那个：

```
dp[i] = max(a[i], dp[i-1] + a[i])
```

然后遍历所有 `dp[i]`，取最大值即为答案。

**完整代码**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    
    int curMax = a[0], ans = a[0];
    for (int i = 1; i < n; i++) {
        curMax = max(a[i], curMax + a[i]);
        ans = max(ans, curMax);
    }
    cout << ans << endl;
    return 0;
}
```

**关键点总结**：
- `dp[i]` 必须包含 `a[i]`，这样才能保证子段的连续性。
- 答案取所有 `dp[i]` 的最大值，而非仅 `dp[n-1]`。
- 可用滚动变量将空间优化至 O(1)。

### 例题2：最长上升子序列

**题目描述**：
给定一个长度为 `n` 的整数序列，找出最长的**严格递增**子序列的长度。子序列不要求连续，但必须保持原序列中的相对顺序。

**输入格式**：
- 第一行：一个整数 `n`，表示序列长度。
- 第二行：`n` 个整数，表示序列中的元素。

**输出格式**：
- 一个整数，表示最长上升子序列的长度。

**样例输入**：
```
8
3 1 4 1 5 9 2 6
```

**样例输出**：
```
4
```

**样例解释**：最长上升子序列可以是 `[1, 4, 5, 9]` 或 `[1, 4, 5, 6]`，长度为 `4`。

---

**题解（O(n²)）**：

设 `dp[i]` 为以第 `i` 个元素结尾的最长上升子序列的长度。

对于每个 `i`，检查所有 `j < i`：若 `a[j] < a[i]`，则可以将 `a[i]` 接在以 `a[j]` 结尾的子序列后面，长度为 `dp[j] + 1`。取所有这些可能长度的最大值：

```
dp[i] = max(1, max(dp[j] + 1))   其中 j < i 且 a[j] < a[i]
```

**完整代码**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    
    vector<int> dp(n, 1);
    int ans = 1;
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }
    cout << ans << endl;
    return 0;
}
```

**优化（O(n log n)）**：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];
    
    vector<int> tails;
    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end())
            tails.push_back(x);
        else
            *it = x;
    }
    cout << tails.size() << endl;
    return 0;
}
```

**关键点总结**：
- `dp[i]` 必须包含 `a[i]`，否则无法递推。
- `a[j] < a[i]` 是严格递增条件，若要求非严格递增则改为 `<=`。
- O(n log n) 优化使用了 `tails` 数组 + `lower_bound`，需要理解“最小末尾”的贪心思想。

### 提高题

#### 练习3：最大连续子段乘积

**题目描述**：给定一个整数数组（可能包含负数），找出连续子数组的最大乘积。注意：由于负负得正，需要同时维护以当前元素结尾的最大乘积和最小乘积。

**状态定义**：
- `dpMax[i]`：以第 i 个元素结尾的最大乘积
- `dpMin[i]`：以第 i 个元素结尾的最小乘积

**状态转移**：
- `dpMax[i] = max(a[i], dpMax[i-1] * a[i], dpMin[i-1] * a[i])`
- `dpMin[i] = min(a[i], dpMax[i-1] * a[i], dpMin[i-1] * a[i])`

**输入格式**：
- 第一行：一个整数 n（1 ≤ n ≤ 10⁵）
- 第二行：n 个整数（int 范围内），空格分隔

**输出格式**：一行一个整数，表示最大连续子段乘积（结果在 int 范围内）。

**样例输入**：
```
5
2 3 -2 4 -1
```

**样例输出**：
```
48
```

**样例解释**：子数组 [2, 3, -2, 4, -1] 的乘积 = 48（三个负数相乘得正）。

#### 练习4：打家劫舍（House Robber）

**题目描述**：你是一个小偷，计划偷窃沿街的房屋。每间房屋内都有一定数量的现金。唯一的限制是：相邻的房屋装有相互连通的防盗系统，如果两间相邻的房屋在同一晚被偷窃，系统会自动报警。给定一个代表每个房屋现金数的数组，计算在不触发报警的情况下，你能偷窃到的最高金额。

**状态定义**：`dp[i]` 表示前 i 个房屋能偷到的最高金额。

**状态转移**：`dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])`（第 i 个房屋不偷 vs 偷）。

**输入格式**：
- 第一行：一个整数 n（1 ≤ n ≤ 10⁵）
- 第二行：n 个非负整数，表示每个房屋的现金数

**输出格式**：一行一个整数，表示最高金额。

**样例输入**：
```
4
1 2 3 1
```

**样例输出**：
```
4
```

**样例解释**：偷第 1 间（金额=1）和第 3 间（金额=3），总金额 = 1 + 3 = 4。

### 挑战题

#### 练习5：最长公共子序列（LCS）

**题目描述**：给定两个字符串 s1 和 s2（长度均不超过 1000），求它们的最长公共子序列的长度。子序列不要求连续，但必须保持原字符串中的相对顺序。

**状态定义**：`dp[i][j]` 表示 s1 的前 i 个字符与 s2 的前 j 个字符的最长公共子序列长度。

**状态转移**：
- 如果 s1[i-1] == s2[j-1]：`dp[i][j] = dp[i-1][j-1] + 1`
- 否则：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

这是二维 DP 的经典入门题，请用自底向上的方式实现。

**输入格式**：
- 第一行：字符串 s1
- 第二行：字符串 s2

**输出格式**：一行一个整数，表示最长公共子序列的长度。

**样例输入**：
```
abcde
ace
```

**样例输出**：
```
3
```

**样例解释**：最长公共子序列为 "ace"，长度为 3。

### 练习题参考答案

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

// 练习1：最大子段和 O(n)
int maxSubArray(int a[], int n) {
    int curMax = a[0], ans = a[0];
    for (int i = 1; i < n; i++) {
        curMax = max(a[i], curMax + a[i]);
        ans = max(ans, curMax);
    }
    return ans;
}

// 练习2：最长上升子序列 O(n²)
int LIS(int a[], int n) {
    vector<int> dp(n, 1);
    int ans = 1;
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i])
                dp[i] = max(dp[i], dp[j] + 1);
        }
        ans = max(ans, dp[i]);
    }
    return ans;
}

// 练习3：最大连续子段乘积
int maxProduct(int a[], int n) {
    int curMax = a[0], curMin = a[0], ans = a[0];
    for (int i = 1; i < n; i++) {
        int tempMax = max({a[i], curMax * a[i], curMin * a[i]});
        int tempMin = min({a[i], curMax * a[i], curMin * a[i]});
        curMax = tempMax;
        curMin = tempMin;
        ans = max(ans, curMax);
    }
    return ans;
}

// 练习4：打家劫舍
long long rob(int nums[], int n) {
    if (n == 0) return 0;
    if (n == 1) return nums[0];
    long long prev2 = nums[0], prev1 = max((long long)nums[0], (long long)nums[1]);
    for (int i = 2; i < n; i++) {
        long long cur = max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}

// 练习5：最长公共子序列
int LCS(const string &s1, const string &s2) {
    int m = s1.size(), n = s2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1[i-1] == s2[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m][n];
}

int main() {
    int a1[] = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    cout << "最大子段和: " << maxSubArray(a1, 9) << endl;  // 6

    int a2[] = {3, 1, 4, 1, 5, 9, 2, 6};
    cout << "LIS: " << LIS(a2, 8) << endl;                // 4

    int a3[] = {2, 3, -2, 4, -1};
    cout << "最大乘积: " << maxProduct(a3, 5) << endl;     // 48

    int a4[] = {1, 2, 3, 1};
    cout << "打家劫舍: " << rob(a4, 4) << endl;            // 4

    cout << "LCS: " << LCS("abcde", "ace") << endl;        // 3

    return 0;
}
```

## 📝 本课小结

本节课我们系统学习了一维线性动态规划的核心框架——状态定义、状态转移方程、初始状态与计算顺序四步法。通过最大子段和与最长上升子序列两个经典问题，我们掌握了如何从问题出发定义 `dp[i]` 的含义，推导递推关系，并逐步优化算法复杂度（如最大子段和的空间优化、LIS 的 O(n log n) 贪心+二分优化）。线性 DP 是动态规划的基石，掌握好一维DP的思路将为后续学习多维DP、背包问题、区间DP等打下坚实基础。请同学们课后多加练习，熟练运用四步框架解决各类DP问题。
