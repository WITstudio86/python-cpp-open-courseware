## 📖 算法讲解

在 C++ 编程竞赛中，写出正确的代码只是第一步，更重要的是写出**没有 Bug 的代码**，并且能够在有限时间内**快速调试**。本节将介绍竞赛中最实用的调试技巧与验证方法。

### 常见错误分析

编程竞赛中，最常见的错误包括以下几类：

1. **数组越界**
   - 循环条件写错导致访问 `a[n]`（下标从 0 开始，合法范围是 `0` 到 `n-1`）
   - 全局数组开得太小，大数据时越界
   - 特判边界情况时遗漏条件

2. **未初始化变量**
   - 局部变量没有赋初值就开始使用（C++ 中局部变量默认为随机值）
   - 累加器 `sum`、计数器 `cnt`、答案 `ans` 忘记初始化为 0
   - 多组数据输入时，忘记清空上一次的数据

3. **整数溢出**
   - `int` 类型只支持约 ±21 亿，当数据范围很大时需要使用 `long long`
   - 两个 `int` 相乘再赋给 `long long` 仍然会溢出（需要先强制转换）
   - 中间计算结果溢出但最终结果在范围内

4. **边界条件错误（Off-by-One）**
   - 二分查找的边界 `left` 和 `right` 处理不当
   - 循环遍历时少了一个元素或多了一个元素
   - 数组下标从 0 还是从 1 开始混淆

5. **死循环 / 无限递归**
   - 循环条件永远为真
   - 递归函数没有正确的终止条件
   - BFS/DFS 没有标记已访问节点

### 调试方法

**打印调试（Print Debugging）**：最基础也最实用的方法。在关键位置打印变量值，观察程序的执行流程。

```cpp
// 调试宏，提交时注释掉即可
#define debug(x) cerr << #x << " = " << x << endl;
// 使用：debug(a[i]);
```

**断言 assert**：用于在开发阶段检查不变量。如果条件为假，程序会立即终止并报告错误位置。

```cpp
#include <cassert>
assert(1 <= n && n <= 100000);  // 检查输入合法性
assert(ans >= 0);               // 检查答案合理性
```

**GDB 调试器基础**：GDB 是强大的命令行调试工具，可以设置断点、单步执行、查看变量值。基础用法：
- `gdb ./program` 启动调试
- `b 行号` 设置断点
- `r` 运行程序
- `n` 单步执行（不进入函数）
- `s` 单步执行（进入函数）
- `p 变量名` 打印变量值
- `bt` 查看调用栈（程序崩溃时特别有用）

### 时间复杂度估算

时间复杂度描述了算法执行时间随输入规模增长的趋势。在竞赛中，我们可以根据数据范围反推需要的算法复杂度：

| 数据范围 N | 可接受的时间复杂度 | 常用算法 |
| :---: | :---: | :--- |
| N ≤ 10 | O(N!), O(2^N) | 全排列枚举、回溯 |
| N ≤ 20 | O(2^N), O(N·2^N) | 状态压缩 DP、子集枚举 |
| N ≤ 100 | O(N^3) | Floyd 最短路、区间 DP |
| N ≤ 500 | O(N^3) | Floyd、三重循环 |
| N ≤ 5000 | O(N^2) | 简单 DP、二维前缀和 |
| N ≤ 10^5 | O(N log N) | 排序、二分、堆优化的 Dijkstra |
| N ≤ 10^6 | O(N log N) 或 O(N) | 线性筛、贪心、滑动窗口 |
| N ≤ 10^8 | O(N)（常数要小） | 线性扫描 |

> **经验法则**：现代评测机每秒大约执行 10^8 次基本操作。如果一个算法的复杂度是 O(N^2) 且 N=10^5，那么需要约 10^10 次操作，大约需要 100 秒 — 这显然会超时（TLE）。而 O(N log N) 大约只需要 1.7×10^6 次操作，瞬间完成。

### 对拍（Duipai / Brute-force Verification）

「对拍」是竞赛中最强大的验证技巧。核心思想是：

1. 写一个**暴力解法**（保证正确但可能很慢）
2. 写一个**优化解法**（快速但可能写错）
3. 写一个**随机数据生成器**
4. 写一个**比较脚本**，反复用随机数据测试，比较两个解法的输出

如果两个解法对大量随机数据都输出相同结果，那么优化解法正确的概率就非常高。这也是找出边界 Bug 的最有效方法。

## 💻 代码实现

下面展示一个完整的对拍系统，包含：暴力解法、优化解法、随机数据生成器和自动比较器。本示例以"最大子段和"问题为例。

```cpp
#include <iostream>
#include <vector>
#include <cstdlib>
#include <ctime>
#include <algorithm>
#include <climits>
using namespace std;

// ==================== 暴力解法 O(N²) ====================
int brute_force(const vector<int>& a) {
    int n = a.size();
    int max_sum = INT_MIN;
    for (int i = 0; i < n; i++) {
        int sum = 0;
        for (int j = i; j < n; j++) {
            sum += a[j];
            max_sum = max(max_sum, sum);
        }
    }
    return max_sum;
}

// ==================== 优化解法 O(N) Kadane ====================
int optimized(const vector<int>& a) {
    int max_ending_here = 0;
    int max_so_far = INT_MIN;
    for (int x : a) {
        max_ending_here = max(x, max_ending_here + x);
        max_so_far = max(max_so_far, max_ending_here);
    }
    return max_so_far;
}

// ==================== 随机数据生成器 ====================
vector<int> generate_test(int n, int value_range) {
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        // 生成 [-value_range, value_range] 范围内的随机数
        a[i] = (rand() % (2 * value_range + 1)) - value_range;
    }
    return a;
}

// ==================== 对拍主函数 ====================
void duipai(int rounds, int max_n, int value_range) {
    srand(time(0));
    for (int t = 1; t <= rounds; t++) {
        int n = rand() % max_n + 1;
        vector<int> a = generate_test(n, value_range);
        int ans1 = brute_force(a);
        int ans2 = optimized(a);
        if (ans1 == ans2) {
            cout << "测试 #" << t << " 通过! n=" << n << endl;
        } else {
            cout << "测试 #" << t << " 失败! n=" << n << endl;
            cout << "暴力答案: " << ans1 << ", 优化答案: " << ans2 << endl;
            cout << "数组: ";
            for (int x : a) cout << x << " ";
            cout << endl;
            return;  // 发现 Bug，立即停止
        }
    }
    cout << "全部 " << rounds << " 组测试通过！" << endl;
}
```

## 📊 复杂度分析

### 约束条件 → 算法复杂度 速查表

| 数据范围 N | 时间复杂度上限 | 典型算法 |
| :---: | :---: | :--- |
| N ≤ 10 | O(N!) | 全排列 (next_permutation) |
| N ≤ 15 | O(2^N) | 子集枚举 |
| N ≤ 20 | O(N·2^N) | 状态压缩 DP |
| N ≤ 100 | O(N^3) | Floyd-Warshall |
| N ≤ 500 | O(N^3) | 三重循环枚举 |
| N ≤ 2000 | O(N^2) | 简单 DP |
| N ≤ 10^5 | O(N log N) | 排序、二分、优先队列 |
| N ≤ 10^6 | O(N log N) | 排序、线段树 |
| N ≤ 10^7 | O(N) | 线性扫描、前缀和 |
| N ≤ 10^8 | O(1) 或 O(log N) | 公式、数学推导 |

> 记住：`10^8 次/秒` 是经验法则。如果你的算法预计执行次数超过 10^8，很可能超时。

### 对拍系统的复杂度

- 暴力解法：O(N^2)，适用于小数据（N ≤ 2000）
- 优化解法：O(N)，适用于大数据
- 对拍时使用小数据（N ≤ 100），暴力也能快速运行
- 总时间复杂度：O(轮数 × N^2)，在 N 较小时完全可接受

## 🏋️ 经典例题

### 例题 1：常见错误分析

下面展示 5 种竞赛中最常见的 Bug，以及对应的修复方法。

#### Bug 1：数组越界

**错误代码：**
```cpp
int a[100];
for (int i = 0; i <= 100; i++) {  // ❌ 应该是 i < 100
    a[i] = i;
}
```

**修复代码：**
```cpp
int a[100];
for (int i = 0; i < 100; i++) {   // ✅ 正确：下标 0~99
    a[i] = i;
}
```

#### Bug 2：未初始化变量

**错误代码：**
```cpp
int sum;          // ❌ 局部变量未初始化，值是随机的
for (int i = 0; i < n; i++) {
    sum += a[i];
}
cout << sum;
```

**修复代码：**
```cpp
int sum = 0;      // ✅ 初始化累加器
for (int i = 0; i < n; i++) {
    sum += a[i];
}
cout << sum;
```

#### Bug 3：整数溢出

**错误代码：**
```cpp
int a = 100000, b = 100000;
int c = a * b;    // ❌ 10^10 超出 int 范围（约 2.1×10^9）
cout << c;
```

**修复代码：**
```cpp
long long a = 100000, b = 100000;
long long c = a * b;  // ✅ long long 支持约 9×10^18
cout << c;
```

#### Bug 4：Off-by-One（边界差一）

**错误代码：**
```cpp
// 二分查找：在有序数组中查找 x
int left = 0, right = n - 1;
while (left < right) {         // ❌ 可能漏掉 left == right 的情况
    int mid = (left + right) / 2;
    if (a[mid] >= x) right = mid;
    else left = mid + 1;
}
```

**修复代码：**
```cpp
int left = 0, right = n - 1;
while (left <= right) {        // ✅ 包含边界情况
    int mid = (left + right) / 2;
    if (a[mid] == x) return mid;
    else if (a[mid] < x) left = mid + 1;
    else right = mid - 1;
}
return -1;
```

#### Bug 5：死循环

**错误代码：**
```cpp
int x = 1;
while (x > 0) {   // ❌ 条件永远为真，x 不断增大
    cout << x << " ";
    x++;
}
```

**修复代码：**
```cpp
int x = 1;
while (x <= 10) { // ✅ 有明确的终止条件
    cout << x << " ";
    x++;
}
```

### 例题 2：对拍实践 — 最大子段和

**问题描述**：给定一个长度为 N 的整数数组，找出一个连续子数组，使得子数组的元素和最大，输出最大和。

**输入**：第一行一个整数 N（1 ≤ N ≤ 100），第二行 N 个整数（绝对值 ≤ 1000）。
**输出**：最大的子段和。

**对拍流程**：
1. 用 O(N^2) 暴力枚举所有子数组，保证正确性
2. 用 O(N) 的 Kadane 算法作为优化解法
3. 随机生成 1000 组测试数据
4. 比较两个解法的输出，如果不同则打印出错数据

#### 练习4：调试复杂代码——最大子段和变种

**题目描述**：下面的代码意图求"环形数组的最大子段和"（数组首尾相连，子段可以跨越数组末尾到开头）。但代码存在多个 Bug。请找出所有 Bug 并写出修复后的正确代码。

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int a[100005];

    // 情况1：最大子段和不出环
    int maxEnding = 0, maxNormal = 0;
    for (int i = 0; i <= n; i++) {
        maxEnding = max(a[i], a[i] + maxEnding);
        maxNormal = max(maxNormal, maxEnding);
    }

    // 情况2：最大子段和跨越首尾 = 总和 - 最小子段和
    int total = 0;
    for (int i = 0; i < n; i++) total += a[i];

    int minEnding = 1e9, minSubarray = 1e9;
    for (int i = 0; i < n; i++) {
        minEnding = min(a[i], a[i] + minEnding);
        minSubarray = min(minSubarray, minEnding);
    }

    int ans = max(maxNormal, total - minSubarray);
    cout << ans << endl;
    return 0;
}
```

1. 循环边界可能有问题
2. 变量初始化可能有问题
3. 边界情况（如全负数数组）可能没处理好

### 练习题参考答案

#### 练习1参考答案

**Bug**：循环条件 `i <= n` 应该是 `i < n`。数组 `a[100]` 大小只有 100，如果输入 n=100，访问 `a[100]` 越界。

**后果**：数组越界访问可能导致程序崩溃（Segmentation Fault）或读取/修改其他变量的值，产生难以调试的错误。

**修复代码**：
```cpp
#include <iostream>
using namespace std;

int main() {
    int a[100], n, sum = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {  // 修复：i < n 而非 i <= n
        cin >> a[i];
        sum += a[i];
    }
    cout << sum << endl;
    return 0;
}
```

#### 练习2参考答案

(1) O(N^2)，N=10^5 时约 10^10 次操作 → **不能通过**
(2) 调和级数，O(N log N)，可以通过
(3) O(N log N)，可以通过

#### 练习3参考代码

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
#include <cmath>
using namespace std;

// 暴力解法 O(n)
bool brute_force(int n) {
    if (n < 2) return false;
    for (int i = 2; i < n; i++)
        if (n % i == 0) return false;
    return true;
}

// 优化解法 O(sqrt(n))
bool optimized(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}

// 随机生成 [2, 10000]
int generate_test() {
    return rand() % 9999 + 2;
}

// 对拍
void duipai(int rounds) {
    srand(time(0));
    for (int t = 1; t <= rounds; t++) {
        int n = generate_test();
        bool ans1 = brute_force(n);
        bool ans2 = optimized(n);
        if (ans1 != ans2) {
            cout << "测试 #" << t << " 失败! n=" << n
                 << " 暴力=" << ans1 << " 优化=" << ans2 << endl;
            return;
        }
        if (t % 100 == 0)
            cout << "已通过 " << t << " 组测试" << endl;
    }
    cout << "全部 " << rounds << " 组测试通过！" << endl;
}

int main() {
    duipai(1000);
    return 0;
}
```

#### 练习4参考代码

```cpp
#include <iostream>
#include <algorithm>
#include <climits>
using namespace std;

const int MAXN = 100005;

int main() {
    int n;
    cin >> n;
    int a[MAXN];
    for (int i = 0; i < n; i++) cin >> a[i];

    // Bug 1: 循环改成 i < n（不是 i <= n）
    // Bug 2: maxNormal 初始化为 a[0]，maxEnding 初始化也需要考虑
    int maxEnding = 0, maxNormal = INT_MIN;
    for (int i = 0; i < n; i++) {
        maxEnding = max(a[i], maxEnding + a[i]);
        maxNormal = max(maxNormal, maxEnding);
    }

    int total = 0;
    for (int i = 0; i < n; i++) total += a[i];

    // Bug 3: minEnding 的初始值应设 0（因为最小子段和可以是一个空子段=0）
    // 或者用 Kadane 求最小子段和
    int minEnding = 0, minSubarray = 0;
    for (int i = 0; i < n; i++) {
        minEnding = min(a[i], minEnding + a[i]);
        minSubarray = min(minSubarray, minEnding);
    }

    // Bug 4: 处理全负数的情况，maxNormal 就是答案
    int ans;
    if (total == minSubarray) {
        // 所有数都是负数的情况
        ans = maxNormal;
    } else {
        ans = max(maxNormal, total - minSubarray);
    }

    cout << ans << endl;
    return 0;
}
```

## 📝 本课小结

1. **竞赛常见错误**：数组越界、未初始化变量、整数溢出、Off-by-One、死循环 — 了解这些错误是避免它们的第一步
2. **调试方法**：print 调试、assert 断言、GDB 调试器 — 根据情况选择最合适的工具
3. **时间复杂度估算**：记住 10^8 次/秒 的经验法则，根据数据范围反推算法复杂度
4. **对拍技巧**：暴力 + 优化 + 随机数据 = 最高效的验证方法，在竞赛中遇到不确定的题目时务必使用

> 💡 **小贴士**：竞赛中写出 Bug 是正常的事情，关键是快速找到并修复它。对拍是最值得投入时间学习的技巧之一，它能让你在提交前就发现 90% 的错误。
