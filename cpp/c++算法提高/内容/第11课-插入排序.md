# 第11课：插入排序——像整理扑克牌

## 🎯 学习目标
- 理解插入排序的核心思想：将未排序元素逐一插入到已排序部分的正确位置
- 掌握插入排序的实现方法，理解有序区逐渐扩张的过程
- 能够利用插入排序处理部分有序数据的场景

## 📖 算法讲解

### 一、从整理扑克牌说起

你一定玩过扑克牌吧？想象这样一个场景：你手里已经有一些按点数从小到大排好的牌，现在你又摸到了一张新牌。你会怎么做？

大多数人都会这样做：**从右往左**（从大到小）扫视手中的牌，找到新牌应该"挤"进去的位置，然后把比它大的牌都往右挪一挪，腾出一个空位，最后把新牌插进去。

这就是**插入排序**的核心思想！计算机执行插入排序的过程，和人类整理扑克牌的方式几乎一模一样。

```
摸牌前手中已有（有序）:  [3  5  7  9]
新摸到的牌: 6

步骤1：从右往左找位置
         [3  5  7  9]
                ↑
           9 > 6，9 需要往右挪

步骤2：继续往左找
         [3  5  7  9]
             ↑
         7 > 6，7 也需要往右挪

步骤3：找到了！
         [3  5  7  9]
          ↑
      5 < 6，说明 6 应该插在 5 的右边

步骤4：把比6大的元素右移，腾出空位
         [3  5  _  7  9]
                ↑
             空位！

步骤5：插入新牌
         [3  5  6  7  9]
              ↑
           插入完成！
```

### 二、插入排序的整体流程

插入排序从数组的第二个元素开始，把整个数组分成两个部分：

- **左边（有序区）**：已经排好序的元素
- **右边（无序区）**：还未处理的元素

每一轮，从无序区拿出**第一个**元素，在有序区中找到它应该待的位置，把它插进去。这样，有序区就扩大了一个元素，无序区缩小了一个元素。

```
初始状态:   [5] [3, 8, 2, 7]
             ↑    ↑
          有序区  无序区

第1轮插入：拿出 3，插到 5 前面
           [3, 5] [8, 2, 7]
               ↑      ↑
            有序区扩大 无序区缩小

第2轮插入：拿出 8，插到 5 后面
           [3, 5, 8] [2, 7]
                  ↑      ↑

第3轮插入：拿出 2，插到最前面
           [2, 3, 5, 8] [7]
                     ↑    ↑

第4轮插入：拿出 7，插到 5 和 8 之间
           [2, 3, 5, 7, 8] []
                        ↑
                     全部有序！
```

### 三、"比较"与"移动"——插入排序的两个核心动作

插入排序的每一轮都包含两个关键动作：

**1. 比较（Compare）**：将当前元素 key 与有序区中的元素逐个比较，从右往左进行。

**2. 移动（Shift）**：如果有序区的元素比 key 大，就把它往右挪一个位置，为 key 腾出插入空间。

```
以数组 [3, 5, 9, 6, 1] 的第3轮为例（当前元素 key = 6，有序区为 [3, 5, 9]）：

有序区              无序区
[3,  5,  9]         [6,  1]
         ↑            ↑
        j=2         key=6

比较：arr[2]=9 > key=6  →  需要移动
移动：arr[3] = arr[2]   →  [3, 5, 9, 9, 1]
                                        ↑
                                    被覆盖的6已经保存在key中

j--，继续往前比较：arr[1]=5 < key=6  →  找到位置！
插入：arr[2] = key        →  [3, 5, 6, 9, 1]
```

### 四、完整排序过程演示

让我们用插入排序对数组 `[4, 3, 2, 1]` 进行完整排序：

```
初始: [4, 3, 2, 1]
       ↑
    有序区只有一个元素，天然有序

===== 第1轮：key = arr[1] = 3 =====
有序区 [4]，key=3
比较: 4 > 3  →  4右移  →  [4, 4, 2, 1]
j-- 超出边界  →  插入 key
结果: [3, 4, 2, 1]

===== 第2轮：key = arr[2] = 2 =====
有序区 [3, 4]，key=2
比较: 4 > 2  →  4右移  →  [3, 4, 4, 1]
比较: 3 > 2  →  3右移  →  [3, 3, 4, 1]
j-- 超出边界  →  插入 key
结果: [2, 3, 4, 1]

===== 第3轮：key = arr[3] = 1 =====
有序区 [2, 3, 4]，key=1
比较: 4 > 1  →  4右移  →  [2, 3, 4, 4]
比较: 3 > 1  →  3右移  →  [2, 3, 3, 4]
比较: 2 > 1  →  2右移  →  [2, 2, 3, 4]
j-- 超出边界  →  插入 key
结果: [1, 2, 3, 4]  ← 排序完成！
```

注意观察：这个例子恰好是最坏情况（完全逆序），每一轮都要把有序区所有元素向右移动。

### 五、为什么插入排序适合"部分有序"的数据？

插入排序有一个非常棒的特性：它天生就适合处理**已经基本有序**的数据。

原因有两点：

**1. 比较次数少**：如果数据已经基本有序，大多数元素在有序区中已经有正确的位置。元素 key 只需要和前面的几个元素比较，就能很快找到插入位置。

**2. 移动次数少**：找到位置后，需要向右移动的元素也很少（甚至是零个）。

```
请看这个例子：数组 [1, 2, 4, 3, 5]（只有一对"4, 3"位置不对）

第1轮：key=2，2>1，不需要移动 → 1次比较
第2轮：key=4，4>2，不需要移动 → 1次比较
第3轮：key=3，3<4，4右移；3>2，找到位置 → 2次比较，1次移动
第4轮：key=5，5>4，不需要移动 → 1次比较

总共只做了 5 次比较和 1 次移动！
```

相比之下，如果用冒泡排序处理同样的数据，需要多次遍历和交换，效率低很多。这就是为什么在很多实际场景中（比如数据库的增量排序、在线排序），插入排序是首选。

### 六、插入排序与冒泡排序、选择排序的对比

| 特性 | 冒泡排序 | 选择排序 | 插入排序 |
|------|---------|---------|---------|
| 核心操作 | 相邻交换 | 选择最小值 | 插入到正确位置 |
| 最好情况 | O(n) | O(n²) | O(n) |
| 平均情况 | O(n²) | O(n²) | O(n²) |
| 最坏情况 | O(n²) | O(n²) | O(n²) |
| 稳定性 | 稳定 | 不稳定 | 稳定 |
| 对部分有序数据 | 一般 | 差 | 非常好 |

从表格中可以看出，插入排序在三种基础排序中表现最为均衡，尤其对"部分有序"的数据有天然优势。

### 七、插入位置查找的优化——二分查找

在前面的实现中，我们在有序区中**从右往左线性扫描**来寻找插入位置。这个查找过程的时间复杂度是 O(n)。

因为有序区是已经排好序的，我们可以使用**二分查找**来加速寻找插入位置！二分查找的时间复杂度是 O(log n)。

但需要注意：二分查找虽然能快速找到位置，但插入时仍然需要移动元素（把插入位置及之后的元素都右移一格）。所以插入排序的整体时间复杂度仍然是 O(n²)，只是减少了比较次数。

```
有序区：          [2,   5,   8,   12,  15]
待插入 key = 9

二分查找过程:
left=0, right=4, mid=2, arr[2]=8 < 9  →  left = 3
left=3, right=4, mid=3, arr[3]=12 > 9 → right = 2
left > right，退出循环
插入位置 = left = 3

结果：[2, 5, 8, 9, 12, 15]
```

## 💻 代码实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

// =============================================
// 插入排序（基础版本）
// 参数：
//   arr[] - 待排序的整数数组
//   n     - 数组长度
// 说明：
//   从第1个元素开始（下标从0开始），每个元素向前插入到有序区
// =============================================
void insertionSort(int arr[], int n) {
    // 外层循环：从第2个元素开始（下标1），逐个取出作为"新摸的牌"
    for (int i = 1; i < n; i++) {
        int key = arr[i];   // 当前要插入的元素（就像新摸的牌）
        int j = i - 1;      // 从有序区的最后一个元素开始比较
        
        // 内层循环：在有序区中从右往左找位置
        // 如果有序区的元素比 key 大，就把它往右挪一位
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];  // 右移一位，腾出空间
            j--;                   // 继续往左比较
        }
        
        // 此时 j+1 就是 key 应该待的位置
        arr[j + 1] = key;  // 把"新牌"插入正确位置
    }
}
```

## 📊 复杂度分析

**时间复杂度：**
- 最好情况 O(n)：当数据已经有序时，每次 while 循环只比较一次（arr[j] <= key），不执行移动操作。总共 n-1 次比较。
- 最坏情况 O(n²)：当数据完全逆序时，每个元素都要一路"插"到最前面。第 i 个元素需要执行 i 次比较和 i 次移动。总操作次数约 n²/2。
- 平均情况 O(n²)：在随机数据下，平均每个元素需要移动约一半的有序区长度。

**空间复杂度：O(1)**
插入排序是**原地排序算法**，只需要一个临时变量 key 和几个循环变量，不需要额外的数组。

**稳定性：**
插入排序是**稳定**的排序算法。因为当 arr[j] == key 时，while 条件 arr[j] > key 不成立，key 会被放在 arr[j] 的右边，不会改变相等元素的原始顺序。

## 🏋️ 经典例题

### 例题1：插入位置查找

**题目描述**：给定一个已从小到大排好序的数组（不含重复元素）和一个待插入的数 x，请找出 x 应该插入的位置（下标从 0 开始），使插入后数组仍然有序。

**输入格式**：第一行一个整数 n（1 ≤ n ≤ 100）。第二行 n 个已排序的整数。第三行一个整数 x。

**输出格式**：一个整数，表示 x 应该插入的位置下标。

**样例输入**：
```
5
1 3 5 7 9
6
```

**样例输出**：
```
3
```

**样例解释**：6 介于 5（下标 2）和 7（下标 3）之间，应该插入下标 3 的位置，使数组变为 [1, 3, 5, 6, 7, 9]。

**题解代码（线性查找）**：
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, x;
    int arr[105];  // 多开5个位置，防止越界
    
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }
    cin >> x;
    
    // 线性查找：从左往右找到第一个大于等于 x 的位置
    int pos = n;  // 默认插在末尾
    for (int i = 0; i < n; i++) {
        if (arr[i] >= x) {
            pos = i;
            break;
        }
    }
    
    cout << pos << endl;
    return 0;
}
```

**题解代码（二分查找）**：
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, x;
    int arr[105];
    
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }
    cin >> x;
    
    // 二分查找：在有序数组中找第一个 >= x 的位置
    int left = 0, right = n - 1;
    int pos = n;  // 如果所有元素都 < x，则插在末尾
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] >= x) {
            pos = mid;      // 更新答案
            right = mid - 1; // 继续往左找，看有没有更靠前的位置
        } else {
            left = mid + 1;
        }
    }
    
    cout << pos << endl;
    return 0;
}
```

### 例题2：部分有序排序

**题目描述**：给定一个已经"几乎有序"的整数序列（每个元素离它最终位置不超过 k），使用插入排序将其完全排序，并输出排序后的序列。

**输入格式**：第一行两个整数 n 和 k（1 ≤ n ≤ 1000，1 ≤ k ≤ 10）。第二行 n 个整数。

**输出格式**：一行 n 个整数，排序后的序列，用空格分隔。

**样例输入**：
```
6 2
2 1 4 3 6 5
```

**样例输出**：
```
1 2 3 4 5 6
```

**样例解释**：原始数组 [2, 1, 4, 3, 6, 5] 中，每个元素离它最终位置的距离都不超过 2（例如 2 应该在位置 1，在位置 0，距离为 1），是一个"几乎有序"的序列。插入排序可以高效地完成排序。

**题解代码**：
```cpp
#include <iostream>
using namespace std;

int main() {
    int n, k;
    int arr[1005];
    
    cin >> n >> k;
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }
    
    // 插入排序：对"几乎有序"的数据天然高效
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        
        // 因为每个元素离最终位置不超过 k，
        // 所以最多只需要往前找 k 个位置
        // 但为了代码的通用性，我们仍然写完整的 while 循环
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
    
    for (int i = 0; i < n; i++) {
        cout << arr[i];
        if (i < n - 1) cout << " ";
    }
    cout << endl;
    
    return 0;
}
```

**思路分析**：本题的 k 告诉我们每个元素离最终位置不超过 k，这意味着内层 while 循环平均每轮只需要执行大约 k 次比较和移动。由于 k 很小（≤ 10），实际上排序效率极高，接近 O(n) 级别。这正是插入排序在"几乎有序"数据上的优势体现。

#### 挑战题 参考代码
```cpp
#include <iostream>
using namespace std;

// 二分查找：在已排序区间 [0, end] 中找到 key 应该插入的位置
int binarySearch(int arr[], int key, int end) {
    int left = 0, right = end;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] <= key)
            left = mid + 1;
        else
            right = mid - 1;
    }
    return left;  // 插入位置
}

void binaryInsertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        // 用二分查找找到插入位置
        int pos = binarySearch(arr, key, i - 1);
        
        // 将 [pos, i-1] 的元素右移
        for (int j = i - 1; j >= pos; j--) {
            arr[j + 1] = arr[j];
        }
        arr[pos] = key;
    }
}

int main() {
    int n, arr[1005];
    cin >> n;
    for (int i = 0; i < n; i++) cin >> arr[i];
    
    binaryInsertionSort(arr, n);
    
    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << arr[i];
    }
    cout << endl;
    return 0;
}
```

## 📝 本课小结

本节课我们学习了插入排序算法，它的核心思想就像整理手中的扑克牌——每次拿起一张新牌，在已经排好序的牌中找到它应该存放的位置，然后插进去。插入排序将数组分为"有序区"和"无序区"，每一轮从无序区取出一个元素，经过"比较"和"移动"两个步骤，将它插入到有序区的正确位置，使有序区不断扩张，最终覆盖整个数组。

插入排序的时间复杂度为 O(n²)，但最好情况（数据已有序）只需 O(n)。它最大的亮点是对"几乎有序"的数据效率极高，因为此时大多数元素只需要很少的比较和移动。插入排序是稳定的原地排序算法，空间复杂度仅为 O(1)。

本课还介绍了用二分查找优化插入位置搜索的方法，但需要注意这只能减少比较次数，移动元素的开销依然存在。下一课我们将学习快速排序——一种基于分治思想的高效排序算法。
