## 🎯学习目标

2. **能够独立实现快速幂算法**：分别使用递归和迭代两种方式编写完整的快速幂代码，并结合取模运算解决大数溢出问题。
3. **初步了解矩阵快速幂**：认识矩阵乘法和矩阵快速幂，能够用矩阵快速幂在 $O(\log n)$ 时间内求解斐波那契数列第 $n$ 项。

## 📖算法讲解

### 一、为什么需要快速幂？

在编程竞赛和实际应用中，我们经常会遇到这样的问题：计算 $a^b$，其中 $b$ 可能非常大。例如计算 $2^{100}$ 或者 $3^{100000}$。

如果我们用最朴素的方法——连乘 $b$ 次：

```
int result = 1;
for (int i = 1; i <= b; i++) {
    result = result * a;
}
```

这个方法需要进行 $b$ 次乘法运算。当 $b = 10^9$ 时，程序可能需要运行几十秒甚至更久，这在竞赛中是绝对不能接受的。更糟糕的是，$a^b$ 的数值会以指数的速度增长，很快超出 `int` 甚至 `long long` 的表示范围，导致溢出。

因此，我们需要一种**既快又不溢出**的计算方法，这就是快速幂算法。

### 二、核心思想：二分幂（分治策略）

快速幂的核心思想非常优雅，它利用了指数运算的一个基本性质：

**当 $b$ 是偶数时：**
$$a^b = a^{b/2} \times a^{b/2} = (a^{b/2})^2$$

**当 $b$ 是奇数时：**
$$a^b = a \times a^{b-1} = a \times (a^{(b-1)/2})^2$$

这意味着我们只需要计算一次 $a^{b/2}$，然后把它平方即可！问题的规模从 $b$ 一下子缩小到了 $b/2$。

用 ASCII 图来直观理解这个分治过程，以计算 $a^{13}$ 为例：

```
                     a^13
                      |
               +------+------+
               |             |
           a * a^12       (b=13 是奇数，拆出一个 a)
               |
            (a^6)^2        (b=12 是偶数，平方)
               |
            (a^3)^2        (b=6 是偶数，平方)
               |
         +----+----+
         |         |
     a * a^2     (b=3 是奇数，拆出一个 a)
         |
      (a^1)^2    (b=2 是偶数，平方)
         |
         a        (b=1，递归终点)

回溯计算：
  a^1 = a
  a^2 = (a^1)^2 = a^2          → 第1次乘法（平方）
  a^3 = a * a^2 = a^3          → 第2次乘法
  a^6 = (a^3)^2 = a^6          → 第3次乘法（平方）
  a^12 = (a^6)^2 = a^12        → 第4次乘法（平方）
  a^13 = a * a^12 = a^13       → 第5次乘法

朴素的连乘法：需要 12 次乘法
快速幂方法：   只需要 5 次乘法！
```

随着 $b$ 越来越大，这个优势会越来越明显。比如 $b = 10^9$ 时，朴素法需要 $10^9$ 次运算，而快速幂只需要大约 $log_2(10^9) \approx 30$ 次运算！

### 三、结合取模运算防止溢出

在实际问题中，我们往往不需要 $a^b$ 的完整数值，而是需要 $a^b \bmod m$ 的结果。利用模运算的一个重要性质：

$$(a \times b) \bmod m = ((a \bmod m) \times (b \bmod m)) \bmod m$$

也就是说，我们可以在每一步乘法之后立即取模，这样就永远不会产生超过 $m^2$ 的数，彻底解决了溢出问题。在 C++ 中，只要 $m$ 不超过 $10^9$，使用 `long long` 存放中间结果就完全安全。

### 四、快速幂的两种实现方式

**递归实现**非常直观，直接按照数学定义编写：

```
如果 b == 0，返回 1
如果 b 是奇数，返回 a * pow(a, b-1) % mod
如果 b 是偶数，令 half = pow(a, b/2)，返回 half * half % mod
```

递归的优点是思路清晰，易于理解；缺点是递归调用会产生额外的函数调用开销。

**迭代实现**从二进制角度思考，更加高效：

将指数 $b$ 写成二进制形式。比如 $b = 13 = 1101_2$：

$$a^{13} = a^{8+4+1} = a^8 \times a^4 \times a^1$$

代码中，我们不断将底数平方（$a \to a^2 \to a^4 \to a^8$），同时检查 $b$ 的二进制最低位，如果为 1 就将当前底数乘入结果。迭代实现是竞赛中最常用的版本。

### 五、矩阵快速幂简介

快速幂的思想不仅适用于普通数字，还可以推广到矩阵。矩阵也可以做乘法和幂运算，而且具有结合律：

$$M^n = \begin{cases} I & (n = 0) \\ M \times (M^2)^{(n-1)/2} & (n \text{ 为奇数}) \\ (M^2)^{n/2} & (n \text{ 为偶数}) \end{cases}$$

其中 $I$ 是单位矩阵（类似数字中的 1）。矩阵快速幂最经典的应用就是**在 $O(\log n)$ 时间内求解斐波那契数列第 $n$ 项**。

斐波那契数列的定义是 $F_1 = 1, F_2 = 1, F_n = F_{n-1} + F_{n-2}$。可以证明：

$$\begin{bmatrix} F_n \\ F_{n-1} \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^{n-1} \times \begin{bmatrix} F_1 \\ F_0 \end{bmatrix}$$

右边那个 $\begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}$ 的 $n-1$ 次幂，就用快速幂来计算。这样，原本需要 $O(n)$ 时间的斐波那契问题，直接优化到了 $O(\log n)$！

## 💻代码实现

### 递归实现（带取模）

```cpp
#include <iostream>
using namespace std;

typedef long long ll;

// 快速幂递归实现：计算 (a^b) % mod
ll fastPowRecursive(ll a, ll b, ll mod) {
    // 基础情况：任何数的 0 次幂都是 1
    if (b == 0) return 1 % mod;
    
    // 在递归之前先对 a 取模，防止后续乘法溢出
    a %= mod;
    
    // 计算 a^(b/2) % mod
    ll half = fastPowRecursive(a, b / 2, mod);
    
    // half * half 就是 a^((b/2)*2) = a^(b - b%2)
    ll result = (half * half) % mod;
    
    // 如果 b 是奇数，还需要额外乘以一个 a
    if (b % 2 == 1) {
        result = (result * a) % mod;
    }
    
    return result;
}
```

### 迭代实现（竞赛常用版本）

```cpp
// 快速幂迭代实现：计算 (a^b) % mod
// 核心思路：将 b 按二进制拆解，从低位到高位逐位处理
ll fastPowIterative(ll a, ll b, ll mod) {
    // 结果初始化为 1（乘法的单位元）
    ll result = 1 % mod;
    
    // 先对底数取模，缩小数值范围
    a %= mod;
    
    // 当指数 b 还不为 0，继续处理
    while (b > 0) {
        // 如果当前二进制最低位是 1，
        // 说明这一位的"权重"需要乘入结果
        if (b & 1) {  // 等价于 b % 2 == 1
            result = (result * a) % mod;
        }
        
        // 底数平方，对应当前位的权重翻倍
        // a^1 -> a^2 -> a^4 -> a^8 -> ...
        a = (a * a) % mod;
        
        // 指数右移一位（去掉已处理的最低位）
        b >>= 1;  // 等价于 b /= 2
    }
    
    return result;
}
```

### main 函数测试

```cpp
int main() {
    ll a = 2, b = 10, mod = 1000000007;
    
    cout << "递归实现: " << a << "^" << b << " mod " << mod 
         << " = " << fastPowRecursive(a, b, mod) << endl;
    
    cout << "迭代实现: " << a << "^" << b << " mod " << mod 
         << " = " << fastPowIterative(a, b, mod) << endl;
    
    return 0;
}
```

## 📊复杂度分析

### 朴素算法 vs 快速幂

| 对比维度 | 朴素算法 (连乘) | 快速幂 |
|---------|----------------|--------|
| **时间复杂度** | $O(b)$ 或 $O(n)$ | $O(\log b)$ 或 $O(\log n)$ |
| **乘法次数** (b=10^9) | 约为 $10^9$ 次 | 约 30 次 |
| **空间复杂度** | $O(1)$ | $O(1)$（迭代）/ $O(\log b)$（递归） |
| **是否会溢出** | 中间结果极易溢出 | 结合取模，完全可控 |
| **适用 $b$ 的范围** | $b \le 10^7$ 勉强可用 | $b \le 10^{18}$ 轻松应对 |

### 为什么从 $O(n)$ 降到了 $O(\log n)$？

快速幂的本质是**每次将问题规模减半**。假设 $b$ 的二进制有 $k$ 位，则 $2^{k-1} \le b < 2^k$，所以 $k = \lceil \log_2 b \rceil = O(\log b)$。

- 迭代版本：`while` 循环恰好执行 $k$ 次（每次右移一位）。
- 递归版本：递归深度为 $k$ 层（每次除以 2）。

每次循环（或每层递归）只做常数次乘法取模操作，因此总时间复杂度为 $O(\log b)$。

### 以具体数字感受差距

| 指数 $b$ | 朴素法乘法次数 | 快速幂乘法次数 | 加速倍数 |
|-----------|--------------|--------------|---------|
| 100 | 100 | ~7 | ~14x |
| 10,000 | 10,000 | ~14 | ~714x |
| 1,000,000 | 1,000,000 | ~20 | ~50,000x |
| 1,000,000,000 | 1,000,000,000 | ~30 | ~33,000,000x |

可以看到，随着 $b$ 增大，朴素法完全不可行，而快速幂轻松应对。

## 🏋️经典例题

### 例题 1：a^b mod m（快速幂取模）

**题目描述**

给定三个正整数 $a$、$b$、$m$，计算 $a^b \bmod m$ 的值。

数据范围：$1 \le a \le 10^9$，$0 \le b \le 10^{18}$，$1 \le m \le 10^9$。

**输入格式**

一行三个整数 $a, b, m$，以空格分隔。

**输出格式**

一个整数，表示 $a^b \bmod m$ 的结果。

**样例输入 1**

```
2 10 1000
```

**样例输出 1**

```
24
```

**样例解释**：$2^{10} = 1024$，$1024 \bmod 1000 = 24$。

**样例输入 2**

```
7 0 100
```

**样例输出 2**

```
1
```

**样例解释**：任何正整数的 $0$ 次幂结果都为 $1$，$1 \bmod 100 = 1$。

**解题思路**

本题是快速幂的模板题，直接套用前面介绍的迭代版快速幂即可。需要注意两点：

1. **指数 $b$ 的范围达到 $10^{18}$**，所以必须用 `long long` 类型存储。并且朴素算法完全不可行——$10^{18}$ 次循环在宇宙毁灭前都跑不完，而快速幂只需要大约 60 次循环。
2. **底数 $a$ 也需要先取模**，即 `a %= m`，这样可以防止后续的乘法溢出。因为 `long long` 能安全存放的最大值约为 $9 \times 10^{18}$，如果 $a$ 和 $m$ 都接近 $10^9$，`a * a` 就会接近 $10^{18}$，在我们取模前勉强安全。但 `(a % m) * (a % m)` 在 $m \le 10^9$ 时最大只有 $10^{18}$，依然在 `long long` 范围内。

**核心代码**

```cpp
#include <iostream>
using namespace std;

typedef long long ll;

ll fastPow(ll a, ll b, ll mod) {
    ll result = 1 % mod;   // 处理 mod = 1 的特殊情况
    a %= mod;              // 底数先取模，防止溢出
    
    while (b > 0) {
        if (b & 1) {       // 当前二进制位为 1
            result = (result * a) % mod;
        }
        a = (a * a) % mod; // 底数平方
        b >>= 1;           // 指数右移
    }
    
    return result;
}

int main() {
    ll a, b, m;
    cin >> a >> b >> m;
    
    cout << fastPow(a, b, m) << endl;
    
    return 0;
}
```

### 例题 2：斐波那契第 n 项（矩阵快速幂入门）

**题目描述**

斐波那契数列的定义如下：

$$F_1 = 1, \quad F_2 = 1, \quad F_n = F_{n-1} + F_{n-2} \quad (n \ge 3)$$

给定正整数 $n$，求 $F_n \bmod (10^9 + 7)$。

数据范围：$1 \le n \le 10^{18}$。

**输入格式**

一个正整数 $n$。

**输出格式**

一个整数，表示 $F_n \bmod (10^9 + 7)$ 的结果。

**样例输入 1**

```
5
```

**样例输出 1**

```
5
```

**样例解释**：$F_1=1, F_2=1, F_3=2, F_4=3, F_5=5$。

**样例输入 2**

```
1000000000000000000
```

**样例输出 2**

```
209783453
```

**解题思路**

当 $n$ 达到 $10^{18}$ 时，递推 $O(n)$ 的做法完全行不通。这时就需要用到**矩阵快速幂**。

斐波那契数列有一个经典的矩阵表示。定义转移矩阵 $T = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}$，则有：

$$\begin{bmatrix} F_{k+1} \\ F_k \end{bmatrix} = T \times \begin{bmatrix} F_k \\ F_{k-1} \end{bmatrix}$$

反复应用这个关系：

$$\begin{bmatrix} F_n \\ F_{n-1} \end{bmatrix} = T^{n-1} \times \begin{bmatrix} F_1 \\ F_0 \end{bmatrix}$$

其中 $F_0 = 0, F_1 = 1$。这样，求 $F_n$ 就转化成了求矩阵 $T$ 的 $n-1$ 次幂——这正是快速幂的用武之地！

**2x2 矩阵乘法公式**

设 $C = A \times B$（均为 2x2 矩阵），则：

$$\begin{bmatrix} c_{11} & c_{12} \\ c_{21} & c_{22} \end{bmatrix} = \begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix} \times \begin{bmatrix} b_{11} & b_{12} \\ b_{21} & b_{22} \end{bmatrix}$$

其中：
- $c_{11} = (a_{11} \times b_{11} + a_{12} \times b_{21}) \bmod M$
- $c_{12} = (a_{11} \times b_{12} + a_{12} \times b_{22}) \bmod M$
- $c_{21} = (a_{21} \times b_{11} + a_{22} \times b_{21}) \bmod M$
- $c_{22} = (a_{21} \times b_{12} + a_{22} \times b_{22}) \bmod M$

**计算流程**

1. 如果 $n \le 1$，直接返回 $n$（因为 $F_0 = 0, F_1 = 1$）。
2. 构造转移矩阵 $T$ 和单位矩阵 $I$。
3. 对 $T$ 做 $n-1$ 次“矩阵快速幂”，步骤与数字快速幂完全一致，只是把数字乘法替换为矩阵乘法，把“1”替换为单位矩阵 $I$。
4. 结果矩阵的 $c_{11}$ 位置（即第一行第一列）就是 $F_n$。

**核心代码**

```cpp
#include <iostream>
#include <vector>
using namespace std;

typedef long long ll;
const ll MOD = 1000000007;

// 2x2 矩阵结构体
struct Matrix {
    ll m[2][2];
    
    // 构造函数：初始化为全 0
    Matrix() {
        m[0][0] = m[0][1] = m[1][0] = m[1][1] = 0;
    }
    
    // 初始化为给定值
    Matrix(ll a, ll b, ll c, ll d) {
        m[0][0] = a; m[0][1] = b;
        m[1][0] = c; m[1][1] = d;
    }
};

// 2x2 矩阵乘法（带取模）
Matrix multiply(Matrix A, Matrix B) {
    Matrix C;
    C.m[0][0] = (A.m[0][0] * B.m[0][0] + A.m[0][1] * B.m[1][0]) % MOD;
    C.m[0][1] = (A.m[0][0] * B.m[0][1] + A.m[0][1] * B.m[1][1]) % MOD;
    C.m[1][0] = (A.m[1][0] * B.m[0][0] + A.m[1][1] * B.m[1][0]) % MOD;
    C.m[1][1] = (A.m[1][0] * B.m[0][1] + A.m[1][1] * B.m[1][1]) % MOD;
    return C;
}

// 矩阵快速幂
Matrix matrixPow(Matrix base, ll exp) {
    // 单位矩阵（相当于数字 1）
    Matrix result(1, 0, 0, 1);
    
    while (exp > 0) {
        if (exp & 1) {
            result = multiply(result, base);
        }
        base = multiply(base, base);
        exp >>= 1;
    }
    
    return result;
}

// 求斐波那契数列第 n 项
ll fibonacci(ll n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    
    // 转移矩阵 T = [[1, 1], [1, 0]]
    Matrix T(1, 1, 1, 0);
    
    // 计算 T^(n-1)
    Matrix result = matrixPow(T, n - 1);
    
    // F_n = result[0][0] * F_1 + result[0][1] * F_0 = result[0][0]
    return result.m[0][0];
}

int main() {
    ll n;
    cin >> n;
    
    cout << fibonacci(n) << endl;
    
    return 0;
}
```

typedef long long ll;

// 练习1：快速幂取模
ll fastPow(ll a, ll b, ll mod) {
    ll result = 1 % mod;
    a %= mod;
    while (b > 0) {
        if (b & 1) result = (result * a) % mod;
        a = (a * a) % mod;
        b >>= 1;
    }
    return result;
}

// 练习2：个位数快速幂（即 mod 10）
ll lastDigit(ll a, ll b) {
    return fastPow(a % 10, b, 10);
}

// 练习3：最后三位（mod 1000）
ll lastThreeDigits(ll a, ll b) {
    return fastPow(a % 1000, b, 1000);
}

// 练习5：矩阵快速幂求斐波那契
const ll MOD = 1000000007;

struct Matrix {
    ll m[2][2];
    Matrix() { m[0][0] = m[0][1] = m[1][0] = m[1][1] = 0; }
    Matrix(ll a, ll b, ll c, ll d) {
        m[0][0] = a; m[0][1] = b;
        m[1][0] = c; m[1][1] = d;
    }
};

Matrix multiply(Matrix A, Matrix B) {
    Matrix C;
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++)
            for (int k = 0; k < 2; k++)
                C.m[i][j] = (C.m[i][j] + A.m[i][k] * B.m[k][j]) % MOD;
    return C;
}

Matrix matrixPow(Matrix base, ll exp) {
    Matrix result(1, 0, 0, 1);  // 单位矩阵
    while (exp > 0) {
        if (exp & 1) result = multiply(result, base);
        base = multiply(base, base);
        exp >>= 1;
    }
    return result;
}

ll fibonacci(ll n) {
    if (n <= 1) return n;
    Matrix T(1, 1, 1, 0);
    Matrix result = matrixPow(T, n - 1);
    return result.m[0][0];
}

int main() {
    cout << "练习1: 2^10 mod 1000 = " << fastPow(2, 10, 1000) << endl;  // 24
    cout << "练习2: 7^100 个位数 = " << lastDigit(7, 100) << endl;       // 1
    cout << "练习3: 2^10 最后三位 = " << lastThreeDigits(2, 10) << endl; // 24
    cout << "练习5: fib(10) = " << fibonacci(10) << endl;               // 55
    return 0;
}

## 📝本课小结

本节课我们学习了一个非常重要的算法——**快速幂**。它的核心思想是**分治**：将求 $a^b$ 的问题不断折半，每次只需计算 $a^{b/2}$ 然后平方，从而使时间复杂度从 $O(b)$ 骤降到 $O(\log b)$。对于 $b = 10^{18}$ 这样的大指数，朴素算法需要天文数字般的运算次数，而快速幂只需要大约 60 次循环就能完成计算。

在实际编程中，我们通常会结合**取模运算**来防止数值溢出。模运算的性质 $(a \times b) \bmod m = ((a \bmod m) \times (b \bmod m)) \bmod m$ 使得我们可以在每一步乘法后立即取模，确保所有中间结果都不会超出 `long long` 的范围。

快速幂有两种实现方式：**递归实现**思路直观、代码与数学定义高度一致，适合初学理解；**迭代实现**（二进制分解法）更加高效稳定，是竞赛中的首选写法。建议大家两种都掌握——递归帮助理解思想，迭代用于实际编码。

最后，我们学习了快速幂的一个重要推广——**矩阵快速幂**。通过将斐波那契数列的递推关系转化为矩阵乘法形式，我们得以用 $O(\log n)$ 的时间求解第 $n$ 项斐波那契数。矩阵快速幂的思想在动态规划加速、图论（求两点间经过恰好 $k$ 条边的最短路径）等领域都有广泛应用，是算法进阶的必学内容。

**重点回顾**：
- 快速幂的时间复杂度是 $O(\log b)$，空间复杂度 $O(1)$（迭代）。
- 记住取模的步骤：底数先取模，每次乘法后立即取模。
- 矩阵快速幂 = 快速幂 + 矩阵乘法，关键是把转移矩阵和单位矩阵定义好。
