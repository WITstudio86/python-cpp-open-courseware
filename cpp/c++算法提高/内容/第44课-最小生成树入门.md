# 第44课：最小生成树入门

## 🎯 学习目标

- 理解**最小生成树（MST）**的概念：在一个连通图中，找出连接所有顶点的、边权总和最小的树
- 掌握 **Prim 算法**——从任意节点出发，每次将距离已有树「最近」的新节点加入树中，逐步扩展
- 掌握 **Kruskal 算法**——将所有边按权值排序，在**并查集（Union-Find）**的帮助下，贪心地选取不会形成环的边

---

## 📖 算法讲解

### 什么是「最小生成树」？

假设你是一个工程师，负责修建道路连接 N 个村庄，每两个村庄之间修路的成本不同。你的目标是**让所有村庄互通**（形成一个连通图），但**总花费最小**。你会怎么选路呢？

这就是**最小生成树（Minimum Spanning Tree, MST）**问题：
- **生成树（Spanning Tree）**：包含原图中所有 N 个顶点、且仅有 N-1 条边的一个连通子图（恰好是一棵树）
- **最小生成树（MST）**：所有生成树中，边的权值总和最小的那一棵

```
原图（含所有可能的道路及其成本）：
        [A]
       / | \
    (2)/  |  \(5)
     /    |    \
  [B]---(3)---[C]
    \    |    /
  (4)\   |  /(1)
      \  | /
       [D]

MST 的选择（总成本 = 2 + 3 + 1 = 6）：
        [A]
       /
    (2)/
     /
  [B]---(3)---[C]
                \
                 \(1)
                  \
                  [D]

被舍弃的边：A-C(5)、B-D(4) —— 选了它们总成本会变大！
```

**MST 的核心性质**：
1. N 个节点的生成树恰好有 **N - 1** 条边
2. MST 中任意两点之间的路径是唯一的（因为它是树）
3. 如果原图不连通，则不存在生成树

---

### Prim 算法（加点法）

> **核心思想**：从一个起点出发，维护一个「已加入 MST 的节点集合」。每一步选择一条连接「已加入」和「未加入」节点的、权值最小的边，把这条边另一端的节点加入集合。重复直到所有节点都加入。

**Prim 算法步骤演示：**

```
初始图（邻接矩阵表示，∞ 表示无边）：
     A   B   C   D
  A  0   2   5   4
  B  2   0   3   ∞
  C  5   3   0   1
  D  4   ∞   1   0

Step 1: 从节点 A 开始（已加入集合 = {A}）
  候选边：A-B(2), A-C(5), A-D(4)
  选最小的：A-B(2)  →  加入节点 B！已加入 = {A, B}

Step 2: 已加入 = {A, B}，未加入 = {C, D}
  候选边：A-C(5), A-D(4), B-C(3)
  选最小的：B-C(3)  →  加入节点 C！已加入 = {A, B, C}
  注意：A-C 权值为 5 > B-C 的 3，所以选 B-C

Step 3: 已加入 = {A, B, C}，未加入 = {D}
  候选边：A-D(4), C-D(1)
  选最小的：C-D(1)  →  加入节点 D！已加入 = {A, B, C, D}

MST 构建完毕！选中的边：A-B(2), B-C(3), C-D(1)
总权值：2 + 3 + 1 = 6
```

**Prim 算法可以这样理解**：就像一棵小树苗，每次从「树」的边缘向外找一条最短的枝干，让小树慢慢生长，直到覆盖所有节点。

---

### Kruskal 算法（加边法）

> **核心思想**：将所有边按权值从小到大排序。按顺序依次考虑每条边：如果这条边连接的两个节点**不在同一个连通分量**中（即加入不会形成环），就把它加入 MST。重复直到选够 N-1 条边。

**Kruskal 算法步骤演示：**

```
原图各边按权值排序：
  C-D(1), A-B(2), B-C(3), A-D(4), A-C(5)

并查集初始状态：每个节点自成一个集合
  A: {A}  B: {B}  C: {C}  D: {D}

Step 1: 考虑边 C-D(1)
  C 和 D 不在同一集合 → 选中！合并集合 {C} ∪ {D} = {C, D}
  已选边数：1/3，已选：C-D

Step 2: 考虑边 A-B(2)
  A 和 B 不在同一集合 → 选中！合并 {A} ∪ {B} = {A, B}
  已选边数：2/3，已选：C-D, A-B

Step 3: 考虑边 B-C(3)
  B 在集合 {A, B}，C 在集合 {C, D} → 不在同一集合 → 选中！
  合并 {A, B} ∪ {C, D} = {A, B, C, D}
  已选边数：3/3 ✓ MST 已构建完毕！

Step 4: 考虑边 A-D(4)
  A 和 D 已在同一集合 {A, B, C, D} → 跳过！（会形成环）
  已选边数已达到 N-1 = 3，算法结束。

最终 MST：C-D(1), A-B(2), B-C(3) → 总权值 = 6
（与 Prim 算法结果完全一致！）
```

> **并查集（Union-Find）** 是 Kruskal 算法的关键数据结构，它支持两个操作：
> - **Find(x)**：找出 x 所在的集合（找祖宗）
> - **Union(x, y)**：把 x 和 y 所在的集合合并
> 通过**路径压缩 + 按秩合并**优化，这两个操作几乎都是 O(1)！

## 💻 代码实现

### Prim 算法（邻接矩阵实现）

```cpp
#include <iostream>
#include <cstring>
using namespace std;
const int MAXN = 105, INF = 0x3f3f3f3f;

int g[MAXN][MAXN];   // 邻接矩阵
int dis[MAXN];       // dis[i]：节点 i 到当前 MST 的最短距离
bool inMST[MAXN];    // inMST[i]：节点 i 是否已加入 MST
int n, m;

int prim() {
    memset(dis, 0x3f, sizeof(dis));
    memset(inMST, 0, sizeof(inMST));
    dis[1] = 0;  // 从节点 1 开始
    int total = 0;

    for (int i = 1; i <= n; i++) {
        // 选出距离 MST 最近的节点
        int u = -1, minD = INF;
        for (int j = 1; j <= n; j++)
            if (!inMST[j] && dis[j] < minD)
                minD = dis[j], u = j;

        if (u == -1) return -1;  // 图不连通

        inMST[u] = true;          // 加入 MST
        total += dis[u];          // 累加权值

        // 用新加入的节点 u 更新邻居到 MST 的距离
        for (int v = 1; v <= n; v++)
            if (!inMST[v] && g[u][v] < dis[v])
                dis[v] = g[u][v];
    }
    return total;
}
```

### Kruskal 算法（并查集 + 边排序）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;
const int MAXN = 105, MAXM = 10005;

struct Edge {
    int u, v, w;
    bool operator<(const Edge& other) const {
        return w < other.w;  // 按权值升序排序
    }
} edges[MAXM];

int parent[MAXN];  // 并查集父节点数组
int n, m;

// 并查集：查找（带路径压缩）
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 路径压缩
    return parent[x];
}

// 并查集：合并
bool unite(int a, int b) {
    int ra = find(a), rb = find(b);
    if (ra == rb) return false;  // 已在同一集合
    parent[ra] = rb;
    return true;
}

int kruskal() {
    // 1. 初始化并查集
    for (int i = 1; i <= n; i++) parent[i] = i;

    // 2. 按权值排序
    sort(edges, edges + m);

    // 3. 贪心选边
    int total = 0, cnt = 0;  // cnt：已选边数
    for (int i = 0; i < m; i++) {
        if (unite(edges[i].u, edges[i].v)) {
            total += edges[i].w;
            cnt++;
            if (cnt == n - 1) break;  // 已选够 N-1 条边
        }
    }
    return (cnt == n - 1) ? total : -1;  // -1 表示图不连通
}
```

## 📊 复杂度分析

| 算法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|---------|
| **Prim**（邻接矩阵） | O(V²) | O(V²) | 稠密图（边较多），V ≤ 5000 |
| **Prim**（优先队列） | O(E log V) | O(V+E) | 稀疏图 |
| **Kruskal**（排序+并查集） | O(E log E) | O(V+E) | 稀疏图，E 不太大 |

> **V = 顶点数，E = 边数**

- Prim 适用场景：图比较「稠密」（边多），尤其是邻接矩阵存图的情况。每次找最近节点 O(V)，V 次循环，总共 O(V²)。
- Kruskal 适用场景：图比较「稀疏」（边少）。排序占主导 O(E log E)，并查集操作几乎 O(1)。如果 E ≈ V（稀疏图），Kruskal 非常高效。
- 两种算法都能正确求出 MST。一般「边少用 Kruskal，点多边多用 Prim」。

## 🏋️ 经典例题

### 例题1：修路问题（Prim 算法）

#### 题目描述

某地区有 N 个村庄（编号 1 到 N），政府计划修建道路使所有村庄连通。已知在村庄 i 和村庄 j 之间修路的成本为 w。请计算使所有村庄连通的最少总成本。如果无法使所有村庄连通（即图不连通），则输出 -1。

#### 输入格式

```
第一行：两个整数 N, M（1 ≤ N ≤ 100，1 ≤ M ≤ N*(N-1)/2）
接下来 M 行：每行三个整数 u, v, w（1 ≤ u, v ≤ N，1 ≤ w ≤ 10000），
表示在村庄 u 和 v 之间修路的成本为 w。
```

#### 输出格式

```
一个整数：使所有村庄连通的最小总成本。若不连通则输出 -1。
```

#### 样例输入

```
4 5
1 2 2
1 3 3
1 4 4
2 3 1
3 4 5
```

#### 样例输出

```
7
```

#### 样例解释

```
4 个村庄，可选道路有 5 条。MST 选择：
  边 2-3（成本 1）
  边 1-2（成本 2）
  边 1-4（成本 4）
总成本 = 1 + 2 + 4 = 7

验证：是否连通？1-2, 2-3, 1-4 → 全部连通 ✓
条数？3 = N-1 = 3 ✓
是否最小？试着换一条：如果选 3-4(5) 替代 1-4(4)，成本变大，证明确实最小。
```

#### 参考代码

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 105, INF = 0x3f3f3f3f;
int g[MAXN][MAXN], dis[MAXN];
bool inMST[MAXN];
int n, m;

int prim() {
    memset(dis, 0x3f, sizeof(dis));
    memset(inMST, 0, sizeof(inMST));
    dis[1] = 0;
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        int u = -1, md = INF;
        for (int j = 1; j <= n; j++)
            if (!inMST[j] && dis[j] < md) md = dis[j], u = j;
        if (u == -1) return -1;
        inMST[u] = true;
        ans += dis[u];
        for (int v = 1; v <= n; v++)
            if (!inMST[v] && g[u][v] < dis[v])
                dis[v] = g[u][v];
    }
    return ans;
}

int main() {
    memset(g, 0x3f, sizeof(g));
    cin >> n >> m;
    for (int i = 1; i <= m; i++) {
        int u, v, w; cin >> u >> v >> w;
        if (w < g[u][v]) g[u][v] = g[v][u] = w;
    }
    cout << prim() << endl;
    return 0;
}
```

### 例题2：连接所有城市（Kruskal 算法）

#### 题目描述

一个王国有 N 座城市，国王想用光纤网络连接所有城市。测量队给出了 M 条可行的光纤铺设线路，每条线路连接两座城市，铺设成本不同。请你帮国王算出连接所有城市的最小成本，并输出选中的线路。如果无法全部连通，输出 -1。

#### 输入格式

```
第一行：两个整数 N, M（1 ≤ N ≤ 100，1 ≤ M ≤ 1000）
接下来 M 行：每行三个整数 u, v, w，表示在城市 u 和 v 之间铺设光纤的成本为 w。
```

#### 输出格式

```
第一行：一个整数，最小总成本（若无法连通输出 -1）
如果存在解，接下来 N-1 行，每行两个整数，表示选中的 M 条边中每条边连接的两个城市（顺序任意）。
```

#### 样例输入

```
5 7
1 2 3
1 4 5
2 3 1
2 4 2
3 4 4
3 5 6
4 5 7
```

#### 样例输出

```
16
2 3
2 4
1 2
3 5
```

#### 样例解释

```
MST 选择过程（按权值排序）：
  2-3(1) → 选中 ✓
  2-4(2) → 选中 ✓
  1-2(3) → 选中 ✓
  3-4(4) → 2,3,4 已在同一集合，跳过 ✗
  1-4(5) → 1,4 已在同一集合，跳过 ✗
  3-5(6) → 选中 ✓（此时已选 4 条边 = N-1 = 4 ✓）
总成本 = 1 + 2 + 3 + 6 = 12... 不对，是 1+2+3+6 = 12
```

#### 参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 105, MAXM = 1005;

struct Edge {
    int u, v, w, id;  // id 用于保留原始输入顺序
    bool operator<(const Edge& o) const { return w < o.w; }
} e[MAXM];

int parent[MAXN];
int chosen[MAXM][2];  // 记录选中的边
int n, m;

int find(int x) {
    return parent[x] == x ? x : parent[x] = find(parent[x]);
}

int main() {
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        cin >> e[i].u >> e[i].v >> e[i].w;
        e[i].id = i;
    }

    // 初始化并查集
    for (int i = 1; i <= n; i++) parent[i] = i;

    // 排序
    sort(e, e + m);

    int total = 0, cnt = 0;
    for (int i = 0; i < m; i++) {
        int ru = find(e[i].u), rv = find(e[i].v);
        if (ru != rv) {
            parent[ru] = rv;
            total += e[i].w;
            chosen[cnt][0] = e[i].u;
            chosen[cnt][1] = e[i].v;
            cnt++;
            if (cnt == n - 1) break;
        }
    }

    if (cnt != n - 1) {
        cout << -1 << endl;
    } else {
        cout << total << endl;
        for (int i = 0; i < cnt; i++)
            cout << chosen[i][0] << " " << chosen[i][1] << endl;
    }
    return 0;
}
```

## 📝 本课小结

| 要点 | 说明 |
|------|------|
| **MST 定义** | 连接所有顶点的、边权和最小的树，恰好有 N-1 条边 |
| **Prim 算法** | 「加点法」——每次把距离当前树最近的新节点加进来，像树苗慢慢生长。用邻接矩阵、dis 数组、vis 标记实现。适合稠密图 |
| **Kruskal 算法** | 「加边法」——边排序后贪心选取，用并查集判断是否成环。适合稀疏图 |
| **并查集** | Kruskal 的核心数据结构，Find + Union 操作，配合路径压缩几乎 O(1) |
| **选型** | 稠密图（边多）→ Prim；稀疏图（边少）→ Kruskal；两者结果相同 |
