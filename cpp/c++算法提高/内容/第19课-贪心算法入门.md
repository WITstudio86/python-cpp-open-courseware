## 📖 算法讲解

### 什么是贪心算法？

贪心算法（Greedy Algorithm）是一种在每一步选择中都采取在当前状态下最好或最优（即最有利）的选择，从而希望导致结果是全局最好或最优的算法策略。打个比方：就像登山时，每一步都朝着海拔更高的方向走，希望最终能到达山顶。

贪心算法并不从整体最优上加以考虑，它所做的只是某种意义上的局部最优解。因此，贪心算法不是对所有问题都能得到整体最优解，但对范围相当广泛的许多问题能产生整体最优解，或者整体最优解的近似解。

### 局部最优与全局最优

理解贪心算法的关键在于区分两个概念：

- **局部最优（Local Optimum）**：在当前这一步，在所有可选方案中做出的最佳选择。这个选择只考虑眼前，不关心未来。
- **全局最优（Global Optimum）**：从整体来看，对所有步骤进行通盘考虑后能达到的最佳结果。

贪心算法的核心逻辑是：**如果一个问题的最优解可以通过一系列局部最优选择来构造，那么贪心算法就是可行的。** 也就是说，通过反复做局部最优的选择，最终能够得到全局最优解。这被称为「贪心选择性质」。

### 最优子结构

一个问题具有「最优子结构」性质，是指该问题的最优解包含了其子问题的最优解。换句话说，如果原问题的最优解可以通过组合子问题的最优解来得到，那么这个问题就具有最优子结构。

例如，在找零钱问题中，如果要凑出 N 元的最优方案，那么凑出 N - 100 元（如果 N >= 100）的最优方案加上一张 100 元，就是 N 元的最优方案。这就是最优子结构。

### 贪心算法何时有效？何时无效？

**贪心算法有效的必要条件**：
1. 问题具有最优子结构
2. 问题具有贪心选择性质（即局部最优选择能导向全局最优）

**贪心算法失效的典型场景**：
- 背包问题（0-1 背包）：按单位价值贪心选择不一定得到最优解，需要用动态规划
- 最短路径中的负权边：Dijkstra 算法本质上也是贪心，但遇到负权边时会失效

**例子对比**：假设硬币面额为 [1, 3, 4]，要找零 6 元。
- 贪心策略：选最大面额 → 6 = 4 + 1 + 1，用了 3 枚硬币
- 最优策略：6 = 3 + 3，只需 2 枚硬币
- **结论**：贪心失效了！因为硬币面额不满足贪心选择性质

这个例子告诉我们，使用贪心算法之前，必须先证明贪心选择性质的正确性。

### 贪心算法的基本解题框架

```
1. 建立数学模型来描述问题
2. 把求解的问题分成若干个子问题
3. 对每一子问题求解，得到子问题的局部最优解
4. 把子问题的局部最优解合成为原问题的一个解
```

在实际编程中，贪心算法通常遵循以下模式：
1. **排序**：按照某种规则对数据进行排序
2. **选择**：按顺序处理，做出当前最优的选择
3. **验证**：检查选择是否满足约束条件

贪心算法的优势在于思路直观、实现简单、时间复杂度通常较低。但它的局限性也很明显：不是所有问题都适用贪心策略。一般而言，如果一个问题的最优解可以通过排序 + 一次扫描得到，那么很可能贪心就是正解；如果需要回溯或考虑多种组合，往往就需要动态规划或其他方法。

核心要点：
- 排序是贪心算法中最常见的预处理步骤，排序的依据就是「贪心策略」
- 遍历时只需要一次线性扫描，不需要回溯
- 贪心算法的代码往往比动态规划简洁得多

## 📊 复杂度分析

贪心算法的复杂度分析通常分为两部分：

| 操作 | 时间复杂度 |
|------|-----------|
| 排序 | O(n log n) |
| 遍历选择 | O(n) |
| **总计** | **O(n log n)** |

- **时间复杂度**：通常由排序步骤主导，为 O(n log n)。如果数据本身已有序或不需要排序，则为 O(n)。
- **空间复杂度**：通常为 O(1) 或 O(n)，取决于是否需要额外的数组来辅助选择过程。

相比动态规划动辄 O(n²) 或更高的复杂度，贪心算法在适用场景下具有显著的性能优势。这也是为什么算法竞赛中，如果能确定贪心策略正确，通常优先选择贪心的原因。

## 🏋️ 经典例题

### 例题1：找零钱问题

#### 问题描述

假设你有无限多张面额为 100 元、50 元、20 元、10 元、5 元、1 元的纸币。现在需要找零 N 元，请你设计一个算法，找出所需纸币张数**最少**的找零方案。

#### 输入格式

一个正整数 N（1 ≤ N ≤ 10000），表示需要找零的金额。

#### 输出格式

第一行输出一个整数 M，表示最少需要的纸币张数。
第二行输出各面额的使用张数（按面额从大到小排列）。

#### 样例输入1

```
286
```

#### 样例输出1

```
7
100元: 2张
50元: 1张
20元: 1张
10元: 1张
5元: 1张
1元: 1张
```

#### 样例输入2

```
63
```

#### 样例输出2

```
5
50元: 1张
10元: 1张
1元: 3张
```

#### 解题思路

对于人民币的这套面额（100、50、20、10、5、1），贪心策略是正确的。这是因为任意大面额都能被若干小面额整除或组合。我们每次选择不超过剩余金额的最大面额，就能保证找到最优解。

**贪心策略**：每次选择面额最大且不超过当前剩余金额的纸币。

**正确性说明**：在人民币面额体系下，贪心选择性质成立。用最大的面额尽可能多地减少剩余金额，不会使后续的选择变差。因为任意面额都是比它小的面额的整数倍或能被小面额组合。

#### 参考代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int money[] = {100, 50, 20, 10, 5, 1};
    int count[6] = {0};
    int N;

    cin >> N;

    int total = 0;
    for (int i = 0; i < 6; i++) {
        count[i] = N / money[i];  // 当前面额最多能用几张
        N %= money[i];             // 更新剩余金额
        total += count[i];         // 累加总张数
    }

    cout << total << endl;
    for (int i = 0; i < 6; i++) {
        if (count[i] > 0) {
            cout << money[i] << "元: " << count[i] << "张" << endl;
        }
    }

    return 0;
}
```

### 例题2：最大分数

#### 问题描述

小明的期末周有 N 项作业需要完成。每项作业有一个**截止日期**和一个**分数**。完成一项作业需要恰好 1 个单位时间，小明每天只能完成一项作业。如果一项作业在截止日期之前（含当天）完成，小明就能获得对应的分数；否则该项作业作废，得 0 分。

请你帮小明规划一个完成作业的方案，使得获得的总分数**最大**。

#### 输入格式

第一行一个整数 N（1 ≤ N ≤ 1000），表示作业数量。
接下来 N 行，每行两个整数 d 和 s（1 ≤ d ≤ 1000，1 ≤ s ≤ 10000），分别表示第 i 项作业的截止日期和分数。

#### 输出格式

输出一个整数，表示能获得的最大总分数。

#### 样例输入1

```
5
2 60
1 30
2 40
1 80
3 100
```

#### 样例输出1

```
240
```

#### 样例说明

作业信息如下：
- 作业1：截止日期2，分数60
- 作业2：截止日期1，分数30
- 作业3：截止日期2，分数40
- 作业4：截止日期1，分数80
- 作业5：截止日期3，分数100

最优安排：
- 第1天：做作业4（分数80）——截止日期1
- 第2天：做作业1（分数60）——截止日期2
- 第3天：做作业5（分数100）——截止日期3
- 作业2和作业3放弃
- 总分数 = 80 + 60 + 100 = 240

**贪心算法执行过程**（按分数从高到低排序：100, 80, 60, 40, 30）：
1. 作业5（100分，截止3）→ 安排在第3天 ✓
2. 作业4（80分，截止1）→ 安排在第1天 ✓
3. 作业1（60分，截止2）→ 安排在第2天 ✓
4. 作业3（40分，截止2）→ 第2天和第1天都已被占，放弃 ✗
5. 作业2（30分，截止1）→ 第1天已被占，放弃 ✗
- 总分数 = 240

#### 样例输入2

```
4
1 50
2 50
2 100
3 100
```

#### 样例输出2

```
250
```

#### 解题思路

**贪心策略**：按分数从高到低排序，对于每项作业，尽可能安排在截止日期当天完成；如果当天已被占用，则往前找空闲的日子。

这个策略的正确性在于：分数高的作业应该优先得到完成机会。如果一项分数高的作业无法在截止日期前完成，那么用它替换掉已安排的某项作业也不会更好（因为已安排的都是分数更高的）。

**算法步骤**：
1. 将所有作业按分数从高到低排序
2. 使用一个数组 `used[]` 记录每一天是否已被分配作业
3. 对于每项作业，从它的截止日期开始往前找，找到第一个空闲的日子就安排
4. 如果能找到空闲日，就将该作业的分数累加到总分数中

这种策略也称为「带权重的区间调度」问题的贪心解法。

#### 参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Job {
    int deadline, score;
};

bool cmp(Job a, Job b) {
    return a.score > b.score;  // 按分数降序排列
}

int main() {
    int n;
    cin >> n;
    Job jobs[1005];

    int maxDeadline = 0;
    for (int i = 0; i < n; i++) {
        cin >> jobs[i].deadline >> jobs[i].score;
        if (jobs[i].deadline > maxDeadline)
            maxDeadline = jobs[i].deadline;
    }

    // 贪心策略：优先安排分数高的作业
    sort(jobs, jobs + n, cmp);

    bool used[1005] = {false};  // used[t] 表示第 t 天是否已被占用
    int totalScore = 0;

    for (int i = 0; i < n; i++) {
        // 从截止日期往前找空闲的日子
        for (int t = jobs[i].deadline; t >= 1; t--) {
            if (!used[t]) {
                used[t] = true;          // 占用这一天
                totalScore += jobs[i].score;
                break;
            }
        }
    }

    cout << totalScore << endl;
    return 0;
}
```

#### 挑战题1 参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int M, S, C;
    cin >> M >> S >> C;
    int stalls[205];
    for (int i = 0; i < C; i++) cin >> stalls[i];
    sort(stalls, stalls + C);

    // 一整块木板从第一个到最后一个有牛的牛棚
    int total = stalls[C - 1] - stalls[0] + 1;

    // 计算相邻有牛牛棚之间的间隔
    int gaps[205];
    for (int i = 0; i < C - 1; i++) {
        gaps[i] = stalls[i + 1] - stalls[i] - 1;
    }
    sort(gaps, gaps + C - 1, greater<int>());

    // 锯 M-1 次（在最大的 M-1 个间隔处锯断）
    for (int i = 0; i < M - 1 && i < C - 1; i++) {
        total -= gaps[i];
    }

    cout << total << endl;
    return 0;
}
```

## 📝 本课小结

在本课中，我们学习了贪心算法的核心思想：

1. **贪心思想**：每一步都做当前看起来最好的选择，希望通过局部最优达到全局最优。
2. **最优子结构**：问题的最优解包含子问题的最优解，这是贪心算法适用的前提条件之一。
3. **贪心选择性质**：局部最优选择能导向全局最优，使用贪心前需要证明这一点。
4. **典型应用**：找零钱问题（在特定面额体系下）、活动安排/任务调度问题（按分数降序贪心）。
5. **局限性**：贪心算法并非万能，对于不满足贪心选择性质的问题（如 0-1 背包、部分硬币体系下的找零），需要动态规划等方法。

**一句话总结**：贪心算法就是用「鼠目寸光」的策略，争取「高瞻远瞩」的结果——前提是问题本身具有贪心选择性质。
