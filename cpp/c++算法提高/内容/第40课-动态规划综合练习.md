## 📖 算法讲解

### 动态规划解题六步法

经过前面几课的学习，我们已经接触了多种DP类型。现在将它们统一归纳为一个系统化的解题框架：

```
┌─────────────────────────────────────────────────────────────────┐
│  Step 1: 分析问题 ── 识别重叠子问题与最优子结构                    │
│  判断该问题是否具有：① 重叠子问题（相同子问题被反复求解）；          │
│  ② 最优子结构（大问题的最优解包含子问题的最优解）。                 │
├─────────────────────────────────────────────────────────────────┤
│  Step 2: 定义状态 ── dp[...] 表示什么？                           │
│  这是DP最关键的一步。状态定义决定了后续转移方程的复杂度。            │
│  例如：dp[i][j] 表示从三角形顶部走到 (i,j) 位置的最大和。           │
├─────────────────────────────────────────────────────────────────┤
│  Step 3: 找转移方程 ── 状态如何由子状态推导？                      │
│  思考："当前状态可以由哪些更小的状态转移过来？"                      │
│  例如：dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j]        │
├─────────────────────────────────────────────────────────────────┤
│  Step 4: 确定初始状态和边界条件                                    │
│  递推需要起点。比如数字三角形的顶部、编辑距离中空串的情况。          │
│  边界条件如果不处理好，会导致数组越界或结果错误。                    │
├─────────────────────────────────────────────────────────────────┤
│  Step 5: 确定计算顺序 (循环顺序)                                   │
│  确保在计算 dp[i][j] 时，它所依赖的所有子状态都已经算出来了。        │
│  一维DP通常正序，01背包反向遍历，区间DP按区间长度递增。              │
├─────────────────────────────────────────────────────────────────┤
│  Step 6: 确定答案在哪里                                            │
│  dp 数组计算完毕后，答案可能在 dp[n-1]、dp[n][C]、dp[1][n] 等位置，  │
│  也可能是 max(dp[...])（如最大子段和），这一步容易被忽略。           │
└─────────────────────────────────────────────────────────────────┘
```

### 已学DP类型总结

| DP 类型 | 对应课程 | 状态定义特点 | 转移方程特点 | 经典问题 |
|---------|---------|-------------|-------------|---------|
| 记忆化搜索 | 第35课 | 递归 + memo数组 | 自顶向下，遇到重叠子问题查表 | 斐波那契、爬楼梯 |
| 线性DP（一维） | 第36课 | dp[i] 表示以 i 结尾的某种最优值 | dp[i] 仅依赖前若干个 dp[j] (j < i) | 最大子段和、LIS |
| 01背包 | 第37课 | dp[i][j] 表示前 i 个物品、容量 j 的最大价值 | 选或不选：max(dp[i-1][j], dp[i-1][j-w]+v) | 采药、装箱 |
| 完全背包 | 第38课 | 与01背包相同，但每个物品可无限取 | 正向遍历：dp[j] = max(dp[j], dp[j-w]+v) | 硬币找零、完全背包 |
| 区间DP | 第39课 | dp[i][j] 表示区间 [i, j] 上的最优解 | 枚举分割点 k：dp[i][j] = merge(dp[i][k], dp[k+1][j]) | 石子合并、矩阵链乘 |

### 数字三角形

**数字三角形**是二维DP的经典入门问题，非常适合练习"自底向上"和"自顶向下"两种DP思路。

**问题描述**：给定一个 n 行的数字三角形，从顶部出发，在每一节点可以选择向左下或向右下走，一直走到底部。求路径上数字之和的最大值。

**状态定义**：
- 自底向上：`dp[i][j]` 表示从底部走到位置 (i, j) 的最大和。
- 自顶向下：`dp[i][j]` 表示从顶部走到位置 (i, j) 的最大和。

**转移方程（自底向上，推荐）**：
```
dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j]
```
从最后一行开始，逐层向上递推。最后一行的 dp 值就等于 a[n-1][j] 本身。最终答案在 dp[0][0]。

**转移方程（自顶向下）**：
```
dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j]
```
从第一行开始，逐层向下递推。需要注意 j=0 和 j=i 时的边界条件（只能从一个方向转移过来）。最终答案是最后一行 dp[n-1][...] 的最大值。

自底向上的优点是不需要处理边界条件，代码更简洁，推荐使用。

### 编辑距离

**编辑距离**（Levenshtein Distance）衡量两个字符串的相似程度，定义为：将一个字符串转换成另一个字符串所需的最少单字符编辑操作次数。允许的操作有三种：

1. **插入**一个字符
2. **删除**一个字符
3. **替换**一个字符

**状态定义**：
`dp[i][j]` 表示将字符串 A 的前 i 个字符转换为字符串 B 的前 j 个字符所需的最少操作次数。

**转移方程**：
对于 A 的第 i 个字符和 B 的第 j 个字符（下标从 1 开始计数）：

```
dp[i][j] = min(
    dp[i-1][j] + 1,          // 删除 A[i]（删除后，A[1..i-1] 匹配 B[1..j]）
    dp[i][j-1] + 1,          // 在 A 末尾插入 B[j]（插入后，A[1..i] 匹配 B[1..j-1]）
    dp[i-1][j-1] + (A[i] != B[j] ? 1 : 0)  // 替换：若相同无需操作，否则替换
)
```

**初始状态**：
- `dp[0][j] = j`：空串 A 变成 B 的前 j 个字符，需要插入 j 次。
- `dp[i][0] = i`：A 的前 i 个字符变成空串，需要删除 i 次。

## 💻 代码实现

### 数字三角形（自底向上）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 105;
int a[MAXN][MAXN];   // 存储三角形
int dp[MAXN][MAXN];  // dp[i][j]：从底部到 (i,j) 的最大和

int numberTriangle(int n) {
    // 初始化最后一行
    for (int j = 0; j < n; j++)
        dp[n-1][j] = a[n-1][j];
    
    // 自底向上递推
    for (int i = n - 2; i >= 0; i--)
        for (int j = 0; j <= i; j++)
            dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j];
    
    return dp[0][0];  // 答案在顶部
}
```

### 编辑距离

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

const int MAXLEN = 1005;
int dp[MAXLEN][MAXLEN];

int editDistance(string A, string B) {
    int m = A.size(), n = B.size();
    
    // 初始化边界
    for (int i = 0; i <= m; i++) dp[i][0] = i;  // 全部删除
    for (int j = 0; j <= n; j++) dp[0][j] = j;  // 全部插入
    
    // 递推
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (A[i-1] == B[j-1]) {
                dp[i][j] = dp[i-1][j-1];  // 相同则无需操作
            } else {
                dp[i][j] = min({
                    dp[i-1][j] + 1,      // 删除
                    dp[i][j-1] + 1,      // 插入
                    dp[i-1][j-1] + 1     // 替换
                });
            }
        }
    }
    return dp[m][n];
}
```

## 🏋️ 经典例题

### 例题1：数字三角形

**题目描述**：给定一个数字三角形，从顶部出发，在每一节点可以选择向左下或向右下走，一直走到底部。求路径上数字之和的最大值。

**输入格式**：
- 第一行：一个整数 n（1 ≤ n ≤ 100），表示三角形的行数。
- 接下来 n 行：第 i 行有 i 个整数，表示三角形第 i 层的数字。

**输出格式**：
- 一个整数，表示最大路径和。

**样例输入**：
```
5
7
3 8
8 1 0
2 7 4 4
4 5 2 6 5
```

**样例输出**：
```
30
```

**样例解释**：最优路径为 7 → 3 → 8 → 7 → 5，和为 30。

---

**题解**：

采用**自底向上**的动态规划，从三角形的最后一行开始，逐层向上计算。设 `dp[i][j]` 表示从底部走到位置 (i, j) 所能获得的最大和。

对于位置 (i, j)，它只能从正下方的 (i+1, j) 或右下方的 (i+1, j+1) 走上来，因此：

```
dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j]
```

最后一行的 dp 值就等于 a[n-1][j] 本身。最终答案在 dp[0][0]。

**参考代码**：

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 105;
int a[MAXN][MAXN];
int dp[MAXN][MAXN];

int main() {
    int n;
    cin >> n;
    
    // 读入三角形
    for (int i = 0; i < n; i++)
        for (int j = 0; j <= i; j++)
            cin >> a[i][j];
    
    // 初始化最后一行
    for (int j = 0; j < n; j++)
        dp[n-1][j] = a[n-1][j];
    
    // 自底向上递推
    for (int i = n - 2; i >= 0; i--)
        for (int j = 0; j <= i; j++)
            dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j];
    
    cout << dp[0][0] << endl;
    return 0;
}
```

**关键点总结**：
- 自底向上避免了边界判断，代码更简洁。
- dp 数组的大小可以和 a 相同，也可以在原数组上直接修改（节省空间）。
- 答案就是 dp[0][0]，无需遍历最后一行取最大值。

### 例题2：编辑距离

**题目描述**：给定两个字符串 A 和 B，可以进行三种操作：插入一个字符、删除一个字符、替换一个字符。求将 A 转换为 B 的最少操作次数。

**输入格式**：
- 第一行：字符串 A（长度不超过 1000）。
- 第二行：字符串 B（长度不超过 1000）。

**输出格式**：
- 一个整数，表示最少操作次数。

**样例输入**：
```
sunday
saturday
```

**样例输出**：
```
3
```

**样例解释**：将 "sunday" 转换为 "saturday" 的最少操作：
1. 在 's' 后插入 'a' → "saunday"
2. 在 'u' 后插入 't' → "satunday"
3. 将 'n' 替换为 'r' → "saturday"

共 3 步。

---

**题解**：

设 `dp[i][j]` 表示将 A 的前 i 个字符转换为 B 的前 j 个字符所需的最少操作次数。

考虑 A 的第 i 个字符和 B 的第 j 个字符：
- 如果 A[i] == B[j]，则不需要额外操作：`dp[i][j] = dp[i-1][j-1]`
- 如果 A[i] != B[j]，有三种操作可选：
  - **删除** A[i]：`dp[i-1][j] + 1`
  - **插入** B[j]：`dp[i][j-1] + 1`
  - **替换** A[i] 为 B[j]：`dp[i-1][j-1] + 1`
  - 取三者的最小值。

边界条件：`dp[0][j] = j`（空串变非空串需要 j 次插入），`dp[i][0] = i`（非空串变空串需要 i 次删除）。

**参考代码**：

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

const int MAXLEN = 1005;
int dp[MAXLEN][MAXLEN];

int main() {
    string A, B;
    cin >> A >> B;
    int m = A.size(), n = B.size();
    
    // 初始化边界
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    
    // 递推
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (A[i-1] == B[j-1]) {
                dp[i][j] = dp[i-1][j-1];
            } else {
                dp[i][j] = min({dp[i-1][j] + 1,
                                 dp[i][j-1] + 1,
                                 dp[i-1][j-1] + 1});
            }
        }
    }
    
    cout << dp[m][n] << endl;
    return 0;
}
```

**关键点总结**：
- 字符串下标从 1 开始方便处理边界（代码中 A[i-1] 对应 C++ 的 0 起始下标）。
- 三种操作分别对应 dp 表中三个方向的转移：上（删除）、左（插入）、左上（替换）。
- 编辑距离的 DP 表是理解二维 DP 的绝佳范例，建议手动画表加深理解。

```cpp
                dp[i][j] = min({
                    dp[i-1][j] + b,      // 删除
                    dp[i][j-1] + a,      // 插入
                    dp[i-1][j-1] + c     // 替换
                });
        }
    }
    cout << dp[m][n] << endl;
    return 0;
}
```

## 📝 本课小结

动态规划不是死记硬背的模板，而是一套系统化的**问题分解与递推求解方法论**。从分析问题的重叠子结构和最优子结构开始，到定义状态、推导转移方程、确定边界和计算顺序，每一步都需要清晰的逻辑思维。数字三角形和编辑距离是两个经典的二维DP问题，通过它们我们看到了自底向上与自顶向下两种递推视角、以及多方向转移的处理技巧。DP 是算法竞赛中最核心的考点之一，也是最能体现"计算思维"的领域——将复杂问题拆解为简单子问题，用空间换时间，积小胜为大胜。请同学们课后多加练习，用这六步法去解决更多DP问题！
