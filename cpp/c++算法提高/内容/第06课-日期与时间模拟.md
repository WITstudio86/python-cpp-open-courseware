## 📖 算法讲解

### 一、日期问题概述

日期与时间是信息学竞赛中非常常见的模拟题型。这类题目通常不需要复杂的算法，但要求对日历规则有准确的理解，以及细心的代码实现。

常见的日期问题类型：
- 判断某年是否为闰年
- 计算某月的天数
- 计算两个日期之间相隔多少天
- 判断某天是星期几
- 计算某年某月的某天是当年的第几天

### 二、闰年判断规则

闰年的判断是日期问题中最基础也是最重要的知识点。规则如下：

```
闰年判断规则（公历）：
┌──────────────────────────────────────────────────┐
│  1. 能被4整除但不能被100整除的年份是闰年          │
│     例：2004年、2008年、2012年 → 都是闰年        │
│                                                  │
│  2. 能被400整除的年份也是闰年                     │
│     例：1600年、2000年、2400年 → 都是闰年        │
│                                                  │
│  3. 其他年份都是平年                             │
│     例：1900年（能被100整除但不能被400整除）      │
│          → 平年！不是闰年！                       │
└──────────────────────────────────────────────────┘
```

**C++代码实现：**

```cpp
bool isLeapYear(int year) {
    return (year % 400 == 0) || 
           (year % 4 == 0 && year % 100 != 0);
}
```

**记忆口诀**：四年一闰，百年不闰，四百年再闰。

### 三、各月天数

记住了闰年规则，各月天数就容易了：

```
月份    1月 2月   3月 4月 5月 6月 7月 8月 9月 10月 11月 12月
平年    31  28    31  30  31  30  31  31  30  31   30   31
闰年    31  29    31  30  31  30  31  31  30  31   30   31

只有2月受闰年影响！
```

**代码实现：**

```cpp
int daysInMonth(int year, int month) {
    int days[] = {0, 31, 28, 31, 30, 31, 30, 
                  31, 31, 30, 31, 30, 31};
    if (month == 2 && isLeapYear(year)) 
        return 29;
    return days[month];
}
```

### 四、计算两个日期的天数差

这是一个经典的日期问题，基本思路有两种：

**方法一：逐日累加（小间距适用）**
```
如果两个日期在同一年：
  从较早日期开始，逐天加1，直到等于较晚日期。
如果跨年：
  先算到年底 + 中间整年 + 年初到目标日期
```

**方法二：计算从"公元元年1月1日"到某日期的总天数（通用）**
```
天数差 = |总天数(日期2) - 总天数(日期1)|
其中：总天数 = 整年天数 + 当年已过天数
整年天数 = 365×整年数 + 闰年数
```

### 五、星期推算

给定一个日期，判断它是星期几。通常我们需要一个已知的"锚点日期"（如1900年1月1日是星期一），然后计算目标日期与锚点之间的天数差，再对7取模。

```
星期计算步骤：
1. 计算从锚点日期到目标日期的总天数差
2. 天数差 % 7 = 偏移量
3. 根据偏移量确定星期几
```

## 💻 代码实现

```cpp
#include <iostream>
using namespace std;

// 闰年判断
bool isLeap(int y) {
    return (y % 400 == 0) || (y % 4 == 0 && y % 100 != 0);
}

// 月份天数
int monthDays(int y, int m) {
    int d[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (m == 2 && isLeap(y)) return 29;
    return d[m];
}

// 计算从1900-01-01到指定日期的总天数
int totalDays(int y, int m, int d) {
    int days = 0;
    // 加上整年的天数
    for (int i = 1900; i < y; i++) {
        days += isLeap(i) ? 366 : 365;
    }
    // 加上当年已过去月份的天数
    for (int i = 1; i < m; i++) {
        days += monthDays(y, i);
    }
    // 加上当月的天数
    days += d;
    return days;
}

// 计算星期几（0=星期日, 1=星期一, ..., 6=星期六）
int dayOfWeek(int y, int m, int d) {
    // 1900-01-01 是星期一
    int days = totalDays(y, m, d) - totalDays(1900, 1, 1);
    return (days % 7 + 1) % 7;  // 1=星期一
}
```

## 📊 复杂度分析

- 闰年判断：O(1)，常数时间
- 月份天数：O(1)
- 两个日期天数差（逐日法）：O(天数差)，对于跨度大的可能慢
- 两个日期天数差（总天数法）：O(年数)，非常快
- 空间复杂度：O(1)

## 🏋️ 经典例题

### 例题1：黑色星期五

**题目描述**："黑色星期五"是指既是13号又是星期五的日期。当然，并不是每个13号都是星期五。请编写程序，计算从1900年1月1日到N年12月31日之间，有多少个"黑色星期五"。

已知：1900年1月1日是星期一。

**输入格式**：一个整数 N（1900 ≤ N ≤ 9999）

**输出格式**：一个整数，表示"黑色星期五"的数量

**样例输入**：
```
1900
```

**样例输出**：
```
2
```

**题解代码**：
```cpp
#include <iostream>
using namespace std;

bool isLeap(int y) {
    return (y % 400 == 0) || (y % 4 == 0 && y % 100 != 0);
}

// 计算从1900-01-01到 y-m-d 的天数差
int daysFrom1900(int y, int m, int d) {
    int monthDay[] = {0,31,28,31,30,31,30,31,31,30,31,30,31};
    int days = 0;
    // 整年
    for (int i = 1900; i < y; i++)
        days += isLeap(i) ? 366 : 365;
    // 整月
    for (int i = 1; i < m; i++) {
        days += monthDay[i];
        if (i == 2 && isLeap(y)) days++;
    }
    // 天数
    days += d;
    return days;
}

int main() {
    int N, count = 0;
    cin >> N;

    for (int y = 1900; y <= N; y++) {
        for (int m = 1; m <= 12; m++) {
            // 计算y年m月13日是星期几
            // 1900-01-01是星期一（dayOfWeek=1）
            int diff = daysFrom1900(y, m, 13) - 1;
            int weekDay = diff % 7;  // 0=周一
            if (weekDay == 4) {  // 4=周五（0周一,4周五）
                count++;
            }
        }
    }
    cout << count << endl;
    return 0;
}
```

### 例题2：日期差

**题目描述**：输入两个日期（格式：YYYY MM DD），计算它们之间相差的天数。保证第一个日期早于第二个日期。

**输入格式**：两行，每行三个整数，分别表示年、月、日

**输出格式**：一个整数，表示两个日期之间相差的天数

**样例输入**：
```
2020 1 1
2020 12 31
```

**样例输出**：
```
365
```

**题解代码**：
```cpp
#include <iostream>
using namespace std;

bool isLeap(int y) {
    return (y % 400 == 0) || (y % 4 == 0 && y % 100 != 0);
}

int monthDay[] = {0,31,28,31,30,31,30,31,31,30,31,30,31};

// 计算从0001-01-01到指定日期的天数
int totalDays(int y, int m, int d) {
    int days = 0;
    for (int i = 1; i < y; i++)
        days += isLeap(i) ? 366 : 365;
    for (int i = 1; i < m; i++) {
        days += monthDay[i];
        if (i == 2 && isLeap(y)) days++;
    }
    days += d;
    return days;
}

int main() {
    int y1, m1, d1, y2, m2, d2;
    cin >> y1 >> m1 >> d1;
    cin >> y2 >> m2 >> d2;
    
    int diff = totalDays(y2, m2, d2) - totalDays(y1, m1, d1);
    cout << diff << endl;
    return 0;
}
```

**题目描述**：给定一个日期（年、月、日），请判断该年是否为闰年，并计算该日期是当年的第几天。

**输入格式**：一行三个整数，分别表示年 Y、月 M、日 D（1 ≤ Y ≤ 9999，1 ≤ M ≤ 12，1 ≤ D ≤ 31，保证日期合法）。

**输出格式**：
第一行输出该年是否为闰年，是输出 `Leap year`，不是输出 `Common year`。
第二行输出一个整数，表示该日期是当年的第几天。

**样例输入**：
```
2024 3 1
```

**样例输出**：
```
Leap year
61
```

**样例解释**：2024 年是闰年；3 月 1 日是第 31(1月) + 29(2月) + 1 = 61 天。

### 📝 挑战题

#### 挑战题：回文日期

**题目描述**：在日常生活中，我们会遇到一些特别的日期，这些日期的 8 位数字表示（YYYYMMDD）是回文的。例如 2020 年 2 月 2 日表示为 20200202，从左往右读和从右往左读是一样的。

给定一个起始日期和一个结束日期（包含两端），请统计其中有多少个回文日期。注意日期必须真实存在（考虑闰年）。

**输入格式**：两行。第一行一个日期（YYYYMMDD 格式的 8 位整数），表示起始日期。第二行一个日期（同格式），表示结束日期。保证起始日期 ≤ 结束日期，且都是合法日期。

**输出格式**：一个整数，表示回文日期的数量。

**样例输入**：
```
20000101
20201231
```

**样例输出**：
```
3
```

**样例解释**：2000~2020 年间的回文日期有：2001 年 10 月 2 日（20011002）、2010 年 1 月 2 日（20100102）、2020 年 2 月 2 日（20200202）。共 3 个。

#### 挑战题 参考代码
```cpp
#include <iostream>
using namespace std;

bool isLeap(int y) {
    return (y % 400 == 0) || (y % 4 == 0 && y % 100 != 0);
}

int monthDay[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

// 判断 8 位数是否为合法日期
bool isValidDate(int date) {
    int y = date / 10000;
    int m = (date / 100) % 100;
    int d = date % 100;
    if (m < 1 || m > 12) return false;
    int maxDay = monthDay[m];
    if (m == 2 && isLeap(y)) maxDay = 29;
    return d >= 1 && d <= maxDay;
}

// 判断 8 位数是否为回文数
bool isPalindrome(int n) {
    int original = n, reversed = 0;
    while (n > 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    return original == reversed;
}

int main() {
    int date1, date2;
    cin >> date1 >> date2;
    
    int count = 0;
    for (int date = date1; date <= date2; date++) {
        if (isPalindrome(date) && isValidDate(date)) {
            count++;
        }
    }
    
    cout << count << endl;
    return 0;
}
```

## 📝 本课小结

本节课我们学习了日期与时间模拟，这是信息学竞赛中的经典题型。核心知识点包括：闰年判断（四年一闰，百年不闰，四百年再闰）、各月天数计算（只有2月受闰年影响）、以及利用"总天数法"计算日期差和星期推算。

日期问题的关键是细心。建议写代码时多用函数封装基础操作（如 isLeap()、monthDays()、totalDays()），这样主逻辑会更加清晰，也不容易出错。同时，预处理月份天数表（数组）可以避免大量 if-else 判断，使代码更简洁。
