## 📖 算法讲解

### 从二分查找到二分答案的思维跃迁

在前面的课程中，我们学习了二分查找：在一个**有序数组**中，通过不断将查找范围折半，快速定位目标值。二分查找的本质是：**在已知的排列顺序中，利用"中间值"与"目标"的大小关系，每次排除一半候选**。

那么，二分答案和二分查找有什么不同呢？

- **二分查找**：我们有一个排好序的数组，要在里面**找到一个具体的值**。
- **二分答案**：我们没有一个现成的数组，但有一个**可能的答案范围**，而且要在这个范围内**找到一个满足条件的最优解**。

打个比方：

- 二分查找像是在一本按字母顺序排列的电话簿里找"张三"的电话号码。你一翻到中间，发现当前页全是"李"姓，就知道"张"姓在后面，于是扔掉前半本。
- 二分答案像是在猜一个人的年龄。你说"25岁？"，对方说"高了"；你说"20岁？"，对方说"低了"；你不断缩小范围，直到猜中。你猜的每一个年龄本身就是一个"候选答案"。

关键的区别在于：二分答案需要一个**判断函数 check(x)**，这个函数回答"答案 x 是否可行？"。通过 check 函数的返回值（true 或 false），我们就能像二分查找中比较大小一样，决定该往哪边继续搜索。

### 二分答案的适用场景：单调性

二分答案能用的前提是：**答案空间具有单调性**。也就是说，存在一个分界点，分界点的一侧全部满足条件（check 返回 true），另一侧全部不满足条件（check 返回 false）。

举个直观的例子：

```
问题：砍树时电锯高度 H 能否获得足够木材？

     高度 H:  0    1    2    ...  14   15   16   17  ...
     ────────────────────────────────────────────────
    check(H): YES  YES  YES  ...  YES  YES  NO   NO  ...
                                  ↑
                              分界点(最优解)
```

在这个例子中：
- 如果电锯设置得很低（H 小），砍到的木材就很多，一定能满足需求 → check 返回 true
- 如果电锯设置得很高（H 大），砍到的木材就很少，可能不够 → check 返回 false
- 分界点就是"能满足需求的最大高度"，这正是我们要找的答案！

这种单调性就是：**check(H) 从 true 变成 false 只发生一次**，之后不会再变回 true。二分答案正是利用了这一点，不断用中间值测试 check，逐步逼近分界点。

### 两种典型模式

根据我们要找的是分界点左侧还是右侧，二分答案有两种常见写法：

#### 模式一：求最大值（找最后一个满足条件的）

```
check 序列:  true  true  true  true  false  false  false
                                  ↑
                              我们要找这个位置（最大值）

写法特点：
- 当 mid 满足条件时，答案至少为 mid，向右搜索 → left = mid
- 当 mid 不满足条件时，答案一定小于 mid，向左搜索 → right = mid - 1
```

#### 模式二：求最小值（找第一个满足条件的）

```
check 序列:  false  false  false  true  true  true  true
                                   ↑
                               我们要找这个位置（最小值）

写法特点：
- 当 mid 满足条件时，答案至多为 mid，向左搜索 → right = mid
- 当 mid 不满足条件时，答案一定大于 mid，向右搜索 → left = mid + 1
```

**记忆口诀**：最大左缩右，最小右缩左。具体来说，"求最大值"用 left = mid（保留满足的那一侧）；"求最小值"用 right = mid（保留满足的那一侧）。

### 答案范围的确定

在写二分答案之前，首先要确定答案的可能范围 [L, R]：

- **下界 L**：答案的最小可能值。通常取 0 或题目约束中的最小值。
- **上界 R**：答案的最大可能值。通常取题目约束中的最大值，或者一个明显的上界。

例如砍树问题中，电锯高度 H 的范围是 [0, max(树高)]，其中 max(树高) 就是所有树中最高的那棵。

### 判定函数的设计

check 函数是二分答案的**灵魂**。它的设计通常遵循以下步骤：

1. **明确问题**：我要判断"答案是 mid 时，是否满足题目条件"。
2. **模拟计算**：假设答案是 mid，按照题目规则计算出实际结果。
3. **比较判断**：将计算结果与题目要求进行比较，返回 true 或 false。
4. **注意单调性**：确保 check 函数在答案范围内确实是单调的（前半段全 true 后半段全 false，或反之）。

### 二分答案的标准代码框架

```cpp
// 框架1：求最大值——找最后一个满足 check 的位置
int binaryAnswerMax(int L, int R) {
    int left = L, right = R, ans = L;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;       // 记录当前可行解
            left = mid + 1;  // 尝试更大的答案
        } else {
            right = mid - 1; // 答案太大，往小找
        }
    }
    return ans;
}

// 框架2：求最小值——找第一个满足 check 的位置
int binaryAnswerMin(int L, int R) {
    int left = L, right = R, ans = R;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;       // 记录当前可行解
            right = mid - 1; // 尝试更小的答案
        } else {
            left = mid + 1;  // 答案太小，往大找
        }
    }
    return ans;
}
```

注意：使用 `left + (right - left) / 2` 而不是 `(left + right) / 2`，是为了防止 left + right 超过 int 的范围导致溢出。

### 为什么二分答案很高效

假设答案范围是 [0, 10^9]，线性枚举需要 10^9 次 check，这在 1 秒内是不可能完成的。而二分答案只需要大约 log₂(10^9) ≈ 30 次 check！这是从"不可能完成"到"瞬间完成"的质变。

## 💻 代码实现

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// 二分答案模板 —— 求最大值
// 假设答案范围是 [L, R]，check(x) 在 x 较小时返回 true，较大时返回 false
// 我们要找满足 check 的最大 x
long long binaryAnswerMax(long long L, long long R) {
    long long left = L, right = R, ans = L;
    while (left <= right) {
        long long mid = left + (right - left) / 2;  // 防溢出写法
        if (check(mid)) {
            ans = mid;        // mid 可行，记录下来
            left = mid + 1;   // 尝试找更大的可行解
        } else {
            right = mid - 1;  // mid 不可行，答案必须更小
        }
    }
    return ans;
}

// 二分答案模板 —— 求最小值
// 假设答案范围是 [L, R]，check(x) 在 x 较小时返回 false，较大时返回 true
// 我们要找满足 check 的最小 x
long long binaryAnswerMin(long long L, long long R) {
    long long left = L, right = R, ans = R;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;        // mid 可行，记录下来
            right = mid - 1;  // 尝试找更小的可行解
        } else {
            left = mid + 1;   // mid 不可行，答案必须更大
        }
    }
    return ans;
}
```

**关键理解**：
- 求最大值时，可行解的方向是"往右"（越大越好），所以 left = mid + 1
- 求最小值时，可行解的方向是"往左"（越小越好），所以 right = mid - 1
- 两种写法都需要用一个 ans 变量记录"到目前为止最好的可行解"

## 📊 复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| 时间复杂度 | O(log R × T_check) | R 为答案范围，T_check 为单次 check 的时间 |
| 空间复杂度 | O(1) | 仅使用几个变量，不需要额外存储 |

- 如果答案范围是 [0, 10^9]，只需约 30 次 check 调用
- 如果答案范围是 [0, 10^18]，只需约 60 次 check 调用
- 这是二分答案相比线性枚举的巨大优势

check 函数的复杂度取决于具体问题：
- 砍树问题：check 需要遍历所有树，O(n)；总复杂度 O(n log R)
- 跳石头问题：check 需要遍历所有石头，O(n)；总复杂度 O(n log R)

## 🏋️ 经典例题

### 例题1：砍树问题

**题目描述**：有 n 棵树，每棵树的高度为 h[i] 米。伐木工需要获得至少 M 米长的木材。如果将电锯设置在高度 H 处，则所有高度大于 H 的树会被砍掉高于 H 的部分。请确定电锯的最大高度 H，使得获得的木材总长度至少为 M 米。

**输入格式**：第一行两个整数 n 和 M（1 ≤ n ≤ 1000000, 1 ≤ M ≤ 2×10^9）。第二行 n 个整数 h[i]，表示树的高度（1 ≤ h[i] ≤ 10^9）。

**输出格式**：一个整数，表示电锯的最大设置高度。

**样例输入**：
```
4 7
20 15 10 17
```

**样例输出**：
```
15
```

**样例解释**：将电锯设置在 15 米高度：
- 第1棵树：20 - 15 = 5 米
- 第2棵树：15 - 15 = 0 米（低于或等于电锯高度，不砍）
- 第3棵树：10 < 15，不砍
- 第4棵树：17 - 15 = 2 米
- 总木材 = 5 + 0 + 0 + 2 = 7 米，恰好满足要求

如果设在 16 米，总木材 = 4 + 0 + 0 + 1 = 5 米，不足 7 米。所以最大高度是 15。

**解题思路**：

1. **答案范围**：H ∈ [0, max(h[i])]，下界为 0，上界为最高树的高度
2. **单调性**：H 越小 → 砍到的木材越多 → 越容易满足需求
   - 即 check(H) = "在高度 H 处砍树，能否获得至少 M 米木材"
   - check(H) 在 H 较小时为 true，H 较大时为 false
3. **二分策略**：求最大值，找最后一个满足 check 的位置
4. **check 函数**：遍历所有树，累加 max(0, h[i] - H)，判断总和是否 ≥ M

**题解代码**：

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 1000005;
int n;
long long M;
long long h[MAXN];

// check(H)：在高度 H 处砍树，能否获得至少 M 米木材
bool check(long long H) {
    long long total = 0;  // 累加获得的木材总长度
    for (int i = 0; i < n; i++) {
        if (h[i] > H) {
            total += h[i] - H;  // 只砍高于 H 的部分
        }
        // 提前退出优化：如果已经满足，不需要继续累加
        if (total >= M) return true;
    }
    return total >= M;
}

int main() {
    // 输入
    cin >> n >> M;
    long long maxH = 0;
    for (int i = 0; i < n; i++) {
        cin >> h[i];
        if (h[i] > maxH) maxH = h[i];  // 记录最高树的高度
    }

    // 二分答案：求最大可行高度
    long long left = 0, right = maxH, ans = 0;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;        // mid 可行，记录答案
            left = mid + 1;   // 尝试更高的设置
        } else {
            right = mid - 1;  // mid 太高了，降低高度
        }
    }

    cout << ans << endl;
    return 0;
}
```

### 例题2：跳石头

**题目描述**：一条直线上有 n 块石头（不含起点和终点），起点到终点的距离为 L。需要移除至多 M 块石头，使得相邻石头之间的最小距离尽可能大。求这个最小距离的最大值。

**输入格式**：第一行三个整数 L、n、M（1 ≤ L ≤ 10^9, 0 ≤ n ≤ 50000, 0 ≤ M ≤ n）。第二行 n 个整数，表示每块石头到起点的距离（递增给出）。

**输出格式**：一个整数，表示最小距离的最大值。

**样例输入**：
```
25 5 2
2 11 14 17 21
```

**样例输出**：
```
4
```

**样例解释**：

起点位置为 0，终点位置为 25，石头位置为 [2, 11, 14, 17, 21]。

如果移除位置为 2 和 14 的两块石头（共移除了 2 块），剩余石头为 [11, 17, 21]：
- 起点→石头11：距离 = 11
- 石头11→石头17：距离 = 6
- 石头17→石头21：距离 = 4
- 石头21→终点：距离 = 4
- 最小距离 = min(11, 6, 4, 4) = 4

这个 4 是能得到的最大最小距离。如果尝试让最小距离 ≥ 5，则无论如何移除 2 块石头都无法做到。

**解题思路**：

1. **问题转化**：题目说"最小距离尽可能大"，这是"求最大值"的信号。我们二分的是"最小距离"这个值。

2. **答案范围**：最小距离 d ∈ [1, L]
   - 下界：至少为 1（如果所有石头都可以被移除，只剩起点和终点，距离为 L，但最小距离至少 ≥ 1 是合理的下界）
   - 上界：最大为 L（起点到终点只有 L 距离）

3. **单调性**：d 越小 → 越容易满足（需要移除的石头越少）
   - check(d) = "是否可以通过移除至多 M 块石头，使得任意相邻石头之间的距离 ≥ d"
   - check(d) 在 d 较小时为 true，d 较大时为 false
   - 我们要找满足 check 的最大 d

4. **check 函数设计**：
   - 从起点开始，依次检查每块石头
   - 维护"上一块保留的石头的位置" prev
   - 如果当前石头到 prev 的距离 < d，则这块石头必须移除（计数 +1）
   - 如果当前石头到 prev 的距离 ≥ d，则保留这块石头（更新 prev）
   - 最后检查移除的石头数量是否 ≤ M

**图解 check 过程**（以 d = 4 为例）：

```
起点(0)    石头2    石头11   石头14   石头17   石头21    终点(25)
   |         |        |        |        |        |         |
   ●---------●--------●--------●--------●--------●---------●
   
从起点 prev=0 开始：
- 石头2(距离=2): 2 - 0 = 2 < 4，移除！(移除数=1)
- 石头11(距离=11): 11 - 0 = 11 ≥ 4，保留！prev=11
- 石头14(距离=14): 14 - 11 = 3 < 4，移除！(移除数=2)
- 石头17(距离=17): 17 - 11 = 6 ≥ 4，保留！prev=17
- 石头21(距离=21): 21 - 17 = 4 ≥ 4，保留！prev=21
- 终点(25): 25 - 21 = 4 ≥ 4，OK！

移除数 = 2 ≤ M = 2，check(4) = true ✓
```

**题解代码**：

```cpp
#include <iostream>
using namespace std;

const int MAXN = 50005;
int L, n, M;
int rock[MAXN];  // rock[i] 表示第 i 块石头到起点的距离

// check(d)：判断是否可以通过移除至多 M 块石头，
//           使得任意相邻石头之间的距离 ≥ d
bool check(int d) {
    int removed = 0;       // 已移除的石头数量
    int prev = 0;          // 上一块保留的石头的位置（初始为起点 0）

    for (int i = 1; i <= n; i++) {
        if (rock[i] - prev < d) {
            // 当前石头离上一块保留的石头太近，需要移除
            removed++;
            if (removed > M) return false;  // 超过限制，不可行
        } else {
            // 距离足够，保留这块石头
            prev = rock[i];
        }
    }

    // 最后检查终点
    if (L - prev < d) {
        removed++;
    }

    return removed <= M;
}

int main() {
    cin >> L >> n >> M;
    for (int i = 1; i <= n; i++) {
        cin >> rock[i];
    }

    // 二分答案：求最大最小距离
    int left = 1, right = L, ans = 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;        // mid 可行，记录下来
            left = mid + 1;   // 尝试更大的距离
        } else {
            right = mid - 1;  // mid 不可行，减小距离
        }
    }

    cout << ans << endl;
    return 0;
}
```

### 📝 提高题

#### 提高题1：分巧克力

**题目描述**：儿童节那天有 K 位小朋友到小明家做客。小明拿出了珍藏的巧克力招待小朋友们。小明一共有 N 块巧克力，其中第 i 块是 H[i] × W[i] 的方格组成的长方形。为了公平起见，小明需要从这 N 块巧克力中切出 K 块巧克力分给小朋友们。切出的巧克力需要满足：形状是正方形，边长是整数，大小相同。请计算小明了能让每个小朋友都分到一块巧克力，能切出的最大正方形边长是多少。

**输入格式**：第一行两个整数 N 和 K（1 ≤ N, K ≤ 100000）。接下来 N 行，每行两个整数 H[i] 和 W[i]（1 ≤ H[i], W[i] ≤ 100000）。

**输出格式**：一个整数，表示最大可能的正方形边长。

**样例输入**：
```
2 10
6 5
5 6
```

**样例输出**：
```
2
```

**样例解释**：两块巧克力都是 6×5 或 5×6。如果边长 = 2，第一块可以切出 (5/2)×(6/2) = 2×3 = 6 块，第二块可以切出 6 块，共 12 块 ≥ 10。如果边长 = 3，只能切出 1×2 + 1×2 = 4 块 < 10，不行。所以最大边长是 2。

#### 提高题2：网线切割

**题目描述**：Wonderland 的居民决定举办一场编程区域赛。组委会专门成立了负责网线切割的小组。现在有 N 条网线，第 i 条长度为 L[i]。他们需要从这些网线中切割出 K 条长度相等的网线。网线不能被拼接，但可以被切割成任意长度。切割时不能有损耗。请计算能切割出的网线的最大长度（保留两位小数）。

**输入格式**：第一行两个整数 N 和 K（1 ≤ N ≤ 10000, 1 ≤ K ≤ 10000）。接下来 N 行，每行一个实数 L[i]（1.00 ≤ L[i] ≤ 100000.00），保留两位小数。

**输出格式**：一个实数，表示能切割出的网线的最大长度（保留两位小数）。

**样例输入**：
```
4 11
8.02
7.43
4.57
5.39
```

**样例输出**：
```
2.00
```

### 📝 挑战题

#### 挑战题1：月度开销

**题目描述**：有 N 天的开销，需要将这 N 天划分为 M 个连续的周期（每个周期包含一天或连续多天）。使得开销最多的那个周期的开销尽可能少。请输出这个最小值。

**输入格式**：第一行两个整数 N 和 M（1 ≤ N ≤ 100000, 1 ≤ M ≤ N）。接下来 N 行，每行一个整数，表示每天的开销（1 ≤ 开销 ≤ 10000）。

**输出格式**：一个整数，即最大月度开销的最小值。

**样例输入**：
```
7 5
100
400
300
100
500
101
400
```

**样例输出**：
```
500
```

**提示**：这是典型的「最小化最大值」问题。二分答案搜索目标值 X，check(X) 函数判断能否在每段和不超过 X 的情况下将序列分成不超过 M 段。使用贪心策略验证。

### 🔍 参考答案

#### 基础题1 参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 1000005;
int n;
long long M, h[MAXN];

bool check(long long H) {
    long long total = 0;
    for (int i = 0; i < n; i++) {
        if (h[i] > H) total += h[i] - H;
        if (total >= M) return true;
    }
    return total >= M;
}

int main() {
    cin >> n >> M;
    long long maxH = 0;
    for (int i = 0; i < n; i++) {
        cin >> h[i];
        maxH = max(maxH, h[i]);
    }

    long long left = 0, right = maxH, ans = 0;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    cout << ans << endl;
    return 0;
}
```

#### 提高题1 参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 100005;
int N, K;
int H[MAXN], W[MAXN];

// check(len): 边长为 len 时能否切出至少 K 块
bool check(int len) {
    long long cnt = 0;
    for (int i = 0; i < N; i++) {
        cnt += (long long)(H[i] / len) * (W[i] / len);
        if (cnt >= K) return true;
    }
    return cnt >= K;
}

int main() {
    cin >> N >> K;
    int maxSide = 0;
    for (int i = 0; i < N; i++) {
        cin >> H[i] >> W[i];
        maxSide = max(maxSide, max(H[i], W[i]));
    }

    int left = 1, right = maxSide, ans = 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    cout << ans << endl;
    return 0;
}
```

#### 提高题2 参考代码

```cpp
#include <iostream>
#include <algorithm>
#include <cmath>
#include <cstdio>
using namespace std;

const int MAXN = 10005;
int N, K;
double L[MAXN];

// check(len): 能否切割出至少 K 条长度为 len 的网线
bool check(double len) {
    long long cnt = 0;
    for (int i = 0; i < N; i++) {
        cnt += (long long)(L[i] / len);
        if (cnt >= K) return true;
    }
    return cnt >= K;
}

int main() {
    cin >> N >> K;
    double maxL = 0;
    for (int i = 0; i < N; i++) {
        cin >> L[i];
        maxL = max(maxL, L[i]);
    }

    double left = 0.01, right = maxL, ans = 0.01;
    // 浮点二分：精度到 0.01
    while (right - left > 1e-4) {
        double mid = (left + right) / 2.0;
        if (check(mid)) {
            ans = mid;
            left = mid;
        } else {
            right = mid;
        }
    }
    printf("%.2f\n", floor(ans * 100) / 100.0);  // 向下保留两位
    return 0;
}
```

#### 挑战题1 参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 100005;
int N, M;
long long expense[MAXN];

bool check(long long limit) {
    int segments = 1;
    long long sum = 0;
    for (int i = 0; i < N; i++) {
        if (expense[i] > limit) return false;
        if (sum + expense[i] > limit) {
            segments++;
            sum = expense[i];
            if (segments > M) return false;
        } else {
            sum += expense[i];
        }
    }
    return segments <= M;
}

int main() {
    cin >> N >> M;
    long long left = 0, right = 0;
    for (int i = 0; i < N; i++) {
        cin >> expense[i];
        left = max(left, expense[i]);
        right += expense[i];
    }

    long long ans = right;
    while (left <= right) {
        long long mid = left + (right - left) / 2;
        if (check(mid)) {
            ans = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    cout << ans << endl;
    return 0;
}
```

## 📝 本课小结

在本课中，我们学习了二分答案这一强大算法：

1. **核心思想**：将最优化问题（求最大/最小值）转化为判定问题（check(x) 是否可行），然后在答案范围内二分搜索。
2. **关键前提**：答案空间必须具有**单调性**——check(x) 的结果在某个分界点两侧是统一的（一侧全 true，一侧全 false）。
3. **两种模式**：求最大值时用 left = mid（向右靠拢），求最小值时用 right = mid（向左靠拢）。
4. **check 函数是灵魂**：二分答案的对错、好坏，关键在于 check 函数的设计是否正确、高效。
5. **经典应用**：砍树问题（求最大高度）、跳石头问题（求最大最小距离），这两个是二分答案的"入门必刷题"。
6. **效率惊人**：O(log R) 次 check 调用，即使答案范围高达 10^9，也只需约 30 次判定。

**一句话总结**：二分答案 = 把"求最优解"变成"判断某个解是否可行" + 二分查找。当答案具有单调性时，这是从"暴力不可解"到"秒出结果"的神奇转变！
