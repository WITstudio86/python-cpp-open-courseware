# 第39课：区间DP入门

## 🎯 学习目标

1. **理解区间DP的核心思想**：大区间的最优解由小区间的最优解合并而来，通过枚举分割点将区间问题转化为子区间问题。
2. **掌握区间DP的状态定义和枚举顺序**：`dp[i][j]` 表示区间 `[i, j]` 上的最优值，枚举顺序为「区间长度 → 左端点 → 分割点」。
3. **能够解决石子合并、矩阵链乘等经典区间DP问题**：熟练运用前缀和优化、理解代价计算方式，并能独立编写完整代码。

## 📖 算法讲解

### 什么是区间DP？

区间DP是动态规划中处理**区间问题**的一类重要方法。当问题的最优解可以通过枚举区间内的某个分割点，将当前区间划分为两个更小的子区间来求解时，就可以使用区间DP。

**核心思想**：对于区间 `[i, j]`，枚举一个分割点 `k`（`i ≤ k < j`），将区间分成 `[i, k]` 和 `[k+1, j]` 两部分。如果我们已经知道这两个小区间的最优解，那么就可以通过某种「合并」操作得到大区间 `[i, j]` 的最优解。

### 状态定义

```
dp[i][j] = 区间 [i, j] 上的最优值（最小值 / 最大值 / 方案数等）
```

### 状态转移

```
dp[i][j] = merge(dp[i][k], dp[k+1][j])   其中 i ≤ k < j
```

合并操作 `merge` 的具体形式取决于问题本身。例如：
- 石子合并：`dp[i][j] = min(dp[i][k] + dp[k+1][j]) + cost(i, j)`
- 矩阵链乘：`dp[i][j] = min(dp[i][k] + dp[k+1][j] + cost(i, k, j))`

### 枚举顺序（关键！）

区间DP的枚举顺序至关重要。由于大区间依赖于小区间，我们必须**先计算所有小区间，再计算大区间**。正确的枚举方式是：

1. **第一层循环**：枚举区间长度 `len`，从 `2` 到 `n`
2. **第二层循环**：枚举左端点 `i`，右端点 `j = i + len - 1`
3. **第三层循环**：枚举分割点 `k`，从 `i` 到 `j - 1`

```
len=2: [1,2] [2,3] [3,4] [4,5]
len=3: [1,3] [2,4] [3,5]
len=4: [1,4] [2,5]
len=5: [1,5]
```

这种枚举方式保证了在计算 `dp[i][j]` 时，所有比它短的子区间 `dp[i][k]` 和 `dp[k+1][j]` 都已经计算完毕。

### 经典问题一：石子合并（直线版）

**问题描述**：有 `n` 堆石子排成一行，第 `i` 堆石子有 `a[i]` 个。每次可以合并**相邻**的两堆石子，合并的代价为这两堆石子的数量之和。经过 `n-1` 次合并后，所有石子合并成一堆。求最小的总合并代价。

**状态定义**：`dp[i][j]` 表示将第 `i` 堆到第 `j` 堆石子合并成一堆的最小代价。

**状态转移**：
```
dp[i][j] = min( dp[i][k] + dp[k+1][j] ) + sum(i, j)   其中 i ≤ k < j
```

其中 `sum(i, j)` 是区间 `[i, j]` 内石子总数。无论以什么顺序合并，最终一次合并的代价一定是整个区间的石子总数。使用**前缀和**可以在 O(1) 时间内求出任意区间的和。

**初始化**：`dp[i][i] = 0`（单堆石子不需要合并，代价为0）

**最终答案**：`dp[1][n]`

### 经典问题二：矩阵链乘

**问题描述**：给定 `n` 个矩阵的维度序列 `r[0], r[1], ..., r[n]`，其中第 `i` 个矩阵的行数为 `r[i-1]`，列数为 `r[i]`。矩阵乘法满足结合律，不同的加括号方式会导致不同的计算量。求最少的标量乘法次数。

例如，三个矩阵 A1(10×100), A2(100×5), A3(5×50)：
- `(A1 × A2) × A3`：10×100×5 + 10×5×50 = 5000 + 2500 = 7500
- `A1 × (A2 × A3)`：100×5×50 + 10×100×50 = 25000 + 50000 = 75000

**状态定义**：`dp[i][j]` 表示计算矩阵 `i` 到矩阵 `j`（连续相乘）所需的最少标量乘法次数。

**状态转移**：
```
dp[i][j] = min( dp[i][k] + dp[k+1][j] + r[i-1] * r[k] * r[j] )   其中 i ≤ k < j
```

其中 `r[i-1] * r[k] * r[j]` 是将左半部分的结果矩阵与右半部分的结果矩阵相乘的代价。

**初始化**：`dp[i][i] = 0`（单个矩阵不需要乘法）

**最终答案**：`dp[1][n]`

## 💻 代码实现

### 石子合并（直线版）

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

int stoneMerge(vector<int>& a) {
    int n = a.size() - 1;  // a[1..n] 存储石子数量
    vector<int> prefix(n + 1, 0);
    for (int i = 1; i <= n; i++)
        prefix[i] = prefix[i - 1] + a[i];
    
    // dp[i][j] = 合并区间 [i, j] 的最小代价
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));
    
    // 按区间长度从小到大枚举
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp[i][j] = INT_MAX;
            // 枚举分割点 k
            for (int k = i; k < j; k++) {
                int cost = dp[i][k] + dp[k+1][j] + prefix[j] - prefix[i-1];
                dp[i][j] = min(dp[i][j], cost);
            }
        }
    }
    return dp[1][n];
}
```

### 矩阵链乘

```cpp
int matrixChain(vector<int>& r) {
    int n = r.size() - 1;  // n 个矩阵，r[0..n] 共 n+1 个维度
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));
    
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++) {
                // 左半：[i, k]  右半：[k+1, j]
                // 合并代价：r[i-1] * r[k] * r[j]
                int cost = dp[i][k] + dp[k+1][j] + r[i-1] * r[k] * r[j];
                dp[i][j] = min(dp[i][j], cost);
            }
        }
    }
    return dp[1][n];
}
```

## 📊 复杂度分析

| 问题 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| 石子合并（直线） | O(n³) | O(n²) | 三重循环：长度、左端点、分割点 |
| 矩阵链乘 | O(n³) | O(n²) | 同上 |

- **n³ 的来源**：长度 O(n) × 左端点 O(n) × 分割点 O(n)，虽然内层循环的实际次数为 ∑(j-i) = O(n³/6)，但渐进复杂度仍是 O(n³)。
- **可优化的变种**：
  - 石子合并（环形）：将数组复制一倍，转化为直线问题，O(n³)。
  - 四边形不等式优化：对于满足单调性的问题，可将分割点枚举范围缩小，优化至 O(n²)。（进阶内容）

## 🏋️ 经典例题

### 例题1：石子合并（直线版）

**题目描述**：有 `n` 堆石子排成一行，第 `i` 堆石子有 `a[i]` 个。每次合并相邻的两堆石子，合并代价为这两堆石子数之和。求将所有石子合并成一堆的**最小总代价**。

**输入格式**：
```
第一行：一个整数 n，表示石子堆数
第二行：n 个整数，表示每堆石子的数量
```

**输出格式**：
```
一个整数，表示最小总代价
```

**样例输入**：
```
4
1 3 5 2
```

**样例输出**：
```
22
```

**样例解释**：
合并过程如下：
1. 合并第1堆(1)和第2堆(3)，代价 = 1 + 3 = 4，新堆为4。当前石子：`[4, 5, 2]`，累计代价 = 4
2. 合并前两堆(4)和(5)，代价 = 4 + 5 = 9，新堆为9。当前石子：`[9, 2]`，累计代价 = 4 + 9 = 13
3. 合并(9)和(2)，代价 = 9 + 2 = 11，新堆为11。当前石子：`[11]`，累计代价 = 13 + 11 = 24

不对，还有更优的方案：
1. 合并第2堆(3)和第3堆(5)，代价 = 8，石子变为 `[1, 8, 2]`，累计 = 8
2. 合并后两堆(8)和(2)，代价 = 10，石子变为 `[1, 10]`，累计 = 18
3. 合并(1)和(10)，代价 = 11，石子变为 `[11]`，累计 = 29

最优方案：
1. 合并第3堆(5)和第4堆(2)，代价 = 7，石子变为 `[1, 3, 7]`，累计 = 7
2. 合并第1堆(1)和第2堆(3)，代价 = 4，石子变为 `[4, 7]`，累计 = 11
3. 合并(4)和(7)，代价 = 11，石子变为 `[11]`，累计 = 22 ✓

**题解**：

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    // 前缀和
    vector<int> sum(n + 1, 0);
    for (int i = 1; i <= n; i++)
        sum[i] = sum[i - 1] + a[i];
    
    // dp[i][j] = 合并 [i, j] 的最小代价
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));
    
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++) {
                dp[i][j] = min(dp[i][j], 
                    dp[i][k] + dp[k+1][j] + sum[j] - sum[i-1]);
            }
        }
    }
    
    cout << dp[1][n] << endl;
    return 0;
}
```

### 例题2：矩阵链乘

**题目描述**：给定 `n` 个矩阵的维度。第 `i` 个矩阵的行数为 `r[i-1]`，列数为 `r[i]`。矩阵乘法满足结合律，通过加括号可以改变计算顺序。求完成这 `n` 个矩阵相乘所需的**最少标量乘法次数**。

**输入格式**：
```
第一行：一个整数 n，表示矩阵个数
第二行：n+1 个整数 r[0], r[1], ..., r[n]，表示矩阵维度序列
```

**输出格式**：
```
一个整数，表示最少标量乘法次数
```

**样例输入**：
```
3
10 100 5 50
```

**样例输出**：
```
7500
```

**样例解释**：
三个矩阵：
- A₁：10 × 100
- A₂：100 × 5
- A₃：5 × 50

两种加括号方式：
- `(A₁ × A₂) × A₃`：计算 A₁×A₂ 需 10×100×5 = 5000 次，结果矩阵 10×5；再与 A₃ 相乘需 10×5×50 = 2500 次。总计 7500 次。✓
- `A₁ × (A₂ × A₃)`：计算 A₂×A₃ 需 100×5×50 = 25000 次，结果矩阵 100×50；再与 A₁ 相乘需 10×100×50 = 50000 次。总计 75000 次。

最优为 `(A₁ × A₂) × A₃`，总代价 7500。

**题解**：

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> r(n + 1);
    for (int i = 0; i <= n; i++) cin >> r[i];
    
    // dp[i][j] = 计算矩阵 i 到矩阵 j 的最少乘法次数
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));
    
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++) {
                int cost = dp[i][k] + dp[k+1][j] + r[i-1] * r[k] * r[j];
                dp[i][j] = min(dp[i][j], cost);
            }
        }
    }
    
    cout << dp[1][n] << endl;
    return 0;
}
```

#include <string>
#include <vector>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();
    vector<vector<bool>> dp(n, vector<bool>(n, false));
    int maxLen = 1;

    // 长度为1的子串都是回文
    for (int i = 0; i < n; i++) dp[i][i] = true;

    // 按长度递推
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (s[i] == s[j]) {
                if (len == 2) dp[i][j] = true;
                else dp[i][j] = dp[i+1][j-1];
                if (dp[i][j]) maxLen = max(maxLen, len);
            }
        }
    }
    cout << maxLen << endl;
    return 0;
}

```cpp
#include <iostream>
#include <vector>
#include <climits>
using namespace std;

int main() {
    int N;
    cin >> N;
    vector<int> a(2 * N + 1), sum(2 * N + 1, 0);
    for (int i = 1; i <= N; i++) {
        cin >> a[i];
        a[i + N] = a[i];  // 复制一倍
    }
    for (int i = 1; i <= 2 * N; i++)
        sum[i] = sum[i - 1] + a[i];

    vector<vector<int>> dpMin(2 * N + 1, vector<int>(2 * N + 1, 0));
    vector<vector<int>> dpMax(2 * N + 1, vector<int>(2 * N + 1, 0));

    for (int len = 2; len <= N; len++) {
        for (int i = 1; i + len - 1 <= 2 * N; i++) {
            int j = i + len - 1;
            dpMin[i][j] = INT_MAX;
            dpMax[i][j] = 0;
            for (int k = i; k < j; k++) {
                dpMin[i][j] = min(dpMin[i][j],
                    dpMin[i][k] + dpMin[k+1][j] + sum[j] - sum[i-1]);
                dpMax[i][j] = max(dpMax[i][j],
                    dpMax[i][k] + dpMax[k+1][j] + sum[j] - sum[i-1]);
            }
        }
    }

    int ansMin = INT_MAX, ansMax = 0;
    for (int i = 1; i <= N; i++) {
        ansMin = min(ansMin, dpMin[i][i + N - 1]);
        ansMax = max(ansMax, dpMax[i][i + N - 1]);
    }
    cout << ansMin << endl << ansMax << endl;
    return 0;
}
```

## 📝 本课小结

本节课学习了区间DP的核心思想：大区间最优解由小区间合并而来。关键点包括：状态定义 `dp[i][j]` 表示区间 `[i, j]` 的最优值；枚举顺序必须按区间长度从小到大；状态转移通过枚举分割点 `k` 完成。重点掌握了石子合并和矩阵链乘两道经典例题，两者均使用 O(n³) 的区间DP求解。区间DP在竞赛中是高频考点，建议多加练习以熟练掌握枚举顺序和状态转移的设计。
