# 第21课：区间覆盖与选点

---

## 🎯 学习目标

- 理解「区间覆盖」与「最少点覆盖所有区间」这两类经典贪心问题的本质
- 掌握「按右端点排序」的贪心策略，并能解释为什么这样做是最优的
- 能够独立实现区间选点问题（每个区间至少包含一个点）的贪心算法
- 能够将「种树问题」转化为区间覆盖模型，并使用从右向左贪心填坑的方法求解
- 学会分析贪心算法的时间复杂度，并能在 O(n log n) 时间内解决此类问题

## 📖 算法讲解

### 问题引入

想象这样一个场景：一条笔直的街道上分布着 N 个住户，每个住户都希望在自己家门口的某个范围内至少有一个公交站。现在政府要在这条街上修建公交站，每个公交站可以服务到它周围一定范围内的所有住户。问题来了：**最少需要修建几个公交站，才能满足所有住户的需求？**

这就是经典的「区间选点问题」。如果我们用数轴来表示这条街道，每个住户的需求就是一个区间 `[l, r]`（即公交站必须建在这个区间内），而我们的目标就是用最少的点，使得每个区间内都至少包含一个点。

### 核心思想：按右端点排序的贪心策略

面对区间选点问题，直觉上我们可能会想：把点放在区间的中间位置，这样能覆盖更多区间？或者按左端点排序来贪心？但这些策略在遇到某些特殊情况时都会失效。

正确的贪心策略是 **按右端点从小到大排序**，然后依次处理每个区间。对于当前区间，如果它还没有被任何已选中的点覆盖，那么我们就在它的**右端点**处放置一个新的点。这个策略的正确性基于以下观察：

1. **右端点是最优的放置位置**：如果我们必须在某个区间内放一个点，放在右端点是最「保守」的选择——因为它能覆盖到尽可能多的后续区间（后续区间的左端点可能出现在当前区间右端点的左侧，即它们的区间范围可以延伸到与当前区间重叠）。如果放在更靠左的位置，虽然也能覆盖当前区间，但会减少覆盖后续区间的可能性。

2. **右端点排序的理由**：将所有区间按照右端点从小到大排序后，我们处理的顺序就是「结束最早」的区间优先。早结束的区间如果不优先处理，后面可能就来不及放点进去了。而晚结束的区间因为跨度大，有更多的回旋余地。

### 算法流程（区间选点）

1. 将所有区间按照右端点 `r` 从小到大排序。如果右端点相同，可以按左端点从小到大排序（虽然很多时候不影响结果）。
2. 初始化 `last_point = -∞`（一个很小的数），表示上一个被选中的点的位置。
3. 遍历排序后的每个区间 `[l, r]`：
   - 如果 `last_point < l`（即上一个选中的点不在当前区间内），则在 `r` 处放置一个新点，并更新 `last_point = r`。
   - 否则（`last_point >= l`），说明上一个点已经在当前区间内，不需要新增点。
4. 统计总共放置的点数，即为答案。

### 扩展：种树问题

种树问题是区间选点问题的一个变体。在区间选点问题中，每个区间只需要一个点就够了。但种树问题中，每个区间 `[l, r]` 需要至少 `t` 棵树。树可以共享——一棵树种在某个位置，它可以同时满足多个区间对「该位置有树」的需求。

此时贪心策略需要稍作调整：

1. 仍然按右端点从小到大排序。
2. 使用一个布尔数组 `planted[]` 来标记哪些位置已经种了树。
3. 对于当前区间 `[l, r]`，需要的树数量为 `need`：
   - 先统计区间 `[l, r]` 内已经种了多少棵树 `planted_count`。
   - 计算还需要种多少棵：`remain = need - planted_count`。
   - 如果 `remain > 0`，则从右端点 `r` 开始，**从右向左**依次在还没有种树的位置种树，直到种满 `remain` 棵为止。
4. 从右向左种树的原因是：右侧的位置更接近后续区间的左端点，更容易被后续区间共享，从而减少总种树量。

**为什么这些贪心策略是正确的？** 贪心正确性的证明通常使用「交换论证法」——假设存在一个最优解，我们可以通过交换操作将它转化为贪心解而不增加点数，从而证明贪心解也是最优的。

## 💻 代码实现

### 区间选点（基础版）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Interval {
    int l, r;
    // 按右端点从小到大排序
    bool operator<(const Interval &other) const {
        return r < other.r;
    }
};

const int MAXN = 100005;
Interval a[MAXN];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i].l >> a[i].r;
    }
    sort(a, a + n);  // 按右端点排序

    int ans = 0;
    int last = -2e9;  // 上一个选的点，初始化为很小的数
    for (int i = 0; i < n; i++) {
        if (last < a[i].l) {  // 上一个点不在当前区间内
            ans++;
            last = a[i].r;    // 在当前区间的右端点放一个点
        }
    }
    cout << ans << endl;
    return 0;
}
```

### 种树问题（扩展版）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Task {
    int l, r, need;  // 区间左端点、右端点、需要种树的数量
    bool operator<(const Task &other) const {
        return r < other.r;
    }
};

const int MAXN = 30005;
const int MAXPOS = 30005;
Task a[MAXN];
bool planted[MAXPOS];  // planted[i] = true 表示位置 i 已经种了树

int main() {
    int n, maxR = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i].l >> a[i].r >> a[i].need;
        maxR = max(maxR, a[i].r);
    }
    sort(a, a + n);

    int total = 0;
    for (int i = 0; i < n; i++) {
        int l = a[i].l, r = a[i].r, need = a[i].need;

        // 统计 [l, r] 区间内已经种了多少棵树
        int cnt = 0;
        for (int pos = l; pos <= r; pos++) {
            if (planted[pos]) cnt++;
        }

        // 还需要种多少棵
        int remain = need - cnt;

        // 从右向左贪心种树
        for (int pos = r; pos >= l && remain > 0; pos--) {
            if (!planted[pos]) {
                planted[pos] = true;
                remain--;
                total++;
            }
        }
    }
    cout << total << endl;
    return 0;
}
```

## 📊 复杂度分析

- **时间复杂度**：排序花费 `O(n log n)`，遍历区间处理的过程花费 `O(n)`。对于基础区间选点问题，总时间复杂度为 **O(n log n)**。对于种树问题，由于需要在区间内遍历每个位置来统计已种树数量并从右向左种树，最坏情况下每个位置可能被多次访问，时间复杂度为 **O(n · L)**，其中 L 是坐标范围。当坐标范围较大时，可以考虑使用树状数组（Fenwick Tree）或线段树来优化，将复杂度降至 **O(n log L)**。
- **空间复杂度**：存储区间数组需要 **O(n)** 空间。种树问题额外需要 **O(L)** 的空间来存储 `planted[]` 数组。

## 🏋️ 经典例题

### 例题 1：种树问题

#### 题目描述

一条街道可以看作一条数轴，街道上有 N 个居民区。每个居民区 i 的要求是：在闭区间 `[l_i, r_i]` 范围内，至少种 `t_i` 棵树。一棵树种在某个位置，它可以同时满足所有包含该位置的居民区的需求。请问最少需要种多少棵树，才能满足所有居民区的要求？

#### 输入格式

```
第一行：一个整数 N，表示居民区数量
接下来 N 行：每行三个整数 l_i, r_i, t_i，表示第 i 个居民区的区间和需要的树数
```

#### 输出格式

```
一行：一个整数，表示最少需要种的树的总数
```

#### 样例输入

```
4
1 4 2
2 5 2
3 7 3
5 9 2
```

#### 样例输出

```
4
```

#### 样例解释

4 个居民区的需求如下：
- 居民区 1：[1, 4]，需要 2 棵树
- 居民区 2：[2, 5]，需要 2 棵树
- 居民区 3：[3, 7]，需要 3 棵树
- 居民区 4：[5, 9]，需要 2 棵树

最优方案：在位置 3、4、7、9 各种一棵树，共 4 棵（从右向左贪心恰好得到此方案）。
- 居民区 1 ([1,4])：位置 3、4 有树 → 满足 2 棵
- 居民区 2 ([2,5])：位置 3、4 有树 → 满足 2 棵
- 居民区 3 ([3,7])：位置 3、4、7 有树 → 满足 3 棵
- 居民区 4 ([5,9])：位置 7、9 有树 → 满足 2 棵

#### 解题代码

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>
using namespace std;

struct Task {
    int l, r, need;
    bool operator<(const Task &other) const {
        return r < other.r;
    }
};

const int MAXN = 5005;
const int MAXPOS = 30005;
Task a[MAXN];
bool planted[MAXPOS];

int main() {
    int n, maxR = 0;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i].l >> a[i].r >> a[i].need;
        maxR = max(maxR, a[i].r);
    }
    sort(a, a + n);

    int total = 0;
    for (int i = 0; i < n; i++) {
        int l = a[i].l, r = a[i].r, need = a[i].need;

        // 统计 [l, r] 内已种树的数量
        int cnt = 0;
        for (int pos = l; pos <= r; pos++) {
            if (planted[pos]) cnt++;
        }

        // 从右向左补种缺少的树
        int remain = need - cnt;
        for (int pos = r; pos >= l && remain > 0; pos--) {
            if (!planted[pos]) {
                planted[pos] = true;
                remain--;
                total++;
            }
        }
    }
    cout << total << endl;
    return 0;
}
```

### 例题 2：区间选点

#### 题目描述

给定数轴上的 N 个闭区间 `[l_i, r_i]`，请在数轴上选择尽可能少的点，使得每个区间内都至少包含一个选中的点。输出最少需要选择的点的数量。

#### 输入格式

```
第一行：一个整数 N，表示区间数量
接下来 N 行：每行两个整数 l_i, r_i，表示一个闭区间
```

#### 输出格式

```
一行：一个整数，表示最少需要选择的点的数量
```

#### 样例输入

```
5
1 3
2 5
3 6
4 7
0 2
```

#### 样例输出

```
2
```

#### 样例解释

5 个区间：
- [1, 3]
- [2, 5]
- [3, 6]
- [4, 7]
- [0, 2]

按右端点排序后为：[0,2]、[1,3]、[2,5]、[3,6]、[4,7]。
- 处理 [0,2]：没有点覆盖，在右端点 2 放第一个点。
- 处理 [1,3]：2 ∈ [1,3]，已被覆盖。
- 处理 [2,5]：2 ∈ [2,5]，已被覆盖。
- 处理 [3,6]：2 < 3，未被覆盖，在右端点 6 放第二个点。
- 处理 [4,7]：6 ∈ [4,7]，已被覆盖。

最少需要 2 个点（位置 2 和 6）。

#### 解题代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Interval {
    int l, r;
    bool operator<(const Interval &other) const {
        return r < other.r;  // 按右端点排序
    }
};

const int MAXN = 100005;
Interval a[MAXN];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i].l >> a[i].r;
    }
    sort(a, a + n);

    int ans = 0;
    int last = -2e9;  // 上一个点的位置
    for (int i = 0; i < n; i++) {
        if (last < a[i].l) {
            ans++;
            last = a[i].r;
        }
    }
    cout << ans << endl;
    return 0;
}
```

#### 提高题2 参考代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Interval {
    int l, r;
};

bool cmp(Interval a, Interval b) {
    return a.l < b.l;  // 按左端点排序
}

const int MAXN = 100005;
Interval a[MAXN];

int main() {
    int n, start, end;
    cin >> n >> start >> end;
    for (int i = 0; i < n; i++) cin >> a[i].l >> a[i].r;
    sort(a, a + n, cmp);

    int ans = 0, cur = start, i = 0;
    while (cur < end) {
        int maxR = cur;
        // 在所有左端点 ≤ cur 的区间中选右端点最大的
        while (i < n && a[i].l <= cur) {
            maxR = max(maxR, a[i].r);
            i++;
        }
        if (maxR == cur) {  // 无法扩展
            cout << -1 << endl;
            return 0;
        }
        cur = maxR;
        ans++;
    }
```

#### 挑战题1 参考代码

```cpp
#include <iostream>
#include <algorithm>
#include <cmath>
#include <cstdio>
using namespace std;

struct Interval {
    double l, r;
    bool operator<(const Interval &other) const {
        return r < other.r;
    }
};

int main() {
    int n;
    double D;
    cin >> n >> D;
    Interval ivals[1005];

    for (int i = 0; i < n; i++) {
        double x, y;
        cin >> x >> y;
        if (y > D) {
            cout << -1 << endl;
            return 0;
        }
        double d = sqrt(D * D - y * y);
        ivals[i].l = x - d;
        ivals[i].r = x + d;
    }
    sort(ivals, ivals + n);

    int ans = 1;
    double last = ivals[0].r;
    for (int i = 1; i < n; i++) {
        if (ivals[i].l > last) {
            ans++;
            last = ivals[i].r;
        }
    }
    cout << ans << endl;
    return 0;
}
```

## 📝 本课小结

在本课中，我们学习了两种经典的贪心问题：**区间选点**和**种树问题**。它们的核心思想都是 **按右端点排序** 后进行贪心选择。

- **区间选点**是基础模型：每个区间至少一个点，直接按右端点排序，把点放在未被覆盖区间的右端点即可。
- **种树问题**是区间选点的扩展：每个区间需要不同数量的点，需要先统计已有数量，再从右向左补种。两个问题一脉相承，掌握好区间选点就能顺利推广到种树问题。

这两种贪心策略在竞赛中非常常见，也是理解「交换论证法」证明贪心正确性的好例子。熟练掌握它们，面对更多的区间调度类问题（如区间覆盖、活动安排等）也能举一反三。
