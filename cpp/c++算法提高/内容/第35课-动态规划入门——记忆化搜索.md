# 第35课：动态规划入门——记忆化搜索

## 🎯 学习目标

1. **理解动态规划的核心思想**：掌握重叠子问题与最优子结构这两个动态规划的关键性质，理解为什么朴素递归会带来指数级的时间复杂度。
2. **掌握记忆化搜索的实现方法**：学会使用数组（或哈希表）来存储已经计算过的结果，避免重复计算，从而大幅提升算法效率。
3. **能够用记忆化搜索优化递归算法**：能够识别递归算法中的重叠子问题，并运用记忆化搜索将其从指数级时间复杂度优化为多项式级。

## 📖 算法讲解

### 从斐波那契数列说起

斐波那契数列是理解动态规划最经典的入门问题。它的定义非常简单：

```
F(1) = 1
F(2) = 1
F(n) = F(n-1) + F(n-2)  （当 n ≥ 3）
```

按照这个定义，我们很容易写出一个朴素的递归函数。但是，这个看似简洁的递归实现存在一个致命的问题：**大量的重复计算**。

让我们来看看计算 F(6) 时到底发生了什么：

```
                        F(6)
                       /    \
                   F(5)      F(4)
                  /    \     /    \
              F(4)    F(3) F(3)  F(2)
             /    \   /  \  /  \
         F(3)  F(2) F(2)F(1)F(2)F(1)
        /   \
    F(2)   F(1)
```

注意看，F(4) 被计算了 **2 次**，F(3) 被计算了 **3 次**，F(2) 被计算了 **5 次**！随着 n 的增大，重复计算的数量呈指数级增长。这就是为什么朴素递归计算 F(50) 可能需要几个小时甚至更久——时间复杂度高达 **O(2^n)**。

### 重叠子问题（Overlapping Subproblems）

上面递归树中被标出的重复节点，就是**重叠子问题**。所谓"重叠"，是指在递归求解过程中，同一个子问题会被反复求解多次。

动态规划的第一个核心洞察就是：**如果一个问题具有重叠子问题的性质，我们可以用一个数据结构（通常是数组）把已经求解过的子问题答案"记住"，下次再遇到时直接查表，而不是重新计算。**

### 记忆化搜索（Memoization）

"记忆化"这个名字非常形象——给递归函数加上"记忆"能力。具体做法是：

1. 创建一个数组 `memo[]`，初始化为一个特殊值（比如 -1），表示"尚未计算"。
2. 每次调用递归函数时，先检查 `memo[n]` 是否已经被计算过：
   - 如果 `memo[n] ≠ -1`，说明已经算过了，直接返回 `memo[n]`。
   - 如果 `memo[n] = -1`，则递归计算，算完后把结果存入 `memo[n]`，再返回。

这样一来，**每个子问题只会被计算一次**。时间复杂度从 O(2^n) 骤降到 **O(n)**！

### 爬楼梯问题

爬楼梯问题是斐波那契数列的一个经典变体，也是 LeetCode 上的著名题目（Climbing Stairs）。

**问题描述**：假设你正在爬楼梯。楼梯有 n 级台阶，每次你可以爬 1 级或 2 级。从第 0 级开始，你有多少种不同的方法可以爬到第 n 级？

**分析**：想爬到第 n 级，你有两种选择：
- 从第 n-1 级爬 1 级上来。
- 从第 n-2 级爬 2 级上来。

因此，爬到第 n 级的方法数 = 爬到第 n-1 级的方法数 + 爬到第 n-2 级的方法数。这就得到了递推公式：

```
f(1) = 1  （只有一种方法：爬1级）
f(2) = 2  （两种方法：1+1 或者 2）
f(n) = f(n-1) + f(n-2)  （当 n ≥ 3）
```

这和斐波那契数列几乎一样（只是初始条件略有不同），同样可以用记忆化搜索来优化。

### 记忆化搜索 vs 自底向上动态规划

记忆化搜索是"自顶向下"的动态规划——从大问题出发，递归分解为小问题，并用备忘录避免重复计算。而经典的动态规划通常是"自底向上"——从小问题开始，逐步推导出大问题的答案。

这两种方法本质上等价，复杂度相同。记忆化搜索的优点是思路自然、容易从递归改写而来；自底向上的优点是避免了递归的函数调用开销，且某些情况下更容易优化空间。

## 💻 代码实现

### 朴素递归 —— 斐波那契（仅供对比）

```cpp
// 朴素递归 —— 时间复杂度 O(2^n)，极其低效
long long fib_naive(int n) {
    if (n <= 2) return 1;
    return fib_naive(n - 1) + fib_naive(n - 2);
}
```

### 记忆化搜索 —— 斐波那契

```cpp
#include <iostream>
#include <cstring>
using namespace std;

long long memo[100];  // 备忘录数组

long long fib(int n) {
    if (n <= 2) return 1;        // 递归边界
    if (memo[n] != -1) return memo[n];  // 已经算过，直接返回
    return memo[n] = fib(n - 1) + fib(n - 2);  // 计算并存起来
}

int main() {
    memset(memo, -1, sizeof(memo));  // 初始化为 -1，表示未计算
    int n;
    cin >> n;
    cout << fib(n) << endl;
    return 0;
}
```

### 记忆化搜索 —— 爬楼梯

```cpp
long long stairs[100];

long long climb(int n) {
    if (n == 1) return 1;   // 只有 1 级：1 种方法
    if (n == 2) return 2;   // 2 级：1+1 或 2，共 2 种
    if (stairs[n] != -1) return stairs[n];
    return stairs[n] = climb(n - 1) + climb(n - 2);
}
```

## 📊 复杂度分析

| 实现方式 | 时间复杂度 | 空间复杂度 | n=50 时的表现 |
|---------|-----------|-----------|-------------|
| 朴素递归 | O(2^n) | O(n)（递归栈） | 几乎无法算出 |
| 记忆化搜索 | O(n) | O(n)（memo数组） | 瞬间得出 |
| 自底向上DP | O(n) | O(n) 或 O(1) | 瞬间得出 |

可以看到，记忆化搜索将指数级的时间复杂度降到了线性级别，效果极为显著。对于 n=50，朴素递归需要约 2^50 ≈ 10^15 次计算，而记忆化搜索只需要约 50 次计算。

## 🏋️ 经典例题

### 例题1：斐波那契数列优化

**题目描述**：斐波那契数列定义：F(1)=1, F(2)=1, F(n)=F(n-1)+F(n-2)（n≥3）。输入 n（1≤n≤80），输出 F(n)。请使用记忆化搜索实现。

**输入格式**：一个整数 n。

**输出格式**：F(n)。

**样例输入 1**：
```
10
```
**样例输出 1**：
```
55
```

**样例输入 2**：
```
50
```
**样例输出 2**：
```
12586269025
```

---

**题解**：

这是一个经典的重叠子问题。当我们用朴素递归计算 F(n) 时，F(n-1) 和 F(n-2) 会分别递归，导致大量重复计算。使用记忆化搜索，我们用一个 `long long` 数组 `memo[100]` 来存储已经计算过的值。

由于 n 最大可达 80，F(80) 的结果非常大（约 2.3×10^16），因此必须使用 `long long` 类型（64位整数）。

**参考代码**：

```cpp
#include <iostream>
#include <cstring>
using namespace std;

long long memo[100];

long long fib(int n) {
    if (n <= 2) return 1;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib(n - 1) + fib(n - 2);
}

int main() {
    memset(memo, -1, sizeof(memo));
    int n;
    cin >> n;
    cout << fib(n) << endl;
    return 0;
}
```

### 例题2：爬楼梯

**题目描述**：楼梯有 n 级台阶，每次你可以爬 1 级或 2 级。从第 0 级开始，问爬到第 n 级有多少种不同的方法。

**输入格式**：一个整数 n（1≤n≤70）。

**输出格式**：方法数。

**样例输入**：
```
5
```
**样例输出**：
```
8
```

**样例解释**：爬到第 5 级共有 8 种方法：
- 1+1+1+1+1
- 1+1+1+2
- 1+1+2+1
- 1+2+1+1
- 2+1+1+1
- 1+2+2
- 2+1+2
- 2+2+1

---

**题解**：

设 f(n) 表示爬到第 n 级的方法数。要到达第 n 级：
- 如果最后一步爬了 1 级，那么之前在第 n-1 级，有 f(n-1) 种方法到达那里。
- 如果最后一步爬了 2 级，那么之前在第 n-2 级，有 f(n-2) 种方法到达那里。

因此 f(n) = f(n-1) + f(n-2)，边界条件为 f(1)=1, f(2)=2。这与斐波那契数列几乎相同，区别仅在于 f(2) 的值。

同样使用记忆化搜索优化，时间复杂度 O(n)，空间复杂度 O(n)。

**参考代码**：

```cpp
#include <iostream>
#include <cstring>
using namespace std;

long long memo[100];

long long climb(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    if (memo[n] != -1) return memo[n];
    return memo[n] = climb(n - 1) + climb(n - 2);
}

int main() {
    memset(memo, -1, sizeof(memo));
    int n;
    cin >> n;
    cout << climb(n) << endl;
    return 0;
}
```

### 提高题

#### 练习3：最小花费爬楼梯

**题目描述**：楼梯有 n 级台阶（n ≥ 2），每级台阶有一个费用 cost[i]（i 从 0 到 n-1）。你可以从第 0 级或第 1 级开始，每次爬 1 级或 2 级。每次爬上一级台阶，你需要支付该台阶对应的费用。求到达第 n 级的最小总费用。

**状态定义**：dp[i] 表示到达第 i 级的最小花费。dp[0]=0, dp[1]=0。dp[i]=min(dp[i-1]+cost[i-1], dp[i-2]+cost[i-2])。

**输入格式**：
- 第一行：一个整数 n（2 ≤ n ≤ 1000）
- 第二行：n 个整数，表示每级台阶的费用

**输出格式**：一行一个整数，表示最小总费用。

**样例输入**：
```
3
10 15 20
```

**样例输出**：
```
15
```

**样例解释**：从第 1 级开始，支付 15，到达第 3 级；总花费 15。

#### 练习4：递归函数的记忆化改造

**题目描述**：给定一个递归定义的函数：
```
w(0, 0, 0) = 1
如果 a ≤ 0 或 b ≤ 0 或 c ≤ 0，则 w(a, b, c) = 1
如果 a > 20 或 b > 20 或 c > 20，则 w(a, b, c) = w(20, 20, 20)
如果 a < b 且 b < c，则 w(a, b, c) = w(a, b, c-1) + w(a, b-1, c-1) - w(a, b-1, c)
否则 w(a, b, c) = w(a-1, b, c) + w(a-1, b-1, c) + w(a-1, b, c-1) - w(a-1, b-1, c-1)
```
输入多组 a, b, c，对每组输出 w(a, b, c) 的值（结果保证在 int 范围内）。输入以 -1 -1 -1 结束。

**输入格式**：多行，每行三个整数 a, b, c，以 -1 -1 -1 结束。

**输出格式**：对每组数据，输出一行 `w(a, b, c) = 结果`。

**样例输入**：
```

-1 -1 -1
```

### 挑战题

#### 练习5：硬币找零问题（记忆化搜索）

**题目描述**：给定 n 种不同面值的硬币（每种数量无限）和一个总金额 amount，求凑出该金额所需的最少硬币个数。如果无法凑出，输出 -1。

**状态定义**：`dfs(rem)` 表示凑出金额 rem 所需的最少硬币数。边界：rem=0 时返回 0，rem<0 时返回无穷大。转移：`dfs(rem) = min(1 + dfs(rem - coin))` 对所有 coin 面值。

**输入格式**：
- 第一行：两个整数 n 和 amount（1 ≤ n ≤ 12, 0 ≤ amount ≤ 10⁴）
- 第二行：n 个整数，表示硬币面值

**输出格式**：一行，最少硬币数，无法凑出则输出 -1。

**样例输入**：
```
3 11
1 2 5
```

**样例输出**：
```
3
```

**样例解释**：11 = 5 + 5 + 1，最少 3 枚硬币。

### 练习题参考答案

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>
using namespace std;

// 练习1：记忆化斐波那契
long long fibMemo[100];
long long fib(int n) {
    if (n <= 2) return 1;
    if (fibMemo[n] != -1) return fibMemo[n];
    return fibMemo[n] = fib(n - 1) + fib(n - 2);
}

// 练习2：爬楼梯
long long climbMemo[100];
long long climb(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    if (climbMemo[n] != -1) return climbMemo[n];
    return climbMemo[n] = climb(n - 1) + climb(n - 2);
}

// 练习3：最小花费爬楼梯
int minCostClimbingStairs(int cost[], int n) {
    int dp[1005];
    dp[0] = 0; dp[1] = 0;
    for (int i = 2; i <= n; i++)
        dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2]);
    return dp[n];
}

// 练习4：递归函数记忆化
int wMemo[25][25][25];
bool vis[25][25][25];

int w(int a, int b, int c) {
    if (a <= 0 || b <= 0 || c <= 0) return 1;
    if (a > 20 || b > 20 || c > 20) return w(20, 20, 20);
    if (vis[a][b][c]) return wMemo[a][b][c];
    vis[a][b][c] = true;
    int &ret = wMemo[a][b][c];
    if (a < b && b < c)
        ret = w(a, b, c-1) + w(a, b-1, c-1) - w(a, b-1, c);
    else
        ret = w(a-1, b, c) + w(a-1, b-1, c) + w(a-1, b, c-1) - w(a-1, b-1, c-1);
    return ret;
}

// 练习5：硬币找零（记忆化搜索）
int coinMemo[10005];
int coinChange(int coins[], int n, int rem) {
    if (rem == 0) return 0;
    if (rem < 0) return 1e9;
    if (coinMemo[rem] != -1) return coinMemo[rem];
    int ans = 1e9;
    for (int i = 0; i < n; i++)
        ans = min(ans, 1 + coinChange(coins, n, rem - coins[i]));
    return coinMemo[rem] = ans;
}

int main() {
    memset(fibMemo, -1, sizeof(fibMemo));
    cout << "fib(10) = " << fib(10) << endl;             // 55

    memset(climbMemo, -1, sizeof(climbMemo));
    cout << "climb(5) = " << climb(5) << endl;           // 8

    int cost[] = {10, 15, 20};
    cout << "minCost(3) = " << minCostClimbingStairs(cost, 3) << endl; // 15

    cout << "w(10, 4, 6) = " << w(10, 4, 6) << endl;    // 523

    memset(coinMemo, -1, sizeof(coinMemo));
    int coins[] = {1, 2, 5};
    int ans = coinChange(coins, 3, 11);
    cout << "coinChange(11) = " << (ans >= 1e9 ? -1 : ans) << endl; // 3

    return 0;
}
```

## 📝 本课小结

动态规划的核心理念是 **"空间换时间"**——用额外的存储空间来记录子问题的解，从而避免重复计算。记忆化搜索（自顶向下）是最直观的动态规划实现方式：保持递归的思路不变，只加一个"备忘录"数组，就能将指数级算法优化为线性算法。掌握了记忆化搜索，你就打开了动态规划的大门。下一课我们将学习自底向上的动态规划，以及更多有趣的应用场景。
