六大贪心策略一览

排序贪心
先排序，再从小到大/从大到小依次选择。关键词：排序、依次取
区间调度
按结束时间排序，每次选最早结束且不冲突的区间。关键词：不重叠、最多
分数背包
按单位价值排序，能拿多少拿多少。关键词：可分割、性价比
均分策略
算平均值，逐堆调整差额。关键词：平均数、均衡
删数策略
维护单调性，删除"破坏者"。关键词：删元素、最小/最大
哈夫曼编码
每次合并最小的两个。关键词：合并、最小代价

如何识别贪心策略？

判断标准1 —— 最优子结构： 问题的最优解包含子问题的最优解。大问题可以拆成小问题，且大问题的最优解由小问题的最优解组成。
判断标准2 —— 贪心选择性质： 每一步的局部最优选择，不会影响后续得到全局最优。
相当于"先做最优的一步，剩下的问题还是一个同类问题"。
解题口诀：先猜后证 —— 大胆提出贪心猜想，用反例验证，找不到反例就写代码！

例题1：删数问题 —— 代码实现

问题描述

给定一个数字串，删除 K 个数字，使剩下的数字组成的数值最小。

贪心策略

从高位到低位扫描，找到第一个「当前位 > 下一位」的位置，删除当前位。
因为高位越小，整体数值越小！把较小数字往高位"推"，是核心思路。 
// 删数问题：每次删除第一个「比下一位大」的数字
string deleteDigits(string s, int k) {
    for (int t = 0; t < k; t++) {
        int pos = s.size() - 1;   // 默认删最后一位
        // 扫描：找第一个 s[i] > s[i+1] 的位置
        for (int i = 0; i < (int)s.size() - 1; i++) {
            if (s[i] > s[i + 1]) {
                pos = i;          // 找到！删除它
                break;
            }
        }
        s.erase(pos, 1);          // 执行删除
    }
    // 去除前导零（保留至少一个 '0'）
    while (s.size() > 1 && s[0] == '0')
        s.erase(0, 1);
    return s;
}

样例演示：178543，删4个

178543 → 找 8>5，删 8 → 17543 17543 → 找 7>5，删 7 → 1543 1543 → 找 5>4，删 5 → 143 143 → 找 4>3，删 4 → 13 结果：13 ✅
时间复杂度：O(n×k) | 空间复杂度：O(1)

例题2：均分纸牌 —— 分步演示

问题描述

N 堆纸牌排成一行，每次可将任意张牌移到相邻堆（算1次移动）。求使所有堆相等的最少移动次数。

初始状态：N=4，纸牌 [9, 8, 17, 6]，平均值 = 10

贪心调整过程（从左到右）

步骤1：堆1 少1张 → 从堆2借1张 [10] [7] [17] [6] 移动 1 次 步骤2：堆2 少3张 → 从堆3借3张 [10] [10] [14] [6] 移动 2 次 步骤3：堆3 多4张 → 给堆4 4张 [10] [10] [10] [10] 移动 3 次 ✅

核心代码

int avg = sum / n;
int moves = 0;
for (int i = 0; i < n - 1; i++) {
    if (a[i] != avg) {
        int diff = a[i] - avg;   // 差额（正=多，负=少）
        a[i + 1] += diff;        // 转移给下一堆
        moves++;                 // 无论多少张，算 1 次移动
    }
}
时间复杂度：O(n) | 空间复杂度：O(1) | 关键：每堆差额必须通过相邻堆转移

贪心 vs 动态规划 + 本课小结

贪心 vs 动态规划 —— 一张表说清楚

对比维度 贪心算法 动态规划
决策方式 每步做局部最优，不回头 记录多种可能，选最优
是否可撤销 不可撤销 可以回退比较
时间复杂度 通常较低 O(n log n) 通常较高 O(n²)
正确性 需要严格证明 天然保证全局最优
典型问题 删数、均分纸牌、活动选择 0-1背包、最长子序列

本课核心收获

删数问题
策略：每次删除第一个「当前位 > 下一位」的数字
本质：维护高位单调性，让高位尽可能小
复杂度：O(n×k)
均分纸牌
策略：算平均值，从左到右差额转移
本质：每堆差额必须通过相邻堆调整
复杂度：O(n)
