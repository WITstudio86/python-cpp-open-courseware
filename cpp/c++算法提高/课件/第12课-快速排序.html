快速排序——分治的威力

核心思想：选基准 → 分区 → 递归排序 | 平均 O(n log n)

🎯 学习目标

  • 理解快速排序的分治思想：选取基准元素，将数组分为左右两部分，递归排序
  • 掌握快速排序的基准选择和分区（partition）操作
  • 能够利用快速排序解决第k大的数等问题

算法时间复杂度（平均）核心思想稳定性

📖 快速排序的"三步走"

快速排序的核心策略叫做 分治（Divide and Conquer）——把一个大问题拆解成若干个相似的子问题。

// 快速排序的算法框架 void quickSort(arr, left, right) { if (left >= right) return; // 递归终止 // 第1步：选基准 — 选一个"标杆"元素 pivot = 选基准(arr, left, right); // 第2步：分区 — 小的放左边，大的放右边 pivotIndex = partition(arr, left, right); // 第3步：递归 — 对左右两边重复以上操作 quickSort(arr, left, pivotIndex - 1); quickSort(arr, pivotIndex + 1, right); }

🔍 分区操作详解 — 双指针法

分区（Partition）是快速排序最核心的操作。我们用「双指针法」来演示：

选定基准 pivot = 10（最右边的元素）

🔴 pivot = 10 🔵 i = -1 🟠 j = 0
准备开始分区... 基准=10，i=-1，j=0

分区算法要点

  • 指针 i：指向"小于基准区域"的最后一个元素
  • 指针 j：遍历扫描，寻找小于基准的元素
  • 遍历结束后，将基准放到 i+1 的位置
  • 时间复杂度：O(n) | 空间复杂度：O(1)

递归终止条件

当 left >= right 时（区间只有一个元素或为空），无需再排序，递归结束。

🚀 快速选择算法（QuickSelect）

快速选择是快速排序分区思想的巧妙应用。问题：在无序数组中找第k大的元素。

算法思路

  1. 进行一次分区操作，pivot 得到确定的排名 rank
  2. 如果 rank == k → pivot 就是答案
  3. 如果 rank > k → 答案在左半部分，递归左边
  4. 如果 rank < k → 答案在右半部分，递归右边

示例：在 [3, 1, 4, 1, 5, 9] 中找第2大

// "第k大" = "第(n-k+1)小" // 第2大 = 第(6-2+1) = 第5小 数组: [3, 1, 4, 1, 5, 9] 分区: [1, 1, 3, 4, 5, 9] pivot=3 rank=3 rank(3) > k(5th小)? 否! rank(3) < k(5th小)? → 看右边 [4, 5, 9] 在 [4,5,9] 中找第(5-3)=2小 → 5 ✓
方法思想时间复杂度
先排序再取第k个完全排序O(n log n)
快速选择只递归一边O(n) 平均

⚡ 快速选择比全排序快了一个 log n 倍！

📊 复杂度分析

项目最好情况平均情况最坏情况
时间复杂度 O(n log n) O(n log n) O(n²)
空间复杂度 O(log n) —— 递归调用栈的深度
稳定性 不稳定 —— 分区时相同元素可能被交换

为什么最坏是 O(n²)？

如果每次分区的基准都是数组中最大/最小的元素（比如数组已排序且固定选第一个），那么：

// 每次分区只"切掉"一个元素 递归深度：n → n-1 → n-2 → ... → 1 总操作量 ≈ n + (n-1) + (n-2) + ... + 1 = n(n+1)/2 = O(n²)

💡 解决办法：随机选基准或三数取中，将最坏概率降到极低！

为什么空间是 O(log n)？

递归调用栈的深度 ≈ log₂n（每次分区将数组均匀分为两半）。最坏情况下（没有随机化）递归深度可达 n。

💻 核心代码实现

partition 函数

// 分区函数：小的放左边，大的放右边，返回 pivot 的最终位置 int partition(int arr[], int left, int right) { // 随机选择基准，避免最坏情况 int rIdx = left + rand() % (right - left + 1); swap(arr[rIdx], arr[right]); // 将基准换到最右边 int pivot = arr[right]; int i = left - 1; // 小于区域的边界 for (int j = left; j < right; j++) { if (arr[j] < pivot) { // 找到了一个小元素 i++; swap(arr[i], arr[j]); // 交换到小于区域 } } swap(arr[i + 1], arr[right]); // 基准放到正确位置 return i + 1; // 返回基准位置 }

quickSort 函数

void quickSort(int arr[], int left, int right) { if (left >= right) return; // 递归终止 int p = partition(arr, left, right); quickSort(arr, left, p - 1); // 递归左边 quickSort(arr, p + 1, right); // 递归右边 }

🏋️ 例题1：第k大的数

题目描述：给定 n 个整数，找出其中第 k 大的数（k 从 1 开始）。

输入：第一行 n 和 k，第二行 n 个整数。

输出：第 k 大的数。

// 样例输入 6 2 3 1 4 1 5 9 // 样例输出 5 // 解释：排序后 [1,1,3,4,5,9]，第2大是5

核心代码 — quickSelect

int quickSelect(int arr[], int left, int right, int k) { if (left == right) return arr[left]; int p = partition(arr, left, right); int rank = p - left + 1; // pivot 的排名（从1开始） if (rank == k) return arr[p]; // 找到了！ else if (rank > k) return quickSelect(arr, left, p - 1, k); // 看左边 else return quickSelect(arr, p + 1, right, k - rank); // 看右边 } // 调用：第k大 = 第 (n-k+1) 小 ans = quickSelect(arr, 0, n-1, n - k + 1);

📝 本课小结

  1. 快速排序的核心是分治：选基准 → 分区 → 递归排序左右两半
  2. partition 是关键：双指针 i/j，O(n) 时间完成分区
