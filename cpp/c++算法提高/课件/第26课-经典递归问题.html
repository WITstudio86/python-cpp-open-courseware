汉诺塔 —— 古老的传说

传说：在印度的一座神庙里，有一块黄铜板上插着三根宝石针。梵天在创造世界时，在其中一根针上从下到上穿好了由大到小的64片金片——这就是汉诺塔。僧侣们日夜不停地移动金片，当64片金片全部移动到另一根针上时，世界将在一声霹雳中毁灭。

游戏规则（三条铁则）：

  • 规则一：每次只能移动一个圆盘
  • 规则二：大盘不能放在小盘上面
  • 规则三：可以将圆盘临时放在中间的辅助柱上

目标：将 n 个圆盘从柱 A（起始柱）全部移动到柱 C（目标柱），可以借助柱 B（辅助柱）。

A (起始)
B (辅助)
C (目标)
汉诺塔的递归思路

核心思想：要把 n 个盘从 A 移到 C，可以分三步：

①
移走上面 n-1 个
把 A 柱上面的 n-1 个盘
借助 C 柱 → 移到 B 柱
hanoi(n-1, A, C, B)
②
移动最底下的大盘
把 A 柱剩下的第 n 个盘
直接 → 移到 C 柱
A → C
③
移回上面 n-1 个
把 B 柱上的 n-1 个盘
借助 A 柱 → 移到 C 柱
hanoi(n-1, B, A, C)
hanoi(3, A, C, B) 目标：把3个盘从A移到C │ ├── hanoi(2, A, B, C) 把上面2个盘从A移到B（借助C） │ ├── hanoi(1, A, C, B) → A→C │ ├── A→B 移动大盘 │ └── hanoi(1, C, B, A) → C→B │ ├── A→C ← 最底下的大盘直接移过去！ │ └── hanoi(2, B, C, A) 把上面2个盘从B移到C（借助A） ├── hanoi(1, B, A, C) → B→A ├── B→C 移动大盘 └── hanoi(1, A, C, B) → A→C 总移动次数 = 2³ - 1 = 7 次

辗转相除法 —— 求最大公约数

什么是最大公约数（GCD）？两个整数共有的约数中最大的那个。例如 gcd(48, 18) = 6。

辗转相除法（欧几里得算法）是公元前300年由欧几里得发明的，至今仍是求GCD最优雅高效的方法。

核心原理（带余除法）：

gcd(a, b) = gcd(b, a % b)

当 b = 0 时，a 就是最大公约数。

直观理解：一个长方形的长是 a，宽是 b。不断用短边去"量"长边（取余数），相当于不断用正方形去填充长方形，直到恰好填满为止。最后的正方形边长就是最大公约数。

gcd(48, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0) → = 6
步骤aba % b说明
148181248 ÷ 18 = 2 余 12
21812618 ÷ 12 = 1 余 6
3126012 ÷ 6 = 2 余 0，b=0，结束！
GCD —— 递归代码实现
cm">// 辗转相除法：递归求最大公约数 int gcd(int a, int b) { cm">// 终止条件：余数为0，a就是答案 if (b == 0) return a; cm">// 递归：gcd(a, b) = gcd(b, a % b) return gcd(b, a % b); } cm">// 也可以写成一行（C++三目运算符） int gcd2(int a, int b) { return b == 0 ? a : gcd2(b, a % b); }

为什么这个算法这么高效？

每两次递归，a 的值至少减半。因此即使是对非常大的数（比如 10¹⁸），递归深度也不超过约 100 层。时间复杂度仅为 O(log min(a,b))。

扩展知识 —— 最小公倍数（LCM）：

lcm(a, b) = a / gcd(a, b) * b

注意：先除后乘，避免 a×b 溢出！

递归思想总结
🧩
自相似性
问题能分解为结构相同、规模更小的子问题，是使用递归的前提。
🎯
终止条件
必须有明确的递归出口，否则会无限递归导致栈溢出。
📐
问题规模缩小
每次递归调用必须向终止条件靠近，问题规模必须严格缩小。
问题递归要素时间复杂度空间复杂度
阶乘n! = n × (n-1)!O(n)O(n)
斐波那契F(n) = F(n-1) + F(n-2)O(2ⁿ)O(n)
汉诺塔H(n) = 2H(n-1) + 1O(2ⁿ)O(n)
GCDgcd(a,b) = gcd(b, a%b)O(log n)O(log n)

💡 递归不是魔法，而是一种思维方式——相信函数能"解决好规模更小的问题"，然后利用这个结果解决当前问题。
