高精度乘法

模拟竖式乘法 · 逐位相乘 · 统一进位

当 int 和 long long 都不够用时，就该数组登场了

为什么需要高精度？

整数类型的"天花板"

int 最大值
≈ 2.1 × 10⁹
long long 最大值
≈ 9.2 × 10¹⁸
50! 约为
≈ 3.0 × 10⁶⁴
核心矛盾： 计算机的整数类型空间有限，但我们想算的数可以无限大。50 的阶乘有 65 位，远超 long long 的范围！

解决思路

  • 用数组存储每一位数字 — 一个格子存一位，想存多少位就开多大的数组
  • 模拟手工竖式计算 — 用代码"复刻"我们小学就会的算法
  • 倒序存储 — 个位在索引 0，进位往右自然扩展

例如 12345 在数组中：
a[0]=5（个位）, a[1]=4（十位）, a[2]=3（百位）, a[3]=2（千位）, a[4]=1（万位）

竖式乘法原理

回顾：123 × 456 竖式

1 2 3 ← 被乘数 A (3位) × 4 5 6 ← 乘数 B (3位) ────────────── 7 3 8 ← 123 × 6 = 738 6 1 5 ← 123 × 5 = 615（左移一位） 4 9 2 ← 123 × 4 = 492（左移两位） ────────────── 5 6 0 8 8 ← 相加结果 = 56088
核心规律：
A 的第 i 位 × B 的第 j 位 → 贡献到答案的第 i+j 位

即： c[i+j] += a[i] × b[j]

数组存储与逐位相乘

第一步：逐位相乘累加

// 倒序存储：a = [3,2,1]（即 123），b = [6,5,4]（即 456） for (int i = 0; i < len1; i++) { for (int j = 0; j < len2; j++) { c[i + j] += a[i] * b[j]; // 关键公式 } } // 结果 c = [18, 27, 28, 13, 4]（尚未进位）

第二步：统一进位

for (int i = 0; i < len1 + len2; i++) { if (c[i] >= 10) { c[i + 1] += c[i] / 10; // 进位 c[i] %= 10; // 保留个位 } } // 进位后 c = [8, 8, 0, 6, 5] → 倒序读出 "56088"
进位过程可视化：
c[0]=18 → 留8进1　c[1]=27+1=28 → 留8进2
c[2]=28+2=30 → 留0进3　c[3]=13+3=16 → 留6进1
c[4]=4+1=5 → 留5　结果：5 6 0 8 8 ✓

完整实现：高精度乘高精度

// 高精度乘法函数 string high_precision_multiply(const string &num1, const string &num2) { if (num1 == "0" || num2 == "0") return "0"; int len1 = num1.size(), len2 = num2.size(); vector<int> a(len1), b(len2); // 倒序存储：个位在索引 0 for (int i = 0; i < len1; i++) a[i] = num1[len1-1-i] - '0'; for (int i = 0; i < len2; i++) b[i] = num2[len2-1-i] - '0'; vector<int> c(len1 + len2, 0); // 逐位相乘累加 for (int i = 0; i < len1; i++) for (int j = 0; j < len2; j++) c[i+j] += a[i] * b[j]; // 统一进位 for (int i = 0; i < len1+len2; i++) { if (c[i] >= 10) { c[i+1] += c[i] / 10; c[i] %= 10; } } // 去除前导零并转换字符串 int pos = len1+len2-1; while (pos > 0 && c[pos] == 0) pos--; string result; for (int i = pos; i >= 0; i--) result += char(c[i]+'0'); return result; }
时间复杂度
O(n × m)
空间复杂度
O(n + m)

阶乘之和与总结

例题：计算 S = 1! + 2! + ... + n!（n ≤ 50）

// 递推计算阶乘并累加 string factorial = "1"; // 当前阶乘 string sum = "0"; // 累加和 for (int i = 1; i <= n; i++) { factorial = multiply(factorial, to_string(i)); sum = add(sum, factorial); }
本课核心要点：
  • 高精度运算的本质：用数组模拟手工竖式
  • 核心公式：c[i+j] += a[i] × b[j]
  • 倒序存储（个位在索引 0）方便进位
  • 先逐位相乘，再统一进位，分两步走最清晰
  • 时间复杂度 O(n×m)，对于 200 位以内的数足够快
