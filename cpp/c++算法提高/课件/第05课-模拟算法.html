📌 经典问题：蜗牛爬井、猴子吃桃

📖 模拟算法框架 & 流程

模拟算法四要素

┌─────────────────────────────────────┐ │ ① 状态变量 → 记录当前状态 │ │ ② 循环推进 → while/for 推进时间 │ │ ③ 规则执行 → 按规则更新状态 │ │ ④ 终止条件 → 何时停止模拟 │ └─────────────────────────────────────┘

蜗牛爬井流程图

开始 ↓ 初始化: pos=H, day=0 ↓ ┌──────┐ │pos>0?│──否──→ 输出 day，结束 └──是──┘ ↓ day++, pos -= A (白天爬) ↓ ┌──────┐ │pos≤0?│──是──→ 输出 day，结束 (出井了！) └──否──┘ ↓ pos += B (晚上滑) ↓ 返回循环

💻 蜗牛爬井 —— 代码实现

long long pos = H;   // 距离井口的深度
int day = 0;

while (pos > 0) {          // 还没出井就继续
    day++;                 // 新的一天
    pos -= A;              // 白天向上爬

    if (pos <= 0) break;   // ← 关键！白天出井就不滑了

    pos += B;              // 晚上下滑
}

🐌 示例：H=10, A=3, B=2

第1天: 10→7→9（滑回） 第2天: 9→6→8 第3天: 8→5→7 第4天: 7→4→6 第5天: 6→3→5 第6天: 5→2→4 第7天: 4→1→3 第8天: 3→0 出井！

⚠️ 常见错误

  • 忘写 break：出井后还下滑
  • 先下滑再爬：顺序错了
  • 位置从0开始：应从H开始（距离井口的深度）
  • 用 int 溢出：应该用 long long

🏋️ 例题：猴子吃桃（逆向模拟）

问题描述

猴子每天吃前一天剩下的一半多一个。第N天早上只剩1个。问第一天有多少？

正向 vs 逆向

正向（自然过程）
x个 → 吃 x/2+1 → 剩 x/2-1 46 → 吃24 → 剩22 22 → 吃12 → 剩10 10 → 吃6 → 剩4 4 → 吃3 → 剩1
逆向（从结果推）
剩1 → 原有 (1+1)×2 = 4 剩4 → 原有 (4+1)×2 = 10 剩10 → 原有 (10+1)×2 = 22 剩22 → 原有 (22+1)×2 = 46
// 逆向递推公式：前一天的桃子 = (当天桃子 + 1) × 2
int peach = 1;                    // 第N天剩1个
for (int day = N; day > 1; day--) {
    peach = (peach + 1) * 2;
}
cout << peach;  // 第一天的总数
💡 技巧：逆向思维在模拟题中非常实用——当正向难推时，试着从结果倒着走！

📝 本课小结

✅ 模拟算法检查清单

  • ☑ 状态变量定义清晰了吗？
  • ☑ 循环条件写对了吗？（while vs for）
  • ☑ 每一步的更新顺序对吗？
  • ☑ 边界情况处理了吗？（正好在边界时）
  • ☑ 数据类型够大吗？（int vs long long）

🔄 while vs for 选择指南

情况用哪个例子
知道具体次数for猴子吃桃（推N-1次）
不知道次数while蜗牛爬井（直到出井）
可能永远循环while+上限需要加保护
