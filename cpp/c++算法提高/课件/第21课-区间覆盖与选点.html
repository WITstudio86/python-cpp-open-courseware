Lesson 21

区间覆盖与选点

最少点覆盖所有区间 · 种树问题

C++ 算法提高

核心策略：按右端点排序

问题回顾

给定 N 个闭区间，每个区间内至少需要一个点。求最少需要多少个点？

贪心选择规则：将所有区间按 右端点 从小到大排序，然后依次处理。对于每个未被覆盖的区间，在其右端点放置一个点。

为什么放在右端点？

  • 最大化覆盖：右端点是区间内最靠右的位置，更容易落入后续区间的范围内
  • 最保守策略：如果放在左端，会浪费覆盖后续区间的机会
  • 交换论证：任何最优解都可以通过交换操作转化为「放在右端点」的贪心解而不增加点数

为什么按右端点排序？

  • 优先处理「最早结束」的区间，避免它被遗漏
  • 晚结束的区间跨度大，有更多机会被后续放置的点覆盖
  • 按左端点排序会失效（反例：[1,100], [2,3], [4,5]）

代码实现：区间选点

核心代码

struct Interval { int l, r; bool operator<(const Interval &o) const { return r < o.r; // 按右端点排序 } }; int solve(int n) { sort(a, a + n); // 排序 int ans = 0; int last = -2e9; // 上一个点的位置 for (int i = 0; i < n; i++) { if (last < a[i].l) { // 未被覆盖？ ans++; // 新增一个点 last = a[i].r; // 放在右端点 } } return ans; }

种树问题（扩展版）

for (int i = 0; i < n; i++) { // 1. 统计 [l, r] 内已有树数 int cnt = 0; for (int p = l; p <= r; p++) if (planted[p]) cnt++; // 2. 从右向左补种不足部分 int need = t - cnt; for (int p = r; p >= l && need > 0; p--) if (!planted[p]) { planted[p] = true; need--; total++; } }

逐步演示：区间选点

输入区间：[0,2] [1,3] [2,5] [3,6] [4,7]

1
排序后（按右端点）：[0,2] [1,3] [2,5] [3,6] [4,7]
2

3
处理 [1,3]： 点①(位置2) ∈ [1,3] → 已覆盖，跳过
4
处理 [2,5]： 点①(位置2) ∈ [2,5] → 已覆盖，跳过
5

6
处理 [4,7]： 点②(位置6) ∈ [4,7] → 已覆盖，跳过
最终答案：最少需要 2 个点（位置 2 和 6）

本课小结

🎯

核心策略

按右端点排序，将点放在未覆盖区间的右端点

🌳

种树问题

区间选点的扩展：每个区间需要多个点，从右向左补种

⏱️

时间复杂度

排序 O(n log n)，贪心处理 O(n)

💡

证明方法

交换论证法：任何最优解都可转化为贪心解

关键要点

  • 区间问题的贪心策略几乎都是按端点排序，不同问题排序依据不同
  • 区间选点 → 按右端点排序，放在右端
  • 种树问题 → 同样按右端点排序，从右向左填坑
  • 掌握这两种模型，就能应对大多数区间覆盖类问题
