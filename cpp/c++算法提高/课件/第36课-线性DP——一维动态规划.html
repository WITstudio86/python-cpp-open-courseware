DP 核心概念

动态规划解题四步框架

1

状态定义

明确 dp[i] 表示的含义。

例：dp[i] = 以第 i 个元素结尾的最大子段和

2

状态转移方程

找到 dp[i] 与 dp[j] (j < i) 的递推关系。

例：dp[i] = max(a[i], dp[i-1] + a[i])

3

初始状态

确定递推的起点，给 dp[0] 赋值。

例：dp[0] = a[0]

4

计算顺序

从小到大依次递推，确保依赖已算出。

例：for i = 1 to n-1

核心思想：动态规划的本质是 记住已经解决过的子问题的答案，避免重复计算。每个子问题的解只计算一次并存储起来，后续需要时直接使用。

最大子段和（Maximum Subarray Sum）

算法思想

状态定义：dp[i] = 以第 i 个元素结尾的最大子段和

转移方程：

dp[i] = max(a[i], dp[i-1] + a[i])

答案：max(dp[0..n-1])

复杂度：O(n) 时间，O(1) 空间

代码实现

int maxSubarraySum(vector<int>& a) {
    int curMax = a[0], ans = a[0];
    for (int i = 1; i < a.size(); i++) {
        curMax = max(a[i], curMax + a[i]);  // 状态转移
        ans = max(ans, curMax);            // 更新全局最优
    }
    return ans;
}

最长上升子序列（LIS）

算法思想

状态定义：dp[i] = 以第 i 个元素结尾的LIS长度

转移方程：

dp[i] = max(dp[j] + 1)
        (j < i, a[j] < a[i])

复杂度：O(n²) 时间，O(n) 空间

O(n log n) 优化思路

贪心 + 二分：维护 tails 数组，tails[k] = 长度为 k+1 的上升子序列的最小末尾。遍历每个元素 x，在 tails 中二分查找第一个 `>= x` 的位置并替换。tails 最终长度 = LIS 长度。

核心代码 (O(n²))

vector<int> dp(n, 1);  // 初始：每个元素自身长为 1
for (int i = 1; i < n; i++)
    for (int j = 0; j < i; j++)
        if (a[j] < a[i])
            dp[i] = max(dp[i], dp[j] + 1);

为什么 DP 必须包含当前元素？

如果 dp[i] 不强制包含 a[i]，那么无法从 dp[i-1] 递推出 dp[i]，因为缺少了"连续性"的约束。定义 dp[i] 为 "以 i 结尾" 是线性 DP 中最常用的技巧。

答案取 max(dp[0..n-1]) 而非 dp[n-1]，因为最优解不一定以最后一个元素结尾。

DP 常见优化方向

  • 滚动数组：dp[i] 只依赖 dp[i-1] 时，用变量替代数组（如最大子段和）
  • 贪心 + 二分：利用单调性减少状态转移的枚举（如 LIS 的 tails 优化）
  • 数据结构优化：用线段树/树状数组加速区间查询（后续课程）
