核心技巧：标记数组

不使用标记数组 ❌ 
for(i=1;i<=3;i++)
 for(j=1;j<=3;j++)
  for(k=1;k<=3;k++)
   // j可能==i，k可能==i或j
   // 需要很多if判断
使用标记数组 ✅ 
if(!used[i]) {
  a[pos] = i;
  used[i] = true;
  // 递归下一层
  used[i] = false; // 回溯
}

排列数量公式

P(n,m) = n×(n-1)×...×(n-m+1) = n!/(n-m)!
全排列 P(n,n) = n! = n×(n-1)×...×2×1

💻 三数排序组合

从1~9选3个不同数字，组成严格递增或递减的三位数

for (int a = 1; a <= 9; a++) {          // 百位
    for (int b = 1; b <= 9; b++) {      // 十位
        if (b == a) continue;            // ← 避免重复
        for (int c = 1; c <= 9; c++) {  // 个位
            if (c == a || c == b) continue; // ← 避免重复

            if (a < b && b < c) {       // 严格递增
                cout << a*100+b*10+c << " [递增]" << endl;
            }
            else if (a > b && b > c) {  // 严格递减
                cout << a*100+b*10+c << " [递减]" << endl;
            }
        }
    }
}
🔺 递增（84个）
C(9,3) = 84种选法
每组数字只有1种递增排列
例：选{1,2,3} → 只有123
🔻 递减（84个）
C(9,3) = 84种选法
每组数字只有1种递减排列
例：选{1,2,3} → 只有321
总计 84+84 = 168 个

📝 本课小结

✅ 核心要点

  • 排列定义：顺序重要！{1,2}≠{2,1}
  • 全排列数量：P(n,n) = n!，增长极快
  • 循环枚举：用 if-continue 跳过已用元素
  • 标记数组：bool used[] 追踪使用状态
  • 回溯：used[i]=false 恢复状态
