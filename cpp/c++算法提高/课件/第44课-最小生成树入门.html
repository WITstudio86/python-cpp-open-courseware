Prim 算法 & Kruskal 算法

🌉 如何用最低成本连接所有城市？

🌳 什么是最小生成树（MST）？

📐 定义

最小生成树：在一个带权连通图中，选择 N-1 条边连接所有 N 个顶点，使得这些边的权值总和最小。

📐 关键性质

  • 包含图中所有 N 个顶点，恰好 N-1 条边
  • 是一棵树（无环、连通）
  • 任意两点之间的路径唯一
  • 如果图不连通，则不存在生成树

💡 现实应用：修路规划、网络布线、电路设计、集群分析... 处处都是 MST！

🔍 Prim 算法 — 「加点法」

像树苗一样慢慢生长，每次加一条最短的枝干

算法演示

原图：A-B(2), A-C(5), A-D(4), B-C(3), C-D(1) Step 1 从 A 开始，已加入 = {A} 候选：A-B(2), A-C(5), A-D(4) → 选最小 A-B(2)，加入 B ✓ 已加入 = {A, B} Step 2 已加入 = {A, B} 候选：A-C(5), A-D(4), B-C(3) → 选最小 B-C(3)，加入 C ✓ 已加入 = {A, B, C} Step 3 已加入 = {A, B, C} 候选：A-D(4), C-D(1) → 选最小 C-D(1)，加入 D ✓ 已加入 = {A, B, C, D} MST 构建完成！总权值 = 2 + 3 + 1 = 6

核心数据结构：dis[v] = 节点 v 到当前 MST 的最短距离。每加入一个节点，更新所有邻居的 dis 值。

🔍 Kruskal 算法 — 「加边法」

边排序后贪心选择，用并查集防止成环

算法演示

所有边排序：C-D(1), A-B(2), B-C(3), A-D(4), A-C(5) Step 1 边 C-D(1)：C∈{C}, D∈{D} → 不在同一集合，选中！ 合并 {C} ∪ {D} = {C, D} 已选：1/3 Step 2 边 A-B(2)：A∈{A}, B∈{B} → 选中！ 合并 {A} ∪ {B} = {A, B} 已选：2/3 Step 3 边 B-C(3)：B∈{A,B}, C∈{C,D} → 选中！ 合并 {A,B} ∪ {C,D} = {A,B,C,D} 已选：3/3 ✓ Step 4 边 A-D(4)：A,D 已在同一集合 → 跳过（会形成环！） N-1=3 条边已选够，算法结束。总权值 = 6

💻 代码实现

Prim 算法

int prim() { memset(dis, 0x3f, sizeof(dis)); memset(inMST, 0, sizeof(inMST)); dis[1] = 0; int total = 0; for (int i = 1; i <= n; i++) { // 选出距离 MST 最近的未加入节点 int u = -1, md = INF; for (int j = 1; j <= n; j++) if (!inMST[j] && dis[j] < md) md = dis[j], u = j; if (u == -1) return -1; // 不连通 inMST[u] = true; total += dis[u]; // 累加权值 // 用 u 更新邻居到 MST 的距离 for (int v = 1; v <= n; v++) if (!inMST[v] && g[u][v] < dis[v]) dis[v] = g[u][v]; } return total; }

Kruskal 算法（含并查集）

// 并查集：查找（路径压缩） int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); } // Kruskal 主函数 int kruskal() { for (int i = 1; i <= n; i++) parent[i] = i; sort(edges, edges + m); // 按权值排序 int total = 0, cnt = 0; for (int i = 0; i < m; i++) { int ru = find(edges[i].u); int rv = find(edges[i].v); if (ru != rv) { parent[ru] = rv; // 合并 total += edges[i].w; // 累加 cnt++; if (cnt == n - 1) break; } } return (cnt == n - 1) ? total : -1; }

🏋️ 例题演示

例题1：修路问题（Prim）

N=4 村庄，M=5 可选道路： 1-2(2), 1-3(3), 1-4(4), 2-3(1), 3-4(5) MST 选择： 边 2-3（成本 1）+ 边 1-2（成本 2）+ 边 1-4（成本 4） 总成本 = 1 + 2 + 4 = 7

例题2：连接所有城市（Kruskal）

N=5 城市，M=7 光纤线路： 1-2(3), 1-4(5), 2-3(1), 2-4(2), 3-4(4), 3-5(6), 4-5(7) MST 选择（按权值排序后贪心选取）： · 2-3(1) → 选中 ✓ · 2-4(2) → 选中 ✓ · 1-2(3) → 选中 ✓ · 3-4(4) → 跳过（会成环） · 1-4(5) → 跳过 · 3-5(6) → 选中 ✓（N-1=4 条选够！） 总成本 = 1 + 2 + 3 + 6 = 12

📝 本课小结

🔹 Prim 算法（加点法）

从一个起点出发
每次选距离 MST 最近的新节点
像树苗生长一样扩展
时间复杂度：O(V²)
适合：稠密图

🔹 Kruskal 算法（加边法）

所有边按权值排序
贪心选取不形成环的边
核心依赖：并查集
时间复杂度：O(E log E)
适合：稀疏图

对比维度 Prim Kruskal
核心策略 加点（维护 dis 数组） 加边（排序 + 并查集）
时间复杂度 O(V²) O(E log E)
适合的图 稠密图（边多） 稀疏图（边少）
MST 结果 两种算法求出的总权值相同！
