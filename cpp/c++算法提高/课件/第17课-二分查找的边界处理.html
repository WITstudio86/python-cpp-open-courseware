lower_bound vs upper_bound

lower_bound(x)

查找第一个 ≥ x 的元素位置

判断条件：a[mid] >= x

即：找到"不小于 x"的第一个位置
也称"下界"

upper_bound(x)

查找第一个 > x 的元素位置

判断条件：a[mid] > x

即：找到"严格大于 x"的第一个位置
也称"上界"

示例数组：1, 2, 2, 3, 3, 3, 5, 7   查询 x = 3

lower_bound(3) = 3（第一个 ≥3 的位置） upper_bound(3) = 6（第一个 >3 的位置）

因此，3 在数组中出现了 6 - 3 = 3 次， 范围是 [3, 5]

【讲解】lower_bound vs upper_bound 本页要点（照着讲即可）： · 查找第一个 ≥ x 的元素位置 · 判断条件： a[mid] >= x · 即：找到"不小于 x"的第一个位置 也称"下界" · 查找第一个 > x 的元素位置 · 判断条件： a[mid] > x · 即：找到"严格大于 x"的第一个位置 也称"上界" 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：lower_bound、upper_bound、边界细节

/** * lower_bound：在升序数组中查找第一个 >= x 的位置 * @param a 升序数组 * @param n 数组长度 * @param x 目标值 * @return 第一个 >= x 的元素下标；若不存在则返回 n */ int lower_bound(int a[], int n, int x) { int left = 0, right = n - 1; int ans = n; // 默认答案：不存在 while (left <= right) { // 闭区间 [left, right] int mid = left + (right - left) / 2; if (a[mid] >= x) { // 找到了一个候选 ans = mid; // 记录当前位置 right = mid - 1; // 向左继续找更靠前的 } else { left = mid + 1; // a[mid] < x，去右边找 } } return ans; }
/** * upper_bound：在升序数组中查找第一个 > x 的位置 * 与 lower_bound 只有一处不同：判断条件从 >= 变成 > */ int upper_bound(int a[], int n, int x) { int left = 0, right = n - 1; int ans = n; while (left <= right) { int mid = left + (right - left) / 2; if (a[mid] > x) { // ⬅ 唯一的区别！ ans = mid; right = mid - 1; } else { left = mid + 1; } } return ans; }
/** * 利用 lower_bound + upper_bound 解决"数的范围" * first = lower_bound(x) → 起始位置 * last = upper_bound(x) - 1 → 终止位置 */ void find_range(int a[], int n, int x, int& first, int& last) { first = lower_bound(a, n, x); // 检查 x 是否存在 if (first == n || a[first] != x) { first = last = -1; return; } last = upper_bound(a, n, x) - 1; } // 核心关系： // 出现次数 = upper_bound(x) - lower_bound(x) // 起始位置 = lower_bound(x) // 终止位置 = upper_bound(x) - 1
【讲解】代码实现 本页要点（照着讲即可）： · 代码实现 · lower_bound · upper_bound · 数的范围 · * lower_bound：在升序数组中查找第一个 >= x 的位置 · * @param a 升序数组 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

逐步演示：查询 x = 3
1
调用 lower_bound(a, n, 3) → 二分查找第一个 ≥ 3 的位置 → 返回 3（a[3] = 3 ✓）
2
检查 a[3] 是否真的等于 3？→ 是，确认 3 存在
3

本课小结

lower_bound — 下界

查找第一个 ≥ x 的位置。条件：a[mid] ≥ x 时记录答案并左移。返回 x 的"起始位置"。

upper_bound — 上界

查找第一个 > x 的位置。条件：a[mid] > x 时记录答案并左移。返回 x 的"结束边界+1"。

边界细节

while 用 left ≤ right（闭区间）确保每个元素都被检查。用 ans 变量记录候选答案，即使没匹配也能正确返回。

防溢出写法

mid = left + (right - left) / 2，不写 (left+right)/2，避免整数溢出，是二分查找的好习惯。

✦ 核心公式 ✦

出现次数 = upper_bound(x) − lower_bound(x)
起始位置 = lower_bound(x) | 终止位置 = upper_bound(x) − 1

判断 x 是否存在：lower_bound(x) < n && a[lower_bound(x)] == x

二分查找看似简单，边界细节是关键 —— 多动手写几遍，做到"闭眼写出"！
