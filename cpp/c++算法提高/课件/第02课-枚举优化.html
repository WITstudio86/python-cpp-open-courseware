📖 枚举优化四大策略

🎯 策略一：缩小范围

用数学分析找更紧的上下界
公鸡 ∈ [0,20] 而非 [0,100]

✂️ 策略二：剪枝 break

不可能满足条件时提前终止
b³ ≥ a³ 就 break

📐 策略三：减少嵌套

用等式推导，少写一层循环
xiao = 100 - gong - mu

🔄 策略四：利用对称性

约定顺序，避免排列重复
b ≤ c ≤ d，减少到1/6

剪枝可视化

枚举树 剪枝后 / | \ / | \ 1 2 3 ... → 1 2 ✂ (3不符合，整枝剪掉！) / \ / \ 1 2 1 2 ✂ ✓ ✂ ✓ (找到解)

💻 完美立方 —— 四重循环优化

问题描述

a³ = b³ + c³ + d³，其中 1 < b ≤ c ≤ d < a ≤ N

剪枝策略详解

for a ← 2 to N: a³ 预计算 for b ← 2 to a-1: ✂ b³ ≥ a³ → break ← 剪枝点1 for c ← b to a-1: ✂ b³+c³ ≥ a³ → break ← 剪枝点2 for d ← c to a-1: 检查 b³+c³+d³ == a³ ✂ sum > a³ → break ← 剪枝点3 
// 关键代码段
for (int d = c; d < a; d++) {
    int sum = b3 + c3 + d3;
    if (sum == a3) { /* 找到解！ */ }
    if (sum > a3) break;  // 剪枝：d再大更不可能
}
📊 效果：从朴素 O(N⁴) ≈ 1亿次 → 优化后实际约10万次，提升1000+倍

🏋️ 例题：回文平方数

回文数判断算法

判断 12321 是否回文： 原数: 12321 反转: ↓ 第1步: 取出1 → reversed = 0×10 + 1 = 1, n = 1232 第2步: 取出2 → reversed = 1×10 + 2 = 12, n = 123 第3步: 取出3 → reversed = 12×10 + 3 = 123, n = 12 第4步: 取出2 → reversed = 123×10 + 2 = 1232, n = 1 第5步: 取出1 → reversed = 1232×10 + 1 = 12321, n = 0 比较: 12321 == 12321 ✓ 是回文数！ 
// 回文判断函数
bool isPalindrome(int n) {
    int original = n, reversed = 0;
    while (n > 0) {
        reversed = reversed * 10 + n % 10;
        n /= 10;
    }
    return original == reversed;
}
🎯 1~30的回文平方数：1²=1, 2²=4, 3²=9, 11²=121, 22²=484, 26²=676

📝 本课小结

🎯 优化技巧速记

  • 范围缩小：买鸡上限100/5=20，而非100
  • break剪枝：当b³已经≥a³，后面的b更大，直接break
  • continue跳过：当不满足某条件时，跳过一次循环
  • 顺序约定：b≤c≤d，把组合变成排列，减少到1/6
