动态规划经典入门 · 每个物品选或不选

动态规划 背包问题 空间优化

n 个物品 · 容量 C · 每件最多一次 · 最大化总价值

01背包问题定义

给定 n 个物品和一个容量为 C 的背包：

  • 第 i 个物品重量为 w[i]，价值为 v[i]
  • 每个物品要么取（1）、要么不取（0），不能分割
  • 求不超过背包容量的前提下，能获得的最大总价值

示例数据

📦
物品 1
w=2, v=3
🎒
物品 2
w=3, v=4
💎
物品 3
w=4, v=5
👜
背包容量
C = 8
问题本质：在 2^n 种可能的选法中，找出满足容量约束、总价值最大的方案。 暴力枚举不可行（指数级），需要用动态规划。

二维DP解法

状态定义

dp[i][j] = 考虑前 i 个物品，容量为 j 时的最大价值

状态转移方程

dp[i][j] = max( dp[i-1][j] , dp[i-1][j-w[i]] + v[i] )

不选 ↑                       选 ↑ (前提: j ≥ w[i])

一维空间优化

观察

dp[i][j] 只依赖于上一行 dp[i-1][...]，可以压缩为一维数组：

dp[j] = max( dp[j] , dp[j - w[i]] + v[i] )

关键：为什么反向遍历？

// ✅ 正确：反向遍历（j从C递减到w[i]） for (int j = C; j >= w[i]; j--) dp[j] = max(dp[j], dp[j - w[i]] + v[i]); // ❌ 错误：正序遍历会导致同一物品被多次使用 // 因为 dp[j-w[i]] 可能已经在当前轮被更新过了！
原理：反向遍历时，dp[j - w[i]] 还是上一轮（i-1）的旧值， 保证第 i 个物品最多只被用一次。正序遍历时 dp[j - w[i]] 可能已经被第 i 个物品更新过，就会多用——变成完全背包。

一维DP代码（核心）

int dp[MAXC] = {0}; for (int i = 1; i <= n; i++) { for (int j = C; j >= w[i]; j--) { dp[j] = max(dp[j], dp[j - w[i]] + v[i]); } } return dp[C];
空间复杂度 时间复杂度
O(C) O(n × C)

例题解析

例题1：采药问题 🏥

n 株草药，每株需 t[i] 时间采摘、价值 v[i]，共 T 时间，求最大总价值。

转化：时间 = 重量，价值 = 价值 → 标准 01 背包
样例：T=70, n=3：草药 (71,100) (69,1) (1,2) → 答案 3
解释：选第2株(69,1) + 第3株(1,2) = 时间70，价值3

例题2：装箱问题 📦

箱子容量 V，n 个物品体积 v[i]，求最小剩余空间。

转化：体积 = 重量 = 价值 → 01背包求最大装入体积
答案 = V - dp[V]（总容量减去最大装入体积）
样例：V=24, n=6, 体积={8,3,12,7,9,7} → 答案 0
解释：选 8+3+12+1? 不对——选 12+3+9+? → 实际上能装满：8+7+9 = 24
// 装箱问题核心代码 for (int j = V; j >= vol; j--) dp[j] = max(dp[j], dp[j - vol] + vol); ans = V - dp[V]; // 最小剩余空间

本课小结

核心思想

  • 状态定义：dp[i][j] = 前 i 个物品、容量 j 的最大价值
  • 转移方程：dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
  • 二维 → 一维：dp[j] 反向遍历保证每件物品只用一次

解题模板

// 01背包一维模板 int dp[C+1] = {0}; for (int i = 0; i < n; i++) for (int j = C; j >= w[i]; j--) dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
