重叠子问题 —— 斐波那契的陷阱

计算 F(6) 时，朴素递归会产生大量重复计算：

F(6) / \ F(5) F(4) / \ / \ F(4) F(3) F(3) F(2) / \ / \ / \ F(3) F(2) F(2) F(1) F(2) F(1) / \ F(2) F(1)

红色节点 表示被重复计算的子问题。F(4) 算 2 次，F(3) 算 3 次，F(2) 算 5 次！

朴素递归时间复杂度：O(2n) —— n=50 时约需 1015 次计算，几乎无法完成。

【讲解】重叠子问题 —— 斐波那契的陷阱 结合讲义《重叠子问题（Overlapping Subproblems）》强调： · 上面递归树中被标出的重复节点，就是**重叠子问题**。所谓"重叠"，是指在递归求解过程中，同一个子问题会被反复求解多次。 · 动态规划的第一个核心洞察就是：**如果一个问题具有重叠子问题的性质，我们可以用一个数据结构（通常是数组）把已经求解过的子问题答案"记住"，下次再遇到时直接查表，而不是重新计算。** 幻灯片上可见要点： · 计算 F(6) 时，朴素递归会产生大量 重复计算 ： · 重复计算 · 红色节点 表示被重复计算的子问题。F(4) 算 2 次，F(3) 算 3 次，F(2) 算 5 次！ · 朴素递归时间复杂度： O(2 n ) —— n=50 时约需 10 15 次计算，几乎无法完成。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：重叠子问题、记忆数组

记忆化搜索原理 —— "备忘录"数组

核心思想：把算过的结果记下来，下次直接用

  1. 创建数组 memo[]，初始化为 -1（表示未计算）
  2. 每次调用函数时，先查 memo[n]：
    • 若已算过（≠ -1）→ 直接返回
    • 若未算过（= -1）→ 递归计算，存入 memo[n]
  3. 每个子问题只计算一次

≈ 1015 次
n=50，几乎不可能
记忆化搜索 O(n)
50 次
n=50，瞬间完成
// 记忆化的关键代码
long long memo[100];

long long fib(int n) {
    if (n <= 2) return 1;
    if (memo[n] != -1) return memo[n];  // 查表
    return memo[n] = fib(n-1) + fib(n-2);  // 计算并存
}

爬楼梯问题 —— 经典 DP 入门题

每次可以爬 1 级 或 2 级 台阶。从第 0 级开始，爬到第 n 级有多少种方法？

递推公式： f(n) = f(n-1) + f(n-2)

边界条件：f(1) = 1，f(2) = 2

long long climb(int n) {
    if (n == 1) return 1;   // 只有 1 级
    if (n == 2) return 2;   // 1+1 或 2
    if (memo[n] != -1) return memo[n];
    return memo[n] = climb(n-1) + climb(n-2);
}

理解要点：到达第 n 级，最后一步要么从 n-1 跨 1 级，要么从 n-2 跨 2 级。

【讲解】爬楼梯问题 —— 经典 DP 入门题 结合讲义《爬楼梯问题》强调： · 爬楼梯问题是斐波那契数列的一个经典变体，也是 LeetCode 上的著名题目（Climbing Stairs）。 · 问题描述：假设你正在爬楼梯。楼梯有 n 级台阶，每次你可以爬 1 级或 2 级。从第 0 级开始，你有多少种不同的方法可以爬到第 n 级？ · 分析：想爬到第 n 级，你有两种选择： · 从第 n-1 级爬 1 级上来。 · 从第 n-2 级爬 2 级上来。 幻灯片上可见要点： · 每次可以爬 1 级 或 2 级 台阶。从第 0 级开始，爬到第 n 级有多少种方法？ · 递推公式： f(n) = f(n-1) + f(n-2) · 递推公式： · 边界条件：f(1) = 1，f(2) = 2 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

本课小结 —— 记忆化搜索要点

  • 动态规划的核心：重叠子问题 + 最优子结构。当递归出现大量重复计算时，就是使用 DP 的信号。
  • 记忆化搜索 = 递归 + 备忘录：用数组存储已计算的结果，将指数级递归优化为线性。
  • 时间复杂度：O(子问题个数) × O(每个子问题的计算时间)。通常从 O(2n) 降到 O(n)。
  • 使用 long long：斐波那契数列增长极快，F(80) 已超 32 位整数范围，务必使用 64 位整数。
  • 爬楼梯：与斐波那契本质相同，是动态规划最经典的入门例题之一。
  • 下一课预告：自底向上的动态规划（迭代法）—— 省掉递归栈，进一步优化空间。
