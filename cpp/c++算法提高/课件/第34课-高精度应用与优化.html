压位存储原理

普通高精度：每个 int 只存 1位 十进制数字——浪费了 int 的存储能力！

核心思想：让每个 int 存储多位十进制数字

普通存储（十进制）

1 2 3 4 5 6 7 8

[0] [1] [2] [3] [4] [5] [6] [7]

需要 8个 数组元素

压位存储（万进制）

[5678]   [1234]

digits[0]   digits[1]

只需要 2个 数组元素！

效果对比

对比项 普通存储（BASE=10） 压位存储（BASE=10000）
数组长度 N 个元素 约 N/4 个元素
每次乘法循环次数 N 次 约 N/4 次
效率提升 基准 约 4 倍
进位计算 digit / 10, digit % 10 digit / 10000, digit % 10000
输出难度 简单，直接输出 需处理前导零
溢出风险 无（乘数 ≤ 10） 需注意乘数 × BASE 不超过 int 范围

万进制实现细节

1. 常量定义

const int BASE = 10000;   // 万进制基数
const int WIDTH = 4;       // 每段对应4位十进制数
vector<int> digits;         // 低位在前，高位在后

2. 乘法：高精度 × 低精度

void multiply(int x) {
    int carry = 0;
    for (int i = 0; i < digits.size(); i++) {
        long long cur = (long long)digits[i] * x + carry;
        digits[i] = cur % BASE;    // 当前段
        carry = cur / BASE;          // 进位
    }
    while (carry > 0) {           // 处理剩余进位
        digits.push_back(carry % BASE);
        carry /= BASE;
    }
}

3. 输出：前导零处理（最容易出错！）

void print() {
    cout << digits.back();              // 最高段：不补零
    for (int i = digits.size() - 2; i >= 0; i--) {
        cout << setw(WIDTH) << setfill('0') << digits[i];
    }
}
错误示范（忘记补零）

digits = [2, 1]

输出 → "12"

（10002 变成了 12！）

正确做法

digits = [2, 1]

输出 → "10002"

（2 补零为 0002，正确！）

例题2：Hanoi双塔问题

A 柱上有 2n 个圆盘（n 种大小，每种 2 个），按汉诺塔规则全部移到 C 柱。

最少移动次数   H(n) = 2 n+1 − 2

递推推导：

  1. 将上面 2(n-1) 个圆盘从 A 移到 B：H(n-1) 步
  2. 将最大的 2 个圆盘从 A 移到 C：2 步
  3. 将 B 上 2(n-1) 个圆盘移到 C：H(n-1) 步
H(n) = 2 × H(n-1) + 2  →  H(n) = 2 n+1 − 2

验证：n=1 → 22-2=2；n=2 → 23-2=6 ✓

本课小结

01
压位存储让每个数组元素存储 4 位十进制数，数组长度缩减为原来的约 1/4，运算效率提升约 4 倍。
02
万进制实现：进位/借位基数变为 10000，使用 long long 防止中间结果溢出。
03
前导零处理：非最高段输出时必须用 setw(4) << setfill('0') 补齐到 4 位，这是最容易出错的地方！
04
2的N次方：循环 n 次每次乘 2，n=500 时结果有 151 位数字，万进制下仅需 38 个段。
05
Hanoi双塔：最少移动次数 H(n) = 2n+1 - 2，先计算 2n+1 再减去 2 即可。
06
扩展思路：压位思想可推广到亿进制（BASE=100000000），进一步压缩，但需注意 int 溢出问题。

核心收获：用更少的容器，装同样多的信息，让高精度计算飞起来！
