第 22 课 · 贪心算法

背包贪心
部分背包

当物品可以切割时，简单的性价比排序就能找到最优解。
本节学习分数背包与最优装载两大经典贪心问题。

性价比排序 部分背包 金银岛 最优装载
01 对比：0/1 背包 vs 部分背包

01 0/1 背包（不可分割）

  • 每件物品要么全拿，要么不拿
  • 贪心策略（按性价比装）可能失败
  • 需要用动态规划 DP 求解
  • 时间复杂度：O(N × C)，N件物品，C为容量
  • 状态转移：dp[j] = max(dp[j], dp[j-w] + v)

½ 部分背包（可分割）

  • 物品可以切割，取任意比例
  • 贪心策略（按性价比装）总是最优
  • 排序 + 贪心 即可完美求解
  • 时间复杂度：O(N log N)，瓶颈在排序
  • 贪心标准：value / weight（性价比）
关键洞察：物品能否分割，决定了贪心策略是否有效。
可分割 → 不存在"替换"问题，每个单位重量独立决策 → 贪心即最优。
不可分割 → 拿一件完整物品会占空间，可能挤出更有价值的组合 → 需要 DP。

数学证明（交换论证）：如果存在比贪心更优的方案，它一定在某处用低性价比物品替代了高性价比物品。将这部分替换后，总价值只增不减，因此贪心解不可能被超越。

02 核心代码：部分背包的贪心实现
▸ 金属结构体 & 排序
struct Metal { double weight; // 重量 double value; // 总价值 double ratio; // 性价比 = 价值 / 重量 Metal(double w, double v) : weight(w), value(v) { ratio = v / w; } bool operator<(const Metal& other) const { return ratio > other.ratio; // 降序排列 } };
▸ 贪心装入函数
double fractionalKnapsack(vector<Metal>& items, double C) { sort(items.begin(), items.end()); // 按性价比排序 double ans = 0.0, remain = C; for (auto& m : items) { if (remain >= m.weight) { // 够装整个 ans += m.value; remain -= m.weight; } else if (remain > 0) { // 只能装部分 ans += m.ratio * remain; // 部分价值 break; // 背包满了 } } return ans; }
03 经典例题：金银岛（逐步演示）

题目描述

N=3 种金属，背包容量 C=50 千克。
金属1: 10kg, 60金币 | 金属2: 20kg, 100金币 | 金属3: 30kg, 120金币

1
计算性价比
金属1: 60/10 = 6.0  |  金属2: 100/20 = 5.0  |  金属3: 120/30 = 4.0
2
按性价比降序排列
金属1 (6.0) → 金属2 (5.0) → 金属3 (4.0)
3
贪心装入
装金属1: 10kg，获60金币，剩余40kg →
装金属2: 20kg，获100金币，剩余20kg →
装金属3（部分）: 取20kg，获20×4=80金币 → 背包满！
✓
结果：最大价值 = 240.00 金币
60 + 100 + 80 = 240

04 经典例题：最优装载

题目描述

货轮载重 C=50 吨，有 N=6 个集装箱。
重量: [30, 10, 15, 20, 25, 5] 吨。每个集装箱不可切割。
目标：最大化装载数量（不关心价值，只看个数）。

输入样例
6 50
30 10 15 20 25 5
输出样例
4
贪心策略：按重量从小到大排序 → [5, 10, 15, 20, 25, 30]
依次装载：5+10+15+20=50（恰好装满），共4个集装箱。
为什么正确？每个箱子对"数量"的贡献相同，应优先选择消耗载重最少的。
排序 vs 装船直观对比： 排序前: 30, 10, 15, 20, 25, 5 → 排序后: 5, 10, 15, 20, 25, 30 → 装船: 5+10+15+20=50
05 本课小结
问题 排序依据 贪心方向 目标 复杂度
部分背包 性价比（v/w） 从大到小 最大化总价值 O(N log N)
最优装载 重量（w） 从小到大 最大化物品数量 O(N log N)

04
贪心核心：确定正确的"评价标准"，局部最优 → 全局最优
