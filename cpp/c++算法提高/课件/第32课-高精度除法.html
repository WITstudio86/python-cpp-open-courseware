高精度除法

竖式除法模拟 · 逐位取商 · 减法模拟除法

高精度四则运算的最后一块拼图

竖式除法回顾

小学竖式：12345 ÷ 12

1 0 2 8 ... 余 9 ← 商 ┌───────────────────── 12 │ 1 2 3 4 5 ← 被除数 1 2 ← 12×1=12 ───── 0 3 ← 余0，带下3 0 ← 3<12，商0 ───── 3 4 ← 带下4：34 2 4 ← 12×2=24 ───── 1 0 5 ← 带下5：105 9 6 ← 12×8=96 ───── 9 ← 最终余数
竖式除法的核心步骤：
  1. 从被除数高位开始，取出一部分
  2. 看这部分能容纳几个除数 → 得到商位
  3. 减去 除数 × 商位 → 得到余数
  4. 余数 × 10 + 下一位 → 回到步骤 2，继续

高精度除以单精度

算法原理（O(n)）

从左到右遍历被除数，每次：cur = 上一位余数 × 10 + 当前位

示例：1234 ÷ 5 i=0: cur = 0×10+1 = 1, 1/5=0（商0）, 1%5=1（余1） i=1: cur = 1×10+2 = 12, 12/5=2（商2）, 12%5=2（余2） i=2: cur = 2×10+3 = 23, 23/5=4（商4）, 23%5=3（余3） i=3: cur = 3×10+4 = 34, 34/5=6（商6）, 34%5=4（余4） 商 = "246"，余数 = 4 验证：5 × 246 + 4 = 1234 ✓
// 高精度除以单精度的核心代码 string div_single(const string &num, int divisor, int &remainder) { string quotient; long long cur = 0; for (int i = 0; i < num.size(); i++) { cur = cur * 10 + (num[i] - '0'); // 带上一位的余数 quotient += char(cur / divisor + '0'); // 商位 cur %= divisor; // 新的余数 } remainder = (int)cur; // 去除前导零后返回 quotient }
时间复杂度
O(n)
关键点
逐位取商，余数传递

高精度除以高精度

核心思想：用减法模拟除法

"除法就是看被除数能减去多少个除数"

示例：4567 ÷ 23（补零加速） ① 23 → 2300（补2个零） 4567 - 2300 = 2267 商 += 100 ② 2267 < 2300 → 缩小：23 → 230（补1个零） 2267 - 230 = 2037 → 1807 → 1577 → ... 共减 9 次 商 += 90 ③ 197 < 230 → 缩小：23 197 - 23 = 174 → ... 共减 8 次 商 += 8 ④ 余 13 < 23 → 停止 商 = 100 + 90 + 8 = 198，余数 = 13 验证：23 × 198 + 13 = 4567 ✓
时间复杂度
O(n × m)
辅助函数
比较、减法、加法

除法代码实现

高精度除以单精度

// 简洁高效：一次遍历 O(n) string div_single(const string &a, int b, int &r) { string q; long long cur = 0; for (int i = 0; i < (int)a.size(); i++) { cur = cur * 10 + (a[i] - '0'); q += char(cur / b + '0'); cur %= b; } r = (int)cur; // 去前导零 int s = 0; while (s < (int)q.size()-1 && q[s] == '0') s++; return q.substr(s); }

高精度除以高精度（减法模拟核心）

// 需要辅助函数：compare(), subtract(), add() while (compare(remainder, b) >= 0) { string temp = b; // 扩大后的除数 string weight = "1"; // 当前权重 while (compare(remainder, temp + "0") >= 0) { temp += "0"; // 除数 × 10 weight += "0"; // 权重 × 10 } while (compare(remainder, temp) >= 0) { remainder = subtract(remainder, temp); quotient = add(quotient, weight); } }

高精度运算总结

四则运算对比

运算 时间复杂度 核心技巧 难度
加法 O(max(n,m)) 逐位相加，即时进位 ⭐
减法 O(max(n,m)) 逐位相减，不够借位 ⭐
乘法 O(n×m) 逐位相乘累加，统一进位 ⭐⭐
除法 O(n) / O(n×m) 逐位取商 / 减法模拟 ⭐⭐⭐
本课核心要点：
  • 除单精度 O(n)：cur = cur*10 + a[i]，逐位取商
  • 除高精度 O(n×m)：用减法模拟，补零加速
  • 高精度除高精度需要比较、减法、加法三个辅助函数
  • 除法是四则运算中最复杂的，需要综合运用前面所学
