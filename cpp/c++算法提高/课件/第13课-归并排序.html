第13课：归并排序

合并有序序列 —— 分治策略的经典应用


学习目标：
1. 理解归并排序的分治策略：先递归分解，再合并有序子数组
2. 掌握合并两个有序数组（merge）的双指针操作
3. 能够利用归并排序解决逆序对计数等问题

┌─────────────────────────────────────────────┐ │ 归 并 排 序 的 三 部 曲 │ ├─────────────────────────────────────────────┤ │ 分 (Divide) → 把大数组对半拆分成小数组 │ │ 治 (Conquer) → 递归地使每个小数组变有序 │ │ 合 (Combine) → 把有序小数组两两合并 │ └─────────────────────────────────────────────┘

核心思想：把排序一个大数组的问题，分解为排序两个小数组的问题。
当小到只剩1个元素时（天然有序），再自底向上地两两合并成有序序列。

一、分治思想：把大问题变成小问题

生活中的类比

想象你在整理一副散乱的扑克牌：

  • 不分治：一张一张地挑，52张牌要比较很多次
  • 分治：把52张分成两叠26张 → 分别排好 → 合并
  • 26张还是太多？继续分 —— 直到每叠只有1张（天然有序！）

递归分解过程（以 [8, 4, 5, 7, 1, 3, 6, 2] 为例）

第0层 [8, 4, 5, 7, 1, 3, 6, 2] → 拆成两半
第1层 [8, 4, 5, 7] | [1, 3, 6, 2]
第2层 [8, 4] [5, 7]  |  [1, 3] [6, 2]
第3层 [8] [4] [5] [7]  |  [1] [3] [6] [2] ← 每个都是"有序"的！
关键洞察：单个元素天然就有序。递归的"终止条件"就是区间长度 ≤ 1。
分解的层数 = log₂(n)，例如 8 个元素分解了 3 层（log₂8 = 3）。

二、核心操作：合并两个有序数组

归并排序最关键的一步。假设我们已经有两个排好序的小数组，如何合并？

双指针法图解

初始 左: [4, 8]   i=0 (指向4)
右: [5, 7]   j=0 (指向5)
临时: [_]   k=0
步骤1 比较 4 vs 5 → 4 更小 → 取 4 放入 temp
左: [4✓, 8]   i=1
临时: [4]
步骤2 比较 8 vs 5 → 5 更小 → 取 5 放入 temp
右: [5✓, 7]   j=1
临时: [4, 5]
步骤3 比较 8 vs 7 → 7 更小 → 取 7 放入 temp
右: [5✓, 7✓]   j=2 (超出)
临时: [4, 5, 7]
步骤4 右边空了 → 把左边剩余的 [8] 全搬过来
临时: [4, 5, 7, 8] → 拷贝回原数组
// 合并的核心逻辑（伪代码） while (左边和右边都有元素) { if (左[i] <= 右[j]) temp[k++] = 左[i++]; else temp[k++] = 右[j++]; } // 把剩余的元素全搬过去 while (左边还有) temp[k++] = 左[i++]; while (右边还有) temp[k++] = 右[j++];
注意：使用 <= 而非 <，保证了归并排序的稳定性——相等元素保持原有相对顺序。

三、完整排序过程：自底向上构建有序序列

继续用 [8, 4, 5, 7, 1, 3, 6, 2] 演示，从叶子节点向上合并：

第1轮合并 [8]+[4] → [4,8]    [5]+[7] → [5,7]
[1]+[3] → [1,3]    [6]+[2] → [2,6]
第2轮合并 [4,8] + [5,7] → 逐个比较：
  4 vs 5→取4 | 8 vs 5→取5 | 8 vs 7→取7 | 剩8→取8
→ [4, 5, 7, 8]
第2轮合并 [1,3] + [2,6] → 逐个比较：
  1 vs 2→取1 | 3 vs 2→取2 | 3 vs 6→取3 | 剩6→取6
→ [1, 2, 3, 6]
第3轮合并 ✓ [4,5,7,8] + [1,2,3,6] → 逐个比较：
  4 vs 1→取1 | 4 vs 2→取2 | 4 vs 3→取3
  4 vs 6→取4 | 5 vs 6→取5 | 7 vs 6→取6 | 剩7,8→依次取
→ [1, 2, 3, 4, 5, 6, 7, 8] ✓ 排序完成！

递归树视角

┌───────── [1,2,3,4,5,6,7,8] ─────────┐ ← 第0层（合并 n 个元素） │ │ ┌── [4,5,7,8] ──┐ ┌── [1,2,3,6] ──┐ ← 第1层 │ │ │ │ [4,8] [5,7] [1,3] [2,6] ← 第2层 | | | | | | | | [8][4] [5][7] [1][3] [6][2] ← 第3层（叶子节点） 每一层合并所有元素 → O(n) 共 log₂n 层 → O(n log n)
【讲解】三、完整排序过程：自底向上构建有序序列 本页要点（照着讲即可）： · 继续用 [8, 4, 5, 7, 1, 3, 6, 2] 演示，从叶子节点向上合并： · [4, 5, 7, 8] · [1, 2, 3, 6] · [1, 2, 3, 4, 5, 6, 7, 8] ✓ 排序完成！ 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

四、代码实现（带详细注释）

合并函数 merge

void merge(vector<int>& arr, int left, int mid, int right) { vector<int> temp(right - left + 1); // 临时数组 int i = left; // 左子数组指针 int j = mid + 1; // 右子数组指针 int k = 0; // 临时数组指针 // 两个子数组都有元素时，谁小取谁 while (i <= mid && j <= right) { if (arr[i] <= arr[j]) temp[k++] = arr[i++]; else temp[k++] = arr[j++]; } // 把剩余元素搬过去 while (i <= mid) temp[k++] = arr[i++]; while (j <= right) temp[k++] = arr[j++]; // 拷贝回原数组 for (int t = 0; t < temp.size(); t++) arr[left + t] = temp[t]; }

递归排序函数 mergeSort

void mergeSort(vector<int>& arr, int left, int right) { if (left >= right) return; // 终止：≤1个元素 int mid = left + (right - left) / 2; // 防止溢出 mergeSort(arr, left, mid); // 递归排序左半 mergeSort(arr, mid + 1, right); // 递归排序右半 merge(arr, left, mid, right); // 合并左右有序子数组 }
入口调用：mergeSort(arr, 0, n - 1); 即可对整个数组排序。
注意 mid 用 left + (right - left) / 2 而非 (left + right) / 2，防止 left + right 溢出。
【讲解】四、代码实现（带详细注释） 结合讲义《💻 代码实现》强调： · using namespace std; · // ================================================================ · // 函数：合并两个有序子数组 · // 参数说明： · // arr - 原始数组 幻灯片上可见要点： · 入口调用： 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

五、复杂度分析

时间复杂度：O(n log n)（始终稳定）

  • 递归深度：每次对半分，共 log₂n 层
  • 每层工作量：每层对所有 n 个元素做一次合并 = O(n)
  • 总量：n × log₂n 次操作，无论输入如何都是这个量

空间复杂度：O(n)

  • 合并时需要大小为 n 的临时数组（最坏情况是合并整层时）
  • 递归调用栈深度为 log₂n，额外 O(log n)
  • 总计 O(n + log n) = O(n)

归并排序 vs 快速排序

比较维度归并排序快速排序
核心操作合并（合）划分（分）
时间复杂度始终 O(n log n)平均 O(n log n)，最坏 O(n²)
空间复杂度O(n) —— 需要额外数组O(log n) —— 递归栈
稳定性✅ 稳定❌ 不稳定
递归顺序后序（先递归，后合并）前序（先划分，后递归）
适用场景链表排序、外部排序、要求稳定内存受限、追求平均速度
记忆口诀：快速排序是"先分后排"，归并排序是"先排后合"。
归并排序需要额外空间，但换来的是稳定和性能可预测。

六、经典应用：求逆序对

逆序对定义：对于序列 a，如果 i < j 且 a[i] > a[j]，则 (a[i], a[j]) 是一个逆序对。

如何在归并中统计？

场景 合并时，左: [3, 5, 8] 右: [2, 6, 9]
当 arr[i] > arr[j] 时……
关键发现 因为左子数组已经有序，如果 arr[i] > arr[j]，
那么 arr[i], arr[i+1], ..., arr[mid] 全部大于 arr[j]
→ 一次就找到 (mid - i + 1) 个逆序对！

示例：序列 [3, 1, 4, 2, 5]

分解: [3, 1, 4] | [2, 5] → [3, 1] | [4] + [2] | [5] → [3] | [1] + [4] + [2] | [5] 合并 [3] 和 [1]: 3 > 1 → 逆序对 +1 (3,1) 合并 [3,1] → 变为 [1,3] 合并 [1,3] 和 [4]: 无逆序对 → [1,3,4] 合并 [2] 和 [5]: 无逆序对 → [2,5] 合并 [1,3,4] 和 [2,5]: i=0(1) vs j=0(2): 1 < 2 → 取1 i=1(3) vs j=0(2): 3 > 2 → ★逆序对 +2★ {(3,2),(4,2)} i=1(3) vs j=1(5): 3 < 5 → 取3 i=2(4) vs j=1(5): 4 < 5 → 取4 i=3(超出) → 取剩余5 逆序对总数: 1 + 2 = 3 {(3,1), (3,2), (4,2)}

核心代码

while (i <= mid && j <= right) { if (arr[i] <= arr[j]) { temp[k++] = arr[i++]; } else { temp[k++] = arr[j++]; count += (mid - i + 1); // ★ 累加逆序对 ★ } }
注意：逆序对数量最多可达 n(n-1)/2（n=100000时约 5×10⁹），
超过 int 范围（约 2.1×10⁹），必须使用 long long 类型！
【讲解】六、经典应用：求逆序对 结合讲义《七、归并排序的"副产品"——求逆序对》强调： · 在合并两个有序子数组的过程中，我们可以顺手统计"逆序对"的数量。 · 什么情况下会产生逆序对呢？在合并时，当我们发现**右边的某个元素比左边当前元素还要小**，这意味着：左边当前元素及其后面的所有元素，都和这个右边的元素构成逆序对。 · 合并中检测逆序对： · 左: [3, 5, 8] 右: [2, 6, 9] · i=0 j=0 幻灯片上可见要点： · 逆序对定义： 对于序列 a，如果 i a[j]，则 (a[i], a[j]) 是一个逆序对。 · 逆序对定义： · (mid - i + 1) · long long 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
