分治三步走

分(Divide) — 治(Conquer) — 合(Combine)

1

分 Divide

将原问题划分为若干个规模更小的子问题， 子问题与原问题形式相同。

2

治 Conquer

递归求解各个子问题。 当子问题规模足够小时，直接求解（递归基）。

3

合 Combine

将子问题的解合并成原问题的解。 这是分治算法的关键——合并的效率决定整体效率。

以归并排序为例 —— 递归树展示：

[38, 27, 43, 3, 9, 82, 10] / \ / \ [38, 27, 43, 3] [9, 82, 10] / \ / \ / \ / \ [38, 27] [43, 3] [9, 82] [10] / \ / \ / \ | [38] [27] [43] [3] [9] [82] [10] ← 分到最小 \ / \ / \ / | [27,38] [3,43] [9,82] [10] ← 开始合 \ / \ / [3,27,38,43] [9,10,82] ← 合并有序子数组 \ / [3, 9, 10, 27, 38, 43, 82] ← 最终有序
时间复杂度：T(n) = 2T(n/2) + O(n) → O(n log n)

最大子段和问题

Maximum Subarray — 经典的分治应用

问题描述：
给定一个整数数组 a[1..n]， 求其连续子数组的最大和（允许空子数组，和为 0）。

例：[-2, 1, -3, 4, -1, 2, 1, -5, 4]
→ 最大子段和 = 6（子数组 [4, -1, 2, 1]）

分治思路：

  • 分：将数组从中间 mid 分成左右两半
  • 治：递归求左半部分和右半部分的最大子段和
  • 合：考虑跨越中点的情况——从 mid 向左扫描最大后缀和，向右扫描最大前缀和，二者相加
  • 答案：max(左半答案, 右半答案, 跨越中点的答案)
// 分治法求最大子段和 O(n log n) int maxSubArray(int a[], int l, int r) { if (l == r) return max(0, a[l]); // 递归基 int mid = (l + r) / 2; // 1. 递归求左右两边的最大子段和 int leftMax = maxSubArray(a, l, mid); int rightMax = maxSubArray(a, mid + 1, r); // 2. 求跨越中点的最大子段和 int leftSum = 0, maxLeft = 0; for (int i = mid; i >= l; i--) { leftSum += a[i]; maxLeft = max(maxLeft, leftSum); } int rightSum = 0, maxRight = 0; for (int i = mid + 1; i <= r; i++) { rightSum += a[i]; maxRight = max(maxRight, rightSum); } int crossMax = maxLeft + maxRight; // 3. 返回三者最大值 return max({leftMax, rightMax, crossMax}); }
【讲解】最大子段和问题 本页要点（照着讲即可）： · Maximum Subarray — 经典的分治应用 · 问题描述： 给定一个整数数组 a[1..n] ， 求其连续子数组的最大和（允许空子数组，和为 0）。 · 问题描述： · 分治思路： · 分： 将数组从中间 mid 分成左右两半 · 治： 递归求左半部分和右半部分的最大子段和 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

棋盘覆盖问题

L 形骨牌覆盖 2k × 2k 棋盘 —— 分治的几何应用

问题描述：
在一个 2k × 2k 的棋盘上，恰好有一个方格是特殊方格（缺失）。 用 L 形骨牌（占据 3 个方格，形状如「┣」）覆盖所有非特殊方格， 骨牌之间不可重叠。

关键性质：2k × 2k 棋盘去掉一格后，
一定可以用 L 形骨牌完全覆盖！

分治策略：

  • 将 2k×2k 棋盘分为 4 个 2k-1×2k-1 子棋盘
  • 特殊格必在其中一个子棋盘中
  • 在棋盘中心放置一个 L 形骨牌，使其覆盖另外三个子棋盘各一格
  • 这样四个子棋盘各有一个"特殊格"，递归求解
棋盘 (k=2, 4×4, ★=特殊格): ┌───────┬───────┐ │ │ │ 1. 将棋盘分成 4 个 2×2 子棋盘 │ ★ │ │ │ │ │ 2. 特殊格 ★ 在左上子棋盘 ├───────┼───────┤ │ │ │ 3. 在中心放 L 形骨牌（用数字标记） │ │ │ 覆盖右下 / 左下 / 右上 │ │ │ 各一格 └───────┴───────┘ 放置 L 骨牌后的递归： ★ ① ① ① ← 数字表示 L 骨牌覆盖 ─────── ─── ① 递归处理 4 个 2×2 子棋盘， 每个都有恰好一个"特殊格"！ 覆盖结果示意 (相同数字 = 同一 L 骨牌): 2 2 3 3 2 1 1 3 5 个 L 形骨牌完美覆盖！ 4 1 5 5 4 4 ★ 5 (★ 为原始特殊格)
时间复杂度递推：T(k) = 4·T(k-1) + O(1)
→ T(k) = O(4k) = O(n2)（n = 2k 为边长）

分治算法总结

核心思想回顾 · 复杂度分析 · 适用场景

核心思想

将原问题划分为若干个规模较小的同类子问题， 递归求解后合并子问题的解得到原问题的解。

适用条件

  • 问题可以分解为形式相同的子问题
  • 子问题之间相互独立（无公共子问题）
  • 子问题的解可以合并为原问题的解
  • 分解到足够小时可以直接求解（递归基）
