问题引入：指数爆炸的挑战

一个看似简单的问题

计算 ab mod m，其中 a、b、m 都是非常大的整数。
例如：计算 21000000000 mod (109+7)，直接循环 109 次？

⏱️ 朴素算法的困境：
// 朴素方法：O(b) —— b 次循环！
long long result = 1;
for (int i = 0; i < b; i++) {
    result = (result * a) % m;  // 每次模运算防止溢出
}
// 当 b = 10^9 时，需要 10^9 次循环，约 1 秒（勉强）
// 当 b = 10^18 时，需要 10^18 次循环，约 30 亿年！

算法竞赛

RSA 等算法需要计算 ab mod m，b 可达 22048
核心洞察：利用指数的"可拆分性"，将 b 次乘法减少到 log2(b) 次！

快速幂代码实现

版本一：递归实现

// 递归快速幂 (带取模)
long long qpow_recursive(long long a, long long b, long long m) {
    if (b == 0) return 1 % m;           // 任何数的0次方 = 1
    long long half = qpow_recursive(a, b / 2, m);
    half = (half * half) % m;           // 先平方
    if (b % 2 == 1)                     // 奇数多乘一个a
        half = (half * a) % m;
    return half;
}
// 调用: qpow_recursive(2, 10, 1000000007) → 1024

版本二：迭代实现（推荐）

// 迭代快速幂 —— 更高效，无递归栈开销
long long qpow(long long a, long long b, long long m) {
    long long result = 1 % m;           // 初始化结果
    a = a % m;                          // 先取模，防溢出
    while (b > 0) {
        if (b & 1)                      // b 的最低位是 1
            result = (result * a) % m;  // 奇数时乘入答案
        a = (a * a) % m;                // a 自乘，对应指数翻倍
        b >>= 1;                        // b 右移一位（等价于 b/2）
    }
    return result;
}
// 调用: qpow(2, 10, 1000000007) → 1024
位运算技巧说明：
b & 1 → 判断 b 的二进制最低位是否为 1（等价于 b % 2 == 1）
b >>= 1 → b 右移一位（等价于 b / 2），每次循环指数减半
【讲解】快速幂代码实现 本页要点（照着讲即可）： · 位运算技巧说明： 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

矩阵快速幂入门

将快速幂思想扩展到矩阵

矩阵乘法也有结合律：(A × B) × C = A × (B × C)，因此快速幂同样适用！

斐波那契数列与矩阵

┌──────────────────────────────────────────────┐ │ Fibonacci 的矩阵形式（n ≥ 2）： │ │ │ │ ┌ ┐ ┌ ┐^n ┌ ┐ │ │ │ F(n+1) │ = │ 1 1 │ × │ F(1) │ │ │ │ F(n) │ │ 1 0 │ │ F(0) │ │ │ └ ┘ └ ┘ └ ┘ │ │ │ │ 其中 F(0) = 0, F(1) = 1 │ └──────────────────────────────────────────────┘

矩阵快速幂代码（2×2 矩阵）

struct Matrix {
    long long m[2][2];
    Matrix() { m[0][0]=m[0][1]=m[1][0]=m[1][1]=0; }
};

Matrix mul(Matrix a, Matrix b, long long mod) {
    Matrix c;
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++)
            for (int k = 0; k < 2; k++)
                c.m[i][j] = (c.m[i][j] + a.m[i][k] * b.m[k][j]) % mod;
    return c;
}

Matrix mat_qpow(Matrix a, long long n, long long mod) {
    Matrix res;
    res.m[0][0] = res.m[1][1] = 1 % mod;  // 单位矩阵
    while (n > 0) {
        if (n & 1) res = mul(res, a, mod);
        a = mul(a, a, mod);
        n >>= 1;
    }
    return res;
}

// 求第 n 项斐波那契数：F(n) = mat_qpow(base, n, mod).m[0][1]
矩阵快速幂的威力：
普通递推求 F(109) → O(n)，完全不可行
矩阵快速幂求 F(109) → O(log n)，约 30 次矩阵乘法即可！

核心口诀

┌──────────────────────────────────────────────────┐ │ 快速幂，真巧妙，指数拆成二进制瞧： │ │ 最低位是 1 就乘上，底数平方不能忘； │ │ 指数右移减一半，log 级别飞一样！ │ │ 矩阵快速幂同理，Fib 第 n 项秒出结果不用慌。 │ └──────────────────────────────────────────────────┘

算法要点

  • 指数 b → 二进制 → 每位的 1 决定是否乘入
  • 底数 a 不断自乘（平方）
  • 迭代版用位运算更高效
  • 记得每一步取模防止溢出
  • 矩阵快速幂 = 快速幂 + 矩阵乘法

⚠️ 易错点

  • 忘记初始取模：a = a % m
  • result 初始化为 1 % m（非 1），防 m=1 的情况
  • 矩阵乘法注意取模和顺序
  • 递归版中 b 为奇数时不要漏乘 a
  • long long 也可能溢出？考虑 __int128
