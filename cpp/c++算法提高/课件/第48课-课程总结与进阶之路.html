模拟测试 —— 检验学习成果

3 道综合题 · 建议时间 2.5 小时

题目 1：图的连通分量

图论DFS/BFS

描述：给定 N 个节点 M 条边的无向图，求连通分量的个数和每个分量的大小。

解法：DFS/BFS 遍历 + visited 标记。复杂度 O(N+M)。

题目 2：最小花费路径

DP二维DP

描述：N×M 网格，每格有花费。从左上角到右下角，只能向右或向下移动，求最小总花费。

解法：dp[i][j] = cost[i][j] + min(dp[i-1][j], dp[i][j-1])。复杂度 O(N×M)。

题目 3：最短路径计数

图论DPDAG

描述：在 DAG 中，求从节点 1 到节点 N 的最短路径长度（按边数）和不同路径的条数。

解法：拓扑排序 + DP。dist[v] 更新时重置 cnt，相同时累加。复杂度 O(N+M)。

解题提示

// 题目3：拓扑排序 + DP 核心
for (int u : topo_order) {
    for (int v : adj[u]) {
        if (dist[v] > dist[u] + 1) {
            dist[v] = dist[u] + 1; cnt[v] = cnt[u];
        } else if (dist[v] == dist[u] + 1) {
            cnt[v] = (cnt[v] + cnt[u]) % MOD;
        }
    }
}

竞赛准备与学习方法

竞赛准备清单

  1. 熟练掌握 STL：vector, stack, queue, priority_queue, set, map, sort, next_permutation
  2. 模板代码：整理常用算法模板（快排、二分、Dijkstra、并查集等），赛前打印或熟记
  3. 对拍验证：写暴力程序 + 随机数据生成器 + 对拍脚本，确保算法正确性
  4. 时间复杂度估算：1秒约 10^8 次基本运算，根据数据范围选择合适的算法
  5. 常见坑点：long long 溢出、数组越界、未初始化、多组数据未重置

高效学习方法

  1. 多做题 > 多看题：看题解能理解，但自己写才是真掌握
  2. 做题 → 总结 → 复习：每道题做后记笔记（核心思路/坑点/技巧）
  3. 打比赛：参加洛谷/Codeforces 定期比赛，限时训练抗压能力
  4. 补题：赛后再做没做出的题，研究题解的多种解法
  5. 刷专题：按知识点刷题（DP专题、图论专题），集中突破弱点

竞赛策略

先易后难 → 对拍验证 → 部分分获取 → 时间管理
