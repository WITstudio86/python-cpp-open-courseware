递归与分治 —— 知识回顾

递归三要素

① 终止条件 (Base Case)
问题足够小，可以直接求解
例：n == 0 或 n == 1
② 递归关系 (Recurrence)
将大问题转化为同构的小问题
例：f(n) = n * f(n-1)
③ 递归调用 (Recursive Call)
函数调用自身，向终止条件逼近
每次递归，问题规模必须减小

幂次方表示 —— 递归嵌套分解

问题描述

将正整数表示为 2 的幂次方之和，且指数也要递归分解。
最终表达式只包含 2、0 和括号 ()。

n = 137 → 2(2(2)+2+2(0)) + 2(2+2(0)) + 2(0)

递归思路图解

137 的二进制 = 10001001 → 第7位、第3位、第0位为 1 ┌─ 2^7 → 指数 7 │ 7 的二进制 = 111 → 2^2 + 2^1 + 2^0 │ → 2( 2(2) + 2 + 2(0) ) │ ↑ ↑ ↑ │ 2^2=2(2) 2^1=2 2^0=2(0) ← 指数也递归分解！ │ ├─ 2^3 → 指数 3 │ 3 的二进制 = 11 → 2^1 + 2^0 │ → 2( 2 + 2(0) ) │ └─ 2^0 → 2(0) 拼接结果：2(2(2)+2+2(0)) + 2(2+2(0)) + 2(0)

递归终止条件

n == 0 → 返回 "0"
用于表示指数为 0
n == 1 → 返回 ""
约定 2^1 简写为 "2"，省略括号

幂次方表示 —— 代码实现

核心递归函数

string powerRepr(int n) {
    if (n == 0) return "0";      // 终止：指数为0
    if (n == 1) return "";        // 终止：2^1简写

    string result = "";
    bool first = true;

    for (int i = 15; i >= 0; i--) {  // 高位→低位扫描
        if (n & (1 << i)) {              // 第i位为1
            if (!first) result += "+";
            first = false;

            if (i == 0)      result += "2(0)";
            else if (i == 1) result += "2";
            else result += "2(" + powerRepr(i) + ")";
        }
    }
    return result;
}

关键技巧： 从高位向低位扫描二进制位，使用 first 标志控制 + 的输出时机。

FBI树 —— 二叉树的递归构建

问题描述

给定长度为 2N 的 "01" 串，递归构建 FBI 树并输出后序遍历。

节点类型判断

B 全 '0' → Bomb
I 全 '1' → Intelligence
F 混合 → FBI

FBI树构建过程（以 "10001011" 为例）

F ("10001011") / \ F ("1000") F ("1011") / \ / \ F ("10") B ("00") F ("10") I ("11") / \ / \ / \ / \ I("1") B("0") B("0") B("0") I("1") B("0") I("1") I("1") 后序遍历（左→右→根）：IBFBBBFIBFIIIFF

代码核心框架

void buildFBI(int l, int r) {
    if (l < r) {                    // 非叶子：先递归子树
        int mid = (l + r) / 2;
        buildFBI(l, mid);            // 左子树（后序遍历）
        buildFBI(mid + 1, r);        // 右子树
    }
    // 判断 [l,r] 的节点类型并输出（后序遍历：最后输出根）
    bool has0 = false, has1 = false;
    for (int i = l; i <= r; i++) {
        if (s[i] == '0') has0 = true;
        if (s[i] == '1') has1 = true;
    }
    if (has0 && has1) cout << 'F';   // 混合
    else if (has0)    cout << 'B';   // 全0
    else              cout << 'I';   // 全1
}
