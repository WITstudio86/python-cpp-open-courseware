第19课：贪心算法

局部最优到全局最优

C++ 算法提高 第 3 阶段

核心思想：每一步都选择当前看起来最好的方案
关键问题：局部最优能否导致全局最优？
典型应用：找零钱、任务调度、最小生成树

生活中的贪心：
登山时每一步都往高处走，希望最终到达山顶 —— 这就是贪心！但不能保证到达的是最高峰。

贪心算法原理

什么是贪心算法？

贪心算法（Greedy Algorithm）在每一步选择中都采取当前状态下最好或最优的选择， 从而希望导致结果是全局最好的算法策略。

┌───────────────────────────────────────────────────────────┐ │ 【贪心算法解题框架】 │ │ │ │ ① 排序 ──→ 按照贪心策略对数据排序 │ │ ② 选择 ──→ 按顺序处理，每次做出当前最优选择 │ │ ③ 验证 ──→ 检查选择是否满足约束条件，不满足则丢弃 │ │ │ │ 核心要求：问题必须具有「贪心选择性质」+「最优子结构」 │ └───────────────────────────────────────────────────────────┘

局部最优 vs 全局最优

概念 含义 贪心中的角色
局部最优 当前步骤下所有可选方案中的最佳 贪心算法直接依据
全局最优 整体通盘考虑后的最佳结果 贪心算法的最终目标
警示：贪心并非万能！
硬币面额 [1, 3, 4] 找零 6 元 → 贪心得 4+1+1 = 3 枚，最优解是 3+3 = 2 枚。
使用贪心前，必须先证明贪心选择性质成立！

例题 1：找零钱问题

问题：有无限多张面额为 100、50、20、10、5、1 的纸币，找零 N 元，求最少纸币张数。

贪心策略：每次选不超过剩余金额的最大面额。 

// 找零钱问题 —— 贪心解法
int denominations[] = {100, 50, 20, 10, 5, 1};
int counts[6] = {0};     // 存储每种面额使用张数
int N, remain, total = 0;

cin >> N;
remain = N;

for (int i = 0; i < 6; i++) {
    counts[i] = remain / denominations[i];  // 贪心：尽量多用大面额
    remain %= denominations[i];             // 更新剩余金额
    total += counts[i];                     // 累计总张数
}

cout << total << endl;
// 输出各面额使用情况...
复杂度：O(k)，k = 面额种类数。这里 k = 6，常数时间。
正确性：人民币面额体系满足贪心选择性质（大面额是小面额的整数倍）。

例题 2：最大分数

问题：N 项作业，每项有截止日期 d 和分数 s。每天只能完成一项，求最大总分。

贪心策略：按分数从高到低排序，每项作业尽量安排在截止日期前最晚的日子。 

// 作业结构体
struct Job { int deadline, score; };

// 自定义排序：按分数降序
bool cmp(Job a, Job b) { return a.score > b.score; }

int n;
Job jobs[1005];
bool used[1005] = {false};   // 记录每天是否已被占用
int totalScore = 0;

sort(jobs, jobs + n, cmp);            // 贪心：优先处理高分作业

for (int i = 0; i < n; i++) {
    for (int day = jobs[i].deadline; day >= 1; day--) {
        if (!used[day]) {            // 找到空闲日
            used[day] = true;
            totalScore += jobs[i].score;
            break;                    // 安排成功，处理下一项
        }
    }
}

cout << totalScore << endl;
复杂度：排序 O(N log N)，安排 O(N × maxDeadline)。
核心技巧：从截止日期往前找，越晚安排越好，为其他作业留出空间。

本课小结

贪心算法的核心要点

  • 1. 贪心思想：每一步都做当前最优选择，希望通过局部最优达到全局最优
  • 2. 最优子结构：原问题的最优解包含子问题的最优解
  • 3. 贪心选择性质：局部最优选择能导向全局最优 —— 使用前必须证明！
  • 4. 解题模板：排序 → 遍历 → 选择 → 验证

贪心 vs 动态规划

维度 贪心算法 动态规划
决策方式 每步做当前最优 考虑所有可能再选择
是否需要回溯 不需要 需要
时间复杂度 O(N log N) 通常 O(N²) 或更高
适用范围 有贪心选择性质的问题 有最优子结构的问题
一句话总结：
贪心算法就是用「鼠目寸光」的策略，争取「高瞻远瞩」的结果——
前提是问题本身具有贪心选择性质。
