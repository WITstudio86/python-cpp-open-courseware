课程导入：为什么要用数组？

想象一下体育课上的场景：老师让全班同学排成一列纵队，每个人站在自己固定的位置上。老师说"第3位同学出列"，那位同学就马上站出来。为什么这么方便？因为大家排好了队，每个人都有固定的位置编号！

在C++编程中，如果我们要处理40位同学的考试成绩、30位同学的名字、50位同学的身高……为每一个数据都单独创建一个变量，那得写多少代码呀！

于是，数组（Array）就诞生了——它就像给数据排排队，让一组相同类型的数据整齐地站成一排，每个数据都有自己固定的位置编号，访问起来又快又方便！

🎯 本节课目标：用数组制作一个班级花名册程序！

什么是数组？

数组是一组相同类型数据的集合。这些数据在内存中连续存放，每一个数据称为数组的一个元素（Element）。每个元素都有一个下标（Index），表示它在数组中的位置。

可以把数组想象成一列小火车🚂：火车头后面挂着一节节车厢，每节车厢装着一个数据，车厢的编号就是下标。

数组 scores： ┌──────┬──────┬──────┬──────┬──────┐ │ 98 │ 85 │ 92 │ 78 │ 95 │ ← 元素的值 ├──────┼──────┼──────┼──────┼──────┤ │ [0] │ [1] │ [2] │ [3] │ [4] │ ← 下标（从0开始！） └──────┴──────┴──────┴──────┴──────┘
⚠️ 关键记忆：在C++中，数组下标从 0 开始，而不是从 1 开始！这是初学者最容易出错的地方。
数组的声明

声明一个数组需要指定三个要素：数据类型、数组名、元素个数。

// 声明格式： 数据类型 数组名[元素个数];
int scores[40]; // 声明一个能存40个整数的数组，存放成绩 string names[30]; // 声明一个能存30个字符串的数组，存放名字 float heights[50]; // 声明一个能存50个小数的数组，存放身高 double prices[100]; // 声明一个能存100个双精度小数的数组 char letters[26]; // 声明一个能存26个字符的数组，存放字母
⚠️ 注意：元素个数必须是一个常量或常量表达式。一旦声明，静态数组的大小就固定了，不能改变。
数组的初始化（5种方式）

我们可以在声明数组的同时给它赋初值，使用花括号 { }：

// ① 完全初始化：给所有元素赋值 int numbers[5] = {10, 20, 30, 40, 50}; // ② 部分初始化：只给前几个赋值，其余自动为 0 int nums[5] = {1, 2}; // 相当于 {1, 2, 0, 0, 0} // ③ 省略大小：编译器自动计算元素个数 int grades[] = {90, 85, 92, 78, 95}; // 自动确定为5个元素 // ④ 全部初始化为 0 int zeros[100] = {0}; // 所有100个元素都是0 // ⑤ 字符串数组初始化 string names[3] = {"小明", "小红", "小刚"};

特别技巧：使用 sizeof(数组名) / sizeof(数组名[0]) 可以计算出数组的元素个数。

下标访问规则（非常重要！）

在C++中，数组的下标从 0 开始。如果数组有 n 个元素，有效下标范围是 0 ~ n-1。

第几个下标访问方式示例值
第 1 个0arr[0]10
第 2 个1arr[1]20
第 3 个2arr[2]30
第 4 个3arr[3]40
第 5 个4arr[4]50

📌 第 n 个元素 ↔ 下标 = n - 1

int arr[5] = {10, 20, 30, 40, 50}; cout << arr[0]; // 输出 10（第1个元素） arr[2] = 100; // 把第3个元素改成 100
⚠️ 数组越界：访问 arr[5] 或 arr[-1] 会导致数组越界！这就像在5个人的队伍里喊"第6位同学"——没有这个人！C++不会阻止你这样做，但结果不可预料，可能导致程序崩溃或得到奇怪的值。
配合循环遍历数组

数组和 for 循环是天生的好搭档！循环变量 i 从 0 到 n-1，正好遍历数组的每个元素。

// ===== 输入5个成绩 ===== int scores[5]; for (int i = 0; i < 5; i++) { cout << "请输入第" << i + 1 << "个成绩："; cin >> scores[i]; } // ===== 输出所有成绩 ===== for (int i = 0; i < 5; i++) { cout << "第" << i + 1 << "个成绩：" << scores[i] << endl; }

💡 技巧：循环中显示"第几个"给用户看时，用 i + 1 把下标转成人类习惯的编号（从1开始）。

🔗
为什么是绝配？
循环变量 i 天然对应数组下标
0 → 1 → 2 → ... → n-1
刚好逐个访问每个元素
⚡
高效处理
无论数组有5个还是500个元素
几行代码就能全部处理完
这就是"批量处理"的力量
综合示例：制作班级花名册

用三个并行数组存储同学的信息：姓名、年龄、爱好

// 花名册数据 —— 三个数组，下标对应同一个人 string names[5] = {"小明", "小红", "小刚", "小丽", "小华"}; int ages[5] = {11, 10, 12, 11, 10}; string hobbies[5] = {"踢足球", "画画", "编程", "跳舞", "阅读"}; for (int i = 0; i < 5; i++) { cout << " " << i + 1 << ". " << names[i] << "（" << ages[i] << "岁）" << endl; }

本课小结
📦 什么是数组
一组相同类型数据的集合，在内存中连续存放
📝 声明格式
类型 数组名[大小];
🔢 下标规则
从 0 开始，第 n 个元素的下标是 n-1
🎬 初始化
用花括号 {值1, 值2, ...} 在声明时赋值
👆 访问元素
通过 数组名[下标] 读取或修改
🔁 遍历数组
配合 for 循环和下标变量，高效处理所有元素
⚠️ 数组越界
访问超出 0 ~ (大小-1) 范围的下标会导致不可预料的错误
📏 获取大小
sizeof(数组) / sizeof(数组[0])

📖 学习口诀

数据排队站整齐，类型相同在一起。
下标从零开始记，第n元素下标减一。
花括号里赋初值，for循环遍历最容易！
