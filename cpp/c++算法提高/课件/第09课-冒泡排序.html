📖 冒泡排序原理

核心思想

反复扫描数组，每次比较相邻的两个元素，如果前面的比后面的大，就交换它们。就像池塘里的气泡，较大的元素一轮一轮地"浮"到数组末尾。

🔍 单次相邻比较与交换

比较 arr[j] 和 arr[j+1]： 如果 arr[j] > arr[j+1]： 交换(arr[j], arr[j+1]) 示例：arr = [5, 3, 8, 1, 2] ↑ ↑ 比较 5 和 3 → 5 > 3，交换！ 结果：[3, 5, 8, 1, 2]
💡 理解关键：每完成一整轮扫描，当前未排序部分的最大值就会被"推"到最后面，就像气泡浮到水面一样。因此，下一轮就可以少比较一个元素。
【讲解】📖 冒泡排序原理 本页要点（照着讲即可）： · 反复扫描数组，每次比较 相邻 的两个元素，如果前面的比后面的大，就交换它们。就像池塘里的气泡，较大的元素一轮一轮地"浮"到数组末尾。 · 🔍 单次相邻比较与交换 · 💡 理解关键： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

⚡ 提前终止优化

为什么要优化？

如果数组 [1, 2, 3, 4, 5] 已经是有序的，普通冒泡排序还会傻傻地执行 4 轮比较。但优化版只需要 1 轮就能发现"没有任何交换"，直接结束！

🔑 优化方法：引入 swapped 标志变量

1bool swapped = false; // 每轮开始时，假设没有交换 2for (int j = 0; j < n - 1 - i; j++) { 3 if (arr[j] > arr[j + 1]) { 4 swap(arr[j], arr[j + 1]); 5 swapped = true; // 发生了交换，更新标志 6 } 7} 8if (!swapped) break; // ★ 没有交换 → 已有序 → 提前结束！
💡 效果对比：优化后最好情况时间复杂度从 O(n²) 降到 O(n)！在"几乎有序"的数组上效果尤为显著。
【讲解】⚡ 提前终止优化 结合讲义《四、提前终止优化——当数组已经有序时》强调： · 你有没有注意到，在上面例子的第 4 轮中，我们比较了 1 和 2，它们没有发生交换。实际上，如果某一轮扫描中**一次交换都没有发生**，说明数组已经全部有序了，后面那些轮就可以跳过了！ · 这就是冒泡排序的经典优化：**引入一个标志变量 swapped（或 flag）**。 · 每一轮开始时，设 swapped = false · 如果本轮发生了交换，就将 swapped 设为 true · 本轮结束时，如果 swapped 仍然为 false，说明数组已有序，提前结束！ 幻灯片上可见要点： · 如果数组 [1, 2, 3, 4, 5] 已经是有序的，普通冒泡排序还会傻傻地执行 4 轮比较。但优化版只需要 1 轮就能发现"没有任何交换"，直接结束！ · [1, 2, 3, 4, 5] · 🔑 优化方法：引入 swapped 标志变量 · 💡 效果对比： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

排队按身高调整

水杯里的气泡

📝

考试卷子排名

老师拿着一叠试卷，相邻两张比分数，低分的往上换。重复操作，最终从低到高排好。

冒泡排序的特点

  • ✅ 稳定性：相邻相等元素不交换，相等元素的相对顺序保持不变
  • ✅ 原地排序：不需要额外数组空间，直接在原数组上操作
  • ✅ 适合小数据：n ≤ 1000 时简单够用
  • ✅ 适合教学：最直观的排序算法，算法入门的绝佳起点

📝 本课小结

  1. 核心思想：反复扫描数组，相邻两个元素比较，前大后小则交换。就像气泡上浮。
  2. 轮数规律：n 个元素的数组最多需要 n-1 轮。每轮将当前最大值"浮"到末尾。
  3. 关键优化：引入 swapped 标志，本轮无交换则提前终止。
  4. 复杂度：最好 O(n)，最坏/平均 O(n²)，空间 O(1)。稳定排序。
  5. 学习价值：最易理解的排序算法，算法世界的入门钥匙。掌握它，为后续学习更高效的排序算法打下基础。
🔑 记住一句话：冒泡排序就是"比邻居、换位置"，一轮一轮把大的往后推。优化就加一句"没换就停"。
