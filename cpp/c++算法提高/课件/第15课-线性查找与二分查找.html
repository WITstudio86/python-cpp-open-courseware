线性查找 —— 最朴素的方法

线性查找（Linear Search）就是一个一个按顺序找，从数组的第一个元素开始，逐个比较直到找到目标或到达末尾。

线性查找示例// 查找目标值 target = 9
数组：[ 3, 7, 1, 9, 4, 2 ]
  i=0: 3≠9 → 下一个
  i=1: 7≠9 → 下一个
  i=2: 1≠9 → 下一个
  i=3: 9==9 → 找到了！下标为 3

特点

  • 不要求数组有序：乱序也能用
  • 代码非常简单，容易理解
  • 时间复杂度 O(n)：最坏情况需要检查所有元素
  • n=1,000,000 时，最坏需要 1,000,000 次比较
C++ 实现int linearSearch(int arr[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == target)
            return i;   // 找到了！
    }
    return -1;  // 没找到
}

二分查找的引入：猜数字游戏

我心里想了一个 1 到 100 之间的数字，你来猜。每猜一次，我会告诉你大了还是小了。

最佳策略 —— 每次都猜中间！

秘密数字：67
第1次：猜 50 → 小了  范围缩小到 [51, 100]
第2次：猜 75 → 大了  范围缩小到 [51, 74]
第3次：猜 62 → 小了  范围缩小到 [63, 74]
第4次：猜 68 → 大了  范围缩小到 [63, 67]
第5次：猜 65 → 小了  范围缩小到 [66, 67]
第6次：猜 66 → 小了  范围缩小到 [67, 67]
第7次：猜 67 → 正确！

100 以内的数字，最多 7 次就能猜中！每次猜中间值，就可以排除掉一半的可能性。这就是二分查找的核心思想！

二分查找的核心：左右指针不断缩小范围

前提条件：数组必须有序（通常升序排列）

用两个指针 left 和 right 标记当前搜索范围，每次取中间位置 mid 与 target 比较：

  • arr[mid] == target → 找到了！
  • arr[mid] < target → target 在右边，left = mid + 1
  • arr[mid] > target → target 在左边，right = mid - 1
二分查找 迭代实现int binarySearch(int arr[], int n, int target) {
    int left = 0, right = n - 1;
    while (left <= right) {            // 区间非空
        int mid = left + (right - left) / 2;  // 防溢出
        if (arr[mid] == target)
            return mid;
        else if (arr[mid] < target)
            left = mid + 1;           // 目标在右边
        else
            right = mid - 1;          // 目标在左边
    }
    return -1;  // 没找到
}

两种区间定义：左闭右闭 vs 左闭右开

[left, right] 左闭右闭

int left = 0, right = n - 1;
while (left <= right) {
    mid = (left+right)/2;
    if (arr[mid] < target)
        left = mid + 1;
    else
        right = mid - 1;
}
  • 左右边界都包含在范围内
  • left == right 时区间还有 1 个元素
  • 更新: left=mid+1, right=mid-1

[left, right) 左闭右开

int left = 0, right = n;
while (left < right) {
    mid = (left+right)/2;
    if (arr[mid] < target)
        left = mid + 1;
    else
        right = mid;
}
  • 右边界不包含在范围内
  • left == right 时区间为空
  • 更新: left=mid+1, right=mid

⚠ 两种写法的循环条件和边界更新必须配套使用，混用会造成死循环或漏查！

二分查找的多种变体（数组含重复元素）

示例数组：[1, 3, 3, 3, 5, 7]

变体含义示例（target=3）关键技巧
找第一个等于target 第一次出现的位置返回 1相等时 right=mid-1 继续左找
找最后一个等于target 最后一次出现的位置返回 3相等时 left=mid+1 继续右找
lower_bound第一个 >= target 的位置返回 1arr[mid]>=target 时 right=mid-1
upper_bound第一个 > target 的位置返回 4arr[mid]>target 时 right=mid-1

找第一个等于 target 的核心代码

int ans = -1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (arr[mid] >= target) {
        if (arr[mid] == target) ans = mid;  // 记录！但不返回
        right = mid - 1;  // 继续向左找！
    } else {
        left = mid + 1;
    }
}

常见陷阱与注意事项

1. 整型溢出

// ❌ 错误写法：left + right 可能溢出 int 范围
int mid = (left + right) / 2;
// ✅ 正确写法：防溢出
int mid = left + (right - left) / 2;

2. 死循环陷阱

当 left + 1 == right 时，mid = (left + right) / 2 在整数除法下等于 left。如果此时更新 left = mid（而不是 left = mid + 1），left 永远不变，死循环！

3. 返回值检查

// 二分查找结束后，一定要检查结果是否有效
if (ans != -1 && arr[ans] == target)
    cout << "找到了：" << ans;
else
    cout << "不存在";

4. 数组必须有序

二分查找的前提是数组有序。如果不是有序的，必须先排序（排序通常 O(n log n)），再使用二分。

本课核心要点

  • 线性查找 O(n)：简单直白，不要求有序
  • 二分查找 O(log n)：必须有序，每次排除一半
  • 防溢出：mid = left + (right - left) / 2
  • 区间定义和边界更新要配套
  • 变体写法：找第一个、找最后一个、lower_bound、upper_bound
  • 如果只需查找一次 → 线性查找；反复查找多次 → 先排序再二分
