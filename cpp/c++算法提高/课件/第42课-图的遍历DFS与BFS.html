图的遍历——DFS与BFS

一、图的遍历概述

定义：图的遍历（Graph Traversal）是指从图中的某个顶点出发，按照一定的规则，系统地访问图中所有顶点各一次的过程。

形象的比喻

算法比喻关键词
DFS 走迷宫时"一条路走到黑"，撞墙再回头 递归 · 回溯 · 栈
BFS 水波纹一圈一圈向外扩散 队列 · 分层 · 最短

遍历顺序对比

图结构: DFS 访问顺序: BFS 访问顺序: 1 1 → 2 → 4 → 3 1 → 2 → 3 → 4 / \ (一直深入) (逐层扩散) 2 3 \ 4
关键问题：同一个图，DFS 和 BFS 的访问顺序可以完全不同！DFS 沿一条路深入到底，BFS 则一层层地"扫荡"过去。

二、深度优先搜索（DFS）

核心思想：递归 + 回溯
1. 从起点出发，标记已访问
2. 选一个未访问邻居，递归深入
3. 无路可走时回溯
4. 直到所有可达顶点都被访问

DFS 执行过程（动画式分解）

状态: 访问路径栈: visited: ① 从 1 出发 [1] [1:√, 2:✗, 3:✗, 4:✗] ② 1→2 (深入) [1, 2] [1:√, 2:√, 3:✗, 4:✗] ③ 2→4 (深入) [1, 2, 4] [1:√, 2:√, 3:✗, 4:√] ④ 4 无路(回溯) [1, 2] 同上 ⑤ 2 无其他邻居 [1] 同上 ⑥ 1→3 (深入) [1, 3] [1:√, 2:√, 3:√, 4:√] ⑦ 遍历完成！

递归实现（最常用）

bool visited[MAXN];
vector<int> adj[MAXN];

void dfs(int u) {
    visited[u] = true;           // 标记已访问
    cout << u << " ";           // 访问当前顶点

    for (int v : adj[u]) {       // 遍历所有邻居
        if (!visited[v]) {       // 如果邻居未访问
            dfs(v);                // 递归深入！
        }
    }
}
复杂度：时间 O(V + E)，空间 O(V)（递归栈深度）。
适用：连通性检测、拓扑排序、回溯问题、找所有路径。

三、广度优先搜索（BFS）

核心思想：使用 队列，按照"距离起点的层数"逐层访问——先访问距离为 1 的顶点，再距离为 2，以此类推。

BFS 执行过程（动画式分解）

状态: 队列: 层次: ① 1 入队 [1] 层0: {1} ② 1 出队, 2&3 入队 [2, 3] 层1: {2, 3} ③ 2 出队, 4 入队 [3, 4] 层2: {4} ④ 3 出队 [4] ⑤ 4 出队, 队列空 [] → 结束 BFS 访问顺序：1 → 2 → 3 → 4

队列实现

bool visited[MAXN];

void bfs(int start) {
    queue<int> q;
    q.push(start);
    visited[start] = true;     // 入队时立即标记！

    while (!q.empty()) {
        int u = q.front(); q.pop();
        cout << u << " ";       // 出队时访问

        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true; // 关键：入队前标记
                q.push(v);
            }
        }
    }
}
复杂度：时间 O(V + E)，空间 O(V)（队列最大宽度）。
适用：最短路径（无权图）、层次遍历、二分图判定。

四、DFS vs BFS 全面对比

特性DFS 深度优先BFS 广度优先
数据结构栈（递归/显式栈）队列
遍历策略一条路走到黑逐层扩散，水波式
时间复杂度O(V + E)O(V + E)
空间复杂度O(V)（递归栈深度）O(V)（队列宽度）
最短路径不保证保证（无权图）
递归实现简洁自然不常用
连通性检测支持支持
拓扑排序支持（后序）支持（Kahn算法）
迷宫问题找一条通路找最短通路
判环三色标记拓扑判环

经典应用场景速查

问题推荐算法原因
连通分量计数DFS / BFS每发现未访问顶点就启动新搜索
无权图最短路径BFS按层扩展，首次到达即最短
迷宫所有通路DFS + 回溯需要探索所有可能性

五、经典应用：连通分量计数

问题：给定一个无向图，判断图中有多少个连通分量（互相可达的顶点组成一个连通分量）。
思路：遍历所有顶点，对每个未访问的顶点启动一次 BFS/DFS，启动次数 = 连通分量数。

示例输入

6 个顶点，4 条边: 1 ─── 2 ─── 3 4 ─── 5 ─── 6 分量 1：{1, 2, 3} 分量 2：{4, 5, 6}

核心代码

int countComponents(int n) {
    bool vis[MAXN] = {false};
    int components = 0;

    for (int i = 1; i <= n; i++) {
        if (!vis[i]) {
            components++;          // 新分量！
            queue<int> q;
            q.push(i); vis[i] = true;
            while (!q.empty()) {     // BFS 标记该分量
                int u = q.front(); q.pop();
                for (int v : adj[u])
                    if (!vis[v]) { vis[v] = true; q.push(v); }
            }
        }
    }
    return components;
}
连通图的判定：如果 components == 1，说明图是连通的（所有顶点都互相可达）；如果 > 1，说明图是非连通图。

六、经典应用：BFS 最短路径

问题：给定一个无权无向图以及起点 S 和终点 T，求从 S 到 T 的最短路径长度（经过的最少边数）。

为什么 BFS 能找到最短路径？

BFS 按层扩展： (第0层) 1 ──────── 终点？距离 0 / \ (第1层) 2 3 ─── 终点？距离 1 / \ (第2层) 4 5 ─── 终点？距离 2 首次到达 = 最短路径（因为是一层层往外找的！）

核心代码（含路径还原）

int dist[MAXN], parent[MAXN];
memset(dist, -1, sizeof(dist));

queue<int> q;
q.push(S); dist[S] = 0;

while (!q.empty()) {
    int u = q.front(); q.pop();
    if (u == T) break;           // 找到！

    for (int v : adj[u]) {
        if (dist[v] == -1) {      // 首次到达
            dist[v] = dist[u] + 1;
            parent[v] = u;          // 记录前驱
            q.push(v);
        }
    }
}

// 回溯还原路径
vector<int> path;
for (int v = T; v != -1; v = parent[v])
    path.push_back(v);
reverse(path.begin(), path.end());
本课核心收获：
1. DFS：栈（递归），一条路走到黑 → 连通性、回溯、拓扑
2. BFS：队列，逐层扩散 → 最短路径、层次遍历
3. 两者时间均为 O(V+E)，空间均为 O(V)
4. 连通分量：对未访问顶点启搜索，启动次数 = 分量数
5. 无权图最短路径：BFS 首次到达即为最短
