区间DP核心思想

核心思路

大区间的最优解由小区间的最优解合并而来。
枚举区间内的分割点 k，将 [i, j] 分成 [i, k] 和 [k+1, j] 两部分求解。

状态定义 & 转移

// dp[i][j] = 区间 [i, j] 上的最优值
for (int k = i; k < j; k++)
    dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost);

枚举顺序（关键！）

第1层：len = 2 → [1,2] [2,3] [3,4] [4,5]
第2层：len = 3 → [1,3] [2,4] [3,5]
第3层：len = 4 → [1,4] [2,5]
第4层：len = 5 → [1,5]
保证：计算 dp[i][j] 时，所有更短的子区间都已计算完毕。
【讲解】区间DP核心思想 本页要点（照着讲即可）： · 大区间的最优解由 小区间的最优解 合并而来。 枚举区间内的 分割点 k ，将 [i, j] 分成 [i, k] 和 [k+1, j] 两部分求解。 · 小区间的最优解 · 分割点 k 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：区间DP、区间合并

石子合并

问题：n 堆石子排成一行，每次合并相邻两堆，代价为两堆石子数之和。求最小总代价。

状态转移

// dp[i][j] = 合并区间 [i,j] 的最小代价
dp[i][j] = min(dp[i][k] + dp[k+1][j]) + sum(i, j);

样例演示：石子 [1, 3, 5, 2] 最优合并 = 22

1 5 + 2 → 7 代价 = 7，石子变为 [1, 3, 7]
2 1 + 3 → 4 代价 = 4，石子变为 [4, 7]
3 4 + 7 → 11 代价 = 11，累计 = 7+4+11 = 22
前缀和优化：使用 sum[j] - sum[i-1] 在 O(1) 时间内求区间和。
【讲解】石子合并 结合讲义《经典问题一：石子合并（直线版）》强调： · 问题描述：有 n 堆石子排成一行，第 i 堆石子有 a[i] 个。每次可以合并**相邻**的两堆石子，合并的代价为这两堆石子的数量之和。经过 n-1 次合并后，所有石子合并成一堆。求最小的总合并代价。 · 状态定义：dp[i][j] 表示将第 i 堆到第 j 堆石子合并成一堆的最小代价。 · 状态转移： · dp[i][j] = min( dp[i][k] + dp[k+1][j] ) + sum(i, j) 其中 i ≤ k < j · 其中 sum(i, j) 是区间 [i, j] 内石子总数。无论以什么顺序合并，最终一次合并的代价一定是整个区间的石子总数。使用**前缀和**可以在 O(1) 时间内求出任意区间的和。 幻灯片上可见要点： · 问题： n 堆石子排成一行，每次合并相邻两堆，代价为两堆石子数之和。求最小总代价。 · 前缀和优化： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

矩阵链乘

问题：给定 n 个矩阵的维度，通过加括号改变计算顺序，求最少标量乘法次数。

状态转移

// dp[i][j] = 矩阵i到矩阵j相乘的最少乘法次数
dp[i][j] = min(dp[i][k] + dp[k+1][j]
          + r[i-1] * r[k] * r[j]);

本课小结

核心思想

大区间最优解 = 小区间最优解的合并，枚举分割点分解问题。

状态 & 转移

dp[i][j] 表示区间 [i, j] 的最优值， 转移时枚举 k ∈ [i, j-1]。

枚举顺序

按区间长度从小到大：len=2→n，保证子问题先求解。

复杂度

石子合并 & 矩阵链乘均为 O(n³) 时间、O(n²) 空间。 四边形不等式优化可降至 O(n²)（进阶）。
