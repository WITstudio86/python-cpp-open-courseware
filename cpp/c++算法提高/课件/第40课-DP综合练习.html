DP 解题六步法回顾

经过第35~39课的学习，我们将DP方法统一归纳为六个步骤：

1
分析问题：识别是否具有重叠子问题与最优子结构。这是判断一个问题能否用DP解决的核心标准。
2
定义状态：明确 dp[...] 的含义。这是DP最关键的一步 —— 状态定义直接决定后续转移方程的复杂度。
3
找转移方程：思考当前状态可以由哪些子状态推导而来。例如 dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j]。
4
确定边界：递推需要起点 —— dp[0] 或 dp[n-1] 等初始值。边界条件处理不当会导致数组越界或逻辑错误。
5
计算顺序：确保计算 dp[i][j] 时，依赖的所有子状态都已算好。一维正序、01背包逆序、区间DP按长度递增。
6
确定答案：dp 数组计算完毕后，答案可能在 dp[n-1]、dp[n][C]、dp[1][n] 或 max(dp[...]) 中 —— 这一步常被忽略。

数字三角形 —— 自底向上DP

问题：给定一个 n 行的数字三角形，从顶部出发，每次可以向左下或右下走，求到底部的最大路径和。

最优路径：7 → 3 → 8 → 7 → 5 = 30

状态定义：dp[i][j] = 从底部走到 (i, j) 的最大和

转移方程：dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j]

边界：dp[n-1][j] = a[n-1][j]（最后一行的 dp 值等于自身）

答案：dp[0][0]

int numberTriangle(int n) { // 初始化最后一行 for (int j = 0; j < n; j++) dp[n-1][j] = a[n-1][j]; // 自底向上递推 for (int i = n - 2; i >= 0; i--) for (int j = 0; j <= i; j++) dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j]; return dp[0][0]; }
编辑距离 —— 双字符串DP

问题：通过插入、删除、替换三种操作，将字符串 A 转换为 B，求最少操作次数。

状态定义：dp[i][j] = 将 A[0..i-1] 转换为 B[0..j-1] 的最少操作次数

转移方程：

if (A[i-1] == B[j-1]) dp[i][j] = dp[i-1][j-1]; // 相同无需操作 else dp[i][j] = min({ dp[i-1][j] + 1, // 删除 A[i-1] dp[i][j-1] + 1, // 插入 B[j-1] dp[i-1][j-1] + 1 // 替换 });
示例："sunday" → "saturday"，最少操作次数 = 3

本课小结与展望

六步法框架

分析问题 → 定义状态 → 找转移方程 → 确定边界 → 计算顺序 → 确定答案。这套方法论适用于所有DP问题。

自底向上 vs 自顶向下

数字三角形中自底向上避免了边界判断，代码更简洁。记忆化搜索则是自顶向下的代表。

二维DP建模

数字三角形和编辑距离都是二维DP的经典模型。二维DP通常用双重循环，注意循环的顺序和边界。

空间换时间

DP的核心哲学：用额外的存储空间记录子问题解，避免重复计算。从指数级到多项式级，性能飞跃。

DP 不是死记硬背的模板，而是系统化的问题分解与递推求解方法论。
