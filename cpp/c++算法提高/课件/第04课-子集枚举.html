int total = 1 << n;           // 2^n
for (int mask = 0; mask < total; mask++) {
    for (int i = 0; i < n; i++) {
        if (mask & (1 << i)) {  // ← 检查第i位
            // 第i个元素被选中！处理它...
        }
    }
}

三个关键位运算速记

1 << n    左移n位 → 等于 2^n
6 & 3     按位与   → 0110 & 0011 = 0010 = 2
           (对应位都为1才为1)
5 | 3     按位或   → 0101 | 0011 = 0111 = 7
           (对应位有一个为1就为1)

🏋️ 例题：砝码称重

砝码 1g,2g,3g,5g,10g,20g 各一个，放同一边，能称多少种重量？

砝码: [1g] [2g] [3g] [5g] [10g] [20g] 位号: 0 1 2 3 4 5 ───────────────────────────────────── mask=0 0 0 0 0 0 0 → 0g (空) mask=1 0 0 0 0 0 1 → 1g mask=2 0 0 0 0 1 0 → 2g mask=3 0 0 0 0 1 1 → 3g (1+2) mask=7 0 0 0 1 1 1 → 11g (1+2+3+5) ... mask=63 1 1 1 1 1 1 → 41g (全部) ───────────────────────────────────── 共 64 种选取方案，去重后得到所有可能重量 
// 砝码称重核心代码
int weights[] = {1, 2, 3, 5, 10, 20};
set<int> result;
for (int mask = 0; mask < 64; mask++) {
    int sum = 0;
    for (int i = 0; i < 6; i++)
        if (mask & (1 << i)) sum += weights[i];
    result.insert(sum);
}
cout << result.size(); // 输出不同重量数
所有砝码之和 = 1+2+3+5+10+20 = 41g

📝 本课小结

📌 子集枚举核心三步骤

  1. 确定元素个数 n → 共有 2ⁿ 个子集
  2. 遍历 mask: 0 到 (1<<n)-1 → 每个mask代表一种选法
  3. 检查 mask & (1<<i) → 判断第i个元素是否被选中
