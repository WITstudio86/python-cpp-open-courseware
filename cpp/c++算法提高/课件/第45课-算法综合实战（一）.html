枚举 + 贪心 + 二分

📋 枚举算法回顾

枚举（暴力法）是最朴素的算法思想：把所有可能的情况一一列出，逐一判断。

枚举三要素

要素说明示例（找质数）
枚举对象你要枚举什么？可能的因数 d
枚举范围从哪里枚举到哪里？2 到 sqrt(n)
检验条件什么样的结果有效？n % d == 0
✅ 优点
  • 思路简单直观
  • 不容易出错
  • 适合入门学习
⚠️ 缺点
  • 时间复杂度高
  • 数据大时不可行
  • 需要优化配合

适用场景 数据范围较小（n ≤ 1000），或作为其他算法的验证模块

// 枚举示例：判断n是否为质数 bool isPrime(int n) { if (n < 2) return false; for (int i = 2; i * i <= n; i++) { if (n % i == 0) return false; } return true; }

🎯 贪心算法回顾

贪心算法的核心思想：每一步都做当前看起来最优的选择，通过局部最优达到全局最优。

经典贪心问题

问题贪心策略时间复杂度
硬币找零每次选面额最大的硬币O(N)
活动安排每次选结束时间最早的活动O(N log N)
排队接水接水时间短的人先接O(N log N)

🔑 贪心正确性证明（关键！）

不是所有问题都能用贪心。需要确认问题满足：

  • 贪心选择性质：每一步的局部最优选择不会影响最终结果
  • 最优子结构：问题的最优解包含子问题的最优解
// 贪心示例：活动安排问题 struct Activity { int start, end; }; int maxActivities(Activity a[], int n) { sort(a, a+n, [](Activity x, Activity y) { return x.end < y.end; // 按结束时间排序 }); int cnt = 1, lastEnd = a[0].end; for (int i = 1; i < n; i++) if (a[i].start >= lastEnd) { cnt++; lastEnd = a[i].end; } return cnt; }

🔍 二分查找（二分答案）回顾

二分查找是处理单调性问题的利器——当答案越大越容易满足（或越难满足）时，就可以二分搜索答案。

二分答案三步法

1. 定上下界
left / right → 2. 写 check(mid)
判断可行性 → 3. 调区间
移动 left 或 right
// 二分答案模板：找最大值 double left = 0, right = maxVal; while (right - left > EPS) { double mid = (left + right) / 2; if (check(mid)) left = mid; // mid可行 → 尝试更大 else right = mid; // mid不可行 → 减小 } // left 即为答案

💡 单调性判断技巧

问自己一个问题：如果 x 满足条件，那么所有＜x 的值也都满足吗？

如果答案是"是"→ 可以用二分！

典型场景

  • 最大值最小化
  • 最小值最大化

典型题目

  • 切割绳子
  • 分巧克力

🔪 例题1：切割绳子

二分答案 贪心验证

问题描述

有 N 条绳子，需要切成 K 段等长的绳子，求每段的最大长度。绳子切割后剩余部分不能拼接。

📥 样例输入
4 11 8.02 7.43 4.57 5.39
📤 样例输出
2.00
绳子可视化（长度=2.00时）：
8.02 → 4段 7.43 → 3段 4.57 → 2段 5.39 → 2段
总计：4+3+2+2 = 11段 ✓

🧠 算法思路

二分搜索
绳子长度 → 贪心计算
能切几段 → 判断
是否 ≥ K

check(mid): 每条绳子能贡献 floor(Lᵢ / mid) 段，求和判断是否 ≥ K

🤝 例题2：最优配对

排序 贪心配对

问题描述

有 2N 个整数，将它们两两配对，使得每对差的绝对值之和最小。

📥 样例输入
3 1 3 4 6 7 9
📤 样例输出
6
排序后配对可视化：

原始：1 3 4 6 7 9
排序：1 3 4 6 7 9

配对：1, 3 → 差2 4, 6 → 差2 7, 9 → 差2
总差值：2+2+2 = 6

🧠 贪心策略证明

假设 a ≤ b ≤ c ≤ d 四个数，比较配对方案：

配对方案差值结果
(a,b) + (c,d)(b-a)+(d-c)✅ 最小
(a,c) + (b,d)(c-a)+(d-b)❌ 较大
(a,d) + (b,c)(d-a)+(c-b)❌ 最大

结论：排序后相邻配对是最优的。将2N个数扩展到任意N，该结论仍然成立。

📝 本课小结

算法组合模式总结

模式说明例题
二分+贪心二分搜索答案，贪心验证可行性切割绳子
排序+贪心排序使问题有序，再贪心选择最优配对
枚举+剪枝枚举所有可能，用条件提前排除组合问题
1 二分答案+贪心验证是"最大值最小化/最小值最大化"的经典套路，关键在于判断单调性
2 排序+贪心适用于通过排序使问题变得有序，然后进行贪心选择的场景
3 面对综合题时，先分析数据规模和数据特征，再决定算法组合，不要盲目套模板
4 将问题拆分为"验证"和"搜索"两个阶段，分别用不同算法解决

算法不是孤立的，学会组合才是真正的能力！
