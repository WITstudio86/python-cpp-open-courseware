动态规划（DP）核心回顾

DP 的本质：将大问题拆解为子问题，记住子问题的答案，利用子问题的最优解构造全局最优解。

DP 四步法

  1. 确定状态 — 用什么变量描述局面？dp[i][j] 表示什么意义？
  2. 转移方程 — 当前状态如何从之前状态推导？dp[i][j] = min(...) / max(...)
  3. 边界条件 — 初始状态（起点）的值是什么？dp[1][1] = ?
  4. 计算顺序 — 按什么顺序递推？从前往后还是从后往前？

DP 适用三条件

  • 最优子结构：最优解包含子问题最优解
  • 无后效性：状态确定后不受后续决策影响
  • 重叠子问题：同一子问题被多次计算

图论视角：DAG 上的 DP

  • 有向无环图（DAG）= 天然无后效性
  • 拓扑排序 = DP 的计算顺序
  • 状态转移 = 沿边传播最优值
DAG→拓扑序→DP递推

状态：dp[i][j] = 到达 (i,j) 的最小路径和

转移：dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])

核心代码实现

数字三角形（自底向上）

// 初始化最底层
for (int j = 1; j <= n; j++)
    dp[n][j] = a[n][j];

// 从下往上递推
for (int i = n-1; i >= 1; i--)
    for (int j = 1; j <= i; j++)
        dp[i][j] = a[i][j]
                 + max(dp[i+1][j],
                        dp[i+1][j+1]);

cout << dp[1][1] << endl;

最小路径和

// 边界
dp[1][1] = grid[1][1];

// 从左上到右下逐行递推
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= m; j++) {
        if (i==1 && j==1) continue;
        dp[i][j] = grid[i][j];
        int up = i>1? dp[i-1][j] : 1e9;
        int lf = j>1? dp[i][j-1] : 1e9;
        dp[i][j] += min(up, lf);
    }

cout << dp[n][m] << endl;

空间优化技巧

两种问题都可以用滚动数组将空间从 O(N²) 优化到 O(N)：

  • 数字三角形：只保留当前行和下一行的 DP 值，从下往上只用到 i+1 行
  • 最小路径和：只保留上一行的 DP 值 + 当前行前一列，两次一维数组即可

DP + 图论综合解题策略

1. 识别问题→ 2. 建图/建状态→ 3. 确定拓扑序→ 4. 递推计算
  1. 判断问题能否建模为 DAG（无环 → 无后效性）
  2. 确定状态：dp[节点] 或 dp[坐标] 表示到达该位置的最优值
  3. 按拓扑序或坐标顺序递推（图论：拓扑排序；网格：逐行逐列）
  4. 利用转移方程计算，注意边界条件和初始化极大/极小值
核心思想：网格/三角形本质上是有向无环图（DAG），DP 递推顺序就是图的拓扑排序。理解了这一点，任何路径类问题都能用 DP + 图论的统一框架解决。

本课小结与延伸

核心收获

  1. DP 四步法是解决所有 DP 问题的通用框架：状态→转移→边界→顺序
  2. 自底向上递推比递归+记忆化更高效，是竞赛推荐写法，空间还可以用滚动数组优化
  3. 图论视角：网格/三角形 = DAG，DP 递推顺序 = 拓扑排序，这是理解路径 DP 的本质
  4. DP + 图论结合是竞赛中的高频考点：最短路径计数、DAG 最长路、网格路径变种等
