第14课：计数排序与sort函数

桶的智慧 —— 不比较也能排序！

📌 核心问题：排序一定要"比较"吗？
📌 计数排序：用"桶"统计出现次数，O(n+m)线性时间
📌 STL sort：C++内置排序利器，一行代码搞定
📌 适用场景：数据量大但范围小（如年龄、成绩）

💡 生活联想：
班长统计全班成绩：在黑板上写出0~100，每念到一个分数就在对应位置画一笔"正"字。全部念完后，排序结果一目了然——这就是计数排序！

📖 算法原理：桶的思想

核心思路：用空间换时间

为每个可能的值准备一个"桶"（数组元素），每遇到一个数据，就往对应的桶里+1。最后按桶的顺序把数据"倒"出来，天然有序！

待排序数组：[3, 1, 2, 3, 0, 2, 3, 1]（范围 0~5）

读到 3
3
→ 扔进 3号桶
读到 1
1
→ 扔进 1号桶
读到 2
2
→ 扔进 2号桶
📦 桶状态变化过程： 初始状态（6个空桶）： ┌───┬───┬───┬───┬───┬───┐ │ 0 │ 0 │ 0 │ 0 │ 0 │ 0 │ └───┴───┴───┴───┴───┴───┘ 0 1 2 3 4 5 ← 桶编号 全部入桶后： ┌───┬───┬───┬───┬───┬───┐ │ 1 │ 2 │ 2 │ 3 │ 0 │ 0 │ └───┴───┴───┴───┴───┴───┘ 0 1 2 3 4 5 解读：0出现1次，1出现2次，2出现2次，3出现3次，4和5没出现
🎯 关键洞察：一旦统计完毕，排序就完成了——0号桶有1个0，1号桶有2个1……按顺序"倒出"就是排好序的结果！

💻 计数排序：完整代码

/**
 * 计数排序 —— 不比较，只统计！
 * 时间复杂度 O(n+m)，空间复杂度 O(m)
 * 适用：整数、数据范围 m 较小
 */
void countingSort(int arr[], int n) {
    if (n <= 1) return;

    // 第1步：找数据范围
    int minVal = arr[0], maxVal = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < minVal) minVal = arr[i];
        if (arr[i] > maxVal) maxVal = arr[i];
    }

    // 第2步：创建计数桶
    int range = maxVal - minVal + 1;
    vector<int> bucket(range, 0);   // 全部初始化为0

    // 第3步：元素入桶
    for (int i = 0; i < n; i++) {
        bucket[arr[i] - minVal]++; // 对应桶计数+1
    }

    // 第4步：桶中倒出，填回原数组
    int idx = 0;
    for (int i = 0; i < range; i++) {
        int value = i + minVal;       // 还原真实值
        while (bucket[i] > 0) {
            arr[idx++] = value;
            bucket[i]--;
        }
    }
}
🔑 核心公式：
元素值 → 桶下标：bucket[arr[i] - minVal]
桶下标 → 元素值：value = i + minVal
偏移量 minVal 让我们能把任意范围的整数映射到从0开始的桶数组

⚡ STL 中的 sort 函数

基本用法 —— 一行代码完成排序

#include <algorithm>   // 必须包含此头文件

vector<int> v = {5, 2, 8, 1, 9};

sort(v.begin(), v.end());      // 升序 → [1,2,5,8,9]
sort(v.begin(), v.end(), greater<int>()); // 降序 → [9,8,5,2,1]

int a[] = {5, 2, 8};          // 普通数组也支持
sort(a, a + 3);                // → [2,5,8]

自定义比较函数

// 规则：a 应该排在 b 前面时，返回 true
bool cmp(int a, int b) {
    return a > b;    // 降序：大的在前
}
sort(v.begin(), v.end(), cmp);

// 数组按绝对值从小到大
int arr[] = {-5, 3, -1, 4, -2};
sort(arr, arr + 5, [](int a, int b) {
    return abs(a) < abs(b);    // Lambda 表达式
});
// 结果：[-1, -2, 3, 4, -5]
🎯 sort 底层算法：IntroSort（内省排序）= 快速排序 + 堆排序 + 插入排序的混合体，保证 O(n log n) 的最坏情况复杂度。

📊 计数排序 vs STL sort

对比维度计数排序STL sort
时间复杂度 O(n + m) O(n log n)
空间复杂度 O(m) — 需要桶数组 O(log n) — 递归栈
是否比较元素 不比较！只统计 需要两两比较
适用数据类型 仅整数（范围小） 任意可比较类型
编码难度 需自己实现 一行代码

选择策略

✅ 用计数排序

  • 数据范围 m 很小（如年龄6~18，成绩0~100）
  • 数据量 n 很大（如10万人）
  • 追求极致的速度

✅ 用 STL sort

  • 数据范围太大或不确定
  • 数据有小数、字符串等
  • 想快速编码，一行搞定
经验法则：范围小→计数排序；范围大→sort()；拿不准→sort() 永远没错！

🏋️ 例题1：年龄排序

题目描述：某学校体检，将学生年龄从小到大排序。年龄范围 6~18岁，学生人数 n ≤ 100000。

输入样例： 8 12 15 8 10 13 8 15 10 输出样例： 8 8 10 10 12 13 15 15

计数排序解法（数据范围极小！）

int cnt[19] = {0};  // 下标直接作年龄，0~18
for (int i = 0; i < n; i++) {
    int age;
    cin >> age;
    cnt[age]++;       // 年龄对应桶 +1
}
// 输出：按年龄从小到大
for (int age = 6; age <= 18; age++) {
    while (cnt[age] > 0) {   // 该年龄有几个人
        cout << age << " ";
        cnt[age]--;
    }
}
效率分析：n 可达 10 万，计数排序 O(100000+13) ≈ 10 万次；sort() 需要 O(10万 × 17) ≈ 170 万次。计数排序快17倍！

🏋️ 例题2：成绩统计

题目描述：统计 n 个学生的成绩分布（0~100分），按分数从高到低输出有学生的成绩及人数。

输入样例： 5 85 92 85 78 92 输出样例： 92: 2 85: 2 78: 1

桶统计 + 可视化思路

int cnt[101] = {0};         // 0~100 共101个分数
for (int i = 0; i < n; i++) {
    int score; cin >> score;
    cnt[score]++;
}
// 从高到低输出人数 > 0 的成绩
for (int score = 100; score >= 0; score--) {
    if (cnt[score] > 0) {
        cout << score << ": " << cnt[score] << endl;
    }
}
📊 可视化成绩分布（样例数据）：
分数 100 ▏ . . 92 ██ ← 2人 91 ▏ . 85 ██ ← 2人 84 ▏ . 78 █ ← 1人 77 ▏

📝 本课小结

🔢 计数排序要点

  • 思想：桶统计 → 不比较就能排序
  • 步骤：找范围 → 开桶 → 入桶 → 出桶
  • 复杂度：O(n+m)，m为数据范围
  • 适用：整数、范围小（年龄/成绩）
  • 不适：范围太大、浮点数

⚡ STL sort 要点

  • 头文件：<algorithm>
  • 升序：sort(begin, end)
  • 降序：sort(begin, end, greater<T>())
  • 自定义：第三个参数写比较函数
  • 复杂度：O(n log n)，通用可靠

核心记忆口诀

┌──────────────────────────────────────────────────┐ │ 排序之法有两条，计数与sort要记牢： │ │ 数据范围若很小，桶计数排序效率高； │ │ 范围大或难确定，一行sort()最可靠！ │ │ 比较函数会自定，降序绝对值随你调。 │ └──────────────────────────────────────────────────┘
