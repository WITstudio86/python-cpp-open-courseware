常见错误分析

竞赛中最容易犯的 5 类错误，看看你中招了几个？

🐛 1. 数组越界

for (int i = 0; i <= n; i++)  // ❌ 访问 a[n] 越界！
for (int i = 0; i < n; i++)   // ✅ 下标范围 0 ~ n-1

🐛 2. 未初始化变量

int sum; sum += a[i];  // ❌ sum 是随机垃圾值
int sum = 0;           // ✅ 显式初始化为 0

🐛 3. 整数溢出

int c = 100000 * 100000;  // ❌ 溢出! int ~2e9
long long c = 100000LL * 100000;  // ✅ long long ~9e18

🐛 4. 边界差一 (Off-by-One)

while (left < right) { ... }  // ❌ 漏掉 left==right
while (left <= right) { ... } // ✅ 遍历所有情况

🐛 5. 死循环

while (x > 0) { x++; }  // ❌ x 永远 > 0
while (x <= 10) { x++; } // ✅ 有终止条件

调试方法

三种实用的调试技巧，帮你快速定位 Bug

🖨 打印调试 (Print Debugging)

#define debug(x) cerr << #x << " = " << x << endl;
debug(a[i]);   // 输出到 cerr，不影响 cout 答案
// 提交时注释掉 #define 即可关闭所有调试输出

🛡 断言 (assert)

#include <cassert>
assert(n >= 1 && n <= 100000);  // 检查输入范围
assert(ans >= 0);               // 检查答案合理性
// 条件为假时程序终止，报告文件和行号

🐞 GDB 调试器

gdb ./program      // 启动调试
(gdb) b 42         // 在第 42 行设断点
(gdb) r             // 运行程序
(gdb) n             // 单步执行（不进入函数）
(gdb) s             // 单步执行（进入函数）
(gdb) p 变量名      // 打印变量值
(gdb) bt            // 查看调用栈（崩溃时必用）
💡 小贴士：程序崩溃（RE）时，GDB 的 bt 命令可以直接告诉你哪一行出了错！

时间复杂度估算

根据数据范围选择算法 — 竞赛必备技能

数据范围 N 可接受复杂度 典型算法
N ≤ 10O(N!)全排列、回溯
N ≤ 15O(2N)子集枚举
N ≤ 20O(N·2N)状态压缩 DP
N ≤ 100O(N3)Floyd-Warshall
N ≤ 500O(N3)三重循环
N ≤ 2000O(N2)简单 DP
N ≤ 105O(N log N)排序、二分、堆
N ≤ 106O(N log N) / O(N)线性筛、贪心
N ≤ 107O(N)前缀和、双指针
N ≤ 108O(log N) / O(1)公式、二分
⚡ 经验法则：现代评测机大约 108 次操作 / 秒
例：N=105，O(N2) = 1010 次 → 约 100 秒 → 超时 (TLE)
例：N=105，O(N log N) ≈ 1.7×106 次 → 瞬间完成

核心步骤

  1. 写一个暴力解法（保证正确，允许慢）
  2. 写一个优化解法（快速，需要验证）
  3. 写一个随机数据生成器
  4. 循环：生成数据 → 分别运行 → 比较结果
  5. 结果不一致 → 打印出错的输入（Bug 定位！）
  6. 全部一致 → 优化解法的正确性得到充分验证
💡 重要：对拍使用小数据（N ≤ 100），暴力解法也能瞬间完成。2000 轮测试足以发现 95% 以上的 Bug。

实战演练：最大子段和 对拍

完整演示暴力解法 vs Kadane 算法的对拍过程

问题描述

给定数组 [-2, 1, -3, 4, -1, 2, 1, -5, 4]，求最大子段和。

答案：6（子数组 [4, -1, 2, 1]）

暴力解法 O(N²)

for (int i = 0; i < n; i++) {
    int sum = 0;
    for (int j = i; j < n; j++) {
        sum += a[j];
        max_sum = max(max_sum, sum);
    }
}

优化解法 O(N) — Kadane 算法

int max_ending = 0, max_so_far = INT_MIN;
for (int x : a) {
    max_ending = max(x, max_ending + x); // DP 转移
    max_so_far = max(max_so_far, max_ending);
}
