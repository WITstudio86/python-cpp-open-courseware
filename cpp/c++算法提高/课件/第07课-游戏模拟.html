📖 约瑟夫环问题

问题描述： n 个人围成一圈，编号 1~n。从第 1 个人开始报数（1, 2, 3...）， 报到 m 的人出列，下一个人重新从 1 开始报数。 求最后剩下的人的编号。

📐 直观演示（n=5, m=3）

初始状态： 第1轮（报数到3→出列）： (1) (1) 报数"1" / \ / \ (5) (2) → (5) (2) 报数"2" \ / \ / (4)-(3) (4)-(3) 报数"3" ✗出列！ 第2轮（从4开始）： 第3轮（从2开始）： (1) 报数"3" ✗出列！ (5) 报数"3" ✗出列！ / \ / (5) (4) 报数"2" (2) 报数"1" \ / \ (4) 报数"1" (4) 报数"2" 第4轮（从2开始）： 最终： (2) 报数"3" ✗出列！ 🏆 幸存者：4号 \ (4) 报数"1,2"

答案：最后剩下的人是 4 号

💡 方法一：队列模拟法

核心思想：用队列模拟"圆圈"

出队再入队 = 圆圈中"从一个人传到下一个人"。 不断循环，就像旋转的圆环。

  • 将 1~n 依次入队
  • 每轮：前 m-1 人出队→入队（安全），第 m 人直接出队（淘汰）
  • 重复直到队列中只剩 1 人
  • 返回最后一个人

演示（n=5, m=3）

初始队列：[1, 2, 3, 4, 5] 第1轮：前2人出队再入队 → [3, 4, 5, 1, 2] 第3人(3)出列淘汰 → [4, 5, 1, 2] 第2轮：前2人出队再入队 → [1, 2, 4, 5] 第3人(1)出列淘汰 → [2, 4, 5] 第3轮：前2人出队再入队 → [5, 2, 4] 第3人(5)出列淘汰 → [2, 4] 第4轮：前2人出队再入队 → [4, 2] 第3人(2)出列淘汰 → [4] 🏆 队列只剩[4]，幸存者是 4 号！

🧮 方法二：数学递推法（高效）

递推公式推导

设 f(i) = 有 i 个人时，幸存者的编号（0-indexed）

步骤公式含义
基础f(1) = 01个人时，0号幸存
递推f(i) = (f(i-1) + m) % i淘汰1人后，规模缩小，编号偏移
答案ans = f(n) + 10-indexed → 1-indexed

手动推演（n=5, m=3）

f(1) = 0 f(2) = (f(1) + 3) % 2 = (0 + 3) % 2 = 1 f(3) = (f(2) + 3) % 3 = (1 + 3) % 3 = 1 f(4) = (f(3) + 3) % 4 = (1 + 3) % 4 = 0 f(5) = (f(4) + 3) % 5 = (0 + 3) % 5 = 3 答案 = f(5) + 1 = 3 + 1 = 4 ✓
⚡ 优势： 时间复杂度 O(n)，空间复杂度 O(1)。 当 n 很大（如 10^7）时，这是唯一可行的解法！

💻 代码实现

约瑟夫环 — 队列模拟法

// 队列模拟法求约瑟夫环最后幸存者（1-indexed）
int josephus_queue(int n, int m) {
    queue<int> q;
    // 将 1~n 依次入队
    for (int i = 1; i <= n; i++) q.push(i);

    // 不断淘汰，直到只剩1人
    while (q.size() > 1) {
        // 前 m-1 人安全：出队再入队
        for (int i = 1; i < m; i++) {
            q.push(q.front());
            q.pop();
        }
        // 第 m 人淘汰：直接出队
        q.pop();
    }
    return q.front();  // 最后剩下的人
}

约瑟夫环 — 数学递推法

// 数学递推法 O(n)，O(1)空间
int josephus_math(int n, int m) {
    int result = 0;  // f(1) = 0（0-indexed）
    for (int i = 2; i <= n; i++) {
        result = (result + m) % i;  // f(i) = (f(i-1)+m)%i
    }
    return result + 1;  // 转为 1-indexed
}

🎲 报数游戏（变体）

与约瑟夫环的区别

特征 约瑟夫环 报数游戏
起始位置 始终从第1个人开始 从第 k 个人开始
输出内容 只输出最后幸存者 输出完整出列顺序
解法 队列模拟 / 数学递推 队列模拟（必须）

示例（n=7, m=3, k=2）

初始排列（从k=2开始）：[2, 3, 4, 5, 6, 7, 1] 第1轮：1(2), 2(3), 3(4)→4出列 第2轮：1(5), 2(6), 3(7)→7出列 第3轮：1(1), 2(2), 3(3)→3出列 第4轮：1(5), 2(6), 3(1)→1出列 第5轮：1(2), 2(5), 3(6)→6出列 第6轮：1(2), 2(5), 3(2)→2出列 第7轮：5→出列 出列顺序：4 → 7 → 3 → 1 → 6 → 2 → 5
💡 提示： 报数游戏必须完整模拟过程，无法用简单的递推公式替代。 队列是记录出列顺序的自然工具。

📊 复杂度分析

方法 时间复杂度 空间复杂度 适用场景
队列模拟（约瑟夫环） O(n × m) O(n) n、m 较小（≤10⁴）
数学递推（约瑟夫环） O(n) O(1) n 任意大（≤10⁷）
队列模拟（报数游戏） O(n × m) O(n) 需要完整出列顺序时必须使用

分析说明

  • 队列模拟每淘汰 1 人需要 O(m) 次队列操作
  • 共淘汰 n-1 人，总复杂度 O(n × m)
  • 数学递推法无需模拟过程，线性复杂度是最优解
最优解： f(1) = 0，f(i) = (f(i-1) + m) % i，答案 = f(n) + 1

⚠️ 注意：报数游戏因需要完整出列顺序，必须完整模拟，无法用递推公式替代。
