🚀 第01课：枚举算法入门

穷举的力量 —— 逐一尝试，不遗漏任何可能

📌 核心思想：把所有可能的情况一个一个试一遍
📌 别称：穷举法 / 暴力搜索 / Brute Force
📌 优势：思路简单，保证找到所有解
📌 经典问题：百钱买百鸡、水仙花数

💡 生活中的枚举：
假如钥匙掉在黑暗的房间里，你会把每一寸地面都摸一遍——这就是枚举！

📖 算法原理：枚举三要素

┌──────────────────────────────────────────────┐ │ 【枚举算法三要素】 │ │ │ │ ① 枚举对象 → 我们要枚举"什么"？ │ │ ② 枚举范围 → 可能取值"从哪到哪"？ │ │ ③ 判断条件 → 满足"什么条件"才是答案？ │ └──────────────────────────────────────────────┘

单层循环枚举框架

for (int i = 起点; i <= 终点; i++) {
    if (满足条件(i)) {
        // 找到了！输出或记录
    }
}

双层嵌套枚举框架

for (int i = 起点1; i <= 终点1; i++) {
    for (int j = 起点2; j <= 终点2; j++) {
        if (满足条件(i, j)) {
            // 找到一组解
        }
    }
}
⚠ 嵌套层数越多，总枚举次数指数级增长！

💻 百钱买百鸡 —— 枚举思路

公鸡 gong
0 ~ 20 只
5元/只
母鸡 mu
0 ~ 33 只
3元/只
小鸡 xiao
= 100-gong-mu
1元3只
// 枚举公鸡和母鸡，小鸡由总数推导
for (int gong = 0; gong <= 20; gong++) {
    for (int mu = 0; mu <= 33; mu++) {
        int xiao = 100 - gong - mu;      // 总数=100
        if (xiao >= 0 && xiao % 3 == 0) { // 小鸡须为3的倍数
            if (5*gong + 3*mu + xiao/3 == 100) { // 总价=100
                cout << gong << " " << mu << " " << xiao << endl;
            }
        }
    }
}
运行结果（共4组解）：
(0, 25, 75) (4, 18, 78) (8, 11, 81) (12, 4, 84)

🏋️ 例题：水仙花数

问题描述

一个三位数，其各位数字的立方和等于该数本身。
例如：153 = 1³ + 5³ + 3³ = 1 + 125 + 27 = 153 ✅

数字分解图示

数字 153 ┌───┬───┬───┐ │ 1 │ 5 │ 3 │ ← 百位(153/100) 十位(153/10%10) 个位(153%10) └───┴───┴───┘ ↓ ↓ ↓ 1³ + 5³ + 3³ = 1 + 125 + 27 = 153 
// 水仙花数枚举
for (int n = 100; n <= 999; n++) {
    int a = n / 100;       // 百位
    int b = n / 10 % 10;   // 十位
    int c = n % 10;        // 个位
    if (a*a*a + b*b*b + c*c*c == n) {
        cout << n << " 是水仙花数" << endl;
    }
}
全部4个三位水仙花数： 153、370、371、407

📝 本课小结

✅ 优点

  • 思路简单直观
  • 保证找到所有解
  • 不易出错
  • 是复杂算法的基础

⚠️ 缺点

  • 数据大时效率低
  • 嵌套多时代码复杂
  • 需要优化控制范围
