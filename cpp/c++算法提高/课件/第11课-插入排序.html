一、算法原理：像整理扑克牌

插入排序的核心思想非常直观——和人类整理扑克牌的方式一模一样：

  1. 初始时，手里只有第一张牌（数组的第一个元素），它天然有序
  2. 每次摸起一张新牌（取数组的下一个元素）
  3. 在已经排好序的牌中，从右往左找到新牌应该放的位置
  4. 把比它大的牌都往右挪一挪，腾出空位
  5. 把新牌插入到空位中

二、有序区扩张——数组分为两个世界

插入排序过程中，数组被分为两个区域：

有序区（左边）：已经排好序的元素，初始只有第一个元素
无序区（右边）：还未处理的元素，逐一被"抽取"并插入到有序区

每完成一轮插入，有序区就扩大一个元素，无序区缩小一个元素。当无序区变为空时，排序完成！

三、代码实现

C++ 
// 插入排序：像整理扑克牌一样
void insertionSort(int arr[], int n) {
    // 外层循环：从第2个元素开始，逐个取出"新牌"
    for (int i = 1; i < n; i++) {
        int key = arr[i];   // 当前要插入的元素
        int j = i - 1;      // 从有序区末尾开始

        // 内层循环：在有序区中从右往左找位置
        // 如果 arr[j] > key，就把它往右移一格
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];  // 右移，腾位置
            j--;                   // 继续往左看
        }

        // 把 key 插入到正确位置
        arr[j + 1] = key;   // 插入完成！
    }
}
代码解读：
key = 新摸的牌（临时保存）
arr[j+1] = arr[j] = 把大牌往右挪（腾位置）
arr[j+1] = key = 把新牌放进空位
为什么用 while 而不是 for？因为不确定需要比较多少次——遇到比 key 小的元素就停。while 循环可以随时终止，刚好符合"从右往左找到合适位置就停"的逻辑。

四、复杂度分析

时间复杂度

情况时间复杂度说明
最好情况 O(n) 数据已有序，每次只比较 1 次，不需要移动
平均情况 O(n²) 随机数据，平均每个元素移动约一半有序区长度
最坏情况 O(n²) 完全逆序，每个元素都要插到最前面

空间复杂度：O(1)

插入排序是原地排序，只需要一个临时变量 key 和几个循环变量。

稳定性：稳定

当 arr[j] == key 时，while 循环条件 arr[j] > key 不成立，key 会被放在 arr[j] 之后，不会打乱相等元素的原始顺序。

五、经典例题

例题1：插入位置查找

题目：给定已排好序的数组 [1, 3, 5, 7, 9] 和待插入的数 6，请找出插入位置（下标从0开始）。

解法1 — 线性查找（O(n)）：从左往右找第一个 ≥ x 的位置。

C++ 
for (int i = 0; i < n; i++) {
    if (arr[i] >= x) {
        cout << i << endl;  // 输出插入位置
        break;
    }
}

解法2 — 二分查找（O(log n)）：利用有序区的特性，快速定位。

C++ 
int left = 0, right = n - 1, pos = n;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (arr[mid] >= x) { pos = mid; right = mid - 1; }
    else left = mid + 1;
}
cout << pos << endl;
注意：二分查找虽然能快速找到位置，但插入时仍需移动元素（O(n)），所以插入排序整体时间复杂度不变，只是减少了比较次数。

例题2：部分有序排序

题目：给定"几乎有序"的序列 [2, 1, 4, 3, 6, 5]（每个元素离最终位置 ≤ 2），请用插入排序完成排序。

直接用标准的插入排序即可。由于大部分元素都已经在正确位置附近，内层 while 循环平均只执行约 k 次（k=2），效率接近 O(kn) ≈ O(n)！
