完全背包 vs 01背包

核心差异：01背包每种物品只有1个（选或不选），完全背包每种物品有无限个（可以选0次、1次、2次……）。
对比维度 01背包 完全背包
物品数量 每种1个 每种无限个
状态定义 dp[j]：容量j的最大价值 dp[j]：容量j的最大价值
转移方程 dp[j] = max(dp[j], dp[j-w]+v) dp[j] = max(dp[j], dp[j-w]+v)
遍历方向 逆向 ↓ j=C→w 正向 ↑ j=w→C
原因 dp[j-w]来自上一轮，保证物品只用一次 dp[j-w]可能来自当前轮，允许重复使用
关键发现：转移方程完全相同！唯一的区别就是 循环方向。这就是本节最重要的知识点。

正向遍历的原理

以 w=2, v=3, C=4 为例，直观理解为什么方向决定重复选取：

01背包 — 逆向遍历

for j = 4 → 2: 
j=4: dp[4]=max(0, dp[2]+3)=3
j=3: dp[3]=max(0, dp[1]+3)=3
j=2: dp[2]=max(0, dp[0]+3)=3
结果: dp=[0,0,3,3,3] 价值=3 ✓

dp[4]用到的dp[2]还是0（旧值，未包含当前物品）
→ 所以最多选1次

完全背包 — 正向遍历

for j = 2 → 4: 
j=2: dp[2]=max(0, dp[0]+3)=3
j=3: dp[3]=max(0, dp[1]+3)=3
j=4: dp[4]=max(0, dp[2]+3)=6
结果: dp=[0,0,3,3,6] 价值=6 ✓

dp[4]用到的dp[2]已经是3了！（新值，已包含当前物品）
→ 相当于选了第2个物品！

正向遍历 → dp[j-w]可能已被更新 → 实现重复选取
这就是完全背包用正向遍历的根本原因

货币系统问题

硬币找零方案数 —— 计数型完全背包

问题：有n种面值硬币，每种无限个。要凑出金额m，有多少种不同的组合方式？（顺序不同的算同一种）

状态定义与转移

状态dp[j] = 凑出金额 j 的方案数
初始化dp[0] = 1（凑0元有一种方案：什么都不选）
转移dp[j] += dp[j - coin[i]]（累加，不是取max！）
遍历外层硬币 → 内层金额（正向），保证组合无序性

代码实现

vector<int> dp(amount + 1, 0);
dp[0] = 1;                         // 凑0元一种方案
for (int coin : coins) {
    for (int j = coin; j <= amount; j++) {
        dp[j] += dp[j - coin];     // 累加新方案
    }
}
为什么外层循环是硬币？
这样保证 {1,2,5} 和 {5,2,1} 被视为同一种方案（组合）。如果外层是金额，内层是硬币，计算的就是排列数了。

扩展思考

  • 计数型完全背包：dp[j] += dp[j-coin[i]]，求方案数而非最大值
  • 多重背包：每种物品有限个（介于01和完全之间），可以用二进制优化或单调队列优化
  • 混合背包：部分物品01、部分完全、部分多重，分类处理即可
