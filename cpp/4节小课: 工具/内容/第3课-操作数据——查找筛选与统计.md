# 第3课：操作数据 —— 查找、筛选与统计

## 课程导入

前两节课，我们的任务管理器已经能添加和查看任务了！但光有这两个功能还不够——当任务多了以后，我们需要**标记哪些做完了**、**删除不需要的任务**、**筛选查看未完成的任务**、**统计完成情况**。

这节课，我们要给程序加上这些"高级操作"能力。核心思路其实很简单：**用循环遍历 vector，找到目标任务，然后修改或删除它**。这就像在一排储物柜中寻找特定编号的柜子，找到后打开它进行操作。

让我们把任务管理器变得真正实用起来！💪

## 核心概念

### 1. 线性查找 —— 根据 ID 找到任务

要标记或删除任务，首先需要根据用户提供的编号找到对应的任务。最直接的方法就是**逐个遍历**：

```cpp
// 根据ID查找任务，返回下标；找不到返回 -1
int findTaskById(int id) {
    for (int i = 0; i < tasks.size(); i++) {
        if (tasks[i].id == id) {
            return i;  // 找到了，返回下标
        }
    }
    return -1;  // 没找到
}
```

这种逐个检查的方法叫**线性查找（Linear Search）**。对于数量不大的数据（几百条以内），完全够用。

> **为什么返回下标而不是任务本身？**
> 返回下标后，调用者既可以读取任务信息（`tasks[idx]`），也可以修改它（`tasks[idx].done = true`），还可以删除它。一举三得！

### 2. 标记任务完成 / 未完成

找到任务后，修改它的 `done` 成员即可：

```cpp
void markDone() {
    if (tasks.empty()) {
        cout << "📭 暂无任务！" << endl;
        return;
    }

    int id;
    cout << "请输入要标记的任务编号：";
    cin >> id;

    int idx = findTaskById(id);
    if (idx == -1) {
        cout << "❌ 未找到编号为 " << id << " 的任务！" << endl;
        return;
    }

    // 切换完成状态
    tasks[idx].done = !tasks[idx].done;
    cout << "✓ 任务 #" << id;
    if (tasks[idx].done)
        cout << " 已标记为「完成」✅" << endl;
    else
        cout << " 已标记为「未完成」⬜" << endl;
}
```

`!` 运算符表示"取反"：`!true` 变成 `false`，`!false` 变成 `true`。这样同一个函数既能"标记完成"也能"取消完成"。

### 3. 删除任务 —— 使用 erase() 方法

删除 vector 中的元素使用 `erase()` 方法，需要传入**迭代器**：

```cpp
void deleteTask() {
    if (tasks.empty()) {
        cout << "📭 暂无任务！" << endl;
        return;
    }

    int id;
    cout << "请输入要删除的任务编号：";
    cin >> id;

    int idx = findTaskById(id);
    if (idx == -1) {
        cout << "❌ 未找到编号为 " << id << " 的任务！" << endl;
        return;
    }

    // 确认删除
    cout << "确定要删除任务「" << tasks[idx].title << "」吗？(y/n)：";
    char confirm;
    cin >> confirm;

    if (confirm == 'y' || confirm == 'Y') {
        tasks.erase(tasks.begin() + idx);  // 删除指定位置元素
        cout << "✓ 任务已删除！" << endl;
    } else {
        cout << "已取消删除。" << endl;
    }
}
```

**关键语法：`tasks.erase(tasks.begin() + idx)`**
- `tasks.begin()` 返回指向第一个元素的迭代器
- `tasks.begin() + idx` 指向第 idx 个元素
- `erase()` 删除该位置的元素，后面的元素自动前移

### 4. 筛选查询 —— 只看未完成的任务

筛选的核心思路是：**遍历所有任务，只显示符合条件的**。

```cpp
void viewPending() {
    int count = 0;
    cout << "\n📋 待完成的任务：" << endl;

    for (int i = 0; i < tasks.size(); i++) {
        if (!tasks[i].done) {   // 只显示未完成的
            count++;
            cout << "  [" << tasks[i].id << "] "
                 << tasks[i].title;
            if (tasks[i].priority == 1) cout << " 🔴";
            else if (tasks[i].priority == 2) cout << " 🟡";
            else cout << " 🟢";
            cout << endl;
        }
    }

    if (count == 0) {
        cout << "  🎉 所有任务都完成了！" << endl;
    } else {
        cout << "  ──────── 共 " << count << " 个待完成 ────────" << endl;
    }
}
```

### 5. 数据统计

遍历统计各类数据的数量：

```cpp
void showStats() {
    int total = tasks.size();
    int done = 0;
    int high = 0, mid = 0, low = 0;

    for (int i = 0; i < tasks.size(); i++) {
        if (tasks[i].done) done++;
        if (tasks[i].priority == 1) high++;
        else if (tasks[i].priority == 2) mid++;
        else low++;
    }

    cout << "\n📊 任务统计：" << endl;
    cout << "  总任务数：" << total << endl;
    cout << "  已完成：" << done << "  (" << (total > 0 ? done * 100 / total : 0) << "%)" << endl;
    cout << "  未完成：" << total - done << endl;
    cout << "  高优先级：" << high << "  中优先级：" << mid << "  低优先级：" << low << endl;
}
```

## 本课小结

| 知识点 | 要点 |
|--------|------|
| 线性查找 | 逐个遍历找到目标元素，O(n)复杂度 |
| 查找函数 | 返回下标，调用者可读/可写/可删 |
| erase() | `v.erase(v.begin() + idx)` 删除指定位置元素 |
| 筛选 | 遍历 + if 条件判断，只处理符合条件的元素 |
| 统计 | 遍历 + 计数器变量，汇总各类数据 |
| 二次确认 | 删除前询问确认（y/n），防止误操作 |

**学习口诀：**
> 查找任务用循环，找到下标好操作。
> erase 删除传迭代，begin+idx 记心窝。
> 筛选全靠 if 判断，统计计数好掌握。
> 删除之前问一句，用户体验暖心窝！
