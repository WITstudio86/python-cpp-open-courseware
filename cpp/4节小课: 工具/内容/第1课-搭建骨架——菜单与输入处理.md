## 核心概念

### 1. 什么是 CLI 程序？

**CLI**（Command-Line Interface，命令行界面）是一种通过文本命令与计算机交互的程序。用户输入文字指令，程序解析后执行相应操作。

```
CLI 程序交互示意：
┌─────────────────────────────────┐
│  $ todo                          │  ← 用户输入命令
│  ╔══════════════════════════╗    │
│  ║   任务管理器 v1.0       ║    │  ← 程序响应
│  ╠══════════════════════════╣    │
│  ║ 1. 添加任务             ║    │
│  ║ 2. 查看所有任务         ║    │
│  ║ ...                     ║    │
│  ╚══════════════════════════╝    │
│  请输入你的选择：                 │
└─────────────────────────────────┘
```

### 2. CLI 程序的基本骨架

一个典型的 CLI 程序包含以下组件：

```
程序启动
    │
    ▼
┌──────────┐     ┌──────────────┐
│ 显示菜单  │ ←── │ 用户选择操作  │
└──────────┘     └──────────────┘
    │                    │
    ▼                    ▼
┌──────────┐     ┌──────────────┐
│ 执行功能  │ ──→ │ 返回菜单     │
└──────────┘     └──────────────┘
    │
    ▼
┌──────────┐
│ 退出程序  │
└──────────┘
```

用代码实现这个骨架，核心是 **主循环 + switch 分支**：

```cpp
int main() {
    int choice;
    do {
        showMenu();           // 显示菜单
        cin >> choice;        // 获取用户选择
        switch (choice) {     // 根据选择执行
            case 1: addTask();      break;
            case 2: viewTasks();    break;
            case 0: cout << "再见！"; break;
            default: cout << "无效选择！";
        }
    } while (choice != 0);
    return 0;
}
```

### 3. 用户输入处理

CLI 程序中处理用户输入有几种常见方式：

```cpp
// 方式1：读取整数（菜单选择）
int choice;
cin >> choice;

// 方式2：读取一行文字（任务标题）
string title;
cin.ignore();           // 先清空缓冲区！
getline(cin, title);    // 再读取整行（包含空格）

// 方式3：读取单个字符（y/n确认）
char confirm;
cin >> confirm;
```

> **⚠️ 重要陷阱：** 在 `cin >>` 读取整数后，输入缓冲区中会残留一个换行符 `\n`。如果紧接着使用 `getline()`，它会把那个换行符当作一行读完，导致"跳过输入"的问题。解决方法：在 `getline()` 之前调用 `cin.ignore()` 清空缓冲区！

### 4. do-while 循环

`do-while` 循环的特点是：**先执行一次循环体，再检查条件**。这非常适合菜单程序，因为菜单至少要显示一次。

```cpp
do {
    // 至少执行一次
    showMenu();
    cin >> choice;
    // ...
} while (choice != 0);  // 用户选择0时退出
```

与 `while` 的区别：

| 循环类型 | 执行顺序 | 最少执行次数 |
|---------|---------|------------|
| `while (条件) { }` | 先判断，再执行 | 0 次 |
| `do { } while (条件);` | 先执行，再判断 | 1 次 |

## 代码示例：任务管理器骨架

```cpp
#include <iostream>
#include <string>
using namespace std;

// 显示主菜单
void showMenu() {
    cout << "\n╔══════════════════════════╗" << endl;
    cout << "║    📋 任务管理器 v1.0    ║" << endl;
    cout << "╠══════════════════════════╣" << endl;
    cout << "║  1. ➕ 添加新任务        ║" << endl;
    cout << "║  2. 📋 查看所有任务      ║" << endl;
    cout << "║  3. ✅ 标记任务完成      ║" << endl;
    cout << "║  4. 🗑️  删除任务         ║" << endl;
    cout << "║  0. 🚪 退出程序          ║" << endl;
    cout << "╚══════════════════════════╝" << endl;
    cout << "请输入你的选择：";
}

// 各功能的占位函数（后续课程实现）
void addTask() {
    cout << "  [功能开发中] 添加任务功能将在第2课实现！" << endl;
}

void viewTasks() {
    cout << "  [功能开发中] 查看任务功能将在第2课实现！" << endl;
}

void markDone() {
    cout << "  [功能开发中] 标记完成功能将在第3课实现！" << endl;
}

void deleteTask() {
    cout << "  [功能开发中] 删除任务功能将在第3课实现！" << endl;
}

int main() {
    int choice;

    do {
        showMenu();
        cin >> choice;

        // 清理输入缓冲区
        cin.ignore();

        cout << endl;

        switch (choice) {
            case 1: addTask();    break;
            case 2: viewTasks();  break;
            case 3: markDone();   break;
            case 4: deleteTask(); break;
            case 0:
                cout << "👋 感谢使用任务管理器，再见！" << endl;
                break;
            default:
                cout << "❌ 无效选择！请输入 0~4 之间的数字。" << endl;
        }
    } while (choice != 0);

    return 0;
}
```

**逐行讲解：**

1. `void showMenu()` — 封装菜单显示逻辑，让 `main` 函数保持简洁。
2. `do { ... } while (choice != 0);` — 至少显示一次菜单，用户选 0 时退出。
3. `switch (choice)` — 根据用户输入跳转到不同功能。
4. `cin.ignore()` — **关键！** 读取整数后清空缓冲区，避免影响后续 `getline()` 读取。
5. 各功能函数目前是"占位"的——这是**增量开发**的思路：先把骨架搭好，再逐步填充功能。

## 本课小结

| 知识点 | 要点 |
|--------|------|
| CLI 程序骨架 | 主循环 + 菜单显示 + switch 分支 |
| do-while 循环 | 先执行后判断，菜单至少显示一次 |
| switch 分支 | 根据整数选择跳转到不同功能 |
| cin.ignore() | 清空输入缓冲区，防止 getline 跳过 |
| 增量开发 | 先搭骨架（占位函数），再逐步填充功能 |
| getline vs cin>> | getline 读取整行（含空格），cin>> 遇空白停止 |

**学习口诀：**
> CLI 程序有骨架，循环菜单 switch 查。
> 整数读完留换行，ignore 清空不害怕。
> 先搭框架后填充，增量开发顶呱呱！
