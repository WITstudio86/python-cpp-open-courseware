## 核心概念

### 1. 文件流 —— 与文件对话的桥梁

C++ 通过**文件流对象**来进行文件读写，需要包含 `<fstream>` 头文件。

| 类 | 用途 | 模式 |
|----|------|------|
| `ofstream` | 写文件（output） | 从头覆盖写入 |
| `ifstream` | 读文件（input） | 从头读取 |
| `fstream` | 读写文件 | 可指定读写模式 |

### 2. 写入文件 —— 保存数据

```cpp
#include <fstream>

void saveToFile() {
    // 创建输出文件流对象，关联到文件
    ofstream file("tasks.txt");

    // 检查文件是否成功打开
    if (!file.is_open()) {
        cout << "❌ 无法打开文件进行保存！" << endl;
        return;
    }

    // 逐行写入数据（使用分隔符 | 隔开各字段）
    for (int i = 0; i < tasks.size(); i++) {
        file << tasks[i].id << "|"
             << tasks[i].title << "|"
             << tasks[i].done << "|"
             << tasks[i].priority << endl;
    }

    file.close();  // 关闭文件
    cout << "✓ 数据已保存到 tasks.txt（共 " << tasks.size() << " 条）" << endl;
}
```

**文件内容示例（tasks.txt）：**
```
1|完成数学作业|0|1
2|背英语单词|1|2
3|跑步30分钟|0|3
```

> **为什么用 `|` 分隔？** 任务标题中可能包含空格，用 `|`（或其他特殊符号）作为分隔符可以避免解析歧义。

### 3. 读取文件 —— 加载数据

```cpp
void loadFromFile() {
    ifstream file("tasks.txt");

    if (!file.is_open()) {
        // 首次运行，没有文件是正常的
        cout << "📝 未找到数据文件，将创建新任务列表。" << endl;
        return;
    }

    tasks.clear();  // 清空现有数据
    string line;

    while (getline(file, line)) {
        if (line.empty()) continue;  // 跳过空行

        // 解析每一行：按 | 分割
        Task t;
        int pos1 = line.find('|');
        int pos2 = line.find('|', pos1 + 1);
        int pos3 = line.find('|', pos2 + 1);

        t.id = stoi(line.substr(0, pos1));
        t.title = line.substr(pos1 + 1, pos2 - pos1 - 1);
        t.done = (line.substr(pos2 + 1, pos3 - pos2 - 1) == "1");
        t.priority = stoi(line.substr(pos3 + 1));

        tasks.push_back(t);
    }

    file.close();

    // 更新 nextId
    if (!tasks.empty()) {
        nextId = tasks.back().id + 1;
    }

    cout << "✓ 已从文件加载 " << tasks.size() << " 条任务。" << endl;
}
```

### 4. 字符串解析技巧

从文件中读取的数据是字符串格式，需要使用一些技巧来解析：

| 操作 | 代码 | 说明 |
|------|------|------|
| 查找子串位置 | `str.find('\|')` | 返回第一个 `\|` 的位置 |
| 从指定位置查找 | `str.find('\|', pos+1)` | 从 pos+1 位置开始查找 |
| 截取子串 | `str.substr(开始, 长度)` | 截取一段字符串 |
| 字符串转整数 | `stoi(str)` | "123" → 123 |
| 字符串转bool | `str == "1"` | "1" → true, "0" → false |

**解析过程可视化：**
```
原始行："1|完成数学作业|0|1"
        │  │            │  │
        │  │            │  └→ pos3 之后："1" → priority = 1
        │  │            └→ pos2~pos3："0" → done = false
        │  └→ pos1~pos2："完成数学作业" → title
        └→ 开头~pos1："1" → id = 1
```

### 5. 自动保存 —— 提升用户体验

每次修改数据后自动保存，用户无需手动操作：

```cpp
// 在 addTask() 末尾添加：
saveToFile();

// 在 markDone() 末尾添加：
saveToFile();

// 在 deleteTask() 确认删除后添加：
saveToFile();
```

### 6. 终端彩色输出（进阶）

使用 ANSI 转义码，可以让终端输出带颜色：

```cpp
// 定义颜色常量
const string RED    = "\033[31m";
const string GREEN  = "\033[32m";
const string YELLOW = "\033[33m";
const string BLUE   = "\033[34m";
const string RESET  = "\033[0m";  // 重置颜色

// 使用示例
cout << RED   << "❌ 错误！" << RESET << endl;
cout << GREEN << "✓ 成功！" << RESET << endl;
cout << YELLOW << "⚠ 警告！" << RESET << endl;
```

> **注意：** ANSI 转义码在大多数现代终端（macOS Terminal、Linux 终端、Windows Terminal）都能正常显示，但老旧的 Windows 命令提示符可能不支持。

## 代码示例：完整版任务管理器

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <fstream>
using namespace std;

// ===== 颜色常量（可选） =====
const string GREEN = "\033[32m";
const string YELLOW = "\033[33m";
const string RED = "\033[31m";
const string CYAN = "\033[36m";
const string RESET = "\033[0m";

// ===== 数据结构 =====
struct Task {
    int id;
    string title;
    bool done;
    int priority;  // 1=高, 2=中, 3=低
};

vector<Task> tasks;
int nextId = 1;

// ===== 文件操作 =====
void saveToFile() {
    ofstream file("tasks.txt");
    if (!file.is_open()) {
        cout << RED << "❌ 无法保存文件！" << RESET << endl;
        return;
    }
    for (int i = 0; i < tasks.size(); i++) {
        file << tasks[i].id << "|"
             << tasks[i].title << "|"
             << tasks[i].done << "|"
             << tasks[i].priority << endl;
    }
    file.close();
}

void loadFromFile() {
    ifstream file("tasks.txt");
    if (!file.is_open()) {
        cout << YELLOW << "📝 首次使用，创建新的任务列表。" << RESET << endl;
        return;
    }
    tasks.clear();
    string line;
    while (getline(file, line)) {
        if (line.empty()) continue;
        Task t;
        int p1 = line.find('|');
        int p2 = line.find('|', p1 + 1);
        int p3 = line.find('|', p2 + 1);
        t.id = stoi(line.substr(0, p1));
        t.title = line.substr(p1 + 1, p2 - p1 - 1);
        t.done = (line.substr(p2 + 1, p3 - p2 - 1) == "1");
        t.priority = stoi(line.substr(p3 + 1));
        tasks.push_back(t);
    }
    file.close();
    if (!tasks.empty()) nextId = tasks.back().id + 1;
    cout << GREEN << "✓ 已加载 " << tasks.size() << " 条任务。" << RESET << endl;
}

// ===== 其余功能（与前三课相同，增加了自动保存调用） =====
// ... (addTask, viewTasks, markDone, deleteTask, viewPending, showStats 等)

// ===== 主函数 =====
int main() {
    loadFromFile();  // 启动时自动加载数据

    int choice;
    do {
        showMenu();
        cin >> choice;
        cin.ignore();
        cout << endl;

        switch (choice) {
            case 1: addTask();    break;
            case 2: viewTasks();  break;
            case 3: markDone();   break;
            case 4: deleteTask(); break;
            case 5: viewPending(); break;
            case 6: showStats();   break;
            case 0:
                saveToFile();  // 退出时保存
                cout << GREEN << "👋 数据已保存，再见！" << RESET << endl;
                break;
            default:
                cout << RED << "❌ 无效选择！请输入 0~6。" << RESET << endl;
        }
    } while (choice != 0);

    return 0;
}
```

## 本课小结

| 知识点 | 要点 |
|--------|------|
| ofstream | 用于写文件，`<<` 运算符写入数据 |
| ifstream | 用于读文件，`getline()` 逐行读取 |
| 文件格式 | 用分隔符（如 `\|`）组织数据，便于解析 |

| stoi() | 字符串转整数 |
| 自动保存 | 在数据变化后立即保存，防止丢失 |
| 自动加载 | 程序启动时读取文件，恢复上次数据 |

| 项目发布 | `g++ -std=c++11` 编译成可执行文件 |

**学习口诀：**
> ofstream 写文件，ifstream 来读取。
> 分隔符串数据，find+substr 拆出来。
