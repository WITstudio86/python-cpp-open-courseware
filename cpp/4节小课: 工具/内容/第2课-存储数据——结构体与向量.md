# 第2课：存储数据 —— 结构体与向量

## 课程导入

上节课我们搭好了任务管理器的骨架——菜单系统已经能跑起来了！但是，当我们选择"添加任务"时，程序只是打印了一句"功能开发中"。

今天，我们要让程序真正**记住任务**！这就需要解决两个问题：
1. 每个任务包含哪些信息？（标题、是否完成、优先级……）
2. 如何存储多个任务？（数量不确定，可能随时增减）

C++ 为我们准备了两个强大的工具：**结构体（struct）** 用于定义任务的数据结构，**向量（vector）** 用于动态存储任意数量的任务。

让我们开始赋予程序"记忆力"吧！🧠

## 核心概念

### 1. 结构体 —— 自定义复合数据类型

结构体允许我们把**多个不同类型的数据组合在一起**，形成一个新的数据类型。就像一个"档案袋"，里面可以装各种信息。

```cpp
// 定义任务结构体
struct Task {
    int id;           // 任务编号
    string title;     // 任务标题
    bool done;        // 是否完成（true/false）
    int priority;     // 优先级（1=高, 2=中, 3=低）
};
```

**使用结构体：**

```cpp
// 声明一个 Task 类型的变量
Task t1;
t1.id = 1;
t1.title = "完成数学作业";
t1.done = false;
t1.priority = 1;

// 也可以在声明时初始化（C++11起支持）
Task t2 = {2, "背英语单词", false, 2};

// 访问结构体成员
cout << t1.title << endl;     // 输出：完成数学作业
cout << t1.id << endl;        // 输出：1
```

结构体的每个组成部分叫**成员变量**，使用 `.` 运算符来访问，就像 `变量名.成员名`。

### 2. 向量 —— 动态数组

`vector` 是 C++ 标准库提供的**动态数组**容器，它可以根据需要自动调整大小。与普通数组不同，vector 不需要在声明时确定大小。

```cpp
#include <vector>    // 使用 vector 必须包含这个头文件

// 声明一个存放 Task 的向量
vector<Task> tasks;

// 添加元素
tasks.push_back(t1);  // 把 t1 添加到末尾
tasks.push_back(t2);  // 把 t2 添加到末尾

// 获取元素个数
cout << tasks.size() << endl;  // 输出：2

// 访问元素（和数组一样用下标！）
cout << tasks[0].title << endl;  // 输出：完成数学作业
cout << tasks[1].title << endl;  // 输出：背英语单词

// 清空向量
tasks.clear();
```

| 操作 | 代码 | 说明 |
|------|------|------|
| 添加元素 | `v.push_back(x)` | 在末尾添加一个元素 |
| 元素个数 | `v.size()` | 返回当前元素数量 |
| 访问元素 | `v[i]` | 用下标访问，从 0 开始 |
| 清空 | `v.clear()` | 删除所有元素 |
| 判空 | `v.empty()` | 是否为空，返回 bool |

### 3. 用 vector 存储任务

将结构体和向量结合起来，我们就能动态管理任务了：

```cpp
vector<Task> tasks;     // 全局任务列表
int nextId = 1;         // 下一个任务的编号

void addTask() {
    Task t;
    t.id = nextId++;    // 自动编号，编号自增
    t.done = false;     // 新任务默认未完成

    cout << "请输入任务标题：";
    cin.ignore();
    getline(cin, t.title);

    cout << "优先级（1=高, 2=中, 3=低）：";
    cin >> t.priority;

    tasks.push_back(t);  // 存入列表
    cout << "✓ 任务添加成功！（编号：" << t.id << "）" << endl;
}
```

### 4. 格式化输出任务列表

用循环遍历 vector 中的所有任务，并以表格形式展示：

```cpp
void viewTasks() {
    if (tasks.empty()) {
        cout << "📭 暂无任务！" << endl;
        return;  // 提前返回
    }

    // 表头
    cout << "\n┌──────┬────────────────────────┬──────────┬──────────┐" << endl;
    cout << "│ 编号 │       任务标题         │   状态   │  优先级  │" << endl;
    cout << "├──────┼────────────────────────┼──────────┼──────────┤" << endl;

    // 表体：遍历每个任务
    for (int i = 0; i < tasks.size(); i++) {
        cout << "│  " << tasks[i].id << "   │  " << tasks[i].title;
        // 手动对齐空格
        int len = tasks[i].title.length() * 2;  // 中文占2字符宽度
        for (int s = 0; s < 22 - len; s++) cout << " ";
        cout << "│  " << (tasks[i].done ? "✅ 已完成" : "⬜ 未完成") << "  │";
        cout << "    " << tasks[i].priority << "     │" << endl;
    }

    cout << "└──────┴────────────────────────┴──────────┴──────────┘" << endl;
    cout << "共 " << tasks.size() << " 个任务。" << endl;
}
```

## 代码示例：能"记住"任务的任务管理器

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <iomanip>
using namespace std;

// 任务结构体
struct Task {
    int id;
    string title;
    bool done;
    int priority;
};

// 全局数据
vector<Task> tasks;
int nextId = 1;

// 添加任务
void addTask() {
    Task t;
    t.id = nextId++;
    t.done = false;

    cout << "请输入任务标题：";
    cin.ignore();
    getline(cin, t.title);

    cout << "优先级（1=高, 2=中, 3=低）：";
    cin >> t.priority;

    tasks.push_back(t);
    cout << "✓ 任务添加成功！（编号：" << t.id << "）" << endl;
}

// 查看所有任务
void viewTasks() {
    if (tasks.empty()) {
        cout << "📭 暂无任务！" << endl;
        return;
    }
    cout << "\n┌────┬──────────────────────┬──────────┬──────┐" << endl;
    cout << "│ 编号│       任务标题       │   状态   │ 优先级│" << endl;
    cout << "├────┼──────────────────────┼──────────┼──────┤" << endl;
    for (int i = 0; i < tasks.size(); i++) {
        cout << "│ " << setw(2) << tasks[i].id << " │ " << tasks[i].title;
        cout << " │ " << (tasks[i].done ? "✅ 已完成" : "⬜ 未完成");
        cout << " │   " << tasks[i].priority << "  │" << endl;
    }
    cout << "└────┴──────────────────────┴──────────┴──────┘" << endl;
    cout << "共 " << tasks.size() << " 个任务。" << endl;
}
```

## 本课小结

| 知识点 | 要点 |
|--------|------|
| struct | 自定义复合数据类型，用 `.` 访问成员 |
| vector\<T\> | 动态数组，自动管理大小，用下标访问 |
| push_back() | 向 vector 末尾添加元素 |
| size() | 获取 vector 中元素个数 |
| empty() | 判断 vector 是否为空 |
| 全局数据 | 在函数外声明 vector，让所有函数共享 |
| 自动编号 | 用 `nextId++` 给每个新任务分配唯一编号 |

**学习口诀：**
> 结构体是档案袋，多个数据装一块。
> 向量是个魔法袋，想装多少都能塞。
> push_back 后面加，下标访问快又快！
