线性查找 —— 在任务列表中寻找目标

要标记或删除某个任务，首先需要根据编号找到它。最直接的方法：逐个遍历匹配——这叫线性查找（Linear Search）。

int findTaskById(int id) { for (int i = 0; i < tasks.size(); i++) { if (tasks[i].id == id) { return i; // 找到了！返回下标 } } return -1; // 遍历完都没找到 }
查找 id=3 的过程： tasks[0].id=1 ≠ 3 → 继续 tasks[1].id=2 ≠ 3 → 继续 tasks[2].id=3 == 3 → 找到！返回 idx=2

💡 为什么返回下标？调用者拿到下标后，既可以读取（tasks[idx]）、也可以修改（tasks[idx].done = true）、还可以删除（erase）。一举三得！

标记任务 —— 切换完成状态
void markDone() { if (tasks.empty()) { cout << "📭 暂无任务！" << endl; return; } int id; cout << "请输入任务编号："; cin >> id; int idx = findTaskById(id); if (idx == -1) { cout << "❌ 未找到！" << endl; return; } tasks[idx].done = !tasks[idx].done; // ★ 取反：true↔false cout << "✓ 任务 #" << id; if (tasks[idx].done) cout << " 已标记为 ✅ 已完成" << endl; else cout << " 已标记为 ⬜ 未完成" << endl; }

亮点：使用 !（取反运算符），同一个函数既能"标记完成"也能"取消完成"——一键切换！

// 关键语法： tasks.erase(tasks.begin() + idx); // ↑ 指向第一个元素的迭代器 + 偏移量
删除 tasks[2] 的过程： 删除前：[Task0] [Task1] [Task2] [Task3] [Task4] ↑ 要删除这个 删除后：[Task0] [Task1] [Task3] [Task4] 后面的元素自动前移！
⚠️ 二次确认很重要！删除是不可逆操作，一定要在删除前询问用户确认（y/n），防止误删。这是良好用户体验的基本要求。

筛选查询 —— 只看待完成的任务

筛选的核心思路：遍历所有任务，用 if 条件过滤，只显示符合条件的。

void viewPending() { int count = 0; cout << "\n📋 待完成的任务：" << endl; for (int i = 0; i < tasks.size(); i++) { if (!tasks[i].done) { // ★ 只显示未完成的 count++; cout << " [" << tasks[i].id << "] " << tasks[i].title; if (tasks[i].priority == 1) cout << " 🔴"; else if (tasks[i].priority == 2) cout << " 🟡"; else cout << " 🟢"; cout << endl; } } if (count == 0) cout << " 🎉 所有任务都完成了！" << endl; else cout << " 共 " << count << " 个待完成。" << endl; }

泛化能力：只需改 if 条件，就能实现各种筛选——按优先级、按关键字搜索、按日期范围……

数据统计 —— 让数字说话
void showStats() { int total = tasks.size(); int done = 0; int high = 0, mid = 0, low = 0; for (int i = 0; i < total; i++) { if (tasks[i].done) done++; if (tasks[i].priority == 1) high++; else if (tasks[i].priority == 2) mid++; else low++; } cout << "\n📊 任务统计：" << endl; cout << " 总任务：" << total << " | 已完成：" << done; cout << " | 完成率：" << (total ? done*100/total : 0) << "%" << endl; }
进度条可视化： [████████████░░░░░░░░] 60% 3/5 个任务已完成

技巧：用 total ? done*100/total : 0 防止除以 0 导致程序崩溃。

🔍 线性查找

遍历 + if 条件，只处理符合条件的元素
📊 数据统计
