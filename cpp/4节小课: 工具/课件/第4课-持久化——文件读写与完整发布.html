致命问题：数据去哪了？

前三节课，我们做出了一个功能齐全的任务管理器。但有一个致命问题：

$ ./todo 添加了 5 个任务... 标记完成了 3 个... 退出程序。 $ ./todo ← 重新打开 📭 暂无任务！ ↑ 数据全丢了！😱

因为数据只存在内存里，程序关闭后内存就释放了。

🎯 解决方案：持久化（Persistence）——把数据写入硬盘上的文件！

文件流 —— 与文件对话的桥梁

C++ 通过文件流对象读写文件，需要包含 <fstream> 头文件。

类用途类比关键方法
ofstream写文件（Output）把数据"倒"进文件open(), <<, close()
ifstream读文件（Input）从文件"取"出数据open(), getline(), close()
fstream读写文件可读可写上述两者之和
#include <fstream> // 文件操作必备 // 写文件 ofstream outFile("tasks.txt"); // 创建/打开文件用于写入 outFile << "Hello, 文件！" << endl; // 像 cout 一样写入 outFile.close(); // 关闭文件（好习惯！） // 读文件 ifstream inFile("tasks.txt"); // 打开文件用于读取 string line; getline(inFile, line); // 像 cin 一样读取 inFile.close();
保存数据 —— 把任务写入文件
void saveToFile() { ofstream file("tasks.txt"); // 创建/打开文件 if (!file.is_open()) { // 检查是否成功打开 cout << "❌ 无法保存！" << endl; return; } // 逐行写入：id|title|done|priority for (int i = 0; i < tasks.size(); i++) { file << tasks[i].id << "|" << tasks[i].title << "|" << tasks[i].done << "|" << tasks[i].priority << endl; } file.close(); cout << "✓ 已保存 " << tasks.size() << " 条任务。" << endl; }
tasks.txt 内容示例： 1|完成数学作业|0|1 2|背英语单词|1|2 3|跑步30分钟|0|3 ↑id ↑标题 ↑done ↑优先级

为什么用 | 分隔？任务标题可能含空格，用 | 作为分隔符可以避免解析歧义。

读取数据 —— 解析文件还原任务
void loadFromFile() { ifstream file("tasks.txt"); if (!file.is_open()) { // 首次使用，没文件正常 cout << "📝 首次使用，创建新列表。" << endl; return; } tasks.clear(); // 清空现有数据 string line; while (getline(file, line)) { // 逐行读取 if (line.empty()) continue; // 跳过空行 // 按 | 分割字符串 Task t; int p1 = line.find('|'); int p2 = line.find('|', p1 + 1); int p3 = line.find('|', p2 + 1); t.id = stoi(line.substr(0, p1)); t.title = line.substr(p1+1, p2-p1-1); t.done = (line.substr(p2+1, p3-p2-1) == "1"); t.priority = stoi(line.substr(p3 + 1)); tasks.push_back(t); } file.close(); if (!tasks.empty()) nextId = tasks.back().id + 1; }
字符串解析 —— 拆解"|"分隔的数据行
原始行："1|完成数学作业|0|1" │ │ │ │ │ │ │ └→ p3之后："1" → stoi → priority = 1 │ │ └→ p2~p3："0" →=="1"? → done = false │ └→ p1~p2："完成数学作业" → title └→ 开头~p1："1" → stoi → id = 1
操作代码说明
查找分隔符line.find('|')返回第一个 | 的位置
继续查找line.find('|', pos+1)从指定位置向后找
截取子串line.substr(start, len)截取一段字符串
转整数stoi(str)"123" → 123
转布尔str == "1""1" → true, "0" → false

锦上添花 —— 终端彩色输出

使用 ANSI 转义码让终端输出带颜色：

// 定义颜色常量 const string RED = "\033[31m"; const string GREEN = "\033[32m"; const string YELLOW = "\033[33m"; const string CYAN = "\033[36m"; const string RESET = "\033[0m"; // ★ 用完颜色要重置！ // 使用示例 cout << RED << "❌ 错误！" << RESET << endl; cout << GREEN << "✓ 成功！" << RESET << endl; cout << YELLOW << "⚠ 警告！" << RESET << endl;
⚠️ 注意：ANSI 转义码在现代终端（macOS Terminal、Linux、Windows Terminal）都能正常工作，但旧版 Windows CMD 可能不支持。可以用 #ifdef _WIN32 做平台兼容处理。
