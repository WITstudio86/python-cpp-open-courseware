结构体与向量

4节小课 · 第2课 | 从零构建 CLI 任务管理器

上节课回顾 & 本节课目标

上节课我们搭好了任务管理器的骨架——菜单系统已经能跑起来了！但是选择"添加任务"时，只是打印了一句"功能开发中"……

今天要让程序真正记住任务！需要解决两个核心问题：

❓1
数据长什么样？
每个任务包含：编号、标题、是否完成、优先级……需要一种复合数据类型
❓2
怎么存多个？
任务数量不确定，可能随时增减……需要一种动态容器

答案：struct（结构体） + vector（向量） = 完美组合！🧠

结构体 —— 自定义"档案袋"

结构体（struct）允许我们把多个不同类型的数据组合在一起，形成一个新的复合数据类型。

struct Task { int id; // 任务编号 string title; // 任务标题 bool done; // 是否完成（true/false） int priority; // 优先级（1=高, 2=中, 3=低） }; // ★ 注意：末尾有分号！
Task t1; ← 声明一个 Task 类型的变量 ┌─────────────────────────────────────┐ │ id → 1 │ │ title → "完成数学作业" │ │ done → false │ │ priority → 1 │ └─────────────────────────────────────┘ 就像一个"档案袋"，里面可以装各种信息！
使用结构体 —— 点运算符访问成员

结构体的每个组成部分叫成员变量，使用 . 运算符来访问。

// 方式1：逐个赋值 Task t1; t1.id = 1; t1.title = "完成数学作业"; t1.done = false; t1.priority = 1; // 方式2：声明时初始化（C++11起支持） Task t2 = {2, "背英语单词", false, 2}; // 访问成员 cout << t1.title << endl; // 输出：完成数学作业 cout << t1.id << endl; // 输出：1

💡 类比：就像填写一张表格——t1.id = 1 就是在"编号"那一栏填上 1。

vector —— 会"自动长大"的魔法袋

vector 是 C++ 标准库提供的动态数组容器。与普通数组不同，vector 不需要在声明时确定大小，可以根据需要自动扩容。

#include <vector> // 使用 vector 必须包含这个头文件 // 声明：vector<元素类型> 变量名; vector<Task> tasks; // 存放 Task 的动态数组 vector<int> numbers; // 存放整数的动态数组 vector<string> names; // 存放字符串的动态数组
操作代码说明
添加元素v.push_back(x)在末尾添加
元素个数v.size()返回 int
访问元素v[i]下标访问，从0开始
清空v.clear()删除所有元素
判空v.empty()返回 bool
vector vs 普通数组 —— 为什么选 vector？
特性普通数组vector
大小声明时确定，不可变动态变化，自动扩容
初始化int arr[5] = {1,2,3,4,5};vector<int> v = {1,2,3,4,5};
获取大小sizeof(arr)/sizeof(arr[0])v.size()
越界检查不检查，危险！v.at(i) 方式会检查（可选）
添加元素不支持v.push_back(x)
适用场景数量固定且已知数量不确定/动态变化

结论：任务管理器的任务数量是动态变化的——用户随时添加和删除——vector 是唯一正确的选择。

struct + vector —— 动态任务存储的实现
struct Task { int id; string title; bool done; int priority; }; vector<Task> tasks; // 全局任务列表 int nextId = 1; // 下一个任务的编号（自动增长） void addTask() { Task t; t.id = nextId++; // 自动编号：先用当前值，再+1 t.done = false; cout << "请输入任务标题："; cin.ignore(); getline(cin, t.title); cout << "优先级（1=高, 2=中, 3=低）："; cin >> t.priority; tasks.push_back(t); // ★ 存入列表 cout << "✓ 任务添加成功！" << endl; }

关键细节：nextId++ 是后置自增——先使用当前值赋给 id，再将 nextId 加 1。这样每个任务都有唯一编号。

格式化输出 —— 把任务列表变成漂亮表格
void viewTasks() { if (tasks.empty()) { // 先检查是否为空 cout << "📭 暂无任务！" << endl; return; } // ★ 表头 cout << "\n┌────┬──────────────────────┬──────────┬──────┐" << endl; cout << "│ 编号│ 任务标题 │ 状态 │ 优先级│" << endl; cout << "├────┼──────────────────────┼──────────┼──────┤" << endl; // ★ 表体：遍历每个任务 for (int i = 0; i < tasks.size(); i++) { cout << "│ " << setw(2) << tasks[i].id << " │ " << tasks[i].title; cout << " │ " << (tasks[i].done ? "✅ 已完成" : "⬜ 未完成"); cout << " │ " << tasks[i].priority << " │" << endl; } cout << "└────┴──────────────────────┴──────────┴──────┘" << endl; cout << "共 " << tasks.size() << " 个任务。" << endl; }

本课小结
🏗️ struct
自定义复合数据类型，用 . 访问成员
📦 vector\
动态数组，自动管理大小，用下标访问
➕ push_back()
向 vector 末尾添加元素
📏 size()
获取 vector 中元素个数
🈳 empty()
判断 vector 是否为空
🌐 全局数据
在函数外声明 vector，让所有函数共享
🔢 自动编号
用 nextId++ 给每个新任务唯一编号
📊 格式化输出
表格 + 循环 = 美观的数据展示
