【开场】第 1/14 页 · for 循环结构 大纲考点：for 语法、循环变量作用域、累加累乘、嵌套、次数计算 互动：问学生「不用循环，1 到 100 求和要写多少行？」

一、为什么需要循环

编程中经常需要重复执行同一类操作：

  • 计算 1 到 100 的和——不用循环要写 100 行加法
  • 打印九九乘法表——需要 9×9 = 81 行输出
  • 遍历数组所有元素——可能有成千上万个
循环类型特点典型场景
for最紧凑，三要素集中已知循环次数
while先判断后执行未知次数、有终止条件
do-while先执行后判断至少执行一次
本课聚焦 for： 当循环次数已知（或可用公式表达）时，for 是首选。C++ 三种循环可互相改写，但语义清晰度不同。
// 输出 1 到 5（不用循环要写 5 行 cout） for (int i = 1; i <= 5; i++) { cout << i << " "; } // 输出：1 2 3 4 5
【讲解】为什么需要循环 强调 for 适合已知次数；后两课补 while / do-while。

二、for 循环的三要素详解

for (初始化语句; 条件表达式; 更新语句) { // 循环体：需要重复执行的代码 }
要素执行时机示例
初始化循环开始前执行一次int i = 1
条件每次循环开始前判断i <= 10
更新每次循环体结束后执行i++

执行流程图

初始化
int i=1 → 条件?
i<=5 →true 循环体
cout << i → 更新
i++ ↺

条件为 false → 退出循环

// 逐步：i=1 输出1 → i=2…→ i=5 输出5 → i=6 条件假，退出 for (int i = 1; i <= 5; i++) { cout << i << " "; }
记忆口诀： 初始化只做一次；条件每次进循环前判断；更新在循环体之后。
【讲解】三要素 板书：初始化→判断→体→更新→判断…

三、循环变量作用域（C++ 特性）

在 for 初始化中声明的变量（如 for (int i = 1; ...)），作用域仅限于 for 循环内部。

内部声明：循环后不可用
for (int i = 1; i <= 3; i++) { cout << i; // OK } // cout << i; 编译错误！
外部声明：循环后仍可用
int i; for (i = 1; i <= 3; i++) { cout << i; } cout << i; // i = 4
考试高频： 问「循环结束时 i 的值」——必须先分清 i 是在 for 内还是 for 外声明。结束时 i 往往是「第一个使条件为假」的值。
代码结束后 i（外部声明）
for (i = 0; i < 5; i++)i = 5
for (i = 1; i <= 3; i++)i = 4
for (i = 10; i >= 1; i--)i = 0
【讲解】作用域 选择题常考循环结束后 i 的值。

四、累加与累乘模式

累加模式（Sum）

// 计算 1+2+...+n int sum = 0; // 必须初始化 0 for (int i = 1; i <= n; i++) { sum += i; // sum = sum + i } cout << sum;

关键：累加器初值为 0（加法单位元）

累乘模式（Product）

// 计算 n! = 1*2*...*n int fact = 1; // 必须初始化 1 for (int i = 1; i <= n; i++) { fact *= i; // fact = fact * i } cout << fact;

关键：累乘器初值为 1（乘法单位元）

模式初始值运算符典型应用
累加0+=求和、计数、总分
累乘1*=阶乘、乘方、组合数
常见错误： 累乘器初始化为 0 → 任何数×0=0，结果恒为 0。n 较大时阶乘可能溢出 int，可用 long long。
// 素数判断：for + break 经典模式 bool isPrime = true; for (int i = 2; i * i <= n; i++) { if (n % i == 0) { isPrime = false; break; } } if (n < 2) isPrime = false;
【讲解】累加累乘 对比 0 和 1 的单位元；提素数判断预告 break。

五、循环嵌套原理

外层每执行一次，内层完整跑一遍。核心原则：外层控制行，内层控制列。

九九乘法表

for (int i = 1; i <= 9; i++) { // 行 for (int j = 1; j <= i; j++) { // 列 cout << j << "x" << i << "=" << i * j << "\t"; } cout << endl; }

内层 j <= i → 下三角形状。

直角三角形

for (int i = 1; i <= 5; i++) { for (int j = 1; j <= i; j++) { cout << "*"; } cout << endl; } // * // ** // *** // **** // *****
分析套路： 先定外层「有几行」，再定内层「第 i 行打几个什么」。内层条件常依赖外层变量 i。
【讲解】嵌套 外层 i 行、内层 j 列；乘法表 j<=i 形成三角。

六、循环次数计算公式

代码模式执行次数示例
for(i=a; i<=b; i++)b − a + 11~10 → 10 次
for(i=a; i<b; i++)b − a0~<10 → 10 次
for(i=a; i>=b; i--)a − b + 110~1 → 10 次
for(i=a; i<=b; i+=step)(b−a)/step + 1整除时适用
嵌套 n 层 × m 层n × m3×4 → 12 次
Off-by-One（差一错误）陷阱：
for (int i = 0; i < 10; i++) // 10 次（0~9） for (int i = 0; i <= 10; i++) // 11 次（0~10）易误为 10！ for (int i = 1; i < 10; i++) // 9 次（1~9）易误为 10！
口诀： <= 包含边界，< 不包含。写完 for 先脑补「第一次」和「最后一次」的 i。
【讲解】次数公式 读代码题高频；强调 < 与 <= 差一。

七、for 循环的更多用法

1. 多变量（逗号表达式）

for (int i = 0, j = 10; i < j; i++, j--) { cout << i << " " << j << endl; }

2. 倒序遍历

for (int i = 10; i >= 1; i--) { cout << i << " "; } // 10 9 8 ... 1

3. 无限循环 + break

for (;;) { // 三部分都空 // 处理逻辑 if (某条件) break; }

4. 步长不为 1

// 输出 1~20 奇数 for (int i = 1; i <= 20; i += 2) { cout << i << " "; }
提示： CSP-J 不考 C++11 范围 for（for (int x : a)）。考场优先用经典三要素 for。
勿在循环体内随意改循环变量： for (int i=1; i<=10; i++) { i=0; } 会导致死循环。
【讲解】扩展用法 倒序、步长、for(;;) 即可，范围 for 不考。

代码模板

模板1：累加求和

#include <iostream> using namespace std; int main() { int n; cin >> n; int sum = 0; for (int i = 1; i <= n; i++) { sum += i; } cout << sum << endl; return 0; }

模板2：九九乘法表（嵌套）

#include <iostream> #include <iomanip> using namespace std; int main() { for (int i = 1; i <= 9; i++) { for (int j = 1; j <= i; j++) { cout << j << "x" << i << "=" << setw(2) << i * j << " "; } cout << endl; } return 0; }
【讲解】模板1、2 强调 sum=0 与 setw 对齐可选。

代码模板 · 因子枚举

#include <iostream> using namespace std; int main() { int n; cin >> n; for (int i = 1; i <= n; i++) { if (n % i == 0) { cout << i << " "; } } cout << endl; return 0; }
延伸： 因子个数恰好为 2 → 素数（1 与自身）。进阶可只枚举到 sqrt(n) 优化。

易错点预览（下页详解）

  • for 后误加分号 → 空循环体
  • 边界 < / <= 差一
  • 循环变量作用域混淆
  • 循环体内改 i 导致死循环
  • 嵌套中内外层变量写混
【讲解】因子枚举 演示 n=12 输出 1 2 3 4 6 12。

易错点精讲

1. for 后加分号 → 空循环体
for (int i = 1; i <= 10; i++); // 分号！空循环 cout << i; // 不在循环内，且 i 可能越界/编译错
避免： 始终用 {} 包住循环体，即使只有一行。
2. 边界 Off-by-One — 想输出 1~10 却写 i < 10，只得 1~9。
3. 作用域混淆 — for (int i=...) 后访问 i 编译错误。
4. 循环体内重置 i — i = 0; 可能导致死循环。
5. 嵌套变量混淆
// 错：两处都用 i cout << i << "x" << i << "=" << i * i; // 对：j << "x" << i << "=" << i * j
【讲解】易错点 重点讲分号陷阱和 off-by-one。

真题2：嵌套循环输出分析（金字塔）

n=4，写出完整输出

int n = 4; for (int i = 1; i <= n; i++) { for (int j = 1; j <= n - i; j++) cout << " "; for (int k = 1; k <= 2 * i - 1; k++) cout << "*"; cout << endl; }
