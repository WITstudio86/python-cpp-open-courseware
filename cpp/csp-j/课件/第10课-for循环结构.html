for 循环结构

掌握计次循环的核心技术

三要素 累加/累乘 循环嵌套 次数计算

for 循环三要素详解

for (初始化; 条件; 更新) { // 循环体：需要重复执行的代码 }
要素执行时机示例
初始化循环开始前执行一次int i = 1
条件每次循环开始前判断i <= 10
更新每次循环体结束后执行i++

执行流程图

初始化
int i=1 → 条件?
i<=10 →true 循环体
cout << i → 更新
i++ ↺

条件为 false 时退出循环

考试技巧： C++ 允许在 for 初始化部分声明变量（int i = 1），该变量作用域仅限于 for 循环内部。循环结束后 i 不可访问。这是 C++ 区别于 C 语言（C99 之前）的重要特性，常出现在选择题中。

累加与累乘模式

累加模式（Sum Pattern）

// 计算 1+2+...+n int sum = 0; // 累加器初始化为 0 for (int i = 1; i <= n; i++) { sum += i; // sum = sum + i } cout << sum;

关键：累加器初始化为 0（加法的单位元）

累乘模式（Product Pattern）

// 计算 n! = 1*2*...*n int fact = 1; // 累乘器初始化为 1 for (int i = 1; i <= n; i++) { fact *= i; // fact = fact * i } cout << fact;

关键：累乘器初始化为 1（乘法的单位元）

常见错误： 累乘器初始化为 0！任何数乘以 0 都是 0，导致结果始终为 0。累加器初始化为 0，累乘器必须初始化为 1。
模式初始值运算符典型应用
累加0+=求和、计数、总分
累乘1*=阶乘、乘方、组合数

循环嵌套与次数计算

核心原则：「外层控制行，内层控制列」

九九乘法表：

for (int i = 1; i <= 9; i++) { // 行 for (int j = 1; j <= i; j++) { // 列 cout << j<<"x"<<i<<"="<<i*j<<" "; } cout << endl; }

金字塔打印：

for (int i = 1; i <= n; i++) { for (int j = 1; j <= n-i; j++) cout << " "; for (int k = 1; k<=2*i-1; k++) cout << "*"; cout << endl; }

循环次数计算公式

代码执行次数示例
for(i=a; i<=b; i++)b - a + 1for(i=1;i<=10;i++) → 10次
for(i=a; i<b; i++)b - afor(i=0;i<10;i++) → 10次
for(i=a; i>=b; i--)a - b + 1for(i=10;i>=1;i--) → 10次
嵌套循环（n层×m层）n × m3层×4层 → 12次
Off-by-One 陷阱： i < 10 执行 10 次（i=0~9），i <= 10 执行 11 次（i=0~10）。差一个边界是考试中最容易出错的地方！

真题精练

真题1：循环执行次数计算

分析以下三段代码的执行次数：

// 代码A for(i=0; i<5; i++) for(j=0; j<=i; j++) count++; // → 输出：15 (1+2+3+4+5) // 代码B: 内层改为 j<3 // → 输出：15 (5×3) // 代码C: for(i=1;i<=5;i++) for(j=1;j<=i;j++) count+=j; // → 输出：35 (1+3+6+10+15)

考点：嵌套循环执行次数 = 各层次数的乘积（或累加和）

真题2：嵌套循环输出分析

分析以下代码的完整输出（n=4 的金字塔图形）：

* 第1行: 3空格 + 1星号 *** 第2行: 2空格 + 3星号 ***** 第3行: 1空格 + 5星号 ******* 第4行: 0空格 + 7星号

考点：外层控制行数 → 内层分别控制空格（n-i）和星号（2i-1）

解题思路： 遇到嵌套循环输出分析题，逐行列出外层 i 的值，然后根据内层循环条件计算每行的输出。画表格是最高效的解题方法。

本课小结

for 三要素
初始化（一次） → 条件（每次前） → 更新（每次后）
变量作用域
for 内声明的变量只在循环内有效（C++ 特性）
累加模式
sum=0; sum+=i;（加法的单位元是 0）
累乘模式
fact=1; fact*=i;（乘法的单位元是 1）
循环嵌套
外层行、内层列；总次数 = 外层 × 内层
次数计算
<= 包含边界，< 不包含；注意 off-by-one
三大易错点：
1. for 后加分号：for(...); 导致空循环体，后面的代码只执行一次
2. 边界 off-by-one：i<10 是 10 次（0~9），i<=10 是 11 次
3. 累乘器初始化为 0：任何数乘 0 得 0，正确做法是初始化为 1
考试建议： 读代码题常考嵌套循环的执行次数和输出结果，逐行画表分析最可靠。编程题常考累加求和、乘法表和图形打印。每写一个 for 循环，先模拟第一次和最后一次的执行，验证边界。
