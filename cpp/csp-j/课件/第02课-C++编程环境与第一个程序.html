CSP-J 第一轮 · 编程基础模块

【开场】建文件→写代码→编译→运行→对照样例。本课是后续所有课程的入口。

一、为什么需要编程环境？

编辑器

输入源代码 .cpp 文本文件。

编译器

把源码翻译成可执行机器码（常见 MinGW g++）。

运行与调试

一键编译运行，查看报错与输出。

IDE特点适用
Dev-C++轻量、界面简单，考场常见入门首选
Code::Blocks功能较全，工程管理清晰入门 / 进阶
VS Code + MinGW现代编辑器，需自行配置有基础后
在线 IDE洛谷 / AcWing 等临时验证
💡 IDE = 编辑 + 编译 + 运行集成在一起。学语法不绑死某一个 IDE，换环境只需熟悉快捷键。
考场多为 Dev-C++ / Code::Blocks + MinGW，支持 C++14 左右。

二、Dev-C++ 基本使用

操作快捷键
新建 / 打开Ctrl+N / Ctrl+O
保存 / 另存为Ctrl+S / Ctrl+Shift+S
编译F9
运行F10
编译并运行F11（最常用）

不同版本略有差异，以菜单“运行”标注为准。

  1. 新建 → 立即另存为 英文路径 hello.cpp
  2. 输入代码 → Ctrl+S 保存
  3. F11 编译运行
  4. 看黑框输出 / 下方编译日志
  5. 有错：按行号改 → 再保存 → 再 F11
⚠️ 路径用纯英文、无空格，如 D:\cspj\lesson02\hello.cpp。修改后必须重新编译。
黑框一闪：勿依赖 system("pause") 提交。正式评测不需要暂停。

  1. 预处理：处理 #include、#define 等，文本级展开

  3. 链接：与标准库等合并成可执行文件
  4. 运行：OS 加载，从 main 开始执行

五、第一个 C++ 程序逐行解析

hello.cpp 
#include <iostream>          // ① 输入输出流头文件
using namespace std;         // ② 标准命名空间

int main() {                 // ③ 唯一入口，返回 int
    cout << "Hello, CSP-J!" << endl;  // ④ 输出
    return 0;                // ⑤ 正常结束
}
#include <iostream>：引入 cin/cout/endl。尖括号走系统路径。
using namespace std：可写 cout；否则写 std::cout。CSP-J 可用。
int main()：区分大小写；勿写 void main / Main。
cout <<：标准输出，可链式；字符串用英文双引号。
endl：换行并刷新；也可用 '\n'。
return 0：成功退出；教学建议显式写出。
最小骨架 int main(){return 0;}；一用 cout 就必须 iostream。

八、cout 输出与转义字符

cout_demo.cpp 
#include <iostream>
using namespace std;
int main() {
    cout << "第一行" << endl;
    cout << "A" << "B" << "C" << endl;   // ABC
    cout << 2 + 3 * 4 << endl;       // 14（先乘后加）

七、注释 Comment

comments.cpp
// 单行：到行末
int a = 10; // 也可行尾

/*
 * 多行注释
 * 常用于文件头
 */

cout << "Hello";
// cout << " World";
cout << " CSP-J" << endl;
// 输出：Hello CSP-J
⚠️ 多行注释不能嵌套！
/* 外 /* 内 */ 这里已暴露 */ 会编译错误。
  • 注释给人看，编译器忽略
  • 阅读程序时被注释语句不执行
  • 可用注释临时关掉代码调试
  • 提交前清理无用调试输出
demoComments。真题常考输出结果：先划掉注释再算。

九、排查与调试输出

读编译信息

  • error：必须改，否则无法通过
  • warning：能生成但有隐患
  • 行号指“发现不对的位置”，漏写点常在上一行

样例对照法

  • 先手算样例 → 再跑程序
  • 不一致则注释后半段、打印中间量
debug_scaffold.cpp
int a = 10, b = 20;
cerr << "[DEBUG] a=" << a
     << " b=" << b << endl;
int sum = a + b;
cerr << "[DEBUG] sum="
     << sum << endl;
cout << sum << endl; // 正式输出
// 提交前删除 cerr 调试行
demoDebugPrint。printf-debug 是入门最实用的调试法。

易错点速查

1. 漏写分号

语句末要 ;。但 #include 与 int main() 后没有分号。

2. main 不规范

勿 void main / Main / 漏 ()。正确：int main() { ... }

3. 中文标点

从网页复制易带入全角引号、分号。必须英文符号。

4. 注释嵌套

/* /* */ */ 非法。

5. 路径 / 未重编译

中文空格路径易炸；改代码后跑的是旧 exe。

6. 缺头文件 / 命名空间

用 cout 必须 iostream + std。字符串 "A" ≠ 字符 'A'。

demoCommonMistakes。课堂可现场制造再修一个错。
