一、最长上升子序列（LIS）

问题描述

给定长度为n的序列，求最长的严格递增子序列的长度。子序列不要求连续，但要保持原始顺序。

例：[3, 1, 4, 1, 5, 9, 2, 6] 的 LIS 长度为 4（如 [1, 4, 5, 9]）

状态定义与转移

状态定义

dp[i] = 以第i个元素结尾的LIS长度

注意：必须是「以a[i]结尾」

转移方程

dp[i] = max(dp[j] + 1)

对所有 j < i 且 a[j] < a[i]

答案位置

ans = max(dp[1..n])

不是dp[n]！

int ans = 0; for (int i = 1; i <= n; i++) { dp[i] = 1; // 自身成序列 for (int j = 1; j < i; j++) if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1); ans = max(ans, dp[i]); }
高频易错：LIS的答案是 max(dp[1..n])，不是 dp[n]！因为最长上升子序列不一定以最后一个元素结尾。

二、最长公共子序列（LCS）

问题描述

给定两个字符串A和B，求它们的最长公共子序列的长度。子序列不要求连续，但顺序必须保持。

状态定义

dp[i][j] 表示 A的前i个字符 与 B的前j个字符 的LCS长度

转移方程（核心，必须背诵）

若 A[i] == B[j]：dp[i][j] = dp[i-1][j-1] + 1

若 A[i] != B[j]：dp[i][j] = max(dp[i-1][j], dp[i][j-1])

完整代码

for (int i = 1; i <= n; i++) { for (int j = 1; j <= m; j++) { if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1; else dp[i][j] = max(dp[i-1][j], dp[i][j-1]); } } cout << dp[n][m]; // 答案在 dp[n][m]

转移方程理解

情况逻辑公式
A[i] == B[j]这对字符可同时选入LCSdp[i-1][j-1] + 1
A[i] != B[j]至少舍弃其中一个字符max(dp[i-1][j], dp[i][j-1])

三、最大子段和（Kadane算法）

问题描述

给定整数序列（可含负数），求连续子段的最大和。

例：[-2, 1, -3, 4, -1, 2, 1, -5, 4] 的最大子段和为 6

DP状态与转移

状态：dp[i] = 以第i个元素结尾的最大子段和

dp[i] = max(dp[i-1] + a[i], a[i])

理解：要么把a[i]接在前面的子段后面，要么a[i]自己独立成段。

空间优化至 O(1)

int maxSubArray(vector<int>& a) { int cur = 0, ans = INT_MIN; for (int x : a) { cur = max(cur + x, x); // 当前位置结尾的最大和 ans = max(ans, cur); // 更新全局最大值 } return ans; }
高频易错：ans 必须初始化为 INT_MIN（而非0），因为数组可能全为负数。如果全是负数，最大子段和应是最大的那个负数，而不是表示空子段的0。

变种扩展

  • 环形数组最大子段和：max(普通最大子段和, 总和 - 最小子段和)
  • 长度至少为k的最大子段和：前缀和 + 滑动窗口

四、编辑距离入门

问题描述

将一个字符串转换为另一个字符串所需的最少操作次数。操作包括：插入、删除、替换。

例："kitten" → "sitting" 编辑距离为 3

状态定义

dp[i][j] = 将A的前i个字符转换为B的前j个字符的最少操作数

转移方程

若 A[i] == B[j]：dp[i][j] = dp[i-1][j-1]

若 A[i] != B[j]：dp[i][j] = min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]) + 1

三种操作对应：

  • dp[i-1][j-1] + 1 → 替换 A[i] 为 B[j]
  • dp[i-1][j] + 1 → 删除 A[i]
  • dp[i][j-1] + 1 → 在A的i位置后插入 B[j]
// 边界初始化 for (int i = 0; i <= n; i++) dp[i][0] = i; // 删除i个 for (int j = 0; j <= m; j++) dp[0][j] = j; // 插入j个 for (int i = 1; i <= n; i++) { for (int j = 1; j <= m; j++) { if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1]; else dp[i][j] = min({dp[i-1][j-1], dp[i-1][j], dp[i][j-1]}) + 1; } }
与LCS的对比：编辑距离和LCS有相同的二维dp结构，都依赖左、上、左上三个方向。CSP-J阶段重点是LCS，编辑距离作为拓展了解即可。

五、核心代码模板汇总

模板1：LIS O(n²)

int ans = 0; for (int i = 1; i <= n; i++) { dp[i] = 1; for (int j = 1; j < i; j++) if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1); ans = max(ans, dp[i]); }

模板2：LCS O(n*m)

for (int i = 1; i <= n; i++) for (int j = 1; j <= m; j++) if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1; else dp[i][j] = max(dp[i-1][j], dp[i][j-1]); // 答案: dp[n][m]

模板3：Kadane O(n)

int cur = 0, ans = INT_MIN; for (int x : a) { cur = max(cur + x, x); ans = max(ans, cur); }
考试建议：这三个模板是CSP-J线性DP的「三板斧」，必须能熟练默写。考场上看到序列型问题，优先匹配这三个模型。

六、真题精讲

真题1：最长上升子序列

给定N（1≤N≤5000）个整数，求最长严格上升子序列长度。

#include <bits/stdc++.h> using namespace std; const int MAXN = 5005; int a[MAXN], dp[MAXN]; int main() { int n; cin >> n; for (int i = 1; i <= n; i++) cin >> a[i]; int ans = 0; for (int i = 1; i <= n; i++) { dp[i] = 1; for (int j = 1; j < i; j++) if (a[j] < a[i] && dp[j] + 1 > dp[i]) dp[i] = dp[j] + 1; ans = max(ans, dp[i]); } cout << ans << '\n'; return 0; }

真题2：最大子段和

给定整数序列（可含负数），求连续子段的最大和。

int cur = 0, ans = INT_MIN; for (int i = 0; i < n; i++) { int x; cin >> x; cur = max(cur + x, x); ans = max(ans, cur); } cout << ans << '\n';
注意：如果题目要求子段长度至少为1（不允许空子段），ans必须初始化为INT_MIN。如果允许空子段（和为0），则ans初始化为0。

本课总结

LIS（最长上升子序列）

dp[i] = 以a[i]结尾的LIS长度
O(n²)：扫描前面所有j
答案：max(dp[1..n])

LCS（最长公共子序列）

dp[i][j] = A前i个与B前j个的LCS
相等：dp[i-1][j-1]+1
不等：max(上方, 左方)
答案：dp[n][m]

Kadane（最大子段和）

cur = max(cur+x, x)
O(n)时间，O(1)空间
ans初始化为INT_MIN
可扩展到环形数组

编辑距离

dp[i][j] = 最小操作数
三种操作取min
与LCS结构类似
作为拓展了解

算法 状态维度 时间复杂度 答案位置 CSP-J考频
LIS 一维 O(n²) max(dp[1..n]) ★★★
LCS 二维 O(n*m) dp[n][m] ★★★
最大子段和 一维（可O(1)空间） O(n) max(dp[1..n]) ★★★
编辑距离 二维 O(n*m) dp[n][m] ★☆☆
