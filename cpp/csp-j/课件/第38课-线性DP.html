【开场】1/14 线性 DP：状态沿序列一维推进。

什么是线性 DP

状态沿序列「线性」推进：dp[i] 表示以 i 结尾或考虑前 i 个元素的最优值；dp[i] 依赖 j<i。

类型状态例题
一维dp[i]LIS、最大子段和
二维dp[i][j]LCS、编辑距离
共性：序列/字符串 + 最优子序列/子串属性。答案位置要仔细：LIS 不是 dp[n]！
【讲解】线性定义

一、LIS — 最长上升子序列

严格递增子序列（可不连续）。例：[3,1,4,1,5,9,2,6] 长度 4。

  • 状态：dp[i] = 以 a[i] 结尾的 LIS 长度
  • 转移：dp[i] = max(dp[j]+1)（j<i 且 a[j]<a[i]），否则 1
  • 答案：max(dp[1..n])
  • 复杂度：O(n²)（CSP-J 够用；O(n log n) 了解即可）
【讲解】「以 i 结尾」是独立性关键。

LIS 代码模板

for (int i = 1; i <= n; i++) { dp[i] = 1; for (int j = 1; j < i; j++) if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1); ans = max(ans, dp[i]); }
非严格上升把 < 改成 <=。求方案用 pre[i] 记前驱，从 best 回溯再 reverse。
【讲解】对照 lesson38 LIS。

LIS 输出序列

if (a[j] < a[i] && dp[j] + 1 > dp[i]) { dp[i] = dp[j] + 1; pre[i] = j; } // 找 best 后： while (best) { seq.push_back(a[best]); best = pre[best]; } reverse(seq.begin(), seq.end());
【讲解】回溯输出

二、LCS — 最长公共子序列

A="ABCBDAB", B="BDCABA" → LCS 长度 4（如 BCBA）。

  • 状态：dp[i][j] = A 前 i 与 B 前 j 的 LCS 长度
  • A[i]==B[j]：dp[i][j] = dp[i-1][j-1]+1
  • 否则：dp[i][j] = max(dp[i-1][j], dp[i][j-1])
  • 边界 dp[0][*]=dp[*][0]=0；答案 dp[n][m]
【讲解】分两种情况讨论。

LCS 模板

a = " " + a; b = " " + b; // 1-based for (int i = 1; i <= n; i++) for (int j = 1; j <= m; j++) { if (a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1; else dp[i][j] = max(dp[i-1][j], dp[i][j-1]); } cout << dp[n][m];
n,m≤1000 开二维即可；更大可滚动数组两行。子序列 ≠ 子串（子串要连续）。
【讲解】LCS vs 子串

三、最大子段和（Kadane）

连续子数组最大和。例：[-2,1,-3,4,-1,2,1,-5,4] → 6。

  • dp[i] = 以 i 结尾的最大子段和
  • dp[i] = max(dp[i-1]+a[i], a[i])
  • 答案 max(dp[*])；可压成两个变量 O(1) 空间
int cur = 0, ans = INT_MIN; for (int x : nums) { cur = max(cur + x, x); ans = max(ans, cur); }
【讲解】Kadane 前面为负则重启。

最大子段和变种

  • 不连续最大和：所有正数之和（全负则最大负数）
  • 环形：max(普通最大子段, 总和−最小子段)；全负特判
  • 长度≥k：前缀和 + 维护窗口最小前缀
ans 初始化 INT_MIN，勿写成 0（全负数组会错）。
【讲解】变种

四、编辑距离入门

最少插入/删除/替换次数把 A 变成 B。kitten → sitting = 3。

  • dp[i][j] = A 前 i → B 前 j 最少操作
  • 相等：dp[i-1][j-1]；否则 min(替换,删除,插入)+1
  • 边界：dp[i][0]=i，dp[0][j]=j
if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1]; else dp[i][j] = min({dp[i-1][j-1], dp[i-1][j], dp[i][j-1]}) + 1;
【讲解】与 LCS 同为二维串 DP 模型。

线性 DP 解题套路

模式状态直觉转移特点
LIS以 i 结尾扫所有 j<i
LCS两前缀相等/不等分支
Kadane以 i 结尾连续接上 or 重启
编辑距离两前缀三种操作 min
先判定「连续？单序列还是双序列？求长还是求和？」再套模型。

真题精练

① 合唱队形 / 导弹拦截

本质 LIS 或最长不升。O(n²) 双方向或单方向。

② 公共子序列

两串 LCS 长度。注意下标从 1 与边界 0。

③ 最大子段和

经典 Kadane；注意全负数。

【讲解】真题

易错点

  • LIS 答案写成 dp[n] 而非 max
  • 严格/非严格比较符用错
  • LCS 与最长公共子串混淆（子串连续，转移不同）
  • Kadane 初始化 0 导致全负 WA
  • 编辑距离边界未设 i/j
  • 字符串下标 0/1 混用
【讲解】易错

本课小结

  • 线性 DP：沿序列递推，注意答案位置。
  • LIS：O(n²)，以 i 结尾；可回溯序列。
  • LCS：二维，相等 +1，不等取 max 舍弃一边。
  • 最大子段和：Kadane O(n)。
  • 编辑距离：三种操作取 min，巩固二维 DP。
