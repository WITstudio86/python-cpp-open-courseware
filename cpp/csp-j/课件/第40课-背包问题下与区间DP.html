二、多重背包 — 问题与朴素做法

问题描述

有 N 种物品，容量 W。第 i 种物品重量 w[i]，价值 v[i]，数量上限 c[i]。每种物品最多选 c[i] 次。求最大价值。

朴素做法：三重循环

for (int i = 1; i <= N; i++) { for (int j = W; j >= 0; j--) { for (int k = 0; k <= c[i] && k * w[i] <= j; k++) { dp[j] = max(dp[j], dp[j - k * w[i]] + k * v[i]); } } }

复杂度分析

时间复杂度：O(N × W × max(c[i]))

当 c[i] 较大时（如 c[i] = 10000），总计算量可达 10⁸ ~ 10⁹，必然超时！

问题：能否把多重背包转化为我们熟悉的01背包，同时不增加太多物品数？答案是——二进制优化！

三、多重背包 — 二进制优化（核心重点）

核心思想

将 c[i] 个相同物品按 1, 2, 4, 8, ... 的二进制方式打包，使得这些"打包物品"能组合出 0 ~ c[i] 之间的任意数量。

拆分示例

原始数量 c拆分为可组合范围打包物品数
71 + 2 + 40 ~ 73 个
131 + 2 + 4 + 60 ~ 134 个
10001+2+4+...+256+4890 ~ 1000约 10 个

拆分代码模板

for (int k = 1; k <= c; k <<= 1) { // k = 1,2,4,8,... new_w[++cnt] = k * w; // 打包k个物品 new_v[cnt] = k * v; c -= k; } if (c > 0) { // 剩余部分（不够2^k） new_w[++cnt] = c * w; new_v[cnt] = c * v; }

复杂度对比

朴素：O(N × W × c[i]) → 二进制优化：O(W × N × log c[i])

c[i]=1000：1000次循环 → 10次循环！效率提升 100倍！

拆分后的"打包物品"每个最多选一次 → 完美转化为01背包！后面直接套用01背包倒序遍历即可。

四、分组背包 — 每组最多选一个

问题描述

有 G 组物品，每组内有若干物品。从每组中最多选一个物品放入背包。求最大价值。

核心约束：同一组内的物品互斥 — 选了A就不能选B。

标准代码（三层循环）

for (int g = 1; g <= G; g++) { // 第一层：枚举组 for (int j = W; j >= 0; j--) { // 第二层：枚举容量（倒序） for (int k = 0; k < group[g].size(); k++) { // 第三层：组内物品 if (j >= w) dp[j] = max(dp[j], dp[j - w] + v); } } }

为什么容量循环必须在外面？

如果物品循环在外面（对于每个物品遍历容量），同组内的多个物品可能在同一轮DP中被选中 — dp[j-w1]更新后，处理物品2时可能用到已包含物品1的信息。

容量循环在外面意味着：对于每个容量 j，在所有物品中只选出最优的那一个来更新 — 恰好实现"每组最多选一个"！

分组容量外

五、分组背包 — 正确 vs 错误对比

示例数据：2组，容量10

第1组：A(3kg, 5元), B(4kg, 6元) | 第2组：C(2kg, 3元), D(5kg, 8元)

理论最大值：选B+D = 9kg, 14元

写法循环顺序结果判断
正确 组 → 容量（倒序） → 物品 14 ✓ 每组最多1个
错误 组 → 物品 → 容量（正序） 19 ✗ 同组多选！

错误写法的后果

物品外循环 + 正序容量 → 变成完全背包 → 同组的A和B都被选中，得到(3+4=7kg, 5+6=11元)，再加上C或D，结果远超正确值。

分组背包最常见错误：把循环写成 组 → 物品 → 容量。这会导致同一组内多个物品被选中，违反核心约束！必须记住：容量在物品外面。

六、区间DP — 从线段到区间

什么是区间DP？

定义 dp[i][j] = 区间 [i, j] 范围内的最优解。通过枚举分割点 k，将大区间分解为两个小区间，先子问题再合并。

通用框架（三层循环）

// 1. 初始化：长度为1的区间 for (int i = 1; i <= N; i++) dp[i][i] = 初始值; // 2. 枚举区间长度（从小到大，必须最外层！） for (int len = 2; len <= N; len++) { for (int i = 1; i + len - 1 <= N; i++) { int j = i + len - 1; // 区间终点 // 3. 枚举分割点，将[i,j]分为[i,k]和[k+1,j] for (int k = i; k < j; k++) { dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + 合并代价); } } }

为什么 len 必须在最外层？

长区间的计算依赖于短区间。当 len=x 时，所有长度小于 x 的区间都已计算完毕。dp[i][k] 和 dp[k+1][j] 的长度都严格小于 len，保证子问题已求解。

七、石子合并 — 区间DP经典模板

问题描述

N 堆石子排成一排，第 i 堆有 a[i] 个。每次合并相邻两堆，代价为两堆石子数之和。求合并成一堆的最小总代价。

状态定义与转移

dp[i][j] = 将区间 [i, j] 合并为一堆的最小代价

dp[i][j] = min{ dp[i][k] + dp[k+1][j] } + (a[i] + ... + a[j])

AC代码（含前缀和优化）

#include <iostream> #include <cstring> using namespace std; const int N = 305, INF = 0x3f3f3f3f; int a[N], pre[N], dp[N][N]; int main() { int n; cin >> n; for (int i = 1; i <= n; i++) { cin >> a[i]; pre[i] = pre[i-1] + a[i]; } memset(dp, 0x3f, sizeof(dp)); for (int i = 1; i <= n; i++) dp[i][i] = 0; for (int len = 2; len <= n; len++) for (int i = 1; i + len - 1 <= n; i++) { int j = i + len - 1; for (int k = i; k < j; k++) dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + pre[j] - pre[i-1]); } cout << dp[1][n]; }
常见错误：忘记初始化 dp[i][i] = 0！长度为1的区间不需要合并，代价为0。若初始化为INF，整个DP结果都会出错。

八、真题1：庆功会（多重背包模板）

题目描述

N 种奖品，每种有价格 w[i]、价值 v[i] 和数量上限 c[i]。预算 W 元，求最大总价值。

1 ≤ N ≤ 100, 1 ≤ W ≤ 6000, 1 ≤ c[i] ≤ 10

样例

输入：5 1000，5种奖品，预算1000
奖品1：80元 20价值 ×4 | 奖品2：40元 50价值 ×9
奖品3：30元 50价值 ×7 | 奖品4：40元 30价值 ×6
奖品5：20元 20价值 ×1

输出：1040

AC代码（二进制优化）

#include <iostream> #include <algorithm> using namespace std; const int MAXW = 6005; int dp[MAXW], w[2005], v[2005]; int main() { int N, W, cnt = 0; cin >> N >> W; for (int i = 1; i <= N; i++) { int wt, val, c; cin >> wt >> val >> c; for (int k = 1; k <= c; k <<= 1) { w[++cnt] = k * wt; v[cnt] = k * val; c -= k; } if (c > 0) { w[++cnt] = c * wt; v[cnt] = c * val; } } for (int i = 1; i <= cnt; i++) for (int j = W; j >= w[i]; j--) // 倒序01背包 dp[j] = max(dp[j], dp[j - w[i]] + v[i]); cout << dp[W]; }
二进制拆分 → 01背包，两步走，思路清晰。即使c[i]只有10，形成好习惯总是好的，比赛时遇到c[i]=10⁵也不怕。

九、真题2：石子合并（区间DP模板）

题目描述

N 堆石子排成一排，第 i 堆 a[i] 个。每次合并相邻两堆，代价为两堆石子数之和。求最小总代价。

1 ≤ N ≤ 300, 1 ≤ a[i] ≤ 1000

样例

输入：4（4堆）
石子：1 3 5 2

输出：22

样例分析

最优合并顺序：

(1, 3) → 4，代价 4
(5, 2) → 7，代价 7
(4, 7) → 11，代价 11
总代价 = 4 + 7 + 11 = 22

复杂度

O(N³)：N=300 → 约 4.5 × 10⁶ 次运算，现代计算机可轻松秒过。

前缀和 sum(i,j) = pre[j] - pre[i-1] → O(1) 查询区间和。

注意：dp[i][i] 必须初始化为 0！区间DP的memset(0x3f) 和 dp[i][i]=0 缺一不可。

十、易错点汇总

三大常见错误

错误1：多重背包二进制拆分不完整

拆分循环结束后，如果还有剩余数量 c > 0，必须单独作为一个打包物品加入。例如 c=13 拆分为 1+2+4 后还剩 6，必须把 6 也加入。

错误2：分组背包循环顺序写反

正确错误
组 → 容量 → 物品 组 → 物品 → 容量

写成错误顺序会导致同一组内多个物品被选中，违反"每组最多选一个"。

错误3：区间DP初始化不当

求最小值要用 memset(dp, 0x3f) 初始化为 INF，然后 dp[i][i] = 0。长度最外层循环不能乱！

多重二进制拆，分组容量外。区间先长度，石子并着走。
