一、多重背包

第 i 种：重量 w、价值 v、数量上限 c。介于 01 与完全之间。

// 朴素：枚举取 k 个，倒序容量 for (int i = 1; i <= N; i++) for (int j = W; j >= 0; j--) for (int k = 0; k <= c[i] && k*w[i] <= j; k++) dp[j] = max(dp[j], dp[j - k*w[i]] + k*v[i]);
复杂度 O(N·W·max c)，c 大易超时 → 需要二进制优化。
【讲解】朴素多重

二进制优化思想

把 c 个相同物品拆成 1,2,4,… 与剩余，使得能组合出 0..c 任意个数，再当 01 背包做。

  • 7 = 1+2+4（3 个打包）
  • 13 = 1+2+4+6（剩余 6）
  • 物品数从 O(c) 降到 O(log c)
多重二进制拆，拆完当 01 做
【讲解】二进制拆分原理

二进制拆分代码

int cnt = 0; for (int i = 1; i <= N; i++) { int w, v, c; cin >> w >> v >> c; for (int k = 1; k <= c; k <<= 1) { new_w[++cnt] = k * w; new_v[cnt] = k * v; c -= k; } if (c > 0) { new_w[++cnt] = c * w; new_v[cnt] = c * v; } } // 再对 cnt 个物品做 01 倒序背包
【讲解】对照 lesson40 multiple_knapsack_binary。

拆分后 01 求解

for (int i = 1; i <= cnt; i++) for (int j = W; j >= new_w[i]; j--) dp[j] = max(dp[j], dp[j - new_w[i]] + new_v[i]);
  • 总复杂度约 O(W · Σ log c[i])
  • 数组要开够 N*log(max_c) 量级
  • c=0 的物品跳过
【讲解】拆完就是第39课 01。

二、分组背包

G 组，每组最多选一个物品。组内互斥。

for (int g = 1; g <= G; g++) { // 组 for (int j = W; j >= 0; j--) { // 容量倒序在中 for (int k = 0; k < sz[g]; k++) { // 组内物品 int ww = group[g][k].w, vv = group[g][k].v; if (j >= ww) dp[j] = max(dp[j], dp[j-ww] + vv); } } }
循环顺序关键：容量必须在组内物品外面。若物品在外，同组可能被选多个。
【讲解】分组 三层顺序是考试易错点。

分组背包理解

  • 对每个容量 j，在组内物品中选最优一个（或不选）
  • 倒序保证 01 语义（每件至多一次）
  • 类比：每组是一个「互斥选项集合」
错误顺序后果
组 → 物品 → 倒序容量同组多选（像多个 01 叠加）
组 → 倒序容量 → 组内正确
【讲解】对比实验见 lesson40。

三、区间 DP 基础

dp[i][j] = 区间 [i,j] 的最优解。枚举分割点 k，合并 [i,k] 与 [k+1,j]。

for (int len = 2; len <= N; len++) for (int i = 1; i + len - 1 <= N; i++) { int j = i + len - 1; dp[i][j] = INF; for (int k = i; k < j; k++) dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i,j)); }
顺序：len 必须最外（短区间先算）。识别：合并相邻段、答案常在 dp[1][N]。
【讲解】区间框架

为何 len → i → k

  • 计算 len 时，子区间长度 < len 已完成
  • i 为起点，j=i+len-1 为终点
  • k 为最后一次合并的分界
区间 DP 复杂度常 O(N³)。N≤300 可行（约 10⁷ 量级可过）。
【讲解】依赖关系

四、石子合并

N 堆排成一排，只能合并相邻两堆，代价为两堆之和，求最小总代价。

  • dp[i][j] = 合并 [i,j] 成一堆的最小代价
  • dp[i][j] = min_k (dp[i][k]+dp[k+1][j]) + sum(i..j)
  • dp[i][i]=0；sum 用前缀和 O(1)
与「合并果子」不同：相邻约束 → 不能用堆贪心！
【讲解】石子合并 Hello World。

石子合并完整模板

for (int i = 1; i <= N; i++) pre[i] = pre[i-1] + a[i]; memset(dp, 0x3f, sizeof(dp)); for (int i = 1; i <= N; i++) dp[i][i] = 0; for (int len = 2; len <= N; len++) for (int i = 1; i + len - 1 <= N; i++) { int j = i + len - 1; for (int k = i; k < j; k++) dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + pre[j] - pre[i-1]); } cout << dp[1][N];
【讲解】模板默写。最大代价改 min→max 即可。

真题精练

① 多重背包（有数量限制）

二进制拆分 + 01。注意 cnt 上界与 long long 价值。

② 分组背包 / 依赖选一

严格三层循环顺序。

③ 石子合并

区间 DP + 前缀和；勿套合并果子堆。

【讲解】真题

易错点

  • 多重：拆分后忘记 01 倒序；数组开小
  • 分组：容量与组内循环顺序反了
  • 区间：len 不在最外；忘记 dp[i][i]=0
  • sum 每次暴力累加 → 变 O(N⁴)
  • 合并果子模板误用于相邻合并题
  • INF 初始化不够大或未初始化
【讲解】易错
