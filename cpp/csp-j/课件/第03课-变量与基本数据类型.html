一、什么是变量 · 二、类型总览

变量 = 命名的内存盒子：名字 + 类型 + 值。先声明再使用，推荐声明时初始化。

var_intro.cpp
int score = 98;
double pi = 3.14159;
char grade = 'A';
bool passed = true;
int x = 10;
x = x + 5;   // 读再写 → 15
类型字节用途
int4普通整数 · 约 ±21 亿
long long8大整数 · 约 ±9e18
float4约 7 位有效数字（少用）
double8小数首选 · 约 15~16 位
char1单字符 / ASCII
bool1true / false
口诀：整数 int，超 21 亿 long long；实数 double；字符 char；真假 bool。

三、整型：int 与 long long

  • int：约 -2147483648 ~ 2147483647
  • long long：约 ±9.2×10¹⁸；字面量加 LL
  • 看最终答案不够，还要看中间结果
  • 口诀：两个 int 一相乘，先升 long long
场景建议
n≤1e5 简单加减int 常够
两数相乘 / 累加和long long
|aᵢ|≤1e9 且要 a×blong long
不确定会不会爆优先 long long
ll_mul.cpp
int a = 100000, b = 100000;
// 错：先 int 乘再赋，已溢出
// long long c = a * b;

long long c1 = 1LL * a * b;
long long c2 = (long long)a * b;
long long big = 14000000000LL;
demo02_integer_types；INT_MAX / LLONG_MAX。

四、浮点型：float 与 double

  • 竞赛优先 double，几乎不用 float
  • 0.1 等小数二进制往往无法精确表示
  • 不要直接 == 比较浮点
  • 整数除法 vs 浮点除法：操作数类型决定结果
div.cpp
cout << 5 / 2;          // 2
cout << 5.0 / 2;        // 2.5
cout << (double)5 / 2;  // 2.5
eps.cpp
#include <cmath>
const double EPS = 1e-9;
double x = 0.1 + 0.2;
// if (x == 0.3) 危险
if (fabs(x - 0.3) < EPS) {
  /* 认为相等 */
}
demo03_floating。容差 1e-6 / 1e-8 / 1e-9 看题意。

五、字符型 char

  • 单引号 'A' 是字符；双引号 "A" 是字符串
  • 参与运算时提升为 int（ASCII）
  • 锚点：'0'=48，'A'=65，'a'=97
表达式含义
'9' - '0'数值 9
7 + '0'字符 '7'
'B' - 'A'1（序号）
ch-'a'+'A'小写→大写
char_ops.cpp
char ch = 'A';
cout << ch;            // A
cout << (int)ch;       // 65
cout << 'A' + 1;       // 66 陷阱!
cout << (char)('A'+1); // B
int v = '7' - '0';     // 7
demo04_char_ascii。输出字符必须 (char) 转换。

六、布尔型 bool

  • true / false；cout 常输出 1 / 0
  • 非 0 → true，0 → false
  • 算术中 true≈1，false≈0
  • 适合标记：found、ok、pass
bool_demo.cpp
bool ok = true, fail = false;
cout << ok << " " << fail; // 1 0
bool b = 5;     // true
int x = true;   // 1
int score = 60;
bool pass = (score >= 60);
if (pass) cout << "Yes\n";
demo05_bool。

七、sizeof 运算符

sizeof_demo.cpp
#include <iostream>
using namespace std;
int main() {
    cout << sizeof(int) << endl;         // 常见 4
    cout << sizeof(long long) << endl;  // 常见 8
    cout << sizeof(double) << endl;      // 常见 8
    cout << sizeof(char) << endl;        // 恒为 1（标准保证）
    int arr[10];
    cout << sizeof(arr) / sizeof(arr[0]); // 10
    return 0;
}
📌 sizeof 在编译期确定类型/变量占用；数组作函数参数退化为指针后，sizeof 不再是数组长度。
demo01_sizeof。考试：sizeof(char)≡1；sizeof(int)常见 4 但标准不强制“全世界永远 4”。

八、变量命名规则

必须遵守

  1. 只能字母、数字、下划线
  2. 不能以数字开头
  3. 不能是关键字（int、if、return、sizeof…）
  4. 区分大小写：age ≠ Age

习惯：见名知意；常量 MAX_N；循环 i,j,k。

标识符合法？
myVar / _count✔
total_score / MAX_N✔
2ndPlace✗ 数字开头
float✗ 关键字
my-name✗ 含 -
student count✗ 空格

九、const · 十、声明与初始化

const_init.cpp
const int MAXN = 1000000;
const double PI = 3.141592653589793;
const int MOD = 1000000007;
// MAXN = 20; // 编译错误

int a = 10;      // 拷贝初始化
int b(20);       // 直接初始化
int c{30};       // 列表初始化
int sum = 0;    // 累加器必须 0
int x;          // 局部：垃圾值！
  • const：只读，有类型，优于随意 #define
  • 局部变量未初始化 → 不确定（垃圾）
  • 全局/静态默认 0
  • 铁律：计数器、累加器、标记务必赋初值
  • 注意：int* p, q; 中 q 不是指针
⚠️ 局部变量使用前必须初始化！
数组大小、取模、EPS 用 const 放在程序前部。

十一、整数溢出（重点）

超出表示范围：常见补码下“绕回”。如 INT_MAX+1 → INT_MIN。

  • 相乘：两 int 先乘再赋 long long 无效
  • 累加：n=1e5、aᵢ=1e9 → sum 用 long long
  • 公式：n*(n+1)/2 中 n 要先是 long long
overflow_safe.cpp
int x = 100000, y = 100000;
long long z1 = x * y;       // 错
long long z2 = 1LL * x * y; // 对

int n = 100000;
long long s = 1LL * n * (n + 1) / 2;

long long sum = 0;
// for (...) sum += a[i];
💡 预防：读题估算 n·a、a·b、n²；答案与和直接开 long long；乘法前 1LL *。
真题 3 直接考 INT_MAX+1 与 z1/z2 对比。

十二、类型转换初步

隐式

  • int → double 安全拓宽
  • 3.9 → int 截断得 3（非四舍五入）
  • 非 0 → bool true；65 → char 'A'

注意

  • 大整数勿用 double 硬存再转回
  • 显式：(double)a 或 static_cast<double>(a)
cast.cpp
int a = 5, b = 2;
double r = (double)a / b; // 2.5
char next = (char)('a' + 1);

double avg =
  (chinese + math + eng) / 3.0;
// 综合：int/char/bool/double/const

    int n = 0; long long sum = 0; double ans = 0.0;

易错点速查

1. int 乘法溢出

用 1LL * a * b 或强制转换其中一个。

2. 局部未初始化

int sum; 再累加 → 垃圾。写 sum = 0。

3. 整数除法当小数

double avg = a/b; 先得整数。写 (double)a/b。

4. char 输出陷阱

'A'+1 打印 66；要 (char)('A'+1)。

5. 浮点 ==

用 fabs(x-y)<EPS。

6. 非法名 / 忘 LL / float

数字开头、关键字、-；超 int 字面量加 LL；高精度用 double。

八大易错对照讲义；课堂改错。

本课小结

六种类型

int / long long / float / double / char / bool；常见 4/8/4/8/1/1 字节。

选型

普通 int；中间结果大用 long long；小数 double；字符 ASCII 运算。

命名 · sizeof · const

标识符三铁律；sizeof 求字节；const 只读常量。

初始化 · 溢出

局部必初值；1LL*a*b 防爆；注意整除与 char 输出陷阱。

选对类型是避免 bug 的第一步！超 21 亿用 long long，实数用 double。
