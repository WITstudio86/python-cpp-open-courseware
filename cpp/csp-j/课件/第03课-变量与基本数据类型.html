六种基本数据类型详解

数据类型关键字字节数取值范围典型用途
整型int4 -2,147,483,648 ~ 2,147,483,647
（约 ±21亿）		 计数、数组下标、循环变量
长整型long long8 约 -9×10¹⁸ ~ 9×10¹⁸ 大整数运算、阶乘、累计和
单精度浮点float4 约 6~7 位有效数字 精度要求不高的实数（不推荐）
双精度浮点double8 约 15~16 位有效数字 实数运算首选（CSP-J 推荐）
字符型char1 -128 ~ 127 或 0 ~ 255 存储单个字符、ASCII 操作
布尔型bool1 true (1) 或 false (0) 条件判断、标志位

关键记忆口诀

整数优先 int，超过 21 亿用 long long；实数一律用 double（别用 float）；字符用 char，真假用 bool。

sizeof 运算符与变量命名规则

sizeof 运算符

sizeof_demo.cpp 
#include <iostream>
using namespace std;
int main() {
    cout << "int: " << sizeof(int) << endl;
    cout << "long long: " << sizeof(long long) << endl;
    cout << "double: " << sizeof(double) << endl;
    cout << "char: " << sizeof(char) << endl;
    cout << "bool: " << sizeof(bool) << endl;
    return 0;
}

典型输出: 4, 8, 8, 1, 1 （字节数）

变量命名规则

  • 由字母、数字、下划线组成
  • 不能以数字开头
  • 不能是 C++ 关键字（如 int、if、return）
  • 区分大小写（Name 和 name 是不同的）

命名示例

✅ 合法：score、max_value、_count、num2

❌ 非法：2abc（数字开头）、my-var（含短横线）、int（关键字）

const 常量与变量初始化

const 常量

使用 const 关键字定义不可修改的变量：

const_demo.cpp 
const int MAXN = 100000;
const double PI = 3.1415926;
const char CH = 'A';

// MAXN = 200;  // ❌ 编译错误!
// const 变量不可修改
  • 防止意外修改，增强代码安全性
  • 编译器可做优化（常量折叠）
  • CSP-J 中数组大小推荐用 const 定义

变量初始化

init_demo.cpp 
// 1. 拷贝初始化
int a = 10;

// 2. 直接初始化
int b(20);

// 3. 列表初始化 (C++11)
int c{30};
int d = {40};

// ⚠️ 局部变量不初始化
int x;  // 值是随机的!
⚠️重要：局部变量必须初始化后再使用！未初始化的局部变量值是随机的（不确定的），可能导致程序出现离奇的 bug。

代码模板 — 数据类型选择与溢出预防

💡考试技巧：浮点数优先用 double，整数超出 21 亿用 long long。局部变量必须初始化，否则值是随机的！
data_type_practice.cpp 
#include <iostream>
using namespace std;

const int MAXN = 100005;        // 数组大小用 const

int main() {
    int n = 0;                    // 普通计数：int 足够
    long long sum = 0;            // 累计和：用 long long
    double avg = 0.0;              // 平均数：用 double
    char ch = ' ';                  // 字符型
    bool flag = false;             // 布尔型

    // sizeof 检查在当前环境的实际大小
    cout << sizeof(sum) << endl;  // 8 (64位环境)

    // 溢出预防：大数相乘前先转为 long long
    int a = 100000, b = 100000;
    long long c = 1LL * a * b;  // 1LL 强制提升类型

    return 0;
}

要点：1LL * a * b 利用 long long 字面量将整个乘法表达式提升为 long long，是防止整数溢出的标准技巧。

真题精练

例题 1 · 数据类型范围
在 C++ 中，int 类型变量的取值范围大约是？
A. -10⁴ ~ 10⁴
B. -2×10⁹ ~ 2×10⁹
C. -10¹⁸ ~ 10¹⁸
D. 0 ~ 4×10⁹
✅ 答案：B。int 占 4 字节（32 位），有符号范围约为 -2.1×10⁹ ~ 2.1×10⁹，即约 ±21 亿。A 对应 short，C 对应 long long，D 对应 unsigned int。
例题 2 · 变量命名合法性
以下哪一个不是合法的 C++ 变量名？
A. _abc
B. a_b
C. 2abc
D. Abc
✅ 答案：C。变量名不能以数字开头。_abc（下划线开头）、a_b（字母+下划线）、Abc（大写字母开头）都是合法的。
例题 3 · sizeof 判断
在大多数 64 位 C++ 环境中，sizeof(long long) 的值是？
A. 2 B. 4 C. 8 D. 16
✅ 答案：C。long long 在 C++ 标准中保证至少 64 位（8 字节），绝大多数平台实现为 8 字节。

本课小结

六种基本数据类型

int（±21亿）、long long（大整数）、float（不推荐）、double（实数首选）、char（字符）、bool（真假）。

sizeof 与命名规则

sizeof(类型) 返回字节数；变量名由字母、数字、下划线组成，不能以数字开头，不能是关键字。

const 常量

const 定义不可修改的常量，增强安全性。CSP-J 中数组大小推荐用 const int 定义。

初始化与溢出

局部变量必须初始化；大数运算使用 1LL * a * b 防止 int 溢出。

选对数据类型是避免 bug 的第一步！超 21 亿用 long long，实数用 double。
