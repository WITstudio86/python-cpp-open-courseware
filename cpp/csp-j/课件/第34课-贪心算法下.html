二、合并果子 · 哈夫曼编码思想

📌 问题：n 堆果子，每次合并任意两堆，代价 = 两堆数量之和。求合并成一堆的最小总代价。

贪心策略：每次合并最小的两堆

// 合并果子核心代码 —— 使用小根堆 priority_queue<int, vector<int>, greater<int>> pq; // 将所有果子推入堆中 for (int i = 0; i < n; i++) { int x; cin >> x; pq.push(x); } long long totalCost = 0; while (pq.size() > 1) { int a = pq.top(); pq.pop(); // 最小的 int b = pq.top(); pq.pop(); // 第二小的 int sum = a + b; totalCost += sum; pq.push(sum); // 合并后的新堆放回 } cout << totalCost << endl;
⚠️ 重要区分：合并果子（贪心）≠ 石子合并（区间 DP）
— 合并果子：可任意选择两堆合并，用贪心 → O(n log n)
— 石子合并：只能合并相邻的两堆，必须用区间 DP → O(n³)
读题时务必看清楚是否有"相邻"约束！
🎯 考试技巧：小根堆的声明是 priority_queue<int, vector<int>, greater<int>>。默认是大根堆！如果忘记语法，可以 push 时取负数来模拟小根堆。

三、删数问题 · 最优装载

删数问题：删除 k 位数字使剩余数字最小

贪心策略：删除第一个 "山峰"（num[i] > num[i+1] 的位置），重复 k 次。可用单调栈优化到 O(n)。

// 删数问题 —— 单调栈优化版 string removeKdigits(string num, int k) { string stk; // 用 string 模拟单调栈 for (char c : num) { while (!stk.empty() && stk.back() > c && k > 0) { stk.pop_back(); // 删除"山峰" k--; } stk.push_back(c); } while (k-- > 0) stk.pop_back(); // 剩余删除名额 // 去除前导零 int s = 0; while (s < stk.size() && stk[s] == '0') s++; return (s == stk.size()) ? "0" : stk.substr(s); }

最优装载：载重 C 下最多能装多少个物品

贪心策略：按重量从小到大排序，依次装入直到超重。这是最简单的贪心问题——所有物品"价值"相同（都是1个），重量越轻性价比越高。

// 最优装载 sort(w, w + n); // 按重量升序 int cnt = 0; long long sum = 0; // 注意 long long！ for (int i = 0; i < n; i++) { if (sum + w[i] <= C) { sum += w[i]; cnt++; } else break; // 后面的更重 }

四、贪心 vs DP：如何选择？

对比维度贪心算法动态规划
决策方式每步选当前最优，不回溯考虑所有子问题的最优解
正确性需额外证明数学上保证最优
时间复杂度O(n log n) 或 O(n)O(n²) 到 O(n³)
典型例题合并果子、最优装载、删数01背包、LIS、石子合并

五、真题精练

📝 题目一：合并果子
题目：n 堆果子，每堆 a_i 个。每次合并任意两堆，代价为两堆数量之和。求合并成一堆的最小总代价。
输入：n (1 ≤ n ≤ 10000)，第二行 n 个整数 a_i。
输出：一个整数，最小体力耗费值。
样例输入：3 \n 1 2 9
样例输出：15
解法：小根堆，每次取最小的两堆合并，O(n log n)。
📝 题目二：删数问题
题目：给定 n 位正整数（长度 ≤ 250），删除 k 个数字，使剩余数字按原顺序组成的新数最小。
输入：第一行正整数 n，第二行 k。
输出：最小的剩余整数（无前导零）。
样例输入：175438 \n 4
样例输出：13
解法：单调栈，删除"山峰"位（num[i] > num[i+1]），O(n)。
🎯 解题关键：合并果子注意用小根堆而非大根堆；删数问题注意处理前导零和剩余删除名额。两道题代码都很短，但策略设计是重点。

六、易错点 + 本课小结

⚠️ 六大易错点

  • 合并果子用大根堆：priority_queue<int> 默认是大根堆，必须显式指定 greater<int>。
  • 删数问题忘记处理前导零：输出结果前必须去除前导零，全零时输出 "0"。
  • 删数问题 k 剩余未处理：单调栈遍历完成后若 k > 0，需从末尾继续删除。
  • 最优装载数据溢出：累计重量可能超 int，务必使用 long long。
  • 合并果子 vs 石子合并混淆：前者可任意合并（贪心），后者只能合并相邻（区间DP）。
  • 贪心策略不确定时坚持使用：能想到的反例才是最好的老师——找不到反例不代表正确。
