一、排序 + 贪心通用模式

// 输入 → 按关键属性排序 → 依次贪心选择 → 输出 sort(...); for (...) { /* 能选就选 / 更新状态 */ }
  • 按数值大小：排队接水、最优装载（升序）
  • 按区间端点：活动选择（右端）、覆盖（左端）
  • 按性价比：部分背包思想（CSP-J 少考）
  • 不排序用堆：需动态取最小/最大 → priority_queue

交换论证：若最优解第一个不是按属性 P 最优的元素，可交换而不变差 → P 最优元素属于某最优解。

【讲解】排序替我们完成「当前最优」判定。

二、哈夫曼思想与合并果子

问题：n 堆果子，每次合并任意两堆，代价为数量之和，求合并成一堆的最小总代价。

策略：每次取最小的两堆合并（哈夫曼编码思想）。小堆越早合并，其重量被重复计入的代价越小。

样例：1, 2, 9 → (1+2)=3，代价 3；再 (3+9)=12，代价 12；总 15。

与石子合并区别：本题可任意两堆 → 贪心；若只能相邻 → 区间 DP（第40课），切勿套堆！
【讲解】合并果子 板书 1,2,9；强调「任意」vs「相邻」。

合并果子 — 小根堆模板

priority_queue<int, vector<int>, greater<int>> pq; // 小根堆！ for (int i = 0; i < n; i++) { int x; cin >> x; pq.push(x); } long long totalCost = 0; while (pq.size() > 1) { int a = pq.top(); pq.pop(); int b = pq.top(); pq.pop(); int sum = a + b; totalCost += sum; pq.push(sum); } cout << totalCost << endl;
写法声明
大根堆（默认）priority_queue<int>
小根堆（推荐）priority_queue<int, vector<int>, greater<int>>
取负技巧push(-x)，用时取反（注意溢出）
易错：默认大根堆会错；代价用 long long。
【讲解】模板 对照 lesson34 mergeFruits。复杂度 O(n log n)。

合并果子 — 过程推演

堆：3, 5, 1, 2, 8, 13（示意过程）

  • 取 1,2 → 合 3，代价 +3，堆中有 3,3,5,8,13
  • 取 3,3 → 合 6，代价 +6
  • 取 5,6 → 合 11，代价 +11
  • 取 8,11 → 合 19，代价 +19
  • 取 13,19 → 合 32，代价 +32

总代价 = 3+6+11+19+32（以程序验算为准）。n=1 时答案 0（无需合并）。

正确性直觉：较早合并的堆会多次进入后续代价，故应让小堆先合并。
【讲解】可让学生手推小样例再对程序输出。

三、删数问题

问题：n 位正整数（字符串），删 k 位，使剩余按原序组成的数最小（去前导零）。

贪心：删除「山峰」——从左往右，若 a[i] > a[i+1]，删 a[i]（高位变小）。重复 k 次；若序列非递减，删末尾。

例：num="1432219", k=3 → 删 4,3,2 → "1219"。

朴素 O(kn)：n、k 大时超时。CSP-J 高频考单调栈 O(n)。
【讲解】删数 口诀：遇山删峰，让更小数字提前。

删数 — 单调栈模板

string removeKdigits(string num, int k) { string stk; for (char c : num) { while (!stk.empty() && stk.back() > c && k > 0) { stk.pop_back(); k--; } stk.push_back(c); } while (k > 0 && !stk.empty()) { stk.pop_back(); k--; } int start = 0; while (start < (int)stk.size() && stk[start] == '0') start++; if (start == (int)stk.size()) return "0"; return stk.substr(start); }
  • 栈维护非递减数字序列
  • 遍历完 k 仍 >0 → 删尾
  • 必须去前导零；全 0 输出 "0"
【讲解】对照 lesson34 removeKdigitsOptimized。三坑：前导零、k剩余、方向删峰非山谷。

删数 — 朴素版与细节

// 理解用：每轮找第一个山峰删掉 for (int t = 0; t < k; t++) { bool found = false; for (int i = 0; i + 1 < (int)num.size(); i++) { if (num[i] > num[i+1]) { num.erase(i, 1); found = true; break; } } if (!found) num.pop_back(); }
易错清单：① 未处理前导零；② k 未用尽；③ 删成「山谷」方向反；④ 结果为空应输出 0。
【讲解】先朴素再栈，理解「等价」。

四、最优装载

n 件不可分割物品，船载重 C，求最多件数（每件价值视为 1）。

sort(w, w + n); // 轻的优先 int count = 0; long long sum = 0; for (int i = 0; i < n; i++) { if (sum + w[i] <= C) { sum += w[i]; count++; } else break; }
为何不用 DP？价值都相同，轻的「性价比」最高。若价值不同 → 01 背包。
【讲解】装载 与第33课呼应，强调 long long。

五、贪心 vs 动态规划

维度贪心DP
选择不可撤销记录所有子问题
正确性需证明状态对即最优
复杂度O(n log n)/O(n)O(n²)～O(nW)
典型题活动选择、合并果子01背包、LIS
  1. n≤20？→ 可枚举/回溯
  2. 能想到合理贪心策略？
  3. 能构造反例吗？不能则样例验证
  4. 通过 → 贪心；否则 → DP
实战：策略明确且样例过 → 优先贪心；不确定且范围允许 → DP 更安全。
【讲解】判断流 结合「任意合并 vs 相邻」「件数 vs 价值」。

真题精练

① 合并果子（NOIP 风格）
n 堆，任意两堆合并，代价为和。求最小总代价。n≤1e4。→ 小根堆模板。
② 删数字
给定数字串与 k，使剩余最小。→ 单调栈 + 去前导零。
③ 装船
载重 C，重量 w_i，最多件数。→ 重量升序贪心。
【讲解】三题各点 1 分钟思路即可。

易错点汇总

  • 大根堆误用：必须 greater<int> 小根堆。
  • 删数前导零 / k 剩余 / 方向错误。
  • 装载 sum 用 int 溢出。
  • 合并果子 vs 石子合并 条件「任意/相邻」看错。
  • 价值不同装载 误用重量贪心 → 应 DP。
考场检查清单：堆类型 → long long → 边界 n=1 / 全0 / k=n-1。
【讲解】易错 逐条勾选。

本课小结

  • 排序 + 贪心是 CSP-J 主流框架。
  • 合并果子 = 哈夫曼 = 小根堆每次合最小两堆。
  • 删数 = 删山峰 = 单调非递减栈 O(n)。
  • 最优装载（件数）= 轻的优先；价值不同 → 背包。
  • 选贪心还是 DP：有无反例、数据范围、约束（相邻/次数）。
