一、DP的四大核心概念

1. 什么是动态规划？

动态规划（Dynamic Programming）的核心思想：将复杂问题分解为重叠子问题，缓存子问题结果以避免重复计算。

1
状态定义

用数学语言描述子问题局面

2
状态转移

从前驱状态推导当前状态

3
最优子结构

最优解包含子问题最优解

4
无后效性

状态值不受后续决策影响

2. 状态定义的关键原则

  • 状态必须唯一描述一个子问题
  • 状态空间应便于写出转移方程
  • 可根据数据范围预估状态数量和维数
考试技巧：拿到DP题，先不要急着写代码，花3分钟在草稿纸上写清楚「状态定义」「转移方程」「边界条件」三项，再开始编码。

二、DP的两种实现方式

记忆化搜索 vs 递推DP

对比维度 记忆化搜索（自顶向下） 递推DP（自底向上）
方向 从原问题递归分解 从最小子问题递推
实现 递归 + 缓存数组 循环 + dp数组
优点 思维直观，只算需要的状态 效率高，无递归开销
缺点 递归深度大可能栈溢出 需仔细设计递推顺序
推荐场景 递推顺序不直观时 CSP-J首选
考试建议：CSP-J考试中优先使用递推DP（自底向上），常数小、不易出错、不会栈溢出。

记忆化搜索代码框架

int dfs(int i, int j) { if (i == n) return a[i][j]; // 边界 if (vis[i][j]) return memo[i][j]; // 已计算 vis[i][j] = true; return memo[i][j] = max(dfs(i+1,j), dfs(i+1,j+1)) + a[i][j]; }

三、经典问题：数字三角形

问题描述

7 3 8 8 1 0 2 7 4 4 4 5 2 6 5

从顶部出发，每次向左下或右下移动，到达底部。求路径数字和的最大值。

从底向上递推（推荐写法）

// dp[i][j] 表示从 (i,j) 出发到达底部的最大和 for (int j = 1; j <= n; j++) dp[n][j] = a[n][j]; for (int i = n - 1; i >= 1; i--) for (int j = 1; j <= i; j++) dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j]; cout << dp[1][1]; // 答案直接是 dp[1][1]
易错提醒：从上向下递推也可以，但最终答案需要遍历最后一行取max（max(dp[n][1..n])），容易忘记。从底向上写法直接输出dp[1][1]，更不容易出错。

四、路径计数问题

基本模型

m*n网格，从(1,1)出发，每次只能向右或向下移动，到达(m,n)。
求总共有多少条不同的路径。

状态与转移

状态：dp[i][j] = 到达 (i, j) 的路径数

转移：dp[i][j] = dp[i-1][j] + dp[i][j-1]

边界：第一行和第一列初始化为1（只有一种走法）

// 初始化 for (int j = 1; j <= n; j++) dp[1][j] = 1; for (int i = 1; i <= m; i++) dp[i][1] = 1; // 递推 for (int i = 2; i <= m; i++) for (int j = 2; j <= n; j++) dp[i][j] = (dp[i-1][j] + dp[i][j-1]) % MOD;

带障碍物的扩展

如果某些格子是障碍（不可通行），则这些格子的dp值为0：

if (block[i][j]) dp[i][j] = 0; // 无法到达 else dp[i][j] = dp[i-1][j] + dp[i][j-1];
考试技巧：路径计数类问题的答案可能非常大，记得按题目要求取模（通常是 1e9+7）。

五、DP解题六步法

1
判断问题类型

确认最优子结构和无后效性

2
定义状态

确定dp数组含义和维度

3
推导转移方程

分析前驱状态和转移代价

4
确定边界条件

初始化最小子问题

5
确定计算顺序

保证前驱已计算

6
定位答案

明确答案在dp数组的位置

真题实战：过河卒（经典CSP-J题目）

棋盘上卒从(0,0)到(n,m)，马在(x,y)及控制点处不可走。卒只能向右或向下走，求路径数。

解题思路：先标记马的控制点（9个位置），将障碍格dp值设为0，其余正常递推。这是路径计数模型+障碍物处理的综合应用。

六、真题精讲：数字三角形

题目

给定n（1≤n≤1000）行数字三角形，从顶部出发每次向左下/右下移动，求到达底部的最大路径和。

AC代码

#include <bits/stdc++.h> using namespace std; const int MAXN = 1005; int a[MAXN][MAXN], dp[MAXN][MAXN]; int main() { int n; cin >> n; for (int i = 1; i <= n; i++) for (int j = 1; j <= i; j++) cin >> a[i][j]; for (int j = 1; j <= n; j++) dp[n][j] = a[n][j]; for (int i = n-1; i >= 1; i--) for (int j = 1; j <= i; j++) dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j]; cout << dp[1][1] << '\n'; return 0; }

输入样例：n=5，三角形如本页图，输出：30

必考知识点：数字三角形是CSP-J中最常考的DP入门题。必须熟练掌握从底向上递推的写法，并理解为什么这样做是正确的。

本课总结

DP本质

分解为重叠子问题，缓存结果避免重复计算。是一种「带记忆的枚举」。

四大核心

状态定义、状态转移方程、最优子结构、无后效性——四者缺一不可。

两种实现

记忆化搜索（递归+缓存）和递推DP（循环+数组）。考试优先递推DP。

DP六步法

判断类型→定义状态→推导转移→确定边界→确定顺序→定位答案。

数字三角形

从底向上递推：dp[i][j]=max(dp[i+1][j],dp[i+1][j+1])+a[i][j]

路径计数

dp[i][j]=dp[i-1][j]+dp[i][j-1]，注意取模和障碍物处理。
