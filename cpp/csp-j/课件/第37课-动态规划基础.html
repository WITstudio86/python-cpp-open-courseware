考纲与目标

  • 掌握：状态定义、转移方程、最优子结构、无后效性
  • 会写：记忆化搜索与递推 DP

一句话：把大问题拆成重叠子问题，存结果避免重复计算。
【讲解】与递推关系：递推是实现手段，DP 强调状态与最优性。

一、什么是动态规划

Bellman 提出：复杂问题 → 重叠子问题 → 保存子问题解 → 高效求原问题。

  • 与暴力递归：同枚举思想，但消除重复
  • 与贪心：都要最优子结构；DP 考虑多种选择并记录最优，贪心只走当前最优
  • 与递推：递推是计算顺序；DP 是问题分析框架
// 爬楼梯：f[i] = f[i-1] + f[i-2] f[0] = f[1] = 1; for (int i = 2; i <= n; i++) f[i] = f[i-1] + f[i-2];
【讲解】爬楼梯引出四要素。

二、DP 四核心概念

概念含义
状态定义用变量描述子问题局面，如 dp[i][j]
转移方程如何由前驱状态得到当前最优
最优子结构全局最优由子问题最优构成
无后效性状态值确定后不依赖「如何到达」的历史细节
  • 状态唯一描述子问题；空间受数据范围约束
  • 有后效性时需加维度记录历史
【讲解】四要素 板书固定格式。

状态与转移怎么想

  1. 当前状态可由哪些前驱到达？
  2. 每条转移的代价/收益是什么？
  3. 在所有可能中取 max/min/sum
// 数字三角形从上到下 dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j]; // 网格路径计数 dp[i][j] = dp[i-1][j] + dp[i][j-1];
写转移前先用中文说清 dp 的含义，否则极易写错。
【讲解】先定义后转移。

三、两种实现：记忆化 vs 递推

记忆化（Top-Down）递推（Bottom-Up）
方向从原问题递归拆从小问题推到大
优点思维直观；只算需要的状态常数好；无栈溢出
缺点递归开销/深栈要设计循环顺序
CSP-J 优先递推 DP。转移顺序难写时用记忆化。
【讲解】实现选型。

记忆化搜索示例

int memo[MAXN][MAXN]; bool vis[MAXN][MAXN]; int dfs(int i, int j) { if (i == 1 && j == 1) return a[1][1]; if (i < 1 || j < 1 || j > i) return -INF; if (vis[i][j]) return memo[i][j]; vis[i][j] = true; return memo[i][j] = max(dfs(i-1, j-1), dfs(i-1, j)) + a[i][j]; }
【讲解】vis 防重复；边界与非法状态。

四、数字三角形

     7
    3 8
   8 1 0
  2 7 4 4
 4 5 2 6 5
答案路径和 30（如 7-3-8-7-5）
  • 状态：dp[i][j] = 从顶到 (i,j) 的最大和 或 从 (i,j) 到底的最大和
  • 从上到下：答案 = max(dp[n][*])
  • 从下到上：答案 = dp[1][1]（更简洁）
【讲解】手推三角形，对照 lesson37。

数字三角形 — 从底向上模板

for (int j = 1; j <= n; j++) dp[n][j] = a[n][j]; for (int i = n - 1; i >= 1; i--) for (int j = 1; j <= i; j++) dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j]; cout << dp[1][1];
转移：只能左下/右下。边界：最底行 = 自身。复杂度 O(n²)。
【讲解】模板 必须默写。

五、路径计数

m×n 网格，只能右或下，从左上到右下路径数。

for (int j = 1; j <= n; j++) dp[1][j] = 1; for (int i = 1; i <= m; i++) dp[i][1] = 1; for (int i = 2; i <= m; i++) for (int j = 2; j <= n; j++) dp[i][j] = dp[i-1][j] + dp[i][j-1];

障碍：若 (i,j) 不可走，dp[i][j]=0；否则仍为上+左。

答案可能很大，用 long long；障碍在第一行/列时边界初始化要小心。
【讲解】路径计数 过河卒思想。

六、DP 六步法（考场流程）

  1. 判断：最优子结构 + 无后效性？
  2. 定义状态：dp 含义与维度
  3. 推导转移方程
  4. 确定边界/初始化
  5. 确定计算顺序（依赖已算完）
  6. 确定答案位置（未必是 dp[n]）
每道 DP 题按六步写在草稿纸上，再写代码，正确率显著提升。
【讲解】六步法 反复强调。

真题精练

数字三角形（NOIP 经典）

n≤1000，求最大路径和。→ 从底向上 O(n²) 递推。

方格取数 / 路径条数

网格路径数或带障碍。→ dp[i][j]=上+左；障碍置 0。

【讲解】真题

易错点

  • 状态含义不清，转移抄错维度
  • 边界未初始化 / 第一行第一列障碍处理错
  • 循环顺序导致用到未计算状态
  • 答案取 dp[n] 却应取 max(dp[*])
  • 记忆化未标记 vis，或递归深度过大
  • int 存路径数溢出
【讲解】易错

本课小结

  • DP = 重叠子问题 + 最优子结构 + 存结果。
  • 四要素：状态、转移、边界、顺序（+答案位置）。
  • 优先自底向上递推；难时用记忆化。
  • 数字三角形、路径计数是入门标准模板。
  • 牢记六步法，进入线性 DP / 背包。
