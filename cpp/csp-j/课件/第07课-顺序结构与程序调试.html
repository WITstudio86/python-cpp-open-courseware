一、顺序结构概念

程序按代码书写顺序，从上到下逐条执行。没有任何跳转、循环、分支干预的情况下，每一条语句按照它在源代码中出现的先后顺序被 CPU 依次执行。

C++ 语句分类

1. 声明语句

定义变量、函数等：int a;、double pi = 3.14;

2. 表达式语句

以分号结尾的表达式：a = b + c;、cout << x;

3. 控制语句

改变执行流程：if、for、while、switch

4. 复合语句

用花括号 {} 包裹的多条语句，视为一个整体

顺序结构是程序设计的最基础结构。理解顺序执行、逐行追踪是读懂任何复杂程序的前提。

二、程序中的四类错误

1. 编译错误 (CE)

语法错误、类型不匹配、未声明变量等。编译阶段就能被发现。

// 缺少分号 → syntax error int a = 10 // 类型不匹配 → cannot convert string s = 123;

2. 链接错误 (LE)

函数声明了但未定义、缺少库文件等。链接阶段报错。

典型信息：undefined reference to 'xxx'

3. 运行时错误 (RE)

程序运行时崩溃：除零、数组越界、空指针访问、栈溢出等。

4. 逻辑错误 (WA)

程序正常运行但结果不对 — 算法/思路有问题。最难排查，需要通过调试定位。

编译错误信息解读要点：看文件+行号 → 看错误类型 → 看描述信息。先修第一个错误（后面的可能是连锁反应）。常见英文提示：syntax error（语法错）、undefined reference（未定义引用）、segmentation fault（段错误=越界）。

三、程序调试方法

方法一：输出调试法

在关键位置插入 cout 输出变量值，观察执行过程。

int a = 3, b = 7; cout << "【调试】a=" << a << ", b=" << b << endl; a = b - a; cout << "【调试】执行后 a=" << a << endl;

简单直接，不需要特殊工具。但提交前必须删除！

方法二：断点调试法

在 IDE 中设置断点，然后调试运行：

  1. 在目标行左侧单击设置断点（红点）
  2. 选择"调试运行"（F5）而非"运行"
  3. 程序在断点处暂停
  4. 使用单步执行（F10/F11）逐行运行
  5. 在变量窗口观察变量值变化

调试时需要关注的点

  • 变量的值：是否符合预期？何时与预期偏离？
  • 执行路径：程序是否走进了预期的 if/else 分支？
  • 循环次数：循环执行了多少次？边界条件是否正确？
  • 表达式求值：复杂表达式每一步的中间结果是否正确？

四、程序阅读技巧

标准阅读流程

  1. 概览：快速浏览代码，明确输入/输出/核心变量
  2. 找关键变量：定位哪些变量会被修改
  3. 逐行模拟执行：用笔和纸模拟计算机执行每条代码
  4. 制作变量追踪表：记录每一步后各变量的变化

变量追踪表示例：交换两个变量的值

int a = 3, b = 7, t; t = a; a = b; b = t;

五、代码模板：调试输出与变量追踪

使用 #ifdef 控制调试输出（推荐方法）

#include <iostream> #define DEBUG // 提交前删除或注释此行 using namespace std; int main() { int a = 3, b = 7, c = 4; #ifdef DEBUG cout << "[DEBUG] 初始 a=" << a << endl; #endif a = b - a; c = a + b; #ifdef DEBUG cout << "[DEBUG] a=" << a << " c=" << c << endl; #endif cout << c << endl; return 0; }

提交时只需删除 #define DEBUG 一行，所有调试输出即失效。这是竞赛中最推荐的调试写法。

竞赛最佳实践：用 #ifdef DEBUG 包裹调试输出，提交时删除 #define DEBUG 即可，不用担心遗留多余的 cout。

七、真题练习二：交换变量

题目：用临时变量 t 完成 x 和 y 的交换。

int x = 8, y = 15, t; // 请补充交换代码，使最终 x=15, y=8 t = x; x = y; y = t;

交换过程分析

步骤代码xyt说明
初始声明815?赋初值
①t = x8158暂存 x 的值
②x = y15158x 获取 y 的值
③y = t1588y 获取暂存的旧 x 值

常见错误

  • 错误写法：x = y; y = x; — 第一句后 x 已经变成 y 的值，第二句把 y 赋回 y；结果 x=15, y=15。
  • 正确思路：必须有一个临时变量暂存原始值，就像"两杯水交换需要第三个空杯子"。

八、本课小结

知识点核心要点
顺序结构程序从上到下逐条执行；C++四大语句类型
三类错误编译错误(CE)、运行时错误(RE)、逻辑错误(WA)
调试方法输出调试法(cout)、断点调试法(F5/F10/F11)
变量追踪逐行模拟执行，记录每一步变量值的变化
最佳实践用 #ifdef DEBUG 控制调试输出，提交前删除 #define
本课核心提醒：
🔹 提交前务必删除所有调试用的 cout 语句！多余的输出会导致评测系统判为 WA。
🔹 遇到复杂代码，不要心算 — 用纸笔画出变量追踪表，一步一步来。
🔹 编译错误看第一个报错；运行时错误看报错行号；逻辑错误靠调试定位。
🔹 变量交换三部曲：t=a; a=b; b=t;（第三个杯子）不可省略。
