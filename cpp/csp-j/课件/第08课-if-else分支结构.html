一、三种分支结构

单分支 if

条件成立？
├─ 是 → 执行语句块
└─ 否 → 跳过
if (条件) { 语句块; }

双分支 if-else

条件成立？
├─ 是 → 执行A
└─ 否 → 执行B
if (条件) { A; } else { B; }

多分支 if-else if-else

条件1？→A
条件2？→B
否则 →C
if (c1) {A;} else if (c2) {B;} else {C;}

执行规则：多分支从上到下依次检查条件，第一个为 true 的条件对应的代码块被执行，其余全部跳过。最后的 else 在所有条件都为 false 时执行（可省略）。

二、嵌套 if — 在分支内部再写分支

在 if 或 else 的代码块内部，还可以继续写 if 语句。

示例：找三个数的最大值

int a = 10, b = 25, c = 18, max; if (a > b) { if (a > c) // 嵌套在 if 内部 max = a; else max = c; } else { if (b > c) // 嵌套在 else 内部 max = b; else max = c; } // 结果：max = 25

嵌套层数不宜过多（通常不超过 3 层），否则代码可读性急剧下降。可以用 提前 return 或 三目运算符 简化。

简化写法：max = (a > b ? a : b) > c ? (a > b ? a : b) : c; 但可读性差，考试中建议老老实实用嵌套 if + 花括号。
【讲解】二、嵌套 if — 在分支内部再写分支 结合讲义《四、嵌套 if》强调： · 在 if 或 else 的语句块中再包含 if 结构。 · int a, b, c; · cin >> a >> b >> c; · if (a > b) { · if (a > c) { 幻灯片上可见要点： · 在 if 或 else 的代码块内部，还可以继续写 if 语句。 · 示例：找三个数的最大值 · 嵌套层数不宜过多（通常不超过 3 层），否则代码可读性急剧下降。可以用 提前 return 或 三目运算符 简化。 · 提前 return 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

三、悬空 else 问题 （考试重点！）

规则：else 总是与最近的、尚未配对的 if 匹配。这被称为「就近原则」。

经典例题

int x = 5, y = 0; if (x > 0) if (y > 0) cout << "A"; else cout << "B";

—— 输出什么？

分析

根据「就近原则」，else 与 if (y > 0) 匹配，不是与 if (x > 0) 匹配！

  • ① x > 0 → true，进入外层 if
  • ② y > 0 → false，跳过内层 if 体
  • ③ else 与内层 if 匹配 → 执行 cout << "B"

最终输出：B

解决悬空 else 的最佳方法：始终使用花括号 {} 明确范围！
if (x > 0) { if (y > 0) { cout << "A"; } } else { cout << "B"; } — 花括号使 else 明确匹配外层 if。
【讲解】三、悬空 else 问题 （考试重点！） 结合讲义《五、悬空 else 问题（考试重点！）》强调： · 规则：else 总是与最近的、尚未配对的 if 匹配（就近原则）。 · 经典例题： · int a = 1, b = 2; · if (a == 0) · if (b == 2) 幻灯片上可见要点： · 规则： else 总是与 最近的、尚未配对的 if 匹配。这被称为「 就近原则 」。 · 最近的、尚未配对的 if · 就近原则 · 经典例题 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

四、条件表达式深入

条件可以是任意能转换为 bool 的表达式

条件写法含义示例
关系表达式比较大小a > b、x == 0
逻辑组合多个条件 && / ||a > 0 && b > 0
直接数值非0即 true，0即 falseif (a) — a≠0 执行
函数返回值返回 bool 或数值if (isPrime(n))

闰年判断条件

// 闰年规则：能被4整除但不能被100整除，或者能被400整除 if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) cout << "闰年"; else cout << "平年";

注意 复合条件的短路特性同样适用于 if 条件判断。合理利用短路可以写出更高效的代码。

五、代码模板

成绩等级判定（多分支）

int score; cin >> score; if (score >= 90) cout << "A"; else if (score >= 80) cout << "B"; else if (score >= 70) cout << "C"; else if (score >= 60) cout << "D"; else cout << "F";

关键：条件从大到小排列！

三个数排序（if+swap）

int a, b, c, t; cin >> a >> b >> c; if (a > b) { t = a; a = b; b = t; } if (a > c) { t = a; a = c; c = t; } if (b > c) { t = b; b = c; c = t; } cout << a << " " << b << " " << c; // 升序排列

思路：逐个将最小值"冒泡"到前面。

【讲解】五、代码模板 本页要点（照着讲即可）： · 成绩等级判定（多分支） · 关键：条件 从大到小 排列！ · 从大到小 · 三个数排序（if+swap） · 思路：逐个将最小值"冒泡"到前面。 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

六、真题练习一：悬空 else

题目：以下代码输出什么？

int x = 5, y = 0; if (x > 0) if (y > 0) cout << "A"; else cout << "B";

执行流程分析

步骤判断结果操作
①x > 0？(5 > 0)true进入外层 if 体
②y > 0？(0 > 0)false跳过内层 if 体
③else 就近与内层 if 配对—执行 else 体：输出 "B"

输出结果：B

避坑指南：代码缩进会骗人！编译器不看缩进，只看花括号和语法规则。
要改写为「输出A」的效果，需要用花括号：if (x>0) { if (y>0) cout<<"A"; else cout<<"B"; }

七、真题练习二：多分支条件顺序陷阱

题目：输入 85，以下代码输出什么？

int score; cin >> score; // 输入 85 if (score >= 60) cout << "及格"; else if (score >= 80) cout << "良好"; else if (score >= 90) cout << "优秀"; else cout << "不及格";

分析

  • 85 >= 60 → true，输出 "及格"
  • 多分支只执行第一个匹配的，后面的 >=80 和 >=90 永远不会执行！

输出结果：及格（但这显然不对 — 85应该是"良好"）

正确写法：条件从大到小排列

if (score >= 90) cout << "优秀"; else if (score >= 80) cout << "良好"; else if (score >= 60) cout << "及格"; else cout << "不及格";
多分支条件顺序原则：从大到小（或从小大到）排列，或者确保条件之间互斥。考试中这是极易出错的地方！

八、本课小结

知识点核心要点
三种分支if（单分支）、if-else（双分支）、if-else if-else（多分支）
嵌套 if分支内部再写分支，用花括号控制范围
悬空 else就近原则 — else 匹配最近的未配对的 if
条件顺序多分支条件必须从大到小排列（按范围筛选）
条件表达式任意能转 bool 的表达式；复合条件注意短路

三个常见陷阱

陷阱1：if 后多余分号
if (a > b); // 分号是空语句！ cout << "这里无条件执行";

if 后跟分号 = 条件成立时执行空语句，后面的花括号代码无条件执行！

陷阱2：= 赋值当 == 比较
if (a = 5) // 赋值！不是比较！ // 赋值表达式值为5(true)，总是执行

写成 if (5 == a) 可预防此错误（常量在左）。

陷阱3：浮点数 == 比较
if (a == 0.1) // 浮点精度问题

浮点数用 fabs(a - b) < 1e-9 判断相等！

本课最重要的一句话：if 后面不要加分号！if(a>b); 分号构成了空语句，后面的花括号代码会无条件执行。这是初学 C++ 最高频的错误。
