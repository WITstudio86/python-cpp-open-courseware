一、为什么需要分支结构？

顺序结构只能“一条道走到黑”。现实问题却经常是：分数≥60 及格；奇偶判断；闰年；多档成绩 A/B/C…

条件？
/ \
true false
| |
路径 A 路径 B

分支结构让程序根据条件选择不同路径。C++ 中最基础、也是 CSP-J 最高频的分支语法就是 if-else。

单分支 if

if (条件) { 语句块; }

真执行，假跳过

双分支 if-else

if (条件) {A;} else {B;}

二选一

多分支 else if

if (c1) {A;} else if (c2) {B;} else {C;}

命中即停

【讲解】十字路口类比。三种基本形态先建立全局图。

二、单分支 if 与双分支 if-else

单分支

int score = 85; if (score >= 60) { cout << "及格" << endl; } cout << "程序继续" << endl; // 输出：及格 / 程序继续 // score=50 时只输出「程序继续」

只有一条语句时可省略 {}，但强烈建议始终写花括号。

双分支

int n; cin >> n; if (n % 2 == 0) { cout << "偶数" << endl; } else { cout << "奇数" << endl; }

if 与 else 二选一；else 不能单独出现，必须依附 if。

执行流程：计算条件 → 真走 if 块 / 假走 else 块（若有）→ 继续执行 if-else 之后的代码。
【讲解】对应 lesson08 demo01 / demo02。花括号与悬空 else 强相关。

三、多分支 if-else if-else：命中即停

系统从上到下检查：找到第一个为真的条件 → 执行对应块 → 结束整条链。后面即使还有为真的条件，也不会再判断。

if (score >= 90) cout << "A"; else if (score >= 80) cout << "B"; // 隐含 score < 90 else if (score >= 70) cout << "C"; else if (score >= 60) cout << "D"; else cout << "E"; // score=85 → 跳过 90，命中 80 → 输出 B，停止
正确：从严到宽
>=90 → >=80 → >=70 → >=60 → else
错误：从宽到严
if (score >= 60) /* 先截走 */ else if (score >= 80) /* 永不可达 */ else if (score >= 90) /* 永不可达 */
输入 85 会输出“及格”！
【讲解】这是多分支最重要考试点。写法 A 依赖 else if 互斥；写法 B 显式写区间更安全但冗长。

四、嵌套 if

在 if 或 else 的语句块中再写 if，称为嵌套。考试嵌套尽量 ≤ 3 层。

三数求最大值

int maxVal; if (a >= b) { if (a >= c) maxVal = a; else maxVal = c; } else { if (b >= c) maxVal = b; else maxVal = c; }

嵌套 vs 逻辑运算符拍平

// 嵌套 if (x > 0) { if (y > 0) cout << "第一象限"; } // 等价拍平 if (x > 0 && y > 0) cout << "第一象限";

内外层有不同 else 时，嵌套往往更清晰。

// 三数升序（冒泡思想三步） if (a > b) swap(a, b); if (a > c) swap(a, c); if (b > c) swap(b, c);
【讲解】对应 lesson08 demo04。也可用 max({a,b,c}) 简洁求最值。

五、悬空 else 问题 （考试重点！）

规则（必须背）：else 总是与上面最近的、尚未配对的 if 匹配——就近原则。与缩进无关！编译器不看缩进。

int x = 5, y = 0; if (x > 0) if (y > 0) cout << "A" << endl; else cout << "B" << endl; // 实际匹配内层 if (y>0)
  • x>0 为真 → 进入外层；y>0 为假 → 执行内层 else → 输出 B
  • 若 x=-1：外层假，整个内层 if-else 被跳过 → 无输出
正确做法：永远加花括号，明确 else 配外层还是内层。某些写法会触发 -Wdangling-else 警告。
【讲解】对应 lesson08 demo05 / exam01。读程先重画配对再判断。

六、条件表达式深入

写法含义示例
关系表达式比较大小a > b、x == 0
逻辑组合&& / || / !a>0 && b>0
直接数值非 0 为真，0 为假if (a)、if (a%2)
短路左假则右不算（&&）b!=0 && a/b>1

优先级：&& 优先于 ||

if (a > 0 || b > 0 && c > 0); // 等价于 a>0 || (b>0 && c>0) // 不确定就加括号！

三目运算符（缩写）

int maxv = (a > b) ? a : b; // 大段逻辑仍建议 if-else
安全写法：先判除数非 0 / 先判下标合法，再利用短路保护后续运算。
【讲解】对应 lesson08 demo07。两个独立 if 可能都执行；只取一档用 else if。

七、复合条件经典：闰年判断

规则：能被 4 整除且不能被 100 整除，或能被 400 整除。

if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0) { cout << "Y" << endl; // 闰年 } else { cout << "N" << endl; // 平年 }
年份结果原因
2000闰 (Y)能被 400 整除
1900平 (N)能被 100 整除且不能被 400 整除
2024闰 (Y)能被 4 整除且不能被 100 整除
2023平 (N)不能被 4 整除
手测边界：成绩 0/59/60/90/100；闰年 1900/2000/2024。括号保证 && / || 组合语义正确。
【讲解】对应 lesson08 demo06 / exam04。考点：复合逻辑、括号优先级。

八、代码模板

成绩等级（从严到宽）

cin >> score; if (score >= 90) cout << "A"; else if (score >= 80) cout << "B"; else if (score >= 70) cout << "C"; else if (score >= 60) cout << "D"; else cout << "E";

分段函数

// y=x (x<1); 2x-1 (1≤x<10); 3x-11 (x≥10) if (x < 1) y = x; else if (x < 10) y = 2*x - 1; else y = 3*x - 11;
// 悬空 else 安全写法：else 明确匹配内层 / 外层 if (x > 0) { if (y > 0) { cout << "A"; } else { cout << "B"; } // 内层 } if (x > 0) { if (y > 0) { cout << "A"; } } else { cout << "B"; } // 外层
【讲解】编程先列区间表再写条件，并手测边界。

九、易错点（八大坑）

1. if 后多余分号
if (a > 0); { ... } // 空语句，花括号无条件执行
2. = 与 == 混用
if (a = 5) // 赋值且常为真 // 正确 if (a == 5) 或 if (5 == a)
3. 悬空 else

else 配最近 if，与缩进无关——永远写 {}

4. 从宽到严

先 ≥60 再 ≥90，高分到不了后面——从严到宽

5. 优先级

a || b && c = a || (b && c)，不确定加括号

6. 浮点 ==
fabs(x - 0.3) < 1e-9
7. 并列 if 重复输出

只取一档时必须 else if，不要多个独立 if

8. 缺少 else 兜底

菜单/等级转换建议写最终 else 防漏网

【讲解】对应讲义易错点全部覆盖。

十、真题练习一：悬空 else 读程

题目：阅读程序，写出输出。

int x = 5, y = 0; if (x > 0) if (y > 0) cout << "A" << endl; else cout << "B" << endl;
步骤判断结果操作
①x > 0？(5>0)true进入外层 if 体
②else 就近配 if(y>0)—非外层 if
③y > 0？(0>0)false执行 else → 输出 B

答案：B　考点：就近匹配；花括号改变配对

【练习】先独立想 → 再对就近原则。对应 lesson08 exam01。

十一、真题练习二：多分支条件顺序

题目：输入 85，下列程序输出什么？

if (score >= 60) cout << "及格"; else if (score >= 80) cout << "良好"; else if (score >= 90) cout << "优秀";
  • 85 ≥ 60 → true，输出「及格」，链结束
  • 后面 80、90 分支不可达

错误输出：及格（85 实际应是“良好”）

正确写法

if (score >= 90) cout << "优秀"; else if (score >= 80) cout << "良好"; // 85 命中这里 else if (score >= 60) cout << "及格"; else cout << "不及格";
考点：else if 命中即停；条件顺序从严到宽。
【练习】对应 lesson08 exam02。

十二、真题练习三 / 四：闰年 & 分段函数

题目3：闰年 Y/N

输入 year，闰年输出 Y，否则 N

if ((year%4==0 && year%100!=0) || year%400==0) cout << "Y"; else cout << "N";

样例：2000→Y，1900→N

题目4：分段函数

y=x (x<1); 2x−1 (1≤x<10); 3x−11 (x≥10)

if (x < 1) y = x; else if (x < 10) y = 2*x-1; else y = 3*x-11; cout << y;

考点：区间划分与边界归属（1 归中段，10 归右段）

下一课预告：switch-case 适合离散常量（星期 1~7、运算符字符）；范围判断仍用 if-else。
【练习】对应 lesson08 exam03 / exam04。

十三、本课小结

知识点核心要点
单分支 if条件真才执行，假则跳过
双分支 if-else二选一，覆盖真假两种路径
多分支 else if自上而下，命中即停
条件顺序范围判断必须从严到宽
嵌套 if更细条件；注意层次与括号
悬空 elseelse 配最近 if；与缩进无关
条件表达式非 0 为真；注意优先级与短路
防御性写法始终 {}；慎用 =；浮点近似比较
考试建议：读程先找 if 配对；无括号嵌套先重画再就近原则；编程先列区间表再写条件并手测边界。
