考纲与为什么学 STL

知识点要求
vector定义、push_back、[]、size、clear
迭代器初步begin / end 基本用法
string 高级find、substr、insert、erase、getline

  • 省时间：动态数组一行搞定
  • 少 Bug：成熟实现，少内存错误
  • 可读：v.push_back 语义清晰
【讲解】竞赛不是造轮子。

一、vector：声明与常用操作

#include <vector> vector<int> v; // 空 vector<int> v2(10); // 10 个 0 vector<int> v3(10, 5); // 10 个 5 vector<int> v4 = {1,2,3};
操作含义复杂度
push_back / pop_back尾增 / 尾删均摊 O(1) / O(1)
size / empty / clear大小 / 空 / 清空O(1) / O(1) / O(n)
front / back / [i]首尾 / 下标O(1)
resize / reserve改大小 / 预留容量O(n)
vector<int> v(10) 是 10 个 0，不是容量 10 的空向量。预留用 reserve。
【讲解】演示 push 后 size。

vector 遍历与二维

// 下标 for (int i = 0; i < (int)v.size(); i++) cout << v[i]; // 范围 for for (int x : v) cout << x; // 二维 / 邻接表 vector<vector<int>> g(n + 1); g[u].push_back(v); g[v].push_back(u);
知道规模时 reserve(n) 减扩容；竞赛用 v[i] 自己保证不越界。
【讲解】邻接表为图论预告。

二、迭代器初步

迭代器 ≈ 封装的指针：*it 取值，++it 前进。

vector<int> v = {10,20,30}; for (auto it = v.begin(); it != v.end(); ++it) cout << *it << " "; // end() 是「尾后」位置，不要 *end() sort(v.begin(), v.end()); v.erase(v.begin() + 1); auto it = find(v.begin(), v.end(), 30);
sort / unique / find 都要 begin、end。区间半开 [begin, end)。
【讲解】与指针类比。

三、string：getline / find / substr

#include <string> string line; getline(cin, line); // 整行含空格 // cin>>n 后用 getline 前：cin.ignore(); string s = "hello world, hello cpp"; size_t p = s.find("hello"); // 0 if (s.find("java") == string::npos) { /* 没找到 */ } string sub = s.substr(0, 5); // "hello" string tail = s.substr(6); // 到末尾
判断失败写 == string::npos，勿写 find < 0（size_t 无符号）。
【讲解】npos 是巨大无符号数。

string：insert / erase / 数转

string s = "Hello World"; s.insert(5, " beautiful"); string t = "abcdef"; t.erase(2, 3); // "abf" cout << s.length() << s.size(); // 等价 // 字典序：a < b 可直接比较 string s1 = to_string(123); int num = stoi("456"); long long big = stoll("1234567890123");
to_string / stoi / stoll 为 C++11，CSP-J 可用。
【讲解】解析题常用 substr+stoi。

四、auto 与范围 for

auto x = 10; // int auto it = v.begin(); // 省掉冗长类型 for (auto x : v) { } // 拷贝 for (auto& x : v) { x *= 2; } // 可改 for (const auto& x : v) { } // 大对象只读
写法何时
auto x : v小类型只读
auto& x : v要修改元素
const auto& x : vstring 等避免拷贝
【讲解】auto 是编译期推导，非弱类型。

五、CSP-J 常见模式

// 去重排序 sort(a.begin(), a.end()); a.erase(unique(a.begin(), a.end()), a.end()); // 邻接表读图 vector<vector<int>> g(n + 1); for (...) { cin >> u >> v; g[u].push_back(v); g[v].push_back(u); } // CSV：find + substr while ((pos = line.find(',')) != string::npos) { ... }
【讲解】三模式覆盖大半基础题。

代码模板

// 模板1 vector 综合 vector<int> v; v.push_back(x); sort(v.begin(), v.end()); // 模板2 字符串解析字段 size_t start = 0, end; while ((end = line.find(',', start)) != string::npos) { fields.push_back(line.substr(start, end - start)); start = end + 1; } fields.push_back(line.substr(start)); // 模板3 auto + 范围 for for (const auto& s : fields) cout << s << endl;
【讲解】套模板写真题。

易错点

1. v[i] 越界（无检查）
2. 忘记 #include <vector> / <string>
3. 混淆 size() 与 capacity()
4. find 与 npos 比较写错（<0）
5. cin >> 后 getline 吃到空行 —— 用 cin.ignore()
【讲解】ignore 清掉换行。

真题1：去重排序

题目

n≤1e5 个数，排序去重，输出个数与升序列。

样例：3 1 4 1 5 9 2 6 → 7 个数；1 2 3 4 5 6 9

vector<int> a(n); for (int i = 0; i < n; i++) cin >> a[i]; sort(a.begin(), a.end()); a.erase(unique(a.begin(), a.end()), a.end()); cout << a.size() << endl; for (int i = 0; i < (int)a.size(); i++) { ... }
unique 只把重复挪到后部，必须 erase 才真正缩短。
【练习】强调 unique 语义。

真题2：CSV 字段解析

题目

一行逗号分隔字段，每字段一行输出。样例：Zhang,San,15,Math,95

string line; getline(cin, line); vector<string> fields; size_t pos; while ((pos = line.find(',')) != string::npos) { fields.push_back(line.substr(0, pos)); line.erase(0, pos + 1); } fields.push_back(line); for (const auto& f : fields) cout << f << endl;
【练习】也可用 start/end 不 erase 写法。
