Vector——会自己长大的数组

什么是vector？

vector是一个动态数组。普通数组大小编译时固定，vector可以在运行时自动扩容。

声明与初始化（5种方式）

// 包含头文件 #include <vector> vector<int> v; // 空vector，size=0 vector<int> v(10); // 10个元素，默认都是0 vector<int> v(10, 5); // 10个元素，每个都是5 vector<int> v = {1, 2, 3}; // C++11列表初始化 vector<int> v2(v); // 拷贝构造

常用操作速查表

操作说明复杂度
v.push_back(x)在末尾添加元素x均摊O(1)
v.pop_back()删除末尾元素O(1)
v.size()返回元素个数O(1)
v.empty()判断是否为空O(1)
v.clear()清空所有元素O(n)
v.front() / v.back()首元素 / 尾元素O(1)
v[i]下标访问（无越界检查）O(1)
注意：v[i] 不检查越界，你必须自己保证 0 ≤ i < v.size()。 v.at(i) 会检查越界但速度更慢，竞赛中常用 v[i]。

Vector 操作详解

push_back / pop_back / size / empty / clear

vector<int> v; v.push_back(10); // v = {10} v.push_back(20); // v = {10, 20} v.push_back(30); // v = {10, 20, 30} cout << v.size(); // 输出 3 cout << v.front(); // 输出 10（第一个元素） cout << v.back(); // 输出 30（最后一个元素） v.pop_back(); // v = {10, 20} v.clear(); // v = {}，size变为0 cout << v.empty(); // 输出 1 (true)

三种遍历方式

// 方式1：下标循环（需要用到索引时） for (int i = 0; i < v.size(); i++) { cout << v[i] << " "; } // 方式2：迭代器（配合STL算法时） for (auto it = v.begin(); it != v.end(); ++it) { cout << *it << " "; } // 方式3：范围for循环（最简洁，C++11） for (int x : v) { cout << x << " "; }

二维vector（邻接表基础）

vector<vector<int>> graph(n + 1); // n个节点，1-indexed graph[1].push_back(2); // 节点1→节点2 graph[1].push_back(3); // 节点1→节点3 for (int neighbor : graph[1]) { // 遍历节点1的所有邻居 cout << neighbor << " "; // 输出: 2 3 }

竞赛提示

  • 邻接表用 vector<vector<int>> 是最简洁的实现方式
  • 如果预先知道元素数量，用 reserve(n) 提前分配空间，避免多次扩容
  • size() 返回的是实际元素数，capacity() 是已分配的空间大小——不要搞混

迭代器——广义的"指针"

什么是迭代器？

迭代器（iterator）是一种遍历容器元素的对象，可以理解为封装的指针： *it 取值，++it 后移。

vector<int> v = {10, 20, 30, 40, 50}; // begin() → 第一个元素 end() → 最后一个元素之后 auto it = v.begin(); // *it = 10 cout << *it; // 输出 10 // 遍历 for (auto it = v.begin(); it != v.end(); ++it) { cout << *it << " "; // 10 20 30 40 50 }

迭代器的常用配合（algorithm库）

// 排序 sort(v.begin(), v.end()); // 反转 reverse(v.begin(), v.end()); // 查找 auto it = find(v.begin(), v.end(), 30); if (it != v.end()) { cout << "找到! 索引=" << (it - v.begin()); } // 插入/删除 v.insert(v.begin() + 2, 100); // 在下标2处插入100 v.erase(v.begin() + 1); // 删除下标1处的元素
关键记忆：begin() 是第一个元素，end() 是最后一个元素的下一个位置 （不是最后一个元素）。所以遍历条件永远是 it != v.end()。

竞赛建议

  • 遍历容器优先使用范围for，简洁不易错
  • 配合 algorithm 库函数时必须使用迭代器
  • auto 让迭代器声明简单10倍——auto it = v.begin()

String 高级操作——CSP-J字符串处理利器

getline()——读一整行（含空格）

#include <string> string line; getline(cin, line); // 读入一整行，包括空格 // ⚠️ 陷阱：cin >> 之后必须 cin.ignore() int n; cin >> n; cin.ignore(); // 清除残留的换行符！ string s; getline(cin, s); // 现在才能正确读取

find()——查找子串

string s = "hello world, hello cpp"; size_t p1 = s.find("hello"); // p1 = 0 (第一个出现位置) size_t p2 = s.find("hello", 5); // p2 = 13 (从下标5开始找) if (s.find("java") == string::npos) { cout << "没找到"; // npos = 没找到 }

substr()——截取子串

string s = "0123456789"; s.substr(0, 3); // "012" (从0开始，取3个字符) s.substr(5); // "56789" (从5到末尾)

insert() / erase()——修改字符串

string s = "Hello World"; s.insert(5, " beautiful"); // "Hello beautiful World" string t = "abcdef"; t.erase(2, 3); // "abf" (从2开始删3个)

字符串比较与转换

// 字符串可直接用 ==, <, > 比较（字典序） if ("abc" < "abd") { ... } // true // 数字与字符串互转 (C++11) string s1 = to_string(123); // "123" int n1 = stoi("456"); // 456 double d1 = stod("3.14"); // 3.14

C++11利器：auto + 范围for

auto——编译时类型推导

auto x = 42; // int auto y = 3.14; // double auto it = v.begin(); // vector<int>::iterator（省太多字了！） auto s = "hello"; // const char*

范围for——三种模式的记忆口诀

写法含义何时使用
for (auto x : v)拷贝每个元素值类型小，不需要修改
for (auto& x : v)引用每个元素需要修改原容器中的值
for (const auto& x : v)只读引用值类型大（如string）且不修改

实战模板：去重排序

vector<int> a(n); for (int i = 0; i < n; i++) cin >> a[i]; sort(a.begin(), a.end()); // 排序 auto last = unique(a.begin(), a.end()); // 去重 a.erase(last, a.end()); for (int i = 0; i < a.size(); i++) { cout << a[i] << " \n"[i == a.size() - 1]; }

实战模板：CSV字符串分割

string line; getline(cin, line); vector<string> fields; size_t pos; while ((pos = line.find(',')) != string::npos) { fields.push_back(line.substr(0, pos)); line.erase(0, pos + 1); } fields.push_back(line); // 最后一段

竞赛技巧

  • auto + 范围for 一起用，代码量减半
  • unique 只是把重复元素移到末尾，必须配合 erase 才能真正删除
  • 字符串分割时注意最后一段要单独处理

⚠️ 易错点——这些坑千万别踩

易错点1：vector越界访问

  • vector<int> v(5); 有 v[0] 到 v[4]，v[5] 就是越界！
  • 循环条件必须是 i < v.size()，不是 i <= v.size()

易错点2：忘记 include 头文件

  • vector 需要 #include <vector>
  • string 需要 #include <string>
  • 使用 sort/unique/find 需要 #include <algorithm>
  • 竞赛中可以用 #include <bits/stdc++.h> 一劳永逸

易错点3：混淆 size() 和 capacity()

  • size()：实际存储的元素数量
  • capacity()：已分配内存能容纳的元素数
  • reserve(100) 改capacity，不改size——此时 v[0] 仍然越界！

易错点4：string::npos 比较错误

  • find() 返回的是 size_t（无符号类型）
  • 正确：if (s.find(x) == string::npos)
  • 错误：if (s.find(x) < 0) —— 永远为false，因为无符号数不可能小于0

易错点5：cin >> 后直接 getline

  • cin >> n 在缓冲区留下了换行符
  • 紧接着的 getline(cin, s) 会读到空字符串
  • 解决方法：cin >> n; cin.ignore(); getline(cin, s);

真题精练

题目1：去重排序

给定n个整数（可能有重复），从小到大排序并输出去重后的结果。

输入样例：
8
3 1 4 1 5 9 2 6

输出样例：
7
1 2 3 4 5 6 9
#include <iostream> #include <vector> #include <algorithm> using namespace std; int main() { int n; cin >> n; vector<int> a(n); for (int i = 0; i < n; i++) cin >> a[i]; sort(a.begin(), a.end()); auto last = unique(a.begin(), a.end()); a.erase(last, a.end()); cout << a.size() << endl; for (int i = 0; i < a.size(); i++) { if (i > 0) cout << " "; cout << a[i]; } cout << endl; return 0; }

题目2：CSV字段解析

解析逗号分隔的字符串，每行输出一个字段。

输入样例： Zhang,San,15,Math,95
输出样例：
Zhang
San
15
Math
95
#include <iostream> #include <string> #include <vector> using namespace std; int main() { string line; getline(cin, line); vector<string> fields; size_t pos; while ((pos = line.find(',')) != string::npos) { fields.push_back(line.substr(0, pos)); line.erase(0, pos + 1); } fields.push_back(line); for (const auto& f : fields) cout << f << endl; return 0; }

竞赛建议

  • vector 是CSP-J中最常用的容器，几乎所有"不确定个数"的数组都用它
  • 学string高级操作，一劳永逸解决字符串解析题
  • auto 和范围for让代码更短、更少出错
  • 考前务必回顾五大易错点：越界、npos、include、cin.ignore、size vs capacity
