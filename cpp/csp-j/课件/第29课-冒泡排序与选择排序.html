一、冒泡排序原理

重复遍历，相邻逆序则交换；每轮把当前最大「冒」到末尾。

void bubbleSort(int a[], int n) { for (int i = 0; i < n - 1; i++) for (int j = 0; j < n - 1 - i; j++) if (a[j] > a[j+1]) swap(a[j], a[j+1]); }
  • 外层 n-1 轮
  • 内层 j < n-1-i：已排好的尾部不再比
  • 比较次数约 n(n-1)/2 → O(n²)
【讲解】气泡上浮类比。

二、冒泡过程模拟

数组 {5, 3, 8, 1, 9, 2}：

轮关键交换后状态本轮归位
13 5 1 8 2 99
23 1 5 2 8 98
………
51 2 3 5 8 9完成

初赛技巧

问「第 k 轮后」：只需模拟 k 轮，每轮把最大值沉到当前未排序区末尾。

【讲解】当堂手推第1、2轮。

三、冒泡优化：swapped

void bubbleSortOptimized(int a[], int n) { for (int i = 0; i < n - 1; i++) { bool swapped = false; for (int j = 0; j < n - 1 - i; j++) { if (a[j] > a[j+1]) { swap(a[j], a[j+1]); swapped = true; } } if (!swapped) break; // 已有序 } }
优化版最好 O(n)（已有序只扫一轮）；最坏仍 O(n²)。判断题常考「冒泡最优是 O(n)」——指带 early-stop 的版本。
【讲解】区分标准版与优化版。

四、选择排序原理

每轮在未排序区找最小值下标，与未排序区首元素交换。

void selectionSort(int a[], int n) { for (int i = 0; i < n - 1; i++) { int minIdx = i; for (int j = i + 1; j < n; j++) if (a[j] < a[minIdx]) minIdx = j; if (minIdx != i) swap(a[i], a[minIdx]); } }
  • 比较次数恒为 n(n-1)/2，与数据无关
  • 交换最多 n-1 次（每轮至多一次）
【讲解】前有序后无序分区。

六、排序稳定性

稳定：关键字相同的记录，排序后相对顺序不变。

算法稳定性原因
冒泡稳定仅 a[j] > a[j+1] 才交换；相等不换
选择不稳定跳跃交换打乱相同元素次序
例：{5ₐ, 8, 5ᵦ, 2} 选择排序第1轮 2 与 5ₐ 交换 → {2, 8, 5ᵦ, 5ₐ}，5ₐ 跑到 5ᵦ 后面。

陷阱

若冒泡写成 >= 则变成不稳定！

【讲解】成绩同分保持报名顺序的例子。

七、比较次数与交换次数

冒泡选择
比较次数最坏 n(n-1)/2；优最好 n-1恒为 n(n-1)/2
交换次数最坏≈比较次数；最好 0最多 n-1；最少 0
干扰项：「选择排序交换次数恒为 n(n-1)/2」——错！恒定的是比较次数。
【讲解】初赛选择题核心表。

八、三种 O(n²) 算法对比（含插入预告）

特性冒泡选择插入
基本操作相邻交换选最小交换插入有序区
最好时间O(n) 优化后O(n²)O(n)
最坏时间O(n²)O(n²)O(n²)
稳定性稳定不稳定稳定

九、代码模板

// 标准冒泡 for (int i=0; i<n-1; i++) for (int j=0; j<n-1-i; j++) if (a[j]>a[j+1]) swap(a[j], a[j+1]); // 优化冒泡：加 swapped，!swapped 则 break // 选择排序 for (int i=0; i<n-1; i++) { int minIdx = i; for (int j=i+1; j<n; j++) if (a[j]<a[minIdx]) minIdx=j; if (minIdx!=i) swap(a[i], a[minIdx]); }
【讲解】默写内层边界 n-1-i。

十、易错点

1. 比较 vs 交换混淆

选择：比较恒定，交换很少。

2. 内层忘记减 i

j < n-1-i，不减结果对但浪费且手算会错。

3. 稳定性条件

必须用严格 >；>= 破坏冒泡稳定性。

4. 最坏交换次数

冒泡逆序 ≈ n(n-1)/2；选择 ≪ 这个数。

【讲解】四易错对号入座。

十三、真题③：稳定性+次数

序列 A={4,2,4,1}：

  • 冒泡（> 才换）两 4 是否保持原序？→ stable

  • 选择交换次数？→ 2
