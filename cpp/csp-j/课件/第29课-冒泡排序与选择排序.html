冒泡排序与选择排序

基础排序算法 — 理解排序的本质与优化

掌握两种经典 O(n²) 排序算法的原理、代码实现与对比分析

第 29 课

冒泡排序 (Bubble Sort)

核心思想：相邻比较，逐步交换，大数"浮"到末尾

  • 执行过程：从第一个元素开始，依次比较相邻两个元素，如果前大后小则交换。每完成一轮，最大的元素会"浮"到数组末尾。
  • 轮次规律：n 个元素的数组，需要 n-1 轮扫描即可完成排序。
  • 优化技巧 — swapped 标志：如果某一轮中没有发生任何交换，说明数组已经有序，可以提前终止。最好情况（已有序）只需一轮 O(n)。

执行过程演示 — 数组 [5, 3, 8, 1, 2]

轮次比较过程本轮结果交换次数
第 1 轮5↔3, 5↔8(不换), 8↔1, 8↔2[3, 5, 1, 2, 8]3 次
第 2 轮3↔5(不换), 5↔1, 5↔2[3, 1, 2, 5, 8]2 次
第 3 轮3↔1, 3↔2[1, 2, 3, 5, 8]2 次
第 4 轮1↔2(不换)[1, 2, 3, 5, 8]0 次(可提前终止)
📝 考试技巧： CSP-J 初赛中常考排序过程模拟题——给一个数组，要求写出某轮排序后的结果。注意：每轮冒泡完成后，末尾已排好序的元素不再参与比较！

选择排序 (Selection Sort)

核心思想：每轮在未排序部分中选择最小元素，放到已排序部分的末尾

  • 执行过程：第 i 轮在区间 [i, n-1] 中找到最小元素的下标，将其与位置 i 的元素交换。每轮确定一个位置。
  • 与冒泡排序的区别：冒泡通过相邻交换"冒泡"，每轮可能交换多次；选择排序每轮只交换一次（找到最小值后再交换）。
  • 固定比较次数：无论数据如何，比较次数固定为 n(n-1)/2，交换次数固定为 n-1 次。

执行过程演示 — 数组 [5, 3, 8, 1, 2]

轮次查找范围最小值交换本轮结果
第 1 轮[0,4]a[3]=1a[0]↔a[3][1, 3, 8, 5, 2]
第 2 轮[1,4]a[4]=2a[1]↔a[4][1, 2, 8, 5, 3]
第 3 轮[2,4]a[4]=3a[2]↔a[4][1, 2, 3, 5, 8]
第 4 轮[3,4]a[3]=5不交换[1, 2, 3, 5, 8]

排序稳定性

什么是排序稳定性？

稳定排序：值相等的元素在排序前后，它们的相对顺序保持不变。不稳定排序：值相等的元素在排序后相对顺序可能改变。

冒泡排序 — 稳定

冒泡排序只在 a[j] > a[j+1] 时交换，相等时不交换，因此相等元素的相对顺序不变，是稳定排序。

选择排序 — 不稳定

选择排序最小值的"跳跃式交换"会破坏顺序。例如：

示例：数组 [(5, A), (5, B), 3] 执行选择排序
第一轮找最小值 3 (下标2)，将 a[0] 与 a[2] 交换 → [3, (5, B), (5, A)]
(5, A) 从前面跳到了后面，相对顺序改变 → 不稳定 
// 冒泡排序（稳定）：相等不交换
if (a[j] > a[j + 1]) { swap(a[j], a[j + 1]); }

// 选择排序（不稳定）：跨元素交换破坏顺序
int minIdx = i;
for (int j = i + 1; j < n; j++)
    if (a[j] < a[minIdx]) minIdx = j;
swap(a[i], a[minIdx]);  // 跳跃交换 → 不稳定
📝 考试技巧： CSP-J 中常考"哪些排序算法是稳定的？"答案：冒泡、插入、归并和计数排序是稳定的，选择、快速和堆排序是不稳定的。口诀："冒插归计稳如山，快选堆序容易翻"。

比较与交换次数分析

时间复杂度 O(n²) 的两种实现

算法比较次数交换次数最好情况最坏情况稳定性
冒泡排序n(n-1)/2（最坏）0~n(n-1)/2O(n) 优化版O(n²)✅ 稳定
选择排序n(n-1)/2（固定）n-1（固定）O(n²)O(n²)❌ 不稳定

详细分析

  • 冒泡排序：比较次数 = (n-1) + (n-2) + ... + 1 = n(n-1)/2。加入 swapped 优化标志后，最好情况（已有序）只需一轮比较 n-1 次，时间复杂度 O(n)。
  • 选择排序：无论数据如何，比较次数始终为 n(n-1)/2。交换次数固定为 n-1 次，这在元素移动代价高（如交换大型结构体）时有优势。
  • 空间复杂度：两者都是 O(1)，原地排序。
📝 考试技巧： 选择题中若问"对 n 个元素排序，比较次数与初始排列无关的是？"答案：选择排序。因为无论数据怎样，选择排序的比较次数永远是 n(n-1)/2，不会减少。

代码模板

冒泡排序模板（含优化与计数器）

// 冒泡排序 — 优化版（含比较/交换计数器）
void bubbleSort(int a[], int n) {
    int cmpCnt = 0, swpCnt = 0;
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            cmpCnt++;
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swpCnt++;
                swapped = true;
            }
        }
        if (!swapped) break;  // 提前终止
    }
    // cmpCnt: 比较次数, swpCnt: 交换次数
}

选择排序模板（含计数器）

// 选择排序（含比较/交换计数器）
void selectionSort(int a[], int n) {
    int cmpCnt = 0, swpCnt = 0;
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            cmpCnt++;
            if (a[j] < a[minIdx]) minIdx = j;
        }
        if (minIdx != i) {
            swap(a[i], a[minIdx]);
            swpCnt++;
        }
    }
}

本课小结

  • 冒泡排序：相邻比较交换，每轮最大值"浮"到末尾。加入 swapped 标志可优化到最好情况 O(n)。
  • 选择排序：每轮选未排序部分的最小值，与当前位置交换。比较次数固定 O(n²)，交换次数固定 n-1。
  • 稳定性：冒泡稳定（相等不交换），选择不稳定（跳跃交换破坏顺序）。
  • 时间复杂度：两者均为 O(n²)，空间复杂度 O(1)。
  • 实用建议：实际竞赛中不推荐手写这两种排序，直接用 sort() 更高效，但初赛模拟题必考，需熟练掌握过程。
