一、关系运算符

比较两个值，结果为 bool：true→1，false→0。

运算符含义示例结果
>大于5 > 3true
<小于5 < 3false
>= / <=大于等于 / 小于等于5 >= 5true
==等于5 == 5true
!=不等于5 != 3true
// 结果可参与算术 cout << (5 > 3) + 10; // 11 // 字符按 ASCII 'A' < 'B' // true (65<66) 'a' > 'A' // true (97>65)
== 与 = ：
if (a = 5) 赋值且恒真
if (a == 5) 判断相等
禁止数学链式：
0 < x < 10 实际是 (0<x)<10 几乎恒真
正确：0 < x && x < 10
【讲解】Demo1。浮点用 fabs 误差比较，少用 ==。

二、逻辑运算符与真值表

aba && ba || b!a
TTTTF
TFFTF
FTFTT
FFFFT

T=true(非0), F=false(0)

  • && 逻辑与：两边都真才真
  • || 逻辑或：至少一边真就真
  • ! 逻辑非：取反
  • 非 0 即真：5、-1 为真；0 为假
if (5) { } // 真 if (0) { } // 假 if (3 && 0) { } // 假 if (3 || 0) { } // 真
逻辑 vs 按位（预告）：4&&2=1，但 4&2=0（0100&0010）。判断真假用 &&||，拆二进制用 &|。
【讲解】Demo2。!!5 规范化为 1；!5=0，~5=-6。

三、短路特性 （考试重点）

  • &&：左边已 false → 右边不计算
  • ||：左边已 true → 右边不计算
// 安全除法 / 安全下标（先判合法性） if (b != 0 && a / b > 10) { } if (i >= 0 && i < n && arr[i] > 0) { } // 反了会崩：if (a/b>10 && b!=0)

经典：int a=0,b=0; if(a++ && b++) a++;

步骤操作ab
①a++ 取值 0（假），a→110
②&& 短路，b++ 不执行10
③条件假，if 体不进10

输出：1 0

【讲解】Demo3。再对比 ||：a++||b++ 两边都执行得 1 1；左真短路 e++||f++ → e=3 f=0。

四、短路对比 · || 与赋值副作用

int a = 0, b = 0; if (a++ || b++) { } // a++ 用0假→a=1 // 左假必须算 b++→b=1 // 0||0 假 → a=1 b=1 int c = 1, d = 0; if (c++ || d++) c++; // c++ 用1真→c=2 // 短路 d++ 不执行 // 进 if，c++ → c=3 d=0
int x = 0, y = 5; int r3 = x && (y = 100); // x=0 短路，y 仍5，r3=0 int r4 = x || (y = 100); // x假，执行 y=100，r4=1 // 最终 y=100
分析顺序：先看后置自增「用什么值、变量变成几」→ 再判断是否短路 → 再看 if 体是否进入。
【讲解】真题3拓展：r1 r2 r3 y r4 → 1 1 0 100 1。

五、位运算符基础

预备：5 = 0101₂，3 = 0011₂（示低4位）

运算符名称示例规则
&按位与5 & 3 = 1全1才1
|按位或5 | 3 = 7有1就1
^按位异或5 ^ 3 = 6不同为1
~按位取反~5 = -60↔1（补码）
<<左移5 << 1 = 10≈ ×2k
>>右移5 >> 1 = 2≈ ÷2k（正数）
& 无短路，&& 有短路；对象：每一位 vs 真假整体。
移位：1<<40 危险 → 用 1LL<<40；有符号右移实现定义，竞赛尽量只对非负右移。
【讲解】Demo4。~0=-1。先画二进制再算。

六、位运算经典技巧

// 1. 判奇偶 if (n & 1) { /* 奇 */ } else { /* 偶 */ } // 2. 判 2 的幂（二进制只有一个 1） if (n > 0 && (n & (n - 1)) == 0) { } // 3. 取 / 置 / 翻 第 k 位（k 从 0，最低位） int bit = (n >> k) & 1; n |= (1 << k); // 置 1 n &= ~(1 << k); // 置 0 n ^= (1 << k); // 翻转 // 4. 去掉最低的 1 · lowbit n = n & (n - 1); int lowbit = n & -n; // 树状数组常用 // 5. 异或交换（a、b 不能是同一变量） a ^= b; b ^= a; a ^= b;
【讲解】Demo5。编程题奇偶+2的幂组合常考。

七、三目运算符 ?:

语法：条件 ? 表达式1 : 表达式2 — 真取1，假取2。

int maxVal = (a > b) ? a : b; int absX = (x >= 0) ? x : -x; cout << ((n & 1) ? "奇数" : "偶数"); string s = (score >= 60) ? "及格" : "不及格"; // 右结合嵌套：成绩等级 char g = (score >= 90) ? 'A' : (score >= 80) ? 'B' : (score >= 70) ? 'C' : (score >= 60) ? 'D' : 'E';
右结合：a?b:c?d:e = a?b:(c?d:e)
简单二选一用三目；逻辑复杂用 if-else。两分支类型应兼容。
【讲解】模板3。嵌套时建议加括号或改 if。

八、混合表达式与优先级回顾

// 关系优先于逻辑 if (a > 0 && b > 0) // (a>0) && (b>0) // && 优先于 || if (a || b && c) // a || (b && c) // 位运算建议一律加括号 if ((x & 1) && (y > 0)) { } // 三目低于逻辑，赋值更低 int z = (x > y) ? x : y;
对比逻辑按位
与 / 或 / 非&&   ||   !&   |   ~
对象真假（整体）每一个二进制位
短路有无
铁律：位运算、混合逻辑、三目嵌套时，多写括号。逗号运算符了解即可（for 里常见）。
【讲解】与第5课优先级衔接。不确定就加括号。

九、代码模板

#include <iostream> using namespace std; int main() { // 关系 + 区间 + 短路保护 int x = 5, den = 0; if (0 < x && x < 10) cout << "in range\n"; if (den != 0 && 100 / den > 1) { } else cout << "safe\n"; int p = 0, q = 0; if (p++ && q++) { } cout << p << " " << q << endl; // 1 0 // 位运算技巧 int n = 8; cout << (n & 1 ? "odd" : "even"); if (n > 0 && (n & (n-1)) == 0) cout << " power2"; cout << endl; int a = 10, b = 20; cout << ((a > b) ? a : b) << endl; // 20 return 0; }

十、易错点清单

十三、本课小结

类别核心要点
关系> < >= <= == !=；禁止链式比较
逻辑&& || !；非0即真
短路&& 左假跳右；|| 左真跳右
位运算& | ^ ~ << >>；左移≈×2，右移≈÷2
技巧n&1 奇偶；n&(n-1)==0 二的幂
三目cond?a:b；右结合可嵌套
核心区分：
🔹 &（按位，无短路）vs &&（逻辑，有短路）
🔹 | vs || 同理
🔹 第5课「算多少」+ 第6课「判真假 / 拆二进制」→ 为 if/while 打基础
