一、关系运算符 & 逻辑运算符

关系运算符（比较大小）

运算符含义
>大于
<小于
>=大于等于
<=小于等于
==等于
!=不等于

结果为 bool 类型（true/false）

逻辑运算符 & 真值表

ABA && BA || B!A
TTTTF
TFFTF
FTFTT

T=true(非0), F=false(0)

短路特性详解（高频考点）

  • &&（逻辑与）：左边为 false 时，右边不执行（因为结果已确定）
  • ||（逻辑或）：左边为 true 时，右边不执行（因为结果已确定）

二、位运算符详解

运算符名称示例运算规则
&按位与5 & 3 = 1两1则1，有0则0
|按位或5 | 3 = 7有1则1，两0则0
^按位异或5 ^ 3 = 6相同为0，不同为1
~按位取反~5 = -60变1，1变0
<<左移5 << 2 = 20左移n位 = 乘以 2ⁿ
>>右移20 >> 2 = 5右移n位 = 除以 2ⁿ

经典位运算应用

  • 判断奇偶：n & 1 — 结果为 1 是奇数，0 是偶数
  • 判断 2 的幂：n > 0 && (n & (n - 1)) == 0 — 真则是 2 的整数次幂
  • 交换两数（无临时变量）：a ^= b; b ^= a; a ^= b;
  • 获取第 k 位：(n >> k) & 1 — 结果为 0 或 1
区分：&（按位与）和 &&（逻辑与）完全不同！
& 按位运算，不短路；&& 逻辑运算，有短路。

三、三目运算符 （?:）

基本语法：

条件 ? 表达式1 : 表达式2

如果条件为 true（非0），执行表达式1；否则执行表达式2。

常见用法

// 求最大值 int max = (a > b) ? a : b; // 求绝对值 int abs_val = (x >= 0) ? x : -x; // 嵌套三目（注意右结合性） int result = (score >= 90) ? 1 : (score >= 60) ? 2 : 3; // score>=90 →1; score>=60 →2; 否则 →3

关键性质：三目运算符是 右结合 的。a ? b : c ? d : e 等价于 a ? b : (c ? d : e)。

提醒：三目运算符的两个表达式类型应尽量一致，否则会发生隐式类型转换，可能导致意外结果。

五、真题练习一：逻辑短路

题目：阅读以下代码，求最终 a, b 的值。

int a = 0, b = 0; if (a++ && b++) a++;

逐行分析

步骤操作ab说明
初始声明00—
①a++（后置）0→10取值 0（false），然后 a 自增为 1
②短路！10a++ 为 false，b++ 不执行
③短路！10整个条件为 false，if 体 a++ 不执行

最终答案：a = 1，b = 0

关键：a++ 先用 0（false），导致 && 短路，b++ 根本不执行！这就是逻辑短路的经典考题。

六、真题练习二：位运算 + 三目

题目：阅读以下代码，求最终 z 的值。

int x = 5, y = 3; int z = (x & y) ? (x << 1) : (y << 1);

逐步分析

步骤表达式计算结果
①x & y5 (0101) & 3 (0011)1 (0001) — 真
②条件为真执行 : 前面的表达式执行 x << 1
③x << 15 (0101) 左移 1 位 → 101010

最终答案：z = 10   (x=5, y=3 未改变)

思路：①先算 x & y：5(101₂) & 3(011₂) = 1 ≠ 0，∴ 条件为 true
②执行 x << 1：5 × 2 = 10
③因此 z = 10。注意 & 是位与，不是 &&！

七、本课小结

运算符类别核心要点
关系运算符> < >= <= == !=，结果为 bool
逻辑运算符&& || !，&& 左false短路，|| 左true短路
位运算符& | ^ ~ << >>，左移=乘2，右移=除2
位运算经典应用n&1判奇偶、n&(n-1)==0判2的幂、异或交换
三目运算符条件 ? 表达式1 : 表达式2，右结合
本课核心区分：
🔹 &（按位与，无短路） vs &&（逻辑与，有短路）— 完全不同！
🔹 |（按位或，无短路） vs ||（逻辑或，有短路）— 完全不同！
🔹 短路特性实战：用 ptr != NULL && ptr->data > 0 安全访问指针
🔹 三目嵌套是右结合：a?b:c?d:e = a?b:(c?d:e)
