一、等差数列与等比数列

等差：公差 d，通项 aₙ = a₁+(n-1)d

前 n 项和 Sₙ = n(a₁+aₙ)/2

long long arithmeticSum(long long a1, long long d, long long n) { long long an = a1 + (n - 1) * d; return n * (a1 + an) / 2; }

等比：公比 q，通项 aₙ = a₁·qⁿ⁻¹；q≠1 时 Sₙ = a₁(1-qⁿ)/(1-q)

口诀：等差数对乘，等比指数幂。qⁿ 可用快速幂（第36课）。注意 long long 防溢出。
【讲解】数列 高斯求和故事可一提。

二、递推关系 · 斐波那契

F(1)=F(2)=1，F(n)=F(n-1)+F(n-2)

// 迭代 O(n) O(1) 空间 — 竞赛推荐 long long fib(int n) { if (n <= 2) return 1; long long a = 1, b = 1, c; for (int i = 3; i <= n; i++) { c = (a + b) % MOD; a = b; b = c; } return b; }
禁止裸递归 Fib：指数级重复计算。每步取模；MOD 常用 1e9+7。
【讲解】递推本质：当前由过去推出。对照 lesson35 demo_fibonacci。

卡特兰数入门

C₀=1，Cₙ₊₁ = Σ Cᵢ·Cₙ₋ᵢ（i=0..n）

前几项：1, 1, 2, 5, 14, 42, 132…

long long catalan(int n) { vector<long long> C(n + 1, 0); C[0] = 1; for (int i = 1; i <= n; i++) for (int j = 0; j < i; j++) C[i] += C[j] * C[i - 1 - j]; return C[n]; }
  • 应用：合法括号序列数、二叉树形态数、凸多边形三角剖分等
  • 解题：分析关系式 → 初值 → 递推方向 → 取模
【讲解】卡特兰 CSP-J 了解公式与应用即可。

三、一维前缀和

定义 pre[i] = a[1]+…+a[i]，则 sum(l,r) = pre[r] − pre[l−1]

for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] + a[i]; // 查询 [l,r] long long rangeSum = pre[r] - pre[l - 1];
场景：多次区间求和；数组不变、查询多。预处理 O(n)，每次查询 O(1)。下标建议从 1 开始，避免 l-1 越界。
【讲解】前缀和 画数轴示意减左边。

二维前缀和

构建：pre[i][j] = pre[i-1][j] + pre[i][j-1] − pre[i-1][j-1] + a[i][j]

矩形 (x1,y1)–(x2,y2)：

sum = pre[x2][y2] − pre[x1-1][y2] − pre[x2][y1-1] + pre[x1-1][y1-1]

for (int i = 1; i <= n; i++) for (int j = 1; j <= m; j++) pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j];
容斥：减上、减左，左上减了两次要加回。与一维一样：空间换时间。
【讲解】二维 画 2x2 方格演示容斥。

四、差分数组

差分是前缀和的逆运算：多次区间修改，最后统一查询。

对 [l,r] 全体 +x：仅 d[l]+=x，d[r+1]-=x

vector<int> d(n + 2, 0); d[l] += x; d[r + 1] -= x; // 区间加 for (int i = 1; i <= n; i++) { d[i] += d[i - 1]; // 还原后 d[i] 即 a[i] }
选择口诀：多次查询 → 前缀和；多次区间修改 → 差分。
【讲解】差分 延迟计算思想。

前缀和 ↔ 差分关系

操作结构单次复杂度
区间求和（数组不变）前缀和O(1) 查询
区间加减（最后查）差分O(1) 修改
既改又查频繁树状数组/线段树（提高）—
  • 前缀和的差分 = 原数组
  • 差分数组的前缀和 = 原数组
  • 注意 d 数组开 n+2，防 r+1 越界
【讲解】互逆关系 加深记忆。

代码模板合集

// Fib 取模 + 一维前缀 + 差分 核心行 c = (a + b) % MOD; pre[i] = pre[i-1] + a[i]; sum = pre[r] - pre[l-1]; d[l] += x; d[r+1] -= x;
// 二维查询一行记牢 s = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1];
累加与 pre 建议 long long；取模时注意负数 (x%MOD+MOD)%MOD。
【讲解】模板页 让学生齐背公式。

真题精练①

区间和查询

给定 n 个数与 q 次询问，每次给 l,r 求区间和。n,q ≤ 1e5。

做法：建一维前缀和，每次 O(1) 输出 pre[r]-pre[l-1]。

矩形区域和

n×m 矩阵，多次询问子矩形和。→ 二维前缀和容斥。

【讲解】真题 强调为何不能每次暴力 O(n)。

真题精练②

区间加最后输出序列

初始全 0，q 次操作 [l,r]+=x，最后输出 a[1..n]。→ 差分 + 一次前缀还原。

斐波那契第 n 项

n ≤ 1e6，对 1e9+7 取模。→ 迭代递推，禁止指数递归。

【讲解】差分题画 d 数组小例子。

易错点

  • 前缀和下标从 0/1 混用，l-1 越界
  • 二维容斥漏加左上角
  • 差分 r+1 未开空间 / 最后忘记前缀还原
  • Fib 递归爆栈/超时；忘记取模
  • 等差求和公式写成等比；int 溢出
检查：边界 l=1、整段 [1,n]、空修改、n=1。
【讲解】易错清单

本课小结

  • 等差/等比：通项 + 求和，注意溢出与快速幂。
  • 递推：迭代写 Fib/Catalan，分析关系式与初值。
  • 前缀和：多次区间和；二维用容斥。
  • 差分：多次区间改；与前缀和互逆。
  • 口诀：多查前缀，多改差分。
