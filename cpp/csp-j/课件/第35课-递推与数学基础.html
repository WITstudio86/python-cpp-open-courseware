一、等差数列与等比数列

等差数列

通项公式：an = a1 + (n-1)d

前 n 项和：Sn = n(a1 + an) / 2

long long arithmeticSum(long long a1, long long d, long long n) { long long an = a1 + (n - 1) * d; return n * (a1 + an) / 2; }

等比数列

通项公式：an = a1 × qn-1

前 n 项和：Sn = a1(1 - qn) / (1 - q)（q ≠ 1）

记住高斯求和公式：（首项 + 末项）× 项数 ÷ 2，这是等差数列和的最快求法！

二、递推关系

斐波那契数列

定义：F(1)=1, F(2)=1, F(n)=F(n-1)+F(n-2)

int fib(int n) { if (n <= 2) return 1; int a = 1, b = 1, c; for (int i = 3; i <= n; i++) { c = a + b; a = b; b = c; } return b; }

卡特兰数

递推：C0=1, Cn+1 = Σ Ci × Cn-i

前几项：1, 1, 2, 5, 14, 42, 132...

应用：合法括号序列、二叉树形态数、凸多边形三角剖分

注意：斐波那契数列从第93项起超出 long long 范围！考试中几乎都需要取模。

三、前缀和（Prefix Sum）

核心公式

构建：pre[i] = pre[i-1] + a[i]

查询 [l, r] 的和：sum = pre[r] - pre[l-1]

一维前缀和代码模板

vector<long long> pre(n + 1, 0); for (int i = 1; i <= n; i++) { pre[i] = pre[i - 1] + a[i]; } // 查询 O(1) long long sum = pre[r] - pre[l - 1];

二维前缀和

构建：pre[i][j] = pre[i-1][j] + pre[i][j-1] − pre[i-1][j-1] + a[i][j]

查询 (x1,y1) 到 (x2,y2)：sum = pre[x2][y2] − pre[x1-1][y2] − pre[x2][y1-1] + pre[x1-1][y1-1]

// 二维前缀和构建 for (int i = 1; i <= n; i++) for (int j = 1; j <= m; j++) pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j]; // 查询 O(1) long long sum = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1];
前缀和的思想是"空间换时间"，用 O(n) 的预处理换取 O(1) 的查询。二维公式记住"容斥原理"：加奇数层，减偶数层。

四、差分数组（Difference Array）

核心思想

差分是前缀和的逆运算：d[i] = a[i] - a[i-1]

区间 [l, r] 加上 x 只需要操作两步：

d[l] += x,    d[r+1] -= x

最后对 d 求前缀和，即可还原修改后的数组。

vector<long long> d(n + 2, 0); // 多开一位防越界 // 构建差分数组 for (int i = 1; i <= n; i++) d[i] = a[i] - a[i - 1]; // 区间 [l,r] 加上 x — 仅需 O(1)！ d[l] += x; d[r + 1] -= x; // 还原 — O(n) for (int i = 1; i <= n; i++) { d[i] += d[i - 1]; // 此时 d[i] 就是修改后的 a[i] }
易错：差分数组大小必须为 n+2，因为要对 r+1 位置操作。如果 r = n，r+1 = n+1 需要有效的数组位置！

前缀和 vs 差分 对比

前缀和差分
适用场景多次查询区间和多次区间修改，最后查询
预处理O(n)O(n)
操作复杂度查询 O(1)修改 O(1)

五、真题示例

题目：区间和查询（CSP-J 风格）

给定长度为 n 的序列和 q 个询问，每个询问给出 [l, r]，输出区间和。n, q ≤ 105。

完整 AC 代码

#include <iostream> #include <vector> using namespace std; typedef long long ll; int main() { ios::sync_with_stdio(false); cin.tie(nullptr); int n, q; cin >> n >> q; vector<ll> pre(n + 1, 0); for (int i = 1; i <= n; i++) { ll x; cin >> x; pre[i] = pre[i - 1] + x; } while (q--) { int l, r; cin >> l >> r; cout << pre[r] - pre[l - 1] << '\n'; } return 0; }
数据范围 n, q ≤ 105 意味着 O(nq) = 1010 必定超时。前缀和将每次查询降为 O(1)，总复杂度 O(n+q) 完美通过。

六、本课总结

核心技能清单

知识点核心公式复杂度
等差数列和Sn = n(a1+an)/2O(1)

解题思路

  1. 多次查询区间和 → 前缀和
  2. 多次修改区间值 → 差分数组
  3. 递推关系 → 找递推式 → 确定初始值 → 迭代求解 → 记得取模
考场口诀：查和多，用前缀；改区间，用差分；推数列，要取模；下标从1，防越界。
