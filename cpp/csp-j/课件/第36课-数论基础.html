一、质数判断 — 试除法

核心原理

如果 n 有因子 d > √n，则必有对应的因子 n/d < √n。只需检测到 √n！

bool isPrime(long long n) { if (n < 2) return false; // 0 和 1 不是质数 if (n == 2) return true; // 2 是唯一的偶质数 if (n % 2 == 0) return false; // 排除其他偶数 for (long long i = 3; i * i <= n; i += 2) { if (n % i == 0) return false; } return true; }

时间复杂度分析

  • 普通遍历 2 到 n-1：O(n) — 太慢
  • 只遍历到 √n：O(√n) — 当 n=109 时只需约 15000 次
  • 再优化只查奇数：大约再减少一半
注意溢出：循环条件 i * i <= n 在 n 接近 INT_MAX 时可能溢出！建议用 long long i 或改为 i <= n / i。

二、质数筛法

埃氏筛法 — O(n log log n)

vector<int> eratosthenes(int n) { vector<bool> isPrime(n + 1, true); isPrime[0] = isPrime[1] = false; for (int i = 2; i * i <= n; i++) { if (isPrime[i]) { for (int j = i * i; j <= n; j += i) // 从 i*i 开始！ isPrime[j] = false; } } // 收集质数... }

线性筛法 — O(n)

核心思想：每个合数只被它的最小质因子筛掉。

for (int i = 2; i <= n; i++) { if (isPrime[i]) primes.push_back(i); for (int p : primes) { if (i * p > n) break; isPrime[i * p] = false; if (i % p == 0) break; // 关键行！ } }
埃氏筛从 i×i 开始标记，因为更小的倍数已被之前的质数筛过。线性筛的关键是 i%p==0 时 break，保证每个合数只被标记一次。

三、GCD 与 LCM

最大公约数 GCD — 辗转相除法

原理：gcd(a, b) = gcd(b, a mod b)，直到 b=0

// 递归版（最简洁） int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); } // 迭代版（无递归开销） int gcd_iter(int a, int b) { while (b != 0) { int t = b; b = a % b; a = t; } return a; }

最小公倍数 LCM

公式：lcm(a, b) = a × b / gcd(a, b)

long long lcm(long long a, long long b) { return a / gcd(a, b) * b; // 先除后乘，防溢出！ }
致命错误：计算 LCM 时直接 a * b / gcd(a,b)，当 a=b=109 时 a×b=1018 溢出！必须先除后乘：a / gcd(a,b) * b。

复杂度

辗转相除法的时间复杂度为 O(log min(a,b))，非常高效。

【讲解】三、GCD 与 LCM 结合讲义《二、最大公约数（GCD）与最小公倍数（LCM）》强调： · 求最大公约数的经典算法，基于一个简单的数学原理： · $$\gcd(a, b) = \gcd(b, a \bmod b)$$ · 当 $b = 0$ 时，$\gcd(a, 0) = a$。 · // 迭代版 · int gcd(int a, int b) { 幻灯片上可见要点： · 原理： gcd(a, b) = gcd(b, a mod b) ，直到 b=0 · 公式： lcm(a, b) = a × b / gcd(a, b) · 致命错误： · 必须先除后乘： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

四、快速幂（二分求幂）

核心思想

利用指数的二进制表示，将幂次拆解为 2 的幂之和：

a13 = a8 × a4 × a1（13 = 11012）

时间复杂度从 O(b) 降为 O(log b)！

迭代版（最常用）

long long quickPow(long long a, long long b, long long mod) { long long res = 1; a %= mod; while (b > 0) { if (b & 1) res = res * a % mod; // 二进制位为 1 时乘入 a = a * a % mod; // a = a^2, a^4, a^8... b >>= 1; // 指数右移一位 } return res; }

递归版（更直观）

long long quickPowRec(long long a, long long b, long long mod) { if (b == 0) return 1; long long half = quickPowRec(a, b / 2, mod); half = half * half % mod; if (b % 2 == 1) half = half * a % mod; return half; }
快速幂的迭代版在竞赛中最常用：无递归栈开销、代码简洁。每一步乘法后立刻 % mod 是防止中间结果溢出的关键。
【讲解】四、快速幂（二分求幂） 结合讲义《三、快速幂（Binary Exponentiation）》强调： · 计算 $a^b \bmod m$，如果直接用循环乘 $b$ 次，复杂度为 $O(b)$。当 $b$ 很大（如 $b \leq 10^9$）时，这显然不可接受。快速幂利用二分思想，将指数按二进制拆解： · $$a^b = a^{b_0 \cdot 2^0} \times a^{b_1 \cdot 2^1} \times \cdots \times a^{b_k \cdot 2^k}$$ · 其中 $b_i$ 是 $b$ 的二进制第 $i$ 位。实际操作时，我们自底向上计算 $a^{2^i}$，并根据 $b$ 的每一位是否为 1 决定是否将当前结果乘入答案。 · 迭代写法（最常用）： · long long quickPow(long long a, long long b, long long mod) { 幻灯片上可见要点： · 利用指数的二进制表示，将幂次拆解为 2 的幂之和： · a 13 = a 8 × a 4 × a 1 （13 = 1101 2 ） · 时间复杂度从 O(b) 降为 O(log b)！ 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

五、约数 / GCD真题

求一个数的所有约数

vector<long long> getDivisors(long long n) { vector<long long> divs; for (long long i = 1; i * i <= n; i++) { if (n % i == 0) { divs.push_back(i); if (i != n / i) divs.push_back(n / i); // 成对 } } sort(divs.begin(), divs.end()); return divs; }

六、数论易错点

易错点错误做法正确做法
试除法循环溢出 i * i <= n 用 int，n 接近 2×109 时溢出 用 long long i 或 i <= n / i
LCM 先乘后除 a * b / gcd(a,b) a / gcd(a,b) * b
快速幂 res=0 累乘从 0 开始 res 初始化为 1（乘法的单位元）

核心技能清单

知识点核心方法时间复杂度
