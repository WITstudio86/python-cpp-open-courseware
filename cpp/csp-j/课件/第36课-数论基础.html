一、试除法判质数

质数：>1 且只有 1 与自身两个正因数。

bool isPrime(long long n) { if (n < 2) return false; if (n == 2) return true; if (n % 2 == 0) return false; for (long long i = 3; i * i <= n; i += 2) if (n % i == 0) return false; return true; }
  • 只需检查到 √n（因子成对）
  • 2 特判，其后只试奇数
  • i 用 long long，防 i*i 溢出
【讲解】对照 lesson36 demo_is_prime。

埃氏筛（埃拉托斯特尼）

找 1..n 全部质数：质数的倍数皆合数。

vector<bool> isP(n+1, true); isP[0] = isP[1] = false; for (int i = 2; i * i <= n; i++) if (isP[i]) for (int j = i * i; j <= n; j += i) isP[j] = false;
为何从 i*i 起标？更小的倍数 2i,3i,… 已被更小质数筛过。复杂度约 O(n log log n)。
【讲解】筛法 手动画 1..30 演示。

线性筛（欧拉筛）

每个合数只被最小质因子筛一次 → O(n)。

vector<int> primes; vector<bool> isP(n+1, true); isP[0] = isP[1] = false; for (int i = 2; i <= n; i++) { if (isP[i]) primes.push_back(i); for (int p : primes) { if ((long long)i * p > n) break; isP[i * p] = false; if (i % p == 0) break; // 关键：最小质因子 } }
关键行：if (i % p == 0) break; 保证每个合数只被最小质因子标记。
【讲解】线性筛 对比埃氏重复标记。

二、GCD 与 LCM

欧几里得：gcd(a,b)=gcd(b, a mod b)，gcd(a,0)=a。

int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); } // 迭代：while(b){ t=b; b=a%b; a=t; } return a; long long lcm(long long a, long long b) { return a / gcd(a, b) * b; // 先除后乘防溢出！ }
错误写法 a*b/gcd 在 a=b=1e9 时中间溢出。C++17 有 std::gcd，竞赛常手写。
【讲解】GCD 手推 gcd(48,18)。

三、快速幂

求 a^b mod m，O(log b)。按二进制拆指数。

long long quickPow(long long a, long long b, long long mod) { long long res = 1; a %= mod; while (b > 0) { if (b & 1) res = res * a % mod; a = a * a % mod; b >>= 1; } return res; }
  • b&1：当前最低位为 1 则乘入答案
  • 每步乘法后取模，防溢出（极端情况用 __int128）
  • b=0 时返回 1（0^0 题面约定）
【讲解】快速幂 画 3^13 二进制。

快速幂递归版 + 注意点

long long quickPow(long long a, long long b, long long mod) { if (b == 0) return 1; long long half = quickPow(a, b / 2, mod); half = half * half % mod; if (b % 2) half = half * a % mod; return half; }
考试优先迭代版：无栈风险、常数好。mod 为 1 时任何数 ^ 次幂 ≡ 0（a%1==0），注意题面。
【讲解】两种写法等价。

四、约数与倍数

vector<int> getDivisors(int n) { vector<int> divs; for (int i = 1; i * i <= n; i++) if (n % i == 0) { divs.push_back(i); if (i != n / i) divs.push_back(n / i); } sort(divs.begin(), divs.end()); return divs; }
  • n 是 m 的倍数 ⇔ n % m == 0
  • 完全平方数时 i == n/i 勿重复加入
  • 约数个数可在筛法中预处理（进阶）
【讲解】约数成对。

a,b,p 可达 1e9/1e18。→ 快速幂；乘法注意溢出。

约数和/个数

枚举 √n 成对累加。或结合筛法预处理（范围允许时）。

【讲解】快速幂题必考取模位置。

易错点

  • 1 被判为质数；0、负数未处理
  • i*i 用 int 溢出（n 大时）
  • 埃氏筛内层从 2*i 而非 i*i（慢但不错）；漏标 isP[0/1]
  • 线性筛忘记 if(i%p==0) break
  • LCM 先乘后除溢出；GCD 参数未取绝对值（负）
  • 快速幂未边乘边模；b 用 int 右移错误类型
【讲解】易错

本课小结

  • 单点判质 O(√n)；批量用筛法。
  • 线性筛核心：最小质因子只筛一次。
  • gcd 辗转相除；lcm = a/gcd*b。
  • 快速幂 O(log b)，迭代优先。
  • 约数枚举到 √n，注意完全平方。
