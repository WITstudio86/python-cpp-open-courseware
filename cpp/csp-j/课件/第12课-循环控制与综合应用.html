一、break：跳出当前层循环

作用：立即终止当前循环

for (int i = 1; i <= 10; i++) { if (i == 5) { break; // i=5 时立刻跳出整个循环 } cout << i << " "; } // 输出：1 2 3 4

核心特性

  • 只跳出最近一层循环（嵌套中外层不受影响）
  • break 之后循环体中剩余代码不执行
  • 也用于 switch 语句跳出

经典应用：素数判断

for (int i = 2; i * i <= n; i++) { if (n % i == 0) { isPrime = false; break; // 找到因子立刻退出 } }
考试技巧："找到即退出"的优化场景必须用 break，不然后面白跑很多次。

二、continue：跳过本次迭代

作用：跳过当前迭代剩余代码，进入下一次迭代

for (int i = 1; i <= 10; i++) { if (i % 2 == 0) { continue; // 遇到偶数跳过 } cout << i << " "; } // 输出：1 3 5 7 9

关键注意：for vs while 中的 continue

for 循环（安全）

for (int i=1; i<=5; i++) { if (i==3) continue; cout << i; } // i++ 照常执行！

while 循环（危险！）

while (i <= 5) { if (i==3) continue; cout << i; i++; } // 跳过 i++ → 死循环！
高频陷阱：while 循环中 continue 直接跳到条件判断，可能跳过变量更新导致死循环。先用 i++ 再用 continue！

四、真题精练

真题1：程序阅读 - break/continue 效果判断

阅读以下程序，写出最终输出结果。

int sum = 0; for (int i = 1; i <= 10; i++) { if (i % 3 == 0) continue; if (i == 8) break; sum += i; } cout << sum;

变量追踪表格法

ii%3==0?i==8?操作sum
1否否sum+=11
2否否sum+=23
3是(continue)—跳过3
4否否sum+=47
5否否sum+=512
6是(continue)—跳过12
7否否sum+=719
8否是(break)终止19
最终输出：19（1+2+4+5+7=19，3和6跳过，8时终止）

五、本课小结

学习要点核心记忆
break 作用立即终止当前层循环，后续迭代不再执行
continue 作用跳过本次迭代剩余代码，进入下一次迭代
for 中的 continue更新表达式（i++）仍会执行
while 中的 continue直接跳回条件判断，小心跳过变量更新导致死循环
break 在嵌套中只跳出最近一层，外层不受影响（高频考点）
图形打印核心先空格再星号，公式对了代码就对了一半
程序阅读方法变量追踪表格法：逐行记录，汇总输出

易错点速记

⚠️ break 只跳出当前层，不是所有层
⚠️ while + continue 跳过 i++ 会死循环
⚠️ 混淆 break（终止循环）和 continue（跳过本次）
⚠️ 内层 break 对外层迭代次数无影响
⚠️ 图形打印内层循环条件写 n 而非 i
⚠️ 只眼看不走表格 → 程序阅读丢分
