C 风格字符串

char 数组 · '\0' · strlen/strcpy/strcat/strcmp · 回文

🎯 考纲：C 风格字符串本质；输入输出选型；四大库函数；回文与字符统计。现代 C++ 更推荐 string（下节），但底层规则必须会。
【开场】配套 lesson15。

一、C 风格字符串的本质

本质：以空字符 '\0'（ASCII 0）结尾的 char 数组。

下标:  0   1   2   3   4   5
内容: 'h' 'e' 'l' 'l' 'o' '\0'   // "hello" 占 6 字节

char s1[100] = "hello";  // 自动加 '\0'
char s2[] = "world";     // 大小 6
char s3[6] = {'h','e','l','l','o','\0'};
char s4[5] = {'h','e','l','l','o'};  // 错：无 '\0'
缺 '\0'：strlen / cout 会一直往后读，直到碰巧遇到 0 —— 未定义行为。
【讲解】空间 = 字符数 + 1。

二、'\0' 的作用与重要性

  • strlen：数到 '\0'，不含结束符
  • strcpy：复制到并包含 '\0'
  • strcmp：遇不等或 '\0' 停止
  • cout << s：输出到 '\0'
char s[6] = "hello";   // 正确
char t[100] = "hello";  // 更安全：便于 strcat
// 数组大小至少 字符串长度 + 1
【讲解】所有标准字符串函数依赖 '\0'。

三、声明与初始化

char name[20] = "Alice";     // 字面量，自动 '\0'
char greeting[] = "Hello!"; // 编译器推大小
char city[20];
// city = "Beijing";  // 错！不能对数组 = 赋值
strcpy(city, "Beijing");    // 正确

char c = 'A';      // 单引号：一个字符
char s[] = "A";    // 双引号：'A' + '\0'
char buf[100];     // 垃圾值，用前必须写入
【讲解】单双引号区别必考。

四、输入与输出

方式说明
cin >> s遇空白停；不能读含空格句子
cin.getline(s, size)整行；最多 size-1 字符 + 自动 '\0'
gets已废弃，禁止使用
fgets安全读行，可能含 '\n'
puts(s)输出并换行
 
int n; cin >> n;      // 留下 '\n'
cin.ignore();         // 先吃掉换行！
cin.getline(s, 100);
混用陷阱：cin >> 后直接 getline 会读到空行。
【讲解】竞赛首选 cin.getline。

五、四大函数（1）strlen · strcpy

#include <cstring>
char s[100] = "abc";
strlen(s);   // 3，不含 '\0'
sizeof(s);   // 100，数组容量

char dest[20], src[] = "Hello";
strcpy(dest, src);     // dest 必须够大，含 '\0' 一并拷
strcpy(dest, "World"); // 覆盖原内容
对比：长度永远用 strlen；若 s 是指针，sizeof 是指针宽度，不是串长。
【讲解】strcpy 目标溢出是 RE 大户。

五、四大函数（2）strcat · strcmp

char s[50] = "Hello";
strcat(s, " ");
strcat(s, "World");  // "Hello World"
// 需要：strlen(dest)+strlen(src)+1 ≤ 容量

strcmp("abc", "abc");  // 0 相等
strcmp("abc", "abd");  // <0
strcmp("abd", "abc");  // >0
// 正确：if (strcmp(a,b) == 0)
// 错误：if (a == b)  // 比地址！
// 错误：if (strcmp(a,b))  // 相等反而是假
【讲解】strcmp 返回 int，0 才相等。

六、字符判断 · 七、回文

for (int i=0; s[i]; i++) {
  char c = s[i];
  if (c>='0' && c<='9') ...
  if (c>='a' && c<='z') ...
}
// 或 cctype: isdigit/isalpha
// 大小写：c-'a'+'A'
bool isPal(char s[]) {
  int n = strlen(s);
  for (int i=0, j=n-1; i<j; i++,j--)
    if (s[i]!=s[j]) return false;
  return true;
}
// "level" 双指针相向
【讲解】空串、单字符是回文。

八、手写 strlen / 反转 · 九、对比 string

int my_strlen(char s[]) {
    int i = 0;
    while (s[i] != '\0') i++;
    return i;
}
// 反转：for i=0..n/2-1 swap(s[i], s[n-1-i])
char[]std::string
结束必须 '\0'自带长度
赋值/拼/比strcpy/strcat/strcmp= + ==
安全易越界更安全
【讲解】理解手写版才真懂 '\0'。

strcpy(c, a); strcat(c, " "); strcat(c, b);
if (strcmp(a, b) < 0) cout << "a<b";

// 统计数字字符
cin.getline(s, 110);

    if (s[i]>='0' && s[i]<='9') cnt++;
【讲解】模板一～四浓缩。

📝 真题精练

真题1：统计数字字符（可含空格）→ getline + 范围判断。样例 Hello123 World456 → 6

真题2：回文 yes/no → 双指针。level→yes，hello→no

例题3：拼 a+b、长度、字典序比较

strcpy(c, a); strcat(c, b);
cout << c << endl << strlen(c) << endl;
int cmp = strcmp(a, b);
if (cmp<0) cout<<"<"; else if (cmp>0) cout<<">";
else cout<<"=";
【讲解】数字判断勿写成 0..9 数值。

⚠ 易错点

  1. 忘记为 '\0' 预留：char s[5]="hello" 错
  2. strcmp==0 才相等；不要 s1==s2
  3. 禁用 gets
  4. strcpy/strcat 目标太小 → 溢出
  5. strlen 与 sizeof 混淆
  6. 不能对数组直接 = 赋值
  7. cin>> 与 getline 混用要 ignore
  8. fgets 可能残留 '\n'
【讲解】投影逐条点名。

🎯 本课小结

  1. 本质：以 '\0' 结尾的 char 数组
  2. 空间：长度+1；拼接预留更大缓冲
  3. 输入：cin>> 遇空白停；getline 读整行；禁用 gets
  4. 四函数：strlen / strcpy / strcat / strcmp（0 相等）
  5. 回文：双指针 O(n)
  6. 安全：目标够大；比内容不用 ==
一句话：有 '\0' 才是 C 字符串；比内容用 strcmp==0；回文两端往中间夹。
