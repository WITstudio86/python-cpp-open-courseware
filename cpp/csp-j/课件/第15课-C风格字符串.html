一、C 风格字符串的本质

🔹 定义：以 '\0' 结尾的 char 数组

'\0' 的 ASCII 码值为 0，是字符串的"终点标志"。所有字符串函数都依赖它判断结束。

字符hello\0
索引012345
ASCII1041011081081110
// 声明与初始化
char s1[100] = "hello";   // ✅ 自动添加 '\0'
char s2[]   = "world";    // ✅ 大小自动 = 6
char s3[6]  = {'h','e','l','l','o','\0'}; // ✅ 手动加 '\0'
char s4[5]  = {'h','e','l','l','o'};    // ❌ 不是合法字符串！
⚠️ 核心警示：没有 '\0' 的 char 数组不是字符串！使用 strlen / strcpy / cout 等操作会导致越界访问，输出乱码甚至程序崩溃。
💡 经验法则：声明数组时，大小 = 最大字符数 + 1（为 '\0' 预留）。建议留足余量：char s[100] = "hello"; 比 char s[6] = "hello"; 更安全，后续拼接不愁。

二、常用字符串函数

头文件：#include <cstring>

函数作用返回值注意事项
strlen(s) 求长度 字符个数（不计 \0） 区别于 sizeof
strcpy(d,s) 拷贝 目标指针 目标必须足够大！
strcat(d,s) 拼接（末尾追加） 目标指针 目标容量要够！
strcmp(a,b) 逐字符比较 0=相等，>0=a大，<0=a小 不是 bool！

🔹 strcmp 比较机制

strcmp("abc", "abc")  → 0   // 完全相等
strcmp("abc", "abd")  → 负数 // 'c'(99) < 'd'(100)
strcmp("abd", "abc")  → 正数 // 'd'(100) > 'c'(99)
strcmp("ab",  "abc")  → 负数 // 短字符串 < 长字符串
⚠️ 高频易错：if (strcmp(a, b)) 在相等时为 假！
正确写法：if (strcmp(a, b) == 0) 判断相等。

三、回文判断

回文：正读和反读都一样的字符串，如 "level"、"12321"。

🔹 双指针算法

指针 i 从头向后，指针 j 从尾向前，逐对比较 s[i] 与 s[j]。

bool isPalindrome(char s[]) {
    int len = strlen(s);
    for (int i = 0, j = len - 1; i < j; i++, j--) {
        if (s[i] != s[j]) {
            return false;
        }
    }
    return true;
}
字符串过程结果
"level"l==l ✓, e==e ✓, v 居中✅ 回文
"hello"h==o ✗ (第一对就不等)❌ 不是回文
"a"len=1, i<j 为假，直接返回 true✅ 回文
💡 复杂度分析：时间 O(n)，空间 O(1)。循环条件 i < j 确保每对字符只比较一次，发现不等立即退出。

四、真题精练

📝 真题1：统计数字字符个数

输入一个字符串（可含空格），输出其中数字字符 '0'~'9' 的数量。

char s[110];
cin.getline(s, 110);
int cnt = 0;
for (int i = 0; i < strlen(s); i++) {
    if (s[i] >= '0' && s[i] <= '9') cnt++;
}
cout << cnt << endl;

样例："Hello123" → 3

📝 真题2：验证回文

输入一个小写字母字符串，判断是否为回文。

char s[110]; cin >> s;
int len = strlen(s);
bool flag = true;
for (int i = 0, j = len - 1; i < j; i++, j--) {
    if (s[i] != s[j]) { flag = false; break; }
}
cout << (flag ? "yes" : "no") << endl;

样例："level" → yes；"hello" → no

五、本课小结

  1. C 风格字符串本质：以 '\0' 结尾的 char 数组，所有标准函数依赖 '\0' 判断结束位置。
  2. 数组大小：声明时必须预留 '\0' 的空间（大小 = 字符数 + 1），建议留足余量。
  3. 输入方式：cin >> s 遇空格停止；cin.getline(s, n) 可读整行；禁止使用 gets。
  4. 核心函数：
    • strlen — 长度（不含 \0）
    • strcpy — 拷贝（目标要够大）
    • strcat — 拼接（目标要够大）
    • strcmp — 比较（返回 int，0 表示相等）
  5. 回文判断：双指针法，O(n) 时间，O(1) 空间，高频考点。
  6. 安全第一：strcpy / strcat 前确保目标数组容量足够，防范缓冲区溢出。
