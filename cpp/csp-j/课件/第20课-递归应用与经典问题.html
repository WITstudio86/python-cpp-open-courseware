汉诺塔问题（Tower of Hanoi）

问题描述

有三根柱子 A、B、C。A 柱上有 n 个大小不等的圆盘，大盘在下、小盘在上。要求将所有圆盘从 A 柱移动到 C 柱，移动过程中遵守以下规则：

  1. 每次只能移动 一个 圆盘
  2. 大盘不能放在小盘上面
  3. 可以借助 B 柱作为辅助
核心递归思路：
1. 将上面 n-1 个盘子从 A 移到 B（借助 C）
2. 将第 n 个（最大的）盘子从 A 直接移到 C
3. 将 n-1 个盘子从 B 移到 C（借助 A）

移动步数

设 T(n) 为移动 n 个盘子所需的步数
T(1) = 1， T(n) = 2 × T(n−1) + 1
T(n) = 2n − 1
关键洞察：当 n = 64 时，需要移动 264 − 1 ≈ 1.84 × 1019 次。即使每秒移动一次，也需要约 5800 亿年——远超宇宙的年龄！汉诺塔问题是指数级复杂度的经典范例。

汉诺塔 —— 代码实现与追踪

递归代码

#include <iostream> using namespace std; void hanoi(int n, char from, char aux, char to) { if (n == 1) { cout << "Move disk 1 from " << from << " to " << to << endl; return; } hanoi(n - 1, from, to, aux); // Step 1: n-1 from A→B cout << "Move disk " << n << " from " << from << " to " << to << endl; // Step 2: largest A→C hanoi(n - 1, aux, from, to); // Step 3: n-1 from B→C } int main() { int n; cin >> n; hanoi(n, 'A', 'B', 'C'); return 0; }

n = 3 时的执行追踪（共 23 − 1 = 7 步）

hanoi(3, A, B, C) ├─ hanoi(2, A, C, B) // 把上面2个从A移到B │ ├─ hanoi(1, A, B, C) → Step 1: Move disk 1 from A to C │ ├─ Step 2: Move disk 2 from A to B │ └─ hanoi(1, C, A, B) → Step 3: Move disk 1 from C to B ├─ Step 4: Move disk 3 from A to C // 最大的盘子 └─ hanoi(2, B, A, C) // 把上面2个从B移到C ├─ hanoi(1, B, C, A) → Step 5: Move disk 1 from B to A ├─ Step 6: Move disk 2 from B to C └─ hanoi(1, A, B, C) → Step 7: Move disk 1 from A to C
考点提醒 递归函数的参数顺序至关重要：hanoi(n, from, aux, to)。在 CSP-J 初赛中，常以填空题或阅读程序题的形式考察汉诺塔的递归调用顺序和输出结果。

辗转相除法（欧几里得算法）—— 求最大公约数

数学原理

对于两个正整数 a 和 b（a ≥ b），有：

gcd(a, b) = gcd(b, a % b)

递归的终止条件是 b == 0，此时 gcd(a, 0) = a。

举例：gcd(48, 18) → gcd(18, 12) → gcd(12, 6) → gcd(6, 0) = 6

递归写法

int gcd(int a, int b) { if (b == 0) return a; return gcd(b, a % b); }

迭代写法

int gcd(int a, int b) { while (b != 0) { int temp = b; b = a % b; a = temp; } return a; }
时间复杂度：O(log min(a, b))。每两次取模操作至少将较大的数缩小一半，因此效率极高。这是信息学竞赛中最常用的数论基础算法之一。
考点提醒 扩展欧几里得算法（exgcd）可以求解 ax + by = gcd(a, b) 的整数解，常在 CSP-J 提高组或 CSP-S 中考察。本题只需掌握基础 GCD 即可。

二分查找的递归实现

算法思想

在有序数组中查找目标值。每次比较中间元素，若等于目标则找到；若目标较小则递归左半部，否则递归右半部。每次将搜索范围减半。

代码实现

int binarySearch(int arr[], int left, int right, int target) { if (left > right) return -1; // 未找到：搜索范围无效 int mid = left + (right - left) / 2; // 防溢出写法 if (arr[mid] == target) return mid; // 找到目标 else if (arr[mid] > target) return binarySearch(arr, left, mid - 1, target); else return binarySearch(arr, mid + 1, right, target); }

查找示例：在数组中查找 7

索引012345678
值1357911131517
调用 binarySearch(arr, 0, 8, 7) mid = 4, arr[4] = 9 > 7 → 搜索左半部 [0, 3] mid = 1, arr[1] = 3 < 7 → 搜索右半部 [2, 3] mid = 2, arr[2] = 5 < 7 → 搜索右半部 [3, 3] mid = 3, arr[3] = 7 == 7 → 找到！返回索引 3
时间复杂度：O(log n)。每次递归将问题规模减半。二分查找是分治思想的典型应用，也是 CSP-J 复赛中最常用的优化技巧之一。

回溯算法 —— 全排列生成

回溯（Backtracking）的核心思想

系统地搜索问题的所有解。在搜索过程中，如果发现当前路径不可能得到解，就撤销上一步的选择（回溯），尝试其他分支。本质是深度优先搜索 + 剪枝。

生成 1~n 的全排列

#include <iostream> using namespace std; int n; int path[20]; // 保存当前排列 bool used[20]; // 标记数字是否已被使用 void dfs(int depth) { if (depth == n) { // 找到一组完整排列 for (int i = 0; i < n; i++) cout << path[i] << " "; cout << endl; return; } for (int i = 1; i <= n; i++) { if (!used[i]) { // 数字 i 还没用过 path[depth] = i; // 选择 i used[i] = true; // 标记已使用 dfs(depth + 1); // 递归下一层 used[i] = false; // 回溯：撤销标记 } } }

回溯的关键步骤

  1. 选择：从候选集合中选择一个数字放入当前位置
  2. 标记：将该数字标记为「已使用」，避免重复
  3. 递归：进入下一层，继续选择
  4. 回溯：递归返回后，撤销标记（used[i] = false），让该数字在其他分支中可以被使用
考点提醒 回溯算法是 CSP-J 复赛的高频考点。常见题型包括：全排列、N 皇后问题、组合数生成、子集生成等。核心在于理解「选择→递归→撤销」这一模式。

代码模板集成 —— 考场上直接套用

模板一：最大公约数（GCD）

// ========== GCD 模板 ========== int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); } // 使用示例 int result = gcd(48, 18); // result = 6

模板二：二分查找（递归版）

// ========== 二分查找模板 ========== int binarySearch(int a[], int L, int R, int x) { if (L > R) return -1; int mid = L + (R - L) / 2; // 防溢出 if (a[mid] == x) return mid; if (a[mid] > x) return binarySearch(a, L, mid - 1, x); else return binarySearch(a, mid + 1, R, x); } // 前提：数组 a[0..n-1] 必须是升序排列

模板三：汉诺塔

// ========== 汉诺塔模板 ========== void hanoi(int n, char from, char aux, char to) { if (n == 1) { cout << from << "->" << to << endl; return; } hanoi(n - 1, from, to, aux); cout << from << "->" << to << endl; hanoi(n - 1, aux, from, to); }
模板使用建议：考场上建议熟记这三个模板的骨架。GCD 一行三元表达式即可写完；二分查找注意 mid = L + (R - L) / 2 防溢出；汉诺塔记住参数顺序 (n, from, aux, to)。

真题精练与课堂小结

真题一：最大公约数（CSP-J 模拟）

题目 输入两个正整数 a 和 b（1 ≤ a, b ≤ 109），输出它们的最大公约数。要求使用递归实现。
#include <iostream> using namespace std; int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); } int main() { int a, b; cin >> a >> b; cout << gcd(a, b); return 0; }

真题二：递归生成二进制串（CSP-J 初赛改编）

题目 给定正整数 n，按字典序输出所有长度为 n 的二进制串（由字符 '0' 和 '1' 组成）。例如 n=3 时，输出 000, 001, 010, 011, 100, 101, 110, 111。
#include <iostream> using namespace std; char s[20]; void gen(int k, int n) { if (k == n) { s[k] = '\0'; cout << s << endl; return; } s[k] = '0'; gen(k + 1, n); s[k] = '1'; gen(k + 1, n); } int main() { int n; cin >> n; gen(0, n); return 0; }

本课学习要点总结

  1. 汉诺塔：掌握递归三步骤（移动 n-1 → 移动最大的 → 移动 n-1），理解 2n−1 的指数增长
  2. 辗转相除法：熟记 gcd(a,b) = gcd(b, a%b)，终止条件 b == 0
  3. 二分查找：理解分治思想，注意 mid = L + (R−L)/2 防溢出
  4. 回溯算法：掌握「选择 → 标记 → 递归 → 撤销」四步模式，是 CSP-J 复赛的核心技能
  5. 递归设计要点：明确终止条件 → 缩小问题规模 → 合并子问题的解
