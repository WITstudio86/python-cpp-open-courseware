一、汉诺塔：问题分解

三柱 A/B/C，n 盘从 A→C，大盘不可压小盘。每次移一盘，B 为辅助。

  1. 把 n−1 盘从 src 移到 aux（借助 dst）
  2. 把最大盘从 src 直接移到 dst
  3. 把 n−1 盘从 aux 移到 dst（借助 src）

边界：n==1 时直接移动。递推：T(n)=2T(n−1)+1 → T(n)=2ⁿ−1

n=3，共 7 步： 1: 1 A→C 2: 2 A→B 3: 1 C→B 4: 3 A→C 5: 1 B→A 6: 2 B→C 7: 1 A→C
【讲解】板书三步分解，强调柱子参数互换。

汉诺塔：代码实现

int steps = 0; void hanoi(int n, char src, char aux, char dst) { if (n == 1) { steps++; cout << "第 " << steps << " 步：盘 " << n << " 从 " << src << " 到 " << dst << endl; return; } hanoi(n - 1, src, dst, aux); // n-1 → 辅助柱 steps++; cout << "第 " << steps << " 步：盘 " << n << " 从 " << src << " 到 " << dst << endl; hanoi(n - 1, aux, src, dst); // n-1 → 目标柱 } // 调用：hanoi(n, 'A', 'B', 'C');
参数顺序易混：第二次递归是 aux, src, dst。初赛常考阅读输出顺序。
【讲解】对照 n=3 输出验证。

二、辗转相除法求 GCD

性质：gcd(a,b)=gcd(b, a%b)；边界：gcd(a,0)=a

递归

int gcd(int a, int b) { if (b == 0) return a; return gcd(b, a % b); }

迭代

int gcd(int a, int b) { while (b != 0) { int t = b; b = a % b; a = t; } return a; }
gcd(48,18)→gcd(18,12)→gcd(12,6)→gcd(6,0)=6 lcm(a,b)=a/gcd(a,b)*b // 先除后乘防溢出
时间 O(log min(a,b))。勿写 if(b==0) return 0;！
【讲解】证明公约数集合不变（可选简述）。

三、二分查找的递归实现

有序区间 [left,right] 查 target；mid = left+(right-left)/2 防溢出。

int binarySearch(int arr[], int left, int right, int target) { if (left > right) return -1; int mid = left + (right - left) / 2; if (arr[mid] == target) return mid; if (arr[mid] > target) return binarySearch(arr, left, mid - 1, target); else return binarySearch(arr, mid + 1, right, target); }
区间必须严格缩小：mid−1 / mid+1。写 mid 不减易无限递归。
复杂度 O(log n)。后续二分答案、分治排序同一思想。
【讲解】手追 {1,3,5,7,9,11,13} 查 5 与 4。

四、回溯框架与全排列思想

void backtrack(状态) { if (到达终止) { 记录解; return; } for (每个可能选择) { if (合法) { 做出选择; backtrack(新状态); 撤销选择; // 灵魂步骤！ } } }

全排列：path 记路径，used 标记是否用过；path.size()==n 时输出。

n=3 部分搜索树： [1]→[1,2]→[1,2,3] ✓ → 撤销3 → [1,3]→[1,3,2] ✓ 撤销1 → [2]… 共 3!=6 种
【讲解】强调撤销 used 与 pop_back。

全排列：完整代码

int n; vector<int> path; bool used[15]; void dfs() { if ((int)path.size() == n) { for (int x : path) cout << x << " "; cout << endl; return; } for (int i = 1; i <= n; i++) { if (!used[i]) { used[i] = true; path.push_back(i); dfs(); path.pop_back(); used[i] = false; // 回溯 } } } // main: cin>>n; dfs();
模式：选择 → 递归 → 撤销。组合/子集/N 皇后同一骨架。
【讲解】n=3 让学生口述完整 6 行输出。

五、递归局限性与选型

问题表现对策
栈溢出深度过大 RE迭代 / 显式栈
重复计算如裸 fib O(2ⁿ)记忆化 / DP
尾递归C++ 不保证优化竞赛勿依赖
  • 用递归：树/图 DFS、分治、回溯、定义天然递归且深度可控
  • 用迭代：线性递推、深度可能 >1e4、性能极致要求
CSP-J 多数递归题深度安全；先写对，再视数据范围优化。
【讲解】与第19课选型呼应加深。

代码模板精选

GCD + 二分 + 回溯骨架（考场速查）

int gcd(int a, int b) { return b ? gcd(b, a % b) : a; } int bs(int a[], int L, int R, int t) { if (L > R) return -1; int m = L + (R - L) / 2; if (a[m] == t) return m; return a[m] > t ? bs(a, L, m - 1, t) : bs(a, m + 1, R, t); } // 回溯：used + path + 撤销 // 汉诺塔：hanoi(n,s,a,d)
完整汉诺塔/全排列见讲义模板1–4 与配套 .cpp。
【讲解】提醒学生默写 GCD 与回溯框架。

易错点

1. 二分边界 off-by-one：必须 mid±1，否则死递归。

2. GCD 边界：b==0 返回 a，不是 0 或 1。

3. 回溯漏撤销：忘记 used[i]=false 或 path.pop_back()。

4. 汉诺塔参数：柱子顺序写错导致移盘逻辑全错。

5. 深度过大：n=1e5 链式递归慎用。
【讲解】各举一行错误代码对比。

真题1：递归求最大公约数

题目

输入 a,b（1≤a,b≤1e9），递归辗转相除求 gcd。禁止直接 __gcd 得分。

样例：48 18 → 6；1071 462 → 21

#include <iostream> using namespace std; int gcd(int a, int b) { if (b == 0) return a; return gcd(b, a % b); } int main() { int a, b; cin >> a >> b; cout << gcd(a, b) << endl; }
【练习】手算 1071,462 过程。

真题2：生成所有二进制串

题目

给定 n（1≤n≤15），输出长度 n 的全部 0/1 串，字典序（先 0 后 1）。

n=3 → 000…111 共 8 行

int n; string path; void dfs(int pos) { if (pos == n) { cout << path << endl; return; } path.push_back('0'); dfs(pos + 1); path.pop_back(); path.push_back('1'); dfs(pos + 1); path.pop_back(); }
无需 used；每位 2 选 1。先 0 后 1 保证字典序。复杂度 O(2ⁿ·n)。
【练习】与全排列对比：有无 used 的区别。
