二、选择题技巧

  1. 排除法：去掉明显错误选项
  2. 代入验证：进制、计算题反代选项
  3. 特殊值：0、1、-1 试边界
// 例：a=5,b=3; cout << (a & b); // 5=101, 3=011 → 001 = 1 // 排除 ≥5 的结果；答案 1
十进制二进制十六进制
101010A
151111F
161000010
25511111111FF
二→八：每 3 位一组；二→十六：每 4 位一组。存储：1KB=1024B。
位运算、进制每年必考。

三、程序阅读技巧

模拟执行：草稿纸建变量表，逐行更新。

  • 循环边界：<= 与 <
  • i++ 先用后加 / ++i 先加后用
  • 整数除法截断：5/2=2
  • continue 跳过本次；break 跳出循环
  • switch 穿透：无 break 会掉进下一 case
int x = 2; switch (x) { case 1: cout << "A"; case 2: cout << "B"; case 3: cout << "C"; break; default: cout << "D"; } // 输出：BC
if (a = b) 是赋值！非零即真。应写 ==。
函数调用要跟踪参数与返回值。

四、程序填空技巧

  1. 先通读：弄清整体算法再填空
  2. 对称法：二分左右、交换三行等对称结构
  3. 高频模式：
  • 遍历 for：0..n-1 或 1..n
  • 最值初始化：a[0] / INT_MIN
  • 交换 swap 或三变量
  • 递归边界：n==0 / n<=1
运算符优先级口诀（节选）：一元 ! ＞ * / % ＞ + - ＞ 关系 ＞ == ＞ & ＞ && ＞ || ＞ 赋值
填空别只盯空格，看上下文变量用途。

五、易错点速查

  1. 整数除法精度丢失
  2. 数组越界 / 未初始化局部变量
  3. 逻辑短路：A&&B 中 A 假则不执行 B
  4. switch 无 break 穿透
  5. 赋值 = 与等于 ==
  6. C 字符串多 1 字节 '\0'（"abc" 占 4 字节）
  7. 自增副作用未定义行为（少写奇怪表达式）
// 位运算速记 a & b 按位与； a | b 或； a ^ b 异或 a << 1 乘2； a >> 1 除2 x & 1 判奇偶； (x & (x-1))==0 是否2的幂

六、选择题精练（1–5）

1. 存储单位正确的是？（ ）A 1KB=1000B B 1MB=1024KB C 1GB=1000MB D 1TB=1000GB

答案 B。计算机内部 1024 进制；硬盘厂商常说 1000。

2. 1 字节 = ? bit　A 4 B 7 C 8 D 16 → C

3. 十进制 29 的二进制？　A 11001 B 11101 C 10111 D 11100 → B（16+8+4+1）

4. 二进制 10110 的十进制？　→ 22（16+4+2）

5. 非 C++ 基本类型？A int B float C string D char → C（string 是类）

可让学生先独立做再揭晓。

选择题精练（6–10）

6. 表达式 5/2 的值？ → 2（整数除法）

7.

int a=3,b=5; if (a = b) cout << "Equal"; else cout << "Not Equal";
答案 Equal：赋值 a=5 非零为真。

8. 优先级最高？A && B == C ! D = → C

9. while(i<5){i++;} 从 i=0 起循环体执行次数？ → 5

10. int a[10]={1,2,3,4}; 则 a[5]？ → 0（其余元素补 0）

7 是经典陷阱题。

选择题精练（11–15）

11. break 与 continue？ → break 结束循环，continue 跳过本次

12. 字符串 "abc" 占字节？ → 4（含 '\0'）

13. a=6; a>>1 ？ → 3

14. x=5; cout<<(x>3 && x<10 || x==0); → 1

15. 十六进制 2A 转十进制？ → 42（2×16+10）

做完选择立刻涂卡/填涂，避免最后来不及。
15 题共 30 分，基础分务必拿满。

八、程序填空 1–2 · 题意+答案

填空1：素数判定

for (int i = 2; i <= ①; i++) { if (n % i == ②) { flag = false; ③; } } if (④) cout << "YES";
① sqrt(n)　② 0　③ break　④ flag

填空2：十进制转二进制

while (①) { a[cnt++]=n%2; n=②; } for (int i=cnt-1; i>=③; i--) cout<<a[i];
① n>0　② n/2　③ 0
强调倒序输出余数。

程序填空 3–5

填空3：求和与平均

① a[0]（sizeof）　② a[i]　③ (double)sum

填空4：统计大小写与数字

① s[i]>='A' && s[i]<='Z'
② s[i]>='a' && s[i]<='z'
③ s[i]>='0' && s[i]<='9'

填空5：二分查找 while 条件、mid、左右更新

while (left <= right) { mid = left + (right - left) / 2; if (a[mid]==x) { ans=mid; break; } else if (a[mid]<x) left=mid+1; else right=mid-1; }
二分边界易死循环：更新要用 mid±1，mid 用防溢出写法。
对照内容.md 完整空位。
