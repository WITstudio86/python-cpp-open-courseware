🎯 选择题答题技巧

1
排除法

逐个排除明显错误的选项，缩小选择范围。即便不确定正确答案，也能提高猜对的概率。

// 题目：5 & 3 的结果是？ int a = 5, b = 3; cout << (a & b); // 5(101) & 3(011) = 1(001) // 排除法：结果不可能 >5 → 排除 C、D // 5和3第0位都是1 → 排除 A(0) // 答案只能是 B(1) ✓
2
代入验证法

将选项反代回题目条件中验证。进制转换题尤其适用：已知十六进制 2F，快速计算 2×16+15=47，在选项中找 47。

3
特殊值法

代入 0、1、-1 等边界值快速验证。对于循环边界题，代入 n=1 看程序行为是否符合预期。

💡 选择题得分目标：24 分以上（答对 12 题以上）
基础题（前 8 题）争取全对，偏难题（后 7 题）用排除法至少排除 2 个选项再选择。

🔍 程序阅读题技巧

核心方法：模拟执行法

在草稿纸上建立变量变化表，逐行模拟执行过程。

// 例题：写出输出 int a[5] = {1, 2, 3, 4, 5}; int s = 0; for (int i = 0; i < 5; i++) { if (a[i] % 2 == 0) s += a[i]; else s -= a[i]; } cout << s; // 输出: -3
ia[i]a[i]%2==0s的变化s的值
01falses = 0 - 1-1
12trues = -1 + 21
23falses = 1 - 3-2
34trues = -2 + 42
45falses = 2 - 5-3

六大常见陷阱

  • 循环边界：<= 比 < 多执行一次
  • 自增自减：i++ 先用后增，++i 先增后用
  • 整数除法：5 / 2 = 2，不是 2.5
  • switch 穿透：没有 break 会继续执行下一个 case
  • 短路求值：A && B 中 A 为 false 则 B 不执行
  • 变量未初始化：局部变量默认值不确定

📝 程序填空题方法

1
整体阅读法

不看空，先通读完整程序，理解程序的整体功能和算法思路。很多空可以通过上下文"推断"——前面有赋值，后面在使用，中间的空往往是对该变量的处理。

2
对称法

许多程序存在对称结构：二分查找的左右区间更新、交换两个变量的三行代码。利用对称性推断缺失内容。

3
常见模式识别
模式典型填空示例
数组遍历循环条件for(int i=0; i<n; i++)
求最大值初始值maxv = a[0] 或 INT_MIN
二分查找区间更新left = mid+1 / right = mid-1
素数判断循环上界i <= sqrt(n)
进制转换取余存入a[cnt] = n % base
字符串反转交换位置s[len-1-i]
💡 程序填空得分目标：18 分以上（至少答对 3 题）
常见套路：变量声明对应初始化后的使用，循环条件对应循环体内的变量变化。

快速转换技巧

二进制 → 八进制：从右向左每 3 位一组
二进制 → 十六进制：从右向左每 4 位一组
十六进制 → 二进制：每位展开为 4 位二进制
例：2A(16) = 0010 1010(2)

📋 示例选择题详解

第 7 题（经典陷阱）：以下程序段的输出是？
int a = 3, b = 5; if (a = b) cout << "Equal"; else cout << "Not Equal"; // A. Equal B. Not Equal C. 编译错误 D. 运行错误
答案：A (Equal)
if (a = b) 是赋值而非比较！a = b 的值是 5，非零即 true。
正确写法：if (a == b) —— 这是每年必考的陷阱！
第 11 题：关于 break 和 continue 的正确说法是？
A. break 跳过本次循环，continue 结束整个循环
B. break 结束整个循环，continue 跳过本次循环的剩余部分 ✓
C. 两者作用完全相同
D. break 只能用于 switch 语句中

记法：break = "打破"整个循环；continue = "继续"下一次循环。

第 8 题：以下运算符优先级最高的是？
A. &&   B. ==   C. ! ✓   D. =

记法：一元运算符（!）优先级高于二元运算符（==, &&），赋值（=）优先级最低。

⚠️ 高频陷阱详解

1. Switch 穿透（每年必考）

int x = 2; switch (x) { case 1: cout << "A"; case 2: cout << "B"; // 匹配这里，但没有 break case 3: cout << "C"; break; // 穿透到这里才停止 default: cout << "D"; } // 输出: BC（不是 B！）

2. 整数除法截断

int a = 5 / 2; // a = 2，不是 2.5 double b = 5 / 2; // b = 2.0，因为右侧先做 int 除法 double c = 5.0 / 2; // c = 2.5（有一个操作数是浮点即可）

3. 数组下标从 0 开始 & 部分初始化

int a[5] = {1, 2}; // a[0]=1, a[1]=2, a[2]=0, a[3]=0, a[4]=0 int b[5]; // 局部变量，值为随机值！

4. 字符串结束符

char s[] = "abc"; // 实际占 4 字节: 'a','b','c','\0' cout << sizeof(s); // 输出 4

🗂️ 关键知识总结

📐 进制转换

• 2→8: 每 3 位一组
• 2→16: 每 4 位一组
• 10→N: 除 N 取余，倒序排列
• N→10: 按权展开求和
• 29(10) = 11101(2) = 35(8) = 1D(16)

⚙️ 位运算

• x & 1：判断奇偶
• x & (x-1) == 0：判断 2 的幂
• x << 1：乘 2
• x >> 1：除 2

🔄 数据类型

• int: ±2.1×10⁹
• long long: ±9.2×10¹⁸
• char: -128~127
• bool: true(1)/false(0)
• string 不是基本类型！

🔍 程序填空口诀

• 循环边界看数组大小
• 初始值看累加/找最值
• 二分看区间更新方向
• 递归看终止条件和递推
