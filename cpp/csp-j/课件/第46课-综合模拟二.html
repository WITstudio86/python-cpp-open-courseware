二、模拟 · 枚举 · 贪心 · 二分答案

模拟：按题意逐步实现；日期要闰年与每月天数。

枚举优化：减一维、剪枝、排序+双指针。

贪心：每步局部最优；区间调度按结束时间排序。

二分答案：答案单调 → check(mid) 判定 → 求最大/最小可行值。

// 二分答案：求满足条件的最大 mid while (left <= right) { mid = left + (right - left) / 2; if (check(mid)) { ans = mid; left = mid + 1; } else right = mid - 1; }
01 背包不能贪价值密度；部分背包可以。

三、常用模板

bool isLeap(int y) { return (y%4==0 && y%100!=0) || (y%400==0); } // 高精度加法：从低位加，处理 carry，最后 reverse // 活动选择：sort by end；if (start >= lastEnd) 选
易错：闰年漏 400 规则；枚举超时不看 n；二分边界死循环；int 溢出用 long long；数组多开 5。
调试用 cerr；边界测 min/max。

四、模拟题：日期差 · 题意思路

题意：两日期 YYYY-MM-DD，保证 date1≤date2，输出相差天数。

样例：2024-01-01 与 2024-01-10 → 9

思路：写 isLeap、daysOfMonth；把日期换成「从公元 1-1-1 起总天数」再相减。用 long long 防大年份。
60% 数据同年；100% 年份 1–9999。

日期差 · 核心代码

long long totalDays(int y, int m, int d) { long long total = 0; for (int i = 1; i < y; i++) total += isLeap(i) ? 366 : 365; for (int i = 1; i < m; i++) total += daysOfMonth(y, i); total += d; return total; } // main: scanf 两个日期；输出 t2-t1
也可用逐日推进，大跨度慢但数据可过时可用。

五、枚举题：三数之和为 0 · 题意

题意：n 个数（n≤1000），是否存在 a+b+c=0。输出 YES/NO。

样例：-1 0 1 2 -1 -4 → YES；全正 → NO

思路：O(n³) 超时。排序后枚举 i，双指针 left/right 找两数和为 -a[i]，总 O(n²)。a[i]>0 可 break 剪枝。
注意 long long 若数据大；本题绝对值 1e6，int 可。

三数之和 · 核心代码

sort(a, a + n); for (int i = 0; i < n - 2; i++) { if (a[i] > 0) break; int L = i + 1, R = n - 1; while (L < R) { int sum = a[i] + a[L] + a[R]; if (sum == 0) { cout << "YES\n"; return 0; } else if (sum < 0) L++; else R--; } } cout << "NO\n";
只需判断存在，找到立即退出。

六、贪心题：活动选择 · 题意思路

题意：n 个活动共用一教室，求最多不重叠个数。n≤1e5。

样例：5 个区间 → 最多 2

思路：按结束时间升序；贪心选结束最早且与上一个不冲突（start ≥ lastEnd）的活动。
按开始时间排序会错！反例：[1,10],[2,3],[4,5] 贪开始会只选 1 个。
交换论证：最优解可换成结束更早的不更差。

活动选择 · 核心代码

struct Activity { int start, end; } a[100005]; bool cmp(Activity x, Activity y) { return x.end < y.end; } // sort(a,a+n,cmp); int count = 0, lastEnd = -1; for (int i = 0; i < n; i++) if (a[i].start >= lastEnd) { count++; lastEnd = a[i].end; } cout << count << endl;
时间复杂度 O(n log n) 排序。

七、二分答案：砍树 · 题意思路

题意：n 棵树高 h_i，锯子高度 H，高于 H 的部分砍下。求最大 H 使木材 ≥ M。n≤1e6。

样例：20 15 10 17，M=7 → H=15

思路：H 越高木材越少（单调）。二分 H∈[0,maxH]；check(H) 累加 max(0,h_i-H) 是否 ≥M；能则试更高。
total 用 long long；n 大加 fast IO。

砍树 · 核心代码

bool check(int H) { long long total = 0; for (int i = 0; i < n; i++) if (h[i] > H) { total += h[i] - H; if (total >= M) return true; } return total >= M; } // while(left<=right) 能则 ans=mid, left=mid+1；否则 right=mid-1
O(n log maxH) ≈ 3e7 可过。
