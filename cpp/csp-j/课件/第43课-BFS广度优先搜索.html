一、BFS 核心思想与队列框架

1.1 什么是 BFS？

BFS — 广度优先搜索，逐层扩展：先近后远。从起点出发，先访问所有距离为1的节点，再访问所有距离为2的节点……类似水波纹从中心向外扩散。

1.2 为什么用队列？

BFS 需要保证"先被发现的节点先被访问" — 这是典型的 FIFO（先进先出）特性，恰好对应队列（queue）的行为。

#include <queue> using namespace std; queue<int> q; q.push(x); // 入队 q.pop(); // 出队 q.front(); // 访问队首 q.empty(); // 判空 q.size(); // 队列大小

1.3 BFS 标准框架

void bfs(int start) { queue<int> q; q.push(start); // 1. 起点入队 vis[start] = true; // 2. 标记已访问 dist[start] = 0; // 3. 起点距离为0 while (!q.empty()) { // 4. 队列非空就继续 int u = q.front(); // 5. 取队首 q.pop(); // 6. 出队 for (int v : G[u]) { // 7. 遍历邻接点 if (!vis[v]) { // 8. 未访问？ vis[v] = true; // 9. 标记 dist[v] = dist[u] + 1; // 10. 更新距离 q.push(v); // 11. 入队 } } } }
关键：必须在入队时标记 vis，不是在出队时！否则同一节点会被重复入队多次，导致 TLE/MLE。

二、BFS 求最短路径

核心性质（常考）

在无权图中，BFS 天然求出的是起点到各点的最短路径（经过边数最少）。

证明思路：BFS 按层扩展，第 k 层扩展到的所有节点距离起点恰好为 k。如果一个节点在第 k 层被首次访问，不存在更短路径。

路径回溯：记录前驱节点

int pre[MAXN]; // 记录每个节点的前驱 for (int v : G[u]) { if (!vis[v]) { vis[v] = true; dist[v] = dist[u] + 1; pre[v] = u; // 记录前驱节点 q.push(v); } } // 回溯路径：从终点沿pre数组倒推到起点 void print_path(int start, int end) { if (start == end) { cout << start; return; } print_path(start, pre[end]); cout << " -> " << end; }

时间复杂度

邻接表 BFS：O(V + E) — 每个节点入队一次、出队一次，每条边被检查一次。

邻接矩阵 BFS：O(V²) — 大规模数据会导致超时，强烈建议使用邻接表。

考试技巧：dist 数组初始化为 -1，可以同时承担"距离记录"和"访问标记"两个功能（-1 = 未访问，>= 0 = 已访问且记录距离）。省掉一个 vis 数组。

三、网格 BFS（迷宫问题）

CSP-J 最常见的一类 BFS 应用。给定 n*m 网格，有些格子是墙，求从 S 到 E 的最短步数。

网格 BFS 框架

int dx[4] = {0, 0, 1, -1}; // 四个方向：右左下上 int dy[4] = {1, -1, 0, 0}; struct Node { int x, y; }; queue<Node> q; q.push({sx, sy}); vis[sx][sy] = true; dist[sx][sy] = 0; while (!q.empty()) { Node cur = q.front(); q.pop(); if (cur.x == ex && cur.y == ey) return dist[cur.x][cur.y]; for (int i = 0; i < 4; i++) { int nx = cur.x + dx[i]; int ny = cur.y + dy[i]; // 边界检查 必须 在内容检查之前！ if (nx >= 0 && nx < n && ny >= 0 && ny < m && grid[nx][ny] != '#' && !vis[nx][ny]) { vis[nx][ny] = true; dist[nx][ny] = dist[cur.x][cur.y] + 1; q.push({nx, ny}); } } }
易错点：边界检查必须在内容检查之前！grid[nx][ny] != '#' 放在 nx >= 0 && nx < n 之后，利用短路求值避免越界访问导致 RE（运行时错误）。

四、DFS 与 BFS 的选择

特性 DFS（深度优先） BFS（广度优先）
数据结构 栈（递归 / 显式stack） 队列（queue）
空间复杂度 O(深度) — 链状图可能很深 O(宽度) — 星形图可能很大
最短路径 不能保证 无权图天然最短
求所有解 适合（回溯枚举） 不方便
连通性判断 适合（递归标记） 适合（队列标记）
拓扑排序 适合（后序遍历） 适合（Kahn算法）

选择策略（记住口诀）

"最短看 BFS，全部看 DFS，连通看哪个都行。"
  • 求最短路径 / 最少步数 → 首选 BFS
  • 求所有可能的路径 / 方案 → 首选 DFS
  • 判断连通性 / 能否到达 → DFS 和 BFS 均可，DFS 递归更简洁
  • 图特别深（链状图）→ BFS 更安全（DFS 可能爆栈）
  • 图特别宽（星形图）→ DFS 更安全（BFS 队列可能过大）
  • 需要按层处理 → BFS（层序遍历特性）

五、真题演练：迷宫逃脱

题目描述：给定 n*m 迷宫，'.' 为空地，'#' 为墙壁，'S' 为起点，'E' 为终点。每次可向上下左右移动一格。求从 S 到 E 的最短步数，不可达则输出 "Impossible"。

输入样例

5 5 S.#.. .#... ..#.. ...#. ....E

AC 代码

#include <iostream> #include <queue> using namespace std; char grid[105][105]; bool vis[105][105]; int dist[105][105]; int dx[4] = {0, 0, 1, -1}; int dy[4] = {1, -1, 0, 0}; struct Node { int x, y; }; int main() { int n, m, sx, sy, ex, ey; cin >> n >> m; for (int i = 0; i < n; i++) { cin >> grid[i]; for (int j = 0; j < m; j++) { if (grid[i][j] == 'S') { sx = i; sy = j; } if (grid[i][j] == 'E') { ex = i; ey = j; } } } queue<Node> q; q.push({sx, sy}); vis[sx][sy] = true; int ans = -1; while (!q.empty()) { Node cur = q.front(); q.pop(); if (cur.x == ex && cur.y == ey) { ans = dist[cur.x][cur.y]; break; } for (int i = 0; i < 4; i++) { int nx = cur.x + dx[i], ny = cur.y + dy[i]; if (nx >= 0 && nx < n && ny >= 0 && ny < m && grid[nx][ny] != '#' && !vis[nx][ny]) { vis[nx][ny] = true; dist[nx][ny] = dist[cur.x][cur.y] + 1; q.push({nx, ny}); } } } if (ans == -1) cout << "Impossible"; else cout << ans; }

输出结果：8

本课小结

  1. BFS 核心思想：逐层扩展，先近后远。队列实现 FIFO。
  2. 标准框架（必须熟记）：初始化队列 → while(!empty) → front+pop → 遍历邻接点 → 未访问则标记并入队。
  3. 最短路径：无权图中 BFS 天然求最短路径（最少步数），这是 BFS 最重要的性质。
  4. 标记时机：必须在入队时标记 vis，不是在出队时。否则同一节点重复入队导致 TLE/MLE。
  5. 网格 BFS：四个方向遍历，边界检查必须在内容检查之前（短路求值）。
  6. DFS vs BFS："最短看 BFS，全部看 DFS，连通看哪个都行。"
  7. 时间复杂度：O(V + E)（邻接表），O(V²)（邻接矩阵），优先使用邻接表。
