开场：BFS 是无权最短路的标准解法。

一、什么是 BFS？

广度优先搜索：从起点按层扩展，先访问距离 1 的点，再访问距离 2 的点……像水波纹。

对比 DFS「一条路走到底」，BFS 是「齐头并进」。

生活类比：找关系最近的朋友——先问完所有直接朋友，再问朋友的朋友。

核心数据结构：队列 queue

#include <queue> queue<int> q; q.push(x); q.pop(); q.front(); q.empty(); q.size();

FIFO（先进先出）保证「先被发现的先处理」。

复习第24课 queue 基本操作。

二、BFS 标准框架（必背）

void bfs(int start) { queue<int> q; q.push(start); vis[start] = true; dist[start] = 0; while (!q.empty()) { int u = q.front(); q.pop(); for (int v : G[u]) { if (!vis[v]) { vis[v] = true; // 入队时标记！ dist[v] = dist[u] + 1; q.push(v); } } } }
  1. 起点入队并标记
  2. while 队列非空
  3. 取队首，扩展邻点
  4. 未访问 → 标记 + 入队
标记必须在入队时，不是出队时！否则同一点多次入队 → TLE/MLE。
用 A 连 B、C，B、C 都连 D 的例子讲重复入队。

三、无权图最短路径

性质：BFS 首次到达某点时，经过的边数最少。

原因：按层扩展，第 k 层点距离恰为 k；若有更短路径，会在更早层被访问。

int pre[MAXN]; // 记录前驱，可回溯路径 // 扩展时：pre[v] = u; void print_path(int s, int e) { if (s == e) { cout << s; return; } print_path(s, pre[e]); cout << " -> " << e; }
可用 dist 兼作标记：初始化 -1，dist[v]==-1 表示未访问。
有权图最短路要用 Dijkstra，CSP-J 进阶了解。

四、网格 BFS（迷宫最短步）

int dx[4]={0,0,1,-1}, dy[4]={1,-1,0,0}; int bfs_grid(int sx,int sy,int ex,int ey) { queue<pair<int,int>> q; q.push({sx,sy}); vis[sx][sy]=true; dist[sx][sy]=0; while (!q.empty()) { int x=q.front().first, y=q.front().second; q.pop(); if (x==ex && y==ey) return dist[x][y]; for (int i=0; i<4; i++) { int nx=x+dx[i], ny=y+dy[i]; if (nx>=0 && nx<n && ny>=0 && ny<m && grid[nx][ny]!='#' && !vis[nx][ny]) { vis[nx][ny]=true; dist[nx][ny]=dist[x][y]+1; q.push({nx,ny}); } } } return -1; }
边界检查必须写在前面（短路），否则 grid[nx][ny] 越界 RE！
也可用 struct Node{x,y} 或三元组带 step。

五、层序遍历技巧

需要「按层处理」时：用 sz = q.size() 固定本层节点数。

while (!q.empty()) { int sz = q.size(); for (int i = 0; i < sz; i++) { int u = q.front(); q.pop(); // 处理 u，扩展邻点入队 } level++; }
树的层序遍历、按层统计最值，都用此技巧。与第44课二叉树层序相通。
强调 sz 在循环外取，不能在 for 里用 q.size() 当上限（会变）。

六、DFS / BFS 怎么选

需求选择
无权最短路 / 最少步数BFS
全部路径 / 排列组合DFS 回溯
连通性 / 能否到达两者均可
图特别深（链）BFS 更安全
图特别宽（星形）DFS 空间可能更省
按层处理BFS

时间复杂度（邻接表）：O(V+E)；邻接矩阵 O(V²)——稀疏图务必用表。

最短看 BFS，全部看 DFS，连通看哪个都行
考试选择策略反复强调。

七、模板汇总

// 图上 BFS 求 1 到各点距离 memset(dist, -1, sizeof(dist)); queue<int> q; q.push(1); dist[1] = 0; while (!q.empty()) { int u = q.front(); q.pop(); for (int v : G[u]) if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); } } // 不可达保持 -1

多组数据：每组前重置 vis、dist（memset / fill）。

对照 lesson43 程序演示。

八、易错点

  1. 入队不标 vis → 重复入队
  2. 网格边界检查顺序错 → RE
  3. 多组数据未清空 vis/dist
  4. 混用 DFS/BFS 场景
  5. 图不连通：只从一个起点搜，外层要扫全点
  6. 稀疏图用邻接矩阵 → TLE
  7. 无向图忘记双向建边
自检口诀：入队必标记 · 边界写前面 · 无向写两边 · 不可达输出 -1
让学生检查自己写的模板是否入队时标 vis。

九、真题1：社交距离 · 题意思路

题意：n 用户 m 好友关系（无向），输出用户 1 到每个人的最短社交距离；不可达 -1。n≤1e5,m≤2e5。

样例：边 1-2,2-3,3-4,1-5 → 输出 0,1,2,3,1

思路：标准 BFS 最短路。dist 初值 -1 兼作 vis；无向双向建边；从 1 出发。
输出 n 行每个 dist[i]。

真题1：核心代码

vector<int> G[MAXN]; int dist[MAXN]; // 建无向图后： memset(dist, -1, sizeof(dist)); queue<int> q; q.push(1); dist[1] = 0; while (!q.empty()) { int u = q.front(); q.pop(); for (int v : G[u]) if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); } } for (int i = 1; i <= n; i++) cout << dist[i] << endl;
n 大必须邻接表 + 可选 fast IO。

十、真题2：迷宫逃脱 · 题意思路

题意：n×m 迷宫，. 空地，# 墙，S 起点，E 终点。最短步数；不可达输出 Impossible。

样例 5×5 → 输出 8

思路：读图时记录 S/E 坐标；网格 BFS 四方向；到达 E 得 dist；否则 Impossible。
S、E 也可当作可通行格。

真题2：核心代码

struct Node { int x, y; }; // 找到 sx,sy,ex,ey 后： queue<Node> q; q.push({sx, sy}); vis[sx][sy] = true; dist[sx][sy] = 0; int ans = -1; while (!q.empty()) { Node cur = q.front(); q.pop(); if (cur.x == ex && cur.y == ey) { ans = dist[cur.x][cur.y]; break; } for (int i = 0; i < 4; i++) { int nx = cur.x + dx[i], ny = cur.y + dy[i]; if (nx>=0 && nx<n && ny>=0 && ny<m && grid[nx][ny]!='#' && !vis[nx][ny]) { vis[nx][ny] = true; dist[nx][ny] = dist[cur.x][cur.y] + 1; q.push({nx, ny}); } } } cout << (ans == -1 ? "Impossible" : to_string(ans)) << endl;
实际可直接 if(ans==-1) 分支输出，不必 to_string。

十一、本课小结

  1. BFS：队列 + 逐层扩展，先近后远
  2. 框架：入队标记 → while → 扩展邻点
  3. 无权最短路是 BFS 最重要性质
  4. 网格：四方向 + 边界先判
  5. 层序：sz = q.size()
  6. 与 DFS 分工：最短 BFS，全部 DFS
