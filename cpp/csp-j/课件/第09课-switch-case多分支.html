switch-case 基本语法

switch-case 是一种多分支选择结构，根据表达式的值跳转到对应的 case 标签执行代码。

switch (表达式) { case 常量1: 语句块1; break; case 常量2: 语句块2; break; default: 默认语句块; break; }
考试技巧： switch 的表达式只能是整型、字符型或枚举类型。float、double、string 都不能用于 switch。这是 CSP-J 选择题的常考知识点。
要素说明
switch(表达式)整型/字符型/枚举型，与各 case 常量比较
case 常量:必须是编译期确定的常量（字面量或 const）
break;跳出 switch 结构，防止穿透
default:所有 case 都不匹配时执行（可选但推荐）

break 与穿透现象（Fall-through）

什么是穿透？

当一个 case 执行完毕但没有遇到 break 时，程序会继续执行下一个 case 的代码，直到遇到 break 或 switch 结束。

错误示范：忘记 break
int x = 2; switch (x) { case 1: cout << "A"; case 2: cout << "B"; case 3: cout << "C"; } // 输出 BCD，不是 B！
正确示范：合并 case
switch (grade) { case 'A': cout << "优秀"; break; case 'B': case 'C': cout << "良好"; break; } // B 和 C 共享代码块

穿透现象的合理利用：多个 case 需要执行相同逻辑时，可以让它们共享代码块，减少重复代码。

default 分支与选择策略

default 的作用

当表达式的值与所有 case 都不匹配时执行。用于错误处理或默认行为。习惯上放在末尾，建议也写 break。

switch vs if-else 选择策略

场景推荐结构原因
离散值判断（1,2,3 或 'A','B','C'）switch代码清晰，可合并 case
范围判断（x > 0 && x < 100）if-elsecase 后必须是常量
多变量组合条件if-elseswitch 只能判断一个表达式
浮点数或字符串判断if-elseswitch 不支持这些类型
记忆口诀： 「离散值用 switch，范围判断用 if-else」。switch 表达式只能是整型/字符型/枚举型，遇到浮点数或字符串用 if-else。

真题精练

真题1：简单计算器

输入 a op b（如 10 + 5），根据运算符执行运算并输出结果。除法时分母为 0 需报错。

输入：10 + 5 输出：15 输入：10 / 0 输出：Error: Division by zero
switch (op) { case '+': cout << a + b << endl; break; case '-': cout << a - b << endl; break; case '*': cout << a * b << endl; break; case '/': if (b == 0) cout << "Error: Division by zero"; else cout << a / b << endl; break; default: cout << "Error: Invalid operator"; }

真题2：成绩等级转换

输入 A/B/C/D/F（不区分大小写），输出对应分数范围和评语。

输入：A 输入：c 输出：90-100 优秀 输出：70-79 中等
switch (grade) { case 'A': case 'a': cout << "90-100 优秀"; break; case 'B': case 'b': cout << "80-89 良好"; break; case 'C': case 'c': cout << "70-79 中等"; break; case 'D': case 'd': cout << "60-69 及格"; break; case 'F': case 'f': cout << "0-59 需要努力"; break; default: cout << "无效等级"; }

本课小结

switch 语法
switch(整型/字符型) + case 常量 + break
break 穿透
无 break 会穿透到下一个 case；可合理合并 case
default 分支
兜底处理，当所有 case 不匹配时执行
选择策略
离散值用 switch，范围判断用 if-else
类型限制
表达式不能是 float/double/string
嵌套 switch
内层 break 只跳出内层，外层需单独 break
考试建议： 读代码题常考穿透输出；选择题常考 switch vs if-else 场景判断；编程题常考简单计算器和等级转换。每写完一个 case 就立刻写 break，养成肌肉记忆。
