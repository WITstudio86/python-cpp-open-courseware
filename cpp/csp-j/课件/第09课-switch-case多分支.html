一、多分支的现实需求

当一个变量有多个离散可能取值，且每个取值对应一段独立逻辑时，if-else 链会变得冗长。C++ 提供 switch-case 优雅解决：

  • 计算器：根据运算符 + - * / 执行运算
  • 成绩等级：A/B/C/D/F 转分数范围与评语
  • 菜单系统：输入 1~5 跳转到对应功能
  • 星期几、月份天数、元音字母判断……
选型口诀：离散常量值 → 优先 switch；范围 / 多变量 / 浮点 / 字符串 → 用 if-else。
【讲解】先建立“何时需要 switch”的直觉，再学语法。

二、switch-case 基本语法

switch (表达式) { case 常量1: 语句块1; break; case 常量2: 语句块2; break; default: 默认语句块; break; }
要素说明
switch(表达式)只能是整型 / 字符型 / 枚举，不能 float、double、string
case 常量:编译期常量（字面量或 const），不能是变量；值不可重复
break;跳出 switch，防止穿透
default:所有 case 不匹配时执行（可选但推荐）
考试技巧：「float / string 能否用于 switch」是选择题常考知识点。底层用跳转表，要求 case 为编译期可确定的离散值。
【讲解】表达式类型限制是 CSP-J 高频选择考点。

三、入门示例：星期几

int day = 3; switch (day) { case 1: cout << "星期一" << endl; break; case 2: cout << "星期二" << endl; break; case 3: cout << "星期三" << endl; break; case 4: cout << "星期四" << endl; break; case 5: cout << "星期五" << endl; break; case 6: cout << "星期六" << endl; break; case 7: cout << "星期日" << endl; break; default: cout << "输入错误" << endl; break; } // 输出：星期三

执行：比较 day 与各 case → 跳到匹配标签 → 执行到 break → 离开 switch。

【讲解】对应 lesson09 demo01。default 处理 1~7 之外的非法输入。

四、break 与穿透现象（Fall-through）

case 执行完若没有 break，会继续执行下一个 case，直到遇到 break 或 switch 结束。

错误示范：忘记 break
int x = 2; switch (x) { case 1: cout << "A"; case 2: cout << "B"; case 3: cout << "C"; default: cout << "D"; } // 输出 BCD，不是 B！
穿透表（读程常考）
x输出
1ABCD
2BCD
3CD
4D
肌肉记忆：每写完一个 case 块立刻写 break。写完后脑中模拟每个分支是否意外穿透。
【讲解】对应 lesson09 demo02。读代码题核心：有没有 break、是否穿透。

五、穿透的合理利用：合并 case

元音字母

switch (ch) { case 'a': case 'e': case 'i': case 'o': case 'u': case 'A': case 'E': case 'I': case 'O': case 'U': cout << "元音"; break; default: cout << "辅音"; }

月份天数

switch (month) { case 1: case 3: case 5: case 7: case 8: case 10: case 12: cout << "31天"; break; case 4: case 6: case 9: case 11: cout << "30天"; break; case 2: cout << "28/29天"; break; default: cout << "无效"; }

多个 case 标签可连续写在同一代码块前，减少重复——这是 switch 的重要编码技巧。

【讲解】对应 lesson09 demo03 / demo04。有意穿透 vs 无意穿透。

六、default 分支的作用与位置

default 用于兜底：表达式与所有 case 都不匹配时执行。可放任意位置，习惯放最后；末尾 break 可省，但建议也写以保持一致。

int choice; cin >> choice; switch (choice) { case 1: cout << "新建文件" << endl; break; case 2: cout << "打开文件" << endl; break; case 3: cout << "保存文件" << endl; break; case 4: cout << "退出程序" << endl; break; default: cout << "无效选项，请重新输入！" << endl; break; }
  • 错误处理：预期之外的输入给出提示
  • 默认行为：无匹配时执行通用操作
【讲解】体现程序健壮性；菜单系统是典型场景。

七、switch vs if-else 选择策略

场景推荐原因
离散值（1,2,3 或 'A','B'）switch清晰，可合并 case
范围（x>0 && x<100）if-elsecase 必须是常量
多变量组合条件if-elseswitch 只判一个表达式
浮点 / 字符串if-else类型不支持
分支很少（1~2）if-else 即可更简洁
// 等级字母 → switch switch (grade) { case 'A': ... break; case 'B': ... break; }
// 分数段 → if-else if (score >= 90) ... else if (score >= 80) ... // 不能 case score>=90:
记忆口诀：离散值用 switch，范围判断用 if-else。
【讲解】对应 lesson09 demo06。选择题高频：场景选哪种结构。

八、嵌套 switch

case 内部再写 switch，适合「两级分类」。注意：内层 break 只跳出内层，外层 break 须单独写。

switch (category) { case 1: // 电子产品 cout << "电子产品 -> "; switch (subType) { case 1: cout << "手机"; break; case 2: cout << "电脑"; break; default: cout << "其他"; break; } break; // 外层 break 不能省 case 2: // 食品 ... break; default: cout << "未知分类"; }
【讲解】对应 lesson09 demo05。category=1, subType=2 → 电子产品 -> 电脑。

九、代码模板

经典菜单模板

switch (option) { case 1: cout << "选项1"; break; case 2: cout << "选项2"; break; default: cout << "无效"; break; }

写代码习惯

  1. 先搭框架：switch + 全部 case + default
  2. 再填充各分支逻辑
  3. 每写完一个 case 立刻 break
  4. 最后补 default 健壮性
建议：先写完整骨架再填代码，避免遗漏 case 或漏写 break。
【讲解】编程题先骨架后细节，减少穿透 bug。

十、易错点

1. 忘记 break（最常见） — x==1 时输出「一二三」而非「一」。立刻写 break，养成肌肉记忆。
2. 表达式类型错误
double x = 3.14; switch (x) { ... } // 编译错误 string s = "hi"; switch (s) { ... } // 编译错误
3. case 后用变量 / 重复 case
case b: // 错误：b 是变量 case 1: ... case 1: ... // 错误：重复 case 值
【讲解】类型错误与重复 case 是编译期错误；选择题可能以“能否编译”形式出现。

十一、真题精练一：简单计算器

题目：输入 a op b，按运算符输出结果

输入：10 + 5 输出：15 输入：10 / 0 输出：Error: Division by zero 输入：10 ^ 5 输出：Error: Invalid operator
int a, b; char op; cin >> a >> op >> b; switch (op) { case '+': cout << a + b << endl; break; case '-': cout << a - b << endl; break; case '*': cout << a * b << endl; break; case '/': if (b == 0) cout << "Error: Division by zero" << endl; else cout << a / b << endl; break; default: cout << "Error: Invalid operator" << endl; }

考点：char 作 switch 表达式；除零在 case 内用 if；default 处理非法运算符；每 case 都有 break。

【练习】对应 lesson09 exam01。switch 处理不了范围判断，故除零用 if。

十二、真题精练二：成绩等级转换

题目：输入 A/B/C/D/F（不区分大小写），输出分数范围和评语

输入：A 输入：c 输入：E 输出：90-100 优秀 输出：70-79 中等 输出：无效等级
char grade; cin >> grade; switch (grade) { case 'A': case 'a': cout << "90-100 优秀"; break; case 'B': case 'b': cout << "80-89 良好"; break; case 'C': case 'c': cout << "70-79 中等"; break; case 'D': case 'd': cout << "60-69 及格"; break; case 'F': case 'f': cout << "0-59 需要努力"; break; default: cout << "无效等级"; }

考点：利用穿透合并大小写；比 if-else 链更简洁；default 处理无效输入。

【练习】对应 lesson09 exam02。合并 case 的经典应用。
