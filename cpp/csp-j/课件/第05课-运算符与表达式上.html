一、表达式与运算符概述

表达式：操作数 + 运算符，计算后得到一个值。例如 3+5、a*b+c、x=y+1。

类型操作数个数示例
单目1++a、-x、!flag
双目2a+b、a%b、a=b
三目3a?b:c（第6课）
语句 vs 表达式
a = 5; 是语句（带分号）
a = 5 是表达式（有值 = 5）
表达式可嵌套，语句不行
本课定位：笔试大量「写出输出结果」。三大高频陷阱：自增自减、整数除法、复合赋值优先级。
【讲解】表达式有值；赋值也是表达式。为后文优先级与自增铺垫。

三、取模运算与经典技巧

  • 仅用于整数；结果符号跟随被除数（左操作数）
  • 关系：a = (a/b)*b + (a%b) 恒成立（不溢出时）
  • a%0 与 a/0 均为未定义行为
表达式结果
5 % 32
5 % -32
-5 % 3-2
-5 % -3-2
// 1. 奇偶（负数慎用 ==1） if (n % 2 != 0) { /* 奇 */ } // 2. 个位 / 后 k 位 int d = n % 10; int last2 = n % 100; // 3. 逐位分离 while (n > 0) { int d = n % 10; n /= 10; } // 4. 环形：下一小时 h = (h + 1) % 24;
数位口诀：n%10 个位，n/10%10 十位，n/100%10 百位。注意结合性：n/(10%10) 会除零！
【讲解】Demo2。奇偶、数位、环形是编程题高频应用。

四、赋值运算符

基本赋值 =

  • 方向：右 → 左
  • 赋值表达式有值 = 赋给左边的值
  • 右结合连续赋值
u = v = w = 100; // 等价 w=100; v=w; u=v; // = 不是判断！ if (a = 5) { } // 赋值，恒真 if (a == 5) { } // 判断

复合赋值

运算符等价于
+=a = a + b
-=a = a - b
*=a = a * b
/=a = a / b
%=a = a % b
右侧整体优先：
r *= 2 + 3; → r = r * (2+3) = 25
不是 (r*2)+3 = 13！
【讲解】Demo4。复合赋值优先级很低，右侧先算完。

五、自增自减（高频）· 基础对比

写法名称口诀
++a前置自增先加后用
a++后置自增先用后加
--a / a--自减先减后用 / 先用后减
int a = 5, b; b = ++a; // 先 a→6，再 b=6 // a=6, b=6
int x = 5, y; y = x++; // 先 y=5，再 x→6 // x=6, y=5

单独成语句时，前置与后置最终效果相同；差异只在「表达式中要用该值」时。

int m = 10; cout << m++; // 输出 10，m→11 cout << ++m; // m→12，输出 12
【讲解】口诀「前加后用，先用后加」。Demo3 前半。

六、复杂自增：变量变化表

例：int x=5, y=10; int z = x++ + ++y;

步骤子表达式使用值变量变化
初始——x=5, y=10
1x++5x→6
2++y11y→11
3相加z=16z=16

结果：x=6, y=11, z=16　（不同变量，定义良好）

同一变量多次修改危险：q = ++p + p++; 属未定义/未定序行为！
考试常按「从左到右」简化给分；工程上必须拆成多条语句。
// 安全拆分（模拟从左到右） int p = 3; int left = ++p; // p=4, left=4 int right = p++; // right=4, p=5 int q = left + right; // 8
【讲解】画表法是阅读题核心技能。Demo3 后半。

七、运算符优先级与结合性

口诀（高→低）：单目 > 算术 > 关系 > 逻辑 > 赋值

优先级运算符结合性
高() [] · 单目 ++ -- ! + - *单目右→左
* / % · + -左→右
关系 · 相等 · 位 · 逻辑左→右
?: 三目右→左
低= += *= ... · 逗号 ,赋值右→左
3 + 5 * 2 // 13，不是 16 10 - 3 - 2 // (10-3)-2 = 5 a *= 2 + 3; // a = a*(2+3) a += b += c; // a += (b += c) 右结合 int u = -t + 3; // (-t)+3
考试建议：不确定就加括号；阅读时先括号 → 再优先级 → 再结合性。
【讲解】结合性：算术左、赋值右。复合赋值右侧先算。

八、类型转换与溢出

隐式提升

int a = 5; double b = 2.0; double c = a / b; // 2.5 int x = 5, y = 2; double z = x / y; // 2.0！先整除 double w = 1.0 * x / y; // 2.5

强制转换 · 溢出

(double)a / b // 或 static_cast<double>(a)/b int a = 100000, b = 100000; long long c = a * b; // 错！int 已溢出 long long d = (long long)a * b; // ✓ long long e = a * 1LL * b; // ✓
求值套路：①标运算符查优先级 ②括号从内到外 ③++/-- 画变量表 ④ / % 查是否整数与符号 ⑤复合赋值右侧整体 ⑥逐步写中间结果
【讲解】乘法溢出必须先提升类型。综合求值 6 步。

十一、真题1：复合赋值 + 整数除法

int a = 10, b = 3; cout << a / b << endl; cout << a % b << endl; a += b; cout << a << endl; a *= 2 + 3; cout << a << endl;
语句计算a输出
a/b10/3=3103
a%b10%3=1101
a+=b10+31313
a*=2+313*56565
答案四行：3 · 1 · 13 · 65。关键陷阱：*= 右侧整体优先。
【讲解】先让学生独立写，再对表。对应程序真题验证。

十二、真题2 · 真题3（拓展）

真题2：int x=5,y=10; int z=x++ + ++y; 输出 x,y,z？

答案：x=6, y=11, z=16（x++ 用5；++y 用11）

真题3：

int a=2, b=3, c=4; int d = a + b * c; // 14 int e = (a + b) * c; // 20 a += b += c; // b=7, a=9 cout << d << " " << e << " " << a << " " << b;

答案：14 20 9 7　（* 优先；赋值右结合）

编程拓展：输入正整数 n，输出数位和与个位 → ones=n%10，循环 sum+=t%10; t/=10; 样例 12345 → 15 5
【讲解】真题2不同变量定义良好；真题3优先级+右结合；数位分离实战。

十三、本课小结

知识点核心要点
算术运算+ - * / %；整数除截断；% 仅整数
复合赋值+= -= *= /= %=；右侧整体先算

优先级单目 > 算术 > 关系 > 逻辑 > 赋值
