一、算术运算符

C/C++ 提供了 5 种基本算术运算符：

运算符含义示例结果
+加法7 + 310
-减法7 - 34
*乘法7 * 321
/除法7 / 32（整÷截断）
%取模（余）7 % 31

整数除法截断规则

两个整数相除，结果向 零 方向截断（丢弃小数部分）：7 / 3 = 2、-7 / 3 = -2。

取模运算符号规则

a % b 结果的符号与 a 相同：7 % 3 = 1、-7 % 3 = -1、7 % -3 = 1。

实战技巧：利用 n % 10 获取个位、n / 10 % 10 获取十位、n / 100 % 10 获取百位，以此类推获取数字各位。
【讲解】一、算术运算符 结合讲义《一、算术运算符》强调： · 整数除法规则： · 两个整数相除，结果仍为整数（**小数部分直接丢弃**，向零取整） · 5 / 2 = 2，-5 / 2 = -2（C++11起，向零取整） · 要得到小数结果，需要至少一个操作数为浮点型：5.0 / 2 或 (double)5 / 2 · 取模运算规则： 幻灯片上可见要点： · C/C++ 提供了 5 种基本算术运算符： · 整数除法截断规则 · 两个整数相除，结果向 零 方向截断（丢弃小数部分）： 7 / 3 = 2 、 -7 / 3 = -2 。 · 取模运算符号规则 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：算术运算符、赋值运算符、自增自减、运算符优先级

二、自增自减运算符 （高频考点）

前置 ++a / --a

先自增/自减 后取值

int a = 5, b; // 前置：a先变成6，再赋给b b = ++a; // 结果：a=6, b=6

后置 a++ / a--

先取值 后自增/自减

int a = 5, b; // 后置：先取a的值5赋给b，a再变成6 b = a++; // 结果：a=6, b=5

记忆口诀：「前加后用，先用后加」 — 符号在前就先加后用，符号在后就先用后加。

复杂表达式分析

int a = 3; int b = ++a + a++; // 注意：为学习分析思路，实际编程请勿写此类表达式 // ++a: a变为4，值为4 // a++: 先取值4，a变为5 // b = 4 + 4 = 8，最终 a=5, b=8
【讲解】二、自增自减运算符 （高频考点） 结合讲义《三、自增自减运算符（++ / --）》强调： · 这是CSP-J考试的**高频考点**，务必掌握！ · 基本形式： · 记忆口诀：**前加后用（前置：先加后用），先用后加（后置：先用后加）** · 经典例题： · int a = 5, b; 幻灯片上可见要点： · 前置 ++a / --a · 先自增/自减 后取值 · 后置 a++ / a-- · 先取值 后自增/自减 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

三、复合赋值运算符与优先级

复合赋值运算符

运算符等效写法
+=a = a + n
-=a = a - n
*=a = a * n
/=a = a / n
%=a = a % n

注意：a *= 2 + 3 等价于 a = a * (2 + 3)！

运算符优先级表

优先级运算符类别
1（最高）单目：++ -- ! ~ + -(取正负)
2算术：* / %
3算术：+ -
4关系：< <= > >=
5关系：== !=
6逻辑：&&
7逻辑：||
8（最低）赋值：= += -= 等

优先级口诀：「单目 > 算术 > 关系 > 逻辑 > 赋值」

结合性：赋值运算符是 右结合：a = b = c = 5 先执行 c = 5，再 b = c，最后 a = b。

#include <iostream> using namespace std; int main() { int a = 7, b = 3; cout << a / b << endl; // 2 —— 整数除法 cout << 1.0 * a / b << endl; // 2.33333 —— 浮点除法 cout << (double)a / b << endl; // 2.33333 —— 强制转换 return 0; }

自增自减逐步分析

int x = 5; int y = ++x; // x: 5→6, y=6 int z = x++; // z=6, x: 6→7 cout << x << " " << y << " " << z; // 输出：7 6 6

逐步分析

步骤表达式结果说明
①10 / 33整数除法截断
②10 % 31余数
