STL容器：stack与queue

第24课 · CSP-J 备考课程

后进先出 vs 先进先出——两种最基本的受限数据结构

stack栈(LIFO) | queue队列(FIFO) | 括号匹配 | 约瑟夫问题 | BFS预备

Stack（栈）——后进先出 LIFO

现实中的栈

  • 一摞盘子：最后放上去的，第一个被拿走
  • 浏览器后退按钮：最后访问的页面最先回去
  • 撤销操作 (Ctrl+Z)：最后做的操作最先被撤销
  • 函数调用栈：最后调用的函数最先返回

声明与核心操作

#include <stack> using namespace std; stack<int> s; s.push(10); // 压入栈顶 s.push(20); s.push(30); cout << s.top(); // 输出 30（栈顶元素） cout << s.size(); // 输出 3 s.pop(); // ⚠️ 不返回元素！只删除栈顶 cout << s.top(); // 输出 20 cout << s.empty(); // 输出 0 (false, 不为空)
操作说明复杂度
s.push(x)元素x压入栈顶O(1)
s.pop()弹出栈顶（不返回值！）O(1)
s.top()返回栈顶元素（不弹出）O(1)
s.empty()是否为空O(1)
s.size()元素个数O(1)

⚠️ 最重要的坑

  • pop() 不返回值！必须先 top() 再 pop()
  • 对空栈调用 top() 或 pop() → 未定义行为，比赛直接0分
  • 每次操作前用 empty() 检查是好习惯

Queue（队列）——先进先出 FIFO

现实中的队列

  • 排队买票：排在最前面的人最先买到
  • 打印队列：先提交的文档先被打印
  • 消息队列：先收到的消息先处理

声明与核心操作

#include <queue> using namespace std; queue<int> q; q.push(10); // 加入队尾 q.push(20); q.push(30); cout << q.front(); // 输出 10（队首，最先进入的） cout << q.back(); // 输出 30（队尾，最后进入的） cout << q.size(); // 输出 3 q.pop(); // ⚠️ 也不返回元素！移除队首 cout << q.front(); // 输出 20（新队首） cout << q.empty(); // 输出 0 (false)
操作说明复杂度
q.push(x)元素x加入队尾O(1)
q.pop()移除队首（不返回值！）O(1)
q.front()返回队首元素（不移除）O(1)
q.back()返回队尾元素（不移除）O(1)
q.empty()是否为空O(1)
q.size()元素个数O(1)
Stack vs Queue 直观对比：
同样的 push(1) push(2) push(3)：
Stack 弹出：3 → 2 → 1（后进先出）
Queue 弹出：1 → 2 → 3（先进先出）

应用1：括号匹配（Stack经典题）

算法思路

  1. 遇到左括号（( [ {）→ 压入栈中
  2. 遇到右括号 → 检查栈顶是否匹配：
    • 栈空 → 失败（右括号多了）
    • 栈顶类型不匹配 → 失败
    • 栈顶匹配 → 弹出栈顶，继续
  3. 遍历结束后：栈空 → 完全匹配！栈非空 → 左括号多了

完整代码

#include <iostream> #include <stack> #include <string> using namespace std; bool isValid(string s) { stack<char> st; for (char ch : s) { if (ch == '(' || ch == '[' || ch == '{') { st.push(ch); // 左括号入栈 } else { if (st.empty()) return false; // 右括号多了 char top = st.top(); if ((ch == ')' && top != '(') || (ch == ']' && top != '[') || (ch == '}' && top != '{')) return false; // 类型不匹配 st.pop(); // 匹配成功，弹出 } } return st.empty(); // 栈空才算完全匹配 } int main() { cout << boolalpha; cout << "() → " << isValid("()") << endl; // true cout << "()[]{} → " << isValid("()[]{}") << endl; // true cout << "(] → " << isValid("(]") << endl; // false cout << "([)] → " << isValid("([)]") << endl; // false cout << "{[]} → " << isValid("{[]}") << endl; // true return 0; }

时间复杂度

O(n) 时间，O(n) 空间。每个字符恰好入栈一次、出栈一次。

应用2&3：约瑟夫问题 + 服务窗口模拟

约瑟夫问题（Queue）

n个人围成一圈，每数到m的人出列，求出列顺序。

int n = 5, m = 3; queue<int> q; for (int i = 1; i <= n; i++) q.push(i); while (!q.empty()) { // 前 m-1 人移到队尾 for (int i = 1; i < m; i++) { q.push(q.front()); q.pop(); } // 第 m 人出列 cout << q.front() << " "; q.pop(); } // 输出: 3 1 5 2 4

核心思想：模拟循环 → 前移m-1个到队尾，第m个出队。

服务窗口模拟（Queue）

n个客户排队，每个有到达时间和所需服务时间，单窗口FIFO服务。

queue<Customer> q; // 所有客户入队 int curTime = 0, totalWait = 0; while (!q.empty()) { Customer c = q.front(); q.pop(); if (curTime < c.arriveTime) curTime = c.arriveTime; int wait = curTime - c.arriveTime; totalWait += wait; curTime += c.serveTime; cout << "等待:" << wait << endl; } cout << "平均等待:" << (double)totalWait / n;

核心思想：按到达顺序入队，逐个出队处理，统计等待时间。

两种队列模式的本质：
约瑟夫 = 循环队列（元素不断从队首移到队尾）
服务模拟 = 标准FIFO（元素依次出队，不再回来）

三套代码模板 + BFS预备

模板1：括号匹配

stack<char> st; for (char ch : s) { if (左括号) st.push(ch); else { if (st.empty() || 不匹配) return false; st.pop(); } } return st.empty();

模板2：约瑟夫问题

queue<int> q; for (i=1..n) q.push(i); while (!q.empty()) { for (i=1..m-1) { q.push(q.front()); q.pop(); } cout << q.front(); q.pop(); }

模板3：十进制转二进制（Stack反转顺序）

stack<int> s; while (n > 0) { s.push(n % 2); n /= 2; } while (!s.empty()) { cout << s.top(); s.pop(); } // 余数压栈再弹出 = 自然反转

BFS预备——队列的核心价值

// BFS = 队列逐层扩展 queue<int> q; q.push(start); visited[start] = true; while (!q.empty()) { int cur = q.front(); q.pop(); for (每个邻居) { if (!visited[neighbor]) { visited[neighbor] = true; q.push(neighbor); // 下一层入队 } } }

一句话理解BFS

队列就是一个待处理列表，同一层的节点几乎同时入队，又按顺序被处理，自然实现了"一层一层向外扩展"。

⚠️ 五大易错点 + 真题精练

易错1: pop()不返回值

❌ int x = s.pop();（编译错误！）
✅ int x = s.top(); s.pop();

易错2: 空容器操作

每次 top()/front()/pop() 前必须 empty() 检查！

易错3: 忘记头文件

stack → #include <stack>
queue → #include <queue>

易错4: front vs back 搞混

front() = 队首（最先入队，下次pop移除）
back() = 队尾（最后入队，最新添加的）

易错5: 不支持遍历

stack/queue 没有 [] 下标、没有迭代器、不能范围for。需要遍历请用 vector。

真题1：有效括号

输入： ()[]{}
输出： YES

输入： ([)]
输出： NO

栈应用题。左括号入栈，右括号弹栈匹配。两个失败条件：栈空时遇到右括号；遍历完栈非空。

真题2：纸牌游戏

输入：
5
3 5 1 8 2
4 6 9 7 10
输出：
B WIN
9

双队列对战。每轮双方各出一张牌（front + pop），大牌方将两张牌收入自己牌堆底（push + push）。设轮数上限防死循环。

本课小结

知识点关键内容一句记忆
Stackpush进入, top查看, pop移除后进先出，像一摞盘子
Queuepush进入, front看队首, back看队尾, pop移除先进先出，像排队买票
括号匹配左括号进栈，右括号匹配栈顶弹出栈的经典应用
约瑟夫问题前m-1人移到队尾，第m人出队队列循环模型
pop不返回值先top/front取值，再pop移除最易错的STL设计
priority_queue默认大顶堆，top返回最大值需要"优先"时用它
