STL容器：stack与queue

第24课 · CSP-J 备考课程

后进先出 vs 先进先出——两种最基本的受限数据结构

stack栈(LIFO) | queue队列(FIFO) | 括号匹配 | 约瑟夫问题 | BFS预备

为什么需要 Stack 和 Queue？

数组和 vector 解决的是"存数据"的问题，但竞赛中我们经常遇到需要按特定顺序处理数据的场景：

Stack（栈）适用场景

括号嵌套匹配：遇到左括号先存着，遇到右括号时应该匹配最后一个左括号

→ 后进先出（LIFO）

Queue（队列）适用场景

排队叫号：先到的人先服务

→ 先进先出（FIFO）

为什么不用数组手写？

数组手写这些逻辑代码多、容易错。STL 提供了现成的 stack 和 queue，几行代码就能搞定，帮你把注意力集中在算法本身。

Stack（栈）——后进先出 LIFO

现实中的栈

  • 一摞盘子：最后放上去的盘子，第一个被拿走
  • 浏览器后退按钮：最后访问的页面，后退时最先回去
  • 撤销操作 (Ctrl+Z)：最后做的操作，撤销时最先被还原
  • 函数调用栈：最后一个调用的函数最先返回

头文件与声明

#include <stack> using namespace std; stack<int> s; // 存储int的栈 stack<char> charStack; // 存储char的栈 stack<string> strStack; // 存储string的栈

核心操作

操作说明时间复杂度
s.push(x)将元素x压入栈顶O(1)
s.pop()弹出栈顶元素（不返回！）O(1)
s.top()返回栈顶元素（不弹出）O(1)
s.empty()判断栈是否为空O(1)
s.size()返回栈中元素个数O(1)

最重要的坑！

pop() 不返回值！要获取栈顶元素必须先 top()，再 pop()。这和某些其他语言（如Python的 list.pop()）完全不一样。

Stack 完整操作演示

#include <iostream> #include <stack> using namespace std; int main() { stack<int> s; // 压入三个元素 s.push(10); s.push(20); s.push(30); cout << "栈顶: " << s.top() << endl; // 输出 30 cout << "大小: " << s.size() << endl; // 输出 3 // 依次弹出 while (!s.empty()) { cout << "弹出: " << s.top() << endl; // 先取值 s.pop(); // 再弹出 } // 输出顺序: 30, 20, 10（后进先出） cout << "栈是否为空: " << (s.empty() ? "是" : "否") << endl; return 0; }

执行过程追踪

步骤操作栈内容（栈顶→栈底）top()size()
0创建[]-0
1push(10)[10]101
2push(20)[20, 10]202
3push(30)[30, 20, 10]303
4pop()[20, 10]202
5pop()[10]101
6pop()[]-0
底层实现：STL 中 stack 默认基于 deque（双端队列）实现。竞赛中不需要关心底层，用默认的 stack<int> 就行。

Queue（队列）——先进先出 FIFO

现实中的队列

  • 排队买票：排在最前面的人最先买到票
  • 打印队列：先提交的文档先被打印
  • 消息队列：先收到的消息先被处理

头文件与声明

#include <queue> using namespace std; queue<int> q; // 存储int的队列 queue<string> nameQueue; // 存储string的队列

核心操作

操作说明时间复杂度
q.push(x)将元素x添加到队尾O(1)
q.pop()移除队首元素（不返回！）O(1)
q.front()返回队首元素（不移除）O(1)
q.back()返回队尾元素（不移除）O(1)
q.empty()判断队列是否为空O(1)
q.size()返回队列中元素个数O(1)

完整操作演示

#include <iostream> #include <queue> using namespace std; int main() { queue<int> q; q.push(10); q.push(20); q.push(30); cout << "队首: " << q.front() << endl; // 输出 10 cout << "队尾: " << q.back() << endl; // 输出 30 cout << "大小: " << q.size() << endl; // 输出 3 while (!q.empty()) { cout << "出队: " << q.front() << endl; q.pop(); } // 输出顺序: 10, 20, 30（先进先出） return 0; }
直观对比：同样的 push(1) push(2) push(3)：
Stack 弹出：3 → 2 → 1（后进先出）
Queue 弹出：1 → 2 → 3（先进先出）

应用1：括号匹配（Stack 经典题）

算法步骤

  1. 遍历字符串中的每个字符
  2. 遇到左括号（(、[、{）→ 压入栈中
  3. 遇到右括号 → 检查栈是否为空：
    • 栈空 → 匹配失败（右括号多了）
    • 栈顶不是对应的左括号 → 匹配失败（类型不匹配）
    • 栈顶是对应的左括号 → 弹出栈顶，继续遍历
  4. 遍历结束后：栈空 → 完全匹配！栈非空 → 匹配失败（左括号多了）

AC 代码

#include <iostream> #include <stack> #include <string> using namespace std; bool isValid(string s) { stack<char> st; for (char ch : s) { if (ch == '(' || ch == '[' || ch == '{') { st.push(ch); } else { if (st.empty()) return false; char top = st.top(); if ((ch == ')' && top == '(') || (ch == ']' && top == '[') || (ch == '}' && top == '{')) { st.pop(); } else { return false; } } } return st.empty(); } int main() { cout << boolalpha; cout << "() -> " << isValid("()") << endl; // true cout << "()[]{} -> " << isValid("()[]{}") << endl; // true cout << "(] -> " << isValid("(]") << endl; // false cout << "([)] -> " << isValid("([)]") << endl; // false cout << "{[]} -> " << isValid("{[]}") << endl; // true return 0; }

复杂度分析

时间复杂度 O(n)，空间复杂度 O(n)。每个字符恰好入栈一次、出栈一次。

Queue 三大应用场景

约瑟夫问题

n个人围成一圈，数到m的人出列。求出列顺序。

int n = 5, m = 3; queue<int> q; for (int i = 1; i <= n; i++) q.push(i); while (!q.empty()) { for (int i = 1; i < m; i++) { q.push(q.front()); q.pop(); } cout << q.front() << " "; q.pop(); } // 输出: 3 1 5 2 4

核心：前m-1人从队首移到队尾，第m人出队。

服务窗口模拟

n个客户排队，单窗口FIFO服务，统计等待时间。

int curTime = 0; while (!q.empty()) { Customer c = q.front(); q.pop(); if (curTime < c.arriveTime) curTime = c.arriveTime; int wait = curTime - c.arriveTime; curTime += c.serveTime; }

核心：按到达顺序入队，逐个出队处理。

BFS 预备知识

// BFS = 队列逐层扩展 queue<int> q; q.push(start); visited[start] = true; while (!q.empty()) { int cur = q.front(); q.pop(); for (每个邻居 neighbor) { if (!visited[neighbor]) { visited[neighbor] = true; q.push(neighbor); // 下一层入队 } } }

一句话理解 BFS

队列就是一个待处理列表。同一层的节点几乎同时入队，又按顺序被处理，自然实现了"一层一层向外扩展"。

priority_queue 与选择指南

priority_queue（优先队列）

C++ 还提供了优先队列，默认是大顶堆（最大值先出队）：

#include <queue> priority_queue<int> pq; // 大顶堆，最大值在队首 pq.push(3); pq.push(1); pq.push(5); cout << pq.top(); // 输出 5（最大值） pq.pop(); cout << pq.top(); // 输出 3 // 小顶堆（最小值在队首） priority_queue<int, vector<int>, greater<int>> minHeap;

Stack vs Queue 选择指南

场景特征应该用...原因
最后进来的先处理StackLIFO
先进来的先处理QueueFIFO
括号匹配、表达式求值Stack嵌套结构→后进先出
排队模拟、轮流处理Queue公平顺序→先进先出
函数递归的迭代版Stack模拟调用栈
逐层扩展（BFS）Queue按层次顺序
每次取最大/最小值priority_queue堆结构
一句话总结：需要"往回找"用栈，需要"按顺序走"用队列。

五大易错点

易错1：pop() 不返回元素值

❌ int x = s.pop();（编译错误！pop() 返回 void）
✅ int x = s.top(); s.pop();（先取值，再弹出）

易错2：对空容器操作

对空栈调用 top() 或 pop() → 未定义行为！
每次操作前必须用 empty() 检查。

易错3：忘记头文件

stack → #include <stack>
queue 和 priority_queue → #include <queue>

易错4：front() 和 back() 搞混

front() = 队首（最先入队，下次 pop 移除的）
back() = 队尾（最后入队，最新添加的）

易错5：stack/queue 不支持遍历

没有 [] 下标、没有迭代器、不能范围 for。
需要遍历请用 vector。

真题精练

题目1：有效的括号

输入： ()[]{}
输出： YES

输入： ([)]
输出： NO

栈应用题。左括号入栈，右括号弹栈匹配。两个失败条件：栈空时遇到右括号；遍历完栈非空。时间复杂度 O(n)。

题目2：纸牌游戏（双队列对战）

输入：
5
3 5 1 8 2
4 6 9 7 10
输出：
B WIN
9

双队列对战。每轮双方各出一张牌（front + pop），大牌方将两张牌收入自己牌堆底（push + push）。设轮数上限（如1000轮）防死循环。

题目3：十进制转二进制（Stack 反转）

stack<int> s; while (n > 0) { s.push(n % 2); n /= 2; } while (!s.empty()) { cout << s.top(); s.pop(); } // 余数压栈再弹出 = 自然反转顺序

利用 Stack 的 LIFO 特性实现顺序反转，是竞赛中的常见技巧。
