stack 与 queue

LIFO · FIFO · 括号匹配 · 约瑟夫 · BFS 预备
CSP-J 备考 · 配套 lesson24_STL容器stack与queue.cpp
【开场】按特定顺序处理数据的两大利器。

考纲与为什么需要

容器语义核心操作
stack后进先出 LIFOpush / pop / top / empty / size
queue先进先出 FIFOpush / pop / front / back / empty / size
应用括号、排队、BFS 预备—
  • 括号匹配：最后出现的左括号应最先匹配 → 栈
  • 叫号服务：先到先服务 → 队列
【讲解】盘子摞 vs 买票队伍。

一、Stack：后进先出

#include <stack> stack<int> s; s.push(10); s.push(20); s.push(30); cout << s.top(); // 30 只读栈顶 s.pop(); // 弹出，不返回值！ while (!s.empty()) { cout << s.top(); s.pop(); // 先 top 再 pop }
push 10,20,30 → 栈顶 30 pop → 20；再 pop → 10；再 pop → 空 输出弹出序列：30 20 10
最大坑：pop() 无返回值！取值必须先 top()。
【讲解】浏览器后退、调用栈也是栈。

二、Queue：先进先出

#include <queue> queue<int> q; q.push(10); q.push(20); q.push(30); cout << q.front(); // 10 队首 cout << q.back(); // 30 队尾 q.pop(); // 移除队首，无返回值 while (!q.empty()) { cout << q.front(); q.pop(); // 10 20 30 }
对比stackqueue
取端点top()front() / back()
弹出pop 栈顶pop 队首
顺序后进先出先进先出
【讲解】front≠back；空容器勿访问。

三、应用：括号匹配（Stack）

  1. 左括号压栈
  2. 右括号：栈空失败；否则与栈顶类型匹配则弹，否则失败
  3. 结束时栈必须空
bool isValid(string s) { stack<char> st; for (char ch : s) { if (ch=='('||ch=='['||ch=='{') st.push(ch); else { if (st.empty()) return false; char t = st.top(); if ((ch==')'&&t=='(')||(ch==']'&&t=='[')||(ch=='}'&&t=='{')) st.pop(); else return false; } } return st.empty(); }
【讲解】([)] 失败；{[]} 成功。

四、应用：约瑟夫问题（Queue）

n 人围圈，数到 m 出列。队列模拟：前 m−1 人队首→队尾，第 m 人出队。

queue<int> q; for (int i = 1; i <= n; i++) q.push(i); while (!q.empty()) { for (int i = 1; i < m; i++) { q.push(q.front()); q.pop(); } cout << q.front() << " "; q.pop(); // 出列 } // n=5,m=3 → 3 1 5 2 4
[1,2,3,4,5] → 移1,2 → 出3 → [4,5,1,2] → 移4,5 → 出1 → …
【讲解】手推一轮加深。

五、服务窗口与 BFS 预备

窗口模拟： 客户入队，按到达时间推进 currentTime，算等待。

// BFS 骨架（后续图论核心） queue<int> q; q.push(start); vis[start] = true; while (!q.empty()) { int cur = q.front(); q.pop(); for (邻居 nxt : g[cur]) if (!vis[nxt]) { vis[nxt] = true; q.push(nxt); } }
BFS 逐层扩展 = 队列 FIFO：先入队的先处理，自然按层。
【讲解】不必展开完整图论，先建立「待处理列表」直觉。

六、priority_queue 与选型

#include <queue> priority_queue<int> pq; // 大顶堆，最大先出 pq.push(3); pq.push(1); pq.push(5); cout << pq.top(); // 5 // 小顶堆： priority_queue<int, vector<int>, greater<int>> minH;
场景容器
最后处理最新的stack
先来先处理 / BFSqueue
每次取最大/最小priority_queue
【讲解】CSP-J 哈夫曼等会用优先队列。

代码模板

// 1 括号匹配：左压栈，右对 top 匹配 // 2 约瑟夫：for 1..m-1 队首转队尾，再 pop 出列 // 3 十进制转二进制（stack） stack<int> st; if (n == 0) cout << 0; while (n) { st.push(n % 2); n /= 2; } while (!st.empty()) { cout << st.top(); st.pop(); }
完整模板见讲义：括号 / 约瑟夫 / 进制转换。
【讲解】进制转换用栈逆序输出。

易错点

1. pop() 不返回元素 —— 先 top/front 再 pop
2. 空容器上 pop / top / front → 未定义行为，先 empty()
3. 忘记 #include <stack> / <queue>
4. front（队首）与 back（队尾）搞反
5. stack/queue 不能 下标遍历，只能按接口访问
【讲解】与 vector 对比限制。

真题1：有效的括号

题目

字符串只含 ()[]{}，判断是否有效。输出 YES / NO。

()[]{} → YES；([)] → NO

stack<char> st; bool ok = true; for (char ch : s) { if (ch=='('||ch=='['||ch=='{') st.push(ch); else if (ch==')'||ch==']'||ch=='}') { if (st.empty()) { ok = false; break; } // 匹配则 pop，否则 ok=false } } if (!st.empty()) ok = false; cout << (ok ? "YES" : "NO") << endl;
【练习】三种失败：右多、类型错、左多。

真题2：纸牌游戏（双队列）

题目

A、B 各 n 张牌，每轮各出队首比大小：大者两牌入己队尾（先己后对方）；平则各自收回。一方空结束；>1000 轮 DRAW。

queue<int> a, b; // 读入各自 n 张 push while (!a.empty() && !b.empty() && rounds < 1000) { rounds++; int ca = a.front(); a.pop(); int cb = b.front(); b.pop(); if (ca > cb) { a.push(ca); a.push(cb); } else if (cb > ca) { b.push(cb); b.push(ca); } else { a.push(ca); b.push(cb); } }
【练习】样例 B WIN 9 轮；强调轮数上限防死循环。
