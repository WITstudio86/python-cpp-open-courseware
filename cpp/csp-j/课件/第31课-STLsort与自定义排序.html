STL sort 与自定义排序

第31课 · CSP-J 备考课程

竞赛真正用的排序——O(n log n)

sort | greater | cmp | 结构体多关键字 | stable_sort

【开场】第1/14页。手写排序理解原理，比赛用 sort。

考纲要求

考点要点
sort 基本用法默认升序，[begin, end)
自定义 cmptrue = a 排在 b 前
greater / less仿函数降序/升序
结构体多关键字成绩降、学号升
stable_sort需要稳定性时
头文件 <algorithm>。时间 O(n log n)，远快于 O(n²) 手写排序。
【讲解】复赛几乎不手写冒泡。

一、sort 基本用法

#include <algorithm> int a[] = {5,3,8,1,9,2,7,4,6}; sort(a, a + n); // a[0]..a[n-1] 升序 sort(a + 2, a + 7); // 只排 a[2]..a[6] vector<int> v = {...}; sort(v.begin(), v.end()); // vector
  • 区间是左闭右开 [begin, end)
  • a+n 指向末元素的下一个位置
【讲解】画数组指针。

二、自定义 cmp

sort(begin, end, cmp)：cmp(a,b) 返回 true 表示 a 应排在 b 前面。

bool cmp(int a, int b) { return a > b; // 大的在前 → 降序 } sort(a, a + n, cmp);

口诀

想让「谁」在前，就在 return 里让「谁」比较胜出。a=5,b=3 时 a>b 为 true → 5 在 3 前 → 降序。

【讲解】不是 return a<b 却期望降序。

三、greater 与 less

#include <functional> sort(a, a + n, greater<int>()); // 降序 sort(a, a + n, less<int>()); // 升序（默认）
简单降序用 greater<int>()；复杂规则写 cmp。仿函数可被内联，略快。
【讲解】竞赛两种都行。

四、结构体多关键字

struct Student { int id; string name; int score; }; bool cmp(const Student& a, const Student& b) { if (a.score != b.score) return a.score > b.score; // 成绩降序 return a.id < b.id; // 同分学号升序 } sort(stu, stu + n, cmp);

通用模式：高优先级 if 不等则 return；最后一键直接 return 比较。

【讲解】输出 Bob92 Eve92 Alice85…

五、pair 取负技巧

pair<int, int> arr[] = { {-85, 101}, {-92, 102}, {-85, 103}, ... }; sort(arr, arr + n); // first 升序 = 成绩降序 // 成绩 = -arr[i].first，学号 = arr[i].second
pair 默认：先 first 升序，再 second 升序。需要 first 降序时存负数，免写 cmp。
【讲解】优先队列小根堆也常用取负。

六、stable_sort

stable_sort(a, a + n, cmp); // 相等元素保相对顺序
  • 用法同 sort，保证稳定
  • 内部多归并，常数略大；不需稳定时优先 sort
  • 场景：已按 A 排好，再按 B 排且要保留 A 的次序
【讲解】sort 不稳定（内省排序）。

七、严格弱序：相等必须 false

致命错误

return a >= b; 当 a==b 时返回 true，同时 b>=a 也 true → 违反严格弱序 → 崩溃/乱序。

正确：return a > b;（相等时 false）

cmp 必须：非自反、非对称、传递。相等时双方都 return false。
【讲解】Runtime Error 常因 cmp 写错。

八、代码模板汇总

sort(a, a+n); sort(a, a+n, greater<int>()); sort(v.begin(), v.end()); bool cmpDesc(int a, int b) { return a > b; } bool cmpNode(const Node& x, const Node& y) { if (x.a != y.a) return x.a > y.a; if (x.b != y.b) return x.b < y.b; return x.c < y.c; } stable_sort(a, a+n, cmp);
【讲解】四模板。

九、易错点

1. cmp 方向反

true=排前面；降序写 a>b。

2. 相等返回 true

禁用 >= / <= 当主比较。

3. 忘记 algorithm

#include <algorithm>

4. 区间写错

sort(a, a+n) 不是 a+n-1 作 end（end 是开区间端）。

5. 结构体没写全关键字

成绩相同未规定学号 → 顺序不定，输出对拍失败。

【讲解】五条过一遍。

十、真题风格①：成绩排名

n 名学生：成绩降序，同分学号升序，输出排名表。

bool cmp(const Student& a, const Student& b) { if (a.score != b.score) return a.score > b.score; return a.id < b.id; } sort(stu, stu + n, cmp);
【练习】当堂写 cmp。

十一、真题风格②：坐标排序

点 (x,y)：先 x 升序，x 同则 y 升序。

bool cmp(const pair<int,int>& a, const pair<int,int>& b) { if (a.first != b.first) return a.first < b.first; return a.second < b.second; } // 其实 pair 默认就是这样，直接 sort(p, p+n) 即可！
【讲解】默认 pair 排序很香。

十二、真题风格③：需要稳定时

先按班级排序，再按成绩排序，要求同成绩保持原班级内相对序 → 用 stable_sort 按成绩；或把班级并入关键字。

不需稳定：sort。需要稳定或分步排序保序：stable_sort。
【讲解】读题关键字「相对顺序不变」。

十三、选型速查

需求写法
普通升序sort(a,a+n)
普通降序greater<int>()
多关键字自定义 cmp
稳定stable_sort
双关键字简单pair / 取负
【讲解】过渡二分。

十四、本课小结

知识点一句记忆
sort[begin,end) 默认升序
cmptrue = a 在前
greater一行降序
多关键字if 不等 return；相等比下一键
严格弱序相等必须 false
stable_sort要稳定才用
