sort() 基础用法

头文件 <algorithm>，O(n log n) 的快速排序实现

  • 基本语法：sort(begin, end) — 对 [begin, end) 区间（左闭右开）进行升序排列。
  • 降序排列：sort(begin, end, greater<int>()) — 第三个参数传入比较函数对象。
  • 底层实现：C++ 标准库的 sort 使用内省排序（Introsort），混合了快速排序、堆排序和插入排序，保证最坏 O(n log n)。
  • 使用前提：元素类型必须支持 < 运算符，或提供自定义比较函数。
// 头文件
#include <algorithm>

int a[] = {5, 2, 8, 1, 9};
int n = 5;

// 升序排序
sort(a, a + n);                         // 结果: [1, 2, 5, 8, 9]

// 降序排序
sort(a, a + n, greater<int>());         // 结果: [9, 8, 5, 2, 1]

// 对 vector 的用法
vector<int> v = {5, 2, 8};
sort(v.begin(), v.end());              // 结果: [2, 5, 8]
📝 考试技巧： sort 的区间是左闭右开 [begin, end)。对数组 a[0..n-1] 排序，应写 sort(a, a + n) 而不是 sort(a, a + n - 1)。

自定义 cmp 函数

核心规则：cmp(a, b) 返回 true 表示 a 应该排在 b 的前面

  • 升序：return a < b; — a 小于 b 时 a 排前面。
  • 降序：return a > b; — a 大于 b 时 a 排前面。
  • cmp 必须满足严格弱序：不能同时 cmp(a,b) 和 cmp(b,a) 都为 true，否则排序行为未定义。

示例一：按绝对值升序排序

bool cmpAbs(int a, int b) {
    return abs(a) < abs(b);   // 绝对值小的排前面
}
// 输入: [-5, 3, -1, 8, -8]
// 输出: [-1, 3, -5, 8, -8]  (abs值: 1,3,5,8,8，相等时不稳定)

示例二：奇偶分组排序（奇数在前升序，偶数在后升序）

bool cmpOddEven(int a, int b) {
    if (a % 2 != b % 2)
        return a % 2 > b % 2;  // 奇数(1) > 偶数(0)，奇数优先
    return a < b;                    // 同组内升序
}
// 输入: [5, 2, 8, 1, 9, 4]
// 输出: [1, 5, 9, 2, 4, 8]
【讲解】自定义 cmp 函数 结合讲义《二、自定义比较函数 cmp》强调： · sort() 的完整调用形式实际上是三参数版本： · sort(起始地址, 结束地址, 比较函数); · 第三个参数是一个**比较函数**（或仿函数），用于定义排序规则。比较函数 cmp(a, b) 需要返回一个 bool 值： · 返回 true：表示 a 应该**排在 b 的前面** · 返回 false：表示 a 不应该排在 b 的前面（即 b 排在 a 前面或二者等价） 幻灯片上可见要点： · 升序： return a < b; — a 小于 b 时 a 排前面。 · 降序： return a > b; — a 大于 b 时 a 排前面。 · cmp 必须满足严格弱序： 不能同时 cmp(a,b) 和 cmp(b,a) 都为 true，否则排序行为未定义。 · cmp 必须满足严格弱序： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

结构体多关键字排序

典型应用：学生成绩排名 — 按总分降序、总分相同按学号升序、学号相同按姓名字典序

struct Student {
    string name;
    int id, score;
};

bool cmp(const Student& a, const Student& b) {
    if (a.score != b.score)
        return a.score > b.score;        // 成绩高的在前
    if (a.id != b.id)
        return a.id < b.id;              // 学号小的在前
    return a.name < b.name;               // 名字字典序小的在前
}

// 调用
sort(stu, stu + n, cmp);

Lambda 表达式写法（推荐！简洁易读）

sort(stu, stu + n, [](const Student& a, const Student& b) {
    if (a.score != b.score) return a.score > b.score;
    if (a.id != b.id) return a.id < b.id;
    return a.name < b.name;
});
📝 考试技巧： Lambda 表达式是 C++11 特性，CSP-J 复赛环境（如 NOI Linux 2.0）完全支持。Lambda 写法将比较逻辑写在 sort 调用处，避免定义全局函数，减少命名冲突，强烈推荐使用！
【讲解】结构体多关键字排序 结合讲义《四、结构体多关键字排序》强调： · 这是 CSP-J 中最常考、最实用的自定义排序场景。比如有一个学生信息结构体，要求： · 先按总成绩降序排列（成绩高的在前） · 成绩相同时按学号升序排列（学号小的在前） · 完整示例： · using namespace std; 幻灯片上可见要点： · 📝 考试技巧： · 避免定义全局函数 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

真题精练 — 学生成绩排名

题目描述：有 n 名同学参加期末考试，每名同学有三个成绩：语文、数学、英语，以及一个学号。
请按以下规则排名：
(1) 按总分从高到低排序；
(2) 总分相同，按语文成绩从高到低排序；
(3) 语文也相同，按学号从小到大排序。
数据范围：n ≤ 1000，每科成绩 0~100。

解题关键

  1. 结构体定义：包含 id, chinese, math, english, total。
  2. 计算总分：读入后计算 total = chinese + math + english。
  3. 多关键字排序：使用 Lambda 表达式，先比较 total，再比较 chinese，最后比较 id。
  4. 注意比较方向：总分和语文是降序（高的在前），学号是升序（小的在前）。

2 95 80 95    // 学号2: 总分270, 语文95
3 88 92 90    // 学号3: 总分270, 语文88
4 80 85 90    // 学号4: 总分255

本课小结

  • sort() 基础：sort(begin, end) 升序，sort(begin, end, greater<T>()) 降序。时间复杂度 O(n log n)。
  • 自定义 cmp：cmp(a, b) 返回 true 表示 a 排 b 前。支持按绝对值、奇偶分组等任意规则。
  • 多关键字排序：逐层 if-return，先比较第一关键字，相等再比较第二关键字，以此类推。
  • Lambda 表达式：在 sort 调用处直接写比较逻辑，代码更清晰紧凑。格式：[](const T& a, const T& b) { ... }。
  • stable_sort：稳定排序，底层归并，相等元素保持原始顺序。需头文件 <algorithm>。
