一、计算机发展史与重要人物

代际年代核心器件特征 / 代表
第一代1946–1957电子管ENIAC；体积大、耗电多
第二代1958–1964晶体管体积缩小、可靠性提高
第三代1965–1970中小规模集成电路更快，软件系统化
第四代1971 至今大规模/超大规模集成电路微型机 / PC 普及

冯·诺依曼

提出存储程序思想：程序与数据以二进制存放在存储器中，由控制器依次取出执行 → 冯·诺依曼机。

图灵

提出图灵机抽象模型，刻画“什么问题可计算”；图灵奖是计算机领域最高奖之一。

口诀：电晶集大 —— 电子管 → 晶体管 → 集成电路 → 大规模/超大规模。

常见设问：ENIAC；现代结构=冯·诺依曼；第四代=大规模/超大规模集成电路。

三、硬件组成与存储单位

  • CPU：执行指令；主频、核心数、缓存
  • 内存 RAM：临时、速度快、断电丢失；程序须装入内存才能执行
  • 外存：HDD / SSD / U 盘等，断电仍保存，容量大
  • I/O：输入 / 输出；触摸屏等可兼有两者

单位换算（CSP-J 按 1024）

1 Byte = 8 bit
1 KB = 1024 B = 2¹⁰ B
1 MB = 1024 KB = 2²⁰ B
1 GB = 1024 MB · 1 TB = 1024 GB

📌 例：1024×768 真彩色（3B/像素）≈ 1024×768×3 / 1024 / 1024 ≈ 2.25 MB
易混：宣传 1KB=1000B，考试存储题用 1024。英文 1 字节，汉字常见 2~4 字节。

四、进制基础：二 ⇔ 十

概念

  • 基数 R：每位可用数码个数
  • 权：第 i 位权为 Ri（从右、i=0）
  • R→10：按权展开

(1011.01)₂ = 8+2+1+0.25 = 11.25

(11001010)₂ = 128+64+8+2 = 202

10 → 2

整数：除 2 取余，余数倒序

25→ 余 1,0,0,1,1 → 倒序 11001₂

小数：乘 2 取整，整数顺序

0.625 → 1, 0, 1 → 0.101₂

💡 口诀：整数除基取余倒着写，小数乘基取整顺着写。
演示 demoBinToDec / demoDecToBinSteps / demoFracToBin。

四（续）、八进制 / 十六进制与分组

  • 八进制：基数 8，数码 0~7；C++ 前缀 0（如 012=10₁₀）
  • 十六进制：0~9、A~F；C++ 前缀 0x（如 0x2F=47）
  • 2⇔8：因为 2³=8，3 位一组
  • 2⇔16：因为 2⁴=16，4 位一组
⚠️ 整数部分从右往左分组，左边不足补 0！
二进制十八十六
0000~01110~70~70~7
10008108
10101012A
11111517F

(10101110)₂ → 3位：010 101 110 → 256₈
→ 4位：1010 1110 → AE₁₆

2024 → bin 11111101000 → hex 7E8

四（续）、C++ 字面量与进制输出

base_literals.cpp 
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    int a = 26;       // 十进制
    int b = 032;      // 八进制 → 26
    int c = 0x1A;     // 十六进制 → 26
    cout << a << " " << b << " " << c << endl; // 26 26 26

    cout << oct << a << endl;          // 32
    cout << hex << a << endl;          // 1a
    cout << bitset<8>(a) << endl;    // 00011010
    cout << dec;                       // 恢复十进制！
    return 0;
}
⚠️ cout << hex 会“粘住”：后续整数仍按十六进制输出，直到再次 dec / oct。
demoBaseLiterals / demoBaseOutput。对比 012 vs 0x12 vs 12。

  return c - '0';

bin_string.cpp 
long long binToDec(
    const string &s) {
  long long ans = 0;
  for (char c : s)
    ans = ans * 2 + (c - '0');
  return ans;
}
// "10110110" → 182

易错点速查

1. 字面量前缀

012=10（八进制），0x12=18，12=12。

2. 除基取余顺序

余数必须倒序拼；小数乘基取整则顺着写。

3. 分组方向

二转八/十六：整数靠右对齐分组，左边补 0。

4. 存储单位

CSP-J：1KB=1024B，不要默认 1000。

5. hex 污染输出

用过 hex 后务必 dec 恢复。

6. 字符 vs 整数输出

cout<<'A'+1 出 66；要字符加 (char)。大小写差 32，'Z' 与 'a' 不连续。

对照讲义七大易错；可让学生改错题。

真题精练

题目 1 · 进制综合
二进制 10110110 的十 / 八 / 十六进制分别是？
✅ 182 · 266₈ · B6₁₆
十：128+32+16+4+2=182；右起 3 位→010 110 110→266；4 位→1011 0110→B6
题目 2 · ASCII
'E' - 'A' + 'd' 结果字符是？
✅ 'h'（码值 104）：偏移 4 作用到 'd' → d e f g h
题目 3 · 概念选择
正确的是？ A 内存断电仍保存 B CPU 不含控制器 C 1KB=1024B D 第一代用大规模集成电路
✅ C。A 是外存；B CPU=运算器+控制器；D 第一代电子管。
题目 4 · 快速进制
(2F)₁₆ 的 8 位二进制？
✅ 00101111（2→0010，F→1111）；十进制 47 验证。

本课小结
