计算机发展史与冯·诺依曼体系结构

计算机发展历程

  • 第一代（1946-1958）：电子管时代，ENIAC 诞生
  • 第二代（1958-1964）：晶体管计算机
  • 第三代（1964-1971）：集成电路计算机
  • 第四代（1971-至今）：大规模/超大规模集成电路

冯·诺依曼体系结构

五大组成部分：

  1. 输入设备 — 键盘、鼠标等
  2. 存储器 — 内存（RAM）、外存
  3. 控制器 — CPU 的控制单元
  4. 运算器 — CPU 的算术逻辑单元（ALU）
  5. 输出设备 — 显示器、打印机等

核心思想：存储程序

程序和数据以二进制形式预先存放在存储器中，计算机按顺序取出指令并执行。这是所有现代计算机的基础架构。

进制转换详解

💡考试技巧：二进制转八进制3位一组，转十六进制4位一组，都是从右往左分组！不足部分在左边补0。

二进制（Binary）

基数：2，数码：0、1

示例：1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11₁₀


十进制 → 二进制（除2取余）

将 13₁₀ 转为二进制：

13÷2=6...1 → 6÷2=3...0 → 3÷2=1...1 → 1÷2=0...1

从下往上读：1101₂

八进制：基数8，数码 0~7

ASCII 编码

ASCII 三基点

  • '0'（数字0）：ASCII 码 = 48
  • 'A'（大写A）：ASCII 码 = 65
  • 'a'（小写a）：ASCII 码 = 97

大小写转换技巧

大写字母 + 32 = 对应小写字母
小写字母 - 32 = 对应大写字母

例：'A'(65) + 32 = 'a'(97)

常用 ASCII 码速查

字符ASCII（十进制）ASCII（十六进制）

'a'~'z'97 ~ 1220x61 ~ 0x7A

标准 ASCII 码使用 7 位二进制，范围 0~127。扩展 ASCII 使用 8 位，范围 0~255。

代码模板 — 进制与 ASCII 操作

base_conversion.cpp 
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    int x = 255;

    // 输出不同进制
    cout << "十进制: " << dec << x << endl;
    cout << "八进制: " << oct << x << endl;
    cout << "十六进制: " << hex << x << endl;

    // 使用 bitset 输出二进制
    cout << "二进制: " << bitset<8>(x) << endl;

    // ASCII 字符与整数互转
    char ch = 'A';
    cout << "字符: " << ch
         << ", ASCII码: " << (int)ch << endl;
    return 0;
}

要点：dec/oct/hex 是 I/O 操纵符，设置后持续生效直到再次更改。使用 bitset 头文件可以方便地输出二进制。

真题精练

例题 1 · 进制转换
将二进制数 10110₂ 转换为十进制数。
✅ 答案：22
计算过程：1×2⁴ + 0×2³ + 1×2² + 1×2¹ + 0×2⁰ = 16 + 0 + 4 + 2 + 0 = 22
例题 2 · 进制转换
将十进制数 156₁₀ 转换为二进制数。
✅ 答案：10011100₂
计算过程（除2取余）：156÷2=78...0 → 78÷2=39...0 → 39÷2=19...1 → 19÷2=9...1 → 9÷2=4...1 → 4÷2=2...0 → 2÷2=1...0 → 1÷2=0...1
从下往上读：10011100₂
例题 3 · ASCII 运算
已知大写字母 'A' 的 ASCII 码为 65，则 'D' - 'A' + 'a' 的结果是哪个字符？
✅ 答案：'d'
'D' - 'A' = 68 - 65 = 3，3 + 'a' = 3 + 97 = 100，ASCII 100 对应 'd'

本课小结

计算机体系结构

冯·诺依曼五大部件：输入设备、存储器、控制器、运算器、输出设备。核心思想是存储程序。

进制转换

二进制 ↔ 八进制（3位一组）↔ 十六进制（4位一组）↔ 十进制（按权展开 / 除基取余）。

ASCII 编码

三基点：'0'=48, 'A'=65, 'a'=97。大小写相差32。标准 ASCII 范围 0~127。

C++ 进制输出

cout << dec/oct/hex 切换输出进制；bitset<N>(x) 输出二进制。
