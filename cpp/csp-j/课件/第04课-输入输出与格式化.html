输入输出与格式化

cin/cout · scanf/printf · iomanip · 转义字符

CSP-J 第一轮 · 编程基础模块

【开场】第 1/14 页 · 输入输出与格式化 目标：会选 I/O 方式、正确格式化、避开 scanf 漏 & 与格式符错配。 大纲：cin/cout、scanf/printf、格式化、转义、getchar、I/O 加速。

一、为什么 I/O 如此重要

CSP-J 几乎每道编程题都要：读入 → 计算 → 按格式输出。多一个空格、少一个换行、小数位数不对，都可能 WA。

C++ 流：cin / cout

类型安全、写法简洁；默认较慢，关同步后很快。格式化需 iomanip。

C 风格：scanf / printf

格式控制强、通常更快；格式符写错会「能跑但结果错」。必须记格式符表。

知识点考查频率本课目标
cin / cout 链式、空白分隔⭐⭐⭐⭐⭐熟练读写整数/浮点/字符
scanf / printf 格式符⭐⭐⭐⭐⭐默写 %d %lld %f/%lf %c
setw / setprecision / fixed⭐⭐⭐⭐保留 k 位小数
转义 · I/O 加速⭐⭐⭐⭐能读输出题、会写加速两行
【讲解】I/O 是得分基础设施。两套体系竞赛都会考、都会用。强调：格式也是正确性的一部分。

二、cout 输出流

cout_basic.cpp 
#include <iostream>
using namespace std;

int a = 3, b = 5;
cout << "a=" << a
     << ", b=" << b << endl;
// 输出：a=3, b=5

// 空格分隔 / 多行
cout << a << " " << b << "\n";
cout << a << "\n" << b << "\n";

bool ok = true;
cout << ok;  // 默认 1
  • << 是流插入运算符，支持链式输出
  • endl：换行并刷新缓冲区，大数据输出略慢
  • "\n"：仅换行，竞赛更常用
  • bool 默认输出 0/1（了解 boolalpha）
写法含义
endl换行 + 刷新
"\n" / '\n'仅换行
💡大量输出时用 '\n' 代替 endl，避免频繁刷新拖慢程序。
【讲解】链式 cout；endl vs \n。bool 输出 1/0。Demo1 对应程序 lesson04。

三、cin 输入流

cin_demo.cpp 
int n;
double x;
char ch;
cin >> n >> x >> ch;
// 输入: 3 3.5 A  → 均可
// 或换行分隔：3\n3.5\nA

// 空白：空格 / Tab / 换行
// cin 自动跳过前导空白

string s;
cin >> s;  // 遇空白停止
// "hello world" → 只得 "hello"
// 整行：getline(cin, s)（字符串课）
  • >> 是流提取运算符
  • 以空白为分隔，自动跳过前导空白
  • 链式：cin >> a >> b >> c;
  • 读 string 遇空格截断；整行用 getline

常见模式 A：单行多整数

3 5 7 → cin >> a >> b >> c;

常见模式 B：先 n 再 n 个数

cin >> n; 再 for 循环 cin >> a[i];

【讲解】空白分隔、预告 getline。模式 A/B 对应讲义综合模式。

四、I/O 加速（竞赛标配）

fast_io_template.cpp 
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);  // 关闭 C++ 与 C 流同步
    cin.tie(nullptr);             // 解除 cin 与 cout 绑定
    // 可选：cout.tie(nullptr);

    // 题解代码：只使用 cin / cout
    return 0;
}
  • sync_with_stdio(false)：显著加速 cin/cout
  • cin.tie(nullptr)：输入前不强制刷新输出
  • 关同步后速度与 scanf/printf 相当
铁律：关闭同步后，禁止混用 cin/cout 与 scanf/printf！会乱序或读错。整题二选一。
💡选型：多数题用加速后的 cin/cout；严格小数/列对齐时 printf 更省事。
【讲解】两行加速含义与混用危害。正式做题模板头。

五、printf 常用格式符（必背）

格式符类型示例输出
%dintprintf("%d", 42)42
%lldlong longprintf("%lld", x)大整数
%fdouble（printf 中）printf("%f", 3.14)3.140000
%ccharprintf("%c", 65)A
%sC 字符串printf("%s", "Hi")Hi
%x / %X十六进制printf("%x", 255)ff / FF
%o八进制printf("%o", 8)10
%%百分号本身printf("100%%")100%
高频易混：printf 输出 double 用 %f；scanf 读 double 用 %lf。口诀：扫 lf，打 f。
💡long long 必须 %lld（CSP-J/Linux OJ）。用 %d 是未定义行为。
【讲解】格式符表 + 易混点。Demo4 对照。

六、printf 宽度 · 对齐 · 精度

格式大致：%[标志][宽度][.精度]转换符

printf_width.cpp 
printf("%8d", 42);        // 宽8右对齐 → "      42"
printf("%-8d", 42);       // 左对齐 → "42      "
printf("%08d", 42);       // 前导0 → "00000042"
printf("%.2f", 3.14159);  // 两位小数 → "3.14"
printf("%8.2f", 3.14);    // 宽8+两位 → "    3.14"
printf("%-10.3f", 3.14);  // 左对齐宽10
printf("%04d\n", 7);      // "0007"

保留 k 位小数（最常用）

printf("%.2f\n", x); — 简洁可靠，考试首选之一。

cout 等价写法

cout << fixed << setprecision(2) << x;

【讲解】Demo5 宽度精度。题目「保留2位小数」两种写法都要会。

七、scanf 格式化输入

scanf_demo.cpp 
int a, n;
long long b;
double c;   // ⚠️ 用 %lf
char d;
char s[100];

scanf("%d", &a);       // 必须 &
scanf("%lld", &b);
scanf("%lf", &c);      // double → %lf
scanf(" %c", &d);      // 前空格跳过空白
scanf("%s", s);        // 数组名不加 &
scanf("%d%d", &a, &n);  // 连续读
格式符类型
%dint
%lldlong long
%ffloat
%lfdouble
%cchar（会读空白）
%s字符数组
铁律 1：普通变量必须 &！漏写是最高频 RE/WA 原因。
铁律 2：数组名作 %s 目标不加 &。
【讲解】scanf 取地址、%lf、%c 前空格。Demo6。

八、iomanip 格式化操纵符

需 #include <iomanip>

iomanip_demo.cpp 
double pi = 3.1415926;

// 仅 setprecision：有效数字相关
cout << setprecision(4) << pi;

// 保留小数点后 k 位（高频）
cout << fixed << setprecision(2);
cout << pi;  // 3.14

// setw 只作用于下一次输出
cout << setw(5) << 1
     << setw(5) << 2;

cout << setfill('0')
     << setw(5) << 42;  // 00042
操纵符作用
setprecision(n)有效位 / 小数位
fixed定点小数格式
setw(n)宽度（仅一次）
setfill(c)填充字符
left / right对齐
💡fixed 与 setprecision 持续有效；setw 用完即失效，每次要写。
无 fixed 时 setprecision(3) 不是「三位小数」！要 k 位小数必须 fixed + setprecision(k)。
【讲解】Demo7/16。考试「保留k位小数」必用 fixed。

九、转义字符与 getchar / putchar

转义含义ASCII
\n换行10
\t水平制表9
\\反斜杠92
\" \'引号34 / 39
\0空字符（串尾）0
escape.cpp 
cout << "A\tB\nC\\D\"E";
// A<tab>B
// C\D"E
printf("100%%\n");  // 100%
  • getchar()：读一个字符（含空格、换行）
  • putchar(c)：输出一个字符
  • cin >> ch 会跳过空白；getchar 不跳过
char_io.cpp 
char c = getchar();  // 模拟 'Z'
putchar(c);
printf(" %d\n", (int)c);
// 输出: Z 90
路径写 C:\new 会把 \n 当换行 → 应写 C:\\new。
【讲解】Demo9/10。转义阅读题常考。

十、代码模板精选

模板1 · cin/cout 
#include <iostream>
#include <iomanip>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; double x;
    cin >> n >> x;
    cout << fixed << setprecision(2);
    cout << n << " " << x << "\n";
    return 0;
}
模板2 · scanf/printf 
#include <cstdio>
int main() {
    int n; long long s = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        int x;
        scanf("%d", &x);
        s += x;
    }
    printf("%lld\n", s);
    return 0;
}
模板3 · 圆的周长面积（保留2位） 
const double PI = 3.14159;
double r; cin >> r;  // 样例 r=5 → 31.42 78.54
printf("%.2f %.2f\n", 2*PI*r, PI*r*r);
// 或 cout << fixed << setprecision(2) << ...
【讲解】三套模板对应讲义与 Demo12–14。选型：一般加速流；求和/强格式用 C I/O。

十一、易错点清单

1. scanf 漏 &
scanf("%d", a); ✗ → scanf("%d", &a); ✓
2. 格式符不匹配
long long 用 %d、printf double 用 %lf 都错
3. setprecision 无 fixed
要「小数点后 k 位」必须 fixed + setprecision(k)
4. setw 只生效一次
setw(5)<<1<<2 只有 1 有宽度
5. 关同步后混用 I/O
cin 与 printf 混用 → 乱序/读错
6. 转义 / 百分号
\\ 才是反斜杠；printf 中 %% 才是 %
7. scanf 读 double
必须 %lf，不是 %f
8. cin 读串遇空格截断
整行用 getline(cin, s)
【讲解】八条易错逐条过，对应讲义易错点 1–8。

十二、真题精练

真题 1 · fixed / setw 阅读
double x=3.14159; cout<<fixed<<setprecision(3); cout<<x<<endl; cout<<setw(10)<<x<<endl;
✅ 答案：第一行 3.142；第二行右对齐宽度 10 的 3.142（前补空格）。考点：四舍五入 + setw 只一次 + fixed 持续。
真题 2 · scanf A+B
输入 10 20，scanf("%d%d",&a,&b); 后 printf("a=%d\nb=%d\na+b=%d\n",a,b,a+b);
✅ 答案：a=10 / b=20 / a+b=30（三行）。两个 %d 之间可无空格，scanf 仍跳过空白。漏 & 则危险。
真题 3 · 格式符辨析 + 转义
① printf 输出 double 用？ ② cout << "A\tB\nC\\D\"E"; 输出？
① A.%d B.%f C.%lf D.%llf
✅ ① B %f（scanf 才是 %lf）。② 第一行 A<tab>B，第二行 C\D"E。
【讲解】真题1–3 + Demo12/13/09。先让学生写答案再揭晓。

本课小结

cin / cout

链式 >>/<<；空白分隔；大量输出用 '\n' 代替 endl。

加速两行

ios::sync_with_stdio(false); cin.tie(nullptr); 后勿混用 C I/O。

scanf / printf

scanf 必 &；double 扫 %lf、打 %f；long long 用 %lld。

格式化

fixed+setprecision(k) 或 printf("%.kf")；setw 仅一次。

转义 · 字符 I/O

\n \t \\ \"；printf 用 %%；getchar 不跳过空白。

选型建议

多数题：加速 cin/cout；强格式：printf。同一程序坚持一种。

输入输出是每道题的起手式 —— 格式符与取地址符必须烂熟于心！
