输入输出与格式化

掌握 cin/cout、scanf/printf 与格式化操纵符

CSP-J 第一轮 · 编程基础模块

cin / cout 基本输入输出

cout 标准输出

cout_demo.cpp 
int a = 42;
double b = 3.14;
char c = 'X';

// 单个输出
cout << a;

// 链式输出
cout << "a=" << a
     << ", b=" << b << endl;

// endl vs '\n'
cout << "换行+刷新" << endl;
cout << "仅换行" << '\n';

cin 标准输入

cin_demo.cpp 
int x;
double y;
char z;

// 单个输入
cin >> x;

// 连续输入（空格/换行分隔）
cin >> x >> y >> z;

// 输入: 10 3.14 A
// x=10, y=3.14, z='A'
  • cin 以空格、Tab、换行为分隔
  • endl 刷新缓冲区，速度较慢
  • 大量输出时用 '\n' 代替 endl

scanf / printf 格式化输入输出

💡考试技巧：scanf 必须加取地址符 &；printf 的 double 用 %f 而非 %lf；ios::sync_with_stdio(false) 后不能混用 scanf/printf。

printf 格式化输出

格式符类型示例
%dintprintf("%d", 42) → 42
%lldlong longprintf("%lld", sum)
%ffloat / doubleprintf("%.2f", 3.14159) → 3.14
%ccharprintf("%c", 'A') → A
%s字符串printf("%s", "Hi") → Hi
%x / %X十六进制printf("%x", 255) → ff

scanf 格式化输入

scanf_demo.cpp 
int a;
long long b;
double c;   // ⚠️ scanf用%lf
char d;

// ⚠️ 必须加取地址符 &
scanf("%d", &a);
scanf("%lld", &b);
scanf("%lf", &c);  // scanf是%lf!
scanf(" %c", &d); // 空格跳过前导空白

// 连续输入
scanf("%d%lld", &a, &b);
⚠️易错点：printf 输出 double 用 %f，但 scanf 输入 double 用 %lf！两者不一致，是高频考点。

格式化操纵符与转义字符

iomanip 操纵符

需引入 #include <iomanip>

manip_demo.cpp 
double pi = 3.1415926;

// 设置精度（有效位数）
cout << setprecision(4) << pi;
// 输出: 3.142

// 固定小数点 + 精度
cout << fixed << setprecision(2);
cout << pi;
// 输出: 3.14

// 设置宽度（右对齐）
cout << setw(10) << 42;
// 输出: "        42"

代码模板 — I/O 优化与格式化输出

io_template.cpp 
#include <iostream>
#include <cstdio>
#include <iomanip>
using namespace std;

int main() {
    // 加速 cin/cout (之后不能混用 scanf/printf!)
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;

    // cout 格式化：保留2位小数
    double ans = 3.1415926;
    cout << fixed << setprecision(2);
    cout << ans << endl;  // 输出: 3.14

    return 0;
}

// ─── 方案二：纯 scanf/printf ───
// int main() {
//     int n; double x;
//     scanf("%d%lf", &n, &x);
//     printf("%d %.2f\n", n, x);  // double用%f
//     return 0;
// }

方案一：cin/cout + 加速

适合大多数情况。加上 sync_with_stdio(false) 后速度与 scanf/printf 相当。但不能混用。

方案二：scanf/printf

适合高精度格式化输出场景。printf("%.2f", x) 比 cout + setprecision 更简洁。double 用 %f。

真题精练

例题 1 · 格式化输出判断
执行以下代码，输出结果是？
printf("%.2f\n", 3.14159);
printf("%d %d\n", 10, 20);
printf("%c", 65);
✅ 答案：3.14（换行）10 20（换行）A
解析：%.2f 保留 2 位小数为 3.14；%d 输出整数；ASCII 65 对应字符 'A'。
例题 2 · scanf 输入
以下代码中，若从键盘输入 10 20（空格分隔），变量 a 和 b 的值分别是？
int a, b;
scanf("%d%d", &a, &b);
A. a=10, b=20 B. a=0, b=0 C. a=10, b=随机值 D. 编译错误
✅ 答案：A。scanf 以空格、Tab、换行为分隔，%d%d 会依次读取两个整数。如果忘记写 & 则可能运行时出错（不是编译错误，要警惕）。
例题 3 · 格式符辨析
在 C++ 中，使用 printf 输出 double 类型变量 x，正确的格式符是？
A. %d B. %f C. %lf D. %llf
✅ 答案：B。重点记忆：printf 中 double 用 %f；scanf 中 double 用 %lf。两者不同，是 CSP-J 高频易错点！

本课小结

cin / cout

cin >> 输入（空格/Tab/换行分隔），cout << 输出（链式）。endl 刷新缓冲区，大量输出用 '\n'。

scanf / printf

scanf 用 %d %lld %lf %c，必须加 &。printf 用 %d %lld %f(!!) %c。printf 的 double 用 %f！

格式化操纵符

setprecision(n) 精度，fixed 定点小数，setw(n) 宽度，setfill(c) 填充字符。

I/O 优化

ios::sync_with_stdio(false) 加速 cin/cout，但之后不能混用 scanf/printf。选一种方案坚持用到底。

输入输出是每道题的起手式，格式符和取地址符必须烂熟于心！
