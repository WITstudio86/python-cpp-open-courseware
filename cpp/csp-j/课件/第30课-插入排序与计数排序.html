插入排序 (Insertion Sort)

核心思想：维护"有序区"和"无序区"，逐个将无序区元素插入到有序区的正确位置

  • 算法流程：初始时第一个元素视为有序区。从第 2 个元素开始，依次取出"关键值"，在有序区中从后往前找到合适位置插入。
  • 像打扑克牌：摸到一张新牌后，在手中已有的牌中找到合适位置插入——这是插入排序最形象的比喻。
  • 最好情况 O(n)：当数据基本有序时，每次只需比较一次就能确定位置，时间复杂度接近 O(n)。这是插入排序的独特优势。
  • 最坏情况 O(n²)：当数据完全逆序时，每个元素都要与有序区所有元素比较。

执行过程 — 数组 [5, 3, 8, 1, 2]

步骤关键值有序区操作
初始—[5]第一个元素自然有序
第 1 步3[3, 5]3<5，5 后移，3 插入
第 2 步8[3, 5, 8]8>5，直接追加
第 3 步1[1, 3, 5, 8]1<3，全部后移
第 4 步2[1, 2, 3, 5, 8]1<2<3，插入中间

计数排序 (Counting Sort)

核心思想：不通过比较来排序，而是统计每个值出现了多少次

  • 三步走：① 统计频率（count 数组记录每个值的出现次数）→ ② 计算前缀和（确定每个值在结果中的最后位置）→ ③ 倒序放置（保证稳定性）。
  • 时间复杂度 O(n+k)：n 为元素个数，k 为数据范围大小。当 k 不大时效率极高！
  • 适用条件：数据必须是整数，且数据范围 k 不能太大（如 k ≤ 10⁷）。数据范围太大则内存和时间都受不了。
  • 典型场景：成绩排序（0~100）、年龄排序（0~120）、频率统计类问题。

执行过程 — 数组 [2, 5, 3, 0, 3, 5, 2]（范围 0~5）

阶段操作数组内容
① 统计频率count[value]++count = [1, 0, 2, 2, 0, 2]（下标 0~5）
② 前缀和count[i] += count[i-1]count = [1, 1, 3, 5, 5, 7]
③ 倒序放置res[--count[a[i]]] = a[i]结果 = [0, 2, 2, 3, 3, 5, 5]
关键理解：前缀和 count[i] 表示"值 ≤ i 的元素共有多少个"。例如 count[3]=5 说明 ≤3 的元素有 5 个，那么值为 3 的元素应该放在第 5 个位置（下标 4）。倒序遍历保证了稳定性。

选择建议

  • 数据基本有序（如插入少量新数据到已排序数组）：优先选择插入排序。
  • 整数数据且范围小（如学生成绩 0~100）：计数排序 O(n+101) 远优于 O(n²)。
  • 通用场景 / 竞赛：直接使用 sort()（O(n log n)），不作他想。

代码模板

插入排序模板

// 插入排序 — 从第二个元素开始逐个插入有序区
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];             // 当前要插入的关键值
        int j = i - 1;              // 从有序区末尾开始
        // 将大于 key 的元素逐一后移
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;            // 插入到正确位置
    }
}

// 最好情况：已有序，while 循环不执行 → O(n)
// 最坏情况：完全逆序，while 每次都遍历到头 → O(n²)

计数排序模板

// 计数排序 — 三步走：统计频率 → 前缀和 → 倒序放置
void countingSort(int a[], int n, int maxVal) {
    int* cnt = new int[maxVal + 1]();    // ① 统计数组（初始化为0）
    int* res = new int[n];                // 结果数组

    for (int i = 0; i < n; i++)            // ② 统计每个值的出现次数
        cnt[a[i]]++;

    for (int i = 1; i <= maxVal; i++)       // ③ 前缀和：cnt[i] = ≤i 的元素总数
        cnt[i] += cnt[i - 1];

    for (int i = n - 1; i >= 0; i--) {     // ④ 倒序放置（保证稳定性）
        res[cnt[a[i]] - 1] = a[i];
        cnt[a[i]]--;
    }

    for (int i = 0; i < n; i++) a[i] = res[i];  // ⑤ 复制回原数组
    delete[] cnt; delete[] res;
}

真题精练 — 统计成绩分布并排序

题目：成绩排序与分布统计

题目描述：某次考试共有 10 名同学，成绩如下：
scores[10] = {85, 92, 78, 65, 92, 100, 78, 85, 55, 88}
(1) 使用计数排序对成绩进行升序排列。
(2) 统计每个分数段的人数（0~59不及格、60~79中等、80~89良好、90~100优秀）。

解题思路

  1. 范围分析：成绩范围 0~100，k=100，非常适合计数排序。
  2. 统计频率：遍历 scores，cnt[score]++，例如 85 出现 2 次，cnt[85]=2。
  3. 前缀和：cnt[i] = cnt[i] + cnt[i-1]，得到每个分数的最终位置。
  4. 输出结果：从前缀和取出排序结果。
  5. 分数段统计：直接累加 cnt 数组对应区间。

排序结果

升序排列：[55, 65, 78, 78, 85, 85, 88, 92, 92, 100]

本课小结

  • 插入排序：维护有序区+无序区，逐个插入。最好 O(n)、最坏 O(n²)、稳定、适合基本有序数据。
  • 计数排序：非比较排序，频率统计→前缀和→倒序放置。O(n+k)、稳定、适合整数范围小的场景。
  • 四大排序对比：冒泡/选择/插入都是 O(n²) 且 O(1) 空间，计数排序 O(n+k) 但 O(n+k) 空间。稳定性方面只有选择排序不稳定。
  • 场景选择：基本有序用插入，小范围整数用计数，通用场景用 sort()。
  • 初赛重点：排序的稳定性、时间复杂度对比、计数排序的前缀和操作。
