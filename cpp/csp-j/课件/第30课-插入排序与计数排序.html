一、插入排序思想

像整理扑克：前部有序，每次把无序区第一张 key 插入有序区正确位置。

  1. 初始 a[0] 为有序区
  2. i 从 1 到 n-1，key=a[i]
  3. 有序区从后往前，比 key 大的后移
  4. 腾出位置放入 key
条件 a[j] > key（严格大于）→ 稳定；空间 O(1) 原地排序。
【讲解】摸牌整理手势演示。

二、插入排序代码

void insertionSort(int a[], int n) { for (int i = 1; i < n; i++) { int key = a[i]; int j = i - 1; while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; // 后移 j--; } a[j + 1] = key; } }
【讲解】j 可能到 -1，插入位置 j+1。

四、插入排序复杂度

情况复杂度说明
最坏（逆序）O(n²)每次移动整段有序区
最好（已有序）O(n)while 一次都不进
平均O(n²)—
数据越接近有序越快。工程上快排在小规模子问题常切到插入排序。
【讲解】对比选择：选择最好也 O(n²)。

五、计数排序思想

基于比较的排序下界 O(n log n)。若值域有限（如 0～1000 的整数），可统计频率再还原 → O(n + V)。

  1. 找 max（或 min/max 算 range）
  2. cnt[x]++ 统计
  3. 按值从小到大输出 cnt[i] 次 i

适用条件

值域不大；通常整数。值域 10⁹、n=10⁵ 时 cnt 数组放不下 → 不能用。

【讲解】非比较排序破 O(n log n)。

六、计数排序代码（非负）

void countingSort(int a[], int n) { int maxVal = a[0]; for (int i=1; i<n; i++) maxVal = max(maxVal, a[i]); int* cnt = new int[maxVal + 1](); for (int i=0; i<n; i++) cnt[a[i]]++; int idx = 0; for (int i=0; i<=maxVal; i++) while (cnt[i]-- > 0) a[idx++] = i; delete[] cnt; }

例：{5,3,8,3,1,9,2,5,7,3} → 1 2 3 3 3 5 5 7 8 9

【讲解】竞赛可用静态 cnt[MAXV]。

七、带偏移：支持负数

int minVal = *min_element(a, a+n); int maxVal = *max_element(a, a+n); int range = maxVal - minVal + 1; int* cnt = new int[range](); for (int i=0; i<n; i++) cnt[a[i] - minVal]++; int idx=0; for (int i=0; i<range; i++) while (cnt[i]-- > 0) a[idx++] = i + minVal;
偏移 offset=minVal：下标 0 对应最小值。
【讲解】负数映射到 ≥0 下标。

八、全算法对比表

算法最好最坏空间稳定
冒泡(优化)O(n)O(n²)O(1)是
选择O(n²)O(n²)O(1)否
插入O(n)O(n²)O(1)是

【讲解】选型：值域小→计数；基本有序→插入。

十、易错点

1. 插入 while 条件

必须 j>=0 && a[j]>key，顺序不能反（短路保护）。

2. 计数数组开太大/太小

按 max-min+1；注意内存与栈限制。

3. 忘记写回

只统计不还原不算完成排序。

4. 把计数当万能

浮点、大值域、字符串键不适用直接计数。

【讲解】四易错。

十三、选型决策

数据特征推荐

基本有序插入

n 大，一般比较排序STL sort（下节）
