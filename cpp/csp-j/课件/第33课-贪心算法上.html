一、什么是贪心算法

一句话：每一步都采取当前状态下最优的选择，并希望这些局部最优能推出全局最优。

两个关键性质（缺一不可）

  • 贪心选择性质：整体最优可通过一系列局部最优达到；每步选择不可撤销、不需回溯。
  • 最优子结构性质：问题的最优解包含其子问题的最优解（DP 也需要，但贪心用更高效的方式利用它）。

与其它算法对比（先建立直觉）

维度贪心动态规划回溯/枚举
选择方式当前最优，不回溯记录所有子问题最优穷举所有方案
正确性需证明/验证状态对则最优保证最优
复杂度常 O(n log n)常 O(n²)/O(nW)常指数
⚠️：贪心不是万能的。不能证明且存在反例时，不要硬用贪心。
【讲解】核心定义 + 两性质 类比：每天存最多的钱 vs 能否攒出最多总资产——有时会失败。 点出与 DP/回溯的分工。

二、贪心策略设计四步骤

  1. 分析问题，确定候选集合——所有可能被选择的对象（活动、硬币、区间…）
  2. 设计贪心策略——按哪个关键字排序？升序还是降序？这是成败关键。
  3. 验证正确性——比赛中用「反证/替换法」或「找反例」；找不到反例 + 样例通过 → 大概率可用。
  4. 编码实现——多数是 排序 + 一次遍历，时间常由排序决定 O(n log n)。
判断是否用贪心的四步法：
① n≤20 → 可直接枚举/回溯；② 尝试构造反例；③ 定排序标准；④ 小样例与边界验证。
反例提醒：两端取硬币 [1,100,10,1] 若「每次取两端较大」会出错——说明策略必须验证。
【讲解】四步骤 板书流程：候选 → 策略 → 证明/反例 → 实现。 强调「排序标准选错 = 全盘错」。

三、活动选择（区间调度）

问题：n 个活动 [s, f)，同一时间只能做一个，最多参加多少个？

贪心策略：按结束时间升序排序，依次选与已选活动不冲突的活动（s ≥ lastEnd）。

为何正确（替换法）：若最优解第一个不是结束最早的 g，用 g 替换后仍合法且数量不少 → 存在以 g 开头的最优解，归纳即可。

// 手推样例（按结束时间排序后） // [1,4) [3,5) [0,6) [5,7) [5,9) [8,9) // lastEnd=0 → 选[1,4) lastEnd=4 // [3,5) 冲突；[0,6) 冲突 // 选[5,7) lastEnd=7；[5,9)冲突；选[8,9) // 答案 = 3
错策略：按开始时间或区间长度排序可能选中长区间占住时间，答案更差。例：[1,10][2,4][5,6] 按开始只能 1 个，按结束可得 2 个。
【讲解】活动选择 黑板上画时间轴，边选边标 lastEnd。 一定强调「结束最早 = 为后面留空间」。

活动选择 — 完整模板

struct Activity { int start, end; } a[MAXN]; bool cmp(Activity x, Activity y) { return x.end < y.end; // 严格 <，禁止 <= } int main() { ios::sync_with_stdio(false); cin.tie(0); int n; cin >> n; for (int i = 0; i < n; i++) cin >> a[i].start >> a[i].end; sort(a, a + n, cmp); int ans = 1, lastEnd = a[0].end; for (int i = 1; i < n; i++) { if (a[i].start >= lastEnd) { ans++; lastEnd = a[i].end; // 选中后必须更新 } } cout << ans << endl; }
复杂度：O(n log n)（排序主导）。n 可达 1e5，勿用 O(n²) DP。左闭右开时 start ≥ lastEnd 即可。
【讲解】模板 对照程序 lesson33 的 activitySelection。 易错：cmp 写成 <=；忘记更新 lastEnd；n=0 边界可补充说明。

四、区间类贪心对照表（必背）

问题排序关键字扫描决策输出
最多不重叠区间右端点 ↑不冲突则选个数
移除最少重叠同上n − 最多不重叠个数
区间选点右端点 ↑右端点放点点数
区间覆盖左端点 ↑覆盖当前点且右端最远区间数或 -1
排队接水时间 ↑累加等待总等待
最优装载（件数）重量 ↑能装就装件数
记忆：「要多选 / 要少点」→ 多按右端；「要盖满」→ 按左端 + 每次延伸最远。
【讲解】对照表 考前必过。可让学生闭卷说出每种排序关键字。

区间覆盖 + 区间选点

区间覆盖：用最少区间盖住 [L,R]

sort(a, a + n, cmpByLeft); // 左端点升序 int ans = 0, currentR = targetL, i = 0; while (currentR < targetR) { int maxR = currentR; while (i < n && a[i].left <= currentR) { maxR = max(maxR, a[i].right); i++; } if (maxR == currentR) { ans = -1; break; } // 无解 ans++; currentR = maxR; }

区间选点：最少点使每个区间至少含一点

// 按右端点升序；若当前区间未被 last 覆盖，则在右端放点 if (a[i].first > last) { last = a[i].second; ans++; }
覆盖题易错：忘记 maxR==currentR 时输出 -1；目标区间外的区间要正确跳过。
【讲解】覆盖与选点 覆盖：贪心延伸；选点：右端放点。对照程序 intervalCover。

五、硬币找零

贪心：每次选不超过剩余金额的最大面额（人民币等规范硬币系统可用）。

// coins 从大到小 int greedyCoinChange(int coins[], int m, int amount) { int count = 0; for (int i = 0; i < m; i++) { count += amount / coins[i]; amount %= coins[i]; } return amount == 0 ? count : -1; }
反例 {1,3,4} 找零 6：贪心 4+1+1=3 枚；最优 3+3=2 枚。非规范系统贪心失效！
考试策略：未说明面额规律且金额≤1e4、面额种类少 → 用完全背包 DP 保底。
【讲解】找零 现场算 87 元人民币：50+20+10+5+1+1=6。 再讲反例，过渡到 DP。

找零 DP 保底 + 排队接水

完全背包最少硬币

memset(dp, 0x3f, sizeof(dp)); dp[0] = 0; for (int i = 1; i <= amount; i++) for (int j = 0; j < m; j++) if (i >= coins[j]) dp[i] = min(dp[i], dp[i - coins[j]] + 1); // 答案：dp[amount]==INF ? -1 : dp[amount]

排队接水：短作业优先

n 人接水时间 t[i]，最小化总完成时间之和。

sort(t, t + n); // 升序 long long total = 0, cur = 0; for (int i = 0; i < n; i++) { cur += t[i]; total += cur; }
样例：3 1 4 2 → 排序 1,2,3,4 → 完成 1+3+6+10=20。务必 long long。
【讲解】DP 找零 + 排队 解释为何短的先接：长的排前面会拖累所有后面的人。

最优装载 + 何时不用贪心

件数最多：按重量升序，能装就装（每件「价值」都是 1）。

sort(w, w + n); int ans = 0; long long sum = 0; for (int i = 0; i < n; i++) { if (sum + w[i] <= C) { sum += w[i]; ans++; } else break; }
  • 若求价值最大且价值不同 → 一般是 01 背包，不能按重量简单贪心。
  • 硬币非规范、需要全局权衡、能构造反例 → 别贪心。
  • 状态依赖复杂、像 DP → 按 DP 做。
CSP-J 贪心主旋律：排序定优先级 + 一次扫描决策 + 注意 long long 与 cmp 严格弱序。
【讲解】装载 vs 背包 件数 vs 价值：价值不同就回到第39课背包。

真题精练① 活动选择

📝 社团使用礼堂
题意：n 个社团申请 [s_i, f_i)，同一时间只能一个。最多安排多少个？
范围：1 ≤ n ≤ 1e5，0 ≤ s < f ≤ 1e9。
样例：6 个区间 → 输出 3（如 [1,4)[5,7)[8,9)）。
sort(a, a+n, [](Activity x, Activity y){ return x.end < y.end; }); int ans = 1, last = a[0].end; for (int i = 1; i < n; i++) if (a[i].start >= last) { ans++; last = a[i].end; } cout << ans;
得分点：n=1e5 必须 O(n log n)；结构体排序；冲突判断 start ≥ lastEnd。
【讲解】真题① 让学生先独立想 1 分钟再给模板。对应内容.md 题目一。

真题精练② + 易错点

📝 排队接水
题意：n 人 t_i 分钟，求最小总等待（各完成时间之和）。样例 4 人 3 1 4 2 → 20。

五大易错点

  • 排序标准选错——活动选择必须按结束时间，不是开始/长度。
  • 贪心未必正确——{1,3,4} 找零 6 贪心错；不确定时用 DP。
  • 区间覆盖无解——maxR==currentR 输出 -1。
  • cmp 写成 ≤——破坏严格弱序，可能 RE/答案乱。
  • 溢出——排队/装载累计用 long long。
【讲解】真题② + 易错 让学生口述 5 条易错。强调 long long 与 cmp。

本课小结

  • 贪心 = 局部最优步步推进；需贪心选择性质 + 最优子结构。
  • 设计流：候选集合 → 策略（排序）→ 验证 → 实现（排序+扫描）。
  • 活动选择：结束时间 ↑；区间覆盖：左端 ↑ + 延伸最远；选点：右端放点。
  • 硬币找零：规范系统可贪，否则完全背包 DP。
  • 排队接水 / 最优装载（件数）：时间或重量升序。
  • 难点在「能否贪心」与「排序关键字」，代码通常很短。
