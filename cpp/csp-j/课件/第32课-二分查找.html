第 32 课

二分查找基础

核心前提：序列必须有序（升序或降序）

写法一：闭区间 while (l <= r)

  • 搜索区间：[l, r]，左右均闭合。当 l > r 时区间为空，搜索结束。
  • mid 计算：mid = l + (r - l) / 2，或 mid = (l + r) / 2（无溢出风险时）。
  • 调整规则：a[mid] < x 则 l = mid + 1；a[mid] > x 则 r = mid - 1。
  • 优点：逻辑直观，容易理解边界条件。

写法二：左闭右开 while (l < r)

  • 搜索区间：[l, r)，左闭右开。当 l == r 时区间为空。
  • 调整规则：a[mid] < x 则 l = mid + 1；a[mid] > x 则 r = mid。
  • 优点：与 C++ STL 迭代器区间风格一致，常用于查找下界。
对比项闭区间 [l, r]左闭右开 [l, r)
循环条件while (l <= r)while (l < r)
初始区间l=0, r=n-1l=0, r=n
找到目标return mid需要额外判断
未找到l > r 结束l == r 结束
📝 考试技巧： 推荐优先掌握闭区间写法，因为判断条件对称（l=mid+1, r=mid-1），边界不易出错。左闭右开写法的 r 更新为 mid（不-1），初学者容易混淆。

lower_bound / upper_bound

STL 提供的二分查找函数（头文件 <algorithm>）

  • lower_bound(begin, end, x)：返回第一个 ≥ x 的元素位置（迭代器）。即第一个不小于 x 的位置。
  • upper_bound(begin, end, x)：返回第一个 > x 的元素位置（迭代器）。即第一个大于 x 的位置。
  • 返回类型：迭代器，减去 begin() 可得下标。若所有元素都小于 x，则返回 end()。
// 示例：有序数组 a = {1, 3, 3, 5, 7, 9, 9, 11}
int a[] = {1, 3, 3, 5, 7, 9, 9, 11};

// lower_bound(a, a+8, 3) → 下标1（第一个≥3的位置）
int p1 = lower_bound(a, a + 8, 3) - a;  // p1 = 1

// upper_bound(a, a+8, 3) → 下标3（第一个＞3的位置）
int p2 = upper_bound(a, a + 8, 3) - a;  // p2 = 3

// 元素 3 的出现次数 = upper_bound - lower_bound
int cnt = p2 - p1;                     // cnt = 2

// 查找不存在的元素
int p3 = lower_bound(a, a + 8, 4) - a;  // p3 = 3（第一个≥4的是a[3]=5）
实用技巧：计算元素 x 在有序数组中的出现次数 = upper_bound(begin, end, x) - lower_bound(begin, end, x)。

二分答案思想

当问题的答案具有"单调性"时，可以在答案范围上二分

  • 核心思路：答案在某个区间 [L, R] 内，存在一个分界点：分界点一侧都满足条件，另一侧都不满足。二分寻找这个分界点。
  • check(mid) 函数：判断"如果答案是 mid，是否可行"。这是二分答案的关键——如何写出正确的 check 函数。

两种二分方向

目的二分方向模板
找最大值可行区域在左侧if(check(mid)) l=mid; else r=mid-1;
找最小值可行区域在右侧if(check(mid)) r=mid; else l=mid+1;
// 二分答案通用框架：在 [L, R] 上二分答案
int l = L, r = R, ans = -1;
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (check(mid)) {      // mid 可行
        ans = mid;          // 记录当前最优答案
        r = mid - 1;        // 尝试找更小/更大的可行解
    } else {
        l = mid + 1;
    }
}
// ans 即为最终答案
📝 考试技巧： CSP-J 复赛第二题经常是二分答案应用题。关键在于将原问题转化成"判断 mid 是否可行"的形式。如果题目中有"最大值最小"或"最小值最大"的描述，大概率是二分答案！

二分答案经典问题 — 砍树

题目描述：有 n 棵树，每棵树高度为 h[i]。伐木工想砍下总长度至少为 M 米的木材。锯片设置成高度 H 时，能砍下所有高于 H 的部分（树高 > H 的部分长度之和）。问：锯片最高能设置成多少米？
输入：n=4, M=7, h[]={20, 15, 10, 17}
条件：1 ≤ n ≤ 10⁶, 1 ≤ M ≤ 2×10⁹, h[i] ≤ 10⁹

问题转化

check(H) = 判断锯片高度为 H 时，能砍下的木材总长度是否 ≥ M。

H 越小 → 砍下的越多 → 越满足条件。因此满足条件的 H 都在左侧（小值），我们要找最大的满足条件的 H。

// check 函数：高度 H 能否砍到至少 M 米
bool check(long long H) {
    long long total = 0;
    for (int i = 0; i < n; i++) {
        if (h[i] > H)
            total += h[i] - H;
        if (total >= M) return true;  // 提前返回优化
    }
    return total >= M;
}

输入示例的二分过程

h = [20, 15, 10, 17]，M = 7，答案范围 [0, 20]

mid砍下木材check操作
10(20-10)+(15-10)+(17-10)=10+5+7=22✅l→11 记录答案
15(20-15)+(17-15)=5+2=7✅l→16 记录答案
16(20-16)+(17-16)=4+1=5❌r→15
最终答案：H = 15（此时恰好砍下 7 米）

浮点数二分

当答案不是整数时，使用浮点二分

  • 核心区别：整数二分的边界是 l > r 或 l == r，浮点数二分用精度控制 while (r - l > eps)。
  • eps 选择：一般取 1e-7 到 1e-9。如果题目要求保留 k 位小数，eps 设为 1e-(k+2)。
  • mid 更新：直接 l = mid 或 r = mid（不需要 ±1）。

示例：求 x 的平方根（保留 6 位小数）

double mySqrt(double x) {
    double l = 0, r = x, eps = 1e-8;
    if (x < 1) r = 1;  // 处理 0<x<1 的情况

    while (r - l > eps) {
        double mid = (l + r) / 2;
        if (mid * mid >= x)
            r = mid;      // 平方过大，缩小右边界
        else
            l = mid;      // 平方过小，增大左边界
    }
    return l;  // 或 return r，此时 l≈r
}
// 注意：mid*mid 可能溢出，实际可用 mid > x/mid 代替
⚠️ 常见错误： 浮点数二分不能使用 while(l <= r) 因为浮点数几乎永远不会精确相等。务必使用精度控制！如果固定迭代次数（如 100 次），可以保证结果精度达到 2^(-100)。

代码模板汇总

模板一：整数二分查找（闭区间）

// 在有序数组 a[0..n-1] 中查找 x，返回下标，未找到返回 -1
int binarySearch(int a[], int n, int x) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}

模板二：二分答案（找最大可行解）

int l = L, r = R, ans = 0;
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (check(mid)) {
        ans = mid;        // 记录可行解
        l = mid + 1;      // 尝试更大的（找最大值）
    } else {
        r = mid - 1;
    }
}

模板三：浮点数二分

double l = L, r = R;
const double eps = 1e-8;
while (r - l > eps) {
    double mid = (l + r) / 2;
    if (check(mid)) r = mid;
    else l = mid;
}

真题精练 — 砍树问题（完整 AC 代码）

题目再现：n 棵树高度 h[i]，需要至少 M 米木材。锯片高度 H 能砍下所有高于 H 的部分。求锯片能设置的最大高度 H。

完整 AC 代码

#include <iostream>
using namespace std;
typedef long long ll;

const int N = 1e6 + 5;
int n, h[N];
ll M;

bool check(ll H) {
    ll total = 0;
    for (int i = 0; i < n; i++) {
        if (h[i] > H) total += h[i] - H;
        if (total >= M) return true;
    }
    return false;
}

int main() {
    cin >> n >> M;
    ll maxH = 0;
    for (int i = 0; i < n; i++) {
        cin >> h[i];
        maxH = max(maxH, (ll)h[i]);
    }

    ll l = 0, r = maxH, ans = 0;
    while (l <= r) {
        ll mid = l + (r - l) / 2;
        if (check(mid)) {
            ans = mid;
            l = mid + 1;    // 找更大的 H
        } else {
            r = mid - 1;
        }
    }
    cout << ans << endl;
    return 0;
}
📝 考试技巧： 砍树问题数据范围可达 10⁹，要使用 long long！total 累加和 mid*mid 都可能溢出 int。在 CSP-J 中，涉及累加和的二分答案题，一律用 long long。

本课小结

  • 二分查找前提：序列有序。闭区间写法 while(l <= r) 最推荐，边界清晰不易出错。
  • STL 函数：lower_bound() 找第一个 ≥x 的位置，upper_bound() 找第一个 >x 的位置。差值可得出现次数。
  • 二分答案：当答案区间有单调性时，二分答案值，通过 check(mid) 判断可行性。关键词："最大值最小"、"最小值最大"。
  • check 函数设计：二分答案的核心！必须保证正确性和高效性（通常 O(n) 即可）。
  • 浮点数二分：用精度控制 while(r-l > eps)，eps 一般为 1e-8。注意 mid*mid 溢出。
  • 类型安全：二分答案题数据范围大，养成用 long long 和 mid = l + (r-l)/2 防溢出的好习惯。
