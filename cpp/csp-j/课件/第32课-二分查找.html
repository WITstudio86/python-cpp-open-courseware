一、核心思想与例子

  1. [0,9] mid=4，a[4]=9<11 → 右 [5,9]
  2. [5,9] mid=7，a[7]=15>11 → 左 [5,6]
  3. [5,6] mid=5，a[5]=11 → 找到
n线性最坏二分约
10³100010
10⁶1e620

【讲解】log2 心算。

二、闭区间写法 while(l<=r)

int binarySearch(int a[], int n, int x) { int l = 0, r = n - 1; while (l <= r) { int mid = l + (r - l) / 2; // 防溢出 if (a[mid] == x) return mid; else if (a[mid] < x) l = mid + 1; else r = mid - 1; } return -1; }
  • l==r 时仍要检查
  • 排除 mid：l=mid+1 / r=mid-1
【讲解】三者一致：定义/条件/缩小。

三、左边界（第一个 =x）

int lowerBoundManual(int a[], int n, int x) { int l=0, r=n-1, ans=-1; while (l <= r) { int mid = l + (r - l) / 2; if (a[mid] >= x) { if (a[mid] == x) ans = mid; r = mid - 1; // 继续向左 } else l = mid + 1; } return ans; }
【讲解】有重复时找最左。

四、左闭右开 while(l<r)

int l = 0, r = n; // [l, r) while (l < r) { int mid = l + (r - l) / 2; if (a[mid] == x) return mid; else if (a[mid] < x) l = mid + 1; else r = mid; // 注意不是 mid-1 }
闭区间左闭右开
初始 rn-1n
循环l<=rl<r
向左r=mid-1r=mid
常用精确查找边界/二分答案
【讲解】混用是死循环主因。

五、lower_bound / upper_bound

#include <algorithm> // 第一个 >= x int p1 = lower_bound(a, a+n, x) - a; // 第一个 > x int p2 = upper_bound(a, a+n, x) - a; // 等于 x 的个数 int cnt = upper_bound(a,a+n,x) - lower_bound(a,a+n,x); // 是否存在 bool ok = binary_search(a, a+n, x);
返回迭代器/指针；不存在则等于 end（a+n）。
【讲解】竞赛优先 STL。

六、二分答案思想

在「可判定可行性」的答案区间上二分求最优。

  • 确定 [L,R] 候选答案范围
  • 写 check(mid)：mid 是否可行
  • 单调性：能/不能成一段，不能交替
// 求满足条件的最大值 while (l <= r) { int mid = l + (r-l)/2; if (check(mid)) { ans = mid; l = mid + 1; } else r = mid - 1; } // 求最小值：可行则 r=mid-1，不可行 l=mid+1
【讲解】最优化→判定。

七、二分答案例：木材切割

n 段木材，切出至少 k 段长度为 mid 的小段，求 mid 最大。

bool check(int mid) { long long cnt = 0; for (int i=0; i<n; i++) cnt += a[i] / mid; return cnt >= k; } // l=1, r=max(a_i)，二分最大 mid
mid 越大越难满足 → 单调，可二分。
【讲解】经典模型。

八、浮点数二分

double l = 0, r = x; const double eps = 1e-9; while (r - l > eps) { double mid = (l + r) / 2.0; if (mid * mid <= x) l = mid; // 无 ±1 else r = mid; } // 更稳：for(int i=0;i<100;i++) 固定 100 次

精度

eps 常用 1e-6～1e-9；过小可能死循环。优先固定迭代 60～100 次。

【讲解】sqrt 二分演示。

九、代码模板汇总

// 1. 标准查找 int binarySearch(...); // 见前 // 2. 二分答案最大值 int binaryAnswerMax(int L, int R) { int ans=L; while(L<=R){ int mid=L+(R-L)/2; if(check(mid)){ans=mid;L=mid+1;} else R=mid-1; } return ans; } // 3. STL lower_bound(a,a+n,x)-a; upper_bound(a,a+n,x)-lower_bound(a,a+n,x);
【讲解】三件套。

十、易错点

1. mid 溢出

用 l+(r-l)/2，勿 (l+r)/2 在极大时。

2. 区间与缩小不匹配

闭区间必须 ±1；半开 r=mid。

3. check 无单调

能→不能→能 不能二分。

4. 浮点 eps 不当

改用固定迭代更稳。

5. 未排序就二分

结果错误且难查。

【讲解】死循环多半是 2。

十一、真题①：多查询存在性

升序数组 a[n]，q 次询问 x 是否存在。

sort(a, a+n); // 若未保证有序 while (q--) { int x; cin >> x; cout << (binary_search(a, a+n, x) ? "Yes" : "No") << endl; }

或 lower_bound 后判断 *it==x 且 it!=end。

【练习】对比手写与 STL。

十二、真题②：统计区间个数

有序数组中，有多少个数落在 [L,R]？

int left = lower_bound(a, a+n, L) - a; int right = upper_bound(a, a+n, R) - a; cout << right - left << endl;
[L,R] 个数 = 第一个>R 的位置 − 第一个≥L 的位置。
【练习】画数轴理解。

十三、复杂度与选型

场景方法
