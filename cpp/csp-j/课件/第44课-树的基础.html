第44课：树的基础

CSP-J 备考课程

树 = 连通无环图 · n 个点恰好 n-1 条边

二叉树遍历：前中后序 + 层序

并查集：find · union · 路径压缩

图论单元收官：树 + 并查集。

一、树的基本概念

  • 有且仅有一个根
  • 除根外，每个点恰有一个父节点
  • 可有零或多个子节点；无孩子 → 叶子
  • 树 vs 图：连通且无环的无向图；n 点树有 n-1 边
术语含义
深度 Depth根到该点边数（根深度 0）
高度 Height到最远叶子边数
度 Degree子节点个数
子树某点及其所有后代
struct TreeNode { int val; TreeNode *left, *right; TreeNode(int x) : val(x), left(nullptr), right(nullptr) {} };
竞赛中常用编号 + 邻接表存一般树。

二、二叉树性质

  1. 第 i 层最多 2^(i-1) 个节点（i≥1）
  2. 深度 k 最多 2^k - 1 个节点
  3. 满二叉树：每层都满
  4. 完全二叉树：除最后一层外满，最后一层靠左（堆的结构）
  5. 叶子数 n0 与度为 2 的节点 n2：n0 = n2 + 1
完全二叉树数组下标（从 1 起）：左儿子 2i，右儿子 2i+1，父 i/2。

了解：BST（中序有序）、AVL（平衡）——选择题可能出现。

推导 n0=n2+1 可用边数关系：e=n-1。

三、四种遍历（必考）

名称顺序记忆
前序 Preorder根 → 左 → 右根打头
中序 Inorder左 → 根 → 右根居中
后序 Postorder左 → 右 → 根根收尾
层序 Level-orderBFS 按层队列
void preorder(TreeNode* r) { if (!r) return; cout << r->val << " "; preorder(r->left); preorder(r->right); } // 中序：左-根-右；后序：左-右-根
前序第一个 = 根；后序最后一个 = 根。BST 中序 = 升序。
递归第一行务必 if(!root) return。

四、层序 & 由遍历重建

void levelorder(TreeNode* root) { if (!root) return; queue<TreeNode*> q; q.push(root); while (!q.empty()) { TreeNode* cur = q.front(); q.pop(); cout << cur->val << " "; if (cur->left) q.push(cur->left); if (cur->right) q.push(cur->right); } }

前序+中序（或后序+中序）可唯一重建：

  • 前序第一个是根
  • 中序中根左为左子树，右为右子树
  • 仅前序+后序不能唯一确定
rootVal = pre[0]; pos = in.find(rootVal); 左子树大小 = pos; 递归 build 左右
手算前序 ABDECF + 中序 DBEACF → 后序 DEBFCA。

五、并查集入门

处理「集合合并与查询」：find（查代表元）+ union（合并）。

int parent[MAXN]; void init(int n) { for (int i = 1; i <= n; i++) parent[i] = i; } int find(int x) { if (parent[x] == x) return x; return parent[x] = find(parent[x]); // 路径压缩 } void unite(int a, int b) { int ra = find(a), rb = find(b); if (ra != rb) parent[ra] = rb; }
return parent[x] = find(parent[x]); // 一行路径压缩
无路径压缩链退化 O(n)，大数据 TLE。

六、按秩合并 & 应用

int rnk[MAXN]; void unite(int a, int b) { int ra = find(a), rb = find(b); if (ra == rb) return; if (rnk[ra] < rnk[rb]) parent[ra] = rb; else if (rnk[ra] > rnk[rb]) parent[rb] = ra; else { parent[rb] = ra; rnk[ra]++; } }

应用：

  • 两点是否连通：find(a)==find(b)
  • 连通分量数：统计 find(i)==i 的个数
  • Kruskal 最小生成树判环
  • 朋友圈 / 社交圈
路径压缩 + 按秩：均摊近 O(1)（阿克曼反函数）。
union 开头务必 if(ra==rb) return。

七、存储与技巧

  • 链式指针：适合二叉树动态结构
  • parent 数组：简单树
  • 邻接表：一般树 / 无根树（注意与父节点，防走回）
  • 完全二叉树数组：2i / 2i+1
口诀：前序根打头，中序根居中，后序根收尾；左总在右前。
无根树 DFS 传 fa 参数避免回头。

八、易错点

  1. 遍历顺序混淆（左/右搞反）
  2. 递归忘记判空指针
  3. 并查集不写路径压缩 → TLE
  4. union 不判已同集合
  5. 完全二叉树下标 0/1 约定混用
  6. 性质死记不推，变形题不会
统计朋友圈用 find(i)==i，比只看 parent[i]==i 更稳妥（有路径压缩后通常等价）。
课堂默写 find 一行路径压缩。

九、真题1：前序+中序求后序 · 题意

题意：两行字符串，前序与中序（互异大写字母），输出后序。

样例

输入： ABDECF DBEACF 输出： DEBFCA
思路：前序首字符为根；中序找根分左右；递归重建后后序输出（左右根）。
可手动画树验证。

真题1：核心代码

TreeNode* build(string pre, string in) { if (pre.empty() || in.empty()) return nullptr; char rootVal = pre[0]; TreeNode* root = new TreeNode(rootVal); int pos = in.find(rootVal); root->left = build(pre.substr(1, pos), in.substr(0, pos)); root->right = build(pre.substr(pos + 1), in.substr(pos + 1)); return root; } void postorder(TreeNode* r) { if (!r) return; postorder(r->left); postorder(r->right); cout << r->val; }
字母≤26，substr 开销可接受。

十、真题2：朋友圈 · 题意思路

题意：n 学生 m 对朋友关系（传递），问有几个朋友圈。n≤1e5。

样例：1-2,2-3,4-5 → 2

思路：并查集：每对朋友 unite；最后统计 find(i)==i 的个数。
等价于无向图连通块数（DFS/BFS 也可）。

真题2：核心代码

int parent[MAXN], rnk[MAXN]; int find(int x) { return parent[x]==x ? x : parent[x]=find(parent[x]); } void unite(int a, int b) { a=find(a); b=find(b); if (a==b) return; if (rnk[a]<rnk[b]) parent[a]=b; else if (rnk[a]>rnk[b]) parent[b]=a; else { parent[b]=a; rnk[a]++; } } // main: init; 读边 unite; cnt=0; for (int i=1;i<=n;i++) if (find(i)==i) cnt++; cout << cnt << endl;
加 ios 提速；路径压缩必写。

十一、本课小结

  1. 树：n 点 n-1 边，连通无环
  2. 二叉树性质：层节点、满/完全、n0=n2+1
  3. 四遍历：前中后 + 层序（BFS）
  4. 前序+中序 / 后序+中序 可重建
  5. 并查集：find 路径压缩 + union（按秩）
  6. 应用：连通、朋友圈、Kruskal
根的位置定遍历名；find 一行路径压
