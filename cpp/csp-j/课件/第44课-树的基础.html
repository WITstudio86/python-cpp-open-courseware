一、树的基本概念

什么是树？

树是一种非线性数据结构，模拟层级关系。有 n 个节点的树恰好有 n-1 条边，连通且无环。

基本术语

术语含义
根节点 (Root)树的最顶层节点，没有父节点，每棵树有且仅有一个根
父节点 (Parent)直接连接到当前节点上层的节点
子节点 (Child)直接连接到当前节点下层的节点
叶子节点 (Leaf)没有子节点的节点（度为0）
深度 (Depth)从根到该节点的路径长度（边数），根的深度为0
高度 (Height)从该节点到最远叶子的路径长度，叶子的高度为0
度 (Degree)一个节点拥有的子节点数目

二、二叉树的性质

二叉树（Binary Tree）是每个节点最多有两个子节点（左子节点和右子节点）的树。

五大核心性质（常考）

  1. 第 i 层最多节点数：2i−1 个（i ≥ 1）。
    推导：第1层 2⁰=1，第2层 2¹=2，第3层 2²=4 ... 数学归纳法可证
  2. 深度为 k 的二叉树最多节点数：2k − 1 个（k ≥ 1）。
    推导：等比数列和 2⁰ + 2¹ + ... + 2k−1 = 2k − 1
  3. 满二叉树：深度为 k 且有 2k−1 个节点的二叉树（每层都填满）。
  4. 完全二叉树：除最后一层外每层填满，且最后一层节点靠左排列。堆（heap）基于完全二叉树。
  5. n0 = n2 + 1：叶子节点数 = 度为2的节点数 + 1。
    推导：n = n0 + n1 + n2，边数 e = n1 + 2n2 = n − 1，代入得 n0 = n2 + 1

特殊二叉树

  • 二叉搜索树 (BST)：左子树所有值 < 根 < 右子树所有值。中序遍历 BST 得到递增有序序列。
  • 平衡二叉树 (AVL)：任意节点左右子树高度差不超过 1。
考试技巧：理解推导过程比死记硬背更重要。对于 k 叉树，第 i 层最多 ki−1 个节点，深度 k 的 k 叉树最多 (kk−1)/(k−1) 个节点。

三、二叉树的四种遍历

遍历是 CSP-J 的必考内容，必须能脱稿写出四种遍历的递归代码。

遍历方式速览

前序 Preorder
根 → 左 → 右
第一个一定是根
中序 Inorder
左 → 根 → 右
BST 中序 = 有序
后序 Postorder
左 → 右 → 根
最后一个一定是根
层序 Level-order
逐层从上到下
使用 BFS / 队列

递归实现代码

// 前序：根左右 void preorder(TreeNode* root) { if (!root) return; cout << root->val << " "; preorder(root->left); preorder(root->right); } // 中序：左根右 void inorder(TreeNode* root) { if (!root) return; inorder(root->left); cout << root->val << " "; inorder(root->right); } // 后序：左右根 void postorder(TreeNode* root) { if (!root) return; postorder(root->left); postorder(root->right); cout << root->val << " "; } // 层序：队列（BFS） void levelorder(TreeNode* root) { if (!root) return; queue<TreeNode*> q; q.push(root); while (!q.empty()) { TreeNode* cur = q.front(); q.pop(); cout << cur->val << " "; if (cur->left) q.push(cur->left); if (cur->right) q.push(cur->right); } }

遍历序列重建二叉树

前序 + 中序 或 后序 + 中序 可以唯一确定二叉树。核心：前序第一个 / 后序最后一个 = 根，在中序中确定左右子树范围。

注意：已知前序和后序不能唯一确定二叉树（无法区分左右子树为空的情况）。

四、并查集（Union-Find）

并查集用于处理"不相交集合的合并与查询"问题。两种核心操作：Find（查找所属集合）和 Union（合并两个集合）。

基础版本（理解原理用）

int parent[MAXN]; void init(int n) { for (int i = 1; i <= n; i++) parent[i] = i; // 每个元素自成集合 } int find(int x) { if (parent[x] == x) return x; return find(parent[x]); // 沿链向上查找 } void union_sets(int a, int b) { int ra = find(a), rb = find(b); if (ra != rb) parent[ra] = rb; }
问题：树可能退化成链，find 最坏 O(n)。需要优化！

优化版本（CSP-J 必备）

int parent[MAXN], rnk[MAXN]; void init(int n) { for (int i = 1; i <= n; i++) parent[i] = i, rnk[i] = 0; } // 路径压缩：关键的一行代码！ int find(int x) { if (parent[x] == x) return x; return parent[x] = find(parent[x]); } // 按秩合并 void union_sets(int a, int b) { int ra = find(a), rb = find(b); if (ra == rb) return; if (rnk[ra] < rnk[rb]) parent[ra] = rb; else if (rnk[ra] > rnk[rb]) parent[rb] = ra; else { parent[rb] = ra; rnk[ra]++; } }
核心记忆：return parent[x] = find(parent[x]); — 这一行代码同时完成了递归查找 + 路径压缩。时间复杂度近似 O(1)。

五、真题演练：树的遍历与朋友圈

题1：前序+中序求后序

题目：给定二叉树的前序和中序遍历序列（大写字母，互不相同），输出后序遍历序列。

输入：ABDECF / DBEACF    输出：DEBFCA

AC 代码

#include <iostream> #include <string> using namespace std; struct TreeNode { char val; TreeNode *left, *right; TreeNode(char x) : val(x), left(nullptr), right(nullptr) {} }; TreeNode* build(string pre, string in) { if (pre.empty() || in.empty()) return nullptr; TreeNode* root = new TreeNode(pre[0]); int pos = in.find(pre[0]); root->left = build(pre.substr(1, pos), in.substr(0, pos)); root->right = build(pre.substr(pos + 1), in.substr(pos + 1)); return root; } void postorder(TreeNode* root) { if (!root) return; postorder(root->left); postorder(root->right); cout << root->val; } int main() { string pre, in; cin >> pre >> in; TreeNode* root = build(pre, in); postorder(root); cout << endl; }

题2：朋友圈（并查集）

题目：n 个学生，m 对好友关系（传递性），求朋友圈数量。

输入：5 3 / 1 2 2 3 4 5    输出：2

解法：将所有关系 union，统计 find(i) == i 的节点数 = 朋友圈数量。

本课小结

  1. 树的基本概念：n 个节点的树有 n-1 条边，无环连通图。理解根、父、子、叶子、深度、高度、度等术语。
  2. 二叉树性质（必背）：第 i 层最多 2i−1 个节点；深度 k 最多 2k−1 个节点；n0 = n2 + 1。
  3. 四种遍历（必会）：前序（根左右）、中序（左根右）、后序（左右根）、层序（BFS 按层）。必须能写出递归代码并手算结果。
  4. 遍历序列重建：前序 + 中序 或 后序 + 中序 可唯一重建。前序 + 后序不行。
  5. 并查集核心操作：find（带路径压缩）+ union（按秩合并）。路径压缩一行代码 return parent[x] = find(parent[x]); 必须熟记。
  6. 并查集应用：判断连通性、统计连通分量数、Kruskal 最小生成树。均摊时间近似 O(1)。

  • 练习"前序 + 中序求后序"类题目，理解子串划分逻辑
