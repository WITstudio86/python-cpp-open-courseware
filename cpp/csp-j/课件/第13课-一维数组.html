第13课：一维数组

从单个变量到批量数据

📖 数组定义与初始化

定义语法

int a[100]; // 100个整数的数组 double b[50]; // 50个浮点数的数组 char s[1000]; // 1000个字符的数组（字符串）

初始化方式一：花括号

// 全部初始化 int a[5] = {10, 20, 30, 40, 50}; // 部分初始化，其余为0 int b[5] = {1, 2}; // {1,2,0,0,0} // 全部清零的快捷写法 int c[100] = {0}; // 省略大小 int d[] = {1, 3, 5, 7};

初始化方式二：逐个赋值

int a[5]; for (int i = 0; i < 5; i++) { cin >> a[i]; }

内存存储：连续存放

// int a[5]; 内存布局（每int占4字节） a[0] → a[1] → a[2] → a[3] → a[4] 0x1000 0x1004 0x1008 0x100C 0x1010
💡 关键特性
数组所有元素类型相同，在内存中连续存储，这使得遍历效率非常高（CPU 缓存友好）。

🔍 下标从0开始与数组遍历

下标规则

概念说明
第1个元素a[0]
第2个元素a[1]
第i个元素a[i-1]
最后元素a[n-1]
有效范围0 ~ n-1，共 n 个

经典遍历模板

for (int i = 0; i < n; i++) { cout << a[i] << " "; }

i 从 0 开始，i < n（不是 <=），这样 i 最大取 n-1。

常见应用一览

应用代码片段
求和sum += a[i];
最大值if (a[i] > maxVal) maxVal = a[i];
计数if (a[i] >= 60) cnt++;
反转swap(a[i], a[n-1-i]);（i 从 0 到 n/2）
查找if (a[i] == target) pos = i;
⚠ 越界访问 — 最危险的陷阱
C++ 不检查数组下标是否越界！a[5] = 100;（数组只有5个元素）不会报错，但可能修改其他变量的值，导致程序行为不可预料。这是 OJ 中 WA 或 RE 的常见原因。

💻 核心代码模板

模板一：找最大值及位置

int maxVal = a[0], pos = 0; for (int i = 1; i < n; i++) { if (a[i] > maxVal) { maxVal = a[i]; pos = i; } } cout << maxVal << " " << pos+1;

模板二：数组反转

// 方法一：对称交换 for (int i = 0; i < n/2; i++) swap(a[i], a[n-1-i]); // 方法二：双指针 int L = 0, R = n - 1; while (L < R) { swap(a[L], a[R]); L++; R--; }

模板三：计数统计（桶）

// 统计 0~100 分数段的人数 int cnt[101] = {0}; for (int i = 0; i < n; i++) { cnt[a[i]]++; // 以值作为下标计数 }
🎯 考试技巧
大数组（超过 10 万）一定要定义为全局数组（在 main 函数外面），否则会栈溢出导致程序崩溃。用 const int N = 100005; 定义常量是竞赛最佳实践。

📝 真题精练

真题1：不与最大数相同的数字之和

输入 N 个数，输出去掉所有最大值后剩余数字的和。

/* 样例输入: 3 1 2 3 样例输出: 3 ← 去掉最大数3，剩1和2 */ int maxVal = -2000000, sum = 0; for (int i = 0; i < n; i++) { cin >> a[i]; if (a[i] > maxVal) maxVal = a[i]; } for (int i = 0; i < n; i++) if (a[i] != maxVal) sum += a[i];

真题2：数组逆序重放

将一个数组中的值按逆序重新存放并输出。

/* 样例输入: 5 8 6 5 4 1 样例输出: 1 4 5 6 8 */ int L = 0, R = n - 1; while (L < R) { swap(a[L], a[R]); L++; R--; }
🎯 考试技巧
这两类题是 CSP-J 数组部分的"必考题"。核心思路：先遍历找最值，再遍历做处理；反转用双指针或对称交换。注意反转只需遍历到 n/2。

⚠ 易错点总结 & 本课小结

#易错点正确做法
1Off-by-one：遍历写成 i <= n应写 i < n，最后一个元素是 a[n-1]
2数组大小不是常量：int a[n]使用 const int N = 1005; int a[N];
3越界不报错：访问 a[100] 但只有100个元素始终确认下标在 0~n-1 范围内
4局部大数组：main 里定义 int a[1000000]定义为全局数组，避免栈溢出
5忘记初始化：局部数组含随机值定义时初始化为0，或全局定义
6部分初始化误解：int a[5]={1}只有 a[0]=1，其余=0，不是全1
🎯 本课核心要点
  1. 定义：类型 数组名[常量大小]，内存连续，通过下标访问。
  2. 下标从 0 开始，n 个元素下标范围 0 ~ n-1。
  3. 遍历模板：for (int i = 0; i < n; i++) 是所有操作的基础。
  4. 五大应用：求和平均、找最值、反转、计数统计、线性查找。
  5. 大数组放全局、大小用常量、绝不越界。
