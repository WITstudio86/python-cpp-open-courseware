第13课：一维数组

从单个变量到批量数据

定义 · 初始化 · 下标 0 起 · 遍历 · 最值/反转/计数/查找

【开场】说明本课从“几个变量”跨越到“一批数据”；配套 lesson13 程序可演示。

一、为什么需要数组

50 个成绩若写成 a1,a2,...,a50 几乎无法维护。数组用一个名字 + 下标管理同类型批量数据。

// 不用数组（灾难） int a1, a2, a3, a4, a5; cin >> a1 >> a2 >> a3 >> a4 >> a5; int sum = a1+a2+a3+a4+a5;
// 使用数组（优雅） int a[5]; for (int i=0; i<5; i++) cin >> a[i]; int sum = 0; for (int i=0; i<5; i++) sum += a[i];
知识点要求
定义 / 初始化掌握语法与 {}、逐个赋值
下标 / 遍历从 0 起，for 熟练读写
应用统计、最值、反转、计数、查找
越界 / 全局大数组了解危害；大数组放全局
【讲解】数据从 5→5000，数组写法几乎不改。点题：循环处理批量数据是算法入门门槛。

二、数组的定义语法

类型 数组名[数组大小]; // 大小须为常量表达式 int a[100]; double b[50]; char s[1000]; long long c[100005]; // 竞赛常用 const int N = 1005; int a[N]; // 推荐：常量命名上限
  • 类型：所有元素类型相同
  • 数组名：合法标识符
  • 大小：常量表达式；勿依赖 VLA int a[n]
💡 竞赛习惯
用 const int N = 100005; 开全局数组，改上限只改一处。
【讲解】三要素；强调大小必须常量。

三、数组在内存中的存储

数组在内存中连续存放。设 int a[5]，每 int 占 4 字节：

元素地址示例含义
a[0]0x1000起始
a[1]0x1004+4
a[2]0x1008+8
a[3]0x100C+12
a[4]0x1010+16
// 地址公式 地址(a[i]) = 地址(a[0]) + i * sizeof(类型) // a[i] 等价于 *(a + i)
  • 可快速定位任意下标；遍历缓存友好
  • 越界会踩到相邻内存，后果不可控
【讲解】连续存储是下标运算与越界危害的根因。

四、数组的初始化

// 花括号 int a[5] = {10,20,30,40,50}; int b[5] = {1, 2}; // 其余 0 int c[5] = {0}; // 全 0 int d[] = {1,2,3}; // 大小 3
// 逐个 / 统一赋值 int a[5]; for (int i=0; i<5; i++) cin >> a[i]; for (int i=0; i<5; i++) a[i] = 1; fill(a, a+5, 1); // algorithm
⚠ 重要规则
int a[5] = {1}; 是 a[0]=1、其余 0，不是全 1。
局部未初始化 = 垃圾值；全局默认全 0。
【讲解】配合 demo01_definition。

五、下标从 0 开始 · 六、遍历

概念写法
第 1 个a[0]
最后a[n-1]
有效范围[0, n-1]
0-index推荐 C++ 习惯
1-index数组开 N+5，统一即可
// 经典遍历 for (int i = 0; i < n; i++) { // 处理 a[i] } // 从后往前 / 双指针 for (int i=n-1; i>=0; i--) ... for (int i=0,j=n-1; i<j; i++,j--)
🎯 口诀
i 从 0 起，条件写 i < n（不是 <=），最后下标是 n-1。整份代码编号习惯要统一。
【讲解】为什么从 0：偏移量 i*sizeof，i=0 正好起点。

七、下标越界 · 八、局部大数组与全局

int a[5] = {1,2,3,4,5}; a[5] = 100; // 越界！有效下标 0~4 // C++ 不检查越界 → WA / RE / 段错误 / 碰巧正确
规模建议
n ≤ 1000局部 / 全局均可
n ≥ 1e5必须全局（或堆）
二维 1000×1000 int约 4MB，优先全局
const int N = 1000000; int a[N]; // 全局：静态存储区，安全 int main() { // int a[1000000]; // 局部约 4MB，可能栈溢出 RE }
【讲解】防护：i<n；访问 a[i+1] 先保证 i+1<n。

九、常见应用（1）求和 / 最值 / 计数 / 查找

long long sum = 0; for (int i=0; i<n; i++) sum += a[i]; double avg = 1.0 * sum / n; // 防整除 int maxVal = a[0], maxPos = 0; for (int i=1; i<n; i++) if (a[i] > maxVal) { maxVal=a[i]; maxPos=i; } int cnt = 0, pos = -1; for (int i=0; i<n; i++) { if (a[i] == x) { cnt++; if (pos==-1) pos=i; } } // 桶计数（值域小）：int cnt[101]={0}; cnt[a[i]]++;
💡 初始化最值
非空用 a[0] 最稳；题目要“编号最小的最大元”用 > 不用 >=。
【讲解】demo03 / demo05 / demo06。

九、常见应用（2）反转与高频技巧

// 对称交换 for (int i=0; i<n/2; i++) swap(a[i], a[n-1-i]); // 双指针 int L=0, R=n-1; while (L < R) { swap(a[L], a[R]); L++; R--; }
// 循环右移 1 位 int last = a[n-1]; for (int i=n-1; i>=1; i--) a[i] = a[i-1]; a[0] = last; // 右移 k：b[(i+k)%n]=a[i] // 删除下标 p：整体前移 n--

手算示例：[3,1,4,1,5] → 和 14，最大 5@4，反转后 [5,1,4,1,3]，1 出现 2 次。

【讲解】demo04 / demo07；只输出逆序可从后往前打印。

💻 代码模板（1）输入输出 · 最值

#include <iostream> using namespace std; const int N = 1005; int a[N]; int main() { int n; cin >> n; for (int i=0; i<n; i++) cin >> a[i]; int maxVal = a[0], maxPos = 0; for (int i=1; i<n; i++) if (a[i] > maxVal) { maxVal=a[i]; maxPos=i; } cout << maxVal << " " << maxPos+1 << endl; // 1-编号 return 0; }
【讲解】模板一、二；输出编号注意 +1。

💻 代码模板（2）反转 · 综合统计

// 反转后输出 for (int i=0; i<n/2; i++) swap(a[i], a[n-1-i]); // 求和 / 平均 / 计数 / 首次位置 long long sum = 0; int cnt = 0, pos = -1; for (int i=0; i<n; i++) { sum += a[i]; if (a[i] == x) { cnt++; if (pos==-1) pos=i; } } cout << fixed << setprecision(2) << 1.0*sum/n << endl;
🎯 必须默写
输入输出、最值位置、反转、桶计数、线性查找——五类模板考前过一遍。
【讲解】模板三、四；sum 用 long long。

📝 真题精练

真题1：不与最大数相同的数字之和

去掉所有最大值后求和；元素可负，max 初值勿用 0。

int maxVal = -2000000, sum = 0; for (int i=0; i<n; i++) { cin >> a[i]; if (a[i] > maxVal) maxVal = a[i]; } for (int i=0; i<n; i++) if (a[i] != maxVal) sum += a[i];

真题2：数组逆序重放

int L=0, R=n-1; while (L < R) { swap(a[L], a[R]); L++; R--; } // 或仅输出：for (int i=n-1; i>=0; i--) cout<<a[i]<<" ";
【讲解】exam01/exam02；边界：全相同输出 0；负数。

⚠ 易错点

#易错点正确做法
1Off-by-one：i<=ni < n，末元 a[n-1]
2int a[n] 非常量const int N; int a[N]
3越界不报错始终保证 0~n-1
4局部大数组栈溢出全局定义
5局部未初始化赋值或全局 0
6{1} 当全 1仅 a[0]=1，余 0
7平均整除1.0*sum/n
8sum 溢出long long
9编号混用输出 1-index 记得 +1
自查 10 秒
循环条件？数组够大/全局？类型？n=1 边界？编号 +1？
【讲解】CSP-J 最频繁扣分：Off-by-one。

🎯 本课小结

  1. 定义：类型 名[常量大小]，同类型连续存储。
  2. 下标：从 0 起，范围 0~n-1，遍历 i < n。
  3. 初始化：{} / 部分补 0 / 循环赋值；{1}≠全 1。
  4. 五大应用：求和平均、最值、反转、计数、线性查找。
  5. 安全：不越界；大数组全局；sum 用 long long。
一句话记忆
数组是“连续编号的同类型变量队列”；下标从 0，循环 i < n，大数组放全局。
