第14课：二维数组

矩阵 · 转置 · 对角线 · 杨辉三角

行优先存储 · 双层 for · 全局大数组

【开场】从“线”到“面”；配套 lesson14。

一、为什么需要二维数组

  • 课程表、棋盘、成绩表、像素、迷宫……数据天然是“行 × 列”
  • 一维是“一条线”，二维用 a[i][j] 定位表格中的一格
  • 逻辑二维，内存仍是连续一维（行优先）
知识点要求
定义 / 初始化类型 名[行][列]；按行 {{}}
行列遍历双层 for 熟练
矩阵操作转置、对角线、边缘
杨辉三角生成并输出前 n 行
【讲解】场景引入；考纲对照。

二、定义语法 · 三、行优先存储

int a[3][4]; // 3 行 4 列，共 12 元 const int N = 105; int a[N][N]; // 竞赛推荐 bool vis[1005][1005]; // 访问标记

int a[2][3] 内存顺序：

a[0][0] → a[0][1] → a[0][2] → a[1][0] → a[1][1] → a[1][2] 地址(a[i][j]) = 基址 + (i * 列数 + j) * sizeof(类型)
  • 按行遍历更贴合缓存
  • 初始化只能省略第一维，第二维必须写
【讲解】a[0][3] 可能踩到 a[1][0]。

四、二维数组的初始化

int a[2][3] = { {1, 2, 3}, {4, 5, 6} }; // 推荐：按行分组 int b[2][3] = {1,2,3,4,5,6}; // 合法但不直观 int c[3][3] = {0}; // 全 0 int d[][3] = {{1,2,3},{4,5,6}}; // 推 2 行 // int e[3][]; // 非法！不能省略列
⚠ 规则
{{1,2}} 只初始化部分元素，其余自动 0。列维不可省略。
【讲解】与一维部分初始化一致。

五、行列遍历（双层 for）

// 输入 n 行 m 列 for (int i = 0; i < n; i++) // 外层：行 for (int j = 0; j < m; j++) // 内层：列 cin >> a[i][j]; // 按矩阵格式输出（每行换行） for (int i = 0; i < n; i++) { for (int j = 0; j < m; j++) cout << a[i][j] << " "; cout << endl; }
关键规律
a[i][j] = 第 i 行、第 j 列（均从 0 起）。按列遍历时交换内外层即可。
【讲解】输出少 endl 是常见格式错。

六、矩阵操作（1）转置 · 对角线

// 转置：b[j][i]=a[i][j] for (int i=0; i<n; i++) for (int j=0; j<m; j++) b[j][i] = a[i][j]; // 输出 m 行 n 列 // 方阵原地：扫上三角 for (int i=0; i<n; i++) for (int j=i+1; j<n; j++) swap(a[i][j], a[j][i]);
// 主对角 i==j sum += a[i][i]; // 副对角 i+j==n-1 sum += a[i][n-1-i]; // 奇数阶：中心在主+副 // 两对角相加会重复一次 if (n%2) both -= a[n/2][n/2];
【讲解】转置后循环上下界互换。

六、矩阵操作（2）边缘 · 三角 · 行和

// 边缘：首末行或首末列 if (i==0 || i==n-1 || j==0 || j==m-1) border += a[i][j]; // 逐格判断，角不重复 // 上三角 i<=j；下三角 i>=j // 行和 / 列和 for (int j=0; j<m; j++) rowSum += a[i][j]; for (int i=0; i<n; i++) colSum += a[i][j];
⚠ 角点重复
若分四条边累加，四个角各加两次；优先用“逐格 if 边缘”写法。
【讲解】1×m 全部是边缘。

七、杨辉三角

  • 每行首尾为 1
  • 其余：a[i][j] = a[i-1][j-1] + a[i-1][j]
  • 内层 j 从 1 到 i-1（j < i）
for (int i = 0; i < n; i++) { a[i][0] = a[i][i] = 1; for (int j = 1; j < i; j++) a[i][j] = a[i-1][j-1] + a[i-1][j]; } // n=5：1 / 1 1 / 1 2 1 / 1 3 3 1 / 1 4 6 4 1
溢出
n 稍大组合数暴涨，必要时 long long。
【讲解】手算第 3 行 3=1+2。

八、地图入门 · 九、规模 · 十、一维映射

char mp[105][105]; int dx[4]={-1,1,0,0}; int dy[4]={0,0,-1,1}; // (x,y)→(x+dx[k], y+dy[k]) // 一维模拟二维 // id = i*m + j a[i*m + j] = x;
声明约空间建议
100×100 int40KB随便
1000×10004MB全局
5000×5000100MB慎用
【讲解】DFS/BFS 后续课；本课先会存与扫。

💻 代码模板（1）输入输出 · 转置

const int N = 105; int a[N][N], b[N][N]; int n, m; cin >> n >> m; for (int i=0; i<n; i++) for (int j=0; j<m; j++) cin >> a[i][j]; for (int i=0; i<n; i++) for (int j=0; j<m; j++) b[j][i] = a[i][j]; for (int i=0; i<m; i++) { for (int j=0; j<n; j++) cout << b[i][j] << " "; cout << endl; }
【讲解】样例 2×3 → 3×2。

💻 代码模板（2）杨辉 · 对角边缘

// 杨辉 n 行 for (int i=0; i<n; i++) { a[i][0]=a[i][i]=1; for (int j=1; j<i; j++) a[i][j]=a[i-1][j-1]+a[i-1][j]; } // 主对角 + 边缘 int d=0, e=0; for (int i=0; i<n; i++) { d += a[i][i]; for (int j=0; j<n; j++) if (i==0||i==n-1||j==0||j==n-1) e += a[i][j]; }
【讲解】模板三、四。

📝 真题精练

真题1 转置：2 3 / 1 2 3 / 4 5 6 → 1 4 / 2 5 / 3 6

真题2 杨辉：输入 5，输出标准三角

例题3：主对角和 + 边缘和（3×3 示例 15 与 40）

// 主对角 1+5+9=15；边缘不含中心 5 → 40 for (int i=0; i<n; i++) { d += a[i][i]; for (int j=0; j<n; j++) if (i==0||i==n-1||j==0||j==n-1) e+=a[i][j]; } cout << d << endl << e << endl;
【讲解】先想行列，再写循环。

⚠ 易错点

#易错纠正
1行列混淆i 行 j 列，写反全错
2int a[3][]只能省第一维
3内外层搞反先 i 后 j 按行扫
4局部 1000×1000全局
5杨辉内层 j<=ij<i，末元已置 1
6转置后循环不换输出 m 行 n 列
7主+副重复中心奇数阶减一次
8边缘分边加角逐格 if 更安全
【讲解】投影对照表过一遍。

🎯 本课小结

  1. 定义 类型 名[行][列]，内存行优先连续。
  2. 初始化推荐 {{1,2},{3,4}}；只能省行维。
  3. 双层 for：外行内列；每行输出后 endl。
  4. 转置 b[j][i]=a[i][j]；主 i==j；副 i+j==n-1。
  5. 杨辉：首尾 1，中间上一行两数之和。
  6. 大二维数组放全局；防行列、重复、格式错误。
一句话
二维数组是“行优先的表格”；外层行内层列；转置换下标，杨辉看上一行。
【收尾】练习：副对角、行和、对称矩阵、上下翻转。
