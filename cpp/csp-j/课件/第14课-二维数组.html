📖 二维数组定义与初始化

定义语法

int a[3][4]; // 3行4列的二维数组 double b[10][10]; // 10x10 矩阵

内存存储：行优先

二维数组在内存中仍然是一维连续存储的，按行依次排列：

// a[2][3] 的内存布局（6个int连续存放）： a[0][0] a[0][1] a[0][2] a[1][0] a[1][1] a[1][2]

初始化方式一：按行初始化

int a[2][3] = { {1, 2, 3}, {4, 5, 6} };

最清晰的方式，推荐使用。

初始化方式二：省略第一维

int a[][3] = { {1,2,3}, {4,5,6} }; // 自动推导为2行
int b[3][3] = {0}; // 全部清零
⚠ 重要规则
初始化时只能省略第一维的大小，第二维必须指定！因为编译器需要通过列数来计算每行的起始位置。

🔍 矩阵遍历与常见操作

标准双层遍历模板

// 输入 for (int i = 0; i < n; i++) { // 外层：行 for (int j = 0; j < m; j++) { // 内层：列 cin >> a[i][j]; } } // 输出 for (int i = 0; i < n; i++) { for (int j = 0; j < m; j++) { cout << a[i][j] << " "; } cout << endl; }

常见操作

操作条件/方式
主对角线i == j
副对角线i + j == n - 1
边缘元素i==0 || j==0 || i==n-1 || j==n-1
上三角i <= j
下三角i >= j

矩阵转置

// a[n][m] 转置为 b[m][n] for (int i = 0; i < n; i++) for (int j = 0; j < m; j++) b[j][i] = a[i][j];
💡 记忆技巧
外层行 i，内层列 j。
a[i][j] 表示第 i 行第 j 列的元素。

🔺 杨辉三角

原理

每行首尾为 1，中间每个数等于上一行左上方与正上方两数之和：a[i][j] = a[i-1][j-1] + a[i-1][j]

生成代码

// 生成前 n 行杨辉三角 int a[15][15] = {0}; for (int i = 0; i < n; i++) { a[i][0] = a[i][i] = 1; // 首尾为1 for (int j = 1; j < i; j++) { a[i][j] = a[i-1][j-1] + a[i-1][j]; } }

输出效果（n=6）

1 1 1 1 2 1 1 3 3 1 1 4 6 4 1 1 5 10 10 5 1
🎯 考试技巧
杨辉三角是 CSP-J 二维数组的经典考题，核心公式 a[i][j] = a[i-1][j-1] + a[i-1][j] 必须熟练记忆。出题可能变式为：倒三角、左对齐输出、每行求和等。

真题2：杨辉三角

/* 输入: 5 输出: 1 1 1 1 2 1 1 3 3 1 1 4 6 4 1 */
🎯 考试技巧
这两道题在历年 CSP-J 中反复出现。矩阵转置注意行和列不能搞反；杨辉三角注意不要忘记初始化首尾的1。完整 AC 代码见配套程序文件。

⚠ 常见易错点

#易错点说明
1行与列混淆a[i][j] 中 i 是行、j 是列，遍历时外层永远是行、内层永远是列。
2只能省略第一维int a[][4] 合法，int a[3][] 非法。
3内外层循环搞反如果先遍历列再遍历行，会破坏空间局部性，效率降低且输出格式错误。
4数组大小需常量和一维数组一样，二维数组的每一维大小都必须是常量表达式。
5大数组放全局int a[1000][1000] 约 4MB，必须定义为全局数组。
6对角线条件主对角线 i==j，副对角线 i+j==n-1（方阵）。务必记住这两个条件。
⚠ 特别注意
在杨辉三角代码中，a[i][0] = a[i][i] = 1 是把第 i 行第 0 列和第 i 列同时设为 1。
内层循环是 j = 1; j < i; j++（注意 j < i，不应该包含 i）。

🎯 本课小结

  1. 二维数组定义：类型 数组名[行数][列数]，内存按行优先连续存储。
  2. 初始化：推荐按行初始化 {{1,2},{3,4}}，只能省略第一维大小。
  3. 双层遍历：外层 i 控制行、内层 j 控制列，这是所有矩阵操作的基础。
  4. 常见操作：转置（b[j][i] = a[i][j]）、对角线（i==j 或 i+j==n-1）、边缘元素判断。
  5. 杨辉三角：核心公式 a[i][j] = a[i-1][j-1] + a[i-1][j]，首尾为 1。
  6. 易错防范：行列不搞反、大小用常量、大数组放全局。
