一、全排列与 next_permutation

{1,2,3} 共 3!=6 种：123,132,213,231,312,321。定义在 <algorithm>。

int arr[] = {1, 2, 3}; int n = 3; sort(arr, arr + n); // 必须先排序！ do { for (int i = 0; i < n; i++) cout << arr[i] << " "; cout << endl; } while (next_permutation(arr, arr + n));
  1. 必须先 sort：否则漏掉更小的排列
  2. 用 do-while：确保第一个（最小）排列也被处理
  3. 复杂度 O(n!)：n≥10 要小心，CSP-J 常 n≤8～10

返回值

存在下一排列 → true 并改序列；已是最大（降序）→ false 并重置为升序。

【讲解】对照程序 demoNextPermutation。

二、手动递归全排列（回溯）

bool used[15]; int result[15], arr[15], n; void dfs(int depth) { if (depth == n) { for (int i = 0; i < n; i++) cout << result[i] << " "; cout << endl; return; } for (int i = 0; i < n; i++) { if (!used[i]) { used[i] = true; result[depth] = arr[i]; dfs(depth + 1); used[i] = false; // 回溯：恢复状态 } } }
精髓：「标记 → 递归 → 恢复」。忘记 used[i]=false 是最常见 bug。

也可用 swap 法：在原数组上交换 pos 与 i，递归 pos+1，再 swap 回来（见程序 demoRecursivePermutation）。

【讲解】画决策树：depth 定位置，used 管元素。

三、子集枚举：位运算法

n 元集合有 2ⁿ 个子集。用 mask 的第 i 位表示是否选 a[i]。

for (int mask = 0; mask < (1 << n); mask++) { for (int i = 0; i < n; i++) { if (mask & (1 << i)) { // a[i] 在当前子集中 } } }
操作含义示例
1 << n2ⁿ1<<3 = 8
mask & (1<<i)第 i 位是否为 15&(1<<2)=4≠0
mask | (1<<i)第 i 位置 1—
1LL<<n防 int 溢出n≥31 必须

优先级陷阱

错误：mask & (1<<i) == 0（== 先算）。正确：(mask & (1<<i)) == 0。

【讲解】n=3 手写 8 个 mask 表。

四、子集递归生成 & 剪枝

bool chosen[25]; void generateSubset(int idx) { if (idx == n) { /* 输出当前子集 */ return; } chosen[idx] = false; generateSubset(idx + 1); // 不选 chosen[idx] = true; generateSubset(idx + 1); // 选 }

递归优势：过程中可剪枝。子集和问题中，若当前和已 > target（元素为正），直接 return。

选型：代码短、无剪枝 → 位运算；需要深剪枝/记录路径 → 递归回溯。
【讲解】对比位运算与递归。

五、回溯算法框架

void backtrack(当前状态) { if (满足结束条件) { 记录解; return; } for (枚举所有可能选择) { if (该选择可行) { 做出选择; // 改状态 backtrack(下一状态); 撤销选择; // 回溯 } } }
  • 普通枚举：盲目扫完所有叶子
  • 回溯：中间发现无解就剪枝回退

例：6 个数选 3 个和为 10；若第一个数已 7，则不必再选后两个。

【讲解】尝试→判断→继续/回退。

六、N皇后（以 4 皇后为例）

N×N 棋盘放 N 个皇后，不同行、列、对角线。每行恰放一个：pos[row]=col。

bool check(int row, int col) { for (int i = 0; i < row; i++) { if (pos[i] == col) return false; // 同列 if (abs(row - i) == abs(col - pos[i])) return false; // 对角线 } return true; } void solve(int row) { if (row == n) { ans++; return; } for (int col = 0; col < n; col++) if (check(row, col)) { pos[row] = col; solve(row + 1); } }
4 皇后共 2 种解；列位置序列 (1,3,0,2) 与 (2,0,3,1)（0-based）。复杂度 O(N!)。
【讲解】对照程序 printBoard 演示。

七、4皇后回溯过程示意

  1. row=0 放 col=0 → row=1
  2. row=1：col=0 同列、col=1 对角冲突，col=2 合法 → row=2
  3. row=2 全部冲突 → 回退 row=1
  4. row=1 试 col=3 合法 → … 继续搜索
  5. 最终找到 2 组完整方案
方案1 棋盘示意：. Q . .
. . . Q
Q . . .
. . Q .

为何不用显式撤销 pos？

下一轮 for 会覆盖 pos[row]；used 类标记则必须显式恢复。

【讲解】在黑板走一遍冲突判断。

八、代码模板汇总

// 1. next_permutation sort(a, a+n); do { /* 处理 a */ } while (next_permutation(a, a+n)); // 2. 位运算子集和 for (int mask = 0; mask < (1<<n); mask++) { int sum = 0; for (int i=0; i<n; i++) if (mask & (1<<i)) sum += a[i]; } // 3. 回溯全排列框架 void backtrack(int depth) { if (depth == n) { /* 输出 */ return; } for (int i=0; i<n; i++) if (!visited[i]) { visited[i]=true; result[depth]=i+1; backtrack(depth+1); visited[i]=false; } } // 4. N皇后：check + dfs(row) 见上页
【讲解】四模板对照默写。

九、五大易错点

1. next_permutation 忘记排序

漏掉字典序更小的排列。do-while 前永远 sort。

2. 位运算优先级

(mask & (1<<i)) 必须加括号。

3. 回溯忘记恢复

visited[i]=false 与修改对称书写。

4. 排列与组合混淆

有顺序→排列；无顺序→子集/组合。

5. 1<<n 溢出

n≥31 用 1LL<<n；CSP-J 通常 n≤20 用 int 即可。

【讲解】每条 15 秒反例。

十、真题①：全排列输出

给定互异小写字母串，字典序输出所有排列。1≤n≤8。

输入： 3 / abc
输出： abc acb bac bca cab cba（各占一行）
int n; char s[10]; cin >> n >> s; sort(s, s + n); do { cout << s << endl; } while (next_permutation(s, s + n));

8!=40320，完全可行。字符互异无需去重。

【练习】先写再对答案。

十一、真题②：子集和

n 个正整数，是否存在非空子集和 = target。1≤n≤20。

5 10 / 1 2 3 4 5 → YES
3 10 / 5 3 7 → NO
for (int mask = 1; mask < (1 << n); mask++) { // 从1跳过空集 int sum = 0; for (int i = 0; i < n; i++) { if (mask & (1 << i)) { sum += a[i]; if (sum > target) break; } } if (sum == target) { cout << "YES"; return 0; } } cout << "NO";

O(n·2ⁿ)，n=20≈2e7，C++ 可过。n=30 需折半搜索（超纲）。

【练习】强调 mask 从 1 开始。
