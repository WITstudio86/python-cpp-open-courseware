一、全排列生成 — next_permutation

1.1 什么是全排列？

将 n 个不同的元素按照所有可能的顺序进行排列。n 个元素的全排列共有 n! 种。

  • 例如 {1, 2, 3} 的全排列：123, 132, 213, 231, 312, 321（共 3! = 6 种）

1.2 C++ STL — next_permutation

C++ 标准库提供了 next_permutation 函数，可以按字典序生成下一个排列。

  • 头文件：<algorithm>
  • 语法：next_permutation(begin, end)，返回 true 表示生成了新排列，false 表示已经是最后一个排列
  • 使用前必须先排序，确保从最小的字典序开始
// 全排列示例 int a[] = {1, 2, 3}; sort(a, a + 3); // 必须先排序 do { cout << a[0] << " " << a[1] << " " << a[2] << endl; } while (next_permutation(a, a + 3));

1.3 prev_permutation

prev_permutation 生成前一个字典序排列。使用时需要先降序排列。

💡 考试技巧：next_permutation 的时间复杂度为 O(n) 每次调用，全排列枚举总复杂度为 O(n!)。当 n ≤ 10 时可行，n ≤ 8 时非常安全。千万不要忘记先 sort！

二、子集枚举 — 位运算的威力

2.1 什么是子集枚举？

给定 n 个元素的集合，枚举其所有子集（共 2n 个）。比如 {A, B, C} 的子集有 2³ = 8 个：{}, {A}, {B}, {C}, {A,B}, {A,C}, {B,C}, {A,B,C}。

2.2 位运算方法

用一个 n 位的二进制数 mask 表示子集，第 i 位为 1 表示包含第 i 个元素。

  • mask 从 0 到 2n-1 循环（共 2n 种状态）
  • 判断第 i 位是否为 1：(mask >> i) & 1 或 mask & (1 << i)
  • 时间复杂度：O(n × 2n)，n ≤ 20 时可行
// 枚举 {A, B, C} 的所有子集 char elems[] = {'A', 'B', 'C'}; int n = 3; for (int mask = 0; mask < (1 << n); mask++) { cout << "{"; for (int i = 0; i < n; i++) { if (mask & (1 << i)) cout << elems[i]; } cout << "}" << endl; }

2.3 递归方法

递归地"选/不选"每个元素，调用的递归树天然对应所有子集。代码更直观，但常数略大。

void dfs(int pos) { if (pos == n) { // 到达叶子节点，输出当前选中的元素 return; } selected[pos] = true; // 选择第 pos 个元素 dfs(pos + 1); selected[pos] = false; // 不选第 pos 个元素 dfs(pos + 1); }
💡 考试技巧：位运算子集枚举在 CSP-J 中非常高频。注意 1 << n 表示 2n，当 n=20 时约 10⁶，刚好够用。n 再大就需要剪枝或动态规划。

三、回溯思想入门

3.1 什么是回溯？

回溯（Backtracking）是一种深度优先的试探搜索算法，核心框架是：

  1. 尝试：选择一个可行的选项
  2. 判断：检查当前状态是否合法
  3. 回退：如果不合法或搜索完毕，撤销当前选择

3.2 回溯通用框架

void backtrack(int step) { if (step == n) { // 找到一组解 record_answer(); return; } for (int i = 0; i < choices; i++) { if (valid(i)) { // 剪枝：判断是否合法 apply(i); // 尝试 backtrack(step + 1); undo(i); // 回退（回溯） } } }

3.3 经典例题：N 皇后（4 皇后演示）

在 4×4 的棋盘上放置 4 个皇后，使它们互不攻击（任意两个皇后不在同一行、同一列、同一对角线）。

列 (col)主对角线 (d1)副对角线 (d2)
一维数组 col[n]row + colrow - col + n - 1

关键约束：每行必须放一个皇后，逐行放置，对每一列试探。4 皇后共有 2 种本质不同的解：

解 1：第 1 行第 3 列，第 2 行第 1 列，第 3 行第 4 列，第 4 行第 2 列

解 2：第 1 行第 2 列，第 2 行第 4 列，第 3 行第 1 列，第 4 行第 3 列

💡 考试技巧：回溯 = DFS + 剪枝 + 状态恢复。写回溯代码最忌讳忘了"回退"——恢复状态，否则后面的搜索会受影响。对角线判断用 row + col 和 row - col + n - 1 的技巧是高频考点。

// 子集枚举位运算模板 int n; // 元素个数 for (int mask = 0; mask < (1 << n); mask++) { // mask 的二进制位表示子集中包含哪些元素 for (int i = 0; i < n; i++) { if (mask & (1 << i)) { // 第 i 个元素在子集中 } } }

4.3 回溯框架模板

// 回溯通用框架 bool used[MAXN]; int ans[MAXN]; void backtrack(int step) { if (step == n) { // 找到一组解，输出或统计 return; } for (int i = 0; i < n; i++) { if (!used[i]) { // 剪枝判断 used[i] = true; // 尝试 ans[step] = i; backtrack(step + 1); used[i] = false; // 回退 } } }

五、真题精练 — 子集和问题

题目描述

给定 n 个正整数和一个目标值 S，判断是否存在一个子集，其元素之和恰好等于 S。如果存在，输出 "YES"；否则输出 "NO"。（n ≤ 20，元素值 ≤ 10⁶，S ≤ 2 × 10⁷）

输入格式

第一行：两个整数 n 和 S。第二行：n 个正整数 a₁, a₂, ..., aₙ。

输出格式

一行："YES" 或 "NO"。

输入样例

5 10 1 3 5 7 9

输出样例

YES // 解释：可以选择 {1, 9} 或 {3, 7}

解题思路

使用子集枚举位运算，枚举 2n 种选法，对每种选法求和并与 S 比较。n ≤ 20 时 2²⁰ ≈ 10⁶，完全可行。

参考代码

#include <iostream> using namespace std; int main() { int n, S, a[25]; cin >> n >> S; for (int i = 0; i < n; i++) cin >> a[i]; for (int mask = 0; mask < (1 << n); mask++) { int sum = 0; for (int i = 0; i < n; i++) { if (mask & (1 << i)) sum += a[i]; } if (sum == S) { cout << "YES" << endl; return 0; } } cout << "NO" << endl; return 0; }
💡 考试技巧：子集和问题是 CSP-J 常客。n 较大时（n > 20），可用「折半搜索」（Meet in the Middle）将复杂度降为 O(2n/2)，这是进阶考点。

六、本课小结

  1. next_permutation 是 C++ STL 提供的全排列利器，使用前必须 sort，n ≤ 10 时 O(n!) 可行
  2. 子集枚举位运算法：mask 从 0 到 2n-1，用 & 运算判断元素是否在子集中，n ≤ 20 可行
  3. 子集枚举递归法：每个元素"选/不选"的递归树天然对应所有子集
  4. 回溯 = DFS + 剪枝 + 状态恢复：尝试 → 判断 → 回退，千万不要忘记恢复状态！
  5. N 皇后问题的对角线技巧：row + col（主对角线）和 row - col + n - 1（副对角线）
  6. 子集和问题是典型应用，位运算枚举 2n 种选法即可解决 n ≤ 20 的情况

枚举进阶的核心是：用正确的方式穷举，用智慧的方式剪枝。
