一、string 类的定义与输入

🔹 为什么用 string？

C 风格字符串的痛点：

  • 手动管理 \0，易遗漏
  • 容量固定，拼接前需估算
  • 不能直接用 =、+、==

string 类的优势：

  • 自动管理内存，无需关心容量
  • 动态扩容，随心拼接
  • 直观的运算符重载

🔹 定义与初始化

#include <string>
using namespace std;

string s1;                     // 空字符串 ""
string s2 = "hello";          // 字面量初始化
string s3("world");           // 构造函数方式
string s4 = s2;               // 拷贝初始化
string s5(5, 'a');           // 重复字符 "aaaaa"
string s6 = s2 + " " + s3;    // 拼接初始化

🔹 输入方式

string s;
cin >> s;                  // 遇空格/Tab/换行停止
getline(cin, s);          // 读取整行（含空格）
⚠️ 混用陷阱：cin >> 后缓冲区残留 '\n'，紧接着的 getline 会读到空行。
解决方法：在 cin >> 后加 cin.ignore(); 清除换行符。

二、string 常用操作

操作语法说明
拼接 s1 + s2 或 s1 += s2 至少一个操作数是 string
比较 == != > < >= <= 字典序比较，返回 bool
长度 .length() 或 .size() 两者等价
子串 .substr(pos, len) len 是长度，非结束位置
查找 .find(str) 找不到返回 string::npos
访问字符 s[i] 可读可写

🔹 substr 与 find 详解

string s = "Hello World";
cout << s.substr(0, 5);   // "Hello"（从0开始，取5个）
cout << s.substr(6);      // "World"（省略len，取到末尾）

size_t pos = s.find("World");   // pos = 6
if (pos != string::npos) {         // 找到了！
    cout << "找到，位置: " << pos << endl;
}
💡 substr 易错：第2参数是取几个字符，不是结束索引。
s.substr(2, 3) → 取索引 2、3、4（共3个），而非取到索引 3。
⚠️ find 易错：找不到返回 string::npos，不是 -1。
正确判断：if (s.find(x) != string::npos)

三、字符判断函数

头文件：#include <cctype>（C++ 风格，推荐）

函数作用示例
isdigit(c) 是否为数字 '0'~'9' isdigit('5') → true
isalpha(c) 是否为字母 a~z 或 A~Z isalpha('A') → true
islower(c) 是否为小写字母 islower('a') → true
isupper(c) 是否为大写字母 isupper('Z') → true
isalnum(c) 是否为字母或数字 isalnum('9') → true
isspace(c) 是否为空白字符 isspace(' ') → true
tolower(c) 转为小写字母 tolower('A') → 'a'
toupper(c) 转为大写字母 toupper('a') → 'A'

🔹 综合示例：字符统计 + 大小写翻转

string s;
getline(cin, s);

int upper = 0, lower = 0, digit = 0;
for (char &c : s) {          // 用引用 &c 直接修改原字符
    if (isupper(c)) { upper++; c = tolower(c); }
    else if (islower(c)) { lower++; c = toupper(c); }
    else if (isdigit(c)) { digit++; }
}
💡 技巧：使用 for (char &c : s) 的引用形式，可以直接修改字符串中的字符，无需通过下标。

四、真题精练

📝 真题1：string 操作结果判断

阅读代码，判断输出结果。

string s = "I love CSP-J";
cout << s.length() << endl;       // Q1: 12（空格也算）
cout << s.substr(7, 5) << endl;   // Q2: "CSP-J"
cout << s.find("CSP") << endl;      // Q3: 7
s += "!";
cout << s << endl;                    // Q4: "I love CSP-J!"
cout << (s.find("Python") == string::npos);
                                     // Q5: 1（未找到）

📝 真题2：字符统计与大小写翻转

输入一个字符串，统计大写、小写、数字的数量，并将大小写翻转输出。

样例输入："Hello World 123!"

样例输出：2 8 3 + "hELLO wORLD 123!"

int u = 0, l = 0, d = 0;
for (char &c : s) {
    if (isupper(c)) { u++; c = tolower(c); }
    else if (islower(c)) { l++; c = toupper(c); }
    else if (isdigit(c)) d++;
}
cout << u << " " << l << " " << d << endl << s;

五、本课小结

  1. string 类的优势：自动内存管理、运算符重载（+ += == 等）、丰富成员函数，比 C 风格字符串更安全便捷。
  2. 定义与初始化：多种构造方式；+ 拼接至少需要一个 string 操作数（两 const char* 不能直接相加）。
  3. 输入方式：cin >> s 遇空格停止；getline(cin, s) 读整行。混用时用 cin.ignore() 清除换行符。
  4. 核心操作： 长度 .length() / .size() 子串 .substr(pos, len)（len 是长度！） 查找 .find(str)（返回 string::npos 表示未找到）
  5. 字符判断函数：需要 #include <cctype>；isdigit / isalpha / islower / isupper / tolower / toupper。
  6. CSP-J 选型建议：字符串操作频繁时优先使用 string 类；需要与 C 函数交互时可用 .c_str() 转换。
