string 类与字符处理

定义 · 输入 · +/== · length · substr · find · cctype

🎯 考纲：string 核心操作；isdigit/isalpha/tolower 等；理解相对 C 风格字符串的优势。
【开场】配套 lesson16。

一、为什么用 string？

  • C 串痛点：手动 '\0'、容量固定、操作靠 strcpy/strcmp
  • string：自动内存；支持 = + ==；成员函数丰富
// C 风格
char a[100]="hello", b[100];
strcpy(b, a); strcat(b, " world");
if (strcmp(a,b)==0) ...

// string
string s1 = "hello";
string s2 = s1; s2 += " world";
if (s1 == s2) ...
【讲解】新写代码优先 string。

二、定义与初始化

#include <string>
string s1;                 // ""
string s2 = "hello";
string s3("world");
string s4 = s2;            // 拷贝
string s5(5, 'a');         // "aaaaa"
string s6 = s2 + " " + s3;  // "hello world"
// string s = "a" + "b";  // 错：两个字面量不能 +
// string s = string("a") + "b";  // 对
【讲解】+ 至少一侧是 string。

三、输入：cin 与 getline

string s;
cin >> s;           // 遇空白停
getline(cin, s);    // 整行含空格

int n; cin >> n;
cin.ignore();       // 清残留 '\n'
getline(cin, s);    // 否则读空行
混用必 ignore：先 cin>> 再 getline 是考试高频坑。
【讲解】读 n 行：循环前 ignore 一次。

四、基本操作（1）拼 · 比 · 长度 · 下标

string s1="Hello", s2="World";
string s3 = s1 + " " + s2;  s1 += "!";
if (s1 < s2) ...     // 字典序
cout << s3.length(); // 与 .size() 等价
s3[0] = 'h';          // 可改字符
【讲解】比较语义比 strcmp 直观。

四、基本操作（2）substr · find

string s = "Hello World";
s.substr(0, 5);   // "Hello"  —— 第2参是长度！
s.substr(6);      // "World" 到末尾
// s.substr(2,3) → 索引 2,3,4 共3个，不是取到索引3

size_t pos = s.find("World");  // 6
if (s.find("abc") == string::npos)  // 未找到
    cout << "no";
// 多次：find(P, pos); pos = p + P.size(); // 不重叠
【讲解】npos 不要写 -1（虽有时碰巧）。

五、字符判断函数（cctype）

函数作用
isdigit / isalpha数字 / 字母
islower / isupper小写 / 大写
isalnum / isspace字母数字 / 空白
tolower / toupper大小写转换
 
#include <cctype>
for (char c : s) {
    if (isdigit(c)) digits++;
    if (isalpha(c)) letters++;
}
for (char &c : s) c = toupper(c);  // 引用可改
【讲解】返回 int，非 0 为真。

六、综合：字符统计 · 进阶成员

getline(cin, s);
int d=0, u=0, l=0;
for (char &c : s) {
    if (isupper(c)) { u++; c=tolower(c); }
    else if (islower(c)) { l++; c=toupper(c); }
    else if (isdigit(c)) d++;
}
// push_back / insert / erase / replace / empty / clear
// c_str() → const char* 给旧接口
// 桶：int letter[26]; letter[c-'a']++
【讲解】进阶节可扫；CSP-J 够用。

遍历陷阱 · 输入专题

// size_t 无符号：空串时 size()-1 下溢
for (int i=(int)s.size()-1; i>=0; i--) ...

// 多组行
while (getline(cin, s)) { ... }

// 按空格拆词
stringstream ss(line);

while ((p = T.find(P, p)) != string::npos) {

⚠ 易错点

  1. cin 与 getline 混用忘 ignore
  2. find 用 npos 判断，勿写 -1
  3. substr 第二参数是长度
  4. 两个字面量不能直接 +
  5. size_t 反向循环空串下溢
  6. c_str() 指针勿长期保存
【讲解】对照讲义易错表。

🎯 本课小结

  1. string 自动内存，运算符直观
  2. cin 单词 / getline 整行；混用 ignore
  3. 核心：length、[]、substr(pos,len)、find→npos
  4. cctype 做分类与大小写转换
  5. find 循环统计；substr 拼接完成替换
  6. 新代码优先 string；旧题/C 接口再用 c_str
