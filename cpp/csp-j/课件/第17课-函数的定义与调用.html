函数的定义与调用

四要素 · 声明与定义 · 调用机制 · 返回值 · void · main · 设计原则

【开场】配套 lesson17。

一、为什么需要函数

  • 复用：写一次，多处调用
  • 模块化：大问题拆成小函数
  • 可维护：改一处，结构清晰
// 有了 isPrime 后 bool isPrime(int n) { if (n < 2) return false; for (int i=2; i*i<=n; i++) if (n%i==0) return false; return true; } cout << (isPrime(17) ? "YES" : "NO");
【讲解】对比无函数重复代码。

【讲解】形参实参细节第18课。

四要素细化：返回类型 · 命名 · 参数 · 体

int add(int a, int b) { return a+b; } bool isEven(int n) { return n%2==0; } void printHello() { cout << "Hello!"; } // 好命名：getMax / isPrime / printArray // 坏命名：f / check int factorial(int n) { int r=1; for (int i=1; i<=n; i++) r*=i; return r; }
注意：返回类型与 return 表达式应匹配；int 里 return 3.14 会截断。
【讲解】参数可无、一、多。

三、声明与定义分离

  • 声明（原型）：类型+名+参数，分号结尾，无函数体
  • 定义：完整实现
  • 编译器自上而下：先声明才能调用后面的定义
int add(int a, int b); // 声明 int main() { cout << add(3,5); return 0; } int add(int a, int b) { return a+b; } // 定义
推荐结构：文件头集中声明 → main → 底部集中定义（目录清晰）。
【讲解】声明忘分号是经典编译错。

四、函数调用机制（理解）

  1. 压栈：实参副本、返回地址入栈
  2. 跳转：执行函数体
  3. 执行：操作形参（默认是副本）
  4. 返回：return 值 → 回到调用点下一条
核心印象：值传递时，函数内改形参不影响外部实参（第18课详讲）。
【讲解】不必讲汇编，建立副本概念即可。

五、返回值的使用模式 · 六、void

cout << max2(10,20); // 直接用 int r = max2(10,20); // 赋值 if (isPrime(n)) ... // 条件 cout << max3(max2(a,b), c); // 嵌套 void greet(int hour) { if (hour < 6) { cout << "夜深"; return; } cout << "你好"; } // void 不能：int x = greet(1);
【讲解】void 的 return; 可提前退出。

七、main 的特殊地位 · 八、设计原则

  • 程序唯一入口；返回类型 int；0 表示正常结束
  • 不能被其他函数调用；可不写 return 0 但建议写
  • 单一职责：一函数一事；好命名 is/get/print
bool isPrime(...); long long factorial(...); int sumOfDigits(...); // 不要一个 process 又判素数又求阶乘又打印
【讲解】复赛模块化加分。

💻 代码模板（1）多函数组织

// 声明区 bool isPrime(int n); int max2(int a, int b); void printArray(int arr[], int n); int main() { cout << isPrime(17); cout << max2(10, 25); int a[]={1,3,5}; printArray(a,3); return 0; } // 定义区在 main 后
【讲解】模板一。

💻 代码模板（2）数字操作函数集

int sumOfDigits(int n) { int s=0; while (n>0) { s+=n%10; n/=10; } return s; } int reverseNumber(int n) { int r=0; while (n>0) { r=r*10+n%10; n/=10; } return r; } bool isPalindrome(int n) { return n == reverseNumber(n); }
【讲解】模板二；函数互相调用。

📝 真题精练

题1：统计 1~n 素数个数（必须写 isPrime）。样例 n=20 → 8

int cnt=0; for (int i=1; i<=n; i++) if (isPrime(i)) cnt++;

题2：完美数——除自身外因子和等于自身。6→YES，10→NO

int sumOfDivisors(int x) { ... sum 1..x/2 的因子; } bool isPerfect(int x) { return x==sumOfDivisors(x); }
【讲解】体现拆函数。

⚠ 易错点

易错说明
声明/定义类型不一致返回类型、参数类型数量须一致
非 void 忘记 return未定义行为；所有路径都要 return
声明漏分号编译器连环报错
void 写 return 0只能 return; 或不写
先调用后定义且无声明编译失败
【讲解】-Wall 可帮查。
