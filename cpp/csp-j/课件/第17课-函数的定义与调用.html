函数声明与定义的分离

为什么需要分离？

C++ 编译器从上到下编译。如果 main 调用了某个函数，但该函数定义在 main 之后，编译器会报错。解决方法就是把声明（原型）放在前面，定义放在后面。

// 声明：只写头部，以分号结尾（"预告"） int add(int a, int b); bool isPrime(int n); void printArray(int arr[], int n); // 定义：完整函数体（"实现"） int add(int a, int b) { return a + b; }
对比维度函数声明函数定义
是否包含函数体否，以分号结尾是，以花括号包裹
作用告知编译器函数存在提供函数的实际实现
可以出现次数多次（但不推荐）仅一次（唯一定义规则）
类比目录 / 预告正文 / 实现
最佳实践：将所有函数声明集中放在文件开头（#include 之后），将 main 函数放在中间，将所有函数定义放在 main 之后。这样代码结构清晰，阅读方便。
【讲解】函数声明与定义的分离 结合讲义《三、函数声明与定义的分离》强调： · 函数声明（也叫函数原型，Function Prototype）：只写出返回类型、函数名和参数列表，以分号结尾，不写函数体。 · 函数定义：写出完整的函数体。 · // 函数声明（原型）—— 只告诉编译器"有这样的函数" · int add(int a, int b); · // 函数定义 —— 告诉编译器"这个函数具体做什么" 幻灯片上可见要点： · C++ 编译器 从上到下 编译。如果 main 调用了某个函数，但该函数定义在 main 之后，编译器会报错。解决方法就是把 声明（原型） 放在前面， 定义 放在后面。 · 从上到下 · 声明（原型） · 最佳实践： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

函数调用机制

调用过程的四个步骤

  1. 压栈（Push）：将实参的值、返回地址（下一条指令的位置）压入调用栈。
  2. 跳转（Jump）：程序计数器跳转到被调用函数的第一条指令，开始执行函数体。
  3. 执行：在函数体内执行代码。形参获得实参的副本（这就是值传递的本质）。
  4. 返回（Return）：将返回值放入指定位置，弹出栈中保存的信息，跳回调用处继续执行。

关键理解

核心结论：函数调用时，形参获得的是实参的一个副本。函数内部对形参的修改，不会影响调用处的原始变量。这就是 C++ 默认的值传递机制。
void tryModify(int x) { x = 999; // 修改的是形参 x（实参的副本） } int main() { int a = 10; tryModify(a); cout << a; // 输出 10，a 没有被修改！ return 0; }
考点提醒：这是 CSP-J 的高频考点！很多同学初次接触时容易误认为函数内修改形参会同步影响实参。请牢记：默认情况下，形参和实参是两个独立的变量。
【讲解】函数调用机制 结合讲义《四、函数调用机制》强调： · 当程序执行到函数调用语句时，背后发生了一系列操作。了解这个过程有助于理解变量的作用域和参数传递。 · 压栈（Push）：将实参的值、当前函数的返回地址（即调用语句的下一条指令的地址）压入调用栈（Call Stack）。 · 跳转（Jump）：程序计数器跳转到被调用函数的入口地址，开始执行函数体。 · 执行：在函数体内执行代码，形参的值为实参压栈时的副本。 · 返回（Return）：执行到 return 语句时，将返回值存入指定位置（通常是寄存器），弹出调用栈中保存的信息，程序计数器跳回返回地址，继续执行调用函数的下一条语句。 幻灯片上可见要点： · 压栈（Push） ：将实参的值、返回地址（下一条指令的位置）压入调用栈。 · 压栈（Push） · 跳转（Jump） ：程序计数器跳转到被调用函数的第一条指令，开始执行函数体。 · 跳转（Jump） 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

代码模板：多函数组织

#include <iostream> using namespace std; // ===== 函数声明（原型） ===== bool isPrime(int n); int max2(int a, int b); int max3(int a, int b, int c); void printArray(int arr[], int n); // ===== 主函数 ===== int main() { cout << isPrime(17) << endl; cout << max3(10, 25, 18) << endl; int arr[] = {1, 3, 5, 7}; printArray(arr, 4); return 0; } // ===== 函数定义 ===== bool isPrime(int n) { if (n < 2) return false; for (int i = 2; i * i <= n; i++) if (n % i == 0) return false; return true; } int max2(int a, int b) { return a > b ? a : b; } int max3(int a, int b, int c) { return max2(max2(a, b), c); } void printArray(int arr[], int n) { for (int i = 0; i < n; i++) cout << arr[i] << " "; cout << endl; }
结构说明：声明 → main → 定义，这是 CSP-J 复赛中最推荐的程序组织方式。声明如同"目录"，让阅卷老师一眼看到你写了哪些函数。

真题精练

题目一：统计 1 到 n 的素数个数

给定正整数 n（1 ≤ n ≤ 100000），统计 1 到 n 之间的素数个数。要求使用 isPrime 函数。

bool isPrime(int x) { if (x < 2) return false; for (int i = 2; i * i <= x; i++) if (x % i == 0) return false; return true; } int main() { int n, cnt = 0; cin >> n; for (int i = 1; i <= n; i++) if (isPrime(i)) cnt++; cout << cnt << endl; return 0; }

题目二：完美数检测

判断 n 是否为完美数（等于除自身外所有正因子之和）。如 6 = 1+2+3。

bool isPerfect(int x) { if (x <= 1) return false; int sum = 0; for (int i = 1; i <= x / 2; i++) if (x % i == 0) sum += i; return sum == x; }
