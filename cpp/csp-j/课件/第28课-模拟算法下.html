一、游戏模拟：剪刀石头布

0 剪刀 1 石头 2 布；按固定序列周期出拳，模拟 N 轮比分。

for (int round = 0; round < N; round++) { int moveA = a[round % NA]; int moveB = b[round % NB]; if (moveA == moveB) continue; if ((moveA==0&&moveB==2) || (moveA==1&&moveB==0) || (moveA==2&&moveB==1)) scoreA++; else scoreB++; }
通用框架：定义状态 → 循环每轮 → index = round % len 实现周期序列 → 输出结果。
【讲解】取模=环形出拳序列。

二、约瑟夫环：队列模拟

n 人围圈，报 m 出列。例 n=7,m=3 → 3 6 2 7 5 1 4。

queue<int> q; for (int i = 1; i <= n; i++) q.push(i); int count = 0; while (!q.empty()) { count++; int person = q.front(); q.pop(); if (count == m) { cout << person << " "; count = 0; } else q.push(person); // 回队尾=继续留在圈中 }

复杂度 O(n·m)。n≤1000 足够。FIFO 天然模拟「转圈」。

【讲解】对照第24课队列应用。

三、约瑟夫：数学递推

求最后幸存者（编号从 0）：

f[1] = 0; f[i] = (f[i-1] + m) % i; // 实现： int survivor = 0; for (int i = 2; i <= n; i++) survivor = (survivor + m) % i; cout << survivor + 1; // 转 1-based
O(n)，适合 n 很大、只需幸存者时。要完整出列顺序仍用队列模拟。
【讲解】进阶了解即可，CSP-J 队列更常见。

四、高精度：大整数 × 普通整数

string multiply(string a, int b) { if (a == "0" || b == 0) return "0"; string result = ""; int carry = 0; for (int i = a.size()-1; i >= 0; i--) { int product = (a[i]-'0') * b + carry; result += char(product % 10 + '0'); carry = product / 10; } while (carry > 0) { result += char(carry % 10 + '0'); carry /= 10; } reverse(result.begin(), result.end()); return result; }

与加法不同

b 可能很大，最终 carry 可能 >9，必须用 while 拆多位进位。

【讲解】999×3 手推。

五、高精度：大 × 大

string multiply(string a, string b) { if (a=="0"||b=="0") return "0"; int n=a.size(), m=b.size(); vector<int> res(n+m, 0); reverse(a.begin(), a.end()); reverse(b.begin(), b.end()); for (int i=0; i<n; i++) for (int j=0; j<m; j++) res[i+j] += (a[i]-'0')*(b[j]-'0'); for (int i=0; i<n+m; i++) { if (res[i] >= 10) { res[i+1] += res[i]/10; res[i] %= 10; } } // 从高位跳前导零输出 }
核心：res[i+j] += da*db 即竖式「错位相加」。结果最多 n+m 位。
【讲解】先累加再统一进位。

六、进制：任意 → 十进制

按权展开 / 秦九韶：result = result * base + digit

int charToValue(char c) { if (c>='0'&&c<='9') return c-'0'; if (c>='A'&&c<='Z') return c-'A'+10; return c-'a'+10; } long long result = 0; for (char c : s) result = result * base + charToValue(c);
【讲解】FF₁₆=15*16+15=255。

七、进制：十进制 → 任意

除基取余：余数=低位，最后 reverse。

if (n == 0) { cout << 0; return; } string result = ""; while (n > 0) { result += valueToChar(n % base); n /= base; } reverse(result.begin(), result.end());
A 进制 → B 进制：先 toDecimal 再 fromDecimal，十进制作中转。
【讲解】n=0 特判。

十、易错点

1. 取模周期写错

用 length 不是 N；下标从 0 时 round%len。

2. 约瑟夫报数重置

出列后 count=0，从下一人重新报 1。

3. 高精度乘 0 / 前导零

特判 "0"；输出跳过高位 0。

4. 进制字符映射

A-Z 对应 10-35；大小写分别处理。

5. 除基取余忘记 reverse

先得低位，输出前必须反转。

【讲解】五条过一遍。

string ans = "1"; for (int i = 2; i <= 50; i++) ans = multiply(ans, i); // 大×小
