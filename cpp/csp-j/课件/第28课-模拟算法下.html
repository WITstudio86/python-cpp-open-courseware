一、约瑟夫环问题

1.1 问题描述

n 个人围成一圈，从第 1 个人开始报数，报到 m 的人出局。下一个人从 1 重新报数。重复此过程，直到所有人出局。求出局顺序或最后剩下的人。

1.2 队列模拟法

使用 queue（队列）模拟整个过程：

  • 将 1~n 依次入队
  • 每次将队头取出，计数 +1
  • 如果计数 == m，该人出局（不入队），计数器清零
  • 否则重新入队（排到末尾）
  • 直到队列为空
// 约瑟夫环 — 队列模拟 #include <queue> int n, m; cin >> n >> m; queue<int> q; for (int i = 1; i <= n; i++) q.push(i); int cnt = 0; while (!q.empty()) { cnt++; int x = q.front(); q.pop(); if (cnt == m) { cout << x << " "; // 出局 cnt = 0; } else { q.push(x); // 活下来，排到末尾 } }

1.3 数学递推法

如果只求最后存活者的编号，有 O(n) 递推公式：

f(1) = 0; f(i) = (f(i - 1) + m) % i

最终存活者为 f(n) + 1（从 0 编号转换为从 1 编号）。

💡 考试技巧：队列模拟法时间复杂度 O(nm)，适用于 n ≤ 10⁴。数学递推法 O(n)，适用于 n 非常大的情况。CSP-J 通常用队列模拟即可，但递推法更优雅。

二、高精度乘法

2.1 高精度乘普通整数

大整数 × 普通整数（在 int 范围内）：逐位相乘，处理进位。

// 大整数 a（string）× 普通整数 b → 结果 string string mul(string a, int b) { reverse(a.begin(), a.end()); string c; int carry = 0; for (int i = 0; i < a.size() || carry; i++) { int d = (i < a.size() ? a[i]-'0' : 0) * b + carry; c += char(d % 10 + '0'); carry = d / 10; } reverse(c.begin(), c.end()); return c; }

2.2 高精度乘高精度

两个大整数相乘：模拟竖式乘法。a[i] × b[j] 的结果加到 c[i+j] 中，最后统一处理进位。

string bigMul(string a, string b) { reverse(a.begin(), a.end()); reverse(b.begin(), b.end()); int c[2005] = {0}; // 结果数组，足够大 for (int i = 0; i < a.size(); i++) for (int j = 0; j < b.size(); j++) c[i+j] += (a[i]-'0') * (b[j]-'0'); int len = a.size() + b.size(); // 结果最大长度 for (int i = 0; i < len; i++) { c[i+1] += c[i] / 10; // 进位 c[i] %= 10; } // 转为字符串（去除前导零） string res; int start = len; while (start > 0 && c[start] == 0) start--; for (int i = start; i >= 0; i--) res += char(c[i] + '0'); return res; }
💡 考试技巧：高精度乘高精度的关键在于 c[i+j] += a[i] * b[j] 这个公式 — 竖式中 a 的第 i 位 × b 的第 j 位，结果贡献到结果的第 i+j 位。最后统一进位，比边乘边进位更简洁。

三、进制转换

3.1 任意进制转十进制

按权展开法：每一位的数字 × 该位的权值（baseposition）之和。

公式：D = dk-1 × Bk-1 + dk-2 × Bk-2 + ... + d0 × B0

// base 进制字符串 s → 十进制整数 int toDecimal(string s, int base) { int ans = 0; for (char c : s) { int digit; if (c >= '0' && c <= '9') digit = c - '0'; else digit = c - 'A' + 10; // 支持十六进制 ans = ans * base + digit; } return ans; }

3.2 十进制转任意进制

除基取余法：不断除以目标进制 base，将每次的余数记录下来，最后倒序排列。

// 十进制整数 n → base 进制字符串 string fromDecimal(int n, int base) { if (n == 0) return "0"; string ans; char digits[] = "0123456789ABCDEF"; while (n > 0) { ans += digits[n % base]; n /= base; } reverse(ans.begin(), ans.end()); return ans; }

四、文件操作 — freopen

4.1 为什么需要文件操作？

在 CSP-J 正式比赛中，输入输出通常是文件而非终端。例如题目可能要求从 sum.in 读取，输出到 sum.out。

4.2 freopen 基本用法

使用 freopen 重定向标准输入输出到文件，写在 main 函数最开头。

#include <cstdio> using namespace std; int main() { freopen("sum.in", "r", stdin); // 从文件读入 freopen("sum.out", "w", stdout); // 输出到文件 // ... 正常使用 cin/cout 或 scanf/printf ... fclose(stdin); fclose(stdout); return 0; }

4.3 关键注意事项

  • 读写模式："r" 只读（文件必须存在），"w" 只写（会覆盖），"a" 追加
  • freopen 之后，cin / scanf 从文件读取，cout / printf 写入文件
  • 本地调试时，如果文件不存在会导致程序崩溃。可以用条件编译切换：
// 条件编译：本地调试用终端，比赛用文件 #ifndef ONLINE_JUDGE // 本地调试：不重定向，使用终端 IO #else freopen("problem.in", "r", stdin); freopen("problem.out", "w", stdout); #endif
💡 考试技巧：freopen 的文件名必须和题目要求完全一致（包括大小写）！交卷前务必注释掉或删除 freopen 的调试版本，否则可能因文件不存在而得 0 分。建议用 #ifndef ONLINE_JUDGE 宏自动切换。

六、真题精练 — 高精度乘法

题目描述

求 2 的 n 次方（即计算 2n），其中 0 ≤ n ≤ 100。n=10 时 210=1024；n=100 时是一个 31 位数，int/long long 无法表示。

输入格式

一行，一个整数 n（0 ≤ n ≤ 100）。

输出格式

一行，2n 的精确值。

输入样例 1

10

输出样例 1

1024

输入样例 2

100

输出样例 2

1267650600228229401496703205376

解题思路

初始 ans = "1"，循环 n 次，每次将 ans × 2。即 高精度乘普通整数 的 n 次重复。

参考代码

#include <iostream> #include <algorithm> using namespace std; string mul2(string a) { reverse(a.begin(), a.end()); string ans; int carry = 0; for (int i = 0; i < a.size() || carry; i++) { int d = (i < a.size() ? a[i]-'0' : 0) * 2 + carry; ans += char(d % 10 + '0'); carry = d / 10; } reverse(ans.begin(), ans.end()); return ans; } int main() { int n; cin >> n; string ans = "1"; for (int i = 0; i < n; i++) ans = mul2(ans); cout << ans << endl; return 0; }
💡 考试技巧：高精度乘 2 是高精度乘单精度的特例。写一个通用的 mul(string a, int b) 函数更方便。CSP-J 中 2n 是经典题，n=100 时有 31 位，手写高精度是唯一方法。

七、本课小结

  1. 约瑟夫环：队列模拟法 O(nm) 直观易写；数学递推法 O(n) 求最后存活者：f(i) = (f(i-1) + m) % i
  2. 高精度乘法（大 × 普通）：逐位相乘 + 进位，反转-乘-反转三部曲
  3. 高精度乘法（大 × 大）：核心公式 c[i+j] += a[i] * b[j]，最后统一进位
  4. 进制转换：任意进制 → 十进制用"按权展开"；十进制 → 任意进制用"除基取余"
  5. freopen：比赛必需技能，用 freopen("in","r",stdin) 和 freopen("out","w",stdout) 重定向 IO
  6. 建议使用 #ifndef ONLINE_JUDGE 条件编译，本地调试用终端，比赛自动切换为文件 IO
