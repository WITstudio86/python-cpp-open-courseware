一、动态规划速通

三要素：状态 · 转移 · 边界。CSP-J 重中之重。

模型要点
01 背包容量倒序：dp[j]=max(dp[j], dp[j-v]+w)
完全背包容量正序
LISdp[i]=max(dp[j])+1（a[j]<a[i]），O(n²)
// 01 背包一维 for (int i = 1; i <= N; i++) { cin >> v >> w; for (int j = M; j >= v; j--) dp[j] = max(dp[j], dp[j - v] + w); }
01 与完全：内层方向写反 = 答案全错。口诀「01 倒」。
数字三角形、最大子段和也是线性 DP 常客。

二、搜索：DFS / BFS

  • DFS：全部方案、排列组合、连通块；回溯要撤销
  • BFS：无权最短步；入队即 vis
// 全排列骨架 if (depth == N) { /* 输出 path */ return; } for (i=1;i<=N;i++) if (!vis[i]) { vis[i]=1; path.push_back(i); dfs(depth+1); path.pop_back(); vis[i]=0; } // 迷宫最短：queue 存 {x,y,step}，四方向
最短步数必 BFS；枚举方案必 DFS。大深度慎用递归。
与第42/43课模板一致，考场直接套。

三、图论：最短路 & 并查集

Dijkstra（非负权）：堆优化 O((V+E)log V)

pq 小根堆 {dis, u}; while (!pq.empty()) { u = pq.top().second; pq.pop(); if (vis[u]) continue; vis[u] = true; for (邻边 v,w) if (dis[v] > dis[u]+w) { dis[v] = dis[u]+w; pq.push({dis[v], v}); } }

并查集：find 路径压缩 + unite；连通 / 朋友圈 / Kruskal。

出队判 vis 跳过已确定节点。

四、数论：质数 · GCD · LCM

  • 试除判质：2..√n，特判 n≤1
  • 埃氏筛 / 欧拉线性筛 O(n)
  • gcd(a,b)=gcd(b,a%b)；lcm=a/gcd*b（先除后乘防溢出）
void eulerSieve(int n) { fill(isPrime, isPrime+n+1, true); isPrime[0]=isPrime[1]=false; for (int i=2; i<=n; i++) { if (isPrime[i]) primes.push_back(i); for (int p : primes) { if (i*p > n) break; isPrime[i*p] = false; if (i % p == 0) break; } } }
i*p 注意溢出时用 1LL 或 i>n/p。

六、易错点集中营

  1. 01/完全循环方向混淆
  2. BFS 出队才标 vis → 重复入队
  3. Dijkstra 出队不跳过已 vis
  4. 判质数忘 n≤1；i*i 溢出
  5. DFS 深链栈溢出 → 改 BFS/并查集
  6. 无向图单向建边

七、真题1：采购方案 · 题意

题意：N 件商品，预算 M。每件价格 p、喜爱 v，每件最多买一次。求喜爱度最大。N≤100,M≤1000。

样例

4 10 2 3 3 4 4 5 5 6 → 最大喜爱 13（选 1+2+4：价 2+3+5，值 3+4+6）
标准 01 背包：体积=价格，价值=喜爱；内层 j 从 M 倒到 p。
讲义中曾有 11 的笔误，正确样例为 13。

采购方案 · 核心代码

const int MAXM = 1005; int dp[MAXM]; int main() { int N, M; cin >> N >> M; for (int i = 1; i <= N; i++) { int p, v; cin >> p >> v; for (int j = M; j >= p; j--) dp[j] = max(dp[j], dp[j - p] + v); } cout << dp[M] << endl; }
O(NM)=1e5，轻松。

八、真题2：逃离迷宫 · 题意

题意：N×M 网格，. 空 # 墙 S 起点 E 终点，最短步数，不可达 -1。N,M≤100。

样例 5×5 → 8

思路：扫矩阵找 S/E；BFS 四方向；入队标 vis；首次到 E 即最短。
S、E 视为可走。

逃离迷宫 · 核心代码

struct Node { int x, y, step; }; int bfs(int sx,int sy,int ex,int ey) { queue<Node> q; q.push({sx,sy,0}); vis[sx][sy]=true; while (!q.empty()) { Node c = q.front(); q.pop(); if (c.x==ex && c.y==ey) return c.step; for (int i=0;i<4;i++) { int nx=c.x+dx[i], ny=c.y+dy[i]; if (nx>=1&&nx<=n&&ny>=1&&ny<=m &&!vis[nx][ny]&&g[nx][ny]!='#') { vis[nx][ny]=true; q.push({nx,ny,c.step+1}); } } } return -1; }
边界与障碍顺序不能反。

九、综合小题思路（选做）

  • LIS：序列最长严格上升 → O(n²) DP
  • 全排列输出：n≤8 DFS 回溯
  • 单源最短路：非负权 Dijkstra；全 1 权 BFS
  • 朋友圈：并查集计数根
  • 第 k 个质数：欧拉筛预处理
读题先分类：背包？最短步？连通？质数？再选模板，别上来硬写。
分类比编码更重要。
