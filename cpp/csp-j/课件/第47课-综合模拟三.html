动态规划 — DP状态设计

01背包问题核心要点

状态定义 dp[j] 表示容量为 j 的背包能获得的最大价值。

状态转移 dp[j] = max(dp[j], dp[j - w[i]] + v[i])

// 01背包 — 一维DP优化模板
int dp[1005];  // 数组大小根据最大容量设定
for (int i = 1; i <= n; i++) {
    for (int j = V; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
cout << dp[V] << endl;

关键细节：

  • 内层循环必须倒序遍历（从 V 到 w[i]），保证每个物品只被选一次
  • 若正序遍历，会变成完全背包（物品可无限选）
  • 时间复杂度 O(nV)，空间复杂度 O(V)
⚠ 考试提醒：01背包必须倒序遍历容量！正序遍历是错误代码，会变成完全背包，丢分严重！
【讲解】动态规划 — DP状态设计 结合讲义《一、动态规划（DP）》强调： · 动态规划是CSP-J第二轮考查的重中之重。其核心思想是将原问题分解为若干子问题，通过求解子问题来递推出原问题的解。DP的三个关键要素是：状态定义、状态转移方程和边界条件。 · 01背包问题是最经典的DP模型。设有N件物品和一个容量为M的背包，第i件物品的体积为v[i]，价值为w[i]，每件物品只能选一次，求解将哪些物品装入背包可使总价值最大。我们定义dp[j]表示容量为j的背包能获得的最大价值，则状态转移方程为dp[j] = max(dp[j], dp[j - v[i]] + w[i])，其中j需要从M倒序枚举到v[i]，以保证每件物品只被考虑一次。这一维优化的技巧是01背包的重点——如果正序枚举j，就会退化成完全背包，即每件物品可以被无限次选择。时间复杂度O(NM)，空间复杂度O(M)。 · 线性DP是另一类高频考点，通常涉及一维或二维序列上的递推。以最长上升子序列（LIS）为例：给定一个长度为N的序列a[1..N]，求其中最长的严格递增子序列的长度。定义dp[i]表示以a[i]结尾的最长上升子序列长度，则dp[i] = max{ dp[j] + 1 | 1 <= j < i 且 a[j] < a[i] }，初始dp[i] = 1。朴素做法的时间复杂度为O(N^2)，对于N <= 1000的情况可以直接使用；对于更大规模的数据，可以用贪心+二分优化到O(N log N)。此外，最大子段和、编辑距离、数字三角形等经典模型也需要熟练掌握。 · // 01背包 一维优化模板 · using namespace std; 幻灯片上可见要点： · 状态定义 dp[j] 表示容量为 j 的背包能获得的最大价值。 · 状态转移 dp[j] = max(dp[j], dp[j - w[i]] + v[i]) · 关键细节： · 内层循环必须 倒序 遍历（从 V 到 w[i] ），保证每个物品只被选一次 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：编程题专项训练：DP+搜索+图论

搜索算法 — DFS与BFS

DFS（深度优先搜索）

  • 使用栈（递归实现）
  • 适合求所有解、连通性问题
  • 适合图/树的遍历与回溯
  • 经典应用：全排列、N皇后、迷宫路径
// DFS 递归模板
void dfs(int x) {
    if (/* 终止条件 */) {
        // 处理答案
        return;
    }
    vis[x] = 1;
    for (int nx : adj[x]) {
        if (!vis[nx])
            dfs(nx);
    }
}

BFS（广度优先搜索）

  • 使用队列（迭代实现）
  • 适合求最短路径（无权图）
  • 按层扩展，第一次到达即为最短
  • 经典应用：走迷宫最少步数、层次遍历
// BFS 队列模板
queue<int> q;
q.push(start);
vis[start] = 1;
dist[start] = 0;
while (!q.empty()) {
    int cur = q.front(); q.pop();
    for (int nx : adj[cur]) {
        if (!vis[nx]) {
            vis[nx] = 1;
            dist[nx] = dist[cur] + 1;
            q.push(nx);
        }
    }
}
⚠ 考试提醒：BFS求最短路时，第一次到达即为最短距离！不需要像DFS那样枚举所有路径后取min。无权图最短路用BFS，带权图用Dijkstra！
【讲解】搜索算法 — DFS与BFS 结合讲义《二、搜索（DFS与BFS）》强调： · 搜索是解决组合优化和状态空间探索问题的通用方法。深度优先搜索（DFS）沿着一条路径走到底再回溯，适合枚举所有方案、排列组合、连通块等问题；广度优先搜索（BFS）逐层扩展，适合求解最短步数、最少操作次数等无权图上的最短路径问题。 · DFS的核心框架为：设定递归终止条件 -> 枚举当前状态的所有合法扩展 -> 标记已访问 -> 递归进入下一层 -> 回溯撤销标记。在解决迷宫问题时，DFS可以找到一条通往终点的路径（不保证最短），而BFS可以找到最短路径。DFS使用系统栈实现递归，空间复杂度取决于递归深度，在极端情况下可能导致栈溢出，因此对于深度较大的问题（如N >= 10^5），需要使用迭代栈或改写为BFS。 · BFS使用队列（queue）实现，模板固定：将起点入队并标记已访问 -> 循环取出队首元素 -> 枚举所有相邻状态 -> 若未访问则入队并标记。BFS的一个关键特性是"首次访问即最短"，只要边的权值均匀（单位长度），第一次到达某个状态时走过的步数就是最短步数。如果边权不同（有权图），则需要用Dijkstra或SPFA等最短路算法。 · DFS和BFS的选择原则：求所有方案用DFS，求最短路径（无权）用BFS，求连通性两者皆可。剪枝是DFS中的关键技术——在搜索过程中，如果发现当前分支不可能产生比已有最优解更好的结果，就可以提前返回（可行性剪枝、最优性剪枝），大幅减少搜索量。 · // BFS 迷宫最短路径模板 幻灯片上可见要点： · 使用 栈 （递归实现） · 适合求 所有解 、连通性问题 · 适合图/树的 遍历与回溯 · 遍历与回溯 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

图论 — 最短路径与连通性

Dijkstra 堆优化

使用 priority_queue（小根堆），每次取出距离最小的节点进行松弛操作。

// Dijkstra 堆优化模板 O((V+E)logV)
#include <queue>
using namespace std;

const int INF = 1e9;
vector<pair<int,int>> G[100005];
int dist[100005];

void dijkstra(int s) {
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
    fill(dist, dist + n + 1, INF);
    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : G[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
}

并查集 (Union-Find) 快速模板

int fa[100005];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
void merge(int a, int b) { fa[find(a)] = find(b); }
⚠ 考试提醒：Dijkstra不能处理负权边，遇到负权用SPFA！并查集记得初始化 fa[i] = i，并带上路径压缩！
【讲解】图论 — 最短路径与连通性 结合讲义《三、图论（最短路径与连通性）》强调： · 图论是算法竞赛中的重要板块，CSP-J阶段主要考查图的存储、最短路径算法和连通性判定。图的存储有两种基本方式：邻接矩阵（适用于稠密图，空间O(V^2)）和邻接表（适用于稀疏图，空间O(V+E)）。在CSP-J的实际题目中，大部分图的边数不超过10^5级别，因此通常使用邻接表（vector>）存储。 · Dijkstra算法是求解非负权图单源最短路径的经典算法。其核心思想是贪心：每次从未确定最短距离的点中选出距离起点最近的点，用它的距离去松弛其所有邻接点的距离。朴素实现的复杂度为O(V^2)，适用于V , vector>, greater>>实现小根堆，pair的first存储距离、second存储节点编号。Dijkstra不能处理负权边，遇到负权边需要使用SPFA或Bellman-Ford算法（但CSP-J通常不考查负权边）。 · 连通性问题通常使用并查集（Disjoint Set Union, DSU）解决。并查集支持两种基本操作：find(x)查找元素x所在集合的代表元（带路径压缩），union(x, y)合并两个集合（按秩合并）。路径压缩使find的均摊复杂度接近O(1)，总复杂度为O(alpha(N))，其中alpha是阿克曼函数的反函数，在实际数据范围内可以视为常数。并查集常用于判断无向图中两点是否连通、检测图中的环、求解最小生成树（Kruskal算法）等。 · // Dijkstra + 邻接表 + 优先队列优化 · using namespace std; 幻灯片上可见要点： · 使用 priority_queue （小根堆），每次取出距离最小的节点进行松弛操作。 · ⚠ 考试提醒： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

数论 — 质数与GCD

埃拉托色尼筛法 (Sieve of Eratosthenes)

// 埃筛 O(n log log n) — 简单实用
bool isPrime[1000005];
void sieve(int n) {
    memset(isPrime, 1, sizeof(isPrime));
    isPrime[0] = isPrime[1] = 0;
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i)
                isPrime[j] = 0;
        }
    }
}

欧几里得算法 (GCD) + 快速幂

// 辗转相除法求最大公约数
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }

// 快速幂 a^b mod MOD (O(log b))
long long qpow(long long a, long long b, long long mod) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
⚠ 考试提醒：筛法数组大小至少开到 n+1（甚至 n+5 防溢出），快速幂注意开 long long 防止中间乘法溢出！

欧拉筛（线性筛）优化点：每个合数只被其最小质因子筛掉，时间复杂度 O(n)，适合 n ≥ 10^7 的场景。

【讲解】数论 — 质数与GCD 结合讲义《四、数论（质数与最大公约数）》强调： · 数论在CSP-J中主要围绕质数判定、质数筛法和最大公约数展开。质数是大于1的自然数中，除了1和它本身之外没有其他因数的数。判断一个数N是否为质数的最简单方法是试除法：枚举2到sqrt(N)之间的所有整数，若存在某个数能整除N，则N不是质数。时间复杂度O(sqrt(N))，适用于单次判定。 · 当需要批量获取一定范围内的所有质数时，需要使用筛法。埃拉托斯特尼筛法（埃氏筛）是最直观的筛法：初始化一个布尔数组isPrime，全部设为true；从2开始，若isPrime[i]为true，则将i的所有倍数标记为false。时间复杂度O(N log log N)，空间复杂度O(N)。欧拉筛（线性筛）进一步优化到O(N)：每个合数只被其最小的质因数筛掉一次。欧拉筛的核心在于内层循环判断 i % primes[j] == 0 时跳出，它保证了每个合数只被筛一次，在N达到10^7时可以显著减少常数。 · 最大公约数（GCD）使用辗转相除法（欧几里得算法）：gcd(a, b) = gcd(b, a % b)，当b == 0时返回a。最小公倍数（LCM）通过公式 lcm(a, b) = a / gcd(a, b) * b 计算（注意先除后乘防止溢出）。对于三个及以上数字的GCD或LCM，可以利用GCD和LCM的结合律逐次计算。 · // 欧拉线性筛 + GCD/LCM · using namespace std; 幻灯片上可见要点： · ⚠ 考试提醒： · 欧拉筛（线性筛） 优化点：每个合数只被其最小质因子筛掉，时间复杂度 O(n) ，适合 n ≥ 10^7 的场景。 · 欧拉筛（线性筛） 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

综合例题 — 采药问题

📋 题目描述（洛谷 P1048 / NOIP2005 普及组）

辰辰是个天资聪颖的孩子，他的梦想是成为世界上最伟大的医师。为此，他想拜附近最有威望的医师为师。

医师给他出了一道难题：山洞里有一些不同的草药，采每一株都需要一些时间，每一株也有它自身的价值。在总时间 T 内，辰辰应该采哪些草药才能让总价值最大？

输入格式：第一行两个整数 T（总时间）和 M（草药数目）。接下来 M 行，每行两个整数 t_i（采摘时间）和 v_i（价值）。
输出：一个整数，表示最大总价值。

解题思路

  1. 这是一个标准的01背包问题：背包容量 = 总时间 T，物品重量 = 采摘时间 t_i，物品价值 = v_i
  2. 使用一维DP优化：dp[j] 表示时间 j 内获得的最大价值
  3. 外层循环遍历每一株草药，内层循环倒序更新 dp 数组
  4. 答案即为 dp[T]
// 采药 — 完整AC代码
#include <iostream>
using namespace std;

int dp[1005];  // dp[j]: 时间j内最大价值
int t[105], v[105];

int main() {
    int T, M;
    cin >> T >> M;
    for (int i = 1; i <= M; i++)
        cin >> t[i] >> v[i];

    for (int i = 1; i <= M; i++)
        for (int j = T; j >= t[i]; j--)
            dp[j] = max(dp[j], dp[j - t[i]] + v[i]);

    cout << dp[T] << endl;
    return 0;
}

📌 变体思考：如果每种草药可以采无限次（完全背包），只需将内层循环改为正序即可。
