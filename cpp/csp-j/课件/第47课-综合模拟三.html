动态规划 — DP状态设计

01背包问题核心要点

状态定义 dp[j] 表示容量为 j 的背包能获得的最大价值。

状态转移 dp[j] = max(dp[j], dp[j - w[i]] + v[i])

// 01背包 — 一维DP优化模板
int dp[1005];  // 数组大小根据最大容量设定
for (int i = 1; i <= n; i++) {
    for (int j = V; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
cout << dp[V] << endl;

关键细节：

  • 内层循环必须倒序遍历（从 V 到 w[i]），保证每个物品只被选一次
  • 若正序遍历，会变成完全背包（物品可无限选）
  • 时间复杂度 O(nV)，空间复杂度 O(V)
⚠ 考试提醒：01背包必须倒序遍历容量！正序遍历是错误代码，会变成完全背包，丢分严重！

搜索算法 — DFS与BFS

DFS（深度优先搜索）

  • 使用栈（递归实现）
  • 适合求所有解、连通性问题
  • 适合图/树的遍历与回溯
  • 经典应用：全排列、N皇后、迷宫路径
// DFS 递归模板
void dfs(int x) {
    if (/* 终止条件 */) {
        // 处理答案
        return;
    }
    vis[x] = 1;
    for (int nx : adj[x]) {
        if (!vis[nx])
            dfs(nx);
    }
}

BFS（广度优先搜索）

  • 使用队列（迭代实现）
  • 适合求最短路径（无权图）
  • 按层扩展，第一次到达即为最短
  • 经典应用：走迷宫最少步数、层次遍历
// BFS 队列模板
queue<int> q;
q.push(start);
vis[start] = 1;
dist[start] = 0;
while (!q.empty()) {
    int cur = q.front(); q.pop();
    for (int nx : adj[cur]) {
        if (!vis[nx]) {
            vis[nx] = 1;
            dist[nx] = dist[cur] + 1;
            q.push(nx);
        }
    }
}
⚠ 考试提醒：BFS求最短路时，第一次到达即为最短距离！不需要像DFS那样枚举所有路径后取min。无权图最短路用BFS，带权图用Dijkstra！

图论 — 最短路径与连通性

Dijkstra 堆优化

使用 priority_queue（小根堆），每次取出距离最小的节点进行松弛操作。

// Dijkstra 堆优化模板 O((V+E)logV)
#include <queue>
using namespace std;

const int INF = 1e9;
vector<pair<int,int>> G[100005];
int dist[100005];

void dijkstra(int s) {
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
    fill(dist, dist + n + 1, INF);
    dist[s] = 0;
    pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : G[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
}

并查集 (Union-Find) 快速模板

int fa[100005];
int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
void merge(int a, int b) { fa[find(a)] = find(b); }
⚠ 考试提醒：Dijkstra不能处理负权边，遇到负权用SPFA！并查集记得初始化 fa[i] = i，并带上路径压缩！

数论 — 质数与GCD

埃拉托色尼筛法 (Sieve of Eratosthenes)

// 埃筛 O(n log log n) — 简单实用
bool isPrime[1000005];
void sieve(int n) {
    memset(isPrime, 1, sizeof(isPrime));
    isPrime[0] = isPrime[1] = 0;
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i)
                isPrime[j] = 0;
        }
    }
}

欧几里得算法 (GCD) + 快速幂

// 辗转相除法求最大公约数
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }

// 快速幂 a^b mod MOD (O(log b))
long long qpow(long long a, long long b, long long mod) {
    long long res = 1;
    while (b) {
        if (b & 1) res = res * a % mod;
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}
⚠ 考试提醒：筛法数组大小至少开到 n+1（甚至 n+5 防溢出），快速幂注意开 long long 防止中间乘法溢出！

欧拉筛（线性筛）优化点：每个合数只被其最小质因子筛掉，时间复杂度 O(n)，适合 n ≥ 10^7 的场景。

综合例题 — 采药问题

📋 题目描述（洛谷 P1048 / NOIP2005 普及组）

辰辰是个天资聪颖的孩子，他的梦想是成为世界上最伟大的医师。为此，他想拜附近最有威望的医师为师。

医师给他出了一道难题：山洞里有一些不同的草药，采每一株都需要一些时间，每一株也有它自身的价值。在总时间 T 内，辰辰应该采哪些草药才能让总价值最大？

输入格式：第一行两个整数 T（总时间）和 M（草药数目）。接下来 M 行，每行两个整数 t_i（采摘时间）和 v_i（价值）。
输出：一个整数，表示最大总价值。

解题思路

  1. 这是一个标准的01背包问题：背包容量 = 总时间 T，物品重量 = 采摘时间 t_i，物品价值 = v_i
  2. 使用一维DP优化：dp[j] 表示时间 j 内获得的最大价值
  3. 外层循环遍历每一株草药，内层循环倒序更新 dp 数组
  4. 答案即为 dp[T]
// 采药 — 完整AC代码
#include <iostream>
using namespace std;

int dp[1005];  // dp[j]: 时间j内最大价值
int t[105], v[105];

int main() {
    int T, M;
    cin >> T >> M;
    for (int i = 1; i <= M; i++)
        cin >> t[i] >> v[i];

    for (int i = 1; i <= M; i++)
        for (int j = T; j >= t[i]; j--)
            dp[j] = max(dp[j], dp[j - t[i]] + v[i]);

    cout << dp[T] << endl;
    return 0;
}

📌 变体思考：如果每种草药可以采无限次（完全背包），只需将内层循环改为正序即可。
