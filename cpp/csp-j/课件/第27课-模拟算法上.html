一、模拟算法思想

1.1 什么是模拟算法？

模拟算法就是"题目怎么说，代码就怎么写"。将题目中的规则和过程用代码一步步还原，让计算机按照规则执行。

  • 模拟 = 把现实问题的过程翻译为程序的执行流程
  • 模拟不需要高深的数学推导，关键是细心和严谨
  • CSP-J 中模拟题占比可达 30% 以上，是必考题型

1.2 两类模拟

类型特征典型例题
过程模拟按时间线一步步执行特定操作日期计算、约瑟夫环、游戏模拟
状态模拟根据规则更新状态，直到达到某种条件高精度运算、进制转换、矩阵变换

1.3 适用题型

  • 题目描述了一个明确的逐步操作流程
  • 数据范围较小，不涉及复杂优化
  • "阅读理解型"题目：题目较长，但逻辑清晰
  • 数学计算类：大整数、日期、进制
💡 考试技巧：模拟题的核心是准确理解题意。建议：① 先手动模拟小样例；② 注意边界条件；③ 善用函数拆分复杂逻辑；④ 正确率优先于速度，模拟题通常没有超时风险。

二、日期计算

2.1 闰年判断

闰年满足：① 能被 400 整除；或 ② 能被 4 整除但不能被 100 整除。

bool isLeap(int year) { return (year % 400 == 0) || (year % 4 == 0 && year % 100 != 0); }

2.2 月份天数

每月天数口诀："一三五七八十腊，三十一天永不差；四六九冬三十天，平年二月二十八，闰年二月二十九。"

int daysInMonth[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31}; int getDays(int year, int month) { if (month == 2 && isLeap(year)) return 29; return daysInMonth[month]; }

2.3 日期差计算

计算两个日期的间隔天数：

  1. 定义一个"起点日期"（如公元 1 年 1 月 1 日）
  2. 分别计算两个日期距离起点的绝对天数
  3. 两数相减得到结果
int daysFromStart(int y, int m, int d) { int days = 0; for (int i = 1; i < y; i++) days += isLeap(i) ? 366 : 365; for (int i = 1; i < m; i++) days += getDays(y, i); days += d; return days; }

三、高精度加法 — 竖式模拟

3.1 问题背景

当整数超出 long long 的范围（约 9 × 10¹⁸）时，需要手动模拟竖式加法。使用字符串读入，数组存储每一位。

3.2 竖式模拟原理

模拟小学竖式加法：从最低位开始逐位相加，处理进位。

  1. 将两个数的每一位存入数组（低位在前，即个位在 a[0]）
  2. 从低位到高位逐位相加：c[i] = a[i] + b[i] + carry
  3. carry = c[i] / 10，c[i] %= 10（保留个位）
  4. 最后若 carry > 0，需额外加一个进位

3.3 核心代码

string bigAdd(string s1, string s2) { // 反转，使低位在索引 0 reverse(s1.begin(), s1.end()); reverse(s2.begin(), s2.end()); string result; int carry = 0, i = 0; while (i < s1.size() || i < s2.size() || carry) { int d1 = (i < s1.size()) ? s1[i] - '0' : 0; int d2 = (i < s2.size()) ? s2[i] - '0' : 0; int sum = d1 + d2 + carry; result += (char)(sum % 10 + '0'); carry = sum / 10; i++; } reverse(result.begin(), result.end()); return result; }
💡 考试技巧：高精度加法的核心是 反转字符串 + 逐位相加 + 进位处理。特别注意 while 条件中要带上 || carry，否则最高位进位会丢失。输入时用 string 而非 int。

五、代码模板汇总

5.1 闰年判断模板

bool isLeap(int y) { return y % 400 == 0 || (y % 4 == 0 && y % 100 != 0); }

5.2 日期计算模板

int mdays[13] = {0,31,28,31,30,31,30,31,31,30,31,30,31}; int totalDays(int y, int m, int d) { int ans = 0; for (int i = 1; i < y; i++) ans += isLeap(i) ? 366 : 365; for (int i = 1; i < m; i++) { ans += mdays[i]; if (i == 2 && isLeap(y)) ans++; } ans += d; return ans; } // 日期差 = totalDays(y2,m2,d2) - totalDays(y1,m1,d1)

5.3 高精度加法模板

// 反转 + 逐位加 + 进位 string add(string a, string b) { reverse(a.begin(), a.end()); reverse(b.begin(), b.end()); string c; int carry = 0; for (int i = 0; i < max(a.size(), b.size()) || carry; i++) { int da = i < a.size() ? a[i]-'0' : 0; int db = i < b.size() ? b[i]-'0' : 0; int s = da + db + carry; c += char(s % 10 + '0'); carry = s / 10; } reverse(c.begin(), c.end()); return c; }

六、真题精练 — 日期差值计算

题目描述

给定两个日期，计算它们之间相差的天数。日期格式为 YYYYMMDD。（日期范围：1 年 1 月 1 日 ~ 9999 年 12 月 31 日，两个日期可能先后顺序不定）

输入格式

两行，每行一个 8 位整数（YYYYMMDD），分别表示两个日期。

输出格式

一个整数，表示两个日期相差的天数（绝对值）。

输入样例

20240101 20231225

输出样例

7

参考代码

#include <iostream> #include <cmath> using namespace std; int mdays[13] = {0,31,28,31,30,31,30,31,31,30,31,30,31}; bool leap(int y) { return y%400==0 || (y%4==0 && y%100!=0); } int calc(int y, int m, int d) { int ans = 0; for (int i=1; i<y; i++) ans += leap(i)?366:365; for (int i=1; i<m; i++) { ans += mdays[i]; if (i==2 && leap(y)) ans++; } ans += d; return ans; } int main() { int a, b; cin >> a >> b; int y1=a/10000, m1=a/100%100, d1=a%100; int y2=b/10000, m2=b/100%100, d2=b%100; cout << abs(calc(y1,m1,d1) - calc(y2,m2,d2)) << endl; return 0; }

七、本课小结

  1. 模拟算法的本质：照题目规则编写代码，不需要高级数学技巧，但需要细心和严谨
  2. 模拟题在 CSP-J 中占比高（约 30%），通常没有超时风险，正确率优先
  3. 闰年判断公式：(year % 400 == 0) || (year % 4 == 0 && year % 100 != 0)
  4. 日期差计算的核心思路：先算绝对天数，再相减取绝对值。注意闰年二月单独处理
  5. 高精度加法三部曲：① 反转字符串（低位在前）；② 逐位相加 + 进位；③ 反转结果（恢复高位在前）
  6. 做模拟题时，建议先在纸上手动模拟小样例，验证理解是否正确，再动手编码

模拟无他，唯手熟尔 — 多做练习，培养"翻译规则为代码"的能力。
