模拟题代码可能很长，但分步写、样例手算对照，往往比「想巧解」更稳拿分。

一、过程模拟：数字反转

int n; cin >> n; int sign = 1; if (n < 0) { sign = -1; n = -n; } int reversed = 0; while (n > 0) { int digit = n % 10; reversed = reversed * 10 + digit; n /= 10; } cout << sign * reversed << endl;

模拟「取最低位 → 追加到结果」。状态：reversed=已反转，n=剩余。

约分：模拟辗转相除

while (denominator != 0) { int temp = denominator; denominator = numerator % denominator; numerator = temp; } int g = numerator; // gcd cout << a/g << "/" << b/g << endl;
【讲解】过程模拟=手工步骤的程序化。

二、状态模拟：开关灯

n 盏灯初关；第 i 人翻转编号为 i 倍数的灯。输出最终开着的灯。

bool lights[5005] = {false}; for (int i = 1; i <= n; i++) for (int j = i; j <= n; j += i) lights[j] = !lights[j]; for (int i = 1; i <= n; i++) if (lights[i]) cout << i << " ";
框架：初始化状态 → 对每个时刻/指令更新 → 输出。若同一轮既读旧状态又写新状态，常用双数组暂存。

数学彩蛋

最后开着的恰是完全平方数编号的灯（因子成对，平方数多一个因子）。模拟仍是最稳写法。

【讲解】状态数组 lights[] 映射现实。

三、日期计算：闰年与月天数

bool isLeap(int year) { return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0); } int daysInMonth[13] = {0,31,28,31,30,31,30, 31,31,30,31,30,31}; int getDays(int y, int m) { if (m == 2 && isLeap(y)) return 29; return daysInMonth[m]; }
  • 数组下标从 1 开始，[0] 占位
  • 1900 非闰，2000 是闰——用 %400 覆盖世纪年
【讲解】默写 isLeap 是硬要求。

四、日期差：换算总天数

int totalDays(int year, int month, int day) { int total = 0; for (int y = 1; y < year; y++) total += isLeap(y) ? 366 : 365; for (int m = 1; m < month; m++) total += getDays(year, m); total += day; return total; } // 两日期差（含起止） cout << abs(totalDays(y2,m2,d2) - totalDays(y1,m1,d1)) + 1;

易错

  • 2 月闰年 +1 天别忘
  • 是否 +1 含起始日要读题
  • 年份范围过大时注意效率（可优化但 CSP-J 通常够）
【讲解】统一基准日再相减。

五、高精度加法原理

超过 long long（~10¹⁸）时用字符串竖式加法。

  1. 从最低位（串末）逐位相加
  2. 维护进位 carry
  3. 当前位 = (da+db+carry)%10，新 carry=(da+db+carry)/10
  4. 处理完后若仍有 carry，补最高位
  5. 结果逆序（或边算边拼前）
字符转数字：a[i]-'0'；数字转字符：char(d+'0')。sum 最大 9+9+1=19，carry 仅 0/1。
【讲解】先在黑板竖式 999+1。

六、高精度加法完整代码

string add(string a, string b) { string res = ""; int carry = 0; int i = a.size() - 1, j = b.size() - 1; while (i >= 0 || j >= 0 || carry) { int da = (i >= 0) ? a[i] - '0' : 0; int db = (j >= 0) ? b[j] - '0' : 0; int sum = da + db + carry; res += char(sum % 10 + '0'); carry = sum / 10; i--; j--; } reverse(res.begin(), res.end()); return res; }

另一种写法：先补前导零对齐，结果用 char(...) + res 拼在前面，可省 reverse。

【讲解】对照程序演示。

八、易错点

1. 闰年公式漏世纪年

只写 %4 会把 1900 当闰年。必须 (y%4==0 && y%100!=0) || y%400==0。

2. 月份数组 off-by-one

下标从 1；2 月在闰年单独 return 29。

3. 高精度忘记最后进位

循环条件要含 || carry，否则 999+1=000 错成 000。

4. 字符与数字混淆

'5'+'3' 不是 8；必须 -'0' 再算。

5. 同轮读写状态互相污染

需要时用新旧两个数组。

【讲解】高精度进位最常忘。

九、真题风格①：日期相关

给定两个日期，求相差天数（含首尾）。

输入：2020 1 1 / 2020 1 3
输出：3
套路：totalDays 两次相减 +1。注意 2 月 29 与跨年累加。
cout << abs(totalDays(y2,m2,d2) - totalDays(y1,m1,d1)) + 1 << endl;
【练习】手算 2020-2-28 到 2020-3-1。

十、真题风格②：大整数加法

输入：12345678901234567890
　　　98765432109876543210
输出：111111111011111111100

直接套 add(a,b)。注意：输入用 string，不要 cin 到 long long。

调试建议

先测 9+1、99+1、999+1、0+0，确认进位与前导。

【练习】当堂写 add 函数骨架。
