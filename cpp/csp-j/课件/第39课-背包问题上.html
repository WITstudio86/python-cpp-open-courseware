一、背包问题概述

基本模型

给定 N 件物品，每件有重量 w[i] 和价值 v[i]，背包容量为 W。求在总重量不超过 W 的前提下，总价值最大的选择方案。

三大分类

类型物品选择次数典型场景
01背包每个最多选1次采药、装箱、选课
完全背包每个可选无限次货币系统、找零钱
多重背包每个有数量上限c[i]物品有库存

本课重点：01背包 和 完全背包

01背包是DP的入门经典，搞懂遍历方向原理（正序 vs 倒序），后续所有背包变种都能轻松应对！

二、01背包 — 状态与转移

状态定义

dp[i][j] = 前 i 件物品，背包容量为 j 时能获得的最大价值

答案就是 dp[N][W]

状态转移方程

对于第 i 件物品，两种选择：

  • 不选：dp[i][j] = dp[i-1][j]
  • 选（前提 j ≥ w[i]）：dp[i][j] = dp[i-1][j-w[i]] + v[i]

dp[i][j] = max( dp[i-1][j] , dp[i-1][j-w[i]] + v[i] )

二维DP代码

for (int i = 1; i <= N; i++) { for (int j = 0; j <= W; j++) { dp[i][j] = dp[i-1][j]; if (j >= w[i]) dp[i][j] = max(dp[i][j], dp[i-1][j-w[i]] + v[i]); } }
关键细节：选第i件时用 dp[i-1][j-w[i]]（上一行！），不是 dp[i][j-w[i]]。这保证了每件物品只选一次。

三、01背包 — 一维优化与倒序原理

为什么可以优化为一维？

dp[i][j] 只依赖于 dp[i-1] 行，更早的行不再需要。可以用一维数组 dp[j] 滚动更新。

一维DP代码

for (int i = 1; i <= N; i++) { for (int j = W; j >= w[i]; j--) { // 必须倒序！ dp[j] = max(dp[j], dp[j-w[i]] + v[i]); } }

为什么必须倒序遍历？

正序遍历的问题：当 j 从小往大遍历时，dp[j-w[i]] 可能已被本轮更新过（已包含物品i），导致物品i被使用多次，变成完全背包！

倒序遍历的保证：计算 dp[j] 时，dp[j-w[i]] 还未被本轮更新，保存的仍是上一轮（前 i-1 件物品）的结果，因此物品i不会被重复使用。

零一倒着走，完全正着走

四、初始化细节 — 90%新手的坑！

两种初始化方式

需求初始化方式含义
求最大价值
（可以不满）		 dp[0..W] = 0 容量j未计算时默认为0，允许不装满背包
求恰好装满
的最大价值		 dp[0] = 0
dp[1..W] = -INF		 只有dp[0]可达，其他初始-INF表示"不可达"，必须恰好装满

恰好装满の代码模板

const int INF = 0x3f3f3f3f; vector<int> dp(W + 1, -INF); dp[0] = 0; // 容量0，恰好装满，价值0 for (int i = 1; i <= N; i++) for (int j = W; j >= w[i]; j--) if (dp[j - w[i]] != -INF) // 前驱必须可达 dp[j] = max(dp[j], dp[j - w[i]] + v[i]); if (dp[W] < 0) cout << "无法恰好装满";
易错：如果题目说"可以不满"，用0初始化就够了。不要无缘无故加-INF，否则会丢分！

五、完全背包 — 正序遍历

问题定义

与01背包唯一区别：每种物品可以选无限次。

二维转移方程（与01的区别）

类型选第i件的转移
01背包dp[i-1][j-w[i]] + v[i]（上一行）
完全背包dp[i][j-w[i]] + v[i]（同一行！）

一维实现：正序遍历

for (int i = 1; i <= N; i++) { for (int j = w[i]; j <= W; j++) { // 正序！ dp[j] = max(dp[j], dp[j-w[i]] + v[i]); } }

正序遍历的原理

正序遍历时，dp[j-w[i]] 可能已经被本轮更新过（已包含物品i），所以物品i可以被反复使用——这正是"无限次"的含义！

完全背包的正序遍历本质上是在对同一个物品反复尝试：先算放1个，再算放2个，再算放3个……直到容量不够为止。

七、真题1：采药（01背包模板）

题目描述

山洞里有 N 株草药，采第 i 株需要时间 T[i]，价值 V[i]。在总时间 M 内采到价值总和最大的草药。每株只能采一次。

1 ≤ N ≤ 100, 1 ≤ M ≤ 1000

样例

输入：70 3（时间70，3株药）
药1：时间71 价值100
药2：时间69 价值1
药3：时间1 价值2

输出：3（采药2和药3：时间69+1 ≤ 70，价值1+2=3）

AC代码

#include <iostream> #include <algorithm> using namespace std; int dp[1005], t[105], v[105]; int main() { int M, N; cin >> M >> N; for (int i = 1; i <= N; i++) cin >> t[i] >> v[i]; for (int i = 1; i <= N; i++) for (int j = M; j >= t[i]; j--) // 倒序！ dp[j] = max(dp[j], dp[j - t[i]] + v[i]); cout << dp[M] << endl; return 0; }
这道题是NOIP 2005 普及组原题，经典01背包模板。记住：时间 = 重量，价值 = 价值，每株药 = 每个物品只能采一次 → 01背包，倒序遍历！

八、真题2：货币系统（完全背包）

题目描述

给定 n 种面值的货币，求组成面值 m 的方案数。每种货币可以用任意多次。

1 ≤ n ≤ 25, 1 ≤ m ≤ 10000

样例

输入：3 10（3种面值，组成10）
面值：1 2 5

输出：10（共有10种方案）

AC代码

#include <iostream> using namespace std; long long dp[10005]; // 方案数可能很大！ int a[30]; int main() { int n, m; cin >> n >> m; for (int i = 1; i <= n; i++) cin >> a[i]; dp[0] = 1; // 组成0元：什么都不选，1种方案 for (int i = 1; i <= n; i++) for (int j = a[i]; j <= m; j++) // 正序！完全背包 dp[j] += dp[j - a[i]]; cout << dp[m] << endl; return 0; }
注意：求方案数时转移用 += 而非 max！dp[0]要初始化为1（表示"什么都不选"是一种方案）。另外要用 long long，方案数可能超出int范围！

九、易错点汇总

三大常见错误

❌ 错误1：01背包正序遍历

忘记倒序，写成 for (j = w[i]; j <= W; j++)，导致物品被重复使用，01背包变成完全背包。这是最高频错误。

❌ 错误2：循环边界写错

01背包：j >= 0 会访问 dp[j-w[i]] 时j-w[i]可能为负。
正确写法：j >= w[i]。

❌ 错误3：初始化混淆

题目要求正确初始化常见错误
求最大价值（可以不满）dp全0用了-INF → 结果偏小
恰好装满dp[0]=0, 余=-INF用了全0 → 可能输出非法状态
零一倒着走，完全正着走

把这句话背熟，考场上绝不会搞混遍历方向！
