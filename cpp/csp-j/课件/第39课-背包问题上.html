【开场】1/14 背包是 CSP-J DP 必考模型。口诀：零一倒着走，完全正着走。

一、背包问题概述

若干物品有代价 w、收益 v；容量上限 W。总代价 ≤W 时收益最大（或方案数等）。

类型可选次数本课
01 背包最多 1 次✅
完全背包无限次✅
多重背包最多 c[i]第40课
  • 做题三问：容量是什么？代价/收益是什么？能选几次？
  • 映射：时间→容量，采药耗时→w，价值→v
【讲解】抽象映射

二、01 背包 — 状态与转移

dp[i][j] = 只考虑前 i 件、容量 j 时的最大价值。答案 dp[N][W]。

  • 不选：dp[i][j] = dp[i-1][j]
  • 选（j≥w[i]）：dp[i-1][j-w[i]] + v[i]
  • 合并：max(不选, 选)
for (int i = 1; i <= N; i++) for (int j = 0; j <= W; j++) { dp[i][j] = dp[i-1][j]; if (j >= w[i]) dp[i][j] = max(dp[i][j], dp[i-1][j-w[i]] + v[i]); }
【讲解】选必须来自 i-1 行，保证只用一次。

一维优化与倒序原理

dp[i][j] 只依赖上一行 → 压成 dp[j]。

for (int i = 1; i <= N; i++) for (int j = W; j >= w[i]; j--) // 倒序！ dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
正序错误原因：j 从小到大时，dp[j-w] 已含本物品 → 等于可再选一次 → 变成完全背包。
零一倒着走，完全正着走
【讲解】倒序保证用的是「未装 i」的旧值。

初始化：可不装满 vs 恰好装满

题意初始化
不超过容量，最大价值全部 0
必须恰好装满dp[0]=0，其余 -INF
// 可不装满 fill(dp, dp + W + 1, 0); // 恰好装满 memset(dp, 0xcf, sizeof(dp)); // 约 -INF dp[0] = 0; // 最终 dp[W]<0 表示无法恰好装满
【讲解】初始化大坑。

三、完全背包

每种物品可选无限次。二维差异：用同一行 dp[i][j-w] 而非 dp[i-1]。

// 一维：正序 for (int i = 1; i <= N; i++) for (int j = w[i]; j <= W; j++) // 正序！ dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
  • 正序使本物品可被多次叠加
  • 硬币无限枚、货币系统 → 完全背包
  • 最少硬币：价值改为 1 次数，min 转移 + INF 初始化
【讲解】完全背包 与 01 只差循环方向。

01 vs 完全 对照

项目01完全
次数≤1无限
二维转移第二项dp[i-1][j-w]dp[i][j-w]
一维容量循环倒序 j=W..w正序 j=w..W
典型题采药、装箱零钱、完全货币
考试先判断次数，再决定正/倒序。写反必 WA。
【讲解】对照表 齐背。

采药类完整模板（01）

int T, M; // 时间上限、草药种数 cin >> T >> M; for (int i = 1; i <= M; i++) cin >> t[i] >> v[i]; for (int i = 1; i <= M; i++) for (int j = T; j >= t[i]; j--) dp[j] = max(dp[j], dp[j - t[i]] + v[i]); cout << dp[T];
NOIP 采药：时间=容量，每株最多一次 → 标准 01。
【讲解】采药 映射清晰。

完全背包 — 最少硬币

fill(dp, dp + amount + 1, INF); dp[0] = 0; for (int i = 0; i < m; i++) for (int j = coins[i]; j <= amount; j++) dp[j] = min(dp[j], dp[j - coins[i]] + 1); // 输出 dp[amount]==INF ? -1 : dp[amount]
【讲解】与第33课找零 DP 一致，正式归入完全背包。

方案回溯（选了哪些）

// 用二维表时： int j = W; for (int i = N; i >= 1; i--) { if (j >= w[i] && dp[i][j] == dp[i-1][j-w[i]] + v[i]) { // 选了物品 i j -= w[i]; } }
一维难以直接回溯，需额外记录或保留二维。CSP-J 多数只求最大价值。
【讲解】回溯可选讲。

真题精练

① 采药 / 装箱问题

01 背包一维倒序。注意数组下标从 1、容量循环到 0 或 w。

② 货币系统 / 完全背包

无限枚，正序；或求方案数 dp[j]+=dp[j-w]。

【讲解】真题

易错点

  • 01 写成正序 / 完全写成倒序
  • 恰好装满仍用全 0 初始化
  • 内外循环颠倒（物品必须在外层）
  • w、v 下标与循环不一致
  • 空间：W 大时注意数组大小；价值用 long long（若题面需要）
【讲解】易错

本课小结

  • 01：每件 ≤1 次，一维倒序。
  • 完全：无限次，一维正序。
  • 状态 dp[i][j] / dp[j]；手推表理解转移。
  • 初始化分「可不装满」与「恰好装满」。
  • 口诀：零一倒着走，完全正着走。
