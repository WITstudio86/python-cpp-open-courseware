参数传递与作用域

形参实参 · 值传递 · 引用传递 · 数组参数 · 全局/局部 · static

【开场】初赛常考读代码输出；配套 lesson18。

一、形参与实参

形参实参
位置定义/声明参数列表调用时括号内
本质函数内局部变量表达式/变量/常量
生命周期调用期间取决于自身作用域
void func(int x) { x = 100; } // 形参 int main() { int x = 10; // 实参变量 func(x); cout << x; // 10 —— 同名也是不同变量 }
【讲解】名字可相同，内存不同。

二、值传递（默认）

  1. 计算实参 → 创建形参 → 复制值
  2. 函数只改副本，不影响实参
  3. 适合“只读参数”：factorial、isPrime
void tryToModify(int num) { num = 999; } int a = 10; tryToModify(a); // 调用后 a 仍是 10
初赛高频：给出函数内改参数，问外部变量是否变化 → 值传递则不变。
【讲解】安全：不会误改调用者数据。

三、引用传递（&）

引用 = 变量的别名；形参写 int &num 时改的是实参本身。

// 错误：值传递 swap void swapWrong(int a, int b) { int t=a; a=b; b=t; }
// 正确：引用 swap void swap(int &a, int &b) { int t=a; a=b; b=t; }
// 通过引用“返回”多值 void calc(int a, int b, int &sum, int &product) { sum = a+b; product = a*b; }
【讲解】引用实参必须是可修改左值，不能传 5 或 a+b。

四、数组作为参数

  • 传的是首元素地址，函数内改数组会影响原数组
  • 必须额外传长度 n；函数内 sizeof(arr) 是指针大小
  • 多维：除第一维外，其余维大小必须写
void doubleElements(int arr[], int n) { for (int i=0; i<n; i++) arr[i] *= 2; } // void print(int mat[][3], int rows); // 列必须指定
【讲解】类似“引用式”传递元素。

五、局部变量与全局变量

局部全局
定义位置函数/块内所有函数外
作用域所在块定义处到文件尾
生命周期进入→离开块程序全程
初始化默认垃圾值默认 0
int value = 100; // 全局 int main() { int value = 50; // 遮蔽全局 cout << value; // 50 cout << ::value; // 100 显式访问全局 }
【讲解】共享数据可用全局，但优先参数传递。

六、静态变量 static

  • 局部 static：只初始化一次
  • 生命周期贯穿程序；作用域仍在函数内
  • 典型：统计调用次数、生成递增 ID
void countCalls() { static int callCount = 0; // 仅首次 callCount++; cout << callCount; } // 调 5 次 → 1 2 3 4 5 // 若无 static，每次都是 1
【讲解】别把 static 当“每次从 0 累加”。

七、生命周期与作用域总表

类型作用域生命周期初始化
局部块内进出块不自动
全局文件全程0
static 局部函数内全程0（一次）
形参函数内调用期间由实参
【讲解】存储：局部/形参在栈；全局/static 在静态区。

void badSwap(int a, int b) { int t=a; a=b; b=t; // 无效 } void swap(int &a, int &b) { int t=a; a=b; b=t; // 有效 } void getMinMax(int a,int b,int c, int &mn, int &mx) { mn = mx = a; if (b<mn) mn=b; if (c<mn) mn=c; if (b>mx) mx=b; if (c>mx) mx=c; }

int globalValue = 0; void trackCalls() { static int callCount = 0; callCount++; } void localLifecycle() { int localVar = 1; static int staticVar = 1; localVar++; staticVar++; // 每次 local 重新 1 再变 2；static 累积 }
【讲解】模板二。

📝 真题精练

题1：swap 引用交换后输出，再算绝对值差。输入 10 30 → 30 10 / 20

void swap(int &a, int &b) { ... } int diff(int a, int b) { int d=a-b; return d>0?d:-d; }

题2：sumOfDigits 内 static 计调用次数；T 组，输出 各位和 与 次数

static int callCount = 0; callCount++; // 样例 123/45/6789 → 6 1 / 9 2 / 30 3
【讲解】static 与全局两种暴露 callCount 的设计。

⚠ 易错点

  1. 以为值传递能改实参 → 要加 &
  2. 数组参数里用 sizeof 求长度 → 必须传 n
  3. 引用绑定常量/表达式 → 非法
  4. static 只初始化一次，不是每次清零
  5. 局部遮蔽全局时忘记 ::
读题口诀：有没有 &？是数组吗？有 static 吗？同名遮蔽了吗？
【讲解】对照讲义四易错。
