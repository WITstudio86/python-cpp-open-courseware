值传递 vs 引用传递

值传递（默认）

传递实参的副本

函数内修改不影响原始变量

void f(int x) { x = 999; } // a 不变！

引用传递（&）

传递实参本身

函数内修改直接影响原始变量

void f(int &x) { x = 999; } // a 被改变！

经典示例：swap 函数

// 引用传递版 —— 真正交换 void swap(int &a, int &b) { int temp = a; a = b; b = temp; } int x = 10, y = 20; swap(x, y); // x=20, y=10 ← 成功交换！
高频考点：CSP-J 初赛选择题经常给出一段含有值传递和引用传递的代码，问最终输出结果。请务必区分：默认是值传递（不改变实参），加了 & 才是引用传递（改变实参）。
【讲解】值传递 vs 引用传递 结合讲义《二、值传递（Pass by Value）》强调： · 值传递是 C++ 默认的参数传递方式。当使用值传递时，函数调用会发生以下过程： · 计算实参表达式的值 · 在函数栈帧中创建形参变量 · 将实参的值**复制**给形参 · 函数内部对形参的任何操作都限于这个副本 幻灯片上可见要点： · 值传递（默认） · 传递实参的 副本 · 函数内修改 不影响 原始变量 · 引用传递（&） 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：值传递/引用传递、全局变量/局部变量、静态变量

数组作为函数参数

传递本质

数组作为参数时，传递的是数组首元素的地址（指针），而不是整个数组的副本。因此函数内部对数组元素的修改会直接影响原始数组。

void doubleElements(int arr[], int n) { for (int i = 0; i < n; i++) { arr[i] *= 2; // 修改原始数组！ } } int a[] = {1, 2, 3, 4, 5}; doubleElements(a, 5); // a 变为 {2, 4, 6, 8, 10}

关键注意事项

  1. 必须额外传递数组长度：函数内部 sizeof(arr) 返回的是指针大小（4 或 8 字节），不是数组总大小。
  2. 数组参数是"类引用"效果：虽然没写 &，但修改数组元素会同步到原始数组，这与普通值传递完全不同。
  3. 多维数组：除第一维外，其他维度的大小必须显式指定。
记忆技巧：普通变量 → 值传递（副本）；数组 → 地址传递（直接操作原数组）。因此在 CSP-J 中，数组参数实际上是一种"隐式的引用传递"。
【讲解】数组作为函数参数 结合讲义《四、数组作为函数参数》强调： · 在 C++ 中，将数组作为函数参数传递时，实际上传递的是**数组首元素的地址**（指针）。因此，函数内部对数组元素的修改会直接影响调用处的原始数组。 · using namespace std; · // 数组参数：方括号中的数字可以写也可以不写（编译器会忽略） · void doubleElements(int arr[], int n) { // arr 实际接收的是地址 · for (int i = 0; i < n; i++) { 幻灯片上可见要点： · 数组作为参数时，传递的是 数组首元素的地址 （指针），而不是整个数组的副本。因此函数内部对数组元素的修改会 直接影响原始数组 。 · 数组首元素的地址 · 直接影响原始数组 · 必须额外传递数组长度 ：函数内部 sizeof(arr) 返回的是指针大小（4 或 8 字节），不是数组总大小。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

全局变量 / 局部变量 / 静态变量

局部变量
作用域：定义处到代码块结束
生命周期：进入代码块 → 离开代码块
初始化：不自动初始化（垃圾值）
存储位置：栈
全局变量
作用域：整个文件（定义处到文件尾）
生命周期：程序开始 → 程序结束
初始化：自动初始化为 0
存储位置：静态存储区
静态变量（static）
作用域：定义它的函数内部
生命周期：第一次进入 → 程序结束
初始化：自动初始化为 0（仅一次）
存储位置：静态存储区

静态变量的关键特征

void countCall() { static int cnt = 0; // 只初始化一次！ cnt++; cout << "调用次数: " << cnt << endl; } countCall(); // 输出：调用次数: 1 countCall(); // 输出：调用次数: 2 countCall(); // 输出：调用次数: 3 // 如果是 int cnt = 0;（普通局部变量），每次都输出"调用次数: 1"
考点提醒：判断 static 变量的输出也是初赛常见题型。关键点——static 变量的初始化代码只执行一次，之后每次调用都保留上一次的值。
【讲解】全局变量 / 局部变量 / 静态变量 结合讲义《六、静态变量（static）》强调： · 在局部变量前加上 static 关键字，该变量就变成了**静态局部变量**。静态局部变量与普通局部变量有本质区别： · 只初始化一次：静态局部变量的初始化代码只在第一次执行到时执行一次，之后每次进入函数都跳过初始化。 · 生命周期贯穿整个程序运行：函数返回后，静态局部变量不会被销毁，而是保存其当前值，供下一次调用时使用。 · 作用域仍然是局部的：只能在定义它的函数内部访问。 · using namespace std; 幻灯片上可见要点： · 考点提醒： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

代码模板：值传递 vs 引用传递

模板一：swap 函数的两种实现对比

#include <iostream> using namespace std; // 值传递 —— 无效交换 void badSwap(int a, int b) { int t = a; a = b; b = t; } // 引用传递 —— 真正交换 void swap(int &a, int &b) { int t = a; a = b; b = t; } int main() { int x = 10, y = 20; badSwap(x, y); cout << x << " " << y; // 10 20（没交换！） swap(x, y); cout << x << " " << y; // 20 10（真正交换） return 0; }

模板二：通过引用"返回"多个值

void getMinMax(int a, int b, int c, int &minVal, int &maxVal) { minVal = maxVal = a; if (b < minVal) minVal = b; if (c < minVal) minVal = c; if (b > maxVal) maxVal = b; if (c > maxVal) maxVal = c; } int main() { int mn, mx; getMinMax(42, 17, 88, mn, mx); cout << "最小:" << mn << " 最大:" << mx; return 0; }
技巧：函数只能有一个返回值（return），但可以通过多个引用参数把多个计算结果"带出来"。

真题精练

题目一：交换变量并计算差值

定义 void swap(int &a, int &b) 和 int diff(int a, int b)。读入两个整数，交换后输出两数及差的绝对值。

样例：输入 10 30，输出 30 10 和 20。

void swap(int &a, int &b) { int t = a; a = b; b = t; } int diff(int a, int b) { return a > b ? a - b : b - a; } int main() { int x, y; cin >> x >> y; swap(x, y); cout << x << " " << y << endl; cout << diff(x, y) << endl; return 0; }

题目二：使用静态变量统计函数调用次数

定义 int sumOfDigits(int n)，在其内部使用 static int callCount 统计总调用次数。读入 T 个数字，对每个数字输出各位数字之和及当前调用次数。

样例：输入 3 然后 123、45、6789，依次输出 6 1、9 2、30 3。

int sumOfDigits(int n) { static int callCount = 0; callCount++; int sum = 0; while (n > 0) { sum += n % 10; n /= 10; } cout << sum << " " << callCount << endl; return 0; }
得分技巧：题目要求使用 static 时，一定不能省略 static 关键字。判题系统可能会检查函数内部是否包含指定关键字的变量声明。

本课小结

知识模块核心要点
形参与实参 形参是定义时的变量声明，实参是调用时的具体值；同名也互不影响
值传递 默认方式，传递副本；函数内修改不影响原始变量；适合"只读"参数
引用传递 类型后加 &，传递变量本身；函数内修改同步到原始变量；适合 swap、"返回"多个值
数组参数 传递首地址；修改元素影响原始数组；必须额外传递长度；sizeof 在函数内失效
局部变量 作用域限于代码块，离开即销毁；每次进入重新创建；不自动初始化
全局变量 所有函数共享；生命周期贯穿整个程序；自动初始化为 0；过多使用导致难以维护
静态变量 (static) 只初始化一次；生命周期贯穿整个程序；作用域限于定义它的函数；适合统计调用次数
