第21课：结构体定义与使用

打包数据 · 数组 · 排序 · 传参
CSP-J 备考 · 配套 lesson21_结构体定义与使用.cpp
【开场】把学生档案从散变量升级为 struct。

考纲与为什么需要结构体

知识点要求
struct 定义 / 成员访问掌握 · 点运算符 .
初始化方式掌握
结构体数组 + sort/cmp掌握（高频）
函数参数值/引用掌握 const &
嵌套结构体理解
散变量 name1,age1,chinese1… 难管理。结构体 = 自定义类型，把相关字段打包成「档案袋」。
【讲解】现实类比学生档案。

一、定义结构体

struct Student { string name; int age; int chinese, math, english; }; // ⚠️ 右花括号后必须有分号！
  • struct 关键字 + 类型名 + 成员列表
  • 定义后 Student 就是新类型，可声明变量/数组
  • 最易忘：末尾分号
【讲解】对比 class，CSP-J 用 struct 即可。

二、创建与初始化

// 1 先声明再赋值 Student s1; s1.name = "张三"; s1.age = 12; s1.chinese = 90; s1.math = 85; s1.english = 88; // 2 初始化列表 Student s2 = {"李四", 13, 88, 92, 95}; // 3 C++11 统一初始化 Student s3{"王五", 12, 78, 85, 80};
初始化顺序与成员声明顺序一致。未写的成员默认初始化（POD 可能未定义，竞赛中建议写全）。
【讲解】三种方式都合法，考场任选一种熟练。

三、点运算符访问成员

Student stu = {"张三", 90, 85, 88}; // 按实际成员调整 int total = stu.chinese + stu.math + stu.english; double avg = total / 3.0; stu.math = 95; // 修改成员 cout << stu.name << " 总分 " << total << endl;
  • 读：int a = s.age;
  • 写：s.chinese = 95;
  • 表达式中直接用成员参与运算
【讲解】. 与指针 -> 对比（下节课）。

四、结构体数组

Student stus[100]; int n; cin >> n; for (int i = 0; i < n; i++) { cin >> stus[i].name >> stus[i].chinese >> stus[i].math >> stus[i].english; stus[i].total = stus[i].chinese + stus[i].math + stus[i].english; } // 扫描最高分：比较 stus[i].total
用法与普通数组相同，元素类型是结构体。批量管理学生/点/边的标准做法。
【讲解】演示最高/最低/平均统计思路。

五、结构体排序：sort + cmp

bool cmp(const Student &a, const Student &b) { if (a.total != b.total) return a.total > b.total; // 总分降序 return a.name < b.name; // 同名次按姓名升序 } // sort(stus, stus + n, cmp);
  • cmp 返回 true 表示 a 应排在 b 前面
  • 参数推荐 const T&，避免复制大结构体
  • 范围 [begin, end) → stus ~ stus+n
CSP-J 高频：多关键字排序几乎必考结构体 + cmp。
【讲解】严格弱序：不要写不稳定相等时两边 true。

六、结构体作为函数参数

值传递

void f(Student s) { s.total += 10; // 改副本 } // 原对象不变；大结构慢

引用传递

void g(Student &s) { s.total += 10; // 改原对象 } void print(const Student &s);
只读 → const Student&；要改 → Student&。竞赛默认 const 引用。
【讲解】对照第18课传参。

七、嵌套结构体

struct Date { int year, month, day; }; struct Student { string name; Date birthday; // 嵌套 int total; }; Student stu; stu.birthday.year = 2012; stu.birthday.month = 6; stu.birthday.day = 15; // 多级点号：stu.birthday.year
点坐标 Point{x,y} 嵌套在边/图形中同理。访问链式点号即可。
【讲解】为真题最近点对铺垫 Point。

代码模板：学生成绩 + 点距离

struct Student { string name; int chinese, math, english, total; }; bool cmp(const Student &a, const Student &b) { if (a.total != b.total) return a.total > b.total; return a.name < b.name; } // 读入 → 算 total → sort(stus, stus+n, cmp) → 输出排名 struct Point { int x, y; }; double dist(const Point &a, const Point &b) { int dx = a.x - b.x, dy = a.y - b.y; return sqrt(dx * dx + dy * dy); }
【讲解】两模板覆盖成绩榜与几何点。

易错点

1. 结构体定义漏分号 → 编译错
2. 混淆类型名 Student 与变量名 s
3. 大结构体值传递拖慢 / 改不动原数据
4. cmp 签名错误：必须 bool，两参数同类型
5. 结构体数组下标越界 / n 读错
// ❌ bool cmp(Student a, Student b) 可用但慢 // ✅ bool cmp(const Student& a, const Student& b) // ❌ return a.total >= b.total; // 相等时不该 true
【讲解】cmp 相等返回 false。

真题1：学生成绩排名

题目

N 名学生，三科成绩，按总分降序；同分按姓名字典序升序。输出排名与各科+总分。

样例要点：赵六与李四同 275 分，赵 < 李 → 赵排前。

bool cmp(const Student &a, const Student &b) { if (a.total != b.total) return a.total > b.total; return a.name < b.name; } // 读 n 行 → total=c+m+e → sort → 输出 i+1 与字段
【练习】完整 AC 见讲义。

真题2：最近点对

题目

平面 N 个点（2≤N≤100），求最近两点欧氏距离，保留两位小数。

struct Point { int x, y; }; double minDist = 1e18; for (int i = 0; i < n; i++) for (int j = i + 1; j < n; j++) minDist = min(minDist, dist(pts[i], pts[j])); printf("%.2f\n", minDist);
N≤100 暴力 O(n²) 足够。结构体封装坐标，距离函数用 const 引用。
【练习】样例四点最小 1.00。
