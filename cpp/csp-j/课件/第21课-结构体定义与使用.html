结构体的定义

结构体（struct）是将多个相关数据组合成一个整体的自定义数据类型。

类比：学生档案袋 = 结构体；档案上的各项信息（姓名、年龄、成绩）= 成员变量。

定义语法

struct Student { string name; // 姓名 int age; // 年龄 int chinese; // 语文 int math; // 数学 int english; // 英语 }; // 注意：分号不能忘！
易错：右花括号 } 后面必须写分号 ;，否则编译错误！

结构体定义后，Student 就成为一个新的数据类型，可以像 int、string 一样使用。

成员访问与初始化

三种初始化方式

// 1. 逐个赋值 Student s1; s1.name = "张三"; s1.age = 12; s1.chinese = 90; // 2. 初始化列表 Student s2 = {"李四", 13, 88, 92, 95}; // 3. C++11 统一初始化 Student s3{"王五", 12, 78, 85, 80};

点运算符 .

// 读取成员 int a = s1.age; // 修改成员 s1.math = 95; // 计算表达式 int total = s1.chinese + s1.math + s1.english;

结构体数组

可以创建结构体类型的数组，方便批量管理数据：

Student stus[100]; // 最多存储 100 个学生 int n; cin >> n; for (int i = 0; i < n; i++) { cin >> stus[i].name >> stus[i].chinese >> stus[i].math >> stus[i].english; stus[i].total = stus[i].chinese + stus[i].math + stus[i].english; }
常见操作：遍历结构体数组，统计最高分/最低分/平均分。使用循环遍历每个元素，通过 stus[i].成员名 访问数据。

与普通数组的区别仅在于：数组元素的类型是结构体，需要使用点运算符访问内部成员。

【讲解】结构体数组 结合讲义《5. 结构体数组》强调： · 当需要管理多个学生的信息时，可以使用结构体数组。这与普通数组的使用方式类似，只是数组元素的类型变成了结构体。 · 定义结构体数组： · Student stus[100]; // 最多存储100个学生 · int n; // 实际学生数量 · cin >> n; 幻灯片上可见要点： · 可以创建结构体类型的数组，方便批量管理数据： · 常见操作： · 与普通数组的区别仅在于： 数组元素的类型是结构体 ，需要使用点运算符访问内部成员。 · 数组元素的类型是结构体 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

结构体排序 —— sort + cmp

CSP-J 高频考点！使用 sort() 配合自定义比较函数实现按任意字段排序。

比较函数模板

bool cmp(const Student &a, const Student &b) { if (a.total != b.total) return a.total > b.total; // 总分降序 return a.name < b.name; // 总分相同按姓名升序 } sort(stus, stus + n, cmp);
排序需求cmp 核心代码
总分降序return a.total > b.total;
按姓名升序return a.name < b.name;
总分降序，同分按姓名升序先用 if 判断总分，再判断姓名
易错：cmp 的返回值必须是 bool，参数必须用 const & 避免复制！
【讲解】结构体排序 —— sort + cmp 结合讲义《6. 结构体排序——配合 `sort()` + 自定义比较函数》强调： · CSP-J 考试中非常常见的题型：对结构体数组按照某个字段进行排序。 · sort() 函数需要三个参数： · 排序的起始地址 · 排序的结束地址（不包含） · 比较函数（cmp）：决定排序规则 幻灯片上可见要点： · CSP-J 高频考点！使用 sort() 配合 自定义比较函数 实现按任意字段排序。 · 自定义比较函数 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

结构体作为函数参数

值传递（不推荐）

void print(Student s) { cout << s.name; s.total = 0; // 改的是副本 }
缺点：会复制整个结构体，效率低。修改不影响原数据。

引用传递（推荐）

// 只读引用（最常用） void print(const Student &s) { cout << s.name; } // 可修改引用 void addBonus(Student &s) { s.total += 10; }
优点：不复制，效率高。const & 既安全又快速，是 CSP-J 最佳实践。
口诀：「只读用 const &，修改用 &，永远不用值传递传大结构体！」
【讲解】结构体作为函数参数 结合讲义《7. 结构体作为函数参数》强调： · （1）值传递（Pass by Value）： · void printStudent(Student s) { // 会复制整个结构体！ · cout << s.name << " " << s.total << endl; · 函数内部操作的是**原始结构体的副本** · 修改副本**不会影响**原始数据 幻灯片上可见要点： · 结构体作为函数参数 · 值传递（不推荐） · void · print 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

代码模板 —— 学生成绩排序

定义 Student 结构体，输入 n 个学生，按总分降序排序，输出前三名：

struct Student { string name; int chinese, math, english, total; }; bool cmp(const Student &a, const Student &b) { return a.total > b.total; } int main() { int n; cin >> n; Student stus[105]; for (int i = 0; i < n; i++) { cin >> stus[i].name >> stus[i].chinese >> stus[i].math >> stus[i].english; stus[i].total = stus[i].chinese + stus[i].math + stus[i].english; } sort(stus, stus + n, cmp); for (int i = 0; i < min(3, n); i++) cout << stus[i].name << " " << stus[i].total << endl; return 0; }
【讲解】代码模板 —— 学生成绩排序 本页要点（照着讲即可）： · 定义 Student 结构体，输入 n 个学生，按总分降序排序，输出前三名： 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

易错点总结

错误1：结构体定义末尾忘记加分号 ;
struct Student { ... } // ❌ 编译错误！
错误2：混淆结构体名与变量名
Student.name = "张三"; // ❌ Student 是类型，不是变量！
错误3：cmp 函数签名错误
int cmp(Student a, Student b) { ... } // ❌ 返回类型应为 bool，参数应加 const &
错误4：值传递复制大结构体导致效率低
void f(Student s) { ... } // ❌ 每次都复制，应该用 const Student &s
错误5：结构体数组下标越界
数组大小固定为 100，但输入的 n 可能超过 100，注意题目范围限制。
