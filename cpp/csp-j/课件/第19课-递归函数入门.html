一、什么是递归？

递归（Recursion）：函数直接或间接调用自身，把大问题拆成结构相同的小问题，直到可直接求解。

🪆 俄罗斯套娃：一直打开到最小实心娃，再逐层装回 —— 「递」深入、「归」返回。
void countdown(int n) { if (n <= 0) { // 边界 cout << "发射！"; return; } cout << n << " "; // 递：先输出 countdown(n - 1); // 交给更小规模 cout << n << " "; // 归：返回后再输出 } // countdown(3) → 3 2 1 发射！ 1 2 3
关键： 调用返回后，会继续执行调用点之后的语句 —— 这才是「归」。
【讲解】板书 countdown(3) 递与归时间线。

二、递归三要素（缺一不可）

① 边界条件

最小规模直接答案，递归「出口」。

if (n==0) return 1;

② 递归关系

大问题如何由小问题推出。

n * fact(n-1)

③ 参数收敛

每次调用必须更靠近边界。

n-1 / n/10 等

正确： 向边界靠近
return n * f(n-1);
错误： 背离边界
return f(n+1); 永不到 0
考场习惯：先写三要素注释（停在哪 / 怎么拆 / 参数怎么变），再填代码。
【讲解】三要素口诀：何时停？怎么分？往哪缩？

三、阶乘深度解析

定义：0! = 1；n! = n × (n-1)!

long long factorial(int n) { if (n == 0) return 1; // 边界 return n * factorial(n - 1); // 关系 + 收敛 }
factorial(5) = 5 * factorial(4) = 5 * (4 * factorial(3)) = ... = 5*(4*(3*(2*(1*factorial(0))))) = 5*(4*(3*(2*(1*1)))) = 120 递阶段：层层等待；归阶段：边界返回后逐层相乘
递阶段没有任何一层能立刻算出最终结果；只有边界返回后，「归」才开始计算。
【讲解】手算 fact(5)，强调等待-返回。

四、斐波那契：三种写法效率对比

fib(0)=0, fib(1)=1, fib(n)=fib(n-1)+fib(n-2)

写法时间空间说明
朴素递归O(2ⁿ)O(n)大量重复子问题，n≥40 极慢
记忆化O(n)O(n)memo 缓存，每个 n 算一次
迭代O(n)O(1)两变量滚动，考场首选
// 记忆化骨架 long long memo[N]; // 初始化为 -1 long long fib(int n) { if (n <= 1) return n; if (memo[n] != -1) return memo[n]; return memo[n] = fib(n-1) + fib(n-2); }
考试 n 较大时禁止裸递归 fib；用记忆化或迭代。
【讲解】画 fib(5) 递归树，标重复节点。

五、递归调用栈

每次调用压入栈帧（参数、局部变量、返回地址）；返回时弹出。LIFO 匹配「后调用先返回」。

main 调 fact(3) [栈] fact(n=3) | main fact(3) 调 fact(2) [栈] fact(2) | fact(3)等待 | main ... 直到 fact(0) 边界返回 1 弹栈：fact(1)=1 → fact(2)=2 → fact(3)=6 → 回 main
  • 栈深度 ≈ 递归深度 → 空间至少 O(深度)
  • 默认栈约数 MB，深度上万可能 Stack Overflow
  • 深度过大：改迭代，或手动 stack 模拟
CSP-J：多数题深度可控；见 n≥10⁵ 且深度为 n 时警惕栈溢出。
【讲解】对应程序 demo5 可视化输出。

六、递归与迭代对比

维度递归迭代
代码贴近数学定义，简洁需维护循环变量
时间朴素可能指数级通常 O(n)
空间O(深度) 调用栈常 O(1)
风险栈溢出无调用栈风险
适用树/图/分治/回溯线性递推、简单遍历
选型： 结构天然递归且深度安全 → 递归；线性递推或深度巨大 → 迭代。先保证正确，再谈优化。
【讲解】阶乘/fib 两种写法对照。

七、递归思维训练：五步法

  1. 找自相似：能否拆成更小同类问题？
  2. 定最小答案：规模不能再分时返回什么？
  3. 写关系式：当前答案如何用子答案表示？
  4. 信任子调用：假设 f(n-1) 已正确，只写本层逻辑
  5. 验证收敛：参数每步更接近边界
// 各位数字之和：digitSum(n) = n%10 + digitSum(n/10) int digitSum(int n) { if (n < 10) return n; // 边界 return (n % 10) + digitSum(n / 10); } // 同类：gcd、位数、数组和、幂运算……
【讲解】配套 digitCount / gcd / power。

代码模板

模板1：阶乘（递归 + 迭代）

long long fact_r(int n) { if (n == 0) return 1; return n * fact_r(n - 1); } long long fact_i(int n) { long long r = 1; for (int i = 1; i <= n; i++) r *= i; return r; }

模板2：斐波那契记忆化

long long memo[100]; long long fib(int n) { if (n <= 1) return n; if (memo[n] != -1) return memo[n]; return memo[n] = fib(n-1) + fib(n-2); } // main 中 memset(memo, -1, sizeof(memo));
【讲解】考场直接套模板，边界写在最前。

易错点清单

1. 忘记边界：无限递归 → 栈溢出。养成「先写出口」习惯。

2. 参数不收敛：边界 n==0 却写 n+1；或边界 n>100 却递减。

3. 返回值丢失：factorial(n-1); 未 return；或算了不 return。

4. 深度过大：dfs(1e5) 可能 RE。改迭代 / 显式栈 / 查数据范围。
// ❌ 丢返回值 // ✅ 正确 int bad(int n) { int ok(int n) { if (n==0) return 1; if (n==0) return 1; bad(n-1); return n * ok(n-1); } }
口诀：边界在前 → 关系正确 → 参数收敛 → 结果 return。
【讲解】对应程序 demo10（错误代码只注释）。

真题1：递归求和

题目

给定 n（1≤n≤10000），用递归求 1+2+…+n，禁止循环与公式。

样例：5 → 15；100 → 5050

long long sum_recursive(int n) { if (n == 1) return 1; // 边界 return n + sum_recursive(n - 1); // sum(n)=n+sum(n-1) } int main() { int n; cin >> n; cout << sum_recursive(n) << endl; }
复杂度 O(n) 时间、O(n) 栈空间。思考：n=1e5 会否栈溢出？应如何改迭代？
【练习】对照讲义题目1。

真题2：递归求数字位数

题目

给定正整数 n（1≤n≤10⁹），递归求十进制位数。例：12345 → 5；100 → 3。

int digitCount(int n) { if (n < 10) return 1; // 一位数 return 1 + digitCount(n / 10); // 去掉最低位 }
时间/空间 O(log n)，n≤1e9 最多约 10 层，安全。
变式： 二进制 1 的个数 → 边界 n==0 返回 0；关系 (n&1)+countOne(n>>1)。
【练习】与 sum 同模式：边界 + 缩小规模。
