什么是递归？

递归（Recursion）是一种编程技巧：函数直接或间接地调用自身，将一个大问题逐步分解为规模更小、结构相同的子问题，直到问题小到可以直接求解为止。

🪆 递归就像俄罗斯套娃 — 打开一个娃娃，里面还是一个娃娃，直到最小的那个无法再打开。

下面是一个简单的倒数例子：从 n 开始倒数到 1。

void countdown(int n) { if (n == 0) return; // 边界条件：停止递归 cout << n << " "; countdown(n - 1); // 递归调用：规模缩小 } // 调用 countdown(5) → 输出: 5 4 3 2 1
💡 核心思想：把大问题转化为同类型的小问题，直到可以直接求解。

递归三要素

每一个正确的递归函数都必须具备以下三个要素，缺一不可。

① 边界条件（终止条件）

明确递归何时停止。
没有边界条件会导致无限递归，最终栈溢出。

if (n == 0) return 1;

② 递归关系（递推公式）

定义问题如何分解为更小的同类子问题。

return n * fact(n - 1);

③ 参数变化（规模缩小）

每次递归调用，问题的规模必须向终止条件靠近。

n - 1  → 参数逐步减小

三要素是 CSP-J 递归题目最核心的考点。遇到递归题，先把三要素写出来再编码，正确率能大幅提高。

三要素可以总结为三个问题：什么时候停？怎么分解？参数怎样变化？

【讲解】第 3 页 本页要点（照着讲即可）： · 每一个正确的递归函数都必须具备以下三个要素，缺一不可。 · ① 边界条件（终止条件） · 明确递归何时停止。 没有边界条件会导致无限递归，最终栈溢出。 · if (n == 0) return 1; · ② 递归关系（递推公式） · 定义问题如何分解为更小的同类子问题。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
阶乘深度解析：factorial(5)

阶乘定义：n! = n × (n-1) × ... × 1，且 0! = 1。

int factorial(int n) { if (n == 0) return 1; // 边界条件 return n * factorial(n - 1); // 递归关系 }

调用 factorial(5) 的递归展开过程：

factorial(5) = 5 * factorial(4) = 5 * (4 * factorial(3)) = 5 * (4 * (3 * factorial(2))) = 5 * (4 * (3 * (2 * factorial(1)))) = 5 * (4 * (3 * (2 * (1 * factorial(0))))) ← 到达边界条件 factorial(0) = 1 = 5 * (4 * (3 * (2 * (1 * 1)))) = 5 * (4 * (3 * (2 * 1))) = 5 * (4 * (3 * 2)) = 5 * (4 * 6) = 5 * 24 = 120
🧠 递归分为两个阶段：递推阶段（一路向下展开）和 回归阶段（逐层返回计算结果）。
【讲解】第 4 页 本页要点（照着讲即可）： · 阶乘定义： n! = n × (n-1) × ... × 1 ，且 0! = 1 。 · 调用 factorial(5) 的递归展开过程： · 递推阶段 · 回归阶段 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
斐波那契数列：三种写法的效率对比

斐波那契数列：F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)。计算 F(40) 来看看三种写法的天壤之别。

朴素递归 O(2ⁿ) 极慢

int fib(int n) { if (n <= 1) return n; return fib(n-1) + fib(n-2); }

F(40) 需要约 3 亿次调用，耗时数秒甚至数十秒。

记忆化递归 O(n) 较好

int memo[100]; int fib(int n) { if (n <= 1) return n; if (memo[n]) return memo[n]; return memo[n] = fib(n-1)+fib(n-2); }

缓存已计算结果，避免重复计算，F(40) 瞬间出结果。

迭代 O(n) 最优

int fib(int n) { if (n <= 1) return n; int a=0, b=1; for(int i=2; i<=n; i++){ int c=a+b; a=b; b=c; } return b; }

空间 O(1)，无递归栈开销，是所有写法中最高效的。

考试中如果 n 较大（如 n ≥ 30），朴素递归会严重超时。务必使用记忆化或直接改写成迭代。

代码模板：考场上直接套用

以下两个模板覆盖了 CSP-J 递归题目的最常见模式。理解后可在考场上快速套用。

模板一：阶乘 / 累乘 / 累加类

int calc(int n) { // ① 边界条件：问题的最小情况 if (n == 0 || n == 1) return 1; // ② 递归关系：n 与 n-1 的结果之间的关系 return n * calc(n - 1); // ③ 参数变化：n → n-1，向边界靠近 }

模板二：斐波那契 / 递推类

int memo[N]; // 记忆化数组（视题目要求决定是否使用） int solve(int n) { // ① 边界条件：基础情况 if (n == 0) return 0; if (n == 1) return 1; // ② 记忆化：查缓存 if (memo[n] != -1) return memo[n]; // ③ 递归关系 + 存储结果 return memo[n] = solve(n-1) + solve(n-2); }
⚡ 考场技巧：写出递归三要素注释（边界 / 关系 / 变化），再填代码，思路更清晰，不易漏掉边界条件。

真题精练

📌 真题一：递归求 1 + 2 + 3 + ... + n

给定正整数 n，用递归函数求 1 到 n 的和。要求写出完整代码。

输入：一个正整数 n（1 ≤ n ≤ 1000）
输出：1 + 2 + ... + n 的结果

int sum(int n) { if (n == 1) return 1; // 边界条件：n=1 时和为 1 return n + sum(n - 1); // 递归关系：sum(n) = n + sum(n-1) } // 时间复杂度 O(n)，空间复杂度 O(n)

递推公式：sum(n) = n + sum(n-1)，边界条件 sum(1) = 1。

📌 真题二：递归求数字位数（数位统计）

给定一个正整数 n，用递归函数计算它的十进制位数。例如 12345 有 5 位。

输入：一个正整数 n（1 ≤ n ≤ 10⁹）
输出：n 的十进制位数

int digitCount(int n) { if (n < 10) return 1; // 边界条件：个位数只有 1 位 return 1 + digitCount(n / 10); // 去掉最低位，位数 +1 } // 时间复杂度 O(log₁₀ n)，空间复杂度 O(log₁₀ n)

递推公式：digitCount(n) = 1 + digitCount(n / 10)，边界条件 digitCount(n < 10) = 1。

两道题都遵循同一模式：确定边界条件（最小情况）→ 写出递推公式 → 每次递归缩小问题规模。理解了这一点，80% 的 CSP-J 递归题都能迎刃而解。
