一、枚举算法思想

1.1 什么是枚举？

枚举算法（Enumeration Algorithm）是一种通过逐一列举所有可能情况来求解问题的方法。它是算法设计中最基础、最直接的策略，也是 CSP-J 中最高频的考点之一。

  • 核心思想：在问题解空间中，逐一验证每一个候选解，直到找到满足所有约束条件的可行解。
  • 本质：把"所有可能性"变成一个可遍历的集合，然后用循环去检查每一个。

1.2 枚举三要素

要素含义示例（百钱百鸡）
枚举对象我们要枚举什么？解空间中的候选解是什么？公鸡 x、母鸡 y、小鸡 z 的数量组合
枚举范围每个对象的取值上下界，避免无意义穷举0 ≤ x ≤ 20, 0 ≤ y ≤ 33, z = 100 - x - y
约束条件判断候选解是否可行的检验标准5x + 3y + z/3 = 100 且 z 能被 3 整除

1.3 适用场景

  • 数据规模较小（n ≤ 10³ ~ 10⁴），枚举所有情况在时限内可行
  • 问题有明确的判定条件，且解空间结构良好
  • 没有现成的数学公式可以直接求解
  • 题目描述中有"找出所有..."、"判断是否存在..."等表述
💡 考试技巧：枚举不意味着"暴力尝试所有数字"！聪明的枚举是：先想清楚范围，再动手写代码。拿到题后三步走：① 分析问题结构，确定枚举对象属于哪种类型（排列/组合/子集）；② 估计枚举范围多大，判断是否超时；③ 找出隐藏的数学性质来剪枝优化。

二、百钱百鸡问题 — 经典枚举

2.1 问题描述

中国古代数学家张丘建在《算经》中提出：

"鸡翁一，值钱五；鸡母一，值钱三；鸡雏三，值钱一。百钱买百鸡，问鸡翁、母、雏各几何？"

翻译：公鸡 5 钱一只，母鸡 3 钱一只，小鸡 1 钱三只。用 100 钱买 100 只鸡，问公鸡、母鸡、小鸡各多少只？

2.2 朴素暴力解法 — O(n³)

设公鸡 x 只，母鸡 y 只，小鸡 z 只。则约束为：x + y + z = 100（数量），5x + 3y + z/3 = 100（钱数），且 z 是 3 的倍数。

// 朴素三重循环 — 100 × 100 × 100 = 10⁶ 次判断 for (int x = 0; x <= 100; x++) { for (int y = 0; y <= 100; y++) { for (int z = 0; z <= 100; z++) { if (x + y + z == 100 && 5*x + 3*y + z/3 == 100 && z % 3 == 0) cout << x << " " << y << " " << z << endl; } } }

2.3 优化策略 — 缩小范围 + 消元

观察 1：公鸡最贵（5 钱），最多买 100/5 = 20 只，所以 x 范围缩小到 0~20。

观察 2：母鸡 3 钱一只，最多买 100/3 ≈ 33 只。

观察 3：利用方程消元：z = 100 - x - y，代入钱数方程得：5x + 3y + (100-x-y)/3 = 100。化简后只需两重循环，z 由公式直接算出。

// 优化版：两重循环 + 数学消元 — 约 20 × 33 = 660 次 for (int x = 0; x <= 20; x++) { // 公鸡最多 20 只 for (int y = 0; y <= 33; y++) { // 母鸡最多 33 只 int z = 100 - x - y; // 小鸡数量由总数确定 if (z % 3 == 0 && 5*x + 3*y + z/3 == 100) printf("公鸡:%d 母鸡:%d 小鸡:%d\n", x, y, z); } } // 输出：公鸡:0 母鸡:25 小鸡:75 // 公鸡:4 母鸡:18 小鸡:78 // 公鸡:8 母鸡:11 小鸡:81 // 公鸡:12 母鸡:4 小鸡:84
💡 考试技巧：优化枚举的核心手段：① 利用数学性质缩小范围（如公鸡最多 20 只）；② 利用方程消元减少循环层数（用两个变量表示第三个）；③ 提前剪枝（不满足条件时直接 continue）。

三、代码模板

3.1 单层枚举框架

适用于：在一个序列中查找满足条件的元素，或对每个元素进行某种操作。

// 单层枚举：遍历数组，查找满足条件的元素 for (int i = 0; i < n; i++) { if (check(a[i])) { // 判断 a[i] 是否满足条件 ans++; // 计数或记录答案 } } cout << ans << endl;

3.2 双层枚举框架

适用于：枚举数对 (i, j)，判断两两之间的关系。时间复杂度 O(n²)。

// 双层枚举：枚举所有 (i, j) 对，找满足条件的组合 for (int i = 0; i < n; i++) { for (int j = i + 1; j < n; j++) { // j 从 i+1 开始，避免重复 if (a[i] + a[j] == target) { // 两数之和 cout << i << " " << j << endl; } } }

3.3 枚举 + 剪枝框架

适用于：搜索空间大但可以通过约束条件提前排除无效分支的场景。

// 枚举 + 剪枝：在循环中提前排除不可能的情况 for (int a = mina; a <= maxa; a++) { if (a 不满足某必要条件) continue; // 剪枝 for (int b = minb; b <= maxb; b++) { if (a + b 超出限制) break; // 剪枝：由于 b 递增，后面只会更大 int c = calc(a, b); // 用公式直接算第三个变量 if (check(a, b, c)) record(a, b, c); } }

四、真题精练 — 质因数分解

题目描述

已知正整数 n（2 ≤ n ≤ 10⁹），将其分解为质因数的乘积。从小到大输出每个质因数（重复的也要输出）。

输入格式

一行一个正整数 n。

输出格式

若干行，每行一个质因数（从小到大）。

输入样例

12

输出样例

2 2 3 // 12 = 2 × 2 × 3

解题思路

枚举 i 从 2 到 sqrt(n)：如果 n 能被 i 整除，则 i 是质因数（因为 i 是最小的可能因数，必然是质数——反证法可证）。不断用 i 除 n，直到 n 不能被 i 整除为止。最后如果 n > 1，说明 n 本身是一个大于 sqrt(n) 的质因数。

参考代码

#include <iostream> using namespace std; int main() { int n; cin >> n; // 枚举可能的因数 i，从 2 开始 for (int i = 2; i * i <= n; i++) { // 如果 i 是 n 的因数，则不断除以 i while (n % i == 0) { cout << i << endl; // 输出质因数 n /= i; // 去掉这个因数 } } // 如果 n > 1，说明剩下的 n 本身是一个质数 if (n > 1) cout << n << endl; return 0; }
💡 考试技巧：质因数分解的枚举上界是 sqrt(n)，因为任何合数 n 必有一个因子 ≤ sqrt(n)。所以循环条件写 i * i <= n，时间复杂度 O(sqrt(n))。n 最大 10⁹ 时，最多循环约 31623 次，非常快。

五、本课小结

  1. 枚举三要素：枚举对象（解空间中的候选解是什么）、枚举范围（合理上下界）、约束条件（判定可行解的标准）
  2. 百钱百鸡问题是枚举优化的经典案例：利用单价限制缩小范围（公鸡 0~20，母鸡 0~33），利用方程消元减少循环层数（z = 100 - x - y）
  3. 优化手段：① 数学性质缩小范围；② 方程消元减少变量；③ 提前剪枝（continue/break）；④ 利用单调性
  4. 单层枚举 O(n) 适合遍历序列，双层枚举 O(n²) 适合枚举数对，枚举+剪枝适合搜索空间大的场景
  5. 质因数分解是枚举的典型应用：循环上界 sqrt(n)，找到因数就不断除以它。最后 n > 1 说明剩下的是质数
  6. 枚举是 CSP-J 最高频考点，核心不是"能不能写循环"，而是"能不能把问题转化为可枚举的形式"

枚举的智慧：不是穷尽所有，而是精准打击可能区域。
