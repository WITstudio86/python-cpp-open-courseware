CSP-J 为什么爱考枚举？

数据规模常 n≤1000 或更小；枚举确定性好（范围对就不漏解），比贪心/DP 更不容易想偏。很多满分题就是「聪明的暴力」。

【讲解】考纲与目标。强调：枚举不是笨办法，是 CSP-J 最高频策略之一。

一、枚举算法的核心思想

枚举（穷举）：把所有候选解逐一列举，逐一检验，找到满足条件的解。

// 枚举通用框架 for (/* 遍历所有候选解 */) { if (/* 候选解满足条件 */) { // 记录或输出该解 } }

三个关键问题

  1. 枚举范围是什么？必须有限、可列举
  2. 如何判断候选解？判定逻辑正确且尽量高效
  3. 如何避免多余枚举？缩小范围或剪枝
要素含义百钱百鸡示例
枚举对象候选解是什么公鸡 x、母鸡 y、小鸡 z
枚举范围合法上下界0≤x≤20，0≤y≤33，z=100-x-y
约束条件可行性检验5x+3y+z/3=100 且 z%3==0
【讲解】先画三要素表，再讲框架。强调「先想范围再写代码」。

二、单层循环枚举

候选解只需一个变量描述时用单层循环。经典：质数判断（试除法）。

bool isPrime(int n) { if (n < 2) return false; // 只需枚举到 sqrt(n)：用 i*i<=n，避免浮点误差 for (int i = 2; i * i <= n; i++) { if (n % i == 0) return false; } return true; }
优化要点：范围从 [2, n-1] 缩到 [2, √n]，O(n)→O(√n)。n=10⁹ 时约 31623 次，完全可行。

写法注意

优先写 i * i <= n，不要写 i <= sqrt(n)（浮点精度 + 需 cmath）。n 很大时注意 i*i 溢出，用 long long。

【讲解】单层枚举 + 缩小范围。可现场算 √1e9≈3e4。

三、双层 / 三层循环枚举

双层：两数之和

for (int i = 0; i < n; i++) { for (int j = i + 1; j < n; j++) { if (a[i] + a[j] == target) { // 找到解 } } }

j 从 i+1 开始：避免 (i,j)/(j,i) 重复，且自动 i≠j，枚举量减半。

三层：勾股数

for (int a = 1; a <= n; a++) for (int b = a+1; b <= n; b++) for (int c = b+1; c <= n; c++) if (a*a + b*b == c*c) cout << a << " " << b << " " << c << endl;

O(n³)：n=100 约 50 万可行；n=1000 约 1e8 可能卡时限 → 必须优化。

层数复杂度CSP-J 经验 n 上限（粗估）
1O(n) / O(√n)10⁷～10⁹（视常数）
2O(n²)n≈1000～3000
3O(n³)n≈100～200
【讲解】强调组合枚举 j=i+1、a<b<c 的习惯。

四、枚举优化三法宝

  1. 缩小枚举范围：用数学约束定上下界（公鸡最多 100/5=20）
  2. 利用等式减层：x+y+z=100 ⇒ z=100-x-y，三层变两层
  3. 剪枝：排序后若前缀和已超 target，break 掉内层
sort(a, a + n); // 排序后便于剪枝 for (int i = 0; i < n; i++) { if (a[i] > target) break; for (int j = i + 1; j < n; j++) { if (a[i] + a[j] > target) break; // 后续更大 for (int k = j + 1; k < n; k++) { if (a[i] + a[j] + a[k] > target) break; if (a[i] + a[j] + a[k] == target) { /* 输出 */ } } } }

剪枝条件别写反

升序时：sum > target 才 break；若 sum < target 应 continue 找更大 k，不能 break。

【讲解】三法宝配合百钱百鸡数字对比 100万→660。

五、经典例题：百钱百鸡

公鸡 5 文/只，母鸡 3 文/只，小鸡 1 文 3 只。100 文买 100 只，各多少？（可含 0）

朴素三层：约 100³=100 万次

for (x=0; x<=100; x++) for (y=0; y<=100; y++) for (z=0; z<=100; z++) if (x+y+z==100 && 5*x+3*y+z/3==100 && z%3==0) cout << x<<y<<z;

优化两层：20×33=660 次

for (int x = 0; x <= 20; x++) { for (int y = 0; y <= 33; y++) { int z = 100 - x - y; if (z >= 0 && z % 3 == 0 && 5*x + 3*y + z/3 == 100) cout << x << " " << y << " " << z << endl; } }
解（含 0）： (0,25,75) (4,18,78) (8,11,81) (12,4,84) 等。优化到朴素的 0.066% 量级——数学分析带来数量级提升。
【讲解】对照程序 lesson25 演示 2-a / 2-b。

六、水仙花数 & 数字统计

水仙花数

三位数，各位立方和等于自身。如 153=1³+5³+3³。

for (int num = 100; num <= 999; num++) { int a = num / 100; int b = (num / 10) % 10; int c = num % 10; if (a*a*a + b*b*b + c*c*c == num) cout << num << endl; } // 输出：153 370 371 407

数字统计

统计 [L,R] 中数字 2 出现次数（22 计 2 次）。

int countDigit(int n, int d) { int cnt = 0; while (n > 0) { if (n % 10 == d) cnt++; n /= 10; } return cnt; } // 外层 for i=L..R 累加

O((R-L)·log₁₀ R)。R≤10⁵ 足够；10⁹ 级需数位 DP（超纲）。

【讲解】拆位通用：%10 取最低位，/10 去掉。

七、代码模板汇总

// 模板1：质数（单层优化） bool isPrime(int n) { if (n < 2) return false; for (int i = 2; i * i <= n; i++) if (n % i == 0) return false; return true; } // 模板2：百钱百鸡（两层优化） for (int cock = 0; cock <= 20; cock++) for (int hen = 0; hen <= 33; hen++) { int chick = 100 - cock - hen; if (chick >= 0 && chick % 3 == 0 && 5*cock + 3*hen + chick/3 == 100) cout << cock << " " << hen << " " << chick << endl; } // 模板3：区间数字统计 int ans = 0; for (int i = L; i <= R; i++) ans += countDigitInNum(i, 2);
【讲解】让学生默写 isPrime 与 chick%3 条件。

八、五大易错点

1. 枚举边界错误

公鸡写成 ≤100 而非 ≤20；质数写成 i≤n。写循环前先草稿纸定界。

2. 忘记整除条件

小鸡必须 chick % 3 == 0，否则 chick/3 整数截断导致假解。

3. 重复 / 遗漏枚举

双层从 j=0 会重复 (i,j)(j,i)。无序组合：内层从 j=i+1 开始。

4. sqrt 精度

一律 i*i <= n，不用 i <= sqrt(n)。

5. 剪枝条件写反

升序数组：sum > target 才 break；小于时应继续找更大元素。

【讲解】易错页：每条举反例 10 秒。

九、真题精练①：买铅笔（CSP-J 2016）

需要 n 支铅笔；3 种包装（数量 cnt、单价 price）；只买同一种且不拆包，求最少花费。

输入：
57
2 2
50 30
30 27
输出： 54
int n; cin >> n; int ans = 1e9; for (int i = 0; i < 3; i++) { int cnt, price; cin >> cnt >> price; int packs = (n % cnt == 0) ? n / cnt : n / cnt + 1; // 向上取整 ans = min(ans, packs * price); } cout << ans << endl;
解析：枚举 3 种包装；包数 = ⌈n/cnt⌉。样例：包装 30 支 27 元，买 2 包=60 支，花费 54 最优。
【练习】先独立想 1 分钟再讲向上取整。

十、真题精练②：质因数分解

n 是两个不同质数之积（2≤n≤10⁹），求较大那个质数。

输入： 21　输出： 7
long long n; cin >> n; for (long long i = 2; i * i <= n; i++) { if (n % i == 0) { cout << n / i << endl; // i 较小，n/i 较大 break; } }
  • 从 2 起第一个因子必为较小质因数（合数因子会先被其质因子除尽）
  • 必须用 long long：i*i 可达 10¹⁸
  • 时间 O(√n)≈3×10⁴，轻松通过
【练习】强调 long long 与无需 isPrime 的巧妙点。

十一、何时用枚举？复杂度速查

场景特征策略
n 小、有明确判定条件直接枚举
变量间有等式关系消元减层
有单价/容量等上界缩小范围
数组有序或可排序剪枝 break
题目说「找所有…」「是否存在…」优先想枚举
一句话：枚举的智慧不是穷尽所有数字，而是精准打击可能区域——先想清对象、范围、约束，再动手写循环。

考试三步走

  1. 确定枚举对象（排列/组合/子集/数值）
  2. 估计复杂度是否超时
  3. 找数学性质剪枝优化
【讲解】过渡到下节：排列、子集、回溯。
