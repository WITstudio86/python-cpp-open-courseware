一、做题策略：先易后难

第二轮通常 4 题 / 2 小时（以当年通知为准），总分 400。

  1. 开考 5 分钟通读全部题目，标定难度
  2. 按「有把握优先」排序，不固执按题号
  3. 简单题 20′ 内搞定；中等 30′；难 35–40′
  4. 思考 >10 分钟无思路 → 跳过
会做的全做对 · 不会的拿部分分 · 绝不空白交卷
题号难度不一定严格递增。

  1. cerr 打印：不影响 freopen 文件输出
  2. assert：检查下标、假设
  3. 对拍：暴力 vs 优化，随机小数据

四、freopen 与文件 IO

int main() { freopen("candy.in", "r", stdin); freopen("candy.out", "w", stdout); // 业务代码 return 0; }
最冤 0 分：文件名写错、只写输入不写输出、调试注释掉 freopen 忘记恢复。文件名与题目一字不差。
  • 本地调试：建同名 .in 文件，或用 LOCAL 宏切换
  • 程序「卡住」其实在等文件输入——正常
模板第一行就写 freopen。

七、心态与考场事务

  • 卡题正常：重新读题 → 暴力 → 子任务 → 特殊输出
  • 深呼吸，不因一题毁掉全场
  • 物品：准考证×2、证件、笔；草稿纸考场发
  • 环境：Dev-C++ / Code::Blocks，熟悉快捷键
  • 每题写完立即存盘；文件夹按题目命名
  • 最后 5 分钟：检查 freopen、删调试、备份代码
提交前 30 秒清单：文件名 · freopen · 样例 · 数组大小 · 调试输出
考前一天别熬夜刷难题。

九、真题思路1：分糖果（2021）

题意简述：n 人围圈，从 L 到 R 分糖，每人糖果数 = 编号 % n 相关；问区间内最多分到多少。

思路：最大值理论为 n-1。若 [L,R] 跨过完整模 n 周期，答案 n-1；否则为 R%n。禁止暴力循环到 1e9。
long long n, L, R; cin >> n >> L >> R; if (L / n != R / n || R - L >= n - 1) cout << n - 1 << endl; else cout << R % n << endl;
强调 freopen candy.in/out。

十、真题思路2：直播获奖类

典型考察：排序 + 名次/阈值统计 + 边界（并列、阈值阈值阈值阈值）。

通用套路：读入 → 排序（注意稳定/自定义比较）→ 扫一遍统计答案 → 注意 long long 与下标从 0/1。
  • 先保证样例全过
  • 再想 n=1、全相同、已有序等边界
  • 数据大时 sort O(n log n) 即可，别 O(n²)
具体题面以当年真题为准，课上讲策略。

考场通常不能长时间对拍，考前在家练熟流程。
本地脚本化可节省时间。

十二、开考到交卷流程

  1. 建文件夹，四题四个 cpp
  2. 通读 → 排序做题顺序
  3. 写 freopen → 编码 → 本地样例
  4. 边界手测 → 保存
  5. 难题暴力/部分分
  6. 最后检查 freopen 与调试输出
  7. 备份代码
宁可少做一题难题，也不要简单题 WA 丢 100 分。
强调「简单题全对」是获奖基础。
