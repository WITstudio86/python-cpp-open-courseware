考试策略

先易后难原则

  • 快速浏览 4 道题目，评估每道题的难度和把握度
  • 优先完成最有把握的题目，建立信心和分数基础
  • 难题放到后面攻克，不要在难题上消耗过多时间

题目阅读技巧

  • 仔细读题至少两遍，圈出关键条件和数据范围
  • 注意输入输出格式、样例解释，理解题意后再动手
  • 数据范围决定算法选择：n ≤ 100 → O(n³), n ≤ 10&sup5; → O(n log n)

时间分配方案

题目 建议时间 难度 策略
第 1 题 30 分钟 较简单 稳拿满分，仔细检查
第 2 题 30 分钟 中等 争取满分，注意边界
第 3 题 30 分钟 中等偏难 保部分分，争满分
第 4 题 30 分钟 较难 部分分策略，不恋战

部分分策略

  • 暴力法：n 较小时直接枚举所有情况
  • 特殊性质：利用题目给定的特殊条件简化问题
  • 小数据：部分测试点数据规模小，暴力可过
不要在一道题上死磕超过 40 分钟！超过时间果断跳过，回头再做往往有新的思路。

时间管理

各时间段详细计划

时间段 任务 注意事项
0 - 5 分钟 快速浏览所有题目 评估难度，确定做题顺序
5 - 35 分钟 完成第 1 题 仔细读题，一遍过，写 freopen
35 - 65 分钟 完成第 2 题 注意数据类型，避免 int 溢出
65 - 95 分钟 完成第 3 题 复杂题先写暴力保底，再优化
95 - 120 分钟 攻克第 4 题 + 全面检查 争取部分分，检查文件 I/O

最后检查清单

📁 文件保存
确认所有 .cpp 文件已保存
📝 文件名正确
按题目要求命名（如 task1.cpp）
📂 freopen 检查
每道题都要写 freopen，文件名与题目一致
🔍 样例测试
用题目样例验证程序输出是否匹配
最后 5 分钟检查所有题目的文件输入输出！freopen 文件名写错直接 0 分！

调试技巧

打印调试法

  • 使用 cerr 输出中间变量，提交到 OJ 时不会影响评测结果
  • 打印关键变量的值、循环次数、分支走向

assert 断言

  • 用 assert(condition) 验证中间条件是否成立
  • 数组下标、变量范围、不变量检查
  • 在评测机上 assert 失败会导致 RE，提交前记得注释掉

小数据对拍

  • 写一个暴力程序（保证正确）和一个优化程序
  • 用脚本生成随机小数据，对比两个程序的输出
  • 发现不一致时，缩小数据范围定位 bug

二分错误定位

  • 注释掉一半代码，快速判断 bug 在前半还是后半
  • 逐步缩小范围，直到定位到具体行
#include <iostream>
using namespace std;

#define DEBUG(x) cerr << "[DEBUG] " << #x << " = " << (x) << endl

int main() {
    int n = 100;
    long long sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
        DEBUG(i);      // 打印循环变量
        DEBUG(sum);    // 打印累加和
        assert(sum >= 0);  // 断言和为非负
    }
    cout << sum << endl;
    return 0;
}
调试完记得删除或注释掉调试输出！cerr 虽不影响结果，但过多的输出可能拖慢程序。

常见陷阱

以下是 CSP-J 考试中最常见的失分陷阱，每一条都可能让你丢掉宝贵的分数。

  1. 数组越界 — 访问 a[n] 或负数下标导致 RE 开数组时多开 10 个单位：int a[100010];
  2. 未初始化变量 — 局部变量值是随机的 全局变量自动为 0；局部变量声明时初始化：int ans = 0;
  3. int 溢出 — int 范围约 ±2.1×10&sup9; 超过 2×10&sup9; 就用 long long，养成习惯
  4. 多组数据未清零 — 上一组数据残留影响结果 用 memset 或循环重新初始化所有数组和变量
  5. freopen 未写或写错 — 最冤枉的 0 分方式 每道题第一时间写 freopen，复制题面中的文件名
  6. STL 使用不当 — priority_queue 默认大顶堆，vector 未 resize 小顶堆：priority_queue<int, vector<int>, greater<int>>
  7. 0-index 与 1-index 混淆 — for 循环边界搞错 统一风格：输入从 1 开始，数组开 n+5
以上 7 条是历年考生失分最多的原因！考前逐条检查，确保万无一失。

历年真题精选

回顾近年 CSP-J 经典题目，理解命题思路和解题关键。

年份 / 题目 考察内容 关键思路
2022 · 乘方 溢出判断、数学推导 不需要真正算 ab，判断是否超过 109 即可。用对数或循环提前终止，考察"快速幂思维"但不要求实现快速幂。
2021 · 分糖果 数学推导、O(1) 算法 不需要模拟分糖果过程。利用模运算性质，直接 O(1) 计算答案。数据范围大到无法模拟，必须数学推导。
2020 · 直播获奖 桶排序、计数统计 成绩范围仅 0~600，用桶计数代替排序。每次查询分数线时从高到低遍历桶，利用成绩范围小的特点将 O(n log n) 降为 O(600)。
2019 · 公交换乘 队列、滑动窗口 优惠时间 45 分钟构成滑动窗口。用队列维护有效车票，过期则出队。贪心选择最早可用的优惠票。

命题趋势总结

  • 数学化：越来越多的题目需要数学推导优化
  • 数据范围大：暴力模拟通常只能拿部分分
  • 考察思维：重在算法设计而非代码量
CSP-J 题目往往有数学优化方法，不要只想着暴力模拟！读题时多思考数据范围背后的提示。

心态调整

考前准备

  • 充足睡眠：考试前一晚保证 8 小时睡眠，不要熬夜刷题
  • 清淡饮食：考试当天早餐吃饱但不过饱，避免考试时犯困
  • 提前到场：至少提前 30 分钟到达考点，熟悉考场环境

遇到不会的题怎么办？

  • 先深呼吸 3 次，告诉自己"大家都会觉得难"
  • 果断跳过，先做后面的题，回头再看往往豁然开朗
  • 即使不会完整解法，也要写部分分：暴力、特殊数据、输出样例

保持节奏感

  • 每完成一题在心里给自己一个正反馈："很好，又拿下一题！"
  • 不要受周围人敲键盘速度的影响，按自己的节奏来
  • 把考试当作一次限时训练，减少紧张感
