第11课：while 与 do-while 循环

先判断 or 先执行？两种循环的奥秘
CSP-J 备考课程 | 循环结构（二） | 考纲要求：掌握 while 与 do-while 循环

一、while 循环：先判断，后执行

语法格式

while (条件表达式) { // 循环体：条件为 true 时执行 } // 条件为 false 时跳出循环

执行流程图

┌──────────┐ │ 进入循环 │ └────┬─────┘ ▼ ┌──────────┐ false ◄───│ 判断条件？├────────┐ │ └────┬─────┘ │ │ true │ ▼ │ ▼ ┌──────────┐ │ ┌──────────┐ │ 跳出循环 │ │ │ 执行循环体│ └──────────┘ │ └────┬─────┘ │ │ └────────┘

关键特性

  • 条件为 false 时，循环体一次都不执行
  • 适合"不知道要循环几次，但有明确停止条件"的场景
  • 循环变量必须朝着使条件变为 false 的方向变化
考试技巧：统计数字位数、数字反转、辗转相除法等"未知次数"场景，优先考虑 while 循环。

二、do-while 循环：先执行，后判断

语法格式

do { // 循环体：至少执行一次 } while (条件表达式); // ⚠️ 分号不可省略！

执行流程图

┌──────────┐ │ 进入循环 │ └────┬─────┘ ▼ ┌──────────┐ ┌──►│ 执行循环体│ │ └────┬─────┘ │ ▼ │ ┌──────────┐ false │ │ 判断条件？├────────┐ │ └────┬─────┘ │ │ true │ ▼ └────────┘ ┌──────────┐ │ 跳出循环 │ └──────────┘

经典应用：输入校验

int age; do { cout << "请输入年龄（0-120）："; cin >> age; } while (age < 0 || age > 120); // 走到这里时，age 一定在合法范围内
考试技巧：看到"至少执行一次""反复输入直到合法""菜单至少显示一次"等描述，优先考虑 do-while。

三、while vs do-while 核心对比

对比维度 while do-while
判断时机 先判断，后执行 先执行，后判断
最少执行次数 0 次 1 次
分号 不需要 while(条件); 必须加分号
适用场景 可能一次都不需要执行 至少需要执行一次

行为对比代码

while：条件 false → 0次

int n = 0; while (n > 0) { cout << "执行了"; } // 不输出任何内容

do-while：条件 false → 1次

int n = 0; do { cout << "执行了"; } while (n > 0); // 输出一次 "执行了"
高频易错：do-while 结尾的 while(条件); 分号不能省略，这是 CSP-J 选择题的经典考点！

四、真题精练

真题1：数字反转（while）

给定正整数 N，将其各位数字反转后输出。如 123 → 321，120 → 21（无前导零）。

int n, rev = 0; cin >> n; while (n > 0) { int digit = n % 10; // 取出最后一位 rev = rev * 10 + digit; // 拼接到反转结果 n /= 10; // 去掉最后一位 } cout << rev << endl;

真题2：密码校验（do-while）

密码要求：6~16位，不能全数字。反复输入直到合法。

string password; bool valid; do { valid = true; cin >> password; if (password.length() < 6) { cout << "长度不足!" << endl; valid = false; } else if (password.length() > 16) { cout << "长度超出!" << endl; valid = false; } } while (!valid); cout << "密码设置成功" << endl;
复习要点：真题1重点考查"未知循环次数"场景下 while 的使用；真题2重点考查 do-while "至少执行一次"的语义和输入校验模式。

五、本课小结

学习要点核心记忆
while 执行流程先判断 → 条件为真才执行 → 可能一次都不执行
do-while 执行流程先执行 → 再判断 → 至少执行一次
do-while 语法细节while(条件); 分号不能省略
循环条件设计确保条件最终为 false，循环变量要朝终止方向变化
死循环原因忘记更新循环变量 / 更新方向错误 / 浮点数精度
适用场景已知次数用 for，未知次数用 while，至少一次用 do-while
EOF 读入while(cin >> x) 是经典写法

易错点速记

⚠️ while 条件永远为真 → 死循环
⚠️ 忘记更新循环变量 → 死循环
⚠️ do-while 后分号遗漏 → 编译错误
⚠️ 混淆 while 和 do-while 执行次数
课后练习建议： ① 手动模拟数字反转的每一步 ② 写出三种循环（for/while/do-while）各自最适合的场景 ③ 上机验证 do-while 结尾分号遗漏的编译报错信息
