一、while 循环：先判断，后执行

while (条件表达式) { // 循环体：条件为 true 时执行 } // 条件为 false 时跳出
判断条件？ ──false──► 跳出 │ true ▼ 执行循环体 ──► 再判断 …
关键： 条件一开始就为 false → 循环体一次都不执行。
int i = 10, sum = 0; while (i <= 5) { // 一开始 false sum += i; i++; } cout << sum; // 输出 0
【讲解】while 流程 强调最少 0 次。

while 典型应用：统计数字位数

不知道有多少位（未知次数），但知道「只要 n>0 就还有位」——用 while。

int n = 12345; int cnt = 0; while (n > 0) { cnt++; // 位数 +1 n /= 10; // 去掉最后一位 } cout << cnt; // 输出 5
过程： 12345→1234→123→12→1→0，共 5 次。注意 n=0 需特判为 1 位。
// 模板：保留原数，用 temp 操作 int temp = n, cnt = 0; if (n == 0) cnt = 1; else while (temp > 0) { cnt++; temp /= 10; }
【讲解】位数统计 手算 12345 拆位过程。

二、do-while 循环：先执行，后判断

do { // 循环体：至少执行一次 } while (条件表达式); // ⚠️ 分号不能省！
执行循环体 │ 判断条件？ ──false──► 跳出 │ true └──► 再执行循环体 …
关键： 无论条件如何，循环体至少执行一次。
int i = 10, sum = 0; do { sum += i; // 会执行 i++; } while (i <= 5); // 之后条件 false cout << sum; // 输出 10
【讲解】do-while 与 while 对比：同样 i=10，结果 10 vs 0。

do-while 典型：输入校验 / 菜单

输入校验

int age; do { cout << "年龄(0-120):"; cin >> age; } while (age < 0 || age > 120); // 此处 age 合法

菜单循环

int choice; do { cout << "1.A 2.B 0.退出"; cin >> choice; // 处理选项 } while (choice != 0);
语义匹配： 「至少让用户操作一次，再看是否继续」→ do-while 最自然。
【讲解】校验与菜单 配套程序 demo4、demo5。

三、while 与 do-while 核心对比

对比维度whiledo-while
判断时机先判断后执行先执行后判断
最少执行次数0 次1 次
分号条件后无分号while(条件); 必须有分号
适用可能一次都不做至少需要做一次

while（n=0）

while (n > 0) { cout << "while"; } // 不输出

do-while（n=0）

do { cout << "do-while"; } while (n > 0); // 输出一次
【讲解】对比 选择题常考：条件同是否执行次数同？答：否。

四、循环条件设计原则

  1. 循环变量必须朝使条件变 false 的方向变化
  2. 条件中的变量必须在循环体内被修改
  3. EOF 读入用 while：while (cin >> x)
错误： 忘记 x-- / 忘记 sum += x → 死循环。
// ✅ 正确：x 递减 int x = 10; while (x > 0) { cout << x << " "; x--; } // ✅ EOF 累加 int x, sum = 0; while (cin >> x) { sum += x; }
【讲解】条件设计 板书「朝终止方向变化」。

五、死循环的识别与避免

类型示例原因对策
忘记更新变量while 内无 i++检查条件相关变量
更新方向错误i>0 却 i++核对增减方向
浮点精度x != 1.0 永不真用整数计数或范围
while(true)无 break 出口必须有明确退出
// while(true) + break 合法模式 while (true) { int x; cin >> x; if (x == -1) break; cout << x * 2 << endl; }
考试： 读代码时若条件中变量在循环内不变，优先怀疑死循环。
【讲解】死循环 演示 while(true)+break，不真跑死循环。

六、while / for / do-while 适用场景

场景推荐原因

未知次数有终止条件while关注条件即可

// 位数 → while；菜单 → do-while；1~n → for for (int i = 1; i <= n; i++) cout << i; while (n > 0) { cnt++; n /= 10; } do { cin >> choice; } while (choice != 0);
【讲解】场景 考场看到题干关键词选型。

代码模板

模板1：while 读到 EOF 累加

#include <iostream> using namespace std; int main() { int x, sum = 0; while (cin >> x) sum += x; cout << sum << endl; return 0; }

模板2：do-while 成绩校验

int score; do { cout << "成绩(0-100):"; cin >> score; if (score < 0 || score > 100) cout << "不合法，请重输！" << endl; } while (score < 0 || score > 100); cout << "有效：" << score << endl;
【讲解】模板 强调 do-while 末尾分号。

模板3：位数 + 易错点

#include <iostream> using namespace std; int main() { int n; cin >> n; if (n == 0) { cout << "1 位" << endl; return 0; } int cnt = 0, temp = n; while (temp > 0) { cnt++; temp /= 10; } cout << n << " 是 " << cnt << " 位数" << endl; return 0; }
易错1： 忘记更新循环变量 → 死循环
易错2： 条件中的 n 忘了 n/=10
易错3： do-while 漏写分号 → 编译错误
易错4： 混淆最少次数：while 可为 0，do-while 至少 1
【讲解】易错点 选择题：do-while 分号；最少次数。

真题1：数字反转（while）

题目

给定正整数 N，各位反转输出。前导零不输出（120 → 21）。1 ≤ N ≤ 109。

样例：123 → 321；120 → 21

#include <iostream> using namespace std; int main() { int n; cin >> n; int rev = 0; while (n > 0) { int digit = n % 10; // 取末位 rev = rev * 10 + digit; // 拼到 rev n /= 10; // 去末位 } cout << rev << endl; return 0; }
解析： 120：rev=0→2→21，末尾 0 自然丢弃。未知位数 → while。
【练习】真题1 板书 120 三步反转。

真题2：密码校验（do-while）+ 小结

密码长度 6~16，且不能全数字；反复输入直至合法。

#include <iostream> #include <string> #include <cctype> using namespace std; bool isAllDigit(const string& s) { for (char c : s) if (!isdigit(c)) return false; return true; } int main() { string password; bool valid; do { valid = true; cin >> password; if (password.length() < 6) { cout << "密码长度不足，请重新输入！" << endl; valid = false; } else if (password.length() > 16) { cout << "密码长度超出，请重新输入！" << endl; valid = false; } else if (isAllDigit(password)) { cout << "密码不能全为数字，请重新输入！" << endl; valid = false; } } while (!valid); cout << "密码设置成功" << endl; return 0; }
while：先判后做，可 0 次
do-while：先做后判，至少 1 次；分号必写
条件设计：变量朝终止方向变
选型：已知 for / 未知 while / 至少一次 do
