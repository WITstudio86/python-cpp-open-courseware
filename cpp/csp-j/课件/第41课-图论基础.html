一、考纲目标 & 什么是图

知识点要求
图的定义理解顶点、边，G=(V,E)
分类有向/无向、带权/无权
邻接矩阵 / 邻接表掌握建图、判边、遍历邻点
度、路径、连通概念清晰，能统计度数
遍历基础了解 DFS/BFS 与 vis（下两课展开）

图的定义

图由顶点集合 V 与边集合 E 构成：G = (V, E)

  • V：常编号 1..n（也有 0..n-1）
  • E：无向边 {u,v} 或有向边 (u,v)

可表示：道路、好友关系、超链接、课程先修、迷宫格子相邻……

做题第一步：点是什么？边是什么？有没有方向？有没有权？
强调抽象建模：先说清点边方向权，再写代码。

二、有向 / 无向 · 带权 / 无权

无向图：边无方向

vector<int> g[N]; g[u].push_back(v); g[v].push_back(u); // 必须双向

有向图：边有方向

g[u].push_back(v); // 只存一个方向
无向写两行，有向写一行
类型含义存储
无权只关心是否相连push(v) 或矩阵 0/1
带权距离 / 费用 / 时间{to,w} 或矩阵存权
struct Edge { int to, weight; }; vector<Edge> g[N]; g[u].push_back({v, w}); // 无向：再 g[v].push_back({u, w});
无权边代价常视为 1，最短路可用 BFS（第43课）。

三、基本术语扫盲

  • 自环：两端是同一顶点
  • 重边：同一对点之间多条边
  • 简单图：无自环、无重边（多数题默认）
  • 稀疏图：m 远小于 n²，如 m = O(n)
  • 稠密图：m 接近 n²
  • 完全图：任意两点都有边，无向边数 n(n-1)/2
CSP-J 多数题目：简单稀疏图 → 默认优先 邻接表。

其他概念：

  • 路径：相邻有边的顶点序列；长度常指边数
  • 简单路径：顶点不重复
  • 回路（环）：起点 = 终点
  • 连通（无向）：任意两点都有路径；连通块 = 极大连通子图
  • 强连通（有向）：任意两点互相可达
稀疏/稠密直接决定存储选型。

四、邻接矩阵

二维数组 g[i][j] 表示 i→j 是否有边（或边权）。

int g[1005][1005]; // 无权无向 g[u][v] = g[v][u] = 1; // 带权有向 g[u][v] = w; // 无边：0 或 INF memset(g, 0, sizeof(g));
优点缺点
判边 O(1)空间 O(n²)，n=1e4 易 MLE
代码短好写枚举邻点 O(n)，即使度数很小

适用：n ≤ 1000 左右，或需要频繁判边的稠密图。

注意：n > 5000 几乎不能开矩阵。最短路矩阵无边应是 INF 不是 0。
判边狂多 + n 小 → 矩阵很香。

五、邻接表（CSP-J 主力）

g[i] 存所有与 i 相邻的点（及边权）。

vector<int> g[N]; g[u].push_back(v); g[v].push_back(u); // 无向 for (int v : g[u]) { /* 遍历邻点 */ }
特性邻接矩阵邻接表
空间O(n²)O(n+m)
判边O(1)O(度)
遍历邻点O(n)O(度)
适用n≤1000 稠密/多判边n 大稀疏
选型口诀：n > 5000 几乎只能表；n ≤ 1000 且狂问「有没有边」→ 矩阵；其余默认邻接表。

链式前向星：竞赛进阶数组模拟邻接表；CSP-J 用 vector 足够。

链式前向星了解形态即可，不必深究。

六、顶点的度

无向图

  • 度 deg(v)：与 v 相连的边数
  • 握手定理：∑ deg(v) = 2|E|

有向图

  • 出度：从 v 出发的边数 · 入度：指向 v 的边数
  • ∑ 入度 = ∑ 出度 = |E|
int indeg[N], outdeg[N]; for (int u = 1; u <= n; u++) for (int v : g[u]) { outdeg[u]++; indeg[v]++; } // 无向：读边时 deg[u]++, deg[v]++
预告：拓扑排序依赖入度；欧拉路径看奇度点个数。
无向 ∑deg=2m，不是 m —— 易错！

七、路径 · 连通 · 遍历骨架

可达性：从 s 到 t → DFS/BFS + vis
连通块数：对每个未访问点开一次 DFS/BFS，次数即块数

方式思想结构下节
DFS一路走到底再回溯递归栈第42课
BFS按层扩展队列第43课
// DFS 骨架 void dfs(int u) { vis[u] = true; for (int v : g[u]) if (!vis[v]) dfs(v); } // BFS 骨架 void bfs(int s) { queue<int> q; q.push(s); vis[s] = true; while (!q.empty()) { int u = q.front(); q.pop(); for (int v : g[u]) if (!vis[v]) { vis[v] = true; q.push(v); } } }
共同点：必须有 vis，有环时否则死循环。
本课重点是存图；遍历下两课展开。

八、读图习惯 & 代码模板

常见输入：先 n m，再 m 行边（可能带 w）。注意：编号从 0/1？有向无向？是否连通？

const int N = 100005; vector<int> g[N]; cin >> n >> m; for (int i = 0; i < m; i++) { int u, v; cin >> u >> v; g[u].push_back(v); g[v].push_back(u); // 无向 } // 多组数据：for (i=1;i<=n;i++) g[i].clear();

带权邻接表 · 度数最大点

struct Edge { int to, weight; }; vector<Edge> g[N]; // 读边后： deg[u]++; deg[v]++; // 无向 // 最大度：用 > 更新，并列取编号最小
网格迷宫：格子是点，四连通是边；也可直接在网格上搜，不必显式建表。
调试可打印邻接表/矩阵，对查建图错误很有用。

九、易错点清单

  1. 无向图只存一边 → 遍历丢半张图
  2. 点编号 0/1 混用 → 数组开 N+5，统一 1..n
  3. n 大却开矩阵 → MLE，n>5000 优先表
  4. 度数误解：无向 ∑deg=2m，不是 m
  5. 有向当无向建（或反过来）
  6. 多组数据未 clear vector
  7. 遍历无 vis → 有环死循环
  8. 重边：矩阵覆盖；表会存多份
  9. 边权初始化：最短路矩阵无边 = INF 不是 0
自检：有向无向说清了吗？存储匹配 n 吗？读边 m 次？需要双向 push 吗？
考前把这份清单背熟，建图环节少一半错。

十、真题1：度数统计 · 题意与思路

题意：n 点 m 条无向边（1≤n≤1e5，m≤2e5）。输出每个点度数，以及度数最大的顶点编号（并列取编号最小）。

样例

输入： 5 4 1 2 2 3 3 4 4 5 输出： 1 2 2 2 1 2

deg=[1,2,2,2,1]，最大度 2，编号最小为 2。

思路：n=1e5 必须邻接表（或只开 deg 数组，甚至不必存边）。读边时 deg[u]++、deg[v]++；扫一遍输出；再用 > 更新最大值取最小编号。
若题意“任意一个最大度点”，2/3/4 均可；本题强调最小编号。

真题1 核心代码 · 真题2 判边

const int N = 100005; int deg[N]; int main() { int n, m; cin >> n >> m; for (int i = 0; i < m; i++) { int u, v; cin >> u >> v; deg[u]++; deg[v]++; } for (int i = 1; i <= n; i++) cout << deg[i] << (i == n ? '\n' : ' '); int maxDeg = -1, ans = 1; for (int i = 1; i <= n; i++) if (deg[i] > maxDeg) { maxDeg = deg[i]; ans = i; } cout << ans << endl; }

真题2：邻接矩阵判边

n≤1000 有向边 m 条，q 次询问是否存在 u→v。矩阵 O(1) 判边，只赋 g[u][v]=1。

int g[1005][1005]; // 读 m 条边 g[u][v]=1；询问 if(g[u][v]) Yes else No
题2样例：1→4 无、2→1 无、1→3 有。

十一、真题3：连通块计数（遍历预热）

题意：n 点 m 条无向边，求连通块个数（n≤1e5）。

思路：邻接表建图；对每个未访问点 DFS/BFS 一次，cnt++。

vector<int> g[N]; bool vis[N]; void dfs(int u) { vis[u] = true; for (int v : g[u]) if (!vis[v]) dfs(v); } int main() { // 无向建图后： int cnt = 0; for (int i = 1; i <= n; i++) if (!vis[i]) { dfs(i); cnt++; } cout << cnt << endl; }
链很长时递归可能爆栈，稳健写法用 BFS；CSP-J 常见规模多数可过。
为第42/43课做铺垫：存图不牢，搜索全塌。

十二、本课小结

  1. 图 = 点 + 边；先分清有向/无向、带权/无权
  2. 邻接矩阵：O(n²)，O(1) 判边，适合 n 小
  3. 邻接表：O(n+m)，稀疏大图主力，CSP-J 默认
  4. 度：无向 ∑deg=2m；有向 ∑in=∑out=m
  5. 路径/连通：为 DFS、BFS 做概念准备
  6. 易错：双向存、编号一致、大 n 不用矩阵、遍历要 vis
表存稀疏、阵存稠密；无向双边、有向单边；有 vis 才敢逛
