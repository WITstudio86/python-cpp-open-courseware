图论基础

Graph Theory Fundamentals

顶点 | 边 | 有向图 | 邻接矩阵 | 邻接表

一、图的定义与分类

图 G = (V, E) 由顶点集合 V 和边集合 E 构成。顶点编号通常从 1 到 n。

无向图

  • 边没有方向
  • (u, v) 等价于 (v, u)
  • 好比 双向道路
  • 存图需双向存储
// 无向图加边
g[u].push_back(v);
g[v].push_back(u);

有向图

  • 边有方向
  • (u, v) 只能 u → v
  • 好比 单行道
  • 只存一个方向
// 有向图加边
g[u].push_back(v);
考试要点

无向图的边数 m 如果很大（接近 n²），称为稠密图；边数很小（接近 n）则为稀疏图。存储方式的选择取决于图的稠密程度！

二、图的存储方式

这是 CSP-J 考试的重中之重！两种存储方式必须烂熟于心。

1. 邻接矩阵 g[i][j]

int g[1005][1005];
memset(g, 0, sizeof(g));
g[u][v] = 1;              // 无权图
g[u][v] = w;              // 带权图

判断边是否存在：if (g[u][v]) — O(1)

2. 邻接表 vector<int> g[N]

vector<int> g[N];
g[u].push_back(v);
// 遍历邻接点
for (int v : g[u]) { ... }
特性邻接矩阵邻接表
空间复杂度O(n²)O(n+m)
判断边O(1)O(度数)
遍历邻接点O(n)O(度数)
适用场景n ≤ 1000 稠密图n 可达 10⁵ 稀疏图
易错警告

如果 n = 100000 还用邻接矩阵 g[100000][100000]，内存直接爆炸（约 40GB）！必须用邻接表。

三、顶点的度与路径回路

顶点的度

  • 度 (Degree)：与该顶点相连的边数
  • 入度：指向该顶点的边数（有向图）
  • 出度：从该顶点出发的边数（有向图）
重要性质

无向图：度数之和 = 2m
有向图：入度和 = 出度和 = m

路径与回路

  • 路径：顶点序列 v₀→v₁→...→vₖ
  • 简单路径：顶点不重复
  • 回路（环）：起点 = 终点
  • 连通图：任意两点间有路径
// 计算入度和出度
int indeg[N] = {0}, outdeg[N] = {0};
for (int u = 1; u <= n; u++) {
    for (int v : g[u]) {
        outdeg[u]++;
        indeg[v]++;
    }
}

图的遍历是后续 DFS/BFS 算法的基础，需要用一个 bool vis[N] 数组标记已访问的顶点，防止重复访问和死循环。

四、真题精练 1：图的存储与度数统计

题目：给定一个包含 n 个顶点和 m 条边的无向图，输出每个顶点的度数，以及度数最大的顶点编号。

输入样例
5 4
1 2
2 3
3 4
4 5

输出：
1 2 2 2 1
3

// AC代码要点
for (int i = 0; i < m; i++) {
    int u, v; cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u);   // 无向图：双向存储！
    deg[u]++; deg[v]++;      // 度数+1
}
int maxDeg = -1, ans = 1;
for (int i = 1; i <= n; i++)
    if (deg[i] > maxDeg)
        maxDeg = deg[i], ans = i;
注意

有多解时输出编号最小的：因为代码中只在 deg[i] > maxDeg 时更新（不是 >=），所以自动保留了最小编号。

五、真题精练 2：邻接矩阵判断边

题目：给定一个有向图，q 次询问 u→v 是否有边。n ≤ 1000，因此适合使用邻接矩阵。

int g[1005][1005] = {0};
int n, m, q; cin >> n >> m >> q;

// 读入边
for (int i = 0; i < m; i++) {
    int u, v; cin >> u >> v;
    g[u][v] = 1;              // 有向图只存一个方向
}

// 处理询问
while (q--) {
    int u, v; cin >> u >> v;
    if (g[u][v]) cout << "Yes" << endl;
    else cout << "No" << endl;
}
选择策略总结
条件选择
n > 5000（稀疏图）✅ 邻接表 vector
n ≤ 1000 且频繁判边✅ 邻接矩阵 g[i][j]
n ≤ 1000 且只需遍历✅ 两者皆可

六、本课小结

  • 图的构成：顶点 V + 边 E，记作 G = (V, E)
  • 四种分类：有向/无向、带权/无权
  • 邻接矩阵 g[i][j]：空间 O(n²)，判边 O(1)，适合稠密图
  • 邻接表 vector g[N]：空间 O(n+m)，适合稀疏图（绝大多数情况）
  • 顶点的度：入度/出度，总度数 = 2m（无向图）
  • 路径与回路：连通性判断是图遍历的基础
  • 选择铁律：n > 5000 必用邻接表；n ≤ 1000 且需频繁判边用邻接矩阵
