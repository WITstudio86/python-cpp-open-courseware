【开场】指针=存门牌号的纸条。

考纲与内存地址

知识点要求
指针概念存储地址的变量
& 取地址 / * 解引用掌握
指针与数组arr[i] ⇔ *(arr+i)
指针运算 / 传地址掌握
空指针安全nullptr，解引用前检查
内存像储物柜；变量占若干柜；地址=首柜编号；指针=写着编号的纸条。
【讲解】画 a 与 p 关系图。

一、指针变量

int *p; // 指向 int 的指针 double *q; int a = 42; p = &a; // p 存 a 的地址 cout << a << endl; // 42 值 cout << &a << endl; // a 的地址 cout << p << endl; // 同 &a cout << &p << endl; // p 自己也有地址
声明里的 * 表示「这是指针类型」；与后文解引用 * 同符号不同义。
【讲解】p 是变量，也占内存。

二、& 与 * 运算符

取地址 &

int a = 10; int *p = &a; // 合法 // &10 非法 // &(a+1) 非法

解引用 *

int x = 100; int *ptr = &x; cout << *ptr; // 100 *ptr = 200; // x 变 200
上下文含义
int *p;声明：p 是指针
*p（表达式）访问指向的值
【讲解】通过指针修改与直接改 a 等价。

三、指针与数组

int arr[5] = {10, 20, 30, 40, 50}; int *p = arr; // 等价 &arr[0] // arr[i] ⇔ *(arr+i) ⇔ p[i] ⇔ *(p+i)
  • 数组名多数场合退化为首元素指针
  • 数组名是常量，不能 arr = p;
  • sizeof(arr) 是整数组字节数；sizeof(p) 是指针大小
核心等式：arr[i] ≡ *(arr + i) —— 下标从 0 起的原因。
【讲解】四种访问 arr[2] 写法。

四、指针运算

p + n：地址增加 n × sizeof(指向类型) 字节（按元素移动）。

int arr[5] = {10, 20, 30, 40, 50}; for (int *p = arr; p < arr + 5; p++) cout << *p << " "; // p2 - p1：同类型指针元素个数差 int *p1 = &arr[1], *p2 = &arr[4]; cout << p2 - p1; // 3
允许：+n -n ++ -- 同类型相减。禁止：指针乘除、异类型相减。
【讲解】int* +1 跨 4 字节。

五、指针与函数

void swap_ptr(int *a, int *b) { int t = *a; *a = *b; *b = t; } // 调用：swap_ptr(&x, &y); void doubleArray(int *arr, int n) { for (int i = 0; i < n; i++) *(arr + i) *= 2; }
传地址可改实参。引用版 void swap(int& a,int& b) 更简洁；两者都要会。
【讲解】对比值传递改不动 x,y。

六、空指针

int *p = nullptr; // C++11 推荐 int *q = NULL; // 传统 if (p != nullptr) cout << *p; else cout << "空指针不可解引用";
  • 初始化为「无效」状态，避免野指针
  • 解引用空指针 → 崩溃
  • 安全准则：声明即初始化；用前检查；勿返回局部变量地址
【讲解】野指针危害。

七、CSP-J 常见指针模式

// 1 指针找最大：维护 maxPtr int *maxPtr = arr; for (int *p = arr + 1; p < arr + n; p++) if (*p > *maxPtr) maxPtr = p; // 2 双指针原地反转 int *L = arr, *R = arr + n - 1; while (L < R) { /* swap *L *R; L++; R--; */ } // 3 C 字符串：while (*s) { cout<<*s; s++; }
下标 = 指针差：位置 maxPtr - arr
【讲解】为真题铺垫。

代码模板

// 模板1：基础 & * int a = 42; int *p = &a; *p = 100; // 模板2：指针参数交换 + 数组放大 void swap_ptr(int *a, int *b); void doubleArray(int *arr, int n);
配套程序含声明、数组遍历、函数参数完整演示。
【讲解】对照 lesson22.cpp。

易错点

1. 声明 * 与解引用 * 混淆
2. 解引用未初始化指针（野指针）→ 未定义行为
3. 误以为 p+1 只加 1 字节（实际加 sizeof）
4. 把数组名当可写左值 arr=p;
5. 返回局部变量指针 → 悬空
int *p; // ❌ 未初始化 int *q = nullptr; // ✅ // int* f(){ int x=1; return &x; } // ❌ 悬空
【讲解】竞赛中少用 new，先掌握栈上指针。

真题1：指针找最大最小值

题目

N 个整数，用指针找 max/min 及下标（最先出现）。要求搜索过程用指针。

样例：3 7 2 8 1 9 → Max:9(位置:5) Min:1(位置:4)

int *maxPtr = arr, *minPtr = arr; for (int *p = arr + 1; p < arr + n; p++) { if (*p > *maxPtr) maxPtr = p; if (*p < *minPtr) minPtr = p; } cout << "Max: " << *maxPtr << " (位置: " << maxPtr - arr << ")" << endl;
【练习】完整输入输出见讲义。

真题2：指针原地反转数组

题目

N 个整数原地反转，禁止新数组。样例：1 2 3 4 5 → 5 4 3 2 1

void reverse(int *arr, int n) { int *left = arr, *right = arr + n - 1; while (left < right) { int t = *left; *left = *right; *right = t; left++; right--; } }
双指针向中间夹逼，O(n) 时间 O(1) 额外空间。
【练习】手模拟 5 元素交换 2 次。
