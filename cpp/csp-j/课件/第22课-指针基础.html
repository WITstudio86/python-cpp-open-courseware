内存地址 —— 变量的「门牌号」

计算机中每个变量都占据一块内存空间，每个字节都有唯一的地址（Address）。

类比：内存就像一排排储物柜，地址就是柜子的编号。指针是一张写着柜子编号的纸条。
int a = 42; // a 的值是 42 // a 的地址可能是 0x7ffeedb5a9bc // a 占用 4 个字节（取决于系统和编译器）
概念说明
内存地址变量在内存中的起始位置编号（十六进制表示）
指针变量存储「地址」这个数值的特殊变量
解引用通过地址访问该地址中存储的数据
【讲解】内存地址 —— 变量的「门牌号」 本页要点（照着讲即可）： · 计算机中每个变量都占据一块内存空间，每个字节都有唯一的 地址 （Address）。 · 内存地址 · 指针变量 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：指针概念/&/*运算符、指针与数组、指针与函数

指针变量 —— 存储地址的变量

声明语法

int *p; // 指向 int 的指针 double *q; // 指向 double 的指针 char *r; // 指向 char 的指针

声明中的 * 表示「这是一个指针类型」

取地址与解引用

int a = 42; int *p = &a // & → 取地址 cout << *p; // * → 解引用，输出 42 *p = 100; // 通过指针修改 a cout << a; // 输出 100
核心记忆：& 是取地址（address-of），* 是解引用（dereference）。
注意：声明中的 * 和表达式中的 * 含义不同！
【讲解】指针变量 —— 存储地址的变量 结合讲义《2. 指针变量》强调： · 指针变量（简称指针）是一种特殊的变量，它不存储普通的数据（如整数、字符），而是**存储另一个变量的内存地址**。 · 声明语法： · 数据类型 *指针变量名; · int *p; // p 是一个指向 int 类型变量的指针 · double *q; // q 是一个指向 double 类型变量的指针 幻灯片上可见要点： · 声明中的 * 表示「这是一个指针类型」 · 核心记忆： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

出现位置含义示例

表达式中
*p		 * 是解引用运算符

指针与数组 —— 核心对应关系

核心等式：arr[i] 完全等价于 *(arr + i) —— 这解释了下标从 0 开始的原因！

数组名 = 首地址

int arr[5] = {10,20,30,40,50}; // arr 等价于 &arr[0] int *p = arr; // p 指向 arr[0]

访问数组元素

方式代码值
下标arr[2]30
指针+偏移*(arr+2)30
指针下标p[2]30

关键区别：数组名是常量，不能修改（arr = p; ❌）；指针是变量，可以重新指向（p = arr; ✅）。

指针运算 —— 不是简单的加减

指针加 n，地址值实际增加 n * sizeof(指向的类型) 个字节。

int *p; // sizeof(int) = 4 → p+1 地址 +4 double *q; // sizeof(double) = 8 → q+1 地址 +8 char *r; // sizeof(char) = 1 → r+1 地址 +1
运算含义示例
p + n向后移动 n 个元素p + 3 → 第 4 个元素
p - n向前移动 n 个元素p - 1 → 前一个元素
p++移动到下一个元素常用于遍历数组
p2 - p1两指针间的元素个数计算下标差
// 用指针遍历数组 for (int *p = arr; p < arr + n; p++) { cout << *p << " "; }
【讲解】指针运算 —— 不是简单的加减 结合讲义《6. 指针运算》强调： · 指针可以进行加减运算，但规则与普通整数不同。 · 核心规则：指针加 n，地址值增加 n * sizeof(指向的类型) 个字节。 · 如果 p 是 int *（sizeof(int) = 4），那么 p + 1 会让地址增加 4 个字节 · 如果 p 是 double *（sizeof(double) = 8），那么 p + 1 会让地址增加 8 个字节 · 如果 p 是 char *（sizeof(char) = 1），那么 p + 1 会让地址增加 1 个字节 幻灯片上可见要点： · 指针加 n，地址值实际增加 n * sizeof(指向的类型) 个字节。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

指针与函数 —— 修改实参的利器

通过传递地址（指针），函数可以直接修改调用者的变量。

swap 函数（指针版）

void swap(int *a, int *b) { int temp = *a; *a = *b; *b = temp; } // 调用：swap(&x, &y);

修改数组（指针版）

void doubleArr(int *arr, int n) { for (int i = 0; i < n; i++) arr[i] *= 2; } // 调用：doubleArr(nums, 5);

空指针 —— 安全第一

int *p = nullptr; // C++11 推荐写法 int *q = NULL; // 传统写法（本质是 0） // 解引用前务必检查！ if (p != nullptr) { cout << *p; // 安全 ✅ } else { cout << "空指针！"; // 跳过解引用 }
危险！解引用空指针（*nullptr）会导致程序崩溃（段错误 SegFault）。这是 C++ 编程中最常见的运行时错误之一。

安全准则

  1. 声明指针时务必初始化（设为 nullptr 或有效地址）
  2. 解引用前检查是否为 nullptr
  3. 绝不返回指向局部变量的指针
【讲解】空指针 —— 安全第一 结合讲义《8. 空指针》强调： · 空指针是指不指向任何有效内存地址的指针。在 C++ 中，使用 nullptr（C++11 起推荐）或 NULL 来表示空指针。 · int *p = nullptr; // C++11 推荐写法 · int *q = NULL; // 传统写法（本质是 0） · 为什么需要空指针？ · 初始化指针为「空」状态，避免指向随机地址 幻灯片上可见要点： · 声明指针时 务必初始化 （设为 nullptr 或有效地址） · 务必初始化 · 解引用前 检查是否为 nullptr · 检查是否为 nullptr 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

代码模板

找最值（指针版）

int* findMax(int *arr, int n) { int *maxPtr = arr; for (int *p = arr+1; p < arr+n; p++) if (*p > *maxPtr) maxPtr = p; return maxPtr; // 返回值的指针 } // 位置 = pMax - arr

数组反转（指针版）

void reverse(int *arr, int n) { int *L = arr, *R = arr + n - 1; while (L < R) { int t = *L; *L = *R; *R = t; L++; R--; } }
技巧：指针相减 pEnd - pStart 得到的是它们之间元素个数，不是字节数。这个特性可以用来计算数组下标。

易错点总结

错误1：声明中的 * vs 解引用的 * 混淆
int *p = &a 的 * 表示指针类型；*p = 100; 的 * 是解引用操作。
错误2：解引用未初始化的「野指针」
int *p; *p = 10; ❌ —— p 未初始化，指向随机地址！应该 int *p = nullptr; 或 int *p = &a。
错误3：指针算术越界
int arr[5]; *(arr + 5) ❌ —— 有效索引是 0-4，arr + 5 指向数组之后。
错误4：忘记数组名是常量指针
arr++; ❌ —— 数组名不可修改！应该 int *p = arr; p++; ✅。
错误5：返回局部变量的指针
return &localVar ❌ —— 函数结束时局部变量被销毁，返回的指针变成「悬空指针」。
