## 📖 知识精讲

### 一、多重背包问题

**问题描述**：有N种物品和一个容量为W的背包。第i种物品的重量是w[i]，价值是v[i]，数量上限是c[i]。求最大价值。

多重背包介于01背包和完全背包之间——每种物品有确定的数量上限。这是背包问题中非常常见的一种变体。

**1. 朴素做法（三重循环）**

最直接的想法：把每种物品的数量限制直接体现在循环中。对于每种物品，我们枚举选取的个数k（0 ≤ k ≤ c[i]），然后像01背包一样倒序遍历容量。

```
dp[j] = max(dp[j], dp[j - k*w[i]] + k*v[i])  （k = 0, 1, 2, ..., c[i]）
```

```cpp
for (int i = 1; i <= N; i++) {
    for (int j = W; j >= 0; j--) {
        for (int k = 0; k <= c[i] && k * w[i] <= j; k++) {
            dp[j] = max(dp[j], dp[j - k * w[i]] + k * v[i]);
        }
    }
}
```

时间复杂度O(N * W * max(c[i]))，当c[i]较大的时候（例如c[i]达到10000），这个做法会超时。因此我们需要更高效的优化方法。

**2. 二进制优化（核心重点，考试必考）**

二进制优化是多重背包最重要的优化手段，也是CSP-J考试中的高频考点。核心思想非常巧妙：**将c[i]个相同物品拆分成若干个"打包"的物品，使得这些打包物品能够组合出0~c[i]之间的任意数量**。

为什么可以这样拆分？因为任何正整数都可以用二进制表示。例如：
- 数字7 = 1 + 2 + 4（恰好3个打包物品，可以组合出0~7的任何数）
- 数字13 = 1 + 2 + 4 + 6（4个打包物品，其中1,2,4可以组合0~7，加上6可以组合6~13，全部0~13都可表示）

**拆分代码的通用写法**：
```cpp
for (int k = 1; k <= c; k <<= 1) {  // k = 1, 2, 4, 8, ... 每次翻倍
    new_w[++cnt] = k * w;           // 打包k个物品的重量
    new_v[cnt] = k * v;             // 打包k个物品的价值
    c -= k;                          // 减去已拆分的数量
}
if (c > 0) {                         // 处理剩余部分（不够2^k的部分）
    new_w[++cnt] = c * w;
    new_v[cnt] = c * v;
}
```

**复杂度分析**：每种物品由O(c[i])降为O(log c[i])。例如c[i]=1000时，1000次循环变为log₂(1000)≈10次。拆分后总物品数由Σc[i]降为Σlog(c[i])，总时间复杂度O(W * Σlog(c[i]))，效率极高。

拆分后，问题就完美转化为了01背包——每个"打包物品"最多选一次，直接用倒序遍历容量的01背包一维DP即可求解。

### 二、分组背包问题

**问题描述**：有G组物品，每组内有若干物品。从每组中**最多选一个**物品放入背包。求最大价值。

**核心约束**：同一组内的物品互斥——选了组内物品A就不能选组内物品B。这是与普通背包最本质的区别。

**三层循环结构**（顺序至关重要！这是考试最容易出错的地方）：

```cpp
for (int g = 1; g <= G; g++) {           // 第一层：枚举组
    for (int j = W; j >= 0; j--) {        // 第二层：枚举容量（倒序）
        for (int k = 0; k < group[g].size(); k++) {  // 第三层：枚举组内物品
            int w = group[g][k].weight;
            int v = group[g][k].value;
            if (j >= w)
                dp[j] = max(dp[j], dp[j - w] + v);
        }
    }
}
```

**为什么容量循环必须在物品循环外面？**
这是分组背包最关键的理解点。如果物品循环在外面（即对于每个物品，遍历所有容量），那么同组内的多个物品可能在同一轮DP中被选中——因为dp[j - w1]被更新后，再处理物品2时可能会用到dp[j - w2]，但此时dp数组已经包含了物品1的信息。而把容量循环放在外面，意味着对于每个容量j，我们在所有物品中只选出最优的那一个来更新——这正好实现了"每组最多选一个"的约束。

**类比理解**：可以把分组背包想象成——对于第g组，容量j的背包从该组的cnt个物品中，选一个（或不选）放入。因为是倒序遍历容量，每个物品最多被选一次（01背包特性），加上容量外循环保证同组内只能有一个物品被选中。

**容量倒序的原因**：因为转化后本质上还是01背包——每个打包后的物品最多选一次，所以容量要倒序遍历。

### 三、区间DP基础

区间DP（Interval DP）是动态规划的一个重要分支，与线性DP不同，它的状态定义不再是一条线，而是一个区间。

**核心思想**：定义dp[i][j]表示区间[i, j]范围内的最优解。通过枚举区间内的分割点k，将大区间[i, j]分解为两个小区间[i, k]和[k+1, j]，先子问题，再合并。

**通用框架（三层循环）**：
```cpp
// 初始化：长度为1的区间（dp[i][i]）通常有明确的初始值
for (int i = 1; i <= N; i++) dp[i][i] = 初始值;

// 第一层：枚举区间长度（从小到大的顺序至关重要）
for (int len = 2; len <= N; len++) {
    // 第二层：枚举区间起点
    for (int i = 1; i + len - 1 <= N; i++) {
        int j = i + len - 1;  // 区间终点
        dp[i][j] = INF;       // 初始化为极值
        
        // 第三层：枚举分割点，将[i,j]分为[i,k]和[k+1,j]
        for (int k = i; k < j; k++) {
            dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + 合并代价);
        }
    }
}
```

**循环顺序为什么必须是len→i→k？**
- len必须在最外层：因为长区间的计算依赖于短区间。当len=x时，所有长度小于x的区间都已经计算完毕。dp[i][k]（长度为k-i+1）和dp[k+1][j]（长度为j-k）的长度都严格小于len，所以一定能保证子问题已经求解。
- i和k的顺序可以灵活：只要len在外层，i和k的内外层关系不影响正确性，但通常i在外、k在内比较自然。

**区间DP的识别特征**：
- 问题可以按区间/段来划分
- 每次操作合并相邻的两段
- 答案通常是dp[1][N]（整个区间的最优解）

### 四、石子合并问题——区间DP的经典模板

**问题描述**：有N堆石子排成一排，第i堆有a[i]个石子。每次可以将**相邻**的两堆合并为一堆，合并的代价为两堆石子数之和。求将所有石子合并为一堆的**最小总代价**。

这个问题是区间DP的"Hello World"，几乎所有的区间DP教程都会以它开篇。

**状态定义**：dp[i][j]表示将区间[i, j]内的所有石子堆合并为一堆所需的最小总代价。

**转移方程推导**：
考虑区间[i, j]的最后一组合并。无论之前的合并顺序如何，最后一步一定是将某两个相邻的大堆合并为一堆。假设这两堆的分界点在k，即左半部分[i, k]已合并为一堆，右半部分[k+1, j]也已合并为一堆，最后将这两堆合并。

```
dp[i][j] = min{ dp[i][k] + dp[k+1][j] } + (a[i] + a[i+1] + ... + a[j])
           (k = i, i+1, ..., j-1)
```

其中dp[i][k]是合并左半的代价，dp[k+1][j]是合并右半的代价，而(a[i]+...+a[j])是最后一次合并的代价（因为最后合并时，两堆包含了区间内所有的石子）。

**前缀和优化**：计算区间和sum(i,j)如果每次用循环累加，会使总复杂度变为O(N⁴)。使用前缀和可以将区间和的计算优化到O(1)：

```cpp
// 预处理前缀和
for (int i = 1; i <= N; i++) pre[i] = pre[i-1] + a[i];
// sum(i, j) = pre[j] - pre[i-1]
```

**完整实现**：
```cpp
int dp[305][305], a[305], pre[305];

// 前缀和预处理
for (int i = 1; i <= N; i++) pre[i] = pre[i-1] + a[i];

// dp初始化：长度为1的区间合并代价为0
memset(dp, 0x3f, sizeof(dp));
for (int i = 1; i <= N; i++) dp[i][i] = 0;

// 区间DP核心
for (int len = 2; len <= N; len++) {
    for (int i = 1; i + len - 1 <= N; i++) {
        int j = i + len - 1;
        for (int k = i; k < j; k++) {
            dp[i][j] = min(dp[i][j], 
                dp[i][k] + dp[k+1][j] + pre[j] - pre[i-1]);
        }
    }
}
cout << dp[1][N] << endl;  // 答案
```

**时间复杂度**：O(N³)，对于N≤300的数据完全可行。N=300时约300³/6≈4.5×10⁶，现代计算机可以轻松秒过。

**边界条件**：区间长度为1时（即dp[i][i]），不需要任何合并操作，代价为0。这是DP的初始/边界条件，忘记初始化dp[i][i]=0是极其常见的错误。

## 💻 代码模板

### 模板1：多重背包（二进制优化版）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 2005;  // 拆分后总物品数（N*log(max_c)）
const int MAXW = 20005;
int w[MAXN], v[MAXN], dp[MAXW];

int main() {
    int N, W, cnt = 0;
    cin >> N >> W;
    
    // 二进制拆分
    for (int i = 1; i <= N; i++) {
        int weight, value, count;
        cin >> weight >> value >> count;
        for (int k = 1; k <= count; k <<= 1) {
            w[++cnt] = k * weight;
            v[cnt] = k * value;
            count -= k;
        }
        if (count > 0) {
            w[++cnt] = count * weight;
            v[cnt] = count * value;
        }
    }
    
    // 01背包求解
    for (int i = 1; i <= cnt; i++)
        for (int j = W; j >= w[i]; j--)
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    
    cout << dp[W] << endl;
    return 0;
}
```

## ⚠️ 易错点

- **易错点1：多重背包的二进制拆分不完整**。拆分时必须包含剩余部分（c -= k后剩余的c），否则会丢失一些物品数量组合。例如c=13拆分为1,2,4后还剩6，必须单独作为一个打包物品加入。拆分循环的条件是`k <= c`而非`k < c`，因为要确保在k超过剩余c之前先取出剩余部分。

- **易错点2：分组背包的循环顺序错误**。必须保证容量循环在外、物品循环在内（对于每种容量j，在所有物品中选最优的那一个）。如果反过来（物品在外、容量在内），同一组内的多个物品可能都被选中，违反了"每组最多选一个"的核心约束。这是分组背包最常见也是最致命的错误。

- **易错点3：区间DP的dp数组初始化不当**。石子合并问题求最小值，dp[i][j]应初始化为INF（如0x3f3f3f3f）。但dp[i][i]（长度为1的区间）合并代价必须设为0，否则所有dp值都会保持INF，整个DP结果出错。另外区间DP的三层循环顺序不能乱：区间长度len必定在最外层（因为长区间依赖短区间）。

### 真题2：石子合并（区间DP）

**题目描述**：设有N堆石子排成一排，第i堆石子有a[i]个。现要将石子有次序地合并成一堆。规定每次只能选相邻的两堆合并，合并的代价为这两堆石子数之和。求将所有石子合并成一堆的最小总代价。

**输入格式**：第一行一个整数N。第二行N个整数a[i]。（1 ≤ N ≤ 300，1 ≤ a[i] ≤ 1000）

**输出格式**：一个整数，表示最小总代价。

**样例输入**：
```
4
1 3 5 2
```

**样例输出**：
```
22
```

**样例说明**：最优合并顺序为：(1,3)→4（代价4），然后(5,2)→7（代价7），最后(4,7)→11（代价11），总代价=4+7+11=22。

**参考代码**：
```cpp
#include <iostream>
#include <algorithm>
#include <cstring>
using namespace std;

const int N = 305, INF = 0x3f3f3f3f;
int a[N], pre[N], dp[N][N];

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        pre[i] = pre[i-1] + a[i];
    }
    memset(dp, 0x3f, sizeof(dp));
    for (int i = 1; i <= n; i++) dp[i][i] = 0;
    
    for (int len = 2; len <= n; len++)
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            for (int k = i; k < j; k++)
                dp[i][j] = min(dp[i][j], dp[i][k] + dp[k+1][j] + pre[j] - pre[i-1]);
        }
    cout << dp[1][n] << endl;
    return 0;
}
```

#include <iostream>

int dp[1005];

## 🧩 进阶精讲

### 五、背包家族速查（上+下）

| 类型 | 物品限制 | 容量循环 | 关键技巧 |
|------|----------|----------|----------|
| 01 | 每种 0/1 | 倒序 | 基础 |
| 完全 | 无限 | 正序 | 可重复选 |
| 多重 | 最多 c[i] | 倒序（拆分后） | 二进制优化 |
| 分组 | 每组 ≤1 | 倒序且容量在外 | 循环顺序 |

### 六、二进制拆分手算示例

c=13：k=1 → 剩 12；k=2 → 剩 10；k=4 → 剩 6；k=8>6 停；追加 6。  
打包：1,2,4,6。可组合出 0~13 任意整数。

### 七、石子合并：最小与最大

最小代价：`dp[i][j]=min_k + sum(i,j)`  
最大代价：`dp[i][j]=max_k + sum(i,j)`，初始化为 0 或 -INF，`dp[i][i]=0`。

环形石子合并（提高）：断环成链，复制成 2n-1，再区间 DP，答案取所有长度为 n 的区间最优。

### 八、区间 DP 其它模型（了解）

- 矩阵链乘：`dp[i][j]=min(dp[i][k]+dp[k+1][j]+p[i-1]*p[k]*p[j])`  
- 括号匹配/能量项链：枚举分割点合并  
- 回文相关：有时 `dp[i][j]` 表示区间是否回文或最少插入

识别：**合并相邻段、最优划分区间** → 想区间 DP。

### 九、复杂度与数据范围

- 多重二进制：W·Σlog c，W≤1e4、N≤100 常见  
- 分组：O(W · 总物品数)  
- 石子合并 O(N³)，N≤300  

### 十、易错点补充

1. 二进制拆分数组要开到 `N*logC` 量级。  
2. 分组背包若容量内层、物品外层 → 同组多选。  
3. 石子合并忘记 `dp[i][i]=0`。  
4. `memset(dp, 0x3f)` 后务必再设对角线。  
5. 前缀和 `pre[0]=0`，`sum=pre[j]-pre[i-1]`。

### 十一、三种背包代码骨架对比

```cpp
// 01
for i: for j=W..w[i]: dp[j]=max(dp[j], dp[j-w[i]]+v[i]);

// 完全
for i: for j=w[i]..W: dp[j]=max(dp[j], dp[j-w[i]]+v[i]);

// 分组
for g: for j=W..0: for item in g: if j>=w: dp[j]=max(...);
```

## 🎯 本课小结

本课深入讲解了背包问题的进阶内容以及区间DP的入门知识：

1. **多重背包**：每种物品有数量上限c[i]。核心技巧是**二进制优化**——将c[i]个相同物品按1,2,4,8,...的二进制方式拆分为约log₂(c[i])个打包物品，完美转化为01背包求解。时间复杂度从O(N*W*max(c))降到O(W*Σlog(c))。

2. **分组背包**：每组最多选一个物品。循环顺序至关重要：**组 → 容量（倒序）→ 组内物品**。容量循环必须在物品循环外面，确保每组最多选一个。

3. **区间DP**：dp[i][j]表示区间[i,j]的最优解。通用框架：枚举len → 枚举i → 枚举k。石子合并是区间DP最经典的模板题，转移方程为dp[i][j]=min(dp[i][k]+dp[k+1][j])+sum(i,j)，结合前缀和可实现O(N³)求解。

4. **记忆口诀**："多重二进制拆，分组容量外。区间先长度，石子并着走。"——掌握这些口诀，应对CSP-J中的背包和区间DP题目将游刃有余。

5. **与上节衔接**：01/完全看容量正倒序；多重先拆再01；分组多一层“组内互斥”。

从本课开始，动态规划的学习进入了更深层次。背包问题的各种变种和区间DP在CSP-J考试中都是高频考点，务必通过大量练习熟练掌握。
