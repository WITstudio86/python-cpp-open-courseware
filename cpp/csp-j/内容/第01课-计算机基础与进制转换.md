## 📖 知识精讲

### 一、计算机发展史

计算机的硬件核心器件经历了四次重要换代，考点通常要求能对应“时代—核心器件—典型特征”。

| 代际 | 大致年代 | 核心器件 | 代表 / 特征 |
|------|----------|----------|-------------|
| 第一代 | 1946–1957 | 电子管 | ENIAC；体积巨大、耗电多、速度慢、可靠性差 |
| 第二代 | 1958–1964 | 晶体管 | 体积缩小、功耗降低、可靠性提高 |
| 第三代 | 1965–1970 | 中小规模集成电路 | 体积更小、速度更快，开始软件系统化 |
| 第四代 | 1971 至今 | 大规模 / 超大规模集成电路 | 微型计算机（PC）普及，个人电脑时代 |

**记忆口诀**：电晶集大——电子管、晶体管、集成电路、大规模/超大规模。

#### 重要人物

- **冯·诺依曼（John von Neumann）**  
  提出**“存储程序”**思想：程序与数据都以二进制形式存放在存储器中，由控制器按地址依次取出执行。这是现代计算机体系结构的理论基础，因此常把符合该思想的机器称为**冯·诺依曼机**。

- **图灵（Alan Turing）**  
  提出**图灵机**抽象模型，从理论上刻画“什么问题可以被计算”；被誉为“人工智能之父”“计算机科学之父”。图灵奖是计算机领域最高奖项之一。

#### 初赛常见设问

1. 世界上第一台电子数字计算机通常指 **ENIAC**（1946）。
2. 现代计算机普遍采用 **冯·诺依曼** 体系结构。
3. 第四代计算机的核心器件是 **大规模/超大规模集成电路**。

### 二、冯·诺依曼体系结构

冯·诺依曼结构把计算机逻辑上分为**五大部件**，它们协同工作：

```
        ┌──────────┐
        │  控制器  │◄──── 指挥协调
        └────┬─────┘
             │
   ┌─────────┼─────────┐
   ▼         ▼         ▼
┌──────┐ ┌──────┐ ┌──────────┐
│运算器│ │存储器│ │输入/输出 │
└──────┘ └──────┘ └──────────┘
```

| 部件 | 功能 | 考试提示 |
|------|------|----------|
| **运算器** | 算术运算（+−×÷）与逻辑运算（与或非等） | 与控制器合称 **CPU** |
| **控制器** | 取出指令、分析指令、指挥各部件 | 计算机的“指挥中心” |
| **存储器** | 存放程序与数据 | 分内存（RAM）与外存 |
| **输入设备** | 把信息送入计算机 | 键盘、鼠标、扫描仪、麦克风等 |
| **输出设备** | 把结果呈现给用户 | 显示器、打印机、音箱等 |

**核心思想再强调三点**（初赛高频）：

1. **采用二进制**表示指令和数据。  
2. **程序与数据一起存放**在存储器中（存储程序）。  
3. 由控制器按顺序（也可跳转）**自动执行**指令。

> 注意：CPU = 运算器 + 控制器（现代 CPU 内还集成了高速缓存等，但考纲层面按五部件 + “CPU 含运算器控制器”即可）。

### 三、计算机硬件组成

#### 1. CPU（中央处理器）

- 计算机的“大脑”，负责执行指令。
- 主要性能指标：**主频**（Hz，如 GHz）、**核心数**、缓存大小等。
- 逻辑上包含运算器与控制器。

#### 2. 内存（RAM，随机存取存储器）

- **临时**存储正在运行的程序和数据。
- **断电后数据丢失**（易失性）。
- 读写速度快，容量相对外存较小（常见 8GB、16GB 等）。
- 程序必须先装入内存才能被 CPU 执行。

#### 3. 外存（硬盘 / SSD 等）

- **永久**（非易失）存储，断电数据仍在。
- 常见类型：**HDD**（机械硬盘，有盘片磁头）、**SSD**（固态硬盘，速度快、抗震）。
- 容量通常远大于内存（数百 GB 到数 TB）。
- U 盘、光盘、移动硬盘也属于外存范畴。

#### 4. 输入 / 输出设备（I/O）

| 类型 | 举例 |
|------|------|
| 输入 | 键盘、鼠标、扫描仪、摄像头、麦克风、触控板 |
| 输出 | 显示器、打印机、音箱、投影仪 |
| 既是输入又是输出 | 触摸屏、可读写外接硬盘（视场景） |

#### 5. 存储单位换算（必背）

计算机中信息的最小单位是 **bit（比特）**，常用单位是 **Byte（字节）**。

```
1 Byte（字节） = 8 bit（比特）

1 KB = 1024 B      （2^10 B）
1 MB = 1024 KB     （2^20 B）
1 GB = 1024 MB     （2^30 B）
1 TB = 1024 GB     （2^40 B）
```

**易混点**：

- 通信、部分厂商宣传可能用 1KB=1000B（十进制千），但 **CSP-J 计算存储时通常按 1024**。
- 1 个英文字符（ASCII）约占 **1 字节**；汉字编码常见为 2 字节（GBK）或 3~4 字节（UTF-8）。

**例**：一张 1024×768 的真彩色（每像素 3 字节）无压缩图片大约占多少？

```
像素数 = 1024 × 768
字节数 = 1024 × 768 × 3 = 2359296 B
约等于 2359296 / 1024 / 1024 ≈ 2.25 MB
```

#### 6. 软件与硬件的关系（简述）

- **硬件**：看得见摸得着的物理设备。  
- **软件**：程序与数据，包括系统软件（操作系统、编译器）与应用软件。  
- 没有硬件，软件无法运行；没有软件，硬件只是“裸机”。

### 四、进制与进位计数制

计算机内部用**二进制**；为书写方便，还常用**八进制、十六进制**。十进制是人类日常使用的进制。

#### 1. 基本概念

- **基数（R）**：每位可用的数码个数。二进制 R=2，八进制 R=8，十进制 R=10，十六进制 R=16。
- **数码**：二进制 0,1；八进制 0~7；十进制 0~9；十六进制 0~9 与 A~F（A=10 … F=15）。
- **权（位权）**：第 i 位（从右、整数最低位 i=0 起）权为 R^i。

任意 R 进制数可写成**按权展开式**，再求和得到十进制值。

例：十进制 345.67

```
345.67 = 3×10² + 4×10¹ + 5×10⁰ + 6×10⁻¹ + 7×10⁻²
```

#### 2. 二进制（Binary）

- 基数 2，数码 0 和 1；逢二进一。
- 计算机中一切最终是 0/1 的组合（电平高低）。

**（1）二进制 → 十进制：按权展开**

```
(1011.01)₂
= 1×2³ + 0×2² + 1×2¹ + 1×2⁰ + 0×2⁻¹ + 1×2⁻²
= 8 + 0 + 2 + 1 + 0 + 0.25
= 11.25
```

再练一例：`(11001010)₂`

```
= 1×128 + 1×64 + 0×32 + 0×16 + 1×8 + 0×4 + 1×2 + 0×1
= 128 + 64 + 8 + 2
= 202
```

**（2）十进制整数 → 二进制：除 2 取余，余数倒序**

```
例：25 → 二进制
25 ÷ 2 = 12 余 1  ← 最低位（LSB）
12 ÷ 2 = 6  余 0
6  ÷ 2 = 3  余 0
3  ÷ 2 = 1  余 1
1  ÷ 2 = 0  余 1  ← 最高位（MSB）
结果：(25)₁₀ = (11001)₂
```

**（3）十进制小数 → 二进制：乘 2 取整，整数顺序**

```
例：0.625 → 二进制
0.625 × 2 = 1.25  取整 1
0.25  × 2 = 0.5   取整 0
0.5   × 2 = 1.0   取整 1  （小数部分为 0，结束）
结果：(0.625)₁₀ = (0.101)₂
```

有限十进制小数未必对应有限二进制小数（如 0.1₁₀），考试以能整除结束或指定精度为主。

**记忆口诀**：整数**除基取余倒着写**，小数**乘基取整顺着写**。

#### 3. 八进制（Octal）

- 基数 8，数码 0~7；逢八进一。
- C++ 中整型字面量若以 `0` 开头表示八进制：`012` 表示十进制 10。

**八进制 → 十进制**：

```
(237)₈ = 2×8² + 3×8¹ + 7×8⁰ = 128 + 24 + 7 = 159
```

**二进制 ⇔ 八进制（3 位一组）**：

因为 2³ = 8，每 3 位二进制对应 1 位八进制。  
**从小数点起，整数部分向左、小数部分向右分组，不足补 0。**

```
(10101110)₂ → 010 101 110 → 2 5 6 → (256)₈
(256)₈     → 010 101 110 → (10101110)₂
```

#### 4. 十六进制（Hexadecimal）

- 基数 16，数码 0~9、A~F（大小写均可，A=10 … F=15）。
- C++ 中以 `0x` 或 `0X` 开头：`0x2F` 表示十进制 47。

**十六进制 → 十进制**：

```
(2AF)₁₆ = 2×16² + 10×16¹ + 15×16⁰ = 512 + 160 + 15 = 687
```

**二进制 ⇔ 十六进制（4 位一组）**：

因为 2⁴ = 16，每 4 位二进制对应 1 位十六进制。

```
(10101110)₂ → 1010 1110 → A E → (AE)₁₆
(AE)₁₆      → 1010 1110 → (10101110)₂
```

#### 5. 常用对照表（建议默写 0~15）

| 二进制 | 十进制 | 八进制 | 十六进制 | 二进制 | 十进制 | 八进制 | 十六进制 |
|--------|--------|--------|----------|--------|--------|--------|----------|
| 0000   | 0      | 0      | 0        | 1000   | 8      | 10     | 8        |
| 0001   | 1      | 1      | 1        | 1001   | 9      | 11     | 9        |
| 0010   | 2      | 2      | 2        | 1010   | 10     | 12     | A        |
| 0011   | 3      | 3      | 3        | 1011   | 11     | 13     | B        |
| 0100   | 4      | 4      | 4        | 1100   | 12     | 14     | C        |
| 0101   | 5      | 5      | 5        | 1101   | 13     | 15     | D        |
| 0110   | 6      | 6      | 6        | 1110   | 14     | 16     | E        |
| 0111   | 7      | 7      | 7        | 1111   | 15     | 17     | F        |

#### 6. 综合转换示例

**例1**：二进制 `(11001010)₂` 转八、十、十六进制。

- 八进制：`011 001 010` → `(312)₈`
- 十进制：128+64+8+2 = **202**
- 十六进制：`1100 1010` → `(CA)₁₆`

**例2**：十进制 2024 转二进制与十六进制。

- 除 2 取余得：`(11111101000)₂`（可用 `bitset` 验证）
- 分组：`0111 1110 1000` → `(7E8)₁₆`

**例3**：十六进制 `(1A3)₁₆` 转十进制与二进制。

```
(1A3)₁₆ = 1×256 + 10×16 + 3 = 256 + 160 + 3 = 419
(1A3)₁₆ → 0001 1010 0011 → (110100011)₂（前导 0 可省略）
```

#### 7. C++ 中的进制字面量与输出

```cpp
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    int a = 26;      // 十进制
    int b = 032;     // 八进制 → 十进制 26
    int c = 0x1A;    // 十六进制 → 十进制 26

    cout << a << " " << b << " " << c << endl; // 都是 26
    cout << oct << a << endl;   // 输出八进制 32
    cout << hex << a << endl;   // 输出十六进制 1a
    cout << bitset<8>(a) << endl; // 00011010
    cout << dec;                // 记得恢复十进制！
    return 0;
}
```

**重要**：`cout << hex` 会**改变后续**整数输出格式，直到再次 `cout << dec`（或 `oct`）。考试写代码或阅读输出时务必注意。

### 五、ASCII 编码

#### 1. 定义与范围

**ASCII**（American Standard Code for Information Interchange，美国标准信息交换码）：

- **标准 ASCII**：7 位，共 **128** 个字符（码值 0~127）。
- **扩展 ASCII**：8 位，共 256 个（0~255），不同系统扩展区可能不同。
- 在 C++ 中，`char` 通常占 1 字节；字符可与整数互相转换（本质是码值）。

#### 2. 必记三个锚点

| 字符 | ASCII（十进制） | 说明 |
|------|-----------------|------|
| `'0'` | **48** | 数字字符起点 |
| `'A'` | **65** | 大写字母起点 |
| `'a'` | **97** | 小写字母起点 |

补充：

- 空格 `' '` = 32  
- 换行 `'\n'` = 10（在多数系统）  
- 数字字符 `'0'~'9'` 码值 **连续**  
- 大写 `'A'~'Z'`、小写 `'a'~'z'` 各自 **连续**  
- 同一字母大小写相差 **32**：`'a' - 'A' = 32`  
- 顺序：**控制字符 / 符号 < 数字 < 大写 < 小写**（就常见可打印字符相对位置而言）

#### 3. 高频运算模式

```cpp
// 1）字符 → 整数码值
char ch = 'A';
int code = (int)ch;      // 65
// 或
int code2 = ch;          // 隐式提升

// 2）码值 → 字符
char c2 = (char)65;      // 'A'

// 3）大小写转换
char lower = 'A' + 32;   // 'a'
char upper = 'b' - 32;   // 'B'
// 或
char lower2 = 'A' - 'A' + 'a'; // 通用一点的写法思路

// 4）数字字符 ↔ 数值
int v = '7' - '0';       // 7
char d = 7 + '0';        // '7'

// 5）字母序号（从 0 或 1 起）
int idx0 = 'D' - 'A';    // 3（A=0,B=1,C=2,D=3）
int idx1 = 'D' - 'A' + 1;// 4（A=1…）
```

#### 4. 典型小题

1. 已知 `'A'=65`，求 `'D'` → 65+3=**68**  
2. 已知 `'a'=97`，求 `'A'` → 97-32=**65**  
3. 已知 `'0'=48`，求 `'5'` → 48+5=**53**  
4. 表达式 `'E' - 'A' + 'd'` → 4 + 100 = 104 → 字符 **`'h'`**

#### 5. 与编程的联系

```cpp
#include <iostream>
using namespace std;

int main() {
    // 输出 'A' 到 'Z'
    for (char c = 'A'; c <= 'Z'; c++) {
        cout << c;
    }
    cout << endl;

    // 判断是否为大写
    char x = 'M';
    if (x >= 'A' && x <= 'Z') {
        cout << x << " 是大写字母" << endl;
    }
    return 0;
}
```

> 说明：本课只要求理解 ASCII 规律；`isdigit`/`isalpha` 等库函数在后续字符串课再系统学习。

## 💻 代码模板

### 模板一：多进制输出与 bitset

可直接用于验证手算结果，或作为调试“整数在计算机中的样子”的工具。

```cpp
#include <iostream>
#include <bitset>
#include <iomanip>
using namespace std;

// 以固定宽度打印 n 的二进制/八/十/十六进制
void printBases(int n, int binWidth = 16) {
    cout << "十进制: " << dec << n << endl;
    cout << "八进制: " << oct << n << endl;
    cout << "十六进制(小写): " << hex << n << endl;
    cout << "十六进制(大写): " << hex << uppercase << n << endl;
    cout << noshowbase << nouppercase << dec; // 恢复默认习惯
    // 注意：bitset 宽度固定，过大数只显示低 binWidth 位
    cout << "二进制(" << binWidth << "位): " << bitset<32>(n).to_string().substr(32 - binWidth)
         << endl;
    // 更简单写法（宽度编译期常量时）：
    // cout << bitset<16>(n) << endl;
    cout << dec;
}

int main() {
    printBases(2024, 16);
    printBases(0xFF, 8);
    return 0;
}
```

**精简考试版**（宽度用 `bitset<16>` 即可）：

```cpp
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    int n = 2024;
    cout << "dec=" << dec << n
         << " oct=" << oct << n
         << " hex=" << hex << uppercase << n
         << " bin=" << bitset<16>(n) << endl;
    cout << dec;
    return 0;
}
```

### 模板二：ASCII 常用变换

```cpp
#include <iostream>
using namespace std;

// 字符转小写（若已是小写或非字母则原样返回的简化版思路见注释）
char toLowerSimple(char c) {
    if (c >= 'A' && c <= 'Z') return c + 32;
    return c;
}

char toUpperSimple(char c) {
    if (c >= 'a' && c <= 'z') return c - 32;
    return c;
}

int digitCharToInt(char c) {   // '0'~'9'
    return c - '0';
}

char intToDigitChar(int x) {   // 0~9
    return char(x + '0');
}

int main() {
    cout << (int)'0' << " " << (int)'A' << " " << (int)'a' << endl; // 48 65 97
    cout << toLowerSimple('Z') << endl;  // z
    cout << toUpperSimple('m') << endl;  // M
    cout << digitCharToInt('7') << endl; // 7
    cout << intToDigitChar(3) << endl;   // 3
    cout << char('E' - 'A' + 'd') << endl; // h
    return 0;
}
```

### 模板三：二进制串（0/1 字符串）转十进制（模拟手算）

```cpp
#include <iostream>
#include <string>
using namespace std;

// s 仅为 '0'/'1' 组成的无符号整数二进制
long long binStringToDec(const string &s) {
    long long ans = 0;
    for (char c : s) {
        ans = ans * 2 + (c - '0');
    }
    return ans;
}

int main() {
    cout << binStringToDec("10110110") << endl; // 182
    cout << binStringToDec("11001") << endl;    // 25
    return 0;
}
```

## ⚠️ 易错点

### 1. C++ 整型字面量前缀搞混

```cpp
// 错误理解
int x = 012;   // 以为是十二 → 实际是八进制，值为 10
int y = 0x12;  // 以为是十二 → 实际是十六进制，值为 18
int z = 12;    // 这才是十进制 12
```

**正确习惯**：看到前导 `0` 先想八进制，看到 `0x` 想十六进制。

### 2. 除基取余的顺序写反

```
25 → 二进制
余数依次是 1,0,0,1,1
错误：直接写成 10011
正确：倒序 → 11001
```

小数则相反：乘 2 取整**从高位到低位顺着写**。

### 3. 二转八/十六时从左边分组

```
错误：10101110 从左按 3 位 → 101 011 10(还要补?) → 容易错
正确：从右（整数）→ 010 101 110 → 256₈
```

口诀：**整数部分靠右对齐分组，左边不足补 0**。

### 4. 存储单位用 1000 还是 1024

```
错误：1KB = 1000B（在 CSP-J 存储计算题中通常不这样）
正确：1KB = 1024B，1MB = 1024KB，…
```

### 5. ASCII 大小写不连续

```cpp
// 错误：以为 'Z' 的下一个可打印字母相关码就是 'a'
// 'Z' = 90，'a' = 97，中间还有 [ \ ] ^ _ ` 等字符
// 正确：大小写转换用 ±32，或判断区间后转换
char c = 'Z';
char lower = c + 32; // 'z'  —— 仅对 A~Z 成立
```

### 6. `cout << hex` 污染后续输出

```cpp
// 错误示范
cout << hex << 255 << endl;
cout << 10 << endl;   // 仍是十六进制！输出 a，不是 10

// 正确
cout << hex << 255 << endl;
cout << dec << 10 << endl; // 恢复十进制
```

### 7. 字符输出与整数输出混淆

```cpp
char ch = 'A';
cout << ch << endl;        // A
cout << (int)ch << endl;   // 65
cout << ch + 1 << endl;    // 66（算术后提升为 int）
cout << (char)(ch + 1) << endl; // B
```

### 题目1：进制转换综合

**题目描述**  
若一个二进制数是 `10110110`，请回答：  
(1) 这个数的十进制值是多少？  
(2) 这个数的八进制值是多少？  
(3) 这个数的十六进制值是多少？

**答案**  
(1) **182**  
(2) **266**（即 `(266)₈`）  
(3) **B6**（即 `(B6)₁₆`）

**解析**

- 十进制：  
  `1×128 + 0×64 + 1×32 + 1×16 + 0×8 + 1×4 + 1×2 + 0×1 = 128+32+16+4+2 = 182`
- 八进制：从右每 3 位 → `010 110 110` → `2 6 6` → `266₈`
- 十六进制：从右每 4 位 → `1011 0110` → `B 6` → `B6₁₆`

**完整 AC / 验证代码**

```cpp
#include <iostream>
#include <bitset>
#include <string>
using namespace std;

int main() {
    // 方法1：按权展开
    int decVal = 1*128 + 0*64 + 1*32 + 1*16 + 0*8 + 1*4 + 1*2 + 0*1;

    // 方法2：二进制字符串累加
    string bin = "10110110";
    int dec2 = 0;
    for (char c : bin) dec2 = dec2 * 2 + (c - '0');

    cout << "十进制: " << decVal << " (check " << dec2 << ")" << endl;
    cout << "八进制: " << oct << decVal << endl;
    cout << "十六进制: " << hex << uppercase << decVal << endl;
    cout << "二进制复核: " << bitset<8>(decVal) << endl;
    cout << dec;
    return 0;
}
```

**期望输出要点**：十进制 182，八进制 266，十六进制 B6。

### 题目2：ASCII 码运算

**题目描述**  
已知字符 `'A'` 的 ASCII 码是 65，请计算表达式  
`'E' - 'A' + 'd'`  
的结果（以字符形式给出）。

**答案**  
**`h`**（码值 104）

**解析**

```
'E' - 'A' = 69 - 65 = 4
4 + 'd' = 4 + 100 = 104
ASCII 104 对应字符 'h'
```

直观理解：`'E'` 相对 `'A'` 偏移 4，再作用到 `'d'` 上，相当于把 `'d'` 往后推 4 个字母：`d e f g h`。

**完整代码**

```cpp
#include <iostream>
using namespace std;

int main() {
    char result = 'E' - 'A' + 'd';
    cout << "计算结果(字符): " << result << endl;
    cout << "'E' - 'A' = " << ('E' - 'A') << endl;
    cout << "码值 = " << (int)result << endl;
    return 0;
}
```

### 题目4（补充模拟）：快速进制

**题目描述**  
十六进制数 `(2F)₁₆` 的二进制是？  
A. 101111  
B. 1011111  
C. 0101111  
D. 00101111  

**答案**：D（也可写作 `101111`，但完整 8 位是 `00101111`）  

**解析**：`2 → 0010`，`F → 1111`，合起来 `00101111`。十进制验证：2×16+15=47，`47=32+8+4+2+1` → `101111`。

**验证代码**

```cpp
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    int x = 0x2F;
    cout << x << endl;              // 47
    cout << bitset<8>(x) << endl;   // 00101111
    return 0;
}
```

## 🎯 本课小结

1. **发展史**：四代器件——电子管 → 晶体管 → 集成电路 → 大规模/超大规模集成电路；冯·诺依曼提出存储程序，图灵提出图灵机。  
2. **冯·诺依曼五大部件**：运算器、控制器、存储器、输入设备、输出设备；CPU = 运算器 + 控制器。  
3. **硬件要点**：内存易失、外存非易失；单位 **1B=8bit，1KB=1024B** 逐级 ×1024。  
4. **进制核心方法**：  
   - R→10：按权展开  
   - 10→R（整数）：除基取余，**倒序**  
   - 10→R（小数）：乘基取整，**顺序**  
   - 2⇔8：3 位一组；2⇔16：4 位一组（从右分组）  
5. **ASCII 三锚点**：`'0'=48`，`'A'=65`，`'a'=97`；大小写差 **32**；数字/字母区间内码值连续。  
6. **C++ 辅助**：`dec`/`oct`/`hex`/`bitset`；字面量 `012`（八进制）、`0x12`（十六进制）；用完 `hex` 记得 `dec` 恢复。
