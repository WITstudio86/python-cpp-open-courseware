## 📖 知识精讲

### 一、计算机发展史
计算机发展经历了四个阶段：
1. **第一代（1946-1957）**：电子管计算机，代表：ENIAC，体积大、耗电多、速度慢
2. **第二代（1958-1964）**：晶体管计算机，体积减小、功耗降低、可靠性提高
3. **第三代（1965-1970）**：集成电路计算机，体积更小、速度更快
4. **第四代（1971至今）**：大规模/超大规模集成电路计算机，微型计算机（PC）普及

**重要人物**：
- 冯·诺依曼：提出"存储程序"概念，现代计算机体系结构基础
- 图灵：提出图灵机模型，"人工智能之父"

### 二、冯·诺依曼体系结构
五大部件：
1. **运算器**：执行算术运算和逻辑运算
2. **控制器**：指挥各部件协调工作（运算器+控制器=CPU）
3. **存储器**：存放数据和程序（内存RAM、外存硬盘）
4. **输入设备**：键盘、鼠标、扫描仪等
5. **输出设备**：显示器、打印机、音箱等

### 三、计算机硬件组成

**CPU（中央处理器）**：
- 计算机的核心，负责执行指令
- 主要性能指标：主频（Hz）、核心数
- 包含运算器和控制器

**内存（RAM）**：
- 临时存储，断电后数据丢失
- 存取速度快，容量相对较小
- 常见单位：GB

**外存（硬盘/SSD）**：
- 永久存储，断电后数据不丢失
- 常见类型：HDD（机械硬盘）、SSD（固态硬盘）
- 容量通常比内存大

**存储单位换算**：
```
1B（字节）= 8bit（比特）
1KB = 1024B
1MB = 1024KB
1GB = 1024MB
1TB = 1024GB
```

### 四、进制转换

计算机中所有的数据最终都以**二进制**形式存储。但二进制书写太长，人们也常用八进制和十六进制来表示。

#### 1. 进位计数制的基本概念

任意一个R进制数的值可以表示为**按权展开式**：每个数位上的数字乘以基数的相应幂次，再求和。

例如十进制数 345.67：345.67 = 3×10² + 4×10¹ + 5×10⁰ + 6×10⁻¹ + 7×10⁻²

#### 2. 二进制（Binary）

**基本规则**：
- 基数R=2，数码是0和1
- 逢二进一，借一当二
- 第i位的权值为2ⁱ

**二进制转十进制**（按权展开法）：
```
(1011.01)₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ + 0×2⁻¹ + 1×2⁻²
          = 8 + 0 + 2 + 1 + 0 + 0.25 = 11.25
```

**十进制整数转二进制**（除2取余法，倒序排列）：
```
例：将十进制数 25 转换为二进制
25 ÷ 2 = 12 余 1  ← 最低位
12 ÷ 2 = 6  余 0
6 ÷ 2 = 3   余 0
3 ÷ 2 = 1   余 1
1 ÷ 2 = 0   余 1  ← 最高位
结果：(25)₁₀ = (11001)₂
```

**十进制小数转二进制**（乘2取整法，顺序排列）：
```
例：将十进制小数 0.625 转换为二进制
0.625 × 2 = 1.25  取整数部分 1
0.25 × 2 = 0.5    取整数部分 0
0.5 × 2 = 1.0     取整数部分 1（小数部分为0，结束）
结果：(0.625)₁₀ = (0.101)₂
```

**记忆技巧**：整数部分除基取余倒着写，小数部分乘基取整顺着写。

#### 3. 八进制（Octal）

**基本规则**：
- 基数R=8，数码是0~7
- 逢八进一
- C++中八进制常量以前导0表示，如 `int x = 012;` // 十进制10

**八进制转十进制**：
```
(237)₈ = 2×8² + 3×8¹ + 7×8⁰ = 128 + 24 + 7 = 159
```

**二进制与八进制的快速转换**（3位一组）：
二进制每3位对应1位八进制（从右往左分组，不足补0）
```
(10101110)₂ → 010 101 110 → 2 5 6 → (256)₈
```

#### 4. 十六进制（Hexadecimal）

**基本规则**：
- 基数R=16，数码是0~9和A~F（A=10, B=11, C=12, D=13, E=14, F=15）
- 逢十六进一
- C++中十六进制常量以前导0x表示，如 `int x = 0x2F;` // 十进制47

**十六进制转十进制**：
```
(2AF)₁₆ = 2×16² + 10×16¹ + 15×16⁰ = 512 + 160 + 15 = 687
```

**二进制与十六进制的快速转换**（4位一组）：
二进制每4位对应1位十六进制（从右往左分组，不足补0）
```
(10101110)₂ → 1010 1110 → A E → (AE)₁₆
```

**常见二进制-十进制-十六进制对照表**：
| 二进制 | 十进制 | 十六进制 | 二进制 | 十进制 | 十六进制 |
|--------|--------|----------|--------|--------|----------|
| 0000   | 0      | 0        | 1000   | 8      | 8        |
| 0001   | 1      | 1        | 1001   | 9      | 9        |
| 0010   | 2      | 2        | 1010   | 10     | A        |
| 0011   | 3      | 3        | 1011   | 11     | B        |
| 0100   | 4      | 4        | 1100   | 12     | C        |
| 0101   | 5      | 5        | 1101   | 13     | D        |
| 0110   | 6      | 6        | 1110   | 14     | E        |
| 0111   | 7      | 7        | 1111   | 15     | F        |

#### 5. 进制转换综合练习

**例1**：将二进制 (11001010)₂ 分别转换为八进制、十进制、十六进制。
- 八进制：011 001 010 → (312)₈
- 十进制：128+64+0+0+8+0+2+0 = 202
- 十六进制：1100 1010 → (CA)₁₆

**例2**：将十进制 2024 转换为二进制和十六进制。
- 二进制：使用除2取余法 → (11111101000)₂
- 十六进制：先转二进制，再4位一组 → 0111 1110 1000 → (7E8)₁₆

### 五、ASCII编码

**定义**：American Standard Code for Information Interchange，美国标准信息交换码。

**基本规则**：
- 标准ASCII码用7位二进制表示一个字符，共128个（0~127）
- 扩展ASCII码用8位二进制表示一个字符，共256个（0~255）
- 计算机中1个英文字母占**1字节**（8bit），1个汉字通常占**2~4字节**

**重要规律**（考试高频）：
- `'0'` 的ASCII码是 **48**（十进制）
- `'A'` 的ASCII码是 **65**（十进制）
- `'a'` 的ASCII码是 **97**（十进制）
- 规律：数字 < 大写字母 < 小写字母
- 同一字母大小写相差 **32**：`'a' - 'A' = 32`
- 相邻字母ASCII码连续：`'B' = 66, 'C' = 67`
- 相邻数字ASCII码连续：`'1' = 49, '2' = 50`

**常见题型**：
1. 已知 `'A'` 的ASCII码为65，求 `'D'` → 65+3=68
2. 已知 `'a'` 的ASCII码为97，求 `'A'` → 97-32=65
3. 已知 `'0'` 的ASCII码为48，求 `'5'` → 48+5=53

## 💻 代码模板

### 进制输出模板
```cpp
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    int n = 2024;
    
    // 输出十进制
    cout << "十进制: " << dec << n << endl;
    
    // 输出八进制
    cout << "八进制: " << oct << n << endl;
    
    // 输出十六进制（默认小写字母）
    cout << "十六进制: " << hex << n << endl;
    
    // 输出十六进制（大写字母）
    cout << "十六进制(大写): " << hex << uppercase << n << endl;
    
    // 输出二进制（使用bitset）
    cout << "二进制: " << bitset<16>(n) << endl;
    
    // 恢复十进制输出
    cout << dec;
    
    return 0;
}
```

### ASCII码操作模板
```cpp
#include <iostream>
using namespace std;

int main() {
    char ch = 'A';
    
    // 字符和ASCII码互转
    cout << "字符: " << ch << ", ASCII码: " << (int)ch << endl;
    
    // 大小写转换（相差32）
    char lower = ch + 32;  // 'A' + 32 = 'a'
    cout << ch << " 的小写是: " << lower << endl;
    
    // 数字字符转数值
    char digit = '5';
    int num = digit - '0';  // '5' - '0' = 5
    cout << "字符" << digit << "对应的数值: " << num << endl;
    
    return 0;
}
```

## ⚠️ 易错点

- **进制前缀混淆**：C++中 `012` 是八进制（十进制10），`0x12` 是十六进制（十进制18），普通 `12` 是十进制。考试中看到前导0的数字要特别注意！
- **除2取余方向搞反**：整数部分除基取余是**倒序**取余数（先出来的余数是低位），小数部分乘基取整是**顺序**取整数。
- **存储单位换算**：1KB=1024B 而非 1000B，但硬盘厂商常用1000来标称，这是CSP-J容易出现的陷阱题。
- **ASCII码字母顺序**：大写字母ASCII码在65~90，小写字母在97~122。同一字母的大写和小写ASCII码相差32。注意：`'A'`到`'Z'`连续，`'a'`到`'z'`连续，但大写和小写之间不连续（中间有6个其他字符）。
- **二进制转八进制/十六进制**：分组必须从**右往左**，不是从左往右！例如二进制转八进制 `11001010` → 从右开始分组为 `011 001 010`。

## 📝 真题精练

### 题目1：进制转换综合
**题目描述**：如果一个二进制数是 10110110，请回答：
(1) 这个数的十进制值是多少？
(2) 这个数的八进制值是多少？
(3) 这个数的十六进制值是多少？

**解题思路**：
- 十进制：按权展开求和 = 128+0+32+16+0+4+2+0 = 182
- 八进制：从右往左每3位一组，010 110 110 = 266₈
- 十六进制：从右往左每4位一组，1011 0110 = B6₁₆

```cpp
#include <iostream>
#include <bitset>
using namespace std;

int main() {
    // 二进制 10110110
    int dec_val = 1*128 + 0*64 + 1*32 + 1*16 + 0*8 + 1*4 + 1*2 + 0*1;
    
    cout << "十进制值: " << dec_val << endl;
    cout << "八进制值: " << oct << dec_val << endl;
    cout << "十六进制值: " << hex << uppercase << dec_val << endl;
    cout << dec;
    
    return 0;
}
```

### 题目2：ASCII码运算
**题目描述**：已知字符 'A' 的ASCII码是65，请计算 'E' - 'A' + 'd' 的结果（结果用字符表示）。

**解题思路**：
- 'E' - 'A' = 69 - 65 = 4
- 4 + 'd' = 4 + 100 = 104
- ASCII码104对应字符 'h'

```cpp
#include <iostream>
using namespace std;

int main() {
    char result = 'E' - 'A' + 'd';
    
    cout << "计算结果: " << result << endl;
    cout << "'E' - 'A' = " << (int)('E' - 'A') << endl;
    cout << "('E' - 'A') + 'd' = " << (int)result;
    cout << " -> 字符 '" << result << "'" << endl;
    
    return 0;
}
```

## 🎯 本课小结
1. 冯·诺依曼体系结构五大部件：运算器、控制器、存储器、输入设备、输出设备
2. 进制转换核心方法：按权展开（R→10）、除基取余倒序（10→R整数）、乘基取整顺序（10→R小数）
3. 二进制⇔八进制：3位一组；二进制⇔十六进制：4位一组（均从右往左分组）
4. ASCII三基点：'0'=48, 'A'=65, 'a'=97；大小写差32
5. 存储单位：1B=8bit, 1KB=1024B, 1MB=1024KB, 1GB=1024MB, 1TB=1024GB
