## 📖 知识精讲

### 一、为什么需要二维数组

在编程中，很多数据天然就是二维的：课程表（星期 x 节次）、棋盘（行 x 列）、成绩表（学生 x 科目）、图像像素（高 x 宽）。一维数组只能表示"一条线"，而二维数组可以表示"一个面"，用**行**和**列**来定位每一个元素。

### 二、二维数组的定义语法

```cpp
类型 数组名[行数][列数];
```

例如：

```cpp
int a[3][4];        // 3行4列的整数矩阵，共 3x4=12 个元素
double b[10][10];   // 10x10 的浮点数方阵
char board[8][8];   // 8x8 的棋盘（字符表示棋子）
```

定义时，第一对方括号表示**行数**，第二对表示**列数**。因此 `a[3][4]` 有 3 行、4 列，总共 12 个元素。习惯上，我们用 `n` 表示行数、`m` 表示列数（或方阵时都用 `n`）。

### 三、二维数组在内存中的存储方式

二维数组在内存中**并不是**一个真正的二维表格，而是按照**行优先（Row-major order）**的方式，将所有元素展平为一维连续存储的。

以 `int a[2][3]` 为例，内存中的存放顺序为：

```
a[0][0] → a[0][1] → a[0][2] → a[1][0] → a[1][1] → a[1][2]
```

也就是说，**先把第 0 行的所有列存完，再存第 1 行的所有列**，依此类推。了解这一点，对于理解数组指针和越界访问的后果非常有帮助。

### 四、二维数组的初始化

**方式一：按行初始化（推荐）**

```cpp
int a[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

每组花括号对应一行，清晰直观。最终 `a[0][0]=1, a[0][1]=2, a[0][2]=3, a[1][0]=4, a[1][1]=5, a[1][2]=6`。

**方式二：不分组初始化**

```cpp
int a[2][3] = {1, 2, 3, 4, 5, 6};
```

效果与方式一相同，编译器按行优先顺序依次填充。但不推荐，因为不够直观。

**方式三：部分初始化**

```cpp
int a[3][3] = {0};        // 全部清零
int b[3][3] = {{1, 2}};   // 只有 b[0][0]=1, b[0][1]=2，其余为0
```

**方式四：省略第一维大小**

```cpp
int a[][3] = {
    {1, 2, 3},
    {4, 5, 6}
};  // 编译器自动推导为 2 行
```

**重要规则**：初始化时只能省略第一维（行数）的大小，第二维（列数）必须指定。因为编译器需要通过列数来计算每行的偏移量。

### 五、二维数组的行列遍历

遍历二维数组的标准模式是**双层 for 循环**：

```cpp
// 输入 n 行 m 列的矩阵
for (int i = 0; i < n; i++) {        // 外层循环：遍历每一行
    for (int j = 0; j < m; j++) {    // 内层循环：遍历当前行的每一列
        cin >> a[i][j];
    }
}

// 按矩阵格式输出
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cout << a[i][j] << " ";
    }
    cout << endl;  // 每行结束后换行
}
```

**关键规律**：
- 外层 `i` 始终控制**行**，内层 `j` 始终控制**列**。
- `a[i][j]` 表示第 `i` 行、第 `j` 列的元素（`i` 和 `j` 都从 0 开始）。

### 六、矩阵的常见操作

#### 1. 矩阵转置

转置是将矩阵的行和列互换。若原矩阵 `a[n][m]`，则转置后为 `b[m][n]`，且 `b[j][i] = a[i][j]`。

```cpp
// a 为 n 行 m 列，转置到 b（m 行 n 列）
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        b[j][i] = a[i][j];
    }
}
```

如果要在原矩阵上原地转置，必须是方阵（n == m），且只遍历上三角部分：

```cpp
// 原地转置方阵
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        swap(a[i][j], a[j][i]);
    }
}
```

#### 2. 主对角线元素

在一个方阵中，主对角线元素满足 **`i == j`**。例如 3x3 矩阵的主对角线元素是 `a[0][0], a[1][1], a[2][2]`。

```cpp
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i][i];  // 主对角线求和
}
```

#### 3. 副对角线元素

副对角线从右上到左下，满足 **`i + j == n - 1`**。

```cpp
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i][n - 1 - i];  // 副对角线求和
}
```

#### 4. 边缘元素

矩阵四条边上的元素称为边缘元素，满足以下条件之一：

```cpp
if (i == 0 || i == n - 1 || j == 0 || j == m - 1) {
    // 这是边缘元素
}
```

这四个条件分别表示：第一行、最后一行、第一列、最后一列。

#### 5. 上三角和下三角

- 上三角（含对角线）：`i <= j`
- 下三角（含对角线）：`i >= j`

### 七、杨辉三角

杨辉三角是二维数组的经典应用。它的生成规律是：
- 每行的第一个和最后一个元素为 1。
- 其余每个元素等于它**正上方**和**左上方**两个元素之和：`a[i][j] = a[i-1][j-1] + a[i-1][j]`。

```cpp
const int N = 15;
int a[N][N] = {0};

int n;
cin >> n;

for (int i = 0; i < n; i++) {
    a[i][0] = 1;      // 每行第一个为 1
    a[i][i] = 1;      // 每行最后一个为 1
    for (int j = 1; j < i; j++) {
        a[i][j] = a[i - 1][j - 1] + a[i - 1][j];
    }
}

// 输出
for (int i = 0; i < n; i++) {
    for (int j = 0; j <= i; j++) {   // 注意：每行只输出 i+1 个数
        cout << a[i][j] << " ";
    }
    cout << endl;
}
```

## ⚠️ 易错点

| 序号 | 易错点 | 说明 |
|------|--------|------|
| 1 | **行列混淆** | `a[i][j]` 中 i 是行、j 是列。遍历时外层必须对应行、内层对应列，搞反会导致结果错误。 |
| 2 | **只能省略第一维** | `int a[][4]` 合法，编译器可以根据初始化数据推导行数。但 `int a[3][]` 非法，因为不知道每行有多少列。 |
| 3 | **内外层循环搞反** | 如果先遍历列再遍历行 `for j { for i {} }`，输出格式会是按列排列的，与预期不同。 |
| 4 | **数组大小需常量** | 二维数组的每一维都必须是常量表达式，不能用变量定义数组大小（C++ 标准）。 |
| 5 | **大数组必须全局** | `int a[1000][1000]` 约 4MB，远超栈空间限制（通常 8MB），必须定义为全局数组。 |
| 6 | **杨辉三角内层循环范围** | 内层是 `j < i`，不是 `j <= i`，因为 `a[i][i]` 已经在前面单独赋值为 1 了。 |
| 7 | **转置后的行列数** | 原矩阵 n 行 m 列，转置后是 m 行 n 列，输出时要注意行列数交换。 |

## 📝 真题精练

### 真题1：矩阵转置输出

**题目描述**

输入一个 n 行 m 列的矩阵 A，输出它的转置矩阵 A^T。

**输入格式**

第一行包含两个整数 n 和 m，表示矩阵 A 的行数和列数。1 <= n, m <= 100。
接下来 n 行，每行 m 个整数，表示矩阵 A 的元素。

**输出格式**

输出 m 行，每行 n 个整数，为转置后的矩阵。数与数之间用一个空格隔开。

**样例输入**

```
2 3
1 2 3
4 5 6
```

**样例输出**

```
1 4
2 5
3 6
```

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 105;
int a[N][N], b[N][N];

int main() {
    int n, m;
    cin >> n >> m;

    // 输入
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    // 转置
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            b[j][i] = a[i][j];

    // 输出（m 行 n 列）
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            cout << b[i][j] << " ";
        }
        cout << endl;
    }

    return 0;
}
```

### 真题2：杨辉三角

**题目描述**

输入一个正整数 n（n <= 20），输出杨辉三角的前 n 行。每行的数之间用一个空格隔开。

**输入格式**

一个正整数 n。

**输出格式**

n 行，第 i 行有 i 个整数，表示杨辉三角的前 n 行。

**样例输入**

```
5
```

**样例输出**

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 25;
int a[N][N];

int main() {
    int n;
    cin >> n;

    // 生成杨辉三角
    for (int i = 0; i < n; i++) {
        a[i][0] = 1;          // 每行第一个为 1
        a[i][i] = 1;          // 每行最后一个为 1
        for (int j = 1; j < i; j++) {
            a[i][j] = a[i - 1][j - 1] + a[i - 1][j];
        }
    }

    // 输出
    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) {
            cout << a[i][j] << " ";
        }
        cout << endl;
    }

    return 0;
}
```

## 🎯 本课小结

1. **二维数组定义**：`类型 数组名[行数][列数]`，内存中按行优先连续存储。
2. **初始化要点**：推荐按行初始化 `{{1,2},{3,4}}`；只能省略第一维大小；`{0}` 全部清零。
3. **双层遍历**：外层 i 控制行，内层 j 控制列，`a[i][j]` 表示第 i 行第 j 列。
4. **矩阵操作**：转置 `b[j][i] = a[i][j]`、主对角线 `i == j`、副对角线 `i + j == n - 1`、边缘元素 `i == 0 || j == 0 || i == n-1 || j == m-1`。
5. **杨辉三角**：核心公式 `a[i][j] = a[i-1][j-1] + a[i-1][j]`，首尾为 1，内层循环 `j < i`。
6. **易错防范**：行列不搞反、大数组放全局、杨辉三角内层范围注意不要覆盖首尾的 1。

课后请独立完成以下练习：

- 练习1：输入一个 3x3 的方阵，求主对角线元素之和。
- 练习2：输入 n 行 m 列矩阵，输出最外面一圈（边缘元素）之和。
- 练习3：输入方阵 n，按螺旋顺序（顺时针）遍历输出矩阵的所有元素。
