## 📖 知识精讲

### 一、为什么需要二维数组

在编程中，很多数据天然就是二维的：

- 课程表：星期 × 节次  
- 棋盘：行 × 列  
- 成绩表：学生 × 科目  
- 图像像素：高 × 宽  
- 地图 / 迷宫：n × m 格子  

一维数组只能表示“一条线”，二维数组可以表示“一个面”，用**行**和**列**定位每一个元素。

当然，二维数组在逻辑上是二维，在内存中仍是**一段连续的一维空间**（见后文）。

### 二、二维数组的定义语法

```cpp
类型 数组名[行数][列数];
```

例如：

```cpp
int a[3][4];        // 3行4列的整数矩阵，共 3×4=12 个元素
double b[10][10];   // 10×10 的浮点数方阵
char board[8][8];   // 8×8 的棋盘
bool vis[1005][1005]; // 访问标记（图/迷宫常用）
```

定义时，第一对方括号表示**行数**，第二对表示**列数**。习惯上：

- 用 `n` 表示行数、`m` 表示列数；
- 方阵时两者都用 `n`。

竞赛推荐：

```cpp
const int N = 105;
int a[N][N];
```

### 三、二维数组在内存中的存储方式

二维数组在内存中**并不是**真正的二维表格，而是按**行优先（Row-major order）**展平为一维连续存储。

以 `int a[2][3]` 为例，内存中的存放顺序为：

```
a[0][0] → a[0][1] → a[0][2] → a[1][0] → a[1][1] → a[1][2]
```

也就是说：**先把第 0 行的所有列存完，再存第 1 行**。

地址计算：

```
地址(a[i][j]) = 地址(a[0][0]) + (i * 列数 + j) * sizeof(类型)
```

因此：

1. 按行遍历更“贴合内存”，缓存友好。
2. 初始化时只能省略第一维，第二维必须给定（编译器要知道每行跨度）。
3. 越界写 `a[0][3]` 在 `a[2][3]` 这种布局里，可能实际踩到 `a[1][0]`。

### 四、二维数组的初始化

**方式一：按行初始化（推荐）**

```cpp
int a[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

每组花括号对应一行，清晰直观。

**方式二：不分组初始化**

```cpp
int a[2][3] = {1, 2, 3, 4, 5, 6};
```

效果相同，但不直观，不推荐。

**方式三：部分初始化**

```cpp
int a[3][3] = {0};        // 全部清零
int b[3][3] = {{1, 2}};   // 只有 b[0][0]=1, b[0][1]=2，其余为0
```

**方式四：省略第一维大小**

```cpp
int a[][3] = {
    {1, 2, 3},
    {4, 5, 6}
};  // 编译器自动推导为 2 行
```

**重要规则**：初始化时只能省略第一维（行数），第二维（列数）必须指定。

### 五、二维数组的行列遍历

遍历二维数组的标准模式是**双层 for 循环**：

```cpp
// 输入 n 行 m 列的矩阵
for (int i = 0; i < n; i++) {        // 外层：行
    for (int j = 0; j < m; j++) {    // 内层：列
        cin >> a[i][j];
    }
}

// 按矩阵格式输出
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        cout << a[i][j] << " ";
    }
    cout << endl;  // 每行结束后换行
}
```

**关键规律**：

- 外层 `i` 控制**行**，内层 `j` 控制**列**。
- `a[i][j]`：第 i 行、第 j 列（均从 0 开始）。

**按列遍历**（较少见，但要会）：

```cpp
for (int j = 0; j < m; j++) {
    for (int i = 0; i < n; i++) {
        // 访问 a[i][j]
    }
}
```

### 六、矩阵的常见操作

#### 1. 矩阵转置

转置是将矩阵的行和列互换。若原矩阵 `a[n][m]`，则转置后为 `b[m][n]`，且：

```
b[j][i] = a[i][j]
```

```cpp
// a 为 n 行 m 列，转置到 b（m 行 n 列）
for (int i = 0; i < n; i++) {
    for (int j = 0; j < m; j++) {
        b[j][i] = a[i][j];
    }
}
```

方阵原地转置（只扫上三角）：

```cpp
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        swap(a[i][j], a[j][i]);
    }
}
```

#### 2. 主对角线元素

方阵中主对角线满足 **`i == j`**：

```cpp
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i][i];
}
```

#### 3. 副对角线元素

副对角线从右上到左下，满足 **`i + j == n - 1`**：

```cpp
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i][n - 1 - i];
}
```

**注意中心元素**：当 n 为奇数时，中心既在主对角又在副对角，若分别求和再相加会**重复计算一次**，需要减掉。

#### 4. 边缘元素

```cpp
if (i == 0 || i == n - 1 || j == 0 || j == m - 1) {
    // 边缘元素
}
```

四个条件：第一行、最后一行、第一列、最后一列。  
对 1×1 或 1×m、n×1 的矩阵，所有元素都是边缘。

#### 5. 上三角和下三角

- 上三角（含对角线）：`i <= j`
- 下三角（含对角线）：`i >= j`
- 严格上三角：`i < j`
- 严格下三角：`i > j`

#### 6. 矩阵加法 / 数乘（了解）

```cpp
// C = A + B，同型矩阵
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        c[i][j] = a[i][j] + b[i][j];

// 数乘：k * A
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        a[i][j] *= k;
```

#### 7. 行和、列和、鞍点思想

```cpp
// 第 i 行的和
int rowSum = 0;
for (int j = 0; j < m; j++) rowSum += a[i][j];

// 第 j 列的和
int colSum = 0;
for (int i = 0; i < n; i++) colSum += a[i][j];
```

“鞍点”：某位置是所在行的最小值、所在列的最大值（了解即可，CSP-J 偶见模拟题）。

### 七、杨辉三角

杨辉三角（Pascal 三角形）是二维数组的经典应用。规律：

1. 每行第一个和最后一个元素为 1。
2. 其余元素：`a[i][j] = a[i-1][j-1] + a[i-1][j]`（正上方与左上方之和）。
3. 第 i 行（0-index）有 i+1 个数；也可看成组合数 `C(i, j)`。

```cpp
const int N = 15;
int a[N][N] = {0};

int n;
cin >> n;

for (int i = 0; i < n; i++) {
    a[i][0] = 1;      // 每行第一个为 1
    a[i][i] = 1;      // 每行最后一个为 1
    for (int j = 1; j < i; j++) {
        a[i][j] = a[i - 1][j - 1] + a[i - 1][j];
    }
}

for (int i = 0; i < n; i++) {
    for (int j = 0; j <= i; j++) {
        cout << a[i][j] << " ";
    }
    cout << endl;
}
```

**手算验证（n=5）**

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

其中第 4 行（0-index 第 3 行）的 3 = 1+2，3 = 2+1。

**溢出注意**：n 稍大时中间数增长很快（组合数），必要时用 `long long`。

### 八、二维数组与“地图/迷宫”入门

很多搜索题把地图存成二维数组：

```cpp
char mp[105][105];
// 或
int mp[105][105];  // 0 空地，1 障碍
```

四个方向常用数组：

```cpp
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};
// 从 (x,y) 走到 (x+dx[k], y+dy[k])
```

本课先掌握存储与遍历；DFS/BFS 在后续图论课展开。

### 九、规模与空间估算

| 声明 | 大约空间 | 建议 |
|------|----------|------|
| `int a[100][100]` | 40KB | 随便 |
| `int a[1000][1000]` | 4MB | 全局 |
| `int a[5000][5000]` | 100MB | 常超限，慎用 |
| `bool a[1000][1000]` | 约 1MB | 可接受 |

经验：二维 `int` 开到 1000×1000 量级优先**全局**；更大要想压缩或换算法。

### 十、从一维映射到二维（拓展）

有时用一维数组模拟二维：

```cpp
// 下标：id = i * m + j
int a[n * m];
// 访问 (i,j)
a[i * m + j] = x;
```

理解行优先后，这种写法很自然。竞赛中一般直接用二维更清晰。

### 模板四：对角线与边缘

```cpp
#include <iostream>
using namespace std;

const int N = 105;
int a[N][N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> a[i][j];

    int mainDiag = 0, antiDiag = 0, border = 0;
    for (int i = 0; i < n; i++) {
        mainDiag += a[i][i];
        antiDiag += a[i][n - 1 - i];
        for (int j = 0; j < n; j++) {
            if (i == 0 || i == n - 1 || j == 0 || j == n - 1)
                border += a[i][j];
        }
    }

    // 若需要主+副且 n 为奇数，中心加了两次
    int both = mainDiag + antiDiag;
    if (n % 2 == 1) both -= a[n / 2][n / 2];

    cout << mainDiag << " " << antiDiag << " " << both << " " << border << endl;
    return 0;
}
```

## ⚠️ 易错点

| 序号 | 易错点 | 说明 |
|------|--------|------|
| 1 | **行列混淆** | `a[i][j]` 中 i 是行、j 是列。搞反会错位。 |
| 2 | **只能省略第一维** | `int a[][4]` 合法；`int a[3][]` 非法。 |
| 3 | **内外层循环搞反** | 先列后行会按列扫描，输出格式也错。 |
| 4 | **数组大小需常量** | 每一维都必须是常量表达式（标准 C++）。 |
| 5 | **大数组必须全局** | `int a[1000][1000]` 约 4MB，放局部易栈溢出。 |
| 6 | **杨辉三角内层范围** | 内层是 `j < i`，`a[i][i]` 已单独置 1。 |
| 7 | **转置后的行列数** | n×m 转置后是 m×n，输出循环上下界要交换。 |
| 8 | **对角线重复** | 主+副时奇数阶中心重复计算。 |
| 9 | **边缘重复加** | 用四条边分别加时，四个角会各加两次，需处理。 |
| 10 | **输出格式** | 行末空格一般可有可无，但必须每行换行。 |

**边缘求和的安全写法（避免角重复）**

```cpp
int sum = 0;
for (int i = 0; i < n; i++)
    for (int j = 0; j < m; j++)
        if (i == 0 || i == n - 1 || j == 0 || j == m - 1)
            sum += a[i][j];
```

这种“逐格判断”不会重复。

## 📝 真题精练

### 真题1：矩阵转置输出

**题目描述**

输入一个 n 行 m 列的矩阵 A，输出它的转置矩阵 A^T。

**输入格式**

第一行包含两个整数 n 和 m，表示矩阵 A 的行数和列数。1 ≤ n, m ≤ 100。  
接下来 n 行，每行 m 个整数，表示矩阵 A 的元素。

**输出格式**

输出 m 行，每行 n 个整数，为转置后的矩阵。数与数之间用一个空格隔开。

**样例输入**

```
2 3
1 2 3
4 5 6
```

**样例输出**

```
1 4
2 5
3 6
```

**思路**

`b[j][i] = a[i][j]`，输出时外循环到 m，内循环到 n。

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 105;
int a[N][N], b[N][N];

int main() {
    int n, m;
    cin >> n >> m;

    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            cin >> a[i][j];

    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            b[j][i] = a[i][j];

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            cout << b[i][j] << " ";
        }
        cout << endl;
    }
    return 0;
}
```

### 真题2：杨辉三角

**题目描述**

输入一个正整数 n（n ≤ 20），输出杨辉三角的前 n 行。每行的数之间用一个空格隔开。

**输入格式**

一个正整数 n。

**输出格式**

n 行，第 i 行有 i 个整数，表示杨辉三角的前 n 行。

**样例输入**

```
5
```

**样例输出**

```
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
```

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 25;
int a[N][N];

int main() {
    int n;
    cin >> n;

    for (int i = 0; i < n; i++) {
        a[i][0] = 1;
        a[i][i] = 1;
        for (int j = 1; j < i; j++) {
            a[i][j] = a[i - 1][j - 1] + a[i - 1][j];
        }
    }

    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) {
            cout << a[i][j] << " ";
        }
        cout << endl;
    }
    return 0;
}
```

### 例题3：主对角线与边缘之和

**题目描述**

输入 n（1 ≤ n ≤ 100）及 n×n 整数矩阵。输出两行：  
第一行：主对角线元素之和；  
第二行：边缘元素之和。

**样例输入**

```
3
1 2 3
4 5 6
7 8 9
```

**样例输出**

```
15
40
```

说明：主对角 1+5+9=15；边缘 1+2+3+4+6+7+8+9=40（中心 5 不是边缘）。

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 105;
int a[N][N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            cin >> a[i][j];

    int d = 0, e = 0;
    for (int i = 0; i < n; i++) {
        d += a[i][i];
        for (int j = 0; j < n; j++) {
            if (i == 0 || i == n - 1 || j == 0 || j == n - 1)
                e += a[i][j];
        }
    }
    cout << d << endl << e << endl;
    return 0;
}
```

**练习3 螺旋遍历思路提示**

```
定义四边界 top, bottom, left, right
while 还有未访问元素：
  从左到右扫 top 行，top++
  从上到下扫 right 列，right--
  从右到左扫 bottom 行，bottom--
  从下到上扫 left 列，left++
```

## 🎯 本课小结

1. **二维数组定义**：`类型 数组名[行数][列数]`，内存按行优先连续存储。
2. **初始化要点**：推荐 `{{1,2},{3,4}}`；只能省略第一维；`{0}` 清零。
3. **双层遍历**：外层 i 行，内层 j 列，`a[i][j]` 表示第 i 行第 j 列。
4. **矩阵操作**：转置 `b[j][i]=a[i][j]`；主对角 `i==j`；副对角 `i+j==n-1`；边缘四条件。
5. **杨辉三角**：`a[i][j]=a[i-1][j-1]+a[i-1][j]`，首尾为 1，内层 `j < i`。
6. **易错防范**：行列不反、大数组全局、对角线中心重复、边缘角点重复。

**一句话记忆**：二维数组是“行优先的表格”；外层行内层列；转置换下标，杨辉看上一行。
