# 第4课：输入输出与格式化

## 🎯 考纲要求
- cin / cout 基本输入输出
- scanf / printf 格式化输入输出
- 格式化输出（setw、setprecision、fixed）
- 转义字符（\n \t \\ \")
- getchar / putchar

## 📖 知识精讲

### 一、C++ 输入输出流（cin / cout）

**cout（输出）**：
```cpp
cout << 内容1 << 内容2 << ...;
```
- `<<` 是输出运算符（流插入运算符）
- 可以**链式调用**：`cout << a << b << c;`
- `endl` 表示换行并刷新缓冲区
- `"\n"` 仅换行不刷新，效率更高

**cin（输入）**：
```cpp
cin >> 变量1 >> 变量2 >> ...;
```
- `>>` 是输入运算符（流提取运算符）
- 以**空白字符**（空格、Tab、换行）作为分隔
- 自动跳过前导空白

**优化输入输出速度**（竞赛常用技巧）：
```cpp
ios::sync_with_stdio(false);  // 关闭与C流的同步，加速cin/cout
cin.tie(0);                    // 解除cin与cout的绑定
```
注意：使用这两行代码后，不要混用 `cin/cout` 和 `scanf/printf`。

### 二、C风格输入输出（scanf / printf）

**printf（格式化输出）**：
```cpp
printf("格式控制字符串", 参数列表);
```

**常用格式符**：

| 格式符 | 含义 | 示例 |
|--------|------|------|
| `%d` | 十进制整数(int) | `printf("%d", 42);` → 42 |
| `%lld` | 长整型(long long) | `printf("%lld", 10000000000LL);` |
| `%f` | 浮点数(double) | `printf("%f", 3.14);` → 3.140000 |
| `%lf` | scanf中的double | `scanf("%lf", &x);` |
| `%c` | 单个字符 | `printf("%c", 'A');` → A |
| `%s` | 字符串 | `printf("%s", "hello");` → hello |
| `%x` / `%X` | 十六进制 | `printf("%x", 255);` → ff |
| `%o` | 八进制 | `printf("%o", 8);` → 10 |
| `%%` | 输出百分号 | `printf("%%");` → % |

**printf 宽度与精度控制**：
```cpp
printf("%8d", 42);       // 宽度8，右对齐 → "      42"
printf("%-8d", 42);      // 宽度8，左对齐 → "42      "
printf("%08d", 42);      // 宽度8，前导0填充 → "00000042"
printf("%.2f", 3.14159); // 保留2位小数 → "3.14"
printf("%8.2f", 3.14);   // 宽度8，2位小数 → "    3.14"
```

**scanf（格式化输入）**：
```cpp
scanf("格式控制字符串", &变量1, &变量2, ...);
```
- **务必加取地址符 `&`**（最容易忘记！）
- 数组名已经是指针，不需要 `&`

### 三、格式化输出操纵符（iomanip）

需要包含头文件 `<iomanip>`。

**setw(n)**：设置输出宽度为n
```cpp
cout << setw(8) << 42; // 宽度8，默认右对齐
```

**setprecision(n)**：配合fixed表示保留n位小数
```cpp
cout << fixed << setprecision(2) << 3.14159; // 3.14
```

**fixed**：以固定小数点表示法输出
```cpp
cout << fixed << 3.14159 << endl;  // 3.141590
```

**left / right**：左对齐 / 右对齐
```cpp
cout << left << setw(10) << "Hello";   // Hello     
cout << right << setw(10) << "Hello";  //      Hello
```

### 四、转义字符

| 转义字符 | 含义 | ASCII码 |
|---------|------|---------|
| `\n` | 换行（newline） | 10 |
| `\t` | 水平制表（Tab） | 9 |
| `\\` | 反斜杠本身 | 92 |
| `\"` | 双引号 | 34 |
| `\'` | 单引号 | 39 |
| `\0` | 空字符（字符串结束标志） | 0 |

### 五、getchar / putchar（字符输入输出）

**getchar()**：从标准输入读取一个字符，返回该字符的ASCII码。
```cpp
char ch = getchar();  // 读取一个字符
```

**putchar(c)**：向标准输出写一个字符。
```cpp
putchar('A');  // 输出字符A
putchar(65);   // 输出字符A（ASCII码65）
```

### 六、cin/cout vs scanf/printf 对比

| 特性 | cin/cout | scanf/printf |
|------|----------|-------------|
| 格式化控制 | 弱（需iomanip辅助） | 强（格式字符串灵活） |
| 类型安全 | 强（自动类型匹配） | 弱（需手动指定格式符） |
| 默认速度 | 慢 | 快 |
| 使用难度 | 简单 | 中等 |

**CSP-J建议**：日常练习用cin/cout，格式化输出优先用printf。

## 💻 代码模板

### 标准输入输出模板
```cpp
#include <iostream>
#include <cstdio>
#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    double x;
    
    cin >> n >> x;
    cout << n << " " << x << endl;
    
    return 0;
}
```

### 格式化输出模板
```cpp
#include <iostream>
#include <iomanip>
#include <cstdio>
using namespace std;

int main() {
    double pi = 3.1415926535;
    
    // cout方式：保留3位小数
    cout << fixed << setprecision(3);
    cout << "PI = " << pi << endl;     // 3.142
    
    // printf方式：保留3位小数，宽度10
    printf("PI = %10.3f\n", pi);       // PI =      3.142
    
    return 0;
}
```

## ⚠️ 易错点

- **scanf忘记取地址符&**：`scanf("%d", a)` 错误，应该 `scanf("%d", &a)`。这是最高频的错误。
- **printf格式符不匹配**：用 `%d` 输出 `long long` 会出错。long long 用 `%lld`。
- **cin读取字符串遇空格停止**：要读取带空格的整行，使用 `getline(cin, str)`。
- **setprecision含义**：不带fixed时是有效数字位数，带fixed时是小数位数。两者完全不同。
- **cin/cout与scanf/printf混用**：在未关闭同步的情况下混用可能导致输出顺序混乱。

## 📝 真题精练

### 题目1：格式化输出判断
**题目描述**：阅读以下程序，写出输出结果。
```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int main() {
    double x = 3.14159;
    cout << fixed << setprecision(3);
    cout << x << endl;
    cout << setw(10) << x << endl;
    return 0;
}
```

**答案**：
```
3.142
     3.142
```
**解析**：fixed + setprecision(3) 保留3位小数，四舍五入得3.142。setw(10) 宽度10右对齐，前有6个空格。

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x = 3.14159;
    cout << fixed << setprecision(3);
    cout << x << endl;              // 3.142
    cout << setw(10) << x << endl;  // "     3.142"
    
    printf("printf方式: %10.3f\n", x);
    return 0;
}
```

### 题目2：scanf输入
**题目描述**：以下程序运行时输入 `10 20`，输出的结果是什么？
```cpp
#include <cstdio>
int main() {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("a=%d\n", a);
    printf("b=%d\n", b);
    printf("a+b=%d\n", a + b);
    return 0;
}
```

**答案**：
```
a=10
b=20
a+b=30
```

```cpp
#include <cstdio>

int main() {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("a=%d\n", a);
    printf("b=%d\n", b);
    printf("a+b=%d\n", a + b);
    return 0;
}
```

## 🎯 本课小结
1. cin/cout 适合一般场景，scanf/printf 适合格式化输出和大数据量
2. printf 格式符：%d(int)、%lld(long long)、%f(double)、%c(char)
3. scanf 必须加 `&` 取地址符；printf 的 double 用 `%f` 而非 `%lf`
4. 格式化小数：`cout << fixed << setprecision(n)` 或 `printf("%.nf", x)`
5. 转义字符：\n换行、\t制表、\\反斜杠、\"双引号
6. ios::sync_with_stdio(false) 加速cin/cout，之后不能混用scanf/printf
