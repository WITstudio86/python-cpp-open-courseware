## 📖 知识精讲

### 一、为什么输入输出如此重要

CSP-J 几乎每道编程题都要：

1. **读入**题目给定的数据；
2. **计算**得到答案；
3. **按格式输出**（空格、换行、小数位数都可能影响正确性）。

输出多一个空格、少一个换行、小数位数不对，都可能被判 **WA**。因此 I/O 是“得分基础设施”。

C++ 中常用两套体系：

| 体系 | 代表 | 特点 |
|------|------|------|
| C++ 流 | `cin` / `cout` | 类型安全、写法简洁 |
| C 风格 | `scanf` / `printf` | 格式控制强、通常更快 |

竞赛中两者都会考、都会用。

---

### 二、`cout` 输出流

#### 1. 基本语法

```cpp
#include <iostream>
using namespace std;

cout << 内容1 << 内容2 << ... ;
```

- `<<` 称为**流插入运算符**（输出运算符）。
- 支持**链式调用**：从左到右依次输出。

```cpp
int a = 3, b = 5;
cout << "a=" << a << ", b=" << b << endl;
// 输出：a=3, b=5
```

#### 2. 换行：`endl` 与 `\n`

| 写法 | 含义 | 特点 |
|------|------|------|
| `endl` | 换行并**刷新缓冲区** | 安全直观，大量输出时可能稍慢 |
| `"\n"` | 仅换行 | 通常更快，竞赛大数据输出更常用 |

```cpp
cout << "第一行" << endl;
cout << "第二行\n";
```

#### 3. 常见输出模式

```cpp
// 空格分隔
cout << a << " " << b << " " << c << "\n";

// 直接拼接
cout << "Hello, " << name << "!\n";

// 多行
cout << a << "\n" << b << "\n";
```

#### 4. 布尔输出

默认 `bool` 输出为 `1` / `0`：

```cpp
bool ok = true;
cout << ok;  // 1
```

若需文字 true/false（了解即可）：

```cpp
cout << boolalpha << ok;  // true
```

### 三、`cin` 输入流

#### 1. 基本语法

```cpp
cin >> 变量1 >> 变量2 >> ...;
```

- `>>` 称为**流提取运算符**（输入运算符）。
- 默认以**空白字符**（空格、Tab、换行）作为分隔。
- 会**自动跳过前导空白**。

```cpp
int a, b;
cin >> a >> b;
// 输入：10   20\n  或  10\n20\n  都可以
```

#### 2. 读入示例

```cpp
int n;
double x;
char ch;
cin >> n >> x >> ch;
```

#### 3. 与字符串相关的注意点（预告）

- `cin >> s` 读 `string` 或字符数组时，**遇空白停止**。
- 若要读整行（含空格），用 `getline(cin, str)`（后续字符串课深入）。

```cpp
string s;
cin >> s;           // 输入 "hello world" 只得到 "hello"
// getline(cin, s); // 得到整行
```

#### 4. 输入失败（了解）

类型不匹配时，`cin` 会进入失败状态。初学保证输入格式与变量类型一致即可。

---

### 四、I/O 加速（竞赛常用）

默认情况下，`cin/cout` 与 C 的 `stdio` 同步，较慢。大数据量时推荐：

```cpp
ios::sync_with_stdio(false);
cin.tie(nullptr);   // 或 cin.tie(0);
// 可选：cout.tie(nullptr);
```

**含义**：

1. `ios::sync_with_stdio(false)`：关闭 C++ 流与 C 流的同步，显著加速 `cin/cout`。
2. `cin.tie(nullptr)`：解除 `cin` 与 `cout` 的绑定，避免每次输入前强制刷新输出。

**重要限制**：

- 关闭同步后，**不要混用** `cin/cout` 与 `scanf/printf`（可能乱序或读错）。
- 二选一：要么整题用流，要么整题用 C I/O。

**完整比赛模板头**：

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 题解代码
    return 0;
}
```

### 五、`printf` 格式化输出

#### 1. 基本形式

```cpp
#include <cstdio>
printf("格式控制字符串", 参数1, 参数2, ...);
```

格式控制字符串中的**转换说明**以 `%` 开头，按顺序与后面参数匹配。

#### 2. 常用格式符（必须背）

| 格式符 | 含义 | 示例 | 典型输出 |
|--------|------|------|----------|
| `%d` | `int` 十进制 | `printf("%d", 42);` | `42` |
| `%lld` | `long long` | `printf("%lld", 1e10);` | `10000000000` |
| `%f` | `double`（printf 中） | `printf("%f", 3.14);` | `3.140000` |
| `%c` | 字符 | `printf("%c", 'A');` | `A` |
| `%s` | C 字符串 | `printf("%s", "hi");` | `hi` |
| `%x` / `%X` | 十六进制 | `printf("%x", 255);` | `ff` / `FF` |
| `%o` | 八进制 | `printf("%o", 8);` | `10` |
| `%%` | 输出百分号 | `printf("100%%");` | `100%` |

> **易混点**：`printf` 输出 `double` 用 `%f`；`scanf` 读 `double` 用 `%lf`。

#### 3. 宽度、对齐、填充、精度

格式大致为：`%[标志][宽度][.精度]转换符`

```cpp
printf("%8d", 42);        // 宽度 8，右对齐 → "      42"
printf("%-8d", 42);       // 左对齐 → "42      "
printf("%08d", 42);       // 前导 0 → "00000042"
printf("%.2f", 3.14159);  // 两位小数 → "3.14"
printf("%8.2f", 3.14);    // 宽度 8 + 两位小数 → "    3.14"
printf("%-10.3f", 3.14);  // 左对齐宽度 10 → "3.140     "
```

#### 4. `long long` 必须用 `%lld`

```cpp
long long x = 10000000000LL;
printf("%lld\n", x);   // 正确
// printf("%d\n", x);  // 错误：格式符不匹配，结果未定义
```

部分旧环境 Windows 用 `%I64d`，CSP-J / 主流 Linux OJ 用 **`%lld`**。

### 六、`scanf` 格式化输入

#### 1. 基本形式

```cpp
scanf("格式控制字符串", &变量1, &变量2, ...);
```

**铁律：普通变量必须取地址 `&`！**

```cpp
int a, b;
scanf("%d%d", &a, &b);     // 正确
// scanf("%d%d", a, b);    // 错误：致命
```

#### 2. 常用输入格式符

| 格式符 | 对应类型 | 备注 |
|--------|----------|------|
| `%d` | `int` | |
| `%lld` | `long long` | |
| `%f` | `float` | |
| `%lf` | `double` | **读 double 用 %lf** |
| `%c` | `char` | 会读入空白字符，需小心 |
| `%s` | 字符数组 | 遇空白停止，注意越界 |

```cpp
int n;
long long x;
double y;
char ch;
scanf("%d%lld%lf", &n, &x, &y);
scanf(" %c", &ch);  // 前有空格可跳过空白再读字符
```

#### 3. 数组名不必再加 `&`

```cpp
char s[100];
scanf("%s", s);     // 正确：数组名退化为指针
// scanf("%s", &s); // 类型其实也不对，不要这样写
```

#### 4. 返回值（进阶）

`scanf` 返回成功读入的变量个数，可用于判断输入结束：

```cpp
while (scanf("%d", &x) == 1) {
    // 处理 x
}
```

CSP-J 多数题目输入规模明确，用 `for` 读满即可。

### 七、C++ 格式化操纵符（`<iomanip>`）

#### 1. 头文件

```cpp
#include <iomanip>
```

#### 2. `setw(n)`：设置**下一次**输出的宽度

```cpp
cout << setw(8) << 42;   // 宽度 8，默认右对齐
```

注意：`setw` **只作用于紧接着的一次**输出，用完即失效。

```cpp
cout << setw(5) << 1 << setw(5) << 2 << "\n";
// 需要每次都写 setw
```

#### 3. `setprecision(n)` 与 `fixed`

| 组合 | 含义 |
|------|------|
| 仅 `setprecision(n)` | 默认表示**有效数字**位数（非 fixed 时） |
| `fixed` + `setprecision(n)` | **小数点后**保留 n 位 |

```cpp
double pi = 3.1415926535;
cout << setprecision(3) << pi << endl;           // 可能是 3.14（有效数字相关）
cout << fixed << setprecision(3) << pi << endl;  // 3.142
```

**考试高频**：题目要求“保留 k 位小数” → 用：

```cpp
cout << fixed << setprecision(k);
cout << ans << "\n";
```

或：

```cpp
printf("%.kf\n", ans);  // 把 k 换成具体数字，如 %.2f
```

#### 4. `left` / `right` / `setfill`

```cpp
cout << left << setw(10) << "Hello";   // 左对齐
cout << right << setw(10) << "Hello";  // 右对齐（默认）
cout << setfill('0') << setw(5) << 42; // 00042
cout << setfill(' ');                  // 改回空格填充
```

#### 5. `fixed` 的持续性

`fixed`、`setprecision` 的设置会**保持**，直到再次修改；而 `setw` 只一次。

```cpp
cout << fixed << setprecision(2);
cout << 1.234 << "\n";  // 1.23
cout << 5.6 << "\n";    // 5.60
```

### 八、转义字符

在字符/字符串字面量中，反斜杠 `\` 开始转义序列：

| 转义字符 | 含义 | ASCII |
|----------|------|-------|
| `\n` | 换行 | 10 |
| `\t` | 水平制表 Tab | 9 |
| `\\` | 反斜杠本身 | 92 |
| `\"` | 双引号 | 34 |
| `\'` | 单引号 | 39 |
| `\0` | 空字符（C 字符串结束标志） | 0 |
| `\r` | 回车 | 13 |
| `\a` | 响铃（了解） | 7 |

```cpp
cout << "第一行\n第二行\n";
cout << "A\tB\tC\n";
cout << "路径: C:\\Users\\name\n";
cout << "他说: \"你好\"\n";
cout << "字符: \'A\'\n";
printf("正确率 100%%\n");  // printf 中 % 要写成 %%
```

**易错**：

- 想输出反斜杠，必须写 `\\`。
- `printf` 想输出 `%`，必须写 `%%`。
- `\0` 是字符串结束符，中间出现会导致 `%s` 提前结束。

### 九、`getchar` / `putchar`

#### 1. `getchar`

从标准输入读**一个字符**，返回其 ASCII（类型实际为 `int`，以便表示 EOF）。

```cpp
#include <cstdio>
char ch = getchar();
// 或 int c = getchar(); if (c != EOF) ...
```

#### 2. `putchar`

输出一个字符：

```cpp
putchar('A');
putchar(65);   // 同样输出 A
```

#### 3. 与 `cin` 读 `char` 的差别（概念）

- `cin >> ch` 会跳过空白。
- `getchar()` **不会**主动跳过空白，空格、换行都会读进来。

常用于：逐字符处理、读完整行、卡常时的快速读入模板（进阶）。

#### 4. 简单示例

```cpp
// 读入一个字符并输出其 ASCII
char c = getchar();
printf("%c %d\n", c, (int)c);
```

### 十、`cin/cout` vs `scanf/printf` 对比与选型

| 特性 | cin/cout | scanf/printf |
|------|----------|--------------|
| 类型安全 | 强，自动匹配类型 | 弱，格式符写错就炸 |
| 格式化能力 | 需 iomanip，稍繁 | 格式串强大 |
| 默认速度 | 慢；关同步后很快 | 通常快 |
| 学习难度 | 入门简单 | 格式符需记忆 |
| 混用风险 | 关同步后勿混用 | 同上 |

**CSP-J 建议**：

1. 日常与多数题：`cin/cout` + 加速三件套。
2. 严格小数格式、列对齐：`printf` 往往更省事。
3. 同一程序选定一种主 I/O，避免混用。
4. 输出“保留 k 位小数”优先：

```cpp
printf("%.2f\n", x);
// 或
cout << fixed << setprecision(2) << x << "\n";
```

### 十二、缓冲区与混用陷阱（加深）

#### 1. `endl` 刷新

频繁 `endl` 在超大输出时可能拖慢程序，可改用 `'\n'`，最后再适当刷新。

#### 2. `cin` 与 `getline` 混用（预告）

`cin >> n` 后行尾换行残留，接着 `getline` 可能读到空行。解决：`cin.ignore(...)` 或统一读法。字符串课再练。

#### 3. `scanf("%c")` 读到换行

上一次输入残留的 `\n` 可能被 `%c` 读走。可在格式串前加空格：`scanf(" %c", &ch)`。

### 十三、格式化对照速查表

**保留 2 位小数**：

```cpp
printf("%.2f\n", x);
cout << fixed << setprecision(2) << x << "\n";
```

**宽度 10、右对齐整数**：

```cpp
printf("%10d\n", n);
cout << setw(10) << n << "\n";
```

**前导 0 的 4 位数**：

```cpp
printf("%04d\n", n);  // 7 → 0007
```

**long long**：

```cpp
printf("%lld\n", x);
cout << x << "\n";    // cout 无需区分格式符
```

## 💻 代码模板

### 模板 1：竞赛标准 I/O 头（cin/cout）

```cpp

#include <iomanip>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    double x;
    cin >> n >> x;
    cout << fixed << setprecision(2);
    cout << n << " " << x << "\n";
    return 0;
}
```

### 模板 2：scanf / printf 常用骨架

```cpp
#include <cstdio>

int main() {
    int n;
    long long s = 0;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        int x;
        scanf("%d", &x);
        s += x;
    }
    printf("%lld\n", s);
    return 0;
}
```

```cpp
#include <iostream>

#include <cstdio>
using namespace std;

int main() {
```

## ⚠️ 易错点

### 易错点 1：`scanf` 忘记取地址 `&`

**错误示例**：

```cpp
int a;
scanf("%d", a);   // 错！
```

**正确示例**：

```cpp
int a;
scanf("%d", &a);
```

**解析**：`scanf` 需要指针以写入变量；漏 `&` 是最高频 CE/RE/WA 原因之一。

---

### 易错点 2：`printf` 格式符与类型不匹配

**错误示例**：

```cpp
long long x = 10000000000LL;
printf("%d\n", x);   // 错
double y = 3.14;
printf("%d\n", y);   // 错
```

**正确示例**：

```cpp
long long x = 10000000000LL;
printf("%lld\n", x);
double y = 3.14;
printf("%f\n", y);   // printf 的 double 用 %f
```

**解析**：格式符错误属于未定义行为，可能打印乱值却仍“能跑”。

---

### 易错点 3：`setprecision` 与 `fixed` 搞混

**错误理解**：

```cpp
// 以为 setprecision(3) 一定是三位小数
cout << setprecision(3) << 123.456789 << endl;
```

**正确示例**：

```cpp
cout << fixed << setprecision(3) << 123.456789 << endl;  // 123.457
```

**解析**：无 `fixed` 时 `setprecision` 控制的是有效数字相关表现；要“小数点后 k 位”必须配合 `fixed`（或用 `printf`）。

---

### 易错点 4：`setw` 只生效一次却期望一直生效

**错误示例**：

```cpp
cout << setw(5) << 1 << 2 << 3 << endl;
// 只有 1 有宽度，2 和 3 没有
```

**正确示例**：

```cpp
cout << setw(5) << 1 << setw(5) << 2 << setw(5) << 3 << endl;
```

**解析**：`setw` 是“一次性”操纵符。

---

### 易错点 5：关闭同步后混用两套 I/O

**错误示例**：

```cpp
ios::sync_with_stdio(false);
cin >> a;
printf("%d\n", a);  // 危险：可能异常
```

**正确示例**：

```cpp
ios::sync_with_stdio(false);
cin >> a;
cout << a << "\n";  // 统一用流
// 或全程 scanf/printf，且不要乱开关同步
```

**解析**：混用可能导致输入错位、输出顺序混乱。

---

### 易错点 6：`cin` 读字符串遇空格截断

**错误示例**（期望读整句）：

```cpp
string s;
cin >> s;  // 输入 Hello World 只得到 Hello
```

**正确示例**：

```cpp
string s;
getline(cin, s);  // 读整行
```

**解析**：`>>` 以空白为分隔；整行输入用 `getline`。

---

### 易错点 7：转义与百分号

**错误示例**：

```cpp
cout << "C:\new\test";     // \n 被当成换行
printf("正确率 100%\n");   // % 后格式残缺
```

**正确示例**：

```cpp
cout << "C:\\new\\test\n";
printf("正确率 100%%\n");
```

### 易错点 8：`scanf` 读 `double` 用错格式

**错误示例**：

```cpp
double x;
scanf("%f", &x);  // %f 对应 float*
```

**正确示例**：

```cpp
double x;
scanf("%lf", &x);
float y;
scanf("%f", &y);
```

**解析**：记口诀——**扫 double 用 `%lf`，打 double 用 `%f`**。

### 真题 1：格式化输出阅读题

**题目描述**

阅读下列程序，写出输出结果（每行输出后的空格请仔细数清）。

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double x = 3.14159;
    cout << fixed << setprecision(3);
    cout << x << endl;
    cout << setw(10) << x << endl;
    return 0;
}
```

**答案**：

```
3.142
     3.142
```

**解析**：

1. `fixed + setprecision(3)`：小数点后 3 位，四舍五入得 `3.142`。
2. `setw(10)`：字段宽 10，默认右对齐；`3.142` 占 5 个字符，前面补 5 个空格（以常见实现为准）。
3. 第二行看起来像“缩进的 3.142”。

**AC 扩展代码**（同时对照 printf）：

```cpp
#include <iostream>
#include <iomanip>
#include <cstdio>
using namespace std;

int main() {
    double x = 3.14159;
    cout << fixed << setprecision(3);
    cout << x << endl;              // 3.142
    cout << setw(10) << x << endl;  // 右对齐宽度 10

    printf("printf: %10.3f\n", x);  // 对照
    return 0;
}
```

### 真题 2：`scanf` 输入与输出

**题目描述**

程序运行时输入：

```
10 20
```

下列程序输出是什么？

```cpp
#include <cstdio>
int main() {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("a=%d\n", a);
    printf("b=%d\n", b);
    printf("a+b=%d\n", a + b);
    return 0;
}
```

**答案**：

```
a=10
b=20
a+b=30
```

**解析**：`scanf("%d%d", &a, &b)` 从空白分隔的输入中读取两个整数；`printf` 按格式串逐行输出。注意两个 `%d` 之间可以没有空格，`scanf` 仍能正确跳过空白。

**AC 代码**：

```cpp
#include <cstdio>

int main() {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("a=%d\n", a);
    printf("b=%d\n", b);
    printf("a+b=%d\n", a + b);
    return 0;
}
```

**无交互验证版**（课堂演示可用写死值）：

```cpp
#include <cstdio>
#include <iostream>
using namespace std;

int main() {
    // 模拟输入 10 20
    int a = 10, b = 20;
    // 真实写法：scanf("%d%d", &a, &b);
    printf("a=%d\n", a);
    printf("b=%d\n", b);
    printf("a+b=%d\n", a + b);
    return 0;
}
```

### 真题 3：保留小数与类型（补充）

**题目描述**

输入一个圆的半径 r（实数），输出周长与面积，保留 2 位小数。  
圆周率取 3.14159。  
（模拟题，训练格式化）

**样例输入**：

```
5
```

**样例输出**：

```
31.42 78.54
```

**AC 代码**：

```cpp
#include <iostream>
#include <iomanip>
#include <cstdio>
using namespace std;

int main() {
    const double PI = 3.14159;
    double r;
    cin >> r;
    double c = 2 * PI * r;
    double area = PI * r * r;

    // 写法一
    cout << fixed << setprecision(2) << c << " " << area << "\n";

    // 写法二（任选其一即可）
    // printf("%.2f %.2f\n", c, area);
    return 0;
}
```

**解析**：面积公式 \(\pi r^2\)，周长 \(2\pi r\)；输出格式是得分关键。注意用 `double` 与 `fixed/setprecision` 或 `printf("%.2f")`。

### 真题 4：转义字符阅读

**题目描述**

下列语句的输出是？

```cpp
cout << "A\tB\nC\\D\"E";
```

**答案**（示意）：

```
A	B
C\D"E
```

**解析**：

- `\t`：A 与 B 之间为制表符；
- `\n`：换行；
- `\\`：输出一个 `\`；
- `\"`：输出一个 `"`。

**演示代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "A\tB\nC\\D\"E" << endl;
    return 0;
}
```

## 🎯 本课小结

1. **`cin/cout`**：链式 `>>` / `<<`；空白分隔输入；`endl` 换行并刷新，`\n` 通常更快。
2. **加速**：`ios::sync_with_stdio(false); cin.tie(nullptr);` 后不要混用 C I/O。
3. **`printf`**：`%d %lld %f %c %s`；宽度精度如 `%8.2f`；`long long` 用 `%lld`。
4. **`scanf`**：必须 `&`；读 `double` 用 `%lf`；数组名作 `%s` 目标时不加 `&`。
5. **`iomanip`**：`setw` 一次性；`fixed+setprecision(k)` 保留 k 位小数。
6. **转义**：`\n \t \\ \" \' \0`；`printf` 中 `%%` 输出百分号。
7. **`getchar/putchar`**：单字符读写；`getchar` 不跳过空白。
8. **选型**：一般题用加速后的 `cin/cout`；强格式化可用 `printf`。
