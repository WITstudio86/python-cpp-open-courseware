### 一、第一轮考试策略总览

CSP-J 第一轮考试为笔试形式，考试时间为 2 小时，满分 100 分。试卷结构通常为：单项选择题（约 30 分）、程序阅读题（约 30-35 分）、程序填空/完善程序题（约 30-35 分）。第一轮考试的核心在于：**准确率优先，时间分配合理**。

#### 1.1 时间管理策略

考试时间 120 分钟，建议分配如下：

| 阶段 | 时间 | 任务 |
|------|------|------|
| 选择题 | 30-35 分钟 | 15 道选择题，平均每题 2 分钟 |
| 程序阅读 | 35-40 分钟 | 5 道程序阅读，平均每题 7-8 分钟 |

**关键原则**：遇到卡壳超过 3 分钟的题目，立即标记并跳过，待全部完成后再回头攻克。不要因一道题影响整体节奏。

#### 1.2 选择题答题技巧

第一轮选择题考查范围广泛，涵盖计算机基础、进制转换、语法语义、简单算法等。常用技巧包括：

**（1）排除法**：当无法直接确定正确答案时，逐个排除明显错误的选项。例如：

```cpp
// 题目：以下程序的输出是什么？
int a = 5, b = 3;
cout << (a & b) << endl;
// A. 0    B. 1    C. 5    D. 8
```

分析：5 的二进制是 101，3 的二进制是 011。按位与：101 & 011 = 001 = 1。若不确定，可以先排除明显不对的选项——5 & 3 不可能大于 5，排除 C、D；5 和 3 都不是 0，按位与结果一般不为 0（除非没有相同位为 1 的位置），但这里第 0 位都是 1，结果至少是 1，所以排除 A。答案是 B。

**（2）代入验证法**：将选项反代回题目条件中验证。对于计算类题目特别有效，比如进制转换题：若题目问十六进制 2F 对应的十进制值，可以快速计算 2×16+15=47，然后在选项中找 47。

**（3）特殊值法**：对于分析程序执行结果的题目，如果变量取值范围特殊（如边界值），可代入 0、1、-1 等特殊值快速验证。

#### 1.3 程序阅读题答题技巧

程序阅读题要求考生阅读给定的 C++ 程序，推断输出结果。这是第一轮考试中失分最多的题型之一。以下是几个关键技巧：

**（1）模拟执行法**：在草稿纸上建立变量表格，逐行模拟程序执行过程。

```cpp
// 例题：请写出以下程序的输出
int a[5] = {1, 2, 3, 4, 5};
int s = 0;
for (int i = 0; i < 5; i++) {
    if (a[i] % 2 == 0) s += a[i];
    else s -= a[i];
}
cout << s;
```

模拟执行：

| i | a[i] | a[i]%2==0 | s 的变化 | s 的值 |
|---|------|-----------|---------|--------|
| 0 | 1    | false     | s = 0 - 1 | -1 |
| 1 | 2    | true      | s = -1 + 2 | 1 |
| 2 | 3    | false     | s = 1 - 3 | -2 |
| 3 | 4    | true      | s = -2 + 4 | 2 |
| 4 | 5    | false     | s = 2 - 5 | -3 |

输出：-3

**（2）识别常见陷阱**：

- **循环边界陷阱**：注意 `<=` 和 `<` 的区别，`for (int i = 0; i <= n; i++)` 执行 n+1 次。
- **自增自减陷阱**：`a[i++]` 与 `a[++i]` 的区别——前者先使用 i 再自增，后者先自增再使用。
- **整数除法陷阱**：`int a = 5 / 2;` 结果是 2 而非 2.5。
- **continue 与 break 陷阱**：`continue` 跳过本次循环剩余部分，`break` 跳出整个循环。
- **switch 的 break 缺失陷阱**：`switch` 语句中如果没有 `break`，会发生"穿透"现象，继续执行下一个 case。

```cpp
// 陷阱示例：switch穿透
int x = 2;
switch (x) {
    case 1: cout << "A";
    case 2: cout << "B";
    case 3: cout << "C"; break;
    default: cout << "D";
}
// 输出：BC（因为 case 2 没有 break，穿透到 case 3）
```

**（3）函数调用追踪**：当程序中包含函数调用时，在草稿纸上标注参数传递和返回值，特别注意局部变量的作用域。

#### 1.4 程序填空题答题技巧

程序填空题要求根据上下文逻辑补全缺失代码，通常每个空 3-5 分。

**（1）整体阅读法**：不要直接看空，先把完整程序通读一遍，理解程序的整体功能和算法思路。很多空是可以通过上下文"推断"出来的——前面有某个变量的赋值，后面就在使用它，中间的空往往是对该变量的处理。

**（2）对称法**：许多程序存在对称结构，如二分查找的左半部分和右半部分处理、交换两个变量的三行代码等。利用对称性可以快速推断出缺失的内容。

**（3）常见模式识别**：CSP-J 第一轮程序填空题有几种高频出题模式：

- **数组遍历模式**：`for (int i = 0; i < n; i++)` 或 `for (int i = 1; i <= n; i++)`——区分下标从 0 还是 1 开始
- **最大值/最小值模式**：初始化为 `a[0]` 或 `INT_MIN`/`INT_MAX`
- **排序算法中的交换模式**：`swap(a[i], a[j])` 或三变量交换
- **递归终止条件**：`if (n == 0) return 1;`（阶乘）或 `if (n <= 1) return n;`（斐波那契）

## 💻 代码模板

### 进制转换模板

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

// 十进制转任意进制（2-36）
string decToBase(int n, int base) {
    if (n == 0) return "0";
    string digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    string result = "";
    while (n > 0) {
        result += digits[n % base];
        n /= base;
    }
    reverse(result.begin(), result.end());
    return result;
}

// 任意进制转十进制
int baseToDec(string s, int base) {
    int result = 0;
    for (char c : s) {
        int digit;
        if (c >= '0' && c <= '9') digit = c - '0';
        else digit = c - 'A' + 10;
        result = result * base + digit;
    }
    return result;
}

int main() {
    cout << "255 in binary: " << decToBase(255, 2) << endl;   // 11111111
    cout << "255 in octal: " << decToBase(255, 8) << endl;    // 377
    cout << "255 in hex: " << decToBase(255, 16) << endl;     // FF
    cout << "FF hex to dec: " << baseToDec("FF", 16) << endl; // 255
    return 0;
}
```

### 数组与字符串操作模板

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>
using namespace std;

int main() {
    // 一维数组遍历：求和、求最值
    int a[] = {3, 1, 4, 1, 5, 9, 2, 6};
    int n = sizeof(a) / sizeof(a[0]);
```

### 位运算模板

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5;  // 0101
    int b = 3;  // 0011

    cout << "a & b = " << (a & b) << endl;   // 1  (0001) 按位与
    cout << "a | b = " << (a | b) << endl;   // 7  (0111) 按位或
    cout << "a ^ b = " << (a ^ b) << endl;   // 6  (0110) 按位异或
    cout << "~a = " << (~a) << endl;          // -6 (按位取反)
    cout << "a << 1 = " << (a << 1) << endl; // 10 (左移1位，相当于乘2)
    cout << "a >> 1 = " << (a >> 1) << endl; // 2  (右移1位，相当于除2)

    // 位运算常用技巧
    int x = 8;
    // 判断奇偶
    cout << (x & 1 ? "Odd" : "Even") << endl;  // Even
    // 判断是否为2的幂
    cout << ((x & (x - 1)) == 0 ? "Power of 2" : "Not") << endl; // Power of 2
    // 获取第k位（最低位为第0位）
    int k = 2;
    cout << "Bit " << k << ": " << ((x >> k) & 1) << endl; // Bit 2 of 8(1000) = 0

    return 0;
}
```

## ⚠️ 易错点

- **自增运算符的副作用**：`int i = 1; int x = i++ + ++i;` 这种表达式的结果在不同编译器中可能不同（UB，未定义行为）。CSP-J 中通常要求分析确定的行为，遇到时要特别小心。口诀：`i++` 先用后加，`++i` 先加后用。
- **整数除法的精度丢失**：`1 / 2` 的结果是 0，不是 0.5。如果需要小数结果，必须将至少一个操作数转为浮点型：`1.0 / 2` 或 `(double)1 / 2`。
- **数组越界**：C++ 不检查数组边界，`int a[5]; a[5] = 10;` 虽然可能编译通过，但访问了非法内存。程序阅读题中要特别注意循环条件中 `<=` 和 `<` 的区别。
- **逻辑运算符短路特性**：`A && B` 中如果 A 为 false，B 不会被执行；`A || B` 中如果 A 为 true，B 不会被执行。在程序阅读题中，短路可能导致某些语句不被执行。
- **switch 穿透**：`switch` 语句中，如果某个 case 后面没有 `break`，程序会继续执行下一个 case 的代码，直到遇到 `break` 或 switch 结束。这是每年必考的易错点。
- **变量未初始化**：局部变量在 C++ 中不会自动初始化为 0，使用未初始化的变量会导致不可预测的结果。在程序填空和阅读中要注意变量的初始值。
- **赋值与等于混淆**：`if (a = 5)` 是赋值，返回值是 5（非零即 true），条件永远成立；`if (a == 5)` 才是判断相等。程序填空和阅读中，这是一个极高频的陷阱。

**1. 以下关于计算机存储单位的描述，正确的是（ ）**

A. 1KB = 1000B  
B. 1MB = 1024KB  
C. 1GB = 1000MB  
D. 1TB = 1000GB  

**答案：B**

A. 4  
B. 7  
C. 8  
D. 16  

**答案：C**

**解析**：1 Byte = 8 bits。这是计算机的基本常识。一个字节可以表示 0-255 共 256 种不同的值。

**3. 十进制数 29 对应的二进制数是（ ）**

A. 11001  
B. 11101  
C. 10111  
D. 11100  

**答案：B**

**解析**：29 转二进制：
29 ÷ 2 = 14 余 1 → 最低位
14 ÷ 2 = 7 余 0
7 ÷ 2 = 3 余 1
3 ÷ 2 = 1 余 1
1 ÷ 2 = 0 余 1 → 最高位
从下往上读：11101，即 29 = 16 + 8 + 4 + 0 + 1 = 29。验证正确。

**7. 以下程序段的输出是（ ）**

```cpp
int a = 3, b = 5;
if (a = b)
    cout << "Equal";
else
    cout << "Not Equal";
```

A. Equal  
B. Not Equal  
C. 编译错误  
D. 运行错误  

**答案：A**

**解析**：`if (a = b)` 是一个常见的陷阱。这里 `=` 是赋值运算符而非相等比较运算符。`a = b` 将 b 的值（5）赋给 a，赋值表达式的值是 5，5 是非零值，在条件判断中被视为 true，因此输出 "Equal"。正确的写法应该是 `if (a == b)`。

**9. 以下循环的循环体执行次数是（ ）**

```cpp
int i = 0;
while (i < 5) {
    i++;
}
```

A. 4  
B. 5  
C. 6  
D. 无限次  

**答案：B**

**解析**：i 从 0 开始，循环条件为 i < 5。
第1次：i=0 < 5，进入，i 变为 1
第2次：i=1 < 5，进入，i 变为 2
第3次：i=2 < 5，进入，i 变为 3
第4次：i=3 < 5，进入，i 变为 4
第5次：i=4 < 5，进入，i 变为 5
第6次：i=5，不满足 i < 5，退出循环
循环体共执行 5 次。

**10. 已知 `int a[10] = {1, 2, 3, 4};`，则 `a[5]` 的值是（ ）**

B. `break` 用于结束整个循环，`continue` 用于跳过本次循环的剩余部分

**14. 以下程序段的输出是（ ）**

```cpp
int x = 5;
cout << (x > 3 && x < 10 || x == 0);
```

A. 0  
B. 1  
C. true  
D. 编译错误  

**答案：B**

**解析**：表达式求值过程：`x > 3` 为 true（5 > 3），`x < 10` 为 true（5 < 10），`x > 3 && x < 10` 为 true。`&&` 优先级高于 `||`，所以表达式等价于 `(x > 3 && x < 10) || x == 0`。前半部分为 true，`||` 短路，整个表达式为 true。C++ 中布尔值输出为 1（true）或 0（false）。所以输出 1。

**3. 阅读以下程序，写出输出结果。**

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[] = {2, 5, 1, 8, 3};
    int n = 5;
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < n - i; j++) {
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }

        cout << a[i] << " ";
    }

}
```

**5. 阅读以下程序，写出当输入 `8` 时的输出结果。**

```cpp
#include <iostream>
using namespace std;

int f(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    return f(n - 1) + f(n - 2);
}

int main() {
    int n;
    cin >> n;
    cout << f(n) << endl;
    return 0;
}
```

**答案**：`21`

**解析**：函数 `f` 是递归实现的斐波那契数列：f(0)=0, f(1)=1, f(n)=f(n-1)+f(n-2)。
计算 f(8)：
- f(2) = f(1) + f(0) = 1 + 0 = 1
- f(3) = f(2) + f(1) = 1 + 1 = 2
- f(4) = f(3) + f(2) = 2 + 1 = 3
- f(5) = f(4) + f(3) = 3 + 2 = 5
- f(6) = f(5) + f(4) = 5 + 3 = 8
- f(7) = f(6) + f(5) = 8 + 5 = 13
- f(8) = f(7) + f(6) = 13 + 8 = 21
所以输入 8 时输出 21。

**5. 以下程序的功能是：用二分查找法在已排序数组 a 中查找目标值 x。如果找到则输出其下标（从 0 开始），找不到则输出 -1。请补全程序。**

```cpp
#include <iostream>

    int a[] = {1, 3, 5, 7, 9, 11, 13, 15};

    cin >> x;

    int ans = -1;
    while (①) {
        int mid = (left + right) / 2;
        if (a[mid] == x) {
            ans = ②;

            left = ③;
        } else {
            right = ④;
        }
    }

}
```

**答案**：
① `left <= right`  
② `mid`  
③ `mid + 1`  
④ `mid - 1`
