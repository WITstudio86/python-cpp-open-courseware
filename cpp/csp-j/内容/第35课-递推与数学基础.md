### 一、等差数列与等比数列

**等差数列**是指从第二项起，每一项与前一项的差等于同一个常数 $d$（公差）的数列。其通项公式为：

$$a_n = a_1 + (n-1) \times d$$

前 $n$ 项和公式（高斯求和公式）为：

$$S_n = \frac{n \times (a_1 + a_n)}{2} = n \times a_1 + \frac{n(n-1)d}{2}$$

在实际编程中，我们可以这样计算等差数列的和：

```cpp
// 计算首项为a1，公差为d，共n项的等差数列和
long long arithmeticSum(long long a1, long long d, long long n) {
    long long an = a1 + (n - 1) * d;  // 第n项
    return n * (a1 + an) / 2;          // 高斯求和
}
```

**等比数列**是指从第二项起，每一项与前一项的比等于同一个常数 $q$（公比）的数列。其通项公式为：

$$a_n = a_1 \times q^{n-1}$$

前 $n$ 项和公式为（当 $q \neq 1$ 时）：

$$S_n = \frac{a_1(1 - q^n)}{1 - q}$$

在编程时，计算等比数列的和需要注意使用快速幂（见第36课）来计算 $q^n$，并注意数据范围，避免溢出。

```cpp
// 计算首项为a1，公比为q，共n项的等比数列和
// 注意：q^n 可能很大，需要使用快速幂
long long geometricSum(long long a1, long long q, long long n) {
    if (q == 1) return a1 * n;
    long long qn = 1, base = q, exp = n;
    while (exp > 0) {
        if (exp & 1) qn *= base;
        base *= base;
        exp >>= 1;
    }
    return a1 * (1 - qn) / (1 - q);
}
```

**易混淆点**：很多同学容易将等差数列的前 $n$ 项和公式与等比数列搞混。记住口诀——"等差数对乘，等比指数幂"。

### 二、递推关系

递推（Recurrence）是算法竞赛中最核心的数学工具之一。递推关系的本质是：当前状态可以由之前的状态推导出来。

**斐波那契数列**是最经典的递推关系：

$$F(1) = 1, \quad F(2) = 1, \quad F(n) = F(n-1) + F(n-2) \quad (n \geq 3)$$

递推的两种实现方式——递归与迭代：

```cpp
// 递归写法（不推荐竞赛使用，有大量重复计算）
int fib_recursive(int n) {
    if (n <= 2) return 1;
    return fib_recursive(n - 1) + fib_recursive(n - 2);
}

// 迭代写法（推荐，O(n)时间，O(1)空间）
int fib_iterative(int n) {
    if (n <= 2) return 1;
    int a = 1, b = 1, c;
    for (int i = 3; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

**卡特兰数（Catalan Number）**是另一种常见的递推数列，应用场景包括：合法括号序列个数、二叉树形态个数、凸多边形三角剖分数等。其递推公式为：

$$C_0 = 1, \quad C_{n+1} = \sum_{i=0}^{n} C_i \times C_{n-i}$$

前几项卡特兰数为：$1, 1, 2, 5, 14, 42, 132, \ldots$

```cpp
// 计算第n个卡特兰数（n从0开始）
long long catalan(int n) {
    vector<long long> C(n + 1, 0);
    C[0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            C[i] += C[j] * C[i - 1 - j];
        }
    }
    return C[n];
}
```

递推题目的解题步骤一般为：分析关系式 → 确定初始状态 → 选择递推方向（从前往后或从后往前）→ 注意取模。

### 三、前缀和（Prefix Sum）

前缀和是一种空间换时间的预处理技术，解决"多次查询区间和"的问题。

**一维前缀和**：定义 $pre[i] = a[1] + a[2] + \cdots + a[i]$。则任意区间 $[l, r]$ 的和可以在 $O(1)$ 时间内计算：

$$sum(l, r) = pre[r] - pre[l-1]$$

前缀和数组的构建是 $O(n)$ 的，$pre[i] = pre[i-1] + a[i]$。

```cpp
// 一维前缀和
vector<int> a(n + 1), pre(n + 1, 0);
for (int i = 1; i <= n; i++) {
    pre[i] = pre[i - 1] + a[i];
}
// 查询区间 [l, r] 的和
int rangeSum = pre[r] - pre[l - 1];
```

**二维前缀和**：定义 $pre[i][j]$ 表示从 $(1,1)$ 到 $(i,j)$ 的矩形区域内所有元素之和。构建公式：

$$pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j]$$

查询 $(x_1, y_1)$ 到 $(x_2, y_2)$ 矩形区域和：

$$sum = pre[x_2][y_2] - pre[x_1-1][y_2] - pre[x_2][y_1-1] + pre[x_1-1][y_1-1]$$

```cpp
// 二维前缀和
vector<vector<int>> a(n + 1, vector<int>(m + 1));
vector<vector<int>> pre(n + 1, vector<int>(m + 1, 0));

for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j];
    }
}
// 查询 (x1,y1) 到 (x2,y2)
int sum = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1];
```

前缀和的核心思想是"用减法消除重复部分"，一维是减左边，二维是减上边和左边，再加回多减的左上角。理解这个"容斥原理"就能轻松记住公式。

### 四、差分数组（Difference Array）

差分数组是前缀和的"逆运算"，解决"多次区间修改，最后统一查询"的问题。

**一维差分**：定义 $d[i] = a[i] - a[i-1]$（设 $a[0] = 0$）。对区间 $[l, r]$ 统一加上 $x$，只需：

$$d[l] \mathrel{+}= x, \quad d[r+1] \mathrel{-}= x$$

最后对差分数组求一次前缀和即可还原修改后的数组：$a[i] = d[1] + d[2] + \cdots + d[i]$。

```cpp
// 一维差分数组
vector<int> d(n + 2, 0);  // 多开一个位置用于 r+1
// 区间 [l, r] 加上 x
d[l] += x;
d[r + 1] -= x;
// 还原数组
for (int i = 1; i <= n; i++) {
    d[i] += d[i - 1];
    // 此时 d[i] 就是 a[i] 修改后的值
}
```

差分的思想非常巧妙：我们不在修改时遍历区间内的每个元素（那样是 $O(n)$ 的），而是只标记区间的"开始"和"结束"，最后统一处理。这种"延迟计算"的思想在算法竞赛中非常常见。

**前缀和与差分的关系**：前缀和数组的差分就是原数组，差分数组的前缀和也是原数组。两者互为逆运算。在解题时，要能根据题目的操作类型灵活选择使用前缀和还是差分——"多次查询"用前缀和，"多次修改"用差分。

## 💻 代码模板

### 模板1：斐波那契递推（取模）

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MOD = 1e9 + 7;

// 计算第 n 个斐波那契数（对 MOD 取模）
long long fib(int n) {
    if (n <= 2) return 1;
    long long a = 1, b = 1, c;
    for (int i = 3; i <= n; i++) {
        c = (a + b) % MOD;
        a = b;
        b = c;
    }
    return b;
}

int main() {
    int n;
    cin >> n;
    cout << fib(n) << endl;
    return 0;
}
```

### 模板3：二维前缀和 + 矩形查询

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m, q;
    cin >> n >> m >> q;
    vector<vector<int>> a(n + 1, vector<int>(m + 1));
    vector<vector<long long>> pre(n + 1, vector<long long>(m + 1, 0));

    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            cin >> a[i][j];
            pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j];
        }

    while (q--) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        long long sum = pre[x2][y2] - pre[x1-1][y2]
                      - pre[x2][y1-1] + pre[x1-1][y1-1];
        cout << sum << endl;
    }
    return 0;
}
```

### 模板4：差分数组 + 区间修改

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    vector<int> a(n + 1), d(n + 2, 0);

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        d[i] = a[i] - a[i - 1];  // 构建差分数组
    }

    while (m--) {
        int l, r, x;
        cin >> l >> r >> x;
        d[l] += x;
        d[r + 1] -= x;
    }

    // 还原并输出
    for (int i = 1; i <= n; i++) {
        d[i] += d[i - 1];
        cout << d[i] << " \n"[i == n];
    }
    return 0;
}
```

## ⚠️ 易错点

- **前缀和数组下标从1开始**：很多同学习惯数组下标从0开始，导致 `pre[r] - pre[l-1]` 中 `l=0` 时出现 `pre[-1]` 的数组越界错误。建议统一从1开始索引，`pre[0] = 0` 作为哨兵。

- **差分数组的数组大小**：差分数组需要对 $r+1$ 位置进行操作，因此数组大小必须至少为 `n+2`（如果 $r$ 可能等于 $n$）。忘记多开一个位置会导致数组越界。

- **前缀和与差分的二维公式记混**：二维前缀和查询时需要 `+pre[x1-1][y1-1]`（加回多减的左上角），而二维差分还原时也需要类似的操作。建议用"容斥原理"来理解：加奇数层、减偶数层。

- **递推时忘记取模**：很多递推问题数值增长极快（如斐波那契数列第50项已超过 $10^{10}$），必须每一步都取模。注意：`(a + b) % MOD` 要在加法后立即取模，不能等到最后再取。

### 题目1：数列分段（改编自CSP-J真题）

**题目描述**：
给定一个长度为 $n$ 的整数序列 $a_1, a_2, \ldots, a_n$，以及 $q$ 个询问。每个询问给出两个整数 $l$ 和 $r$，请你输出区间 $[l, r]$ 内所有元素的和。

**输入格式**：
第一行两个整数 $n, q$（$1 \leq n, q \leq 10^5$）。
第二行 $n$ 个整数，表示序列 $a_i$（$|a_i| \leq 10^4$）。
接下来 $q$ 行，每行两个整数 $l, r$（$1 \leq l \leq r \leq n$）。

**输出格式**：
对于每个询问，输出一行一个整数，表示区间和。

**样例输入**：
```
5 3
2 1 -3 6 4
1 3
2 5
1 5
```

**样例输出**：
```
0
8
10
```

**AC代码**：

```cpp
#include <iostream>
#include <vector>
using namespace std;

typedef long long ll;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;
    vector<ll> pre(n + 1, 0);

    for (int i = 1; i <= n; i++) {
        ll x;
        cin >> x;
        pre[i] = pre[i - 1] + x;
    }

    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << pre[r] - pre[l - 1] << '\n';
    }
    return 0;
}
```

**解析**：这是一道典型的前缀和模板题。由于 $n, q \leq 10^5$，如果每个询问都遍历区间求和，复杂度为 $O(nq)$，会超时。使用前缀和预处理后，每个询问只需 $O(1)$ 时间。

### 题目2：斐波那契数列的第k项

**题目描述**：
斐波那契数列的定义如下：$F_1 = 1, F_2 = 1, F_n = F_{n-1} + F_{n-2}$（$n \geq 3$）。给定整数 $k$（$1 \leq k \leq 10^6$），求 $F_k$ 对 $10^9 + 7$ 取模的结果。

**输入格式**：
一行一个整数 $k$。

**输出格式**：
一行一个整数，表示 $F_k \bmod (10^9 + 7)$。

**样例输入**：
```
10
```

**样例输出**：
```
55
```

**AC代码**：

```cpp
#include <iostream>
using namespace std;

const int MOD = 1e9 + 7;

int main() {
    int k;
    cin >> k;

    if (k <= 2) {
        cout << 1 << endl;
        return 0;
    }

    long long a = 1, b = 1, c;
    for (int i = 3; i <= k; i++) {
        c = (a + b) % MOD;
        a = b;
        b = c;
    }

    cout << b << endl;
    return 0;
}
```

**解析**：$k$ 最大可达 $10^6$，递推 $O(n)$ 可以接受。由于斐波那契数增长极快，必须在每一步都取模，否则会溢出 `long long`（第93项斐波那契数就已经超过了 $2^{63}-1$）。

### 题目3：区间加分与最终查询（差分 + 前缀和）

**题目描述**：  
长度为 n 的序列初始全为 0。进行 m 次操作：每次把区间 $[l,r]$ 全部加上 x。最后输出整个序列。

**输入格式**：  
第一行 n m（1 ≤ n,m ≤ 1e5）  
接下来 m 行：l r x（1 ≤ l ≤ r ≤ n，|x| ≤ 1e4）

**输出格式**：  
一行 n 个数，表示最终序列。

**样例输入**：
```
5 3
1 3 2
2 5 1
3 3 5
```

**样例输出**：
```
2 3 8 1 1
```

**AC代码**：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n, m;
    cin >> n >> m;
    vector<long long> d(n + 2, 0);
    while (m--) {
        int l, r, x;
        cin >> l >> r >> x;
        d[l] += x;
        d[r + 1] -= x;
    }
    for (int i = 1; i <= n; i++) {
        d[i] += d[i - 1];
        cout << d[i] << (i == n ? '\n' : ' ');
    }
    return 0;
}
```

**解析**：经典差分模板。m 次区间修改若每次暴力会 O(nm) 超时；差分每次 O(1)，最后 O(n) 还原。

## 🧩 进阶精讲

### 五、前缀和常见变体

**1. 前缀异或**  
`pre[i] = a[1] xor ... xor a[i]`，区间异或：`pre[r] xor pre[l-1]`。

**2. 前缀最大值**  
`premax[i] = max(premax[i-1], a[i])`，可 O(1) 查前缀 max，但任意区间 max 需要 ST 表（提高）。

**3. 二维差分（了解）**  
对子矩形 (x1,y1)-(x2,y2) 加 v：
```
d[x1][y1] += v;
d[x2+1][y1] -= v;
d[x1][y2+1] -= v;
d[x2+1][y2+1] += v;
```
再做二维前缀和还原。

### 六、递推与 DP 的边界

递推强调“按公式往下算”；DP 强调“最优子结构 + 状态”。斐波那契既是递推也是最简单 DP。卡特兰数在 CSP-J 较少直接出，但括号匹配计数可能涉及。

**递推写题检查清单**：
1. 初值对不对（F1、F2）？  
2. 下标从 0 还是 1？  
3. 是否每步取模？  
4. 是否会爆 `int`（改 `long long`）？  
5. n=1 边界是否特判？

### 七、等差/等比在编程题中的坑

- 求和公式里的除法：在模意义下不能直接 `/2`，要用逆元或保证整除后用整数除。CSP-J 多数不取模直接算，但要用 `long long`。  
- `n * (a1 + an) / 2` 应写成 `(long long)n * (a1 + an) / 2`，防止中间溢出。  
- 等比公比 q=1 要特判。

### 八、前缀和下标口诀

```
         a1  a2  a3  a4  a5
pre:  0  p1  p2  p3  p4  p5
sum[l..r] = pre[r] - pre[l-1]
```

### 九、差分与前缀和选型

| 操作模式 | 用什么 |
|----------|--------|
| 静态数组，多次区间和查询 | 前缀和 |
| 多次区间加减，最后统一问 | 差分 |
| 既改又查（任意交错） | 树状数组/线段树（提高） |
| 二维矩形和 | 二维前缀和 |

### 十、补充模板：一维前缀和 + 差分混合

有时题目先给出原数组 a，再多次区间加，最后查询区间和：  
先把 a 建成差分，操作打在差分上，还原成新数组后再建前缀和查询——或操作完还原一次后直接扫。

```cpp
// 已有 a[1..n]，m 次区间加，再 q 次区间和
// 1) 建差分数组
for (int i = 1; i <= n; i++) d[i] = a[i] - a[i-1];
// 2) 区间修改
// 3) 还原 a
for (int i = 1; i <= n; i++) a[i] = a[i-1] + d[i]; // 注意别与旧 a 混用
// 更清晰：用 d 累加得到 b[i]
for (int i = 1; i <= n; i++) b[i] = b[i-1] + d[i];
// 4) 前缀和
for (int i = 1; i <= n; i++) pre[i] = pre[i-1] + b[i];
```

## 🎯 本课小结

本课学习了四个核心工具：
1. **数列公式**：等差数列求和用"高斯公式"，等比数列求和注意 $q^n$ 的计算。
2. **递推关系**：分析递推式 → 确定初值 → 迭代求解，注意取模。
3. **前缀和**：$pre[r] - pre[l-1]$，一维减左边，二维减上左加上角。
4. **差分数组**：$d[l] \mathrel{+}= x, d[r+1] \mathrel{-}= x$，最后求前缀和还原。

这些工具的共性是"预处理 + 快速响应"，掌握了它们，就能在时间限制内高效解决大量查询/修改类问题。  
考试口诀：**多查询 → 前缀和；多区间改 → 差分；递推先写初值再循环；加法取模步步做。**
