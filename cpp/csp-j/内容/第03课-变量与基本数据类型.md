# 第3课：变量与基本数据类型

## 🎯 考纲要求
- 基本数据类型：int、long long、float、double、char、bool
- 变量命名规则（字母数字下划线、不能数字开头、不能关键字）
- sizeof 运算符
- 常量 const

## 📖 知识精讲

### 一、什么是变量

变量是程序中用来**存储数据**的命名空间。可以理解为计算机内存中的"小盒子"，每个盒子有自己的名字和类型。

**变量三要素**：
1. **变量名**（标识符）：用来引用这个存储空间
2. **数据类型**：决定了存储空间的大小和能存储什么类型的数据
3. **值**：实际存储的数据

### 二、基本数据类型

| 数据类型 | 关键字 | 占用字节 | 取值范围 | 用途 |
|---------|--------|---------|---------|------|
| 整型 | `int` | 4字节 | -2³¹ ~ 2³¹-1（约±21亿） | 普通整数 |
| 长整型 | `long long` | 8字节 | -2⁶³ ~ 2⁶³-1（约±9×10¹⁸） | 大整数 |
| 单精度浮点 | `float` | 4字节 | 约7位有效数字 | 小数（不推荐） |
| 双精度浮点 | `double` | 8字节 | 约15~16位有效数字 | 小数（推荐） |
| 字符型 | `char` | 1字节 | -128 ~ 127 或 0~255 | 单个字符 |
| 布尔型 | `bool` | 1字节 | true 或 false | 逻辑判断 |

**详细说明**：

**int（整型）**：
- 最常用的数据类型
- 范围：-2147483648 ~ 2147483647
- 当数值可能超过21亿时必须使用 `long long`
- CSP-J中经常有大数据范围的题目，要注意判断

**long long（长整型）**：
- 范围：-9223372036854775808 ~ 9223372036854775807
- 当数据范围超过 ±2×10⁹ 时，必须使用
- 考试技巧：不确定数据范围时，优先使用 `long long`

**float / double（浮点型）**：
- float 精度约7位有效数字，double 精度约15~16位
- **考试中浮点数优先使用 double**，精度更高
- 浮点数有舍入误差，不能直接用 `==` 判断相等

**char（字符型）**：
- 用单引号括起来：`'A'`, `'7'`, `'#'`
- 字符在内存中以ASCII码（整数）形式存储
- 可以参与算术运算：`'B' - 'A' = 1`

**bool（布尔型）**：
- 只有两个值：`true`（真，值为1）和 `false`（假，值为0）
- 非0值转换为bool都是 `true`，0转换为 `false`

### 三、sizeof 运算符

`sizeof` 用于获取数据类型或变量在内存中占用的**字节数**。

**语法**：`sizeof(类型)` 或 `sizeof(变量名)`

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "int: " << sizeof(int) << " 字节" << endl;
    cout << "long long: " << sizeof(long long) << " 字节" << endl;
    cout << "float: " << sizeof(float) << " 字节" << endl;
    cout << "double: " << sizeof(double) << " 字节" << endl;
    cout << "char: " << sizeof(char) << " 字节" << endl;
    cout << "bool: " << sizeof(bool) << " 字节" << endl;
    return 0;
}
```

**考试要点**：
- `sizeof(int)` 在绝大多数环境是 4
- `sizeof(long long)` 是 8
- `sizeof(char)` 永远是 1（C++标准保证）

### 四、变量命名规则

C++标识符（变量名、函数名等）的命名规则：

**合法字符**：字母（A-Z, a-z）、数字（0-9）、下划线（_）

**规则**（必须遵守，否则编译错误）：
1. 只能由字母、数字、下划线组成
2. 第一个字符不能是数字
3. 不能是C++关键字
4. C++区分大小写（`age` 和 `Age` 是不同的变量）

**良好命名习惯**：
- 使用有意义的英文单词：`score`, `total`, `maxValue`
- 多个单词用下划线或驼峰法：`student_count` 或 `studentCount`
- 避免使用拼音：`fenshu` → 用 `score`
- 临时变量可用简单名字：`i`, `j`, `k`, `tmp`

**常见C++关键字**（不能用作变量名）：
`int, long, float, double, char, bool, void, if, else, for, while, do, switch, case, break, continue, return, class, struct, namespace, using, new, delete, sizeof, const, static`

**判断练习**：
- `myVar` ✔
- `2ndPlace` ✗（数字开头）
- `total_score` ✔
- `float` ✗（关键字）
- `_count` ✔（下划线开头合法）
- `max-value` ✗（含非法字符 `-`）

### 五、常量 const

`const` 关键字用于定义常量，一旦赋值后不能再修改。

```cpp
const int MAXN = 1000000;     // 数组最大长度
const double PI = 3.14159;    // 圆周率
const int MOD = 1000000007;   // 常见取模常量
```

**const的优点**：
1. 防止意外修改
2. 代码可读性更好
3. 比 `#define` 更安全（有类型检查）

### 六、变量的声明与初始化

```cpp
int a;              // 声明但不初始化（值未定义！）
int b = 10;         // 声明并初始化
int c(20);          // 构造函数初始化
int d = a + b;      // 用表达式初始化
int x = 0, y = 0;   // 同时声明多个变量
```

**重要提示**：
- 局部变量不初始化，其值是**不确定**的（垃圾值）
- CSP-J考试中，务必在声明时初始化变量
- 全局变量和静态变量默认初始化为0

## 💻 代码模板

### 数据类型检查模板
```cpp
#include <iostream>
using namespace std;

int main() {
    // 输出各类型大小
    cout << "=== 数据类型占用字节 ===" << endl;
    cout << "int:      " << sizeof(int) << " 字节" << endl;
    cout << "long long:" << sizeof(long long) << " 字节" << endl;
    cout << "float:    " << sizeof(float) << " 字节" << endl;
    cout << "double:   " << sizeof(double) << " 字节" << endl;
    cout << "char:     " << sizeof(char) << " 字节" << endl;
    cout << "bool:     " << sizeof(bool) << " 字节" << endl;
    
    // 数据范围演示
    int intMax = 2147483647;
    cout << "int最大值: " << intMax << endl;
    cout << "int最大值+1(溢出): " << intMax + 1 << endl;
    
    long long bigNum = 10000000000LL;
    cout << "大整数(long long): " << bigNum << endl;
    
    return 0;
}
```

## ⚠️ 易错点

- **int溢出问题**：两个int相乘可能超出int范围！例如 `100000 * 100000 = 100亿`，超出int范围。解决：使用 `long long` 或强制类型转换 `(long long)a * b`。
- **浮点数比较陷阱**：`if (a == 0.1)` 可能为假，因为0.1在二进制中无法精确表示。正确做法：`if (fabs(a - 0.1) < 1e-9)`。
- **整数除法截断**：C++中两个整数相除结果还是整数（向下截断）。例如 `5 / 2` 结果是 `2` 而不是 `2.5`。要得到小数结果：`5.0 / 2` 或 `(double)5 / 2`。
- **char运算的隐式转换**：char参与算术运算时会自动转为int。`cout << 'A' + 1` 输出 `66` 而非 `'B'`。需强制转换：`cout << (char)('A' + 1)`。
- **未初始化变量**：局部变量声明后不初始化就使用，其值是随机的。务必给变量赋初值。

## 📝 真题精练

### 题目1：数据类型范围判断
**题目描述**：在C++中，要存储全国人口数量（约14亿），以下哪个数据类型最合适？
A. int
B. float
C. long long
D. int即可，因为14亿 < 21亿

**答案**：D
**解析**：14亿 = 1,400,000,000，int的范围约±21亿，完全够用。但如果涉及14亿的数据进行乘法运算（如人均GDP计算），乘积可能超出int范围，此时需要注意使用 long long。

```cpp
#include <iostream>
using namespace std;

int main() {
    int population = 1400000000;  // 14亿
    cout << "人口用int存储: " << population << endl;
    
    // 但乘法可能溢出，要用long long
    long long totalGDP = 80000LL * 1400000000LL;
    cout << "总GDP(long long): " << totalGDP << endl;
    
    return 0;
}
```

### 题目2：变量命名合法性
**题目描述**：以下哪个变量名是合法的C++标识符？
A. `2score`
B. `_value`
C. `float`
D. `my-name`

**答案**：B
**解析**：A以数字开头非法；C是关键字非法；D含连字符 `-` 非法；B以下划线开头合法。

```cpp
#include <iostream>
using namespace std;

int main() {
    int _value = 100;      // 合法：下划线开头
    int myVar = 200;       // 合法：大小写混合
    
    const double PI = 3.1415926535;
    
    cout << "_value = " << _value << endl;
    cout << "myVar = " << myVar << endl;
    cout << "sizeof(int) = " << sizeof(int) << endl;
    cout << "PI = " << PI << endl;
    
    return 0;
}
```

## 🎯 本课小结
1. 六种基本数据类型：int(4B)、long long(8B)、float(4B)、double(8B)、char(1B)、bool(1B)
2. 考试中整数优先用int，超出21亿用long long；浮点数一律用double
3. 变量命名三规则：只能字母数字下划线、不能数字开头、不能关键字
4. `sizeof` 运算符获取类型占用的字节数，`sizeof(char)` 恒为1
5. `const` 定义常量，初始化后不可修改；局部变量务必初始化
