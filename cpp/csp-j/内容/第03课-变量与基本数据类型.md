## 📖 知识精讲

### 一、什么是变量

变量是程序中用来**存储数据**的命名内存空间。可以把它想象成计算机内存里的“小盒子”：

- 盒子上贴着**名字**（变量名）
- 盒子规定了**能装什么**（数据类型）
- 盒子里装着**当前内容**（值）

**变量三要素**：

| 要素 | 含义 | 示例 |
|------|------|------|
| 变量名 | 引用该存储空间的标识符 | `score` |
| 数据类型 | 决定占用字节数与可存数据形态 | `int` |
| 值 | 当前存储的数据 | `98` |

在 C++ 中，使用变量之前必须先**声明**（告诉编译器名字和类型）。推荐在声明时一并**初始化**。

```cpp
int score = 98;        // 声明 + 初始化
double pi = 3.14159;   // 浮点变量
char grade = 'A';      // 字符变量
bool passed = true;    // 布尔变量
```

程序对变量的基本操作只有两类：**读**（使用它的值）和**写**（给它赋新值）。

```cpp
int x = 10;   // 写：放入 10
x = x + 5;    // 读出 10，加 5，再写回 15
cout << x;    // 读：输出 15
```

### 二、基本数据类型总览

CSP-J 阶段必须熟练掌握以下六种类型：

| 类型 | 关键字 | 常见占用 | 取值范围（常见 64 位环境） | 典型用途 |
|------|--------|----------|----------------------------|----------|
| 整型 | `int` | 4 字节 | \(-2^{31}\) ~ \(2^{31}-1\)，约 ±21 亿 | 普通整数、循环下标 |
| 长整型 | `long long` | 8 字节 | \(-2^{63}\) ~ \(2^{63}-1\)，约 ±9×10¹⁸ | 大整数、防止溢出 |
| 单精度浮点 | `float` | 4 字节 | 约 6~7 位有效数字 | 一般不推荐竞赛使用 |
| 双精度浮点 | `double` | 8 字节 | 约 15~16 位有效数字 | 小数、精度要求更高 |
| 字符型 | `char` | 1 字节 | 通常 -128~127 或 0~255 | 单个字符、ASCII |
| 布尔型 | `bool` | 1 字节 | `true` / `false` | 逻辑判断 |

> 说明：`sizeof(int)` 等在个别平台可能不同，但 NOIP/CSP 常用环境与大多数在线评测机上，上表与下面演示一致。`sizeof(char)` 在标准中恒为 1。

### 三、整型：`int` 与 `long long`

#### 1. `int`（整型）

- 最常用的整数类型。
- 范围约：`-2147483648` ~ `2147483647`（即约 ±2.1×10⁹）。
- 适合：计数、下标、中等规模整数运算。

```cpp
int n = 100;
int age = 15;
int year = 2026;
```

#### 2. `long long`（长整型）

- 范围约：`-9223372036854775808` ~ `9223372036854775807`（约 ±9.2×10¹⁸）。
- 当数据或**中间结果**可能超过约 2×10⁹ 时，必须使用。
- 字面量写法：在数字后加 `LL` 或 `ll`，如 `10000000000LL`。

```cpp
long long population = 14000000000LL;  // 140 亿
long long product = 100000LL * 100000LL; // 100 亿，安全
```

#### 3. 选型经验（考试高频）

| 场景 | 建议类型 |
|------|----------|
| n ≤ 1e5，简单加减 | `int` 通常够用 |
| 两数相乘、累加和可能很大 | `long long` |
| 题目明确 \(|a_i| ≤ 1e9\) 且要算 \(a×b\) | `long long` |
| 不确定会不会爆 | **优先 `long long`**（空间与速度在 CSP-J 可接受） |

**记忆口诀**：

- 看**最终答案**范围不够，还要看**中间结果**。
- “两个 `int` 一相乘，结果先升 `long long`”。

```cpp
int a = 100000, b = 100000;
// 错误：先按 int 乘，再赋给 long long，已经溢出
// long long c = a * b;

// 正确：至少有一个操作数提升为 long long
long long c1 = 1LL * a * b;
long long c2 = (long long)a * b;
```

### 四、浮点型：`float` 与 `double`

#### 1. 精度对比

```cpp
float  f = 1.0f / 3.0f;
double d = 1.0  / 3.0;
// float 约 7 位有效数字；double 约 15~16 位
```

**CSP-J 建议：浮点数一律优先 `double`。** 除非题目明确要求 `float`（极少见）。

#### 2. 浮点数不能直接 `==` 比较

0.1 等小数在二进制中往往无法精确表示，累加后可能产生微小误差。

```cpp
// 危险写法
if (x == 0.1) { ... }

// 推荐写法：比较绝对误差
const double EPS = 1e-9;
if (fabs(x - 0.1) < EPS) { ... }
```

常用容差：`1e-6`、`1e-8`、`1e-9`（看题目精度要求）。

#### 3. 整数除法 vs 浮点除法

```cpp
cout << 5 / 2;           // 2  （两个 int，向零截断）
cout << 5.0 / 2;         // 2.5
cout << (double)5 / 2;   // 2.5
cout << 5 / 2.0;         // 2.5
```

### 五、字符型 `char`

#### 1. 基本写法

- 单个字符用**单引号**：`'A'`、`'7'`、`'#'`。
- 双引号是**字符串**：`"A"` 与 `'A'` 不同。

```cpp
char ch = 'A';
cout << ch;           // 输出 A
cout << (int)ch;      // 输出 65（ASCII）
```

#### 2. 与 ASCII 的关系

常见码点（务必背熟）：

| 字符 | ASCII | 说明 |
|------|-------|------|
| `'0'` | 48 | 数字字符起点 |
| `'A'` | 65 | 大写字母起点 |
| `'a'` | 97 | 小写字母起点 |
| `' '` | 32 | 空格 |
| `'\n'` | 10 | 换行 |

#### 3. 字符运算（竞赛高频）

`char` 参与算术运算时会**提升为 `int`（ASCII 值）**。

```cpp
'B' - 'A';          // 1
'9' - '0';          // 9  数字字符转数值
'a' + 1;            // 98
(char)('A' + 1);    // 'B'
ch = ch - 'a' + 'A'; // 小写转大写（若 ch 为小写字母）
```

**数字字符 → 数值**：

```cpp
char c = '7';
int v = c - '0';   // 7
```

**数值 → 数字字符**：

```cpp
int v = 7;
char c = v + '0';  // '7'
```

#### 4. 输出时的陷阱

```cpp
cout << 'A' + 1;           // 输出 66，不是 B
cout << (char)('A' + 1);   // 输出 B
```

### 六、布尔型 `bool`

```cpp
bool ok = true;
bool fail = false;
cout << ok;    // 输出 1
cout << fail;  // 输出 0
```

转换规则：

- 非 0 → `true`，0 → `false`。
- `true` 在算术中通常当 1，`false` 当 0。

```cpp
bool b = 5;     // true
int x = true;   // 1
int y = false;  // 0
```

常用于条件标记：

```cpp
bool found = false;
// ... 查找过程中 if (hit) found = true;
if (found) cout << "Yes\n";
else cout << "No\n";
```

### 七、`sizeof` 运算符

`sizeof` 用于获取类型或变量在内存中占用的**字节数**。

**语法**：

```cpp
sizeof(类型名)
sizeof(表达式)   // 或 sizeof 变量名（可不加括号，建议统一加括号）
```

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << sizeof(int) << endl;        // 常见 4
    cout << sizeof(long long) << endl;  // 常见 8
    cout << sizeof(float) << endl;      // 常见 4
    cout << sizeof(double) << endl;     // 常见 8
    cout << sizeof(char) << endl;       // 恒为 1
    cout << sizeof(bool) << endl;       // 常见 1

    int a = 10;
    cout << sizeof(a) << endl;          // 与 sizeof(int) 相同
    cout << sizeof(a + 1LL) << endl;    // 表达式类型提升后的大小
    return 0;
}
```

**考试要点**：

1. `sizeof` 在**编译期**即可确定（对普通变量/类型），不是运行时“测量内容长度”。
2. `sizeof(char)` **永远是 1**（C++ 标准保证）。
3. 对数组：`sizeof(arr)` 是整个数组字节数；元素个数常用：

```cpp
int arr[10];
int n = sizeof(arr) / sizeof(arr[0]);  // 10
```

注意：数组作为函数参数退化为指针后，`sizeof` 得到的是指针大小，不再是数组长度。

### 八、变量命名规则

C++ 标识符（变量名、函数名、常量名等）规则：

#### 1. 必须遵守（否则编译错误）

1. 只能由**字母**、**数字**、**下划线 `_`** 组成。
2. **第一个字符不能是数字**。
3. **不能是 C++ 关键字**。
4. **区分大小写**：`age` 与 `Age` 是不同变量。

#### 2. 合法性判断练习

| 标识符 | 是否合法 | 原因 |
|--------|----------|------|
| `myVar` | ✔ | 字母开头 |
| `_count` | ✔ | 下划线开头合法 |
| `total_score` | ✔ | 下划线连接 |
| `2ndPlace` | ✗ | 数字开头 |
| `float` | ✗ | 关键字 |
| `my-name` | ✗ | 含非法字符 `-` |
| `student count` | ✗ | 含空格 |
| `MAX_N` | ✔ | 常量常用大写+下划线 |

#### 3. 常见关键字（不能做变量名）

`int, long, float, double, char, bool, void, if, else, for, while, do, switch, case, break, continue, return, class, struct, namespace, using, new, delete, sizeof, const, static, true, false, ...`

#### 4. 良好命名习惯

- 见名知意：`score`、`total`、`maxValue`。
- 多词：下划线 `student_count` 或驼峰 `studentCount`。
- 避免无意义拼音堆砌；临时循环变量可用 `i, j, k, tmp`。
- 常量常用全大写：`const int MAXN = 1e6;`。

### 九、常量 `const`

`const` 表示**只读**：初始化后不能再修改。

```cpp
const int MAXN = 1000000;
const double PI = 3.141592653589793;
const int MOD = 1000000007;
```

**优点**：

1. 防止误改关键参数。
2. 语义清晰：一眼看出“这是常量”。
3. 比 `#define` 更安全（有类型检查、有作用域）。

```cpp
// #define PI 3.14          // 无类型，预处理简单替换
const double PI = 3.14;     // 有类型，推荐
```

错误示例：

```cpp
const int N = 10;
// N = 20;  // 编译错误：不能修改 const 对象
```

数组大小、取模、圆周率等建议用 `const` 定义在程序前部，便于统一修改。

### 十、变量的声明与初始化

#### 1. 常见写法

```cpp
int a;              // 仅声明：局部变量值不确定！
int b = 10;         // 拷贝初始化
int c(20);          // 直接初始化
int d{30};          // 列表初始化（C++11）
int x = 0, y = 0;   // 同时声明多个
int p = 1, q = p + 2; // 可用前面已声明的变量
```

#### 2. 未初始化的危险

```cpp
void f() {
    int x;          // 局部变量：垃圾值
    cout << x;      // 未定义行为，可能输出任意数
}
```

- **局部变量**：未初始化 → 值不确定（垃圾值）。
- **全局变量 / 静态变量**：默认初始化为 0（`bool` 为 `false`，指针为 `nullptr` 等）。

**考试铁律**：局部变量声明时尽量赋初值；累加器、计数器必须 `= 0`。

```cpp
int sum = 0;
int cnt = 0;
int maxv = -1e9;   // 或 INT_MIN，按数据范围选
```

#### 3. 多变量声明的坑

```cpp
int* p, q;   // p 是 int*，q 是 int！不是两个指针
int *p, *q;  // 两个指针
```

初学阶段建议一行一个变量，更清晰。

### 十一、整数溢出详解（重点）

#### 1. 什么是溢出

有符号整数超出表示范围时，行为在标准中属于**未定义/实现相关**，在常见补码实现上常表现为“绕回”（wrap-around）：

```cpp
int mx = 2147483647;  // INT_MAX
cout << mx + 1;       // 常见输出 -2147483648
```

#### 2. 高频溢出场景

**场景 A：两数相乘**

```cpp
int a = 1e5, b = 1e5;
long long c = a * b;           // 错：a*b 先按 int 算爆
long long d = 1LL * a * b;     // 对
```

**场景 B：累加和**

```cpp
// n=1e5, a_i=1e9，总和可达 1e14，必须 long long
long long sum = 0;
for (int i = 0; i < n; i++) sum += a[i];
```

**场景 C：阶乘、组合数中间项**

```cpp
// 计算过程中每一步都可能爆，要边算边用 long long，甚至取模
```

**场景 D：循环变量看似 int 够，但表达式爆**

```cpp
int n = 100000;
// long long s = n * (n + 1) / 2;  // n*(n+1) 可能先爆
long long s = 1LL * n * (n + 1) / 2;
```

#### 3. 如何预防

1. 读题时估算数量级：\(n·a_i\)、\(a·b\)、\(n^2\) 等。
2. 乘法前先变 `long long`：`1LL * a * b`。
3. 和、积、答案变量直接开 `long long`。
4. 需要时用 `long long` 读入：`long long x; cin >> x;`。

### 十二、类型转换初步

#### 1. 隐式转换

```cpp
int a = 3;
double b = a;      // 3.0
int c = 3.9;       // 3（截断，不是四舍五入）
bool flag = 10;    // true
char ch = 65;      // 'A'
```

#### 2. 显式强制转换

```cpp
int a = 5, b = 2;
double r = (double)a / b;   // 2.5
char next = (char)('a' + 1);
```

C++ 风格：

```cpp
double r = static_cast<double>(a) / b;
```

CSP-J 中 C 风格 `(double)a` 已足够常用。

#### 3. 注意精度丢失

```cpp
double x = 1e20;
int y = (int)x;   // 溢出/不可表示，结果错误
```

大整数不要用 `double` 硬存再转回，优先 `long long`。

```cpp
#include <iostream>

int main() {

    int chinese = 90;
```

该示例综合了 `int`、`char`、`bool`、`double`、`const` 与初始化，是本课知识的一次串联。

## ⚠️ 易错点

### 易错点 1：`int` 乘法溢出

**错误示例**：

```cpp
int a = 100000, b = 100000;
long long c = a * b;   // a*b 已在 int 中溢出
cout << c << endl;     // 错误结果
```

**正确示例**：

```cpp
int a = 100000, b = 100000;
long long c = 1LL * a * b;
// 或 long long c = (long long)a * b;
cout << c << endl;     // 10000000000
```

**解析**：赋值不会“回头”修复已经溢出的中间结果，必须在乘法时就提升类型。

---

### 易错点 2：局部变量未初始化

**错误示例**：

```cpp
int sum;
for (int i = 0; i < n; i++) sum += a[i];  // sum 初始是垃圾
```

**正确示例**：

```cpp
int sum = 0;
for (int i = 0; i < n; i++) sum += a[i];
```

**解析**：累加、计数、标记类变量必须明确初值。

---

### 易错点 3：整数除法当小数用

**错误示例**：

```cpp
int a = 5, b = 2;
double avg = a / b;     // 先算得 2，再变成 2.0
cout << avg << endl;    // 2
```

**正确示例**：

```cpp
int a = 5, b = 2;
double avg = (double)a / b;  // 2.5
// 或 1.0 * a / b
```

**解析**：除法运算时操作数类型决定结果类型，不是由左边变量类型决定。

---

### 易错点 4：`char` 运算直接输出期望字符

**错误示例**：

```cpp
cout << 'A' + 1 << endl;   // 输出 66
```

**正确示例**：

```cpp
cout << (char)('A' + 1) << endl;  // 输出 B
```

**解析**：`char` 算术后提升为 `int`，`cout` 按整数打印。

### 易错点 5：浮点数直接相等比较

**错误示例**：

```cpp
double x = 0.1 + 0.2;

```

**正确示例**：

```cpp
#include <cmath>
```

**解析**：二进制浮点存在表示误差，比相对/绝对误差更稳妥。

### 真题 1：数据类型与范围选择

**题目描述**

在 C++ 中，要存储全国人口数量（约 14 亿），以下说法正确的是？

A. 必须用 `long long`，因为 14 亿很大  
B. 只能用 `float`，整数类型装不下  
C. 用 `int` 存储人口本身可以，因为 14 亿 < 约 21 亿  
D. `bool` 也可以，只要不为 0  

**答案**：C

**解析**：

- 14 亿 = 1,400,000,000，小于 `int` 上限约 2,147,483,647，故单独存储人口可用 `int`。
- 但若后续有“人口 × 人均指标”之类乘法，乘积可能超 `int`，中间结果与答案要用 `long long`。
- A 过于绝对；B 错误；D 语义完全不对。

**AC 演示代码**（验证范围与安全乘法）：

```cpp
#include <iostream>
using namespace std;

int main() {
    int population = 1400000000;  // 14 亿，int 可存
    cout << "population = " << population << endl;

    // 假设人均 GDP 相关整数指标 80000，乘积需要 long long
    long long total = 80000LL * population;
    cout << "total = " << total << endl;

    // 错误乘法对照（演示用，实际不要这样写答案）
    // long long bad = 80000 * population; // 两个 int 先乘可能溢出

    cout << "sizeof(int) = " << sizeof(int) << endl;
    cout << "sizeof(long long) = " << sizeof(long long) << endl;
    return 0;
}
```

**输出要点**：

```
population = 1400000000
total = 112000000000000
sizeof(int) = 4
sizeof(long long) = 8
```

### 真题 3：溢出与表达式（补充实战）

**题目描述**

阅读程序，判断输出（在常见补码 `int` 4 字节环境下）：

```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 2147483647;
    cout << a + 1 << endl;

    int x = 100000, y = 100000;
    long long z1 = x * y;
    long long z2 = 1LL * x * y;
    cout << z1 << endl;
    cout << z2 << endl;
    return 0;
}
```

**参考答案**（常见环境）：

```
-2147483648
（某个错误的溢出值，不是 10000000000）
10000000000
```

**解析**：

1. `INT_MAX + 1` 溢出，常见结果为 `INT_MIN`。
2. `z1 = x * y`：`x*y` 以 `int` 计算已溢出，再赋给 `long long` 无法挽回。
3. `z2` 使用 `1LL * x * y`，结果正确。

**推荐写法模板**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 100000, y = 100000;
    long long z = 1LL * x * y;
    cout << z << endl;  // 10000000000
    return 0;
}
```

### 真题 4：`sizeof` 与类型判断

**题目描述**

下列说法错误的是？

A. `sizeof(char)` 的结果一定是 1  
B. `sizeof(int)` 在所有平台都一定是 4  
C. `long long` 通常占 8 字节  
D. `bool` 只有 `true` 和 `false` 两个逻辑值  

**答案**：B

**解析**：`sizeof(int)` 由实现定义，常见为 4，但标准不保证“全世界永远是 4”。CSP-J 环境可按 4 记忆，但概念上 B 绝对化表述错误。`sizeof(char)` 标准规定为 1。

**演示代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << sizeof(char) << endl;
    cout << sizeof(int) << endl;
    cout << sizeof(long long) << endl;
    cout << sizeof(bool) << endl;
    return 0;
}
```

## 🎯 本课小结

1. **六种基本类型**：`int`(4B)、`long long`(8B)、`float`(4B)、`double`(8B)、`char`(1B)、`bool`(1B)——字节数为常见环境。
2. **选型原则**：普通整数用 `int`；可能超约 21 亿或乘法/累加中间结果大时用 `long long`；小数优先 `double`。
3. **命名三铁律**：字母数字下划线；不能数字开头；不能关键字；区分大小写。
4. **`sizeof`**：求类型或变量占用字节数；`sizeof(char) ≡ 1`。
5. **`const`**：定义只读常量，初始化后不可改，优于随意魔法数字。
6. **初始化**：局部变量务必赋初值；全局默认 0。
7. **溢出**：两 `int` 相乘先提升；答案与累加和优先 `long long`。
8. **字符运算**：按 ASCII 参与运算；数字字符 `ch-'0'`；输出字符需 `(char)` 转换。
