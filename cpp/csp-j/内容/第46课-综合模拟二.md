### 一、CSP-J 第二轮考试策略

CSP-J 第二轮为编程题考试，通常包含 4 道编程题，考试时间 3.5 小时，满分 400 分。每道题 100 分，包含多个测试点，每个测试点有对应的数据规模和分值。

#### 1.1 总体策略：难度梯度与时间分配

CSP-J 第二轮的四道题通常难度递增：
- **第 1 题**：简单模拟或基础算法，大多数选手应能拿到满分。建议用时 30-45 分钟。
- **第 2 题**：中等难度，通常涉及枚举优化或简单贪心。建议用时 45-60 分钟。
- **第 3 题**：中等偏难，可能需要较复杂的数据结构或算法设计。建议用时 50-70 分钟。
- **第 4 题**：压轴题，难度最高，完全做出的人较少。建议用时 50-70 分钟。

最后预留 20-30 分钟用于检查和优化。

#### 1.2 部分分策略（"骗分"技巧）

在 CSP-J 第二轮中，许多题目有部分分的设计——即不需要完全解决所有数据范围的问题，也能拿到一定分数。这是非常重要的应试策略。

```cpp
    } else if (n <= 1000) {

    } else {

```

**（2）特殊情况的特判**：如果题目有特殊的边界情况（如 n=1、全部相同、单调递增等），可以单独写判断逻辑拿到特判分数。

**（3）输出固定值**：对于完全不会做的题目，可以尝试输出一些常见答案如 0、-1、n 等，有时能碰中个别测试点。

**（4）打表法**：如果问题答案只依赖于输入值的范围且范围不大，可以提前计算出所有可能答案，在程序中使用查表的方式直接输出。

#### 1.4 模拟题解题模板

模拟题的核心是按照题目描述的规则，一步步模拟过程。关键点是**仔细读题、准确实现**。

**日期模拟模板**：

```cpp
// 判断闰年
bool isLeap(int year) {
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}

// 每月天数
int daysInMonth(int year, int month) {
    int days[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (month == 2 && isLeap(year)) return 29;
    return days[month];
}

// 计算两个日期之间的天数差（简化版，假设 date1 <= date2）
int daysBetween(int y1, int m1, int d1, int y2, int m2, int d2) {
    int count = 0;
    while (y1 < y2 || m1 < m2 || d1 < d2) {
        d1++;
        count++;
        if (d1 > daysInMonth(y1, m1)) {
            d1 = 1;
            m1++;
            if (m1 > 12) {
                m1 = 1;
                y1++;
            }
        }
    }
    return count;
}
```

#### 1.5 枚举算法优化技巧

枚举（暴力）是竞赛中最常用的入门方法，但朴素枚举通常会导致超时。以下是一些优化技巧：

**（1）减少枚举变量**：对于多重循环的枚举问题，思考是否可以通过等式关系减少一重循环。

```cpp
// 例题：在数组中找到三个数，使它们的和为 target
// 朴素做法：O(n^3) 三重循环
// 优化做法：枚举前两个数，第三个直接用 target-a[i]-a[j] 查找（需预处理哈希表或排序二分）
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        int need = target - a[i] - a[j];
        // 二分查找 need
    }
}
```

**（2）缩小枚举范围**：利用题目中的约束条件（如大小关系、奇偶性等）缩小枚举范围。

**（3）剪枝策略**：在枚举过程中，如果发现当前分支不可能产生最优解，立即跳过。

#### 1.6 贪心算法核心思想

贪心算法的核心是：**每一步都做出当前看起来最优的选择，期望最终得到全局最优解**。

关键问题：**如何证明贪心的正确性？**
- 交换论证法：假设存在一个最优解，通过交换其中某些元素，证明贪心选择不劣于最优解
- 数学归纳法：证明贪心选择后，剩余问题是原问题的子问题

**区间调度（活动选择）模板**：

```cpp
// 选择最多的不重叠区间
struct Interval {
    int start, end;
    bool operator<(const Interval& other) const {
        return end < other.end;  // 按结束时间排序
    }
};

int maxIntervals(vector<Interval>& intervals) {
    sort(intervals.begin(), intervals.end());
    int count = 0, lastEnd = -1;
    for (auto& iv : intervals) {
        if (iv.start >= lastEnd) {
            count++;
            lastEnd = iv.end;
        }
    }
    return count;
}
```

#### 1.7 二分答案模板

二分答案适用于具有**单调性**的最优化问题：如果某个值 x 满足条件，那么所有大于（或小于）x 的值也满足条件。将"求满足条件的最大值/最小值"转化为"判断某个值是否满足条件"。

```cpp
// 二分答案标准模板：求满足条件的最大值
int left = 最小值, right = 最大值;
int ans = left;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (check(mid)) {  // mid 满足条件
        ans = mid;
        left = mid + 1;  // 尝试更大的值
    } else {
        right = mid - 1;  // 尝试更小的值
    }
}
cout << ans << endl;

// 求满足条件的最小值
int left = 最小值, right = 最大值;
int ans = right;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (check(mid)) {
        ans = mid;
        right = mid - 1;  // 尝试更小的值
    } else {
        left = mid + 1;
    }
}
```

```cpp
#include <string>
#include <algorithm>
using namespace std;

// 高精度加法：两个非负大整数相加
string add(string a, string b) {
    string result = "";
    int carry = 0;
    int i = a.size() - 1, j = b.size() - 1;
    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        result += (sum % 10) + '0';
        carry = sum / 10;
    }
    reverse(result.begin(), result.end());
    return result;
}

int main() {
    string a = "12345678901234567890";
    string b = "98765432109876543210";
    cout << add(a, b) << endl;  // 111111111011111111100
    return 0;
}
```

## ⚠️ 易错点

- **模拟题的细节遗漏**：模拟题看似简单，但细节繁多。例如日期题中闰年的判断（能被4整除但不能被100整除，或者能被400整除）、每月天数差异、边界日期的进位等。建议在草稿纸上先列出所有规则和状态转移，再开始编码。
- **枚举超时**：朴素枚举的时间复杂度通常是 O(n^k)，当 n 较大时容易超时。务必分析数据范围：n <= 100 可以用 O(n^3)，n <= 10^4 最多 O(n log n)，n <= 10^5 需要 O(n log n) 或 O(n)。如果发现时间复杂度过高，立即思考减少枚举维度或使用更高效的数据结构。
- **贪心算法的错误使用**：贪心不是万能的。在使用贪心前，必须能够论证贪心选择的正确性。例如：01 背包问题不能用贪心（按价值/重量比选），必须用动态规划；但部分背包（物品可分割）可以用贪心。常见的可贪心问题：区间调度（按结束时间排序）、哈夫曼编码、最小生成树（Kruskal/Prim）。
- **二分答案的单调性判断错误**：二分答案的前提是 check 函数具有单调性。如果 check(mid) 为 true 不保证 check(mid+1) 也为 true，则不能使用二分答案。常见的可二分问题：最大值最小化、最小值最大化。
- **二分查找边界条件**：`while (left <= right)` vs `while (left < right)`、`mid = (left + right) / 2` vs `mid = left + (right - left) / 2`（防溢出）、`left = mid + 1` vs `left = mid`。死循环通常源于边界更新不当。
- **高精度运算的进位/借位处理**：高精度加法中容易忘记最后的进位（当最高位相加产生进位时，需要额外增加一位）；高精度减法中容易忘记借位处理和去除前导零。
- **数组大小不足**：竞赛中数组大小应根据题目数据范围上限 +5 或 +10 来定义，防止越界。例如题目说 n <= 100000，定义 `int a[100005]`。

### 模拟题一：日期差值计算

**题目描述**：
给定两个日期，计算它们之间相差的天数。日期格式为 "YYYY-MM-DD"。保证第一个日期不晚于第二个日期，且两个日期都在公元 1 年 1 月 1 日至 9999 年 12 月 31 日之间。

**输入格式**：
两行，每行一个日期字符串，格式为 "YYYY-MM-DD"。

**输出格式**：
一个整数，表示两个日期之间的天数差。

**样例输入**：
```
2024-01-01
2024-01-10
```

**样例输出**：
```
9
```

**数据范围**：
- 对于 60% 的数据，两个日期在同一年
- 对于 100% 的数据，年份范围 1-9999

**AC 代码**：
```cpp
#include <iostream>
#include <cstdio>
using namespace std;

bool isLeap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}

int daysOfMonth(int y, int m) {
    int days[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (m == 2 && isLeap(y)) return 29;
    return days[m];
}

// 计算从公元1年1月1日到给定日期的总天数
long long totalDays(int y, int m, int d) {
    long long total = 0;
    // 累加整年
    for (int i = 1; i < y; i++) {
        total += isLeap(i) ? 366 : 365;
    }
    // 累加整月
    for (int i = 1; i < m; i++) {
        total += daysOfMonth(y, i);
    }
    // 累加天数
    total += d;
    return total;
}

int main() {
    int y1, m1, d1, y2, m2, d2;
    scanf("%d-%d-%d", &y1, &m1, &d1);
    scanf("%d-%d-%d", &y2, &m2, &d2);

    long long t1 = totalDays(y1, m1, d1);
    long long t2 = totalDays(y2, m2, d2);
    cout << t2 - t1 << endl;

    return 0;
}
```

**算法说明**：将两个日期分别转换为从公元 1 年 1 月 1 日起的总天数，然后相减。这样可以统一处理所有跨年、跨月的情况，代码清晰不易出错。时间复杂度 O(Y+M)，其中 Y 是年份跨度。注意使用 long long 防止大年份溢出。

### 枚举题二：三数之和为零

**题目描述**：
给定一个包含 n 个整数的数组，判断其中是否存在三个元素 a、b、c，使得 a + b + c = 0。如果存在，输出 "YES"；否则输出 "NO"。

**输入格式**：
第一行一个整数 n（3 ≤ n ≤ 1000）。第二行 n 个整数，每个整数的绝对值不超过 10^6。

**输出格式**：
输出 "YES" 或 "NO"。

**样例输入 1**：
```
6
-1 0 1 2 -1 -4
```

**样例输出 1**：
```
YES
```

**样例输入 2**：
```
5
1 2 3 4 5
```

**样例输出 2**：
```
NO
```

**数据范围**：
- 对于 30% 的数据：n ≤ 100
- 对于 100% 的数据：n ≤ 1000

**AC 代码**：
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int a[1005];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    // 排序用于双指针和去重
    sort(a, a + n);

    // 枚举第一个数 a[i]
    for (int i = 0; i < n - 2; i++) {
        // 剪枝：如果 a[i] > 0，后面不可能有和为 0 的三元组
        if (a[i] > 0) break;

        // 跳过重复的第一个数
        if (i > 0 && a[i] == a[i - 1]) continue;

        // 双指针查找另外两个数
        int left = i + 1, right = n - 1;
        while (left < right) {
            int sum = a[i] + a[left] + a[right];
            if (sum == 0) {
                cout << "YES" << endl;
                return 0;
            } else if (sum < 0) {
                left++;
            } else {
                right--;
            }
        }
    }
    cout << "NO" << endl;
    return 0;
}
```

**算法说明**：朴素的三重循环 O(n^3) 在 n=1000 时会超时（10^9 次运算）。优化思路：先对数组排序 O(n log n)，枚举第一个数 a[i]，然后用双指针在剩下的部分找两个数使和为 -a[i]。双指针的单次查找是 O(n)，总体 O(n^2)，在 n=1000 时可接受。剪枝：当 a[i] > 0 时，后面的数都大于 0，不可能凑出 0，直接 break。

### 贪心题三：活动选择

**题目描述**：
学校有 n 个活动需要使用同一个教室，每个活动 i 有开始时间 start_i 和结束时间 end_i。同一时间教室只能供一个活动使用。请问最多能安排多少个活动？

**输入格式**：
第一行一个整数 n（1 ≤ n ≤ 10^5）。接下来 n 行，每行两个整数 start_i 和 end_i（0 ≤ start_i < end_i ≤ 10^9）。

**输出格式**：
一个整数，表示最多能安排的活动数量。

**样例输入**：
```
5
1 4
3 5
0 6
5 7
3 8
```

**样例输出**：
```
2
```

**数据范围**：
- 对于 30% 的数据：n ≤ 20
- 对于 100% 的数据：n ≤ 10^5，时间范围 ≤ 10^9

**AC 代码**：
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

struct Activity {
    int start, end;
} a[100005];

bool cmp(Activity x, Activity y) {
    return x.end < y.end;  // 按结束时间从小到大排序
}

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i].start >> a[i].end;
    }

    // 按结束时间排序
    sort(a, a + n, cmp);

    int count = 0;
    int lastEnd = -1;  // 上一个选中活动的结束时间

    for (int i = 0; i < n; i++) {
        if (a[i].start >= lastEnd) {
            // 当前活动开始时间不早于上一个活动的结束时间，可以安排
            count++;
            lastEnd = a[i].end;
        }
    }

    cout << count << endl;
    return 0;
}
```

**算法说明**：经典的活动选择问题，贪心策略为**每次选择结束时间最早且不与已选活动冲突的活动**。证明思路（交换论证）：假设最优解中第一个活动不是结束最早的，那么用结束最早的活动替换它，不会减少可选活动的数量。时间复杂度 O(n log n)，主要来自排序。

**为什么按开始时间排序不行？** 考虑反例：活动 A: [1, 10]，活动 B: [2, 3]，活动 C: [4, 5]。如果按开始时间排序选 A，那么只能选 1 个；而最优解是选 B 和 C 共 2 个。按结束时间排序则正确。

### 二分答案题四：砍树问题

**题目描述**：
有 n 棵树，每棵树的高度为 h_i。伐木工人需要砍伐这些树，得到总长度至少为 M 的木材。锯子设置的高度为 H，所有高于 H 的部分会被砍下。请问锯子最高可以设置为多少，使得砍下的木材总长度至少为 M？

**输入格式**：
第一行两个整数 n 和 M（1 ≤ n ≤ 10^6，1 ≤ M ≤ 2×10^9）。第二行 n 个整数，表示每棵树的高度 h_i（1 ≤ h_i ≤ 10^9）。

**输出格式**：
一个整数，表示锯子能设置的最高高度 H。

**样例输入**：
```
4 7
20 15 10 17
```

**样例输出**：
```
15
```

**样例解释**：当 H = 15 时，砍下的木材：(20-15) + (15-15) + (10-15 不算，因为低于H) + (17-15) = 5 + 0 + 0 + 2 = 7，刚好满足 M=7 的要求。

**数据范围**：
- 对于 30% 的数据：n ≤ 1000
- 对于 100% 的数据：n ≤ 10^6

**AC 代码**：
```cpp
#include <iostream>
using namespace std;

const int MAXN = 1000005;
int h[MAXN];
int n;
long long M;

// 判断当锯子高度为 H 时，能否获得至少 M 的木材
bool check(int H) {
    long long total = 0;
    for (int i = 0; i < n; i++) {
        if (h[i] > H) {
            total += h[i] - H;
        }
        // 提前剪枝：如果已经满足条件，提前返回
        if (total >= M) return true;
    }
    return total >= M;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> M;
    int maxH = 0;
    for (int i = 0; i < n; i++) {
        cin >> h[i];
        if (h[i] > maxH) maxH = h[i];
    }

    // 二分答案：锯子高度的范围 [0, maxH]
    int left = 0, right = maxH;
    int ans = 0;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (check(mid)) {
            // mid 可行，尝试更高的锯子高度
            ans = mid;
            left = mid + 1;
        } else {
            // mid 不可行，降低锯子高度
            right = mid - 1;
        }
    }

    cout << ans << endl;
    return 0;
}
```

**算法说明**：这是一个经典的二分答案问题。问题的单调性：锯子高度 H 越高，砍下的木材越少。即如果 H 满足条件（木材总长 ≥ M），那么任何小于 H 的高度也满足条件。我们要找的是满足条件的最大 H。

检查函数 check(H) 的时间复杂度是 O(n)，二分次数为 O(log maxH) ≈ 30，总时间复杂度 O(n log maxH) ≈ 3×10^7，在 1 秒内可完成。

**为什么不用贪心？** 这个问题无法用贪心解决，因为 H 值的选择是连续（离散但值域大）的，而且没有明显的局部最优选择策略。二分答案是将最优化问题转化为判定问题的经典手段。

## 🎯 本课小结

本节课我们进行了 CSP-J 第二轮的编程模拟训练，重点覆盖了四种核心算法类型：

1. **模拟算法**：核心是"细心+准确"，严格按照题目规则实现。日期类模拟题是 CSP-J 的高频考点，务必掌握闰年判断、月份天数、日期累加/差值计算等基础操作。

2. **枚举算法优化**：朴素枚举通常不能满足大数据范围的要求。通过排序+双指针、哈希表、前缀和等技巧可以将 O(n^3) 优化到 O(n^2) 或 O(n log n)。关键思路是"减少枚举维度"和"剪枝"。

3. **贪心算法**：适用前提是问题具有"贪心选择性质"和"最优子结构"。区间调度模型（按结束时间排序）是最经典的贪心问题，可以作为模板记忆。在使用贪心前，务必考虑是否存在反例。

4. **二分答案**：当问题具有单调性且直接求解困难时，二分答案是最佳武器。将"求最大值/最小值"转化为"判断某个值是否可行"，配合 O(n) 的 check 函数，可以在 O(n log V) 时间内解决（V 为答案值域范围）。

- 对于难题，不要放弃——部分分策略（暴力、特判、打表）往往能多拿 20-40 分
- 提交前用边界数据测试（n=1, n=最大值）
- 注意数组大小和 long long 的使用，防止溢出和越界
