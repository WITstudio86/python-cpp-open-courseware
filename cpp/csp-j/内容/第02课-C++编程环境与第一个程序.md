## 📖 知识精讲

### 一、为什么需要编程环境？

写 C++ 程序至少需要：

1. **编辑器**：输入源代码（`.cpp` 文本文件）。  
2. **编译器**：把源代码翻译成计算机可执行的机器码（Windows 上常见 MinGW 的 `g++`，考试环境多为类似工具链）。  
3. **调试与运行支持**：一键编译运行、看报错信息。

**IDE（集成开发环境）** 把编辑、编译、运行、简单调试集成在一个软件里。CSP-J 初学者最常见：

| IDE | 特点 | 适用 |
|-----|------|------|
| **Dev-C++** | 轻量、界面简单，许多培训与考场环境提供 | 入门首选 |
| **Code::Blocks** | 功能较全，跨平台，工程管理清晰 | 入门 / 进阶 |
| **VS Code + MinGW** | 现代编辑器，需自行配置编译器 | 有一定基础后 |
| **CLion / Visual Studio** | 功能强大但较重 | 非考试刚需 |

本课以 **Dev-C++** 与 **Code::Blocks** 为主说明操作流程，语法对所有环境通用。

### 二、Dev-C++ 基本使用

#### 1. 安装与首次打开（概述）

- 安装时注意勾选/确认已带 **MinGW 编译器**。  
- 打开后建议：`工具 → 编译选项` 中确认编译器路径有效。  
- 建议把代码保存在**纯英文、无空格**路径，例如 `D:\cspj\lesson02\hello.cpp`。

#### 2. 常用操作与快捷键

| 操作 | 常见快捷键 | 说明 |
|------|------------|------|
| 新建文件 | `Ctrl + N` | 得到空白源文件 |
| 打开文件 | `Ctrl + O` | 打开已有 `.cpp` |
| 保存 | `Ctrl + S` | **先保存再编译** |
| 另存为 | `Ctrl + Shift + S` | 指定文件名与路径 |
| 编译 | `F9` | 只编译，生成可执行文件 |
| 运行 | `F10` | 运行已编译程序 |
| 编译并运行 | `F11` | 最常用 |
| 撤销 | `Ctrl + Z` | 编辑撤销 |

> 不同 Dev-C++ 版本快捷键可能略有差异，以菜单“运行”下标注为准。原则：**修改代码后必须重新编译**。

#### 3. 推荐工作流程

```
1. 新建 → 立即另存为 hello.cpp（英文路径）
2. 输入代码
3. 保存 Ctrl+S
4. 编译运行 F11
5. 看黑框输出 / 看下方编译日志
6. 若有错误：根据行号改代码 → 再保存 → 再 F11
```

#### 4. 黑框一闪而过怎么办？

- 使用 IDE 的“编译运行”，一般会暂停。  
- 若直接双击 `.exe`，窗口可能瞬间关闭——可在 `return 0;` 前临时加：

```cpp
system("pause"); // Windows 下暂停；考试正式代码通常不需要
```

或用：

```cpp
cin.get();
```

竞赛正式提交代码**不要**依赖 `system("pause")`，评测环境不需要暂停。

### 四、编译运行四步骤

从你写的 `hello.cpp` 到屏幕上出现 `Hello`，底层大致经历：

```
源文件 .cpp
    │
    ▼  ① 预处理（Preprocessor）
预处理后的翻译单元
    │
    ▼  ② 编译（Compile）→ 汇编 → 目标文件 .o / .obj
    │
    ▼  ③ 链接（Link）把目标文件与库（如 iostream 实现）拼成可执行文件
可执行文件 .exe（Windows）或无扩展名（Linux/macOS）
    │
    ▼  ④ 运行（Execute）操作系统加载并执行
```

#### ① 预处理

处理以 `#` 开头的**预处理指令**，例如：

- `#include <iostream>`：把头文件内容插入到本文件。  
- `#define`：宏替换（本阶段课可不展开）。  
- 条件编译 `#ifdef` 等。

预处理**还不是**真正的“编译成机器码”，只是文本级处理。

#### ② 编译

- 检查语法：缺分号、括号不配、类型不匹配等在此报错。  
- 把 C++ 翻译成汇编，再变成**目标代码**（机器码片段）。  
- 此时若调用了库里的函数（如 `cout` 的实现），往往只生成“引用”，真正代码在链接阶段找。

#### ③ 链接

- 把多个 `.o` 与标准库、系统库**链接**成一个完整可执行文件。  
- 典型链接错误：`undefined reference to xxx`（写了声明却没实现、拼错函数名等）。

#### ④ 运行

- 操作系统把程序装入内存，从 `main` 开始执行。  
- 除零、越界、死循环、逻辑算错等属于运行阶段问题。

#### 错误类型对照表

| 类型 | 发生阶段 | 典型现象 | 例子 |
|------|----------|----------|------|
| **语法错误** | 编译 | 编译失败，红字报错 | 漏写 `;`、括号不配 |
| **链接错误** | 链接 | 编译过了但链接失败 | 调用未定义函数 |
| **运行时错误** | 运行 | 崩溃、异常退出 | 除以 0、严重越界 |
| **逻辑错误** | 运行 | 能运行但结果不对 | 公式写错、循环少一次 |

初学者 80% 的问题是**语法错误**，仔细看报错**行号**即可定位。

### 五、第一个 C++ 程序（逐行精讲）

```cpp
#include <iostream>          // ① 头文件
using namespace std;         // ② 命名空间

int main() {                 // ③ 主函数入口
    cout << "Hello, CSP-J!" << endl;  // ④ 输出
    return 0;                // ⑤ 正常结束
}
```

#### ① `#include <iostream>`

- `#include`：预处理指令，包含（引入）其他文件内容。  
- `<iostream>`：**输入输出流**头文件，提供 `cin`、`cout`、`endl` 等。  
- **尖括号 `<>`**：在系统标准路径中查找。  
- **双引号 `""`**：通常先在当前工程目录找，再找系统路径（多用于自写头文件）。

**CSP-J 常用头文件速查**：

| 头文件 | 用途 |
|--------|------|
| `<iostream>` | `cin` / `cout` |
| `<cstdio>` | `scanf` / `printf` |
| `<cmath>` | `sqrt` / `pow` / `fabs` 等 |
| `<cstring>` | C 风格字符串函数 |
| `<string>` | `string` 类 |
| `<algorithm>` | `sort` / `min` / `max` 等 |
| `<iomanip>` | `setw` / `setprecision` 等 |
| `<vector>` | 动态数组（后期 STL） |

> **不要**在 macOS 课程环境依赖 `<bits/stdc++.h>`（非标准，MSVC/部分环境没有）。本课程统一使用标准头文件。

#### ② `using namespace std;`

- C++ 标准库名字放在命名空间 `std` 中。  
- 不加时需写 `std::cout`、`std::endl`。  
- `using namespace std;` 后可直接写 `cout`。  
- 大型工程可能避免全局 using；**CSP-J 答题完全可以使用**。

等价写法：

```cpp
#include <iostream>
int main() {
    std::cout << "Hello" << std::endl;
    return 0;
}
```

#### ③ `int main() { ... }`

- 程序**有且仅有一个** `main` 作为入口。  
- 返回类型 `int`：向操作系统返回整型状态码。  
- `void main()` **不符合** C++ 标准，考试与评测中应写 `int main()`。  
- C++ **区分大小写**：`Main`、`MAIN` 都不对。  
- 参数形式 `int main(int argc, char *argv[])` 竞赛入门阶段一般不用。

#### ④ `cout << "Hello, CSP-J!" << endl;`

- `cout`：标准输出流对象（console output）。  
- `<<`：流插入运算符，可**链式**连接多个输出。  
- `endl`：输出换行并刷新缓冲区；也可用 `'\n'` 或 `"\n"` 只换行。  
- 字符串字面量用**英文双引号** `"..."`。

```cpp
cout << "a = " << 10 << ", b = " << 20 << endl;
// 输出：a = 10, b = 20
```

#### ⑤ `return 0;`

- 表示程序**正常结束**。  
- 约定：返回 0 成功，非 0 表示异常（操作系统/脚本可能检查）。  
- 在 `main` 中，C++ 标准允许省略 `return 0;`（编译器自动补），但**教学与 CSP-J 建议显式写出**，养成习惯。

### 六、程序结构的“最小骨架”与扩展

#### 最小可运行结构

```cpp
int main() {
    return 0;
}
```

（无输出；甚至可暂时不 `#include`，但一用 `cout` 就必须包含头文件。）

#### 竞赛实用骨架

```cpp
#include <iostream>
#include <cstdio>
#include <algorithm>
#include <cmath>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // 解题代码写在这里

    return 0;
}
```

说明：

- `ios::sync_with_stdio(false);` 与 `cin.tie(nullptr);` 用于加速 `cin/cout`，在数据量大时有用；与 `scanf/printf` 混用时要小心。  
- 初学阶段可以先不写这两行，不影响正确性。

### 七、注释（Comment）

注释给**人**看，编译器会忽略。

#### 1. 单行注释

```cpp
// 从双斜杠到行末都是注释
int a = 10; // 也可以写在语句后面
// cout << "这行不会执行";
```

#### 2. 多行注释

```cpp
/*
 * 可以写很多行
 * 常用于文件头说明
 */
```

#### 3. 不能嵌套

```cpp
// 错误示例：多行注释不能嵌套
/*
  外层
  /* 内层 */   // 这里外层就被结束了
  后面会暴露导致编译错误
*/
```

#### 4. 良好习惯

- 文件头写清题目、作者、思路（竞赛可简写）。  
- 复杂公式旁加一句人话解释。  
- **不要**用注释“删除”大段调试输出后忘记清理——提交前确认。  
- 用注释临时关掉代码，便于对比调试。

#### 5. 注释与输出题

阅读程序时，被注释掉的语句**不执行**，计算输出时务必划掉注释部分。

```cpp
cout << "Hello"; // 注释1
// cout << " World";
cout << " CSP-J" << endl;
// 输出：Hello CSP-J
```

### 八、`cout` 输出再练几招（为第 4 课铺垫）

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "第一行" << endl;
    cout << "A" << "B" << "C" << endl;  // ABC 紧挨着
    cout << 1 + 2 * 3 << endl;          // 先算表达式再输出 7

    int x = 5;
    cout << "x=" << x << '\n';           // 用 \n 换行

    // 常见转义字符
    cout << "引号: \"Hi\"" << endl;
    cout << "反斜杠: \\" << endl;
    cout << "制表符:\t中间" << endl;

    return 0;
}
```

**转义字符小表**：

| 写法 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 水平制表 |
| `\\` | 反斜杠本身 |
| `\"` | 双引号本身 |

### 九、从“能运行”到“会排查”

#### 1. 编译信息怎么读？

典型信息类似：

```
error: expected ';' before 'return'
```

- `error`：必须改，否则无法通过编译。  
- `warning`：能生成程序但可能有隐患，也应尽量消除。  
- 行号指向**编译器发现不对的位置**，真正漏写点有时在**上一行**。

#### 2. 调试输出法（printf-debug）

在关键步骤插入：

```cpp
cerr << "step1 x=" << x << endl;
```

或用 `cout`。确认程序执行到哪、变量是多少。正式提交前删除或注释调试输出。

#### 3. 样例对照法

- 先手算样例。  
- 再跑程序。  
- 不一致则缩小范围（注释掉后半段、打印中间量）。

### 十、课堂完整示例：欢迎程序 + 简单计算

```cpp
/*
 * 文件：welcome.cpp
 * 功能：演示程序结构、注释与基本输出
 */

#include <iostream>

}
```

```

a + b = 30
Program finished.
```

## ⚠️ 易错点

### 1. 漏写分号

```cpp
// 错误
cout << "Hi" << endl
return 0;

// 正确
cout << "Hi" << endl;
return 0;
```

注意：`#include` 行、函数头 `int main()` **后面没有分号**；函数体用 `{}`。

### 2. main 写法不规范

```cpp
// 错误
void main() { ... }
int Main() { ... }
int main { ... }     // 漏括号

// 正确
int main() { ... }
```

### 3. 中文标点 / 全角字符

```cpp
// 错误：中文引号、中文分号、中文括号
cout << “Hello”； 
// 正确
cout << "Hello";
```

从 PPT、网页复制代码时特别容易带入全角符号。

### 4. 多行注释嵌套

```cpp
// 错误
/* 注释开始
   /* 内层 */
   这里已经不在注释里了 → 编译错误
*/
```

### 5. 路径含中文或空格

```
错误示例：D:\信息学\第 2 课\新建文件夹\a.cpp
正确示例：D:\cspj\lesson02\hello.cpp
```

### 6. 修改代码后不重新编译

运行的是**旧的 exe**。务必保存后再次“编译运行”。

### 7. 头文件或命名空间缺失

```cpp
// 错误：用了 cout 却没 iostream / 没 std
int main() {
    cout << 1; // 报错
    return 0;
}

// 正确
#include <iostream>
using namespace std;
int main() {
    cout << 1;
    return 0;
}
```

### 8. 字符串与字符混淆（铺垫）

```cpp
// "A" 是字符串（const char[]）
// 'A' 是字符（char）
cout << "A" << endl;
cout << 'A' << endl;
```

初学输出用 `"..."` 即可；字符类型第 3 课细讲。

## 📝 真题精练

### 题目1：程序结构识别（选择）

**题目描述**  
下列关于下面程序的说法，**正确**的是？

```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "CSP-J" << endl;
    return 0;
}
```

A. `iostream` 是数学函数库头文件  
B. `main` 可以写成 `Main`  
C. `cout` 的作用是从键盘输入数据  
D. `return 0;` 表示程序正常结束  

**答案**：D  

**解析**：  
- A：`iostream` 是输入输出流，数学库常见 `<cmath>`。  
- B：C++ 区分大小写，`Main` ≠ `main`。  
- C：`cout` 是输出，`cin` 才是输入。  
- D：正确。

**验证 / 演示代码**

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "程序结构测试" << endl;
```

### 题目2：注释与输出结果

**题目描述**  
下列程序运行后的输出是什么？

```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "Hello"; // 这是注释1
    // cout << " World";
    cout << " CSP-J" << endl; /* 输出结束 */
    return 0;
}
```

**答案**：`Hello CSP-J`  

**解析**：  
- 第一句输出 `Hello`（行尾注释不影响）。  
- 第二句整行被 `//` 注释，不输出 ` World`。  
- 第三句输出 ` CSP-J` 并换行。  
- 多行注释包住的是说明文字，不在字符串里。

**完整代码（含说明输出）**

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello";      // 输出 Hello
    // cout << " World";  // 被注释，不执行
    cout << " CSP-J" << endl;

    // 最终输出：Hello CSP-J
    return 0;
}
```

## 🎯 本课小结

1. **环境**：Dev-C++ / Code::Blocks 等 IDE = 编辑 + 调用编译器；保存到英文路径；常用“编译并运行”。  
2. **四步骤**：预处理（`#include`）→ 编译（查语法、生成目标文件）→ 链接（拼库）→ 运行。  
3. **程序三要素**：`#include` 头文件 + `int main()` + `return 0;`；输出用 `cout << ...`。  
4. **命名空间**：`using namespace std;` 或写 `std::cout`。  
5. **注释**：`//` 单行，`/* */` 多行且**不可嵌套**；注释代码不执行。  
6. **易错**：分号、大小写、中文标点、忘记重新编译、`void main`。  
7. **排错顺序**：看清报错行号 → 修语法 → 再对照样例查逻辑；善用调试输出。

**下节预告**：第 3 课学习变量与基本数据类型（`int` / `long long` / `char` / `double` / `bool`）及命名规则，开始真正“存储”数据。
