**Dev-C++ 基本操作**：

- 编译+运行：`F11` 或菜单"运行→编译运行"
- 保存：`Ctrl + S`

### 二、编译运行流程

C++程序从源代码到可执行文件需要经过四个步骤：

```
源文件(.cpp) → [预处理器] → 预处理文件 → [编译器] → 目标文件(.o/.obj) → [链接器] → 可执行文件(.exe)
```

1. **预处理**：处理 `#include`、`#define` 等预处理指令，展开头文件和宏
2. **编译**：将C++代码翻译成汇编代码，再转换为目标代码（机器码）
3. **链接**：将多个目标文件和库文件合并成最终的可执行文件
4. **运行**：操作系统加载可执行文件到内存并执行

**常见编译错误类型**：
- **语法错误**（编译阶段）：缺少分号、括号不匹配、关键字拼写错误
- **链接错误**（链接阶段）：未定义的函数引用、重复定义
- **运行时错误**（运行阶段）：除零、数组越界、空指针访问
- **逻辑错误**：程序结果与预期不符（最难排查）

### 三、第一个C++程序详解

```cpp
#include <iostream>          // ① 包含输入输出流头文件
using namespace std;         // ② 使用标准命名空间

int main() {                 // ③ 主函数入口
    cout << "Hello, CSP-J!" << endl;  // ④ 输出语句
    return 0;                // ⑤ 返回0表示程序正常结束
}
```

**逐行解析**：

**① `#include <iostream>`**：
- `#include` 是预处理指令，作用是将指定文件的内容插入到当前位置
- `<iostream>` 是标准输入输出流头文件，包含了 `cin`、`cout` 的定义
- 尖括号 `<>` 表示从系统路径查找头文件
- 双引号 `""` 表示先从当前目录查找，再到系统路径查找
- 常用头文件：
  - `<iostream>`：输入输出（cin/cout）
  - `<cstdio>`：C风格输入输出（scanf/printf）
  - `<cmath>`：数学函数（sqrt/pow/abs）
  - `<cstring>`：字符串函数（strlen/strcpy/strcmp）
  - `<algorithm>`：算法函数（sort/min/max）
  - `<iomanip>`：格式化输出（setw/setprecision）

**② `using namespace std;`**：
- `namespace`（命名空间）用于避免命名冲突
- `std` 是标准库的命名空间
- 不加这行的写法：`std::cout << "Hello" << std::endl;`
- `using namespace std;` 表示后续代码可以直接使用 `std` 中的名字
- **注意**：在大型项目中不建议全局使用，但CSP-J考试中可以使用

**③ `int main() { ... }`**：
- C++程序的**唯一入口**，每个程序有且只有一个main函数
- `int` 表示main函数返回整型值给操作系统
- 括号 `()` 内可以写参数（`int main(int argc, char* argv[])`），也可省略
- CSP-J中通常使用 `int main()` 的简写形式

**④ `cout << ... << endl;`**：
- `cout`：标准输出流对象，输出内容到屏幕
- `<<`：输出运算符（插入运算符），可以连续使用（链式调用）
- `endl`：换行符 + 刷新缓冲区（等价于 `"\n" + flush`）
- 常用 `"\n"` 代替 `endl` 以提高效率（不刷新缓冲区）

**⑤ `return 0;`**：
- 表示程序正常退出，返回0给操作系统
- 返回值0通常表示成功，非0表示异常
- **CSP-J考试中main函数必须写 `return 0;`**

### 四、注释

注释不会被编译器处理，用于解释代码，提高可读性。

**单行注释**：`// 这是单行注释`（从 `//` 到行尾）

**多行注释**：`/* 这是多行注释 */`（可以跨多行，但不能嵌套）

**注释的使用规范**：
```cpp
/*
 * 文件名：hello.cpp
 * 功能：输出欢迎信息
 * 日期：2024-01-01
 */

#include <iostream>
using namespace std;

int main() {
    // 输出欢迎语句
    cout << "Welcome to CSP-J!" << endl;
    
    /*
    cout << "这行被注释掉了，不会执行" << endl;
    cout << "这行也不会执行" << endl;
    */
    
    return 0;  // 程序正常结束
}
```

## ⚠️ 易错点

- **分号遗漏**：C++中每条语句必须以 `;` 结尾。忘记分号是最常见的编译错误。注意 `#include` 和函数定义的第一行 `int main()` 后面不需要分号。
- **main函数写法错误**：正确写法是 `int main()`，不是 `void main()`（C++标准要求int）、不是 `Main()`（大小写敏感）、不是 `main`（缺少括号）。
- **中文标点符号**：代码中的所有标点必须是英文半角字符！中文的引号 `""`、分号 `；`、括号 `（）` 编译器都不认识，会造成编译错误。这是初学者最常犯的错。
- **注释嵌套问题**：`/* ... */` 注释不能嵌套。例如 `/* 外层注释 /* 内层注释 */ 这里有问题 */` 会导致编译错误。
- **路径与文件名**：Dev-C++编译时文件路径中不能有中文和空格，否则可能出现奇怪的编译错误。建议将代码保存在纯英文路径下。

## 📝 真题精练

### 题目1：程序结构识别
**题目描述**：以下C++代码中，哪个选项的说法是正确的？
```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "CSP-J" << endl;
    return 0;
}
```
A. `iostream` 是数学库头文件
B. `main` 函数可以写成 `Main`
C. `cout` 的作用是输入数据
D. `return 0;` 表示程序正常结束

**答案**：D
**解析**：A错误，iostream是输入输出流；B错误，C++区分大小写；C错误，cout是输出；D正确，return 0表示正常退出。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "程序结构测试" << endl;
    cout << "正确输出: D" << endl;
    return 0;
}
```

### 题目2：注释与编译
**题目描述**：以下程序运行后的输出结果是什么？
```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "Hello"; // 这是注释1
    // cout << " World";
    cout << " CSP-J" << endl; /* 输出结束 */
    return 0;
}
```

**答案**：`Hello CSP-J`
**解析**：注释内容不会被执行。第5行和第6行不影响输出。实际输出是 Hello CSP-J。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello";      // 输出Hello
    // cout << " World";  // 这行被注释，不执行
    cout << " CSP-J" << endl;  // 输出 CSP-J 并换行
    
    // 最终输出：Hello CSP-J
    return 0;
}
```
