## 📖 知识精讲

### 一、关系运算符

关系运算符用于比较两个值，结果为 `bool` 类型：`true`（输出为 1）或 `false`（输出为 0）。

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `>` | 大于 | `5 > 3` | `true` |
| `<` | 小于 | `5 < 3` | `false` |
| `>=` | 大于等于 | `5 >= 5` | `true` |
| `<=` | 小于等于 | `5 <= 3` | `false` |
| `==` | 等于 | `5 == 5` | `true` |
| `!=` | 不等于 | `5 != 3` | `true` |

#### 1.1 重要性质

```cpp
// 1. 结果可参与算术
cout << (5 > 3) + 10;   // 11（true 当作 1）

// 2. 字符按 ASCII 比较
'A' < 'B'    // true（65 < 66）
'a' > 'A'    // true（97 > 65）
'0' < '9'    // true

// 3. 链式比较不能按数学习惯写
// 数学：0 < x < 10
// C++ 错误写法：0 < x < 10
//   实际是 (0 < x) < 10 → 0 或 1 再与 10 比较，恒为 true！
// 正确：0 < x && x < 10
```

#### 1.2 `==` 与 `=` 的生死之别

```cpp
int a = 3;
if (a = 5) {          // 赋值！a 变成 5，条件为真
    cout << "进入了";  // 一定会执行
}
if (a == 5) {         // 判断 a 是否等于 5
    cout << "a 等于 5";
}
```

**防御习惯**：有人把常量写在左边 `if (5 == a)`，若误写成 `if (5 = a)` 会编译报错。考试中仍以理解语义为主。

#### 1.3 浮点数比较陷阱

```cpp
double x = 0.1 + 0.2;
if (x == 0.3) { ... }           // 可能为假！
if (fabs(x - 0.3) < 1e-9) { ... } // 正确：误差范围比较
```

CSP-J 早期题目较少考浮点相等，但一旦涉及，切记不要直接 `==`。

### 二、逻辑运算符

| 运算符 | 含义 | 运算规则 |
|--------|------|----------|
| `&&` | 逻辑与 AND | 两边都为真才为真 |
| `\|\|` | 逻辑或 OR | 至少一边为真就为真 |
| `!` | 逻辑非 NOT | 取反 |

#### 2.1 真值表

| a | b | a && b | a \|\| b | !a |
|---|----|--------|----------|-----|
| true | true | true | true | false |
| true | false | false | true | false |
| false | true | false | true | true |
| false | false | false | false | true |

**非 0 即真**：在条件上下文中，`0` 为假，**任意非 0** 为真。

```cpp
if (5) { ... }      // 真
if (0) { ... }      // 假
if (-1) { ... }     // 真
if (3 && 0) { ... } // 假
if (3 || 0) { ... } // 真
```

#### 2.2 短路特性（考试重点！）

**`&&` 短路**：若左边已为 `false`，右边**不再计算**（结果必为 false）。  
**`||` 短路**：若左边已为 `true`，右边**不再计算**（结果必为 true）。

```cpp
int a = 0, b = 5;
if (a != 0 && b / a > 1) {
    // a==0 时左边 false，b/a 不执行 → 避免除零
}

int x = 10;
if (x > 5 || ++x > 10) {
    // x>5 为 true，++x 不执行，x 仍为 10
}
```

**经典阅读题**：

```cpp
int a = 0, b = 0;
if (a++ && b++) {
    a++;
}
cout << a << " " << b << endl;
// a++ 用 0（假），然后 a=1；短路，b++ 不执行
// if 体不进。输出：1 0
```

再看 `||`：

```cpp
int a = 0, b = 0;
if (a++ || b++) {
    a++;
}
// a++ 用 0（假），a=1；左边假，必须算右边 b++：用 0，b=1
// 0||0 为假，不进 if。输出：1 1

int c = 1, d = 0;
if (c++ || d++) {
    c++;
}
// c++ 用 1（真），c=2；短路，d++ 不执行
// 进 if，c++ → c=3。输出：c=3 d=0
```

#### 2.3 短路的实用写法

```cpp
// 安全除法：先判除数
if (b != 0 && a / b > 10) { ... }

// 安全下标：先判范围
if (i >= 0 && i < n && arr[i] > 0) { ... }

// 顺序反了会崩溃：
// if (a / b > 10 && b != 0)  // b=0 时先除零！
```

#### 2.4 逻辑运算与位运算的区别（预告）

| | 逻辑 | 按位 |
|--|------|------|
| 与 | `&&` | `&` |
| 或 | `\|\|` | `\|` |
| 非 | `!` | `~` |
| 对象 | 真假（整体） | 每一个二进制位 |
| 短路 | 有 | **无** |

```cpp
5 && 3   // 1（两边非0，逻辑真）
5 & 3    // 1（0101 & 0011 = 0001，数值恰巧也是 1）
4 && 2   // 1
4 & 2    // 0（0100 & 0010 = 0000）  ← 与逻辑结果不同！
```

### 三、位运算符

位运算符直接操作整数的二进制位。

预备：`5 = 0101₂`，`3 = 0011₂`（仅示低 4 位）。

| 运算符 | 含义 | 规则 | 示例 |
|--------|------|------|------|
| `&` | 按位与 | 全 1 才 1 | `5 & 3 = 1`（0001） |
| `\|` | 按位或 | 有 1 就 1 | `5 \| 3 = 7`（0111） |
| `^` | 按位异或 | 不同为 1 | `5 ^ 3 = 6`（0110） |
| `~` | 按位取反 | 0↔1 | `~5` 在 32 位补码下为 -6 |
| `<<` | 左移 | 左移 n 位，低位补 0 | `5 << 1 = 10` |
| `>>` | 右移 | 右移 n 位 | `5 >> 1 = 2` |

#### 3.1 按位与、或、异或

```cpp
// 与：常用于取位、清零某些位
n & 1          // 取最低位 → 判奇偶
n & (1 << k)   // 测试第 k 位是否为 1

// 或：常用于置 1
n | (1 << k)   // 将第 k 位置 1

// 异或：相同为 0，不同为 1
// 性质：a ^ a = 0，a ^ 0 = a，满足交换律结合律
a ^= b; b ^= a; a ^= b;  // 交换 a,b（a、b 不能是同一变量）
```

#### 3.2 取反 `~` 与补码

在 32 位 `int` 下：

```cpp
~0 = -1        // 全 1 的补码是 -1
~5 = -6        // 5 的按位取反
```

考试较少要求手算复杂补码，但需知道 `~` 结果一般是负数。

#### 3.3 移位运算

```cpp
n << 1   ≈ n * 2
n << k   ≈ n * (2^k)
n >> 1   ≈ n / 2   （整数除法，向零？实现相关；正数安全）
n >> k   ≈ n / (2^k)
```

**注意**：
- 左移可能溢出
- 移位量 ≥ 类型位数（如 `int` 移 32 位）是未定义行为
- 需要大移位用 `1LL << 40`
- 算术右移（有符号）会填充符号位，逻辑右移填 0；C++ 对有符号右移实现定义，**竞赛中尽量只对非负整数右移**

#### 3.4 竞赛常用位运算技巧

```cpp
// 1. 判奇偶（比 % 快，常写）
if (n & 1) { /* 奇数 */ } else { /* 偶数 */ }

// 2. 判 2 的幂
// n > 0 且二进制只有一个 1
if (n > 0 && (n & (n - 1)) == 0) { /* 是 2 的幂 */ }

// 3. 取第 k 位（k 从 0 开始，0 为最低位）
int bit = (n >> k) & 1;

// 4. 第 k 位置 1 / 置 0 / 翻转
n |= (1 << k);
n &= ~(1 << k);
n ^= (1 << k);

// 5. 去掉最低的 1
n = n & (n - 1);

// 6. 只保留最低的 1
int lowbit = n & -n;  // 树状数组常用
```

### 四、三目运算符（条件运算符 `?:`）

**语法**：`条件 ? 表达式1 : 表达式2`

- 条件为真 → 取表达式1 的值  
- 条件为假 → 取表达式2 的值  

```cpp
int a = 10, b = 20;
int maxVal = (a > b) ? a : b;   // 20

// 等价于：
// if (a > b) maxVal = a; else maxVal = b;
```

#### 4.1 常见用法

```cpp
// 绝对值
int absX = (x >= 0) ? x : -x;

// 奇偶输出
cout << ((n & 1) ? "奇数" : "偶数") << endl;

// 及格判断
string s = (score >= 60) ? "及格" : "不及格";
```

#### 4.2 嵌套与结合性

三目运算符**右结合**：

```cpp
a ? b : c ? d : e
// 等价于 a ? b : (c ? d : e)
// 不是 (a ? b : c) ? d : e
```

成绩等级示例：

```cpp
int score = 85;
char grade = (score >= 90) ? 'A' :
             (score >= 80) ? 'B' :
             (score >= 70) ? 'C' :
             (score >= 60) ? 'D' : 'E';
// grade = 'B'
```

#### 4.3 使用建议

- 简单二选一用三目，代码更紧凑  
- 逻辑复杂时仍用 `if-else`，可读性更好  
- 两个分支类型应兼容（如都是 `int`，或都可转为同一类型）

### 五、混合表达式与优先级回顾

结合第 5 课优先级：

```cpp
// 关系优先于逻辑
if (a > 0 && b > 0)   // (a>0) && (b>0)

// && 优先于 ||
if (a || b && c)      // a || (b && c)

// 位运算优先于逻辑，但低于关系
// 建议：位运算一律加括号
if ((x & 1) && (y > 0)) { ... }

// 三目低于逻辑，赋值更低
int z = (x > y) ? x : y;
```

**铁律**：位运算、混合逻辑、三目嵌套时，**多写括号**。

### 六、逗号运算符（了解）

```cpp
int a = (1, 2, 3);  // a = 3，取最后一个
// for 循环中常见：
for (int i = 0, j = n - 1; i < j; i++, j--) { ... }
```

逗号优先级最低。CSP-J 较少单独考，但阅读 `for` 时会遇到。

## ⚠️ 易错点

### 易错点1：`==` 写成 `=`

```cpp
if (a = 5)  // 赋值且恒真（5 非 0）
```

编译器可能给 warning，但竞赛评测不一定当错误。

### 易错点2：数学链式比较

```cpp
// 错误：
if (0 < x < 10)  // 恒真或逻辑错误
// 正确：
if (0 < x && x < 10)
```

### 易错点3：短路顺序写反

```cpp
// 危险：
if (a / b > 1 && b != 0)
// 安全：
if (b != 0 && a / b > 1)
```

数组访问同理：先判 `i` 合法，再写 `arr[i]`。

### 易错点4：`&` 与 `&&`、`|` 与 `||` 混用

```cpp
if (x & 1 && y > 0)   // 能跑，但建议写成 if ((x & 1) && y > 0)
if (flag1 & flag2)    // 若 flag 是 0/1 有时碰巧对，语义却是按位
```

逻辑判断用 `&&` `||`；位操作用 `&` `|`，并加括号。

### 易错点5：移位越界与有符号右移

```cpp
1 << 40          // int 上未定义（至少危险）
1LL << 40        // 正确
int x = -8;
x >> 1           // 实现定义，不要依赖
```

### 易错点6：三目嵌套结合性搞错

```cpp
a ? b : c ? d : e   // = a ? b : (c ? d : e)
```

复杂嵌套建议加括号或改 `if-else`。

### 易错点7：逻辑非与按位取反

```cpp
!5    // 0（逻辑：非真→假）
~5    // -6（按位取反）
!!5   // 1（规范化为 bool）
```

### 易错点8：异或交换同一变量

```cpp
a ^= a ^= a;  // 危险/错误用法
// a 与 b 是同一变量时 a^=b; b^=a; a^=b; 会清零
```

交换优先用 `swap(a, b)` 或临时变量。

## 📝 真题精练

### 真题1：逻辑短路判断

**题目描述**：阅读以下程序，写出运行结果。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 0, b = 0;
    if (a++ && b++) {
        a++;
    }
    cout << a << " " << b << endl;
    return 0;
}
```

**分析过程**：

1. `a++`：后置，表达式值为 `0`（假），然后 `a = 1`
2. 左边为假 → `&&` 短路 → `b++` **不执行**，`b` 仍为 0
3. 条件为假 → 不进入 if 体
4. 输出 `1 0`

**答案**：`1 0`

**AC 验证代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 0, b = 0;
    if (a++ && b++) {
        a++;
    }
    cout << a << " " << b << endl;  // 1 0
    return 0;
}
```

**考点**：后置自增的值、`&&` 短路、if 是否进入。

### 真题2：位运算与三目运算符

**题目描述**：阅读以下程序，写出运行结果。

```cpp
#include <iostream>
using namespace std;
int main() {
    int x = 5, y = 3;
    int z = (x & y) ? (x << 1) : (y << 1);
    cout << z << endl;
    return 0;
}
```

**分析过程**：

1. `x & y = 5 & 3 = 0101₂ & 0011₂ = 0001₂ = 1`
2. 条件 `1` 为真 → 取 `x << 1`
3. `5 << 1 = 10`
4. 输出 `10`

**答案**：`10`

**AC 验证代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 5, y = 3;
    int z = (x & y) ? (x << 1) : (y << 1);
    cout << z << endl;  // 10
    // 辅助理解：
    // cout << (x & y) << " " << (x << 1) << endl;  // 1 10
    return 0;
}
```

**考点**：按位与、左移、三目分支选择。

### 真题3（拓展）：短路综合

**题目描述**：写出下列程序输出。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 1, b = 2, c = 3;
    int r1 = a < b && b < c;
    int r2 = a > b || b < c;
    int x = 0, y = 5;
    int r3 = x && (y = 100);
    int r4 = x || (y = 100);
    cout << r1 << " " << r2 << " " << r3 << " " << y << " " << r4 << endl;
    return 0;
}
```

**分析**：

| 表达式 | 结果 | 说明 |
|--------|------|------|
| `a<b && b<c` | 1 | 1<2 且 2<3 |
| `a>b \|\| b<c` | 1 | 左边假，右边真 |
| `x && (y=100)` | 0 | x=0 短路，y 仍为 5，r3=0 |
| `x \|\| (y=100)` | 1 | x 假，执行 y=100，r4=1，y 变为 100 |

注意执行顺序：`r3` 时 y 未变；`r4` 时 y 变为 100。最终输出中的 y 是 `r4` 之后的 y。

**答案**：`1 1 0 100 1`

### 真题4（拓展）：奇偶与 2 的幂（编程）

**题目描述**：输入 n 个正整数（1 ≤ n ≤ 100，每个数 ≤ 10^9）。对每个数输出一行：若为奇数输出 `odd`，偶数输出 `even`；若同时是 2 的幂，再输出 ` power2`（前面有一个空格）。

**输入示例**：
```
4
1
2
3
8
```

**输出示例**：
```
odd power2
even power2
odd
even power2
```

**AC 代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (x & 1) {
            cout << "odd";
        } else {
            cout << "even";
        }
        if (x > 0 && (x & (x - 1)) == 0) {
            cout << " power2";
        }
        cout << endl;
    }
    return 0;
}
```

**考点**：`n & 1` 判奇偶，`n & (n-1)` 判 2 的幂，`long long` 防大数。

## 🎯 本课小结

### 核心知识点回顾

| 知识点 | 要点 |
|--------|------|
| 关系运算 | `> < >= <= == !=`；禁止数学链式比较 |
| 逻辑运算 | `&& \|\| !`；非 0 即真 |
| 短路 | `&&` 左假跳右；`\|\|` 左真跳右 |
| 位运算 | `& \| ^ ~ << >>`；左移≈×2，右移≈÷2 |
| 常用技巧 | `n&1` 奇偶；`n&(n-1)==0` 二的幂 |
| 三目 | `cond ? a : b`；右结合可嵌套 |
| 优先级 | 关系 > 位运算？实际请查表并加括号；逻辑低于关系 |

### 与第 5 课的衔接

- 第 5 课：算多少（算术、赋值、自增、优先级）  
- 第 6 课：判真假、拆二进制、写紧凑条件（关系、逻辑、位、三目）  
- 合在一起 → 可写完整的顺序结构表达式，并为第 7–8 课分支打基础

### 考试建议

1. **短路 + 自增** 是阅读题「必杀技」组合，务必练熟  
2. 条件里出现除法、数组下标，**先写合法性判断**  
3. 位运算题先画 4～8 位二进制再算  
4. `==` / `=`、`&&` / `&` 两对符号每次写完扫一眼  

### 下节预告

第 7 课进入**顺序结构与程序调试**：在已掌握表达式的基础上，学习完整的顺序执行流程、常见编译/运行错误与调试方法。
