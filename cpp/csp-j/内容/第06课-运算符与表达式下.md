## 📖 知识精讲

### 一、关系运算符

关系运算符用于比较两个值的大小关系，结果为bool类型（true/false）。

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `>` | 大于 | `5 > 3` | `true` (1) |
| `<` | 小于 | `5 < 3` | `false` (0) |
| `>=` | 大于等于 | `5 >= 5` | `true` (1) |
| `<=` | 小于等于 | `5 <= 3` | `false` (0) |
| `==` | 等于 | `5 == 5` | `true` (1) |
| `!=` | 不等于 | `5 != 3` | `true` (1) |

**重要提醒**：
- `==` 和 `=` 完全不同！`==`判断相等，`=`是赋值。这是最隐蔽的错误。
- 关系运算符产生bool值，可参与算术运算：`(5 > 3) + 10 = 11`（true=1）
- 字符也可以比较（比ASCII码）：`'A' < 'B'` 结果为true

### 二、逻辑运算符

| 运算符 | 含义 | 运算规则 |
|--------|------|----------|
| `&&` | 逻辑与（AND） | 两边都为true才为true |
| `\|\|` | 逻辑或（OR） | 至少一边为true就为true |
| `!` | 逻辑非（NOT） | 取反：true变false，false变true |

**真值表**：

| a | b | a && b | a \|\| b | !a |
|---|----|--------|----------|-----|
| true | true | true | true | false |
| true | false | false | true | false |
| false | true | false | true | true |
| false | false | false | false | true |

**短路特性**（考试重点！）：
- `&&` 短路：如果左边为false，右边不再计算（因为结果已经确定为false）
- `||` 短路：如果左边为true，右边不再计算（因为结果已经确定为true）

```cpp
int a = 0, b = 5;
if (a != 0 && b / a > 1) {  // a=0，左边为false，短路！
    // b / a 不会执行（避免了除零错误）
}

int x = 10;
if (x > 5 || ++x > 10) {    // x>5为true，短路！
    // ++x 不会执行，x仍然为10
}
```

**短路特性的实际应用**：
```cpp
// 安全除法：先判断除数不为0
if (b != 0 && a / b > 10) { ... }

// 安全访问：先判断指针/下标有效
if (i >= 0 && i < n && arr[i] > 0) { ... }
```

### 三、位运算符

位运算符直接对二进制位进行操作，是C++底层操作的重要工具。

**预备知识**：回忆二进制表示
```
例如：a = 5 → 0101, b = 3 → 0011
```

| 运算符 | 含义 | 规则 | 示例（5 & 3） |
|--------|------|------|---------------|
| `&` | 按位与 | 全1为1，有0为0 | `0101 & 0011 = 0001 = 1` |
| `\|` | 按位或 | 有1为1，全0为0 | `0101 \| 0011 = 0111 = 7` |
| `^` | 按位异或 | 不同为1，相同为0 | `0101 ^ 0011 = 0110 = 6` |
| `~` | 按位取反 | 0变1，1变0 | `~0101 = 1010`（32位考虑） |
| `<<` | 左移 | 各二进制位左移n位，低位补0 | `5 << 1 = 1010 = 10` |
| `>>` | 右移 | 各二进制位右移n位 | `5 >> 1 = 0010 = 2` |

**移位运算的重要性质**：
```cpp
n << 1  等价于  n * 2        // 左移1位 = 乘以2
n << k  等价于  n * (2^k)    // 左移k位 = 乘以2的k次方
n >> 1  等价于  n / 2        // 右移1位 = 除以2（整数除法）
n >> k  等价于  n / (2^k)    // 右移k位 = 除以2的k次方
```

**位运算的经典应用**：
```cpp
// 1. 判断奇偶（比 % 更快）
if (n & 1) { /* 奇数 */ } else { /* 偶数 */ }

// 2. 交换两个数（无需临时变量）
a ^= b; b ^= a; a ^= b;

// 3. 取第k位（k从0开始）
int bit = (n >> k) & 1;

// 4. 将第k位置为1
n |= (1 << k);

// 5. 将第k位置为0
n &= ~(1 << k);

// 6. 2的幂判断
if (n > 0 && (n & (n - 1)) == 0) { /* n是2的幂 */ }
```

### 四、三目运算符（条件运算符）

**语法**：`条件 ? 表达式1 : 表达式2`

**执行过程**：
- 先计算"条件"，若为true，返回"表达式1"的值
- 若为false，返回"表达式2"的值

```cpp
int a = 10, b = 20;
int maxVal = (a > b) ? a : b;  // maxVal = 20

// 等价于：
// if (a > b) maxVal = a; else maxVal = b;
```

**嵌套三目运算符**：
```cpp
int score = 85;
char grade = (score >= 90) ? 'A' : 
             (score >= 80) ? 'B' : 
             (score >= 70) ? 'C' : 'D';
// score=85, grade='B'
```

**注意**：
- 三目运算符是**右结合**的
- `a ? b : c ? d : e` 等价于 `a ? b : (c ? d : e)`
- 表达式1和表达式2的类型应当兼容

## 💻 代码模板

### 关系与逻辑运算模板
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 20, c = 10;
    
    // 关系运算
    cout << "a < b: " << (a < b) << endl;    // 1 (true)
    cout << "a == c: " << (a == c) << endl;  // 1 (true)
    cout << "a != b: " << (a != b) << endl;  // 1 (true)
    
    // 逻辑运算
    cout << "(a < b) && (a == c): " << ((a < b) && (a == c)) << endl;  // 1
    cout << "!(a > b): " << (!(a > b)) << endl;  // 1
    
    // 短路演示
    int x = 5;
    if (x > 3 || (x = 100)) {  // x>3为true，短路
        cout << "短路后x = " << x << endl;  // x仍然是5
    }
    
    return 0;
}
```

### 位运算模板
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 5, b = 3;  // a=0101, b=0011
    
    // 基本位运算
    cout << "a & b = " << (a & b) << endl;  // 1 (0001)
    cout << "a | b = " << (a | b) << endl;  // 7 (0111)
    cout << "a ^ b = " << (a ^ b) << endl;  // 6 (0110)
    cout << "~a = " << (~a) << endl;        // 注意：取反考虑补码
    
    // 移位运算
    cout << "5 << 1 = " << (5 << 1) << endl;  // 10
    cout << "5 >> 1 = " << (5 >> 1) << endl;  // 2
    
    // 判断奇偶
    int n;
    cin >> n;
    cout << (n & 1 ? "奇数" : "偶数") << endl;
    
    return 0;
}
```

### 三目运算符模板

```cpp
#include <iostream>

int main() {

```

## ⚠️ 易错点

- **== 与 = 混淆**：`if (a = 5)` 是赋值，始终为true！应该用 `if (a == 5)`。这个错误编译器通常不报错，非常隐蔽。
- **短路特性忽略**：写 `if (a != 0 && b / a > 10)` 是安全的（a=0时右边不执行），但写成 `if (b / a > 10 && a != 0)` 顺序反了，a=0时会除零崩溃。条件判断的**顺序很重要**！
- **位运算与逻辑运算混淆**：`&`（按位与）和 `&&`（逻辑与）不同！`5 & 3 = 1`，`5 && 3 = 1`（值恰好相同但含义不同）。同理 `|` 和 `||` 也不同。
- **移位超出范围**：`1 << 40` 在int类型中会导致未定义行为，因为移位超过了int的位数（32位）。如果需要大移位，用 `1LL << 40`。
- **三目运算符的嵌套**：`a ? b : c ? d : e` 是 `a ? b : (c ? d : e)`，不是 `(a ? b : c) ? d : e`。三目运算符是右结合的。

## 📝 真题精练

### 题目1：逻辑短路判断
**题目描述**：阅读以下程序，写出运行结果。
```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 0, b = 0;
    if (a++ && b++) {
        a++;
    }
    cout << a << " " << b << endl;
    return 0;
}
```

**分析过程**：
- `a++`：后置自增，先用值再++。先用a的值0（false），然后a=1
- 因为a++的结果是0（false），逻辑与短路，`b++`不执行
- if条件为false，不进入if体
- 最终：a=1, b=0

**答案**：`1 0`

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 0, b = 0;
    // a++先用a的值0(false)，然后a=1
    // 短路：左边已经false，b++不执行
    if (a++ && b++) {
        a++;
    }
    cout << a << " " << b << endl;  // 1 0
    return 0;
}
```

### 题目2：位运算与三目运算符
**题目描述**：阅读以下程序，写出运行结果。
```cpp
#include <iostream>
using namespace std;
int main() {
    int x = 5, y = 3;
    int z = (x & y) ? (x << 1) : (y << 1);
    cout << z << endl;
    return 0;
}
```

**分析过程**：
- `x & y = 5 & 3 = (0101) & (0011) = 0001 = 1`
- 三目运算符条件为非0（true），所以执行 `x << 1`
- `x << 1 = 5 << 1 = 10`
- z = 10

**答案**：`10`

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 5, y = 3;
    // 5 & 3 = 1（非0，true）
    // 所以执行 x << 1 = 10
    int z = (x & y) ? (x << 1) : (y << 1);
    cout << z << endl;  // 10
    
    // 验证：位与结果
    cout << "x & y = " << (x & y) << endl;    // 1
    cout << "x << 1 = " << (x << 1) << endl;  // 10
    
    return 0;
}
```

## 🎯 本课小结
1. 关系运算符：`> < >= <= == !=`，注意 `==`（比较）和 `=`（赋值）的区别
2. 逻辑运算符：`&&` 和 `||` 有短路特性，合理利用可避免错误和提高效率
3. 位运算符：`& | ^ ~ << >>`，左移=乘以2，右移=除以2
4. 三目运算符：`条件 ? 表达式1 : 表达式2`，右结合，可嵌套
5. 位运算竞赛常用技巧：`n&1`判奇偶、`a^=b^=a^=b`交换、`n&(n-1)==0`判2的幂
