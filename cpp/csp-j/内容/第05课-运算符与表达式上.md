# 第5课：运算符与表达式（上）

## 🎯 考纲要求
- 算术运算符（+ - * / %）
- 赋值运算符（= += -= *= /= %=）
- 自增自减（++ --）
- 运算符优先级与结合性

## 📖 知识精讲

### 一、算术运算符

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `5 + 3` | `8` |
| `-` | 减法 | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法 | `5 / 2` | `2`（整数除法！） |
| `%` | 取模（取余） | `5 % 2` | `1` |

**整数除法规则**：
- 两个整数相除，结果仍为整数（**小数部分直接丢弃**，向零取整）
- `5 / 2 = 2`，`-5 / 2 = -2`（C++11起，向零取整）
- 要得到小数结果，需要至少一个操作数为浮点型：`5.0 / 2` 或 `(double)5 / 2`

**取模运算规则**：
- `%` 只能用于**整数类型**（int、long long等）
- 结果符号与被除数（左操作数）相同
- `5 % 3 = 2`，`5 % (-3) = 2`，`(-5) % 3 = -2`，`(-5) % (-3) = -2`
- 判断整除：`if (n % 2 == 0)` 表示n能被2整除（偶数）
- 获取个位数：`n % 10` 获得n的个位数字

**常见技巧**：
- 判断奇偶：`n % 2 == 0` 偶数，`n % 2 == 1` 奇数
- 获取最后k位：`n % (10^k)` （k个0）
- 循环取数：`while (n > 0) { digit = n % 10; n /= 10; }` 逐位分离

### 二、赋值运算符

**基本赋值** `=`：
```cpp
int a;
a = 10;      // 将10赋给a
a = a + 5;   // 先计算右边，再赋给左边 → a变为15
```

**复合赋值运算符**：
| 运算符 | 等价于 | 示例 |
|--------|--------|------|
| `+=` | `a = a + b` | `a += 3;` → `a = a + 3;` |
| `-=` | `a = a - b` | `a -= 3;` → `a = a - 3;` |
| `*=` | `a = a * b` | `a *= 3;` → `a = a * 3;` |
| `/=` | `a = a / b` | `a /= 3;` → `a = a / 3;` |
| `%=` | `a = a % b` | `a %= 3;` → `a = a % 3;` |

**解析**：
- 复合赋值更简洁，书写效率高
- 执行效率：复合赋值可能比普通赋值快（编译器优化后通常一样）
- `a += b` 可以理解为：先取a的值，加上b，再存回a

### 三、自增自减运算符（++ / --）

这是CSP-J考试的**高频考点**，务必掌握！

**基本形式**：

| 运算符 | 名称 | 含义 |
|--------|------|------|
| `++a` | 前置自增 | 先将a加1，再使用a的值 |
| `a++` | 后置自增 | 先使用a的值，再将a加1 |
| `--a` | 前置自减 | 先将a减1，再使用a的值 |
| `a--` | 后置自减 | 先使用a的值，再将a减1 |

**记忆口诀**：**前加后用（前置：先加后用），先用后加（后置：先用后加）**

**经典例题**：
```cpp
int a = 5, b;
b = ++a;  // 前置：先a=a+1→a=6，再b=a→b=6。结果：a=6, b=6

int x = 5, y;
y = x++;  // 后置：先y=x→y=5，再x=x+1→x=6。结果：x=6, y=5
```

**复杂表达式分析**（考试重难点）：
```cpp
int a = 3;
int b = ++a + a++;  
// 分析过程：
// a初始=3
// ++a：先加→a=4，值为4
// a++：先取值→值为4，再加→a=5
// 所以 b = 4 + 4 = 8, a=5
```

**考试技巧**：
- 按表达式从左到右逐个分析自增自减
- 画变量变化表，记录每次变化后的值
- 注意：同一个表达式中对一个变量多次自增自减是**未定义行为**，但CSP-J考试中会按特定编译器行为出题（通常按从左到右顺序）

### 四、运算符优先级与结合性

**优先级口诀**（从高到低）：
> 单目 > 算术 > 关系 > 逻辑 > 赋值

**详细优先级表**（重要）：

| 优先级 | 运算符 | 结合性 | 说明 |
|--------|--------|--------|------|
| 1（最高） | `()` `[]` `.` `->` | 左→右 | 括号、下标 |
| 2 | `!` `~` `++` `--` `+`(正) `-`(负) `*`(指针) `&`(取地址) `sizeof` | **右→左** | 单目运算符 |
| 3 | `*` `/` `%` | 左→右 | 乘除取模 |
| 4 | `+` `-` | 左→右 | 加减 |
| 5 | `<<` `>>` | 左→右 | 移位 |
| 6 | `<` `<=` `>` `>=` | 左→右 | 关系比较 |
| 7 | `==` `!=` | 左→右 | 相等判断 |
| 8 | `&` | 左→右 | 按位与 |
| 9 | `^` | 左→右 | 按位异或 |
| 10 | `\|` | 左→右 | 按位或 |
| 11 | `&&` | 左→右 | 逻辑与 |
| 12 | `\|\|` | 左→右 | 逻辑或 |
| 13 | `?:` | **右→左** | 三目运算符 |
| 14 | `=` `+=` `-=` 等 | **右→左** | 赋值运算符 |
| 15（最低） | `,` | 左→右 | 逗号运算符 |

**结合性**：决定同优先级运算符的计算顺序
- 左结合 = 从左往右算（如 `a-b+c` 先算 `a-b` 再加c）
- 右结合 = 从右往左算（如 `a=b=c` 先算 `b=c` 再 `a=b`）

**实战分析**：
```cpp
int a = 3, b = 5, c = 2;
int result = a + b * c;     
// 乘法优先级高于加法
// result = 3 + (5 * 2) = 3 + 10 = 13

int x = 10;
int y = x += x *= 2;   
// 赋值运算符右结合，从右往左
// 先 x *= 2 → x = 20
// 再 x += 20 → x = 40
// y = 40, x = 40
```

**考试建议**：
- 不确定优先级时，**加括号**最安全！
- 如 `(a + b) * c` 比 `a + b * c` 意图更清晰
- CSP-J阅读程序题常考查不加括号的表达式优先级

## 💻 代码模板

### 算术运算模板
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 3;
    
    // 基本算术运算
    cout << "a + b = " << a + b << endl;  // 13
    cout << "a - b = " << a - b << endl;  // 7
    cout << "a * b = " << a * b << endl;  // 30
    cout << "a / b = " << a / b << endl;  // 3（整数除法）
    cout << "a % b = " << a % b << endl;  // 1
    
    // 浮点除法
    cout << "a / b (浮点) = " << (double)a / b << endl;  // 3.33333
    
    // 获取各位数字
    int n = 12345;
    cout << "个位: " << n % 10 << endl;       // 5
    cout << "十位: " << n / 10 % 10 << endl;  // 4
    cout << "百位: " << n / 100 % 10 << endl; // 3
    
    return 0;
}
```

### 自增自减分析模板
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    
    // 前置++
    a = 5;
    b = ++a;
    cout << "前置++: a=" << a << ", b=" << b << endl;  // a=6, b=6
    
    // 后置++
    a = 5;
    b = a++;
    cout << "后置++: a=" << a << ", b=" << b << endl;  // a=6, b=5
    
    // 混合
    a = 3;
    b = ++a + a++;
    cout << "混合: a=" << a << ", b=" << b << endl;    // a=5, b=8
    
    return 0;
}
```

## ⚠️ 易错点

- **整数除法截断**：`5 / 2 = 2` 而不是 2.5！这是初学C++最常见的错误之一。两个操作数都是整数时，结果必然是整数。如果需要小数结果，至少将其中一个转换为浮点型。
- **取模运算的操作数**：`%` 只能用于整数，不能用于浮点数！`5.0 % 2` 是编译错误。此外，`a % b` 中 b 不能为 0（除零错误）。
- **自增自减的前后置混淆**：`++i`（前置，先加后用）与 `i++`（后置，先用后加）结果不同。考试中经常出现复杂表达式，要一个一个按顺序分析，画表格记录变量变化过程。
- **赋值运算符的判断**：`if (a = 5)` 与 `if (a == 5)` 完全不同！`=` 是赋值（结果为5，非0即true），`==` 是判断相等。这个错误编译器不会报错，但逻辑完全不同。
- **溢出问题**：`int a = 100000; int b = a * a;` 结果 b = 10¹⁰，超出int范围导致溢出。解决方案：`long long b = (long long)a * a;`

## 📝 真题精练

### 题目1：表达式求值
**题目描述**：阅读以下程序，写出运行结果。
```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 10, b = 3;
    cout << a / b << endl;
    cout << a % b << endl;
    a += b;
    cout << a << endl;
    a *= 2 + 3;
    cout << a << endl;
    return 0;
}
```

**分析过程**：
1. `a / b = 10 / 3 = 3`（整数除法）
2. `a % b = 10 % 3 = 1`
3. `a += b → a = 10 + 3 = 13`
4. `a *= 2 + 3 → a *= 5 → a = 13 * 5 = 65`
   - 注意：复合赋值中，右侧整体先计算 `2+3=5`，再 `a *= 5`

**答案**：
```
3
1
13
65
```

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 3;
    
    cout << a / b << endl;    // 3
    cout << a % b << endl;    // 1
    
    a += b;  // a = 13
    cout << a << endl;        // 13
    
    a *= 2 + 3;  // a = a * (2+3) = 13 * 5 = 65
    cout << a << endl;        // 65
    
    return 0;
}
```

### 题目2：自增自减运算
**题目描述**：阅读以下程序，写出运行结果。
```cpp
#include <iostream>
using namespace std;
int main() {
    int x = 5, y = 10;
    int z = x++ + ++y;
    cout << "x=" << x << ", y=" << y << ", z=" << z << endl;
    return 0;
}
```

**分析过程**：
- x初始=5, y初始=10
- `x++`：后置自增，先使用x值5，再x→6
- `++y`：前置自增，先y→11，再使用y值11
- z = 5 + 11 = 16
- 最终：x=6, y=11, z=16

**答案**：`x=6, y=11, z=16`

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 5, y = 10;
    int z = x++ + ++y;
    // x++: 先用5，x变6
    // ++y: y先变11，再用11
    // z = 5 + 11 = 16
    
    cout << "x=" << x << ", y=" << y << ", z=" << z << endl;
    // 输出：x=6, y=11, z=16
    
    return 0;
}
```

## 🎯 本课小结
1. 算术运算符：`+ - * / %`，注意整数除法截断和取模只用于整数
2. 复合赋值：`+= -= *= /= %=`，更简洁高效
3. 自增自减：`++a` 先加后用，`a++` 先用后加（考试重难点！）
4. 优先级口诀：单目 > 算术 > 关系 > 逻辑 > 赋值
5. 不确定优先级时，多使用括号明确计算顺序
