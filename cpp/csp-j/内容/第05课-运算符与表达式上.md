## 📖 知识精讲

### 一、表达式与运算符概述

**表达式（Expression）** 是由操作数（常量、变量）和运算符组成的式子，计算后得到一个值。例如：

```cpp
3 + 5          // 值为 8
a * b + c      // 先算 a*b，再加 c
x = y + 1      // 赋值表达式，值等于赋给 x 的结果
```

**运算符按操作数个数分类**：

| 类型 | 操作数个数 | 示例 |
|------|-----------|------|
| 单目运算符 | 1 | `++a`、`-x`、`!flag` |
| 双目运算符 | 2 | `a + b`、`a % b`、`a = b` |
| 三目运算符 | 3 | `a ? b : c`（第6课） |

**语句 vs 表达式**：
- `a = 5;` 是语句（带分号）
- `a = 5` 是表达式（有值，值为 5）
- 表达式可以嵌套在更大的表达式里，语句不行

### 二、算术运算符（`+ - * / %`）

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法（或正号） | `5 + 3` | `8` |
| `-` | 减法（或负号） | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法 | `5 / 2` | `2`（整数除法！） |
| `%` | 取模（取余） | `5 % 2` | `1` |

#### 2.1 整数除法：向零取整

两个操作数都是**整数类型**时，`/` 做整数除法，小数部分**直接丢弃**（C++11 起明确规定为**向零取整**）：

```cpp
5 / 2     // 2    （不是 2.5）
-5 / 2    // -2   （向零取整，不是 -3）
5 / -2    // -2
-5 / -2   // 2
7 / 3     // 2
```

**记忆**：砍掉小数部分，靠近 0。`2.9 → 2`，`-2.9 → -2`。

**要得到小数结果**，至少一个操作数为浮点：

```cpp
5.0 / 2          // 2.5
5 / 2.0          // 2.5
(double)5 / 2    // 2.5
1.0 * 5 / 2      // 2.5（先 1.0*5 变 double，再 /2）
```

**错误写法**：
```cpp
(double)(5 / 2)  // 先整数除得 2，再转 double → 2.0，没用！
```

#### 2.2 取模运算 `%`

- **只能用于整数类型**（`int`、`long long` 等），浮点数取模编译错误
- 结果符号跟随**被除数**（左操作数）
- 数学关系：`a = (a / b) * b + (a % b)` 恒成立（在不溢出时）

```cpp
 5 %  3 =  2
 5 % -3 =  2
-5 %  3 = -2
-5 % -3 = -2
```

**经典技巧**：

```cpp
// 1. 判断奇偶
if (n % 2 == 0) { /* 偶数 */ }
if (n % 2 == 1) { /* 奇数（注意负数：-3%2 == -1） */ }
// 更稳妥：if (n % 2 != 0) 表示奇数

// 2. 取个位
int digit = n % 10;

// 3. 取最后 k 位数字
// n % 100 取后两位，n % 1000 取后三位……

// 4. 逐位分离
while (n > 0) {
    int d = n % 10;  // 当前最低位
    n /= 10;         // 去掉最低位
}

// 5. 判断整除
if (a % b == 0) { /* a 能被 b 整除 */ }

// 6. 时钟/环形下标
// 下一小时：(h + 1) % 24
// 数组环形：i = (i + 1) % n
```

**注意**：`a % 0` 与 `a / 0` 一样是未定义行为（运行时崩溃），必须保证除数非零。

#### 2.3 正负号（单目 `+` `-`）

```cpp
int x = 5;
int y = -x;   // y = -5
int z = +x;   // z = 5（单目正号，较少使用）
```

单目负号优先级高于双目加减（见优先级表）。

### 三、赋值运算符

#### 3.1 基本赋值 `=`

```cpp
int a;
a = 10;        // 将 10 赋给 a
a = a + 5;     // 先算右边 a+5，再赋给左边 → a 变为 15
```

- **赋值方向：右 → 左**
- 赋值表达式本身有值，等于赋给左操作数的值
- 因此可以**连续赋值**（右结合）：

```cpp
int u, v, w;
u = v = w = 100;
// 等价于：w = 100; v = w; u = v;
// 最终 u=v=w=100
```

#### 3.2 复合赋值运算符

| 运算符 | 等价于 | 示例 |
|--------|--------|------|
| `+=` | `a = a + b` | `a += 3;` → `a = a + 3;` |
| `-=` | `a = a - b` | `a -= 3;` |
| `*=` | `a = a * b` | `a *= 3;` |
| `/=` | `a = a / b` | `a /= 3;` |
| `%=` | `a = a % b` | `a %= 3;` |

**复合赋值的隐藏细节——右侧整体优先计算**：

```cpp
int r = 5;
r *= 2 + 3;   // 等价于 r = r * (2 + 3) = 5 * 5 = 25
// 不是 (r * 2) + 3 = 13！
```

因为复合赋值优先级**很低**，右侧的 `2 + 3` 会先算完再参与复合赋值。

**复合赋值 vs 普通写法**：

```cpp
a += b;       // 推荐：简洁
a = a + b;    // 等价，可读性也不差

// 注意：若左边是复杂左值，复合赋值只求值一次
// arr[f()] += 1;  中 f() 只调用一次
// arr[f()] = arr[f()] + 1;  中 f() 可能调用两次
```

#### 3.3 赋值不是相等判断

```cpp
if (a = 5) { ... }   // 把 5 赋给 a，条件值为 5（真），永远进入
if (a == 5) { ... }  // 判断 a 是否等于 5
```

这是 C/C++ 史上最经典的陷阱之一，第 6 课关系运算符会再次强调。

### 四、自增自减运算符（`++` / `--`）——考试重难点

| 运算符 | 名称 | 含义 | 口诀 |
|--------|------|------|------|
| `++a` | 前置自增 | 先 a=a+1，再用新值 | **先加后用** |
| `a++` | 后置自增 | 先用旧值，再 a=a+1 | **先用后加** |
| `--a` | 前置自减 | 先 a=a-1，再用新值 | **先减后用** |
| `a--` | 后置自减 | 先用旧值，再 a=a-1 | **先用后减** |

#### 4.1 基础对比

```cpp
int a = 5, b;
b = ++a;  // 先 a→6，再 b=6。结果：a=6, b=6

int x = 5, y;
y = x++;  // 先 y=5，再 x→6。结果：x=6, y=5
```

**单独成语句时，前置与后置效果相同**：

```cpp
a++;   // a 加 1
++a;   // a 加 1
// 两者最终 a 都加 1，没有区别
```

**差异只出现在「表达式中要使用该值」时**。

#### 4.2 输出中的自增

```cpp
int m = 10;
cout << m++;   // 输出 10，然后 m 变为 11
cout << ++m;   // 先 m 变为 12，再输出 12
```

#### 4.3 分析复杂表达式的标准方法

**方法：变量变化表 + 从左到右拆分**

例：`int x = 5, y = 10; int z = x++ + ++y;`

| 步骤 | 子表达式 | 使用值 | 变量变化 |
|------|----------|--------|----------|
| 初始 | — | — | x=5, y=10 |
| 1 | `x++` | 5 | x→6 |
| 2 | `++y` | 11 | y→11 |
| 3 | 相加 | z=5+11=16 | z=16 |

结果：`x=6, y=11, z=16`

#### 4.4 同一变量在表达式中多次修改（警告）

```cpp
int p = 3;
int q = ++p + p++;  // 未定义/未定序行为！
```

在标准 C++ 中，**同一标量对象在无序列点（或无测序）的情况下被修改两次**，属于未定义行为（C++11/14）或至少求值顺序未指定。不同编译器、不同优化级别结果可能不同。

**考试说明**：
- CSP-J 笔试**常考**此类题，通常按「从左到右、先算自增再参与运算」的简化规则给分
- **实际编程中必须避免**！应拆成多条语句：

```cpp
// 考试可能考，但工程上应这样写：
int p = 3;
++p;           // p = 4
int left = p;  // 4
int right = p; // 4
p++;           // p = 5
int q = left + right;  // 8
```

本课程序中也会用**分开的语句**演示效果，并加注释说明。

#### 4.5 自增自减与循环

```cpp
// for 循环中最常见
for (int i = 0; i < n; i++) { ... }  // 后置自增（习惯写法）
for (int i = 0; i < n; ++i) { ... }  // 前置自增（对 int 无实质差异）

// while 中读取
int x;
while (cin >> x, x != 0) { ... }  // 逗号运算符，第6课延伸
```

### 五、运算符优先级与结合性

#### 5.1 记忆口诀（从高到低）

> **括号 > 单目 > 乘除模 > 加减 > 移位 > 关系 > 相等 > 位运算 > 逻辑 > 三目 > 赋值 > 逗号**

更短版：

> **单目 > 算术 > 关系 > 逻辑 > 赋值**

#### 5.2 详细优先级表（本课相关 + 全局对照）

| 优先级 | 运算符 | 结合性 | 说明 |
|--------|--------|--------|------|
| 1（最高） | `()` `[]` `.` `->` | 左→右 | 括号、下标、成员 |
| 2 | `!` `~` `++` `--` `+`(正) `-`(负) `*` `&` `sizeof` | **右→左** | 单目 |
| 3 | `*` `/` `%` | 左→右 | 乘除取模 |
| 4 | `+` `-` | 左→右 | 加减 |
| 5 | `<<` `>>` | 左→右 | 移位（第6课） |
| 6 | `<` `<=` `>` `>=` | 左→右 | 关系 |
| 7 | `==` `!=` | 左→右 | 相等 |
| 8 | `&` | 左→右 | 按位与 |
| 9 | `^` | 左→右 | 按位异或 |
| 10 | `\|` | 左→右 | 按位或 |
| 11 | `&&` | 左→右 | 逻辑与 |
| 12 | `\|\|` | 左→右 | 逻辑或 |
| 13 | `?:` | **右→左** | 三目 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` 等 | **右→左** | 赋值 |
| 15（最低） | `,` | 左→右 | 逗号 |

#### 5.3 结合性

- **左结合**：同优先级从左往右算。`a - b + c` → `(a - b) + c`
- **右结合**：同优先级从右往左算。`a = b = c` → `a = (b = c)`；`a *= b += 1` → `a *= (b += 1)`

#### 5.4 实战分析

```cpp
// 例1：乘法优先于加法
int result = 3 + 5 * 2;       // 3 + 10 = 13
int result2 = (3 + 5) * 2;    // 8 * 2 = 16

// 例2：左结合
int r = 10 - 3 - 2;           // (10 - 3) - 2 = 5，不是 10 - (3-2)=9

// 例3：复合赋值右侧先算
int a = 10, b = 3;
a += b;                       // a = 13
a *= 2 + 3;                   // a = 13 * 5 = 65

// 例4：赋值右结合
int x = 10;
int y = x += x *= 2;
// 先 x *= 2 → x = 20
// 再 x += 20 → x = 40
// y = 40

// 例5：单目优先
int t = 5;
int u = -t + 3;               // (-t) + 3 = -2
```

#### 5.5 考试建议

1. **不确定就加括号**——既正确又清晰
2. 阅读程序时先找括号，再按优先级分层，最后处理结合性
3. 复合赋值 `*=` `+=` 等优先级低于加减乘除，右侧整块先算

### 六、类型转换与算术运算

混合类型运算时，会发生**隐式类型提升**：

```cpp
int a = 5;
double b = 2.0;
double c = a / b;     // a 提升为 double，c = 2.5

int x = 5, y = 2;
double z = x / y;     // 先整数除得 2，再赋给 double → 2.0
double w = 1.0 * x / y; // 2.5
```

**强制类型转换**：

```cpp
(double)a / b
static_cast<double>(a) / b   // C++ 风格，更推荐
```

**溢出**：

```cpp
int a = 100000, b = 100000;
int c = a * b;                    // 溢出！10^10 超出 int
long long d = (long long)a * b;   // 正确：1e10
long long e = a * 1LL * b;        // 也可以
```

### 七、表达式求值综合套路

面对一道「写出输出结果」的表达式题，按以下步骤：

1. **标出所有运算符**，查优先级表确定运算顺序
2. **括号优先**，从内到外
3. 遇到 `++`/`--`：画**变量变化表**，区分前置/后置
4. 遇到 `/` `%`：检查是否整数运算、符号规则
5. 遇到复合赋值：右侧**整体**先算
6. 逐步写出中间结果，最后汇总输出

## 💻 代码模板

### 模板1：算术运算与取模技巧

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 17, b = 5;
    cout << a + b << " " << a - b << " " << a * b << endl;
    cout << a / b << " " << a % b << endl;          // 3 2
    cout << (double)a / b << endl;                  // 3.4

    // 取各位数字
    int n = 12345;
    cout << "个位: " << n % 10 << endl;
    cout << "十位: " << n / 10 % 10 << endl;
    cout << "百位: " << n / 100 % 10 << endl;

    // 逐位分离求和
    int sum = 0, t = n;
    while (t > 0) {
        sum += t % 10;
        t /= 10;
    }
    cout << "数位和: " << sum << endl;              // 15

    // 奇偶与环形
    int h = 23;
    cout << "下一小时: " << (h + 1) % 24 << endl;  // 0

    return 0;
}
```

### 模板2：自增自减与优先级分析（安全写法）

```cpp
#include <iostream>
using namespace std;

int main() {
    // 前置 / 后置对比
    int a = 5, b;
    b = ++a;
    cout << "前置: a=" << a << " b=" << b << endl;  // 6 6

    a = 5;
    b = a++;
    cout << "后置: a=" << a << " b=" << b << endl;  // 6 5

    // 不同变量混合（定义良好）
    int x = 5, y = 10;
    int z = x++ + ++y;
    cout << "x=" << x << " y=" << y << " z=" << z << endl;
    // x=6 y=11 z=16

    // 复合赋值与优先级
    int r = 5;
    r *= 2 + 3;  // r = 5 * 5 = 25
    cout << "r=" << r << endl;

    // 同一变量多次修改：考试常考，实际应避免
    // 拆开写，行为清晰：
    int p = 3;
    int left = ++p;   // p=4, left=4
    int right = p++;  // right=4, p=5
    int q = left + right;
    cout << "p=" << p << " q=" << q << endl;  // 5 8

    return 0;
}
```

## ⚠️ 易错点

### 易错点1：整数除法截断

**错误认知**：`5 / 2` 以为是 `2.5`。

**事实**：两个 `int` 相除结果仍是 `int`，小数丢弃 → `2`。

**正确写法**：
```cpp
double ans = 5.0 / 2;
// 或
double ans = (double)5 / 2;
```

**反例**：
```cpp
double ans = (double)(5 / 2);  // 仍是 2.0
```

### 易错点2：取模用于浮点或除数为 0

```cpp
// double x = 5.0 % 2;  // 编译错误
// int y = 5 % 0;       // 运行错误
```

负数取模符号跟随被除数：`(-5) % 3 == -2`，判断奇数时不要只写 `n % 2 == 1`。

### 易错点3：前置 / 后置自增混淆

```cpp
int a = 5;
cout << a++;  // 输出 5，不是 6
cout << ++a;  // 若接上一步，a 已是 6，先变 7 再输出 7
```

分析时务必画表：**「用的是旧值还是新值」** 是唯一关键。

### 易错点4：同一表达式中对同一变量多次 `++/--`

```cpp
int i = 5;
int j = i++ + ++i;  // 未定义/未定序，不同编译器可能不同
```

- 考试可能按从左到右给标准答案
- 实际项目：**禁止这样写**，拆成多条语句

### 易错点5：复合赋值优先级被忽略

```cpp
a *= 2 + 3;   // a = a * 5，不是 a = a * 2 + 3
a = a * 2 + 3; // 与上一行不等价
```

### 易错点6：`=` 与 `==` 混淆

```cpp
if (a = 0) { ... }  // 赋值，条件为假，且 a 被改成 0
if (a == 0) { ... } // 判断
```

### 易错点7：乘法溢出

```cpp
int a = 100000, b = 100000;
long long c = a * b;              // 错：右边先按 int 乘已溢出
long long d = (long long)a * b;   // 对
```

### 易错点8：连续除法/取模的结合顺序

```cpp
n / 10 % 10   // (n/10) % 10，正确取十位
n / (10 % 10) // 10%10=0，除零！
```

## 📝 真题精练

### 真题1：表达式求值（复合赋值 + 整数除法）

**题目描述**：阅读以下程序，写出运行结果。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 10, b = 3;
    cout << a / b << endl;
    cout << a % b << endl;
    a += b;
    cout << a << endl;
    a *= 2 + 3;
    cout << a << endl;
    return 0;
}
```

**分析过程**：

| 语句 | 计算 | a 的值 | 输出 |
|------|------|--------|------|
| `a/b` | 10/3=3 | 10 | 3 |
| `a%b` | 10%3=1 | 10 | 1 |
| `a+=b` | a=10+3 | 13 | 13 |
| `a*=2+3` | a=13*(2+3)=65 | 65 | 65 |

**答案**：
```
3
1
13
65
```

**AC 代码（验证用）**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10, b = 3;
    cout << a / b << endl;    // 3
    cout << a % b << endl;    // 1
    a += b;                   // 13
    cout << a << endl;
    a *= 2 + 3;               // 65
    cout << a << endl;
    return 0;
}
```

**考点**：整数除法、取模、复合赋值、`*=` 右侧整体优先。

### 真题2：自增自减混合（不同变量）

**题目描述**：阅读以下程序，写出运行结果。

```cpp
#include <iostream>
using namespace std;
int main() {
    int x = 5, y = 10;
    int z = x++ + ++y;
    cout << "x=" << x << ", y=" << y << ", z=" << z << endl;
    return 0;
}
```

**分析过程**：

| 步骤 | 操作 | 使用值 | 变量 |
|------|------|--------|------|
| 初 | — | — | x=5, y=10 |
| 1 | `x++` | 5 | x→6 |
| 2 | `++y` | 11 | y→11 |
| 3 | z=5+11 | 16 | z=16 |

**答案**：`x=6, y=11, z=16`

**AC 代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 5, y = 10;
    int z = x++ + ++y;
    // x++: 用 5，x→6
    // ++y: y→11，用 11
    // z = 16
    cout << "x=" << x << ", y=" << y << ", z=" << z << endl;
    return 0;
}
```

**考点**：前置/后置自增、不同变量在同一表达式中（此写法定义良好）。

### 真题3（拓展）：优先级与连续赋值

**题目描述**：阅读程序，写出输出。

```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 2, b = 3, c = 4;
    int d = a + b * c;        // 2 + 12 = 14
    int e = (a + b) * c;      // 5 * 4 = 20
    a += b += c;              // 先 b=b+c=7，再 a=a+7=9
    cout << d << " " << e << " " << a << " " << b << endl;
    return 0;
}
```

**答案**：`14 20 9 7`

**解析**：
- `*` 优先于 `+`
- 赋值右结合：`a += b += c` → `a += (b += c)`

### 真题4（拓展）：数位分离编程题

**题目描述**：输入一个不超过 9 位的正整数 n，输出其各位数字之和，以及它的个位数字。

**输入**：一行一个正整数 n。  
**输出**：一行两个整数，分别为数位和与个位。

**样例输入**：
```
12345
```

**样例输出**：
```
15 5
```

**AC 代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int ones = n % 10;
    int sum = 0;
    int t = n;
    while (t > 0) {
        sum += t % 10;
        t /= 10;
    }
    cout << sum << " " << ones << endl;
    return 0;
}
```

**考点**：`%` 与 `/` 在数位处理中的经典应用。

## 🎯 本课小结

### 核心知识点回顾

| 知识点 | 要点 |
|--------|------|
| 算术运算 | `+ - * / %`；整数除法截断；`%` 仅用于整数 |
| 复合赋值 | `+= -= *= /= %=`；右侧整体先算 |
| 自增自减 | `++a` 先加后用，`a++` 先用后加 |
| 优先级 | 单目 > 算术 > 关系 > 逻辑 > 赋值 |
| 结合性 | 算术左结合，赋值右结合 |
| 安全原则 | 同一变量不在同一表达式多次修改；不确定就加括号 |

### 考试建议

1. **阅读程序题**：先画变量表，再逐步求值；重点盯 `/`、`%`、`++`、`+=`
2. **选择题**：常考 `5/2`、`a*=2+3`、`=` vs `==`
3. **编程题**：数位分离、奇偶判断、环形下标都是 `%` `/` 的直接应用
4. 写代码时：**宁可用多行清晰语句，也不写费解的自增堆叠**
