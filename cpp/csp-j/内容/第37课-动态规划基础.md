## 📖 知识精讲

### 一、什么是动态规划

动态规划（Dynamic Programming，简称DP）是信息学竞赛中最重要的算法思想之一。它由美国数学家Richard Bellman于20世纪50年代提出。DP的核心思想是：**将一个复杂问题分解为若干个重叠的子问题，通过保存子问题的解来避免重复计算，从而高效地求解原问题。**

简单来说，DP就是一种「带记忆的枚举」——我们依然需要枚举所有可能的状态，但通过存储中间结果，避免对同一个子问题反复求解。

**DP与递推的关系**：递推是DP的一种实现方式。递推关注的是「从已知推向未知」的计算顺序，而DP更强调「状态定义」和「最优子结构」的分析过程。可以说，DP是递推思想在优化问题中的系统化应用。

### 二、DP的四个核心概念

#### 2.1 状态定义

「状态」是DP中最关键的概念。状态是对问题当前局面的一种数学描述，通常用一个或一组变量来表示。状态定义的好坏直接决定了后续转移方程的复杂度。

例如，在数字三角形问题中，我们用 `dp[i][j]` 表示「从顶部走到位置 (i, j) 的最大和」，这里的 `(i, j)` 就是一个状态。

**状态定义的原则**：
- 状态必须能够唯一描述一个子问题
- 状态空间不宜过大（通常根据数据范围来确定）
- 状态应该便于写出转移方程

```cpp
// 状态定义示例：dp[i] 表示以第i个元素结尾的某种最优值
int dp[MAXN];  // 一维状态，常见于线性DP

// dp[i][j] 表示考虑前i个物品、容量为j时的最优值
int dp[MAXN][MAXM];  // 二维状态，常见于背包DP
```

#### 2.2 状态转移方程

状态转移方程描述了如何从已知状态推导出未知状态。这是DP解题的核心步骤。转移方程的通常形式为：

```
dp[当前状态] = 最优值( dp[前一状态1] + 代价1, dp[前一状态2] + 代价2, ... )
```

**推导转移方程的思考步骤**：
1. 思考当前状态可以由哪些「前驱」状态到达
2. 计算从每个前驱状态转移到当前状态的代价
3. 取所有可能转移中的最优值

以数字三角形为例，走到 `(i, j)` 只能从 `(i-1, j-1)` 或 `(i-1, j)` 过来：

```
dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j]
```

#### 2.3 最优子结构

最优子结构是指：**原问题的最优解包含了其子问题的最优解。** 这意味着我们可以通过组合子问题的最优解来构造原问题的最优解。

换句话说，如果我们已经求得了所有子问题的最优解，那么我们就可以利用这些最优解来求得更大规模问题的最优解。不是所有问题都具有最优子结构性质——例如，最长简单路径问题（不带权值）就不满足最优子结构。

**判断最优子结构的方法**：问自己「当前状态的最优解，是否一定由子状态的最优解构成？」如果答案是「是」，则问题具有最优子结构。

#### 2.4 无后效性

无后效性是指：**一旦某个状态的值被确定，它就不受后续决策的影响。** 或者说，状态的转移只依赖于当前状态本身，而与该状态是如何到达的（历史路径）无关。

这是DP能够正确工作的基石。如果一个问题具有「后效性」——即未来的决策依赖于过去的具体路径而非仅仅当前状态——那么通常不能直接用DP求解，需要在状态中额外记录历史信息（增加维度）来消除后效性。

### 三、DP的两种实现方式

#### 3.1 记忆化搜索（自顶向下 / Top-Down）

记忆化搜索从原问题出发，递归地将问题分解为子问题。对于每个遇到的子问题，先检查是否已经求解过：如果求解过就直接返回缓存的结果，否则计算并存入缓存。

```cpp
int memo[MAXN][MAXN];
bool vis[MAXN][MAXN];  // 标记是否已经计算过

int dfs(int i, int j) {
    if (i == 1 && j == 1) return a[1][1];       // 边界
    if (i < 1 || j < 1 || j > i) return -INF;   // 非法状态
    if (vis[i][j]) return memo[i][j];            // 已经计算过
    vis[i][j] = true;
    return memo[i][j] = max(dfs(i-1, j-1), dfs(i-1, j)) + a[i][j];
}
```

**优点**：思维直观，贴近问题的自然分解方式；只计算实际需要的状态。
**缺点**：递归有额外开销，递归深度过大可能栈溢出；需要额外空间标记访问状态。

#### 3.2 递推DP（自底向上 / Bottom-Up）

递推DP从最小的子问题开始，按照一定的顺序逐步计算更大规模的问题，直到求解原问题。通常使用循环而非递归。

```cpp
// 初始化边界
dp[1][1] = a[1][1];
// 按行递推
for (int i = 2; i <= n; i++) {
    for (int j = 1; j <= i; j++) {
        dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j];
    }
}
```

**优点**：效率高，无递归开销；代码通常更简洁；适合大规模数据。
**缺点**：需要仔细设计递推顺序，确保计算每个状态时其前驱状态已经计算完毕。

**两种方式的选择**：在CSP-J考试中，推荐优先使用递推DP（自底向上），因为它常数小、不易栈溢出。但如果状态转移顺序难以用循环表达（如某些区间DP图DP），可以选用记忆化搜索。

### 四、经典问题：数字三角形

**问题描述**：给定一个n行的数字三角形，从顶部出发，每次可以向左下或右下走一步，到达底部。求路径上所有数字之和的最大值。

```
     7
    3 8
   8 1 0
  2 7 4 4
 4 5 2 6 5
```

**分析过程**：

1. **状态定义**：`dp[i][j]` 表示从顶部走到第i行第j列的最大和
2. **转移方程**：`dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + a[i][j]`
3. **边界条件**：`dp[1][1] = a[1][1]`
4. **答案**：`max(dp[n][1], dp[n][2], ..., dp[n][n])`

**从底向上递推的优化写法**（更简洁）：

```cpp
// dp[i][j] 表示从(i,j)出发到达底部的最大和
for (int j = 1; j <= n; j++)
    dp[n][j] = a[n][j];
for (int i = n - 1; i >= 1; i--)
    for (int j = 1; j <= i; j++)
        dp[i][j] = max(dp[i+1][j], dp[i+1][j+1]) + a[i][j];
// 答案即为 dp[1][1]
```

从底向上写法的优势：最终答案直接是 `dp[1][1]`，不需要再遍历最后一行取最大值。

### 五、路径计数问题

**问题描述**：一个 m * n 的网格，从左上角出发，每次只能向右或向下移动一格，到达右下角。求总共有多少条不同的路径。

**分析**：

1. **状态定义**：`dp[i][j]` 表示从起点 (1,1) 到达 (i,j) 的路径总数
2. **转移方程**：到达 (i,j) 只能从上方 (i-1,j) 或左方 (i,j-1) 过来，因此 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`
3. **边界条件**：第一行和第一列只有一种走法，即 `dp[1][j] = 1`，`dp[i][1] = 1`
4. **答案**：`dp[m][n]`

```cpp
// 初始化
for (int j = 1; j <= n; j++) dp[1][j] = 1;
for (int i = 1; i <= m; i++) dp[i][1] = 1;
// 递推
for (int i = 2; i <= m; i++)
    for (int j = 2; j <= n; j++)
        dp[i][j] = dp[i-1][j] + dp[i][j-1];
```

**带障碍物的网格路径**：如果某些格子是障碍物（不可通行），则有：
```cpp
if (grid[i][j] == 障碍物)
    dp[i][j] = 0;  // 无法到达
else
    dp[i][j] = dp[i-1][j] + dp[i][j-1];
```

### 六、DP解题通用步骤（重点记忆）

在考场上遇到DP问题时，按以下「DP六步法」解题：

1. **判断问题类型**：确认问题是否具有最优子结构和无后效性
2. **定义状态**：用数学语言描述每个子问题的状态，确定dp数组的含义和维度
3. **推导转移方程**：分析当前状态可以由哪些前驱状态转移而来
4. **确定边界条件**：初始化最小的子问题（dp数组的初始值）
5. **确定计算顺序**：确保在计算每个状态时，其依赖的前驱状态已经求出
6. **确定答案位置**：明确最终答案在dp数组中的位置

掌握这六步，就能系统地解决绝大多数CSP-J级别的DP问题。

```cpp
const int MAXN = 1005;
int a[MAXN][MAXN];
```

### 模板2：路径计数

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
const int MOD = 1e9 + 7;
long long dp[MAXN][MAXN];

int main() {
    int m, n;
    cin >> m >> n;
    
    // 初始化第一行和第一列
    for (int j = 1; j <= n; j++) dp[1][j] = 1;
    for (int i = 1; i <= m; i++) dp[i][1] = 1;
    
    // 递推
    for (int i = 2; i <= m; i++)
        for (int j = 2; j <= n; j++)
            dp[i][j] = (dp[i-1][j] + dp[i][j-1]) % MOD;
    
    cout << dp[m][n] << endl;
    return 0;
}
```

### 模板3：记忆化搜索框架

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
int a[MAXN][MAXN], memo[MAXN][MAXN];
bool vis[MAXN][MAXN];
int n;

int dfs(int i, int j) {
    if (i == n) return a[i][j];             // 到达底部
    if (j < 1 || j > i) return -1e9;        // 非法位置
    if (vis[i][j]) return memo[i][j];       // 已计算
    vis[i][j] = true;
    return memo[i][j] = max(dfs(i+1, j), dfs(i+1, j+1)) + a[i][j];
}

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= i; j++)
            cin >> a[i][j];
    cout << dfs(1, 1) << endl;
    return 0;
}
```

## ⚠️ 易错点

- **错误1：递推顺序错误**。必须保证在计算dp[i][j]时，它所依赖的状态（如dp[i-1][j-1]和dp[i-1][j]）已经被计算过了。如果递推顺序不对，会使用未初始化或错误的值。避免方法：先在草稿纸上画出依赖关系图，确定正确的循环顺序。
- **错误2：数组下标越界**。在DP中频繁涉及`i-1`或`j-1`等操作，必须确保循环从正确的起始位置开始。例如数字三角形中，第i行只有i个有效元素，访问`dp[i][0]`或`dp[i][i+1]`会导致越界。避免方法：将dp数组统一从下标1开始使用，并在循环中注意边界检查。
- **错误3：混淆「最优子结构」与「贪心选择」**。DP需要枚举所有可能的前驱状态取最优，而贪心只需要做一个局部最优选择。不要用贪心思维来做DP题——例如在数字三角形中，如果每步都走当前可以走到的最大值，不一定得到全局最优。避免方法：严格验证转移方程是否考虑了所有可能的转移来源。
- **错误4：未考虑答案取模**。路径计数类问题中，答案可能非常大，题目通常要求对某个数取模（如1e9+7）。忘记取模会导致整数溢出。避免方法：在每次加法后立即取模。

### 真题2：过河卒路径计数

**【题目描述】**

棋盘上A点有一个过河卒，需要走到目标B点。卒行走的规则：可以向下、或者向右。同时在棋盘上C点有对方的马，该马所在的点和所有跳跃一步可达的点称为对方马的控制点（卒不能走到这些点上）。棋盘用坐标表示，A点(0,0)、B点(n,m)，同样马的位置坐标是需要给出的。现在要求你计算出卒从A点能够到达B点的路径的条数。

**数据范围**：1 <= n, m <= 20

**【输入格式】**
- 一行四个正整数，分别表示B点坐标(n,m)和马的位置坐标(x,y)

**【输出格式】**
- 一个整数，表示所有的路径条数

**【输入样例】**
```
6 6 3 3
```

**【输出样例】**
```
6
```

**【AC代码】**
```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 25;
long long dp[MAXN][MAXN];
bool block[MAXN][MAXN];

// 马的控制点偏移量
int dx[] = {-2, -1, 1, 2, 2, 1, -1, -2, 0};
int dy[] = {1, 2, 2, 1, -1, -2, -2, -1, 0};

int main() {
    int n, m, x, y;
    cin >> n >> m >> x >> y;
    
    // 标记马的控制点
    for (int k = 0; k < 9; k++) {
        int nx = x + dx[k];
        int ny = y + dy[k];
        if (nx >= 0 && nx <= n && ny >= 0 && ny <= m)
            block[nx][ny] = true;
    }
    
    // dp初始化
    dp[0][0] = block[0][0] ? 0 : 1;
    
    for (int i = 0; i <= n; i++) {
        for (int j = 0; j <= m; j++) {
            if (block[i][j]) {
                dp[i][j] = 0;
                continue;
            }
            if (i == 0 && j == 0) continue;
            if (i > 0) dp[i][j] += dp[i-1][j];
            if (j > 0) dp[i][j] += dp[i][j-1];
        }
    }
    
    cout << dp[n][m] << '\n';
    return 0;
}
```

爬 n 阶楼梯，每次可爬 1 或 2 阶，求有多少种不同走法。n ≤ 40，答案用 `long long`。

**【输入】** 一个整数 n  

**【输出】** 方案数  

**【样例】** 输入 `5`，输出 `8`

**【AC 代码】**

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    // 状态 f[i]：爬到 i 阶的方案数
    // 转移 f[i] = f[i-1] + f[i-2]
    // 边界 f[0]=1, f[1]=1
    // 顺序：从小到大
    vector<long long> f(n + 1);
    f[0] = 1;
    if (n >= 1) f[1] = 1;
    for (int i = 2; i <= n; i++) f[i] = f[i - 1] + f[i - 2];
    cout << f[n] << '\n';
    return 0;
}
```

### 七、为什么需要 DP？暴力递归 vs 记忆化

以斐波那契为例：`fib(n)=fib(n-1)+fib(n-2)` 暴力递归会重复计算同一子问题，调用次数近似指数级；记忆化后每个 n 只算一次，降为 O(n)。

```cpp
// 暴力（仅作对比，n 稍大即慢）
long long fibRaw(int n) {
    if (n <= 1) return n;
    return fibRaw(n - 1) + fibRaw(n - 2);
}

// 记忆化
long long fibMemo(int n, vector<long long> &mem) {
    if (n <= 1) return n;
    if (mem[n] != -1) return mem[n];
    return mem[n] = fibMemo(n - 1, mem) + fibMemo(n - 2, mem);
}
```

**结论**：重叠子问题 + 最优（或可合并）子结构 → 适合 DP/记忆化。

### 八、滚动数组思想（空间优化入门）

网格路径 `dp[i][j] = dp[i-1][j] + dp[i][j-1]` 只依赖上一行和左边，可压成一维：

```cpp
// 求 m 行 n 列路径数，空间 O(n)
vector<long long> dp(n + 1, 1);  // 第 1 行
dp[0] = 0;
for (int i = 2; i <= m; i++) {
    for (int j = 1; j <= n; j++) {
        if (j == 1) dp[j] = 1;
        else dp[j] = dp[j] + dp[j - 1]; // 旧 dp[j] 是上一行，dp[j-1] 是本行左侧
    }
}
```

这与后续 **01 背包一维倒序** 是同一类空间优化思想，本课先建立印象。

### 九、数字三角形两种方向对照

| 方向 | 状态含义 | 答案位置 | 优点 |
|------|----------|----------|------|
| 自上而下 | 到 (i,j) 的最大和 | 最后一行取 max | 符合“走过来”的直觉 |
| 自下而上 | 从 (i,j) 到底的最大和 | dp[1][1] | 答案位置固定，代码短 |

两种都必须保证：**算当前格时，依赖的邻格已算完**。

### 十、带障碍路径的统一写法

```cpp
if (block[i][j]) dp[i][j] = 0;
else {
    long long fromUp = i ? dp[i-1][j] : 0;
    long long fromLeft = j ? dp[i][j-1] : 0;
    dp[i][j] = fromUp + fromLeft;
}
// 起点：若不在障碍上，dp[0][0]=1
```

马的控制点、障碍格、禁行格都可映射为 `block`。

### 十一、DP 与贪心、递推的对比

| | 递推 | 贪心 | DP |
|--|------|------|-----|
| 是否最优 | 算定义的值 | 局部选 | 全局最优（满足条件时） |
| 是否枚举决策 | 固定公式 | 一种选择 | 枚举前驱取优 |
| 典型题 | 斐波那契 | 活动选择 | 数字三角形 |

### 十二、调试 DP 的实用技巧

1. 先用极小 n 手算填表，对照程序打印的 `dp` 表。  
2. 检查边界行/列是否初始化。  
3. 下标是否从 0/1 混用。  
4. 求 max 时 `dp` 初值是否该为负无穷；求 min 是否为正无穷。  
5. 路径计数是否取模、是否用 `long long`。

## 🎯 本课小结

- **DP的本质**：通过将复杂问题分解为重叠子问题，并缓存子问题结果来避免重复计算
- **四大核心概念**：状态定义、状态转移方程、最优子结构、无后效性——缺一不可
- **两种实现方式**：记忆化搜索（自顶向下，递归+缓存）和递推DP（自底向上，循环+数组），优先掌握递推DP
- **DP六步法**：判断类型 -> 定义状态 -> 推导转移 -> 确定边界 -> 确定顺序 -> 定位答案
- **经典问题**：数字三角形（从底向上递推）、路径计数（第一行/列初始化）、爬楼梯方案数，是后续学习线性DP和背包DP的基础
- **考试要点**：注意递推顺序、数组越界、取模运算；多画状态转移图帮助理解
- **空间优化萌芽**：滚动数组把二维路径压成一维，为背包一维化做铺垫
