## 📖 知识精讲

上一节课我们学习了冒泡排序和选择排序，它们都是比较简单的 O(n²) 排序算法。本节课我们学习同样经典的插入排序，以及一种基于统计而非比较的排序方法——计数排序。

### 一、插入排序原理

插入排序的核心思想非常贴近生活：**像打扑克牌时整理手牌一样，将每一张新摸到的牌插入到手中已有牌的正确位置**。

具体来说，插入排序将数组分成两个区域：
- **有序区**（数组前部）：已经排好序的部分
- **无序区**（数组后部）：尚未处理的部分

每一轮从无序区取出第一个元素（称为"当前元素" `key`），在有序区中**从后往前**扫描，找到合适的位置插入。由于有序区是升序的，从后往前扫描时，只要遇到比 `key` 大的元素就将它后移一位，直到找到第一个不大于 `key` 的位置，将 `key` 放入。

**算法步骤**：
1. 初始时，第一个元素 `a[0]` 视为有序区
2. 从 i=1 开始，将 `a[i]` 作为 `key`，在有序区 `[0, i-1]` 中从后往前查找插入位置
3. 将有序区中所有比 `key` 大的元素向后移动一位（腾出空间）
4. 将 `key` 放入正确位置
5. 有序区扩大一位，重复直到所有元素处理完毕

**插入排序完整实现**：

```cpp
#include <iostream>
using namespace std;

void insertionSort(int a[], int n) {
    // 外层循环：i 从 1 开始，每次将 a[i] 插入到前面有序区中
    for (int i = 1; i < n; i++) {
        int key = a[i];               // 当前待插入的元素（摸到的新牌）
        int j = i - 1;                // 从有序区的最后一个位置开始比较
        
        // 内层循环：在有序区中从后往前找插入位置
        // 如果有序区的元素比 key 大，就将其向后移动一位
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];          // 元素后移，腾出位置
            j--;                       // 继续向前比较
        }
        // 找到了合适的位置 j+1，将 key 插入
        a[j + 1] = key;
    }
}

int main() {
    int a[] = {8, 3, 5, 1, 9, 2, 7, 6, 4};
    int n = 9;
    
    cout << "排序前：";
    for (int i = 0; i < n; i++) cout << a[i] << " ";
    cout << endl;
    
    insertionSort(a, n);
    
    cout << "排序后：";
    for (int i = 0; i < n; i++) cout << a[i] << " ";
    cout << endl;
    // 输出：排序后：1 2 3 4 5 6 7 8 9
    return 0;
}
```

**过程模拟**：以数组 `{5, 2, 4, 6, 1, 3}` 为例，逐步分析插入排序：

- **初始**：有序区 = `{5}`，无序区 = `{2, 4, 6, 1, 3}`
- **i=1**（key=2）：有序区从后往前比较，5 > 2，5 后移 → `{5, 5, 4, 6, 1, 3}`，key=2 放入 → `{2, 5, 4, 6, 1, 3}`
- **i=2**（key=4）：5 > 4 后移，2 < 4 停止 → `{2, 4, 5, 6, 1, 3}`
- **i=3**（key=6）：5 < 6，不移动 → 保持 `{2, 4, 5, 6, 1, 3}`
- **i=4**（key=1）：6>1, 5>1, 4>1, 2>1 全部后移 → `{1, 2, 4, 5, 6, 3}`
- **i=5**（key=3）：6>3, 5>3, 4>3 后移，2<3 停止 → `{1, 2, 3, 4, 5, 6}`

**时间复杂度分析**：
- **最坏情况**（完全逆序）：每个 key 都需要比较并移动有序区的所有元素，第 i 个元素需要比较 i 次，总共 1+2+...+(n-1) = n(n-1)/2，即 **O(n²)**
- **最好情况**（已经有序）：每个 key 只需要与有序区最后一个元素比较一次即可确定位置，内层循环的 while 条件 `a[j] > key` 第一次就不满足，总共只需 n-1 次比较，即 **O(n)**
- **平均情况**：O(n²)

插入排序优异之处在于：**数据越接近有序，效率越高**。当数据基本有序时（比如只有少数几个元素位置不对），插入排序几乎接近 O(n)。这也是为什么在实际工程中，快速排序等高级算法在子问题规模较小时（如 n<16）常切换到插入排序。

### 二、插入排序的稳定性与特点

**插入排序是稳定的**。因为在比较时使用 `a[j] > key`（严格大于），只有当有序区元素**大于**key 时才后移。如果遇到相等的元素，key 会放在它的后面，所以相同元素的相对顺序不会改变。

插入排序的另一个优点是**原地排序**，空间复杂度 O(1)，不需要额外数组。

与冒泡和选择排序对比：
- 冒泡排序也是稳定的，但即使优化后，它的实际执行效率通常低于插入排序（冒泡需要多次交换，插入只需元素后移和一次赋值）
- 选择排序是不稳定的，且无论如何都需要 n(n-1)/2 次比较，效率最差
- **插入排序在实际使用中最受欢迎**（在 O(n²) 算法中）

### 三、计数排序原理

前面学的三种排序（冒泡、选择、插入）都是**基于比较的排序**，它们通过比较元素之间的大小关系来决定顺序。基于比较的排序有一个理论下界：**最优时间复杂度为 O(n log n)**。也就是说，任何纯比较排序不可能比 O(n log n) 更快。

但是，如果我们知道数据的范围有限（比如都是 0 到 100 之间的整数），就可以使用**计数排序**——一种不靠比较、而是靠统计出现频率来排序的算法。计数排序的时间复杂度可达 **O(n + max)**，在某些场景下远优于 O(n log n)。

**计数排序核心思想**：
1. 统计每个数值在数组中出现了多少次（频率统计）
2. 根据频率，按顺序"还原"出排序后的数组

**算法步骤（升序排序）**：
1. 找出待排序数组中的最大值 `maxVal` 和最小值 `minVal`（可选，用于处理负数或偏移）
2. 创建一个计数数组 `cnt`，大小为 `maxVal + 1`（如果带偏移则为 `maxVal - minVal + 1`），初始全为 0
3. 遍历原数组，对每个元素 `x`，执行 `cnt[x]++`（带偏移时：`cnt[x - minVal]++`）
4. 遍历计数数组，对于每个值 `i`，重复输出 `cnt[i]` 次 `i + minVal`

**计数排序完整实现（非负数版本）**：

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 100000;    // 原数组最大长度
const int MAXV = 1000;      // 数值的最大可能值

void countingSort(int a[], int n) {
    // 第一步：找到最大值，确定计数数组大小
    int maxVal = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] > maxVal) maxVal = a[i];
    }
    
    // 第二步：创建计数数组并统计频率
    int* cnt = new int[maxVal + 1]();  // () 初始化为 0
    for (int i = 0; i < n; i++) {
        cnt[a[i]]++;
    }
    
    // 第三步：按计数数组还原排序结果
    int idx = 0;                        // 写回原数组的位置
    for (int i = 0; i <= maxVal; i++) {
        while (cnt[i] > 0) {           // 对于数值 i，输出 cnt[i] 次
            a[idx++] = i;
            cnt[i]--;
        }
    }
    
    delete[] cnt;                       // 释放动态数组
}

int main() {
    int a[] = {5, 3, 8, 3, 1, 9, 2, 5, 7, 3};
    int n = 10;
    
    countingSort(a, n);
    
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    cout << endl;
    // 输出：1 2 3 3 3 5 5 7 8 9
    return 0;
}
```

**带偏移的计数排序（支持负数或数据范围偏移）**：

```cpp
#include <iostream>
using namespace std;

// 支持任意整数范围的计数排序
void countingSortWithOffset(int a[], int n) {
    // 找最大值和最小值，确定偏移量
    int minVal = a[0], maxVal = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < minVal) minVal = a[i];
        if (a[i] > maxVal) maxVal = a[i];
    }
    
    int range = maxVal - minVal + 1;    // 数据范围大小
    int offset = minVal;                // 偏移量：将 minVal 映射到下标 0
    
    // 创建计数数组
    int* cnt = new int[range]();
    for (int i = 0; i < n; i++) {
        cnt[a[i] - offset]++;           // 减去偏移量
    }
    
    // 还原
    int idx = 0;
    for (int i = 0; i < range; i++) {
        while (cnt[i] > 0) {
            a[idx++] = i + offset;      // 加回偏移量
            cnt[i]--;
        }
    }
    
    delete[] cnt;
}

int main() {
    int a[] = {-3, 5, -1, 2, -3, 0, 4, -2};
    int n = 8;
    
    countingSortWithOffset(a, n);
    
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    cout << endl;
    // 输出：-3 -3 -2 -1 0 2 4 5
    return 0;
}
```

**计数排序的稳定性**：上面这种直接根据频率还原的写法，由于只保留了频率而丢失了原始顺序，是不稳定的。如果要实现稳定的计数排序，需要额外一个与原数组等长的输出数组，并利用**前缀和**确定每个元素的最终位置——这就是"桶排序/基数排序"的思想，感兴趣的同学可以自行拓展。

**时间复杂度**：O(n + maxVal) 或 O(n + range)。当数据范围范围不大时（比如 n=10^6, range=1000），计数排序非常快。但当 range 很大（比如数据在 0 到 10^9 之间），计数数组会巨大无比，不可行。

### 四、各排序算法适用场景对比

理解和记住下面的对比表，是 CSP-J 中"选择合适排序算法"类题目的关键：

| 排序算法 | 时间复杂度（最好） | 时间复杂度（平均/最坏） | 空间复杂度 | 稳定性 | 适用场景 |
|---------|-------------------|------------------------|-----------|--------|---------|
| 冒泡排序 | O(n²) / O(n)(优化) | O(n²) | O(1) | 稳定 | 教学演示，极少实际使用 |
| 选择排序 | O(n²) | O(n²) | O(1) | 不稳定 | 交换次数少时可考虑 |
| 插入排序 | O(n) | O(n²) | O(1) | 稳定 | 数据量小或基本有序时高效 |
| 计数排序 | O(n+range) | O(n+range) | O(range) | 取决于实现 | 数据范围小的整数 |

**选择建议**：
- 数据量 ≤ 1000，不关心是否稳定：三种 O(n²) 排序任选，插入排序通常最快
- 数据基本有序（如只有少量元素乱序）：优先选择插入排序，可接近 O(n)
- 数据范围较小（如 0~1000 的整数），且数据量很大：计数排序是最佳选择
- 需要稳定性：不能选选择排序，冒泡和插入都可以（注意条件判断用 `>` 而非 `>=`）

**一个重要提醒**：在 CSP-J 复赛中，没有特殊要求时直接使用 `sort()` 即可（O(n log n) 且稳定版本用 `stable_sort`）。但在初赛的选择题和判断题中，必须熟悉这些基础排序算法的各种特性。

## 💻 代码模板

**模板一：标准插入排序**

```cpp
// 功能：对数组 a[0..n-1] 进行升序插入排序
// 特点：稳定排序，数据基本有序时效率极高（接近 O(n)）
void insertionSort(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {  // 用 > 保证稳定性
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
    }
}
```

**模板二：计数排序（非负整数版）**

```cpp
#include <cstring>

// 功能：对数组 a[0..n-1] 进行升序计数排序
// 前提：数组元素均为非负整数，最大值不超过 MAXV
// 时间复杂度：O(n + maxVal)
const int MAXV = 10000;

void countingSort(int a[], int n) {
    int cnt[MAXV + 1] = {0};
    for (int i = 0; i < n; i++) cnt[a[i]]++;
    int idx = 0;
    for (int i = 0; i <= MAXV; i++) {
        for (int k = 0; k < cnt[i]; k++) {
            a[idx++] = i;
        }
    }
}
```

**模板三：插入排序模拟过程输出**

```cpp
// 功能：插入排序并输出每轮结果，帮助理解排序过程
void insertionSortWithTrace(int a[], int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
        }
        a[j + 1] = key;
        
        cout << "第 " << i << " 轮后：";
        for (int k = 0; k < n; k++) cout << a[k] << " ";
        cout << endl;
    }
}
```

## ⚠️ 易错点

- **插入排序 while 循环条件中的 `j >= 0` 不能省略**：写 `while (a[j] > key && j >= 0)` 是错误的！C++ 中逻辑与 `&&` 从左往右求值，如果先判断 `a[j] > key`，当 `j = -1` 时 `a[-1]` 是数组越界访问，会导致未定义行为。必须将 `j >= 0` 写在前面，利用短路求值保护。

- **插入排序比较符号影响稳定性**：`while (j >= 0 && a[j] > key)` 中的 `>` 不能写成 `>=`。如果写成 `>=`，相等元素也会被移动，导致 key 被放到相等元素前面，破坏了稳定性。这也是 CSP-J 选择题中的常考点。

- **计数排序不能处理负数（不带偏移时）**：标准计数排序的计数数组下标从 0 开始，如果数组中有负数（如 `-5`），`cnt[-5]` 是非法的。必须使用带偏移量的版本，将最小值映射到下标 0。

- **计数排序的空间陷阱**：如果数据范围很大（比如最大值是 10^9），即使是稀疏数据，计数数组也需要开 10^9+1 的大小，这早已超出内存限制。计数排序只适用于**数据范围远小于数据规模**的场景，比如 n=10^5 但数值都在 0~1000 之间。

## 📝 真题精练

### 真题一：排序算法选择判断题

**题目描述**：有 100000 个整数，它们的值都在 0 到 1000 之间。请从冒泡排序、选择排序、插入排序和计数排序中选择最合适的排序算法对它们进行升序排序，并简述理由。用代码实现你选择的算法，并输出排序前三个和最后三个元素。

**输入格式**：
- 第一行一个整数 n（1 ≤ n ≤ 100000）
- 第二行 n 个整数，每个数范围 [0, 1000]

**输出格式**：
- 第一行：排序后的序列（用空格分隔）

**样例输入**：
```
8
5 3 8 3 1 9 2 5
```

**样例输出**：
```
1 2 3 3 5 5 8 9
```

**完整 AC 代码**：

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int MAXN = 100005;
const int MAXV = 1000;

int a[MAXN];
int cnt[MAXV + 1];

int main() {
    int n;
    cin >> n;
    
    int maxVal = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    // 选择计数排序：数据范围 0~1000 远小于数据量 100000
    // 时间复杂度 O(n + 1000) ≈ O(n)，远优于 O(n²) 的冒泡/选择/插入
    
    // 清零计数数组
    memset(cnt, 0, sizeof(cnt));
    
    // 统计频率
    for (int i = 0; i < n; i++) {
        cnt[a[i]]++;
    }
    
    // 输出排序结果
    int idx = 0;
    for (int i = 0; i <= MAXV; i++) {
        while (cnt[i] > 0) {
            a[idx++] = i;
            cnt[i]--;
        }
    }
    
    for (int i = 0; i < n; i++) {
        cout << a[i] << (i < n - 1 ? " " : "\n");
    }
    
    return 0;
}
```

**考点分析**：本题考察根据数据特征选择合适的排序算法。当 n=10^5 时，冒泡/选择/插入的 O(n²) 已经不可行（10^10 次操作远超出 1 秒限制）；而数据范围只有 0~1000，计数排序的 O(n+1000) 非常合适。CSP-J 中经常出现这种"根据场景选算法"的题目。

### 真题二：插入排序应用题

**题目描述**：给定一个长度为 n 的序列，已知这个序列是"基本有序的"——最多只有 5 个元素的位置不正确。请使用插入排序对该序列排序，并统计排序过程中内层循环（while 循环）总共执行了多少次比较（即 `a[j] > key` 判断的总执行次数）。

**输入格式**：
- 第一行一个整数 n（1 ≤ n ≤ 1000）
- 第二行 n 个整数

**输出格式**：
- 第一行：排序后的序列
- 第二行：比较次数

**样例输入**：
```
6
1 2 5 3 4 6
```

**样例输出**：
```
1 2 3 4 5 6
5
```

**完整 AC 代码**：

```cpp
#include <iostream>
using namespace std;

int a[1005];
int compareCount = 0;    // 全局变量统计比较次数

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    // 插入排序（带比较次数统计）
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        
        // 每次 while 条件判断都算一次比较
        while (j >= 0 && a[j] > key) {
            compareCount++;             // 条件成立，确实比较了
            a[j + 1] = a[j];
            j--;
        }
        // while 条件最后一次判断（条件不成立退出），也算一次比较
        if (j >= 0) compareCount++;
        
        a[j + 1] = key;
    }
    
    // 输出排序结果
    for (int i = 0; i < n; i++) {
        cout << a[i] << (i < n - 1 ? " " : "\n");
    }
    cout << compareCount << endl;
    
    return 0;
}
```

**考点分析**：本题考察插入排序在"基本有序"数据上的表现，以及比较次数的统计。插入排序在数据基本有序时 while 循环几乎不执行（或执行很少次），比较次数接近 O(n)。题目要求精确统计比较次数，需要仔细处理 while 循环的最初一次判断和最终一次判断。这也提醒了插入排序最好情况 O(n) 的含义：数据有序时，每个 key 只需比较一次即可确定位置。

## 🎯 本课小结
- 插入排序像整理扑克牌，将无序区的元素逐个插入到有序区的正确位置。数据越接近有序，插入排序越快——最好情况 O(n)，这是冒泡和选择排序所不具备的特性。
- 计数排序突破了比较排序的 O(n log n) 下界，通过统计频率实现 O(n+range) 的线性时间排序，但要求数据范围远小于数据量——记住"范围太大不能用，有负数要加偏移"。
- 不同排序算法各有适用场景：插入排序适合小数据或基本有序；计数排序适合小范围大数据量；选择排序适合交换代价高的场景（但很少用到）。
- 稳定性判断要点：插入排序用 `>` 判断时是稳定的；计数排序的简单还原版不稳定（因丢失原始顺序）。考试中稳定性判断题往往就是考察比较符号和算法本质。
