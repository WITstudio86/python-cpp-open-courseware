### 一、游戏模拟：剪刀石头布

游戏模拟是模拟算法中的常见题型。此类题目会描述一个游戏的完整规则，包括胜负判定、计分方式等，要求我们模拟游戏过程并输出最终结果。

以"剪刀石头布"为例，这是一个经典的游戏模拟题。规则很简单：剪刀赢布，石头赢剪刀，布赢石头。两名玩家分别按照各自固定的出拳序列反复出拳，模拟N轮后输出比分。

```cpp
// 剪刀石头布模拟
// 0-剪刀, 1-石头, 2-布
#include <iostream>
using namespace std;

int main() {
    int N, NA, NB;
    cin >> N >> NA >> NB;
    
    int a[105], b[105];
    for (int i = 0; i < NA; i++) cin >> a[i];
    for (int i = 0; i < NB; i++) cin >> b[i];
    
    int scoreA = 0, scoreB = 0;
    
    for (int round = 0; round < N; round++) {
        int moveA = a[round % NA];  // A按照周期NA重复出拳
        int moveB = b[round % NB];  // B按照周期NB重复出拳
        
        if (moveA == moveB) {
            // 平局，不扣分也不加分
            continue;
        }
        
        // 判断A是否获胜
        if ((moveA == 0 && moveB == 2) ||   // 剪刀赢布
            (moveA == 1 && moveB == 0) ||   // 石头赢剪刀
            (moveA == 2 && moveB == 1)) {   // 布赢石头
            scoreA++;
        } else {
            scoreB++;
        }
    }
    
    cout << scoreA << " " << scoreB << endl;
    return 0;
}
```

**游戏模拟的通用框架**：

1. **定义状态**：确定需要维护哪些变量（比分、回合数、当前出拳等）。
2. **循环模拟每一轮**：按照规则更新状态。
3. **使用取模实现循环序列**：如果出拳序列是周期性的，用`index = round % length`来获取当前应出的拳。
4. **输出最终结果**。

### 二、约瑟夫环问题

#### 2.1 问题描述

约瑟夫环（Josephus Problem）是一道经典问题：n个人围成一圈，从第一个人开始报数，报到m的人出列，然后从出列者的下一个人继续报数，直到所有人都出列。求出列的顺序。

例如n=7, m=3时，出列顺序为：3, 6, 2, 7, 5, 1, 4。

#### 2.2 队列模拟解法

用队列可以非常直观地模拟约瑟夫过程。思路：所有人入队，然后不断将队首元素取出：如果它应该出列（报数为m），就记录并移除；否则将其重新放回队尾（模拟环形）。

```cpp
// 约瑟夫环：队列模拟
#include <iostream>
#include <queue>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    
    queue<int> q;
    // 所有人入队（编号1到n）
    for (int i = 1; i <= n; i++) {
        q.push(i);
    }
    
    int count = 0;  // 当前报数
    
    while (!q.empty()) {
        count++;
        int person = q.front();
        q.pop();
        
        if (count == m) {
            // 报数为m的人出列
            cout << person << " ";
            count = 0;  // 重置报数（下一个人重新从1开始报）
        } else {
            // 未报到m，放回队尾
            q.push(person);
        }
    }
    cout << endl;
    
    return 0;
}
```

**队列模拟的详解**：每次从队首取出一个人，如果报数不等于m就放回队尾（模拟这个人继续留在圈内，等待下一轮），如果报数等于m就输出（出列）并重置报数计数器。队列的FIFO特性天然地模拟了环形的"转圈"过程。

对于n<=1000的题目，队列模拟的时间复杂度是O(n*m)，完全可以接受。

#### 2.3 数学递推解法（进阶）

当n非常大时（如n=10^7），O(n*m)的时间复杂度无法接受。此时可以使用数学解法。约瑟夫环的递推公式是：

`f[1] = 0`（当只有1个人时，幸存者的位置是0号，即第1个人）

`f[i] = (f[i-1] + m) % i`（从i-1个人的情况递推到i个人的情况）

这里f[i]表示i个人报数为m时，**最后幸存者**的编号（从0开始计数）。

```cpp
// 约瑟夫环：数学递推求最后幸存者
#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    
    int survivor = 0;  // f[1] = 0
    
    // 递推：从2个人开始，逐步增加人数
    for (int i = 2; i <= n; i++) {
        survivor = (survivor + m) % i;
    }
    
    // 编号从1开始，所以+1
    cout << survivor + 1 << endl;
    return 0;
}
```

**递推公式的直观理解**：
当有i个人时，第一轮报数后第m%i号人出列。之后问题变成了i-1个人的约瑟夫环，只是起始报数位置变成了(m%i)号。因此，i个人时的幸存者位置 = (i-1个人时的幸存者位置 + m) % i。这个递推的巧妙之处在于通过编号的偏移来衔接不同规模的问题。

### 三、高精度乘法

在CSP-J中，高精度乘法有两种常见形式：大整数乘普通整数，以及大整数乘大整数。两者的实现难度不同。

#### 3.1 大整数乘普通整数

这种形式相对简单：将一个用字符串表示的大整数逐个数字乘以一个普通的int。

```cpp
// 高精度乘法：大整数 × 普通整数
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

string multiply(string a, int b) {
    string result = "";
    int carry = 0;
    
    // 从低位到高位逐位相乘
    for (int i = a.size() - 1; i >= 0; i--) {
        int digit = a[i] - '0';              // 当前位的数值
        int product = digit * b + carry;     // 当前位乘积 + 上一轮的进位
        result += (char)(product % 10 + '0'); // 当前位的结果
        carry = product / 10;                // 进位
    }
    
    // 处理剩余的进位（可能有多位）
    while (carry > 0) {
        result += (char)(carry % 10 + '0');
        carry /= 10;
    }
    
    reverse(result.begin(), result.end());
    return result;
}

int main() {
    string a;
    int b;
    cin >> a >> b;
    
    // 处理乘0的情况
    if (a == "0" || b == 0) {
        cout << "0" << endl;
        return 0;
    }
    
    cout << multiply(a, b) << endl;
    return 0;
}
```

**逐行解析**：
- **第12行** `int product = digit * b + carry;`：这是核心计算。digit是当前位(0-9)，b是乘数(可能是任意大小的int)，carry是上一轮留下来的进位。product最大为9×99999+进位，可能是一个很大的数。
- **第17-20行** `while (carry > 0)`：与加法不同，乘法中乘数b可能很大，最后一轮产生的进位可能超过10，需要逐位处理。例如999×3=2997，九九九乘三，最后进位是2，需要循环处理。
- **第11行** `for (int i = a.size() - 1; i >= 0; i--)`：与加法一样，从最低位（个位）开始处理。

#### 3.2 大整数乘大整数（高精度乘高精度）

当两个数都非常大时，需要完整的高精度乘高精度算法。其原理仍然模拟手工竖式乘法：将第一个数的每一位与第二个数的每一位相乘，结果的位数等于两个因子位数之和（或减1），最后将所有部分积相加。

```cpp
// 高精度乘法：大整数 × 大整数
#include <iostream>
#include <string>
#include <algorithm>
#include <vector>
using namespace std;

string multiply(string a, string b) {
    // 处理"乘0"的情况
    if (a == "0" || b == "0") return "0";
    
    int lenA = a.size(), lenB = b.size();
    // 结果最多有 lenA + lenB 位
    vector<int> result(lenA + lenB, 0);
    
    // 将字符串反转，便于从低位开始计算
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());
    
    // 逐位相乘，累加到result中
    for (int i = 0; i < lenA; i++) {
        for (int j = 0; j < lenB; j++) {
            int digitA = a[i] - '0';
            int digitB = b[j] - '0';
            // a的第i位与b的第j位相乘，结果加到result的第i+j位
            result[i + j] += digitA * digitB;
        }
    }
    
    // 处理进位
    string ans = "";
    for (int i = 0; i < lenA + lenB; i++) {
        if (result[i] >= 10) {
            result[i + 1] += result[i] / 10;  // 进位加到高位
            result[i] %= 10;                   // 保留低位
        }
    }
    
    // 将结果转为字符串（从高位到低位）
    int pos = lenA + lenB - 1;
    // 跳过前导零
    while (pos >= 0 && result[pos] == 0) pos--;
    
    for (int i = pos; i >= 0; i--) {
        ans += (char)(result[i] + '0');
    }
    
    return ans;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << multiply(a, b) << endl;
    return 0;
}
```

**算法详解**：

1. **为什么结果最多有lenA+lenB位？** 考虑极端情况：最大的lenA位数（全是9）乘以最大的lenB位数（全是9），乘积约等于10^(lenA+lenB)-10^lenA-10^lenB+1，小于10^(lenA+lenB)，所以最多lenA+lenB位。

2. **为什么加法和乘法进位处理方式不同？** 加法中每位的和最多为9+9+1=19，进位为0或1；而乘法中，所有部分积先累加到一个int数组中，然后再统一处理进位。这是因为乘法中第i+j位可能被多个(i,j)对贡献，需要先全部加起来再统一进位。

3. **核心循环** `result[i+j] += digitA * digitB;`：a的第i位（从低位开始，即10^i的系数）乘以b的第j位（10^j的系数），其乘积对10^(i+j)位有贡献。这正是手工竖式乘法中"错位相加"的原理。

#### 3.3 高精度乘法的注意事项

- **前导零处理**：如果两个数都不是0但结果最前面有0（如999×1=0999？），需要跳过。我们用一个while循环从高位向低位扫描，跳过值为0的高位。
- **乘法溢出**：在第二个版本中，`result[i+j] += digitA * digitB`可能导致int溢出（如果位数很大且没有及时进位）。对于CSP-J的数据范围，使用int数组存储结果通常是安全的，因为最高位也不会超过`9*9*n ≈ 81n`，当n<=1000时完全在int范围内。

### 四、进制转换模拟

进制转换是模拟算法中的经典内容。核心思想只有两个：

1. **任意进制转十进制**：按权展开法。从高位到低位，`result = result * base + 当前位的值`。
2. **十进制转任意进制**：除基取余法。不断除以目标进制，将余数记录下来，最后倒序排列。

#### 4.1 任意进制转十进制

```cpp
// 任意进制转十进制（按权展开法）
// 进制 base (2 <= base <= 36)
// 输入字符串 s 表示该进制下的数字
#include <iostream>
#include <string>
using namespace std;

// 将字符转为对应的数值（'0'-'9' -> 0-9, 'A'-'Z' -> 10-35）
int charToValue(char c) {
    if (c >= '0' && c <= '9') return c - '0';
    if (c >= 'A' && c <= 'Z') return c - 'A' + 10;
    if (c >= 'a' && c <= 'z') return c - 'a' + 10;  // 兼容小写
    return -1;  // 非法字符
}

int main() {
    int base;
    string s;
    cin >> base >> s;
    
    long long result = 0;
    for (int i = 0; i < (int)s.size(); i++) {
        int digit = charToValue(s[i]);
        result = result * base + digit;  // 按权展开的核心公式
    }
    
    cout << result << endl;
    return 0;
}
```

**按权展开的数学原理**：对于base进制的数字"abcd"（从左到右是高位到低位），其十进制值 = a×base^3 + b×base^2 + c×base^1 + d×base^0。而`result = result * base + digit`等价于这个多项式计算的秦九韶算法（Horner's Method），避免了计算幂次，效率更高。

#### 4.2 十进制转任意进制

```cpp
// 十进制转任意进制（除基取余法）
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

// 将数值0-35转为对应字符
char valueToChar(int v) {
    if (v >= 0 && v <= 9) return v + '0';
    return v - 10 + 'A';
}

int main() {
    long long n;
    int base;
    cin >> n >> base;
    
    if (n == 0) {
        cout << "0" << endl;
        return 0;
    }
    
    string result = "";
    while (n > 0) {
        int remainder = n % base;  // 取余数
        result += valueToChar(remainder);
        n /= base;                 // 除以base
    }
    
    // 余数是从低位到高位排列的，需要反转
    reverse(result.begin(), result.end());
    cout << result << endl;
    
    return 0;
}
```

**除基取余的原理**：每次除以base，余数就是当前最低位的值，商继续作为下一轮的被除数。这个过程反复执行，直到商为0。由于先得到的余数是最低位，后得到的是高位，所以需要反转。

#### 4.3 进制转换的综合示例

下面是一个综合示例，演示从任意进制A转换到任意进制B的方法——通常以十进制作为中转：

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int charToValue(char c) {
    if (c >= '0' && c <= '9') return c - '0';
    if (c >= 'A' && c <= 'Z') return c - 'A' + 10;
    if (c >= 'a' && c <= 'z') return c - 'a' + 10;
    return -1;
}

char valueToChar(int v) {
    if (v >= 0 && v <= 9) return v + '0';
    return v - 10 + 'A';
}

// A进制字符串 → 十进制数值
long long toDecimal(string s, int baseA) {
    long long res = 0;
    for (char c : s) {
        res = res * baseA + charToValue(c);
    }
    return res;
}

// 十进制数值 → B进制字符串
string fromDecimal(long long n, int baseB) {
    if (n == 0) return "0";
    string res = "";
    while (n > 0) {
        res += valueToChar(n % baseB);
        n /= baseB;
    }
    reverse(res.begin(), res.end());
    return res;
}

int main() {
    int baseA, baseB;
    string num;
    cin >> baseA >> num >> baseB;  // 将baseA进制的num转为baseB进制
    
    long long decimal = toDecimal(num, baseA);  // 先转为十进制
    cout << fromDecimal(decimal, baseB) << endl;  // 再转为B进制
    
    return 0;
}
```

### 五、文件操作：freopen重定向

在CSP-J的正式考试中，通常需要使用文件输入输出（从指定文件读取输入，将结果写入指定文件，而不是从标准输入输出）。C++中最简单的方式是使用`freopen`函数。

```cpp
#include <cstdio>  // 或 #include <stdio.h>

int main() {
    // 将标准输入重定向到文件 input.txt
    freopen("input.txt", "r", stdin);
    // 将标准输出重定向到文件 output.txt
    freopen("output.txt", "w", stdout);
    
    // 之后的 cin/cout/scanf/printf 都会读写文件而不是控制台
    int n;
    cin >> n;
    cout << n * 2 << endl;
    
    // 可选：关闭文件
    fclose(stdin);
    fclose(stdout);
    
    return 0;
}
```

**freopen的三个参数**：
- 第一个参数：文件名（字符串）。
- 第二个参数：打开模式。"r"表示读取（read），"w"表示写入（write）。
- 第三个参数：要重定向的流。stdin是标准输入，stdout是标准输出。

**使用场景说明**：
1. **CSP-J/NOIP正式考试**：题目通常要求从特定文件（如`problem.in`）读取输入，输出到特定文件（如`problem.out`）。此时必须在代码开头使用freopen。
2. **本地测试**：在本地调试时，可以将输入数据写在文件中，用freopen重定向，避免每次手动输入大量测试数据。
3. **提交到在线评测平台（OJ）时**：通常需要注释掉或删除freopen，因为OJ使用标准输入输出判题。可以使用条件编译来处理：

```cpp
// 条件编译：本地调试时使用文件输入输出，提交时使用标准输入输出
#ifdef LOCAL
    freopen("test.in", "r", stdin);
    freopen("test.out", "w", stdout);
#endif
```

在本地编译时加上`-DLOCAL`参数即可启用文件重定向。

**重要提醒**：在正式考试中，freopen的文件名必须严格按照题目要求填写，写错文件名将导致0分。建议在代码最前面（main函数的第一行）就写freopen，防止不小心输出到标准输出。

### 模板2：高精度乘法（大整数×大整数）

```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <vector>
using namespace std;

string multiply(string a, string b) {
    if (a == "0" || b == "0") return "0";
    
    int n = a.size(), m = b.size();
    vector<int> res(n + m, 0);
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());
    
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            res[i + j] += (a[i] - '0') * (b[j] - '0');
    
    for (int i = 0; i < n + m; i++) {
        if (res[i] >= 10) {
            res[i + 1] += res[i] / 10;
            res[i] %= 10;
        }
    }
    
    string ans = "";
    int pos = n + m - 1;
    while (pos >= 0 && res[pos] == 0) pos--;
    for (int i = pos; i >= 0; i--)
        ans += char(res[i] + '0');
    
    return ans;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << multiply(a, b) << endl;
    return 0;
}
```

### 模板3：进制转换模板

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

int charToVal(char c) {
    if (c >= '0' && c <= '9') return c - '0';
    if (c >= 'A' && c <= 'Z') return c - 'A' + 10;
    if (c >= 'a' && c <= 'z') return c - 'a' + 10;
    return -1;
}

char valToChar(int v) {
    if (v <= 9) return v + '0';
    return v - 10 + 'A';
}

// 任意进制 → 十进制
long long toDec(string s, int base) {
    long long r = 0;
    for (char c : s) r = r * base + charToVal(c);
    return r;
}

// 十进制 → 任意进制
string fromDec(long long n, int base) {
    if (n == 0) return "0";
    string r = "";
    while (n) { r += valToChar(n % base); n /= base; }
    reverse(r.begin(), r.end());
    return r;
}

int main() {
    int from, to;
    string num;
    cin >> from >> num >> to;
    cout << fromDec(toDec(num, from), to) << endl;
    return 0;
}
```

## ⚠️ 易错点

- **易错点1：约瑟夫环中报数重置的时机**。有人出列后，下一个人应该从1开始重新报数（count重置为0），而不是接着上一个报数继续（count保持不变）。在队列模拟中，如果出列后报数不重置，会导致后续的报数偏移。**避免方法**：在输出出列编号后，立即将count重置为0。

- **易错点2：高精度乘法中进位处理的顺序**。如果一边计算一边处理进位（类似于加法），会因为进位产生了新值而导致重复处理。正确的做法是先完成所有逐位相乘的累加，再统一处理进位。**避免方法**：先用一个数组存储所有部分积的和，然后从低位到高位扫描一次，统一处理进位。

- **易错点3：进制转换中字母大小写混淆**。charToValue函数中如果只处理了大写字母(A-Z)，遇到小写输入(a-z)会返回错误值。同样valueToChar中需要明确输出大写还是小写。**避免方法**：charToValue中同时处理大小写（都返回相同的数值），valueToChar中统一使用大写字母（CSP-J题目的惯例）。

- **易错点4：除基取余法忘记n=0的特殊情况**。当n=0时，while(n>0)循环体一次都不会执行，result为空字符串。如果直接输出空字符串，在评测时会判错。**避免方法**：在进制转换函数开头单独判断n==0的情况，直接返回"0"。

- **易错点5：freopen文件名写错或忘记使用**。CSP-J正式考试中题目会指定输入文件名（如"zoo.in"）和输出文件名（如"zoo.out"），如果写错文件名或用错大小写，程序会读取不到输入，导致0分。**避免方法**：拿到题目后第一时间确认输入输出文件名，写在草稿纸上；代码写完后在main函数最前面写freopen，并对照题目检查文件名。

### 真题1：约瑟夫环（CSP-J风格）

**题目描述**：
n个人围成一圈，从第一个人开始报数（报数从1开始），凡报到m的人出列。输出出列的顺序。

**输入格式**：
两个正整数n和m（1 <= n, m <= 1000）。

**输出格式**：
一行n个整数，表示出列的顺序，每个数之间用空格隔开。

**样例输入**：
```
7 3
```

**样例输出**：
```
3 6 2 7 5 1 4
```

**完整AC代码**：

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    
    queue<int> q;
    for (int i = 1; i <= n; i++) {
        q.push(i);
    }
    
    int count = 0;
    while (!q.empty()) {
        count++;
        int person = q.front();
        q.pop();
        
        if (count == m) {
            cout << person;
            if (!q.empty()) cout << " ";  // 控制空格输出
            count = 0;
        } else {
            q.push(person);
        }
    }
    cout << endl;
    
    return 0;
}
```

**解析**：本题使用队列模拟约瑟夫过程。队列的FIFO特性完美模拟了环形的"转圈"过程。每次取出队首元素，如果报数等于m则输出并重置计数器，否则重新入队。需要注意输出格式：最后一个数后面没有空格，用`if (!q.empty())`来判断。n,m均不超过1000，时间复杂度O(n*m)，最多约100万次操作，完全可行。

### 真题2：高精度乘法（CSP-J风格）

**题目描述**：
求两个不超过200位的正整数的乘积。

**输入格式**：
两行，每行一个不超过200位的正整数，没有前导零。

**输出格式**：
一行，即两个数的乘积。

**样例输入**：
```
123456789
987654321
```

**样例输出**：
```
121932631112635269
```

**完整AC代码**：

```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <vector>
using namespace std;

string multiply(string a, string b) {
    if (a == "0" || b == "0") return "0";
    
    int n = a.size(), m = b.size();
    vector<int> product(n + m, 0);
    
    // 反转字符串，从低位开始处理
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());
    
    // 逐位相乘，累加到product[i+j]
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            product[i + j] += (a[i] - '0') * (b[j] - '0');
        }
    }
    
    // 统一处理进位
    for (int i = 0; i < n + m - 1; i++) {
        product[i + 1] += product[i] / 10;
        product[i] %= 10;
    }
    
    // 构建结果字符串
    string ans = "";
    int pos = n + m - 1;
    while (pos > 0 && product[pos] == 0) pos--;  // 跳过前导零
    for (int i = pos; i >= 0; i--) {
        ans += char(product[i] + '0');
    }
    
    return ans;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << multiply(a, b) << endl;
    return 0;
}
```

**解析**：此题是高精度乘高精度的标准模板题。核心步骤：①将两个字符串反转，从低位开始处理；②双层循环逐位相乘，将结果累加到product[i+j]（对应10^(i+j)位）；③从低到高统一处理进位；④反转回正常顺序并去除前导零。对于200位的整数，int和long long均无法直接存储，必须使用高精度算法。由于没有指定输入数字可能为零，需要在函数开头处理乘0的特殊情况，避免结果为空。

## 🎯 本课小结
- 游戏模拟的核心在于将游戏规则转化为计分和状态更新的代码，使用取模运算处理循环序列。
- 约瑟夫环使用队列模拟最为直观，每轮取出队首判断是否出列；数学递推法适用于求最后幸存者的大数据场景。
- 高精度乘法模拟手工竖式，先将所有部分积累加再统一进位；大整数乘普通整数和大整数乘大整数是两种常见形式。
- 进制转换只有两个核心公式：按权展开法（任意进制转十进制）和除基取余法（十进制转任意进制），十进制作为中转可实现任意两进制互转。
- freopen是考试中文件输入输出的标准方法，文件名必须与题目要求一致，本地调试与在线提交需要注意区别处理。
