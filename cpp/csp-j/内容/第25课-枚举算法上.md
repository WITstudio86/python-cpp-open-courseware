## 📖 知识精讲

### 一、枚举算法的核心思想

枚举算法（Enumeration Algorithm），也称为穷举法，是计算机解决问题最朴素、最直观的方法。其核心思想只有一句话：**把所有可能的候选解逐一列举出来，逐一检验，找到满足条件的解**。

枚举算法的威力在于"确定性"——只要枚举范围正确覆盖了所有可能的解，就一定不会漏掉任何答案。相比贪心可能得不到最优解、动态规划需要状态转移方程，枚举是最容易想到、最不容易出错的方法。在CSP-J考试中，许多题目的数据规模较小（通常 n <= 100 或 n <= 1000），直接枚举即可拿到满分。

枚举算法的基本框架如下：

```cpp
// 枚举算法的通用框架
for (/* 遍历所有候选解 */) {
    if (/* 候选解满足条件 */) {
        // 记录或输出该解
    }
}
```

这个框架虽然简单，但真正写起来有三个关键问题需要解决：
1. **枚举范围是什么？** —— 必须在有限的、可列举的范围内，不能是无穷大。
2. **如何判断一个候选解是否满足条件？** —— 判断逻辑要正确且尽量高效。
3. **如何避免不必要的枚举？** —— 通过缩小范围或剪枝来优化。

### 二、循环枚举的三种基本形态

#### 2.1 单层循环枚举

当一个问题的候选解只需要一个变量来描述时，使用单层循环即可。典型例子：判断一个数是否为质数。

```cpp
// 判断 n 是否为质数（单层枚举试除法）
#include <iostream>
#include <cmath>
using namespace std;

bool isPrime(int n) {
    if (n < 2) return false;          // 0和1不是质数
    // 只需枚举到 sqrt(n)，因为如果 n 有大于 sqrt(n) 的因子，
    // 它必然对应一个小于 sqrt(n) 的因子
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) return false; // 找到因子，不是质数
    }
    return true;
}

int main() {
    int n;
    cin >> n;
    if (isPrime(n))
        cout << "Yes" << endl;
    else
        cout << "No" << endl;
    return 0;
}
```

单层枚举的关键细节：枚举范围从2到sqrt(n)而非n-1，这是典型的"缩小枚举范围"优化，将时间复杂度从O(n)降到O(sqrt(n))。对于n=10^9，sqrt(n)约31623，完全可行。

#### 2.2 双层循环枚举

当候选解由两个变量组成时，需要双层循环。最经典的例子是"寻找两个数的和为target"。

```cpp
// 两数之和：在数组 a[0..n-1] 中找两个不同下标，使其和为 target
#include <iostream>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    int a[1005];
    for (int i = 0; i < n; i++) cin >> a[i];
    
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {  // j 从 i+1 开始，避免重复
            if (a[i] + a[j] == target) {
                cout << i << " " << j << endl;
                return 0;  // 找到一个解即可
            }
        }
    }
    cout << "No solution" << endl;
    return 0;
}
```

关键细节：内层循环的 j 从 i+1 开始，而非从0开始。这样做有两个好处：一是避免了(i,j)和(j,i)的重复枚举，二是自动确保了i≠j。这个小小的改动将枚举量减少了一半，从n^2变为约n^2/2。

#### 2.3 三层循环枚举

当候选解由三个变量组成时，需要三层循环。典型例子：寻找勾股数（a^2 + b^2 = c^2，其中a、b、c均为正整数且互不相等）。

```cpp
// 寻找 [1, n] 范围内的所有勾股数组
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    // 枚举三条边 a < b < c，且 c <= n
    for (int a = 1; a <= n; a++) {
        for (int b = a + 1; b <= n; b++) {        // b > a，避免重复
            for (int c = b + 1; c <= n; c++) {    // c > b，且 c <= n
                if (a * a + b * b == c * c) {
                    cout << a << " " << b << " " << c << endl;
                }
            }
        }
    }
    return 0;
}
```

三层循环的复杂度是O(n^3)，对于n=100，大约50万次运算，完全可以接受。如果n=1000，则约为1.7亿次，在CSP-J的1秒时间限制下可能勉强通过。这引出了枚举算法的一个重要课题：如何优化？

### 三、枚举优化策略

#### 3.1 缩小枚举范围

这是最直接有效的优化：通过数学分析，将枚举变量的范围尽可能缩小。以前面的质数判断为例，将范围从[2, n-1]缩小到[2, sqrt(n)]。

对于百钱百鸡问题，我们不需要把公鸡、母鸡、小鸡都从0枚举到100，而是可以用数学约束来缩小范围。

#### 3.2 利用等式关系减少循环层数

当两个变量之间存在确定的数学关系时，可以由一个变量直接算出另一个，从而减少一层循环。例如：已知 a+b+c=100 且 a+b=30，则 c 必然等于 70，根本不需要枚举 c。

#### 3.3 剪枝（提前跳过不可能的分支）

在循环内部，如果发现当前状态已经不可能满足最终条件，就提前跳过后续的计算。经典例子是：在寻找和为目标值的三元组时，如果前两个数的和已经超过目标值，就不需要枚举第三个数了。

```cpp
// 三数之和为 target，剪枝优化
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    int a[1005];
    for (int i = 0; i < n; i++) cin >> a[i];
    sort(a, a + n);  // 排序后便于剪枝
    
    for (int i = 0; i < n; i++) {
        if (a[i] > target) break;  // 第一个数已经大于 target，后面更大
        for (int j = i + 1; j < n; j++) {
            if (a[i] + a[j] > target) break;  // 剪枝：前两个和已超
            for (int k = j + 1; k < n; k++) {
                if (a[i] + a[j] + a[k] > target) break;  // 剪枝
                if (a[i] + a[j] + a[k] == target) {
                    cout << a[i] << " " << a[j] << " " << a[k] << endl;
                }
            }
        }
    }
    return 0;
}
```

### 四、经典例题精讲

#### 4.1 百钱百鸡问题

**问题描述**：公鸡5文钱一只，母鸡3文钱一只，小鸡1文钱三只。用100文钱买100只鸡，问公鸡、母鸡、小鸡各多少只？（每种至少一只）

**朴素三层枚举解法**：

```cpp
#include <iostream>
using namespace std;

int main() {
    // 三层枚举：朴素解法
    for (int cock = 1; cock <= 100; cock++) {
        for (int hen = 1; hen <= 100; hen++) {
            for (int chick = 1; chick <= 100; chick++) {
                if (cock + hen + chick == 100 &&           // 总数量100只
                    5 * cock + 3 * hen + chick / 3 == 100 && // 总价100文
                    chick % 3 == 0) {                      // 小鸡数量是3的倍数
                    cout << "公鸡: " << cock 
                         << " 母鸡: " << hen 
                         << " 小鸡: " << chick << endl;
                }
            }
        }
    }
    return 0;
}
```

朴素解法的循环次数：100 × 100 × 100 = 1,000,000次。对于现代计算机来说不算多，但我们可以做得更好。

**优化后的两层枚举解法**：

分析数学关系：设公鸡x只，母鸡y只，小鸡z只。
- 数量关系：x + y + z = 100，所以 z = 100 - x - y
- 价格关系：5x + 3y + z/3 = 100，且z必须是3的倍数

将z用x、y表示后，只需要两层循环即可。同时缩小范围：公鸡最多20只（全买公鸡才100文），母鸡最多33只（全买母鸡约33只）。

```cpp
#include <iostream>
using namespace std;

int main() {
    // 优化：两层枚举 + 缩小范围
    for (int cock = 1; cock <= 20; cock++) {     // 公鸡最多20只
        for (int hen = 1; hen <= 33; hen++) {    // 母鸡最多33只
            int chick = 100 - cock - hen;         // 直接算出小鸡数量
            if (chick > 0 && chick % 3 == 0 &&    // 小鸡>0且是3的倍数
                5 * cock + 3 * hen + chick / 3 == 100) {
                cout << "公鸡: " << cock 
                     << " 母鸡: " << hen 
                     << " 小鸡: " << chick << endl;
            }
        }
    }
    return 0;
}
```

优化后的循环次数：20 × 33 = 660次，仅为朴素解法的0.066%！这个例子完美展示了枚举优化的威力——不是所有优化都需要复杂的数据结构，很多时候只需要一点数学分析和合理缩小范围，就能获得数量级的性能提升。

**输出结果**：
```
公鸡: 4 母鸡: 18 小鸡: 78
公鸡: 8 母鸡: 11 小鸡: 81
公鸡: 12 母鸡: 4 小鸡: 84
```

#### 4.2 水仙花数

**问题描述**：水仙花数是指一个三位数，其各位数字的立方和等于该数本身。例如153 = 1^3 + 5^3 + 3^3。

```cpp
#include <iostream>
using namespace std;

int main() {
    // 枚举所有三位数（100 - 999）
    for (int num = 100; num <= 999; num++) {
        int a = num / 100;          // 百位
        int b = (num / 10) % 10;    // 十位
        int c = num % 10;           // 个位
        // 判断是否为水仙花数
        if (a * a * a + b * b * b + c * c * c == num) {
            cout << num << endl;
        }
    }
    return 0;
}
```

**输出**：153, 370, 371, 407

这道题的枚举范围天然就是900个三位数，非常小，完全不需要额外优化。关键点在于**正确地分离出每一位数字**。对于任意位数的数字，分离各位数字的通用方法是：

```cpp
// 分离整数 num 的各位数字
int temp = num;
while (temp > 0) {
    int digit = temp % 10;  // 取出最低位
    // 处理 digit...
    temp /= 10;             // 去掉最低位
}
```

#### 4.3 数字统计

**问题描述**：统计区间[L, R]中数字2出现的次数。例如区间[2, 22]中，2、12、20、21、22一共出现了6次数字2（注意22中有两个2）。

```cpp
#include <iostream>
using namespace std;

// 计算数字 n 中数字 digit 出现的次数
int countDigit(int n, int digit) {
    int cnt = 0;
    while (n > 0) {
        if (n % 10 == digit) cnt++;
        n /= 10;
    }
    return cnt;
}

int main() {
    int L, R;
    cin >> L >> R;
    
    int total = 0;
    for (int i = L; i <= R; i++) {
        total += countDigit(i, 2);  // 统计数字2
    }
    cout << total << endl;
    return 0;
}
```

此题的枚举范围是区间长度，对于L,R不超过10^5的题目，直接枚举即可。如果数据范围达到10^9级别，则需要使用数位DP或数学推公式的方法，但那已超出CSP-J的范畴。

## ⚠️ 易错点

- **易错点1：枚举边界错误**。枚举范围写错是最常见的低级错误，比如判断质数时写成`i <= n`而不是`i * i <= n`（虽然逻辑上也对，但效率极低），或者百钱百鸡问题中公鸡的范围写成`cock <= 100`而不是`cock <= 20`。**避免方法**：在写循环之前，先用草稿纸明确列出每个变量的合法取值范围，写完后对照检查。

- **易错点2：忘记整除条件**。百钱百鸡问题中，小鸡1文钱3只，必须确保小鸡数量是3的倍数（`chick % 3 == 0`），否则价格判断`chick / 3`会因为整数除法而得到错误结果。例如如果chick=7，`chick/3=2`（整数除法截断），但实际7只小鸡需要约2.33文钱。**避免方法**：涉及整数除法的判断，务必先确认是否能整除，再进行比较。

- **易错点3：重复枚举和遗漏枚举**。双层循环中，如果内层循环也从0开始（`for(int j=0;j<n;j++)`），会导致(i,j)和(j,i)都被枚举，产生重复解。同时如果写`j!=i`来避免，也不如直接从`j=i+1`开始优雅。**避免方法**：养成习惯，在枚举无序组合时，让内层循环变量从外层循环变量+1开始。

- **易错点4：sqrt精度问题**。使用`sqrt(n)`时需要包含`<cmath>`，且由于浮点数精度问题，推荐使用`i * i <= n`替代`i <= sqrt(n)`。例如当n很大时，`sqrt(n)`可能因为浮点误差而略小于实际平方根，导致循环提前退出。**避免方法**：判断质数一律使用`i * i <= n`而不是`i <= sqrt(n)`。

- **易错点5：剪枝条件写反**。剪枝优化时，如果条件写成了`if (a[i] + a[j] < target) break;`而数组已升序排列，当`a[i]+a[j] < target`时说明还有可能达到target（需要更大的k），此时不应该break而应该continue。只有`a[i]+a[j] > target`时才应该break（因为k只会更大）。**避免方法**：剪枝前先想清楚数组的排序方向，以及在什么条件下才能保证后续不可能出现解。

### 真题1：买铅笔（CSP-J 2016 普及组）

**题目描述**：
P老师需要去商店买n支铅笔作为小朋友们参加NOIP的礼物。商店一共有3种包装的铅笔，不同包装内的铅笔数量有可能不同，价格也有可能不同。P老师决定买同一种包装的铅笔，同时商店不允许将包装拆开。为了公平起见，P老师决定只买同一种包装的铅笔。商店不允许将铅笔的包装拆开，因此P老师可能需要购买超过n支铅笔才够给小朋友们发礼物。现在P老师想知道，在商店每种包装的数量都足够的情况下，要买够至少n支铅笔最少需要花费多少钱。

**输入格式**：
第一行包含一个正整数n，表示需要的铅笔数量。
接下来三行，每行用2个正整数描述一种包装的铅笔：第1个数表示这种包装内铅笔的数量，第2个数表示这种包装的价格。
保证所有的7个数都是不超过10000的正整数。

**输出格式**：
一行一个整数，表示P老师最少需要花费的钱。

**样例输入**：
```
57
2 2
50 30
30 27
```

**样例输出**：
```
54
```

**完整AC代码**：

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int ans = 1e9;  // 初始化为极大值
    
    for (int i = 0; i < 3; i++) {
        int cnt, price;
        cin >> cnt >> price;
        
        // 计算需要买多少包才能达到至少n支铅笔
        int packs;
        if (n % cnt == 0)
            packs = n / cnt;
        else
            packs = n / cnt + 1;  // 向上取整
        
        int cost = packs * price;
        ans = min(ans, cost);
    }
    
    cout << ans << endl;
    return 0;
}
```

**解析**：这道题的核心在于理解"至少买n支"意味着需要向上取整。对于每种包装（数量cnt，价格price），需要的包数packs = ceil(n / cnt)，即如果n能被cnt整除则为n/cnt，否则为n/cnt+1。枚举三种包装，取最小花费即可。时间复杂O(3)，空间复杂度O(1)。

### 真题2：质因数分解（改编自CSP-J常考题型）

**题目描述**：
已知正整数n是两个不同的质数的乘积，试求出两者中较大的那个质数。保证2 <= n <= 10^9。

**输入格式**：
一个正整数n。

**输出格式**：
一个正整数p，即较大的那个质数。

**样例输入**：
```
21
```

**样例输出**：
```
7
```

**完整AC代码**：

```cpp
#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    
    // 从小到大枚举，找到第一个因子
    // 因为 n 是两个不同质数的乘积，第一个因子一定更小
    for (long long i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            // i 是较小的质因数，n/i 是较大的质因数
            cout << n / i << endl;
            break;
        }
    }
    
    return 0;
}
```

**解析**：这道题的巧妙之处在于利用枚举并无需真正判断质数性质——如果n是两个不同质数的乘积，那么从2开始枚举，找到的第一个因子i必定就是较小的那个质数（因为如果i是合数，那么它的质因子会更小且也是n的因子，会先被枚举到）。因此较大的质数就是n/i。注意使用long long类型，因为n可能达到10^9，但i*i可能达到10^18，在int范围内会溢出。时间复杂度O(sqrt(n))，在10^9的数据范围下约为31623次运算，完全可行。

## 🎯 本课小结
- 枚举算法的核心是"遍历所有候选解并逐一检验"，只要枚举范围正确就不会漏解。
- 单层/双层/三层循环是枚举的三种基本形态，复杂度分别为O(n)、O(n^2)、O(n^3)，需根据数据范围选择。
- 枚举优化三法宝：缩小范围（用数学约束限制变量取值范围）、减少循环层数（用等式将某个变量用其他变量表示）、剪枝（提前跳出不可能的分支）。
- 百钱百鸡从100万次优化到660次的例子说明，好的数学分析和范围约束能带来数量级的性能提升。
- 整数除法、边界条件、枚举范围的正确性是枚举题目中最容易出错的地方，务必仔细检查。
