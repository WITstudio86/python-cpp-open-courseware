## 📖 知识精讲

### 一、为什么需要数组

在编程中，我们经常需要处理一批同类型的数据。比如一个班级 50 名学生的成绩，如果为每个成绩都定义一个变量（`a1, a2, a3, ..., a50`），代码会极其冗长且难以维护。数组正是为解决这一问题而生——它用**一个名字**代表**一组数据**，通过**下标**来区分每一个元素。

对比一下：

```cpp
// 不用数组（灾难）
int a1, a2, a3, a4, a5;
cin >> a1 >> a2 >> a3 >> a4 >> a5;
int sum = a1 + a2 + a3 + a4 + a5;

// 使用数组（优雅）
int a[5];
for (int i = 0; i < 5; i++) cin >> a[i];
int sum = 0;
for (int i = 0; i < 5; i++) sum += a[i];
```

当数据规模从 5 变成 5000 时，第一种写法不可行，第二种写法几乎不用改。**数组让我们用循环处理批量数据**，这是从“写几行计算”走向“写算法程序”的关键一步。

### 二、数组的定义语法

一维数组的定义格式为：

```cpp
类型 数组名[数组大小];
```

例如：

```cpp
int a[100];        // 定义一个能存 100 个整数的数组 a
double b[50];      // 定义一个能存 50 个双精度浮点数的数组 b
char s[1000];      // 定义一个能存 1000 个字符的数组 s（即字符串）
long long c[100005]; // 竞赛中常用 long long 存大整数
```

这里有三个要素：

- **类型**：数组中每个元素的数据类型，所有元素类型相同。
- **数组名**：合法的 C++ 标识符，命名规则与变量名相同。
- **数组大小**：必须是一个**常量表达式**，表示数组能容纳的元素个数。

推荐写法：用常量命名数组上限。

```cpp
const int N = 1005;
int a[N];
```

这样修改上限时只需改一处，也方便统一开全局数组。

### 三、数组在内存中的存储

数组在内存中是**连续存放**的，这是数组最重要的特性。假设我们定义了 `int a[5];`，且 `a[0]` 的地址是 `0x1000`，每个 `int` 占 4 个字节，那么：

| 元素 | 地址 | 含义 |
|------|------|------|
| `a[0]` | `0x1000` | 起始位置 |
| `a[1]` | `0x1004` | 偏移 4 字节 |
| `a[2]` | `0x1008` | 偏移 8 字节 |
| `a[3]` | `0x100C` | 偏移 12 字节 |
| `a[4]` | `0x1010` | 偏移 16 字节 |

连续存储意味着：

1. 可以通过 `a + i` 定位任意元素（这是下标运算的本质）。
2. 遍历数组时 CPU 缓存命中率高，效率很好。
3. 一旦越界，会读到/写到相邻变量所在内存，后果不可控。

`a[i]` 等价于 `*(a + i)`，地址计算为：

```
地址(a[i]) = 地址(a[0]) + i * sizeof(元素类型)
```

### 四、数组的初始化

C++ 提供了灵活的数组初始化方式。

**方式一：定义时使用花括号初始化**

```cpp
int a[5] = {10, 20, 30, 40, 50};  // 全部初始化
int b[5] = {1, 2};                 // 部分初始化：b[0]=1, b[1]=2, 其余自动为0
int c[5] = {0};                    // 全部清零的快捷写法
int d[] = {1, 2, 3, 4, 5};        // 省略大小，编译器自动推导为5
```

**方式二：定义后逐个赋值**

```cpp
int a[5];
for (int i = 0; i < 5; i++) {
    cin >> a[i];    // 从键盘逐个读入
}
```

**方式三：统一赋值**

```cpp
// 全部赋同一个值，不能写 int a[5] = {1}; 这只会把 a[0] 设为1
// 正确做法：循环赋值
for (int i = 0; i < 5; i++) a[i] = 1;

// 或者用 fill（需要 algorithm）
fill(a, a + 5, 1);
```

**重要规则**：

1. 部分初始化时，未指定的元素会自动初始化为 0。
2. `int a[5] = {1};` **不是**全部为 1，而是 `a[0]=1`，其余为 0。
3. 局部数组若不初始化，内容是**垃圾值**；全局数组默认全 0。

### 五、下标从 0 开始

这是初学者最容易犯错的点。C++ 中数组的下标**从 0 开始**：

- 第一个元素是 `a[0]`，而不是 `a[1]`。
- 最后一个元素是 `a[n-1]`，而不是 `a[n]`。
- 下标范围是 `[0, n-1]`，共 n 个元素。

```cpp
int a[5] = {10, 20, 30, 40, 50};
a[0] = 100;   // 修改第一个元素
a[4] = 500;   // 修改最后一个元素（第5个）
cout << a[2]; // 输出 30，第三个元素
```

**为什么从 0 开始？** `a[i]` 实际访问的是地址 `a + i * sizeof(类型)` 处的数据。当 `i = 0` 时偏移量为 0，正好指向数组起始位置。

**竞赛中的两种编号习惯**：

| 习惯 | 下标范围 | 说明 |
|------|----------|------|
| 0-index | `0 .. n-1` | C++ 自然下标，推荐 |
| 1-index | `1 .. n` | 有时为了和题目编号一致，数组开 `N+5`，不用下标 0 |

两种都可以，但**整份代码要统一**，不要混用。

### 六、数组的遍历

遍历数组最经典的模式是使用 for 循环：

```cpp
for (int i = 0; i < n; i++) {
    // 处理 a[i]
}
```

这个模式中：

- `i` 从 0 开始，对应第一个元素。
- `i < n` 保证 i 最大取到 n-1，对应最后一个元素。
- `i++` 每次递增 1，逐个处理每个元素。

C++11 还支持**范围 for 循环**：

```cpp
int a[5] = {10, 20, 30, 40, 50};
for (int x : a) {
    cout << x << " ";  // 依次输出每个元素
}
```

不过竞赛中传统的 `for (int i = 0; i < n; i++)` 更灵活（可以获取下标），因此更常用。

**常见遍历变体**：

```cpp
// 从后往前遍历
for (int i = n - 1; i >= 0; i--) { ... }

// 只处理偶数下标
for (int i = 0; i < n; i += 2) { ... }

// 双指针：一头一尾
for (int i = 0, j = n - 1; i < j; i++, j--) { ... }
```

### 七、下标越界的危害

**这是 C++ 数组最危险的陷阱之一。** 访问 `a[n]`（n 为数组大小）或 `a[-1]` 就是越界访问。

```cpp
int a[5] = {1, 2, 3, 4, 5};
a[5] = 100;   // 严重错误！a 的有效下标是 0~4
a[100] = 200; // 更加危险
```

C++ 语言本身**不检查数组下标是否越界**。这意味着：

- 越界访问**不会**必然在编译期/运行时报错。
- 越界写入可能修改其他变量、函数返回地址等关键数据。
- 后果完全不可预料：WA、RE、段错误、甚至“看起来碰巧正确”。

**防护方法**：

1. 遍历时严格使用 `i < n` 而非 `i <= n`。
2. 竞赛中局部大数组定义为全局数组（避免栈溢出）。
3. 始终清楚数组大小，使用 `const int N = ...;`。
4. 需要访问 `a[i+1]` 时，先保证 `i+1 < n`。

### 八、局部大数组与全局数组

C++ 程序的函数局部变量存放在**栈**中，栈空间通常只有几 MB（如 8MB）。如果定义一个巨大的局部数组：

```cpp
int main() {
    int a[1000000];  // 约 4MB，可能栈溢出导致 RE！
    return 0;
}
```

解决办法是将大数组定义为**全局数组**，全局数组存储在**静态存储区**，空间充足：

```cpp
const int N = 1000000;
int a[N];  // 全局数组，安全

int main() {
    // 使用 a
    return 0;
}
```

**经验法则（CSP-J）**：

| 规模 | 建议 |
|------|------|
| n ≤ 1000 | 局部/全局均可 |
| n ≥ 1e5 | **必须全局**（或堆上分配） |
| 二维 `1000×1000` int | 约 4MB，优先全局 |

### 九、数组的常见应用（核心必会）

#### 1. 求和与平均值

```cpp
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i];
}
double avg = 1.0 * sum / n;  // 注意先 *1.0 避免整除
```

**注意**：若每个 `a[i]` 很大、n 也很大，`sum` 要用 `long long`。

#### 2. 找最大值与最小值

```cpp
int maxVal = a[0], minVal = a[0];
int maxPos = 0, minPos = 0;
for (int i = 1; i < n; i++) {
    if (a[i] > maxVal) {
        maxVal = a[i];
        maxPos = i;
    }
    if (a[i] < minVal) {
        minVal = a[i];
        minPos = i;
    }
}
```

**初始化技巧**：

- 已知数组非空：用 `a[0]` 初始化最稳妥。
- 若可能为空或想统一写法：`maxVal = INT_MIN`（需 `<climits>`），`minVal = INT_MAX`。
- 题目要求“编号最小的最大元素”：用 `>` 而不是 `>=`。

#### 3. 元素反转

将数组首尾对称位置的元素互换：

```cpp
for (int i = 0; i < n / 2; i++) {
    swap(a[i], a[n - 1 - i]);
}
```

等价双指针写法：

```cpp
int L = 0, R = n - 1;
while (L < R) {
    swap(a[L], a[R]);
    L++;
    R--;
}
```

#### 4. 计数统计

统计某个值出现的次数，或统计每个分数段的人数（桶计数）：

```cpp
// 统计某个值
int cnt = 0;
for (int i = 0; i < n; i++) {
    if (a[i] == x) cnt++;
}

// 桶计数：分数范围 0~100
int cnt[101] = {0};
for (int i = 0; i < n; i++) {
    cnt[a[i]]++;
}
// cnt[k] 表示值 k 出现的次数
```

桶计数要求值域不能太大；值域大时后面会学 `map` / 排序 + 二分。

#### 5. 线性查找

在一维数组中查找指定元素：

```cpp
int target = 42;
int pos = -1;  // -1 表示未找到
for (int i = 0; i < n; i++) {
    if (a[i] == target) {
        pos = i;
        break;  // 找到第一个即可
    }
}
```

查找所有出现位置：

```cpp
for (int i = 0; i < n; i++) {
    if (a[i] == target) {
        cout << i + 1 << " ";  // 题目若从 1 开始编号
    }
}
```

#### 6. 其他高频小技巧

```cpp
// 判断数组是否非降序
bool ok = true;
for (int i = 1; i < n; i++) {
    if (a[i] < a[i - 1]) { ok = false; break; }
}

// 循环右移 1 位
int last = a[n - 1];
for (int i = n - 1; i >= 1; i--) a[i] = a[i - 1];
a[0] = last;

// 删除下标 p 的元素（后面整体前移）
for (int i = p; i < n - 1; i++) a[i] = a[i + 1];
n--;
```

### 十、手算示例：把流程走一遍

给定数组：`a = [3, 1, 4, 1, 5]`，`n = 5`。

| 操作 | 过程 | 结果 |
|------|------|------|
| 求和 | 3+1+4+1+5 | 14 |
| 平均 | 14/5 | 2.8 |
| 最大 | 依次比较得到 5 | max=5, pos=4 |
| 反转 | 交换 (3,5)(1,1) | [5,1,4,1,3] |
| 计数 1 | a[1],a[3] | 2 次 |
| 查找 4 | i=2 | 找到 |

考试时若卡壳，可先用小数据在纸上模拟，再写代码。

### 模板二：找最大值及其位置

```cpp
#include <iostream>
using namespace std;

const int N = 1005;
int a[N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    int maxVal = a[0], maxPos = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] > maxVal) {
            maxVal = a[i];
            maxPos = i;
        }
    }
```

### 模板三：数组反转

```cpp
#include <iostream>

const int N = 1005;
int a[N];

int main() {
    int n;
```

### 模板四：求和 / 平均 / 计数 / 查找一体化

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

const int N = 1005;
int a[N];

int main() {
    int n, x;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    cin >> x;  // 要查找/统计的值

    long long sum = 0;
    int cnt = 0, pos = -1;
    for (int i = 0; i < n; i++) {
        sum += a[i];
        if (a[i] == x) {
            cnt++;
            if (pos == -1) pos = i;  // 记录第一次出现
        }
    }

    cout << "sum=" << sum << endl;
    cout << fixed << setprecision(2) << "avg=" << 1.0 * sum / n << endl;
    cout << "count(" << x << ")=" << cnt << endl;
    if (pos == -1) cout << "not found" << endl;
    else cout << "first pos=" << pos + 1 << endl;
    return 0;
}
```

## ⚠️ 易错点

| 序号 | 易错点 | 说明 |
|------|--------|------|
| 1 | **Off-by-one 错误** | 下标从 0 开始，最后一个元素是 `a[n-1]`，遍历条件是 `i < n` 而非 `i <= n`。这是 CSP-J 最频繁的扣分原因。 |
| 2 | **数组大小必须为常量** | `int n; cin >> n; int a[n];` 在某些编译器中可能通过，但这不符合 C++ 标准，CSP-J 推荐用 `const int N` 定义最大大小。 |
| 3 | **越界不报错** | 越界访问不会必然导致编译错误，OJ 上可能 WA 或 RE。 |
| 4 | **局部大数组栈溢出** | 函数内定义超过数十万的数组可能栈溢出，应定义为全局数组。 |
| 5 | **忘记初始化** | 局部数组默认是垃圾数据；全局数组默认 0。使用前要清楚是否已赋值。 |
| 6 | **部分初始化混淆** | `int a[5] = {1}` 只把 `a[0]` 初始化为 1，其余为 0，并不是全部为 1。 |
| 7 | **平均值整除** | `sum / n` 若 sum 与 n 都是 int，结果向下取整；应写 `1.0 * sum / n`。 |
| 8 | **求和溢出** | n 大、元素大时 `int sum` 可能溢出，改用 `long long`。 |
| 9 | **输出多余空格/少换行** | 注意题目格式；最后通常要 `endl` 或 `'\n'`。 |
| 10 | **编号混用** | 内部 0-index，输出若要求 1-index 记得 `+1`。 |

**自查清单（写完题后 10 秒过一遍）**

1. 循环是 `i < n` 还是 `i <= n`？
2. 数组开得够大吗？是否全局？
3. `sum` / `max` 类型够不够？
4. 空数组或 n=1 的边界想过了吗？
5. 输出编号是否需要 +1？

## 📝 真题精练

### 真题1：不与最大数相同的数字之和

**题目描述**

输出一个整数序列中不与最大数相同的数字之和。

**输入格式**

输入分为两行：  
第一行为 N（N 为接下来数的个数，N ≤ 100）；  
第二行为 N 个整数，数与数之间以一个空格分开，每个整数的范围是 -1,000,000 到 1,000,000。

**输出格式**

输出为 N 个数中除去所有最大数后其余数字之和。

**样例输入**

```
3
1 2 3
```

**样例输出**

```
3
```

**样例解释**：最大数为 3，除去后剩下 1 和 2，和为 3。

**思路分析**

1. 先读入数组，同时（或再扫一遍）求出最大值 `maxVal`。
2. 再扫一遍，把所有 `!= maxVal` 的数累加。
3. 注意：最大值可能出现多次，**所有等于最大值的都要排除**。
4. 元素可为负数，初始化 `maxVal` 时不要写成 0。

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 105;
int a[N];

int main() {
    int n;
    cin >> n;

    int maxVal = -2000000;  // 比题目最小值还小
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        if (a[i] > maxVal) {
            maxVal = a[i];
        }
    }

    int sum = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] != maxVal) {
            sum += a[i];
        }
    }

    cout << sum << endl;
    return 0;
}
```

**边界自测建议**

| 输入 | 期望 | 说明 |
|------|------|------|
| `1` / `5` | `0` | 全部是最大值 |
| `4` / `2 2 2 2` | `0` | 全相同 |
| `3` / `-1 -3 -2` | `-4` | 负数：去掉 -1 后 -3+-2 |

### 真题2：数组逆序重放

**题目描述**

将一个数组中的值按逆序重新存放。例如，原来顺序为 8, 6, 5, 4, 1，要求改为 1, 4, 5, 6, 8。

**输入格式**

输入为两行：第一行是数组中元素的个数 n（1 ≤ n ≤ 100）；第二行是 n 个整数，每两个整数之间用空格分隔。

**输出格式**

输出为一行：输出逆序后数组的整数，每两个整数之间用空格分隔。

**样例输入**

```
5
8 6 5 4 1
```

**样例输出**

```
1 4 5 6 8
```

**思路分析**

方法 A：双指针原地交换，空间 O(1)。  
方法 B：开另一个数组 `b[i] = a[n-1-i]`，空间 O(n)。  
方法 C：从后往前输出，不修改原数组（若题目只要求输出逆序，这最简单）。

**AC 代码（双指针原地反转）**

```cpp
#include <iostream>
using namespace std;

const int N = 105;
int a[N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int left = 0, right = n - 1;
    while (left < right) {
        int temp = a[left];
        a[left] = a[right];
        a[right] = temp;
        left++;
        right--;
    }

    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    cout << endl;
    return 0;
}
```

**等价简写（只输出逆序）**

```cpp
for (int i = n - 1; i >= 0; i--) {
    cout << a[i] << " ";
}
```

### 例题3：统计偶数个数并输出大于平均值的数

**题目描述**

输入 n（1 ≤ n ≤ 1000）和 n 个整数，输出：  
第一行：偶数的个数；  
第二行：所有严格大于平均值的数（按原顺序，空格分隔）。若没有则输出空行。

**样例输入**

```
5
1 2 3 4 10
```

**样例输出**

```
3
4 10
```

**说明**：偶数 2,4,10 共 3 个；平均值 4，大于 4 的是 10；等等——再算：sum=20, avg=4，大于 4 的是 10。若样例要 4 和 10，则是“大于等于”？按题面“严格大于”，只有 10。下面代码按严格大于实现；若题目要求 ≥ 平均，改成 `>=` 即可。

修正样例理解：sum=20, avg=4.0，严格大于 4 的只有 10。演示输出第二行应为 `10`。

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 1005;
int a[N];

int main() {
    int n;
    cin >> n;
    long long sum = 0;
    int evenCnt = 0;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        sum += a[i];
        if (a[i] % 2 == 0) evenCnt++;
    }
    cout << evenCnt << endl;

    double avg = 1.0 * sum / n;
    bool first = true;
    for (int i = 0; i < n; i++) {
        if (a[i] > avg) {
            if (!first) cout << " ";
            cout << a[i];
            first = false;
        }
    }
    cout << endl;
    return 0;
}
```

## 🎯 本课小结

1. **数组定义**：`类型 数组名[常量大小]`，所有元素类型相同，内存连续存储。
2. **下标规则**：从 0 开始，n 个元素的有效下标是 0 ~ n-1，遍历用 `i < n`。
3. **初始化方式**：花括号初始化 `{1,2,3}`、部分初始化 `{0}` 全部清零、逐个赋值；`{1}` 不是全 1。
4. **经典应用**：求和平均、找最值、元素反转、计数统计、线性查找——必须默写。
5. **防范越界**：C++ 不检查越界；大数组定义为全局；大小用常量。
6. **for 遍历模板**：`for (int i = 0; i < n; i++)` 是数组操作的基础。
7. **类型意识**：求和用 `long long`，平均用浮点，编号注意 +1。

下一课我们将学习二维数组，处理矩阵、表格等更复杂的数据结构。

**一句话记忆**：数组是“连续编号的同类型变量队列”；下标从 0 开始，循环写 `i < n`，大数组放全局。
