## 📖 知识精讲

### 一、为什么需要数组

在编程中，我们经常需要处理一批同类型的数据。比如一个班级 50 名学生的成绩，如果为每个成绩都定义一个变量（`a1, a2, a3, ..., a50`），代码会极其冗长且难以维护。数组正是为解决这一问题而生——它用**一个名字**代表**一组数据**，通过**下标**来区分每一个元素。

### 二、数组的定义语法

一维数组的定义格式为：

```cpp
类型 数组名[数组大小];
```

例如：

```cpp
int a[100];        // 定义一个能存 100 个整数的数组 a
double b[50];      // 定义一个能存 50 个双精度浮点数的数组 b
char s[1000];      // 定义一个能存 1000 个字符的数组 s（即字符串）
```

这里有三个要素：
- **类型**：数组中每个元素的数据类型，所有元素类型相同。
- **数组名**：合法的 C++ 标识符，命名规则与变量名相同。
- **数组大小**：必须是一个**常量表达式**，表示数组能容纳的元素个数。

### 三、数组在内存中的存储

数组在内存中是**连续存放**的，这是数组最重要的特性。假设我们定义了 `int a[5];`，且 `a[0]` 的地址是 `0x1000`，每个 `int` 占 4 个字节，那么：

| 元素 | 地址 |
|------|------|
| `a[0]` | `0x1000` |
| `a[1]` | `0x1004` |
| `a[2]` | `0x1008` |
| `a[3]` | `0x100C` |
| `a[4]` | `0x1010` |

连续存储意味着我们可以通过 `a + i` 来定位任意元素（这也正是下标运算的本质），也意味着遍历数组时 CPU 缓存命中率很高，效率非常高。

### 四、数组的初始化

C++ 提供了灵活的数组初始化方式。

**方式一：定义时使用花括号初始化**

```cpp
int a[5] = {10, 20, 30, 40, 50};  // 全部初始化
int b[5] = {1, 2};                 // 部分初始化：b[0]=1, b[1]=2, 其余自动为0
int c[5] = {0};                    // 全部清零的快捷写法
int d[] = {1, 2, 3, 4, 5};        // 省略大小，编译器自动推导为5
```

**方式二：定义后逐个赋值**

```cpp
int a[5];
for (int i = 0; i < 5; i++) {
    cin >> a[i];    // 从键盘逐个读入
}
```

**重要规则**：部分初始化时，未指定的元素会自动初始化为 0。这一特性在需要清零数组时非常方便。

### 五、下标从 0 开始

这是一个初学者最容易犯错的点。C++ 中数组的下标**从 0 开始**，也就是说：

- 第一个元素是 `a[0]`，而不是 `a[1]`。
- 最后一个元素是 `a[n-1]`，而不是 `a[n]`。
- 下标范围是 `[0, n-1]`，共 n 个元素。

示例：

```cpp
int a[5] = {10, 20, 30, 40, 50};
a[0] = 100;   // 修改第一个元素
a[4] = 500;   // 修改最后一个元素（第5个）
cout << a[2];  // 输出 30，第三个元素
```

**为什么从 0 开始？** 这与数组在内存中的存储方式有关。`a[i]` 实际访问的是地址 `a + i * sizeof(类型)` 处的数据。当 `i = 0` 时，正好偏移量为 0，指向数组的起始位置。

### 六、数组的遍历

遍历数组最经典的模式是使用 for 循环：

```cpp
for (int i = 0; i < n; i++) {
    // 处理 a[i]
}
```

这个模式中：
- `i` 从 0 开始，对应第一个元素。
- `i < n` 保证 i 最大取到 n-1，对应最后一个元素。
- `i++` 每次递增 1，逐个处理每个元素。

C++11 还支持**范围 for 循环**（Range-based for loop）：

```cpp
int a[5] = {10, 20, 30, 40, 50};
for (int x : a) {
    cout << x << " ";  // 依次输出每个元素
}
```

不过竞赛中传统的 `for (int i = 0; i < n; i++)` 更加灵活（可以获取下标），因此更常用。

### 七、下标越界的危害

**这是 C++ 数组最危险的陷阱之一。** 访问 `a[n]`（n 为数组大小）或 `a[-1]` 就是越界访问。

```cpp
int a[5] = {1, 2, 3, 4, 5};
a[5] = 100;   // 严重错误！a 的有效下标是 0~4
a[100] = 200; // 更加危险的严重错误！
```

C++ 语言本身**不检查数组下标是否越界**。这意味着：
- 越界访问**不会报错**，程序继续执行。
- 越界写入可能修改了其他变量、函数返回地址等关键数据。
- 后果完全不可预料：结果错误、程序崩溃、安全漏洞都有可能。

**防护方法**：
- 遍历时严格使用 `i < n` 而非 `i <= n`。
- 竞赛中局部大数组定义为全局数组（避免栈溢出）。
- 始终清楚数组的大小，使用 `const int N = ...;` 定义常量。

### 八、局部大数组与全局数组

C++ 程序的函数局部变量存放在**栈**中，栈空间通常只有几 MB（如 8MB）。如果定义一个巨大的局部数组：

```cpp
int main() {
    int a[1000000];  // 可能栈溢出导致程序崩溃！
    return 0;
}
```

解决办法是将大数组定义为**全局数组**，全局数组存储在**静态存储区**，空间充足：

```cpp
const int N = 1000000;
int a[N];  // 全局数组，安全

int main() {
    // 使用 a
    return 0;
}
```

### 九、数组的常见应用

#### 1. 求和与平均值

```cpp
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += a[i];
}
double avg = 1.0 * sum / n;
```

#### 2. 找最大值与最小值

```cpp
int maxVal = a[0], minVal = a[0];
for (int i = 1; i < n; i++) {
    if (a[i] > maxVal) maxVal = a[i];
    if (a[i] < minVal) minVal = a[i];
}
```

#### 3. 元素反转

将数组首尾对称位置的元素互换：

```cpp
for (int i = 0; i < n / 2; i++) {
    swap(a[i], a[n - 1 - i]);
}
```

#### 4. 计数统计

统计某个值出现的次数，或统计每个分数段的人数：

```cpp
int cnt[101] = {0};  // 分数范围 0~100
for (int i = 0; i < n; i++) {
    cnt[a[i]]++;
}
```

#### 5. 线性查找

在一维数组中查找指定元素：

```cpp
int target = 42;
int pos = -1;  // -1 表示未找到
for (int i = 0; i < n; i++) {
    if (a[i] == target) {
        pos = i;
        break;
    }
}
```

## 💻 代码模板

### 模板一：数组输入输出

```cpp
#include <iostream>
using namespace std;

const int N = 1005;
int a[N];

int main() {
    int n;
    cin >> n;
    // 输入
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    // 输出（每个数后跟一个空格）
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    return 0;
}
```

### 模板二：找最大值及其位置

```cpp
#include <iostream>
using namespace std;

const int N = 1005;
int a[N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    int maxVal = a[0], maxPos = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] > maxVal) {
            maxVal = a[i];
            maxPos = i;
        }
    }
    cout << maxVal << " " << maxPos + 1 << endl;  // +1转为从1开始编号
    return 0;
}
```

### 模板三：数组反转

```cpp
#include <iostream>
#include <algorithm>  // swap
using namespace std;

const int N = 1005;
int a[N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];

    // 反转
    for (int i = 0; i < n / 2; i++) {
        swap(a[i], a[n - 1 - i]);
    }

    // 输出反转后结果
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    return 0;
}
```

## ⚠️ 易错点

| 序号 | 易错点 | 说明 |
|------|--------|------|
| 1 | **Off-by-one 错误** | 下标从 0 开始，最后一个元素是 `a[n-1]`，遍历条件是 `i < n` 而非 `i <= n`。这是 CSP-J 最频繁的扣分原因。 |
| 2 | **数组大小必须为常量** | `int n; cin >> n; int a[n];` 在某些编译器中可能通过，但这不符合 C++ 标准，CSP-J 推荐用 `const int N` 定义最大大小。 |
| 3 | **越界不报错** | 越界访问不会导致编译错误或运行时报错，但结果不可预料，OJ 判题时可能 WA（Wrong Answer）或 RE（Runtime Error）。 |
| 4 | **局部大数组栈溢出** | 函数内定义超过数十万的数组可能栈溢出，应定义为全局数组。 |
| 5 | **忘记初始化** | 局部定义的数组默认值是随机的垃圾数据，使用前务必初始化。全局数组默认初始化为 0。 |
| 6 | **部分初始化混淆** | `int a[5] = {1}` 只把 `a[0]` 初始化为 1，其余为 0，并不是全部为 1。 |

## 📝 真题精练

### 真题1：不与最大数相同的数字之和

**题目描述**

输出一个整数序列中不与最大数相同的数字之和。

**输入格式**

输入分为两行：
第一行为 N（N 为接下来数的个数，N <= 100）；
第二行为 N 个整数，数与数之间以一个空格分开，每个整数的范围是 -1,000,000 到 1,000,000。

**输出格式**

输出为 N 个数中除去最大数其余数字之和。

**样例输入**

```
3
1 2 3
```

**样例输出**

```
3
```

**样例解释**：最大数为 3，除去后剩下 1 和 2，和为 3。

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 105;
int a[N];

int main() {
    int n;
    cin >> n;

    // 读入并找最大值
    int maxVal = -2000000;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        if (a[i] > maxVal) {
            maxVal = a[i];
        }
    }

    // 求不与最大数相同的数字之和
    int sum = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] != maxVal) {
            sum += a[i];
        }
    }

    cout << sum << endl;
    return 0;
}
```

### 真题2：数组逆序重放

**题目描述**

将一个数组中的值按逆序重新存放。例如，原来顺序为 8, 6, 5, 4, 1，要求改为 1, 4, 5, 6, 8。

**输入格式**

输入为两行：第一行是数组中元素的个数 n（1 <= n <= 100）；第二行是 n 个整数，每两个整数之间用空格分隔。

**输出格式**

输出为一行：输出逆序后数组的整数，每两个整数之间用空格分隔。

**样例输入**

```
5
8 6 5 4 1
```

**样例输出**

```
1 4 5 6 8
```

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 105;
int a[N];

int main() {
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    // 双指针法反转
    int left = 0, right = n - 1;
    while (left < right) {
        int temp = a[left];
        a[left] = a[right];
        a[right] = temp;
        left++;
        right--;
    }

    // 输出
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    cout << endl;
    return 0;
}
```

## 🎯 本课小结

1. **数组定义**：`类型 数组名[常量大小]`，所有元素类型相同，内存连续存储。
2. **下标规则**：从 0 开始，n 个元素的有效下标是 0 ~ n-1，遍历用 `i < n`。
3. **初始化方式**：花括号初始化 `{1,2,3}`、部分初始化 `{0}` 全部清零、逐个赋值。
4. **经典应用**：求和平均、找最值、元素反转、计数统计、线性查找。
5. **防范越界**：C++ 不检查越界，越界后果不可预料。大数组定义为全局，大小用常量。
6. **for 遍历模板**：`for (int i = 0; i < n; i++)` 是数组操作的基础，务必熟练掌握。

下一课我们将学习二维数组，处理矩阵、表格等更复杂的数据结构。课后请独立完成以下练习：

- 练习1：输入 n 个数，统计其中偶数的个数。
- 练习2：输入 n 个数，输出所有大于平均值的数。
- 练习3：输入 n 个数，将它们循环右移 k 位后输出。
