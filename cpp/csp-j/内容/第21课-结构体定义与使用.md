## 📖 知识精讲

### 1. 为什么需要结构体？

在编程中，我们经常需要表示一个由多个属性组成的「实体」。例如，一个学生有以下信息：

- 姓名（字符串）
- 年龄（整数）
- 语文成绩（整数/浮点数）
- 数学成绩（整数/浮点数）
- 英语成绩（整数/浮点数）

如果使用单独的变量来存储每个学生的这些信息，代码会变得非常混乱：

```cpp
string name1 = "张三";
int age1 = 12;
int chinese1 = 90;
int math1 = 85;
int english1 = 88;

string name2 = "李四";
int age2 = 13;
// ... 难以管理！
```

结构体（struct）允许我们将这些**相关数据打包成一个整体**，就像用一个「学生档案袋」把该学生的所有信息装在一起。这是一种**自定义的数据类型**，你可以根据自己的需求来定义它包含哪些成员。

**现实类比**：就像学校里的学生档案，每个档案袋上贴着学生的姓名、年龄、各科成绩。结构体就是这个「档案袋」的模板。

---

### 2. 定义结构体

定义结构体的基本语法如下：

```cpp
struct 结构体名 {
    数据类型 成员1;
    数据类型 成员2;
    // ...
};  // 注意：这里必须有分号！
```

**完整示例——定义 Student 结构体**：

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;    // 姓名
    int age;        // 年龄
    int chinese;    // 语文成绩
    int math;       // 数学成绩
    int english;    // 英语成绩
};  // 千万别忘了这个分号！

int main() {
    // 结构体定义完成，现在 Student 是一种新的数据类型
    cout << "Student 结构体定义完成！" << endl;
    return 0;
}
```

**关键点**：
- `struct` 是关键字，告诉编译器我们要定义一个结构体
- `Student` 是结构体的名字，命名规则与变量名相同
- 花括号内是成员变量列表，每个成员需要指明类型和名字
- **右花括号后面必须有分号 `;`**，这是最容易忘记的地方！

---

### 3. 创建与初始化结构体变量

定义好结构体之后，就可以像使用 `int`、`string` 一样使用它来创建变量。C++ 提供了多种初始化方式：

**（1）先声明再逐个赋值**：

```cpp
Student s1;
s1.name = "张三";
s1.age = 12;
s1.chinese = 90;
s1.math = 85;
s1.english = 88;
```

**（2）声明时直接初始化（C++11 统一初始化）**：

```cpp
Student s2 = {"李四", 13, 88, 92, 95};
```

**（3）使用花括号统一初始化**：

```cpp
Student s3{"王五", 12, 78, 85, 80};
```

**完整示例**：

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int age;
    int chinese, math, english;
};

int main() {
    // 方式1：逐个赋值
    Student s1;
    s1.name = "张三";
    s1.age = 12;
    s1.chinese = 90;
    s1.math = 85;
    s1.english = 88;

    // 方式2：初始化列表
    Student s2 = {"李四", 13, 88, 92, 95};

    // 方式3：C++11 统一初始化
    Student s3{"王五", 12, 78, 85, 80};

    // 输出验证
    cout << s1.name << " 年龄 " << s1.age << " 总分: "
         << s1.chinese + s1.math + s1.english << endl;
    cout << s2.name << " 年龄 " << s2.age << " 总分: "
         << s2.chinese + s2.math + s2.english << endl;
    cout << s3.name << " 年龄 " << s3.age << " 总分: "
         << s3.chinese + s3.math + s3.english << endl;

    return 0;
}
```

**输出**：
```
张三 年龄 12 总分: 263
李四 年龄 13 总分: 275
王五 年龄 12 总分: 243
```

### 4. 访问结构体成员——点运算符 `.`

使用**点运算符（`.`）**来访问结构体变量的成员：

```cpp
结构体变量名.成员名
```

- **读取**成员值：`int a = s1.age;`
- **修改**成员值：`s1.chinese = 95;`
- **在表达式中使用**：`int total = s1.chinese + s1.math + s1.english;`

**完整示例——计算学生总分和平均分**：

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int chinese, math, english;
};

int main() {
    Student stu = {"张三", 90, 85, 88};

    // 使用点运算符访问成员
    int total = stu.chinese + stu.math + stu.english;
    double avg = total / 3.0;

    cout << "姓名: " << stu.name << endl;
    cout << "语文: " << stu.chinese << endl;
    cout << "数学: " << stu.math << endl;
    cout << "英语: " << stu.english << endl;
    cout << "总分: " << total << endl;
    cout << "平均分: " << avg << endl;

    // 修改成员值
    stu.math = 95;  // 数学成绩提高了
    cout << "修改后数学成绩: " << stu.math << endl;

    return 0;
}
```

### 5. 结构体数组

当需要管理多个学生的信息时，可以使用结构体数组。这与普通数组的使用方式类似，只是数组元素的类型变成了结构体。

**定义结构体数组**：

```cpp
Student stus[100];  // 最多存储100个学生
int n;              // 实际学生数量
cin >> n;
```

**完整示例——学生成绩统计（最高分、最低分、平均分）**：

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

struct Student {
    string name;
    int chinese, math, english;
    int total;  // 总分
};

int main() {
    Student stus[100];
    int n;
    cout << "请输入学生人数: ";
    cin >> n;

    // 输入学生信息并计算总分
    for (int i = 0; i < n; i++) {
        cout << "请输入第" << i + 1 << "个学生的姓名 语文 数学 英语: ";
        cin >> stus[i].name >> stus[i].chinese >> stus[i].math >> stus[i].english;
        stus[i].total = stus[i].chinese + stus[i].math + stus[i].english;
    }

    // 找最高分和最低分的学生
    int maxIdx = 0, minIdx = 0;
    int sumTotal = 0;
    for (int i = 0; i < n; i++) {
        sumTotal += stus[i].total;
        if (stus[i].total > stus[maxIdx].total) maxIdx = i;
        if (stus[i].total < stus[minIdx].total) minIdx = i;
    }

    // 输出统计结果
    cout << "\n===== 成绩统计 =====" << endl;
    cout << "最高分: " << stus[maxIdx].name
         << " 总分: " << stus[maxIdx].total << endl;
    cout << "最低分: " << stus[minIdx].name
         << " 总分: " << stus[minIdx].total << endl;
    cout << "平均分: " << (double)sumTotal / n << endl;

    return 0;
}
```

### 6. 结构体排序——配合 `sort()` + 自定义比较函数

CSP-J 考试中非常常见的题型：对结构体数组按照某个字段进行排序。

`sort()` 函数需要三个参数：
- 排序的起始地址
- 排序的结束地址（不包含）
- **比较函数（cmp）**：决定排序规则

**比较函数的规范**：
- 返回 `bool` 类型
- 接受两个**同类型**的结构体参数
- 返回 `true` 表示第一个参数应该排在第二个参数**前面**
- **推荐使用 `const` 引用**传递参数，避免复制大结构体

**示例——按总分降序排序，总分相同按姓名升序**：

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

struct Student {
    string name;
    int chinese, math, english;
    int total;
};

// 比较函数：总分降序，总分相同按姓名升序
bool cmp(const Student &a, const Student &b) {
    if (a.total != b.total)
        return a.total > b.total;  // 总分高的在前
    return a.name < b.name;        // 总分相同，姓名小的在前
}

int main() {
    Student stus[100];
    int n;
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> stus[i].name >> stus[i].chinese >> stus[i].math >> stus[i].english;
        stus[i].total = stus[i].chinese + stus[i].math + stus[i].english;
    }

    // 排序
    sort(stus, stus + n, cmp);

    cout << "排名\t姓名\t总分" << endl;
    for (int i = 0; i < n; i++) {
        cout << i + 1 << "\t" << stus[i].name << "\t" << stus[i].total << endl;
    }

    return 0;
}
```

**按姓名升序排序的 cmp 函数**：

```cpp
bool cmpByName(const Student &a, const Student &b) {
    return a.name < b.name;  // 按姓名字典序升序
}
```

**`sort()` 的工作原理**：
1. `sort(stus, stus + n, cmp)` 中的 `stus` 是数组名，即首地址
2. `stus + n` 是「尾后」地址，表示排序范围是 `[stus, stus + n)`
3. 排序过程中，`sort()` 会多次调用 `cmp(a, b)` 来比较两个元素的大小关系
4. 当 `cmp(a, b)` 返回 `true` 时，`a` 被放在 `b` 前面

### 7. 结构体作为函数参数

**（1）值传递（Pass by Value）**：

```cpp
void printStudent(Student s) {  // 会复制整个结构体！
    cout << s.name << " " << s.total << endl;
}
```

- 函数内部操作的是**原始结构体的副本**
- 修改副本**不会影响**原始数据
- 如果结构体很大，复制操作开销较高

**（2）引用传递（Pass by Reference）**：

```cpp
void printStudent(const Student &s) {  // 不复制，直接引用原数据
    cout << s.name << " " << s.total << endl;
}
```

- `&` 表示引用，函数内部直接操作原始数据
- 加上 `const` 表示函数不会修改它，既安全又高效
- **推荐在 CSP-J 中优先使用 `const &`**

**（3）需要修改原始数据时，使用非 const 引用**：

```cpp
void addBonus(Student &s, int bonus) {
    s.total += bonus;
}
```

**完整对比示例**：

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int total;
};

// 值传递：不会修改原数据
void tryModifyByValue(Student s) {
    s.total += 10;
    cout << "值传递内部: " << s.name << " 总分=" << s.total << endl;
}

// 引用传递：会修改原数据
void tryModifyByRef(Student &s) {
    s.total += 10;
    cout << "引用传递内部: " << s.name << " 总分=" << s.total << endl;
}

int main() {
    Student stu1 = {"张三", 260};
    Student stu2 = {"李四", 270};

    cout << "=== 值传递 ===" << endl;
    cout << "调用前: " << stu1.name << " 总分=" << stu1.total << endl;
    tryModifyByValue(stu1);
    cout << "调用后: " << stu1.name << " 总分=" << stu1.total << endl;
    // stu1.total 未变！因为函数操作的是副本

    cout << "\n=== 引用传递 ===" << endl;
    cout << "调用前: " << stu2.name << " 总分=" << stu2.total << endl;
    tryModifyByRef(stu2);
    cout << "调用后: " << stu2.name << " 总分=" << stu2.total << endl;
    // stu2.total 被修改了！

    return 0;
}
```

**输出**：
```
=== 值传递 ===
调用前: 张三 总分=260
值传递内部: 张三 总分=270
调用后: 张三 总分=260

=== 引用传递 ===
调用前: 李四 总分=270
引用传递内部: 李四 总分=280
调用后: 李四 总分=280
```

### 8. 嵌套结构体

结构体可以包含另一个结构体作为其成员，形成嵌套关系。

**示例——日期结构体嵌套在学生结构体中**：

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Date {
    int year;
    int month;
    int day;
};

struct Student {
    string name;
    Date birthday;  // 嵌套 Date 结构体
    int total;
};

int main() {
    Student stu;
    stu.name = "张三";
    stu.birthday.year = 2012;
    stu.birthday.month = 6;
    stu.birthday.day = 15;
    stu.total = 280;

    cout << "姓名: " << stu.name << endl;
    cout << "生日: " << stu.birthday.year << "年"
         << stu.birthday.month << "月"
         << stu.birthday.day << "日" << endl;
    cout << "总分: " << stu.total << endl;

    return 0;
}
```

访问嵌套结构体的成员时，使用**多级点运算符**：`stu.birthday.year`。

## 💻 代码模板

### 模板 1：学生成绩管理系统

**功能**：定义 Student 结构体，输入 n 个学生信息，按总分降序排序，输出前三名。

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

struct Student {
    string name;
    int chinese, math, english;
    int total;
};

bool cmp(const Student &a, const Student &b) {
    return a.total > b.total;  // 总分降序
}

int main() {
    int n;
    cin >> n;
    Student stus[100];

    for (int i = 0; i < n; i++) {
        cin >> stus[i].name >> stus[i].chinese >> stus[i].math >> stus[i].english;
        stus[i].total = stus[i].chinese + stus[i].math + stus[i].english;
    }

    sort(stus, stus + n, cmp);

    cout << "前三名：" << endl;
    for (int i = 0; i < min(3, n); i++) {
        cout << "第" << i + 1 << "名: " << stus[i].name
             << " 总分=" << stus[i].total << endl;
    }

    return 0;
}
```

### 模板 2：点坐标与距离计算

**功能**：定义 Point 结构体，输入 n 个点坐标，计算每个点到原点 (0,0) 的距离，并按距离升序排序。

```cpp
#include <iostream>
#include <cmath>
#include <algorithm>
using namespace std;

struct Point {
    int x, y;
    double dist;  // 到原点的距离
};

// 计算到原点距离
double calcDist(int x, int y) {
    return sqrt(x * x + y * y);
}

// 按距离升序排序
bool cmp(const Point &a, const Point &b) {
    return a.dist < b.dist;
}

int main() {
    int n;
    cin >> n;
    Point pts[100];

    for (int i = 0; i < n; i++) {
        cin >> pts[i].x >> pts[i].y;
        pts[i].dist = calcDist(pts[i].x, pts[i].y);
    }

    sort(pts, pts + n, cmp);

    cout << "按距离排序后的点：" << endl;
    for (int i = 0; i < n; i++) {
        cout << "(" << pts[i].x << ", " << pts[i].y << ") 距离=" << pts[i].dist << endl;
    }

    return 0;
}
```

## ⚠️ 易错点

### 错误 1：忘记结构体定义末尾的分号

```cpp
// 错误 ❌
struct Student {
    string name;
    int age;
}   // 编译错误！缺少分号

// 正确 ✅
struct Student {
    string name;
    int age;
};  // 必须有分号
```

**原因**：C++ 中结构体定义是一条完整的语句，需要以分号结束。这是从 C 语言继承的语法规则。编译器会在缺少分号的地方报错，通常是令人困惑的「expected ';' after struct definition」。

---

### 错误 2：混淆结构体名与变量名

```cpp
struct Student {
    string name;
    int age;
};

// 错误 ❌
Student.name = "张三";  // Student 是类型名，不是变量名！

// 正确 ✅
Student stu;           // 先创建变量
stu.name = "张三";     // 再通过变量访问成员
```

**原因**：结构体名是一种**数据类型**（就像 `int`、`string`），不能直接使用点运算符。必须先声明该类型的变量，再通过变量名访问成员。

---

### 错误 3：值传递导致不必要的复制

```cpp
struct BigData {
    int arr[10000];
    // ... 大量数据
};

// 不推荐 ❌ —— 会复制整个结构体，非常慢
void process(BigData d) {
    // ...
}

// 推荐 ✅ —— 仅传递引用，不复制
void process(const BigData &d) {
    // ...
}
```

**原因**：值传递会在函数调用时复制整个结构体。如果结构体较大（包含数组等），会导致大量的内存复制，严重影响程序效率。在 CSP-J 中，比较函数 `cmp` 传入的 `const &` 就是为了避免这个问题。

---

### 错误 4：sort 比较函数签名错误

```cpp
// 错误 ❌ —— 缺少 const 和 &，或参数类型不对
bool cmp(Student a, Student b) {         // 缺少 const &，会复制
    return a.total > b.total;
}

// 错误 ❌ —— 返回类型错误
int cmp(const Student &a, const Student &b) {  // 应该返回 bool
    return a.total - b.total;
}

// 错误 ❌ —— 参数名相同
bool cmp(const Student &a, const Student &a) {  // 参数名冲突！
    return a.total > a.total;
}

// 正确 ✅
bool cmp(const Student &a, const Student &b) {
    return a.total > b.total;
}
```

**原因**：`sort()` 要求比较函数返回 `bool` 类型，且接受两个同类型的参数。使用 `const &` 可以避免不必要的复制。注意两个参数的**名称必须不同**。

---

### 错误 5：结构体数组下标越界

```cpp
Student stus[100];  // 最多存储 100 个学生

// 危险 ⚠️ —— 如果 n > 100，产生数组越界
int n;
cin >> n;
for (int i = 0; i < n; i++) {
    cin >> stus[i].name;  // 如果 n=200，访问 stus[100]..stus[199] 就越界了！
}

// 安全做法 ✅
if (n > 100) n = 100;  // 限制输入范围
// 或者根据实际 n 动态分配（但 CSP-J 中通常题目保证 n 在数组范围内）
```

## 📝 真题精练

### 题目 1：学生成绩排名

**【题目描述】**

某班级有 N 名学生，期末考试包含语文、数学、英语三科。请你编写程序，输入每个学生的姓名和三科成绩，计算每个学生的总分，然后按总分从高到低排序。如果总分相同，则按姓名的字典序从小到大排序。输出排序后的学生排名列表。

**【输入格式】**

第 1 行：一个整数 N（1 ≤ N ≤ 100），表示学生人数。
接下来 N 行，每行包含一个字符串 S 和三个整数 C, M, E，分别表示学生姓名（不含空格，长度不超过 20）、语文成绩、数学成绩、英语成绩（0 ≤ C, M, E ≤ 100）。

**【输出格式】**

共 N 行，每行输出排名、姓名、语文、数学、英语、总分，用空格分隔。

**【样例输入】**

```
4
张三 90 85 88
李四 88 92 95
王五 78 85 80
赵六 95 88 92
```

**【样例输出】**

```
1 赵六 95 88 92 275
2 李四 88 92 95 275
3 张三 90 85 88 263
4 王五 78 85 80 243
```

（赵六和李四总分相同，按姓名排序，赵 < 李）

**【AC 代码】**

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

struct Student {
    string name;
    int chinese, math, english;
    int total;
};

bool cmp(const Student &a, const Student &b) {
    if (a.total != b.total)
        return a.total > b.total;  // 总分降序
    return a.name < b.name;        // 总分相同按姓名升序
}

int main() {
    int n;
    cin >> n;
    Student stus[105];

    for (int i = 0; i < n; i++) {
        cin >> stus[i].name >> stus[i].chinese >> stus[i].math >> stus[i].english;
        stus[i].total = stus[i].chinese + stus[i].math + stus[i].english;
    }

    sort(stus, stus + n, cmp);

    for (int i = 0; i < n; i++) {
        cout << i + 1 << " " << stus[i].name << " "
             << stus[i].chinese << " " << stus[i].math << " "
             << stus[i].english << " " << stus[i].total << endl;
    }

    return 0;
}
```

### 题目 2：最近点对

**【题目描述】**

在二维平面上有 N 个点，每个点用坐标 (x, y) 表示。请你找出距离最近的两个点，并输出它们之间的距离（保留两位小数）。两点 P1(x1, y1) 和 P2(x2, y2) 之间的距离公式为：√((x1-x2)² + (y1-y2)²)。

**【输入格式】**

第 1 行：一个整数 N（2 ≤ N ≤ 100），表示点的数量。
接下来 N 行，每行包含两个整数 x, y（-1000 ≤ x, y ≤ 1000），表示一个点的坐标。

**【输出格式】**

一个浮点数，表示最近两点之间的距离，保留 2 位小数。

**【样例输入】**

```
4
0 0
1 1
0 1
2 0
```

**【样例输出】**

```
1.00
```

（点 (0,0) 和点 (0,1) 的距离为 1.00，是最小的）

**【AC 代码】**

```cpp
#include <iostream>
#include <cmath>
#include <cstdio>
#include <algorithm>
using namespace std;

struct Point {
    int x, y;
};

// 计算两点距离
double distance(const Point &a, const Point &b) {
    int dx = a.x - b.x;
    int dy = a.y - b.y;
    return sqrt(dx * dx + dy * dy);
}

int main() {
    int n;
    cin >> n;
    Point pts[105];

    for (int i = 0; i < n; i++) {
        cin >> pts[i].x >> pts[i].y;
    }

    double minDist = 1e18;  // 初始化为一个很大的值
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            double d = distance(pts[i], pts[j]);
            if (d < minDist) {
                minDist = d;
            }
        }
    }

    printf("%.2f\n", minDist);
    return 0;
}
```

## 🎯 本课小结

本节课学习了 C++ 中结构体的核心知识：

1. **结构体的定义**：使用 `struct` 关键字，将多个相关数据组合成一个新的数据类型。注意定义末尾的分号！

2. **成员访问**：通过点运算符 `.` 访问结构体的成员变量，可以读取也可以修改。

3. **初始化方式**：支持逐个赋值、初始化列表、C++11 统一初始化等多种方式。

4. **结构体数组**：可以像普通数组一样定义结构体数组，方便批量管理相同类型的数据。

5. **结构体排序**：使用 `sort()` 配合自定义比较函数 `cmp` 实现按任意字段排序，这是 CSP-J 的高频考点。记住比较函数需要返回 `bool`，参数使用 `const &`。

6. **函数参数传递**：值传递会复制整个结构体，推荐使用 `const &` 引用传递来提高效率。如需修改原始数据，使用非 `const` 引用。

7. **嵌套结构体**：结构体中可以包含另一个结构体，通过多级点运算符访问。

掌握了结构体，你就能更好地组织和处理复杂的数据，为后续学习链表、树等数据结构打下坚实基础。
