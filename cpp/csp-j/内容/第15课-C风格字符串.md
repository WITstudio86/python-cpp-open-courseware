## 📖 知识精讲

### 一、C 风格字符串的本质

在 C++ 中，C 风格字符串本质上是一个**以空字符 `'\0'` 结尾的 `char` 数组**。`'\0'` 的 ASCII 码值为 0，不属于可见字符，却是所有 C 字符串函数判断结束位置的唯一依据。

例如字符串 `"hello"` 在内存中实际占用 **6** 个字节：

```
下标:  0   1   2   3   4   5
内容: 'h' 'e' 'l' 'l' 'o' '\0'
```

```cpp
char s1[100] = "hello";  // 自动在末尾添加 '\0'
// 内存: h e l l o \0 [剩余单元为 '\0' 或未使用]

char s2[] = "world";     // 编译器自动计算大小：6（5个字符 + '\0'）

char s3[6] = {'h', 'e', 'l', 'l', 'o', '\0'};  // 必须手动加 '\0'
char s4[5] = {'h', 'e', 'l', 'l', 'o'};         // 错误！没有 '\0'
```

**核心要点**：如果忘记 `'\0'`，`strlen` / `strcpy` / `cout << s` 会一直向后读内存，直到碰巧遇到 0 字节——结果不可预测，甚至崩溃。

### 二、`'\0'` 结束符的作用与重要性

所有标准字符串函数都依赖 `'\0'`：

1. **`strlen(s)`**：向后计数，遇 `'\0'` 停止，返回长度（不含 `'\0'`）。
2. **`strcpy(dest, src)`**：复制直到 `'\0'`（包含 `'\0'`）。
3. **`strcmp(s1, s2)`**：逐字符比较，遇不相等或 `'\0'` 停止。
4. **`cout << s`**：输出到 `'\0'` 为止。

```cpp
char s[5] = {'h', 'e', 'l', 'l', 'o'};  // 没有 '\0'！
// cout << strlen(s);  // 危险：未定义行为
// cout << s;          // 危险：可能输出乱码
```

**正确做法**：数组大小至少 **字符串长度 + 1**。

```cpp
char s[6] = "hello";   // 正确
char s[100] = "hello"; // 更安全：便于后续拼接
```

### 三、字符串的声明与初始化

```cpp
// 方式1：字符串字面量（最常用）
char name[20] = "Alice";    // 自动 '\0'，其余也是 '\0'

// 方式2：不指定大小，编译器推导
char greeting[] = "Hello, World!";  // 14 = 13 + 1

// 方式3：先声明后赋值（不能直接 = 赋值！）
char city[20];
// city = "Beijing";           // 错误！数组名不能赋值
strcpy(city, "Beijing");       // 正确

// 方式4：逐字符初始化
char code[5] = {'A', 'B', 'C', 'D', '\0'};

// 方式5：未初始化
char buffer[100];  // 垃圾值，使用前必须写入有效字符串
```

**字符 vs 字符串字面量**

```cpp
char c = 'A';     // 单引号：一个字符
char s[] = "A";   // 双引号：两个单元 'A' 和 '\0'
```

### 四、字符串的输入与输出

#### 1. `cin >> s`

遇到**空格、Tab、换行**等空白就停止，**不能**读含空格的句子。

```cpp
char s[100];
cin >> s;         // 输入 "Hello World"，s 只有 "Hello"
cout << s;        // Hello
```

#### 2. `cin.getline(s, size)`

读取整行（可含空格），遇换行结束，自动加 `'\0'`。第二个参数表示最多读 `size-1` 个字符。

```cpp
char s[100];
cin.getline(s, 100);  // "Hello World" 完整读入
```

#### 3. `gets(s)` —— 已废弃！

`gets` 不检查缓冲区大小，输入过长会**缓冲区溢出**。C++11 已移除。**绝对不要用！**

#### 4. `fgets(s, size, stdin)`（了解）

C 风格安全读行函数：

```cpp
#include <cstdio>
char s[100];
fgets(s, 100, stdin);  // 可能把换行符 '\n' 也读进来
// 若需要去掉末尾换行：
int len = strlen(s);
if (len > 0 && s[len - 1] == '\n') s[len - 1] = '\0';
```

竞赛 C++ 中更常用 `cin.getline`。

#### 5. `puts(s)`

输出字符串并**自动换行**，约等于 `cout << s << endl;`。

#### 6. 混用 `cin >>` 与 `getline` 的坑

```cpp
int n;
cin >> n;           // 数字后留下换行符
cin.getline(s, 100); // 立刻读到空行！

// 正确：先吃掉换行
cin >> n;
cin.ignore();       // 或 cin.ignore(1024, '\n');
cin.getline(s, 100);
```

### 五、常用字符串函数详解

头文件：`#include <cstring>`（推荐）或 `#include <string.h>`。

#### 1. `strlen(s)` —— 长度

```cpp
char s[] = "Hello";
cout << strlen(s);  // 5，不含 '\0'
```

| 对比 | `strlen(s)` | `sizeof(s)` |
|------|-------------|-------------|
| 含义 | 实际字符数 | 数组总字节数 |
| 是否含 `'\0'` | 否 | 是（若 s 是数组） |
| 计算时机 | 运行时扫描 | 编译期 |

```cpp
char s[100] = "abc";
// strlen(s) == 3
// sizeof(s) == 100
```

若 `s` 是指针，`sizeof(s)` 是指针宽度（4/8），**绝不是**字符串长度。

#### 2. `strcpy(dest, src)` —— 拷贝

将 `src`（含 `'\0'`）复制到 `dest`。**目标必须足够大**。

```cpp
char src[] = "Hello";
char dest[20];
strcpy(dest, src);
strcpy(dest, "World");
```

注意：`strcpy` 会覆盖 dest 原内容。

#### 3. `strcat(dest, src)` —— 拼接

把 `src` 追加到 `dest` 末尾（覆盖 dest 原 `'\0'`，再写新 `'\0'`）。

```cpp
char s[50] = "Hello";
strcat(s, " ");
strcat(s, "World");  // "Hello World"
```

容量需求：`strlen(dest) + strlen(src) + 1 ≤ 数组大小`。

#### 4. `strcmp(s1, s2)` —— 比较

按字典序（ASCII）比较：

| 返回值 | 含义 |
|--------|------|
| `0` | 相等 |
| `> 0` | s1 > s2 |
| `< 0` | s1 < s2 |

```cpp
strcmp("abc", "abc");  // 0
strcmp("abc", "abd");  // <0  ('c'<'d')
strcmp("abd", "abc");  // >0
strcmp("ab", "abc");   // <0  (短的更小)
```

> **易错**：`if (strcmp(s1, s2))` 在**相等时为假**！  
> 正确：`if (strcmp(s1, s2) == 0)`。

不要写 `if (s1 == s2)`——那是比较**地址**，不是内容。

#### 5. 其他常用（了解）

```cpp
strncpy(dest, src, n);  // 最多拷 n 个字符（注意是否补 '\0'）
strncmp(s1, s2, n);     // 只比较前 n 个
strchr(s, 'a');         // 查找字符，返回指针
strstr(s, "ab");        // 查找子串
```

CSP-J 重点仍是前四个。

### 六、字符判断与遍历技巧

```cpp
char s[100];
cin >> s;
int len = strlen(s);

for (int i = 0; i < len; i++) {
    char c = s[i];
    if (c >= '0' && c <= '9') { /* 数字 */ }
    if (c >= 'a' && c <= 'z') { /* 小写 */ }
    if (c >= 'A' && c <= 'Z') { /* 大写 */ }
}

// 大小写转换
// 小写 -> 大写：c = c - 'a' + 'A';  或 c -= 32;（仅限小写）
// 大写 -> 小写：c = c - 'A' + 'a';
```

也可使用 `<cctype>`：`isdigit` / `isalpha` / `islower` / `toupper` 等。

### 七、回文判断

**回文**：正读反读相同，如 `"level"`、`"radar"`、`"12321"`。

**双指针**：`i` 从头，`j` 从尾，向中间靠拢比较。

```cpp
bool isPalindrome(char s[]) {
    int len = strlen(s);
    for (int i = 0, j = len - 1; i < j; i++, j--) {
        if (s[i] != s[j]) return false;
    }
    return true;
}
```

- 时间 O(n)，空间 O(1)
- 空串、单字符都是回文
- 若题目忽略大小写，先统一转换再判断

**手算** `"level"`：

| i | j | s[i] | s[j] | 结果 |
|---|---|------|------|------|
| 0 | 4 | l | l | 同 |
| 1 | 3 | e | e | 同 |
| 2 | 2 | 停止 | | 是回文 |

### 八、字符串反转与复制手写版

不依赖库时也能写：

```cpp
// 反转
void reverseStr(char s[]) {
    int n = strlen(s);
    for (int i = 0; i < n / 2; i++) {
        char t = s[i];
        s[i] = s[n - 1 - i];
        s[n - 1 - i] = t;
    }
}

// 手写 strlen
int my_strlen(char s[]) {
    int i = 0;
    while (s[i] != '\0') i++;
    return i;
}

// 手写 strcmp
int my_strcmp(char a[], char b[]) {
    int i = 0;
    while (a[i] && b[i] && a[i] == b[i]) i++;
    return (unsigned char)a[i] - (unsigned char)b[i];
}
```

理解手写版有助于真正搞懂 `'\0'` 驱动的逻辑。

### 九、与 `string` 的关系（预习）

| 对比 | C 风格 `char[]` | `std::string` |
|------|-----------------|---------------|
| 结束标记 | 必须 `'\0'` | 自带长度 |
| 赋值 | 用 `strcpy` | 可 `s = t` |
| 拼接 | `strcat` | `s += t` |
| 比较 | `strcmp` | `s == t` / `<` |
| 安全性 | 易越界 | 更安全 |

下一课系统学 `string`；本课先把底层规则打牢。

### 模板四：统计各类字符

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char s[110];
    cin.getline(s, 110);
    int digit = 0, lower = 0, upper = 0, space = 0, other = 0;
    for (int i = 0; s[i]; i++) {  // 等价于 i < strlen，但不必每次算
        char ch = s[i];
        if (ch >= '0' && ch <= '9') digit++;
        else if (ch >= 'a' && ch <= 'z') lower++;
        else if (ch >= 'A' && ch <= 'Z') upper++;
        else if (ch == ' ') space++;
        else other++;
    }
    cout << digit << " " << lower << " " << upper << " "
         << space << " " << other << endl;
    return 0;
}
```

## ⚠️ 易错点

1. **忘记为 `'\0'` 预留空间**  
   - `char s[5] = "hello";` 错误（需要 6）。  
   - 正确：`char s[6] = "hello";` 或更大。

2. **`strcmp` 返回 int 不是 bool**  
   - 相等返回 0。  
   - 写 `if (strcmp(s1, s2) == 0)`。

3. **`gets` 不安全，已移除**  
   - 用 `cin.getline(s, size)` 或 `fgets`。

4. **`strcpy` / `strcat` 目标太小**  
   - 缓冲区溢出，极难查的 RE/WA。

5. **`strlen` 与 `sizeof` 混淆**  
   - 长度用 `strlen`；数组容量才是 `sizeof`（数组名）。

6. **不能对数组直接 `=` 赋值**  
   - 用 `strcpy`。

7. **`cin >>` 与 `getline` 混用**  
   - 中间要 `cin.ignore()` 吃掉换行。

8. **比较内容写成 `s1 == s2`**  
   - 那是指针/地址比较。

9. **`fgets` 残留 `'\n'`**  
   - 记得去掉再处理长度/回文。

10. **中文等多字节字符**  
    - `strlen` 计的是字节数不是“字符个数”；CSP-J 一般考 ASCII。

## 📝 真题精练

### 真题1：统计字符串中数字字符的个数

**题目描述**  
给定一个长度不超过 100 的字符串（可能包含空格），统计其中数字字符（`'0'`~`'9'`）出现的次数。

**输入格式**  
一行，一个字符串，长度不超过 100。

**输出格式**  
一个整数，表示数字字符的数量。

**样例输入**
```
Hello123 World456
```

**样例输出**
```
6
```

**思路**  
整行读入 → 遍历每个字符 → 判断是否在 `'0'`~`'9'`。

**AC 代码**

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char s[110];
    cin.getline(s, 110);

    int cnt = 0;
    int len = strlen(s);
    for (int i = 0; i < len; i++) {
        if (s[i] >= '0' && s[i] <= '9') {
            cnt++;
        }
    }
    cout << cnt << endl;
    return 0;
}
```

**解析**

1. 含空格必须用 `getline`。  
2. 用 `strlen` 或 `s[i] != '\0'` 控制循环。  
3. 数字判断用字符范围，不要写成 `s[i] >= 0 && s[i] <= 9`（那是数值）。

### 真题2：验证回文

**题目描述**  
给定由小写字母组成的字符串，判断是否回文。是则输出 `yes`，否则 `no`。

**输入格式**  
一行，小写字母字符串，长度不超过 100。

**输出格式**  
`yes` 或 `no`。

**样例输入1**
```
level
```

**样例输出1**
```
yes
```

**样例输入2**
```
hello
```

**样例输出2**
```
no
```

**AC 代码**

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char s[110];
    cin >> s;

    int len = strlen(s);
    bool flag = true;
    for (int i = 0, j = len - 1; i < j; i++, j--) {
        if (s[i] != s[j]) {
            flag = false;
            break;
        }
    }

    if (flag) cout << "yes" << endl;
    else cout << "no" << endl;
    return 0;
}
```

**解析**

1. 双指针 `i` 增、`j` 减。  
2. `i < j` 避免重复与无效比较。  
3. 一旦失配立即 `break`。

### 例题3：字符串拼接与比较

**题目描述**  
输入两个不含空格的字符串 a、b（长度均 ≤ 50）。  
输出三行：  
1. `a` 与 `b` 拼接结果；  
2. 拼接后长度；  
3. 若 a 的字典序小于 b 输出 `<`，相等输出 `=`，大于输出 `>`。

**样例输入**
```
cloud
code
```

**样例输出**
```
cloudcode
9
<
```

**AC 代码**

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char a[60], b[60], c[120];
    cin >> a >> b;

    strcpy(c, a);
    strcat(c, b);
    cout << c << endl;
    cout << strlen(c) << endl;

    int cmp = strcmp(a, b);
    if (cmp < 0) cout << "<" << endl;
    else if (cmp > 0) cout << ">" << endl;
    else cout << "=" << endl;
    return 0;
}
```

## 🎯 本课小结

1. **本质**：C 风格字符串 = 以 `'\0'` 结尾的 `char` 数组。  
2. **空间**：长度 + 1；拼接预留更大缓冲。  
3. **输入**：`cin >>` 遇空白停；`cin.getline` 读整行；禁用 `gets`。  
4. **四函数**：`strlen` 长度、`strcpy` 拷贝、`strcat` 拼接、`strcmp` 比较（0 表示相等）。  
5. **回文**：双指针 O(n)/O(1)，高频考点。  
6. **安全**：目标数组够大；混用输入注意 `ignore`；不要用 `==` 比内容。

**一句话记忆**：有 `'\0'` 才是 C 字符串；比内容用 `strcmp==0`；回文两端往中间夹。

下一课学习 `std::string`，写法会更轻松，但本课概念依然是底层基础。
