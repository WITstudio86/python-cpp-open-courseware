## 📖 知识精讲

### 一、C 风格字符串的本质

在 C++ 中，C 风格字符串本质上是一个**以空字符 `'\0'` 结尾的 `char` 数组**。`'\0'` 的 ASCII 码值为 0，它不属于可见字符，但却是所有 C 字符串函数判断字符串结束位置的唯一依据。例如字符串 `"hello"` 在内存中实际占用 6 个字节：`'h'`、`'e'`、`'l'`、`'l'`、`'o'`、`'\0'`。

```cpp
char s1[100] = "hello";  // 自动在末尾添加 '\0'
// 内存: h e l l o \0 [剩余 94 个未使用单元]

char s2[] = "world";     // 编译器自动计算大小：6（5个字符 + '\0'）

char s3[6] = {'h', 'e', 'l', 'l', 'o', '\0'};  // 逐个字符初始化，必须手动加 '\0'
char s4[5] = {'h', 'e', 'l', 'l', 'o'};         // 错误！没有 '\0'，不是合法字符串
```

**核心要点**：如果忘记在字符数组末尾添加 `'\0'`，使用 `strlen`、`strcpy`、`cout` 等操作时，程序会一直向后读取内存直到碰巧遇到一个值为 0 的字节，这会导致不可预测的结果甚至程序崩溃。

### 二、`'\0'` 结束符的作用与重要性

`'\0'` 是 C 风格字符串的灵魂。所有标准字符串函数都依赖它来判断字符串是否结束：

1. **`strlen(s)`**：从 `s` 开始向后计数，遇到 `'\0'` 停止，返回计数值（不包含 `'\0'`）。
2. **`strcpy(dest, src)`**：将 `src` 中的字符逐个复制到 `dest`，直到遇到 `'\0'`（`'\0'` 也会被复制）。
3. **`strcmp(s1, s2)`**：从两个字符串的首字符开始逐个比较 ASCII 码值，遇到 `'\0'` 或不相等的字符时停止。
4. **`cout << s`**：输出从 `s` 开始的每个字符，遇到 `'\0'` 停止。

如果没有 `'\0'`，上述所有操作都会发生**越界访问**，这是 C 风格字符串最常见的错误来源。

```cpp
char s[5] = {'h', 'e', 'l', 'l', 'o'};  // 没有 '\0'！
cout << strlen(s);  // 危险！会一直向后扫描，返回一个不可预测的值
cout << s;          // 危险！可能会输出乱码
```

**正确的做法**：声明字符数组时，数组大小至少要等于**字符串长度 + 1**，为 `'\0'` 预留一个位置。

```cpp
char s[6] = "hello";   // 正确：5个字符 + '\0' = 6字节
char s[100] = "hello"; // 更安全：预留足够空间，便于后续拼接操作
```

### 三、字符串的声明与初始化

C 风格字符串有多种声明方式，各有适用场景：

```cpp
// 方式1：用字符串字面量初始化（最常用）
char name[20] = "Alice";    // 自动添加 '\0'，其余位置初始化为 '\0'

// 方式2：不指定大小，编译器自动推导
char greeting[] = "Hello, World!";  // 大小为 14（13字符 + '\0'）

// 方式3：先声明后赋值（不能直接用 = 赋值！）
char city[20];
// city = "Beijing";           // 错误！数组名是常量指针，不能赋值
strcpy(city, "Beijing");       // 正确：使用 strcpy

// 方式4：逐个字符初始化
char code[5] = {'A', 'B', 'C', 'D', '\0'};  // 必须手动加 '\0'

// 方式5：声明但不初始化（内容未定义）
char buffer[100];  // 内容是随机的，使用前需初始化
```

### 四、字符串的输入与输出

#### 1. `cin >> s`

使用 `cin >>` 读取字符串时，遇到**空格、Tab、换行**等空白字符就会停止。因此它无法读取包含空格的字符串。

```cpp
char s[100];
cin >> s;         // 输入 "Hello World"，s 中只存储 "Hello"
cout << s;        // 输出 "Hello"
```

#### 2. `cin.getline(s, size)`

`cin.getline(字符数组, 最大字符数)` 可以读取**包含空格的整行**，直到遇到换行符，且会自动添加 `'\0'`。第二个参数指定最多读取 `size - 1` 个字符（为 `'\0'` 预留一位）。

```cpp
char s[100];
cin.getline(s, 100);  // 输入 "Hello World"，s 中存储完整的 "Hello World"
```

#### 3. `gets(s)` —— 已废弃！

`gets(s)` 不检查缓冲区大小，如果输入超过数组容量会导致**缓冲区溢出**，是严重的安全漏洞。C++11 已将其移除。**绝对不要使用！**

#### 4. `puts(s)`

`puts(s)` 输出字符串并**自动换行**，等价于 `cout << s << endl;`。

```cpp
char s[] = "Hello";
puts(s);   // 输出 "Hello" 并换行
```

### 五、常用字符串函数详解

使用这些函数需要包含头文件 `#include <cstring>`（C++ 风格）或 `#include <string.h>`（C 风格）。

#### 1. `strlen(s)` —— 求字符串长度

计算字符串中字符的个数，**不包含 `'\0'`**。

```cpp
char s[] = "Hello";
cout << strlen(s);  // 输出 5，不计算 '\0'
```

**注意**：`strlen` 和 `sizeof` 的区别——`sizeof(s)` 返回数组的总字节数（包含 `'\0'`），对于上例 `sizeof(s)` 为 6。

#### 2. `strcpy(dest, src)` —— 字符串拷贝

将 `src` 的内容（包括 `'\0'`）复制到 `dest`。**目标数组必须足够大**，否则会越界。

```cpp
char src[] = "Hello";
char dest[20];
strcpy(dest, src);  // dest 现在也是 "Hello"
strcpy(dest, "World");  // 也可以直接用字面量
```

#### 3. `strcat(dest, src)` —— 字符串拼接

将 `src` 的内容追加到 `dest` 末尾（覆盖 `dest` 原来的 `'\0'`，并在新末尾添加 `'\0'`）。**目标数组必须有足够空间容纳拼接后的结果**。

```cpp
char s[50] = "Hello";   // 必须足够大！
strcat(s, " ");          // s = "Hello "
strcat(s, "World");      // s = "Hello World"
```

#### 4. `strcmp(s1, s2)` —— 字符串比较

按**字典序**（ASCII 码）逐字符比较两个字符串。返回值含义：

| 返回值 | 含义 |
|--------|------|
| `0` | `s1` 和 `s2` 完全相等 |
| `> 0`（正数） | `s1` 的字典序大于 `s2` |
| `< 0`（负数） | `s1` 的字典序小于 `s2` |

比较机制：从两个字符串的首字符开始，逐一比较对应位置的 ASCII 码值。如果发现不相等的字符，直接返回它们的差值；如果一直相等且同时遇到 `'\0'`，说明两字符串完全相同，返回 0；如果一方先遇到 `'\0'`，则较短的那一方字典序更小。

```cpp
cout << strcmp("abc", "abc") << endl;   // 输出 0（相等）
cout << strcmp("abc", "abd") << endl;   // 输出负数（'c' < 'd'）
cout << strcmp("abd", "abc") << endl;   // 输出正数（'d' > 'c'）
cout << strcmp("ab", "abc") << endl;    // 输出负数（短字符串更小）
```

> **易错提醒**：`strcmp` 返回 `int` 而非 `bool`！`if (strcmp(s1, s2))` 在字符串相等时条件为假（返回 0），不等时为真——这恰恰和直觉相反。正确写法：`if (strcmp(s1, s2) == 0)`。

### 六、回文判断

**回文**是指正读和反读都一样的字符串，如 `"level"`、`"radar"`、`"12321"`。

**双指针算法**：设置两个指针 `i`（从头向后）和 `j`（从尾向前），逐对比较 `s[i]` 与 `s[j]`，只要有一对不相等就不是回文。循环终止条件是 `i >= j`。

时间复杂度 O(n)，空间复杂度 O(1)。

```cpp
bool isPalindrome(char s[]) {
    int len = strlen(s);
    for (int i = 0, j = len - 1; i < j; i++, j--) {
        if (s[i] != s[j]) {
            return false;
        }
    }
    return true;
}
```

```cpp
#include <iostream>
#include <cstring>
using namespace std;

bool isPalindrome(char s[]) {
    int len = strlen(s);
    for (int i = 0, j = len - 1; i < j; i++, j--) {
        if (s[i] != s[j]) return false;
    }
    return true;
}

int main() {
    char s[100];
    cin >> s;  // 回文判断通常不含空格
    if (isPalindrome(s))
        cout << "yes" << endl;
    else
        cout << "no" << endl;
    return 0;
}
```

### 字符串拼接模板

```cpp
#include <iostream>
#include <cstring>

int main() {

    cin.ignore();             // 吸收数字后的换行符
```

## ⚠️ 易错点

1. **忘记为 `'\0'` 预留空间导致越界**
   - `char s[5] = "hello";` 是**错误的**！"hello" 实际需要 6 字节（5+1），数组大小不够。
   - 正确写法：`char s[6] = "hello";` 或 `char s[100] = "hello";`

2. **`strcmp` 返回值不是 `bool` 而是 `int`**
   - `0` 表示相等，非 0 表示不等。
   - `if (strcmp(s1, s2))` 在相等时条件为假，容易写反。
   - 推荐写法：`if (strcmp(s1, s2) == 0)` 明确表达意图。

3. **`gets` 不安全，已从 C++11 移除**
   - 使用 `cin.getline(s, size)` 或 `fgets(s, size, stdin)` 替代。

4. **`strcpy` / `strcat` 目标数组必须足够大**
   - 目标数组过小会导致**缓冲区溢出**，覆盖相邻内存，引发难以排查的错误。
   - 使用前确保目标数组容量 = 源字符串长度 + 已有内容长度 + 1（`'\0'`）。

5. **`strlen` 与 `sizeof` 的区别**
   - `strlen(s)` 返回字符串长度（不含 `'\0'`），运行时计算。
   - `sizeof(s)` 返回数组总字节数（含 `'\0'`），编译时计算。
   - 对于指针，`sizeof(ptr)` 返回指针大小（通常 4 或 8），而非字符串长度。

## 📝 真题精练

### 真题1：统计字符串中数字字符的个数

**题目描述**：
给定一个长度不超过 100 的字符串（可能包含空格），统计其中数字字符（'0'~'9'）出现的次数。

**输入格式**：
一行，一个字符串，长度不超过 100。

**输出格式**：
一个整数，表示数字字符的数量。

**样例输入**：
```
Hello123 World456
```

**样例输出**：
```
6
```

**AC 代码**：

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char s[110];
    cin.getline(s, 110);
    
    int cnt = 0;
    int len = strlen(s);
    for (int i = 0; i < len; i++) {
        if (s[i] >= '0' && s[i] <= '9') {
            cnt++;
        }
    }
    cout << cnt << endl;
    return 0;
}
```

**代码解析**：
1. 使用 `cin.getline` 读取包含空格的整行字符串。
2. 用 `strlen(s)` 获取字符串实际长度，精确控制循环次数。
3. 通过 ASCII 码范围判断 `s[i] >= '0' && s[i] <= '9'` 判断字符是否为数字。

### 真题2：验证回文

**题目描述**：
给定一个由小写字母组成的字符串，判断它是否是回文字符串。如果是，输出 "yes"；否则输出 "no"。

**输入格式**：
一行，一个由小写字母组成的字符串，长度不超过 100。

**输出格式**：
"yes" 或 "no"。

**样例输入1**：
```
level
```

**样例输出1**：
```
yes
```

**样例输入2**：
```
hello
```

**样例输出2**：
```
no
```

**AC 代码**：

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char s[110];
    cin >> s;
    
    int len = strlen(s);
    bool flag = true;
    for (int i = 0, j = len - 1; i < j; i++, j--) {
        if (s[i] != s[j]) {
            flag = false;
            break;
        }
    }
    
    if (flag)
        cout << "yes" << endl;
    else
        cout << "no" << endl;
    return 0;
}
```

**代码解析**：
1. 使用双指针 `i` 从头向尾，`j` 从尾向头，同时移动。
2. 循环条件 `i < j`：当两个指针相遇或交错时停止，避免重复比较。
3. 一旦发现 `s[i] != s[j]`，立即设置 `flag = false` 并 `break` 退出循环。

## 🎯 本课小结

1. **C 风格字符串本质**：以 `'\0'` 结尾的 `char` 数组，所有标准函数依赖 `'\0'` 判断结束。
2. **数组大小**：声明时必须为 `'\0'` 预留一个位置，建议声明时留足余量以支持后续操作。
3. **输入方式**：`cin >> s` 遇空格停止；`cin.getline(s, size)` 可读取整行含空格；**禁止使用 `gets`**。
4. **核心函数**：`strlen`（长度）、`strcpy`（拷贝）、`strcat`（拼接）、`strcmp`（比较，返回 int 非 bool）。
5. **回文判断**：双指针法，O(n) 时间，O(1) 空间——这是信息学竞赛中的高频考点。
6. **安全第一**：使用 `strcpy`/`strcat` 前确保目标数组容量足够，避免缓冲区溢出。
