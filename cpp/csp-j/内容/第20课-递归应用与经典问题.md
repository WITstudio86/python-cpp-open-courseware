## 📖 知识精讲

递归是计算机科学中最优美的思想之一。它的核心在于：一个函数直接或间接地调用自身，将原问题分解为一个或多个规模更小但结构相同的子问题，直到子问题简单到可以直接求解（即递归边界或基线条件）。递归的强大之处在于，它能用极其简洁的代码表达复杂的逻辑，许多看似困难的问题（如汉诺塔、排列组合、树的遍历）用递归来表达都变得一目了然。本节我们将通过几个经典问题，深入探讨递归的应用技巧与注意事项。

递归函数的设计通常遵循三个步骤。第一步：明确函数的定义与功能 —— 这个函数接收什么参数，完成什么任务。第二步：确定递归边界（基线条件）—— 规模小到何种程度时可以直接给出答案而无需继续递归。第三步：写出递推关系 —— 如何将当前规模的问题转化为一个或多个规模更小的同类问题，并利用子问题的结果构造出当前问题的解。这三个步骤贯穿了所有递归算法设计，熟练掌握它们是写出正确递归程序的关键。

### 1. 汉诺塔问题

汉诺塔（Tower of Hanoi）是递归思想的经典体现。问题描述如下：有三根柱子 A、B、C，其中 A 柱上套有 n 个大小不等的圆盘，大盘在下、小盘在上。要求将所有圆盘从 A 柱移动到 C 柱，移动过程中必须遵守以下规则：（1）每次只能移动一个圆盘；（2）任何时候大盘不能放在小盘上面；（3）可以使用 B 柱作为辅助。

表面上看，移动 n 个盘子似乎非常复杂，但递归的思想让问题变得清晰。我们要完成的任务是：将 n 个盘子从 A 移动到 C（以 B 为辅助）。这个任务可以分解为三个步骤。

第一步：将 A 柱上面 n-1 个盘子（看作一个整体）从 A 移动到 B（以 C 为辅助）。这恰好是原问题规模缩小 1 的子问题 —— 把 n-1 个盘子从一根柱子移动到另一根柱子。

第二步：将 A 柱剩下的最大的那个盘子（第 n 个）直接从 A 移动到 C。这是一步简单的操作，不需要递归。

第三步：将 B 柱上的 n-1 个盘子从 B 移动到 C（以 A 为辅助）。这又是一个规模为 n-1 的子问题。

当 n = 1 时，直接将唯一的盘子从源柱移动到目标柱，这就是递归边界。

按照上述策略，移动 n 个盘子所需的总步数 T(n) 满足递推公式：T(1) = 1，T(n) = T(n-1) + 1 + T(n-1) = 2T(n-1) + 1。展开可得：T(n) = 2^n - 1。

让我们以 n = 3 为例，完整追踪整个移动过程。初始状态：A 柱从上到下为 [1, 2, 3]（1 最小，3 最大），B 柱为空，C 柱为空。

第 1 步：将盘子 1 从 A 移动到 C（将 n-1=2 个盘子从 A 移到 B 的第一步）。
第 2 步：将盘子 2 从 A 移动到 B。
第 3 步：将盘子 1 从 C 移动到 B（此时 A 顶部的 n-1=2 个盘子都已移到 B）。
第 4 步：将盘子 3 从 A 移动到 C（最大的盘子直接到位）。
第 5 步：将盘子 1 从 B 移动到 A（将 B 上的 n-1=2 个盘子移到 C 的第一步）。
第 6 步：将盘子 2 从 B 移动到 C。
第 7 步：将盘子 1 从 A 移动到 C（所有盘子就位，共 2^3 - 1 = 7 步）。

下面是完整的 C++ 实现，包含步数统计：

```cpp
#include <iostream>
using namespace std;

int steps = 0;

// 将 n 个盘子从 src 移动到 dst，以 aux 为辅助
void hanoi(int n, char src, char aux, char dst) {
    if (n == 1) {
        steps++;
        cout << "第 " << steps << " 步：将盘子 " << n 
             << " 从 " << src << " 移动到 " << dst << endl;
        return;
    }
    // 第一步：将 n-1 个盘子从 src 移到 aux（以 dst 为辅助）
    hanoi(n - 1, src, dst, aux);
    // 第二步：将最大的盘子从 src 移到 dst
    steps++;
    cout << "第 " << steps << " 步：将盘子 " << n 
         << " 从 " << src << " 移动到 " << dst << endl;
    // 第三步：将 n-1 个盘子从 aux 移到 dst（以 src 为辅助）
    hanoi(n - 1, aux, src, dst);
}

int main() {
    int n;
    cin >> n;
    hanoi(n, 'A', 'B', 'C');
    cout << "总共移动了 " << steps << " 步，理论值 2^" << n 
         << " - 1 = " << (1 << n) - 1 << endl;
    return 0;
}
```

对于 n = 3，程序输出与上面的手动追踪完全一致，步数为 7。对于 n = 64（传说中的世界末日问题），步数为 2^64 - 1，即使每秒移动一次也需要约 5800 亿年。

### 2. 辗转相除法求 GCD

辗转相除法，又称欧几里得算法（Euclidean Algorithm），是求两个正整数最大公约数（GCD）的最古老且最高效的算法。其核心原理基于一条简洁的数学性质：gcd(a, b) = gcd(b, a % b)，其中 a % b 表示 a 除以 b 的余数。当 b = 0 时，gcd(a, 0) = a，这是递归的终止条件。

这条性质的正确性可以这样理解：设 d 是 a 和 b 的任意公约数，即 d | a 且 d | b。将 a 写成 a = qb + r，其中 r = a % b（0 ≤ r < b）。那么 r = a - qb。由于 d 同时整除 a 和 b，所以 d 也整除 a - qb = r。因此 d 也是 b 和 r 的公约数。反之，若 d 整除 b 和 r，由于 a = qb + r，d 也整除 a。所以（a, b）的公约数集合与（b, r）的公约数集合完全相同，它们的最大公约数自然相等。

举个例子：求 gcd(48, 18)：
- gcd(48, 18)：48 % 18 = 12，转化为 gcd(18, 12)
- gcd(18, 12)：18 % 12 = 6，转化为 gcd(12, 6)
- gcd(12, 6)：12 % 6 = 0，转化为 gcd(6, 0)
- gcd(6, 0) = 6，所以 gcd(48, 18) = 6。

递归实现的代码极其简洁：

```cpp
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
```

迭代版本同样清晰，而且避免了递归调用的栈开销：

```cpp
int gcd_iter(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
```

关于时间复杂度：可以证明，每经过两次迭代（或递归），较小的那个数至少减半。因此算法的递归深度或迭代次数不超过 2 × log_2(min(a, b))，即 O(log min(a, b))。即使对于 10^18 级别的大整数，也只需要约 60 步就能得到答案，效率极高。

C++ 标准库中也提供了 `__gcd(a, b)` 函数（位于 `<algorithm>` 头文件，GCC 编译器支持），其内部实现正是辗转相除法。

### 3. 二分查找的递归实现

二分查找（Binary Search）是信息学竞赛中最常用的算法之一。虽然它通常用迭代方式实现，但递归版本更能体现"分治"的思想，也更容易与更复杂的分治算法（如归并排序、快速排序）建立联系。

二分查找的递归思路：在有序数组的区间 [left, right] 内查找目标值 target。计算中间位置 mid = (left + right) / 2（或 left + (right - left) / 2 以防止溢出）。如果 arr[mid] == target，查找成功，返回 mid；如果 arr[mid] > target，说明 target 只可能在左半部分，递归在 [left, mid-1] 中查找；如果 arr[mid] < target，说明 target 只可能在右半部分，递归在 [mid+1, right] 中查找。当 left > right 时，区间为空，查找失败，返回 -1。

递归二分查找的关键在于正确处理边界条件。每次递归调用时区间必须严格缩小（mid-1 或 mid+1），否则可能陷入无限递归。此外，`mid = left + (right - left) / 2` 的写法在 left 和 right 都很大时能避免整数溢出。

下面以在有序数组 {1, 3, 5, 7, 9, 11, 13} 中查找 target = 7 为例，追踪递归过程。

初始调用：binarySearch(arr, 0, 6, 7)
- left = 0, right = 6, mid = 3, arr[3] = 7 == target，直接返回 mid = 3，查找成功。

再以查找 target = 5 为例：
- 第 1 层：left = 0, right = 6, mid = 3, arr[3] = 7 > 5，递归调用 binarySearch(arr, 0, 2, 5)
- 第 2 层：left = 0, right = 2, mid = 1, arr[1] = 3 < 5，递归调用 binarySearch(arr, 2, 2, 5)
- 第 3 层：left = 2, right = 2, mid = 2, arr[2] = 5 == target，返回 mid = 2。

查找 target = 4（不存在）为例：
- 第 1 层：left = 0, right = 6, mid = 3, arr[3] = 7 > 4，递归调用 binarySearch(arr, 0, 2, 4)
- 第 2 层：left = 0, right = 2, mid = 1, arr[1] = 3 < 4，递归调用 binarySearch(arr, 2, 2, 4)
- 第 3 层：left = 2, right = 2, mid = 2, arr[2] = 5 > 4，递归调用 binarySearch(arr, 2, 1, 4)
- 第 4 层：left = 2, right = 1, left > right，返回 -1。

完整的递归二分查找代码如下：

```cpp
int binarySearch(int arr[], int left, int right, int target) {
    if (left > right) return -1;  // 查找失败
    int mid = left + (right - left) / 2;  // 防止溢出
    if (arr[mid] == target) return mid;
    if (arr[mid] > target)
        return binarySearch(arr, left, mid - 1, target);
    else
        return binarySearch(arr, mid + 1, right, target);
}
```

### 4. 回溯算法初步 —— 全排列

回溯算法（Backtracking）是一种系统地搜索问题解空间的方法，它的基本思想是：在解空间中逐步构建候选解，当发现当前路径不可能得到有效解时，就"回溯"到上一步，尝试其他选择。回溯算法通常用递归来实现，递归函数代表了搜索树中的一个节点，函数的参数记录了当前状态。

回溯算法的经典模板如下：

```cpp
void backtrack(当前状态) {
    if (当前状态是终止条件) {
        记录或输出解;
        return;
    }
    for (所有可能的选择) {
        if (选择合法) {
            做出选择;
            backtrack(更新后的状态);
            撤销选择;  // 回溯的关键步骤！
        }
    }
}
```

全排列问题是回溯算法最典型的应用。给定 n，要求输出 1 到 n 的所有排列（共 n! 种）。我们用一个数组 path 记录当前已选择的数字序列，用一个布尔数组 used 标记每个数字是否已被使用。当 path 的长度达到 n 时，输出这个排列并返回。否则，遍历 1 到 n，对于每个未被使用的数字 i，将其加入 path、标记 used[i] = true，递归进入下一层，然后撤销标记 used[i] = false（即回溯），以便尝试下一个数字。

以 n = 3 为例，搜索树的遍历过程如下：
- 第一层选择 1：path = [1]，used[1] = true
  - 第二层选择 2：path = [1,2]，used[2] = true
    - 第三层选择 3：path = [1,2,3] → 输出 1 2 3，回溯撤销 used[3]
  - 第二层选择 3：path = [1,3]，used[3] = true
    - 第三层选择 2：path = [1,3,2] → 输出 1 3 2，回溯撤销 used[2]
  - 回溯撤销 used[1]
- 第一层选择 2：path = [2]，used[2] = true
  - 第二层选择 1：path = [2,1]，used[1] = true
    - 第三层选择 3：path = [2,1,3] → 输出 2 1 3
  - 第二层选择 3：path = [2,3]，used[3] = true
    - 第三层选择 1：path = [2,3,1] → 输出 2 3 1
- 第一层选择 3：path = [3]，used[3] = true
  - 第二层选择 1：path = [3,1]，used[1] = true
    - 第三层选择 2：path = [3,1,2] → 输出 3 1 2
  - 第二层选择 2：path = [3,2]，used[2] = true
    - 第三层选择 1：path = [3,2,1] → 输出 3 2 1

共 3! = 6 种排列。注意每次递归返回后必须执行 used[i] = false，否则上层无法重新选择这个数字。这个"撤销选择"的操作是回溯算法的灵魂，不理解这一点就很难正确写出回溯程序。

完整的全排列代码如下：

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<int> path;
bool used[10] = {false};  // 根据 n 的大小调整数组大小
int n;

void dfs() {
    if (path.size() == (size_t)n) {
        for (int i = 0; i < n; i++) {
            cout << path[i] << " ";
        }
        cout << endl;
        return;
    }
    for (int i = 1; i <= n; i++) {
        if (!used[i]) {
            used[i] = true;       // 做出选择
            path.push_back(i);    // 记录选择
            dfs();                // 递归进入下一层
            path.pop_back();      // 撤销记录
            used[i] = false;      // 撤销选择（回溯）
        }
    }
}

int main() {
    cin >> n;
    dfs();
    return 0;
}
```

### 5. 递归的局限性

递归虽然优雅，但也存在不可忽视的局限性。

首先是栈溢出（Stack Overflow）风险。每次函数调用都会在调用栈上分配一块栈帧（Stack Frame），用于存储局部变量、参数和返回地址。大多数在线评测系统（如洛谷、Codeforces）的默认栈大小约为 8MB。对于深度过大的递归（通常超过 10000 层），栈空间会被耗尽，导致程序崩溃（段错误或 RE）。例如，计算第 100000 个斐波那契数如果直接使用深度递归便会触发栈溢出。因此，在 CSP-J 竞赛中，如果题目数据范围暗示递归深度可能很大，就应考虑使用迭代方案或手动模拟栈。

其次，重复计算是递归效率低下的另一大元凶。以斐波那契数列为例，简单的递归实现 `fib(n) = fib(n-1) + fib(n-2)` 会产生大量的重复子问题，时间复杂度为指数级别 O(2^n)。这时需要使用记忆化搜索（加一个数组存储已计算的结果）或动态规划来优化。

尾递归（Tail Recursion）是一种特殊情况：当递归调用是函数执行的最后一步且返回值直接传递给上一层时，称为尾递归。某些编译器（如开启优化选项的 GCC）能够将尾递归优化为循环，从而不消耗额外的栈空间。例如，下面用尾递归求阶乘：`int factorial(int n, int acc = 1) { if (n == 0) return acc; return factorial(n - 1, acc * n); }`。但遗憾的是，C++ 标准并不强制要求编译器进行尾递归优化，在竞赛中不应依赖这一特性。

### 6. 递归与迭代选择指南

在实际编程中，面对一个问题时如何决定使用递归还是迭代？可以参考以下决策清单。

适合使用递归的情形：
- 问题本身具有天然的递归结构，如树的遍历、图的深度优先搜索、分治算法（归并排序、快速排序）。
- 问题的数学定义是递归的，如阶乘、斐波那契数列、汉诺塔。
- 需要回溯搜索所有解，如全排列、子集生成、N 皇后问题。
- 递归深度可控（通常不超过 1000 层），不会导致栈溢出。

适合使用迭代的情形：
- 问题可以自然地用循环表达，如遍历数组、简单求和。
- 递归深度可能非常大（n > 10000），存在栈溢出风险。
- 性能要求极高，需要避免函数调用的开销（虽然现代编译器内联优化能力很强）。
- 递归版本存在大量重复计算且不便使用记忆化。

一般原则是：先用最自然、最清晰的方式表达算法。如果递归更清晰且深度安全，就用递归；如果数据规模大或迭代同样清晰，就用迭代。在 CSP-J 的考试中，绝大多数递归问题的深度不会特别大（题目设计者会考虑到默认栈大小），所以不必过度担心栈溢出，把重点放在写出正确的递归逻辑上。

### 模板1：汉诺塔完整解法

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int steps = 0;

// 将 n 个盘子从柱子 src 移动到柱子 dst，柱子 aux 作为辅助
void hanoi(int n, char src, char aux, char dst) {
    if (n == 1) {
        steps++;
        cout << "第 " << steps << " 步：将 1 号盘从 " << src 
             << " 移动到 " << dst << endl;
        return;
    }
    // 第一步：将上面 n-1 个盘子从 src 移动到 aux（借助 dst）
    hanoi(n - 1, src, dst, aux);
    // 第二步：将最大的盘子（第 n 号）从 src 移动到 dst
    steps++;
    cout << "第 " << steps << " 步：将 " << n << " 号盘从 " 
         << src << " 移动到 " << dst << endl;
    // 第三步：将 n-1 个盘子从 aux 移动到 dst（借助 src）
    hanoi(n - 1, aux, src, dst);
}

int main() {
    int n;
    cout << "请输入盘子数量 n：";
    cin >> n;
    steps = 0;
    hanoi(n, 'A', 'B', 'C');
    cout << "总共移动了 " << steps << " 步。" << endl;
    cout << "理论最少步数：2^" << n << " - 1 = " 
         << ((long long)pow(2, n) - 1) << endl;
    return 0;
}
```

### 模板2：GCD 递归与迭代

```cpp
#include <iostream>
using namespace std;

// 递归版本：辗转相除法求最大公约数
int gcd_recursive(int a, int b) {
    if (b == 0) return a;
    return gcd_recursive(b, a % b);
}

// 迭代版本：辗转相除法求最大公约数
int gcd_iterative(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

// 求最小公倍数（LCM），利用 GCD 公式：lcm(a,b) = a / gcd(a,b) * b
int lcm(int a, int b) {
    return a / gcd_recursive(a, b) * b;  // 先除后乘防止溢出
}

int main() {
    int a, b;
    cout << "请输入两个正整数：";
    cin >> a >> b;
    cout << "gcd(" << a << ", " << b << ") = " 
         << gcd_recursive(a, b) << " (递归)" << endl;
    cout << "gcd(" << a << ", " << b << ") = " 
         << gcd_iterative(a, b) << " (迭代)" << endl;
    cout << "lcm(" << a << ", " << b << ") = " << lcm(a, b) << endl;
    return 0;
}
```

### 模板3：二分查找递归版

```cpp
#include <iostream>
using namespace std;

// 在有序数组 arr 的 [left, right] 区间内递归查找 target
// 找到返回下标，找不到返回 -1
int binarySearch(int arr[], int left, int right, int target) {
    if (left > right) return -1;  // 搜索区间为空，查找失败
    int mid = left + (right - left) / 2;  // 防止 left+right 溢出
    if (arr[mid] == target) return mid;
    if (arr[mid] > target)
        return binarySearch(arr, left, mid - 1, target);  // 去左半部分找
    else
        return binarySearch(arr, mid + 1, right, target); // 去右半部分找
}

int main() {
    int arr[] = {1, 3, 5, 7, 9, 11, 13};
    int n = sizeof(arr) / sizeof(arr[0]);
    int target;
    cout << "数组：";
    for (int i = 0; i < n; i++) cout << arr[i] << " ";
    cout << endl;
    cout << "请输入要查找的数：";
    cin >> target;
    int pos = binarySearch(arr, 0, n - 1, target);
    if (pos != -1)
        cout << target << " 在数组中的下标为 " << pos << endl;
    else
        cout << target << " 不在数组中" << endl;
    return 0;
}
```

### 模板4：回溯求全排列

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int MAXN = 10;

int n;
vector<int> path;
bool used[MAXN];

void dfs() {
    // 终止条件：path 长度等于 n
    if ((int)path.size() == n) {
        for (int i = 0; i < n; i++) {
            cout << path[i] << " \n"[i == n - 1];
        }
        return;
    }
    // 遍历所有可能的选择
    for (int i = 1; i <= n; i++) {
        if (!used[i]) {           // 数字 i 尚未使用
            used[i] = true;       // 标记使用
            path.push_back(i);    // 加入当前路径
            dfs();                // 递归到下一层
            path.pop_back();      // 回溯：移除路径末尾
            used[i] = false;      // 回溯：恢复未使用状态
        }
    }
}

int main() {
    cin >> n;
    dfs();
    return 0;
}
```

## ⚠️ 易错点

**易错点 1：二分查找的边界错误（off-by-one）**

递归二分查找中，最常见的错误是传递错误的新区间边界。当 `arr[mid] > target` 时，应递归到 `[left, mid-1]`，而不是 `[left, mid]`（如果写 `[left, mid]` 且 `arr[mid]` 始终大于 target，就会陷入无限递归）。同理，当 `arr[mid] < target` 时应递归到 `[mid+1, right]`，而不是 `[mid, right]`。务必确保每次递归调用后区间严格缩小，否则程序会死循环直到栈溢出。

**易错点 2：辗转相除法忘记 gcd(a, 0) = a**

递归 GCD 的终止条件是 `b == 0` 时返回 `a`，而不是返回 0 或 1。很多新手会错误地写成 `if (b == 0) return 0;`，这会导致所有结果都变成 0。正确的边界是：任何数与 0 的最大公约数是它本身（因为 0 可以被任何非零整数整除）。

**易错点 3：全排列回溯中混淆参数**

全排列的递归函数中，`used` 数组和 `path` 数组的状态必须与递归深度保持同步。最常见的 bug 是忘记在递归返回后执行 `used[i] = false` 或 `path.pop_back()`，导致后续分支无法选择被错误标记为"已使用"的数字。另一点是 `used` 数组的大小要开够（建议开到比 n 的最大值大一些，如 `MAXN = 15`），否则数组越界会导致 RE。

**易错点 4：忽略递归深度导致栈溢出**

局部变量的开销和操作系统的默认栈限制意味着递归深度不能无限制增长。在 Windows 系统上，默认栈大小通常为 1MB~8MB。以每个栈帧约 100 字节估算，递归深度超过约 10000 层就可能导致栈溢出。在实际竞赛中，如果 n 的范围达到 10^5 以上，不要使用深度为 n 的递归。例如，用递归遍历长度为 10^5 的链表就会在某些环境下栈溢出。遇到这种情况应改用迭代，或使用 `#pragma comment(linker, "/STACK:16777216")` 等编译器指令增大栈空间（但这不是通用解法，不推荐在竞赛中依赖）。

### 题目1：递归求最大公约数

**题目描述**

输入两个正整数 a 和 b（1 ≤ a, b ≤ 10^9），使用递归方法求它们的最大公约数。

**输入格式**

一行，两个正整数 a 和 b，用空格分隔。

**输出格式**

一行，一个整数，表示 a 和 b 的最大公约数。

**样例输入 1**

```
48 18
```

**样例输出 1**

```
6
```

**样例输入 2**

```
1071 462
```

**样例输出 2**

```
21
```

**说明**

必须使用递归实现辗转相除法。直接使用 C++ 内置 `__gcd` 函数不得分。

**AC 参考代码**

```cpp
#include <iostream>
using namespace std;

int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

int main() {
    int a, b;
    cin >> a >> b;
    cout << gcd(a, b) << endl;
    return 0;
}
```

### 题目2：生成所有二进制串

**题目描述**

给定一个正整数 n（1 ≤ n ≤ 15），输出所有长度为 n 的二进制串（仅由字符 `0` 和 `1` 组成），按字典序从小到大输出，每行一个。

**输入格式**

一行，一个正整数 n。

**输出格式**

共 2^n 行，每行一个长度为 n 的字符串，由 `0` 和 `1` 组成。按字典序输出（即先输出全 0，最后输出全 1）。

**样例输入**

```
3
```

**样例输出**

```
000
001
010
011
100
101
110
111
```

**说明**

本题需使用回溯（递归）实现。对于 n = 3，共有 2^3 = 8 个二进制串，按字典序输出即按数值从小到大排列。

**AC 参考代码**

```cpp
#include <iostream>
#include <string>
using namespace std;

int n;
string path;

void dfs(int pos) {
    // 终止条件：已经构造了长度为 n 的二进制串
    if (pos == n) {
        cout << path << endl;
        return;
    }
    // 先尝试填 '0'，保证字典序
    path.push_back('0');
    dfs(pos + 1);
    path.pop_back();  // 回溯

    // 再尝试填 '1'
    path.push_back('1');
    dfs(pos + 1);
    path.pop_back();  // 回溯
}

int main() {
    cin >> n;
    path.reserve(n);  // 预分配空间，提高效率
    dfs(0);
    return 0;
}
```

**思路分析**

本题是回溯算法的变体。与全排列不同，这里每一位有两种选择（'0' 或 '1'），且同一个字符可以重复使用，因此不需要 used 数组。核心思路是：用 `pos` 表示当前填充到的位置（0 到 n-1）。当 `pos == n` 时，表示已经填充完所有位置，输出结果。否则，在 `pos` 位置先尝试填 '0'，递归进入 `pos+1`；回溯后再尝试填 '1'，再次递归。为了满足字典序要求，必须先尝试 '0' 再尝试 '1'。时间复杂度为 O(2^n × n)，空间复杂度为 O(n)（递归栈深度 + path 字符串长度）。

## 🎯 本课小结

本节课围绕递归的应用展开了系统的学习。我们首先通过汉诺塔问题体会了递归"大事化小"的核心思想 —— 将 n 个盘子的移动分解为两个 n-1 盘子子问题和一次直接移动，步骤数满足 2^n - 1 的指数增长。接着学习了辗转相除法的递归与迭代实现，掌握了 O(log min(a, b)) 的高效 GCD 求解方法。二分查找的递归实现展示了分治策略在有序数组查找中的优美应用。回溯算法中的全排列问题引入了"选择 — 递归 — 撤销选择"这一重要模式，这是求解组合优化问题的基础框架。最后，我们讨论了递归的局限性（栈溢出、重复计算）以及递归与迭代的选择指南。

掌握这些经典递归问题，不仅有助于应对 CSP-J 考试中的相关题目，更重要的是培养了"用递归思维分析问题"的能力。在实际解题时，建议首先判断问题是否具有递归结构 —— 能否将当前问题转化为规模更小的同类子问题。若能，则大胆写出递归函数；若不能或递归深度过大，再考虑迭代方案。递归是程序员的"基本功"，多用、多练，终能达到"手中无递归，心中有递归"的境界。
