## 📖 知识精讲

### 一、什么是线性DP

线性DP（Linear DP）是动态规划中最基础也最常见的一类模型。所谓「线性」，指的是状态的演进沿着序列的某一维线性推进——通常dp[i]表示「以第i个元素结尾」或「考虑前i个元素」时的某种最优值，状态转移沿着i从小到大或从大到小进行。

线性DP的状态通常是一维或二维的：
- **一维线性DP**：`dp[i]`，如最长上升子序列（LIS）、最大子段和
- **二维线性DP**：`dp[i][j]`，如最长公共子序列（LCS）、编辑距离

在线性DP中，`dp[i]` 往往只依赖于 `dp[j]`（其中 `j < i`），这保证了我们可以按顺序递推。

### 二、最长上升子序列（LIS）

#### 2.1 问题描述

给定一个长度为n的整数序列，求其中最长的严格递增子序列的长度。子序列不要求连续，但要保持原序列中的相对顺序。

例如：序列 `[3, 1, 4, 1, 5, 9, 2, 6]` 的最长上升子序列为 `[1, 4, 5, 9]` 或 `[1, 4, 5, 6]` 或 `[3, 4, 5, 9]` 等，长度为4。

#### 2.2 状态定义与转移

**状态定义**：`dp[i]` 表示以第i个元素 **结尾** 的最长上升子序列的长度。

注意：子序列必须「以a[i]结尾」，这一定义保证了子问题之间的独立性。

**转移方程**：对于每个位置i，我们向前扫描所有位置 `j < i`：
- 如果 `a[j] < a[i]`，说明可以将 a[i] 接在以 a[j] 结尾的上升子序列后面
- 因此：`dp[i] = max(dp[j] + 1)`，对所有满足 `j < i` 且 `a[j] < a[i]` 的j取最大值
- 如果前面没有比a[i]小的数，则 `dp[i] = 1`（只包含a[i]自身）

```cpp
for (int i = 1; i <= n; i++) {
    dp[i] = 1;  // 自身成序列
    for (int j = 1; j < i; j++) {
        if (a[j] < a[i])
            dp[i] = max(dp[i], dp[j] + 1);
    }
}
```

**答案**：`max(dp[1], dp[2], ..., dp[n])`（不是dp[n]！因为最长上升子序列不一定以最后一个元素结尾）

**时间复杂度**：O(n²)，空间复杂度：O(n)。

对于CSP-J考试，O(n²)的LIS解法完全够用。O(n log n)的优化（二分+贪心）属于提高级内容，入门阶段了解即可。

#### 2.3 如何输出LIS的具体序列

在考试中，有时不仅要求输出长度，还要求输出具体的子序列。我们可以使用 `pre[i]` 数组记录dp[i]是由哪个位置转移过来的：

```cpp
int pre[MAXN];  // pre[i] 记录 dp[i] 的前驱位置

for (int i = 1; i <= n; i++) {
    dp[i] = 1;
    pre[i] = 0;  // 0表示没有前驱
    for (int j = 1; j < i; j++) {
        if (a[j] < a[i] && dp[j] + 1 > dp[i]) {
            dp[i] = dp[j] + 1;
            pre[i] = j;
        }
    }
}

// 找到最优结尾位置
int best = 1;
for (int i = 2; i <= n; i++)
    if (dp[i] > dp[best]) best = i;

// 回溯输出（需要反转）
vector<int> seq;
while (best != 0) {
    seq.push_back(a[best]);
    best = pre[best];
}
reverse(seq.begin(), seq.end());
```

### 三、最长公共子序列（LCS）

#### 3.1 问题描述

给定两个字符串（或序列）A和B，求它们的最长公共子序列的长度。公共子序列是指在A和B中都出现的子序列（不要求连续，但要保持顺序）。

例如：A = "ABCBDAB"，B = "BDCABA"，最长公共子序列为 "BCBA" 或 "BDAB"，长度为4。

#### 3.2 状态定义与转移

**状态定义**：`dp[i][j]` 表示A的前i个字符与B的前j个字符的最长公共子序列长度。

这一定义的思想是：逐步考虑A和B的更多前缀，利用前缀之间的关系推导最终答案。

**转移方程**（核心，务必牢记）：

```
              / dp[i-1][j-1] + 1,           当 A[i] == B[j] 时
dp[i][j] = max|
              \ max(dp[i-1][j], dp[i][j-1]), 当 A[i] != B[j] 时
```

**理解转移方程**：

- **情况1：A[i] == B[j]**。此时这两个相同的字符一定可以被同时选入公共子序列中（至少可以选它们）。因此，在A的前i-1个和B的前j-1个的LCS基础上，加上这对相同的字符，长度为 `dp[i-1][j-1] + 1`。

  有人可能会问：`max(dp[i-1][j], dp[i][j-1])` 会不会更大？答案是不会。因为 `dp[i-1][j-1] + 1 >= max(dp[i-1][j], dp[i][j-1])`。（为什么？因为 `dp[i-1][j]` 最多比 `dp[i-1][j-1]` 大1，而我们已经加上了1。）

- **情况2：A[i] != B[j]**。此时A[i]和B[j]不可能同时出现在公共子序列中。要么舍弃A[i]，考虑 `dp[i-1][j]`；要么舍弃B[j]，考虑 `dp[i][j-1]`。取两者中的较大值。

**边界条件**：`dp[0][j] = 0`（A为空），`dp[i][0] = 0`（B为空）。

**答案**：`dp[lenA][lenB]`

**时间复杂度**：O(n*m)，空间复杂度：O(n*m)。

#### 3.3 滚动数组优化（进阶）

观察转移方程可以发现，`dp[i][j]` 只依赖于 `dp[i-1][...]` 和 `dp[i][j-1]`，因此我们可以将二维数组压缩为两行（甚至一行）：

```cpp
// 滚动数组优化 LCS，空间 O(min(n, m))
int dp[2][MAXN];  // 只用两行
for (int i = 1; i <= n; i++) {
    int cur = i % 2;
    int prev = 1 - cur;
    for (int j = 1; j <= m; j++) {
        if (a[i] == b[j])
            dp[cur][j] = dp[prev][j-1] + 1;
        else
            dp[cur][j] = max(dp[prev][j], dp[cur][j-1]);
    }
}
```

在CSP-J考试中，如果数据范围较小（如 n, m <= 1000），直接开二维数组即可；如果 n, m 较大（如达到5000），需要滚动数组优化以节省内存。

### 四、最大子段和（Kadane算法）

#### 4.1 问题描述

给定一个长度为n的整数序列（可能包含负数），求其连续子段的最大和。

例如：序列 `[-2, 1, -3, 4, -1, 2, 1, -5, 4]` 的最大子段和为 6，对应的子段为 `[4, -1, 2, 1]`。

#### 4.2 DP解法（O(n)）

**状态定义**：`dp[i]` 表示 **以第i个元素结尾** 的最大子段和。

**转移方程**：
```
dp[i] = max(dp[i-1] + a[i], a[i])
```

理解：以a[i]结尾的最大子段，要么把a[i]接在前面的子段后面，要么a[i]自己单独成一段（当前面的和为负时）。

**答案**：`max(dp[1], dp[2], ..., dp[n])`

#### 4.3 Kadane算法的空间优化

观察发现 `dp[i]` 只依赖于 `dp[i-1]`，因此不需要数组，只需一个变量：

```cpp
int maxSubArray(vector<int>& nums) {
    int cur = 0, ans = INT_MIN;  // ans初始化为负无穷
    for (int x : nums) {
        cur = max(cur + x, x);   // 以当前位置结尾的最大和
        ans = max(ans, cur);     // 更新全局最大
    }
    return ans;
}
```

**时间复杂度**：O(n)，空间复杂度：O(1)。

#### 4.4 最大子段和的变种

**变种1：不要求连续的子序列最大和**（即所有正数之和）
**变种2：环形数组的最大子段和**（将数组视为首尾相连的环）
- 解法：max(最大子段和, 总和 - 最小子段和)
- 注意：如果全为负数，需要特判
**变种3：长度至少为k的最大子段和**（需要前缀和+滑动窗口）

### 五、编辑距离入门

#### 5.1 问题描述

编辑距离（Levenshtein Distance）是指：将一个字符串转换为另一个字符串所需的最少操作次数。允许的操作包括：
1. **插入**一个字符
2. **删除**一个字符
3. **替换**一个字符

例如："kitten" 到 "sitting" 的编辑距离为 3（k->s, e->i, 插入g）。

#### 5.2 状态定义与转移

**状态定义**：`dp[i][j]` 表示将A的前i个字符转换为B的前j个字符所需的最少操作次数。

**转移方程**：

```
              / dp[i-1][j-1],                        当 A[i] == B[j] 时（不需要操作）
dp[i][j] = min|
              | dp[i-1][j-1] + 1,    (替换操作)
              | dp[i-1][j] + 1,      (删除A[i]操作)
              \ dp[i][j-1] + 1,      (插入操作——在A的i位置后插入B[j])
              └── 以上三种取最小，当 A[i] != B[j] 时
```

**边界条件**：
- `dp[0][j] = j`（将空串转换为B的前j个字符，需要j次插入）
- `dp[i][0] = i`（将A的前i个字符转换为空串，需要i次删除）

**答案**：`dp[lenA][lenB]`

**时间复杂度**：O(n*m)，空间复杂度：O(n*m)。

```cpp
for (int i = 0; i <= n; i++) dp[i][0] = i;
for (int j = 0; j <= m; j++) dp[0][j] = j;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        if (a[i-1] == b[j-1])
            dp[i][j] = dp[i-1][j-1];
        else
            dp[i][j] = min({dp[i-1][j-1], dp[i-1][j], dp[i][j-1]}) + 1;
    }
}
```

编辑距离在CSP-J中不常作为核心考点，但理解其思想有助于加深对二维DP模型的理解。它和LCS有相似的dp[i][j]定义方式和转移模式（都依赖于左、上、左上三个方向）。

### 六、线性DP解题通用思路

1. **识别序列型问题**：题目涉及一个或多个序列（数组、字符串），要求求最优子序列/子串的属性
2. **定义状态的核心技巧**：
   - 一维dp[i]：通常表示「以第i个元素结尾」
   - 二维dp[i][j]：通常表示「考虑A的前i个和B的前j个」
3. **转移方程的推导模式**：
   - LIS模式：向前扫描所有j < i，`dp[i] = max(dp[j] + 1)`
   - LCS模式：根据A[i]和B[j]是否相等分情况讨论
   - Kadane模式：`dp[i] = max(dp[i-1] + a[i], a[i])`（选或不选）
4. **答案位置**：线性DP的答案不一定在dp[n]处！LIS的答案需要扫一遍dp数组取max；LCS的答案在dp[n][m]；最大子段和的答案需要取dp[1..n]的max。

## 💻 代码模板

### 模板1：最长上升子序列 LIS（O(n²)）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 5005;
int a[MAXN], dp[MAXN];

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        dp[i] = 1;
        for (int j = 1; j < i; j++) {
            if (a[j] < a[i])
                dp[i] = max(dp[i], dp[j] + 1);
        }
        ans = max(ans, dp[i]);
    }
    cout << ans << '\n';
    return 0;
}
```

```cpp
int main() {
```


## ⚠️ 易错点

- **错误1：LIS答案取dp[n]而非max(dp[1..n])**。这是LIS最常见的错误。dp[n]表示以最后一个元素结尾的LIS长度，但全局最长上升子序列不一定以最后一个元素结尾。必须遍历dp数组取最大值。避免方法：在更新dp[i]的同时维护全局最大值 `ans = max(ans, dp[i])`。
- **错误2：LCS中字符串下标混淆**。如果a和b从下标0开始存储，dp[i][j]对应的字符是a[i-1]和b[j-1]，容易写错。避免方法：统一在前面补一个空格，使字符串从下标1开始使用（如 `a = " " + 原始字符串`）。
- **错误3：Kadane算法中ans初始化为0而非INT_MIN**。如果数组中全是负数，最大子段和应该是最大的那个负数（即绝对值最小的负数），而不是0（0表示空子段，但子段通常要求至少包含一个元素）。避免方法：`ans` 初始化为 `INT_MIN`（或 `a[0]`）。
- **错误4：编辑距离中dp[0][j]和dp[i][0]的初始化错误**。`dp[0][j] = j` 表示将空串变为j个字符需j次插入，`dp[i][0] = i` 表示将i个字符变为空串需i次删除。不要混淆。

## 📝 真题精练

### 真题1：最长上升子序列

**【题目描述】**

给定一个长度为N（1 <= N <= 5000）的整数序列，求最长严格上升子序列的长度。上升子序列指数列中严格递增的子序列（不要求连续）。

**【输入格式】**
- 第一行一个整数N，表示序列长度
- 第二行N个整数，表示该序列

**【输出格式】**
- 一个整数，表示最长上升子序列的长度

**【输入样例】**
```
7
3 1 4 1 5 9 2
```

**【输出样例】**
```
4
```

**【说明】**
最长上升子序列可以是 `[1, 4, 5, 9]` 或 `[3, 4, 5, 9]` 或 `[1, 4, 5, 6]`（如果输入中有6），长度均为4。

**【AC代码】**
```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 5005;
int a[MAXN], dp[MAXN];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++)
        cin >> a[i];
    
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        dp[i] = 1;
        for (int j = 1; j < i; j++) {
            if (a[j] < a[i] && dp[j] + 1 > dp[i])
                dp[i] = dp[j] + 1;
        }
        ans = max(ans, dp[i]);
    }
    cout << ans << '\n';
    return 0;
}
```

### 真题2：最长公共子序列

**【题目描述】**

给定两个字符串S1和S2（长度均不超过1000），求它们的最长公共子序列的长度。

**【输入格式】**
- 一行，两个字符串S1和S2，用空格分隔

**【输出格式】**
- 一个整数，输出最长公共子序列的长度

**【输入样例】**
```
ABCBDAB BDCABA
```

**【输出样例】**
```
4
```

**【AC代码】**
```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
int dp[MAXN][MAXN];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    string a, b;
    cin >> a >> b;

    a = " " + a;
    b = " " + b;

        for (int j = 1; j <= m; j++) {
            if (a[i] == b[j])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    
    cout << dp[n][m] << '\n';
    return 0;
}
```

## 🎯 本课小结

- **LIS（最长上升子序列）**：状态定义为「以a[i]结尾」，O(n²)转移扫描前面所有j，答案是max(dp[1..n])
- **LCS（最长公共子序列）**：二维状态dp[i][j]，A[i]==B[j]时`dp[i-1][j-1]+1`，否则取`max(dp[i-1][j], dp[i][j-1])`
- **Kadane算法（最大子段和）**：`dp[i] = max(dp[i-1]+a[i], a[i])`，可空间优化为O(1)，ans初始化为负无穷
- **编辑距离**：三种操作（插入、删除、替换）取min，与LCS的二维DP结构类似
- **线性DP共性**：状态沿序列维度线性推进，dp[i]通常表示「以i结尾」或「考虑前i个」
- **考试策略**：先分析是否满足线性DP模型，准确定义状态和转移，注意边界条件和答案位置
