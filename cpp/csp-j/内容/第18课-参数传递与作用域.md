## 📖 知识精讲

### 一、形参与实参的区别

#### 基本定义

- **实际参数（实参，Actual Argument）**：调用函数时，写在函数名后面括号里的具体值或变量。
- **形式参数（形参，Formal Parameter）**：函数定义时，写在函数头部括号里的变量声明。

```cpp
//          形参（变量声明）
//          ↓↓↓
int add(int a, int b) {
    return a + b;
}

int main() {
    int x = 3, y = 5;
    int z = add(x, y);   // x 和 y 是实参
    //        ↑↑
    //        实参（具体的变量）
    cout << z << endl;
    return 0;
}
```

#### 关键区别

| 对比维度 | 形参 | 实参 |
|----------|------|------|
| 出现位置 | 函数定义 / 声明的参数列表 | 函数调用时的参数列表 |
| 本质 | 局部变量，属于被调用函数 | 表达式、变量或常量 |
| 内存分配 | 函数被调用时才分配内存 | 在调用发生前就已经存在 |
| 生命周期 | 函数执行期间存在，返回后释放 | 取决于实参自身的作用域 |

#### 一个重要认识

形参和实参的名字可以相同，但它们是**不同的变量**，存储在不同的内存位置。形参的名字只在该函数内部有意义。

```cpp
void func(int x) {   // 这里的 x 是形参
    x = 100;          // 修改的是形参
}

int main() {
    int x = 10;       // 这里的 x 是实参（也是 main 的局部变量）
    func(x);          // 把 main 中 x 的值 10 传给 func
    cout << x;        // 输出 10，main 中的 x 没有被修改！
    return 0;
}
```

这个例子清楚地说明了形参和实参虽然同名，但它们是两个完全不同且互不影响的变量。

### 二、值传递（Pass by Value）

#### 什么是值传递

值传递是 C++ 默认的参数传递方式。当使用值传递时，函数调用会发生以下过程：

1. 计算实参表达式的值
2. 在函数栈帧中创建形参变量
3. 将实参的值**复制**给形参
4. 函数内部对形参的任何操作都限于这个副本

**核心结论：值传递时，函数操作的是实参的副本，不会影响原始实参。**

#### 代码演示

```cpp
#include <iostream>
using namespace std;

void tryToModify(int num) {  // num 是形参，接收的是实参的副本
    cout << "函数内：修改前 num = " << num << endl;
    num = 999;                // 修改形参
    cout << "函数内：修改后 num = " << num << endl;
}

int main() {
    int a = 10;
    cout << "调用前：a = " << a << endl;

    tryToModify(a);           // 值传递，传递 a 的副本

    cout << "调用后：a = " << a << endl;  // a 仍然是 10，没有变化！
    return 0;
}

/* 输出：
调用前：a = 10
函数内：修改前 num = 10
函数内：修改后 num = 999
调用后：a = 10
*/
```

从这个输出可以清楚地看到，函数内部将 `num` 改为 999 之后，外部的 `a` 依然是 10。这就是值传递的核心特征。

#### 为什么需要值传递

值传递最大的优点是**安全**——函数不会意外地修改调用者的数据。对于只需要"读取"参数值而不需要"修改"参数原始值的函数，值传递是最合适的选择。

```cpp
// 这些函数都只需要"读取"参数的值，使用值传递即可
int factorial(int n) { ... }
bool isPrime(int n) { ... }
int sumOfDigits(int n) { ... }
```

### 三、引用传递（Pass by Reference）

#### 什么是引用

在 C++ 中，`&` 符号出现在类型后面时表示"引用"。引用是某个变量的**别名**，对引用的操作等同于对原变量的操作。

```cpp
int a = 10;
int &ref = a;   // ref 是 a 的引用（别名）
ref = 20;       // 修改 ref 等同于修改 a
cout << a;      // 输出 20
```

#### 引用作为函数参数

当形参声明为引用类型时，传递的不再是实参的副本，而是实参**本身**。函数内部对引用形参的修改会直接反映到实参上。

```cpp
#include <iostream>
using namespace std;

void modifyByReference(int &num) {  // 注意 & 符号
    num = 999;  // 修改的是引用指向的原始变量
}

int main() {
    int a = 10;
    cout << "调用前：a = " << a << endl;

    modifyByReference(a);  // 引用传递

    cout << "调用后：a = " << a << endl;  // a 变成了 999！
    return 0;
}

/* 输出：
调用前：a = 10
调用后：a = 999
*/
```

#### 经典应用：swap 函数

交换两个变量的值是引用传递最经典的例子。如果使用值传递，swap 函数无法完成交换，因为交换的只是形参的副本。

```cpp
// 错误：值传递版本 —— 无法交换
void swapWrong(int a, int b) {
    int temp = a;
    a = b;
    b = temp;     // 交换的是形参，不影响实参
}

// 正确：引用传递版本 —— 真正交换
void swap(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;     // 交换的是原始变量
}

int main() {
    int x = 10, y = 20;
    cout << "交换前：" << x << " " << y << endl;   // 10 20

    swap(x, y);

    cout << "交换后：" << x << " " << y << endl;   // 20 10
    return 0;
}
```

#### 何时使用引用传递

1. **需要修改实参的值**（如 swap 函数）。
2. **需要从函数中返回多个值**——通过引用参数将结果"带出来"。
3. **传递大型对象时提高效率**（避免拷贝开销，CSP-J 阶段不涉及）。

```cpp
// 同时计算两个数的和与积 —— 通过引用参数"返回"两个结果
void calc(int a, int b, int &sum, int &product) {
    sum = a + b;
    product = a * b;
}

int main() {
    int s, p;
    calc(5, 3, s, p);
    cout << "和：" << s << "，积：" << p << endl;  // 和：8，积：15
    return 0;
}
```

### 四、数组作为函数参数

#### 数组参数的传递本质

在 C++ 中，将数组作为函数参数传递时，实际上传递的是**数组首元素的地址**（指针）。因此，函数内部对数组元素的修改会直接影响调用处的原始数组。

```cpp
#include <iostream>
using namespace std;

// 数组参数：方括号中的数字可以写也可以不写（编译器会忽略）
void doubleElements(int arr[], int n) {   // arr 实际接收的是地址
    for (int i = 0; i < n; i++) {
        arr[i] *= 2;  // 修改的是原始数组的元素
    }
}

int main() {
    int a[] = {1, 2, 3, 4, 5};
    cout << "修改前：";
    for (int i = 0; i < 5; i++) cout << a[i] << " ";
    cout << endl;

    doubleElements(a, 5);

    cout << "修改后：";
    for (int i = 0; i < 5; i++) cout << a[i] << " ";
    cout << endl;

    return 0;
}

/* 输出：
修改前：1 2 3 4 5
修改后：2 4 6 8 10
*/
```

#### 数组参数的关键注意点

1. **一定要传递数组长度**：函数内部无法通过 `sizeof(arr)` 来获取数组的长度。因为 `arr` 在函数内部已经退化为指针，`sizeof(arr)` 返回的是指针的大小（通常为 4 或 8 字节），而不是整个数组的大小。

```cpp
void printSize(int arr[]) {
    // 错误示例
    cout << sizeof(arr) << endl;  // 输出 8（指针大小），而非数组大小
}

int main() {
    int a[100];
    cout << sizeof(a) << endl;   // 输出 400（100 * 4 字节）
    printSize(a);                // 输出 8（指针大小）
    return 0;
}
```

2. **数组参数实际上类似于引用传递**：函数内部修改数组元素会直接影响原始数组，这一点和值传递完全不同。

3. **多维数组参数**：除了第一维，其他维度必须指定大小。

```cpp
void printMatrix(int mat[][3], int rows) {  // 第二维大小必须指定
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < 3; j++) {
            cout << mat[i][j] << " ";
        }
        cout << endl;
    }
}
```

### 五、全局变量与局部变量

#### 局部变量

在函数内部（包括 main 函数）定义的变量称为**局部变量**。局部变量具有以下特征：

- **作用域**：从定义处开始，到所在代码块（最近的一对花括号）结束为止。
- **生命周期**：程序执行进入该作用域时创建，离开该作用域时销毁。
- 不同函数中的同名局部变量互不影响。

```cpp
void funcA() {
    int x = 10;          // funcA 的局部变量
    cout << x << endl;   // 输出 10
}

void funcB() {
    int x = 20;          // funcB 的局部变量，与 funcA 的 x 无关
    cout << x << endl;   // 输出 20
}

int main() {
    int x = 30;          // main 的局部变量
    cout << x << endl;   // 输出 30
    funcA();
    funcB();
    cout << x << endl;   // 仍然输出 30
    return 0;
}
```

#### 全局变量

在所有函数之外定义的变量称为**全局变量**。全局变量具有以下特征：

- **作用域**：从定义处开始，到整个文件结束。所有函数都可以访问和修改它。
- **生命周期**：从程序开始运行到程序结束，始终存在。
- **默认初始化**：全局变量会自动初始化为 0（整型）或空（字符等），而局部变量若未初始化则包含未定义的"垃圾值"。

```cpp
#include <iostream>
using namespace std;

int globalCounter = 0;   // 全局变量

void increment() {
    globalCounter++;     // 修改全局变量
    cout << "increment 调用后：globalCounter = " << globalCounter << endl;
}

int main() {
    cout << "初始值：" << globalCounter << endl;  // 0
    increment();                                      // 1
    increment();                                      // 2
    cout << "最终值：" << globalCounter << endl;  // 2
    return 0;
}
```

#### 变量遮蔽（Shadowing）

如果局部变量与全局变量同名，在局部变量的作用域内，**局部变量会覆盖（遮蔽）全局变量**。

```cpp
#include <iostream>
using namespace std;

int value = 100;  // 全局变量

void showValue() {
    cout << "全局 value = " << value << endl;  // 访问全局变量，输出 100
}

int main() {
    int value = 50;  // 局部变量，遮蔽了同名的全局变量
    cout << "局部 value = " << value << endl;  // 输出 50

    showValue();  // showValue 函数中访问的是全局变量

    // 使用作用域解析运算符 :: 可以显式访问全局变量
    cout << "全局 value = " << ::value << endl;  // ::value 访问全局变量，输出 100
    return 0;
}
```

#### 全局变量的使用建议

| 使用场景 | 建议 |
|----------|------|
| 程序中多个函数需要共享的数据 | 可以考虑使用全局变量，但要谨慎 |
| 仅在两个函数之间传递数据 | 优先使用函数参数和返回值 |
| 只在一个函数内使用的数据 | 必须使用局部变量 |

全局变量虽然方便，但过度使用会让程序难以理解和调试。CSP-J 阶段，仅在确实需要多个函数共享数据时才使用全局变量。

### 六、静态变量（static）

#### 基本概念

在局部变量前加上 `static` 关键字，该变量就变成了**静态局部变量**。静态局部变量与普通局部变量有本质区别：

- **只初始化一次**：静态局部变量的初始化代码只在第一次执行到时执行一次，之后每次进入函数都跳过初始化。
- **生命周期贯穿整个程序运行**：函数返回后，静态局部变量不会被销毁，而是保存其当前值，供下一次调用时使用。
- **作用域仍然是局部的**：只能在定义它的函数内部访问。

```cpp
#include <iostream>
using namespace std;

void countCalls() {
    static int callCount = 0;  // 静态局部变量，只在第一次调用时初始化为 0
    callCount++;
    cout << "函数已被调用 " << callCount << " 次" << endl;
}

int main() {
    for (int i = 0; i < 5; i++) {
        countCalls();
    }
    return 0;
}

/* 输出：
函数已被调用 1 次
函数已被调用 2 次
函数已被调用 3 次
函数已被调用 4 次
函数已被调用 5 次
*/
```

如果 `callCount` 是普通的局部变量（去掉 `static`），每次输出都会是"函数已被调用 1 次"，因为普通的局部变量每次进入函数都会重新创建和初始化。

#### static 的典型应用场景

1. **统计函数调用次数**：跟踪某个函数在程序运行期间被调用了多少次。
2. **缓存计算结果**：将函数上次计算的结果保存下来，避免重复计算（CSP-J 不常考这个）。
3. **生成唯一 ID**：每次调用返回一个递增的编号。

```cpp
int generateID() {
    static int nextID = 1000;  // 从 1000 开始分配
    return nextID++;
}

int main() {
    cout << generateID() << endl;  // 1000
    cout << generateID() << endl;  // 1001
    cout << generateID() << endl;  // 1002
    return 0;
}
```

### 七、变量生命周期与作用域总结

| 变量类型 | 作用域 | 生命周期 | 初始化 | 存储位置 |
|----------|--------|----------|--------|----------|
| 局部变量 | 定义处到代码块结束 | 进入代码块 → 离开代码块 | 不自动初始化（垃圾值） | 栈（Stack） |
| 全局变量 | 整个文件（定义处到文件尾） | 程序开始 → 程序结束 | 自动初始化为 0 | 静态存储区 |
| 静态局部变量 | 局部（定义它的函数内） | 第一次进入函数 → 程序结束 | 自动初始化为 0（且只初始化一次） | 静态存储区 |
| 形参 | 函数体内部 | 函数被调用 → 函数返回 | 由实参的值初始化 | 栈（Stack） |

## 💻 代码模板

### 模板一：值传递与引用传递对比

本模板直观展示值传递和引用传递的区别，以及 swap 函数的两种写法。

```cpp
#include <iostream>
using namespace std;

// ===== 值传递：不改变实参 =====
void badSwap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
    cout << "  badSwap 内部：a = " << a << ", b = " << b << endl;
}

// ===== 引用传递：改变实参 =====
void swap(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
    cout << "  swap 内部：a = " << a << ", b = " << b << endl;
}

// ===== 通过引用"返回"多个值 =====
void getMinMax(int a, int b, int c, int &minVal, int &maxVal) {
    minVal = maxVal = a;
    if (b < minVal) minVal = b;
    if (c < minVal) minVal = c;
    if (b > maxVal) maxVal = b;
    if (c > maxVal) maxVal = c;
}

int main() {
    // 测试 badSwap（值传递——无效）
    int x1 = 10, y1 = 20;
    cout << "badSwap 前：x1 = " << x1 << ", y1 = " << y1 << endl;
    badSwap(x1, y1);
    cout << "badSwap 后：x1 = " << x1 << ", y1 = " << y1 << "（未改变！）" << endl;

    // 测试 swap（引用传递——有效）
    int x2 = 30, y2 = 50;
    cout << "\nswap 前：x2 = " << x2 << ", y2 = " << y2 << endl;
    swap(x2, y2);
    cout << "swap 后：x2 = " << x2 << ", y2 = " << y2 << "（已交换！）" << endl;

    // 测试通过引用返回多个值
    int minVal, maxVal;
    getMinMax(42, 17, 88, minVal, maxVal);
    cout << "\n三个数 42, 17, 88 中：" << endl;
    cout << "  最小值 = " << minVal << endl;
    cout << "  最大值 = " << maxVal << endl;

    return 0;
}
```

### 模板二：变量作用域综合演示

本模板演示全局变量、局部变量、静态变量的作用域和生命周期。

```cpp
#include <iostream>
using namespace std;

// 全局变量
int globalValue = 0;

// 使用静态变量统计调用次数
void trackCalls() {
    static int callCount = 0;
    callCount++;
    cout << "  trackCalls 已被调用 " << callCount << " 次" << endl;
}

// 修改全局变量的函数
void modifyGlobal() {
    globalValue += 10;
    cout << "  modifyGlobal 修改后：globalValue = " << globalValue << endl;
}

// 演示局部变量遮蔽
int shadowValue = 100;  // 全局

void demonstrateShadow() {
    int shadowValue = 200;  // 局部变量，遮蔽全局
    cout << "  demonstrateShadow 内（局部）：shadowValue = " << shadowValue << endl;
    cout << "  demonstrateShadow 内（全局）：::shadowValue = " << ::shadowValue << endl;
}

// 演示局部变量生命周期
void localLifecycle() {
    int localVar = 1;          // 普通局部变量，每次调用重新初始化
    static int staticVar = 1;  // 静态局部变量，只初始化一次

    cout << "  局部变量 localVar = " << localVar;
    cout << "，静态变量 staticVar = " << staticVar << endl;

    localVar++;
    staticVar++;
}

int main() {
    cout << "===== 1. 全局变量演示 =====" << endl;
    cout << "初始 globalValue = " << globalValue << endl;
    modifyGlobal();
    modifyGlobal();
    cout << "最终 globalValue = " << globalValue << endl;

    cout << "\n===== 2. 静态变量演示 =====" << endl;
    for (int i = 0; i < 4; i++) {
        trackCalls();
    }

    cout << "\n===== 3. 变量遮蔽演示 =====" << endl;
    demonstrateShadow();

    cout << "\n===== 4. 局部变量生命周期演示 =====" << endl;
    for (int i = 0; i < 3; i++) {
        localLifecycle();
    }

    // 注意：局部变量每次调用都会重新创建
    // 静态变量在整个程序生命周期中持续存在
    cout << "\n总结：局部变量每次调用重新初始化，静态变量只初始化一次。" << endl;

    return 0;
}
```

## ⚠️ 易错点

### 易错点一：误以为值传递可以修改实参

```cpp
void doubleValue(int x) {
    x *= 2;  // 只修改了形参 x（实参的副本）
}

int main() {
    int num = 5;
    doubleValue(num);
    cout << num << endl;  // 输出 5，而不是 10！
    return 0;
}
```

**原因**：C++ 默认使用值传递，形参获得的是实参的副本。函数内部对该副本的修改不会影响原始变量。这是 CSP-J 初赛选择题的高频考点。

**如何避免**：明确函数的意图——如果确实需要修改实参，使用引用传递（在参数类型后加 `&`）。如果只需要读取值，值传递即是正确选择。

### 易错点二：数组参数中误用 sizeof 获取长度

```cpp
void printArray(int arr[]) {
    int len = sizeof(arr) / sizeof(arr[0]);  // 错误！
    // sizeof(arr) 返回的是指针大小（4 或 8），不是数组总大小
    for (int i = 0; i < len; i++) {
        cout << arr[i] << " ";
    }
}
```

**原因**：数组作为函数参数时会退化为指针。在函数内部，`arr` 实际上是一个指针，`sizeof(arr)` 返回指针的大小而非整个数组的大小。因此 `len` 的计算结果是错误的（在 64 位系统上，8 / 4 = 2，无论如何都只会遍历 2 个元素）。

**如何避免**：将数组长度作为单独的参数传入，这是 C++ 中处理数组参数的惯用做法。

```cpp
void printArray(int arr[], int n) {   // 正确：额外传入数组长度
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
}
```

### 易错点三：引用参数传入常量或表达式

```cpp
void increment(int &x) {
    x++;
}

int main() {
    increment(5);       // 错误：不能将字面常量绑定到非 const 引用
    increment(a + b);   // 错误：不能将表达式绑定到非 const 引用
    return 0;
}
```

**原因**：非 const 引用参数要求实参必须是一个可以修改的左值（lvalue）。字面常量 `5` 和临时表达式 `a + b` 都是右值（rvalue），不能被修改，因此不能绑定到非 const 引用。

**如何避免**：引用参数只能传入有名字的变量（左值）。如果需要接受常量和表达式，可以使用值传递或 const 引用（CSP-J 阶段将引用参数用于修改实参时，老老实实传变量即可）。

### 易错点四：忘记静态变量只初始化一次

```cpp
void accumulate(int val) {
    static int sum = 0;  // 期待 sum 每次从 0 开始累加？错！
    sum += val;
    cout << sum << endl;
}

int main() {
    accumulate(10);  // 输出 10
    accumulate(20);  // 期望输出 20，实际输出 30（因为 sum 保留了上次的值）
    return 0;
}
```

**原因**：`static int sum = 0;` 中的初始化只在第一次执行到时发生一次。之后每次调用 `accumulate`，`sum` 都保留着上一次的值。如果期望每次调用都是独立计算，就不应该使用 `static`。

**如何避免**：使用 static 之前，明确变量的生命周期需求。如果每次函数调用都需要"全新"的变量，使用普通局部变量。如果需要在多次调用之间保留状态，才使用 static。

### 题目一：交换变量并计算差值

**题目描述**

定义函数 `swap(int &a, int &b)` 使用引用传递交换两个整数。然后读入两个整数，交换后输出它们的值并计算两数之差（大减小）的绝对值。

要求：
1. 必须定义 `void swap(int &a, int &b)` 函数
2. 必须定义 `int diff(int a, int b)` 函数返回两数之差的绝对值

**输入格式**

一行，两个整数 a 和 b，以空格分隔。保证 |a|, |b| ≤ 10000。

**输出格式**

交换后的 a 和 b（空格分隔），以及两数之差的绝对值（换行分隔）。

**样例输入**

```
10 30
```

**样例输出**

```
30 10
20
```

**AC 代码**

```cpp
#include <iostream>
using namespace std;

void swap(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

int diff(int a, int b) {
    int d = a - b;
    return d > 0 ? d : -d;
}

int main() {
    int x, y;
    cin >> x >> y;
    swap(x, y);
    cout << x << " " << y << endl;
    cout << diff(x, y) << endl;
    return 0;
}
```

### 题目二：使用静态变量跟踪函数调用次数，求各位数字之和

**题目描述**

定义函数 `int sumOfDigits(int n)` 计算一个非负整数 n 的各位数字之和。在该函数内部使用**静态变量**（static）统计该函数在整个程序运行期间一共被调用了多少次。

读入一个正整数 T（1 ≤ T ≤ 100），表示接下来有 T 个待处理的数字。对于每个数字，输出其各位数字之和，以及 """到目前为止""" sumOfDigits 函数被调用的总次数。

**要求**：sumOfDigits 函数内部必须包含 `static int callCount = 0;` 来统计调用次数。对于每个测试数字，调用 sumOfDigits 之后，输出 sumOfDigits 的返回值和当前的 callCount 值。

**输入格式**

```
T
num1
num2
...
numT
```

**输出格式**

对于每个数字，输出一行：各位数字之和 和 当前调用次数，空格分隔。

**样例输入**

```
3
123
45
6789
```

**样例输出**

```
6 1
9 2
30 3
```

**样例解释**

- 123 的各位和 = 1+2+3 = 6，这是第 1 次调用。
- 45 的各位和 = 4+5 = 9，这是第 2 次调用。
- 6789 的各位和 = 6+7+8+9 = 30，这是第 3 次调用。

**AC 代码**

```cpp
#include <iostream>
using namespace std;

int sumOfDigits(int n) {
    static int callCount = 0;
    callCount++;

    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }

    // 输出调用次数（由调用者控制输出格式的一种方式）
    cout << sum << " " << callCount << endl;

    return 0;  // 返回值可以随意，因为题目直接输出
}

int main() {
    int T;
    cin >> T;
    for (int i = 0; i < T; i++) {
        int num;
        cin >> num;
        sumOfDigits(num);
    }
    return 0;
}
```

**补充说明**：上面的 AC 代码采用了"在函数内部直接输出"的方式。另一种更规范的做法是让函数返回 sum 值，同时通过引用参数或全局变量暴露 callCount。同学们可以思考一下这两种设计方式的区别和适用场景。

```cpp
// 另一种更规范的写法
int callCount = 0;  // 全局变量

int sumOfDigits(int n) {
    callCount++;
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

int main() {
    int T;
    cin >> T;
    for (int i = 0; i < T; i++) {
        int num;
        cin >> num;
        int result = sumOfDigits(num);
        cout << result << " " << callCount << endl;
    }
    return 0;
}
```

## 🎯 本课小结

| 知识模块 | 核心要点 |
|----------|----------|
| 形参与实参 | 形参是函数定义时的变量声明，实参是函数调用时的具体值；两者即使同名也是不同的变量 |
| 值传递 | C++ 默认方式，传递实参的副本；函数内部修改形参不影响实参；适合只读参数 |
| 引用传递 | 形参前加 &，传递实参本身；函数内部修改直接影响实参；适用于 swap、"返回"多个值 |
| 数组参数 | 本质传递首地址，函数内修改数组元素会影响原始数组；必须额外传递数组长度 |
| 局部变量 | 作用域限于定义它的代码块，离开后销毁；每次进入函数重新创建 |
| 全局变量 | 作用域为整个文件，生命周期为整个程序；所有函数共享；过多使用导致难以调试 |
| 静态变量 | static 关键字修饰，只初始化一次，生命周期为整个程序；适用于统计调用次数等 |

在后续课程中，我们将学习递归函数——函数调用自身的一种强大编程技巧，它在解决分治问题（如汉诺塔、快速排序）时非常有用。
