## 📖 知识精讲

### 一、while 循环：先判断，后执行

`while` 循环是 C++ 中最基础的循环结构之一，其执行逻辑可以概括为四个字：**先判断，后执行**。

**语法格式：**

```cpp
while (条件表达式) {
    // 循环体：条件为 true 时执行
}
// 条件为 false 时跳出循环，继续执行后续代码
```

**执行流程图解：**

```
        ┌──────────┐
        │ 进入循环  │
        └────┬─────┘
             ▼
        ┌──────────┐     false
   ◄────│ 判断条件？├──────────┐
   │    └────┬─────┘          │
   │   true  │                ▼
   │         ▼           ┌──────────┐
   │    ┌──────────┐     │ 跳出循环  │
   │    │ 执行循环体│     └──────────┘
   │    └────┬─────┘
   │         │
   └─────────┘
```

**关键特性：如果条件一开始就为 false，循环体一次都不执行。**

来看一个简单的例子：

```cpp
int i = 10;
int sum = 0;
while (i <= 5) {             // 条件一开始就是 false
    sum += i;
    i++;
}
cout << sum << endl;         // 输出 0，循环体未执行
```

**统计数字位数的例子：**

```cpp
int n = 12345;
int cnt = 0;
while (n > 0) {
    cnt++;                   // 每循环一次，位数加 1
    n /= 10;                 // 去掉最后一位
}
cout << cnt << endl;         // 输出 5
```

这个例子展示了 `while` 的典型用法：我们不知道数字有多少位（未知次数），但我们知道"只要 n > 0 就还有位数要数"。这就是 `while` 的核心应用场景：**当循环次数未知，但有明确的终止条件时使用**。

### 二、do-while 循环：先执行，后判断

`do-while` 循环的设计理念与 `while` 恰好相反：**先执行，后判断**。这意味着循环体**至少会被执行一次**。

**语法格式：**

```cpp
do {
    // 循环体：至少执行一次
} while (条件表达式);    // ⚠️ 注意：这里分号不能省略！
```

**执行流程图解：**

```
        ┌──────────┐
        │ 进入循环  │
        └────┬─────┘
             ▼
        ┌──────────┐
   ┌───►│ 执行循环体│
   │    └────┬─────┘
   │         ▼
   │    ┌──────────┐     false
   │    │ 判断条件？├──────────┐
   │    └────┬─────┘          │
   │   true  │                ▼
   └─────────┘           ┌──────────┐
                         │ 跳出循环  │
                         └──────────┘
```

**关键特性：无论条件如何，循环体至少执行一次。**

```cpp
int i = 10;
int sum = 0;
do {
    sum += i;                  // 这句会执行
    i++;
} while (i <= 5);             // 条件为 false，但 sum 已经是 10 了
cout << sum << endl;          // 输出 10
```

**典型应用场景：输入校验**

```cpp
int age;
do {
    cout << "请输入年龄（0-120）：";
    cin >> age;
} while (age < 0 || age > 120);   // 不合法就重新输入
// 走到这里时，age 一定在 0-120 之间
cout << "您输入的年龄是：" << age << endl;
```

输入校验是 `do-while` 最经典的应用：用户至少需要输入一次，如果不合法就不断重新输入。

### 三、while 与 do-while 的核心区别对比

| 对比维度 | `while` | `do-while` |
|----------|---------|------------|
| 判断时机 | **先**判断，后执行 | **先**执行，后判断 |
| 最少执行次数 | 0 次（条件不成立时不执行） | 1 次（无论条件如何） |
| 分号 | 不需要分号 | `while(条件);` 后面**必须加分号** |
| 适用场景 | 可能一次都不需要执行的情况 | 至少需要执行一次的情况 |

**对比代码：**

```cpp
// 场景：n = 0 时
int n = 0;

// while 版本：不输出任何内容
while (n > 0) {
    cout << "while: n > 0" << endl;
}

// do-while 版本：输出一次
do {
    cout << "do-while: n > 0" << endl;
} while (n > 0);
```

### 四、循环条件设计原则

编写循环时，最重要的事情是**确保循环最终能够终止**。这里有几条核心原则：

**原则 1：循环变量必须朝着使条件变为 false 的方向变化**

```cpp
// ❌ 错误：x 永远不减，条件永远为真
int x = 10;
while (x > 0) {
    cout << x << " ";
    // 忘记 x--，死循环！
}

// ✅ 正确：x 每次减 1，最终变为 0
int x = 10;
while (x > 0) {
    cout << x << " ";
    x--;
}
```

**原则 2：循环条件中涉及的变量必须在循环体内被修改**

```cpp
// ❌ 错误：sum 不断增加，条件 sum <= 100 永远不会变为 false
int sum = 0;
while (sum <= 100) {
    int x;
    cin >> x;
    // 忘记 sum += x，死循环！
}

// ✅ 正确
int sum = 0;
while (sum <= 100) {
    int x;
    cin >> x;
    sum += x;    // sum 在变化，最终会超过 100
}
```

**原则 3：处理 EOF（文件结束）输入时使用 while 循环**

```cpp
// 读取未知数量的整数直到文件结束
int x;
while (cin >> x) {     // cin >> x 在读到 EOF 时返回 false
    // 处理 x
}
```

### 五、死循环的识别与避免

**死循环**是指循环条件永远为 true，程序永远无法跳出循环的情况。

**常见死循环类型：**

1. **忘记更新循环变量**

```cpp
int i = 1;
while (i <= 10) {
    cout << i << endl;
    // 缺少 i++，永远输出 1
}
```

2. **循环变量更新方向错误**

```cpp
int i = 10;
while (i > 0) {
    i++;          // i 越来越大，永远不会 ≤ 0
    cout << i << endl;
}
```

3. **浮点数精度问题**

```cpp
double x = 0.0;
while (x != 1.0) {     // 浮点数可能永远不等于 1.0
    x += 0.1;
}
// 建议：用整数或范围判断代替精确相等
int cnt = 0;
while (cnt < 10) {
    cnt++;
    double x = cnt * 0.1;
}
```

4. **刻意使用 `while(true)` 但要配合 break**

```cpp
while (true) {
    int x;
    cin >> x;
    if (x == -1) break;   // 必须要有退出机制
    cout << x * 2 << endl;
}
```

### 六、while 与 for 的适用场景对比

| 场景 | 推荐结构 | 原因 |
|------|----------|------|
| 已知循环次数（如 1 到 N） | `for` | 初始化、条件、更新集中在一起，更清晰 |
| 未知次数，有终止条件 | `while` | 不需要计次变量，关注终止条件即可 |
| 至少执行一次 | `do-while` | 先执行后判断的语义天然匹配 |
| 遍历数组/容器 | `for` | C++11 范围 for 循环非常方便 |
| 读取到 EOF | `while` | `while(cin >> x)` 是经典写法 |
| 输入校验 | `do-while` | 先让用户输入，再检查合法性 |

**场景对比代码：**

```cpp
// 场景一：打印 1 到 N → 用 for
for (int i = 1; i <= n; i++) {
    cout << i << " ";
}

// 场景二：统计数字位数 → 用 while
int cnt = 0;
while (n > 0) {
    cnt++;
    n /= 10;
}

// 场景三：至少输出一次菜单 → 用 do-while
int choice;
do {
    cout << "1. 选项A  2. 选项B  0. 退出" << endl;
    cin >> choice;
    // 处理选项...
} while (choice != 0);
```

## 💻 代码模板

### 模板一：while 循环读取直到 EOF

```cpp
#include <iostream>
using namespace std;

int main() {
    int x, sum = 0;
    // 不断读取整数，直到文件结束（Ctrl+D / Ctrl+Z）
    while (cin >> x) {
        sum += x;
    }
    cout << "总和：" << sum << endl;
    return 0;
}
```

### 模板二：do-while 输入校验

```cpp
#include <iostream>
using namespace std;

int main() {
    int score;
    do {
        cout << "请输入成绩（0-100）：";
        cin >> score;
        if (score < 0 || score > 100) {
            cout << "输入不合法，请重新输入！" << endl;
        }
    } while (score < 0 || score > 100);
    
    cout << "成绩有效：" << score << " 分" << endl;
    return 0;
}
```

### 模板三：while 读取数字位数

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    // 处理 n = 0 的特殊情况
    if (n == 0) {
        cout << "1 位" << endl;
        return 0;
    }
    
    int cnt = 0;
    int temp = n;       // 保留原数，用 temp 操作
    while (temp > 0) {
        cnt++;
        temp /= 10;
    }
    cout << n << " 是 " << cnt << " 位数" << endl;
    return 0;
}
```

## ⚠️ 易错点

### 易错点 1：while 条件永远为真导致死循环

```cpp
// ❌ 错误
int i = 1;
while (i <= 10) {
    cout << i << " ";
    // 忘记 i++，死循环！
}

// ✅ 正确
int i = 1;
while (i <= 10) {
    cout << i << " ";
    i++;    // 必须更新循环变量
}
```

### 易错点 2：忘记更新循环变量

不仅仅是 `i` 这种计数器，任何在条件中出现的变量都需要在循环体中向"终止方向"变化。例如：

```cpp
// ❌ 错误：n 不变，死循环
int n, cnt = 0;
cin >> n;
while (n > 0) {
    cnt++;
    // 忘记 n /= 10
}

// ✅ 正确
while (n > 0) {
    cnt++;
    n /= 10;
}
```

### 易错点 3：do-while 后的分号遗漏

```cpp
// ❌ 错误：缺少分号，编译错误
do {
    cout << "Hello" << endl;
} while (x > 0)    // 这里需要分号！

// ✅ 正确
do {
    cout << "Hello" << endl;
} while (x > 0);   // 分号不能少
```

### 易错点 4：混淆 while 和 do-while 的执行次数

```cpp
int x = 0;
while (x > 0) {        // 条件 false，执行 0 次
    cout << "while" << endl;
}

do {
    cout << "do-while" << endl;  // 执行 1 次
} while (x > 0);
```

很多同学看到条件一样就认为执行次数一样，这是错误的。`do-while` **无论如何至少执行一次**。

## 📝 真题精练

### 真题 1：数字反转（while 循环）

**题目描述：**
给定一个正整数 N，请将其各位数字反转后输出。例如输入 123，输出 321。如果反转后最高位是 0，则不输出前导零（如输入 120，输出 21）。

**输入格式：**
一行一个正整数 N（1 ≤ N ≤ 10^9）。

**输出格式：**
一行一个整数，表示反转后的数字。

**样例输入 1：**
```
123
```

**样例输出 1：**
```
321
```

**样例输入 2：**
```
120
```

**样例输出 2：**
```
21
```

**AC 代码：**

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int rev = 0;
    while (n > 0) {
        int digit = n % 10;      // 取出最后一位
        rev = rev * 10 + digit;  // 拼接到反转结果后面
        n /= 10;                 // 去掉最后一位
    }
    
    cout << rev << endl;
    return 0;
}
```

**代码解析：**
- 每次循环取出 n 的最后一位（`n % 10`），拼接到 `rev` 的末尾（`rev * 10 + digit`）
- 从反转后的低位开始拼，自然就实现了反转
- `n = 120` 时：第一次 `rev = 0`，第二次 `rev = 2`，第三次 `rev = 21`，前导零自动被忽略

### 真题 2：输入校验（do-while 循环）

**题目描述：**
洛谷网站上注册账号需要设置密码。密码要求：长度在 6 到 16 位之间，且不能全是数字。请编写一个程序，反复提示用户输入密码，直到输入的密码符合要求为止，然后输出"密码设置成功"。

**输入格式：**
多行输入，每行一个字符串，直到输入合法密码为止。

**输出格式：**
对于每次不合法的输入，输出对应的提示信息；对于合法输入，输出"密码设置成功"。

**样例输入：**
```
123
abcdefghijklmnopq
1234567890123456
abc123
```

**样例输出：**
```
密码长度不足，请重新输入！
密码长度超出，请重新输入！
密码长度超出，请重新输入！
密码设置成功
```

**AC 代码：**

```cpp
#include <iostream>
#include <string>
#include <cctype>
using namespace std;

// 判断字符串是否全为数字
bool isAllDigit(const string& s) {
    for (char c : s) {
        if (!isdigit(c)) return false;
    }
    return true;
}

int main() {
    string password;
    bool valid;
    
    do {
        valid = true;
        cin >> password;
        
        // 检查长度
        if (password.length() < 6) {
            cout << "密码长度不足，请重新输入！" << endl;
            valid = false;
        }
        else if (password.length() > 16) {
            cout << "密码长度超出，请重新输入！" << endl;
            valid = false;
        }
        // 检查是否全数字
        else if (isAllDigit(password)) {
            cout << "密码不能全为数字，请重新输入！" << endl;
            valid = false;
        }
        
    } while (!valid);   // 合法时 valid 为 true，!valid 为 false，退出循环
    
    cout << "密码设置成功" << endl;
    return 0;
}
```

**代码解析：**
- 使用 `do-while` 确保用户至少输入一次密码
- `valid` 标志位记录当前输入是否合法
- 先检查长度（< 6 或 > 16），再检查是否全数字
- 多重 if-else 确保每种不合法情况都有对应的提示
- `isAllDigit` 辅助函数利用 `isdigit()` 检查每个字符

## 🎯 本课小结

| 学习要点 | 核心记忆 |
|----------|----------|
| while 执行流程 | 先判断条件 → 条件为真才执行 → 可能一次都不执行 |
| do-while 执行流程 | 先执行循环体 → 再判断条件 → 至少执行一次 |
| do-while 语法细节 | `while(条件);` 分号**不能省略** |
| 循环条件设计 | 必须确保条件最终为 false，循环变量要朝终止方向变化 |
| 死循环原因 | 忘记更新循环变量 / 更新方向错误 / 浮点数精度 |
| 适用场景 | 已知次数用 `for`，未知次数用 `while`，至少一次用 `do-while` |
| EOF 读入 | `while(cin >> x)` 是经典写法 |

**考试技巧：**
1. 看到"直到合法为止""反复输入"这类描述，优先考虑 `do-while`
2. 统计数据位数、数字反转等"未知循环次数"的问题，用 `while`
3. 循环体内一定要仔细检查：条件中涉及的变量是否在向终止方向变化
4. `do-while` 结尾的分号是 CSP-J 选择题的高频考点，务必牢记
