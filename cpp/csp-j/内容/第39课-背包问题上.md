## 📖 知识精讲

### 一、背包问题概述

背包问题（Knapsack）是动态规划最经典的模型之一：

> 有若干物品，每个有**代价**（重量/时间/体积）和**收益**（价值）；有一个容量上限 W。  
> 在总代价不超过 W 的前提下，使总收益最大（或方案数最多等）。

按可选次数分类：

| 类型 | 每件可选次数 | 本课 |
|------|--------------|------|
| **01 背包** | 最多 1 次 | ✅ 重点 |
| **完全背包** | 无限次 | ✅ 重点 |
| **多重背包** | 最多 c[i] 次 | 下节/拓展 |
| 分组背包等 | 组内限制 | 后续 |

**抽象映射（非常重要）**

| 现实含义 | 背包术语 |
|----------|----------|
| 时间限制 M | 容量 W |
| 采药耗时 t[i] | 重量 w[i] |
| 草药价值 v[i] | 价值 v[i] |
| 最多采一株 | 01 |
| 硬币无限枚 | 完全 |

做题时先问自己三句话：

1. “容量”是什么？  
2. “代价/收益”是什么？  
3. 每个物品能选几次？

### 二、01 背包问题

**问题描述**：N 件物品，容量 W。第 i 件重量 w[i]、价值 v[i]，每件最多用一次。求最大总价值。

#### 1. 状态定义

```
dp[i][j] = 只考虑前 i 件物品、背包容量为 j 时的最大价值
```

答案：`dp[N][W]`。

#### 2. 状态转移

对第 i 件物品：

- **不选**：`dp[i][j] = dp[i-1][j]`
- **选**（需 `j >= w[i]`）：`dp[i][j] = dp[i-1][j - w[i]] + v[i]`

合并：

```
若 j < w[i]:  dp[i][j] = dp[i-1][j]
否则:         dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
```

**关键**：选的时候必须来自 **`dp[i-1][...]`**，保证物品 i 只用一次。

#### 3. 边界

```
dp[0][j] = 0   // 没有物品，价值为 0
dp[i][0] = 0   // 容量为 0，装不下
```

#### 4. 二维实现

```cpp
for (int i = 1; i <= N; i++) {
    for (int j = 0; j <= W; j++) {
        dp[i][j] = dp[i - 1][j];
        if (j >= w[i])
            dp[i][j] = max(dp[i][j], dp[i - 1][j - w[i]] + v[i]);
    }
}
```

时间 O(NW)，空间 O(NW)。

#### 5. 手推 DP 表（务必会）

物品：

| i | w | v |
|---|---|---|
| 1 | 2 | 3 |
| 2 | 3 | 4 |
| 3 | 4 | 5 |

W = 5。

逐步（仅列关键格）：

- i=1 后：容量 0..1 为 0；j≥2 可装物品1，价值 3。  
- i=2：j=3 时，`max(3, 0+4)=4`；j=5 时 `max(3, 3+4)=7`（物品1+2）。  
- i=3：j=4 时 `max(4, 0+5)=5`；j=5 时 `max(7, 3+5)=8`（物品1+3）。

最终 `dp[3][5] = 8`。

建议自己在纸上画出完整 `(i,j)` 表，对照程序输出。

#### 6. 一维滚动数组优化

观察：`dp[i][j]` 只依赖第 `i-1` 行 → 可压成一维 `dp[j]`。

**错误（正序）**：

```cpp
for (int j = w[i]; j <= W; j++)
    dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

j 从小到大时，`dp[j-w[i]]` 可能**已经本轮更新**，等于允许物品 i 再用一次 → 变成完全背包。

**正确（倒序）**：

```cpp
for (int i = 1; i <= N; i++) {
    for (int j = W; j >= w[i]; j--) {  // 倒序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

倒序时，计算 `dp[j]` 所用的 `dp[j-w[i]]` 仍是**上一轮（未含物品 i）** 的值。

**记忆口诀**：

> **零一倒着走，完全正着走。**

#### 7. 初始化细节（大坑）

| 题意 | 初始化 | 含义 |
|------|--------|------|
| 不超过容量，求最大价值（可不装满） | 全部 `0` | 任何容量至少可得 0 |
| 必须恰好装满 | `dp[0]=0`，其余 `-INF` | 不可达状态为 -∞ |

恰好装满时，若最终 `dp[W] < 0`（或仍是 -INF），说明无法恰好装满。

```cpp
// 可不装满
fill(dp, dp + W + 1, 0);

// 恰好装满
memset(dp, 0xcf, sizeof(dp)); // 约 -INF，或手动赋 -1e9
dp[0] = 0;
```

`memset(dp, -0x3f, sizeof(dp)); dp[0]=0;` 也是常见写法。

### 三、完全背包问题

**与 01 唯一核心区别**：每种物品可选**无限次**。

#### 1. 二维转移差异

```
// 01：   dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
// 完全： dp[i][j] = max(dp[i-1][j], dp[i][j-w[i]] + v[i])
//                              注意这里是 dp[i] 同一行！
```

同一行意味着：放了一个物品 i 之后，还可以再放。

#### 2. 一维实现：正序

```cpp
for (int i = 1; i <= N; i++) {
    for (int j = w[i]; j <= W; j++) {  // 正序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

正序时 `dp[j-w[i]]` 可能已含物品 i，从而实现“无限次”。

#### 3. 对比总表

| 对比项 | 01 背包 | 完全背包 |
|--------|---------|----------|
| 选次 | ≤1 | 无限 |
| 二维第二项 | `dp[i-1][j-w]+v` | `dp[i][j-w]+v` |
| 一维 j 方向 | **倒序** | **正序** |
| 口诀 | 零一倒着走 | 完全正着走 |

#### 4. 完全背包的“多重累加”理解

对固定物品 i，正序扫 j：

- 先更新 `j = w`：相当于放 1 个  
- 再 `j = 2w`：可用已含 1 个的状态，变成 2 个  
- ……  

像“同一种物品不断叠加”。

#### 5. 方案数变体（货币系统）

若求“组成金额 m 的方案数”，转移变成**加法**而非 `max`：

```cpp
dp[0] = 1;  // 组成 0 有 1 种：什么都不选
for (int i = 1; i <= n; i++)
    for (int j = a[i]; j <= m; j++)
        dp[j] += dp[j - a[i]];
```

这是完全背包在计数问题中的经典形态。注意用 `long long` 防溢出。

### 四、推导训练：从枚举到 DP

朴素枚举每个物品选/不选：2^N 子集，N≤20 才行。  
N=100、W=1000 时必须 DP。

决策树视角：

```
处理物品 i、剩余容量 j
  → 不选：去 (i+1, j)
  → 选：  去 (i+1, j-w[i]) 且 +v[i]   （01）
```

DP 就是按 i、j 顺序填表，复用子问题答案。

### 五、采药问题完整建模

题目：时间上限 M，N 株草药，第 i 株耗时 t[i]、价值 v[i]，每株至多一次，求最大价值。

映射：

- W ← M（时间当容量）  
- w[i] ← t[i]  
- 01 背包一维倒序  

样例：

```
70 3
71 100
69 1
1 2
```

分析：第一株 71>70 永远不能选；选 69+1 得价值 1+2=3；只选 1 得 2。答案 3。

### 六、输出方案（拓展）

若要输出选了哪些物品，二维更直观：

```cpp
// 转移时记录
if (j >= w[i] && dp[i-1][j-w[i]] + v[i] > dp[i-1][j]) {
    dp[i][j] = dp[i-1][j-w[i]] + v[i];
    pre[i][j] = 1; // 选了
} else {
    dp[i][j] = dp[i-1][j];
    pre[i][j] = 0;
}
// 回溯
for (int i = N, j = W; i >= 1; i--) {
    if (pre[i][j]) {
        // 选了 i
        j -= w[i];
    }
}
```

一维也能做，但信息少，竞赛普及组少要求。

### 七、复杂度与数据范围

| N | W | NW | 评价 |
|---|---|-----|------|
| 100 | 1000 | 1e5 | 轻松 |
| 1000 | 1000 | 1e6 | 可过 |
| 100 | 1e7 | 1e9 | 需换思路/优化 |

若 W 极大而价值总和不大，可“交换维度”：`dp[j]=价值为 j 时的最小重量`。本课先掌握标准 NW 模板。

### 八、常见变形速查

| 变形 | 改法 |
|------|------|
| 至少价值 V，求最小重量 | 交换或二分+DP |
| 方案数 | `max` 改 `+=`，注意初始化 |
| 恰好装满 | -INF 初始化 |
| 每种无限 | 完全：正序 |
| 两种限制（如体积+重量） | 二维费用背包（后续） |

## ⚠️ 易错点

1. **01 写成正序** → 物品可被多次使用，答案偏大。  
2. **完全写成倒序** → 每件最多一次，答案偏小。  
3. **循环下界错误**：01 内层 `j >= w[i]`；不要写到负数下标。  
4. **初始化用错**：可不装满用 0；恰好装满用 -INF。  
5. **数组下标从 0/1 混用**：物品建议 1..N，与模板一致。  
6. **N、W 读反**：采药是先 M 再 N，注意题面顺序。  
7. **价值/重量读反**：`cin >> w >> v` 与题面“时间 价值”对齐。  
8. **int 溢出**：方案数、大价值用 `long long`。  
9. **全局 dp 多测未清零**：多组数据要重新初始化。  
10. **只背模板不理解**：考试小变就崩；要能解释倒序原理。

**快速自检**

- 01？内层从大到小。  
- 完全？内层从小到大。  
- 代码里 `j` 的方向与题型是否一致？

## 📝 真题精练

### 真题1：采药（01 背包模板题）

**题目描述**  
辰辰要在时间 M 内采 N 株草药中的若干株（每株至多一次）。第 i 株耗时 T[i]、价值 V[i]。求最大总价值。

**输入**  
第一行：M N  
接下来 N 行：T[i] V[i]  
（1 ≤ N ≤ 100，1 ≤ M ≤ 1000）

**输出**  
一个整数：最大价值。

**样例输入**
```
70 3
71 100
69 1
1 2
```

**样例输出**
```
3
```

**思路**  
经典 01：容量=时间，倒序更新。

**AC 代码**

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int dp[1005], t[105], v[105];

int main() {
    int M, N;
    cin >> M >> N;
    for (int i = 1; i <= N; i++) cin >> t[i] >> v[i];

    for (int i = 1; i <= N; i++)
        for (int j = M; j >= t[i]; j--)
            dp[j] = max(dp[j], dp[j - t[i]] + v[i]);

    cout << dp[M] << endl;
    return 0;
}
```

**二维写法对照（便于打表调试）**

```cpp
// dp[i][j]：前 i 株，时间 j
for (int i = 1; i <= N; i++) {
    for (int j = 0; j <= M; j++) {
        dp[i][j] = dp[i - 1][j];
        if (j >= t[i])
            dp[i][j] = max(dp[i][j], dp[i - 1][j - t[i]] + v[i]);
    }
}
cout << dp[N][M] << endl;
```

### 真题2：货币系统（完全背包求方案数）

**题目描述**  
n 种面值，组成金额 m，每种可用无限次，求方案数。

**输入**  
第一行 n m  
第二行 n 个面值  
（1 ≤ n ≤ 25，1 ≤ m ≤ 10000）

**输出**  
方案数（`long long` 范围内）。

**样例输入**
```
3 10
1 2 5
```

**样例输出**
```
10
```

**思路**  
完全背包计数：`dp[0]=1`，正序 `dp[j] += dp[j-a[i]]`。  
外层物品、内层金额 → 组合数（与排列不同；顺序无关）。

**AC 代码**

```cpp
#include <iostream>
using namespace std;

long long dp[10005];
int a[30];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];

    dp[0] = 1;
    for (int i = 1; i <= n; i++)
        for (int j = a[i]; j <= m; j++)
            dp[j] += dp[j - a[i]];

    cout << dp[m] << endl;
    return 0;
}
```

**说明**：若外层金额、内层物品，通常统计的是排列意义，答案不同。本题要组合，必须**物品在外、容量在内**。

### 例题3：01 与完全对比小测

**题目**  
2 件物品，容量 5。  
物品1：w=2,v=3；物品2：w=3,v=4。  
分别按 01 与完全计算最大价值。

**手算**

- 01：可选 (1+2) → 2+3=5 重量，价值 7；或单选。答案 **7**。  
- 完全：可两个物品1 → 重量 4 价值 6；或 1+2=7；或物品1×1+… 答案仍 7？  
  再试：物品1×2 + 放不下2；物品2 不能两次（6>5）。最大仍 7。  
- 改 W=6：01 仍 7；完全可选物品1×3=9，或 2×2=8，答案 **9**。

建议写两个程序对比输出。

## 🎯 本课小结

1. **01 背包**：每件 ≤1 次；`dp[j]=max(dp[j], dp[j-w]+v)`，一维**倒序**。  
2. **完全背包**：无限次；同一式子，一维**正序**。  
3. **二维理解**：01 用 `i-1` 行，完全可用 `i` 行。  
4. **初始化**：最大价值用 0；恰好装满 `dp[0]=0` 其余 -INF。  
5. **采药** = 时间当容量的 01 模板。  
6. **货币方案数** = 完全背包 + 加法转移 + `dp[0]=1`。  
7. **口诀**：**零一倒着走，完全正着走。**

下一课将涉及多重背包、分组背包与更多 DP 综合。先把本课两个模板练到默写无误。

**一句话记忆**：背包是“容量维上的最优决策”；选几次看题型，正倒序是灵魂。
