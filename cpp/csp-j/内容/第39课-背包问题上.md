## 📖 知识精讲

### 一、背包问题概述

背包问题（Knapsack Problem）是动态规划中最经典的一类问题。其基本模型是：给定一组物品，每个物品有重量w[i]和价值v[i]，以及一个容量为W的背包，要求选择若干物品放入背包，使得总重量不超过背包容量的前提下，总价值最大。

根据每种物品可选择的次数限制，背包问题分为三大类：
- **01背包**：每种物品最多选1次（选或不选）
- **完全背包**：每种物品可选无限次
- **多重背包**：每种物品有数量上限c[i]

本课重点讲解01背包和完全背包。

### 二、01背包问题

**问题描述**：有N件物品和一个容量为W的背包。第i件物品的重量是w[i]，价值是v[i]。每件物品只能使用一次。求解将哪些物品装入背包可使总价值最大。

**1. 状态定义**

设dp[i][j]表示前i件物品，背包容量为j时能获得的最大价值。最终的答案就是dp[N][W]。

**2. 状态转移方程**

对于第i件物品，我们有两种选择：

- **不选第i件**：dp[i][j] = dp[i-1][j]（直接从上一行继承）
- **选第i件**（前提 j >= w[i]）：dp[i][j] = dp[i-1][j-w[i]] + v[i]

取两者的最大值：

```
dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])   (当 j >= w[i] 时)
dp[i][j] = dp[i-1][j]                                 (当 j < w[i] 时)
```

**关键理解**：这里必须是dp[i-1][j-w[i]]，即"前i-1件物品、容量为j-w[i]"的状态，因为每件物品只能用一次。这一点决定了后续一维优化时必须倒序遍历。

**3. 二维DP实现**

```cpp
for (int i = 1; i <= N; i++) {
    for (int j = 0; j <= W; j++) {
        dp[i][j] = dp[i-1][j];
        if (j >= w[i])
            dp[i][j] = max(dp[i][j], dp[i-1][j-w[i]] + v[i]);
    }
}
```

**4. 一维滚动数组优化**

观察二维DP可发现：dp[i][j]只依赖于dp[i-1]这一行（即上一行），更早的行不再需要。因此我们可以用一维数组dp[j]来滚动更新，但必须注意遍历顺序。

**为什么必须倒序遍历？**

如果正序遍历j：
```
dp[j] = max(dp[j], dp[j-w[i]] + v[i])
```
当j从小往大遍历时，dp[j-w[i]]可能已被当前第i轮更新过（即dp[j-w[i]]已经包含了第i件物品），这样第i件物品就可能被使用多次，变成了完全背包！

倒序遍历则保证了当我们计算dp[j]时：
- dp[j-w[i]]还未被本轮更新（因为j-w[i] < j，而我们是倒序，小容量在后面才更新）
- 所以dp[j-w[i]]仍然保存的是上一轮（第i-1轮）的结果
- 这意味着dp[j-w[i]]代表的是"前i-1件物品"的状态，物品i不会被重复使用

```cpp
for (int i = 1; i <= N; i++) {
    for (int j = W; j >= w[i]; j--) {  // 倒序遍历！
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
```

**5. 初始化细节——这个坑90%的新手都会踩！**

初始化方式取决于问题要求：

- **求"最大价值"（可以不满）**：`memset(dp, 0, sizeof(dp))`
  分析：dp[0]=0表示容量为0时价值为0，其他dp[j]=0表示"未计算过，视为0"。这种初始化允许背包不被装满，即"不超过容量W"。

- **求"恰好装满"的最大价值**：`dp[0]=0, dp[1..W]=-INF`
  分析：除dp[0]=0外全设为负无穷，表示"非0容量恰好装满"的状态初始为不可达（负无穷）。只有通过合法转移，某个容量对应的价值才会被更新为正数。

  最终答案判断：如果dp[W]为负，说明无法恰好装满容量W；如果为正，则dp[W]即为答案。

### 三、完全背包问题

**问题描述**：与01背包唯一区别——每种物品可以选无限次。

**1. 状态转移方程**

在二维DP中，完全背包的转移变为：
```
dp[i][j] = max(dp[i-1][j], dp[i][j-w[i]] + v[i])
```
注意第二项是dp[i][j-w[i]]（同一行！）而非dp[i-1][j-w[i]]，因为第i件可以重复选。

**2. 一维实现：正序遍历**

由于第i件物品可以无限选，我们在计算容量j时，需要用到"已包含第i件物品"的dp[j-w[i]]（即本轮已更新过的值），所以必须正序遍历：

```cpp
for (int i = 1; i <= N; i++) {
    for (int j = w[i]; j <= W; j++) {  // 正序遍历！
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
```

**3. 01背包与完全背包的核心区别总结**

| 对比项 | 01背包 | 完全背包 |
|--------|--------|----------|
| 物品选择 | 最多选1次 | 可选无限次 |
| 二维转移 | dp[i-1][j-w[i]] + v[i] | dp[i][j-w[i]] + v[i] |
| 一维遍历 | 倒序（j从W到w[i]） | 正序（j从w[i]到W） |
| 记忆口诀 | "零一倒着走" | "完全正着走" |

**4. 完全背包的另一种理解**

完全背包可以转化为：将容量j拆分成若干份，每份可以放同一个物品。正序遍历j等价于：对当前物品i，不断尝试多放一次——先计算dp[w[i]]（放1个），再用dp[w[i]]计算dp[2*w[i]]（放2个），以此类推。这正是"同件物品可使用多次"的体现。

### 四、实战技巧

1. **物品重量和价值有时是同一个数组**：比如"采药"问题中每个药的采摘时间既是"重量"也是"代价"，需要根据题意灵活映射。
2. **W可能很大时的处理**：如果W过大（如1e9），但N较小（如100），传统的O(N*W)DP无法通过。这时可能需要转换维度：dp[i][j]表示前i个物品价值为j时的最小重量。
3. **输出方案**：如果需要输出具体选了哪些物品，可以在DP过程中用path数组记录转移路径，然后逆推。

## 💻 代码模板

### 模板1：01背包（一维DP，最常用）

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 1005;  // 物品数量上限
const int MAXW = 10005; // 背包容量上限
int w[MAXN], v[MAXN];   // 重量、价值
int dp[MAXW];           // 一维dp数组

int main() {
    int N, W;
    cin >> N >> W;
    for (int i = 1; i <= N; i++) {
        cin >> w[i] >> v[i];
    }
    
    // 初始化：求最大价值（可以不满）
    fill(dp, dp + W + 1, 0);
    
    // 01背包一维DP：倒序遍历容量
    for (int i = 1; i <= N; i++) {
        for (int j = W; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    
    cout << dp[W] << endl;
    return 0;
}
```

### 模板2：完全背包（一维DP）

```cpp
#include <iostream>

    return 0;

```

### 模板3：恰好装满的01背包

```cpp
#include <iostream>
#include <algorithm>
#include <cstring>
using namespace std;

const int MAXN = 1005;
const int MAXW = 10005;
const int INF = 0x3f3f3f3f;
int w[MAXN], v[MAXN];
int dp[MAXW];

int main() {
    int N, W;
    cin >> N >> W;
    for (int i = 1; i <= N; i++) {
        cin >> w[i] >> v[i];
    }
    
    // 初始化：dp[0]=0，其余为-INF
    memset(dp, -0x3f, sizeof(dp));
    dp[0] = 0;
    
    for (int i = 1; i <= N; i++) {
        for (int j = W; j >= w[i]; j--) {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    
    if (dp[W] < 0)
        cout << "无法恰好装满" << endl;
    else
        cout << dp[W] << endl;
    return 0;
}
```

## ⚠️ 易错点

- **易错点1：01背包正序遍历导致物品重复使用**。这是最常见的错误。忘记将j的遍历方向改为倒序，导致dp[j-w[i]]已被当前物品更新，物品i被使用了多次，01背包变成了完全背包。记住口诀："零一倒着走，完全正着走"。

- **易错点2：循环边界错误**。一维01背包的内循环应该从W到w[i]（大于等于w[i]），写成`j >= 0`会导致访问dp[j-w[i]]时下标为负数。同样，完全背包的内循环应从w[i]到W。

- **易错点3：初始化的值不当导致结果错误**。很多人直接用`memset(dp, 0, sizeof(dp))`初始化后，却把问题理解为"恰好装满"。如果需要恰好装满，必须将dp[1..W]初始化为一个很小的负数（如-0x3f3f3f3f），dp[0]=0。反过来说，如果问题不要求恰好装满，"最大价值"问题直接用0初始化即可。

## 📝 真题精练

### 真题1：采药（01背包模板题）

**题目描述**：辰辰是个天资聪颖的孩子，他的梦想是成为世界上最伟大的医师。为此，他想拜附近最有威望的医师为师。医师给他出了一个难题：山洞里有N株不同的草药，采每一株都需要一些时间T[i]，每一株也有它自身的价值V[i]。医师要求辰辰在M时间内采到价值总和最大的草药。每株草药只能采一次。

**输入格式**：第一行两个整数M和N，表示限定的总时间和草药的数量。接下来N行，每行两个整数T[i]和V[i]，表示采第i株草药的时间和价值。（1 ≤ N ≤ 100，1 ≤ M ≤ 1000）

**输出格式**：一个整数，表示在规定时间内可以采到的草药的最大总价值。

**样例输入**：
```
70 3
71 100
69 1
1 2
```

**样例输出**：
```
3
```

**参考代码**：
```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int dp[1005], t[105], v[105];

int main() {
    int M, N;
    cin >> M >> N;
    for (int i = 1; i <= N; i++) cin >> t[i] >> v[i];
    
    for (int i = 1; i <= N; i++)
        for (int j = M; j >= t[i]; j--)
            dp[j] = max(dp[j], dp[j - t[i]] + v[i]);
    
    cout << dp[M] << endl;
    return 0;
}
```

### 真题2：货币系统（完全背包模板题）

**题目描述**：给你一个n种面值的货币系统，求组成面值为m的货币有多少种方案。每种货币可以使用任意多次。

**输入格式**：第一行两个整数n和m。第二行n个整数，表示每种货币的面值。（1 ≤ n ≤ 25，1 ≤ m ≤ 10000）

**输出格式**：一个整数，表示方案数。保证答案在long long范围内。

**样例输入**：
```
3 10
1 2 5
```

**样例输出**：
```
10
```

**参考代码**：
```cpp
#include <iostream>
using namespace std;

long long dp[10005];
int a[30];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];
    
    dp[0] = 1;  // 组成0元的方案数为1（什么都不选）
    for (int i = 1; i <= n; i++)
        for (int j = a[i]; j <= m; j++)  // 正序：完全背包
            dp[j] += dp[j - a[i]];
    
    cout << dp[m] << endl;
    return 0;
}
```

## 🎯 本课小结

本课系统讲解了背包问题的两大基础模型：

1. **01背包**：每个物品最多选一次。核心转移：`dp[j] = max(dp[j], dp[j-w[i]] + v[i])`，一维实现必须**倒序**遍历容量，防止物品被重复使用。

2. **完全背包**：每个物品可选无限次。仅需将遍历方向改为**正序**即可。

3. **初始化细节**：求最大价值（可以不装满）用0初始化；求恰好装满用dp[0]=0, 其余-INF初始化。

4. **记忆口诀**："零一倒着走，完全正着走"——这是区分两种背包最实用的口诀。

背包问题作为动态规划的入门经典，理解透彻后，后续多重背包、分组背包都能游刃有余。
