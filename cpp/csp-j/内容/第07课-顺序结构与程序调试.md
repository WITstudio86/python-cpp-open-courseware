## 📖 知识精讲

### 一、顺序结构

顺序结构是程序最基本的执行方式：**按照代码书写的先后顺序，从上到下逐条执行**。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;           // ① 执行
    int b = 20;           // ② 执行
    int c = a + b;        // ③ 执行（使用①②的结果）
    cout << c << endl;    // ④ 执行
    return 0;             // ⑤ 执行
}
```

**顺序结构的特点**：
- 每条语句按顺序执行一次（除非遇到分支/循环）
- 后面的语句可以使用前面语句的结果
- 前一条语句执行完才会执行下一条
- 是C++程序的默认执行方式

### 二、C++语句分类

1. **声明语句**：`int a;` `double x = 3.14;`
2. **表达式语句**：`a = b + c;` `cout << a;`（以分号结尾的表达式）
3. **控制语句**：`if` `for` `while` `switch`（改变执行顺序）
4. **空语句**：单独的分号 `;`（什么也不做）
5. **复合语句（代码块）**：用花括号 `{ }` 括起来的一组语句

### 三、程序调试方法

#### 1. 常见错误类型

**编译错误（Compile Error）**：
- 语法错误：分号遗漏、括号不匹配、关键字拼写错误
- 类型错误：类型不匹配的赋值或运算
- 常见编译错误信息解读：
  - `expected ';' before 'xxx'` → 缺少分号
  - `'xxx' was not declared in this scope` → 变量未定义
  - `expected '}' at end of input` → 缺少花括号

**链接错误（Link Error）**：
- 未定义的函数引用：调用了只有声明没有定义的函数
- 重复定义：同一个函数/全局变量定义了多次

**运行时错误（Runtime Error）**：
- 除零：`int x = 5 / 0;`
- 数组越界：访问超出数组范围的元素
- 段错误：非法内存访问

**逻辑错误（Wrong Answer）**：
- 程序能编译运行，但结果不正确
- 原因：算法逻辑有误、边界条件处理不当、数据类型选择错误
- 这是最难排查的错误，需要仔细阅读代码逻辑

#### 2. 调试技巧

**输出调试法**（最实用）：
在关键位置插入输出语句，观察变量值和程序流程。
```cpp
int main() {
    int a = 10, b = 20;
    cout << "调试: a = " << a << ", b = " << b << endl;  // 检查变量值
    
    int c = a + b;
    cout << "调试: c = " << c << endl;  // 检查计算结果
    
    // 检查程序是否执行到某位置
    cout << "调试: 程序执行到第3步" << endl;
    
    return 0;
}
```

**断点调试法**：
1. 在代码编辑器中点击行号左侧设置**断点**（红点）
2. 以调试模式运行程序（如F5）
3. 程序运行到断点处暂停
4. 查看当前所有变量的值（监视窗口）
5. **单步执行**（F7/F8）：逐行执行，观察变量变化
6. 继续执行（F5）到下一个断点

**调试时需关注**：
- 变量的值是否符合预期
- 程序是否进入了预期的分支
- 循环是否按预期次数执行
- 数组下标是否在合法范围内

### 四、程序阅读方法

程序阅读（或称"读程"）是CSP-J的重要题型，考察对代码执行过程的跟踪能力。

**阅读步骤**：
1. **概览**：快速浏览代码，了解程序整体结构和目的
2. **找关键变量**：确定哪些变量的值会变化，关注循环变量和累加变量
3. **逐行模拟执行**：用手算/纸笔模拟计算机的执行过程，跟踪每个变量的值
4. **注意关键语句**：特别关注赋值、条件判断、循环
5. **制作变量表**：用表格记录每个时刻各变量的值

**变量追踪表示例**：
```cpp
int a = 3, b = 5;
a = a + b;
b = a - b;
a = a - b;
```

| 步骤 | 执行后a | 执行后b | 说明 |
|------|---------|---------|------|
| 初始 | 3 | 5 | 声明并初始化 |
| `a=a+b` | 8 | 5 | 3+5=8 |
| `b=a-b` | 8 | 3 | 8-5=3 |
| `a=a-b` | 5 | 3 | 8-3=5 |

最终a=5, b=3（两个变量交换了值！）

### 变量追踪练习模板
```cpp
#include <iostream>
using namespace std;

int main() {
    // 变量追踪练习
    int x = 10, y = 5;
    
    cout << "初始: x=" << x << ", y=" << y << endl;
    
    x = x + y;
    cout << "x=x+y后: x=" << x << ", y=" << y << endl;
    
    y = x - y;
    cout << "y=x-y后: x=" << x << ", y=" << y << endl;
    
    x = x - y;
    cout << "x=x-y后: x=" << x << ", y=" << y << endl;
    
    cout << "最终结果: x=" << x << ", y=" << y << endl;
    
    return 0;
}
```

## ⚠️ 易错点

- **分号与花括号**：每行语句以分号结尾，但if/for/while等控制语句后面一般不加分号（除非是空语句）。花括号成对出现，一个都不能少。
- **变量作用域**：在代码块 `{}` 内定义的变量，出了该代码块就失效了。不能在外部访问内部定义的变量。
- **输出调试信息残留**：考试提交代码时，务必删除所有调试用的输出语句，否则会因为输出多余内容被判定为答案错误。
- **变量未初始化就使用**：在顺序结构中，如果在给变量赋值之前就使用它，值是未定义的。务必在使用前初始化。
- **整数除法截断**：在复杂表达式中，隐蔽的整数除法可能导致结果错误。例如 `a / 2 * 2` 当a为奇数时结果不等于a！

## 📝 真题精练

### 题目1：变量值追踪
**题目描述**：阅读以下程序，写出运行结果。
```cpp
#include <iostream>
using namespace std;
int main() {
    int a = 3, b = 7, c = 4;
    a = b - a;
    b = c * a;
    c = b + a;
    cout << c << endl;
    return 0;
}
```

**分析过程**（用变量追踪表）：

| 步骤 | a | b | c | 说明 |
|------|---|---|---|------|
| 初始 | 3 | 7 | 4 | |
| `a=b-a` | 4 | 7 | 4 | 7-3=4 |
| `b=c*a` | 4 | 16 | 4 | 4×4=16 |
| `c=b+a` | 4 | 16 | 20 | 16+4=20 |

**答案**：`20`

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 3, b = 7, c = 4;
    
    a = b - a;  // a = 7 - 3 = 4
    cout << "a=b-a: a=" << a << endl;
    
    b = c * a;  // b = 4 * 4 = 16
    cout << "b=c*a: b=" << b << endl;
    
    c = b + a;  // c = 16 + 4 = 20
    cout << "c=b+a: c=" << c << endl;
    
    cout << "最终输出: " << c << endl;
    return 0;
}
```

### 题目2：交换变量值与调试
**题目描述**：以下程序实现什么功能？写出变量最终状态。
```cpp
#include <iostream>
using namespace std;
int main() {
    int x = 15, y = 8;
    int t = x;
    x = y;
    y = t;
    cout << x << " " << y << endl;
    return 0;
}
```

**分析过程**：
- 使用临时变量t进行交换
- t=x → t=15
- x=y → x=8
- y=t → y=15
- 最终x=8, y=15（两个变量交换成功）

**答案**：`8 15`

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 15, y = 8;
    
    // 标准交换方法：使用临时变量
    int t = x;  // t保存x的值
    x = y;      // x获得y的值
    y = t;      // y获得原来的x值
    
    cout << "交换后: x=" << x << ", y=" << y << endl;
    cout << x << " " << y << endl;  // 输出：8 15
    
    return 0;
}
```
