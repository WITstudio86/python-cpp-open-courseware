## 📖 知识精讲

### 一、什么是图？

图（Graph）由**顶点**（Vertex）集合与**边**（Edge）集合构成，记作：

```
G = (V, E)
```

- V：顶点有限集合，常编号 1..n（也有 0..n-1）  
- E：边的集合；无向边 {u,v} 或有向边 (u,v)

图可表示：

- 城市与道路  
- 好友关系  
- 网页超链接  
- 课程先修关系  
- 迷宫格子的相邻关系  

**例**：5 个点，边 1-2, 2-3, 3-4, 4-5, 2-5。  
这是一条“链 + 弦”的无向图。

### 二、有向图与无向图

#### 无向图

边无方向，(u,v) 与 (v,u) 相同。如双向道路。

```cpp
vector<int> g[N];
g[u].push_back(v);
g[v].push_back(u);  // 必须双向
```

#### 有向图

边有方向，u→v 不能自动走回。如单行道、依赖关系。

```cpp
g[u].push_back(v);  // 只存一个方向
```

**建图口诀**：无向“写两行”，有向“写一行”。

### 三、带权图与无权图

| 类型 | 含义 | 存储 |
|------|------|------|
| 无权 | 只关心是否相连 | `g[u].push_back(v)` 或矩阵 0/1 |
| 带权 | 边有距离/费用/时间 | 存 `{to, w}` 或矩阵存权值 |

```cpp
struct Edge {
    int to;
    int weight;
};
vector<Edge> g[N];
g[u].push_back({v, w});
// 无向：再 g[v].push_back({u, w});
```

无权图中“走一条边”的代价通常视为 1，最短路可用 BFS。

### 四、更多基本术语（扫盲）

- **自环**：边的两端是同一顶点。  
- **重边**：同一对点之间多条边。  
- **简单图**：无自环、无重边（多数题默认）。  
- **稀疏图**：m 远小于 n²，如 m = O(n)。  
- **稠密图**：m 接近 n²。  
- **子图**：点边都是原图子集。  
- **完全图**：任意两点都有边，无向边数 n(n-1)/2。

CSP-J 多数题目给的是简单稀疏图。

### 五、图的存储方式（核心）

#### 1. 邻接矩阵

用二维数组 `g[i][j]` 表示 i 到 j 是否有边（或边权）。

```cpp
int g[1005][1005];

// 无权无向
g[u][v] = g[v][u] = 1;

// 带权有向
g[u][v] = w;  // 无边可初始化为 0 或 INF
```

**优点**

- 判边 O(1)：`if (g[u][v])`  
- 代码短，好写

**缺点**

- 空间 O(n²)。n=1e4 时约 1e8 个 int → 400MB 级，易 MLE  
- 枚举邻点 O(n)，即使度数很小

**适用**：n ≤ 1000 左右，或需要频繁判边的稠密图。

**初始化**

```cpp
memset(g, 0, sizeof(g));           // 无权
// 带权最短路常用：
// memset(g, 0x3f, sizeof(g)); g[i][i]=0;
```

#### 2. 邻接表

`g[i]` 存储所有与 i 相邻的点（及边权）。

```cpp
vector<int> g[N];

g[u].push_back(v);
g[v].push_back(u);

// 遍历 u 的邻点
for (int v : g[u]) {
    // ...
}
```

**优点**

- 空间 O(n+m)  
- 枚举邻点 O(度)

**缺点**

- 判边最坏 O(度)  
- 稍比矩阵“绕”一点（但 vector 已经很好写）

**适用**：**稀疏图**、n 可达 1e5。CSP-J **默认优先邻接表**。

#### 3. 链式前向星（了解）

竞赛进阶常用数组模拟邻接表，CSP-J 用 `vector` 足够：

```cpp
// 了解形态即可
struct E { int to, nxt, w; } e[M];
int head[N], tot;
void add(int u, int v, int w) {
    e[++tot] = {v, head[u], w};
    head[u] = tot;
}
```

#### 4. 对比与选型

| 特性 | 邻接矩阵 | 邻接表 |
|------|----------|--------|
| 空间 | O(n²) | O(n+m) |
| 判边 | O(1) | O(度) |
| 遍历邻点 | O(n) | O(度) |
| 适用 | n≤1000 稠密/多判边 | n 大稀疏 |
| 实现 | 简单 | 很常用 |

**考试策略**：

- n > 5000：几乎只能邻接表  
- n ≤ 1000 且大量“是否有边”询问：矩阵很香  
- 其余情况：**邻接表**

### 六、顶点的度

#### 无向图

- **度 deg(v)**：与 v 相连的边数  
- 握手定理：∑ deg(v) = 2|E|

#### 有向图

- **出度**：从 v 出发的边数  
- **入度**：指向 v 的边数  
- ∑ 入度 = ∑ 出度 = |E|

```cpp
int indeg[N], outdeg[N];
for (int u = 1; u <= n; u++) {
    for (int v : g[u]) {
        outdeg[u]++;
        indeg[v]++;
    }
}
// 无向图：读边时 deg[u]++, deg[v]++
```

**应用预告**：拓扑排序依赖入度；欧拉路径看奇度点个数。

### 七、路径、回路与连通

- **路径**：顶点序列 v0,v1,...,vk，相邻有边；长度常指边数 k。  
- **简单路径**：顶点不重复。  
- **回路（环）**：起点=终点，且长度 ≥1（通常 ≥3 对简单无向图）。  
- **连通（无向）**：任意两点都有路径。  
- **连通块**：极大连通子图。  
- **强连通（有向）**：任意两点互相可达。

**可达性**：从 s 能否到 t → DFS/BFS + `vis`。  
**连通块数量**：对所有未访问点开一次 DFS/BFS，次数即块数。

### 八、图的遍历基础（铺垫）

从某点出发访问所有能到的点，且通常每个点标记一次。

| 方式 | 思想 | 数据结构 | 下节 |
|------|------|----------|------|
| DFS | 一路走到底再回溯 | 递归栈/显式栈 | 第42课 |
| BFS | 按层扩展 | 队列 | 第43课 |

共同点：必须有 `bool vis[N]`，防止死循环（尤其有环时）。

```cpp
// DFS 骨架
void dfs(int u) {
    vis[u] = true;
    for (int v : g[u])
        if (!vis[v]) dfs(v);
}

// BFS 骨架
void bfs(int s) {
    queue<int> q;
    q.push(s);
    vis[s] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u])
            if (!vis[v]) {
                vis[v] = true;
                q.push(v);
            }
    }
}
```

本课重点是**存图**；遍历下两课展开。

### 九、读图与编号习惯

题目常见输入：

```
n m
u1 v1
u2 v2
...
um vm
```

注意：

1. 点是否从 1 开始？多数是。  
2. 有向还是无向？  
3. 是否带权（每行 u v w）？  
4. 是否保证无重边/自环？  
5. 图是否连通？

```cpp
const int N = 100005;
vector<int> g[N];
int n, m;
cin >> n >> m;
for (int i = 0; i < m; i++) {
    int u, v;
    cin >> u >> v;
    g[u].push_back(v);
    g[v].push_back(u); // 无向
}
```

多组数据时记得清空：

```cpp
for (int i = 1; i <= n; i++) g[i].clear();
```

### 十、从网格到图（拓展）

n×m 迷宫中，每个格子是点，四连通是边：

```
id = (i-1)*m + j
// 或直接用坐标 (x,y) 做 BFS，不必显式建表
```

显式建图与“在网格上直接搜”本质相同。

### 模板四：无向图度数 + 最大度点

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int N = 100005;
vector<int> g[N];
int deg[N];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
        deg[u]++;
        deg[v]++;
    }

    int best = 1;
    for (int i = 1; i <= n; i++) {
        cout << deg[i] << (i == n ? '\n' : ' ');
        if (deg[i] > deg[best]) best = i;
        // 度数相同取编号更小：用 > 即可
    }
    cout << best << endl;
    return 0;
}
```

## ⚠️ 易错点

1. **无向图只存一边** → 遍历丢半张图。  
2. **点编号 0/1 混用** → 建议数组开 N+5，统一 1..n。  
3. **n 大却开矩阵** → MLE。n>5000 优先表。  
4. **度数统计误解**：无向 ∑deg=2m，不是 m。  
5. **有向当无向建** 或反过来。  
6. **多组数据未 clear** vector。  
7. **遍历无 vis** → 有环时无限递归/死循环。  
8. **重边**：矩阵可直接覆盖；表会存多份，注意题意。  
9. **自环**：无向 deg 通常 +2 还是 +1 看定义；一般题无自环。  
10. **边权初始化**：最短路矩阵无边应是 INF 不是 0。

**自检清单**

- 有向/无向是否说清？  
- 存储结构是否匹配 n？  
- 读边循环是否为 m 次？  
- 需要双向 push 吗？

### 题目1：图的存储与度数统计

**题目描述**  
给定 n 个顶点 m 条边的**无向图**，编号 1..n。输出每个点的度数，以及度数最大的顶点编号（并列取编号最小）。

**输入**  
第一行 n m（1 ≤ n ≤ 1e5，0 ≤ m ≤ 2e5）  
接下来 m 行 u v

**输出**  
第一行 n 个度数  
第二行一个编号

**样例输入**
```
5 4
1 2
2 3
3 4
4 5
```

**样例输出**
```
1 2 2 2 1
2
```

说明：deg = [1,2,2,2,1]，最大度 2，编号最小为 2。  
（若实现时用 `>` 更新，得到 2；旧讲义样例写 3 不严谨，以“并列取最小编号”为准。）

更正样例期望第二行为 **2**。若题目写“任意一个”，2 或 3 或 4 均可。

**AC 代码**

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int N = 100005;
vector<int> g[N];
int deg[N];

int main() {
    int n, m;
    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
        deg[u]++;
        deg[v]++;
    }

    for (int i = 1; i <= n; i++) {
        cout << deg[i] << (i == n ? '\n' : ' ');
    }

    int maxDeg = -1, ans = 1;
    for (int i = 1; i <= n; i++) {
        if (deg[i] > maxDeg) {
            maxDeg = deg[i];
            ans = i;
        }
    }
    cout << ans << endl;
    return 0;
}
```

**为何必须邻接表？** n=1e5 不能开 n×n 矩阵。

### 题目2：邻接矩阵判断边

**题目描述**  
n 点 m 条**有向**边，q 次询问：是否存在边 u→v？

**输入**  
第一行 n m q（1 ≤ n ≤ 1000，0 ≤ m ≤ 10000，1 ≤ q ≤ 1000）  
m 行边；q 行询问

**输出**  
每次 Yes / No

**样例输入**
```
4 5 3
1 2
1 3
2 3
2 4
3 4
1 4
2 1
1 3
```

**样例输出**
```
No
No
Yes
```

**思路**  
n≤1000，矩阵判边 O(1)。注意有向只赋 `g[u][v]=1`。

**AC 代码**

```cpp
#include <iostream>
using namespace std;

const int N = 1005;
int g[N][N];

int main() {
    int n, m, q;
    cin >> n >> m >> q;

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u][v] = 1;
    }

    while (q--) {
        int u, v;
        cin >> u >> v;
        if (g[u][v]) cout << "Yes" << endl;
        else cout << "No" << endl;
    }
    return 0;
}
```

### 例题3：统计连通块数量（遍历预热）

**题目描述**  
n 点 m 条无向边，求连通块个数。（1 ≤ n ≤ 1e5，0 ≤ m ≤ 2e5）

**思路**  
邻接表建图；对每个未访问点 DFS/BFS 一次，计数 +1。

**AC 代码（DFS）**

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int N = 100005;
vector<int> g[N];
bool vis[N];

void dfs(int u) {
    vis[u] = true;
    for (int v : g[u])
        if (!vis[v]) dfs(v);
}

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        if (!vis[i]) {
            dfs(i);
            cnt++;
        }
    }
    cout << cnt << endl;
    return 0;
}
```

注意：n 大且链很长时递归可能爆栈，可用 BFS 或扩栈；CSP-J 常见 n 下多数可过，稳健写法用 BFS。

## 🎯 本课小结

1. **图** = 点 + 边；先分清有向/无向、带权/无权。  
2. **邻接矩阵**：O(n²) 空间，O(1) 判边，适合 n 小。  
3. **邻接表**：O(n+m) 空间，适合稀疏大图，CSP-J 主力。  
4. **度**：无向 ∑deg=2m；有向 ∑in=∑out=m。  
5. **路径/连通**：为 DFS、BFS、最短路做概念准备。  
6. **易错**：无向双向存、编号一致、大 n 不用矩阵、遍历要 vis。  
7. **选型口诀**：n 大用表，n 小又狂判边用矩阵。

下一课 **DFS**，再下一课 **BFS**。存图不牢，搜索全塌——请把本课模板默写熟练。

**一句话记忆**：图是关系的网；表存稀疏、阵存稠密；无向双边、有向单边；有 vis 才敢逛。
