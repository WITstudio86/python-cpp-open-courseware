## 📖 知识精讲

### 一、什么是图？

图（Graph）是由**顶点**（Vertex）集合和**边**（Edge）集合构成的数据结构，记作 G = (V, E)。其中 V 是顶点的有限非空集合，E 是连接两个顶点的边的集合。图可以表示万事万物之间的关系：城市之间的道路、社交网络中的好友关系、网页之间的超链接，都可以抽象为图。

顶点通常编号为 1, 2, 3, ..., n。边则用一对顶点 (u, v) 来表示：若 u 和 v 之间有一条边相连，我们就说 (u, v) ∈ E。

### 二、有向图与无向图

- **无向图**：边没有方向，即边 (u, v) 与 (v, u) 是等价的。好比双向通行的道路，你可以从 u 走到 v，也可以从 v 走到 u。无向图的边在存储时通常看作两条有向边。

```cpp
// 无向图添加一条边
vector<int> g[N];
g[u].push_back(v);
g[v].push_back(u);  // 双向都要存
```

- **有向图**：边有方向，(u, v) 表示只能从 u 走到 v，不能反向。好比单行道。

```cpp
// 有向图添加一条边
vector<int> g[N];
g[u].push_back(v);  // 只存一个方向
```

### 三、带权图与无权图

- **无权图**：每条边没有权重，只表示连接关系。遍历时每走一条边代价为 1。
- **带权图**（加权图）：每条边有一个权值 weight，可以表示距离、花费、时间等。比如城市 A 到城市 B 的距离是 50km。

```cpp
// 带权图的邻接表存储
struct Edge {
    int to;     // 目标顶点
    int weight; // 边权
};
vector<Edge> g[N];
g[u].push_back({v, w});
```

### 四、图的存储方式（重点）

这是CSP-J考试的重中之重，必须熟练掌握两种存储方式及其适用场景。

#### 1. 邻接矩阵

用一个二维数组 `g[i][j]` 表示顶点 i 到顶点 j 是否有边（或边的权值）。

```cpp
int g[1005][1005];  // 邻接矩阵

// 无权图：g[i][j] = 1 表示有边，0 表示无边
g[u][v] = 1;
g[v][u] = 1;  // 无向图

// 带权图：g[i][j] = w 表示边权为 w
g[u][v] = w;
```

**优点**：
- 判断两点之间是否有边只需 O(1) 时间：`if (g[u][v])`
- 代码简洁直观，适合初学者理解

**缺点**：
- 空间复杂度 O(n²)。当 n = 10000 时，需要 10000×10000 = 1 亿个 int，约 400MB 内存，远超竞赛限制（通常 256MB）
- 遍历一个顶点的所有邻接点需要 O(n)，即使该顶点只有很少的边

**适用场景**：**稠密图**，即边数 m 接近 n²。一般 n ≤ 1000 时可以考虑使用邻接矩阵。

#### 2. 邻接表

用一个 `vector<int>` 数组，其中 `g[i]` 存储与顶点 i 相邻的所有顶点。

```cpp
vector<int> g[N];  // 邻接表（无权图）

// 添加边
g[u].push_back(v);
g[v].push_back(u);  // 无向图

// 遍历顶点 u 的所有邻接点
for (int v : g[u]) {
    // 处理邻接点 v
}
```

**优点**：
- 空间复杂度 O(n + m)，只存储实际存在的边，非常节省空间
- 遍历一个顶点的所有邻接点只需 O(度数) 时间

**缺点**：
- 判断两点之间是否有边需要遍历邻接表，最坏 O(n)
- 代码稍复杂（不过 C++ 中用 vector 已经很方便了）

**适用场景**：**稀疏图**，即边数 m 远小于 n²。绝大多数CSP-J题目都是稀疏图，所以**优先使用邻接表**。

#### 3. 两种存储方式的对比总结

| 特性 | 邻接矩阵 | 邻接表 |
|------|---------|--------|
| 空间 | O(n²) | O(n + m) |
| 判边 | O(1) | O(度数) |
| 遍历邻接点 | O(n) | O(度数) |
| 适用 | n ≤ 1000 稠密图 | n 可上万，稀疏图 |
| 实现难度 | 简单 | 稍复杂 |

**考试选择策略**：如果题目 n ≤ 1000 且需要频繁判断边是否存在，用邻接矩阵；其余情况一律用邻接表。

### 五、顶点的度

- **度（degree）**：与顶点相连的边的数量。
- **入度（in-degree）**：在有向图中，以该顶点为**终点**的边的数量，即有多少条边"指向"该顶点。
- **出度（out-degree）**：在有向图中，以该顶点为**起点**的边的数量，即有多少条边"从该顶点出发"。

对于无向图，度 = 与该顶点相连的边数。对于有向图，总度数 = 入度 + 出度。

```cpp
// 计算有向图的入度和出度
int indeg[N], outdeg[N];
for (int u = 1; u <= n; u++) {
    for (int v : g[u]) {
        outdeg[u]++;  // u 出发的边
        indeg[v]++;   // 指向 v 的边
    }
}
```

**性质**：所有顶点的度数之和等于边数的 2 倍（无向图），因为每条边贡献 2 个度。对于有向图，所有顶点的入度之和 = 所有顶点的出度之和 = 边数。

### 六、路径与回路

- **路径**：从顶点 u 到顶点 v 的一条顶点序列 v₀, v₁, v₂, ..., vₖ，其中 v₀ = u，vₖ = v，且每对相邻顶点之间都有边相连。路径的长度为经过的边的数量（即 k）。
- **简单路径**：路径上的顶点互不相同（不重复经过同一顶点）。
- **回路（环）**：起点和终点相同的路径，即 v₀ = vₖ 且 k ≥ 1。
- **连通图**：无向图中，任意两个顶点之间都存在路径。有向图的连通分为强连通（任意两点互相可达）和弱连通（将有向边视为无向边后连通）。

**真题方向**：判断图中是否存在路径（可达性）、判断图中是否有环、统计连通块数量——这些都是DFS/BFS的核心应用，下节课会详细讲解。

### 七、图的遍历基础

图的遍历是指从某个顶点出发，按照某种规则访问图中所有顶点且每个顶点只访问一次。主要方式有两种：

- **深度优先搜索（DFS）**：沿着一条路径走到尽头再回溯
- **广度优先搜索（BFS）**：先访问所有邻近顶点，再逐层向外扩展

两者都需要一个 `bool vis[N]` 数组来标记顶点是否已被访问，防止重复访问和死循环。

## 💻 代码模板

### 邻接矩阵存储 + 基本操作

```cpp
#include <iostream>
#include <cstring>
using namespace std;

const int N = 1005;
int g[N][N];  // 邻接矩阵
int n, m;     // n 个顶点，m 条边

int main() {
    cin >> n >> m;
    memset(g, 0, sizeof(g));
    
    // 读入无向无权图的边
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u][v] = 1;
        g[v][u] = 1;  // 无向图，双向标记
    }
    
    // 判断 1 和 2 之间是否有边
    if (g[1][2]) cout << "Yes" << endl;
    else cout << "No" << endl;
    
    // 遍历顶点 1 的所有邻接点
    for (int v = 1; v <= n; v++) {
        if (g[1][v]) {
            cout << v << " ";
        }
    }
    
    return 0;
}
```

### 邻接表存储 + 基本操作

```cpp
#include <iostream>
#include <vector>
using namespace std;

const int N = 100005;
vector<int> g[N];
int n, m;
int indeg[N], outdeg[N];

int main() {
    cin >> n >> m;
    
    // 读入有向无权图的边
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);  // 有向边 u->v
        outdeg[u]++;
        indeg[v]++;
    }
    
    // 遍历顶点 u 的所有邻接点
    for (int v : g[1]) {
        cout << v << " ";
    }
    
    // 输出每个顶点的入度和出度
    for (int i = 1; i <= n; i++) {
        cout << "顶点" << i << ": 入度=" << indeg[i] 
             << ", 出度=" << outdeg[i] << endl;
    }
    
    return 0;
}
```

### 带权图邻接表

```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Edge {
    int to, weight;
};

const int N = 100005;
vector<Edge> g[N];
int n, m;

int main() {
    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        g[u].push_back({v, w});
        // 无向图需要添加 g[v].push_back({u, w});
    }
    
    // 遍历顶点 1 的所有邻接边
    for (Edge e : g[1]) {
        cout << "到" << e.to << "的权值为" << e.weight << endl;
    }
    
    return 0;
}
```

## ⚠️ 易错点

- **易错点1：无向图忘记双向存储**。使用邻接表时，无向图必须在 `g[u]` 和 `g[v]` 中都添加对方，否则会丢失一半的边。同理，邻接矩阵也需要 `g[u][v] = g[v][u] = 1`。这是初学者最容易犯的错误，一旦漏掉某一方向，DFS/BFS遍历结果将完全不正确。

- **易错点2：邻接矩阵下标从0还是1开始混淆**。题目中顶点通常从 1 开始编号，但数组下标默认从 0 开始。建议统一将数组开到 N+5，顶点从 1 到 n 使用，下标 0 闲置不用，避免 off-by-one 错误。

- **易错点3：稀疏图使用邻接矩阵导致 MLE（内存超限）**。如果 n = 100000 却开 `g[100000][100000]`，直接爆内存。面对大 n，务必第一时间想到邻接表。判断标准：n > 5000 时几乎只能用邻接表。

- **易错点4：度数计算时的重复统计**。无向图中计算度数时，每条边 (u, v) 会使 deg[u]++ 和 deg[v]++，总度数 = 2m，不要奇怪为什么度数之和是边数的两倍。

## 📝 真题精练

### 题目1：图的存储与度数统计

**题目描述**：
给定一个包含 n 个顶点和 m 条边的无向图，顶点编号从 1 到 n。请输出每个顶点的度数，以及度数最大的顶点编号（如有多个，输出编号最小的那个）。

**输入格式**：
第一行两个整数 n 和 m（1 ≤ n ≤ 100000，0 ≤ m ≤ 200000）。
接下来 m 行，每行两个整数 u 和 v，表示一条无向边。

**输出格式**：
第一行输出 n 个整数，表示每个顶点的度数，空格分隔。
第二行输出一个整数，表示度数最大的顶点编号。

**样例输入**：
```
5 4
1 2
2 3
3 4
4 5
```

**样例输出**：
```
1 2 2 2 1
3
```

**AC代码**：
```cpp
#include <iostream>
#include <vector>
using namespace std;

const int N = 100005;
vector<int> g[N];
int deg[N];

int main() {
    int n, m;
    cin >> n >> m;
    
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);  // 无向图，双向存储
        deg[u]++;
        deg[v]++;
    }
    
    for (int i = 1; i <= n; i++) {
        cout << deg[i] << (i == n ? "\n" : " ");
    }
    
    int maxDeg = -1, ans = 1;
    for (int i = 1; i <= n; i++) {
        if (deg[i] > maxDeg) {
            maxDeg = deg[i];
            ans = i;
        }
    }
    cout << ans << endl;
    
    return 0;
}
```

### 题目2：邻接矩阵判断边

**题目描述**：
给定一个包含 n 个顶点和 m 条边的有向图，顶点编号从 1 到 n。接下来有 q 次询问，每次询问两个顶点 u 和 v，请判断是否存在从 u 到 v 的边。

**输入格式**：
第一行三个整数 n, m, q（1 ≤ n ≤ 1000，0 ≤ m ≤ 10000，1 ≤ q ≤ 1000）。
接下来 m 行，每行两个整数 u 和 v，表示一条有向边 u → v。
接下来 q 行，每行两个整数 u 和 v，表示一次询问。

**输出格式**：
对于每次询问，如果存在边 u → v，输出 "Yes"，否则输出 "No"，每行一个结果。

**样例输入**：
```
4 5 3
1 2
1 3
2 3
2 4
3 4
1 4
2 1
1 3
```

**样例输出**：
```
No
No
Yes
```

**AC代码**：
```cpp
#include <iostream>
using namespace std;

const int N = 1005;
int g[N][N];

int main() {
    int n, m, q;
    cin >> n >> m >> q;
    
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u][v] = 1;  // 有向图，只存一个方向
    }
    
    while (q--) {
        int u, v;
        cin >> u >> v;
        if (g[u][v]) cout << "Yes" << endl;
        else cout << "No" << endl;
    }
    
    return 0;
}
```
