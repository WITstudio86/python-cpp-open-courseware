### 一、质数判断

**质数（素数）**是指在大于1的自然数中，除了1和它本身以外不再有其他因数的数。与之相对的概念是**合数**。

#### 1.1 试除法（Trial Division）

判断一个数 $n$ 是否为质数，最直接的方法是依次用 $2$ 到 $n-1$ 之间的每个数去除 $n$。但我们可以做两个优化：
- 优化1：只需检查到 $\sqrt{n}$，因为如果 $n$ 有因子 $d > \sqrt{n}$，则必有对应的因子 $n/d < \sqrt{n}$。
- 优化2：2之后只需检查奇数（因为除2以外的偶数不可能是质数）。

```cpp
bool isPrime(int n) {
    if (n < 2) return false;          // 1和0不是质数
    if (n == 2) return true;           // 2是唯一的偶质数
    if (n % 2 == 0) return false;      // 排除其他偶数
    for (int i = 3; i * i <= n; i += 2) {
        if (n % i == 0) return false;
    }
    return true;
}
```

时间复杂度为 $O(\sqrt{n})$，适合判断单个数。如果要判断多个数，每次 $O(\sqrt{n})$ 可能会很慢。

#### 1.2 埃拉托斯特尼筛法（埃氏筛）

当需要找出 $1$ 到 $n$ 范围内所有质数时，筛法是最经典的做法。埃氏筛的基本思想是：从小到大枚举每个数，如果它是质数，就把它的所有倍数标记为合数。

```cpp
// 埃氏筛，返回 [1, n] 内的质数列表
vector<int> eratosthenes(int n) {
    vector<bool> isPrime(n + 1, true);
    isPrime[0] = isPrime[1] = false;  // 0和1不是质数

    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            // 从 i*i 开始标记，因为更小的倍数已被标记过
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }

    vector<int> primes;
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) primes.push_back(i);
    }
    return primes;
}
```

时间复杂度约为 $O(n \log \log n)$，非常接近线性。内层循环从 $i \times i$ 开始而不是 $2i$ 开始是一个重要的优化。

**为什么内层循环从 $i \times i$ 开始？** 因为所有小于 $i \times i$ 的 $i$ 的倍数（如 $2i, 3i, \ldots, (i-1)i$）都已经被比 $i$ 更小的质数标记过了，不需要重复标记。

#### 1.3 线性筛法（欧拉筛 / Linear Sieve）

线性筛的核心思想是：**让每个合数都只被它的最小质因子筛掉**，确保每个合数只被访问一次，从而实现 $O(n)$ 的线性复杂度。

```cpp
vector<int> linearSieve(int n) {
    vector<bool> isPrime(n + 1, true);
    vector<int> primes;
    isPrime[0] = isPrime[1] = false;

    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) {
            primes.push_back(i);  // i是质数
        }
        // 用当前枚举到的质数去筛合数
        for (int p : primes) {
            if (i * p > n) break;     // 超出范围
            isPrime[i * p] = false;   // 标记为合数
            if (i % p == 0) break;    // 关键：p是i的最小质因子时停止
        }
    }
    return primes;
}
```

**线性筛最关键的一行**是 `if (i % p == 0) break;`。它的含义是：当 $p$ 是 $i$ 的最小质因子时，对于更大的质数 $p'$，$i \times p'$ 的最小质因子将是 $p$ 而不是 $p'$，应该由 $p$ 在后续筛掉。这保证了每个合数只被其最小质因子筛一次。

### 二、最大公约数（GCD）与最小公倍数（LCM）

#### 2.1 辗转相除法（欧几里得算法）

求最大公约数的经典算法，基于一个简单的数学原理：

$$\gcd(a, b) = \gcd(b, a \bmod b)$$

当 $b = 0$ 时，$\gcd(a, 0) = a$。

```cpp
// 迭代版
int gcd(int a, int b) {
    while (b != 0) {
        int t = b;
        b = a % b;
        a = t;
    }
    return a;
}

// 递归版（更简洁）
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}
```

C++17 起标准库提供了 `std::gcd(a, b)`，但在竞赛中自己实现更灵活。时间复杂度为 $O(\log \min(a, b))$。

#### 2.2 最小公倍数

最小公倍数与最大公约数的关系为：

$$\operatorname{lcm}(a, b) = \frac{a \times b}{\gcd(a, b)}$$

**重要提示**：计算 `a * b / gcd(a, b)` 时，务必先除后乘，即 `a / gcd(a, b) * b`，否则 $a \times b$ 可能溢出。例如 $a = b = 10^9$ 时，$a \times b = 10^{18}$ 超出了 32 位 `int` 的范围，但除以 gcd 后在 `long long` 范围内。

```cpp
long long lcm(long long a, long long b) {
    return a / gcd(a, b) * b;  // 先除后乘，防止溢出
}
```

### 三、快速幂（Binary Exponentiation）

计算 $a^b \bmod m$，如果直接用循环乘 $b$ 次，复杂度为 $O(b)$。当 $b$ 很大（如 $b \leq 10^9$）时，这显然不可接受。快速幂利用二分思想，将指数按二进制拆解：

$$a^b = a^{b_0 \cdot 2^0} \times a^{b_1 \cdot 2^1} \times \cdots \times a^{b_k \cdot 2^k}$$

其中 $b_i$ 是 $b$ 的二进制第 $i$ 位。实际操作时，我们自底向上计算 $a^{2^i}$，并根据 $b$ 的每一位是否为 1 决定是否将当前结果乘入答案。

**迭代写法**（最常用）：

```cpp
long long quickPow(long long a, long long b, long long mod) {
    long long res = 1;
    a %= mod;
    while (b > 0) {
        if (b & 1) res = res * a % mod;  // 当前二进制位为1
        a = a * a % mod;                  // a = a^2
        b >>= 1;                          // b右移一位
    }
    return res;
}
```

**递归写法**（更直观）：

```cpp
long long quickPow(long long a, long long b, long long mod) {
    if (b == 0) return 1;
    long long half = quickPow(a, b / 2, mod);
    half = half * half % mod;
    if (b % 2 == 1) half = half * a % mod;
    return half;
}
```

时间复杂度为 $O(\log b)$。注意每一步乘法后都要取模，否则中间结果可能溢出。

### 四、约数与倍数

**求一个数的所有约数**：利用"约数成对出现"的性质，只需遍历到 $\sqrt{n}$。

```cpp
vector<int> getDivisors(int n) {
    vector<int> divs;
    for (int i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            divs.push_back(i);
            if (i != n / i) divs.push_back(n / i);  // 成对加入
        }
    }
    sort(divs.begin(), divs.end());  // 排序（可选）
    return divs;
}
```

**判断一个数是否是另一个数的倍数**很简单：`n % m == 0` 即表示 $n$ 是 $m$ 的倍数。

### 模板2：埃氏筛法

```cpp
#include <iostream>
#include <vector>
using namespace std;

vector<int> sieve(int n) {
    vector<bool> isPrime(n + 1, true);
    vector<int> primes;
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) {
            primes.push_back(i);
            if ((long long)i * i <= n) {
                for (int j = i * i; j <= n; j += i) {
                    isPrime[j] = false;
                }
            }
        }
    }
    return primes;
}

int main() {
    int n;
    cin >> n;
    vector<int> primes = sieve(n);
    for (int p : primes) cout << p << ' ';
    cout << endl;
    return 0;
}
```

### 模板4：快速幂（迭代版）

```cpp
#include <iostream>
using namespace std;

const long long MOD = 1e9 + 7;

long long quickPow(long long a, long long b) {
    long long res = 1;
    a %= MOD;
    while (b > 0) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

int main() {
    long long a, b;
    cin >> a >> b;
    cout << quickPow(a, b) << endl;
    return 0;
}
```

## ⚠️ 易错点

- **试除法循环条件 `i * i <= n` 的溢出问题**：当 $n$ 很大（接近 `INT_MAX`）时，`i * i` 可能溢出，导致死循环或错误判断。解决方案是使用 `i <= n / i` 或使用 `long long` 类型的 `i`。

- **LCM 计算时先乘后除导致溢出**：`a * b / gcd(a, b)` 中的 `a * b` 可能溢出。必须改为 `a / gcd(a, b) * b`，利用整数除法的性质先缩小数值。

- **埃氏筛从 `2i` 开始标记**：如果从 `2i` 开始而不是 `i*i`，虽然结果正确，但会做大量重复标记，效率降低。记住优化：从 `i * i` 开始，且注意 $i \times i$ 不能超过 $n$（也需要注意溢出）。

- **快速幂中 `res` 初始化为0而非1**：在乘法单位元的语境下，累乘的单位元是 1 而不是 0。如果 `res = 0`，任何乘法结果都是 0。

- **线性筛中忘记 `if (i % p == 0) break;`**：这会使复杂度退化为 $O(n \log n)$，不再是线性筛。这是线性筛正确性和效率的关键。

## 📝 真题精练

### 题目1：质数距离（改编自CSP-J模拟题）

**题目描述**：
给定一个整数 $n$（$2 \leq n \leq 10^6$），请你输出 $1$ 到 $n$ 之间质数的个数，以及其中最大的质数。

**输入格式**：
一行一个整数 $n$。

**输出格式**：
一行两个整数，分别表示质数个数和最大质数。如果不存在质数，第二项输出 0。

**样例输入**：
```
20
```

**样例输出**：
```
8 19
```

**样例解释**：
1 到 20 之间的质数有 2, 3, 5, 7, 11, 13, 17, 19，共 8 个，最大的是 19。

**AC代码**：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<bool> isPrime(n + 1, true);
    isPrime[0] = isPrime[1] = false;

    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }

    int cnt = 0, maxPrime = 0;
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) {
            cnt++;
            maxPrime = i;
        }
    }

    cout << cnt << ' ' << maxPrime << endl;
    return 0;
}
```

**解析**：直接使用埃氏筛法标记 $1$ 到 $n$ 的所有合数，然后统计质数的个数和找到最大值即可。$n \leq 10^6$，埃氏筛 $O(n \log \log n)$ 完全够用。

### 题目2：最大公约数与最小公倍数

**题目描述**：
给定两个正整数 $a$ 和 $b$（$1 \leq a, b \leq 10^9$），求它们的最大公约数和最小公倍数。

**输入格式**：
一行两个正整数 $a$ 和 $b$。

**输出格式**：
一行两个整数，分别表示 $\gcd(a, b)$ 和 $\operatorname{lcm}(a, b)$。

**样例输入**：
```
12 18
```

**样例输出**：
```
6 36
```

**AC代码**：

```cpp
#include <iostream>
using namespace std;

int gcd(int a, int b) {
    while (b != 0) {
        int t = b;
        b = a % b;
        a = t;
    }
    return a;
}

int main() {
    int a, b;
    cin >> a >> b;

    int g = gcd(a, b);
    long long l = (long long)a / g * b;  // 先除后乘

    cout << g << ' ' << l << endl;
    return 0;
}
```

**解析**：使用辗转相除法求 GCD，然后用公式 $a \times b / \gcd(a, b)$ 求 LCM。注意先除后乘防止溢出——$a$ 和 $b$ 最大可达 $10^9$，直接相乘会溢出 `int`。

## 🎯 本课小结

本课学习了数论的五个核心知识点：
1. **质数判断**：单个数用试除法 $O(\sqrt{n})$，批量用埃氏筛 $O(n \log \log n)$ 或线性筛 $O(n)$。
2. **GCD**：辗转相除法 `gcd(a, b) = gcd(b, a % b)`，递归实现最简洁。
3. **LCM**：`a / gcd(a, b) * b`，务必先除后乘。
4. **快速幂**：二分思想 $O(\log n)$，迭代版最常用，每步取模。
5. **约数**：成对枚举到 $\sqrt{n}$。

这些模板在 CSP-J 中经常出现，建议熟练背诵并能手写。尤其注意溢出问题和边界条件。
