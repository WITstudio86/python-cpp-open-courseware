### 一、树的基本概念

树（Tree）是一种非常重要的非线性数据结构，它模拟了一种层级关系。树由节点（Node）和边（Edge）组成，具有以下特征：
- 每个树有且仅有一个根节点（Root）
- 除根节点外，每个节点有且仅有一个父节点（Parent）
- 每个节点可以有零个或多个子节点（Child）
- 没有子节点的节点称为叶子节点（Leaf）

**树 vs 图**：树是一种特殊的图——连通且无环的无向图。换句话说，一个有n个节点的树恰好有n-1条边。这个性质经常在CSP-J题目中出现。

```cpp
// 树节点的基本结构
struct TreeNode {
    int val;              // 节点值
    TreeNode* left;       // 左子节点
    TreeNode* right;      // 右子节点
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

**树的基本术语**：
- **深度（Depth）**：从根节点到该节点的路径长度（边的数量）。根的深度为0。
- **高度（Height）**：从该节点到最远叶子节点的路径长度。叶子的高度为0。树的高度等于根节点的高度。
- **度（Degree）**：一个节点拥有的子节点数目。
- **子树**：以某节点为根的树，包含该节点及其所有后代。

### 二、二叉树及其性质

二叉树（Binary Tree）是每个节点最多有两个子节点的树，分别称为左子节点和右子节点。二叉树是树中最重要的类型。

**重要性质**：

1. **第i层节点数**：在二叉树的第i层上，最多有2^(i-1)个节点（i >= 1）。

   推导：第1层（根节点所在层）最多1个节点（2^0 = 1），第2层最多2个节点（2^1 = 2），第3层最多4个节点（2^2 = 4），以此类推。用数学归纳法可证：假设第k层最多2^(k-1)个，每个节点最多2个子节点，则第k+1层最多2 * 2^(k-1) = 2^k个。

2. **深度为k的二叉树最多节点数**：深度为k的二叉树最多有2^k - 1个节点（k >= 1）。

   推导：等比数列求和。最多节点数 = 2^0 + 2^1 + 2^2 + ... + 2^(k-1) = 2^k - 1。

3. **满二叉树**：深度为k且有2^k - 1个节点的二叉树（每一层都填满）。

4. **完全二叉树**：除最后一层外，每层都填满，且最后一层的节点都靠左排列。完全二叉树是常考概念，堆（heap）就是基于完全二叉树的。

5. **叶子节点与度为2的节点关系**：对于任意二叉树，如果叶子节点数为n0，度为2的节点数为n2，则 n0 = n2 + 1。

   推导：设总结点数为n，边数为e（e = n - 1，因为树有n-1条边）。又设度为1的节点数为n1。有：n = n0 + n1 + n2。从边的角度看：e = 0 * n0 + 1 * n1 + 2 * n2 = n1 + 2n2。所以 n - 1 = n1 + 2n2，即 (n0 + n1 + n2) - 1 = n1 + 2n2，得到 n0 = n2 + 1。这个性质偶尔会在选择题或填空题中出现。

**特殊二叉树**：
- **二叉搜索树（BST）**：左子树所有节点的值 < 根的值 < 右子树所有节点的值。
- **平衡二叉树（AVL）**：任意节点左右子树高度差不超过1。

### 三、二叉树的遍历

二叉树的遍历是CSP-J的必考内容，必须熟练掌握四种遍历方式。

#### 3.1 前序遍历（Preorder）：根 → 左 → 右

```cpp
void preorder(TreeNode* root) {
    if (root == nullptr) return;
    cout << root->val << " ";     // 先访问根
    preorder(root->left);         // 再访问左子树
    preorder(root->right);        // 最后访问右子树
}
```

**特点**：第一个访问的节点一定是根节点。

#### 3.2 中序遍历（Inorder）：左 → 根 → 右

```cpp
void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);          // 先访问左子树
    cout << root->val << " ";     // 再访问根
    inorder(root->right);         // 最后访问右子树
}
```

**特点**：对于二叉搜索树（BST），中序遍历的结果是递增有序的。

#### 3.3 后序遍历（Postorder）：左 → 右 → 根

```cpp
void postorder(TreeNode* root) {
    if (root == nullptr) return;
    postorder(root->left);        // 先访问左子树
    postorder(root->right);       // 再访问右子树
    cout << root->val << " ";     // 最后访问根
}
```

**特点**：最后一个访问的节点一定是根节点。

#### 3.4 层序遍历（Level-order）：按层从上到下、每层从左到右

层序遍历需要使用队列（BFS思想）：

```cpp
void levelorder(TreeNode* root) {
    if (root == nullptr) return;
    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        TreeNode* cur = q.front();
        q.pop();
        cout << cur->val << " ";
        if (cur->left != nullptr) q.push(cur->left);
        if (cur->right != nullptr) q.push(cur->right);
    }
}
```

**特点**：层序遍历按"深度"顺序访问，先访问深度小的节点。

#### 3.5 根据遍历序列重建二叉树

CSP-J中常见的题目是"已知前序和中序，求后序"或"已知中序和后序，求前序"。核心原理：
- 前序的第一个节点是根节点
- 后序的最后一个节点是根节点
- 中序中根节点左边的是左子树，右边的是右子树

**不能唯一确定的情况**：已知前序和后序，不能唯一确定二叉树（因为无法区分左右子树为空的情况）。

```cpp
// 已知前序pre[pl..pr]和中序in[il..ir]，重建二叉树
TreeNode* build(vector<int>& pre, int pl, int pr,
                vector<int>& in, int il, int ir) {
    if (pl > pr) return nullptr;
    int rootVal = pre[pl];             // 前序第一个是根
    TreeNode* root = new TreeNode(rootVal);
    int pos = il;                      // 在中序中找根的位置
    while (in[pos] != rootVal) pos++;
    int leftSize = pos - il;           // 左子树大小
    root->left = build(pre, pl + 1, pl + leftSize, in, il, pos - 1);
    root->right = build(pre, pl + leftSize + 1, pr, in, pos + 1, ir);
    return root;
}
```

### 四、并查集（Union-Find）入门

并查集是处理"不相交集合的合并与查询"问题的数据结构，在CSP-J中经常出现。它支持两种操作：
- **Find**：查找元素属于哪个集合（集合用代表元素标识）
- **Union**：将两个元素所在的集合合并

#### 4.1 基础版本

```cpp
int parent[MAXN];

void init(int n) {
    for (int i = 1; i <= n; i++)
        parent[i] = i;  // 初始化：每个元素自成集合
}

int find(int x) {
    if (parent[x] == x) return x;
    return find(parent[x]);  // 沿着链向上查找
}

void union_sets(int a, int b) {
    int ra = find(a);
    int rb = find(b);
    if (ra != rb)
        parent[ra] = rb;  // 将a的根连到b的根
}
```

**问题**：如果树退化成链，find操作的最坏时间复杂度为O(n)。

#### 4.2 路径压缩优化

在find过程中，将路径上的所有节点直接连到根节点，使后续查找大幅加速。

```cpp
int find(int x) {
    if (parent[x] == x) return x;
    return parent[x] = find(parent[x]);  // 路径压缩
}
```

这个写法虽然只有一行代码的变化，但效果极大——经过路径压缩后，find操作的均摊时间复杂度近似为O(alpha(n))，其中alpha是阿克曼函数的反函数，在n <= 2^65536时都不超过5，基本可以视为O(1)。

#### 4.3 按秩合并优化

在union时，将较小的树合并到较大的树上，避免树的高度过度增长。

```cpp
int parent[MAXN];
int rnk[MAXN];  // 秩（近似树的高度）

void init(int n) {
    for (int i = 1; i <= n; i++) {
        parent[i] = i;
        rnk[i] = 0;
    }
}

int find(int x) {
    if (parent[x] == x) return x;
    return parent[x] = find(parent[x]);
}

void union_sets(int a, int b) {
    int ra = find(a);
    int rb = find(b);
    if (ra == rb) return;
    if (rnk[ra] < rnk[rb])
        parent[ra] = rb;
    else if (rnk[ra] > rnk[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rnk[ra]++;
    }
}
```

#### 4.4 并查集的应用场景

1. **判断连通性**：两个节点是否在同一个连通分量中（find(a) == find(b)）。
2. **统计连通分量数量**：执行完所有union后，统计不同的find(i)值个数。
3. **最小生成树（Kruskal算法）**：判断加边是否会形成环。
4. **朋友圈问题**：给定好友关系，求有多少个社交圈子。

### 五、解题技巧总结

1. **遍历顺序记忆口诀**：
   - 前序：根左右
   - 中序：左根右
   - 后序：左右根
   - 记忆要点：前/中/后指的是"根"的位置，左总在右之前。

2. **递归与栈的关系**：前/中/后序遍历本质上是DFS过程，递归隐式使用了系统栈。如果题目要求"非递归实现"，可以显式使用stack。

3. **并查集find的口诀**：`return parent[x] = find(parent[x])` 这个一行代码包含了递归查找+路径压缩，必须熟记。

4. **树的存储方式**：
   - 链式存储：使用指针或引用连接父子关系（适合动态结构）
   - 数组存储：使用数组下标作为节点编号，parent数组记录父节点（简单方便）
   - 对于完全二叉树，可以用数组顺序存储：节点i的左子节点在2i，右子节点在2i+1（下标从1开始）

#include <iostream>

using namespace std;

TreeNode* buildTree(vector<int>& pre, int pl, int pr,

    if (pl > pr || il > ir) return nullptr;
    int rootVal = pre[pl];

## ⚠️ 易错点

- **错误1：遍历顺序混淆**。将中序的"左根右"写成"右根左"，或将前序的"根左右"写成"根右左"。虽然写错后程序不会报错，但遍历结果完全不同，会导致题目答案错误。**解决方法**：记住"前序：根打头；中序：根居中；后序：根收尾"。多画图验证。

- **错误2：递归遍历时忘记空指针判断**。在调用preorder(root->left)前没有判断if(root)，当递归到叶子节点的子节点（nullptr）时会导致访问空指针崩溃。**解决方法**：递归函数第一行务必写`if (!root) return;`。

- **错误3：并查集find中没有路径压缩导致超时**。在节点数较大的情况下（n >= 10000），如果不写路径压缩（`return parent[x] = find(parent[x])`），最坏情况下find退化为O(n)，大量查询会TLE。**解决方法**：无论题目有没有明确要求，养成写路径压缩的习惯。

- **错误4：union时忘记判断是否已经在同一集合**。如果a和b已经在同一集合中（find(a) == find(b)），再次执行union会浪费操作，而且在某些场景（如Kruskal算法中统计连通分量）可能导致错误结果。**解决方法**：union开头写`if (ra == rb) return;`。

- **错误5：完全二叉树数组下标计算错误**。使用数组存储完全二叉树时，下标从1开始：节点i的左子节点是2*i，右子节点是2*i+1，父节点是i/2。如果下标从0开始，则左子节点是2*i+1，右子节点是2*i+2。混淆这两种约定会导致访问错误的节点。**解决方法**：统一使用下标从1开始的约定，更加直观。

- **错误6：树的性质死记硬背，不理解推导**。只记住"第i层最多2^(i-1)个节点"但不理解为什么，遇到变形题（如三叉树、k叉树）就无从下手。**解决方法**：理解推导过程——每层节点数是上一层的k倍，等比数列。

### 题目1：树的遍历输出

**题目描述**：给定一棵二叉树的前序遍历序列和中序遍历序列，请输出该二叉树的后序遍历序列。节点值均为互不相同的大写英文字母。

**输入格式**：
第一行一个字符串，表示前序遍历序列（长度不超过26）。
第二行一个字符串，表示中序遍历序列（长度与前序相同）。

**输出格式**：
输出一行字符串，表示后序遍历序列。

**样例输入**：
```
ABDECF
DBEACF
```

**样例输出**：
```
DEBFCA
```

**AC代码**：

```cpp
#include <iostream>
#include <string>
using namespace std;

struct TreeNode {
    char val;
    TreeNode *left, *right;
    TreeNode(char x) : val(x), left(nullptr), right(nullptr) {}
};

TreeNode* build(string pre, string in) {
    if (pre.empty() || in.empty()) return nullptr;
    char rootVal = pre[0];
    TreeNode* root = new TreeNode(rootVal);
    int pos = in.find(rootVal);  // 根在中序中的位置
    // 左子树的pre和in
    root->left = build(pre.substr(1, pos), in.substr(0, pos));
    // 右子树的pre和in
    root->right = build(pre.substr(pos + 1), in.substr(pos + 1));
    return root;
}

void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    cout << root->val;
}

int main() {
    string pre, in;
    cin >> pre >> in;
    TreeNode* root = build(pre, in);
    postorder(root);
    cout << endl;
    return 0;
}
```

**解析**：这是"前序+中序求后序"的经典题目。核心在于从pre中找到根（第一个字符），在in中找到根的位置，确定左右子树的范围，然后递归重建。后序直接按"左右根"的顺序输出。

### 题目2：朋友圈

**题目描述**：学校有n个学生（编号1到n），给出m对学生之间的关系（表示他们是朋友）。朋友关系具有传递性：如果A和B是朋友，B和C是朋友，那么A和C也是朋友（在一个朋友圈中）。请计算总共有多少个朋友圈。

**输入格式**：
第一行两个整数n, m（1 <= n <= 100000, 0 <= m <= 200000）。
接下来m行，每行两个整数u, v，表示u和v是朋友。

**输出格式**：
输出一个整数，表示朋友圈的数量。

**样例输入**：
```
5 3
1 2
2 3
4 5
```

**样例输出**：
```
2
```

**样例解释**：{1, 2, 3}形成一个朋友圈，{4, 5}形成另一个朋友圈，共2个。

**AC代码**：

```cpp
#include <iostream>
using namespace std;

const int MAXN = 100005;
int parent[MAXN];
int rnk[MAXN];

void init(int n) {
    for (int i = 1; i <= n; i++) {
        parent[i] = i;
        rnk[i] = 0;
    }
}

int find(int x) {
    if (parent[x] == x) return x;
    return parent[x] = find(parent[x]);
}

void union_sets(int a, int b) {
    int ra = find(a);
    int rb = find(b);
    if (ra == rb) return;
    if (rnk[ra] < rnk[rb])
        parent[ra] = rb;
    else if (rnk[ra] > rnk[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rnk[ra]++;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;
    init(n);

    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        union_sets(u, v);
    }

    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        if (find(i) == i) cnt++;  // 根节点的数量 = 集合数量
    }
    cout << cnt << endl;
    return 0;
}
```

**解析**：典型并查集应用。将所有朋友关系union后，统计`parent[i] == i`（或`find(i) == i`）的节点个数，即为朋友圈个数。注意这里使用`find(i) == i`而非`parent[i] == i`，因为有些节点的parent指向了根节点但parent值可能不是自身（尽管在路径压缩后这两者通常等价，但为了保险建议用find(i)）。

## 🎯 本课小结

1. **树的基本概念**：n个节点的树有n-1条边，无环连通图。理解根、父、子、叶子、深度、高度、度等术语。
2. **二叉树性质**：第i层最多2^(i-1)个节点，深度k的二叉树最多2^k - 1个节点，n0 = n2 + 1。
3. **四种遍历**：前序（根左右）、中序（左根右）、后序（左右根）、层序（BFS按层）。务必能写出递归代码并手算遍历结果。
4. **遍历序列重建**：前序+中序或后序+中序可唯一重建二叉树，关键是找到根节点在中序中的位置并确定左右子树范围。
5. **并查集核心操作**：find（带路径压缩的查找）+ union（按秩合并）。路径压缩的一行代码`return parent[x] = find(parent[x])`必须熟记。
6. **并查集应用**：判断连通性、统计连通分量数、Kruskal算法。时间复杂度接近O(1)（阿克曼函数反函数）。
7. **考试重点**：二叉树的遍历结果是CSP-J选择题和填空题的必考内容，并查集的路径压缩是代码题的常见考点。
