### 一、为什么需要函数

在编写程序时，我们经常会遇到需要在不同位置重复执行的逻辑。比如判断一个数是否为素数，可能在程序中多处用到。如果每次都把判断素数的代码重新写一遍，程序会变得冗长、难以维护、容易出错。

函数（Function）就是解决这个问题的核心工具。它把一段具有特定功能的代码封装成一个独立的模块，给它取一个名字，需要时通过名字来调用即可。

使用函数有三大好处：

1. **代码复用**：写一次，多次调用。修改逻辑时只需改一处。
2. **模块化**：将复杂问题拆解为若干小问题，每个函数解决一个小问题。
3. **可维护性**：程序结构清晰，调试时更容易定位问题。

```cpp
// 没有函数的情况 —— 重复代码多，容易出错
#include <iostream>
using namespace std;

int main() {
    // 判断 17 是不是素数
    int n1 = 17;
    bool f1 = true;
    for (int i = 2; i * i <= n1; i++) {
        if (n1 % i == 0) { f1 = false; break; }
    }
    cout << (f1 ? "YES" : "NO") << endl;

    // 判断 29 是不是素数 —— 又要写一遍完全相同的逻辑
    int n2 = 29;
    bool f2 = true;
    for (int i = 2; i * i <= n2; i++) {
        if (n2 % i == 0) { f2 = false; break; }
    }
    cout << (f2 ? "YES" : "NO") << endl;
    return 0;
}
```

```cpp
// 有了函数之后 —— 简洁、清晰、易维护
#include <iostream>
using namespace std;

bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    cout << (isPrime(17) ? "YES" : "NO") << endl;
    cout << (isPrime(29) ? "YES" : "NO") << endl;
    return 0;
}
```

### 二、函数定义的四要素

在 C++ 中，一个完整的函数定义由四个部分构成：

```
返回类型  函数名  (参数列表) {
    函数体
}
```

#### 要素一：返回类型

返回类型告诉编译器这个函数会返回什么类型的数据。它写在函数名的最前面。

- `int` —— 返回整数
- `bool` —— 返回布尔值（true 或 false）
- `double` —— 返回浮点数
- `char` —— 返回字符
- `string` —— 返回字符串
- `void` —— 不返回任何数据

```cpp
int add(int a, int b) {       // 返回类型是 int
    return a + b;
}

bool isEven(int n) {          // 返回类型是 bool
    return n % 2 == 0;
}

void printHello() {           // 返回类型是 void，没有返回值
    cout << "Hello!" << endl;
}
```

**注意**：返回类型必须与 return 语句中表达式的类型匹配。例如返回类型是 `int`，就不能 `return 3.14;`（会发生隐式转换，小数部分丢失）。

#### 要素二：函数名

函数名是调用函数时使用的标识符。命名规则与变量名相同：由字母、数字、下划线组成，不能以数字开头，不能使用 C++ 关键字。

命名建议：
- 使用动词或动词短语，体现"做什么"
- 驼峰命名法：`isPrime`、`getMax`、`sumOfDigits`
- 下划线命名法：`is_prime`、`get_max`、`sum_of_digits`（两种风格都可以，但要保持一致）

```cpp
// 好的命名
int getMax(int a, int b);          // 一看就知道是取最大值
bool isPrime(int n);               // 判断是否素数
void printArray(int arr[], int n); // 打印数组

// 不好的命名
int f(int a, int b);               // f 是什么？无法理解
bool check(int n);                 // check 什么？含糊不清
```

#### 要素三：参数列表

参数列表放在函数名后面的圆括号里，用于接收调用者传入的数据。参数列表可以为空，此时写一对空括号 `()`。

每个参数都要写明类型和名称，多个参数之间用逗号分隔。

```cpp
// 无参数
void sayHello() {
    cout << "Hello, CSP-J!" << endl;
}

// 一个参数
int square(int x) {
    return x * x;
}

// 两个参数
int max2(int a, int b) {
    return a > b ? a : b;
}

// 三个参数
int max3(int a, int b, int c) {
    return max2(max2(a, b), c);
}
```

参数列表中的参数称为**形式参数**（形参），调用时传入的具体数值称为**实际参数**（实参）。关于形参和实参的深入讨论将在第 18 课展开。

#### 要素四：函数体

函数体是用一对花括号 `{}` 包裹起来的代码块，定义了函数要执行的具体操作。

```cpp
int factorial(int n) {
    // 函数体开始
    int result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
    // 函数体结束
}
```

函数体中至少应该包含一条 `return` 语句（返回类型为 `void` 时可以不写，或者写 `return;` 直接返回）。函数执行到 `return` 语句时立即结束，并将 `return` 后面的表达式的值返回给调用者。

### 三、函数声明与定义的分离

#### 基本概念

- **函数声明**（也叫函数原型，Function Prototype）：只写出返回类型、函数名和参数列表，以分号结尾，不写函数体。
- **函数定义**：写出完整的函数体。

```cpp
// 函数声明（原型）—— 只告诉编译器"有这样的函数"
int add(int a, int b);

// 函数定义 —— 告诉编译器"这个函数具体做什么"
int add(int a, int b) {
    return a + b;
}
```

#### 为什么要分离声明和定义

C++ 编译器从上到下逐行编译源代码。如果函数 A 调用函数 B，那么函数 B 必须在函数 A 之前定义，否则编译器会报"未声明的标识符"错误。

```cpp
// 错误示例 —— 编译失败
#include <iostream>
using namespace std;

int main() {
    cout << add(3, 5) << endl;  // 错误：add 尚未声明
    return 0;
}

int add(int a, int b) {
    return a + b;
}
```

有两种解决方法：

**方法一**：把被调用函数写在前面。

```cpp
int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(3, 5) << endl;  // 正确
    return 0;
}
```

**方法二**：把函数声明写在前面，定义写在后面（推荐）。

```cpp
// 所有函数声明集中放在文件开头
int add(int a, int b);
int subtract(int a, int b);
int multiply(int a, int b);

int main() {
    cout << add(3, 5) << endl;
    cout << subtract(10, 4) << endl;
    cout << multiply(6, 7) << endl;
    return 0;
}

// 所有函数定义放在 main 之后
int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }
int multiply(int a, int b) { return a * b; }
```

方法二是最推荐的组织方式，因为它：
1. 让阅读代码的人一眼看到程序提供了哪些功能（声明就是"目录"）
2. 不必关心函数之间的调用顺序
3. 是多文件项目的基础（声明放在头文件 `.h` 中，定义放在源文件 `.cpp` 中）

### 四、函数调用机制

当程序执行到函数调用语句时，背后发生了一系列操作。了解这个过程有助于理解变量的作用域和参数传递。

#### 调用过程的四个步骤

1. **压栈（Push）**：将实参的值、当前函数的返回地址（即调用语句的下一条指令的地址）压入调用栈（Call Stack）。
2. **跳转（Jump）**：程序计数器跳转到被调用函数的入口地址，开始执行函数体。
3. **执行**：在函数体内执行代码，形参的值为实参压栈时的副本。
4. **返回（Return）**：执行到 `return` 语句时，将返回值存入指定位置（通常是寄存器），弹出调用栈中保存的信息，程序计数器跳回返回地址，继续执行调用函数的下一条语句。

#### 一个简单的图解说明

```
main 函数执行:                    调用栈变化:
┌─────────────────┐              ┌──────────────┐
│ int x = 3;      │              │  栈顶 →     │
│ int y = 5;      │              │  局部变量   │
│ int z = add(3,5)│──调用──→     │  返回地址   │
│       ↓         │              │  形参 b=5   │
│   (返回后继续)  │←──返回──     │  形参 a=3   │
│ cout << z;      │              │  栈底 →     │
└─────────────────┘              └──────────────┘
```

对于 CSP-J 学生来说，不需要深入理解汇编级别的调用细节，但需要建立"函数调用时形参会获得实参的一个副本，函数内部的修改不影响外部的原始变量"这一核心概念。这就是第 18 课要深入讲解的**值传递**。

### 五、返回值的几种使用模式

#### 模式一：直接使用

```cpp
cout << max2(10, 20) << endl;  // 直接在输出中使用
```

#### 模式二：赋值给变量

```cpp
int result = max2(10, 20);     // 赋值给变量保存
cout << result << endl;
```

#### 模式三：作为条件判断

```cpp
if (isPrime(n)) {
    cout << n << " 是素数" << endl;
}
```

#### 模式四：作为另一个函数的实参

```cpp
cout << max3(max2(10, 20), 30) << endl;  // 嵌套调用
```

#### 返回值类型匹配规则

- 返回类型是 `int`，return 后面的表达式应该是整数类型。如果 return 一个 `double`，小数部分会被截断。
- 返回类型是 `bool`，return 后面的表达式会被隐式转换为 `true` 或 `false`（非零即为 true）。
- 返回类型是 `void`，不能有带返回值的 `return` 语句。

```cpp
int getValue() {
    return 3.14;  // 危险：3.14 被截断为 3，可能导致逻辑错误
}

// 正确做法：根据函数目的选择合适的返回类型
double getValueDouble() {
    return 3.14;  // 正确，返回类型匹配
}
```

### 六、void 函数

`void` 类型的函数不返回任何值。它们通常用于执行某些操作而不需要返回结果，比如打印输出、修改全局状态等。

```cpp
void printLine(char ch, int len) {
    for (int i = 0; i < len; i++) {
        cout << ch;
    }
    cout << endl;
}

void printArray(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}
```

void 函数中的 `return` 语句（不带值）是可选的。如果函数执行到末尾自然结束，也相当于执行了 `return;`。

```cpp
void greet(int hour) {
    if (hour < 6) {
        cout << "夜深了，早点休息！" << endl;
        return;  // 提前返回
    }
    if (hour < 12) {
        cout << "早上好！" << endl;
        return;
    }
    cout << "下午好！" << endl;
    // 函数末尾可以不写 return;
}
```

void 函数**不能**作为表达式的一部分使用，也不能赋值给变量：

```cpp
int x = printHello();  // 编译错误：void 函数没有返回值
```

### 七、main 函数的特殊地位

`main` 函数是每个 C++ 程序的入口点。当程序启动时，操作系统会调用 `main` 函数，程序从 `main` 的第一条语句开始执行，到 `main` 的最后一条语句（或遇到 `return`）时结束。

`main` 函数的特殊之处：

1. **它是程序唯一必需的函数**。没有 `main` 函数，链接器会报错。
2. **它的返回类型必须是 `int`**。返回 0 表示程序正常结束，返回非零值表示异常退出。
3. **它不能被程序中的其他函数调用**。只有操作系统（或运行时环境）可以调用 `main`。
4. **它有两种合法的定义形式**：

```cpp
// 形式一：无参数
int main() {
    // ...
    return 0;
}

// 形式二：带命令行参数（CSP-J 一般不涉及）
int main(int argc, char* argv[]) {
    // ...
    return 0;
}
```

5. **return 0; 可以省略**。在 C++ 标准中，`main` 函数如果不写 `return` 语句，编译器会隐式添加 `return 0;`。但建议明确写出，养成好习惯。

```cpp
int main() {
    // 程序的所有调用都从这里开始
    cout << "程序开始" << endl;

    // 调用各种自定义函数
    doTask1();
    doTask2();
    printResult();

    cout << "程序结束" << endl;
    return 0;  // 明确表示程序正常退出
}
```

### 八、函数设计原则

#### 单一职责原则

一个函数只做一件事，并且把它做好。如果一个函数既要计算又要打印又要读写文件，就应当拆分成多个函数。

```cpp
// 不好的设计：一个函数做了太多事情
void process(int n) {
    // 判断素数
    bool isP = true;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) { isP = false; break; }
    }
    // 又要求阶乘
    long long fact = 1;
    for (int i = 1; i <= n; i++) fact *= i;
    // 又要求各位和
    int sum = 0, tmp = n;
    while (tmp > 0) { sum += tmp % 10; tmp /= 10; }
    // 还要打印所有结果
    cout << isP << " " << fact << " " << sum << endl;
}

// 好的设计：每个函数只做一件事
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}

long long factorial(int n) {
    long long result = 1;
    for (int i = 1; i <= n; i++) result *= i;
    return result;
}

int sumOfDigits(int n) {
    int sum = 0;
    while (n > 0) { sum += n % 10; n /= 10; }
    return sum;
}

int main() {
    int n = 17;
    cout << "素数判断: " << (isPrime(n) ? "是" : "否") << endl;
    cout << "阶乘: " << factorial(n) << endl;
    cout << "各位和: " << sumOfDigits(n) << endl;
    return 0;
}
```

#### 命名规范

| 规则 | 示例 |
|------|------|
| 函数名使用动词开头 | `calculate`, `print`, `get`, `set`, `is`, `has` |
| 布尔函数用 `is` 或 `has` 开头 | `isPrime`, `isEven`, `hasDuplicates` |
| 获取值的函数用 `get` 或直接名词 | `getMax`, `getSum`, `reverseNumber` |
| 不产生副作用的函数（纯函数）优先 | 传入参数，返回结果，不修改外部状态 |

## 💻 代码模板

### 模板一：多函数的完整组织

本模板展示函数的声明、定义和调用的完整组织方式，包含 `isPrime`（素数判断）、`max2`（两个数最大值）、`max3`（三个数最大值）、`printArray`（打印数组）四个实用函数。

```cpp
#include <iostream>
using namespace std;

// ========== 函数声明（原型） ==========
bool isPrime(int n);
int max2(int a, int b);
int max3(int a, int b, int c);
void printArray(int arr[], int n);

// ========== 主函数 ==========
int main() {
    // 测试 isPrime
    int x = 17;
    cout << x << (isPrime(x) ? " 是素数" : " 不是素数") << endl;

    // 测试 max2 和 max3
    cout << "max(10, 25) = " << max2(10, 25) << endl;
    cout << "max(10, 25, 18) = " << max3(10, 25, 18) << endl;

    // 测试 printArray
    int arr[] = {1, 3, 5, 7, 9};
    printArray(arr, 5);

    return 0;
}

// ========== 函数定义 ==========
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}

int max2(int a, int b) {
    return a > b ? a : b;
}

int max3(int a, int b, int c) {
    return max2(max2(a, b), c);
}

void printArray(int arr[], int n) {
    cout << "数组内容: ";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;
}
```

### 模板二：数字操作函数集

本模板展示先声明、后定义的函数组织方式，包含 `sumOfDigits`（各位数字之和）、`reverseNumber`（反转数字）、`isPalindrome`（回文数判断）三个与数字操作相关的函数。

```cpp
#include <iostream>
using namespace std;

// ========== 函数声明 ==========
int sumOfDigits(int n);
int reverseNumber(int n);
bool isPalindrome(int n);

// ========== 主函数 ==========
int main() {
    int num = 12321;

    cout << "数字: " << num << endl;
    cout << "各位数字之和: " << sumOfDigits(num) << endl;
    cout << "反转后的数字: " << reverseNumber(num) << endl;
    cout << "是否回文数: " << (isPalindrome(num) ? "是" : "否") << endl;

    // 再测试一个非回文数
    int num2 = 12345;
    cout << "\n数字: " << num2 << endl;
    cout << "各位数字之和: " << sumOfDigits(num2) << endl;
    cout << "反转后的数字: " << reverseNumber(num2) << endl;
    cout << "是否回文数: " << (isPalindrome(num2) ? "是" : "否") << endl;

    return 0;
}

// ========== 函数定义 ==========
int sumOfDigits(int n) {
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

int reverseNumber(int n) {
    int rev = 0;
    while (n > 0) {
        rev = rev * 10 + n % 10;
        n /= 10;
    }
    return rev;
}

bool isPalindrome(int n) {
    return n == reverseNumber(n);
}
```

## ⚠️ 易错点

### 易错点一：函数声明和定义的类型不一致

```cpp
// 错误：声明返回 int，定义返回 double
int getValue();        // 声明

double getValue() {    // 错误：与声明的返回类型不匹配！
    return 3.14;
}
```

**原因**：C++ 编译器通过函数签名（返回类型 + 函数名 + 参数列表）来识别函数。如果声明和定义的返回类型不同，编译器会报告"函数重定义"或"类型冲突"错误。

**如何避免**：声明和定义必须逐字逐句地保持一致（参数名可以不同，但类型和数量必须完全一致）。建议先写好完整的函数定义，然后把函数头复制粘贴到前面加个分号就变成了声明。

### 易错点二：忘记写 return 语句

```cpp
// 错误：函数有非 void 返回类型，但没有 return 语句
int max2(int a, int b) {
    if (a > b) {
        cout << a << endl;  // 没有 return！
    }
    // 函数结束也没有 return！
}
```

**原因**：当函数声明的返回类型不是 `void` 时，编译器要求函数的每一条执行路径都必须有 `return` 语句。上面的代码中，如果 `a > b` 为真，执行完之后没有 `return`；如果 `a > b` 为假，函数执行到末尾也没有 `return`。这属于**未定义行为**（Undefined Behavior），程序可能返回一个随机的"垃圾值"。

**如何避免**：
1. 写完函数后检查所有分支是否都有 `return`。
2. 使用编译器的警告选项（如 `-Wall`）让编译器帮你检查。
3. 如果一个函数的所有分支都应该返回值，就把 `return` 写在最后面作为默认情况。

```cpp
// 修正后
int max2(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}
```

### 易错点三：函数声明忘记加分号

```cpp
// 错误：声明语句缺少分号
int add(int a, int b)   // 编译器会认为这是函数定义的开始

int main() {            // 编译错误：int 前缺少分号
    // ...
}
```

**原因**：函数声明是一个独立的语句，必须以分号结尾。如果忘记加分号，编译器会把下面的内容当作函数定义的一部分，产生一连串难以理解的错误信息。

**如何避免**：写完函数声明后立即检查末尾是否有分号。养成良好的习惯——函数声明分号结尾，函数定义花括号开头。

### 易错点四：在 void 函数中使用带返回值的 return

```cpp
void printMessage() {
    cout << "Hello" << endl;
    return 0;  // 错误：void 函数不能返回 int 值
}
```

**原因**：`void` 类型表示"没有返回值"，所以 `return` 后面不能跟任何表达式。如果确实需要提前退出函数，应该写 `return;`（不带任何值）。

**如何避免**：在 void 函数中，要么不写 `return`（让函数自然结束），要么只写 `return;`。不要画蛇添足地加上返回值。

### 题目一：统计 1 到 n 的素数个数

**题目描述**

给定一个正整数 n（1 ≤ n ≤ 100000），请统计 1 到 n 之间（包含 1 和 n）有多少个素数。

要求：必须定义一个名为 `isPrime` 的函数来判断一个数是否为素数，在 `main` 函数中调用它来完成统计。

**输入格式**

一个正整数 n。

**输出格式**

一个整数，表示 1 到 n 之间的素数个数。

**样例输入**

```
20
```

**样例输出**

```
8
```

**样例解释**

1 到 20 之间的素数有：2, 3, 5, 7, 11, 13, 17, 19，共 8 个。

**AC 代码**

```cpp
#include <iostream>
using namespace std;

bool isPrime(int x) {
    if (x < 2) return false;
    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) return false;
    }
    return true;
}

int main() {
    int n, cnt = 0;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        if (isPrime(i)) cnt++;
    }
    cout << cnt << endl;
    return 0;
}
```

### 题目二：完美数检测

**题目描述**

如果一个正整数等于除它自身以外的所有正因子之和，则称该数为**完美数**（Perfect Number）。例如：
- 6 的因子有 1, 2, 3, 6，除自身外 1 + 2 + 3 = 6，所以 6 是完美数。
- 28 的因子有 1, 2, 4, 7, 14, 28，除自身外 1 + 2 + 4 + 7 + 14 = 28，所以 28 是完美数。

给定一个正整数 n（1 ≤ n ≤ 10000），判断 n 是否为完美数。

要求：必须定义一个名为 `isPerfect` 的函数来判断。

**输入格式**

一个正整数 n。

**输出格式**

如果 n 是完美数，输出 `YES`；否则输出 `NO`。

**样例输入 1**

```
6
```

**样例输出 1**

```
YES
```

**样例输入 2**

```
10
```

**样例输出 2**

```
NO
```

**AC 代码**

```cpp
#include <iostream>
using namespace std;

int sumOfDivisors(int x) {
    int sum = 0;
    for (int i = 1; i <= x / 2; i++) {
        if (x % i == 0) {
            sum += i;
        }
    }
    return sum;
}

bool isPerfect(int x) {
    return x == sumOfDivisors(x);
}

int main() {
    int n;
    cin >> n;
    cout << (isPerfect(n) ? "YES" : "NO") << endl;
    return 0;
}
```

**说明**：这里我们额外定义了一个 `sumOfDivisors` 函数来计算除自身外所有正因子之和，体现了"一个函数只做一件事"的设计原则。当然也可以直接在 `isPerfect` 内部完成所有逻辑。
