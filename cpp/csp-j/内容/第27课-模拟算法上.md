## 📖 知识精讲

### 一、模拟算法的核心思想

模拟算法（Simulation Algorithm）是CSP-J中考察频率最高的一类算法。它的核心思想非常简单：**按照题目描述的规则，一步一步地在程序中复现这个过程**。

与其他算法（如动态规划需要推导状态转移方程、贪心需要证明正确性）不同，模拟算法不需要复杂的数学推导，只需要做到两点：

1. **准确理解规则**：把题目描述的每一步规则都转化为代码。
2. **正确维护状态**：确保程序中的变量始终反映当前的真实状态。

模拟算法题目的难点不在于算法本身，而在于**细节处理**——边界条件、特殊情况、数据范围等。一道模拟题可能有几十行的代码，任何一个细节出错都可能导致答案错误。因此，写模拟题的核心能力是"细心"和"结构化思维"。

### 二、过程模拟

过程模拟是最基础的模拟形式：将题目描述的操作流程直接翻译成代码。典型例子包括：模拟一个计算器的运算过程、模拟排队叫号、模拟电梯运行等。

以"数字反转"为例，模拟将一个整数各位数字反转的过程：

```cpp
// 数字反转模拟
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int sign = 1;
    if (n < 0) {
        sign = -1;
        n = -n;  // 先转为正数处理
    }
    
    int reversed = 0;
    while (n > 0) {
        int digit = n % 10;           // 取出最低位
        reversed = reversed * 10 + digit;  // 将取出的位"追加"到结果中
        n /= 10;                      // 去掉最低位
    }
    
    cout << sign * reversed << endl;
    return 0;
}
```

这个过程模拟了"逐位取出、逐位追加"的手工反转过程。while循环每轮处理一个数字位，直到所有位都处理完毕。变量reversed始终维护"当前已反转的结果"，n维护"剩余待处理的数字"。

再看一个稍复杂的过程模拟——约分分数：

```cpp
// 模拟分数约分过程
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;  // 分子和分母
    
    // 求最大公约数（欧几里得算法模拟辗转相除过程）
    int numerator = a, denominator = b;
    // 模拟辗转相除：不断用较大数除以较小数取余，直到余数为0
    while (denominator != 0) {
        int temp = denominator;
        denominator = numerator % denominator;
        numerator = temp;
    }
    int gcd = numerator;  // 此时 numerator 即为最大公约数
    
    cout << a / gcd << "/" << b / gcd << endl;
    return 0;
}
```

### 三、状态模拟

状态模拟是更常见的模拟形式：系统有一组状态变量，程序根据输入或时间推移不断更新这些状态。典型例子包括电梯运行模拟、自动售货机模拟、游戏状态模拟等。

**核心框架**：

```
初始化状态变量
对于每个时刻或每条指令：
    根据当前状态和输入，更新状态
    可能需要记录或输出某个结果
```

下面以"开关灯"问题为例，这是一个典型的状态模拟题。有n盏灯，初始全部关闭。第1个人将所有灯打开，第2个人将编号为2的倍数的灯切换状态（开变关、关变开），第3个人将编号为3的倍数的灯切换状态……以此类推，直到第n个人。问最后哪些灯是开着的。

```cpp
// 开关灯问题：状态模拟
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    // lights[i] = 1 表示灯开着，0 表示关着
    bool lights[5005] = {false};  // 初始全部关闭
    
    // 第 i 个人操作
    for (int i = 1; i <= n; i++) {
        // 操作 i 的倍数编号的灯
        for (int j = i; j <= n; j += i) {
            lights[j] = !lights[j];  // 状态翻转
        }
    }
    
    // 输出开着灯的编号
    for (int i = 1; i <= n; i++) {
        if (lights[i]) {
            cout << i << " ";
        }
    }
    cout << endl;
    
    return 0;
}
```

这段代码的核心在于：用bool数组`lights[]`维护每盏灯当前的状态（开/关），每轮操作遍历对应的灯并翻转状态。状态数组的每一次更新，都对应着现实世界中灯状态的改变。

状态模拟的一个关键原则是：**状态的更新必须基于上一时刻的完整状态，不能因为本轮的部分更新影响了本轮后续的判断**。如果需要在同一轮中既读取旧状态又写入新状态，通常需要一个新的数组来暂存新状态。

### 四、日期计算

日期计算是CSP-J中常考的模拟题型，考察对日历规则的理解和细心程度。

#### 4.1 闰年判断

闰年规则：能被4整除但不能被100整除，或者能被400整除。

```cpp
bool isLeap(int year) {
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}
```

#### 4.2 月份天数数组

使用数组预先存储每月的天数，避免大量if-else判断：

```cpp
// 平年每月的天数
int daysInMonth[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
// 下标从1开始，daysInMonth[0]占位不用
```

```cpp
// 获取某年某月的天数
int getDays(int year, int month) {
    int days[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    if (month == 2 && isLeap(year)) return 29;
    return days[month];
}
```

#### 4.3 计算从公元1年1月1日到指定日期的总天数

这是处理日期差值的常用技巧——将两个日期都换算成"从某个基准日期起的总天数"，然后相减。

```cpp
#include <iostream>
using namespace std;

bool isLeap(int year) {
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}

int daysInMonth[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

// 计算从公元1年1月1日到 year-month-day 的总天数
int totalDays(int year, int month, int day) {
    int total = 0;
    
    // 累加整年的天数
    for (int y = 1; y < year; y++) {
        total += isLeap(y) ? 366 : 365;
    }
    
    // 累加当年整月的天数
    for (int m = 1; m < month; m++) {
        total += daysInMonth[m];
        if (m == 2 && isLeap(year)) total++;  // 闰年2月多1天
    }
    
    // 累加当月天数
    total += day;
    
    return total;
}

int main() {
    // 计算两个日期的差值
    int y1, m1, d1, y2, m2, d2;
    cin >> y1 >> m1 >> d1 >> y2 >> m2 >> d2;
    
    int days1 = totalDays(y1, m1, d1);
    int days2 = totalDays(y2, m2, d2);
    
    cout << abs(days2 - days1) + 1 << endl;  // +1 表示包含起始日
    return 0;
}
```

**日期计算易错点提醒**：
- 闰年2月有29天，不要忘记判断。
- 月份数组下标从1开始，注意不要用0下标。
- 年份范围为公元后，如果是公元前需要额外处理。
- 计算差值时需明确是否包含起始日（通常+1表示包含）。

### 五、高精度加法

C++中int类型最大能表示约21亿（2^31-1），long long类型最大约9×10^18。当数字超过这个范围时（比如100位的整数相加），就需要用**高精度计算**——用字符串模拟手工计算的竖式加法。

#### 5.1 高精度加法的原理

手工计算竖式加法时，我们从最低位开始，逐位相加，如果和>=10则进位。高精度加法完全模拟这个过程。

**算法步骤**：
1. 将两个数字以字符串形式读入。
2. 从最低位（字符串末尾）开始，逐位相加。
3. 维护进位变量carry，初始为0。
4. 每一位的结果 = (数字A的该位 + 数字B的该位 + carry) % 10。
5. 新的进位 = (数字A的该位 + 数字B的该位 + carry) / 10。
6. 所有位处理完后，如果进位还有剩余，补上最高位的进位。

#### 5.2 完整高精度加法代码

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

// 高精度加法：返回 a + b 的结果（字符串形式）
string highPrecisionAdd(string a, string b) {
    string result = "";     // 存储结果
    int carry = 0;          // 进位
    
    // 从最低位（字符串末尾）开始逐位相加
    int i = a.size() - 1;   // a 的当前位指针
    int j = b.size() - 1;   // b 的当前位指针
    
    // 当还有数字位需要处理，或还有进位需要处理时，继续循环
    while (i >= 0 || j >= 0 || carry > 0) {
        int digitA = (i >= 0) ? (a[i] - '0') : 0;  // 取a当前位的值
        int digitB = (j >= 0) ? (b[j] - '0') : 0;  // 取b当前位的值
        
        int sum = digitA + digitB + carry;  // 当前位的总和
        carry = sum / 10;                    // 更新进位（0或1）
        int digit = sum % 10;                // 当前位的结果
        
        // 将当前位结果添加到结果字符串中（注意：是从低位往高位添加的）
        result += (char)(digit + '0');
        
        i--;
        j--;
    }
    
    // 此时result中的数字是从低位到高位排列的，需要反转
    reverse(result.begin(), result.end());
    
    return result;
}

int main() {
    string a, b;
    cin >> a >> b;
    cout << highPrecisionAdd(a, b) << endl;
    return 0;
}
```

**逐行解释关键代码**：

**第10行** `int i = a.size() - 1;`：将指针i指向字符串a的最后一个字符（即个位），j同理。这是为了从低位向高位逐位处理，与手工竖式加法一致。

**第14行** `int digitA = (i >= 0) ? (a[i] - '0') : 0;`：`a[i] - '0'`是将字符转为对应的数字值（例如'3'的ASCII码减去'0'的ASCII码等于3）。如果i<0说明a已经处理完所有位，该位的值为0。三元运算符实现了代码的简洁性。

**第18行** `carry = sum / 10;`：由于digitA和digitB最大为9，carry最大为1，所以sum最大为9+9+1=19。sum/10的结果只可能是0（sum<10）或1（sum>=10），carry因此也只会是0或1。

**第22行** `result += (char)(digit + '0');`：将数字转回字符，追加到结果字符串末尾。由于我们从低位往高位加，结果的字符顺序也是从低位到高位。

**第30行** `reverse(result.begin(), result.end());`：将结果字符串反转，使其符合正常的从高位到低位的阅读顺序。

#### 5.3 高精度加法的更简洁写法

如果不需要手动维护进位细节，也可以利用STL的便捷写法：

```cpp
string add(string a, string b) {
    // 补齐前导零使两数等长
    while (a.size() < b.size()) a = "0" + a;
    while (b.size() < a.size()) b = "0" + b;
    
    string res = "";
    int carry = 0;
    for (int i = a.size() - 1; i >= 0; i--) {
        int sum = (a[i] - '0') + (b[i] - '0') + carry;
        res = char(sum % 10 + '0') + res;  // 注意：直接拼在前面
        carry = sum / 10;
    }
    if (carry) res = "1" + res;
    return res;
}
```

这种写法将结果直接拼接在前面（`char(...) + res`），省去了最后的reverse操作。两种写法都正确，选择自己习惯的即可。

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

string add(string a, string b) {
    string res = "";
    int carry = 0;
    int i = a.size() - 1, j = b.size() - 1;
    
    while (i >= 0 || j >= 0 || carry) {
        int da = (i >= 0) ? a[i] - '0' : 0;
        int db = (j >= 0) ? b[j] - '0' : 0;
        int sum = da + db + carry;
        res += char(sum % 10 + '0');
        carry = sum / 10;
        i--; j--;
    }
    reverse(res.begin(), res.end());
    return res;
}

    cin >> a >> b;
    cout << add(a, b) << endl;
    return 0;
}
```

## ⚠️ 易错点

- **易错点1：日期计算中闰年的2月处理遗漏**。很多同学习惯用固定数组`{0,31,28,31,30,31,30,31,31,30,31,30,31}`直接取值，但忘记当月份是2月且年份是闰年时需要+1。**避免方法**：始终使用getDays(year, month)函数来获取月份天数，在函数内部统一处理闰年2月。

- **易错点2：高精度加法中字符与数字的转换混乱**。`a[i]`是字符'3'，其ASCII值是51，不是数字3。如果忘记`- '0'`转换，会导致计算结果完全错误且不报错（因为编译通过，运行时默默算错）。**避免方法**：始终记住`字符数字 - '0' = 实际数值`，以及`实际数值 + '0' = 字符数字`。

- **易错点3：高精度加法忘记反转结果**。从低位往高位计算时，result中存储的数字顺序与正常的阅读顺序相反（个位在前），必须reverse后输出。**避免方法**：在返回结果前检查是否调用了reverse；或者使用`res = char(sum%10+'0') + res`的方式直接拼在前面。

- **易错点4：状态模拟中原地更新导致连锁反应**。例如在"生命游戏"模拟中，如果直接在原数组上更新每个细胞的状态，会导致本轮已经更新的细胞影响本轮后续细胞的判断。**避免方法**：需要"读取旧状态、写入新状态"时，使用两个数组交替存储：从A读取旧状态，写入B的新状态；下一轮再交换。

- **易错点5：数字反转时前导零处理**。例如将1200反转成0021（实际应为21）。C++中整数没有前导零，int类型存储0021就是21。但如果题目要求输出字符串格式且保留前导零，就需要特殊处理。**避免方法**：明确题目对输出格式的要求，根据需要决定是用int存储还是string存储。

## 📝 真题精练

### 真题1：日期差值计算（CSP-J风格）

**题目描述**：
给定两个日期（年、月、日），计算它们之间相差的天数。注意：闰年的2月有29天。日期的年份范围在[1, 9999]之间。

**输入格式**：
第一行：三个整数y1 m1 d1，表示第一个日期
第二行：三个整数y2 m2 d2，表示第二个日期

**输出格式**：
一个整数，表示两个日期之间相差的天数（包含起始日，即如果两个日期是同一天，输出1）。

**样例输入**：
```
2023 1 1
2023 1 5
```

**样例输出**：
```
5
```

**完整AC代码**：

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int daysInMonth[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

bool isLeap(int year) {
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}

int totalDays(int year, int month, int day) {
    int total = 0;
    // 累加年份天数
    for (int y = 1; y < year; y++) {
        total += isLeap(y) ? 366 : 365;
    }
    // 累加月份天数
    for (int m = 1; m < month; m++) {
        total += daysInMonth[m];
        if (m == 2 && isLeap(year)) total++;
    }
    // 累加日期天数
    total += day;
    return total;
}

int main() {
    int y1, m1, d1, y2, m2, d2;
    cin >> y1 >> m1 >> d1;
    cin >> y2 >> m2 >> d2;
    
    int days1 = totalDays(y1, m1, d1);
    int days2 = totalDays(y2, m2, d2);
    
    // 包含起始日所以+1
    cout << abs(days2 - days1) + 1 << endl;
    return 0;
}
```

**解析**：本题的关键是将日期转换为绝对天数。以公元1年1月1日为基准，计算每个日期到基准的总天数，然后两个总天数相减即得日期差。闰年的判断是核心：能被4整除但不能被100整除，或者能被400整除。注意如果两个日期输入顺序不确定（可能第一个日期更晚），使用abs取绝对值。

### 真题2：高精度加法应用（CSP-J风格）

**题目描述**：
求两个不超过200位的非负整数的和。

**输入格式**：
两行，每行一个不超过200位的非负整数，可能有多余的前导0。

**输出格式**：
一行，即相加后的结果。结果里不能有多余的前导0，即如果结果是0，输出0。

**样例输入**：
```
99999999999999999999
1
```

**样例输出**：
```
100000000000000000000
```

**完整AC代码**：

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

// 高精度加法
string add(string a, string b) {
    string result = "";
    int carry = 0;
    int i = a.size() - 1, j = b.size() - 1;
    
    while (i >= 0 || j >= 0 || carry > 0) {
        int digitA = (i >= 0) ? (a[i] - '0') : 0;
        int digitB = (j >= 0) ? (b[j] - '0') : 0;
        
        int sum = digitA + digitB + carry;
        carry = sum / 10;
        result += (char)(sum % 10 + '0');
        
        i--; j--;
    }
    
    reverse(result.begin(), result.end());
    return result;
}

// 去除前导零
string removeLeadingZeros(string s) {
    int pos = 0;
    while (pos < (int)s.size() - 1 && s[pos] == '0') {
        pos++;
    }
    return s.substr(pos);
}

int main() {
    string a, b;
    cin >> a >> b;
    
    string ans = add(a, b);
    cout << removeLeadingZeros(ans) << endl;
    
    return 0;
}
```

**解析**：此题是标准的高精度加法模板题。关键点包括：
1. 字符串从低位（末尾）逐位相加，维护进位变量carry。
2. 循环条件`i >= 0 || j >= 0 || carry > 0`确保了所有位和进位都被处理。
3. 结果需要reverse因为计算时从低位到高位存储。
4. 需要去除前导零（例如"00123"应输出"123"），但保留至少一位（"00"应输出"0"）。

对于200位的整数，int和long long都无法直接存储，必须使用高精度算法。int范围约10位，long long范围约19位，200位远超这两个类型的上限。
