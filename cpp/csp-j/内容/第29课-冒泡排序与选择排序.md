### 一、冒泡排序原理

冒泡排序的核心思想是：**重复地遍历数组，依次比较相邻的两个元素，如果顺序错误就交换它们**。每一轮遍历会将当前未排序部分的最大值"冒泡"到末尾。

举个形象的例子：假设有一排气泡（数据），大的气泡会慢慢浮到水面（数组末尾），就像碳酸饮料中的气泡往上冒一样。

**算法步骤**：
1. 从数组第一个元素开始，依次比较相邻元素 `a[j]` 和 `a[j+1]`
2. 如果 `a[j] > a[j+1]`，交换它们
3. 每一轮结束后，最大的元素会 "浮" 到数组末尾
4. 下一轮可以忽略已经排好的末尾元素，缩短遍历范围
5. 重复直到所有元素有序

**基础实现代码**：

```cpp
#include <iostream>
using namespace std;

void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {          // 外层循环：需要 n-1 轮
        for (int j = 0; j < n - 1 - i; j++) {  // 内层循环：每轮比较范围缩小
            if (a[j] > a[j+1]) {               // 相邻比较
                int temp = a[j];
                a[j] = a[j+1];
                a[j+1] = temp;
            }
        }
    }
}

int main() {
    int a[] = {5, 3, 8, 1, 9, 2};
    int n = 6;
    bubbleSort(a, n);
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    // 输出：1 2 3 5 8 9
    return 0;
}
```

让我们模拟一下数组 `{5, 3, 8, 1, 9, 2}` 的排序过程：

- **第 1 轮**（i=0，比较范围 j=0 到 4）：
  - j=0: 比较 5 和 3，5>3，交换 → `{3, 5, 8, 1, 9, 2}`
  - j=1: 比较 5 和 8，5<8，不交换 → `{3, 5, 8, 1, 9, 2}`
  - j=2: 比较 8 和 1，8>1，交换 → `{3, 5, 1, 8, 9, 2}`
  - j=3: 比较 8 和 9，8<9，不交换 → `{3, 5, 1, 8, 9, 2}`
  - j=4: 比较 9 和 2，9>2，交换 → `{3, 5, 1, 8, 2, 9}`
  - 第 1 轮结束，最大值 9 已到末尾
- **第 2 轮**（i=1，比较范围 j=0 到 3）：
  - j=0: 比较 3 和 5，3<5，不交换
  - j=1: 比较 5 和 1，5>1，交换 → `{3, 1, 5, 8, 2, 9}`
  - j=2: 比较 5 和 8，5<8，不交换
  - j=3: 比较 8 和 2，8>2，交换 → `{3, 1, 5, 2, 8, 9}`
  - 第 2 轮结束，次大值 8 到倒数第二
- 依此类推，直到第 5 轮完成排序

**时间复杂度分析**：外层循环 n-1 轮，内层循环平均约 n/2 次，总比较次数约为 n(n-1)/2，时间复杂度为 **O(n²)**。

### 二、冒泡排序的优化

标准的冒泡排序即使数组已经有序，依然会执行完所有轮次。我们可以引入一个 `bool swapped` 标记来检测某轮中是否发生了交换。如果某一轮没有任何交换，说明数组已经有序，可以提前终止。

**优化版冒泡排序**：

```cpp
#include <iostream>
using namespace std;

void bubbleSortOptimized(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;                   // 每轮开始时重置标记
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j+1]) {
                int temp = a[j];
                a[j] = a[j+1];
                a[j+1] = temp;
                swapped = true;                 // 发生了交换，标记为 true
            }
        }
        if (!swapped) break;                    // 本轮没有交换，数组已有序，提前结束
    }
}

int main() {
    int a[] = {1, 2, 3, 5, 8, 9};              // 已经有序的数组
    int n = 6;
    bubbleSortOptimized(a, n);
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    // 只需 1 轮即发现有序，不会继续做无用功
    return 0;
}
```

有了 `swapped` 标记后，最好情况下（数组已经有序）冒泡排序只需 O(n) 时间——只做一轮扫描即可发现没有交换，提前结束。这在 CSP-J 的判断题中经常出现，需要特别注意：**冒泡排序的最优时间复杂度是 O(n)**（优化版），而非总是 O(n²)。

### 三、选择排序原理

选择排序的核心思想是：**每一轮从未排序部分中选出最小值的下标，然后将该最小值与未排序部分的第一个元素交换位置**。每一轮确定一个最小元素，将其放到已排序区的末尾。

这个过程中，数组自然地分成了两部分：前半部分是已排序区，后半部分是未排序区。

**算法步骤**：
1. 从 i=0 开始，在第 i 轮中，在区间 [i, n-1] 中查找最小元素的下标 `minIdx`
2. 将 `a[minIdx]` 与 `a[i]` 交换——最小值归位
3. i 加 1，已排序区扩大一位，重复直到 i=n-1

**选择排序完整实现**：

```cpp
#include <iostream>
using namespace std;

void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {         // 需要 n-1 轮选择
        int minIdx = i;                        // 假设当前位置就是最小值的下标
        for (int j = i + 1; j < n; j++) {     // 在未排序区 [i+1, n-1] 中查找
            if (a[j] < a[minIdx]) {
                minIdx = j;                    // 更新最小值的下标
            }
        }
        // 将最小值交换到已排序区的末尾（即位置 i）
        if (minIdx != i) {                     // 如果最小值不在位置 i 上才交换
            int temp = a[i];
            a[i] = a[minIdx];
            a[minIdx] = temp;
        }
    }
}

int main() {
    int a[] = {5, 3, 8, 1, 9, 2};
    int n = 6;
    selectionSort(a, n);
    for (int i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
    // 输出：1 2 3 5 8 9
    return 0;
}
```

同样模拟数组 `{5, 3, 8, 1, 9, 2}` 的选择排序过程：

- **第 1 轮**（i=0）：在 `{5, 3, 8, 1, 9, 2}` 中找最小值 1（下标 3），将 a[0]=5 与 a[3]=1 交换 → `{1, 3, 8, 5, 9, 2}`
- **第 2 轮**（i=1）：在 `{3, 8, 5, 9, 2}` 中找最小值 2（下标 5），将 a[1]=3 与 a[5]=2 交换 → `{1, 2, 8, 5, 9, 3}`
- **第 3 轮**（i=2）：在 `{8, 5, 9, 3}` 中找最小值 3（下标 5），将 a[2]=8 与 a[5]=3 交换 → `{1, 2, 3, 5, 9, 8}`
- **第 4 轮**（i=3）：在 `{5, 9, 8}` 中找最小值 5（下标 3），不交换 → `{1, 2, 3, 5, 9, 8}`
- **第 5 轮**（i=4）：在 `{9, 8}` 中找最小值 8（下标 5），将 a[4]=9 与 a[5]=8 交换 → `{1, 2, 3, 5, 8, 9}`

### 四、排序的稳定性

**稳定性定义**：如果待排序的序列中存在多个**关键字相同**的记录，经过排序后，这些相同关键字记录的**相对先后顺序保持不变**，则称该排序算法是**稳定的**；否则称为**不稳定的**。

举例说明：假设有一个学生成绩表，按成绩排序：

| 姓名 | 成绩 | 原始序号 |
|------|------|---------|
| 张三 | 85   | 1       |
| 李四 | 90   | 2       |
| 王五 | 85   | 3       |
| 赵六 | 78   | 4       |

如果使用**稳定排序**按成绩升序排列，则张三（85分）一定排在王五（85分）前面（因为原始顺序中张三在前）。如果使用**不稳定排序**，王五可能排到张三前面。

**各算法稳定性判断**：
- **冒泡排序是稳定的**：因为只有在 `a[j] > a[j+1]`（严格大于）时才交换，相等时不会交换，所以相同元素的相对顺序不变。注意：如果条件写成 `>=`，冒泡排序就变成不稳定的了！
- **选择排序是不稳定的**：考虑序列 `{5, 8, 5, 2, 9}`，第 1 轮选择最小值 2（下标 3）与 a[0]=5（第一个 5）交换，结果变成 `{2, 8, 5, 5, 9}`。原来第一个 5 跑到了第二个 5 的后面——相对顺序变了。

选择排序不稳定性的本质原因在于"跳跃式交换"——最小值可能跳过多个元素与远端的元素交换，打乱了相同元素的相对顺序。

### 五、交换次数与比较次数计算

这是 CSP-J 初赛选择题的高频考点。理解两种排序的比较和交换特性非常重要：

**冒泡排序**：
- **比较次数**：最坏情况（完全逆序）每轮都要比较到底，第 1 轮比较 n-1 次，第 2 轮比较 n-2 次……总共 `(n-1) + (n-2) + ... + 1 = n(n-1)/2` 次。最好情况（已有序，优化版）只需 1 轮 n-1 次比较。
- **交换次数**：每次比较如果发现逆序就交换。最坏情况（完全逆序）每次比较都交换，交换次数 = 比较次数 ≈ n(n-1)/2。最好情况（已有序）交换次数为 0。

**选择排序**：
- **比较次数**：无论数据初始状态如何，选择排序**总是**执行 `n(n-1)/2` 次比较——因为每轮都要扫描整个未排序区来寻找最小值。这是选择排序的一个重要特征：比较次数与数据分布无关，恒为 n(n-1)/2。
- **交换次数**：最多 n-1 次交换（每轮最多交换一次）。最少 0 次（已有序）。注意：即使数据已经有序，选择排序依然会执行全部比较，只是不交换而已。

**关键记忆点**：选择排序的比较次数恒为 n(n-1)/2，而冒泡排序（优化版）在最好情况下只需 O(n) 次比较。

### 六、插入排序简要对比

插入排序的基本思路是将数组分为"有序区"和"无序区"，每次从无序区取一个元素插入到有序区的正确位置。它与冒泡/选择排序的对比如下：

| 特性 | 冒泡排序 | 选择排序 | 插入排序 |
|------|---------|---------|---------|
| 基本操作 | 相邻比较交换 | 选最小值交换 | 插入到有序区 |
| 最好时间 | O(n²)/O(n)(优化) | O(n²) | O(n) |
| 最坏时间 | O(n²) | O(n²) | O(n²) |
| 比较次数 | 取决于数据 | 恒为 n(n-1)/2 | 取决于数据 |
| 稳定性 | 稳定 | 不稳定 | 稳定 |

插入排序在数据基本有序时非常高效（接近 O(n)），这也是为什么在实际工程中，高级排序算法（如快速排序）在子问题规模较小时常切换到插入排序。我们将在下一节课详细讲解插入排序与计数排序。

## 💻 代码模板

**模板一：标准冒泡排序（可直接套用）**

```cpp
// 功能：对数组 a[0..n-1] 进行升序冒泡排序
// 时间复杂度：O(n²)，空间复杂度：O(1)
void bubbleSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j+1]) {
                swap(a[j], a[j+1]);  // 使用 C++ 标准库的 swap
            }
        }
    }
}
```

**模板二：优化冒泡排序（带提前终止）**

```cpp
// 功能：对数组 a[0..n-1] 进行升序冒泡排序（优化版）
// 最好情况（已有序）时间复杂度为 O(n)
void bubbleSortOptimized(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j+1]) {
                swap(a[j], a[j+1]);
                swapped = true;
            }
        }
        if (!swapped) break;  // 提前终止
    }
}
```

**模板三：标准选择排序（可直接套用）**

```cpp
// 功能：对数组 a[0..n-1] 进行升序选择排序
// 时间复杂度：O(n²)，交换次数最多 n-1 次
void selectionSort(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[minIdx]) {
                minIdx = j;
            }
        }
        if (minIdx != i) {
            swap(a[i], a[minIdx]);
        }
    }
}
```

## ⚠️ 易错点

- **混淆比较次数与交换次数**：选择排序的比较次数恒为 n(n-1)/2，与数据初始状态无关；但它的交换次数最多只有 n-1 次。有些选择题会故意将"选择排序交换次数恒为 n(n-1)/2"作为干扰项，一定要辨别清楚——恒为 n(n-1)/2 的是**比较次数**，不是交换次数。

- **忘记内层循环的范围递减**：冒泡排序内层循环的条件是 `j < n - 1 - i`，而不是 `j < n - 1`。如果不减 i，会重复比较已经排好的尾部元素，虽然不影响结果正确性，但会做很多无用功，而且考试中手算模拟结果时会被扣分。

- **稳定性判断条件**：冒泡排序稳定的前提是使用 `>` 判断而非 `>=`。如果写成 `if (a[j] >= a[j+1])` 来交换，相等元素也会被交换，稳定性就被破坏了。选择排序无论怎么写都是不稳定的，原因在于跳跃式交换的本质。

- **最坏情况交换次数**：冒泡排序最坏情况（完全逆序）下，每次比较都伴随一次交换，交换次数达到 n(n-1)/2。例如对 `{5, 4, 3, 2, 1}` 做升序冒泡排序，总共会发生 10 次交换。而选择排序对同样的逆序数组，只需 2 次交换（n=5 为奇数时是 floor(n/2) 次）。

### 真题一：排序过程模拟题

**题目描述**：对序列 `{8, 3, 2, 5, 7, 1, 4, 6}` 进行升序冒泡排序。请回答：经过第 2 轮排序后，序列的最后两个元素是什么？

**输入格式**：无

**输出格式**：输出经过第 2 轮冒泡排序后的完整序列，用空格分隔。

**样例**：
- 经过第 2 轮后的序列应为：2 3 5 1 4 6 7 8

**完整 AC 代码**：

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a[] = {8, 3, 2, 5, 7, 1, 4, 6};
    int n = 8;
    
    // 冒泡排序：只模拟前 2 轮
    for (int i = 0; i < 2; i++) {              // 只跑 2 轮
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j+1]) {
                swap(a[j], a[j+1]);
            }
        }
        // 输出每一轮的结果（便于观察过程）
        cout << "第 " << i+1 << " 轮后：";
        for (int k = 0; k < n; k++) cout << a[k] << " ";
        cout << endl;
    }
    
    cout << "最终序列：";
    for (int i = 0; i < n; i++) {
        cout << a[i] << (i < n-1 ? " " : "\n");
    }
    // 第 1 轮后：3 2 5 7 1 4 6 8
    // 第 2 轮后：2 3 5 1 4 6 7 8
    // 最后两个元素是 7 和 8 (但注意题意可能问的是第2轮后序列最后两元素)
    return 0;
}
```

**考点分析**：本题考察冒泡排序的过程模拟能力。关键是要理解每一轮排序后最大值会"冒泡"到末尾，第 1 轮后 8 到末尾，第 2 轮后 7 到倒数第二。CSP-J 初赛经常出现这类手算模拟题，要求考生能正确模拟每一轮的中间状态。

### 真题二：统计交换次数

**题目描述**：给定一个长度为 n（1 ≤ n ≤ 1000）的整数序列，请用选择排序对该序列进行升序排序，并统计整个排序过程中一共进行了多少次元素交换。注意：只有当 `minIdx != i` 时才计入一次交换。

**输入格式**：
- 第一行一个整数 n，表示序列长度
- 第二行 n 个整数，表示序列元素

**输出格式**：
- 输出一个整数，表示选择排序过程中元素交换的总次数

**样例输入**：
```
5
5 3 4 1 2
```

**样例输出**：
```
4
```

**完整 AC 代码**：

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int n;
    cin >> n;
    int a[1005];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    int swapCount = 0;
    
    // 选择排序
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[minIdx]) {
                minIdx = j;
            }
        }
        if (minIdx != i) {
            swap(a[i], a[minIdx]);
            swapCount++;                       // 统计交换次数
        }
    }
    
    cout << swapCount << endl;
    return 0;
}
```

**考点分析**：本题考察选择排序的交换次数统计。选择排序每轮至多交换一次，总交换次数 ≤ n-1。与冒泡排序不同，选择排序的交换次数非常少。这类题目要求考生理解两种排序算法的核心区别：冒泡排序通过大量相邻交换来移动元素，选择排序通过较少的长距离交换来实现排序。

### 真题三：稳定性与比较次数综合判断

**题目描述**：  
对序列 `A = {4, 2, 4, 1}` 分别用：
1. 标准升序冒泡排序（条件 `a[j] > a[j+1]` 才交换）；
2. 标准升序选择排序。

请回答：
- 冒泡排序结束后两个值同为 4 的元素，原始顺序是否保持？
- 选择排序过程中比较次数是多少？
- 选择排序过程中交换次数是多少？

用程序模拟并输出三行答案：`stable/unstable`、比较次数、交换次数。

**输出样例**（对本序列）：
```
stable
6
2
```

**AC 代码**：

```cpp
#include <iostream>
#include <utility>
using namespace std;

// 用 pair 标记原始相对顺序：first=值，second=原始下标
int main() {
    pair<int,int> a[4] = {{4,0},{2,1},{4,2},{1,3}};
    int n = 4;

    // --- 冒泡稳定性检测 ---
    pair<int,int> b[4];
    for (int i = 0; i < n; i++) b[i] = a[i];
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (b[j].first > b[j+1].first) {
                swap(b[j], b[j+1]);
            }
        }
    }
    // 两个 4 的原始下标应仍是 0 在 2 前
    bool stable = true;
    int pos4a = -1, pos4b = -1;
    for (int i = 0; i < n; i++) {
        if (b[i].first == 4) {
            if (pos4a == -1) pos4a = b[i].second;
            else pos4b = b[i].second;
        }
    }
    if (pos4a > pos4b) stable = false;
    cout << (stable ? "stable" : "unstable") << endl;

    // --- 选择排序统计 ---
    int c[4] = {4, 2, 4, 1};
    int cmpCnt = 0, swpCnt = 0;
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            cmpCnt++;                 // 每次 a[j] 与 a[minIdx] 比较
            if (c[j] < c[minIdx]) minIdx = j;
        }
        if (minIdx != i) {
            swap(c[i], c[minIdx]);
            swpCnt++;
        }
    }
    cout << cmpCnt << endl;  // n(n-1)/2 = 6
    cout << swpCnt << endl;
    return 0;
}
```

**解析**：  
- 冒泡用严格 `>`，相等不交换 → 稳定。  
- 选择排序比较次数恒为 \(n(n-1)/2=6\)。  
- 本例交换两次（具体与数据有关，但 ≤ n-1）。

## 🧩 进阶精讲

### 七、双向冒泡（鸡尾酒排序）简介

普通冒泡每轮只把最大值“沉”到右边；双向冒泡一轮内先从左到右，再从右到左：

- 从左到右：大的右移；
- 从右到左：小的左移。

最好情况仍可配合 `swapped` 达到 O(n)，平均仍 O(n²)。CSP-J 了解即可，重点仍是标准冒泡。

### 八、手算模拟的标准步骤（初赛选择题）

1. **画表**：每轮结束后写一整行序列。  
2. **圈出有序区**：冒泡右端有序，选择左端有序。  
3. **只算题目问的轮次**：不要算完所有轮再倒推，容易算错。  
4. **交换时写清楚下标**：避免“脑内交换”漏步。

**小练习**：序列 `{5, 1, 4, 2, 8}`  
- 冒泡第 1 轮后：`1 4 2 5 8`  
- 选择第 1 轮后：`1 5 4 2 8`

### 九、复杂度与数据规模对照（写程序前先估）

| n 规模 | O(n²) 约操作次数 | 1 秒能否通过（约 1e8） |
|--------|------------------|------------------------|
| 100    | 1e4              | 轻松 |
| 1000   | 1e6              | 可以 |
| 5000   | 2.5e7            | 勉强 |
| 1e5    | 1e10             | 超时 |

复赛若 n≥5000 且无特殊说明，应优先 `sort()`（第31课），不要手写 O(n²)。

### 十、降序与“选最大”变体

升序冒泡改降序：把 `a[j] > a[j+1]` 改成 `a[j] < a[j+1]`。  
升序选择改成每轮选最大值放到未排序区右端，或选最大值与 `a[i]` 交换并改为从大到小。

```cpp
// 降序选择：每轮选最大
void selectionSortDesc(int a[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int maxIdx = i;
        for (int j = i + 1; j < n; j++)
            if (a[j] > a[maxIdx]) maxIdx = j;
        if (maxIdx != i) swap(a[i], a[maxIdx]);
    }
}
```

### 十一、与插入排序、STL 的衔接

| 算法 | 是否本课重点 | 稳定性 | 最好 | 备注 |
|------|--------------|--------|------|------|
| 冒泡 | 是 | 稳定 | O(n)（优化） | 过程模拟高频 |
| 选择 | 是 | 不稳定 | O(n²) | 交换少 |
| 插入 | 下节 | 稳定 | O(n) | 基本有序快 |
| `sort` | 第31课 | 不稳定 | O(n log n) | 复赛默认 |

### 十二、常见选择题干扰项

1. “选择排序最好 O(n)”——**错**，比较次数恒定。  
2. “冒泡一定不稳定”——**错**，标准写法稳定。  
3. “选择排序交换次数恒为 n(n-1)/2”——**错**，那是比较次数。  
4. “已有序时冒泡内层仍执行 n-1 轮”——优化版会提前结束，基础版外层仍 n-1 轮。

## 💻 补充模板：同时统计比较与交换

```cpp
void bubbleStat(int a[], int n, int &cmpCnt, int &swpCnt) {
    cmpCnt = swpCnt = 0;
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            cmpCnt++;
            if (a[j] > a[j+1]) {
                swap(a[j], a[j+1]);
                swpCnt++;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}
```

## 🎯 本课小结
- 冒泡排序通过相邻比较交换实现排序，时间复杂度 O(n²)，加入 `swapped` 标记后最好情况可达 O(n)；选择排序每轮选最小值交换，时间复杂度恒为 O(n²)，交换次数最多 n-1 次。
- 冒泡排序是稳定的（前提是用 `>` 判断），选择排序天生不稳定——理解"跳跃式交换"破坏相对顺序是掌握稳定性的关键。
- 选择排序的比较次数恒为 n(n-1)/2，不受初始数据影响；冒泡排序的比较和交换次数都受数据初始状态影响，这是二者的重要区别。
- 解题时遇到排序过程模拟题，要一步步手算，注意每一轮结束后最大值/最小值的位置变化，切勿跳步。
- 数据规模与复杂度要匹配：O(n²) 适合教学与小 n；大 n 用 STL sort。稳定性、比较/交换次数是初赛高频陷阱，务必分清概念。
