📖 核心知识：冒泡排序详解

🫧 生活中的类比

想象一杯汽水里的气泡：大的气泡会慢慢浮到水面。冒泡排序就像让大的数字像气泡一样"浮"到数组的末尾！

📋 算法四步骤

  1. 从第一个元素开始，比较相邻的两个元素
  2. 如果前面的比后面的大，就交换它们
  3. 每一轮结束后，最大的元素"浮"到最后
  4. 重复以上步骤，直到所有元素有序

🔍 图解示例：数组 [5, 3, 8, 1]

轮数比较过程本轮结果归位元素
第1轮5>3✅ 5<8❌ 8>1✅ 8>?✅[3,5,1,8]8 ✓
第2轮3<5❌ 5>1✅ 5[3,1,5,8]5 ✓
第3轮3>1✅[1,3,5,8]3 ✓
⚠️ 关键规律：第 i 轮（从0开始）只需要比较前 n-1-i 个元素！因为末尾的 i 个元素已经排好了。
💡 优化技巧：如果某一轮没有发生任何交换，说明数组已经排好序了，可以提前结束，不用继续比较！

💻 示例代码：基础冒泡排序

// ===== 基础冒泡排序：从小到大排列 ===== #include <iostream> using namespace std; int main() { // 1. 准备待排序的数组 int arr[] = {5, 3, 8, 1, 6}; int n = 5; // 数组长度 cout << "排序前："; for (int i = 0; i < n; i++) cout << arr[i] << " "; cout << endl; // 2. 冒泡排序：外层循环控制"轮数" // n个元素最多需要 n-1 轮 for (int i = 0; i < n - 1; i++) { // 3. 内层循环：相邻比较和交换 // j 从 0 到 n-2-i（每轮范围缩小1） for (int j = 0; j < n - 1 - i; j++) { // 4. 如果前面 > 后面 → 交换！ if (arr[j] > arr[j + 1]) { // 三步交换法（必须用临时变量） int temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp; } } } // 5. 输出排序后的结果 cout << "排序后："; for (int i = 0; i < n; i++) cout << arr[i] << " "; cout << endl; return 0; }

⚡ 优化版：加一个标志位

// 在每轮开始前加一行： bool swapped = false; // 在交换操作后加一行： swapped = true; // 在内层循环结束后加判断： if (!swapped) { cout << "已有序，提前结束！" << endl; break; }

📌 运行结果：排序前 5 3 8 1 6 → 排序后 1 3 5 6 8

📝 本课小结

知识点核心内容
🔑 基本思想相邻元素两两比较，大的往后"冒泡"
🔁 双层循环外层 i 控制轮数，内层 j 控制比较
📐 比较次数第 i 轮比较 n-1-i 次，总共 n(n-1)/2 次
🔄 交换操作三步法：temp = a; a = b; b = temp;
⚡ 优化技巧swapped 标志位，无交换则提前结束
⏱️ 时间复杂度最坏/平均 O(n²)，最好 O(n)，适合小数据
📌 记忆口诀："相邻比较往后冒，外层轮数内层跑；标志位来提效率，n² 复杂度要记牢！"
