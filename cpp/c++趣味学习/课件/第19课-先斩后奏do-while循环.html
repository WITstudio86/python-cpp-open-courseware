第19课：先斩后奏——do-while循环

循环选择 | 课时：45分钟

✨ 🎲 掷骰子直到6 ✨

想一想：有没有必须至少做一次的事情？do-while就是为这种场景设计的！

🎯 学习目标

  1. 理解do-while"先执行后判断"的独特特点
  2. 掌握do-while与while的区别和适用场景
  3. 能够根据需求灵活选择循环结构
📌 核心区别：while可能一次都不执行，do-while至少执行一次！
循环最少次数适用场景
while0次不确定次数
do-while1次至少执行一次
for0次确定次数

📖 核心知识

do-while的语法

do { // 循环体：至少会执行一次 } while (条件); // ⚠️ 这里有个分号！

生活类比：三种家长作风

🔴 while循环 = 严厉家长："写完作业才能看电视！"（先检查）

🟢 do-while循环 = 宽松家长："先看一会，看完再决定要不要写。"（先行动）

🔵 for循环 = 计划家长："看30分钟，每分钟检查一次。"（精确计数）

经典对比实验

int x = 10; // 条件x < 5 一开始就是假的 while (x < 5) { // → 什么都不输出 cout << x; } do { // → 输出 10（至少执行一次！） cout << x; } while (x < 5);

💻 示例代码

🎲 掷骰子直到6

int dice, count = 0; do { dice = rand() % 6 + 1; // 生成1-6的随机数 count++; cout << "第" << count << "次：掷出了 " << dice << " 点" << endl; } while (dice != 6); cout << "🎉 一共掷了 " << count << " 次！" << endl;

🔐 密码验证系统

const string PASSWORD = "c++123"; string input; int attempts = 0; do { cout << "密码："; cin >> input; attempts++; if (input == PASSWORD) break; // 正确就跳出 cout << "还剩 " << 3 - attempts << " 次机会" << endl; } while (attempts < 3);

🎮 趣味练习

练习1：猜数字（do-while版） ⭐

生成1-10的随机数，用do-while让用户至少猜一次。

练习2：数字输入验证 ⭐⭐

要求用户输入1-100之间的数字，不合法就重新输入，保证至少执行一次。

练习3：简易计算器 ⭐⭐

使用do-while实现菜单：1-加法 2-减法 3-乘法 4-除法 5-退出。

🏆 挑战任务：多功能运算器
包含加法、减法、乘法、除法、平方、立方的循环菜单。除法时检查除数不能为0！

📝 本课小结

要点说明
语法do{循环体}while(条件); ← 分号不能少
特点先执行循环体，再判断条件
最少次数至少执行1次
适用场景菜单系统、输入验证、游戏重玩
vs whilewhile可能0次，do-while至少1次
记口诀："do-while分号莫忘记，至少一次是它的意义！"
