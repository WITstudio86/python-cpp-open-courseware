变量概念 int类型 声明赋值 命名规则

🎯 学习目标

  • 理解变量的概念：给数据贴标签的"储物柜"
  • 掌握 int 类型变量的声明、赋值和使用

💡 想一想：
变量就像你的储物柜 —— 有名字（标签）、能放东西（值）、还能换东西（修改）！

📖 变量的三要素

1️⃣ 声明变量（准备柜子）

int score; // 声明一个整数柜子，叫score score = 100; // 把100放进去

2️⃣ 一步到位（声明+初始化）

int age = 10; // 类型 + 名字 + 值，一步完成

3️⃣ 值可以改变！

int score = 80; score = 95; // 成绩提高了！ score = score + 5; // 又加了5分 → 100分！

规则✅ 正确❌ 错误

区分大小写age 不等于 Age—

💻 成绩管理系统

int math = 95; int chinese = 88; int english = 92; // 用变量做计算 int total = math + chinese + english; int average = total / 3; cout << "总分：" << total << "分" << endl; cout << "平均：" << average << "分" << endl; // 修改变量——英语成绩提高了！ english = 97; total = math + chinese + english; // 重新计算

交换两个变量的值

// 怎么交换两杯水？需要第三杯！ int cupA = 10, cupB = 20; int temp = cupA; // 倒进临时杯子 cupA = cupB; // B倒进A cupB = temp; // 临时倒进B // 现在 cupA=20, cupB=10

🎮 趣味练习

练习1：找错误 🔍

int 1stPlace = 100; // Bug1 int score; cout << score; // Bug2 int return = 5; // Bug3

3个错误：数字开头、未赋值就使用、用了关键字

练习2：我是计算器 🧮

长方形：长=10，宽=5。计算周长和面积。

int length = 10, width = 5; int perimeter = 2 * (length + width); // 周长 int area = length * width; // 面积

练习3：倒计时 🚀

用变量从5倒数到1，每次减1。

int count = 5; cout << count; // 5 count = count - 1; // 4 count = count - 1; // 3 // ... 直到1 → 发射！

📝 本课小结

知识点说明示例
变量存储数据的"储物柜"int age;
声明告诉电脑变量名和类型int score;
初始化声明同时赋值int age = 10;
赋值改变变量的值score = 95;
int类型整数（年龄、分数）不能存小数
命名规则有意义、不数字开头见名知意
