💻 sizeof 测量大小

cout << "int: " << sizeof(int) << "字节" << endl; cout << "double: " << sizeof(double) << "字节" << endl; cout << "char: " << sizeof(char) << "字节" << endl; cout << "bool: " << sizeof(bool) << "字节" << endl; // 输出：int=4, double=8, char=1, bool=1

整数除法 vs 小数除法

int a = 10, b = 3; cout << a / b; // 输出 3（整数除法） cout << a / 3.0; // 输出 3.33333（有double，结果变小数） cout << (int)3.99; // 输出 3（强制转int，丢弃小数！）
⚠️ 重要：整数除法 10/3 = 3，不是3.333！
只要有一个操作数是double（如3.0），结果就是小数。
