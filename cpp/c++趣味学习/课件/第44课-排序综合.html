🏗️ 结构体排序的核心秘诀

比较的是结构体的某个成员，但交换的是整个结构体！
就像给一叠名片排序——按电话号码排序，但移动的是整张名片。
名片上的姓名、地址、公司都要跟着一起移动！
// 比较成员 score，交换整个 Student if (students[j].score < students[j+1].score) { Student temp = students[j]; // 交换整个结构体！ students[j] = students[j+1]; students[j+1] = temp; }

🔀 多条件排序

用 if ... else if ... 实现分层判断：

// 先按成绩降序，成绩相同按年龄升序 if (students[j].score < students[j+1].score) { 交换; // 主条件：成绩 } else if (students[j].score == students[j+1].score) { if (students[j].age > students[j+1].age) { 交换; // 次条件：年龄 } }

💻 示例代码：学生成绩排名

使用结构体数组 + 冒泡排序，按成绩从高到低排名：

#include <iostream> #include <string> using namespace std; struct Student { string name; // 姓名 int age; // 年龄 double score; // 成绩 }; int main() { Student stu[5] = { {"小明", 12, 88.5}, {"小红", 11, 95.0}, {"小刚", 12, 76.0}, {"小丽", 11, 95.0}, // 和小红同分！ {"小华", 13, 82.5} }; // 冒泡排序：按成绩降序 for (int i = 0; i < 4; i++) { for (int j = 0; j < 4 - i; j++) { if (stu[j].score < stu[j+1].score) { Student temp = stu[j]; // 交换整个结构体 stu[j] = stu[j+1]; stu[j+1] = temp; } } } // 输出排行榜 cout << "🏅 成绩排行榜：" << endl; for (int i = 0; i < 5; i++) { cout << "第" << i+1 << "名：" << stu[i].name << " " << stu[i].score << "分" << endl; } return 0; }
▶ 运行结果：
第1名：小红 95分   第2名：小丽 95分   第3名：小明 88.5分
第4名：小华 82.5分   第5名：小刚 76分
注意：小红和小丽都是95分，但小红排前面 → 冒泡排序是稳定的！

练习2：比较次数计算 🔢

数组 {9,7,5,3,1}（完全倒序，5个元素）：

排序方法比较次数交换次数
冒泡排序4+3+2+1 = 10次每次都交换 = 10次
选择排序4+3+2+1 = 10次每轮1次 = 4次

结论：比较次数相同，但选择排序的交换次数远少于冒泡排序！

📝 本课小结

知识点核心要点
🔬 两种排序对比 比较次数相同，但冒泡交换多、稳定；选择交换少、不稳定
🏗️ 结构体排序 比较的是某个成员（如 .score），交换的是整个结构体
🔀 多条件排序 用 if...else if 分层判断：主条件 → 次条件 → 再次条件
📈 升序/降序 升序用 >（大的往后移），降序用 <（小的往后移）
🛠️ 选择指南 需稳定选冒泡，追求效率选选择；初学者以冒泡为主
