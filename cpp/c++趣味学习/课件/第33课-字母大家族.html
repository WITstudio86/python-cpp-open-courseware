📖 核心知识：字符类型与 ASCII

什么是 char 类型？

char（character，字符）是 C++ 中用来存储单个字符的数据类型。每个字符在计算机内部都用一个数字编码来表示，最常用的编码就是 ASCII（美国标准信息交换码）。

char grade = 'A'; // ✅ 用单引号 char digit = '7'; // 这是字符'7'，不是数字7！ // char bad = "A"; // ❌ 不能用双引号！

ASCII 码速查表

字符范围ASCII值说明
'A' ~ 'Z'65 ~ 90大写字母（共26个）
'a' ~ 'z'97 ~ 122小写字母（共26个）
'0' ~ '9'48 ~ 57数字字符（不是数字！）
空格 ' '32空格字符

字符运算的核心秘密

因为字符实质上就是整数，所以可以对字符做加减运算！

例如：'A' + 1 = 'B'，'A' + 25 = 'Z'

🔑 关键公式：
大写字母 + 32 = 对应的小写字母
小写字母 - 32 = 对应的大写字母

验证：'A'(65) + 32 = 'a'(97) ✓
          'z'(122) - 32 = 'Z'(90) ✓
📐 ASCII 码大小顺序：
数字字符 < 大写字母 < 小写字母
'0'(48) < 'A'(65) < 'a'(97)

💻 示例代码：ASCII 密码解密器

示例1：char 基本用法 + ASCII码查询

#include <iostream> using namespace std; int main() { // 1️⃣ 声明char变量 char myChar = 'A'; cout << "字符: " << myChar << endl; cout << "ASCII码: " << (int)myChar << endl; // 2️⃣ 交互式查询 char query; cout << "输入一个字符："; cin >> query; cout << "它的ASCII码是：" << (int)query << endl; return 0; }

示例2：打印字母表 + 大小写转换

// 用for循环打印大写字母表（A~Z） cout << "大写字母表：" << endl; for (char c = 'A'; c <= 'Z'; c++) { cout << c << " "; } cout << endl; // 大小写转换 char lower = 'h'; char upper = lower - 32; // 小写转大写 cout << lower << " 变大写 → " << upper << endl; // 输出：h 变大写 → H

示例3：凯撒密码加密（后移3位）

cout << "请输入一个小写字母加密："; char letter; cin >> letter; // 加密：后移3位 char encrypted = letter + 3; if (encrypted > 'z') { encrypted = encrypted - 26; // 超出回绕 } cout << "原文：" << letter << " → 密文：" << encrypted << endl; // 解密：前移3位 char decrypted = encrypted - 3; if (decrypted < 'a') { decrypted = decrypted + 26; } cout << "解密还原：" << decrypted << endl;

🎮 趣味练习

练习1：ASCII 侦探 🔍

请回答以下问题：

  1. 字符 'M' 的 ASCII 码是多少？
  2. ASCII 码 100 代表什么字符？
  3. 字符 '9' 和数字 9 一样吗？为什么？
答案：
① 'M' 的 ASCII 码是 77（'A'=65，M是第13个字母，65+12=77）
② ASCII 码 100 代表字符 'd'（'a'=97，100-97=3，即第4个小写字母）
③ 不一样！字符 '9' 的 ASCII 码是 57，数字 9 就是 9。'9' + 1 = 58，而 9 + 1 = 10

练习2：密码大师 🎩

编写程序：输入一个小写字母，输出它的大写形式，并输出原字母后移5位的结果（需要处理超出'z'的回绕）。

提示：小写 - 32 = 大写；后移5位用 `letter + 5`，如果 > 'z' 就减26回绕。

练习3：字符分类器 📊

编写程序：输入一个字符，判断它是大写字母、小写字母、数字字符还是其他字符，并输出它的 ASCII 码。

提示：用 if-else if 结构，判断范围：'A'~'Z'、'a'~'z'、'0'~'9'。

🏆 挑战任务：完整的凯撒密码系统

编写程序，让用户输入一句英文（仅小写字母和空格）和一个偏移量（1~25），输出加密后的密文。还能把密文解密还原！

⭐ 核心算法：加密公式为 (c - 'a' + shift) % 26 + 'a'
其中 c - 'a' 把字母变成0~25的数字，% 26 保证不超出范围。

📝 本课小结

  • char 类型：用于存储单个字符，用单引号 '' 括起来
  • ASCII 编码：每个字符对应一个 0~127 的数字
  • 大写字母：'A'~'Z' 对应 65~90
  • 小写字母：'a'~'z' 对应 97~122
  • 数字字符：'0'~'9' 对应 48~57（不是数字0~9！）
  • 大小写关系：大写 + 32 = 小写，小写 - 32 = 大写
  • 字符运算：字符可以加减整数，结果仍是字符
  • 字符比较：按 ASCII 码比大小，'0' < 'A' < 'a'
  • 实用技巧：利用 ASCII 可以做简单加密（凯撒密码）
