📖 核心知识：模块化编程与多函数协作

🧩 1. 模块化编程 —— "分而治之"

把一个复杂的大任务，拆解成若干个简单的小步骤，每个小步骤用独立的函数来实现。

大问题拆解后的小函数
制作多功能工具箱calculator() 计算器、tempConverter() 温度转换、stringReverser() 字符串反转、asciiPrinter() ASCII艺术

🤝 2. 三种协作模式

模式说明例子
接力模式函数A调用B，B调用C...像接力赛main() → menu() → tool() → helper()
聚合模式一个总控函数调用多个子函数，汇总结果showReport() 内部调用 calcAvg()、findMax()、findMin()
嵌套调用函数内部调用另一个函数，形成调用链asciiPrinter() → printTriangle() → printCharLine()

🎛️ 3. 菜单驱动设计框架

int main() { int choice; do { showMenu(); // 显示菜单 cin >> choice; // 获取用户选择 switch (choice) { // 调度函数 case 1: calculator(); break; case 2: tempConverter(); break; case 0: cout << "再见！" << endl; break; default: cout << "无效选择！" << endl; } } while (choice != 0); // 循环直到退出 return 0; }
🔑 关键：main() 函数不自己做具体工作，而是像一个"聪明的经理"——分配任务给各个"员工"（功能函数）！

main() —总调度—→ showToolboxMenu() ├─ case 1: calculator() —嵌套—→ add()/subtract()/multiply()/divide() ├─ case 2: tempConverter() —嵌套—→ c2f()/f2c() ├─ case 3: stringReverser() —嵌套—→ manualReverse() —嵌套—→ manualLength() ├─ case 4: asciiPrinter() —嵌套—→ printSquare()/printTriangle()/ │ printDiamond() —嵌套—→ printCharLine() └─ case 5: mathTools() —嵌套—→ isPrime()/factorial()/listPrimes() listPrimes() —嵌套—→ isPrime()
