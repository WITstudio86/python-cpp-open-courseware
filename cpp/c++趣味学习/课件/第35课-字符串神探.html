📖 核心知识：神探四大工具

🔢 索引：字符的"座位号"

字符串就像一排座位，每个字符都有自己的座位号（索引）。在C++中，索引从 0 开始！

字符侦探柯南
索引0123
⚠️ 注意：索引从0开始，最后一个字符的索引是 length() - 1！访问越界索引会得到未定义的值。

💻 代码演示：密码破译器

示例1：隔字取码——破解加密纸条

纸条内容每隔2个字符取一个字，还原密码。

#include <iostream> #include <string> using namespace std; int main() { string secret = "山猫雨狗风鱼雪鸟云虫雷蛙"; string password = ""; cout << "🔍 破译中..." << endl; // 每隔2个字符取一个（索引 0, 2, 4, 6...） for (int i = 0; i < secret.length(); i += 2) { password += secret[i]; // 拼接破译出的字 } cout << "密码：" << password << endl; // 输出：密码：山雨风雪云雷 return 0; }

示例2：substr() 与 find() 综合破案

string report = "嫌疑人在图书馆三楼"; string location = report.substr(4, 3); // 从索引4取3个字 cout << "地点：" << location << endl; // "图书馆" int pos = report.find("三楼"); if (pos != string::npos) { cout << "在哪层？" << report.substr(pos, 2) << endl; // "三楼" }
💡 关键技巧：
• find() 找不到时返回 string::npos，记得用 != npos 检查
• substr(4) 只写一个参数 = 从索引4取到末尾
• 循环中用 += 可以逐个拼接字符

🎮 趣味练习 & 挑战任务

练习1：字符统计员 📊

输入一段文字，输出它的长度，并逐个打印每个字符。

string text; getline(cin, text); cout << "长度：" << text.length() << endl; for (int i = 0; i < text.length(); i++) { cout << "第" << i << "个：" << text[i] << endl; }

练习2：姓名拆分器 👤

输入全名，用 substr() 拆分姓氏和名字。

string surname = fullName.substr(0, 1); // 姓（第1个字） string givenName = fullName.substr(1); // 名（第2个字开始）

🏆 挑战任务：信息加密与破译系统

加密：用户输入原始消息 → 在每个字符间插入随机噪音字母 → 输出密文（带长度标记）

破译：解析长度标记 → 隔一个字符取一个 → 还原原始消息

📝 本课小结

工具作用关键点
📏 length() 丈量字符串长度 返回值是字符个数；中文字符也按1个计
🔢 [] 索引 访问指定位置字符 索引从0开始；末位=length()-1
✂️ substr() 截取子串 substr(pos, len)；省略len取到末尾
🔎 find() 搜索关键词 返回位置或 string::npos（没找到）
🔄 遍历 逐个处理字符 for(i=0; i<len; i++) 配合 []
🔑 神探口诀：
length 测量有多长，
索引方括取字符。
substr 截取关键段，
find 搜索找线索。

📌 常见错误提醒：
• 忘记索引从0开始，访问了 length() 位置→越界！
• find() 找不到没检查 npos，当成有效位置用→出错！
• substr 参数写反了→截出来的内容和预期完全不同！
