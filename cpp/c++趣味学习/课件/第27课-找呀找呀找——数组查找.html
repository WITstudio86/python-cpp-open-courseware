🔹 如何在数组中查找数据？

🔹 如何找到最大值和最小值？

🔹 用程序分析全班成绩！

📋 学习目标

  1. 理解线性查找的原理——从第一个元素开始，逐个比较，直到找到目标值。
  2. 掌握查找最大值的算法——假设第一个最大，逐个比较并更新。
  3. 掌握查找最小值的算法——与最大值类似，但比较方向相反。
  4. 能够综合运用数组查找解决实际问题，如成绩分析、数据统计。
💡 小提示：数组查找就像在书架上找一本书——你可以一本一本翻过去看，这就是"线性查找"！

🧠 核心知识

1. 线性查找（Linear Search）

从数组的第一个元素开始，逐个比较，直到找到目标值或遍历完整个数组。用 break 可以在找到后立即退出循环。

// 在数组中查找目标值 int pos = -1; // -1 表示没找到 for (int i = 0; i < n; i++) { if (arr[i] == target) { pos = i; break; // 找到了，退出！ } }

2. 查找最大值算法

int maxVal = arr[0]; // 假设第一个最大 int maxIdx = 0; // 记录位置 for (int i = 1; i < n; i++) { if (arr[i] > maxVal) { maxVal = arr[i]; // 更新最大值 maxIdx = i; // 更新位置 } }

3. 查找最小值算法

与最大值同理，把 > 换成 < 即可！

💻 完整代码：寻找最高分的同学

#include <iostream> #include <string> using namespace std; int main() { const int N = 5; string names[N]; int scores[N]; // 输入学生姓名和成绩 for (int i = 0; i < N; i++) { cout << "姓名："; cin >> names[i]; cout << "成绩："; cin >> scores[i]; } // 查找最高分 int maxScore = scores[0], maxIdx = 0; for (int i = 1; i < N; i++) { if (scores[i] > maxScore) { maxScore = scores[i]; maxIdx = i; } } // 查找最低分 int minScore = scores[0], minIdx = 0; for (int i = 1; i < N; i++) { if (scores[i] < minScore) { minScore = scores[i]; minIdx = i; } } cout << "最高分：" << names[maxIdx] << " " << maxScore << "分" << endl; cout << "最低分：" << names[minIdx] << " " << minScore << "分" << endl; return 0; }
⚡ 注意：数组下标从0开始！第i个元素的位置就是下标i，但是从"第几个"来说，是第 i+1 个。

✅ 本课小结

  • 线性查找是最基本的查找方法：从第一个元素开始，逐个比较，直到找到目标。
  • 查找最大值：假设第一个最大，遍历比较，遇到更大的就更新。
  • 查找最小值：方法与最大值相同，比较条件从"大于"变成"小于"。
  • 记录位置很重要——不仅要知道值，还要知道是谁（哪个下标）。
  • break 语句可以在找到目标后立即退出循环，提高效率。
  • 数组查找是编程中最常用的操作之一，掌握它就能解决成绩分析、数据统计等实际问题！
