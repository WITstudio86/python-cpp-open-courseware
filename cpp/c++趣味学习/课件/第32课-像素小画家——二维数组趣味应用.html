🎨

项目：字符画创作大师

第三单元：数据的组织 课时：45分钟

每个格子都是一颗像素——用字符在控制台上画出你的精彩世界！

🎯 学习目标

  1. 理解二维数组的"画布"角色：将二维字符数组看作一张方格画布，每个元素就是一个"像素点"，用不同字符创作图案
  2. 掌握图案填充的嵌套循环模式：学会用行号i和列号j的关系来控制图案的形状，理解空格和字符的配合规律
  3. 区分实心与空心形状的绘制逻辑：实心形状判断"范围"条件，空心形状只判断"边界"条件
  4. 能用地形模拟理解数据映射：把数字编码转换为可视化符号，理解数据与呈现之间的关系，为后续图形编程打下基础

📖 核心知识：二维数组画图

1. 二维数组 = 画布

二维字符数组就像方格画纸，每个格子存放一个字符，"画图"就是给特定位置赋值：

char canvas[5][5]; // 5×5 画布 // 初始化：全部涂成空白 for (int i = 0; i < 5; i++) for (int j = 0; j < 5; j++) canvas[i][j] = ' ';

2. 图案规律（以三角形为例）

图案规律条件
左下直角三角第i行画i+1个*j <= i
等腰三角形第i行画2i+1个*前导空格: n-i-1
菱形上下对称的等腰三角先递增再递减
空心正方形只在边界画*i==0||i==n-1||j==0||j==n-1
万能绘图模式：
for (i: 行) { for (j: 列) { if (条件) 画字符 else 画空格 } 换行 }

3. 地形模拟：数字 → 符号

数字01234
含义海洋平原高山森林沙漠
符号~.^Ts

💻 代码示例：等腰三角形 & 地形图

等腰三角形

int n = 5; // 高度 for (int i = 0; i < n; i++) { // 前导空格：数量 = n - i - 1 for (int j = 0; j < n - i - 1; j++) cout << " "; // 星星数量 = 2 * i + 1 for (int j = 0; j < 2 * i + 1; j++) cout << "* "; cout << endl; }

地形图模拟

int map[5][5] = { {0,0,1,1,0}, {0,1,2,2,1}, {1,2,2,2,1}, {0,1,2,3,1}, {0,0,1,1,0} }; for (int i = 0; i < 5; i++) { for (int j = 0; j < 5; j++) { switch (map[i][j]) { case 0: cout << "~ "; break; // 海洋 case 1: cout << ". "; break; // 平原 case 2: cout << "^ "; break; // 高山 case 3: cout << "T "; break; // 森林 } } cout << endl; }

运行结果：一片有海洋环绕、高山耸立、森林点缀的地形图！

📝 本课小结

  • 二维字符数组 = 画布：把数组想象成方格纸，给每个格子填上字符就是在"画画"
  • 图案的数学规律：每种图案都有行号 i 和列号 j 的关系公式，找到公式就找到了画法
  • 万能绘图框架：嵌套循环（外循环行、内循环列）+ if-else 判断（满足条件画字符，否则画空格）
  • 实心 vs 空心：实心形状判断"覆盖范围"，空心形状只判断"边界线条"
  • 地形模拟 = 数据映射：用数字编码地形类型，通过 switch 映射为可视化符号，这是"数据可视化"的雏形
  • 创意无限：字符画锻炼逻辑思维和空间想象力，也是学习图形编程和游戏开发的第一步
