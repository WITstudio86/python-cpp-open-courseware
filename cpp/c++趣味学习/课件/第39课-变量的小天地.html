📖 核心知识：变量的"家"在哪里？

🏠 房子比喻：全局 vs 局部

  • 全局变量 = 花园里的公告牌 📋 —— 全家人（整个程序）都能看到
  • 局部变量 = 房间里的私人物品 🧸 —— 只有那个房间里的代码能看到
  • 代码块 { } = 房间的墙壁 🧱 —— 围起来的区域就是作用域

📊 对比表：全局变量 vs 局部变量

属性 全局变量 🌍 局部变量 🚪
定义位置 所有函数外面 函数 / 代码块 { } 内部
可见范围 整个程序所有地方 仅定义它的代码块内
生命周期 程序启动 → 程序结束 进入代码块 → 离开代码块
默认初值 自动初始化为 0 随机垃圾值（须手动赋值）
同名遮盖 能被同名局部变量遮盖 不会被外层遮盖（它自己就是"遮盖者"）
内存位置 静态存储区 📌 栈 Stack 📚

🙈 名字遮盖规则

当局部变量和全局变量同名时，在局部作用域内，局部变量"遮盖"全局变量。

🎯 这就是"就近原则"——离得近的优先！

🧠 记忆技巧： 就像手电筒照在眼前，你会先看到手电筒的光，而看不到远处的星星。局部变量就是"手电筒"，全局变量就是"远处的星星"。
【讲解】📖 核心知识：变量的"家"在哪里？ 结合讲义《2.1 变量的"家"——作用域是什么？》强调： · 想象你住在一栋大房子里，房子里有很多房间：客厅、厨房、卧室、书房。当你站在客厅里，你能看见客厅里的家具；但你看不见卧室里的台灯，也看不见厨房里的冰箱——因为它们在别的房间里。 · 变量的作用域（Scope） 就是这个道理。程序就像一栋大楼，函数、代码块就像不同的房间。变量定义在哪个"房间"里，就只能在哪个"房间"里使用。出了这个房间，变量就"看不见"啦！ · 在 C++ 中，括号 { } 就是"墙壁"——它们围起来的地方就是一个作用域。外面的代码看不到里面的变量，就像隔壁邻居看不到你房间里的玩具一样。 幻灯片上可见要点： · 全局变量 = 花园里的公告牌 📋 —— 全家人（整个程序）都能看到 · 全局变量 · 局部变量 = 房间里的私人物品 🧸 —— 只有那个房间里的代码能看到 · 局部变量 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

💻 代码演示：探索变量的家

示例 1：局部变量——房间里的私有物品

#include <iostream> using namespace std; string garden = "阳光花园"; // 全局：花园公告牌 int houseNo = 39; // 全局：门牌号 void livingRoom() { string sofa = "蓝色沙发"; // 局部：只在客厅里 cout << "客厅有：" << sofa << endl; cout << "花园名：" << garden << endl; // ✅ 能看到全局 // cout << bed; // ❌ 看不到卧室的床！ }

示例 2：名字遮盖——灯光的故事 💡

int light = 1; // 全局：屋外的路灯 void kitchen() { int light = 2; // 局部：厨房的灯（遮盖了路灯！） cout << "在厨房里 light = " << light; // 输出 2 ← 厨房的灯，路灯被"遮住"了 } int main() { cout << "院子里 light = " << light; // 输出 1 kitchen(); // 输出 2（遮盖发生！） cout << "回到院子 light = " << light; // 输出 1 ← 路灯没变 return 0; }
⚠️ 重要： 虽然局部变量遮盖了全局变量，但全局变量并没有被修改！离开局部作用域后，全局变量的值还是原来的值。

✍️ 课堂练习：猜一猜输出什么？

练习 1：同名变量测试

int a = 5; // 全局 void testA() { int a = 10; cout << "A: " << a << endl; // 输出多少？ } void testB() { cout << "B: " << a << endl; // 输出多少？ } int main() { testA(); testB(); cout << "M: " << a << endl; // 输出多少？ return 0; }
✅ 答案：
A: 10（testA 里的局部 a 遮盖了全局 a）
B: 5（testB 没有局部 a，所以看到全局 a）
M: 5（main 也没有局部 a，看到全局 a）

练习 2：生命力测试

int main() { { int secret = 42; } cout << secret; // 这行能正确输出吗？ return 0; }
✅ 答案：编译报错！
secret 在内层 { } 中定义，离开内层 { } 后它就"消失"了（生命周期结束）。
外层的 cout << secret 找不到这个变量，编译器会报错：'secret' was not declared in this scope。

练习 3：作用域判断

int money = 1000; // 全局变量 void saveMoney() { int piggyBank = 50; cout << piggyBank; // ① ✅ 还是 ❌？ cout << money; // ② ✅ 还是 ❌？ } int main() { cout << money; // ③ ✅ 还是 ❌？ // cout << piggyBank; // ④ ✅ 还是 ❌？ }
✅ 答案：
① ✅ piggyBank 在自己作用域内
② ✅ money 是全局变量，任何函数都能访问
③ ✅ money 是全局变量，main 里也能用
④ ❌ piggyBank 是 saveMoney() 的局部变量，main() 看不到它！

📋 本课小结

🏠
概念 一句话解释
局部变量 定义在 { } 里面，只在"这个房间"里能用
全局变量 定义在所有函数外面，整个程序都能用
作用域 变量"能被看见"的代码范围
生命周期 变量从"出生"到"消失"的这段时间
名字遮盖 同名变量就近优先，内层"挡住"外层
🎓 核心法则：
🔹 外层看不到内层——花园看不到卧室里的床 🛏️
🔹 内层能看到外层——卧室里能望见花园 🌳
🔹 同名就近优先——房间里开灯就看不到路灯 💡
🔹 人走茶凉——离开作用域，变量就消失了 ☕
