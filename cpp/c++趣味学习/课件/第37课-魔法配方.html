🔍 函数的"四要素"详解

int add(int a, int b) { // 函数体 —— 这里是具体的"魔法步骤" int result = a + b; return result; // 把计算结果交还给调用者 }
要素 说明 本例中
① 返回类型 函数执行完后交还的数据类型；void 表示不返回任何值 int —— 返回一个整数
② 函数名 给函数起的名字，见名知意，方便调用 add —— 一看就知道是做加法
③ 参数列表 函数的"输入材料"，写在括号里，每个参数需指定类型和名字 (int a, int b) —— 两个整数参数
④ 函数体 花括号 { } 里的代码，描述具体的执行步骤 计算 a+b 并返回结果
🧪 魔法配方类比：
返回类型 = 变出什么东西（药水？卷轴？）
函数名 = 咒语的名字
参数 = 需要的魔法材料
函数体 = 炼制步骤
return = 把成品交出来！
【讲解】🔍 函数的"四要素"详解 结合讲义《🔧 函数的"四要素"》强调： · 一个完整的函数定义包含四个部分，我们可以用下面这个结构图来理解： · 返回类型 函数名 ( 参数列表 ) · ↓ ↓ ↓ · int add ( int a, int b ) · // 函数体 —— 这里是具体的"魔法步骤" 幻灯片上可见要点： · ① 返回类型 · ② 函数名 · ③ 参数列表 · ④ 函数体 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

💻 魔法咒语代码演示

🧙 示例一：void 函数 —— 念咒语（不需要返回值）

// 吟唱魔法咒语 —— void 类型，只做动作不返回值 void castSpell() { cout << "🔮 Expelliarmus! 除你武器！" << endl; }

🧪 示例二：有返回值的函数 —— 炼制药水

// 炼制药水 —— 根据草药和水晶数量计算效力，返回 int int brewPotion(int herbs, int crystals) { int potency = herbs * 5 + crystals * 7; return potency; // 把药水效力交还给调用者 } // 判断药水是否成功 —— 返回 bool 类型 bool isPotionReady(int potency) { return potency > 50; // 效力 > 50 才算成功 }

📞 在 main 函数中调用它们

int main() { castSpell(); // 直接调用 void 函数 int myPotion = brewPotion(3, 2); // 用变量接收返回值 cout << "药水效力：" << myPotion << endl; if (isPotionReady(myPotion)) { cout << "✅ 药水炼制成功！" << endl; } return 0; }
✅ 要点： 函数调用时传入的实参会按顺序赋值给形参。有返回值的函数可以像变量一样用在表达式中！
【讲解】💻 魔法咒语代码演示 本页要点（照着讲即可）： · ✅ 要点： 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

✏️ 课堂练习与挑战

练习一：填空补全函数 基础

下面的 square 函数用于计算整数的平方，请补全缺少的部分：

_____ square(int n) { // ① 返回类型应该是什么？ return _____; // ② 应该返回什么表达式？ }
答案： ① int ② n * n

练习二：找出错误 进阶

下面代码有 3 处错误，请找出来：

int max(int a, b) { // 错误① if (a > b) return a; } // 错误② // ... int result = max(10); // 错误③
答案： ① b 缺少类型 → int b；② 缺少 else return b;；③ 只传了1个参数，应传2个 → max(10, 20)

📝 本课总结

知识点 核心内容
函数是什么 一段有名字、可重复使用的代码块，像魔法书中的配方 📖
函数四要素 返回类型 + 函数名 + 参数列表 + 函数体
void vs 有返回值 void 只执行动作不返回；其他类型必须用 return 交还数据
形参 vs 实参 定义时写的是形参（占位符），调用时传的是实参（实际值）
声明 vs 定义 声明 = 头部 + 分号（告诉编译器"有这个函数"）；定义 = 完整写法
代码复用 写一次，用多次 —— DRY 原则：Don't Repeat Yourself！
🧪 魔法咒语口诀：
定义函数像写配方，返回类型要思量；
函数名字见名知意，参数列表不能忘；
花括号里写步骤，return 把结果交上；
要使用时喊名字，传入实参就能用上！
