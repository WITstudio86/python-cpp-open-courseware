📖 核心知识：五种算术运算符

🔢 运算符一览表

运算符名称示例结果说明
+加法3 + 58把两个数相加
-减法10 - 46求两个数的差
*乘法6 * 742键盘没有×，用*代替
/除法15 / 43整数相除，小数丢弃！
%取余15 % 43求除法的余数
⚠️ 特别注意：整数除法的怪脾气
15 / 4 在数学上是 3.75，但在C++中整数相除，结果是 3——小数部分被直接丢掉，不是四舍五入！
🍬 分糖果理解「取余」：
17颗糖分给5个小朋友 → 17 / 5 = 3（每人3颗）
→ 17 % 5 = 2（还剩2颗）
除法告诉你"每人分多少"，取余告诉你"分完剩多少"！

📋 优先级：运算符的"排队规则"

优先级运算符规则
🥇 第一( ) 括号绝对优先，括号里的先算
🥈 第二* / %乘除取余，同级从左到右
🥉 第三+ -加减最后，同级从左到右

例：3+5*2=13，(3+5)*2=16 —— 括号一加，结果大变！

💻 示例代码

🍬 分糖果程序

// 用户输入糖果数和小朋友数，自动计算分配结果 int candies, kids; cout << "请输入糖果总数："; cin >> candies; cout << "请输入小朋友人数："; cin >> kids; int eachGets = candies / kids; // 每人分到几颗 int leftOver = candies % kids; // 还剩下几颗 cout << "每人分到 " << eachGets << " 颗" << endl; cout << "还剩 " << leftOver << " 颗" << endl;

🔢 优先级演示

// 对比：有没有括号，结果大不同！ cout << "3+5*2 = " << 3+5*2 << endl; // 13 cout << "(3+5)*2 = " << (3+5)*2 << endl; // 16 // 综合计算：一步一步来！ int r = (10+2)*3%5 - 4/2; // 结果 = -1 // ① (10+2)=12 ② 12*3=36 // ③ 36%5=1 ④ 4/2=2 ⑤ 1-2=-1
🔑 口诀：括号排第一，乘除站中间，加减靠后边，同级左到右！

练习2：优先级大考验 🧠

先心算，再用程序验证：(3+5)*2 - 8/4 = ?

提示：①括号 ②乘法 ③除法 ④减法

练习3：数位分离 🔢

把一个三位数368的百位、十位、个位分离出来。

百位 = 368 / 100; // 3 十位 = 368 / 10 % 10; // 6 个位 = 368 % 10; // 8
✅ 练习2答案：(3+5)*2 - 8/4 = 16 - 2 = 14
步骤：3+5=8 → 8×2=16 → 8/4=2 → 16−2=14

📝 本课小结

知识点内容
加法 +两数相加，如 3+5=8
减法 -两数相减，如 10-4=6
乘法 *两数相乘，如 6*7=42
整数除法 /整数相除只留整数，如 15/4=3
取余 %求余数，如 17%5=2、15%4=3
优先级括号 → 乘除取余 → 加减，同级左到右
分糖果公式每人 = 总数 / 人数；剩余 = 总数 % 人数
🔑 记住口诀：
加减乘除和取余，五位助手来帮忙；
整数除法丢小数，取余专管剩多少；
括号优先排第一，乘除取余站中间；
加减最后来处理，同级就从左到右！
