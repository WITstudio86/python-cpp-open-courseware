📖 核心知识

嵌套循环的语法

for (int i = 1; i <= 3; i++) { // 外层 cout << "第" << i << "行: "; for (int j = 1; j <= 4; j++) { // 内层 cout << j << " "; } cout << endl; } /* 输出： 第1行: 1 2 3 4 第2行: 1 2 3 4 第3行: 1 2 3 4 */

循环次数计算

🔢 总执行次数 = 外层循环次数 × 内层循环次数

上面例子：3 × 4 = 12次（内层循环体的执行次数）

如果内层次数随外层变化：

for(i=1;i<=5;i++) for(j=1;j<=i;j++) → 1+2+3+4+5 = 15次

💻 示例代码

🟦 数字正方形生成器

int n; cout << "请输入边长："; cin >> n; for (int i = 1; i <= n; i++) { // 外层控制行 for (int j = 1; j <= n; j++) { // 内层控制列 cout << j << " "; } cout << endl; // 每行结束换行 }

📍 坐标网格

for (int row = 1; row <= 5; row++) { for (int col = 1; col <= 5; col++) { cout << "(" << row << "," << col << ") "; } cout << endl; } // 输出25个坐标：(1,1)(1,2)...(5,5)

🎮 趣味练习

📝 本课小结

要点说明
结构循环体内再套一个循环
核心规律外层1次 → 内层1遍
总次数外层次数 × 内层次数
变量命名外层常用i，内层常用j
组合形式for套for、while套for、for套while均可
记口诀："外圈走一步，内圈走一圈！总次数=外×内"
