📖 核心知识

嵌套循环的语法

for (int i = 1; i <= 3; i++) { // 外层 cout << "第" << i << "行: "; for (int j = 1; j <= 4; j++) { // 内层 cout << j << " "; } cout << endl; } /* 输出： 第1行: 1 2 3 4 第2行: 1 2 3 4 第3行: 1 2 3 4 */

循环次数计算

🔢 总执行次数 = 外层循环次数 × 内层循环次数

上面例子：3 × 4 = 12次（内层循环体的执行次数）

如果内层次数随外层变化：

for(i=1;i<=5;i++) for(j=1;j<=i;j++) → 1+2+3+4+5 = 15次

【讲解】📖 核心知识 本页要点（照着讲即可）： · 🔢 总执行次数 = 外层循环次数 × 内层循环次数 · 总执行次数 = 外层循环次数 × 内层循环次数 · 上面例子：3 × 4 = 12 次（内层循环体的执行次数） · 如果内层次数随外层变化： · for(i=1;i<=5;i++) for(j=1;j<=i;j++) → 1+2+3+4+5 = 15 次 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
