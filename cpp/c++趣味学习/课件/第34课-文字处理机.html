📖 核心知识：深入理解 string

1️⃣ 什么是 string？

string 是 C++ 提供的字符串类型，专门用来存储和处理文字。使用前需要 #include <string>。

string name = "小明"; string message = "你好，欢迎学习 C++！"; // 注意：必须用英文双引号 "" 括起来！

2️⃣ cin >> vs getline() 对比

输入方式能读空格？读到哪停止？适用场景
cin >> s❌ 不能遇到空格 / Tab / 换行读单词、学号等不含空格的
getline(cin, s)✅ 可以遇到换行符读名字、地址、一句话等
⚠️ 关键警告：混合使用 cin >> 和 getline() 时，必须在 cin >> 后面加上 cin.ignore();，否则 getline() 会"吃"到残留的换行符，导致输入被跳过！

3️⃣ 字符串拼接：用 + 把文字连起来

string firstName = "张"; string lastName = "三"; string fullName = firstName + lastName; // "张三" string card = "姓名：" + fullName + "\n"; card += "年龄：12岁\n"; // += 在末尾追加 card += "爱好：编程\n";

4️⃣ 常用操作速查

操作代码说明
获取长度s.length()返回字符个数
访问字符s[0]第1个字符（索引从0开始）
判断为空s.empty()空则返回 true
清空s.clear()变成空字符串
比较s1 == s2内容相同则 true

💻 示例代码：个人名片生成器

输入你的姓名、学校、爱好和电话，程序自动生成一张漂亮的文字名片！

#include <iostream> #include <string> using namespace std; int main() { string name, school, hobby, phone; cout << "🎨 === 个人名片生成器 === 🎨" << endl; cout << "请输入你的姓名："; getline(cin, name); // 用 getline 读取整行 cout << "请输入你的学校："; getline(cin, school); cout << "请输入你的爱好："; getline(cin, hobby); cout << "请输入你的电话："; getline(cin, phone); // 拼接生成名片 string card = ""; card += "╔══════════════════════════╗\n"; card += "║ 🪪 个 人 名 片 ║\n"; card += "╠══════════════════════════╣\n"; card += "║ 姓名：" + name + " ║\n"; card += "║ 学校：" + school + " ║\n"; card += "║ 爱好：" + hobby + " ║\n"; card += "║ 电话：" + phone + " ║\n"; card += "╚══════════════════════════╝\n"; cout << card; // 输出名片 // 统计信息 cout << "📊 姓名字符数：" << name.length() << endl; return 0; }
💡 思考：为什么这里用 getline() 而不是 cin >>？因为姓名和学校名称可能包含空格（比如"北京大学附属中学"），用 cin >> 会读到空格就停止，导致数据不完整！

🎮 趣味练习

练习一：填空补全代码

补全下面的代码，实现输入名字和爱好后输出一句话：

string name, _____; // ① 第二个变量名 cout << "你的名字："; getline(cin, _____); // ② 变量名 cout << "你的爱好："; getline(cin, hobby); // ③ 补全输出：小华喜欢编程！ cout << name __ "喜欢" __ hobby __ "！" << endl;
✅ 答案：① hobby ② name ③ + + <<

练习二：判断对错

小明写了一段代码，输入"Bei Jing"后，输出的 a 和 b 分别是什么？

string a, b; cin >> a >> b; // 用户输入：Bei Jing
✅ 答案：a = "Bei"，b = "Jing"。cin >> 遇到空格就停下来，所以"Bei Jing"被分成了两个单词。

🏆 挑战：智能问候机器人

编写程序：输入名字和心情（"开心"/"有点困"），根据心情输出不同的问候语。提示：用 if-else 判断心情，用 + 拼接问候。

✅ 核心思路：
if (mood == "开心") → cout << name + "，太棒了！" << endl;
else if (mood == "有点困") → cout << name + "，喝杯水提提神！" << endl;
else → cout << name + "，每天都是新的开始，加油！" << endl;

📝 本课小结

  • string 是处理文字的类型 —— 用双引号 "" 赋值，用 + 拼接，需 #include <string>。
  • cin >> 读单词 —— 遇空格就停，适合读学号、单词。
  • getline() 读整行 —— 空格也保留，适合读姓名、地址、句子。
  • 混用别忘 cin.ignore() —— 清除缓冲区残留的换行符，防止 getline 被跳过。
  • length() 获取长度 —— 知道字符串里有多少个字符。
  • 字符串可以比较 —— 用 == 判断内容是否相同，实现智能对话。
