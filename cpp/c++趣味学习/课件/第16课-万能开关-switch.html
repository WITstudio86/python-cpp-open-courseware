📖 switch语法结构图

switch像一个多档位旋转开关，根据变量的值接通对应的电路：

🔘 switch(变量) —— 旋钮

⬇️

case 值1: → 变量 == 值1？执行这里 → break; 🛑
case 值2: → 变量 == 值2？执行这里 → break; 🛑
case 值3: → 变量 == 值3？执行这里 → break; 🛑
default: → 都不匹配？执行这里（兜底）
⚠️ break到底有多重要？
有break：执行完当前case → 跳出switch → 结束 ✅
没break：执行完当前case → 穿透到下一个case → 继续执行！❌
就像开车没有刹车——根本停不下来！
💡 巧用穿透：多个case可以共用同一段代码！
case 1: case 2: case 3: case 4: case 5:
cout << "工作日"; break;
这里case 1-5全部"穿透"到同一行代码，非常巧妙！

💻 示例代码：自动点餐机

#include <iostream> using namespace std; int main() { int choice; cout << "🍔 欢迎来到自动点餐机！" << endl; cout << "1.汉堡15元 2.薯条8元 3.可乐5元" << endl; cout << "请选择序号（1-3）："; cin >> choice; switch (choice) { // ← 开关旋钮 case 1: // ← 冒号！ cout << "🍔 汉堡 15元" << endl; break; // ← 刹车！跳出switch case 2: // ← 冒号！ cout << "🍟 薯条 8元" << endl; break; // ← 刹车！ case 3: // ← 冒号！ cout << "🥤 可乐 5元" << endl; break; // ← 刹车！ default: // ← 兜底 cout << "❌ 没有这个菜品！" << endl; break; } return 0; }

🚫 穿透演示（没有break的危险）

int n = 2; switch (n) { case 1: cout << "A"; // 没有break！ case 2: cout << "B"; // 没有break！ case 3: cout << "C"; // 没有break！ } // 输出：BC （从case 2开始穿透到case 3！）

⚠️ 注意：case后面是冒号:不是分号;！这是初学者最容易犯的语法错误！

🎮 趣味练习

练习1：星期翻译官 📅

用switch写程序，输入1-7，输出对应的中文星期几。

✅ 参考答案：
case 1: cout << "星期一"; break; 以此类推到case 7，default提示"输入错误"。

练习2：穿透大考验 ⚡

下面代码输入3会输出什么？

switch (n) { case 1: cout << "A"; case 2: cout << "B"; case 3: cout << "C"; case 4: cout << "D"; case 5: cout << "E"; }
🔍 答案：CDE — 从case 3匹配开始，因为没有break，一路穿透输出C、D、E。注意A、B没有被输出，因为switch不是从头开始执行的！

练习3：选对工具 🔧

第15课的成绩等级评定（>=90→A, >=80→B...），用switch改写合适吗？

✅ 答案：不适合！因为switch只能判断等于具体值，不能判断范围。如果硬用switch需要写100个case，不现实。判断范围用if-else才是正确选择！

📝 本课小结

知识点说明
switch语法switch(变量) { case 值: 代码; break; }
case冒号case后面跟冒号(:)，不是分号(;)！
break刹车遇到break跳出switch，没有break会"穿透"
default兜底所有case都不匹配时执行，相当于if-else的else
穿透妙用多个case可共享代码：case 1: case 2: ... break;

🔀 switch vs if-else 选择指南

判断内容推荐例子
等于具体值switch ✅星期几、菜单、按键
大于/小于范围if-else ✅分数等级、温度、年龄
复杂条件(&& ||)if-else ✅多重条件组合
🔑 记住口诀：
万能开关switch到，case对应把路找；
遇到break就刹车，没有break一路跑！
default做兜底，具体值判断它最好；
范围判断用if-else，选对工具代码妙！
