📖 核心知识：六位比较裁判

⚖️ 数字比大小擂台

两个数字上台PK，比较运算符就是公正的裁判！裁判给出结果：对（true/1）或错（false/0）。

运算符名称例子结果含义
>大于8 > 5true (1)8比5大
<小于3 < 10true (1)3比10小
>=大于等于7 >= 7true (1)7不小于7（相等也行）
<=小于等于5 <= 8true (1)5不大于8
==等于10 == 10true (1)左右两边相等
!=不等于4 != 9true (1)左右两边不同
🔑 比较结果只有两种：
对 → true → 1   |   错 → false → 0

💻 示例代码

比大小擂台——六种运算符全演示

#include <iostream> using namespace std; int main() { int a = 8, b = 5; cout << a << " > " << b << " ? " << (a > b) << endl; cout << a << " < " << b << " ? " << (a < b) << endl; cout << a << " >= " << b << " ? " << (a >= b) << endl; cout << a << " <= " << b << " ? " << (a <= b) << endl; cout << a << " == " << b << " ? " << (a == b) << endl; cout << a << " != " << b << " ? " << (a != b) << endl; return 0; }

练习2：找茬大侦探 🕵️

下面的代码有什么问题？

int a = 5; if (a = 3) { // ← 发现问题了吗？ cout << "相等"; }

答案：if (a = 3) 用的是赋值=而不是比较==！应该写成 if (a == 3)。

📝 本课小结

运算符名称例子结果为true时
>大于8 > 5左边大于右边
<小于3 < 10左边小于右边
>=大于等于7 >= 7左边不小于右边
<=小于等于5 <= 8左边不大于右边
==等于10 == 10左右两边相等
!=不等于4 != 9左右两边不同
🚨 重中之重：
= 是赋值（把东西放进去），== 是比较（问相等吗？）
比较结果是布尔值：真（1）或假（0）
🔑 记住口诀：
比较运算有六种，大于小于两兄弟；
等于用两个等号，一个等号是赋值！
比较结果只有真和假，true就是1，false就是0！
