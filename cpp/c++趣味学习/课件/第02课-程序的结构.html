第02课：编程积木——程序的结构

第一阶段：C++初体验 | 课时：45分钟

✨ 搭建程序积木块 ✨

头文件 main函数 语句与分号

🎯 学习目标

  • 理解C++程序的基本结构：头文件、main函数、语句
  • 认识 #include、using namespace std、main() 的作用
  • 理解语句和分号的关系 —— 分号 = 句号！
💡 想一想：
你见过乐高积木吗？一个复杂的大城堡，其实是由很多小积木拼成的。C++程序也是一样哦！

📖 五大积木块

🧰 积木块1：头文件 #include
准备工具箱！#include <iostream> 引入输入输出工具
📚 积木块2：命名空间 using namespace std;
告诉电脑"工具在标准书架上"
🚪 积木块3：main函数 int main() { }
程序的"大门"，电脑从这里开始执行
📝 积木块4：语句
花括号里面具体要做的指令
✅ 积木块5：返回值 return 0;
告诉系统"程序正常结束啦！"
🔑 口诀：
头文件是工具箱，main函数是进门；花括号里写指令，句句分号记在心！

💻 程序结构详解

// ===== 积木块1：工具箱 ===== #include <iostream> #include <cmath> // 数学工具箱 // ===== 积木块2：使用说明 ===== using namespace std; // ===== 积木块3+4+5：程序主体 ===== int main() { // 大门 cout << "程序开始了!" << endl; // 语句 cout << sqrt(16) << endl; // 用数学工具 return 0; // 结束信号 }

⚠️ 最容易犯的错：忘记分号！

cout << "你好" << endl // ❌ 少分号！ cout << "世界" << endl; // ✅ 有分号

分号 ; 就像写作文的句号，告诉电脑："这句话说完啦！"

🎮 趣味练习

练习1：拼图大师 🧩

把下面的积木块排成正确的顺序：

A. return 0;   B. int main() {   C. cout ...   D. #include <iostream>   E. }   F. using namespace std;

答案：D → F → B → C → A → E

练习2：找茬游戏 🔍

下面程序有3处分号缺失，你找到了吗？

using namespace std // 缺分号！ cout << "hello" << endl // 缺分号！ return 0 // 缺分号！
✅ 答案：以上三行末尾都要加上分号 ;

📝 本课小结

积木块代码比喻
头文件#include <iostream>🧰 工具箱

main函数int main() { }🚪 房子大门
语句cout << "你好";📝 指令
返回值return 0;✅ 完成信号
分号;🔴 句号
