🔗 知识点之间的联系

核心公式：程序 = 数据 + 逻辑

数据（变量 → 数组 → 结构体）提供了"原材料"
逻辑（条件判断 → 循环 → 函数）提供了"加工方法"
排序是数据处理的高级操作，结合了数组、循环、条件判断和交换

🧩 编程思维五大能力

  1. 分解思维—— 大问题拆成小问题（函数）
  2. 抽象思维—— 提取关键特征（结构体）
  3. 算法思维—— 设计步骤解决问题（排序）
  4. 调试思维—— 不慌不乱排查错误
  5. 迭代思维—— 不断改进、越来越完善

💻 综合示例：学生成绩管理系统

以下代码整合了结构体、冒泡排序、选择排序、菜单交互、统计分析等多个知识点：

#include <iostream> #include <string> using namespace std; // 定义学生结构体 —— 把姓名、年龄、成绩打包 struct Student { string name; int age; double score; }; // 冒泡排序：按成绩从高到低（降序） void bubbleSort(Student arr[], int n) { for (int i = 0; i < n - 1; i++) { bool swapped = false; for (int j = 0; j < n - 1 - i; j++) { if (arr[j].score < arr[j + 1].score) { Student temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp; swapped = true; } } if (!swapped) break; // 优化：无交换则提前结束 } } // 选择排序：按年龄从小到大（升序） void selectSort(Student arr[], int n) { for (int i = 0; i < n - 1; i++) { int minIdx = i; for (int j = i + 1; j < n; j++) { if (arr[j].age < arr[minIdx].age) minIdx = j; } if (minIdx != i) { Student temp = arr[i]; arr[i] = arr[minIdx]; arr[minIdx] = temp; } } } int main() { const int N = 5; Student stu[N] = { {"小明", 12, 88.5}, {"小红", 11, 96.0}, {"小刚", 12, 75.5}, {"小丽", 13, 91.0}, {"小强", 11, 62.0} }; int choice; while (true) { cout << "\n=== 菜单 ===" << endl; cout << "1.查看 2.成绩排名(冒泡)" << endl; cout << "3.年龄排序(选择) 4.统计 5.退出" << endl; cin >> choice; if (choice == 1) { // 显示所有学生（含等级评定） for (int i = 0; i < N; i++) { char g = stu[i].score >= 90 ? 'A' : stu[i].score >= 80 ? 'B' : stu[i].score >= 60 ? 'C' : 'D'; cout << stu[i].name << " " << stu[i].score << " " << g << endl; } } else if (choice == 2) { bubbleSort(stu, N); // 冒泡排序 } else if (choice == 3) { selectSort(stu, N); // 选择排序 } else if (choice == 4) { // 统计：平均分、最高分、最低分 double sum = 0, maxS = stu[0].score, minS = stu[0].score; for (int i = 0; i < N; i++) { sum += stu[i].score; if (stu[i].score > maxS) maxS = stu[i].score; if (stu[i].score < minS) minS = stu[i].score; } cout << "平均:" << sum/N << " 最高:" << maxS << " 最低:" << minS << endl; } else if (choice == 5) { break; } } return 0; }
⚡ 代码要点：这个程序展示了如何用while(true)+if-else实现菜单交互，用结构体数组管理数据，用两种排序算法处理数据，用循环遍历进行统计分析。这就是知识综合运用的力量！

🏆 毕业挑战：创造你的毕业作品

🎓 任务：从以下三个方向中任选一个，设计并实现一个完整的综合小程序！

方向一：我的编程工具箱 🧰

设计一个多功能菜单程序，至少包含 4 个功能：

  • 计算功能（计算器、找素数、九九乘法表）
  • 排序/查找功能（成绩排名、数字排序）
  • 游戏功能（猜数字、石头剪刀布、知识问答）
  • 信息管理功能（通讯录、图书管理）

方向二：班级成绩管理系统 📊

设计完整的成绩管理程序：

  • 结构体存储学生信息（姓名、学号、多科成绩）
  • 按总分排名（冒泡排序/选择排序）
  • 每门课的最高分、最低分、平均分统计
  • 找出需要补考的学生（有不及格科目）

方向三：自由创作 ✨

用你学过的知识自由设计！至少使用 5 种不同知识点。

  • 灵感：宠物养成游戏 / 小小图书馆 / 运动会统计
  • 灵感：幸运大转盘 / 密码管理器 / 冒险文字游戏
