🎯 学习目标

  • 区分形参与实参：理解函数定义时的"占位变量"（形参）和调用时传入的"真实数据"（实参），借助"快递单空白栏 vs 填好的单子"的比喻建立清晰概念。
  • 掌握 return 语句：学会用 return 把计算结果"寄回"给调用方，理解不同返回值类型（int / double / string / bool）的用法。
  • 认识 void 类型：理解 void 函数"只干活、不退货"的特点，知道何时该用 void，何时该用有返回值的函数。
  • 传递多个参数：学会编写接收多个参数的函数，掌握数量、类型、顺序一一对应的"对号入座"规则。

一、形参 vs 实参 —— 快递单的空白栏 vs 填好的信息

对比维度形参（占位符）实参（真实数据）
出现位置函数定义时函数调用时
类比📋 快递单空白栏✏️ 填写后的快递单
本质变量声明（占位置的）具体的值或变量
举例int add(int x, int y) —— x, y 是形参add(3, 5) —— 3, 5 是实参

二、return 语句 —— 签收回执

返回类型示例函数return 的内容
intint getAge()return 12;

三、void 函数 —— 投递公告，无需签收

void 函数只执行任务（如打印面单），不返回任何值。
不能写成 int x = voidFunction(); —— 这就像向一个只投递公告的邮递员要签收单！

🔑 记忆口诀：
形参像空白栏，实参把内容填；
return 带回执，void 不归还；
参数对号坐，顺序别乱串！

💻 代码演示：数据快递站系统

📦 快递计费函数（有参数、有返回值）

// 计算快递费用的函数 // weight, distance, isUrgent 是形参（占位符） double calculateFee(double weight, int distance, bool isUrgent) { double fee = weight * 2.0; // 基础费：每kg 2元 if (distance > 1000) { // 远距离附加费 fee += 10.0; } if (isUrgent) { // 加急服务费 fee += 15.0; } return fee; // ← 把结果"寄回"给调用方 } int main() { double fee1 = calculateFee(2.5, 500, false); // 2.5, 500, false 是实参（真实数据） // → 费用 = 2.5 × 2 = 5.0 元 cout << "普通包裹费用：￥" << fee1 << endl; double fee2 = calculateFee(8.0, 1500, true); // → 费用 = 8.0×2 + 10 + 15 = 41 → 满30打9折 → 36.9 元 cout << "加急包裹费用：￥" << fee2 << endl; return 0; }

📋 打印面单（void 函数 —— 只干活，不退货）

// void 函数：只执行任务，不返回任何值 void printReceipt(string sender, string receiver, double weight, int distance, bool isUrgent) { // 在 void 函数内部调用其他函数帮忙！ double fee = calculateFee(weight, distance, isUrgent); cout << "╔══════════════════════════════╗" << endl; cout << "║ 📬 数据快递站 · 电子面单 ║" << endl; cout << "║ 发件人：" << sender << " ║" << endl; cout << "║ 收件人：" << receiver << " ║" << endl; cout << "║ 费用合计：￥" << fee << " ║" << endl; cout << "╚══════════════════════════════╝" << endl; // void 函数不需要 return —— 执行完就结束 }

🎮 趣味练习

练习1：填空补全 —— 计算圆面积 🟡

小明想写一个函数计算圆面积，请帮他补全缺少的内容：

______ circleArea(double ______) { // ① 返回值类型和形参名 const double PI = 3.14159; return PI * r * r; // ② 计算结果返回 } int main() { double r; cin >> r; double s = circleArea(______); // ③ 实参填什么？ cout << "面积：" << s << endl; return 0; }
✅ 答案：① double 和 r ② 代码本身正确 ③ 填 r（把用户输入传给函数）

练习2：判断正误 ⚖️

以下说法中，正确的是哪一条？

  1. 形参在函数定义时可以不给名字，只写类型就行。
  2. void 函数中可以用 return 0; 提前退出。
  3. 实参和形参的名字必须相同。
  4. 函数有2个 int 形参时，调用时必须传恰好2个 int 实参。
✅ 答案：只有第 4 条正确。第 1 条：形参必须有名字；第 2 条：void 函数中 return; 不带值；第 3 条：名字可以不同，关键看位置对应。

🏆 挑战题：快递费用计算系统

编写函数 double calculateFee(double w, int d, bool u)：基础费=w×2元，d>1000加10元，u=true加15元；费用>30打9折。再写 void printReceipt(...) 打印电子面单。

💡 提示：在 printReceipt 中调用 calculateFee —— 函数之间可以互相调用！这就是模块化编程的核心：各司其职，互相协作。

📝 本课小结：快递站工作手册

概念快递站比喻C++ 代码

✨ 核心要点

  • 形参是占位符（定义时），实参是真数据（调用时），两者在位置上"对号入座"。
  • return 做两件事：① 把结果"寄回去"；② 立刻结束函数执行。
  • void 函数不返回值，只执行任务。调用时不能赋值给变量。
  • 参数传递规则：数量、类型、顺序必须与定义时一模一样。
  • 函数之间可以互相调用：一个函数可以请另一个函数帮忙，分工合作效率高！
  • 基本类型参数是"拷贝传递"：函数内部修改形参，不会影响外部的实参。
🔑 终极口诀：
形参实参对号入座，return 把结果带回家，
void 只管干好活，模块分工力量大！
