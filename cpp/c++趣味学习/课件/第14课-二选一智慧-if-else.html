📖 if-else 语法详解

if (条件) { // 条件成立 → 走这条路 代码A; } else { // 条件不成立 → 走另外一条路 代码B; }

🔍 核心理解

if和else是互斥的：

  • 要么执行if里的代码（条件成立时）
  • 要么执行else里的代码（条件不成立时）
  • 二者必选其一，不可能两个都执行或都不执行
🧠 记忆口诀：
条件成立走if路，条件不成走else路；
两条路里必选一，花括号里看清楚！

⚠️ else配对规则 —— 本课重点！

规则：else和最近的、未配对的if配对

🔴 陷阱代码：

if (score >= 90) // 第1个if if (score == 100) // 第2个if cout << "满分！" << endl; else // 这个else和谁配对？ cout << "优秀！" << endl;
答案：else和第2个if（score == 100）配对！
• score = 100 → 输出"满分！" ✓
• score = 95 → 输出"优秀！"（因为==100不成立，执行else）
• score = 80 → 什么都不输出！（最外层if都没进去）
这很可能不是你想要的！

✅ 修复：用花括号明确配对

if (score >= 90) { if (score == 100) { cout << "满分！" << endl; } } else { // 现在明确和第一个if配对 cout << "要继续加油！" << endl; }

💻 示例1：判断奇偶数

#include <iostream> using namespace std; int main() { int number; cout << "请输入一个整数："; cin >> number; // 用 % 取余运算：除以2的余数 // 余数为0 → 偶数；余数为1 → 奇数 if (number % 2 == 0) { cout << number << " 是偶数！" << endl; cout << "偶数可以被2整除，没有余数~" << endl; } else { cout << number << " 是奇数！" << endl; cout << "奇数除以2会余1~" << endl; } return 0; }
📝 关键是 % 运算符：
• 10 % 2 = 0 → 偶数 → 执行if
• 7 % 2 = 1 → 奇数 → 执行else
• % 是取余运算，不是百分号哦！

💻 示例2：嵌套if-else

判断一个数是正数、负数还是零：

int number; cin >> number; if (number > 0) { cout << number << " 是正数！" << endl; } else { // number <= 0，在else里继续判断 if (number == 0) { cout << "你输入的是零！" << endl; cout << "零既不是正数也不是负数。" << endl; } else { cout << number << " 是负数！" << endl; } }

🧩 嵌套结构分析

输入第1层判断第2层判断输出
5number > 0 → true不进入else"是正数"
0number > 0 → falsenumber == 0 → true"是零"
-3number > 0 → falsenumber == 0 → false"是负数"
💡 提示： 这种"else里再写if-else"很常见。下次课我们还会学到更简洁的 else if 写法！
