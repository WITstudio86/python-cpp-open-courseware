第03课：注释与代码规范

第一阶段：C++初体验 | 课时：45分钟

✨ 给程序写说明书 ✨

单行注释 多行注释 缩进 命名规则

🎯 学习目标

  • 理解注释是什么 —— 写在代码旁边的"备忘条"
  • 掌握单行注释（//）和多行注释（斜杠星号...星号斜杠）
  • 学习代码缩进和命名规范，养成好习惯
💡 想一想：
你有没有在课本上划过重点、做过笔记？注释就是代码里的"笔记"！ 编译器会忽略注释，但它们能让代码变得超级好懂。

📖 注释的种类

1️⃣ 单行注释：//

// 这是单行注释 cout << "Hello!"; // 也可以写在代码后面

2️⃣ 多行注释：/* 开始，*/ 结束

/* 这是多行注释 可以写很多行 编译器全都会忽略 */

3️⃣ 缩进：让代码有层次

❌ 没有缩进
int main() { cout << "A"; { cout << "B"; } }
✅ 有缩进
int main() { cout << "A"; { cout << "B"; } }

💻 好命名 vs 坏命名

❌ 坏名字✅ 好名字说明
a, b, cage, score, name名字要有意义
x1, x2studentAge, maxScore见名知意
1namename1不能数字开头

命名规则速记

  • 只能使用 字母、数字、下划线
  • 第一个字符不能是数字
  • 区分大小写（age 和 Age 不同）
  • 使用驼峰式（myAge）或下划线式（my_age）
🔑 口诀：双斜杠写单行，星号斜杠包多行； 缩进对齐层次清，好名字让代码自己会说话！
