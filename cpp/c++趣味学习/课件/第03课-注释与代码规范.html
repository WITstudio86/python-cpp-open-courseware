📖 注释的种类

1️⃣ 单行注释：//

// 这是单行注释 cout << "Hello!"; // 也可以写在代码后面

2️⃣ 多行注释：/* 开始，*/ 结束

/* 这是多行注释 可以写很多行 编译器全都会忽略 */

3️⃣ 缩进：让代码有层次

❌ 没有缩进
int main() { cout << "A"; { cout << "B"; } }
✅ 有缩进
int main() { cout << "A"; { cout << "B"; } }
【讲解】📖 注释的种类 本页要点（照着讲即可）： · ❌ 没有缩进 · ✅ 有缩进 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

💻 好命名 vs 坏命名

❌ 坏名字✅ 好名字说明
a, b, cage, score, name名字要有意义
x1, x2studentAge, maxScore见名知意
1namename1不能数字开头

命名规则速记

  • 只能使用 字母、数字、下划线
  • 第一个字符不能是数字
  • 区分大小写（age 和 Age 不同）
  • 使用驼峰式（myAge）或下划线式（my_age）
🔑 口诀：双斜杠写单行，星号斜杠包多行； 缩进对齐层次清，好名字让代码自己会说话！
【讲解】💻 好命名 vs 坏命名 本页要点（照着讲即可）： · 只能使用 字母、数字、下划线 · 字母、数字、下划线 · 第一个字符 不能是数字 · 不能是数字 · 区分大小写 （age 和 Age 不同） · 区分大小写 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
