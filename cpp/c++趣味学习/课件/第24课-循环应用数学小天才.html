📖 核心知识

素数判断（优化技巧）

// 只需检查到 sqrt(n)！ bool isPrime = true; for (int i = 2; i <= sqrt(n); i++) { if (n % i == 0) { isPrime = false; break; // 找到一个因子就够了 } }

为什么是√n？如果n=a×b，a和b中必有一个≤√n。n=100时，本来要查98次，现在只需10次！

完数 = 真因子之和

因子成对出现：如果i是n的因子，n/i也是。只需搜索到√n。

水仙花数：分离各位数字

int ge = num % 10; // 个位 int shi = num / 10 % 10; // 十位 int bai = num / 100; // 百位 if (ge*ge*ge + shi*shi*shi + bai*bai*bai == num) cout << num << " 是水仙花数！" << endl;
【讲解】📖 核心知识 本页要点（照着讲即可）： · 为什么是√n？ 如果n=a×b，a和b中必有一个≤√n。n=100时，本来要查98次，现在只需10次！ · 为什么是√n？ · 因子成对出现：如果i是n的因子，n/i也是。只需搜索到√n。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

💻 示例代码

🔍 素数判断器

int n; cin >> n; bool isPrime = true; for (int i = 2; i <= sqrt(n); i++) { if (n % i == 0) { isPrime = false; cout << "因子：" << i << " × " << n/i << endl; break; } } if (isPrime) cout << n << " 是素数！" << endl;

🌸 寻找水仙花数

for (int num = 100; num <= 999; num++) { int a = num/100, b = num/10%10, c = num%10; if (a*a*a + b*b*b + c*c*c == num) cout << num << " "; } // 输出：153 370 371 407
