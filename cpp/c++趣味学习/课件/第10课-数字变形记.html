💡 先想一想：
你有一个整数 5 和一个小数 3.2，如果把它们加在一起，结果应该是什么类型？整数还是小数？C++是怎么处理这个问题的？

📖 核心知识：数字变装秀

👗 数字的"衣服"——数据类型

int 是一件"整数外套"，穿上它就没有小数尾巴。double 是一件"小数披风"，穿上它就能保留小数部分。所谓类型转换，就是让数字换一件衣服穿！

🎭 类型转换规则

场景方式安全性例子结果
int + double隐式（自动）✅ 安全3 + 2.55.5
int 赋值给 double隐式（自动）✅ 安全double d=5d=5.0
double 赋值给 int隐式（自动）❌ 数据丢失int i=3.14i=3
(int) 强制转换强制（手动）⚠️ 人工确认(int)5.95（截断）
char 超出范围溢出❌ 错误结果char c=128c=-128
⚠️ 整数除法的陷阱：
5 / 2 = 2（整数除法，小数丢了！）
5.0 / 2 = 2.5（有小数参与，结果正确！）
规则：只要除号两边有一个是小数，结果就是小数。
💧 数据溢出——水杯的比喻：
每个数据类型都像一个固定大小的水杯。char 的杯子最小（-128~127），int 大得多（约±21亿）。当数字超出杯子容量时，就会"溢出"，数值会发生奇怪的跳变！

例如：char c = 127; c = c + 1; 结果不是 128，而是 -128！就像钟表一样，走到头就绕回去了。

💻 代码演示

隐式转换 & 强制转换

// 隐式转换：int 自动换装成 double int a = 5; double b = 3.2; double sum = a + b; // 5 → 5.0，结果 8.2 // 强制转换：手动把小数砍成整数（C语言风格） int x = (int)5.9; // x = 5（不是四舍五入！） int y = (int)3.14; // y = 3 // 强制转换：C++风格（推荐写法） int z = static_cast<int>(5.9); // z = 5 // 整数除法的正确姿势 cout << 5 / 2; // 输出 2（陷阱！） cout << 5.0 / 2; // 输出 2.5（正确） cout << (double)5/2; // 输出 2.5（正确）

数据溢出演示

char c = 127; // char 范围：-128~127 cout << (int)c; // 输出 127 c = c + 1; // 水杯溢出！ cout << (int)c; // 输出 -128（绕回去了！） int max = 2147483647; // int 最大值 ≈ 21亿 cout << max + 1; // 输出 -2147483648（溢出！）

小结：小转大自动安全，大转小手动小心。除法要带小数，溢出记得绕圈！

🎮 趣味练习

练习1：火眼金睛 🔍

不看电脑，猜猜 (int)5.7 的结果是多少？

✅ 答案：5 —— 强制转换是直接砍掉小数，不是四舍五入哦！5.7 的小数部分被截断，剩下 5。

练习2：温度转换器 🌡️

华氏度转摄氏度，公式：C = (F - 32) × 5 ÷ 9

如果写成 (F-32)*5/9 会发生什么？应该怎么改？

✅ 提示：整数除法 5/9 = 0，会导致结果永远是 0！必须用 5.0/9 或 (double)5/9，让小数参与除法。

练习3：溢出的秘密 ❓

把 127 + 1 存入 char 类型变量，结果是多少？为什么？

✅ 答案：-128 —— char 的范围是 -128~127，127 再加 1 就超出了，数字在计算机里像钟表一样绕圈，从最大值跳到了最小值！

📝 本课小结

知识点内容
隐式类型转换小类型→大类型自动完成（安全），如 int→double
强制类型转换用 (int)x 或 static_cast<int>(x)，小数直接截断
整数除法的坑5/2=2（整数除法），5.0/2=2.5（浮点除法）
数据溢出超出类型范围时数值会"绕圈"，如 char: 127+1=-128
char 范围-128 ~ 127，只有 256 个数字，特别容易溢出
安全除法只要除号两边有一个是小数，结果就是小数

数字换装分两种，隐式自动显式手；
整数除法要小心，小数登场才不愁；
水杯有量别装满，溢出之后数字走！
