📖 核心知识：矩阵转置

什么是矩阵转置？

矩阵转置就是把矩阵的行和列互换。原矩阵中第 i 行第 j 列的元素，跑到转置矩阵的第 j 行第 i 列：

AT[i][j] = A[j][i]

原始矩阵（3×3） 转置矩阵（3×3）
1   2   3
4   5   6
7   8   9 		1   4   7
2   5   8
3   6   9

第1行 {1,2,3} → 第1列 {1,2,3}

// 方阵原地转置的核心代码 for (int i = 0; i < n; i++) { for (int j = i + 1; j < n; j++) { int temp = a[i][j]; a[i][j] = a[j][i]; a[j][i] = temp; } } // 关键：j从i+1开始，只交换上三角部分！
对角线知识：
• 主对角线：满足 i == j 的位置，转置时位置不变！
• 副对角线：满足 i + j == n - 1 的位置
• 对称矩阵：AT == A，即 a[i][j] == a[j][i]
长方形矩阵转置：M×N 矩阵转置后变成 N×M 矩阵。不能原地转置，需要创建新数组：b[j][i] = a[i][j]
【讲解】📖 核心知识：矩阵转置 本页要点（照着讲即可）： · 矩阵转置就是把矩阵的 行和列互换 。原矩阵中第 i 行第 j 列的元素，跑到转置矩阵的第 j 行第 i 列： · 行和列互换 · A T [i][j] = A[j][i] · 第1行 {1,2,3} → 第1列 {1,2,3} · 对角线知识： · 主对角线 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

💻 代码示例：完整的矩阵转置程序

#include <iostream> #include <iomanip> using namespace std; int main() { const int N = 3; int a[N][N] = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}}; cout << "原始矩阵：" << endl; for (int i = 0; i < N; i++) { for (int j = 0; j < N; j++) { cout << setw(4) << a[i][j]; } cout << endl; } // 原地转置：只交换上三角 for (int i = 0; i < N; i++) { for (int j = i + 1; j < N; j++) { int temp = a[i][j]; a[i][j] = a[j][i]; a[j][i] = temp; } } cout << "转置后矩阵：" << endl; for (int i = 0; i < N; i++) { for (int j = 0; j < N; j++) { cout << setw(4) << a[i][j]; } cout << endl; } return 0; }

运行结果：第1行 {1,2,3} 变成第1列 {1,2,3}，主对角线 {1,5,9} 保持不动！

📝 本课小结

  • 矩阵转置：行和列互换，AT[i][j] = A[j][i]，就像矩阵"照镜子"
  • 方阵转置可原地进行，只需交换上三角和下三角的对称元素，j 从 i+1 开始避免重复
  • 长方形矩阵转置必须创建新数组，因为行列数不同，转置后维度互换
  • 主对角线（i==j）元素在转置中位置不变，是转置操作的"对称轴"
  • 对称矩阵满足 AT == A，即镜像位置的元素两两相等
  • 矩阵转置是图像旋转、数据变换等高级应用的基础操作，实用价值极高
