第20课：循环控制台——break与continue

循环控制 | 课时：45分钟

✨ 🕹️ 数字躲避游戏 ✨

想一想：如果你在循环中途想"退出"或"跳过"，该怎么办？

🎯 学习目标

  1. 掌握break跳出循环的用法
  2. 掌握continue跳过本次循环的用法
  3. 理解break和continue的区别，灵活运用
📌 游戏类比：break = 退出键(ESC)，continue = 跳过键(Skip)
语句作用类比口诀
break终止整个循环紧急出口一刀两断
continue跳过本次迭代跳过按钮只跳一段

📖 核心知识

break —— 循环的"紧急出口"

for (int i = 1; i <= 10; i++) { if (i == 5) break; // 到5立刻跳出！ cout << i << " "; } // 输出：1 2 3 4（5及以后全部消失）

continue —— 循环的"跳过按钮"

for (int i = 1; i <= 10; i++) { if (i == 5) continue; // 只跳过5 cout << i << " "; } // 输出：1 2 3 4 6 7 8 9 10（只有5被跳过）

⚠️ 重要警告

在while循环中使用continue要小心！

如果continue跳过了变量更新语句，可能导致死循环！

而for循环中continue后会自动执行更新语句，相对安全。

💻 示例代码

🕹️ 数字躲避游戏（continue应用）

for (int i = 1; i <= 30; i++) { // 遇到3的倍数、个位是3、十位是3就跳过 if (i % 3 == 0 || i % 10 == 3 || i / 10 == 3) { cout << "💨 跳过！" << endl; continue; // 跳过危险数字 } cout << "🔢 " << i << endl; }

🔍 质数查找（break应用）

for (int num = 2; num <= 100; num++) { bool isPrime = true; for (int i = 2; i <= sqrt(num); i++) { if (num % i == 0) { isPrime = false; break; // 找到因子就停止检查 } } if (isPrime) cout << num << " "; }

🎮 趣味练习

练习1：跳过3的倍数 ⭐

打印1到30，跳过所有3的倍数（使用continue）。

练习2：找到第一个公倍数 ⭐⭐

在1-100中找第一个既能被7又能被5整除的数（使用break）。

答案：35（因为35÷7=5，35÷5=7）

练习3：数字过滤器 ⭐⭐

输入10个整数，只显示偶数。遇到0时用break终止。

🏆 挑战任务：猜数字豪华版
7次机会猜1-100的数字。用break提前结束，用continue跳过无效输入（不耗次数）。

📝 本课小结

语句作用典型场景
break立即终止整个循环提前结束查找、退出菜单
continue跳过本次剩余代码数据过滤、跳过无效值
记口诀："break一刀两断，continue只跳一段！"
⚠️ 注意：break只影响当前层循环，不影响外层。while中用continue要确保更新语句不被跳过！
