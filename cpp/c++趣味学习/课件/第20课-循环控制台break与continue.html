📖 核心知识

break —— 循环的"紧急出口"

for (int i = 1; i <= 10; i++) { if (i == 5) break; // 到5立刻跳出！ cout << i << " "; } // 输出：1 2 3 4（5及以后全部消失）

continue —— 循环的"跳过按钮"

for (int i = 1; i <= 10; i++) { if (i == 5) continue; // 只跳过5 cout << i << " "; } // 输出：1 2 3 4 6 7 8 9 10（只有5被跳过）

⚠️ 重要警告

在while循环中使用continue要小心！

如果continue跳过了变量更新语句，可能导致死循环！

而for循环中continue后会自动执行更新语句，相对安全。

【讲解】📖 核心知识 本页要点（照着讲即可）： · 在 while循环 中使用continue要小心！ · while循环 · 如果continue跳过了变量更新语句，可能导致 死循环 ！ · 而 for循环 中continue后会自动执行更新语句，相对安全。 · for循环 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 本课小结

语句作用典型场景
break立即终止整个循环提前结束查找、退出菜单
continue跳过本次剩余代码数据过滤、跳过无效值
记口诀："break一刀两断，continue只跳一段！"
⚠️ 注意：break只影响当前层循环，不影响外层。while中用continue要确保更新语句不被跳过！
