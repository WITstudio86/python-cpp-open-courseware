📖 核心知识：编程是什么？

🤖 编程 = 给电脑写说明书

想象你有一个超级听话的机器人，但它只懂一种特殊的语言。你想让它帮你做事，就必须把每一步都写得清清楚楚。这就是编程！

🐣 C++ 小档案

项目详情
创造者Bjarne Stroustrup（比雅尼·斯特劳斯特鲁普）
出生年份1979年开始设计，1985年正式发布
年龄40多岁！比你爸爸妈妈可能还大
特长速度快、功能强、哪里都能用
用在哪游戏引擎、操作系统、浏览器…
🔑 口诀：写代码 → 编译 → 运行 → 看结果！

💻 你的第一个C++程序

// 你的第一个C++程序 —— Hello World! #include <iostream> using namespace std; int main() { // cout 就是电脑的"嘴巴"，让它说话 cout << "Hello, World!" << endl; // endl 表示"换行"，像按回车键 return 0; // 告诉电脑：程序结束了 }

运行结果：

Hello, World!

试试多说几句：

cout << "你好，我是C++！" << endl; cout << "很高兴认识你！" << endl; cout << "1 + 1 = " << 1 + 1 << endl;

发现了没？cout不仅能输出文字，还能做数学计算！

🎮 趣味练习

cout << "我爱编程" << endl cout << "编程使我快乐" << endl;

提示：仔细看第一行末尾少了什么？

练习2：创作自我介绍 ✍️

写一个程序输出你的自我介绍：名字、年龄、爱好……

练习3：字符画艺术家 🎨

用cout画一个简单的图案，比如笑脸 ^_^

✅ 练习1答案：第一行末尾少了分号（;）！每一句cout后面都要加分号哦。
