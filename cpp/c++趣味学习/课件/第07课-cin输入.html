  • 能够编写交互式程序：让电脑和用户"对话"
  • 制作一个智能问答机器人
💡 cout vs cin：
cout = 电脑的嘴巴（输出，说话）
cin = 电脑的耳朵（输入，听话）
注意箭头方向：cout <<，cin >> —— 方向相反！

📖 cin 核心用法

基本语法

int age; cout << "请输入年龄："; // 提示 cin >> age; // 等待输入并存入age cout << "你" << age << "岁"; // 使用输入的值

cout 和 cin 对比

coutcin
全称character outputcharacter input
方向电脑 → 屏幕键盘 → 电脑
运算符<<>>
比喻嘴巴（说话）耳朵（听话）
后面跟要输出的内容要存入的变量

链式输入

int a, b; cin >> a >> b; // 一次输入两个数（空格分隔）
⚠️ 注意：cin 遇到空格就停止读取字符串！
输入"Xiao Ming" → 只读到"Xiao"

💻 交互式程序示例

简易计算器

int num1, num2; cout << "输入第一个数："; cin >> num1; cout << "输入第二个数："; cin >> num2; cout << num1 << "+" << num2 << "=" << num1 + num2;

猜数字游戏

int secret = 7, guess; cout << "猜一个1-10的数："; cin >> guess; if (guess == secret) cout << "猜对了！🎉"; else cout << "答案是" << secret;

个人信息收集

string name; int age; string hobby; cout << "姓名："; cin >> name; cout << "年龄："; cin >> age; cout << "爱好："; cin >> hobby; cout << name << "," << age << "岁,喜欢" << hobby;

📝 本课小结

知识点说明
cin电脑的"耳朵"，接收键盘输入
cin >>输入运算符，数据流入变量
交互式程序程序能接收用户输入并回应
提示信息cin之前用cout提示输入什么
链式输入cin >> a >> b; 一次多值
cin小脾气遇空格停止（用getline读整行）
🔑 记住口诀：
cout说话cin听话，箭头方向反着画；
cin后面跟变量，用户输入全靠它！
