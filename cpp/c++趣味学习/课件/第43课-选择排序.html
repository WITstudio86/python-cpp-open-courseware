📖 什么是选择排序？

选择排序的核心：数组分成"已排序区"和"未排序区"，每轮从未排序区中选出最小的元素，放到已排序区的末尾。

算法步骤（从小到大）

第①步：从 arr[0] 到 arr[n-1] 中，找到最小元素的下标 minIndex
第②步：将 arr[minIndex] 与 arr[0] 交换 —— 第 1 个位置排好了！
第③步：从 arr[1] 到 arr[n-1] 中，再找最小元素的下标
第④步：将 arr[minIndex] 与 arr[1] 交换 —— 第 2 个位置排好了！
重复以上……直到第 n-1 个位置也排好。最后一个元素自动归位！

与冒泡排序的区别

比较维度冒泡排序 🫧选择排序 ⚡
核心操作相邻元素两两比较并交换先找最值，再一次性交换
每轮交换次数可能很多次最多 1 次
总交换次数最多约 n²/2 次最多 n-1 次
比喻像气泡慢慢冒上来像快刀一下子切到位
🔑 关键技巧：记录最小值的下标
在内层循环中，我们不直接交换，而是用一个变量 minIndex 记录当前找到的最小值的下标。等内层循环结束后，再把 arr[i] 和 arr[minIndex] 交换。
这样做的好处是：每轮只做 1 次交换，效率最高！

💻 选择排序代码（从小到大）

// 选择排序：从小到大排列 #include <iostream> using namespace std; int main() { int arr[] = {64, 25, 12, 22, 11}; int n = 5; // 外层循环：控制已排序区边界，只需 n-1 轮 for (int i = 0; i < n - 1; i++) { int minIndex = i; // 假设第 i 个最小 // 内层循环：在未排序区中找真正的最小值 for (int j = i + 1; j < n; j++) { if (arr[j] < arr[minIndex]) { minIndex = j; // 更新最小下标 } } // 将最小值交换到已经排序区的末尾 if (minIndex != i) { int temp = arr[i]; arr[i] = arr[minIndex]; arr[minIndex] = temp; } } // 输出结果 cout << "排序结果："; for (int i = 0; i < n; i++) { cout << arr[i] << " "; } // 输出：11 12 22 25 64 return 0; }

⚡ 从大到小排列——只需改一个符号！

// 把内层 if 中的 < 改成 > 即可！ for (int i = 0; i < n - 1; i++) { int maxIndex = i; for (int j = i + 1; j < n; j++) { if (arr[j] > arr[maxIndex]) { // ← 这里改成了 > maxIndex = j; } } if (maxIndex != i) { swap(arr[i], arr[maxIndex]); } }
✅ 记忆口诀：
外层轮次 i 开路，内层遍历找最小；
minIndex 记位置，一轮只换一次位！

练习2：代码找茬 🐛

下面这段选择排序代码有一个错误，你能找到吗？

for (int i = 0; i < n; i++) { // ← 这里有问题！ int minIndex = i; for (int j = i + 1; j < n; j++) { if (arr[j] < arr[minIndex]) minIndex = j; } int temp = arr[i]; arr[i] = arr[minIndex]; arr[minIndex] = temp; }
🐛 错误：外层循环应该写 i < n - 1，而不是 i < n。
因为当 i = n-1 时，只剩下最后一个元素，它自然已经在正确位置了！写成 i < n 会让程序多做一轮无用的循环。

📝 本课小结

  • 核心思想：每轮"找最值 → 交换归位"，像挑苹果一样从小到大排列
  • 代码结构：外层循环控制轮次（n-1轮），内层循环找最值下标（从 i+1 开始）
  • 关键技巧：用 minIndex 记录最小值的下标，循环结束后再交换——每轮最多只交换 1 次
  • 与冒泡排序的区别：冒泡排序每轮可能交换多次，选择排序每轮最多只交换 1 次，所以选择排序的交换次数更少
  • 方向切换：从小到大用 arr[j] < arr[minIndex]，从大到小用 arr[j] > arr[maxIndex]
🔑 记住口诀：
选择排序快刀斩，每轮挑出最值来；
下标先记不着急，一轮一次交换好；
冒泡慢慢往上冒，选择一刀切到位；
n减一轮就排好，从小到大真巧妙！
