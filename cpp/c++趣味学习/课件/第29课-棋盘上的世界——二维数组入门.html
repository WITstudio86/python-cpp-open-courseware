📖 核心知识：二维数组

🧩 声明与初始化

// 声明格式：类型 数组名[行数][列数]; int grid[3][4] = { // 3行4列的整数数组 {1, 2, 3, 4}, // 第0行 {5, 6, 7, 8}, // 第1行 {9, 10, 11, 12} // 第2行 };

📍 下标访问

grid[0][0] → 1 (第0行, 第0列) grid[1][2] → 7 (第1行, 第2列) grid[2][3] → 12 (第2行, 第3列) // 修改元素 grid[1][1] = 100; // 把第1行第1列改成100

🔑 核心规则：行和列的下标都从0开始！grid[第几行][第几列]。
棋盘规律：(行+列) % 2 可以产生交替的0和1！

💻 代码示例：打造数字棋盘

#include <iostream> using namespace std; int main() { int board[8][8]; // 8×8棋盘 // 填充棋盘：交替填0和1 for (int i = 0; i < 8; i++) { for (int j = 0; j < 8; j++) { board[i][j] = (i + j) % 2; // 行+列为偶数→0(白), 奇数→1(黑) } } // 图形化显示 for (int i = 0; i < 8; i++) { for (int j = 0; j < 8; j++) { if (board[i][j] == 0) cout << "■ "; else cout << "□ "; } cout << endl; } return 0; }

运行效果：一个8行8列的交替黑白方块棋盘！

🔍 核心技巧：(i + j) % 2 判断格子颜色。观察规律——相邻格子的行+列奇偶性必然相反！

📝 本课小结

知识点内容
二维数组概念按行和列组织数据，像表格/棋盘/座位表
声明方式类型 数组名[行数][列数]; — 先行后列
下标规则行和列都从0开始：数组[行下标][列下标]
初始化嵌套花括号：{{行1}, {行2}, ...}
棋盘规律(行+列) % 2 产生交替的0和1
🔑 记住口诀：
一维变成线，二维变成面。
先行后列记心间，两个下标定一点。
棋盘座位都可以，二维数组是真便！
