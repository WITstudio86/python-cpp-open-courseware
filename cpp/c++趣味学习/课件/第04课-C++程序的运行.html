💡 Bug的故事：
1947年，一只真的飞蛾飞进了电脑，导致故障。从此程序错误就叫"Bug"，找错误就叫"Debug"！

📖 从代码到程序：神奇的旅程

📝 源代码（.cpp文件） — 你写的代码
⬇️
🔧 编译器 — "翻译官"翻译成机器语言
⬇️

⬇️
🔗 链接器 — 组装所有零件
⬇️

💻 常见编译错误速查表

错误症状编译报错解决方法
忘记分号expected ';'在语句末尾加 ;
拼写错误'xxx' was not declared检查拼写！
变量未定义undeclared identifier先定义，再使用
缺少引号各种奇怪报错字符串加 " "
少花括号expected '}'检查 { } 是否配对
忘头文件cout was not declared加 #include <iostream>

调试五步法

  1. 读错误信息 — 编译器说了什么？
  2. 定位问题 — 哪一行出错了？
  3. 分析原因 — 为什么会出错？
  4. 修改代码 — 改正它！
  5. 重新编译 — 修好了吗？

🎮 趣味练习

练习1：Bug侦探 🔍

下面的程序有4个错误，找出来！

cout << "Bug侦探" << endl // Bug1 int score = 100 // Bug2 cout << score << end; // Bug3 retrun 0; // Bug4

练习2：编译器翻译官 🗣️

猜猜这些报错是什么意思：

  • expected ';' → 少了分号
  • 'cout' was not declared → 忘了头文件
  • expected '}' → 少了个花括号
✅ 练习1答案：
Bug1: 第1行少分号 | Bug2: 第2行少分号 | Bug3: end应该是endl | Bug4: retrun应该是return
