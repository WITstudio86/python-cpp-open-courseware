通过本课学习，你将能够：

  • 掌握 struct 的定义语法 —— 知道每一部分怎么写
  • 学会创建结构体变量，并用点运算符 . 访问成员

💡 想一想：假设要管理全班40个同学的姓名、年龄、语文、数学、英语成绩，没有结构体需要多少个变量？有了结构体又需要多少个？

答案：没有结构体 = 200个变量 😱 | 有了结构体 = 40个变量 😊

📖 核心知识

🔍 什么是结构体？

结构体就像一个超级名片 —— 它可以把不同类型的信息（姓名、年龄、成绩）打包在一起，用一个变量统一管理！

没有结构体 ❌有了结构体 ✅
信息分散在多个独立变量一个学生的信息打包在一个变量里
不容易看出数据之间的关联一眼看出哪些信息属于同一个人
修改和传递很麻烦只需传一个结构体变量

📝 定义语法

struct Student { // Student 是结构体名称（可自定义） string name; // 姓名 —— 字符串类型 int age; // 年龄 —— 整数类型 double score; // 成绩 —— 小数类型 }; // ⚠️ 注意：末尾必须加分号！

🔧 创建与使用

Student s1; // 创建一个学生变量（像 int a; 一样） s1.name = "小明"; // 用 . 给 name 赋值 s1.age = 12; // 用 . 给 age 赋值 s1.score = 95.5; // 用 . 给 score 赋值
💡 记忆口诀：点运算符 . 就像一把钥匙，打开结构体这个"百宝箱"，取出或放入数据！"变量名点成员名"
⚠️ 最易错点：结构体定义末尾的分号 ; 绝对不能忘！这是新手最容易犯的错误！

💻 示例代码 —— 学生信息卡

完整程序：创建学生、输出信息、修改成绩

#include <iostream> #include <string> using namespace std; // 定义学生结构体 struct Student { string name; // 姓名 int age; // 年龄 double score; // 成绩 }; int main() { // 花括号初始化 —— 按成员定义顺序 Student s1 = {"小明", 12, 95.5}; cout << "===== 学生信息卡 =====" << endl; cout << "姓名：" << s1.name << endl; cout << "年龄：" << s1.age << " 岁" << endl; cout << "成绩：" << s1.score << " 分" << endl; // 修改成绩：直接赋值即可 s1.score = 98.0; cout << "进步后成绩：" << s1.score << " 分" << endl; // 结构体赋值：整体复制 Student s2 = s1; s2.name = "小明副本"; cout << "原姓名：" << s1.name << endl; // 小明 cout << "副本姓名：" << s2.name << endl; // 小明副本 return 0; }

🏃 运行结果

===== 学生信息卡 ===== 姓名：小明 年龄：12 岁 成绩：95.5 分 进步后成绩：98 分 原姓名：小明 副本姓名：小明副本
💡 发现：修改 s2.name 不影响 s1.name！结构体赋值是值复制，就像复印了一张名片 —— 在复印件上写字不会影响原件。
