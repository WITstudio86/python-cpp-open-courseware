📖 核心知识

什么是while循环？

就像扫地机器人：只要电量充足（条件为真），就会一直转圈清扫（执行循环体），直到电量不足（条件为假）才停下来。

while循环三要素

1️⃣ 循环变量初始化——给循环变量一个初始值（跑步前站在起点）

2️⃣ 循环条件——决定是否继续的判断（还没到终点）

3️⃣ 循环变量更新——每次执行后改变变量（每跑一步离终点更近）

⚠️ 忘记更新 = 死循环！程序永远停不下来！

死循环——有用的"坏东西"

游戏主循环、ATM菜单——这些场景故意使用死循环，配合break在需要时跳出。

💻 示例代码

🚀 火箭发射倒计时器

int countdown = 10; cout << "🚀 火箭发射倒计时开始！" << endl; while (countdown > 0) { cout << countdown << "..." << endl; countdown--; // 每次减1，至关重要！ } cout << "🔥 发射！火箭升空！" << endl;

🎯 猜数字游戏

int secret = rand() % 100 + 1; // 1-100随机数 int guess = 0; while (guess != secret) { cout << "请输入你猜的数字："; cin >> guess; if (guess > secret) cout << "太大了！" << endl; else if (guess < secret) cout << "太小了！" << endl; } cout << "🎉 恭喜你猜对了！" << endl;

📝 本课小结

要点说明
语法格式while(条件){ 循环体 }
执行顺序先判断条件，再执行循环体
三要素初始化 → 条件 → 更新，缺一不可
死循环忘记更新变量导致，while(true)是故意死循环
适用场景不知道具体循环次数时，如猜数字、输入验证
记口诀："条件为真就转圈，千万别忘把数变！"
