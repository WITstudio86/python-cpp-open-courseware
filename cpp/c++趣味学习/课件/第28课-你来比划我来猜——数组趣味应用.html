📋 学习目标

  1. 理解数组作为计数器的原理——用下标表示种类，用值表示出现次数。
  2. 掌握频率统计的核心代码：count[数字]++。
  3. 了解标记数组的用法——记录"是否出现过"，用于去重和查重。
  4. 能够编写数字频率计数器、成绩分布统计等实用程序。
💡 趣味联想：数组计数就像运动会上的记分牌——每位选手（下标）都有一块独立的记分牌（值），得一分就翻一下！

🧠 核心知识

1. 数组作为计数器

核心思想：下标代表"种类"，值代表"出现次数"

int count[10] = {0}; // 10个计数器，全部归零 // 读到一个数字 num count[num]++; // 对应的计数器加1！ // 举例：读到数字5 count[5]++; // 数字5的计数器从0变成1 // 再读到数字5 count[5]++; // 数字5的计数器从1变成2

2. 逐位提取数字

int n = 35241; while (n > 0) { int digit = n % 10; // 取出最后一位：1, 4, 2, 5, 3 count[digit]++; n = n / 10; // 去掉最后一位 }

3. 标记数组去重

用 bool 数组记录每个数字是否已经出现过。第一次出现时输出并标记，再次出现时跳过。

💻 完整代码：数字频率计数器

#include <iostream> using namespace std; int main() { int digitCount[10] = {0}; // 统计0-9 long long n; cout << "请输入一个整数："; cin >> n; if (n < 0) n = -n; // 负数转正 // 逐位提取并计数 while (n > 0) { int digit = n % 10; // 取最后一位 digitCount[digit]++; // 对应计数器+1 n = n / 10; // 去掉最后一位 } // 输出结果 cout << "\n数字频率统计：" << endl; for (int i = 0; i < 10; i++) { cout << "数字 " << i << " 出现了 " << digitCount[i] << " 次 "; for (int j = 0; j < digitCount[i]; j++) cout << "█"; cout << endl; } return 0; }
⚡ 运行示例：输入 35241 → 数字1出现1次，2出现1次，3出现1次，4出现1次，5出现1次

✅ 本课小结

  • 数组不仅能存储数据，还能作为强大的计数工具。
  • 频率计数的核心代码：count[数字]++——简单一行，功能强大！
  • 标记数组用 true/false 记录"是否出现过"，常用于去重。
  • 计数数组使用前必须全部初始化为0，否则会出错。
  • 这种方法比定义大量独立变量更简洁、灵活。
  • 数组计数是"以空间换时间"的经典编程思想，广泛应用于成绩统计、投票系统、数据分析等领域！
