📖 核心知识
一、手势映射表
数字 手势名称 符号 说明
0 石头 ✊ 能砸坏剪刀
1 剪刀 ✌ 能剪开布
2 布 ✋ 能包住石头
💡 为什么用 0、1、2？ 使用连续的数字让我们可以利用数学关系来简化判断。
例如：(player + 1) % 3 == computer 时，玩家获胜！
二、胜负判断表
玩家 / 电脑 电脑出 0（石头✊） 电脑出 1（剪刀✌） 电脑出 2（布✋）
玩家出 0（石头✊） 平局 玩家赢 ✅ 电脑赢 ❌
玩家出 1（剪刀✌） 电脑赢 ❌ 平局 玩家赢 ✅
玩家出 2（布✋） 玩家赢 ✅ 电脑赢 ❌ 平局
三、三局两胜制计分规则
计分项 说明
初始分数 玩家和电脑各 0 分
每局胜者 得分 +1
平局 双方都不加分
胜利条件 先获得 2 分的一方获胜（最多 3 局）
可能比分 2:0（完胜）、2:1（决胜）、1:2（落败）、0:2（完败）
💻 示例代码
三局两胜制石头剪刀布完整程序
// 三局两胜制石头剪刀布
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));

    int playerScore = 0;
    int computerScore = 0;
    int round = 1;
    string g[] = {"石头", "剪刀", "布"};

    cout << "===== 石头剪刀布-三局两胜 =====\n";
    cout << "先赢两局者获胜！\n\n";

    while (playerScore < 2 && computerScore < 2) {
        cout << "--- 第 " << round << " 局 ---\n";
        cout << "比分: 你 " << playerScore << " - " << computerScore << " 电脑\n";

        int p, c;
        cout << "请出拳(0=石头,1=剪刀,2=布): ";
        cin >> p;

        // 输入验证
        if (p < 0 || p > 2) {
            cout << "输入无效! 请输入0/1/2\n";
            continue;
        }

        c = rand() % 3;  // 电脑随机出拳

        cout << "你:" << g[p] << "  电脑:" << g[c] << endl;

        if (p == c) {
            cout << "平局!\n";
        } else if ((p + 1) % 3 == c) {
            cout << "你赢了! +1分\n";
            playerScore++;
        } else {
            cout << "电脑赢了! +1分\n";
            computerScore++;
        }
        round++;
        cout << endl;
    }

    // 最终结果
    cout << "===== 最终结果 =====\n";
    cout << "比分: 你 " << playerScore
         << " - " << computerScore << " 电脑\n";
    if (playerScore > computerScore)
        cout << "恭喜你获得了最终胜利!\n";
    else if (computerScore > playerScore)
        cout << "电脑获胜,继续加油!\n";
    else
        cout << "平局收场!\n";

    return 0;
}
🔑 关键代码解读：
• (p + 1) % 3 == c —— 用一行公式判断玩家是否获胜！
• while 循环 —— 持续比赛直到有人赢得 2 分
• 输入验证 —— continue 跳过无效输入，让程序更健壮
🏆 趣味练习
✏️ 练习一：补全胜负条件

玩家出布（2），电脑出石头（0）。
补全下方横线处的判断条件，让程序输出 "玩家赢了！"： 

int player = 2, computer = 0;
if (                          ) {
    cout << "玩家赢了!" << endl;
}
💡 答案： player == 2 && computer == 0（布赢石头）
✏️ 练习二：三局两胜的逻辑分析

在"三局两胜"制中，最少需要打几局才能决出胜负？最多能打几局？

📝 答案：
• 最少 2 局：一方连赢两局（2:0），比赛结束
• 最多 3 局：双方各赢一局后（1:1），第三局决出胜负

📝 本课小结
回顾本节课的核心要点
🎲
随机数是模拟电脑出拳的核心
使用 srand(time(0)) 设置种子，rand() % 3 生成 0~2 的随机数来代表石头、剪刀、布。
🧠
胜负判断是游戏的灵魂
可以用 if-else 逐条件判断，也可以用 (p - c + 3) % 3 的数学关系来优雅实现。
📊
多轮计分需要循环和累加
通过 while 循环控制比赛轮次，用变量记录双方得分，每局结束后根据结果更新分数。
🏆
三局两胜的关键逻辑
循环继续条件是双方分数都小于 2，一旦有人先得 2 分则比赛结束。使用 break 可以提前退出循环。
💡
从简单到复杂逐步构建
先写单局对战 → 加上循环变成多局 → 加上计分变完整比赛 → 扩展手势、统计胜率等高级功能。这是非常好的编程思维训练过程！
