第18课：数数我最行——for循环

计数循环 | 课时：45分钟

✨ 🎰 制作乘法口诀表 ✨

想一想：如果你知道要做一件事情10次，你会怎么告诉计算机？

🎯 学习目标

  1. 掌握for循环三要素（初始化、条件、更新）
  2. 理解循环变量的作用域和生命周期
  3. 能够根据问题选择合适的循环结构
📌 核心问题：当你提前知道循环次数时，for循环就是最佳选择！
循环类型适用场景记忆口诀
for知道次数"做N次"
while不知道次数"做到...为止"
do-while至少做一次"先做再说"

📖 核心知识

for循环的三要素

for (初始化; 条件; 更新) { // 循环体 } // 例子：跑步5圈 for (int lap = 1; lap <= 5; lap++) { cout << "正在跑第" << lap << "圈！" << endl; }

执行顺序（重要！）

第1步：初始化（只执行一次）

第2步：检查条件 → 为真则执行循环体 → 更新 → 回到第2步

⚠️ 更新语句在循环体执行完毕之后才执行！

循环变量的作用域

for中定义的变量只在循环内部有效，循环结束后就"消失"了。如需在外部使用，请在循环前定义。

💻 示例代码

📐 九九乘法口诀表

for (int i = 1; i <= 9; i++) { for (int j = 1; j <= i; j++) { cout << j << "×" << i << "=" << i * j << " "; } cout << endl; }

📊 分数统计器

double total = 0, maxScore = 0, minScore = 100; for (int i = 1; i <= count; i++) { cout << "请输入第" << i << "位同学的成绩："; cin >> score; total += score; if (score > maxScore) maxScore = score; if (score < minScore) minScore = score; } cout << "平均分：" << total / count << endl;

🎮 趣味练习

练习1：偶数特工 ⭐

使用for循环打印1到100之间的所有偶数。

练习2：阶乘计算器 ⭐⭐

输入n（n≤12），计算n! = 1×2×3×...×n。如5! = 120

练习3：自定义乘法表 ⭐⭐

输入一个数字n，输出1×n到9×n的结果。

🏆 挑战任务：斐波那契数列
输出斐波那契数列前20项：1, 1, 2, 3, 5, 8, 13...（每一项=前两项之和）

📝 本课小结

要点说明
语法for(初始化;条件;更新){循环体}
三要素初始化、条件、更新集中在括号中
执行顺序初始化→条件→循环体→更新→条件→...
作用域for中定义的变量只在循环内有效
何时用知道循环次数时优先用for
记口诀："三要素放括号，知道次数用for！"
