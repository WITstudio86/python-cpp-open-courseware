💡 先想一想：
如果让你在 1~100 之间猜一个数字，对方只告诉你"大了"或"小了"，你用什么样的策略最快？一个一个猜？还是另有妙招？

📖 核心知识

🎲 随机数生成

// 1. 设置随机种子（只需一次！） srand(time(0)); // 2. 生成指定范围的随机数 // 公式：rand() % (max - min + 1) + min int secret = rand() % 100 + 1; // 1~100

公式记忆：`rand() % N + 1` 生成 1~N 的随机数，比如 `rand() % 50 + 1` 生成 1~50。

🔍 二分查找思想（演示：目标数字 73）

第1次：范围 [1, 100]，猜 50 → 小了 → 排除 1~50
第2次：范围 [51, 100]，猜 75 → 大了 → 排除 76~100
第3次：范围 [51, 74]，猜 62 → 小了 → 排除 51~62
第4次：范围 [63, 74]，猜 68 → 小了 → 排除 63~68
第5次：范围 [69, 74]，猜 71 → 小了 → 排除 69~71
第6次：范围 [72, 74]，猜 73 → 🎉 猜中了！

💻 示例代码：猜数字游戏

// ===== 猜数字游戏（电脑出题，玩家猜）===== #include <iostream> #include <cstdlib> #include <ctime> using namespace std; int main() { srand(time(0)); // 设置随机种子 int secret = rand() % 100 + 1; // 1~100 随机数 int guess, count = 0; cout << "猜 1~100 的数字：" << endl; do { cout << "请输入："; cin >> guess; count++; if (guess > secret) { cout << "太大了！" << endl; } else if (guess < secret) { cout << "太小了！" << endl; } else { cout << "猜对了！答案：" << secret << endl; cout << "你猜了 " << count << " 次" << endl; } } while (guess != secret); return 0; }

🎮 升级版：电脑用二分法猜你的数字

// 核心：二分查找策略 int low = 1, high = 100; // 范围上下界 while (low <= high) { int mid = (low + high) / 2; // 猜中间值 cout << "电脑猜：" << mid << endl; char feedback; cin >> feedback; if (feedback == 'y') break; // 对了 else if (feedback == 'd') high = mid - 1; // 大了 else low = mid + 1; // 小了 }

二分查找的核心就是：每次猜中间值，根据反馈调整范围！

🎮 趣味练习

练习1：修改随机数范围 📝

将猜数字游戏的范围改为 1~50，如何修改代码？

提示：修改 `rand() % 100 + 1` 中的数字

答案：`rand() % 50 + 1`

练习2：找bug 🔍

下面的代码有什么问题？

if (guess = secret) { cout << "猜对了！" << endl; }

答案：`=` 是赋值，`==` 才是比较！这里会把 `guess` 变成 `secret` 的值，条件永远为真。

🏆 挑战任务：电脑猜你的数字

你在心里想一个 1~100 的数字，让电脑用二分法来猜。电脑每次猜一个数，你告诉它"大了""小了"还是"对了"。要求电脑每次猜中间值，并显示范围缩小过程。

💡 提示：用 `low` 和 `high` 记录范围，`mid = (low + high) / 2` 是中间值。如果反馈"大了"，`high = mid - 1`；"小了"，`low = mid + 1`。
