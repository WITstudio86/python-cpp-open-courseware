第12课：逻辑大侦探——逻辑运算符

第二单元：运算小当家 | 课时：45分钟

🔎 破译逻辑密码

&& 逻辑与 || 逻辑或 ! 逻辑非 真值表

🎯 学习目标

  • 掌握三种逻辑运算符：与（&&）、或（||）、非（!）
  • 理解真值表并能判断逻辑表达式的结果
  • 能够用逻辑运算符组合多个条件做复杂判断
💡 先想一想：
你生活中做过"既要...又要..."或者"要么...要么..."的选择吗？比如：周末到了而且作业写完了并且天气好，才能出去玩。这就是逻辑！
🔗 和上节课的联系：
比较运算符 + 逻辑运算符 = 黄金搭档！比如：x >= 10 && x <= 20 判断x是否在区间内。

📖 核心知识：三位逻辑大侦探

🔍 侦探1号：&&（与）——"两边都对才行"

就像进游乐园：既要买票 又要身高够 → 两个都满足才能进！

条件A条件BA && B解读
truetruetrue ✓两个都对
truefalsefalse ✗一对 一错
falsetruefalse ✗一错 一对
falsefalsefalse ✗两个都错

口诀：全真才真，一假全假！

🔍 侦探2号：||（或）——"一个对就行"

周末活动：可以看电视 或者出去玩 → 有一个就行！

条件A条件BA || B解读
truetruetrue ✓两个都对
truefalsetrue ✓一对 一错
falsetruetrue ✓一错 一对
falsefalsefalse ✗两个都错

口诀：一真全真，全假才假！

🔍 侦探3号：!（非）——"说反话"

条件A!A解读
truefalse真的反义词是假
falsetrue假的反义词是真

口诀：真变假，假变真！

💻 示例代码

🕵️ 逻辑大侦探综合案例

// 示例1：&& —— 游乐园入园检查 bool hasTicket = true; int height = 130; if (hasTicket && height >= 120) { cout << "欢迎进入游乐园！"; } // 示例2：|| —— 周末活动选择 bool watchTV = true, playOutside = false; if (watchTV || playOutside) { cout << "周末有事做！"; } // 示例3：! —— 说反话 bool isRaining = false; if (!isRaining) { cout << "没下雨，可以出去！"; }

🌟 黄金搭档：比较 + 逻辑

int score; cin >> score; // 判断成绩是否在良好区间 [80, 90) if (score >= 80 && score < 90) { cout << "成绩良好！"; } // 判断是否在区间外 if (score < 60 || score > 100) { cout << "分数异常！"; }
💡 短路求值（聪明的大侦探）：
false && ??? → 左边是false，右边不用看，结果肯定是false！
true || ??? → 左边是true，右边不用看，结果肯定是true！

判断下列表达式的真假：

练习2：游乐园入园条件 🎢

练习3：区间判断 📏

判断一个数是否在10到20之间（包含边界）。

if (num >= 10 && num <= 20) { cout << "在区间内！"; }

🏆 挑战任务：闰年判断器 📅

输入一个年份，判断是否为闰年。

规则：（能被4整除 且 不能被100整除）或（能被400整除）

bool isLeap = (year%4==0 && year%100!=0) || (year%400==0);
💡 测试数据：2000→闰年 | 2004→闰年 | 1900→不是 | 2024→闰年 | 2023→不是

📝 本课小结

运算符名称含义口诀
&&逻辑与两个条件都满足才为真全真才真，一假全假
||逻辑或满足一个条件就为真一真全真，全假才假
!逻辑非把真变假，把假变真说反话，真假颠倒

优先级（从高到低）

! → 算术运算符 → 比较运算符 → && → ||

🔑 记住口诀：
与（&&）是同时都要有，或（||）是至少有一个，
非（!）是说反话颠倒走。
比较逻辑是搭档，复杂判断不用愁！
