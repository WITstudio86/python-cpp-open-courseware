📖 核心知识：三位逻辑大侦探

🔍 侦探1号：&&（与）——"两边都对才行"

就像进游乐园：既要买票 又要身高够 → 两个都满足才能进！

条件A条件BA && B解读
truetruetrue ✓两个都对
truefalsefalse ✗一对 一错
falsetruefalse ✗一错 一对
falsefalsefalse ✗两个都错

口诀：全真才真，一假全假！

💻 示例代码

🕵️ 逻辑大侦探综合案例

// 示例1：&& —— 游乐园入园检查 bool hasTicket = true; int height = 130; if (hasTicket && height >= 120) { cout << "欢迎进入游乐园！"; } // 示例2：|| —— 周末活动选择 bool watchTV = true, playOutside = false; if (watchTV || playOutside) { cout << "周末有事做！"; } // 示例3：! —— 说反话 bool isRaining = false; if (!isRaining) { cout << "没下雨，可以出去！"; }

🌟 黄金搭档：比较 + 逻辑

int score; cin >> score; // 判断成绩是否在良好区间 [80, 90) if (score >= 80 && score < 90) { cout << "成绩良好！"; } // 判断是否在区间外 if (score < 60 || score > 100) { cout << "分数异常！"; }
💡 短路求值（聪明的大侦探）：
false && ??? → 左边是false，右边不用看，结果肯定是false！
true || ??? → 左边是true，右边不用看，结果肯定是true！

📝 本课小结

运算符名称含义口诀
&&逻辑与两个条件都满足才为真全真才真，一假全假
||逻辑或满足一个条件就为真一真全真，全假才假
!逻辑非把真变假，把假变真说反话，真假颠倒

优先级（从高到低）

! → 算术运算符 → 比较运算符 → && → ||

🔑 记住口诀：
与（&&）是同时都要有，或（||）是至少有一个，
非（!）是说反话颠倒走。
比较逻辑是搭档，复杂判断不用愁！
