📖 核心知识

1. 题库结构体设计

struct Question { string question; // 题干 string options[4]; // 四个选项：A、B、C、D char answer; // 正确答案：'A'/'B'/'C'/'D' };

2. 结构体数组初始化

Question quiz[3] = { {"中国的首都是哪里？", {"A. 上海", "B. 北京", "C. 广州", "D. 深圳"}, 'B'}, {"1 + 1 等于几？", {"A. 1", "B. 2", "C. 3", "D. 4"}, 'B'}, {"太阳从哪个方向升起？", {"A. 东边", "B. 西边", "C. 南边", "D. 北边"}, 'A'} };

3. 随机不重复抽题

srand(time(0)); // 初始化随机种子 bool used[N] = {false}; // 标记数组 int idx; do { idx = rand() % N; } // 随机选一个下标 while (used[idx]); // 用过了就重选 used[idx] = true; // 标记为已使用

4. 答案验证与计分

char ans; cin >> ans; ans = toupper(ans); // 统一转大写 if (ans == quiz[idx].answer) { score += 10; // 答对加10分 correctCount++; // 正确计数+1 }
⚠️ 要点：答案字符用 toupper() 统一大小写，避免用户输入小写 a 被判错！
💡 扩展：可在结构体中添加 level（难度）和 explanation（解析）字段，实现分级题库和答题解析。

💻 示例代码 —— 知识问答竞赛

#include <iostream> #include <string> #include <cstdlib> #include <ctime> using namespace std; struct Question { string question; // 题干 string options[4]; // 选项 A/B/C/D char answer; // 正确答案 string explanation; // 解析 }; int main() { srand(time(0)); const int N = 5; Question quiz[N] = { {"中国的首都是？", {"A.上海","B.北京","C.广州","D.深圳"},'B', "北京是中国的首都。"}, {"最大海洋是？", {"A.大西洋","B.印度洋","C.太平洋","D.北冰洋"},'C', "太平洋约1.8亿km²。"}, {"平年有多少天？", {"A.360","B.365","C.366","D.350"},'B', "平年365天。"}, {"水的化学式？", {"A.CO₂","B.H₂O","C.O₂","D.NaCl"},'B', "水是H₂O。"}, {"《静夜思》作者？", {"A.杜甫","B.白居易","C.李白","D.王维"},'C', "李白：床前明月光。"} }; int score = 0, correct = 0; bool used[N] = {false}; // 随机不重复出题 for (int i = 0; i < N; i++) { int idx; do { idx = rand() % N; } while (used[idx]); used[idx] = true; cout << "\n第" << i+1 << "题: " << quiz[idx].question << endl; for (int j = 0; j < 4; j++) cout << " " << quiz[idx].options[j] << endl; char ans; cout << "你的答案(A/B/C/D): "; cin >> ans; ans = toupper(ans); if (ans == quiz[idx].answer) { cout << "✅ 正确！+10分" << endl; score += 10; correct++; } else { cout << "❌ 错误！答案是" << quiz[idx].answer << endl; } cout << "💡 " << quiz[idx].explanation << endl; } // 成绩统计 cout << "\n======== 成绩 ========" << endl; cout << "答对: " << correct << "/" << N << " 题" << endl; cout << "正确率: " << (double)correct/N*100 << "%" << endl; cout << "总分: " << score << " 分" << endl; return 0; }
💡 关键技巧：用 bool used[] 数组标记已出题目，确保每道题只出现一次！

🎮 趣味练习

练习1：判断题类型

以下哪个是正确的结构体数组初始化方式？

struct Quiz { string q; string opts[4]; char a; }; A. Quiz q1 = {"2+2=?", "A.3", "B.4", "C.5", "D.6", 'B'}; B. Quiz q1 = {"2+2=?", {"A.3","B.4","C.5","D.6"}, 'B'}; C. Quiz q1 = {"2+2=?", "A.3/B.4/C.5/D.6", 'B'};

答案：B —— 选项数组必须用内层花括号包裹。

📝 本课小结

知识点说明
题库结构体设计将题干、选项数组、答案用 struct 打包，一个数组管理全部题目
结构体数组初始化使用嵌套花括号 {{题},{选项},{答案}} 批量初始化
随机不重复出题srand(time(0)) + rand()%N + bool used[] 标记数组
答案验证toupper() 统一大小写后，与 quiz[i].answer 比较
计分统计维护 score 和 correctCount，最后计算正确率并分段评语
  • 结构体数组 = 结构体（打包不同数据）+ 数组（批量管理），威力翻倍！
  • 随机出题的关键：种子 + 取余 + 去重标记
