📚 核心知识

一、ASCII 码与大小写转换

字符类别ASCII 范围关键值
大写字母 A~Z65 ~ 90'A' = 65, 'Z' = 90
小写字母 a~z97 ~ 122'a' = 97, 'z' = 122
大小写差值'a' - 'A' = 32

两种转换方式：

  • 库函数：toupper(c) / tolower(c)（需 #include <cctype>）
  • 手动 ASCII：小写→大写：c - 32；大写→小写：c + 32

二、凯撒加密原理

把每个字母按字母表顺序向后移动固定位数（偏移量/密钥），非字母不变。

明文：A B C D E ... X Y Z ↓ ↓ ↓ ↓ ↓ ↓ ↓ ↓ 偏移量 = 3 密文：D E F G H ... A B C 示例："HELLO" → (shift=3) → "KHOOR" 示例："abc" → (shift=3) → "def" 示例："Z" → (shift=1) → "A" ← 循环！

解密就是反方向移动同样的位数。加密用 +shift，解密用 -shift（或 +26-shift）。

💻 凯撒加密完整代码

#include <iostream> #include <string> using namespace std; // 凯撒加密：对单个字符加密 char caesarEncrypt(char ch, int shift) { if (ch >= 'A' && ch <= 'Z') return (ch - 'A' + shift) % 26 + 'A'; else if (ch >= 'a' && ch <= 'z') return (ch - 'a' + shift) % 26 + 'a'; return ch; // 非字母不变 } // 凯撒解密：对单个字符解密 char caesarDecrypt(char ch, int shift) { if (ch >= 'A' && ch <= 'Z') return (ch - 'A' - shift + 26) % 26 + 'A'; else if (ch >= 'a' && ch <= 'z') return (ch - 'a' - shift + 26) % 26 + 'a'; return ch; } int main() { int shift; string msg; cout << "输入偏移量(1~25)："; cin >> shift; cin.ignore(); cout << "输入消息："; getline(cin, msg); // 加密 string enc = ""; for (int i = 0; i < msg.length(); i++) enc += caesarEncrypt(msg[i], shift); // 解密 string dec = ""; for (int i = 0; i < enc.length(); i++) dec += caesarDecrypt(enc[i], shift); cout << "密文：" << enc << endl; cout << "解密：" << dec << endl; cout << (msg == dec ? "✅ 成功" : "❌ 失败") << endl; return 0; }
🔑 代码要点：
① (ch - 'A' + shift) % 26 + 'A' 是加密核心
② 解密时 + 26 是为了避免负数取模的问题
③ 非字母字符（空格、数字、标点）原样保留
