第23课：对称之美——打印菱形与沙漏

对称图案 | 课时：45分钟

✨ 💎 闪闪钻石图案 ✨

想一想：剪纸时把纸对折再剪——这和编程打印对称图形有什么关系？

🎯 学习目标

  1. 掌握对称图形的"上半+下半"拆分策略
  2. 能够编程打印菱形、沙漏等经典对称图案
  3. 理解空心图形的打印技巧
📌 核心思路：把复杂图形拆成两个简单的三角形——"分而治之"！
图形上半下半
💎 菱形正三角形(1→n)倒三角形(n-1→1)
⏳ 沙漏倒三角形(n→1)正三角形(2→n)

📖 核心知识

菱形 = 正三角 + 倒三角

*　　　上半：正三角形 1→4 *** ***** ******* *****　　下半：倒三角形 3→1 *** *

上下部分的公式完全相同！

上半部分（i从1到n）：空格=n-i，星号=2i-1

下半部分（i从n-1到1）：空格=n-i，星号=2i-1

→ 公式不变，只需改变i的取值方向！

空心图形的技巧

每行只在第一个和最后一个位置打印星号，中间用空格填充。

条件：j==1 || j==2*i-1 时打印星号，否则打印空格。

💻 示例代码

💎 闪闪钻石（完整代码）

int n = 4; // 上半：正三角形 1→n for (int i = 1; i <= n; i++) { for (int j = 1; j <= n - i; j++) cout << " "; for (int j = 1; j <= 2 * i - 1; j++) cout << "*"; cout << endl; } // 下半：倒三角形 n-1→1 for (int i = n - 1; i >= 1; i--) { for (int j = 1; j <= n - i; j++) cout << " "; for (int j = 1; j <= 2 * i - 1; j++) cout << "*"; cout << endl; }

⏳ 时光沙漏

// 上半：倒三角形 n→1 for (int i = n; i >= 1; i--) { /* ... */ } // 下半：正三角形 2→n for (int i = 2; i <= n; i++) { /* ... */ }

🎮 趣味练习

练习1：蝴蝶翅膀 ⭐⭐

打印两个相对的直角三角形：左翅膀递增星号，中间空格递减。

* * ** ** *** *** **** **** **********

练习2：数字菱形 ⭐⭐

用回文数字填充菱形，如：1, 121, 12321, 1234321...

练习3：自定义字符菱形 ⭐

让用户选择填充字符（如@、#、$），打印该字符的菱形。

🏆 挑战任务：空心菱形
打印空心菱形——只有边框有星号，中间是空的。需要精确判断每行的左星号和右星号位置。

📝 本课小结

要点说明
核心思想"分而治之"——拆成上下两半
菱形上半正三角 + 下半倒三角（总行数2n-1）
沙漏上半倒三角 + 下半正三角
公式复用上下部分公式完全相同，只改变i方向
空心只在每行首尾打印，中间填空格
记口诀："复杂图形分两半，上下公式都一样。递增递减换方向，空心记得判位置！"
