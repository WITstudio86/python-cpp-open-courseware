📖 核心知识

菱形 = 正三角 + 倒三角

*　　　上半：正三角形 1→4 *** ***** ******* *****　　下半：倒三角形 3→1 *** *

上下部分的公式完全相同！

上半部分（i从1到n）：空格=n-i，星号=2i-1

下半部分（i从n-1到1）：空格=n-i，星号=2i-1

→ 公式不变，只需改变i的取值方向！

空心图形的技巧

每行只在第一个和最后一个位置打印星号，中间用空格填充。

条件：j==1 || j==2*i-1 时打印星号，否则打印空格。

【讲解】📖 核心知识 本页要点（照着讲即可）： · 上半部分（i从1到n）：空格=n-i，星号=2i-1 · 下半部分（i从n-1到1）：空格=n-i，星号=2i-1 · → 公式不变，只需改变i的取值方向！ · 每行只在 第一个 和 最后一个 位置打印星号，中间用空格填充。 · 最后一个 · 条件： j==1 || j==2*i-1 时打印星号，否则打印空格。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

💻 示例代码

💎 闪闪钻石（完整代码）

int n = 4; // 上半：正三角形 1→n for (int i = 1; i <= n; i++) { for (int j = 1; j <= n - i; j++) cout << " "; for (int j = 1; j <= 2 * i - 1; j++) cout << "*"; cout << endl; } // 下半：倒三角形 n-1→1 for (int i = n - 1; i >= 1; i--) { for (int j = 1; j <= n - i; j++) cout << " "; for (int j = 1; j <= 2 * i - 1; j++) cout << "*"; cout << endl; }

要点说明
核心思想"分而治之"——拆成上下两半
