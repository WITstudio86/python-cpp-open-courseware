第22课：图形魔法师——打印三角形

图案打印 | 课时：45分钟

✨ 🔺 绘制三角形图案 ✨

想一想：如何让星号从少到多，形成一个漂亮的三角形？

🎯 学习目标

  1. 使用嵌套循环打印各种三角形图案
  2. 掌握空格和星号在三角形中的数量关系
  3. 理解行号、空格数、星号数之间的数学公式
📌 核心公式：等腰三角形第i行 → 空格=n-i个，星号=2i-1个
三角形类型空格数内容数
左下直角0i
右下直角n-ii
等腰三角n-i2i-1

📖 核心知识

规律观察

*　　　　　第1行：1个星号 * *　　　　第2行：2个星号 * * *　　　第3行：3个星号 * * * *　　第4行：4个星号

→ 第i行有i个星号，内层循环上限 = i

等腰三角形分析（n=5）

行号i空格 n-i星号 2i-1
141
233

星号数 = 奇数序列：1, 3, 5, 7, 9...

三步设计法

1. 确定行数n → 2. 找出每行的空格和内容规律 → 3. 转化为循环代码

💻 示例代码

左下角直角三角形

for (int i = 1; i <= 5; i++) { for (int j = 1; j <= i; j++) { cout << "* "; } cout << endl; }

等腰三角形（金字塔）

int n = 5; for (int i = 1; i <= n; i++) { for (int j = 1; j <= n - i; j++) cout << " "; // 空格 for (int j = 1; j <= 2 * i - 1; j++) cout << "*"; // 星号 cout << endl; } // 输出： // * // *** // ***** // ******* // *********

🎮 趣味练习

练习1：右下角倒直角三角形 ⭐

打印一个星号从5递减到1的右下角对齐三角形。

练习2：字母三角形 ⭐⭐

用字母A-Z打印左下角三角形。第1行A，第2行AB，第5行ABCDE。

练习3：空心等腰三角形 ⭐⭐⭐

打印5层空心等腰三角形——只有边框有星号，中间是空的。

🏆 挑战任务：弗洛伊德三角形
用连续自然数填充的三角形：第1行1，第2行2,3，第3行4,5,6...输出前8行。

📝 本课小结

要点说明
核心思路找到行号与打印数量的数学关系
左下直角第i行打i个，最简单
等腰三角空格n-i个，星号2i-1个
右边对齐内容前加n-i个空格
倒三角外循环从n递减到1
记口诀："第i行打i个是直角，再加空格靠右站。2i-1是等腰，空格放在星号前！"
