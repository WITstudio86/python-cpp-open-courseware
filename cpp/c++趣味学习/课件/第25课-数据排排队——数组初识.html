📖 核心知识

【数组就像数据的"小火车"】

数组是一组相同类型数据的集合，每个数据在数组中有一个固定的位置——就像同学们排队时每个人都有自己固定的位置一样！

数组的声明

数据类型 数组名[元素个数]; // 例如： int scores[40]; // 存储40个成绩 string names[30]; // 存储30个名字 float heights[50]; // 存储50个身高

数组的初始化

int numbers[5] = {10, 20, 30, 40, 50}; // 也可以只初始化部分元素 int nums[5] = {1, 2}; // 剩余自动为0

下标访问规则

重要：下标从 0 开始！

第一个元素的位置是 0，第二个是 1，第三个是 2……

int arr[5] = {10, 20, 30, 40, 50}; cout << arr[0]; // 输出 10（第1个） cout << arr[1]; // 输出 20（第2个） cout << arr[2]; // 输出 30（第3个） cout << arr[3]; // 输出 40（第4个） cout << arr[4]; // 输出 50（第5个）
⚠️ 注意：下标范围是 0 到 n-1（n 为数组大小）。访问 arr[5] 会导致数组越界错误！
💡 小技巧：第 i 个元素的下标是 i-1。最后一个元素的下标 = 数组大小 - 1。

📝 本课小结

  • 数组是一组相同类型数据的集合，就像排队的队伍
  • 声明格式：类型 数组名[大小];
  • 数组下标从0开始，最后一个元素下标是"大小-1"
  • 初始化可以用花括号：{值1, 值2, ...}
  • 通过数组名[下标]来访问和修改元素
  • 配合循环可以高效地处理大量数据
