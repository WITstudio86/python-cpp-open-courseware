⚖️ 条件表达式 & 比较运算符

if的条件必须是一个能判断真假的表达式。在C++中，我们用比较运算符来构造条件：

运算符含义示例结果
>大于10 > 5true ✓
<小于3 < 8true ✓
>=大于等于60 >= 60true ✓
<=小于等于30 <= 15false ✗
==等于5 == 5true ✓
!=不等于7 != 3true ✓
⚠️ 特别注意：
==（两个等号）是 判断相等
=（一个等号）是 赋值
这是新手最容易犯的错误！
❌ if (x = 5) —— 这是赋值，不是判断！
✅ if (x == 5) —— 这才是判断x是否等于5
【讲解】⚖️ 条件表达式 & 比较运算符 结合讲义《比较运算符》强调： · 写条件时常用的比较运算符： · 特别注意：判断"等于"用的是两个等号 ==，一个等号 = 是赋值！这是新手最容易搞混的地方。 幻灯片上可见要点： · if的条件必须是一个 能判断真假 的表达式。在C++中，我们用 比较运算符 来构造条件： · 能判断真假 · 比较运算符 · ⚠️ 特别注意： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📦 代码块 { } —— 不可忽视的细节

🔴 陷阱：忘记花括号的后果

int x = -5; // ❌ 错误写法：没有花括号 if (x > 0) cout << "A: x是正数" << endl; cout << "B: 这行不受if控制！" << endl; // 总是执行！

运行结果：只输出 "B: 这行不受if控制！"
因为 cout << "A" 受if控制被跳过，但 cout << "B" 不在if范围内！

🟢 正确写法：用花括号保护

// ✅ 正确写法：使用花括号 if (x > 0) { cout << "C: x是正数" << endl; cout << "D: 这行也在if控制内" << endl; } // 当 x = -5 时：C和D都不会输出 ✓
💡 最佳实践： 无论if里面有几条语句，都永远加上花括号！这样代码清晰，绝不出错。
【讲解】📦 代码块 { } —— 不可忽视的细节 结合讲义《代码块 { } 的重要性》强调： · 很多初学者会犯一个错误：**忘记写花括号**。如果不写花括号，if语句只会控制紧跟它的**一条**语句！ · 来看看这个陷阱： · int score = 59; · if (score >= 60) · cout << "及格啦！" << endl; 幻灯片上可见要点： · 运行结果 ：只输出 "B: 这行不受if控制！" 因为 cout << "A" 受if控制被跳过，但 cout << "B" 不在if范围内！ · 运行结果 · "B: 这行不受if控制！" · 💡 最佳实践： 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

💻 示例：🚦 交通信号灯程序

#include <iostream> using namespace std; int main() { char light; // 存储信号灯颜色 cout << "请输入信号灯颜色（R=红，G=绿，Y=黄）："; cin >> light; if (light == 'R' || light == 'r') { cout << "=== 交通信号灯 ===" << endl; cout << "当前信号：红灯 🔴" << endl; cout << "请停下！耐心等待~" << endl; } if (light == 'G' || light == 'g') { cout << "=== 交通信号灯 ===" << endl; cout << "当前信号：绿灯 🟢" << endl; cout << "可以安全通行！" << endl; } if (light == 'Y' || light == 'y') { cout << "=== 交通信号灯 ===" << endl; cout << "当前信号：黄灯 🟡" << endl; cout << "请减速，准备停下！" << endl; } return 0; }
📝 代码解读：
• 三个独立的if，分别判断三种颜色的灯
• || 是"或"运算符，R或r都能匹配
• 每个if都有花括号{}包裹所有输出语句
【讲解】💻 示例：🚦 交通信号灯程序 结合讲义《示例1：最简单的if——检查数字是否为正数》强调： · using namespace std; · int main() { · int number; · cout << "请输入一个整数："; · cin >> number; 幻灯片上可见要点： · 📝 代码解读： 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

int num; cin >> num; if (num > 0) { cout << "这是正数" << endl; }

练习2：代码阅读

下面代码输出什么？

int x = -5; if (x > 0) cout << "A"; cout << "B";

答案：只输出 B。因为A受if控制被跳过，B不受if控制。
