📖 if语句的基本语法

if (条件) { // 条件成立时才执行的代码 语句1; 语句2; ... }

🔍 结构拆解

部分说明例子
if关键字，表示"如果"告诉计算机这里开始判断
(条件)条件表达式，结果必须是true或falseage > 18、score == 100
{ }代码块，包裹多条语句为一个整体花括号里的代码要么全执行，要么全不执行
🧠 记忆口诀：
条件成立走if，花括号里一起走；
不成立就跳过去，继续往下不回头！

⚖️ 条件表达式 & 比较运算符

if的条件必须是一个能判断真假的表达式。在C++中，我们用比较运算符来构造条件：

运算符含义示例结果
>大于10 > 5true ✓
<小于3 < 8true ✓
>=大于等于60 >= 60true ✓
<=小于等于30 <= 15false ✗
==等于5 == 5true ✓
!=不等于7 != 3true ✓
⚠️ 特别注意：
==（两个等号）是 判断相等
=（一个等号）是 赋值
这是新手最容易犯的错误！
❌ if (x = 5) —— 这是赋值，不是判断！
✅ if (x == 5) —— 这才是判断x是否等于5

📦 代码块 { } —— 不可忽视的细节

🔴 陷阱：忘记花括号的后果

int x = -5; // ❌ 错误写法：没有花括号 if (x > 0) cout << "A: x是正数" << endl; cout << "B: 这行不受if控制！" << endl; // 总是执行！

运行结果：只输出 "B: 这行不受if控制！"
因为 cout << "A" 受if控制被跳过，但 cout << "B" 不在if范围内！

🟢 正确写法：用花括号保护

// ✅ 正确写法：使用花括号 if (x > 0) { cout << "C: x是正数" << endl; cout << "D: 这行也在if控制内" << endl; } // 当 x = -5 时：C和D都不会输出 ✓
💡 最佳实践： 无论if里面有几条语句，都永远加上花括号！这样代码清晰，绝不出错。

💻 示例：🚦 交通信号灯程序

#include <iostream> using namespace std; int main() { char light; // 存储信号灯颜色 cout << "请输入信号灯颜色（R=红，G=绿，Y=黄）："; cin >> light; if (light == 'R' || light == 'r') { cout << "=== 交通信号灯 ===" << endl; cout << "当前信号：红灯 🔴" << endl; cout << "请停下！耐心等待~" << endl; } if (light == 'G' || light == 'g') { cout << "=== 交通信号灯 ===" << endl; cout << "当前信号：绿灯 🟢" << endl; cout << "可以安全通行！" << endl; } if (light == 'Y' || light == 'y') { cout << "=== 交通信号灯 ===" << endl; cout << "当前信号：黄灯 🟡" << endl; cout << "请减速，准备停下！" << endl; } return 0; }
📝 代码解读：
• 三个独立的if，分别判断三种颜色的灯
• || 是"或"运算符，R或r都能匹配
• 每个if都有花括号{}包裹所有输出语句

🎮 趣味练习

练习1：正数判断器

写一个程序，输入一个整数，如果是正数就输出"这是正数"。

int num; cin >> num; if (num > 0) { cout << "这是正数" << endl; }

练习2：代码阅读

下面代码输出什么？

int x = -5; if (x > 0) cout << "A"; cout << "B";

答案：只输出 B。因为A受if控制被跳过，B不受if控制。

🏆 挑战任务：简易银行取款

定义余额 balance = 1000，用户输入取款金额：

  • 余额足够 → 扣款并显示新余额
  • 余额不足 → 提示余额不足
  • 输入无效 → 提示输入有效金额
double balance = 1000.00; double amount; cin >> amount; if (amount > 0 && amount <= balance) { balance = balance - amount; cout << "取款成功！剩余余额：" << balance << " 元" << endl; } if (amount > balance) { cout << "余额不足！当前余额仅：" << balance << " 元" << endl; } if (amount <= 0) { cout << "请输入有效的取款金额！" << endl; }
