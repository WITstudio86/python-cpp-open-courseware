📖 核心知识

【数组遍历——数据处理的魔法】

遍历就是按照顺序访问数组中的每一个元素。配合 for 循环，我们可以轻松处理成百上千个数据！

1. 遍历的标准写法

// 遍历数组的经典模式 for (int i = 0; i < n; i++) { // 对 arr[i] 进行操作 cout << arr[i] << " "; // 例如：输出 sum += arr[i]; // 例如：累加 }
💡 为什么条件是 i < n？
因为下标从0开始，最大下标是 n-1。当 i = n 时访问 arr[n] 会导致越界！

2. 计算总和与平均值

int sum = 0; // 累加器，初始为0 for (int i = 0; i < n; i++) { sum += arr[i]; // 累加每个元素 } double avg = (double)sum / n; // 强制转换为浮点数
⚠️ 整数除法陷阱：如果 sum 和 n 都是整数，sum / n 会进行整数除法（丢掉小数）！必须用 (double)sum / n 或 sum / (double)n。

3. 遍历中的条件统计

// 统计及格人数 int count = 0; for (int i = 0; i < n; i++) { if (scores[i] >= 60) { count++; // 满足条件，计数器+1 } } // 找最大值（打擂台法） int maxVal = arr[0]; for (int i = 1; i < n; i++) { if (arr[i] > maxVal) { maxVal = arr[i]; // 发现更大的，替换擂主 } }

4. 常用遍历模式速查表

💻 示例代码：成绩统计

#include <iostream> using namespace std; int main() { int scores[5] = {85, 92, 78, 95, 88}; int n = 5; // 1. 输出所有成绩 cout << "成绩列表："; for (int i = 0; i < n; i++) { cout << scores[i] << " "; } cout << endl; // 2. 计算总分和平均分 int sum = 0; for (int i = 0; i < n; i++) { sum += scores[i]; } double avg = (double)sum / n; // 3. 找最高分和最低分 int maxS = scores[0], minS = scores[0]; for (int i = 1; i < n; i++) { if (scores[i] > maxS) maxS = scores[i]; if (scores[i] < minS) minS = scores[i]; } // 4. 统计各个分数段人数 int great = 0, good = 0, pass = 0, fail = 0; for (int i = 0; i < n; i++) { if (scores[i] >= 90) great++; else if (scores[i] >= 80) good++; else if (scores[i] >= 60) pass++; else fail++; } // 5. 输出分析报告 cout << "===== 成绩分析报告 =====" << endl; cout << "总分：" << sum << " 平均分：" << avg << endl; cout << "最高分：" << maxS << " 最低分：" << minS << endl; cout << "优秀(≥90)：" << great << "人" << endl; cout << "良好(80~89)：" << good << "人" << endl; cout << "及格(60~79)：" << pass << "人" << endl; cout << "不及格：" << fail << "人" << endl; // 6. 简易柱状图 cout << "\n成绩分布图：" << endl; cout << "优秀: "; for (int i = 0; i < great; i++) cout << "█"; cout << endl; cout << "良好: "; for (int i = 0; i < good; i++) cout << "█"; cout << endl; cout << "及格: "; for (int i = 0; i < pass; i++) cout << "█"; cout << endl; cout << "不及格: "; for (int i = 0; i < fail; i++) cout << "█"; cout << endl; return 0; }

📝 本课小结

  • 遍历数组用 for (i = 0; i < n; i++)，i 从0到 n-1
  • 求和时累加器 初始化为0，每次循环 sum += arr[i]
  • 求平均值注意 类型转换，用 (double)sum / n 避免整数除法
  • 找最值用"打擂台法"：先假设第一个，然后循环比较更新
  • 条件统计在遍历时用 if 判断 + 计数器，即可统计任意条件
  • 数组 + 循环 = 批量处理数据的超级武器！
