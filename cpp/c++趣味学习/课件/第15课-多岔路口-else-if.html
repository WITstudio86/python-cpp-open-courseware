📖 多岔路口——if-else if-else 阶梯

多分支结构就像一个层层过滤的筛子——从最严格的条件开始，一层层往下筛选：

🔝 第1级：if (条件1)
→ 条件1成立？执行代码1，结束！不成立？往下走 ↓
📊 第2级：else if (条件2)
→ 条件2成立？执行代码2，结束！不成立？继续往下 ↓
📊 第3级：else if (条件3)
→ 条件3成立？执行代码3，结束！不成立？继续往下 ↓
🔄 最后：else
→ 前面都不成立？执行这里的代码（兜底）
⚠️ 条件顺序为什么重要？
反例：if (score >= 60) ... else if (score >= 90) ...
95分满足 >=60，先被拦截，永远看不到后面的 >=90！
✅ 正确：if (score >= 90) ... else if (score >= 80) ... （从高到低）
🌍 生活例子：
🚦 红绿灯：红灯停、绿灯行、黄灯等一等 → 三种情况的判断
📋 菜单选择：看菜单选菜 → 第一页没有想吃的看第二页 → 都没有就随便点（兜底）

💻 示例代码：成绩等级评定系统

#include <iostream> using namespace std; int main() { int score; cout << "请输入考试分数（0-100）："; cin >> score; // ✅ 正确的条件顺序：从高到低！ if (score >= 90) { cout << "等级：A（优秀）🎉" << endl; } else if (score >= 80) { cout << "等级：B（良好）💪" << endl; } else if (score >= 70) { cout << "等级：C（中等）📚" << endl; } else if (score >= 60) { cout << "等级：D（及格）✏️" << endl; } else { cout << "等级：E（需努力）📖" << endl; } return 0; }

⚠️ 常见错误写法对比

// ❌ 错误：从低到高 — 95分也会判为"及格"！ if (score >= 60) { ... } else if (score >= 90) { ... } // 永远执行不到！ // ✅ 正确：从高到低 if (score >= 90) { ... } else if (score >= 60) { ... } // 正确！

记住：条件要从最特殊到最一般排列，就像排队——个子高的站前面！

🎮 趣味练习

练习1：成绩等级评定 ✏️

编写程序输出：90-100→"A"，80-89→"B"，70-79→"C"，60-69→"D"，60以下→"E"。

✅ 提示：从高到低排列：if (score >= 90) → else if (score >= 80) → ...

练习2：季节判断器 🍂

输入月份（1-12），输出对应季节（春3-5，夏6-8，秋9-11，冬12-2）。

✅ 提示：使用逻辑运算符：month >= 3 && month <= 5 判断春季。

练习3：找茬大侦探 🔍

下面代码有什么问题？

int score = 95; if (score >= 60) cout << "及格"; else if (score >= 90) cout << "优秀";
🔍 答案：条件顺序错误！>=60 包含了所有 >=90 的分数，后面的 >=90 永远不会执行。应该把 >=90 放前面！

📝 本课小结

知识点说明
多分支语法if(){} else if(){} else{}
执行规则从上到下依次检查，第一个成立的就执行，后面跳过
条件顺序从最特殊到最一般排列（从高到低）
else的妙用兜底处理，所有条件都不满足时执行
逻辑运算符&&（与）、||（或）精确限定范围
🔑 记住口诀：
多岔路口有导航，if-else-if 来帮忙！
条件顺序最关键，从高到低不迷路；
层层筛选往下走，只走一条不回头！
