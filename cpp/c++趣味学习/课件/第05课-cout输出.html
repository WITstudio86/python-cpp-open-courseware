📖 cout 的核心用法

1️⃣ 链式输出：串糖葫芦

cout << "我叫" << "小明" << "，今年" << 10 << "岁。"; // 输出：我叫小明，今年10岁。

2️⃣ 换行方式对比

方式写法效果
endlcout << "你好" << endl;换行+刷新
\ncout << "你好\n";只换行

3️⃣ 常用转义字符

代码含义效果
\n换行光标到下一行
\tTab跳到下一个制表位
\\反斜杠输出 \
\"双引号在字符串中输出 "

💻 示例代码

输出数字和计算

cout << 100; // 输出数字 cout << 10 + 5; // 输出：15 cout << 7 * 8; // 输出：56 cout << "10+5=" << 10+5; // 输出：10+5=15

制作漂亮标题框

cout << "****************" << endl; cout << "* 欢迎学习C++ *" << endl; cout << "****************" << endl;

用 \t 对齐表格

cout << "姓名\t年龄\t成绩" << endl; cout << "小明\t10\t98" << endl; cout << "小红\t9\t95" << endl;
🔑 注意：C++中的乘号是 *，除号是 /，和数学书不一样！

🎮 趣味练习

练习1：填词游戏 ✏️

string name = "小明"; int age = 10; cout << "我叫" << ___ << "，今年" << ___ << "岁";

空格处填什么？（答案：name 和 age）

练习2：课程表设计师 📚

用 cout + \t 设计一张课程表，要求有标题、边框、至少3天课程。

练习3：算术小能手 🧮

用 cout 输出：12+35、99-28、8×7、144÷12、17÷5的余数

✅ 提示：乘号是 *，除号是 /，取余数是 %。别忘了用链式输出！
