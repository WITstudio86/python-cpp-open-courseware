# 第28课：你来比划我来猜——数组趣味应用

## 课程导入

同学们，上一节课我们学会了用数组来存储数据，并且在数组中"找呀找呀找"，查找特定的值和最大值。今天我们要解锁数组的一个神奇新用法——数组不仅可以"存储"数据，还能用来"计数"！

想象一下这个场景：老师需要统计全班同学最喜欢的水果是什么。苹果、香蕉、橘子、西瓜……每一种水果有多少人选呢？如果让你用程序来做，你会怎么做？聪明的你可能会想：用变量！苹果一个变量，香蕉一个变量……但如果有一百种水果呢？那得定义一百个变量，太麻烦了！

这时候，数组的"计数"本领就派上用场了。我们可以用一个数组当"计数器"，数组的下标表示"哪种数字"，数组的值表示"出现了几次"。就像做游戏"你来比划我来猜"一样——你输入一个数字，数组就帮你记住它出现过的次数！

## 核心概念

### 1. 数组作为计数器

数组作为计数器（Frequency Counting）的核心思想是：**用下标代表"种类"，用值代表"出现次数"**。

例如，要统计数字0到9每个数字出现了多少次，我们可以定义一个长度为10的数组 `int count[10] = {0};`：
- `count[0]` 表示数字0出现了几次
- `count[1]` 表示数字1出现了几次
- ……依此类推
- `count[9]` 表示数字9出现了几次

当我们读到一个数字时，只需要执行 `count[数字]++`，就把对应的计数器加1。这就是数组计数最核心的一行代码！

### 2. 标记数组

标记数组（Marker Array）与计数器类似，但它只记录"是否出现过"，而不关心出现次数。通常用0和1来表示：
- 0 表示"未出现"
- 1 表示"已经出现"

标记数组常用于"去重"问题：判断一个数字是否已经出现过。

### 3. 频率统计的步骤

1. **初始化**：将计数数组的所有元素初始化为0
2. **遍历数据**：读入每一个数据，将对应下标的计数器加1
3. **输出结果**：遍历计数数组，输出每个下标及其对应的计数值

### 4. 字符频率统计

同样的思想也可以用来统计字符的频率。由于每个字符在计算机中都对应一个数字（ASCII码），我们可以用数组来统计一段文字中每个字母出现的次数。例如，统计一个字符串中各个小写字母的出现次数。

## 代码示例

### 示例1：统计1到10之间数字出现频率

```cpp
#include <iostream>
using namespace std;

int main() {
    int count[11] = {0};  // 下标0不用，下标1-10分别计数字1-10
    int n, num;

    cout << "请输入数字的个数：";
    cin >> n;

    cout << "请输入 " << n << " 个数字（范围1-10）：" << endl;
    for (int i = 0; i < n; i++) {
        cin >> num;
        if (num >= 1 && num <= 10) {
            count[num]++;  // 核心：对应数字的计数器加1
        }
    }

    cout << "\n数字出现次数统计：" << endl;
    for (int i = 1; i <= 10; i++) {
        if (count[i] > 0) {
            cout << "数字 " << i << " 出现了 " << count[i] << " 次" << endl;
        }
    }

    return 0;
}
```

**关键行解释**：
- 第5行：定义计数数组，必须有足够的长度以覆盖所有可能的数字
- 第14行：`count[num]++` 是核心——读到数字num，就把count[num]加1
- 第19-21行：只输出出现过的数字（count[i] > 0）

### 示例2：使用标记数组去重

```cpp
#include <iostream>
using namespace std;

int main() {
    bool appeared[101] = {false};  // 标记数字1-100是否出现过
    int n, num;

    cout << "请输入数字的个数：";
    cin >> n;

    cout << "请输入 " << n << " 个数字：";
    for (int i = 0; i < n; i++) {
        cin >> num;
        if (num >= 1 && num <= 100) {
            if (!appeared[num]) {
                cout << num << " ";  // 第一次出现就输出
                appeared[num] = true;
            }
        }
    }
    cout << endl << "（以上是去重后的结果）" << endl;

    return 0;
}
```

### 示例3：数字频率计数器（完整项目）

```cpp
#include <iostream>
using namespace std;

int main() {
    int digitCount[10] = {0};  // digitCount[0]~[9] 分别统计数字0~9
    long long n;

    cout << "请输入一个整数：";
    cin >> n;

    // 如果输入的是负数，先转为正数
    if (n < 0) {
        n = -n;
    }

    // 如果是0，单独处理
    if (n == 0) {
        digitCount[0] = 1;
    }

    // 逐位提取数字并计数
    while (n > 0) {
        int digit = n % 10;    // 取出最后一位数字
        digitCount[digit]++;   // 对应的计数器加1
        n = n / 10;            // 去掉最后一位
    }

    // 输出统计结果
    cout << "\n数字频率统计结果：" << endl;
    cout << "==================" << endl;
    for (int i = 0; i < 10; i++) {
        cout << "数字 " << i << " 出现了 " << digitCount[i] << " 次";
        // 用星号画出简易柱状图
        cout << "  ";
        for (int j = 0; j < digitCount[i]; j++) {
            cout << "█";
        }
        cout << endl;
    }

    return 0;
}
```

## 本课小结

1. 数组不仅是数据的"容器"，还是一种强大的**计数工具**：用下标表示种类，用值表示次数。
2. **频率计数**的核心代码是 `count[数字]++`——把对应数字的计数器加1。
3. **标记数组**用于记录"是否出现过"，常用于去重和查重问题。
4. 计数数组在使用前必须**全部初始化为0**，否则会出现奇怪的数字。
5. 数组作为计数器的思想可以推广到很多场景：成绩段统计、字符频率、投票统计等。
6. 这种方法比定义大量独立变量更简洁、更灵活，是"以空间换时间"的经典应用。
