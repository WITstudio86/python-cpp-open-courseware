## 一、课堂引入：秘密暗号的魅力

**场景设定**：你和你的好朋友想在学校里传递秘密消息，不想让其他人看懂你们写的字条。怎么办？我们可以把普通文字变成"密文"——只有知道解密方法的人才能读懂！

古代罗马的凯撒大帝就用过一种非常聪明的方法：**把每个字母按照字母表顺序向后移动固定位数**。比如 A 变成 D，B 变成 E，C 变成 F……这样，"你好"就变成了一串看起来毫无意义的字母。只有知道"向后移动3位"这个规则的人，才能把密文恢复成原文。

今天，我们就来化身"密文特工队"，用 C++ 实现自己的秘密暗号系统！

## 二、基础知识：大小写转换

在加密通信中，我们经常需要统一字母的大小写，或者对大小写进行变换。C++ 提供了两种方式来实现大小写转换。

### 2.1 使用 cctype 库函数

C++ 的 `<cctype>`（或 C 语言的 `<ctype.h>`）头文件提供了两个非常有用的函数：

| 函数 | 功能 | 示例 |
|------|------|------|
| `toupper(c)` | 将小写字母转换为大写，非小写字母保持不变 | `toupper('a')` → `'A'` |
| `tolower(c)` | 将大写字母转换为小写，非大写字母保持不变 | `tolower('Z')` → `'z'` |

**代码示例**：

```cpp
#include <iostream>
#include <cctype>   // 包含 toupper 和 tolower
using namespace std;

int main() {
    char ch1 = 'h';
    char ch2 = 'K';
    char ch3 = '5';
    char ch4 = '!';

    cout << "toupper('h') = " << (char)toupper(ch1) << endl;  // 输出 H
    cout << "tolower('K') = " << (char)tolower(ch2) << endl;  // 输出 k
    cout << "toupper('5') = " << (char)toupper(ch3) << endl;  // 输出 5（数字不变）
    cout << "tolower('!') = " << (char)tolower(ch4) << endl;  // 输出 !（符号不变）

    return 0;
}
```

**重要提示**：`toupper` 和 `tolower` 返回的是 `int` 类型（即字母的 ASCII 码），需要用 `(char)` 强制转换为字符才能正确显示。另外，这两个函数对于非字母字符（数字、标点符号等）不会做任何改变。

### 2.2 手动 ASCII 码转换

每个字符在计算机内部都对应一个数字，这个数字叫做 **ASCII 码**。关键记忆点：

- 大写字母 A～Z 的 ASCII 码范围：**65～90**
- 小写字母 a～z 的 ASCII 码范围：**97～122**
- 同一个字母的大写和小写之间正好相差 **32**！例如：`'A' = 65`，`'a' = 97`，差值为 `97 - 65 = 32`。

因此，我们可以利用这个规律手动转换大小写：

```cpp
// 小写转大写：减去 32
char lowerToUpper(char c) {
    if (c >= 'a' && c <= 'z') {
        return c - 32;   // 等价于 c - ('a' - 'A')
    }
    return c;
}

// 大写转小写：加上 32
char upperToLower(char c) {
    if (c >= 'A' && c <= 'Z') {
        return c + 32;   // 等价于 c + ('a' - 'A')
    }
    return c;
}
```

**更专业的写法**（不依赖具体数字，可读性更好）：

```cpp
// 小写转大写
if (c >= 'a' && c <= 'z') {
    c = c - ('a' - 'A');   // 'a' - 'A' 的值就是 32
}

// 大写转小写
if (c >= 'A' && c <= 'Z') {
    c = c + ('a' - 'A');   // 'a' - 'A' 的值就是 32
}
```

这样做的好处是：即使换了字符编码方案（虽然现在都是 ASCII/Unicode），代码的含义也更清晰。

## 三、核心内容：凯撒加密（Caesar Cipher）

### 3.1 什么是凯撒加密？

凯撒加密是一种**替换加密**算法。它的原理非常简单：把明文中的每个字母，按照字母表顺序**向后（或向前）移动固定位数**，替换成另一个字母。

**加密公式**：

```
密文字母 = (明文字母 - 基准值 + 偏移量) % 26 + 基准值
```

- **基准值**：大写字母用 `'A'`（65），小写字母用 `'a'`（97）。
- **偏移量**：移动的位数（即密钥，key）。正数表示向后移，负数表示向前移。
- **% 26**：模运算确保字母在 A～Z（或 a～z）之间循环。比如 Z 后移 1 位应该变成 A。

### 3.2 加密过程详解

**举例**：偏移量 = 3（凯撒大帝当年用的就是 3），加密单词 "HELLO"。

| 明文字母 | ASCII 步骤 | 计算过程 | 密文字母 |
|----------|------------|----------|----------|
| H (72) | 72 - 65 = 7 | (7 + 3) % 26 = 10 | 10 + 65 = 75 → K |
| E (69) | 69 - 65 = 4 | (4 + 3) % 26 = 7 | 7 + 65 = 72 → H |
| L (76) | 76 - 65 = 11 | (11 + 3) % 26 = 14 | 14 + 65 = 79 → O |
| L (76) | 76 - 65 = 11 | (11 + 3) % 26 = 14 | 14 + 65 = 79 → O |
| O (79) | 79 - 65 = 14 | (14 + 3) % 26 = 17 | 17 + 65 = 82 → R |

结果："HELLO" 加密后变成 **"KHOOR"**。

### 3.3 解密过程

解密就是加密的逆过程：**将密文每个字母向前移动同样的位数**。

如果加密偏移量 = 3，那么解密偏移量 = -3（即向前移 3 位），或者等价地用 +23（因为 -3 在模 26 下等于 23）。

**解密公式**：

```
明文字母 = (密文字母 - 基准值 - 偏移量 + 26) % 26 + 基准值
```

注意：这里加上 26 是为了避免负数取模的问题（C++ 中负数 % 正数的结果可能为负数）。

### 3.4 完整加密解密程序

```cpp
#include <iostream>
#include <string>
using namespace std;

// 凯撒加密函数：对单个字符进行加密
char caesarEncrypt(char ch, int shift) {
    // 处理大写字母
    if (ch >= 'A' && ch <= 'Z') {
        return (ch - 'A' + shift) % 26 + 'A';
    }
    // 处理小写字母
    else if (ch >= 'a' && ch <= 'z') {
        return (ch - 'a' + shift) % 26 + 'a';
    }
    // 非字母字符保持不变
    return ch;
}

// 凯撒解密函数：对单个字符进行解密
char caesarDecrypt(char ch, int shift) {
    // 处理大写字母（反方向移动）
    if (ch >= 'A' && ch <= 'Z') {
        return (ch - 'A' - shift + 26) % 26 + 'A';
    }
    // 处理小写字母（反方向移动）
    else if (ch >= 'a' && ch <= 'z') {
        return (ch - 'a' - shift + 26) % 26 + 'a';
    }
    // 非字母字符保持不变
    return ch;
}

int main() {
    int shift;
    string message, encrypted, decrypted;

    cout << "🔐 欢迎使用凯撒加密系统！" << endl;
    cout << "请输入偏移量（1~25）：";
    cin >> shift;
    cin.ignore();  // 清除输入缓冲区中的换行符

    cout << "请输入要加密的消息：";
    getline(cin, message);

    // 加密
    encrypted = "";
    for (int i = 0; i < message.length(); i++) {
        encrypted += caesarEncrypt(message[i], shift);
    }

    // 解密
    decrypted = "";
    for (int i = 0; i < encrypted.length(); i++) {
        decrypted += caesarDecrypt(encrypted[i], shift);
    }

    cout << "\n===== 结果 =====" << endl;
    cout << "原文：" << message << endl;
    cout << "密文：" << encrypted << endl;
    cout << "解密：" << decrypted << endl;

    // 验证解密是否正确
    if (message == decrypted) {
        cout << "✅ 加密解密成功！解密结果与原文一致。" << endl;
    } else {
        cout << "❌ 出现错误，请检查程序。" << endl;
    }

    return 0;
}
```

**运行示例**：

```
🔐 欢迎使用凯撒加密系统！
请输入偏移量（1~25）：3
请输入要加密的消息：Hello World

===== 结果 =====
原文：Hello World
密文：Khoor Zruog
解密：Hello World
✅ 加密解密成功！解密结果与原文一致。
```

## 四、知识拓展：更安全的暗号系统

### 4.1 暴力破解与安全性

凯撒加密只有 25 种可能的偏移量（1～25），攻击者只需要尝试所有 25 种可能，就能破解密文。这在计算机面前连一秒钟都不需要。

**暴力破解演示思路**（可以在课堂上讨论）：

```cpp
// 暴力破解：尝试所有偏移量
for (int s = 1; s <= 25; s++) {
    string attempt = "";
    for (int i = 0; i < ciphertext.length(); i++) {
        attempt += caesarDecrypt(ciphertext[i], s);
    }
    cout << "偏移量 " << s << ": " << attempt << endl;
}
```

25 行输出中，只有一行是有意义的明文——那就是正确的解密结果。

### 4.2 进阶算法简介

- **ROT13**：凯撒加密的特例，偏移量固定为 13。因为字母表共 26 个字母，加密和解密使用同一个操作（加密两次就回到原文）。常用于互联网上隐藏剧透信息。
- **维吉尼亚密码**：使用一个关键词作为密钥，每个字母的偏移量由关键词对应位置的字母决定，比凯撒加密更安全。
- **现代加密**：如 AES、RSA 算法，使用复杂的数学运算，广泛用于网络通信、银行交易等场景。

**题目**：编写一个程序，输入一个字符串，将其中的大写字母全部转换为小写，小写字母全部转换为大写（即大小写翻转），其他字符保持不变。

**输入示例**：
```
Hello, C++ World!
```

**输出示例**：
```
hELLO, c++ wORLD!
```

<details>
<summary>点击查看参考答案</summary>

```cpp
#include <iostream>
#include <string>
#include <cctype>
using namespace std;

int main() {
    string s;
    cout << "请输入字符串：";
    getline(cin, s);

    for (int i = 0; i < s.length(); i++) {
        if (s[i] >= 'a' && s[i] <= 'z') {
            s[i] = toupper(s[i]);
        } else if (s[i] >= 'A' && s[i] <= 'Z') {
            s[i] = tolower(s[i]);
        }
    }

    cout << "转换后：" << s << endl;
    return 0;
}
```

**不使用 cctype 的版本**：

```cpp
for (int i = 0; i < s.length(); i++) {
    if (s[i] >= 'a' && s[i] <= 'z') {
        s[i] = s[i] - 32;   // 小写转大写
    } else if (s[i] >= 'A' && s[i] <= 'Z') {
        s[i] = s[i] + 32;   // 大写转小写
```

**题目**：截获了一段密文 `"Xlmw mw e Jsvqirx irgvcTxiv!"`，已知加密时使用的偏移量为 4。请编写程序解密这段消息。这段消息解密后是什么？（提示：这是一句英文名言）

<details>
<summary>点击查看参考答案</summary>

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string cipher = "Xlmw mw e Jsvqirx irgvcTxiv!";
    int shift = 4;

    for (int i = 0; i < cipher.length(); i++) {
        char ch = cipher[i];
        if (ch >= 'A' && ch <= 'Z') {
            cipher[i] = (ch - 'A' - shift + 26) % 26 + 'A';
        } else if (ch >= 'a' && ch <= 'z') {
            cipher[i] = (ch - 'a' - shift + 26) % 26 + 'a';
        }
    }

    cout << "解密结果：" << cipher << endl;
```

## 六、挑战任务：制作升级版暗号系统

**任务描述**：设计一个"混合暗号系统"，包含以下功能：

1. 先对原文进行凯撒加密（偏移量由用户输入）。
2. 再对加密结果进行大小写翻转（大写变小写，小写变大写）。
3. 实现对应的解密功能（先翻转大小写，再凯撒解密）。
4. 在程序中使用函数分离各个步骤，使代码清晰可读。

**要求**：
- 程序接受用户输入的原文和偏移量。
- 先展示加密后的密文。
- 再展示解密后的明文，并验证与原文是否一致。

<details>
<summary>点击查看参考答案</summary>

```cpp
#include <iostream>
#include <string>
#include <cctype>
using namespace std;

// 步骤1：凯撒加密
string caesarEncrypt(string text, int shift) {
    string result = "";
    for (int i = 0; i < text.length(); i++) {
        char ch = text[i];
        if (ch >= 'A' && ch <= 'Z') {
            result += (ch - 'A' + shift) % 26 + 'A';
        } else if (ch >= 'a' && ch <= 'z') {
            result += (ch - 'a' + shift) % 26 + 'a';
        } else {
            result += ch;
        }
    }
    return result;
}

// 步骤2：大小写翻转
string flipCase(string text) {
    string result = "";
    for (int i = 0; i < text.length(); i++) {
        char ch = text[i];
        if (ch >= 'A' && ch <= 'Z') {
            result += tolower(ch);
        } else if (ch >= 'a' && ch <= 'z') {
            result += toupper(ch);
        } else {
            result += ch;
        }
    }
    return result;
}

// 解密步骤1：大小写翻回（和翻转操作一样）
string flipCaseDecrypt(string text) {
    return flipCase(text);  // 翻转两次等于不变，所以相同
}

// 解密步骤2：凯撒解密
string caesarDecrypt(string text, int shift) {
    string result = "";
    for (int i = 0; i < text.length(); i++) {
        char ch = text[i];
        if (ch >= 'A' && ch <= 'Z') {
            result += (ch - 'A' - shift + 26) % 26 + 'A';
        } else if (ch >= 'a' && ch <= 'z') {
            result += (ch - 'a' - shift + 26) % 26 + 'a';
        } else {
            result += ch;
        }
    }
    return result;
}

int main() {
    int shift;
    string original;

    cout << "🔐 混合暗号系统" << endl;
    cout << "请输入偏移量（1~25）：";
    cin >> shift;
    cin.ignore();

    cout << "请输入原文：";
    getline(cin, original);

    // 加密：先凯撒，再翻转大小写
    string step1 = caesarEncrypt(original, shift);
    string encrypted = flipCase(step1);

    // 解密：先翻转大小写，再凯撒解密
    string step3 = flipCaseDecrypt(encrypted);
    string decrypted = caesarDecrypt(step3, shift);

    cout << "\n===== 加密结果 =====" << endl;
    cout << "原文　：" << original << endl;
    cout << "密文　：" << encrypted << endl;
    cout << "解密后：" << decrypted << endl;

    if (original == decrypted) {
        cout << "✅ 加密解密成功！" << endl;
    } else {
        cout << "❌ 解密失败，请检查程序。" << endl;
    }

    return 0;
}
```

**运行示例**：

```
🔐 混合暗号系统
请输入偏移量（1~25）：5
请输入原文：Hello World

===== 加密结果 =====
原文　：Hello World
密文　：mJQQT bTWQI
解密后：Hello World
✅ 加密解密成功！
```
</details>

## 七、本课总结

| 知识点 | 核心内容 |
|--------|----------|
| **toupper / tolower** | `<cctype>` 库函数，方便地转换字母大小写 |
| **ASCII 码** | 'A'=65, 'a'=97，差值 32，可手动转换大小写 |
| **凯撒加密原理** | 每个字母按字母表顺序移位，非字母不变 |
| **加密公式** | `(ch - base + shift) % 26 + base` |
| **解密公式** | `(ch - base - shift + 26) % 26 + base` |
| **模运算** | 使用 `% 26` 实现字母循环（Z 后面回到 A） |
| **安全性** | 凯撒加密只有 25 种可能，可以被暴力破解 |

### 关键提醒

1. **非字母字符不处理**：空格、数字、标点符号在加密时应原样保留。
2. **区分大小写**：加密时大写字幕和大写字幕对应，小写和小写对应，不要混在一起。
3. **模运算的陷阱**：在 C++ 中，负数取模的结果可能是负数，所以解密时需要用 `+26` 调整。
4. **cin 和 getline 混用**：`cin >>` 读完后缓冲区会留一个换行符，需要用 `cin.ignore()` 清除，否则后面的 `getline` 会读到空行。

### 拓展思考

- 如果凯撒加密的偏移量为 0，密文是什么？（答案：就是原文本身！）
- 如果偏移量为 26，密文是什么？（答案：也是原文，因为绕了一圈回到原点！）
- 你能想到什么方法来让凯撒加密更安全一些吗？（提示：每个字母使用不同的偏移量，比如维吉尼亚密码。）
