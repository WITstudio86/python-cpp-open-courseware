## 🎯 学习目标

## 📖 知识讲解

同学们，想象一下你正站在人生的十字路口前。前方有一个交通信号灯：绿灯亮了，你可以放心地走过去；红灯亮了，你必须停下来等待。在编程的世界里，我们也有这样一个"信号灯"——它就是我们今天要学习的 **if语句**！

### 什么是if语句？

if在英语里就是"如果"的意思。在C++中，if语句就是告诉计算机："**如果**某个条件成立，就执行一段代码；如果不成立，这段代码就被跳过。"

这就好比生活中：
- 如果(下雨了) { 带伞；穿雨鞋； }
- 如果(考了100分) { 爸妈很开心；奖励冰激凌； }
- 如果(肚子饿了) { 吃饭； }

### if语句的基本语法

```cpp
if (条件) {
    // 条件成立时执行的代码
}
```

让我们拆解一下这个结构：

1. **`if`** —— 关键字，告诉计算机这里开始一个判断
2. **`(条件)`** —— 圆括号里写条件表达式。条件的结果要么是 **true**（真，成立），要么是 **false**（假，不成立）
3. **`{ }`** —— 花括号，也叫"代码块"。花括号里面的所有语句是一个整体

### 把条件比喻为"门卫"

你可以把if的条件想象成一位严格的门卫：
- 当条件为 **true** 时，门卫说："请进！"——花括号里的代码全部执行
- 当条件为 **false** 时，门卫说："此路不通！"——花括号里的代码通通被跳过，程序继续往下走

### 代码块 { } 的重要性

很多初学者会犯一个错误：**忘记写花括号**。如果不写花括号，if语句只会控制紧跟它的**一条**语句！

来看看这个陷阱：

```cpp
int score = 59;
if (score >= 60)
    cout << "及格啦！" << endl;
    cout << "你可以升级了！" << endl;  // 这一行不管条件成立与否都会执行！
```

上面的代码中，`"你可以升级了！"` 无论分数多少都会输出，因为它不在if的控制范围内！

**正确写法**应该用花括号把属于同一组的语句包起来：

```cpp
int score = 59;
if (score >= 60) {
    cout << "及格啦！" << endl;
    cout << "你可以升级了！" << endl;  // 现在这两行是一个整体了
}
```

### 嵌套if——判断里面还有判断

有时候，一个判断还不够，我们需要在判断里面再做判断。这就像俄罗斯套娃，一层套一层，我们称之为**"嵌套if"**。

来看一个生活中的例子——游乐园的身高限制：

```
进入游乐设施前，工作人员会检查：
if (身高 >= 140cm) {
    可以玩所有项目；
    if (身高 >= 160cm) {
        连最刺激的过山车也能玩;
    }
}
```

在C++中，嵌套if的写法是：

```cpp
int height;
cout << "请输入你的身高（厘米）：";
cin >> height;

if (height >= 120) {
    cout << "你可以进入游乐园！" << endl;
    
    if (height >= 160) {
        cout << "哇，你可以玩所有项目，包括最刺激的过山车！" << endl;
    } else if (height >= 140) {
        cout << "你可以玩大部分项目，但过山车还需要再长高一点哦！" << endl;
    } else {
        cout << "你可以玩儿童专区，旋转木马在向你招手！" << endl;
    }
} else {
    cout << "抱歉，身高不够120厘米，还不能进入游乐园哦。" << endl;
}
```

**嵌套if的注意事项**：
1. 每层if都要写好自己的花括号`{}`，不能省略
2. 缩进要一层比一层多，这样代码看起来才清晰
3. 嵌套不要太深（一般2-3层就足够），太深了会变成"箭头代码"，很难看懂
4. 内层if完全依赖于外层if——外面不成立，里面的判断根本不会执行

### 比较运算符

写条件时常用的比较运算符：

| 运算符 | 含义 | 示例 | 生活说法 |
|--------|------|------|----------|
| `>` | 大于 | `age > 18` | "比18大" |
| `<` | 小于 | `score < 60` | "不到60" |
| `>=` | 大于等于 | `height >= 120` | "至少120" |
| `<=` | 小于等于 | `price <= 50` | "不超过50" |
| `==` | 等于 | `level == 5` | "刚好是5" |
| `!=` | 不等于 | `answer != 0` | "不是0" |

**特别注意**：判断"等于"用的是两个等号 `==`，一个等号 `=` 是赋值！这是新手最容易搞混的地方。

### 易错点分析——避开if的常见陷阱

学习if语句时，有几个"坑"特别容易踩进去，提前知道就能轻松避开！

**易错点1：`=` 和 `==` 混淆**

这是新手排名第一的错误！看下面的代码：

```cpp
int score = 85;
if (score = 100) {  // 错误！这里用了赋值=而不是比较==
    cout << "满分！" << endl;
}
```

这段代码会发生什么？`score = 100` 是一个赋值操作，它的结果是100。在C++中，非零值都算作`true`，所以这个if条件**永远成立**！而且 `score` 的值还被悄悄改成了100。正确的写法是：

```cpp
if (score == 100) {  // 正确！双等号是比较
    cout << "满分！" << endl;
}
```

**记忆口诀**：一个等号是"变成"，两个等号是"等于"。

**易错点2：忘记写花括号**

前面已经讲过，这里再强调一次。if语句如果不写花括号，只能控制紧跟它的一条语句。建议**永远**写上花括号，哪怕里面只有一行代码。

```cpp
// 不推荐 —— 容易出错
if (x > 0)
    cout << "正数" << endl;

// 推荐 —— 永远清晰明确  
if (x > 0) {
    cout << "正数" << endl;
}
```

**易错点3：条件表达式写反**

```cpp
// 想要判断"分数不及格"
if (score < 60) {  // 正确：分数小于60
    cout << "不及格" << endl;
}

// 常见错误：大于号和小于号搞反
if (score > 60) {  // 这是"分数大于60"，意思完全不同！
    cout << "不及格" << endl;  // 逻辑错误！
}
```

写条件时一定要想清楚：你想要的到底是什么关系？可以先用中文说出来，再翻译成C++。

**易错点4：花括号后面多加了一个分号**

```cpp
if (x > 0);  // 这里多了一个分号！if语句到此结束
{
    cout << "正数" << endl;  // 这一段已经和if没关系了，总是会执行！
}
```

if的圆括号后面**绝对不能加分号**！分号表示一条空语句，加了分号就等于说"如果条件成立，什么也不做"。

**易错点5：字符串比较不能用==**

这个知识点在以后学了字符串才能完全理解，但提前知道有好处。在C++中，用 `string` 类型时可以放心用 `==` 比较；但如果用的是C风格的字符数组（`char[]`），就不能直接用 `==` 来比较内容了，需要用专门的函数。目前我们学的基础阶段，先用简单的数字来比较就可以。

## 💻 示例代码

### 示例1：最简单的if——检查数字是否为正数

```cpp
#include <iostream>
using namespace std;

int main() {
    int number;
    cout << "请输入一个整数：";
    cin >> number;
    
    if (number > 0) {
        cout << number << " 是一个正数！" << endl;
        cout << "正数都大于零哦~" << endl;
    }
    
    cout << "程序结束，谢谢使用！" << endl;
    return 0;
}
```

**运行效果**：输入5 → 输出"5 是一个正数！正数都大于零哦~"和"程序结束"；输入-3 → 只输出"程序结束"。

### 示例3：if的陷阱——忘记加{}的后果

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = -5;
    
    cout << "=== 演示：没有{}的陷阱 ===" << endl;
    
    // 陷阱版本：没有{}
    if (x > 0)
        cout << "A：x是正数" << endl;
        cout << "B：这行不受if控制！" << endl;  // 总是执行！
    
    cout << "---" << endl;
    
    // 正确版本：有{}
    if (x > 0) {
        cout << "C：x是正数" << endl;
        cout << "D：这行也受if控制" << endl;
    }
    
    cout << "=== 比较两段输出的区别 ===" << endl;
    return 0;
}
```

**运行结果**：你会发现只有B输出了，A、C、D都没有输出。因为x=-5不大于0，A被跳过但B不受if控制所以照样执行；而C和D都被{}保护着一起跳过了。

### 示例5：数字大小比较器（综合练习）

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    
    cout << "===== 数字大小比较器 =====" << endl;
    cout << "请输入第一个整数：";
    cin >> a;
    cout << "请输入第二个整数：";
    cin >> b;
    
    cout << "\n—— 比较结果 ——" << endl;
    
    // 分别用三种比较
    if (a > b) {
        cout << a << " 大于 " << b << " —— 第一个数更大！" << endl;
    }
    if (a < b) {
        cout << a << " 小于 " << b << " —— 第二个数更大！" << endl;
    }
    if (a == b) {
        cout << a << " 等于 " << b << " —— 两个数一样大！" << endl;
    }
    
    // 额外判断：是否为特殊数字
    if (a == 0 || b == 0) {
        cout << "💡 提示：你输入了数字 0！任意数加0还是它自己哦~" << endl;
    }
    
    cout << "\n谢谢使用，再见！" << endl;
    return 0;
}
```

**运行效果**：输入5和10 → 输出"5小于10——第二个数更大！"；输入7和7 → 输出"7等于7——两个数一样大！"

### 练习2：代码阅读——理解{}的作用

下面代码会输出什么？

```cpp
int x = -5;
if (x > 0)
    cout << "A";
    cout << "B";
```

**答案**：只输出 **B**。因为if条件`x > 0`不成立（-5不大于0），所以紧跟if的`cout << "A"`被跳过了。但是`cout << "B"`没有在花括号里，它不属于if的控制范围，所以它**总是会执行**。这就是忘记写花括号的经典陷阱！

### 练习4：偶数判断器

### 练习5：密码验证器

写一个简单的密码验证程序。预设正确密码为 `1234`（整数），让用户输入密码。如果密码正确，输出"密码正确，欢迎进入！"；如果密码错误，输出"密码错误，拒绝访问！"。

## 🏆 挑战任务

### 简易银行取款程序

写一个"简易银行取款"程序：定义余额变量`balance = 1000`，用户输入取款金额，如果余额足够就扣款并显示新余额，不够则提示余额不足。

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    double balance = 1000.00;
    double amount;
    
    cout << "========== 简易银行取款系统 ==========" << endl;
    cout << fixed << setprecision(2);
    cout << "当前余额：" << balance << " 元" << endl;
    cout << "--------------------------------------" << endl;
    cout << "请输入取款金额：";
    cin >> amount;
    
    if (amount > 0 && amount <= balance) {
        balance = balance - amount;
        cout << "取款成功！" << endl;
        cout << "取款金额：" << amount << " 元" << endl;
        cout << "剩余余额：" << balance << " 元" << endl;
    }
    
    if (amount > balance) {
        cout << "余额不足！取款失败。" << endl;
        cout << "当前余额仅：" << balance << " 元" << endl;
    }
    
    if (amount <= 0) {
        cout << "请输入有效的取款金额（大于0）！" << endl;
    }
    
    cout << "======================================" << endl;
    return 0;
}
```

| 知识点 | 说明 |
|--------|------|
| if语句格式 | `if (条件) { 代码块; }` |
| 条件的结果 | 只能是 true（成立）或 false（不成立） |
| 代码块 {} | 把多条语句变成一个整体，建议**永远**写花括号 |
| 比较运算符 | `>` `<` `>=` `<=` `==` `!=` |
