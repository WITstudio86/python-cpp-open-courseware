## 二、课前引入：生活中的冒泡排序 🫧

### 2.1 气泡上浮的启发

同学们，你们喝过汽水吗？打开一瓶汽水，你会看到许许多多的小气泡从瓶底"咕噜咕噜"地往上冒。**越大的气泡，上升得越快，最终浮到水面的最上面。**

冒泡排序（Bubble Sort）的名字就来源于这个现象。在排序过程中，我们让**较大的数字像大气泡一样，一点一点地"浮"到数组的末尾**。每一轮排序，当前最大的数字就会像气泡一样浮到最后面的位置。

### 2.2 一个生活中的例子

想象体育课上，老师让同学们按身高从矮到高排成一排。有一种"笨办法"可以做到：

- 从队伍最左边开始，让相邻的两个同学比一比身高
- 如果左边的同学比右边的高，两个人就交换位置
- 一直比到队伍最右边，最高的同学自然就站到了最后

这不就是冒泡排序吗？每一轮"冒泡"，都把当前最高的人"挤"到了队伍的末尾。重复几轮之后，整支队伍就从矮到高排好了！

## 三、算法步骤详解 📖

### 3.1 核心思想

冒泡排序的核心操作只有两个：**比较**和**交换**。

**算法流程：**
1. 从数组的第一个元素开始，依次比较相邻的两个元素（第 j 个和第 j+1 个）
2. 如果前面的元素 **大于** 后面的元素（`arr[j] > arr[j+1]`），就交换它们的位置
3. 第一轮比较完 `n-1` 次之后，**最大的元素一定会"冒泡"到数组的最后一个位置**
4. 第二轮只需要比较前 `n-2` 次（因为最后一个已经排好了）
5. 重复以上步骤，每一轮的比较范围缩小 1
6. 当某一轮没有任何交换发生时，或者所有轮次完成时，排序结束

### 3.2 图解冒泡排序过程

以数组 **`[5, 3, 8, 1, 6]`** 为例，我们来一步一步看冒泡排序是怎么工作的。

#### 初始状态
```
索引:  0   1   2   3   4
数值: [5,  3,  8,  1,  6]
```

#### 第 1 轮（`i = 0`）：找出最大值 8，放到最后

```
j=0: 比较 arr[0]=5 和 arr[1]=3
     5 > 3 → 交换！
     结果: [3, 5, 8, 1, 6]

j=1: 比较 arr[1]=5 和 arr[2]=8
     5 < 8 → 不交换
     结果: [3, 5, 8, 1, 6]

j=2: 比较 arr[2]=8 和 arr[3]=1
     8 > 1 → 交换！
     结果: [3, 5, 1, 8, 6]

j=3: 比较 arr[3]=8 和 arr[4]=6
     8 > 6 → 交换！
     结果: [3, 5, 1, 6, 8]  ← 8 已经"冒泡"到最后啦！
```

#### 第 2 轮（`i = 1`）：找出次大值 6，放到倒数第二

```
j=0: 比较 arr[0]=3 和 arr[1]=5 → 不交换 → [3, 5, 1, 6, 8]
j=1: 比较 arr[1]=5 和 arr[2]=1 → 5>1，交换！→ [3, 1, 5, 6, 8]
j=2: 比较 arr[2]=5 和 arr[3]=6 → 不交换 → [3, 1, 5, 6, 8]
     第2轮结束，6 已经在正确位置！注意：j 只到 n-1-i = 3
```

#### 第 3 轮（`i = 2`）

```
j=0: 比较 3 和 1 → 3>1，交换！→ [1, 3, 5, 6, 8]
j=1: 比较 3 和 5 → 不交换
     第3轮结束，5 就位！
```

#### 第 4 轮（`i = 3`）

```
j=0: 比较 1 和 3 → 不交换
     第4轮结束，排序完成！
```

**最终结果：`[1, 3, 5, 6, 8]`** ✅

### 3.3 关键规律总结

| 轮数 `i` | 比较范围 `j` 从 0 到 | 比较次数 | 本轮的"气泡" |
|:--------:|:---------------------:|:--------:|:------------:|
| 第 1 轮  | `n-2` (即 `n-1-0`)   | n-1 = 4  | 最大值 8     |
| 第 2 轮  | `n-3` (即 `n-1-1`)   | n-2 = 3  | 次大值 6     |
| 第 3 轮  | `n-4` (即 `n-1-2`)   | n-3 = 2  | 第三大值 5   |
| 第 4 轮  | `n-5` (即 `n-1-3`)   | n-4 = 1  | 第四大值 3   |

**规律：** 第 `i` 轮（从 0 开始），内层循环 `j` 的范围是 `0` 到 `n-2-i`，共比较 `n-1-i` 次。

## 四、交换操作的秘密 🔄

在 C++ 中，交换两个变量的值不能直接写 `a = b; b = a;`（想想为什么？）。

正确的方法是使用一个**临时变量**，就像两个小朋友交换座位，需要一个空位暂时站一下：

```cpp
int temp = arr[j];      // 第①步：把 arr[j] 暂存到 temp（腾出位置）
arr[j] = arr[j + 1];    // 第②步：把 arr[j+1] 的值放到 arr[j]
arr[j + 1] = temp;      // 第③步：把暂存的值放到 arr[j+1]
```

> 💡 **小贴士：** 可以把 `temp` 想象成一个"中转站"或者"临时仓库"，交换两件物品时总要有个地方先暂放一下！

## 五、代码实现 💻

### 5.1 基础冒泡排序（从小到大排列）

```cpp
#include <iostream>
using namespace std;

int main() {
    // 待排序的数组
    int arr[] = {5, 3, 8, 1, 6};
    int n = 5;  // 数组长度

    cout << "排序前：";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    // 冒泡排序 —— 外层循环控制轮数
    for (int i = 0; i < n - 1; i++) {
        // 内层循环进行相邻比较和交换
        // j 从 0 到 n-2-i，每轮比较范围缩小 1
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {   // 前面的比后面的大
                // 交换 arr[j] 和 arr[j+1]
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }

    cout << "排序后：";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}
```

**运行结果：**
```
排序前：5 3 8 1 6
排序后：1 3 5 6 8
```

### 5.2 带优化标志的冒泡排序（提前退出）

有时候，数组可能在中间某一轮就已经排好序了，后面的比较完全是浪费时间。我们可以加一个**标志位 `swapped`** 来检测：如果某一轮一次交换都没有发生，说明数组已经完全有序，可以直接结束！

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[] = {5, 3, 8, 1, 6};
    int n = 5;

    cout << "排序前：";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    // 优化版冒泡排序
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;  // 本轮是否发生了交换

        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                // 交换
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;  // 标记发生了交换
            }
        }

        // 如果本轮没有发生任何交换，说明已经排好序了
        if (!swapped) {
            cout << "第 " << i + 1 << " 轮没有发生交换，数组已有序，提前结束！" << endl;
            break;  // 退出外层循环
        }
    }

    cout << "排序后：";
    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    return 0;
}
```

> 📌 **优化效果：** 如果原始数组是 `[1, 2, 3, 5, 4]`，不带优化的版本仍然会比较 4 轮（共 10 次），而优化版第 1 轮交换一次后发现 `4` 和 `5` 归位后，后面的轮次可能更早结束。对于**已经基本有序**的数组，优化效果非常明显！

## 六、时间复杂度简单介绍 ⏱️

### 6.1 什么是时间复杂度？

时间复杂度用来描述一个算法**随着数据规模增大，执行时间增长的速度**。我们不需要精确计算秒数，而是关心"当 n 翻倍时，工作量大约翻几倍"。

### 6.2 冒泡排序的时间复杂度

| 情况 | 比较次数 | 时间复杂度 | 说明 |
|:----:|:--------:|:----------:|:-----|
| 最坏情况（完全逆序）| n(n-1)/2 ≈ n² | **O(n²)** | 每一对相邻元素都需要比较和交换 |
| 最好情况（已经有序）| n-1 | **O(n)** | 优化版第一轮就发现没有交换，直接结束 |
| 平均情况 | n(n-1)/4 ≈ n² | **O(n²)** | 平均约一半的比较需要交换 |

对于 5 个数字，最坏情况需要比较 10 次，这很快。但如果是 1000 个数字，最坏情况需要比较约 50 万次！所以冒泡排序适合**数据量较小**的场景。

> 💡 **记忆口诀：** 冒泡排序两层循环，时间复杂度 **O(n²)**，适合小数据，大数据要用更快的排序方法（如快速排序）！

**题目：** 对数组 `[9, 2, 7, 4, 1]` 进行冒泡排序（从小到大），写出每一轮结束后的数组状态。

**答案：**

```
第1轮后：[2, 7, 4, 1, 9]   ← 最大值 9 浮到最后
第2轮后：[2, 4, 1, 7, 9]   ← 次大值 7 浮到倒数第二
第3轮后：[2, 1, 4, 7, 9]   ← 第三大值 4 就位
第4轮后：[1, 2, 4, 7, 9]   ← 排序完成
```

### 练习 2：从大到小排序

**题目：** 修改基础冒泡排序的代码，实现**从大到小**的降序排列。

**答案：** 只需要把比较条件 `>` 改成 `<` 即可！

```cpp
// 从大到小排序：只需要改一行！
if (arr[j] < arr[j + 1]) {   // 如果前面的比后面的小，就交换
    // 交换
    int temp = arr[j];
    arr[j] = arr[j + 1];
    arr[j + 1] = temp;
}
```

当 `arr[j] < arr[j+1]` 时交换，意思是"小的往后放，大的往前浮"，最终大的数字浮到前面，实现降序排列。

### 练习 3：判断对错

**题目：** 判断以下说法是否正确。

1. 冒泡排序每一轮都能确定一个元素的最终位置。（ ✅ 正确）
2. 外层循环 `i` 从 `0` 到 `n-1` 可以完成排序。（ ❌ 应该是 `n-2`，即 `i < n-1`）
3. 如果数组已经排好序，优化版的冒泡排序只需要一轮就能结束。（ ✅ 正确）
4. 冒泡排序是速度最快的排序算法。（ ❌ 快速排序、归并排序等都比它快）

## 八、挑战任务 🏆

### 题目：成绩排名系统

输入 5 个同学的成绩（0~100 分），用**优化版冒泡排序**从高到低排列，并输出排名！

**要求：**
1. 使用 `cin` 输入 5 个成绩
2. 使用带标志位的冒泡排序实现降序排列
3. 输出格式：`第1名：XX分`、`第2名：XX分` ...

**提示：**
- 降序排序只需把 `if (arr[j] > arr[j+1])` 改成 `if (arr[j] < arr[j+1])`
- 记得加 `swapped` 标志位优化

**参考答案：**

```cpp
#include <iostream>
using namespace std;

int main() {
    int scores[5];

    // 输入成绩
    cout << "请输入5个同学的成绩（0~100）：" << endl;
    for (int i = 0; i < 5; i++) {
        cout << "同学" << i + 1 << "的成绩：";
        cin >> scores[i];
    }

    // 冒泡排序（从高到低，降序）
    for (int i = 0; i < 4; i++) {
        bool swapped = false;
        for (int j = 0; j < 4 - i; j++) {
            if (scores[j] < scores[j + 1]) {  // 降序：大的往前浮
                int temp = scores[j];
                scores[j] = scores[j + 1];
                scores[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }

    // 输出排名
    cout << "\n========== 成绩排名 ==========" << endl;
    for (int i = 0; i < 5; i++) {
        cout << "第" << i + 1 << "名：" << scores[i] << "分" << endl;
    }

    return 0;
}
```

## 九、常见错误提醒 ⚠️

| 常见错误 | 为什么错 | 正确写法 |
|:---------|:---------|:---------|
| `j <= n - 1 - i` | 会越界访问 `arr[j+1]` | `j < n - 1 - i` |
| `i <= n - 1` | 多循环一轮，浪费计算 | `i < n - 1` |
| 忘记 `temp` 直接交换 | 会丢失数据 | 必须用临时变量三步交换 |
| 内层 `j` 从 1 开始 | 漏掉第一个元素的比较 | `j` 从 0 开始 |
