## 📖 知识讲解

### 什么是 char 类型？

在前面的课程里，我们学过 int 存储整数、double 存储小数。但是，如果要存储一个字母，比如 'A'、'b'、'X'，该用什么类型呢？答案就是 **char**（读作"查尔"，是 character 的缩写）。

char 类型专门用来存储**单个字符**。在 C++ 中，字符必须用**单引号** ' ' 括起来，这和字符串的双引号 " " 是不同的。

```cpp
char letter1 = 'A';      // ✅ 正确：用单引号
char letter2 = 'b';      // ✅ 正确
char number = '7';       // ✅ 这是字符'7'，不是数字7
// char bad = "A";       // ❌ 错误！不能用双引号
```

小智有一个装满了字母贴纸的盒子。他想知道 'A' 和 'a' 有什么区别，为什么字母可以"比较大小"，还发现字母竟然能"做加法"！原来，这一切都是因为藏在字符背后的秘密编码 —— ASCII。

**重要**：char 类型只能存储**一个**字符。如果要存储"Hello"这样的多个字符，需要用 string（字符串）类型，这个我们下一课会学到。

### ASCII 编码：字符的"身份证号码"

你有没有想过，电脑只能识别 0 和 1，那它是怎么处理字母的呢？

答案就是编码！就像每个同学都有学号一样，每个字符在计算机内部都有一个对应的**数字编号**。最常用的编码系统叫做 **ASCII**（American Standard Code for Information Interchange，美国标准信息交换码）。

ASCII 编码把字符和 0~127 之间的整数一一对应起来：

| 范围 | 对应字符 | 说明 |
|------|---------|------|
| 0 ~ 31 | 控制字符 | 不可见字符，如换行、回车 |
| 32 | 空格 ' ' | 空格字符 |
| 48 ~ 57 | '0' ~ '9' | 数字字符（注意：'0'的ASCII码是48，不是0！） |
| 65 ~ 90 | 'A' ~ 'Z' | 大写英文字母（共26个） |
| 97 ~ 122 | 'a' ~ 'z' | 小写英文字母（共26个） |

一个很重要的发现：大写字母和小写字母的 ASCII 码恰好相差 **32**！
- 'A' 的 ASCII 码是 65，'a' 的 ASCII 码是 97，差 97 - 65 = 32
- 'B' 的 ASCII 码是 66，'b' 的 ASCII 码是 98，差 98 - 66 = 32
- 依此类推，任意字母的大写和小写之间都差 32！

这就引出了一个非常有用的规律：

> **🔑 关键公式：**
> - 大写字母 + 32 = 对应的小写字母
> - 小写字母 - 32 = 对应的大写字母

```cpp
char lower = 'a';
char upper = lower - 32;   // upper 变成 'A'
cout << lower << " 变成大写是 " << upper << endl;
// 输出：a 变成大写是 A
```

### 字符和整数的"变身术"

因为字符在底层就是整数，所以 char 和 int 之间可以互相转换：

```cpp
char ch = 'A';
cout << "字符: " << ch << endl;           // 输出字符：A
cout << "ASCII码: " << (int)ch << endl;   // 输出整数：65

int num = 98;
cout << "数字: " << num << endl;          // 输出数字：98
cout << "对应字符: " << (char)num << endl; // 输出字符：b
```

这里 `(int)ch` 叫做**强制类型转换**，意思是"把这个变量当作 int 类型来看"。同样地，`(char)num` 就是把整数当作字符来看。

**想一想**：为什么 '7' 不等于 7？因为 '7' 的 ASCII 码是 55，而数字 7 就是 7。它们完全是两回事！

```cpp
cout << '7' + 1 << endl;   // 输出 56（55 + 1，因为'7'的ASCII码是55）
cout << 7 + 1 << endl;     // 输出 8
```

### 字符的比较

既然字符本质上是整数，那么字符之间当然可以比大小！比较的规则就是比较它们的 ASCII 码：

```cpp
cout << ('A' < 'B') << endl;   // 输出 1（真），因为 65 < 66
cout << ('a' > 'A') << endl;   // 输出 1（真），因为 97 > 65
cout << ('Z' < 'a') << endl;   // 输出 1（真），因为 90 < 97
cout << ('0' < 'A') << endl;   // 输出 1（真），因为 48 < 65
```

总结规律：**数字字符 < 大写字母 < 小写字母**。

利用这个特性，我们可以判断一个字符是不是大写字母：

```cpp
char ch = 'M';
if (ch >= 'A' && ch <= 'Z') {
    cout << ch << " 是大写字母！" << endl;
}
```

### 字符的算术运算

字符可以做加减法！规则是：字符 + 整数 = 新字符。

```cpp
char ch = 'A';
cout << ch + 1 << endl;       // 输出 66（整数）
cout << (char)(ch + 1) << endl; // 输出 B（字符）
cout << (char)(ch + 2) << endl; // 输出 C
cout << (char)(ch + 25) << endl; // 输出 Z
```

这个特性非常有用！比如：
- 用 for 循环轻松打印出 A 到 Z
- 实现大小写转换
- 制作简单的加密程序（比如凯撒密码）

> ⚠️ **注意事项**：
> 1. 字符运算的结果默认是 int 类型，如果要输出字符，记得转换成 char
> 2. 像 'A' + 'B' 这样的两个字符相加，结果是它们的 ASCII 码相加（65 + 66 = 131），一般没有实际意义
> 3. 字符加上太大的数字，可能会超出 ASCII 范围，得到意想不到的结果

### 常用的字符判断函数

C++ 的 `<cctype>` 头文件提供了一些方便的字符判断函数：

| 函数 | 作用 | 示例 |
|------|------|------|
| isupper(c) | 判断是否大写字母 | isupper('A') → true |
| islower(c) | 判断是否小写字母 | islower('z') → true |
| isdigit(c) | 判断是否数字字符 | isdigit('5') → true |
| isalpha(c) | 判断是否字母 | isalpha('x') → true |
| isspace(c) | 判断是否空白字符 | isspace(' ') → true |
| toupper(c) | 转成大写字母 | toupper('a') → 'A' |
| tolower(c) | 转成小写字母 | tolower('Z') → 'z' |

### 生活中的应用：简单加密

古罗马的凯撒大帝用过一个简单的加密方法：把每个字母向后移动固定的位数。比如后移3位，A变成D，B变成E，……，X变成A（循环回来）。

这就是**凯撒密码**，是利用 ASCII 码最经典的应用！

```cpp
char letter;
int shift = 3;
cout << "输入一个字母：";
cin >> letter;

// 加密：字母后移shift位
char encrypted = letter + shift;
cout << "加密后：" << encrypted << endl;

// 解密：字母前移shift位
char decrypted = encrypted - shift;
cout << "解密后：" << decrypted << endl;
```

> ⚠️ 上面的简单版凯撒密码有个问题：如果输入的是 'X'、'Y'、'Z'，后移3位就超出了 'Z' 的范围。完整版的凯撒密码需要处理回绕，这留给大家作为挑战任务！

## 💻 示例代码

### 示例1：char 类型的基本用法和 ASCII 码查询

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. 声明并初始化 char 变量
    cout << "===== char 类型基本用法 =====" << endl;
    char grade = 'A';        // 成绩等级
    char symbol = '#';       // 特殊符号
    char digit = '7';        // 数字字符（注意：不是数字7！）

    cout << "成绩等级：" << grade << endl;
    cout << "特殊符号：" << symbol << endl;
    cout << "数字字符：" << digit << endl;
    cout << "数字字符的 ASCII 码：" << (int)digit << endl;

    // 2. 查询任意字符的 ASCII 码
    cout << "===== 任意字符查询 =====" << endl;
    char query;
    cout << "请输入一个字符，我来告诉你它的 ASCII 码：";
    cin >> query;

    cout << "字符 '" << query << "' 的 ASCII 码是：" << (int)query << endl;

    return 0;
}
```

### 示例2：大写字母表生成 + 大小写转换

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. 用 for 循环打印大写字母表（A~Z）
    cout << "===== 大写字母表 =====" << endl;
    for (char c = 'A'; c <= 'Z'; c++) {
        cout << c << " ";
    }
    cout << endl;

    // 2. 打印小写字母表（a~z）
    cout << "\n===== 小写字母表 =====" << endl;
    for (char c = 'a'; c <= 'z'; c++) {
        cout << c << " ";
    }
    cout << endl;

    // 3. 演示大小写转换
    cout << "\n===== 大小写转换演示 =====" << endl;
    char ch = 'K';
    cout << "原字母：" << ch
         << " (ASCII码：" << (int)ch << ")" << endl;

    // 大写转小写：+32
    char lowerCh = ch + 32;
    cout << "转小写：" << lowerCh
         << " (ASCII码：" << (int)lowerCh << ")" << endl;

    // 小写转大写：-32
    char upperCh = lowerCh - 32;
    cout << "再转大写：" << upperCh
         << " (ASCII码：" << (int)upperCh << ")" << endl;

    return 0;
}
```

### 示例3：简单凯撒密码加密器

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "===== 🔐 凯撒密码加密器 =====" << endl;
    cout << "规则：把小写字母后移3位进行加密\n" << endl;

    // 输入明文
    cout << "请输入一个小写字母（a-z）：";
    char letter;
    cin >> letter;

    // 判断输入是否合法
    if (letter >= 'a' && letter <= 'z') {
        // 加密：后移3位
        char encrypted = letter + 3;

        // 处理超出范围的情况（回绕）
        if (encrypted > 'z') {
            encrypted = encrypted - 26;  // 从头开始
        }

        cout << "\n--- 加密结果 ---" << endl;
        cout << "原文：" << letter << "（ASCII码：" << (int)letter << "）" << endl;
        cout << "密文：" << encrypted << "（ASCII码：" << (int)encrypted << "）" << endl;
        cout << "\n💡 把" << letter << "后移3位就得到了" << encrypted << "！" << endl;
    } else {
        cout << "❌ 请输入小写字母（a-z）！" << endl;
    }

    return 0;
}
```

### 练习2：大小写魔术师 🎩

编写程序：输入一个大写字母，输出它的小写形式，并同时输出原字母后移5位的结果（要处理超出 'z' 的回绕）。

**参考答案：**
```cpp
#include <iostream>
using namespace std;

int main() {
    char upper;
    cout << "请输入一个大写字母：";
    cin >> upper;

    if (upper >= 'A' && upper <= 'Z') {
        // 转小写
        char lower = upper + 32;
        cout << "小写形式：" << lower << endl;

        // 后移5位（作为小写字母处理）
        char shifted = lower + 5;
        if (shifted > 'z') {
            shifted = shifted - 26;  // 超出则回绕
        }
        cout << "后移5位：" << shifted << endl;
    } else {
        cout << "请输入大写字母（A-Z）！" << endl;
    }

    return 0;
}
```

### 练习3：字符分类器 📊

编写程序：输入一个字符，判断它是大写字母、小写字母、数字还是其他字符。

**参考答案：**
```cpp
#include <iostream>
using namespace std;

int main() {
    char ch;
    cout << "请输入一个字符：";
    cin >> ch;

    cout << "\n分析结果：字符 '" << ch << "' ";

    if (ch >= 'A' && ch <= 'Z') {
        cout << "是一个大写字母" << endl;
    } else if (ch >= 'a' && ch <= 'z') {
        cout << "是一个小写字母" << endl;
    } else if (ch >= '0' && ch <= '9') {
        cout << "是一个数字字符" << endl;
    } else {
        cout << "是其他字符（可能是标点符号或特殊符号）" << endl;
    }

    cout << "它的 ASCII 码是：" << (int)ch << endl;

    return 0;
}
```

## 🏆 挑战任务

### 完整的凯撒密码加密/解密系统

编写一个"凯撒密码"程序，要求：
1. 用户可以输入任意一句英文（仅小写字母和空格）
2. 用户可以指定偏移量（1~25之间的整数）
3. 程序输出加密后的密文
4. 加密时，空格保持不变，小写字母按偏移量后移（超出 'z' 就回绕到 'a' 继续）
5. 额外加分：程序还能解密，把密文还原为原文

**提示：**
- 用 `getline(cin, str)` 读取整行文本（需要 `#include <string>`）
- 用 `str.length()` 获取字符串长度
- 用 for 循环遍历每个字符

**思路点拨：**
1. 对于字母 c，加密公式为 `(c - 'a' + shift) % 26 + 'a'`
2. 这个公式的妙处：`c - 'a'` 把字母变成 0~25 的数字，加上偏移量后 `% 26` 保证不超出范围，最后 `+ 'a'` 变回字母
3. 解密时，把 `shift` 换成 `26 - shift` 即可

## 📝 本课小结

- **char 类型**：用于存储单个字符，字符必须用单引号括起来，如 `'A'`、`'7'`、`'#'`
- **ASCII 编码**：每个字符对应一个 0~127 的整数编号。大写字母（65~90）、小写字母（97~122）、数字字符（48~57）
- **字符与整数可以转换**：用 `(int)` 把字符转成 ASCII 码，用 `(char)` 把数字转成字符
- **大小写关系**：大写字母 + 32 = 对应小写字母，小写字母 - 32 = 对应大写字母
- **字符可以比较**：因为底层是数字，所以 'A' < 'a'、'0' < 'A' 等
- **字符可以做加减运算**：'A' + 1 = 'B'，利用这个可以做字母表的打印、大小写转换和简单加密
- **实用技巧**：利用 ASCII 编码可以制作密码程序、字符处理工具，是编程中非常实用的基础知识
- **常用函数（`<cctype>`）**：isupper()、islower()、isdigit()、toupper()、tolower() 等可以方便地判断和转换字符

> 🔑 **口诀：**
> 字母背后藏数字，ASCII 编码记心间；
> 大写小写差三二，字符也能做加减；
> 加密解密都靠它，密码达人就是你！
