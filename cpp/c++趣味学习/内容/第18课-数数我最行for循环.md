## 📖 知识讲解

### 什么是for循环？

上一课我们学了while循环，它像一个"条件哨兵"——只要满足条件就继续执行。但很多时候，我们提前就知道要循环多少次，比如"打印1到10"、"重复5次"。这时候，for循环就是更好的选择！

for循环就像一个计步器：你设定好从哪开始、到哪结束、每步走多远，然后它就能精确地走完这段路。

### for循环的三要素

for循环的语法把三个重要部分都写在了括号里，一目了然：

```cpp
for (初始化; 条件; 更新) {
    // 循环体
}
```

- **初始化**：循环开始前执行一次，通常用来定义循环变量并赋初值。比如`int i = 1`
- **条件**：每次循环前检查，为真就继续，为假就停止。比如`i <= 10`
- **更新**：每次循环体执行完后执行，通常用来改变循环变量。比如`i++`

用一个生活中的例子来理解：你在操场上跑步，老师让你跑5圈。

- 初始化：从第1圈开始数 → `int lap = 1`
- 条件：还没到第6圈 → `lap <= 5`
- 更新：每跑完一圈，圈数加1 → `lap++`

```cpp
for (int lap = 1; lap <= 5; lap++) {
    cout << "正在跑第" << lap << "圈！加油！" << endl;
}
```

### for循环的执行顺序

很多同学会搞混for循环的执行顺序，让我们用一张图来说明：

```
        第1步：初始化（只执行一次）
               ↓
    ┌→ 第2步：检查条件
    │         ↓ (真)
    │    第3步：执行循环体
    │         ↓
    │    第4步：执行更新
    │         ↓
    └─── 回到第2步
              ↓ (假)
         第5步：循环结束
```

**重要：** 更新语句是在循环体执行完毕后才执行的！比如：

```cpp
for (int i = 1; i <= 3; i++) {
    cout << "循环体中 i = " << i << endl;
}
// 输出：
// 循环体中 i = 1
// 循环体中 i = 2
// 循环体中 i = 3
// 循环结束后，跳出循环
```

### for循环 vs while循环

什么时候用for，什么时候用while？这里有一个简单的原则：

- **知道循环次数** → 用for。比如"打印乘法表"、"遍历数组"
- **不知道循环次数** → 用while。比如"猜数字直到猜对"、"等待用户输入q退出"

其实for和while可以互相转换！下面的两段代码是完全等价的：

```cpp
// for版本
for (int i = 1; i <= 10; i++) {
    cout << i << " ";
}

// while版本（等价）
int i = 1;
while (i <= 10) {
    cout << i << " ";
    i++;
}
```

### 循环变量的作用域

在for循环的初始化部分定义的变量，它的"生命"只在循环内部。循环结束后，这个变量就"消失"了：

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << " ";  // 这里可以访问i
}
// cout << i;  // ❌ 错误！循环结束后i已经不存在了！
```

如果需要在循环外使用循环变量，可以在循环前定义：

```cpp
int i;
for (i = 1; i <= 5; i++) {
    cout << i << " ";
}
cout << "循环结束后 i = " << i << endl;  // ✅ 输出 i = 6
```

### for循环的花式写法

for循环非常灵活，每部分都可以省略（但分号不能省）：

```cpp
// 多个变量同时初始化
for (int i = 1, j = 10; i <= 5; i++, j--) {
    cout << "i=" << i << " j=" << j << endl;
}

// 省略初始化（变量已在外部定义）
int i = 1;
for (; i <= 5; i++) {
    cout << i << " ";
}

// ⚠️ 死循环：三部分全省略
// for (;;) { cout << "无限循环！" << endl; }
```

## 💻 示例代码

### 示例1：制作乘法口诀表

```cpp
#include <iostream>
#include <iomanip>  // 用于setw设置输出宽度
using namespace std;

int main() {
    cout << "📐 九九乘法口诀表" << endl;
    cout << "==============================" << endl;

    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= i; j++) {
            // setw(2)让每个数字占2个字符宽度，对齐美观
            cout << j << "×" << i << "=" << setw(2) << i * j << "  ";
        }
        cout << endl;  // 每行结束换行
    }

    return 0;
}
```

### 示例2：分数统计器

```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 0;        // 学生人数
    double score, total = 0, maxScore = 0, minScore = 100;

    cout << "请输入学生人数：";
    cin >> count;

    for (int i = 1; i <= count; i++) {
        cout << "请输入第" << i << "位同学的成绩：";
        cin >> score;

        total += score;                      // 累加总分
        if (score > maxScore) maxScore = score;  // 更新最高分
        if (score < minScore) minScore = score;  // 更新最低分
    }

    cout << "📊 成绩统计：" << endl;
    cout << "平均分：" << total / count << endl;
    cout << "最高分：" << maxScore << endl;
    cout << "最低分：" << minScore << endl;

    return 0;
}
```

## 🎮 趣味练习

### 练习1：偶数特工

使用for循环打印1到100之间的所有偶数。

**参考答案：**
```cpp
for (int i = 2; i <= 100; i += 2) {
    cout << i << " ";
}
// 或者
for (int i = 1; i <= 100; i++) {
    if (i % 2 == 0) cout << i << " ";
}
```

### 练习2：阶乘计算器

输入一个正整数n（n <= 12，因为13的阶乘太大了），计算n的阶乘（n! = 1×2×3×...×n）。

**参考答案：**
```cpp
int n;
long long factorial = 1;  // 用long long防止溢出
cout << "请输入n：";
cin >> n;
for (int i = 1; i <= n; i++) {
    factorial *= i;
}
cout << n << "! = " << factorial << endl;
```

### 斐波那契数列

斐波那契数列是这样的：1, 1, 2, 3, 5, 8, 13, 21, 34...（从第三项开始，每一项等于前两项之和）。

使用for循环输出斐波那契数列的前20项，每输出5个换一行。

**提示：** 你需要用三个变量：当前项`c`、前一项`a`、前两项`b`。每次循环更新它们的关系。

## 📝 本课小结

- **for循环**把初始化、条件、更新集中写在一起，格式为`for(初始化;条件;更新){循环体}`
- for循环的执行顺序是：初始化→条件检查→循环体→更新→条件检查→...
- **知道循环次数**时优先用for，**不知道次数**时用while
- for循环中定义的变量只在循环内有效，循环结束后就"消失"了
- for循环的每一部分都可以省略，甚至能写出`for(;;)`这样的死循环
- for循环特别适合和计数、遍历相关的任务，比如打印乘法表、统计数据等
