# 第08课：数字的多样性——变量类型

## 🎯 学习目标
- 认识C++中的常用数据类型：`int`、`double`、`char`、`bool`、`string`
- 理解每种类型的用途和特点
- 学会使用 `sizeof()` 查看数据类型的大小
- 能够根据需求选择合适的变量类型

## 📖 知识讲解

### 为什么需要不同的数据类型？

你有没有想过，为什么图书馆要把书分类？小说类、科普类、绘本类……分类之后，找书就方便多了。同样，电脑也需要对数据进行分类——这就是**数据类型**。

不同的数据有不同的特点：
- 年龄：永远是整数（10岁，不是10.5岁）
- 身高：可能是小数（1.45米）
- 名字：是文字
- 是否及格：只有"是"或"不是"两种情况

C++为不同的数据准备了不同的"柜子类型"，各有各的用途。今天我们就来参观这个"数据类型大观园"！

### 数据类型一览表

| 类型 | 关键字 | 存储内容 | 例子 | 占内存 |
|------|--------|----------|------|--------|
| 整数 | `int` | 整数 | 10, -5, 2026 | 4字节 |
| 浮点数 | `double` | 小数（双精度） | 3.14, -0.5, 2.0 | 8字节 |
| 字符 | `char` | 单个字符 | 'A', '7', '+' | 1字节 |
| 布尔 | `bool` | 真/假 | true, false | 1字节 |
| 字符串 | `string` | 一串文字 | "Hello" | 可变 |

> 注意：`string` 需要 `#include <string>` 才能使用哦！

### 1. int —— 整数型

`int` 我们已经很熟悉了，它用来存储整数。

```cpp
int age = 10;          // 年龄
int score = 98;        // 分数
int year = 2026;       // 年份
int temperature = -5;  // 可以是负数
int population = 1400000000;  // 可以很大（约21亿以内）
```

`int` 的范围大约是 **-21亿到21亿**（-2,147,483,648 到 2,147,483,647）。对于大多数情况来说足够了，但如果要存储更大的数（比如地球到太阳的距离），就需要更大的类型了。

### 2. double —— 小数型（浮点数）

生活中有很多小数：身高1.45米、体温36.5度、圆周率3.14159……这些都需要用 `double` 来存储。

```cpp
double pi = 3.14159;      // 圆周率
double height = 1.45;     // 身高（米）
double price = 12.50;     // 价格
double avg = 95.5;        // 平均分
double g = 9.8;           // 重力加速度
```

`double` 是 "double precision floating point"（双精度浮点数）的缩写。它能存储非常大或非常小的数，精度也很高（大约15-17位有效数字）。

注意：`int` 和 `double` 之间的运算会把 `int` 自动转换成 `double`：
```cpp
int a = 5;
double b = 2.5;
cout << a + b << endl;  // 输出 7.5（int自动转为double）
cout << a / 2 << endl;  // 输出 2（整数除法！）
cout << a / 2.0 << endl;  // 输出 2.5（因为2.0是double）
```

这个例子很重要：`5 / 2` 结果是 `2`（整数除法，舍去小数），而 `5 / 2.0` 结果是 `2.5`。

### 3. char —— 字符型

`char` 是 "character"（字符）的缩写，用来存储**单个字符**。注意哦，是"单个"，不是一个单词或一句话。

```cpp
char grade = 'A';       // 等级
char firstLetter = 'X'; // 名字首字母
char digit = '7';       // 数字字符（注意是字符7，不是数字7！）
char symbol = '+';      // 符号
char space = ' ';       // 空格也是一个字符
```

`char` 类型的值要用**单引号** `' '` 括起来（不是双引号！）。`'A'` 是一个字符，`"A"` 是一个字符串，虽然它们看起来很像，但在C++中是不同的类型。

### 4. bool —— 布尔型（真假型）

`bool` 是最简单的类型——它只有两个值：`true`（真）和 `false`（假）。

```cpp
bool isRaining = false;     // 今天没下雨
bool isPassed = true;       // 考试通过了
bool hasHomework = true;    // 有作业
bool isWeekend = false;     // 不是周末
```

`bool` 类型虽然简单，但在后面的课程中非常重要——它用来控制程序的"选择"和"判断"。

### 5. string —— 字符串型

`string` 用来存储一串文字（字符串）。和 `char` 不同，`string` 可以存储多个字符。

```cpp
string name = "小明";            // 名字
string school = "阳光小学";       // 学校
string greeting = "Hello World";  // 问候语
string empty = "";                // 空字符串
```

`string` 要用**双引号** `" "` 括起来。使用 `string` 之前记得 `#include <string>`！

### sizeof —— 测量数据类型的大小

C++提供了一个神奇的工具——`sizeof()`，它可以告诉我们每种数据类型占用多少字节的内存。

```cpp
cout << "int占用：" << sizeof(int) << "字节" << endl;
cout << "double占用：" << sizeof(double) << "字节" << endl;
cout << "char占用：" << sizeof(char) << "字节" << endl;
cout << "bool占用：" << sizeof(bool) << "字节" << endl;
```

1字节（Byte）= 8比特（bit）。比特是电脑最小的存储单位，只能是0或1。1字节可以表示256种不同的值（比如0到255）。

### 如何选择正确的数据类型？

这是一个很重要的技能！选择类型的经验法则：

| 你要存什么 | 用什么类型 | 例子 |
|-----------|-----------|------|
| 整数（年龄、数量、分数） | `int` | 10, 98, 2026 |
| 小数（价格、身高、平均分） | `double` | 12.50, 1.45, 95.5 |
| 单个字符（等级、首字母） | `char` | 'A', 'X' |
| 是/否（开关、对错） | `bool` | true, false |
| 一串文字（名字、句子） | `string` | "小明" |

## 💻 示例代码

### 示例1：数据类型展示
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 各种数据类型
    int age = 10;
    double height = 1.45;
    char grade = 'A';
    bool isHappy = true;
    string name = "小明";

    cout << "===== 数据类型展示 =====" << endl;
    cout << "int（整数）：" << age << "岁" << endl;
    cout << "double（小数）：" << height << "米" << endl;
    cout << "char（字符）：" << grade << "等" << endl;
    cout << "bool（真假）：" << isHappy << "（1=true, 0=false）" << endl;
    cout << "string（字符串）：" << name << endl;

    return 0;
}
```

### 示例2：sizeof 测量内存大小
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    cout << "===== 数据类型大小测量 =====" << endl;
    cout << "int 占用：" << sizeof(int) << " 字节" << endl;
    cout << "double 占用：" << sizeof(double) << " 字节" << endl;
    cout << "char 占用：" << sizeof(char) << " 字节" << endl;
    cout << "bool 占用：" << sizeof(bool) << " 字节" << endl;
    cout << "string 占用：" << sizeof(string) << " 字节（固定部分）" << endl;

    // 也可以测量变量的大小
    int num = 100;
    double pi = 3.14;
    cout << "变量num占用：" << sizeof(num) << " 字节" << endl;
    cout << "变量pi占用：" << sizeof(pi) << " 字节" << endl;

    return 0;
}
```

### 示例3：类型转换演示
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 10;
    int b = 3;
    double c = 3.0;

    cout << "===== 类型转换 =====" << endl;
    cout << "10 / 3 = " << a / b << "（整数除法，结果是整数）" << endl;
    cout << "10 / 3.0 = " << a / c << "（有double参与，结果是小数）" << endl;
    cout << "10.0 / 3 = " << 10.0 / b << "（同上）" << endl;

    // 显式转换
    cout << "把double转成int：" << (int)3.99 << "（小数被丢弃）" << endl;

    return 0;
}
```

### 示例4：学生信息管理系统
```cpp

    cout << "平均成绩：" << averageScore << "分" << endl;

    return 0;
}
```

### 练习2：sizeof小实验
写一个程序，用 `sizeof` 测量你在程序中定义的5个不同变量的内存占用，看看它们各有多大。

**参考答案：**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int a = 10;
    double b = 3.14;
    char c = 'X';

    cout << "char变量c：" << sizeof(c) << "字节" << endl;
    cout << "bool变量d：" << sizeof(d) << "字节" << endl;
    cout << "string变量e：" << sizeof(e) << "字节" << endl;

    return 0;
}
```

## 🏆 挑战任务

### 挑战：制作"我的数据名片"

用所有学过的数据类型，制作一张"我的数据名片"程序。要求：

1. 至少使用 `int`、`double`、`char`、`bool`、`string` 各一次
2. 用 `sizeof` 测量至少3个变量的大小
3. 在输出中展示每个变量的类型、值和大小
4. 设计漂亮的输出格式

**参考示例：**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 定义各种类型的变量
    string name = "小明";
    int age = 10;
    double height = 1.45;
    char favoriteLetter = 'C';
    bool loveCoding = true;

    cout << "🌟 ================================ 🌟" << endl;
    cout << "           我的数据名片" << endl;
    cout << "🌟 ================================ 🌟" << endl;
    cout << endl;

    // 展示每个变量
    cout << "📛 姓名（string）：" << name;
    cout << " | 占用 " << sizeof(name) << " 字节（固定部分）" << endl;

    cout << "🎂 年龄（int）：" << age << "岁";
    cout << " | 占用 " << sizeof(age) << " 字节" << endl;

    cout << "📏 身高（double）：" << height << "米";
    cout << " | 占用 " << sizeof(height) << " 字节" << endl;

    cout << "🔤 最喜欢字母（char）：" << favoriteLetter;
    cout << " | 占用 " << sizeof(favoriteLetter) << " 字节" << endl;

    cout << "💻 喜欢编程（bool）：" << (loveCoding ? "是" : "否");
    cout << " | 占用 " << sizeof(loveCoding) << " 字节" << endl;

    cout << endl;
    cout << "🌟 ================================ 🌟" << endl;
    cout << "  数据总大小：" << sizeof(name) + sizeof(age) + sizeof(height)
         + sizeof(favoriteLetter) + sizeof(loveCoding) << " 字节" << endl;
    cout << "🌟 ================================ 🌟" << endl;

    return 0;
}
```
