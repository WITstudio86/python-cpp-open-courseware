# 第32课：像素小画家——二维数组趣味应用

## 课程导入

同学们，你们玩过"像素画"吗？在电脑上，每一张图片都是由成千上万个小小的"像素点"组成的。每个像素点就是一个颜色值，所有的像素按照行和列整齐排列，就构成了我们看到的图像。

在C++的世界里，我们也能用二维数组来创作"字符画"！把二维字符数组想象成一张画布，每个格子就是一个"像素"，我们可以用不同的字符（比如 `*`、`#`、`@`、空格等）来填充这些格子，从而画出各种有趣的图案。

想象一下：如果用 `*` 号在控制台上画出一个三角形、一个菱形，甚至是一个爱心，是不是很酷？更厉害的是，我们还可以用不同的数字代表不同的地形（0代表海洋，1代表陆地，2代表高山），用二维数组来模拟一个简单的地图！

小华是班上的"像素艺术家"，他喜欢用字符在控制台上创作各种图案。从简单的三角形开始，到复杂的菱形和空心正方形，每次创作都让他感到无比满足。他说："写代码就像画画，只不过画笔变成了键盘，画布变成了二维数组！"

今天，我们就来当一把"像素小画家"，用二维数组在控制台上创作属于自己的字符画！

## 核心概念

### 1. 二维字符数组——我们的画布

二维字符数组就像一个方格画布，每个格子可以存放一个字符：

```cpp
// 创建一个 10行×10列 的画布，全部初始化为空格
char canvas[10][10];
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        canvas[i][j] = ' ';  // 先涂成"空白"
    }
}
```

画布的"绘制"过程就是给数组的特定位置赋值。比如 `canvas[2][3] = '*'` 就是在第3行第4列画了一个星星。

### 2. 图案填充的规律

绘制图案的关键在于找到**行号 i** 和 **列号 j** 之间的关系。只要掌握了这个规律，就能用两层循环画出各种形状！

**直角三角形（左下角）：**
```
*         第0行：第0列到第0列（j <= 0）
**        第1行：第0列到第1列（j <= 1）
***       第2行：第0列到第2列（j <= 2）
****      第3行：第0列到第3列（j <= 3）
```
规律：第 i 行，从第 0 列画到第 i 列 —— 条件就是 `j <= i`。

**等腰三角形（居中对齐）：**
```
   *       第0行：中间位置画1个*
  ***      第1行：中间位置画3个*
 *****     第2行：中间位置画5个*
```
规律：第 i 行画 `2*i+1` 个星星，起始列号 = `总行数 - i - 1`。

**菱形：**
```
   *       上半部分：等腰三角形
  ***
 *****
*******
 *****    下半部分：倒等腰三角形
  ***
   *
```
规律：先画上半部分的等腰三角形，再画下半部分的倒等腰三角形。

### 3. 空心形状

空心形状只在**边界**上画字符，内部留空。比如空心正方形：

```
****     第0行：画满
*  *     第1行到倒数第2行：只画第0列和最后一列
*  *     
****     最后一行：画满
```

规律：当 `i==0`（第一行）、`i==n-1`（最后一行）、`j==0`（第一列）、`j==n-1`（最后一列）时画字符，其余位置画空格。

### 4. 地图模拟——数字代表地形

我们还可以用整数二维数组来模拟地图，不同的数字代表不同的地形类型：

```cpp
// 0 = 海洋（~），1 = 陆地（.），2 = 高山（^），3 = 森林（T）
int map[5][5] = {
    {0, 0, 1, 1, 0},
    {0, 1, 2, 2, 1},
    {1, 2, 2, 2, 1},
    {0, 1, 2, 3, 1},
    {0, 0, 1, 1, 0}
};
```

然后遍历这个数组，根据数字输出对应的字符，就能在控制台上看到一幅"地形图"。

这种用数字模拟地形的思想，正是许多游戏地图编辑器的基础！比如经典的《超级马里奥》《我的世界》等游戏，底层都是用二维数组来存储地图信息的。

### 5. 嵌套循环的绘图模式

几乎所有的二维图案绘制都遵循同一个模式：

```cpp
for (int i = 0; i < 行数; i++) {        // 遍历每一行
    for (int j = 0; j < 列数; j++) {    // 遍历每一列
        if (/* 判断条件：这里放画图的规则 */) {
            cout << '*';   // 满足条件就画
        } else {
            cout << ' ';   // 不满足就留空
        }
    }
    cout << endl;   // 一行画完，换行
}
```

掌握了这个模式，你就能画出任何你想要的图案！

## 代码示例

### 示例1：画一个靠左的直角三角形

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;  // 三角形的高度
    
    cout << "直角三角形（左下角）：" << endl;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j <= i; j++) {
            cout << "* ";
        }
        cout << endl;
    }
    
    return 0;
}
```

**运行结果：**
```
直角三角形（左下角）：
* 
* * 
* * * 
* * * * 
* * * * * 
```

### 示例2：画一个居中的等腰三角形

```cpp
#include <iostream>
using namespace std;

int main() {
    int n = 5;  // 三角形的高度
    
    cout << "等腰三角形（居中）：" << endl;
    for (int i = 0; i < n; i++) {
        // 打印前面的空格
        for (int j = 0; j < n - i - 1; j++) {
            cout << "  ";
        }
        // 打印星星
        for (int j = 0; j < 2 * i + 1; j++) {
            cout << "* ";
        }
        cout << endl;
    }
    
    return 0;
}
```

**运行结果：**
```
等腰三角形（居中）：
        * 
      * * * 
    * * * * * 
  * * * * * * * 
* * * * * * * * * 
```

### 示例3：模拟简单地形图

```cpp
#include <iostream>
using namespace std;

int main() {
    const int R = 5, C = 5;
    // 0=海洋, 1=平原, 2=高山, 3=森林
    int map[R][C] = {
        {0, 0, 1, 1, 0},
        {0, 1, 2, 2, 1},
        {1, 2, 2, 2, 1},
        {0, 1, 2, 3, 1},
        {0, 0, 1, 1, 0}
    };
    
    cout << "简单地形图：" << endl;
    cout << "图例: ~ = 海洋  . = 平原  ^ = 高山  T = 森林" << endl << endl;
    
    for (int i = 0; i < R; i++) {
        for (int j = 0; j < C; j++) {
            switch (map[i][j]) {
                case 0: cout << "~ "; break;  // 海洋
                case 1: cout << ". "; break;  // 平原
                case 2: cout << "^ "; break;  // 高山
                case 3: cout << "T "; break;  // 森林
                default: cout << "? "; break;
            }
        }
        cout << endl;
    }
    
    return 0;
}
```

**运行结果：**
```
简单地形图：
图例: ~ = 海洋  . = 平原  ^ = 高山  T = 森林

~ ~ . . ~ 
~ . ^ ^ . 
. ^ ^ ^ . 
~ . ^ T . 
~ ~ . . ~ 
```

## 挑战任务：字符画创作大师

设计一个交互式的"字符画创作大师"程序，实现以下功能：

1. **菜单选择**：让用户从以下选项中选一个：
   - (A) 画实心矩形（输入宽、高和填充字符）
   - (B) 画等腰三角形（输入高度和填充字符）
   - (C) 画菱形（输入高度和填充字符）

4. **扩展创意**：尝试自己设计一个新的图案（比如箭头、爱心等），加入到菜单中。

## 本课小结

1. **二维字符数组**是我们创作字符画的"画布"，每个格子存放一个字符
2. 绘制图案的关键是找到**行号 i 和列号 j 的关系**，用嵌套循环 + 条件判断来实现
3. **实心形状**只需判断范围（如 j <= i），**空心形状**只需在边界位置画字符
4. **地形模拟**用不同的数字代表不同的地形类型，遍历数组时转换为对应的符号
5. 嵌套循环的**绘图模式**是先遍历行再遍历列，满足了"画图条件"就输出字符，否则输出空格
6. 字符画创作不仅有趣，还锻炼了**逻辑思维**和**空间想象力**，同时为理解图像处理打好基础
