# 第02课：编程积木——程序的结构

## 🎯 学习目标
- 理解C++程序的基本结构：头文件、main函数、语句
- 认识 `#include`、`using namespace std`、`main()` 的作用
- 理解语句和分号的关系

## 📖 知识讲解

### 程序就像搭积木

你有没有玩过乐高积木？一个复杂的城堡，其实是由一块一块的小积木拼成的。C++程序也是一样——它由几个固定的"积木块"组成。不管多大多复杂的程序，基本结构都是相似的。

让我们用搭积木的眼光来看一个C++程序：

```cpp
#include <iostream>        // ← 积木块1：工具箱
using namespace std;       // ← 积木块2：使用说明书

int main() {               // ← 积木块3：大门（程序入口）
    cout << "你好！";      // ← 积木块4：做事情的指令
    return 0;              // ← 积木块5：结束标志
}
```

### 积木块1：头文件 `#include`

`#include` 就像给你的程序**准备一个工具箱**。

想象你要做手工，需要剪刀、胶水、彩纸。在开始之前，你得先把工具箱拿过来，对吧？`#include` 就是在做这件事——它告诉电脑："嘿，我待会儿需要用到这些工具！"

`#include <iostream>` 的意思是：把 `iostream` 这个工具箱拿过来。`iostream` 是 "input output stream" 的缩写，里面装着输入和输出的工具——比如我们用的 `cout`（输出）就在这个工具箱里。

常见的头文件就像不同用途的工具箱：
- `<iostream>`：输入输出工具箱（里面有 cout、cin）
- `<string>`：文字处理工具箱
- `<cmath>`：数学工具箱（里面有各种数学函数）
- `<algorithm>`：算法工具箱（排序、查找等）

> **小贴士**：`#include` 通常写在程序的最开头。就像做菜之前要先准备好锅碗瓢盆一样！

### 积木块2：命名空间 `using namespace std`

`using namespace std` 这句话看起来有点复杂，但它的意思很简单：**告诉电脑"标准工具箱"在哪里**。

打个比方：你去图书馆借书，如果不说清楚书在哪个书架上，图书管理员就找不到。`std` 就像告诉电脑："我要用的工具都在'标准书架'上"。

`std` 是 "standard"（标准）的缩写。C++把很多好用的工具都打包在这个"标准书架"里，所以我们需要先声明一下要用它。

> **重要提示**：`using namespace std;` 的末尾有一个分号！因为这个声明本身也是一条"语句"。

### 积木块3：main函数——程序的"大门"

`main` 函数是每个C++程序的**入口**，就像一栋房子的**大门**。不管你写了多少代码，电脑总是从 `main()` 开始执行。

为什么叫"函数"呢？你可以把函数想象成一个**魔法盒子**：你给它一些东西（输入），它处理之后给你结果（输出）。`main` 函数比较特殊，它是程序启动时自动被调用的。

来看看 `main` 函数的结构：
```cpp
int main() {        // 函数头：int是返回值类型，main是函数名
    // 这里写你要做的事情
    return 0;       // 函数体结束前，返回一个值
}
```

- `int`：表示这个函数会返回一个整数（integer）
- `main`：函数的名字，必须是"main"
- `()`：括号，里面可以放参数（暂时留空）
- `{ }`：花括号，里面是函数的内容，像一堵围墙把代码围起来
- `return 0;`：返回0，表示"一切顺利，程序正常结束啦！"

### 积木块4：语句与分号

程序是由一条一条的**语句**组成的，就像文章是由一句一句话组成的。

在C++里，**每条语句的末尾必须有一个分号 `;`**。这个分号就像句号——它告诉电脑："这句话说完了，请执行下一句！"

```cpp
cout << "第一句话";   // 有分号 ✓
cout << "第二句话";   // 有分号 ✓
int a = 5;           // 有分号 ✓
return 0;            // 有分号 ✓
```

如果忘了写分号，编译器就会像老师批改作文一样，给你标一个红红的错误！这是初学者最容易犯的错误之一，所以一定要仔细检查哦。

> **记忆口诀**：写完一句，分号结尾；句号不忘，编译不慌！

### 程序的"骨架"

如果把一个C++程序比作人体，那么：
- `#include` = 工具箱（手脚）
- `using namespace std` = 说明书（大脑记忆）
- `int main() { }` = 身体躯干
- 花括号里的语句 = 要做的动作
- `return 0;` = 程序结束的信号

不管多复杂的程序，都离不开这个基本骨架！

## 💻 示例代码

### 示例1：认识程序结构（带详细标注）
```cpp
// ===== 第1部分：准备工具箱 =====
#include <iostream>          // 输入输出工具箱
using namespace std;         // 使用标准命名空间

// ===== 第2部分：程序入口 =====
int main() {                 // main函数——程序从这里开始执行
    // ===== 第3部分：执行语句 =====
    cout << "程序开始运行！" << endl;
    cout << "我正在学习程序的结构。" << endl;

    // ===== 第4部分：结束程序 =====
    return 0;                // 返回0，表示正常结束
}
```

### 示例2：包含多个头文件
```cpp
#include <iostream>   // 输入输出
#include <cmath>      // 数学函数（比如平方根sqrt）
using namespace std;

int main() {
    cout << "4的平方根是：" << sqrt(4) << endl;
    cout << "9的平方根是：" << sqrt(9) << endl;
    cout << "16的平方根是：" << sqrt(16) << endl;
    return 0;
}
```
**运行结果：**
```
4的平方根是：2
9的平方根是：3
16的平方根是：4
```

### 示例3：语句必须分号结尾
```cpp
#include <iostream>
using namespace std;

int main() {
    // ✅ 正确：每条语句后面都有分号
    cout << "第一条语句" << endl;
    cout << "第二条语句" << endl;
    cout << "第三条语句" << endl;

    // ❌ 如果忘记分号，编译器会报错！
    // 试试把上面某行的分号删掉，看看编译器说什么？

    return 0;
}
```

## 🎮 趣味练习

### 练习1：拼图大师
下面程序的"积木块"顺序被打乱了，请把它们按正确的顺序排列：

```
A. return 0;
B. int main() {
C. cout << "我会编程了！" << endl;
D. #include <iostream>
E. }
F. using namespace std;
```

**参考答案：** 正确顺序是 D → F → B → C → A → E
```
#include <iostream>
using namespace std;
int main() {
    cout << "我会编程了！" << endl;
    return 0;
}
```

## 🏆 挑战任务

### 挑战：搭建你的第一个多功能程序
编写一个程序，要求：
1. 包含 `<iostream>` 和 `<cmath>` 两个头文件
2. 在 `main` 函数中至少写5条 `cout` 语句
3. 使用 `sqrt()` 函数计算一个数的平方根
4. 在程序末尾用注释写出这个程序的结构说明

**参考示例：**
```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    // 这是我的多功能程序
    cout << "===== 我的程序 =====" << endl;
    cout << "大家好！" << endl;
    cout << "100的平方根是：" << sqrt(100) << endl;
    cout << "256的平方根是：" << sqrt(256) << endl;
    cout << "程序到此结束，再见！" << endl;
    return 0;
}

/*
 * 程序结构说明：
 * 1. #include —— 引入输入输出和数学工具箱
 * 2. using namespace std —— 使用标准命名空间
 * 3. int main() —— 程序入口
 * 4. { } 内部 —— 5条输出语句
 * 5. return 0 —— 程序正常结束
 */
```

## 📝 本课小结

| 积木块 | 代码 | 比喻 | 作用 |
|--------|------|------|------|
| 头文件 | `#include <iostream>` | 工具箱 | 引入需要的工具 |
| 命名空间 | `using namespace std;` | 书架标签 | 告诉电脑工具在哪 |
| main函数 | `int main() { }` | 房子大门 | 程序的入口 |
| 语句 | `cout << "你好";` | 指令 | 具体要做的事 |
| 返回值 | `return 0;` | 完成信号 | 告诉系统程序结束 |
| 分号 | `;` | 句号 | 每条语句的结束标志 |

**记住这句口诀：**
> 头文件是工具箱，main函数是进门；花括号里写指令，句句分号记在心！
