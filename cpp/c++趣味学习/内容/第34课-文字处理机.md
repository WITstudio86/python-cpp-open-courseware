## 📖 核心知识讲解

### 一、什么是字符串？

在前面的课程中，我们学过了 `int`（整数）、`double`（小数）、`char`（单个字符）等数据类型。但是，如果要处理一段文字，比如"你好，我是小明！"这样的信息，用一个 `char` 只能存一个汉字，显然不够用。

C++ 给我们提供了一个专门用来处理文字的数据类型——**`string`**（字符串）。

```cpp
string name = "小明";        // 用双引号括起来的文字就是字符串
string message = "你好，欢迎学习C++！";
```

> **注意**：
> - 字符串必须用**英文双引号** `""` 括起来。
> - 使用 `string` 类型需要包含头文件 `#include <string>`。
> - `string` 是 C++ 标准库提供的高级类型，使用起来非常方便。

### 二、字符串的输入：cin vs getline

这是学习 string 时最容易踩坑的地方！C++ 提供了两种常用的字符串输入方式，它们的行为很不一样。

| 输入方式 | 说明 | 能读取空格吗？ | 读取到哪为止？ |
|----------|------|:---:|--------------|
| `cin >> s` | 从标准输入读取一个"单词" | ❌ 不能 | 遇到空格、Tab 或换行就停止 |
| `getline(cin, s)` | 从标准输入读取一整行 | ✅ 可以 | 遇到换行符才停止 |

**实例对比：**

```cpp
string word, line;
cout << "请输入一句话：";
cin >> word;                    // 输入 "Hello World"，只能读到 "Hello"
cout << "cin 读到：" << word << endl;

cin.ignore();                   // 重要！清除缓冲区中的换行符
cout << "请再输入一句话：";
getline(cin, line);             // 输入 "I love C++"，完整读到 "I love C++"
cout << "getline 读到：" << line << endl;
```

**为什么需要 `cin.ignore()`？**

混合使用 `cin` 和 `getline()` 时，`cin` 输入后在缓冲区里会残留一个换行符 `\n`，如果不调用 `cin.ignore()` 清除它，后面的 `getline()` 会立刻读到这个换行符而直接结束，导致你以为程序"跳过了"输入。

> **记忆口诀**：`cin >>` 只读一个词，空格就是分界线；`getline` 读一整行，空格换行全拿下！

### 三、字符串拼接

在 C++ 中，把两个或多个字符串合并在一起，叫做**字符串拼接**（concatenation）。我们使用 `+` 运算符来完成这个操作。

```cpp
string firstName = "张";
string lastName = "小明";
string fullName = firstName + lastName;     // 结果："张小明"
string intro = "大家好，我是" + fullName;  // 结果："大家好，我是张小明"

// 也可以用 += 在原字符串后面追加
string card = "姓名：" + fullName + "\n";
card += "年龄：12岁\n";
card += "爱好：编程\n";
cout << card;
```

**拼接规则**：
- `string + string` → 两个字符串连接。
- `string + 字符字面量`（如 `"你好"`）→ 也可以拼接，但注意两边至少有一边是 string 变量。
- 使用 `+=` 运算符可以在原有字符串的末尾追加新内容，就像往一张纸上继续写字一样。

### 四、常用字符串操作

| 操作 | 代码示例 | 说明 |
|------|---------|------|
| 获取长度 | `s.length()` 或 `s.size()` | 返回字符串中包含多少个字符 |
| 访问单个字符 | `s[0]` 或 `s.at(0)` | 获取字符串中第 0 位的字符（索引从 0 开始） |
| 判断是否为空 | `s.empty()` | 如果字符串为空则返回 true |
| 清空字符串 | `s.clear()` | 把字符串变成空的 |
| 比较字符串 | `s1 == s2` | 判断两个字符串是否完全一样 |

## 💻 代码示例

### 示例一：基础 string 操作

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 1. 声明与初始化
    string name = "小明";
    cout << "初始名字：" << name << endl;

    // 2. 修改字符串
    name = "新的小明";
    cout << "修改后名字：" << name << endl;

    // 3. 获取长度
    cout << "名字长度：" << name.length() << " 个字符" << endl;

    // 4. 访问单个字符
    cout << "名字的第1个字是：" << name[0] << endl;

    return 0;
}
```

**运行结果：**
```
初始名字：小明
修改后名字：新的小明
名字长度：8 个字符
名字的第1个字是：新
```

### 示例二：个人名片生成器（本课综合项目）

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name, school, hobby, phone;

    // 收集用户信息
    cout << "🎨 === 个人名片生成器 === 🎨" << endl << endl;
    cout << "请输入你的姓名：";
    getline(cin, name);

    cout << "请输入你的学校：";
    getline(cin, school);

    cout << "请输入你的爱好：";
    getline(cin, hobby);

    cout << "请输入你的电话：";
    getline(cin, phone);

    // 拼接生成名片
    string card = "";
    card += "╔══════════════════════════╗\n";
    card += "║      🪪 个人名片          ║\n";
    card += "╠══════════════════════════╣\n";
    card += "║  姓名：" + name;
    // 对齐空格：根据名字长度动态计算
    for (int i = 0; i < (int)(20 - name.length() * 2); i++) {
        card += " ";
    }
    card += "║\n";

    card += "║  学校：" + school;
    for (int i = 0; i < (int)(20 - school.length() * 2); i++) {
        card += " ";
    }
    card += "║\n";

    card += "║  爱好：" + hobby;
    for (int i = 0; i < (int)(20 - hobby.length() * 2); i++) {
        card += " ";
    }
    card += "║\n";

    card += "║  电话：" + phone;
    for (int i = 0; i < (int)(20 - phone.length() * 2); i++) {
        card += " ";
    }
    card += "║\n";

    card += "╚══════════════════════════╝\n";

    // 输出最终名片
    cout << endl;
    cout << card;

    // 输出统计信息
    cout << "📊 名片信息统计：" << endl;
    cout << "  姓名字符数：" << name.length() << endl;
    cout << "  学校字符数：" << school.length() << endl;
    cout << "  爱好字符数：" << hobby.length() << endl;
    cout << "  电话字符数：" << phone.length() << endl;

    return 0;
}
```

### 练习二：cin 和 getline 的区别（进阶）

阅读下面的程序，假设用户从键盘输入：`Zhang San` 然后按回车，接着输入：`Beijing School` 然后按回车。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    cin >> a;
    cin >> b;
    cout << "a = " << a << endl;
    cout << "b = " << b << endl;
    return 0;
}
```

**问题：输出结果是什么？为什么？**

<details>
<summary>点击查看答案</summary>

输出：
```
a = Zhang
b = San
```

原因：`cin >>` 遇到空格就会停止。用户虽然有两次输入的行为（两次回车），但实际上：
- 第一次 `cin >> a` 读取时，用户输入了 `Zhang San\n`，`cin >>` 读到空格就停止，所以 `a = "Zhang"`。
- 此时缓冲区中还剩下 ` San\n`，第二个 `cin >> b` 会跳过前面的空格，读取到 `b = "San"`。

**如果改成用 `getline` 呢？**

```cpp
string a, b;
getline(cin, a);  // 第一次输入 "Zhang San"，a = "Zhang San"
getline(cin, b);  // 第二次输入 "Beijing School"，b = "Beijing School"
```

这才是大多数人期望的行为！所以**当你需要读取带空格的文本时，一定要用 `getline`**。

</details>

### 练习三：代码改错（进阶）

下面的代码有 3 处错误，请找出来并改正。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;                     // 输入 "我爱编程"
    cout << "你输入的是：" << s << endl;

    string greeting = 你好;        // 错误1
    string name = "小明";
    cout << greeting + "，" + name << endl;

    string city;
    getline(city, cin);           // 错误3
    cout << "城市是：" << city << endl;

    return 0;
}
```

<details>
<summary>点击查看答案</summary>

**错误 1**：`string greeting = 你好;` → 字符串必须用双引号括起来，应该改为 `string greeting = "你好";`

**错误 2**：`cin >> s` 只能读到空格前的内容。用户输入 `我爱编程`，因为 `cin >>` 只读到空格或换行，本例中没有空格，所以能正常读到。但如果你想要输入含空格的句子，应该用 `getline(cin, s)`。

**错误 3**：`getline(city, cin);` → 参数顺序写反了！正确的写法是 `getline(cin, city);`，第一个参数是输入流 `cin`，第二个参数是存储结果的字符串变量。

**修正后的代码：**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    getline(cin, s);                        // 改用 getline 可读取带空格的句子
    cout << "你输入的是：" << s << endl;

    string greeting = "你好";                // 修正：加上双引号
    string name = "小明";
    cout << greeting + "，" + name << endl;

    string city;
    getline(cin, city);                     // 修正：参数顺序
    cout << "城市是：" << city << endl;

    return 0;
}
```

</details>

## 🏆 挑战任务：智能问候机器人

**任务描述：** 编写一个程序，实现以下功能：

1. 让用户输入自己的**名字**。
2. 让用户输入**当前的心情**（如"开心"、"有点困"、"充满能量"）。
3. 程序根据用户的心情，自动生成不同的问候语：
   - 如果心情是"开心"→ 回复："太棒了！保持好心情，今天一定万事如意！"
   - 如果心情是"有点困"→ 回复："来一杯热水提提神吧，代码世界需要清醒的你！"
   - 其他心情 → 回复："感谢你的分享，每一天都是新的开始，加油！"
4. 使用 `+` 拼接生成一句完整的问候，并输出。

**提示：** 使用 `getline()` 读取输入，使用 `if-else` 判断心情，使用 `+` 拼接最终输出。

<details>
<summary>点击查看参考答案</summary>

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name, mood;

    }

    cout << "━━━━━━━━━━━━━━━━━━━━" << endl;
    return 0;
}
```

## 📝 本课总结

1. **`string` 是处理文字的数据类型**，使用前要 `#include <string>`，赋值时用英文双引号 `""` 括起来。
2. **`cin >> s`** 只能读取空格前的一个"单词"；**`getline(cin, s)`** 可以读取包含空格的整行文本。
3. **字符串拼接用 `+` 运算符**，就像把两段文字粘在一起；`+=` 可以在原字符串后面继续追加内容。
4. **字符串有长度**，用 `.length()` 或 `.size()` 可以知道里面有多少个字符。
5. **混合使用 `cin` 和 `getline` 时**，记得用 `cin.ignore()` 清除残留的换行符，否则 `getline` 会"跳过"。
6. **字符串比较用 `==`**，可以判断两个字符串的内容是否完全相同，这在人机交互中非常有用。
