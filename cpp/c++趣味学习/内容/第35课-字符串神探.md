## 📖 知识讲解

### 什么是字符串？

在C++中，`string` 就是"一串字符"，简单来说就是文字的集合。你的名字、一句话、一整篇文章，在计算机里都是字符串！比如 `"Hello"` 是一个长度为5的字符串，`"我爱编程"` 是一个长度为4的字符串（每个中文字符算1个！）。

字符串就像一个排好队的字符队伍，每个字符都有自己的"座位号"，这个座位号就叫**索引**。

```
字符串:  H  e  l  l  o
索引:   0  1  2  3  4
```

注意啦！在C++里，索引是从 **0** 开始数的，不是从1开始！这就像一栋楼的楼层编号：中国的一楼 = C++的0号位置。初学者一定要记住这个规则！

### 字符串的神探工具箱

在今天的课堂上，你将化身"文字神探"，用以下四个强力工具来破案：

#### 工具1：length() —— 丈量字符串

`length()` 能告诉你这个字符串里有多少个字符。就像用尺子丈量一根绳子有多长。

```cpp
string word = "Hello";
cout << word.length() << endl;  // 输出：5
```

`size()` 和 `length()` 在 `string` 中是同样的意思，两者都可以用。但是对于 `string`，推荐使用 `length()`，因为它更直观——"字符串的长度"嘛！

#### 工具2：索引访问 [] —— 揪出第N个字

有了索引，你可以像点名一样，把队伍中的任意一个字符揪出来！`str[0]` 就是第一个字符，`str[1]` 是第二个，依此类推。

```cpp
string name = "侦探柯南";
cout << name[0] << endl;  // 输出「侦」
cout << name[2] << endl;  // 输出「柯」
cout << name[3] << endl;  // 输出「南」
```

我们来算一算：`"侦探柯南"` 有4个中文字符，所以索引范围是 0 ~ 3。如果访问 `name[4]` 会怎样？那就会越界！C++不会报错，但你会拿到一个不知道是什么的字符——这就是著名的"数组越界"问题。所以每次用索引访问之前，最好先确认索引 < 长度。

还有一个重要的工具：**反向索引**。最后一个字符的索引是 `str.length() - 1`。如果你想访问最后一个字，可以这样做：

```cpp
cout << name[name.length() - 1] << endl;  // 输出「南」
```

#### 工具3：substr() —— 截取线索片段

`substr(pos, len)` 能从字符串中截取一段子串。`pos` 是起始位置（从第几个字开始截），`len` 是要截取的长度（截几个字）。

```cpp
string message = "嫌疑人在图书馆三楼";
string location = message.substr(4, 3);  // 从索引4开始，取3个字
cout << location << endl;  // 输出「图书馆」
```

截取出"图书馆"后，神探就可以去这个位置调查啦！

`substr()` 的第二个参数还可以省略。如果只写一个参数 `substr(pos)`，那就表示"从这个位置开始，一直取到末尾"：

```cpp
string clue = "密码是473829";
string password = clue.substr(4);  // 从索引4开始取到末尾
cout << password << endl;  // 输出「473829」
```

#### 工具4：find() —— 搜索关键字

`find()` 是最强大的神探工具！它能在一大段文字中搜索某个关键词，并返回它第一次出现的位置。如果没找到，就返回一个特殊值 `string::npos`。

```cpp
string report = "目击者说看到穿红色外套的人进入大楼";
int pos = report.find("红色");
if (pos != string::npos) {
    cout << "找到线索「红色」在位置 " << pos << endl;
} else {
    cout << "没有找到相关线索" << endl;
}
// 输出：找到线索「红色」在位置 6
```

`find()` 也可以从指定位置开始搜索，只需多传一个参数：

```cpp
string text = "abc abc abc";
int first = text.find("abc");       // 找第一个：0
int second = text.find("abc", 1);   // 从位置1开始找：4
int third = text.find("abc", 5);    // 从位置5开始找：8
```

## 💻 示例代码

### 示例1：密码破译器

一个神秘人留下了一张纸条，纸条上的文字被编码了。我们需要解密这条信息！

**编码规则**：真正的密码是纸条内容每隔2个字符取一个字（取第0、2、4、6...个字）。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string secret = "山猫雨狗风鱼雪鸟云虫雷蛙";
    string password = "";  // 用来存放破译出的密码

    cout << "🕵️ 加密纸条内容：" << secret << endl;
    cout << "📏 纸条长度：" << secret.length() << " 个字符" << endl;
    cout << "🔍 开始破译（每隔2个字符取一个字）..." << endl;

    // 每隔2个字符取一个（索引0, 2, 4, 6, ...）
    for (int i = 0; i < secret.length(); i += 2) {
        char ch = secret[i];
        password += ch;  // 把破译的字拼接到密码里
        cout << "  发现第" << i / 2 + 1 << "个密码字：" << ch << endl;
    }

    cout << "✅ 破译完成！密码是：" << password << endl;
    cout << "📦 密码长度：" << password.length() << " 个字符" << endl;

    return 0;
}
```

**运行效果：** 纸条内容是"山猫雨狗风鱼雪鸟云虫雷蛙"，隔一个字取一个，密码就是"山雨风雪云雷"——原来是个天气预报！

### 示例2：文字侦探——寻找嫌疑人

现在你是侦探事务所的实习神探，需要根据目击报告找出嫌疑人的关键特征。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // === 案件1：寻找嫌疑人特征 ===
    cout << "════════ 案件1：寻找嫌疑人特征 ════════" << endl;

    string report = "目击者：周三下午3点，一个戴帽子、穿蓝色衣服的高个子男人走进巷子。";
    cout << "📋 目击报告：" << report << endl;
    cout << "📏 报告共 " << report.length() << " 个字。" << endl << endl;

    // 查找关键词
    string keywords[] = {"帽子", "蓝色", "高个子", "巷子"};
    for (int i = 0; i < 4; i++) {
        int pos = report.find(keywords[i]);
        if (pos != string::npos) {
            cout << "🔎 发现关键线索「" << keywords[i] << "」在第 " << pos << " 个字符处！" << endl;
        }
    }

    // 提取特征描述
    cout << endl << "👤 嫌疑人画像：" << endl;
    // "穿蓝色衣服的" 中提取 "蓝色"
    int colorStart = report.find("穿");
    string clothing = report.substr(colorStart + 2, 2);  // "蓝色"
    cout << "  衣服颜色：" << clothing << endl;

    // 提取"高个子"
    string build = report.substr(report.find("高个子"), 3);
    cout << "  身材：" << build << endl;

    cout << endl;

    // === 案件2：暗号解析 ===
    cout << "════════ 案件2：暗号解析 ════════" << endl;

    string coded = "AB见CD面EF地GH点IJ是KL公MN园OP长QR椅ST";
    cout << "📝 截获暗号：" << coded << endl;
    cout << "📏 暗号长度：" << coded.length() << " 个字符" << endl;

    // 解码规则：只保留中文字符（索引2,3, 6,7, 10,11 ... 即每4个一组取后两个）
    string decoded = "";
    for (int i = 0; i < coded.length(); i++) {
        char c = coded[i];
        // 中文字符在C++中占用多个字节，这里每个中文是一个char元素
        // 判断是否为中文字符：中文字符的每个字节值通常 > 127
        if (c < 0 || static_cast<unsigned char>(c) > 127) {
            decoded += c;
        }
    }
    cout << "🔓 解码结果：" << decoded << endl;

    // 手工解析：每隔4个字符取后2个字
    cout << endl << "🧩 手工解析（跳过字母标记）：" << endl;
    string manualDecode = "";
    for (int i = 2; i < coded.length(); i += 4) {
        manualDecode += coded[i];
        manualDecode += coded[i + 1];
    }
    cout << "  最终暗号：" << manualDecode << endl;

    // === 案件3：密码验证 ===
    cout << endl << "════════ 案件3：密码验证系统 ════════" << endl;

    string correctPassword = "Sunflower2024";
    string userInput;

    cout << "🔐 请输入密码：";
    cin >> userInput;

    if (userInput == correctPassword) {
        cout << "✅ 密码正确！保险箱已打开！" << endl;
        // 显示密码信息
        cout << "📊 密码分析：" << endl;
        cout << "  密码长度：" << correctPassword.length() << " 位" << endl;
        cout << "  首字符：" << correctPassword[0] << endl;
        cout << "  末字符：" << correctPassword[correctPassword.length() - 1] << endl;

        // 检查密码中是否包含数字
        size_t digitPos = correctPassword.find("2024");
        if (digitPos != string::npos) {
            cout << "  包含年份：" << correctPassword.substr(digitPos, 4) << endl;
        }
    } else {
        cout << "❌ 密码错误！警报响起！🚨" << endl;
        cout << "  提示：密码和向日葵有关哦~" << endl;
    }

    cout << endl << "🕵️ 神探任务全部完成！" << endl;

    return 0;
}
```

## 🎮 趣味练习

### 练习1：字符统计员

写一段程序，让用户输入一个字符串，然后统计这个字符串中有多少个字符，并逐个输出每个字符（每输出一个换一行）。

**要求：** 使用 `length()` 和索引访问 `[]`。

**参考答案：**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string text;
    cout << "请输入一段文字：";
    getline(cin, text);  // 用getline可以读入带空格的整行文字

    cout << "文字长度为：" << text.length() << " 个字符" << endl;
    cout << "逐个输出字符：" << endl;
    for (int i = 0; i < text.length(); i++) {
        cout << "第" << i << "个字符：" << text[i] << endl;
    }
    return 0;
}
```

### 练习2：姓名拆分器

请用户输入完整的姓名（格式：姓+名，如"诸葛亮"），然后使用 `substr()` 将姓氏和名字拆分开来输出。

**提示：** 中国人的姓通常是1个字（如"张"）或2个字（如"欧阳"）。先判断输入的名字长度，然后假设姓是1个字来拆分。

**参考答案：**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string fullName;
    cout << "请输入你的全名：";
    cin >> fullName;

    // 假设姓是1个字
    string surname = fullName.substr(0, 1);
    string givenName = fullName.substr(1);

    cout << "姓氏：" << surname << endl;
    cout << "名字：" << givenName << endl;

    // 进阶：如果是复姓（长度为4），姓是2个字
    if (fullName.length() == 4) {
        surname = fullName.substr(0, 2);
        givenName = fullName.substr(2);
        cout << "检测到复姓！" << endl;
        cout << "姓氏：" << surname << endl;
        cout << "名字：" << givenName << endl;
    }

    return 0;
}
```

### 练习3：关键词替换器

让用户输入一句话和一个关键词，把这句话中所有的关键词替换成 `[已加密]`。使用 `find()` 来定位关键词的位置。

**参考答案：**
```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string sentence, keyword;
    cout << "请输入一句话：";
    getline(cin, sentence);
    cout << "请输入要加密的关键词：";
    cin >> keyword;

    string replacement = "[已加密]";
    int pos = 0;

    // 循环查找并替换
    while ((pos = sentence.find(keyword, pos)) != string::npos) {
        sentence.replace(pos, keyword.length(), replacement);
        pos += replacement.length();  // 跳过替换后的内容，继续往后找
    }

    cout << "加密后的句子：" << sentence << endl;
    return 0;
}
```

### 终极文字侦探：信息加密与破译系统

设计一个完整的信息加密与破译程序。这个程序需要完成以下功能：

**加密功能：**
1. 用户输入一段原始消息
2. 程序自动为消息添加"噪音字符"——在每个字符之间插入一个随机字母
3. 输出加密后的密文

**破译功能：**
1. 拿到密文后，每隔一个字符取一个字符，还原出原始消息

**附加挑战：** 在密文开头添加一个长度标记（比如"L8:"表示原始消息有8个字符），方便破译时验证。

**示例运行：**
```
原始消息：你好世界
加密后：L4:X你Y好Z世A界  ← X、Y、Z、A是插入的噪音字母
破译后：你好世界
```

**提示：**
- 使用 `length()` 获取消息长度
- 使用索引访问 `[]` 往密文中拼接字符
- 使用 `substr()` 提取原始消息
- 可以用26个英文字母作为"噪音"字符池
- 注意中文字符在 `string` 中每个字符也占一个 `char` 位置（在 UTF-8 编码下，一个汉字占多个字节，但在本课的基础示例中，我们简化处理，把每个 `char` 元素当作一个"字"来操作）

## 📝 本课小结

- **字符串 `string`** 是C++中用来存储和处理文字的数据类型，能存放字母、数字、中文等各种字符
- **`length()`** 方法返回字符串中字符的个数，是神探丈量线索长度的尺子
- **索引 `[]`** 从0开始编号，你用它来访问字符串中任意位置的字符，就像点名一样
- **`substr(pos, len)`** 从指定位置截取指定长度的子串，是提取关键线索的利器
- **`find(str)`** 在一段文字中搜索关键词，返回它第一次出现的位置，找不到则返回 `string::npos`
- 综合使用这四种字符串操作，你就能成为一名出色的"文字神探"，破解各种各样的文字谜题
- 字符串操作是编程中最常用的技能之一，从密码验证、搜索功能、文本处理到聊天机器人，处处都有它的身影。掌握好字符串，你就打开了信息处理的大门
