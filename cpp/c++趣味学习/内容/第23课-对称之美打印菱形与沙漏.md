# 第23课：对称之美——打印菱形与沙漏

## 🎯 学习目标
- 掌握复杂对称图形的打印方法
- 理解"上半部分+下半部分"的拆分策略
- 能够设计菱形、沙漏等经典对称图案

## 📖 知识讲解

### 对称图形的奥秘

你有没有在纸上折过剪纸？把纸对折，沿着折痕剪出一个形状，打开后就是一个对称的图案。打印菱形和沙漏用的也是同样的思路——先打印上半部分，再打印下半部分，两部分沿水平中线对称。

把一个复杂图形拆成两半，每半都是一个简单的三角形。这就是"分而治之"的思想！

### 菱形——两颗三角形拼在一起

菱形可以看作是一个正三角形加上一个倒三角形：

```
   *          上半：正三角形（5行）
  ***
 *****
*******
 *****       下半：倒三角形（4行）
  ***
   *
```

你会发现：如果把菱形分成上、下两部分：
- **上半部分**：正三角形（等腰），第i行有(n-i)个空格和(2i-1)个星号
- **下半部分**：倒三角形（等腰），第i行有i个空格和(2n-2i-1)个星号

设菱形的总行数为`2n-1`（奇数行），中间行有`2n-1`个星号。

### 菱形上半部分

上半部分就是一个我们上一课学过的等腰三角形。行数i从1到n：

```cpp
// 上半部分（行数：1 到 n）
for (int i = 1; i <= n; i++) {
    // 空格：n-i个
    for (int j = 1; j <= n - i; j++) {
        cout << " ";
    }
    // 星号：2i-1个
    for (int j = 1; j <= 2 * i - 1; j++) {
        cout << "*";
    }
    cout << endl;
}
```

### 菱形下半部分

下半部分是一个倒等腰三角形。行数i从n-1递减到1：

```cpp
// 下半部分（行数：n-1 到 1）
for (int i = n - 1; i >= 1; i--) {
    // 空格：n-i个
    for (int j = 1; j <= n - i; j++) {
        cout << " ";
    }
    // 星号：2i-1个
    for (int j = 1; j <= 2 * i - 1; j++) {
        cout << "*";
    }
    cout << endl;
}
```

有没有发现？下半部分的代码和上半部分几乎一模一样！因为当i递减时，`n-i`和`2i-1`自动给出了正确的值。

### 沙漏——倒三角+正三角

沙漏图形刚好和菱形相反——上面是倒三角形，下面是正三角形：

```
*******      上半：倒三角形（4行）
 *****
  ***
   *
  ***        下半：正三角形（3行）
 *****
*******
```

分析规律（总行数为2n-1，n=4）：

**上半部分**（i从n到1递减）：
- 空格数：n-i个
- 星号数：2i-1个

**下半部分**（i从2到n递增）：
- 空格数：n-i个
- 星号数：2i-1个

注意到没有？上半部分和下半部分的公式完全一样，只是i的取值方向不同！

### 空心菱形

更进一步，我们还可以打印空心菱形——只有边框有星号，中间是空的：

```
   *          只有每行的第一个和最后一个星号
  * *
 *   *
*     *
 *   *
  * *
   *
```

这需要在内层循环中加入判断：每行只在特定位置打印星号，其他位置打印空格。

对于上半部分第i行：
- 左星号位置：第(n-i+1)列
- 右星号位置：第(n+i-1)列

### 对称图形的设计心法

1. **确定中线**：把图形分成上半和下半
2. **分开计算**：对上半部分和下半部分分别找规律
3. **复用公式**：上下部分通常用相同的公式，只是循环方向不同
4. **奇数总行**：菱形/沙漏的总行数通常是奇数（2n-1）

## 💻 示例代码

### 示例1：闪闪钻石（菱形）

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "💎 闪闪钻石生成器" << endl;
    cout << "请输入钻石的一半高度：";
    cin >> n;
    cout << endl;

    // 上半部分：正三角形
    for (int i = 1; i <= n; i++) {
        // 打印空格
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        // 打印星号
        for (int j = 1; j <= 2 * i - 1; j++) {
            cout << "*";
        }
        cout << endl;
    }

    // 下半部分：倒三角形
    for (int i = n - 1; i >= 1; i--) {
        // 打印空格
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        // 打印星号
        for (int j = 1; j <= 2 * i - 1; j++) {
            cout << "*";
        }
        cout << endl;
    }

    return 0;
}

/* 输入4时的输出：
   *
  ***
 *****
*******
 *****
  ***
   *
*/
```

### 示例2：时光沙漏

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "⏳ 时光沙漏生成器" << endl;
    cout << "请输入沙漏的一半高度：";
    cin >> n;
    cout << endl;

    // 上半部分：倒三角形
    for (int i = n; i >= 1; i--) {
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        for (int j = 1; j <= 2 * i - 1; j++) {
            cout << "*";
        }
        cout << endl;
    }

    // 下半部分：正三角形
    for (int i = 2; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) {
            cout << " ";
        }
        for (int j = 1; j <= 2 * i - 1; j++) {
            cout << "*";
        }
        cout << endl;
    }

    return 0;
}

/* 输入4时的输出：
*******
 *****
  ***
   *
  ***
 *****
*******
*/
```

## 🎮 趣味练习

### 练习1：蝴蝶翅膀

打印一个蝴蝶翅膀图案（两个直角三角形相对）：

```
*        *
**      **
***    ***
****  ****
**********
```

**提示：** 第i行：i个星号 + (2n-2i)个空格 + i个星号。

**参考答案：**
```cpp
int n = 5;
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= i; j++) cout << "*";
    for (int j = 1; j <= 2 * (n - i); j++) cout << " ";
    for (int j = 1; j <= i; j++) cout << "*";
    cout << endl;
}
```

## 🏆 挑战任务

### 空心菱形

打印一个空心的菱形，中间是空的，只有边框有星号。效果如下（n=4）：

```
   *
  * *
 *   *
*     *
 *   *
  * *
   *
```

**提示：** 每行只在特定位置打印星号。对于第i行：
- 左星号位置：(n-i+1)
- 右星号位置：(n+i-1)
- 其他位置都是空格

需要注意菱形的上下两部分公式略有不同。

## 📝 本课小结

- 对称图形使用**"分而治之"**策略：拆成上半和下半分别处理
- 菱形 = 正三角形（上半） + 倒三角形（下半），总行数为**2n-1**
- 沙漏 = 倒三角形（上半） + 正三角形（下半）
- 上下部分的**公式完全相同**，区别只在于循环变量i的取值方向（递增 vs 递减）
- 空心图形需要在每行**判断位置**，只在特定位置打印符号
- 灵活运用这种思路，可以打印出**蝴蝶、X形、十字形**等各种对称图案
