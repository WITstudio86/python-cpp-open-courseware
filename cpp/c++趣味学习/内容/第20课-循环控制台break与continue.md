# 第20课：循环控制台——break与continue

## 🎯 学习目标
- 掌握break语句跳出循环的用法
- 掌握continue语句跳过本次循环的用法
- 理解break和continue的区别，能灵活运用

## 📖 知识讲解

### 循环的"紧急按钮"和"跳过键"

你有没有玩过电子游戏？在游戏里，通常有两个重要的按钮：
- **退出键（ESC）**：按了就完全退出游戏，不玩了
- **跳过键（Skip）**：跳过当前这一关，但游戏还在继续

break和continue就是C++循环中的"退出键"和"跳过键"：
- **break** = 退出键：立即终止整个循环，跳出去不回来了
- **continue** = 跳过键：跳过本次循环剩下的代码，但循环继续执行下一次

### break——循环的"紧急出口"

break像教室里的紧急出口——一旦触发，你立刻离开教室（跳出循环），不会回头。

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;  // 当i等于5时，立刻跳出循环！
    }
    cout << i << " ";
}
// 输出：1 2 3 4
// i=5时触发break，5以及后面的数字都不会被输出
```

break的执行效果是：**立即、彻底**地终止当前所在的循环。程序会跳到循环后面的第一条语句继续执行。

### break的使用场景

**场景1：提前结束查找**
在100个数字中找第一个能被17整除的数，找到了就没必要继续找了：

```cpp
for (int i = 1; i <= 100; i++) {
    if (i % 17 == 0) {
        cout << "找到了！第一个是 " << i << endl;
        break;  // 找到了就停下，不用看后面的了
    }
}
```

**场景2：配合死循环**
```cpp
while (true) {
    cout << "输入数字（0退出）：";
    int n;
    cin >> n;
    if (n == 0) break;  // 用户输入0就退出
    cout << "你输入的是：" << n << endl;
}
```

### continue——循环的"跳过按钮"

continue像看视频时的"跳过片头"按钮——当前这一段不看了，直接跳到下一次播放。

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        continue;  // 跳过i=5这一轮，直接进入i=6
    }
    cout << i << " ";
}
// 输出：1 2 3 4 6 7 8 9 10
// 注意：5被跳过了，但后面的数字照常输出
```

continue的执行效果是：跳过循环体中continue之后的所有代码，直接进入下一次循环（更新变量，然后检查条件）。

### break vs continue 对比

让我们做一个小实验来区分它们：

```cpp
// 实验：遇到3时，break和continue分别做什么？
cout << "使用break：";
for (int i = 1; i <= 5; i++) {
    if (i == 3) break;
    cout << i << " ";
}
cout << endl;

cout << "使用continue：";
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;
    cout << i << " ";
}
```

**输出：**
```
使用break：1 2
使用continue：1 2 4 5
```

看出区别了吗？
- break遇到3就**完全停止了**，后面的4、5都没了
- continue遇到3**只跳过3自己**，4、5照样输出

### 重要注意事项

1. **break只跳出最内层循环**：如果循环嵌套，break只跳出它所处的最近一层循环，外层循环不受影响。

2. **continue在while和for中的区别**：
   - 在for循环中，continue后会先执行更新语句（如i++），再检查条件
   - 在while循环中，continue后直接回到条件检查，小心跳过更新语句导致死循环！

```cpp
// ⚠️ 常见的错误：while中用continue忘记更新变量
int i = 1;
while (i <= 10) {
    if (i == 5) {
        continue;  // 跳过了i++，i永远是5 → 死循环！
    }
    cout << i << " ";
    i++;
}
```

## 💻 示例代码

### 示例1：数字躲避游戏

有一个游戏：从1数到30，但遇到带有数字3的数（3、13、23、30）或者3的倍数时要"跳过"。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "🕹️ 数字躲避游戏——遇到3就跳过！" << endl;
    cout << "规则：数1-30，遇到含3的数字或3的倍数就跳过" << endl;
    cout << "-------------------------------------------" << endl;

    for (int i = 1; i <= 30; i++) {
        // 判断条件：是3的倍数，或者个位是3，或者十位是3
        if (i % 3 == 0 || i % 10 == 3 || i / 10 == 3) {
            cout << "💨 跳过！" << endl;
            continue;  // 跳过这个数
        }
        cout << "🔢 " << i << endl;
    }

    cout << "游戏结束！" << endl;
    return 0;
}
```

### 示例2：查找质数——break的应用

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    cout << "🔍 质数查找器（100以内）" << endl;
    cout << "质数：只能被1和自身整除的大于1的自然数" << endl;
    cout << "-------------------------------------------" << endl;

    int count = 0;
    for (int num = 2; num <= 100; num++) {
        bool isPrime = true;

        // 只需检查到sqrt(num)即可
        for (int i = 2; i <= sqrt(num); i++) {
            if (num % i == 0) {
                isPrime = false;
                break;  // 找到一个因子就够了，不用继续检查
            }
        }

        if (isPrime) {
            cout << num << " ";
            count++;
            if (count % 10 == 0) cout << endl;  // 每10个换行
        }
    }

    cout << endl << "100以内共有 " << count << " 个质数。" << endl;
    return 0;
}
```

## 🎮 趣味练习

### 练习1：跳过3的倍数

使用for循环打印1到30的数字，但是跳过所有3的倍数（使用continue）。

**参考答案：**
```cpp
for (int i = 1; i <= 30; i++) {
    if (i % 3 == 0) continue;
    cout << i << " ";
}
```

### 练习2：找到第一个公倍数

在1到100中，找到第一个既能被7整除又能被5整除的数（使用break）。

**参考答案：**
```cpp
for (int i = 1; i <= 100; i++) {
    if (i % 7 == 0 && i % 5 == 0) {
        cout << "找到了！" << i << " 是7和5的公倍数" << endl;
        break;
    }
}
// 答案是35
```

## 📝 本课小结

- **break**是循环的"紧急出口"，立即终止整个循环，跳到循环后的代码
- **continue**是循环的"跳过按钮"，跳过本次循环剩余代码，进入下一次迭代
- break常用于**提前结束查找**和**配合死循环做菜单**
- continue常用于**跳过不符合条件的数据**，做"过滤器"
- break**只影响当前层循环**，不影响外层
- while循环中使用continue要小心，确保更新语句不被跳过，否则容易死循环
- 记口诀：**break一刀两断，continue只跳一段**
