# 第06课：听电脑说话——变量入门

## 🎯 学习目标
- 理解变量的概念：给数据贴标签
- 掌握 `int` 类型变量的声明、赋值和使用
- 理解变量名命名规则
- 能够用变量存储和修改数据

## 📖 知识讲解

### 什么是变量？

想象你有一个储物柜。你可以在柜子里放东西——一本书、一个玩具、一包零食。每个柜子都有一个标签，写上里面放的是什么。当你需要的时候，打开标签对应的柜子就能找到东西。

在编程中，**变量**就是这样的"储物柜"——它用来**存储数据**。每个变量有一个名字（标签），里面存着一个值（柜子里的东西）。

变量为什么叫"变"量呢？因为里面的值可以**改变**！就像你今天在柜子里放一本书，明天可以换成一本漫画。变量的值在程序运行过程中是可以变化的。

### 变量的三要素

一个变量有三个重要的属性：

1. **类型**：这个柜子能放什么东西？整数？小数？文字？
2. **名字**：这个柜子叫什么？通过名字来找到它
3. **值**：柜子里现在放的是什么？

举个例子：
```cpp
int age = 10;
```

拆开来看：
- `int`——类型，表示这个变量存的是**整数**（integer）
- `age`——名字，你可以通过"age"这个名字找到它
- `10`——值，现在里面存的是数字10
- `=`——赋值符号，把右边的值放进左边的变量里

### 声明变量：先报名，再使用

在使用一个变量之前，必须**先声明它**。声明就是告诉电脑："嘿，我要用一个柜子，它叫这个名字，里面放这种类型的东西。"

```cpp
int score;        // 声明一个叫 score 的整数变量（柜子还是空的）
score = 100;      // 把 100 放进去
```

也可以声明的同时就放东西进去，这叫**初始化**：

```cpp
int score = 100;  // 声明 + 初始化，一步完成
```

> **重要规则**：必须先声明变量，然后才能使用它！如果直接使用一个从未声明过的变量，编译器会报错：`'xxx' was not declared`。

### int 类型：整数的家

`int` 是 "integer"（整数）的缩写。`int` 类型的变量可以存储整数，比如：
- 你的年龄：10岁
- 你的考试成绩：98分
- 你收集的卡片数量：56张
- 班级的人数：45人

但是 `int` 不能存小数！如果你想把 3.14 存进 int 变量，小数部分会被丢掉，只剩 3。

```cpp
int age = 10;        // ✅ 正确：10是整数
int score = 98;      // ✅ 正确：98是整数
int pi = 3.14;       // ⚠️ 虽然能编译，但pi的值会变成3（小数被丢了）
```

### 变量的值可以改变

变量最厉害的地方就是——它的值可以改变！这就是为什么叫"变"量。

```cpp
int score = 80;           // 初始成绩：80分
cout << score << endl;    // 输出：80

score = 95;               // 成绩提高了！
cout << score << endl;    // 输出：95

score = score + 5;        // 又加了5分！
cout << score << endl;    // 输出：100
```

注意到 `score = score + 5` 这行了吗？这看起来在数学里是不可能的（一个数怎么能等于自己加5？），但在编程中是完全合理的。它表示：**先计算右边**（score + 5 = 95 + 5 = 100），**再把结果存回** score 里。

### 变量命名规则

给变量起名字有一些规则：

| 规则 | 正确示例 | 错误示例 | 原因 |
|------|----------|----------|------|
| 只能用字母、数字、下划线 | `age`, `my_score` | `my-score` | 不能用连字符 |
| 不能以数字开头 | `score1`, `n2` | `1score`, `2nd` | 数字开头不行 |
| 区分大小写 | `age`, `Age`, `AGE` | — | 三个是不同的变量！ |
| 不能用关键字 | `myAge` | `int`, `return` | int是关键字 |
| 见名知意 | `studentAge` | `a`, `x`, `aaa` | 让人看不懂 |

> **命名建议**：用有意义的英文单词，如果不会英文也可以用拼音，比如 `nianLing`（年龄）、`fenShu`（分数）。

### 多个变量

你当然可以声明多个变量：

```cpp
int math = 95;
int english = 88;
int science = 92;

// 也可以一行声明多个（但不推荐，不够清晰）
int a = 1, b = 2, c = 3;
```

### 用变量做计算

变量可以参与计算，就像数字一样：

```cpp
int math = 95;
int english = 88;
int total = math + english;        // total = 183
int average = total / 2;           // average = 91
```

这样，当你改变 `math` 的值时，只需要改一处，所有用到 `math` 的地方都会自动用新值计算。

## 💻 示例代码

### 示例1：变量的基本操作
```cpp
#include <iostream>
using namespace std;

int main() {
    // 声明并初始化变量
    int age = 10;
    cout << "我的年龄是：" << age << "岁" << endl;

    // 修改变量的值
    age = 11;
    cout << "过了一年，我" << age << "岁了。" << endl;

    // 用变量做计算
    int thisYear = 2026;
    int birthYear = thisYear - age;
    cout << "我出生于" << birthYear << "年。" << endl;

    return 0;
}
```

### 示例2：变量值的交换
```cpp
#include <iostream>
using namespace std;

int main() {
    // 两个杯子里的水怎么交换？你需要第三个杯子！
    int cupA = 10;  // A杯子里有10
    int cupB = 20;  // B杯子里有20

    cout << "交换前：A=" << cupA << ", B=" << cupB << endl;

    // 交换两个变量的值
    int temp = cupA;  // 先把A倒进临时杯子
    cupA = cupB;      // 把B倒进A
    cupB = temp;      // 把临时杯子的水倒进B

    cout << "交换后：A=" << cupA << ", B=" << cupB << endl;

    return 0;
}
```

### 示例3：成绩管理系统
```cpp
#include <iostream>
using namespace std;

int main() {
    // 小明各科成绩
    int math = 95;
    int chinese = 88;
    int english = 92;
    int science = 90;

    // 计算总分和平均分
    int total = math + chinese + english + science;
    int average = total / 4;

    // 输出成绩单
    cout << "========== 成绩单 ==========" << endl;
    cout << "数学：" << math << "分" << endl;
    cout << "语文：" << chinese << "分" << endl;
    cout << "英语：" << english << "分" << endl;
    cout << "科学：" << science << "分" << endl;
    cout << "------------------------" << endl;
    cout << "总分：" << total << "分" << endl;
    cout << "平均分：" << average << "分" << endl;

    // 如果英语成绩提高了5分（修改成绩）
    english = 97;
    total = math + chinese + english + science;  // 重新计算总分
    average = total / 4;                          // 重新计算平均

    cout << endl;
    cout << "=== 英语成绩提高后 ===" << endl;
    cout << "英语：" << english << "分（提高了5分！）" << endl;
    cout << "新总分：" << total << "分" << endl;
    cout << "新平均分：" << average << "分" << endl;

    return 0;
}
```

## 🎮 趣味练习

### 练习1：找错误
下面的程序有几个错误，找出来并改正：

```cpp
#include <iostream>
using namespace std;

int main() {
    1stPlace = 100;  // 变量名错误：不能以数字开头
    int score;
    cout << score;   // score没有赋值就直接使用
    int return = 5;  // return是关键字，不能做变量名

    return 0;
}
```

**参考答案：**
```cpp
#include <iostream>
using namespace std;

int main() {
    int firstPlace = 100;    // 修正：变量名不能以数字开头
    int score = 0;           // 修正：先赋值再使用
    cout << score << endl;
    int returnValue = 5;     // 修正：不能用关键字做变量名

    return 0;
}
```

### 练习2：我是计算器
请写一个程序，用变量完成以下任务：
- 定义变量 `length = 10`, `width = 5`（长方形的长和宽）
- 计算周长和面积
- 用 `cout` 输出结果

**参考答案：**
```cpp
#include <iostream>
using namespace std;

int main() {
    int length = 10;    // 长
    int width = 5;      // 宽

    int perimeter = 2 * (length + width);  // 周长 = 2 × (长 + 宽)
    int area = length * width;             // 面积 = 长 × 宽

    cout << "长方形长：" << length << "，宽：" << width << endl;
    cout << "周长 = " << perimeter << endl;
    cout << "面积 = " << area << endl;

    return 0;
}
```

### 练习3：倒计时程序
写一个程序，用一个变量从5倒数到1，每次输出当前数字。提示：用 `score = score - 1` 的方式修改变量的值。

**参考答案：**
```cpp
#include <iostream>
using namespace std;

int main() {
    int count = 5;
    cout << "倒计时开始！" << endl;
    cout << count << "..." << endl;

    count = count - 1;  // count变为4
    cout << count << "..." << endl;

    count = count - 1;  // count变为3
    cout << count << "..." << endl;

    count = count - 1;  // count变为2
    cout << count << "..." << endl;

    count = count - 1;  // count变为1
    cout << count << "..." << endl;

    cout << "发射！🚀" << endl;

    return 0;
}
```

## 🏆 挑战任务

### 挑战：小小收银员

编写一个收银小程序，要求：
1. 定义变量记录：苹果单价、购买数量、付款金额
2. 计算总价和找零
3. 输出一张"购物小票"

要求变量名有意义，程序有适当的注释。

**参考示例：**
```cpp
#include <iostream>
using namespace std;

int main() {
    // 商品信息
    int applePrice = 5;     // 苹果单价：5元/个
    int appleCount = 8;     // 买了8个苹果
    int moneyPaid = 100;    // 付了100元

    // 计算
    int totalPrice = applePrice * appleCount;    // 总价
    int change = moneyPaid - totalPrice;         // 找零

    // 输出购物小票
    cout << "========== 购物小票 ==========" << endl;
    cout << "商品：苹果" << endl;
    cout << "单价：" << applePrice << "元/个" << endl;
    cout << "数量：" << appleCount << "个" << endl;
    cout << "------------------------" << endl;
    cout << "总价：" << totalPrice << "元" << endl;
    cout << "付款：" << moneyPaid << "元" << endl;
    cout << "找零：" << change << "元" << endl;
    cout << "==============================" << endl;
    cout << "谢谢惠顾！欢迎下次再来！😊" << endl;

    return 0;
}
```

## 📝 本课小结

| 知识点 | 说明 |
|--------|------|
| 变量 | 存储数据的"储物柜"，有类型、名字、值三个属性 |
| 声明变量 | `int score;`——告诉电脑你要用这个柜子 |
| 初始化 | `int score = 100;`——声明的同时放东西进去 |
| 赋值 | `score = 95;`——改变柜子里的东西 |
| 变量命名 | 有意义、不能数字开头、不能用关键字 |
| int类型 | 存储整数（年龄、分数、数量等） |
| 变量运算 | 变量可以像数字一样参与加减乘除 |

**记住这句口诀：**
> 变量就像储物柜，贴上标签放东西；int整数最常见，先声明后再使用！
