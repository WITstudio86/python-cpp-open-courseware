叮铃铃——电话响了！"喂？逻辑大侦探事务所。什么？有个神秘的逻辑密码需要破解？好的，我们马上出发！"

同学们，今天你们就是**逻辑大侦探**！上一课我们学了比较运算符，可以用它判断"8比5大吗？"这样简单的问题。但现实中的判断往往更复杂——比如"周末到了**而且**作业写完了吗？""去游乐园**或者**去博物馆？"

### 认识三位逻辑大侦探

逻辑运算符就像侦探破案的工具，它们能把简单的条件组合成复杂的判断。

#### 大侦探1号：与（&&）——"两个条件都要满足"

`&&` 读作"与"或者"并且"。就像侦探说的："两个线索都对上了，才能锁定嫌疑人！"

生活中的例子：
> 要进入游乐园，需要满足两个条件：
> ① 买了门票 ✓
> ② 身高达到120cm ✓
> **两个条件都满足才能进去！**

```cpp
// 判断能否进入游乐园
bool bought_ticket = true;  // 买了票
bool height_ok = true;      // 身高够
bool can_enter = bought_ticket && height_ok;
// can_enter = true && true = true，可以进！
```

`&&` 的规则很简单：**全部为真才是真，只要有一个假就是假。**

#### 大侦探2号：或（||）——"满足一个就行"

`||` 读作"或"或者"或者"。就像侦探说的："这条线索对**或者**那条线索对，都可以继续调查！"

生活中的例子：
> 周末安排：可以看电视**或者**出去踢球。
> 只要满足一个，就是愉快的周末！

```cpp
// 判断周末玩的方案
bool watch_tv = false;    // 不想看电视
bool play_soccer = true;  // 想踢球
bool have_fun = watch_tv || play_soccer;
// have_fun = false || true = true，有开心的安排！
```

`||` 的规则很简单：**只要有一个是真就是真，全部是假才是假。**

#### 大侦探3号：非（!）——"说反话"

`!` 读作"非"或者"取反"。它就像一个爱说反话的小朋友！

生活中的例子：
> "今天不是星期天"  →  !今天是星期天
> 如果今天是星期天（真），那 !真 = 假（意思就是"不是"）
> 如果今天不是星期天（假），那 !假 = 真（意思就是"是"）

```cpp
bool is_sunday = false;   // 今天不是星期天
bool is_school_day = !is_sunday;
// is_school_day = !false = true，要上学！
```

`!` 的规则最简单：**真变假，假变真。**就像翻硬币——正面翻过来是反面，反面翻过来是正面。

### 真值表——逻辑大侦探的秘密武器

真值表就像一张"密码破译表"，它列出了所有可能的情况和对应的结果。让我们来看看三位大侦探的真值表：

**&&（与）真值表——"两个都要对"**

| 条件A | 条件B | A && B | 解读 |
|-------|-------|--------|------|
| true | true | **true** | 两个都对 → 对 ✓ |
| true | false | **false** | 一个对一个错 → 错 ✗ |
| false | true | **false** | 一个错一个对 → 错 ✗ |
| false | false | **false** | 两个都错 → 错 ✗ |

**记忆口诀**：一假全假，全真才真！

**||（或）真值表——"一个对就行"**

| 条件A | 条件B | A \|\| B | 解读 |
|-------|-------|---------|------|
| true | true | **true** | 两个都对 → 对 ✓ |
| true | false | **true** | 一个对 → 对 ✓ |
| false | true | **true** | 一个对 → 对 ✓ |
| false | false | **false** | 两个都错 → 错 ✗ |

**记忆口诀**：一真全真，全假才假！

**!（非）真值表——"说反话"**

| 条件A | !A | 解读 |
|-------|-----|------|
| true | **false** | 真的反面是假 |
| false | **true** | 假的反面是真 |

**记忆口诀**：真变假，假变真！

### 短路求值——聪明的大侦探

大侦探还有一个特殊技能叫**短路求值**。什么意思呢？

**对于 &&（与）**：如果左边的条件已经是 `false` 了，那右边就不用看了——因为不管右边是什么，结果都是 `false`！

```cpp
false && ???  // → 结果肯定是false，右边不用算了！
```

**对于 ||（或）**：如果左边已经是 `true` 了，那右边也不用看了——因为不管右边是什么，结果都是 `true`！

```cpp
true || ???  // → 结果肯定是true，右边不用算了！
```

这就像聪明的侦探：一旦找到关键证据，其他线索就不用再查了！

### 把比较和逻辑结合起来

比较运算符和逻辑运算符是黄金搭档！它们一起使用，能写出非常强大的判断条件：

```cpp
// 判断一个数是否在10到20之间
if (x >= 10 && x <= 20) {
    // x 在 [10, 20] 这个区间里
}

// 判断一个数是否在区间外
if (x < 10 || x > 20) {
    // x 不在 [10, 20] 这个区间里
}

// 判断成绩是否及格且在优秀以下
if (score >= 60 && score < 90) {
    cout << "及格但还需努力！" << endl;
}
```

## 💻 示例代码

### 示例1：逻辑与(&&)——都要满足
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "===== 游乐园入园检查 =====" << endl;
    
    // 入园条件：①买了票 ②身高>=120cm
    bool has_ticket = true;
    int height = 130;
    
    cout << "买票了吗？ " << has_ticket << endl;
    cout << "身高多少？ " << height << "cm" << endl;
    cout << endl;
    
    if (has_ticket && height >= 120) {
        cout << "✅ 欢迎进入游乐园！请尽情玩耍！" << endl;
    } else {
        cout << "❌ 抱歉，暂时不能进入。" << endl;
        if (!has_ticket) {
            cout << "   原因：还没买票哦～" << endl;
        }
        if (height < 120) {
            cout << "   原因：身高还不够呢，再长高点吧！" << endl;
        }
    }
    
    return 0;
}
```

### 示例2：逻辑或(||)——满足一个就行
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "===== 周末活动选择器 =====" << endl;
    
    bool watch_tv = true;
    bool play_outside = false;
    bool read_book = true;
    
    cout << "看电视？ " << watch_tv << endl;
    cout << "出去玩？ " << play_outside << endl;
    cout << "看书？ " << read_book << endl;
    cout << endl;
    
    if (watch_tv || play_outside || read_book) {
        cout << "😊 至少有一件事可以做，周末不无聊！" << endl;
    } else {
        cout << "😴 什么都没安排，睡大觉吧！" << endl;
    }
    
    return 0;
}
```

### 示例3：逻辑非(!)——说反话
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "===== !（非）运算符演示 =====" << endl;
    
    bool is_raining = false;
    bool is_sunny = true;
    
    cout << "下雨了吗？ " << is_raining << endl;
    cout << "没下雨？ " << !is_raining << " （取反）" << endl;
    cout << endl;
    cout << "是晴天吗？ " << is_sunny << endl;
    cout << "不是晴天？ " << !is_sunny << " （取反）" << endl;
    cout << endl;
    cout << "===== 规律：!true=false, !false=true =====" << endl;
    
    return 0;
}
```

## 🎮 趣味练习

### 练习1：逻辑侦探考试
请判断下列表达式的真假（true还是false？）：

```
① true && false    →  _____
② true || false    →  _____
③ !true            →  _____
④ (5 > 3) && (2 < 1)   →  _____
⑤ (8 == 8) || (3 > 10) →  _____
⑥ !(4 <= 2)        →  _____
⑦ (10 > 5) && (6 != 3) && (7 >= 7)  →  _____
⑧ false || false || true   →  _____
```

**参考答案：**
① false（&&需要两个都为真）
② true（||只有一个真就行）
③ false（取反）
④ false（5>3是true，但2<1是false，true && false = false）
⑤ true（8==8是true，||只需要一个真）
⑥ true（4<=2是false，!false = true）
⑦ true（三个条件全真，&&的结果为true）
⑧ true（||只要有一个真就行）

## 🏆 挑战任务

### 挑战：闰年判断器

编写一个"闰年判断器"程序：输入一个年份，判断它是否是闰年。

**闰年规则（公历）：**
1. 能被4整除，但**不能**被100整除
2. **或者**能被400整除

也就是说：
```
闰年 = (能被4整除 && 不能被100整除) || (能被400整除)
```

提示：判断能否整除，用取余运算符 `%`。比如 `year % 4 == 0` 表示能被4整除。

**参考示例：**
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "===== 🔍 闰年判断器 =====" << endl;
    cout << "请输入一个年份：";
    
    int year;
    cin >> year;
    
    cout << endl;
    
    // 闰年判断：逻辑运算符综合运用
    // 规则1：能被4整除但不能被100整除 → year%4==0 && year%100!=0
    // 规则2：能被400整除 → year%400==0
    // 综合：规则1 或 规则2
    bool is_leap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
    
    cout << "===== 判断结果 =====" << endl;
    cout << "年份：" << year << endl;
    
    if (is_leap) {
        cout << "结果：是闰年！✅" << endl;
        cout << year << "年的2月有29天哦！" << endl;
    } else {
        cout << "结果：不是闰年。❌" << endl;
        cout << year << "年的2月有28天。" << endl;
    }
    
    // 展示判断细节
    cout << endl;
    cout << "----- 判断过程 -----" << endl;
    cout << year << " % 4 == 0 ? " << (year % 4 == 0) << endl;
    cout << year << " % 100 != 0 ? " << (year % 100 != 0) << endl;
    cout << year << " % 400 == 0 ? " << (year % 400 == 0) << endl;
    
    return 0;
}
```

**测试数据：**
```
2000 → 闰年（能被400整除）
2004 → 闰年（能被4整除且不能被100整除）
1900 → 不是闰年（能被100整除但不能被400整除）
2024 → 闰年（能被4整除且不能被100整除）
2023 → 不是闰年（不能被4整除）
```

## 📝 本课小结

| 运算符 | 名称 | 含义 | 口诀 |
|--------|------|------|------|
| `&&` | 逻辑与 | 两个条件都满足才为真 | 全真才真，一假全假 |
| `\|\|` | 逻辑或 | 满足一个条件就为真 | 一真全真，全假才假 |
| `!` | 逻辑非 | 把真变假，把假变真 | 说反话，真假颠倒 |

**&& 真值表速查：**
```
true  && true  → true      ✅
true  && false → false     ❌
false && true  → false     ❌
false && false → false     ❌
```

**|| 真值表速查：**
```
true  || true  → true      ✅
true  || false → true      ✅
false || true  → true      ✅
false || false → false     ❌
```

**运算符优先级（从高到低）：**
`!` → `算术运算符` → `比较运算符` → `&&` → `||`

**记住这句口诀：**
> 与是同时都要有，或是至少有一个，非是说反话颠倒走。比较逻辑是搭档，复杂判断不用愁！
>
> **小提示**：比较运算符和逻辑运算符是黄金搭档，把它们组合起来，你就能写出"大于10且小于20"、"不是周末或者天气好"这样的复杂判断了！下一课我们就要用它们来控制程序的走向——if条件语句等着你！
