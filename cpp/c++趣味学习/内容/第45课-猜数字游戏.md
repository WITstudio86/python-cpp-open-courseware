## 一、生活中的猜数字

同学们，你们玩过"猜数字"的游戏吗？一个人心里想一个数字，另一个人来猜。猜的人每猜一次，出题人就告诉他"大了"还是"小了"，直到猜对为止。

这个游戏看起来简单，但里面藏着大学问！假如数字范围是 1 到 100：
- 如果你从 1 开始一个一个猜（1、2、3……），运气不好的话要猜 100 次！
- 如果你每次猜中间的数字，最多只需要 7 次就能猜中！

为什么差距这么大？答案就是今天我们要学的——**二分查找**（又叫折半查找）。

> 二分查找的核心思想：每次猜中间值，根据"大了"还是"小了"的反馈，排除掉一半，剩下的范围越来越小，直到找到答案。

## 二、让电脑"想"一个数字——随机数生成

在 C++ 中，我们使用 `rand()` 函数来生成随机数。但是，`rand()` 每次运行程序生成的"随机数"序列都是一样的（这叫**伪随机数**）。为了让每次运行都产生不同的数字，我们需要使用 `srand()` 配合时间种子。

### 2.1 rand() 的基本使用

```cpp
#include <iostream>
#include <cstdlib>   // rand() 和 srand() 在这里
#include <ctime>     // time() 在这里
using namespace std;

int main() {
    srand(time(0));  // 用当前时间做种子，保证每次运行结果不同
    
    int secret = rand();  // 生成一个随机整数
    cout << "随机数：" << secret << endl;
    
    return 0;
}
```

**重要说明：**
- `rand()` 生成的随机数范围是 0 到 `RAND_MAX`（通常约 32767）。
- `srand(time(0))` 用当前时间（秒数）作为"种子"。因为时间每秒钟都在变，所以每次运行都会得到不同的随机数序列。
- **`srand(time(0))` 在整个程序中只需要调用一次！** 放在 `main()` 函数的开头就好。

### 2.2 生成指定范围的随机数

大多数情况下，我们不想要 0 到 32767 那么大的随机数。比如猜数字游戏，我们可能希望范围是 1 到 100。这时候需要用到**取余运算**：

```cpp
// 公式：rand() % (最大值 - 最小值 + 1) + 最小值

// 生成 1 到 100 的随机数
int secret = rand() % 100 + 1;

// 解释：rand() % 100 生成 0~99，再加 1 变成 1~100

// 生成 50 到 200 的随机数
int num = rand() % 151 + 50;
// rand() % 151 生成 0~150，加 50 变成 50~200
```

**通用公式：**
```
rand() % (max - min + 1) + min
```

这个公式非常重要，后面的程序里会反复用到。请把它记下来！

## 三、二分查找——猜数字的最佳策略

### 3.1 什么是二分查找？

二分查找就像翻字典：你想查一个单词，不会从第一页开始一页一页翻，而是先翻到中间，看看目标单词在前面还是后面，然后排除掉一半的页面。反复这样做，很快就能找到。

用猜数字来理解二分查找最直观：
1. 范围是 1~100
2. 先猜 50（中间值）
3. 如果"大了"，说明答案在 1~49 之间，排除 50~100
4. 如果"小了"，说明答案在 51~100 之间，排除 1~50
5. 在新的范围内再猜中间值
6. 反复进行，每次排除一半

### 3.2 图解二分查找过程

假设目标数字是 73：

```
第1次：范围 [1, 100]，猜 50 → 小了！范围缩小到 [51, 100]
第2次：范围 [51, 100]，猜 75 → 大了！范围缩小到 [51, 74]
第3次：范围 [51, 74]，猜 62 → 小了！范围缩小到 [63, 74]
第4次：范围 [63, 74]，猜 68 → 小了！范围缩小到 [69, 74]
第5次：范围 [69, 74]，猜 71 → 小了！范围缩小到 [72, 74]
第6次：范围 [72, 74]，猜 73 → 猜中了！
```

只用了 6 次！如果用从 1 开始的一个一个猜法，要猜 73 次。

### 3.3 为什么二分查找这么高效？

| 数据范围 | 最多需要猜的次数 | 说明 |
|---|---|---|
| 1~10 | 4次 | 2⁴ = 16 ≥ 10 |
| 1~100 | 7次 | 2⁷ = 128 ≥ 100 |
| 1~1000 | 10次 | 2¹⁰ = 1024 ≥ 1000 |
| 1~10000 | 14次 | 2¹⁴ = 16384 ≥ 10000 |
| 1~100万 | 20次 | 2²⁰ ≈ 104万 |

二分查找每猜一次，范围就缩小一半。这种"指数级缩小"的速度非常惊人！我们称之为**对数级复杂度**，用 O(log₂n) 表示。这是计算机科学中最优雅的算法之一。

### 3.4 二分查找的适用条件

二分查找虽然高效，但它有一个前提：**数据必须是有序的**。猜数字游戏天然满足这个条件——1 到 100 本身就是从小到大排列的。

如果数据是无序的（乱序数组），就不能用二分查找，只能用线性查找一个一个找。

## 四、猜数字游戏规则设计

一个完整的猜数字游戏需要包含以下要素：

1. **随机出题**：电脑生成一个 1~100 的随机数作为"密码"。
2. **玩家输入**：玩家输入自己的猜测。
3. **比较提示**：电脑告诉玩家猜大了还是猜小了。
4. **计次统计**：记录玩家一共猜了几次。
5. **胜利提示**：猜中后显示结果和猜测次数。
6. **可选功能**：限制猜测次数、难度选择、排行榜等。

### 游戏流程图

```
开始
  ↓
电脑生成随机数（1~100）
  ↓
玩家输入猜测 ←——————┐
  ↓                    │
比较：猜大了？猜小了？猜对了？  │
  ↓         ↓         │
输出"大了"  输出"小了"   │
  │         │         │
  └─────────┴────→ 次数+1，继续循环
                      ↓
                    猜对了！
                      ↓
              输出结果和次数
                      ↓
                     结束
```

## 五、完整示例代码

### 示例1：基础猜数字游戏（电脑出题，玩家猜）

```cpp
#include <iostream>
#include <cstdlib>   // rand() 和 srand()
#include <ctime>     // time()
using namespace std;

int main() {
    // 1. 设置随机种子（用当前时间）
    srand(time(0));

    // 2. 生成 1~100 的随机数
    int secret = rand() % 100 + 1;

    int guess;      // 玩家猜的数字
    int count = 0;  // 猜测次数

    cout << "====================================" << endl;
    cout << "  欢迎来到猜数字游戏！" << endl;
    cout << "  我已经想好了一个 1~100 之间的数字" << endl;
    cout << "  快来猜猜看吧！" << endl;
    cout << "====================================" << endl;

    // 3. 循环猜数
    do {
        cout << "请输入你猜的数字：";
        cin >> guess;
        count++;  // 每次猜测，次数+1

        if (guess > secret) {
            cout << "太大了！往小猜一猜~" << endl;
        } else if (guess < secret) {
            cout << "太小了！往大猜一猜~" << endl;
        } else {
            cout << endl;
            cout << "🎉 恭喜你猜对了！" << endl;
            cout << "正确答案就是：" << secret << endl;
            cout << "你一共猜了 " << count << " 次！" << endl;
        }
    } while (guess != secret);

    return 0;
}
```

**运行示例：**
```
====================================
  欢迎来到猜数字游戏！
  我已经想好了一个 1~100 之间的数字
  快来猜猜看吧！
====================================
请输入你猜的数字：50
太大了！往小猜一猜~
请输入你猜的数字：25
太小了！往大猜一猜~
请输入你猜的数字：37
太大了！往小猜一猜~
请输入你猜的数字：31
太小了！往大猜一猜~
请输入你猜的数字：34
🎉 恭喜你猜对了！
正确答案就是：34
你一共猜了 5 次！
```

### 示例2：带提示和计次的升级版

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));

    int secret = rand() % 100 + 1;
    int guess;
    int count = 0;
    const int MAX_GUESS = 10;  // 最多猜10次

    cout << "========================================" << endl;
    cout << "  升级版猜数字游戏 🎯" << endl;
    cout << "  规则：猜 1~100 的数字，最多 " << MAX_GUESS << " 次机会" << endl;
    cout << "========================================" << endl;

    while (count < MAX_GUESS) {
        cout << "\n第 " << count + 1 << " 次猜测（还剩 " 
             << MAX_GUESS - count << " 次机会）：";
        cin >> guess;
        count++;

        if (guess == secret) {
            cout << "\n🎉 恭喜！你在第 " << count << " 次猜对了！" << endl;
            cout << "正确答案：" << secret << endl;
            
            // 评价猜测水平
            if (count == 1) {
                cout << "运气爆棚！一次就中！你是天选之子！" << endl;
            } else if (count <= 3) {
                cout << "非常厉害！你是猜数小天才！" << endl;
            } else if (count <= 5) {
                cout << "不错哦！逻辑思维很棒！" << endl;
            } else if (count <= 7) {
                cout << "还可以，继续加油！" << endl;
            } else {
                cout << "下次试试二分法，会更快哦！" << endl;
            }
            return 0;
        } else if (guess > secret) {
            cout << "📉 太大了！往下猜~";
            if (guess - secret > 20) {
                cout << "（差得很远哦）";
            }
            cout << endl;
        } else {
            cout << "📈 太小了！往上猜~";
            if (secret - guess > 20) {
                cout << "（差得很远哦）";
            }
            cout << endl;
        }
    }

    // 次数用完了
    cout << "\n😢 很遗憾，10 次机会用完了！" << endl;
    cout << "正确答案是：" << secret << endl;
    cout << "下次试试从中间开始猜，会更高效！" << endl;

    return 0;
}
```

## 六、练习题

### 练习1：修改随机数范围（简单）

将猜数字游戏的范围改为 1 到 50，并修改相应的提示文字。

**参考答案：**

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));
    int secret = rand() % 50 + 1;  // 修改为 1~50
    int guess;
    
    cout << "我已经想好了一个 1~50 之间的数字，来猜猜看！" << endl;

        cout << "请输入你猜的数字：";

```

**关键修改：** `rand() % 50 + 1` 生成 1~50。公式 `rand() % N + 1` 生成 1~N。

### 练习3：找bug（简单）

下面的程序有一段代码写错了，你能找出来吗？

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));
    int secret = rand() % 100 + 0;  // 这里对吗？
    int guess;
    
    cout << "猜 1~100 的数字：" << endl;
    cin >> guess;
    
    if (guess = secret) {  // 这里对吗？
        cout << "猜对了！" << endl;
    }
    
    return 0;
}
```

**答案：**

1. `rand() % 100 + 0` 生成的是 0~99，不是 1~100。应该改为 `rand() % 100 + 1`。
2. `if (guess = secret)` 是一个**赋值语句**，不是比较！在 C++ 中，`=` 是赋值，`==` 才是比较。这里应该改为 `if (guess == secret)`。这个 bug 会导致 `guess` 被赋值为 `secret`，条件永远为真。

## 七、挑战任务

### 🏆 终极挑战：让电脑用二分法猜你的数字！

**任务描述：**

这次反过来！你在心里想一个 1~100 的数字（或者写在纸上），让电脑用二分查找法来猜你的数字。程序每次输出一个猜测，你告诉电脑"大了"、"小了"还是"对了"，直到电脑猜中为止。

**要求：**
1. 电脑必须使用二分查找策略（每次猜当前范围的中间值）
2. 统计电脑猜了多少次
3. 显示每次猜测后范围的缩小过程

**提示：**
- 用两个变量 `low` 和 `high` 分别表示当前范围的下界和上界
- 每次猜 `mid = (low + high) / 2`
- 如果"大了"，则 `high = mid - 1`
- 如果"小了"，则 `low = mid + 1`
- 如果"对了"，游戏结束
