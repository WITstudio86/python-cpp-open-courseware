# 第27课：找呀找呀找——数组查找

## 课程导入

同学们，假如老师手里有一份全班40位同学的数学成绩单，现在老师想要知道：谁考了第一名？有没有人得了满分？张三同学考了多少分？如果我们用眼睛一个一个去找，不仅费时费力，还容易看漏。但是，如果我们把这些成绩存进计算机的数组里，就可以让程序帮我们"找呀找呀找"，快速找到我们想要的信息！

数组就像一个排列整齐的抽屉柜，每个抽屉里放着一个数据。今天我们要学习的就是：怎么在数组中进行"查找"，包括查找特定的值、找出最大值和最小值。这就像在一排数字里玩"捉迷藏"——让我们来看看怎么把那个"藏起来"的数字最快找出来！

在日常生活中，查找无处不在：超市里找最便宜的商品、运动会上找跑得最快的选手、考试后找最高分的同学……学会数组查找，你就能写出让计算机自动完成这些任务的程序了！

## 核心概念

### 1. 什么是线性查找？

**线性查找**（Linear Search）是最简单、最直观的查找方法。它的思路就像是逐页翻书：从数组的第一个元素开始，一个一个往后看，直到找到目标值为止。

线性查找可以用于：
- 查找数组中是否存在某个值
- 查找某个值在数组中的位置（下标）
- 查找数组中满足某个条件的所有元素

**基本步骤**：
1. 从数组的第一个元素（下标0）开始
2. 逐个检查每个元素是否等于目标值
3. 如果找到，返回当前位置
4. 如果找完整个数组都没有找到，说明该值不存在

### 2. 查找最大值

查找数组中的最大值是另一类常见的查找任务。思路是：
1. 先假设第一个元素是最大值
2. 从第二个元素开始，逐个与当前最大值比较
3. 如果遇到更大的值，就更新最大值
4. 遍历完整个数组后，当前记录的就是真正的最大值

### 3. 查找最小值

查找最小值的方法与最大值类似，只是比较方向相反：
1. 先假设第一个元素是最小值
2. 逐个比较，遇到更小的值就更新

### 4. 记录位置信息

在实际应用中，我们常常不仅要知道最大值是多少，还要知道它在数组中的位置（谁得了最高分）。因此，在更新最大值的同时，也要记录下它的下标。

## 代码示例

### 示例1：线性查找——在数组中查找特定值

```cpp
#include <iostream>
using namespace std;

int main() {
    int scores[] = {85, 92, 78, 95, 88, 76, 90, 83};
    int n = 8;  // 数组长度
    int target;

    cout << "请输入要查找的分数：";
    cin >> target;

    int pos = -1;  // -1 表示没找到
    for (int i = 0; i < n; i++) {
        if (scores[i] == target) {
            pos = i;
            break;  // 找到了，退出循环
        }
    }

    if (pos != -1) {
        cout << "找到了！分数 " << target << " 在第 " << pos + 1 << " 个位置（下标" << pos << "）。" << endl;
    } else {
        cout << "没有找到分数 " << target << "。" << endl;
    }

    return 0;
}
```

**逐行解释**：
- 第5行：定义一个包含8个成绩的数组
- 第12行：`pos = -1` 是一个常用的技巧，用 -1 表示"还没找到"
- 第13-17行：用 for 循环遍历数组，比较每个元素与目标值
- 第15行：如果匹配成功，记录位置并用 `break` 跳出循环（因为不需要继续找了）
- 第20-23行：根据 pos 是否还是 -1 来判断找到了没有

### 示例2：查找最大值及其位置

```cpp
#include <iostream>
using namespace std;

int main() {
    int scores[] = {85, 92, 78, 95, 88, 76, 90, 83};
    int n = 8;

    int maxScore = scores[0];  // 假设第一个是最大值
    int maxIndex = 0;          // 记录最大值的位置

    for (int i = 1; i < n; i++) {
        if (scores[i] > maxScore) {
            maxScore = scores[i];
            maxIndex = i;
        }
    }

    cout << "最高分是：" << maxScore << endl;
    cout << "最高分在第 " << maxIndex + 1 << " 个位置。" << endl;

    return 0;
}
```

### 示例3：寻找最高分的同学（完整项目）

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    const int N = 5;
    string names[N];
    int scores[N];

    // 输入学生姓名和成绩
    cout << "请输入 " << N << " 位同学的姓名和成绩：" << endl;
    for (int i = 0; i < N; i++) {
        cout << "第 " << i + 1 << " 位同学姓名：";
        cin >> names[i];
        cout << names[i] << " 的成绩：";
        cin >> scores[i];
    }

    // 查找最高分
    int maxScore = scores[0];
    int maxIndex = 0;
    for (int i = 1; i < N; i++) {
        if (scores[i] > maxScore) {
            maxScore = scores[i];
            maxIndex = i;
        }
    }

    // 查找最低分
    int minScore = scores[0];
    int minIndex = 0;
    for (int i = 1; i < N; i++) {
        if (scores[i] < minScore) {
            minScore = scores[i];
            minIndex = i;
        }
    }

    cout << "\n========== 成绩分析结果 ==========" << endl;
    cout << "最高分：" << names[maxIndex] << " 同学，成绩为 " << maxScore << " 分！" << endl;
    cout << "最低分：" << names[minIndex] << " 同学，成绩为 " << minScore << " 分。" << endl;

    // 查找特定同学
    string searchName;
    cout << "\n请输入要查找的同学姓名：";
    cin >> searchName;

    bool found = false;
    for (int i = 0; i < N; i++) {
        if (names[i] == searchName) {
            cout << searchName << " 的成绩是：" << scores[i] << " 分。" << endl;
            found = true;
            break;
        }
    }
    if (!found) {
        cout << "没有找到 " << searchName << " 同学。" << endl;
    }

    return 0;
}
```

## 本课小结

1. **线性查找**是最基本的查找方法：从数组第一个元素开始，逐个比较，直到找到目标值或遍历完整个数组。
2. 查找**最大值**的方法：先假设第一个是最大值，然后遍历数组，遇到更大的就更新。
3. 查找**最小值**的方法与最大值类似，只是比较条件从"大于"变成"小于"。
4. 在实际项目中，我们往往需要**同时记录值和位置**（下标），这样才能知道"谁"获得了最高分。
5. 使用 **break** 可以在找到目标后提前结束循环，提高效率。
6. 数组查找是编程中最常用的操作之一，掌握了它，你就能够解决很多实际问题，比如成绩分析、数据统计、信息检索等。
