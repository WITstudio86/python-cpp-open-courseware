# 第11课：关系对对碰——比较运算符

## 🎯 学习目标
- 认识C++六种比较运算符：>、<、>=、<=、==、!=
- 理解比较运算的结果是布尔值（true/false，即1/0）
- 能运用比较运算符解决判断大小的实际问题

## 📖 知识讲解

### 欢迎来到数字比大小擂台！

同学们，今天我们要举办一场特别的比赛——**数字比大小擂台**！两个数字上台PK，谁大谁小？谁和谁一样？这就需要一位公正的裁判——**比较运算符**。

假设你和小伙伴站在一起比身高，你会说"我比他高"或者"他比我矮"。在C++的世界里，比较运算符就是帮电脑做这种判断的工具。

### 认识六位"裁判"

C++里有六位比较裁判，它们各有各的本事：

| 运算符 | 名称 | 含义 | 生活例子 |
|--------|------|------|----------|
| `>` | 大于 | 左边比右边大吗？ | 小红身高150cm > 小明身高140cm？是的！ |
| `<` | 小于 | 左边比右边小吗？ | 你的年龄10岁 < 爸爸年龄35岁？是的！ |
| `>=` | 大于等于 | 左边不小于右边吗？ | 游乐园要求身高>=120cm，你130cm能进吗？能！ |
| `<=` | 小于等于 | 左边不大于右边吗？ | 考试分数<=60分不及格，你考了59分…加油呀！ |
| `==` | 等于 | 左边和右边一样吗？ | 你的学号==23号？是的话就是你！ |
| `!=` | 不等于 | 左边和右边不一样吗？ | 今天!=星期天？对，今天要上学！ |

> **特别注意**：`==`（两个等号）和 `=`（一个等号）是完全不同的东西！**这是初学者最最容易犯的错！**
> - `=` 是赋值：把右边的数装进左边的变量里。比如 `int a = 5;` 意思是让a变成5。
> - `==` 是判断：左边和右边相等吗？比如 `a == 5` 是在问"a是5吗？"
>
> 你可以这样记：**一个等号是"变成"，两个等号是"等于吗？"**

### 比较运算的结果

比较运算符做完判断后，会给出一个答案。这个答案只有两种可能：
- **对**（true / 真）—— 在C++里用 `1` 表示
- **错**（false / 假）—— 在C++里用 `0` 表示

这就像考试里的判断题，答案只能是"对"或"错"，没有"差不多"！

来看几个例子：

```cpp
cout << (8 > 5) << endl;    // 输出：1（8比5大，对！）
cout << (3 == 4) << endl;   // 输出：0（3等于4？错！）
cout << (7 <= 7) << endl;   // 输出：1（7小于等于7？对！因为7等于7）
cout << (10 != 9) << endl;  // 输出：1（10不等于9？对！）
```

看到了吗？电脑用 `1` 代表"对"，用 `0` 代表"错"。这种只有两种可能的结果，在编程里叫**布尔值**（bool）。

### 比较运算符的小陷阱

#### 陷阱1：= 和 == 傻傻分不清

```cpp
int a = 5;        // 赋值：让a变成5
if (a == 3) {     // 判断：a等于3吗？（结果是false）
    cout << "相等";
}
// 如果你不小心写成了 if (a = 3)
// 那就变成了"把3赋值给a"，这行代码永远不会报错，但结果就完全错了！
```

#### 陷阱2：不要连续比较

在数学里我们写 `1 < x < 10` 表示x在1和10之间。但在C++里不能这样写！你需要用逻辑运算符（下一课学）来连接：

```cpp
// ❌ 错误写法（不会报错，但意思完全不同）
if (1 < x < 10)

// ✅ 正确写法（配合逻辑运算符&&，第12课详细学）
if (x > 1 && x < 10)
```

## 💻 示例代码

### 示例1：比较两个数字——比大小擂台
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 8, b = 5;
    
    cout << "===== 数字比大小擂台 =====" << endl;
    cout << "红方选手：" << a << "  VS  蓝方选手：" << b << endl;
    cout << endl;
    
    cout << a << " > " << b << " 吗？ " << (a > b) << " (1=对, 0=错)" << endl;
    cout << a << " < " << b << " 吗？ " << (a < b) << " (1=对, 0=错)" << endl;
    cout << a << " >= " << b << " 吗？ " << (a >= b) << " (1=对, 0=错)" << endl;
    cout << a << " <= " << b << " 吗？ " << (a <= b) << " (1=对, 0=错)" << endl;
    cout << a << " == " << b << " 吗？ " << (a == b) << " (1=对, 0=错)" << endl;
    cout << a << " != " << b << " 吗？ " << (a != b) << " (1=对, 0=错)" << endl;
    
    return 0;
}
```

**运行结果：**
```
===== 数字比大小擂台 =====
红方选手：8  VS  蓝方选手：5

8 > 5 吗？ 1 (1=对, 0=错)
8 < 5 吗？ 0 (1=对, 0=错)
8 >= 5 吗？ 1 (1=对, 0=错)
8 <= 5 吗？ 0 (1=对, 0=错)
8 == 5 吗？ 0 (1=对, 0=错)
8 != 5 吗？ 1 (1=对, 0=错)
```

### 示例2：=和==的区别陷阱（重要！）
```cpp
#include <iostream>
using namespace std;

int main() {
    int score = 60;  // ← = 是赋值：设分数为60
    
    cout << "你的分数是：" << score << endl;
    cout << endl;
    
    // 判断是否及格（分数大于等于60）
    cout << "----- 正确写法 -----" << endl;
    if (score >= 60) {                    // >= 是比较运算符
        cout << "恭喜！你及格了！" << endl;
    }
    
    // 判断是不是满分
    cout << endl;
    cout << "----- 判断是否满分 -----" << endl;
    if (score == 100) {                   // == 是比较（两个等号！）
        cout << "满分！太厉害了！" << endl;
    } else {
        cout << "还不是满分，继续加油！" << endl;
    }
    
    // ⚠️ 常见错误演示（注释掉的代码）
    // if (score = 100) {   // 这是赋值！不是判断！score会变成100
    //     cout << "这行永远会执行，因为赋值语句的值是非0（真）" << endl;
    // }
    
    return 0;
}
```

### 示例3：比较运算符综合应用——成绩评级
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "===== 成绩判断系统 =====" << endl;
    
    int math = 95;      // 数学成绩
    int english = 88;   // 英语成绩
    int chinese = 82;   // 语文成绩
    
    cout << "数学：" << math << endl;
    cout << "英语：" << english << endl;
    cout << "语文：" << chinese << endl;
    cout << endl;
    
    // 判断最高分
    cout << "----- 成绩分析 -----" << endl;
    if (math > english) {
        cout << "数学 > 英语" << endl;
    }
    if (english > chinese) {
        cout << "英语 > 语文" << endl;
    }
    
    // 判断是否有满分
    cout << "数学 == 100？ " << (math == 100) << endl;
    cout << "英语 == 100？ " << (english == 100) << endl;
    
    // 判断两科是否同分
    cout << "数学和英语同分？ " << (math == english) << endl;
    cout << "语文不等于数学？ " << (chinese != math) << endl;
    
    return 0;
}
```

### 练习2：找茬大侦探
下面代码有什么问题？请指出并改正。
```cpp
int a = 5;
if (a = 3) {
    cout << "相等";
}
```

**参考答案：**
问题出在 `if (a = 3)` —— 这里用的是赋值运算符 `=`，而不是比较运算符 `==`。正确的写法应该是 `if (a == 3)`。使用 `=` 的话，`a` 会被改成3，而且整个表达式 `a = 3` 的值是3（非0），所以if条件永远为真，程序会永远输出"相等"，完全失去了判断的意义！

### 练习3：编写比大小程序
编写一个程序，输入两个整数，判断第一个数是否大于第二个数，并输出结果。

**参考答案：**
```cpp
#include <iostream>
using namespace std;

int main() {
    int num1, num2;
    
    cout << "请输入第一个整数：";
    cin >> num1;
    cout << "请输入第二个整数：";
    cin >> num2;
    
    cout << endl;
    cout << "===== 比较结果 =====" << endl;
    
    if (num1 > num2) {
        cout << num1 << " 大于 " << num2 << endl;
    } else if (num1 < num2) {
        cout << num1 << " 小于 " << num2 << endl;
    } else {
        cout << num1 << " 等于 " << num2 << endl;
    }
    
    return 0;
}
```

## 🏆 挑战任务

### 挑战：数字比大小擂台——找出最大值

编写一个"数字比大小擂台"程序：
- 输入三个整数
- 使用比较运算符判断它们的大小关系
- 找出最大值并输出
- 如果三个数都相等，输出"三位选手打平！"

提示：可以先比较前两个数，找出较大的那个，再和第三个数比较。

**参考示例：**
```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b, c;
    int max;
    
    cout << "===== 数字比大小擂台 =====" << endl;
    cout << "请输入三位选手的分数：" << endl;
    cout << "红方选手：";
    cin >> a;
    cout << "蓝方选手：";
    cin >> b;
    cout << "绿方选手：";
    cin >> c;
    
    cout << endl;
    cout << "===== 比赛结果 =====" << endl;
    
    // 先比较 a 和 b
    if (a > b) {
        max = a;
    } else {
        max = b;
    }
    
    // 再用 max 和 c 比较
    if (c > max) {
        max = c;
    }
    
    // 判断是否有平局
    if (a == b && b == c) {
        cout << "三位选手打平！大家都是" << a << "分！" << endl;
    } else {
        cout << "冠军得分：" << max << " 分！" << endl;
    }
    
    return 0;
}
```

## 📝 本课小结

| 运算符 | 名称 | 例子 | 结果为true的情况 |
|--------|------|------|-----------------|
| `>` | 大于 | `8 > 5` | 左边大于右边 |
| `<` | 小于 | `3 < 10` | 左边小于右边 |
| `>=` | 大于等于 | `7 >= 7` | 左边不小于右边 |
| `<=` | 小于等于 | `5 <= 8` | 左边不大于右边 |
| `==` | 等于 | `10 == 10` | 左右两边相等 |
| `!=` | 不等于 | `4 != 9` | 左右两边不同 |

> **重中之重：**
> - `=` 是赋值（把东西放进去），`==` 是判断（问相等吗？）
> - 比较结果是布尔值：真（1）或假（0）
> - 不能连续写成 `1 < x < 10`，要配合逻辑运算符使用

**记住这句口诀：**
> 比较运算有六种，大于小于两兄弟；等于用两个等号，一个等号是赋值！比较结果只有真和假，true就是1，false就是0！
