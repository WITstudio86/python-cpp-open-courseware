# 第19课：先斩后奏——do-while循环

## 🎯 学习目标
- 理解do-while循环"先执行后判断"的特点
- 掌握do-while与while循环的区别和适用场景
- 能够根据需求选择合适的循环结构

## 📖 知识讲解

### 什么是do-while循环？

古人有一句话叫"先斩后奏"，意思是先行动再报告。do-while循环就是编程世界中的"先斩后奏"——它不管三七二十一，先执行一次循环体，然后再看条件是否满足，决定要不要继续。

这就像去游乐园坐过山车：你得先坐上去（先执行），然后工作人员检查你的身高（判断条件），如果不达标才让你下来。而while循环相反——先检查身高，通过了才让你坐。

### do-while循环的语法

```cpp
do {
    // 循环体：至少会执行一次
} while (条件);  // ⚠️ 注意：这里有个分号！
```

do-while循环的执行流程：
1. 首先执行循环体（不管条件如何，先执行！）
2. 执行完毕后，检查条件
3. 条件为真 → 回到第1步，再来一次
4. 条件为假 → 结束循环

如果把三种循环比作三种不同的家长作风：
- **while循环**像是严厉的家长："写完作业才能看电视！"（先检查条件）
- **do-while循环**像是宽松的家长："先看电视吧，看完再决定要不要写作业。"（先行动再判断）
- **for循环**像是计划周密的家长："看30分钟电视，每分钟检查一次。"（精确计数）

### 什么时候需要do-while？

do-while最大的特点是"至少执行一次"。这在以下场景中特别有用：

**场景1：菜单系统**
用户进入程序后，一定要先看到菜单，然后才能选择操作。

**场景2：输入验证**
先让用户输入，再检查是否合法。不合法就让用户重新输入。

**场景3：游戏循环**
游戏至少要让玩家玩一次，然后再问"要不要再玩一局？"

### do-while vs while 对比

```cpp
// 示例：假设初始条件就是假的
int x = 10;

// while循环 —— 一次都不执行
while (x < 5) {
    cout << "while: x = " << x << endl;  // 不会输出
}

// do-while循环 —— 至少执行一次
do {
    cout << "do-while: x = " << x << endl;  // 会输出一次！
} while (x < 5);
```

**运行结果：**
```
do-while: x = 10
```
while循环什么都没输出，因为条件一开始就是假的。但do-while循环还是输出了一次！

### 三种循环的对比总结

| 特性 | while | do-while | for |
|------|-------|----------|-----|
| 最少执行次数 | 0次 | 1次 | 0次 |
| 适用场景 | 不确定次数 | 至少执行一次 | 确定次数 |
| 语法复杂度 | 简单 | 注意分号 | 三要素在一行 |
| 典型用例 | 猜数字 | 菜单系统 | 遍历数组 |

## 💻 示例代码

### 示例1：掷骰子直到6

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));  // 初始化随机种子
    int dice;        // 骰子点数
    int count = 0;   // 投掷次数

    cout << "🎲 掷骰子游戏——直到掷出6点！" << endl;
    cout << "-------------------------------" << endl;

    do {
        dice = rand() % 6 + 1;  // 生成1-6的随机数
        count++;
        cout << "第" << count << "次：掷出了 " << dice << " 点" << endl;
    } while (dice != 6);

    cout << "🎉 恭喜！一共掷了 " << count << " 次才掷出6点！" << endl;
    return 0;
}
```

### 示例2：密码验证系统

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    const string PASSWORD = "c++123";  // 正确的密码
    string input;
    int attempts = 0;
    const int MAX_ATTEMPTS = 3;        // 最多尝试3次

    cout << "🔐 请输入密码（最多" << MAX_ATTEMPTS << "次机会）：" << endl;

    do {
        cout << "密码：";
        cin >> input;
        attempts++;

        if (input == PASSWORD) {
            cout << "✅ 密码正确！欢迎进入系统！" << endl;
            break;
        } else {
            cout << "❌ 密码错误！";
            if (attempts < MAX_ATTEMPTS) {
                cout << "还剩 " << MAX_ATTEMPTS - attempts << " 次机会。" << endl;
            }
        }
    } while (attempts < MAX_ATTEMPTS);

    if (input != PASSWORD) {
        cout << "🔒 尝试次数用完，账户已锁定！" << endl;
    }

    return 0;
}
```

## 🎮 趣味练习

### 练习1：猜数字（至少猜一次）

使用do-while循环实现猜数字游戏。程序生成一个1-10的随机数，用户来猜。由于do-while的特性，用户至少有一次猜测机会。

**参考答案：**
```cpp
srand(time(0));
int target = rand() % 10 + 1;
int guess;
do {
    cout << "猜一个1-10的数字：";
    cin >> guess;
    if (guess > target) cout << "大了！" << endl;
    else if (guess < target) cout << "小了！" << endl;
} while (guess != target);
cout << "猜对了！答案就是" << target << "！" << endl;
```

要求用户输入一个1到100之间的数字。如果输入不合法，要求重新输入。使用do-while确保至少执行一次验证。

## 📝 本课小结

- **do-while循环**的格式是`do{循环体}while(条件);`，注意末尾的**分号不能少**
- do-while**先执行循环体，再判断条件**，因此循环体**至少会执行一次**
- while和for可能**一次都不执行**（条件一开始就为假时），但do-while一定会执行**至少一次**
- do-while特别适合**菜单系统、输入验证、游戏重玩**等场景
- 三种循环各有优势：for适合已知次数、while适合条件判断、do-while适合至少执行一次
