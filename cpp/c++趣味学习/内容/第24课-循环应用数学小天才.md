## 📖 知识讲解

### 当循环遇上数学

学完了循环的各种技巧，现在让我们用这些"武器"来探索数学世界中的宝藏数字！今天我们要寻找三种特别的数字：素数、完数和水仙花数。它们就像藏在数字海洋中的珍珠，等待我们用循环去发现。

### 素数（质数）判断

**素数**是指大于1的自然数中，除了1和它本身以外，不能被其他自然数整除的数。换句话说，素数只有两个因子：1和它自己。

例如：2、3、5、7、11、13、17、19...这些数都是素数。

判断一个数n是不是素数，最直接的方法是用循环从2试到n-1，看有没有能整除n的数：

```cpp
bool isPrime = true;  // 假设n是素数
for (int i = 2; i < n; i++) {
    if (n % i == 0) {   // 能被整除，说明不是素数
        isPrime = false;
        break;          // 找到一个因子就够了
    }
}
```

**但是有更聪明的方法！** 如果一个数n不是素数，它一定可以写成 a × b = n。其中a和b中至少有一个 ≤ √n。所以，我们只需要检查到√n就够了：

```cpp
bool isPrime = true;
for (int i = 2; i <= sqrt(n); i++) {  // 只需检查到sqrt(n)
    if (n % i == 0) {
        isPrime = false;
        break;
    }
}
```

当n=100时，原本要检查98次，现在只需检查10次，效率提高了近10倍！

### 完数——完美的数字

**完数**（也叫完全数、完美数）是指一个数恰好等于它的所有真因子（除了自身以外的因子）之和。

例如：6 = 1 + 2 + 3（6的真因子是1、2、3，加起来正好是6）
又如：28 = 1 + 2 + 4 + 7 + 14

完数非常稀少！在10000以内只有4个完数：6、28、496、8128。

找出一个数的所有真因子并求和：

```cpp
int sum = 0;
for (int i = 1; i < n; i++) {
    if (n % i == 0) {   // i是n的因子
        sum += i;       // 累加到总和中
    }
}
if (sum == n) {
    cout << n << " 是完数！" << endl;
}
```

同样可以优化：因子是成对出现的，如果i是n的因子，那n/i也是。所以我们只需检查到√n：

```cpp
int sum = 1;  // 1总是因子
for (int i = 2; i <= sqrt(n); i++) {
    if (n % i == 0) {
        sum += i;
        if (i != n / i) {    // 避免重复计算（比如25的因子5）
            sum += n / i;
        }
    }
}
```

### 水仙花数——自恋的数字

**水仙花数**（也称为阿姆斯特朗数）是指一个n位数，它的每个位上的数字的n次幂之和等于它本身。

对于三位数的水仙花数：各位数字的立方和等于该数本身。

例如：153 = 1³ + 5³ + 3³ = 1 + 125 + 27 = 153 ✓
又如：370 = 3³ + 7³ + 0³ = 27 + 343 + 0 = 370 ✓

要判断一个三位数是不是水仙花数，需要：
1. 分离出个位、十位、百位
2. 计算各位的立方和
3. 判断是否等于原数

```cpp
int num = 153;
int ge = num % 10;           // 个位：3
int shi = num / 10 % 10;     // 十位：5
int bai = num / 100;         // 百位：1

if (ge*ge*ge + shi*shi*shi + bai*bai*bai == num) {
    cout << num << " 是水仙花数！" << endl;
}
```

所有的三位水仙花数有4个：**153、370、371、407**。

### 其他有趣的数字

除了上面三种，数学中还有很多有趣的数字可以用循环来探索：

| 数字类型 | 定义 | 例子 |
|---------|------|------|
| 回文数 | 正读反读都一样 | 121、12321 |
| 勾股数 | a² + b² = c² | 3² + 4² = 5² |
| 亲和数 | 两个数互为对方的真因子和 | 220和284 |
| 阶乘和数 | 各位阶乘之和等于自身 | 145 = 1!+4!+5! |

## 💻 示例代码

### 示例1：素数判断器

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cout << "🔍 素数判断器" << endl;
    cout << "请输入一个正整数：";
    cin >> n;

    if (n <= 1) {
        cout << n << " 不是素数（素数必须大于1）" << endl;
        return 0;
    }

    bool isPrime = true;
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) {
            isPrime = false;
            cout << "找到了因子 " << i << " × " << n/i << " = " << n << endl;
            break;
        }
    }

    if (isPrime) {
        cout << "✅ " << n << " 是素数！" << endl;
    } else {
        cout << "❌ " << n << " 不是素数。" << endl;
    }

    return 0;
}
```

### 示例2：寻找完数

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int limit;
    cout << "🏆 完数猎人" << endl;
    cout << "请输入搜索范围上限：";
    cin >> limit;

    cout << endl << "正在搜索 1 ~ " << limit << " 范围内的完数..." << endl;
    cout << "----------------------------------------" << endl;

    for (int n = 2; n <= limit; n++) {
        int sum = 1;  // 1总是因子

        // 找所有真因子并求和
        for (int i = 2; i <= sqrt(n); i++) {
            if (n % i == 0) {
                sum += i;
                if (i != n / i) {
                    sum += n / i;
                }
            }
        }

        if (sum == n && n != 1) {
            cout << "💎 发现完数：" << n << " = 1";
            for (int i = 2; i < n; i++) {
                if (n % i == 0) {
                    cout << " + " << i;
                }
            }
            cout << endl;
        }
    }

    cout << "----------------------------------------" << endl;
    cout << "搜索完成！" << endl;

    return 0;
}
```

## 🎮 趣味练习

### 练习1：找出100-200之间的素数

使用循环找出100到200之间的所有素数，每行输出5个。

**参考答案：**
```cpp
int count = 0;
for (int n = 100; n <= 200; n++) {
    bool isPrime = true;
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) { isPrime = false; break; }
    }
    if (isPrime) {
        cout << n << " ";
        count++;
        if (count % 5 == 0) cout << endl;
    }
}
cout << endl << "100-200之间共有 " << count << " 个素数。" << endl;
```

### 练习2：回文数判断

判断一个数是不是回文数（正读反读都一样，如121、12321）。

**提示：** 将一个数反转，然后和原数比较。

**参考答案：**
```cpp
int n, original, reversed = 0;
cin >> n;
original = n;
while (n > 0) {
    reversed = reversed * 10 + n % 10;
    n /= 10;
}
if (original == reversed)
    cout << original << " 是回文数！" << endl;
else
    cout << original << " 不是回文数。" << endl;
```

**提示：** 可以用嵌套循环和取位运算来分离任意位数的数字。分离n位数的每一位：
```cpp
int temp = num;
int sum = 0;
while (temp > 0) {
    int digit = temp % 10;
    sum += pow(digit, digits);  // digits是位数
    temp /= 10;
}
```

## 📝 本课小结

- **素数**只有1和自身两个因子，判断时可用`%`运算，优化到√n
- **完数**等于其真因子之和，如6=1+2+3，28=1+2+4+7+14
- **水仙花数**的各位数字的N次幂之和等于自身，如153=1³+5³+3³
- 循环是解决数学问题的**强大工具**，配合取位、取余等运算可以探索数字的奥秘
- 记住优化技巧：找因子时只需搜索到√n，效率大幅提升
- 数学中还有很多有趣的数字等着你去发现：回文数、亲和数、勾股数...
