## 二、知识体系回顾 📚

### 2.1 我们学过了什么？

同学们，从第一课"你好，编程世界！"到今天，我们已经一起走过了 47 节课的编程之旅。让我们来回顾一下这段精彩的旅程：

#### 第一阶段：认识C++和编程环境（第1-4课）

还记得你写的第一个程序吗？`cout << "Hello, World!" << endl;` 当屏幕上出现这行文字的时候，你就已经是一名"程序员"了！我们学会了：
- 什么是编程，C++ 是什么
- `main` 函数、头文件、语句与分号
- 注释怎么写，代码规范是什么
- 编译和运行一个程序的完整流程

#### 第二阶段：输入输出与变量（第5-8课）

程序不再"自言自语"，它开始和我们对话了！我们学会了：
- `cout` 输出信息、`cin` 读取用户的输入
- 变量是"贴了标签的盒子"，用来存储各种数据
- 不同的数据类型：`int`（整数）、`double`（小数）、`char`（字符）、`bool`（真假）

#### 第三阶段：运算符与表达式（第9-12课）

程序有了"计算能力"！我们学会了：
- 算术运算：加减乘除、取余数
- 比较运算：大于、小于、等于、不等于
- 逻辑运算：与（`&&`）、或（`||`）、非（`!`）

#### 第四阶段：条件判断（第13-16课）

程序会"做选择"了！我们学会了：
- `if` 单分支判断——"如果……就……"
- `if-else` 双分支判断——"如果……否则……"
- `else if` 多分支判断——面对多个选项的选择
- `switch-case` 多路开关——适合固定选项的判断

#### 第五、六阶段：循环结构（第17-24课）

程序会"重复做事"了！我们学会了：
- `while` 循环——"当条件成立时，一直做……"
- `for` 循环——"数着次数做事"，最适合已知循环次数的情况
- `do-while` 循环——"先做一次再说"
- `break` 和 `continue`——灵活控制循环的走向
- 嵌套循环——循环里面套循环，画出各种漂亮的图形

#### 第七、八阶段：数组（第25-32课）

程序有了"批量处理"的能力！我们学会了：
- 一维数组——"一排抽屉"，用下标来存取数据
- 二维数组——"棋盘格"，有行有列的数据
- 数组遍历——用循环一个一个访问数组元素
- 数组查找——线性查找、找最大值和最小值
- 数组的趣味应用——频率统计、矩阵转置

#### 第九阶段：字符与字符串（第33-36课）

程序能处理"文字"了！我们学会了：
- `char` 字符类型和 ASCII 码的秘密
- `string` 字符串类型的各种操作
- 字符串的长度、拼接、索引访问
- 大小写转换、凯撒加密等趣味应用

#### 第十阶段：函数（第37-40课）

程序变得"模块化"了！我们学会了：
- 什么是函数——"一段有名字的代码"，可以重复使用
- 参数和返回值——函数如何接收"输入"和产生"输出"
- 变量的作用域——局部变量和全局变量的区别
- 多函数协作——把一个大问题拆成小问题来解决

#### 第十一阶段：结构体与排序（第41-44课）

程序能够管理"复杂数据"了！我们学会了：
- **结构体（`struct`）** —— 把不同类型的数据打包在一起，像一张"信息卡片"
- **冒泡排序** —— 相邻比较、逐步交换，像气泡一样把大的数字"浮"到后面
- **选择排序** —— 每一轮找最小的元素，把它放到最前面
- **结构体排序** —— 对结构体数组进行排序，实现"成绩排名"等功能

#### 第十二阶段：综合趣味项目（第45-47课）

我们把学过的知识变成了好玩的游戏！：
- 猜数字游戏——用随机数生成目标，用二分查找的思想来猜
- 石头剪刀布——人机对战，多轮计分
- 知识问答王——结构体数组 + 计分统计

### 2.2 知识之间的联系

编程的各个知识点不是孤立的，它们像积木一样可以组合在一起：

```
                    程序 = 数据 + 逻辑
                          |
          +---------------+---------------+
          |                               |
      【数据】                          【逻辑】
          |                               |
   +------+------+              +---------+---------+
   |      |      |              |         |         |
 变量   数组   结构体         条件判断   循环     函数
   |      |      |              |         |         |
  类型   遍历   排序           if       for     参数/返回
   |      |      |           else     while    作用域
  int   []访问  冒泡        switch   do-while   模块化
 double        选择                        嵌套循环
 string        比较
```

**核心思想：**
- **数据** 是程序的"原材料"——简单数据用变量，多个同类数据用数组，不同类数据打包用结构体
- **逻辑** 是程序的"加工方法"——做选择用条件判断，重复做事用循环，复杂逻辑拆成函数
- **排序** 是数据处理的"高级操作"，它结合了数组、循环、条件判断和交换操作

### 2.3 编程思维总结

经过 48 节课的学习，你不但学会了 C++ 的语法，更重要的是建立了"编程思维"：

1. **分解思维** —— 把一个大问题拆解成若干个小问题，逐个击破（函数就是这种思维的体现）
2. **抽象思维** —— 从具体事物中提取出关键特征，用数据和逻辑来描述它（结构体就是这种思维的体现）
3. **算法思维** —— 设计出一套清晰的操作步骤，一步一步解决问题（排序算法就是这种思维的体现）
4. **调试思维** —— 发生错误不要慌，仔细看错误提示，一步步排查（每次编译报错都是锻炼的机会）
5. **迭代思维** —— 程序不是一次写好的，不断改版、不断优化、越来越完善

## 三、如何选择和组合工具解决问题 🛠️

当你面对一个编程问题时，可以按照以下思路来思考：

### 步骤一：分析问题，确定"输入"和"输出"

问自己三个问题：
- 这个程序需要用户输入什么？（输入）
- 程序需要对这些数据做什么处理？（处理）
- 程序最后要显示什么结果？（输出）

### 步骤二：选择合适的数据结构

| 数据类型 | 什么时候用？ | 例子 |
|:---------|:-------------|:-----|
| `int`、`double` | 存储单个数值 | 分数、价格、年龄 |
| `char` | 存储单个字符 | 等级（A/B/C） |
| `string` | 存储文字 | 姓名、书名 |
| `bool` | 存储真/假 | 是否及格、是否找到 |
| 一维数组 | 存储多个同类型的数据 | 全班同学的分数 |
| 二维数组 | 存储有行有列的数据 | 座位表、棋盘 |
| 结构体 | 把多个不同类型的相关数据打包 | 学生信息（姓名、年龄、分数） |
| 结构体数组 | 存储多个"打包好的信息" | 全班同学的信息列表 |

### 步骤三：选择合适的算法和逻辑

| 需求 | 用什么？ | 
|:-----|:---------|
| 做判断 | `if`、`if-else`、`else if` |
| 固定选项的选择 | `switch-case` |
| 已知次数的重复 | `for` 循环 |
| 未知次数、满足条件就停 | `while` 循环 |
| 至少做一次再判断 | `do-while` |
| 从数组里找东西 | 线性查找（`for` + `if`） |
| 把数组从小到大排列 | 冒泡排序或选择排序 |
| 把结构体数组排序 | 在排序算法中比较结构体的某个成员（如 `.score`） |
| 代码需要复用 | 写成函数 |
| 需要随机性 | `rand()` + `srand(time(0))` |
| 菜单交互 | `while(true)` + `switch-case` |

## 四、综合复习示例：学生成绩管理系统 💻

下面是一个完整的综合示例，它整合了**结构体、冒泡排序、选择排序、菜单交互、循环、条件判断、数组**等多个知识点：

```cpp
#include <iostream>
#include <string>
#include <iomanip>
using namespace std;

// 定义学生结构体
struct Student {
    string name;      // 姓名
    int age;          // 年龄
    double score;     // 成绩（0~100分）
};

// 打印分隔线
void printLine(string title) {
    cout << "\n========== " << title << " ==========" << endl;
}

// 显示所有学生信息
void showAll(Student arr[], int n) {
    cout << "\n学号\t姓名\t年龄\t成绩\t等级" << endl;
    cout << "----\t----\t----\t----\t----" << endl;
    for (int i = 0; i < n; i++) {
        char grade;  // 根据成绩给出等级
        if (arr[i].score >= 90) grade = 'A';
        else if (arr[i].score >= 80) grade = 'B';
        else if (arr[i].score >= 70) grade = 'C';
        else if (arr[i].score >= 60) grade = 'D';
        else grade = 'E';
        
        cout << (i + 1) << "\t" << arr[i].name << "\t" 
             << arr[i].age << "\t" << fixed << setprecision(1)
             << arr[i].score << "\t" << grade << endl;
    }
}

// 冒泡排序——按成绩从高到低
void bubbleSortByScore(Student arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j].score < arr[j + 1].score) {
                // 交换整个结构体
                Student temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

// 选择排序——按年龄从小到大
void selectionSortByAge(Student arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j].age < arr[minIdx].age) {
                minIdx = j;
            }
        }
        if (minIdx != i) {
            Student temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }
}

// 计算并显示统计信息
void showStats(Student arr[], int n) {
    double sum = 0;
    double maxScore = arr[0].score;
    double minScore = arr[0].score;
    int maxIdx = 0, minIdx = 0;
    
    for (int i = 0; i < n; i++) {
        sum += arr[i].score;
        if (arr[i].score > maxScore) {
            maxScore = arr[i].score;
            maxIdx = i;
        }
        if (arr[i].score < minScore) {
            minScore = arr[i].score;
            minIdx = i;
        }
    }
    
    double avg = sum / n;
    int aboveAvg = 0;  // 高于平均分的人数
    for (int i = 0; i < n; i++) {
        if (arr[i].score > avg) aboveAvg++;
    }
    
    cout << fixed << setprecision(1);
    cout << "平均分：" << avg << " 分" << endl;
    cout << "最高分：" << arr[maxIdx].name << " " << maxScore << " 分" << endl;
    cout << "最低分：" << arr[minIdx].name << " " << minScore << " 分" << endl;
    cout << "高于平均分的人数：" << aboveAvg << " / " << n << endl;
}

int main() {
    const int N = 5;
    Student students[N] = {
        {"小明", 12, 88.5},
        {"小红", 11, 96.0},
        {"小刚", 12, 75.5},
        {"小丽", 13, 91.0},
        {"小强", 11, 62.0}
    };
    
    int choice;
    while (true) {
        cout << "\n╔══════════════════════════════════╗" << endl;
        cout << "║    📚 学生成绩管理系统 v1.0     ║" << endl;
        cout << "╠══════════════════════════════════╣" << endl;
        cout << "║  1. 查看所有学生信息            ║" << endl;
        cout << "║  2. 按成绩排名（冒泡排序-降序） ║" << endl;
        cout << "║  3. 按年龄排序（选择排序-升序） ║" << endl;
        cout << "║  4. 查看统计信息                ║" << endl;
        cout << "║  5. 退出系统                    ║" << endl;
        cout << "╚══════════════════════════════════╝" << endl;
        cout << "请输入你的选择(1-5)：";
        cin >> choice;
        
        if (choice == 1) {
            showAll(students, N);
        } else if (choice == 2) {
            bubbleSortByScore(students, N);
            showAll(students, N);
        } else if (choice == 3) {
            selectionSortByAge(students, N);
            showAll(students, N);
        } else if (choice == 4) {
            showStats(students, N);
        } else if (choice == 5) {
            cout << "感谢使用，再见！👋" << endl;
            break;
        } else {
            cout << "输入错误，请重新选择！" << endl;
        }
    }
    
    return 0;
}
```

### 代码分析

这个程序展示了如何把多个知识点组合在一起：

| 知识点 | 在程序中的体现 |
|:-------|:--------------|
| **结构体** | `Student` 结构体包含姓名、年龄、成绩三个成员 |
| **结构体数组** | `Student students[5]` 用数组管理5个学生的信息 |
| **冒泡排序** | `bubbleSortByScore` 函数，按成绩降序排列，带 `swapped` 优化 |
| **选择排序** | `selectionSortByAge` 函数，按年龄升序排列 |
| **函数** | 每个功能独立封装为函数：`showAll`、`bubbleSortByScore`、`selectionSortByAge`、`showStats` |
| **菜单交互** | `while(true)` 循环 + `if-else` 实现菜单选择 |
| **条件判断** | 成绩等级评定（if-else if）、菜单选项判断 |
| **循环** | 遍历数组用 `for`、菜单用 `while` |
| **格式化输出** | `setprecision`、`fixed` 控制小数位数 |

```cpp
#include <iostream>

// ============================================

void guessNumber() {
    srand(time(0));
    int target = rand() % 100 + 1;  // 生成1~100的随机数
    int guess, count = 0;
    
    cout << "\n--- 🎯 猜数字游戏 ---" << endl;
    cout << "我已经想好了一个1~100之间的数字，来猜猜看！" << endl;
    
    while (true) {
        cout << "请输入你猜的数字：";
        cin >> guess;
        count++;
        
        if (guess > target) {
            cout << "太大了！往小了猜～" << endl;
        } else if (guess < target) {
            cout << "太小了！往大了猜～" << endl;
        } else {
            cout << "🎉 恭喜你猜对了！你一共猜了 " << count << " 次。" << endl;
            break;
        }
    }
}

// ============================================
// 模块2：成绩排序器
// ============================================
struct ScoreRecord {
    string name;
    double score;
};

void scoreSorter() {
    const int N = 5;
    ScoreRecord records[N];
    
    cout << "\n--- 📊 成绩排序器 ---" << endl;
    cout << "请输入 " << N << " 位同学的姓名和成绩：" << endl;
    for (int i = 0; i < N; i++) {
        cout << "第" << (i + 1) << "位 姓名：";
        cin >> records[i].name;
        cout << "      成绩：";
        cin >> records[i].score;
    }
    
    // 冒泡排序（成绩从高到低）
    for (int i = 0; i < N - 1; i++) {
        for (int j = 0; j < N - 1 - i; j++) {
            if (records[j].score < records[j + 1].score) {
                ScoreRecord temp = records[j];
                records[j] = records[j + 1];
                records[j + 1] = temp;
            }
        }
    }
    
    cout << "\n===== 成绩排行榜 =====" << endl;
    for (int i = 0; i < N; i++) {
        cout << "第" << (i + 1) << "名：" << records[i].name 
             << " — " << records[i].score << "分" << endl;
    }
}

// ============================================
// 模块3：简易计算器

void simpleCalculator() {
    double a, b;
    char op;
    
    cout << "\n--- 🧮 简易计算器 ---" << endl;
    cout << "请输入算式（格式：数字 运算符 数字，如 3 + 5）：";
    cin >> a >> op >> b;
    
    switch (op) {
        case '+': cout << a << " + " << b << " = " << (a + b) << endl; break;
        case '-': cout << a << " - " << b << " = " << (a - b) << endl; break;
        case '*': cout << a << " * " << b << " = " << (a * b) << endl; break;
        case '/': 
            if (b != 0) {
                cout << a << " / " << b << " = " << (a / b) << endl;
            } else {
                cout << "错误：除数不能为0！" << endl;
            }
            break;
        default: cout << "不支持的运算符！支持 +、-、*、/" << endl;
    }
}

// ============================================
// 模块4：找最大值/最小值
// ============================================
void findMaxMin() {
    int n;
    cout << "\n--- 🔍 找最大值/最小值 ---" << endl;
    cout << "请输入数字个数：";
    cin >> n;
    
    int arr[100];  // 假设最多100个数字
    
    cout << "请输入 " << n << " 个整数：" << endl;
    for (int i = 0; i < n; i++) {
        cout << "第" << (i + 1) << "个：";
        cin >> arr[i];
    }
    
    int maxVal = arr[0], minVal = arr[0];
    int maxIdx = 0, minIdx = 0;
    
    for (int i = 1; i < n; i++) {
        if (arr[i] > maxVal) { maxVal = arr[i]; maxIdx = i; }
        if (arr[i] < minVal) { minVal = arr[i]; minIdx = i; }
    }
    
    // 计算总和和平均值
    double sum = 0;
    for (int i = 0; i < n; i++) sum += arr[i];
    
    cout << "\n====== 结果 ======" << endl;
    cout << "最大值：第" << (maxIdx + 1) << "个数 = " << maxVal << endl;
    cout << "最小值：第" << (minIdx + 1) << "个数 = " << minVal << endl;
    cout << "总和：" << sum << endl;
    cout << "平均值：" << fixed << setprecision(2) << (sum / n) << endl;
}

        switch (choice) {
            case 1: guessNumber(); break;
            case 2: scoreSorter(); break;
            case 3: simpleCalculator(); break;
            case 4: findMaxMin(); break;
            case 5: 
                cout << "\n👋 感谢使用我的编程工具箱，再见！" << endl;
                cout << "希望你继续在编程的世界里探索！" << endl;
                return 0;
            default:
                cout << "输入错误，请输入1~5之间的数字！" << endl;
        }
    }
    
    return 0;
}
```

### 框架说明

这个"多功能工具箱"展示了模块化编程的思想：
- 每个功能是一个独立的**函数模块**
- 主程序用 **`while` + `switch`** 实现菜单交互
- 你可以**随时添加新的模块**——只要新增一个函数，然后在菜单里加一个选项即可

### 练习3：编程题

**题目：** 设计一个"班级通讯录"程序，要求：
1. 使用结构体存储学生的姓名、年龄、电话（字符串）和QQ号（字符串）
2. 至少存储5个学生
3. 提供菜单让用户选择：查看全部、按姓名查找、按年龄排序

**参考答案框架：**
```cpp
#include <iostream>
#include <string>
using namespace std;

struct Contact {
    string name;
    int age;
    string phone;
    string qq;
};

// 按姓名查找
void searchByName(Contact arr[], int n, string target) {
    bool found = false;
    for (int i = 0; i < n; i++) {
        if (arr[i].name == target) {
            cout << "找到了！" << endl;
            cout << "姓名：" << arr[i].name << endl;
            cout << "年龄：" << arr[i].age << endl;
            cout << "电话：" << arr[i].phone << endl;
            cout << "QQ：" << arr[i].qq << endl;
            found = true;
            break;
        }
    }
    if (!found) {
        cout << "未找到该同学！" << endl;
    }
}

// 按年龄排序（冒泡排序，升序）
void sortByAge(Contact arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j].age > arr[j + 1].age) {
                Contact temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```
