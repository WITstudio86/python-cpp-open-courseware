# 第10课：数字变形记——类型转换

## 🎯 学习目标
- 理解什么是隐式类型转换，知道不同类型数据如何自动转换
- 掌握强制转换和显式转换的方法，能把小数变成整数
- 认识数据溢出现象，学会判断数字是否超出了类型的范围

## 📖 知识讲解

### 数字也有"衣服"吗？

你有没有去过化装舞会？每个人都穿上不同的服装，扮演不同的角色。在C++的世界里，数字也需要"穿衣服"才能工作！这些"衣服"就是我们之前学过的**数据类型**。

打个比方：`int` 是一件"整数外套"，穿上它，数字就是整整齐齐的整数，没有小数点后面的尾巴。`double` 是一件"小数披风"，穿上它，数字就能保留小数部分，变得精确又细致。

而所谓的**类型转换**，就是让数字换一件衣服穿！这种"换装"在编程中非常常见，有时候是自动完成的，有时候则需要我们手动"帮忙"。今天，就让我们一起走进C++的"数字变装秀"表演现场！

### 第一幕：自动换装——隐式类型转换

想象一下这个场景：你有一个整数3，穿着 `int` 的衣服；又有一个小数2.5，穿着 `double` 的衣服。当你把它们放在一起做运算时，比如 `3 + 2.5`，会发生什么？

C++非常聪明，它会自动帮整数3"换上"小数的衣服，让大家都穿着同一款衣服来参加舞会。于是 `3` 变成了 `3.0`，再进行计算：`3.0 + 2.5 = 5.5`。整个过程是自动完成的，不需要你写任何额外的代码，这就是**隐式类型转换**（也叫自动类型转换）。

隐式转换有一个重要的安全规则：
- **小类型 → 大类型：安全！** 就像把小杯子的水倒进大杯子里，完全不会洒出来。比如 `int` 转 `double`、`float` 转 `double`。
- **大类型 → 小类型：危险！** 就像把大桶的水倒进小杯子里，水会溢出来，数据会丢失。比如 `double` 转 `int`，小数部分会被无情地扔掉。

为什么小类型转大类型要"安全"呢？我们来看看常见的类型从小到大是怎么排列的：

`char` < `short` < `int` < `long` < `long long` < `float` < `double` < `long double`

左边的类型就像小号的衣服，右边的是大号的衣服。小穿大没问题，大穿小就要小心了！

### 第二幕：手动换装——强制类型转换

有时候，你希望把一个 `double` 类型的数字（比如3.14）变成一个 `int` 类型的数字。但C++不会自动帮你做这个转换，因为这样做会丢掉小数部分，属于"危险操作"。这时候，就需要你亲自动手了！

强制转换有两种写法：

**传统写法（C语言风格）：**
```cpp
(int)3.14   // 结果是 3，小数部分被切掉了
```

**现代写法（C++风格，推荐）：**
```cpp
static_cast<int>(3.14)   // 结果也是 3，更规范、更安全
```

注意哦！强制转换不是四舍五入，而是直接把小数点后面的尾巴"砍掉"。无论小数是 .1 还是 .9，统统去掉，只剩下整数部分。就像一个严格的理发师，不管头发多长多短，一律剪成平头！

### 第三幕：小心！整数除法的"陷阱"

这是一个让很多初学者栽跟头的地方！请看下面的代码：

```cpp
int a = 5, b = 2;
cout << a / b << endl;   // 输出：2，不是 2.5！
```

什么？！5除以2不是等于2.5吗？为什么输出了2？因为当 `int` 和 `int` 相除时，C++会执行**整数除法**——结果的小数部分会被自动丢弃，只保留整数部分。这就像两个人分5块糖，每人只能分到2块，剩下的1块没法再分了。

那怎么才能得到正确的2.5呢？有以下几种办法：

1. 把其中一个数写成小数：`5.0 / 2` 或者 `5 / 2.0`，结果就是 `2.5`。
2. 使用强制转换：`(double)5 / 2` 或者 `(double)a / b`，结果也是 `2.5`。
3. 变量本身就是 `double` 类型：`double a = 5, b = 2;`，结果自然是 `2.5`。

**重要规则：只要除法运算中有一个数是小数（double/float），整个运算就会按小数方式来计算。** 记住这句话，以后做除法就不会出错了！

### 第四幕：数字"水杯"——数据溢出

每个数据类型都像是一个固定大小的水杯。`char` 类型的"水杯"特别小，只能装下从 -128 到 127 之间的整数（共256个数字）。

假设你现在有一个 `char` 类型的变量，里面装着 `127`——这是水杯能装的最大值。这时候，如果你试图再加1：

```cpp
char c = 127;
c = c + 1;   // 或者写成 c++;
cout << (int)c << endl;   // 输出：-128，不是 128！
```

结果竟然变成了 -128！这就像水杯装满了水，你再倒水进去，水就会"溢出"流到别的地方去。在计算机内部，数字像一个圆环一样排列着，127 的下一个位置刚好就是 -128。这种现象叫做**溢出**（Overflow）。

不只是 `char` 会溢出，任何类型的变量都有可能溢出，只是它们的"水杯"大小不同：
- `char`：-128 ~ 127（杯子最小，最容易溢出）
- `int`：约 -21亿 ~ 21亿（杯子大多了，但也不是无限的）
- `long long`：大约 -9百京 ~ 9百京（超级大杯子，几乎装不满）

所以，当你写程序时，如果发现得到了一个奇怪的负数或一个异常小的数，很可能就是溢出了哦！

### 换装规则速记表

| 场景 | 转换方式 | 是否安全 | 例子 | 结果 |
|------|----------|----------|------|------|
| int + double | 隐式（自动） | ✅ 安全 | 3 + 2.5 | 5.5 |
| int 赋值给 double | 隐式（自动） | ✅ 安全 | double d = 5 | d = 5.0 |
| double 赋值给 int | 隐式（自动） | ❌ 数据丢失 | int i = 3.14 | i = 3 |
| 用 (int) 强制转换 | 强制（手动） | ⚠️ 人工确认 | (int)5.9 | 5 |
| char 超出范围 | 溢出 | ❌ 错误结果 | char c=128 | c = -128 |

## 💻 示例代码

### 示例1：隐式类型转换演示
```cpp
#include <iostream>
using namespace std;

int main() {
    // 隐式转换演示：int 和 double 做运算
    int a = 5;
    double b = 3.2;
    
    // a 自动"换装"成 double，变成 5.0，然后相加
    double result = a + b;   // 5.0 + 3.2 = 8.2
    cout << a << " + " << b << " = " << result << endl;
    
    // 输出 result 的类型大小，证明它是 double
    cout << "result 占用的字节数：" << sizeof(result) << "（double = 8字节）" << endl;
    
    // 反过来：double 赋值给 int，小数部分丢失
    int c = b;   // 隐式转换：int c = 3.2 → c = 3
    cout << "把 double " << b << " 赋值给 int 变量，结果是：" << c << endl;
    
    return 0;
}
```
**运行结果：**
```
5 + 3.2 = 8.2
result 占用的字节数：8（double = 8字节）
把 double 3.2 赋值给 int 变量，结果是：3
```

### 示例2：强制转换——小数变整数
```cpp
#include <iostream>
using namespace std;

int main() {
    double pi = 3.1415926;
    
    // 方法1：C语言风格——(类型名)变量
    int a = (int)pi;             // 结果是 3，小数直接砍掉
    cout << "(int)" << pi << " = " << a << endl;
    
    // 方法2：C++风格——static_cast<类型名>(变量)（推荐）
    int b = static_cast<int>(pi);  // 结果也是 3
    cout << "static_cast<int>(" << pi << ") = " << b << endl;
    
    // 注意：强制转换不是四舍五入！
    double x = 5.9;
    int y = (int)x;              // y = 5，不是 6！
    cout << "(int)" << x << " = " << y << "（注意：不是四舍五入！）" << endl;
    
    // 整数除法的正确和错误写法对比
    cout << "\n=== 整数除法对比 ===" << endl;
    cout << "5 / 2     = " << 5 / 2 << "（整数除法，错误！）" << endl;
    cout << "5.0 / 2   = " << 5.0 / 2 << "（正确！）" << endl;
    cout << "(double)5 / 2 = " << (double)5 / 2 << "（正确！）" << endl;
    
    return 0;
}
```
**运行结果：**
```
(int)3.14159 = 3
static_cast<int>(3.14159) = 3
(int)5.9 = 5（注意：不是四舍五入！）

=== 整数除法对比 ===
5 / 2     = 2（整数除法，错误！）
5.0 / 2   = 2.5（正确！）
(double)5 / 2 = 2.5（正确！）
```

### 示例3：数据溢出演示——char的"水杯"满了
```cpp
#include <iostream>
using namespace std;

int main() {
    // char 类型的范围：-128 ~ 127
    // 就像一个只能装下 256 个数字的小杯子
    
    char c = 127;   // char 能存的最大值
    cout << "c 的初始值：" << (int)c << endl;  // 强制转成 int 才能看到数字
    
    c = c + 1;      // 试图装第 128 个数字，水杯满了！溢出！
    cout << "c + 1 之后的值：" << (int)c << "（溢出了！变成了 -128）" << endl;
    
    // 再来演示 int 类型的溢出（范围更大，但也不是无限的）
    cout << "\n=== int 类型的范围 ===" << endl;
    int max_int = 2147483647;  // int 能装的最大值
    cout << "int 最大值：" << max_int << endl;
    cout << "int 最大值 + 1：" << max_int + 1 << "（溢出了！变成了负数）" << endl;
    
    // 安全提醒
    cout << "\n【温馨提示】" << endl;
    cout << "char 的杯子很小（-128 ~ 127），int 的杯子大得多（约 ±21亿）。" << endl;
    cout << "计算之前，先想想数字会不会溢出来哦！" << endl;
    
    return 0;
}
```
**运行结果：**
```
c 的初始值：127
c + 1 之后的值：-128（溢出了！变成了 -128）

=== int 类型的范围 ===
int 最大值：2147483647
int 最大值 + 1：-2147483648（溢出了！变成了负数）

【温馨提示】
char 的杯子很小（-128 ~ 127），int 的杯子大得多（约 ±21亿）。
计算之前，先想想数字会不会溢出来哦！
```

### 练习1：火眼金睛——预测结果
不看电脑，猜猜下面代码的输出是什么？

```cpp
int a = 5;
double b = 2.7;
int c = (int)(a + b);
cout << c << endl;
```

**参考答案：** 结果是 `7`。首先 `a + b = 5 + 2.7 = 7.7`，然后 `(int)7.7` 直接把小数部分砍掉，得到 `7`。记住，不是四舍五入，是直接截断！

### 练习2：温度转换器（华氏度转摄氏度）
编写一个程序，把华氏度（F）转换成摄氏度（C）。转换公式是：

**C = (F - 32) × 5 ÷ 9**

请特别注意：5 ÷ 9 如果用整数除法会得到 0！想一想应该怎么写才正确？
- 提示1：可以用 `5.0 / 9`
- 提示2：可以用 `(double)5 / 9`
- 提示3：可以把变量都设成 `double` 类型

**参考答案：**
```cpp
#include <iostream>
using namespace std;

int main() {
    double fahrenheit = 98.6;  // 华氏度（人体正常体温）
    
    // 方法1：使用 5.0/9 避免整数除法
    double celsius1 = (fahrenheit - 32) * 5.0 / 9;
    
    // 方法2：先乘5再除以9.0（顺序很重要！）
    double celsius2 = (fahrenheit - 32) * 5 / 9.0;
    
    cout << fahrenheit << " 华氏度 = " << celsius1 << " 摄氏度" << endl;
    
    return 0;
}
```

### 练习3：猜猜 char 溢出
如果把数字 127 加 1 存到 `char` 类型的变量里，结果是多少？为什么会这样？

**参考答案：** 结果是 `-128`。因为 `char` 类型只能存储 -128 到 127 之间的整数。当 127 再加 1 时，超出了 `char` 的存储范围，就像水杯里的水溢出来一样，数字"绕"了一圈，从最大值 127 跳到了最小值 -128。计算机内部是用补码来表示数字的，01111111（127）加 1 变成 10000000（-128）。

## 🏆 挑战任务

### 挑战：万能温度转换器

编写一个程序，输入摄氏度（C）的数值，输出对应的华氏度（F）和开尔文温度（K），结果保留 2 位小数。

公式：
- 华氏度：**F = C × 9 ÷ 5 + 32**
- 开尔文：**K = C + 273.15**

提示：
- 输入使用 `cin` 读取一个 `double` 类型的变量
- 使用 `printf("%.2f", 变量)` 来控制输出 2 位小数
- 注意 9 ÷ 5 的写法，要避免整数除法（可以用 `9.0/5.0`）
- 想想看：C 应该用什么类型？F 和 K 又应该用什么类型？

**参考示例：**
```cpp
#include <iostream>
#include <cstdio>    // 提供 printf 函数
using namespace std;

int main() {
    double celsius;   // 摄氏度（用 double，因为可能有小数）
    
    cout << "请输入摄氏温度：";
    cin >> celsius;
    
    // 计算华氏度和开尔文
    double fahrenheit = celsius * 9.0 / 5.0 + 32;
    double kelvin = celsius + 273.15;
    
    // 输出结果，保留 2 位小数
    cout << "===== 温度转换结果 =====" << endl;
    printf("摄氏度：   %.2f °C\n", celsius);
    printf("华氏度：   %.2f °F\n", fahrenheit);
    printf("开尔文：   %.2f K\n", kelvin);
    
    // 也可以用 cout 的方式输出 2 位小数
    cout << endl;
    cout << "（以下是 cout 方式的输出）" << endl;
    cout << fixed;             // 启用固定小数位模式
    cout.precision(2);         // 设置保留 2 位小数
    cout << "摄氏度：   " << celsius << " °C" << endl;
    cout << "华氏度：   " << fahrenheit << " °F" << endl;
    cout << "开尔文：   " << kelvin << " K" << endl;
    
    return 0;
}
```
**示例运行：**
```
请输入摄氏温度：25
===== 温度转换结果 =====
摄氏度：   25.00 °C
华氏度：   77.00 °F
开尔文：   298.15 K
```

## 📝 本课小结

| 知识点 | 内容 |
|--------|------|
| 隐式类型转换 | 小类型转大类型自动完成（安全），如 int→double |
| 强制类型转换 | 用 `(int)x` 或 `static_cast<int>(x)` 手动转换，小数直接截断 |
| 整数除法的坑 | 5/2=2（整数除法），5.0/2=2.5（浮点除法） |
| 数据溢出 | 超出类型范围时数值会"绕圈"，如 char: 127+1=-128 |
| char 范围 | -128 ~ 127，只有 256 个数字，特别容易溢出 |
| 安全除法 | 只要除号两边有一个是小数，结果就是小数 |

**记住这句口诀：**
> 数字换装分两种，隐式自动显式手；整数除法要小心，小数登场才不愁；水杯有量别装满，溢出之后数字走！
