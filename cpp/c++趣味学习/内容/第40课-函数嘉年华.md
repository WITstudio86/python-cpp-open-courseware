### 🧩 一、模块化编程：把大象放进冰箱

有一则经典的笑话："把大象放进冰箱需要几步？"

答案只有三步：
1. 打开冰箱门
2. 把大象放进去
3. 关上冰箱门

这个笑话其实揭示了**模块化编程（Modular Programming）**的核心思想：**把一个复杂的大任务，拆解成若干个简单的小步骤，每个小步骤用独立的函数来实现**。

在编程中，我们面对一个大问题时，不要被它的复杂性吓倒。正确的做法是：

```
大问题：制作一个多功能工具箱程序
    ↓ 拆解
  小问题1：显示菜单界面       → 写成 showMenu() 函数
  小问题2：实现计算器功能     → 写成 calculator() 函数
  小问题3：实现温度转换功能   → 写成 tempConverter() 函数
  小问题4：实现字符串反转功能 → 写成 stringReverser() 函数
  小问题5：实现ASCII艺术功能  → 写成 asciiArt() 函数
    ↓ 组装
  主函数 main() 像一个"调度员"，根据用户的选择来调用对应的小函数
```

这种方式就像玩**乐高积木**一样——每一块积木（函数）都是独立的小零件，但你把这些小零件组合起来，就能搭出宏伟的城堡（完整的应用程序）！

#### 模块化编程的三大好处

| 好处 | 解释 | 生活类比 |
|------|------|---------|
| **可读性强** | `main()` 函数简短清晰，一看就知道程序做了什么事 | 就像看目录就知道一本书讲了什么 |
| **易于调试** | 出问题时，只需检查对应的那个小函数 | 电风扇不转了，只需检查电机，不用拆整台 |
| **便于扩展** | 想加新功能时，只需添加一个新函数并注册到菜单里 | 想在手机上装新App，下载安装即可 |

### 🤝 二、多函数协作：团队的力量

一个函数就像一个人，能力有限。但是多个函数团结协作，就能完成不可思议的事情！

#### 协作模式一：接力模式（串行调用）

函数 A 调用函数 B，函数 B 调用函数 C……像接力赛一样，一个传给下一个：

```
main() → 显示菜单 → 用户选择 → 调用对应功能函数 → 功能函数内部再调用辅助函数 → 返回结果
```

举例：计算器函数内部调用了加法、减法、乘法、除法等子函数。

#### 协作模式二：聚合模式（数据汇总）

一个"总控函数"调用多个"子函数"，收集它们的结果进行汇总：

```cpp
void showReport() {
    // 聚合模式：一个函数调用多个子函数，汇总结果
    double avg = calcAverage(scores);   // 调用计算平均分的函数
    int maxVal = findMax(scores);       // 调用找最大值的函数
    int minVal = findMin(scores);       // 调用找最小值的函数

    // 汇总展示
    cout << "平均分：" << avg << endl;
    cout << "最高分：" << maxVal << endl;
    cout << "最低分：" << minVal << endl;
}
```

#### 协作模式三：嵌套调用（函数调用函数）

函数 A 调用函数 B，而函数 B 内部又调用了函数 C：

```cpp
void showAsciiArt() {          // 最外层：ASCII艺术
    printBorder();             // 调用：打印边框
    printPattern();            // 调用：打印图案（内部又会调用其他函数）
    printBorder();             // 再次调用：打印边框
}

void printPattern() {          // 中间层：打印图案
    printLine("*", 10);        // 调用：打印一行星号（10个）
    printLine("#", 10);        // 调用：打印一行井号（10个）
}

void printLine(string ch, int count) {  // 最底层：打印一行
    for (int i = 0; i < count; i++) {
        cout << ch;
    }
    cout << endl;
}
```

这种嵌套结构就像一个公司的管理层次——CEO（main函数）下达指令给经理（高级函数），经理再安排具体员工（底层函数）执行任务。

### 🎛️ 三、菜单驱动设计：打造交互式工具箱

最让人兴奋的部分来了！我们要学习如何设计一个**菜单驱动的交互式程序**。这种程序的运行流程是：

```
1. 显示一个功能菜单（列出所有可用的功能）
2. 让用户输入一个数字来选择功能
3. 根据用户的选择，调用对应的函数
4. 功能执行完毕后，返回菜单（除非用户选择退出）
5. 循环往复，直到用户选择退出
```

核心框架如下：

```cpp
int main() {
    int choice;
    do {
        showMenu();             // 1. 显示菜单
        cin >> choice;          // 2. 获取用户选择

        switch (choice) {       // 3. 根据选择调度函数
            case 1: calculator();      break;
            case 2: tempConverter();   break;
            case 3: stringReverser();  break;
            case 4: asciiPrinter();    break;
            case 0: cout << "再见！" << endl; break;
            default: cout << "无效选择！" << endl;
        }
    } while (choice != 0);      // 4. 不是"退出"就继续循环
    return 0;
}
```

关键要点：
- 使用 `do-while` 循环保证菜单至少显示一次；
- 使用 `switch` 语句根据用户选择分发到不同的函数；
- 选项 `0` 通常被设为"退出"选项；
- `default` 分支用来处理无效输入。

### 👷 四、构建完整应用程序的工程思维

当你着手开发一个完整的小应用程序时，可以遵循以下"四步工程法"：

**第一步：需求分析（想清楚要做什么）**
列出你的程序需要实现的所有功能。比如我们的"函数嘉年华工具箱"需要：计算器、温度转换、字符串反转、ASCII艺术打印。

**第二步：模块划分（拆分成小函数）**
每个功能对应一个函数。此外，还需要一些通用辅助函数（如清屏、显示分隔线、暂停等待等）。

**第三步：逐个实现（一个一个地写）**
从最简单的函数开始写，写完一个测试一个。不要试图一口气写完所有函数再测试——那样出了问题很难找！

**第四步：组装整合（在 main 中串联）**
用菜单系统把所有函数串起来，形成一个完整的交互式程序。

> 💡 **编程箴言**："分而治之"（Divide and Conquer）—— 把大问题分解成小问题，逐个击破！这是所有优秀程序员都在用的核心策略。

### 示例一：独立工具函数演示

下面的程序展示了多个功能独立的小函数，每个函数负责一个特定的任务。这是模块化编程的基础形态。

```cpp
#include <iostream>
#include <string>
#include <cmath>
using namespace std;

// ========== 工具函数集合 ==========

// 工具1：计算矩形面积
double rectArea(double width, double height) {
    return width * height;
}

// 工具2：判断是否为闰年
bool isLeapYear(int year) {
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
}

// 工具3：获取成绩等级
string getGrade(int score) {
    if (score >= 90) return "优秀 🏆";
    else if (score >= 80) return "良好 👍";
    else if (score >= 70) return "中等 🙂";
    else if (score >= 60) return "及格 💪";

// 工具4：打印一行分隔线

    cout << "==============================" << endl;
}

// ========== 演示函数 ==========

void demoArea() {
    cout << "【矩形面积计算器】" << endl;
    cout << "宽5, 高3 的矩形面积 = " << rectArea(5, 3) << endl;
    cout << "宽7.5, 高2 的矩形面积 = " << rectArea(7.5, 2) << endl;

void demoLeapYear() {
    cout << "【闰年判断器】" << endl;
    cout << "2024年是闰年吗？" << (isLeapYear(2024) ? "是 ✅" : "否 ❌") << endl;
    cout << "2025年是闰年吗？" << (isLeapYear(2025) ? "是 ✅" : "否 ❌") << endl;
    cout << "2000年是闰年吗？" << (isLeapYear(2000) ? "是 ✅" : "否 ❌") << endl;

void demoGrade() {
    cout << "【成绩等级评定】" << endl;
    int scores[] = {95, 82, 75, 60, 45};
    for (int i = 0; i < 5; i++) {
        cout << "成绩 " << scores[i] << " 分 → " << getGrade(scores[i]) << endl;

// 聚合函数：一次性运行所有演示

    runAllDemos();
    return 0;
}
```

### 示例二：交互式多功能工具箱（完整版）

这是本课的核心示例——一个带有菜单系统的完整交互式工具箱程序！用户可以从菜单中选择不同的工具来使用。

```cpp
#include <iostream>
#include <string>
#include <algorithm>   // 用于 reverse 函数
using namespace std;

// ========== 辅助函数 ==========

void showSeparator(string title) {
    cout << "\n========== " << title << " ==========" << endl;
}

void pauseAndReturn() {
    cout << "\n按 Enter 键返回主菜单...";
    cin.get();      // 消耗上一个输入遗留的换行符
    cin.get();      // 等待用户按回车
}

// ========== 工具1：四则运算计算器 ==========

void calculator() {
    showSeparator("🧮 四则运算计算器");
    char op;
    double a, b;

    cout << "请输入算式（格式：数字 运算符 数字）：";
    cin >> a >> op >> b;

    cout << a << " " << op << " " << b << " = ";
    switch (op) {
        case '+': cout << a + b; break;
        case '-': cout << a - b; break;
        case '*': cout << a * b; break;
        case '/':
            if (b != 0) {
                cout << a / b;
            } else {
                cout << "错误！除数不能为零！";
            }
            break;
        default:
            cout << "不支持的运算符！";
    }
    cout << endl;
    pauseAndReturn();
}

// ========== 工具2：温度转换器 ==========

// 辅助函数：摄氏转华氏
double c2f(double celsius) {
    return celsius * 9.0 / 5.0 + 32;
}

// 辅助函数：华氏转摄氏
double f2c(double fahrenheit) {
    return (fahrenheit - 32) * 5.0 / 9.0;
}

void tempConverter() {
    showSeparator("🌡️ 温度转换器");
    cout << "请选择转换方向：" << endl;
    cout << "  1. 摄氏度 → 华氏度" << endl;
    cout << "  2. 华氏度 → 摄氏度" << endl;
    cout << "请输入选择：";
    int choice;
    cin >> choice;

    double temp;
    if (choice == 1) {
        cout << "请输入摄氏温度：";
        cin >> temp;
        cout << temp << "°C = " << c2f(temp) << "°F" << endl;
    } else if (choice == 2) {
        cout << "请输入华氏温度：";
        cin >> temp;
        cout << temp << "°F = " << f2c(temp) << "°C" << endl;
    } else {
        cout << "无效选择！" << endl;
    }
    pauseAndReturn();
}

// ========== 工具3：字符串反转器 ==========

// 辅助函数：获取字符串长度（不使用 length() 方法）
int stringLength(string str) {
    int len = 0;
    while (str[len] != '\0') {
        len++;
    }
    return len;
}

// 辅助函数：手动反转字符串
string reverseString(string str) {
    int len = stringLength(str);
    for (int i = 0; i < len / 2; i++) {
        char temp = str[i];
        str[i] = str[len - 1 - i];
        str[len - 1 - i] = temp;
    }
    return str;
}

void stringReverser() {
    showSeparator("🔤 字符串反转器");
    cout << "请输入一个字符串：";
    string input;
    cin >> input;

    cout << "原字符串：" << input << endl;
    cout << "反转结果：" << reverseString(input) << endl;

    // 判断是否为回文（正读反读都一样）
    if (input == reverseString(input)) {
        cout << "🎉 惊喜！这是一个回文字符串！" << endl;
    }
    pauseAndReturn();
}

// ========== 工具4：ASCII 艺术打印机 ==========

// 打印指定字符组成的一行
void printCharLine(char ch, int count) {
    for (int i = 0; i < count; i++) {
        cout << ch;
    }
    cout << endl;
}

// 打印三角形
void printTriangle(int height) {
    for (int i = 1; i <= height; i++) {
        for (int j = 1; j <= height - i; j++) {
            cout << " ";       // 空格填充左半边
        }
        for (int j = 1; j <= 2 * i - 1; j++) {
            cout << "*";        // 星号组成三角形
        }
        cout << endl;
    }
}

// 打印菱形
void printDiamond(int size) {
    // 上半部分
    for (int i = 1; i <= size; i++) {
        for (int j = 1; j <= size - i; j++) cout << " ";
        for (int j = 1; j <= 2 * i - 1; j++) cout << "*";
        cout << endl;
    }
    // 下半部分
    for (int i = size - 1; i >= 1; i--) {
        for (int j = 1; j <= size - i; j++) cout << " ";
        for (int j = 1; j <= 2 * i - 1; j++) cout << "*";
        cout << endl;
    }
}

void asciiPrinter() {
    showSeparator("🎨 ASCII 艺术打印机");
    cout << "请选择图案：" << endl;
    cout << "  1. 正方形" << endl;
    cout << "  2. 三角形" << endl;
    cout << "  3. 菱形" << endl;
    cout << "  4. 分隔线" << endl;
    cout << "请输入选择：";
    int choice;
    cin >> choice;

    int size;
    switch (choice) {
        case 1:
            cout << "请输入正方形边长：";
            cin >> size;
            for (int i = 0; i < size; i++) {
                printCharLine('*', size);  // 嵌套调用！
            }
            break;
        case 2:
            cout << "请输入三角形高度：";
            cin >> size;
            printTriangle(size);            // 嵌套调用！
            break;
        case 3:
            cout << "请输入菱形半高：";
            cin >> size;
            printDiamond(size);             // 嵌套调用！
            break;
        case 4:
            printCharLine('=', 40);         // 嵌套调用！
            cout << "这是一条由 printCharLine() 绘制的分隔线" << endl;
            printCharLine('=', 40);
            break;
        default:
            cout << "无效选择！" << endl;
    }
    pauseAndReturn();
}

// ========== 工具5：数学小工具 ==========

// 判断素数
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}

// 计算阶乘
long long factorial(int n) {
    long long result = 1;
    for (int i = 1; i <= n; i++) {
        result *= i;
    }
    return result;
}

void mathTools() {
    showSeparator("📐 数学小工具");
    int num;

    cout << "请输入一个正整数：";
    cin >> num;

    // 调用 isPrime 和 factorial —— 这是聚合模式的协作
    cout << num << " 是素数吗？" << (isPrime(num) ? "是 ✅" : "否 ❌") << endl;
    if (num <= 20) {  // 阶乘增长非常快，限制输入以免溢出
        cout << num << "! = " << factorial(num) << endl;
    } else {
        cout << num << " 太大了，阶乘结果会溢出！" << endl;
    }

    // 列出 2~num 之间的所有素数（再次嵌套调用 isPrime）
    cout << "2~" << num << " 之间的素数有：";
    for (int i = 2; i <= num; i++) {
        if (isPrime(i)) {    // 嵌套调用！
            cout << i << " ";
        }
    }
    cout << endl;

    pauseAndReturn();
}

int main() {

    do {

        switch (choice) {

            case 5: mathTools();       break;
            case 0:
                cout << "\n感谢你参加函数嘉年华！再见！👋" << endl;
                break;
```

### 练习三：函数嵌套调用分析

阅读下面的代码，回答：程序的输出是什么？哪些函数发生了嵌套调用？

```cpp
#include <iostream>
using namespace std;

int triple(int x) {
    return x * 3;
}

int doubleThenTriple(int x) {
    int doubled = x * 2;
    return triple(doubled);  // 这里发生了什么？
}

void printResult(int original) {
    int result = doubleThenTriple(original);  // 这里发生了什么？
    cout << original << " 先翻倍再乘三 = " << result << endl;
}

int main() {
    printResult(5);
    return 0;
}
```

<details>
<summary>点击查看答案</summary>

**程序输出：**
```
5 先翻倍再乘三 = 30
```

**嵌套调用链分析：**

```
main() 
  → 调用 printResult(5)
    → 调用 doubleThenTriple(5)
      → 内部计算：doubled = 5 * 2 = 10
      → 调用 triple(10)        ← 这里发生了嵌套！
        → 返回 10 * 3 = 30
      → 返回 30
    → 输出结果
  → 返回
```

嵌套调用发生在 `doubleThenTriple()` 函数的内部——它调用了 `triple()` 函数。这就是典型的"函数 A 调用函数 B，函数 B 又调用函数 C"的嵌套模式。

</details>
