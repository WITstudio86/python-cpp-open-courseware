## 📖 核心知识讲解

### 一、函数的"邮递员"比喻

想象一下，你家楼下有一个**快递站**。函数就像一个勤劳的**邮递员**：

- **形参（形式参数）**：就像快递单上的"收件人姓名"栏。它只是一个**占位符**，告诉你"这里需要一个名字"，但并不知道具体是谁。
- **实参（实际参数）**：就像你填在快递单上的具体名字——"小明"、"小红"。它是**真实的数据**，在调用函数时传递给函数。
- **return 返回值**：邮递员把包裹送到后，有时候需要把**签收单**带回来。这个"带回来的东西"就是返回值。
- **void 函数**：有时候邮递员只是把通知单投进信箱（比如贴一张公告），不需要带任何东西回来。这就是 void 函数——只执行任务，不返回数据。

```cpp
// 形参就是在函数定义时的"占位变量名"
int add(int a, int b) {   // a 和 b 是形参（占位符）
    return a + b;          // return 就是把结果"寄回去"
}

int main() {
    int x = 3, y = 5;
    int result = add(x, y);  // x 和 y 是实参（真实数据）
    //              ↑  这里 add(3, 5)，3和5代替了a和b的位置
    cout << result << endl;  // 输出 8
    return 0;
}
```

> **记忆口诀**：形参像快递单的空白栏，实参是你填上去的具体信息；return 是签收回执，void 是只送不收！

### 二、形参与实参详解

| 对比维度 | 形参（Formal Parameter） | 实参（Actual Argument） |
|----------|--------------------------|--------------------------|
| 出现位置 | 函数定义时的括号里 | 函数调用时的括号里 |
| 本质 | 变量声明（占位符） | 具体的值或变量 |
| 何时存在 | 函数被调用时才"活"过来 | 调用前就已经有了 |
| 作用范围 | 只能在函数内部使用 | 属于调用方的作用域 |
| 个数对应 | 定义了几个，调用时就要传几个 | 数量、类型、顺序必须与形参一一对应 |

**举个例子**，就像学校食堂打饭：
- 窗口阿姨的菜单上写着"红烧肉盖饭，配菜______、______"——这是形参，告诉你需要选配菜。
- 你大声喊："阿姨，配菜要土豆丝和番茄炒蛋！"——这是实参，给出了具体的菜名。
- 阿姨把饭给你——这是返回值！

```cpp
// 函数定义：阿姨的打饭窗口（2个形参）
string dabao(string cai1, string cai2) {
    return "一份" + cai1 + "和" + cai2 + "的套餐！";
}

int main() {
    // 函数调用：你点菜（2个实参）
    string food = dabao("土豆丝", "番茄炒蛋");
    cout << food << endl;  // 输出：一份土豆丝和番茄炒蛋的套餐！
    return 0;
}
```

### 三、return 语句详解

`return` 语句有两件事要做：
1. **立刻结束函数**：无论后面还有多少代码，遇到 `return` 就马上"下班回家"。
2. **把结果带回去**：把紧跟在 return 后面的值传递给调用方。

```cpp
// return 不同类型的值
int getAge() { return 12; }           // 返回整数
double getPi() { return 3.14159; }    // 返回小数
string getName() { return "小明"; }    // 返回字符串
bool isPassed() { return true; }      // 返回布尔值

int main() {
    cout << "年龄：" << getAge() << endl;         // 12
    cout << "圆周率：" << getPi() << endl;        // 3.14159
    cout << "姓名：" << getName() << endl;        // 小明
    cout << "及格：" << isPassed() << endl;       // 1 (true)
    return 0;
}
```

> **注意**：函数的返回值类型（函数名前面的那个类型）必须和 `return` 后面的值的类型匹配！如果函数声明为 `int`，就不能 `return "hello"`。

**return 的"提前下班"特性：**

```cpp
// 检查年龄是否合法，不合法就提前"下班"
string checkAge(int age) {
    if (age < 0) {
        return "错误：年龄不能是负数！";  // 这里就直接回去了
    }
    if (age > 150) {
        return "错误：年龄不能超过150岁！";  // 这里也直接回去
    }
    return "年龄合法，欢迎！";       // 只有上面都不成立才走到这里
}
```

### 四、void 函数——"只干活，不退货"

有些函数不需要返回任何东西。比如"打印问候语"这个函数，它只需要把问候语打印到屏幕上就行了，不需要给调用方回传任何数据。这时我们就用 `void` 类型。

```cpp
// void 函数：不返回任何值
void printGreeting(string name) {
    cout << "=========================================" << endl;
    cout << "  📬 你好，" << name << "！欢迎来到数据快递站！" << endl;
    cout << "=========================================" << endl;
    // 注意：这里没有 return 语句！
}

int main() {
    printGreeting("小明");   // 直接调用，不需要用变量接收返回值
    printGreeting("小红");   // 再来一次
    return 0;
}
```

> **void 函数的特点**：
> - 函数名前写 `void`，表示"我不返回任何东西"。
> - void 函数可以没有 `return` 语句，执行完花括号就自动结束。
> - 调用 void 函数时，不能把它赋值给变量——`int x = printGreeting("小明");` 是错误的！
> - 如果想在 void 函数中提前结束，可以写 `return;`（不带任何值）。

### 五、传递多个参数

函数可以接收任意多个参数，参数之间用逗号隔开。参数的数量、类型和顺序在定义时确定，调用时必须一一对应。

```cpp
// 快递寄送函数：需要发件人、收件人、物品、重量
void sendPackage(string sender, string receiver, string item, double weight) {
    cout << "╔═════════════════════════════════╗" << endl;
    cout << "║     📬 快递单——数据快递站      ║" << endl;
    cout << "╠═════════════════════════════════╣" << endl;
    cout << "║  发件人：" << sender << "                      ║" << endl;
    cout << "║  收件人：" << receiver << "                      ║" << endl;
    cout << "║  物品：" << item << "                         ║" << endl;
    cout << "║  重量：" << weight << " kg                     ║" << endl;
    cout << "╚═════════════════════════════════╝" << endl;
}
```

> **参数传递的黄金法则**：调用函数时，实参必须按照形参定义的顺序"对号入座"！就像寄快递要按顺序填写：姓名→地址→电话，不能把电话填在姓名那一栏。

## 💻 代码示例

### 示例一：计算面积——带参数和返回值的函数

```cpp
#include <iostream>
using namespace std;

// 计算长方形面积——这是一个"有来有回"的函数
// 输入：长(length)和宽(width) → 输出：面积
double calculateArea(double length, double width) {
    double area = length * width;  // 计算面积
    return area;                   // 把结果"寄回去"
}

int main() {
    double l, w;
    cout << "📐 长方形面积计算器" << endl;
    cout << "请输入长：";
    cin >> l;
    cout << "请输入宽：";
    cin >> w;

    // 调用函数，接收返回值
    double result = calculateArea(l, w);

    cout << "长为 " << l << "、宽为 " << w << " 的长方形" << endl;
    cout << "面积是：" << result << " 平方单位" << endl;
    return 0;
}
```

**运行示例：**
```
请输入长：5.5
请输入宽：3
长为 5.5、宽为 3 的长方形
面积是：16.5 平方单位
```

### 示例二：找最大值——快递站里比较包裹重量

```cpp
#include <iostream>
#include <string>
using namespace std;

// 比较两个整数，返回较大的那个
int maxOfTwo(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}

// 比较两个包裹的重量，返回更重的包裹信息
string findHeavierPackage(string name1, double weight1,
                          string name2, double weight2) {
    if (weight1 > weight2) {
        return name1 + "（" + to_string(weight1) + " kg）更重";
    } else if (weight2 > weight1) {
        return name2 + "（" + to_string(weight2) + " kg）更重";
    } else {
        return "两个包裹一样重";
    }
}

int main() {
    // 测试 maxOfTwo
    cout << "📦 包裹重量比较站" << endl;
    cout << "maxOfTwo(10, 25) = " << maxOfTwo(10, 25) << endl;
    cout << "maxOfTwo(99, 50) = " << maxOfTwo(99, 50) << endl;
    cout << endl;

    // 测试查找更重的包裹

    return 0;
}
```

### 练习二：判断正误（进阶）

以下关于函数参数和返回值的说法，哪些是正确的？哪些是错误的？请说明原因。

1. 形参可以在函数定义时不给名字，只写类型就行。
2. void 函数中可以写 `return 0;` 提前结束。
3. 实参和形参的名字必须相同。
4. 函数 `int calculate(int x, int y)` 被调用时必须恰好传递 2 个 int 类型的实参。

<details>
<summary>点击查看答案</summary>

**1. 错误。**
形参在函数定义中必须有名字（在函数声明中可以省略名字，但函数定义中必须有），因为函数体内部需要通过形参名来使用传入的值。例如 `int add(int a, int b)` 中的 `a` 和 `b` 必须有名字。

**2. 错误。**
void 函数中如果要用 `return` 提前退出，只能写 `return;`（不带任何值）。`return 0;` 会试图返回一个 int，与 void 的类型声明矛盾，编译器会报错。

**3. 错误。**
形参和实参的名字完全可以不同，甚至大多数情况下就是不同的。形参是函数内部的局部变量名，实参是调用方作用域中的变量名，互不影响。关键是**位置对应**，不是名字对应。

**4. 正确。**
调用函数时，实参的数量、类型必须与形参一一对应。`int calculate(int x, int y)` 有 2 个 int 形参，所以调用时必须传 2 个 int（或可以被隐式转换为 int 的）实参。

</details>

### 练习三：代码改错（进阶）

下面的代码中共有 4 处错误，请找出来并改正。

```cpp
#include <iostream>
using namespace std;

int multiply(int x, y) {               // 错误①
    return x * y;
}

void printResult(int answer) {
    cout << "结果是：" << answer << endl;
    return answer;                     // 错误②
}

int main() {
    int a = 7, b = 8;
    int c = multiply(a);               // 错误③
    int d = printResult(c);            // 错误④
    return 0;
}
```

<details>
<summary>点击查看答案</summary>

**错误①**：`int multiply(int x, y)` — 每个形参都必须有自己的类型声明。
**改正**：`int multiply(int x, int y)`

**错误②**：`return answer;` — 这是在 void 函数中试图返回一个值。
**改正**：删掉这行（void 函数不需要 return），或者改成 `return;`（不带值）。

**错误③**：`int c = multiply(a);` — 只传了 1 个实参，但 multiply 需要 2 个。
**改正**：`int c = multiply(a, b);`

**错误④**：`int d = printResult(c);` — 试图把 void 函数的"返回值"赋给 int 变量。
**改正**：直接调用 `printResult(c);`，不要赋值给变量。

**修正后的完整代码：**
```cpp
#include <iostream>
using namespace std;

int multiply(int x, int y) {
    return x * y;
}

void printResult(int answer) {
    cout << "结果是：" << answer << endl;
    // void 函数不需要 return
}

int main() {
    int a = 7, b = 8;
    int c = multiply(a, b);    // 传递两个实参
    printResult(c);            // 直接调用，不赋值
    return 0;
}
```

</details>

## 🏆 挑战任务：快递费用计算系统

**任务描述：** 编写一个完整的"快递费用计算系统"，包含以下功能：

1. **`double calculateFee(double weight, int distance, bool isUrgent)`** — 计算快递费用：
   - 基础费用 = 重量 × 2 元（每千克 2 元）
   - 远距离附加费：距离 > 1000 公里时，追加 10 元
   - 加急服务费：如果 `isUrgent` 为 true，额外加 15 元
   - 返回最终费用

2. **`void printReceipt(string sender, string receiver, double weight, int distance, bool isUrgent)`** — 打印电子面单：
   - 用 `calculateFee` 计算出费用
   - 打印格式化的快递电子面单（包括发件人、收件人、重量、距离、是否加急、费用）

3. 在 main 函数中测试：
   - 创建至少 2 个快递订单，展示不同的费用计算结果

**提示：** 在 `printReceipt` 中调用 `calculateFee`——函数之间可以互相调用！这正是模块化编程的强大之处。

<details>
<summary>点击查看参考答案</summary>

```cpp
#include <iostream>
#include <string>
#include <iomanip>
using namespace std;

// 计算快递费用
double calculateFee(double weight, int distance, bool isUrgent) {
    double fee = weight * 2.0;       // 基础费：每千克2元

    if (distance > 1000) {           // 远距离附加费
        fee += 10.0;
    }
    if (isUrgent) {                  // 加急服务费
        fee += 15.0;
    }

    return fee;
}

// 打印电子面单
void printReceipt(string sender, string receiver,
                  double weight, int distance, bool isUrgent) {
    double fee = calculateFee(weight, distance, isUrgent);

    cout << "╔══════════════════════════════════════╗" << endl;
    cout << "║     📬 数据快递站 · 电子面单         ║" << endl;
    cout << "╠══════════════════════════════════════╣" << endl;
    cout << "║  发件人：" << sender;
    for (int i = 0; i < (int)(26 - sender.length() * 2); i++) cout << " ";
    cout << "║" << endl;

    cout << "║  收件人：" << receiver;
    for (int i = 0; i < (int)(26 - receiver.length() * 2); i++) cout << " ";
    cout << "║" << endl;

    cout << "║  重量：" << weight << " kg";
    for (int i = 0; i < 20; i++) cout << " ";
    cout << "║" << endl;

    cout << "║  距离：" << distance << " 公里";
    for (int i = 0; i < 18; i++) cout << " ";
    cout << "║" << endl;

    cout << "║  加急：" << (isUrgent ? "是（+15元）" : "否");
    for (int i = 0; i < 20; i++) cout << " ";
    cout << "║" << endl;

    cout << "╠══════════════════════════════════════╣" << endl;
    cout << "║  费用合计：￥" << fee;
    for (int i = 0; i < 22; i++) cout << " ";
    cout << "║" << endl;
    cout << "╚══════════════════════════════════════╝" << endl;
    cout << endl;
}

int main() {
    cout << "🚚 === 数据快递站 · 费用计算系统 === 🚚" << endl;
    cout << endl;

    // 订单1：普通包裹，近距离
    printReceipt("小明", "小红", 2.5, 500, false);

    // 订单2：加急包裹，远距离
    printReceipt("北京分公司", "上海分公司", 8.0, 1500, true);

    // 订单3：轻便包裹，中距离，不加急
    printReceipt("文具店", "三（1）班", 0.5, 800, false);

    return 0;
}
```

</details>

## 📝 本课总结

1. **形参**是函数定义时的"占位变量"，就像快递单上的空白栏；**实参**是函数调用时传入的"真实数据"，就像填在空白栏里的具体内容。
2. **return 语句**有两个作用：① 把计算结果"寄回"给调用方；② 立即结束函数的执行。返回值的类型必须与函数声明中的返回类型一致。
3. **void 函数**表示"只干活不退货"，执行完就结束，不需要（也不能）返回任何值。如果需要在 void 函数中提前退出，可以用 `return;`（不带值）。
4. 函数可以接收**多个参数**，参数之间用逗号隔开，调用时实参必须按照形参的**数量、类型、顺序**一一对应。
5. 函数之间可以**互相调用**——一个函数可以调用另一个函数，形成模块化的程序结构，就像快递站里各个岗位各司其职、互相合作！
6. **参数的值传递**：在 C++ 中，基本类型的实参传递给形参时是"复制一份"，函数内部对形参的修改不会影响外部的实参。记住口诀："参数进门，拷贝一份，改了不管，外面不变"。

> 📝 掌握了函数参数和返回值，你的程序就不再是"一条道走到黑"的流水账了！你可以把不同的任务分给不同的函数，它们拿着参数（就像快递单）去干活，干完活把结果（返回值）带回来。这就是模块化编程的核心思想——分工合作，各司其职！下一课我们将学习函数的更多进阶用法，让代码更加强大！
