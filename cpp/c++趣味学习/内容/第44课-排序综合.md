## 一、两种排序大比拼

### 1.1 回顾两种排序

在前面两节课中，我们学习了两种经典的排序方法：

**冒泡排序（Bubble Sort）：** 像水里的气泡一样，每次让较大的数"浮"到数组的末尾。它的核心操作是**相邻两两比较**，如果顺序不对就交换位置。

**选择排序（Selection Sort）：** 像选班干部一样，每一轮找出数组中最小的（或最大的）数，把它放到最前面。它的核心操作是**找最值**，然后交换一次。

这两种排序都能把乱序的数组排好，但它们的工作方式完全不同。今天我们就来一场"王者对决"，看看它们各自的优缺点是什么。

### 1.2 比较次数大比拼

假设我们要对一个长度为 n 的数组进行排序，两种算法各需要比较多少次呢？

**冒泡排序的比较次数：**

冒泡排序每一轮都要两两比较相邻的元素。第一轮比较 n-1 次，第二轮比较 n-2 次，依次递减……总共的比较次数是：

> (n-1) + (n-2) + (n-3) + … + 2 + 1 = n(n-1)/2

对于 5 个元素，需要比较 5×4/2 = 10 次。

**选择排序的比较次数：**

选择排序每一轮也要遍历剩余的元素来找到最值。第一轮比较 n-1 次，第二轮比较 n-2 次……总共的比较次数也是：

> (n-1) + (n-2) + (n-3) + … + 2 + 1 = n(n-1)/2

咦？比较次数居然一样！那它们到底差在哪里呢？答案是——**交换次数**。

### 1.3 交换次数大不同

这是两种排序最大的区别：

**冒泡排序的交换次数：** 每次发现相邻两个元素顺序不对，就马上交换。在**最坏情况下**（数组完全倒序），每一轮中每次比较都要交换。总的交换次数可以达到 n(n-1)/2 次，和比较次数一样多！对于 5 个元素，最多可能交换 10 次。

**选择排序的交换次数：** 每一轮只交换一次——找到最值后，把它和目标位置交换。所以交换次数永远是 **最多 n-1 次**。对于 5 个元素，最多只交换 4 次。

看出差别了吗？选择排序的交换次数少得多！如果每次交换的代价很大（比如交换的是大块数据），选择排序就有明显优势。

### 1.4 稳定性对比

**稳定性**是指：如果数组中有两个值相等的元素，排序后它们的相对顺序是否保持不变。

**冒泡排序是稳定的。** 因为冒泡排序只在相邻元素"严格逆序"（前面的比后面的大）时才交换。如果两个元素相等，它们不会被交换，相对顺序保持不变。

**选择排序是不稳定的。** 因为选择排序会"跳跃式"地把最值和目标位置交换，这可能会打乱相等元素的相对顺序。

举个例子：假设我们要按照**分数**排序，有两个同学都是 90 分——小明（年龄 12）和小红（年龄 11）。如果是稳定的排序，排序后小明仍然在小红前面（保持原来的顺序）；如果是不稳定的排序，小明和小红的顺序可能会颠倒。

### 1.5 对比总结表

| 对比维度 | 冒泡排序 | 选择排序 |
|---|---|---|
| 基本思路 | 相邻比较，顺序不对就交换 | 找最值，放到目标位置 |
| 比较次数 | n(n-1)/2 | n(n-1)/2 |
| 交换次数（最坏） | n(n-1)/2 | n-1 |
| 是否稳定 | 稳定 | 不稳定 |
| 代码复杂度 | 稍复杂（双重循环+交换） | 较简单（找最值+交换） |
| 优点 | 稳定，可以在检测到已有序时提前结束 | 交换次数少，写操作少 |
| 缺点 | 交换次数多，效率较低 | 不稳定，不能提前结束 |

## 二、结构体排序——排序的新挑战

### 2.1 从"排数字"到"排名片"

之前两课我们排序的都是整数，但现实生活中，我们需要排序的往往是更复杂的数据。比如：

- 给全班同学**按成绩排名**（每个同学有姓名、年龄、成绩多个信息）
- 给商品**按价格排序**（每个商品有品名、价格、库存）
- 给图书**按销量排序**（每本书有书名、作者、销量）

这些数据就是我们在第41课学过的**结构体**。现在问题来了——结构体包含多个成员，我们怎么对它排序呢？

### 2.2 核心秘诀：比较成员，交换整体

结构体排序有一个非常重要的原则：

> **比较的时候，看的是结构体的某个成员（比如成绩）；但交换的时候，交换的是整个结构体！**

这就像给一叠名片排序。你要按照"电话号码"来排，但你移动的是整张名片，而不是只把电话号码抠出来交换。名片上的姓名、地址、公司都要跟着一起移动。

用代码来表示就是：

```cpp
// 比较的是结构体的某个成员
if (students[j].score > students[j+1].score) {
    // 交换的是整个结构体！
    Student temp = students[j];
    students[j] = students[j+1];
    students[j+1] = temp;
}
```

关键点：
1. `students[j].score` —— 用 `.` 运算符访问成员的分数来比较
2. `Student temp = students[j];` —— 交换的是整个结构体变量
3. 交换后，该同学的姓名、年龄、成绩等所有信息都一起移动了

### 2.3 多条件排序

有时候，我们需要更复杂的排序规则。比如：

- **先按成绩从高到低排序，成绩相同的按年龄从小到大排序**
- **先按价格从低到高排序，价格相同的按库存从高到低排序**
- **先按班级排序，同班级的按学号排序**

这就是**多条件排序**。实现的关键是：在比较的时候，先判断主要条件；如果主要条件相等，再判断次要条件。

```cpp
// 先按score（成绩）排序，score相同再按age（年龄）排序
if (students[j].score < students[j+1].score) {
    // 按成绩降序，成绩低的往后移
    swap(students[j], students[j+1]);
} else if (students[j].score == students[j+1].score) {
    // 成绩相同，按年龄升序，年龄大的往后移
    if (students[j].age > students[j+1].age) {
        swap(students[j], students[j+1]);
    }
}
```

### 2.4 升序还是降序

排序方向也是一个重要选择：

- **升序（从小到大）：** `>` 号比较，让大的往后移
- **降序（从大到小）：** `<` 号比较，让小的往后移

在冒泡排序中：
- 如果要用**升序**排列，条件是 `arr[j] > arr[j+1]`（前面比后面大就交换，大的往后走）
- 如果要用**降序**排列，条件是 `arr[j] < arr[j+1]`（前面比后面小就交换，小的往后走）

### 2.5 实际应用场景

结构体排序在实际编程中随处可见：

1. **成绩排名系统** —— 学校需要按总分给学生排名
2. **排行榜** —— 游戏中的玩家按分数排名
3. **商品筛选** —— 购物网站中按价格、销量、评价排序
4. **成绩单打印** —— 按学号或按成绩排列打印成绩单
5. **比赛排名** —— 运动会上按成绩排列名次
6. **图书馆管理** —— 按书名、作者、出版日期排列图书

## 三、如何选择排序方法

面对一个排序问题，我们应该如何选择呢？这里给大家一个**排序选择指南**：

| 场景 | 推荐方法 | 原因 |
|---|---|---|
| 数据量很小（< 20个） | 冒泡排序或选择排序都可以 | 差别不大，选自己最熟悉的 |
| 数据是结构体，需要稳定性 | 冒泡排序 | 保持相等元素的原始顺序 |
| 交换代价很大（结构体很大） | 选择排序 | 交换次数少，节省时间 |
| 数据基本有序 | 冒泡排序 | 可以提前结束，效率高 |
| 需要多条件排序 | 冒泡排序更好 | 稳定性让多条件排序更可控 |
| 追求代码简单 | 选择排序 | 逻辑更直观，每轮只交换一次 |

**一句话总结：** 如果追求稳定和可控，选冒泡排序；如果追求交换次数少，选选择排序。对于初学者来说，熟练掌握一种，理解另一种就够了。

## 四、完整示例代码

### 示例1：学生成绩排名（结构体数组，按成绩降序）

```cpp
#include <iostream>
#include <string>
using namespace std;

// 定义学生结构体
struct Student {
    string name;    // 姓名
    int age;        // 年龄
    double score;   // 成绩
};

int main() {
    const int N = 5;
    
    // 创建学生数组并初始化
    Student students[N] = {
        {"小明", 12, 88.5},
        {"小红", 11, 95.0},
        {"小刚", 12, 76.0},
        {"小丽", 11, 95.0},  // 和小红成绩相同！
        {"小华", 13, 82.5}
    };
    
    // 输出排序前的名单
    cout << "========== 排序前的学生名单 ==========" << endl;
    cout << "姓名\t年龄\t成绩" << endl;
    for (int i = 0; i < N; i++) {
        cout << students[i].name << "\t"
             << students[i].age << "\t"
             << students[i].score << endl;
    }
    
    // 使用冒泡排序，按成绩从高到低排列（降序）
    for (int i = 0; i < N - 1; i++) {
        for (int j = 0; j < N - 1 - i; j++) {
            // 比较成绩：如果前面的成绩比后面的低，就交换
            // 注意：比较的是 score 成员，但交换的是整个结构体
            if (students[j].score < students[j+1].score) {
                Student temp = students[j];
                students[j] = students[j+1];
                students[j+1] = temp;
            }
        }
    }
    
    // 输出排序后的排行榜
    cout << "\n========== 🏅 成绩排行榜 ==========" << endl;
    cout << "排名\t姓名\t年龄\t成绩" << endl;
    for (int i = 0; i < N; i++) {
        cout << "第" << i + 1 << "名\t"
             << students[i].name << "\t"
             << students[i].age << "岁\t"
             << students[i].score << "分" << endl;
    }
    
    // 观察稳定性：小红和小丽都是95分
    // 冒泡排序是稳定的，所以小红仍然在小丽前面（保持原始顺序）
    
    return 0;
}
```

========== 🏅 成绩排行榜 ==========

观察结果：小红和小丽都是 95 分，但是小红排在小丽前面。因为冒泡排序是**稳定的**，保持了她们在原始数组中的相对顺序。

### 示例2：多条件排序（先按成绩降序，成绩相同按年龄升序）

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Student {
    string name;
    int age;
    double score;
};

int main() {
    const int N = 6;
    
    Student students[N] = {
        {"小明", 12, 88.5},
        {"小红", 11, 95.0},
        {"小刚", 13, 88.5},  // 和小明成绩相同，但年龄不同
        {"小丽", 12, 95.0},  // 和小红成绩相同
        {"小华", 14, 82.5},
        {"小强", 12, 76.0}
    };
    
    // 多条件冒泡排序
    // 第一条件：成绩从高到低（降序）
    // 第二条件：成绩相同时，年龄从小到大（升序）
    for (int i = 0; i < N - 1; i++) {
        for (int j = 0; j < N - 1 - i; j++) {
            // 先比较成绩（主要条件）
            if (students[j].score < students[j+1].score) {
                // 成绩低，往后移
                Student temp = students[j];
                students[j] = students[j+1];
                students[j+1] = temp;
            } else if (students[j].score == students[j+1].score) {
                // 成绩相同，再比较年龄（次要条件）
                if (students[j].age > students[j+1].age) {
                    // 年龄大，往后移（年龄升序）
                    Student temp = students[j];
                    students[j] = students[j+1];
                    students[j+1] = temp;
                }
            }
        }
    }
    
    // 输出多条件排序结果
    cout << "========== 多条件排序结果 ==========" << endl;
    cout << "规则：成绩从高到低，成绩相同则年龄从小到大" << endl;
    cout << "\n排名\t姓名\t年龄\t成绩" << endl;
    cout << "--------------------------------" << endl;
    for (int i = 0; i < N; i++) {
        cout << "第" << i + 1 << "名\t"
             << students[i].name << "\t"
             << students[i].age << "岁\t"
             << students[i].score << "分" << endl;
    }
    
    return 0;
}
```

**运行结果：**
```
========== 多条件排序结果 ==========
规则：成绩从高到低，成绩相同则年龄从小到大

排名    姓名    年龄    成绩
--------------------------------
第1名   小红    11岁    95.0分
第2名   小丽    12岁    95.0分
第3名   小明    12岁    88.5分
第4名   小刚    13岁    88.5分
第5名   小华    14岁    82.5分
第6名   小强    12岁    76.0分
```

观察结果：
- 小红 95 分排第 1，小丽也是 95 分排第 2。两人成绩相同，但小红年龄更小（11岁 < 12岁），所以小红排前面。这就是多条件排序的威力！
- 小明和小刚都是 88.5 分，小明年龄 12 < 小刚年龄 13，所以小明排前面。

## 五、练习题

### 练习1：商品按价格排序（简单）

定义一个 `Product` 结构体，包含：商品名（name）、价格（price）。创建一个包含 4 个商品的数组，使用冒泡排序按价格从低到高排列，并输出排序结果。

**商品数据：** 铅笔 2.5元、橡皮 1.5元、尺子 3.0元、本子 4.0元

**参考答案：**

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Product {
    string name;
    double price;
};

int main() {
    Product products[4] = {
        {"铅笔", 2.5},
        {"橡皮", 1.5},
        {"尺子", 3.0},
        {"本子", 4.0}
    };
    
    // 按价格升序排列（冒泡排序）
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3 - i; j++) {
            if (products[j].price > products[j+1].price) {
                Product temp = products[j];
                products[j] = products[j+1];
                products[j+1] = temp;
            }
        }
    }
    
    cout << "价格从低到高排序：" << endl;
    for (int i = 0; i < 4; i++) {
        cout << products[i].name << "：" << products[i].price << "元" << endl;
    }
    
    return 0;
}
```

### 练习2：比较次数计算（中等）

阅读下面的代码，回答问题：

```cpp
int arr[5] = {9, 7, 5, 3, 1};
int compareCount = 0;
int swapCount = 0;

// 冒泡排序（升序）
for (int i = 0; i < 4; i++) {
    for (int j = 0; j < 4 - i; j++) {
        compareCount++;
        if (arr[j] > arr[j+1]) {
            int temp = arr[j];
            arr[j] = arr[j+1];
            arr[j+1] = temp;
            swapCount++;
        }
    }
}

cout << "比较次数：" << compareCount << endl;
cout << "交换次数：" << swapCount << endl;
```

**问题：**
1. 这个数组是完全倒序的（9→7→5→3→1），冒泡排序一共比较了多少次？交换了多少次？
2. 如果改用选择排序，比较多少次？交换多少次？

**答案：**
1. 冒泡排序：比较次数 = 4 + 3 + 2 + 1 = **10 次**。由于是完全倒序，每次比较都触发交换，交换次数 = **10 次**。
2. 选择排序：比较次数也是 **10 次**（和冒泡一样）。但交换次数只需要 **4 次**（每轮找最值后只交换一次，共 4 轮）。

**解析：** 这就是选择排序的优势——在数组完全倒序这种最坏情况下，选择排序的交换次数远少于冒泡排序。冒泡排序需要交换 10 次，选择排序只需要 4 次。

### 练习3：判断排序稳定性（中等）

有以下学生数据，使用选择排序按成绩降序排列：

```
原始顺序：小A(90分) → 小B(85分) → 小C(90分) → 小D(80分)
```

**问题：** 排序后小A和小C（都是90分）的先后顺序会改变吗？为什么？

**答案：** 可能会改变。因为选择排序是**不稳定的**。在第一轮中，选择排序找到最大值 90 分。假设它先扫描到小A（下标0），然后扫描到小C也是90分。因为选择排序通常使用 `>` 来判断"更优"，`90 > 90` 为假，所以第一轮不会更新"最值"的位置。第一轮结束后，小A（下标0）的 90 分已经是第一个，不需要交换。但第二轮在剩余元素中找最大值，找到小C（90分），把小C和下标1的小B交换。此时小C排到了小A后面——顺序颠倒了！

如果使用冒泡排序（稳定的），小A会一直在小C前面，保持原始顺序。

**选择排序可能导致的不稳定结果：** 小A → 小C → 小B → 小D（取决于实现细节）
**冒泡排序的稳定结果：** 小A → 小C → 小B → 小D（但小A一定在小C前面）

**任务描述：**

学校运动会刚刚结束，每个运动员参加了多个项目。现在需要你编写一个**运动会成绩排行榜**程序。

每个运动员的信息用结构体表示：

```cpp
struct Athlete {

};

**要求：**

2. 计算每个运动员的 `total`（奖牌总数）

   - 第一条件：金牌数从高到低
   - 第二条件：金牌相同时，银牌数从高到低
   - 第三条件：银牌也相同时，铜牌数从高到低

```

## 本课小结

| 知识点 | 说明 |
|---|---|
| 两种排序对比 | 比较次数相同，但冒泡交换次数多、稳定；选择交换次数少、不稳定 |
| 结构体排序原则 | 比较的是某个成员（如 `.score`），交换的是整个结构体 |
| 多条件排序 | 用 `if ... else if` 实现：先判断主条件，相等时判断次条件 |
| 升序/降序选择 | 升序用 `>`（大的往后移），降序用 `<`（小的往后移） |
| 稳定性意义 | 稳定排序保持相等元素的原始顺序，适合多条件排序场景 |
| 选择排序方法 | 需要稳定选冒泡，追求效率选选择；初学者以冒泡为主 |
