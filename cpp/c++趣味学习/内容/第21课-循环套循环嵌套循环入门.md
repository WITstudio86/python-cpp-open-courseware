## 📖 知识讲解

### 什么是嵌套循环？

你有没有见过俄罗斯套娃？打开一个娃娃，里面还有一个娃娃，再打开，里面还有一个……嵌套循环就像编程世界里的俄罗斯套娃——一个循环里面，还套着另一个循环。

生活中嵌套循环的例子到处都是：
- 学校的课程表：每天（外层）有6节课（内层），一周5天就是5×6=30节课
- 时钟的运行：时针每走1格（外层），分针要走60格（内层）
- 电影院的座位：每一排（外层）有若干个座位（内层）

### 嵌套循环的语法

```cpp
for (int i = 1; i <= 3; i++) {      // 外层循环
    cout << "外层第" << i << "圈开始" << endl;
    for (int j = 1; j <= 2; j++) {  // 内层循环
        cout << "  内层第" << j << "次" << endl;
    }
    cout << "外层第" << i << "圈结束" << endl;
}
```

**运行结果：**
```
外层第1圈开始
  内层第1次
  内层第2次
外层第1圈结束
外层第2圈开始
  内层第1次
  内层第2次
外层第2圈结束
外层第3圈开始
  内层第1次
  内层第2次
外层第3圈结束
```

### 嵌套循环的执行规律

嵌套循环有一个非常重要的规律：**外层循环每执行1次，内层循环就要完整地执行1遍**。

以上面的代码为例：
- 外层执行3次（i=1,2,3）
- 内层每次执行2次（j=1,2）
- 总执行次数 = 3 × 2 = 6次（内层循环体的执行次数）

用时钟来理解特别形象：
- 时针（外层）一天转2圈
- 分针（内层）时针每转1圈，分针转60圈
- 分针一天转 2 × 60 = 120圈

### 嵌套循环的变量命名

当循环嵌套时，我们通常用不同的字母来命名循环变量：
- 外层常用：`i`
- 内层常用：`j`
- 更深层：`k`, `l`...

这不是规定，只是约定俗成的习惯。但这些变量各有各的作用域，互不干扰。

### 嵌套循环的形式

嵌套循环不限于for套for，可以任意组合：

```cpp
// for套for（最常见）
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; j++) {
        cout << "(" << i << "," << j << ") ";
    }
    cout << endl;
}

// while套for
int i = 1;
while (i <= 3) {
    for (int j = 1; j <= 3; j++) {
        cout << i * j << " ";
    }
    cout << endl;
    i++;
}

// for套while
for (int i = 1; i <= 3; i++) {
    int j = 1;
    while (j <= 3) {
        cout << i + j << " ";
        j++;
    }
    cout << endl;
}
```

### 分析循环次数

嵌套循环的总执行次数 = 外层次数 × 内层次数

```cpp
// 总次数 = 5 × 10 = 50次
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 10; j++) {
        // 这里面的代码执行了50次
    }
}

// 总次数 = 1+2+3+4+5 = 15次（内层次数随外层变化）
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) {  // 内层上限=i
        // i=1时执行1次，i=2时执行2次...
    }
}
```

### break在嵌套循环中

在嵌套循环中，break只能跳出它所在的那层循环：

```cpp
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 10; j++) {
        if (j == 3) break;  // 只跳出内层j循环，外层i循环继续
        cout << "(" << i << "," << j << ") ";
    }
    cout << endl;  // 内层break后执行这里，然后外层进入下一轮
}
```

## 💻 示例代码

### 示例1：打印数字正方形

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "🟦 数字正方形生成器" << endl;
    cout << "请输入边长：";
    cin >> n;

    cout << endl << "边长为 " << n << " 的数字正方形：" << endl << endl;

    for (int i = 1; i <= n; i++) {         // 外层控制行
        for (int j = 1; j <= n; j++) {     // 内层控制列
            cout << j << " ";               // 打印列号
        }
        cout << endl;                       // 每行结束换行
    }

    return 0;
}
```

### 示例2：打印坐标网格

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    cout << "📍 坐标网格（1-5行 × 1-5列）" << endl;
    cout << "每个位置用(行号,列号)表示" << endl;
    cout << "---------------------------------" << endl;

    // 表头
    cout << "      ";
    for (int col = 1; col <= 5; col++) {
        cout << "  列" << col << "  ";
    }
    cout << endl;

    // 网格内容
    for (int row = 1; row <= 5; row++) {
        cout << "行" << row << "：";
        for (int col = 1; col <= 5; col++) {
            cout << " (" << row << "," << col << ")";
        }
        cout << endl;
    }

    cout << "---------------------------------" << endl;
    cout << "🌟 一共 " << 5 * 5 << " 个坐标位置！" << endl;

    return 0;
}
```

## 📝 本课小结

- **嵌套循环**就是一个循环的循环体内又包含另一个循环
- 嵌套循环的核心规律：**外层每循环1次，内层完整循环1遍**
- 总循环次数 = 外层次数 × 内层次数（内层次数固定时）
- 常用变量命名：外层用`i`，内层用`j`
- 嵌套循环可以任意组合：for套for、while套for、for套while等
- break在嵌套循环中**只跳出当前层**，不影响外层循环
- 嵌套循环是打印**二维图形**（正方形、矩形、三角形等）的基础
