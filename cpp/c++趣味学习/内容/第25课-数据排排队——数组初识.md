## 课程导入

同学们，想象一下体育课上的场景：老师让全班同学排成一列纵队，每个人站在自己固定的位置上。老师说"第3位同学出列"，那位同学就马上站出来。为什么这么方便？因为大家排好了队，每个人都有固定的位置编号！

## 核心概念

### 1. 什么是数组？

数组是一组**相同类型**数据的集合。这些数据在内存中连续存放，每一个数据称为数组的一个**元素（Element）**。数组中的每个元素都有一个**下标（Index）**，用来表示它在数组中的位置。

可以把数组想象成一列小火车：火车头后面挂着一节节车厢，每节车厢装着一个数据，车厢的编号就是下标。

```
数组 scores：
+------+------+------+------+------+
|  98  |  85  |  92  |  78  |  95  |   ← 元素的值
+------+------+------+------+------+
  [0]    [1]    [2]    [3]    [4]      ← 下标（从0开始！）
```

### 2. 数组的声明

声明一个数组需要指定：**数据类型**、**数组名**、**元素个数**。

```cpp
数据类型 数组名[元素个数];
```

实际例子：

```cpp
int scores[40];        // 声明一个能存40个整数的数组，存放成绩
string names[30];      // 声明一个能存30个字符串的数组，存放名字
float heights[50];     // 声明一个能存50个小数的数组，存放身高
double prices[100];    // 声明一个能存100个双精度小数的数组，存放价格
char letters[26];      // 声明一个能存26个字符的数组，存放字母
```

注意：元素个数必须是一个**常量**或**常量表达式**，一旦声明，数组的大小就固定了（静态数组）。

### 3. 数组的初始化

我们可以在声明数组的同时给它赋初值：

```cpp
// 完全初始化：给所有元素赋值
int numbers[5] = {10, 20, 30, 40, 50};

// 部分初始化：只给前几个元素赋值，其余自动为0
int nums[5] = {1, 2};    // 相当于 {1, 2, 0, 0, 0}

// 省略大小：编译器自动计算元素个数
int grades[] = {90, 85, 92, 78, 95};  // 自动确定为5个元素

// 全部初始化为0
int zeros[100] = {0};    // 所有100个元素都是0

// 字符串数组初始化
string names[3] = {"小明", "小红", "小刚"};
```

### 4. 下标访问规则（非常重要！）

在C++中，**数组的下标从0开始**，而不是从1开始。这是初学者最容易出错的地方！

- 第1个元素的下标是 **0**
- 第2个元素的下标是 **1**
- 第3个元素的下标是 **2**
- ...
- 第n个元素的下标是 **n-1**

也就是说，如果数组有5个元素，有效下标范围是 **0 ~ 4**。

```cpp
int arr[5] = {10, 20, 30, 40, 50};

cout << arr[0];  // 输出 10（第1个元素）
cout << arr[1];  // 输出 20（第2个元素）
cout << arr[2];  // 输出 30（第3个元素）
cout << arr[3];  // 输出 40（第4个元素）
cout << arr[4];  // 输出 50（第5个元素）

// 修改元素的值
arr[2] = 100;    // 把第3个元素改成100
```

> **⚠️ 数组越界：** 访问 `arr[5]` 或 `arr[-1]` 会导致**数组越界**错误！这就像在只有5个人的队伍里喊"第6位同学出列"。C++不会阻止你这样做，但结果不可预料，可能导致程序崩溃！

### 5. 数组元素的输入与输出

配合循环，我们可以方便地输入和输出数组中的所有元素：

```cpp
// 输入5个成绩
int scores[5];
for (int i = 0; i < 5; i++) {
    cout << "请输入第" << i + 1 << "个成绩：";
    cin >> scores[i];
}

// 输出所有成绩
for (int i = 0; i < 5; i++) {
    cout << "第" << i + 1 << "个成绩：" << scores[i] << endl;
}
```

## 代码示例：制作班级花名册

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // ========== 示例1：基本数组声明与初始化 ==========
    cout << "=== 示例1：数组的声明与初始化 ===" << endl;
    
    // 声明并初始化一个整数数组
    int scores[5] = {95, 87, 92, 78, 88};
    cout << "声明了一个包含5个成绩的数组" << endl;
    
    // 声明并初始化一个字符串数组——这就是我们的花名册！
    string names[5] = {"小明", "小红", "小刚", "小丽", "小华"};
    cout << "声明了一个包含5个名字的花名册" << endl;
    cout << endl;
    
    // ========== 示例2：下标访问 ==========
    cout << "=== 示例2：使用下标访问数组元素 ===" << endl;
    cout << "第1位同学：" << names[0] << "，成绩：" << scores[0] << endl;
    cout << "第3位同学：" << names[2] << "，成绩：" << scores[2] << endl;
    cout << "最后一位同学：" << names[4] << "，成绩：" << scores[4] << endl;
    cout << endl;
    
    // ========== 示例3：花名册展示系统 ==========
    cout << "=== 示例3：班级花名册 ===" << endl;
    cout << "╔══════════════════════╗" << endl;
    cout << "║     班级花名册       ║" << endl;
    cout << "╠════╦═════════════════╣" << endl;
    cout << "║ 编号║     姓名       ║" << endl;
    cout << "╠════╬═════════════════╣" << endl;
    for (int i = 0; i < 5; i++) {
        cout << "║  " << i + 1 << "  ║  " << names[i];
        // 为了对齐，补充空格
        int len = names[i].length();
        for (int j = 0; j < 12 - len; j++) {
            cout << " ";
        }
        cout << "║" << endl;
    }
    cout << "╚════╩═════════════════╝" << endl;
    cout << endl;
    
    // ========== 示例4：修改花名册 ==========
    cout << "=== 示例4：修改花名册 ===" << endl;
    cout << "小刚转学了，新同学'小强'加入班级！" << endl;
    names[2] = "小强";  // 修改第3位同学的名字（下标为2）
    cout << "更新后的第3位同学：" << names[2] << endl;
    
    // 显示更新后的花名册
    cout << "\n更新后的花名册：" << endl;
    for (int i = 0; i < 5; i++) {
        cout << i + 1 << ". " << names[i] << endl;
    }
    
    return 0;
}
```

**逐行讲解：**

1. `int scores[5] = {95, 87, 92, 78, 88};` — 声明一个有5个元素的整数数组，同时初始化成绩。
2. `string names[5] = {"小明", "小红", ...};` — 声明一个字符串数组作为花名册。
3. `names[0]` — 访问数组的第1个元素（下标为0），得到"小明"。
4. `for (int i = 0; i < 5; i++)` — 循环变量`i`从0到4，正好对应5个元素的下标。
5. `names[i]` — 在循环中使用变量`i`作为下标，依次访问每个元素。
6. `names[2] = "小强";` — 修改下标为2的元素（第3位同学）。
7. 表格输出使用了Unicode制表符，让花名册看起来更美观。

## 本课小结

| 知识点 | 要点 |
|--------|------|
| 什么是数组 | 一组**相同类型**数据的集合，在内存中连续存放 |
| 声明格式 | `类型 数组名[大小];` |
| 下标规则 | **从0开始**，第n个元素的下标是 n-1 |
| 初始化 | 用花括号 `{值1, 值2, ...}` 在声明时赋值 |
| 访问元素 | 通过 `数组名[下标]` 读取或修改 |
| 遍历数组 | 配合 `for` 循环和下标变量，高效处理所有元素 |
| 数组越界 | 访问超出 0 ~ (大小-1) 范围的下标会导致错误 |

**学习口诀：**
> 数据排队站整齐，类型相同在一起。
> 下标从零开始记，第n元素下标减一。
> 花括号里赋初值，for循环遍历最容易！

数组是编程中非常重要的数据结构，下节课我们将学习如何用循环遍历数组，来进行求和、求平均值等更复杂的计算。别忘了完成课后练习哦！
