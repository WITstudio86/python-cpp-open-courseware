# 第37课：魔法配方——函数初识 🧪

## 📋 学习目标

1. **理解函数的概念**：知道什么是函数，为什么需要函数，函数在编程中扮演的角色。
2. **掌握函数的定义方法**：能够正确书写函数的返回类型、函数名、参数列表和函数体。
3. **学会调用函数**：理解函数调用的语法，能够在主函数或其他函数中正确调用已定义的函数。
4. **体会代码复用的价值**：通过实际例子感受"写一次，用多次"带来的便利，理解 DRY（Don't Repeat Yourself）原则。

## 📖 知识讲解：什么是函数？

### 🧪 从魔法配方说起

想象你是一位小魔法师，你有一本**魔法书**。魔法书里记录着各种各样的配方（Recipe）——比如"治疗药水配方"、"火焰咒语配方"。每一个配方都告诉你：需要什么材料（输入），按照什么步骤操作（过程），最终变出什么东西（输出）。

在 C++ 编程中，**函数（Function）** 就是这样的"魔法配方"！函数是一段**有名字的、可以重复使用的代码块**。当你需要执行某个任务时，只需要"念出咒语"（调用函数的名字），而不需要每次都把配方从头到尾重新写一遍。

### 🔧 函数的"四要素"

一个完整的函数定义包含四个部分，我们可以用下面这个结构图来理解：

```
返回类型  函数名  ( 参数列表 )
   ↓        ↓         ↓
  int     add   ( int a, int b )
{
    // 函数体 —— 这里是具体的"魔法步骤"
    int result = a + b;
    return result;   ← 返回值
}
```

#### 1. 返回类型（Return Type）

返回类型告诉计算机：这个函数执行完毕后，会"交还"一个什么类型的值。常见的返回类型有：

| 返回类型 | 含义 | 举例 |
|---------|------|------|
| `int` | 返回一个整数 | 加法函数返回两数之和 |
| `double` | 返回一个小数 | 计算平均分的函数 |
| `char` | 返回一个字符 | 获取成绩等级的函数 |
| `string` | 返回一个字符串 | 获取用户姓名的函数 |
| `bool` | 返回真或假 | 判断是否及格的函数 |
| `void` | **不返回任何值** | 打印一条消息的函数 |

> 💡 `void` 是一个特殊的返回类型，它表示"空"——这个函数只是执行一些操作，但不返回任何数据。比如一个专门负责在屏幕上打印图案的函数。

#### 2. 函数名（Function Name）

函数名是你给这个"魔法配方"起的名字。好的函数名应该：
- **见名知意**：一看就知道这个函数是干什么的，比如 `add`（加法）、`printGreeting`（打印问候语）。
- **符合命名规范**：通常使用小写字母开头，多个单词用驼峰命名法（camelCase）或下划线分隔。
- **使用动词或动词短语**：因为函数代表一个"动作"。

#### 3. 参数列表（Parameters）

参数是函数的"输入材料"。它们写在函数名后面的**小括号 `()`** 里。参数也需要指定类型和名字：

```cpp
int multiply(int x, int y)  // x 和 y 是两个 int 类型的参数
```

- **形参（Formal Parameter）**：定义函数时写的参数，如上面的 `x` 和 `y`。它们是"占位符"，告诉函数"你会收到两个整数"。
- **实参（Actual Argument）**：调用函数时实际传入的值，如 `multiply(3, 5)` 中的 `3` 和 `5`。

一个函数可以有零个、一个或多个参数。没有参数的函数，括号里留空即可：

```cpp
void sayHello()  // 没有参数
{
    cout << "Hello!" << endl;
}
```

#### 4. 函数体（Function Body）

函数体是花括号 `{}` 里面的所有代码，它描述了函数具体要执行的步骤。就像魔法配方中的"制作过程"：

```cpp
int add(int a, int b)
{
    int sum = a + b;   // 步骤1：计算和
    return sum;        // 步骤2：返回结果
}
```

### 📞 函数调用：念出咒语！

定义好函数之后，我们需要**调用（Call）** 它才能让它执行。函数调用的语法很简单：

```cpp
函数名(实参1, 实参2, ...);
```

如果函数有返回值，我们可以用一个变量来接收它：

```cpp
int result = add(10, 20);  // 调用 add 函数，result 的值为 30
```

如果函数是 `void` 类型（没有返回值），直接调用即可：

```cpp
sayHello();  // 直接调用，屏幕上会显示 "Hello!"
```

### 🏠 函数声明 vs 函数定义

在 C++ 中，函数需要**先声明（或定义），后使用**。也就是说，编译器必须在上方"见过"这个函数，才能在下方调用它。

**函数声明（Function Declaration）**：只写出函数的"头部"（返回类型 + 函数名 + 参数列表），以分号结尾，不写函数体。它告诉编译器："有这么一个函数存在，具体的实现后面再说。"

```cpp
int add(int a, int b);  // 函数声明（也叫函数原型）
```

**函数定义（Function Definition）**：包含函数头和函数体的完整写法。

通常在程序中，我们有两种组织方式：

**方式一：定义在调用之前（简单程序常用）**
```cpp
#include <iostream>
using namespace std;

// 先定义
void greet() {
    cout << "你好，小魔法师！" << endl;
}

int main() {
    greet();  // 再调用 —— 没问题！
    return 0;
}
```

**方式二：先声明，后定义（大程序常用）**
```cpp
#include <iostream>
using namespace std;

// 先声明
void greet();

int main() {
    greet();  // 调用 —— 编译器已经知道 greet 存在了
    return 0;
}

// 后定义
void greet() {
    cout << "你好，小魔法师！" << endl;
}
```

### ♻️ 代码复用的魔力

函数最大的价值在于**代码复用（Code Reuse）**。想象一下，如果你的魔法书中有 10 个不同的配方都需要"烧开水"这个步骤，你是选择：

- ❌ 在每个配方中都写一遍"烧开水"的详细步骤？
- ✅ 还是定义一个 `boilWater()` 函数，然后在 10 个配方中各调用一次？

显然，第二种方式更聪明！这就是函数的魅力：

1. **减少重复代码**：同样的逻辑只写一次。
2. **易于维护**：如果需要修改"烧开水"的步骤，只需改一处。
3. **代码更清晰**：主程序读起来像一份简洁的"任务清单"。
4. **便于分工合作**：不同的人可以负责不同的函数。

## 💻 代码示例

### 示例一：简单的计算器函数

```cpp
#include <iostream>
using namespace std;

// 函数定义：加法
int add(int a, int b) {
    return a + b;
}

// 函数定义：减法
int subtract(int a, int b) {
    return a - b;
}

// 函数定义：乘法
int multiply(int a, int b) {
    return a * b;
}

// 函数定义：除法
double divide(int a, int b) {
    if (b == 0) {
        cout << "错误：除数不能为零！" << endl;
        return 0;
    }
    return static_cast<double>(a) / b;
}

// 函数定义：打印分隔线（void 类型，无返回值）
void printLine() {
    cout << "==============================" << endl;
}

int main() {
    int x = 24, y = 6;

    printLine();
    cout << "🧮 简易计算器" << endl;
    printLine();

    // 调用各个函数并输出结果
    cout << x << " + " << y << " = " << add(x, y) << endl;
    cout << x << " - " << y << " = " << subtract(x, y) << endl;
    cout << x << " × " << y << " = " << multiply(x, y) << endl;
    cout << x << " ÷ " << y << " = " << divide(x, y) << endl;

    printLine();

    return 0;
}
```

**运行结果：**
```
==============================
🧮 简易计算器
==============================
24 + 6 = 30
24 - 6 = 18
24 × 6 = 144
24 ÷ 6 = 4
==============================
```

### 示例二：判断数字属性的函数

```cpp
#include <iostream>
using namespace std;

// 判断一个数是否为偶数（返回 bool 类型）
bool isEven(int num) {
    return num % 2 == 0;
}

// 判断一个数是否为正数
bool isPositive(int num) {
    return num > 0;
}

// 获取一个数的绝对值
int myAbs(int num) {
    if (num >= 0) {
        return num;
    } else {
        return -num;
    }
}

// 打印一个数的所有属性
void describeNumber(int num) {
    cout << "数字 " << num << " 的属性：" << endl;
    cout << "  - 是偶数吗？" << (isEven(num) ? "是" : "否") << endl;
    cout << "  - 是正数吗？" << (isPositive(num) ? "是" : "否") << endl;
    cout << "  - 绝对值是：" << myAbs(num) << endl;
}

int main() {
    describeNumber(12);
    cout << endl;
    describeNumber(-7);
    cout << endl;
    describeNumber(0);

    return 0;
}
```

**运行结果：**
```
数字 12 的属性：
  - 是偶数吗？是
  - 是正数吗？是
  - 绝对值是：12

数字 -7 的属性：
  - 是偶数吗？否
  - 是正数吗？否
  - 绝对值是：7

数字 0 的属性：
  - 是偶数吗？是
  - 是正数吗？否
  - 绝对值是：0
```

```cpp
_____ square(int n) {   // ① 应该写什么返回类型？

```

```cpp
int square(int n) {

}
```

① 返回类型应为 `int`，因为整数的平方还是整数。
② 返回 `n * n`，即 n 乘以自身。

</details>

### 练习二：找出错误

下面的代码有 **3 处错误**，请找出并改正。

```cpp
#include <iostream>
using namespace std;

int max(int a, b) {          // 错误1
    if (a > b) {
        return a;
    }
    // 错误2：如果 a <= b 时没有返回值
}

int main() {
    int result = max(10);    // 错误3
    cout << result << endl;
    return 0;
}
```

<details>
<summary>点击查看答案</summary>

**错误1：** 参数 `b` 没有指定类型。应改为 `int max(int a, int b)`。

**错误2：** 当 `a <= b` 时，函数没有 `return` 语句。应在花括号结束前加上 `return b;`。

**错误3：** 调用 `max(10)` 只传了一个参数，但函数需要两个参数。应改为 `max(10, 20)`。

**修正后的代码：**
```cpp
#include <iostream>
using namespace std;

int max(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}

int main() {
    int result = max(10, 20);
    cout << result << endl;
    return 0;
}
```

</details>

### 练习三：编写函数

请编写一个名为 `power` 的函数，接收两个 `int` 参数 `base`（底数）和 `exp`（指数），返回 `base` 的 `exp` 次方（假设 `exp >= 0`）。然后在 `main` 函数中测试它。

<details>
<summary>点击查看答案</summary>

```cpp
#include <iostream>
using namespace std;

int power(int base, int exp) {
    int result = 1;
    for (int i = 0; i < exp; i++) {
        result *= base;
    }
    return result;
}

int main() {
    cout << "2^3 = " << power(2, 3) << endl;   // 输出 8
    cout << "5^4 = " << power(5, 4) << endl;   // 输出 625
    cout << "10^0 = " << power(10, 0) << endl; // 输出 1
    return 0;
}
```

</details>

## 🏆 挑战任务：打造你的魔法书

请创建至少 **5 个函数**，组合成一个"魔法配方书"程序。要求：

1. 至少包含一个 `void` 类型的函数（如打印魔法书的封面）。
2. 至少包含一个返回 `int` 的函数（如计算药水效力）。
3. 至少包含一个返回 `bool` 的函数（如判断药水是否炼制成功）。
4. 在 `main` 函数中有逻辑地调用这些函数，呈现一个完整的"炼制魔法药水"的过程。

<details>
<summary>点击查看参考思路</summary>

```cpp
#include <iostream>
#include <string>
using namespace std;

// 打印魔法书封面
void showBookCover() {
    cout << "📖 ╔══════════════════════╗" << endl;
    cout << "   ║   🧪 魔法配方全书 🧪  ║" << endl;
    cout << "   ╚══════════════════════╝" << endl;
}

// 计算材料总价
int calcCost(int herb, int crystal, int powder) {
    return herb * 3 + crystal * 5 + powder * 2;
}

// 判断药水是否成功（成功率 > 50% 则成功）
bool isSuccess(int power) {
    return power > 50;
}

// 获取药水等级
string getPotionGrade(int power) {
    if (power >= 90) return "✨ 传说级";
    else if (power >= 70) return "🌟 稀有级";
    else if (power >= 50) return "⭐ 精良级";
    else return "💨 普通级";
}

// 打印炼制结果
void printResult(string potionName, int power, bool success) {
    cout << "\n🧪 炼制结果：" << endl;
    cout << "   药水名称：" << potionName << endl;
    cout << "   药水效力：" << power << endl;
    cout << "   炼制状态：" << (success ? "✅ 成功！" : "❌ 失败...") << endl;
    cout << "   药水等级：" << getPotionGrade(power) << endl;
}

int main() {
    showBookCover();

    cout << "\n🔮 开始炼制：治疗药水" << endl;
    int power1 = 75;
    printResult("治疗药水", power1, isSuccess(power1));

    cout << "\n------------------------" << endl;
    cout << "💰 材料费用：" << calcCost(3, 1, 5) << " 金币" << endl;

    cout << "\n🔮 开始炼制：力量药水" << endl;
    int power2 = 45;
    printResult("力量药水", power2, isSuccess(power2));

    cout << "\n📖 魔法书已合上，下次再见！" << endl;
```

## 📝 本课小结

| 知识点 | 核心内容 |
|--------|---------|
| **函数是什么** | 一段有名字、可重复使用的代码块，像魔法书中的配方 |
| **函数四要素** | 返回类型、函数名、参数列表、函数体 |
| **返回类型** | 告诉计算机函数返回什么类型的数据；`void` 表示不返回 |
| **参数** | 函数的"输入材料"，写在括号里，需要指定类型和名字 |
| **函数调用** | `函数名(实参)`；有返回值的可以用变量接收 |
| **声明 vs 定义** | 声明只写头部 + 分号；定义包含函数体；必须先声明/定义后调用 |
| **代码复用** | "写一次，用多次"——减少重复、易于维护、代码更清晰 |
| **DRY 原则** | Don't Repeat Yourself —— 不要重复你自己！ |

> 🧪 **魔法咒语口诀**：定义函数像写配方，返回类型要思量；函数名字见名知意，参数列表不能忘；花括号里写步骤，return 把结果交上；要使用时喊名字，传入实参就能用上！
