## 📖 知识讲解

### 一、游戏规则回顾

石头剪刀布是大家从小就熟悉的猜拳游戏，规则非常简单：

- **石头** 赢 **剪刀**（石头能砸坏剪刀）
- **剪刀** 赢 **布**（剪刀能剪开布）
- **布** 赢 **石头**（布能包住石头）
- 相同手势则为 **平局**

在编程中，我们需要用数字来表达这些手势。最常见的做法是：

| 数字 | 手势 | 符号 |
|:----:|:----:|:----:|
| 0 | 石头 | ✊ |
| 1 | 剪刀 | ✌ |
| 2 | 布 | ✋ |

> **为什么用 0/1/2？** 使用连续的数字能让我们利用数学关系来简化判断逻辑。例如，`(player - computer + 3) % 3` 的结果可以直接告诉我们胜负情况。

### 二、胜负判断逻辑

假设玩家出拳为 `player`，电脑出拳为 `computer`，我们可以建立一个胜负判断表：

| 玩家 \ 电脑 | 电脑出 0 (石头) | 电脑出 1 (剪刀) | 电脑出 2 (布) |
|:-----------:|:---------------:|:---------------:|:-------------:|
| 玩家出 0 (石头) | 平局 | **玩家赢** | 电脑赢 |
| 玩家出 1 (剪刀) | 电脑赢 | 平局 | **玩家赢** |
| 玩家出 2 (布) | **玩家赢** | 电脑赢 | 平局 |

上表中玩家赢的三种情况是：
- 玩家出石头(0)，电脑出剪刀(1)
- 玩家出剪刀(1)，电脑出布(2)
- 玩家出布(2)，电脑出石头(0)

这正好对应：`(player + 1) % 3 == computer` 时玩家获胜。美丽且整洁！

当然，用 `if-else` 逐一判断也完全可以，对于初学者来说更加直观易懂：

```cpp
if (player == computer) {
    cout << "平局！" << endl;
} else if ((player == 0 && computer == 1) ||
           (player == 1 && computer == 2) ||
           (player == 2 && computer == 0)) {
    cout << "你赢了！" << endl;
} else {
    cout << "电脑赢了！" << endl;
}
```

### 三、多轮比赛的计分系统

在实际的石头剪刀布比赛中，我们往往采用"三局两胜"制——即进行最多 3 局比赛，先赢 2 局的一方获得最终胜利。

**计分逻辑的核心思路：**

1. 设置 `playerScore` 和 `computerScore` 两个变量，初始值为 0。
2. 使用 `while` 循环，条件是双方分数都小于 2（即还没有人赢得 2 局）。
3. 每局结束后，根据胜负结果给对应分数 +1。
4. 循环结束后，比较双方的最终分数，宣布获胜者。

**三局两胜的三种可能结果：**
- 玩家连胜两局（2:0 获胜）
- 电脑连胜两局（0:2 落败）
- 双方各赢一局后，第三局决出胜负（2:1 或 1:2）

还有一种特殊情况：如果前两局都打平，则需要继续第三局——虽然概率较低，但程序逻辑需要覆盖。

### 四、随机数的公平性

在编写电脑出拳的代码时，我们使用 `rand() % 3` 来生成 0、1、2 中的一个随机数，分别代表石头、剪刀、布。为了让每次运行程序时电脑的出拳顺序不同，我们需要在程序开始时调用 `srand(time(0))` 来设置随机种子。

> **课堂小知识：** `time(0)` 返回从 1970年1月1日 到现在经过的秒数。因为每秒钟这个值都在变化，所以我们用时间来作为随机种子，保证每次游戏体验都不同。如果不设置种子，每次运行程序时 `rand()` 都会产生相同的随机数序列——那可就太无聊了！

另外，`rand() % 3` 会生成 0、1、2 三个数，它们的概率基本相等（各约 33.3%），因此电脑的出拳是公平的，不会偏向任何一种手势。

## 💻 代码示例

### 示例 1：单局石头剪刀布（一局定胜负）

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    // 设置随机种子
    srand(time(0));

    int player, computer;

    // 玩家输入
    cout << "===== 石头剪刀布 =====" << endl;
    cout << "请出拳：0-石头  1-剪刀  2-布" << endl;
    cout << "你的选择：";
    cin >> player;

    // 电脑随机出拳
    computer = rand() % 3;

    // 显示双方出拳
    string gestures[] = {"石头", "剪刀", "布"};
    cout << "你出了：" << gestures[player] << endl;
    cout << "电脑出了：" << gestures[computer] << endl;

    // 判断胜负
    if (player == computer) {
        cout << "结果：平局！🤝" << endl;
    } else if ((player == 0 && computer == 1) ||
               (player == 1 && computer == 2) ||
               (player == 2 && computer == 0)) {
        cout << "结果：你赢了！🎉" << endl;
    } else {
        cout << "结果：电脑赢了！😢" << endl;
    }

    return 0;
}
```

### 示例 2：三局两胜制完整游戏

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand(time(0));

    int playerScore = 0;
    int computerScore = 0;
    int round = 1;
    string gestures[] = {"石头", "剪刀", "布"};

    cout << "===== 石头剪刀布 —— 三局两胜 =====" << endl;
    cout << "规则：先赢两局者获胜！" << endl << endl;

    // 最多进行3轮，或直到有人赢2局
    while (playerScore < 2 && computerScore < 2 && round <= 3) {
        cout << "------ 第 " << round << " 局 ------" << endl;
        cout << "当前比分 —— 你：" << playerScore
             << "  电脑：" << computerScore << endl;

        int player, computer;
        cout << "请出拳：0-石头  1-剪刀  2-布" << endl;
        cout << "你的选择：";
        cin >> player;

        // 输入合法性检查
        if (player < 0 || player > 2) {
            cout << "输入无效，请输入 0、1 或 2！" << endl;
            continue;  // 跳过本轮，重新输入
        }

        computer = rand() % 3;

        cout << "你出了：" << gestures[player] << endl;
        cout << "电脑出了：" << gestures[computer] << endl;

        // 判断本局胜负并计分
        if (player == computer) {
            cout << "本局：平局！" << endl;
        } else if ((player == 0 && computer == 1) ||
                   (player == 1 && computer == 2) ||
                   (player == 2 && computer == 0)) {
            cout << "本局：你赢了！" << endl;
            playerScore++;
        } else {
            cout << "本局：电脑赢了！" << endl;
            computerScore++;
        }

        round++;
        cout << endl;
    }

    // 最终结果判定
    cout << "===== 最终结果 =====" << endl;
    cout << "最终比分 —— 你：" << playerScore
         << "  电脑：" << computerScore << endl;

    if (playerScore > computerScore) {
        cout << "🎉 恭喜你，获得了最终胜利！" << endl;
    } else if (computerScore > playerScore) {
        cout << "😢 很遗憾，电脑获得了最终胜利！" << endl;
    } else {
        cout << "🤝 平局收场！" << endl;
    }

    return 0;
}
```

### 练习 2：理解三局两胜

在"三局两胜"制中，最少需要打几局才能决出胜负？最多能打几局？

<details>
<summary>点击查看答案</summary>

**答案**：
- **最少 2 局**：如果一方连赢两局（2:0），比赛直接结束，不需要打第三局。
- **最多 3 局**：如果双方各赢一局后（1:1），需进行第三局决胜。即使前两局都平局，第三局如果再次平局，则最终比分可能是 0:0 或 1:1，以平局收场。

</details>

## 🚀 挑战任务

**挑战：为游戏添加更多手势——"蜥蜴史波克"版**

在经典石头剪刀布的基础上，有一种叫做"石头剪刀布蜥蜴史波克"（Rock Paper Scissors Lizard Spock）的扩展版本，共有 5 种手势：

| 手势 | 数字 | 能击败 |
|:----:|:----:|:------:|
| 剪刀 | 0 | 布、蜥蜴 |
| 布 | 1 | 石头、史波克 |
| 石头 | 2 | 剪刀、蜥蜴 |
| 蜥蜴 | 3 | 史波克、布 |
| 史波克 | 4 | 剪刀、石头 |

胜利规则为每种手势能击败另外两种手势。请尝试编写这个五手势版本的游戏。

**提示**：
- 使用 `rand() % 5` 随机生成 0-4 之间的数
- 胜负判断可以用数组或条件语句实现
- 可以设计一个二维胜负表来简化判断逻辑

<details>
<summary>点击查看挑战任务参考思路</summary>

可以用一个 5x5 的二维数组 `rules[5][5]` 来存储胜负关系：
- `rules[i][j] = 0` 表示平局
- `rules[i][j] = 1` 表示玩家手势 i 赢手势 j
- `rules[i][j] = -1` 表示玩家手势 i 输给手势 j

这样可以大大简化判断逻辑！

</details>

## 📝 本课小结

1. **随机数是模拟电脑出拳的核心**：使用 `srand(time(0))` 设置随机种子，`rand() % 3` 生成 0-2 的随机数来代表石头、剪刀、布。
2. **胜负判断是游戏的灵魂**：可以用 `if-else` 逐条件判断，也可以用 `(a - b + 3) % 3` 的数学关系来优雅地实现。
3. **多轮计分需要循环和累加**：通过 `while` 循环控制比赛轮次，用变量记录双方得分，每局结束后根据结果更新分数。
4. **三局两胜的关键**：循环继续的条件是双方分数都小于 2，一旦有人先得 2 分则比赛结束。
5. **从简单到复杂逐步构建**：先写单局对战 → 加上循环变成多局 → 加上计分变成完整的比赛系统 → 最后可以扩展手势、添加胜率统计等功能，这是一个非常好的编程思维训练过程！
