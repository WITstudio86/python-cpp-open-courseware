- 能够运用算术运算符解决生活中的数学问题

## 📖 知识讲解

### 认识"数学小助手"

同学们，你们在数学课上学过加、减、乘、除四则运算对吧？在C++编程世界里，也有一群勤劳的"数学小助手"，它们的工作就是帮我们完成各种计算。这群小助手的名字叫做**算术运算符**。

算术运算符一共有五位成员，让我们一个个来认识它们：

| 助手代号 | 名字 | 作用 | 举例 |
|---------|------|------|------|
| `+` | 加法小助手 | 把两个数加在一起 | `3 + 5` 结果是 `8` |
| `-` | 减法小助手 | 从一个数中减去另一个 | `10 - 4` 结果是 `6` |
| `*` | 乘法小助手 | 把两个数相乘 | `6 * 7` 结果是 `42` |
| `/` | 除法小助手 | 把一个数除以另一个 | `15 / 4` 结果是 `3` |
| `%` | 取余小助手 | 求除法剩下的余数 | `15 % 4` 结果是 `3` |

你可能会好奇：为什么乘法用 `*` 而不是 `×` 呢？这是因为在键盘上找不到 `×` 这个符号，所以程序员们就用星号 `*` 来代替。同样地，除法也没有用 `÷`，而是用斜杠 `/`。

### 除法小助手的"怪脾气"

接下来要讲一个非常重要的知识点——除法小助手有一个"怪脾气"。在C++中，当两个**整数**相除时，结果仍然是**整数**，小数部分会被直接扔掉（不是四舍五入哦，是直接丢弃）。

比如说，`15 / 4` 在数学上是 `3.75`，但是在C++中，`15 / 4` 的结果是 `3`。是不是很奇怪？这就像是你和三个朋友分15块钱，每个人分到3块，剩下的3块没法再分了，就暂时放在一边。

所以请记住这个规则：

> **整数 ÷ 整数 = 整数（小数部分直接舍弃）**

那如果我们想要得到带小数的结果怎么办呢？这就要用到后面课程会学到的"小数类型"（`double` 或 `float`），比如写成 `15.0 / 4.0` 就会得到 `3.75` 了。不过那是以后的内容，今天我们先记住整数除法的特点就好。

### 取余小助手——分糖果大法

现在来认识一位新朋友：取余运算符 `%`。它是五兄弟中最特别的，因为在小学数学里你还没学过它呢！

取余运算的作用是：求两个数相除之后的**余数**。我们用一个生活中的例子来理解：

**分糖果的故事：**

想象你过生日，带了17颗糖果到学校，想要分给班上的5个好朋友。你该怎么分呢？

- 首先，你给每个小朋友发糖果，一轮一轮地发
- 第一轮，每人发1颗，发掉5颗，还剩12颗
- 第二轮，每人发1颗，发掉5颗，还剩7颗
- 第三轮，每人发1颗，发掉5颗，还剩2颗
- 只剩2颗了，不够再给每人发一颗，分糖果结束！

最后，每个小朋友分到了 **3** 颗糖果，还剩下 **2** 颗糖果没人要（你可以自己吃掉！）。

用C++代码来表示就是：
- `17 / 5` 得到 `3`（每个小朋友分到几颗——这是除法）
- `17 % 5` 得到 `2`（最后剩下几颗——这是取余）

这下懂了吧？除法和取余是一对好搭档：
- 除法 `/` 告诉你**每人分几个**
- 取余 `%` 告诉你**分完之后还剩几个**

再来几个例子巩固一下：
- `20 / 6 = 3`，`20 % 6 = 2`（20个苹果分给6个人，每人3个，剩2个）
- `10 / 3 = 3`，`10 % 3 = 1`（10块饼干分给3个人，每人3块，剩1块）
- `8 / 4 = 2`，`8 % 4 = 0`（8支铅笔分给4个人，每人2支，正好分完，没有剩余！）

### 运算符的"排队规则"——优先级

五种算术运算符在一起干活的时候，可不是谁站在前面就先算谁。它们有一套"排队规则"，就像我们在学校排队做操一样——有些同学站在前面，有些同学站在后面，按照固定的顺序来。

C++中的运算符优先级规则和数学课上学的一模一样：

1. **括号 `()` —— 绝对优先！** 就像班级里的班长，有最高的权力。括号里面的计算总是最先进行。
2. **乘除取余 `* / %` —— 第二梯队。** 这三位是好朋友，优先级相同，谁在前面就先算谁。
3. **加减 `+ -` —— 第三梯队。** 这两位也是好朋友，优先级相同，谁在前面就先算谁。

来看几个例子：

- `3 + 5 * 2`：乘法比加法优先，先算 `5 * 2 = 10`，再算 `3 + 10 = 13`
- `(3 + 5) * 2`：括号优先！先算括号里的 `3 + 5 = 8`，再算 `8 * 2 = 16`
- `10 - 6 / 2`：除法优先，先算 `6 / 2 = 3`，再算 `10 - 3 = 7`
- `8 * 3 % 5`：乘法和取余同级，从左到右，先算 `8 * 3 = 24`，再算 `24 % 5 = 4`

> **记住口诀：** 括号排第一，乘除站中间，加减靠后边，同级左到右！

这个口诀和我们小学数学的"先乘除、后加减"是一样的，只不过C++里还多了一个取余运算，它和乘除是同一级别的。

### 算术运算符的"超能力"

掌握了这五位数学小助手，你的C++程序就能变成一个小小的计算器！你可以：
- 让程序帮你算出买文具要花多少钱
- 计算班级平均分
- 验证数学题的答案
- 甚至做一个分糖果的公平分配系统！

是不是很酷？接下来的例子和练习，会带你一步步成为名副其实的"算术小天才"！

## 💻 示例代码

### 示例1：五种算术运算初体验
```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 15, b = 4;

    cout << "===== 五个数学小助手登场！=====" << endl;
    cout << "a = " << a << ", b = " << b << endl;
    cout << endl;

    // 加法
    cout << "加法小助手：a + b = " << a + b << endl;

    // 减法
    cout << "减法小助手：a - b = " << a - b << endl;

    // 乘法
    cout << "乘法小助手：a * b = " << a * b << endl;

    // 除法（注意：整数相除，结果也是整数！）
    cout << "除法小助手：a / b = " << a / b;
    cout << "  （注意！15÷4=3.75，但整数除法只保留3）" << endl;

    // 取余（求余数）
    cout << "取余小助手：a % b = " << a % b;
    cout << "  （15÷4=3余3，所以取余结果是3）" << endl;

    return 0;
}
```
**运行结果：**
```
===== 五个数学小助手登场！=====
a = 15, b = 4

加法小助手：a + b = 19
减法小助手：a - b = 11
乘法小助手：a * b = 60
除法小助手：a / b = 3  （注意！15÷4=3.75，但整数除法只保留3）
取余小助手：a % b = 3  （15÷4=3余3，所以取余结果是3）
```

### 示例2：分糖果问题
```cpp
#include <iostream>
using namespace std;

int main() {
    int candies, kids;

    // 让用户输入糖果数和小朋友数
    cout << "请输入糖果总数：";
    cin >> candies;
    cout << "请输入小朋友人数：";
    cin >> kids;

    // 计算每个小朋友分到几颗糖，以及剩下几颗
    int eachGets = candies / kids;    // 除法：每人分几颗
    int leftOver = candies % kids;    // 取余：还剩下几颗

    cout << endl;
    cout << "===== 分糖果结果 =====" << endl;
    cout << "一共有 " << candies << " 颗糖果" << endl;
    cout << "分给 " << kids << " 个小朋友" << endl;
    cout << "每个小朋友分到：" << eachGets << " 颗" << endl;
    cout << "还剩下：" << leftOver << " 颗" << endl;

    // 判断分得是否公平
    if (leftOver == 0) {
        cout << "🎉 太棒了！正好分完，每人一样多！" << endl;
    } else {
        cout << "还剩下 " << leftOver << " 颗，老师帮你保管吧~" << endl;
    }

    return 0;
}
```
**运行示例（输入17和5）：**
```
请输入糖果总数：17
请输入小朋友人数：5

===== 分糖果结果 =====
一共有 17 颗糖果
分给 5 个小朋友
每个小朋友分到：3 颗
还剩下：2 颗
还剩下 2 颗，老师帮你保管吧~
```

### 示例3：运算符优先级大挑战
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "===== 优先级大挑战！=====" << endl;
    cout << endl;

    // 对比1：有没有括号，差别很大！
    cout << "3 + 5 * 2 的结果是：" << 3 + 5 * 2;
    cout << "  （先算5*2=10，再算3+10=13）" << endl;

    cout << "(3 + 5) * 2 的结果是：" << (3 + 5) * 2;
    cout << "  （先算括号3+5=8，再算8*2=16）" << endl;
    cout << endl;

    // 对比2：同级运算符，从左到右
    cout << "20 - 8 - 3 的结果是：" << 20 - 8 - 3;
    cout << "  （从左到右：20-8=12，12-3=9）" << endl;

    cout << "24 / 3 * 2 的结果是：" << 24 / 3 * 2;
    cout << "  （从左到右：24/3=8，8*2=16）" << endl;
    cout << endl;

    // 综合挑战：一道复杂的表达式
    int result = (10 + 2) * 3 % 5 - 4 / 2;
    cout << "(10+2)*3%5 - 4/2 = " << result << endl;
    cout << "计算过程：" << endl;
    cout << "  第1步：括号 (10+2) = 12" << endl;
    cout << "  第2步：12 * 3 = 36" << endl;
    cout << "  第3步：36 % 5 = 1 （36÷5=7余1）" << endl;
    cout << "  第4步：4 / 2 = 2" << endl;
    cout << "  第5步：1 - 2 = -1" << endl;

    return 0;
}
```
**运行结果：**
```
===== 优先级大挑战！=====

3 + 5 * 2 的结果是：13  （先算5*2=10，再算3+10=13）
(3 + 5) * 2 的结果是：16  （先算括号3+5=8，再算8*2=16）

20 - 8 - 3 的结果是：9  （从左到右：20-8=12，12-3=9）
24 / 3 * 2 的结果是：16  （从左到右：24/3=8，8*2=16）

(10+2)*3%5 - 4/2 = -1
计算过程：
  第1步：括号 (10+2) = 12
  第2步：12 * 3 = 36
  第3步：36 % 5 = 1 （36÷5=7余1）
  第4步：4 / 2 = 2
  第5步：1 - 2 = -1
```

### 练习1：分糖果小能手
你有 **17** 颗糖果，要平均分给 **5** 个小朋友。请问：
- 每个小朋友分到几颗糖？
- 还剩几颗糖没有分出去？

请用C++代码计算并输出这两个结果。

**提示：** 用 `/` 算每人分多少，用 `%` 算剩下多少。

**参考答案：**
```cpp
#include <iostream>
using namespace std;

int main() {

    // 输出：每人分到：3 颗
    //      还剩下：2 颗
    return 0;
}
```

### 练习2：优先级大考验
不用电脑，先自己算一算下面这个表达式的值是多少？然后用程序验证你的答案。

```cpp
(3 + 5) * 2 - 8 / 4
```

一步一步来：
1. 先算括号里的 `3 + 5 = 8`
2. 再算乘法 `8 * 2 = 16`
3. 再算除法 `8 / 4 = 2`
4. 最后算减法 `16 - 2 = 14`

**参考答案：** 结果是 `14`。

```cpp
#include <iostream>

    // 输出：(3+5)*2 - 8/4 = 14
    return 0;

```

### 练习3：三位数的数位分离
编写程序，把一个三位数（比如 `368`）的**百位、十位、个位**上的数字分别取出来并输出。

**提示：**
- 百位数字 = 原数字 ÷ 100 （比如 `368 / 100 = 3`）
- 十位数字 = 原数字 ÷ 10，再取余10 （比如 `368 / 10 = 36`，`36 % 10 = 6`）
- 个位数字 = 原数字 % 10 （比如 `368 % 10 = 8`）

**参考答案：**
```cpp
#include <iostream>
using namespace std;

int main() {
    int num = 368;

    int bai = num / 100;        // 百位：368 / 100 = 3
    int shi = num / 10 % 10;    // 十位：368 / 10 = 36，36 % 10 = 6
    int ge = num % 10;          // 个位：368 % 10 = 8

    cout << "数字 " << num << " 的数位分离：" << endl;
    cout << "百位：" << bai << endl;
    cout << "十位：" << shi << endl;
    cout << "个位：" << ge << endl;

    // 验证一下：3*100 + 6*10 + 8 = 368
    cout << "验证：" << bai << "×100 + " << shi << "×10 + " << ge << " = ";
    cout << bai * 100 + shi * 10 + ge << endl;

    return 0;
}
```
**运行结果：**
```
数字 368 的数位分离：
百位：3
十位：6
个位：8
验证：3×100 + 6×10 + 8 = 368
```

### 挑战：制作超级计算器！

编写一个C++程序，让用户输入两个整数，然后程序自动计算出并显示：
1. 它们的**和**（加法）
2. 它们的**差**（减法）
3. 它们的**积**（乘法）
4. 它们的**商**（除法，保留小数！）
5. 它们的**余数**（取余）

**提示：**
- 用 `cin` 获取用户输入的两个数字
- 商要保留小数的话，需要把整数转换成小数类型（`double`）
- 比如：`double(a) / b` 或 `a * 1.0 / b` 都可以得到带小数的商

**参考示例：**
```cpp
#include <iostream>
using namespace std;

int main() {
    int num1, num2;

    cout << "====== 超级计算器 ======" << endl;
    cout << "请输入第一个整数：";
    cin >> num1;
    cout << "请输入第二个整数：";
    cin >> num2;

    cout << endl;
    cout << "===== 计算结果 =====" << endl;
    cout << num1 << " + " << num2 << " = " << num1 + num2 << endl;
    cout << num1 << " - " << num2 << " = " << num1 - num2 << endl;
    cout << num1 << " × " << num2 << " = " << num1 * num2 << endl;

    // 用 double 保留小数，避免整数除法丢失小数
    cout << num1 << " ÷ " << num2 << " = ";
    cout << double(num1) / num2 << "  （精确商，保留小数）" << endl;

    cout << num1 << " % " << num2 << " = " << num1 % num2;
    cout << "  （余数）" << endl;

    return 0;
}
```
**运行示例（输入17和5）：**
```
====== 超级计算器 ======
请输入第一个整数：17
请输入第二个整数：5

===== 计算结果 =====
17 + 5 = 22
17 - 5 = 12
17 × 5 = 85
17 ÷ 5 = 3.4  （精确商，保留小数）
17 % 5 = 2  （余数）
```

## 📝 本课小结

| 知识点 | 内容 |
|--------|------|
| 加法 `+` | 把两个数相加，如 `3 + 5 = 8` |
| 减法 `-` | 从一个数中减去另一个，如 `10 - 4 = 6` |
| 乘法 `*` | 把两个数相乘，如 `6 * 7 = 42` |
| 整数除法 `/` | 两个整数相除，结果只保留整数部分。如 `15 / 4 = 3` |
| 取余 `%` | 求除法剩下的余数，如 `15 % 4 = 3`，`17 % 5 = 2` |
| 优先级 | 括号 → 乘除取余 → 加减，同级从左到右 |
| 分糖果公式 | 每人分到 = 总数 / 人数；剩下的 = 总数 % 人数 |

**记住这句口诀：**

> 加减乘除和取余，五位助手来帮忙；
> 整数除法丢小数，取余专管剩多少；
> 括号优先排第一，乘除取余站中间；
> 加减最后来处理，同级就从左到右！
