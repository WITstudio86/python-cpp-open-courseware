## 核心概念

### 1. 为什么要遍历数组？

**遍历（Traversal）** 就是按照顺序访问数组中的每一个元素。就像老师点名一样——从队伍的第1个人开始，一个一个点过去，直到最后一个人。

遍历数组通常使用 `for` 循环，循环变量 `i` 从 0 变化到 `n-1`（n 为数组大小），每次循环用 `数组名[i]` 访问当前元素。

```cpp
// 遍历数组的标准写法
for (int i = 0; i < n; i++) {
    // 对 arr[i] 进行操作
    cout << arr[i] << " ";   // 例如：输出当前元素
}
```

**为什么循环变量从0开始？** 因为数组下标从0开始，i = 0 对应第1个元素，i = n-1 对应第n个（最后一个）元素。

**为什么条件是 `i < n` 而不是 `i <= n`？** 因为当 i = n 时，访问 `arr[n]` 会导致越界！有效下标最大是 n-1。

### 2. 求数组元素的总和（Sum）

求总和是遍历数组最经典的应用。思路很简单：用一个累加变量，遍历数组时把每个元素加进去。

```cpp
// 计算数组所有元素的总和
int sum = 0;                      // 累加器，初始为0
for (int i = 0; i < n; i++) {
    sum = sum + arr[i];           // 也可以写 sum += arr[i];
}
cout << "总和：" << sum << endl;
```

**算法图解（以成绩数组为例）：**

```
数组：  [85]  [92]  [78]  [95]  [88]
        i=0   i=1   i=2   i=3   i=4

循环过程：
i=0: sum = 0  + 85 = 85
i=1: sum = 85 + 92 = 177
i=2: sum = 177 + 78 = 255
i=3: sum = 255 + 95 = 350
i=4: sum = 350 + 88 = 438

最终总和 = 438
```

### 3. 求平均值（Average）

有了总和，平均值 = 总和 ÷ 元素个数。

```cpp
double average = (double)sum / n;   // 强制转换为小数，避免整除
cout << "平均分：" << average << endl;
```

**重要提醒：** 注意 `sum / n` 的问题！
- 如果 `sum` 和 `n` 都是整数，C++ 会进行**整数除法**（舍弃小数部分）。
- 例如：`438 / 5` 在整数除法中结果是 `87`，而不是 `87.6`。
- 解决方法：`(double)sum / n` 或 `sum * 1.0 / n`，将其中一个操作数转为浮点数。

### 4. 遍历中的条件统计

在遍历数组的同时，我们还可以根据条件进行各种统计：

```cpp
// 统计及格人数（成绩 >= 60）
int passCount = 0;
for (int i = 0; i < n; i++) {
    if (scores[i] >= 60) {
        passCount++;    // 及格人数加1
    }
}
cout << "及格人数：" << passCount << endl;

// 统计最高分
int maxScore = scores[0];   // 先假设第一个是最高分
for (int i = 1; i < n; i++) {
    if (scores[i] > maxScore) {
        maxScore = scores[i];  // 发现了更高的分数，更新
    }
}
cout << "最高分：" << maxScore << endl;
```

### 5. 常用遍历模式总结

| 任务 | 核心代码模式 |
|------|------------|
| 输出所有元素 | `for(i=0; i<n; i++) cout << arr[i];` |
| 输入所有元素 | `for(i=0; i<n; i++) cin >> arr[i];` |
| 求和 | `sum = 0; for(...) sum += arr[i];` |
| 求平均值 | `avg = (double)sum / n;` |
| 找最大值 | `max = arr[0]; for(...) if(arr[i]>max) max=arr[i];` |
| 找最小值 | `min = arr[0]; for(...) if(arr[i]<min) min=arr[i];` |
| 条件计数 | `count = 0; for(...) if(条件) count++;` |

## 代码示例：成绩统计分析器

### 完整程序代码

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    const int MAX = 100;            // 最多支持100个成绩
    int scores[MAX];                // 成绩数组
    int n;                          // 实际人数

    // ===== 输入阶段 =====
    cout << "╔══════════════════════════╗" << endl;
    cout << "║    成绩统计分析器       ║" << endl;
    cout << "╚══════════════════════════╝" << endl;
    cout << "请输入班级人数（最多" << MAX << "人）：";
    cin >> n;

    if (n <= 0 || n > MAX) {
        cout << "输入人数无效！" << endl;
        return 1;
    }

    cout << "\n请逐个输入成绩（0~100）：" << endl;
    for (int i = 0; i < n; i++) {
        cout << "  第" << i + 1 << "位同学的成绩：";
        cin >> scores[i];

        // 输入验证
        while (scores[i] < 0 || scores[i] > 100) {
            cout << "  成绩应在0~100之间，请重新输入：";
            cin >> scores[i];
        }
    }

    // ===== 显示所有成绩 =====
    cout << "\n===== 全班成绩列表 =====" << endl;
    for (int i = 0; i < n; i++) {
        cout << "第" << setw(2) << i + 1 << "位：" << setw(3) << scores[i] << "分  ";
        // 每行显示5个成绩
        if ((i + 1) % 5 == 0) cout << endl;
    }
    cout << endl;

    // ===== 统计分析 =====
    // 1. 计算总和与平均分
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += scores[i];
    }
    double average = (double)sum / n;

    // 2. 找最高分和最低分
    int maxScore = scores[0];
    int minScore = scores[0];
    for (int i = 1; i < n; i++) {
        if (scores[i] > maxScore) maxScore = scores[i];
        if (scores[i] < minScore) minScore = scores[i];
    }

    // 3. 统计人数分布
    int aboveAverage = 0;   // 高于平均分的人数
    int belowAverage = 0;   // 低于平均分的人数
    int excellent = 0;      // 优秀人数（>=90）
    int good = 0;           // 良好人数（80~89）
    int medium = 0;         // 中等人数（70~79）
    int pass = 0;           // 及格人数（60~69）
    int fail = 0;           // 不及格人数（<60）

    for (int i = 0; i < n; i++) {
        // 与平均分比较
        if (scores[i] > average) aboveAverage++;
        else if (scores[i] < average) belowAverage++;

        // 分数段统计
        if (scores[i] >= 90) excellent++;
        else if (scores[i] >= 80) good++;
        else if (scores[i] >= 70) medium++;
        else if (scores[i] >= 60) pass++;
        else fail++;
    }

    // ===== 输出分析报告 =====
    cout << fixed << setprecision(1);  // 保留1位小数
    cout << "\n╔═══════════════════════════════════╗" << endl;
    cout << "║        成绩分析报告               ║" << endl;
    cout << "╠═══════════════════════════════════╣" << endl;
    cout << "║  班级人数：        " << setw(6) << n << " 人        ║" << endl;
    cout << "║  总分：            " << setw(6) << sum << " 分        ║" << endl;
    cout << "║  平均分：          " << setw(6) << average << " 分        ║" << endl;
    cout << "║  最高分：          " << setw(6) << maxScore << " 分        ║" << endl;
    cout << "║  最低分：          " << setw(6) << minScore << " 分        ║" << endl;
    cout << "╠═══════════════════════════════════╣" << endl;
    cout << "║  优秀（90~100）：  " << setw(6) << excellent << " 人        ║" << endl;
    cout << "║  良好（80~89）：   " << setw(6) << good << " 人        ║" << endl;
    cout << "║  中等（70~79）：   " << setw(6) << medium << " 人        ║" << endl;
    cout << "║  及格（60~69）：   " << setw(6) << pass << " 人        ║" << endl;
    cout << "║  不及格（<60）：   " << setw(6) << fail << " 人        ║" << endl;
    cout << "╠═══════════════════════════════════╣" << endl;
    cout << "║  高于平均分：      " << setw(6) << aboveAverage << " 人        ║" << endl;
    cout << "║  低于平均分：      " << setw(6) << belowAverage << " 人        ║" << endl;
    cout << "╚═══════════════════════════════════╝" << endl;

    // ===== 成绩柱状图（简易） =====
    cout << "\n===== 成绩分布柱状图 =====" << endl;
    cout << "优秀(≥90): ";
    for (int i = 0; i < excellent; i++) cout << "█";
    cout << " " << excellent << "人" << endl;
    cout << "良好(80): ";
    for (int i = 0; i < good; i++) cout << "█";
    cout << " " << good << "人" << endl;
    cout << "中等(70): ";
    for (int i = 0; i < medium; i++) cout << "█";
    cout << " " << medium << "人" << endl;
    cout << "及格(60): ";
    for (int i = 0; i < pass; i++) cout << "█";
    cout << " " << pass << "人" << endl;
    cout << "不及格:   ";
    for (int i = 0; i < fail; i++) cout << "█";
    cout << " " << fail << "人" << endl;

    return 0;
}
```

**代码逐行讲解：**

1. `const int MAX = 100;` — 定义常量，数组最大容量为100。
2. `for (int i = 0; i < n; i++)` — 经典遍历模式，用循环输入所有成绩。
3. `sum += scores[i];` — 累加求和，`+=` 是 `sum = sum + scores[i]` 的简写。
4. `double average = (double)sum / n;` — 计算平均分，`(double)`强制转换避免整数除法。
5. `if (scores[i] > maxScore) maxScore = scores[i];` — "打擂台"法找最大值。
6. `fixed << setprecision(1)` — 设置输出格式：固定小数点，保留1位小数。
7. 柱状图部分 — 用循环输出 `█` 字符，直观展示成绩分布。

## 本课小结

| 知识点 | 要点 |
|--------|------|
| 遍历数组 | 使用 `for (i = 0; i < n; i++)` 依次访问每个元素 |
| 循环变量 | i 从0开始，条件是 i < n（不是 i <= n） |
| 求和 | 累加器 `sum += arr[i]`，初始化为0 |
| 求平均 | `(double)sum / n`，注意类型转换避免整数除法 |
| 找最值 | "打擂台"法：假设第一个是最值，循环比较更新 |
| 条件统计 | 在遍历时用 `if` 判断，计数器累加 |
| 数据展示 | 可以用柱状图、表格等形式直观展示分析结果 |

**学习口诀：**
> for循环来遍历，i从零到n减一。
> 累加求和先清零，求平均值转浮点。
> 擂台法找最值，条件统计加判断。
> 数组配合循环用，批量处理最给力！

数组遍历是编程中最基础也最重要的技能之一。无论以后学习什么算法——搜索、排序、统计——都离不开数组的遍历。下一节课我们将学习数组的排序算法，敬请期待！
