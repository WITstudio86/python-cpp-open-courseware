# 第03课：电脑的记忆——注释与代码规范

## 🎯 学习目标
- 理解什么是注释以及注释的作用
- 掌握单行注释（`//`）和多行注释（`/* */`）的使用方法
- 学习代码缩进和命名规范，养成良好编程习惯

## 📖 知识讲解

### 什么是注释？

你有没有在课本上做过笔记？在重要的地方画一条线，在旁边写上自己的理解？编程里的**注释**就是这样的"笔记"——它是写在代码旁边、帮助理解代码的文字。

注释有一个神奇的特点：**编译器会完全忽略它们！** 也就是说，注释是写给"人"看的，不是写给电脑看的。电脑执行程序时会跳过所有注释，就像你读故事书时跳过插图下面的小字一样。

为什么需要注释呢？想象一下：

1. **帮助自己记忆**：你今天写了一段很厉害的代码，但一周后可能就想不起来它是干什么的了。注释就像给自己留的"备忘条"。
2. **帮助别人理解**：如果你的代码要给同学看，注释可以帮助他们更快地理解你的想法。
3. **解释复杂逻辑**：有些代码可能比较复杂，一两句注释就能解释清楚"为什么这样写"。

### 单行注释：`//`

单行注释用两个斜杠 `//` 开头。从 `//` 开始到这一行结束的所有内容都会被认为是注释。

```cpp
// 这是一个单行注释，编译器会忽略它
cout << "Hello!" << endl;  // 注释也可以写在代码的后面
```

语法规则：
- `//` 后面的所有文字（到行尾）都是注释
- 注释可以是中文、英文、甚至是表情符号！
- 注释写在代码上面、代码后面都可以

### 多行注释：`/* */`

如果你要写比较长的注释——比如一段详细的说明——用单行注释就得写好多行 `//`。这时候多行注释就派上用场了！

多行注释用 `/*` 开始，用 `*/` 结束。两个标记之间的所有内容都是注释。

```cpp
/* 这是一个多行注释
   可以写很多行
   编译器都会忽略
   非常适合写长说明！ */
cout << "多行注释演示" << endl;
```

**注意事项：**
- `/*` 和 `*/` 必须成对出现，就像一个包装盒的盖子，有开就有合
- 多行注释不能嵌套（一个多行注释里面不能再包含一个多行注释）
- 多行注释中间可以写任意内容，包括代码

### 代码缩进——让代码"有层次感"

看看下面两段代码，你觉得哪个更清晰？

**没有缩进的代码（乱糟糟的）：**
```cpp
int main() {
cout << "第一行" << endl;
cout << "第二行" << endl;
if (true) {
cout << "条件成立" << endl;
}
return 0;
}
```

**有缩进的代码（整整齐齐的）：**
```cpp
int main() {
    cout << "第一行" << endl;
    cout << "第二行" << endl;
    if (true) {
        cout << "条件成立" << endl;
    }
    return 0;
}
```

显然第二种更清晰，对吧？**缩进**就是在每行代码前面加上空格（通常是2个或4个空格，或者按一次Tab键），让代码看起来有层次感。

缩进的规则很简单：
- 每进入一对花括号 `{ }`，就增加一级缩进
- 同一级的代码缩进要一样多
- 大多数程序员用4个空格作为一级缩进

缩进就像写作文时的分段——你会在新的一段开头空两格，让文章更有层次感。代码缩进也是同样的道理！

### 命名规则——给东西起个好名字

在编程中，我们需要给很多东西起名字：变量名、函数名、文件名……好的名字能让代码"会说话"，坏的名字则让人摸不着头脑。

来看看对比：

| 坏名字 | 好名字 | 说明 |
|--------|--------|------|
| `a`, `b`, `c` | `age`, `score`, `name` | 名字要有意义 |
| `x1`, `x2` | `studentAge`, `maxScore` | 用英文单词描述用途 |
| `aaa`, `bbb` | `totalSum`, `average` | 见名知意 |
| `我的变量` | `myVariable` | 变量名一般用英文 |

**C++命名规则：**
1. 只能用字母（A-Z, a-z）、数字（0-9）和下划线（_）
2. 第一个字符不能是数字（`1name` 不行，`name1` 可以）
3. 不能使用C++的关键字（如 `int`、`return`、`if`）
4. 区分大小写（`age` 和 `Age` 是两个不同的名字）

**命名风格：**
- **驼峰式命名**：`myAge`, `studentName`, `totalScore`（像骆驼的驼峰一样，每个新单词首字母大写）
- **下划线命名**：`my_age`, `student_name`, `total_score`（用下划线连接单词）

两种都可以，关键是要**保持一致**！

## 💻 示例代码

### 示例1：注释的各种用法
```cpp
// ==========================================
//  程序：注释与代码规范示例
//  作者：小明
//  日期：2026年
//  说明：这个程序展示了注释的用法
// ==========================================

#include <iostream>
using namespace std;

int main() {
    // 单行注释：输出欢迎信息
    cout << "欢迎来到C++世界！" << endl;

    /*
     * 多行注释：
     * 下面我们输出几条信息
     * 每条信息介绍一个知识点
     * 这样写注释是不是很清晰？
     */
    cout << "今天我们要学习注释的使用。" << endl;  // 行尾注释
    cout << "注释让代码更容易理解！" << endl;

    return 0;  // 程序正常结束
}
```

### 示例2：好的缩进 vs 坏的缩进
```cpp
#include <iostream>
using namespace std;

int main() {
    // ✅ 好的缩进：层次分明，一目了然
    cout << "第一层" << endl;
    cout << "还是第一层" << endl;

    // 下面是一个代码块（以后会学到）
    {
        cout << "第二层：多缩进了4个空格" << endl;
        {
            cout << "第三层：又多缩进了4个空格" << endl;
        }
        cout << "回到第二层" << endl;
    }

    cout << "回到第一层" << endl;
    return 0;
}
```

### 示例3：好的命名 vs 坏的命名
```cpp
#include <iostream>
using namespace std;

int main() {
    // ❌ 不好的命名：完全不知道这些变量是干什么的
    int a = 100;
    int b = 95;
    int c = 88;

    // ✅ 好的命名：看名字就知道是什么
    int mathScore = 100;    // 数学成绩
    int chineseScore = 95;  // 语文成绩
    int englishScore = 88;  // 英语成绩

    int totalScore = mathScore + chineseScore + englishScore;  // 总分

    cout << "数学成绩：" << mathScore << "分" << endl;
    cout << "语文成绩：" << chineseScore << "分" << endl;
    cout << "英语成绩：" << englishScore << "分" << endl;
    cout << "三门总分：" << totalScore << "分" << endl;

    return 0;
}
```

## 🎮 趣味练习

### 练习1：注释找茬
下面的程序有一个注释错误，你能找出来吗？

```cpp
#include <iostream>
using namespace std;

/* 这是一个多行注释
int main() {
    cout << "这段代码会被执行吗？" << endl;
    return 0;
}
*/  ← 缺少结束标记！
```

**参考答案：** 多行注释缺少结束标记 `*/`。正确的注释应该是：
```cpp
/* 这是一个多行注释
int main() {
    cout << "这段代码会被执行吗？" << endl;
    return 0;
} */
```

### 练习2：给代码"化妆"
下面这段代码没有缩进，看起来乱糟糟的。请你帮它加入正确的缩进，让它"变漂亮"：

```cpp
int main() {
cout << "第一层" << endl;
{
cout << "第二层" << endl;
{
cout << "第三层" << endl;
}
cout << "回到第二层" << endl;
}
return 0;
}
```

**参考答案：**
```cpp
int main() {
    cout << "第一层" << endl;
    {
        cout << "第二层" << endl;
        {
            cout << "第三层" << endl;
        }
        cout << "回到第二层" << endl;
    }
    return 0;
}
```

## 🏆 挑战任务

### 挑战：编写一个带完整注释的自我介绍程序

要求：
1. 在程序开头用多行注释写一段程序说明（程序名、作者、日期、功能）
2. 在关键代码处用单行注释说明每行代码的作用
3. 保持良好的缩进
4. 变量名有意义
5. 程序输出内容包含：姓名、年龄、最喜欢的一句话、三个科目的成绩和平均分

**参考示例：**
```cpp
/*
 * 程序名称：自我介绍
 * 作者：小明
 * 日期：2026年6月
 * 功能：输出个人介绍和成绩信息
 */

#include <iostream>
using namespace std;

int main() {
    // 个人信息
    string myName = "小明";          // 姓名
    int myAge = 10;                  // 年龄
    string favoriteQuote = "好好学习，天天向上";  // 最喜欢的名言

    // 成绩信息
    int math = 98;                   // 数学成绩
    int english = 95;                // 英语成绩
    int science = 93;                // 科学成绩

    // 计算平均分（总分除以科目数）
    double average = (math + english + science) / 3.0;

    // 输出自我介绍
    cout << "========== 自我介绍 ==========" << endl;
    cout << "大家好！" << endl;
    cout << "我叫" << myName << "，今年" << myAge << "岁。" << endl;
    cout << "我最喜欢的一句话是：「" << favoriteQuote << "」" << endl;
    cout << endl;
    cout << "========== 我的成绩 ==========" << endl;
    cout << "数学：" << math << "分" << endl;
    cout << "英语：" << english << "分" << endl;
    cout << "科学：" << science << "分" << endl;
    cout << "平均分：" << average << "分" << endl;

    return 0;  // 程序结束
}
```

## 📝 本课小结

| 知识点 | 说明 |
|--------|------|
| 单行注释 | `// 注释内容` —— 到行尾都是注释 |
| 多行注释 | `/* 注释内容 */` —— 适合长说明 |
| 注释的作用 | 给人看的"备忘条"，编译器会忽略 |
| 缩进 | 每进入花括号加一级缩进（4个空格），让代码有层次感 |
| 命名规则 | 用有意义的英文单词，驼峰式或下划线式 |

**记住这句口诀：**
> 双斜杠写单行，星号斜杠包多行；缩进对齐层次清，好名字让代码自己会说话！
