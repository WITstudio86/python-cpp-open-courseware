# 第41课：超级名片——结构体入门

## 学习目标

- 理解结构体(struct)的概念和作用
- 掌握struct的定义语法
- 学会访问和修改结构体成员
- 能够创建结构体变量并初始化

---

## 一、什么是结构体？

### 1.1 一个生活中的问题

同学们，假设老师现在要登记全班同学的信息。每个同学有：

- **姓名**（字符串）
- **年龄**（整数）
- **语文成绩**（小数）
- **数学成绩**（小数）
- **英语成绩**（小数）

如果只用我们之前学过的普通变量，一个同学就需要5个变量。全班40个同学，就需要 40 × 5 = 200 个变量！你能想象声明200个变量的代码有多长吗？

```cpp
string name1 = "小明";  int age1 = 12;  double chinese1 = 95.5;  double math1 = 90.0;  double english1 = 88.0;
string name2 = "小红";  int age2 = 11;  double chinese2 = 92.0;  double math2 = 96.5;  double english2 = 91.0;
// …… 写到第40个同学，手都酸了！
```

这就像你有5个不同的抽屉，分别放了5个同学的一样东西——钱放在第一个抽屉，照片放在第二个抽屉，太混乱了！我们需要的是一人一个**专属档案袋**，把属于这个人的所有资料都放在一起。

### 1.2 结构体就是"超级名片"

**结构体（struct）** 就是C++提供的一种"自定义数据类型"，它允许我们把**不同类型**的数据打包在一起，组成一个**整体**。

把它想象成一张**超级名片**：

> 一张普通名片上包含：姓名、电话、公司  
> 一张"超级名片"可以包含：姓名、年龄、成绩、地址、兴趣爱好……

所有跟这个人有关的资料，都印在同一张名片上，用一个变量就能管理所有信息！

### 1.3 为什么需要结构体？

| 没有结构体 | 有了结构体 |
|---|---|
| 一个学生的信息分散在多个独立变量中 | 一个学生的所有信息打包在一个变量里 |
| 不容易看出变量之间的关联 | 一眼就能看出哪些信息属于同一个人 |
| 修改和传递很麻烦（要传一堆参数） | 只需传一个结构体变量就够了 |
| 数据容易搞混、写错 | 数据组织清晰，不容易出错 |

结构体让我们的代码更加**有组织、易读、易维护**，是通往高级编程的重要一步。

## 二、结构体的定义语法

C++中定义结构体使用 `struct` 关键字，基本格式如下：

```cpp
struct 结构体名称 {
    数据类型 成员1;
    数据类型 成员2;
    数据类型 成员3;
    // ……可以有任意多个成员
};  // 注意：这里必须加分号！
```

让我们来看一个具体的例子——定义一个"学生"结构体：

```cpp
struct Student {
    string name;      // 姓名
    int age;          // 年龄
    double score;     // 成绩
};  // 分号不能忘！
```

**语法要点：**

1. `struct` 是关键字，告诉编译器我们要定义一个结构体。
2. `Student` 是我们给这个结构体起的名字（可以自定义，习惯上用大写开头）。
3. 花括号 `{}` 里面列出所有**成员变量**，每个成员都要声明数据类型。
4. **末尾的分号 `;` 非常重要！** 这是新手最容易忘记的地方。
5. 结构体定义通常放在 `main()` 函数之前，或者放在头文件中。

### 常用结构体命名

| 结构体名 | 含义 | 典型成员 |
|---|---|---|
| Student | 学生 | name, age, score |
| Book | 图书 | title, author, price |
| Point | 坐标点 | x, y |
| Pet | 宠物 | name, type, age |
| Car | 汽车 | brand, speed, price |

## 三、创建结构体变量

定义好结构体之后，它就像一个新的数据类型（类似 `int`、`double`），我们可以用它来声明变量：

```cpp
// 方式1：先定义结构体，再声明变量
struct Student {
    string name;
    int age;
    double score;
};

Student s1;          // 创建一个Student类型的变量s1
Student s2;          // 再创建一个变量s2

// 方式2：定义结构体的同时声明变量
struct Student {
    string name;
    int age;
    double score;
} s1, s2;            // 直接在花括号后面声明变量
```

在C++中，声明变量时前面的 `struct` 关键字可以省略。所以 `Student s1;` 和 `struct Student s1;` 效果完全相同。

---

## 四、访问成员——点运算符 `.`

创建结构体变量后，如何读写里面的成员呢？C++使用**点运算符** `.` 来访问：

```cpp
Student s1;              // 创建一个学生变量

s1.name = "小明";         // 用 . 访问name成员，赋值
s1.age = 12;             // 用 . 访问age成员，赋值
s1.score = 95.5;         // 用 . 访问score成员，赋值

// 读取成员的值
cout << s1.name << endl;  // 输出：小明
cout << s1.age << endl;   // 输出：12
cout << s1.score << endl; // 输出：95.5
```

**点运算符记忆口诀：**  
> "变量名点成员名"——就像用 `.` 这把钥匙打开结构体这个"百宝箱"，取出里面的宝贝。

---

## 五、结构体初始化

创建结构体变量时，我们可以直接给它赋初值：

```cpp
// 方式1：使用花括号初始化（按成员定义顺序）
Student s1 = {"小明", 12, 95.5};

// 方式2：先声明再逐个赋值
Student s2;
s2.name = "小红";
s2.age = 11;
s2.score = 92.0;

// 方式3：使用另一个结构体变量初始化（复制）
Student s3 = s1;    // s3 的所有成员和 s1 相同
```

**注意：** 花括号初始化的顺序必须和结构体定义中成员的顺序一致！

---

## 六、结构体赋值

相同类型的结构体变量之间可以直接赋值：

```cpp
Student s1 = {"小明", 12, 95.5};
Student s2;

s2 = s1;  // 把 s1 的所有成员值复制给 s2

cout << s2.name << endl;   // 输出：小明
cout << s2.age << endl;    // 输出：12
cout << s2.score << endl;  // 输出：95.5
```

这比一个一个成员复制方便多了！这也是结构体的一个重要优势——**整体操作**。

## 八、完整示例代码

### 示例1：学生信息卡

```cpp
#include <iostream>
#include <string>
using namespace std;

// 定义学生结构体
struct Student {
    string name;      // 姓名
    int age;          // 年龄
    double score;     // 成绩
};

int main() {
    // 创建并初始化一个学生
    Student s1 = {"小明", 12, 95.5};
    
    // 输出学生信息
    cout << "========== 学生信息卡 ==========" << endl;
    cout << "姓名：" << s1.name << endl;
    cout << "年龄：" << s1.age << " 岁" << endl;
    cout << "成绩：" << s1.score << " 分" << endl;
    
    // 修改成绩
    s1.score = 98.0;
    cout << "更新后的成绩：" << s1.score << " 分" << endl;
    
    // 创建一个副本
    Student s2 = s1;
    s2.name = "小明副本";
    cout << "副本姓名：" << s2.name << endl;
    cout << "原姓名：" << s1.name << endl;
    
    return 0;
}
```

**运行结果：**
```
========== 学生信息卡 ==========
姓名：小明
年龄：12 岁
成绩：95.5 分
更新后的成绩：98 分
副本姓名：小明副本
原姓名：小明
```

### 示例2：图书信息管理

```cpp
#include <iostream>
#include <string>
#include <iomanip>
using namespace std;

// 定义图书结构体
struct Book {
    string title;     // 书名
    string author;    // 作者
    double price;     // 价格
};

int main() {
    // 创建三本图书
    Book book1 = {"小王子", "圣埃克苏佩里", 29.90};
    Book book2 = {"西游记", "吴承恩", 45.00};
    Book book3 = {"哈利·波特与魔法石", "J.K.罗琳", 39.50};
    
    // 打印图书列表
    cout << "========== 图书信息管理系统 ==========" << endl;
    cout << fixed << setprecision(2);
    cout << "书名\t\t\t作者\t\t价格" << endl;
    cout << "-------------------------------------------------" << endl;
    cout << book1.title << "\t\t" << book1.author << "\t" << book1.price << " 元" << endl;
    cout << book2.title << "\t\t\t" << book2.author << "\t\t" << book2.price << " 元" << endl;
    cout << book3.title << "\t" << book3.author << "\t\t" << book3.price << " 元" << endl;
    
    // 计算总价
    double total = book1.price + book2.price + book3.price;
    cout << "-------------------------------------------------" << endl;
    cout << "合计：" << total << " 元" << endl;
    
    // 打折促销
    book1.price = book1.price * 0.8;  // 打8折
    cout << book1.title << " 打折后：" << book1.price << " 元" << endl;
    
    return 0;
}
```

### 练习2：商品信息管理（中等）

1. 定义一个 `Product` 结构体，包含：商品名（name）、价格（price）、库存数量（quantity）
2. 创建两个商品，分别初始化为："铅笔"（2.5元，库存100支）和"橡皮"（1.5元，库存80块）
3. 计算并输出所有商品的总价值（价格 × 库存 之和）

**参考答案：**

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Product {
    string name;
    double price;
    int quantity;
};

int main() {
    Product p1 = {"铅笔", 2.5, 100};
    Product p2 = {"橡皮", 1.5, 80};
    
    double total1 = p1.price * p1.quantity;
    double total2 = p2.price * p2.quantity;
    double grandTotal = total1 + total2;
    
    cout << "商品1：" << p1.name << "，总价值：" << total1 << " 元" << endl;
    cout << "商品2：" << p2.name << "，总价值：" << total2 << " 元" << endl;
    cout << "所有商品总价值：" << grandTotal << " 元" << endl;
    
    return 0;
}
```

### 练习3：结构体之间的复制（简单）

阅读下面的代码，写出程序的输出结果。

```cpp
struct Point {
    int x;
    int y;
};

int main() {
    Point p1 = {3, 5};
    Point p2 = p1;
    p2.x = 10;
    p2.y = 20;
    
    cout << "p1: (" << p1.x << ", " << p1.y << ")" << endl;
    cout << "p2: (" << p2.x << ", " << p2.y << ")" << endl;
    
    return 0;
}
```

**答案：**
```
p1: (3, 5)
p2: (10, 20)
```

**解析：** 结构体赋值是**值复制**——`p2 = p1` 把 `p1` 所有的值复制给了 `p2`，之后修改 `p2` 不会影响 `p1`。它们各自独立，就像把一张名片的复印件给了别人，别人在复印件上修改不会影响原件。
