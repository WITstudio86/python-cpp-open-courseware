# 第39课：变量的小天地——作用域

> 🏠 变量的家在哪里？每个变量都有自己专属的"房间"，只在特定的范围内才能被访问哦！

## 二、知识讲解

### 2.1 变量的"家"——作用域是什么？

想象你住在一栋大房子里，房子里有很多房间：客厅、厨房、卧室、书房。当你站在客厅里，你能看见客厅里的家具；但你看不见卧室里的台灯，也看不见厨房里的冰箱——因为它们在别的房间里。

**变量的作用域（Scope）** 就是这个道理。程序就像一栋大楼，函数、代码块就像不同的房间。变量定义在哪个"房间"里，就只能在哪个"房间"里使用。出了这个房间，变量就"看不见"啦！

在 C++ 中，括号 `{ }` 就是"墙壁"——它们围起来的地方就是一个作用域。外面的代码看不到里面的变量，就像隔壁邻居看不到你房间里的玩具一样。

### 2.2 全局变量——住在"大客厅"的变量

**全局变量**定义在所有函数的外面，通常写在文件最上方、`#include` 之后。整个程序的所有函数都能访问它，就像大客厅里的电视，家里每个人都能用。

```cpp
#include <iostream>
using namespace std;

int score = 100;  // 全局变量，住在"大客厅"

void showScore() {
    cout << "当前分数：" << score << endl;  // 可以直接用！
}

int main() {
    cout << "初始分数：" << score << endl;
    score = score + 50;
    showScore();
    return 0;
}
```

全局变量的特点：
- 定义在所有函数外面
- 整个程序任何地方都能看到它
- 程序一开始运行它就"出生"，程序结束它才"消失"
- 如果不手动赋初值，自动初始化为 0

### 2.3 局部变量——住在"小房间"的变量

**局部变量**定义在某个函数或代码块的内部（也就是一对 `{ }` 里面）。它只在自己的"房间"里有效，外面的代码看不到它。

```cpp
#include <iostream>
using namespace std;

int main() {
    int x = 10;  // 局部变量，只在 main() 里有效
    
    {
        int y = 20;  // 局部变量，只在这个内层 {} 里有效
        cout << "在内层：x = " << x << ", y = " << y << endl;
    }
    // cout << y;  // 错误！y 已经"出房间"了，看不见了！
    
    cout << "在外层：x = " << x << endl;
    return 0;
}
```

局部变量的特点：
- 定义在函数或代码块内部
- 只在自己的代码块里可见
- 进入代码块时"出生"，离开代码块时"消失"
- 必须手动赋初值，否则是随机值

### 2.4 名字遮盖——同名变量谁说了算？

如果在客厅放了一个闹钟，又在卧室放了一个也叫"闹钟"的东西，当你在卧室时，你看到的是卧室的闹钟，客厅的那个被"遮盖"了。

C++ 里也一样：**当局部变量和全局变量同名时，局部变量会"遮盖"全局变量。**

```cpp
#include <iostream>
using namespace std;

int gold = 100;  // 全局变量：金库里的金币

int main() {
    int gold = 50;  // 局部变量：口袋里的金币（遮盖了全局的！）
    
    cout << "gold = " << gold << endl;  // 输出 50，不是 100！
    return 0;
}
```

### 2.5 生命周期——变量的"生老病死"

| 变量类型 | 什么时候出生 | 什么时候消失 | 内存位置 |
|---------|------------|------------|---------|
| 全局变量 | 程序开始运行 | 程序结束 | 静态存储区 |
| 局部变量 | 进入代码块时 | 离开代码块时 | 栈（Stack） |

用房间的比喻：全局变量是房子的地基，从房子盖好（程序启动）到拆掉（程序结束）一直存在；局部变量像是你搭的积木，你进屋开始搭，出门就自己倒了。

### 2.6 作用域级别对照表

| 属性 | 全局变量 | 局部变量 |
|------|---------|---------|
| 定义位置 | 所有函数外面 | 函数 / 代码块内部 |
| 可见范围 | 整个程序 | 定义它的代码块内 |
| 生命周期 | 程序启动→结束 | 进入块→离开块 |
| 默认初值 | 自动为 0 | 随机值（垃圾值） |
| 能否被遮盖 | 能被同名局部变量遮盖 | 不能被外层同名变量遮盖（它自己就是"遮盖者"） |

## 三、代码示例

### 示例 1：探索变量的家

```cpp
#include <iostream>
using namespace std;

// === 全局变量——住在大门外的花园里 ===
string gardenName = "阳光花园";     // 整个程序都能看到
int houseNumber = 39;               // 门牌号，所有人都知道

// === 函数：客厅 ===
void livingRoom() {
    string sofa = "蓝色沙发";       // 局部变量，只在客厅里
    cout << "【客厅】" << endl;
    cout << "  花园名：" << gardenName << " ✅（能看到花园）" << endl;
    cout << "  沙发：" << sofa << " ✅" << endl;
    cout << "  门牌号：" << houseNumber << " ✅" << endl;
    // cout << bed;  // ❌ 看不到卧室的床！
}

// === 函数：卧室 ===
void bedroom() {
    string bed = "双人床";          // 局部变量，只在卧室里
    cout << "【卧室】" << endl;
    cout << "  花园名：" << gardenName << " ✅（能看到花园）" << endl;
    cout << "  床：" << bed << " ✅" << endl;
    // cout << sofa;  // ❌ 看不到客厅的沙发！
}

int main() {
    cout << "🏠 欢迎来到第 " << houseNumber << " 号，" << gardenName << "！\n" << endl;
    
    livingRoom();
    cout << endl;
    bedroom();
    
    cout << "\n在院子里大喊：门牌号是 " << houseNumber << "！" << endl;
    // cout << sofa;  // ❌ 院子也看不到客厅的沙发！
    
    return 0;
}
```

### 示例 2：名字遮盖实验

```cpp
#include <iostream>
using namespace std;

int light = 1;  // 全局：屋外的路灯

void kitchen() {
    int light = 2;  // 局部：厨房的灯（遮盖了路灯！）
    
    cout << "在厨房里，light = " << light << endl;
    cout << "  看到的编号是 2（厨房的灯，不是路灯）" << endl;
}

void study() {
    // 这里没有定义 light，所以看到的是全局的
    cout << "在书房里，light = " << light << endl;
    cout << "  看到的编号是 1（路灯——因为书房没开灯）" << endl;
}

int main() {
    cout << "在院子里，light = " << light << endl;  // 1——路灯
    cout << endl;
    
    kitchen();
    cout << endl;
    
    study();
    cout << endl;
    
    // 再次确认：全局 light 没有被改变
    cout << "回到院子，light 还是 = " << light << endl;
    
    return 0;
}
```

## 四、课堂练习

### 练习 1：猜输出

阅读下面的代码，写出程序的输出结果：

```cpp
#include <iostream>
using namespace std;

int a = 5;

void testA() {
    int a = 10;
    cout << "A: " << a << endl;
}

void testB() {
    cout << "B: " << a << endl;
}

int main() {
    testA();
    testB();
    cout << "M: " << a << endl;
    return 0;
}
```

<details>
<summary>点击查看答案</summary>

**输出结果：**
```
A: 10
B: 5
M: 5
```

**解析：**
- `testA()` 内部定义了一个局部变量 `a = 10`，遮盖了全局的 `a = 5`，所以输出 10
- `testB()` 内部没有定义 `a`，所以使用的是全局的 `a = 5`
- `main()` 里也没有定义 `a`，同样使用全局的 `a = 5`

</details>

### 练习 2：找错误

下面的代码有错误吗？如果有，错在哪里？

```cpp
#include <iostream>
using namespace std;

int main() {
    {
        int secret = 42;
    }
    cout << secret << endl;   // 能正确输出 42 吗？
    return 0;
}
```

<details>
<summary>点击查看答案</summary>

**有错误！**

代码中 `secret` 定义在内层代码块 `{ }` 里面。当程序执行完 `}` 后，`secret` 就"消失"了（生命周期结束）。所以外面的 `cout << secret` 找不到这个变量，**编译会报错**：`'secret' was not declared in this scope`。

正确的做法是：要么把 `cout` 也放在代码块里，要么把 `secret` 的定义移到代码块外面。

</details>

### 练习 3：作用域判断

阅读下面的代码，判断哪些地方的 `cout` 语句是正确的，哪些会报错：

```cpp
#include <iostream>
using namespace std;

int money = 1000;

void saveMoney() {
    int piggyBank = 50;
    cout << "存钱罐：" << piggyBank << " 元" << endl;   // ① 正确吗？
    cout << "总资产：" << money << " 元" << endl;        // ② 正确吗？
}

int main() {
    cout << "总资产：" << money << " 元" << endl;        // ③ 正确吗？
    // cout << "存钱罐：" << piggyBank << " 元" << endl;  // ④ 正确吗？
    return 0;
}
```

<details>
<summary>点击查看答案</summary>

- ① ✅ 正确。`piggyBank` 和 `cout` 都在 `saveMoney()` 函数内部。
- ② ✅ 正确。`money` 是全局变量，任何函数都能访问。
- ③ ✅ 正确。同理，全局变量在任何函数中都可以使用。
- ④ ❌ 错误。`piggyBank` 是 `saveMoney()` 里的局部变量，`main()` 里看不到它。

</details>

## 五、挑战任务 🏆

### 任务：设计你的"变量之家"

请编写一个完整的 C++ 程序，实现以下要求：

1. 定义一个全局变量 `int totalGuests = 0;`（来访总人数）
2. 定义三个函数，分别代表"客厅"、"厨房"、"卧室"
3. 每个函数内部定义一个局部变量，表示该房间的"访客人数"（不同值）
4. 每个函数都将自己的访客人数加到全局变量 `totalGuests` 上
5. 在 `main()` 中依次调用这三个函数
6. 最后输出总访客人数

**提示：** 客厅来了 5 人、厨房 3 人、卧室 2 人，期待输出 `totalGuests` 最终为 10。

<details>
<summary>点击查看参考代码</summary>

```cpp
#include <iostream>
using namespace std;

int totalGuests = 0;  // 全局变量：来访总人数

void livingRoom() {
    int guests = 5;   // 局部变量：客厅访客
    totalGuests += guests;
    cout << "客厅来了 " << guests << " 位客人" << endl;
}

void kitchen() {
    int guests = 3;   // 局部变量：厨房访客
    totalGuests += guests;
    cout << "厨房来了 " << guests << " 位客人" << endl;
}

void bedroom() {
    int guests = 2;   // 局部变量：卧室访客
    totalGuests += guests;
    cout << "卧室来了 " << guests << " 位客人" << endl;
}

int main() {
    cout << "🏠 欢迎光临！\n" << endl;
    livingRoom();
    kitchen();
    bedroom();
    cout << "\n📊 全屋总共来了 " << totalGuests << " 位客人！" << endl;
    return 0;
}
```

</details>

## 六、本课小结

今天我们学习了变量作用域的知识：

| 概念 | 一句话解释 |
|------|----------|
| **局部变量** | 定义在 `{ }` 里面，只在这个"房间"里能用 |
| **全局变量** | 定义在所有函数外面，整个程序都能用 |
| **作用域** | 变量"能被看见"的代码范围 |
| **生命周期** | 变量从"出生"到"消失"的这段时间 |
| **名字遮盖** | 局部变量和全局变量同名时，局部变量"挡住"全局变量 |

**记忆口诀：**
> 全局是客厅大家用，局部是房间自己管。
> 同名变量有规矩，就近原则它优先。
> 人走茶凉变量散，生命周期记心间。

理解作用域是写好程序的基础。就像整理房间一样，把变量的"活动范围"安排清楚，程序才不会乱糟糟的。下一课我们将学习更多有关变量作用域的高级用法，敬请期待！
