01 DP 核心概念

最优子结构

问题的最优解可由子问题的最优解组合而成。大问题的最优策略，建立在子问题最优策略的基础之上。

无后效性

未来与过去无关，状态一旦确定则不受之前决策影响。每一个状态都是过去历史的一个完整总结。

重叠子问题

不同路径到达相同的子问题，通过记忆化（Memoization）避免重复计算，将指数级复杂度降至多项式级别。

02 LIS 问题与 O(n²) DP

LIS 定义

给定一个长度为 n 的序列 a[0..n-1]，求其最长严格递增子序列（Longest Increasing Subsequence）的长度。

例如：a = [3, 1, 4, 1, 5, 9, 2, 6]，LIS = [1, 4, 5, 9] 或 [1, 4, 5, 6]，长度为 4。

状态定义

dp[i] = 以 a[i] 结尾的最长上升子序列长度

转移方程

dp[i] = max(dp[j] + 1)
 for j < i and a[j] < a[i]
C++ — O(n²) 实现 O(n²) 时间 | O(n) 空间 
int lis_n2(const vector<int>& a) {
    int n = a.size();
    vector<int> dp(n, 1);
    int ans = 1;
    for (int i = 1; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            if (a[j] < a[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }
    return ans;
}

时间复杂度 O(n²)，空间复杂度 O(n)，适用于 n ≤ 5000 的数据范围。

03 O(n log n) 优化 — 贪心 + 二分

核心思想

维护 tails 数组：tails[k] = 长度为 k+1 的上升子序列的 最小末尾元素。

贪心性质：末尾元素越小，后续元素越容易接上，从而能构造出更长的子序列。

算法流程

  1. 初始化 tails 为空数组
  2. 遍历每个元素 x：
  3. 在 tails 中二分查找 第一个 ≥ x 的位置 pos
  4. 若找到了则 tails[pos] = x（替换），否则 tails.push_back(x)（追加）
  5. 最终 tails.size() 即为 LIS 长度
C++ — O(n log n) 实现 O(n log n) 时间 | O(n) 空间 
int lis_nlogn(const vector<int>& a) {
    vector<int> tails;  // tails[k] = 长度为k+1的LIS的最小末尾
    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) {
            tails.push_back(x);  // 所有末尾都小于x，扩展长度
        } else {
            *it = x;  // 替换第一个≥x的位置，保持贪心最优
        }
    }
    return tails.size();
}

严格 vs 非严格

严格上升：用 lower_bound（第一个 ≥ x）

非严格上升：用 upper_bound（第一个 > x）

Dilworth 定理

偏序集中，最长链长度 = 最少反链覆盖数。

在 LIS 中：最长上升子序列长度 = 最少不上升子序列覆盖数

04 真题精练 — 经典考题分析

真题 1：导弹拦截 — NOIP 1999

题目大意：给定导弹高度序列，一套拦截系统每次拦截的导弹高度必须不高于前一次。问最多能拦截多少导弹？最少需要多少套系统？

➔ 第一问：最长不上升子序列长度。用 O(n²) DP 或 O(n log n) 贪心（upper_bound，因为等号允许）。

➔ 第二问：最少系统数 = 最长上升子序列长度（Dilworth 定理的直接应用）。

真题 2：合唱队形 — NOIP 2004

题目大意：N 位同学排成一列，要求中间高两边低（严格先上升后下降），问最少需要几位同学出列。

➔ 双向 LIS：

left[i] = 从左到右以 i 结尾的 LIS 长度

right[i] = 从右到左以 i 结尾的 LIS 长度

答案 = N - max(left[i] + right[i] - 1)

解题关键总结

  • 导弹拦截是 Dilworth 定理 的模板题，CSP-S 高频考点
  • 合唱队形体现了 双向 DP 的经典思路，将问题拆解为两个反向的 LIS
  • 路径还原：在 DP 过程中维护 pre[] 数组记录前驱，从最优尾结点回溯即可得到完整的 LIS 序列
