朴素 Dijkstra — O(V²)

适合稠密图（V ≤ 1000, E ≈ V²），配合邻接矩阵使用。

算法流程

  1. 初始化：dist[s]=0，其余 dist = INF，vis 全 false
  2. 重复 V 轮：从未确定顶点中选出 dist 最小的 u
  3. 将 u 标记为「已确定」：vis[u] = true
  4. 用 u 松弛所有邻接点 v：dist[v] = min(dist[v], dist[u] + w(u,v))

代码框架

for (int i = 1; i <= n; i++) { // 1. 找最小 dist 的未确定顶点 int u = -1; for (int j = 1; j <= n; j++) if (!vis[j] && (u == -1 || dist[j] < dist[u])) u = j; if (u == -1) break; vis[u] = true; // 2. 松弛邻接点 for (int v = 1; v <= n; v++) if (!vis[v] && g[u][v] != INF) dist[v] = min(dist[v], dist[u] + g[u][v]); }

松弛邻接点O(V) 全扫描
总复杂度O(V²)

堆优化 Dijkstra — O(E log V)

适合稀疏图（V ≤ 10⁵），配合邻接表使用。这是 CSP-S 最常用版本。

核心改进

朴素版的瓶颈是「找最小 dist」。用优先队列（小根堆）代替暴力扫描。

完整代码

priority_queue<pair<int,int>, vector<...>, greater<>> pq; pq.push({0, s}); while (!pq.empty()) { auto [d, u] = pq.top(); pq.pop(); if (vis[u]) continue; // ← 「懒删除」 vis[u] = true; for (auto [v, w] : g[u]) { if (dist[v] > dist[u] + w) { dist[v] = dist[u] + w; pq.push({dist[v], v}); } } }

操作复杂度说明
每个顶点出队O(log V)最多 V 次
每次松弛入堆O(log V)最多 E 次
总复杂度O((V+E) log V)简记 O(E log V)

贪心正确性证明

定理（Dijkstra 正确性）

在边权非负的图中，每次选中 dist 最小的未确定顶点时，其 dist 值等于该顶点的真正最短距离。

反证法证明

设当前选中 u，假设存在比 dist[u] 更短的真实路径 P。

P 必然在某个点首次离开「已确定集合 S」：设该点为 x ∈ S，下一个点为 y ∉ S。

len(P) ≥ dist[x] + w(x,y) // P 经 x→y 到达 y ≥ dist[y] // dist[y] 可能已被 x 更新过，即 dist[y] ≤ dist[x]+w(x,y) ≥ dist[u] // 因为算法选了 dist 最小的 u，而非 y 因此 len(P) ≥ dist[u]，矛盾 ∎

为什么负权边不可用？

❌ 关键矛盾：若有负权边，经过更多边的路径可能反而更短！
dist[u] 最小时，其他未确定顶点可能通过负权边让路径缩短，贪心性质被破坏。

反例：三角形 A→B(2), B→C(-3), A→C(1)。Dijkstra 先确定 dist[C]=1（错），实际 A→B→C = -1。

图类型可用算法
非负权Dijkstra O(E log V)
含负权边Bellman-Ford O(VE) / SPFA
含负环Bellman-Ford 检测负环
全源最短（含负）Floyd O(V³) 或 Johnson O(VE log V)

代码模板 & 路径还原

模板：堆优化 Dijkstra

int dist[MAXN], pre[MAXN]; bool vis[MAXN]; void dijkstra(int s) { memset(dist, 0x3f, sizeof(dist)); dist[s] = 0; priority_queue<...> pq; pq.push({0, s}); while (!pq.empty()) { auto [d, u] = pq.top(); pq.pop(); if (vis[u]) continue; vis[u] = true; for (auto [v, w] : g[u]) { if (dist[v] > dist[u] + w) { dist[v] = dist[u] + w; pre[v] = u; // ← 记录前驱，用于路径还原 pq.push({dist[v], v}); } } } }

路径还原

// 还原 s → t 的最短路径 vector<int> get_path(int s, int t) { vector<int> path; if (dist[t] == INF) return path; // 不可达 for (int v = t; v != -1; v = pre[v]) path.push_back(v); reverse(path.begin(), path.end()); return path; }

真题精练

题1：单源最短路径（标准模板）

n ≤ 10⁵, m ≤ 2×10⁵，w ≤ 10⁹，有向图，求 s 到所有顶点的最短距离。不可达输出 -1。

注意：边权可达 10⁹，dist 用 long long，INF 用 1e18。

题2：最短路径 + 路径还原

给定 s 和 t，输出 s 到 t 的最短距离，以及完整的路径序列。若不可达输出 -1。

常考变式：

  • 输出路径上的顶点序列（需 pre[] 回溯）
  • 统计最短路径的条数（需 cnt[] 累加）
  • 次短路径（维护两个 dist 数组）
  • K 短路（A* 算法）

易错点与技巧总结

常见错误原因解决方案
priority_queue 是大根堆默认 less<> 是最大堆用 greater<pair>
vis 标记时机错在 push 时就标 vis在 pop 后才标 vis（懒删除）
INF 溢出INT_MAX + 正数 溢出用 0x3f3f3f3f 或 1e18
重边导致错误多条 (u,v) 取错权值根据题意取 min 或保留
无向图漏反向边只加了单向边g[u].push({v,w}); g[v].push({u,w})
负权边用 DijkstraDijkstra 不适用负权图换用 SPFA / Bellman-Ford
memset 给 long longmemset 按字节填充用 fill / for 循环 / 手动赋值

核心技巧清单

  • 0x3f3f3f3f 技巧：memset 按字节填充，int 值为 10⁶⁷，两倍相加不溢出，常用于 dist 初始化
  • 懒删除：不做 decrease-key，旧记录在 pop 时跳过，代码量减半
  • 稠密图用朴素：V ≤ 1000 时 O(n²) 往往比堆优化快
  • 多源最短路径：建超级源点，向各个起点连 0 权边，一次 Dijkstra
  • 路径记录：松弛时 pre[v] = u，终点回溯即可
  • 边权很大时：dist 换 long long，INF 换 1e18
