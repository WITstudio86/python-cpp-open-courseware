多重背包问题定义

问题描述

有 n 种物品和一个容量为 V 的背包。

第 i 种物品最多有 c[i] 件可用，每件重量 w[i]，价值 v[i]。

求在不超过容量的前提下，能获得的最大总价值。

朴素做法 O(V · Σc[i])

将每种物品拆成 c[i] 个单独物品，转化为 01 背包：

for (int i = 1; i <= n; i++)
    for (int j = V; j >= w[i]; j--)
        for (int k = 0; k <= c[i] && k*w[i] <= j; k++)
            dp[j] = max(dp[j], dp[j - k*w[i]] + k*v[i]);
问题：当 Σc[i] 很大（如 c[i] 可达 105）时， 时间复杂度 O(V · Σc[i]) 会严重超时，必须优化。

优化方向

  • 二进制拆分优化：O(V · Σ log c[i])，实现简单
  • 单调队列优化：O(V · n)，理论最优

二进制拆分优化

核心思想

将 c[i] 拆为若干"打包物品"，使它们能组合出 0 ~ c[i] 之间的任意整数。

拆分方法

c[i] = 2⁰ + 2¹ + 2² + ... + 2ᵏ + r

其中 2k+1 - 1 ≤ c[i]，余数 r = c[i] - (2k+1 - 1)

示例：c[i] = 13

步k打包重量打包价值剩余
11wv12
222w2v10
344w4v6
4余数6w6v0

拆分结果：1件、2件、4件、6件打包 → 共 4 个 01 背包物品

验证：选 11 件 = 1+4+6 ✓ | 选 7 件 = 1+2+4 ✓

复杂度

O(V · Σ log c[i])

拆分后物品数 ≈ Σ ⌈log₂(c[i]+1)⌉，远小于 Σc[i]

单调队列优化原理

状态转移分析

dp[j] = max{ dp[j - k·w] + k·v }   (0 ≤ k ≤ c, k·w ≤ j)

同余分组

令 r = j mod w，则同组容量为：r, r+w, r+2w, r+3w, ...

组内状态转移只依赖同组前面的状态，各组独立计算。

滑动窗口 + 单调队列

设 j = r + x·w，候选值：

candidate[t] = g[r + t·w] − t·v

则：

dp[r + x·w] = max{ candidate[t] } + x·v

其中 t ∈ [x−c, x]，g[] 为上一轮 dp 状态

队列操作

  • 入队：将新 candidate[x] 入队前，弹出队尾所有 ≤ 它的元素（维护递减）
  • 出队：队首下标 < x−c 时弹出（窗口滑动，超出范围）
  • 取值：队首即窗口内最大值，dp[j] = candidate[队首] + x·v
复杂度 O(V·n)：每个容量被每个物品处理常数次（入队/出队各至多一次）

分组背包

问题定义

有 n 组物品，每组最多选一件（也可不选）。求最大价值。

标准代码（三层循环）

for (int i = 0; i < n; i++)              // 外层：枚举组
    for (int j = V; j >= 0; j--)          // 中层：容量逆序 V→0
        for (auto& item : group[i])      // 内层：组内物品
            if (j >= item.w)
                dp[j] = max(dp[j], dp[j - item.w] + item.v);

为什么中层必须逆序？

如果 正序（j=0→V）：物品 k 更新 dp[j] 后， 更大的 j' 可能再次使用同组物品（dp[j' - w[k']] 已含物品 k）， 导致同组选多件，违反约束。

逆序（j=V→0）：dp[j - w[k]] 尚未被当前组更新， 保证每组最多选一件。

类比理解

内层循环本质是 同组物品间的"竞争"——在同一个容量 j 上， 多个物品各自尝试更新 dp[j]，最终只有一个能"占领"该状态。

四种背包对比总结

背包类型 物品限制 容量循环方向 时间复杂度 空间
01背包 每种最多选1次 逆序 V→0 O(V·n) O(V)
完全背包 每种可选无限次 正序 0→V O(V·n) O(V)
多重背包 第 i 种最多 c[i] 件 逆序（拆分后） O(V·Σlog c[i]) 二进制
O(V·n) 单调队列		 O(V)
分组背包 每组最多选1件 逆序 V→0 O(V·Σsize[i]) O(V)

记忆口诀

「01 逆，完全正，分组外层组中层逆，多重拆了再 01」

  • 逆序 → 保证每个物品只用一次（依赖上一轮状态）
  • 正序 → 允许物品多次使用（依赖本轮已更新状态）

循环顺序对比

// 01背包：外层物品，内层逆序容量
for(i) for(j=V..w) dp[j]=max(dp[j], dp[j-w]+v);

// 完全背包：外层物品，内层正序容量
for(i) for(j=w..V) dp[j]=max(dp[j], dp[j-w]+v);

// 分组背包：外层组，中层逆序容量，内层组内物品
for(组) for(j=V..0) for(k in 组) dp[j]=max(dp[j], dp[j-w[k]]+v[k]);

真题精练

题1：宝物筛选（多重背包）

来源：Luogu P1776 | N ≤ 100, V ≤ 40000, c[i] ≤ 100

N 种宝物，容量 V，每种有重量 w、价值 v、数量 c，求最大价值。

解法：二进制拆分 → 01背包。O(V · N · log c) ≈ 2.8×10⁷

核心技巧：拆分时不漏余数 r，c·w ≥ V 时转完全背包剪枝。

// 二进制拆分核心
for (int k = 1; k <= cnt; k <<= 1) {
    goods.push_back({w * k, v * k});
    cnt -= k;
}
if (cnt > 0) goods.push_back({w * cnt, v * cnt});

题2：选拔队员（分组背包）

N 个班级，预算 V，每班若干候选人（费用 w, 能力 v），每班最多选1人。

解法：标准分组背包。O(N · V · m) ≈ 10⁷

关键：中层容量必须逆序，保证同组最多选一件。

for (int i = 0; i < n; i++)           // 每组
    for (int j = V; j >= 0; j--)       // 逆序容量
        for (auto& [w, v] : group[i])  // 组内竞争
            if (j >= w) dp[j] = max(dp[j], dp[j - w] + v);

本课小结

核心要点回顾

  1. 多重背包是 01 背包的推广，每种物品有数量限制 c[i]
  2. 二进制拆分优化：将 c[i] 拆为 1, 2, 4, …, 2ᵏ, r， 转化为 O(log c[i]) 个 01 背包物品，复杂度 O(V · Σ log c[i])
  3. 单调队列优化：同余分组 + 滑动窗口， 复杂度 O(V·n)，理论最优但实现较复杂， 注意 −t·v 和 +x·v 偏移量
  4. 分组背包：每组最多选一件， 关键特征：容量必须逆序！

循环方向规律

背包类型循环方向原因
01背包逆序 V→0保证每件只用一次
完全背包正序 0→V允许无限次使用
分组背包逆序 V→0保证每组最多一件
多重背包逆序（拆分后做01）拆后等价于01背包

易错提醒

  • 二进制拆分：不能漏掉余数 r（cnt > 0 时的处理）
  • 分组背包：中层容量必须逆序，防止同组多选
  • 单调队列：注意 candidate 的 −t·v 偏移和最后 +x·v 回补
  • 可行剪枝：c·w ≥ V 时可转为完全背包处理

掌握循环方向规律，灵活运用优化策略，轻松应对背包变种问题！
