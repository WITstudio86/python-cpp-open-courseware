第 26 课

LCS（最长公共子序列）与编辑距离

字符串 DP 经典问题
滚动数组优化 序列比对 区间 DP 拓展
适用于 CSP-S / NOIP 提高组
算法竞赛进阶 · 动态规划专题

LCS 问题定义

LCS：Longest Common Subsequence，最长公共子序列

子序列：不要求连续，但要求保持原序列中的相对顺序。

对于一个长度为 n 的序列，其子序列共有 2ⁿ 个。

示例

// 两个字符串
s1 = "ABCBDAB"
s2 = "BDCABA"

// LCS = "BCBA" 或 "BDAB"，长度 = 4
//   B   C   B   A   （非连续出现）

子序列 vs 子串

要求连续？保持顺序？示例（s="abc"）
子序列否是"a", "ac", "b", "abc" ...
子串是是"a", "ab", "abc", "bc" ...

实际应用

LCS 是许多字符串问题的核心基础：

  • diff 工具：git diff、文件差异对比
  • 版本控制：计算两个版本的共同部分
  • DNA 序列比对：生物信息学中的核心算法
  • 拼写检查：与编辑距离结合使用

LCS 动态规划推导

状态定义

dp[i][j] = s1 前 i 个字符与 s2 前 j 个字符的 LCS 长度

转移方程

若 s1[i-1] == s2[j-1]：dp[i][j] = dp[i-1][j-1] + 1

否则：dp[i][j] = max(dp[i-1][j], dp[i][j-1])

代码实现 — O(n×m) 二维 DP

int lcs(string& s1, string& s2) {
    int n = s1.size(), m = s2.size();
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (s1[i - 1] == s2[j - 1])
                dp[i][j] = dp[i - 1][j - 1] + 1;
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
    return dp[n][m];
}
初始化dp[0][j] = dp[i][0] = 0（空串 LCS 为 0）
答案dp[n][m]（右下角）
时间复杂度O(n × m)
空间复杂度O(n × m) → 可优化

空间优化原理

依赖关系分析

dp[i][j] 只依赖三个位置：

  上方 dp[i-1][j] · 左侧 dp[i][j-1] · 左上角 dp[i-1][j-1]

因此只需要保留当前行和上一行即可计算！

方案一：两行交替法

// dp[2][m+1]，用 cur = i % 2 交替
int dp[2][MAXM];
for (int i = 1; i <= n; i++) {
    int cur = i & 1, pre = cur ^ 1;
    for (int j = 1; j <= m; j++)
        if (s1[i-1] == s2[j-1])
            dp[cur][j] = dp[pre][j-1] + 1;
        else
            dp[cur][j] = max(dp[pre][j], dp[cur][j-1]);
}

方案二：一维数组 + prev 变量（更省空间）

// 核心技巧：prev 保存左上角 dp[i-1][j-1]
int dp[MAXM] = {0};
for (int i = 1; i <= n; i++) {
    int prev = 0;                    // prev = dp[i-1][j-1]
    for (int j = 1; j <= m; j++) {
        int temp = dp[j];            // 暂存当前 dp[j] (上一行的值)
        if (s1[i-1] == s2[j-1])
            dp[j] = prev + 1;         // dp[i-1][j-1] + 1
        else
            dp[j] = max(dp[j], dp[j-1]);
        prev = temp;                // 更新左上角
    }
}

空间复杂度从 O(nm) 降至 O(min(n, m))

注意：一维优化后无法直接回溯 LCS 路径，需要额外记录方向数组。

编辑距离（Levenshtein 距离）

问题描述

将 word1 转换为 word2 所需的最少操作次数。

三种操作（代价均为 1）：

  🔹 插入一个字符  |  🔹 删除一个字符  |  🔹 替换一个字符

DP 推导

状态dp[i][j]：word1 前 i 个 → word2 前 j 个的最小代价
匹配dp[i][j] = dp[i-1][j-1]（字符相同无需操作）
不匹配dp[i][j] = 1 + min(删除, 插入, 替换)
初始化dp[i][0] = i（全删），dp[0][j] = j（全插）
int editDistance(string& w1, string& w2) {
    int n = w1.size(), m = w2.size();
    vector<vector<int>> dp(n + 1, vector<int>(m + 1));
    for (int i = 0; i <= n; i++) dp[i][0] = i;
    for (int j = 0; j <= m; j++) dp[0][j] = j;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (w1[i - 1] == w2[j - 1])
                dp[i][j] = dp[i - 1][j - 1];
            else
                dp[i][j] = 1 + min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]});
    return dp[n][m];
}

应用场景

拼写检查 模糊搜索 DNA 序列比对 NLP 文本相似度 语音识别纠错

同样可滚动数组优化空间至 O(min(n,m))。

真题精练

真题 1：LCS 模板题

题意：给定两个字符串，求最长公共子序列的长度。

数据范围：n, m ≤ 1000

解法：O(nm) DP 模板直接套用，可用滚动数组优化空间。

真题 2：编辑距离（LeetCode 72 等价题）

示例："horse" → "ros"，最少操作 3 步：

horse → rorse（h→r，替换）→ rose（删 r）→ ros（删 e）

数据范围：n, m ≤ 500，标准编辑距离 DP 即可。

扩展知识点

LCS → LIS 转化 当一个字符串字符唯一时，可转化为最长上升子序列，O(n log n) 解决
Needleman-Wunsch 全局比对算法，本质是 LCS 加上了匹配/不匹配/空位的打分矩阵
Smith-Waterman 局部比对算法，找出两序列中相似度最高的子段
最短公共超序列 SCS = n + m - LCS，包含两个串的最短序列

拓展阅读：最长公共子串 → 可用后缀自动机 (SAM) 在 O(n) 时间内求解。

总结：LCS 与编辑距离核心对照

知识点 核心内容
LCS 基础 DP dp[i][j] = dp[i-1][j-1]+1（匹配）或 max(dp[i-1][j], dp[i][j-1])（不匹配）
LCS 空间优化 一维 + prev 变量法，注意 左上角依赖，空间 O(min(n,m))
LCS 路径回溯 用 dir 方向数组记录来源（左上/上/左），从右下角反向追踪
编辑距离 三种操作（插入/删除/替换），初始化边界 dp[i][0]=i, dp[0][j]=j 有讲究
编辑距离空间优化 同样可一维优化至 O(min(n,m))
LCS → LIS 转化 字符唯一时可转化为最长上升子序列，用 O(n log n) 解法
序列比对推广 NW（全局比对）与 SW（局部比对），本质是 DP 的推广，加入打分矩阵

两类问题的核心都是在两个序列上做二维 DP，

掌握转移方程的推导逻辑，举一反三应对更多序列比对变种！
