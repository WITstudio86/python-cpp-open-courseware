堆（Heap）的核心原理

1. 完全二叉树 + 数组存储（1-based 索引）

索引公式：

parent(i) = i / 2

left(i)  = 2 * i

right(i) = 2 * i + 1

索引从 1 开始，heap[0] 为哨兵

索引: 1 2 3 4 5 6 7 数组: [1, 3, 5, 7, 9, 8, 10] 对应完全二叉树（最小堆）： 1 / \ 3 5 / \ / \ 7 9 8 10

2. shiftUp（上浮）—— 插入后恢复堆性质

// 时间复杂度 O(log n) void shiftUp(int idx) { while (idx > 1 && heap[idx] < heap[idx / 2]) { swap(heap[idx], heap[idx / 2]); idx /= 2; // 继续向上 } }

3. shiftDown（下沉）—— 删除堆顶后恢复堆性质

// 时间复杂度 O(log n) void shiftDown(int idx) { int n = heap.size() - 1; while (2 * idx <= n) { int child = 2 * idx; if (child + 1 <= n && heap[child + 1] < heap[child]) child++; // 选较小的子节点 if (heap[child] < heap[idx]) { swap(heap[idx], heap[child]); idx = child; } else break; } }
建堆 push：heap.push_back(val); shiftUp(size);    建堆 pop：heap[1] = heap.back(); heap.pop_back(); shiftDown(1);
【讲解】堆（Heap）的核心原理 结合讲义《一、堆（Heap）的完全二叉树性质与数组存储》强调： · 堆是一种特殊的完全二叉树，满足**堆性质**： · 最小堆（Min-Heap）：每个节点的值都不大于其子节点的值，即 heap[parent] <= heap[child] · 最大堆（Max-Heap）：每个节点的值都不小于其子节点的值，即 heap[parent] >= heap[child] · 堆通常用于实现**优先队列（Priority Queue）**——一种每次取出优先级最高（最大或最小）元素的数据结构。 · 由于堆是一棵完全二叉树，我们可以用数组来紧凑存储，无需指针。 幻灯片上可见要点： · 索引公式： · parent(i) = i / 2 · left(i) = 2 * i · right(i) = 2 * i + 1 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：堆的实现原理、自定义比较函数、单调栈、单调队列

建堆 O(n) 证明 + priority_queue 比较器

建堆 O(n) 严格证明（sum of heights）

自底向上 heapify：从 i = n/2 到 1 执行 shiftDown。

总操作次数 S = 0·(n/2) + 1·(n/4) + 2·(n/8) + ... + h·1 ≤ n · Σ(i/2^(i+1)) (i=0 to ∞) = n · 1 = O(n) 恒等式证明：Σ i/2^i = 2 ⇒ Σ i/2^(i+1) = 1

priority_queue 的 3 种自定义比较器

方法写法适用场景
1. 仿函数 struct Cmp { bool operator()(int a,int b){return a>b;} }; 复杂逻辑、需复用
2. lambda auto cmp=[](int a,int b){return a>b;};
priority_queue<int,vector<int>,decltype(cmp)> pq(cmp);		 简单逻辑、一次性使用
3. greater priority_queue<int,vector<int>,greater<int>> pq; 基本类型反转方向
记忆口诀： greater → 小的优先级高 → 最小堆； 默认 less → 最大堆（反直觉！注意！）
lambda 陷阱：C++20 之前 lambda 不可默认构造，必须传对象给构造函数！
【讲解】建堆 O(n) 证明 + priority_queue 比较器 本页要点（照着讲即可）： · 自底向上 heapify：从 i = n/2 到 1 执行 shiftDown。 · 1. 仿函数 · 2. lambda · 3. greater · 记忆口诀： · lambda 陷阱： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

代码模板：手写堆 + 单调栈 + 单调队列

手写最小堆（核心骨架）

class MinHeap { vector<int> heap; void shiftUp(int idx) { /* while idx>1 && heap[idx] < heap[idx/2] swap */ } void shiftDown(int idx) { /* 找最小子节点，下沉 */ } public: MinHeap() { heap.push_back(0); } // 哨兵 void push(int x) { heap.push_back(x); shiftUp(size()); } void pop() { heap[1]=heap.back(); heap.pop_back(); shiftDown(1); } int top() { return heap[1]; } };

单调栈：下一个更大元素

for (int i = 0; i < n; ++i) { while (!st.empty() && nums[i] > nums[st.top()]) { ans[st.top()] = nums[i]; st.pop(); // 找到答案 } st.push(i); } // 剩余元素无答案，ans 保持 -1

单调队列：滑动窗口最大值

for (int i = 0; i < n; ++i) { while (!dq.empty() && dq.front() < i - k + 1) dq.pop_front(); // 过期 while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back(); // 维护递减 dq.push_back(i); if (i >= k - 1) ans.push_back(nums[dq.front()]); }
核心技巧：单调栈/队列都存储索引而非值——这是保留位置信息的关键！每个元素最多入一次、出一次，保证 O(n)。

真题精练

真题1：合并K个有序链表 优先队列

K <= 105，总节点数 N <= 105，每个链表已升序排列。合并成一个升序链表。

struct Cmp { bool operator()(ListNode* a,ListNode* b){ return a->val > b->val; } }; priority_queue<ListNode*, vector<ListNode*>, Cmp> pq; for (auto head : lists) if(head) pq.push(head); ListNode dummy(0), *tail = &dummy while (!pq.empty()) { tail->next = pq.top(); pq.pop(); tail = tail->next; if (tail->next) pq.push(tail->next); } return dummy.next; // 复杂度 O(N log K)
每步从堆中取最小节点 O(log K)，共 N 步 → O(N log K)

真题2：滑动窗口最大值 单调队列

n <= 106, k <= n。找出每个长度为 k 的滑动窗口中的最大值。

deque<int> dq; // 存储索引，维护 nums 值单调递减 for (int i = 0; i < n; ++i) { while (!dq.empty() && dq.front() < i - k + 1) dq.pop_front(); while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back(); dq.push_back(i); if (i >= k - 1) ans.push_back(nums[dq.front()]); } // 复杂度 O(n)，n=10^6 时优势明显

易错点与优化技巧

常见易错点

  1. 索引错误：手写堆 1-based vs 0-based 必须统一。建议 1-based（公式简洁），构造时 push 哨兵 heap.push_back(0)
  2. 比较器语义：priority_queue<int> 默认是最大堆（反直觉！）；greater<int> 才是最小堆
  3. lambda 忘记传参：C++20 前 lambda 不可默认构造，必须传对象给构造函数
  4. 存索引 vs 存值：单调栈/队列强烈建议存储索引，保留位置信息用于判断过期
  5. 过期条件：使用 dq.front() < i - k + 1 而非 > k

优化技巧

场景技巧
结果数组预分配ans.reserve(n - k + 1); 避免扩容
第K大/第K小维护大小为 K 的堆（第K大用小根堆，第K小用大根堆）
优先队列插入用 emplace 代替 push，原地构造减少拷贝
