一、大O表示法 (Big-O Notation)

1. 数学定义

设 f(n) 为实际运行时间，g(n) 为参考函数（足够大的 n）：

O(g(n)) - 上界：∃ c, n₀ 使得 ∀ n ≥ n₀ 有 0 ≤ f(n) ≤ c·g(n)
描述率增长率的上限（≤）—— 最坏不会超过
Ω(g(n)) - 下界：∃ c, n₀ 使得 ∀ n ≥ n₀ 有 0 ≤ c·g(n) ≤ f(n)
描述率增长率的下限（≥）—— 最好不会低于
Θ(g(n)) - 紧确界：f(n) = O(g(n)) 且 f(n) = Ω(g(n))
精确描述增长率 —— 恰好一样快

2. 化简规则

  • 忽略常数因子：O(3n) = O(n)
  • 忽略低阶项：O(n² + n log n) = O(n²)
  • 加法法则：O(f) + O(g) = O(max(f, g))
  • 乘法法则：O(f) × O(g) = O(f × g)

二、主定理 (Master Theorem)

用于求解形如 T(n) = a·T(n/b) + O(n^d) 的递推式。

情况 条件 结论 解释
情况 1 d < logba T(n) = O(nlogba) 递归调用占主导
情况 2 d = logba T(n) = O(nd log n) 递归与合并平衡
情况 3 d > logba T(n) = O(nd) 合并开销占主导

经典实例

归并排序

T(n) = 2T(n/2) + O(n)

a=2, b=2, d=1

log₂2 = 1 = d → 情况2

➜ O(n log n)

二分查找

T(n) = T(n/2) + O(1)

a=1, b=2, d=0

log₂1 = 0 = d → 情况2

➜ O(log n)

Strassen 矩阵乘法（情况1示例）

T(n) = 7T(n/2) + O(n²)

a=7, b=2, d=2 → log₂7 ≈ 2.81 > 2 → 情况1 → O(n2.81)

三、代码模板：二分与排序的复杂度

二分查找 O(log n)

int binary_search(vector<int>& arr, int target) { int l = 0, r = arr.size() - 1; while (l <= r) { int mid = l + (r - l) / 2; if (arr[mid] == target) return mid; else if (arr[mid] < target) l = mid + 1; else r = mid - 1; } return -1; }

归并排序 O(n log n)

void merge_sort(vector<int>& arr, int l, int r) { if (l >= r) return; int mid = l + (r - l) / 2; merge_sort(arr, l, mid); merge_sort(arr, mid + 1, r); merge(arr, l, mid, r); // merge: 合并两个有序子数组 O(n) }
易错提醒：
  • 使用 mid = l + (r - l) / 2 而非 (l + r) / 2，防止 整数溢出！
  • 外层 while 条件写 l <= r（带等号），否则会漏掉边界情况

四、真题精练：复杂度判断

题目：多重循环复杂度分析

分析以下两段代码的时间复杂度，判断 n = 10⁵ 时能否在 1 秒内完成。

代码段 1

for (int i = 1; i <= n; i++) { for (int j = 1; j <= n; j += i) { ans++; } }
分析：内层步长为 i，总执行次数：
Σ n/i ≈ n·Hn = n·O(log n)
➜ O(n log n) ✅ 可行

代码段 2

for (int i = 1; i <= n; i++) { for (int j = 1; j <= i; j *= 2) { for (int k = 1; k <= j; k++) { ans++; } } }
分析：对于固定 i，中层执行 O(log i) 次，
最内层执行 Σ 2^t < 2i = O(i)
Σ O(i) = O(n²) ❌ 不可行

六、本课小结

🎯 核心知识回顾
  1. 大O表示法 —— 描述算法增长率的上界，忽略常数和低阶项
  2. O / Ω / Θ —— 上界、下界、紧确界，O 是最常用的渐进符号
  3. 主定理 —— 分治递归的三种情况：
    d < logba → O(nlogba)   |   d = logba → O(nd log n)   |   d > logba → O(nd)
  4. 复杂度金字塔 —— O(1) < O(log n) < O(√n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)
  5. 均摊分析 —— 动态数组扩容是 O(1) 均摊的经典例子
🔑 应试金句：
看到数据范围 n ≤ 10⁵ 且操作次数 q ≤ 10⁵？
→ 你需要 O((n+q) log n) 的算法，优先考虑 线段树 / 树状数组 / 排序 + 二分！
