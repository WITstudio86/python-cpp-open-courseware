Floyd-Warshall 算法
基于动态规划的全源最短路算法

问题定义

给定 n 个节点的有向图，求出 任意两点之间的最短距离。允许负权边，但不允许负环。

DP 状态定义

设 dp[k][i][j] 表示从节点 i 到节点 j，仅经过编号为 1~k 的中间节点时的最短距离。

状态转移

dp[k][i][j] = min( dp[k-1][i][j] , dp[k-1][i][k] + dp[k-1][k][j] )

含义：i 到 j 的最短路，要么 不经过 k，要么 经过 k（拆为两段各自在 1..k-1 范围内的最短路）。

复杂度： 时间 O(V³)，空间 O(V²)（滚动数组优化后）。V ≤ 500~800 是实用范围。

DP 视角深入分析
理解 k 循环位置、滚动数组与边界条件

为什么 k 循环必须在最外层？

dp[k][i][j] 依赖的是 dp[k-1][i][k] 和 dp[k-1][k][j]（上一阶段的值）。如果将 k 放在内层，可能使用了「本阶段已被更新过的 dist[i][k]」，破坏了 DP 的正确性。

常见错误： 把 k 放在 i 或 j 的内层，导致最短路计算错误。在简单样例中可能碰巧正确，但在复杂图中会出错。

滚动数组优化原理

观察到 dp[k][i][k] = dp[k-1][i][k]（终点就是 k，不会再用 k 本身作为中间节点），因此第一维可以省略，直接在二维数组上迭代更新。

边界条件

  • dist[i][i] = 0（自己到自己的距离必须初始化为 0）
  • 无直接边 → INF（防止溢出时需用 1e18）
  • 重边 → 取最小值

传递闭包（Warshall 算法）
判断任意两点间可达性

问题定义

在有向图中，判断 i 是否能到达 j（存在从 i 到 j 的路径）。输出一个 n×n 的 0/1 矩阵。

算法——Floyd 的逻辑变体

将 min 替换为逻辑或，加法替换为逻辑与：

for (int k = 1; k <= n; k++) for (int i = 1; i <= n; i++) for (int j = 1; j <= n; j++) reach[i][j] |= (reach[i][k] & reach[k][j]);

bitset 优化

内层 j 循环替换为 bitset 按位或，复杂度从 O(V³) 降至 O(V³ / 64)。

bitset<MAXN> reach[MAXN]; for (k = 1..n) for (i = 1..n) if (reach[i][k]) reach[i] |= reach[k];
实战效果： V=2000 时，朴素 O(V³)=8×10⁹（不可过），bitset 优化后 ~1.25×10⁸（1s 内可过）。

Floyd 代码模板
全源最短路 + 路径还原
void floyd() { for (int k = 1; k <= n; k++) { for (int i = 1; i <= n; i++) { if (dist[i][k] == INF) continue; for (int j = 1; j <= n; j++) { if (dist[k][j] == INF) continue; long long nd = dist[i][k] + dist[k][j]; if (nd < dist[i][j]) { dist[i][j] = nd; nxt[i][j] = nxt[i][k]; // 路径还原 } } } } }
关键细节：
1. k 循环必须在最外层
2. dist[i][k] == INF 时 continue 可剪枝
3. 路径还原：nxt[i][j] 记录 i 到 j 的下一跳

优化技巧与进阶应用
最小环、负环检测、INF 防溢出

无向图最小环

在 Floyd 的每一轮 k，在 更新之前 遍历 i, j < k：

环权值 = dist[i][j] + g[i][k] + g[k][j]

其中 dist[i][j] 是基于 1..k-1 的最短路，保证环的中间节点 < k。

有向图最小环

跑完 Floyd 后检查 min(dist[i][i])（排除值为 0 的平凡情况）。若 dist[i][i] 为负值，说明 i 在负环上。

INF 防溢出

计算 dist[i][k] + dist[k][j] 时，若两者都是 INF，相加会溢出为负数。
推荐做法： 使用 1e18 作为 INF（long long），并在加法前用 if 判断。

其他应用

  • 判负环： Floyd 结束后检查 dist[i][i] < 0
  • 直径： 全源最短路的最大值即为图的直径
  • 传递闭包 + 二分图匹配： 先求闭包，再跑匈牙利
