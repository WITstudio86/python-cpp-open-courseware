知识精讲：sort 的内部实现 —— Introsort

三种基础排序的优缺点

算法平均最坏空间特点
快速排序O(n log n)O(n²)O(log n)平均最快，但可能退化为 O(n²)
堆排序O(n log n)O(n log n)O(1)严格 O(n log n)，常数较大
插入排序O(n²)O(n²)O(1)小数据时常数极低，接近线性

Introsort 的核心设计

  • 深度监控：设定最大递归深度 = 2⌊log₂(n)⌋。当快排递归超过此阈值时，切换到堆排序，避免退化
  • 小数组优化：子数组长度 < 16 时，切换到插入排序，利用缓存友好和常数优势
  • 三数取中 pivot：取 left、mid、right 三个元素的中位数作为基准，进一步降低退化风险
// Introsort 伪代码
void IntroSort(A, left, right, depthLimit) {
    if (right - left + 1 < 16) { InsertionSort(A, left, right); return; }
    if (depthLimit == 0) { HeapSort(A, left, right); return; }
    pivot = MedianOfThree(A, left, right);
    p = Partition(A, left, right, pivot);
    IntroSort(A, left, p - 1, depthLimit - 1);
    IntroSort(A, p + 1, right, depthLimit - 1);
}

关键结论 Introsort 以快排为主线，用堆排兜底最坏情况，用插入加速小规模子问题，从而在任何输入上都保证 O(n log n) 且平均性能接近快排。

原理推导：nth_element 快速选择 & next_permutation

nth_element —— O(n) 快速选择

基于快速排序的 partition 思想，但每次只递归一侧：

  • Partition 将数组分为 ≤pivot 和 ≥pivot 两部分
  • 如果第 k 小的位置在 pivot 左侧：只递归左侧
  • 如果第 k 小的位置在 pivot 右侧：只递归右侧
  • 期望复杂度：T(n) = T(n/2) + O(n) → O(n)
// nth_element 的简化实现
while (left < right) {
    p = Partition(A, left, right);  // O(n)
    if (k == p) return A[k];
    else if (k < p) right = p - 1;
    else left = p + 1;
}

next_permutation —— 字典序排列生成

算法步骤（以 {1,3,5,4,2} 为例）：

  1. ① 从右向左找第一个升序对：a[1]=3 < a[2]=5
  2. ② 从右向左找第一个大于 a[1] 的元素：a[3]=4 > 3
  3. ③ 交换 a[1] 和 a[3] → {1,4,5,3,2}
  4. ④ 反转 a[2..4] → {1,4,2,3,5} ← 下一个排列！

时间复杂度 O(n)，空间 O(1)。注意：初始序列必须升序才能生成全排列。

典型应用对比

场景推荐函数复杂度
求第 k 小（n=5×10⁶）nth_elementO(n) vs O(n log n)

代码模板：二分查找 & 离散化

lower_bound / upper_bound 记忆口诀

// lower_bound : 第一个 >= x 的位置 —— "下界"
// upper_bound : 第一个 >  x 的位置 —— "上界"
auto lb = lower_bound(v.begin(), v.end(), x);
auto ub = upper_bound(v.begin(), v.end(), x);
int cnt_eq = ub - lb;          // 等于 x 的个数
int cnt_lt = lb - v.begin();   // 小于 x 的个数
int cnt_ge = v.end() - lb;     // 大于等于 x 的个数

离散化模板（排序 + 去重 + 二分）推荐

vector<int> sorted = raw;
sort(sorted.begin(), sorted.end());
sorted.erase(unique(sorted.begin(), sorted.end()), sorted.end());
auto get_id = [&sorted](int x) {
    return lower_bound(sorted.begin(), sorted.end(), x) - sorted.begin() + 1;
};

离散化模板（map 映射）在线

map<int, int> id; int cnt = 0;
auto get_id = [&](int x) {
    if (!id.count(x)) id[x] = ++cnt;
    return id[x];
};

unique 去重原理 重要

unique() 并不真正删除元素，而是将不重复的元素移到前面，返回新结尾迭代器。
必须配合 erase 使用，否则容器大小不变，末尾存在残留值。

vector<int> v = {1,2,2,3,3};
auto it = unique(v.begin(), v.end());  // v = {1,2,3,?,?}
v.erase(it, v.end());                // v = {1,2,3}

题目1：区间覆盖统计（离散化 + 差分）

n 个区间 [l, r]，m 次询问点 x 被多少区间覆盖。坐标 ≤ 10⁹

  • 核心思路：收集所有坐标（端点 + 查询点）→ 离散化 → 差分数组 → 前缀和
  • 复杂度：O((n+m) log (n+m))，n,m ≤ 2×10⁵
  • 关键细节：差分右端点 +1 位置也需计入坐标集合
// 核心：收集坐标 + 差分 + 前缀和
for (int i = 0; i < n; i++) {
    coords.push_back(L[i]);          // 左端点
    coords.push_back(R[i] + 1);      // 右端点+1（差分减位）
}
// 排序去重后用 idx() 映射到紧凑下标
diff[idx(L[i])]++; diff[idx(R[i] + 1)]--;
// 前缀和 cover[i] = cover[i-1] + diff[i]

题目2：第K小数（nth_element vs sort）

n ≤ 5×10⁶，q ≤ 10。要求高效算法

  • nth_element：每次 O(n)，总计 O(qn) ≈ 5×10⁷ 操作 → 最优解
  • sort：O(n log n) ≈ 1.15×10⁸ 比较 → 勉强可通过，但不如 nth_element
  • 决策原则：当 q ≤ log₂n 时，nth_element 更优；当 q 很大时，sort 一次性排序更优
// nth_element 求第 k 小（1-based 索引）
nth_element(a.begin(), a.begin() + k - 1, a.end());
cout << a[k - 1];  // 这就是答案！

优化技巧：易错点汇总

六大经典错误

#错误后果正确做法
① 比较函数用 >= / <= 违反严格弱序，UB / 崩溃 始终使用 < 或 >
② 对未排序序列用 lower_bound 返回结果不可预测 使用前必须 sort
③ 对 set 用 std::lower_bound 退化为 O(n) 使用 s.lower_bound(x)
④ next_permutation 前未排序 遗漏排列，结果不全 初始序列必须升序
⑤ unique 后忘记 erase 容器大小不变，残留垃圾值 必须 erase(it, end)
⑥ lower_bound 返回值直接解引用 找不到时解引用 end() 导致 UB 先判断 it != end()

性能优化 checklist

  • 大型结构体排序时，Lambda 参数用 const T& 传引用，避免拷贝
  • 离散化时预先 reserve 空间，减少 vector 扩容
  • 不需要稳定性时用 sort 而非 stable_sort（省空间，更快）
  • 求第 k 小用 nth_element（O(n)），不要盲目 sort（O(n log n)）
  • 使用 ios::sync_with_stdio(false) + cin.tie(nullptr) 加速 I/O
  • n 很大时（> 10⁶）考虑手写快速读入函数
