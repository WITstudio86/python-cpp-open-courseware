📖 知识精讲 — 多懒标记协同

同时支持加法 + 乘法

核心原则：先乘后加

对值 x，先乘 a 再加 b → a·x + b

再乘 c 再加 d → c·(a·x + b) + d = (a·c)·x + (b·c + d)

apply 函数（统一更新节点）

void apply(int p, int len, long long mu, long long ad) {
    sum[p] = (sum[p] * mu + ad * len) % P;
    mul[p] = (mul[p] * mu) % P;
    add[p] = (add[p] * mu + ad) % P;
    // 关键：原有的加法标记也要乘 mu！
}

📖 知识精讲 — 权值线段树

值域线段树 vs 下标线段树

叶子节点代表某个值的出现次数，而非数组元素

第 K 小查询（线段树上二分）

int kth(int p, int l, int r, int k) {
    if (l == r) return l;
    int mid = (l + r) >> 1;
    if (tree[lc[p]] >= k)
        return kth(lc[p], l, mid, k);
    else
        return kth(rc[p], mid+1, r, k - tree[lc[p]]);
}

适用场景

  • 全局第K小 / 第K大
  • 查询排名、前驱、后继
  • 动态开点处理 10⁹ 值域

💻 代码模板 — 线段树合并 & 可持久化

线段树合并（动态开点）

int merge(int p, int q, int l, int r) {
    if (!p || !q) return p + q;     // 一方为空
    if (l == r) { cnt[p] += cnt[q]; return p; }
    lc[p] = merge(lc[p], lc[q], l, mid);
    rc[p] = merge(rc[p], rc[q], mid+1, r);
    pushup(p); return p;
}

可持久化（主席树）— 修改

int update(int pre, int l, int r, int x) {
    int p = ++tot; t[p] = t[pre];  // 复制节点
    if (l == r) { cnt[p]++; return p; }
    if (x <= mid) lc[p] = update(lc[pre], l, mid, x);
    else rc[p] = update(rc[pre], mid+1, r, x);
    pushup(p); return p;
}

每次修改只新建 O(log n) 个节点

⚠️ 易错点与优化技巧

  • ⚠ 多懒标记顺序 — 必须"先乘后加"，pushdown和update一致
  • ⚠ 加法标记被乘法影响 — add[p] = add[p] * mu + ad
  • ⚠ 动态开点空间 — 开到 操作数×log(值域)，约30~40倍
  • ⚠ 线段树合并不回溯 — 原树可能被破坏，必要时先复制
  • ✔ 离散化 + 权值树 — 减小值域，降低log因子
  • ✔ mid防溢出 — l + (r-l)/2 而非 (l+r)/2
  • ✔ 主席树静态区间K小 — 版本前缀和做差

📝 真题精练

真题一：区间加法+乘法+求和（模 P）

n, m ≤ 10⁵ | 三种操作：乘、加、求和

要点：apply 统一处理、pushdown 正确传递、取模

真题二：静态区间第 K 小（主席树）

n, q ≤ 2×10⁵ | 在线询问任意区间第K小

要点：离散化、前缀版本树、两版本做差在线段树上二分

复杂度分析：

真题一：O((n+m) log n) | 真题二：O((n+q) log n)，空间 O(n log n)
