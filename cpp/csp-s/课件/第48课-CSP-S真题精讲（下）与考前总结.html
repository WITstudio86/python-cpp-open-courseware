📝 T3 真题：树的最大权值独立集（根必选）

题目大意

树上选择节点，满足：① 任意两个被选节点不相邻；② 根（1号）必须被选。求最大总权值。

样例输入

5
10 5 8 3 6
1 2
1 3
1 4
3 5

样例输出 & 树结构

16
      1(10)  ← 必须选
    /  |  \
  2(5) 3(8) 4(3)
        |
       5(6)  ← 可选

选 1(10) + 5(6) = 16

数据范围

n ≤ 20 (20分) | 链 (30分) | n ≤ 10⁵ (50分)

💻 T3 真题：树形DP 正解

核心思路

dp[u][0] = 不选 u 时子树最大权值  |  dp[u][1] = 选 u 时子树最大权值

// 后序遍历树形DP
void dfs(int u, int fa) {
    dp[u][0] = 0;
    dp[u][1] = w[u];
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);  // 先递归子节点
        dp[u][0] += max(dp[v][0], dp[v][1]);  // 不选u，儿子可选可不选
        dp[u][1] += dp[v][0];                // 选u，儿子都不能选
    }
}
// 答案 = dp[1][1]（根必须选！）

部分分解法

Subtask 1 (n≤20)：O(2ⁿ) 子集枚举

Subtask 2 (链)：线性DP，f[i] = max(f[i-1], f[i-2]+w[i])

复杂度

时间：O(n)

空间：O(n)

每个节点和每条边仅访问一次

📝 T4 真题：加权区间调度

题目大意

n 个区间 [lᵢ, rᵢ]，权值 wᵢ。选择互不重叠的区间，最大化总权值。

输入样例

5
1 3 10
2 5 5
5 7 15
4 8 20
8 10 8

输出

33

选 [1,3](10) + [5,7](15) + [8,10](8) = 33

数据范围

n ≤ 1000 (30分) | 等长 (30分) | n ≤ 2×10⁵ (40分)

核心思路

1. 按 右端点 rᵢ 升序排列  |  2. dp[i] = max(dp[i-1], dp[p[i]] + wᵢ)

3. p[i] = upper_bound(R 中最后一个 < lᵢ 的位置)

复杂度：O(n log n)

💻 T4 真题：加权区间调度 正解

// DP + 二分查找优化，O(n log n)
sort(intervals.begin(), intervals.end(),
     [](auto& a, auto& b) { return a.r < b.r; });

vector<long long> dp(n + 1, 0);
for (int i = 0; i < n; i++) {
    // 不选第 i 个区间
    long long skip = dp[i];
    // 选第 i 个：二分找最后一个 r < l_i 的区间
    int p = upper_bound(right_ends.begin(), right_ends.end(),
                            intervals[i].l - 1)
            - right_ends.begin() - 1;
    long long take = intervals[i].w;
    if (p >= 0) take += dp[p + 1];
    dp[i + 1] = max(skip, take);
}
return dp[n];

部分分 30 分

O(n²) DP：对每个区间枚举所有前面的不重叠区间

n ≤ 1000 时完全可行

等长特殊性质 30 分

lᵢ + L = rᵢ 时，按左端点排序后贪心选择

时间复杂度可优化到 O(n log n)
