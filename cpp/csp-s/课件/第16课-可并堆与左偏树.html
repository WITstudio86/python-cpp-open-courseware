第16课：可并堆与左偏树

Leftist Heap（Meldable Heap）

CSP-S 高级堆O(log n) 合并左偏性质猴子打架

当二叉堆不够用时——O(log n) 合并两个堆

📖 知识精讲 — 左偏树原理

左偏树的核心概念：npl（Null Path Length）

npl(x) = 从 x 到最近空节点的距离（边数）

  • 空节点 npl = 0
  • 叶子节点 npl = 0
  • npl(x) = min(npl(lc), npl(rc)) + 1

左偏性质

对于任意节点：npl(lc) ≥ npl(rc)

即：左儿子的 npl 不小于右儿子的 npl

推论：右脊长度 ≤ O(log n)

每次走右儿子的路径长度不超过 O(log n)

因此沿右脊递归合并，复杂度为 O(log n)

📖 知识精讲 — 合并算法

merge(x, y) — 左偏树的灵魂

  1. 若一方为空，返回另一方
  2. 确保 val[x] ≤ val[y]（小根堆，x 的新根）
  3. 递归合并 rc[x] 与 y（沿右脊走）
  4. 回溯时检查：若 dist[lc] < dist[rc] → 交换左右子
  5. 更新 dist[x] = dist[rc] + 1

其他操作都基于 merge

push(root,v)merge(root, new_node(v))
pop(root)merge(lc[root], rc[root])
top(root)val[root]

💻 代码模板 — 左偏树完整实现

int merge(int x, int y) {
    if (!x || !y) return x + y;        // 一方为空
    if (val[x] > val[y]) swap(x, y); // 小根堆
    rc[x] = merge(rc[x], y);          // 递归合并右儿子
    if (dist[lc[x]] < dist[rc[x]])     // 维护左偏性质
        swap(lc[x], rc[x]);
    dist[x] = dist[rc[x]] + 1;
    return x;
}

// 三种基本操作
int push(int root, int v) { return merge(root, new_node(v)); }
int pop(int root)  { return merge(lc[root], rc[root]); }
int top(int root)  { return val[root]; }

仅 ~10 行核心代码，即可实现 O(log n) 的可并堆！

⚠️ 易错点与经典应用

常见错误

  • ⚠ dist 初始值 — 新节点 dist=0，空节点 dist=0
  • ⚠ 交换子节点时机 — 仅在 dist[lc] < dist[rc] 时
  • ⚠ 大根堆 vs 小根堆 — 只改 merge 中比较符号
  • ⚠ 并查集配合 — pop 后根可能变化，及时更新

猴子打架问题

左偏树 + 并查集的经典组合：

  • 并查集维护朋友圈
  • 每个圈用大根左偏树维护强壮值
  • 打架：取最强 → 减半 → 放回 → 合并两棵树

O(m log n) 解决猴子打架

📝 真题精练

真题一：猴子打架（HDU 1512）

n ≤ 10⁵，m ≤ 10⁵ | 大根左偏树 + 并查集

核心流程：find 代表 → pop 最强 → 减半后 push → merge 两棵树

真题二：动态组最小值

n, q ≤ 10⁵ | 合并组、查最小并删除、插入

小根左偏树 + 并查集，每个组维护一个左偏树

复杂度分析：

插入/删除/合并：O(log n) | 总 O((n+m) log n)

左偏树 vs 二叉堆：唯一区别就是支持 O(log n) 合并
