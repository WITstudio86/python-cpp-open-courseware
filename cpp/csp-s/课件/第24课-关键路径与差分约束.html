📘 AOE 网与关键路径

AOE 网（Activity On Edge）：一种带权有向无环图。顶点 = 事件（时间点），有向边 = 活动（任务），边的权值 = 活动持续时间。

核心概念

概念定义计算方法
源点入度为 0 的顶点，工程起点—
汇点出度为 0 的顶点，工程终点—
ve[v]事件 v 最早发生时间ve[v] = max{ve[u] + w}（正向拓扑 DP）
vl[u]事件 u 最晚发生时间vl[u] = min{vl[v] - w}（逆向拓扑 DP）
关键活动没有任何时间余量的活动ve[u] + w == vl[v]

工程最短完成时间 = 关键路径的长度（汇点的 ve 值）

📗 差分约束系统

定义：一组形如 x_i - x_j ≤ c_k 的不等式组。通过图论的方法求解。

核心转化：不等式 → 图中的边

利用最短路三角不等式 dist[i] ≤ dist[j] + w（对于边 j→i 权 w）：

不等式转化建边
x_i - x_j ≤ cx_i ≤ x_j + cj → i，权 c
x_i - x_j ≥ cx_j ≤ x_i - ci → j，权 -c
x_i - x_j = c两条不等式j→i 权c，i→j 权-c
x_i ≤ cx_i - x₀ ≤ c超级源点 → i，权 c

超级源点：创建一个虚拟节点，向所有变量节点连一条权值为 0 的边，保证图的连通性并为解提供统一基准。

无解判定：若图中存在负环，则不等式组无解（因为负环导致 x_i ≤ x_i + (负数) 矛盾）。

📙 SPFA 求解差分约束（原理推导）

算法流程

  1. 建图：对每个约束 x_i - x_j ≤ c，添加有向边 j → i，权值为 c。
  2. 超级源点：创建节点 S = n，对所有 i ∈ [0, n-1] 添加边 S → i，权 0。
  3. SPFA 求最短路：以 S 为起点运行 SPFA，得到 dist[0..n-1]。
  4. 检测负环：若某节点入队次数 ≥ n+1，说明存在负环 → 不等式组无解。
  5. 输出解：x_i = dist[i] 即为一组可行解。

为什么最短路径就是解？

SPFA 求出的最短距离满足：对每条边 j→i（权 c），有 dist[i] ≤ dist[j] + c。

令 x_i = dist[i]，则 x_i ≤ x_j + c，即 x_i - x_j ≤ c —— 正好满足差分约束！

解的平移性质

若 (x₁, x₂, ..., xₙ) 是一组可行解，则 (x₁+d, x₂+d, ..., xₙ+d) 也是可行解。

因为 (x_i+d) - (x_j+d) = x_i - x_j，差值不变。

📝 真题精练

题目1：关键路径（CSP 经典题型）

给定 AOE 网（n 个事件，m 个活动），求：工程最短完成时间 和 关键路径上的活动。

解题步骤：

① 正向拓扑排序，计算 ve[v] = max{ve[u] + w}（DP 转移）

② 逆向计算 vl[u] = min{vl[v] - w}

③ 遍历所有边，ve[u] + w == vl[v] 即为关键活动

复杂度：O(V+E)

题目2：差分约束（POJ 1201 风格）

给定 m 个约束条件，形如 x_b - x_a ≥ c，求满足所有约束的最小解空间。

转化：x_b - x_a ≥ c → x_a - x_b ≤ -c → 建边 b → a，权 -c。添加超级源点后 SPFA 求解。

注意：求最短路得到的是使变量尽可能小的解（最大下界）。

⚡ 优化技巧与易错点

常见错误

错误正确做法
ve 初始化为 INFve 应初始化为 0
vl 各节点初始值不一致统一初始化为汇点 ve
差分约束建边方向反x_i - x_j ≤ c → j→i
遗忘超级源点必须加！否则不连通
负环检测阈值用 n应用总节点数 N = n+1

优化技巧

  • 边权取负求最长路：DAG 上关键路径即最长路，可对边权取负后求最短路。
  • SPFA 优化：使用 SLF（Small Label First）优化入队策略。
  • DAG 用拓扑 DP：如果差分约束图是 DAG，直接用 DP 可按 O(V+E) 求解，无需 SPFA。
  • Bellman-Ford 备选：当数据规模较小时，用 Bellman-Ford 更稳定（负环检测无遗漏）。
  • 不等式转化模板：建立 Builder 辅助类，统一处理 LEQ/GEQ/EQ 约束。

关键路径 vs 差分约束 解题思路对比

维度关键路径差分约束
图类型DAG（必须无环）任意有向图
求解目标最长路径最短路径
判无解拓扑序列长度 < n存在负环
算法拓扑排序 + DPSPFA / Bellman-Ford

🎯 本课小结

知识点核心复杂度
AOE 网顶点=事件，边=活动，带权 DAG—
ve（最早时间）正向拓扑 DP：ve[v] = max(ve[u] + w)O(V+E)
vl（最晚时间）逆向拓扑 DP：vl[u] = min(vl[v] - w)O(V+E)
关键活动判定ve[u] + w == vl[v]O(E)
差分约束建模x_i - x_j ≤ c → 边 j→i 权 c—
SPFA 求解最短路 + 负环检测（cnt ≥ N）O(kE)
超级源点向所有节点连权 0 边，保证连通O(V)

一句话总结：关键路径在 DAG 上通过拓扑 DP 求最长路；差分约束将不等式组转化为图中最短路问题，由 SPFA 求解，负环即无解。两者都是「约束 → 图」的建模思维。
