Bellman-Ford 算法
处理负权边的基础算法

核心思想

进行 V-1 轮 对所有边的松弛操作。第 k 轮后，dist[v] 表示从源点出发经过 不超过 k 条边 的最短距离。

松弛操作： 对边 (u, v, w)，若 dist[u] + w < dist[v]，则更新 dist[v] = dist[u] + w

为什么是 V-1 轮？

在无负环的图中，任意两点间的最短路径 最多经过 V-1 条边（不会重复经过同一个点）。V-1 轮松弛足以找出所有最短路。

复杂度

项目复杂度
时间复杂度O(VE)
空间复杂度（边集数组）O(V)
适用场景含有负权边、需检测负环
SPFA 算法
Shortest Path Faster Algorithm —— 队列优化的 Bellman-Ford

优化动机

Bellman-Ford 每轮遍历所有边，但 只有上一轮被更新的节点，其出边才可能引起新的松弛。因此用队列维护这些节点，避免无效遍历。

算法流程

  • 初始化 dist[s] = 0，源点入队
  • 取出队首 u，遍历其出边进行松弛
  • 若 v 被更新且不在队列中，则 v 入队
  • 队列为空时算法结束
复杂度： 期望 O(kE)（随机图 k≤2），最坏 O(VE)
注意： SPFA 可能被卡退化为 O(VE)。网格图、蒲公英图是经典卡法。无负权边时优先使用 Dijkstra。
负环检测原理
Bellman-Ford 与 SPFA 两种检测方法

方法一：第 V 轮松弛法（Bellman-Ford）

进行第 V 轮松弛：若仍有边可以被松弛，说明存在 经过 ≥ V 条边的最短路径。由抽屉原理，这条路径必定重复经过某顶点，形成负环。

// 第 V 轮检测负环 for (int j = 1; j <= m; j++) { if (dist[u] != INF && dist[u] + w < dist[v]) return false; // 存在负环 }

方法二：路径边数法（SPFA 推荐）

维护 cnt[v] = 从源点到 v 的最短路径经历的边数。若 cnt[v] ≥ V，则路径经过了 V+1 个顶点，必存在负环。

全局负环检测： 若图不连通，负环可能不在源点可达范围内。解决方法：将所有节点的初始距离设为 0，全部入队。此时能从任意节点出发检测负环。
SPFA 代码模板
邻接表 + 队列 + 负环检测
bool spfa(int s) { fill(dist, dist + n + 1, INF); fill(cnt, cnt + n + 1, 0); queue<int> q; dist[s] = 0; q.push(s); inq[s] = true; while (!q.empty()) { int u = q.front(); q.pop(); inq[u] = false; for (auto &e : g[u]) { int v = e.first; long long w = e.second; if (dist[u] + w < dist[v]) { dist[v] = dist[u] + w; cnt[v] = cnt[u] + 1; if (cnt[v] >= n) return false; // 负环! if (!inq[v]) { q.push(v); inq[v] = true; } } } } return true; }
关键实现细节：
1. cnt[v] = cnt[u] + 1 记录路径边数
2. 节点出队时 inq[v] = false，允许再次入队
3. INF 建议使用 1e18（long long），防止 INF + w 溢出

经典题目与 AC 策略

P3385 【模板】负环

  • 题意：判断有向图是否存在负环（图可能不连通）
  • 策略：全局入队 + cnt[v] ≥ n 判负环
  • 复杂度：最坏 O(VE)，n≤2000, m≤6000 可行
bool spfa_detect_all() { // 所有点初始入队，dist 设为 0 for (int i = 1; i <= n; i++) { q.push(i); inq[i] = true; } // ... 松弛过程同 spfa，cnt[v] >= n 即返回 true }

优化技巧与卡 SPFA 策略
SLF、LLL 优化原理及防御思路

SLF（Small Label First）

入队时，若 dist[v] < dist[q.front()]，将 v 插入 队首（使用 deque）。距离更小的节点优先处理，加速收敛。

if (!q.empty() && dist[v] < dist[q.front()]) q.push_front(v); else q.push_back(v);

LLL（Large Label Last）

出队时，若队首距离 > 队列平均值，移回队尾。实际竞赛中 SLF 更常用，LLL 效果不稳定。

卡 SPFA 攻击原理： 构造网格图或蒲公英图，使节点更新顺序与 SPFA 的遍历顺序高度不一致，每个节点被松弛 O(V) 次，退化为 O(VE)。
应对策略： 无负权边 → Dijkstra；有负权但不确定是否卡 → SLF + 随机化边表；稠密图 → Floyd 或朴素 Bellman-Ford。
