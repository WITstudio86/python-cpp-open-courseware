知识精讲

树形DP的核心思想

树形DP是将动态规划与树的递归结构结合的高级算法。核心在于 后序遍历：子节点的DP值计算完成后，再计算父节点。

核心特点

利用树的递归结构，DFS后序遍历确保子问题先求解。状态通常分为"选/不选当前节点"两类。

时间复杂度

O(n) —— 每个节点和每条边各被访问一次。内存使用邻接表存储，空间 O(n)。

DP 计算顺序（伪代码）： DFS(u, fa): for v in u的儿子: if v != fa: DFS(v, u) // 先递归处理子树 // 后序遍历：利用v的DP值更新u的DP值

原理推导

两大经典模型

模型一：最大独立集（没有上司的舞会）

在树中选择一个最大点集，使得任意两个被选中的点不相邻。

状态转移： dp[u][0] = Σ max(dp[v][0], dp[v][1]) // 不选u，儿子随意 dp[u][1] = w[u] + Σ dp[v][0] // 选u，儿子都不能选

模型二：最小点覆盖（战略游戏）

选择一个最小点集，使得每条边至少有一个端点被选中。

状态转移： dp[u][0] = Σ dp[v][1] // 不选u，儿子必须全选 dp[u][1] = 1 + Σ min(dp[v][0], dp[v][1]) // 选u，儿子随意

代码模板

标准模板 — 最大独立集

// 树形DP标准模板 —— 最大独立集 #include <bits/stdc++.h> using namespace std; const int MAXN = 100005; vector<int> g[MAXN]; int w[MAXN]; // 节点权值 int dp[MAXN][2]; // dp[u][0]: 不选u; dp[u][1]: 选u void dfs(int u, int fa) { dp[u][0] = 0; dp[u][1] = w[u]; for (int v : g[u]) { if (v == fa) continue; dfs(v, u); // 先递归子节点 dp[u][0] += max(dp[v][0], dp[v][1]); dp[u][1] += dp[v][0]; } } int main() { int n; cin >> n; for (int i = 1; i <= n; i++) cin >> w[i]; for (int i = 1; i < n; i++) { int u, v; cin >> u >> v; g[u].push_back(v); g[v].push_back(u); } dfs(1, 0); cout << max(dp[1][0], dp[1][1]) << '\n'; }

真题精练

经典例题

题1：没有上司的舞会

某公司 n 个职员，关系构成一棵树。父节点是子节点的直接上司。 每个职员有快乐指数 H_i。如果上司来了，直接下属就不来。 求最大快乐指数总和。

数据范围：n ≤ 6000, -128 ≤ H_i ≤ 127 · 时间 O(n)

题2：战略游戏

树上有 n 个节点，放置最少的士兵观察所有边。 每个士兵放在节点上可观察到所有与该节点相连的边。 求最少需要多少士兵。

数据范围：n ≤ 1500 · 时间 O(n) · 最小点覆盖模型

解题提示： 题1是标准最大权独立集；题2是最小点覆盖。 两者在树上满足：最大独立集 + 最小点覆盖 = n。

树形DP基础总结

✓ 后序遍历是核心

先处理子树，再处理根节点。DFS(fa)防止无限递归。

✓ 选/不选 维度

dp[u][0] 和 dp[u][1] 是最经典的状态设计方案。

✓ 两个经典模型

最大独立集（不相邻选点）与最小点覆盖（覆盖所有边）。

✓ 复杂度 O(n)

每个节点访问一次，适合处理 n ≤ 10^5 的大规模数据。
