📖 知识精讲 — 核心概念

轻重链剖分定义

重儿子子树节点数最多的儿子
轻儿子除重儿子外的其他儿子
重边/轻边父节点连向重/轻儿子的边
重链由连续重边组成的路径
top[u]节点 u 所在重链的顶端节点

关键性质

  • 根到任意叶子的路径上，轻边不超过 O(log n) 条
  • 每条重链上的节点 DFS 序连续
  • DFS 序中，子树区间为 [dfn[u], dfn[u] + siz[u] - 1]

📖 知识精讲 — 两次 DFS

DFS1：计算子树信息

求 father、depth、siz、heavy（重儿子）

DFS2：分配 DFS 序

优先遍历重儿子 → 重链上 dfn 连续

轻儿子作为新重链的顶端

// DFS2 核心逻辑
void dfs2(int u, int tp) {
    dfn[u] = ++timer; rnk[timer] = u; top[u] = tp;
    if (heavy[u] == 0) return;
    dfs2(heavy[u], tp);         // 优先重儿子！
    for (int v : adj[u]) {
        if (v == parent[u] || v == heavy[u]) continue;
        dfs2(v, v);              // 轻儿子：新链顶
    }
}
【讲解】📖 知识精讲 — 两次 DFS 本页要点（照着讲即可）： · 求 father、depth、siz、 heavy（重儿子） · 优先遍历重儿子 → 重链上 dfn 连续 · 轻儿子作为新重链的顶端 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

💻 代码模板 — 路径跳链

核心：路径跳链算法

// 查询路径 u-v 的和
long long query_path(int u, int v) {
    long long res = 0;
    while (top[u] != top[v]) {           // 不在同一条链
        if (depth[top[u]] < depth[top[v]])
            swap(u, v);                      // 确保 u 的链顶更深
        res += seg.sum(dfn[top[u]], dfn[u]); // 查当前链
        u = parent[top[u]];                 // 跳到链顶的父节点
    }
    if (depth[u] > depth[v]) swap(u, v);
    res += seg.sum(dfn[u], dfn[v]);          // 同一条链，查剩余
    return res;
}

时间复杂度

每条路径分解为 O(log n) 条重链 × 每次区间查询 O(log n) = O(log² n)

子树操作：只需 1 个区间 → O(log n)

⚠️ 易错点与优化技巧

  • ⚠ dfs2 优先遍历重儿子 — 重链连续的关键，忘记会全错
  • ⚠ 跳链比较 depth[top[u]] — 不是 depth[u]！
  • ⚠ 跳链后 u = parent[top[u]] — 不是 parent[u]
  • ⚠ 同链后确保 dfn 有序 — 深度小的 dfn 也小
  • ✔ dfn 从 1 开始 — 方便直接配合线段树
  • ✔ 线段树用 dfn 索引 — 不是原始节点编号
  • ✔ 子树区间 — [dfn[u], dfn[u] + siz[u] - 1]
  • ✔ lca 可用 HLD — 最后在同一链上深度小的即为 LCA
【讲解】⚠️ 易错点与优化技巧 结合讲义《⚠️ 易错点与优化技巧》强调： · dfs2 中先遍历重儿子 —— 这是保证重链连续的关键，忘记会导致完全错误 · 跳链时的深度比较 —— 比较的是 depth[top[u]] 而非 depth[u] · 跳链后跳到 parent[top[u]] —— 不是 parent[u] · 同链后区分 u 和 v 的深度 —— 确保 dfn 区间左端点 ≤ 右端点 · dfn 从 1 开始 —— 方便配合线段树 幻灯片上可见要点： · ⚠ dfs2 优先遍历重儿子 — 重链连续的关键，忘记会全错 · ⚠ 跳链比较 depth[top[u]] — 不是 depth[u]！ · ⚠ 跳链后 u = parent[top[u]] — 不是 parent[u] · ⚠ 同链后确保 dfn 有序 — 深度小的 dfn 也小 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

操作：路径加 x、查询路径和、子树加 x、查询子树和

n, m ≤ 10⁵

路径 O(log² n)，子树 O(log n)

真题二：HLD 求 LCA

int lca(int u, int v) {
    while (top[u] != top[v]) {
        if (depth[top[u]] < depth[top[v]]) swap(u, v);
        u = parent[top[u]];
    }
    return depth[u] < depth[v] ? u : v;
}

O(log n) 单次查询，常数比倍增法大，但可顺便维护路径信息
