📖 排列组合基础

核心公式

排列 P(n,k) = n! / (n-k)! = n×(n-1)×...×(n-k+1)

组合 C(n,k) = n! / (k! × (n-k)!)

三条黄金性质

  1. 对称性：C(n,k) = C(n, n-k)
  2. 递推公式（杨辉三角）：C(n,k) = C(n-1,k-1) + C(n-1,k)
  3. 边界条件：C(n,0) = C(n,n) = 1

杨辉三角（前6行）

n=0: 1 n=1: 1 1 n=2: 1 2 1 n=3: 1 3 3 1 n=4: 1 4 6 4 1 n=5: 1 5 10 10 5 1

递推复杂度 O(n²)，适合 n ≤ 5000；更大规模需要阶乘+逆元

📖 阶乘预处理 + 逆元求组合数

O(1) 查询的奥秘

C(n,k) = fact[n] × inv_fact[k] × inv_fact[n-k] (mod MOD)

预处理三步骤

  1. 预处理 fact[i] = fact[i-1] × i % MOD（正推）
  2. 用费马小定理求 inv_fact[n] = pow(fact[n], MOD-2)
  3. 倒推 inv_fact[i-1] = inv_fact[i] × i % MOD
// 核心代码 — O(n) 预处理，O(1) 查询
void precompute(int n) {
    fact[0] = 1;
    for (int i = 1; i <= n; i++)
        fact[i] = fact[i-1] * i % MOD;
    inv_fact[n] = qpow(fact[n], MOD - 2);
    for (int i = n; i >= 1; i--)
        inv_fact[i-1] = inv_fact[i] * i % MOD;
}
ll C(int n, int k) {
    if (k < 0 || k > n) return 0;
    return fact[n] * inv_fact[k] % MOD * inv_fact[n-k] % MOD;
}

⚠ 前提条件

MOD 必须是质数且 n < MOD。若 n ≥ MOD，需使用卢卡斯定理

📖 卡特兰数精讲（Catalan Number）

定义公式

Hₙ = C(2n, n) / (n+1) = C(2n, n) − C(2n, n−1)

前几项：1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, 16796

递推公式（二选一）

卷积型：Hₙ = ΣHᵢ · Hₙ₋₁₋ᵢ（O(n²)）

线性型：Hₙ = Hₙ₋₁ · (4n−2) / (n+1)（O(n)，推荐）

四大经典应用（CSP-S 高频）

应用场景卡特兰项举例
合法括号序列Hₙn=3: ()(), (())(), (()()), ((())), ()()()
出栈序列数Hₙn=3: 123,132,213,231,321（5种）
二叉树形态数Hₙn=3: 5种不同形态的二叉搜索树
凸多边形三角剖分Hₙ₋₂六边形(n+2=6)有 H₄=14 种剖分
// 线性递推求卡特兰数（取模）
ll catalan(int n) {
    ll h = 1;
    for (int i = 1; i <= n; i++)
        h = h * (4*i - 2) % MOD * inv(i+1) % MOD;
    return h;
}

📖 卢卡斯定理与容斥原理

卢卡斯定理（Lucas Theorem）

适用场景：n 和 k 极大（≤ 10¹⁸），模数 p 较小且为质数

C(n, k) ≡ C(n mod p, k mod p) · C(n/p, k/p) (mod p)

ll lucas(ll n, ll k, ll p) {
    if (k == 0) return 1;
    return smallC(n % p, k % p) * lucas(n / p, k / p, p) % p;
}

容斥原理（Inclusion-Exclusion）

奇加偶减：奇数个集合交 → 加，偶数个集合交 → 减

|A ∪ B| = |A| + |B| − |A ∩ B|

|A ∪ B ∪ C| = |A|+|B|+|C| − |A∩B|−|A∩C|−|B∩C| + |A∩B∩C|

经典应用：1~n 中与 m 互质的数

  1. 对 m 做质因子分解，得到质因子集合 P
  2. 二进制枚举质因子子集，容斥求和
  3. 答案 = n − |∪Aᵢ|（全集减去能被任一质因子整除的）
  4. 复杂度：O(2ᵏ)，k 为质因子个数（通常 ≤ 10）

📝 真题精练

真题一：出栈序列计数（卡特兰数）

题目：n 个元素依次入栈，求合法出栈序列数，对 1e9+7 取模

数据范围：n ≤ 10⁵

答案：Hₙ = C(2n, n) × inv(n+1)

// 核心代码
ll solve(int n) {
    return C(2*n, n) * qpow(n+1, MOD-2) % MOD;
}
// 其中 C(n,k) 使用阶乘+逆元 O(1) 查询

真题二：区间容斥计数

题目：求 [a, b] 中能被质数集合 {p₁,...,pₖ} 中至少一个整除的数的个数

数据范围：a,b ≤ 10⁹，k ≤ 10

// 先求 f(x) = [1,x] 中能被至少一个整除的个数（容斥）
// 答案 = f(b) - f(a-1)
ll ans = f(b, primes) - f(a-1, primes);
// f(x) 内部：二进制枚举子集，奇加偶减，注意防溢出

关键注意事项

  • 组合数取模 → MOD 必须为质数，n < MOD
  • 容斥溢出 → 乘积超过 x 时直接跳过（贡献为 0）
  • 卡特兰数 → 分母 (n+1) 在取模下用逆元
