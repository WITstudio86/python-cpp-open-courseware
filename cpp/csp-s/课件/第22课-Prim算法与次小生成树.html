🎯 本课核心

  • Prim vs Dijkstra — 仅一处公式不同（易混淆点）
  • 严格次小生成树 — 枚举非树边 + 树上倍增 + LCA

⚡ 核心思想：Prim 以"选点"构造 MST，次小生成树通过"替换 MST 中的一条边"得到。严格次小需维护路径上最大和严格次大边权。
Prim 朴素实现 — O(V²)
邻接矩阵 · 稠密图首选 · 代码极简

📐 算法思想

维护已选顶点集合 S，初始 S = {1}。每次从 S 到 V\S 的跨越边中选权值最小的边 (u∈S, v∉S)，将 v 加入 S。重复直到 S = V。

💻 核心代码

long long prim_dense(int n, const vector<vector<int>>& g) { const int INF = 0x3f3f3f3f; vector<int> dis(n+1, INF); vector<bool> vis(n+1, false); dis[1] = 0; long long mst = 0; for (int iter = 1; iter <= n; iter++) { int u = -1; for (int j = 1; j <= n; j++) // 找最小 dis if (!vis[j] && (u == -1 || dis[j] < dis[u])) u = j; if (dis[u] == INF) return -1; // 不连通 vis[u] = true; mst += dis[u]; for (int v = 1; v <= n; v++) // 用 u 更新 if (!vis[v] && g[u][v] < dis[v]) dis[v] = g[u][v]; // ← 注意：不是 dis[u]+w } return mst; }
✅ 适用场景：完全图、邻接矩阵输入的稠密图（V ≤ 5000, E ≈ V²）。此时 O(V²) 的常数极小，比 O(E log V) 的堆优化更快。
Prim 堆优化 — O(E log V)
邻接表 + 优先队列 · 稀疏图适用

💻 核心代码

long long prim_heap(int n, const vector<vector<pair<int,int>>>& adj) { const int INF = 0x3f3f3f3f; vector<int> dis(n+1, INF); vector<bool> vis(n+1, false); priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq; dis[1] = 0; pq.push({0, 1}); long long mst = 0; int cnt = 0; while (!pq.empty() && cnt < n) { auto [d, u] = pq.top(); pq.pop(); if (vis[u]) continue; // 懒惰删除 vis[u] = true; mst += d; cnt++; for (auto& [v, w] : adj[u]) if (!vis[v] && w < dis[v]) { dis[v] = w; pq.push({w, v}); } } return (cnt == n) ? mst : -1; }

🔴 Prim 与 Dijkstra 的核心区别

✅ Prim（MST）
dis[v] = min(dis[v], w);

到已选集合的最小边权

✅ Dijkstra（最短路）
dis[v] = min(dis[v], dis[u] + w);

到源点的最短路径和

⚠️ 竞赛血泪教训：两段代码几乎一模一样，仅一行公式不同。抄模板时一定确认是 Prim 还是 Dijkstra！

📐 次小生成树原理

  1. 先求出 MST，记录树边集
  2. 枚举每条非树边 e = (u, v, w)：
  3. 将 e 加入 MST 形成一个环
  4. 从环上去掉一条最大边权的树边 f
  5. 新生成树权值 = mst_weight - w(f) + w(e)
  6. 所有替换方案的最小值即次小生成树
⚠️ 严格 vs 非严格：若 w(e) == w(f)，替换后权值不变。要得到严格更大的生成树，必须去掉严格次大边（而非最大边）。
严格次小生成树 — 倍增预处理
树上倍增 + LCA + 最大/次大边权合并

📐 倍增数组定义

  • up[u][k] — u 的 2^k 级祖先
  • mx[u][k] — u 到 2^k 祖先路径上的最大边权
  • mx2[u][k] — u 到 2^k 祖先路径上的严格次大边权（若无则为 -INF）

💻 四值合并取最大和严格次大

pair<ll, ll> merge_four(const vector<ll>& vals) { ll first = -1e18, second = -1e18; for (ll val : vals) { if (val > first) { second = first; first = val; } else if (val < first && val > second) { second = val; } } return {first, second}; }

💻 DFS 预处理核心

for (int k = 1; k < LOG; k++) { int mid = up[v][k-1]; up[v][k] = up[mid][k-1]; auto [m1, m2] = merge_four({ mx[v][k-1], mx2[v][k-1], mx[mid][k-1], mx2[mid][k-1] }); mx[v][k] = m1; mx2[v][k] = m2; }
复杂度：MST O(E log E) + 倍增 O(V log V) + 枚举非树边查询 O(E log V)。总 O((V+E) log V)。
真题精练
稠密图 MST · 严格次小生成树

📝 例题 1：最短网络 Agri-Net（稠密图 Prim）

  • n ≤ 100（部分数据到 5000），输入为 邻接矩阵
  • 解法：朴素 Prim O(n²)，因为 E = n(n-1)/2，Kruskal 排序 O(n² log n) 太慢
  • 注意：邻接矩阵中 0 表示 i=j，对角线忽略；不存在的边用 INF 标记

📝 例题 2：洛谷 P4180【BJWC2010】严格次小生成树

  • n ≤ 10⁵，m ≤ 3×10⁵，求严格次小生成树
  • 解法：
    1. Kruskal 求 MST，标记树边
    2. DFS 预处理倍增数组（mx, mx2, up, depth）
    3. 枚举非树边，查询路径 max/max2
    4. 若 w > 路径最大 → 替换最大边
    5. 若 w == 路径最大 → 替换路径严格次大边
    6. 取所有候选的最小值
🔑 关键技巧：mx2 初始化为 -1e18（足够小的负无穷），合并四个候选值时正确处理去重逻辑。若找不到严格次大值（mx2 == -INF），则无法通过该非树边得到严格次小生成树。
易错点与优化技巧
竞赛中的常见坑与应对策略

⚠️ 常见错误 Top 6

  1. Prim vs Dijkstra 公式混淆 — 仅 dis 更新一行不同，写错直接 WA
  2. 次小生成树忘记维护 mx2 — 导致无法处理 w == max_w 的情况，严格次小求错
  3. INF 初始值太小 — 边权 1e9，n=1e5，MST 可达 1e14，INF 需 ≥ 1e18
  4. 倍增 LOG 不够大 — n=3e5 时 LOG=20，n=1e5 时 LOG=17 即可
  5. 堆优化 Prim 重复节点入队 — 需 vis 数组懒惰删除，与 Dijkstra 同理
  6. mx2 合并时未正确处理 — 四个候选值取严格次大时不能遗漏候选值

🚀 优化技巧

  • ✅ 稠密图优先朴素 Prim：O(V²) 常数极小，E 大时碾压 Kruskal/堆 Prim
  • ✅ 提取 merge_four 函数：避免多次手写合并逻辑，减少 bug
  • ✅ query 函数支持同时返回 max + max2：一次 LCA 查询获取两个值
  • ✅ MST 边集复用：Kruskal 输出 in_mst 标记 + MST 邻接表，直接供 DFS 使用
  • ✅ 使用 1-indexed：统一编号从 1 开始，减少越界和初始化遗漏
🔴 关键提醒：严格次小生成树如果不存在（所有非树边替换后权值都等于 MST），需特殊判断。题目通常保证存在，但防御性编程应处理无解情况。
