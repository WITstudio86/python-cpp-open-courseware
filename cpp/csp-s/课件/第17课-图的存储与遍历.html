图的基础存储方式

1. 邻接矩阵

int g[MAXN][MAXN]; // g[u][v] = 1 有边 / 0 无边（无权图） // g[u][v] = w 边权为 w（带权图）
操作复杂度
查询边 (u, v)O(1)
遍历 u 的所有邻接点O(V)
空间复杂度O(V²)

❗ 仅适合 n ≤ 1000 的稠密图，稀疏图会内存溢出

2. vector 邻接表（最常用）

vector<int> g[MAXN]; // 无权图 vector<pair<int,int>> g[MAXN]; // 带权图
操作复杂度
查询边 (u, v)O(deg(u))
遍历 u 的所有邻接点O(deg(u))
空间复杂度O(V + E)

链式前向星（Forward Star）

用数组模拟链表，常数最小，适合大规模稀疏图。

核心数据结构

int head[MAXN]; // head[u]：u 的第一条边的编号 int to[MAXM]; // to[i]：第 i 条边的终点 int nxt[MAXM]; // nxt[i]：下一条同起点的边编号 int w[MAXM]; // w[i]：第 i 条边的权值 int cnt = 0; // 边计数器

加边操作（头插法）

void add_edge(int u, int v, int weight) { to[++cnt] = v; w[cnt] = weight; nxt[cnt] = head[u]; head[u] = cnt; }

遍历 u 的所有出边

for (int i = head[u]; i; i = nxt[i]) { int v = to[i], weight = w[i]; // 处理边 (u → v, weight) }
vector 邻接表链式前向星
内存动态分配静态数组
缓存友好一般更好
删除边容易困难
推荐场景日常训练竞赛 + 大数据
⚠️ 无向图记得 MAXM 开 2 倍！每条无向边 = 两条有向边。
【讲解】链式前向星（Forward Star） 本页要点（照着讲即可）： · 用数组模拟链表，常数最小，适合大规模稀疏图。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

图的遍历：DFS 与 BFS

DFS — 深度优先搜索

沿路径尽可能深入，无路可走才回溯。使用栈（递归 / 显式栈）。

void dfs(int u) { vis[u] = true; for (int v : g[u]) if (!vis[v]) dfs(v); }

BFS — 广度优先搜索

按层逐级向外扩展。使用队列，天然得到无权图最短路径。

queue<int> q; q.push(s); vis[s] = true; while (!q.empty()) { int u = q.front(); q.pop(); for (int v : g[u]) if (!vis[v]) { vis[v] = true; q.push(v); } }
维度DFSBFS
数据结构栈（递归/显式）队列
空间O(h)，h=深度O(w)，w=最大宽度
最短路径❌ 不保证✅ 无权图最短
连通性✅✅
拓扑排序✅ 后序遍历✅ Kahn 算法
🔑 关键记忆：DFS 适合"路径探索"（找环、桥、割点），BFS 适合"最短步数"。
【讲解】图的遍历：DFS 与 BFS 结合讲义《模板 1：邻接表 + DFS + BFS》强调： · using namespace std; · const int MAXN = 1e5 + 5; · vector g[MAXN]; · bool vis[MAXN]; · int n, m; 幻灯片上可见要点： · 沿路径尽可能 深入 ，无路可走才回溯。使用栈（递归 / 显式栈）。 · 按层 逐级 向外扩展。使用队列，天然得到无权图最短路径。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

核心模板：连通分量 & 二分图判定

连通分量计数

对每个未访问顶点执行一次遍历，计数器 +1。

int count_comp() { int comp = 0; for (int i = 1; i <= n; i++) if (!vis[i]) { comp++; dfs(i); } return comp; }

二分图判定（染色法）

定理：无奇环 ⇔ 二分图。用 0/1 染色，相邻必须异色。

int color[MAXN]; // -1 未染 bool dfs(int u, int c) { color[u] = c; for (int v : g[u]) { if (color[v] == -1) { if (!dfs(v, c ^ 1)) return false; } else if (color[v] == c) { return false; // 冲突！ } } return true; }
算法时间复杂度空间复杂度
连通分量计数O(V + E)O(V + E)
染色法二分图判定O(V + E)O(V + E)
DFS/BFS 遍历O(V + E)O(V)
【讲解】核心模板：连通分量 & 二分图判定 结合讲义《5. 二分图判定》强调： · 定义：一个图是二分图，当且仅当可以将顶点集划分为两个不相交的集合 $A, B$，使得每条边的两个端点分别属于 $A$ 和 $B$。 · 判定定理：一个图是二分图当且仅当它不包含奇数环。 · 染色法： · 用 0/1 两种颜色给顶点染色。 · 从任意未染色顶点出发，将其染为 0，DFS/BFS 将其邻接点染为相反颜色 1。 幻灯片上可见要点： · 对每个未访问顶点执行一次遍历，计数器 +1。 · 定理： 无奇环 ⇔ 二分图 。用 0/1 染色，相邻必须异色。 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

真题精练

题1：连通分量大小统计

给定 n 个顶点 m 条边的无向图（n ≤ 10⁵, m ≤ 2×10⁵），输出连通分量数 k，以及每个分量的大小。

解法：对每个未访问顶点 BFS/DFS，在遍历过程中用计数器统计该分量大小。O(n+m) 可 AC。

题2：二分图判定

给定 n 顶点 m 边的无向图（n ≤ 10⁵, m ≤ 2×10⁵），判断是否为二分图。输出 "Yes" 或 "No"。

解法：染色法 DFS。color[] 初始化为 -1，从每个未染色顶点出发染 0，邻接点染 1 ^ c。若发现相邻同色则非二分图。
考点常与什么结合
连通分量并查集、最小生成树 Kruskal
二分图判定匈牙利算法（最大匹配）、Kőnig 定理
DFS/BFS拓扑排序、Tarjan 缩点、双连通分量
【讲解】真题精练 本页要点（照着讲即可）： · 给定 n 个顶点 m 条边的无向图（n ≤ 10⁵, m ≤ 2×10⁵），输出连通分量数 k，以及每个分量的大小。 · 给定 n 顶点 m 边的无向图（n ≤ 10⁵, m ≤ 2×10⁵），判断是否为二分图。输出 "Yes" 或 "No"。 练习页节奏：先独立想 1 分钟 → 再点拨思路 → 最后对答案讲为什么。 可联系：图的连通性判定、BFS最短路

易错点与优化技巧

常见错误原因解决方案
DFS 爆栈递归过深（n≤10⁵ 链图）改用迭代栈 / BFS / 增大栈空间
邻接矩阵 MLEn 太大导致 g[n][n] 超内存换用邻接表或链式前向星
BFS 重复入队出队时才标 vis入队时立即标 vis！
color 初值冲突初始化 0 与颜色 0 混淆初始化为 -1，颜色用 0/1
无向图漏反向边只加了单向add(u,v); add(v,u);
链式前向星 size 不足无向图只开 MAXM开 MAXM * 2

优化技巧

  • 输入加速：ios::sync_with_stdio(false); cin.tie(0);
  • BFS 距离：用 memset(dist, -1, sizeof(dist)) 一举两得
  • vector 预分配：已知度时 g[u].reserve(deg[u]) 减少扩容
  • 递归转循环：手动维护栈避免爆栈，尤其在单链图上

本课小结

模块要点
邻接矩阵O(1) 查边，O(V²) 空间，仅适合稠密图
vector 邻接表O(V+E) 空间，最常用，适合稀疏图
链式前向星静态数组，常数最小，竞赛大规模图首选
DFS栈 / 递归，适合路径探索、连通性、染色
BFS队列，天然得到无权图最短路径
连通分量对每个未访问顶点执行一次遍历
二分图判定染色法：相邻异色，同色则非二分图
🎯 CSP-S 应试核心：邻接表 + BFS/DFS 必须能够手写无误。染色法模板是二分图相关题的基础，务必熟练。连通分量常常与并查集互为替代解法。
