一、二进制状态表示法

核心思想

用一个整数的二进制位来表示集合中每个元素的「选 / 不选」状态。

十进制二进制含义（选中元素）
0000空集 {}
1001{0}
3011{0, 1}
5101{0, 2}
7111{0, 1, 2}

常用位运算操作

// 检查第 i 位是否为 1 if (mask & (1 << i)) // 将第 i 位置为 1 / 置为 0 / 翻转 mask |= (1 << i); mask &= ~(1 << i); mask ^= (1 << i); // 统计 1 的个数 (GCC 内置) int cnt = __builtin_popcount(mask); // 最低位 1 的位置 int pos = __builtin_ctz(mask);
适用条件：元素数 n ≤ 20（状态空间 O(2^n)，n=20 时约 100 万状态）
【讲解】一、二进制状态表示法 本页要点（照着讲即可）： · 用 一个整数的二进制位 来表示集合中每个元素的「选 / 不选」状态。 · 一个整数的二进制位 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：二进制状态表示、子集枚举、TSP问题

二、子集枚举技巧

枚举 mask 的所有子集

// 经典 O(3^n) 子集枚举模板 for (int sub = mask; sub; sub = (sub - 1) & mask) { // sub 是 mask 的一个非空子集 // 在此处理 sub... } // 如果需要包含空集：for (int sub = mask; ; sub = (sub-1) & mask)

原理

(sub - 1) & mask 得到「比 sub 小的、且是 mask 子集的最大整数」。

时间复杂度：O(3^n)
每个元素有三种状态：① 不在 mask 中 / ② 在 mask 中但不在 sub 中 / ③ 在 mask 中且在 sub 中
总状态数 = 3^n，是一次枚举所有子集的子集的复杂度。
CSP-S 应用场景：需要枚举上一行的状态来转移时（如「互不侵犯」问题中枚举上一行的所有合法状态）。
【讲解】二、子集枚举技巧 本页要点（照着讲即可）： · (sub - 1) & mask 得到「比 sub 小的、且是 mask 子集的最大整数」。 · 时间复杂度：O(3^n) · CSP-S 应用场景： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

三、TSP 问题（最短Hamilton路径）

状态设计

dp[mask][i] = 已访问 mask 中的点，当前在点 i 的最短路径

核心代码

// 初始化 memset(dp, 0x3f, sizeof(dp)); dp[1 << 0][0] = 0; // 从城市 0 出发 // DP：从小到大枚举 mask for (int mask = 1; mask < (1 << n); mask++) { for (int i = 0; i < n; i++) { if (!(mask & (1 << i))) continue; int prev = mask ^ (1 << i); // 去掉 i 后的集合 for (int j = 0; j < n; j++) { if (!(prev & (1 << j))) continue; dp[mask][i] = min(dp[mask][i], dp[prev][j] + dist[j][i]); } } } // 答案：dp[(1<<n)-1][n-1]

转移方程

dp[mask][i] = min(dp[mask⊕{i}][j] + dist[j][i])

复杂度

O(n² · 2ⁿ)

n=20：约 4×10⁸ 次操作

【讲解】三、TSP 问题（最短Hamilton路径） 本页要点（照着讲即可）： · n=20：约 4×10⁸ 次操作 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
