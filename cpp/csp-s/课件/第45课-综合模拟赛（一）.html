📖 知识回顾 — 数据结构

树状数组（差分）— 区间修改 + 单点查询

核心：维护原数组的差分数组 d[i] = a[i] - a[i-1]

区间加 [l, r] + v → add(l, v)、add(r+1, -v)

单点查询 a[x] → sum(x)（查询差分前缀和）

void range_add(int l, int r, ll v) {
    add(l, v);
    add(r + 1, -v);
}
ll point_query(int x) {
    return sum(x);
}

时间复杂度：O(log n) 每次操作

为什么要用差分？

  • 直接修改区间 O(n) 不可接受（n ≤ 5×10⁵）
  • 差分将"区间修改"转化为"两次单点修改"
  • 配合 BIT 实现 O(log n) 操作

Kruskal 最小生成树

核心：边排序 + 并查集判环，O(m log m)

变种处理：

  • 必须选中的边 → 初始化时直接加入 MST，不计入 Kruskal 选择
  • 禁止选择的边 → 遍历时跳过（用 set 快速检查）

拓扑排序（Kahn 算法）

应用：DAG 判环 + 拓扑序 DP，O(n+m)

  • 入度为零的节点入队 → 出队处理 → 邻接点入度减 1
  • 处理节点数 < n → 存在环
  • 在出队时执行 DP（保证前驱已被处理）

📝 T1：区间操作与查询 [简单]

数据范围：n, m ≤ 5×10⁵

操作 1：1 l r x — 区间 [l, r] 全体加 x
操作 2：2 p — 查询 a[p] 的值

样例：n=5，1 1 3 2、2 2→2，1 2 4 3、2 5→0，2 3→5

解题思路

  • 树状数组维护差分数组：add 向上跳、sum 向下跳
  • 区间修改：add(l, x)、add(r+1, -x)
  • 单点查询：sum(p) — 求差分前缀和

核心代码

int lowbit(int x) { return x & (-x); }
void add(int x, ll v) { while (x <= n) { c[x] += v; x += lowbit(x); } }
ll sum(int x) { ll r = 0; while (x) { r += c[x]; x -= lowbit(x); } return r; }

复杂度：O(m log n)，空间 O(n)

【讲解】📝 T1：区间操作与查询 [简单] 结合讲义《题目1（T1 简单）：区间操作与查询》强调： · 题目描述： · 给定一个长度为 n 的整数数组 a[1..n]，初始时所有元素均为 0。现在有 m 个操作，操作分为两种： · 1 l r x：将区间 [l, r] 内的所有元素增加 x · 2 p：查询 a[p] 当前的值 · 请处理所有操作，并对每个类型 2 的操作输出结果。 幻灯片上可见要点： · 数据范围 ：n, m ≤ 5×10⁵ · 操作 1 ： 1 l r x — 区间 [l, r] 全体加 x 操作 2 ： 2 p — 查询 a[p] 的值 · 样例 ：n=5， 1 1 3 2 、 2 2 →2， 1 2 4 3 、 2 5 →0， 2 3 →5 · 树状数组维护 差分数组 ：add 向上跳、sum 向下跳 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 T2：带限制的最短路 [中等]

n 节点 m 边无向图，边权 w，类型 c∈{0,1}

限制：经过的高速公路（c=1）数量 ≤ k（k ≤ 10）

求：1 到 n 的最小费用，不可达输出 -1

解题思路 — 分层图

将每个节点复制为 k+1 层，第 j 层表示已走 j 条高速

  • 普通路（c=0）：层内走，距离不变层
  • 高速路（c=1）：跨层走，从 j → j+1 层

等价做法：dist[node][used_hw] 作为 Dijkstra 的节点状态

关键代码

// 高速公路：进入下一层
if (c == 1 && hw + 1 <= k && dist[v][hw+1] > d + w) {
    dist[v][hw+1] = d + w;
    pq.push({dist[v][hw+1], v, hw+1});
}

复杂度：O((n·k + m·k) log(n·k)) ≈ O((n+m) log n)

【讲解】📝 T2：带限制的最短路 [中等] 结合讲义《题目2（T2 中等）：带限制的最短路》强调： · 题目描述： · 给定一个 n 个节点 m 条边的**无向**图，每条边有两个属性：(u, v, w, c)，其中 w 是通行费用（权值），c 是边类型（c = 0 表示普通路，c = 1 表示高速公路）。 · 你现在从节点 1 出发，要到达节点 n。你不希望经过超过 k 条高速公路。在所有满足经过高速公路数 ≤ k 的路径中，求最小的通行费用总和。如果不存在这样的路径，输出 -1。 · 输入格式： · 第一行四个整数 n, m, k（1 ≤ n ≤ 10⁵, 1 ≤ m ≤ 2×10⁵, 0 ≤ k ≤ 10）。 幻灯片上可见要点： · n 节点 m 边无向图，边权 w，类型 c∈{0,1} · 限制 ：经过的高速公路（c=1）数量 ≤ k（k ≤ 10） · 求 ：1 到 n 的最小费用，不可达输出 -1 · 将每个节点复制为 k+1 层 ，第 j 层表示已走 j 条高速 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 T3：MST + 特殊条件 [中等]

n 社区 m 条可选道路，每条有修建费用 w

q 对必须直连：这些边必须被选中
p 对禁止直连：这些边不能选中

求：满足条件的最小生成树总费用，不可行输出 -1

解题思路

  • Step 1：初始化并查集，遍历必须边，查找每条的最小费用并加入 MST
  • Step 2：若必须边形成环 → 直接 -1
  • Step 3：对剩余边执行 Kruskal，跳过禁止边
  • Step 4：最终边数 < n-1 → 图不连通 → -1

必须边处理

// 在边集中找 a-b 的最小费用
ll min_w = LLONG_MAX;
for (auto& e : edges)
    if ((e.u==a && e.v==b) || (e.u==b && e.v==a))
        min_w = min(min_w, (ll)e.w);

复杂度：O(m log m)，空间 O(n+m)

【讲解】📝 T3：MST + 特殊条件 [中等] 结合讲义《题目3（T3 中等）：最小生成树 + 特殊条件》强调： · 题目描述： · 某城市有 n 个社区，社区之间可通过道路连接。现在政府计划修建道路，使得任意两个社区之间都能直接或间接通过道路相连（即图连通），且总修建费用最小。 · 但是由于地理条件，有 q 对社区是 **必须直连** 的（即它们之间的边必须被选中），还有 p 对社区是 **禁止直连** 的（即它们之间的边不能被选中）。 · 给定所有可选的道路信息（保证至少包含所有必须直连的边），请你求出满足条件的最小总修建费用。若无法满足条件（如必须直连的边形成环，或剔除禁止边后图无法连通），输出 -1。 · 输入格式： 幻灯片上可见要点： · n 社区 m 条可选道路，每条有修建费用 w · q 对必须直连 ：这些边必须被选中 p 对禁止直连 ：这些边不能选中 · 求 ：满足条件的最小生成树总费用，不可行输出 -1 · Step 1 ：初始化并查集，遍历必须边，查找每条的最小费用并加入 MST 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 T4：拓扑排序 + DP [较难]

n 个任务，耗时 t[i]，m 条依赖边 u→v

求：① 工程最早完成时间（最长路径长度）
      ② 最长路径的方案数（mod 10⁹+7）
      ③ 有环则输出 -1

解题思路

  1. Kahn 拓扑排序判环：若处理节点数 < n，存在环
  2. dp_time[v]：最早完成时间 = max(dp_time[u] + t[v])，其中 u→v
  3. dp_cnt[v]：方案数累计（仅统计最长路径上的前驱）

DP 核心

if (dp_time[v] < dp_time[u] + t[v]) {
    dp_time[v] = dp_time[u] + t[v];  // 找到更长路径
    dp_cnt[v] = dp_cnt[u];           // 重置方案数
} else if (dp_time[v] == dp_time[u] + t[v]) {
    dp_cnt[v] = (dp_cnt[v] + dp_cnt[u]) % MOD;  // 累加
}

复杂度：O(n+m)，空间 O(n+m)

【讲解】📝 T4：拓扑排序 + DP [较难] 结合讲义《题目4（T4 较难）：拓扑排序 + DP》强调： · 题目描述： · 某个工程项目包含 n 个任务，任务之间存在依赖关系（由 m 条有向边表示）。每个任务有一个完成所需的时间 t[i]。 · 工程可以同时进行多个没有依赖关系的任务。求整个工程完成的最短时间（关键路径长度）。此外，求在有向无环图（DAG）的前提下，从开始到结束共有多少条不同的最长路径（方案数可能很大，对 10⁹ + 7 取模）。 · 输入格式： · 第一行两个整数 n 和 m（1 ≤ n ≤ 10⁵, 0 ≤ m ≤ 2×10⁵）。 幻灯片上可见要点： · n 个任务，耗时 t[i]，m 条依赖边 u→v · 求 ：① 工程最早完成时间（最长路径长度） ② 最长路径的方案数（mod 10⁹+7） ③ 有环则输出 -1 · Kahn 拓扑排序判环 ：若处理节点数 < n，存在环 · dp_time[v] ：最早完成时间 = max(dp_time[u] + t[v])，其中 u→v 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

初始化

答案汇总

// 可能有多个终点，汇总所有终点的方案数

  • ⚠ 环的处理：visited < n → 必有环，输出 -1

⚠️ 易错点与优化技巧

树状数组

  • 下标从 1 开始！lowbit(0)=0 死循环
  • 数据范围大用 long long
  • 差分边界：r+1 不能超过 n+1

最短路

  • 优先队列默认大根堆，需 greater<>
  • vis 数组避免重复扩展
  • 多测试数据时初始化 dist 数组

Kruskal

  • 并查集路径压缩（find 函数）
  • 生成树边数 = n-1 的判断
  • 必须边可能有多条，取最小费用

拓扑排序+DP

  • 入度为 0 节点全部入队
  • DP 在拓扑序上进行
  • 方案数取模 1e9+7
  • 多终点汇总方案数
【讲解】⚠️ 易错点与优化技巧 结合讲义《⚠️ 易错点与优化技巧》强调： · 多测试用例时的初始化：务必在每组数据前清空/重置全局数组。对于很大的数组，memset 可能耗时，只初始化实际使用的范围（使用 fill 或循环） · 图的存储方式选择： · 一般优先选 vector>（邻接表），方便遍历 · 链式前向星（head/edge/next）适合超大型图，但代码较繁琐 · 稠密图（m 接近 n²）用邻接矩阵 幻灯片上可见要点： · 下标从 1 开始 ！lowbit(0)=0 死循环 · 数据范围大用 long long · 差分边界：r+1 不能超过 n+1 · 优先队列默认 大根堆 ，需 greater<> 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
