🧮 红黑树原理：5 条性质与插入修复

红黑树的 5 条核心性质

  1. 每个节点要么是红色，要么是黑色
  2. 根节点是黑色
  3. 每个叶子节点（NIL）是黑色
  4. 红色节点的两个子节点必须是黑色（无连续红色）
  5. 任一节点到所有叶子路径上，黑色节点数量相同（黑高相等）
推导：由性质 4 和 5 → 最长路径 ≤ 最短路径 × 2 → 树高 ≤ 2log(n+1) → 保证 O(log n)

插入修复：Case 1-3（父为祖父左子时）

Case条件修复
1叔叔为红色颜色翻转：父叔变黑，祖父变红；递归向上
2叔叔黑色，新节点右孩子左旋转为 Case 3
3叔叔黑色，新节点左孩子右旋 + 颜色翻转；修复完成

每次插入最多 2 次旋转（Case 2 + Case 3）→ 非常高效！

为什么 C++ 选红黑树而非 AVL？STL 容器频繁 insert/erase，红黑树最多 3 次旋转即可完成删除修复，而 AVL 可能需要 O(log n) 次旋转向上回溯。

💻 代码模板：自定义比较器与哈希

方法一：函数对象（Functor）

struct CmpByLen {
    bool operator()(const string& a, const string& b) const {
        if (a.size() != b.size()) return a.size() < b.size();
        return a < b;
    }
};
set<string, CmpByLen> s;
map<string, int, CmpByLen> mp;

方法二：Lambda 表达式（C++11 + decltype）

auto cmp = [](int a, int b) { return a > b; };
set<int, decltype(cmp)> s(cmp);  // 必须传 lambda 给构造函数

自定义哈希（pair<int,int>）

struct PairHash {
    size_t operator()(const pair<int,int>& p) const {
        auto h1 = hash<int>{}(p.first);
        auto h2 = hash<int>{}(p.second);
        // hash_combine: 黄金比例 + 移位，避免 (1,2) 与 (2,1) 冲突
        return h1 ^ (h2 + 0x9e3779b9 + (h1 << 6) + (h1 >> 2));
    }
};
unordered_map<pair<int,int>, int, PairHash> ump;
ump.reserve(100000);  // 预分配 bucket，终极优化

⚠️ 易错点与优化技巧

6 大常见错误

  1. map 的 operator[] 意外插入元素 — 只想检查存在性？用 find() 或 count()
  2. set 迭代器无法修改元素 — set<T>::iterator 即 const_iterator
  3. rehash 使 unordered 迭代器全部失效 — 预 reserve 避免 rehash
  4. 自定义哈希质量差 — 所有 key 映射到同一桶 → 退化为链表 O(n)
  5. 忘记为自定义类型提供 operator< — 用于 set/map 的红黑树排序
  6. 对 unordered 容器调用 lower_bound — 不存在此方法，编译错误

性能优化速查

🔑 竞赛黄金法则：
✅ ump.reserve(n) — 最廉价的哈希表优化，速度提升 2-5×
✅ mp.emplace(key, val) — 比 insert({key, val}) 少一次临时对象
✅ set(v.begin(), v.end()) — 一步完成排序 + 去重
✅ mp.lower_bound(x) — 范围查询，哈希表做不到
平衡树 vs 哈希表选择口诀：有序遍历用 map，范围查询用 map，纯查找用 unordered_map，不确定时用 map（保底 O(log n)）。

📝 真题精练

真题一：区间覆盖查询（map + 差分）

n 个 ADD [l, r] 操作和 QUERY x 操作，查询某点被多少个区间覆盖。坐标范围 10⁹，操作数 ≤ 2×10⁵。

// 核心思路：用 map 维护差分数组（处理稀疏大坐标）
map<int, int> diff;
for (auto& [l, r] : adds) {
    diff[l]++;          // 差分起点 +1
    diff[r+1]--;       // 差分终点 -1
}
// 查询：前缀和累加到 ≤ x 即可得到覆盖数

复杂度：O(n log n) 时间（每次 map 操作 O(log n)），O(n) 空间。

关键技巧：用 map 而非大数组处理 10⁹ 量级的稀疏坐标，map 自动排序保证前缀和累加的顺序正确。

真题二：前 K 高频单词（unordered_map + sort）

给定 n 个单词，找出频率前 k 高的单词。频率相同时按字典序升序。n ≤ 10⁵。

unordered_map<string, int> freq;
freq.reserve(n);   // ① 预分配，避免 rehash
for (auto& w : words) freq[w]++;

vector<pair<string,int>> v(freq.begin(), freq.end());
sort(v.begin(), v.end(), [](auto& a, auto& b) {
    if (a.second != b.second) return a.second > b.second; // ② 频率降序
    return a.first < b.first;  // ③ 字典序升序
});
// 输出前 k 个

复杂度：O(n log n) 时间，O(n) 空间。若用 nth_element 可优化到 O(n + k log k)。
