01背包与完全背包

动态规划核心模型 —— 从二维到一维，从逆序到正序

01背包 完全背包 恰好装满 方案数 字典序最小方案

前置知识：动态规划基础 (DP)  |  适用级别：CSP-S / NOIP 提高组

01背包问题定义

问题描述：有 N 件物品和一个容量为 V 的背包。 第 i 件物品的重量为 w[i]，价值为 v[i]。 每件物品最多只能选择一次（要么选，要么不选）。 求解：在总重量不超过 V 的前提下，最大总价值是多少？

状态定义

dp[i][j]：考虑前 i 件物品，总重量不超过 j 时，所能获得的最大价值。

决策分析

对于第 i 件物品，只有两种选择：

  • 不选：dp[i][j] = dp[i-1][j]
  • 选：（需 j ≥ w[i]）dp[i][j] = dp[i-1][j-w[i]] + v[i]

状态转移方程

dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])
边界条件
dp[0][j] = 0（0件物品）
dp[i][0] = 0（容量为0）
答案
dp[N][V]
复杂度
时间：O(N × V)
空间：O(N × V)

01背包 —— 二维DP实现

核心代码

// 物品编号从 1 到 N，w[1..N], v[1..N]
vector<vector<int>> dp(N + 1, vector<int>(V + 1, 0));

for (int i = 1; i <= N; i++) {
    for (int j = 0; j <= V; j++) {
        dp[i][j] = dp[i-1][j];  // 不选
        if (j >= w[i]) {
            dp[i][j] = max(dp[i][j], dp[i-1][j-w[i]] + v[i]);
        }
    }
}
// 答案：dp[N][V]
维度复杂度
时间O(N × V)
空间O(N × V) ⚠ 当 N、V 达 10⁴ 时内存不足
优化动机：观察递推公式，计算第 i 行时只依赖第 i-1 行， 与更早的行无关 → 可以用滚动数组将空间优化到 O(V)！

01背包 —— 一维优化 & 逆序原理

一维状态转移

// ===== 01背包：一维滚动数组 =====
vector<int> dp(V + 1, 0);

for (int i = 1; i <= N; i++) {
    for (int j = V; j >= w[i]; j--) {  // ← 必须逆序！
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
// 答案：dp[V]   空间复杂度：O(V)
为什么必须逆序遍历？
  • dp[j] = max(dp[j], dp[j-w[i]] + v[i]) 中，右边的 dp[j-w[i]] 必须是上一轮（i-1）的旧值
  • 逆序时：计算 j 大的先更新，j-w[i]（更小）尚未被本轮覆盖 → 保留了旧值 ✔
  • 正序时：j-w[i] 可能已被本轮更新 → 物品被重复使用 → 退化为完全背包 ✘

图解：逆序 vs 正序（w=4, v=5, V=10）

[逆序 j: 10 → 4] j=10: dp[10]=max(dp[10]=0, dp[6]=0 +5) = 5 ← dp[6]还是旧值 j=9: dp[9] =max(dp[9]=0, dp[5]=0 +5) = 5 ← dp[5]还是旧值 j=8: dp[8] =max(dp[8]=0, dp[4]=0 +5) = 5 ← dp[4]还是旧值 ... 物品用了1次，正确！✓ [正序 j: 4 → 10]（错误！） j=8: dp[8] =max(dp[8]=0, dp[4]=5 +5) = 10 ← dp[4]已更新！ j=10: dp[10]=max(dp[10]=0, dp[6]=5 +5) = 10 ← 物品被用了2次！ 物品被重复使用了！✘

记忆口诀：零逆完正 —— 01背包用逆序，完全背包用正序

完全背包 —— 正序原理

问题定义

与01背包相同，但每件物品可以选任意多次（0次、1次、2次……），只要总重量不超过V。

一维状态转移（正序）

// ===== 完全背包：一维正序遍历 =====
vector<int> dp(V + 1, 0);

for (int i = 1; i <= N; i++) {
    for (int j = w[i]; j <= V; j++) {  // ← 正序遍历！
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
// 答案：dp[V]   时间 O(NV)  空间 O(V)
为什么正序遍历就允许重复选？
正序时，dp[j-w[i]] 在本轮中可能已经被更新过，已经包含了物品 i。 在此基础之上再加一件物品 i，相当于物品 i 被使用了多次 —— 这正是完全背包所允许的。

图解：正序实现无限次（w=2, v=3, V=6）

w=2, v=3, 正序遍历 j=2: dp[2] = max(dp[2], dp[0]=0+3) = 3 ← 1件 j=3: dp[3] = max(dp[3], dp[1]=0+3) = 3 j=4: dp[4] = max(dp[4], dp[2]=3+3) = 6 ← 2件（dp[2]已含1件） j=5: dp[5] = max(dp[5], dp[3]=3+3) = 6 j=6: dp[6] = max(dp[6], dp[4]=6+3) = 9 ← 3件（dp[4]已含2件） 最终 dp[6]=9，物品被使用了3次，正确！✓
01背包完全背包
每件使用次数最多1次无限次
遍历顺序逆序 V→w[i]正序 w[i]→V
依赖上一轮旧值允许本轮新值

恰好装满 —— 初始化技巧

问题变体

求恰好装满容量 V 的最大价值（而非"不超过 V"）。

初始化方法

vector<int> dp(V + 1, -INF);  // 初始化为负无穷
dp[0] = 0;  // ← 关键：容量0可以恰好装满（一件都不装）

// 其余代码不变，仍按 逆序(01背包) 或 正序(完全背包) 遍历
为什么这样初始化？
  • dp[0]=0：容量为0时，"恰好装满"所需重量为0，是合法状态
  • dp[1..V]=-INF：其他容量暂时无法恰好装满，标记为非法
  • 转移时 dp[j-w[i]] + v[i] 若来自非法状态，结果仍为极小的负数
  • 只有从 dp[0]=0 出发、通过合法转移到达的状态才会被赋有效值

判断是否存在方案

if (dp[V] < 0) {
    cout << "无法恰好装满" << endl;
} else {
    cout << dp[V] << endl;
}

求方案数——另一种初始化

// 恰好装满的方案数
vector<int> dp(V + 1, 0);
dp[0] = 1;  // 空背包算1种方案

// 01背包求方案数（逆序）：
for (int i = 1; i <= N; i++)
    for (int j = V; j >= w[i]; j--)
        dp[j] = (dp[j] + dp[j-w[i]]) % MOD;

// 完全背包求方案数（正序）：
for (int i = 1; i <= N; i++)
    for (int j = w[i]; j <= V; j++)
        dp[j] = (dp[j] + dp[j-w[i]]) % MOD;

真题精练

真题1：采药（NOIP2005 普及组）

题目：T 时间，M 株草药。每株需要 time[i] 时间，有 value[i] 价值。 每株只能采一次，求最大总价值。
本质：标准01背包 —— 容量 = T，重量 = 时间，价值 = 草药价值。
样例：T=70, M=3，草药：(71,100)、(69,1)、(1,2) → 输出 3

真题2：装箱问题（最小剩余容量）

题目：箱子容量 V，n 个物品各有体积。求装入后箱子的最小剩余空间。
本质：01背包变体 —— w[i] = v[i] = 体积（体积既是重量也是价值）。
答案：V - dp[V]
样例：V=24，物品体积 8,3,12,7,9,7 → 选 8+7+9=24 → 剩余 0

装箱问题 AC 代码

// w[i] = 物品体积（重量=价值=体积）
vector<int> dp(V + 1, 0);

for (int i = 1; i <= n; i++) {
    for (int j = V; j >= w[i]; j--) {
        dp[j] = max(dp[j], dp[j-w[i]] + w[i]);
    }
}
int minRemain = V - dp[V];  // 最小剩余空间
cout << minRemain << endl;

字典序最小方案

使用二维DP记录 g[i][j]（是否选了物品 i），从 (N, V) 回溯： 对 i = N → 1，若选了则加入答案，最终 reverse 输出。

本课小结

01背包 dp[j] = max(dp[j], dp[j-w[i]]+v[i])
遍历顺序：逆序 (V → w[i])
完全背包 dp[j] = max(dp[j], dp[j-w[i]]+v[i])
遍历顺序：正序 (w[i] → V)
逆序原理 确保 dp[j-w[i]] 来自上一轮（旧值）
→ 每件物品最多用一次
正序原理 允许 dp[j-w[i]] 来自本轮（可能已含该物品）
→ 实现物品无限次使用
恰好装满 dp[0] = 0, dp[1..V] = -INF
→ 未装满状态自动被排除
求方案数 dp[0] = 1
dp[j] = (dp[j] + dp[j-w[i]]) % MOD
装箱问题（变体） w[i] = v[i] = 体积
答案 = V - dp[V]
字典序最小方案 二维DP + 记录表 g[i][j]
从 (N,V) 回溯 → reverse 输出
核心口诀：零逆完正
01背包（零）用逆序，完全背包（完）用正序。

掌握了这两个基础模型，多重背包、分组背包、混合背包等变体都可以迎刃而解。
