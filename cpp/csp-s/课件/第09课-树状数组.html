📖 知识精讲 — 核心概念

什么是 lowbit？

lowbit(x) = x & (-x) — 取出 x 二进制最低位的 1

例如：lowbit(6) = 2（6 = 110₂，最低位 1 在 2¹ 位置）

BIT 的存储结构

c[i] 维护区间 [i - lowbit(i) + 1, i] 上的元素和

c[1] → a[1] c[2] → a[1] + a[2] c[3] → a[3] c[4] → a[1] + a[2] + a[3] + a[4] c[5] → a[5] c[6] → a[5] + a[6] c[7] → a[7] c[8] → a[1] + a[2] + a[3] + a[4] + a[5] + a[6] + a[7] + a[8]

每个区间的长度 = lowbit(i)，c[i] 恰好覆盖了长度为 lowbit(i) 的一段

【讲解】📖 知识精讲 — 核心概念 本页要点（照着讲即可）： · lowbit(x) = x & (-x) — 取出 x 二进制最低位的 1 · 例如： lowbit(6) = 2 （6 = 110₂，最低位 1 在 2¹ 位置） · c[i] 维护区间 [i - lowbit(i) + 1, i] 上的元素和 · 每个区间的长度 = lowbit(i) ，c[i] 恰好覆盖了长度为 lowbit(i) 的一段 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：单点修改区间查询、区间修改单点查询、二维树状数组

📖 知识精讲 — 核心操作

单点修改 add(x, v)

修改 a[x] 后，需要更新所有覆盖 x 的 c 节点：

x → x + lowbit(x) → x + lowbit(x) + lowbit(...) 持续向上跳

前缀查询 sum(x)

求 a[1..x] 的和，从 x 出发持续去掉最低位：

x → x - lowbit(x) → x - lowbit(x) - lowbit(...) 持续向下跳

区间查询

sum[l, r] = sum(r) - sum(l - 1)

示例：查询 sum(7)

sum(7) = c[7] + c[6] + c[4]
7 (111₂) → 6 (110₂) → 4 (100₂) → 0

【讲解】📖 知识精讲 — 核心操作 本页要点（照着讲即可）： · 修改 a[x] 后，需要更新所有 覆盖 x 的 c 节点： · x → x + lowbit(x) → x + lowbit(x) + lowbit(...) 持续向上跳 · 求 a[1..x] 的和，从 x 出发持续去掉最低位： · x → x - lowbit(x) → x - lowbit(x) - lowbit(...) 持续向下跳 · sum[l, r] = sum(r) - sum(l - 1) · sum(7) = c[7] + c[6] + c[4] 7 (111₂) → 6 (110₂) → 4 (100₂) → 0 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

💻 代码模板 — 差分 BIT 与逆序对

差分 BIT（区间修改 + 单点查询）

// 区间 [l, r] 全部加 v
void range_add(int l, int r, int v) {
    add(l, v);
    add(r + 1, -v);
}

// 单点查询 a[x] → 查询差分数组前缀和
int point_query(int x) {
    return sum(x);
}

逆序对计数

// 从右向左遍历，BIT 维护已访问元素的出现次数
long long ans = 0;
for (int i = n - 1; i >= 0; i--) {
    ans += sum(a[i] - 1);  // 比 a[i] 小的、已在右边的元素
    add(a[i], 1);
}

⚠️ 易错点与优化技巧

  • ⚠ 下标从 1 开始 — lowbit(0) = 0 会导致死循环！
  • ⚠ 数据溢出 — n ≤ 5×10⁵ 时使用 long long
  • ⚠ 离散化 — 值域很大时必须先离散化再使用 BIT
  • ✔ 树状数组 vs 线段树 — BIT 常数仅为线段树的 1/5~1/3
  • ✔ 能用 BIT 不用线段树 — 代码量少、常數小、不易出错
  • ✔ 二维 BIT 谨慎 — n,m ≤ 2000 才安全，否则 MLE
  • ✔ 倍增求第K小 — O(log n) 替代二分+前缀和的 O(log² n)
【讲解】⚠️ 易错点与优化技巧 结合讲义《⚠️ 易错点与优化技巧》强调： · 下标从 1 开始：树状数组要求下标从 1 开始（因为 lowbit(0) = 0 会死循环），务必注意 · 数据范围：CSP-S 题目中 n 通常 ≤ 5×10⁵，使用 long long 防止溢出 · 离散化：值域很大时必须离散化，逆序对问题时注意重复元素处理 · 二维树状数组的空间：O(n×m)，谨慎开数组。n,m ≤ 2000 时才安全 · 单点查询 vs 区间修改：区间修改单点查询使用差分思想，注意差分边界处理 幻灯片上可见要点： · ⚠ 下标从 1 开始 — lowbit(0) = 0 会导致死循环！ · ⚠ 数据溢出 — n ≤ 5×10⁵ 时使用 long long · ⚠ 离散化 — 值域很大时必须先离散化再使用 BIT · ✔ 树状数组 vs 线段树 — BIT 常数仅为线段树的 1/5~1/3 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 真题精练

真题一：逆序对计数（排列版）

数据范围：n ≤ 5×10⁵，a 为 1..n 的排列

从右向左遍历，BIT 维护已访问元素的出现次数，
对每个 a[i]，查询 sum(a[i]-1) 即为逆序对贡献

时间复杂度：O(n log n)，空间：O(n)

真题二：二维矩阵操作

数据范围：n, m ≤ 1000，操作数 q ≤ 10⁵

支持单点修改和子矩阵求和，
利用二维 BIT 的前缀和思想与容斥原理

时间复杂度：O(q · log n · log m)

🎯 本课小结

核心函数

lowbit(x) — x & (-x)

add(x, v) — 向上跳，修改

sum(x) — 向下跳，查询

高级应用

差分 BIT — 区间修改

二维 BIT — 矩阵操作

逆序对 — 离散化 + BIT

第 K 小 — 倍增查找

复杂度

所有操作：O(log n)

二维操作：O(log n · log m)

常见错误

下标从 0 开始

int 溢出未用 long long

未离散化直接 BIT

lowbit 写成宏忘记加括号
