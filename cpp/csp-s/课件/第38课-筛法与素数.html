一、素数判定：从 O(√n) 到 6k±1 优化

朴素试除法 O(√n)

bool isPrime(int n) { if (n < 2) return false; for (int i = 2; i*i <= n; i++) if (n % i == 0) return false; return true; }

从 2 到 √n 逐一试除，简单可靠

6k±1 优化

原理：所有大于 3 的素数都可表示为 6k ± 1

只需试除 2、3 和 6k±1 形式的数，
常数优化约 3 倍

bool isPrimeFast(int n) { if (n < 2) return false; if (n <= 3) return true; if (n%2==0 || n%3==0) return false; for (int i=5; i*i<=n; i+=6) if (n%i==0 || n%(i+2)==0) return false; return true; }
注意：试除法仅适用于单点判定（n ≤ 1012）。 大规模筛素数需使用筛法。

二、埃拉托色尼筛法（埃氏筛）O(n log log n)

算法思想：从 2 开始，标记每个素数的所有倍数为合数

步骤演示 (n=30)：


代码实现

int eratosthenes(int n) { fill(isPrime, isPrime+n+1, true); isPrime[0] = isPrime[1] = false; int cnt = 0; for (int i=2; i<=n; i++) { if (isPrime[i]) { cnt++; // 从 i*i 开始标记（优化） if ((ll)i*i <= n) for (int j=i*i; j<=n; j+=i) isPrime[j] = false; } } return cnt; }

关键优化：内层从 i² 开始（2i 到 (i-1)i 已被更小的素数筛过）

时间复杂度：调和级数 Σ(n/p) ≈ n ln ln n

n=106 时约 78498 个素数，埃氏筛约 0.1 秒即可完成。

三、欧拉筛（线性筛）O(n) — 重点算法

核心思想：每个合数只被其最小质因子筛掉一次

算法流程：

  1. 维护 primes[] 素数列表
  2. 遍历 i = 2..n：若为素数则加入列表
  3. 对每个素数 p = primes[j]：
    • 标记 i×p 为合数
    • 若 i % p == 0，立即 break
为什么 break？
i % p == 0 说明 p 是 i 的最小质因子。
对于更大的素数 p'，i×p' 的最小质因子仍是 p，
应在后面由 p 筛掉，现在跳过以保证每个合数只被筛一次。
int primes[MAXN], cnt = 0; int eulerSieve(int n) { fill(isPrime, isPrime+n+1, true); isPrime[0] = isPrime[1] = false; for (int i=2; i<=n; i++) { if (isPrime[i]) primes[cnt++] = i; for (int j=0; jint p = primes[j]; if ((ll)i * p > n) break; isPrime[i * p] = false; // 关键！p 是 i 的最小质因子 if (i % p == 0) break; } } return cnt; }

复杂度分析：

项目欧拉筛埃氏筛
时间O(n)O(n log log n)
空间O(n)O(n)
常熟略大较小

四、区间筛：大范围、小间距

问题场景：b 很大（如 1012）但 b-a 较小（如 106）

策略：

  1. 先用欧拉筛求出 [2, √b] 的所有素数
  2. 用这些素数去筛 [a, b] 区间内的合数
  3. 统计区间内未被标记的数

技巧：向上取整

start = ceil(a / p) * p = (a + p - 1) / p * p

但不能小于 p²（更小的倍数已在筛 sqrt(b) 时处理）

ll segmentSieve(ll a, ll b) { ll limit = sqrt(b); int cnt = eulerSieve(limit); vector<bool> isSeg(b-a+1, true); if (a == 1) isSeg[0] = false; for (int i=0; ill p = primes[i]; if (p * p > b) break; ll start = max(p*p, (a+p-1)/p * p); for (ll j = start; j <= b; j += p) isSeg[j - a] = false; } ll ans = 0; for (ll i=a; i<=b; i++) if (isSeg[i-a]) ans++; return ans; }
例题：求 [1011, 1011+100] 区间的素数个数。
复杂度：O((b-a) log log √b + √b)，可轻松处理。

五、欧拉函数 φ(n) 与线性筛求欧拉函数

定义与公式

φ(n)：小于 n 且与 n 互质的正整数个数。

φ(n) = n · ∏p|n (1 - 1/p)

性质：

  • 质数：φ(p) = p - 1
  • 积性：gcd(a,b)=1 → φ(ab) = φ(a)φ(b)
  • 质数幂：φ(pk) = pk - pk-1
  • 求和：Σd|n φ(d) = n

线性筛同时求 φ(1..n)

在欧拉筛的过程中，利用积性递推：

void eulerSieveWithPhi(int n) { fill(isPrime, isPrime+n+1, true); phi[1] = 1; int cnt = 0; for (int i=2; i<=n; i++) { if (isPrime[i]) { primes[cnt++] = i; phi[i] = i - 1; // 质数 } for (int j=0; jint p = primes[j]; if (i*p > n) break; isPrime[i*p] = false; if (i % p == 0) { phi[i*p] = phi[i] * p; // p|i break; } else phi[i*p] = phi[i] * (p-1); // p⊥i } } }

关键区分：

  • p | i → φ(i·p) = φ(i) · p
  • p ⟂ i → φ(i·p) = φ(i) · (p-1)
