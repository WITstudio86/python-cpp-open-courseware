CSP-S 提高组 · 基础优化技巧


一维前缀和 二维前缀和 差分数组 二维差分 DP优化 差分约束


前缀和与差分是竞赛中最基础也是最实用的优化技巧。它们能将区间查询和修改从 O(n) 降到 O(1)，是处理大规模数据时的重要武器。

1. 一维前缀和

定义

pre[0] = 0
pre[i] = pre[i-1] + a[i]   (1 ≤ i ≤ n)

区间和查询 — O(1)

sum(l, r) = pre[r] - pre[l-1]

核心代码

// 构建前缀和（输入 a 为 0-indexed，pre 为 1-indexed）
vector<ll> build_prefix(const vector<ll>& a) {
    int n = a.size();
    vector<ll> pre(n + 1, 0);
    for (int i = 1; i <= n; ++i)
        pre[i] = pre[i - 1] + a[i - 1];
    return pre;
}

// 区间和查询（l, r 为 1-indexed）
ll range_sum(const vector<ll>& pre, int l, int r) {
    return pre[r] - pre[l - 1];
}
构建时间O(n)
每次查询O(1)
空间O(n)
核心思想：「预处理换时间」— 一次性 O(n) 构建，后续每次区间查询只需 O(1)。

2. 二维前缀和

递推公式（容斥原理）

pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j]

子矩阵和查询

以 (x1,y1) 为左上角、(x2,y2) 为右下角：

sum = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1]
┌──────────────────────────────┐ │ pre[x2][y2] │ ← 整个大矩形 │ ┌──────────┐ │ │ │ 目标区域 │ │ = 大矩形 - 上 - 左 + 左上 │ └──────────┘ │ （容斥：多减的补回来） └──────────────────────────────┘

核心代码

// 构建二维前缀和
vector<vector<ll>> build_prefix2d(const vector<vector<ll>>& a) {
    int n = a.size(), m = a[0].size();
    vector<vector<ll>> pre(n+1, vector<ll>(m+1, 0));
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j)
            pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i-1][j-1];
    return pre;
}

ll rect_sum(..., int x1, int y1, int x2, int y2) {
    return pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1];
}
构建时间O(n×m)
每次查询O(1)
空间O(n×m)

3. 一维差分数组

核心思想

对区间进行 O(1) 修改，最后 O(n) 还原。差分数组 d 满足：原数组 a 是 d 的前缀和。

区间修改操作

对 [l, r] 每个元素加 val：

d[l] += val
d[r+1] -= val

完整代码

// 区间加（l, r 为 1-indexed）
void range_add(vector<ll>& d, int l, int r, ll val) {
    d[l] += val;
    d[r + 1] -= val;
}

// 还原：对差分数组求前缀和
vector<ll> restore(const vector<ll>& d, int n) {
    vector<ll> a(n);
    ll cur = 0;
    for (int i = 1; i <= n; ++i) {
        cur += d[i];
        a[i - 1] = cur;
    }
    return a;
}
示例：初始全 0 → [2,4]+3 → [3,5]+2 → 还原 差分: [0, 0, 0, 0, 0] → [0, +3, 0, 0, -3] → [0, +3, +2, 0, -3] 还原: [0, 0, 0, 0, 0] → [0, 3, 3, 3, 0] → [0, 3, 5, 5, 2] ✓
每次区间修改O(1)
最终还原O(n)
适用场景离线批量修改

4. 二维差分数组

子矩阵加 O(1)

对以 (x1,y1) 为左上角、(x2,y2) 为右下角的子矩阵所有元素加 val：

d[x1][y1] += val
d[x2+1][y1] -= val
d[x1][y2+1] -= val
d[x2+1][y2+1] += val

代码实现

// 子矩阵加（坐标均为 1-indexed）
void rect_add(vector<vector<ll>>& d,
              int x1, int y1, int x2, int y2, ll val) {
    d[x1][y1]         += val;
    d[x2+1][y1]       -= val;
    d[x1][y2+1]       -= val;
    d[x2+1][y2+1]     += val;
}

// 还原：对 d 原地求二维前缀和
void restore2d(vector<vector<ll>>& d, int n, int m) {
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j)
            d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1];
}
记忆技巧：二维差分就是二维前缀和的逆运算。修改时四个角的操作符号按「左上 +、右上 -、左下 -、右下 +」记忆（与二维前缀和查询的符号一致）。

5. 前缀最值优化DP

前缀和视角的最大子段和

子段 [l, r] 的和 = pre[r] - pre[l-1]

最大子段和 = maxr( pre[r] - minl≤r pre[l-1] )

维护一个「前缀最小值」，在线性时间内求出答案。

ll max_subarray_prefix(const vector<ll>& a) {
    ll pre = 0;          // 当前前缀和
    ll min_pre = 0;      // 当前遇到的最小前缀和
    ll ans = LLONG_MIN;
    for (ll x : a) {
        pre += x;
        ans = max(ans, pre - min_pre);
        min_pre = min(min_pre, pre);
    }
    return ans;
}

推广：前缀最值消除内层循环

很多DP转移形如：dp[i] = max_{j < i} { dp[j] + w(i, j) }

当 w 可拆分为仅与 i 和仅与 j 相关的部分时，维护 dp[j] + f(j) 的前缀最值，将内层循环从 O(n) 优化到 O(1)。

常见套路：
• 前缀最小值：用于"最小前缀和"类问题
• 前缀最大值：用于"最大递推"类问题
• 区间DP配合前缀和：O(1) 查询区间和来加速转移

6. 真题精练

真题1：区间修改与查询

长度为 n 的全 0 数组，m 次区间 +1。求最终数组的最大值。

n,m ≤ 1e5

// 差分 O(1) 修改 + O(n) 还原
vector<int> d(n + 2, 0);
while (m--) {
    int l, r; cin >> l >> r;
    d[l] += 1; d[r + 1] -= 1;
}
int cur = 0, ans = 0;
for (int i = 1; i <= n; ++i) {
    cur += d[i];
    ans = max(ans, cur);
}
cout << ans << "\n";

复杂度：O(n+m) 时间，O(n) 空间。


真题2：二维前缀和查询

n×n 矩阵（n ≤ 1000），q 次查询子矩阵和（q ≤ 1e5）。

预处理 O(n²) + 查询 O(1)

先 O(n²) 构建二维前缀和，后续每次查询 O(1) 回答。

总复杂度：O(n² + q)。若每次暴力求和则为 O(q×n²)，差距巨大。

核心思想总结：
1. 前缀和 = 预处理换时间：区间查询从 O(n) 降到 O(1)
2. 差分数组 = 离线批量处理：区间修改从 O(n) 降到 O(1)
3. 容斥原理是二维前缀和/差分的核心，画图辅助理解
4. 前缀最值可以消除DP内层循环，是常见的 O(n²)→O(n) 优化手段
5. 下标从 1 开始是竞赛中的常用约定，可以简化边界处理
常见错误提醒：
  • 前缀和下标混乱（0-indexed 输入 vs 1-indexed pre）
  • 二维容斥公式符号写反
  • 差分数组 r+1 越界（多开 1~2 位）
  • 累加时 int 溢出（使用 long long）
