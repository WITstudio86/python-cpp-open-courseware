一、输入输出优化

为什么需要 I/O 优化？

在 CSP-S 中，部分题目输入量巨大（n 可达 10⁶+）。默认 cin/cout 因与 C 标准 I/O 同步及频繁刷新缓冲区，I/O 耗时可能超过算法本身。

方法读取 10⁷ 个整数耗时（约）使用场景
cin（默认）~2.0s小数据量
cin（解同步）~0.8s一般场景
scanf~0.9sC 风格
快速读入~0.3s极限数据量

方案一：解同步（推荐首选）

int main() { ios::sync_with_stdio(false); cin.tie(nullptr); // 之后使用 cin/cout，不要混用 scanf/printf }

方案二：快速读入（极限优化）

inline int read() { int x = 0, f = 1; char ch = getchar(); while (ch < '0' || ch > '9') { if (ch == '-') f = -1; ch = getchar(); } while (ch >= '0' && ch <= '9') { x = x * 10 + (ch ^ 48); ch = getchar(); } return x * f; }
重要提醒：解同步后不能混用 cin/cout 和 scanf/printf！输出时用 '\n' 替代 endl（endl 会额外调用 flush）。

lowbit 原理与树状数组

lowbit(x) = x & (-x) — 返回 x 最低位的 1 所代表的值。
示例：x=12 (1100₂) → lowbit = 4 (100₂)   |   x=7 (0111₂) → lowbit = 1
树状数组的核心就是 lowbit：idx += idx & -idx（向上更新）和 idx -= idx & -idx（向下查询）

快速幂：二进制拆分 O(log n)

ll qpow(ll a, ll b, ll mod) { ll res = 1; a %= mod; while (b) { if (b & 1) res = res * a % mod; a = a * a % mod; b >>= 1; } return res; }

原理：a¹³ = a^(1101₂) = a⁸ · a⁴ · a¹ — 指数按二进制位拆分

⚠️ 优先级陷阱：&、|、^ 优先级低于 ==！
错误：if (x & 1 == 0)   |   正确：if ((x & 1) == 0)

三、搜索剪枝策略

三大剪枝策略

策略 定义 N皇后问题应用示例
可行性剪枝 当前状态不可能到达目标 → 回溯 列已占用 → 不可放；对角线已占用 → 不可放
最优性剪枝 当前代价已超过最优解 → 回溯 （N皇后是计数问题，不求最优）
顺序性剪枝 通过规定搜索顺序减少重复 按行搜索（每行必放一个）代替逐格搜索

数组标记剪枝（方案1）

void dfs(int r) { if (r == n) { ans++; return; } for (int c = 0; c < n; c++) { if (col[c] || diag1[r+c] || diag2[r-c+n]) continue; // 可行性剪枝 col[c] = diag1[r+c] = diag2[r-c+n] = true; dfs(r + 1); col[c] = diag1[r+c] = diag2[r-c+n] = false; } }

位运算优化剪枝（方案2）

void dfs(int r, int col, int d1, int d2) { if (r == n) { ans++; return; } int avail = full & ~(col|d1|d2); while (avail) { int pos = avail & -avail; // lowbit avail -= pos; dfs(r+1, col|pos, (d1|pos)<<1, (d2|pos)>>1); } }
剪枝效果（N皇后实测）： N=14 时，数组剪枝约 0.8s，位运算版约 0.15s — 加速比约 5 倍！
位运算版将所有合法性判断合并为一条 full & ~(col|d1|d2) 指令，CPU 级别并行。

真题2：采药问题（0-1背包 - 记忆化搜索）

T(≤1000) 时间，M(≤100) 株草药，每株有时间 t[i] 和价值 v[i]，求最大总价值。

记忆化搜索思路：
dfs(idx, remain)：从第 idx 株开始，剩余 remain 时间的最大价值
= max( 不选: dfs(idx+1, remain), 选: v[idx] + dfs(idx+1, remain-t[idx]) )
状态数 = M × T = 10⁵，O(N×T) 可轻松通过。

五、记忆化搜索详解

什么是记忆化搜索？

记忆化 = 搜索 + 缓存 = 自顶向下的动态规划。将已计算的子问题结果存储，遇到相同子问题时直接返回。

斐波那契：指数 → 线性

// 记忆化版：O(n) ll memo[MAXN]; bool vis[MAXN]; ll fib(int n) { if (n <= 1) return n; if (vis[n]) return memo[n]; vis[n] = true; return memo[n] = fib(n-1) + fib(n-2); }

从 O(2n) 降至 O(n)

数字三角形：记忆化框架

// dp[i][j]: 从(i,j)到底层的最大和 ll dfs(int i, int j, int n) { if (i == n) return a[i][j]; if (vis[i][j]) return dp[i][j]; vis[i][j] = true; return dp[i][j] = a[i][j] + max(dfs(i+1,j,n), dfs(i+1,j+1,n)); }

O(n²)，每个状态只计算一次

记忆化 vs 递推DP：如何选择？

场景推荐方法原因
状态转移有清晰拓扑序递推 DP无递归开销，更快
状态空间稀疏、不需全算记忆化搜索只计算需要的状态
状态转移顺序复杂记忆化搜索递归自然处理依赖
状态压缩 DP记忆化搜索配合位掩码非常自然
记忆化的时间戳技巧：多组测试数据时，不用 memset 重置 vis 数组，用 cur_time++ 和 vis[state] < cur_time 判"未访问"，O(1) 重置！

六、本课小结

核心知识回顾
  1. I/O 优化 —— 标配 ios::sync_with_stdio(false)；极大数据量用快速读入；输出用 \n 不用 endl
  2. 位运算 —— lowbit、快速幂、子集枚举是竞赛高频技巧；注意加括号防优先级陷阱
  3. 搜索剪枝三把刀：
    (1) 可行性剪枝：不可能到达目标 → 回溯
    (2) 最优性剪枝：不如当前最优 → 回溯
    (3) 顺序性剪枝：优化搜索顺序减少重复
  4. 记忆化搜索 —— 递归 + 缓存，自顶向下 DP。适用于状态稀疏或拓扑序不明确的场景
  5. 编译器内置函数 —— __builtin_popcount/clz/ctz 映射到 CPU 指令，比手写快
