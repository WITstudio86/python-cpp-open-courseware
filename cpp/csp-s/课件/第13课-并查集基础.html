第13课：并查集基础

Union-Find / Disjoint Set Union（DSU）

CSP-S 数据结构O(α(n)) ≈ O(1)路径压缩按秩合并

近乎 O(1) 的合并与查询，竞赛中最常用的数据结构之一

📖 知识精讲 — 基本概念

并查集维护什么？

维护不相交集合的森林结构

  • 每个集合用一棵有根树表示
  • 根节点是该集合的代表元素

两种核心操作

Find(x)查找 x 所属集合的代表元素（根）
Union(x,y)合并 x 和 y 所在的两个集合

两个关键优化

路径压缩：find 时将沿路节点直接连到根

按大小/秩合并：将小树合并到大树，保持平衡

同时使用两者 → 复杂度 O(α(n)) ≈ O(1)

📖 知识精讲 — 实现细节

路径压缩（递归版）

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}  // 顺便把路径上所有节点直接指向根！

按大小合并

bool unite(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return false;     // 已经在同一集合
    if (sz[x] < sz[y]) swap(x, y); // 小挂大
    fa[y] = x;
    sz[x] += sz[y];
    return true;
}

反阿克曼函数 α(n)

α(10⁶) ≈ 4，α(10¹⁰⁰) ≈ 5 → 竞赛中视为 常数

💻 代码模板 — 完整 DSU 结构体

struct DSU {
    vector<int> fa, sz;
    int comp;  // 连通块数量

    DSU(int n) : fa(n+1), sz(n+1, 1), comp(n) {
        for (int i = 1; i <= n; i++) fa[i] = i;
    }

    int find(int x) {
        return fa[x] == x ? x : fa[x] = find(fa[x]);
    }

    bool unite(int x, int y) {
        x = find(x); y = find(y);
        if (x == y) return false;
        if (sz[x] < sz[y]) swap(x, y);
        fa[y] = x; sz[x] += sz[y]; comp--;
        return true;
    }

    bool same(int x, int y) { return find(x) == find(y); }
    int  size(int x) { return sz[find(x)]; }
};

⚠️ 易错点与经典应用

常见错误

  • ⚠ 忘记初始化 fa[i] = i
  • ⚠ 递归 find 可能爆栈 — n 很大时使用迭代版
  • ⚠ unite 中未 find 就去比较
  • ⚠ 按大小合并写反 — 小树挂大树

经典应用场景

  • ✔ 连通块计数 — 初始 n，每次 unite 减 1
  • ✔ Kruskal 最小生成树 — 判断边是否形成环
  • ✔ 离线删边转加边 — 反向处理
  • ✔ 动态连通性 — 在线查询两点是否连通

📝 真题精练

真题一：连通块维护

操作：M x y（加边）、Q x y（查询连通 + 连通块总数）

n, m ≤ 2×10⁵ | O(m·α(n))

真题二：离线删边求连通块

场景：动态删边，每次删边后求连通块数

技巧：离线 + 反向 = 加边

先建出所有未删除的边 → 逆序加回被删边 → 记录连通块数

O((m+k)·α(n))

思想：删边难，加边易。将问题逆序转化为加边问题。

🎯 本课小结

两大优化

路径压缩：fa[x] = find(fa[x])

按大小合并：小树挂大树

复杂度

单次操作：O(α(n)) ≈ O(1)

竞赛范围：α(n) ≤ 4

经典应用

连通性 · 连通块

Kruskal MST
