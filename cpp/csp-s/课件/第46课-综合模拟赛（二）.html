📖 知识回顾 — 背包DP与区间DP

背包类型对比

类型容量遍历复杂度
01背包倒序O(nV)
完全背包正序O(nV)
多重背包倒序O(V·Σlog c)

二进制拆分核心

int k = 1;
while (c >= k) {
    // 拆出 k 个物品成一包
    for (j=V; j>=v*k; j--)
        dp[j] = max(dp[j], dp[j-v*k]+w*k);
    c -= k; k <<= 1;
}
if (c > 0) { // 剩余零头 }

区间 DP 模板

// 经典三层循环
for (int len = 2; len <= n; len++)       // 1. 枚举长度
    for (int l = 1; l+len-1 <= n; l++)  // 2. 枚举起点
        for (int k = l; k < r; k++)     // 3. 枚举分割点
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + cost);

时间复杂度：O(n³)，n ≤ 300 可接受

📖 知识回顾 — 状压DP与组合数学

状压 DP 要点

  • n ≤ 20 时考虑，状态数 2ⁿ
  • mask & (1 << i) 检查第 i 位
  • mask | (1 << j) 设置第 j 位
  • TSP 经典状态：dp[mask][i]
  • 枚举子集：for(sub=mask; sub; sub=(sub-1)&mask)

组合数工具函数

// 快速幂
ll qpow(ll a, ll b) {
    ll r=1; a%=MOD;
    while(b){if(b&1)r=r*a%MOD;a=a*a%MOD;b>>=1;}
    return r;
}
// C(n,k) = n!/(k!(n-k)!)

📝 T1：多重背包 [简单]

数据范围：n ≤ 100, V ≤ 40000, c[i] ≤ 10⁴

每种物品有 c[i] 个，每个体积 v[i]，价值 w[i]，求最大总价值

二进制拆分原理

将 c 个物品拆成 1, 2, 4, 8, ..., 2ᵏ, c-2ᵏ⁺¹+1 个"打包物品"，
每个打包物品视为独立的 01 背包物品。拆分后物品数 ≈ log(c)。

AC 代码

int k = 1;
while (c >= k) {
    int nv = v * k, nw = w * k;
    for (int j = V; j >= nv; j--)
        dp[j] = max(dp[j], dp[j - nv] + nw);
    c -= k; k <<= 1;
}
if (c > 0) { /* 处理剩余 */ }

复杂度：O(V × Σlog c[i]) ≈ 5.6×10⁷，可通过。

【讲解】📝 T1：多重背包 [简单] 结合讲义《题目1（T1 简单）：多重背包的二进制优化》强调： · 题目描述： · 有 n 种物品和一个容量为 V 的背包。第 i 种物品有 c[i] 个，每个体积为 v[i]，价值为 w[i]。每种物品可以取不超过 c[i] 个。求背包能装下的最大总价值。 · 输入格式： · 第一行两个整数 n 和 V（1 ≤ n ≤ 100，1 ≤ V ≤ 4×10⁴）。 · 接下来 n 行，每行三个整数 v[i], w[i], c[i]（1 ≤ v[i], w[i], c[i] ≤ 10⁴）。 幻灯片上可见要点： · 数据范围 ：n ≤ 100, V ≤ 40000, c[i] ≤ 10⁴ · 每种物品有 c[i] 个，每个体积 v[i]，价值 w[i]，求最大总价值 · 将 c 个物品拆成 1, 2, 4, 8, ..., 2ᵏ, c-2ᵏ⁺¹+1 个"打包物品"， 每个打包物品视为独立的 01 背包物品。拆分后物品数 ≈ log(c) 。 · 复杂度：O(V × Σlog c[i]) ≈ 5.6×10⁷，可通过。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 T2：区间DP — 乘积代价合并 [中等]

n 堆石子排成一排，每次合并相邻两堆，代价为两堆石子数量的乘积

数据范围：n ≤ 300, a[i] ≤ 100

求：合并为一堆的最小总代价

状态与转移

设 dp[l][r] = 合并区间 [l, r] 的最小代价

转移方程：

dp[l][r] = mink=l..r-1 { dp[l][k] + dp[k+1][r] + sum[l][k] × sum[k+1][r] }

AC 代码核心

// 区间 DP 三层循环
for (int len = 2; len <= n; len++)
    for (int l = 1; l+len-1 <= n; l++)
        for (int k = l; k < r; k++) {
            ll cost = sum(l,k) * sum(k+1,r);
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + cost);
        }

复杂度：O(n³) ≈ 2.7×10⁷，空间 O(n²)。

【讲解】📝 T2：区间DP — 乘积代价合并 [中等] 结合讲义《题目2（T2 中等）：区间DP — 石子合并变种》强调： · 题目描述： · 有 n 堆石子排成一排，第 i 堆石子有 a[i] 颗。每次可以合并**相邻的两堆**石子，合并的代价为**两堆石子数量的乘积**。合并后形成的新石子堆数量为二者之和。 · 求将 n 堆石子合并为 1 堆的**最小总代价**。 · 例如：三堆石子 [2, 3, 4]： · 先合并 2 和 3，代价 2×3=6，得到 [5, 4] 幻灯片上可见要点： · n 堆石子排成一排 ，每次合并相邻两堆，代价为 两堆石子数量的乘积 · 数据范围 ：n ≤ 300, a[i] ≤ 100 · 求 ：合并为一堆的最小总代价 · 设 dp[l][r] = 合并区间 [l, r] 的最小代价 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 T3：TSP 旅行商问题 [中等]

n 个城市，从 1 出发，经过所有城市恰好一次后回到 1

数据范围：n ≤ 15, d[i][j] ∈ [0, 10⁶] 或 -1

求：最短总距离，不可行输出 -1

状压 DP 解法

dp[mask][i]：已访问城市集合为 mask，当前在城市 i 的最短距离

转移：dp[mask|(1<<j)][j] = min(dp[mask|(1<<j)][j], dp[mask][i] + d[i][j])

AC 代码

for (int mask = 1; mask < (1<<n); mask++)
    for (int i = 0; i < n; i++) {
        if (!(mask & (1<<i)) || dp[mask][i] == INF) continue;
        for (int j = 0; j < n; j++) {
            if (mask & (1<<j) || d[i][j] == -1) continue;
            int nxt = mask | (1<<j);
            dp[nxt][j] = min(dp[nxt][j], dp[mask][i] + d[i][j]);
        }
    }
// 答案 = min(dp[full][i] + d[i][0])

复杂度：O(n²×2ⁿ) ≈ 7.4×10⁶，n=15 轻松通过。

【讲解】📝 T3：TSP 旅行商问题 [中等] 结合讲义《题目3（T3 中等）：状压DP — 旅行商问题（TSP）》强调： · 题目描述： · 有 n 个城市，编号为 1, 2, ..., n。给出任意两个城市 i 和 j 之间的距离 d[i][j]（不满足三角不等式）。 · 一个商人要从城市 1 出发，**经过所有城市恰好一次**，最后回到城市 1。求最短的总旅行距离。若无法完成（例如某些城市之间不连通，距离为 -1），输出 -1。 · 输入格式： · 第一行一个整数 n（2 ≤ n ≤ 15）。 幻灯片上可见要点： · n 个城市 ，从 1 出发，经过 所有城市恰好一次 后回到 1 · 数据范围 ：n ≤ 15, d[i][j] ∈ [0, 10⁶] 或 -1 · 求 ：最短总距离，不可行输出 -1 · dp[mask][i] ：已访问城市集合为 mask，当前在城市 i 的最短距离 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 T4：组合数学+DP [较难]

长度为 n 的序列，值域 [1..k]，求恰好 m 个上升位置的序列个数

数据范围：n ≤ 2000, k ≤ 10⁹, m < n

取模：10⁹ + 7

核心思想 — 欧拉数

排列中上升位置个数的计数 = 欧拉数 A(n, m)

递推公式：

A(n, m) = (m+1)·A(n-1, m) + (n-m)·A(n-1, m-1)

推广到值域 [1..k]（允许重复取值）：

ans = Σt=0n-1-m C(k, m+t+1) × A(n, m+t)

直观理解：m 个上升把序列分成 m+1 个非升段，段的"最大值"从 k 个值中选，段内用 multiset 填充。

【讲解】📝 T4：组合数学+DP [较难] 结合讲义《题目4（T4 较难）：组合数学 + DP + 快速幂》强调： · 题目描述： · 给定正整数 n 和 k，求满足以下条件的长度为 n 的整数序列 a[1..n] 的个数（对 10⁹ + 7 取模）： · 1 ≤ a[i] ≤ k（每个元素在 1 到 k 之间） · 序列中**恰好**有 m 个位置 i（1 ≤ i < n）满足 a[i] < a[i+1]（即相邻的上升位置数恰好为 m） · 输入格式： 幻灯片上可见要点： · 长度为 n 的序列，值域 [1..k] ，求 恰好 m 个上升位置 的序列个数 · 数据范围 ：n ≤ 2000, k ≤ 10⁹, m < n · 取模 ：10⁹ + 7 · 排列中上升位置个数的计数 = 欧拉数 A(n, m) 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 T4 代码实现

Step 1：计算欧拉数 A(n, m)

ll euler[MAXN][MAXN];
euler[0][0] = 1;
for (int i = 1; i <= n; i++) {
    euler[i][0] = 1;
    for (int j = 1; j < i; j++)
        euler[i][j] = ((j+1)*euler[i-1][j] + (i-j)*euler[i-1][j-1]) % MOD;
}

Step 2：推广到 k 值域

ll ans = 0;
for (int t = 0; t <= n-1-m; t++) {
    int seg = m + t + 1;   // 需要的不同值的个数
    if (seg > k) break;
    ll comb = comb_large_n(k, seg);  // C(k, seg) mod MOD
    ans = (ans + comb * euler[n][m+t]) % MOD;
}

复杂度：O(n²) 欧拉数 + O(n) 组合数计算。n ≤ 2000，轻松通过。

⚠️ 易错点总结

背包 DP

  • 01背包倒序，完全背包正序！
  • 混淆内外循环顺序 → 0 分
  • 多重背包务必将 c[i] 正确拆分

区间 DP

  • 先枚举 len，再枚举 l
  • 环形区间：复制数组到 2n
  • cost 函数确保使用前缀和
  • 初始化：单元素区间 cost=0

状压 DP

  • mask 从 0 到 2ⁿ-1，共 2ⁿ 个
  • n > 20 不能用状压
  • 初始化第几位对应哪个元素
  • 最终答案可能需遍历多种状态

组合数学

  • 除法用乘法逆元
  • 每步都取模防止溢出
  • 减法取模：(a-b+MOD)%MOD
  • 大 n 小 k 时用乘积公式
