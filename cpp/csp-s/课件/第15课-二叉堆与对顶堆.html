📖 知识精讲 — 二叉堆结构

完全二叉树 + 堆序性质

用数组存储完全二叉树，下标从 1 开始

  • 父节点：i/2 | 左子：2i | 右子：2i+1

大根堆 vs 小根堆

大根堆：父 ≥ 子（根最大）| 小根堆：父 ≤ 子（根最小）

两大核心操作

swim（上浮）插入：新元素放末尾，向上比较交换 → O(log n)
sink（下沉）删除堆顶：末尾元素放堆顶，向下比较交换 → O(log n)

O(n) 堆化（heapify）

从最后一个非叶子节点 n/2 开始，依次 sink → O(n) 建堆

📖 知识精讲 — 对顶堆与动态中位数

对顶堆 = 大根堆 + 小根堆

[MaxHeap: 较小的一半] ... [MinHeap: 较大的一半]

不变式

  • MaxHeap.size() == MinHeap.size() 或 MaxHeap.size() == MinHeap.size() + 1
  • MaxHeap 的所有元素 ≤ MinHeap 的所有元素

操作复杂度

插入：O(log n) | 查询中位数：O(1)

💻 代码模板

对顶堆（动态中位数）

void addNum(int x) {
    if (maxHeap.empty() || x <= maxHeap.top())
        maxHeap.push(x);
    else
        minHeap.push(x);
    // 平衡两个堆
    if (maxHeap.size() > minHeap.size() + 1) {
        minHeap.push(maxHeap.top()); maxHeap.pop();
    } else if (minHeap.size() > maxHeap.size()) {
        maxHeap.push(minHeap.top()); minHeap.pop();
    }
}

小根堆核心实现

// sink: 堆顶下沉
void sink(int i) {
    while (2 * i <= sz) {
        int j = 2 * i;
        if (j < sz && heap[j+1] < heap[j]) j++; // 选更小的儿子
        if (heap[i] <= heap[j]) break;
        swap(heap[i], heap[j]); i = j;
    }
}

⚠️ 易错点与优化技巧

  • ⚠ 下标从 1 开始 — 方便父子计算，0 下标需偏移公式
  • ⚠ sink 选对儿子 — 小根堆选小的，大根堆选大的
  • ⚠ 对顶堆平衡 — 插入后必须调整保持 size 约束
  • ⚠ 取模运算 — 堆排序不稳定，不保证相同元素的相对顺序
  • ✔ STL priority_queue 默认大根堆
  • ✔ 小根堆：greater<T> 或存负数
  • ✔ 合并果子 → 贪心 + 小根堆 → Huffman
  • ✔ 堆化 O(n) 优于逐个插入 O(n log n)

📝 真题精练

真题一：动态中位数

在线查询奇数位置的中位数 | M ≤ 10⁵

对顶堆：插入 O(log M)，查询 O(1)，总 O(M log M)

真题二：合并果子（Huffman 编码）

n 堆果子，每次合并两堆，代价 = 重量和 | n ≤ 10⁴

贪心：每次选最小两堆合并 → 小根堆 → O(n log n)

堆排序

原地 O(n log n)，不稳定。建堆 O(n) + 排序 O(n log n)

堆 vs 快排：堆排序原地但常数大、不稳定；快速排序常数小但不稳定；归并排序稳定但需 O(n) 空间
