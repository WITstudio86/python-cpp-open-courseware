📖 矩阵乘法基础

定义

若 A 是 n×m 矩阵，B 是 m×p 矩阵，则 C = A×B 是 n×p 矩阵：

C[i][j] = Σ A[i][k] · B[k][j]   （k = 1..m）

关键性质

性质说明重要性
结合律(A×B)×C = A×(B×C)矩阵快速幂的基础
不满足交换律一般 A×B ≠ B×A容易出错
单位矩阵I[i][i]=1, 其余为0; A×I = I×A = A快速幂的初始化

缓存优化技巧

循环顺序应为 i → k → j（而非 i → j → k），利用 B 的第 k 行被重复使用的特性：

// 正确的循环顺序（缓存友好）
for (int i = 0; i < n; i++)
    for (int k = 0; k < m; k++)        // k 在中间!
        if (A[i][k])                     // 稀疏优化
            for (int j = 0; j < p; j++)
                C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;

时间复杂度：朴素 O(n³)，竞赛中 n ≤ 300 安全

📖 矩阵快速幂 — 原理推导

核心思想

矩阵乘法满足结合律，因此整数快速幂的二分思想可直接推广：

Aⁿ = (A²)^(n/2)  （n 为偶数）

Aⁿ = A · (A²)^((n-1)/2)  （n 为奇数）

// 矩阵快速幂模板
Matrix mat_pow(Matrix A, ll n) {
    Matrix res = identity(A.size());  // 单位矩阵
    while (n) {
        if (n & 1) res = mat_mul(res, A);
        A = mat_mul(A, A);
        n >>= 1;
    }
    return res;
}

最重要的应用：加速线性递推

任何 k 阶线性递推 都可以用 k×k 矩阵在 O(k³·log n) 内求解：

核心思想：将递推状态列向量 × 转移矩阵 = 下一状态列向量

递推 → 矩阵转换规则

递推 aₙ = c₁·aₙ₋₁ + c₂·aₙ₋₂ + ... + cₖ·aₙ₋ₖ

→ 构造 k×k 矩阵：第一行 = [c₁, c₂, ..., cₖ]；其余行为偏移单位矩阵

💻 斐波那契数列 — 矩阵加速 O(log n)

从 O(n) 到 O(log n) 的质变

递推关系：fib(n) = fib(n-1) + fib(n-2)

将递推写成矩阵形式：

[fib(n)    fib(n-1)]ᵀ = [[1,1],[1,0]] · [fib(n-1)    fib(n-2)]ᵀ

展开后：

[fib(n)    fib(n-1)]ᵀ = [[1,1],[1,0]]ⁿ⁻¹ · [fib(1)    fib(0)]ᵀ

// 完整代码 — 仅 O(log n) 时间
ll fibonacci(ll n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    Matrix T = {{1, 1}, {1, 0}};
    T = mat_pow(T, n - 1);
    return T[0][0];
    // 因为 [fib(1), fib(0)] = [1, 0]，结果第一位 = T[0][0]
}

适用范围

递推类型矩阵大小总复杂度

k 阶线性递推k×kO(k³·log n)
DP 转移（状态数 k）k×kO(k³·log n)
图论路径计数（n 个点）n×nO(n³·log L)

📖 高斯消元精讲

解线性方程组 Ax = b

算法两步走

  1. 前向消元：化为行阶梯形（选主元 → 消下方行）
  2. 回代：从最后一行向上求解

三种结果的判定

情况判定条件输出
唯一解所有列有主元，无矛盾行回代得唯一解
无解存在行 [0...0|c] 且 c ≠ 0No solution
无穷多解存在自由变量，无矛盾行Infinite solutions

核心操作：选列主元

每列选择绝对值最大的元素所在行，交换到当前行

  • 避免除以 0 → NaN 错误
  • 减少浮点数累积误差
  • 比较时使用 fabs()，精度判零用 EPS = 1e-9

进阶应用

求行列式：化为上三角矩阵 → 对角线乘积（注意行交换变号）

求逆矩阵：增广矩阵法 [A | I] → [I | A⁻¹]
