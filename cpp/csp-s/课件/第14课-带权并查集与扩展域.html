📖 知识精讲 — 两种方法

方法一：扩展域（k倍空间）

将每个元素拆成 k 个域，每个域代表一种可能的类型

例（食物链，3类）：x → A类，x+n → B类，x+2n → C类

方法二：边带权并查集

维护 d[x]：x 到父节点的关系权值

find 时累加：d[x] = (d[x] + d[fa[x]]) % mod

对比

扩展域边带权
空间O(kn)O(n)
代码直观需推导
适用k≤3任意mod

📖 知识精讲 — 扩展域详解

食物链（3 类环形关系）

A 吃 B，B 吃 C，C 吃 A

合并规则

设 X 吃 Y：

  • X 是 A → Y 是 B：unite(x, y+n)
  • X 是 B → Y 是 C：unite(x+n, y+2n)
  • X 是 C → Y 是 A：unite(x+2n, y)

矛盾判定

说 X 和 Y 同类时，矛盾条件：X 在 A 且 Y 在 B 或 X 在 A 且 Y 在 C

说 X 吃 Y 时，矛盾条件：同类 或 Y 吃 X

【讲解】📖 知识精讲 — 扩展域详解 本页要点（照着讲即可）： · A 吃 B，B 吃 C，C 吃 A · 设 X 吃 Y： · X 是 A → Y 是 B： unite(x, y+n) · X 是 B → Y 是 C： unite(x+n, y+2n) · X 是 C → Y 是 A： unite(x+2n, y) · 说 X 和 Y 同类时，矛盾条件： X 在 A 且 Y 在 B 或 X 在 A 且 Y 在 C 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

💻 代码模板 — 边带权并查集

核心：find 中的路径压缩

int find(int x) {
    if (fa[x] == x) return x;
    int root = find(fa[x]);      // 先递归！
    d[x] = (d[x] + d[fa[x]]) % mod; // 再更新 d
    return fa[x] = root;
}

合并时的关系推导

bool unite(int x, int y, int rel) {
    int fx = find(x), fy = find(y);
    if (fx == fy)
        return (d[x] - d[y] + mod) % mod == rel;
    fa[fx] = fy;
    d[fx] = (d[y] - d[x] + rel + mod) % mod;
    // 推导：x→fx→fy→y = rel
    return true;
}

⚠️ 易错点与优化技巧

  • ⚠ find 递归顺序 — 必须先递归 fa[x]，再更新 d[x]
  • ⚠ 模运算负数 — 公式用 (a - b + mod) % mod
  • ⚠ 扩展域空间 — 需要 k*n，注意数组大小
  • ⚠ 扩展域矛盾检查 — 检查所有可能的目标域
  • ⚠ d[x] 方向一致 — 统一使用 x→fa[x] 的方向
  • ✔ 种类 ≤3 用扩展域 — 代码直观不易错
  • ✔ 种类多/关系复杂用带权 — 空间 O(n)
  • ✔ 关系链式推导 — x→fx→fy→y 形成闭环
【讲解】⚠️ 易错点与优化技巧 结合讲义《⚠️ 易错点与优化技巧》强调： · find 的递归顺序 —— 必须先 find(fa[x]) 再更新 d[x]，否则 d[fa[x]] 可能不是到根的关系 · 模运算的负数处理 —— 公式写成 (a + b) % mod 和 (a - b + mod) % mod · 扩展域的空间 —— 需要开 k*n 的大小，注意数组越界 · 扩展域中矛盾判断 —— 需要检查所有可能的目标域 · 关系方向 —— 注意 d[x] 的方向（x→fa[x] 还是 fa[x]→x），保持一致 幻灯片上可见要点： · ⚠ find 递归顺序 — 必须先递归 fa[x]，再更新 d[x] · ⚠ 模运算负数 — 公式用 (a - b + mod) % mod · ⚠ 扩展域空间 — 需要 k*n，注意数组大小 · ⚠ 扩展域矛盾检查 — 检查所有可能的目标域 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

📝 真题精练

真题一：[NOI 2001] 食物链

N ≤ 5×10⁴，K ≤ 10⁵ | 3 类环形关系

两种解法：扩展域（3N）或边带权（模 3）

真题二：奇偶性判定（XOR 关系）

N ≤ 10⁵，M ≤ 2×10⁵ | 判断条件是否矛盾

扩展域（2N）：x=0 域和 x=1 域

XOR=0 → 合并相同域；XOR=1 → 合并不同域

复杂度：O((N+K)·α(N))，即近乎 O(N+K)
