1. 最大子段和 — Kadane算法

问题描述

给定长度为 n 的整数序列，求连续子段的最大和。

状态定义与转移

dp[i] = max(a[i], dp[i-1] + a[i])

含义：要么从当前元素重新开始，要么接上前面的子段。

核心代码（滚动优化 O(1) 空间）

using ll = long long;

ll max_subarray_sum(const vector<ll>& a) {
    ll cur = 0, best = LLONG_MIN;
    for (ll x : a) {
        cur = max(x, cur + x);
        best = max(best, cur);
    }
    return best;
}
指标值
时间复杂度O(n)
空间复杂度O(1)
关键技巧用单个变量代替 dp 数组（滚动优化）
易错点：如果数组全为负数，必须用 LLONG_MIN 初始化 best，否则 cur=0 会导致结果错误地为 0。

2. 数字三角形 — 逆推法

问题描述

给定 n 行数字三角形，每次只能向左下或右下走，求从顶部到底部的最大路径和。

逆推法（自底向上）

dp[i][j] = a[i][j] + max(dp[i+1][j], dp[i+1][j+1])

代码

int triangle_max_path(const vector<vector<int>>& tri) {
    int n = tri.size();
    auto dp = tri;  // 复制最后一行作为初始值
    for (int i = n - 2; i >= 0; --i)
        for (int j = 0; j <= i; ++j)
            dp[i][j] += max(dp[i+1][j], dp[i+1][j+1]);
    return dp[0][0];
}
为什么推荐逆推？
顺推时第一列和最后一列需要特殊处理边界（j-1 可能为 -1），而逆推法天然规避了所有边界问题，代码更简洁、不易出错。
时间复杂度O(n²)
空间优化可使用一维数组优化到 O(n)

3. 路径计数DP（含障碍物）

问题描述

在 m×n 网格中从左上角走到右下角，每次只能向右或向下。某些格子有障碍物，不能经过。求不同路径数。

状态转移

dp[i][j] = 0（若为障碍）
dp[i][j] = dp[i-1][j] + dp[i][j-1]（否则）

代码

const int MOD = 1e9 + 7;

int count_paths(const vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<int>> dp(m, vector<int>(n, 0));
    dp[0][0] = (grid[0][0] == 0) ? 1 : 0;
    for (int i = 0; i < m; ++i)
        for (int j = 0; j < n; ++j) {
            if (grid[i][j] == 1) { dp[i][j] = 0; continue; }
            if (i > 0) dp[i][j] = (dp[i][j] + dp[i-1][j]) % MOD;
            if (j > 0) dp[i][j] = (dp[i][j] + dp[i][j-1]) % MOD;
        }
    return dp[m-1][n-1];
}
关键细节：
  • 每次加法后都要取模，防止溢出
  • 起点或终点是障碍物时直接返回 0
  • 空间可优化到 O(n)（滚动数组）

4. 最大子矩阵和 O(n³)

核心思想：压缩降维

1 枚举上边界 top
2 枚举下边界 bottom（向下扩展）
3 将 [top, bottom] 的每一列求和，压缩为一维数组
4 对一维数组运行 Kadane 算法

代码

ll max_submatrix_sum(const vector<vector<ll>>& mat) {
    int m = mat.size(), n = mat[0].size();
    ll ans = LLONG_MIN;
    for (int top = 0; top < m; ++top) {
        vector<ll> compressed(n, 0);
        for (int bot = top; bot < m; ++bot) {
            for (int j = 0; j < n; ++j)
                compressed[j] += mat[bot][j];
            // Kadane on compressed array
            ll cur = 0, best = LLONG_MIN;
            for (ll x : compressed) {
                cur = max(x, cur + x);
                best = max(best, cur);
            }
            ans = max(ans, best);
        }
    }
    return ans;
}
时间复杂度O(m²·n)
空间复杂度O(n)
优化技巧若 m > n，先转置矩阵再计算

5. 变体：环形最大子段和 & 最大子段积

环形最大子段和

序列首尾相接，子段可以跨越边界。

答案 = max(普通最大子段和, total - 最小子段和)
全负数特判：如果 max_normal < 0，说明数组全为负数，此时 total - min_sum = 0 是不合法的，应直接返回 max_normal。

最大子段积

负数乘以负数会变成正数，需要同时维护以 i 结尾的最大值和最小值。

max_dp[i] = max(a[i], max_dp[i-1]×a[i], min_dp[i-1]×a[i])
min_dp[i] = min(a[i], max_dp[i-1]×a[i], min_dp[i-1]×a[i]) 
ll max_product_subarray(const vector<ll>& a) {
    ll max_cur = a[0], min_cur = a[0], ans = a[0];
    for (int i = 1; i < a.size(); ++i) {
        ll x = a[i];
        ll nm = max({x, max_cur * x, min_cur * x});
        ll nmin = min({x, max_cur * x, min_cur * x});
        max_cur = nm; min_cur = nmin;
        ans = max(ans, max_cur);
    }
    return ans;
}

6. 真题精练

真题1：最大子矩阵和（P1719）

给定 n×n 矩阵（n ≤ 120），求最大子矩阵和。

解法：枚举上下边界 + 压缩为一维 + Kadane，O(n³)。

核心代码：见本课配套 C++ 程序。


真题2：数字三角形变体（模运算）

求数字三角形路径和 模 100 的最大值。

关键思路：模运算不满足单调性，不能直接对 DP 值取模后比较大小。
应当使用可行性 DP：
dp[i][j][k] = 到达 (i,j) 时路径和 % 100 = k 是否可达。
最后在最后一行的所有可达 k 中取最大值。

复杂度：O(n² × 100)，n=100 时约 10⁶ 次操作。

1. 线性DP核心是「以第 i 个元素结尾」的状态定义
