拓扑排序

有向无环图（DAG）的线性排序 · 依赖关系建模 · 判环技术

Kahn 算法 DFS 后序 字典序最小 课程表问题 O(V+E)

📘 Kahn 算法（BFS + 入度表）

核心思想：每次「删除」一个入度为 0 的节点及其所有出边，不断重复。

算法步骤

  1. 建图 + 统计入度：遍历所有边，建立邻接表，同时计算每个节点的入度。
  2. 初始化队列：将所有入度为 0 的节点入队（多源 BFS 起点）。
  3. BFS 迭代：取出队首节点 u → 加入拓扑序列 → u 的所有邻接点 v 入度减 1 → 若 v 入度变为 0，入队。
  4. 判环：若最终拓扑序列长度 < n，说明图中存在环。

复杂度：O(V+E) 时间 | O(V+E) 空间 | 适用于 n ≤ 10⁵ 规模

📗 DFS 拓扑排序（后序遍历逆序）

核心原理：在 DAG 的 DFS 中，子节点先于父节点被"后序加入"。将加入顺序反转后，父节点排在子节点前面——正是拓扑排序。

三色标记法判环

状态值含义遇到时的操作
白色0未访问递归进入
灰色1正在访问中（在递归栈）发现环！
黑色2已完成跳过

关键代码逻辑

// DFS 后序遍历 void dfs(int u) { state[u] = 1; // 标记「访问中」 for (int v : adj[u]) { if (state[v] == 1) return; // 发现环 if (state[v] == 0) dfs(v); } state[u] = 2; // 标记「已完成」 result.push_back(u); // ★ 后序位置加入 } // 最后 reverse(result) 即得拓扑序

字典序最小拓扑序

将 Kahn 算法中的普通队列替换为小根堆 priority_queue 即可。

// 关键代码 priority_queue<int, vector<int>, greater<int>> pq; for (int i=0; i<n; i++) if (indeg[i]==0) pq.push(i); while (!pq.empty()) { int u = pq.top(); pq.pop(); // ... 处理邻接点 }

时间复杂度：O(V log V + E)

💻 代码模板 — Kahn 算法（完整版）

/** Kahn 拓扑排序：返回拓扑序列，有环则返回空 vector */ vector<int> topoSort(int n, vector<vector<int>>& edges) { vector<vector<int>> adj(n); vector<int> indeg(n, 0); for (auto& e : edges) { // 建图 + 统计入度 int u = e[0], v = e[1]; adj[u].push_back(v); indeg[v]++; } queue<int> q; for (int i=0; i<n; i++) if (indeg[i] == 0) q.push(i); vector<int> res; while (!q.empty()) { int u = q.front(); q.pop(); res.push_back(u); for (int v : adj[u]) if (--indeg[v] == 0) q.push(v); } if ((int)res.size() < n) return {}; // 有环 return res; }

📝 真题精练

题目1：课程表 I（判环）

给定 n 门课程和先修关系 prerequisites[i] = [a,b]（学 a 前必须先学 b），判断能否完成所有课程。本质：判断有向图是否为 DAG。使用 Kahn 算法，比较拓扑序列长度与 n。

复杂度：O(V+E)

题目2：课程表 II（输出拓扑序）

在题目1的基础上，返回一个可行的课程学习顺序。本质：求任意一个拓扑序列。直接使用 Kahn 算法，若序列长度 == n 则返回结果，否则返回空数组。

建图时注意边的方向：学完 b 才能学 a，即 b → a。

易错提醒

  • 📌 DFS 拓扑排序必须在后序位置将节点加入结果，而非前序。
  • 📌 多源 BFS 初始化时，不要遗漏任何入度为 0 的节点。
  • 📌 字典序最小需使用 greater<int>（小根堆）。

⚡ 优化技巧与常见错误

常见错误

错误正确做法
DFS 前序加入节点必须在后序位置加入
遗漏入度为0节点遍历所有节点检查入度
重边导致入度多算根据需要去重或特殊处理
大根堆求字典序最小应使用 greater<int>

优化技巧

  • 邻接表优于邻接矩阵：稀疏图 O(V+E) vs O(V²)
  • 保存原始入度：多次拓扑排序时避免重建
  • 拓扑序唯一性判定：Kahn 算法中若队列始终只有 1 个元素，则序列唯一
  • 静态数组替代 vector：在极限性能要求下使用数组池
