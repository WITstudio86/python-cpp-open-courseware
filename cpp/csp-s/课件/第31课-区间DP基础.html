区间DP概念

定义

区间动态规划（Interval DP）是一类在区间上进行动态规划的方法。 它将原问题分解为若干个小区间上的子问题，先求解小区间的最优解， 再通过某种合并方式得到大区间的最优解。

核心特征

  • 状态定义为dp[l][r]，表示区间 [l, r] 上的最优解
  • 按区间长度从小到大递推（长度=1 为边界）
  • 大区间的解由两个更小的子区间合并得到
  • 最终答案通常是 dp[0][n-1] 或 dp[1][n]

与线性DP的对比

维度线性DP区间DP
状态定义dp[i]dp[l][r]
递推方向按位置 i 递推按区间长度 len 递推
典型问题LIS、LCS、背包石子合并、矩阵链乘法
时间复杂度O(n) ~ O(n²)O(n³)，可优化至 O(n²)
判断依据：如果问题要求将一个序列「合并」成一整个结果，且合并操作只能发生在相邻元素之间 → 大概率是区间DP。

五步转移法（通用框架）

区间DP有一个标准的代码框架，掌握它即可解决 80% 的区间DP问题。

步骤内容代码
第一步枚举区间长度 lenfor (int len = 2; len ≤ n; ++len)
第二步枚举左端点 lfor (int l = 0; l+len-1 < n; ++l)
第三步计算右端点 rint r = l + len - 1;
第四步枚举分割点 kfor (int k = l; k < r; ++k)
第五步状态合并转移dp[l][r] = merge(dp[l][k], dp[k+1][r])

为什么必须按长度枚举？

计算 dp[l][r] 时，需要用到 dp[l][k] 和 dp[k+1][r] —— 这些都是更短的区间。 因此必须先计算出所有长度较小的区间，才能递推出大区间。这就是按区间长度从小到大的原因。

for (int len = 2; len <= n; ++len) // ① 枚举区间长度（len=1是边界） for (int l = 0; l + len - 1 < n; ++l) // ② 枚举左端点 { int r = l + len - 1; // ③ 计算右端点 for (int k = l; k < r; ++k) // ④ 枚举分割点 k ∈ [l, r-1] dp[l][r] = min(dp[l][r], // ⑤ 状态转移 dp[l][k] + dp[k+1][r] + cost(l, r)); }
关键细节：分割点 k 的范围因问题而异 → 石子合并: k∈[l, r-1]，最优三角剖分: k∈[l+1, r-1]。

石子合并问题详解

问题描述

n 堆石子排成一行，每堆重量为 aᵢ。每次只能合并相邻两堆， 合并代价 = 两堆重量之和。经过 n-1 次合并后所有石子合成一堆。求最小总代价。

状态定义与转移方程

dp[l][r] = 将区间 [l, r] 的全部石子合并成一堆的最小代价

dp[l][r] = min(dp[l][k] + dp[k+1][r]) + sum(l, r) k ∈ [l, r-1]

前缀和优化 — 区间求和 O(1)

pre[i] = pre[i-1] + a[i-1] // 前缀和数组 sum(l, r) = pre[r+1] - pre[l] // O(1) 查询区间和

最优三角剖分

问题描述

给定一个 n 边形（顶点编号 1..n），用 n-3 条不相交的弦将它剖分成 n-2 个三角形。 每条弦 (i, j) 有权值 w[i][j]。求一种剖分方式，使得所有弦的权值之和最小。

状态定义

dp[l][r] = 将顶点 l 到顶点 r 组成的多边形进行三角剖分的最小权值和
（默认多边形边 (l, r) 已经存在，不需要计算其权值）

转移方程

dp[l][r] = min( dp[l][k] + dp[k][r] + w[l][k] + w[k][r] ) k ∈ (l+1, r-1)

核心思想：选择顶点 k 将多边形分成三部分 —— 子多边形 [l..k]、 子多边形 [k..r]、以及三角形 △(l, k, r)。 注意与石子合并不同，这里的 k 同时属于左右两个子问题。

与矩阵链乘法的关系

最优三角剖分与矩阵链乘法本质上是同一个问题： 矩阵链乘法的代价函数 p[l-1] * p[k] * p[r] 对应三角剖分中三角形 (l, k, r) 的权值。 两者使用完全相同的区间DP框架，只是代价函数不同。

// 最优三角剖分核心代码 for (int len = 3; len <= n; ++len) for (int l = 1; l + len - 1 <= n; ++l) { int r = l + len - 1; for (int k = l + 1; k < r; ++k) dp[l][r] = min(dp[l][r], dp[l][k] + dp[k][r] + w[l][k] + w[k][r]); }

矩阵链乘法与回文串

矩阵链乘法

给定 n 个矩阵的维度序列 p[0..n]（第 i 个矩阵为 p[i-1] × p[i]）， 求完全括号化后最少标量乘法次数。

// 代价函数 cost = p[l-1] * p[k] * p[r]

示例：维度 [10, 100, 5, 50]（3个矩阵: 10×100, 100×5, 5×50）
最优括号化：(A1×(A2×A3)) → 7500 次乘法
若按 ((A1×A2)×A3) 则需要 75000 次 —— 相差 10 倍！

回文串：最少插入次数

给定字符串 s，求最少插入多少个字符使之成为回文串。

if (s[l] == s[r]) dp[l][r] = dp[l+1][r-1]; // 两端相同，无需插入 else dp[l][r] = min(dp[l+1][r], dp[l][r-1]) + 1;
输入 s最少插入次数结果示例
"abca"1"acbca" 或 "abcba"
"aba"0已经是回文
"abcde"4"abcdedcba"
"mbadm"2"mbdadbm"
注意：回文串问题不需要枚举 k —— 两端字符直接决定转移方向，因此复杂度为 O(n²) 而非 O(n³)。 这是区间DP中少见的「无需分割点」模型。

真题精练

题1：石子合并（洛谷 P1775）

n ≤ 300，n 堆石子排成一行，求合并成一堆的最小代价。

解法：标准区间DP模板。O(n³) 约 27×10⁶ 次运算，完全可过。
关键：前缀和 O(1) 求区间和，注意 INF 初始化为 0x3f3f3f3f。

题2：矩阵链乘法

给定 n 个矩阵的维度，求最少乘法次数并输出最优括号化方案。

解法：区间DP框架不变，代价函数为 p[l-1] * p[k] * p[r]。
输出括号化：额外记录 s[l][r] = k，递归打印 ( A[l..k] * A[k+1..r] )。

题3：最优三角剖分

给定 n 边形的顶点，每条弦有权值，求最小剖分代价。

解法：k ∈ [l+1, r-1]，转移为 dp[l][k] + dp[k][r] + w[l][k] + w[k][r]。
注意 len 从 3 开始，因为三角形是最小的完整剖分单元。

题4：最少插入使之成为回文

给定字符串 s，求最少插入字符数使之成为回文。

解法：无需枚举 k，s[l]==s[r] 时 dp[l][r]=dp[l+1][r-1]，否则 dp[l][r]=min(dp[l+1][r],dp[l][r-1])+1。

本课小结

模块要点
区间DP核心将问题分解为小区间，再合并为大区间
状态定义dp[l][r] = 区间 [l, r] 的最优解
五步转移法长度 → 左端点 → 右端点 → 分割点 → 状态转移
石子合并最经典入门问题，掌握 O(n³) 标准写法
前缀和优化区间求和从 O(n) 优化到 O(1)
最优三角剖分k ∈ [l+1, r-1]，与矩阵链乘法本质相同
矩阵链乘法与石子合并框架相同，代价函数为 p[l-1]*p[k]*p[r]
回文串DP无需分裂点，O(n²)，两端字符决定转移
四边形不等式记录 s[l][r] 缩小 k 的范围，O(n³) → O(n²)
破环成链环形问题将数组复制一份，详见第32课

常见易错点

  • len 从 1 开始 — 单个元素不需要合并，必须从 2 开始
  • k 枚举到 r — 分割点应在 [l, r-1] 范围（左闭右开）
  • 前缀和写错 — 正确写法为 pre[r+1] - pre[l]，不是 pre[r] - pre[l]
  • 忘记初始化 dp[i][i]=0 — 边界条件缺失，结果是 INF
  • 循环顺序错误 — 必须先枚举 len，再枚举 l（不能反过来）
CSP-S 应试核心：石子合并模板必须能够手写无误。五步转移法是所有区间DP的通用框架， 熟练掌握后可解决 80% 的区间DP问题。建议将标准模板反复练习 3-5 遍。
