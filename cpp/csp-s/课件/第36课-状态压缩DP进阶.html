一、轮廓线DP（插头DP入门）

什么是轮廓线DP？

在逐格递推时，只保存当前「轮廓线」上的状态，而不是整个棋盘。

┌─────────────────────┐ │ ■ ■ ■ │ □ □ □ │ │ ■ ■ ■ │ □ □ □ │ │ ■ ■ ● │ □ □ □ │ ← 轮廓线（● = 当前格子） └─────────────────────┘ 已处理区域 未处理区域
核心优势：
  • 对于 n×m 网格，轮廓线上最多 m 个格子
  • 状态数从 2^(n×m) 降至 2^m（当逐列DP）或 2^n（当逐行DP）
  • 边界条件清晰，适合骨牌覆盖、哈密顿回路等问题

二、蒙德里安的梦想 —— 骨牌覆盖

问题

用 1×2 或 2×1 的骨牌铺满 N×M 棋盘，求方案数。

按列DP状态设计

dp[col][state] = 前 col 列铺满，第 col 列的「伸出」状态为 state 的方案数

state 的第 i 位为 1 → 第 i 行有横向骨牌伸到 col+1 列。

转移合法性判断

// 从 prev 状态转移到 cur 状态的条件： 1. prev & cur == 0 → 同一行不能同时被两个横骨牌占据 2. st[prev | cur] == true → 本列的空格必须能被竖骨牌（2×1）填满 → 即 prev|cur 中，所有连续的 0 段长度均为偶数

预处理 st[state]

bool check(int state, int N) { int cnt = 0; // 连续 0 的个数 for (int i = 0; i < N; i++) { if (state >> i & 1) { if (cnt & 1) return false; cnt = 0; } else cnt++; } return !(cnt & 1); }
最终答案：dp[M][0] —— 第 M 列没有骨牌伸出（棋盘恰好铺满）。

三、代码模板

蒙德里安的梦想

// DP 核心循环 dp[0][0] = 1; for (int col = 1; col <= M; col++) { for (int prev=0; prev<full; prev++) { for (int cur : trans[prev]) { dp[col][cur] += dp[col-1][prev]; } } } ans = dp[M][0]; // 答案

复杂度：O(M × 4^N)，N≤11 可行
N=11, M=11 约 11×4M 操作

奖励关（期望DP）

// 逆推 DP for (round = K; round >= 1; round--) for (mask = 0; mask < full; mask++) for (int i = 0; i < n; i++) if (满足前提) v = max(take, skip); else v = skip; dp[round][mask] += v / n;

复杂度：O(K × n × 2^n)
n≤15, K≤100 约 5×10⁷ 操作

四、状压 + 期望DP

期望DP基本概念

在随机过程的每个状态，求达到目标状态的期望步数 / 期望收益。

状态设计范式

dp[mask] = 从状态 mask 出发，到达目标还需的最优期望值

逆推法的优势

为什么用逆推（从终态向前推）？
  • 终态的值是确定的（dp[K+1][*] = 0），可以作为DP的边界
  • 当前决策可以直接利用「未来已计算好的最优值」
  • 避免了「最优策略是什么」的复杂分析——取 max 即可
  • 自然处理了概率平均

奖励关 转移方程详解

// 第 round 轮，当前已收集 mask，系统随机抛出宝物 i（概率 1/n） for each 宝物 i: if (require[i] ⊆ mask): // 前提满足，可以选择 best = max(dp[round+1][mask], // 放弃 dp[round+1][mask|(1<<i)] + score[i]) // 获取 else: // 前提不满足，只能放弃 best = dp[round+1][mask] dp[round][mask] = average(best over all i) // Σ best_i / n

如何处理负分宝物？

由于采用 max(take, skip)，当宝物分值为负时，最优策略是放弃获取——期望DP自动处理了这种决策。
