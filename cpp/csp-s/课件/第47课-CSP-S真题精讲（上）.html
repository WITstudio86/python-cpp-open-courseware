📝 T1 真题1：零和子数组

题目大意

给定长度为 n 的整数数组，求有多少个连续子数组的和为 0。

输入

4
2 -2 3 -3

输出

3

[1,2] [3,4] [1,4] 和均为0

数据范围

1 ≤ n ≤ 2×10⁵，|aᵢ| ≤ 10⁹

解题思路

暴力 O(n²)：枚举所有子数组 → 30 分

正解 O(n)：prefix[r] == prefix[l-1] ⟺ 子数组和为 0

使用 unordered_map 统计前缀和出现次数

对出现 cnt 次的值，贡献 C(cnt, 2) 个子数组

💻 T1 真题1：零和子数组 —— AC代码

// 核心：前缀和 + 哈希表，O(n)
long long solve(int n, const vector<long long>& a) {
    unordered_map<long long, int> cnt;
    cnt[0] = 1;           // prefix[0] = 0（空前缀）
    long long prefix = 0, ans = 0;
    for (int i = 0; i < n; i++) {
        prefix += a[i];
        // 之前每个 prefix 值出现的位置都能与当前位置构成零和子数组
        ans += cnt[prefix];
        cnt[prefix]++;
    }
    return ans;
}

复杂度分析

时间：O(n)

空间：O(n)

每个元素访问一次，哈希表查询 O(1)

关键注意

⚠ 使用 long long 防溢出

⚠ 必须统计 prefix[0]=0

✔ ans += cnt[prefix] 已经是组合数

📝 T1 真题2：最优任务调度

题目大意

n 个任务，每个需 1 单位时间，截止时间 dᵢ，收益 vᵢ。选择并安排任务，最大化总收益。

输入样例

4
3 10
1 5
2 6
2 7

输出

23

选 (1,5)→(2,7)→(3,10) 但5被更优的方案替换
最终：时刻1做6，时刻2做7，时刻3做10

数据范围

1 ≤ n ≤ 10⁵，dᵢ ≤ 10⁹，vᵢ ≤ 10⁹

核心思路：反悔贪心

1. 按截止时间 升序排列   2. 用 最小堆 维护已选任务收益

3. 当前收益入堆   4. 若堆大小 > 截止时间 → 弹出最小收益（反悔）

复杂度：O(n log n)

📝 T2 真题1：分割数组的最小最大段和

题目大意

将 n 个正整数划分为 最多 k 段，最小化 最大段和。

输入

5 3
7 2 5 10 8

输出

14

[7,2,5]=14, [10], [8]

数据范围

n ≤ 10⁵，k ≤ n，aᵢ ≤ 10⁹

核心思路：二分答案 + 贪心判定

单调性：若 X 可行（能分 ≤ k 段，每段和 ≤ X），则 X' > X 也可行

判定 check(X)：贪心切分 —— 当前段和超过 X 时新开一段

二分范围：[max(aᵢ), sum(aᵢ)]

复杂度：O(n log sum)，约 47 次判定

📝 T2 真题2：K 步最短路

题目大意

有向图，从节点 1 走到节点 n，恰好经过 k 条边，求最小总权值。

数据范围

n ≤ 1000，m ≤ 10000，k ≤ 100，w ≤ 1000

核心思路：分层图 DP

dp[e][v] = 恰好经过 e 条边到达节点 v 的最小总权值

初始化：dp[0][1] = 0，其他 dp[0][v] = INF

转移（对每条边 (u,v,w)）：

dp[e][v] = min(dp[e][v], dp[e-1][u] + w)

复杂度

时间：O(k · m)  |  空间：O(k · n)，可用滚动数组优化到 O(n)

等价于 Bellman-Ford 迭代 k 次求恰 k 条边的最短路

⚠️ 易错点与考试技巧

常见易错点

  • ⚠ 整数溢出——n ≥ 2×10⁵ 时用 long long
  • ⚠ 前缀和下标——不要忘记 prefix[0]
  • ⚠ 二分边界——检查 L 和 R 的初始化
  • ⚠ 不可达情况——图论题输出 -1
  • ⚠ 多组数据——每组都要初始化全局变量

考试技巧

  • ✔ 对拍验证——暴力 + 正解 + 数据生成器
  • ✔ 大样例测试——freopen + diff 对比
  • ✔ 分段保存——完成阶段性代码就存一份
  • ✔ 先用暴力——想不出正解就写暴力拿分
  • ✔ 文件 IO——freopen 文件名必须完全一致
