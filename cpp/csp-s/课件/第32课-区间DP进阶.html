环形区间DP：破环成链 x2

问题引入

第31课的石子合并是直线排列的。现实中石子可能排成一个圈，首尾也相邻。环形问题如何转化为线形？答案：破环成链 x2。

四大步骤

步骤操作示例（n=4）
①将原始序列 a[0..n-1] 复制一份接在尾部[4,5,9,4] → [4,5,9,4,4,5,9,4]
②得到长度为 2n 的新序列 bb[i] = a[i mod n]
③在 b 上做标准线性区间DP五步转移法，len ≤ n
④答案取所有长度为 n 的区间ans = max/min(dp[i][i+n-1])

图解：环形 → 线性

原始环形: [4] - [5] - [9] - [4] - (回到4) 破环成链: [4] [5] [9] [4] | [4] [5] [9] [4] (长度 2n = 8) |------- n=4 -------| |------- n=4 -------| |------- n=4 -------| ← 枚举所有断点位置

正确性证明

环形合并的任意方案都存在一个「断开点」。在 2n 的序列上枚举所有可能的断点（i=0..n-1），取长度为 n 的区间，等价于枚举了环上所有可能的合并方式。

易错点：答案不是 dp[0][n-1]！必须遍历所有 dp[i][i+n-1]（i = 0..n-1）取最优值。前缀和数组也要扩展至 2n+1。

环形石子合并（洛谷 P1880）

标准代码框架

// 1. 输入并扩展至 2n int n; cin >> n; vector<int> a(2 * n), pre(2 * n + 1, 0); for (int i = 0; i < n; ++i) { cin >> a[i]; a[i + n] = a[i]; } for (int i = 1; i <= 2 * n; ++i) pre[i] = pre[i-1] + a[i-1]; // 2. 区间DP（五步转移法，len ≤ n） vector<vector<int>> dp_min(2*n, vector<int>(2*n, INF)); vector<vector<int>> dp_max(2*n, vector<int>(2*n, 0)); for (int i = 0; i < 2 * n; ++i) dp_min[i][i] = 0; for (int len = 2; len <= n; ++len) for (int l = 0; l + len - 1 < 2 * n; ++l) { int r = l + len - 1; for (int k = l; k < r; ++k) { int s = pre[r+1] - pre[l]; dp_min[l][r] = min(dp_min[l][r], dp_min[l][k] + dp_min[k+1][r] + s); dp_max[l][r] = max(dp_max[l][r], dp_max[l][k] + dp_max[k+1][r] + s); } } // 3. 取最优答案 int ans_min = INF, ans_max = 0; for (int i = 0; i < n; ++i) { ans_min = min(ans_min, dp_min[i][i + n - 1]); ans_max = max(ans_max, dp_max[i][i + n - 1]); }

样例验证（[4, 5, 9, 4]）

断点 i排列最小最大
0[4,5,9,4]4354
1[5,9,4,4]4354
2[9,4,4,5]4454
3[4,4,5,9]4354

最终输出：43 54

能量项链（NOIP2006 提高组）

问题描述

N 颗能量珠排在环形项链上。每颗珠子有头标记和尾标记。相邻珠子：前一颗的尾标记 = 后一颗的头标记。合并 (m,r) 和 (r,n) 释放能量 m x r x n，新珠的头尾标记变为 (m,n)。求最大总能量。

状态定义与转移

dp[l][r] = 将第 l 到第 r 颗珠子合并的最大能量。

// 关键：与石子合并的转移差异 dp[l][r] = max(dp[l][k] + dp[k][r] + head[l] * head[k+1] * head[r+1])

与石子合并的核心差异

比较项石子合并能量项链
子区间划分dp[l][k] + dp[k+1][r]dp[l][k] + dp[k][r]
附加代价sum(l, r)head[l] x head[k+1] x head[r+1]
环形处理序列 a[i] 复制head[i] 复制，1-based 索引
答案min 和 max仅 max

样例分析：head = [2, 3, 5, 10]

珠子：珠1(2,3)、珠2(3,5)、珠3(5,10)、珠4(10,2) 最优合并顺序： ① 合并珠2(3,5) + 珠3(5,10) → 3x5x10 = 150，得新珠(3,10) ② 合并珠1(2,3) + 新珠(3,10) → 2x3x10 = 60，得新珠(2,10) ③ 合并新珠(2,10) + 珠4(10,2) → 2x10x2 = 500 总能量 = 150 + 60 + 500 = 710
易错点：能量项链的子区间划分是 dp[l][k] + dp[k][r]，不是 dp[l][k] + dp[k+1][r]！因为 k 位置的珠子也参与了合并，其标记信息在合并后仍然存在。

合并型 vs 消去型区间DP

一、合并型（Merge Type）

将两个相邻的小区间合并为一个大的区间。所有元素最终都参与合并。

问题转移特征复杂度环形否
石子合并dp[l][k] + dp[k+1][r] + sum(l,r)O(n³)直线/环形
能量项链dp[l][k] + dp[k][r] + h[l]*h[k+1]*h[r+1]O(n³)环形
矩阵链乘法dp[l][k] + dp[k+1][r] + p[l-1]*p[k]*p[r]O(n³)直线

二、消去型（Elimination Type）

消去区间中的某一段，消去后两边的部分变得相邻。某些元素可能被完全消除。

问题核心特征额外维度
祖玛消去同色连续球颜色信息
移除盒子消去 k 个同数盒子得 k² 分右侧同色数量 k
括号匹配删除匹配的括号对否
回文串DP两端字符决定转移否 O(n²)

消去型示例：移除盒子

状态定义为 dp[l][r][k]，k = 区间右侧与 a[r] 同色的盒子数量。

// 策略1：直接消去 a[r] 及右侧 k 个同色盒子 dp[l][r][k] = dp[l][r-1][0] + (k+1) * (k+1); // 策略2：在 [l, r-1] 中找同色位置 i for (int i = l; i < r; ++i) if (a[i] == a[r]) dp[l][r][k] = max(dp[l][r][k], dp[l][i][k+1] + dp[i+1][r-1][0]);
CSP-S 重点：合并型区间DP是考查重点。消去型通常需要三维或更高维度记录额外状态，难度较高，作为进阶了解。

四边形不等式优化：O(n³) → O(n²)

动机

石子合并 O(n³) 在 n ≥ 1000 时无法通过。四边形不等式可以将复杂度优化到 O(n²)。

四边形不等式条件

若代价函数 w(l, r) 满足：对于任意 a ≤ b ≤ c ≤ d：

w(a, c) + w(b, d) ≤ w(a, d) + w(b, c)

则DP具有决策单调性：设 s[l][r] 为 dp[l][r] 的最优分割点 k：

s[l][r-1] ≤ s[l][r] ≤ s[l+1][r]

优化代码对比

// 朴素 O(n³) for (int k = l; k < r; ++k) dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + sum(l,r)); // 四边形不等式优化 O(n²) for (int k = s[l][r-1]; k <= s[l+1][r]; ++k) { int val = dp[l][k] + dp[k+1][r] + sum(l, r); if (val < dp[l][r]) { dp[l][r] = val; s[l][r] = k; } }

效果对比

数据规模朴素 O(n³)四边不等式 O(n²)
n = 100~10⁶ AC~10⁴ AC
n = 500~1.25x10⁸ 可能TLE~2.5x10⁵ AC
n = 1000~10⁹ TLE~10⁶ AC
n = 5000TLE~2.5x10⁷ AC
CSP-S 建议：n ≤ 500 直接写 O(n³)；n ≥ 1000 才需优化。考前熟练掌握 O(n³) 模板更为重要，优化技巧掌握原理即可。

真题精练

题1：环形石子合并【洛谷 P1880】

n ≤ 100，环形石子合并，求最小得分和最大得分。

关键步骤：破环成链 x2 → 前缀和 O(1) → 标准五步区间DP → 遍历 dp[i][i+n-1]。
复杂度 O(n³) ≈ 10⁶。样例：[4,5,9,4] 输出 "43 54"。

题2：能量项链【洛谷 P1063 / NOIP2006】

n ≤ 100，环形能量珠合并，求最大总能量。

关键步骤：head 数组扩展至 2n → dp[l][r] = max(dp[l][k]+dp[k][r]+head[l]*head[k+1]*head[r+1]) → ans = max(dp[i][i+n-1])。
复杂度 O(n³) ≈ 10⁶。样例：[2,3,5,10] 输出 710。

题3：环形最大子段和（拓展）

长度为 n 的环形数组，求最大子段和。

解法一（DP）：不跨越边界 → Kadane；跨越边界 → total - min_subarray_sum；取 max。
解法二（破环成链）：复制 x2，滑动窗口求长度 ≤ n 的最大子段和。
注意全负数：若 max_normal < 0，直接返回 max_normal。

优化技巧与总结

优化技巧大全

技巧说明效果
破环成链 x2环形转线性，复制序列到 2n适用所有环形DP
前缀和pre[r+1] - pre[l] O(1)必备优化
四边形不等式s[l][r-1] ≤ s[l][r] ≤ s[l+1][r]O(n³)→O(n²)

常见易错点

  • 环形答案取错：不是 dp[0][n-1]，必须遍历 dp[i][i+n-1]
  • 能量项链转移：dp[l][k] + dp[k][r]，不是 dp[l][k] + dp[k+1][r]
  • 前缀和下标：环形下 pre 长度 = 2n+1，公式 pre[r+1]-pre[l]
  • len 枚举范围：环形问题只需枚举到 n，不是 2n
  • 头标记索引偏移：能量项链 head 数组和珠子的对应关系要厘清
  • 初始化区别：求最小值 dp[i][i]=0 其余 INF，求最大值 dp 全 0

本课核心总结

  • 破环成链法 x2 是处理环形DP的万能模板
  • 能量项链 是 NOIP2006 经典真题，转移有关键差异
  • 区间DP分 合并型（二维dp）和 消去型（需额外维度）
  • 四边形不等式优化 可将 O(n³) 降到 O(n²)
  • 考前务必手写环形石子合并和能量项链各 3-5 遍
CSP-S 应试核心：环形石子合并和能量项链是区间DP的必考题型。破环成链是处理环形DP的万能模板。建议将两类环形问题各练习 3 遍以上。
