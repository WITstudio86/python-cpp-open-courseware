🧮 原理推导：vector 扩容与均摊分析

扩容因子 k 的影响

因子实现最大内存浪费级数收敛
k = 2GCC libstdc++100%发散（不能复用内存）
k = 1.5MSVC / Clang libc++50%收敛（可复用旧内存）

均摊 O(1) 证明（k = 2）

// 插入 n 个元素，容量序列：1, 2, 4, 8, ..., 2^m  (2^m ≥ n)
// 扩容时拷贝总次数：1 + 2 + 4 + ... + 2^(m-1) = 2^m - 1 ≤ 2n - 1
// 均摊拷贝：(2n-1) / n ≈ 2 → O(1)

vector<int> v;
v.reserve(100000);  // 最佳实践：一次分配，永不扩容

swap 释放内存的原理

// clear() 和 shrink_to_fit() 都不能 100% 保证释放内存
// = 唯一可靠的方法：与临时空 vector 交换 =
vector<int>().swap(v);  // 临时对象析构时释放 v 原来持有的内存
⚠️ 关键区别：reserve 只改变 capacity，resize 改变 size（可能顺带改变 capacity）。 v[3] = 42 需要 3 < v.size() 而不是 3 < v.capacity()！

💻 代码模板：高频操作速查

vector 最优填充模式

vector<int> v;
v.reserve(n);          // ① 先预分配
for (int i = 0; i < n; i++)
    v.emplace_back(i);   // ② 再原位构造 (比 push_back 快 30-50%)

字符串分割

vector<string> split(const string& s, char delim) {
    vector<string> tokens;
    stringstream ss(s);
    string token;
    while (getline(ss, token, delim))
        if (!token.empty())
            tokens.push_back(token);
    return tokens;
}

迭代器安全删除（erase-remove 惯用法）

// 删除所有偶数
v.erase(remove_if(v.begin(), v.end(),
    [](int x) { return x % 2 == 0; }), v.end());

stringstream 类型转换

// 任意类型 → string
template<typename T> string tos(const T& v) {
    ostringstream oss; oss << v; return oss.str();
}
// string → 任意类型
template<typename T> T sto(const string& s) {
    T val; istringstream(s) >> val; return val;
}

⚠️ 易错点：6 大迭代器失效场景

场景操作失效范围解决办法
1push_back 触发扩容所有迭代器失效提前 reserve
2insert 触发扩容所有迭代器失效提前 reserve + 使用返回值
3insert 未扩容插入点之后失效it = v.insert(it, val);
4erase 删除元素删除点及之后失效it = v.erase(it);
5resize 增大可能所有失效先 reserve 再 resize
6clear / swap所有迭代器失效重新获取迭代器

常见错误示例

// ❌ 错误：erase 后迭代器失效，++it 是未定义行为
for (auto it = v.begin(); it != v.end(); ++it)
    if (*it % 2 == 0) v.erase(it);  // 💥 崩溃！

// ✅ 正确：使用 erase 的返回值
for (auto it = v.begin(); it != v.end(); )
    if (*it % 2 == 0) it = v.erase(it);
    else ++it;
⚠️ 额外陷阱：string::find 返回值是 size_t（无符号类型），不要用 >= 0 判断，必须用 != string::npos。用 int 接收会发生截断！

📝 真题精练

真题一：字符串展开

给定压缩字符串如 3(ab) → ababab，2(a3(bc)) → abcbcbcabcbcbc，支持嵌套。展开后总长度 ≤ 10⁶。

string decode(const string& s, int& pos) {
    string result;
    while (pos < (int)s.size()) {
        if (s[pos] == ')') { pos++; return result; }
        if (isdigit(s[pos])) {
            int num = 0;
            while (isdigit(s[pos])) num = num * 10 + (s[pos++] - '0');
            pos++;  // 跳过 '('
            string sub = decode(s, pos);
            for (int i = 0; i < num; i++) result += sub;
        } else { result += s[pos++]; }
    }
    return result;
}

复杂度：O(输出长度) 时间，O(深度 + 输出长度) 空间。递归 + string 拼接。
