一、快速幂算法 O(log n)

核心思想：二分幂 / 二进制拆分

递归视角：

ab = ab/2 · ab/2  （b 偶数）
ab = a · ab/2 · ab/2  （b 奇数）

每次指数折半 → O(log b)

迭代视角（二进制拆分）：

例：b = 13 = (1101)₂ = 8+4+1

a13 = a8 · a4 · a1

遍历二进制位，位为 1 则乘入

// 迭代快速幂（推荐，避免递归栈溢出） long long fastPow(long long a, long long b, long long MOD) { long long result = 1; a %= MOD; // 先取模防溢出 while (b > 0) { if (b & 1) result = result * a % MOD; a = a * a % MOD; // a → a² → a⁴ → a⁸ b >>= 1; } return result; }
【讲解】一、快速幂算法 O(log n) 本页要点（照着讲即可）： · 递归视角： · 每次指数折半 → O(log b) · 迭代视角（二进制拆分）： · 例：b = 13 = (1101)₂ = 8+4+1 · 遍历二进制位，位为 1 则乘入 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。 本课大纲考点（可适时点题）：快速幂、乘法逆元（费马小定理、扩欧）、模运算性质

二、模运算基本性质 & 费马小定理求逆元

模运算基本性质

运算性质
加法(a + b) mod m = ((a mod m) + (b mod m)) mod m
减法(a - b) mod m = ((a mod m) - (b mod m) + m) mod m
乘法(a · b) mod m = ((a mod m) · (b mod m)) mod m
除法无直接公式！需用乘法逆元

费马小定理求逆元

若 p 为质数且 a 不是 p 的倍数：

ap-1 ≡ 1 (mod p)

推导：a · ap-2 ≡ 1 (mod p)

a-1 ≡ ap-2 (mod p)

使用快速幂 O(log p) 求出

long long invFermat(long long a, long long MOD) { return fastPow(a, MOD - 2, MOD); }

适用条件：MOD 必须是质数

常见质数模数 1e9+7   998244353   1000000007

三、扩展欧几里得求逆元 & 线性求逆元

扩展欧几里得求逆元

当 gcd(a, m) = 1 时，解 ax + my = 1：

x 即为 a 在模 m 下的逆元。

通用 m 不一定是质数

// 扩展欧几里得求 ax+by=gcd ll exgcd(ll a, ll b, ll &x, ll &y) { if (b == 0) { x=1; y=0; return a; } ll d = exgcd(b, a%b, y, x); y -= a/b * x; return d; } ll invExgcd(ll a, ll MOD) { ll x, y; if (exgcd(a, MOD, x, y) != 1) return -1; return (x % MOD + MOD) % MOD; }

线性求逆元 O(n)

当 MOD 为质数时，O(n) 求出 1~n 所有逆元：

inv[i] = (MOD - MOD/i) · inv[MOD % i] % MOD

推导：设 MOD = k·i + r（k=MOD/i, r=MOD%i）

k·i + r ≡ 0 → r ≡ -k·i
乘 r⁻¹·i⁻¹ → i⁻¹ ≡ -k·r⁻¹

void linearInv(int n, ll MOD, ll inv[]) { inv[1] = 1; for (int i = 2; i <= n; i++) inv[i] = (MOD - MOD / i) * inv[MOD % i] % MOD; }
【讲解】三、扩展欧几里得求逆元 & 线性求逆元 本页要点（照着讲即可）： · 当 gcd(a, m) = 1 时，解 ax + my = 1： · gcd(a, m) = 1 · x 即为 a 在模 m 下的逆元。 · 通用 m 不一定是质数 · 当 MOD 为质数时，O(n) 求出 1~n 所有逆元： · 推导： 设 MOD = k·i + r（k=MOD/i, r=MOD%i） 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

四、组合数取模 & 完整代码模板

C(n, k) mod p 的标准做法（p 为质数）

C(n, k) = fact[n] · invFact[k] · invFact[n - k] mod p

预处理：O(n) 算阶乘 → O(log p) 求 invFact[n] → O(n) 倒推

// 预处理阶乘与阶乘逆元 void precompute(int n, ll MOD) { fact[0] = 1; for (int i = 1; i <= n; i++) fact[i] = fact[i-1] * i % MOD; invFact[n] = fastPow(fact[n], MOD - 2, MOD); for (int i = n; i >= 1; i--) invFact[i-1] = invFact[i] * i % MOD; } // O(1) 查询组合数 ll C(int n, int k, ll MOD) { if (k < 0 || k > n) return 0; return fact[n] * invFact[k] % MOD * invFact[n-k] % MOD; }
