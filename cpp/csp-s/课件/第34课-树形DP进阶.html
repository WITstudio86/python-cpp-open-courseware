两种方法

① 两次DFS（仅非负权）
② 树形DP（可负权）

模型一

树的直径

直径定义为树上任意两点间的最长简单路径长度。

方法1：两次DFS

从任意点找最远点A，再从A找最远点B。dist(A,B)即为直径。

仅适用于边权非负 | O(n)

方法2：树形DP

维护每个节点向下最长路径d1和次长路径d2。diameter = max(d1[i] + d2[i])。

可处理负权边 | O(n) | 一次DFS

方法2核心代码： int diameter = 0; int dfs(int u, int fa) { int d1 = 0, d2 = 0; for (auto [v, w] : g[u]) { if (v == fa) continue; int d = dfs(v, u) + w; if (d > d1) { d2 = d1; d1 = d; } else if (d > d2) d2 = d; } diameter = max(diameter, d1 + d2); return d1; }

模型二

树上背包 — 选课问题

n 门课，每门有学分和先修课。选 m 门课，若选某课则其先修课也必须选。求最大总学分。

建模思路

① 添加虚拟根节点 0（学分为 0）
② 所有无先修课的课程父节点设为 0 → 构建有根树
③ 问题转化为：在树上选 m+1 个节点（含虚拟根），父节点必选，最大化学分
④ 使用分组背包模型进行 DP 转移

// 核心转移（分组背包） void dfs(int u) { sz[u] = 1; dp[u][1] = score[u]; for (int v : g[u]) { dfs(v); // j 逆序，上限取 min(m, sz[u]+sz[v]) for (int j = min(m, sz[u] + sz[v]); j >= 1; j--) for (int k = max(1, j - sz[u]); k <= min(j-1, sz[v]); k++) dp[u][j] = max(dp[u][j], dp[u][j-k] + dp[v][k]); sz[u] += sz[v]; } }
复杂度优化： 利用子树大小 sz 剪枝，j 的上界取已处理大小而非 m， 可将复杂度从 O(nm²) 优化到 O(nm)。

模型三

换根DP — 二次扫描法

有时需要求以每个节点为根时的某种 DP 值。 若对每个根都重新计算，复杂度 O(n²)。换根 DP 可在 O(n) 内完成。

第一次扫描（后序）

固定根为 1，计算每个节点的子树信息：子树大小 size[u]、子树内深度和 dp_down[u]。

size[u] = 1 + Σ size[v] dp_down[u] = Σ (dp_down[v] + size[v])

第二次扫描（先序）

利用父节点答案推导子节点答案。从 u 换根到 v 的递推公式：

ans[v] = ans[u] + n - 2×size[v]

换根公式的直观理解

从以 u 为根切换到以 v 为根时：
• 子树 v 中的 size[v] 个点到新根的距离减 1
• 其余 n - size[v] 个点到新根的距离加 1
因此：ans[v] = ans[u] - size[v] + (n - size[v])

求一个节点为根，使得所有节点深度之和最大。多解输出编号最小的。
n ≤ 10⁶ · 换根DP: ans[v] = ans[u] + n - 2×size[v]

树形DP进阶总结

✓ 树的直径

两次DFS（非负权，简洁）或树形DP维护 d1+d2（可负权）。均为 O(n)。

✓ 树上背包

将子树视为分组背包的"组"。利用子树大小剪枝优化到 O(nm)。

✓ 换根DP

固定根 → 子树信息 → 利用父节点递推。核心是找到换根公式。

CSP-S 考试要点： 树的直径是高频考点（优先两次DFS）； 树上背包关注复杂度剪枝；换根DP掌握两次扫描框架。 识别题目中的树结构是第一步！
