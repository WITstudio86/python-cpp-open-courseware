📖 知识精讲：Trie 树概述

什么是 Trie 树？

Trie 树（字典树、前缀树）是一种用于高效存储和检索字符串集合的树形数据结构。

核心思想：利用字符串的公共前缀来减少查询时间。

基本性质

  • 根节点不包含字符，每个非根节点只包含一个字符
  • 从根到某节点的路径 = 该节点对应的字符串
  • 每个节点的子节点字符各不相同

时间复杂度

操作时间复杂度
插入长度为 L 的字符串O(L)
查询长度为 L 的字符串O(L)
空间复杂度O(总字符数 × 字符集)

数据结构定义

const int N = 100010; // 节点总数 int son[N][26]; // Trie 树（小写字母） int cnt[N]; // 以该节点结尾的单词数 int idx = 0; // 当前节点编号（0=根节点）
注意：节点编号从 1 开始，0 是根节点。N 要开到「总字符数」，而非字符串个数。

🔍 插入与查询操作

插入操作 insert

void insert(const string &s) { int p = 0; // 从根节点开始 for (char ch : s) { int c = ch - 'a'; if (!son[p][c]) son[p][c] = ++idx; // 不存在则新建 p = son[p][c]; } cnt[p]++; // 字符串结束标记 }

查询操作 query

int query(const string &s) { int p = 0; for (char ch : s) { int c = ch - 'a'; if (!son[p][c]) return 0; // 路径不存在 p = son[p][c]; } return cnt[p]; // 返回出现次数 }

🔢 01Trie —— 二进制字典树

什么是 01Trie？

01Trie 是 Trie 树的特例：将整数按二进制位插入 Trie（字符集为 {0, 1}），从高位到低位依次处理。

为什么从高位开始？

高位对数值大小的影响更大。例如 25 = 32 远大于 24 + 23 + ... + 20 = 31。求解最大异或值时，高位取 1 比低位取 1 重要得多。

🏆 最大异或对 —— 贪心策略

问题：给定 N 个数，求两两异或的最大值

贪心策略

对于查询值 x 的每一位 bit：尽量走与 bit 相反的边（bit ^ 1）。

如果相反的边存在，异或结果的这一位就是 1；如果不存在，只能走相同的边，异或结果为 0。

为什么贪心是正确的？

因为 2i > 2i-1 + 2i-2 + ... + 20，即高位取 1 的贡献大于所有低位取 1 的贡献之和。优先保证高位异或出 1 必然最优。

核心代码

int queryMaxXor(int x) { int p = 0, res = 0; for (int i = 30; i >= 0; i--) { int bit = (x >> i) & 1; if (son[p][bit ^ 1]) { // 尽量走相反的位 res |= (1 << i); // 这一位异或结果为 1 p = son[p][bit ^ 1]; } else { p = son[p][bit]; } } return res; // 返回最大异或值 }

📝 真题精练 1：前缀统计

题目

维护一个字符串集合，支持两种操作：
I s：向集合中插入字符串 s
Q s：询问集合中有多少个字符串以 s 为前缀
总操作数 ≤ 10⁵，字符串总长度 ≤ 10⁵

样例

输入： 5 I abc I abcdef I ab Q ab Q abc 输出： 3 2

解题关键

  • 维护 pass 数组：记录每个节点被经过的次数
  • insert 时每经过一个节点 pass[p]++
  • 查询前缀时，如果路径存在则返回终点的 pass 值
时间复杂度：O(总字符数)，远优于每次查询都暴力匹配的 O(NL)。

📝 真题精练 2：最大异或对

题目

给定 N 个整数 a₁, a₂, ..., aN，选出两个数进行异或运算，求最大结果。
数据范围：1 ≤ N ≤ 10⁵，0 ≤ aᵢ ≤ 2³¹ - 1

样例

输入输出解释
5
1 2 3 4 5		74 ⊕ 3 = 7 (100 ⊕ 011 = 111)

解题步骤

  1. 将每个数按二进制（高位到低位）插入 01Trie
  2. 对每个数 x，在 01Trie 中贪心查询最大异或值：每位尽量走相反边
  3. 取所有查询结果的最大值
时间复杂度：O(N × 31) = O(N log MAX)，相比暴力 O(N²) 有了质的提升。

🔮 可持久化 Trie 入门

什么是可持久化 Trie？

可持久化 Trie 用于查询历史版本中与某个值异或最大的值。

核心思想：节点复用

  • 每次插入时，新建一条路径上的所有节点
  • 其他节点复用之前版本的节点
  • 每个节点记录一个 version（版本号），表示该节点属于哪个版本
  • 查询时只走 version ≥ L 的节点

典型应用：区间最大异或和

查询 a[l..r] 中与 x 异或最大的值。

// 可持久化 Trie 插入框架 void insert(int prev, int ver, int x) { int p = root[ver] = ++idx; int q = root[prev]; for (int i = 30; i >= 0; i--) { int bit = (x >> i) & 1; son[p][bit ^ 1] = son[q][bit ^ 1]; // 复用另一分支 son[p][bit] = ++idx; // 新建当前分支 p = son[p][bit]; q = son[q][bit]; } }
