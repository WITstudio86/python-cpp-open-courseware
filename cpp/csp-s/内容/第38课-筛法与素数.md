## 一、素数判定（试除法）

### 1.1 朴素试除法

判定 $n$ 是否为素数：从 $2$ 到 $\sqrt{n}$ 试除，若存在因子则不是素数。

```cpp
bool isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
```

时间复杂度：$O(\sqrt{n})$。

### 1.2 优化的试除法

所有大于 $3$ 的素数都可以表示为 $6k \pm 1$ 的形式。因此只需试除 $2, 3$ 和 $6k \pm 1$ 形式的数。

```cpp
bool isPrimeFast(int n) {
    if (n < 2) return false;
    if (n == 2 || n == 3) return true;
    if (n % 2 == 0 || n % 3 == 0) return false;
    // 从 5 开始，步长为 6（因为素数 ≡ ±1 mod 6）
    for (int i = 5; i * i <= n; i += 6)
        if (n % i == 0 || n % (i + 2) == 0)
            return false;
    return true;
}
```

时间复杂度约为 $O(\sqrt{n} / 6)$，常数优化明显。

## 二、埃拉托色尼筛法（埃氏筛）

### 2.1 算法思想

从 $2$ 开始，将每个素数的所有倍数标记为合数。最终未被标记的数即为素数。

### 2.2 算法步骤

1. 创建布尔数组 `isPrime[0..n]`，全部初始化为 `true`
2. `isPrime[0] = isPrime[1] = false`
3. 从 $i=2$ 到 $\sqrt{n}$：
   - 若 `isPrime[i] == true`，则对于 $j = i^2, i^2+i, i^2+2i, \dots$，标记 `isPrime[j] = false`
4. 遍历数组，所有 `isPrime[i] == true` 的 $i$ 即为素数

### 2.3 时间复杂度

$$O(n \log \log n)$$

调和级数近似：$\sum_{p \le n} \frac{n}{p} \approx n \cdot \ln \ln n$。

### 2.4 代码实现

```cpp
const int MAXN = 10000005;
bool isPrime[MAXN];

// 埃氏筛：求出 1..n 中的所有素数
int eratosthenes(int n) {
    fill(isPrime, isPrime + n + 1, true);
    isPrime[0] = isPrime[1] = false;
    int cnt = 0;
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) {
            cnt++;
            // 从 i*i 开始标记（i*2, i*3, ..., i*(i-1) 已被标记过）
            if ((long long)i * i <= n) {
                for (int j = i * i; j <= n; j += i)
                    isPrime[j] = false;
            }
        }
    }
    return cnt;
}
```

### 2.5 优化技巧

- 内层循环从 $i^2$ 而非 $2i$ 开始（$2i$ 到 $(i-1)i$ 已被更小的素数筛掉）
- 只用奇数筛可以减半空间

## 三、欧拉筛（线性筛）—— 重点

### 3.1 核心思想

**每个合数只被它的最小质因子筛掉一次**，从而保证 $O(n)$ 的线性时间复杂度。

### 3.2 算法步骤

- 维护质数列表 `primes[]` 和标记数组 `isPrime[]`
- 遍历 $i$ 从 $2$ 到 $n$：
  1. 若 `isPrime[i] == true`，将 $i$ 加入 `primes[]`
  2. 对于 `primes[]` 中的每个素数 $p$：
     - 若 $i \times p > n$，跳出
     - 标记 $i \times p$ 为合数
     - 若 $i \bmod p = 0$，跳出内层循环（关键！保证每个合数只被最小质因子筛掉）

### 3.3 关键分析

当 $i \bmod p = 0$ 时：
- 设 $i = p \times k$
- 下一个素数 $p' > p$，则 $i \times p' = p \times (k \times p')$
- $p$ 是 $i \times p'$ 的最小质因子
- 因此 $i \times p'$ 应该在 $i' = k \times p'$ 时被 $p$ 筛掉，现在跳过

**这保证了每个合数只被筛一次！**

### 3.4 代码实现

```cpp
int primes[MAXN];  // 存储素数
bool isPrime[MAXN];

int eulerSieve(int n) {
    fill(isPrime, isPrime + n + 1, true);
    isPrime[0] = isPrime[1] = false;
    int cnt = 0;  // 素数个数
    for (int i = 2; i <= n; i++) {
        if (isPrime[i])
            primes[cnt++] = i;
        for (int j = 0; j < cnt && (long long)i * primes[j] <= n; j++) {
            isPrime[i * primes[j]] = false;
            if (i % primes[j] == 0)  // primes[j] 是 i 的最小质因子
                break;
        }
    }
    return cnt;
}
```

时间复杂度：$O(n)$，每个合数被筛恰好一次。

## 四、素数分布定理

### 4.1 素数定理

设 $\pi(n)$ 表示不超过 $n$ 的素数个数，则：

$$\pi(n) \sim \frac{n}{\ln n}$$

### 4.2 第 $n$ 个素数的近似

第 $n$ 个素数 $p_n$ 约等于 $n \ln n$。

### 4.3 实际应用

| $n$ | $\pi(n)$ | $n/\ln n$ |
|-----|----------|-----------|
| $10^2$ | 25 | 22 |
| $10^3$ | 168 | 145 |
| $10^4$ | 1229 | 1086 |
| $10^5$ | 9592 | 8686 |
| $10^6$ | 78498 | 72382 |
| $10^7$ | 664579 | 620421 |
| $10^8$ | 5761455 | 5428681 |

从表可知，$n \le 10^6$ 约有 $8 \times 10^4$ 个素数，完全可以用线性筛处理。

## 五、区间筛

### 5.1 问题描述

求 $[a, b]$ 区间内的素数个数/列表。
- $b$ 可能非常大（如 $10^{12}$），不能直接筛到 $b$
- 但 $b - a$ 较小（如 $\le 10^6$），可以用区间筛

### 5.2 算法思路

1. 先用线筛/埃筛求出 $[2, \sqrt{b}]$ 内的所有素数
2. 用这些素数去筛 $[a, b]$ 区间内的合数

### 5.3 代码实现

```cpp
// 区间筛：求 [a, b] 区间内的素数个数
// b 可高达 10^12，b - a <= 10^6
long long segmentSieve(long long a, long long b) {
    // 1. 预处理 [2, sqrt(b)] 的素数
    int limit = sqrt(b);
    // primes[] 来自欧拉筛
    
    // 2. 标记区间 [a, b] 的合数
    vector<bool> isPrimeSeg(b - a + 1, true);
    if (a == 1) isPrimeSeg[0] = false;  // 1 不是素数
    
    for (int i = 0; i < cnt && primes[i] <= limit; i++) {
        long long p = primes[i];
        // 找到区间内第一个 p 的倍数
        long long start = max(p * p, (a + p - 1) / p * p);
        for (long long j = start; j <= b; j += p)
            isPrimeSeg[j - a] = false;
    }
    
    // 3. 统计
    long long ans = 0;
    for (long long i = a; i <= b; i++)
        if (isPrimeSeg[i - a]) ans++;
    return ans;
}
```

**注意：** `(a + p - 1) / p * p` 是向上取整的常用技巧（整数除法天花板）。

## 六、欧拉函数 $\varphi(n)$

### 6.1 定义

$\varphi(n)$ 表示小于等于 $n$ 且与 $n$ 互质的正整数个数。即：

$$\varphi(n) = \left|\{ x \mid 1 \le x \le n, \gcd(x, n) = 1 \}\right|$$

### 6.2 计算公式

若 $n = p_1^{a_1} \cdot p_2^{a_2} \cdots p_k^{a_k}$（质因数分解），则：

$$\varphi(n) = n \cdot \prod_{i=1}^k \left(1 - \frac{1}{p_i}\right) = n \cdot \prod_{i=1}^k \frac{p_i - 1}{p_i}$$

### 6.3 性质

1. **积性：** 若 $\gcd(a, b) = 1$，则 $\varphi(ab) = \varphi(a) \cdot \varphi(b)$
2. **质数的 $\varphi$：** $\varphi(p) = p - 1$（$p$ 为质数）
3. **质数幂的 $\varphi$：** $\varphi(p^k) = p^k - p^{k-1} = p^{k-1}(p-1)$
4. **求和性质：** $\sum_{d \mid n} \varphi(d) = n$

### 6.4 单点求欧拉函数 $O(\sqrt{n})$

```cpp
long long phi(long long n) {
    long long res = n;
    for (long long i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            res = res / i * (i - 1);
            while (n % i == 0) n /= i;
        }
    }
    if (n > 1) res = res / n * (n - 1);
    return res;
}
```

## 七、线性筛求欧拉函数

### 7.1 核心思想

在欧拉筛的过程中，利用欧拉函数的积性性质，同时求出 $\varphi(1)$ 到 $\varphi(n)$。

### 7.2 递推关系

在筛素数时，对于每个 $i$ 和素数 $p = \text{primes}[j]$，筛掉合数 $t = i \times p$ 时，计算 $\varphi(t)$：

- **情况1：** $p \mid i$（即 $i \bmod p = 0$）
  - $p$ 是 $i$ 的质因子
  - $\varphi(i \times p) = \varphi(i) \times p$（因为 $i$ 已包含 $p$ 的贡献）

- **情况2：** $p \nmid i$（即 $i \bmod p \neq 0$）
  - $p$ 与 $i$ 互质
  - $\varphi(i \times p) = \varphi(i) \times \varphi(p) = \varphi(i) \times (p-1)$

### 7.3 完整代码

```cpp
int primes[MAXN];
bool isPrime[MAXN];
int phi[MAXN];  // 欧拉函数值

void eulerSieveWithPhi(int n) {
    fill(isPrime, isPrime + n + 1, true);
    isPrime[0] = isPrime[1] = false;
    int cnt = 0;
    phi[1] = 1;
    
    for (int i = 2; i <= n; i++) {
        if (isPrime[i]) {
            primes[cnt++] = i;
            phi[i] = i - 1;  // 质数的 φ(p) = p - 1
        }
        for (int j = 0; j < cnt && (long long)i * primes[j] <= n; j++) {
            int p = primes[j];
            isPrime[i * p] = false;
            
            if (i % p == 0) {
                // p 是 i 的最小质因子
                phi[i * p] = phi[i] * p;
                break;
            } else {
                // p 与 i 互质，利用积性
                phi[i * p] = phi[i] * (p - 1);
            }
        }
    }
}
```

时间复杂度：$O(n)$。

## 八、CSP-S 考点总结

| 算法 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|-----------|-----------|----------|
| 试除法（朴素） | $O(\sqrt{n})$ | $O(1)$ | 单点判定小 $n$ |
| 试除法（6k±1） | $O(\sqrt{n})$ | $O(1)$ | 单点判定（常数优化） |
| 埃氏筛 | $O(n \log \log n)$ | $O(n)$ | 筛素数到 $10^7$ |
| 欧拉筛（线性筛） | $O(n)$ | $O(n)$ | 筛素数到 $10^7$~$10^8$ |
| 区间筛 | $O((b-a) \log \log \sqrt{b})$ | $O(\sqrt{b} + (b-a))$ | $b$ 大但 $b-a$ 小 |
| 线性筛求 $\varphi$ | $O(n)$ | $O(n)$ | 批量求欧拉函数 |

## 九、真题精练

### 例题1：区间筛模板题

**题目：** 给定 $a, b$（$1 \le a \le b \le 10^{12}$，$b - a \le 10^6$），求 $[a, b]$ 区间内素数个数。

**输入格式：** 两个整数 $a, b$。

**输出格式：** 一个整数，表示素数个数。

**示例输入：**
```
1 100
```
**示例输出：**
```
25
```

**参考解法：** 先用欧拉筛求出 $[2, \sqrt{b}]$ 的素数，再区间筛 $[a, b]$。

---

### 例题2：欧拉函数求和

**题目：** 给定 $n$（$1 \le n \le 10^7$），求 $\sum_{i=1}^n \varphi(i)$。

**输入格式：** 一个整数 $n$。

**输出格式：** 一个整数（可能超过 int 范围，用 long long）。

**示例输入：**
```
10
```
**示例输出：**
```
32
```
**说明：** φ(1)=1, φ(2)=1, φ(3)=2, φ(4)=2, φ(5)=4, φ(6)=2, φ(7)=6, φ(8)=4, φ(9)=6, φ(10)=4，总和=32。

**参考解法：** 线性筛同时求欧拉函数，再求前缀和。
