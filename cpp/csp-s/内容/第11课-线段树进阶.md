## 📖 知识精讲

### 一、多懒标记协同

当线段树需要同时支持**区间加法**和**区间乘法**时，需要维护两个懒标记 `add[p]` 和 `mul[p]`。

**核心原则**：**先乘后加**。对于一个值为 x 的元素：
- 操作序列：先乘 a 再加 b → a·x + b
- 如果再乘 c 再加 d → c·(a·x + b) + d = (a·c)·x + (b·c + d)

因此更新规则为（新来的乘法 c 和加法 d）：
```cpp
mul[p] = mul[p] * c;           // 先乘
add[p] = add[p] * c + d;        // 后加：原有 add 也要乘 c
tree[p] = tree[p] * c + (r-l+1) * d;
```

**多懒标记 pushdown**：

```cpp
void pushdown(int p, int l, int r) {
    int mid = (l + r) >> 1;
    int lc = p << 1, rc = p << 1 | 1;

    // 下传给左儿子
    tree[lc] = (tree[lc] * mul[p] + add[p] * (mid - l + 1));
    mul[lc] = mul[lc] * mul[p];
    add[lc] = add[lc] * mul[p] + add[p];

    // 下传给右儿子
    tree[rc] = (tree[rc] * mul[p] + add[p] * (r - mid));
    mul[rc] = mul[rc] * mul[p];
    add[rc] = add[rc] * mul[p] + add[p];

    // 重置当前节点标记
    mul[p] = 1;   // 乘法单位元
    add[p] = 0;   // 加法单位元
}
```

**注意**：初始化时 `mul[p] = 1`（乘法单位元），`add[p] = 0`（加法单位元）。

### 二、权值线段树（值域线段树）

权值线段树不维护数组下标，而是维护**值域**。其叶子节点代表某个值的出现次数。

**用途**：
1. 查询全局第 K 小数（线段树二分）
2. 查询某个数的排名
3. 查询前驱/后继
4. 配合动态开点实现主席树

**第 K 小数查询**（在线段树上二分）：

```cpp
// 在线段树上查找第 k 小的值
int kth(int p, int l, int r, int k) {
    if (l == r) return l;               // 找到叶子
    int mid = (l + r) >> 1;
    if (tree[p << 1] >= k)              // 左子树的元素数 >= k
        return kth(p << 1, l, mid, k);
    else
        return kth(p << 1 | 1, mid + 1, r, k - tree[p << 1]);
}
```

**时间复杂度**：O(log V)，其中 V 是值域大小。配合动态开点，可处理值域达 10⁹ 的情况。

### 三、线段树合并（动态开点）

当需要合并两个线段树（如处理树上问题时），使用线段树合并。

**前提**：使用**动态开点**的线段树（左/右儿子用指针/数组索引表示，不用 2p 和 2p+1）。

**合并算法**（以两棵权值线段树合并为例）：

```cpp
// 返回合并后的新节点编号
int merge(int p, int q, int l, int r) {
    if (!p || !q) return p + q;    // 一方为空，返回另一方
    if (l == r) {
        tree[p].cnt += tree[q].cnt; // 叶子节点：合并计数
        return p;
    }
    int mid = (l + r) >> 1;
    tree[p].lc = merge(tree[p].lc, tree[q].lc, l, mid);
    tree[p].rc = merge(tree[p].rc, tree[q].rc, mid + 1, r);
    pushup(p);
    return p;
}
```

**时间复杂度**：O(m log V)，其中 m 为两树共有的节点数量。均摊 O(n log V)。

### 四、可持久化线段树（主席树）

可持久化线段树保存每次修改的历史版本，基于**动态开点**实现。每次修改只新建 O(log n) 个节点。

**单点修改的可持久化**：

```cpp
// 在版本 pre 的基础上，修改位置 x 的值为 v，返回新版本根节点
int update(int pre, int l, int r, int x, int v) {
    int p = ++tot;                 // 新建节点
    tree[p] = tree[pre];          // 复制旧节点信息
    if (l == r) {
        tree[p].val = v;
        return p;
    }
    int mid = (l + r) >> 1;
    if (x <= mid)
        tree[p].lc = update(tree[pre].lc, l, mid, x, v);
    else
        tree[p].rc = update(tree[pre].rc, mid + 1, r, x, v);
    pushup(p);
    return p;
}
```

**经典应用**：静态区间第 K 小数（主席树 + 前缀和思想）。

## 💻 代码模板

```cpp
// ========== 多懒标记线段树（加法 + 乘法） ==========
struct Node {
    long long sum, add, mul;
} tree[4 * MAXN];

void build(int p, int l, int r) {
    tree[p].add = 0; tree[p].mul = 1;
    if (l == r) { tree[p].sum = a[l]; return; }
    int mid = (l + r) >> 1;
    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);
    pushup(p);
}

void pushdown(int p, int l, int r) {
    int mid = (l + r) >> 1;
    int lc = p << 1, rc = p << 1 | 1;
    long long mul = tree[p].mul, add = tree[p].add;

    tree[lc].sum = (tree[lc].sum * mul + add * (mid - l + 1));
    tree[lc].mul = tree[lc].mul * mul;
    tree[lc].add = tree[lc].add * mul + add;

    tree[rc].sum = (tree[rc].sum * mul + add * (r - mid));
    tree[rc].mul = tree[rc].mul * mul;
    tree[rc].add = tree[rc].add * mul + add;

    tree[p].mul = 1; tree[p].add = 0;
}

// ========== 权值线段树第 K 小 ==========
int kth(int p, int l, int r, int k) {
    if (l == r) return l;
    int mid = (l + r) >> 1;
    if (tree[p << 1] >= k)
        return kth(p << 1, l, mid, k);
    else
        return kth(p << 1 | 1, mid + 1, r, k - tree[p << 1]);
}
```

## ⚠️ 易错点与优化技巧

1. **多懒标记顺序**：必须遵循"先乘后加"原则，乘法对加法标记也有影响
2. **顺序一致性**：pushdown 和 update 中的乘法/加法顺序必须一致
3. **取模运算**：多懒标记配合取模时，所有运算都需要取模
4. **动态开点的空间**：通常开到 `操作数 × log(值域)`，约 20~40 倍
5. **线段树合并不回溯**：合并后原树可能被修改，注意是否需要备份
6. **权值线段树配合离散化**：若值域太大但元素数不多，可以先离散化
7. **主席树的内存**：每次修改新建 O(log n) 节点，需预开足够空间
8. **数组复用**：线段树合并中，节点编号可能快速增长，注意回收

## 📝 真题精练

### 真题一：[CSP-S 模拟] 区间乘法和加法

**题目描述**：
维护数组 a[1..n]，支持三种操作：
1. `1 l r v`：a[l..r] 每个元素乘 v（模 P）
2. `2 l r v`：a[l..r] 每个元素加 v（模 P）
3. `3 l r`：查询 a[l..r] 的和（模 P）

**数据范围**：n, m ≤ 10⁵，P 为质数，1 ≤ P ≤ 10⁹+7

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, m;
long long P, a[MAXN];

struct Node {
    long long sum, add, mul;
} tree[4 * MAXN];

void pushup(int p) {
    tree[p].sum = (tree[p << 1].sum + tree[p << 1 | 1].sum) % P;
}

void build(int p, int l, int r) {
    tree[p].add = 0; tree[p].mul = 1;
    if (l == r) { tree[p].sum = a[l] % P; return; }
    int mid = (l + r) >> 1;
    build(p << 1, l, mid);
    build(p << 1 | 1, mid + 1, r);
    pushup(p);
}

void pushdown(int p, int l, int r) {
    int mid = (l + r) >> 1;
    int lc = p << 1, rc = p << 1 | 1;
    long long mu = tree[p].mul, ad = tree[p].add;

    tree[lc].sum = (tree[lc].sum * mu + ad * (mid - l + 1)) % P;
    tree[lc].mul = (tree[lc].mul * mu) % P;
    tree[lc].add = (tree[lc].add * mu + ad) % P;

    tree[rc].sum = (tree[rc].sum * mu + ad * (r - mid)) % P;
    tree[rc].mul = (tree[rc].mul * mu) % P;
    tree[rc].add = (tree[rc].add * mu + ad) % P;

    tree[p].mul = 1; tree[p].add = 0;
}

void update_mul(int p, int l, int r, int ql, int qr, long long v) {
    if (ql <= l && r <= qr) {
        tree[p].sum = (tree[p].sum * v) % P;
        tree[p].mul = (tree[p].mul * v) % P;
        tree[p].add = (tree[p].add * v) % P;
        return;
    }
    pushdown(p, l, r);
    int mid = (l + r) >> 1;
    if (ql <= mid) update_mul(p << 1, l, mid, ql, qr, v);
    if (qr > mid)  update_mul(p << 1 | 1, mid + 1, r, ql, qr, v);
    pushup(p);
}

void update_add(int p, int l, int r, int ql, int qr, long long v) {
    if (ql <= l && r <= qr) {
        tree[p].sum = (tree[p].sum + v * (r - l + 1)) % P;
        tree[p].add = (tree[p].add + v) % P;
        return;
    }
    pushdown(p, l, r);
    int mid = (l + r) >> 1;
    if (ql <= mid) update_add(p << 1, l, mid, ql, qr, v);
    if (qr > mid)  update_add(p << 1 | 1, mid + 1, r, ql, qr, v);
    pushup(p);
}

long long query(int p, int l, int r, int ql, int qr) {
    if (ql <= l && r <= qr) return tree[p].sum;
    pushdown(p, l, r);
    int mid = (l + r) >> 1;
    long long res = 0;
    if (ql <= mid) res = (res + query(p << 1, l, mid, ql, qr)) % P;
    if (qr > mid)  res = (res + query(p << 1 | 1, mid + 1, r, ql, qr)) % P;
    return res;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    cin >> n >> m >> P;
    for (int i = 1; i <= n; i++) cin >> a[i];
    build(1, 1, n);
    while (m--) {
        int op, l, r; long long v;
        cin >> op >> l >> r;
        if (op == 1) { cin >> v; update_mul(1, 1, n, l, r, v % P); }
        else if (op == 2) { cin >> v; update_add(1, 1, n, l, r, v % P); }
        else cout << query(1, 1, n, l, r) << '\n';
    }
    return 0;
}
```

**复杂度分析**：O((n+m) log n)。

### 真题二：[CSP-S 模拟] 权值线段树 — 排名查询

**题目描述**：
维护一个可重集合，支持：
1. 插入一个数 x
2. 删除一个数 x（保证 x 存在）
3. 查询第 k 小的数
4. 查询 x 的排名（比 x 小的数的个数 + 1）

**数据范围**：操作数 q ≤ 2×10⁵，|x| ≤ 10⁷

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005, OFFSET = 1e7 + 5;
int tot = 0, root = 0;
int sum[MAXN * 30], lc[MAXN * 30], rc[MAXN * 30];

void pushup(int p) { sum[p] = sum[lc[p]] + sum[rc[p]]; }

void update(int &p, int l, int r, int x, int v) {
    if (!p) p = ++tot;
    if (l == r) { sum[p] += v; return; }
    int mid = l + (r - l) / 2;
    if (x <= mid) update(lc[p], l, mid, x, v);
    else          update(rc[p], mid + 1, r, x, v);
    pushup(p);
}

int kth(int p, int l, int r, int k) {
    if (l == r) return l;
    int mid = l + (r - l) / 2;
    if (sum[lc[p]] >= k) return kth(lc[p], l, mid, k);
    else return kth(rc[p], mid + 1, r, k - sum[lc[p]]);
}

int rnk(int p, int l, int r, int x) {
    if (!p) return 0;
    if (l == r) return 0; // 不包含等于 x 的
    int mid = l + (r - l) / 2;
    if (x <= mid) return rnk(lc[p], l, mid, x);
    else return sum[lc[p]] + rnk(rc[p], mid + 1, r, x);
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    int q; cin >> q;
    const int L = -1e7, R = 1e7;
    while (q--) {
        int op, x; cin >> op >> x;
        if (op == 1) update(root, L, R, x, 1);       // 插入
        else if (op == 2) update(root, L, R, x, -1);  // 删除
        else if (op == 3) cout << rnk(root, L, R, x) + 1 << '\n';  // 排名
        else if (op == 4) cout << kth(root, L, R, x) << '\n';      // 第k小
    }
    return 0;
}
```

**复杂度分析**：每次操作 O(log V)，V = 2×10⁷，实际 log V ≈ 25。

## 🎯 本课小结

1. **多懒标记**：先乘后加，乘法影响加法标记，pushdown 时注意顺序
2. **权值线段树**：维护值域而非下标，实现排名/第K小查询
3. **动态开点**：值域大时必需的优化，节点只在使用时创建
4. **线段树合并**：O(m log V) 合并两树，常用于树上问题
5. **主席树**：可持久化 + 前缀和 → 静态区间第 K 小
