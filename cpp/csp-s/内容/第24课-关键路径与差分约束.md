## 📖 知识精讲

### 一、AOE 网与关键路径

**AOE 网（Activity On Edge network）** 是一种带权有向无环图，用于描述工程项目中各活动之间的依赖关系和持续时间：
- **顶点（事件）**：表示某个时刻——前面所有活动都已完成，后面活动可以开始的瞬间。
- **有向边（活动）**：表示一个任务/活动，边的权值表示该活动的持续时间。
- **源点**：入度为 0 的顶点，表示工程的起始事件。
- **汇点**：出度为 0 的顶点，表示工程的结束事件。

**关键路径（Critical Path）** 是从源点到汇点的最长路径。关键路径上的活动称为**关键活动**，它们没有任何时间余量，任何延迟都会导致整个工程的延迟。

**工程的最短完成时间 = 关键路径的长度**。因为所有活动最终都需要完成，所以总工期由最长的那个依赖链决定。

### 二、最早发生时间 ve 与最晚发生时间 vl

**事件的最早发生时间 ve（earliest）**：
- 从源点开始，沿正向拓扑序递推。
- 对于事件 v，ve[v] = max{ ve[u] + w(u,v) }，其中 (u,v) 是 v 的所有入边。
- 源点的 ve = 0。

**事件的最晚发生时间 vl（latest）**：
- 从汇点开始，沿反向拓扑序递推。
- 对于事件 u，vl[u] = min{ vl[v] - w(u,v) }，其中 (u,v) 是 u 的所有出边。
- 汇点的 vl = ve（先让工程在最短时间完成）。

**关键活动判定**：对于活动 (u, v)，若满足：
- `ve[u] = vl[u]` 且 `ve[v] = vl[v]`
- `ve[u] + w(u,v) = ve[v]`

则该活动为关键活动。

等价简化：活动 (u,v) 是关键活动当且仅当 `ve[u] + w(u,v) = vl[v]`（即活动的最早完成时间等于最晚完成时间）。

### 三、关键路径算法步骤

1. **建图**：构建 AOE 网的邻接表，统计入度。
2. **正向拓扑排序 + ve 计算**：按拓扑序依次处理节点，对每条出边 (u→v, w)，更新 `ve[v] = max(ve[v], ve[u] + w)`。
3. **确定汇点**：工程的完成时间 = 所有节点 ve 的最大值（即汇点的 ve）。
4. **反向拓扑排序 + vl 计算**：初始化所有节点 vl = 汇点 ve，按拓扑序的逆序处理，对每条出边 (u→v, w)，更新 `vl[u] = min(vl[u], vl[v] - w)`。
5. **找出关键活动**：遍历所有边，若 `ve[u] + w == vl[v]`，则 (u,v) 是关键活动。
6. **输出关键路径**：从源点出发，沿关键活动走到汇点。

**时间复杂度**：O(V+E)，空间复杂度 O(V+E)。

### 四、差分约束系统

**差分约束系统** 是一组形如 `x_i - x_j ≤ c_k` 的不等式，其中 c_k 是常数。

**核心转化**：将不等式 `x_i - x_j ≤ c` 转化为图中的边 `j → i`，权值为 `c`。这是因为**最短路径的三角不等式**：
- 如果 dist[i] 是源点到 i 的最短距离，那么对于每条边 `j → i (权c)`，有 `dist[i] ≤ dist[j] + c`
- 令 `x_i = dist[i]`，则 `x_i ≤ x_j + c`，即 `x_i - x_j ≤ c`

所以，求解差分约束系统 = 在转化后的图中求**单源最短路径**！

### 五、SPFA 求解差分约束

**算法步骤：**

1. **建图**：对每个不等式 `x_i - x_j ≤ c`，添加边 `j → i`，权值为 `c`。
2. **超级源点**：创建一个虚拟节点 `n`（编号从 0 开始则为 n），向所有节点连一条权值为 0 的边（`n → i, w=0`）。这保证了从超级源点出发可以到达所有节点，同时也为变量提供了一个统一的参考基准。
3. **SPFA 求最短路**：以超级源点为起点运行 SPFA。
4. **判无解**：如果 SPFA 检测到**负环**，说明不等式组无解。因为负环意味着 `x_i ≤ x_i + (负数和)`，即 `0 ≤ 负数`，矛盾。
5. **得到一组可行解**：`x_i = dist[i]`（从超级源点到 i 的最短距离）。

**解的平移性质**：若 `(x_1, x_2, ..., x_n)` 是一组可行解，则 `(x_1+d, x_2+d, ..., x_n+d)` 也是可行解。因为 `(x_i+d) - (x_j+d) = x_i - x_j ≤ c`。

### 六、常见不等式的转化

| 原不等式 | 转化 | 建边 |
|----------|------|------|
| x_i - x_j ≤ c | x_i ≤ x_j + c | j → i, w=c |
| x_i - x_j ≥ c | x_j ≤ x_i - c | i → j, w=-c |
| x_i - x_j = c | x_i - x_j ≤ c 且 x_j - x_i ≤ -c | j→i w=c, i→j w=-c |
| x_i ≤ c | x_i - x_0 ≤ c（设 x_0 为超级源点） | 0 → i, w=c |
| x_i ≥ c | x_0 - x_i ≤ -c | i → 0, w=-c |

### 七、关键路径与差分约束的关系

两者都依赖于图论中的「最短路/最长路」框架：

- **关键路径**：求 DAG 中的**最长路径**（将边权取反可转化为最短路径）。
- **差分约束**：将不等式组转化为图的**最短路径**问题。

共性：都使用图来表达「约束/依赖」关系，并通过图的遍历（拓扑序/SPFA）求解。

## 💻 代码模板

### 模板一：关键路径算法

```cpp
struct Edge {
    int to, weight;
};

// 返回：first=工程最短完成时间, second=关键活动列表
pair<int, vector<pair<int,int>>> criticalPath(int n, vector<tuple<int,int,int>>& edges) {
    // n: 节点数(0~n-1), edges: (u, v, w)
    vector<vector<Edge>> adj(n);
    vector<int> indegree(n, 0);
    for (auto& [u, v, w] : edges) {
        adj[u].push_back({v, w});
        indegree[v]++;
    }
    
    // 1. 拓扑排序 + 计算 ve
    vector<int> ve(n, 0);
    queue<int> q;
    for (int i = 0; i < n; i++)
        if (indegree[i] == 0) q.push(i);
    
    vector<int> topo;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);
        for (auto& e : adj[u]) {
            ve[e.to] = max(ve[e.to], ve[u] + e.weight);
            if (--indegree[e.to] == 0) q.push(e.to);
        }
    }
    
    // 2. 计算 vl（逆拓扑序）
    int maxTime = *max_element(ve.begin(), ve.end());
    vector<int> vl(n, maxTime);
    for (int i = n - 1; i >= 0; i--) {
        int u = topo[i];
        for (auto& e : adj[u]) {
            vl[u] = min(vl[u], vl[e.to] - e.weight);
        }
    }
    
    // 3. 找出关键活动
    vector<pair<int,int>> critical;
    for (auto& [u, v, w] : edges) {
        if (ve[u] + w == vl[v]) {
            critical.push_back({u, v});
        }
    }
    
    return {maxTime, critical};
}
```

### 模板二：差分约束 SPFA 求解

```cpp
// 求解差分约束系统 x_i - x_j ≤ c
// 若存在负环则返回 false（无解）
bool diffConstraint(int n, vector<tuple<int,int,int>>& constraints, vector<int>& result) {
    // n: 变量数(0~n-1), constraints: (j, i, c) 表示 x_i - x_j ≤ c
    int N = n + 1;          // 额外一个超级源点
    int super = n;          // 超级源点编号
    vector<vector<pair<int,int>>> adj(N);
    
    // 1. 添加约束边
    for (auto& [j, i, c] : constraints)
        adj[j].push_back({i, c});
    
    // 2. 超级源点连向所有节点，权值为 0
    for (int i = 0; i < n; i++)
        adj[super].push_back({i, 0});
    
    // 3. SPFA 求最短路
    vector<int> dist(N, 1e9), cnt(N, 0);
    vector<bool> inq(N, false);
    queue<int> q;
    
    dist[super] = 0;
    q.push(super);
    inq[super] = true;
    
    while (!q.empty()) {
        int u = q.front(); q.pop();
        inq[u] = false;
        for (auto& [v, w] : adj[u]) {
            if (dist[v] > dist[u] + w) {        // 松弛操作
                dist[v] = dist[u] + w;
                cnt[v] = cnt[u] + 1;
                if (cnt[v] >= N) return false;  // 负环，无解
                if (!inq[v]) {
                    q.push(v);
                    inq[v] = true;
                }
            }
        }
    }
    
    for (int i = 0; i < n; i++) result[i] = dist[i];
    return true;
}
```

## ⚠️ 易错点与优化技巧

### 常见错误

| 错误类型 | 错误表现 | 正确做法 |
|---------|---------|---------|
| ve/vl 初始化错误 | ve 初始化为极大值 | ve 应初始化为 0（源点最早开始时间为0） |
| vl 不统一 | 各节点 vl 初始值不一致 | 所有节点 vl 都应初始化为汇点的 ve |
| 差分约束建边方向反 | 将 x_i - x_j ≤ c 建为 i→j | 正确的建边方向是 j→i |
| 超级源点遗忘 | SPFA 无法到达某些节点 | 必须从超级源点向所有节点连权0边 |
| 负环检测阈值太小 | cnt ≥ n 而非 cnt ≥ n+1 | 节点数包含超级源点后为 N，应用 cnt ≥ N |

### 优化技巧

1. **关键路径替代实现**：可将边权取负，在 DAG 上用 DP 求最短路，再将结果取负得到最长路。
2. **差分约束的 SPFA 优化**：使用 SLF（Small Label First）或 LLL 优化；对于稀疏图可用优先队列优化版 SPFA（接近 Dijkstra）。
3. **预先拓扑序优化**：如果差分约束图是 DAG（无不含超级源点的环），可以直接按拓扑序 DP，O(V+E) 即可求解。
4. **最长路求法**：将不等式方向反转（x_i - x_j ≥ c）或用 Bellman-Ford 求最长路（初始化 -INF，松弛方向反转）。

## 📝 真题精练

### 题目1：关键路径（CSP-J/S 经典题型）

**题目描述**：给定一个 AOE 网，包含 n 个事件（节点 0 ~ n-1）和 m 个活动（有向边）。求：
1. 完成整个工程的最短时间
2. 关键路径上的活动

**输入格式**：
- 第一行 n m
- 接下来 m 行，每行 u v w，表示活动从 u 到 v，持续时间为 w

**解题思路**：
1. 正向拓扑排序计算 ve
2. 反向计算 vl
3. 遍历所有边，ve[u]+w == vl[v] 的边为关键活动

**AC 代码**：见程序文件 `lesson24_critical_path_diff_constraint.cpp` 中的 `criticalPathMain()` 函数。

---

### 题目2：差分约束（POJ 1201 / CSP 经典题型）

**题目描述**：给定 m 个约束条件，每个条件形如 `x_b - x_a ≥ c`，求满足所有约束的最小解空间范围。

**解题思路**：将约束转化为最短路问题，使用 SPFA 求解。
- `x_b - x_a ≥ c` 转化为 `x_a - x_b ≤ -c`，建边 `b → a`，权值为 `-c`。
- 添加超级源点保证连通性。

**AC 代码**：见程序文件 `lesson24_critical_path_diff_constraint.cpp` 中的 `diffConstraintMain()` 函数。

## 🎯 本课小结

1. **AOE 网**：用顶点表示事件、有向边表示活动的带权 DAG。
2. **ve 最早时间**：正向拓扑 DP，取入边 ve+weight 的最大值。
3. **vl 最晚时间**：逆向拓扑 DP，取出边 vl-weight 的最小值。
4. **关键活动判定**：`ve[u] + w == vl[v]` 成立时，(u,v) 为关键活动。
5. **差分约束系统**：`x_i - x_j ≤ c` 等价于图中 `j→i`、权 `c` 的最短路径约束。
6. **SPFA 求解**：用 SPFA 求最短路，检测负环判断无解。
7. **超级源点**：向所有节点连权 0 的边，保证连通性和统一基准。
8. **时间复杂度**：关键路径 O(V+E)；差分约束 SPFA O(VE) 最坏，实际通常更快。
