## 📖 知识精讲

### 一、树的直径

树的直径（Diameter）定义为树上任意两点间的最长简单路径的长度（或边数）。求解树的直径是树形DP的基本应用，有两种经典方法。

#### 方法1：两次DFS（两次BFS）

**算法原理：**
树上两点间的最长路径有以下性质：从任意一点 u 出发，到达最远点 v 一定是直径的一个端点。再从 v 出发到达最远点 w，路径 v→w 即为直径。

**算法步骤：**
```
1. 从任意节点（如1号节点）出发，做一次DFS/BFS，找到距离最远的节点A
2. 从节点A出发，再做一次DFS/BFS，找到距离最远的节点B
3. 路径 A→B 即为直径，dist(A,B) 即为直径长度
```

**正确性证明概要：**
设真正的直径端点为 P 和 Q（即 P→Q 是直径）。从任意点 u 出发，找到最远点 v。
- 若 v 恰好是 P 或 Q，则第二次DFS从 v 出发必然找到真正的直径。
- 若 v 不是 P 或 Q，设路径 u→v 与直径 P→Q 首次相交于节点 X。由"v 是离 u 最远的点"可推导出 dist(v,X) ≥ dist(P,X) 且 dist(v,X) ≥ dist(Q,X)，从而 v→P 或 v→Q 中必有一条不短于 P→Q，因此 v 必然是某条直径的端点。

**时间复杂度：** O(n)，两次遍历。

**适用范围：** 仅适用于边权**非负**的树。若有负权边，该算法失效。

**代码模板（两次DFS法）：**
```cpp
// dist[i]: 从起点到节点i的距离
// 第一次DFS找到最远端点A
void dfs1(int u, int fa) {
    for (auto [v, w] : g[u]) {
        if (v == fa) continue;
        dist[v] = dist[u] + w;
        if (dist[v] > dist[A]) A = v;    // 更新最远点
        dfs1(v, u);
    }
}

// 第二次DFS从A出发找到直径另一端B
void dfs2(int u, int fa) {
    for (auto [v, w] : g[u]) {
        if (v == fa) continue;
        dist[v] = dist[u] + w;
        if (dist[v] > dist[B]) B = v;
        dfs2(v, u);
    }
}
// 直径长度 = dist[B]
```

#### 方法2：树形DP法

**算法原理：**
对每个节点 u，维护从 u 出发向下的最长路径长度 `dp1[u]` 和次长路径长度 `dp2[u]`（两条路径不能经过同一个子节点）。直径就是以 u 为"拐点"的最长路径：`diameter = max(dp1[u] + dp2[u])`。

**状态设计：**
- `dp1[u]`：从 u 出发，向下走的最长路径长度
- `dp2[u]`：从 u 出发，向下走的次长路径长度（与 dp1[u] 来自不同儿子）

**状态转移：**
```
对于 u 的每个儿子 v，设边权为 w：
    路径长 = dp1[v] + w
    若 路径长 > dp1[u]：
        dp2[u] = dp1[u]
        dp1[u] = 路径长
    否则若 路径长 > dp2[u]：
        dp2[u] = 路径长
```

最终直径 = max(dp1[u] + dp2[u])（遍历所有 u）。

**代码模板（树形DP法）：**
```cpp
int diameter = 0;

int dfs(int u, int fa) {
    int d1 = 0, d2 = 0;           // 最长和次长向下路径
    for (auto [v, w] : g[u]) {
        if (v == fa) continue;
        int d = dfs(v, u) + w;    // 经过v向下的路径长
        if (d > d1) { d2 = d1; d1 = d; }
        else if (d > d2) { d2 = d; }
    }
    diameter = max(diameter, d1 + d2);
    return d1;                    // 返回从u出发向下的最长路径
}
```

**时间复杂度：** O(n)，一次DFS。

**适用范围：** 可以处理**负权边**（此时 d1, d2 初始化为 -INF 而非 0）。但两次DFS法在有负权边时不适用。

**两种方法的对比：**

| 特性 | 两次DFS法 | 树形DP法 |
|------|----------|---------|
| 时间复杂度 | O(n) | O(n) |
| 边权要求 | 必须非负 | 可处理负权 |
| 实现难度 | 简单 | 中等 |
| 能否记录具体路径 | 容易（两次遍历记录前驱） | 较复杂（需要额外数组） |
| 扩展性 | 仅求直径 | 可求所有节点向下的最长路径 |

### 二、树上背包（依赖背包问题）

**问题背景：** 选课问题（洛谷 P2014 / AcWing 286）。有 n 门课程，每门课有学分，部分课程有先修课要求（形成森林结构）。需要选出 m 门课程使得总学分最大。如果一门课有先修课，则必须先修它的先修课。

#### 1. 问题建模

将课程关系建成一棵树（添加虚拟根节点 0 连接所有森林的根，虚拟根学分为 0）。问题转化为：在树上选择恰好 m+1 个节点（含虚拟根），满足父子依赖关系（选子必选父），最大化学分总和。

#### 2. 状态设计

- `dp[u][j]`：在以 u 为根的子树中，选择 j 门课程（包含 u 本身）能获得的最大总学分。

状态维度的含义：
- 第一维 u：当前子树的根节点
- 第二维 j：表示在当前子树中一共选了多少门课（0 ≤ j ≤ min(size[u], m)）

#### 3. 状态转移（分组背包模型）

```
初始化：
    dp[u][1] = score[u]          // 只选u自己
    dp[u][0] = 0                 // 不选u（但选了u的祖先）

对于 u 的每个儿子 v（先修 v 的子树）：
    对于 j 从 当前已处理大小 递减到 2：
        对于 k 从 1 到 size[v] 且 k < j：
            dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k])
    更新已处理大小 += size[v]
```

这个转移本质是**分组背包**：将每个儿子子树视为一组物品，组内只能选一种"选 k 门课"的方案。

#### 4. 复杂度分析

- 朴素实现：O(n × m²)，最坏情况 O(n³)
- 优化实现（利用子树大小剪枝）：O(n × m)，因为每个节点对 (u,v) 的枚举次数受限于它们所在子树的大小乘积，总和为 O(nm)
- 关键在于：j 的枚举上界取 `min(已处理大小, m)`，k 的上界取 `size[v]`

**时间复杂度优化到 O(nm) 的原理（简要）：**
在处理 u 的所有子树时，任意两个节点 a,b（来自不同子树）只会在它们的 LCA（u）处被枚举一次。总枚举次数 = O(n × m)。

**代码模板（树上背包）：**
```cpp
void dfs(int u) {
    size[u] = 1;
    dp[u][1] = score[u];         // 选u自己
    dp[u][0] = 0;
    
    for (int v : g[u]) {
        dfs(v);
        // 分组背包：逆序枚举容量
        for (int j = min(m, size[u] + size[v]); j >= 1; j--) {
            for (int k = max(1, j - size[u]); k <= min(j - 1, size[v]); k++) {
                dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k]);
            }
        }
        size[u] += size[v];
    }
}
```

### 三、换根DP（二次扫描法 / Rerooting DP）

**问题背景：** 有时需要求出以每个节点为根时的某种DP值（如：每个节点到其他所有节点的距离之和、以每个节点为根时的最大独立集等）。如果对每个根都重新计算，复杂度为 O(n²)。换根DP可以在 O(n) 内完成。

#### 核心思想：两次扫描

1. **第一次扫描（Downward / Post-order）：** 固定一个根（如1号节点），用树形DP计算出每个节点的"子树信息"。
2. **第二次扫描（Upward / Pre-order）：** 从根节点出发，利用父节点的全局信息，推导出子节点作为根时的全局信息。

#### 经典模型：求每个节点到其他所有节点的距离之和

**状态定义：**
- `size[u]`：以 u 为根的子树中的节点数
- `dp_down[u]`：以 u 为根的子树中，所有节点到 u 的距离之和
- `dp_all[u]`：整棵树中，所有节点到 u 的距离之和（最终答案）

**第一次扫描（自底向上）：**
```
dp_down[u] = Σ (dp_down[v] + size[v])    // 子树v中每个节点到u的距离 = 到v的距离 + 1
size[u] = 1 + Σ size[v]
```

**第二次扫描（自顶向下，换根公式）：**
```
// 已知父节点 u 的全局答案 dp_all[u]，求子节点 v 的 dp_all[v]
// 从 u 换根到 v 时：
//   - 子树 v 中的点（共 size[v] 个）离 v 比离 u 近 1
//   - 其余点（共 n - size[v] 个）离 v 比离 u 远 1
dp_all[v] = dp_all[u] - size[v] + (n - size[v])
          = dp_all[u] + n - 2 * size[v]
```

**关键洞察（换根公式的推导）：**
```
dp_all[v] = Σ_{x∈子树v} (dist(u,x) - 1) + Σ_{x∉子树v} (dist(u,x) + 1)
          = dp_all[u] - size[v] + (n - size[v])
          = dp_all[u] + n - 2 * size[v]
```

**完整的二次扫描框架：**
```cpp
// 第一次扫描：计算子树信息
void dfs1(int u, int fa) {
    size[u] = 1;
    dp_down[u] = 0;
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs1(v, u);
        size[u] += size[v];
        dp_down[u] += dp_down[v] + size[v];
    }
}

// 第二次扫描：换根，计算全局答案
void dfs2(int u, int fa) {
    for (int v : g[u]) {
        if (v == fa) continue;
        // 换根公式
        dp_all[v] = dp_all[u] + n - 2 * size[v];
        dfs2(v, u);
    }
}

// 主函数中：
dfs1(1, 0);
dp_all[1] = dp_down[1];          // 根节点的答案就是子树信息
dfs2(1, 0);
```

**时间复杂度：** O(n)，两次DFS。

#### 换根DP的通用框架

换根DP的关键是找到一个递推公式，能够在已知父节点答案的情况下，O(1) 推导出子节点的答案。适用于以下场景：
- 求每个节点到其他所有节点的距离之和（如上例）
- 求以每个节点为根时的最大独立集
- 求每个节点能到达的最远距离（树形DP求直径的变体）
- 树的重心相关问题

**一般模式：**
```
// 第一次（post-order）：计算以u为根的子树信息 sub[u]
sub[u] = merge( sub[v1], sub[v2], ... )    // 合并所有子树信息

// 第二次（pre-order）：利用父节点的全局信息 ans[fa] 更新 ans[u]
ans[u] = reroot(ans[fa], sub[u], sub[other_children_of_fa])
```

### 四、树上背包的复杂度优化详解

#### 为什么优化后是 O(nm) 而非 O(nm²)？

考虑以下枚举方式（正确实现）：
```
for (int j = min(m, size_now); j >= 1; j--)           // 当前已合并的容量
    for (int k = max(1, j - size_before); k <= min(j - 1, size[v]); k++)  // 新子树的贡献
        dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[v][k])
```

**为什么是 O(nm)：**
1. 每对节点 (a, b) 仅在其 LCA（最近公共祖先）处被枚举
2. 若节点 a 和节点 b 属于 u 的不同子树，则它们只在处理 u 时被同时考虑
3. 总枚举次数 ≤ n × m

**常见错误实现（导致 O(nm²)）：**
```
// 错误！没有利用 size 剪枝，枚举了无效状态
for (int j = m; j >= 1; j--)
    for (int k = 1; k < j; k++)
        // 很多 k 超过了 size[v]，枚举了无效状态
```

## 📝 真题精练

### 题目1：树的直径

**题目描述：**
给定一棵 n 个节点的树，边有长度（正整数），求树的直径长度（最长路径的长度）。

**数据范围：** 1 ≤ n ≤ 100000, 1 ≤ 边权 ≤ 1000

**解题思路：**
- 方法一（两次DFS）：从节点1开始DFS找到最远点A，再从A开始DFS找到最远点B，dist(A,B)即直径。适用于边权非负。
- 方法二（树形DP）：维护每个节点的最长向下路径和次长向下路径，直径 = max(dp1[u] + dp2[u])。可处理负权边。

**AC代码：** 见 `程序/lesson34_tree_dp_advanced.cpp`

**复杂度：** O(n) 时间，O(n) 空间。

### 题目2：选课问题（树上背包）

**题目描述：**
学校实行学分制。每门课有学分，有些课有先修课（最多一门）。学生必须修完先修课才能选后续课。共有 n 门课，需要选 m 门课，求最大总学分。

**数据范围：** 1 ≤ n ≤ 300, 1 ≤ m ≤ n, 1 ≤ 学分 ≤ 20

**解题思路：**
1. 添加虚拟根节点 0，所有没有先修课的课程的父亲设为 0
2. 转化为树上背包：选择 m+1 个节点（含虚拟根），父节点必选
3. 使用分组背包模型进行DP转移
4. 利用子树大小剪枝将复杂度优化到 O(nm)

**AC代码：** 见 `程序/lesson34_tree_dp_advanced.cpp`

**复杂度：** O(nm) 时间（优化后），O(nm) 空间。

## 🎯 本课小结

### 三种进阶模型总结

| 模型 | 核心思想 | 时间复杂度 | 关键技巧 |
|------|---------|-----------|---------|
| 树的直径 | 最长路径必然以某节点为"拐点" | O(n) | 两次DFS（只能非负权）或树形DP（可负权） |
| 树上背包 | 将子树视为分组背包的"组" | O(nm) | 利用子树大小剪枝，j枚举上限取已处理大小 |
| 换根DP | 先固定根求子树信息，再推导全局信息 | O(n) | 找到换根递推公式，利用父节点答案O(1)推导子节点 |

### CSP-S 考试要点

1. **树的直径**是高频考点，两次DFS法在边权非负时最简洁
2. **树上背包**常与"选课问题"、"依赖关系"结合，注意复杂度剪枝
3. **换根DP**常见于"求每个节点的某个全局属性"，需掌握两次扫描框架
4. 识别题目中的**树结构**是第一步——很多题目表面上是图，实际建图后是树
5. 树形DP进阶题常常需要**同时维护多个DP值**（最长+次长，选+不选等）
