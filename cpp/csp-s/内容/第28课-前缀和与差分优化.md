## 二、知识精讲

### 1. 一维前缀和

**定义**：对于数组 $a[1\dots n]$，前缀和 $pre[i] = \sum_{k=1}^{i} a[k]$

**递推公式**：

$$pre[0] = 0$$
$$pre[i] = pre[i-1] + a[i]$$

**区间和查询**：求 $[l, r]$ 的区间和（闭区间，$1 \le l \le r \le n$）

$$sum(l, r) = pre[r] - pre[l-1]$$

> **关键**：区间和查询从 $O(n)$ 降到 $O(1)$。

```cpp
vector<ll> build_prefix(const vector<ll>& a) {
    int n = a.size();
    vector<ll> pre(n + 1, 0);  // pre[0] = 0
    for (int i = 1; i <= n; ++i)
        pre[i] = pre[i-1] + a[i-1];  // 注意 a 是 0-indexed
    return pre;
}

ll range_sum(const vector<ll>& pre, int l, int r) {
    // l, r 是 1-indexed 的闭区间
    return pre[r] - pre[l-1];
}
```

### 2. 二维前缀和

**定义**：对于矩阵 $a[1\dots n][1\dots m]$，前缀和 $pre[i][j] = \sum_{x=1}^{i}\sum_{y=1}^{j} a[x][y]$，即 $(1,1)$ 到 $(i,j)$ 的矩形和。

**递推公式**（容斥原理）：

$$pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i][j]$$

**子矩阵和查询**：求以 $(x_1, y_1)$ 为左上角、$(x_2, y_2)$ 为右下角的子矩阵和：

$$sum(x_1, y_1, x_2, y_2) = pre[x_2][y_2] - pre[x_1-1][y_2] - pre[x_2][y_1-1] + pre[x_1-1][y_1-1]$$

> **可视化**：
> - $pre[x_2][y_2]$：整个大矩形
> - $- pre[x_1-1][y_2]$：减去上方多余行
> - $- pre[x_2][y_1-1]$：减去左方多余列
> - $+ pre[x_1-1][y_1-1]$：加回被重复减去的左上角

```cpp
vector<vector<ll>> build_prefix2d(const vector<vector<ll>>& a) {
    int n = a.size(), m = a[0].size();
    vector<vector<ll>> pre(n + 1, vector<ll>(m + 1, 0));
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j)
            pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + a[i-1][j-1];
    return pre;
}

ll rect_sum(const vector<vector<ll>>& pre,
            int x1, int y1, int x2, int y2) {
    // 坐标均为 1-indexed
    return pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1];
}
```

### 3. 一维差分数组

**核心思想**：对区间进行 $O(1)$ 修改，最后 $O(n)$ 还原。

**定义**：差分数组 $d$ 满足 $a[i] = \sum_{k=1}^{i} d[k]$，即 $a$ 是 $d$ 的前缀和。

**构造**：$d[i] = a[i] - a[i-1]$（令 $a[0] = 0$）

**区间修改**：对 $[l, r]$ 区间每个元素加 $val$

$$d[l] \mathrel{+}= val$$
$$d[r+1] \mathrel{-}= val$$

修改 $m$ 次后，对 $d$ 求前缀和即可得到最终的 $a$。

```cpp
vector<ll> build_diff(const vector<ll>& a) {
    int n = a.size();
    vector<ll> d(n + 2, 0);  // 多开一位防止 r+1 越界
    for (int i = 1; i <= n; ++i)
        d[i] = a[i-1] - (i == 1 ? 0 : a[i-2]);
    return d;
}

void range_add(vector<ll>& d, int l, int r, ll val) {
    // l, r 为 1-indexed
    d[l] += val;
    d[r + 1] -= val;
}

vector<ll> restore(const vector<ll>& d, int n) {
    vector<ll> a(n);
    ll cur = 0;
    for (int i = 1; i <= n; ++i) {
        cur += d[i];
        a[i-1] = cur;
    }
    return a;
}
```

### 4. 二维差分数组

对子矩阵进行 $O(1)$ 修改。

**子矩阵加 $val$**：对以 $(x_1, y_1)$ 为左上角、$(x_2, y_2)$ 为右下角的子矩阵所有元素加 $val$

$$d[x_1][y_1] \mathrel{+}= val$$
$$d[x_2+1][y_1] \mathrel{-}= val$$
$$d[x_1][y_2+1] \mathrel{-}= val$$
$$d[x_2+1][y_2+1] \mathrel{+}= val$$

还原时，对二维差分数组求**二维前缀和**即可。

```cpp
// 二维区间加
void rect_add(vector<vector<ll>>& d,
              int x1, int y1, int x2, int y2, ll val) {
    d[x1][y1]         += val;
    d[x2+1][y1]       -= val;
    d[x1][y2+1]       -= val;
    d[x2+1][y2+1]     += val;
}

// 还原：对 d 求二维前缀和
void restore2d(vector<vector<ll>>& d, int n, int m) {
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j)
            d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1];
}
```

### 5. 前缀和与DP的结合

前缀和不仅可以加速区间查询，还能优化DP的状态转移。

#### 5.1 前缀最大值优化

**场景**：DP转移形如 $dp[i] = \max_{j < i}\{ dp[j] + cost(i, j) \}$，其中 $cost$ 可分拆时，可用前缀最大值维护。

**经典例题**：最大子段和的另一种推导（前缀和视角）

设 $pre[i] = \sum_{k=1}^{i} a[k]$，则子段 $[l, r]$ 的和为 $pre[r] - pre[l-1]$。

最大子段和 = $\max_{1 \le l \le r \le n} (pre[r] - pre[l-1])$ = $\max_{r}\left( pre[r] - \min_{l \le r} pre[l-1] \right)$

```cpp
ll max_subarray_prefix(const vector<ll>& a) {
    ll pre = 0;
    ll min_pre = 0;          // 当前最小的前缀和
    ll ans = -INF;
    for (ll x : a) {
        pre += x;
        ans = max(ans, pre - min_pre);
        min_pre = min(min_pre, pre);
    }
    return ans;
}
```

#### 5.2 前缀和优化区间DP

很多区间DP问题可以配合前缀和 $O(1)$ 求区间和来优化。

### 6. 差分约束简介

差分约束系统是一组形如 $x_j - x_i \le c$ 的不等式，可以通过**最短路径算法**求解。

例如：已知 $x_1 - x_2 \le 3$，$x_2 - x_3 \le -2$，求 $x_1$ 与 $x_3$ 的最大可能差值。

**建模方法**：对每个约束 $x_j - x_i \le c$，建立一条从 $i$ 到 $j$ 权值为 $c$ 的有向边。从超级源点（与所有点连 0 权边）跑 SPFA/Bellman-Ford 最短路，得到的 $dist[i]$ 即为一组可行解（且满足 $x_i$ 最大）。

## 四、易错点与优化技巧

### 易错点

| 易错点 | 说明 | 修复方法 |
|--------|------|----------|
| 下标混乱 | 前缀和需 pre[0]=0，输入通常 0-indexed | 统一使用 1-indexed 的 pre 数组 |
| 二维容斥符号 | 子矩阵和公式中符号常写错 | 画图辅助记忆：加奇数次矩形、减偶数次 |
| 差分越界 | `r+1` 可能超出数组范围 | 差分数组多开 1~2 位 |
| 二维差分顺序 | 修改后直接求前缀和就能还原 | 确保修改操作在求前缀和之前完成 |
| 前缀和溢出 | 累加时可能超出 `int` 范围 | 使用 `long long` |
| 差分约束负环 | 存在负环时无解 | 用 SPFA 检测负环 |

### 优化技巧

1. **差分离线化**：所有修改执行完后再一次性还原，避免中间查询的额外开销
2. **前缀和预处理**：需要多次区间查询时，一次性构建前缀和
3. **二维转一维**：配合坐标压缩可将二维前缀和空间优化
4. **树状数组**：需要支持在线修改+区间查询时，可用树状数组（BIT）代替前缀和

## 五、真题精练

### 真题1：区间修改与查询（差分 + 前缀和）

**题目描述**：有一个长度为 $n$ 的初始全零数组，进行 $m$ 次操作：对 $[l, r]$ 每个元素加 $1$。求最终数组的最大值。

**数据范围**：$1 \le n, m \le 10^5$。

**解题思路**：差分数组 $O(1)$ 修改，最后 $O(n)$ 还原并求最大值。

**AC代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m; cin >> n >> m;
    vector<int> d(n + 2, 0);  // 差分数组，多开一位

    // 记录所有区间加
    while (m--) {
        int l, r; cin >> l >> r;
        d[l] += 1;
        d[r + 1] -= 1;
    }

    // 还原并求最大值
    int cur = 0, ans = 0;
    for (int i = 1; i <= n; ++i) {
        cur += d[i];
        ans = max(ans, cur);
    }
    cout << ans << "\n";
    return 0;
}
```

**复杂度分析**：
- 时间：$O(n + m)$
- 空间：$O(n)$

### 真题2：最大子矩阵和（前缀和优化版）

**题目描述**：给定 $n \times n$ 矩阵，多次查询任意子矩阵的元素和。有 $q$ 次查询。

**数据范围**：$1 \le n \le 1000$，$1 \le q \le 10^5$。

**解题思路**：预处理二维前缀和，每次查询 $O(1)$ 回答。

**AC代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, q;
    cin >> n >> q;

    // 二维前缀和（1-indexed）
    vector<vector<ll>> pre(n + 1, vector<ll>(n + 1, 0));
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            ll x; cin >> x;
            pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + x;
        }
    }

    while (q--) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        // 确保 x1 <= x2, y1 <= y2
        ll ans = pre[x2][y2] - pre[x1-1][y2] - pre[x2][y1-1] + pre[x1-1][y1-1];
        cout << ans << "\n";
    }
    return 0;
}
```

**复杂度分析**：
- 预处理：$O(n^2)$
- 每次查询：$O(1)$
- 总时间：$O(n^2 + q)$
- 空间：$O(n^2)$

## 六、本课小结

| 技术 | 核心公式 | 构建复杂度 | 查询/修改 | 空间复杂度 |
|------|----------|-----------|----------|-----------|
| 一维前缀和 | `pre[i] = pre[i-1] + a[i]` | $O(n)$ | $O(1)$ 区间和 | $O(n)$ |
| 二维前缀和 | 容斥公式（4项） | $O(nm)$ | $O(1)$ 子矩阵和 | $O(nm)$ |
| 一维差分 | `d[l]+=val, d[r+1]-=val` | $O(1)$ 修改 | $O(n)$ 还原 | $O(n)$ |
| 二维差分 | 4点修改 + 2D前缀和还原 | $O(1)$ 修改 | $O(nm)$ 还原 | $O(nm)$ |
| 前缀最值优化DP | `dp[i] = f(pre_min, pre_max)` | — | 取决于场景 | — |

**核心思想**：
1. **前缀和**将区间查询从 $O(n)$ 降到 $O(1)$——「预处理换时间」
2. **差分数组**将区间修改从 $O(n)$ 降到 $O(1)$——「离线批量处理」
3. **容斥原理**是二维前缀和/差分的核心，画图辅助理解
4. 前缀最值可以消除DP转移中的内层循环，是常见的优化手段
5. 下标从 **1 开始** 可以简化边界处理，是竞赛中的常用约定
