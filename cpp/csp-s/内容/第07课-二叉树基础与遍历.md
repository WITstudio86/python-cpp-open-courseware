## 📖 知识精讲

### 一、二叉树的定义与基本性质

**二叉树**是每个节点最多有两个子树的树结构，通常子树被称作"左子树"和"右子树"。二叉树是有序树，左右子树不能颠倒。

**基本术语**：
- **根节点（Root）**：树的最顶层节点，没有父节点
- **叶子节点（Leaf）**：没有子节点的节点
- **节点的度**：节点拥有的子树个数（二叉树中为 0、1 或 2）
- **树的深度（Depth）**：从根节点到最深叶子节点的路径长度

**特殊二叉树**：

**1. 满二叉树（Full Binary Tree）**

一棵深度为 k 且有 2^k - 1 个节点的二叉树称为满二叉树。即每一层的节点数都达到最大值。

```
        1                  ← 第1层：2^0 = 1 个节点
      /   \
     2     3               ← 第2层：2^1 = 2 个节点
    / \   / \
   4   5 6   7             ← 第3层：2^2 = 4 个节点
```

性质：对于深度为 k 的满二叉树：
- 节点总数 = 2^k - 1
- 第 i 层有 2^(i-1) 个节点
- 叶子节点数 = 2^(k-1)

**2. 完全二叉树（Complete Binary Tree）**

一棵深度为 k、有 n 个节点的二叉树，当且仅当其每一个节点都与深度为 k 的满二叉树中编号从 1 到 n 的节点一一对应时，称为完全二叉树。

简单理解：**完全二叉树是在满二叉树的基础上，从最后一层的最右边开始连续缺少若干个节点的树**。

**关键性质（数组存储的下标关系）**：

如果对一棵有 n 个节点的完全二叉树按层序编号（从 1 开始），则对编号为 i 的节点（1 ≤ i ≤ n）：

| 关系 | 下标 |
|------|------|
| 父节点 | i / 2（向下取整） |
| 左孩子 | 2 × i |
| 右孩子 | 2 × i + 1 |
| 判断是否有左孩子 | 2i ≤ n |
| 判断是否有右孩子 | 2i + 1 ≤ n |
| 判断是否为叶子 | 2i > n |
| 最后一个非叶子节点 | n / 2 |

这也是**堆（二叉堆）使用数组存储**的理论基础。

### 二、二叉树的存储方式

#### 方式一：链式存储（左右孩子表示法）

最常用的存储方式，每个节点包含数据域、左孩子指针和右孩子指针。

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};
```

**优点**：结构灵活，适用于任意形态的二叉树，节省空间
**缺点**：无法 O(1) 找到父节点（除非增加 parent 指针）

#### 方式二：数组存储法

将二叉树节点按层序编号，存储在一维数组中。**仅适用于完全二叉树或近似完全二叉树**。

```cpp
int tree[MAXN];      // tree[1] 是根节点
// tree[2*i] 是 i 的左孩子
// tree[2*i+1] 是 i 的右孩子
```

**优点**：父子节点访问 O(1)，无需指针，适用于堆、线段树等
**缺点**：对于退化为链的二叉树，空间浪费严重（需要开 2^深度 大小）

### 三、二叉树的四种遍历

二叉树的遍历是指按某种顺序访问树中的每一个节点，使得每个节点被访问一次且仅一次。

#### 1. 前序遍历（Preorder Traversal）—— 根 → 左 → 右

**访问顺序**：先访问根节点，再前序遍历左子树，最后前序遍历右子树。

```
遍历结果：A B D E C F G

        A
      /   \
     B     C
    / \   / \
   D   E F   G
```

**递归实现**：
```cpp
void preorder(TreeNode* root) {
    if (root == nullptr) return;
    cout << root->val << ' ';   // 访问根
    preorder(root->left);       // 遍历左子树
    preorder(root->right);      // 遍历右子树
}
```

**非递归实现（栈模拟）**：

核心思想：用**栈**模拟递归时的系统调用栈。由于前序是"根-左-右"，我们可以：
1. 将根节点入栈
2. 弹出栈顶并访问
3. **先压右孩子，再压左孩子**（因为栈是后进先出，这样左孩子会先被处理）

```cpp
void preorder_iterative(TreeNode* root) {
    if (root == nullptr) return;
    stack<TreeNode*> st;
    st.push(root);
    while (!st.empty()) {
        TreeNode* cur = st.top(); st.pop();
        cout << cur->val << ' ';       // 访问
        if (cur->right) st.push(cur->right);  // 先右
        if (cur->left)  st.push(cur->left);   // 后左
    }
}
```

**迭代过程模拟**（以 A(B(D),C) 为例）：
```
初始：栈 = [A]
第1步：弹出 A，访问 A，压入 C、B → 栈 = [C, B]  （栈顶是 B）
第2步：弹出 B，访问 B，压入 B 的右(nullptr)、左 D → 栈 = [C, D]
第3步：弹出 D，访问 D，D 无孩子 → 栈 = [C]
第4步：弹出 C，访问 C，C 无孩子 → 栈 = []
结束
输出：A B D C ✓
```

#### 2. 中序遍历（Inorder Traversal）—— 左 → 根 → 右

**访问顺序**：先中序遍历左子树，再访问根节点，最后中序遍历右子树。

```
遍历结果：D B E A F C G
```

**递归实现**：
```cpp
void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);        // 遍历左子树
    cout << root->val << ' ';   // 访问根
    inorder(root->right);       // 遍历右子树
}
```

**中序遍历的重要性质**：对于**二叉搜索树（BST）**，中序遍历的结果是递增有序序列。

**非递归实现（栈模拟）**：

核心思想：一直沿着左子树向下走，将沿途节点压栈；当无法继续向左时，弹出栈顶访问，然后转向右子树。

```cpp
void inorder_iterative(TreeNode* root) {
    stack<TreeNode*> st;
    TreeNode* cur = root;
    while (cur != nullptr || !st.empty()) {
        // 一路向左，将所有左孩子入栈
        while (cur != nullptr) {
            st.push(cur);
            cur = cur->left;
        }
        // 左子树为空或已遍历完，弹出栈顶
        cur = st.top(); st.pop();
        cout << cur->val << ' ';   // 访问
        cur = cur->right;           // 转向右子树
    }
}
```

**迭代过程模拟**：
```
以树 A(B(D,E),C(F,G)) 为例
初始：cur=A, 栈=[]
入栈 A, B, D → 栈=[A,B,D], cur=nullptr(D的左孩子)
弹出 D, 访问 D, cur=D.right=nullptr
弹出 B, 访问 B, cur=E
入栈 E → 栈=[A,E], cur=nullptr(E的左孩子)
弹出 E, 访问 E, cur=nullptr
弹出 A, 访问 A, cur=C
入栈 C, F → 栈=[C,F], cur=nullptr
弹出 F, 访问 F, cur=nullptr
弹出 C, 访问 C, cur=G
入栈 G → 栈=[G], cur=nullptr
弹出 G, 访问 G, cur=nullptr
输出：D B E A F C G ✓
```

#### 3. 后序遍历（Postorder Traversal）—— 左 → 右 → 根

**访问顺序**：先后序遍历左子树，再后序遍历右子树，最后访问根节点。

```
遍历结果：D E B F G C A
```

**递归实现**：
```cpp
void postorder(TreeNode* root) {
    if (root == nullptr) return;
    postorder(root->left);      // 遍历左子树
    postorder(root->right);     // 遍历右子树
    cout << root->val << ' ';   // 访问根
}
```

**非递归实现（栈模拟）—— 双栈法**：

后序遍历的非递归实现比前序和中序更 tricky。一种优雅的方法是使用**两个栈**，利用前序遍历的变体：

前序遍历（根-左-右）→ 改为（根-右-左）→ 反转 →（左-右-根）= 后序遍历！

```cpp
void postorder_iterative(TreeNode* root) {
    if (root == nullptr) return;
    stack<TreeNode*> st1, st2;
    st1.push(root);
    while (!st1.empty()) {
        TreeNode* cur = st1.top(); st1.pop();
        st2.push(cur);                      // 存入第二个栈
        if (cur->left)  st1.push(cur->left);   // 先左（反着来）
        if (cur->right) st1.push(cur->right);  // 后右
    }
    // st2 的出栈顺序就是后序遍历
    while (!st2.empty()) {
        cout << st2.top()->val << ' ';
        st2.pop();
    }
}
```

**非递归实现（单栈法 + 标记）**：

```cpp
void postorder_iterative_single_stack(TreeNode* root) {
    if (root == nullptr) return;
    stack<pair<TreeNode*, bool>> st;  // bool表示右子树是否已访问
    TreeNode* cur = root;
    while (cur || !st.empty()) {
        while (cur) {
            st.push({cur, false});
            cur = cur->left;
        }
        auto& top = st.top();
        if (top.second == false) {
            // 右子树还未访问，转向右子树
            top.second = true;
            cur = top.first->right;
        } else {
            // 左右子树都已访问
            cout << top.first->val << ' ';
            st.pop();
        }
    }
}
```

#### 4. 层序遍历（Level-order Traversal）

**访问顺序**：从上到下、从左到右逐层访问。

```
遍历结果：A B C D E F G
```

**实现方式**：使用**队列（BFS）**。

```cpp
void levelorder(TreeNode* root) {
    if (root == nullptr) return;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        TreeNode* cur = q.front(); q.pop();
        cout << cur->val << ' ';
        if (cur->left)  q.push(cur->left);
        if (cur->right) q.push(cur->right);
    }
}
```

**时间/空间复杂度**：O(n)，其中队列最大宽度为二叉树的最大宽度，最坏 O(n)。

### 四、Morris 遍历简介（O(1) 额外空间）

Morris 遍历是一种利用二叉树中大量空闲指针（叶子节点的左右指针为 null）来实现 O(1) 空间复杂度遍历的巧妙方法。

**核心思想**：利用当前节点左子树的最右节点（前驱节点）的空闲右指针，建立临时的"线索"指向当前节点，从而在遍历完左子树后能够回到当前节点。

**中序 Morris 遍历步骤**：
1. 如果 cur 没有左孩子：访问 cur，cur = cur.right
2. 如果 cur 有左孩子：找到 cur 左子树中的最右节点 pre（即 cur 在中序下的前驱）
   - 如果 pre.right == null：令 pre.right = cur（建立线索），cur = cur.left
   - 如果 pre.right == cur（已建立线索）：pre.right = null（恢复），访问 cur，cur = cur.right

```cpp
void morris_inorder(TreeNode* root) {
    TreeNode* cur = root;
    while (cur) {
        if (cur->left == nullptr) {
            cout << cur->val << ' ';
            cur = cur->right;
        } else {
            // 找左子树的最右节点
            TreeNode* pre = cur->left;
            while (pre->right && pre->right != cur) pre = pre->right;
            if (pre->right == nullptr) {
                pre->right = cur;     // 建立线索
                cur = cur->left;
            } else {
                pre->right = nullptr; // 恢复
                cout << cur->val << ' ';
                cur = cur->right;
            }
        }
    }
}
```

**复杂度分析**：虽然每步可能走 O(height) 找前驱，但每条边最多被经过两次，总复杂度仍为 O(n)。空间复杂度 O(1)。

### 五、前序 + 中序重建二叉树

**问题**：给定一棵二叉树的前序遍历序列和中序遍历序列，构造出这棵二叉树。

**定理**：如果二叉树中所有节点的值都不相同，那么前序 + 中序（或后序 + 中序）可以唯一确定一棵二叉树。

**推导与证明**：

设前序序列为 `pre[0..n-1]`，中序序列为 `in[0..n-1]`。

1. **前序的第一个元素 `pre[0]` 一定是整棵树的根节点**（前序定义：根-左-右）

2. 在中序序列中找到根节点 `pre[0]` 的位置 `pos`。由中序定义（左-根-右）：
   - `in[0..pos-1]` 是左子树的中序序列（共 pos 个节点）
   - `in[pos+1..n-1]` 是右子树的中序序列（共 n-pos-1 个节点）

3. 对应到前序序列：
   - `pre[1..pos]` 是左子树的前序序列（恰好 pos 个节点）
   - `pre[pos+1..n-1]` 是右子树的前序序列（恰好 n-pos-1 个节点）

4. 递归地在左右区间上重复上述过程，即可构建整棵树。

**证明唯一性**：每一步根节点的选择由前序唯一确定，左右子树的划分由中序唯一确定（值各不相同保证 pos 唯一），递归下去整个树结构唯一确定。

**实现**：
```cpp
// 使用哈希表快速定位中序中根节点的位置
unordered_map<int, int> inMap;  // 值 -> 中序下标

TreeNode* buildTree(vector<int>& pre, int preL, int preR,
                    vector<int>& in,  int inL,  int inR) {
    if (preL > preR) return nullptr;
    int rootVal = pre[preL];
    int pos = inMap[rootVal];                // 根在中序中的位置
    int leftSize = pos - inL;                // 左子树大小
    TreeNode* root = new TreeNode(rootVal);
    root->left  = buildTree(pre, preL + 1, preL + leftSize,
                            in,  inL, pos - 1);
    root->right = buildTree(pre, preL + leftSize + 1, preR,
                            in,  pos + 1, inR);
    return root;
}
```

### 六、后序 + 中序重建二叉树

**推导**：

设后序序列为 `post[0..n-1]`，中序序列为 `in[0..n-1]`。

1. **后序的最后一个元素 `post[n-1]` 一定是根节点**（后序定义：左-右-根）

2. 在中序序列中找到根节点的位置 `pos`：
   - `in[0..pos-1]` 是左子树（共 pos 个节点）
   - `in[pos+1..n-1]` 是右子树（共 n-pos-1 个节点）

3. 对应到后序序列：
   - `post[0..pos-1]` 是左子树的后序序列
   - `post[pos..n-2]` 是右子树的后序序列

4. 递归构建。

**实现**：
```cpp
TreeNode* buildTreePost(vector<int>& post, int postL, int postR,
                        vector<int>& in,   int inL,   int inR) {
    if (postL > postR) return nullptr;
    int rootVal = post[postR];
    int pos = inMap[rootVal];
    int leftSize = pos - inL;
    TreeNode* root = new TreeNode(rootVal);
    root->left  = buildTreePost(post, postL, postL + leftSize - 1,
                                in,   inL, pos - 1);
    root->right = buildTreePost(post, postL + leftSize, postR - 1,
                                in,   pos + 1, inR);
    return root;
}
```

**注意**：仅凭前序 + 后序无法唯一确定一棵二叉树（存在歧义）。例如两个序列为 `pre=[A,B]`，`post=[B,A]`，无法确定 B 是 A 的左孩子还是右孩子。

## 💻 代码模板

```cpp
// ========== 二叉树节点定义 ==========
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

// ========== 递归遍历 ==========
void preorder(TreeNode* root) {
    if (!root) return;
    cout << root->val << ' ';
    preorder(root->left);
    preorder(root->right);
}
void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val << ' ';
    inorder(root->right);
}
void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    cout << root->val << ' ';
}

// ========== 层序遍历（BFS）==========
void levelorder(TreeNode* root) {
    if (!root) return;
    queue<TreeNode*> q; q.push(root);
    while (!q.empty()) {
        TreeNode* cur = q.front(); q.pop();
        cout << cur->val << ' ';
        if (cur->left) q.push(cur->left);
        if (cur->right) q.push(cur->right);
    }
}

// ========== 前序 + 中序重建 ==========
unordered_map<int, int> inMap;
TreeNode* build(vector<int>& pre, int pL, int pR,
                vector<int>& in, int iL, int iR) {
    if (pL > pR) return nullptr;
    int rv = pre[pL], pos = inMap[rv], sz = pos - iL;
    TreeNode* root = new TreeNode(rv);
    root->left  = build(pre, pL+1, pL+sz, in, iL, pos-1);
    root->right = build(pre, pL+sz+1, pR, in, pos+1, iR);
    return root;
}
TreeNode* buildTree(vector<int>& pre, vector<int>& in) {
    int n = in.size();
    for (int i = 0; i < n; i++) inMap[in[i]] = i;
    return build(pre, 0, n-1, in, 0, n-1);
}

// ========== 后序 + 中序重建 ==========
TreeNode* buildPost(vector<int>& post, int pL, int pR,
                    vector<int>& in, int iL, int iR) {
    if (pL > pR) return nullptr;
    int rv = post[pR], pos = inMap[rv], sz = pos - iL;
    TreeNode* root = new TreeNode(rv);
    root->left  = buildPost(post, pL, pL+sz-1, in, iL, pos-1);
    root->right = buildPost(post, pL+sz, pR-1, in, pos+1, iR);
    return root;
}
```

## ⚠️ 易错点与优化技巧

1. **空节点的处理**：递归遍历时必须先判断 `root == nullptr`，否则访问 `root->val` 会崩溃
2. **非递归后序遍历的顺序**：双栈法的本质是 `(根-右-左)` 的反转，即用前序遍历的思路，调整左右顺序后反转
3. **栈模拟的 while 条件**：中序遍历的条件是 `while (cur || !st.empty())`，不能只写 `while (!st.empty())`，因为在到达最左叶子后还需要转向右子树
4. **Morris 遍历的恢复**：遍历结束后务必恢复树的原始结构（断开临时指针），否则会破坏树的结构
5. **重建二叉树的唯一性条件**：必须二叉树中所有节点值各不相同；前序 + 后序不能唯一确定
6. **数组存储的下标从 1 开始**：完全二叉树使用数组存储时下标从 1 开始，0 号位置空置，这样 2×i 和 2×i+1 的关系才简练
7. **层序遍历记录层次**：若需要知道每层有哪些节点，可以在 BFS 中记录每层的 size：
   ```cpp
   while (!q.empty()) {
       int size = q.size();
       for (int i = 0; i < size; i++) {
           // 处理当前层的每个节点
       }
   }
   ```
8. **递归转非递归的通法**：使用显式栈模拟系统调用栈，同时保存"当前执行到哪一步"的状态（类似协程）

### 真题一：[CSP-S 模拟] 二叉树重建与遍历

**题目描述**：
给定一棵二叉树的**前序遍历**序列和**中序遍历**序列，节点值均为 1 到 n 的正整数且互不相同。请你：
1. 重建这棵二叉树
2. 输出该二叉树的后序遍历序列

**输入格式**：
- 第一行：一个整数 n (1 ≤ n ≤ 10^5)，表示节点数量
- 第二行：n 个整数，表示前序遍历序列
- 第三行：n 个整数，表示中序遍历序列

**输出格式**：
- 一行 n 个整数，表示后序遍历序列

**数据范围**：
- 1 ≤ n ≤ 10^5
- 1 ≤ 节点值 ≤ n
- 保证序列合法

**解题思路**：
使用哈希表存储中序中每个值的下标，递归构建树。由于 n ≤ 10^5，需要用非递归方式输出后序遍历（或增大栈空间），这里我们用栈来模拟后序遍历，避免递归过深导致栈溢出。

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n;
int pre[MAXN], in[MAXN], pos_map[MAXN];

// 递归构建 + 直接后序输出（免去建树后再遍历）
void build_and_post(int pL, int pR, int iL, int iR) {
    if (pL > pR) return;
    int rootVal = pre[pL];
    int rootPos = pos_map[rootVal];
    int leftSize = rootPos - iL;
    // 后序：左 → 右 → 根
    build_and_post(pL + 1, pL + leftSize, iL, rootPos - 1);
    build_and_post(pL + leftSize + 1, pR, rootPos + 1, iR);
    cout << rootVal << ' ';
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> pre[i];
    for (int i = 1; i <= n; i++) {
        cin >> in[i];
        pos_map[in[i]] = i;    // 值→中序下标
    }
    build_and_post(1, n, 1, n);
    cout << '\n';
    return 0;
}
```

**复杂度分析**：时间 O(n)，空间 O(n)（哈希表 + 递归栈）。递归深度最坏为 n（退化为链），建议在本地运行时增加栈空间（`ulimit -s unlimited`）或改用非递归方式。

### 真题二：[CSP-S 套题] 树的子结构判定

**题目描述**：
给定两棵二叉树 A 和 B（节点值可能重复），判断 B 是否是 A 的子树。子树定义为：B 与 A 的某个子树结构完全相同（节点位置和值都相同）。

**输入格式**：
- 第一行：两个整数 n 和 m（1 ≤ m ≤ n ≤ 10^4），分别表示树 A 和树 B 的节点数
- 接下来描述 A 的前序和中序遍历序列
- 接下来描述 B 的前序和中序遍历序列

**输出格式**：
- 如果 B 是 A 的子树，输出 "YES"，否则输出 "NO"

**解题思路**：
核心观察：将两棵树分别**序列化**（比如用前序遍历的特殊编码：用特殊字符表示空节点），然后问题转化为判断 B 的序列化结果是否是 A 序列化结果的**子串**。子串匹配可使用 KMP 算法做到 O(n+m)。

**序列化规则**：前序遍历，用 -1 表示 nullptr（因为节点值为正整数）。

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<int> preA, inA, preB, inB;
unordered_map<int, int> inMapA, inMapB;

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

// 前序+中序建树
TreeNode* build(vector<int>& pre, unordered_map<int,int>& mp,
                int pL, int pR, int iL, int iR) {
    if (pL > pR) return nullptr;
    int rv = pre[pL], pos = mp[rv], sz = pos - iL;
    TreeNode* root = new TreeNode(rv);
    root->left  = build(pre, mp, pL+1, pL+sz, iL, pos-1);
    root->right = build(pre, mp, pL+sz+1, pR, pos+1, iR);
    return root;
}

// 序列化：前序遍历，空节点用 -1 表示
void serialize(TreeNode* root, vector<int>& seq) {
    if (!root) { seq.push_back(-1); return; }
    seq.push_back(root->val);
    serialize(root->left, seq);
    serialize(root->right, seq);
}

// KMP 求 next 数组
vector<int> getNext(vector<int>& pattern) {
    int m = pattern.size();
    vector<int> nxt(m);
    for (int i = 1, j = 0; i < m; i++) {
        while (j && pattern[i] != pattern[j]) j = nxt[j - 1];
        if (pattern[i] == pattern[j]) j++;
        nxt[i] = j;
    }
    return nxt;
}

// KMP 匹配：判断 pattern 是否是 text 的子串
bool kmpMatch(vector<int>& text, vector<int>& pattern) {
    if (pattern.size() > text.size()) return false;
    vector<int> nxt = getNext(pattern);
    for (int i = 0, j = 0; i < (int)text.size(); i++) {
        while (j && text[i] != pattern[j]) j = nxt[j - 1];
        if (text[i] == pattern[j]) j++;
        if (j == (int)pattern.size()) return true;
    }
    return false;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    cin >> n >> m;
    preA.resize(n); inA.resize(n);
    preB.resize(m); inB.resize(m);
    for (int i = 0; i < n; i++) cin >> preA[i];
    for (int i = 0; i < n; i++) { cin >> inA[i]; inMapA[inA[i]] = i; }
    for (int i = 0; i < m; i++) cin >> preB[i];
    for (int i = 0; i < m; i++) { cin >> inB[i]; inMapB[inB[i]] = i; }

    TreeNode* rootA = build(preA, inMapA, 0, n-1, 0, n-1);
    TreeNode* rootB = build(preB, inMapB, 0, m-1, 0, m-1);

    vector<int> seqA, seqB;
    serialize(rootA, seqA);
    serialize(rootB, seqB);

    cout << (kmpMatch(seqA, seqB) ? "YES" : "NO") << '\n';
    return 0;
}
```

**复杂度分析**：
- 建树：O(n + m)
- 序列化：O(n + m)
- KMP 子串匹配：O(n + m)
- 总复杂度：O(n + m)，空间 O(n + m)

## 🎯 本课小结

1. **二叉树基本性质**：满二叉树节点数为 2^k-1；完全二叉树可用数组存储，父子下标关系为 i↔2i,2i+1
2. **四种遍历**：前序（根左右）、中序（左根右）、后序（左右根）、层序（BFS 队列），递归实现简洁，非递归需掌握栈/队列模拟
3. **非递归遍历核心**：前序用栈 + 先压右再压左；中序用栈 + 一路向左；后序用双栈法（前序变体反转）或标记法
4. **Morris 遍历**：利用空闲指针实现 O(1) 空间遍历，面试/竞赛进阶技巧
5. **二叉树重建**：前序 + 中序唯一确定二叉树（前序第一个是根，中序划分左右）；后序 + 中序同理（后序最后一个是根）；仅前序 + 后序无法唯一确定
6. **链式 vs 数组存储**：链式适用于任意形态二叉树；数组仅适用于完全二叉树（堆、线段树的底层）
