## 二、知识精讲

### 1. 区间DP的定义与特征

区间DP（Interval DP）是一类特殊的动态规划问题。它的核心思想是：**将原问题分解为若干个小区间上的子问题，求解小区间的最优解后，再通过某种合并方式得到大区间的最优解**。

**特征识别**：
- 问题涉及一个**序列**或**区间**
- 每次操作是在一个**连续区间**上进行
- 相邻的子问题**合并**后形成更大的子问题
- 最终答案是整个区间 `[1, n]` 或 `[0, n-1]` 的解

**与线性DP的区别**：
- 线性DP通常按位置 `i` 递推，维度是 `dp[i]`
- 区间DP按**区间长度**递推，维度是 `dp[l][r]`

### 2. 区间DP的五步转移法

区间DP有一个通用的代码框架，称为「**五步转移法**」：

| 步骤 | 内容 | 代码 |
|------|------|------|
| 第一步 | 确定区间长度 `len`（从2到n递增） | `for (int len = 2; len <= n; ++len)` |
| 第二步 | 枚举区间左端点 `l` | `for (int l = 0; l + len - 1 < n; ++l)` |
| 第三步 | 计算右端点 `r = l + len - 1` | `int r = l + len - 1;` |
| 第四步 | 枚举分割点 `k ∈ [l, r-1]` | `for (int k = l; k < r; ++k)` |
| 第五步 | 合并 `dp[l][r] = merge(dp[l][k], dp[k+1][r])` | `dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + ...)` |

**为什么按长度枚举？**
因为计算 `dp[l][r]` 需要用到比它更短的区间 `dp[l][k]` 和 `dp[k+1][r]`，所以必须先计算出所有长度小于当前区间的子问题 —— 这就是「按区间长度从小到大」枚举的原因。

### 3. 石子合并问题（直线版）

#### 问题描述
有 $n$ 堆石子排成一行，每堆石子有重量 $a_i$。每次可以合并**相邻**的两堆石子，合并的代价为这两堆石子的重量之和。经过 $n-1$ 次合并后，所有石子合成一堆。求最小总代价。

#### 状态定义
设 $dp[l][r]$ 表示将区间 $[l, r]$ 内的石子合并成一堆的**最小代价**。

#### 状态转移
将区间 $[l, r]$ 以分割点 $k$ 分成两段：$[l, k]$ 和 $[k+1, r]$。先将这两段分别合并成两堆，再将这两堆合并：
$$dp[l][r] = \min_{k=l}^{r-1}\{dp[l][k] + dp[k+1][r] + sum(l, r)\}$$

其中 $sum(l, r) = \sum_{i=l}^{r} a_i$，即区间内所有石子的总重量。

#### 前缀和优化
使用前缀和数组 `pre[i]` 表示前 $i$ 堆石子的总重量，则：
$$sum(l, r) = pre[r+1] - pre[l]$$

可以在 $O(1)$ 时间内查询任意区间的和。

#### 复杂度分析
- **时间复杂度**：$O(n^3)$ —— 三层循环（长度 × 左端点 × 分割点）
- **空间复杂度**：$O(n^2)$ —— `dp` 数组

### 4. 四边形不等式优化简介

对于石子合并这类**满足四边形不等式**的区间DP，可以将时间复杂度从 $O(n^3)$ 优化到 $O(n^2)$。

**四边形不等式**：若对于任意 $a \leq b \leq c \leq d$，有 $w(a, c) + w(b, d) \leq w(a, d) + w(b, c)$，则称代价函数 $w$ 满足四边形不等式。

**优化方法**：引入决策单调性，记录最优分割点 `s[l][r]`，缩小 $k$ 的枚举范围：
$$s[l][r-1] \leq k \leq s[l+1][r]$$

这样可以大幅减少内层循环的枚举量，使总时间复杂度降为 $O(n^2)$。

### 5. 最优三角剖分问题

#### 问题描述
给定一个 $n$ 边形的顶点，每个三角形有一个权值（例如顶点权值之和），求一种三角剖分方式，使得所有三角形的权值之和最小。

#### 与矩阵链乘法的关系
最优三角剖分和矩阵链乘法本质上是**同一个问题**的不同表述：
- 矩阵链乘法：选择括号化方式
- 最优三角剖分：选择弦的划分方式

两者的DP结构完全相同：
$$dp[l][r] = \min_{k=l+1}^{r-1}\{dp[l][k] + dp[k][r] + w(l, k, r)\}$$

### 6. 回文串相关问题

区间DP也可以用于处理字符串的回文相关问题。

**最少插入次数使之成为回文串**：
- $dp[l][r]$ 表示使子串 $s[l..r]$ 成为回文串所需的最少插入次数
- 若 $s[l] = s[r]$，则 $dp[l][r] = dp[l+1][r-1]$
- 否则 $dp[l][r] = \min(dp[l+1][r], dp[l][r-1]) + 1$

## 三、代码模板

### 石子合并标准模板

```cpp
// 石子合并（直线版）- 最小代价
int mergeStones(vector<int>& a) {
    int n = a.size();
    vector<int> pre(n + 1, 0);
    for (int i = 1; i <= n; ++i) pre[i] = pre[i-1] + a[i-1];
    auto sum = [&](int l, int r) { return pre[r+1] - pre[l]; };
    
    vector<vector<int>> dp(n, vector<int>(n, INF));
    for (int i = 0; i < n; ++i) dp[i][i] = 0;
    
    for (int len = 2; len <= n; ++len) {          // 第一步：枚举长度
        for (int l = 0; l + len - 1 < n; ++l) {   // 第二步：枚举左端点
            int r = l + len - 1;                    // 第三步：计算右端点
            for (int k = l; k < r; ++k) {           // 第四步：枚举分割点
                dp[l][r] = min(dp[l][r],            // 第五步：状态转移
                    dp[l][k] + dp[k+1][r] + sum(l, r));
            }
        }
    }
    return dp[0][n-1];
}
```

### 最优三角剖分模板

```cpp
int triangulation(vector<vector<int>>& w, int n) {
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, INF));
    for (int i = 1; i <= n; ++i) {
        dp[i][i] = 0;
        if (i < n) dp[i][i+1] = 0;
    }
    
    for (int len = 3; len <= n; ++len) {
        for (int l = 1; l + len - 1 <= n; ++l) {
            int r = l + len - 1;
            for (int k = l + 1; k < r; ++k) {
                dp[l][r] = min(dp[l][r],
                    dp[l][k] + dp[k][r] + w[l][k] + w[k][r]);
            }
        }
    }
    return dp[1][n];
}
```

## 四、易错点与优化技巧

### 易错点

1. **`len` 的起始值**：`len` 应从 2 开始（单个元素不需要合并），而不是 1
2. **`k` 的枚举范围**：$k \in [l, r-1]$（分割点必须在区间内部，左闭右开）
3. **前缀和的下标对应**：`sum(l, r) = pre[r+1] - pre[l]`，注意 `r+1` 的偏移
4. **`dp` 初始值**：求最小值时应初始化为足够大的数（如 `INF = 0x3f3f3f3f`），求最大值时应初始化为 0
5. **`dp[i][i] = 0`**：单个元素的代价为 0，这是DP的边界条件

### 优化技巧

1. **前缀和优化**：所有区间求和操作都用前缀和 $O(1)$ 完成
2. **四边形不等式优化**：记录最优决策点，缩小 $k$ 的枚举范围
3. **`vector` 优于数组**：使用 `vector<vector<int>>` 比固定大小的二维数组更安全
4. **`0x3f3f3f3f`**：这是一个常用的「足够大但不会溢出」的常数
5. **破环成链**：对于环形问题（将在第32课详细讲解），将数组复制一份接在尾部

## 五、真题精练

### 真题1：石子合并（直线版）【洛谷 P1775】

**题目描述**：
有 $n$ 堆石子排成一排，第 $i$ 堆石子有 $a_i$ 个。每次可以合并相邻的两堆，合并的代价为这两堆石子的数量之和。求将所有石子合并成一堆的最小代价。

**输入格式**：
第一行一个整数 $n$（$1 \leq n \leq 300$）。
第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示每堆石子的数量。

**输出格式**：
一个整数，表示最小代价。

**样例输入**：
```
4
4 5 9 4
```
**样例输出**：
```
43
```

**AC代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;
const int INF = 0x3f3f3f3f;

int main() {
    int n; cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    
    vector<int> pre(n + 1, 0);
    for (int i = 1; i <= n; ++i) pre[i] = pre[i-1] + a[i-1];
    auto sum = [&](int l, int r) { return pre[r+1] - pre[l]; };
    
    vector<vector<int>> dp(n, vector<int>(n, INF));
    for (int i = 0; i < n; ++i) dp[i][i] = 0;
    
    for (int len = 2; len <= n; ++len) {
        for (int l = 0; l + len - 1 < n; ++l) {
            int r = l + len - 1;
            for (int k = l; k < r; ++k) {
                dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + sum(l, r));
            }
        }
    }
    cout << dp[0][n-1] << endl;
    return 0;
}
```

**复杂度分析**：$O(n^3)$ 时间，$O(n^2)$ 空间，对于 $n \leq 300$ 可以轻松通过。

### 真题2：矩阵链乘法

**题目描述**：
给定 $n$ 个矩阵的维度 $p_0, p_1, \dots, p_n$（第 $i$ 个矩阵的大小为 $p_{i-1} \times p_i$），求最少乘法次数。

**输入格式**：
第一行一个整数 $n$。
第二行 $n+1$ 个整数 $p_0, p_1, \dots, p_n$。

**样例输入**：
```
3
10 100 5 50
```
**样例输出**：
```
7500
```

**AC代码**：
```cpp
#include <bits/stdc++.h>
using namespace std;
const int INF = 0x3f3f3f3f;

int main() {
    int n; cin >> n;
    vector<int> p(n + 1);
    for (int i = 0; i <= n; ++i) cin >> p[i];
    
    vector<vector<int>> dp(n + 1, vector<int>(n + 1, INF));
    for (int i = 1; i <= n; ++i) dp[i][i] = 0;
    
    for (int len = 2; len <= n; ++len) {
        for (int l = 1; l + len - 1 <= n; ++l) {
            int r = l + len - 1;
            for (int k = l; k < r; ++k) {
                dp[l][r] = min(dp[l][r], 
                    dp[l][k] + dp[k+1][r] + p[l-1] * p[k] * p[r]);
            }
        }
    }
    cout << dp[1][n] << endl;
    return 0;
}
```

**复杂度分析**：$O(n^3)$ 时间，$O(n^2)$ 空间。

## 六、本课小结

1. 区间DP适用于**将问题分解为小区间、再合并为大区间**的场景
2. **五步转移法**是区间DP的通用框架：枚举长度 → 枚举左端点 → 计算右端点 → 枚举分割点 → 状态转移
3. 石子合并是区间DP最经典的入门问题，要熟练掌握其 $O(n^3)$ 写法
4. 前缀和可以将区间求和优化到 $O(1)$
5. 四边形不等式可以将部分区间DP优化到 $O(n^2)$
6. 矩阵链乘法和最优三角剖分本质上是同一类问题
7. 区间DP也可以处理回文串等字符串问题
