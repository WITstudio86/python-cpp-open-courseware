## 📖 知识精讲

### 一、树链剖分的基本概念

树链剖分是一种将**树上路径操作转化为区间操作**的技术。其核心思想是将树上的节点重新编号（DFS 序），使得**每条重链上的节点编号连续**，从而可以配合线段树/树状数组维护树上路径的信息。

**关键定义**：

| 术语 | 含义 |
|------|------|
| **重儿子** | 子树节点数最多的儿子 |
| **轻儿子** | 除重儿子外的其他儿子 |
| **重边** | 父节点到重儿子的边 |
| **轻边** | 父节点到轻儿子的边 |
| **重链** | 由连续的重边组成的路径 |
| **top[u]** | 节点 u 所在重链的顶端节点 |
| **dfn[u]** | 节点 u 的 DFS 序（新编号） |
| **rnk[x]** | DFS 序为 x 对应的原始节点 |

**性质**：

1. 从根节点到任意叶子节点的路径上，最多经过 **O(log n)** 条轻边
2. 每条重链上的节点编号（dfn）是**连续**的
3. 每条重链的顶端节点是轻儿子（或其父节点为轻边）

### 二、两次 DFS 实现剖分

**第一次 DFS**：计算每个节点的父节点、深度、子树大小、重儿子

```cpp
void dfs1(int u, int fa) {
    parent[u] = fa;
    depth[u] = depth[fa] + 1;
    size[u] = 1;
    int max_size = 0;
    for (int v : adj[u]) {
        if (v == fa) continue;
        dfs1(v, u);
        size[u] += size[v];
        if (size[v] > max_size) {
            max_size = size[v];
            heavy[u] = v;  // 重儿子
        }
    }
}
```

**第二次 DFS**：分配 DFS 序，确定每条重链的顶端

```cpp
void dfs2(int u, int top_node) {
    dfn[u] = ++timer;
    rnk[timer] = u;       // 记录 DFS 序到节点的映射
    top[u] = top_node;

    if (heavy[u] == 0) return;  // 叶子节点

    dfs2(heavy[u], top_node);    // 优先遍历重儿子，保持重链连续

    for (int v : adj[u]) {
        if (v == parent[u] || v == heavy[u]) continue;
        dfs2(v, v);              // 轻儿子作为新重链的顶端
    }
}
```

**关键点**：第二次 DFS 时，**优先遍历重儿子**，确保重链上的节点在 DFS 序中连续。

### 三、树上路径操作

**核心算法**：将树上路径 (u, v) 的查询/修改拆分为若干条重链的区间操作。

```cpp
// 查询路径 (u, v) 的和
long long query_path(int u, int v) {
    long long res = 0;
    while (top[u] != top[v]) {
        // 让深度更大的链的顶端向上跳
        if (depth[top[u]] < depth[top[v]]) swap(u, v);
        // 查询 [dfn[top[u]], dfn[u]] 这段重链
        res += seg.query(dfn[top[u]], dfn[u]);
        u = parent[top[u]];  // 跳到链顶的父节点
    }
    // 现在 u 和 v 在同一条重链上
    if (depth[u] > depth[v]) swap(u, v);
    res += seg.query(dfn[u], dfn[v]);
    return res;
}
```

**路径修改**（加 v）同理，将 query 换成 update。

### 四、子树的处理

由于 DFS 序的性质，**以 u 为根的子树**所有节点的 dfn 是连续的：
- 子树 dfn 区间：**[dfn[u], dfn[u] + size[u] - 1]**

因此子树操作直接转化为一个区间操作，时间复杂度 **O(log n)**。

### 五、时间复杂度分析

- 树上路径被分解为 **O(log n)** 条重链（每次跳轻边，轻边不超过 O(log n)）
- 每条重链上的区间操作是 **O(log n)**（线段树）
- **总复杂度：O(log² n)** 每次路径操作
- 子树操作：**O(log n)**（仅一个区间）

## 💻 代码模板

```cpp
// ========== 树链剖分模板 ==========
const int MAXN = 100005;
int n;
vector<int> adj[MAXN];

// 第一次 DFS 所需
int parent[MAXN], depth[MAXN], size[MAXN], heavy[MAXN];

// 第二次 DFS 所需
int dfn[MAXN], rnk[MAXN], top[MAXN], timer;

void dfs1(int u, int fa) {
    parent[u] = fa;
    depth[u] = depth[fa] + 1;
    size[u] = 1;
    heavy[u] = 0;
    int max_size = 0;
    for (int v : adj[u]) {
        if (v == fa) continue;
        dfs1(v, u);
        size[u] += size[v];
        if (size[v] > max_size) {
            max_size = size[v];
            heavy[u] = v;
        }
    }
}

void dfs2(int u, int top_node) {
    dfn[u] = ++timer;
    rnk[timer] = u;
    top[u] = top_node;

    if (heavy[u] == 0) return;

    // 优先遍历重儿子
    dfs2(heavy[u], top_node);

    for (int v : adj[u]) {
        if (v == parent[u] || v == heavy[u]) continue;
        dfs2(v, v);
    }
}

// 路径查询（配合线段树）
long long query_path(int u, int v) {
    long long res = 0;
    while (top[u] != top[v]) {
        if (depth[top[u]] < depth[top[v]]) swap(u, v);
        res += seg.query(dfn[top[u]], dfn[u]);
        u = parent[top[u]];
    }
    if (depth[u] > depth[v]) swap(u, v);
    res += seg.query(dfn[u], dfn[v]);
    return res;
}

// 路径修改
void update_path(int u, int v, long long val) {
    while (top[u] != top[v]) {
        if (depth[top[u]] < depth[top[v]]) swap(u, v);
        seg.update(dfn[top[u]], dfn[u], val);
        u = parent[top[u]];
    }
    if (depth[u] > depth[v]) swap(u, v);
    seg.update(dfn[u], dfn[v], val);
}
```

## ⚠️ 易错点与优化技巧

1. **dfs2 中先遍历重儿子** —— 这是保证重链连续的关键，忘记会导致完全错误
2. **跳链时的深度比较** —— 比较的是 `depth[top[u]]` 而非 `depth[u]`
3. **跳链后跳到 parent[top[u]]** —— 不是 parent[u]
4. **同链后区分 u 和 v 的深度** —— 确保 dfn 区间左端点 ≤ 右端点
5. **dfn 从 1 开始** —— 方便配合线段树
6. **线段树的索引** —— 使用 dfn 而非原始编号来访问线段树
7. **子树区间** —— [dfn[u], dfn[u] + size[u] - 1]
8. **多次询问注意清空** —— timer、数组重置

## 📝 真题精练

### 真题一：[CSP-S 模拟] 树上路径和

**题目描述**：
给定一棵 n 个节点的树，每个节点有权值 w[i]，支持两种操作：
1. `1 u v x`：将 u 到 v 路径上所有节点的权值增加 x
2. `2 u v`：查询 u 到 v 路径上所有节点的权值之和

**数据范围**：n, m ≤ 10⁵

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, m;
vector<int> adj[MAXN];
int w[MAXN], parent[MAXN], depth[MAXN], siz[MAXN], heavy[MAXN];
int dfn[MAXN], rnk[MAXN], top[MAXN], timer;

// 线段树部分（略，使用第10课标准模板）
// ...

void dfs1(int u, int fa) {
    parent[u] = fa; depth[u] = depth[fa] + 1;
    siz[u] = 1; heavy[u] = 0;
    int mx = 0;
    for (int v : adj[u]) {
        if (v == fa) continue;
        dfs1(v, u);
        siz[u] += siz[v];
        if (siz[v] > mx) { mx = siz[v]; heavy[u] = v; }
    }
}

void dfs2(int u, int tp) {
    dfn[u] = ++timer; rnk[timer] = u; top[u] = tp;
    if (heavy[u]) dfs2(heavy[u], tp);
    for (int v : adj[u]) {
        if (v == parent[u] || v == heavy[u]) continue;
        dfs2(v, v);
    }
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> w[i];
    for (int i = 1; i < n; i++) {
        int u, v; cin >> u >> v;
        adj[u].push_back(v); adj[v].push_back(u);
    }
    dfs1(1, 0); dfs2(1, 1);
    // 建立线段树：a[dfn[i]] = w[i]
    // 然后使用 update_path / query_path
    return 0;
}
```

**复杂度分析**：O(m log² n)。

### 真题二：[CSP-S 模拟] 子树查询与路径查询

**题目描述**：
在真题一的基础上增加第三种操作：`3 u` 查询以 u 为根的子树的权值和。

**解题思路**：
子树区间为 [dfn[u], dfn[u] + siz[u] - 1]，直接调用线段树区间查询即可。

**AC 代码补充**：

```cpp
long long query_subtree(int u) {
    return seg.query(dfn[u], dfn[u] + siz[u] - 1);
}
```

**复杂度分析**：子树操作 O(log n)，路径操作 O(log² n)。

## 🎯 本课小结

1. **树链剖分本质**：将树上路径操作转化为 O(log n) 个区间操作
2. **两遍 DFS**：第一遍求子树大小和重儿子，第二遍分配 DFS 序
3. **跳链技巧**：每次将深度更大的链顶端向上跳
4. **连续性质**：重链连续（dfn 连续），子树连续
5. **应用广泛**：LCA、树上路径修改/查询、子树修改/查询
6. **配合线段树**：树剖提供区间编号，线段树提供区间操作
