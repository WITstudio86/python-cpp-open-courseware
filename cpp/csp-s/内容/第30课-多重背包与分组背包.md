## 二、知识精讲

### 2.1 多重背包问题定义

**问题描述**：有 n 种物品和一个容量为 V 的背包。第 i 种物品最多有 `c[i]` 件可用，每件重量为 `w[i]`，价值为 `v[i]`。求解将哪些物品装入背包可使物品重量总和不超过背包容量，且价值总和最大。

**朴素做法**（O(V · Σc[i])）：

将每种物品拆成 c[i] 个单独的物品，转化为 01 背包问题：

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = V; j >= w[i]; j--) {
        for (int k = 0; k <= c[i] && k * w[i] <= j; k++) {
            dp[j] = max(dp[j], dp[j - k * w[i]] + k * v[i]);
        }
    }
}
```

**问题**：当 Σc[i] 较大（如每种物品 c[i] 可达 10^5）时，时间复杂度 O(V · Σc[i]) 会严重超时，需要优化。

---

### 2.2 二进制拆分优化 O(V · Σ log c[i])

#### 核心思想

将 c[i] 件物品拆成若干件「打包物品」，使得这些打包物品能组合出 0 到 c[i] 之间的任意件数。

**拆分方法**：将 c[i] 拆分为：

$$
c[i] = 2^0 + 2^1 + 2^2 + \dots + 2^k + r
$$

其中 $k$ 是满足 $2^0 + 2^1 + \dots + 2^k = 2^{k+1} - 1 \le c[i]$ 的最大整数，剩余 $r = c[i] - (2^{k+1} - 1)$，且满足 $0 \le r < 2^{k+1}$。

**拆分后生成的新物品**：

- 物品 1：(w[i] × 1,  v[i] × 1)
- 物品 2：(w[i] × 2,  v[i] × 2)
- 物品 3：(w[i] × 4,  v[i] × 4)
- ...
- 物品 k+1：(w[i] × 2^k, v[i] × 2^k)
- 物品 k+2：(w[i] × r,  v[i] × r)  （如果 r > 0）

这样一共拆出约 $\lceil \log_2(c[i] + 1) \rceil$ 个物品，每个物品做一次 01 背包决策（选或不选）。

**为什么能组合出 0~c[i]？**

- 前 k+1 项（1, 2, 4, …, 2^k）可以组合出 0 ~ (2^{k+1} - 1) 的所有整数
- 加上余数 r 后，可以组合出 r ~ (2^{k+1} - 1 + r) = r ~ c[i] 的所有整数
- 由于 r < 2^{k+1}，区间 [0, 2^{k+1} - 1] 与 [r, c[i]] 无缝衔接，整体覆盖 [0, c[i]]

**示例**：c[i] = 13

- k = 3（因为 2^0+2^1+2^2+2^3 = 15 > 13，取 k=3 时 2^4-1=15>13，实际取 k=2: 1+2+4=7 ≤ 13, k=3: 1+2+4+8=15>13，所以 k=2）
- 拆分：1, 2, 4, r = 13 - 7 = 6
- 新物品：(w, v), (2w, 2v), (4w, 4v), (6w, 6v)
- 验证：例如要取 11 件，由 1+4+6=11 组成；取 7 件，由 1+2+4=7 组成 ✓

#### 标准代码模板

```cpp
// 二进制拆分 + 01背包
vector<pair<int, int>> goods; // (重量, 价值)
for (int i = 1; i <= n; i++) {
    int weight = w[i], value = v[i], cnt = c[i];
    for (int k = 1; k <= cnt; k <<= 1) { // k = 1, 2, 4, 8, ...
        goods.push_back({weight * k, value * k});
        cnt -= k;
    }
    if (cnt > 0) { // 剩余余数 r
        goods.push_back({weight * cnt, value * cnt});
    }
}
// 转化为01背包
for (auto &g : goods) {
    for (int j = V; j >= g.first; j--) {
        dp[j] = max(dp[j], dp[j - g.first] + g.second);
    }
}
```

**复杂度**：O(V · Σ log c[i])，显著优于朴素做法。

### 2.3 单调队列优化 O(V · n)

#### 核心思想

多重背包的状态转移方程：

$$
dp[j] = \max_{0 \le k \le c[i],\ k \cdot w[i] \le j} \{ dp[j - k \cdot w[i]] + k \cdot v[i] \}
$$

观察发现：对于固定的物品 i，**容量 j 按照模 w[i] 的余数分组后，每组内的状态转移是独立的**。

#### 同余分组

对于每个物品 i，令 $r = j \bmod w[i]$，则 j 可以表示为 $j = r + t \cdot w[i]$（其中 t 为整数）。

同组的容量为：$r,\ r + w[i],\ r + 2\cdot w[i],\ \dots$，它们之间的转移只依赖同组内前面的状态。

#### 滑动窗口（单调队列）

对每组同余的容量序列，我们在其上滑动一个长度为 c[i]+1 的窗口，维护窗口内 **候选最大值**。

令 $x = \lfloor j / w[i] \rfloor$ 表示当前容量对应的「件数编号」，则：

$$
dp[j] = \max_{0 \le k \le c[i],\ k \le x} \{ dp[j - k \cdot w[i]] + k \cdot v[i] \}
$$

为了统一比较基准，我们将候选值调整为：

$$
candidate[t] = dp[r + t \cdot w[i]] - t \cdot v[i]
$$

则：

$$
dp[r + x \cdot w[i]] = \max_{x - c[i] \le t \le x} \{ candidate[t] \} + x \cdot v[i]
$$

**单调队列维护**：维护一个**值递减**的双端队列，存储候选值的下标 t。

- 入队：将新的 candidate[x] 加入队尾前，弹出队尾所有比它小的（因为它们永远不会成为最大值）
- 出队：队首下标 < x - c[i] 时弹出（超出窗口范围）
- 取值：队首即为窗口内 candidate 最大值，dp[j] = 队首值 + x · v[i]

#### 伪代码流程

```
for i = 1 to n:
    将 dp 拷贝到 g (上一层的状态)
    for r = 0 to w[i] - 1:              // 枚举余数
        deque.clear()
        for x = 0; r + x * w[i] <= V; x++:  // 同余序列
            j = r + x * w[i]
            // 1. 计算当前 candidate
            cur = g[j] - x * v[i]
            // 2. 维护队列单调递减
            while deque not empty and g[deque.back] - deque.back * v[i] <= cur:
                deque.pop_back()
            deque.push_back(x)
            // 3. 弹出超出窗口的
            while deque.front < x - c[i]:
                deque.pop_front()
            // 4. 更新dp
            dp[j] = g[deque.front] + (x - deque.front) * v[i]
```

#### 标准代码模板

```cpp
for (int i = 1; i <= n; i++) {
    memcpy(g, dp, sizeof(dp)); // g 保存上一轮dp状态
    for (int r = 0; r < w[i]; r++) { // 枚举余数
        deque<int> q; // 存下标x
        for (int x = 0; r + x * w[i] <= V; x++) {
            int j = r + x * w[i];
            // candidate 值（偏移调整后）
            int cur = g[j] - x * v[i];
            // 维护单调递减
            while (!q.empty() && (g[r + q.back() * w[i]] - q.back() * v[i]) <= cur) {
                q.pop_back();
            }
            q.push_back(x);
            // 移除过期元素
            while (!q.empty() && q.front() < x - c[i]) {
                q.pop_front();
            }
            // 更新答案
            dp[j] = g[r + q.front() * w[i]] + (x - q.front()) * v[i];
        }
    }
}
```

**复杂度**：O(V · n)，每个容量被每个物品处理常数次。

### 2.4 分组背包

#### 问题定义

有 n 组物品，每组有若干件物品。**每组最多选一件物品**（也可以不选）。第 i 组第 k 件物品重量为 w[i][k]，价值为 v[i][k]。背包容量 V，求最大价值。

#### 三层循环结构

```cpp
for (int i = 1; i <= n; i++) {              // 外层：枚举组
    for (int j = V; j >= 0; j--) {          // 中层：逆序枚举容量
        for (int k = 0; k < group[i].size(); k++) { // 内层：枚举组内物品
            if (j >= w[i][k]) {
                dp[j] = max(dp[j], dp[j - w[i][k]] + v[i][k]);
            }
        }
    }
}
```

#### 为什么中层容量必须逆序？

这个循环顺序有严格的逻辑原因：

1. **如果中层正序（j = 0 → V）**：当选中组内物品 k 更新 dp[j] 后，dp[j] 可能又被同组另一个物品 k' 再次更新（在更大的 j' 处，dp[j' - w[i][k']] 可能已经包含了物品 k）。这会导致**同组物品被多次选择**，违反每组最多选一件的约束。

2. **中层逆序（j = V → 0）**：每个容量 j 只会被当前组内的物品更新一次（每个物品 k 各自尝试），且由于从大到小遍历，dp[j - w[i][k]] 尚未被当前组更新过，保证当前组对 dp[j] 的影响只来自**上一组的状态**。这样就自然保证了每组最多选一件。

**类比理解**：分组背包的内层（枚举组内物品）本质上是 **在同一个容量 j 上对同组物品做 «max» 竞争**，最终只有一个物品能「占领」dp[j]。

#### 另一种等价写法（先物品后容量，错误！）

```cpp
// 错误写法！
for (int i = 1; i <= n; i++) {
    for (int k = 0; k < group[i].size(); k++) {  // 先枚举物品
        for (int j = w[i][k]; j <= V; j++) {      // 再枚举容量
            dp[j] = max(dp[j], dp[j - w[i][k]] + v[i][k]);
        }
    }
}
```

这变成了 **完全背包** 的循环顺序（正序容量），同一物品可以选多次，完全错误。

### 2.5 四种背包问题对比总结

| 背包类型 | 物品限制 | 中层循环方向 | 内层/额外循环 | 时间复杂度 | 空间复杂度（滚动数组） |
|----------|----------|-------------|-------------|-----------|---------------------|
| **01背包** | 每种物品最多选1次 | **逆序** (V→0) | 无 | O(V·n) | O(V) |
| **完全背包** | 每种物品可选无限次 | **正序** (0→V) | 无 | O(V·n) | O(V) |
| **多重背包** | 第i种最多c[i]件 | 逆序（二进制拆分后做01） | 拆分循环 | O(V·Σlog c[i])（二进制）<br>O(V·n)（单调队列） | O(V) |
| **分组背包** | 每组最多选1件 | **逆序** (V→0) | 组内物品循环 | O(V·Σsize[i]) | O(V) |

**记忆口诀**：
- 「01 逆，完全正，分组外层组中层逆，多重拆了再 01」
- 逆序 = 保证每个物品只用一次（依赖上一轮状态）
- 正序 = 允许物品多次使用（依赖本轮已更新状态）

## 三、易错点与优化技巧专题

### 易错点 1：二进制拆分漏掉余数 r

```cpp
// 错误写法：只拆了 2 的幂次，忘了余数
for (int k = 1; k <= c[i]; k <<= 1) {
    goods.push_back({w[i] * k, v[i] * k});
}
// 如果 c[i] = 13，只拆出了 1, 2, 4, 8（和=15>13），
// 实际上 8 不应该被添加（因为 1+2+4+8=15 > 13）
```

**正确做法**：每拆一个就减去对应的数量，最后剩余的作为余数。

```cpp
int cnt = c[i];
for (int k = 1; k <= cnt; k <<= 1) {
    goods.push_back({w[i] * k, v[i] * k});
    cnt -= k;
}
if (cnt > 0) { // 余数
    goods.push_back({w[i] * cnt, v[i] * cnt});
}
```

### 易错点 2：分组背包中层容量必须逆序

如果写成 `for (int j = 0; j <= V; j++)`，会导致同组物品之间互相影响（类似完全背包的正序效果），可能使得同组多个物品被选中。

### 易错点 3：单调队列优化中偏移量的处理

关键公式：

$$
dp[j] = \max_{0\le k\le c[i]} \{ g[j - k\cdot w[i]] + k\cdot v[i] \}
$$

进行变形（设 j = r + x·w[i]）：

$$
dp[r + x\cdot w[i]] = \max_{x-c[i]\le t\le x} \{ g[r + t\cdot w[i]] - t\cdot v[i] \} + x\cdot v[i]
$$

注意最后要**加回 x·v[i]**，这个偏移量极易遗漏。

### 优化技巧 1：滚动数组

所有背包问题都可以使用一维 dp 数组 + 正确的循环方向来节省空间，复杂度从 O(V·n) 降为 O(V)。

### 优化技巧 2：可行性剪枝

当 c[i] × w[i] ≥ V 时，第 i 种物品相当于「完全背包」（因为即使全拿该物品也装不满背包），此时可直接用完全背包的正序循环处理：

```cpp
if (c[i] * w[i] >= V) {
    // 转化为完全背包
    for (int j = w[i]; j <= V; j++) {
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    }
}
```

## 四、真题精练

### 真题 1：宝物筛选（多重背包模板）

**题目来源**：Luogu P1776

**题目描述**：有 N 种宝物和一个容量为 V 的背包。第 i 种宝物重量为 w[i]，价值为 v[i]，最多有 c[i] 件。求最大总价值。

**数据范围**：N ≤ 100，V ≤ 40000，c[i] ≤ 100（总物品数 Σc[i] ≤ 10000）

**输入格式**：
```
第一行：N V
接下来 N 行：每行 v[i] w[i] c[i]（价值 重量 数量）
```

**输出格式**：
```
一个整数：最大价值
```

**样例输入**：
```
4 20
3 9 3
5 9 1
9 4 2
8 1 3
```

**样例输出**：
```
47
```

**AC 代码（二进制拆分解法）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXV = 40005;
int dp[MAXV];

int main() {
    int n, V;
    cin >> n >> V;
    vector<pair<int, int>> goods;
    for (int i = 0; i < n; i++) {
        int v, w, c;
        cin >> v >> w >> c;
        // 二进制拆分
        for (int k = 1; k <= c; k <<= 1) {
            goods.push_back({w * k, v * k});
            c -= k;
        }
        if (c > 0) {
            goods.push_back({w * c, v * c});
        }
    }
    // 01背包
    for (auto &g : goods) {
        for (int j = V; j >= g.first; j--) {
            dp[j] = max(dp[j], dp[j - g.first] + g.second);
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

**复杂度分析**：

- 拆分后物品数目：$\sum_{i=1}^{N} \log_2(c[i]+1) \le 100 \times 7 = 700$
- 01背包复杂度：O(物品数 × V) = O(700 × 40000) ≈ 2.8 × 10^7，可过
- 空间复杂度：O(V) = O(40000)

### 真题 2：选拔队员（分组背包）

**题目描述**：学校要从 N 个班级中选拔队员参加比赛，每个班级有若干名候选人，第 i 个班级的第 k 名候选人有能力值 v[i][k] 和训练费用 w[i][k]。学校预算为 V。每个班级最多只能选拔一名队员（也可以不选）。求在预算范围内，能获得的最大总能力值。

**数据范围**：N ≤ 100，V ≤ 1000，每个班候选人数 ≤ 100

**输入格式**：
```
第一行：N V
接下来 N 组，每组格式：
  第一个整数 m 表示该班候选人数
  接下来 m 行：每行 w v（费用 能力值）
```

**输出格式**：
```
一个整数：最大总能力值
```

**样例输入**：
```
3 10
2
2 8
3 15
3
4 10
5 18
6 20
1
7 12
```

**样例输出**：
```
35
```

**解释**：选班级1的第2人(3,15) + 班级2的第2人(5,18) = 费用8，能力33。或选班级1的第2人(3,15) + 班级3的第1人(7,12) = 费用10，能力27。最优为15+20=35（选班级1的第2人和班级2的第3人，费用3+6=9，能力15+20=35）。

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXV = 1005;
int dp[MAXV];

int main() {
    int n, V;
    cin >> n >> V;
    for (int i = 1; i <= n; i++) {
        int m;
        cin >> m;
        vector<int> w(m), v(m);
        for (int j = 0; j < m; j++) {
            cin >> w[j] >> v[j];
        }
        // 分组背包：中层容量逆序
        for (int j = V; j >= 0; j--) {
            for (int k = 0; k < m; k++) {
                if (j >= w[k]) {
                    dp[j] = max(dp[j], dp[j - w[k]] + v[k]);
                }
            }
        }
    }
    cout << dp[V] << endl;
    return 0;
}
```

**复杂度分析**：

- 三层循环：组数 N × 容量 V × 每组物品数 m
- O(N · V · m) = O(100 × 1000 × 100) = 1 × 10^7，可过
- 空间复杂度：O(V)

## 五、本课小结

1. **多重背包** 是 01 背包的推广，每种物品有数量限制 c[i]

2. **二进制拆分优化** 将 c[i] 拆为 1, 2, 4, …, 2^k, r，转化为 O(log c[i]) 个 01 背包物品，复杂度 O(V · Σ log c[i])，实现简单，足以应对大多数题目

3. **单调队列优化** 通过同余分组 + 滑动窗口，将复杂度进一步降为 O(V · n)，是多重背包的最优解法，但实现较为复杂，需注意偏移量的加减

4. **分组背包** 每组最多选一件，关键特征是 **三层循环中容量必须逆序**，这是与完全背包（正序）的本质区别

5. **循环方向规律**：
   - 逆序（V→0）：保证每个物品只使用一次 → 01背包、分组背包
   - 正序（0→V）：允许物品多次使用 → 完全背包

6. **优化技巧**：二进制拆分注意余数，分组背包注意容量逆序，单调队列注意 `-t·v` 和 `+x·v` 的偏移量，可行剪枝（c·w ≥ V 时转完全背包）
