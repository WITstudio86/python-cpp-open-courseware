# 第09课：树状数组（Fenwick Tree）

## 📖 知识精讲

### 一、树状数组的核心思想

树状数组是一种基于二进制拆分的数据结构。其核心思想是：**利用任意正整数都可以唯一分解为若干个 2 的幂次之和**这一性质，将前缀信息按二进制位进行分层管理。

对于任意正整数 x，定义 `lowbit(x) = x & (-x)`，表示 x 在二进制下最低位的 1 所代表的值。例如：
- lowbit(1) = 1（二进制 1）
- lowbit(6) = 2（二进制 110，最低位 1 在 2^1 位置）
- lowbit(8) = 8（二进制 1000）

### 二、树状数组的存储结构

设原数组为 a[1..n]，树状数组 c[1..n] 的定义如下：

**c[i] 维护的是区间 [i - lowbit(i) + 1, i] 上 a 数组的信息（通常为和）**。

这意味着：
- c[1] 维护 a[1]（区间 [1,1]）
- c[2] 维护 a[1] + a[2]（区间 [1,2]）
- c[3] 维护 a[3]（区间 [3,3]）
- c[4] 维护 a[1] + a[2] + a[3] + a[4]（区间 [1,4]）
- c[6] 维护 a[5] + a[6]（区间 [5,6]）

构建出的树形结构（以 n=8 为例）：

```
                c[8]
              /      \
          c[4]        \
        /    \         \
     c[2]    c[6]      \
    /  \    /  \        \
 c[1] a[1] c[5] c[3]   c[7]
```

### 三、核心操作

#### 1. 单点修改（add）

修改 a[x] 的值，需要更新所有覆盖 a[x] 的 c 节点。算法如下：

```cpp
// 在位置 x 上增加值 v
void add(int x, int v) {
    while (x <= n) {
        c[x] += v;
        x += lowbit(x);  // 跳到父节点（或覆盖 x 的下一个区间）
    }
}
```

**复杂度**：每次 x 的二进制中至少有一位变为 0，最多跳 log₂(n) 次，故复杂度为 **O(log n)**。

#### 2. 前缀和查询（query / sum）

查询 a[1] + a[2] + ... + a[x] 的值：

```cpp
// 查询前缀和 sum[1..x]
int sum(int x) {
    int res = 0;
    while (x > 0) {
        res += c[x];
        x -= lowbit(x);  // 跳到上一个不相交的区间
    }
    return res;
}
```

**复杂度**：同样每次去除二进制最低位的 1，最多 log₂(n) 次，**O(log n)**。

#### 3. 区间查询

查询区间和 sum[l, r] = sum(r) - sum(l-1)。

### 四、区间修改与单点查询（差分树状数组）

若需要对区间 [l, r] 内的所有元素加上同一个值 v，并能够查询单个位置的值，可以使用**差分数组**的思想：

1. 维护差分数组 d，其中 d[i] = a[i] - a[i-1]，则 a[x] = Σd[1..x]
2. 对 a[l..r] 全体加 v，等价于：
   - d[l] += v
   - d[r+1] -= v
3. 因此：**区间修改 → 两次单点修改；单点查询 → 前缀和查询**

```cpp
// 区间加 [l, r] 全部加 v
void range_add(int l, int r, int v) {
    add(l, v);
    add(r + 1, -v);
}

// 单点查询 a[x]
int point_query(int x) {
    return sum(x);
}
```

### 五、二维树状数组

扩展到二维平面上的矩阵操作。二维树状数组 c[x][y] 维护 (x - lowbit(x) + 1, y - lowbit(y) + 1) 到 (x, y) 的子矩阵和。

**单点修改**：

```cpp
void add(int x, int y, int v) {
    for (int i = x; i <= n; i += lowbit(i))
        for (int j = y; j <= m; j += lowbit(j))
            c[i][j] += v;
}
```

**子矩阵查询** sum[(1,1) .. (x,y)]：

```cpp
int sum(int x, int y) {
    int res = 0;
    for (int i = x; i > 0; i -= lowbit(i))
        for (int j = y; j > 0; j -= lowbit(j))
            res += c[i][j];
    return res;
}
```

**矩形查询** sum[(x1,y1) .. (x2,y2)] = sum(x2, y2) - sum(x1-1, y2) - sum(x2, y1-1) + sum(x1-1, y1-1)。

### 六、逆序对计数

逆序对问题：给定序列 a[1..n]，求满足 i < j 且 a[i] > a[j] 的 (i, j) 对数。

**树状数组解法**：

1. 将数值**离散化**（因为值域可能很大，而 n ≤ 5×10⁵）
2. 从后向前遍历：对于位置 i，查询树状数组中小于 a[i] 的元素个数（即已统计的、在 i 后面的、小于 a[i] 的元素数），就是 a[i] 作为较小值的逆序对数
3. 或者从前向后遍历：查询树状数组中大于 a[i] 的元素个数

**推而广之，树状数组还能解决以下问题**：
- 顺序对计数（正序对）
- 三连逆序对（树状数组套树状数组或 CDQ 分治）
- 滑动窗口的中位数（配合离散化和二分查找）

## 💻 代码模板

```cpp
// ========== 一维树状数组模板 ==========
const int MAXN = 500005;
int n;
long long c[MAXN];

int lowbit(int x) { return x & (-x); }

void add(int x, long long v) {
    while (x <= n) {
        c[x] += v;
        x += lowbit(x);
    }
}

long long sum(int x) {
    long long res = 0;
    while (x > 0) {
        res += c[x];
        x -= lowbit(x);
    }
    return res;
}

long long range_sum(int l, int r) {
    return sum(r) - sum(l - 1);
}

// ========== 二维树状数组模板 ==========
const int MAXN2 = 1005;
int n2, m2;
long long c2[MAXN2][MAXN2];

void add2(int x, int y, long long v) {
    for (int i = x; i <= n2; i += lowbit(i))
        for (int j = y; j <= m2; j += lowbit(j))
            c2[i][j] += v;
}

long long sum2(int x, int y) {
    long long res = 0;
    for (int i = x; i > 0; i -= lowbit(i))
        for (int j = y; j > 0; j -= lowbit(j))
            res += c2[i][j];
    return res;
}

// ========== 逆序对计数 ==========
// 需要先将 a 数组离散化到 [1..n]
long long count_inversions(vector<int>& a) {
    n = a.size();
    // 离散化
    vector<int> b = a;
    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end());
    for (int& x : a) x = lower_bound(b.begin(), b.end(), x) - b.begin() + 1;
    // 统计逆序对
    memset(c, 0, sizeof(c));
    long long ans = 0;
    for (int i = a.size() - 1; i >= 0; i--) {
        ans += sum(a[i] - 1);  // 比 a[i] 小的、已在 BIT 中的元素数
        add(a[i], 1);
    }
    return ans;
}
```

## ⚠️ 易错点与优化技巧

1. **下标从 1 开始**：树状数组要求下标从 1 开始（因为 lowbit(0) = 0 会死循环），务必注意
2. **数据范围**：CSP-S 题目中 n 通常 ≤ 5×10⁵，使用 `long long` 防止溢出
3. **离散化**：值域很大时必须离散化，逆序对问题时注意重复元素处理
4. **二维树状数组的空间**：O(n×m)，谨慎开数组。n,m ≤ 2000 时才安全
5. **单点查询 vs 区间修改**：区间修改单点查询使用差分思想，注意差分边界处理
6. **树状数组 vs 线段树**：树状数组常数小（约线段树的 1/5~1/3），能解决的问题尽量用树状数组
7. **lowbit 宏定义**：建议用函数而非宏，避免多次求值问题：`#define lowbit(x) ((x) & (-(x)))`
8. **树状数组求第 k 小**：可通过二分 + 前缀和实现，O(log²n)；也可用二进制倍增 O(log n)

## 📝 真题精练

### 真题一：[CSP-S 模拟] 逆序对

**题目描述**：
给定一个长度为 n 的排列 a[1..n]，求该排列的逆序对总数。

**数据范围**：
- 1 ≤ n ≤ 5×10⁵
- 1 ≤ a[i] ≤ n，且 a 是一个排列（无重复元素）

**解题思路**：
因为是排列，无需离散化。从右向左遍历，对于每个 a[i]，查询 BIT 中 [1, a[i]-1] 的和（即已在 BIT 中的、比 a[i] 小的元素的个数），这个个数就是 a[i] 贡献的逆序对数。

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 500005;
int n, a[MAXN];
long long c[MAXN], ans;

int lowbit(int x) { return x & (-x); }

void add(int x, int v) {
    while (x <= n) { c[x] += v; x += lowbit(x); }
}

long long sum(int x) {
    long long res = 0;
    while (x > 0) { res += c[x]; x -= lowbit(x); }
    return res;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = n; i >= 1; i--) {
        ans += sum(a[i] - 1);
        add(a[i], 1);
    }
    cout << ans << '\n';
    return 0;
}
```

**复杂度分析**：时间 O(n log n)，空间 O(n)。

### 真题二：[CSP-S 套题] 二维区间查询

**题目描述**：
维护一个 n×m 的矩阵，支持两种操作：
1. `1 x y k`：将位置 (x, y) 的值增加 k
2. `2 x1 y1 x2 y2`：查询子矩阵 (x1,y1) 到 (x2,y2) 的所有元素之和

**数据范围**：
- 1 ≤ n, m ≤ 1000
- 操作数 q ≤ 10⁵

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
int n, m, q;
long long c[MAXN][MAXN];

int lowbit(int x) { return x & (-x); }

void add(int x, int y, long long v) {
    for (int i = x; i <= n; i += lowbit(i))
        for (int j = y; j <= m; j += lowbit(j))
            c[i][j] += v;
}

long long sum(int x, int y) {
    long long res = 0;
    for (int i = x; i > 0; i -= lowbit(i))
        for (int j = y; j > 0; j -= lowbit(j))
            res += c[i][j];
    return res;
}

long long query(int x1, int y1, int x2, int y2) {
    return sum(x2, y2) - sum(x1-1, y2) - sum(x2, y1-1) + sum(x1-1, y1-1);
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    cin >> n >> m >> q;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++) {
            int x; cin >> x;
            add(i, j, x);
        }
    while (q--) {
        int op; cin >> op;
        if (op == 1) {
            int x, y, k; cin >> x >> y >> k;
            add(x, y, k);
        } else {
            int x1, y1, x2, y2; cin >> x1 >> y1 >> x2 >> y2;
            cout << query(x1, y1, x2, y2) << '\n';
        }
    }
    return 0;
}
```

**复杂度分析**：每次操作 O(log n × log m)，总复杂度 O(q · log n · log m)。

## 🎯 本课小结

1. **树状数组本质**：利用二进制拆分实现 O(log n) 的前缀和信息维护
2. **核心函数**：lowbit、add（向上跳）、sum（向下跳）
3. **高级应用**：差分实现区间修改单点查询、二维扩展、逆序对计数
4. **选择建议**：能树状数组不线段树——常数小得多，代码简洁
5. **难点突破**：理解 c[i] 区间的几何意义，掌握离散化技巧
