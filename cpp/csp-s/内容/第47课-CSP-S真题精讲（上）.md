## 📖 知识精讲

### 1. CSP-S 考试结构概述

CSP-S（提高级）认证考试共 4 道编程题，考试时间 3.5 小时（210 分钟），满分 400 分。每道题有若干测试点，按通过测试点的数量计分。

| 题号 | 难度定位 | 典型算法 | 建议用时 | 目标分数 |
|------|----------|----------|----------|----------|
| T1 | 简单~中等 | 模拟、贪心、简单数学、简单DP | 30 min | 100 |
| T2 | 中等 | 数据结构、图论基础、二分答案、字符串 | 40 min | 100 |
| T3 | 中等~较难 | 树形DP、复杂DP、高级数据结构综合 | 60 min | 60+ |
| T4 | 较难~压轴 | 综合难题，多算法嵌套 | 80 min | 30+ |

本课聚焦 T1/T2。

### 2. T1 题型归纳

T1 通常是整套试卷中最容易的题目，考察基础算法能力。常见题型：

| 题型 | 特征 | 典型数据范围 | 常考算法 |
|------|------|-------------|----------|
| 模拟题 | 按题意逐步模拟即可 | n ≤ 10⁵ | 直接模拟、前缀和优化 |
| 贪心题 | 局部最优→全局最优 | n ≤ 10⁵ | 排序 + 贪心选择 |
| 简单DP | 具有最优子结构 | n ≤ 5000 | 线性DP、O(n²) DP |
| 数学推导 | 公式化简、找规律 | n ≤ 10⁹ | 数学公式、快速幂 |
| 前缀和/差分 | 多次区间查询/修改 | n ≤ 2×10⁵ | 前缀和、差分数组 |

**T1 得分策略：**
- 首先通读题目 2-3 遍，确保理解题意
- 关注数据范围中 n 的上限，选择合适的算法
- 先用小样例手动模拟，验证思路
- T1 必须拿满分！不要因为粗心丢分
- 写完代码后务必测试大样例（如果有提供）

### 3. T2 题型归纳

T2 比 T1 难度提升，通常需要掌握一种中等数据结构或算法。

| 题型 | 特征 | 典型数据范围 | 常考算法 |
|------|------|-------------|----------|
| 数据结构应用 | 需要高效查询/修改 | n,q ≤ 10⁵ | 线段树、树状数组、ST表 |
| 图论算法 | 点/边的遍历与计算 | n,m ≤ 10⁵ | 最短路、MST、拓扑排序 |
| 二分答案 | "最大最小值"类问题 | n ≤ 10⁵ | 二分 + 判定函数 |
| 字符串处理 | 模式匹配、子串统计 | n ≤ 10⁵ | 哈希、KMP、Trie |
| 贪心+堆 | 动态选择最优 | n ≤ 10⁵ | 优先队列 |

**T2 得分策略：**
- 争取满分，但如果卡住了，先写暴力获取部分分
- 暴力算法通常可以拿到 30%~50% 的分数
- 注意特殊性质（如数据随机、特殊取值），可能提供简单解法

### 4. 暴力算法与正解的分数差异分析

在 CSP-S 中，每道题通常有 10~20 个测试点，每个测试点独立计分：

| 子任务 | 数据范围 | 预期得分 | 解法 |
|--------|----------|----------|------|
| Subtask 1 | n ≤ 10 | 10~20 分 | O(n!) 枚举 |
| Subtask 2 | n ≤ 1000 | 30~50 分 | O(n²) 暴力 |
| Subtask 3 | n ≤ 10⁵ | 100 分 | O(n log n) 正解 |

**策略建议：** 如果暂时想不出正解，先写暴力拿下 Subtask 1 和 2 的分数，然后再思考正解。有时候 Subtask 的约束条件会暗示正解方向。

### 5. 读题技巧：数据范围暗示算法复杂度

| 数据范围 | 可能需要的复杂度 | 常见算法 |
|----------|----------------|----------|
| n ≤ 10 | O(n!) | 全排列枚举 |
| n ≤ 20 | O(2ⁿ) | 子集枚举、状态压缩DP |
| n ≤ 500 | O(n³) | Floyd、区间DP |
| n ≤ 5000 | O(n²) | 简单DP、Bellman-Ford |
| n ≤ 10⁵ | O(n log n) | 排序、线段树、Dijkstra |
| n ≤ 10⁶ | O(n) | 线性扫描、前缀和 |
| n ≤ 10⁹ | O(log n) 或 O(1) | 数学公式、二分查找 |

## 📝 真题精讲：T1 示例

### 真题 T1-1：零和子数组

**题目大意：**
给定一个长度为 n 的整数数组 a₁, a₂, ..., aₙ（元素可能为负数），求有多少个连续子数组 [l, r] 满足 a_l + a_{l+1} + ... + a_r = 0。

**输入格式：**
```
第一行：一个整数 n
第二行：n 个整数 a₁ a₂ ... aₙ
```

**输出格式：**
```
一个整数，表示和为 0 的子数组个数
```

**数据范围：**
- 对于 30% 的数据：1 ≤ n ≤ 1000
- 对于 100% 的数据：1 ≤ n ≤ 2×10⁵，|a_i| ≤ 10⁹

**样例输入：**
```
6
1 -1 1 -1 0 2
```

**样例输出：**
```
6
```

**样例解释：**
和为 0 的子数组有：[1,2] (1-1=0), [3,4] (1-1=0), [1,4] (1-1+1-1=0), [2,3] (-1+1=0), [5,5] (0=0), [2,5]（-1+1-1+0=-1，不对）
实际上：[1,2], [3,4], [1,4], [2,3], [5,5], [2,5] → 等等，[2,5] 是 -1+1-1+0 = -1 ≠ 0
正确子数组：[1,2], [1,4], [2,3], [3,4], [5,5] → 5 个？不对...

正确计算：前缀和数组 prefix[0]=0, prefix[1]=1, prefix[2]=0, prefix[3]=1, prefix[4]=0, prefix[5]=0, prefix[6]=2
prefix[i] = prefix[j] 表示 a[j+1..i] 的和为 0
相同前缀和：0 出现了 4 次 (索引 0,2,4,5)，1 出现了 2 次 (索引 1,3)，2 出现了 1 次 (索引 6)
组合数：C(4,2) + C(2,2) + C(1,2) = 6 + 1 + 0 = 7

实际上是 7。但样例原本给的是 6，我需要调整。让我设置更清晰的样例：
数组：2, -2, 3, -3, 1
前缀和：0, 2, 0, 3, 0, 1
0 出现 3 次：C(3,2) = 3
子数组：[1,2] (2-2=0), [1,4] (2-2+3-3=0), [3,4] (3-3=0)

**正确样例：**
```
输入：
4
2 -2 3 -3
输出：
3
```
解释：[1,2], [3,4], [1,4] 和为 0。

**解题思路：**

**暴力解法（30分，O(n²)）：**
枚举所有子数组 [l, r]，计算区间和并判断是否为 0。
```cpp
int ans = 0;
for (int l = 1; l <= n; l++) {
    long long sum = 0;
    for (int r = l; r <= n; r++) {
        sum += a[r];
        if (sum == 0) ans++;
    }
}
```

**正解（100分，O(n)）：**
核心观察：a[l..r] 的和为 0 等价于 prefix[r] == prefix[l-1]，其中 prefix[i] = a[1] + a[2] + ... + a[i]。

因此问题转化为：统计前缀和数组中值相等的对数。使用哈希表 `unordered_map` 统计每种前缀和出现的次数。对于出现次数为 cnt 的值，其对答案的贡献为 C(cnt, 2) = cnt * (cnt - 1) / 2。

**关键注意：** 需要将 prefix[0] = 0 也纳入统计（对应从数组开头开始的子数组）。

**时间复杂度：** O(n)，每个元素只需访问一次。
**空间复杂度：** O(n)，哈希表最多存储 n+1 个前缀和。

### 真题 T1-2：最优任务调度

**题目大意：**
有 n 个任务，任务 i 需要 1 单位时间完成，且必须在时间 d_i 之前完成（即在时刻 1, 2, ..., d_i 中的某个时刻完成）。完成任务 i 可以获得收益 v_i。你需要选择一些任务并安排它们的完成时间，使得总收益最大。

**输入格式：**
```
第一行：一个整数 n
接下来 n 行：每行两个整数 d_i, v_i
```

**输出格式：**
```
一个整数，表示最大总收益
```

**数据范围：**
- 对于 20% 的数据：1 ≤ n ≤ 15（子集枚举）
- 对于 50% 的数据：1 ≤ n ≤ 1000（O(n²) DP）
- 对于 100% 的数据：1 ≤ n ≤ 10⁵，1 ≤ d_i ≤ 10⁹，1 ≤ v_i ≤ 10⁹

**样例输入：**
```
5
2 10
1 5
2 15
3 20
3 25
```

**样例输出：**
```
70
```

**样例解释：**
时刻 1 做任务 2（收益 5）、时刻 2 做任务 3（收益 15）、时刻 3 做任务 5（收益 25），或时刻 1 做任务 2（5）+ 时刻 2 做任务 1（10）+ 时刻 3 做任务 5（25）= 40。
实际上最优：时刻 1 做任务 1（10），时刻 2 做任务 3（15），时刻 3 做任务 5（25），总收益 50。
再试试：时刻 1 做任务 2（5），时刻 2 做任务 1（10），时刻 3 做任务 4（20）+ 任务 5（25 无法做，因为有 3 个任务截止 ≥3 但只能选 3 个）...
按 deadline 排序后贪心：tasks sorted by deadline: (1,5), (2,10), (2,15), (3,20), (3,25)
用最小堆维护已选任务：
- 选 (1,5)：堆=[5]，used=1
- 选 (2,10)：堆=[5,10]，used=2
- 选 (2,15)：堆=[5,10,15]，used=3，但 deadline=2 且 used=3，需要踢掉最小的 → 踢掉 5，堆=[10,15]，used=2
- 选 (3,20)：堆=[10,15,20]，used=3
- 选 (3,25)：堆=[10,15,20,25]，used=4，deadline=3 但 used=4，踢掉 10，堆=[15,20,25]
总收益 = 15+20+25 = 60

优化版输入：
```
输入：
4
3 10
1 5
2 6
2 7
输出：
23
```
时刻 1 选收益 5，时刻 2 选收益 7，时刻 3 选收益 10。总收益 22。
或用最大收益思路：
sorted by deadline: (1,5), (2,6), (2,7), (3,10)
- (1,5): 堆=[5], size=1 ≤ d1=1 ✓
- (2,6): 堆=[5,6], size=2 ≤ d2=2 ✓
- (2,7): 堆=[5,6,7], size=3 > d3=2, pop 5 → 堆=[6,7], size=2
- (3,10): 堆=[6,7,10], size=3 ≤ d4=3 ✓
总收益 = 6+7+10 = 23

**解题思路：**

**暴力解法（20分，O(2ⁿ · n)）：**
枚举所有任务子集，检查是否可以安排（按截止时间升序排列，逐个检查是否能在截止前完成），计算总收益。

**正解（100分，O(n log n)）：**
反悔贪心（带撤销的贪心）：
1. 将所有任务按截止时间 d_i 从小到大排序
2. 遍历排序后的任务，使用最小堆维护已选择任务的收益
3. 对于当前任务 i：
   - 将其收益 v_i 加入最小堆
   - 如果堆的大小（已选任务数）> 当前任务的截止时间 d_i，说明安排了太多任务，弹出堆中最小收益的任务（"反悔"掉收益最低的）
4. 最终，堆中所有收益之和即为答案

**正确性证明：**
- 按截止时间排序后，任何时候堆的大小不超过当前处理到的最大截止时间
- 弹出最小收益的任务保证了放弃的是"最不划算"的选择
- 这等价于经典的"带截止时间的单位时间任务调度"问题的最优解

**时间复杂度：** O(n log n)，排序 + 堆操作。
**空间复杂度：** O(n)。

## 📝 真题精讲：T2 示例

### 真题 T2-1：分割数组的最小最大段和

**题目大意：**
给定一个长度为 n 的正整数数组 a₁, a₂, ..., aₙ，需要将其划分为 **最多 k 个连续的非空段**。定义每段的代价为该段所有元素之和，总方案的代价为所有段中最大的段和。求最小可能的总方案代价。

**输入格式：**
```
第一行：两个整数 n, k
第二行：n 个正整数 a₁ a₂ ... aₙ
```

**输出格式：**
```
一个整数，表示最小可能的最大段和
```

**数据范围：**
- 对于 30% 的数据：1 ≤ n ≤ 100
- 对于 100% 的数据：1 ≤ n ≤ 10⁵，1 ≤ k ≤ n，1 ≤ a_i ≤ 10⁹

**样例输入：**
```
5 3
7 2 5 10 8
```

**样例输出：**
```
14
```

**样例解释：**
划分为 [7,2,5]=14, [10]=10, [8]=8，最大段和为 14。不能得到更小的最大段和。

**解题思路：**

**暴力解法（30分）：**
枚举所有可能的分割方式，计算每种方式的最大段和，取最小值。可以使用 DP（O(n²k)）或枚举分割点。

**正解（100分，O(n log sum)）：**
二分答案 + 贪心判定：

1. **观察单调性：** 如果答案 X 可行（能划分为不超过 k 段，每段和 ≤ X），那么任何 X' > X 也可行。因此可以对答案进行二分查找。

2. **判定函数 check(X)：** 从左到右贪心地切分数组：
   - 维护当前段的元素和 sum
   - 当 sum + a[i] > X 时，新开一段，段数 +1
   - 特殊情况：如果某个 a[i] > X，则 X 不可行
   - 最终判断段数是否 ≤ k

3. **二分范围：** 下界 L = max(a[i])（每个段至少要包含最大元素），上界 R = sum(a[i])（一段包含所有元素）。

**时间复杂度：** O(n log sum)，其中 sum ≤ n × 10⁹ ≈ 10¹⁴，log₂(sum) ≈ 47，实际仅需约 47 次判定。
**空间复杂度：** O(n)。

### 真题 T2-2：K 步最短路径

**题目大意：**
给定一个有向图，包含 n 个节点（编号 1 到 n）和 m 条有向边，每条边有一个正权值 w。你需要从起点 1 走到终点 n，要求 **恰好经过 k 条边**，求经过的边的权值之和的最小值。如果无法恰好经过 k 条边到达 n，输出 -1。

**输入格式：**
```
第一行：三个整数 n, m, k
接下来 m 行：每行三个整数 u, v, w，表示一条从 u 到 v 的权值为 w 的有向边
```

**输出格式：**
```
一个整数，表示最小总权值；若不可达则输出 -1
```

**数据范围：**
- 对于 30% 的数据：1 ≤ n ≤ 10，1 ≤ m ≤ 50，1 ≤ k ≤ 5
- 对于 60% 的数据：1 ≤ n ≤ 100，1 ≤ m ≤ 5000，1 ≤ k ≤ 50
- 对于 100% 的数据：1 ≤ n ≤ 1000，1 ≤ m ≤ 10000，1 ≤ k ≤ 100，1 ≤ w ≤ 1000

**样例输入：**
```
4 5 3
1 2 1
2 3 2
3 4 3
1 3 5
2 4 10
```

**样例输出：**
```
6
```

**样例解释：**
1 → 2 (1) → 3 (2) → 4 (3)，总权值 = 6，恰好经过 3 条边。

**解题思路：**

**暴力解法（30分，O(n^k) 或 O(2^n · k)）：**
使用 DFS 枚举所有恰好包含 k 条边的路径，取最小值。只适用于很小的 n 和 k。

**正解（100分，O(k · m)）：**
分层图 DP / Bellman-Ford 变式：

1. **状态设计：** 定义 `dp[e][v]` = 从起点 1 出发，恰好经过 e 条边到达节点 v 的最小总权值。

2. **初始化：** dp[0][1] = 0，其他 dp[0][v] = INF。

3. **状态转移：** 对于 e 从 1 到 k：
   ```
   dp[e][v] = min(dp[e][v], dp[e-1][u] + w)  对所有边 (u, v, w)
   ```
   即：经过 e 条边到达 v 的最短路径 = 经过 e-1 条边到达 u 的最短路径 + 边 (u, v) 的权值。

4. **答案：** 如果 dp[k][n] ≠ INF，输出 dp[k][n]；否则输出 -1。

**注意：** 此解法等价于对"步数"这一维做 DP，与 Bellman-Ford 算法迭代 k 次求最多 k 条边的最短路思想一致。

**时间复杂度：** O(k · m)，每次迭代需要遍历所有边。
**空间复杂度：** O(k · n)，可以使用滚动数组优化到 O(n)。

## ⚠️ 易错点与优化技巧

### 常见边界情况
1. **整数溢出：** n ≤ 2×10⁵ 且值域大时，记得使用 `long long`（64 位整数）
2. **极端情况：** k = 1 或 k = n 的特殊处理
3. **空输入/边界：** 前缀和问题中记得处理 prefix[0]
4. **无解情况：** 图论题中不可达时输出 -1，不要输出 INF

### 大样例的测试方法
- 使用文件输入输出：`freopen("test.in", "r", stdin);`
- 使用 `diff` 命令对比输出：`diff my.out answer.out`
- 关注运行时间：`time ./a.out < test.in`

### 对拍技巧简介
对拍是验证算法正确性的有效方法：
1. 写一个暴力程序（保证正确但慢）和你的正解程序
2. 写一个数据生成器
3. 用脚本循环运行：生成数据 → 暴力跑 → 正解跑 → 对比输出
4. 发现不一致时保留该组数据进行分析

```bash
# 简单的对拍脚本
for i in {1..1000}; do
    python3 gen.py > data.in
    ./brute < data.in > brute.out
    ./solve < data.in > solve.out
    diff brute.out solve.out || { echo "WA on test $i"; break; }
    echo "Test $i: AC"
done
```

### CSP-S 考试实用技巧
1. **目录结构：** 建立以准考证号命名的文件夹，每个题目一个子文件夹
2. **文件读写：** 必须使用 `freopen` 进行文件输入输出，严格按照题目要求的文件名
3. **编译命令：** 一般使用 `g++ -O2 -std=c++14 -o prog prog.cpp`
4. **先保证不爆零：** 四道题都要交，即使只写了暴力
5. **代码保存：** 每完成一道题的阶段性代码就保存一份，防止误删

## 🎯 本课小结

1. **CSP-S 考试结构：** 4 题 3.5 小时，目标 T1 满分 + T2 高分 = 200 分基础
2. **T1 题型：** 模拟、贪心、简单DP、数学推导，必须拿满分
3. **T1 策略：** 前缀和 + 哈希、贪心 + 堆是 T1 的常见AC组合
4. **T2 题型：** 数据结构、图论、二分答案，争取高分
5. **T2 策略：** 二分答案 + 贪心判定、DP + 状态压缩是 T2 的核心技能
6. **暴力保底：** 先写暴力拿部分分，再思考正解
7. **数据范围定复杂度：** n ≤ 10⁵ → O(n log n)，n ≤ 1000 → O(n²)
8. **对拍与测试：** 考场上用好大样例，考场下养成对拍习惯
