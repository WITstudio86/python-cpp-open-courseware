## 二、知识精讲

### 2.1 动态规划核心思想

**最优子结构（Optimal Substructure）**
一个问题具有最优子结构性质，意味着问题的最优解可以由其子问题的最优解组合而成。例如，在 LIS 问题中，以第 i 个元素结尾的最长上升子序列，必然由以某个 j < i 且 a[j] < a[i] 结尾的最长上升子序列再加上 a[i] 构成。

**无后效性（No Aftereffect）**
无后效性是指某阶段的状态一旦确定，则此后过程的演变不再受此前各状态及决策的影响。简单来说，"未来与过去无关"，这就是"无后效性"。在 DP 中，我们只关心当前状态是什么，而不关心它是如何到达的。

**重叠子问题（Overlapping Subproblems）**
动态规划区别于分治法的关键在于子问题重叠。不同的决策路径可能到达相同的子问题，DP 通过记忆化或递推避免重复计算，将指数级复杂度降低到多项式级别。

**DP 解题通用步骤：**
1. 设计状态表示（确定 dp 数组的含义）
2. 推导状态转移方程
3. 确定初始条件和边界
4. 确定计算顺序（确保无后效性）
5. 分析时间和空间复杂度，考虑优化

### 2.2 状态设计原则

- **明确性**：状态必须清晰描述当前局面。例如 `dp[i]` 表示"以第 i 个元素结尾"的某个最优值。
- **完整性**：状态应包含推导后续状态所需的全部信息。
- **最小性**：在不失完整性的前提下，状态维度越少越好。多余的信息会增加状态空间，降低效率。
- **可递推性**：状态之间必须能够通过转移方程相互推导。
- **常见状态设计模式**：
  - `dp[i]` — 以前 i 个元素 / 以第 i 个元素结尾
  - `dp[i][j]` — 二维状态，常见于两个序列的问题
  - `dp[i][j][k]` — 三维状态，多约束条件
  - 状态压缩 DP — 用二进制位表示集合状态

### 2.3 LIS 的 O(n²) DP 解法

**问题定义：** 给定一个长度为 n 的整数序列 a，求最长的严格递增子序列的长度。

**状态定义：** `dp[i]` 表示以 `a[i]` 结尾的最长上升子序列的长度。

**状态转移方程：**
```
dp[i] = max( dp[j] + 1 )  对于所有 j < i 且 a[j] < a[i]
```

**初始条件：** `dp[i] = 1`（每个元素自身构成长度为 1 的上升子序列）

**最终答案：** `max(dp[0], dp[1], ..., dp[n-1])`

**时间复杂度：** O(n²)，空间复杂度：O(n)

**算法流程：**
1. 初始化 dp 数组所有元素为 1
2. 外层循环 i 从 1 到 n-1
3. 内层循环 j 从 0 到 i-1，若 a[j] < a[i]，则尝试更新 dp[i]
4. 遍历过程中维护全局最大值

### 2.4 LIS 的 O(n log n) 贪心+二分优化

**核心思想：** 维护一个数组 `tails`，其中 `tails[k]` 表示当前找到的长度为 k+1 的上升子序列中，末尾元素的最小可能值。

**贪心性质：** 对于相同长度的上升子序列，末尾元素越小，越有可能在后续接上更多的元素。因此我们总是希望维护每种长度下末尾元素的最小值。

**算法流程：**
1. 遍历数组中的每个元素 x
2. 在 tails 中二分查找第一个 ≥ x 的位置（lower_bound）
3. 如果 x 大于 tails 中所有元素，则将 x 追加到 tails 末尾
4. 否则，用 x 替换该位置的元素
5. 最终 tails 的长度即为 LIS 的长度

**为什么 tails 最终严格递增？**
- 每次操作要么在末尾追加更大的元素，要么用较小的元素替换某个位置，保证了 tails 的单调递增性，从而可以使用二分查找。

**时间复杂度：** O(n log n)，空间复杂度：O(n)

**关键细节：**
- 求**严格上升**子序列：使用 `lower_bound`（找第一个 ≥ x 的位置）
- 求**不下降**（非严格上升）子序列：使用 `upper_bound`（找第一个 > x 的位置）
- 求**最长下降**子序列：将数组取负或逆序，转化为上升问题，或使用带比较器的二分

### 2.5 Dilworth 定理简介

**定理内容：** 在任意有限偏序集中，最大反链的大小等于最小链划分的大小。

**在 LIS 中的应用：**
- 最长上升子序列长度 = 将序列划分为若干个不上升子序列的最少组数
- 换言之，**最少的不上升子序列覆盖数 = 最长上升子序列长度**

**经典例题——导弹拦截（NOIP1999）：**
- 第一问：最长不上升子序列长度（单套系统最多拦截的导弹数）
- 第二问：最少需要多少套拦截系统 = 最长上升子序列长度（Dilworth 定理的直接应用）

## 三、代码模板

### 3.1 LIS O(n²) 模板

```cpp
int lis_n2(const vector<int>& a) {
    int n = a.size();
    vector<int> dp(n, 1);
    int ans = 1;
    for (int i = 1; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            if (a[j] < a[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
        ans = max(ans, dp[i]);
    }
    return ans;
}
```

### 3.2 LIS O(n log n) 模板

```cpp
int lis_nlogn(const vector<int>& a) {
    vector<int> tails;
    for (int x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) {
            tails.push_back(x);
        } else {
            *it = x;
        }
    }
    return tails.size();
}
```

### 3.3 LIS 路径还原

```cpp
vector<int> lis_path(const vector<int>& a) {
    int n = a.size();
    vector<int> dp(n, 1), pre(n, -1);
    int best_end = 0;
    for (int i = 1; i < n; ++i) {
        for (int j = 0; j < i; ++j) {
            if (a[j] < a[i] && dp[j] + 1 > dp[i]) {
                dp[i] = dp[j] + 1;
                pre[i] = j;
            }
        }
        if (dp[i] > dp[best_end]) best_end = i;
    }
    vector<int> path;
    for (int i = best_end; i != -1; i = pre[i]) {
        path.push_back(a[i]);
    }
    reverse(path.begin(), path.end());
    return path;
}
```

### 3.4 最长不下降子序列（LNDS）

```cpp
int lnds_nlogn(const vector<int>& a) {
    vector<int> tails;
    for (int x : a) {
        auto it = upper_bound(tails.begin(), tails.end(), x);  // 注意：upper_bound
        if (it == tails.end()) {
            tails.push_back(x);
        } else {
            *it = x;
        }
    }
    return tails.size();
}
```

## 四、易错点与优化技巧

### 4.1 易错点

| 易错点 | 说明 | 正确做法 |
|--------|------|----------|
| 二分边界 | 混淆 `lower_bound` 和 `upper_bound` | 严格上升用 `lower_bound`，非严格用 `upper_bound` |
| 降序转化 | 求最长下降子序列时忘记反转比较关系 | 可以取负值后求 LIS，或使用 `greater<int>()` 比较器 |
| 初始化遗漏 | dp 数组未初始化为 1 | 每个元素自身就是长度为 1 的子序列 |
| Dilworth 方向混淆 | 不理解链与反链的对应关系 | 最长上升子序列长度 = 最少不上升子序列覆盖数 |
| 空数组处理 | n=0 时未特判 | 加入 `if (a.empty()) return 0;` |

### 4.2 优化技巧

1. **二分优化是必须掌握的：** O(n²) 只能在 n ≤ 5000 时使用，n 达到 10⁵ 级别必须用 O(n log n) 算法。
2. **tails 数组只记录长度，不记录实际序列：** 若需要还原具体序列，需额外记录每个元素在 tails 中被放置的位置（pos 数组），最后反向构造。或者使用 O(n²) DP 进行路径还原。
3. **二维 LIS（按某一维排序后对另一维求 LIS）：** 常见于"信封嵌套"类问题。
4. **Dilworth 定理是 CSP-S 常考点：** 将序列划分问题转化为 LIS 问题，大幅降低难度。

## 五、真题精练

### 5.1 真题1：导弹拦截（NOIP1999 提高组）

**题目描述：**
某国为了防御敌国的导弹袭击，发展出一种导弹拦截系统。但是这种拦截系统有一个缺陷：虽然它的第一发炮弹能够到达任意高度，但是以后每一发炮弹都不能高于前一发的高度。某天，雷达捕捉到敌国的导弹来袭。由于该系统还在试用阶段，所以只有一套系统，因此有可能不能拦截所有的导弹。

输入导弹依次飞来的高度（雷达给出的高度数据是不大于 30000 的正整数），计算：
1. 这套系统最多能拦截多少导弹？
2. 如果要拦截所有导弹，最少要配备多少套这种导弹拦截系统？

**数据范围：** 导弹个数 n ≤ 100000，导弹高度 ≤ 30000

**解题思路：**
- 第一问：求最长不上升子序列（Longest Non-Increasing Subsequence）的长度
- 第二问：由 Dilworth 定理，最少的不上升子序列覆盖数 = 最长上升子序列长度

因此两问都可以用 O(n log n) 的贪心+二分解决。

**AC 代码核心：**
- 第一问：维护 tails 数组，对每个高度 h，在 tails 中找第一个 < h 的位置（使用 `upper_bound` + `greater<int>()` 或等价写法），替换或追加
- 第二问：标准 LIS（严格上升），使用 `lower_bound`

**复杂度分析：** O(n log n) 时间，O(n) 空间

### 5.2 真题2：合唱队形（NOIP2004 提高组）

**题目描述：**
N 位同学站成一排，音乐老师要请其中的 (N-K) 位同学出列，使得剩下的 K 位同学排成合唱队形。合唱队形是指这样的一种队形：设 K 位同学从左到右依次编号为 1, 2, …, K，他们的身高分别为 T₁, T₂, …, T_K，则他们的身高满足 T₁ < T₂ < … < T_i > T_{i+1} > … > T_K (1 ≤ i ≤ K)。

任务：已知所有 N 位同学的身高，计算最少需要几位同学出列。

**数据范围：** 2 ≤ N ≤ 100，130 ≤ 身高 ≤ 230

**解题思路：**
- 对每个位置 i，分别计算：
  - `left[i]`：以 i 结尾的最长上升子序列长度（从左到右）
  - `right[i]`：以 i 开头的最长下降子序列长度（从右到左求 LIS，等价于从左看的 LDS）
- 以 i 为最高点的合唱队形长度 = `left[i] + right[i] - 1`
- 需要出列的人数 = N - max(left[i] + right[i] - 1)

**复杂度分析：** O(n²) 时间（n=100 足够），O(n) 空间。n 上限小，O(n²) DP 完全可行。
