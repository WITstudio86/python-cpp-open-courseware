## 二、知识精讲

### 1. 最大子段和（Kadane算法）

**问题描述**：给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，求连续子段的最大和。

**状态定义**：$dp[i]$ 表示以第 $i$ 个元素结尾的最大子段和。

**状态转移方程**：

$$dp[i] = \max(a[i],\ dp[i-1] + a[i])$$

含义：要么从当前元素重新开始，要么接上前面的子段。

**滚动数组优化**：由于 $dp[i]$ 只依赖 $dp[i-1]$，可以用一个变量 `cur` 代替 $dp$ 数组，空间复杂度降为 $O(1)$。

```cpp
ll max_subarray_sum(const vector<ll>& a) {
    ll cur = 0, best = LLONG_MIN;
    for (ll x : a) {
        cur = max(x, cur + x);
        best = max(best, cur);
    }
    return best;
}
```

- **时间复杂度**：$O(n)$
- **空间复杂度**：$O(1)$

### 2. 数字三角形（逆推法）

**问题描述**：给定一个 $n$ 行的数字三角形，从顶部出发，每次可以向左下或右下走，求到达底部的最大路径和。

**状态定义**：$dp[i][j]$ 表示从位置 $(i, j)$ 出发，到达底层能获得的最大和。

**逆推法（自底向上）**：

$$dp[i][j] = a[i][j] + \max(dp[i+1][j],\ dp[i+1][j+1])$$

从倒数第二行开始向上计算，最终答案在 $dp[0][0]$。

**为什么逆推更好**：
- 顺推需要考虑边界条件（第一列和最后一列特殊处理）
- 逆推天然规避了边界问题，代码更简洁

```cpp
int triangle_max_path(const vector<vector<int>>& tri) {
    int n = tri.size();
    vector<vector<int>> dp = tri;
    for (int i = n - 2; i >= 0; --i)
        for (int j = 0; j <= i; ++j)
            dp[i][j] += max(dp[i+1][j], dp[i+1][j+1]);
    return dp[0][0];
}
```

- **时间复杂度**：$O(n^2)$
- **空间复杂度**：$O(n^2)$，可优化到 $O(n)$（只保留一行）

### 3. 路径计数DP（含障碍物）

**问题描述**：在一个 $m \times n$ 的网格中，从左上角 $(1,1)$ 出发，每次只能向右或向下移动，求到达右下角 $(m,n)$ 的不同路径数。网格中某些格子有障碍物（标记为 1），不能经过。

**状态转移方程**：

$$dp[i][j] = \begin{cases}
0 & \text{if grid[i][j] 是障碍} \\
dp[i-1][j] + dp[i][j-1] & \text{otherwise}
\end{cases}$$

**边界条件**：$dp[0][0] = 1$（如果没有障碍）

**关键细节**：
- 第一行和第一列需要特殊处理：如果前面有障碍，后面的格子都无法到达
- 注意取模（通常是 $10^9 + 7$）

```cpp
const int MOD = 1e9 + 7;
int count_paths_with_obstacles(const vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<int>> dp(m, vector<int>(n, 0));

    // 初始化第一格
    if (grid[0][0] == 0) dp[0][0] = 1;

    for (int i = 0; i < m; ++i) {
        for (int j = 0; j < n; ++j) {
            if (grid[i][j] == 1) { dp[i][j] = 0; continue; }
            if (i > 0) dp[i][j] = (dp[i][j] + dp[i-1][j]) % MOD;
            if (j > 0) dp[i][j] = (dp[i][j] + dp[i][j-1]) % MOD;
        }
    }
    return dp[m-1][n-1];
}
```

- **时间复杂度**：$O(m \times n)$
- **空间复杂度**：$O(m \times n)$，可优化到 $O(n)$

### 4. 最大子矩阵和（O(n³)算法）

**问题描述**：给定一个 $m \times n$ 的矩阵，求其所有子矩阵中元素和的最大值。

**核心思想**：压缩降维 + Kadane算法

**步骤**：
1. 枚举上边界 `top`（第 $i$ 行到第 $i$ 行）
2. 枚举下边界 `bottom`（从 `top` 向下扩展）
3. 将 `top` 到 `bottom` 之间的每一列求和，压缩成一个一维数组 `compressed[j]`
4. 对压缩数组运行 Kadane 算法求最大子段和
5. 更新全局最优解

```cpp
ll max_submatrix_sum(const vector<vector<ll>>& mat) {
    int m = mat.size(), n = mat[0].size();
    ll ans = LLONG_MIN;

    for (int top = 0; top < m; ++top) {
        vector<ll> compressed(n, 0);
        for (int bottom = top; bottom < m; ++bottom) {
            for (int j = 0; j < n; ++j) {
                compressed[j] += mat[bottom][j];
            }
            // Kadane on compressed array
            ll cur = 0, best = LLONG_MIN;
            for (ll x : compressed) {
                cur = max(x, cur + x);
                best = max(best, cur);
            }
            ans = max(ans, best);
        }
    }
    return ans;
}
```

- **时间复杂度**：$O(m^2 \cdot n)$。当 $m > n$ 时，可以转置矩阵，以较小维度枚举上下边界，时间复杂度优化到 $O(\min(m,n)^2 \cdot \max(m,n))$
- **空间复杂度**：$O(n)$

### 5. 最大子段和的变体

#### 5.1 环形最大子段和

序列首尾相接，子段可以跨越边界。

**两种情况**：
1. **不跨越边界**：普通 Kadane
2. **跨越边界**：总和 $-$ 最小子段和（中间被挖掉一段）

$$answer = \max(\text{max\_normal},\ \text{total} - \text{min\_subarray\_sum})$$

> **注意**：如果数组全为负数，`total - min_sum = 0`（因为最小子段和等于总和），此时应直接返回 `max_normal`。

```cpp
ll max_circular_subarray_sum(const vector<ll>& a) {
    ll total = accumulate(a.begin(), a.end(), 0LL);
    ll max_normal = max_subarray_sum(a);

    // 求最小子段和
    ll cur_min = 0, min_sum = 0;
    for (ll x : a) {
        cur_min = min(x, cur_min + x);
        min_sum = min(min_sum, cur_min);
    }

    if (max_normal < 0) return max_normal;  // 全负数
    return max(max_normal, total - min_sum);
}
```

#### 5.2 最大子段积

将加法换为乘法，注意负数乘以负数会变成正数。

**状态定义**：
- `max_dp[i]`：以 $i$ 结尾的最大乘积
- `min_dp[i]`：以 $i$ 结尾的最小乘积（因为负数乘以最小可能变成最大）

$$max\_dp[i] = \max(a[i],\ max\_dp[i-1] \times a[i],\ min\_dp[i-1] \times a[i])$$
$$min\_dp[i] = \min(a[i],\ max\_dp[i-1] \times a[i],\ min\_dp[i-1] \times a[i])$$

```cpp
ll max_product_subarray(const vector<ll>& a) {
    ll max_cur = a[0], min_cur = a[0], ans = a[0];
    for (int i = 1; i < a.size(); ++i) {
        ll x = a[i];
        ll new_max = max({x, max_cur * x, min_cur * x});
        ll new_min = min({x, max_cur * x, min_cur * x});
        max_cur = new_max;
        min_cur = new_min;
        ans = max(ans, max_cur);
    }
    return ans;
}
```

## 四、易错点与优化技巧

### 易错点

| 易错点 | 说明 | 修复方法 |
|--------|------|----------|
| Kadane 全负数 | `cur=0` 初始值会导致结果为 0 | 用 `LLONG_MIN` 初始化 `best` |
| 环形子段和全负数 | `total - min_sum = 0` 大于 `max_normal` | 加判断 `if (max_normal < 0)` |
| 路径计数取模遗漏 | 只在最终结果取模会导致溢出 | 每次加法后都取模 |
| 最大子矩阵 sum 溢出 | 使用 `int` 存储压缩和可能溢出 | 使用 `long long` |
| 数字三角形越界 | 顺推时 `j-1` 可能为 -1 | 使用逆推或从下标 1 开始 |

### 优化技巧

1. **空间优化**：路径计数DP可将二维数组优化为一维（滚动数组）
2. **矩阵转置**：最大子矩阵和问题，枚举较短的维度可优化常数
3. **前缀和配合**：最大子矩阵和可以配合前缀和 $O(1)$ 查询子矩阵和，将枚举上下边界后的一维数组采用前缀和求任意区间和
4. **提前剪枝**：最大子段积中，遇到 0 可以重置状态

## 五、真题精练

### 真题1：最大子矩阵和（P1719 最大加权矩形）

**题目描述**：给定一个 $n \times n$ 的矩阵，找出其中元素和最大的子矩阵，输出该最大和。

**数据范围**：$1 \le n \le 120$，$|a_{ij}| \le 100$。

**解题思路**：枚举上下边界 + 压缩为一维 + Kadane，时间复杂度 $O(n^3)$。

**AC代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
const ll INF = 1e18;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; cin >> n;
    vector<vector<ll>> a(n, vector<ll>(n));
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < n; ++j)
            cin >> a[i][j];

    ll ans = -INF;
    for (int top = 0; top < n; ++top) {
        vector<ll> col_sum(n, 0);
        for (int bot = top; bot < n; ++bot) {
            ll cur = 0, best = -INF;
            for (int j = 0; j < n; ++j) {
                col_sum[j] += a[bot][j];
                cur = max(col_sum[j], cur + col_sum[j]);
                best = max(best, cur);
            }
            ans = max(ans, best);
        }
    }
    cout << ans << "\n";
    return 0;
}
```

**复杂度分析**：
- 时间：$O(n^3)$，$n=120$ 时约 $1.7 \times 10^6$ 次操作，可以通过
- 空间：$O(n)$，仅需一个一维压缩数组

### 真题2：数字三角形变体（模运算）

**题目描述**：给定一个数字三角形，求从顶部到底部的路径和最大是多少。但本题要求输出**路径和模 100 的最大值**。

**数据范围**：$1 \le n \le 100$，$0 \le a_{ij} \le 99$。

**解题思路**：标准 DP 求最大值不能直接取模（模运算不满足单调性），因此需要转换思路——设 `dp[i][j][k]` 表示到达位置 $(i,j)$ 是否能获得模 100 等于 $k$ 的路径和。

**AC代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n; cin >> n;
    vector<vector<int>> a(n, vector<int>(n));
    for (int i = 0; i < n; ++i)
        for (int j = 0; j <= i; ++j)
            cin >> a[i][j];

    // dp[i][j][k]: 到达 (i,j) 时，路径和 mod 100 = k 是否可达
    vector<vector<vector<bool>>> dp(n, vector<vector<bool>>(n, vector<bool>(100, false)));
    dp[0][0][a[0][0] % 100] = true;

    for (int i = 0; i < n - 1; ++i) {
        for (int j = 0; j <= i; ++j) {
            for (int k = 0; k < 100; ++k) {
                if (!dp[i][j][k]) continue;
                int nk = (k + a[i+1][j]) % 100;
                dp[i+1][j][nk] = true;
                nk = (k + a[i+1][j+1]) % 100;
                dp[i+1][j+1][nk] = true;
            }
        }
    }

    int ans = 0;
    for (int j = 0; j < n; ++j)
        for (int k = 0; k < 100; ++k)
            if (dp[n-1][j][k]) ans = max(ans, k);
    cout << ans << "\n";
    return 0;
}
```

**复杂度分析**：
- 时间：$O(n^2 \times 100)$，$n=100$ 时约 $10^6$ 次操作
- 空间：$O(n^2 \times 100)$，可压缩为 $O(n \times 100)$

## 六、本课小结

| 模型 | 核心方程 | 时间复杂度 | 空间复杂度 | 关键技巧 |
|------|----------|-----------|-----------|----------|
| 最大子段和 | `dp[i] = max(a[i], dp[i-1]+a[i])` | $O(n)$ | $O(1)$ | 滚动变量 |
| 环形最大子段和 | `max(normal, total-min_sum)` | $O(n)$ | $O(1)$ | 分类讨论 |
| 数字三角形 | `dp[i][j] = a[i][j] + max(下, 右下)` | $O(n^2)$ | $O(n^2)$ | 逆推法 |
| 路径计数DP | `dp[i][j] = dp[i-1][j] + dp[i][j-1]` | $O(mn)$ | $O(mn)$ | 障碍物处理 |
| 最大子矩阵和 | 枚举上下界 + Kadane | $O(m^2 n)$ | $O(n)$ | 压缩降维 |
| 最大子段积 | 同时维护max_dp和min_dp | $O(n)$ | $O(1)$ | 负数翻转 |

**核心思想**：
1. **线性DP**的核心是「以第 i 个元素结尾」的状态定义
2. **压缩降维**是高维问题的重要转化手段
3. **滚动数组**是DP空间优化的基本功
4. 遇到「模运算下的最值」问题，考虑**可行性DP**而非直接取模
