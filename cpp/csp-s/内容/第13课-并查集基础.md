# 第13课：并查集基础（Union-Find / Disjoint Set Union）

## 📖 知识精讲

### 一、并查集的基本概念

并查集是一种维护**不相交集合**的数据结构，支持两种基本操作：
- **Find(x)**：查找元素 x 所属集合的代表元素（根节点）
- **Union(x, y)**：合并 x 和 y 所在的两个集合

核心思想是使用**森林**（多棵树）表示集合，每个集合用一棵树表示，树的根为该集合的代表元素。

### 二、朴素实现与优化

#### 1. 朴素实现（可能退化成链，O(n)）

```cpp
int fa[MAXN];  // fa[x] 表示 x 的父节点，根节点满足 fa[x] == x

// 初始化：每个元素自成一个集合
void init(int n) {
    for (int i = 1; i <= n; i++) fa[i] = i;
}

// 查找（朴素版）：沿父链向上，最坏 O(n)
int find(int x) {
    while (fa[x] != x) x = fa[x];
    return x;
}

// 合并（朴素版）
void unite(int x, int y) {
    fa[find(x)] = find(y);
}
```

**问题**：如果每次将深度大的树合并到深度小的树上，可能退化成一条链，find 的最坏复杂度为 O(n)。

#### 2. 路径压缩（Path Compression）

**访问路上顺便优化**：在 find 过程中，将路径上所有节点直接连接到根节点。

```cpp
int find(int x) {
    if (fa[x] != x) fa[x] = find(fa[x]);  // 递归：路径压缩
    return fa[x];
}
```

等价迭代写法：
```cpp
int find(int x) {
    int r = x;
    while (fa[r] != r) r = fa[r];   // 找根
    while (x != r) {                 // 路径压缩
        int t = fa[x];
        fa[x] = r;
        x = t;
    }
    return r;
}
```

#### 3. 按秩合并（Union by Rank / Size）

合并时，将**高度较小/节点数较少**的树合并到较大的树上，保持树的平衡。

**按大小合并**（推荐，更直观）：
```cpp
int fa[MAXN], sz[MAXN];  // sz 为集合大小

void init(int n) {
    for (int i = 1; i <= n; i++) fa[i] = i, sz[i] = 1;
}

int find(int x) {
    if (fa[x] != x) fa[x] = find(fa[x]);
    return fa[x];
}

void unite(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return;
    if (sz[x] < sz[y]) swap(x, y);  // 小树合并到大树
    fa[y] = x;
    sz[x] += sz[y];
}
```

**按高度（秩）合并**：
```cpp
int fa[MAXN], rk[MAXN];  // rk 为树的高度上界

void unite(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return;
    if (rk[x] < rk[y]) swap(x, y);
    fa[y] = x;
    if (rk[x] == rk[y]) rk[x]++;  // 只有等高时增加秩
}
```

### 三、时间复杂度分析

同时使用**路径压缩**和**按秩合并**的并查集，其时间复杂度为 **O(α(n))**，其中 α(n) 是反阿克曼函数。

**反阿克曼函数 α(n)**：
- α(10⁶) ≈ 4
- α(10⁹) ≈ 4
- α(10¹⁰⁰) ≈ 5
- 在 CSP-S 的数据范围内，α(n) ≤ 4

因此并查集的每次操作**近似 O(1)**，可以视为常数时间。

**证明思路（简要）**：
- 阿克曼函数 A(m, n) 增长极快
- α(n) 是其反函数，增长极慢
- 路径压缩使得树的高度快速降低
- 按秩合并保证树保持平衡

### 四、经典应用：连通块问题

并查集最常见的应用是维护图的连通性：
- 初始时有 n 个连通块
- 每次成功的 unite 操作，连通块数量减 1
- 可以离线处理加边和查询连通块数量

```cpp
int components = n;  // 初始连通块数

void unite(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return;
    if (sz[x] < sz[y]) swap(x, y);
    fa[y] = x;
    sz[x] += sz[y];
    components--;  // 连通块减少
}
```

## 💻 代码模板

```cpp
// ========== 并查集标准模板（路径压缩 + 按大小合并） ==========
struct DSU {
    vector<int> fa, sz;
    int components;

    DSU(int n) : fa(n + 1), sz(n + 1, 1), components(n) {
        for (int i = 1; i <= n; i++) fa[i] = i;
    }

    int find(int x) {
        return fa[x] == x ? x : fa[x] = find(fa[x]);
    }

    bool unite(int x, int y) {
        x = find(x); y = find(y);
        if (x == y) return false;
        if (sz[x] < sz[y]) swap(x, y);
        fa[y] = x;
        sz[x] += sz[y];
        components--;
        return true;
    }

    bool same(int x, int y) { return find(x) == find(y); }
    int size(int x) { return sz[find(x)]; }
};
```

## ⚠️ 易错点与优化技巧

1. **初始化 fa[i] = i** —— 每个元素是自己的根，忘记初始化会出错
2. **路径压缩在递归中写 `fa[x] = find(fa[x])`** —— 不是 `find(fa[x])`
3. **合并时先 find 再比较** —— unite 中必须 find 获取代表元素
4. **按大小合并比按秩合并更直观** —— 同时还能维护集合大小
5. **迭代版 find 避免栈溢出** —— n 很大时递归可能爆栈
6. **带权并查集** —— 下节课内容，维护元素间的关系值
7. **离线逆序处理** —— 配合并查集处理删边问题（倒序加边）
8. **连通块数量** —— 初始 n，每次成功 unite 减 1

## 📝 真题精练

### 真题一：[CSP-S 经典] 连通块

**题目描述**：
给定 n 个点和 m 次操作，操作有两种类型：
1. `M x y`：在 x 和 y 之间添加一条边
2. `Q x y`：查询 x 和 y 是否连通，以及当前连通块总数

**数据范围**：n, m ≤ 2×10⁵

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
int fa[MAXN], sz[MAXN], comp;

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

void unite(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return;
    if (sz[x] < sz[y]) swap(x, y);
    fa[y] = x;
    sz[x] += sz[y];
    comp--;
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    int n, m; cin >> n >> m;
    comp = n;
    for (int i = 1; i <= n; i++) fa[i] = i, sz[i] = 1;
    while (m--) {
        char op; int x, y;
        cin >> op >> x >> y;
        if (op == 'M') unite(x, y);
        else cout << (find(x) == find(y) ? "Yes" : "No")
                  << " " << comp << '\n';
    }
    return 0;
}
```

**复杂度分析**：每次操作 O(α(n))，总 O(m·α(n))。

### 真题二：[CSP-S 套题] 离线加边 + 连通块

**题目描述**：
给定一个 n 个点 m 条边的图，依次删去 k 条边（每次删一条）。求每次删边后图的连通块个数。

**数据范围**：n ≤ 10⁵，m, k ≤ 2×10⁵

**解题思路**：
离线反向处理。先建出所有未删除的边，用并查集求连通块数。然后**逆序**加回被删的边，每次加边更新连通块数。

**AC 代码核心**：

```cpp
// 标记被删除的边
set<pair<int,int>> deleted;
// 先加入所有未被删除的边
for (auto &e : edges) {
    if (!deleted.count({e.u, e.v}))
        dsu.unite(e.u, e.v);
}
// 逆序加回被删的边
vector<int> ans(k);
for (int i = k - 1; i >= 0; i--) {
    ans[i] = dsu.components;
    auto e = deleted_edges[i];
    dsu.unite(e.u, e.v);
}
// 输出 ans
```

**复杂度分析**：O((m+k)·α(n))。

## 🎯 本课小结

1. **并查集本质**：维护不相交集合的森林，支持近乎 O(1) 的合并与查询
2. **两大优化**：路径压缩（find 时扁平化）+ 按大小/秩合并（unite 时保持平衡）
3. **复杂度**：O(α(n))，在竞赛数据范围内视为 O(1)
4. **典型应用**：连通性判断、连通块计数、最小生成树（Kruskal）、离线逆序处理
