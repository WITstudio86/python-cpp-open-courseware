## 📖 知识精讲

### 一、拓扑排序基本概念

**拓扑排序（Topological Sort）** 是对有向无环图（DAG, Directed Acyclic Graph）的所有顶点进行线性排序，使得对于图中的每一条有向边 `(u, v)`，顶点 `u` 在排序中都出现在顶点 `v` 之前。

**重要性质：**
- 拓扑排序只存在于 DAG 中。如果图中存在环，则不存在拓扑排序。
- 一个 DAG 可能有多于一种拓扑排序。
- 拓扑排序可以理解为一种「依赖关系」的排序——做一件事之前，必须先完成它的所有前置任务。

**典型应用场景：**
- 课程安排（先修课关系）
- 项目构建系统（文件依赖）
- 任务调度（依赖关系）
- 编译器的指令调度
- 包管理器中的依赖解析

### 二、Kahn 算法（BFS + 入度表）

Kahn 算法是求解拓扑排序最直观的方法，时间复杂度 O(V+E)，空间复杂度 O(V)。

**算法步骤：**

1. **建图并统计入度**：遍历所有边，建立邻接表，同时统计每个节点的入度（即有多少条边指向该节点）。
2. **初始化队列**：将所有入度为 0 的节点加入队列。这些节点没有任何前置依赖，可以作为起始节点。
3. **BFS 处理**：循环执行以下操作直到队列为空：
   - 取出队首节点 u，将其加入拓扑序列。
   - 遍历 u 的所有出边邻接点 v，将 v 的入度减 1。
   - 如果 v 的入度变为 0，将 v 加入队列。
4. **判环**：如果最终拓扑序列的长度 < 节点总数 n，说明图中存在环，无法得到拓扑排序。

**核心思想**：每次「删除」一个入度为 0 的节点及它发出的所有边，不断重复。如果图是 DAG，最终所有节点都会被删除。

### 三、DFS 拓扑排序（后序遍历逆序）

DFS 方法利用深度优先搜索的后序遍历特性来获得拓扑序列。

**算法步骤：**

1. 对每个未访问节点进行 DFS。
2. 在 DFS 中，先递归访问所有邻接点（即所有后继节点）。
3. 递归返回后（即后序遍历位置），将当前节点加入结果序列。
4. 最终将结果序列**反转**，即得到拓扑排序。

**为什么是后序遍历的逆序？**
在一个 DAG 中进行 DFS，后序遍历意味着「子节点先于父节点被加入结果」。将这个顺序反转后，父节点就会排在子节点前面——这正是拓扑排序的要求。

**DFS 判断环的方法**：使用三色标记法（或访问状态数组）：
- `0` = 未访问
- `1` = 正在访问中（在当前递归栈中）
- `2` = 已访问完成

如果在 DFS 过程中遇到一个状态为 `1` 的节点，说明存在环（遇到了正在递归栈中的祖先）。

### 四、字典序最小拓扑序

在拓扑排序的基础上，如果需要输出字典序（编号顺序）最小的拓扑序列，只需将 Kahn 算法中的普通队列替换为**优先队列（小根堆）** 即可。

优先队列始终弹出编号最小的入度为 0 的节点，从而保证字典序最小。

### 五、DAG 判环方法对比

| 方法 | 实现 | 时间复杂度 | 特点 |
|------|------|-----------|------|
| Kahn 入度法 | BFS + 入度表 | O(V+E) | 直观易懂，可以同时得到拓扑序列 |
| DFS 三色标记 | DFS + 状态数组 | O(V+E) | 可以发现环上的具体节点 |
| 强连通分量 | Tarjan/Kosaraju | O(V+E) | 功能更强大，可以找出所有环 |

### 六、课程表问题分析

**LeetCode 207（课程表 I）**：给定课程总数和先修关系，判断是否可能完成所有课程。本质是**判断有向图是否为 DAG**。使用 Kahn 算法或 DFS 判环均可。

**LeetCode 210（课程表 II）**：在判断可行的基础上，返回任意一个可行的上课顺序。本质是**求任意一个拓扑序列**。使用 Kahn 算法即可。

**复杂度分析**：
- 时间复杂度：O(V+E)，每个节点和每条边都被处理一次。
- 空间复杂度：O(V+E)，邻接表存储图的结构。

### 七、常见误区与注意事项

1. **DFS 拓扑排序的递归顺序**：必须在递归子节点**之后**将当前节点加入序列（后序遍历），而非之前。
2. **入度为 0 节点的初始化**：不要遗漏任何入度为 0 的节点作为起始点。
3. **字典序最小 vs 任意拓扑序**：普通队列是 FIFO，得到的是「层次」相关的拓扑序；优先队列得到字典序最小的拓扑序。
4. **环的检测**：Kahn 算法通过比较拓扑序列长度与节点数判环；DFS 通过当前栈中节点的检测判环。

## 💻 代码模板

### 模板一：Kahn 算法（BFS + 入度表）

```cpp
// 返回拓扑序列，若存在环则返回空 vector
vector<int> topologicalSort(int n, vector<vector<int>>& edges) {
    vector<vector<int>> adj(n);
    vector<int> indegree(n, 0);
    
    // 建图 + 统计入度
    for (auto& e : edges) {
        int u = e[0], v = e[1];  // u → v
        adj[u].push_back(v);
        indegree[v]++;
    }
    
    queue<int> q;
    for (int i = 0; i < n; i++)
        if (indegree[i] == 0) q.push(i);
    
    vector<int> result;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        result.push_back(u);
        for (int v : adj[u]) {
            if (--indegree[v] == 0)
                q.push(v);
        }
    }
    
    // 判断是否有环
    if ((int)result.size() < n) return {};  // 有环
    return result;
}
```

### 模板二：DFS 拓扑排序

```cpp
// 三色标记法：0=未访问, 1=访问中, 2=已完成
bool dfs(int u, vector<vector<int>>& adj, vector<int>& state, vector<int>& result) {
    state[u] = 1;  // 标记为访问中
    for (int v : adj[u]) {
        if (state[v] == 1) return false;   // 发现环
        if (state[v] == 0 && !dfs(v, adj, state, result))
            return false;
    }
    state[u] = 2;  // 标记为已完成
    result.push_back(u);  // 后序遍历位置
    return true;
}

vector<int> topologicalSortDFS(int n, vector<vector<int>>& edges) {
    vector<vector<int>> adj(n);
    for (auto& e : edges)
        adj[e[0]].push_back(e[1]);
    
    vector<int> state(n, 0), result;
    for (int i = 0; i < n; i++) {
        if (state[i] == 0 && !dfs(i, adj, state, result))
            return {};  // 有环
    }
    reverse(result.begin(), result.end());  // 逆序即拓扑序
    return result;
}
```

### 模板三：字典序最小拓扑序（优先队列）

```cpp
vector<int> topologicalSortMinLexical(int n, vector<vector<int>>& edges) {
    vector<vector<int>> adj(n);
    vector<int> indegree(n, 0);
    for (auto& e : edges) {
        adj[e[0]].push_back(e[1]);
        indegree[e[1]]++;
    }
    
    // 使用小根堆（优先队列）
    priority_queue<int, vector<int>, greater<int>> pq;
    for (int i = 0; i < n; i++)
        if (indegree[i] == 0) pq.push(i);
    
    vector<int> result;
    while (!pq.empty()) {
        int u = pq.top(); pq.pop();
        result.push_back(u);
        for (int v : adj[u]) {
            if (--indegree[v] == 0) pq.push(v);
        }
    }
    if ((int)result.size() < n) return {};  // 有环
    return result;
}
```

## ⚠️ 易错点与优化技巧

### 常见错误

| 错误类型 | 错误表现 | 正确做法 |
|---------|---------|---------|
| DFS后序理解错误 | 在前序位置将节点加入结果 | 必须在递归子节点**之后**加入 |
| 入度为0节点遗漏 | 结果序列不完整 | 遍历所有节点，将所有deg=0入队 |
| 忽略重边 | 入度被重复计算 | 如果题目有重边需特殊处理 |
| pq类型错误 | 使用大根堆 | 字典序最小需使用greater\<int\> |

### 优化技巧

1. **邻接表 vs 邻接矩阵**：对于稀疏图（E << V²），使用邻接表；密集图可使用邻接矩阵。
2. **入度表使用数组池**：对于动态变化的图，可以使用vector替代数组以便重置。
3. **多次查询优化**：如果需要对同一个图进行多次拓扑排序（如逐个删除节点验证），可预先保存原始入度表。
4. **拓扑排序判断唯一性**：在 Kahn 算法中，如果同一时刻队列中只有一个节点，则拓扑序列唯一。

## 🎯 本课小结

1. **拓扑排序**是对 DAG 的顶点线性排序，使得每条边 (u,v) 中 u 排在 v 前面。
2. **Kahn 算法（BFS）**：维护入度表，每次将入度为 0 的节点入队，是应用最广泛的方法。
3. **DFS 算法**：利用后序遍历的逆序得到拓扑序列，同时可以三色标记判环。
4. **字典序最小**：将队列替换为优先队列即可。
5. **判环**：Kahn 算法比较序列长度 vs 节点数；DFS 检测当前递归栈中的节点。
6. **核心应用**：课程表问题、任务调度、依赖解析等，本质都是 DAG 的拓扑排序问题。
7. **时间复杂度**：O(V+E)，适用于 n ≤ 10^5 的规模。
