## 知识精讲

### 一、输入输出优化

#### 1.1 问题分析

在CSP-S考试中，部分题目输入量极大（n 可达 10^6 甚至更多），默认的 `cin/cout` 由于与 C 标准输入输出同步以及频繁刷新缓冲区，会导致大量时间消耗在 I/O 上而非算法本身。

**典型场景**：
- 需要读入 10^6 个整数，使用 `cin` 可能耗时 0.5~1 秒
- 使用 `scanf` 约耗时 0.2~0.3 秒
- 使用快速读入（`getchar` 实现）约耗时 0.05~0.1 秒

#### 1.2 标准优化方案

**方案一：解除同步 + 关闭绑定（最简方案）**

```cpp
ios::sync_with_stdio(false);  // 解除 cin/cout 与 scanf/printf 的同步
cin.tie(nullptr);              // 解除 cin 与 cout 的绑定
```

**原理**：
- 默认情况下，`cin` 与 `scanf` 共享缓冲区（同步），确保混用时的正确性。关闭同步后，`cin` 使用独立缓冲区，速度显著提升。
- 默认情况下，每次 `cin` 之前都会刷新 `cout` 缓冲区（绑定），确保交互式程序的输出顺序。解除绑定可避免不必要的刷新。

**注意**：使用此优化后，不能混用 `cin/cout` 与 `scanf/printf`，否则可能出现顺序错乱。

**方案二：快速读入模板（最快方案）**

```cpp
// 快速读入整数（支持负数）
inline int read() {
    int x = 0, f = 1;
    char ch = getchar();
    while (ch < '0' || ch > '9') {
        if (ch == '-') f = -1;
        ch = getchar();
    }
    while (ch >= '0' && ch <= '9') {
        x = x * 10 + (ch ^ 48);  // ch ^ 48 等价于 ch - '0'，位运算更快
        ch = getchar();
    }
    return x * f;
}

// 快速输出整数
inline void write(int x) {
    if (x < 0) { putchar('-'); x = -x; }
    if (x > 9) write(x / 10);
    putchar(x % 10 + '0');
}
```

**性能对比**（读取 10^7 个整数）：
| 方法 | 耗时（约） |
|------|-----------|
| `cin`（默认）| ~2.0s |
| `cin`（解同步）| ~0.8s |
| `scanf` | ~0.9s |
| 快速读入 | ~0.3s |

#### 1.3 输出优化


### 二、位运算优化技巧

位运算直接操作二进制位，是计算机最底层、最快速的操作。合理使用位运算可以显著减少常数因子。

#### 2.1 基础位运算

| 运算 | 符号 | 示例 | 效果 |
|------|------|------|------|
| 与 | `&` | `x & 1` | 判断奇偶（奇数为1） |
| 或 | `\|` | `x \| (1 << k)` | 将第 k 位置 1 |
| 异或 | `^` | `x ^ x` | 结果为 0（自反性） |
| 取反 | `~` | `~x` | 按位取反 |
| 左移 | `<<` | `1 << k` | 计算 2^k |
| 右移 | `>>` | `x >> 1` | 整数除以 2 |

#### 2.2 lowbit 操作

**定义**：`lowbit(x)` 返回 `x` 在二进制表示下最低位的 1 所代表的值。

**公式**：`lowbit(x) = x & (-x)`

**原理**：在计算机中，负数用补码表示：`-x = ~x + 1`。
`x & (-x) = x & (~x + 1)`，恰好保留最低位的 1。

**应用——树状数组（Fenwick Tree）**：
```cpp
// 树状数组的核心就是 lowbit
void add(int idx, int val) {
    while (idx <= n) {
        tree[idx] += val;
        idx += idx & -idx;  // lowbit
    }
}

int query(int idx) {
    int sum = 0;
    while (idx > 0) {
        sum += tree[idx];
        idx -= idx & -idx;  // lowbit
    }
    return sum;
}
```

#### 2.3 位运算实用技巧集


#### 2.4 快速幂（二进制拆分）

```cpp
// 求 a^b mod MOD，复杂度 O(log b)
ll qpow(ll a, ll b, ll mod) {
    ll res = 1;
    a %= mod;
    while (b) {
        if (b & 1) res = res * a % mod;  // b 当前最末位为 1
        a = a * a % mod;
        b >>= 1;  // b = b / 2
    }
    return res;
}
```

**原理**：将指数 b 按二进制拆分为若干个 2 的幂之和。
例如：`a^13 = a^(8+4+1) = a^8 · a^4 · a^1`（13₁₀ = 1101₂）

### 三、循环展开

#### 3.1 原理

循环展开是一种以代码体积换取运行速度的优化技术。通过减少循环控制指令（比较、跳转、计数器更新）的执行次数来提升性能。

**普通循环**（每迭代 4 次需要 4 次条件判断 + 4 次跳转）：
```cpp
for (int i = 0; i < n; i++) {
    a[i] = b[i] + c[i];
}
```

**展开为 4 路循环**（每 4 次迭代仅需 1 次条件判断 + 1 次跳转）：
```cpp
int i = 0;
for (; i + 3 < n; i += 4) {
    a[i]   = b[i]   + c[i];
    a[i+1] = b[i+1] + c[i+1];
    a[i+2] = b[i+2] + c[i+2];
    a[i+3] = b[i+3] + c[i+3];
}
// 处理剩余元素
for (; i < n; i++) {
    a[i] = b[i] + c[i];
}
```

#### 3.2 适用场景与注意事项

- **适用**：简单循环体（数组赋值、加法等），循环次数很大（10^6 以上）
- **不适用**：循环体复杂时收益递减；现代编译器 (`-O2`/`-O3`) 会自动进行循环展开
- **CSP-S 建议**：一般不需要手动展开，现代编译器优化足够好。了解原理即可。

### 四、搜索剪枝策略

搜索剪枝是在搜索过程中通过判断条件提前排除不可能产生答案的分支，从而大幅减少搜索空间。好的剪枝可以将指数级复杂度降低到可接受的范围。

#### 4.1 可行性剪枝

**定义**：在当前状态下，判断是否有可能到达目标状态。如果不可能，立即回溯。

**经典例题——N皇后问题**：
在 N×N 的棋盘上放置 N 个皇后，使其互不攻击。

剪枝策略：
- 每行只能放一个皇后（按行DFS）
- 每列只能放一个皇后（列标记数组）
- 每条对角线只能放一个皇后（对角线标记数组）

```cpp
bool col[N], diag1[2*N], diag2[2*N];

void dfs(int row, int n) {
    if (row == n) { ans++; return; }
    for (int c = 0; c < n; c++) {
        if (col[c] || diag1[row + c] || diag2[row - c + n])
            continue;  // 可行性剪枝：该位置不可放
        // 放置皇后
        col[c] = diag1[row + c] = diag2[row - c + n] = true;
        dfs(row + 1, n);
        col[c] = diag1[row + c] = diag2[row - c + n] = false;
    }
}
```

**剪枝效果**：对于 N=8，从可能的 4,426,165,368 个状态减少到仅搜索几千个状态。

#### 4.2 最优性剪枝

**定义**：在求最优解的搜索中，如果当前状态的代价已经超过（或不优于）目前已找到的最优解，则剪枝。

**经典例题——0-1 背包（搜索解法）**：
```cpp
int best = 0;  // 当前最优解
int w[N], v[N]; // 重量、价值

void dfs(int idx, int cur_w, int cur_v, int capacity, int n) {
    if (cur_w > capacity) return;  // 可行性剪枝

    // 最优性剪枝：即使剩下全部拿完也不会更好
    int max_remaining = 0;
    for (int i = idx; i < n; i++) max_remaining += v[i];
    if (cur_v + max_remaining <= best) return;

    if (idx == n) {
        best = max(best, cur_v);
        return;
    }

    // 不选第 idx 个物品
    dfs(idx + 1, cur_w, cur_v, capacity, n);
    // 选第 idx 个物品
    dfs(idx + 1, cur_w + w[idx], cur_v + v[idx], capacity, n);
}
```

#### 4.3 顺序性剪枝

**定义**：通过规定搜索顺序来减少重复状态的搜索。

**技巧**：
1. **优先搜索约束最强的分支**（最少剩余值启发式）：减少分支因子
2. **避免搜索对称状态**：如在组合问题中强制元素选择顺序递增
3. **预处理排序**：先处理"选择余地小"的选项

```cpp
// 组合数枚举：强制递增顺序避免重复
// 如从 n 个数中选 k 个的所有组合
void dfs_comb(int start, int cnt, int n, int k) {
    if (cnt == k) { /* 处理组合 */ return; }
    // 顺序性剪枝：从 start 开始选择，保证递增
    // 可行性剪枝：剩余元素不够选满 k 个
    for (int i = start; i <= n - (k - cnt); i++) {
        chosen[cnt] = i;
        dfs_comb(i + 1, cnt + 1, n, k);
    }
}
```

### 五、记忆化搜索

#### 5.1 原理

记忆化搜索（Memoization）是动态规划的一种实现方式：将已经计算过的子问题结果存储起来，下次遇到相同子问题时直接返回缓存结果，避免重复计算。

**核心思想**：搜索 + 哈希表（或数组）= 记忆化 = 自顶向下的 DP

#### 5.2 经典实现

**斐波那契数列（记忆化版）**：
```cpp
const int MAXN = 100005;
ll memo[MAXN];
bool visited[MAXN];  // 标记是否已计算

ll fib(int n) {
    if (n <= 1) return n;
    if (visited[n]) return memo[n];  // 记忆化：直接返回缓存
    visited[n] = true;
    return memo[n] = fib(n - 1) + fib(n - 2);
}
// 复杂度：从 O(2^n) 降至 O(n)
```

**数字三角形（经典DP的记忆化实现）**：
```cpp
// 输入：一个数字三角形，从顶部出发在每一节点可以选择向左下或右下走，
//      求走到最底层的最大路径和。
int a[MAXN][MAXN];
ll dp[MAXN][MAXN];
bool vis[MAXN][MAXN];

ll dfs(int i, int j, int n) {
    if (i == n) return a[i][j];  // 最后一行
    if (vis[i][j]) return dp[i][j];  // 记忆化
    vis[i][j] = true;
    return dp[i][j] = a[i][j] + max(dfs(i + 1, j, n), dfs(i + 1, j + 1, n));
}
```

#### 5.3 记忆化 vs 递推 DP

| 方面 | 记忆化搜索（自顶向下） | 递推 DP（自底向上） |
|------|----------------------|-------------------|
| 实现难度 | 较简单（递归思路） | 需分析状态转移顺序 |
| 计算所有状态 | 否（只计算需要的） | 是（计算所有状态） |
| 空间开销 | 需额外 vis 数组 | 仅需 dp 数组 |
| 递归深度限制 | 受栈大小限制 | 无限制 |
| 适用场景 | 状态空间稀疏 | 状态转移有拓扑序 |

#### 5.4 状态压缩 DP + 记忆化

对于状态用位掩码表示的问题，记忆化搜索尤其自然：

```cpp
// 旅行商问题 (TSP) 的记忆化解法
// dp[mask][i]: 已访问城市集合为 mask，当前在城市 i 的最短路径
int n;
ll dist[20][20];
ll dp[1 << 20][20];
bool vis[1 << 20][20];

ll tsp(int mask, int u) {
    if (mask == (1 << n) - 1) return 0;  // 所有城市已访问
    if (vis[mask][u]) return dp[mask][u];
    vis[mask][u] = true;
    ll ans = LLONG_MAX;
    for (int v = 0; v < n; v++) {
        if (!(mask & (1 << v))) {
            ans = min(ans, dist[u][v] + tsp(mask | (1 << v), v));
        }
    }
    return dp[mask][u] = ans;
}
```

## 易错点与优化技巧

### 常见错误

1. **解同步后混用 cin 和 scanf**：解除 `ios::sync_with_stdio(false)` 后，C++ 流和 C 标准 I/O 的缓冲区独立，混用会导致输入输出顺序错乱。**解决方案**：全用 cin/cout 或全用 scanf/printf。

2. **递归记忆化忘记初始化 vis 数组**：全局 vis 数组默认零值，但如果有多组测试数据，需要在每组数据前重置。可以使用时间戳技巧避免 memset：
   ```cpp
   int vis[MAXN];     // 存储"最后一次访问的时间"
   int cur_time = 0;  // 当前时间戳
   // 检查：if (vis[state] == cur_time) return memo[state];
   // 标记：vis[state] = cur_time;
   ```

3. **剪枝条件写反**：最优性剪枝中，求最大值和求最小值的剪枝方向相反：
   - 求**最小值**：当前代价 + 乐观下界 ≥ 当前最优 → 剪枝
   - 求**最大值**：当前代价 + 乐观上界 ≤ 当前最优 → 剪枝

4. **位运算符优先级**：`&`、`|`、`^` 的优先级低于 `==` 和 `!=`，需要加括号：
   ```cpp
   if (x & 1 == 0)   // 错误！等价于 x & (1 == 0) = x & 0 = 0
   if ((x & 1) == 0) // 正确
   ```

5. **快速幂取模溢出**：`res * a % mod` 中，如果 `res * a` 超过 `long long` 范围，需要使用 `__int128` 或快速乘：
   ```cpp
   // 快速乘（俄罗斯农民乘法），防溢出
   ll mul_mod(ll a, ll b, ll mod) {
       ll res = 0;
       while (b) {
           if (b & 1) res = (res + a) % mod;
           a = (a + a) % mod;
           b >>= 1;
       }
       return res;
   }
   ```

### 优化技巧

1. **inline 小函数**：对于频繁调用的短函数（如 `lowbit`、`read`），使用 `inline` 提示编译器内联展开。

2. **数组维度顺序**：遍历二维数组时，优先遍历连续内存方向：
   ```cpp
   // 好（行优先，cache 友好）
   for (int i = 0; i < n; i++)
       for (int j = 0; j < m; j++)
           a[i][j] = ...;
   // 差（列优先，大量 cache miss）
   for (int j = 0; j < m; j++)
       for (int i = 0; i < n; i++)
           a[i][j] = ...;
   ```

3. **善用 __builtin 系列函数**：GCC 内置位运算函数通常映射到单条 CPU 指令。

4. **const 引用传参**：对于大对象（如 `vector`、`string`），使用 `const &` 传参避免拷贝。

5. **预分配 vector 容量**：如果能预估大小，使用 `reserve()` 预分配，避免多次扩容。

## 真题精练

### 题目1：N皇后问题（带剪枝优化）

**【题目描述】**

在 N×N 的国际象棋棋盘上放置 N 个皇后，使得它们不能互相攻击。皇后可以攻击同一行、同一列、同一对角线上的任意棋子。请统计所有合法的放置方案数。

要求实现三种解法并进行性能对比：
1. **裸 DFS**：枚举所有 N^N 种放置方式
2. **行剪枝 DFS**：每行只放一个，降低到 N! 种
3. **位运算加速 DFS**：使用位掩码标记列和对角线占用情况

**【输入格式】**

一行一个整数 N（8 ≤ N ≤ 14）。

**【输出格式】**

一个整数，表示合法方案数。

**【样例输入】**

```
8
```

**【样例输出】**

```
92
```

**【题目分析】**

- N=8 时答案为 92。
- 方案1（裸 DFS）：每个位置试放，复杂度 O(N^N × N^2)，N=8 时约 16M 次检查，勉强可过。
- 方案2（行剪枝）：每行确定一列，复杂度 O(N!)，N=10 时约 3.6M，N=12 时约 479M。
- 方案3（位运算）：进一步用位掩码表示列/对角线的占用，CPU 级并行判断，常数极小。N=14 时约 3.6×10^10 理论上太大，但实际剪枝后有效搜索空间远小于此。

对于 N=14（答案 365596），方案3 可在 1 秒内完成。

**【AC代码】**

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// ============ 方案1：裸 DFS（仅用于对比） ============
namespace Naive {
    int n, ans = 0;
    vector<vector<bool>> board;

    bool is_safe(int r, int c) {
        // 检查列
        for (int i = 0; i < r; i++)
            if (board[i][c]) return false;
        // 检查左上对角线
        for (int i = r - 1, j = c - 1; i >= 0 && j >= 0; i--, j--)
            if (board[i][j]) return false;
        // 检查右上对角线
        for (int i = r - 1, j = c + 1; i >= 0 && j < n; i--, j++)
            if (board[i][j]) return false;
        return true;
    }

    void dfs(int r) {
        if (r == n) { ans++; return; }
        for (int c = 0; c < n; c++) {
            if (is_safe(r, c)) {
                board[r][c] = true;
                dfs(r + 1);
                board[r][c] = false;
            }
        }
    }

    int solve(int _n) {
        n = _n; ans = 0;
        board.assign(n, vector<bool>(n, false));
        dfs(0);
        return ans;
    }
}

// ============ 方案2：数组标记剪枝 ============
namespace ArrayPruning {
    int n, ans = 0;
    bool col[50], diag1[100], diag2[100];
    // diag1: row + col（主对角线）, diag2: row - col + n（副对角线）

    void dfs(int r) {
        if (r == n) { ans++; return; }
        for (int c = 0; c < n; c++) {
            if (col[c] || diag1[r + c] || diag2[r - c + n])
                continue;  // 可行性剪枝
            col[c] = diag1[r + c] = diag2[r - c + n] = true;
            dfs(r + 1);
            col[c] = diag1[r + c] = diag2[r - c + n] = false;
        }
    }

    int solve(int _n) {
        n = _n; ans = 0;
        memset(col, 0, sizeof(col));
        memset(diag1, 0, sizeof(diag1));
        memset(diag2, 0, sizeof(diag2));
        dfs(0);
        return ans;
    }
}

// ============ 方案3：位运算优化 ============
namespace Bitwise {
    int n, ans = 0;
    int full_mask;  // (1 << n) - 1，所有位为1表示该列可用

    void dfs(int r, int col_mask, int diag1_mask, int diag2_mask) {
        if (r == n) { ans++; return; }
        // 所有可用的列：full_mask 去除已被占用的列和对角线位置
        int available = full_mask & ~(col_mask | diag1_mask | diag2_mask);
        while (available) {
            int pos = available & -available;  // lowbit：取最低位的1
            available -= pos;                   // 移除该位置
            // 下一行时：diag1 左移一位，diag2 右移一位
            dfs(r + 1, col_mask | pos,
                (diag1_mask | pos) << 1,
                (diag2_mask | pos) >> 1);
        }
    }

    int solve(int _n) {
        n = _n; ans = 0;
        full_mask = (1 << n) - 1;
        dfs(0, 0, 0, 0);
        return ans;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    // 对比三种方案的时间
    auto t1 = chrono::high_resolution_clock::now();
    int ans1 = ArrayPruning::solve(n);
    auto t2 = chrono::high_resolution_clock::now();
    int ans2 = Bitwise::solve(n);
    auto t3 = chrono::high_resolution_clock::now();

    cout << "答案: " << ans1 << '\n';
    cout << "方案2（数组剪枝）: "
         << chrono::duration<double>(t2 - t1).count() << "s\n";
    cout << "方案3（位运算剪枝）: "
         << chrono::duration<double>(t3 - t2).count() << "s\n";

    return 0;
}
```

**【复杂度分析】**

- 方案2：O(N!)，但剪枝使实际搜索空间远小于 N!。每个状态 O(1) 判断合法性。
- 方案3：O(N!)，但位掩码的并行性使每步操作极快（单条 CPU 指令），实际运行时间约为方案2的 1/5。

### 题目2：采药（0-1 背包的记忆化搜索实现）

**【题目描述】**

辰辰是个天资聪颖的孩子，他的梦想是成为世界上最伟大的医师。为此，他想拜附近最有威望的医师为师。医师为了判断他的资质，给他出了一个难题。医师把他带到一个到处都是草药的山洞里，对他说："孩子，这个山洞里有一些不同的草药，采每一株都需要一些时间，每一株也有它自身的价值。我会给你一段时间，在这段时间里，你可以采到一些草药。如果你是一个聪明的孩子，你应该可以让采到的草药的总价值最大。"

请用**记忆化搜索**方法求解 0-1 背包问题。

**【输入格式】**

第一行有两个整数 T（1 ≤ T ≤ 1000）和 M（1 ≤ M ≤ 100），用一个空格隔开，T 代表总共能够用来采药的时间，M 代表山洞里的草药的数目。

接下来的 M 行每行包括两个在 1 到 100 之间（包括 1 和 100）的整数，分别表示采摘某株草药的时间和这株草药的价值。

**【输出格式】**

输出在规定的时间内可以采到的草药的最大总价值。

**【样例输入】**

```
70 3
71 100
69 1
1 2
```

**【样例输出】**

```
3
```

**【数据范围】**

- 对于 30% 的数据，M ≤ 10；
- 对于全部数据，M ≤ 100，T ≤ 1000。

**【AC代码】**

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
const int MAXT = 1005;

int t[M], v[M];  // 草药的采摘时间和价值
int dp[MAXN][MAXT];
bool vis[MAXN][MAXN];
int n, T;

// 记忆化搜索：从第 idx 个物品开始，剩余时间为 remain 的最大价值
int dfs(int idx, int remain) {
    if (idx > n || remain <= 0) return 0;
    if (vis[idx][remain]) return dp[idx][remain];

    vis[idx][remain] = true;

    // 不选第 idx 个物品
    int ans = dfs(idx + 1, remain);

    // 选第 idx 个物品（如果时间足够）
    if (remain >= t[idx]) {
        ans = max(ans, v[idx] + dfs(idx + 1, remain - t[idx]));
    }

    return dp[idx][remain] = ans;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> T >> n;
    for (int i = 1; i <= n; i++) {
        cin >> t[i] >> v[i];
    }

    // 记忆化搜索实现
    int ans = dfs(1, T);
    cout << ans << '\n';

    return 0;
}
```

**【复杂度分析】**

- 状态总数：O(N × T)，最多 100 × 1000 = 10^5 个状态
- 每个状态的计算：O(1)
- 总复杂度：O(N × T)，在给定数据范围内可在 1ms 内完成

**【记忆化 vs 递推对比】**

对于 0-1 背包，递推（自底向上 DP）也是 O(N × T)，两者效率相近。但记忆化搜索的优势在于：如果很多状态实际不会被访问到（如 T 很大但草药时间分布特殊），记忆化只计算实际需要的状态，可能比递推更快。

## 本课小结

1. **输入输出优化**是 CSP-S 的基本功：`ios::sync_with_stdio(false)` + `cin.tie(nullptr)` 是标配；数据量极大时使用快速读入模板。

2. **位运算优化**利用 CPU 原生指令实现 O(1) 的高效操作。`lowbit`、快速幂、子集枚举是竞赛中的高频技巧。

3. **搜索剪枝**可以将指数级搜索降低到可行范围。三种剪枝策略：
   - **可行性剪枝**：排除不可能到达目标的分支
   - **最优性剪枝**：排除不优于当前最优解的分支
   - **顺序性剪枝**：优化搜索顺序，减少重复状态

4. **记忆化搜索** = 递归 + 缓存，实现简单且只计算需要的状态。适合状态空间稀疏或状态转移拓扑序不明确的问题。

5. **应试策略**：
   - 先写对（正确性优先），再写快（优化在后）
   - 优先使用编译器优化（`-O2`），手动优化仅用于热点代码
   - 位运算记住加括号，`&` `|` `^` 优先级低
   - 搜索题必须剪枝，不剪枝几乎必超时
