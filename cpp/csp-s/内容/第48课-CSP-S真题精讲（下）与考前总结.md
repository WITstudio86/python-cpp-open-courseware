## 📖 知识精讲

### 1. T3/T4 难度定位

| 题号 | 难度 | 常见题型 | 目标分数 | 说明 |
|------|------|----------|----------|------|
| T3 | 中等~较难 | 树形DP、复杂DP、高级数据结构综合 | 60~100 | 有成熟的算法框架可循 |
| T4 | 较难~压轴 | 多算法嵌套、贪心+DP+数据结构 | 30~60 | 争取部分分，不强求AC |

CSP-S 的 T3 和 T4 是区分高分选手的关键。T3 通常有明确的算法方向，只要找到正确的模型就能做出来；T4 则需要较强的综合分析能力。

### 2. T3 题型归纳

| 题型 | 特征 | 典型数据范围 | 对应算法 |
|------|------|-------------|----------|
| 树形DP变式 | 在树上做决策，有约束条件 | n ≤ 10⁵ | 树形DP + 状态设计 |
| 复杂DP | 多维状态，需要优化 | n ≤ 5000 | DP + 前缀和/数据结构优化 |
| 数据结构综合 | 线段树/树状数组/Treap组合 | n,q ≤ 10⁵ | 线段树 + 懒标记 / BIT扩展 |
| 网络流初步 | 二分图匹配、最大流 | n,m ≤ 5000 | Dinic / 匈牙利算法 |
| 图论综合 | 最短路 + 特殊约束 | n,m ≤ 10⁵ | 分层图 / 缩点 + 拓扑 |

**T3 得分策略：**
- 仔细分析子任务：第一个子任务（n ≤ 10~20）通常枚举可过 → 10~20 分
- 第二个子任务可能有特殊性质（如树是一条链、图是DAG等）→ 额外 20~30 分
- 正解需要仔细设计算法，但即使写不出 AC，也要把子任务分拿满
- 注意：T3 的暴力分往往比 T4 的暴力分容易拿

### 3. T4 题型归纳

| 题型 | 特征 | 难度 | 策略 |
|------|------|------|------|
| DP + 数据结构 | DP 转移需要 RMQ / 区间最值 | ⭐⭐⭐⭐ | O(n²) DP 拿 30 分 |
| 贪心 + 图论 | 多约束条件下的路径/选择 | ⭐⭐⭐⭐⭐ | 特殊性质简化 + 部分分 |
| 数学 + DP | 需要数学推导的 DP 优化 | ⭐⭐⭐⭐ | 小数据枚举拿分 |
| 字符串 + DP | 复杂字符串处理 | ⭐⭐⭐⭐ | 暴力匹配 + DP |
| 几何 + 算法 | 计算几何与算法结合 | ⭐⭐⭐⭐⭐ | 很少见，可战略性放弃 |

**T4 得分策略：**
- **不强求 AC！** CSP-S T4 的满分在省选中都是少数
- 目标：拿到 30~60 分的部分分
- 仔细阅读每个子任务的条件，寻找突破口
- 特殊性质往往是简化问题的关键（如：区间之间不包含、图是DAG、k 很小等）
- 如果完全没思路，写一个暴力 O(n²) 或 O(2ⁿ) 也比交白卷强

### 4. 部分分策略详解

CSP-S 每道题通常有 4~6 个子任务（Subtask），每个 Subtask 有独立的数据范围或特殊性质。

**子任务分析步骤：**
1. **通读所有子任务** —— 了解满分需要什么算法
2. **先做最简单的子任务** —— 通常是最小数据范围
3. **逐个攻克特殊性质** —— 特殊性质往往去掉了问题的难点
4. **尝试将特殊性质的解法推广** —— 这可能暗示了正解方向

**典型子任务模式：**

| Subtask | 数据范围 | 分值 | 解法 |
|---------|----------|------|------|
| 1 | n ≤ 10 | 10~15 | 枚举/搜索 |
| 2 | n ≤ 1000 | 20~25 | O(n²) 暴力 |
| 3 | 特殊性质A | 20~25 | 针对性算法 |
| 4 | 特殊性质B | 20~25 | 针对性算法 |
| 5 | n ≤ 10⁵ | 余下 | AC正解 |

## 📝 真题精讲：T3 示例

### 真题 T3：树的最大权值独立集（根必须选）

**题目大意：**
给定一棵 n 个节点的树，节点 i 有权值 w_i。你需要选择一个节点集合 S，满足：
1. S 中任意两个节点没有边直接相连（经典**最大独立集**约束）
2. 根节点（1 号节点）**必须在** S 中（附加约束）

求 S 的总权值的最大值。

**输入格式：**
```
第一行：一个整数 n
第二行：n 个整数 w_1 w_2 ... w_n
接下来 n-1 行：每行两个整数 u, v，表示树上的一条边
```

**输出格式：**
```
一个整数，表示最大总权值
```

**数据范围：**
- Subtask 1（20分）：1 ≤ n ≤ 20，1 ≤ w_i ≤ 100
- Subtask 2（30分）：树是一条链（特殊性质：每个节点的度数 ≤ 2，且恰有两个节点的度数为 1）
- Subtask 3（50分）：1 ≤ n ≤ 10⁵，1 ≤ w_i ≤ 10⁴

**样例输入：**
```
5
10 5 8 3 6
1 2
1 3
1 4
3 5
```

**样例输出：**
```
16
```

**样例解释：**
树结构：
```
     1(10)
   /  |  \
 2(5) 3(8) 4(3)
       |
      5(6)
```
根节点1必须选（+10），则2、3、4都不能选。5与3相邻但3未选，所以5可以选（+6）。
总权值 = 10 + 6 = 16。

**解题思路：**

**Subtask 1（20分，n ≤ 20，O(2ⁿ) 子集枚举）：**
枚举所有 2ⁿ 种选法，检查：
- 根节点（编号1）是否被选
- 任意两个被选节点是否不相邻

对于每种合法选法，计算总权值，取最大值。

**Subtask 2（30分，链状特判，O(n)）：**
当树是一条链时，问题简化为：
- 在序列 w₁, w₂, ..., wₙ 中选择一些不相邻的位置
- 位置 1（根）必须选

使用线性 DP：
```
f[1] = w[1]                     // 位置1必须选
f[2] = w[1]                     // 位置2不能选（与1相邻）
f[i] = max(f[i-1], f[i-2] + w[i])  for i ≥ 3
```
答案 = f[n]。这个 DP 的复杂度为 O(n)。

**需要注意的是，** 在链上，根不一定在端点。如果根在中间位置，需要从两端分别 DP 到根。

**Subtask 3（50分，满分解法，O(n) 树形DP）：**

经典树形DP框架 + 根必选的约束：

**状态设计：**
- `dp[u][0]`：以 u 为根的子树中，**不选** u 时的最大权值
- `dp[u][1]`：以 u 为根的子树中，**选** u 时的最大权值

**状态转移：**
```
dp[u][0] = Σ max(dp[v][0], dp[v][1])  // 不选u，儿子v可选可不选
dp[u][1] = w[u] + Σ dp[v][0]          // 选u，所有儿子v都不能选
```

**根必选的约束：** 答案 = `dp[1][1]`（而不是通常的 `max(dp[1][0], dp[1][1])`）。

**算法流程：**
1. 从根节点（1 号节点）开始 DFS
2. 对每个节点，先递归计算所有子节点的 DP 值
3. 然后根据子节点的 DP 值更新当前节点的 DP 值（后序遍历）
4. 最终答案 = dp[1][1]

**时间复杂度：** O(n)，每个节点和每条边被访问一次。
**空间复杂度：** O(n)，邻接表 + DP 数组。

## 📝 真题精讲：T4 示例

### 真题 T4：加权区间调度

**题目大意：**
给定 n 个区间，第 i 个区间为 [l_i, r_i]，有权值 w_i。你需要选择一些互不重叠的区间（即任意两个被选区间的交集为空），使得总权值最大。

**输入格式：**
```
第一行：一个整数 n
接下来 n 行：每行三个整数 l_i, r_i, w_i
```

**输出格式：**
```
一个整数，表示最大总权值
```

**数据范围：**
- Subtask 1（30分）：1 ≤ n ≤ 1000，1 ≤ l_i < r_i ≤ 10⁴，1 ≤ w_i ≤ 10³
- Subtask 2（30分）：所有区间长度相同（l_i + L = r_i，特殊性质）
- Subtask 3（40分）：1 ≤ n ≤ 2×10⁵，1 ≤ l_i < r_i ≤ 10⁹，1 ≤ w_i ≤ 10⁹

**样例输入：**
```
5
1 3 10
2 5 5
5 7 15
4 8 20
8 10 8
```

**样例输出：**
```
33
```

**样例解释：**
选择区间 [1,3]（权值10）、[5,7]（权值15）、[8,10]（权值8），它们互不重叠（3<5, 7<8），总权值 = 10 + 15 + 8 = 33。注意区间[2,5]与[1,3]在点3处相接（3<2不成立，3=3不严格大于），视为重叠。

**解题思路：**

**Subtask 1（30分，n ≤ 1000，O(n²) DP）：**

将所有区间按右端点 r_i 升序排列。定义 `dp[i]` = 考虑前 i 个区间（按 r 排序后），能获得的最大总权值。

对于第 i 个区间：
- **不选它：** dp[i] = dp[i-1]
- **选它：** 找到所有右端点 < l_i 的区间 j，dp[i] = max(dp[j]) + w_i

暴力实现：
```cpp
for (int i = 0; i < n; i++) {
    dp[i] = w[i];
    for (int j = 0; j < i; j++) {
        if (r[j] < l[i]) {
            dp[i] = max(dp[i], dp[j] + w[i]);
        }
    }
    ans = max(ans, dp[i]);
}
```
时间复杂度 O(n²)，可通过 n ≤ 1000 的测试点。

**Subtask 2（30分，等长区间特判）：**

当所有区间长度相同时（l_i + L = r_i），按左端点排序后，问题简化为选择不相交的等长区间。这等价于在时间轴上贪心选择（每次选最早结束且与已选不重叠的区间中权值最大的），可以做到 O(n log n)。

**Subtask 3（40分，满分解法，O(n log n)）：**

在 O(n²) DP 的基础上优化"找最优 j"的过程：

1. 按 r_i 升序排列所有区间
2. 对于每个区间 i，二分查找最后一个 r_j < l_i 的位置 p
3. dp[i] = max(dp[i-1], dp[p] + w_i)（其中 dp 是前缀最大值）

由于 dp 是单调不降的（考虑更多区间不会使答案变差），可以用 dp[p] 直接代替 max_{j≤p} dp[j]。

**算法步骤：**
1. 按右端点排序：O(n log n)
2. 一次性提取所有右端点数组 R
3. 遍历区间，对每个区间：
   - 二分查找 R 中最后一个 < l_i 的位置：O(log n)
   - O(1) 更新 dp
4. 总复杂度：O(n log n)

**空间优化：** dp 数组只需要 O(n)。

**时间复杂度：** O(n log n)，排序 + n 次二分查找。
**空间复杂度：** O(n)。
