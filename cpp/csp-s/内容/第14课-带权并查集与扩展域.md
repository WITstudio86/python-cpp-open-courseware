## 📖 知识精讲

### 一、种类并查集（扩展域并查集）

**适用场景**：
当元素之间的关系不是简单的"同在一个集合"，而是有**多种类型关系**时。例如：
- 同类 / 异类（朋友 / 敌人）
- 同一物种 / 捕食关系（食物链）
- 同一监狱 / 不同监狱（关押罪犯）

#### 方法一：扩展域（2倍空间法）

对于有 k 种关系的题目，将每个元素 x 拆分为 k 个域：
- `x`：表示"x 属于第 1 类"
- `x + n`：表示"x 属于第 2 类"
- `x + 2n`：表示"x 属于第 3 类"
- ...

**食物链问题（A 吃 B 吃 C 吃 A，3 类关系）**：

将每个动物 x 拆分为 3 个节点：
- `x`：x 属于 A 类
- `x + n`：x 属于 B 类
- `x + 2n`：x 属于 C 类

当确定 x 和 y 具有某种关系时，合并对应的域。

**关键思想**：如果 x 吃 y，意味着：
- 若 x 是 A → y 是 B（合并 x 和 y+n）
- 若 x 是 B → y 是 C（合并 x+n 和 y+2n）
- 若 x 是 C → y 是 A（合并 x+2n 和 y）

当判断两个动物 x 和 y 是否为同类时：
- 若 find(x) == find(y)：同类
- 若 find(x) == find(y+n)：x 吃 y
- 若 find(x+n) == find(y)：y 吃 x

#### 方法二：边带权并查集

另一种更通用的方法是**边带权并查集**。每个节点维护与父节点的关系值 `d[x]`：
- `d[x] = 0`：x 与 parent[x] 同类
- `d[x] = 1`：x 被 parent[x] 吃（或 x 与 parent[x] 是"敌人"关系）

find 操作需要路径压缩时**累加路径上的权值**：

```cpp
int find(int x) {
    if (fa[x] == x) return x;
    int root = find(fa[x]);      // 先递归找到根
    d[x] = (d[x] + d[fa[x]]) % 3; // 更新 x 到根的关系
    return fa[x] = root;
}
```

**注意顺序**：必须先递归 `find(fa[x])`（此时 d[fa[x]] 已经被更新为到根的关系），再计算 d[x]（加上旧的 d[fa[x]]）。

#### 关系推导（以食物链为例，模 3 意义）

设 d[x] 表示 x 与 fa[x] 的关系：0 同类，1 x 吃 fa[x]，2 fa[x] 吃 x。

若已知 d[x]（x→fx）和 d[fx]（fx→root），则：
- d[x → root] = (d[x] + d[fx]) % 3

合并 x 和 y 时，若已知它们的关系为 rel（x 吃 y，即 rel=1 表示 x 吃 y）：
- 需要建立 fx → fy 的关系
- d[fx] = (d[y] - d[x] + rel + 3) % 3

### 二、扩展域 vs 边带权

| 对比维度 | 扩展域（2倍空间） | 边带权 |
|----------|-------------------|--------|
| 空间复杂度 | O(kn) | O(n) |
| 代码复杂度 | 较简单 | 需推导公式 |
| 关系种类 | k 种 | 模 m 意义下的关系 |
| 适用场景 | k 较小（2-3）| 关系在模意义下 |
| 查询效率 | O(α(n)) | O(α(n)) |

**建议**：种类较少（2-3 种）优先用扩展域，种类多或关系复杂优先用带权。

### 三、经典问题：食物链

**问题描述**：
有三种动物 A、B、C，食物链关系为 A 吃 B、B 吃 C、C 吃 A。现在给出 K 句话描述动物间的关系：
- `1 x y`：x 和 y 是同类
- `2 x y`：x 吃 y

判断有多少句话是假话（与之前的话矛盾）。

**扩展域解法**：
```cpp
// 并查集大小：3 * n
DSU dsu(3 * n);

// 判断同类：1 x y
if (dsu.same(x, y + n) || dsu.same(x, y + 2 * n)) {
    假话++;
} else {
    dsu.unite(x, y);
    dsu.unite(x + n, y + n);
    dsu.unite(x + 2 * n, y + 2 * n);
}

// 判断 x 吃 y：2 x y
if (dsu.same(x, y) || dsu.same(x, y + 2 * n)) {
    假话++;  // x 和 y 同类，或 y 吃 x，矛盾
} else {
    dsu.unite(x, y + n);       // x是A → y是B
    dsu.unite(x + n, y + 2 * n); // x是B → y是C
    dsu.unite(x + 2 * n, y);     // x是C → y是A
}
```

## 💻 代码模板

```cpp
// ========== 边带权并查集模板（食物链，模 3 意义） ==========
struct WeightedDSU {
    vector<int> fa, d;  // d[x]: x 与 fa[x] 的关系
    // 0: 同类, 1: x吃fa[x], 2: fa[x]吃x

    WeightedDSU(int n) : fa(n + 1), d(n + 1, 0) {
        for (int i = 1; i <= n; i++) fa[i] = i;
    }

    int find(int x) {
        if (fa[x] == x) return x;
        int root = find(fa[x]);
        d[x] = (d[x] + d[fa[x]]) % 3;
        return fa[x] = root;
    }

    // 合并 x 和 y，关系为 rel（0同类、1表示x吃y）
    // 返回 true 表示成功，false 表示矛盾
    bool unite(int x, int y, int rel) {
        int fx = find(x), fy = find(y);
        if (fx == fy) {
            // 检查关系是否一致
            return (d[x] - d[y] + 3) % 3 == rel;
        }
        fa[fx] = fy;
        // d[fx]: fx 到 fy 的关系
        d[fx] = (d[y] - d[x] + rel + 3) % 3;
        return true;
    }

    // 查询 x 和 y 的关系
    int relation(int x, int y) {
        find(x); find(y);
        return (d[x] - d[y] + 3) % 3;
    }
};
```

## ⚠️ 易错点与优化技巧

1. **find 的递归顺序** —— 必须先 find(fa[x]) 再更新 d[x]，否则 d[fa[x]] 可能不是到根的关系
2. **模运算的负数处理** —— 公式写成 `(a + b) % mod` 和 `(a - b + mod) % mod`
3. **扩展域的空间** —— 需要开 k*n 的大小，注意数组越界
4. **扩展域中矛盾判断** —— 需要检查所有可能的目标域
5. **关系方向** —— 注意 d[x] 的方向（x→fa[x] 还是 fa[x]→x），保持一致
6. **合并时的公式推导** —— 核心是链式传递：x→fx→fy→y 形成闭环
7. **初始化** —— d[x] 初始化为 0（自己到自己是同类）
8. **重复合并** —— same 检查前需要 find 更新 d 值

## 📝 真题精练

### 真题一：[NOI 2001] 食物链

**题目描述**：
动物王国中有三类动物 A、B、C，食物链构成环形：A 吃 B，B 吃 C，C 吃 A。现有 N 个动物，K 句话描述关系（1: 同类，2: X 吃 Y）。请求出假话的总数。假话条件：与前面真话矛盾、X 或 Y 超出范围、自己吃自己。

**数据范围**：N ≤ 5×10⁴，K ≤ 10⁵

**AC 代码**（扩展域法）：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 50005;
int fa[3 * MAXN];

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

void unite(int x, int y) {
    fa[find(x)] = find(y);
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    int n, k, ans = 0;
    cin >> n >> k;
    for (int i = 1; i <= 3 * n; i++) fa[i] = i;

    while (k--) {
        int op, x, y;
        cin >> op >> x >> y;
        if (x > n || y > n) { ans++; continue; }
        if (op == 1) {
            // 同类
            if (find(x) == find(y + n) || find(x) == find(y + 2 * n)) {
                ans++;
            } else {
                unite(x, y);
                unite(x + n, y + n);
                unite(x + 2 * n, y + 2 * n);
            }
        } else {
            // x 吃 y
            if (x == y) { ans++; continue; }
            if (find(x) == find(y) || find(x) == find(y + 2 * n)) {
                ans++;
            } else {
                unite(x, y + n);
                unite(x + n, y + 2 * n);
                unite(x + 2 * n, y);
            }
        }
    }
    cout << ans << '\n';
    return 0;
}
```

**复杂度分析**：O((N+K)·α(N))。

### 真题二：[CSP-S 模拟] 奇偶性判定

**题目描述**：
给定 N 个未知布尔变量，M 个条件形如 `x y parity`：表示 x XOR y = parity（0 或 1）。判断是否存在合法赋值。

**数据范围**：N ≤ 10⁵，M ≤ 2×10⁵

**解题思路**：
使用扩展域（2N 空间）：
- `x`：x = 0
- `x + N`：x = 1

若 x XOR y = 0（相同）：合并 (x, y) 和 (x+N, y+N)
若 x XOR y = 1（不同）：合并 (x, y+N) 和 (x+N, y)

矛盾条件：find(x) == find(x+N)（x 既为 0 又为 1）

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int fa[2 * MAXN];

int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

void unite(int x, int y) {
    fa[find(x)] = find(y);
}

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    int n, m; cin >> n >> m;
    for (int i = 1; i <= 2 * n; i++) fa[i] = i;

    bool ok = true;
    while (m--) {
        int x, y, p;
        cin >> x >> y >> p;
        if (p == 0) {
            // XOR = 0，x 和 y 相同
            if (find(x) == find(y + n)) { ok = false; break; }
            unite(x, y);
            unite(x + n, y + n);
        } else {
            // XOR = 1，x 和 y 不同
            if (find(x) == find(y)) { ok = false; break; }
            unite(x, y + n);
            unite(x + n, y);
        }
    }
    cout << (ok ? "Yes" : "No") << '\n';
    return 0;
}
```

**复杂度分析**：O((N+M)·α(N))。

## 🎯 本课小结

1. **扩展域并查集**：将每个元素拆成 k 份，表示 k 种可能的类型，2-3 种关系时最适用
2. **边带权并查集**：维护 d[x] 表示 x 到父节点的关系权值，find 时累加
3. **关系传递**：链式关系 (x→fx) + (fx→root) = (x→root)，取模运算
4. **食物链问题**：3 类环形关系，扩展域 / 带权（模 3）两种方法均可
5. **注意 find 顺序**：先递归再更新 d[x]
