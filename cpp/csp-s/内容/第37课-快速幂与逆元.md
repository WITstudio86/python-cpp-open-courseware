## 一、快速幂算法（Binary Exponentiation）

### 1.1 问题引入

计算 $a^b \bmod m$，其中 $a, b, m$ 可能非常大（如 $b \le 10^{18}$）。如果直接循环乘 $b$ 次，时间复杂度 $O(b)$，显然不可行。

**核心思想：二分幂（Divide and Conquer）**

### 1.2 数学原理

利用指数的二进制拆分：

$$a^b = \begin{cases} 
a^{b/2} \cdot a^{b/2} & b \text{ 为偶数} \\
a \cdot a^{b/2} \cdot a^{b/2} & b \text{ 为奇数}
\end{cases}$$

- 每次将指数 $b$ 折半，递归深度 $O(\log b)$。
- 时间复杂度：$O(\log b)$。

**另一种视角（二进制拆分）：**
将 $b$ 写成二进制：$b = \sum b_i \cdot 2^i$，其中 $b_i \in \{0, 1\}$，则：

$$a^b = \prod_{b_i = 1} a^{2^i}$$

即：从低位到高位遍历 $b$ 的每一位，若该位是 1 则乘上当前的幂。

### 1.3 递归写法

```cpp
// 递归快速幂：计算 a^b mod MOD
long long fastPow(long long a, long long b, long long MOD) {
    if (b == 0) return 1;
    long long half = fastPow(a, b / 2, MOD);
    half = half * half % MOD;
    if (b % 2 == 1)
        half = half * a % MOD;
    return half;
}
```

### 1.4 迭代写法（更常用，避免递归栈溢出）

```cpp
// 迭代快速幂（二进制拆分法）
long long fastPow(long long a, long long b, long long MOD) {
    long long result = 1;
    a = a % MOD;               // 先取模，防止溢出
    while (b > 0) {
        if (b & 1)             // 当前二进制位为 1
            result = result * a % MOD;
        a = a * a % MOD;       // a → a^2 → a^4 → a^8 ...
        b >>= 1;               // 右移一位
    }
    return result;
}
```

**形象理解：**  
比如 $b = 13 = (1101)_2 = 8 + 4 + 1$，则 $a^{13} = a^8 \cdot a^4 \cdot a^1$。

## 二、模运算基本性质

### 2.1 基本运算性质

设 $\text{mod}$ 为模数 $m$，则：

| 运算 | 性质 | 说明 |
|------|------|------|
| 加法 | $(a + b) \bmod m = ((a \bmod m) + (b \bmod m)) \bmod m$ | 可随时取模 |
| 减法 | $(a - b) \bmod m = ((a \bmod m) - (b \bmod m) + m) \bmod m$ | 注意防负 |
| 乘法 | $(a \cdot b) \bmod m = ((a \bmod m) \cdot (b \bmod m)) \bmod m$ | 可随时取模 |
| 除法 | **没有直接公式！** 不能简单地分子分母分别取模 | 需要乘法逆元 |

### 2.2 为什么除法不能直接取模？

反例：$6 \div 2 = 3$，模 $5$：
- $6 \bmod 5 = 1$，$2 \bmod 5 = 2$
- 若直接计算 $1 \div 2 \bmod 5$，无法得到 $3$（$2 \times 3 = 6 \equiv 1 \pmod{5}$，所以 $3$ 是 $2$ 在模 $5$ 下的逆元）

**解决方式：** 除以 $a$ 等价于乘以 $a$ 在模 $m$ 下的乘法逆元。

## 三、乘法逆元（Modular Multiplicative Inverse）

### 3.1 定义

若 $a$ 与 $m$ 互质（$\gcd(a, m) = 1$），则存在唯一的 $x$（$1 \le x < m$），使得：

$$a \cdot x \equiv 1 \pmod{m}$$

称 $x$ 为 $a$ 在模 $m$ 下的**乘法逆元**，记作 $a^{-1}$ 或 $\text{inv}(a)$。

**用途：** 在模意义下计算 "除法"：
$$\frac{b}{a} \bmod m = b \cdot a^{-1} \bmod m$$

### 3.2 逆元存在的条件

当且仅当 $\gcd(a, m) = 1$ 时，$a$ 在模 $m$ 下有逆元。**特别地**，当 $m$ 为质数时，只要 $a$ 不是 $m$ 的倍数，逆元就存在。

## 四、费马小定理求逆元

### 4.1 费马小定理

若 $p$ 是质数且 $a$ 不是 $p$ 的倍数，则：

$$a^{p-1} \equiv 1 \pmod{p}$$

### 4.2 推导逆元公式

由 $a^{p-1} \equiv 1 \pmod{p}$，两边同乘 $a^{-1}$（概念上）或同除以 $a$：

$$a \cdot a^{p-2} \equiv 1 \pmod{p}$$

故：

$$a^{-1} \equiv a^{p-2} \pmod{p}$$

使用快速幂在 $O(\log p)$ 时间内求出。

```cpp
// 费马小定理求逆元（m 必须是质数）
long long invFermat(long long a, long long MOD) {
    return fastPow(a, MOD - 2, MOD);
}
```

### 4.3 适用条件

- $m$ **必须是质数**
- 常见质数模数：$10^9 + 7$、$998244353$ 等

## 五、扩展欧几里得算法求逆元

### 5.1 贝祖定理

对于任意整数 $a, b$，存在整数 $x, y$，使得：

$$ax + by = \gcd(a, b)$$

### 5.2 求解逆元

当 $\gcd(a, m) = 1$ 时，解方程 $ax + my = 1$，则：

$$ax \equiv 1 \pmod{m}$$

故 $x$（取正余数后）即为 $a$ 的逆元。使用扩展欧几里得算法 $O(\log \min(a, m))$。

### 5.3 代码实现

```cpp
// 扩展欧几里得算法，求 ax + by = gcd(a, b) 的一组解
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) {
        x = 1, y = 0;
        return a;
    }
    long long d = exgcd(b, a % b, y, x);
    y -= a / b * x;
    return d;
}

// 扩展欧几里得求逆元（m 不一定是质数，只要求 gcd(a, m) = 1）
long long invExgcd(long long a, long long MOD) {
    long long x, y;
    long long d = exgcd(a, MOD, x, y);
    // 若 d != 1，说明逆元不存在（a 和 MOD 不互质）
    if (d != 1) return -1;  
    return (x % MOD + MOD) % MOD; // 确保返回非负
}
```

### 5.4 适用条件

- 仅要求 $\gcd(a, m) = 1$，$m$ 不一定是质数
- 比费马小定理更通用

## 六、组合数取模

### 6.1 问题描述

计算 $C(n, k) = \dfrac{n!}{k! \cdot (n-k)!} \bmod p$（$p$ 为质数）。

由于除法不能直接取模，需要用到乘法逆元。

### 6.2 思路

预计算：
1. $\text{fact}[i] = i! \bmod p$
2. $\text{invFact}[i] = (i!)^{-1} \bmod p$（阶乘的逆元）

则：

$$C(n, k) = \text{fact}[n] \cdot \text{invFact}[k] \cdot \text{invFact}[n-k] \bmod p$$

**关键优化：** $\text{invFact}[i]$ 可以通过递推求出：
$$\text{invFact}[i] = \text{invFact}[i+1] \cdot (i+1) \bmod p$$

先求出 $\text{invFact}[n]$，然后倒推。

### 6.3 完整代码

```cpp
const int MAXN = 1000005;
long long fact[MAXN], invFact[MAXN];

// 预处理阶乘和阶乘逆元
void precompute(int n, long long MOD) {
    fact[0] = 1;
    for (int i = 1; i <= n; i++)
        fact[i] = fact[i-1] * i % MOD;
    
    // 用费马小定理求 n! 的逆元
    invFact[n] = fastPow(fact[n], MOD - 2, MOD);
    
    // 倒推：invFact[i-1] = invFact[i] * i % MOD
    for (int i = n; i >= 1; i--)
        invFact[i-1] = invFact[i] * i % MOD;
}

// 组合数 C(n, k) mod MOD
long long C(int n, int k, long long MOD) {
    if (k < 0 || k > n) return 0;
    return fact[n] * invFact[k] % MOD * invFact[n-k] % MOD;
}
```

## 七、线性求逆元

### 7.1 问题描述

在 $O(n)$ 时间内求出 $1, 2, \dots, n$ 每个数在模质数 $p$ 下的逆元。

### 7.2 递推公式

当 $p$ 为质数时，有递推公式：

$$\text{inv}[i] = p - \left\lfloor \frac{p}{i} \right\rfloor \cdot \text{inv}[p \bmod i] \bmod p$$

或等价写成：

$$\text{inv}[i] = (p - p / i) \cdot \text{inv}[p \bmod i] \bmod p$$

### 7.3 推导（简略）

令 $p = k \cdot i + r$（$k = \lfloor p/i \rfloor$，$r = p \bmod i$），$0 < r < i$。在模 $p$ 下：
$$k \cdot i + r \equiv 0 \pmod{p}$$
$$r \equiv -k \cdot i \pmod{p}$$
两边乘 $r^{-1} \cdot i^{-1}$：
$$i^{-1} \equiv -k \cdot r^{-1} \pmod{p}$$
即 $\text{inv}[i] = (p - p/i) \cdot \text{inv}[p \bmod i] \bmod p$。

### 7.4 代码

```cpp
// O(n) 线性求 1..n 所有数的逆元（MOD 为质数）
void linearInv(int n, long long MOD, long long inv[]) {
    inv[1] = 1;
    for (int i = 2; i <= n; i++) {
        inv[i] = (MOD - MOD / i) * inv[MOD % i] % MOD;
    }
}
```

## 九、真题精练

### 例题1：快速幂模板题

**题目：** 给定三个整数 $a, b, p$，求 $a^b \bmod p$。（$1 \le a, b \le 10^{18}$，$1 \le p \le 10^9$）

**输入格式：** 一行三个整数 $a, b, p$。

**输出格式：** 一个整数 $a^b \bmod p$。

**示例输入：**
```
2 10 1000
```
**示例输出：**
```
24
```

**参考解法：** 直接使用迭代快速幂模板，注意 $a$ 先对 $p$ 取模。

---

### 例题2：组合数取模

**题目：** 给定 $n, k$，求 $C(n, k) \bmod 1000000007$。（$1 \le k \le n \le 10^6$）

**输入格式：** 一行两个整数 $n, k$。

**输出格式：** 一个整数 $C(n, k) \bmod 1000000007$。

**示例输入：**
```
5 2
```
**示例输出：**
```
10
```

**参考解法：** 预处理阶乘和阶乘逆元，$O(1)$ 查询。注意 $n$ 最大 $10^6$，数组开够。
