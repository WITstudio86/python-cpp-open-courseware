## 📖 知识精讲

### 一、哈希函数设计原理

字符串哈希的核心思想是：**将字符串映射为一个整数，使得相同的字符串映射到相同的整数，不同的字符串以极大概率映射到不同的整数**。

#### BKDR Hash

BKDR（Brian Kernighan 与 Dennis Ritchie）哈希是目前竞赛中最常用的字符串哈希方案。其构造方式为：

将字符串 s 视为一个 base 进制数，逐字符计算：

```
hash(s) = (s[0] × base^{n-1} + s[1] × base^{n-2} + ... + s[n-1]) mod M
```

**seed（base）选择**：
- 常用质数：**131** 或 **13331**
- 这两个质数经过大量实践验证，冲突概率极低
- base 必须大于字符集大小（ASCII 最大 127，一般取 >127 的质数即可）

**模数选择**：

| 方案 | 模数 | 优点 | 缺点 |
|------|------|------|------|
| 自然溢出 | 2^64 | 代码极简，速度最快 | 卡哈希风险较高 |
| 单大质数 | 1e9+7 或 1e9+9 | 速度较快，冲突概率低 | 仍有极小冲突可能 |
| 双哈希 | 1e9+7 + 1e9+9 | 冲突概率极低 | 常数较大，代码稍长 |

#### 代码实现

```cpp
// 自然溢出（unsigned long long 自动对 2^64 取模）
typedef unsigned long long ull;
const ull base = 131;

ull hash_str(const string& s) {
    ull h = 0;
    for (char c : s) {
        h = h * base + c;
    }
    return h;
}
```

### 二、自然溢出（unsigned long long）的优缺点

**自然溢出原理**：C++ 中 `unsigned long long` 为 64 位无符号整数，运算溢出时自动对 2^64 取模，等价于模数为 2^64。

**优点**：
- 代码最简洁，无需取模操作
- 速度最快（无 % 运算）
- 2^64 到 unsigned long long 的溢出是标准行为

**缺点**：
- 2^64 不是质数（有因子 2），可用特殊构造的字符串制造冲突（卡哈希）
- CF / AtCoder 等平台上有 anti-hash test 的传统
- 对于某些出题人会特意构造卡自然溢出的数据

**卡哈希的常见手段**：
- 构造大量字符串使得 hash 值碰撞（利用 2^64 的因数）
- 使用生日悖论：2^64 的冲突需要约 2^32 次尝试

**应对策略**：
1. 使用双哈希（最稳妥）
2. 使用随机化的 base（如在 [129, 1e9] 之间随机选取）
3. 使用大质数模数（如 1e9+7、1e9+9、998244353）

### 三、双哈希防冲突原理

双哈希的核心思想是：**用两个互质的模数分别计算哈希值，只有两个哈希值都相等时才认为字符串相等**。

两个字符串碰撞的概率约为 1/(M1 × M2)，当 M1、M2 都约为 1e9 时，冲突概率约为 1e-18，在竞赛中几乎不可能发生。

```cpp
// 双哈希结构
const int M1 = 1e9 + 7, M2 = 1e9 + 9;
const int base = 131;

struct DoubleHash {
    long long h1, h2;
    DoubleHash() : h1(0), h2(0) {}
    DoubleHash(long long a, long long b) : h1(a), h2(b) {}
    bool operator==(const DoubleHash& o) const {
        return h1 == o.h1 && h2 == o.h2;
    }
};
```

### 四、子串哈希 O(1) 公式推导

预处理出前缀哈希数组 h[0..n] 和 base 的幂次数组 p[0..n]：

```
h[0] = 0
h[i] = (h[i-1] × base + s[i-1]) % M    // i 从 1 到 n

p[0] = 1
p[i] = (p[i-1] × base) % M
```

那么子串 s[l..r]（下标从 0 开始）的哈希值为：

```
hash(l, r) = (h[r+1] - h[l] × p[r-l+1] % M + M) % M
```

**公式推导**：

```
已知：
  h[r+1] = s[0]·base^r + s[1]·base^{r-1} + ... + s[l-1]·base^{r-l+1} + s[l]·base^{r-l} + ... + s[r]
  h[l]   = s[0]·base^{l-1} + s[1]·base^{l-2} + ... + s[l-1]

对齐后相减：
  h[l] × base^{r-l+1} = s[0]·base^r + s[1]·base^{r-1} + ... + s[l-1]·base^{r-l+1}

所以：
  h[r+1] - h[l] × base^{r-l+1} = s[l]·base^{r-l} + s[l+1]·base^{r-l-1} + ... + s[r]
  = hash(s[l..r])
```

**核心代码**：

```cpp
// 预处理前缀哈希和幂次
void init_hash(const string& s) {
    n = s.size();
    h[0] = 0;
    for (int i = 0; i < n; i++) {
        h[i + 1] = (h[i] * base + s[i]) % MOD;
    }
    p[0] = 1;
    for (int i = 1; i <= n; i++) {
        p[i] = (p[i - 1] * base) % MOD;
    }
}

// 获取子串 s[l..r] 的哈希值（l, r 为 0-based）
long long get_hash(int l, int r) {
    long long res = (h[r + 1] - h[l] * p[r - l + 1] % MOD + MOD) % MOD;
    return res;
}
```

### 五、二分 + 哈希求最长公共前缀（LCP）

给定两个字符串 s 和 t（或同一字符串的两个子串），求它们的最长公共前缀长度，可以在 O(log n) 时间内完成：

```cpp
// 求 s 中从位置 a 和 b 开始的最长公共前缀长度
int lcp(const string& s, int a, int b) {
    int lo = 0, hi = min(n - a, n - b);
    while (lo < hi) {
        int mid = (lo + hi + 1) / 2;
        if (get_hash(a, a + mid - 1) == get_hash(b, b + mid - 1))
            lo = mid;
        else
            hi = mid - 1;
    }
    return lo;
}
```

**应用**：判断回文、比较子串字典序、后缀排序等。

### 六、字符串哈希 + unordered_map 去重

当需要快速判断一个字符串是否出现过（或在大量字符串中快速查找）时，可以结合哈希与哈希表：

```cpp
unordered_set<ull> seen;
int distinct = 0;
for (int i = 0; i < N; i++) {
    string s; cin >> s;
    ull h = compute_hash(s);
    if (seen.find(h) == seen.end()) {
        seen.insert(h);
        distinct++;
    }
}
```

**注意**：如果使用单哈希，建议加上双哈希或使用大质数模数来避免被卡。

## 💻 代码模板

```cpp
// ==================== 单哈希（自然溢出） ====================
typedef unsigned long long ull;
const ull BASE = 131;

struct StringHash {
    int n;
    vector<ull> h, p;

    StringHash(const string& s) {
        n = s.size();
        h.resize(n + 1, 0);
        p.resize(n + 1, 1);
        for (int i = 0; i < n; i++) {
            h[i + 1] = h[i] * BASE + s[i];
            p[i + 1] = p[i] * BASE;
        }
    }

    // 获取子串 [l, r] 的哈希值，0-based，闭区间
    ull get(int l, int r) {
        return h[r + 1] - h[l] * p[r - l + 1];
    }
};

// ==================== 双哈希（大质数取模） ====================
const int MOD1 = 1e9 + 7, MOD2 = 1e9 + 9;
const int BASE = 131;

struct DoubleHash {
    int n;
    vector<long long> h1, h2, p1, p2;

    DoubleHash(const string& s) {
        n = s.size();
        h1.resize(n + 1, 0); h2.resize(n + 1, 0);
        p1.resize(n + 1, 1); p2.resize(n + 1, 1);
        for (int i = 0; i < n; i++) {
            h1[i + 1] = (h1[i] * BASE + s[i]) % MOD1;
            h2[i + 1] = (h2[i] * BASE + s[i]) % MOD2;
            p1[i + 1] = (p1[i] * BASE) % MOD1;
            p2[i + 1] = (p2[i] * BASE) % MOD2;
        }
    }

    // 返回哈希值对 (h1, h2)
    pair<long long, long long> get(int l, int r) {
        long long v1 = (h1[r + 1] - h1[l] * p1[r - l + 1] % MOD1 + MOD1) % MOD1;
        long long v2 = (h2[r + 1] - h2[l] * p2[r - l + 1] % MOD2 + MOD2) % MOD2;
        return {v1, v2};
    }
};
```

## ⚠️ 易错点与优化技巧

1. **模数选择不当导致冲突**：
   - 不要用 1e9+7 同时只做单哈希——虽然冲突少，但在 CF 等平台上已被广泛卡
   - 自然溢出（2^64）不是质数，容易被构造数据卡掉
   - **最稳妥方案**：双哈希，MOD1 = 1e9+7，MOD2 = 1e9+9；或者MOD1 = 1e9+7，MOD2 = 998244353

2. **前缀 hash 数组下标从 1 开始**：
   - h[0] = 0，h[1] 对应 s[0] 的前缀哈希
   - 子串哈希公式中，子串的右端点索引需要注意 +1

3. **二分边界处理**：
   - LCP 二分时，lo 的初值为 0，hi 为可能的最大长度
   - 注意二分条件是 `(lo + hi + 1) / 2`，取上取整避免死循环

4. **自然溢出被卡哈希的应对**：
   - 随机化 base（不使用固定的 131）：
     ```cpp
     mt19937 rng(chrono::steady_clock::now().time_since_epoch().count());
     const ull BASE = uniform_int_distribution<ull>(257, 1e9)(rng);
     ```
   - 使用双哈希
   - 使用大质数模数

5. **负数取模问题**：子串哈希公式中 `(h[r+1] - h[l] * p[r-l+1]) % MOD` 可能为负数，需要 `+ MOD` 后再取模。

6. **unordered_map 的自定义哈希**：使用 `pair<long long, long long>` 作为 key 时，需要自定义哈希函数或使用 `map`。

## 📝 真题精练

### 真题一：字符串去重

**题目描述**：
给定 N 个字符串，问其中有多少个不同的字符串。

**数据范围**：
- 1 ≤ N ≤ 10000
- 字符串总长度 ≤ 10^6

**解题思路**：
对每个字符串计算双哈希值，将 `pair<hash1, hash2>` 存入 `set` 或 `unordered_set`，最终集合大小即为答案。

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD1 = 1e9 + 7, MOD2 = 1e9 + 9;
const int BASE = 131;

pair<long long, long long> calc_hash(const string& s) {
    long long h1 = 0, h2 = 0;
    for (char c : s) {
        h1 = (h1 * BASE + c) % MOD1;
        h2 = (h2 * BASE + c) % MOD2;
    }
    return {h1, h2};
}

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int N; cin >> N;
    set<pair<long long, long long>> st;
    for (int i = 0; i < N; i++) {
        string s; cin >> s;
        st.insert(calc_hash(s));
    }
    cout << st.size() << '\n';
    return 0;
}
```

**复杂度分析**：时间 O(N × L)，空间 O(N)，其中 L 为字符串平均长度。

### 真题二：最长回文子串（二分 + 哈希）

**题目描述**：
给定一个字符串 s，求其最长回文子串的长度。

**数据范围**：
- 1 ≤ |s| ≤ 10^5

**解题思路**：
预处理正串哈希和反串哈希。枚举回文中心 i，二分回文半径 len，判断 s[i-len..i+len] 是否为回文（正串哈希 == 反串哈希）。

- 奇数长度回文：中心为 i，二分半径
- 偶数长度回文：中心为 i 和 i+1 之间，二分半径

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef unsigned long long ull;
const ull BASE = 131;

struct Hash {
    vector<ull> h, p;
    int n;
    Hash(const string& s) {
        n = s.size();
        h.resize(n + 1, 0);
        p.resize(n + 1, 1);
        for (int i = 0; i < n; i++) {
            h[i + 1] = h[i] * BASE + s[i];
            p[i + 1] = p[i] * BASE;
        }
    }
    ull get(int l, int r) {
        return h[r + 1] - h[l] * p[r - l + 1];
    }
};

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    string s; cin >> s;
    int n = s.size();

    Hash h1(s);                            // 正串哈希
    string rev_s = s;
    reverse(rev_s.begin(), rev_s.end());
    Hash h2(rev_s);                        // 反串哈希

    int ans = 1;

    // 奇数长度回文
    for (int i = 0; i < n; i++) {
        int lo = 0, hi = min(i, n - 1 - i);
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            // 正串 s[i-mid..i+mid] 与反串对应位置比较
            if (h1.get(i - mid, i + mid) == h2.get(n - 1 - (i + mid), n - 1 - (i - mid)))
                lo = mid;
            else
                hi = mid - 1;
        }
        ans = max(ans, 2 * lo + 1);
    }

    // 偶数长度回文
    for (int i = 0; i < n - 1; i++) {
        int lo = 0, hi = min(i + 1, n - 1 - i);
        while (lo < hi) {
            int mid = (lo + hi + 1) / 2;
            if (h1.get(i - mid + 1, i + mid) == h2.get(n - 1 - (i + mid), n - 1 - (i - mid + 1)))
                lo = mid;
            else
                hi = mid - 1;
        }
        if (lo > 0) ans = max(ans, 2 * lo);
    }

    cout << ans << '\n';
    return 0;
}
```

**复杂度分析**：时间 O(n log n)，空间 O(n)。预处理哈希 O(n)，每个中心二分 O(log n)，共 O(n log n)。

## 🎯 本课小结

1. **哈希函数设计**：BKDR hash，seed 取 131 或 13331，模数可选自然溢出或大质数
2. **子串哈希 O(1)**：预处理前缀哈希和幂次，利用公式 `hash[l,r] = h[r+1] - h[l] × p[r-l+1]` 实现
3. **双哈希防冲突**：两个不同模数同时计算，冲突概率极低，是竞赛中最稳妥的方案
4. **二分 + 哈希**：可在 O(log n) 内求 LCP，进而解决回文判断、子串比较等问题
5. **实践建议**：CSP-S 中优先使用双哈希（1e9+7 + 1e9+9），确保不会被卡；若时间紧迫可用自然溢出但注意随机化 base
