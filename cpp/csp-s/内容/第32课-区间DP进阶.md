### 1. 环形区间DP的处理技巧 —— 破环成链 ×2

#### 问题引入
在第31课中，我们学习了直线版石子合并。但现实中很多问题是**环形**的：石子排成一个**圈**，首尾相邻。

#### 核心技巧：破环成链 ×2
将长度为 $n$ 的环展开为长度为 $2n$ 的链：

1. 将原始序列 $a[0..n-1]$ **复制一份**接在尾部
2. 得到长度为 $2n$ 的新序列 $b[0..2n-1]$，其中 $b[i] = a[i \bmod n]$
3. 在 $b$ 上做普通的线性区间DP
4. 最终答案取自所有长度为 $n$ 的区间：$\max/\min\{dp[i][i+n-1] \mid i = 0, 1, \dots, n-1\}$

#### 为什么这样做是正确的？
因为环形石子合并的任意一种合并方案，总可以找到一个「断开点」，将环断开为一条链。在长度为 $2n$ 的序列上枚举所有可能的断开位置（即枚举 $i$ 从 $0$ 到 $n-1$，取长度为 $n$ 的区间），就等价于枚举了环上所有可能的合并方式。

#### 图解
```
原始环形:  [4] - [5] - [9] - [4] - (回到4)
破环成链:  [4] [5] [9] [4] [4] [5] [9] [4]  (长度 2n = 8)
                         |------n=4------|
               |------n=4------|
          |------n=4------|
```

#### 代码框架
```cpp
// 环形石子合并
int n; cin >> n;
vector<int> a(2 * n);
for (int i = 0; i < n; ++i) {
    cin >> a[i];
    a[i + n] = a[i];  // 复制一份
}

// 在 a[0..2n-1] 上做区间DP
// 最终答案：max/min{dp[i][i+n-1]}, i = 0..n-1
```

### 2. 能量项链问题（NOIP2006 提高组）

#### 问题描述
在 Mars 星球上，每个 Mars 人都随身佩带着一串能量项链。项链上有 $N$ 颗能量珠。能量珠是一颗有**头标记**与**尾标记**的珠子，这些标记对应着某个正整数。对于相邻的两颗珠子，前一颗珠子的尾标记等于后一颗珠子的头标记。

因为只有这样，通过吸盘的作用，这两颗珠子才能聚合成一颗珠子，同时释放出可以被吸盘吸收的能量。如果前一颗能量珠的头标记为 $m$，尾标记为 $r$，后一颗能量珠的头标记为 $r$，尾标记为 $n$，则聚合后释放的能量为 $m \times r \times n$，新产生的珠子的头标记为 $m$，尾标记为 $n$。

需要时，Mars 人就用吸盘夹住相邻的两颗珠子，通过聚合得到能量，直到项链上只剩下一颗珠子为止。显然，不同的聚合顺序得到的总能量是不同的。请你设计一个聚合顺序，使一串项链释放出的总能量最大。

#### 状态定义
设珠子编号为 $1, 2, \dots, n$，第 $i$ 颗珠子的头标记为 $head[i]$，尾标记为 $head[i+1]$（环形：$head[n+1] = head[1]$）。

定义 $dp[l][r]$ 表示将第 $l$ 颗珠子到第 $r$ 颗珠子合并成一颗珠子的**最大能量**。

#### 状态转移
$$dp[l][r] = \max_{k=l}^{r-1}\{dp[l][k] + dp[k][r] + head[l] \times head[k+1] \times head[r+1]\}$$

**注意**：这里的转移与普通石子合并不同——
- 合并 $dp[l][k]$ 和 $dp[k][r]$（注意不是 $dp[k+1][r]$）
- 这是因为能量珠的合并涉及到的是「边界」，而不是「分割点」

#### 环形处理
将 $head$ 数组扩展为 $2n$ 长度，在长度为 $2n$ 的链上DP，最终答案取 $\max\{dp[i][i+n-1] \mid i = 1, 2, \dots, n\}$。

#### 复杂度分析
- **时间复杂度**：$O(n^3)$
- **空间复杂度**：$O(n^2)$

### 3. 区间DP的两种类型

区间DP问题可以分为两大类：

#### a) 合并型（Merge Type）
**特征**：将两个相邻的小区间**合并**为一个大的区间。

**典型问题**：
- 石子合并：$dp[l][r] = \min(dp[l][k] + dp[k+1][r]) + sum(l, r)$
- 能量项链：$dp[l][r] = \max(dp[l][k] + dp[k][r]) + head[l] \times head[k] \times head[r]$
- 矩阵链乘法：$dp[l][r] = \min(dp[l][k] + dp[k+1][r]) + p[l-1] \times p[k] \times p[r]$

**转移特征**：$dp[l][r]$ 由 $dp[l][k]$ 和 $dp[k][r]/dp[k+1][r]$ 转移而来。

#### b) 消去型（Elimination Type）
**特征**：消去区间中的某一段，消去后两边的部分变得相邻。

**典型问题**：
- 祖玛（Zuma）：消去连续相同颜色的球
- 移除盒子（Remove Boxes）：消去相同数字的盒子
- 括号匹配删除：删除匹配的括号对

**转移特征**：需要考虑消去后两侧的合并，可能需要**额外的维度**记录状态（如颜色、连续数量等）。

### 4. 消去型区间DP示例：移除盒子问题

#### 问题描述
给出一些不同颜色的盒子，盒子的颜色由数字表示。你可以移除具有**相同颜色**的**连续的** $k$ 个盒子，得到 $k \times k$ 分。求最大总得分。

#### 状态定义
$dp[l][r][k]$ 表示区间 $[l, r]$ 加上右侧 $k$ 个与 $a[r]$ 颜色相同的盒子，能获得的最大得分。

#### 状态转移
1. 直接将右侧的 $(k+1)$ 个同色盒子一起消去：
   $dp[l][r][k] = dp[l][r-1][0] + (k+1)^2$
2. 在区间内找一个与 $a[r]$ 同色的位置 $i$，先消去 $(i+1, r-1)$：
   $dp[l][r][k] = \max(dp[l][i][k+1] + dp[i+1][r-1][0])$

### 5. 区间DP的空间优化与常数优化

#### a) 四边形不等式优化（Decision Monotonicity）
对于满足四边形不等式的合并型区间DP，可以记录最优分割点 $s[l][r]$：
$$s[l][r-1] \leq s[l][r] \leq s[l+1][r]$$

将原本的 $O(n^3)$ 优化到 $O(n^2)$。

**适用条件**：
- 代价函数 $w(l, r)$ 满足四边形不等式
- 代价函数 $w(l, r)$ 满足区间包含单调性

#### b) 滚动数组
由于 $dp[l][r]$ 只依赖于长度小于当前区间的子问题，可以按长度分层，使用滚动数组：
- 只用 $dp[l]$ 记录以 $l$ 为左端点、当前长度的最优值
- 但这会丢失分割点枚举时需要的中间结果，实际很少使用

#### c) 常数优化
- 使用 `int` 而非 `long long`（在不溢出的前提下）
- 使用 `0x3f3f3f3f` 作为 INF（两个相加不溢出）
- `memset(dp, 0x3f, sizeof(dp))` 比循环赋值更快

## 三、代码模板

### 环形石子合并模板

```cpp
int solve_circular_stones(vector<int>& a, bool is_min) {
    int n = a.size();
    vector<int> b(2 * n);
    for (int i = 0; i < n; ++i) b[i] = b[i + n] = a[i];
    
    vector<int> pre(2 * n + 1, 0);
    for (int i = 1; i <= 2 * n; ++i) pre[i] = pre[i-1] + b[i-1];
    auto sum = [&](int l, int r) { return pre[r+1] - pre[l]; };
    
    vector<vector<int>> dp(2 * n, vector<int>(2 * n, is_min ? INF : 0));
    for (int i = 0; i < 2 * n; ++i) dp[i][i] = 0;
    
    for (int len = 2; len <= n; ++len) {
        for (int l = 0; l + len - 1 < 2 * n; ++l) {
            int r = l + len - 1;
            for (int k = l; k < r; ++k) {
                int val = dp[l][k] + dp[k+1][r] + sum(l, r);
                if (is_min) dp[l][r] = min(dp[l][r], val);
                else dp[l][r] = max(dp[l][r], val);
            }
        }
    }
    
    int ans = is_min ? INF : 0;
    for (int i = 0; i < n; ++i) {
        if (is_min) ans = min(ans, dp[i][i + n - 1]);
        else ans = max(ans, dp[i][i + n - 1]);
    }
    return ans;
}
```

### 能量项链模板

```cpp
int energy_necklace(vector<int>& head, int n) {
    vector<int> h(2 * n + 1);
    for (int i = 1; i <= n; ++i) h[i] = h[i + n] = head[i];
    
    vector<vector<int>> dp(2 * n + 1, vector<int>(2 * n + 1, 0));
    
    for (int len = 2; len <= n; ++len) {
        for (int l = 1; l + len - 1 <= 2 * n; ++l) {
            int r = l + len - 1;
            for (int k = l; k < r; ++k) {
                dp[l][r] = max(dp[l][r],
                    dp[l][k] + dp[k+1][r] + h[l] * h[k+1] * h[r+1]);
            }
        }
    }
    
    int ans = 0;
    for (int i = 1; i <= n; ++i) ans = max(ans, dp[i][i + n - 1]);
    return ans;
}
```

## 四、易错点与优化技巧

### 易错点

1. **环形数组的索引**：破环成链后数组长度为 $2n$，注意DP时的索引范围
2. **答案取值**：环形问题的答案不是 $dp[0][n-1]$，而是 $\max/\min\{dp[i][i+n-1]\}$ 对所有 $i=0 \dots n-1$
3. **能量项链的转移**：是 $dp[l][k] + dp[k][r]$，而不是 $dp[l][k] + dp[k+1][r]$（因为珠子合并后首尾标记变化）
4. **前缀和在环形下的使用**：前缀和数组长度应为 $2n+1$，且 `sum(l, r)` 公式不变

### 优化技巧

1. **四边形不等式**：记录 $s[l][r]$，缩小 $k$ 的枚举范围
2. **破环成链时只DP长度为 $n$ 的区间**：$len$ 最多枚举到 $n$ 即可
3. **最小值初始化为 INF，最大值初始化为 0**
4. **环形问题的答案遍历**：对所有 $i$ 取最优值

在一个圆形操场的四周摆放 $N$ 堆石子，现要将石子有次序地合并成一堆。规定每次只能选相邻的2堆合并成新的一堆，并将新的一堆的石子数记为该次合并的得分。试设计出1个算法，计算出将 $N$ 堆石子合并成1堆的最小得分和最大得分。

**输入格式**：
第一行一个整数 $N$（$1 \leq N \leq 100$）。
第二行 $N$ 个整数，表示每堆石子的数量。

**输出格式**：
两个整数，分别表示最小得分和最大得分。

**样例输入**：
```
4
4 5 9 4
```
**样例输出**：
```
43 54
```

## 六、本课小结

1. **环形区间DP**的核心技巧是**破环成链 ×2**：将原序列复制一份，在 $2n$ 的链上DP，最终答案遍历所有长度为 $n$ 的区间
2. **能量项链**是经典的环形合并型区间DP，转移时注意索引的对应关系
3. 区间DP分为**合并型**和**消去型**两大类，它们的转移方式有所不同
4. **四边形不等式优化**可以将部分区间DP从 $O(n^3)$ 优化到 $O(n^2)$，但需要满足特定条件
5. 消去型区间DP通常需要**额外的维度**来记录状态，如颜色、连续数量等
6. 环形问题的前缀和、答案取值等细节需要特别小心，容易出错
