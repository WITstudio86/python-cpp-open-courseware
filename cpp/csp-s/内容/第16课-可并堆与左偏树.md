## 📖 知识精讲

### 一、为什么需要可并堆？

普通二叉堆（std::priority_queue）的问题：
- **合并两个堆的时间复杂度为 O(n)**（需要重建）
- 在许多场景中需要频繁合并堆（如：树上合并、动态连通块中的最值维护）

**可并堆**解决了这一问题，支持 O(log n) 的合并操作。

常见的可并堆实现有：
- **左偏树（Leftist Heap）**：最常用，代码简洁，实际效果最好
- 斜堆（Skew Heap）：均摊 O(log n)
- 二项堆（Binomial Heap）
- 配对堆（Pairing Heap）
- 斐波那契堆（Fibonacci Heap）

其中**左偏树**是 CSP-S 中最适合的可并堆实现。

### 二、左偏树的定义与性质

左偏树是一种**堆有序**的二叉树，额外维护每个节点的**零距离（npl / dist）**值。

**npl（Null Path Length）定义**：
- 空节点的 npl = 0
- 叶子节点（或只有一个空儿子的节点）的 npl = 0
- 非空节点 x 的 npl = min(npl(lc[x]), npl(rc[x])) + 1

**等价定义**：npl(x) = 从 x 到最近空节点的距离（边数）

**左偏性质**：对于任意节点 x，**左儿子的 npl ≥ 右儿子的 npl**。
即：`npl(lc[x]) >= npl(rc[x])`

**推论**：
- 若一条路径上的节点，每次都走右儿子，这条路径的长度不超过 O(log n)
- 左偏树的右脊（right spine）长度为 O(log n)
- 因此沿右脊进行合并，复杂度为 O(log n)

### 三、左偏树的核心操作：合并（meld）

合并是左偏树的灵魂，其他操作（插入、删除最值）都基于合并实现。

**合并两棵左偏树 h1 和 h2 的算法**（小根堆为例）：

```cpp
// 返回合并后的根
int merge(int x, int y) {
    if (!x || !y) return x + y;        // 一方为空，返回另一方

    // 确保 x 的值 ≤ y 的值（小根堆）
    if (val[x] > val[y]) swap(x, y);

    // 递归合并 x 的右儿子与 y
    rc[x] = merge(rc[x], y);

    // 维护左偏性质：若左儿子的 npl < 右儿子的 npl，交换左右儿子
    if (dist[lc[x]] < dist[rc[x]]) swap(lc[x], rc[x]);

    // 更新当前节点的 npl
    dist[x] = dist[rc[x]] + 1;

    return x;
}
```

**算法解释**：
1. 比较两棵树的根，较小值作为新根
2. 将新根的右子树与另一棵树递归合并
3. 回溯时检查并维护左偏性质
4. 更新 npl 值

**复杂度**：O(log n + log m)，其中 n 和 m 分别是两棵树的节点数。

### 四、基于合并的其他操作

```cpp
// 插入一个值：将新节点作为单节点树，与当前堆合并
int push(int root, int v) {
    int new_node = create_node(v);
    return merge(root, new_node);
}

// 删除堆顶：合并根的左右子树
int pop(int root) {
    return merge(lc[root], rc[root]);
}

// 获取堆顶
int top(int root) {
    return val[root];
}
```

### 五、经典问题：猴子打架（Monkey King / 左偏树 + 并查集）

**问题描述**：
有 n 只猴子，每只猴子有一个强壮值。初始时每只猴子互不认识。现在发生 m 次打架：
- 每次两只猴子 x 和 y 打架（通过各自的朋友圈中最强的猴子出战）
- 出战的猴子强壮值减半（下取整）
- 打架后两个朋友圈合并
- 输出每次打架后新朋友圈中最强猴子的强壮值

**解法**：
- 用**并查集**维护朋友圈（每只猴子属于哪个朋友圈）
- 每个朋友圈用一个**大根左偏树**维护所有猴子的强壮值
- 打架流程：
  1. 找到 x 和 y 所在朋友圈的代表（并查集 find）
  2. 取出各自的最强猴子（左偏树 top）
  3. 将该最强猴子的值减半后重新插入堆
  4. 合并两个左偏树
  5. 输出新堆的堆顶

**核心代码**：

```cpp
// 处理一次打架
int fight(int x, int y) {
    x = find(x); y = find(y);
    if (x == y) return -1;  // 同一朋友圈不打

    // 获取 x 圈中最强的猴子
    int hx = root[x];
    int strongest_x = val[hx];
    // 减半后放回
    root[x] = pop(root[x]);
    root[x] = merge(root[x], new_node(strongest_x / 2));

    // 对 y 做同样操作
    int hy = root[y];
    int strongest_y = val[hy];
    root[y] = pop(root[y]);
    root[y] = merge(root[y], new_node(strongest_y / 2));

    // 合并两个朋友圈
    fa[y] = x;
    root[x] = merge(root[x], root[y]);

    return val[root[x]];
}
```

## 💻 代码模板

```cpp
// ========== 左偏树模板（小根堆） ==========
const int MAXN = 100005;
int val[MAXN], lc[MAXN], rc[MAXN], dist[MAXN];
int tot;  // 节点总数

// 创建新节点
int new_node(int v) {
    tot++;
    val[tot] = v;
    lc[tot] = rc[tot] = 0;
    dist[tot] = 0;
    return tot;
}

// 合并两棵左偏树，返回新根
int merge(int x, int y) {
    if (!x || !y) return x + y;
    if (val[x] > val[y]) swap(x, y);  // 小根堆：根较小
    rc[x] = merge(rc[x], y);          // 递归合并右儿子
    if (dist[lc[x]] < dist[rc[x]]) swap(lc[x], rc[x]);
    dist[x] = dist[rc[x]] + 1;
    return x;
}

// 插入
int push(int root, int v) { return merge(root, new_node(v)); }

// 删除堆顶
int pop(int root) { return merge(lc[root], rc[root]); }

// 堆顶值
int top(int root) { return val[root]; }
```

## ⚠️ 易错点与优化技巧

1. **npl 的初始值** —— 新创建节点的 dist = 0（叶子），空节点 dist = 0
2. **合并时注意左右儿子交换** —— 只发生在 `dist[lc] < dist[rc]` 时
3. **并查集维护根** —— 猴子打架问题中，左偏树的根可能变化（pop 后），需要更新并查集的记录
4. **大根堆 vs 小根堆** —— 根据题目修改比较方向，或将值取负
5. **内存释放** —— 删除节点时不能物理删除（可能被并查集引用），标记删除即可
6. **递归深度** —— 左偏树的合并递归深度为 O(log n)，通常不会栈溢出
7. **dist 的维护** —— 每次合并后必须更新 dist[x] = dist[rc[x]] + 1

### 真题一：[HDU 1512] 猴子打架（Monkey King）

**题目描述**：
n 只猴子，每只有强壮值 a[i]。发生 m 次打架：每次两只猴子 x 和 y，找各自圈中最强的猴子出战；出战猴子强壮值减半；两圈合并。输出每次打架后新圈中最强猴子的强壮值。

**数据范围**：n, m ≤ 10⁵

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int val[MAXN], lc[MAXN], rc[MAXN], dist[MAXN];
int fa[MAXN], root[MAXN];  // 并查集 + 每圈左偏树的根
int tot;

int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }

int merge(int x, int y) {
    if (!x || !y) return x + y;
    if (val[x] < val[y]) swap(x, y);  // 大根堆：根较大
    rc[x] = merge(rc[x], y);
    if (dist[lc[x]] < dist[rc[x]]) swap(lc[x], rc[x]);
    dist[x] = dist[rc[x]] + 1;
    return x;
}

int pop(int x) { return merge(lc[x], rc[x]); }

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    int n;
    while (cin >> n) {
        tot = 0;
        for (int i = 1; i <= n; i++) {
            int v; cin >> v;
            fa[i] = i;
            lc[i] = rc[i] = dist[i] = 0;
            val[i] = v;
            root[i] = i;
            tot++;
        }
        int m; cin >> m;
        while (m--) {
            int x, y; cin >> x >> y;
            x = find(x); y = find(y);
            if (x == y) { cout << "-1\n"; continue; }

            // x 圈的最强猴子
            int rx = root[x];
            int sx = val[rx];
            root[x] = pop(rx);
            int nx = ++tot; val[nx] = sx / 2;
            lc[nx] = rc[nx] = dist[nx] = 0;
            root[x] = merge(root[x], nx);

            // y 圈的最强猴子
            int ry = root[y];
            int sy = val[ry];
            root[y] = pop(ry);
            int ny = ++tot; val[ny] = sy / 2;
            lc[ny] = rc[ny] = dist[ny] = 0;
            root[y] = merge(root[y], ny);

            // 合并两圈
            fa[y] = x;
            root[x] = merge(root[x], root[y]);

            cout << val[root[x]] << '\n';
        }
    }
    return 0;
}
```

**复杂度分析**：每次操作 O(log n)，总 O(m log n)。

### 真题二：[CSP-S 模拟] 可并堆维护动态最小值

**题目描述**：
有 n 个数分布在 m 个组中。支持操作：
1. 将组 a 和组 b 合并
2. 查询组 a 中的最小值并删除
3. 向组 a 插入一个新数

**数据范围**：n, q ≤ 10⁵

**解题思路**：
每个组用一个小根左偏树维护所有数。操作 1 合并两棵树，操作 2 pop 堆顶，操作 3 push 新节点。配合并查集维护组的代表。

**AC 代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int val[MAXN], lc[MAXN], rc[MAXN], dist[MAXN], tot;
int fa[MAXN], root[MAXN];

int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }

int merge(int x, int y) {
    if (!x || !y) return x + y;
    if (val[x] > val[y]) swap(x, y);  // 小根堆
    rc[x] = merge(rc[x], y);
    if (dist[lc[x]] < dist[rc[x]]) swap(lc[x], rc[x]);
    dist[x] = dist[rc[x]] + 1;
    return x;
}

int pop(int x) { return merge(lc[x], rc[x]); }

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    int n, q; cin >> n >> q;
    tot = 0;
    for (int i = 1; i <= n; i++) {
        int v; cin >> v;
        fa[i] = i;
        tot++; val[tot] = v;
        lc[tot] = rc[tot] = dist[tot] = 0;
        root[i] = tot;
    }
    while (q--) {
        int op; cin >> op;
        if (op == 1) {
            int a, b; cin >> a >> b;
            a = find(a); b = find(b);
            if (a == b) continue;
            fa[b] = a;
            root[a] = merge(root[a], root[b]);
        } else if (op == 2) {
            int a; cin >> a;
            a = find(a);
            cout << val[root[a]] << '\n';
            root[a] = pop(root[a]);
        } else {
            int a, v; cin >> a >> v;
            a = find(a);
            int nd = ++tot; val[nd] = v;
            lc[nd] = rc[nd] = dist[nd] = 0;
            root[a] = merge(root[a], nd);
        }
    }
    return 0;
}
```

**复杂度分析**：每次操作 O(log n)，总 O((n+q) log n)。

## 🎯 本课小结

1. **左偏树核心**：维护 npl 和左偏性质，使右脊长度为 O(log n)
2. **合并操作**：灵魂操作，沿右脊递归，回溯时维护左偏性质
3. **代码简洁**：核心 merge 仅约 10 行，非常实用
4. **配合并查集**：解决动态分组 + 堆合并问题
5. **时间复杂度**：所有操作 O(log n)，空间 O(n)
6. **与二叉堆对比**：左偏树支持 O(log n) 合并，二叉堆不支持
