### 1. 矩阵乘法

**定义：** 设 A 为 n×m 矩阵，B 为 m×p 矩阵，则 C = A×B 是 n×p 矩阵，且：

$$C[i][j] = \sum_{k=1}^{m} A[i][k] \cdot B[k][j]$$

**几何直觉：** C 的第 i 行第 j 列 = A 的第 i 行 与 B 的第 j 列 的内积。

**关键性质：**
- **结合律：** (A×B)×C = A×(B×C) —— 这是矩阵快速幂的基础
- **不满足交换律：** 一般情况下 A×B ≠ B×A，甚至维度可能不匹配
- **单位矩阵：** I[i][i] = 1, I[i][j] = 0 (i≠j)，有 A×I = I×A = A
- **与线性变换的关系：** 每个矩阵代表一个线性变换，矩阵乘法对应变换的复合

**时间复杂度：** 朴素实现 O(n³)，存在 Strassen 算法 O(n^{log₂7}) ≈ O(n^{2.81})，但在竞赛中朴素 O(n³) 已足够（n 通常 ≤ 300）。

**代码模板：**
```cpp
// 矩阵乘法（n×m 与 m×p 相乘，结果 n×p）
vector<vector<long long>> mat_mul(
    const vector<vector<long long>>& A,
    const vector<vector<long long>>& B,
    long long MOD) {
    int n = A.size(), m = B.size(), p = B[0].size();
    vector<vector<long long>> C(n, vector<long long>(p, 0));
    for (int i = 0; i < n; i++)
        for (int k = 0; k < m; k++)  // 注意：k 放在中间以优化缓存
            if (A[i][k])              // 稀疏优化
                for (int j = 0; j < p; j++)
                    C[i][j] = (C[i][j] + A[i][k] * B[k][j]) % MOD;
    return C;
}
```

**优化技巧：** 循环顺序 i→k→j 比 i→j→k 缓存友好得多。因为 B 的 k 行被重复使用，放在中间可以更好地利用 CPU 缓存。

### 2. 矩阵快速幂

**核心思想：** 将整数的快速幂推广到矩阵。因为矩阵乘法满足结合律，所以：

$$A^{n} = \begin{cases} I & n = 0 \\ (A^2)^{n/2} & n \text{ 为偶数} \\ A \cdot (A^2)^{(n-1)/2} & n \text{ 为奇数} \end{cases}$$

**代码模板：**
```cpp
// 矩阵快速幂 A^n（A 为方阵）
vector<vector<long long>> mat_pow(
    vector<vector<long long>> A, long long n, long long MOD) {
    int sz = A.size();
    // 初始化为单位矩阵
    vector<vector<long long>> res(sz, vector<long long>(sz, 0));
    for (int i = 0; i < sz; i++) res[i][i] = 1;
    while (n) {
        if (n & 1) res = mat_mul(res, A, MOD);
        A = mat_mul(A, A, MOD);
        n >>= 1;
    }
    return res;
}
```

**时间复杂度：** O(sz³ · log n)，其中 sz 为矩阵边长。

**最重要的应用：加速线性递推**

以斐波那契数列为例。定义 fib(0)=0, fib(1)=1, fib(n)=fib(n-1)+fib(n-2)。

**关键观察：** 递推关系可以用矩阵乘法表示。

$$\begin{bmatrix} fib(n) \\ fib(n-1) \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix} \cdot \begin{bmatrix} fib(n-1) \\ fib(n-2) \end{bmatrix}$$

展开：

$$\begin{bmatrix} fib(n) \\ fib(n-1) \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^{n-1} \cdot \begin{bmatrix} fib(1) \\ fib(0) \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}^{n-1} \cdot \begin{bmatrix} 1 \\ 0 \end{bmatrix}$$

于是 fib(n) 可以在 **O(log n)** 时间内求出（仅需 2³·log n 次乘法）。

**更一般地：k 阶线性递推** 可以用 k×k 的转移矩阵加速。例如：
- 递推 a_n = c₁·a_{n-1} + c₂·a_{n-2} + ... + c_k·a_{n-k}
- 构造 k×k 矩阵，第一行为 [c₁, c₂, ..., c_k]，下方为单位矩阵的偏移
- 这是 CSP-S 中矩阵快速幂最常见的考法

**另一种应用：图论中的路径计数**

若邻接矩阵 A，则 A^k[i][j] = 从 i 到 j 恰好经过 k 条边的路径条数。用矩阵快速幂可 O(n³ log k) 求出。

### 3. 高斯消元解线性方程组

高斯消元是求解 n 元线性方程组的经典算法。

**问题形式：** 求解 Ax = b，其中 A 为 n×n 系数矩阵，b 为 n 维列向量。

**增广矩阵：** 将 A 和 b 拼在一起，形成 n×(n+1) 的增广矩阵 [A | b]。

**算法步骤：**

**第一步：化为行阶梯形（前向消元）**
1. 对于每一列 col（代表一个未知数）：
   - 选主元：在第 col 行及以下中，找到第 col 列绝对值最大的行，将其交换到第 col 行
   - 若主元为 0（精度下接近 0），跳过该列
   - 用第 col 行消去下方所有行中第 col 列的元素
     - 对于第 r 行（r > col）：`factor = a[r][col] / a[col][col]`
     - 第 r 行 = 第 r 行 - factor × 第 col 行

**第二步：回代（后向消元）**
1. 从最后一行向上，逐行求解
2. 对于第 i 行：`x[i] = (b[i] - Σ_{j>i} a[i][j]·x[j]) / a[i][i]`

**解的判定（三种情况）：**

| 情况 | 判定条件 | 结果 |
|------|---------|------|
| 唯一解 | 消元后所有主元非零，且没有矛盾行 | 回代得到唯一解 |
| 无解 | 存在一行形如 [0 0 ... 0 | c] 且 c ≠ 0 | "No solution" |
| 无穷多解 | 存在自由变量（某列无主元），且无矛盾行 | "Infinite solutions" |

**代码模板（核心逻辑）：**
```cpp
// 高斯消元，返回 -1=无解, 0=无穷多解, 1=唯一解
// a 是 n×(n+1) 的增广矩阵，会被修改
int gauss(vector<vector<double>>& a, vector<double>& x) {
    int n = a.size();
    const double EPS = 1e-9;
    // 前向消元
    for (int col = 0, row = 0; col < n && row < n; col++) {
        // 选主元
        int pivot = row;
        for (int i = row + 1; i < n; i++)
            if (fabs(a[i][col]) > fabs(a[pivot][col]))
                pivot = i;
        if (fabs(a[pivot][col]) < EPS) continue;  // 该列全零
        swap(a[row], a[pivot]);
        // 消元
        for (int i = row + 1; i < n; i++) {
            double factor = a[i][col] / a[row][col];
            for (int j = col; j <= n; j++)
                a[i][j] -= factor * a[row][j];
        }
        row++;
    }
    // 判定无解和无穷多解，回代...
}
```

**数值精度注意事项：**
- 使用 double，EPS 取 1e-9
- 使用 fabs 而非 abs（绝对值）
- 选列主元（部分选主元）可以有效减少浮点误差
- 若题目要求有理数输出，考虑使用分数类或对 mod 取模的版本

### 4. 高斯消元求行列式

**方法：** 将矩阵通过行变换化为上三角矩阵，对角线元素乘积即为行列式。

**规则（行列式性质）：**
- 交换两行 → 行列式变号（乘 -1）
- 某行乘以 k → 行列式乘以 k
- 某行加上另一行的倍数 → 行列式不变（这是消元操作）

**算法：** 在做高斯消元化为上三角矩阵的过程中：
- 每次交换行时，`det = -det`（或 `det = (MOD - det) % MOD`）
- 消元操作不改变行列式
- 最终 `det = Π a[i][i]`（还要考虑符号）

**代码框架：**
```cpp
// 高斯消元求行列式（模 MOD 版本）
long long determinant(vector<vector<long long>> a, long long MOD) {
    int n = a.size();
    long long det = 1;
    for (int i = 0; i < n; i++) {
        // 找主元
        int pivot = -1;
        for (int r = i; r < n; r++) {
            if (a[r][i] != 0) { pivot = r; break; }
        }
        if (pivot == -1) return 0;  // 行列式为 0
        if (pivot != i) {
            swap(a[i], a[pivot]);
            det = (MOD - det) % MOD;  // 交换行，行列式变号
        }
        // 消元（需要逆元）
        long long inv = qpow(a[i][i], MOD - 2, MOD);
        det = det * a[i][i] % MOD;
        for (int j = i + 1; j < n; j++) {
            long long factor = a[j][i] * inv % MOD;
            for (int k = i; k < n; k++)
                a[j][k] = (a[j][k] - factor * a[i][k] % MOD + MOD) % MOD;
        }
    }
    return det;
}
```

**注意：** 在模质数下求行列式需要使用逆元。若 MOD 不是质数，可以使用辗转相除法消元（类似于求 GCD 的过程）。

### 5. 高斯消元求逆矩阵

**增广矩阵法：** 在原矩阵 A 的右侧拼接一个同阶单位矩阵 I，形成 [A | I]。对增广矩阵做行变换，当左侧变成 I 时，右侧就变成了 A^{-1}。

**步骤：**
1. 构造增广矩阵 augmented = [A | I]（n × 2n）
2. 对 augmented 做高斯-约当消元（化为简化行阶梯形）
3. 若 A 可逆（秩为 n），左侧变为 I，右侧即为 A^{-1}
4. 若 A 不可逆（某一列主元为 0），则逆矩阵不存在

**代码模板：**
```cpp
// 求逆矩阵（模 MOD 版本）
bool mat_inv(vector<vector<long long>> a, 
             vector<vector<long long>>& inv, long long MOD) {
    int n = a.size();
    inv.assign(n, vector<long long>(n, 0));
    for (int i = 0; i < n; i++) inv[i][i] = 1;  // 右侧初始为单位矩阵

    for (int i = 0; i < n; i++) {
        // 找主元
        int pivot = -1;
        for (int r = i; r < n; r++)
            if (a[r][i] != 0) { pivot = r; break; }
        if (pivot == -1) return false;  // 不可逆
        swap(a[i], a[pivot]);
        swap(inv[i], inv[pivot]);

        // 将主元化为 1
        long long inv_pivot = qpow(a[i][i], MOD - 2, MOD);
        for (int j = 0; j < n; j++) {
            a[i][j] = a[i][j] * inv_pivot % MOD;
            inv[i][j] = inv[i][j] * inv_pivot % MOD;
        }

        // 消去其他行的第 i 列
        for (int r = 0; r < n; r++) {
            if (r == i) continue;
            long long factor = a[r][i];
            for (int j = 0; j < n; j++) {
                a[r][j] = (a[r][j] - factor * a[i][j] % MOD + MOD) % MOD;
                inv[r][j] = (inv[r][j] - factor * inv[i][j] % MOD + MOD) % MOD;
            }
        }
    }
    return true;
}
```

## 📝 真题精练

### 例题 1：斐波那契数列第 n 项（矩阵快速幂）

**题目描述：** 定义斐波那契数列 fib(0)=0, fib(1)=1, fib(n)=fib(n-1)+fib(n-2) (n≥2)。给定 n（0 ≤ n ≤ 10¹⁸），求 fib(n) 对 1e9+7 取模的结果。

**输入格式：** 一行一个整数 n。

**输出格式：** 一个整数 fib(n) mod 1000000007。

**解题思路：**
- 使用矩阵快速幂：转移矩阵 T = [[1,1],[1,0]]
- fib(n) = (T^(n-1))[0][0] * fib(1) + (T^(n-1))[0][1] * fib(0)
- 当 n=0 时特判返回 0；当 n=1 时返回 1

**时间复杂度：** O(log n)，2³·log n 次乘法

**参考代码：**
```cpp
long long fib(long long n, long long MOD) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    vector<vector<long long>> T = {{1, 1}, {1, 0}};
    T = mat_pow(T, n - 1, MOD);
    return T[0][0];  // T^(n-1)[0][0] * 1 + T^(n-1)[0][1] * 0
}
```

### 例题 2：解线性方程组（高斯消元模板）

**题目描述：** 给定 n 个方程 n 个未知数的线性方程组，判断解的情况并输出。

**输入格式：**
- 第一行：整数 n（1 ≤ n ≤ 100）
- 接下来 n 行，每行 n+1 个浮点数，表示一个方程 aᵢ₁x₁ + aᵢ₂x₂ + ... + aᵢₙxₙ = bᵢ

**输出格式：**
- 若无解：输出 "No solution"
- 若无穷多解：输出 "Infinite solutions"
- 若唯一解：输出 n 行，每行一个浮点数（保留 2 位小数），表示 x₁ 到 xₙ 的解

**解题思路：**
- 标准高斯消元模板
- 前向消元后检查是否有矛盾行（全 0 系数但 b ≠ 0）
- 检查是否有自由变量（某列无主元）
- 回代求解

**时间复杂度：** O(n³)

## ⚠️ 常见错误与注意事项

1. **矩阵乘法维度不匹配** —— 必须 A 的列数 = B 的行数
2. **矩阵快速幂忘记初始化为单位矩阵** —— 结果是全 0 矩阵
3. **高斯消元忘记选主元** —— 遇到 0 系数会除以 0，导致 NaN
4. **浮点数比较不用 EPS** —— 直接 `== 0` 会因为精度问题出错
5. **高斯消元中行列式没有处理变号** —— 交换行时行列式要取反
6. **循环顺序错误** —— 矩阵乘法的 i→k→j 循环不能随意改
7. **取模版本忘记处理负数** —— 减法后要 `(x % MOD + MOD) % MOD`
