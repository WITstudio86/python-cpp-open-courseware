## 📖 知识精讲

### 1. 图的基本概念

图由**顶点（Vertex）**和**边（Edge）**组成，记为 $G = (V, E)$。

| 分类 | 特征 | 应用场景 |
|------|------|----------|
| 有向图 | 边有方向，$(u \to v)$ | 网络流、任务调度 |
| 无向图 | 边无方向，$\{u, v\}$ | 社交网络、连通性 |
| 带权图 | 边有权重 | 最短路径、最小生成树 |
| 无权图 | 边权重为 1 | 最少步数、层级关系 |

### 2. 图的三种存储方式

#### 2.1 邻接矩阵

使用二维数组 $g[u][v]$ 表示 $u$ 到 $v$ 的边关系。

```cpp
int g[MAXN][MAXN];
// g[u][v] = 1 表示有边，g[u][v] = 0 表示无边（无权图）
// g[u][v] = w 表示有边，权值为 w（带权图）
```

| 操作 | 时间复杂度 |
|------|-----------|
| 查询边 $(u,v)$ | $O(1)$ |
| 遍历 $u$ 的所有邻接点 | $O(V)$ |
| 空间复杂度 | $O(V^2)$ |

**适用场景**：稠密图（$E \approx V^2$）、需要快速判断两顶点是否相邻。Floyd 算法、朴素 Prim 算法。

**局限性**：稀疏图空间浪费严重。$V = 10^5$ 时矩阵需 $10^{10}$ 个 int，约 40GB，无法承受。

#### 2.2 邻接表

每个顶点维护一个列表，存储其所有邻接点。

```cpp
vector<int> g[MAXN];           // 无权图
vector<pair<int, int>> g[MAXN]; // 带权图：pair<邻接点, 边权>
```

| 操作 | 时间复杂度 |
|------|-----------|
| 查询边 $(u,v)$ | $O(\deg(u))$ |
| 遍历 $u$ 的所有邻接点 | $O(\deg(u))$ |
| 空间复杂度 | $O(V + E)$ |

**适用场景**：稀疏图（$E \ll V^2$），是 CSP-S 中最常用的存图方式。

#### 2.3 链式前向星

用数组模拟链表，空间紧凑、效率高。由三个数组组成：

```cpp
int head[MAXN];     // head[u]：u 的第一条边的编号
int to[MAXM];       // to[i]：第 i 条边的终点
int nxt[MAXM];      // nxt[i]：与第 i 条边同起点的下一条边的编号
int w[MAXM];        // w[i]：第 i 条边的权值（带权图）
int cnt = 0;        // 边的计数器
```

加边操作（头插法）：

```
void add_edge(int u, int v, int weight) {
    to[++cnt] = v;
    w[cnt] = weight;
    nxt[cnt] = head[u];
    head[u] = cnt;
}
```

| 操作 | 时间复杂度 |
|------|-----------|
| 查询边 | $O(\deg(u))$ |
| 遍历邻接点 | $O(\deg(u))$ |
| 空间复杂度 | $O(V + E)$ |

**优势**：比 `vector` 邻接表常数更小、内存更紧凑，在需要频繁加边或大规模图上表现更优。CSP-S 中处理 $V = 10^5, E = 2 \times 10^5$ 级别图时推荐使用。

### 3. 图的遍历

#### 3.1 深度优先搜索（DFS）

DFS 沿一条路径尽可能深地探索，直到无法继续再回溯。

```
DFS 伪代码：
void dfs(int u) {
    vis[u] = true;
    for (int v : g[u]) {
        if (!vis[v]) dfs(v);
    }
}
```

- **时间复杂度**：邻接表 $O(V + E)$，邻接矩阵 $O(V^2)$。
- **应用**：连通分量、拓扑排序、强连通分量（Tarjan）、二分图判定、桥与割点。

#### 3.2 广度优先搜索（BFS）

BFS 按层遍历，从起点逐层向外扩展。

```
BFS 伪代码：
queue<int> q;
q.push(start); vis[start] = true;
while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
        if (!vis[v]) {
            vis[v] = true;
            q.push(v);
        }
    }
}
```

- **时间复杂度**：邻接表 $O(V + E)$。
- **应用**：无权图最短路径、分层图、双端 BFS（0-1 BFS）。

#### 3.3 DFS 与 BFS 对比

| 维度 | DFS | BFS |
|------|-----|-----|
| 数据结构 | 栈（递归/显式） | 队列 |
| 空间复杂度 | $O(h)$，$h$ 为递归深度 | $O(w)$，$w$ 为最大宽度 |
| 最短路径 | ❌ 不保证 | ✅ 无权图最短路径 |
| 连通分量 | ✅ 直接可得 | ✅ 直接可得 |
| 拓扑排序 | ✅ 后序遍历 | ✅ Kahn 算法 |

### 4. 连通分量计数

对无向图，一个连通分量是一个极大连通子图。通过遍历统计未被访问过的顶点数即可。

- **算法**：对每个未访问顶点执行一次 DFS/BFS，计数器 +1。
- **时间复杂度**：$O(V + E)$。
- **CSP-S 变式**：统计连通块大小、判断整图是否连通。

### 5. 二分图判定

**定义**：一个图是二分图，当且仅当可以将顶点集划分为两个不相交的集合 $A, B$，使得每条边的两个端点分别属于 $A$ 和 $B$。

**判定定理**：一个图是二分图当且仅当它不包含奇数环。

**染色法**：
- 用 0/1 两种颜色给顶点染色。
- 从任意未染色顶点出发，将其染为 0，DFS/BFS 将其邻接点染为相反颜色 1。
- 若发现邻接点已被染成与当前顶点相同的颜色，则该图不是二分图。

```
染色法伪代码：
bool dfs(int u, int c) {
    color[u] = c;
    for (int v : g[u]) {
        if (color[v] == -1) {
            if (!dfs(v, c ^ 1)) return false;
        } else if (color[v] == c) {
            return false; // 冲突
        }
    }
    return true;
}
```

- **时间复杂度**：$O(V + E)$。
- **CSP-S 常考**：二分图最大匹配（匈牙利算法）、最小点覆盖（Kőnig 定理）。

## 💻 代码模板

### 模板 1：邻接表 + DFS + BFS

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 1e5 + 5;

vector<int> g[MAXN];
bool vis[MAXN];
int n, m;

// DFS 遍历
void dfs(int u) {
    vis[u] = true;
    // 在此处处理顶点 u
    for (int v : g[u]) {
        if (!vis[v]) dfs(v);
    }
}

// BFS 遍历（同时计算距离）
int dist[MAXN];
void bfs(int start) {
    queue<int> q;
    q.push(start);
    vis[start] = true;
    dist[start] = 0;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) {
            if (!vis[v]) {
                vis[v] = true;
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
}
```

### 模板 3：连通分量计数

```cpp
int count_components() {
    memset(vis, 0, sizeof(vis));
    int comp = 0;
    for (int i = 1; i <= n; i++) {
        if (!vis[i]) {
            comp++;
            dfs(i); // 或 bfs(i)
```

### 模板 4：二分图判定（染色法）

```cpp
int color[MAXN]; // -1 未染色，0/1 两种颜色

bool is_bipartite(int u, int c) {
    color[u] = c;
    for (int v : g[u]) {
        if (color[v] == -1) {
            if (!is_bipartite(v, c ^ 1)) return false;
        } else if (color[v] == c) {
            return false;
        }
    }
    return true;
}

// 调用：检查整图是否为二分图
bool check_bipartite() {
    memset(color, -1, sizeof(color));
    for (int i = 1; i <= n; i++) {
        if (color[i] == -1) {
            if (!is_bipartite(i, 0)) return false;
        }
    }
    return true;
}
```

## ⚠️ 易错点与优化技巧

### 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| DFS 爆栈 | 递归深度过大（$V = 10^5$ 单链） | 改用显式栈/迭代 DFS，或增大栈空间 `-Wl,-stack_size,0x20000000` |
| 邻接矩阵 MLE | $V$ 过大 | 使用邻接表或链式前向星 |
| BFS 忘记标记 vis | 入队时未标记导致重复入队 | **在入队时立即标记** vis，而非出队时标记 |
| 链式前向星编号从 0 开始 | `head` 数组初始化为 -1 而非 0 | 统一使用 1-based 编号，`head` 初始化为 0 |
| 染色法数组未初始化 | `color` 数组初值 0 与颜色冲突 | 初始化为 -1，颜色用 0/1 |
| 有向图 vs 无向图 | 无向图忘记加反向边 | `add_edge(u,v); add_edge(v,u);` |
| 重边处理 | 邻接表/邻接矩阵中重边导致错误 | 根据题目要求取 min/max 或保留 |

### 优化技巧

1. **输入优化**：大规模图使用 `scanf` / `cin` 关同步（`ios::sync_with_stdio(false); cin.tie(0);`）。
2. **vector 预分配**：已知边数时用 `g.reserve(E/n)` 减少扩容开销。
3. **无向图边数翻倍**：链式前向星 MAXM 要开边数的 2 倍（无向图）。
4. **BFS 距离初始化**：用 `memset(dist, -1, sizeof(dist))` 将距离初始化为 -1，一举两得（既作距离又作 vis）。
5. **递归 DFS 改写为循环**：在需要避免爆栈时，手动维护栈。

## 📝 真题精练

### 题目 1：图的连通性

**【问题描述】**

给定一个无向图 $G$，包含 $n$ 个顶点和 $m$ 条边。顶点编号 $1 \sim n$。请回答以下两个问题：

1. 该图有多少个连通分量？
2. 每个连通分量的大小（顶点数）是多少？（按连通分量编号从小到大的顺序输出）

**【输入格式】**

第一行两个整数 $n, m$（$1 \le n \le 10^5$，$0 \le m \le 2 \times 10^5$）。接下来 $m$ 行，每行两个整数 $u, v$，表示一条无向边。

**【输出格式】**

第一行输出一个整数 $k$，表示连通分量数。接下来 $k$ 行，每行两个整数：连通分量编号（从 1 开始）和该分量的大小（顶点数）。

**【参考代码】**

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e5 + 5;
vector<int> g[MAXN];
bool vis[MAXN];
int n, m, comp_size;

// DFS 遍历一个连通分量，并统计大小
void dfs(int u) {
    vis[u] = true;
    comp_size++;
    for (int v : g[u]) {
        if (!vis[v]) dfs(v);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    vector<int> sizes;
    for (int i = 1; i <= n; i++) {
        if (!vis[i]) {
            comp_size = 0;
            dfs(i);
            sizes.push_back(comp_size);
        }
    }

    cout << sizes.size() << '\n';
    for (int i = 0; i < (int)sizes.size(); i++) {
        cout << i + 1 << ' ' << sizes[i] << '\n';
    }
    return 0;
}
```

**复杂度分析**：每个顶点和每条边均被访问一次，时间复杂度 $O(n + m)$，空间复杂度 $O(n + m)$。可 AC $n = 10^5, m = 2 \times 10^5$ 的数据。

### 题目 2：二分图判定

**【问题描述】**

给定一个 $n$ 个顶点 $m$ 条边的无向图，判断该图是否为二分图。

**【输入格式】**

第一行两个整数 $n, m$（$1 \le n \le 10^5$，$0 \le m \le 2 \times 10^5$）。接下来 $m$ 行，每行两个整数 $u, v$，表示一条无向边。

**【输出格式】**

若图为二分图，输出 `Yes`；否则输出 `No`。

**【参考代码】**

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1e5 + 5;
vector<int> g[MAXN];
int color[MAXN]; // -1 未染色，0/1 两种颜色
int n, m;

bool dfs(int u, int c) {
    color[u] = c;
    for (int v : g[u]) {
        if (color[v] == -1) {
            if (!dfs(v, c ^ 1)) return false;
        } else if (color[v] == c) {
            return false;
        }
    }
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    memset(color, -1, sizeof(color));
    bool ok = true;
    for (int i = 1; i <= n; i++) {
        if (color[i] == -1) {
            if (!dfs(i, 0)) {
                ok = false;
                break;
            }
        }
    }

    cout << (ok ? "Yes" : "No") << '\n';
    return 0;
}
```

**复杂度分析**：染色法每个顶点和每条边访问一次，时间复杂度 $O(n + m)$，空间复杂度 $O(n + m)$。可 AC $n = 10^5, m = 2 \times 10^5$ 的数据。

## 🎯 本课小结

1. **三种存图方式**：邻接矩阵适合稠密图、快速查边，邻接表适合稀疏图且最常用，链式前向星常数更小适合大规模图。
2. **DFS** 用栈（递归），适合路径探索、连通性、染色；**BFS** 用队列，适合无权图最短路径、分层遍历。
3. **连通分量**：对每个未访问顶点执行一次 DFS/BFS，计数器累加。
4. **二分图判定**：染色法，DFS/BFS 交替染两种颜色，出现相邻同色则非二分图。
5. **CSP-S 应试**：邻接表 + DFS/BFS 是核心，熟练记忆染色法模板和连通分量计数模板。
