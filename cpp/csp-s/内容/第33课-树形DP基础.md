## 📖 知识精讲

### 1. 树形DP的核心思想

树形DP是将动态规划的思想应用到树结构上。树是一种无环连通图，其递归性质天然适合DP。

**核心特点：**
- 利用树的递归结构，通过DFS进行后序遍历
- 子节点的DP值计算完成后，再计算父节点的DP值
- 状态通常分为"选/不选当前节点"两类

**DP计算顺序：**
```
DFS(u, fa):
    for v in u的儿子:
        if v != fa:
            DFS(v, u)           // 先递归处理子树
            // 后序遍历：利用v的DP值更新u的DP值
```

### 2. 最大独立集（没有上司的舞会）

**问题描述：** 在树中选择一个最大点集，使得任意两个被选中的点不相邻。

**状态设计：**
- `dp[u][0]`：不选节点 u 时，以 u 为根的子树中能选的最大点数（或最大权值和）
- `dp[u][1]`：选节点 u 时，以 u 为根的子树中能选的最大点数（或最大权值和）

**状态转移：**
```
dp[u][0] = Σ max(dp[v][0], dp[v][1])    // 不选u，儿子可选可不选
dp[u][1] = w[u] + Σ dp[v][0]            // 选u，所有儿子都不能选
```

其中 w[u] 是节点 u 的权值。如果题目没有权值（只求点数），则 w[u] = 1。

**正确性证明：** 考虑以 u 为根的子树。若选 u，则其所有直接儿子都不能被选（最大独立集要求），且各子树之间的选择互不影响（树结构的无环性质）；若不选 u，则每个儿子都可以自由选择选或不选，各子树的最优解之和即为全局最优解。这满足最优子结构性质。

**时间复杂度：** O(n)，每个节点和每条边各被访问一次。

### 3. 最小点覆盖

**问题描述：** 在树中选择一个最小点集，使得每条边至少有一个端点被选中。

**状态设计：**
- `dp[u][0]`：不选节点 u 时，覆盖以 u 为根的子树中所有边所需的最小点数
- `dp[u][1]`：选节点 u 时，覆盖以 u 为根的子树中所有边所需的最小点数

**状态转移：**
```
dp[u][0] = Σ dp[v][1]                  // 不选u，儿子必须全选（否则边(u,v)未被覆盖）
dp[u][1] = 1 + Σ min(dp[v][0], dp[v][1])  // 选u，儿子可选可不选
```

**重要结论：** 在二分图（树是特殊的二分图）中，最大匹配数 = 最小点覆盖数（Kőnig定理）。在树上，最大独立集 + 最小点覆盖 = n。

### 4. 树形DP的状态设计原则

1. **以"选/不选当前节点"为基本状态维度** —— 这是最经典的树形DP模式
2. **明确子树贡献的独立性** —— 确保最优子结构
3. **后序遍历确保子问题先求解** —— 这是树形DP与线性DP的关键区别
4. **复杂度控制在 O(n) 或 O(nk)** —— 树上背包问题可以达到 O(nk)

### 5. 多叉树的处理方法

对于非二叉树：
- 使用邻接表存储树结构
- DFS时传入父节点参数，避免回到父节点
- 状态转移时遍历所有儿子

## 💻 代码模板

```cpp
// 树形DP标准模板 —— 最大独立集
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
vector<int> g[MAXN];
int w[MAXN];                    // 节点权值
int dp[MAXN][2];                // dp[u][0]: 不选u; dp[u][1]: 选u

void dfs(int u, int fa) {
    dp[u][0] = 0;
    dp[u][1] = w[u];
    for (int v : g[u]) {
        if (v == fa) continue;
        dfs(v, u);              // 先递归子节点
        dp[u][0] += max(dp[v][0], dp[v][1]);
        dp[u][1] += dp[v][0];
    }
}

int main() {
    int n; cin >> n;
    for (int i = 1; i <= n; i++) cin >> w[i];
    for (int i = 1; i < n; i++) {
        int u, v; cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    dfs(1, 0);
    cout << max(dp[1][0], dp[1][1]) << '\n';
    return 0;
}
```

## ⚠️ 易错点与优化技巧

### 常见错误
1. **忘记后序遍历顺序**：在更新dp[u]之前必须先完成dp[v]的计算
2. **树的存储方式**：必须用邻接表，不能用邻接矩阵（浪费空间）
3. **无向边导致循环**：DFS必须传入父节点参数，防止回到父节点
4. **初始化顺序**：dp[u][0]和dp[u][1]要在遍历儿子之前正确初始化
5. **根节点的选择**：任意节点都可以作为根，习惯选择1号节点

### 优化技巧
1. **避免全局变量污染**：使用结构体或namespace封装
2. **大型输入使用快速IO**：`ios::sync_with_stdio(false); cin.tie(0);`
3. **树的直径问题要考虑负权边**：dp值初始化要注意
4. **记忆化搜索也是树形DP**：自顶向下（记忆化）和自底向上（递推）都可以

1. **树形DP的核心是后序遍历**：先处理子树，再处理根节点
