## 📚 新知识

### 5.1 碰撞就是距离

```python
if player.distance(star) < 28:
    score += 1
if player.distance(rock) < 26:
    print("失败")
```

没有内置的「碰撞函数」。自己量距离，自己定阈值。海龟越大，阈值越大。

### 5.2 刷新道具时躲开别人

```python
while True:
    star.goto(随机坐标)
    if star.distance(player) > 60:
        break
```

否则星星刷在脚底下，一帧就吃掉，没意思。

### 5.3 多键同时按

用字典记每个方向是否按住，循环里按字典移动。比「一个键走一步」跟手。

## 🚀 加码

## 🐞 改错

1. 阈值太小，贴着星星也吃不到
2. 吃到星星没 `place_star()`，星星停在嘴里
3. 石头 `pendown`，满屏红线
