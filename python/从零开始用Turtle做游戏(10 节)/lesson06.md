## 📚 新知识

### 6.1 先做工厂，再做列表

```python
meteors = []
for _ in range(6):
    m = turtle.Turtle()
    m.shape("circle")
    m.penup()
    m.goto(随机)
    meteors.append(m)
```

一只一只写变量名 `m1 m2 m3` 会写崩溃。列表是游戏对象的家。

### 6.2 统一移动

```python
for m in meteors:
    m.sety(m.ycor() - speed)
    if m.ycor() < -300:
        reset_meteor(m)
    if player.distance(m) < 24:
        结束
```

### 6.3 难度曲线

```python
speed = 4 + score // 15
```

分数越高，`//` 得到的整数越大，掉得越快。不要一上来就快到没法玩。
