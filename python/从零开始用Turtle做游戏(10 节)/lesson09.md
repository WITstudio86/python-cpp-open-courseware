## 🎯 本课目标

- 会用列表表示蛇的每一节
- 会「从尾巴往头挪」：后一节走到前一节的位置
- 会禁止 180 度掉头
- **主游戏：贪吃蛇**

---

## 📚 新知识

### 9.1 身体是列表

```python
snake = [头, 第二节, 第三节]
```

`snake[0]` 永远是头。吃到食物就 `append` 一节新尾巴。

### 9.2 移动算法（本课最重要的 4 行）

```python
for i in range(len(snake) - 1, 0, -1):
    snake[i].goto(snake[i - 1].xcor(), snake[i - 1].ycor())
head.goto(新位置)
```

必须从尾巴往前抄，否则大家都挤到头上。热身先只做这件事情。

### 9.3 不能掉头

```python
if abs(新方向 - 当前方向) == 180:
    return
```

否则一节身体里，头立刻撞上第二节。

---

## 🔥 热身

三节固定长度，方向键转弯，不吃食物、不检测死亡。看懂「尾巴跟着走」。

**课堂提问：** 如果 `for i in range(1, len(snake))` 从头往后抄，会发生什么？
