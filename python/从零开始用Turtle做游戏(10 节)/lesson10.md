## 📚 新知识

### 10.1 状态机

```python
state = "menu"

def tick():
    if state != "play":
        screen.update()
        screen.ontimer(tick, 20)
        return
    # 只有 play 才移动角色
```

菜单时按空格 → `start_game()` 把 `state` 改成 `"play"`。  
生命扣完 → `state = "over"`。  
按 R → `show_menu()`。

同一套按键在不同状态下做不同事（空格：开始 或 射击）。

### 10.2 清场

```python
for shot in bullets:
    shot.hideturtle()
bullets.clear()
```

只 `clear()` 列表但海龟还画在屏幕上，会留下「幽灵子弹」。必须先藏再丢。

### 10.3 波次

```python
if score >= wave * 80:
    wave += 1
    make_enemy()
```

分数门槛升高，敌人更多、掉得更快。这就是关卡。
