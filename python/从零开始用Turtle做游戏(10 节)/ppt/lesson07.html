第 1 / 5 步 · 打

炮台能走

炮台放底部，setheading(90)。press_left 改 vx。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 7 课 · 打气球")
screen.bgcolor("navy")
screen.tracer(0)
vx = 0
cannon = turtle.Turtle()
cannon.shape("triangle")
cannon.color("skyblue")
cannon.penup()
cannon.goto(0, -250)
cannon.setheading(90)

def press_left():
    global vx
    vx = -8
def press_right():
    global vx
    vx = 8
def stop():
    global vx
    vx = 0
def tick():
    cannon.setx(cannon.xcor() + vx)
    if cannon.xcor() > 370:
        cannon.setx(370)
    if cannon.xcor() < -370:
        cannon.setx(-370)
    screen.update()
    screen.ontimer(tick, 20)

screen.listen()
screen.onkeypress(press_left, "Left")
screen.onkeypress(press_right, "Right")
screen.onkeyrelease(stop, "Left")
screen.onkeyrelease(stop, "Right")
screen.ontimer(tick, 20)
turtle.done()
运行后你该看到： 底部青色三角左右滑动。这时空格还没反应。
坑： 忘了 setheading(90)，三角横着。

第 2 / 5 步 · 讲

空格发射

按空格射出黄点，飞出屏幕就删掉。

为什么： 子弹是临时工。按一次键 new 一只，append 进列表。边遍历边删要写成 bullets[:]。
  1. 加 bullets = []、cool = 0、make_bullet、fire
  2. tick 里 for shot in bullets[:]：forward，出屏 hideturtle+remove
  3. 绑 space
运行后你该看到： 空格射出黄点往上飞，到顶消失。连按太快会被冷却拦住。
第 7 课 · 发射！
黑板上写 [:] 的原因。强调子弹也要 penup。大约 12 分钟。

第 2 / 5 步 · 打

空格发射

for shot in bullets[:] 再 remove。子弹一定 penup。空格键名字是 space。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 7 课 · 打气球")
screen.bgcolor("navy")
screen.tracer(0)
vx = 0
cool = 0
cannon = turtle.Turtle()
cannon.shape("triangle")
cannon.color("skyblue")
cannon.penup()
cannon.goto(0, -250)
cannon.setheading(90)
bullets = []

def make_bullet():
    shot = turtle.Turtle()
    shot.shape("square")
    shot.shapesize(0.4, 0.8)
    shot.color("yellow")
    shot.penup()
    shot.goto(cannon.xcor(), cannon.ycor() + 20)
    shot.setheading(90)
    bullets.append(shot)
def press_left():
    global vx
    vx = -8
def press_right():
    global vx
    vx = 8
def stop():
    global vx
    vx = 0
def fire():
    global cool
    if cool <= 0 and len(bullets) < 4:
        make_bullet()
        cool = 10
def tick():
    global cool
    if cool > 0:
        cool = cool - 1
    cannon.setx(cannon.xcor() + vx)
    if cannon.xcor() > 370:
        cannon.setx(370)
    if cannon.xcor() < -370:
        cannon.setx(-370)
    for shot in bullets[:]:
        shot.forward(12)
        if shot.ycor() > 300:
            shot.hideturtle()
            bullets.remove(shot)
    screen.update()
    screen.ontimer(tick, 20)

screen.listen()
screen.onkeypress(press_left, "Left")
screen.onkeypress(press_right, "Right")
screen.onkeyrelease(stop, "Left")
screen.onkeyrelease(stop, "Right")
screen.onkeypress(fire, "space")
screen.ontimer(tick, 20)
turtle.done()
运行后你该看到： 空格射出黄点往上飞，到顶消失。连按太快会被冷却拦住。
坑： 写成 for shot in bullets: remove，会漏删。

第 4 / 5 步 · 讲

打中加分

子弹碰到气球：分数 +1，子弹消失，气球回天上。

为什么： 两层循环：每个气球对每颗子弹测 distance。打中两边都要处理。
  1. 加 score 和 hud
  2. 气球循环里再 for shot in bullets[:]
  3. distance < 22 就加分、删子弹、reset 气球
运行后你该看到： 打中彩圆分数 +1，气球跳回天上。
