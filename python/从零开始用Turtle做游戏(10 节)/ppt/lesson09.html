第 1 / 5 步 · 讲

三节跟着走

三节方块排成一排，从尾巴往头抄坐标，整条往右爬。

为什么： 后一节走到前一节刚才的位置。从头往后抄，整条蛇会叠在一起。
  1. STEP=20，窗口 600×600
  2. 循环 3 次造身体，头是绿色更亮
  3. tick 里倒序 for，然后头 x + 20
运行后你该看到： 一条三节的蛇往右爬，会爬出窗口。这时还不能转弯。

第 1 / 5 步 · 打

三节跟着走

for i in range(len(snake)-1, 0, -1) 抄前一节的坐标。头再往右走一格。

import turtle
import random

STEP = 20
screen = turtle.Screen()
screen.setup(600, 600)
screen.title("第 9 课 · 贪吃蛇")
screen.bgcolor("black")
screen.tracer(0)
snake = []
for i in range(3):
    s = turtle.Turtle()
    s.shape("square")
    if i == 0:
        s.color("lime")
    else:
        s.color("green")
    s.penup()
    s.goto(-i * STEP, 0)
    snake.append(s)

def tick():
    for i in range(len(snake) - 1, 0, -1):
        snake[i].goto(snake[i - 1].xcor(), snake[i - 1].ycor())
    head = snake[0]
    head.setx(head.xcor() + STEP)
    screen.update()
    screen.ontimer(tick, 140)

screen.ontimer(tick, 140)
turtle.done()
运行后你该看到： 一条三节的蛇往右爬，会爬出窗口。这时还不能转弯。
坑： for 写成 range(len(snake)) 从头抄，三节叠成一团。

第 2 / 5 步 · 讲

方向键转弯

方向键改变方向。不能立刻 180 度掉头。

为什么： 掉头会立刻撞上第二节。abs(新-旧)==180 就忽略。pending 记下这一格的转向，下一格再生效。
  1. 加 direction=0 和 pending=None
  2. turn + 四个 turn_up 等小函数
  3. tick 开头把 pending 写进 direction，再按方向走
运行后你该看到： 方向键能转弯。对着身子按反方向，蛇不会掉头。

第 2 / 5 步 · 打

方向键转弯

差 180 度就 return。四个小函数调用 turn。tick 里先处理 pending。

import turtle
import random

STEP = 20
screen = turtle.Screen()
screen.setup(600, 600)
screen.title("第 9 课 · 贪吃蛇")
screen.bgcolor("black")
screen.tracer(0)
direction = 0
pending = None
snake = []
for i in range(3):
    s = turtle.Turtle()
    s.shape("square")
    if i == 0:
        s.color("lime")
    else:
        s.color("green")
    s.penup()
    s.goto(-i * STEP, 0)
    snake.append(s)

def turn(heading):
    global pending
    if abs(heading - direction) == 180:
        return
    pending = heading
def turn_up():
    turn(90)
def turn_down():
    turn(270)
def turn_left():
    turn(180)
def turn_right():
    turn(0)
def tick():
    global direction, pending
    if pending is not None:
        direction = pending
        pending = None
    for i in range(len(snake) - 1, 0, -1):
        snake[i].goto(snake[i - 1].xcor(), snake[i - 1].ycor())
    head = snake[0]
    nx = head.xcor()
    ny = head.ycor()
    if direction == 0:
        nx = nx + STEP
    if direction == 180:
        nx = nx - STEP
    if direction == 90:
        ny = ny + STEP
    if direction == 270:
        ny = ny - STEP
    head.goto(nx, ny)
    head.setheading(direction)
    screen.update()
    screen.ontimer(tick, 140)

screen.listen()
screen.onkeypress(turn_up, "Up")
screen.onkeypress(turn_down, "Down")
screen.onkeypress(turn_left, "Left")
screen.onkeypress(turn_right, "Right")
screen.ontimer(tick, 140)
turtle.done()
运行后你该看到： 方向键能转弯。对着身子按反方向，蛇不会掉头。
坑： 允许 180 掉头，一按就撞自己。

不要用 lambda。turn_up 就是 turn(90)。

第 3 / 5 步 · 讲

吃食物变长

吃到黄点：身体 +1，食物换到空地。

为什么： 食物刷在身上会一帧连吃。while True 随机，直到每一节都离得远。grow 出生在旧尾巴处。
  1. 加 food、place_food、grow
  2. tick 里 distance < 15 就 grow + place_food
  3. 启动时调用一次 place_food()
运行后你该看到： 吃黄点身体变长。食物不会刷在蛇身上。

第 3 / 5 步 · 打

吃食物变长

place_food 用 for 检查每一节。吃到就 grow() 再换位置。

import turtle
import random

STEP = 20
screen = turtle.Screen()
screen.setup(600, 600)
screen.title("第 9 课 · 贪吃蛇")
screen.bgcolor("black")
screen.tracer(0)
direction = 0
pending = None
snake = []
for i in range(3):
    s = turtle.Turtle()
    s.shape("square")
    if i == 0:
        s.color("lime")
    else:
        s.color("green")
    s.penup()
    s.goto(-i * STEP, 0)
    snake.append(s)
food = turtle.Turtle()
food.shape("circle")
food.color("yellow")
food.penup()
food.goto(80, 80)

def turn(heading):
    global pending
    if abs(heading - direction) == 180:
        return
    pending = heading
def turn_up():
    turn(90)
def turn_down():
    turn(270)
def turn_left():
    turn(180)
def turn_right():
    turn(0)
def place_food():
    while True:
        x = random.randint(-13, 13) * STEP
        y = random.randint(-13, 12) * STEP
        ok = True
        for seg in snake:
            if seg.distance(x, y) < 10:
                ok = False
                break
        if ok:
            food.goto(x, y)
            break
def grow():
    tail = turtle.Turtle()
    tail.shape("square")
    tail.color("green")
    tail.penup()
    last = snake[-1]
    tail.goto(last.xcor(), last.ycor())
    snake.append(tail)
def tick():
    global direction, pending
    if pending is not None:
        direction = pending
        pending = None
    for i in range(len(snake) - 1, 0, -1):
        snake[i].goto(snake[i - 1].xcor(), snake[i - 1].ycor())
    head = snake[0]
    nx = head.xcor()
    ny = head.ycor()
    if direction == 0:
        nx = nx + STEP
    if direction == 180:
        nx = nx - STEP
    if direction == 90:
        ny = ny + STEP
    if direction == 270:
        ny = ny - STEP
    head.goto(nx, ny)
    head.setheading(direction)
    if head.distance(food) < 15:
        grow()
        place_food()
    screen.update()
    screen.ontimer(tick, 140)

place_food()
screen.listen()
screen.onkeypress(turn_up, "Up")
screen.onkeypress(turn_down, "Down")
screen.onkeypress(turn_left, "Left")
screen.onkeypress(turn_right, "Right")
screen.ontimer(tick, 140)
turtle.done()

坑： place_food 不用循环避开身体，偶尔会连吃。

结束后按 R 回到 3 节；身体越长稍微越快。

为什么： 多出来的节 pop 并 hideturtle。前 3 节回到起点。速度 140-长度*3，最快 70。

  3. tick 末尾用 wait 再约自己

    for i in range(len(snake) - 1, 0, -1):
        snake[i].goto(snake[i - 1].xcor(), snake[i - 1].ycor())
    head = snake[0]
    nx = head.xcor()
    ny = head.ycor()
    if direction == 0:
        nx = nx + STEP
    if direction == 180:
        nx = nx - STEP
    if direction == 90:
        ny = ny + STEP
    if direction == 270:
        ny = ny - STEP
    head.goto(nx, ny)
    head.setheading(direction)
    if abs(nx) > 280:
        nx = -nx
        head.setx(nx)
    if abs(ny) > 280:
        ny = -ny
        head.sety(ny)
    for seg in snake[1:]:
        if head.distance(seg) < 10:
            game_over()
            screen.update()
            return
    if head.distance(food) < 15:
        grow()
        place_food()
    draw_hud()
    screen.update()
    wait = 140 - len(snake) * 3
    if wait < 70:
        wait = 70
    screen.ontimer(tick, wait)

place_food()
