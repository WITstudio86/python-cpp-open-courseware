第 1 / 4 步 · 讲

地鼠出现

棕色窗口里，一只橙色地鼠出现在随机位置。

为什么： randint 含两端。goto 是瞬移换洞。tracer(0) 要配 update，否则窗口是黑的。

  2. 创建 screen 和 mole，全部 penup
  3. 随机坐标 goto，再 update 和 done
运行后你该看到： 窗口里一只橙色大海龟，每次运行位置可能不同。这时点它没反应。

第 1 / 4 步 · 打

地鼠出现

mole 随机 goto。tracer(0) 后面一定要有 screen.update()。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 3 课 · 打地鼠")
screen.bgcolor("saddlebrown")
screen.tracer(0)
mole = turtle.Turtle()
mole.shape("turtle")
mole.color("orange")
mole.shapesize(2.2, 2.2)
mole.penup()
x = random.randint(-320, 320)
y = random.randint(-180, 180)
mole.goto(x, y)
screen.update()
turtle.done()
运行后你该看到： 窗口里一只橙色大海龟，每次运行位置可能不同。这时点它没反应。
坑： 写了 tracer(0) 却忘了 update，窗口一片黑。

第 2 / 4 步 · 讲

点中加分

点到地鼠附近 40 像素内：分数 +1，地鼠立刻换洞。

为什么： 鼠标很难点到正中心。用 distance < 阈值，不要写 xcor()==x。
  1. 加 score、hud、jump_mole、draw_hud、hit
  2. hit 里要写 global score
  3. onscreenclick(hit)，函数名不要加括号
运行后你该看到： 点中橙色地鼠，头顶分数 +1，地鼠跳到别处。点空了没反应。

第 2 / 4 步 · 打

点中加分

hit 里 distance < 40 就加分并 jump_mole()。hit 开头写 global score。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 3 课 · 打地鼠")
screen.bgcolor("saddlebrown")
screen.tracer(0)
score = 0
mole = turtle.Turtle()
mole.shape("turtle")
mole.color("orange")
mole.shapesize(2.2, 2.2)
mole.penup()
hud = turtle.Turtle()
hud.hideturtle()
hud.penup()
hud.color("white")

def jump_mole():
    x = random.randint(-320, 320)
    y = random.randint(-180, 180)
    mole.goto(x, y)
    mole.showturtle()
    screen.update()
def draw_hud():
    hud.clear()
    hud.goto(0, 240)
    hud.write(f"得分 {score}", align="center", font=("Arial", 22, "bold"))
    screen.update()
def hit(x, y):
    global score
    if mole.distance(x, y) < 40:
        score = score + 1
        mole.hideturtle()
        draw_hud()
        jump_mole()

draw_hud()
jump_mole()
screen.onscreenclick(hit)
turtle.done()
运行后你该看到： 点中橙色地鼠，头顶分数 +1，地鼠跳到别处。点空了没反应。
坑： 写成 onscreenclick(hit())，点击没反应。
第 3 课 · 点哪里打哪里
distance 这一行读出声：地鼠到点击点的距离。

第 3 / 4 步 · 讲

30 秒倒计时

头顶同时显示剩余秒数。到 0 写出最终得分，游戏停。

为什么： while True 会卡死窗口。倒计时用 ontimer 自己叫自己，间隔 1000 毫秒。
  1. score 旁边加 time_left = 30 和 alive = True
  2. 加 tick_timer：减 1，到 0 就停
  3. done 之前 ontimer(tick_timer, 1000)
运行后你该看到： 头顶「剩余 xx 秒」往下减。到 0 出现「时间到！最终得分」。
第 3 课 · 点哪里打哪里
强调不要 while True。让全班看完 5 秒确认在减。大约 10 分钟。

第 3 / 4 步 · 打

30 秒倒计时

tick_timer 每秒减 1。末尾要 ontimer。到 0 就 return。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 3 课 · 打地鼠")
screen.bgcolor("saddlebrown")
screen.tracer(0)
score = 0
time_left = 30
alive = True
mole = turtle.Turtle()
mole.shape("turtle")
mole.color("orange")
mole.shapesize(2.2, 2.2)
mole.penup()
hud = turtle.Turtle()
hud.hideturtle()
hud.penup()
hud.color("white")

def jump_mole():
    if not alive:
        return
    x = random.randint(-320, 320)
    y = random.randint(-180, 180)
    mole.goto(x, y)
    mole.showturtle()
    screen.update()
def draw_hud():
    hud.clear()
    hud.goto(0, 240)
    hud.write(f"得分 {score}    剩余 {time_left} 秒", align="center", font=("Arial", 22, "bold"))
    screen.update()
def hit(x, y):
    global score
    if not alive:
        return
    if mole.distance(x, y) < 40:
        score = score + 1
        mole.hideturtle()
        draw_hud()
        jump_mole()
def tick_timer():
    global time_left, alive
    if not alive:
        return
    time_left = time_left - 1
    draw_hud()
    if time_left <= 0:
        alive = False
        mole.hideturtle()
        hud.goto(0, 40)
        hud.write(f"时间到！最终得分 {score}", align="center", font=("Arial", 28, "bold"))
        screen.update()
        return
    screen.ontimer(tick_timer, 1000)

draw_hud()
jump_mole()
screen.onscreenclick(hit)
screen.ontimer(tick_timer, 1000)
turtle.done()
运行后你该看到： 头顶「剩余 xx 秒」往下减。到 0 出现「时间到！最终得分」。
坑： tick_timer 末尾忘了再约自己，倒计时只跳一次。
第 3 课 · 点哪里打哪里
到 0 之后 return，不要再 ontimer。

第 4 / 4 步 · 讲

地鼠自己换洞

即使你不点，地鼠大约 1.4 秒也会自己跳一次。

为什么： 打地鼠要有紧张感。mole_wander 也是 ontimer 自己叫自己。
  1. 加 mole_wander：先 jump_mole，再约 1400 毫秒后自己
  2. 启动时 ontimer(mole_wander, 1400)
运行后你该看到： 地鼠自己会换洞。点中立刻跳；不点也会跳。30 秒结束。
第 3 课 · 点哪里打哪里
这是过关线。加码才把间隔跟分数挂钩。大约 8 分钟。
