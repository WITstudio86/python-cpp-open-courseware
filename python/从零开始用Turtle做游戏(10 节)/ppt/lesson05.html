📚 新知识

没有内置碰撞函数

自己量距离。阈值跟形状大小有关，课堂上用 25～40 试。

if player.distance(star) < 28:
    score += 1
第 5 课 · 碰一碰
自己量距离。阈值跟形状大小有关，课堂上用 25～40 试。

📚 新知识

刷新时躲开别人

星星刷在脚底下会一帧吃掉。while True 随机，直到离玩家够远。

while True:
    star.goto(随机)
    if star.distance(player) > 60:
        break
第 5 课 · 碰一碰
星星刷在脚底下会一帧吃掉。while True 随机，直到离玩家够远。

📚 新知识

多键字典

四个方向各一个 True/False，循环里谁被按住谁走。可以斜着走。

if keys['Left']:
    player.setheading(180)
    player.forward(6)

📚 新知识

两种结局都要停循环

胜利和失败都把 alive=False，tick 开头就 return。

if not alive:
    screen.update()
    return
