第 1 / 6 步 · 讲

窗口和玩家

弹出深蓝窗口，正中间有一只绿色海龟。

为什么： tracer(0) 会暂时不自动画画，所以最后要 screen.update()，否则窗口是黑的。
  1. 文件最开头写两行 import（random 等会儿用）
  2. 创建 screen，再创建 player
  3. 最后两行：screen.update() 和 turtle.done()
运行后你该看到： 800×600 深蓝窗口，正中间一只绿色海龟。这时还不会动。
第 5 课 · 碰一碰
先让每人建好 lesson5.py。random 这课还不用，但写在开头，后面就不用插到文件顶上。点运行，确认看见海龟再翻页。大约 6 分钟。

第 2 / 6 步 · 讲

方向键开走

按住方向键，海龟连续走；松开就停。

为什么： 和第 4 课篮子左右移动一样：按住改速度，tick 里每帧加上速度。今天多一个 vy 管上下。
  1. 在 player 上面加 vx = 0 和 vy = 0
  2. 删掉单独的 screen.update()，改成 6 个小函数 + tick
  3. turtle.done() 前面绑 8 次键，再 ontimer(tick, 20)
运行后你该看到： 按住方向键海龟连续移动。可以斜着走（左右和上下同时按）。
第 5 课 · 碰一碰
老师当场打 press_left 和 stop_x。其余四个让学生对着改方向。提醒：onkeypress 后面写函数名，不要加括号。大约 10 分钟。

第 2 / 6 步 · 打

方向键开走

先抄 press_left 和 stop_x，另外四个改方向。tick 末尾要 ontimer。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 5 课 · 星星收集者")
screen.bgcolor("#0d1b2a")
screen.tracer(0)
vx = 0
vy = 0
player = turtle.Turtle()
player.shape("turtle")
player.color("green")
player.shapesize(1.5, 1.5)
player.penup()
player.goto(0, 0)

def press_left():
    global vx
    vx = -6
def press_right():
    global vx
    vx = 6
def press_up():
    global vy
    vy = 6
def press_down():
    global vy
    vy = -6
def stop_x():
    global vx
    vx = 0
def stop_y():
    global vy
    vy = 0
def tick():
    player.setx(player.xcor() + vx)
    player.sety(player.ycor() + vy)
    screen.update()
    screen.ontimer(tick, 20)

screen.listen()
screen.onkeypress(press_left, "Left")
screen.onkeyrelease(stop_x, "Left")
screen.onkeypress(press_right, "Right")
screen.onkeyrelease(stop_x, "Right")
screen.onkeypress(press_up, "Up")
screen.onkeyrelease(stop_y, "Up")
screen.onkeypress(press_down, "Down")
screen.onkeyrelease(stop_y, "Down")
screen.ontimer(tick, 20)
turtle.done()
运行后你该看到： 按住方向键海龟连续移动。可以斜着走（左右和上下同时按）。
坑： 函数里改 vx 忘了写 global vx，海龟原地不动。
第 5 课 · 碰一碰
六个函数长得很像，抄完一个改数字和名字。打完先跑，能走再翻页。

第 3 / 6 步 · 讲

屏幕上的距离

再放一颗黄星星。头顶数字是你和星星的距离，走近就变小。

为什么： 没有内置碰撞函数。碰撞就是 distance 小于一个数。先把数字看在眼睛里。
  1. player 下面加 star（黄三角）和 hud（只写字，藏起来）
  2. 六个按键函数下面加 draw_hud
  3. tick 里，update 之前调用 draw_hud()
运行后你该看到： 黄三角在右上方。走动时头顶「距离 xx」变小或变大。贴上去大约是 20 多。
第 5 课 · 碰一碰
这就是以前的热身。让学生走进去看数字。问：阈值写成 5 会怎样？写成 200 会怎样？告诉他们下一步用 28。大约 8 分钟。

第 4 / 6 步 · 讲

吃星星加分

贴上星星：分数 +1，星星跳到别处。不能刷在脚底下。

为什么： 星星刷在脚底下会一帧吃掉。while True 随机，直到离玩家大于 60 再停。
  1. vx 上面加 score = 0
  2. draw_hud 上面加 place_star
  3. tick 开头写 global score；移动之后判断 distance < 28
  4. listen 之前调用一次 place_star()
运行后你该看到： 吃到黄三角，分数 +1，星星换位置。头顶同时显示分数和距离。
第 5 课 · 碰一碰
阈值 28 和 shapesize 1.5 配套，贴着就能吃到。while True 一定要有 break。大约 10 分钟。

第 4 / 6 步 · 打

第 5 / 6 步 · 讲

石头会让你失败

场上 4 颗红圆。碰到任意一颗，写出「撞到石头了」，游戏停。

为什么： 道具加分、障碍结束，都是 distance，只是阈值和后果不同。结束时要把 alive 关掉，tick 开头就 return。
  1. score 旁边加 alive = True
  2. star 下面用 for 循环做 4 颗红石头，装进 rocks 列表
  3. 加 finish(msg)，tick 开头判断 if not alive
  4. tick 里 for rock in rocks 检查距离 < 26
运行后你该看到： 四颗红圆散落。撞上去立刻出现「撞到石头了」，海龟不再动。
第 5 课 · 碰一碰
列表和第 6 课是同一句型，今天只要会 append 和 for 遍历。刷石头也要离玩家 > 80，避免一运行就失败。大约 10 分钟。

第 6 / 6 步 · 讲

满 10 颗就赢

吃满 10 颗写出「你赢了」；海龟走不出窗口。

为什么： 胜利和失败都走 finish，都要停掉 tick。边界用四条 if 夹紧，比一行 max/min 好读。
  1. draw_hud 的文字改成 星星 {score} / 10
  2. tick 里移动之后加四条边界 if
  3. 吃到星星之后再判断 if score >= 10: finish(...)
运行后你该看到： 走到窗口边缘会被挡住。吃满 10 颗出现「收集完成！你赢了」。
第 5 课 · 碰一碰

第 6 / 6 步 · 打

满 10 颗就赢

四条 if 夹紧窗口。score >= 10 时 finish 并 return。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 5 课 · 星星收集者")
screen.bgcolor("#0d1b2a")
screen.tracer(0)
score = 0
alive = True
vx = 0
vy = 0
player = turtle.Turtle()
player.shape("turtle")
player.color("green")
player.shapesize(1.5, 1.5)
player.penup()
player.goto(0, 0)
star = turtle.Turtle()
star.shape("triangle")
star.color("yellow")
star.penup()
star.goto(180, 120)
rocks = []
for _ in range(4):
    rock = turtle.Turtle()
    rock.shape("circle")
    rock.color("red")
    rock.penup()
    while True:
        rock.goto(random.randint(-320, 320), random.randint(-200, 200))
        if rock.distance(player) > 80:
            break
    rocks.append(rock)
hud = turtle.Turtle()
hud.hideturtle()
hud.penup()
hud.color("white")

def press_left():
    global vx
    vx = -6
def press_right():
    global vx
    vx = 6
def press_up():
    global vy
    vy = 6
def press_down():
    global vy
    vy = -6
def stop_x():
    global vx
    vx = 0
def stop_y():
    global vy
    vy = 0
def place_star():
    while True:
        x = random.randint(-330, 330)
        y = random.randint(-220, 200)
        star.goto(x, y)
        if star.distance(player) > 60:
            break
def draw_hud():
    hud.clear()
    hud.goto(0, 250)
    d = int(player.distance(star))
    hud.write(f"星星 {score} / 10    距离 {d}", align="center", font=("Arial", 20, "bold"))
def finish(msg):
    global alive
    alive = False
    hud.goto(0, 30)
    hud.write(msg, align="center", font=("Arial", 28, "bold"))
def tick():
    global score
    if not alive:
        screen.update()
        return
    player.setx(player.xcor() + vx)
    player.sety(player.ycor() + vy)
    if player.xcor() > 370:
        player.setx(370)
    if player.xcor() < -370:
        player.setx(-370)
    if player.ycor() > 250:
        player.sety(250)
    if player.ycor() < -270:
        player.sety(-270)
    if player.distance(star) < 28:
        score += 1
        place_star()
        if score >= 10:
            draw_hud()
            finish("收集完成！你赢了")
            screen.update()
            return
    for rock in rocks:
        if player.distance(rock) < 26:
            finish("撞到石头了")
            screen.update()
            return
    draw_hud()
    screen.update()
    screen.ontimer(tick, 20)

place_star()
screen.listen()
screen.onkeypress(press_left, "Left")
screen.onkeyrelease(stop_x, "Left")
screen.onkeypress(press_right, "Right")
screen.onkeyrelease(stop_x, "Right")
screen.onkeypress(press_up, "Up")
screen.onkeyrelease(stop_y, "Up")
screen.onkeypress(press_down, "Down")
screen.onkeyrelease(stop_y, "Down")
screen.ontimer(tick, 20)
turtle.done()

坑： 赢了却继续 ontimer，还能撞石头把胜利字盖掉。finish 之后要 return。

石头会慢慢转圈

主游戏能玩之后：在 for rock 循环里加 rock.forward(1) 和 rock.left(2)。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 5 课 · 星星收集者")
screen.bgcolor("#0d1b2a")
screen.tracer(0)
score = 0
alive = True
vx = 0
vy = 0
player = turtle.Turtle()
player.shape("turtle")
player.color("green")
player.shapesize(1.5, 1.5)
player.penup()
player.goto(0, 0)
star = turtle.Turtle()
star.shape("triangle")
star.color("yellow")
star.penup()
star.goto(180, 120)
rocks = []
for _ in range(4):
    rock = turtle.Turtle()
    rock.shape("circle")
    rock.color("red")
    rock.penup()
    while True:
        rock.goto(random.randint(-320, 320), random.randint(-200, 200))
        if rock.distance(player) > 80:
            break
    rocks.append(rock)
hud = turtle.Turtle()
hud.hideturtle()
hud.penup()
hud.color("white")

def press_left():
    global vx
    vx = -6
def press_right():
    global vx
    vx = 6
def press_up():
    global vy
    vy = 6
def press_down():
    global vy
    vy = -6
def stop_x():
    global vx
    vx = 0
def stop_y():
    global vy
    vy = 0
def place_star():
    while True:
        x = random.randint(-330, 330)
        y = random.randint(-220, 200)
        star.goto(x, y)
        if star.distance(player) > 60:
            break
def draw_hud():
    hud.clear()
    hud.goto(0, 250)
    d = int(player.distance(star))
    hud.write(f"星星 {score} / 10    距离 {d}", align="center", font=("Arial", 20, "bold"))
def finish(msg):
    global alive
    alive = False
    hud.goto(0, 30)
    hud.write(msg, align="center", font=("Arial", 28, "bold"))
def tick():
    global score
    if not alive:
        screen.update()
        return
    player.setx(player.xcor() + vx)
    player.sety(player.ycor() + vy)
    if player.xcor() > 370:
        player.setx(370)
    if player.xcor() < -370:
        player.setx(-370)
    if player.ycor() > 250:
        player.sety(250)
    if player.ycor() < -270:
        player.sety(-270)
    if player.distance(star) < 28:
        score += 1
        place_star()
        if score >= 10:
            draw_hud()
            finish("收集完成！你赢了")
            screen.update()
            return
    for rock in rocks:
        rock.forward(1)
        rock.left(2)
        if player.distance(rock) < 26:
            finish("撞到石头了")
            screen.update()
            return
    draw_hud()
    screen.update()
    screen.ontimer(tick, 20)

place_star()
screen.listen()
screen.onkeypress(press_left, "Left")
screen.onkeyrelease(stop_x, "Left")
screen.onkeypress(press_right, "Right")
screen.onkeyrelease(stop_x, "Right")
screen.onkeypress(press_up, "Up")
screen.onkeyrelease(stop_y, "Up")
screen.onkeypress(press_down, "Down")
screen.onkeyrelease(stop_y, "Down")
screen.ontimer(tick, 20)
turtle.done()
运行后你该看到： 红圆缓慢游走，仍要躲开它们。
