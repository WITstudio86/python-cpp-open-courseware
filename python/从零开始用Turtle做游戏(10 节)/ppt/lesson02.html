第 2 / 4 步 · 打

方向键开车

先抄 go_up，另外三个改 heading。绑键之前一定 listen。

import turtle

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 2 课 · 遥控小车")
screen.bgcolor("darkgreen")
car = turtle.Turtle()
car.shape("turtle")
car.color("lime")
car.shapesize(1.8, 1.8)
car.pensize(3)
car.penup()
car.goto(0, -180)
car.pendown()
car.setheading(90)

def go_up():
    car.setheading(90)
    car.forward(20)
def go_down():
    car.setheading(270)
    car.forward(20)
def go_left():
    car.setheading(180)
    car.forward(20)
def go_right():
    car.setheading(0)
    car.forward(20)

screen.listen()
screen.onkeypress(go_up, "Up")
screen.onkeypress(go_down, "Down")
screen.onkeypress(go_left, "Left")
screen.onkeypress(go_right, "Right")
turtle.done()
运行后你该看到： 方向键能开车，身后留下绿色车辙。
坑： 忘了 screen.listen()，按键完全没反应。

第 3 / 4 步 · 讲

撞墙弹回

开到窗口边缘会被拉回来并掉头。

为什么： 读 xcor / ycor 做边界。四条 if 夹紧，比一行 max/min 好读。掉头用 setheading。
  1. 加 bounce_inside，四条 if
  2. 四个开车函数末尾都调用 bounce_inside()
运行后你该看到： 开到边上会弹回来，不会开丢。

第 3 / 4 步 · 打

撞墙弹回

bounce_inside 用四条 if 夹紧。每个开车函数末尾都要调用它。

import turtle

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 2 课 · 遥控小车")
screen.bgcolor("darkgreen")
car = turtle.Turtle()
car.shape("turtle")
car.color("lime")
car.shapesize(1.8, 1.8)
car.pensize(3)
car.penup()
car.goto(0, -180)
car.pendown()
car.setheading(90)

def bounce_inside():
    if car.xcor() > 380:
        car.setx(380)
        car.setheading(180)
    if car.xcor() < -380:
        car.setx(-380)
        car.setheading(0)
    if car.ycor() > 280:
        car.sety(280)
        car.setheading(270)
    if car.ycor() < -280:
        car.sety(-280)
        car.setheading(90)
def go_up():
    car.setheading(90)
    car.forward(20)
    bounce_inside()
def go_down():
    car.setheading(270)
    car.forward(20)
    bounce_inside()
def go_left():
    car.setheading(180)
    car.forward(20)
    bounce_inside()
def go_right():
    car.setheading(0)
    car.forward(20)
    bounce_inside()

screen.listen()
screen.onkeypress(go_up, "Up")
screen.onkeypress(go_down, "Down")
screen.onkeypress(go_left, "Left")
screen.onkeypress(go_right, "Right")
turtle.done()
运行后你该看到： 开到边上会弹回来，不会开丢。
坑： 只判断左右，忘了上下，车会从顶上开出去。
第 2 课 · 方向盘
四条 if 可以一起打。每个 go_ 函数末尾加一行调用。

为什么： boost 不再转向，只 forward。reset 要 clear、回到 (0,-180)、再朝上。R 键是小写 r。
  1. 加 hud 写说明
  2. 加 boost 和 reset_car
  3. 绑 space 和 r
运行后你该看到： 空格冲得更远。按 R 车辙消失，小车回到下方。

第 4 / 4 步 · 打

冲刺和重置

空格 forward(40)。R 清轨迹并回到 (0, -180)。键名是小写 r。

import turtle

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 2 课 · 遥控小车")
screen.bgcolor("darkgreen")
car = turtle.Turtle()
car.shape("turtle")
car.color("lime")
car.shapesize(1.8, 1.8)
car.pensize(3)
car.penup()
car.goto(0, -180)
car.pendown()
car.setheading(90)
hud = turtle.Turtle()
hud.hideturtle()
hud.penup()
hud.color("white")
hud.goto(0, 250)
hud.write("方向键开车  ·  空格冲刺  ·  R 重新出发", align="center", font=("Arial", 16, "normal"))

def bounce_inside():
    if car.xcor() > 380:
        car.setx(380)
        car.setheading(180)
    if car.xcor() < -380:
        car.setx(-380)
        car.setheading(0)
    if car.ycor() > 280:
        car.sety(280)
        car.setheading(270)
    if car.ycor() < -280:
        car.sety(-280)
        car.setheading(90)
def go_up():
    car.setheading(90)
    car.forward(20)
    bounce_inside()
def go_down():
    car.setheading(270)
    car.forward(20)
    bounce_inside()
def go_left():
    car.setheading(180)
    car.forward(20)
    bounce_inside()
def go_right():
    car.setheading(0)
    car.forward(20)
    bounce_inside()
def boost():
    car.forward(40)
    bounce_inside()
def reset_car():
    car.clear()
    car.penup()
    car.goto(0, -180)
    car.pendown()
    car.setheading(90)

screen.listen()
screen.onkeypress(go_up, "Up")
screen.onkeypress(go_down, "Down")
screen.onkeypress(go_left, "Left")
screen.onkeypress(go_right, "Right")
screen.onkeypress(boost, "space")
screen.onkeypress(reset_car, "r")
turtle.done()
运行后你该看到： 空格冲得更远。按 R 车辙消失，小车回到下方。
坑： reset 里忘了 pendown，重置之后不再留车辙。

reset_car 五步：clear、penup、goto、pendown、朝上。
