第 1 / 5 步 · 讲

窗口和正方形

弹出深蓝窗口，绿色海龟走出一个正方形。

为什么： Screen 是画布，Turtle 是角色。两个都要创建。forward 走，left(90) 转直角，连走 4 次就是正方形。
  1. 文件最开头写 import turtle
  2. 先创建 screen，再创建 painter
  3. 最后一行 turtle.done()，窗口才不会闪退
运行后你该看到： 800×600 深蓝窗口，一只绿色海龟画出正方形后停在起点附近。
第 1 课 · 海龟登场

第 1 / 5 步 · 打

窗口和正方形

从 import 写到 turtle.done()。forward(100) 和 left(90) 连写 4 次。

import turtle

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 1 课 · 彩虹点击画家")
screen.bgcolor("navy")
painter = turtle.Turtle()
painter.shape("turtle")
painter.color("lime")
painter.forward(100)
painter.left(90)
painter.forward(100)
painter.left(90)
painter.forward(100)
painter.left(90)
painter.forward(100)
painter.left(90)
turtle.done()
运行后你该看到： 800×600 深蓝窗口，一只绿色海龟画出正方形后停在起点附近。
坑： 忘了 turtle.done()，窗口闪一下就关。
第 1 课 · 海龟登场
四次 forward + left 可以一起打。跑起来看见正方形再翻页。

第 2 / 5 步 · 讲

抬笔再盖章

海龟抬笔，在三个位置各盖一个章，不拖线。

为什么： 画画游戏一开始就要 penup。stamp 只印形状，不走线。goto 是瞬移。
  1. 正方形那 8 行删掉，改成 penup
  2. goto 三个点，每个点 stamp 一次
运行后你该看到： 屏幕上并排三只绿色海龟章，中间没有连线。
第 1 课 · 海龟登场
对比上一步的正方形线。问 penup 和 pendown 的区别。大约 6 分钟。

第 2 / 5 步 · 打

抬笔再盖章

先 penup，再 goto 三个点各 stamp 一次。

import turtle

screen = turtle.Screen()

painter.penup()
painter.goto(-120, 0)
painter.stamp()

第 3 / 5 步 · 讲

点哪里盖哪里

鼠标点画面，海龟走到那里盖一个章。

为什么： onscreenclick 会调用你的函数，并传入 x, y。函数名不要加括号，否则会立刻执行。
  1. 三个 stamp 删掉，改成 paint 函数
  2. turtle.done() 前面写 screen.onscreenclick(paint)
运行后你该看到： 点击画面，点一下盖一只绿色海龟。
第 1 课 · 海龟登场
强调函数名不加括号。让每人点 5 下确认。大约 8 分钟。

第 3 / 5 步 · 打

点哪里盖哪里

写 paint(x, y)：goto 再 stamp。onscreenclick 后面写函数名，不要加括号。

import turtle

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 1 课 · 彩虹点击画家")
screen.bgcolor("navy")
painter = turtle.Turtle()
painter.shape("turtle")
painter.color("lime")
painter.penup()

def paint(x, y):
    painter.goto(x, y)
    painter.stamp()

screen.onscreenclick(paint)
turtle.done()
运行后你该看到： 点击画面，点一下盖一只绿色海龟。
坑： 写成 onscreenclick(paint())，加括号会立刻调用，点击没反应。
第 1 课 · 海龟登场
paint 只要两行：goto 和 stamp。

第 4 / 5 步 · 讲

空格换颜色

按空格，下一笔换成调色盘里的下一种颜色。

为什么： 颜色放进列表，用下标取。% len 可以循环取，不会越界。键盘事件之前必须 listen。
  1. painter 上面加 PALETTE 列表和 color_index = 0
  2. 加 next_color，里面要写 global color_index
  3. listen 之后绑空格
运行后你该看到： 点几下是红色；按空格再点，变成橙色，再按变成黄色。
第 1 课 · 海龟登场
调色盘 6 种颜色读一遍。空格的名字是 space。大约 8 分钟。

第 4 / 5 步 · 打

空格换颜色

加上调色盘。next_color 里 global color_index。空格键名字是 space。

import turtle

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 1 课 · 彩虹点击画家")
screen.bgcolor("navy")
PALETTE = ["red", "orange", "yellow", "lime", "cyan", "violet"]
color_index = 0
painter = turtle.Turtle()
painter.shape("turtle")
painter.color(PALETTE[0])
painter.penup()

def paint(x, y):
    painter.goto(x, y)
    painter.stamp()

def next_color():
    global color_index
    color_index = color_index + 1
    painter.color(PALETTE[color_index % len(PALETTE)])

screen.onscreenclick(paint)
screen.listen()
screen.onkeypress(next_color, "space")
turtle.done()
运行后你该看到： 点几下是红色；按空格再点，变成橙色，再按变成黄色。
坑： 改 color_index 忘了 global，颜色一直不变。
第 1 课 · 海龟登场
PALETTE 一行一个颜色，好打。% len(PALETTE) 一起抄。

第 5 / 5 步 · 讲

随机朝向和清屏

每次盖章朝向随机；按 C 清掉所有章；头顶有操作说明。

为什么： setheading 随机 0～360，章不会都朝一个方向。clear 只擦章，不关窗口。C 键名字是小写 c。
  1. 开头加 import random
  2. paint 里 stamp 之前 setheading
  3. 加 hud 写说明，加 clear_canvas，绑到 c
运行后你该看到： 点击盖的海龟朝向各不相同。按 C 画面清空，头顶字还在。

第 5 / 5 步 · 打

随机朝向和清屏

paint 里加 setheading。清屏绑小写 c。头顶写一行说明。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 1 课 · 彩虹点击画家")
screen.bgcolor("navy")
PALETTE = ["red", "orange", "yellow", "lime", "cyan", "violet"]
color_index = 0
painter = turtle.Turtle()
painter.shape("turtle")
painter.color(PALETTE[0])
painter.penup()
hud = turtle.Turtle()
hud.hideturtle()
hud.penup()
hud.color("white")
hud.goto(0, 250)
hud.write("点击盖章  ·  空格换色  ·  C 清屏", align="center", font=("Arial", 18, "normal"))

def paint(x, y):
    painter.goto(x, y)
    painter.setheading(random.randint(0, 360))
    painter.stamp()

def next_color():
    global color_index
    color_index = color_index + 1
    painter.color(PALETTE[color_index % len(PALETTE)])

def clear_canvas():
    painter.clear()

screen.onscreenclick(paint)
screen.listen()
screen.onkeypress(next_color, "space")
screen.onkeypress(clear_canvas, "c")
turtle.done()
运行后你该看到： 点击盖的海龟朝向各不相同。按 C 画面清空，头顶字还在。
坑： 绑成大写 C，按 C 没反应。键盘名字区分大小写。
第 1 课 · 海龟登场
hud 四行：hideturtle、penup、color、goto 再 write。

点击盖一朵花

主游戏能玩之后：paint 里不要只 stamp 一次，转 8 次盖 8 瓣。

import turtle
import random

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 1 课 · 彩虹点击画家")
screen.bgcolor("navy")
PALETTE = ["red", "orange", "yellow", "lime", "cyan", "violet"]
color_index = 0
painter = turtle.Turtle()
painter.shape("turtle")
painter.color(PALETTE[0])
painter.penup()
hud = turtle.Turtle()
hud.hideturtle()
hud.penup()
hud.color("white")
hud.goto(0, 250)
hud.write("点击盖章  ·  空格换色  ·  C 清屏", align="center", font=("Arial", 18, "normal"))

def paint(x, y):
    painter.goto(x, y)
    for _ in range(8):
        painter.stamp()
        painter.left(45)

def next_color():
    global color_index
    color_index = color_index + 1
    painter.color(PALETTE[color_index % len(PALETTE)])

def clear_canvas():
    painter.clear()

screen.onscreenclick(paint)
screen.listen()
screen.onkeypress(next_color, "space")
screen.onkeypress(clear_canvas, "c")
turtle.done()
运行后你该看到： 点一下出现一圈海龟，像一朵花。
分层： 没做完主游戏不要跳到加码。
