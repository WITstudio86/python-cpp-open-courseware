📚 新知识

速度拆成两个方向

海龟对象上可以自己挂 dx、dy。每帧加到 x、y 上，就是在飞。

ball.dx = 4
ball.dy = 3
ball.setx(ball.xcor() + ball.dx)
第 8 课 · 对打
海龟对象上可以自己挂 dx、dy。每帧加到 x、y 上，就是在飞。

📚 新知识

卡墙是经典 bug

反弹时先 sety 拉回场内，再 dy *= -1。否则下一帧还在墙外，会疯狂闪烁。

if ball.ycor() > 280:
    ball.sety(280)
    ball.dy *= -1
第 8 课 · 对打
反弹时先 sety 拉回场内，再 dy *= -1。否则下一帧还在墙外，会疯狂闪烁。

📚 新知识

打到挡板就加速

abs(dx)+0.3 再带上方向。后期会非常刺激，注意别快到看不清。

ball.dx = abs(ball.dx) + 0.3
第 8 课 · 对打
abs(dx)+0.3 再带上方向。后期会非常刺激，注意别快到看不清。

📚 新知识

自定义属性完全合法

ball.dx 不是官方方法，是我们挂上去的数字。海龟也是普通对象。

ball.dx = 4
ball.dy = 3
