第 1 / 5 步 · 讲

挡板和球

两块白挡板，中间一颗黄球自己飞。

为什么： 速度拆成 ball_dx、ball_dy。每帧加到 x、y 上，就是在飞。
  1. 创建 left、right、ball
  2. ball_dx = 4，ball_dy = 3
  3. tick 里球加 dx dy，再 update、ontimer
运行后你该看到： 黄球斜着飞出窗口。挡板还不会动。
第 8 课 · 对打
这就是热身舞台。大约 6 分钟。

第 1 / 5 步 · 打

挡板和球

挡板放 x=-350 和 350。tick 里球加 ball_dx 和 ball_dy。

import turtle

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 8 课 · 乒乓球大战")
screen.bgcolor("navy")
screen.tracer(0)
left = turtle.Turtle()
left.shape("square")
left.color("white")
left.shapesize(5, 0.8)
left.penup()
left.goto(-350, 0)
right = turtle.Turtle()
right.shape("square")
right.color("white")
right.shapesize(5, 0.8)
right.penup()
right.goto(350, 0)
ball = turtle.Turtle()
ball.shape("circle")
ball.color("yellow")
ball.penup()
ball_dx = 4
ball_dy = 3

def tick():
    global ball_dx, ball_dy
    ball.setx(ball.xcor() + ball_dx)
    ball.sety(ball.ycor() + ball_dy)
    screen.update()
    screen.ontimer(tick, 16)

screen.ontimer(tick, 16)
turtle.done()
运行后你该看到： 黄球斜着飞出窗口。挡板还不会动。
坑： tick 忘了 global ball_dx，下一步反弹会报错。
第 8 课 · 对打
两块挡板 shapesize(5, 0.8) 是竖条。

第 2 / 5 步 · 讲

上下墙壁反弹

球碰到上下边会掉头，先拉回场内再取反。

为什么： 反弹时先 sety 拉回，再 dy 乘 -1。否则下一帧还在墙外，会疯狂闪烁。
  1. tick 里两段 if：y>280 和 y<-280
  2. 先 sety，再 ball_dy = ball_dy * -1
运行后你该看到： 球在上下边来回弹。左右还是会飞出去。
第 8 课 · 对打
让学生盯着上边看一眼。大约 6 分钟。

第 3 / 5 步 · 讲

挡板能打

左边 W/S，右边方向键。球碰到挡板就掉头。

为什么： 八个小函数管两个人的速度。挡板碰撞也是 distance。打到后把球拉回场内。
  1. 加 left_v、right_v 和八个按键函数
  2. tick 里移动挡板，四条 if 夹紧
  3. 球靠近挡板则 dx 掉头
运行后你该看到： 两人能上下移动挡板，把球打回去。
第 8 课 · 对打
老师打 press_w / stop_w，其余让学生改。键名 w/s 小写，Up/Down 大写。大约 12 分钟。

第 3 / 5 步 · 打

挡板能打

左边 w/s，右边 Up/Down。碰到挡板先 setx 拉回，再改 ball_dx。

import turtle

screen = turtle.Screen()
screen.setup(800, 600)
screen.title("第 8 课 · 乒乓球大战")
screen.bgcolor("navy")
screen.tracer(0)
left_v = 0
right_v = 0
left = turtle.Turtle()
left.shape("square")
left.color("white")
left.shapesize(5, 0.8)
left.penup()
left.goto(-350, 0)
right = turtle.Turtle()
right.shape("square")
right.color("white")
right.shapesize(5, 0.8)
right.penup()
right.goto(350, 0)
ball = turtle.Turtle()
ball.shape("circle")
ball.color("yellow")
ball.penup()
ball_dx = 4
ball_dy = 3

def press_w():
    global left_v
    left_v = 7
def stop_w():
    global left_v
    left_v = 0
def press_s():
    global left_v
    left_v = -7
def stop_s():
    global left_v
    left_v = 0
def press_up():
    global right_v
    right_v = 7
def stop_up():
    global right_v
    right_v = 0
def press_down():
    global right_v
    right_v = -7
def stop_down():
    global right_v
    right_v = 0
def tick():
    global ball_dx, ball_dy
    left.sety(left.ycor() + left_v)
    if left.ycor() > 230:
        left.sety(230)
    if left.ycor() < -230:
        left.sety(-230)
    right.sety(right.ycor() + right_v)
    if right.ycor() > 230:
        right.sety(230)
    if right.ycor() < -230:
        right.sety(-230)
    ball.setx(ball.xcor() + ball_dx)
    ball.sety(ball.ycor() + ball_dy)
    if ball.ycor() > 280:
        ball.sety(280)
        ball_dy = ball_dy * -1
    if ball.ycor() < -280:
        ball.sety(-280)
        ball_dy = ball_dy * -1
    if ball.xcor() < -330 and left.distance(ball) < 70:
        ball.setx(-330)
        ball_dx = 4
    if ball.xcor() > 330 and right.distance(ball) < 70:
        ball.setx(330)
        ball_dx = -4
    screen.update()
    screen.ontimer(tick, 16)

screen.listen()
screen.onkeypress(press_w, "w")
screen.onkeyrelease(stop_w, "w")
screen.onkeypress(press_s, "s")
screen.onkeyrelease(stop_s, "s")
screen.onkeypress(press_up, "Up")
screen.onkeyrelease(stop_up, "Up")
screen.onkeypress(press_down, "Down")
screen.onkeyrelease(stop_down, "Down")
screen.ontimer(tick, 16)
turtle.done()
运行后你该看到： 两人能上下移动挡板，把球打回去。
坑： 两套键绑到同一块挡板，两人会抢。
第 8 课 · 对打
八个函数长得很像。挡板夹紧用 230。

第 4 / 5 步 · 讲

出界得分

球飞出左边，右边 +1 分并重置中场。飞出右边相反。

为什么： 出界不要让球飞丢。reset_ball 回 (0,0)，direction 决定下一次朝哪边开。
  1. 加 left_score、right_score、hud、reset_ball
  2. x < -390 右边得分；x > 390 左边得分
运行后你该看到： 头顶出现比分。球飞出一侧，对面得分，球回中间。
第 8 课 · 对打
飞出右边界给左边加分，别弄反。大约 8 分钟。

第 5 / 5 步 · 讲

先到 5 分获胜

谁先到 5 分写出获胜；挡板打到后球会稍微加速。

为什么： 和第 5 课一样：finish 关掉 alive，tick 开头 return。加速用 abs(dx)+0.3。
  1. 加 alive 和 finish
  2. 得分之后判断 >= 5
  3. 挡板反弹改成 abs(ball_dx)+0.3
运行后你该看到： 头顶「先到 5 分」。打到后面球越来越快。有人到 5 出现获胜字。
第 8 课 · 对打
这是过关线。找两人上来打一局。大约 8 分钟。

        reset_ball(-1)

    if ball.xcor() > 330 and right.distance(ball) < 70:
        ball.setx(330)
        ball_dx = -(abs(ball_dx) + 0.3)
    if ball.xcor() < -390:
        right_score = right_score + 1
        reset_ball(1)
        if right_score >= 5:
            draw_hud()
            finish("右边获胜！")
            screen.update()
            return
    if ball.xcor() > 390:
        left_score = left_score + 1
        reset_ball(-1)
        if left_score >= 5:
            draw_hud()
            finish("左边获胜！")
            screen.update()
            return
    draw_hud()
    screen.update()
    screen.ontimer(tick, 16)
