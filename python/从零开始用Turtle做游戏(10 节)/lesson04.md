## 🎯 本课目标

- 理解游戏循环：每一小帧更新位置，再画出来
- 会 `tracer(0)` + `update()` 消掉一帧一帧的闪
- 会用按键「按下/松开」控制连续移动

## 📚 新知识

### 4.1 游戏循环长这样

```python
screen.tracer(0)   # 先别自动刷新

def tick():
    coin.sety(coin.ycor() - 5)
    screen.update()
    screen.ontimer(tick, 20)

tick()
```

每 20 毫秒跑一圈。这就是「动画」。

### 4.2 按住方向键

```python
vx = 0
def press_left():
    global vx
    vx = -8
def stop():
    global vx
    vx = 0
```

`onkeypress` 开始动，`onkeyrelease` 停下。否则点一下只挪一点点。
