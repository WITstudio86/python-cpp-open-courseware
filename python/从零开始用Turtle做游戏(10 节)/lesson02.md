## 📚 新知识

### 2.1 键盘三件套

```python
def go_up():
    car.setheading(90)
    car.forward(20)

screen.listen()
screen.onkeypress(go_up, "Up")
```

忘了 `listen()`，按键完全没反应——这是本课第一大坑。

### 2.2 朝向

| 键 | heading | 含义 |
|----|---------|------|
| 右 | 0 | 正东 |
| 上 | 90 | 正北 |
| 左 | 180 | 正西 |
| 下 | 270 | 正南 |

### 2.3 不要开出窗外

```python
if car.xcor() > 380:
    car.setx(380)
    car.setheading(180)
```

碰到右边就朝左弹。四个边同理。
