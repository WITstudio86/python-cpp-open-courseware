## 🎯 本课目标

- 会给球两个速度分量 `dx` / `dy`
- 会「撞墙就把那一轴速度取反」
- 会给两个玩家绑两套键
- **主游戏：乒乓球大战**

---

## 📚 新知识

### 8.1 速度拆成两个方向

```python
ball.dx = 4
ball.dy = 3
ball.setx(ball.xcor() + ball.dx)
ball.sety(ball.ycor() + ball.dy)
```

海龟对象上可以自己挂属性。`dx` 不是官方 API，是我们发明的。

### 8.2 反弹

```python
if ball.ycor() > 280:
    ball.dy *= -1
```

乘 `-1` 就是掉头。左右挡板同理，把 `dx` 取反，并加一点点速度。

### 8.3 出界得分

球的 `x` 超出左右边界，对面得分，球回中场。不要让球飞到看不见的地方还不重置。

## 🔥 热身

不要挡板。球在四壁之间弹。确认 `tracer(0)` 下是平滑的。

**课堂提问：** 只把 `dy *= -1`、永远不改 `dx`，球会走出什么轨迹？
