## 📚 新知识

### 3.1 随机闪现

```python
import random
mole.goto(random.randint(-320, 320), random.randint(-180, 180))
```

窗口大约是 ±400 × ±300，地鼠不要贴边。

### 3.2 点中了吗？

```python
def hit(x, y):
    if mole.distance(x, y) < 40:
        print("打中")
```

`distance` 既可以测两只海龟，也可以测一个点 `(x, y)`。

### 3.3 过一会儿再做

```python
def tick():
    ...
    screen.ontimer(tick, 1000)  # 1000 毫秒后再调用自己
```

这就是「闹钟」。倒计时、地鼠换洞，都靠它。不要写 `while True` 卡死窗口。
