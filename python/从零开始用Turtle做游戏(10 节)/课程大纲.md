# 从零开始用 Turtle 做游戏 · 10 节课

面向刚学完基础语法、想立刻做出「能玩的东西」的学习者。10 节课只用 Python 自带的 `turtle`，**每节课交出一个可玩的小游戏**。

**课时：每节 90 分钟。** 每节课都有热身、主游戏、加码挑战。慢的同学主游戏能玩就算过关，快的同学做加码。

配套材料：

- `ppt/` 课堂课件（键盘左右翻页）
- `lesson01.md` ~ `lesson10.md` 教案（含 90 分钟流程）
- `code/` 完整可运行的小游戏
- `打印/` A4 学案（建议双面打印，约 2 页/课）

不需要安装 Pygame。终端里 `python3 code/lesson1.py` 就能开窗口。

## 90 分钟课堂节奏（每节通用）

| 时间 | 环节 | 教师做什么 | 学生做什么 |
|------|------|------------|------------|
| 0–10 分 | 开场 / 复习 | 第 1 课讲 turtle 是什么；之后课用上节游戏口答 3 题 | 打开 VS Code，建好本课文件 |
| 10–35 分 | 新知识 + 热身 | 课件讲解，带打 10 行热身 | 跟打、运行、看到海龟动 |
| 35–65 分 | 主游戏 | 拆成 4～6 步，一步一运行 | 跟做本课小游戏，改颜色/速度 |
| 65–82 分 | 加码挑战 | 巡堂，给先完成的人加码题 | 做加码；没做完主游戏的继续 |
| 82–90 分 | 学案 + 小结 | 对答案、抽人讲一个 API | 填学案、写收获、听下节预告 |

验收：**主游戏窗口能打开，按说明能玩** 就算本课过关。加码不是全班必须完成。

## 设计原则

1. **每课一个能玩的 demo**：下课学生能把窗口打开给别人玩。
2. **只靠标准库**：`turtle` + `random`，不装第三方。
3. **动画用 `ontimer`，不用死循环**：`while True` 会把窗口卡死，这是本课反复强调的坑。
4. **技能叠罗汉**：点击 → 键盘 → 循环 → 碰撞 → 列表 → 状态机，第 10 课全部用上。
5. **可打印**：学案 2 页 A4（知识点 + 任务单 + 改错 + 填空）。
