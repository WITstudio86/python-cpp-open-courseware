一、本课目标（90 分钟）

学会 distance 碰撞、多种角色、胜负。过关：主项目「星星收集者」能运行。加码选做。

时间环节
0–10开场 / 复习
10–35新知识 + 热身
35–65主项目跟做
65–82加码（选做）
82–90学案填空 + 小结

二、知识点速查（可剪下来当小抄）

名称意思写法 / 例子
distance(海龟)两角色距离player.distance(star)
阈值像素半径< 28 算吃到
胜利score >= 10写一句你赢了
失败碰到石头立刻 return 停循环
penup障碍不要拖线石头也要抬笔

三、热身（10–35 分）

热身：打印距离 — 键盘动一只，write 实时显示 distance。走近看数字变小。

  • 自己把热身代码打一遍并运行
  • 对照输出，和同桌讲清「刚才那一行在干什么」

四、主项目任务单（35–65 分）

项目名称：星星收集者　配套代码：code/lesson5.py

方向键移动绿色海龟。 吃黄三角 +1，吃满 10 胜利。 碰到红圆石头立刻结束。
  • 玩家 / 星星 / 4 颗石头，全部 penup
  • tick 里按 keys 移动，并夹紧在窗口内
  • 靠近星星：加分并 place_star；满 10 胜利
  • 靠近任一块石头：失败并停止 tick

五、加码（65–82 分，选做）

加码：石头会动

每帧 rock.forward(1); rock.left(2)。也要 penup。

  • 主项目还没跑通 → 继续主项目，不要跳到加码
  • 主项目已跑通 → 做加码，改成自己的数据
