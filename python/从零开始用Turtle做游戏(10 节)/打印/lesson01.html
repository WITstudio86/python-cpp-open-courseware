学会 Screen、Turtle、前进转弯、盖章、点击。过关：主项目「彩虹点击画家」能运行。加码选做。

二、知识点速查（可剪下来当小抄）

名称意思写法 / 例子
import turtle标准库，不用 pipimport turtle
Screen()窗口screen.setup(800, 600)
Turtle()角色t.shape("turtle")
stamp()盖章不拖线先 penup 再 stamp
onscreenclick(fn)点击fn(x, y)
turtle.done()保持窗口写在最后

三、热身（10–35 分）

热身：正方形 + 三角形 — forward + left(90) 走 4 次；再 left(120) 走 3 次。先别写点击。

  • 自己把热身代码打一遍并运行
  • 对照输出，和同桌讲清「刚才那一行在干什么」

四、主项目任务单（35–65 分）

项目名称：彩虹点击画家　配套代码：code/lesson1.py

窗口弹出后： 点击画面 → 盖一只彩色小海龟 空格 → 换颜色 C → 清屏
  • 创建 screen 和 painter，penup、shape('turtle')
  • 写 paint(x,y)：goto + 随机朝向 + stamp
  • onscreenclick(paint)，空格换色，C 清屏
  • 最后 turtle.done()，运行后点几下确认

五、加码（65–82 分，选做）

加码：点击盖一朵花

点一下不要只 stamp 一次，转 8 次盖 8 瓣。

  • 主项目还没跑通 → 继续主项目，不要跳到加码
  • 主项目已跑通 → 做加码，改成自己的数据
