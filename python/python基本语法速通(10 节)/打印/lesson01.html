二、知识点速查（可剪下来当小抄）

名称意思写法 / 例子
print()在屏幕上显示内容print("你好")
字符串用引号包住的文字"Python" 或 'Python'
注释# 后的文字不执行# 这是注释

三、热身（10–35 分）

热身：print 的六种玩法 — 多参数、sep、数字算式、字符串乘法、\n/\t、end 不换行。跟打 10 分钟。

  • 自己把热身代码打一遍并运行
  • 对照输出，和同桌讲清「刚才那一行在干什么」

四、主项目任务单（35–65 分）

项目名称：个性签名海报　配套代码：code/lesson1.py

==================== ★ 我的名片 ★ ==================== 姓名：小明 ...
  • 新建 lesson1.py 并保存
  • 用 print("=" * 36) 画上下边框
  • 打印姓名、学校、爱好、座右铭（改成自己的）
  • 运行，检查终端里的海报是否整齐

五、加码（65–82 分，选做）

加码：ASCII 小房子 + 课程表

用 print 画房子；再用 \t 打一周课程表。改成自己的课表。

  • 主项目还没跑通 → 继续主项目，不要跳到加码
  • 主项目已跑通 → 做加码，改成自己的数据
