二、知识点速查（可剪下来当小抄）

名称意思写法 / 例子

三、热身（10–35 分）

热身：变量三连 — 赋值、重新赋值、字符串用 + 拼接。体会盒子里的东西能被换掉。

  • 自己把热身代码打一遍并运行
  • 对照输出，和同桌讲清「刚才那一行在干什么」

四、主项目任务单（35–65 分）

项目名称：自我介绍生成器　配套代码：code/lesson2.py

你叫什么名字？ 小明 你今年几岁？ 12 ... 大家好，我叫 小明！ 今年 12 岁，来自 上海。
  • 用 input 问姓名、年龄、城市、爱好、食物
  • 每个答案都赋给一个变量
  • 用 f-string 拼出 3～4 句自我介绍
  • 运行并自己当一次用户

五、加码（65–82 分，选做）

加码：故事填空机

收集名字、地点、物品、形容词、动词，生成一段小故事。

  • 主项目还没跑通 → 继续主项目，不要跳到加码
  • 主项目已跑通 → 做加码，改成自己的数据

八、改一改（写在纸上或改代码）

  1. 加问题：再问一个梦想并写进介绍
  2. 改提示：把提示语写得更俏皮
  3. 嵌变量：print(f"{name} 来自 {city}")
  4. 对照：故意不赋值，看输入会丢
  5. 挑战：落款写成「来自{city}的{name}」
  6. 故事机：加码故事再加一个「反派名字」字段
  7. 名片落款：最后一行改成「——来自{city}的{name}」
