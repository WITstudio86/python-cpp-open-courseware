二、知识点速查（可剪下来当小抄）

名称意思写法 / 例子
while 条件:条件为 True 就重复记得更新，否则死循环
break立刻结束整个循环猜对就 break
continue结束本圈，进入下一圈非法输入不扣次数
randint(a,b)随机整数，含 a 和 brandom.randint(1, 100)

三、热身（10–35 分）

热身：倒计时 + 口令 go — while n>0 倒数；while word!='go' 直到输入正确。

  • 自己把热身代码打一遍并运行
  • 对照输出，和同桌讲清「刚才那一行在干什么」

四、主项目任务单（35–65 分）

项目名称：猜数字游戏　配套代码：code/lesson8.py

第 1 次，请猜：50 太小了 ⬆ 第 2 次，请猜：75 太大了 ⬇ ... 猜对了！
  • secret = random.randint(1, 100)
  • while tries < 7：读入猜测
  • 非数字 continue；猜对 break
  • 提示太大/太小；用完次数公布答案
