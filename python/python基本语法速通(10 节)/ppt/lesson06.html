📚 新知识

elif 是否则如果

从上往下检查，命中一个就停止。宽条件不要写在最前面。

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")

📚 新知识

顺序比你想的更重要

从上往下，命中一个就停。宽条件（>=60）一定写在窄条件（>=90）后面。

# 错误示范：95 会变成及格
if score >= 60:
    print('及格')
elif score >= 90:
    print('优秀')

🐞 改错时刻

这几类错，课上必踩

❌ 先写 >=60 再写 >=90

✅ 高分档必须在前

❌ elif 单独出现

✅ elif 必须跟在 if 后面
没有 if 不能直接 elif

❌ 三个独立 if 当多路

✅ 用 if/elif/else
独立 if 可能走好几路
