📚 新知识

for 还是 while

次数已知用 for；「猜对才停」用 while。三件套：初始、条件、更新。

n = 1
while n <= 5:
    print(n)
    n = n + 1

次数已知用 for；「猜对才停」用 while。三件套：初始、条件、更新。

📚 新知识

break 与 continue

break 下车；continue 跳过本圈后半段。while True 靠 break 出来。

if guess == secret:
    break
if not raw.isdigit():
    continue

📚 新知识

再来一局：外层再套 while

内层一局游戏，外层问 y/n。两层循环不要怕。

again = 'y'
while again == 'y':
    # 玩一局
    again = input('再来？')
