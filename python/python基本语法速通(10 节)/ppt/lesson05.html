📚 新知识

if / else 二选一

条件写在 if 后面，记得冒号。两路只走一路。

if age < 18:
    print("学生票")
else:
    print("成人票")

缩进是语法

少空格或多空格都会报 IndentationError。Tab 在 VS Code 里一般等于 4 空格。

    print("对了")

📚 新知识

缩进决定「属于谁」

属于 if 的句子必须缩进。通常 4 个空格。少一格都会报错。

if age < 18:
    print('学生票')
    price = 25
else:
    print('成人票')
第 5 课 · 程序会选择了
属于 if 的句子必须缩进。通常 4 个空格。少一格都会报错。

🐞 改错时刻

这几类错，课上必踩

❌ if age < 18

✅ if age < 18:
漏了冒号

❌ if age < 18: print('未成年')

✅ 第二行缩进 4 格
缩进是语法，不是好看

❌ if day = 'y'

✅ if day == 'y'
判断相等必须 ==
