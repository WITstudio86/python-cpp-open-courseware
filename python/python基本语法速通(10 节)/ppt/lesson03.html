📚 新知识

为什么必须转换

'12' 和 12 对 Python 完全不是一回事。要算数，先换身份证。

a = '12'
# print(a + 1)   报错
print(int(a) + 1)  # 13

📚 新知识

小数怎么留一位

{bmi:.1f} 表示保留 1 位小数。:.2f 就是 2 位。

bmi = 19.531
print(f"{bmi:.1f}")  # 19.5

🐞 改错时刻

这几类错，课上必踩

❌ age = input("年龄：") print(age + 1)

✅ age = int(input(...))
input 是字符串，要先 int()

❌ int('3.5')

✅ float('3.5') 或 int(float('3.5'))
带小数点的文字不能直接 int

❌ true

✅ True
布尔值首字母必须大写
