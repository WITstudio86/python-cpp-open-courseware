# Python 基本语法速通 · 10 节课

面向完全零基础的学习者。10 节课过一遍 Python 最常用的语法：**输入输出、数据类型、运算符号、判断、循环、列表**。

**课时：每节 90 分钟。** 每节课都有热身练习、主项目、加码挑战，慢的同学完成主项目即达标，快的同学做加码，整节课都能转起来。

配套材料：

- `ppt/` 课堂课件（键盘左右翻页）
- `lesson01.md` ~ `lesson10.md` 教案（含 90 分钟流程）
- `code/` 完整代码（热身 + 主项目 + 加码，三段式）
- `打印/` A4 学案（建议双面打印，约 2 页/课）

---

## 90 分钟课堂节奏（每节通用）

| 时间 | 环节 | 教师做什么 | 学生做什么 |
|------|------|------------|------------|
| 0–10 分 | 开场 / 复习 | 第 1 课装环境；之后课用 3 道口答题复习上节 | 打开 VS Code，建好本课文件 |
| 10–35 分 | 新知识 + 热身 | 课件讲解，带打热身代码 | 跟打、运行、对照输出 |
| 35–65 分 | 主项目 | 拆成 4～6 步，一步一运行 | 跟做主项目，改成自己的数据 |
| 65–82 分 | 加码挑战 | 巡堂，给先完成的人加码题 | 做加码；没做完主项目的继续主项目 |
| 82–90 分 | 学案 + 小结 | 对答案、抽人讲一个知识点 | 填学案、写收获、听下节预告 |

验收：**主项目能独立运行** 就算本课过关。加码是给吃得快的学生，不是全班必须完成。

## 设计原则

1. **项目制，但不止一个项目**：热身练手感，主项目当堂交付，加码拉开层次。
2. **只学会用的**：不讲函数定义、文件读写、字典、面向对象。
3. **可打印**：学案 2 页 A4（知识点 + 任务单 + 改错 + 填空），课堂上发纸就能用。
4. **能演示**：全部是命令行程序，安装 Python 后即可运行。
