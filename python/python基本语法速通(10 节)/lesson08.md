## 🎯 本课目标

- while 三件套：初始、条件、更新
- `break` 下车；`continue` 跳过本圈后半段
- 外层 while 做「再来一局」
- 主项目：猜数字；加码：密码、累加器

---

## 📚 新知识

次数已知 → for；「直到某事发生」→ while。

忘了更新 → 死循环。演示：故意注释掉 `n = n - 1`，用 Ctrl+C 停。

`while True` 必须有 break。非法输入 `continue` 不扣次数。

---

## 🔥 热身

1. 从 n 倒数到 1，再打印「发射」  
2. 直到输入 `go` 才继续

---

## 💻 主项目：猜数字

1–100，7 次；非数字 / 超范围不扣次数；猜对按次数给评语；问是否再来一局。

见 `code/lesson8.py`。

---

## 🚀 加码

1. 密码最多 3 次，全错锁定  
2. 输入数字累加，0 结束，打印个数和平均；可拒绝负数

---

## 🐞 改错

1. while 里不更新  
2. break / continue 用反  
3. while True 没有出口

---

2. 评语文案改成自己的  
3. 累加器拒绝负数  
4. 密码改成自己的生日数字
