# 第 10 课 · 语法大综合 — 班级成绩统计台

**时长 90 分钟。** 过关：能录入一组成绩并打印人数、平均、最高、及格率。

---

## ⏱️ 90 分钟流程

| 时间 | 环节 | 做什么 |
|------|------|--------|
| 0–10 分 | 复习 | 列表下标、while True、elif 顺序 |
| 10–35 分 | 热身 | 固定 5 个成绩手算 + 程序算，对上 73.8 |
| 35–65 分 | 主项目 | 自己录入，逐人报告 + 全班统计 |
| 65–82 分 | 加码 | 条形图 + 低于平均分 |
| 82–90 分 | 结业 | 学案、清点 10 课技能、推荐下一门课 |

---

## 🎯 本课目标

- 把 1–9 课拼在一条流水线：录入 → 存放 → 遍历统计 → 报告
- 三种套路：累加器、擂台、计数
- 主项目：成绩统计台；加码：条形图、低于平均分

没有新的大语法。

---

## 📚 三种套路

```python
total = 0
highest = scores[0]
passed = 0
for s in scores:
    total = total + s
    if s > highest:
        highest = s
    if s >= 60:
        passed = passed + 1
avg = total / len(scores)
```

哨兵 `-1` 表示录入结束，不当作成绩。非法分数 `continue`。

优秀（≥90）也要算进及格人数。

---

## 🔥 热身

对 `[88, 57, 91, 73, 60]` 先手算：

- 人数 5，总分 369，平均 73.8
- 最高 91，最低 57，及格 4 人

再运行热身代码核对。对不上就不要进入主项目。

---

## 💻 主项目：班级成绩统计台

录入到 -1；逐人优秀/良好/及格/不及格；全班统计；最高分是第几位；及格/不及格两个列表。

见 `code/lesson10.py`。建议先用与热身相同的 5 个数，对上再换自己班的。

---

## 🚀 加码

1. 条形图：每 5 分一颗 ★  
2. 列出低于平均分的座位号

---

## 🐞 改错

1. `avg = total / scores`  
2. `highest = 0`（全是负数会错；空列表会崩）  
3. 优秀没有算进及格

2. 平均保留 2 位  
3. ★ 改成 █  
4. 全班不及格时打印一句鼓励
