## 📚 新知识

| 写法 | 产生 |
|------|------|
| `range(5)` | 0 1 2 3 4 |
| `range(1, 6)` | 1 2 3 4 5 |
| `range(n, 0, -1)` | n … 1 |

累加器：`s = 0` 再 `s = s + i`。  
遍历字符串：`for ch in name:`。

空心矩形：四条边打 ★，中间打空格——需要内层 `if`。
