---

## 📚 新知识

```python
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

错误示范（投影）：先写 `>=60` 再写 `>=90`，让 95 被判及格，全班改。

```python
import random
computer = random.choice(["石头", "剪刀", "布"])
```

三个独立 `if` 可能走好几路；多路选择必须 if/elif/else。
