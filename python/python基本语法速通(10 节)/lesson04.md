## 📚 新知识

| 符号 | 意思 | 例子 |
|------|------|------|
| `/` | 除，结果一定是小数 | `5/2=2.5` |
| `//` | 整除 | `5//2=2` |
| `%` | 余数 | `5%2=1` |
| `**` | 乘方 | `2**3=8` |
| `==` | 等于（两个等号） | `10==10` |
| `and or not` | 并且 / 或者 / 取反 | |

`3+2*4=11`，`(3+2)*4=20`。

`score += 5` 等价 `score = score + 5`。
