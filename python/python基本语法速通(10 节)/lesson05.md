## 🎯 本课目标

- `if / else` 二选一，冒号 + 缩进
- 多个独立 if；一层嵌套 if
- **本课不用 elif**（留给下一课）
- 主项目：电影票价；加码：登录 + 穿衣

---

## 📚 新知识

```python
if age < 18:
    price = 25
else:
    price = 45
```

漏冒号、缩进错都会报错。Tab 在 VS Code 里一般是 4 空格。

嵌套：会员判断里面再判断满不满 30。

独立 if：周末加价和赠品是两件分开的事，不要硬写成一条。

演示：年龄 20，周末 y，会员 y → 55×0.9=49.5。
