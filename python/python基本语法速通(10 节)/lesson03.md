## 📚 新知识

| 类型 | 例子 | 一句话 |
|------|------|--------|
| str | `"12"` | 文字，input 永远返回这个 |
| int | `12` | 整数 |
| float | `1.75` | 小数 |
| bool | `True` `False` | 首字母必须大写 |

`"12" + 1` 会报错。`int("12") + 1` 才是 13。

`{bmi:.1f}` 保留 1 位小数。

BMI = 体重(kg) ÷ 身高(m) ÷ 身高(m)。课堂测试：13 岁、1.60 米、50 公斤 → BMI 约 19.5。

## 🔥 热身：类型侦探

故意运行 `print("12"+1)`，一起读报错，再改成 `int`。
