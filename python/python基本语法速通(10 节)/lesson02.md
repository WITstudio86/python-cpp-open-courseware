## 📚 新知识

### 变量

`name = "小明"`：左边标签，右边数据。可以再 `name = "小红"` 把盒子换掉。

起名：字母数字下划线；不能数字开头；不能有空格；不用 `print`/`if`/`for`。

### input()

```python
name = input("你叫什么名字？ ")
```

程序会暂停。不赋值，用户打的字会丢掉。**得到的永远是字符串**（下节课细讲）。

### f-string

```python
print(f"我叫 {name}，今年 {age} 岁。")
```

忘了写 `f`，`{name}` 会原样印出来。

用 `+` 拼接也可以，但两边必须都是字符串：`"小明" + "12"` → `小明12`。
