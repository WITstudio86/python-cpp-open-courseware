## 📚 新知识

### 1.1 安装（第一课专用）

Windows：https://www.python.org/downloads/ ，勾选 **Add Python to PATH**。  
Mac：同样下载官方安装包。终端里 `python3 --version` 有版本号即成功。  
编辑器：https://code.visualstudio.com/ ，装官方 Python 插件。

文件必须保存为 `xxx.py`。点右上角 ▶️ 运行。

### 1.2 `print()` 与字符串

```python
print("你好，Python！")
```

文字必须加引号。`print(你好)` 会报错。单引号双引号都行，但要配对。

### 1.3 热身要覆盖的六种玩法

```python
print("我", "爱", "编程")           # 多参数，默认空格
print("我", "爱", "编程", sep="-")  # 换分隔符
print("100+23=", 100 + 23)         # 没引号会先算
print("哈" * 8)                    # 重复
print("上一行\n下一行")              # 换行
print("A", end="")                 # 不换行
print("B")
```

### 1.4 注释

`#` 后面电脑不执行。
