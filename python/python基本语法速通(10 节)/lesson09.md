## 📚 新知识

```python
cart = ["苹果", "牛奶"]
cart[0]          # 第一件
cart[-1]         # 最后一件
cart.append(x)
cart.remove(x)   # 不存在会报错，先 in
cart[i] = "新"
cart.pop(i)      # 按位置删
```

对人说的「第 k 件」= 下标 `k-1`。

空列表不要取 `cart[0]`。
