⬇️ 消除与下移算法

算法：从上往下扫描 → pop删除满行 → insert顶部空行

①
扫描检测
从第0行开始
用 all() 检查每行
判断是否填满
②
pop 删除
grid.pop(r)
删除满行
下方所有行自动上移！
③
insert 补空
grid.insert(0, 空行)
在顶部插入新空行
保持20行不变
④
索引不增
r 保持不变！
检查刚移上来的行
自然处理多行消除

🔑 关键：pop后不增加r！因为下一行已经自动移到了当前位置

🔑 如果用 for 循环，索引不会回退 → 会跳过移上来的行！

💻 消除算法代码详解

def clear_lines(grid): """检测并消除满行，上方行整体下移""" cleared = 0 r = 0 while r < len(grid): # 检查第r行是否全部填满 if all(cell != 0 for cell in grid[r]): grid.pop(r) # 删除满行 grid.insert(0, [0] * 10) # 顶部插入空行 cleared += 1 # ⚠️ 不增加 r！下一行已自动移到 r 位置 else: r += 1 # 未满 → 检查下一行 return grid, cleared

⚠️ 常见错误：用了 for r in range(len(grid))

⚠️ 问题：pop后索引不会回退，会跳过移上来的行！

⚠️ 解决：用 while 循环，满足条件时不增加 r

💀 Game Over 判定

判断时机：新方块出生时，如果出生位置已被占据 → 游戏结束

2

检测并消除满行
上方行整体下移
→ clear_lines()
3
生成新方块

→ valid_position()

判定结果

→ game_over = True
显示"游戏结束" + 最终得分
