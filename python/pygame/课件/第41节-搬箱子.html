🔀 推箱子判断流程

玩家按下方向键（如：向右 →）
↓
检查玩家前方一格是什么？
↙ ↘
是墙 (1)
→ 无法通过
✋ 原地不动
是地板 (0) / 目标点 (3)
→ 可以直接走
🚶 玩家移动过去
是箱子 (2) / 箱子到位 (5)
→ 检查箱子前方一格
🔍 再次判断…
↓（箱子前方判断）
是墙 / 箱子 → ✋ 推不动
是地板 / 目标点 → 🎯 推！箱子+玩家同时移动
💡 核心思想：先看再走 —— 移动前检查两层（玩家前方 + 箱子前方）

💻 核心代码：移动逻辑 (1/2)

def try_move(dx, dy):
    """尝试向(dx,dy)方向移动"""
    global player_x, player_y, game_map, steps

    # 1. 计算玩家前方的坐标
    next_x = player_x + dx
    next_y = player_y + dy
    front = game_map[next_y][next_x]  # 前面是什么？

    # 2. 前面是地板(0)或目标点(3) → 直接走
    if front == 0 or front == 3:
        save_state()              # 保存快照（撤销用）
        # 清空玩家原位置
        game_map[player_y][player_x] = 3 \
            if (player_x,player_y) in targets else 0
        # 玩家移到新位置
        player_x, player_y = next_x, next_y
        game_map[player_y][player_x] = 4
        steps += 1

参数说明：dx=1,dy=0 向右 | dx=-1,dy=0 向左 | dx=0,dy=1 向下 | dx=0,dy=-1 向上

⚠️ 关键细节：如果箱子前方是目标点(3)，推过去后变成 5（到位）；如果是地板(0)，变成 2

↩️ 撤销功能实现

# 全局变量：记录每一步的「快照」
move_history = []  # [{player_x, player_y, game_map, steps}, ...]


def save_state():
    """走一步之前，先拍照存档"""
    snapshot = {
        'player_x': player_x,
        'player_y': player_y,
        'game_map': [row[:] for row in game_map],  # 深拷贝！
        'steps': steps
    }
    move_history.append(snapshot)  # 存入历史


def undo():
    """按 U 键 → 恢复到最后一张快照"""
    global player_x, player_y, game_map, steps
    if move_history:
        snap = move_history.pop()        # 取出最后一步
        player_x = snap['player_x']      # 恢复玩家坐标
        player_y = snap['player_y']
        game_map = [row[:] for row in snap['game_map']]
        steps = snap['steps']              # 恢复步数
🔑 深拷贝陷阱：不能用 game_map = snap['game_map']（浅拷贝），
必须用 [row[:] for row in ...] 复制每一行！

🏆 胜利检测 & 重新开始

def check_win():
    """遍历地图，看还有没有空目标点(3)"""
    for row in game_map:
        if 3 in row:          # 只要还有一个空目标点
            return False       # 就还没赢
    return True            # 所有目标点都有箱子 = 胜利！


def restart():
    """按 R 键 → 重置游戏"""
    global player_x, player_y, game_map, steps, move_history

    # 从原始地图深拷贝回来
    game_map = [row[:] for row in ORIGINAL_MAP]
    # 找到玩家初始位置
    for y in range(10):
        for x in range(10):
            if game_map[y][x] == 4:
                player_x, player_y = x, y
    steps = 0           # 步数归零
    move_history = []  # 清空历史
💡 判断逻辑：找不到 3 → 所有箱子都在目标点上 → 恭喜通关！

CELL = 64

def draw_map(screen, game_map):
    for y in range(10):
        for x in range(10):
            rect = (x * CELL, y * CELL, CELL, CELL)
            cell = game_map[y][x]

            if cell == 0:    # 地板 → 浅灰
                pygame.draw.rect(screen, (200,190,170), rect)
            elif cell == 1:  # 墙 → 深棕
                pygame.draw.rect(screen, (80,60,40), rect)
            elif cell == 2:  # 箱子 → 橙色
                pygame.draw.rect(screen, (240,165,0), rect)
                pygame.draw.rect(screen, (180,120,0), rect, 2)
            # ... 目标点(3)、玩家(4)、箱子到位(5) 都用圆/矩形绘制
