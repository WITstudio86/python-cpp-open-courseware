🚶 敌人怎么沿路线走？

核心思路：朝当前目标走 → 到达后换下一个

站在 path[0]
→
朝 path[1] 走
→
到达 path[1]！
target_index +1
→
朝 path[2] 走
→
到达 path[2]！
target_index +1
→
... 继续 ...

target_index 就像导航软件的"下一个路口"指针

每到达一个路口，指针就往后移一位，直到走完全程

💻 敌人移动 — 核心代码

Enemy 类的 update() 方法
def update(self): # 1. 获取当前目标路径点 target = path[self.target_index] # 2. 计算到目标的方向 dx = target[0] - self.rect.centerx dy = target[1] - self.rect.centery # 3. 计算距离（勾股定理） distance = math.sqrt(dx * dx + dy * dy) # 4. 如果到达 → 切换下一个目标 if distance < self.speed: self.target_index += 1 if self.target_index >= len(path): self.kill() # 走到终点，移除 return # 5. 沿方向移动一步（单位向量 × 速度） self.rect.x += (dx / distance) * self.speed self.rect.y += (dy / distance) * self.speed

为什么用 dx/distance？ 这叫"归一化"——把方向变成长度为 1 的向量，再乘以速度。 这样不管朝哪个方向走，实际速度都是一样的。

👀 敌人移动 — 逐步演示

场景：敌人从 (0, 100) 出发，目标是 (200, 100)，速度 = 2

帧数 敌人位置 目标 距离 动作
第 1 帧 (0, 100) (200, 100) 200 向右移动 2px
第 50 帧 (100, 100) (200, 100) 100 继续向右走
第 100 帧 (198, 100) (200, 100) 2 距离 < 速度 → 切换目标!

关键判断： if distance < self.speed: —— 距离小于一步的移动量，就认为"到达了"

🛡️ 点击放置炮塔

放置条件

  • 金币 ≥ 炮塔价格（50 金币）
  • 点击位置不在路线上
  • 不和已有炮塔重叠

实现步骤

  1. 监听 MOUSEBUTTONDOWN 事件
  2. 获取点击位置 event.pos
  3. 检查金币是否够
  4. 检查位置是否合法
  5. 创建 Tower 精灵
  6. 扣除金币

如何判断点击是否在路线上？
遍历每段路径，构造包围矩形（扩展路径宽度的一半），
检查点击坐标是否落在矩形内。

💰 金币系统

金币的三种操作

  • 初始：gold = 200
  • 消耗：放置炮塔 -50
  • 增长：每 2 秒 +1

为什么要自动增长？

给玩家一个持续的"收入"来源。
即使一开始放错了炮塔位置，
等一等金币攒够了还能再放。
这也让游戏不会"卡住"。

金币自动增长
# 在游戏循环中： gold_timer += 1 if gold_timer >= 120: # 120 帧 ≈ 2 秒 gold += 1 # 自动获得 1 金币 gold_timer = 0 # 重置计时器
