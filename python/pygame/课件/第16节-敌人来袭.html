👾 步骤1：敌机生成系统

核心思路：敌机列表 + 定时器 → 每N帧在顶部随机位置生成一架敌机

# 敌机系统变量
enemies = []                 # 敌机列表
enemy_timer = 0              # 生成计时器
ENEMY_SPAWN_INTERVAL = 60   # 每60帧(约1秒)生成一架

# 主循环中：计时 + 生成
enemy_timer += 1
if enemy_timer >= ENEMY_SPAWN_INTERVAL:
    enemy_timer = 0
    new_enemy = {
        "x": random.randint(0, WIDTH - enemy_width),
        "y": -enemy_height  # 从屏幕上方外面出现
    }
    enemies.append(new_enemy)

💥 步骤2：多组碰撞检测

检测1：子弹 vs 敌机（双层循环）

for bullet in bullets:
    b_rect = pygame.Rect(bullet["x"], bullet["y"], bw, bh)
    for enemy in enemies:
        e_rect = pygame.Rect(enemy["x"], enemy["y"], ew, eh)
        if b_rect.colliderect(e_rect):
            # 击中！加分 + 移除双方
            score += 10
            bullets_to_remove.append(bullet)
            enemies_to_remove.append(enemy)
            break  # 一颗子弹只消灭一架敌机

检测2：敌机 vs 玩家（单层循环）

player_rect = pygame.Rect(px, py, pw, ph)
for enemy in enemies:
    e_rect = pygame.Rect(enemy["x"], enemy["y"], ew, eh)
    if player_rect.colliderect(e_rect):
        hp -= 20       # 扣血！
        enemies_to_remove.append(enemy)

❤️ 步骤3：生命值 / 血条系统

原理：两个矩形叠加 — 红色底框（满血背景）+ 绿色填充（宽度=总宽×血量百分比）

max_hp = 100          # 最大生命值
hp = max_hp           # 当前生命值
bar_w, bar_h = 200, 20

# 三步绘制血条：
# 1. 红色底框
pygame.draw.rect(screen, (150,0,0), (10,10, bar_w, bar_h))

# 2. 绿色血量（宽度按比例）
green_w = int(bar_w * (hp / max_hp))
pygame.draw.rect(screen, (50,255,50), (10,10, green_w, bar_h))

# 3. 白色边框
pygame.draw.rect(screen, (255,255,255), (10,10, bar_w, bar_h), 2)

☠️ 步骤4：Game Over 判定与重新开始

Game Over 逻辑

if hp <= 0:
    hp = 0
    game_over = True

# 绘制半透明遮罩
overlay = pygame.Surface((W,H))
overlay.set_alpha(180)
overlay.fill((0,0,0))
screen.blit(overlay, (0,0))

按 R 重新开始

if game_over and
   event.key == pygame.K_r:
    bullets.clear()
    enemies.clear()
    player_x = W // 2 - pw // 2
    player_y = H - ph - 30
    score = 0
    hp = max_hp
    game_over = False

⚠️ 关键：用 if not game_over: 包裹所有游戏更新逻辑，否则 Game Over 后飞机还能动！

💡 常见问题与解决

问题原因解决
敌机生成太快/慢SPAWN_INTERVAL 不当调整间隔值：60=1秒
一颗子弹消灭多架内层循环没加 break命中后 break 跳出
血条不按比例整数除法问题用 / 保证浮点除法
GameOver后还能动没加 if not game_over包裹所有逻辑代码
重新开始有残留没清空列表bullets.clear() enemies.clear()
碰撞"穿过去了"速度太快跨过了降速或增大碰撞体积
