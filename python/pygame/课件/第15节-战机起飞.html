🕹️ 步骤1：方向键控制飞机移动

核心思路：监听键盘 → 修改飞机坐标 → 边界保护

# 按键检测：持续按下方向键时移动
keys = pygame.key.get_pressed()
if keys[pygame.K_LEFT] and player_x > 0:
    player_x -= player_speed   # 向左
if keys[pygame.K_RIGHT] and player_x < WIDTH - player_width:
    player_x += player_speed   # 向右
if keys[pygame.K_UP] and player_y > 0:
    player_y -= player_speed   # 向上
if keys[pygame.K_DOWN] and player_y < HEIGHT - player_height:
    player_y += player_speed   # 向下

⭐ get_pressed() 返回所有按键状态，适合持续按住 | 边界判断防止飞出屏幕

🔫 步骤2：空格键发射子弹

# 事件处理中：检测空格键按下
if event.type == pygame.KEYDOWN:
    if event.key == pygame.K_SPACE and bullet_cooldown == 0:
        new_bullet = {
            "x": player_x + player_width // 2 - bullet_width // 2,
            "y": player_y   # 从飞机顶部发射
        }
        bullets.append(new_bullet)
        bullet_cooldown = COOLDOWN_MAX  # 开始冷却

冷却时间（Cooldown）

没有冷却 → 按住空格 = 每帧都发射 = 机关枪（体验很糟糕！）

设置 COOLDOWN_MAX = 15（约0.25秒），子弹间隔合理。

📋 步骤3：子弹列表管理

完整流程：添加 → 移动 → 绘制 → 移除

# 1. 移动所有子弹
for bullet in bullets:
    bullet["y"] -= bullet_speed     # 向上飞！

# 2. 移除飞出屏幕的子弹（列表推导式）
bullets = [b for b in bullets if b["y"] + bullet_height > 0]

# 3. 绘制所有子弹
for bullet in bullets:
    pygame.draw.rect(screen, YELLOW,
        (bullet["x"], bullet["y"], bullet_width, bullet_height))

⚠️ 常见错误：遍历时直接删除

❌ for b in bullets: bullets.remove(b) → 会漏删！

✅ 用列表推导式"标记后删除"：bullets = [b for b in bullets if ...]

💥 步骤4：碰撞检测基础

核心方法：rect1.colliderect(rect2) → 判断两个矩形是否重叠

# 创建 Rect 对象
bullet_rect = pygame.Rect(bullet["x"], bullet["y"],
                              bullet_width, bullet_height)
enemy_rect  = pygame.Rect(enemy_x, enemy_y,
                              enemy_width, enemy_height)

# 检测碰撞
if bullet_rect.colliderect(enemy_rect):
    score += 10           # 加分！
    bullets.remove(bullet)  # 移除子弹

📐 Rect 的四个要素：x, y, width, height

碰撞 = 两个矩形有重叠区域

🏗️ 游戏主循环架构

while running:
    # ===== 1. 事件处理 =====
    #   按键、退出、发射子弹

    # ===== 2. 逻辑更新 =====
    #   移动飞机、移动子弹、冷却计时
    #   碰撞检测、移除出界子弹

    # ===== 3. 绘制画面 =====
    #   清屏 → 画飞机 → 画子弹 → 画敌机 → 显示分数
    #   flip() 刷新

    # ===== 4. 帧率控制 =====
    #   clock.tick(60)

牢记这四步结构，所有游戏大同小异！

💡 常见问题与解决

问题原因解决
飞机飞出屏幕没有边界判断加 if player_x > 0 等条件
子弹像机关枪没有冷却时间设置 cooldown 倒计时
子弹不消失没有移除飞出屏幕的子弹判断 y < 0 并移除
遍历删除报错边遍历边删列表用列表推导式或标记删除
碰撞检测不准Rect 参数不对检查 x,y,w,h 和绘制位置一致
