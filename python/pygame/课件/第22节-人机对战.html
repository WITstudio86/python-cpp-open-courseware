🧮 AI 追踪算法（核心代码）

算法思路

  • 比较 AI球拍中心点 y 和 球的 y
  • 球在上方 → AI移上去；球在下方 → AI移下去
  • 速度比球慢 → 给人"反应时间"的感觉
# AI追踪逻辑：让AI球拍中心向球的y坐标靠近
ai_speed = 4  # AI移动速度（比球速慢，模拟反应时间）

# 计算AI球拍中心点
ai_center = ai_paddle_y + paddle_height // 2

if ai_center < ball_y:        # 球在下方
    ai_paddle_y += ai_speed
elif ai_center > ball_y:    # 球在上方
    ai_paddle_y -= ai_speed
思考：如果把 ai_speed 改成 10 会怎样？改成 2 呢？这和游戏难度有什么关系？
【讲解】🧮 AI 追踪算法（核心代码） 本页要点（照着讲即可）： · 比较 AI球拍中心点 y 和 球的 y · AI球拍中心点 y · 球的 y · 球在上方 → AI移上去；球在下方 → AI移下去 · 速度比球慢 → 给人"反应时间"的感觉 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

📊 计分系统

计分规则

  • 球出左边界 → AI得1分
  • 球出右边界 → 玩家得1分
  • 先到11分者胜
  • 每次得分后 → 重新发球

判断胜负

WIN_SCORE = 11

if player_score >= WIN_SCORE:
    game_over = True
    winner = "玩家"
elif ai_score >= WIN_SCORE:
    game_over = True
    winner = "AI"

重新发球（reset）

def reset_ball():
    global ball_x, ball_y, ball_dx, ball_dy
    ball_x = 400          # 回到屏幕中心
    ball_y = 250
    ball_dx = random.choice([-4, 4])  # 随机左右
    ball_dy = random.choice([-3, 3])  # 随机上下

⏸️ 暂停功能

核心思想：用一个布尔变量控制游戏是否更新

paused = False  # 暂停状态变量

# 事件处理：按P键切换暂停
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_p:
            paused = not paused  # 切换状态

# 游戏更新：只在非暂停时执行
if not paused and not game_over:
    update_ball()
    update_ai()
    check_score()
关键点：paused = not paused 是最简洁的状态切换写法。
暂停时只绘制不更新 — 画面冻结但不消失。

🎨 半透明中线和虚线网

方法1：半透明实线

# 创建带透明度的 Surface
mid_line = pygame.Surface(
    (4, HEIGHT),
    pygame.SRCALPHA     # 关键！
)
mid_line.fill((255,255,255))
mid_line.set_alpha(80)   # 0=全透 255=不透明
screen.blit(mid_line,
            (398, 0))

pygame.SRCALPHA = 创建支持透明的画布
set_alpha(80) = 整张画布半透明

方法2：虚线网

# 画虚线：循环画短矩形
dash = 20   # 每段长度
gap = 15    # 间隔
for y in range(
    0, HEIGHT,
    dash + gap
):
    pygame.draw.rect(
        screen,
        (200,200,200),
        (398, y, 4, dash)
    )

虚线 = 多个小矩形 + 跳过间隔
也可给虚线加透明度

🔄 游戏主循环结构

while running:
    # 1. 事件处理
    for event in pygame.event.get():
        if event.type == QUIT: running = False
        if event.type == KEYDOWN:
            if event.key == K_p: paused = not paused
            if event.key == K_r and game_over: reset_game()

    # 2. 获取按键状态（玩家控制）
    keys = pygame.key.get_pressed()
    if keys[K_w]: player_y -= speed
    if keys[K_s]: player_y += speed

    # 3. 更新游戏逻辑（非暂停 + 未结束）
    if not paused and not game_over:
        update_ball()      # 移动球
        update_ai()        # AI追踪
        check_bounce()     # 碰撞反弹
        check_score()      # 得分检测

    # 4. 绘制画面（无论什么状态都要画）

    draw_net()          # 虚线网
    draw_paddles()      # 球拍
    draw_ball()         # 球
    draw_score()        # 比分
    draw_status()       # 暂停/结束提示
    pygame.display.update()
