🔧 第一步：提取 reset_game() 函数

为什么要这样做？

把所有初始化代码集中到一个函数里，方便重新开始游戏时一键重置。

好处：按R重新开始时，只需一行
reset_game() 就够了！
# 全局变量 snake = [] dx, dy = 0, 0 food = [] score = 0 game_over = False def reset_game(): """重置游戏状态""" global snake, dx, dy, food global score, game_over snake = [[400,300],[380,300],[360,300]] dx, dy = GRID_SIZE, 0 # 初始向右 food = generate_food(snake) score = 0 game_over = False # 程序启动时调用一次 reset_game()
⚠️ 注意：在函数里修改全局变量，必须用 global 关键字声明！

🧱 碰撞检测（一）：碰到墙壁

判断逻辑

蛇头坐标超出屏幕范围 = 死亡

y < 0 碰上方 ☠ y >= 600 碰下方 ☠ x < 0
碰左边 ☠ x >= 800
碰右边 ☠
✅ 安全区域

代码实现

def check_wall_collision(head): """检查蛇头是否碰到墙壁""" x, y = head[0], head[1] return (x < 0 or x >= WIDTH or y < 0 or y >= HEIGHT) # 在移动后立即检查 if check_wall_collision(snake[0]): game_over = True

左墙 x<0 | 右墙 x>=800
上墙 y<0 | 下墙 y>=600

🔀 碰撞检测（二）：碰到自己

方法一：列表 in 判断（推荐理解）

def check_self_collision(snake): """蛇头是否碰到身体""" return snake[0] in snake[1:]
snake[0] = 新蛇头位置
snake[1:] = 身体所有位置（不含头）
💡 in 运算符检查"蛇头坐标"是否出现在"身体坐标列表"中

方法二：Rect.collidelist()（进阶）

def check_self_collision(snake): # 蛇头转成Rect head_rect = pygame.Rect( snake[0][0], snake[0][1], GRID_SIZE, GRID_SIZE) # 身体每节都转成Rect body_rects = [] for seg in snake[1:]: body_rects.append( pygame.Rect(seg[0], seg[1], GRID_SIZE, GRID_SIZE)) # collidelist返回-1=没碰撞 return head_rect.collidelist(body_rects) != -1
collidelist() 是Pygame的批量碰撞检测函数，高效又好用！

🔄 重新开始：按R键一键重置

事件处理

# 在事件循环中 elif event.type == pygame.KEYDOWN: # 方向键处理... # R键：重新开始（仅游戏结束时有效） if event.key == pygame.K_r \ and game_over: reset_game()
关键点：只有在 game_over==True 时才响应R键，避免游戏中误按导致重置！

🐛 常见 Bug 与排查

❌ 问题现象 🔍 可能原因 ✅ 解决方法
蛇走到边缘没死 边界条件用错了 x>=WIDTH 必须是 >= ，不能是 >
永远不会撞到自己 碰撞检测在 insert 之前执行了 必须在 insert(0) 之后检查
游戏结束后蛇还在动 逻辑代码没放到 if not game_over: 里面 用 if not game_over: 包裹游戏逻辑
按R键没反应 按键判断在方向键的 elif 后面 R键判断用独立的 if，不要连在 elif 上
文字不显示或乱码 字体名称不存在 先用 pygame.font.get_default_font() 测试
重新开始后分数没归零 reset_game() 里没写 score = 0 检查 global score + score = 0
⚠️ 调试技巧：在碰撞检测函数里加一句 print("撞墙了!")，看控制台输出，确认检测是否触发。
