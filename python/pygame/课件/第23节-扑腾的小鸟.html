什么是 Flappy Bird？

Flappy Bird 是 2013 年爆红的手机小游戏：

  • 一只小鸟不停地往下掉
  • 玩家点击屏幕让小鸟往上飞
  • 小鸟需要穿过水管间的空隙
  • 碰到水管或地面 = 游戏结束
  • 每穿过一对水管，得 1 分
数据：Flappy Bird 在 App Store 下载量超过 5000 万次，每天广告收入约 5 万美元！

核心概念：重力模拟

在真实世界中，物体下落时速度越来越快——这就是重力加速度的效果。

velocity = 0 → velocity += gravity → y += velocity

逐帧演示（GRAVITY = 0.5）：

帧数速度 (velocity)位置 (y)
第 0 帧0.0300.0
第 1 帧0.5300.5
第 2 帧1.0301.5
第 3 帧1.5303.0
第 4 帧2.0305.0
第 10 帧5.0327.5
第 20 帧10.0402.5
关键理解：
GRAVITY = 0.5 是加速度，不是速度本身。

它表示每一帧，速度增加 0.5。
物理课上学的：
匀加速运动公式
v = v₀ + a·t
这就是它的编程版本！
a = GRAVITY， t = 帧数
重力：代码实现
# --- 小鸟的物理属性 --- bird_x = 100 bird_y = HEIGHT // 2 # 初始在屏幕中间 bird_velocity = 0 # 初始速度为零 # --- 重力参数 --- GRAVITY = 0.5 # 每帧增加的速度 # --- 在游戏循环中（每帧执行）--- bird_velocity += GRAVITY # ① 速度越来越大 bird_y += bird_velocity # ② 位置随速度改变

两行代码的事：

  • 第①行：重力让速度不断增加
  • 第②行：速度让位置不断变化
  • 结果：小鸟越来越快地往下掉
参数含义：
GRAVITY = 加速度
值越大 → 掉得越快
值越小 → 掉得越慢
试试改成 0.2 或 1.0！
空格键：让小鸟飞起来！

事件检测代码：

for event in pygame.event.get(): if event.type == pygame.QUIT: running = False elif event.type == pygame.KEYDOWN: if event.key == pygame.K_SPACE: bird_velocity = JUMP_STRENGTH # = -8

关键：用 = 还是 += ？

错误写法：
velocity += JUMP_STRENGTH
连续按空格 → 速度累加 → 小鸟像火箭一样冲出屏幕！
正确写法：
velocity = JUMP_STRENGTH
每次按空格 → 速度重置为 -8 → 每次弹跳高度相同

JUMP_STRENGTH = -8 为什么是负数？
在 Pygame 中，y 轴向下是正方向 → 向上移动需要负速度

自绘素材：用代码画一只小鸟

不下载图片，全部用 pygame.draw 自己画！

# 创建透明背景的 Surface 画布 bird_surf = pygame.Surface((34, 34), pygame.SRCALPHA) # ① 身体：黄色圆形 pygame.draw.circle(bird_surf, YELLOW, (16, 16), 13) # ② 翅膀：深黄色小椭圆 pygame.draw.ellipse(bird_surf, WING_COLOR, (2, 12, 12, 7)) # ③ 眼睛：白色 + 黑色瞳孔 pygame.draw.circle(bird_surf, WHITE, (22, 12), 5) pygame.draw.circle(bird_surf, BLACK, (23, 12), 2) # ④ 嘴巴：橙色三角形 pygame.draw.polygon(bird_surf, BEAK_COLOR, [(28,14), (34,17), (28,20)])

图形组成拆解：

  • pygame.draw.circle → 圆形（身体、眼睛）
  • pygame.draw.ellipse → 椭圆（翅膀）
  • pygame.draw.polygon → 多边形（三角形嘴巴）
SRCALPHA 的作用：
pygame.SRCALPHA 让 Surface 支持透明背景。
如果不用它，小鸟周围会有一个黑色方块。
小技巧：
坐标是相对于 Surface 的，不是屏幕坐标！
(16, 16) 是 Surface 内部的中心点，
不是屏幕上的 (16, 16)。
水管：生成逻辑

每根水管由上水管 + 下水管组成，中间留一个随机高度的空隙让小鸟飞过。

# 随机空隙中心（150 ~ 450 之间） gap_center = random.randint(150, HEIGHT - 150) # 空隙的上下边界 gap_top = gap_center - PIPE_GAP // 2 gap_bottom = gap_center + PIPE_GAP // 2 # 上水管：从屏幕顶部到空隙顶部 top_height = gap_top # 下水管：从空隙底部到屏幕底部 bottom_height = HEIGHT - gap_bottom

水管结构示意

┌──────────┐  ← 屏幕顶部 (y=0)
│ 上水管    │
│          │
│          │  ← gap_top（空隙开始）
│          │
│≋≋ 空隙 ≋≋│  ← 小鸟从这里飞过 (160px)
│          │
│          │  ← gap_bottom（空隙结束）
│ 下水管    │
│          │
└──────────┘  ← 屏幕底部 (y=600)
PIPE_GAP = 160：空隙高度
值越大 → 游戏越简单
值越小 → 游戏越困难
水管：移动与生命周期

水管有自己的生命周期：生成 → 移动 → 移除

① 生成（定时触发）

if frame_count >= PIPE_SPAWN_INTERVAL: pipes.append(create_pipe(WIDTH + 50)) frame_count = 0

② 移动（每帧向左）

for pipe in pipes: pipe["x"] -= PIPE_SPEED # 向左移 3 像素/帧

③ 移除（飞出屏幕后）

pipes = [p for p in pipes if p["x"] > -PIPE_WIDTH]

生命周期图解：

阶段条件操作
生成 帧计数器 ≥ 90 append 到列表
移动 每帧 x -= 3
移除 x < -60 从列表删除
为什么要移除？
水管飞出屏幕后，如果不删除：
① 浪费内存
② 列表越来越长
③ 遍历越来越慢
④ 游戏越来越卡
列表推导式复习：
[p for p in pipes if p["x"] > -60]
= 保留 x 坐标还看得见的，删掉已经飞远的
完整游戏循环结构
# ===== 游戏主循环 ===== while running: # 1. 事件处理 for event in pygame.event.get(): if event.type == pygame.QUIT: running = False elif event.type == pygame.KEYDOWN and event.key == pygame.K_SPACE: bird_velocity = JUMP_STRENGTH # 2. 更新物理（重力 → 小鸟下落） bird_velocity += GRAVITY bird_y += bird_velocity # 3. 更新水管（移动 → 移除 → 生成） for pipe in pipes: pipe["x"] -= PIPE_SPEED pipes = [p for p in pipes if p["x"] > -PIPE_WIDTH] if frame_count >= PIPE_SPAWN_INTERVAL: pipes.append(create_pipe(WIDTH + 50)) # 4. 绘制画面 screen.fill(SKY_BLUE) # 天空背景 for pipe in pipes: # 画水管 screen.blit(pipe["top_surf"], (pipe["x"], 0)) screen.blit(pipe["bottom_surf"], (pipe["x"], pipe["bottom_rect"].y)) screen.blit(bird_image, bird_rect) # 画小鸟 pygame.display.flip() # 刷新屏幕 clock.tick(FPS)

四大步骤：事件 → 更新 → 绘制 → 刷新

参数调节：让游戏属于你自己

修改这些参数，感受游戏玩法的变化：

参数 默认值 作用 调大效果 调小效果
GRAVITY 0.5 重力加速度 掉得更快（更难） 掉得更慢（更简单）
JUMP_STRENGTH -8 跳跃力度 飞得更高（更简单） 飞得较低（更难）
PIPE_GAP 160 水管空隙高度 空隙大（更简单） 空隙小（更难）
PIPE_SPEED 3 水管移动速度 移动快（更难） 移动慢（更简单）
PIPE_SPAWN_INTERVAL 90 水管生成间隔（帧） 更稀疏（更简单） 更密集（更难）
FPS 60 帧率 更流畅 更卡顿
试玩建议：调整参数后运行游戏，感受"手感"的变化。好的游戏设计，就是反复调整参数直到手感最舒服的过程！
