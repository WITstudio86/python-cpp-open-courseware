用 Pygame 做一个接水果游戏
Python + Pygame 趣味编程 · 互动课件

💡 综合目标：做出一个完整的 "接水果"小游戏，玩家用方向键移动篮子接住天上掉下来的苹果！

📖 复习：方向键控制移动

还记得第3节学的键盘控制吗？快速回顾一下：

按键检测

import pygame # 获取所有按下的键 keys = pygame.key.get_pressed() if keys[pygame.K_LEFT]: player_x -= speed if keys[pygame.K_RIGHT]: player_x += speed

边界限制

# 不让角色跑出屏幕 if player_x < 0: player_x = 0 if player_x > SCREEN_W - player_w: player_x = SCREEN_W - player_w # 使用 clamp 更简洁： player_x = max(0, min(player_x, W - w))

🧠 核心思路：检测按键 → 修改坐标 → 边界判断 → 刷新画面。这个循环是游戏的基础！

🆕 新知识：random.randint() 随机数

为什么需要随机数？

如果苹果每次都从同一个位置掉下来，游戏就没意思了！我们需要苹果从 随机的 x 坐标 出现。

语法

import random num = random.randint(a, b) # 返回 a~b 之间的随机整数（包含 a 和 b）

示例

import random dice = random.randint(1, 6) # 模拟掷骰子 → 1,2,3,4,5,6 x = random.randint(0, 800) # 屏幕任意 x 坐标 y = random.randint(-100, -20) # 从屏幕上方随机位置出现

🎲 记忆口诀：「random.randint(起, 止)」—— 给它一个范围，还你一个随机整数！

💻 代码示例：苹果从随机位置出现

import pygame import random # 苹果的初始坐标 apple_x = random.randint(0, 750) apple_y = random.randint(-200, -50) # 在主循环中绘制苹果 while running: # ... 其他代码 ... screen.blit(apple_img, (apple_x, apple_y))

为什么 y 用负数？

让苹果从 屏幕上方外面 开始下落，而不是突然出现在可见区域中央——这样看起来更自然！

参数含义示例值
apple_x苹果的 x 坐标（随机）0 ~ 屏幕宽度
apple_y苹果的 y 坐标（负值）-200 ~ -50

🆕 新知识：下落动画原理

动画的本质

动画就是 每帧改变一丁点儿位置，连续播放就产生了"动"的效果。

下落 = y 坐标不断变大

apple_y += speed # 每帧向下移动 speed 个像素

Pygame 帧率概念

# 设置游戏帧率 clock = pygame.time.Clock() FPS = 60 while running: clock.tick(FPS) # 每秒执行 60 次循环 apple_y += 5 # 每帧移动 5px → 每秒 300px

📐 公式记忆：物体的新位置 = 旧位置 + 速度。方向向下，所以 y 坐标增大！

💻 代码示例：让苹果"掉下来"

完整下落逻辑

# 初始化 apple_x = random.randint(0, 750) apple_y = random.randint(-200, -50) apple_speed = 5 # 主循环中 apple_y += apple_speed # 下落 # 如果掉出屏幕底部，重新生成 if apple_y > 600: apple_x = random.randint(0, 750) apple_y = random.randint(-200, -50)

🔄 循环利用：苹果掉出屏幕后，不要创建新苹果——直接 重置坐标 让它重新"从天而降"即可！

🆕 新知识：碰撞检测

什么是碰撞检测？

判断两个物体是否 重叠（碰到一起）。在游戏里就是判断篮子有没有"接住"苹果。

pygame.Rect（矩形对象）

# 创建矩形对象来描述物体的位置和大小 apple_rect = pygame.Rect(apple_x, apple_y, apple_w, apple_h) basket_rect = pygame.Rect(basket_x, basket_y, basket_w, basket_h)

碰撞检测方法

# colliderect() 返回 True/False if apple_rect.colliderect(basket_rect): print("接到啦！🍎")

📦 Rect = (x, y, width, height)：每个游戏角色都有一个"碰撞盒"，检测两个碰撞盒是否重叠。

方法作用
rect1.colliderect(rect2)rect1 和 rect2 是否重叠
rect1.collidepoint(x, y)点 (x, y) 是否在 rect1 内部

💻 代码示例：判断篮子是否接到苹果

# 定义矩形（碰撞盒） apple_rect = pygame.Rect(apple_x, apple_y, 50, 50) basket_rect = pygame.Rect(basket_x, 520, 100, 60) # 碰撞检测 if apple_rect.colliderect(basket_rect): score += 10 # 加分 apple_y = random.randint(-200, -50) # 重置苹果 apple_x = random.randint(0, 750)

碰撞后做什么？

  1. 增加分数 score += 10
  2. 让苹果重新从顶部出现（随机位置）
  3. （进阶）可以播放音效、加速下落等

⚠️ 注意：碰撞检测要放在 苹果移动之后、绘制之前，这样检测结果才准确！

🆕 新知识：分数显示（字体渲染）

Pygame 显示文字的步骤

  1. 创建字体对象 — pygame.font.Font(None, 36)
  2. 渲染文字为图片 — font.render(text, True, color)
  3. 贴到屏幕上 — screen.blit(text_img, (x, y))

代码示例

# 初始化字体 font = pygame.font.Font(None, 36) # None = 系统默认字体 # 主循环中渲染分数 score_text = font.render(f"分数: {score}", True, (255, 255, 255)) screen.blit(score_text, (10, 10))

🖌️ render(文字, 抗锯齿, 颜色)：把文字"画"成一张图片，然后贴到屏幕上。注意分数是整数，需要用 f-string 拼进字符串！

📜 完整代码：游戏主循环

import pygame, random pygame.init() W, H = 800, 600 screen = pygame.display.set_mode((W, H)) pygame.display.set_caption("接水果") clock = pygame.time.Clock() font = pygame.font.Font(None, 36) # 篮子 bx, by, bw, bh = 350, 520, 100, 60 # 苹果 ax = random.randint(0, W - 50) ay = random.randint(-200, -50) speed, score = 5, 0 running = True while running: for e in pygame.event.get(): if e.type == pygame.QUIT: running = False keys = pygame.key.get_pressed() if keys[pygame.K_LEFT]: bx -= 8 if keys[pygame.K_RIGHT]: bx += 8 bx = max(0, min(bx, W - bw)) ay += speed ar = pygame.Rect(ax, ay, 50, 50) br = pygame.Rect(bx, by, bw, bh) if br.colliderect(ar): score += 10 ax = random.randint(0, W - 50) ay = random.randint(-200, -50) if ay > H: ax = random.randint(0, W - 50) ay = random.randint(-200, -50) screen.fill((135, 206, 235)) pygame.draw.rect(screen, (139,69,19), br) # 篮子 pygame.draw.rect(screen, (255,0,0), ar) # 苹果 scr = font.render(f"分数: {score}", True, (255,255,255)) screen.blit(scr, (10, 10)) pygame.display.flip() clock.tick(60) pygame.quit()
