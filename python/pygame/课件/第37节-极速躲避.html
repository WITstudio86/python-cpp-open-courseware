滚动背景循环原理（上）

核心思想：用两张完全相同的道路图片首尾相接，循环滚动

步骤

  • 准备两张相同的道路图片
  • 图1在上，图2紧接其后
  • 每帧将两张图同时向下移动
  • 当图1完全移出屏幕，立即将其放到图2下方
  • 不断重复，形成无限道路
┌─────────────┐
│   屏幕可见区  │
│   (窗口)     │
│             │
├─────────────┤ ← 图1 正在移出
│             │
│   道路图片 2  │
│             │
├─────────────┤
│             │
│   道路图片 1  │ ← 循环回来
│             │
└─────────────┘
关键：road_y 坐标超过屏幕高度时，重置为 road_y - 图片总高度，实现无缝循环。

滚动背景循环原理（下）— 代码实现

# 加载道路图片，假设高度为 600 road_img = pygame.image.load("road.png") road_y1 = 0 # 第一张图片的 Y 坐标 road_y2 = -600 # 第二张图片从屏幕上方开始 scroll_speed = 5 # 在游戏循环中： road_y1 += scroll_speed # 两张图片同时下移 road_y2 += scroll_speed if road_y1 >= 600: # 图1移出屏幕，放到图2上方 road_y1 = road_y2 - 600 if road_y2 >= 600: # 图2移出屏幕，放到图1上方 road_y2 = road_y1 - 600 # 绘制到屏幕上 screen.blit(road_img, (0, road_y1)) screen.blit(road_img, (0, road_y2))

也可以用 road_y %= 600 简化实现，但两张图的首尾相接方法更直观易懂。

障碍物管理机制

使用 列表 (list) 管理所有活跃的障碍车：

→
加入列表
→
每帧更新位置
→

→

# 障碍物列表 obstacles = [] # 存储所有活跃的障碍车 Rect spawn_timer = 0 # 生成计时器 # 每帧更新 for obs in obstacles: obs.y += speed # 障碍物向下移动 # 移除屏幕外的障碍物（节省内存） obstacles = [obs for obs in obstacles if obs.y < 800] # 定时生成新障碍物 spawn_timer += 1 if spawn_timer > spawn_interval: obstacles.append(create_obstacle()) # 创建新障碍车 spawn_timer = 0

关键优化：被移除的障碍物不再绘制/检测，避免列表中对象越来越多导致游戏变卡。

难度自动递增

游戏难度随游戏时长（分数）逐步提高：

递增策略

  • 移动速度递增：每得 100 分，速度 +0.3
  • 生成频率加快：每得 200 分，生成间隔 -5 帧
  • 多车道概率：后期障碍车出现在更多车道上
  • 设置上限：防止速度过快导致无法反应
# 难度递增逻辑 score += 1 speed = 5 + score // 100 * 0.3 # 速度上限 if speed > 12: speed = 12 # 生成间隔随分数减少 spawn_interval = 60 - score // 200 * 5 if spawn_interval < 25: spawn_interval = 25 # 最低间隔
让玩家感受到逐渐增加的压迫感，但保留可玩性。难度曲线要平滑，避免突然变太难。

碰撞检测

使用 Pygame 内置的 Rect.colliderect() 方法判断两个矩形是否重叠：

原理

每个游戏对象都有一个 pygame.Rect，代表它的位置和大小（x, y, width, height）。

当两个矩形的边界发生重叠时，colliderect() 返回 True。

碰撞检测在每一帧都要执行，遍历障碍物列表，逐一检查是否与玩家碰撞。
# 定义玩家和障碍物的碰撞矩形 player_rect = pygame.Rect( player_x, player_y, car_width, car_height ) # 遍历所有障碍物 for obs in obstacles: if player_rect.colliderect(obs): game_state = "game_over" break # 一旦碰撞，立即结束

核心代码 — 主循环

# ===== 初始化 ===== pygame.init() screen = pygame.display.set_mode((400, 700)) clock = pygame.time.Clock() lanes = [60, 160, 260] # 三条车道的 X 坐标 player_lane = 1 # 玩家初始在中间车道 running = True while running: # ----- 事件处理 ----- for event in pygame.event.get(): if event.type == pygame.QUIT: running = False # ----- 键盘输入 ----- keys = pygame.key.get_pressed() if keys[pygame.K_LEFT] and player_lane > 0: player_lane -= 1 # 向左切换车道 if keys[pygame.K_RIGHT] and player_lane < 2: player_lane += 1 # 向右切换车道 # ----- 更新 ----- update_road() # 滚动道路背景 update_obstacles() # 移动障碍物 & 生成新障碍物 check_collision() # 碰撞检测 update_difficulty() # 难度递增 # ----- 绘制 ----- draw_road() # 绘制道路背景 draw_obstacles() # 绘制所有障碍车 draw_player() # 绘制玩家车 draw_score() # 显示分数 pygame.display.flip() clock.tick(60) pygame.quit()

玩家控制 — 车道切换

用方向键控制玩家在三个车道之间移动：

设计思路

  • 用 车道索引 而非像素坐标管理位置
  • 预设三个车道 X 坐标：[60, 160, 260]
  • 按左键 → 索引减 1（不能小于 0）
  • 按右键 → 索引加 1（不能大于 2）
  • 通过索引从车道列表取对应 X 坐标

车道切换的两种实现

# 方法1：即时切换（推荐） if keys[pygame.K_LEFT] and lane > 0: lane -= 1 # 方法2：平滑过渡（有移动动画） target_x = lanes[lane] if player_x < target_x: player_x += 10 # 向右移动 elif player_x > target_x: player_x -= 10 # 向左移动
注意：切换车道时要加上边界判断，防止玩家移出道路范围。
