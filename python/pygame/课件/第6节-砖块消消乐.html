🔁 嵌套循环 —— 一行代码生40块砖

5行 × 8列 = 40块砖，不能一块一块写！

for row in range(5): # 外层循环：第几行 for col in range(8): # 内层循环：第几列 x = col * (90 + 5) # 计算 x 坐标 y = row * (25 + 5) # 计算 y 坐标 bricks.append( Rect(x, y, 90, 25) )

📝 显示分数：font.render()
