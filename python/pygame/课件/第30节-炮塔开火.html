距离计算 —— 炮塔的"眼睛"

炮塔需要知道敌人在不在攻击范围内。这就要用勾股定理计算两点距离。

距离 = √((x₁ − x₂)² + (y₁ − y₂)²) 
import math

def 计算距离(x1, y1, x2, y2):
    # 计算两点之间的直线距离
    dx = x1 - x2          # x方向差值
    dy = y1 - y2          # y方向差值
    return math.sqrt(dx*dx + dy*dy)  # 开方

# 举例：(0,0) 到 (3,4) 的距离
print(计算距离(0, 0, 3, 4))  # 输出：5.0 ✓
💡 记住：3-4-5 是经典的勾股数！3² + 4² = 5²

不开方也能比大小！

如果我们只需要判断"谁更近"，不一定要求出精确距离。

比较 距离² 和 射程² 的结果是一样的，但省去了开方运算！

def 在射程内吗(炮塔, 敌人):
    dx = 炮塔.x - 敌人.x
    dy = 炮塔.y - 敌人.y
    距离平方 = dx*dx + dy*dy

    # 比较距离平方，不需要开方！
    if 距离平方 <= 炮塔.射程 * 炮塔.射程:
        return True
    return False
方法代码性能
精确距离math.sqrt(dx² + dy²) <= 射程较慢
距离平方dx² + dy² <= 射程²更快！

自动瞄准 —— 选择最近的敌人

如果多个敌人在射程内，炮塔优先攻击最近的（威胁最大）。

def 获取最近敌人(炮塔, 敌人列表):
    最近敌人 = None
    最近距离平方 = float('inf')  # 无穷大

    for 敌人 in 敌人列表:
        dx = 炮塔.x - 敌人.x
        dy = 炮塔.y - 敌人.y
        d2 = dx*dx + dy*dy

        # 在射程内 且 比之前找到的更近
        if d2 <= 炮塔.射程² and d2 < 最近距离平方:
            最近距离平方 = d2
            最近敌人 = 敌人

    return 最近敌人  # 没找到则返回 None
🎯 算法核心：遍历 → 比较 → 更新最小值。这是编程中非常常见的模式！

子弹飞行 —— 追踪目标

子弹每帧向目标移动一点点，直到命中。

# 每帧更新子弹位置
for 子弹 in 子弹列表[:]:    # [:] 是安全遍历技巧
    目标 = 子弹['目标']
    dx = 目标.x - 子弹['x']
    dy = 目标.y - 子弹['y']
    距离 = math.sqrt(dx*dx + dy*dy)

    if 距离 < 8:   # 命中！
        目标.血量 -= 子弹['伤害']
        子弹列表.remove(子弹)
    else:
        # 向目标移动（单位向量 × 速度）
        子弹['x'] += dx / 距离 * 子弹['速度']
        子弹['y'] += dy / 距离 * 子弹['速度']
💡 用 dx/距离 得到单位方向向量，再乘速度就是每帧移动量。

敌人血条 —— 可视化剩余生命

在敌人头顶绘制一个红绿相间的血条。

def 绘制血条(屏幕, 敌人):
    条宽 = 30
    条高 = 4
    x = 敌人.x - 条宽 // 2   # 居中
    y = 敌人.y - 15          # 头顶

    # 红色背景（已损失的血量）
    pygame.draw.rect(屏幕, (255,0,0),
                     (x, y, 条宽, 条高))

    # 绿色前景（剩余血量，按比例缩放）
    比例 = 敌人.血量 / 敌人.最大血量
    pygame.draw.rect(屏幕, (0,255,0),
                     (x, y, 条宽*比例, 条高))

代码亮点：炮塔冷却机制

炮塔不能连续攻击，需要攻击间隔（冷却时间）。

class 炮塔:
    def __init__(self, x, y):
        self.冷却 = 0          # 当前冷却
        self.攻击间隔 = 30     # 每30帧攻击一次
        self.射程 = 120
        self.攻击力 = 25

    def 更新(self, 敌人列表):
        if self.冷却 > 0:
            self.冷却 -= 1     # 冷却中
            return None

        目标 = 获取最近敌人(self, 敌人列表)
        if 目标:
            self.冷却 = self.攻击间隔  # 重置冷却
            return 创建子弹(self, 目标)
        return None
