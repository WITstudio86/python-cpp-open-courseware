🧮 三角函数：把角度"拆"成X和Y

直观理解

你射箭时瞄准了45°角的目标

但计算机只会说：
"往右走几个像素，往上走几个像素"

🎯 /| / | / | ← sin = 对边/斜边 /___| 🏹 ^-- cos = 邻边/斜边
🔑 口诀：
cos 管左右   sin 管上下

代码翻译

import math

# 角度 → 弧度
angle = 45
rad = math.radians(angle)
# 45° = π/4 ≈ 0.785 弧度

# 拆解方向
speed = 5
vx = speed * math.cos(rad)   # ≈ 3.54
vy = -speed * math.sin(rad)  # ≈ -3.54
#    ↑ 负号！屏幕Y轴向下，向上飞要取负

🥧 角度制 vs 弧度制

角度制（°）

把圆分成360份

一圈 = 360°

直角 = 90°

人类觉得直观👍

但计算机不认😢

弧度制（rad）

用半径丈量弧长

一圈 = 2π ≈ 6.28 弧度

直角 = π/2 ≈ 1.57 弧度

计算机数学函数的语言👍

sin/cos 都吃弧度👍

🍕 比萨饼类比：角度制就像把比萨切成360片（很细！）
弧度制就像用比萨的半径去量饼边的弧长（很自然！） 
# 转换公式
弧度 = 角度 × π / 180
# Python 帮你做：

deg = math.degrees(rad)   # 0.785 rad → 45°

🖱️ 发射器瞄准——atan2 求角度

思路

  1. 获取鼠标和发射器的坐标
  2. 计算两点的差值 dx、dy
  3. 用 atan2() 算角度
  4. 画一条瞄准线
🤔 atan 和 atan2 有什么区别？
atan2(y, x) 比 atan() 聪明——
能区分左右方向，返回 [-π, π] 
# 发射器在底部中央
lx = WIDTH // 2
ly = HEIGHT - 60

# 获取鼠标位置
mx, my = pygame.mouse.get_pos()

# atan2 求角度
dx = mx - lx
dy = my - ly
angle = math.atan2(-dy, dx)
#        ↑ 负号！屏幕Y轴向下

# 画瞄准线（虚线）
end_x = lx + 100 * math.cos(angle)
end_y = ly - 100 * math.sin(angle)
pygame.draw.line(scr, WHITE,
    (lx, ly), (end_x, end_y), 3)

💥 碰撞检测——泡泡什么时候停？

两种碰撞情况：

情况1：碰到顶部

if bubble.y - RADIUS <= TOP_MARGIN:
    # 泡泡超出顶部了
    bubble.y = TOP_MARGIN + RADIUS
    flying = False
    snap_to_grid()

简单！就是Y坐标太靠上了

情况2：碰到已有泡泡

for other in bubble_list:
    # 圆心距离 < 直径 → 相碰
    dist = math.hypot(
        bubble.x - other.x,
        bubble.y - other.y
    )
    if dist < 2 * RADIUS:
        flying = False
        snap_to_grid()

勾股定理：√(Δx² + Δy²)

🧮 math.hypot(dx, dy) = √(dx² + dy²)，比手写 sqrt(dx*dx + dy*dy) 更简洁！

🔷 六边形网格——泡泡的家

泡泡龙中所有泡泡排列在六边形网格上，像蜂窝一样：

网格规则

  • 列间距 = 2 × R（紧密）
  • 行间距 = √3 × R ≈ 1.732R
  • 奇数行右移半个格子
CELL_W = 2 * RADIUS
CELL_H = int(RADIUS * math.sqrt(3))

# 奇数行的X偏移
if row % 2 == 1:
    x += CELL_W // 2
列0 列1 列2 列3 ⬤ ⬤ ⬤ ⬤ ← 行0(偶数) ⬤ ⬤ ⬤ ⬤ ← 行1(奇数) ⬤ ⬤ ⬤ ⬤ ← 行2(偶数) ⬤ ⬤ ⬤ ⬤ ← 行3(奇数)

像砖墙一样错落排列！

🧲 网格吸附——泡泡"吸"到最近位置

def snap_to_grid(bx, by):
    # 1️⃣ 找到最近的列
    col = round(bx / CELL_W)
    col = max(0, min(GRID_COLS - 1, col))

    # 2️⃣ 找到最近的行（奇数行有X偏移补偿）
    offset = (CELL_W // 2) if col % 2 == 1 else 0
    row = round((by - offset) / CELL_H)
    row = max(0, min(GRID_ROWS - 1, row))

    # 3️⃣ 从下往上找第一个空位
    for r in range(row, -1, -1):
        if grid[r][col] is None:
            # 计算准确的网格坐标
            gx = col * CELL_W + BUBBLE_R
            gy = r * CELL_H + BUBBLE_R + TOP_MARGIN
            if col % 2 == 1:
                gx += CELL_W // 2  # 奇数列右移
            grid[r][col] = bubble_color
            return gx, gy
    return bx, by  # 没空位就停原处
🧲 吸附三步走：找列 → 找行 → 从下往上找空位（因为泡泡都是从上面落下来的）

📝 知识总结

知识点核心内容
三角函数的本质将角度"翻译"成 X和Y的变化量
cos（余弦）= 邻边/斜边 → 水平分量（"管左右"）
sin（正弦）= 对边/斜边 → 垂直分量（"管上下"）
弧度制math.radians(角度) —— 角度→弧度
两点求角度math.atan2(-dy, dx) —— 记住负号！
六边形网格列间距=2R，行间距=√3R，奇数行偏移半个
网格吸附找列→找行→从下往上找空位
