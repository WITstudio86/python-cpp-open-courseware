弹幕（Bullet Curtain）= 从发射点按角度和数量生成的一组子弹

🏭 弹幕生成函数 — "子弹工厂"

# 弹幕生成器 —— 一个函数，制造所有弹幕！ def create_bullet_pattern(cx, cy, start_angle, angle_range, count, speed, group, color): """参数说明（像点菜一样简单）：""" # cx, cy → 发射位置（烟花在哪炸开） # start_angle → 从哪个角度开始（0°=正右） # angle_range → 覆盖多大角度（扇形=60°, 圆形=360°） # count → 产生几颗子弹 # speed → 子弹飞多快 for i in range(count): # 计算第 i 颗子弹的角度（均匀分布） angle = start_angle + angle_range * i / (count - 1) rad = math.radians(angle) # 角度→弧度 vx = speed * math.cos(rad) # cos管左右 vy = speed * math.sin(rad) # sin管上下 bullet = Bullet(cx, cy, vx, vy, color) # 创建子弹 group.add(bullet) # 加入精灵组
关键公式：
第 i 颗子弹的角度 = start_angle + angle_range × i / (count - 1)
例如：start=60°, range=60°, count=5 → 60°、75°、90°、105°、120°

📊 扇形弹幕 vs 圆形弹幕

对比项🪭 扇形弹幕🎆 圆形弹幕
比喻 孔雀开屏 烟花绽放
发射方向 只朝前方（下方） 四面八方（360°）
start_angle 60°（扇子左边） 0°
angle_range 60° ~ 90° 360°
子弹数量 5 ~ 7 颗 16 ~ 24 颗
使用场景 普通攻击 大招 / 半血狂暴
躲避难度 ⭐⭐ ⭐⭐⭐⭐
核心区别只有两个参数：angle_range 和 count！
改一个参数，弹幕效果完全不同 —— 这就是代码复用的威力！

❤️ Boss 血条绘制

def draw_boss_health_bar(screen, boss, screen_width): bar_width = screen_width - 100 # 血条宽度（留边距） bar_height = 25 # 血条高度 bar_x, bar_y = 50, 10 # 屏幕左上角位置 # 1. 画背景（灰色底条 = 总血量） pygame.draw.rect(screen, (60,60,60), (bar_x, bar_y, bar_width, bar_height)) # 2. 画边框（白色描边，更醒目） pygame.draw.rect(screen, WHITE, (bar_x, bar_y, bar_width, bar_height), 3) # 3. 画当前血量 hp_ratio = boss.hp / boss.max_hp # 血量比例 0.0~1.0 current_w = int(bar_width * hp_ratio) # 当前血量条宽度 # 4. 颜色随血量变化：满血绿 → 半血黄 → 残血红 if hp_ratio > 0.5: color = (50,255,50) # 安全 elif hp_ratio > 0.25: color = (255,255,50) # 警告 else: color = (255,50,50) # 危险！ pygame.draw.rect(screen, color, (bar_x, bar_y, current_w, bar_height))
血条核心公式：当前宽度 = 总宽度 × (当前血量 / 最大血量)
就像手机电量条：总宽度不变，绿色部分按比例缩短！

🤖 Boss 类与游戏结构

class Boss(pygame.sprite.Sprite): def __init__(self, x, y): super().__init__() self.image = create_boss_surface() # 用Surface绘制 self.rect = self.image.get_rect(center=(x, y)) self.hp = 300 # Boss血量（玩家子弹10伤害→30枪） self.max_hp = 300 self.direction = 1 # 左右移动方向 self.attack_timer = 0 # 攻击计时器 def update(self): # Boss左右移动 self.rect.x += self.direction * 2 if self.rect.right > WIDTH or self.rect.left < 0: self.direction *= -1 # 攻击计时器递增，每60帧发射一次扇形弹幕 self.attack_timer += 1
Boss血量: 300 玩家伤害: 10/发 扇形弹幕: 每60帧 圆形弹幕: 半血后每120帧

📚 知识点回顾

知识点一句话总结
弹幕生成函数传入（起点、角度、数量、速度）→ 循环生成子弹
扇形弹幕固定角度范围（60°），向下展开，像孔雀开屏
圆形弹幕角度范围 360°，均匀分布，像烟花绽放
Boss 血条灰色底 + 彩色前景，宽度 = 总宽 × 血量比例
代码复用同一个函数，不同参数 → 不同弹幕效果
口诀：
弹幕不可怕，循环加上它；
扇形画扇子，圆形画烟花；
血条按比例，Boss 也不怕！
