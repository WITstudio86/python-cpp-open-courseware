什么是俄罗斯方块？

俄罗斯方块（Tetris）是全球最畅销的游戏之一，诞生于1984年，由苏联程序员阿列克谢·帕基特诺夫发明。

  • 7种不同形状的方块从屏幕上方落下
  • 玩家可移动和旋转方块
  • 方块落到底部后锁定
  • 填满一整行就会消除（下节课实现）
  • 方块堆到顶部=Game Over

简单规则 + 无限乐趣 = 经典永恒

二维列表表示方块

用1表示有方块，0表示空，形成一个"像素图纸"：

T型方块

[0, 1, 0] [1, 1, 1]

S型方块

[0, 1, 1] [1, 1, 0]

I型方块（注意：它是1行4列！）

[1, 1, 1, 1]
关键理解：二维列表中，外层列表代表行（Y方向），内层列表代表列（X方向）。和坐标纸一样，先写行号，再写列号。

旋转算法：两大步骤

顺时针旋转90度 = 转置 + 水平翻转

原始方块
[0,1,0] [1,1,1]
➔
第1步：转置
[0,1] [1,1] [0,1]
➔
第2步：翻转每行
[1,0] [1,1] [1,0]
理解转置：把原来的"第m行第n列"变成"第n行第m列"，就像把一张纸沿对角线翻转。用Python的 zip(*shape) 可以一行代码实现！

旋转算法：代码实现

def rotate_shape(shape): # 顺时针旋转方块90度 # 第1步：转置（行列互换） # zip(*shape) 把每一列的元素组合在一起 transposed = list(zip(*shape)) # 第2步：水平翻转每一行（[::-1]是反转语法） rotated = [list(row)[::-1] for row in transposed] return rotated

为什么O型方块旋转后还是自己？

➔

正方形转90度当然还是正方形！这也证明了我们的旋转算法是正确的。

碰撞检测逻辑

方块能否放在某个位置？需要同时满足两个条件：

条件一：边界检测

  • 不能超出左边界（x < 0）
  • 不能超出右边界（x ≥ 10）
  • 不能超出下边界（y ≥ 20）
  • 可以超出上边界（方块刚生成时）

条件二：重叠检测

  • 方块的每个格子（值为1）
  • 不能和棋盘中已有的方块重叠
  • 即 grid[y][x] != 0 的位置不能放
核心原则：每次移动/旋转前，先用碰撞检测函数检查目标位置。只有检查通过（返回True），才执行移动。这就是"先检查，再移动"！

碰撞检测：代码实现

def is_valid_position(shape, grid_x, grid_y): # 遍历方块的每一个格子 for y, row in enumerate(shape): for x, cell in enumerate(row): if cell == 1: # 只检查有方块的位置 board_x = grid_x + x board_y = grid_y + y # 条件一：边界检测 if board_x < 0 or board_x >= COLS: return False if board_y >= ROWS: return False if board_y < 0: continue # 在棋盘上方，允许 # 条件二：重叠检测 if grid[board_y][board_x] != 0: return False return True # 全部通过！
特别提醒：board_y < 0 时使用 continue 而不是 return False。因为方块刚生成时，可能部分在棋盘上方——这是正常的！

方块移动与锁定机制

四种控制操作

按键操作
← 左键左移一格
→ 右键右移一格
↑ 上键顺时针旋转90°
↓ 下键加速下落一格

每次移动前都要做碰撞检测！

锁定是什么？

当方块无法继续下落（碰到边界或已有方块），就执行锁定：

  1. 把方块所有小格子的颜色写入 grid[y][x]
  2. 生成一个新方块
  3. 新方块从顶部开始下落

核心循环：生成 → 控制 → 下落 → 锁定 → 生成...

自动下落（用时间控制）

fall_interval = 800 # 每800毫秒下落一格 last_fall = pygame.time.get_ticks() # 在主循环中检查时间： if pygame.time.get_ticks() - last_fall > fall_interval: if is_valid_position(shape, cur_x, cur_y + 1): cur_y += 1 # 下落 else: lock_piece(); new_piece() # 锁定+新生 last_fall = pygame.time.get_ticks()

核心代码示例（完整框架）

# ===== 棋盘初始化 ===== COLS, ROWS = 10, 20 grid = [[0 for _ in range(COLS)] for _ in range(ROWS)] # ===== 方块定义（7种） ===== SHAPES = { 'I': [[1,1,1,1]], 'O': [[1,1],[1,1]], 'T': [[0,1,0],[1,1,1]], 'S': [[0,1,1],[1,1,0]], 'Z': [[1,1,0],[0,1,1]], 'J': [[1,0,0],[1,1,1]], 'L': [[0,0,1],[1,1,1]], } # ===== 旋转函数 ===== def rotate_shape(shape): transposed = list(zip(*shape)) return [list(row)[::-1] for row in transposed] # ===== 碰撞检测 ===== def is_valid_position(shape, gx, gy): for y, row in enumerate(shape): for x, c in enumerate(row): if c: bx, by = gx + x, gy + y if bx < 0 or bx >= COLS: return False if by >= ROWS: return False if by < 0: continue if grid[by][bx]: return False return True # ===== 锁定方块 ===== def lock_piece(): for y, row in enumerate(current_shape): for x, c in enumerate(row): if c: bx, by = current_x + x, current_y + y if 0 <= by < ROWS and 0 <= bx < COLS: grid[by][bx] = current_color

主游戏循环结构

def main(): pygame.init() screen = pygame.display.set_mode((600, 700)) clock = pygame.time.Clock() new_piece() # 生成第一个方块 fall_interval = 800 last_fall = pygame.time.get_ticks() running = True while running: # ---- 事件处理 ---- for event in pygame.event.get(): if event.type == pygame.QUIT: running = False elif event.type == pygame.KEYDOWN: if event.key == pygame.K_LEFT: if is_valid_position(cur_shape, cur_x-1, cur_y): cur_x -= 1 elif event.key == pygame.K_RIGHT: if is_valid_position(cur_shape, cur_x+1, cur_y): cur_x += 1 elif event.key == pygame.K_DOWN: if is_valid_position(cur_shape, cur_x, cur_y+1): cur_y += 1 elif event.key == pygame.K_UP: rotated = rotate_shape(cur_shape) if is_valid_position(rotated, cur_x, cur_y): cur_shape = rotated # ---- 自动下落 ---- now = pygame.time.get_ticks() if now - last_fall > fall_interval: if is_valid_position(cur_shape, cur_x, cur_y+1): cur_y += 1 else: lock_piece() new_piece() last_fall = now # ---- 绘制 ---- screen.fill((0,0,0)) draw_grid(screen) pygame.display.flip() clock.tick(60) pygame.quit()

三个核心循环阶段：事件处理 → 自动下落 → 绘制画面（每帧重复）
