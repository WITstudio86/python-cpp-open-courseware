用变量记录当前状态

# 定义4个游戏状态（用大写常量，不易打错）
STATE_WAIT_FIRST  = "wait_first"    # 等待翻第一张牌
STATE_WAIT_SECOND = "wait_second"   # 等待翻第二张牌
STATE_CHECKING    = "checking"       # 正在检查匹配
STATE_GAME_OVER   = "game_over"      # 游戏结束（胜利）

# 当前游戏状态（初始为等待第一张）
game_state = STATE_WAIT_FIRST

# 记录选中的两张牌的位置
first_card = None    # (row, col) 或 None
second_card = None

# 统计信息
steps = 0            # 翻了几"对"牌（每翻两张算一步）
pairs_found = 0     # 已经成功配对的牌对数
为什么需要这些变量？
程序需要"记住"现在该做什么、刚才翻了哪张牌、还剩多少配对。

知识二：根据状态处理点击

同一个"点击"动作，在不同状态下做不同的事！

elif event.type == pygame.MOUSEBUTTONDOWN:
    row, col = get_card_at_pos(event.pos[0], event.pos[1])
    card = board[row][col]

    # ── 状态1：等待翻第一张牌 ──
    if game_state == STATE_WAIT_FIRST:
        if card["state"] == "hidden":
            card["state"] = "revealed"
            first_card = (row, col)          # 记下位置
            game_state = STATE_WAIT_SECOND    # 切换状态！

    # ── 状态2：等待翻第二张牌 ──
    elif game_state == STATE_WAIT_SECOND:
        if card["state"] == "hidden":
            card["state"] = "revealed"
            second_card = (row, col)         # 记下位置
            steps += 1                      # 步数+1
            game_state = STATE_CHECKING       # 进入检查！
注意： 不能点已经翻开的牌！if card["state"] == "hidden" 是关键判断。

知识三：比较两张牌是否相同

# 在主循环中处理"检查匹配"状态
if game_state == STATE_CHECKING:
    r1, c1 = first_card
    r2, c2 = second_card
    card1 = board[r1][c1]
    card2 = board[r2][c2]

    # ═══ 比较颜色是否相同 ═══
    if card1["color"] == card2["color"]:
        # ✅ 匹配成功！
        card1["state"] = "matched"
        card2["state"] = "matched"
        pairs_found += 1

        if pairs_found == 8:           # 8对全找到了
            game_state = STATE_GAME_OVER
        else:
            game_state = STATE_WAIT_FIRST   # 继续找

    else:
        # ❌ 不匹配！先刷新显示，再延迟翻回
        pygame.display.flip()          # ⚠️ 先让玩家看到第二张牌
        pygame.time.delay(500)       # 等500毫秒（0.5秒）
        card1["state"] = "hidden"     # 翻回第一张
        card2["state"] = "hidden"     # 翻回第二张
        game_state = STATE_WAIT_FIRST   # 重新开始

    # 清空记录
    first_card = None
    second_card = None

为什么需要延迟？pygame.time.delay()

❌ 如果不加延迟：

翻第二张牌 → 颜色闪过（太快看不见！）→ 立刻翻回

玩家根本来不及记住牌的位置！

✅ 加上延迟：

翻第二张牌 → 显示两张牌 → 等0.5秒 → 翻回

玩家有足够时间看清并记忆！

关键顺序（非常重要！）：
pygame.display.flip() 必须在 pygame.time.delay(500) 前面
因为 delay 会暂停整个程序——如果不先 flip（刷新显示），屏幕上就看不到第二张牌！ 
# ✅ 正确顺序
pygame.display.flip()    # 1. 先把画面刷新到屏幕上
pygame.time.delay(500)   # 2. 再暂停0.5秒让玩家看

# ❌ 错误顺序（先暂停再刷新——什么都看不到）
# pygame.time.delay(500)
# pygame.display.flip()

知识四：显示步数和配对进度

def draw_ui(screen, steps, pairs_found, game_state):
    font = pygame.font.Font(None, 36)       # 默认字体，36号
    big_font = pygame.font.Font(None, 60)   # 胜利用的大字体

    # 左上角：步数
    text1 = font.render(f"步数: {steps}", True, (255,255,255))
    screen.blit(text1, (20, 20))

    # 右上角：配对进度
    text2 = font.render(f"配对: {pairs_found} / 8", True, (255,255,255))
    screen.blit(text2, (SCREEN_W - 200, 20))

    # 胜利画面
    if game_state == STATE_GAME_OVER:
        # 半透明黑色遮罩
        overlay = pygame.Surface((SCREEN_W, SCREEN_H))
        overlay.set_alpha(180)
        overlay.fill((0, 0, 0))
        screen.blit(overlay, (0, 0))

        # 胜利文字（居中）
        win_text = big_font.render("恭喜你赢了！", True, (255,215,0))
        rect = win_text.get_rect(center=(SCREEN_W//2, SCREEN_H//2 - 30))
        screen.blit(win_text, rect)

        # 显示步数
        final_text = font.render(f"你用了 {steps} 步！按 R 键重玩", True, (255,255,255))
        rect2 = final_text.get_rect(center=(SCREEN_W//2, SCREEN_H//2 + 30))
        screen.blit(final_text, rect2)

完整游戏架构图

步骤做什么
初始化创建棋盘（洗牌）、设置状态变量、创建窗口
事件处理QUIT退 / MOUSEBUTTONDOWN点击翻牌 / KEYDOWN按R重开
状态机逻辑WAIT_FIRST → WAIT_SECOND → CHECKING → WAIT_FIRST (或 GAME_OVER)
比较颜色card1["color"] == card2["color"] ? 匹配 : 不匹配
延迟翻回不匹配时 flip() + delay(500) 再翻回去
胜利判断pairs_found == 8 → GAME_OVER
绘制界面draw_board() + draw_ui() + flip()

写代码时注意这些坑！

  • flip() 和 delay() 的顺序 —— 必须先 flip 再 delay，否则看不到牌
  • 点了同一个位置两次 —— 要判断第二张牌和第一张不是同一张
  • 状态没切换回来 —— CHECKING 结束后必须回到 WAIT_FIRST 或 GAME_OVER
  • 重复翻已翻的牌 —— 只处理 state == "hidden" 的牌
  • R键重置不完整 —— 忘了重置某个变量，导致游戏状态混乱
  • 行和列搞反 —— first_card = (row, col)，使用时也要 (row, col) 的顺序
