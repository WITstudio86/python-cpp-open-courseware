🕐 倒计时是怎么实现的？

计算机内部有一个"毫秒计时器"，从开机就在数。

游戏开始时刻   =   get_ticks()   （比如 52300 ms）

当前时刻   =   get_ticks()   （比如 65300 ms）

⬇️

已过时间 = 65300 - 52300 = 13000 ms = 13 秒

剩余时间 = 30 - 13 = 17 秒 ⏱️

🕐 倒计时 — 代码实现

# 游戏开始前，记录起始毫秒数 start_ticks = pygame.time.get_ticks() GAME_DURATION = 30 # 游戏时长 30 秒 # 主循环中，每帧计算剩余时间 while running: elapsed = pygame.time.get_ticks() - start_ticks remaining = GAME_DURATION - elapsed // 1000 if remaining <= 0: remaining = 0 game_over = True

⚠️ 注意：1 秒 = 1000 毫秒，`// 1000` 是整数除法
