💰 步骤2：收集金币系统
核心思路：碰到金币 → 标记为地板 → 加分
def move_player(dx, dy): global player_x, player_y, steps, coins_collected new_x = player_x + dx new_y = player_y + dy if not can_move(new_x, new_y): return # 撞墙或出界 player_x, player_y = new_x, new_y steps += 1 # 步数 +1 # ★ 核心：检查是否碰到金币 if MAZE[player_y][player_x] == 3: coins_collected += 1 # 加分数 MAZE[player_y][player_x] = 0 # 金币变地板
关键点：
1. 先移动 → 再检查（顺序不能反！）
2. MAZE[y][x] = 0 直接修改地图数据，金币"吃掉"就消失
3. 这就是所有 RPG 游戏拾取物品的基本逻辑！

🏆 步骤4：胜利判定 & 统计画面
胜利判定
# 在游戏主循环中 if not won: if MAZE[player_y][player_x] == 2: won = True # 胜利！

到达终点格子(值为2) → won 变为 True
if not won 防止重复触发

禁止移动
if not won: # 胜利后不再响应按键 if event.key == K_LEFT: move_player(-1, 0)
