核心算法：BFS（Breadth-First Search）—— 今天的主角！

🎮 泡泡龙的消除规则

规则很简单：

  • 发射泡泡，停到网格中
  • 如果它让 ≥3 个同色泡泡 连在一起
  • 这些泡泡就会 消除！
  • 消除后，悬空的泡泡会掉落

💡 问题：怎么找出"连在一起的同色泡泡"？

红色泡泡相连（3个）→ 消除！

↑ 这3个红色是连通的 → 消除！

（蓝色、绿色、黄色各1个 → 不消除）

🌊 BFS = 水波扩散

往平静的水面扔一颗石子，涟漪会一圈一圈向外扩散——这就是 BFS！

BFS 的核心：

  • 从起点开始，把起点放进队列（排队）
  • 取出队首，检查它的所有邻居
  • 符合条件的邻居加入队列，再标记为已访问
  • 重复直到队列为空 → 访问过的就是"连通分量"

📋 BFS 执行步骤（一步一步看）

步骤操作队列内容已访问
0把起点 (2,3) 放入队列[(2,3)]{(2,3)}
1弹出 (2,3)，检查它的邻居[(1,2), (1,3), (3,3)]{(2,3), (1,2), (1,3), (3,3)}
2弹出 (1,2)，检查它的邻居[(1,3), (3,3), (0,2)]{(2,3), (1,2), (1,3), (3,3), (0,2)}
3弹出 (1,3)，检查邻居（无新发现）[(3,3), (0,2)]（不变）
4弹出 (3,3)，检查邻居[(0,2), (3,4)]+{(3,4)}
...继续直到队列为空[]最终：所有连通泡泡

🎯 BFS 结束后，visited 集合 里的所有泡泡就是"与起点连通的所有同色泡泡"！

🔷 六边形网格的"邻居"

六边形网格中，偶数行和奇数行的邻居位置不同！

偶数行（row % 2 == 0）

  (-1,-1)  (-1,0)
(0,-1)  自己  (0,1)
  (1,-1)   (1,0)

奇数行（row % 2 == 1）

  (-1,0)   (-1,1)
(0,-1)  自己  (0,1)
  (1,0)    (1,1)

🐝 像蜂窝一样排列，相邻行会错开半个格子！

为什么是这6个方向？六边形的每个泡泡最多接触6个邻居（上、下、左上、左下、右上、右下）

💻 BFS 代码框架（重点！）

# 导入双端队列（队首弹出效率 O(1)）
from collections import deque

def bfs_same_color(grid, start_row, start_col):
    # 1. 准备：队列 + 已访问集合 + 目标颜色
    queue = deque()
    queue.append((start_row, start_col))
    visited = set()
    visited.add((start_row, start_col))
    target = grid[start_row][start_col]
    result = [(start_row, start_col)]

    # 2. 主循环：队列不为空就继续
    while queue:
        row, col = queue.popleft()  # 取队首

        # 3. 检查 6 个邻居方向
        for dr, dc in neighbors:
            nr, nc = row + dr, col + dc
            if (nr, nc) in visited:  continue
            if nr < 0 or nr >= rows:  continue
            if grid[nr][nc] == target:  # 同色！
                visited.add((nr, nc))
                queue.append((nr, nc))
                result.append((nr, nc))

    return result  # 所有连通的同色泡泡

三个关键数据结构：

🔹 queue（队列）—— 待探索列表，先入先出
🔹 visited（集合）—— 防止重复访问，避免死循环
🔹 result（列表）—— 收集所有同色泡泡

✂️ 判断是否消除

def try_eliminate(grid, row, col):
    # 1. 用 BFS 找到所有连通的同色泡泡
    connected = bfs_same_color(grid, row, col)

    # 2. 判断数量：泡泡龙规则是 ≥ 3
    if len(connected) >= 3:
        # 消除！把格子清空
        for r, c in connected:
            grid[r][c] = None
        return connected  # 返回被消除的泡泡
    else:
        return []  # 不够3个，不消除

连通的同色泡泡 ≥ 3 个 → 🎆 消除！

连通的同色泡泡 ＜ 3 个 → 😴 保留不动

🍇 悬空检测 —— "摘葡萄"

🍇 比喻：摘葡萄

葡萄一串串挂在藤上。
从中摘掉几颗 → 下面的葡萄断了连接 → 整串掉落！

  • 藤 = 网格的顶部行
  • 连着藤的 = 安全的，留着
  • 没连藤的 = 悬空了，掉落！

算法步骤：

1 从顶部所有有泡泡的格子出发

2 用 BFS 向下探索所有连通的泡泡

3 没被访问到的泡泡 = 悬空！

💻 悬空检测代码

def find_floating(grid):
    # 1. 从顶部出发，把所有顶部泡泡加入队列
    queue = deque()
    visited = set()
    for col in range(cols):
        if grid[0][col] is not None:
            queue.append((0, col))
            visited.add((0, col))

    # 2. BFS：从顶部往下找所有"还连着"的泡泡
    while queue:
        row, col = queue.popleft()
        for dr, dc in neighbors:
            nr, nc = row + dr, col + dc
            if (nr, nc) in visited: continue
            if nr < 0 or nr >= rows: continue
            if grid[nr][nc] is not None:
                visited.add((nr, nc))
                queue.append((nr, nc))

    # 3. 找没被访问的 = 悬空的泡泡
    floating = []
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] is not None and (r, c) not in visited:
                floating.append((r, c))

    return floating

关键思想：两次 BFS！第一次找同色消除，第二次找悬空掉落

⚠️ 常见问题与解决

问题原因解决
🔄 BFS 死循环 忘记标记 visited 入队时立刻 visited.add()
❌ 消除后有残留 只设 None 但绘制时仍画了 绘制时检查 if grid[r][c] is not None
📐 悬空检测不准 偶/奇数行偏移搞反了 打印调试，用纸笔画出网格
⏱️ 动画太快/太慢 scale 步长不合适 调整步长：太快→减小，太慢→增大
🐌 BFS 效率低 用了 list 当队列 改用 collections.deque（O(1) 弹出）
