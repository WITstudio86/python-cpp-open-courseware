事件是什么？

在 Pygame 中，事件（Event） 就是游戏中发生的各种"事情"。

打个比方： 你在玩游戏时 ——
鼠标点击 = 一个事件   键盘按键 = 一个事件   关闭窗口 = 一个事件

Pygame 会把这些事件 放进一个队列 里，我们的程序需要逐个取出来处理。

核心思路： "发生什么 → 产生事件 → 程序获取事件 → 做出反应"
↻

Pygame 的事件循环

游戏在每一帧都会执行事件循环：

关键函数：
pygame.event.get() — 获取当前发生的所有事件列表

通常的写法：

for event in pygame.event.get(): # 处理每一个事件 if event.type == pygame.QUIT: running = False

代码含义：用 for 循环遍历每一个事件，根据事件类型做不同处理。

✕

QUIT 事件 — 如何关闭窗口

当你点击游戏窗口右上角的 ✕ 关闭按钮 时，Pygame 会产生一个 pygame.QUIT 事件。

如果不处理 QUIT 事件会怎样？
你就无法正常关闭窗口！上面的 ✕ 按钮会失效，只能用任务管理器强制结束程序。

所以 每个 Pygame 程序 都要处理 QUIT 事件：

if event.type == pygame.QUIT: # 退出游戏循环 running = False
⌨

KEYDOWN 事件 — 检测按键

当你按下键盘上的任意一个键时，Pygame 会产生一个 pygame.KEYDOWN 事件。

每一个按键都有一个"身份证"——
event.key 属性表示你按下的是哪个键。

基本写法：

if event.type == pygame.KEYDOWN: if event.key == pygame.K_RIGHT: # 按下了右箭头键 x += 5
🌐

方向键常量

Pygame 为方向键定义了对应的常量：

方向Pygame 常量
↑ 上pygame.K_UP
↓ 下pygame.K_DOWN
← 左pygame.K_LEFT
→ 右pygame.K_RIGHT

还有这些常用键：

记忆口诀：

K_UP = Key Up
K_DOWN = Key Down
K_LEFT = Key Left
K_RIGHT = Key Right

都是 pygame.K_ + 英文方向单词！
①

方式一：event.get() 检测按键

使用 pygame.event.get() 获取事件列表，检查 KEYDOWN 事件：

特点： 按键每按下一次，只触发一次事件。
# 在游戏循环中 for event in pygame.event.get(): if event.type == pygame.QUIT: running = False if event.type == pygame.KEYDOWN: if event.key == pygame.K_LEFT: player_x -= speed elif event.key == pygame.K_RIGHT: player_x += speed elif event.key == pygame.K_UP: player_y -= speed elif event.key == pygame.K_DOWN: player_y += speed

适合场景：菜单选择、技能释放（按一次触发一次）

②

方式二：key.get_pressed() 持续检测

使用 pygame.key.get_pressed() 获取所有按键的实时状态：

特点： 只要键按住不放，每一帧都能检测到。角色会持续移动！
# 在游戏循环中（放在 for event 循环外面） keys = pygame.key.get_pressed() if keys[pygame.K_LEFT]: player_x -= speed if keys[pygame.K_RIGHT]: player_x += speed if keys[pygame.K_UP]: player_y -= speed if keys[pygame.K_DOWN]: player_y += speed

适合场景：角色移动（按住方向键持续走动）

⚖

对比两种方式

pygame.event.get() pygame.key.get_pressed()
触发方式 按键按下时触发一次 按住时每帧连续触发
返回数据 事件对象列表 布尔值元组（True/False 数组）
代码位置 在 for event 循环内 在循环外（或循环后）
典型用法 菜单选择、跳跃、技能 角色移动、赛车加速
同时按多键 每次只处理一个事件 同时检测多个键
实际游戏开发中，两种方式经常搭配使用：
用 get_pressed() 做持续移动 + 用 event.get() 做按键触发
🔒

边界限制 — 别让角色跑出屏幕！

如果角色一直移动，就会跑到窗口外面去。我们需要用 if 语句限制它的范围。

核心思路： 移动后检查坐标，如果超出边界就把它拉回来。
# 角色移动后，限制在窗口范围内 if player_x < 0: # 不能超出左边界 player_x = 0 if player_x > WIDTH - player_size: # 不能超出右边界 player_x = WIDTH - player_size if player_y < 0: # 不能超出上边界 player_y = 0 if player_y > HEIGHT - player_size: # 不能超出下边界 player_y = HEIGHT - player_size

另一种写法：player_x = max(0, min(player_x, WIDTH - player_size)) 一行搞定！

💻

完整代码展示

把今天学的所有内容整合到一起：

import pygame pygame.init() WIDTH, HEIGHT = 800, 600 screen = pygame.display.set_mode((WIDTH, HEIGHT)) pygame.display.set_caption("键盘控制角色") # 角色的初始位置 player_x, player_y = WIDTH // 2, HEIGHT // 2 player_size = 50 speed = 5 clock = pygame.time.Clock() running = True while running: # 1. 事件处理 for event in pygame.event.get(): if event.type == pygame.QUIT: running = False # 2. 持续按键检测 keys = pygame.key.get_pressed() if keys[pygame.K_LEFT]: player_x -= speed if keys[pygame.K_RIGHT]: player_x += speed if keys[pygame.K_UP]: player_y -= speed if keys[pygame.K_DOWN]: player_y += speed # 3. 边界限制 player_x = max(0, min(player_x, WIDTH - player_size)) player_y = max(0, min(player_y, HEIGHT - player_size)) # 4. 绘制 screen.fill((30, 30, 30)) pygame.draw.rect(screen, (0, 150, 255), (player_x, player_y, player_size, player_size)) pygame.display.flip() clock.tick(60) pygame.quit()
