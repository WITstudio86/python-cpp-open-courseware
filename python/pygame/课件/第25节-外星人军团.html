新概念 精灵 Sprite —— 会动的小贴纸

在之前的课程中，我们用字典或列表来管理游戏物体，代码很乱。

Pygame 提供了一个更好的解决方案 —— 精灵（Sprite）

精灵是一种把"数据"和"行为"打包在一起的类

一个精灵自己知道：
🖼️ 自己长什么样子 → self.image
📍 自己在屏幕的什么位置 → self.rect
🏃 自己每帧要做什么 → self.update()

📌 比喻：精灵就像一个智能贴纸——它知道自己的图案（image）、 贴在哪里（rect）、以及怎么移动（update）。

代码 创建外星人精灵

import pygame class Alien(pygame.sprite.Sprite): # ① 继承 Sprite 类 """外星人精灵""" def __init__(self, x, y, color): super().__init__() # 必须调用父类初始化 self.image = pygame.Surface((40, 30)) # ② image：外观 self.image.fill(color) self.rect = self.image.get_rect() # ② rect：位置+大小 self.rect.x = x self.rect.y = y def update(self): # ③ 每帧的行为 pass # 这里写移动逻辑

新概念 精灵组 Group —— 班级花名册

如果我们有 30个 外星人，不能写30行代码分别去 update 和 draw。

精灵组可以帮我们批量管理一组精灵！

操作代码说明
创建组group = pygame.sprite.Group()新建一个空精灵组
添加精灵group.add(sprite)把精灵加入组
批量更新group.update()调用组内所有精灵的 update()
批量绘制group.draw(screen)把组内所有精灵画到屏幕
删除精灵sprite.kill()从所有组中移除自己
查看数量len(group)组内有多少精灵

📌 比喻：精灵组就像班级花名册——update() 就是喊"全班起立"， 所有同学一起站，不用一个一个点名！

代码 精灵组的使用

# 创建三个精灵组 aliens = pygame.sprite.Group() # 外星人专用组 bullets = pygame.sprite.Group() # 子弹专用组 all_sprites = pygame.sprite.Group() # 总组（所有可见物体） # 批量创建外星人并加入组 for row in range(3): # 3 行 for col in range(8): # 8 列 alien = Alien(col * 60 + 80, row * 50 + 50, GREEN) aliens.add(alien) # 加入外星人组 all_sprites.add(alien) # 也加入总组 # 在主循环中，一行搞定所有精灵！ aliens.update() # 全体外星人自行更新 all_sprites.draw(screen) # 所有精灵一起画到屏幕

看！不管有多少外星人，主循环里只需要两行代码！

核心 编队移动算法 —— 今天最难的部分！

算法规则（用眼睛看，用脑子想）

1️⃣ 所有外星人一起往同一个方向水平移动
2️⃣ 当最边上的外星人碰到屏幕边缘：
    🔄 全体换方向（左→右 / 右→左）
    ⬇️ 全体向下移动一行
3️⃣ 继续按新方向移动，重复上述过程

⚠️ 关键理解

触边检测要在移动之前做！

判断的是"即将"超出，而不是"已经"超出。

否则外星人会在屏幕边缘来回抖动（bug！）

📐 编队移动算法 —— 三步走

①
检测边界
遍历所有外星人
看最边的那个
是否"即将"出界
→
②
触边响应
如果即将出界：
↕ 全体下移
↔ 方向反转
→
③
水平移动
不管是否换向
全体按当前方向
移动一步
class AlienFleet: def update(self): # ① 检查是否有人触边 for alien in self.aliens: if alien.rect.right >= 800 or alien.rect.left <= 0: self.direction *= -1 # ② 反转方向 for a in self.aliens: a.rect.y += 20 # ② 集体下移 break # 检测到一次就够了 # ③ 按方向集体移动 for alien in self.aliens: alien.rect.x += self.direction * self.speed

代码 编队移动管理器 —— 完整版

class AlienFleet: """外星人舰队管理器 —— 负责编队移动""" def __init__(self): self.aliens = pygame.sprite.Group() self.direction = 1 # 方向：1=右，-1=左 self.speed = 2 # 水平速度 self.drop = 20 # 每次下移距离 # 创建 3行×8列 的外星人编队 for row in range(3): for col in range(8): self.aliens.add( Alien(col*65+60, row*55+40)) def update(self): """编队移动算法""" # 第一步：检测边界 need_reverse = False for alien in self.aliens: if self.direction > 0 and alien.rect.right >= 790: need_reverse = True; break if self.direction < 0 and alien.rect.left <= 10: need_reverse = True; break # 第二步：触边则下移 + 换向 if need_reverse: self.direction *= -1 # 换向 for a in self.aliens: a.rect.y += self.drop # 下移 # 第三步：按方向移动 for a in self.aliens: a.rect.x += self.direction * self.speed

📌 三步缺一不可，顺序不能乱：先检测 → 再响应 → 最后移动

📋 课堂小结

知识点 一句话总结
Sprite 精灵 把 image(外观) + rect(位置) + update(行为) 打包在一个类里
Group 精灵组 批量管理精灵的"花名册"，一行代码搞定全体更新和绘制
编队移动 先检测边界 → 触边响应(下移+换向) → 统一水平移动
碰撞检测 groupcollide() 自动检测并销毁碰撞的两个精灵
