📊 多关卡数据 = 三维列表

上节课：二维列表 = 一个关卡的地图

本节课：三维列表 = 多个关卡的地图集合

# 关卡系统：用列表存储多个关卡 # levels[关卡索引][行][列] = 三维列表 levels = [ # ====== 第1关：初入仓库 ====== [[1,1,1,1,1], [1,4,0,3,1], [1,0,2,0,1], [1,1,1,1,1]], # ====== 第2关：渐入佳境 ====== [[1,1,1,1,1], [1,4,1,3,1], [1,0,2,0,1], [1,1,1,1,1]], # ====== 第3关：仓库达人 ====== [[1,1,1,1,1], [1,4,0,3,1], [1,2,2,0,1], [1,1,1,1,1]], ] # 访问方式 current_level = 0 # 当前关卡索引 map_data = levels[current_level] # 取出第1关的二维地图 cell = map_data[1][1] # 第1行第1列 = 4（玩家）

💡 核心思想：把多个二维地图装进一个大列表！

🔄 关卡加载 load_level()

把地图数据拆成 静态部分 + 动态部分

def load_level(level_index): global player_x, player_y, boxes, targets, static_grid map_data = levels[level_index] boxes = []; targets = []; static_grid = [] for row in range(10): for col in range(10): cell = map_data[row][col] if cell == 1: static_grid[row][col] = 1 # 墙 elif cell == 2: static_grid[row][col] = 2 # 目标点 targets.append((col, row)) elif cell == 3: boxes.append((col, row)) # 箱子 elif cell == 4: player_x, player_y = col, row # 玩家 else: static_grid[row][col] = 0 # 地板 # 关卡切换只需要两行代码！ current_level = 1 # 切换到第2关 load_level(current_level) # 加载新关卡

🔑 关键：静态数据不动，动态数据方便操作和撤销

🎮 关卡切换——状态机的力量

用 game_state 变量控制不同的游戏画面

menu → 点击 → playing → 通关 → win → N键 → playing
# 事件处理中的状态切换 if game_state == "menu": if 点击关卡按钮: current_level = 按钮索引 load_level(current_level) game_state = "playing" elif game_state == "playing": if event.key == K_ESCAPE: game_state = "menu" if event.key == K_r: reset_level() if check_win(): game_state = "win" elif game_state == "win": if event.key == K_n: # 下一关 current_level += 1 load_level(current_level) game_state = "playing"

💡 状态机：每个状态只处理自己关心的按键和事件

✅ 通关检测 & 闪烁动画

通关检测（超简单！）

def check_win(): for (tx, ty) in targets: if (tx, ty) not in boxes: return False return True # 所有目标→箱子 ✓

闪烁动画（时间魔法）

elapsed = get_ticks() - start flash = (elapsed // 200) % 2 if flash == 0: color = GREEN # 闪烁！ else: color = RED # 变回

🪄 闪烁动画公式

(当前时间 // 间隔) % 2 = 0 或 1 交替 → 产生闪烁！

改 200 改速度，改 2 改状态数

🖱️ 选关界面设计

就是 画按钮 + 检测点击，和之前做的菜单一样！

# 生成关卡按钮（3列布局） level_buttons = [] for i in range(len(levels)): col = i % 3; row = i // 3 x = 80 + col * 200; y = 220 + row * 140 btn = pygame.Rect(x, y, 160, 90) level_buttons.append(btn) # 检测点击 if event.type == MOUSEBUTTONDOWN: for i, btn in enumerate(level_buttons): if btn.collidepoint(event.pos): current_level = i load_level(i) game_state = "playing" # 悬停效果 — 让按钮有「呼吸感」 if btn.collidepoint(mouse_pos): color = (120, 220, 120) # 亮绿 else: color = (80, 160, 80) # 暗绿

🎨 悬停效果 是好 UI 的基本素养！

📁 JSON 读写关卡数据（选学）

把关卡数据存到文件 → 代码和内容分离

保存关卡

import json with open("levels.json", "w") as f: json.dump(levels, f, indent=2, ensure_ascii=False) # dump = 倒出数据

读取关卡

import json with open("levels.json", "r") as f: levels = json.load(f) # load = 装入数据 print(len(levels)) # 输出：3

📋 口诀

dump = 倒出去（写文件）   |   load = 装进来（读文件）

JSON 文件是人类可读的纯文本，可以用记事本打开修改！

🔄 完整游戏流程总览

步骤游戏状态玩家操作代码动作
1选关界面点击关卡按钮load_level() → playing
2游戏中方向键移动 / 推箱子move_player() → 步数+1
3游戏中按 R 键reset_level() 重新开始
4游戏中按 U 键undo_move() 撤销一步
5游戏中所有箱子到位check_win() → win 状态
6通关动画观看闪烁效果get_ticks() 控制闪烁
7通关画面按 N 键下一关 / 回到选关
8通关画面按 ESC 键回到选关界面

🔑 核心：game_state 变量决定一切行为
