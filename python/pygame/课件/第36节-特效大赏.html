🌠 拖尾残影原理

核心思想

每一帧保存物体位置 → 绘制时画N个"历史残影" → 越旧越透明

就像用手指在满是灰尘的玻璃上画线——当前位置最清晰，旧痕迹逐渐变淡

实现三步曲

  1. 建列表 trail = []
  2. 每帧 trail.insert(0, pos)
  3. 超过N个就 pop()

为什么用reversed()？

先画最旧的（最透明，在底层）
→ 再画最新的（最不透明，在顶层）

如果反过来，旧残影会盖住新残影！

💻 拖尾代码实现

# 1. 存储历史位置
trail_positions = []
MAX_TRAIL = 20

# 2. 每帧更新（最新位置插到最前面）
trail_positions.insert(0, (ball_x, ball_y))
if len(trail_positions) > MAX_TRAIL:
    trail_positions.pop()  # 移除最旧的

# 3. 绘制（从旧到新，越来越不透明）
for i, (tx, ty) in enumerate(reversed(trail_positions)):
    alpha = int(255 * i / len(trail_positions))
    ghost = make_ball_surf(radius, color)
    ghost.set_alpha(alpha)          # ← 关键！
    screen.blit(ghost, (tx - radius, ty - radius))

💡 核心：set_alpha() 控制每个残影的透明度，越旧的残影 alpha 越小 → 越透明 → 拖尾效果！

💬 弹出文字动画

经典游戏效果：伤害数字 / 得分飘字

玩家得分时，"+100"从目标位置向上飘起，逐渐变淡消失。

动画三要素

  • 向上移动：y -= speed
  • 透明度渐减：alpha -= fade
  • 生命控制：alpha降到0 → 移除

关键参数调优

  • 浮动速度太快 → 看不清楚
  • 浮动速度太慢 → 拖沓不干脆
  • 推荐：每秒上升60~120像素
class FloatingText:
    def __init__(self, x, y, text):
        self.x, self.y = x, y
        self.text = text
        self.alpha = 255       # 初始不透明
        self.vy = -2.0         # 向上速度
        self.life = 1.0        # 生命值

🎭 淡入淡出转场

状态机设计

IDLE
空闲
→
FADE_IN
遮罩变黑
→
WAIT
停顿0.3s
→
FADE_OUT
遮罩消失
→
IDLE

各状态做什么？

  • FADE_IN：alpha从0→255（画面渐黑）
  • WAIT：保持黑屏0.3秒（呼吸感）
  • FADE_OUT：alpha从255→0（画面渐亮）

为什么中间要停顿？

给玩家一个"缓冲"——知道场景正在切换。如果没有停顿，淡入后立刻淡出，看起来像画面闪了一下。

💻 转场代码实现

# 更新转场状态
if state == "fade_in":
    alpha += 500 * dt
    if alpha >= 255:
        alpha = 255; state = "wait"; timer = 0.3

elif state == "wait":
    timer -= dt
    if timer <= 0: state = "fade_out"

elif state == "fade_out":
    alpha -= 500 * dt
    if alpha <= 0: alpha = 0; state = "idle"

# 绘制遮罩
if state != "idle":
    overlay = pygame.Surface((W, H))
    overlay.fill((0, 0, 0))
    overlay.set_alpha(int(alpha))   # 控制遮罩透明度
    screen.blit(overlay, (0, 0))

💡 模式切换：在实际程序中，我们在FADE_OUT完成后切换场景（比如换背景、换关卡）。
