第 33 节

跑 和 跳

重力、跳跃与平台碰撞
Pygame 游戏开发课程 | 适用年龄 10-15 岁

学习目标

  • 理解游戏中重力的模拟方法
  • 掌握跳跃的物理原理
  • 学会三种平台碰撞的处理方式
  • 能够创建多个平台组成的小关卡

重力 —— 让角色"掉下来"

现实中的重力

地球重力让一切物体往下掉。扔一个球，它会先上升、减速、再加速下落。

游戏中的重力（超级简单！）

每帧做两件事：

vy = vy + GRAVITY （速度不断增加）
y = y + vy （位置跟着改变）

💡 vy是垂直速度，GRAVITY是重力加速度（比如 0.8）

跳跃 —— 给角色一个"向上的推力"

跳跃的本质

按下空格键 → 把 vy 设置成一个很大的负数

if 按下空格 且 站在地上: vy = -15 ← 负数 = 向上飞！

为什么是负数？

Pygame 中 y 坐标从上往下增大

→ 向上移动 = y 减小 = vy 为负数

→ 向下移动 = y 增大 = vy 为正数

跳跃过程时间线

-15
帧1: 起飞!
→
-10
帧5: 上升中
→
0
帧12: 最高点
→
+8
帧18: 下落中
→
+15
帧25: 着地!

🔑 关键：vy 从 -15 慢慢变成 +15 —— 这就是"先上升再下落"

平台碰撞类型一：站在上面

从上方落在平台上

角色下落时，脚碰到平台顶部 → 站住！

# 检测条件：角色正在下落 + 脚碰到平台顶 if vy > 0 and prev_bottom <= platform.top and cur_bottom >= platform.top: player.bottom = platform.top # 放在平台上面 vy = 0 # 停止下落 on_ground = True # 标记：站在地上

🎯 就像你跳到桌子上 —— 脚碰到桌面就停住了

平台碰撞类型二：从下方穿透

单向平台（One-Way Platform）

从下面跳起来 → 穿过去！

从上面落下来 → 站住！

# 秘诀：只在下落时检测碰撞！ if vy > 0: # ← 只有下落才管平台 # ... 碰撞检测代码 ... # 如果 vy <= 0（上升中），直接忽略 → 穿过去！

🎯 就像单向栅栏门 —— 从下面轻松穿过，从上面被挡住

平台碰撞类型三：侧面挡住

水平方向碰到平台

角色左右移动时，撞到平台侧面 → 被挡住！

# 水平碰撞检测 if player.colliderect(platform): if prev_right <= platform.left: # 从左边撞来 player.right = platform.left # 挡住，不让穿过 elif prev_left >= platform.right: # 从右边撞来 player.left = platform.right # 挡住，不让穿过

🎯 就像走路撞到墙 —— 被挡住了，不能穿过去

三种碰撞类型总结

碰撞方向规则生活类比
⬇ 从上方（站）角色停住，站在平台上跳到桌子上
⬆ 从下方（穿）角色穿过（单向平台）单向栅栏门
⬅➡ 从侧面（挡）角色被挡住走路撞墙

每一帧都要对每个平台做这三种检测！

完整代码结构

# 1. 初始化 import pygame GRAVITY = 0.8 JUMP_FORCE = -15 player_x, player_y = 100, 400 vy = 0 platforms = [...] # 平台列表 # 2. 游戏循环 while running: # 键盘输入 keys = pygame.key.get_pressed() if keys[K_LEFT]: player_x -= 5 if keys[K_RIGHT]: player_x += 5 if keys[K_SPACE] and on_ground: vy = JUMP_FORCE # 重力 vy += GRAVITY player_y += vy # 碰撞检测（三种类型） on_ground = False for p in platforms: # 类型一+二：垂直碰撞 if vy > 0: check_landing(p) # 类型三：水平碰撞 check_side_collision(p) # 绘制 draw_everything() pygame.display.flip()

练习任务

基础任务（必做）

  • 运行基础代码，观察重力和跳跃效果
  • 修改 GRAVITY 的值，感受下落速度变化
  • 修改 JUMP_FORCE，看看角色能跳多高

进阶任务（选做）

  • 添加更多的平台，尝试不同的位置
  • 给平台加上不同的颜色
  • 给角色加上移动动画（变色）

挑战任务（高阶）

  • 实现"移动平台"——让平台来回移动
  • 添加"弹簧平台"——踩上去弹得更高

本课总结

重力 vy += GRAVITY 跳跃 vy = -15 站在平台上 从下穿透 侧面挡住 单向平台
  • 重力公式：vy += GRAVITY，y += vy
  • 跳跃：按下空格 → vy = JUMP_FORCE（负数）
  • 三种平台碰撞：站在上面 / 从下穿透 / 侧面挡住

这就是所有平台跳跃游戏的底层原理！
