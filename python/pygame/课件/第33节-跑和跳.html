重力 —— 让角色"掉下来"

现实中的重力

地球重力让一切物体往下掉。扔一个球，它会先上升、减速、再加速下落。

游戏中的重力（超级简单！）

每帧做两件事：

vy = vy + GRAVITY （速度不断增加）
y = y + vy （位置跟着改变）

💡 vy是垂直速度，GRAVITY是重力加速度（比如 0.8）

【讲解】重力 —— 让角色"掉下来" 本页要点（照着讲即可）： · 地球重力让一切物体往下掉。扔一个球，它会先上升、减速、再加速下落。 · 每帧做两件事： · 💡 vy 是垂直速度， GRAVITY 是重力加速度（比如 0.8） 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

跳跃 —— 给角色一个"向上的推力"

跳跃的本质

按下空格键 → 把 vy 设置成一个很大的负数

if 按下空格 且 站在地上: vy = -15 ← 负数 = 向上飞！

为什么是负数？

Pygame 中 y 坐标从上往下增大

→ 向上移动 = y 减小 = vy 为负数

→ 向下移动 = y 增大 = vy 为正数

【讲解】跳跃 —— 给角色一个"向上的推力" 本页要点（照着讲即可）： · 按下空格键 → 把 vy 设置成一个很大的 负数 · Pygame 中 y 坐标 从上往下增大 · → 向上移动 = y 减小 = vy 为 负数 · → 向下移动 = y 增大 = vy 为 正数 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

平台碰撞类型一：站在上面

从上方落在平台上

角色下落时，脚碰到平台顶部 → 站住！

# 检测条件：角色正在下落 + 脚碰到平台顶 if vy > 0 and prev_bottom <= platform.top and cur_bottom >= platform.top: player.bottom = platform.top # 放在平台上面 vy = 0 # 停止下落 on_ground = True # 标记：站在地上

🎯 就像你跳到桌子上 —— 脚碰到桌面就停住了

【讲解】平台碰撞类型一：站在上面 本页要点（照着讲即可）： · 角色下落时，脚碰到平台顶部 → 站住！ · 🎯 就像你 跳到桌子上 —— 脚碰到桌面就停住了 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

平台碰撞类型二：从下方穿透

单向平台（One-Way Platform）

从下面跳起来 → 穿过去！

从上面落下来 → 站住！

# 秘诀：只在下落时检测碰撞！ if vy > 0: # ← 只有下落才管平台 # ... 碰撞检测代码 ... # 如果 vy <= 0（上升中），直接忽略 → 穿过去！

🎯 就像单向栅栏门 —— 从下面轻松穿过，从上面被挡住

【讲解】平台碰撞类型二：从下方穿透 本页要点（照着讲即可）： · 从下面跳起来 → 穿过去！ · 从上面落下来 → 站住！ · 🎯 就像 单向栅栏门 —— 从下面轻松穿过，从上面被挡住 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

平台碰撞类型三：侧面挡住

水平方向碰到平台

角色左右移动时，撞到平台侧面 → 被挡住！

# 水平碰撞检测 if player.colliderect(platform): if prev_right <= platform.left: # 从左边撞来 player.right = platform.left # 挡住，不让穿过 elif prev_left >= platform.right: # 从右边撞来 player.left = platform.right # 挡住，不让穿过

🎯 就像走路撞到墙 —— 被挡住了，不能穿过去

【讲解】平台碰撞类型三：侧面挡住 本页要点（照着讲即可）： · 角色左右移动时，撞到平台侧面 → 被挡住！ · 🎯 就像 走路撞到墙 —— 被挡住了，不能穿过去 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

三种碰撞类型总结

碰撞方向规则生活类比
⬇ 从上方（站）角色停住，站在平台上跳到桌子上
⬆ 从下方（穿）角色穿过（单向平台）单向栅栏门
⬅➡ 从侧面（挡）角色被挡住走路撞墙

每一帧都要对每个平台做这三种检测！
