⬆️ 经验值与升级系统

经验曲线公式

def exp_to_next(level): return level * 50 # Lv1→2: 50, Lv2→3: 100, Lv3→4: 150...

获取经验 → 检查升级

def gain_exp(amount): player["exp"] += amount needed = exp_to_next(player["level"]) while player["exp"] >= needed: # while 处理连升多级 level_up() player["exp"] -= needed needed = exp_to_next(player["level"])

升级属性增长

def level_up(): player["level"] += 1 player["max_hp"] += 20 # 血量上限+20 player["max_mp"] += 10 # 魔法上限+10 player["atk"] += 5 # 攻击+5 player["def"] += 3 # 防御+3 # 升级福利：满血满蓝！ player["hp"] = player["max_hp"] player["mp"] = player["max_mp"]
关键！使用 while 而非 if，因为经验值可能够升好几级（比如打败 Boss 一次升 5 级）

💾 JSON 存档读写（选学）

存档 — 将游戏数据写入文件

import json def save_game(): data = { "player": player, # 角色属性字典 "inventory": inventory # 背包列表 } with open("save.json", "w", encoding="utf-8") as f: json.dump(data, f, ensure_ascii=False, indent=2)

读档 — 从文件恢复游戏数据

def load_game(): global player, inventory with open("save.json", "r", encoding="utf-8") as f: data = json.load(f) player = data["player"] inventory = data["inventory"]
函数方向作用
json.dump()Python → 文件字典/列表 → JSON字符串 → 写入
json.load()文件 → Python读取 → JSON字符串 → 字典/列表
为什么用JSON？玩家的字典数据和背包列表天然就是JSON格式，一行代码就能保存/读取！这也是用字典管理游戏数据的核心优势之一。
