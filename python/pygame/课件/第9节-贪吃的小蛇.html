💡 核心思想：蛇移动 = 前面加一个 + 后面减一个

🤔 蛇是怎么移动的？

观察贪吃蛇

蛇在屏幕上爬行时：

  • 头向前走一格
  • 尾巴缩短一格
  • 身体跟随着移动
关键发现：每次移动，蛇的 总节数不变（没吃到食物时）

代码思路

# 蛇移动的本质 # 1. 在头部前面插入新位置 # 2. 删除尾部的最后一格 # 列表天然适合做这个！ snake = [头, 身1, 身2, 尾] # insert 加头 snake.insert(0, 新头) # pop 删尾 snake.pop()

🔢 列表 = 蛇的身体

概念

蛇身的每一节是一个坐标 [x, y]

列表里按顺序存放所有节：

头
[400,300] 身
[380,300] 身
[360,300] 尾
[340,300]
snake = [[400,300], [380,300], [360,300], [340,300]] # 蛇头 身1 身2 蛇尾

代码实现

# 初始蛇：3节，横排 snake = [[400, 300], [380, 300], [360, 300]] # 访问蛇头 head = snake[0] # head = [400, 300] # 蛇头的x坐标 head_x = snake[0][0] # 400 # 蛇头的y坐标 head_y = snake[0][1] # 300
💡 列表越前面 = 越靠近蛇头

🧭 方向键控制移动方向

dx / dy 方向变量

方向dxdy
向右200

向下020
向上0-20

防反向移动

# 上键：只有不在上下移动时才能按 if event.key == pygame.K_UP and dy == 0: dx = 0 dy = -GRID_SIZE
⚠️ 为什么要加 and dy == 0？
如果蛇正在向下走，按上键会让蛇头直接撞到脖子！
# 完整的按键处理 if event.key == pygame.K_UP and dy == 0: dx, dy = 0, -GRID_SIZE elif event.key == pygame.K_DOWN and dy == 0: dx, dy = 0, GRID_SIZE elif event.key == pygame.K_LEFT and dx == 0: dx, dy = -GRID_SIZE, 0 elif event.key == pygame.K_RIGHT and dx == 0: dx, dy = GRID_SIZE, 0

🍎 食物的随机生成

要求

  • 食物出现在随机位置
  • 必须对齐到格子上
  • ❌ 不能与蛇身重叠
网格计算：
屏幕 800x600，每格 20px
列数 = 800 / 20 = 40 列
行数 = 600 / 20 = 30 行

代码实现

import random def generate_food(snake): """随机生成不重叠的食物""" while True: # 随机格子坐标 fx = random.randint(0, 39) * 20 fy = random.randint(0, 29) * 20 food = [fx, fy] # 检查是否和蛇身重叠 if food not in snake: return food
randint(0,39) x 20 = 0, 20, 40, ..., 780
刚好落在格子上！

🐻 吃到食物变长的秘密

没吃到食物

new_head = [snake[0][0] + dx, snake[0][1] + dy] snake.insert(0, new_head) snake.pop() # 删除尾部 # 头+1, 尾-1 → 长度不变

吃到食物！

new_head = [snake[0][0] + dx, snake[0][1] + dy] snake.insert(0, new_head) # 不执行 pop()！ # 头+1, 尾不变 → 长度+1 food = generate_food(snake)
💡 变长的本质：只"加头"，不"删尾"，蛇就多了一节。就像贪吃的小蛇把食物"变成"了自己身体的一部分！
# 游戏循环中的完整逻辑 if snake[0] == food: food = generate_food(snake) # 生成新食物 # 注意：这里没有 snake.pop()！蛇自动变长 else: snake.pop() # 没吃到，正常移动

🎨 用 Pygame 绘制画面

绘制食物

# 画红色食物方块 pygame.draw.rect(screen, RED, (food[0], food[1], GRID_SIZE, GRID_SIZE))
食 red方块，20x20像素

绘制蛇身

# 遍历蛇的每一节 for i, segment in enumerate(snake): if i == 0: color = GREEN # 蛇头亮绿 else: color = DARK_GREEN # 身体深绿 pygame.draw.rect(screen, color, (segment[0], segment[1], GRID_SIZE, GRID_SIZE))
头 身 身 尾
💡 enumerate() 同时返回索引和值。i=0 是蛇头，用亮色；i>=1 是身体，用暗色。

📜 程序整体结构

# ===== 初始设置 ===== import pygame, random pygame.init() WIDTH, HEIGHT = 800, 600 GRID_SIZE = 20 screen = pygame.display.set_mode((WIDTH, HEIGHT)) clock = pygame.time.Clock() FPS = 10 # ===== 蛇和食物 ===== snake = [[400,300], [380,300], [360,300]] dx, dy = GRID_SIZE, 0 food = generate_food(snake) # ===== 游戏循环 ===== while running: # 1. 处理事件（方向键） # 2. 移动蛇（insert + pop） # 3. 检查食物（碰到 → 变长 + 新生食物） # 4. 绘制画面 clock.tick(FPS)
📌 记住这个 4步循环：事件 → 逻辑 → 绘制 → 等待

🐛 常见Bug与解决

❌ 问题 🔍 原因 ✅ 解决
蛇不动了 事件循环没更新dx/dy 检查按键处理代码
蛇一移动就只剩一节 先pop()再insert() 必须先insert，再pop
食物出现在蛇身上 没检查重叠 用 if food not in snake
按键没反应 事件类型错了 检查是KEYDOWN（大写）
可以反向走回头路 没检查和条件 加 and dy==0 / dx==0
⚠️ 最常见的错误：insert 和 pop 顺序写反！一定要先 insert(0, new_head)，再 pop()
