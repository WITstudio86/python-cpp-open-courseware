🎨 绘制基本图形 — pygame.draw

Pygame 提供了丰富的绘图函数，可以直接在屏幕上画出各种形状。

常用绘图函数

  • pygame.draw.rect() — 矩形
  • pygame.draw.circle() — 圆形
  • pygame.draw.line() — 线段
  • pygame.draw.ellipse() — 椭圆
  • pygame.draw.polygon() — 多边形

参数说明

  • surface — 画在哪个表面上
  • color — 颜色 (R, G, B)
  • 位置/大小 — rect 或坐标
  • width — 线宽，0 表示填充
# 画一个红色填充矩形
pygame.draw.rect(screen, (255, 0, 0), (100, 100, 200, 150))

# 画一个蓝色空心圆
pygame.draw.circle(screen, (0, 100, 255), (400, 300), 80, 3)

# 画一条绿色线段
pygame.draw.line(screen, (0, 200, 0), (50, 50), (500, 400), 5)

🧩 创建自己的图片 — pygame.Surface

Surface 就像一张透明的画纸，我们可以在上面任意绘制，然后当作一张图片使用。

创建方法

# 创建一个 200x200 的 Surface
my_surface = pygame.Surface((200, 200))

# 填充背景色（白色）
my_surface.fill((255, 255, 255))

# 在 Surface 上画图
pygame.draw.circle(my_surface, ...)

💡 为什么要用 Surface？

  • 把多个图形“打包”成一张图
  • 可以整体移动、复制
  • 方便使用 blit() 显示到屏幕上

😊 动手画一个可爱的笑脸

只用代码，不用任何图片文件，我们画出一个会笑的表情！

def draw_smiley():
    face = pygame.Surface((200, 200), pygame.SRCALPHA)

    # 大圆脸（黄色）
    pygame.draw.circle(face, (255, 220, 50), (100, 100), 90)

    # 左眼（白色 + 黑色瞳孔）
    pygame.draw.circle(face, (255, 255, 255), (70, 80), 22)
    pygame.draw.circle(face, (0, 0, 0),   (70, 80), 10)

    # 右眼
    pygame.draw.circle(face, (255, 255, 255), (130, 80), 22)
    pygame.draw.circle(face, (0, 0, 0),   (130, 80), 10)

    # 微笑的嘴巴（圆弧）
    pygame.draw.arc(face, (0, 0, 0),
                     (60, 90, 80, 60), 3.14, 0, 4)

    return face

🖼️ 加载和显示图片 — load() 与 blit()

除了自己用代码画，我们也可以加载电脑里的图片文件。

load() — 加载图片

# 加载一张图片
player_img = pygame.image.load("player.png")

# 支持 PNG、JPG、GIF 等格式

blit() — 画到屏幕上

# 把图片"贴"到屏幕的 (x, y) 位置
screen.blit(player_img, (x, y))

💡 blit = Block Lmage Transfer（块图像传输）

⚡ 让游戏更流畅 — convert_alpha()

加载图片后，建议做一步格式转换，Pygame 就能更快地处理它。

标准写法

# 最好的加载方式
player_img = pygame.image.load("player.png")
            .convert_alpha()

对比

.convert() 不带透明通道，适合背景图
.convert_alpha() 保留透明通道，适合角色图片

🎯 记住：如果图片有透明背景（PNG），一定要用 convert_alpha()，否则透明部分会变成黑色！

🖱️ 追踪鼠标位置 — MOUSEMOTION

当鼠标在游戏窗口内移动时，Pygame 会发出 MOUSEMOTION 事件。

for event in pygame.event.get():
    if event.type == pygame.MOUSEMOTION:
        # event.pos 就是鼠标的 (x, y) 坐标
        mouse_x, mouse_y = event.pos
        print(f"鼠标位置: ({mouse_x}, {mouse_y})")

也可以直接获取

# 不需要等事件，随时可以获取鼠标位置
mouse_x, mouse_y = pygame.mouse.get_pos()

👆 检测鼠标点击 — MOUSEBUTTONDOWN

按下鼠标按钮时，Pygame 发出 MOUSEBUTTONDOWN 事件。

for event in pygame.event.get():
    if event.type == pygame.MOUSEBUTTONDOWN:
        if event.button == 1:   # 左键
            print("左键点击！")
        elif event.button == 2: # 中键（滚轮）
            print("中键点击！")
        elif event.button == 3: # 右键
            print("右键点击！")

🖱️ 鼠标按钮编号

1 = 左键 🖱️ 2 = 中键 🎡 3 = 右键 🖱️ 4 = 滚轮上滚 🔼 5 = 滚轮下滚 🔽

🔍 缩放图片 — transform.scale()

图片太大或太小？用 transform.scale() 轻松调整大小。

# 加载原始图片
big_img = pygame.image.load("player.png").convert_alpha()

# 缩放到 80x80 像素
small_img = pygame.transform.scale(big_img, (80, 80))

# 放大到原来的 1.5 倍
w = big_img.get_width()
h = big_img.get_height()
large_img = pygame.transform.scale(big_img, (int(w * 1.5), int(h * 1.5)))

还有这些变换

  • rotate() — 旋转图片
  • flip() — 水平/垂直翻转
  • scale2x() — 快速放大2倍
  • smoothscale() — 平滑缩放（更精细）

💻 完整代码 — 笑脸跟随鼠标

综合运用本节课所学知识，做一个笑脸跟随鼠标移动的小程序。

import pygame
import sys

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("笑脸跟随鼠标")
clock = pygame.time.Clock()

# --- 绘制笑脸 ---
def make_smiley(size):
    face = pygame.Surface((size, size), pygame.SRCALPHA)
    r = size // 2
    cx = cy = r
    pygame.draw.circle(face, (255, 220, 50), (cx, cy), r)
    pygame.draw.circle(face, (255, 255, 255), (cx - 30, cy - 25), r // 4)
    pygame.draw.circle(face, (0, 0, 0), (cx - 30, cy - 25), r // 8)
    pygame.draw.circle(face, (255, 255, 255), (cx + 30, cy - 25), r // 4)
    pygame.draw.circle(face, (0, 0, 0), (cx + 30, cy - 25), r // 8)
    pygame.draw.arc(face, (0, 0, 0), (cx - 40, cy - 10, 80, 50), 3.14, 0, 4)
    return face

smiley = make_smiley(120)
mx, my = 400, 300   # 笑脸初始位置

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.MOUSEMOTION:
            mx, my = event.pos

    screen.fill((240, 248, 255))
    screen.blit(smiley, (mx - 60, my - 60))
    pygame.display.flip()
    clock.tick(60)

pygame.quit()
sys.exit()
