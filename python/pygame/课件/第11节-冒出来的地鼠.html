# --- 布局参数 --- GRID_COLS = 3 GRID_ROWS = 3 HOLE_SIZE = 120 COL_SPACING = 200 ROW_SPACING = 150 # --- 用双重循环生成9个洞 --- holes = [] for row in range(3): for col in range(3): cx = 100 + col * 200 + 60 cy = 150 + row * 150 + 60 hole = Rect(0, 0, 120, 120) hole.center = (cx, cy) holes.append(hole)

⚡ 第三步：自定义事件

什么是 自定义事件？

  • Pygame 已经定义了 鼠标点击、键盘按下 等事件
  • 但我们还需要一个 "地鼠换洞"事件 —— 需要自己定义！
  • 使用 pygame.USEREVENT 作为起始编号
# 定义"地鼠换洞"事件 MOLE_CHANGE = pygame.USEREVENT + 1 # 在主循环中处理 if event.type == MOLE_CHANGE: spawn_mole() # 地鼠换洞！

💡 USEREVENT + 1 是一个新的整数编号，不会和系统事件冲突

⏱️ 第三步：定时器 set_timer()

自定义事件需要有人"定时触发"它 — 这就是 set_timer 的作用。

# 每隔 800 毫秒，自动触发一次 MOLE_CHANGE 事件 pygame.time.set_timer(MOLE_CHANGE, 800) # 参数1：要触发的事件类型 # 参数2：间隔时间（毫秒），800 = 0.8 秒

🕐 0.0s → 🐹地鼠出现 → 🕐 0.8s → 🐹地鼠换洞 → 🕐 1.6s → 🐹地鼠换洞 → ...

怎么知道鼠标点到了地鼠？用 collidepoint()！

if event.type == pygame.MOUSEBUTTONDOWN: mouse_x, mouse_y = event.pos # 获取点击坐标 mole_rect = holes[current_mole] # 地鼠所在的洞 if mole_rect.collidepoint(mouse_x, mouse_y): print("打中啦！") current_mole = -1 # 地鼠缩回去
