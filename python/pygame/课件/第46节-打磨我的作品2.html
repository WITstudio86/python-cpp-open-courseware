🔊 pygame 声音系统

两个层次：Sound（短音效） + music（背景音乐）
🎯 Sound 短音效 🎵 Music 背景音乐
用途 射击、跳跃、碰撞 游戏背景音乐
时长 短（< 5秒） 长（几分钟）
同时播放 多个（8通道） 1首（独占）
方法 pygame.mixer.Sound() pygame.mixer.music
推荐格式 .wav / .ogg .mp3 / .ogg
🔑 记忆口诀：音效用 Sound、音乐用 music；多一起放音效，背景音乐只一首。

🎯 音效播放 — pygame.mixer.Sound

# 1. 初始化混音器（必须放在游戏初始化部分）
pygame.mixer.init()
# 2. 加载音效文件（推荐 .wav 或 .ogg 格式）
jump_sound = pygame.mixer.Sound("sounds/jump.wav") shoot_sound = pygame.mixer.Sound("sounds/shoot.wav")
# 3. 播放音效
jump_sound.play() # 播放一次 shoot_sound.play(loops=2) # 播放3次（原始+循环2）
# 4. 控制音量（0.0 ~ 1.0）
jump_sound.set_volume(0.5) # 50% 音量
# 5. 停止播放
jump_sound.stop()
⚠️ 注意：音效文件不要太大（建议 < 1MB），.mp3 作为 Sound 可能在某些电脑上出问题！

🎵 背景音乐 — pygame.mixer.music

# 1. 加载背景音乐
pygame.mixer.music.load("music/bgm.mp3")
# 2. 播放控制
pygame.mixer.music.play(-1) # -1 = 无限循环播放！ pygame.mixer.music.set_volume(0.3) # 背景音乐音量较小，不盖过音效
# 3. 暂停/继续/停止/淡出
pygame.mixer.music.pause() # 暂停 pygame.mixer.music.unpause() # 继续 pygame.mixer.music.stop() # 停止 pygame.mixer.music.fadeout(2000) # 2秒内逐渐淡出
# 4. 检查播放状态
if pygame.mixer.music.get_busy(): print("音乐正在播放中...")
🎯 最佳实践：背景音乐音量设为 0.2~0.3，音效音量设为 0.5~0.7，这样音效才能清晰听到。

🛠️ 没有音频文件？三种解决方案

方案一：下载免费音效

  • freesound.org
  • mixkit.co/free-sound-effects
  • opengameart.org
  • 老师准备的音效素材包

方案二：程序生成 ⭐

  • 用数学波形生成音效
  • 正弦波 → 柔和的音效
  • 方波 → 复古游戏音效
  • 调整频率=不同音调

方案三：纯视觉打磨

  • 专注于UI优化
  • 添加画面动画
  • 优化颜色和字体
  • 做好展示准备
🚀 推荐方案二：看老师写的演示程序！用 pygame.sndarray + 数学公式就能生成各种有趣的音效，不需要任何音频文件！

🎨 UI优化建议

🎨 配色原则

  • 主色调不超过3-4种
  • 使用配色工具：coolors.co
  • 重要元素用亮色突出
  • 背景用暗色、降低饱和度

🔤 字体建议

  • 中文：SimHei / Microsoft YaHei
  • 标题大（48+）、正文适中（24-36）
  • 分数/血量用醒目颜色
  • 避免花哨的装饰字体

✨ 反馈感

  • 按钮hover时变色
  • 得分时数字跳动
  • 受伤时屏幕短暂闪红
  • 过关时弹出胜利画面
