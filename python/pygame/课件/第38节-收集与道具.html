道具计时机制

核心函数：pygame.time.get_ticks()

返回 Pygame 初始化以来经过的毫秒数（整数）。

这不是系统时间，而是游戏内部计时器，精度足够用于道具计时。

计时原理

  • 拾取道具时，记录当前时刻：pickup_time = pygame.time.get_ticks()
  • 每帧检查：elapsed = now - pickup_time
  • 若 elapsed >= duration（如5000ms），道具到期
关键点：道具持续时间通常设为 5000~10000 毫秒（5~10秒），太短没感觉，太长破坏平衡。
# 道具计时示意 import pygame pygame.init() # 拾取道具时记录时间戳 magnet_start = pygame.time.get_ticks() shield_start = pygame.time.get_ticks() # 道具持续时间（毫秒） MAGNET_DURATION = 6000 SHIELD_DURATION = 5000 # 每帧判断是否到期 now = pygame.time.get_ticks() if now - magnet_start > MAGNET_DURATION: has_magnet = False if now - shield_start > SHIELD_DURATION: has_shield = False

计时进阶：倒计时显示 & 冷却

剩余时间计算

让玩家直观看到道具还剩多久：

# 剩余时间（秒），保留 1 位小数 remaining = (duration - (now - start)) / 1000 if remaining > 0: text = f"磁铁：{remaining:.1f}秒" screen.blit(font.render(text, ...), (10, 50))

冷却机制（CD）

防止玩家连续刷道具，引入冷却时间：

# 拾取后进入冷却，期间无法再捡 if now - last_pickup_time > PICKUP_CD: can_pickup = True

计时器封装为类

class Timer: def __init__(self, duration): self.duration = duration self.start_time = 0 self.active = False def start(self): self.start_time = pygame.time.get_ticks() self.active = True def is_done(self): if not self.active: return True if pygame.time.get_ticks() - \ self.start_time > self.duration: self.active = False return True return False
封装成 Timer 类 后，管理多个道具计时变得非常简洁，每个道具只需一个 Timer 实例。

磁铁效果原理

核心思路

磁铁激活后，金币不再静止，而是每帧向玩家位置移动。

关键：计算 方向向量，让金币沿正确方向飞行。

方向向量计算步骤

  1. dx = player.x - coin.x（水平差）
  2. dy = player.y - coin.y（垂直差）
  3. dist = sqrt(dx*dx + dy*dy)（距离）
  4. 归一化：dx /= dist; dy /= dist
  5. 移动：coin.x += dx * speed
注意：需要判断距离——如果金币已经到达玩家位置附近（dist < 阈值），就直接收集，避免除零错误。
import math def magnet_update(coins, player, speed=5): """磁铁效果：让所有金币向玩家移动""" for coin in coins: dx = player.x - coin.x dy = player.y - coin.y dist = math.hypot(dx, dy) if dist < 10: # 到了，直接收集 coins.remove(coin) return 1 # 归一化方向向量 dx /= dist dy /= dist # 按速度移动 coin.x += dx * speed coin.y += dy * speed return 0
math.hypot(dx, dy) 等价于 (dx*dx + dy*dy) ** 0.5，但更精确且高效。

护盾效果原理

实现思路

护盾激活时，跳过敌人碰撞检测，玩家暂时无敌。

视觉效果：在玩家周围画一个 半透明光圈。

道具掉落机制

概率掉落设计

每消灭一个敌人，有一定概率掉落道具：

# 敌人被消灭时调用 def on_enemy_killed(x, y): roll = random.random() # 0.0 ~ 1.0 if roll < 0.3: # 30% 概率 kind = random.choice(["magnet","shield","speed"]) powerups.append(PowerUp(x, y, kind))

加权随机（稀有度）

某些高级道具掉落概率更低：

# 加权掉落的简洁写法 kind = random.choices( ["magnet", "shield", "speed"], weights=[40, 40, 20] # speed 稀有 )[0]

定时掉落

每隔一段时间自动在场景中生成道具，保持游戏节奏：

# 每 10 秒自动掉一个道具 if now - last_spawn_time > 10000: x = random.randint(50, WIDTH-50) y = random.randint(50, HEIGHT-50) kind = random.choice(["magnet", "shield"]) powerups.append(PowerUp(x, y, kind)) last_spawn_time = now
设计建议：道具数量控制上限（如最多 3 个），避免屏幕太乱。还可以让旧道具闪烁提示即将消失。

# 检测玩家是否碰到金币 def check_coin_collision(player_rect, coins): global score collected = [] for i, coin in enumerate(coins): cx, cy = coin.x, coin.y if player_rect.collidepoint(cx, cy): score += coin.value collected.append(i) # 倒序删除避免索引错乱 for i in reversed(collected): coins.pop(i)

# 保持场景中始终有 5~8 个金币 if len(coins) < 5: for _ in range(5 - len(coins)): coins.append(Coin())
