📐 屏幕震动原理

屏幕震动的本质：把画面临时偏移，偏移量越来越小直到消失

核心公式

shake = sin(time × freq) × strength × e-time × decay

sin产生周期振动 × 初始振幅 × 指数衰减 = 逐渐减弱的震动

直观类比

就像一根弹簧：用力拉一下松手 → 来回振荡 → 幅度越来越小 → 最终停下

三个参数

  • freq=30：震动快慢
  • strength=15：初始强度（像素）
  • decay=3：衰减速度

💻 震动代码实现

import math

shake_start_time = -999  # 震动开始时间
shake_duration = 0.5     # 持续0.5秒

def get_shake_offset():
    now = pygame.time.get_ticks() / 1000.0
    elapsed = now - shake_start_time
    if elapsed > shake_duration:
        return 0, 0  # 震动结束

    decay = math.exp(-elapsed * 8.0)  # 指数衰减
    strength = 12.0 * decay            # 当前振幅

    ox = math.sin(elapsed * 40) * strength  # X偏移
    oy = math.cos(elapsed * 35) * strength  # Y偏移
    return ox, oy

# 绘制时应用偏移
shake_x, shake_y = get_shake_offset()
# 所有绘制坐标都要 +shake_x, +shake_y

💡 关键技巧：偏移量同时加到所有物体的绘制坐标上，让整个画面一起震动！

🏗 粒子类设计

class Particle:
    def __init__(self, x, y):
        self.x = x                    # 位置
        self.y = y
        angle = random.uniform(0, 2 * math.pi)
        speed = random.uniform(2, 8)
        self.vx = math.cos(angle) * speed  # X速度
        self.vy = math.sin(angle) * speed  # Y速度
        self.life = 1.0               # 生命值 (1.0→0.0)
        self.max_radius = random.randint(3, 8)
        self.color_start = (255,255,100) # 亮黄
        self.color_end = (180,30,0)      # 暗红

关键属性

  • x, y — 当前位置
  • vx, vy — 运动速度
  • life — 剩余寿命
  • color_start/end — 颜色渐变

为什么用角度+速度？

用 cos/sin 把角度转为速度分量，保证粒子均匀向四周飞散，而不是只飞向四个角落。

🗂 粒子池管理

为什么需要"池"？

想象一个爆炸产生60个粒子，如果不及时清理死掉的粒子，运行几分钟后可能有几千个粒子占据内存！

# 粒子池 — 用列表管理所有活跃粒子
particles = []

# 生成粒子（爆炸时）
def spawn_explosion(x, y):
    for _ in range(60):
        particles.append(Particle(x, y))

# 每帧更新 — 死亡粒子立即移除

    if p.life <= 0:
        particles.remove(p)

⚠️ 注意：遍历 particles[:]（副本）而不是 particles（原列表），否则边遍历边删除会出错！
