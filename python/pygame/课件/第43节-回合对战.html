💥 伤害计算公式

damage = max(1, atk × 倍率 − def × 0.5)

为什么这样设计？

  • atk × 倍率：基础伤害
  • − def × 0.5：防御减伤
  • max(1, ...)：保底1点

计算示例

场景atkdef倍率伤害
普通攻击30201.020
火球术30202.050 💥
防御状态30601.01 （减半=0→保底1）

📉 血条平滑动画 — Lerp插值

核心公式

current_hp += (target_hp − current_hp) × 0.1

原理

每帧向目标值靠近一小步

speed=0.1 表示每帧拉近10%的距离

💻 Lerp 血条代码实现

# 每帧调用：让 current_hp 平滑追向 target_hp def update_hp_bar(): global current_hp current_hp += (target_hp - current_hp) * 0.1 # 受到伤害时：只改 target，current 自动追赶 def take_damage(damage): global target_hp target_hp = max(0, target_hp - damage) # 绘制血条（根据比例变色） def draw_hp_bar(surf, x, y, w, current, max_hp): ratio = current / max_hp color = GREEN if ratio > 0.5 \ else YELLOW if ratio > 0.25 \ else RED # 灰色背景 pygame.draw.rect(surf, GRAY, (x, y, w, 20)) # 当前血量 pygame.draw.rect(surf, color, (x, y, int(w * ratio), 20)) # 白色边框 pygame.draw.rect(surf, WHITE, (x, y, w, 20), 2)
