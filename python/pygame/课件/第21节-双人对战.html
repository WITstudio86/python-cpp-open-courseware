核心函数：pygame.key.get_pressed()

返回一个元组，包含所有按键的当前状态。按住的键为 True，没按的为 False。

与 KEYDOWN 事件的区别：get_pressed() 适合持续移动，KEYDOWN 适合单次触发。

输入处理 —— 代码实现

# 获取所有按键状态
keys = pygame.key.get_pressed()

# 玩家1：左球拍 (W/S)
if keys[pygame.K_w]:
    left_paddle.y -= 5
if keys[pygame.K_s]:
    left_paddle.y += 5

# 玩家2：右球拍 (上下方向键)
if keys[pygame.K_UP]:
    right_paddle.y -= 5
if keys[pygame.K_DOWN]:
    right_paddle.y += 5

# 边界限制
if left_paddle.top < 0:
    left_paddle.top = 0
if left_paddle.bottom > 500:
    left_paddle.bottom = 500
# 右球拍同理...

注意：使用独立的 if 语句，不要用 elif！否则两个玩家不能同时按键。

球拍与球的 Rect 对象

创建球拍 Rect

# x, y, 宽度, 高度
left_paddle = pygame.Rect(
    30, 200, 15, 100
)
right_paddle = pygame.Rect(
    755, 200, 15, 100
)

创建球 Rect

# 球用正方形表示
ball = pygame.Rect(
    390, 240, 20, 20
)

为什么用 Rect？ Pygame 的 Rect 自带碰撞检测方法，管理位置非常方便。

常用属性： x, y, centerx, centery, top, bottom, left, right

反弹物理

上下边界的简单反弹

if ball.top <= 0 or ball.bottom >= HEIGHT:
    speed_y = -speed_y  # 垂直方向反转

球拍碰撞 —— 水平方向反转

if ball.colliderect(paddle):
    speed_x = -speed_x  # 水平方向反转

colliderect() 返回 True 表示两个矩形有重叠区域

碰撞角度变化 —— 核心知识点

问题：每次都45度反弹，太单调了！

解决方案：根据球击中球拍的位置，调整反弹的垂直速度。

原理：计算球心与球拍中心的偏移

# 计算球心与球拍中心的相对偏移（归一化到 -1 到 1）
offset_y = (ball.centery - paddle.centery) / (paddle.height / 2)

# offset_y: -1 = 球拍顶部, 0 = 中心, 1 = 球拍底部
speed_y = int(offset_y * 6)  # 6 = 最大垂直速度
speed_x = -speed_x               # 水平方向始终反转

击球位置与反弹角度

击中位置offset_y 范围效果图示方向
球拍顶部-1.0 ~ -0.5大角度向上弹↖
球拍中上部-0.5 ~ 0小角度向上弹↗
球拍正中≈ 0接近水平反弹→
球拍中下部0 ~ 0.5小角度向下弹↘
球拍底部0.5 ~ 1.0大角度向下弹↙

类比：就像打乒乓球——球拍角度不同，回球方向就不同！

出界判定与得分机制

判定逻辑

if ball.left <= 0:          # 球越过左边界
    right_score += 1         # 右方得分！
    reset_ball()            # 重新发球

if ball.right >= WIDTH:    # 球越过右边界
    left_score += 1          # 左方得分！
    reset_ball()

注意：球出左界 → 右方得分；球出右界 → 左方得分。不要搞反！

重新发球

球回到屏幕中央，随机选择一个方向发出。

完整代码（一）—— 初始化与主循环

import pygame, sys, random

# 初始化
pygame.init()
WIDTH, HEIGHT = 800, 500
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Pong - 双人对战")
clock = pygame.time.Clock()

# 颜色
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
GRAY = (80, 80, 80)

# 球拍
PADDLE_W, PADDLE_H = 15, 100
left_paddle = pygame.Rect(30, HEIGHT//2-PADDLE_H//2, PADDLE_W, PADDLE_H)
right_paddle = pygame.Rect(WIDTH-30-PADDLE_W, HEIGHT//2-PADDLE_H//2, PADDLE_W, PADDLE_H)

# 球
BALL_SIZE = 20
ball = pygame.Rect(WIDTH//2-BALL_SIZE//2, HEIGHT//2-BALL_SIZE//2, BALL_SIZE, BALL_SIZE)
ball_speed_x = 4 * random.choice([-1, 1])
ball_speed_y = 4 * random.choice([-1, 1])

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
    # ... 按键、移动、碰撞、绘制 ...

完整代码（二）—— 核心逻辑

# === 按键处理 ===
keys = pygame.key.get_pressed()
if keys[pygame.K_w] and left_paddle.top > 0:
    left_paddle.y -= 5
if keys[pygame.K_s] and left_paddle.bottom < HEIGHT:
    left_paddle.y += 5
if keys[pygame.K_UP] and right_paddle.top > 0:
    right_paddle.y -= 5
if keys[pygame.K_DOWN] and right_paddle.bottom < HEIGHT:
    right_paddle.y += 5

# === 球移动 ===
ball.x += ball_speed_x
ball.y += ball_speed_y

# === 上下边界反弹 ===
if ball.top <= 0 or ball.bottom >= HEIGHT:
    ball_speed_y = -ball_speed_y

# === 球拍碰撞（带角度变化）===
for paddle in [left_paddle, right_paddle]:
    if ball.colliderect(paddle):
        offset_y = (ball.centery - paddle.centery) / (paddle.height / 2)
        ball_speed_y = int(offset_y * 6)
        ball_speed_x = -ball_speed_x

# === 出界判定 ===
if ball.left <= 0:   # 出左界 → 右方得分
    right_score += 1; reset_ball()
if ball.right >= WIDTH: # 出右界 → 左方得分
    left_score += 1; reset_ball()

绘制所有元素
