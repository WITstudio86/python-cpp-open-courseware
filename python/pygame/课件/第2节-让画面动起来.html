Clock —— 节拍器

Tick · Tick · Tick

节拍器打拍子，Clock 打帧

# 创建 Clock clock = pygame.time.Clock() # 每帧末尾调用： clock.tick(60) ← 最多 60 帧/秒
为什么要 Clcok？
没有 Clock → 快的电脑跑几百帧/秒，慢的电脑只跑十几帧
有 Clock → 所有电脑保持一致速度

清屏与拖尾

screen.fill((255, 248, 240)) 的作用 —— 擦掉上一帧！

没有 fill() → 拖尾！
→
有 fill() → 干净！
每一帧开始前，用 fill() 把整个屏幕涂成背景色 = 擦掉上一帧的内容，再画新的一帧

边缘反弹 —— 别飞出屏幕！

左边缘
x ≤ 0
右边缘
x ≥ W - w
上边缘
y ≤ 0
下边缘
y ≥ H - h
# 假设矩形宽 w, 高 h, 屏幕 800×600 if x <= 0 or x >= 800 - w: speed_x = -speed_x # 水平反弹 if y <= 0 or y >= 600 - h: speed_y = -speed_y # 垂直反弹

核心思路：碰到边缘 → 速度取反 → 掉头往回走！

完整代码 —— 弹跳的矩形

import pygame pygame.init() # 窗口设置 W, H = 800, 600 screen = pygame.display.set_mode((W, H)) pygame.display.set_caption("弹跳矩形") # 矩形属性 rect_w, rect_h = 60, 60 x, y = W // 2, H // 2 speed_x, speed_y = 5, 3 color = (255, 107, 107) # 珊瑚红 clock = pygame.time.Clock() running = True while running: # 1. 处理事件 for event in pygame.event.get(): if event.type == pygame.QUIT: running = False # 2. 更新位置 x += speed_x y += speed_y # 3. 边缘反弹 if x <= 0 or x >= W - rect_w: speed_x = -speed_x if y <= 0 or y >= H - rect_h: speed_y = -speed_y # 4. 绘制画面 screen.fill((255, 248, 240)) pygame.draw.rect(screen, color, (x, y, rect_w, rect_h)) pygame.display.update() # 5. 控制帧率 clock.tick(60) pygame.quit()

动手试一试

在完整代码的基础上，试试修改这些：

  • 1
    改变速度值
    把 speed_x 和 speed_y 改成 10，看看矩形是不是飞得更快了？再试试 1 — 是不是慢得像蜗牛？
  • 2
    改变矩形大小
    把 rect_w 改成 120，rect_h 改成 30 — 变成长条了！注意边缘反弹的条件会自动适配。
  • 3
    添加第二个矩形
    复制一份 x、y、speed，再新增一个 pygame.draw.rect() — 两个矩形同时弹跳！
  • 4
    关掉 fill()
    把 screen.fill() 这一行注释掉，看看屏幕会发生什么——是不是画出一道道「拖尾」？
