什么是 Pygame？

Pygame 是 Python 的一个游戏开发库， 就像给你的 Python 装上了一双"手"和一双"眼睛"！

🎨 类比一下：

如果 Python 是铅笔，那 Pygame 就是一整套彩色画笔 + 画板！

铅笔只能写字，但彩色画笔能画出整个游戏世界 🌍

📌 Pygame 能做什么？

  • 🎨 画图：在屏幕上画出各种形状和颜色
  • 🎵 放声音：给游戏添加音效和背景音乐
  • 🖱️ 检测输入：知道玩家按了哪个键、鼠标点在哪里
  • 💥 碰撞检测：判断两个角色有没有撞到一起
  • ⏱️ 控制速度：让游戏按固定速度运行
📦

创建第一个窗口

只需 5 个步骤，就能打开游戏窗口！

1 导入 pygame
import pygame
2 初始化引擎
pygame.init()
3 设置窗口尺寸
set_mode()
4 主循环
while running:
5 退出
pygame.quit()

📝 就像烤蛋糕一样，每一步都有它的作用，缺一不可！

🔍

代码详解 （上）

# 第 1 步：导入 pygame 库，这样我们才能用它 import pygame # 第 2 步：初始化 pygame（启动游戏引擎！） pygame.init() # 第 3 步：创建一个 800 × 600 的窗口 # set_mode() 返回一个"屏幕对象"，之后画什么都画在这上面 screen = pygame.display.set_mode((800, 600)) # 设置窗口标题 pygame.display.set_caption("我的第一个游戏窗口")
  • import pygame — 告诉 Python："嘿，我要用 Pygame 了！"
  • pygame.init() — 初始化所有 Pygame 模块，相当于"开机"
  • pygame.display.set_mode((宽, 高)) — 创建游戏窗口，括号里是元组
  • pygame.display.set_caption("...") — 给窗口起个名字
🔍

代码详解 （下）

# 第 4 步：主循环 —— 游戏的"心跳" running = True while running: # 遍历所有事件（按键、鼠标、关闭窗口等） for event in pygame.event.get(): if event.type == pygame.QUIT: running = False # 点击关闭按钮就退出 # 用白色填充整个窗口 screen.fill((255, 255, 255)) # 刷新屏幕，显示我们画的东西 pygame.display.flip() # 第 5 步：退出 Pygame，清理资源 pygame.quit()
  • while running: — 游戏主循环，程序一直跑，直到你关闭窗口
  • pygame.event.get() — 获取所有"事件"（键盘、鼠标、关闭窗口...）
  • screen.fill(颜色) — 用指定颜色把屏幕刷一遍
  • pygame.display.flip() — 刷新画面，把画的东西显示出来

理解坐标系

Pygame 的坐标系和数学课上的不太一样哦！

📐 数学坐标系

X → Y ↑ (0,0) Y 向上增大

Y 轴向上

🖥️ 计算机坐标系

X → Y ↓ (0,0)
(200,180)

Y 轴向下

关键区别：计算机屏幕的 Y 轴是向下的！

左上角是 (0, 0)，右下角是 (宽度, 高度)

🎮 比如 pygame.display.set_mode((800, 600)) 创建的窗口：

X 范围：0 ~ 799  |  Y 范围：0 ~ 599

🎨

RGB 颜色

在 Pygame 中，颜色用 三 个数字来表示：

颜色 = (红色, 绿色, 蓝色)

每种颜色的范围：0（没有）~ 255（最亮）

R
红色通道
G
绿色通道
B
蓝色通道

💡 记忆口诀：Red + Green + Blue

R + G = 黄色 🟡  |  R + B = 紫色 🟣  |  G + B = 青色 🩵
R + G + B = 白色 ⚪  |  0 + 0 + 0 = 黑色 ⚫

🌈

完整代码示例

把学到的所有知识串起来，就是下面这段代码！

# -*- coding: utf-8 -*- # 我的第一个 Pygame 程序 🎉 import pygame # 初始化 Pygame pygame.init() # 设置窗口 WIDTH, HEIGHT = 800, 600 screen = pygame.display.set_mode((WIDTH, HEIGHT)) pygame.display.set_caption("Hello, Pygame!") # 定义颜色常量（让代码更好读！） WHITE = (255, 255, 255) CORAL = (255, 107, 107) TEAL = (78, 205, 196) # 游戏主循环 running = True while running: for event in pygame.event.get(): if event.type == pygame.QUIT: running = False screen.fill(WHITE) # TODO: 在这里添加你想要的画面内容！ pygame.display.flip() pygame.quit()

🎯 复制这段代码，保存为 my_first_game.py，运行它！
