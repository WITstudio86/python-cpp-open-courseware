📦 Rect 对象 —— 游戏中的"身份证"

Rect(x, y, w, h)
▸ x — 左边界坐标
▸ y — 上边界坐标
▸ w — 矩形宽度
▸ h — 矩形高度

便捷属性：
▸ centerx / centery
▸ left / right
▸ top / bottom

# 创建一个表示小球的矩形 ball = pygame.Rect(400, 300, 30, 30) # x y 宽 高
3 / 10

🗺️ Pygame 坐标系

(0,0) ────────────────────────► x 增加 → 向右 │ │ ball = Rect(400, 300, 30, 30) │ ┌──────────────────┐ │ │ centerx = 415 │ │ │ centery = 315 │ │ │ (小球中心) │ │ └──────────────────┘ │ ▼ y 增加 → 向下

⚠️ 注意：y轴向下，和数学课本相反！

4 / 10

🏃 让球动起来

动画 = 每帧移动一点点

# 球的速度（每帧移动的像素数） vx = 5 # 水平速度：正=右, 负=左 vy = 5 # 垂直速度：正=下, 负=上 # 游戏循环中每帧执行： ball.x += vx # 水平移动 ball.y += vy # 垂直移动
5 / 10

💥 边界碰撞反弹

核心思想：速度取反！

# 碰到左右墙 → 水平反弹 if ball.left <= 0 or ball.right >= 800: vx = -vx # 正变负，负变正！ # 碰到上下墙 → 垂直反弹 if ball.top <= 0 or ball.bottom >= 600: vy = -vy # 正变负，负变正！

vx = 5 → 碰到墙 → vx = -5 （调头！）

6 / 10

🔍 碰撞检测：colliderect()

判断两个矩形是否重叠

# 球和挡板碰撞检测 if ball.colliderect(paddle): vy = -vy # 反弹！ ball.bottom = paddle.top # 防止卡住
⚽ ┃

返回 True → 碰撞了！
返回 False → 没碰到
（Pygame 帮你算好了！）

7 / 10

🖱️ 挡板跟随鼠标

# 获取鼠标当前坐标 mouse_x, mouse_y = pygame.mouse.get_pos() # 让挡板跟随鼠标水平移动 paddle.centerx = mouse_x # 限制挡板不超出窗口 if paddle.left < 0: paddle.left = 0 if paddle.right > 800: paddle.right = 800

鼠标的 x 坐标 → 自动成为挡板的水平位置

8 / 10

🔄 游戏循环全过程

# 每帧重复执行： 1. 处理事件（点击关闭 → 退出） 2. 更新球的位置（ball.x += vx, ball.y += vy） 3. 检测边界碰撞 → 反弹或重新发球 4. 挡板跟随鼠标移动 5. 检测球 ↔ 挡板碰撞 → 反弹 6. 清屏、画球、画挡板 7. 刷新画面 8. 控制帧率（clock.tick(60)）
