知识一：二维列表 —— 让数据排成表格

一句话解释：二维列表就是"列表的列表"，像一个有行有列的表格。 
# 普通列表（一维）：一排数据
colors = ["红", "蓝", "绿", "黄"]

# 二维列表：一个表格！4行 x 4列
board = [
    ["红", "蓝", "绿", "黄"],  # 第0行
    ["红", "蓝", "绿", "黄"],  # 第1行
    ["红", "蓝", "绿", "黄"],  # 第2行
    ["红", "蓝", "绿", "黄"]   # 第3行
]

# 访问第2行、第3列（注意：从0开始！）
card = board[2][3]   # 得到 "黄"
生活类比：教室座位 —— 第3排第5列坐着小明
seats[3][5] = "小明" 就是二维列表！

如何创建4x4的棋盘？

16张牌 = 8对相同颜色，随机分布

import random

COLORS = [
    (255, 0, 0),    # 红
    (0, 130, 255),  # 蓝
    (0, 200, 0),    # 绿
    (255, 200, 0),  # 黄
    (200, 0, 255),  # 紫
    (255, 130, 0),  # 橙
    (0, 200, 200),  # 青
    (255, 100, 180) # 粉
]

def create_board():
    # 1. 生成8对颜色编号: 0,0,1,1,2,2,...,7,7
    pairs = []
    for i in range(8):
        pairs.append(i)
        pairs.append(i)

    # 2. 洗牌！打乱顺序
    random.shuffle(pairs)

    # 3. 填入4x4的二维列表
    board = []
    for row in range(4):
        current_row = []
        for col in range(4):
            color_index = pairs[row * 4 + col]
            current_row.append(COLORS[color_index])
        board.append(current_row)
    return board
关键公式： row * 4 + col —— 跳过前面整行，加上当前列
【讲解】如何创建4x4的棋盘？ 本页要点（照着讲即可）： · 16张牌 = 8对 相同颜色，随机分布 · 关键公式： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

知识二：卡牌的三种状态

每张牌需要一个 状态标签，告诉程序该怎么画它、能不能点它。

状态含义显示效果能点击吗？
"hidden"隐藏（牌背朝上）灰色方块✅ 能
"revealed"已翻开显示颜色❌ 不能
"matched"已配对颜色变暗❌ 不能

card = {
    "color": (255, 0, 0),    # 红色

# 翻开：修改状态

知识三：用 pygame.draw.rect 画牌

# 卡牌尺寸
CARD_W = 120
CARD_H = 120
GAP = 20            # 间隙

# 计算4x4网格总宽高，并居中
GRID_W = 4 * CARD_W + 3 * GAP
OFFSET_X = (SCREEN_W - GRID_W) // 2

def draw_board(screen, board):
    for row in range(4):
        for col in range(4):
            # 计算屏幕坐标
            x = OFFSET_X + col * (CARD_W + GAP)
            y = OFFSET_Y + row * (CARD_H + GAP)

            card = board[row][col]
            if card["state"] == "hidden":
                color = (80, 80, 120)      # 灰色牌背
            elif card["state"] == "revealed":
                color = card["color"]       # 显示真实颜色

            pygame.draw.rect(screen, color, (x, y, CARD_W, CARD_H))
坐标公式：
每张牌的位置 = 偏移量 + 列号 x (牌宽 + 间隙)
x = OFFSET_X + col * (CARD_W + GAP)
【讲解】知识三：用 pygame.draw.rect 画牌 本页要点（照着讲即可）： · 坐标公式： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

知识四：鼠标坐标 → 卡牌行列

鼠标点的是屏幕像素（x, y），需要换算成"第几行第几列"。

def get_card_at_pos(mouse_x, mouse_y):
    # 核心公式：整数除法 // 把连续坐标变成格子编号
    col = (mouse_x - OFFSET_X) // (CARD_W + GAP)
    row = (mouse_y - OFFSET_Y) // (CARD_H + GAP)

    # 检查是否在有效范围（0~3）
    if 0 <= row < 4 and 0 <= col < 4:
        return (row, col)
    else:
        return None   # 点到了空白处
整数除法 // 的魔法：
• 如果 0 ≤ x < 140 → col = 0（第一列）
• 如果 140 ≤ x < 280 → col = 1（第二列）
• 如果 280 ≤ x < 420 → col = 2（第三列）
• 如果 420 ≤ x < 560 → col = 3（第四列）

类比：你在 Excel 里点击一个格子，程序怎么知道是第几行第几列？
【讲解】知识四：鼠标坐标 → 卡牌行列 本页要点（照着讲即可）： · 鼠标点的是屏幕像素（x, y），需要换算成"第几行第几列"。 · 整数除法 // 的魔法： 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

把它们拼起来：游戏主循环

board = create_board()
running = True

while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        elif event.type == pygame.MOUSEBUTTONDOWN:
            result = get_card_at_pos(event.pos[0], event.pos[1])
            if result is not None:
                row, col = result
                # 只有隐藏的牌才能翻开
                if board[row][col]["state"] == "hidden":
                    board[row][col]["state"] = "revealed"

    draw_board(screen, board)
    pygame.display.flip()
核心逻辑：
1. 检测鼠标点击
2. 坐标换算成行列
3. 检查状态（只有 hidden 才能翻）
4. 修改状态 → 重新绘制

写代码时注意这些！

  • 坐标没减偏移量 —— offset_x 忘了减，点击位置就偏了
  • 忘了检查状态 —— 已经翻开的牌还能点，不符合游戏规则
  • 索引越界 —— row 或 col 超过了 3，记得用 if 0 <= row < 4 保护
  • 颜色全一样 —— 检查 pairs 列表是否生成了 8 对
  • 忘记 flip() —— 画了但没刷新屏幕，等于白画
