# 第9节：贪吃的小蛇

## 🎯 教学目标
- 学生能够理解"列表模拟蛇身"的核心思路：头部插入、尾部删除，实现蛇的移动效果
- 学生能够使用方向变量（dx, dy）控制蛇的移动方向，并理解"防止反向移动"的逻辑
- 学生能够实现食物的随机生成，并确保食物不与蛇身重叠
- 学生能够实现蛇"吃到食物变长"的效果（头插不删尾）

**教师话术：**

"同学们，大家玩过贪吃蛇吗？（等待学生回应）对，就是那个小蛇在屏幕上爬来爬去，吃到食物就变长的游戏。今天我们要用Python和Pygame，亲手做一个贪吃蛇！"

"在开始编程之前，老师先问大家一个问题：小蛇在屏幕上移动的时候，它的身体是怎么变化的？"

> **互动设计：** 播放贪吃蛇游戏动画（或教师在IDE中运行示范程序），让学生观察蛇的移动特点。引导发现：蛇头往前移一格，蛇尾缩短一格 —— 整体长度不变，但位置变了。

"大家发现了吗？蛇的移动其实就像——前面加一个，后面删一个。今天我们就用Python的列表来实现这个巧妙的想法！"

**导入核心概念展示（板书）：**
```
移动前: [头, 身1, 身2, 尾]    -->   移动后: [新头, 头, 身1, 身2]
            ↑头部加一格                   ↑尾部删一格
```

### 二、核心讲解（25分钟）

#### 步骤1：初始化Pygame和基础设置（3分钟）

```python
import pygame
import random

# 初始化Pygame
pygame.init()

# 设置窗口
WIDTH = 800
HEIGHT = 600
GRID_SIZE = 20          # 每格20像素，蛇和食物都按格子走
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("贪吃的小蛇")

# 颜色定义（RGB）
BLACK = (0, 0, 0)
WHITE = (255, 255, 255)
GREEN = (0, 255, 0)
DARK_GREEN = (0, 200, 0)
RED = (255, 0, 0)

clock = pygame.time.Clock()
FPS = 10                # 控制游戏速度，数字越大蛇跑得越快
```

**讲解要点：**
- `GRID_SIZE = 20`：把屏幕分成格子，蛇每次移动一格，简化坐标计算
- `FPS = 10`：每秒刷新10次，控制蛇的移动速度。后面可以让学生改成15或5试试看

#### 步骤2：用列表表示蛇身（7分钟）【本节课核心难点】

**教师话术：**

"现在我们来想一想：蛇的身体怎么存？蛇身上有好几个格子，每个格子有一个坐标。我们要把所有格子的坐标都记下来 —— 这时候列表就是最好的工具了！"

```python
# 蛇的初始位置：放在屏幕中央偏左
# 蛇身是一个列表，每个元素是一个 [x, y] 坐标
# 列表第一个元素是蛇头，最后一个元素是蛇尾
snake = [[400, 300], [380, 300], [360, 300]]
#         蛇头           身1         身2（尾）

# 蛇的移动方向：用dx和dy表示
# dx=20 表示每次向右移动一格（x增加20）
# dy=0  表示垂直方向不动
dx = GRID_SIZE   # 每次移动的像素数 = 格子大小
dy = 0
```

**核心算法 —— 蛇的移动逻辑：**

```python
# 蛇移动的核心代码（在游戏循环中每一帧执行）
# 1. 计算新蛇头的位置
new_head = [snake[0][0] + dx, snake[0][1] + dy]

# 2. 把新蛇头插入到列表最前面
snake.insert(0, new_head)

# 3. 删除列表最后一项（蛇尾）
snake.pop()
```

**讲解关键点（可视化演示）：**

```
方向向右（dx=20, dy=0）时：

移动前: snake = [[400,300], [380,300], [360,300]]
                      ↑头        ↑身       ↑尾

步骤1: new_head = [400+20, 300+0] = [420, 300]

步骤2: snake.insert(0, [420,300])
       snake = [[420,300], [400,300], [380,300], [360,300]]
                ↑新头       ↑旧头       ↑身        ↑尾

步骤3: snake.pop() 删除最后一个
       snake = [[420,300], [400,300], [380,300]]
                ↑新头       ↑旧头       ↑新尾
```

**踩坑提示：**
- `snake[0]` 是列表的第一个元素，即蛇头坐标 `[400, 300]`
- `snake[0][0]` 是蛇头坐标的 x 值（400），`snake[0][1]` 是蛇头坐标的 y 值（300）
- `insert(0, 元素)` 表示在索引0的位置插入，即插到最前面
- `pop()` 不写参数时默认删除最后一个

#### 步骤3：方向键控制移动（5分钟）

```python
# 在事件循环中处理按键
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False
    elif event.type == pygame.KEYDOWN:
        # 按上箭头：向上移动（dy为负）
        if event.key == pygame.K_UP and dy == 0:
            # 注意：dy==0 保证不能在上下移动时直接反向
            dx = 0
            dy = -GRID_SIZE
        # 按下箭头：向下移动
        elif event.key == pygame.K_DOWN and dy == 0:
            dx = 0
            dy = GRID_SIZE
        # 按左箭头：向左移动
        elif event.key == pygame.K_LEFT and dx == 0:
            dx = -GRID_SIZE
            dy = 0
        # 按右箭头：向右移动
        elif event.key == pygame.K_RIGHT and dx == 0:
            dx = GRID_SIZE
            dy = 0
```

**为什么需要 `and dy == 0` 这个条件？**

"同学们，假如蛇正在向右走，你突然按了左键，蛇头会直接撞上自己的脖子——游戏就结束了！所以我们要加一个判断：只有蛇不是正在上下移动的时候，才能改变左右方向；只有蛇不是正在左右移动的时候，才能改变上下方向。"

> **互动设计：** 让学生自己写一下如果不加这个判断会发生什么，然后口头讨论。

#### 步骤4：食物的随机生成（5分钟）

```python
# 生成食物：随机位置，但不能和蛇身重叠
def generate_food(snake):
    """随机生成一个不与蛇身重叠的食物位置"""
    while True:
        # 计算格子的范围
        # 800 // 20 = 40 列, 600 // 20 = 30 行
        fx = random.randint(0, (WIDTH // GRID_SIZE) - 1) * GRID_SIZE
        fy = random.randint(0, (HEIGHT // GRID_SIZE) - 1) * GRID_SIZE
        food_pos = [fx, fy]
        # 检查这个位置是否和蛇身重叠
        if food_pos not in snake:
            return food_pos

# 初始化第一个食物
food = generate_food(snake)
```

**讲解要点：**
- `random.randint(0, 39)` 生成0~39的随机整数，乘以20后得到0, 20, 40, ... 780 —— 恰好落在格子上
- `food_pos not in snake` 检查食物位置是否和蛇身的某个格子重合
- 如果重合了就重新随机，直到找到不重合的位置

---

#### 步骤5：吃到食物的检测与变长（3分钟）

```python
# 在移动蛇之后，检查蛇头是否碰到了食物
if snake[0] == food:
    # 吃到了！重新生成食物
    food = generate_food(snake)
    # 注意：这里不执行 snake.pop()
    # 蛇头插入后不删尾部 → 蛇就变长了一格！
else:
    # 没吃到食物 → 正常移动，删除尾部
    snake.pop()
```

**讲解要点：**
- 吃到的条件：蛇头坐标等于食物坐标
- 变长的关键：不执行 `pop()`，头部增加了但尾部没减少，总长度+1

#### 步骤6：绘制蛇和食物（2分钟）

```python
# 在游戏循环的绘制部分
# 1. 清屏
screen.fill(BLACK)

# 2. 绘制食物（红色方块）
pygame.draw.rect(screen, RED, (food[0], food[1], GRID_SIZE, GRID_SIZE))

# 3. 绘制蛇身（绿色方块）
for i, segment in enumerate(snake):
    if i == 0:
        # 蛇头用亮绿色
        color = GREEN
    else:
        # 身体用深绿色
        color = DARK_GREEN
    pygame.draw.rect(screen, color, (segment[0], segment[1], GRID_SIZE, GRID_SIZE))

# 4. 更新画面
pygame.display.flip()
```

> **小技巧：** `enumerate(snake)` 同时给出索引和值，索引0是蛇头，可以用不同颜色区分。

### 四、总结与作业（5分钟）

#### 本节课要点回顾

1. **蛇身 = 列表**：列表的每个元素是一个坐标 `[x, y]`，第一个是蛇头，最后一个是蛇尾
2. **移动 = 头插 + 尾删**：`insert(0, new_head)` + `pop()`
3. **方向控制**：用 `dx` 和 `dy` 变量，通过判断防止反向移动
4. **食物随机生成**：`randint` 随机坐标，`not in snake` 防止重叠
5. **变长的秘密**：吃到食物时不执行 `pop()`，蛇就多了一节

## 💡 常见问题与解决

- **问题1：蛇不动了**
  → 检查事件循环中是否正确更新了 `dx` 和 `dy`；检查移动代码是否在游戏循环内部。

- **问题2：蛇一走就消失了（只剩最后一节）**
  → 检查 `insert` 和 `pop` 的顺序：必须先 `insert(0, new_head)` 再 `pop()`。如果先 `pop()` 再 `insert`，当蛇只有1节时列表为空，`insert` 会出错。

- **问题3：食物出现在蛇身上**
  → 检查 `generate_food` 中的 `if food_pos not in snake:` 是否生效。注意 `in` 判断的是列表元素是否相等，即坐标列表 `[x, y]` 是否完全相同。

- **问题4：按方向键没有反应**
  → 检查事件类型是 `pygame.KEYDOWN`（注意大写）；检查按键名是否正确（`K_UP`, `K_DOWN`, `K_LEFT`, `K_RIGHT`）。

- **问题5：蛇可以反向走回头路**
  → 检查方向判断条件：`K_UP` 或 `K_DOWN` 时要加 `and dy == 0`；`K_LEFT` 或 `K_RIGHT` 时要加 `and dx == 0`。

- **问题6：蛇移动太快或太慢**
  → 调整 `FPS` 值。`FPS = 10` 是标准速度，降低变慢，增加变快。也可以调节 `clock.tick(FPS)` 的参数。

- **问题7：食物生成太慢，游戏卡住了**
  → 当蛇身很长、几乎占满屏幕时，`while True` 可能循环很多次。可以设置一个最大尝试次数（如1000次），超过后遍历可用位置。
