### 二、核心讲解（25分钟）

#### 步骤1：认识三角函数——"方向拆解器"（8分钟）

**生动的类比——箭头指向**：

想象你站在一个弓箭靶场，你想把箭射向 45° 角的靶子。但计算机只会说"向右走几个像素，向上走几个像素"（x 和 y 的变化量）。

三角函数就像一个"方向翻译官"：你告诉它角度，它告诉你 X 和 Y 分别走多少。

```
              🎯 靶子
             /
            /  ← 泡泡的飞行轨迹（45°）
           /
  🏹 你
```

把这条飞行线画成一个直角三角形的斜边：
- **`cos(角度)`** = 三角形底边（水平分量）→ 控制 X 方向的速度
- **`sin(角度)`** = 三角形对边（垂直分量）→ 控制 Y 方向的速度

**记住口诀**：**"cos 管左右，sin 管上下"**

```python
import math

# 角度 → 弧度（计算机只认识弧度！）
angle = 45                           # 角度制：45°
rad = math.radians(angle)            # 弧度制：约 0.785
#          ⬆️ "radians" = radius（半径）+ ans（...），
#             想象一个半径扫过的弧长

# 三角函数拆解方向
speed = 5                            # 飞行速度（像素/帧）
vx = speed * math.cos(rad)           # X 方向速度 ≈ 3.54
vy = -speed * math.sin(rad)          # Y 方向速度 ≈ -3.54
#      ⬆️ 负号！因为屏幕Y轴向下，向上飞要取负值
```

**为什么用弧度？**（用比萨饼类比）
- 角度制：把圆分成 360 份（古人用 360 因为接近一年天数）
- 弧度制：用圆的半径去"量"弧长，一圈 = 2π ≈ 6.28 弧度
- 计算机数学函数都用弧度，`math.radians()` 帮我们做转换

**验证理解**：
| 角度 | cos 值 | sin 值 | 方向 |
|------|--------|--------|------|
| 0°（正右） | 1 | 0 | → |
| 90°（正上） | 0 | 1 | ↑ |
| 180°（正左） | -1 | 0 | ← |
| 270°（正下） | 0 | -1 | ↓ |

#### 步骤2：发射器的鼠标瞄准（6分钟）

**思路**：
1. 获取发射器位置（屏幕底部中间）和鼠标位置
2. 计算两点之间的角度：`math.atan2(dy, dx)`
3. 画一条从发射器到鼠标方向的瞄准线，帮助玩家预判

```python
# 发射器位置（屏幕底部中央）
launcher_x = WIDTH // 2
launcher_y = HEIGHT - 60

# 获取鼠标位置
mx, my = pygame.mouse.get_pos()

# 计算从发射器指向鼠标的角度
dx = mx - launcher_x
dy = my - launcher_y
aim_angle = math.atan2(-dy, dx)       # atan2 返回弧度
#                     ⬆️ 负号！因为屏幕Y轴向下
# atan2(y, x) 比 atan() 聪明：它能区分左右，返回 [-π, π]

# 画瞄准线（虚线效果更酷）
line_length = 100                     # 瞄准线长度
end_x = launcher_x + line_length * math.cos(aim_angle)
end_y = launcher_y - line_length * math.sin(aim_angle)
#                      ⬆️ 又出现负号了！因为屏幕Y轴向下
pygame.draw.line(screen, WHITE, (launcher_x, launcher_y), (end_x, end_y), 3)
```

**为什么发射时要记住方向？**
发射后泡泡沿直线飞行，不需要每帧都重新算角度——把 `vx` 和 `vy` 存起来就行：

```python
# 发射时（按空格键）
if event.key == pygame.K_SPACE and not bubble_flying:
    bubble_flying = True
    bubble_x = launcher_x
    bubble_y = launcher_y
    # 计算初速度（存起来，飞行时每帧加上去）
    speed = 8
    bubble_vx = speed * math.cos(aim_angle)
    bubble_vy = -speed * math.sin(aim_angle)  # 向上飞，取负
```

#### 步骤3：泡泡飞行与碰撞检测（6分钟）

**飞行**：每帧更新泡泡位置

```python
# 在主循环中更新泡泡位置
if bubble_flying:
    bubble_x += bubble_vx          # 沿X方向移动
    bubble_y += bubble_vy          # 沿Y方向移动
```

**碰撞检测**——泡泡什么时候停下？

1. **碰到顶部**：`bubble_y` 到达顶部边界
2. **碰到已有泡泡**：飞行泡泡的圆心与任一已有泡泡的圆心距离 < 2 * 半径

```python
# 碰撞检测：碰到顶部
if bubble_y - BUBBLE_RADIUS <= TOP_MARGIN:
    bubble_flying = False
    snap_to_grid()                  # 吸附到六边形网格

# 碰撞检测：碰到已有泡泡
for existing in bubble_list:
    # 计算两个圆心之间的距离
    dist = math.sqrt((bubble_x - existing.x) ** 2 + (bubble_y - existing.y) ** 2)
    if dist < 2 * BUBBLE_RADIUS:
        bubble_flying = False
        snap_to_grid()
        break
```

#### 步骤4：六边形网格吸附（5分钟）

**为什么需要网格？**
泡泡龙中所有泡泡都排列在六边形网格上，这样消除判断才准确。飞行泡泡停下后，要"吸"到最近的空网格位置。

**六边形网格的规律**：
- 相邻两列泡泡上下错开半个格子（就像蜂窝）
- 奇数行和偶数行的 X 偏移不同

```python
# 网格参数
GRID_COLS = 8                        # 列数（水平方向）
GRID_ROWS = 12                       # 行数（垂直方向）
CELL_R = BUBBLE_RADIUS               # 网格半径 = 泡泡半径
CELL_W = 2 * CELL_R                  # 水平间距（紧密排列）
CELL_H = int(CELL_R * math.sqrt(3))  # 垂直间距（六边形高度）

def snap_to_grid(bx, by):
    """将泡泡坐标吸附到最近的六边形网格位置"""
    # 1. 先找到最近的列
    col = round(bx / CELL_W)
    col = max(0, min(GRID_COLS - 1, col))  # 限制范围

    # 2. 根据列调整行（偶数行偏移半个格子）
    offset_x = (CELL_W // 2) if col % 2 == 1 else 0
    row = round((by - offset_x) / CELL_H)  # 注意这里的偏移！
    row = max(0, min(GRID_ROWS - 1, row))

    # 3. 找到第一个空位
    for r in range(row, -1, -1):     # 从下往上找
        if grid[r][col] is None:     # 这个位置是空的
            grid_x = col * CELL_W + (CELL_W // 2 if r % 2 == 1 else 0) + BUBBLE_RADIUS
            grid_y = r * CELL_H + BUBBLE_RADIUS + TOP_MARGIN
            return grid_x, grid_y
    return bx, by                    # 没找到空位就停在原处
```

**直观理解六边形排列**：
```
  列0    列1    列2    列3
  ⬤     ⬤     ⬤     ⬤      ← 第0行（偶数行，贴左）
     ⬤     ⬤     ⬤     ⬤   ← 第1行（奇数行，右移半个）
  ⬤     ⬤     ⬤     ⬤      ← 第2行
     ⬤     ⬤     ⬤     ⬤   ← 第3行
```

## 💡 常见问题与解决

| 问题 | 原因 | 解决 |
|------|------|------|
| 泡泡往上飞却往下掉 | `vy` 忘了取负号。屏幕Y轴向下，向上飞需要 `-sin` | 检查 `bubble_vy = -speed * sin(angle)` |
| 泡泡飞行方向不准 | 角度制直接传给了 sin/cos。必须先用 `radians()` 转换 | 检查是否调用了 `math.radians(angle)` |
| 泡泡斜飞角度不对 | `atan2` 的参数顺序写反了 | 正确：`math.atan2(y, x)`，不是 `atan2(x, y)` |
| 网格吸附位置偏移 | 奇数行/偶数列的偏移量没加对 | 检查偶数行和奇数行的 X 偏移逻辑 |
| 泡泡穿过了已有泡泡 | 碰撞检测用矩形碰撞而非圆形碰撞 | 圆形碰撞用圆心距离判断：`dist < 2*R` |
| 瞄准线方向反了 | `atan2` 中 dy 没取负 | 屏幕Y轴向下，需 `atan2(-dy, dx)` |
