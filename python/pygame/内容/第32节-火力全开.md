### 二、核心讲解（25分钟）

#### 2.1 道具掉落系统（7分钟）

**为什么要做道具掉落？**

打败敌人后掉出奖励，是游戏最让人兴奋的时刻之一。这种"随机奖励"机制让每次战斗都有惊喜。

**道具的生命周期**

```
敌人被消灭
    ↓
判断是否掉落（概率 roll 点）
    ↓
创建道具精灵（随机类型）
    ↓
道具从敌人位置开始下落
    ↓
玩家碰到道具 → 拾取 → 生效
道具飞出屏幕 → 删除
```

**代码示例**

```python
import random

class PowerUp(pygame.sprite.Sprite):
    """道具精灵类"""
    
    # 道具类型常量
    TYPE_WEAPON = "weapon"     # 武器升级：散弹/激光
    TYPE_HEAL = "heal"          # 生命恢复
    TYPE_SHIELD = "shield"      # 护盾
    
    def __init__(self, x, y, power_type, weapon_subtype=None):
        super().__init__()
        self.power_type = power_type  # 道具类型
        self.weapon_subtype = weapon_subtype  # 如果是武器，具体是哪一种
        
        # 根据道具类型绘制不同颜色
        self.image = pygame.Surface((24, 24), pygame.SRCALPHA)
        if power_type == self.TYPE_WEAPON:
            color = (255, 200, 0)     # 金色 — 武器道具
        elif power_type == self.TYPE_HEAL:
            color = (100, 255, 100)   # 绿色 — 生命恢复
        else:
            color = (100, 180, 255)   # 蓝色 — 护盾
        
        pygame.draw.circle(self.image, color, (12, 12), 12)
        pygame.draw.circle(self.image, (255, 255, 255), (12, 12), 12, 2)  # 白边
        
        self.rect = self.image.get_rect()
        self.rect.x = x
        self.rect.y = y
        self.speed_y = 2  # 道具下落速度
    
    def update(self):
        """道具每帧下落"""
        self.rect.y += self.speed_y
        # 飞出屏幕底部就删除
        if self.rect.top > 600:
            self.kill()


def try_drop_item(x, y, is_boss=False):
    """尝试在指定位置掉落道具
    
    参数:
        x, y: 掉落位置（敌人死亡位置）
        is_boss: 是否是 Boss 死亡（Boss 100% 掉落）
    
    返回:
        新创建的道具精灵，如果没有掉落则返回 None
    """
    # Boss 被消灭后必定掉落道具
    if is_boss:
        drop_chance = 1.0  # 100%
    else:
        drop_chance = 0.15  # 小兵 15% 掉落
    
    if random.random() < drop_chance:
        # 随机选择道具类型
        roll = random.random()
        if roll < 0.5:
            # 50% 概率：武器升级
            subtype = random.choice(["shotgun", "laser"])
            return PowerUp(x, y, PowerUp.TYPE_WEAPON, subtype)
        elif roll < 0.8:
            # 30% 概率：生命恢复
            return PowerUp(x, y, PowerUp.TYPE_HEAL)
        else:
            # 20% 概率：护盾
            return PowerUp(x, y, PowerUp.TYPE_SHIELD)
    
    return None
```

**讲解要点（板书强调）**

| 要点 | 说明 |
|------|------|
| 概率控制 | `random.random()` 返回 0~1 的随机小数，和阈值比较 |
| 道具类型 | 用常量定义，不要直接写字符串，好维护 |
| is_boss 参数 | Boss 必定掉落，增加击败 Boss 的奖励感 |
| kill() 方法 | Sprite 自带方法，从所在的所有 Group 中移除 |

#### 2.2 武器状态切换（7分钟）

**为什么要做武器切换？**

如果玩家从头到尾只能发射一种子弹，很快就腻了。武器切换让游戏有"变强"的爽感——吃到道具后火力瞬间提升！

**三种武器模式**

| 武器 | 效果 | 持续时间 |
|------|------|----------|
| 普通子弹 | 单发，向前直线飞行 | 永久（默认） |
| 散弹 | 一次发射 5 发，呈扇形散开 | 8 秒 |
| 激光 | 持续发射粗光束 | 6 秒 |

**代码示例**

```python
class Player(pygame.sprite.Sprite):
    """玩家飞机精灵"""
    
    def __init__(self, x, y):
        super().__init__()
        # ... 初始化 image 和 rect ...
        
        # ===== 武器系统 =====
        self.weapon_type = "normal"      # 当前武器类型
        self.weapon_timer = 0            # 武器剩余时间（帧数）
        self.shoot_cooldown = 0          # 射击冷却
        
        # ===== 生命值与护盾 =====
        self.hp = 3                      # 生命值
        self.max_hp = 3                  # 最大生命值
        self.shield_active = False       # 护盾是否激活
        self.shield_timer = 0            # 护盾剩余时间
    
    def activate_weapon(self, weapon_type, duration_seconds):
        """激活新武器
        
        参数:
            weapon_type: "shotgun" 或 "laser"
            duration_seconds: 持续时间（秒）
        """
        self.weapon_type = weapon_type
        # 将秒转换为帧数（假设 60 FPS）
        self.weapon_timer = duration_seconds * 60
    
    def update(self):
        """每帧更新"""
        # 武器倒计时
        if self.weapon_timer > 0:
            self.weapon_timer -= 1
            if self.weapon_timer <= 0:
                # 时间到，恢复普通武器
                self.weapon_type = "normal"
        
        # 护盾倒计时
        if self.shield_timer > 0:
            self.shield_timer -= 1
            if self.shield_timer <= 0:
                self.shield_active = False
        
        # 射击冷却
        if self.shoot_cooldown > 0:
            self.shoot_cooldown -= 1
    
    def shoot(self):
        """发射子弹——根据当前武器类型生成不同的子弹"""
        bullets = []
        
        if self.weapon_type == "normal":
            # 普通子弹：单发
            bullet = Bullet(self.rect.centerx, self.rect.top, 0, -8)
            bullets.append(bullet)
        
        elif self.weapon_type == "shotgun":
            # 散弹：5 发扇形子弹
            spread_angles = [-30, -15, 0, 15, 30]  # 散射角度
            for angle in spread_angles:
                rad = math.radians(angle)
                vx = 8 * math.sin(rad)
                vy = -8 * math.cos(rad)
                bullet = Bullet(self.rect.centerx, self.rect.top, vx, vy)
                bullets.append(bullet)
        
        elif self.weapon_type == "laser":
            # 激光：持续光束（在 draw 时绘制粗线）
            # 激光子弹是一条很长的高速子弹
            laser_bullet = LaserBeam(self.rect.centerx, self.rect.top)
            bullets.append(laser_bullet)
        
        return bullets
```

**讲解要点**

- **计时器模式**：用 `weapon_timer` 倒计时，到 0 自动恢复
- **扇形散射**：用三角函数计算每个子弹的方向分量
- **策略选择**：激光持续时间短但威力大，散弹范围广

#### 2.3 Boss 状态机（6分钟）

**为什么要做状态机？**

如果 Boss 从头到尾都是一个打法，战斗就很单调。好的 Boss 战斗应该有"阶段感"——血量越低，Boss 越疯狂！

这就是游戏开发中的**状态机（State Machine）**概念：根据条件在不同状态之间切换。

**Boss 三阶段设计**

```python
class Boss(pygame.sprite.Sprite):
    """Boss 精灵类"""
    
    # Boss 阶段常量
    PHASE_1 = 1    # 阶段1：血量 > 50%
    PHASE_2 = 2    # 阶段2：血量 20%~50%
    PHASE_3 = 3    # 暴怒阶段：血量 <= 20%
    
    def __init__(self, x, y):
        super().__init__()
        # ... 初始化 ...
        self.max_hp = 100
        self.hp = self.max_hp
        self.phase = self.PHASE_1
        
        # 弹幕发射计时
        self.shoot_timer = 0
        self.shoot_interval = 40  # 发射间隔（帧）
        self.pattern_timer = 0    # 弹幕模式切换计时
    
    def update_phase(self):
        """根据当前血量更新 Boss 阶段"""
        hp_percent = self.hp / self.max_hp
        
        if hp_percent > 0.5:
            self.phase = self.PHASE_1
        elif hp_percent > 0.2:
            self.phase = self.PHASE_2
        else:
            self.phase = self.PHASE_3
    
    def shoot(self):
        """根据当前阶段发射不同弹幕"""
        bullets = []
        cx, cy = self.rect.centerx, self.rect.bottom
        
        if self.phase == self.PHASE_1:
            # 阶段1：扇形弹幕（3 发），移动较慢
            for angle in [-20, 0, 20]:
                rad = math.radians(angle + 90)  # +90 向下
                vx = 3 * math.cos(rad)
                vy = 3 * math.sin(rad)
                bullets.append(EnemyBullet(cx, cy, vx, vy))
        
        elif self.phase == self.PHASE_2:
            # 阶段2：扇形弹 + 圆形弹交替
            self.pattern_timer += 1
            if (self.pattern_timer // 60) % 2 == 0:
                # 扇形弹幕（更多更密）：5 发
                for angle in [-40, -20, 0, 20, 40]:
                    rad = math.radians(angle + 90)
                    vx = 4 * math.cos(rad)
                    vy = 4 * math.sin(rad)
                    bullets.append(EnemyBullet(cx, cy, vx, vy))
            else:
                # 圆形弹幕（12 方向均匀分布）
                for i in range(12):
                    angle = i * 30  # 360 / 12 = 30 度间隔
                    rad = math.radians(angle)
                    vx = 4 * math.cos(rad)
                    vy = 4 * math.sin(rad)
                    bullets.append(EnemyBullet(cx, cy, vx, vy))
        
        elif self.phase == self.PHASE_3:
            # 暴怒阶段：极密扇形 + 追踪弹
            # 密集扇形弹幕：7 发
            for angle in [-45, -30, -15, 0, 15, 30, 45]:
                rad = math.radians(angle + 90)
                vx = 5 * math.cos(rad)
                vy = 5 * math.sin(rad)
                bullets.append(EnemyBullet(cx, cy, vx, vy))
            
            # 追踪弹：每 2 秒发射一枚
            if self.shoot_timer % 120 == 0:
                # 计算朝向玩家的方向
                player = ...  # 需要获取玩家位置
                dx = player.rect.centerx - cx
                dy = player.rect.centery - cy
                dist = math.sqrt(dx**2 + dy**2)
                vx = 3 * dx / dist
                vy = 3 * dy / dist
                bullets.append(HomingBullet(cx, cy, vx, vy))
        
        return bullets
```

**状态机图示（板书）**

```
        血量 > 50%              血量 20%~50%            血量 ≤ 20%
    ┌──────────────┐      ┌──────────────┐      ┌──────────────┐
    │   阶段 1     │ ───→ │   阶段 2     │ ───→ │  暴怒阶段    │
    │              │      │              │      │              │
    │ 移动慢       │      │ 移动加快     │      │ 弹幕极密     │
    │ 扇形弹 3发   │      │ 扇形+圆形交替 │      │ + 追踪弹     │
    └──────────────┘      └──────────────┘      └──────────────┘
```

**讲解要点**

- **状态切换的条件**：血量百分比 —— 简单但有效
- **弹幕模式交替**：用 `pattern_timer` 切换，每 60 帧换一次花样
- **追踪弹算法**：计算朝向玩家的单位向量作为速度方向

#### 2.4 爆炸特效（5分钟）

**为什么要做特效？**

特效让游戏"有感觉"。没有特效的爆炸只是敌人消失，有了特效才有"爽感"！

**爆炸特效的两种实现**

**（1）粒子飞溅**

```python
class Particle(pygame.sprite.Sprite):
    """爆炸粒子"""
    
    def __init__(self, x, y, color):
        super().__init__()
        self.image = pygame.Surface((6, 6), pygame.SRCALPHA)
        pygame.draw.circle(self.image, color, (3, 3), 3)
        self.rect = self.image.get_rect(center=(x, y))
        
        # 随机速度和方向
        angle = random.uniform(0, 2 * math.pi)
        speed = random.uniform(2, 6)
        self.vx = speed * math.cos(angle)
        self.vy = speed * math.sin(angle)
        
        # 生命值（帧），用于渐隐
        self.life = 30
        self.max_life = 30
    
    def update(self):
        """粒子运动 + 渐隐"""
        self.rect.x += self.vx
        self.rect.y += self.vy
        
        # 生命递减
        self.life -= 1
        
        # 渐隐：透明度逐渐降低
        alpha = int(255 * (self.life / self.max_life))
        self.image.set_alpha(alpha)
        
        if self.life <= 0:
            self.kill()


def create_explosion(x, y, particle_count=30):
    """创建爆炸粒子效果
    
    参数:
        x, y: 爆炸中心位置
        particle_count: 粒子数量
    """
    particles = []
    colors = [
        (255, 255, 200),   # 白色
        (255, 255, 0),     # 黄色
        (255, 165, 0),     # 橙色
        (255, 80, 0),      # 橙红色
        (255, 0, 0),       # 红色
    ]
    
    for _ in range(particle_count):
        color = random.choice(colors)
        particle = Particle(x, y, color)
        particles.append(particle)
    
    return particles
```

**（2）Boss 死亡大爆炸（多层圆形扩散）**

```python
class BossExplosion:
    """Boss 死亡时的多层圆形爆炸特效"""
    
    def __init__(self, x, y):
        self.x = x              # 爆炸中心 x
        self.y = y              # 爆炸中心 y
        self.life = 90          # 总生命（帧），约 1.5 秒
        self.max_life = 90
        
        # 定义多层圆圈（每层的半径和颜色）
        self.rings = [
            {"radius": 0, "max_radius": 200, "color": (255, 255, 255)},  # 白
            {"radius": 0, "max_radius": 160, "color": (255, 255, 0)},    # 黄
            {"radius": 0, "max_radius": 120, "color": (255, 165, 0)},    # 橙
            {"radius": 0, "max_radius": 80,  "color": (255, 0, 0)},      # 红
        ]
    
    def update(self):
        """更新：圆圈扩散 + 渐隐"""
        self.life -= 1
        
        # 每层圆圈按比例扩散
        progress = 1 - (self.life / self.max_life)  # 0 → 1
        for ring in self.rings:
            ring["radius"] = ring["max_radius"] * progress
    
    def draw(self, screen):
        """绘制多层爆炸圆圈"""
        alpha = int(255 * (self.life / self.max_life))  # 透明度逐渐降低
        
        for ring in self.rings:
            # 创建临时 surface 实现透明度
            temp = pygame.Surface((ring["max_radius"] * 2, ring["max_radius"] * 2), pygame.SRCALPHA)
            r = int(ring["radius"])
            if r > 0:
                pygame.draw.circle(temp, (*ring["color"], alpha), 
                                   (ring["max_radius"], ring["max_radius"]), r, 4)
            screen.blit(temp, (self.x - ring["max_radius"], self.y - ring["max_radius"]))
    
    def is_finished(self):
        """爆炸是否结束"""
        return self.life <= 0
```

**讲解要点**

- **粒子系统三要素**：位置 + 速度 + 生命值
- **渐隐效果**：`set_alpha()` 调整透明度
- **多层圆形**：利用 `pygame.SRCALPHA` 创建带透明通道的 Surface
- **颜色渐变**：从中心白 → 外圈红，模拟真实爆炸的颜色层次

## 💡 常见问题与解决

### 问题1：道具掉落后玩家碰不到
**原因**：道具下落速度太快，或者碰撞检测没写好  
**解决**：减慢 `speed_y`，确保碰撞检测代码在游戏循环中正确执行

### 问题2：武器切换到激光后子弹不显示
**原因**：激光不是普通子弹，需要用 `pygame.draw.line()` 绘制  
**解决**：激光类单独写一个 `draw()` 方法，在屏幕上绘制粗线

### 问题3：Boss 阶段切换没反应
**原因**：忘记在每次受伤后调用 `update_phase()`  
**解决**：在 Boss 的 `take_damage()` 方法最后调用 `self.update_phase()`

### 问题4：爆炸特效一闪就没了
**原因**：粒子生命值太短，或者 alpha 值设置不对  
**解决**：增加 `max_life` 的值（如从 30 改为 60），确保 `set_alpha()` 的 Surface 创建时带 `pygame.SRCALPHA` 标志

### 问题5：道具拾取后效果重复叠加
**原因**：没有检查当前是否已有同类型道具生效  
**解决**：在 `activate_weapon()` 开头判断，如果已是同类型武器则刷新时间而非重复激活
