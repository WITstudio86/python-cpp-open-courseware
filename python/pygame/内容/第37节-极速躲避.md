### 3.2 讲解（一）：滚动背景与玩家控制（10分钟）

#### 3.2.1 滚动背景 —— 马路为什么"跑不完"？

**核心原理：** 你只需要准备"两张路面图片"，让它们不断往下移动。当一张完全移出屏幕底部后，把它放回屏幕顶部。两张图片交替循环，就形成了"无限延伸"的视觉效果。

**生活类比：**
想象你在看一卷卫生纸从上往下滚——上面的纸不断出现，下面的纸不断消失。其实你只看到一小段，但感觉无穷无尽。

**三种常见实现方式对比：**

| 方式 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 单张图片滚动 | 用一张长图，每次重设 y 坐标偏移 | 实现简单 | 图片尺寸有限，滚完要"跳回去"，会有闪动 |
| 双图片接力 | 两张相同图片首尾衔接，交替循环 | 无缝循环，效果最好 | 需要管理两张图片的位置 |
| 车道线列表 | 用列表存储多条白线的 y 坐标，不断下移 | 灵活控制，适合画虚线 | 需要管理列表元素 |

**本课采用「车道线列表」方式：**

```python
# 用列表存储多条车道线的 y 坐标
# 每条车道线是一个 x 坐标（车道分界线的水平位置）
lane_lines = []  # 列表，存储每一小段虚线小段的位置 (x, y)

# 初始生成车道线：在屏幕纵向均匀分布
def create_lane_lines():
    lines = []
    # 屏幕宽度 600，三条车道，两条分界线在 x=200 和 x=400
    for x_pos in [200, 400]:          # 两条分界线
        for y_pos in range(0, HEIGHT, 60):  # 每隔 60 像素画一段虚线
            lines.append([x_pos, y_pos])
    return lines
```

**更新逻辑（每帧执行）：**

```python
# 车道线滚动速度（初始值）
SCROLL_SPEED = 5

# 每帧更新所有车道线的位置
for line in lane_lines:
    line[1] += SCROLL_SPEED  # y 坐标增加 → 向下移动

    # 如果某段虚线完全移出屏幕底部
    if line[1] > HEIGHT:
        line[1] = -10  # 把它重置到屏幕顶部（-10 让它从屏幕上方慢慢出现）
```

**给学生的比喻：**
> 车道线就像电梯里的灯——电梯一直在往上走，灯一直在往下走，但你永远能看到灯，因为旧灯移出底部的同时，新灯从顶部进来了。

**为什么要用列表管理车道线？**
- 每段虚线都是一个独立元素，可以各自追踪位置
- 方便增减虚线数量，控制道路密度
- 后期可以做"道路弯曲"等进阶效果（不同 x 坐标的线用不同速度）

#### 3.2.2 玩家左右移动 —— 车道切换

**核心思路：** 玩家不是"平滑移动"，而是在三条车道之间"瞬间切换"。按一下左键，跳到左边车道的中心；按一下右键，跳到右边车道的中心。

**为什么是"切换"而不是"平滑移动"？**
- 高速公路跑酷游戏的特点：一秒变换车道，干脆利落
- 平滑移动会让学生混淆"速度控制"和"位置绑定"
- 切换逻辑更简单，更容易和障碍物对齐（障碍物也在车道中心）

**实现代码：**

```python
# 三条车道的 x 中心坐标
LANES = [100, 300, 500]       # 左、中、右车道中心
current_lane = 1              # 当前车道索引（0=左, 1=中, 2=右）

player_x = LANES[current_lane]  # 玩家 x 坐标 = 当前车道中心

# 在事件处理中：
for event in pygame.event.get():
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_LEFT and current_lane > 0:
            current_lane -= 1                       # 向左切换车道
            player_x = LANES[current_lane]          # 瞬间移动到新车道的中心
        if event.key == pygame.K_RIGHT and current_lane < 2:
            current_lane += 1                       # 向右切换车道
            player_x = LANES[current_lane]
```

**图解：**

```
   车道0 (左)      车道1 (中)      车道2 (右)
   x=100           x=300           x=500
      ↓              ↓              ↓
   ┌──────┐      ┌──────┐      ┌──────┐
   │  🚗  │      │  🚗  │      │  🚗  │
   ├──────┤      ├──────┤      ├──────┤
   │      │      │      │      │      │
   │  车  │      │  车  │      │  车  │
   │  道  │  ←→  │  道  │  ←→  │  道  │
   │      │ 切换 │      │ 切换 │      │
   └──────┘      └──────┘      └──────┘
```

**边界保护：**
- 在车道 0（最左）时，不能再按左键（`current_lane > 0` 条件阻止）
- 在车道 2（最右）时，不能再按右键（`current_lane < 2` 条件阻止）

**互动提问：**
> "如果去掉 `current_lane > 0` 这个条件，在车道 0 时按住左键会怎样？"
> 答：`current_lane` 会变成 -1，访问 `LANES[-1]` 会拿到列表最后一个元素（右车道），导致玩家"从左边穿到右边"——这违反了游戏规则！

### 3.3 讲解（二）：障碍物、难度递增与碰撞检测（15分钟）

#### 3.3.1 障碍物管理机制

**核心原理：** 用一个列表 `obstacles` 管理所有"活着的"障碍车。每隔一段时间（如每 60 帧），在屏幕上方随机一条车道生成一辆新车。每帧让所有障碍车向下移动。当障碍车完全移出屏幕底部时，从列表中移除——释放内存，避免列表无限膨胀。

**完整流程：**

```
1. 创建障碍车 → 随机选择车道，y = -车高（在屏幕上方，玩家看不到）
     ↓
2. 加入 obstacles 列表 → "这辆车正式进入游戏"
     ↓
3. 每帧更新 → 障碍车 y 坐标 += 当前速度
     ↓
4. 判断是否出界 → y > 屏幕高度？
     ├── 是 → 5. 从 obstacles 列表移除（销毁）
     └── 否 → 回到 3，继续移动
```

**代码实现：**

```python
# --- 障碍物系统 ---
obstacles = []               # 障碍车列表
obstacle_width = 50
obstacle_height = 90
obstacle_spawn_timer = 0     # 生成计时器（帧数）
SPAWN_INTERVAL = 60          # 每 60 帧（约 1 秒）生成一辆
obstacle_speed = SCROLL_SPEED  # 障碍物初始速度和道路滚动速度一致

# 在主循环中：
# 1. 计时生成障碍车
obstacle_spawn_timer += 1
if obstacle_spawn_timer >= SPAWN_INTERVAL:
    obstacle_spawn_timer = 0
    # 随机选择一条车道
    lane_idx = random.randint(0, 2)
    # 在车道中心、屏幕上方生成
    obs_x = LANES[lane_idx] - obstacle_width // 2
    obs_y = -obstacle_height
    # 创建 Rect 对象并加入列表
    obstacles.append(pygame.Rect(obs_x, obs_y, obstacle_width, obstacle_height))

# 2. 更新障碍车位置 + 移除出界车辆
for obs in obstacles:
    obs.y += obstacle_speed  # 向下移动

# 安全删除：筛选保留仍在屏幕内的障碍车
obstacles = [obs for obs in obstacles if obs.y < HEIGHT]

# 3. 绘制障碍车（红色，用简单矩形表示）
for obs in obstacles:
    pygame.draw.rect(screen, (220, 50, 50), obs)  # 红色车身
    # 画"车窗"让它看起来更像车
    pygame.draw.rect(screen, (150, 200, 255), (obs.x + 5, obs.y + 10, 15, 20))
    pygame.draw.rect(screen, (150, 200, 255), (obs.x + 30, obs.y + 10, 15, 20))
```

**安全删除的重要性：**

> 边遍历边删除列表元素，会导致"漏删"或"索引越界"——这是 Python 编程中的经典陷阱！

```python
# ❌ 错误做法：边遍历边删除
for obs in obstacles:
    if obs.y > HEIGHT:
        obstacles.remove(obs)  # 危险！会打乱遍历的索引

# ✅ 正确做法 1：列表推导式（推荐，简洁清晰）
obstacles = [obs for obs in obstacles if obs.y < HEIGHT]

# ✅ 正确做法 2：标记后删除（原理更直观）
to_remove = []
for obs in obstacles:
    if obs.y > HEIGHT:
        to_remove.append(obs)
for obs in to_remove:
    obstacles.remove(obs)
```

**为什么不能边遍历边删除？**
> 想象你正在数一队人，数到第 3 个人时让他"离开队伍"，后面的人会往前补位——原本的第 4 个人变成了第 3 个，但你的手指已经指到了"下一个"（原本第 4 个的位置），于是你跳过了原本第 4 个人！

#### 3.3.2 难度自动递增

**核心原理：** 随着游戏时间增加，障碍物移动速度越来越快，障碍物出现的间隔越来越短。用变量控制速度，设定加速规则。

**加速规则设计：**

| 控制项 | 初始值 | 变化规则 | 含义 |
|--------|--------|----------|------|
| 滚动速度 | 5 | 每 10 秒 +1，上限 15 | 道路滚动越来越快 |
| 障碍物速度 | 5 | 每 10 秒 +1，上限 15 | 障碍车下落越来越快 |
| 生成间隔（帧） | 60 | 每 10 秒 -5，下限 25 | 障碍车出现越来越频繁 |

**代码实现：**

```python
# --- 难度递增系统 ---
SCROLL_SPEED = 5            # 道路滚动速度（像素/帧）
obstacle_speed = 5          # 障碍物下落速度
SPAWN_INTERVAL = 60         # 障碍物生成间隔（帧）
DIFFICULTY_TIMER = 0        # 难度递增计时器（帧）
DIFFICULTY_INTERVAL = 600   # 每 600 帧（约 10 秒）增加一次难度

# --- 速度上限 ---
MAX_SPEED = 15              # 最大速度
MIN_SPAWN_INTERVAL = 25     # 最短生成间隔

# 在主循环中：
DIFFICULTY_TIMER += 1
if DIFFICULTY_TIMER >= DIFFICULTY_INTERVAL:
    DIFFICULTY_TIMER = 0
    # 加速：但不能超过上限
    if SCROLL_SPEED < MAX_SPEED:
        SCROLL_SPEED += 1
    if obstacle_speed < MAX_SPEED:
        obstacle_speed += 1
    if SPAWN_INTERVAL > MIN_SPAWN_INTERVAL:
        SPAWN_INTERVAL -= 5
```

**给学生的比喻：**
> 难度递增就像跑步机的加速按钮——刚开始走得很慢，每过一会儿教练就帮你把速度调快一格。你的反应必须越来越快，游戏的紧张感也越来越强。

**扩展思路（给学有余力的同学）：**

除了加速，还可以用以下方式增加难度：
- 同时出现两辆障碍车（增加生成数量）
- 引入"移动的障碍车"（在一条车道内左右摇摆）
- 加入金币收集系统（分心——既要躲障碍，又要吃金币）

#### 3.3.3 碰撞检测

**核心原理：** Pygame 提供了 `pygame.Rect` 对象，它有一个 `colliderect` 方法，可以判断两个矩形是否重叠。

```python
# 玩家 Rect
player_rect = pygame.Rect(player_x, player_y, player_width, player_height)

# 遍历所有障碍车，检查是否和玩家碰撞
for obs in obstacles:
    if player_rect.colliderect(obs):  # 两个矩形重叠了！
        game_over = True              # 游戏结束
        break                         # 不用继续检查了
```

**碰撞检测的原理（通俗版）：**

> 两个矩形碰撞，意味着它们在 x 方向有重叠，同时在 y 方向也有重叠。就像两个人走在十字路口——两人都没有让路，结果就撞在一起。

**图解碰撞 vs 不碰撞：**

```
✅ 碰撞（重叠）：            ❌ 不碰撞（错开了）：
┌──────┐                    ┌──────┐
│ 玩家 │                    │ 玩家 │
│  🚗  │                    │  🚗  │
│      ├──────┐             └──────┘
└──────┤ 障碍 │                    ┌──────┐
       │  🚙  │                    │ 障碍 │
       │      │                    │  🚙  │
       └──────┘                    └──────┘
```

**`colliderect` 的本质判断：**

Pygame 内部实际在检查四个条件：
1. 玩家左边 < 障碍物右边
2. 玩家右边 > 障碍物左边
3. 玩家上边 < 障碍物下边
4. 玩家下边 > 障碍物上边

四个条件同时满足，就是碰撞了。

**进阶：碰撞"容错"**

为了让游戏体验更好（不死那么快），可以给碰撞检测加一点"容错空间"：

```python
# 实际碰撞区域比视觉略小（玩家左右各缩 10 像素）
# 这样"擦边而过"不算碰撞，更符合玩家直觉
player_collision_rect = pygame.Rect(
    player_rect.x + 8,     # 左边缩进 8 像素
    player_rect.y + 5,     # 上边缩进 5 像素
    player_rect.width - 16,  # 宽度缩 16 像素
    player_rect.height - 10  # 高度缩 10 像素
)

for obs in obstacles:
    if player_collision_rect.colliderect(obs):
        game_over = True
```

这种技巧在专业游戏开发中非常常见，称为 **"Hitbox 缩小"**（缩小碰撞判定框）。

## 四、完整代码示例

以下是一个完整的"极速躲避"跑酷游戏代码，包含了以上所有知识点。代码带有详细的中文注释，学生可以直接运行。

```python
"""
============================================================
极速躲避 —— Pygame 跑酷躲避游戏
============================================================
玩法：方向键 ← → 在三车道间切换，躲避迎面而来的障碍车。
      游戏随时间加速，越到后面越难！
============================================================
"""

import pygame
import sys
import random

# ==================== 初始化 ====================
pygame.init()

# --- 屏幕设置 ---
WIDTH, HEIGHT = 600, 700          # 窗口宽高
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("极速躲避 🚗💨")
clock = pygame.time.Clock()
FPS = 60                           # 帧率

# --- 颜色常量 ---
BLACK       = (10, 10, 10)         # 天空背景（不是纯黑，带点蓝）
WHITE       = (255, 255, 255)      # 白色（车道线）
GRAY        = (80, 80, 80)         # 路面灰色
GREEN       = (50, 200, 50)        # 路肩绿色
RED         = (230, 50, 50)        # 障碍车红色
BLUE        = (50, 100, 230)       # 玩家车蓝色
YELLOW      = (255, 220, 50)       # 车灯黄色
LIGHT_BLUE  = (150, 200, 255)      # 车窗浅蓝

# ==================== 车道系统 ====================
LANES = [100, 300, 500]            # 三条车道的 x 中心坐标
current_lane = 1                   # 当前车道索引（0=左, 1=中, 2=右）

# --- 玩家车辆 ---
player_width, player_height = 50, 90
player_x = LANES[current_lane] - player_width // 2
player_y = HEIGHT - player_height - 50  # 在屏幕下方 1/3 处

# --- 车道线（滚动虚线） ---
# 用列表存储每一小段车道虚线：每个元素是 [x, y]
lane_lines = []
# 初始化车道线：两条分界线，每 60 像素画一段虚线
for x_pos in [200, 400]:  # 两条分界线
    for y_pos in range(-60, HEIGHT + 60, 80):  # 从屏幕上方开始
        lane_lines.append([x_pos, y_pos])

# --- 滚动速度 ---
SCROLL_SPEED = 5                   # 道路初始滚动速度（像素/帧）

# ==================== 障碍物系统 ====================
obstacles = []                     # 障碍车列表（存储 pygame.Rect 对象）
obstacle_width, obstacle_height = 50, 90
obstacle_spawn_timer = 0           # 障碍物生成计时器（帧）
SPAWN_INTERVAL = 50                # 每 50 帧生成一辆（约 0.83 秒）
obstacle_speed = SCROLL_SPEED      # 障碍物下落速度，初始和道路速度一致

# ==================== 难度递增系统 ====================
DIFFICULTY_TIMER = 0               # 难度递增计时器（帧）
DIFFICULTY_INTERVAL = 600          # 每 600 帧（约 10 秒）加速一次
MAX_SPEED = 15                     # 最高速度上限
MIN_SPAWN_INTERVAL = 20            # 最短生成间隔

# ==================== 游戏状态 ====================
game_over = False                  # 游戏是否结束
score = 0                          # 得分
font = pygame.font.Font(None, 36)  # 默认字体，大小 36
big_font = pygame.font.Font(None, 60)

# ==================== 游戏主循环 ====================
running = True
while running:
    # ── 事件处理 ──
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        # 键盘按下事件（只响应一次，不是持续按住）
        if event.type == pygame.KEYDOWN:
            if not game_over:
                # 左键切换车道
                if event.key == pygame.K_LEFT and current_lane > 0:
                    current_lane -= 1
                    player_x = LANES[current_lane] - player_width // 2
                # 右键切换车道
                if event.key == pygame.K_RIGHT and current_lane < len(LANES) - 1:
                    current_lane += 1
                    player_x = LANES[current_lane] - player_width // 2
            else:
                # 游戏结束后，按空格键重新开始
                if event.key == pygame.K_SPACE:
                    # 重置所有状态
                    game_over = False
                    score = 0
                    current_lane = 1
                    player_x = LANES[current_lane] - player_width // 2
                    obstacles.clear()
                    SCROLL_SPEED = 5
                    obstacle_speed = 5
                    SPAWN_INTERVAL = 50
                    DIFFICULTY_TIMER = 0
                    obstacle_spawn_timer = 0
                    # 重置车道线位置
                    lane_lines.clear()
                    for x_pos in [200, 400]:
                        for y_pos in range(-60, HEIGHT + 60, 80):
                            lane_lines.append([x_pos, y_pos])

    # ── 更新逻辑（只在游戏未结束时执行） ──
    if not game_over:

        # --- 1. 更新车道线位置（滚动背景） ---
        for line in lane_lines:
            line[1] += SCROLL_SPEED               # 每帧向下移动
            if line[1] > HEIGHT + 10:             # 完全移出屏幕底部
                line[1] = -10                     # 回到屏幕顶部，准备下一个循环

        # --- 2. 生成新的障碍车 ---
        obstacle_spawn_timer += 1
        if obstacle_spawn_timer >= SPAWN_INTERVAL:
            obstacle_spawn_timer = 0
            # 随机选择一条车道
            lane_idx = random.randint(0, len(LANES) - 1)
            obs_x = LANES[lane_idx] - obstacle_width // 2
            obs_y = -obstacle_height               # 从屏幕正上方出现
            obstacles.append(
                pygame.Rect(obs_x, obs_y, obstacle_width, obstacle_height)
            )

        # --- 3. 更新障碍车位置 ---
        for obs in obstacles:
            obs.y += obstacle_speed                # 向下移动

        # --- 4. 移除飞出屏幕的障碍车（列表推导式，安全删除） ---
        obstacles = [obs for obs in obstacles if obs.y < HEIGHT]

        # --- 5. 碰撞检测（需要缩小玩家的碰撞判定框，更公平） ---
        # 缩小碰撞框：左右各缩 10px，上下各缩 5px
        player_collision = pygame.Rect(
            player_x + 10, player_y + 5,
            player_width - 20, player_height - 10
        )
        for obs in obstacles:
            if player_collision.colliderect(obs):
                game_over = True                    # 碰撞！游戏结束
                break

        # --- 6. 得分递增（存活时间越长，分数越高） ---
        score += 1

        # --- 7. 难度递增 ---
        DIFFICULTY_TIMER += 1
        if DIFFICULTY_TIMER >= DIFFICULTY_INTERVAL:
            DIFFICULTY_TIMER = 0
            if SCROLL_SPEED < MAX_SPEED:
                SCROLL_SPEED += 1                   # 道路加速
            if obstacle_speed < MAX_SPEED:
                obstacle_speed += 1                 # 障碍物加速
            if SPAWN_INTERVAL > MIN_SPAWN_INTERVAL:
                SPAWN_INTERVAL -= 3                 # 障碍物更频繁出现

    # ── 绘制逻辑 ──
    screen.fill(BLACK)

    # --- 1. 绘制公路背景 ---
    # 公路灰色路面（三条车道宽的区域）
    road_left = 40
    road_right = 560
    pygame.draw.rect(screen, GRAY, (road_left, 0, road_right - road_left, HEIGHT))
    # 路沿（左右绿色边线）
    pygame.draw.rect(screen, GREEN, (road_left - 5, 0, 10, HEIGHT))
    pygame.draw.rect(screen, GREEN, (road_right - 5, 0, 10, HEIGHT))

    # --- 2. 绘制车道虚线 ---
    for line in lane_lines:
        # 每段虚线画一条白色短横线
        pygame.draw.rect(screen, WHITE, (line[0] - 2, line[1], 4, 40))

    # --- 3. 绘制障碍车 ---
    for obs in obstacles:
        # 车身（红色矩形）
        pygame.draw.rect(screen, RED, obs)
        # 车窗（两个浅蓝色小矩形）
        pygame.draw.rect(screen, LIGHT_BLUE, (obs.x + 6, obs.y + 12, 15, 20))
        pygame.draw.rect(screen, LIGHT_BLUE, (obs.x + 29, obs.y + 12, 15, 20))
        # 车灯（两个小黄点）
        pygame.draw.circle(screen, YELLOW, (obs.x + 8, obs.y + obs.height - 8), 4)
        pygame.draw.circle(screen, YELLOW, (obs.x + obs.width - 8, obs.y + obs.height - 8), 4)

    # --- 4. 绘制玩家车辆 ---
    player_rect = pygame.Rect(player_x, player_y, player_width, player_height)
    # 车身（蓝色矩形）
    pygame.draw.rect(screen, BLUE, player_rect)
    # 车窗（浅蓝色）
    pygame.draw.rect(screen, LIGHT_BLUE, (player_x + 8, player_y + 8, 14, 18))
    pygame.draw.rect(screen, LIGHT_BLUE, (player_x + 28, player_y + 8, 14, 18))
    # 车灯（白色，车头灯）
    pygame.draw.circle(screen, WHITE, (player_x + 6, player_y - 3), 5)
    pygame.draw.circle(screen, WHITE, (player_x + player_width - 6, player_y - 3), 5)

    # --- 5. 绘制 UI（分数和速度指示） ---
    score_text = font.render(f"分数: {score}", True, WHITE)
    screen.blit(score_text, (20, 20))
    speed_text = font.render(f"速度: {SCROLL_SPEED}", True, YELLOW)
    screen.blit(speed_text, (20, 55))

    # --- 6. 游戏结束画面 ---
    if game_over:
        # 半透明黑色遮罩（用带透明度的 Surface）
        overlay = pygame.Surface((WIDTH, HEIGHT))
        overlay.set_alpha(180)                     # 透明度 180/255
        overlay.fill((0, 0, 0))
        screen.blit(overlay, (0, 0))

        # "游戏结束"文字
        game_over_text = big_font.render("游戏结束", True, RED)
        text_rect = game_over_text.get_rect(center=(WIDTH // 2, HEIGHT // 2 - 60))
        screen.blit(game_over_text, text_rect)

        # 最终分数
        final_score_text = font.render(f"最终分数: {score}", True, WHITE)
        score_rect = final_score_text.get_rect(center=(WIDTH // 2, HEIGHT // 2))
        screen.blit(final_score_text, score_rect)

        # 重新开始提示
        restart_text = font.render("按 空格键 重新开始", True, YELLOW)
        restart_rect = restart_text.get_rect(center=(WIDTH // 2, HEIGHT // 2 + 60))
        screen.blit(restart_text, restart_rect)

    # ── 刷新画面 ──
    pygame.display.flip()
    clock.tick(FPS)

# ==================== 退出程序 ====================
pygame.quit()
sys.exit()
```

## 七、常见错误排查

| 问题现象 | 可能原因 | 解决方法 |
|----------|---------|---------|
| 运行后窗口一闪就消失 | 没有 `while running` 游戏循环 | 检查代码中是否包含了主循环和 `pygame.quit()` |
| 障碍物不出现 | `obstacle_spawn_timer` 被错误重置，或 `SPAWN_INTERVAL` 值太大 | 打印 `obstacle_spawn_timer` 的值检查计数器是否正常累加 |
| 碰撞后游戏不结束 | `colliderect` 拼写错误，或 `player_collision` 没有正确创建 | 打印 `player_collision` 和 `obs` 的值，确认 Rect 对象正确 |
| 玩家能穿出左右边界 | 车道切换时忘记更新 `player_x` | 检查 `KEYDOWN` 事件中是否正确设置了 `player_x = LANES[current_lane] - ...` |
| 障碍物越来越多，游戏越来越卡 | 没删除出界障碍物 → 内存不断增长 | 检查 `obstacles = [obs for obs in obstacles if obs.y < HEIGHT]` 这行是否正确 |
| 车道线不滚动 | `lane_lines` 列表为空，或更新 `line[1]` 的代码没有被执行 | 在更新循环前打印 `len(lane_lines)` 确认列表非空 |
| 重复按键导致连续换道 | 用了 `pygame.key.get_pressed()` 而不是 `event.type == pygame.KEYDOWN` | 车道切换应该用 `KEYDOWN` 事件（按一次响应一次），不要用持续检测 |
| 游戏结束画面看不到 | `game_over` 覆盖层的透明度太大或绘制顺序不对 | 游戏结束画面应该在其他所有元素之后绘制，确保在最上层 |
| `ModuleNotFoundError: No module named 'pygame'` | Pygame 未安装 | 终端执行 `pip install pygame` |
| 车辆画出屏幕外 | `LANES` 列表中的 x 坐标值超出窗口范围 | `LANES[0]` 应大于车宽/2，`LANES[-1]` 应小于 WIDTH - 车宽/2 |

## 八、教学建议

### 讲解技巧

1. **用生活类比降低门槛：**
   - 滚动背景 = 跑步机上的传送带，永远滚不完
   - 障碍物列表 = 一个"快递箱子"，来了新的放进去、送走的拿出去
   - 碰撞检测 = 两个人走十字路口，都没让路就撞了
   - 车道切换 = 超市排队结账，看到旁边队伍短就跳过去

2. **分步骤教学，每一步都运行验证：**
   - 第一步：只运行道路滚动 + 玩家绘制（让学生看到路在动）
   - 第二步：加入玩家左右移动（让学生操控车辆）
   - 第三步：加入障碍物生成和移动
   - 第四步：加入碰撞检测
   - 第五步：加入难度递增和游戏结束
   - 每完成一步，让学生运行看效果，获得成就感

3. **让学生"先玩后学"：**
   - 课前先让学生玩 2 分钟完整游戏
   - 玩完之后再问"你觉得这个游戏有哪些关键部分需要实现？"
   - 学生自己说出来的东西，学习效果远好于老师直接灌输

4. **故意演示错误代码：**
   - 演示"边遍历边删除障碍物"会怎样（漏删导致列表膨胀）
   - 演示"不用 KEYDOWN 而用 get_pressed"做车道切换（按一下跳好几条车道）
   - 让学生看到 bug，再讲如何修复——印象更深刻

### 课堂节奏把控

- **导入环节**：控制在 5 分钟以内，游戏展示要快速、抓眼球
- **讲解（一）**：滚动背景和车道切换相对简单，10 分钟足够，可以留出时间让学生当场试
- **讲解（二）**：障碍物管理和碰撞检测是重点难点，15 分钟要讲透，特别是"安全删除"的原理要画图辅助
- **练习环节**：基础练习 3 个任务必做，挑战练习留给进度快的学生。教师巡堂时重点关注"安全删除"和"碰撞检测"这两块
- **总结环节**：用表格快速回顾 7 个知识点，点明下节课内容

### 常见教学误区

- 不要一次性把所有代码展示出来——学生会被"代码海"吓到
- 不要跳过"为什么不能边遍历边删除"这个经典陷阱——这是培养学生编程思维的好机会
- 不要在碰撞检测上过度深入（不展开 AABB、SAT 等高级算法）——对于 10-15 岁的学生，`colliderect()` 就够用了
- 难度递增部分让学生理解"变量控制速度"即可，不要过度追求复杂的加速曲线
