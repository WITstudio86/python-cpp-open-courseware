### 二、核心讲解（25分钟）

#### 步骤1：用方向键控制飞机移动（8分钟）

**核心原理**：监听键盘事件，修改飞机的 x、y 坐标。

```python
import pygame
import sys

pygame.init()
WIDTH, HEIGHT = 800, 600
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("战机起飞")
clock = pygame.time.Clock()

# --- 玩家飞机 ---
player_width, player_height = 50, 60
# 飞机初始位置：屏幕底部中间
player_x = WIDTH // 2 - player_width // 2
player_y = HEIGHT - player_height - 30
player_speed = 5  # 飞机移动速度（像素/帧）

running = True
while running:
    # --- 事件处理 ---
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # --- 按键检测：持续按下方向键时移动 ---
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT] and player_x > 0:
        player_x -= player_speed          # 向左移动
    if keys[pygame.K_RIGHT] and player_x < WIDTH - player_width:
        player_x += player_speed          # 向右移动
    if keys[pygame.K_UP] and player_y > 0:
        player_y -= player_speed          # 向上移动
    if keys[pygame.K_DOWN] and player_y < HEIGHT - player_height:
        player_y += player_speed          # 向下移动

    # --- 绘制 ---
    screen.fill((10, 10, 30))  # 深蓝色背景模拟夜空

    # 绘制玩家飞机（蓝色矩形 + 机翼三角形）
    player_rect = pygame.Rect(player_x, player_y, player_width, player_height)
    pygame.draw.rect(screen, (50, 150, 255), player_rect)  # 机身
    # 机翼
    pygame.draw.polygon(screen, (80, 180, 255), [
        (player_x - 15, player_y + player_height // 2),
        (player_x + player_width + 15, player_y + player_height // 2),
        (player_x + player_width // 2, player_y)
    ])

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
sys.exit()
```

**⭐ 重点讲解：**
- `pygame.key.get_pressed()` 返回所有按键状态的元组，适合持续按住的情况。
- 边界判断很重要：`player_x > 0` 防止飞机飞出左边界。
- `clock.tick(60)` 控制帧率为 60 FPS，保证移动速度稳定。

**互动提问：**
> "如果去掉边界判断会发生什么？谁来试试？"
> 让学生思考并回答：飞机会飞出屏幕，再也看不到。

#### 步骤2：空格键发射子弹 + 列表管理（10分钟）

**核心原理**：用列表 `bullets` 存储所有飞行中的子弹，每按一次空格就创建一个新子弹（字典或列表），每帧遍历列表移动子弹，飞出屏幕的子弹从列表中移除。

```python
# --- 子弹系统 ---
bullets = []           # 子弹列表，存放所有飞行中的子弹
bullet_width = 6
bullet_height = 15
bullet_speed = 8       # 子弹飞行速度
bullet_cooldown = 0    # 冷却计时器（帧数）
COOLDOWN_MAX = 15      # 冷却时间（帧），约 0.25 秒

# 在事件循环中添加：
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False
    # 空格键发射子弹（按下事件，不是持续按住）
    if event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE and bullet_cooldown == 0:
            # 创建一颗新子弹，从飞机顶部中央发射
            new_bullet = {
                "x": player_x + player_width // 2 - bullet_width // 2,
                "y": player_y  # 从飞机顶部发出
            }
            bullets.append(new_bullet)  # 加入子弹列表
            bullet_cooldown = COOLDOWN_MAX  # 开始冷却

# 冷却计时器倒计时（在主循环中、每帧执行一次）
if bullet_cooldown > 0:
    bullet_cooldown -= 1

# --- 更新子弹位置 + 移除飞出屏幕的子弹 ---
# 注意：遍历列表时如果要删除元素，需要遍历副本或用反向索引
bullets_to_remove = []  # 待删除的子弹列表
for bullet in bullets:
    bullet["y"] -= bullet_speed  # 子弹向上飞
    # 如果子弹飞出屏幕顶部，标记为待删除
    if bullet["y"] + bullet_height < 0:
        bullets_to_remove.append(bullet)

# 移除飞出屏幕的子弹
for bullet in bullets_to_remove:
    bullets.remove(bullet)

# --- 绘制子弹 ---
for bullet in bullets:
    bx = bullet["x"]
    by = bullet["y"]
    pygame.draw.rect(screen, (255, 255, 0), (bx, by, bullet_width, bullet_height))
```

**⭐ 重点讲解：**
- **列表管理**：`bullets = []` 是一个列表，每发子弹是一个字典，包含 x 和 y 坐标。
- **冷却时间**：`bullet_cooldown` 防止按一次空格键连续发出多颗子弹。设置 15 帧（0.25秒）的间隔。
- **安全删除**：遍历列表时不能直接删除元素（会导致索引混乱），要用"标记后删除"的方法。
  - 创建一个 `bullets_to_remove` 列表收集要删除的子弹
  - 循环结束后统一删除

**常见错误演示：**
```python
# ❌ 错误的做法（边遍历边删除）
for bullet in bullets:
    if bullet["y"] < 0:
        bullets.remove(bullet)  # 这会导致漏删！

# ✅ 正确的做法
bullets = [b for b in bullets if b["y"] + bullet_height >= 0]
# 或者用"标记后删除"的方法
```

**互动提问：**
> "为什么要有冷却时间？去掉冷却时间试试看会怎样？"
> 答：按住空格键时每帧都会发射子弹，会瞬间发出几十颗子弹，体验很差。

#### 步骤3：简单敌机 + 碰撞检测基础（7分钟）

**核心原理**：提前引入一个简单的敌机（固定位置或简单移动），演示碰撞检测的基本方法。

```python
# --- 敌机（简单版，为第16节做准备） ---
enemy_width, enemy_height = 40, 40
enemy_x = 300
enemy_y = 100
enemy_speed_y = 2

# --- 得分 ---
score = 0

# 更新敌机（简单的上下弹跳）
enemy_y += enemy_speed_y
if enemy_y > HEIGHT - enemy_height or enemy_y < 0:
    enemy_speed_y = -enemy_speed_y

# --- 碰撞检测：子弹 vs 敌机 ---
enemy_rect = pygame.Rect(enemy_x, enemy_y, enemy_width, enemy_height)
bullets_to_remove = []
for bullet in bullets:
    bullet_rect = pygame.Rect(bullet["x"], bullet["y"], bullet_width, bullet_height)
    if bullet_rect.colliderect(enemy_rect):
        bullets_to_remove.append(bullet)
        score += 10
        # 重置敌机位置
        enemy_x = 300
        enemy_y = 50

# 移除击中敌机的子弹
for bullet in bullets_to_remove:
    bullets.remove(bullet)

# --- 绘制敌机 ---
enemy_rect = pygame.Rect(enemy_x, enemy_y, enemy_width, enemy_height)
pygame.draw.rect(screen, (255, 50, 50), enemy_rect)  # 红色敌机

# --- 显示得分 ---
font = pygame.font.SysFont("simhei", 28)
score_text = font.render(f"得分: {score}", True, (255, 255, 255))
screen.blit(score_text, (10, 10))
```

**⭐ 重点讲解：**
- `pygame.Rect` 创建一个矩形对象，有 x、y、width、height 属性。
- `rect1.colliderect(rect2)` 检测两个矩形是否重叠，返回 `True`/`False`。
- 碰撞检测的基本流程：获取两个物体的 Rect → 调用 `colliderect()` → 如果碰撞则执行相应逻辑。

**互动提问：**
> "碰撞检测的本质是什么？两个矩形有重叠区域就是碰撞吗？"
> 答：是的，`colliderect` 判断的是两个矩形的重叠。

## 💡 常见问题与解决

| 问题 | 原因 | 解决 |
|------|------|------|
| 飞机一按方向键就飞出屏幕 | 没有加边界判断 | 用 `if player_x > 0` 等条件限制移动范围 |
| 按住空格键子弹像机关枪一样 | 没有冷却时间 | 设置 `bullet_cooldown` 倒计时 |
| 子弹飞出屏幕后还在消耗内存 | 没有删除飞出屏幕的子弹 | 判断 `bullet["y"] < 0` 并从列表移除 |
| 遍历 bullets 时删除元素导致漏删或报错 | Python 列表遍历规则 | 使用"标记后删除"或列表推导式 |
| 碰撞检测不灵敏 | Rect 位置或尺寸不正确 | 检查 Rect 的创建参数是否和绘制位置一致 |
