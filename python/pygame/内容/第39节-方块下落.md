## 二、7种标准方块的二维列表表示（8分钟）

### 2.1 形象比喻：积木图纸

**教师话术**："想象你有一堆积木，每一块积木由若干个小正方体组成。我们怎么用Python来表示这些积木的形状呢？最自然的想法就是用一张'图纸'——二维列表！列表中的1表示'这里有一个小方块'，0表示'这里是空的'。"

### 2.2 7种方块的定义

俄罗斯方块共有7种标准方块，每种用二维列表表示。**注意：下面的定义保证了方块生成时'站立'的朝向。**

```python
# 7种标准方块定义
SHAPES = {
    # I型：长长的一根棍子，4个格子排成一行
    'I': [[1, 1, 1, 1]],

    # O型：正方形，稳稳当当
    'O': [[1, 1],
          [1, 1]],

    # T型：像个T字
    'T': [[0, 1, 0],
          [1, 1, 1]],

    # S型：弯弯扭扭像条蛇
    'S': [[0, 1, 1],
          [1, 1, 0]],

    # Z型：S型的镜像兄弟
    'Z': [[1, 1, 0],
          [0, 1, 1]],

    # J型：像反写的字母J，右下角有个小尾巴
    'J': [[1, 0, 0],
          [1, 1, 1]],

    # L型：J型的镜像，左下角有小尾巴
    'L': [[0, 0, 1],
          [1, 1, 1]],
}
```

### 2.3 图形化理解

**教师话术**："我们用纸笔画一个3×3的格子来理解。比如T型方块，它的二维列表是：

```
[0, 1, 0]
[1, 1, 1]
```

我们在纸上画出来就是：第一行只有中间有方块，第二行三个格子全有方块。像不像一个字母T？"

**教学小技巧**：让每位学生在草稿纸上画出这7种方块的"像素图"，加深对二维列表和图形之间映射关系的理解。用1代表涂黑的格子，0代表空白格子。

### 2.4 为什么用二维列表

- **直观**：列表的行对应方块的高度，列对应宽度
- **易于操作**：旋转、移动、碰撞检测都可以通过数学运算实现
- **Python原生**：不需要额外学习复杂的数据结构

## 三、旋转算法详解（8分钟）

### 3.1 旋转的"魔法公式"

**教师话术**："方块旋转是俄罗斯方块的精髓。数学上，把一个图形顺时针旋转90度，只需要两步操作：第一步——行列互换（专业术语叫'转置'）；第二步——把每一行翻转过来。我们来一步步看！"

### 3.2 旋转算法分解

以T型方块为例，初始形状：

```
原始（3列×2行）：
[0, 1, 0]
[1, 1, 1]
```

**第一步：转置（行列互换）**

把原来的"第0行第0列"变成"第0列第0行"（如同一面镜子沿对角线翻转）：

```
转置后（2列×3行）：
[0, 1]
[1, 1]
[0, 1]
```

**第二步：水平翻转每一行**

把每一行的元素顺序颠倒（第一个变最后一个）：

```
顺时针旋转90°后（2列×3行）：
[1, 0]
[1, 1]
[1, 0]
```

**验证**：现在它看起来像一个向左的T字，正好是原T字顺时针转了90度！

### 3.3 为什么这个算法有效？

**教师话术**（用肢体语言辅助）："想象你面前有一个橡皮图章，上面刻着字母T。'转置'相当于你从左下角往右上角看这个图章，'翻转每一行'则是调整到正确的方向。两步合起来，就完成了顺时针90度的完美旋转！"

### 3.4 代码实现

```python
def rotate_shape(shape):
    """
    顺时针旋转方块90度
    算法：先转置（行列互换），再水平翻转每一行
    """
    # 第一步：转置（用zip函数实现行列互换）
    # zip(*shape) 将每一列的元素组合在一起
    transposed = list(zip(*shape))

    # 第二步：水平翻转（将每一行反转）
    rotated = [list(row)[::-1] for row in transposed]

    return rotated
```

**重难点提示**：
- `zip(*shape)` 中的星号 `*` 是"解包"操作，将二维列表的每一行作为独立参数传给zip。这是Python中一个高级但优雅的用法，教师可以简单解释为"把每一行拆开，重新按列组合"。
- `[::-1]` 是Python的切片反转语法，从末尾到开头取元素，步长为-1。
- 对于O型方块（2×2的全1），旋转后还是自己——这很合理，正方形转90度当然还是正方形！

## 四、碰撞检测逻辑（8分钟）

### 4.1 什么是"碰撞"？

**教师话术**："在俄罗斯方块中，'碰撞'不是撞车那种物理碰撞，而是判断方块能不能放在某个位置。如果新位置出了棋盘边界，或者和已经落下的方块重叠了，那就是'不合法'的位置，方块不能移动或旋转到那里。"

### 4.2 碰撞检测的两个条件

方块能否放在棋盘上的 (grid_x, grid_y) 位置，需要同时满足两个条件：

**条件一：边界检测**
- 方块的每一格都不能超出棋盘左边界（x < 0）
- 方块的每一格都不能超出棋盘右边界（x >= 10）
- 方块的每一格都不能超出棋盘下边界（y >= 20）
- 方块可以部分在棋盘上方（y < 0），这是允许的（待会落下）—— 但需要特殊处理

**条件二：重叠检测**
- 方块的每一格（值为1的位置）都不能和棋盘中已经存在的方块重叠
- 棋盘grid[y][x]中非0的值表示该位置已经有方块了

### 4.3 棋盘数据结构

```python
# 棋盘：10列×20行的二维列表
# grid[y][x] = 0         表示该位置为空
# grid[y][x] = (R,G,B)   表示该位置有方块，存储方块的颜色
COLS = 10  # 列数
ROWS = 20  # 行数
grid = [[0 for _ in range(COLS)] for _ in range(ROWS)]
```

**为什么是`grid[y][x]`而不是`grid[x][y]`？**
因为这样 `grid[y]` 就代表棋盘的"第y行"，和一行的方块定义自然对应，写代码时不会混淆。

### 4.4 碰撞检测代码实现

```python
def is_valid_position(shape, grid_x, grid_y):
    """
    检查方块shape在(grid_x, grid_y)位置是否合法
    返回True表示可以放置，False表示不行
    """
    for y, row in enumerate(shape):      # 遍历方块的每一行
        for x, cell in enumerate(row):   # 遍历每一行的每个格子
            if cell == 1:                # 只检查有方块的位置
                # 计算这个格子在棋盘上的实际坐标
                board_x = grid_x + x
                board_y = grid_y + y

                # 条件一：边界检测
                if board_x < 0 or board_x >= COLS:
                    return False  # 超出左右边界
                if board_y >= ROWS:
                    return False  # 超出下边界
                if board_y < 0:
                    continue      # 在棋盘上方，允许（还没落进来）

                # 条件二：重叠检测
                if grid[board_y][board_x] != 0:
                    return False  # 和已有方块重叠了

    return True  # 所有检查通过，位置合法
```

### 4.5 形象化图示

**教师话术**（在黑板上画图）："我们用坐标纸来理解。棋盘是一个10×20的格子纸，每个格子有自己的'门牌号'（坐标）。方块想搬到新位置，就得挨个检查自己的'成员'是不是都住进了合法的格子。有成员露在外面了？不行！有成员踩到别人的位置了？也不行！只有所有成员都安全入住了，才能批准这次搬家。"

## 五、方块移动控制（5分钟）

### 5.1 三种移动方式

| 操作 | 按键 | 行为 |
|------|------|------|
| 左移 | 方向键 ← | 方块整体向左移一格 |
| 右移 | 方向键 → | 方块整体向右移一格 |
| 旋转 | 方向键 ↑ | 方块顺时针旋转90度 |
| 加速下落 | 方向键 ↓ | 方块向下移一格（加快下落速度） |

**关键原则**：每次移动/旋转前，都必须先用冲突检测函数 `is_valid_position()` 检查目标位置是否合法。**先检查，再移动**！

```python
# 事件处理中的移动逻辑
if event.key == pygame.K_LEFT:
    if is_valid_position(current_shape, current_x - 1, current_y):
        current_x -= 1  # 左移一格

elif event.key == pygame.K_RIGHT:
    if is_valid_position(current_shape, current_x + 1, current_y):
        current_x += 1  # 右移一格

elif event.key == pygame.K_DOWN:
    if is_valid_position(current_shape, current_x, current_y + 1):
        current_y += 1  # 加速下落一格

elif event.key == pygame.K_UP:
    rotated = rotate_shape(current_shape)
    if is_valid_position(rotated, current_x, current_y):
        current_shape = rotated  # 应用旋转
```

### 5.2 自动下落机制

方块不是等着玩家按一下才落一下——它会自动、定时地往下掉。这用Pygame的时间函数实现：

```python
# 用pygame.time.get_ticks()获取游戏运行的时间（毫秒）
fall_interval = 800  # 每800毫秒（0.8秒）下落一格
last_fall_time = pygame.time.get_ticks()  # 记录上次下落的时间

# 在主循环中
current_time = pygame.time.get_ticks()
if current_time - last_fall_time > fall_interval:
    # 时间到了，尝试下落
    if is_valid_position(current_shape, current_x, current_y + 1):
        current_y += 1  # 还能往下，就下落一格
    else:
        # 不能下落了——锁定！
        lock_piece()
        new_piece()
    last_fall_time = current_time  # 重置计时器
```

**形象比喻**：`get_ticks()`就像一个不断走字的秒表。我们每隔800毫秒看一眼秒表——如果距离上次下落已经过了800毫秒，就让方块往下走一格。就像沙漏里的沙子，隔一段时间自动漏一点。

## 六、方块锁定机制（5分钟）

### 6.1 什么时候"锁定"？

当方块尝试自动下落，但 `is_valid_position()` 返回 `False` 时，说明方块已经"踩到地"或"骑在别人头上"了，不能再往下走了。这时就需要执行**锁定操作**。

### 6.2 锁定的本质

锁定 = 把当前方块的"图纸"写入棋盘的二维数组。

```python
def lock_piece():
    """
    将当前方块锁定到棋盘上
    其实就是把方块的每个小格子颜色写入grid数组
    """
    for y, row in enumerate(current_shape):
        for x, cell in enumerate(row):
            if cell == 1:
                board_x = current_x + x
                board_y = current_y + y
                # 只锁定在棋盘范围内的部分
                if 0 <= board_y < ROWS and 0 <= board_x < COLS:
                    grid[board_y][board_x] = current_color
```

### 6.3 锁定后生成新方块

```python
def new_piece():
    """在棋盘顶部中间位置生成一个新的随机方块"""
    global current_shape, current_color, current_x, current_y, current_shape_name

    current_shape_name = random.choice(list(SHAPES.keys()))
    current_shape = SHAPES[current_shape_name]
    current_color = COLORS[current_shape_name]

    # 让方块在棋盘顶部居中生成
    current_x = COLS // 2 - len(current_shape[0]) // 2
    current_y = 0
```

### 6.4 锁定后的连锁反应

锁定完成 → 生成新方块 → 新方块从顶部开始下落 → 循环往复。

这就形成了俄罗斯方块最核心的游戏循环：
**生成 → 控制 → 下落 → 锁定 → 生成 → ...**

```python
import pygame

SCREEN_WIDTH = 600

CELL_SIZE = 30

    'I': (0, 255, 255),    # 青色 - 长条
    'O': (255, 255, 0),    # 黄色 - 方块
    'T': (160, 32, 240),   # 紫色 - T块
    'S': (0, 255, 0),      # 绿色 - S块
    'Z': (255, 0, 0),      # 红色 - Z块
    'J': (0, 0, 255),      # 蓝色 - J块
    'L': (255, 165, 0),    # 橙色 - L块
}

# ===== 方块定义 =====
SHAPES = { ... }  # 前面已定义

# ===== 棋盘初始化 =====
grid = [[0 for _ in range(COLS)] for _ in range(ROWS)]

# ===== 当前方块状态 =====
current_shape = None
current_color = None
current_x = 0
current_y = 0

# ===== 主循环 =====
def main():
    pygame.init()
    screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))
    pygame.display.set_caption("方块下落 — 第39节")
    clock = pygame.time.Clock()

    new_piece()
    fall_interval = 800
    last_fall_time = pygame.time.get_ticks()

    running = True
    while running:
        # 事件处理
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
            elif event.type == pygame.KEYDOWN:
                handle_key(event.key)

        # 自动下落
        current_time = pygame.time.get_ticks()
        if current_time - last_fall_time > fall_interval:
            if is_valid_position(current_shape, current_x, current_y + 1):
                current_y += 1
            else:
                lock_piece()
                new_piece()
            last_fall_time = current_time

        # 绘制画面
        draw(screen)
        pygame.display.flip()
        clock.tick(60)

    pygame.quit()
    sys.exit()
```

### 7.2 绘制函数

```python
def draw(screen):
    """绘制棋盘、已有方块和当前方块"""
    screen.fill(BLACK)

    grid_offset_x = 40
    grid_offset_y = 50

    # 绘制棋盘背景
    pygame.draw.rect(screen, (30, 30, 30),
        (grid_offset_x, grid_offset_y,
         COLS * CELL_SIZE, ROWS * CELL_SIZE))

    # 绘制已锁定的方块
    for y in range(ROWS):
        for x in range(COLS):
            if grid[y][x] != 0:
                pygame.draw.rect(screen, grid[y][x],
                    (grid_offset_x + x * CELL_SIZE,
                     grid_offset_y + y * CELL_SIZE,
                     CELL_SIZE, CELL_SIZE))
                # 绘制格子的边框（让方块之间有间距感）
                pygame.draw.rect(screen, BLACK,
                    (grid_offset_x + x * CELL_SIZE,
                     grid_offset_y + y * CELL_SIZE,
                     CELL_SIZE, CELL_SIZE), 1)

    # 绘制当前下落的方块
    if current_shape:
        for y, row in enumerate(current_shape):
            for x, cell in enumerate(row):
                if cell:
                    pygame.draw.rect(screen, current_color,
                        (grid_offset_x + (current_x + x) * CELL_SIZE,
                         grid_offset_y + (current_y + y) * CELL_SIZE,
                         CELL_SIZE, CELL_SIZE))
                    pygame.draw.rect(screen, BLACK,
                        (grid_offset_x + (current_x + x) * CELL_SIZE,
                         grid_offset_y + (current_y + y) * CELL_SIZE,
                         CELL_SIZE, CELL_SIZE), 1)

    # 绘制网格线（在方块上面画线，让棋盘更清楚）
    for x in range(COLS + 1):
        pygame.draw.line(screen, GRAY,
            (grid_offset_x + x * CELL_SIZE, grid_offset_y),
            (grid_offset_x + x * CELL_SIZE,
             grid_offset_y + ROWS * CELL_SIZE))
    for y in range(ROWS + 1):
        pygame.draw.line(screen, GRAY,
            (grid_offset_x, grid_offset_y + y * CELL_SIZE),
            (grid_offset_x + COLS * CELL_SIZE,
             grid_offset_y + y * CELL_SIZE))

    # 绘制棋盘外边框
    pygame.draw.rect(screen, WHITE,
        (grid_offset_x, grid_offset_y,
         COLS * CELL_SIZE, ROWS * CELL_SIZE), 3)
```

| 碰撞检测的边界条件 | 特别强调y<0的处理（方块在棋盘上方，需要continue跳过重叠检测，但不能跳过后续检查） |

### 8.3 教学建议

1. **分步实现**：先做方块下落（最简单），再加左右移动，再加旋转，最后加锁定。每完成一步都运行测试。
2. **打印调试**：在碰撞检测函数中加 `print()` 语句，让学生看到每次检查的过程。
3. **可视化理解**：用粉笔/白板笔在格子黑板上画方块，直观展示旋转和碰撞。
4. **结对编程**：两人一组，一人写代码，一人"出题"（提出测试场景），互相检查。
5. **降低速度**：初始下落间隔可设为1000ms（1秒），给小同学更多反应时间。

## 九、常见问题与解答

**Q1：为什么O型方块旋转后还是自己？**
A：因为O是2×2的正方形，转90度当然还是正方形，这也说明我们的旋转算法是正确的。

**Q2：方块在棋盘上方（y<0）时，为什么碰撞检测要continue而不是return False？**
A：因为方块刚生成时可能在棋盘顶部上方（部分格子y坐标为负），这是正常的——它马上就会落下来。如果直接return False，方块就永远"生不出来"了。

**Q3：为什么按键加速下落不会触发锁定？**
A：按键移动只是"手动加速"，不触发锁定。只有自动下落（定时器触发）发现落不下去时，才执行锁定。这样设计是为了给玩家更好的操作体验。

**Q4：如何改变下落速度？**
A：修改 `fall_interval` 的值——数值越小，下落越快。800毫秒约等于"慢速"，400毫秒约等于"中速"，200毫秒约等于"快速"。
