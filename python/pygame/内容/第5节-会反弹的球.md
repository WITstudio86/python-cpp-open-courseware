### 二、核心讲解（25分钟）

#### 2.1 Rect 对象详解（8分钟）

**什么是 Rect？**
> 在Pygame中，屏幕上所有看得见的东西都可以用"矩形"来描述。即使是一个圆形的小球，它的位置和大小也是用一个矩形来管理的。这个矩形在Pygame中叫做 `Rect` 对象。

**Rect 的四个基本属性：**

```python
import pygame

# 创建一个 Rect：Rect(左边界x, 上边界y, 宽度, 高度)
ball_rect = pygame.Rect(400, 300, 30, 30)

# 四个核心属性
ball_rect.x      # 矩形左上角的 x 坐标（水平位置）
ball_rect.y      # 矩形左上角的 y 坐标（垂直位置）
ball_rect.width  # 矩形的宽度
ball_rect.height # 矩形的高度
```

**理解坐标系：**
```
(0,0) ────────────────────► x轴（向右增加）
  │
  │     (400, 300)
  │        ┌──────────┐
  │        │  小球     │  宽30
  │        │  (中心)   │
  │        └──────────┘  高30
  │
  ▼ y轴（向下增加）
```

> **要点**：x 增加是向右移动，y 增加是向下移动。这和数学课本上的坐标系不太一样——y轴是反过来的！

**Rect 的便捷属性：**
```python
ball_rect.centerx  # 矩形中心的 x 坐标（= x + width/2）
ball_rect.centery  # 矩形中心的 y 坐标（= y + height/2）
ball_rect.left     # 等价于 ball_rect.x
ball_rect.top      # 等价于 ball_rect.y
ball_rect.right    # 等价于 ball_rect.x + width
ball_rect.bottom   # 等价于 ball_rect.y + height
```

#### 2.2 让球动起来（5分钟）

**移动的原理：**
> 动画就是一幅幅静止画面快速切换形成的。在游戏循环中，每一帧我们改变小球的位置一点点，看起来就像球在动了。

```python
# 球的速度（每帧移动的像素数）
vx = 5   # 水平速度：正数向右，负数向左
vy = 5   # 垂直速度：正数向下，负数向上

# 游戏循环中每帧更新：
ball_rect.x += vx   # 把水平速度加到 x 坐标上
ball_rect.y += vy   # 把垂直速度加到 y 坐标上
```

#### 2.3 边界碰撞反弹（5分钟）

**反弹的核心逻辑：**
> 球碰到墙壁后，对应的速度方向要**取反**。碰到左右墙 → 水平速度取反；碰到上下墙 → 垂直速度取反。

```python
# 碰到左右边界（左墙或右墙）
if ball_rect.left <= 0 or ball_rect.right >= WIDTH:
    vx = -vx   # 水平方向反弹！正变负，负变正

# 碰到上下边界（上墙或下墙）
if ball_rect.top <= 0 or ball_rect.bottom >= HEIGHT:
    vy = -vy   # 垂直方向反弹！
```

> **形象理解**：`vx = -vx` 就像镜子反射——你往右走（vx=5），碰到墙后变成往左走（vx=-5）。如果把速度想象成"每步走多少"，反弹就是"换个方向走同样大的步数"。

#### 2.4 碰撞检测：colliderect()（3分钟）

```python
# 判断两个 Rect 是否碰撞（重叠）
if ball_rect.colliderect(paddle_rect):
    vy = -vy   # 球碰到挡板，垂直反弹
```

> `colliderect()` 是 Rect 对象的方法，用来判断自己是否和另一个 Rect 发生了重叠。如果重叠（碰撞），返回 `True`，否则返回 `False`。这个方法非常高效，Pygame 在底层帮你算好了，一行代码搞定！

**小球和挡板的碰撞注意事项：**
- 球碰到挡板后，不仅要反弹（vy取反），还要把球的位置调整到挡板上方，防止球"卡"在挡板里
- 处理方法：`ball_rect.bottom = paddle_rect.top` —— 让球的底部刚好贴着挡板的顶部

#### 2.5 鼠标交互：mouse.get_pos()（4分钟）

```python
# 获取鼠标当前坐标
mouse_x, mouse_y = pygame.mouse.get_pos()

# 让挡板跟随鼠标水平移动
paddle_rect.centerx = mouse_x

# 限制挡板不超出窗口
if paddle_rect.left < 0:
    paddle_rect.left = 0
if paddle_rect.right > WIDTH:
    paddle_rect.right = WIDTH
```

> `pygame.mouse.get_pos()` 返回一个元组 `(x, y)`，分别是鼠标在窗口中的 x 和 y 坐标（以像素为单位）。我们只需要用到 x 坐标来控制挡板的水平位置。

## 💡 常见问题与解决

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 球移动太快/太慢 | 速度值过大或过小 | 调整 vx、vy 的值（建议 5~8） |
| 球碰到挡板后"卡住" | 没有调整球的位置 | 碰撞后加 `ball_rect.bottom = paddle_rect.top` |
| 球穿过了挡板 | 球速度过大，一帧跳过了挡板 | 降低速度值，或增加碰撞检测的容错范围 |
| 挡板跑到窗口外面 | 没有限制挡板的位置 | 用 `if` 判断把挡板限制在窗口内 |
| `colliderect` 拼写错误 | 方法是 `colliderect` 不是 `collide_rect` | 注意是 `colliderect`（一个词） |
| 鼠标获取不到位置 | 没在游戏循环内调用 | `get_pos()` 要在游戏循环里每帧调用 |
