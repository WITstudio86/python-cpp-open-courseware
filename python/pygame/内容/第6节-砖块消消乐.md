### 二、核心讲解（20分钟）

#### 2.1 嵌套循环生成砖块阵列（6分钟）

**为什么要用嵌套循环？**
> 假设我们要画5行砖块，每行8块。如果一块一块写，需要写40行代码！但用嵌套循环，只需要一个"行×列"的双层循环就能搞定。

```python
# 砖块设置
BRICK_ROWS = 5        # 共5行
BRICK_COLS = 8        # 每行8块
BRICK_WIDTH = 90      # 每块砖的宽度
BRICK_HEIGHT = 25     # 每块砖的高度
BRICK_GAP = 5         # 砖块之间的间隔

# 存储所有砖块的列表
bricks = []

# 嵌套循环生成砖块阵列
for row in range(BRICK_ROWS):         # 外层循环：控制行数
    for col in range(BRICK_COLS):     # 内层循环：控制列数

        # 计算每个砖块的位置
        brick_x = col * (BRICK_WIDTH + BRICK_GAP) + BRICK_GAP
        brick_y = row * (BRICK_HEIGHT + BRICK_GAP) + BRICK_GAP + 50

        # 创建砖块的 Rect 对象
        brick = pygame.Rect(brick_x, brick_y, BRICK_WIDTH, BRICK_HEIGHT)

        # 把砖块加入到列表中
        bricks.append(brick)
```

**理解嵌套循环：**
```
外层 row=0 → 内层 col=0,1,2,...,7 → 画第1行的8块砖
外层 row=1 → 内层 col=0,1,2,...,7 → 画第2行的8块砖
外层 row=2 → 内层 col=0,1,2,...,7 → 画第3行的8块砖
...
```

> **小贴士**：`col * (BRICK_WIDTH + BRICK_GAP)` — 这一步是计算每个砖块的 x 坐标。把"砖块宽度+间隔"当成一个"格子宽度"，第 col 列就乘以 col 个格子宽度。

#### 2.2 列表管理多个对象（4分钟）

**为什么用列表？**
> 游戏中有几十个砖块，每个都需要绘制和碰撞检测。把它们放在一个列表里，就可以用循环批量处理。

```python
# 列表的核心操作：
bricks = []            # 创建一个空列表
bricks.append(obj)     # 往列表末尾添加一个对象
bricks.remove(obj)     # 从列表中删除指定的对象

# 遍历列表：对每个砖块做同样的事
for brick in bricks:
    pygame.draw.rect(screen, color, brick)   # 画出每个砖块
```

**碰撞检测 + 消除砖块：**
```python
# 检查球是否碰到了某个砖块
for brick in bricks:
    if ball.colliderect(brick):
        bricks.remove(brick)   # 消除这块砖！
        ball_vy = -ball_vy     # 球反弹
        score += 1             # 分数+1
        break                  # 一次只消除一块，跳出循环
```

> **重要**：`break` 在这里很关键！如果不用 `break`，当球同时碰到两块相邻的砖块时，循环会试图删除第二块砖，但列表已经在第一次 `remove()` 后改变了，会导致程序出错。用 `break` 确保每帧最多消除一块砖。

**另一种安全遍历方法：**
```python
# 使用 [:] 创建列表的副本进行遍历，避免修改列表时出错
for brick in bricks[:]:      # 注意这里是 bricks[:] 而不是 bricks
    if ball.colliderect(brick):
        bricks.remove(brick)
        ball_vy = -ball_vy
        score += 1
        break
```

#### 2.3 文字显示：font.render()（5分钟）

**Pygame 显示文字的三步走：**
1. 创建字体对象
2. 渲染文字（把文字变成图像）
3. 将图像绘制到屏幕上

```python
# 第1步：创建字体对象
font = pygame.font.Font(None, 36)   # None = 默认字体，36 = 字号

# 第2步：渲染文字为图像（返回一个 Surface 对象）
# render(文字内容, 是否抗锯齿, 颜色)
score_text = font.render("分数: 5", True, (255, 255, 255))

# 第3步：绘制到屏幕上
screen.blit(score_text, (10, 10))    # blit = 把图像"贴"到屏幕的指定位置

# 游戏结束文字
game_over_text = font.render("GAME OVER - 按 R 重新开始", True, (255, 0, 0))
# 把文字居中显示
text_rect = game_over_text.get_rect(center=(WIDTH//2, HEIGHT//2))
screen.blit(game_over_text, text_rect)
```

> **理解 `render()`**：它把文字"画"成一个图像（Surface）。`True` 表示开启抗锯齿——让文字边缘更平滑，不会出现锯齿状的像素边缘。

#### 2.4 游戏结束判定 + 重新开始（5分钟）

**游戏结束的条件：**
> 球掉出屏幕底部 → 游戏结束。不再是像上节课那样重新发球！

```python
# 游戏状态变量
game_over = False

# 在游戏循环中判断：
if ball.bottom >= HEIGHT:
    game_over = True    # 球掉出底部 → 游戏结束

# 如果游戏结束，显示结束画面，等待玩家按R键
if game_over:
    # 显示游戏结束文字
    screen.blit(game_over_text, text_rect)

    # 检测按键
    keys = pygame.key.get_pressed()
    if keys[pygame.K_r]:    # 玩家按下 R 键
        # 重置游戏状态！
        game_over = False
        score = 0

        # 重新生成砖块
        bricks.clear()
        for row in range(BRICK_ROWS):
            for col in range(BRICK_COLS):
                brick_x = col * (BRICK_WIDTH + BRICK_GAP) + BRICK_GAP
                brick_y = row * (BRICK_HEIGHT + BRICK_GAP) + BRICK_GAP + 50
                bricks.append(pygame.Rect(brick_x, brick_y, BRICK_WIDTH, BRICK_HEIGHT))

        # 重置球的位置和速度
        ball.centerx = WIDTH // 2
        ball.centery = HEIGHT // 2
        ball_vx = 6
        ball_vy = 6

    # 游戏结束时跳过更新逻辑（球和挡板不动）
    pygame.display.flip()
    clock.tick(FPS)
    continue    # 跳过本轮循环剩余代码
```

> **`continue` 的作用**：游戏结束时，我们不想让球继续移动、碰撞检测。`continue` 直接跳到下一轮循环，跳过后面的更新和绘制代码。

## 💡 常见问题与解决

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 砖块没有间隙或重叠 | 坐标计算错误 | 检查 `col * (w + gap)` 中的括号 |
| 一次消掉多个砖块 | 没用 `break` | 碰撞检测循环里加 `break` |
| 程序崩溃：`list.remove(x) not in list` | 一帧内重复删除同一砖块 | 用 `bricks[:]` 遍历副本，或加 `break` |
| 分数文字不显示 | 忘记 `screen.blit()` 或字体太小 | 确认调用了 `blit`，字号至少24 |
| 按R键没重置游戏 | 没用事件检测或用错了按键检查方式 | 用 `keys[pygame.K_r]` 代替 `event.key == pygame.K_r` |
| 砖块颜色都一样 | 没用不同颜色 | 创建颜色列表，用 `row` 作为索引 |
| 球穿过砖块 | 球速度太大 | 降低球速（如从8降到5） |
| 游戏结束时球还在动 | 没跳过更新代码 | 游戏结束时加 `continue` |
