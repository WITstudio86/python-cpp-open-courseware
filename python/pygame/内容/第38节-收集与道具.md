### 3.2 讲解（一）：道具计时机制（10分钟）

#### 3.2.1 游戏的"秒表"：pygame.time.get_ticks()

游戏需要一个精确的计时器来记录"道具还剩多久"。Pygame提供了一个非常方便的函数：`pygame.time.get_ticks()`。

**它是什么？**

`pygame.time.get_ticks()` 返回从游戏开始到现在经过的**毫秒数**（1秒 = 1000毫秒）。

```python
import pygame
pygame.init()

start = pygame.time.get_ticks()  # 假设返回 5230（游戏已经运行了5.23秒）
# ... 等待一会儿 ...
now = pygame.time.get_ticks()    # 假设返回 7450（又过了2.22秒）
elapsed = now - start            # 7450 - 5230 = 2220 毫秒 ≈ 2.22秒
```

> **生活类比：** `get_ticks()` 就像体育老师手里的秒表——从上课铃响那一刻开始计时，任何时候看一眼就知道过了多久。

#### 3.2.2 道具拾取计时

当我们吃到道具时，记录下"吃到的时刻"，然后每一帧检查"现在时刻 - 吃到时刻 > 持续时间"，就知道道具是否过期了。

```python
# 道具持续时间（毫秒）
MAGNET_DURATION = 5000   # 磁铁持续 5 秒 = 5000 毫秒
SHIELD_DURATION = 4000   # 护盾持续 4 秒 = 4000 毫秒

# 记录道具拾取时间（初始为0，表示没有激活）
magnet_pickup_time = 0
shield_pickup_time = 0

# 吃到磁铁道具时
magnet_pickup_time = pygame.time.get_ticks()  # 记录"现在几点"
magnet_active = True                          # 标记磁铁已激活

# 每一帧检查磁铁是否过期
now = pygame.time.get_ticks()
if magnet_active:
    if now - magnet_pickup_time > MAGNET_DURATION:
        # 5秒到了！磁铁效果结束
        magnet_active = False
```

**运行时示意图：**

```

t=0ms      吃到磁铁 → magnet_pickup_time = 10000
                              magnet_active = True
t=1000ms   磁铁生效中（还剩4秒）
t=2000ms   磁铁生效中（还剩3秒）
t=3000ms   磁铁生效中（还剩2秒）
t=4000ms   磁铁生效中（还剩1秒）
t=5000ms   now - pickup_time = 5000 > 5000? 不，等于5000
t=5001ms   now - pickup_time = 5001 > 5000? 是！→ magnet_active = False
```

#### 3.2.3 为什么不用 time.sleep()？

有同学可能会想："让道具持续5秒？那我 `time.sleep(5)` 不就行了？"

**大错特错！** `time.sleep()` 会让**整个程序暂停**，游戏画面完全卡住，什么都动不了。

```python
# 错误做法（千万不要这样写！）
magnet_active = True
time.sleep(5)         # 程序卡死5秒！玩家无法操作，画面不动
magnet_active = False

# 正确做法
magnet_pickup_time = pygame.time.get_ticks()  # 记录时间点
magnet_active = True
# 游戏循环继续运行，每帧检查时间是否到了
```

| 方式 | 游戏是否继续运行？ | 玩家能操作吗？ | 画面会更新吗？ |
|------|:---:|:---:|:---:|
| `time.sleep(5)` | 否 | 否 | 否 |
| `get_ticks()` 计时 | **是** | **是** | **是** |

> **生活类比：** `time.sleep(5)` 就像你在跑步时突然被"冰冻"了5秒，一动也不能动；而 `get_ticks()` 计时就像你边跑步边看手表，跑到5秒就停下来，期间一切正常。

#### 3.3.2 磁铁效果原理

磁铁效果的核心是：**让所有金币自动向玩家移动**。

实现这个效果，我们需要用到向量计算：

```
第一步：计算方向向量
  dx = player.x - coin.x    （玩家在金币右边 → dx为正）
  dy = player.y - coin.y    （玩家在金币下方 → dy为正）

第二步：计算距离
  distance = sqrt(dx² + dy²)

第三步：归一化（变成长度为1的方向向量）
  dx_normalized = dx / distance
  dy_normalized = dy / distance

第四步：乘以吸附速度
  coin.x += dx_normalized * magnet_speed
  coin.y += dy_normalized * magnet_speed
```

**代码实现：**

```python
import math

MAGNET_SPEED = 8  # 磁铁吸附速度（每帧移动的像素数）

def apply_magnet_effect(player, coins):
    """磁铁效果：让所有金币向玩家移动"""
    for coin in coins:
        # 第一步：计算方向向量
        dx = player.x - coin.x
        dy = player.y - coin.y

        # 第二步：计算距离
        distance = math.sqrt(dx * dx + dy * dy)

        # 避免除以零（如果金币正好在玩家身上）
        if distance == 0:
            continue

        # 第三步+第四步：归一化并移动
        coin.x += (dx / distance) * MAGNET_SPEED
        coin.y += (dy / distance) * MAGNET_SPEED
```

> **给学生的比喻：** 想象玩家是一块大磁铁，金币是小铁屑。磁铁会"拉着"铁屑向自己靠近。方向向量（dx, dy）就是"拉力方向"，除以距离是为了让远近不同的金币以相同的速度靠近——不然远处的金币会"瞬移"过来！

**磁铁吸引范围优化（可选）：**

如果只想吸引一定范围内的金币，可以加一个距离判断：

```python
MAGNET_RANGE = 200  # 磁铁有效范围（像素）

for coin in coins:
    dx = player.x - coin.x
    dy = player.y - coin.y
    distance = math.sqrt(dx * dx + dy * dy)

    # 只吸引范围内的金币
    if distance < MAGNET_RANGE and distance > 0:
        coin.x += (dx / distance) * MAGNET_SPEED
        coin.y += (dy / distance) * MAGNET_SPEED
```

#### 3.3.3 护盾效果原理

护盾的核心是：**碰撞检测时"豁免"死亡**。

平常的碰撞逻辑是：

```python
# 没有护盾时：碰到障碍物 → 游戏结束
if player.colliderect(obstacle):
    game_over = True
```

有了护盾之后，逻辑变成：

```python
# 有护盾时：碰到障碍物 → 不死亡，但护盾消失（可选）
if player.colliderect(obstacle):
    if shield_active:
        # 有护盾保护！不死亡
        # 可选：碰撞后护盾消失（消耗型护盾）
        # shield_active = False
        pass
    else:
        # 没有护盾，游戏结束
        game_over = True
```

**护盾视觉效果：**

在玩家周围画一个半透明的彩色光圈，让玩家知道自己有护盾：

```python
def draw_shield_effect(screen, player):
    """绘制护盾视觉效果：脉冲光圈"""
    if not shield_active:
        return

    # 计算护盾剩余时间比例（用于脉冲动画）
    now = pygame.time.get_ticks()
    elapsed = now - shield_pickup_time
    remaining = max(0, SHIELD_DURATION - elapsed)
    ratio = remaining / SHIELD_DURATION  # 1.0 → 0.0

    # 脉冲效果：光圈大小周期性变化
    import math
    pulse = math.sin(now / 150) * 3  # 每150毫秒一个脉冲周期，振幅3像素
    radius = 35 + pulse

    # 绘制光圈（从外到内多层，渐变更明显）
    for i in range(3):
        alpha_radius = radius - i * 8
        # 颜色随剩余时间变化：充足时亮蓝，快结束时变红警告
        if ratio > 0.3:
            color = (100, 180, 255)  # 亮蓝色
        else:
            color = (255, 80, 80)    # 警告红色
        pygame.draw.circle(screen, color,
                           (int(player.x), int(player.y)),
                           int(alpha_radius), 2)
```

> **给学生的比喻：** 护盾就像科幻电影里的"能量防护罩"——子弹打过来，碰到防护罩就消失了，里面的角色安然无恙。光圈的颜色变化是给玩家的提示：蓝色=安全，红色=护盾快消失了，赶紧小心！

**护盾倒计时显示：**

在屏幕角落显示护盾剩余时间，让玩家心里有数：

```python
def draw_shield_timer(screen):
    """在屏幕右上角显示护盾剩余时间"""
    if not shield_active:
        return

    now = pygame.time.get_ticks()
    elapsed = now - shield_pickup_time
    remaining = max(0, SHIELD_DURATION - elapsed)
    seconds = remaining / 1000.0  # 转换为秒

    font = pygame.font.SysFont("Arial", 24)
    text = font.render(f"护盾: {seconds:.1f}秒", True, (100, 180, 255))
    screen.blit(text, (screen.get_width() - 180, 10))
```

#### 3.3.4 金币收集系统

金币是游戏中不断出现的可收集物品。它的生命周期是：**出现 → 被收集 → 消失（或移出屏幕后自动移除）**。

**金币数据结构：**

```python
# 金币列表
coins = []

# 每个金币用字典表示
coin = {
    "x": 800,           # 初始x坐标（屏幕右侧外）
    "y": random_y,      # 随机y坐标
    "radius": 10,       # 金币半径
    "value": 1,         # 金币分值
}
```

**金币生成：每隔一定帧数或时间在屏幕右侧生成一枚金币**

```python
COIN_SPAWN_INTERVAL = 60  # 每60帧生成一枚金币
frame_count = 0

# 在游戏循环中
frame_count += 1
if frame_count % COIN_SPAWN_INTERVAL == 0:
    coins.append({
        "x": SCREEN_WIDTH + 20,
        "y": random.randint(100, SCREEN_HEIGHT - 100),
        "radius": 10,
    })
    frame_count = 0
```

**金币移动（向左滚动，模拟跑酷前进）：**

```python
SCROLL_SPEED = 5  # 背景滚动速度

for coin in coins:
    coin["x"] -= SCROLL_SPEED  # 金币从右向左移动
```

**金币收集判定（碰撞检测）：**

```python
def check_coin_collision(player, coins):
    """检测玩家是否吃到金币，返回吃到的金币数量"""
    global score
    collected = 0

    for coin in coins[:]:  # 遍历副本，方便删除
        # 计算玩家与金币的中心距离
        dx = player.x - coin["x"]
        dy = player.y - coin["y"]
        distance = math.sqrt(dx * dx + dy * dy)

        # 如果距离小于玩家半径+金币半径，说明碰到了
        if distance < player.radius + coin["radius"]:
            coins.remove(coin)
            collected += 1
            score += coin.get("value", 1)  # 加分

    return collected
```

**金币移出屏幕后自动移除（防止列表无限增长）：**

```python
# 清理移出屏幕的金币
for coin in coins[:]:
    if coin["x"] < -50:  # 完全离开屏幕左侧
        coins.remove(coin)
```

#### 3.3.5 道具掉落机制

障碍物被消灭或经过一定条件后，有概率掉落道具。

**设计思路：**

- 障碍物经过玩家后（从屏幕左侧消失），有一定概率留下道具
- 道具类型随机选择：磁铁或护盾
- 不同道具用不同颜色和形状区分

**道具数据结构：**

```python
# 道具列表
powerups = []

# 每个道具
powerup = {
    "x": x,                      # 位置
    "y": y,
    "type": "magnet",            # 道具类型："magnet" 或 "shield"
    "radius": 15,                # 道具半径
}
```

**道具生成逻辑：**

```python
import random

POWERUP_DROP_CHANCE = 0.3  # 30% 掉落概率

def try_drop_powerup(obstacle_x, obstacle_y):
    """障碍物消失时，有概率掉落道具"""
    if random.random() < POWERUP_DROP_CHANCE:
        # 随机选择道具类型
        ptype = random.choice(["magnet", "shield"])
        powerups.append({
            "x": obstacle_x,
            "y": obstacle_y,
            "type": ptype,
            "radius": 15,
        })
```

**道具外观区分：**

```python
def draw_powerup(screen, powerup):
    """根据道具类型绘制不同的外观"""
    x, y = int(powerup["x"]), int(powerup["y"])

    if powerup["type"] == "magnet":
        # 磁铁：红色圆形 + "M" 标记
        pygame.draw.circle(screen, (255, 80, 60), (x, y), powerup["radius"])
        pygame.draw.circle(screen, (255, 200, 180), (x, y), powerup["radius"], 2)
        # 可以画一个简单的U形磁铁图案
        font = pygame.font.SysFont("Arial", 14, bold=True)
        text = font.render("M", True, (255, 255, 255))
        screen.blit(text, (x - 5, y - 8))

    elif powerup["type"] == "shield":
        # 护盾：蓝色圆形 + "S" 标记
        pygame.draw.circle(screen, (60, 140, 255), (x, y), powerup["radius"])
        pygame.draw.circle(screen, (180, 210, 255), (x, y), powerup["radius"], 2)
        font = pygame.font.SysFont("Arial", 14, bold=True)
        text = font.render("S", True, (255, 255, 255))
        screen.blit(text, (x - 5, y - 8))
```

**道具移动（和障碍物一样向左滚动）：**

```python
for powerup in powerups:
    powerup["x"] -= SCROLL_SPEED
```

**道具拾取判定：**

```python
def check_powerup_collision(player, powerups):
    """检测玩家是否吃到道具"""
    global magnet_pickup_time, shield_pickup_time
    global magnet_active, shield_active

    for pu in powerups[:]:
        dx = player.x - pu["x"]
        dy = player.y - pu["y"]
        distance = math.sqrt(dx * dx + dy * dy)

        if distance < player.radius + pu["radius"]:
            if pu["type"] == "magnet":
                magnet_pickup_time = pygame.time.get_ticks()
                magnet_active = True
            elif pu["type"] == "shield":
                shield_pickup_time = pygame.time.get_ticks()
                shield_active = True
            powerups.remove(pu)
```

### 3.4 道具备忘小抄

| 机制 | 核心代码 | 关键点 |
|------|----------|--------|
| **计时开始** | `pickup_time = pygame.time.get_ticks()` | 记录拾取时刻（毫秒） |
| **计时检查** | `pygame.time.get_ticks() - pickup_time > DURATION` | 每帧检查是否超时 |
| **磁铁吸引** | `coin.x += (dx/distance) * speed` | 归一化方向向量，等速吸引 |
| **护盾免疫** | `if shield_active: 跳过死亡` | 在碰撞检测中加一层判断 |
| **金币收集** | `distance < r1 + r2 → 加分并移除` | 圆与圆的碰撞检测 |
| **状态重置** | `magnet_active = False` | 到期后重置标记 |

```python
"""
第38节：收集与道具 —— 完整示例代码
在跑酷游戏基础上添加：金币收集、磁铁道具、护盾道具
"""

import pygame
import random
import math

# ==================== 初始化 ====================
pygame.init()
WIDTH, HEIGHT = 800, 500
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("跑酷游戏 - 道具系统")
clock = pygame.time.Clock()
font = pygame.font.SysFont("Arial", 20)
big_font = pygame.font.SysFont("Arial", 36)

# ==================== 常量定义 ====================
SCROLL_SPEED = 6            # 背景滚动速度（也是障碍物/金币移动速度）
GRAVITY = 0.7               # 重力加速度
JUMP_FORCE = -14            # 跳跃力度（负数=向上）

# 道具相关常量
MAGNET_DURATION = 5000      # 磁铁持续时间（毫秒，5秒）
SHIELD_DURATION = 4000      # 护盾持续时间（毫秒，4秒）
POWERUP_DROP_CHANCE = 0.25  # 障碍物掉落道具的概率（25%）
MAGNET_SPEED = 6            # 磁铁吸附速度
MAGNET_RANGE = 250          # 磁铁有效范围（像素）

# ==================== 玩家 ====================
player = {
    "x": 150,
    "y": HEIGHT - 150,
    "vy": 0,
    "radius": 20,
    "on_ground": True,
}

GROUND_Y = HEIGHT - 50      # 地面高度

# ==================== 游戏状态 ====================
score = 0
game_over = False

# 道具状态
magnet_active = False
shield_active = False
magnet_pickup_time = 0
shield_pickup_time = 0

# ==================== 物品列表 ====================
obstacles = []     # 障碍物列表
coins = []         # 金币列表
powerups = []      # 道具列表

# 生成计时器
obstacle_timer = 0
coin_timer = 0
OBSTACLE_INTERVAL = 80    # 每80帧生成一个障碍物
COIN_INTERVAL = 45        # 每45帧生成一枚金币


# ==================== 辅助函数 ====================

def spawn_obstacle():
    """生成一个障碍物（矩形方块）"""
    w = random.randint(20, 50)
    h = random.randint(30, 60)
    y = GROUND_Y - h  # 放在地面上
    obstacles.append({
        "x": WIDTH + 20,
        "y": y,
        "w": w,
        "h": h,
    })


def spawn_coin():
    """生成一枚金币"""
    coins.append({
        "x": WIDTH + 20,
        "y": random.randint(80, GROUND_Y - 40),
        "radius": 8,
    })


def try_drop_powerup(x, y):
    """尝试在指定位置掉落道具"""
    if random.random() < POWERUP_DROP_CHANCE:
        ptype = random.choice(["magnet", "shield"])
        powerups.append({
            "x": x,
            "y": y,
            "type": ptype,
            "radius": 14,
        })


def check_coin_collection():
    """检测玩家是否吃到金币"""
    global score
    for coin in coins[:]:
        dx = player["x"] - coin["x"]
        dy = player["y"] - coin["y"]
        distance = math.sqrt(dx * dx + dy * dy)
        if distance < player["radius"] + coin["radius"]:
            coins.remove(coin)
            score += 10  # 每枚金币加10分


def check_powerup_pickup():
    """检测玩家是否吃到道具"""
    global magnet_active, shield_active
    global magnet_pickup_time, shield_pickup_time

    for pu in powerups[:]:
        dx = player["x"] - pu["x"]
        dy = player["y"] - pu["y"]
        distance = math.sqrt(dx * dx + dy * dy)
        if distance < player["radius"] + pu["radius"]:
            if pu["type"] == "magnet":
                magnet_pickup_time = pygame.time.get_ticks()
                magnet_active = True
                print("吃到磁铁！持续5秒")
            elif pu["type"] == "shield":
                shield_pickup_time = pygame.time.get_ticks()
                shield_active = True
                print("吃到护盾！持续4秒")
            powerups.remove(pu)


def apply_magnet_effect():
    """磁铁效果：范围内的金币自动飞向玩家"""
    for coin in coins[:]:
        dx = player["x"] - coin["x"]
        dy = player["y"] - coin["y"]
        distance = math.sqrt(dx * dx + dy * dy)

        # 只吸引范围内的金币
        if 0 < distance < MAGNET_RANGE:
            # 归一化方向向量并乘以吸附速度
            coin["x"] += (dx / distance) * MAGNET_SPEED
            coin["y"] += (dy / distance) * MAGNET_SPEED


def check_obstacle_collision():
    """检测玩家是否撞到障碍物"""
    global game_over

    player_rect = pygame.Rect(
        player["x"] - player["radius"],
        player["y"] - player["radius"],
        player["radius"] * 2,
        player["radius"] * 2,
    )

    for obs in obstacles[:]:
        obs_rect = pygame.Rect(obs["x"], obs["y"], obs["w"], obs["h"])
        if player_rect.colliderect(obs_rect):
            if shield_active:
                # 有护盾：不死亡，障碍物消失，护盾消耗掉
                obstacles.remove(obs)
                shield_active = False  # 护盾被消耗！
            else:
                # 没有护盾：游戏结束
                game_over = True
                return


def update_timers():
    """检查道具效果是否到期"""
    global magnet_active, shield_active
    now = pygame.time.get_ticks()

    # 检查磁铁是否到期
    if magnet_active:
        if now - magnet_pickup_time > MAGNET_DURATION:
            magnet_active = False
            print("磁铁效果结束")

    # 检查护盾是否到期
    if shield_active:
        if now - shield_pickup_time > SHIELD_DURATION:
            shield_active = False
            print("护盾效果结束")


def move_and_clean():
    """移动所有物体并清理出界的"""
    # 移动障碍物
    for obs in obstacles[:]:
        obs["x"] -= SCROLL_SPEED
        if obs["x"] < -100:
            try_drop_powerup(obs["x"] + 50, obs["y"])  # 消失时尝试掉落道具
            obstacles.remove(obs)

    # 移动金币
    for coin in coins[:]:
        coin["x"] -= SCROLL_SPEED
        if coin["x"] < -50:
            coins.remove(coin)

    # 移动道具
    for pu in powerups[:]:
        pu["x"] -= SCROLL_SPEED
        if pu["x"] < -50:
            powerups.remove(pu)


def update_player():
    """更新玩家位置（重力+跳跃）"""
    keys = pygame.key.get_pressed()

    # 跳跃
    if keys[pygame.K_SPACE] and player["on_ground"]:
        player["vy"] = JUMP_FORCE
        player["on_ground"] = False

    # 重力
    player["vy"] += GRAVITY
    player["y"] += player["vy"]

    # 地面碰撞
    if player["y"] >= GROUND_Y - player["radius"]:
        player["y"] = GROUND_Y - player["radius"]
        player["vy"] = 0
        player["on_ground"] = True


# ==================== 绘制函数 ====================

def draw_background():
    """绘制背景和地面"""
    screen.fill((30, 30, 50))
    # 地面
    pygame.draw.rect(screen, (80, 60, 40),
                     (0, GROUND_Y, WIDTH, HEIGHT - GROUND_Y))
    # 地面线
    pygame.draw.line(screen, (120, 100, 60),
                     (0, GROUND_Y), (WIDTH, GROUND_Y), 3)


def draw_player():
    """绘制玩家（圆形角色）"""
    # 护盾效果：在玩家下面先画光圈
    if shield_active:
        now = pygame.time.get_ticks()
        elapsed = now - shield_pickup_time
        remaining = max(0, SHIELD_DURATION - elapsed)
        ratio = remaining / SHIELD_DURATION

        # 脉冲光圈
        pulse = math.sin(now / 120) * 2.5
        for i in range(3):
            r = player["radius"] + 14 + i * 6 + pulse
            if ratio > 0.3:
                alpha_color = (80, 160, 255)
            else:
                alpha_color = (255, 60, 60)
            pygame.draw.circle(screen, alpha_color,
                               (int(player["x"]), int(player["y"])),
                               int(r), 2)

    # 玩家本身
    body_color = (255, 200, 100)
    if magnet_active:
        body_color = (255, 120, 60)  # 磁铁激活时偏红
    pygame.draw.circle(screen, body_color,
                       (int(player["x"]), int(player["y"])),
                       player["radius"])
    # 眼睛
    eye_x = int(player["x"]) + 7
    eye_y = int(player["y"]) - 5
    pygame.draw.circle(screen, (255, 255, 255), (eye_x, eye_y), 5)
    pygame.draw.circle(screen, (0, 0, 0), (eye_x + 1, eye_y), 2)


def draw_obstacles():
    """绘制障碍物"""
    for obs in obstacles:
        pygame.draw.rect(screen, (200, 60, 40),
                         (obs["x"], obs["y"], obs["w"], obs["h"]))
        pygame.draw.rect(screen, (160, 40, 20),
                         (obs["x"], obs["y"], obs["w"], obs["h"]), 2)


def draw_coins():
    """绘制金币（金色圆形 + 闪光效果）"""
    for coin in coins:
        # 金币主体
        pygame.draw.circle(screen, (255, 215, 0),
                           (int(coin["x"]), int(coin["y"])),
                           coin["radius"])
        # 高光
        pygame.draw.circle(screen, (255, 255, 200),
                           (int(coin["x"]) - 2, int(coin["y"]) - 3),
                           coin["radius"] // 3)


def draw_powerups():
    """绘制道具"""
    for pu in powerups:
        x, y = int(pu["x"]), int(pu["y"])
        r = pu["radius"]

        if pu["type"] == "magnet":
            # 磁铁：红底圆 + "M"字
            pygame.draw.circle(screen, (220, 60, 50), (x, y), r)
            pygame.draw.circle(screen, (255, 160, 140), (x, y), r, 2)
            magnet_text = font.render("M", True, (255, 255, 255))
            screen.blit(magnet_text, (x - 7, y - 10))
        elif pu["type"] == "shield":
            # 护盾：蓝底圆 + "S"字
            pygame.draw.circle(screen, (50, 120, 220), (x, y), r)
            pygame.draw.circle(screen, (150, 200, 255), (x, y), r, 2)
            shield_text = font.render("S", True, (255, 255, 255))
            screen.blit(shield_text, (x - 6, y - 10))


def draw_ui():
    """绘制UI：分数、道具状态、倒计时"""
    # 分数（左上角）
    score_text = font.render(f"分数: {score}", True, (255, 255, 255))
    screen.blit(score_text, (15, 15))

    # 金币数量
    coin_text = font.render(f"金币: {len(coins)}", True, (255, 215, 0))
    screen.blit(coin_text, (15, 40))

    # 道具状态（右上角）
    y_offset = 15
    if magnet_active:
        now = pygame.time.get_ticks()
        remaining = max(0, MAGNET_DURATION - (now - magnet_pickup_time))
        sec = remaining / 1000.0
        magnet_ui = font.render(f"磁铁: {sec:.1f}s", True, (255, 120, 60))
        screen.blit(magnet_ui, (WIDTH - 160, y_offset))
        y_offset += 25

    if shield_active:
        now = pygame.time.get_ticks()
        remaining = max(0, SHIELD_DURATION - (now - shield_pickup_time))
        sec = remaining / 1000.0
        shield_ui = font.render(f"护盾: {sec:.1f}s", True, (80, 160, 255))
        screen.blit(shield_ui, (WIDTH - 160, y_offset))
        y_offset += 25


def draw_game_over():
    """绘制游戏结束画面"""
    overlay = pygame.Surface((WIDTH, HEIGHT))
    overlay.set_alpha(180)
    overlay.fill((0, 0, 0))
    screen.blit(overlay, (0, 0))

    go_text = big_font.render("游戏结束！", True, (255, 80, 80))
    screen.blit(go_text, (WIDTH // 2 - 90, HEIGHT // 2 - 60))

    final_score = big_font.render(f"最终得分: {score}", True, (255, 255, 255))
    screen.blit(final_score, (WIDTH // 2 - 100, HEIGHT // 2 - 10))

    restart_text = font.render("按 R 键重新开始", True, (200, 200, 200))
    screen.blit(restart_text, (WIDTH // 2 - 85, HEIGHT // 2 + 50))


def reset_game():
    """重置游戏状态"""
    global score, game_over
    global magnet_active, shield_active
    global magnet_pickup_time, shield_pickup_time
    global obstacles, coins, powerups
    global obstacle_timer, coin_timer

    score = 0
    game_over = False
    magnet_active = False
    shield_active = False
    magnet_pickup_time = 0
    shield_pickup_time = 0
    obstacles.clear()
    coins.clear()
    powerups.clear()
    obstacle_timer = 0
    coin_timer = 0
    player["y"] = GROUND_Y - player["radius"]
    player["vy"] = 0
    player["on_ground"] = True


# ==================== 主游戏循环 ====================

running = True
while running:
    dt = clock.tick(60)  # 60 FPS

    # ---------- 事件处理 ----------
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.KEYDOWN:
            if event.key == pygame.K_r and game_over:
                reset_game()

    # ---------- 游戏逻辑（仅在未结束时运行） ----------
    if not game_over:
        # 玩家更新
        update_player()

        # 生成障碍物
        obstacle_timer += 1
        if obstacle_timer >= OBSTACLE_INTERVAL:
            spawn_obstacle()
            obstacle_timer = 0

        # 生成金币
        coin_timer += 1
        if coin_timer >= COIN_INTERVAL:
            spawn_coin()
            coin_timer = 0

        # 移动所有物体并清理出界的
        move_and_clean()

        # 道具效果
        if magnet_active:
            apply_magnet_effect()

        # 碰撞检测
        check_coin_collection()
        check_powerup_pickup()
        check_obstacle_collision()

        # 检查道具是否到期
        update_timers()

    # ---------- 绘制 ----------
    draw_background()
    draw_coins()
    draw_powerups()
    draw_obstacles()
    draw_player()
    draw_ui()

    if game_over:
        draw_game_over()

    pygame.display.flip()

pygame.quit()
```

## 六、总结环节（5分钟）

### 6.1 核心知识点回顾

| 知识点 | 一句话总结 |
|--------|-----------|
| `get_ticks()` 计时 | 游戏内置秒表，返回毫秒数，配合减法实现精确计时 |
| 磁铁吸引 | 计算方向向量 → 归一化 → 乘以速度 → 金币向玩家移动 |
| 护盾免疫 | 在碰撞检测中插入 `if shield_active` 判断，有护盾不死亡 |
| 金币收集 | 圆与圆距离检测 → 距离小于半径和 → 加分移除 |
| 道具掉落 | 障碍物消失时随机概率生成，不同颜色/标记区分类型 |

### 6.2 提问检验

- "为什么不能用 `time.sleep()` 来计时道具？"（会让整个游戏卡住）
- "磁铁吸引为什么要除以 distance？"（归一化，让远近不同的金币以相同速度靠近）
- "如果想让护盾被撞后不消失，只消耗耐久次数，代码要怎么改？"（把 `shield_active = False` 改成 `shield_durability -= 1`，到0才设为False）
- "`get_ticks()` 返回的是秒还是毫秒？"（毫秒，1秒=1000毫秒）

## 七、常见错误排查

| 问题现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 道具效果一直不消失 | 忘了在 `update_timers()` 中检查时间 | 确认每帧都调用了计时检查函数 |
| 磁铁效果没生效 | `magnet_active = True` 后没有调用 `apply_magnet_effect()` | 在主循环中加上 `if magnet_active: apply_magnet_effect()` |
| 金币被磁铁吸引时一闪而过 | `MAGNET_SPEED` 设置太大 | 减小吸附速度，如改成3或4 |
| 护盾碰到障碍物还是死了 | 碰撞检测中忘了检查 `shield_active` | 确认 `check_obstacle_collision()` 中有护盾判断分支 |
| 道具倒计时数字跳来跳去 | 格式化字符串时用了整数而不是浮点数 | 使用 `f"{seconds:.1f}"` 保留一位小数 |
| 游戏越玩越卡 | 出界的金币/障碍物/道具没有移除 | 检查清理逻辑：`if x < -50: remove()` |
| 道具和金币重叠无法分辨 | 道具和金币颜色太接近 | 给道具加字母标记（M/S），或用不同形状 |
| `get_ticks()` 计时不准确 | `clock.tick()` 没有调用或帧率不稳定 | 确保 `clock.tick(60)` 在主循环开头 |

## 八、教学建议

### 8.1 生动讲解技巧

- **用赛车比喻道具计时**：就像赛车游戏里的氮气加速——按一下加速3秒，3秒后恢复正常。你不能让游戏暂停等3秒，而是边跑边计时。
- **用磁铁实物演示**：如果教室有磁铁和回形针，可以现场演示磁铁吸引效果，让学生直观理解"距离越近吸力越强"。
- **用手势辅助讲解向量**：伸出双手，一只手代表玩家位置，一只手代表金币位置，然后双手逐渐靠近——这就是向量的方向。

### 8.2 分步教学建议

1. **第一步**：先让学生理解 `get_ticks()`，用一个简单的打印程序验证：
   ```python
   start = pygame.time.get_ticks()
   while True:
       now = pygame.time.get_ticks()
       print(f"已经过了 {(now - start) / 1000:.1f} 秒")
   ```
   让学生看到数字每秒增加1。

2. **第二步**：在基础跑酷代码上逐步添加功能：
   - 先加金币（最简单的收集系统）
   - 再加磁铁（引入计时概念）
   - 最后加护盾（引入碰撞豁免）

3. **第三步**：让学生自由发挥，尝试添加自己的道具创意。

### 8.3 针对不同能力学生的建议

| 学生水平 | 建议 |
|----------|------|
| **基础较弱** | 先确保能理解 `get_ticks()` 和布尔标记，暂时跳过磁铁的向量计算部分，只实现护盾和简单金币收集 |
| **中等水平** | 完成所有核心代码，尝试调整参数观察效果变化 |
| **水平较高** | 挑战"加速鞋"或"双倍分数"等额外道具，尝试实现道具叠加效果的复杂UI |

## 九、课后拓展思考

1. **道具组合技**：如果同时拥有磁铁和双倍分数，被磁铁吸来的金币是否都应该双倍？这涉及效果叠加的设计逻辑。
2. **道具商店**：用收集的金币在"商店"购买道具，引入经济系统。
3. **道具稀有度**：不同颜色的道具代表不同稀有度，稀有道具持续时间更长或效果更强。
4. **敌人掉落**：消灭敌人也掉落道具——设计敌人、战斗系统和掉落表的联动。
5. **道具冷却**：每个道具有冷却时间，不能连续拾取——防止道具效果过于强大。

---

> **本课核心收获：** 学会了游戏中"限时能力"的实现方法——用 `get_ticks()` 记录时间点，每帧检查是否超时，配合布尔标记控制效果开关。这是几乎所有游戏道具系统的底层原理！磁铁吸引用到了向量归一化，护盾免疫用到了条件分支——这些都是编程中非常实用的技巧。
