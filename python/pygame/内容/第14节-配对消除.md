### 二、核心讲解（25分钟）

#### 2.1 游戏逻辑状态机（8分钟）

**知识点：** 状态机就是程序在不同"状态"之间切换，每个状态下执行不同的行为。

**生活类比：** 你做一道菜：先"准备食材"→再"开火炒菜"→最后"装盘出锅"。每个阶段只做该阶段该做的事。程序也一样。

**我们的游戏有4个阶段（状态）：**

```
等待第一张牌 ──(点击翻开)──> 等待第二张牌
                                    │
                              (点击翻开第二张)
                                    │
                                    ▼
                              检查是否匹配
                              ╱          ╲
                         匹配成功      匹配不成功
                            │              │
                            ▼              ▼
                       立即消除       延迟0.5秒翻回
                            │              │
                            └──────┬───────┘
                                   │
                                   ▼
                            判断是否全部消除
                              ╱          ╲
                         全部消除      还没消除
                            │              │
                            ▼              ▼
                         显示胜利      回到 等待第一张牌
```

**代码实现：**

```python
# 游戏状态常量——用大写字母表示"不会变的值"
STATE_WAIT_FIRST = "wait_first"    # 等待翻第一张牌
STATE_WAIT_SECOND = "wait_second"  # 等待翻第二张牌
STATE_CHECKING = "checking"        # 正在检查是否匹配
STATE_GAME_OVER = "game_over"      # 游戏结束（胜利）

# 当前游戏状态
game_state = STATE_WAIT_FIRST

# 记录选中的两张牌
first_card = None   # 第一张牌的位置 (row, col)
second_card = None  # 第二张牌的位置 (row, col)

# 统计信息
steps = 0           # 步数（翻了几"对"牌）
pairs_found = 0     # 已经配对的牌对数
```

**讲解要点：**
- 为什么用常量而不是直接写字符串？避免手误打错字，而且IDE能检查
- `first_card` 和 `second_card` 存储的是位置信息 `(row, col)`
- 为什么需要状态机？因为同一段代码在不同状态下行为不同——比如点牌时，在"等待第一张"和"等待第二张"需要分别处理

#### 2.2 修改点击处理逻辑（7分钟）

**知识点：** 根据 `game_state` 的不同，点击卡牌做不同的事。

**代码示例：**

```python
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False
    
    elif event.type == pygame.MOUSEBUTTONDOWN:
        mouse_x, mouse_y = event.pos
        result = get_card_at_pos(mouse_x, mouse_y)
        
        if result is None:
            continue  # 点到了空白处，忽略
        
        row, col = result
        card = board[row][col]
        
        # ═══════════════════════════════════
        # 状态1：等待翻第一张牌
        # ═══════════════════════════════════
        if game_state == STATE_WAIT_FIRST:
            if card["state"] == "hidden":
                card["state"] = "revealed"
                first_card = (row, col)         # 记下位置
                game_state = STATE_WAIT_SECOND   # 进入下一状态！
                print(f"翻开第一张牌：({row}, {col})")
        
        # ═══════════════════════════════════
        # 状态2：等待翻第二张牌
        # ═══════════════════════════════════
        elif game_state == STATE_WAIT_SECOND:
            if card["state"] == "hidden":
                card["state"] = "revealed"
                second_card = (row, col)        # 记下位置
                steps += 1                       # 步数+1
                game_state = STATE_CHECKING      # 进入检查状态！
                print(f"翻开第二张牌：({row}, {col})，第 {steps} 步")
```

**讲解要点：**
- `continue` 的作用：提前结束本次循环，跳到下一次——点空白处就直接忽略
- 步数 `steps` 在翻第二张牌时 +1，因为一次"尝试"=翻两张牌
- 状态切换的核心：翻完第一张→切换到"等待第二张"；翻完第二张→切换到"检查匹配"
- 注意：不能点已经翻开的牌 `if card["state"] == "hidden"`

#### 2.3 检查匹配 + 延迟翻回（7分钟）

**知识点：** 比较两张牌的颜色；用 `pygame.time.delay()` 实现"先让玩家看清，再翻回"的效果。

**为什么需要延迟？**
如果不延迟，两张不匹配的牌会在翻开第二张的瞬间立刻翻回，玩家根本来不及看！

**代码示例：**

```python
# 在主循环中（不是在事件处理中），检查game_state

if game_state == STATE_CHECKING:
    # 取出两张牌的数据
    r1, c1 = first_card
    r2, c2 = second_card
    card1 = board[r1][c1]
    card2 = board[r2][c2]
    
    # ═══════════════════════════════════
    # 判断是否匹配：比较两张牌的颜色
    # ═══════════════════════════════════
    if card1["color"] == card2["color"]:
        # 匹配成功！
        print("🎉 配对成功！")
        card1["state"] = "matched"
        card2["state"] = "matched"
        pairs_found += 1  # 配对数+1
        
        # 检查是否全部消除
        if pairs_found == 8:
            game_state = STATE_GAME_OVER
            print("🏆 恭喜！你找到了所有配对！")
        else:
            game_state = STATE_WAIT_FIRST  # 回到等待第一张
        
    else:
        # 不匹配！需要翻回去
        # 先让玩家看清0.5秒
        pygame.display.flip()       # 刷新显示（把第二张牌的颜色显示出来）
        pygame.time.delay(500)      # 延迟500毫秒 = 0.5秒
        
        card1["state"] = "hidden"    # 翻回第一张
        card2["state"] = "hidden"    # 翻回第二张
        print("❌ 不匹配，翻回！")
        
        game_state = STATE_WAIT_FIRST  # 重新开始等待
    
    # 清空选中的牌
    first_card = None
    second_card = None
```

**讲解要点：**
- `pygame.display.flip()` 在 `delay` 之前调用！因为必须先"画出来"让玩家看到，再等0.5秒
- `pygame.time.delay(500)` 会让整个程序暂停500毫秒——在这期间什么都不能做，这就是为什么要在 `flip` 之后调用
- 两种结果的对比：匹配成功→直接改状态，不需要延迟；不匹配→延迟0.5秒后翻回
- 全部配对的判断：`pairs_found == 8`（一共8对）

**备选方案（更高级，给有兴趣的学生）：**

```python
# 用时间戳替代delay（更流畅，不阻塞程序）
# 不匹配时记录当前时间
unmatch_start_time = pygame.time.get_ticks()

# 在主循环中检查
if game_state == STATE_CHECKING:
    if not matched:
        # 如果已经过了500毫秒，翻回去
        if pygame.time.get_ticks() - unmatch_start_time > 500:
            card1["state"] = "hidden"
            card2["state"] = "hidden"
            game_state = STATE_WAIT_FIRST
```

#### 2.4 显示统计信息和胜利画面（3分钟）

**知识点：** 在屏幕上绘制文字，展示游戏进度。

**代码示例：**

```python
def draw_ui(screen, steps, pairs_found, game_state):
    """绘制游戏信息（步数、配对进度、胜利提示）"""
    # 创建字体
    font = pygame.font.Font(None, 36)      # None = 使用默认字体，36 = 字号
    big_font = pygame.font.Font(None, 60)  # 用于胜利提示的大字体
    
    # 显示步数（左上角）
    step_text = font.render(f"步数: {steps}", True, (255, 255, 255))
    screen.blit(step_text, (20, 20))
    
    # 显示配对进度（右上角）
    progress_text = font.render(f"配对: {pairs_found} / 8", True, (255, 255, 255))
    screen.blit(progress_text, (SCREEN_W - 200, 20))
    
    # 胜利画面
    if game_state == STATE_GAME_OVER:
        # 半透明遮罩
        overlay = pygame.Surface((SCREEN_W, SCREEN_H))
        overlay.set_alpha(180)  # 透明度 0-255
        overlay.fill((0, 0, 0))
        screen.blit(overlay, (0, 0))
        
        # 胜利文字（居中显示）
        win_text = big_font.render("🎉 恭喜你赢了！ 🎉", True, (255, 215, 0))
        win_rect = win_text.get_rect(center=(SCREEN_W // 2, SCREEN_H // 2 - 30))
        screen.blit(win_text, win_rect)
        
        # 显示步数
        final_text = font.render(f"你一共用了 {steps} 步！", True, (255, 255, 255))
        final_rect = final_text.get_rect(center=(SCREEN_W // 2, SCREEN_H // 2 + 30))
        screen.blit(final_text, final_rect)
        
        # 重新开始提示
        restart_text = font.render("按 R 键重新开始", True, (200, 200, 200))
        restart_rect = restart_text.get_rect(center=(SCREEN_W // 2, SCREEN_H // 2 + 80))
        screen.blit(restart_text, restart_rect)
```

**讲解要点：**
- `font.render(文字, 抗锯齿, 颜色)` 创建文字表面
- `get_rect(center=...)` 获取矩形并自动居中——非常方便
- `set_alpha(透明度)` 让遮罩半透明，下面的卡牌依稀可见
- 按 R 键重新开始的逻辑：在事件处理中检测 `pygame.KEYDOWN` 和 `pygame.K_r`

## 常见问题与解决

- **问题1：翻两张牌后程序卡死不动** → 检查 `pygame.time.delay(500)` 是否放在了不匹配的分支里；确保匹配成功时没有delay
- **问题2：第二张牌的颜色一闪而过看不到** → 检查 `pygame.display.flip()` 是否在 `delay()` 之前调用
- **问题3：点了三张牌** → 检查状态机：翻第二张后状态变为 `CHECKING`，此时点击应该被忽略，不会翻第三张
- **问题4：匹配了的牌还能点** → 点击处理中要检查 `card["state"] == "hidden"`，`matched` 状态的牌不能点
- **问题5：胜利后卡在胜利画面不能重开** → 检查是否在事件处理中添加了 `pygame.K_r` 的检测和 `create_board()` 重置逻辑
- **问题6：同一点击造成两张牌都翻开** → 确保 `first_card` 和 `second_card` 不是同一张牌（`r1 == r2 and c1 == c2`）
