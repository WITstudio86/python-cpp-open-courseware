#### 步骤1：掩体的创建（5分钟）

> "掩体就是挡在我们和外星人之间的防御工事。我们不用图片，用 Surface 自己画。"

```python
class Bunker(pygame.sprite.Sprite):
    """掩体精灵 —— 用 Surface 画出来的防御工事"""

    def __init__(self, x, y):
        super().__init__()
        self.width = 100
        self.height = 60
        # 创建一个 Surface 作为掩体的"画布"
        self.image = pygame.Surface((self.width, self.height))
        self._draw_full_bunker()  # 画出完整的掩体
        self.rect = self.image.get_rect()
        self.rect.x = x
        self.rect.y = y

    def _draw_full_bunker(self):
        """绘制完整掩体 —— 用砖块纹理"""
        self.image.fill((0, 130, 0))  # 深绿色底
        # 画砖块线，模拟防御工事
        for row in range(5):
            offset = (row % 2) * 12  # 偶数行和奇数行错开
            for col in range(5):
                bx = col * 22 + offset
                by = row * 12 + 2
                # 每块砖的边框
                pygame.draw.rect(self.image, (0, 100, 0), (bx, by, 18, 9), 1)
        # 外面的绿色边框
        pygame.draw.rect(self.image, (0, 255, 0), (0, 0, self.width, self.height), 2)
```

> "看，我们在一个 Surface 上画砖块纹理，然后这个 Surface 就是一个精灵的 image。这和之前用 draw.rect 直接在屏幕上画有什么不同？"

引导学生思考：直接画在屏幕上每次都要重画；而作为精灵的 image 画一次就够了，之后每帧只需要 blit。

**创建 4 个掩体**：

```python
def create_bunkers():
    """在屏幕底部创建 4 个掩体，均匀分布"""
    bunkers = pygame.sprite.Group()
    bunker_width = 100
    spacing = (800 - bunker_width * 4) // 5  # 计算间距

    for i in range(4):
        x = spacing + i * (bunker_width + spacing)
        bunker = Bunker(x, 500)  # y 坐标在玩家上方
        bunkers.add(bunker)
    return bunkers
```

#### 步骤2：局部破坏 —— subsurface 的魔法（8分钟）

> "这是今天最重要的知识点！看掩体怎么被破坏的——不是整个消失，而是只有被打中的那一小块没了。"

**生活类比**：
> "想象你有一张纸，上面画了一幅画。subsurface 就像用剪刀在纸上剪下一个方框区域，然后你可以在这个方框里涂黑。神奇的是，因为方框和原画是同一张纸，所以涂黑方框的同时，原画的对应位置也变黑了。"

```python
def damage(self, hit_x, hit_y, blast_radius=10):
    """
    局部破坏掩体 —— 使用 subsurface 实现弹坑效果

    参数:
        hit_x: 子弹命中点 X（相对于掩体左上角）
        hit_y: 子弹命中点 Y（相对于掩体左上角）
        blast_radius: 爆炸半径（像素）
    """
    # 第一步：计算破坏区域矩形（要确保不超出掩体边界）
    left = max(0, hit_x - blast_radius)
    top = max(0, hit_y - blast_radius)
    width = min(blast_radius * 2, self.width - left)
    height = min(blast_radius * 2, self.height - top)
    damage_rect = pygame.Rect(left, top, width, height)

    # 第二步：🔑 使用 subsurface 获取子区域
    # damaged 和 self.image 共享像素内存！
    damaged = self.image.subsurface(damage_rect)

    # 第三步：在子区域上画黑色圆形（弹坑）
    pygame.draw.circle(
        damaged,
        (0, 0, 0),  # 黑色
        (blast_radius, blast_radius),
        blast_radius
    )
    # 因为 damaged 和 self.image 共享内存，
    # 所以在 damaged 上画的黑色圆形会直接出现在 self.image 上！
```

**图解 subsurface 原理**（板书或PPT展示）：

```
self.image (100×60 的 Surface)
┌──────────────────────────────────┐
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
│  ▓▓▓▓▓▓▓▓  ●●●●●●  ▓▓▓▓▓▓▓▓▓  │  ← 子弹打在这里
│  ▓▓▓▓▓▓▓▓  ●●●●●●  ▓▓▓▓▓▓▓▓▓  │    调用 subsurface(这个矩形)
│  ▓▓▓▓▓▓▓▓  ●●●●●●  ▓▓▓▓▓▓▓▓▓  │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
└──────────────────────────────────┘
                    ↓
damaged = self.image.subsurface(damage_rect)
                    ↓
┌──────────┐     在 damaged 上画黑色圆形
│  ●●●●●●  │
│  ●●●●●●  │     damaged.fill(BLACK) 或 draw.circle()
│  ●●●●●●  │
└──────────┘
                    ↓
self.image 的对应位置也变黑了！
（因为它们是同一块内存）
```

**关键点强调**（让学生记笔记）：
1. `subsurface(Rect)` 返回一个**子 Surface**
2. 子 Surface 和父 Surface **共享同一块像素数据**
3. 修改子 Surface = 同时修改父 Surface
4. Rect 必须**完全在父 Surface 内部**，否则会报 `ValueError`

**碰撞检测与破坏的配合**：

```python
# 检测玩家子弹是否击中掩体
for bullet in player_bullets:
    hit_bunkers = pygame.sprite.spritecollide(bullet, bunkers, False)
    if hit_bunkers:
        bullet.kill()  # 子弹消失
        for bunker in hit_bunkers:
            # 计算命中位置（子弹中心相对于掩体左上角）
            hit_x = bullet.rect.centerx - bunker.rect.x
            hit_y = bullet.rect.centery - bunker.rect.y
            bunker.damage(hit_x, hit_y)  # 局部破坏！
```

> "消灭了所有外星人，游戏就结束了吗？不——更厉害的敌人马上来！这就是波次系统。"

**3.1 波次变量的作用**

```python
wave = 1  # 当前波次，从第 1 波开始

# 波次影响敌人数量
cols = min(8 + wave, 12)   # 第 1 波 9 列 → 第 2 波 10 列 → ... → 最多 12 列
rows = min(3 + wave // 2, 5)  # 第 1-2 波 3 行 → 第 3-4 波 4 行 → 最多 5 行

# 波次影响敌人速度
alien_speed = 1.2 + (wave - 1) * 0.4  # 第 1 波 1.2 → 第 2 波 1.6 → 越来越快！

# 波次影响子弹频率
alien_shoot_chance = 0.003 + wave * 0.002  # 越后面子弹越多
```

> "看到了吗？一个 `wave` 变量控制了三个东西：数量、速度、子弹概率。这就是游戏设计的「难度曲线」。"

**3.2 波次检测与切换**


#### 步骤4：波次过渡动画（4分钟）

> "消灭一波敌人后，不要急着出下一波——给玩家 2 秒钟准备时间。我们在屏幕中央显示「Wave X」。"

```python
def show_wave_transition(wave):
    """波次过渡动画 —— 屏幕中央显示 Wave X，持续约 2 秒"""

    duration = 120  # 持续帧数（约 2 秒 @ 60 FPS）
    start_ticks = pygame.time.get_ticks()

    # 波次越高，颜色越"危险"
    if wave <= 3:
        wave_color = (0, 255, 255)    # 青色
    elif wave <= 6:
        wave_color = (255, 255, 0)    # 黄色
    else:
        wave_color = (255, 0, 0)      # 红色（危险！）

    while pygame.time.get_ticks() - start_ticks < duration * 1000 / 60:
        elapsed = pygame.time.get_ticks() - start_ticks
        progress = elapsed / (duration * 1000 / 60)  # 0.0 → 1.0

        screen.fill((0, 0, 0))  # 黑屏

        # 显示 "Wave" 文字
        wave_text = font_large.render("Wave", True, (255, 255, 255))
        screen.blit(wave_text, (400 - wave_text.get_width()//2, 250))

        # 显示波次数字（带缩放动画）
        scale = 1.0 + 0.3 * (1 - abs(progress - 0.5) * 2)  # 先变大再变小
        # ... 根据 scale 调整字号 ...

        # "准备！" 提示（过渡后半段出现）
        if progress > 0.3:
            ready_text = font_medium.render("准备！", True, (255, 255, 255))
            screen.blit(ready_text, (400 - ready_text.get_width()//2, 350))

        pygame.display.flip()
        clock.tick(60)
```

**过渡动画的时间线**（板书）：

```
时间轴：  0s ────── 0.6s ────── 1.2s ────── 1.8s ────── 2.0s
         │          │           │           │           │
显示内容  只显示     出现        Wave 数字   数字缩回    过渡结束
         Wave       "准备！"    最大        准备消失    游戏继续
```

## 💡 常见问题与解决

### Q1：subsurface 报错 "ValueError: subsurface rectangle outside surface area"

**原因**：你计算的 Rect 超出了父 Surface 的范围。

**解决**：在使用 subsurface 之前做边界限制：

```python
left = max(0, hit_x - radius)
top = max(0, hit_y - radius)
right = min(parent_width, hit_x + radius)
bottom = min(parent_height, hit_y + radius)
safe_rect = pygame.Rect(left, top, right - left, bottom - top)
```

### Q2：掩体被破坏后不显示弹坑

**原因**：可能忘了在 damage 之后重新 draw 掩体。

**解决**：确认掩体在精灵组中，精灵组的 `draw()` 会自动处理。如果自己手动 blit，确保用的是同一个 Surface 对象（subsurface 共享内存，不需要重新 blit）。

### Q3：外星人子弹不会发射

**原因 1**：`alien_shoot_chance` 太小（概率太低）。
- 把值调大试试，比如 0.01。

**原因 2**：没有检查"最下层"外星人。
- 只有下面没有其他外星人的那一排才能发射子弹，否则子弹会被自己人挡住。确保代码中有这个检查。

### Q4：波次切换后外星人不移动

**原因**：新创建的外星人没有加入到 `all_sprites` 精灵组。

**解决**：

```python
aliens = create_aliens(wave)
all_sprites.add(aliens)  # 这行容易忘！
```

### Q5：游戏越来越卡

**原因**：如果有子弹飞出屏幕但没有正确 `kill()`，子弹精灵会无限累积。

**解决**：在 Bullet 类的 `update()` 中检查：

```python
if self.rect.bottom < 0 or self.rect.top > SCREEN_HEIGHT:
    self.kill()  # 离开屏幕就销毁
```
