### 二、核心讲解（25分钟）

#### 步骤1：代码结构优化 —— 提取 `reset_game()` 函数（3分钟）

**教师话术：**

"在加新功能之前，我们先做一个很重要的优化：把初始化数据的代码提取到一个函数里。这样以后需要重新开始游戏时，直接调用这个函数就行，不用写重复代码。"

```python
# 全局变量（先用占位值，在 reset_game() 中赋值）
snake = []
dx = 0
dy = 0
food = []
score = 0
game_over = False

def reset_game():
    """重置游戏到初始状态"""
    global snake, dx, dy, food, score, game_over
    # 蛇的初始位置：3节，横排
    snake = [[400, 300], [380, 300], [360, 300]]
    dx = GRID_SIZE    # 初始向右移动
    dy = 0
    food = generate_food(snake)
    score = 0
    game_over = False

# 程序启动时调用一次
reset_game()
```

**讲解要点：**
- `global` 关键字：在函数内部修改全局变量时必须声明
- 初始方向设为向右（`dx = GRID_SIZE`）
- `game_over` 变量：新增，标记游戏是否结束
- 这样做的好处：按R重新开始时，一行 `reset_game()` 就搞定

#### 步骤2：碰撞墙壁检测（6分钟）

**教师话术：**

"蛇碰到墙壁会死，这个怎么判断呢？很简单，就是判断蛇头的坐标是不是超出了屏幕的边界。"

```python
def check_wall_collision(head):
    """检查蛇头是否碰到墙壁
    参数 head: 蛇头坐标 [x, y]
    返回 True 表示碰撞，False 表示安全"""
    x, y = head[0], head[1]
    # 碰到左墙(x<0) 或 右墙(x>=WIDTH) 或 上墙(y<0) 或 下墙(y>=HEIGHT)
    if x < 0 or x >= WIDTH or y < 0 or y >= HEIGHT:
        return True
    return False

# 更简洁的写法：
def check_wall_collision(head):
    x, y = head
    return x < 0 or x >= WIDTH or y < 0 or y >= HEIGHT
```

**讲解要点（结合图示）：**

```
屏幕范围: x ∈ [0, 780], y ∈ [0, 580]（因为GRID_SIZE=20）

死亡条件（4种，只要满足一个就死）：
┌──────────────────────────────────────┐
│  y < 0  (碰上方)                      │
│                                       │
│  x < 0            x >= WIDTH          │
│  (碰左边)         (碰右边)            │
│                                       │
│  y >= HEIGHT (碰下方)                 │
└──────────────────────────────────────┘
```

> **互动设计：** 让学生口头回答：蛇头坐标 (820, 300) 是碰到哪面墙？（右墙）蛇头坐标 (400, -20) 呢？（上墙）

**在游戏循环中的调用位置：**

```python
# 移动蛇之后，立即检查墙壁碰撞
if check_wall_collision(snake[0]):
    game_over = True
```

#### 步骤3：碰撞自身检测（6分钟）【本节课核心难点】

**教师话术：**

"碰撞墙壁很简单，但碰撞自身就没那么直观了。蛇头要检查的是：自己的坐标是否和身体（从第二节开始）的某个坐标重合了。"

**方法一：列表遍历法（先讲这个，容易理解）**

```python
def check_self_collision(snake):
    """检查蛇头是否碰到自己的身体
    参数 snake: 蛇身列表
    返回 True 表示碰撞，False 表示安全"""
    head = snake[0]          # 蛇头
    body = snake[1:]         # 从第二节开始是身体
    if head in body:
        return True
    return False

# 更简洁的写法：
def check_self_collision(snake):
    return snake[0] in snake[1:]
```

**方法二：Rect坐标转换 + collidelist（进阶方法）**

> 先讲方法一，确保理解；方法二作为进阶内容展示。

```python
def check_self_collision(snake):
    """使用 Rect 进行碰撞检测"""
    # 将蛇头转换为 Rect 对象
    head_rect = pygame.Rect(snake[0][0], snake[0][1], GRID_SIZE, GRID_SIZE)
    # 将身体每一节都转换为 Rect 对象
    body_rects = []
    for segment in snake[1:]:
        rect = pygame.Rect(segment[0], segment[1], GRID_SIZE, GRID_SIZE)
        body_rects.append(rect)
    # collidelist 返回第一个碰撞的索引，如果没有碰撞返回 -1
    if head_rect.collidelist(body_rects) != -1:
        return True
    return False
```

**讲解要点：**
- `snake[1:]` 是列表切片，从索引 1（第二节）开始一直到末尾
- `head in body` 利用 Python 列表的 `in` 运算符判断坐标是否在身体中
- `Rect.collidelist()` 是 Pygame 提供的高效碰撞检测方法，返回 -1 表示没有碰撞

> **类比讲解：** "`head in body` 就像点名 —— 在身体这个大名单里，有没有一个坐标和蛇头一模一样？有就说明撞到了。"

**在游戏循环中的调用位置：**

```python
# 检查完墙壁后，继续检查自身碰撞
if check_wall_collision(snake[0]) or check_self_collision(snake):
    game_over = True
```

#### 步骤4：分数面板显示（5分钟）

**教师话术：**

"游戏结束了要有提示，玩游戏的时候也要看得到分数。这些文字信息怎么显示在屏幕上呢？Pygame 有专门的方法。"

```python
# 初始化字体（放在程序开头，只创建一次）
font = pygame.font.SysFont("simhei", 32)      # 普通字体
big_font = pygame.font.SysFont("simhei", 60)   # 大字体（用于游戏结束提示）

# 在绘制部分显示分数
def draw_score(screen, score):
    """在屏幕左上角显示分数"""
    score_text = font.render(f"分数: {score}", True, WHITE)
    screen.blit(score_text, (10, 10))

def draw_game_over(screen):
    """显示游戏结束画面"""
    # 半透明黑色遮罩
    overlay = pygame.Surface((WIDTH, HEIGHT))
    overlay.set_alpha(128)   # 128 = 半透明 (0~255)
    overlay.fill(BLACK)
    screen.blit(overlay, (0, 0))

    # "游戏结束" 大字提示
    text1 = big_font.render("游戏结束", True, RED)
    # 居中显示的核心技巧：获取文字的矩形，设置其中心为屏幕中心
    text1_rect = text1.get_rect(center=(WIDTH // 2, HEIGHT // 2 - 50))
    screen.blit(text1, text1_rect)

    # 最终得分
    text2 = font.render(f"最终得分: {score}", True, WHITE)
    text2_rect = text2.get_rect(center=(WIDTH // 2, HEIGHT // 2 + 20))
    screen.blit(text2, text2_rect)

    # 重新开始提示
    text3 = font.render("按 R 键重新开始", True, GREEN)
    text3_rect = text3.get_rect(center=(WIDTH // 2, HEIGHT // 2 + 70))
    screen.blit(text3, text3_rect)
```

**居中显示的核心技巧（重点讲解）：**

```python
# 让文字在屏幕正中间显示，分两步：
# 1. render() — 把文字渲染成Surface图片
text_surface = font.render("你好", True, WHITE)

# 2. get_rect(center=(x, y)) — 获取文字的矩形，
#    并直接把矩形的中心点定位到目标坐标
text_rect = text_surface.get_rect(center=(WIDTH // 2, HEIGHT // 2))

# 3. blit() — 把文字画到屏幕上
screen.blit(text_surface, text_rect)
```

> **类比讲解：** "`get_rect(center=...)` 就像一个自动计算的便利贴 —— 你告诉它贴在哪里，它自动帮你算好左上角的位置，不用你自己去算文字的宽高。"

**在游戏循环中的绘制逻辑（完整结构）：**

```python
# 绘制画面
screen.fill(BLACK)

# 画食物
pygame.draw.rect(screen, RED, (food[0], food[1], GRID_SIZE, GRID_SIZE))

# 画蛇
for i, segment in enumerate(snake):
    color = GREEN if i == 0 else DARK_GREEN
    pygame.draw.rect(screen, color, (segment[0], segment[1], GRID_SIZE, GRID_SIZE))

# 画分数（总是显示）
draw_score(screen, score)

# 如果游戏结束，显示结束画面
if game_over:
    draw_game_over(screen)

pygame.display.flip()
```

#### 步骤5：重新开始功能（2分钟）

**教师话术：**

"游戏结束后，我们希望按R键就能重新开始。怎么做呢？只需要在事件循环里监听R键，然后调用我们的 `reset_game()` 函数就好！"

```python
# 在事件循环中添加
elif event.type == pygame.KEYDOWN:
    # ... 原来的方向键处理 ...

    # 按R键重新开始（只在游戏结束时有效）
    if event.key == pygame.K_R and game_over:
        reset_game()
```

**讲解要点：**
- 只在 `game_over == True` 时才响应R键，避免游戏中误按
- `reset_game()` 一调用，所有状态回归初始，游戏重新开始

#### 步骤7：游戏循环的完整结构（2分钟）

```python
reset_game()   # 初始状态

running = True
while running:
    # ① 事件处理
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        elif event.type == pygame.KEYDOWN:
            if not game_over:
                # 方向键（游戏进行中才响应）
                if event.key == pygame.K_UP and dy == 0:
                    dx, dy = 0, -GRID_SIZE
                elif event.key == pygame.K_DOWN and dy == 0:
                    dx, dy = 0, GRID_SIZE
                elif event.key == pygame.K_LEFT and dx == 0:
                    dx, dy = -GRID_SIZE, 0
                elif event.key == pygame.K_RIGHT and dx == 0:
                    dx, dy = GRID_SIZE, 0
            # R键重新开始（任何时候都可以按）
            if event.key == pygame.K_r and game_over:
                reset_game()

    # ② 游戏逻辑（只在游戏进行中执行）
    if not game_over:
        # 移动蛇
        new_head = [snake[0][0] + dx, snake[0][1] + dy]
        snake.insert(0, new_head)

        # 检查食物
        if snake[0] == food:
            food = generate_food(snake)
            score += 10
        else:
            snake.pop()

        # 检查碰撞
        if check_wall_collision(snake[0]) or check_self_collision(snake):
            game_over = True

    # ③ 绘制画面（无论是否结束都要画）
    screen.fill(BLACK)
    pygame.draw.rect(screen, RED, (food[0], food[1], GRID_SIZE, GRID_SIZE))
    for i, segment in enumerate(snake):
        color = GREEN if i == 0 else DARK_GREEN
        pygame.draw.rect(screen, color, (segment[0], segment[1], GRID_SIZE, GRID_SIZE))
    draw_score(screen, score)
    if game_over:
        draw_game_over(screen)
    pygame.display.flip()

    clock.tick(FPS)

pygame.quit()
```

## 💡 常见问题与解决

- **问题1：蛇走到边缘没死**
  → 检查 `check_wall_collision` 的边界条件。注意 `x >= WIDTH` 要包含等于号，因为蛇的坐标从0开始，最大是 `WIDTH - GRID_SIZE = 780`，坐标800已经出界。

- **问题2：蛇永远不会撞到自己**
  → 检查 `check_self_collision` 是否在蛇移动之后才调用。必须先 `insert(0, new_head)`，再判断 `snake[0] in snake[1:]`。

- **问题3：游戏结束后蛇还在动**
  → 检查游戏逻辑是否放在 `if not game_over:` 条件块内。

- **问题4：游戏结束后按方向键，游戏就重新开始了**
  → 方向键处理也要加 `if not game_over:` 条件判断。

- **问题5：文字不显示（或显示乱码）**
  → 检查字体名称是否正确。Windows用 `"simhei"` 或 `"microsoft yahei"`，Mac用 `"pingfang"` 或 `"stheitilight"`。可以先用 `pygame.font.get_default_font()` 测试。

- **问题6：按R键没有重新开始**
  → 检查R键的判断条件：是否在 `event.type == pygame.KEYDOWN` 分支内？按键名是 `pygame.K_r`（小写r）。

- **问题7：重新开始后，分数没有归零**
  → 检查 `reset_game()` 中是否写了 `score = 0`，以及是否用了 `global score`。

- **问题8：`Rect.collidelist()` 报错 "argument must be a sequence of rectstyle objects"**
  → `collidelist()` 的参数必须是一个列表，列表中每个元素都是 `Rect` 对象。检查是否把所有身体段都转换成了 `Rect`。
