### 二、核心讲解（25分钟）——双人按键处理、球拍碰撞角度变化、出界得分

#### 2.1 双玩家输入处理（8分钟）

**知识点1：`pygame.key.get_pressed()`**
```python
keys = pygame.key.get_pressed()
if keys[pygame.K_w]:
    left_paddle_y -= paddle_speed
if keys[pygame.K_s]:
    left_paddle_y += paddle_speed
if keys[pygame.K_UP]:
    right_paddle_y -= paddle_speed
if keys[pygame.K_DOWN]:
    right_paddle_y += paddle_speed
```

**讲解要点：**
- `get_pressed()` 返回所有按键状态的元组，支持同时按下多个键
- 与 `KEYDOWN` 事件的区别：`get_pressed()` 适合持续移动（按住就持续执行），`KEYDOWN` 适合单次触发（如跳跃）
- 两套按键互不干扰：W/S 只控制左球拍，↑↓ 只控制右球拍

**边界限制（防止球拍移出屏幕）：**
```python
# 限制左球拍不超出上下边界
if left_paddle.top < 0:
    left_paddle.top = 0
if left_paddle.bottom > HEIGHT:
    left_paddle.bottom = HEIGHT
```

> **教学互动**：让学生思考——"如果不加边界限制会怎样？"

#### 2.2 球拍与球碰撞 —— 根据击球位置改变反弹角度（10分钟）

**知识点2：碰撞检测**
```python
if ball.colliderect(paddle):
    ball_speed_x = -ball_speed_x  # 水平方向反转
```

**知识点3：击球位置影响反弹角度（本课核心）**

要让游戏更有趣，不能永远是45°反弹。需要根据球拍上被击中的位置来调整角度。

**物理模型：**
- 将球拍沿垂直方向分为多个区域
- 球击中球拍上半部分 → 球向上弹（speed_y 为负）
- 球击中球拍中央 → 球水平反弹（speed_y ≈ 0）
- 球击中球拍下半部分 → 球向下弹（speed_y 为正）

**实现方式：**
```python
# 计算球心与球拍中心的相对偏移（归一化到 -1 到 1）
offset_y = (ball.centery - paddle.centery) / (paddle.height / 2)
# offset_y:  -1 = 球拍顶部, 0 = 中心, 1 = 球拍底部
ball_speed_y = int(offset_y * MAX_BOUNCE_SPEED)
ball_speed_x = -ball_speed_x  # 水平方向始终反转
```

| 击中位置 | offset_y 范围 | 效果 |
|---------|-------------|------|
| 球拍顶部 | -1.0 ~ -0.5 | 大角度向上 |
| 球拍中上部 | -0.5 ~ 0 | 小角度向上 |
| 球拍正中 | ≈ 0 | 接近水平 |
| 球拍中下部 | 0 ~ 0.5 | 小角度向下 |
| 球拍底部 | 0.5 ~ 1.0 | 大角度向下 |

> **类比说明**：就像打乒乓球，球拍角度不同，回球方向就不同。球拍的"边缘"比"中心"产生更大的角度变化。

#### 2.3 出界判定与得分机制（7分钟）

**知识点4：出界判定**
```python
if ball.left <= 0:      # 球越过左边界
    right_score += 1     # 右方得分
    reset_ball()         # 重新发球
if ball.right >= WIDTH: # 球越过右边界
    left_score += 1      # 左方得分
    reset_ball()
```

**重新发球逻辑：**
```python
def reset_ball():
    ball.center = (WIDTH // 2, HEIGHT // 2)
    ball_speed_x *= random.choice([-1, 1])  # 随机方向
    ball_speed_y = random.choice([-4, 4])   # 随机上下
```

**知识点5：文字渲染**
```python
font = pygame.font.Font(None, 36)
left_text = font.render(str(left_score), True, WHITE)
screen.blit(left_text, (WIDTH // 4, 20))
```

`pygame.font.Font(None, 36)` 中 `None` 表示使用系统默认字体。

### 四、总结与作业（5分钟）

**知识回顾：**

| 知识点 | 核心代码 |
|--------|---------|
| 双玩家输入 | `pygame.key.get_pressed()` + 不同按键绑定 |
| 碰撞检测 | `rect.colliderect()` |
| 角度变化 | `offset_y * 系数` 根据击球位置调整 |
| 出界得分 | 判断 `ball.left` / `ball.right` 与边界关系 |
| 文字渲染 | `font.render()` + `screen.blit()` |

**常见错误回顾：**
- 忘记限制球拍边界 → 球拍飞出屏幕
- 出界方向与得分方搞反 → 自己出界给对方加分
- 碰撞后忘了 `-ball_speed_x` → 球直接穿过球拍
- `offset_y` 没有归一化 → 角度变化幅度失控

**课后作业：**
1. **必做**：为游戏添加一个"胜利条件"——先得5分的玩家获胜，显示"玩家X获胜！"
2. **选做**：将球拍的 W/S 控制改为 A/Z 控制，观察代码需要修改哪些地方
3. **挑战**：让球的速度随着回合数逐渐加快

## 💡 常见问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 球拍移出屏幕 | 未限制 `top` / `bottom` 边界 | 添加边界判断 |
| 两个球拍同时动不了 | `if`/`elif` 套用错误 | 使用独立 `if`，不要用 `elif` |
| 球穿过球拍 | 球速太快，跨越了球拍 | 降低球速，或每帧多次检测 |
| 角度变化不明显 | `offset_y` 乘的系数太小 | 增大 `MAX_BOUNCE_SPEED` |
| 显示不了中文 | 默认字体不支持中文 | 使用中文字体文件或仅用数字 |
