### 二、核心讲解（25分钟）

#### 2.1 第一步：倒计时系统（7分钟）

**知识点**：`pygame.time.get_ticks()` 获取游戏运行的毫秒数。

> "Pygame 内部有一个毫秒计时器，从 `pygame.init()` 那一刻就开始不停地数。`get_ticks()` 会返回从初始化到现在的总毫秒数。我们只要保存游戏开始时刻的毫秒数，然后不断计算差值，就能知道过了多少秒。"

**核心思路**：

```
游戏时长 = 30 秒 = 30000 毫秒
开始时刻 = pygame.time.get_ticks()   ← 游戏循环开始前记录
已过时间 = pygame.time.get_ticks() - 开始时刻   ← 每帧都在变
剩余时间 = 30000 - 已过时间
剩余秒数 = 剩余时间 // 1000   ← 整除 1000 得到秒数
```

**代码示例**：

```python
# --- 游戏配置 ---
GAME_DURATION = 30  # 游戏时长（秒）

# --- 游戏开始时记录起始时刻 ---
start_ticks = pygame.time.get_ticks()  # 记录游戏开始的毫秒数

# --- 主循环中计算剩余时间 ---
running = True
while running:
    # 计算已经过了多少毫秒
    elapsed_ms = pygame.time.get_ticks() - start_ticks
    # 计算剩余秒数
    remaining_seconds = GAME_DURATION - elapsed_ms // 1000

    # 时间到了，游戏结束
    if remaining_seconds <= 0:
        remaining_seconds = 0
        game_over = True

    # --- 绘制倒计时文字 ---
    # 创建字体对象
    font = pygame.font.Font(None, 48)  # None 表示使用默认字体，48 是字号
    # 渲染文字表面（文字、抗锯齿、颜色）
    timer_text = font.render(f"剩余时间: {remaining_seconds} 秒", True, (255, 255, 255))
    # 把文字画到屏幕上
    screen.blit(timer_text, (20, 20))
```

**讲解要点**：
- `get_ticks()` 返回的是毫秒，除以 1000 才是秒。
- 每次循环都要重新计算剩余时间，这样才能实时更新。
- 文字渲染三步走：创建 Font → render 文字 → blit 到屏幕。
- `None` 作为字体名表示使用 Pygame 的默认字体，简单省事。

#### 2.2 第二步：计分系统（6分钟）

**知识点**：打中加分、空点扣分、分数显示。

> "有了倒计时，我们再加入计分。打中一只地鼠 +10 分，但如果点空了（点到没有地鼠的地方）要 -5 分——这样就不能乱点了！"

**代码示例**：

```python
# --- 初始化分数 ---
score = 0

# --- 鼠标点击处理 ---
for event in pygame.event.get():
    if event.type == pygame.MOUSEBUTTONDOWN:
        mouse_x, mouse_y = event.pos
        hit = False  # 标记这次点击有没有打中地鼠

        # 检查是否点中了有地鼠的洞
        if current_mole != -1:
            mole_rect = holes[current_mole]
            if mole_rect.collidepoint(mouse_x, mouse_y):
                score += 10  # 打中加分！
                current_mole = -1  # 地鼠缩回去
                hit = True

        # 如果没打中——但点在了任意一个洞口上，算"空点"
        if not hit:
            for hole_rect in holes:
                if hole_rect.collidepoint(mouse_x, mouse_y):
                    score -= 5  # 空点扣分！
                    break  # 只扣一次

# --- 绘制分数 ---
score_text = font.render(f"分数: {score}", True, (255, 255, 0))
screen.blit(score_text, (600, 20))  # 放在右上角
```

**讲解要点**：
- 用一个 `hit` 标志来区分"打中"和"空点"两种情况。
- 空点检查需要遍历所有洞口，因为玩家可能点任意一个洞口。
- 分数可能是负数——没关系，这说明手太抖了！
- 进阶：可以加入"combo"机制——连续打中加分递增。

#### 2.3 第三步：难度分级（6分钟）

**知识点**：通过 `set_timer()` 的间隔参数控制地鼠出现频率。

> "简单模式下地鼠换得慢，困难模式下地鼠换得快。其实改一个数字就行——`set_timer()` 的间隔时间！"

**难度设计**：

| 难度 | 地鼠换洞间隔 | 说明 |
|------|-------------|------|
| 简单 (Easy) | 1200ms (1.2秒) | 悠闲模式，适合新手 |
| 普通 (Normal) | 800ms (0.8秒) | 标准节奏 |
| 困难 (Hard) | 500ms (0.5秒) | 手速大考验！ |

**代码示例**：

```python
# --- 难度配置 ---
DIFFICULTY = {
    "简单": {"interval": 1200, "label": "简单"},
    "普通": {"interval": 800,  "label": "普通"},
    "困难": {"interval": 500,  "label": "困难"},
}

# --- 选择难度（游戏开始前） ---
current_difficulty = "普通"  # 默认难度

# --- 根据难度设置定时器 ---
def set_difficulty(level):
    """切换难度，重新设置定时器间隔"""
    global current_difficulty
    current_difficulty = level
    interval = DIFFICULTY[level]["interval"]
    # 重新设置定时器——新的间隔生效
    pygame.time.set_timer(MOLE_CHANGE_EVENT, interval)

# 初始化时设置默认难度
set_difficulty("普通")
```

**难度选择的交互方式**（简单版）：

```python
# --- 绘制难度选择按钮 ---
def draw_difficulty_buttons():
    """在屏幕顶部绘制三个难度按钮"""
    button_font = pygame.font.Font(None, 36)
    buttons = []
    x_start = 250  # 第一个按钮的 x 坐标

    for i, (name, config) in enumerate(DIFFICULTY.items()):
        x = x_start + i * 120
        y = 70
        btn_rect = pygame.Rect(x, y, 100, 40)

        # 当前选中的难度用亮色，其他用暗色
        color = (0, 200, 0) if name == current_difficulty else (100, 100, 100)
        pygame.draw.rect(screen, color, btn_rect, border_radius=5)
        pygame.draw.rect(screen, (255, 255, 255), btn_rect, 2, border_radius=5)

        text = button_font.render(name, True, (255, 255, 255))
        text_rect = text.get_rect(center=btn_rect.center)
        screen.blit(text, text_rect)

        buttons.append((btn_rect, name))

    return buttons
```

**讲解要点**：
- 难度变化的核心是修改 `set_timer()` 的毫秒参数。
- 困难模式不只是"地鼠更快"，实际上更考验反应速度和鼠标精准度。
- 可以引导学生思考：如果地鼠换得太快了（比如 200ms），游戏会变得怎样？（几乎不可能打到，反而不好玩了）

#### 2.4 第四步：Game Over 画面（6分钟）

**知识点**：游戏状态管理、条件渲染、重新开始逻辑。

> "30 秒到了，游戏结束！我们要显示最终得分，还要让玩家可以重新开始。"

**状态管理**：

```
游戏有三种状态：
  "menu"      → 开始画面（选择难度）
  "playing"   → 游戏中
  "gameover"  → 游戏结束
```

**代码示例**：

```python
# --- 游戏状态 ---
game_state = "menu"  # 初始状态：菜单

# --- 主循环结构 ---
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        # --- 菜单状态：处理难度选择 ---
        if game_state == "menu":
            if event.type == pygame.MOUSEBUTTONDOWN:
                # 检查点击了哪个难度按钮
                for btn_rect, name in difficulty_buttons:
                    if btn_rect.collidepoint(event.pos):
                        set_difficulty(name)
                # 检查点击了"开始游戏"按钮
                if start_button_rect.collidepoint(event.pos):
                    game_state = "playing"
                    start_ticks = pygame.time.get_ticks()
                    score = 0

        # --- 游戏中状态：处理打地鼠 ---
        elif game_state == "playing":
            if event.type == MOLE_CHANGE_EVENT:
                spawn_mole()
            elif event.type == pygame.MOUSEBUTTONDOWN:
                # ... 计分逻辑 ...

        # --- Game Over 状态：处理重新开始 ---
        elif game_state == "gameover":
            if event.type == pygame.MOUSEBUTTONDOWN:
                if restart_button_rect.collidepoint(event.pos):
                    game_state = "menu"  # 回到菜单
            # 也可以按 R 键重新开始
            if event.type == pygame.KEYDOWN:
                if event.key == pygame.K_r:
                    game_state = "menu"

    # --- 根据状态绘制不同画面 ---
    if game_state == "menu":
        draw_menu()       # 画菜单
    elif game_state == "playing":
        draw_game()       # 画游戏画面
        # 检查时间是否到了
        if remaining_seconds <= 0:
            game_state = "gameover"
    elif game_state == "gameover":
        draw_gameover()   # 画结束画面

    pygame.display.flip()
```

**Game Over 画面绘制**：

```python
def draw_gameover():
    """绘制游戏结束画面"""
    # 半透明黑色遮罩覆盖整个窗口
    overlay = pygame.Surface((800, 600))
    overlay.set_alpha(180)  # 透明度 180/255
    overlay.fill((0, 0, 0))
    screen.blit(overlay, (0, 0))

    # 大标题"游戏结束"
    big_font = pygame.font.Font(None, 80)
    title = big_font.render("游戏结束!", True, (255, 80, 80))
    title_rect = title.get_rect(center=(400, 200))
    screen.blit(title, title_rect)

    # 最终得分
    score_font = pygame.font.Font(None, 60)
    score_text = score_font.render(f"最终得分: {score}", True, (255, 255, 0))
    score_rect = score_text.get_rect(center=(400, 300))
    screen.blit(score_text, score_rect)

    # 难度信息
    diff_font = pygame.font.Font(None, 40)
    diff_text = diff_font.render(f"难度: {current_difficulty}", True, (200, 200, 200))
    diff_rect = diff_text.get_rect(center=(400, 360))
    screen.blit(diff_text, diff_rect)

    # 重新开始按钮
    restart_btn = pygame.Rect(300, 430, 200, 60)
    pygame.draw.rect(screen, (0, 150, 0), restart_btn, border_radius=10)
    pygame.draw.rect(screen, (255, 255, 255), restart_btn, 3, border_radius=10)
    restart_text = score_font.render("再来一局", True, (255, 255, 255))
    restart_text_rect = restart_text.get_rect(center=restart_btn.center)
    screen.blit(restart_text, restart_text_rect)

    return restart_btn  # 返回按钮 Rect，用于点击检测
```

**讲解要点**：
- 用 `game_state` 变量管理游戏处于哪个阶段，不同阶段画不同内容、处理不同事件。
- 这是"状态机"思想的简单应用——以后做更复杂的游戏也会用到。
- `Surface.set_alpha()` 可以做出半透明遮罩效果，让 Game Over 画面看起来像弹窗。
- 重新开始时要把所有变量重置（分数归零、计时器重置等）。

## 常见问题与解决

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 倒计时不变化 | 没有每帧重新计算 `get_ticks()` | 把计算放在 `while running` 循环内 |
| 倒计时跳着走（如 30、28、26） | 用了 `pygame.time.wait()` 导致帧率不稳定 | 用 `clock.tick(60)` 控制帧率 |
| 点重新开始后分数没清零 | 忘记重置 `score = 0` | 重新开始时重置所有相关变量 |
| 难度切换后地鼠速度没变 | 只改了变量，没重新调用 `set_timer()` | 切换难度时调用 `pygame.time.set_timer()` |
| Game Over 画面闪一下就没了 | 没有阻止游戏逻辑继续执行 | 用 `game_state` 判断，gameover 时跳过游戏逻辑 |
| 按钮点不动 | Rect 坐标和绘制位置不一致 | 用 `get_rect(center=...)` 确保绘制位置和碰撞检测使用同一个 Rect |
