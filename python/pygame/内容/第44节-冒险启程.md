### 二、核心讲解一：字典与升级系统（10分钟）

#### 2.1 角色属性字典（3分钟）

```python
# 旧方式（多个变量，难管理）
player_hp = 100
player_max_hp = 100
player_atk = 15
player_def = 5
player_exp = 0
player_level = 1
# ... 变量越来越多，传参也会很麻烦

# 新方式：一个字典管理一切
player = {
    "hp": 100,       # 当前血量
    "max_hp": 100,   # 最大血量（升级会增长）
    "mp": 50,        # 魔法值
    "max_mp": 50,    # 最大魔法值
    "atk": 15,       # 攻击力
    "def": 5,        # 防御力
    "exp": 0,        # 经验值
    "level": 1,      # 等级
    "gold": 0        # 金币
}
```

**讲解要点**：
- 字典键值对 → 属性名和属性值一一对应
- 代码可读性好：`player["hp"]` 比 `player_hp` 更明确
- 方便批量操作：循环遍历字典修改属性，比如升级时所有属性自动增长
- 方便保存：`json.dump(player, f)` 一行代码存档

#### 2.2 经验值与升级系统（5分钟）

**经验曲线公式**：

```python
# 计算升至下一级所需经验
def exp_to_next_level(level):
    return level * 50  # 1→2: 50, 2→3: 100, 3→4: 150...

# 获取经验后检查升级
def gain_exp(amount):
    player["exp"] += amount
    needed = exp_to_next_level(player["level"])
    while player["exp"] >= needed:
        level_up()
        player["exp"] -= needed
        needed = exp_to_next_level(player["level"])
```

**升级属性增长**：

```python
def level_up():
    player["level"] += 1
    player["max_hp"] += 20   # 最大血量+20
    player["max_mp"] += 10   # 最大魔法+10
    player["atk"] += 5       # 攻击+5
    player["def"] += 3       # 防御+3
    # 升级时满血满蓝！
    player["hp"] = player["max_hp"]
    player["mp"] = player["max_mp"]
    print(f"🎉 升级！当前等级：{player['level']} 级")
```

**教学提示**：可以用 `while` 循环处理连续升级（经验值可能一次升好几级）。

### 三、核心讲解二：背包与存档（10分钟）

#### 3.1 背包/物品系统设计（6分钟）

**物品用字典表示**：

```python
# 物品模板库（所有可获得的物品）
ITEMS = {
    "生命药水": {"type": "恢复", "effect": "hp", "value": 30, "desc": "恢复30点生命"},
    "魔法药水": {"type": "恢复", "effect": "mp", "value": 20, "desc": "恢复20点魔法"},
    "攻击卷轴": {"type": "增益", "effect": "atk", "value": 5,  "desc": "本场战斗攻击+5"},
}

# 背包是一个列表，存储拥有的物品
inventory = []  # 初始空背包
```

**背包操作**：

```python
# 获得物品
def add_item(item_name):
    inventory.append(item_name)
    print(f"获得了 [{item_name}] ！")

# 使用物品
def use_item(index):
    if index >= len(inventory):
        return "背包格子是空的"
    item_name = inventory[index]
    item_info = ITEMS[item_name]
    if item_info["effect"] == "hp":
        player["hp"] = min(player["hp"] + item_info["value"], player["max_hp"])
    elif item_info["effect"] == "mp":
        player["mp"] = min(player["mp"] + item_info["value"], player["max_mp"])
    # ... 其他效果
    inventory.pop(index)  # 使用后移除
    print(f"使用了 [{item_name}]！")
```

**关键讲解**：
- 背包是玩家的附属数据，和 `player` 字典分开管理
- 用列表存储物品名称（轻量），需要信息时查 `ITEMS` 字典（分离数据与模板）
- 物品"使用"后要从列表中移除 → `.pop(index)` 或 `.remove()`

#### 3.2 JSON 存档读写（选学，4分钟）

```python
import json

# 存档（将所有数据合并成一个字典，写入文件）
def save_game():
    data = {
        "player": player,
        "inventory": inventory
    }
    with open("save.json", "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
    print("存档成功！")

# 读档（从文件读取，恢复到游戏数据）
def load_game():
    global player, inventory
    with open("save.json", "r", encoding="utf-8") as f:
        data = json.load(f)
    player = data["player"]
    inventory = data["inventory"]
    print("读档成功！")
```

**讲解要点**：
- `json.dump()`：Python 字典 → JSON 字符串 → 写入文件
- `json.load()`：读取文件 → JSON 字符串 → Python 字典
- `ensure_ascii=False`：允许保存中文
- `indent=2`：让文件内容有缩进，方便人类阅读

**为什么能用 JSON？**
因为我们的 `player` 和 `inventory` 都是字典/列表结构，JSON 天然支持这些数据类型。这也是用字典管理数据的另一个优势！

## 💡 常见问题与解决

| 问题 | 原因 | 解决 |
|------|------|------|
| 升级后血量没回满 | 只改了 `hp` 没考虑上限 | `player["hp"] = player["max_hp"]` |
| 使用物品后血量超过上限 | 直接 `hp += 30` | 用 `min(hp + 30, max_hp)` 截断 |
| JSON 保存报错 | `player` 变量在函数内是局部的 | 使用 `global` 声明或在类中处理 |
| 背包索引越界 | 点了空背包格子 | 使用前检查 `if index < len(inventory)` |
| 连续升级跳过了经验 | 用 `if` 而不是 `while` | 升级后用 `while` 循环继续检查 |
| 升级后经验值被吞掉 | 没减去已用经验 | `player["exp"] -= 所需经验` |
