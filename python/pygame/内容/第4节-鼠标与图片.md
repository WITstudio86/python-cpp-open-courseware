### 二、核心讲解（25分钟）

#### 2.1 认识 Surface——Pygame 的"画布"（5分钟）

在 Pygame 中，**一切可见的东西都是 Surface**。可以把 Surface 理解成一张"透明的塑料卡片"：

- 游戏窗口本身就是一个大 Surface（`screen`）
- 每一张图片、每一个用 draw 画出来的图案，都存在于某个 Surface 上
- 我们通过 `blit()` 把一张小卡片"贴"到大卡片上

```python
import pygame
pygame.init()

screen = pygame.display.set_mode((800, 600))  # 大卡片：游戏窗口
pygame.display.set_caption("我的游戏")

# 创建一张小卡片：200x200 的 Surface
my_surface = pygame.Surface((200, 200))
```

**比喻**：就像做手工一样，`screen` 是最大的那张背景纸，`Surface` 是我们剪下来的小纸片。画好小纸片后，用胶水（`blit`）把它粘到大背景纸上。

#### 2.2 用代码"画"出角色——pygame.draw 家族（8分钟）

既然这节课不依赖外部图片文件，我们就要学会**用代码画画**！Pygame 提供了丰富的绘图函数，全部在 `pygame.draw` 模块中：

| 函数 | 用途 | 示例 |
|------|------|------|
| `pygame.draw.circle()` | 画圆形 | 脸蛋、眼睛 |
| `pygame.draw.rect()` | 画矩形 | 身体、方框 |
| `pygame.draw.ellipse()` | 画椭圆 | 眼睛、气泡 |
| `pygame.draw.line()` | 画线段 | 嘴巴、头发 |
| `pygame.draw.arc()` | 画弧线 | 微笑的嘴巴 |
| `pygame.draw.polygon()` | 画多边形 | 星星、三角形 |

**画一个笑脸角色——完整代码**：

```python
import pygame

def create_smiley_face(size=150):
    """创建一个可爱的笑脸角色，返回一个 Surface 对象"""

    # 创建一张正方形的"画纸"
    face = pygame.Surface((size, size), pygame.SRCALPHA)
    # pygame.SRCALPHA 让这张画纸支持透明背景，这样贴到屏幕上时才不会有一块白色方块

    # 确定中心点和半径
    center_x = size // 2
    center_y = size // 2
    radius = size // 2 - 10  # 留一点边距

    # 1. 画脸蛋（黄色大圆）
    pygame.draw.circle(face, (255, 223, 0), (center_x, center_y), radius)
    # 加一圈黑色边框，更可爱！
    pygame.draw.circle(face, (0, 0, 0), (center_x, center_y), radius, 3)

    # 2. 画左眼（白色眼白 + 黑色眼珠）
    eye_radius = radius // 4
    left_eye_x = center_x - radius // 3
    eye_y = center_y - radius // 4

    # 眼白
    pygame.draw.circle(face, (255, 255, 255), (left_eye_x, eye_y), eye_radius)
    pygame.draw.circle(face, (0, 0, 0), (left_eye_x, eye_y), eye_radius, 2)
    # 眼珠
    pygame.draw.circle(face, (0, 0, 0), (left_eye_x, eye_y), eye_radius // 3)

    # 3. 画右眼
    right_eye_x = center_x + radius // 3
    pygame.draw.circle(face, (255, 255, 255), (right_eye_x, eye_y), eye_radius)
    pygame.draw.circle(face, (0, 0, 0), (right_eye_x, eye_y), eye_radius, 2)
    pygame.draw.circle(face, (0, 0, 0), (right_eye_x, eye_y), eye_radius // 3)

    # 4. 画微笑的嘴巴（用弧线）
    mouth_rect = pygame.Rect(
        center_x - radius // 2,
        center_y - radius // 6,
        radius,
        radius // 2
    )
    # arc 画弧线：从 π/4 到 3π/4（一个弯弯的弧）
    import math
    pygame.draw.arc(face, (0, 0, 0), mouth_rect,
                    math.pi / 4, math.pi * 3 / 4, 3)

    # 5. 画两个小红脸蛋（腮红）
    blush_radius = radius // 6
    pygame.draw.circle(face, (255, 150, 150),
                       (left_eye_x - radius // 6, eye_y + radius // 3),
                       blush_radius)
    pygame.draw.circle(face, (255, 150, 150),
                       (right_eye_x + radius // 6, eye_y + radius // 3),
                       blush_radius)

    return face
```

**重点讲解**：
- `pygame.SRCALPHA`：这个参数很关键，它让 Surface 支持**透明通道**。如果没有它，笑脸背后会有一个白色方块，看起来就不自然了。
- 坐标计算：所有位置都是用比例算出来的（比如 `radius // 3`），这样不管画多大尺寸的笑脸，五官比例都不会乱。
- `pygame.draw.arc()` 中的弧度：用 `math.pi` 来表示角度。`π` 是180度，`π/4` 是45度。

**扩展：画一颗星星**（如果学生进度快，可以额外挑战）：

```python
import math

def create_star(size=150, color=(255, 215, 0)):
    """创建一个五角星"""
    star = pygame.Surface((size, size), pygame.SRCALPHA)
    center = size // 2
    outer_r = size // 2 - 10   # 外顶点到中心距离
    inner_r = outer_r // 2      # 内顶点到中心距离

    points = []
    for i in range(5):
        # 外顶点角度
        outer_angle = math.radians(-90 + i * 72)
        outer_x = center + outer_r * math.cos(outer_angle)
        outer_y = center + outer_r * math.sin(outer_angle)
        points.append((outer_x, outer_y))

        # 内顶点角度（偏移36度）
        inner_angle = math.radians(-90 + 36 + i * 72)
        inner_x = center + inner_r * math.cos(inner_angle)
        inner_y = center + inner_r * math.sin(inner_angle)
        points.append((inner_x, inner_y))

    pygame.draw.polygon(star, color, points)
    pygame.draw.polygon(star, (0, 0, 0), points, 3)  # 边框
    return star
```

#### 2.3 加载外部图片——image.load() 与 blit()（5分钟）

虽然我们本节课重点是自己画角色，但在实际游戏开发中，加载外部图片也很常用。

**加载图片**：

```python
# 加载一张图片
player_img = pygame.image.load("player.png")
```

**注意事项**：
- 图片文件必须放在和 Python 脚本**同一个文件夹**下（或者写上完整的路径）
- 支持的格式：PNG（推荐，支持透明）、JPG、BMP、GIF 等

**显示图片——blit()**：

```python
screen.blit(图片Surface, (x坐标, y坐标))
```

`blit` 是 "Block Image Transfer" 的缩写，可以理解为"把图片贴到屏幕上"。第一个参数是要贴的 Surface，第二个参数是贴在哪个位置。

```python
# 在屏幕左上角(0, 0)位置显示图片
screen.blit(player_img, (0, 0))

# 让图片居中显示
img_width = player_img.get_width()
img_height = player_img.get_height()
screen.blit(player_img, (400 - img_width // 2, 300 - img_height // 2))
```

#### 2.4 鼠标事件——让角色跟鼠标互动（5分钟）

Pygame 中有两种常用的鼠标事件：

| 事件类型 | 含义 | 什么时候触发 |
|----------|------|-------------|
| `pygame.MOUSEMOTION` | 鼠标移动 | 鼠标在窗口中移动时 |
| `pygame.MOUSEBUTTONDOWN` | 鼠标按下 | 按下鼠标任意按键时 |

**获取鼠标位置**：

```python
for event in pygame.event.get():
    if event.type == pygame.MOUSEMOTION:
        # event.pos 是一个元组 (x, y)，记录鼠标当前的位置
        mouse_x, mouse_y = event.pos
        print(f"鼠标移动到了 ({mouse_x}, {mouse_y})")

    if event.type == pygame.MOUSEBUTTONDOWN:
        # event.button 表示按下了哪个键：1=左键, 2=中键, 3=右键
        if event.button == 1:
            print("你按下了左键！")
```

**另一种获取鼠标位置的方式**（更常用）：

```python
# 不依赖事件，随时随地获取鼠标位置
mouse_x, mouse_y = pygame.mouse.get_pos()
```

这种方式在游戏主循环中非常方便——每一帧都能拿到鼠标最新位置，不用等事件触发。

#### 2.5 图片缩放——transform.scale()（1分钟）

```python
# 将图片缩放到指定大小
new_img = pygame.transform.scale(原图片, (新宽度, 新高度))
```

例如，将笑脸从 150x150 缩小到 80x80：

```python
small_face = pygame.transform.scale(big_face, (80, 80))
```

**注意**：`pygame.transform.scale()` 会返回一张**新的** Surface，原图片不受影响。如果反复缩放，建议提前创建好几个不同尺寸的版本，避免在循环中频繁缩放（那样比较消耗性能）。

#### 2.6 性能优化——convert_alpha()（1分钟）

```python
optimized_img = my_image.convert_alpha()
```

**为什么要用 convert_alpha()？**

Pygame 加载图片后，图片的像素格式（pixel format）可能和屏幕不匹配。每次 `blit()` 时，Pygame 都要临时转换格式，这会拖慢游戏速度。

`convert_alpha()` 的作用就是**提前把图片转换成和屏幕匹配的格式**，这样后续的 `blit()` 操作就像"高铁"一样快，而不是"走路上班"。

**规则**：
- 有透明通道的图片（PNG、自己画的带 `SRCALPHA` 的 Surface）→ 用 `convert_alpha()`
- 没有透明通道的纯色图片 → 用 `convert()`

**本节课实践**：因为我们用 `pygame.Surface((size, size), pygame.SRCALPHA)` 创建了支持透明的画纸，所以应该调用 `convert_alpha()` 来优化。

#### 完整参考代码（老师用，可选择性展示）

```python
import pygame
import math
import sys

# ---------- 初始化 ----------
pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("笑脸跟鼠标")
clock = pygame.time.Clock()

# ---------- 创建笑脸函数 ----------
def create_smiley_face(size=150):
    face = pygame.Surface((size, size), pygame.SRCALPHA)
    cx, cy = size // 2, size // 2
    r = size // 2 - 10

    pygame.draw.circle(face, (255, 223, 0), (cx, cy), r)
    pygame.draw.circle(face, (0, 0, 0), (cx, cy), r, 3)

    eye_r = r // 4
    left_x, right_x = cx - r // 3, cx + r // 3
    eye_y = cy - r // 4
    for ex in [left_x, right_x]:
        pygame.draw.circle(face, (255, 255, 255), (ex, eye_y), eye_r)
        pygame.draw.circle(face, (0, 0, 0), (ex, eye_y), eye_r, 2)
        pygame.draw.circle(face, (0, 0, 0), (ex, eye_y), eye_r // 3)

    mouth_rect = pygame.Rect(cx - r // 2, cy - r // 6, r, r // 2)
    pygame.draw.arc(face, (0, 0, 0), mouth_rect,
                    math.pi / 4, math.pi * 3 / 4, 3)

    blush_r = r // 6
    pygame.draw.circle(face, (255, 150, 150),
                       (left_x - r // 6, eye_y + r // 3), blush_r)
    pygame.draw.circle(face, (255, 150, 150),
                       (right_x + r // 6, eye_y + r // 3), blush_r)

    return face.convert_alpha()

# ---------- 准备不同尺寸的笑脸 ----------
sizes = [80, 150, 250]  # 三种尺寸：小、中、大
smiley_faces = []
for s in sizes:
    base = create_smiley_face(s)
    smiley_faces.append(base)

current_index = 1  # 默认用中等尺寸

# ---------- 游戏主循环 ----------
running = True
while running:
    # 事件处理
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        # 点击鼠标左键 → 切换笑脸大小
        if event.type == pygame.MOUSEBUTTONDOWN and event.button == 1:
            current_index = (current_index + 1) % len(sizes)  # 循环切换

    # 获取鼠标位置
    mouse_x, mouse_y = pygame.mouse.get_pos()

    # 绘制背景
    screen.fill((135, 206, 235))

    # 获取当前笑脸
    current_face = smiley_faces[current_index]

    # 让笑脸中心对准鼠标
    face_w = current_face.get_width()
    face_h = current_face.get_height()
    draw_x = mouse_x - face_w // 2
    draw_y = mouse_y - face_h // 2

    # 贴到屏幕上
    screen.blit(current_face, (draw_x, draw_y))

    # 显示大小提示文字
    font = pygame.font.SysFont("simhei", 24)
    size_names = ["小", "中", "大"]
    tip_text = font.render(f"当前大小：{size_names[current_index]}（点击切换）",
                           True, (0, 0, 0))
    screen.blit(tip_text, (10, 10))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()
sys.exit()
```

## 💡 常见问题与解决

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 笑脸背后有白色方块 | Surface 创建时没加 `pygame.SRCALPHA` | 改为 `pygame.Surface((size, size), pygame.SRCALPHA)` |
| 图片不显示 | `blit()` 放在了 `pygame.display.flip()` 之后 | `blit()` 一定要在 `flip()` **之前**调用 |
| 笑脸位置偏离鼠标 | 忘记减去宽度/高度的一半 | `draw_x = mouse_x - 图片宽度 // 2` |
| 点击鼠标没反应 | 没有在事件循环中处理 `MOUSEBUTTONDOWN` | 检查 `for event in pygame.event.get()` 中是否有对应的 `if` 判断 |
| 游戏窗口卡顿 | 没有调用 `clock.tick(60)` | 在主循环中加入 `clock.tick(60)` 控制帧率 |
| 缩放后图片变模糊 | 这是正常现象，放大都会损失清晰度 | 建议直接创建不同尺寸的 Surface，而不是反复缩放 |
| 画弧线时嘴巴方向不对 | `arc()` 的角度用的是弧度制 | 记住：`π`=180度，`π/4`=45度；从右开始顺时针画 |
| `convert_alpha()` 报错 | 图片格式不支持 alpha 通道 | 对于 JPG 等无透明格式，用 `convert()`；自己画的带 `SRCALPHA` 的 Surface 可以用 `convert_alpha()` |

> **给老师的小贴士**：
> 1. 本节课的核心难点在于理解"坐标系"——`blit()` 的坐标是图片**左上角**的位置，而学生直觉想让图片**中心**对齐鼠标。建议用白板画图演示：一个矩形，标出左上角坐标和中心坐标的关系。
> 2. `pygame.draw.arc()` 的弧度制对小学生可能比较抽象，可以简单说"`math.pi` 就是半个圆的意思"，不要求深入理解弧度。
> 3. 如果学生对"自己画角色"特别感兴趣，可以鼓励课后多用 `draw` 函数组合创作，这比用外部图片更能锻炼编程思维和坐标计算能力。
> 4. 时间充裕的话，让学生互相展示自己的作品——每个人画出来的笑脸可能略有不同（有的画了帽子、有的加了眼镜），这正是编程创意的魅力！
