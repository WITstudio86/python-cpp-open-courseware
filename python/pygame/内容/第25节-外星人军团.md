### 二、核心讲解（25分钟）

#### 2.1 认识 Sprite 精灵类（8分钟）

**为什么要用精灵？**

在之前的课程中，我们用一个列表来存放所有的游戏物体，物体的坐标、速度、图片
全都放在字典里，代码很乱。Pygame 提供了一个更好的解决方案——**精灵（Sprite）**。

精灵是一种把"物体的数据"和"物体的行为"打包在一起的类。一个精灵自己知道：
- 自己长什么样（`self.image`，一个 Surface 对象）
- 自己在屏幕的什么位置（`self.rect`，一个 Rect 对象）  
- 自己每帧要做什么（`self.update()` 方法）

**Sprite 类的核心属性**

```python
import pygame

class Alien(pygame.sprite.Sprite):
    """外星人类——继承自 pygame.sprite.Sprite"""
    
    def __init__(self, x, y, color):
        super().__init__()          # 必须调用父类的 __init__()
        
        # image：精灵的外观，一个 Surface 对象
        self.image = pygame.Surface((40, 30))
        self.image.fill(color)
        
        # rect：精灵在屏幕上的位置和大小
        self.rect = self.image.get_rect()
        self.rect.x = x     # 左上角的 x 坐标
        self.rect.y = y     # 左上角的 y 坐标
    
    def update(self):
        """每帧调用一次，定义精灵的行为"""
        # 目前外星人还不会自己动，待会我们来实现
        pass
```

**必须记住的三个要点（板书强调）：**

| 要点 | 说明 |
|------|------|
| ① 继承 Sprite | `class Alien(pygame.sprite.Sprite):` |
| ② 定义 image 和 rect | `self.image` 是外观，`self.rect` 是位置 |
| ③ 实现 update() | 精灵每帧自动调用的方法，写运动逻辑 |

> **比喻讲解：** "精灵就像一个会动的小贴纸。`image` 是贴纸的图案，
> `rect` 是贴纸贴在屏幕上的位置，`update()` 就是贴纸自己知道该怎么移动。"

#### 2.2 精灵组 Group（7分钟）

**为什么要用精灵组？**

如果我们有 30 个外星人，我们不能写 30 行代码分别去 `update()` 和 `draw()`。
精灵组可以帮我们**批量管理**一组精灵。

```python
# 创建精灵组
aliens = pygame.sprite.Group()      # 用来装外星人的容器
bullets = pygame.sprite.Group()     # 用来装子弹的容器
all_sprites = pygame.sprite.Group() # 用来装所有精灵的容器

# 创建外星人并加入精灵组
for row in range(3):
    for col in range(8):
        alien = Alien(col * 60 + 80, row * 50 + 50, (0, 255, 0))
        aliens.add(alien)           # 加入外星人组
        all_sprites.add(alien)      # 同时加入总组

# 在主循环里，一行代码搞定所有精灵的更新和绘制
aliens.update()         # 组内所有精灵的 update() 全被调用
aliens.draw(screen)     # 组内所有精灵全被画到屏幕上
```

**精灵组的常用操作（板书）：**

```python
group.add(sprite)       # 添加一个精灵到组里
group.update()          # 调用组内所有精灵的 update() 方法
group.draw(screen)      # 把组内所有精灵画到 screen 上
group.remove(sprite)    # 从组中移除某个精灵
sprite.kill()           # 从当前精灵所在的所有组中移除自己
len(group)              # 获取组内精灵的数量
```

> **比喻讲解：** "精灵组就像班级的花名册，`update()` 就是对着花名册喊全班起立，
> 所有同学一起站起来。不用一个一个点名，效率非常高！"

#### 2.3 编队移动算法（10分钟）

这是本节课的核心难点。让我们先理解算法，再看代码。

**算法规则（板书画图）：**

```
┌─────────────────────────────┐
│  ← ← ← ← ← ← ← ← ← ← ←     │  第1排
│  ← ← ← ← ← ← ← ← ← ← ←     │  第2排
│  ← ← ← ← ← ← ← ← ← ← ←     │  第3排
│                             │
│  所有外星人一起往左走 ──→    │
│                             │
│  当最左边碰到屏幕边缘时：    │
│  ① 换方向 → 往右走          │
│  ② 所有外星人下移一行       │
└─────────────────────────────┘
```

**实现方案：创建一个管理类 `AlienFleet`**

```python
class AlienFleet:
    """外星人舰队——负责编队移动的管理器"""
    
    def __init__(self, screen_width, screen_height):
        self.aliens = pygame.sprite.Group()    # 外星人精灵组
        self.direction = 1                     # 移动方向：1=右，-1=左
        self.speed = 2                         # 水平移动速度
        self.drop_distance = 20                # 触边后下移的像素数
        self.screen_width = screen_width
        
        # 创建外星人编队（3行 × 8列）
        for row in range(3):
            for col in range(8):
                alien = Alien(
                    x = col * 60 + 80,         # 每列间隔 60 像素
                    y = row * 50 + 50,         # 每行间隔 50 像素
                    color = (0, 255, 0)
                )
                self.aliens.add(alien)
    
    def update(self):
        """编队移动——先水平移动，再判断是否需要换向和下移"""
        
        # 第一步：查边境（移动前检查是否即将越界）
        need_reverse = False
        for alien in self.aliens:
            # 如果正在往右走，且最右边的外星人即将超出屏幕
            if self.direction > 0 and alien.rect.right >= self.screen_width - 10:
                need_reverse = True
                break
            # 如果正在往左走，且最左边的外星人即将超出屏幕
            if self.direction < 0 and alien.rect.left <= 10:
                need_reverse = True
                break
        
        # 第二步：如果需要换向，全体下移并反方向
        if need_reverse:
            self.direction *= -1           # 反转方向
            for alien in self.aliens:
                alien.rect.y += self.drop_distance  # 所有外星人下移
        
        # 第三步：按当前方向水平移动所有外星人
        for alien in self.aliens:
            alien.rect.x += self.direction * self.speed
```

> **关键理解：** "触边检测要在**移动之前**做，判断的是『即将』超出，
> 而不是『已经』超出。否则外星人会卡在屏幕边缘来回抖动。"

#### 2.4 玩家与射击（穿插讲解）

```python
class Player(pygame.sprite.Sprite):
    """玩家飞船"""
    
    def __init__(self, screen_width, screen_height):
        super().__init__()
        
        # 用 Surface 画一个简单的三角形飞船
        self.image = pygame.Surface((50, 30))
        self.image.fill((0, 0, 0))           # 先填充黑色背景
        self.image.set_colorkey((0, 0, 0))   # 设置黑色为透明色
        # 画白色三角形
        pygame.draw.polygon(self.image, (255, 255, 255),
            [(25, 0), (0, 29), (49, 29)])
        
        self.rect = self.image.get_rect()
        self.rect.centerx = screen_width // 2
        self.rect.bottom = screen_height - 20
        self.speed = 5
    
    def update(self):
        """左右移动"""
        keys = pygame.key.get_pressed()
        if keys[pygame.K_LEFT] and self.rect.left > 0:
            self.rect.x -= self.speed
        if keys[pygame.K_RIGHT] and self.rect.right < 800:
            self.rect.x += self.speed


class Bullet(pygame.sprite.Sprite):
    """子弹"""
    
    def __init__(self, x, y):
        super().__init__()
        self.image = pygame.Surface((4, 12))
        self.image.fill((255, 255, 0))       # 黄色子弹
        self.rect = self.image.get_rect()
        self.rect.centerx = x
        self.rect.bottom = y
    
    def update(self):
        """子弹向上飞行，飞出屏幕则自动销毁"""
        self.rect.y -= 8
        
        if self.rect.bottom < 0:             # 飞出屏幕顶部
            self.kill()                      # 自动从所有组中移除
```

## 💡 常见问题与解决

- **问题1：外星人飞到屏幕边缘就卡住了**
  → 解决：边界检测要在"移动前"做，判断的是"即将越界"，而且检测逻辑和移动逻辑要放在同一帧里。

- **问题2：精灵没有显示在屏幕上**
  → 解决：检查三件事——① 是否调用了 `group.draw(screen)`？② `self.image` 是否有内容？③ `self.rect` 的位置是否在屏幕范围内？

- **问题3：子弹打中外星人后，外星人还在屏幕上**
  → 解决：检查 `groupcollide` 的参数，第二个参数要设为 `True` 才会销毁外星人。如果设为 `False`，只会返回碰撞信息但不删除。

- **问题4：游戏运行几秒后变得非常卡**
  → 解决：子弹飞出屏幕后没有 `kill()`，导致子弹精灵越来越多。确保在 `Bullet.update()` 中添加飞出屏幕后 `self.kill()` 的逻辑。

- **问题5：`super().__init__()` 忘记写了**
  → 解决：继承 Sprite 时必须调用父类的初始化方法，否则精灵无法被正确注册到精灵组中。

- **问题6：外星人移动时"一跳一跳"的**
  → 解决：把边界检测和移动逻辑放在同一个 `update()` 调用里，不要在检测和移动之间丢失状态。
