### 二、核心讲解（25分钟）

#### 2.1 什么是 Pygame？（3分钟）

Pygame 是 Python 的一个**游戏开发库**。可以把 Python 想象成"大脑"，Pygame 就是"手和脚"——大脑负责思考逻辑，手脚负责画图、放音乐、检测键盘。

- **类比**：就像 Minecraft 里的"红石"——给你一套工具，让你能创造出各种有趣的互动。
- **Pygame 能做什么？**：创建窗口、画图形、显示图片、播放音效、检测键盘鼠标……几乎所有 2D 游戏都需要的基础功能。

#### 2.2 安装 Pygame（5分钟）

打开终端（或命令提示符），输入以下命令：

```bash
pip install pygame
```

**注意事项**：
- 如果安装失败，可能是网络问题，可以试试 `pip install pygame -i https://pypi.tuna.tsinghua.edu.cn/simple`（使用国内镜像源）
- 验证安装是否成功：在 Python 中输入 `import pygame`，如果没有报错就说明安装好了
- 如果提示 `pip 不是内部或外部命令`，说明 Python 的环境变量没有配置好

#### 2.3 创建第一个游戏窗口（12分钟）

**代码框架**（逐步讲解）：

```python
# 1. 导入库
import pygame
import sys

# 2. 初始化 Pygame（必须要做的第一步！）
pygame.init()  # 就像按下游戏机的"开机键"

# 3. 创建窗口
screen = pygame.display.set_mode((800, 600))  # 800×600 像素的窗口
pygame.display.set_caption("我的第一个游戏")   # 设置标题栏文字

# 4. 游戏主循环
running = True
while running:
    for event in pygame.event.get():  # 检查事件
        if event.type == pygame.QUIT:  # 用户点了关闭按钮
            running = False            # 退出循环
    screen.fill((135, 206, 235))      # 填充天蓝色背景
    pygame.display.flip()             # 刷新画面

# 5. 退出
pygame.quit()
sys.exit()
```

**逐行讲解要点**：

| 代码 | 生活中的类比 |
|------|------------|
| `pygame.init()` | 按下游手机的开机键 |
| `set_mode((800, 600))` | 选一张 800×600 的画纸 |
| `set_caption("...")` | 给画本封面写上标题 |
| `while running:` | 让程序一直运行，不要一闪而过 |
| `pygame.event.get()` | 像一个"收件箱"，查看有没有新消息 |
| `screen.fill(...)` | 用颜料刷满整张画纸 |
| `pygame.display.flip()` | 把画完的画翻过来给大家看 |
| `pygame.quit()` | 关机，收拾好所有工具 |

#### 2.4 理解计算机坐标系（3分钟）

计算机屏幕的坐标系和数学课上学的有点不一样：

```
(0,0) ────────────── X 轴（向右增大）
  │
  │    ⬤ (400, 300)  ← 窗口中心
  │
  Y 轴（向下增大）
```

- **原点 (0, 0)** 在**左上角**，不是左下角！
- **X 轴**：向右增大（和数学一样）
- **Y 轴**：向下增大（和数学**相反**！）

**记忆口诀**："左上角是零零点，向右向下都在涨，X 管左右 Y 管下"

#### 2.5 RGB 颜色模型（2分钟）

屏幕上的所有颜色都由 **红(Red)、绿(Green)、蓝(Blue)** 三种光混合而成，这就是"RGB 颜色"。

| 颜色 | RGB 值 | 口诀 |
|------|--------|------|
| 红色 | (255, 0, 0) | 红满绿蓝零 |
| 绿色 | (0, 255, 0) | 红蓝关绿灯开 |
| 蓝色 | (0, 0, 255) | 红绿关蓝灯开 |
| 白色 | (255, 255, 255) | 三盏灯全开 |
| 黑色 | (0, 0, 0) | 三盏灯全关 |
| 黄色 | (255, 255, 0) | 红绿灯开，蓝灯关 |

每种颜色的取值范围：**0 ~ 255**（共 256 个级别，因为计算机用 8 位存储一个颜色通道，2^8 = 256）

## 💡 常见问题与解决

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| `ModuleNotFoundError: No module named 'pygame'` | Pygame 没有安装 | 终端执行 `pip install pygame` |
| 窗口一闪而过就消失了 | 没有写 `while running` 游戏循环 | 检查代码中是否包含了主循环 |
| 窗口无响应 / 卡死 | 事件处理循环缺失或写错 | 确保 `for event in pygame.event.get()` 在循环内 |
| `pygame` 下有红色波浪线 | IDE 没有识别到 Pygame | 检查 Python 解释器设置，或重启 IDE |
| `pip` 命令找不到 | Python 环境变量未配置 | 重新安装 Python 并勾选"Add to PATH" |
| 窗口显示的内容不对 | `fill()` 和 `flip()` 顺序错误 | 先 `fill` 清屏，再画内容，最后 `flip` |
