### 二、核心讲解（25分钟）

#### 2.1 回合制状态机（5分钟）

回合制战斗本质上是一个**有限状态机（FSM）**，每一帧根据当前状态执行不同逻辑：

```
          ┌──────────────────────────────┐
          │                              │
          ▼                              │
   ┌──────────────┐    选择操作    ┌──────────────┐
   │  PLAYER_TURN ├──────────────►│ PLAYER_ACTION │
   │ （玩家回合）  │               │ （玩家执行）   │
   └──────┬───────┘               └──────┬───────┘
          │                              │
    [跳过] │                              │ 动作完成
          │                              ▼
          │                       ┌──────────────┐
          │                       │  ENEMY_TURN  │
          │                       │ （敌人回合）   │
          │                       └──────┬───────┘
          │                              │
          │                              │ 敌人动作完成
          │                              ▼
          │                       ┌──────────────┐
          └───────────────────────┤ CHECK_RESULT │
                下一轮              │ （判定胜负）  │
                                  └──────────────┘
```

**状态说明：**
| 状态 | 含义 | 做什么 |
|------|------|--------|
| `PLAYER_TURN` | 等待玩家输入 | 显示攻击/防御/技能按钮 |
| `PLAYER_ACTION` | 执行玩家动作 | 计算伤害、播放动画 |
| `ENEMY_TURN` | 敌人回合 | AI选择动作、计算伤害 |
| `CHECK_RESULT` | 判定胜负 | 检查HP、显示结果 |

**代码示例：**
```python
state = "PLAYER_TURN"  # 初始状态

def update():
    if state == "PLAYER_TURN":
        # 显示菜单，等待点击
        pass
    elif state == "PLAYER_ACTION":
        # 执行玩家选择的动作
        pass
    elif state == "ENEMY_TURN":
        # 敌人行动
        pass
    elif state == "CHECK_RESULT":
        # 判定胜负
        pass
```

#### 2.2 技能数据结构（5分钟）

使用**字典**来存储每个技能的信息，这是"数据驱动设计"的体现：

```python
skills = {
    "attack": {
        "name": "普通攻击",
        "multiplier": 1.0,   # 伤害倍率
        "mp_cost": 0,        # MP消耗
        "desc": "造成100%攻击力的伤害"
    },
    "defend": {
        "name": "防御",
        "multiplier": 0,     # 不造成伤害
        "mp_cost": 0,
        "desc": "本回合受到的伤害减半"
    },
    "fireball": {
        "name": "火球术",
        "multiplier": 2.0,   # 双倍伤害！
        "mp_cost": 15,
        "desc": "消耗15MP，造成200%攻击力的伤害"
    }
}
```

**为什么用字典？**
- 方便通过名字查找：`skills["fireball"]["multiplier"]`
- 技能数据与逻辑分离，增加新技能只需添加字典条目
- 便于在UI中遍历显示

#### 2.3 伤害计算公式（5分钟）

**核心公式：**
```
damage = max(1, atk × 技能倍率 − def × 0.5)
```

**为什么这样设计？**
- `atk × 技能倍率`：基础伤害，技能越好伤害越高
- `− def × 0.5`：防御减伤，防御越高减免越多（但不会完全免疫）
- `max(1, ...)`：保底1点伤害，避免出现"打不动"的尴尬

**代码实现：**
```python
def calc_damage(atk, defense, multiplier):
    raw = atk * multiplier - defense * 0.5
    return max(1, int(raw))

# 示例：
# atk=30, def=20, 普通攻击(mult=1.0)
# → 30×1.0 − 20×0.5 = 30−10 = 20 点伤害
#
# atk=30, def=20, 火球术(mult=2.0)
# → 30×2.0 − 20×0.5 = 60−10 = 50 点伤害 💥
#
# atk=10, def=50, 普通攻击(mult=1.0)
# → 10×1.0 − 50×0.5 = 10−25 = -15 → max(1, -15) = 1 点伤害
```

**防御状态下的伤害计算：**
```python
if is_defending:
    damage = max(1, damage // 2)  # 防御状态伤害减半
```

#### 2.4 血条平滑动画（5分钟）

血条直接跳变太生硬，用**lerp（线性插值）**实现平滑过渡：

**原理：**
```
current_hp = current_hp + (target_hp - current_hp) × speed
```

每帧让 `current_hp` 向 `target_hp` 靠近一点，`speed` 控制靠近速度。

**代码实现：**
```python
# 初始化
current_hp = 100
target_hp = 100
lerp_speed = 0.1

def update_hp_bar():
    global current_hp
    # lerp插值：每帧向目标靠近10%
    current_hp = current_hp + (target_hp - current_hp) * lerp_speed

def take_damage(damage):
    global target_hp
    target_hp = max(0, target_hp - damage)
    # current_hp 会在 update 中自动追赶 target_hp
```

**视觉效果：**
```
帧1:  current=100  target=60  → current=100.0 （还没开始）
帧2:  current=100  target=60  → current=96.0  （开始减少）
帧3:  current=96   target=60  → current=92.4
帧4:  current=92.4 target=60  → current=89.2
...  持续逼近，越来越慢
帧N:  current≈60  → 动画完成
```

**绘制血条：**
```python
def draw_hp_bar(surface, x, y, width, current, max_hp):
    # 背景（灰色）
    pygame.draw.rect(surface, GRAY, (x, y, width, 20))
    # 当前血量（绿色→黄色→红色渐变）
    ratio = current / max_hp
    if ratio > 0.5:
        color = GREEN
    elif ratio > 0.25:
        color = YELLOW
    else:
        color = RED
    pygame.draw.rect(surface, color, (x, y, int(width * ratio), 20))
    # 边框
    pygame.draw.rect(surface, WHITE, (x, y, width, 20), 2)
```

**按钮实现：**
```python
buttons = [
    {"rect": pygame.Rect(100, 480, 150, 60), "text": "⚔️ 攻击", "action": "attack"},
    {"rect": pygame.Rect(325, 480, 150, 60), "text": "🛡️ 防御", "action": "defend"},
    {"rect": pygame.Rect(550, 480, 150, 60), "text": "🔥 技能", "action": "fireball"},
]
```

**鼠标点击检测：**
```python
for event in pygame.event.get():
    if event.type == pygame.MOUSEBUTTONDOWN:
        for btn in buttons:
            if btn["rect"].collidepoint(event.pos):
                do_action(btn["action"])
```

## 💡 常见问题与解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 血条不动 | `target_hp` 改了但没调 `update_hp_bar()` | 确保每帧调用更新函数 |
| 点按钮没反应 | `Rect` 坐标不对或忘了写 `MOUSEBUTTONDOWN` | 检查按钮位置和事件处理代码 |
| 伤害为负数 | 没加 `max(1, ...)` 保底 | 检查伤害公式 |
| 状态不切换 | 忘了改 `state` 变量 | 在动作完成后设置下一状态 |
| 血条动画太快/太慢 | `lerp_speed` 不合适 | 调小变慢，调大变快，建议0.05~0.2 |
| 敌人一直不动 | 敌人回合逻辑写在 `ENEMY_TURN` 状态外 | 确认敌人逻辑在正确的状态分支里 |
