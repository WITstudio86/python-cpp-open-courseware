## 四、知识点详解

### 4.1 屏幕震动原理（Sin衰减震动）

屏幕震动的本质是什么？就是把整个画面**临时偏移**一个小距离，而且这个偏移会**越来越小**直到消失。

我们用一个带衰减的正弦函数来描述这个偏移量：

```
shake_offset = sin(时间 × 频率) × 振幅 × 衰减系数

其中：
- sin(time × frequency)：产生正负交替的周期振动
- 振幅(strength)：控制震动有多剧烈（比如初始偏移10像素）
- 衰减系数(decay)：随着时间流逝，让振幅越来越小，比如 decay = e^(-时间 × 衰减速度)
```

物理直觉上，这就像一个弹簧：你用力拉一下然后松手，弹簧会来回振荡，但幅度越来越小，最后停下来。

**代码核心思路**：
```python
# 每一帧计算当前震动偏移
shake_time = (当前帧 - 震动开始帧) / FPS  # 换算成秒数
decay = math.exp(-shake_time * 3.0)       # 衰减因子（3.0控制衰减速度）
shake_offset_x = math.sin(shake_time * 30) * (15 * decay)  # 水平震动
shake_offset_y = math.cos(shake_time * 25) * (15 * decay)  # 垂直震动
# 绘制时把画面平移 (shake_offset_x, shake_offset_y)
```

**不同衰减速度的效果对比**：
| 衰减速度 | 效果描述 | 应用场景 |
|----------|----------|----------|
| 低（1-2） | 震动缓慢衰减，持续较久 | 大地震、大型爆炸 |
| 中（3-5） | 适中震感，0.5-1秒内消失 | 击中反馈、普通爆炸 |
| 高（6-10） | 短促有力，快速停止 | 枪械后坐力、轻微碰撞 |

### 4.2 粒子系统概念

粒子系统是游戏开发中最重要的特效技术之一。简单来说：

> **粒子系统 = 大量微小的、有生命周期的对象组成的动态效果系统**

每个粒子都是一个独立的小"生命体"：
- 它**出生**在某个位置（比如爆炸中心）
- 它**运动**（飞向四周，受到速度、重力影响）
- 它**衰老**（颜色变暗、大小缩小、透明度降低）
- 它**死亡**（生命值归零，被清理掉）

成千上万个这样的粒子同时存在，就形成了壮观的特效！

**粒子在游戏中的典型应用**：
| 效果类型 | 粒子表现 | 代表游戏 |
|----------|----------|----------|
| 爆炸火花 | 从中心向四周飞溅，红→黄→暗色渐变 | 愤怒的小鸟 |
| 烟雾拖尾 | 缓慢上升，逐渐扩散消失 | 火箭发射 |
| 魔法光效 | 螺旋上升，闪烁彩色光芒 | 原神、塞尔达 |
| 雨雪天气 | 从上向下飘落，大量同时存在 | 动物森友会 |
| 击中火花 | 短暂闪烁，沿碰撞法线方向飞溅 | 格斗游戏 |

### 4.3 粒子类设计

我们用Python类来定义粒子：

```python
class Particle:
    def __init__(self, x, y):
        self.x = x              # X坐标
        self.y = y              # Y坐标
        self.vx = random.uniform(-5, 5)  # X方向速度（随机）
        self.vy = random.uniform(-5, 5)  # Y方向速度（随机）
        self.life = 1.0         # 生命值（1.0=满血，0.0=死亡）
        self.max_radius = random.randint(3, 8)  # 最大半径
        self.color_start = (255, 255, 100)      # 起始颜色（亮黄）
        self.color_end = (180, 30, 0)            # 结束颜色（暗红）
```

**粒子属性解释**：
- `x, y`：粒子的当前位置
- `vx, vy`：粒子的运动速度。爆炸时通常给一个随机的初速度，让粒子向四面八方飞散
- `life`：生命值，从1.0衰减到0.0。可以理解为"剩余寿命百分比"
- `max_radius`：粒子的最大半径，每个粒子随机不同，让效果更自然
- `color_start / color_end`：颜色渐变。粒子从亮色（高温）过渡到暗色（冷却）

**粒子更新方法**：
```python
def update(self, dt):
    self.x += self.vx * dt         # 更新位置
    self.y += self.vy * dt
    self.vy += 2.0 * dt            # 模拟重力：向下加速
    self.vx *= 0.99                # 摩擦力：速度逐渐减小
    self.vy *= 0.99
    self.life -= 0.02              # 生命衰减（每秒约衰减0.6）
```

### 4.4 粒子池管理

不要为每个粒子创建新对象然后丢弃——这会造成性能问题。最佳实践是使用**粒子池**：

```python
particles = []  # 粒子池（列表）

# 生成新粒子（爆炸时调用）
def spawn_explosion(x, y, count=50):
    for _ in range(count):
        particles.append(Particle(x, y))

# 更新所有粒子
def update_particles(dt):
    for p in particles[:]:  # 遍历副本，方便删除
        p.update(dt)
        if p.life <= 0:
            particles.remove(p)  # 生命归零，移出粒子池
```

**粒子池管理要点**：
1. 用Python列表存储所有活跃粒子
2. 每帧遍历更新所有粒子
3. 死亡粒子立即移除（避免无限增长）
4. 可用 `particles[:]` 创建副本遍历，避免遍历时修改列表出错

### 4.5 颜色插值（渐变）

粒子的颜色从亮到暗逐渐变化，这需要**颜色插值**：

```python
def lerp_color(c1, c2, t):
    """在c1和c2之间线性插值，t∈[0,1]"""
    return (
        int(c1[0] + (c2[0] - c1[0]) * t),
        int(c1[1] + (c2[1] - c1[1]) * t),
        int(c1[2] + (c2[2] - c1[2]) * t),
    )

# 使用示例：生命值越小，越接近end_color
t = 1.0 - particle.life  # t从0(刚出生)到1(即将死亡)
color = lerp_color(color_start, color_end, t)
```

**第一步：屏幕震动公式（10分钟）**

在黑板上写出公式并逐项解释：
```
shake = sin(time × 频率) × 振幅 × e^(-time × 衰减)
     = sin(time × 30) × 15 × e^(-time × 3)
```

- 用实物演示：拿一支笔，用手捏住一端，拨动另一端——这就是衰减振动
- 让学生自己改参数：把频率30改成60会怎样？把振幅15改成30会怎样？
- 为什么用sin而不是random？——因为sin产生有规律的"来回摆动"，random只会乱抖

**第二步：粒子类设计（10分钟）**

用"生命"做比喻：
- 粒子出生 → `__init__()` 构造函数
- 粒子成长 → `update()` 更新位置和状态
- 粒子死亡 → `life <= 0` 时移除

类比：每个粒子就像一只萤火虫——它亮起来，飞舞，然后慢慢暗下去。

**第三步：粒子池管理（5分钟）**

- 为什么需要"池"？——方便统一管理
- 为什么死亡粒子要移除？——否则列表越来越长，程序越来越慢
- 类比：班级点名册，转学的同学要从名单上划掉

## 六、完整代码示例

以下是本课的完整示例程序核心框架（完整的可运行程序见程序文件夹）：

```python
import pygame
import random
import math

# 初始化
pygame.init()
W, H = 800, 600
screen = pygame.display.set_mode((W, H))
clock = pygame.time.Clock()

# ---------- 粒子类 ----------
class Particle:
    def __init__(self, x, y):
        self.x = x
        self.y = y
        angle = random.uniform(0, 2 * math.pi)  # 随机角度
        speed = random.uniform(2, 8)              # 随机速度
        self.vx = math.cos(angle) * speed
        self.vy = math.sin(angle) * speed
        self.life = 1.0
        self.max_radius = random.randint(3, 8)
        self.color_start = (255, 255, 100)  # 亮黄
        self.color_end = (180, 30, 0)       # 暗红

    def update(self, dt):
        self.x += self.vx * dt * 60
        self.y += self.vy * dt * 60
        self.vy += 3.0 * dt * 60  # 重力
        self.vx *= 0.99
        self.vy *= 0.99
        self.life -= dt * 1.5     # 生命衰减

    def get_color(self):
        """颜色从亮到暗渐变"""
        t = 1.0 - self.life
        return (
            int(self.color_start[0] + (self.color_end[0] - self.color_start[0]) * t),
            int(self.color_start[1] + (self.color_end[1] - self.color_start[1]) * t),
            int(self.color_start[2] + (self.color_end[2] - self.color_start[2]) * t),
        )

    def get_radius(self):
        """大小随生命衰减"""
        return max(1, int(self.max_radius * self.life))

# ---------- 震动管理 ----------
shake_start_time = -999  # 震动开始时间（初始为很久以前，表示无震动）
shake_duration = 0.5     # 震动持续秒数

def trigger_shake():
    """触发屏幕震动"""
    global shake_start_time
    shake_start_time = pygame.time.get_ticks() / 1000.0

def get_shake_offset():
    """计算当前震动偏移"""
    now = pygame.time.get_ticks() / 1000.0
    elapsed = now - shake_start_time
    if elapsed < 0 or elapsed > shake_duration:
        return 0, 0  # 无震动
    decay = math.exp(-elapsed * 8.0)
    strength = 12.0 * decay
    ox = math.sin(elapsed * 40) * strength
    oy = math.cos(elapsed * 35) * strength
    return ox, oy

# ---------- 主循环 ----------
particles = []
running = True
while running:
    dt = clock.tick(60) / 1000.0  # 帧间隔（秒）
    dt = min(dt, 0.05)            # 防止卡顿导致的大跳跃

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        if event.type == pygame.MOUSEBUTTONDOWN:
            mx, my = event.pos
            # 点击产生爆炸粒子
            for _ in range(60):
                particles.append(Particle(mx, my))
            trigger_shake()

    # 更新粒子
    for p in particles[:]:
        p.update(dt)
        if p.life <= 0:
            particles.remove(p)

    # 渲染
    screen.fill((20, 20, 40))
    shake_x, shake_y = get_shake_offset()  # 获取震动偏移

    # 绘制所有物体时应用偏移
    for p in particles:
        color = p.get_color()
        radius = p.get_radius()
        pygame.draw.circle(screen, color,
                           (int(p.x + shake_x), int(p.y + shake_y)), radius)

    pygame.display.flip()

pygame.quit()
```

## 七、常见问题与调试技巧

| 问题现象 | 可能原因 | 解决方法 |
|----------|----------|----------|
| 震动看起来像"瞬移" | dt值太大（卡帧后跳帧） | 限制 dt = min(dt, 0.05) |
| 粒子从角落飞出 | 初始速度使用了错误的随机范围 | 改用角度+速度的方式：用cos/sin生成圆周分布 |
| 程序越来越卡 | 死亡粒子没有正确移除 | 检查 `particles.remove(p)` 是否执行 |
| 画面闪烁 | 没有用双缓冲或绘制顺序问题 | 确保先 fill() 再绘制，最后 flip() |
| 震动方向不对 | sin和cos参数设置问题 | 可以只在一个方向震动来调试 |
