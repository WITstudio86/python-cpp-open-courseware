#### 步骤2：用 Surface 绘制小鸟（5分钟）

**教师话术：**

"以前我们可能用 `pygame.image.load()` 加载图片。但今天我们来点高级的——用代码自己画一只小鸟！"

```python
# --- 创建小鸟的 Surface ---
# 小鸟用一个圆形 + 一个三角形（嘴巴）+ 一个圆点（眼睛）组成

def create_bird_surface():
    """用代码画一只小鸟，返回一个 Surface 对象"""
    # 创建一个小 Surface（32×32 像素，支持透明）
    bird_surf = pygame.Surface((32, 32), pygame.SRCALPHA)

    # 身体：黄色圆形
    pygame.draw.circle(bird_surf, YELLOW, (16, 16), 12)

    # 翅膀：深黄色小椭圆（用一个小矩形近似）
    pygame.draw.ellipse(bird_surf, (255, 200, 0), (4, 12, 10, 6))

    # 眼睛：白色圆 + 黑色瞳孔
    pygame.draw.circle(bird_surf, WHITE, (22, 12), 4)
    pygame.draw.circle(bird_surf, BLACK, (23, 12), 2)

    # 嘴巴：橙色小三角形
    pygame.draw.polygon(bird_surf, (255, 150, 0), [(28, 14), (32, 16), (28, 18)])

    return bird_surf

bird_image = create_bird_surface()
```

**讲解要点：**
- `pygame.SRCALPHA`：让 Surface 支持透明背景，小鸟周围不会有黑色方块
- `draw.circle` 画圆、`draw.ellipse` 画椭圆、`draw.polygon` 画三角形
- 学生可以自由修改颜色和形状，创造自己的小鸟

#### 步骤3：重力模拟 —— 小鸟下落（7分钟）【本节课核心】

**教师话术：**

"现在到了最关键的部分——怎么让小鸟像真的有重力一样往下掉？"

"在真实世界里，一个物体下落时：速度会越来越快！这是因为重力在不停地'推'它。我们用两行代码来模拟这个效果："

```python
# --- 小鸟的物理属性 ---
bird_x = 100              # 小鸟的 x 坐标（固定不变，只上下移动）
bird_y = HEIGHT // 2      # 小鸟的 y 坐标（初始在屏幕中间）
bird_velocity = 0         # 小鸟的垂直速度（正数=向下，负数=向上）

# 重力参数
GRAVITY = 0.5             # 每帧增加的速度（重力加速度）
JUMP_STRENGTH = -8        # 按空格键时给的速度（负数 = 向上跳）

# --- 在游戏循环中 ---
# ① 重力让速度不断增加
bird_velocity += GRAVITY

# ② 速度改变位置
bird_y += bird_velocity
```

**可视化讲解（板书 / PPT 动画）：**

```
第 1 帧: velocity = 0.0    → bird_y = 300.0
第 2 帧: velocity = 0.5    → bird_y = 300.5
第 3 帧: velocity = 1.0    → bird_y = 301.5
第 4 帧: velocity = 1.5    → bird_y = 303.0
第 5 帧: velocity = 2.0    → bird_y = 305.0
...
         ↑ 速度越来越大，下落越来越快！
```

**理解要点：**
- `GRAVITY = 0.5`：这是一个"加速度"，不是"速度"。它是每一帧速度增加的量
- `bird_velocity` 从 0 开始，每帧加 0.5，所以越来越快
- 这就是物理课上学过的：**匀加速运动** `v = v0 + a·t` 的离散版本！

> **互动设计：** 让学生把 `GRAVITY` 改成 0.1 和 1.0，观察小鸟下落速度的变化。学生会发现：数值越大，下落越快。

#### 步骤4：空格键上升（5分钟）

**教师话术：**

"光往下掉可不行，小鸟得会飞！当玩家按下空格键时，我们要给小鸟一个向上的速度——就像拍一下翅膀。"

```python
# --- 在事件循环中 ---
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False
    elif event.type == pygame.KEYDOWN:
        if event.key == pygame.K_SPACE:
            # 空格键：给小鸟一个向上的速度（负数 = 向上）
            bird_velocity = JUMP_STRENGTH  # 直接设置为 -8
```

**为什么是 `velocity = JUMP_STRENGTH` 而不是 `velocity += JUMP_STRENGTH`？**

"同学们注意：这里用的是 `=` 而不是 `+=`！如果我们用 `+=`，连续按空格的时候，小鸟的速度会累加，越飞越快——就像火箭一样直接冲出屏幕。而用 `=`，每次按下空格键，速度都**重置为 -8**，保证每次弹跳的高度相同。"

```
错误写法: velocity += JUMP_STRENGTH
  按1次: velocity = -8  → 飞起来
  按2次: velocity = -16 → 飞得更快（不自然！）
  按3次: velocity = -24 → 飞出屏幕了！

正确写法: velocity = JUMP_STRENGTH
  按1次: velocity = -8  → 飞起来
  按2次: velocity = -8  → 稳定在同一高度
  按3次: velocity = -8  → 稳定在同一高度
```

#### 步骤5：用 Surface 绘制水管（5分钟）

**教师话术：**

"水管是这个游戏的标志性障碍物。一根水管由两部分组成：上面的水管（天花板垂下来）和下面的水管（地面长上去）。中间留一个空隙让小鸟飞过去。"

```python
# --- 水管参数 ---
PIPE_WIDTH = 60           # 水管宽度
PIPE_GAP = 160            # 上下水管之间的空隙（小鸟要通过它！）
PIPE_SPEED = 3            # 水管向左移动的速度
PIPE_SPAWN_INTERVAL = 90  # 每隔多少帧生成一根新水管

# 水管列表：每个元素是一个字典，包含上下水管的 Rect 和 Surface
pipes = []

def create_pipe(x_position):
    """生成一对水管（上面一根 + 下面一根），返回包含两个 Surface 和 Rect 的字典"""
    # 随机决定空隙的中心位置（在屏幕中间上下浮动）
    gap_center_y = random.randint(150, HEIGHT - 150)

    # 上水管的底部 = 空隙的顶部
    top_pipe_height = gap_center_y - PIPE_GAP // 2
    # 下水管的顶部 = 空隙的底部
    bottom_pipe_y = gap_center_y + PIPE_GAP // 2

    # --- 创建上水管 Surface ---
    top_surf = pygame.Surface((PIPE_WIDTH, top_pipe_height))
    top_surf.fill(GREEN)
    # 画水管边框，让它看起来更立体
    pygame.draw.rect(top_surf, DARK_GREEN, (0, 0, PIPE_WIDTH, top_pipe_height), 3)
    # 画管道的"帽檐"（底部加宽的部分）
    cap_height = 20
    pygame.draw.rect(top_surf, DARK_GREEN, (-3, top_pipe_height - cap_height, PIPE_WIDTH + 6, cap_height))

    # --- 创建下水管 Surface ---
    bottom_pipe_height = HEIGHT - bottom_pipe_y
    bottom_surf = pygame.Surface((PIPE_WIDTH, bottom_pipe_height))
    bottom_surf.fill(GREEN)
    pygame.draw.rect(bottom_surf, DARK_GREEN, (0, 0, PIPE_WIDTH, bottom_pipe_height), 3)
    # 画管道的"帽檐"（顶部加宽的部分）
    pygame.draw.rect(bottom_surf, DARK_GREEN, (-3, 0, PIPE_WIDTH + 6, cap_height))

    # 返回水管信息
    return {
        "x": x_position,
        "top_rect": pygame.Rect(x_position, 0, PIPE_WIDTH, top_pipe_height),
        "bottom_rect": pygame.Rect(x_position, bottom_pipe_y, PIPE_WIDTH, bottom_pipe_height),
        "top_surf": top_surf,
        "bottom_surf": bottom_surf,
        "gap_center_y": gap_center_y,  # 记录空隙位置
        "scored": False               # 是否已经被记过分（下一节课用）
    }
```

**讲解要点：**
- `gap_center_y` 使用 `random.randint(150, HEIGHT - 150)` 随机生成，让每根水管的空隙在不同高度
- 上下水管之间有 `PIPE_GAP = 160` 像素的空隙，小鸟要从这里飞过
- 水管的"帽檐"比管身宽一点，模拟真实水管的外观

> **互动设计：** 让学生修改 `PIPE_GAP` 的值（比如改成 100 或 250），观察游戏难度的变化。

#### 步骤6：水管移动与生成逻辑（5分钟）

```python
# --- 初始化：在屏幕右侧生成第一根水管 ---
pipes.append(create_pipe(WIDTH + 100))
frame_count = 0  # 帧计数器，用于控制水管生成间隔

# --- 在游戏循环中 ---
# ① 移动所有水管（向左移动）
for pipe in pipes:
    pipe["x"] -= PIPE_SPEED
    pipe["top_rect"].x = pipe["x"]
    pipe["bottom_rect"].x = pipe["x"]

# ② 移除飞出屏幕左侧的水管
pipes = [p for p in pipes if p["x"] > -PIPE_WIDTH]

# ③ 每隔一定帧数生成新水管
frame_count += 1
if frame_count >= PIPE_SPAWN_INTERVAL:
    pipes.append(create_pipe(WIDTH + 50))
    frame_count = 0
```

**讲解要点：**
- 水管向左移动：`x -= PIPE_SPEED`（每帧减 3 像素）
- `PIPE_SPEED = 3`：让学生理解这和 FPS 的关系——60fps 下每秒移动 180 像素
- 移除出界水管：`x > -PIPE_WIDTH` 意味着水管完全离开屏幕后才删除
- 生成间隔 `PIPE_SPAWN_INTERVAL = 90`：每 90 帧（约 1.5 秒）生成一根新水管

**列表推导式复习：**
```python
pipes = [p for p in pipes if p["x"] > -PIPE_WIDTH]
# 等价于 ↓
new_pipes = []
for p in pipes:
    if p["x"] > -PIPE_WIDTH:
        new_pipes.append(p)
pipes = new_pipes
```

### 四、总结与作业（5分钟）

#### 本节课要点回顾

1. **重力模拟**：`velocity += GRAVITY` → `y += velocity`，每帧速度都在增加，下落越来越快

## 💡 常见问题与解决

- **问题1：小鸟一开局就掉到屏幕外面去了**
  → 检查 `bird_velocity += GRAVITY` 是否写在了游戏循环内部。如果写在循环外面，速度不会更新。

- **问题2：按空格键小鸟不动**
  → ① 检查事件类型是 `pygame.KEYDOWN`（注意大写和下划线）；② 检查按键是 `pygame.K_SPACE`（不是 `K_SPACEBAR`）；③ 检查 `JUMP_STRENGTH` 是负数（比如 -8），正数会让小鸟往下走。

- **问题3：小鸟飞一下就掉下来，飞得不够高**
  → `JUMP_STRENGTH` 的绝对值太小。试试改成 -10 或 -12。同时检查 `GRAVITY` 是否太大。

- **问题4：水管不出现**
  → 检查 `create_pipe()` 是否被调用，水管是否被 `append` 到了列表中，绘制代码是否遍历了列表。

- **问题5：水管不移动**
  → 检查水管移动代码（`pipe["x"] -= PIPE_SPEED`）是否在游戏循环内执行，检查 `PIPE_SPEED` 是否为正数。

- **问题6：水管堆在一起，没有空隙**
  → 检查 `PIPE_GAP` 参数是否设置正确，上下水管的 y 坐标计算是否正确。

- **问题7：小鸟飞到上面停住了**
  → 检查 `velocity = JUMP_STRENGTH` 是否写成了 `velocity += JUMP_STRENGTH`。用 `+=` 会导致连续按空格时速度不断累加。

- **问题8：程序运行很卡**
  → 检查 `clock.tick(FPS)` 是否被调用。没有帧率限制，程序会跑得飞快，消耗大量 CPU。
