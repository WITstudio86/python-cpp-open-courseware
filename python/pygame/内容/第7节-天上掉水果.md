### 二、核心讲解（25分钟）

#### 2.1 随机数 —— 让苹果从不同位置出现（6分钟）

##### 为什么需要随机数？

如果苹果每次都从同一个位置掉下来，游戏就太无聊了。我们需要用 `random.randint()` 让苹果的x坐标随机变化，这样苹果就可以从屏幕顶部的任何位置出现。

##### `random.randint(a, b)` 详解

```python
import random

x = random.randint(0, 100)   # 生成 0~100 之间的随机整数（包含 0 和 100）
y = random.randint(1, 10)     # 生成 1~10 之间的随机整数
print(x)   # 每次运行结果都不一样，比如：42, 87, 3...
```

**关键点**：
- `a` 和 `b` 都包含在内（闭区间）
- 每次调用都会得到一个不同的随机数
- 需要先 `import random`

##### 在游戏中使用

```python
import pygame
import random

# 苹果的初始位置
apple_x = random.randint(50, 750)   # 屏幕宽度800，留50边距
apple_y = 0                           # 从屏幕顶部开始
```

> **类比**：`random.randint()` 就像掷骰子，每次掷出的点数都不一样。这里我们"掷"的是苹果的出生位置。

##### 重置苹果位置

当苹果掉出屏幕底部，或被篮子接住时，我们需要让它重新出现在顶部——这时候再次使用随机数：

```python
if apple_y > 600:   # 掉出屏幕
    apple_x = random.randint(50, 750)   # 重新随机x坐标
    apple_y = 0                          # 回到顶部
```

#### 2.2 下落速度 —— `y += speed` 原理（5分钟）

##### 为什么物体会"动"？

回顾游戏循环的原理：

```python
while running:
    # 1. 处理事件（按键等）
    # 2. 更新位置 ← 这一步让物体动画起来
    # 3. 绘制画面
```

**动画的本质**：每一帧都略微改变物体的位置，连续起来就是动画。

##### 下落 = y坐标不断增加

```python
apple_y = 0           # 初始y坐标
speed = 5             # 每帧下落5个像素

# 在游戏循环中
while running:
    apple_y += speed    # y坐标不断增加 ↓
    # 绘制苹果在 (apple_x, apple_y)
```

**图解**：

```
帧1：y = 0     ●  ← 苹果在顶部
帧2：y = 5     ●
帧3：y = 10    ●
帧4：y = 15    ●
帧5：y = 20    ●
...           ↓
帧60：y = 300  ●  ← 苹果在中间
```

##### 完整下落逻辑

```python
# 初始化
apple_x = random.randint(50, 750)
apple_y = 0
apple_speed = 5
apple_radius = 30

# 游戏循环中
while running:
    # --- 更新位置 ---
    apple_y += apple_speed  # 苹果下落

    # --- 判断是否掉出屏幕 ---
    if apple_y > 600:   # 屏幕高度600
        apple_x = random.randint(50, 750)   # 新位置
        apple_y = 0                          # 回到顶部

    # --- 绘制苹果 ---
    screen.fill(WHITE)   # 清屏（非常重要！）
    pygame.draw.circle(screen, RED, (apple_x, apple_y), apple_radius)
    pygame.display.flip()
```

> **想一想**：如果把 `apple_speed` 从 5 改成 10，会发生什么？苹果会掉得更快！这就是"难度"的来源。

#### 2.3 方向键控制左右移动（加强练习）（5分钟）

##### 复习：键盘事件处理

```python
# 初始化篮子位置
basket_x = 350
basket_y = 550      # 篮子固定在底部
basket_speed = 8

# 游戏循环中
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # --- 连续按键检测（推荐方式） ---
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT]:
        basket_x -= basket_speed    # 左移
    if keys[pygame.K_RIGHT]:
        basket_x += basket_speed    # 右移

    # --- 边界限制（不让篮子跑出屏幕） ---
    if basket_x < 50:
        basket_x = 50
    if basket_x > 750:
        basket_x = 750
```

##### 两种按键方式对比

| 方式 | 代码 | 特点 |
|------|------|------|
| 事件方式 | `for event in ...`<br>`if event.type == KEYDOWN` | 每次按键只触发一次，像打字 |
| 轮询方式 | `keys = pygame.key.get_pressed()` | 按住不放会持续触发，适合游戏 |

> **推荐**：游戏中的移动使用轮询方式，因为玩家按住方向键时希望角色持续移动。

# 用矩形表示篮子

pygame.draw.rect(screen, BROWN, 
                 (basket_x - basket_width//2, basket_y, 
                  basket_width, basket_height))

#### 2.4 碰撞检测 —— 判断是否接到苹果（6分钟）

##### 什么是碰撞检测？

碰撞检测就是判断两个物体是否"碰到一起"。在游戏中，我们需要判断苹果是否掉进了篮子里。

##### 思路：坐标范围判断

苹果是一个圆形（有圆心和半径），篮子是一个矩形。我们用 **包围盒（Bounding Box）** 的概念来简化检测：

> 把苹果看成一个正方形，篮子也看成一个正方形。如果两个正方形重叠，就说明"碰到了"。

##### 碰撞条件分析

```
苹果的包围盒：
  left   = apple_x - apple_radius
  right  = apple_x + apple_radius
  top    = apple_y - apple_radius
  bottom = apple_y + apple_radius

篮子的包围盒：
  left   = basket_x - basket_width // 2
  right  = basket_x + basket_width // 2
  top    = basket_y
  bottom = basket_y + basket_height
```

**碰撞发生的条件（四个同时满足）**：

```python
# 通俗理解：苹果的"身体"和篮子的"身体"有重叠
apple_bottom >= basket_top          # 苹果碰到篮子顶部
    and apple_right >= basket_left  # 苹果的右边在篮子左边之右
    and apple_left <= basket_right  # 苹果的左边在篮子右边之左
    and apple_top <= basket_bottom  # 苹果还没穿过篮子
```

##### 完整碰撞检测函数

```python
def check_collision(apple_x, apple_y, apple_r, 
                    basket_x, basket_y, basket_w, basket_h):
    """
    检测苹果和篮子是否碰撞
    返回 True（接到了） 或 False（没接到）
    """
    # 苹果的包围盒
    apple_left = apple_x - apple_r
    apple_right = apple_x + apple_r
    apple_bottom = apple_y + apple_r
    
    # 篮子的包围盒
    basket_left = basket_x - basket_w // 2
    basket_right = basket_x + basket_w // 2
    basket_top = basket_y
    
    # 碰撞条件
    if (apple_bottom >= basket_top and 
        apple_right >= basket_left and
        apple_left <= basket_right and
        apple_y <= basket_y + basket_h):
        return True
    else:
        return False
```

**好消息**：pygame 提供了更简洁的碰撞检测方法！

```python
# 用 Rect 对象做碰撞检测（更简单）
apple_rect = pygame.Rect(
    apple_x - apple_r, apple_y - apple_r, 
    apple_r * 2, apple_r * 2
)
basket_rect = pygame.Rect(
    basket_x - 50, basket_y, 
    100, 30
)

if apple_rect.colliderect(basket_rect):
    print("接到了！")
```

## 💡 常见问题与解决

### 问题1：苹果掉得太快/太慢，眨个眼就不见了

**原因**：`apple_speed` 设置不当，或忘记使用 `clock.tick(60)`。

**解决**：
```python
# 1. 调整速度值（5-8是比较舒适的范围）
apple_speed = 5

# 2. 确保游戏循环末尾有帧率控制
clock.tick(60)   # 每秒60帧，控制游戏速度
```

### 问题2：苹果掉下来时留下一条"尾巴"（拖影）

**原因**：忘记在每帧开始时清屏。

**解决**：
```python
while running:
    screen.fill(WHITE)   # ← 这一行必须在绘制之前！
    # ... 然后绘制苹果、篮子等
    pygame.display.flip()
```

> **记住**：每一帧都要先擦黑板，再画新内容。不擦黑板，旧画面就会留在上面。

### 问题3：碰撞检测不灵敏，苹果穿过了篮子

**原因**：
- 碰撞检测范围设置太小
- 苹果速度太快，一帧之内穿过了篮子（"隧道效应"）
- 碰撞检测的坐标计算有误

**解决**：
```python
# 方法1：增大检测范围（让篮子的"接住区"比视觉上大一些）
basket_rect = pygame.Rect(basket_x - 60, basket_y - 10, 120, 40)
#                               ↑ 比实际宽      ↑ 比实际高

# 方法2：降低速度
apple_speed = 3  # 慢一点，不容易穿透

# 方法3：检查苹果中心和篮子顶部距离
if abs(apple_y - basket_y) < 15 and abs(apple_x - basket_x) < 60:
    # 接到了
```

### 问题4：按方向键没反应

**原因**：按键检测代码放在了 `for event in pygame.event.get()` 循环里面。

**解决**：
```python
# ❌ 错误写法：放在事件循环里
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False
    # 把移动放在这里——只有事件发生时才会触发，按键不放就没反应

# ✅ 正确写法：放在事件循环外面，用 get_pressed()
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False

# 移到这里来！
keys = pygame.key.get_pressed()
if keys[pygame.K_LEFT]:
    basket_x -= 8
```

### 问题5：接到苹果后分数跳了十几分

**原因**：碰撞持续了多帧。苹果碰到篮子的那一瞬间，其实碰撞了10帧，每帧都加了10分。

**解决**：接到苹果后立即将苹果移走（重置位置）。

```python
if apple_rect.colliderect(basket_rect):
    score += 10
    # ✅ 关键：接到后马上重置苹果，避免重复加分
    apple_x = random.randint(50, 750)
    apple_y = 0
```

### 问题6：`random` 模块导入后报错 `NameError`

**原因**：忘记在文件开头 `import random`。

**解决**：
```python
import pygame
import random   # ← 别忘了这一行！
```

### 问题7：苹果的x坐标超出了屏幕

**原因**：`random.randint()` 的范围太大了。

**解决**：
```python
# 如果屏幕宽度是800，苹果半径是30
# 那么 x 的范围应该是 30 到 770（留出半径的边距）
apple_x = random.randint(30, 770)

# 通式：random.randint(radius, screen_width - radius)
```
