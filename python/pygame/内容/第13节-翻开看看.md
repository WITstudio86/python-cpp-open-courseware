# 第13节：翻开看看 —— 4x4卡牌网格

## 教学目标

- 学生能够理解二维列表的概念，用 `board[row][col]` 存储卡牌数据
- 学生能够使用 `pygame.draw.rect` 配合不同颜色绘制卡牌网格
- 学生能够根据鼠标点击坐标换算出卡牌的行列位置（`col = x // CARD_W`）
- 学生能够实现卡牌的三种状态管理：隐藏（hidden）、翻开（revealed）、已匹配（matched）
- 学生能够完成一个4x4共16张卡牌的点击翻开游戏

### 二、核心讲解（25分钟）

#### 2.1 用二维列表存储棋盘（8分钟）

**知识点：** 二维列表就是"列表的列表"，像一个表格，有行和列。

**生活类比：** 教室里的座位——第3排第5列坐着小明，我们可以用 `seats[3][5] = "小明"` 来表示。`seats[row][col]` 就是二维列表的访问方式。

**代码示例：**

```python
# 卡牌图案列表：一共有8种颜色（8对牌）
COLORS = [
    (255, 0, 0),    # 红色
    (0, 130, 255),  # 蓝色
    (0, 200, 0),    # 绿色
    (255, 200, 0),  # 黄色
    (200, 0, 255),  # 紫色
    (255, 130, 0),  # 橙色
    (0, 200, 200),  # 青色
    (255, 100, 180) # 粉色
]

# 创建4x4的棋盘，每个格子存储两张信息：
# board[row][col] = {"color": 颜色, "state": "hidden"/"revealed"/"matched"}
import random

def create_board():
    """创建4x4的棋盘，随机放置8对颜色"""
    # 生成8对颜色编号：0,0, 1,1, 2,2, ..., 7,7
    pairs = []
    for i in range(8):
        pairs.append(i)
        pairs.append(i)
    
    # 洗牌！把顺序打乱
    random.shuffle(pairs)
    
    # 填入4x4的二维列表
    board = []
    for row in range(4):
        current_row = []
        for col in range(4):
            # 从pairs列表里按顺序取出一个颜色编号
            color_index = pairs[row * 4 + col]
            card = {
                "color": COLORS[color_index],
                "state": "hidden"  # 初始都是隐藏状态
            }
            current_row.append(card)
        board.append(current_row)
    
    return board
```

**强调讲解：**
- `board[row][col]` 中，第一个下标是行号（从上到下），第二个是列号（从左到右）
- 列出 `row * 4 + col` 这个公式怎么来的：每行4个，跳过前面整行再加上当前列
- `random.shuffle(pairs)` 的作用——洗牌，让每次游戏都不一样

#### 2.2 绘制卡牌网格（7分钟）

**知识点：** 用 `pygame.draw.rect` 画矩形表示卡牌，用颜色区分状态。

**卡牌尺寸计算：**

```python
# 窗口大小：800 x 600
SCREEN_W = 800
SCREEN_H = 600

# 卡牌尺寸和间距
CARD_W = 120      # 卡牌宽度
CARD_H = 120      # 卡牌高度
GAP = 20          # 卡牌之间的间隙

# 计算网格的左上角偏移，让16张牌居中
GRID_W = 4 * CARD_W + 3 * GAP   # 整行宽度：4张牌 + 3个间隙
GRID_H = 4 * CARD_H + 3 * GAP   # 整列高度

OFFSET_X = (SCREEN_W - GRID_W) // 2  # 水平居中
OFFSET_Y = (SCREEN_H - GRID_H) // 2  # 垂直居中
```

**绘制函数：**

```python
def draw_board(screen, board):
    """绘制整个棋盘"""
    # 背景色
    screen.fill((30, 30, 50))
    
    for row in range(4):
        for col in range(4):
            # 计算这张牌在屏幕上的位置
            x = OFFSET_X + col * (CARD_W + GAP)
            y = OFFSET_Y + row * (CARD_H + GAP)
            
            card = board[row][col]
            
            if card["state"] == "hidden":
                # 隐藏状态：画灰色牌背
                color = (80, 80, 120)  # 深灰色牌背
                pygame.draw.rect(screen, color, (x, y, CARD_W, CARD_H))
                pygame.draw.rect(screen, (150, 150, 200), (x, y, CARD_W, CARD_H), 3)  # 边框
                
            elif card["state"] == "revealed":
                # 翻开状态：画卡牌的颜色
                pygame.draw.rect(screen, card["color"], (x, y, CARD_W, CARD_H))
                pygame.draw.rect(screen, (255, 255, 255), (x, y, CARD_W, CARD_H), 3)  # 白色边框
                
            elif card["state"] == "matched":
                # 匹配成功的状态（下节课用）：画成半透明或灰色
                gray_color = tuple(c // 2 for c in card["color"])  # 颜色变暗
                pygame.draw.rect(screen, gray_color, (x, y, CARD_W, CARD_H))
                pygame.draw.rect(screen, (100, 100, 100), (x, y, CARD_W, CARD_H), 3)
```

**讲解要点：**
- 为什么用 `col * (CARD_W + GAP)` 而不是 `col * CARD_W`？——因为要加上间隙
- 三种状态的视觉区分：hidden是灰色、revealed显示颜色、matched变灰
- 边框让卡牌看起来更立体

#### 2.3 鼠标点击换算出卡牌行列（5分钟）

**知识点：** 屏幕坐标→卡牌行列的换算。

**核心公式：** `col = (mouse_x - OFFSET_X) // (CARD_W + GAP)`

**代码示例：**

```python
def get_card_at_pos(mouse_x, mouse_y):
    """根据鼠标坐标，返回点击的是哪张牌（行, 列），点击空白返回None"""
    # 先判断是否在网格范围内
    if mouse_x < OFFSET_X or mouse_y < OFFSET_Y:
        return None
    
    # 换算成行列
    col = (mouse_x - OFFSET_X) // (CARD_W + GAP)
    row = (mouse_y - OFFSET_Y) // (CARD_H + GAP)
    
    # 判断行列是否有效（0到3之间）
    if 0 <= row < 4 and 0 <= col < 4:
        # 还要判断点击的是牌本身，不是间隙
        x = OFFSET_X + col * (CARD_W + GAP)
        y = OFFSET_Y + row * (CARD_H + GAP)
        if x <= mouse_x <= x + CARD_W and y <= mouse_y <= y + CARD_H:
            return (row, col)
    
    return None
```

**讲解要点：**
- 整数除法 `//` 的作用：把连续坐标变成离散的格子编号
- 类比：你在Excel里点击一个格子，怎么知道是第几行第几列？
- 为什么要检查 `0 <= row < 4`？防止数组越界
- 为什么要验证点击在牌上而不是间隙里？间隙里不应该触发翻牌

#### 2.4 卡牌状态管理（5分钟）

**知识点：** 用字符串标记三种状态，根据状态决定行为。

**状态转换图：**

```
hidden ──(点击翻开)──> revealed ──(下节课：匹配成功)──> matched
                           │
                           └──(下节课：匹配失败)──> hidden（翻回）
```

**代码示例（主循环中的事件处理）：**

```python
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False
        
        elif event.type == pygame.MOUSEBUTTONDOWN:
            mouse_x, mouse_y = event.pos
            result = get_card_at_pos(mouse_x, mouse_y)
            
            if result is not None:
                row, col = result
                card = board[row][col]
                
                # 只有隐藏状态的牌才能翻开
                if card["state"] == "hidden":
                    card["state"] = "revealed"
                    print(f"翻开了第 {row} 行第 {col} 列的牌！颜色是 {card['color']}")
    
    # 绘制
    draw_board(screen, board)
    pygame.display.flip()
```

**讲解要点：**
- 状态检查 `if card["state"] == "hidden"` 是关键——不能重复翻已经翻开的牌
- `print` 输出帮助调试，在Pygame中可以用 `print` 查看控制台信息
- 这是游戏状态管理的基础，下节课会扩展更多逻辑

## 常见问题与解决

- **问题1：卡牌点击没反应** → 检查 `get_card_at_pos` 中的坐标是否减去了 `OFFSET_X` / `OFFSET_Y`；检查 `MOUSEBUTTONDOWN` 事件处理是否正确
- **问题2：卡牌翻开了但颜色全一样** → 检查 `create_board` 中的 `pairs` 列表是否正确生成，确认8对颜色已随机分配到16个位置
- **问题3：点击间隙也会翻开卡牌** → 在 `get_card_at_pos` 中增加判断，确保 `mouse_x` 在 `x` 到 `x + CARD_W` 范围内
- **问题4：窗口一片空白** → 检查 `draw_board` 中的坐标计算，确认 `OFFSET_X` 和 `OFFSET_Y` 正确；确认 `pygame.display.flip()` 被调用
- **问题5：每次运行卡牌排列都一样** → 忘记调用 `random.shuffle(pairs)` 来打乱顺序
