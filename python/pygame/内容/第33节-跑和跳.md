### 3.2 讲解（一）：重力与跳跃（10分钟）

#### 3.2.1 什么是重力？

在现实生活中，地球重力让一切物体往下掉。在游戏中，我们模拟重力非常简单：

```
每帧：vy = vy + 重力加速度
每帧：y = y + vy
```

**生活类比：**
- 你往上扔一个球 → 球先向上飞（vy是负数），然后越飞越慢，最后掉下来（vy变正数）
- 这就是"先减速上升，再加速下落"的过程

#### 3.2.2 代码实现

```python
# 重力加速度常量
GRAVITY = 0.8
# 角色的垂直速度（初始为0）
vy = 0

# 在游戏循环中，每一帧：
vy += GRAVITY          # 速度不断增加（向下）
player.y += vy         # 位置根据速度改变
```

> **给学生的比喻：** 想象你在玩滑梯——重力就像一直把你往下拉。vy 就是你下滑的"速度"，重力每帧都让这个速度变大一点点。

#### 3.2.3 跳跃

跳跃就是"给速度一个向上的大推力"：

```python
# 按下空格键时
if keys[pygame.K_SPACE] and on_ground:
    vy = -15  # 一个很大的负数 = 向上飞！
```

**为什么是负数？**
- 在pygame中，y坐标从上往下增大
- 所以"向上"就是减小y，vy为负数
- "向下"就是增大y，vy为正数

#### 3.2.4 完整运动示意图

```
时间线：跳跃过程
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

帧1: vy = -15  ↑↑↑  (刚按下空格，飞速上升)
帧2: vy = -14.2 ↑↑  (还在上升，但慢了一点)
帧3: vy = -13.4 ↑   (更慢了)
...
帧12: vy = -0.2  ·   (几乎停在最高点)
帧13: vy = +0.6  ↓   (开始下落！)
帧14: vy = +1.4  ↓↓  (越落越快)
...
帧25: 碰到地面 → vy = 0, on_ground = True
```

### 3.3 讲解（二）：平台碰撞的三种类型（15分钟）

这是本节课的核心难点。平台和角色的碰撞不是"一碰就弹开"那么简单，需要根据碰撞方向区分处理。

#### 3.3.1 类型一：站在平台上（从上方碰撞）

**场景：** 角色下落时，脚碰到了平台的顶部。

**规则：** 角色应该"站住"——落在平台上面，不再下落。

**检测条件：**
```python
# 三个条件同时满足：
# 1. 角色正在下落（vy > 0）
# 2. 角色前一帧的底部 <= 平台的顶部（之前还在平台上方）
# 3. 角色当前帧的底部 >= 平台的顶部（现在已经碰到或穿过平台了）
if vy > 0 and prev_bottom <= platform.top and current_bottom >= platform.top:
    # 站在平台上！
    player.bottom = platform.top
    vy = 0
    on_ground = True
```

> **给学生的比喻：** 就像你跳到桌子上——你的脚碰到桌面就停住了，不会穿过去。

#### 3.3.2 类型二：从下方穿透（单向平台）

**场景：** 角色从下方跳起来，穿过平台，然后落在平台上面。

**规则：**
- 角色从下往上时：可以穿过平台（不碰撞）
- 角色从上往下时：站在平台上（和类型一一样）

**这就是"单向平台"——只能从上往下站，不能从下往上挡。**

```python
# 关键：只在下落时才检测平台碰撞
if vy > 0:  # 只有下落时才可能站在平台上
    if prev_bottom <= platform.top <= current_bottom:
        player.bottom = platform.top
        vy = 0
        on_ground = True
# 如果 vy <= 0（上升中），就直接忽略平台 → 穿过去了！
```

> **生活类比：** 就像公园里那种"只能往上推开、不能往下拉"的栅栏门——你从下面可以轻松穿过，但从上面就会被挡住。

#### 3.3.3 类型三：侧面碰撞（被挡住）

**场景：** 角色水平移动时，撞到了平台的侧面。

**规则：** 角色被挡住，不能穿过去。

```python
# 先检查周围是否有重叠
if player.colliderect(platform):
    if prev_right <= platform.left:  # 从左边撞过来
        player.right = platform.left
    elif prev_left >= platform.right:  # 从右边撞过来
        player.left = platform.right
```

> **给学生的比喻：** 就像你走路撞到墙上——你被挡住了，但你不会穿过去。

#### 3.3.4 三种碰撞总结表

| 碰撞方向 | 规则 | 生活类比 |
|----------|------|----------|
| 从上方（站在上面） | 角色停住，站在平台上 | 跳到桌子上 |
| 从下方（穿透） | 角色穿过（单向平台） | 单向栅栏门 |
| 从侧面（被挡） | 角色被挡住 | 走路撞墙 |

#### 3.3.5 多个平台的生成

在游戏中，我们需要多个平台。做法很简单：

```python
# 用一个列表存储所有平台
platforms = [
    Platform(100, 500, 200, 20),   # 地面平台1
    Platform(350, 400, 150, 20),   # 空中平台2
    Platform(200, 300, 150, 20),   # 空中平台3
    Platform(500, 250, 120, 20),   # 空中平台4
]
```

每帧对每个平台都做碰撞检测即可。

### 3.5 总结环节（5分钟）

**回顾要点：**

1. **重力公式：** `vy += GRAVITY`，`y += vy`
2. **跳跃公式：** 按下空格 → `vy = JUMP_FORCE`（负数）
3. **平台碰撞三种类型：**
   - 站在上面：下落碰到顶部 → 停住
   - 从下穿透：上升时 → 不管它；下落时 → 站住
   - 侧面挡住：水平碰撞 → 弹回

**提问检查：**
- "如果我把GRAVITY改成2，角色下落会变快还是变慢？"（变快）
- "单向平台和普通平台有什么区别？"（单向平台从下面可以穿过）
- "为什么跳跃要在 `on_ground == True` 的时候才能触发？"（防止空中二段跳）

| 问题 | 解答 |
|------|------|
| 角色会穿过平台掉下去 | 检查碰撞检测是否只在下落时判断；检查vy是否为正数时才检测 |

| 二段跳 | 确保跳跃条件包含了 `on_ground == True` |
