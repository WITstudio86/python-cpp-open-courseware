### 二、核心讲解（25分钟）

#### 2.1 AI追踪逻辑（8分钟）

**设计思路：**
- AI球拍的目标位置 = 球的y坐标
- AI每帧向目标移动一小步，而不是瞬间到达
- AI速度略慢于球速度，模拟"反应时间"

**核心代码讲解：**

```python
# AI追踪逻辑
ai_speed = 4  # AI移动速度（比球速慢，模拟反应时间）

# AI球拍y坐标向球的y坐标靠近
if ai_paddle_y + paddle_height//2 < ball_y:
    ai_paddle_y += ai_speed      # 球在上方，AI向下移动
elif ai_paddle_y + paddle_height//2 > ball_y:
    ai_paddle_y -= ai_speed      # 球在下方，AI向上移动
```

**关键讲解点：**
- 为什么比较的是"球拍中心点"而不是"球拍顶部"？（让AI球拍中心对准球，覆盖面积最大）
- `ai_speed` 的大小意味着什么？（越大AI越强，越小AI越弱）
- 可以用这个原理做一个"难度选择"功能吗？（初级speed=2，中级speed=4，高级speed=6）

**边界处理：** AI球拍也不能超出屏幕范围，这和玩家球拍一样。

#### 2.2 计分系统（8分钟）

**设计思路：**

```
球出左边界 → 玩家失分，AI得1分
球出右边界 → AI失分，玩家得1分
先到11分者胜
得分后 → 球回到中心，重新发球
```

**核心代码讲解：**

```python
# 计分变量
player_score = 0
ai_score = 0
WIN_SCORE = 11
game_over = False

# 球出界检测
if ball_x < 0:                    # 球超出左边界
    ai_score += 1                 # AI得分
    reset_ball()                  # 重新发球
elif ball_x > SCREEN_WIDTH:       # 球超出右边界
    player_score += 1             # 玩家得分
    reset_ball()                  # 重新发球

# 重新发球函数
def reset_ball():
    global ball_x, ball_y, ball_dx, ball_dy
    ball_x = SCREEN_WIDTH // 2    # 球回到中心
    ball_y = SCREEN_HEIGHT // 2
    # 随机方向发球（-1或1）
    import random
    ball_dx = random.choice([-4, 4])
    ball_dy = random.choice([-3, 3])
```

**关键讲解点：**
- `reset_ball()` 封装了"重新发球"的逻辑，避免重复代码
- `random.choice()` 让每次发球方向随机，增加不确定性
- 胜利条件 `WIN_SCORE = 11` 是一个常量，修改它就能改变比赛长度

**判断胜负：**

```python
if player_score >= WIN_SCORE:
    game_over = True
    winner_text = "玩家获胜！"
elif ai_score >= WIN_SCORE:
    game_over = True
    winner_text = "AI获胜！"
```

#### 2.3 暂停功能（5分钟）

**设计思路：**
- 用一个布尔变量 `paused` 记录是否暂停
- 按P键切换暂停状态
- 暂停时：停止更新游戏逻辑，只绘制画面

**核心代码讲解：**

```python
paused = False  # 暂停状态

# 事件处理中
if event.type == pygame.KEYDOWN:
    if event.key == pygame.K_p:
        paused = not paused  # 切换暂停状态

# 游戏循环中
if not paused and not game_over:
    # 只在非暂停且游戏未结束时更新
    update_ball()
    update_ai()
    check_collision()
    check_score()
```

**关键讲解点：**
- `paused = not paused` 是切换布尔值的简洁写法
- 暂停时为什么还要绘制画面？（画面不会被清空，但游戏世界冻结了）
- 可以在暂停时显示"暂停中"文字

#### 2.4 半透明中线和虚线网（4分钟）

**设计思路：**
- 使用 `pygame.Surface` 创建带透明度的表面
- 用 `Surface.set_alpha()` 设置透明度
- 画虚线网的方法：画一系列短线段

**核心代码讲解：**

```python
# 方法1：半透明中线（实线）
mid_line = pygame.Surface((4, SCREEN_HEIGHT), pygame.SRCALPHA)
mid_line.fill((255, 255, 255))  # 白色填充
mid_line.set_alpha(80)          # 设置透明度 0-255，值越小越透明
screen.blit(mid_line, (SCREEN_WIDTH//2 - 2, 0))

# 方法2：虚线网（更接近真实Pong）
# 画一系列短线段
dash_length = 20  # 每段虚线长度
gap = 15          # 间隔
for y in range(0, SCREEN_HEIGHT, dash_length + gap):
    pygame.draw.rect(screen, (200, 200, 200),
                     (SCREEN_WIDTH//2 - 2, y, 4, dash_length))
```

**关键讲解点：**
- `pygame.SRCALPHA` 创建支持透明的Surface
- `set_alpha(80)` 中的数值含义（0完全透明，255完全不透明）
- 虚线可以用循环画短矩形实现

## 💡 常见问题与解决

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| AI球拍抖动 | AI速度过大，在目标位置附近反复上下 | 减小AI速度，或添加"死区"（距离小于一定值不移动） |
| 球穿透球拍 | 球速度太快，一帧内越过了球拍 | 降低球速，或增大球拍碰撞检测范围 |
| 分数不变化 | 出界检测条件写错（如用and替代or） | 检查球的x坐标范围和判断条件方向 |
| 重新发球后球不动 | 没有随机化方向，速度为0 | 检查 `reset_ball()` 是否正确赋值 dx/dy |
| 半透明不生效 | 忘记传 `pygame.SRCALPHA` 参数 | 在创建Surface时添加 `pygame.SRCALPHA` |
| 暂停后画面消失 | 暂停时没有继续绘制 | 暂停时跳过update，但保留draw部分 |
