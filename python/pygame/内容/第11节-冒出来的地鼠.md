# 第11节：冒出来的地鼠

## 教学目标
- 学生能够使用 Rect 对象在窗口中创建 3x3 九宫格布局
- 学生能够理解并应用 pygame.USEREVENT 自定义事件
- 学生能够使用 pygame.time.set_timer() 设置定时器，让地鼠定时出现
- 学生能够通过鼠标坐标判断是否点击到了地鼠（碰撞检测）

### 二、核心讲解（25分钟）

#### 2.1 第一步：3x3 九宫格布局（8分钟）

**知识点**：用 Rect 对象在 800x600 的窗口里均匀排列 9 个地鼠洞。

**布局思路**：

```
窗口宽度 800，高度 600
游戏区域居中，左右各留 100 像素，上面留 150 像素（给标题）
实际游戏区域：600×450（3×3 的网格）

每个洞的间距：
  列间距 = 600 / 3 = 200（洞中心之间的距离）
  行间距 = 450 / 3 = 150

起始位置（左上角第一个洞的中心）：
  start_x = 100 + 100 = 200  （左边距 + 半个列间距）
  start_y = 150 + 75  = 225  （上边距 + 半个行间距）
```

**代码示例**：

```python
import pygame
import random

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("打地鼠游戏")
clock = pygame.time.Clock()

# --- 九宫格布局参数 ---
GRID_COLS = 3          # 3 列
GRID_ROWS = 3          # 3 行
HOLE_SIZE = 120        # 每个洞口的宽度和高度（像素）
MARGIN_LEFT = 100      # 左边距
MARGIN_TOP = 150       # 上边距
COL_SPACING = 200      # 列间距（洞中心之间的距离）
ROW_SPACING = 150      # 行间距（洞中心之间的距离）

# --- 计算每个洞的位置，存入列表 ---
holes = []  # 存储 9 个洞的 Rect 对象
for row in range(GRID_ROWS):
    for col in range(GRID_COLS):
        # 计算洞的中心坐标
        cx = MARGIN_LEFT + col * COL_SPACING + HOLE_SIZE // 2
        cy = MARGIN_TOP + row * ROW_SPACING + HOLE_SIZE // 2
        # 创建洞的 Rect（以中心点为基准）
        hole_rect = pygame.Rect(0, 0, HOLE_SIZE, HOLE_SIZE)
        hole_rect.center = (cx, cy)
        holes.append(hole_rect)

# --- 地鼠状态 ---
# 用一个变量记录当前有地鼠的洞的索引（-1 表示没有地鼠）
current_mole = -1
```

**讲解要点**：
- `Rect` 的 `center` 属性可以直接设置中心坐标，非常方便。
- 用双重循环生成 9 个 Rect，避免手写 9 遍重复代码。
- 列表 `holes` 的索引 0~8 分别对应 9 个洞。

#### 2.2 第二步：让地鼠随机出现（7分钟）

**知识点**：使用 `random.randint()` 随机选择洞口，用 `pygame.draw.ellipse()` 画出地鼠。

**代码示例**：

```python
# --- 随机选择一个洞口让地鼠出现 ---
def spawn_mole():
    """随机选一个洞口，让地鼠冒出来"""
    global current_mole
    current_mole = random.randint(0, 8)  # 0~8 共 9 个洞

# 游戏开始时，先让第一只地鼠出现
spawn_mole()
```

**绘制地鼠**：

```python
# --- 绘制函数 ---
def draw_hole(hole_rect):
    """画一个地鼠洞（深色椭圆）"""
    pygame.draw.ellipse(screen, (80, 50, 20), hole_rect)

def draw_mole(hole_rect):
    """在地鼠洞里画一只地鼠（棕色圆 + 小眼睛）"""
    # 地鼠身体（比洞口小一圈的椭圆）
    body_rect = hole_rect.inflate(-20, -20)  # 缩小 20 像素
    body_rect.bottom = hole_rect.bottom      # 底部对齐（像从洞里冒出来）
    pygame.draw.ellipse(screen, (139, 90, 43), body_rect)
    # 地鼠的眼睛（两个小白点 + 黑眼珠）
    eye_size = 10
    left_eye_center = (body_rect.centerx - 15, body_rect.centery - 10)
    right_eye_center = (body_rect.centerx + 15, body_rect.centery - 10)
    pygame.draw.circle(screen, (255, 255, 255), left_eye_center, eye_size)
    pygame.draw.circle(screen, (255, 255, 255), right_eye_center, eye_size)
    pygame.draw.circle(screen, (0, 0, 0), left_eye_center, eye_size // 2)
    pygame.draw.circle(screen, (0, 0, 0), right_eye_center, eye_size // 2)
```

**讲解要点**：
- `random.randint(0, 8)` 随机选择洞口索引。
- `inflate(-20, -20)` 让地鼠比洞口小一点，看起来在洞里。
- 每次重绘时只在地鼠出现的洞口画地鼠，其他洞只画空洞口。

#### 2.3 第三步：自定义事件和定时器（5分钟）

**知识点**：`pygame.USEREVENT`、`pygame.time.set_timer()`

> "如果地鼠一直待在同一个洞里不动，那就不好玩了。我们希望地鼠每隔一段时间就换一个洞。Pygame 提供了一个'定时器'功能，可以每隔一定毫秒数自动触发一个事件。"

**代码示例**：

```python
# --- 自定义事件 ---
# USEREVENT 是 Pygame 预留给我们自定义事件的编号
# 我们用 USEREVENT + 1 表示"地鼠换洞"事件
MOLE_CHANGE_EVENT = pygame.USEREVENT + 1

# --- 设置定时器 ---
# 每隔 800 毫秒（0.8 秒）自动触发一次 MOLE_CHANGE_EVENT
pygame.time.set_timer(MOLE_CHANGE_EVENT, 800)
```

**在主循环中处理事件**：

```python
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

        # --- 处理自定义事件：地鼠换洞 ---
        elif event.type == MOLE_CHANGE_EVENT:
            spawn_mole()  # 地鼠随机换一个洞出现
```

**讲解要点**：
- `pygame.USEREVENT` 是一个基准编号（通常为 24），我们可以用 `USEREVENT + 1`、`USEREVENT + 2` 定义多个自定义事件。
- `set_timer(事件类型, 毫秒数)` 让 Pygame 每隔指定时间自动往事件队列里放一个事件。
- 事件队列中的自定义事件和鼠标、键盘事件一样，都在 `for event in pygame.event.get()` 循环中处理。

#### 2.4 第四步：点击检测——打地鼠！（5分钟）

**知识点**：`pygame.MOUSEBUTTONDOWN`、`Rect.collidepoint()`

> "地鼠已经出来了，现在我们要拿起'锤子'去打它。怎么判断鼠标点击有没有打到地鼠呢？"

**代码示例**：

```python
# --- 在主循环中处理鼠标点击 ---
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False
    elif event.type == MOLE_CHANGE_EVENT:
        spawn_mole()
    elif event.type == pygame.MOUSEBUTTONDOWN:
        # 获取鼠标点击的位置
        mouse_x, mouse_y = event.pos

        # 检查是否点中了当前有地鼠的洞
        if current_mole != -1:
            mole_rect = holes[current_mole]
            if mole_rect.collidepoint(mouse_x, mouse_y):
                print("打中啦！🎯")
                # 打中后，地鼠消失，等待下一个定时器事件重新出现
                current_mole = -1
```

**讲解要点**：
- `event.pos` 是一个元组 `(x, y)`，表示鼠标点击的坐标。
- `Rect.collidepoint(x, y)` 返回 `True` 当 `(x, y)` 在这个矩形内部。
- 打得中是因为鼠标坐标落在地鼠 Rect 的范围内。
- 打中后把 `current_mole` 设为 -1，地鼠就"缩回去"了。等到下一次定时器触发再出来。

## 常见问题与解决

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 地鼠不出现 | 忘记调用 `spawn_mole()` 初始化 | 在游戏循环前调用一次 |
| 地鼠不换位置 | 忘记在主循环中处理自定义事件 | 检查 `elif event.type == MOLE_CHANGE_EVENT` |
| 点不到地鼠 | `collidepoint` 用的 Rect 不对 | 确保用的是 `holes[current_mole]` |
| 地鼠换洞太快/太慢 | `set_timer` 的毫秒参数不合适 | 调整第二个参数（800 = 0.8秒） |
| 自定义事件不触发 | 事件编号冲突 | 用 `USEREVENT + 1` 而不要用 `USEREVENT` 本身 |
