### 二、音效技术讲解（13分钟）

#### 2.1 pygame.mixer 模块概述

pygame 的声音系统分为两个层次：

| 层次 | 用途 | 典型场景 | 同时播放数 |
|------|------|----------|-----------|
| `pygame.mixer.Sound` | 短音效 | 射击声、跳跃声、按钮点击 | 多个（8个通道） |
| `pygame.mixer.music` | 背景音乐 | 游戏BGM | 1首（独占） |

**关键区别（重点强调）：**
- `Sound` 适合短促的音效（< 5秒），可以同时播放多个
- `music` 适合长的背景音乐，同一时间只能播放一首

#### 2.2 音效播放 —— pygame.mixer.Sound

```python
import pygame
pygame.mixer.init()  # 初始化混音器（必须！）

# 加载音效文件
jump_sound = pygame.mixer.Sound("jump.wav")
shoot_sound = pygame.mixer.Sound("shoot.wav")

# 播放音效
jump_sound.play()       # 播放一次
jump_sound.play(loops=2)  # 播放3次（原始+循环2次）

# 控制音量（0.0 ~ 1.0）
jump_sound.set_volume(0.5)  # 50%音量

# 停止音效
jump_sound.stop()
```

**注意事项（告诉学生）：**
- 音效文件推荐使用 `.wav` 或 `.ogg` 格式
- `.mp3` 作为 Sound 加载在某些系统上可能有问题
- 播放前要确保 `pygame.mixer.init()` 已经调用

#### 2.3 背景音乐 —— pygame.mixer.music

```python
import pygame
pygame.mixer.init()

# 加载背景音乐
pygame.mixer.music.load("bgm.mp3")

# 播放控制
pygame.mixer.music.play()        # 播放一次
pygame.mixer.music.play(-1)      # 循环播放（-1表示无限循环）
pygame.mixer.music.play(loops=2) # 播放3次

# 控制
pygame.mixer.music.set_volume(0.3)  # 音量（背景音乐一般小一点）
pygame.mixer.music.pause()          # 暂停
pygame.mixer.music.unpause()        # 继续
pygame.mixer.music.stop()           # 停止
pygame.mixer.music.fadeout(2000)    # 2秒淡出

# 常用状态查询
pygame.mixer.music.get_busy()  # 是否正在播放 → True/False
```

#### 2.5 没有音频文件怎么办？（重要：解决实际困难）

**方案一：找免费音效资源**
- 推荐网站：freesound.org、mixkit.co、opengameart.org
- 课堂可以准备一个"音效素材包"发给学生

**方案二：用程序生成简单音效（推荐课堂演示）**
```python
import pygame
import numpy as np

def generate_beep(frequency=440, duration=0.1, volume=0.5, sample_rate=44100):
    """生成一个简单的蜂鸣音效"""
    t = np.linspace(0, duration, int(sample_rate * duration), False)
    wave = np.sin(frequency * 2 * np.pi * t) * volume
    # 转换为16位整数
    wave = (wave * 32767).astype(np.int16)
    # 立体声：复制到两个声道
    stereo = np.column_stack([wave, wave])
    return pygame.sndarray.make_sound(stereo)

# 使用
shoot_sound = generate_beep(880, 0.05)   # 高频短促 → 射击声
jump_sound = generate_beep(440, 0.1)     # 中频 → 跳跃声
explosion_sound = generate_beep(110, 0.3) # 低频长音 → 爆炸声
```

**方案三：简单的方波音效（无需numpy也能做）**
```python
import pygame
import math
import struct

def make_square_wave_sound(frequency=440, duration=0.1, volume=0.3):
    """用纯Python生成方波音效（不依赖numpy）"""
    sample_rate = 22050
    n_samples = int(sample_rate * duration)
    
    # 生成原始音频数据
    raw_data = b''
    for i in range(n_samples):
        t = i / sample_rate
        # 方波：sin值>0时取+1，否则取-1
        value = 1.0 if math.sin(2 * math.pi * frequency * t) > 0 else -1.0
        # 转换为16位有符号整数
        sample = int(value * volume * 32767)
        # 打包为小端序16位（立体声 = 左右声道相同）
        raw_data += struct.pack('<hh', sample, sample)
    
    return pygame.mixer.Sound(buffer=raw_data)
```

> **教师提示**：如果学生电脑没有numpy，可以使用方案三的纯Python方法。或者预先准备好几个生成的音效文件分发给学生。

### 四、作品完善环节教师指导要点（40分钟）

**巡回指导检查项：**

1. **音效加载检查**
   - 文件路径是否正确？（相对路径问题很常见）
   - 是否调用了 `pygame.mixer.init()`？
   - 音效文件格式是否兼容？（建议 wav/ogg）

2. **常见错误排查**
   - `pygame.error: Unable to open file` → 检查文件路径和文件名
   - `pygame.error: mixer not initialized` → 缺少 `pygame.mixer.init()`
   - 音效播放但没有声音 → 检查音量设置、系统音量

3. **UI优化建议**
   - 颜色搭配：使用不超过3-4种主色调
   - 字体选择：中文推荐使用系统自带字体（`pygame.font.SysFont('SimHei', 36)` 或 `'Microsoft YaHei'`）
   - 间距和对齐：元素之间保持适当间距，文字居中对齐
   - 反馈感：按钮被点击时有视觉变化（颜色变深、短暂缩放）

4. **差异化指导**
   - 进度快的学生：引导他们做挑战任务，或帮助其他同学
   - 进度慢的学生：确保完成基础任务，可以只加1个音效
   - 没有音频文件的学生：提供生成音效的代码，或发放音效素材包
