### 二、核心讲解（25分钟）

#### 步骤1：弹幕生成函数——"子弹工厂"（8分钟）

**核心思路**：弹幕的本质是什么？

想象你站在一个圆圈的中心，手里拿着很多支箭。你每转一个角度就射出一支箭，转完一圈就是 360° 的圆形弹幕；如果你只朝一个扇形区域射箭，那就是扇形弹幕。

所以弹幕生成只需要三个参数：**起点、角度范围、子弹数量**。

```python
import math
import pygame

def create_bullet_pattern(center_x, center_y, start_angle, angle_range, count, speed, bullet_group, color):
    """
    弹幕生成器 —— 子弹工厂！
    
    参数说明（像点菜一样简单）：
    ┌────────────────┬──────────────────────────────────┐
    │ 参数           │ 含义（用"烟花"打比方）            │
    ├────────────────┼──────────────────────────────────┤
    │ center_x, center_y │ 烟花发射的位置（Boss 的中心） │
    │ start_angle    │ 从哪个角度开始（0°=正右，顺时针） │
    │ angle_range    │ 覆盖多大的角度范围（扇形=60°）    │
    │ count          │ 产生几颗子弹（扇形=5~7颗）       │
    │ speed          │ 子弹飞多快                       │
    │ bullet_group   │ 子弹加入哪个精灵组               │
    │ color          │ 子弹什么颜色                     │
    └────────────────┴──────────────────────────────────┘
    """
    for i in range(count):
        # 计算第 i 颗子弹的角度
        if count == 1:
            # 只有1颗子弹 → 直接瞄准玩家方向
            angle_deg = start_angle
        else:
            # 多颗子弹 → 在角度范围内均匀分布
            # 比如 start_angle=60°, angle_range=60°, count=5
            # → 角度分别是 60°、75°、90°、105°、120°
            angle_deg = start_angle + angle_range * i / (count - 1)
        
        # 角度转弧度（计算机只认识弧度！）
        rad = math.radians(angle_deg)
        
        # 用三角函数拆解方向
        vx = speed * math.cos(rad)   # cos 管左右
        vy = speed * math.sin(rad)   # sin 管上下
        
        # 创建子弹精灵
        bullet = Bullet(center_x, center_y, vx, vy, color)
        bullet_group.add(bullet)
```

**为什么这个函数这么重要？**
有了它，我们只需要"点菜"（告诉参数），它就能生成一组子弹。不管是扇形还是圆形弹幕，都调用同一个函数，只是传不同的参数而已。这就是**代码复用**的思想。

#### 步骤2：扇形弹幕——"孔雀开屏"（6分钟）

**比喻讲解**：扇形弹幕就像孔雀开屏——从 Boss 身上向下展开一个扇形，子弹覆盖前方一片区域，让玩家需要左右躲避。

**扇形弹幕的特点**：
- 起始角度通常指向下方（90° 附近）
- 角度范围一般是 60°~90°（不要太宽，否则太简单）
- 子弹数量 5~7 颗（太少没威胁，太多太难）

```python
def fire_fan_pattern(boss, bullet_group):
    """
    扇形弹幕：像一把扇子向下展开
    
    想象一把打开的折扇：
    - 扇子的起点（扇柄）是 Boss 的位置
    - 扇子的方向朝下（90° 方向）
    - 扇子的展开角度是 60°
    - 扇骨就是子弹的飞行路径
    """
    # 参数设置
    center_x = boss.rect.centerx          # Boss 的 X 中心
    center_y = boss.rect.bottom           # 从 Boss 底部发出
    start_angle = 60                       # 起始角 60°（扇子左边缘）
    angle_range = 60                       # 覆盖 60°（扇子右边缘在 120°）
    count = 5                              # 5 颗子弹
    speed = 5                              # 速度适中
    
    # 调用弹幕工厂函数
    create_bullet_pattern(
        center_x, center_y,
        start_angle, angle_range, count, speed,
        bullet_group,
        color=(255, 100, 100)              # 浅红色子弹
    )

# ===== 在主循环里调用 =====
# 每过一定帧数（比如每 60 帧 = 1 秒）发射一次扇形弹幕
frame_count = 0
while running:
    frame_count += 1
    if frame_count % 60 == 0:             # 每 60 帧发射一次
        fire_fan_pattern(boss, enemy_bullets)
```

  ╱      |      ╲
 ●    ●  ●  ●    ●    ← 5颗子弹向下扇形展开（60°~120°）

#### 步骤3：圆形弹幕——"烟花绽放"（6分钟）

**比喻讲解**：圆形弹幕是弹幕游戏中最华丽的效果——Boss 像烟花一样向 360° 所有方向同时发射子弹，场面非常壮观！

**圆形弹幕的特点**：
- 起始角度 0°，角度范围 360°
- 子弹数量 16~24 颗（越多越密集）
- 所有子弹速度相同，向四面八方飞

```python
def fire_circle_pattern(boss, bullet_group):
    """
    圆形弹幕：像烟花一样 360° 绽放！
    
    想象国庆节放的烟花：
    - 烟花弹升到空中炸开
    - 火星向四面八方均匀飞出
    - 360° 形成一个大圆圈
    """
    # 参数设置
    center_x = boss.rect.centerx
    center_y = boss.rect.centery          # 从 Boss 中心发出
    start_angle = 0                        # 从 0° 开始
    angle_range = 360                      # 覆盖 360°（一圈！）
    count = 20                             # 20 颗子弹
    speed = 4                              # 速度稍慢一些
    
    # 调用弹幕工厂函数
    create_bullet_pattern(
        center_x, center_y,
        start_angle, angle_range, count, speed,
        bullet_group,
        color=(255, 200, 50)              # 金黄色子弹
    )

# ===== 在主循环里调用 =====
# Boss 生命值降到一半时开始放大招——每 120 帧发射圆形弹幕
if boss.hp <= boss.max_hp // 2:
    if frame_count % 120 == 0:
        fire_circle_pattern(boss, enemy_bullets)
```

**圆形弹幕的视觉效果**：
```
         ●  ●  ●
      ●           ●
    ●       Boss    ●
      ●     👾    ●
    ●               ●
      ●           ●
         ●  ●  ●
    ← 20颗子弹均匀分布，向四面八方飞出
```

**关键理解**：注意扇形弹幕和圆形弹幕的区别：

| 对比项 | 扇形弹幕 | 圆形弹幕 |
|--------|---------|---------|
| 比喻 | 孔雀开屏 | 烟花绽放 |
| 发射方向 | 只朝前方（下方） | 四面八方 |
| start_angle | 60°（扇子左边） | 0° |
| angle_range | 60°~90° | 360° |
| 发射位置 | Boss 底部 | Boss 中心 |
| 使用场景 | 普通攻击 | 大招/半血狂暴 |

#### 步骤4：Boss 血条绘制（5分钟）

**为什么要画大血条？**
Boss 是游戏中的重要敌人，它的血量比普通敌人多得多。一个大大的血条在屏幕上方，能让玩家清楚地看到 Boss 还剩多少血，增加战斗的紧张感。

**血条的绘制思路**：
1. 用两个矩形表示：背景矩形（灰色底）+ 前景矩形（红色/绿色血量）
2. 血量比例 = 当前血量 / 最大血量
3. 前景矩形的宽度 = 背景矩形宽度 × 血量比例

```python
def draw_boss_health_bar(screen, boss, screen_width):
    """
    绘制 Boss 大血条（屏幕顶部）
    
    血条就像手机的电量显示：
    - 灰色部分是"空电量"（已消耗的血）
    - 红色部分是"剩余电量"（当前血量）
    - 百分比显示在旁边
    """
    # 血条尺寸和位置
    bar_width = screen_width - 100        # 血条宽度（留 50 像素边距）
    bar_height = 25                        # 血条高度
    bar_x = 50                             # 血条左上角 X
    bar_y = 10                             # 血条左上角 Y
    
    # 第一步：画背景（灰色底条 = 总血量）
    pygame.draw.rect(screen, (60, 60, 60),
                     (bar_x, bar_y, bar_width, bar_height))
    
    # 第二步：画边框（白色描边，更醒目）
    pygame.draw.rect(screen, (255, 255, 255),
                     (bar_x, bar_y, bar_width, bar_height), 3)
    
    # 第三步：画当前血量（红色条 = 剩余血量）
    hp_ratio = boss.hp / boss.max_hp       # 血量比例：0.0 ~ 1.0
    current_width = int(bar_width * hp_ratio)  # 当前血量条的宽度
    
    # 血量颜色随比例变化：满血绿色 → 半血黄色 → 残血红色
    if hp_ratio > 0.5:
        hp_color = (50, 255, 50)           # 绿色（安全）
    elif hp_ratio > 0.25:
        hp_color = (255, 255, 50)          # 黄色（警告）
    else:
        hp_color = (255, 50, 50)           # 红色（危险！）
    
    pygame.draw.rect(screen, hp_color,
                     (bar_x, bar_y, current_width, bar_height))
    
    # 第四步：画 Boss 名字和血量文字
    font = pygame.font.Font(None, 28)
    name_text = font.render("BOSS", True, (255, 255, 255))
    screen.blit(name_text, (bar_x, bar_y + bar_height + 5))
    
    hp_text = font.render(f"{boss.hp}/{boss.max_hp}", True, (255, 255, 255))
    screen.blit(hp_text, (bar_x + bar_width - hp_text.get_width(),
                           bar_y + bar_height + 5))
```

- "为什么血量比例用 `boss.hp / boss.max_hp` 来计算？"（引导学生理解百分比的思想）
- "如果 Boss 有 500 点血，玩家每发子弹打 10 点血，需要打中多少次？"（心算练习）

## 💡 常见问题与解决

| 问题 | 原因 | 解决 |
|------|------|------|
| 弹幕方向不对，往天上飞了 | `start_angle` 设错了。屏幕坐标系中，90° 是正下方 | 检查角度值，屏幕下方 = 90°~180° 之间 |
| 圆形弹幕只在一侧 | `angle_range` 不是 360°，或者 `count` 太小 | 确保 `angle_range=360`，`count` 至少 16 颗 |
| 扇形弹幕不居中，偏左或偏右 | `start_angle` 和 `angle_range` 没有配合好 | 如果希望扇子居中朝下：`start_angle = 90 - angle_range/2`，比如 60° = 90 - 60/2 |
| 弹幕之间角度不均匀 | 循环中 `(count-1)` 的分母写错了 | 正确：`angle_deg = start_angle + angle_range * i / (count - 1)` |
| Boss 血条不变化 | `hp_ratio` 使用了整数除法（Python 3 已解决，但注意类型） | 确保 `boss.hp` 和 `boss.max_hp` 都是 float 或使用 `hp_ratio = boss.hp / boss.max_hp` |
| 血量归零后 Boss 还发射弹幕 | 没有在发射前检查 Boss 是否存活 | 在发射函数开头加 `if boss.hp <= 0: return` |
| 弹幕太密，电脑卡顿 | 子弹精灵没有 `kill()`，越积越多 | 确保在 `Bullet.update()` 中，子弹飞出屏幕后调用 `self.kill()` |
