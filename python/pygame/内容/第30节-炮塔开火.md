### 二、核心讲解（25分钟）

#### 2.1 距离计算 —— 炮塔的"眼睛"（5分钟）

炮塔需要知道敌人在不在自己的攻击范围内。这就用到数学中的**两点距离公式**。

```
距离 = √((x1 - x2)² + (y1 - y2)²)
```

在 Python 中的实现：

```python
import math

def 计算距离(x1, y1, x2, y2):
    """计算两点之间的欧几里得距离"""
    dx = x1 - x2          # x方向的差值
    dy = y1 - y2          # y方向的差值
    return math.sqrt(dx * dx + dy * dy)   # 开方得到距离
```

**举例验证**：
- (0, 0) 到 (3, 4) 的距离 = `√(9+16)` = 5 ✓
- 炮塔坐标(200, 300)，敌人坐标(250, 340)：距离 = `√(2500+1600)` = `√4100` ≈ 64

> **技巧提示**：如果只需要比较距离大小（不需要精确值），可以不求平方根，直接比较 `dx² + dy²` 与 `射程²`，这样更快！

```python
# 优化版：不用开方也能判断是否在射程内
距离平方 = dx * dx + dy * dy
if 距离平方 <= 射程 * 射程:
    # 在射程内！
```

#### 2.2 检测射程内的敌人（5分钟）

现在遍历所有敌人，找出在射程内的：

```python
def 获取射程内敌人(炮塔, 敌人列表):
    """返回所有在炮塔射程内的敌人"""
    射程内 = []
    for 敌人 in 敌人列表:
        dx = 炮塔.x - 敌人.x
        dy = 炮塔.y - 敌人.y
        距离平方 = dx * dx + dy * dy
        if 距离平方 <= 炮塔.射程 * 炮塔.射程:
            射程内.append(敌人)
    return 射程内
```

#### 2.3 自动瞄准 —— 选择最近的敌人（5分钟）

如果有多个敌人在射程内，炮塔应该优先攻击**最近的**那个（因为最近的威胁最大）。

```python
def 获取最近敌人(炮塔, 敌人列表):
    """返回射程内最近的敌人，没有则返回 None"""
    最近敌人 = None
    最近距离平方 = float('inf')  # 初始化为无穷大
    
    for 敌人 in 敌人列表:
        dx = 炮塔.x - 敌人.x
        dy = 炮塔.y - 敌人.y
        距离平方 = dx * dx + dy * dy
        
        if 距离平方 <= 炮塔.射程 * 炮塔.射程:
            if 距离平方 < 最近距离平方:
                最近距离平方 = 距离平方
                最近敌人 = 敌人
    
    return 最近敌人
```

**关键点**：
- `float('inf')` 表示无穷大，任何距离都比它小
- 只有射程内的敌人才参与比较

#### 2.4 发射子弹（5分钟）

炮塔在游戏循环中持续检测敌人，如果发现目标就发射子弹：

```python
# 在炮塔的更新逻辑中
if 炮塔.冷却计时器 <= 0:
    目标 = 获取最近敌人(炮塔, 敌人列表)
    if 目标 is not None:
        # 创建一颗子弹，飞向目标
        子弹 = {
            'x': 炮塔.x,
            'y': 炮塔.y,
            '目标': 目标,      # 子弹追踪这个敌人
            '速度': 5,
            '伤害': 炮塔.攻击力
        }
        子弹列表.append(子弹)
        炮塔.冷却计时器 = 炮塔.攻击间隔  # 重置冷却
else:
    炮塔.冷却计时器 -= 1
```

子弹每帧向目标移动：

```python
def 更新子弹(子弹):
    """让子弹飞向目标"""
    if 子弹['目标'] is None or 子弹['目标'].血量 <= 0:
        return False  # 目标已死，移除子弹
    
    dx = 子弹['目标'].x - 子弹['x']
    dy = 子弹['目标'].y - 子弹['y']
    距离 = math.sqrt(dx * dx + dy * dy)
    
    if 距离 < 5:  # 击中目标
        子弹['目标'].血量 -= 子弹['伤害']
        return False  # 子弹消失
    
    # 向目标移动
    子弹['x'] += dx / 距离 * 子弹['速度']
    子弹['y'] += dy / 距离 * 子弹['速度']
    return True  # 子弹继续存在
```

#### 2.5 经济系统（3分钟）

游戏中的金币系统让玩家需要策略性地决定在哪里放置炮塔：

```python
# 游戏初始状态
金币 = 200          # 初始金币
炮塔价格 = 100      # 放置一个炮塔需要100金币

# 放置炮塔时
def 放置炮塔(x, y):
    global 金币
    if 金币 >= 炮塔价格:
        金币 -= 炮塔价格
        炮塔列表.append(创建炮塔(x, y))
        return True
    else:
        print("金币不足！")
        return False

# 击杀敌人时
def 敌人死亡(敌人):
    global 金币
    金币 += 敌人.赏金  # 不同敌人可以有不同的赏金
```

经济系统给游戏增加了**策略深度**：玩家需要决定是先存钱买更贵的炮塔，还是先多放几个便宜的。

#### 2.6 敌人血量条绘制（2分钟）

血量条画在敌人头顶，让玩家直观看到每个敌人的剩余生命：

```python
def 绘制血条(屏幕, 敌人):
    """在敌人头顶绘制血量条"""
    血条宽度 = 30
    血条高度 = 4
    血条x = 敌人.x - 血条宽度 // 2
    血条y = 敌人.y - 15   # 头顶上方
    
    # 背景（红色 = 已损失的血量）
    pygame.draw.rect(屏幕, (255, 0, 0), 
                     (血条x, 血条y, 血条宽度, 血条高度))
    
    # 前景（绿色 = 剩余血量，宽度按比例缩放）
    剩余比例 = 敌人.血量 / 敌人.最大血量
    if 剩余比例 > 0:
        pygame.draw.rect(屏幕, (0, 255, 0),
                         (血条x, 血条y, int(血条宽度 * 剩余比例), 血条高度))
```

## 💡 常见问题与解决

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 炮塔不攻击 | 冷却计时器逻辑错误 | 检查 `if 冷却 <= 0` 和 `冷却 -= 1` 的位置 |
| 子弹追踪偏了 | 敌人位置已更新但子弹追的是旧坐标 | 每帧重新计算 `dx, dy` |
| 血条不变化 | 敌人血量被扣但绘制使用了旧变量 | 确认绘制时引用的是 `敌人.血量` 而非缓存值 |
| 金币变成负数 | 没有在放置前检查金币是否足够 | 加 `if 金币 >= 炮塔价格` 判断 |
| 敌人死后子弹空飞 | 子弹的目标引用已失效 | 检查 `目标.血量 <= 0` 后移除子弹 |
| 距离计算报错 | 忘了 `import math` | 文件顶部加 `import math` |
