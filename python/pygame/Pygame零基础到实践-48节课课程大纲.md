# 阶段一：初识 Pygame（第 1-4 节）

## 第 1 节：Hello, Pygame!

**内容**：安装 Pygame、创建第一个游戏窗口、设置窗口标题和大小、理解坐标系

**知识点**：
- `pygame.init()` / `pygame.quit()` — 初始化和退出
- `pygame.display.set_mode((宽, 高))` — 创建窗口
- `pygame.display.set_caption("标题")` — 设置窗口标题
- 坐标系概念（左上角为原点，x 向右，y 向下）
- RGB 颜色表示法 `(R, G, B)`

**课堂练习**：创建不同大小的彩色窗口

---

## 第 2 节：让画面动起来

**内容**：游戏主循环的概念、帧率控制、清屏与重绘、让一个矩形在屏幕上移动

**知识点**：
- `while True` 游戏主循环
- `pygame.time.Clock()` / `clock.tick(FPS)` — 帧率控制
- `screen.fill(颜色)` — 清屏
- `pygame.draw.rect(屏幕, 颜色, Rect)` — 绘制矩形
- 帧动画原理（每帧微调位置 → 视觉上的连续运动）

**课堂练习**：让一个彩色矩形在窗口中来回移动

---

## 第 3 节：键盘是我的遥控器

**内容**：事件机制入门、键盘按键检测、用方向键控制角色移动、边界限制

**知识点**：
- `pygame.event.get()` — 获取事件列表
- `pygame.QUIT` — 退出事件
- `pygame.KEYDOWN` — 按键按下事件
- `pygame.K_LEFT` / `K_RIGHT` / `K_UP` / `K_DOWN` — 方向键常量
- `pygame.key.get_pressed()` — 持续按键检测（平滑移动）
- 边界限制（`if x < 0: x = 0`）

**课堂练习**：用方向键控制矩形移动，不能跑出窗口

---

## 第 4 节：鼠标与图片

**内容**：鼠标事件处理、加载并显示图片、图片坐标跟随鼠标移动、图片缩放

**知识点**：
- `pygame.image.load("图片.png")` — 加载图片
- `screen.blit(图片, (x, y))` — 绘制图片到屏幕
- `pygame.MOUSEMOTION` — 鼠标移动事件
- `pygame.MOUSEBUTTONDOWN` — 鼠标点击事件
- `pygame.transform.scale(图片, (宽, 高))` — 图片缩放
- `.convert_alpha()` — 图片格式转换（提升性能）

**课堂练习**：图片跟随鼠标移动，点击放大/缩小

---

**阶段一目标**：学生能用 ~30 行代码写出「键盘控制角色 + 鼠标点击特效」的交互程序。

# 🏆 课程特色

1. **项目驱动**：20 个完整游戏，从第 5 节课开始每两节产出一个可玩的作品
2. **难度螺旋**：从弹球、接苹果到俄罗斯方块、RPG，难度逐级上升
3. **趣味优先**：所有案例都是经典游戏，学生有兴趣、有成就感
4. **知识融合**：每个项目引入 1-2 个新知识点，学以致用不枯燥
5. **自由创作**：最后 4 节留给学生发挥创意，真正掌握独立开发能力
6. **适合中小学生**：节奏适中，60 分钟讲练结合，每节课都有视觉反馈
