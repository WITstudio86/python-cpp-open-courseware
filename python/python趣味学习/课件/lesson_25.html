核心概念

KEY CONCEPTS

字典的四个核心概念

字典 (dict)

像一个有标签的收纳盒。每个东西都贴了标签，靠标签来找东西，而不是靠"第几个位置"。

键 (key)

标签，必须是唯一的（不能重名），通常用字符串。相当于字典里要查的那个"词"。

值 (value)

标签对应的内容，可以是任何类型：字符串、数字、列表、甚至另一个字典！

键值对 (key-value)

一个标签 + 它的内容 = 一对。"姓名": "小明"就是用冒号连接的一个键值对。

列表 vs 字典： 列表按位置找（第0个、第1个…像储物柜编号找），字典按标签找（"name"→"小明"，像字典查词找）。
【讲解】字典的四个核心概念 本页要点（照着讲即可）： · 核心概念 · KEY CONCEPTS · 字典 (dict) · 像一个有标签的收纳盒。每个东西都贴了标签，靠标签来找东西，而不是靠"第几个位置"。 · 键 (key) · 标签，必须是唯一的（不能重名），通常用字符串。相当于字典里要查的那个"词"。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

创建与访问

CORE TEACHING

创建字典 & 通过键访问

格式：{key1: value1, key2: value2, ...}，用冒号连接键和值，逗号分隔每一对。

# 创建字典——个人信息
person = {
    "姓名": "小明",
    "年龄": 12,
    "爱好": "编程",
    "城市": "北京"
}

# 通过 key 访问 value
print(person["姓名"])   # 小明
print(person["年龄"])   # 12

# 用变量作为 key
key = "爱好"
print(person[key])      # 编程
注意：如果 key 不存在，用 [] 访问会报错！后面我们会学 .get() 来安全访问。
【讲解】创建字典 & 通过键访问 本页要点（照着讲即可）： · 创建与访问 · CORE TEACHING · 格式： {key1: value1, key2: value2, ...} ，用冒号连接键和值，逗号分隔每一对。 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

增改与项目

PRACTICE

添加修改 & 迷你英汉词典

# 添加新键值对——key不存在就添加
person["宠物"] = "小猫"
person["梦想"] = "成为程序员"

# 修改已有值——key存在就修改
person["年龄"] = 13  # 过生日了！

# 用 in 判断 key 是否存在
print("身高" in person)  # False
# 📖 迷你英汉词典
dictionary = {
    "apple": "苹果", "banana": "香蕉",
    "cat": "猫", "dog": "狗", "hello": "你好"
}

word = input("请输入英文单词：")
if word in dictionary:
    print(f"{word} 的中文：{dictionary[word]}")
else:
    print("词典还没有这个词")
规则：dict[key] = value，如果 key 存在就修改，不存在就添加。非常直观！
