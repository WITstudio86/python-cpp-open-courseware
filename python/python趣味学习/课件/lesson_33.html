重点概念

KEY CONCEPTS

新知识点

import turtle

导入 Python 自带的 turtle（海龟）模块。导入后就能使用所有海龟画图的功能，不需要额外安装任何东西。

forward() / backward()

让海龟前进或后退指定距离（单位：像素）。如 turtle.forward(100) 向前走 100 像素。

right() / left()

让海龟右转或左转指定角度（单位：度）。如 turtle.right(90) 向右转 90 度。

turtle.done()

让画图窗口保持打开，不会画完就自动关闭。一般放在程序的最后一行。

核心讲解

CORE CONTENT

创建 Turtle 画布

# 第一步：导入 turtle 模块
import turtle

# 第二步：创建一个画布窗口（可选，自定义标题和背景色）
screen = turtle.Screen()
screen.title("我的海龟画板")
screen.bgcolor("lightyellow")

# 第三步：创建一只小海龟
t = turtle.Turtle()
t.shape("turtle")   # 设置为海龟形状
t.color("blue")      # 设置画笔颜色
t.pensize(3)         # 设置线条粗细

# 第四步：让海龟保持窗口不关闭
turtle.done()
小提示：Turtle 是 Python 自带的模块，不需要 pip install！只要电脑装了 Python 就能直接用。运行代码后会弹出一个新窗口，海龟就在那个窗口里画画。

画正方形

COMPLETE CODE

用海龟画一个正方形

import turtle

# 创建画布
screen = turtle.Screen()
screen.title("正方形")
screen.bgcolor("#f0f0e8")

# 创建海龟
t = turtle.Turtle()
t.shape("turtle")
t.color("darkgreen")
t.pensize(4)

# 画正方形：前进 → 右转90° → 前进 → 右转90°……
t.forward(150)
t.right(90)
t.forward(150)
t.right(90)
t.forward(150)
t.right(90)
t.forward(150)
t.right(90)

turtle.done()
思考：正方形有 4 条边、4 个直角。每条边前进 150 像素，每画完一条边右转 90 度，重复 4 次 —— 正方形就画好了！这其实就是"前进 + 右转"重复 4 次。

移动指令大全

MOVE COMMANDS

海龟移动指令大全

import turtle

t = turtle.Turtle()
t.shape("turtle")

# ── 前进和后退 ──
t.forward(100)      # 前进 100 像素（也可写成 t.fd(100)）
t.backward(50)      # 后退 50 像素（也可写成 t.bk(50)）

# ── 左转和右转 ──
t.right(90)         # 向右转 90 度（也可写成 t.rt(90)）
t.left(45)          # 向左转 45 度（也可写成 t.lt(45)）

# ── 回到原点 ──
t.home()           # 回到坐标 (0, 0)，方向朝右

# ── 跳转到指定位置（不画线） ──
t.penup()          # 抬笔
t.goto(50, 50)     # 移动到 (50, 50)
t.pendown()        # 落笔，继续画

# ── 画圆 ──
t.circle(60)       # 画一个半径为 60 的圆

turtle.done()
【讲解】海龟移动指令大全 本页要点（照着讲即可）： · 移动指令大全 · MOVE COMMANDS 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
