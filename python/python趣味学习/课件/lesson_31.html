重点概念

KEY CONCEPTS

重点概念

return 是"上交"

函数用 return 把计算结果交出来。调用方可以把返回值存到变量里，拿去继续使用。print 只是"打印给你看"，看完就没了。

print vs return

print 是"展示"——把内容输出到屏幕。return 是"上交"——把值交还给调用者。print 的值无法被变量接收，return 的值可以。

return 终止函数

函数一旦执行到 return，后面的代码就不会再运行了。return 之后的所有代码都会被跳过。

多个返回值

return 后面可以写多个值，用逗号分隔。函数返回一个元组，接收时可以用元组解包一次性拿到所有值。

CORE CONTENT

return 基本用法

# return 语法骨架
def 函数名(参数):
    做事情...
    return 结果值  # 把"结果值"交出去

变量 = 函数名(实参)  # 用变量接住返回值
# 示例：计算圆面积
def circle_area(radius):
    area = 3.14 * radius * radius
    return area  # 把结果"交上去"

r = 5
result = circle_area(r)      # 接住返回值
print(f"半径为{r}的圆面积是：{result}")
没有 return 会怎样？如果函数没有 return 语句，它偷偷返回一个特殊值 None（空值），你存到变量里也啥都拿不到。
# 有 return vs 无 return
def add_with_return(a, b):
    return a + b

def add_without_return(a, b):
    print(a + b)  # 只打印，不交结果

x = add_with_return(3, 5)    # x 拿到 8
y = add_without_return(3, 5) # 屏幕打印 8，但 y 是 None！
print(f"x = {x}, y = {y}")    # x = 8, y = None

print vs return 深度对比

# 场景：写一个函数，判断是否及格
# 用 print —— 结果只能看，没法接着用
def check_score_print(score):
    if score >= 60:
        print("及格！")
    else:
        print("不及格")

msg = check_score_print(85)  # 屏幕打印"及格！"
print(msg)  # None！因为 print 没有返回值！
# 用 return —— 结果可以存下来，发给别人，写进文件
def check_score_return(score):
    if score >= 60:
        return "及格！"
    else:
        return "不及格"

msg = check_score_return(85)  # 屏幕不打印
print(msg)  # "及格！"  —— 存下来了，想怎么用怎么用
记住：print 是"给你看"，return 是"交给你"。"给你看"的东西你拿不到，"交给你"的东西你才能存、能算、能传给别的函数！

return 立即终止函数

def demo():
    print("第1步")
    return "交作业！"   # 函数在这里结束！
    print("第2步")    # 永远不会执行
    print("第3步")    # 永远不会执行

result = demo()
print(result)
# 输出：
# 第1步
# 交作业！

返回多个值 & 课堂练习

# 一个函数，一次返回多个结果！
def analyze_numbers(a, b, c):
    total = a + b + c
    avg = total / 3
    max_val = max(a, b, c)
    min_val = min(a, b, c)
    return total, avg, max_val, min_val  # 逗号分隔！

# 元组解包接收
t, a, mx, mn = analyze_numbers(85, 92, 78)
print(f"总分：{t}，平均：{a:.1f}，最高：{mx}，最低：{mn}")
# 实用示例：计算矩形周长和面积
def rectangle_info(width, height):
    perimeter = 2 * (width + height)
    area = width * height
    return perimeter, area

p, a = rectangle_info(5, 3)
print(f"周长：{p}，面积：{a}")  # 周长：16，面积：15
元组解包：return a, b, c 实际上返回的是一个元组 (a, b, c)。x, y, z = 函数() 就是把这个元组"拆开"分给三个变量。变量个数必须和返回值个数一致！

SUMMARY

学会了什么？

核心要点

  • return 是函数的"交作业"语句，把结果交还给调用者
  • print 只是"展示"，用完就没了；return 才是"上交"，可以存储复用
  • 没有 return 的函数，默认返回 None（空值）
  • 函数执行到 return 就立刻终止，后面的代码不会运行
  • return 可以一次返回多个值（元组），用元组解包接收
  • 能用 return 就不用 print——让函数"上交"结果而不是"喊出来"
