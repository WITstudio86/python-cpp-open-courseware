重点概念

KEY CONCEPTS

重点概念

创作流程

构思 → 草图 → 拆解 → 编码 → 调试 → 展示。
一个好项目从画草图开始，不是上来就写代码。

拆解思维

把复杂画面拆成基本图形：太阳=圆、房子=三角形+正方形、花=循环画花瓣。分而治之，逐个击破。

代码组织

注释说明意图、变量管理颜色/尺寸、函数封装重复图形。让代码像搭积木一样清晰有序。

调试迭代

运行 → 观察 → 调整 → 再运行。每次只改一个小地方，测试通过后再改下一处。别一次改太多！

核心讲解

CORE CONTENT

风景画示例：完整创作流程

画面包含：蓝天背景 + 绿色草地 + 太阳 + 小房子 + 一朵花（循环花瓣）

# 1. 导入库 + 初始化画布
import turtle

t = turtle.Turtle()
t.speed(0)          # 最快速度
screen = turtle.Screen()
screen.bgcolor("#87CEEB")  # 蓝天背景
# 2. 画绿色草地
t.penup()
t.goto(-400, -100)
t.pendown()
t.color("#4CAF50")
t.begin_fill()
for _ in range(2):
    t.forward(800)
    t.right(90)
    t.forward(300)
    t.right(90)
t.end_fill()
# 3. 画太阳（圆形 + 填充）
t.penup()
t.goto(200, 200)
t.pendown()
t.color("#FFD700")
t.begin_fill()
t.circle(50)
t.end_fill()
# 4. 画小房子 —— 用函数封装！
def draw_house(x, y, size=80):
    """在坐标 (x,y) 处画一个小房子"""
    t.penup()
    t.goto(x, y)
    t.pendown()
    t.color("#8B4513")
    # --- 墙壁 ---
    t.begin_fill()
    for _ in range(4):
        t.forward(size)
        t.left(90)
    t.end_fill()
    # --- 屋顶 ---
    t.color("#C4593F")
    t.begin_fill()
    for _ in range(3):
        t.forward(size + 20)
        t.left(120)
    t.end_fill()
    # --- 门 ---
    t.penup()
    t.goto(x + size*0.35, y)
    t.pendown()
    t.color("#5D3A1A")
    t.begin_fill()
    for _ in range(2):
        t.forward(size*0.3)
        t.left(90)
        t.forward(size*0.5)
        t.left(90)
    t.end_fill()

# 调用函数，画房子！
draw_house(-100, -100)
# 5. 画一朵花（循环花瓣）
t.penup()
t.goto(100, -60)
t.pendown()

num_petals = 8
angle = 360 / num_petals

for _ in range(num_petals):
    t.color("#FF69B4")
    t.begin_fill()
    for _ in range(2):
        t.circle(15, 90)
        t.left(90)
        t.circle(15, 90)
    t.end_fill()
    t.left(angle)

# 花蕊
t.color("#FFD700")
t.begin_fill()
t.circle(10)
t.end_fill()

# 隐藏海龟，完成！
t.hideturtle()
turtle.done()
运行方式：把上面的代码按顺序拼到一起，保存为 landscape.py，用 python landscape.py 运行，就能看到完整的风景画！
函数封装的好处：draw_house(x, y, size) 画一次定义好，想在哪里画房子就调用一次，想画多大调一下 size 参数就好。这就是"代码复用"！
【讲解】风景画示例：完整创作流程 本页要点（照着讲即可）： · 核心讲解 · CORE CONTENT · 画面包含：蓝天背景 + 绿色草地 + 太阳 + 小房子 + 一朵花（循环花瓣） 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。

CREATIVE TASK

创作任务：你的 Turtle 作品

创作要求：① 确定一个主题 ② 至少使用 3 种不同的 Turtle 命令 ③ 至少使用 2 种颜色 ④ 代码中要有注释说明
创作流程：5 分钟构思 + 5 分钟拆解草图 + 25 分钟编码。先在纸上画出草图，标出每个部分用什么图形实现，再动手写代码！
