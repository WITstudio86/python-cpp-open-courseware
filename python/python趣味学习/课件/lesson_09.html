第9节
重点概念

KEY CONCEPTS

重点概念

str() — 变成字符串

把任何东西转成字符串。str(123) 得到 "123"，str(3.14) 得到 "3.14"。最包容的转换函数，几乎什么都能转

int() — 变成整数

把字符串或小数转成整数。int("123") 得到 123；int(3.99) 得到 3（截断！不是四舍五入！int("3.14") 会报错！）

float() — 变成小数

把字符串或整数转成小数。float("3.14") 得到 3.14，float(10) 得到 10.0。比 int() 更宽容，能转换带小数点的字符串

input() 陷阱

input() 拿到的永远是字符串！即使用户输入数字 10，得到的也是 "10"（字符串），做数学运算前必须用 int() 或 float() 转换

第9节
核心讲解

EXPLANATION

核心讲解

# ===== 1. str() —— 万物皆可转字符串 =====
print(str(123))               # "123"（数字→文字）
print(str(3.14))             # "3.14"（小数→文字）

# ===== 2. int() —— 变成整数（注意：截断！）=====
print(int("123"))             # 123（字符串→整数）
print(int(3.99))            # 3（直接砍掉小数，不是10！）
print(round(3.99))           # 4（这才是四舍五入）
# int("3.14") ← 报错！先 float 再 int → int(float("3.14"))

# ===== 3. float() —— 变成小数 =====
print(float("3.14"))          # 3.14
print(float(10))            # 10.0（整数→小数）

# ===== 4. input() 陷阱 —— 必须转换！=====
num = input("输入数字：")      # 用户输入 5 → num 是 "5"（字符串！）
print(num * 2)               # "55"（字符串重复，不是10！）
num = int(input("输入数字：")) # 正确做法：直接转换
print(num * 2)               # 10（这才是数学乘法）

# ===== 5. 加法练习器（精简版）=====
import random
a = random.randint(1, 99)
b = random.randint(1, 99)
answer = int(input(f"{a} + {b} = ?"))
print(f"{'✅ 正确！' if answer == a + b else f'❌ 正确答案是 {a + b}'}")
提示： int() 截断不是四舍五入——int(3.99) = 3！要用四舍五入请用 round()。int("3.14") 会报错，需要两步走：int(float("3.14"))。变量名不要用 str、int、float、print 等内置函数名！
