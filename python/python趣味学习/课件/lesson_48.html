子任务A：升级版猜数字

电脑随机生成 1~100 之间的整数，玩家有 7 次机会。每次猜测后系统给出智能提示：

  • 猜对了 → 恭喜通关，显示用了多少次
  • 猜大了 / 猜小了 → 基本方向提示
  • 差距在 5 以内 → "很接近了！🔥"
  • 差距在 20 以上 → "还差得远呢~"
  • 显示 猜测历史记录（所有猜过的数字）
  • 7 次用完未猜中 → 游戏结束，揭晓答案

子任务B：成绩分析器

用户输入 5 个成绩（0~100分），程序自动完成：

  • 计算 平均分（保留1位小数）
  • 找出 最高分 和 最低分
  • 成绩 排序（从高到低 & 从低到高）
  • 自动 评级：90+优秀 / 75+良好 / 60+及格 / 60-需要努力
  • 统计 及格人数 和 不及格人数
算法流程（猜数字）： 生成随机数 → 初始化 chances=7, history=[] → while chances > 0: 输入猜测 → 记录到 history → 判断大小/接近度 → 猜对则 break → chances -= 1 → 次数用完显示答案

CODE WALKTHROUGH

两大子任务核心代码

子任务A：猜数字核心逻辑

import random

secret = random.randint(1, 100)
chances = 7
history = []

print("🎯 升级版猜数字！1~100，你有7次机会")

while chances > 0:
    guess = int(input(f"请输入你的猜测（剩余{chances}次）："))
    history.append(guess)

    if guess == secret:
        print(f"🎉 恭喜猜对！答案就是 {secret}，用了 {len(history)} 次")
        break
    elif guess > secret:
        diff = guess - secret
        if diff <= 5:
            print("大了，但很接近了！🔥")
        elif diff >= 20:
            print("太大了！还差得远呢~")
        else:
            print("大了，再小一点")
    else:
        diff = secret - guess
        if diff <= 5:
            print("小了，但很接近了！🔥")
        elif diff >= 20:
            print("太小了！还差得远呢~")
        else:
            print("小了，再大一点")

    print(f"📋 猜测历史：{history}")
    chances -= 1

if chances == 0:
    print(f"😢 次数用完！答案是 {secret}，下次加油！")

子任务B：成绩分析器

scores = []
for i in range(5):
    score = int(input(f"请输入第 {i+1} 个成绩（0~100）："))
    scores.append(score)

average = sum(scores) / len(scores)
highest = max(scores)
lowest = min(scores)
sorted_desc = sorted(scores, reverse=True)

# 评级
if average >= 90:   grade = "优秀"
elif average >= 75: grade = "良好"
elif average >= 60: grade = "及格"
else:               grade = "需要努力"

pass_count = sum(1 for s in scores if s >= 60)

print(f"平均分：{average:.1f}  最高：{highest}  最低：{lowest}")
print(f"评级：{grade}  及格：{pass_count}人  不及格：{5-pass_count}人")
print(f"成绩排序（高→低）：{sorted_desc}")

FUTURE PATHWAYS

Python 后续学习方向 —— 你的编程之旅才刚刚开始！

Python 是一把瑞士军刀，你可以用它做几乎任何事情！以下是五大进阶方向，选择你最感兴趣的一条路继续前进。

1. 游戏开发 (pygame)

用 pygame 库制作 飞机大战、贪吃蛇、超级玛丽 等经典 2D 游戏。学习碰撞检测、精灵动画、音效播放，把你的创意变成可以玩的作品！推荐资源：《Python游戏编程快速上手》。

2. 网络爬虫 (requests + BS4)

用 requests 获取网页内容，BeautifulSoup 解析数据。自动获取 天气预报、新闻头条、漫画更新，打造专属信息小助手。从爬取一个简单网页开始！

3. AI 人工智能入门

用 scikit-learn 和简单的神经网络，完成 手写数字识别、图片分类、文本情感分析。了解机器学习的基本概念：训练、预测、准确率。推荐：Google 的 Teachable Machine。

4. 实用工具开发

用 Python 写自动化脚本：文件批量改名、PDF 合并拆分、Excel 数据处理、定时发送邮件。给家人和朋友做实用小程序，让编程真正服务于生活！

5. 网站开发 (Flask / Django)

用 Flask 或 Django 框架搭建 个人博客、在线小游戏、班级留言板、学习打卡网站。学习 HTML + CSS + Python 后端，从本地网页到部署上线，拥有一段属于自己的网址！
