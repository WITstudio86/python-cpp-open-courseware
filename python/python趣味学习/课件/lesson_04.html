第4节
重点概念

KEY CONCEPTS

重点概念

input() 函数

Python 接收用户输入的函数。程序运行到 input() 时停下，等用户在键盘输入并按回车，用户输入的内容被当作字符串返回。

交互式程序

能和用户"对话"的程序——不是运行完就结束，而是在运行中问用户问题，根据回答做出不同反应的"活"程序。

变量（初步概念）

像一个有标签的储物盒。name = input("你的名字？") 就是先贴标签"name"，再把用户输入放进去，以后用 name 就是从盒子里取东西。

提示文字（Prompt）

input() 括号里的文字，在等待输入时显示在屏幕上，告诉用户"现在需要输入什么"。可以写得有趣、有创意。

【讲解】重点概念 本页要点（照着讲即可）： · KEY CONCEPTS · input() 函数 · Python 接收用户输入的函数。程序运行到 input() 时停下，等用户在键盘输入并按回车，用户输入的内容被当作字符串返回。 · 交互式程序 · 能和用户"对话"的程序——不是运行完就结束，而是在运行中问用户问题，根据回答做出不同反应的"活"程序。 · 变量（初步概念） 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
第4节
核心讲解

EXPLANATION

核心讲解：input() 让程序"听话"

# 最简单的一问一答
name = input("你叫什么名字？")
print("你好，", name, "！欢迎来学Python！")

# 多轮对话 —— 小调查
print("=" * 30)
name = input("你的名字：")
age = input("你今年几岁了？")
hobby = input("你最大的爱好是？")
print()
print("--- 你的答案 ---")
print("我叫", name, "，今年", age, "岁，喜欢", hobby)

# input() 永远返回字符串！注意这个坑：
num1 = input("请输入第一个数字：")  # 输入5
num2 = input("请输入第二个数字：")  # 输入3
print(num1 + num2)  # 输出"53"而不是8！因为字符串拼接

# 正确做法：用 int() 转换
a = int(input("请输入第一个数字："))
b = int(input("请输入第二个数字："))
print(a + b)  # 正确输出 8！
提示： input() 拿到的东西永远是文字（字符串）。如果要做数学计算，记得用 int() 或 float() 包一下！字符串的 + 是"拼接"（"5"+"3"="53"），不是数学加法。
【讲解】核心讲解：input() 让程序"听话" 本页要点（照着讲即可）： · EXPLANATION 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。
