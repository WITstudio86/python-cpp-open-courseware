重点概念

KEY CONCEPTS

重点概念

函数 = 打包好的代码块

把一段会重复用到的代码「打包」起来，给它起个名字，以后直接用名字调用，不用再重写一遍。

榨汁机类比

放水果（输入）→ 机器内部处理 → 出果汁（输出）。函数也一样：给参数（输入）→ 执行代码 → 返回结果（输出）。

你已经用过很多函数了！

print()、input()、len()、type()、int()、str()、range() —— 这些全是 Python 内置的函数，你已经用了很久了！

函数的三大好处

1) 不重复写代码（DRY 原则）；2) 修改一处，处处生效；3) 代码分块，逻辑更清晰，更容易读懂。

核心讲解

CORE CONTENT

有函数 vs 没函数 —— 代码大对比

场景：你需要在一个程序里三次计算不同圆的面积。看看两种写法差多少！

❌ 没有函数 —— 代码重复又难改

# 计算圆1的面积
r1 = 5
area1 = 3.14 * r1 * r1
print(f"半径{r1}的圆面积是{area1}")

# 计算圆2的面积 —— 又要写一遍！
r2 = 10
area2 = 3.14 * r2 * r2
print(f"半径{r2}的圆面积是{area2}")

# 计算圆3的面积 —— 再来一遍！
r3 = 15
area3 = 3.14 * r3 * r3
print(f"半径{r3}的圆面积是{area3}")

# 如果要把 3.14 改成 3.14159，要改 3 处！😱

✅ 用函数 —— 简洁、清晰、好修改

# 先把「算面积」打包成函数
def circle_area(r):
    return 3.14 * r * r

# 以后想算几次就调用几次！
print(f"半径5的圆面积是{circle_area(5)}")
print(f"半径10的圆面积是{circle_area(10)}")
print(f"半径15的圆面积是{circle_area(15)}")

# 要改精度？只改函数里的 3.14 一处就行！😎
结论：不用函数，同样逻辑写了 3 遍，改一处要改 3 个地方。用函数，逻辑只写 1 遍，改也只改 1 处，调用多少次都行！

ANALOGY & REVIEW

榨汁机类比 —— 函数就是代码界的榨汁机

🍊
放水果
（输入/参数）
→
机器加工
（函数内部代码）
→
出果汁
（输出/返回值）
  • 你不用知道榨汁机里面怎么运作的，你只管放水果、拿果汁 —— 这就是函数的「封装」
  • 同一台榨汁机可以榨橙子、榨苹果、榨西瓜 —— 同一个函数，传入不同参数，得到不同结果
  • 榨汁机坏了只修机器，不用每个水果摊都修 —— 函数有 bug 只改一处

更多示例

MORE EXAMPLES

生活中的「函数思维」

# 场景：在多个地方打印分隔线
# ❌ 没有函数：每次都写一遍
print("====================")
print("  第一章")
print("====================")  # 重复！
print("  第二章")
print("====================")  # 又重复！

# ✅ 用函数：定义一次，到处调用
def print_line():
    print("====================")

print_line()
print("  第一章")
print_line()
print("  第二章")
print_line()

# 如果要改成 "--------" 样式的分隔线，
# 没函数：改 3 处。有函数：只改 1 处！
# 场景：多次计算总分和平均分
def calc_score(chinese, math, english):
    total = chinese + math + english
    avg = total / 3
    return total, avg  # 一次返回两个结果！

# 小明
t, a = calc_score(90, 85, 92)
print(f"小明：总分{t}，平均{a:.1f}")

# 小红
t, a = calc_score(88, 91, 87)
print(f"小红：总分{t}，平均{a:.1f}")

# 小刚 —— 一行搞定！
t, a = calc_score(76, 82, 79)
print(f"小刚：总分{t}，平均{a:.1f}")
记住：只要你发现自己在「复制粘贴」代码，就应该想：「这段代码能不能打包成一个函数？」—— 这是成为编程高手的第一个习惯！

SUMMARY

学会了什么？

核心要点

  • 函数是「打包好的代码块」，给它起个名字就能重复使用
  • 榨汁机类比：放材料（参数）→ 加工（函数体）→ 出成品（返回值）
  • 三大好处：不重复写代码、修改方便、逻辑清晰
  • 你已经用过很多内置函数：print()、input()、len()、type()、int()、str()、float()、range()
  • 编程好习惯：发现复制粘贴代码时，就把它打包成函数
  • 函数让程序从「平铺直叙」变成「分块组织」，更容易理解和维护
