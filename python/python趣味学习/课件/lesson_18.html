重点概念

KEY CONCEPTS

三大循环模式

累加器模式

先准备一个变量（初始为 0），在循环中不断往上面加。就像存钱罐，每次往里面投币。total = 0; total += i

计数器模式

先准备一个变量（初始为 0），满足条件就 +1。就像计分板。count = 0; count += 1

字符串累加

先准备一个空字符串 ""，在循环中不断拼接。就像串珠子。result = ""; result += char

格式化打印

用 \t（制表符）和 :2d 来对齐输出，让打印的内容整整齐齐。

累加器与计数器

CORE CONTENT

累加器与计数器

# 累加器：求 1+2+3+4+5 的和
total = 0  # 先准备一个"存钱罐"
for i in range(1, 6):
    total = total + i  # 或者 total += i
    print(f"加了 {i}，现在总和是 {total}")
print(f"最终结果：{total}")  # 15
执行过程追踪：第1次 total=0+1=1，第2次 total=1+2=3，第3次 total=3+3=6，第4次 total=6+4=10，第5次 total=10+5=15。
# 计数器：统计 1-50 中能被 7 整除的数有几个
count = 0
for i in range(1, 51):
    if i % 7 == 0:
        print(f"{i} 是 7 的倍数")
        count += 1
print(f"一共有 {count} 个")
【讲解】累加器与计数器 本页要点（照着讲即可）： · 累加器与计数器 · CORE CONTENT 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

九九乘法表

CORE CONTENT

九九乘法表

# 完整版九九乘法表
for i in range(1, 10):        # 外层循环：第几行（乘数）
    for j in range(1, i+1):   # 内层循环：这一行有几列
        print(f"{j}×{i}={i*j:2d}", end="  ")
    print()  # 一行结束，换行
双重循环解释：外层循环控制"第几行"（乘数 i），内层循环控制"这一行有几列"（被乘数 j）。第1行有1列（1x1=1），第2行有2列（1x2=2, 2x2=4），...，第9行有9列。
# 输出效果：
# 1×1= 1
# 1×2= 2  2×2= 4
# 1×3= 3  2×3= 6  3×3= 9
# ...
# 1×9= 9  2×9=18  3×9=27  4×9=36  ...  9×9=81
