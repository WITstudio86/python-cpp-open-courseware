第45节
重点概念

KEY CONCEPTS

重点概念

随机数

计算机生成的"看起来没规律"的数字。Python 使用梅森旋转算法（Mersenne Twister）生成高质量伪随机数。random.seed() 可固定种子，让随机结果"可复现"，方便调试。

字符集四大家族

大写字母（26个）、小写字母（26个）、数字（10个）、特殊符号（32个）。四者组合共有 26+26+10+32 = 94 个字符。12位密码的可能组合数 = 94^12，约 4.7×10^23 种！

random.choice()

random.choice(序列) 从列表、字符串等序列中随机选取一个元素返回。比如 random.choice("ABC") 可能返回 "A"、"B" 或 "C"。密码生成的核心工具！

random.shuffle()

random.shuffle(列表) 将列表中元素的顺序原地随机打乱（像洗扑克牌一样），直接修改原列表，返回 None。打乱后先选的大写字母就不会总是排在前面了。

强密码三要素

① 长度 >= 12（越长越难暴力破解）；② 包含多种字符类型（大写+小写+数字+符号全都要）；③ 没有规律（不用生日、姓名、键盘序列如 qwerty、123456 等常见弱密码）

string 模块速查

string.ascii_uppercase = "ABCDEF...Z"
string.ascii_lowercase = "abcdef...z"
string.digits = "0123456789"
string.punctuation = "!\"#$%&...~"
一行 import，免去手打之苦！

核心讲解

EXPLANATION

核心讲解：随机密码生成器完整实现

从一行代码到完整项目 —— 先看最小版本，再看健壮版本，循序渐进。

# ============================================================
# 第一步：导入模块
# ============================================================
import random
import string

# ============================================================
# 第二步：用 string 模块获取四类字符集
# ============================================================
uppers = string.ascii_uppercase   # 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'
lowers = string.ascii_lowercase   # 'abcdefghijklmnopqrstuvwxyz'
digits = string.digits            # '0123456789'
symbols = string.punctuation      # '!"#$%&\'()*+,-./:;<=>?@[\\]^_`{|}~'

# ============================================================
# 第三步：生成密码的核心函数
# ============================================================
def generate_password(length=12):
    # 1. 每种类型至少选 1 个 —— 确保四类字符都有
    password_list = [
        random.choice(uppers),   # 1个大写字母
        random.choice(lowers),   # 1个小写字母
        random.choice(digits),   # 1个数字
        random.choice(symbols),  # 1个特殊符号
    ]

    # 2. 把四类字符合并成一个"大池子"
    all_chars = uppers + lowers + digits + symbols  # 共94个字符

    # 3. 剩余位置从大池子中随机选取
    for _ in range(length - 4):
        password_list.append(random.choice(all_chars))

    # 4. 打乱顺序 —— 让先选的4个不会总是排在最前面
    random.shuffle(password_list)

    # 5. 用 join() 把列表拼成一个字符串
    return "".join(password_list)

# ============================================================
# 第四步：测试生成
# ============================================================
print("=== 随机密码生成器 ===")
for i in range(5):
    pwd = generate_password(16)
    print(f"密码{i+1}: {pwd}")

# 输出示例：
# 密码1: kQ7#mX2_nP!wL5vA
# 密码2: }f3Jc9@hUoGb4(Dx
# 密码3: yR!8pV_m2*Ns6ZqH
进阶版：让用户自定义 —— 在实际项目里，可以增加参数让用户选择要包含哪些字符类型、排除易混淆字符（l/1/O/0），以及指定最短长度（强密码底线：至少12位！）。下面的练习里就让大家自己动手实现这些功能。

random 函数速查卡

random.choice(seq)随机选1个元素
random.choices(seq, k=n)随机选n个（可重复）
random.sample(seq, k=n)随机选n个（不重复）
random.shuffle(lst)原地打乱列表
random.randint(a, b)[a,b]间随机整数
random.seed(n)设置随机种子
