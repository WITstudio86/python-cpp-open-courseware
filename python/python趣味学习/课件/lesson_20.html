重点概念

KEY CONCEPTS

break vs continue

break —— 跳出

立即终止整个循环，执行循环后面的代码。就像"不玩了，退出！"

适用场景："找到就停"——在列表中找第一个满足条件的元素。

continue —— 跳过

跳过本次循环剩余的代码，直接开始下一次循环。就像"这轮跳过，下一轮！"

适用场景："不符合条件就跳过"——只处理满足条件的元素。

区别记忆：break 是"下课了，全体解散"；continue 是"你留下，其他人继续"。两者在 for 和 while 中都能用。

核心讲解

CORE CONTENT

break 和 continue 实战

# break：密码验证（最多3次机会）
password = "hello123"
chances = 3

while chances > 0:
    user_input = input(f"请输入密码（还剩{chances}次）：")
    if user_input == password:
        print("密码正确！欢迎！")
        break  # 对了就跳出
    chances -= 1
    if chances > 0:
        print("密码错误！再试一次~")

if chances == 0:
    print("3次机会用完，账户已锁定！")
# continue：打印 1-10，但跳过 3 的倍数
for i in range(1, 11):
    if i % 3 == 0:
        continue  # 跳过本次，不执行下面的 print
    print(i)
# 输出：1 2 4 5 7 8 10 （3、6、9 被跳过了）

对比演示

COMPARISON

break vs continue 对比

# break：找到第一个偶数就停
for i in [1, 3, 5, 6, 7, 8]:
    if i % 2 == 0:
        print(f"找到偶数 {i}，停止！")
        break
# 输出：找到偶数 6，停止！（不会处理 7 和 8）

# continue：只打印偶数，奇数跳过
for i in [1, 3, 5, 6, 7, 8]:
    if i % 2 != 0:
        continue
    print(f"偶数：{i}")
# 输出：偶数：6  偶数：8
# 点名跳过请假同学
students = ["小明", "小红（请假）", "小刚", "小丽（请假）", "小华"]
for student in students:
    if "请假" in student:
        print(f"  {student} → 跳过")
        continue
    print(f"  {student} → 到！")
