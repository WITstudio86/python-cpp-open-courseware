KEY CONCEPTS

四个核心知识点

列表综合操作

.append() 逐个添加元素，len() 获取列表长度，for 循环遍历每个元素。列表就像一个可以不断装东西的"成绩袋"。

内置统计函数

sum() 求和、max() 最大值、min() 最小值、sorted() 排序。一行代码搞定常见统计需求，比手写循环简洁得多。

函数封装（def）

用 def 将一段逻辑打包成"功能盒子"。定义一次，反复调用。让代码结构清晰、易于维护。本项目封装输入、统计、展示三个函数。

f-string 格式化输出

f"{变量:>8.2f}" 中，> 表示右对齐、8 是宽度、.2f 保留两位小数。让报告排版整齐美观。

# ========== 成绩录入系统 ==========
# 使用 while 循环 + try-except 做输入校验
scores = []  # 空列表，用来存放所有成绩

print("=" * 40)
print("📊 成绩录入系统")
print("输入成绩（0-100），输入 'done' 结束录入")
print("=" * 40)

while True:
    user = input("请输入成绩：")
    if user.lower() == "done":
        break  # 输入结束信号，退出循环
    try:
        score = float(user)  # 转成小数，支持 85.5 这样
        if score < 0 or score > 100:
            print("⚠ 成绩应在 0-100 之间，请重新输入！")
            continue  # 跳过本次循环，重新输入
        scores.append(score)
        print(f"✓ 已录入第 {len(scores)} 个成绩：{score}")
    except ValueError:
        print("⚠ 请输入有效数字，或输入 'done' 结束！")

print(f"\n共录入 {len(scores)} 个成绩：{scores}")

模块二：统计报告生成

# ========== 统计与报告生成 ==========
def generate_report(scores):
    """生成成绩统计报告"""
    if len(scores) == 0:
        print("没有成绩数据！")
        return

    total = sum(scores)          # 总分
    avg = total / len(scores)      # 平均分
    highest = max(scores)        # 最高分
    lowest = min(scores)         # 最低分
    ranked = sorted(scores, reverse=True)  # 降序排列

    # 统计及格人数和优秀人数
    pass_count = 0
    excellent = 0
    for s in scores:
        if s >= 60:
            pass_count += 1
        if s >= 90:
            excellent += 1

    pass_rate = pass_count / len(scores) * 100

    # 格式化输出报告
    print("\n" + "=" * 50)
    print("📈 成绩统计报告".center(46))
    print("=" * 50)
    print(f"总人数：{len(scores):>6} 人")
    print(f"总分　：{total:>8.1f} 分")
    print(f"平均分：{avg:>8.2f} 分")
    print(f"最高分：{highest:>8.1f} 分")
    print(f"最低分：{lowest:>8.1f} 分")
    print(f"及格率：{pass_rate:>7.1f}% ({pass_count}/{len(scores)})")
    print(f"优秀率：{excellent/len(scores)*100:>7.1f}% ({excellent}人)")
    print("-" * 50)
    print("🏆 排名榜（前5名）：")
    for i, s in enumerate(ranked[:5], 1):
        if i == 1:
            medal = "🥇"  # 金牌
        elif i == 2:
            medal = "🥈"  # 银牌
        elif i == 3:
            medal = "🥉"  # 铜牌
        else:
            medal = f" {i}."
        print(f"  {medal} 第{i}名：{s} 分")
    print("=" * 50)

# 调用函数，生成统计报告
generate_report(scores)
运行流程：先执行录入模块，输入若干成绩后输入 done 结束，再调用 generate_report() 输出统计报告。注意代码结构 —— 录入和统计是两大模块，互不干扰。
