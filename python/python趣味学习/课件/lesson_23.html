重点概念

KEY CONCEPTS

增删改查四大招

增：append() / insert()

append(元素) 加到末尾；insert(位置, 元素) 插到指定位置。就像往收纳盒里放新东西。

删：remove() / pop() / del

remove(值) 按值删（只删第一个）；pop(索引) 按位删并返回；del 列表[索引] 直接删。

改：索引赋值

列表[索引] = 新值 直接替换。就像把盒子里的旧东西拿出来，换新东西进去。

查：索引 / in / index()

用索引访问、用 in 判断是否存在、用 index() 找位置。

增加元素

CORE CONTENT

增加元素：append() 和 insert()

# append()：加到末尾
fruits = ["苹果", "香蕉"]
fruits.append("橘子")  # 在最后加上橘子
print(fruits)  # ['苹果', '香蕉', '橘子']

fruits.append("葡萄")
print(fruits)  # ['苹果', '香蕉', '橘子', '葡萄']

# insert()：插到指定位置
fruits = ["苹果", "香蕉", "橘子"]
fruits.insert(1, "西瓜")  # 在索引 1 插入
print(fruits)  # ['苹果', '西瓜', '香蕉', '橘子']
记忆：append = 追加到最后，insert = 插入到中间。insert(索引, 元素) 两个参数都不能少。

删除元素

CORE CONTENT

删除元素：三种方式对比

# remove()：按值删除（只删第一个匹配的）
fruits = ["苹果", "香蕉", "橘子", "香蕉"]
fruits.remove("香蕉")
print(fruits)  # ['苹果', '橘子', '香蕉'] —— 只删了第一个！

# pop()：按索引删除，会返回被删的值
fruits = ["苹果", "香蕉", "橘子"]
removed = fruits.pop(1)  # 删除索引 1
print(removed)  # 香蕉 —— pop 会返回被删掉的值
print(fruits)   # ['苹果', '橘子']

fruits.pop()  # 不写索引，默认删最后一个
print(fruits)  # ['苹果']

# del：直接删除
fruits = ["苹果", "香蕉", "橘子"]
del fruits[0]
print(fruits)  # ['香蕉', '橘子']
三种删除区别：remove(值) 按值删只删第一个 | pop(索引) 按位删会返回值 | del list[i] 按位删不返回值。
