重点概念

KEY CONCEPTS

新知识点

字典 (dict)

用 {键: 值} 配对存储数据。像一本真正的字典：查"apple"得到"苹果"。键必须唯一且不可变（字符串、数字、元组）。

键值对

"apple" → "苹果" 就是一个键值对。键(key)是索引，值(value)是数据。dict 通过键来快速查找对应的值，比列表逐个搜索快得多。

文件读写

open() 打开文件，write() 写入内容，read() 读取内容。记得指定 encoding="utf-8" 支持中文。

菜单驱动循环

用 while True 无限循环显示菜单，if-elif 判断用户选择，执行对应功能。break 退出循环。

CORE CONTENT

字典的增删查改 (CRUD)

# 创建字典 —— 一本迷你翻译本
word_dict = {
    "apple": "苹果",
    "cat": "猫",
    "hello": "你好"
}

# 【增】添加新单词
word_dict["banana"] = "香蕉"
print(word_dict)  # {'apple': '苹果', 'cat': '猫', ...}

# 【查】查询单词 —— 先用 in 安全检查
word = input("请输入要查的单词: ")
if word in word_dict:
    print(f"{word} → {word_dict[word]}")
else:
    print("词典中暂无此单词")

# 安全查询：使用 .get() 避免报错
result = word_dict.get("dog", "未找到")
print(result)  # 未找到（不会报错）

# 【改】修改已有的翻译
word_dict["apple"] = "苹果🍎"

# 【删】删除单词 —— del 或 pop()
del word_dict["cat"]
# 或者用 pop()，可以指定默认值避免报错
removed = word_dict.pop("cat", "不存在")

# 【遍历】逐个查看所有单词
for eng, chn in word_dict.items():
    print(f"{eng} → {chn}")

# 只遍历键
for key in word_dict.keys():
    print(key)  # apple, hello, banana

# 只遍历值
for value in word_dict.values():
    print(value)  # 苹果🍎, 你好, 香蕉

# 字典长度
print(f"共有 {len(word_dict)} 个单词")
易错提醒：直接访问不存在的 key 会报 KeyError！查询前必须用 in 检查或用 .get() 安全取值。

文件读写 —— 让数据"永久保存"

# 【保存】将字典写入文件
def save_dict(word_dict, filename="words.txt"):
    with open(filename, "w", encoding="utf-8") as f:
        for eng, chn in word_dict.items():
            f.write(f"{eng},{chn}\n")

# 【加载】从文件中读取字典
def load_dict(filename="words.txt"):
    word_dict = {}
    try:
        with open(filename, "r", encoding="utf-8") as f:
            for line in f:
                line = line.strip()
                if line:
                    eng, chn = line.split(",", 1)
                    word_dict[eng] = chn
    except FileNotFoundError:
        print("词典文件不存在，将创建新词典")
    return word_dict
with open(...) as f 是推荐的写法：它会自动关闭文件，即使发生异常也不会忘记关闭。参数说明："w" 写入模式（覆盖），"r" 读取模式，"a" 追加模式。务必将 encoding="utf-8" 写全，否则中文会乱码！

while 菜单循环 —— 打造交互式程序

# 菜单循环主体结构
while True:
    print("\n========== 单词翻译本 ==========")
    print("1. 查询单词    2. 添加单词")
    print("3. 修改单词    4. 删除单词")
    print("5. 显示全部    6. 退出")
    print("================================")
    choice = input("请选择功能 (1-6): ")

    if choice == "1":
        # 查询单词
        pass
    elif choice == "2":
        # 添加单词
        pass
    elif choice == "3":
        # 修改单词
        pass
    elif choice == "4":
        # 删除单词
        pass
    elif choice == "5":
        # 显示全部单词
        pass
    elif choice == "6":
        print("再见！单词已自动保存~")
        break
    else:
        print("输入有误，请输入 1-6 之间的数字")

基础练习：代码纠错

下面代码有 3 个错误，找出并修正它们：

# 错误1：字典没有 .add() 方法！
word_dict.add("dog", "狗")
# 应该改为：word_dict["dog"] = "狗"

# 错误2：直接访问不存在的 key 会报 KeyError
result = word_dict["zebra"]  # 如果不存在直接崩溃！
# 应该改为：word_dict.get("zebra", "未找到") 或先 in 检查

# 错误3：遍历写法错误 —— 应使用 .items()
for eng, chn in word_dict:
    print(eng, chn)  # 只会解包 key 的每个字符！
# 应该改为：for eng, chn in word_dict.items():
