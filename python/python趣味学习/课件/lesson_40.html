重点概念

KEY CONCEPTS · 字典

字典（dict）—— Python 的"超级通讯录"

📇生活比喻：Python 字典就像一个智能通讯录——人名（键）→ 电话号码（值）。查"小明"（键），就能找到他的号码（值）。键不能重复，但值可以相同。就像一本真正的英汉字典：查 "apple" 得到 "苹果"。

字典 (dict)

用 {键: 值} 配对存储数据。键必须唯一且不可变（字符串、数字、元组），值可以是任意类型。通过键来快速查找对应的值，比列表逐个搜索快得多。

键值对 (Key-Value Pair)

"apple" → "苹果" 就是一个键值对。键(key)是索引/标签，值(value)是数据。就像一排带标签的储物柜——每个柜子有标签（键），里面放着东西（值）。

字典 vs 列表 —— 什么时候用哪个？

列表：数据有顺序、用数字索引 → fruits[0] 拿到第一个
字典：数据是配对关系、用名字索引 → word_dict["apple"] 直接找到翻译
关键区别：字典查找是 O(1) 的——不管字典有多大，查找时间几乎不变！背后用了"哈希表"数据结构。

文件读写 —— 让数据"活过"一次运行

菜单驱动循环

用 while True 无限循环显示菜单，if-elif 判断用户选择，执行对应功能。break 退出循环。就像餐厅点菜——看菜单 → 选菜 → 上菜 → 再看菜单。

数据持久化

程序启动时从文件 加载 词典 → 运行时在内存中操作字典 → 退出时 保存 回文件。形成"文件→内存→文件"的完整循环，数据再也不会丢失！

核心思路：整个程序就是加载 → 菜单循环(增删查改) → 保存 三个阶段的组合。字典是内存中的数据载体，文件是硬盘上的永久存储。

安全访问 & 遍历字典

🛡️ 安全查询 —— 别让程序崩溃！

# ❌ 危险：直接访问不存在的 key → KeyError!
result = word_dict["zebra"]

# ✅ 方式一：in 检查（推荐！）
if "orange" in word_dict:
    print(word_dict["orange"])
else:
    print("查无此词！")

# ✅ 方式二：.get() 方法（最安全）
result = word_dict.get("orange", "未找到")
print(result)  # 找不到就返回"未找到"，不报错

🔁 三种遍历方式

# 遍历所有键值对
for eng, chn in word_dict.items():
    print(f"{eng} → {chn}")

# 只遍历键（英文单词）
for key in word_dict.keys():
    print(key)  # apple, banana, cat

# 只遍历值（中文翻译）
for value in word_dict.values():
    print(value)  # 苹果, 香蕉, 猫

# 排序后遍历（按字母顺序）
for eng, chn in sorted(word_dict.items()):
    print(f"{eng} → {chn}")
常见错误：for eng, chn in word_dict: 这样写只会解包键的每个字符！必须用 .items() 才能同时拿到键和值。另外，直接访问不存在的 key 会报 KeyError，查询前必须用 in 检查或用 .get()。

✅ 推荐写法：with 语句（自动关闭文件）

保存字典到文件

def save_words(word_dict, filename="words.txt"):
    with open(filename, "w", encoding="utf-8") as f:
        for eng, chn in word_dict.items():
            f.write(f"{eng} = {chn}\n")

从文件加载字典

def load_words(filename="words.txt"):
    word_dict = {}
    try:
        with open(filename, "r", encoding="utf-8") as f:
            for line in f:
                line = line.strip()
                if line:
                    eng, chn = line.split("=", 1)
                    word_dict[eng.strip()] = chn.strip()
    except FileNotFoundError:
        print("词典文件不存在，将创建新词典")
    return word_dict
关键要点：
  • "w" 写入模式（覆盖原文件），"r" 读取模式，"a" 追加模式
  • 务必写全 encoding="utf-8"，否则中文会乱码！
  • with open(...) as f 会自动关闭文件，即使发生异常也不会忘记
  • 用 try-except FileNotFoundError 处理文件不存在的情况

while 菜单循环 —— 打造交互式程序

菜单循环是交互式程序的灵魂：循环显示选项 → 接收用户输入 → 执行对应功能 → 回到菜单。就像餐厅点菜一样自然！

# 菜单循环主体结构
while True:

    print("1. 查询单词    2. 添加单词")
    print("3. 修改单词    4. 删除单词")
    print("5. 显示全部    6. 保存到文件")
    print("7. 退出")
    print("================================")

    # 2. 获取用户选择
    choice = input("请选择功能 (1-7): ")

    # 3. 根据选择执行对应功能
    if choice == "1":
        search_word(word_dict)       # 查询
    elif choice == "2":
        add_word(word_dict)          # 添加
    elif choice == "3":

    elif choice == "4":

    elif choice == "5":
        show_all_words(word_dict)    # 显示全部

def main():

核心函数实现详解

添加单词 —— 带边界检查

def add_word(word_dict):
    english = input("请输入英文单词: ").strip()
    if english == "":
        print("⚠️ 单词不能为空！")
        return
    if english in word_dict:
        print(f"⚠️ '{english}' 已存在")
        return
    chinese = input("请输入中文意思: ").strip()
    if chinese == "":
        print("⚠️ 中文不能为空！")
        return
    word_dict[english] = chinese
    print(f"✅ 已添加：{english} → {chinese}")

修改单词 —— 显示旧值再更新

def modify_word(word_dict):
    english = input("要修改的单词: ").strip()
    if english in word_dict:
        old = word_dict[english]
        new = input(
            f"当前：{old}\n新翻译: ").strip()
        if new == "":
            print("⚠️ 修改取消")
            return
        word_dict[english] = new
        print(f"✏️ 已修改")
    else:
        print("😕 没找到该单词")

删除单词 —— 用 pop() 安全操作

def delete_word(word_dict):
    english = input("要删除的单词: ").strip()
    if english in word_dict:
        chinese = word_dict.pop(english)
        print(f"🗑️ 已删除：{english} → {chinese}")
    else:
        print("😕 没找到，无法删除")

显示全部 —— 排序 + 编号

def show_all_words(word_dict):
    if len(word_dict) == 0:
        print("📭 单词本为空！")
        return
    print(f"\n📋 共 {len(word_dict)} 个单词")
    for i, (e, c) in enumerate(
        sorted(word_dict.items()), 1):
        print(f"  {i}. {e} → {c}")
函数设计原则：每个函数只做一件事。输入验证放在函数内部（检查空值、检查是否存在），让调用者（main）保持简洁。函数名用动词开头（add_、search_、delete_、modify_），一看就知道做什么。

基础练习：代码纠错

下面的代码有 3 个错误，找出并修正它们： 
word_dict = {}
word_dict["hello"] = "你好"
word_dict = {"apple": "苹果"}

# 错误 1：想要添加单词，但写法不对
word_dict.add("cat", "猫")          # ❌ 字典没有 .add() 方法！

# 错误 2：想要查询，但 key 不存在会崩溃
print(word_dict["dog"])              # ❌ 直接访问不存在的 key → KeyError

# 错误 3：想要遍历，但写法不对
for word in word_dict:                # ❌ 只会拿到 key，解包会出错
    print(word + " = " + word_dict.value())  # ❌ .value() 不存在

✅ 修正方案

# 修正1：用方括号赋值
word_dict["cat"] = "猫"

# 修正2：用 in 检查或 .get()
if "dog" in word_dict:
    print(word_dict["dog"])
else:
    print("未找到")
# 或：word_dict.get("dog", "未找到")

# 修正3：用 .items() 遍历
for eng, chn in word_dict.items():
    print(f"{eng} = {chn}")

📝 错误解析

  • 错误1：字典没有 .add() 方法！添加/修改都用 dict[key] = value
  • 错误2：直接访问不存在的 key 会抛出 KeyError，导致程序崩溃。必须先用 in 判断或用 .get()
  • 错误3：for x in dict 只遍历键，且 .value() 方法不存在（应该用 .values() 或 .items()）

进阶版：单词听写模式

综合运用 random 模块、条件判断和计分系统，打造一个单词听写功能！

import random

def dictation_mode(word_dict):
    """单词听写模式 —— 看到中文，写出英文"""
    if len(word_dict) < 3:
        print("⚠️ 单词太少，至少需要3个！")
        return

    print("\n🎧 单词听写模式！")
    print("规则：看到中文，写出英文")
    print("输入'结束'可以提前退出\n")

    words = list(word_dict.items())     # 转成列表
    random.shuffle(words)                # 打乱顺序

    score = 0
    total = min(5, len(words))          # 最多考 5 个

    for i in range(total):
        eng, chn = words[i]
        answer = input(f"第{i+1}题：「{chn}」→ ").strip().lower()
        if answer == "结束":
            print("提前结束")
            break
        elif answer == eng:
            print("  ✅ 正确！")
            score += 1
        else:
            print(f"  ❌ 错误！正确答案：{eng}")

    print(f"\n📊 成绩：{score}/{total}")
    if score == total:
        print("🏆 满分！太厉害了！")
    elif score >= total / 2:
        print("👍 不错，继续加油！")
    else:
        print("💪 再加把劲！")
听写模式用到了哪些知识点？
  • random.shuffle() —— 随机打乱单词顺序，每次听写题目都不一样
  • list(word_dict.items()) —— 把字典转为列表，才能用索引和 shuffle
  • 计分系统 —— score 变量记录答对数量，最后根据得分给出不同评语
  • 提前退出 —— 输入"结束"可以随时停止听写
