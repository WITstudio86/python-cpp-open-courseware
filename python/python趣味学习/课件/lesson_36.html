重点概念

KEY CONCEPTS

五个新方法

.color("颜色")

设置画笔颜色。可以用英文名称如 "red"、"blue"，也可以用十六进制如 "#FF6600"。

.pensize(数字)

设置画笔粗细。数字越大线条越粗。默认是 1，试试 5 或 10 看看效果！

.speed(数字)

控制海龟移动速度。范围 1（最慢）到 10（最快）。0 表示瞬间完成，没有动画过程。

.begin_fill() / .end_fill()

一对搭档方法。在画封闭图形前调用 begin_fill()，画完后调用 end_fill()，图形内部就会自动填上颜色。

.penup() / .pendown()

penup() 抬起画笔，移动时不画线；pendown() 落下画笔，恢复画线。用于在画面不同位置之间"跳转"。

颜色 / 粗细 / 速度

CORE CONTENT

color() / pensize() / speed()

import turtle

t = turtle.Turtle()

# 1. 设置颜色 —— 海龟走过的线就变成这个颜色
t.color("red")        # 红色画笔
t.forward(100)

# 2. 设置粗细 —— 线条的宽度
t.pensize(5)          # 默认是 1，现在变粗了
t.color("blue")
t.forward(100)

# 3. 设置速度
t.speed(0)            # 0=最快（瞬间画完），1=最慢, 10=很快
t.color("green")
t.pensize(10)
t.forward(100)

turtle.done()
常用颜色名："red" "blue" "green" "yellow" "purple" "orange" "pink" "black" "white" "cyan"
也可以用 Hex 颜色码："#FF6600"（橙色）"#00CCFF"（天蓝）"#9933FF"（紫色）

填充 / 抬笔落笔

CORE CONTENT

begin_fill() / end_fill() 与 penup() / pendown()

import turtle

t = turtle.Turtle()
t.speed(5)

# === 填充颜色 ===
# 先告诉海龟要准备填色了
t.color("orange")        # 边框颜色
t.begin_fill()             # 开始填充 —— 记住这个起点

# 画一个封闭图形
for _ in range(4):
    t.forward(100)
    t.right(90)

t.end_fill()               # 结束填充 —— 自动填上颜色！

# === 抬笔与落笔 ===
t.penup()                  # 抬起笔，移动不会画线
t.goto(-150, 0)           # 飞到左边
t.pendown()                # 落下笔，开始画线

t.color("purple")
t.pensize(3)
t.circle(60)              # 在左边画一个紫色圆

turtle.done()
关键点：begin_fill() 和 end_fill() 之间的所有绘图动作围成的封闭区域都会被填充。如果不封闭（起点 ≠ 终点），海龟会自动从终点连一条线回起点再填色。fillcolor() 可以单独设置填充颜色，和边框颜色不同。

COMPLETE CODE

综合实战：画一个彩色填充五角星

import turtle

t = turtle.Turtle()
t.speed(5)                 # 设置速度适中，方便观察
t.pensize(3)              # 线条加粗一点

# 设置颜色：金色边框 + 黄色填充
t.color("gold", "yellow")  # 第一个是边框，第二个是填充
t.begin_fill()              # 开始填充

# 画五角星：5 条边，每边转 144 度
for _ in range(5):
    t.forward(200)
    t.right(144)          # 五角星的关键角度

t.end_fill()                # 结束填充，星星被涂上黄色！

# 抬笔到旁边，写上标题
t.penup()
t.goto(-80, -160)
t.color("black")
t.write("⭐ 我的第一颗彩色星星！",
      font=("Arial", 20, "bold"))
t.ht()                       # 隐藏海龟箭头

turtle.done()
为什么五角星右转 144 度？正五角星的每个内角是 36 度，海龟在拐角处需要转 180 - 36 = 144 度。画完 5 条边后，总转弯 = 5 x 144 = 720 = 2 x 360 度 —— 刚好绕了两圈回到起点！
