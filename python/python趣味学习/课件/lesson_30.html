重点概念

KEY CONCEPTS

三个核心概念

形参 (Parameter)

函数定义时括号里写的变量名，它是一个占位符，等着接收调用时传进来的值。如 def greet(name): 中的 name。

实参 (Argument)

调用函数时括号里实际传进去的值，它是真正的数据。如 greet("小明") 中的 "小明"。

多个参数

函数可以接收不止一个参数，用逗号隔开。调用时按顺序一一对应传入。def add(a, b): —— 接收两个参数。

默认参数

给参数预设一个"默认值"。调用时如果没传这个参数，就用默认值。def greet(name="同学"): —— name 默认为 "同学"。

形参与实参

CORE CONTENT ①

形参 vs 实参 —— 占位符和真实数据

# 定义函数：name 是形参（占位符）
def greet(name):
    print(f"你好，{name}！欢迎来到 Python 世界！")

# 调用函数："小明" 是实参（真实数据）
greet("小明")   # → 你好，小明！欢迎来到 Python 世界！
greet("小红")   # → 你好，小红！欢迎来到 Python 世界！
greet("老师")   # → 你好，老师！欢迎来到 Python 世界！
形参（Parameter）实参（Argument）
出现在哪里函数定义时（def 那一行）函数调用时（使用函数的地方）
是什么变量名（占位符）真实的数据（值）
类比电影票上的"姓名："空位你写上去的"张三"
例子def greet(name): 中的 namegreet("小明") 中的 "小明"
记忆口诀：形参是"空碗"，实参是"饭菜"。定义函数是准备空碗，调用函数是把饭菜装进去！

多个参数

CORE CONTENT ②

多个参数 —— 一次传多条信息

# 定义：接收两个参数
def introduce(name, age):
    print(f"我叫{name}，今年{age}岁。")

introduce("小明", 12)
# → 我叫小明，今年12岁。

# 定义：接收三个参数 —— 制作个人信息卡
def make_card(name, age, hobby):
    print("=" * 30)
    print(f"  姓名：{name}")
    print(f"  年龄：{age}")
    print(f"  爱好：{hobby}")
    print("=" * 30)

make_card("小明", 12, "编程")
make_card("小红", 11, "画画")
重要规则：调用时传入的实参顺序必须和定义时的形参一一对应！第1个实参给第1个形参，第2个给第2个……

如果不按顺序？比如 introduce(12, "小明") —— 会变成"我叫12，今年小明岁。" —— 乱套了！
# 练习：计算长方形面积 —— 接收长和宽两个参数
def rect_area(length, width):
    area = length * width
    print(f"长{length}、宽{width}的长方形面积是：{area}")

rect_area(10, 5)   # → 长10、宽5的长方形面积是：50
rect_area(8, 3)    # → 长8、宽3的长方形面积是：24

默认参数

CORE CONTENT ③

默认参数 —— 给参数一个"备用值"

# name 有默认值 "同学"，不传参就用它
def greet(name="同学"):
    print(f"你好，{name}！")

greet("小明")   # → 你好，小明！ （用了传入的值）
greet()         # → 你好，同学！ （用了默认值）
# 实战：制作分隔线 —— 可以自定义符号和长度
def print_line(symbol="-", length=30):
    print(symbol * length)

print_line()             # → ------------------------------
print_line("⭐")         # → ⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
print_line("=", 50)     # → ==================================================
print_line("~", 20)     # → ~~~~~~~~~~~~~~~~~~~~
默认参数的两个规则：
1. 有默认值的参数必须放在没有默认值的参数后面。
   ✅ def func(a, b=10):   ❌ def func(a=10, b):
2. 调用时可以不传有默认值的参数，按需覆盖即可。
# 综合例子：计算总价 —— 数量必填，折扣可选（默认不打折）
def total_price(quantity, unit_price, discount=0):
    original = quantity * unit_price
    final = original * (1 - discount)
    print(f"原价：{original}元，折后：{final}元")

total_price(3, 20)           # 不打折 → 原价：60元，折后：60元
total_price(3, 20, 0.2)      # 打8折 → 原价：60元，折后：48.0元

EXERCISES

课堂练习

基础练习：定义一个函数 say_hello(name)，接收一个名字参数，打印 "XXX，你好！今天过得怎么样？"。分别用 "小明"、"小红"、"妈妈" 三种实参调用它。
进阶练习：定义一个函数 describe_pet(name, animal_type)，接收宠物名字和动物类型两个参数，打印 "我有一只{animal_type}，它的名字叫{name}。" 调用三次，每次传入不同的宠物信息。
挑战练习：定义一个函数 make_sandwich(size, *toppings) —— 如果你还没有学到 *args，就先用三个固定参数：size（大小，默认"中"）、meat（肉类，默认"火腿"）、veggie（蔬菜，默认"生菜"）。打印出三明治的配置信息。试试覆盖默认值和不覆盖默认值的不同调用方式。

SUMMARY

学会了什么？

核心要点

  • 形参是函数定义时的"占位符"，实参是调用时传入的"真实数据"
  • 函数可以有多个参数，用逗号隔开，调用时按顺序一一对应传入
  • 默认参数让参数拥有"后备值"，调用时可传可不传
  • 有默认值的参数必须放在没有默认值的参数后面
  • 参数让函数变得灵活 —— 同一个函数处理不同的数据！
