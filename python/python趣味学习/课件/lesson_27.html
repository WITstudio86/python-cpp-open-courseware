重点概念

KEY CONCEPTS

重点概念

列表装字典

通讯录是一个列表，里面每个元素都是一个字典。每个字典代表一个联系人，包含 "name" 和 "phone" 两个键。

while 菜单循环

用 while True 做一个无限循环，打印菜单让用户选择操作。用户选择"退出"时用 break 跳出循环。

CRUD 操作

Create（添加）、Read（查找/显示）、Update（修改）、Delete（删除）——这四种操作是几乎所有程序的基石。

遍历查找

用 for 循环遍历通讯录列表，逐一比对字典中的 "name" 字段，找到匹配的联系人就输出他的电话。

核心讲解

CORE CONTENT

数据结构：列表 + 字典

# 通讯录的数据结构：列表里装字典
contacts = [
    {"name": "小明", "phone": "13800138001"},
    {"name": "小红", "phone": "13900139002"},
    {"name": "小刚", "phone": "13700137003"}
]

# 访问方式：列表[索引]["键"]
print(contacts[0]["name"])   # 输出：小明
print(contacts[1]["phone"])  # 输出：13900139002

# 遍历所有联系人
for person in contacts:
    print(f"{person['name']}：{person['phone']}")
为什么这样设计？列表负责"组织顺序"（第1个、第2个...），字典负责"描述一个人"（名字是什么、电话是什么）。两者分工合作，就像书架（列表）上放了很多文件夹（字典），每个文件夹里装着一个人的信息。

代码演示

CODE DEMO

通讯录小管家 —— 完整代码

# ===== 通讯录小管家 =====
contacts = []  # 用列表存放所有联系人

while True:
    print("\n" + "=" * 30)
    print("    📇 通讯录小管家")
    print("=" * 30)
    print("1. 添加联系人")
    print("2. 查找联系人")
    print("3. 显示全部")
    print("4. 删除联系人")
    print("5. 退出")
    print("-" * 30)

    choice = input("请输入你的选择（1-5）：")

    if choice == "1":
        # 添加联系人
        name = input("请输入姓名：")
        phone = input("请输入电话：")
        contacts.append({"name": name, "phone": phone})
        print(f"✅ 已添加联系人：{name}")

    elif choice == "2":
        # 查找联系人
        search_name = input("请输入要查找的姓名：")
        found = False
        for person in contacts:
            if person["name"] == search_name:
                print(f"📞 {person['name']}：{person['phone']}")
                found = True
                break
        if not found:
            print(f"❌ 没有找到 {search_name}")

    elif choice == "3":
        # 显示全部联系人
        if len(contacts) == 0:
            print("通讯录还是空的哦~")
        else:
            print("\n📋 全部联系人：")
            for i, person in enumerate(contacts, 1):
                print(f"  {i}. {person['name']} — {person['phone']}")

    elif choice == "4":
        # 删除联系人
        del_name = input("请输入要删除的联系人姓名：")
        deleted = False
        for person in contacts:
            if person["name"] == del_name:
                contacts.remove(person)
                print(f"🗑️ 已删除：{del_name}")
                deleted = True
                break
        if not deleted:
            print(f"❌ 没有找到 {del_name}")

    elif choice == "5":
        print("👋 再见！")
        break

    else:
        print("⚠️ 请输入 1-5 之间的数字！")
【讲解】通讯录小管家 —— 完整代码 本页要点（照着讲即可）： · 代码演示 · CODE DEMO 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。
