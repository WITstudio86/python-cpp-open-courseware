重点概念

KEY CONCEPTS

核心操作一览

sort() vs sorted()

list.sort() 原地排序，直接修改原列表。sorted(list) 生成新列表，原列表不变。降序用 reverse=True。

reverse()

把列表前后翻转，不是排序！[1,2,3] 变成 [3,2,1]。直接修改原列表。

in 关键字

判断某个元素"在不在"列表里，返回 True/False。常配合 if 语句使用。

min() / max() / sum()

找最小、最大、求和。对数字列表特别有用。sum(list)/len(list) 就是平均值！

排序与反转

CORE CONTENT

排序与反转

# sort()：直接修改原列表（原地排序）
nums = [3, 1, 4, 1, 5, 9, 2]
nums.sort()
print(nums)  # [1, 1, 2, 3, 4, 5, 9] —— 原列表被改变了

# sorted()：生成新列表，原列表不变
nums = [3, 1, 4, 1, 5, 9, 2]
new_nums = sorted(nums)
print("原列表：", nums)      # [3, 1, 4, 1, 5, 9, 2] —— 没变！
print("新列表：", new_nums)   # [1, 1, 2, 3, 4, 5, 9]

# 降序排序
nums.sort(reverse=True)
print(nums)  # [9, 5, 4, 3, 2, 1, 1]
# reverse()：反转（不是排序！）
fruits = ["苹果", "香蕉", "橘子"]
fruits.reverse()
print(fruits)  # ['橘子', '香蕉', '苹果']
类比：sort() 像在原稿上直接涂改，sorted() 像复印一张再涂改，原稿还在。

查找与统计

CORE CONTENT

in 判断与数值统计

# in 关键字：判断是否存在
students = ["小明", "小红", "小刚", "小丽"]
print("小明" in students)   # True
print("小李" in students)   # False

# 配合 if 使用
name = input("请输入要查找的名字：")
if name in students:
    print(name + " 在班级名单中！")
else:
    print(name + " 不在班级名单中。")
# min()、max()、sum() 数值统计
scores = [95, 88, 92, 100, 76, 83]
print("最高分：", max(scores))  # 100
print("最低分：", min(scores))  # 76
print("总分：", sum(scores))    # 534
print("平均分：", sum(scores) / len(scores))  # 89.0
口诀："min 最小 max 大，sum 求和快如马。sort 就地改，sorted 出新来。reverse 翻转，in 看存在。"
