重点概念

KEY CONCEPTS

字典的 CRUD 四大操作

C —— 增 (Create)

dict[新key] = 新value，直接赋值即可添加新键值对。如果 key 已存在，则变成"改"操作。

R —— 查 (Read)

dict[key] 直接取值（key 不存在会报错）；dict.get(key, 默认值) 安全取值（不存在返回 None 或默认值）。

U —— 改 (Update)

dict[已存在的key] = 新value，修改已有键的值。和"增"用的是同一种语法！

D —— 删 (Delete)

del dict[key] 删除指定键值对；dict.pop(key) 删除并返回该值；dict.clear() 清空整个字典。

增删操作

CORE CONTENT

字典的增与删

# 初始字典
info = {"name": "小明", "age": 12}
print(info)  # {'name': '小明', 'age': 12}

# ── 增：添加新键值对 ──
info["phone"] = "13800138000"
info["grade"] = "六年级"
print(info)
# {'name': '小明', 'age': 12, 'phone': '13800138000', 'grade': '六年级'}

# ── 删：三种删除方式 ──
del info["grade"]       # 方式1: del 删除指定 key
phone_num = info.pop("phone")  # 方式2: pop() 删除并返回
print(f"删除的电话号：{phone_num}")
# info.clear()          # 方式3: clear() 清空整个字典

print(info)  # {'name': '小明', 'age': 12}
注意：增和改用同一种语法 info[key] = value —— 如果 key 不存在就是"增"，如果 key 已经存在就是"改"！

查操作

CORE CONTENT

字典的查 —— .get() 安全访问

# 字典
student = {"name": "小红", "age": 11, "score": 95}

# ── 方式1: dict[key] 直接访问 ──
print(student["name"])   # 小红 ✅
# print(student["phone"])  # KeyError! ❌ 直接报错！

# ── 方式2: .get() 安全访问 ──
result1 = student.get("name")
print(result1)  # 小红 （key存在，返回对应的值）

result2 = student.get("phone")
print(result2)  # None （key不存在，返回 None 不报错！）

# .get(key, 默认值) —— 不存在时返回你指定的默认值
result3 = student.get("phone", "暂无")
print(result3)  # 暂无
对比总结：dict[key] —— key 不存在就报错，适合"确定存在"的情况。.get(key, 默认值) —— key 不存在不报错，返回默认值，适合"不确定存不存在"的情况。
判断 key 是否存在：用 if "phone" in student: 来检查字典里有没有这个键。

.keys() .values() .items() 遍历字典

fruit_prices = {"苹果": 5, "香蕉": 3, "橙子": 4}

# ── .keys() 遍历所有键 ──
for fruit in fruit_prices.keys():
    print(fruit)         # 苹果  香蕉  橙子

# ── .values() 遍历所有值 ──
for price in fruit_prices.values():
    print(price)         # 5  3  4

# ── .items() 同时遍历键和值（最常用！）──
for fruit, price in fruit_prices.items():
    print(f"{fruit}：{price}元")
# 苹果：5元  香蕉：3元  橙子：4元
最常用：for key, value in dict.items() 一次拿到键和值，是最常见的遍历字典方式。默认 for key in dict 等于 for key in dict.keys()。

SUMMARY

学会了什么？

核心要点

  • 增：dict[新key] = value（key 已存在则变成改）
  • 删：del dict[key]、pop(key)、clear()
  • 改：dict[已存在key] = 新value
  • 查：dict[key]（可能报错）vs .get(key, 默认值)（安全）
  • 判断存在：if key in dict
  • 遍历：.keys()仅键、.values()仅值、.items()键值一起
  • 最常用：for k, v in dict.items()
