重点概念

KEY CONCEPTS

重点概念

elif = else + if

表示"否则如果"。用于在前面的条件不成立时，再判断一个新的条件。

多选一结构

if → elif → elif → ... → else，从上到下依次判断，命中一个就停止。

条件顺序很重要

条件判断从上到下，一旦某个条件成立，后面的就不再判断。必须从大到小（或从小到大）排列！

elif 可以有多个

根据需要可以写 1 个、2 个、甚至 10 个 elif。最后的 else 是可选的。

核心讲解

CORE CONTENT

if-elif-else 基本结构

# 等级评定：A/B/C/D/E
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "E"

print(f"你的等级是：{grade}")
执行逻辑：先判断 score >= 90（85 >= 90？False，跳过）→ 再判断 score >= 80（85 >= 80？True！打印 B）→ 后面就不判断了！
条件顺序陷阱：如果先写 score >= 60 再写 score >= 90，那么 95 分的人会先命中 >= 60 被评 D！条件必须从大到小排列！

实用示例

# BMI 体重判断
height = float(input("请输入身高（米）："))
weight = float(input("请输入体重（公斤）："))
bmi = weight / (height * height)
print(f"你的 BMI 是：{bmi:.1f}")

if bmi < 18.5:
    print("偏瘦，要多吃点哦~")
elif bmi < 24:
    print("正常，保持住！")
elif bmi < 28:
    print("偏重，注意饮食~")
else:
    print("肥胖，要运动了！")
