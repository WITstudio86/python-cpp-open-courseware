🔮 万花筒的故事

同学们，你们玩过万花筒吗？万花筒里面有几面镜子，把一些彩色碎屑反射、重复、对称地排列，就变出了让人眼花缭乱的美丽图案。你转一下万花筒，图案就会变化——但无论怎么变，它总是对称的、有规律的。

今天我们要让海龟变成一个"万花筒制造机"！秘诀超级简单，就三步：

①
在循环中
画一个图形
②
旋转一个
固定角度
③
不断重复
形成花纹

就这么简单！但画出来的效果会让你大吃一惊——几个正方形旋转叠加就能变成一朵花，几个圆旋转叠加就能变成一朵盛开的玫瑰！

💡 互动思考：猜猜看，如果把一个正方形旋转 10 次，每次转 36°（360 ÷ 10），会变成什么图案？（答案：一个多层重叠的"星形花"）

🎯 核心启发：简单的图形 + 重复旋转 = 复杂美丽的图案。就像万花筒，里面不过是几片彩色碎屑，经过镜面的反复反射，就变成了令人叹为观止的图案。编程也是如此！

核心概念

📖 重点概念（上）—— 旋转对称 & 循环模式

01

旋转对称：360 ÷ 重复次数 = 旋转角度

旋转对称是自然界中最常见的对称形式之一（雪花、五角星、花朵……）。在 Turtle 绘图中，我们利用这个数学原理来生成美丽的花纹。只要"重复次数"能整除 360，转完一整圈后所有图形就会完美地对称排列。

重复次数每次旋转角度效果描述
4360 ÷ 4 = 90°4 个图形均匀分布（像指南针四个方向）
6360 ÷ 6 = 60°6 个图形均匀分布（像雪花❄️）
8360 ÷ 8 = 45°8 个图形均匀分布（八瓣花）
12360 ÷ 12 = 30°12 个图形均匀分布（密集花瓣）
18360 ÷ 18 = 20°18 个图形均匀分布（星芒状）
24360 ÷ 24 = 15°24 个图形均匀分布（细密花纹）
36360 ÷ 36 = 10°36 个图形——万花筒级别！🎆
50360 ÷ 50 = 7.2°50 个图形——超密万花筒！

生活化比喻：想象你站在一个圆形舞台上，手拿一只画笔。你向前走几步画一条线，然后舞台把你旋转 30°，你再向前画线，再转 30°……转了 12 次后（12 × 30° = 360°），你刚好转回原位。你画的 12 条线均匀分布在圆的一周——这就是旋转对称。

💡 关键：次数越多，每个图形之间的角度越小，花纹越密集、越华丽！如果旋转角度不能整除 360（比如每次转 100°），图案会"螺旋"偏移，产生意想不到的动态美。

02

循环 + 旋转：核心代码模式的「骨骼」

整个课程最核心的代码框架只有一行——这就是我们说的"魔法公式"：

for i in range(重复次数):
    # 1. 画出你要的图形（正方形、圆、三角形、五角星...）
    画一个图形()
    # 2. 右转 旋转角度
    t.right(360 / 重复次数)    # 旋转角度 = 360 ÷ 重复次数

循环的每一次迭代：先画一个图形，然后旋转一个固定的角度，为下一次画图做准备。关键在于——画笔朝向在不断变化，图形自动分布在圆周上。这就是从"单个图形"到"对称花纹"的魔法！

📖 重点概念（下）—— 万花筒 + 颜色 + 渐变

03

万花筒效果：多次重复叠加，图形交织成华丽的图案

万花筒（Kaleidoscope）的原理就是通过镜面反射产生对称重复图案。在 Turtle 中，我们通过多次重复绘制同一个图形来模拟这个效果：

  • 重复次数越多（如 36 次），图案越接近圆形排列，越密集华丽
  • 每次旋转的角度 = 360 ÷ 次数，确保图形均匀分布
  • 如果旋转角度不能整除 360，图案会"螺旋"偏移，产生意想不到的动态美
  • 多个图形在中心区域重叠交织，形成最精美的纹理
04

渐变颜色：颜色列表轮换

Turtle 支持使用颜色名称（如 "red", "blue"）或十六进制颜色码（如 "#ff6b6b"）。我们可以把颜色存入列表，在循环中依次使用：

colors = ["red", "orange", "yellow", "green",
          "cyan", "blue", "purple", "magenta"]
for i in range(36):
    t.color(colors[i % len(colors)])  # 取余数实现循环取色
    draw_shape()
    t.right(10)

i % len(colors) 是取余数运算：当 i 超过列表长度时自动回到开头（i=0→0, i=8→0, i=9→1...），实现颜色无限循环轮换。这是实现彩虹万花筒的关键技巧！

05

动态大小：在循环中逐渐改变图形尺寸

除了颜色，我们还可以在每次循环中改变图形大小，让花纹从中心向外"生长"：

for i in range(20):
    radius = 20 + i * 9   # i=0时半径20，i=19时半径191
    t.circle(radius)
    t.right(18)            # 360 ÷ 20 = 18

这样画出来的就是螺旋花纹——从中心向外越来越大，加上旋转，效果非常惊艳！这就是"渐变万花筒"的秘诀：颜色 + 大小同时变化。

06

图形交替：在循环中切换不同图形

更进一步——我们可以在循环中根据奇偶性交替绘制不同图形，让花纹更加丰富：

for i in range(36):
    t.color(colors[i % 8])
    if i % 2 == 0:       # 偶数次：画圆
        t.circle(100)
    else:                # 奇数次：画正方形
        for j in range(4):
            t.forward(80)
            t.right(90)
    t.right(10)

圆和正方形间隔出现，花纹层次更加丰富多变！

💻 代码实战（一）—— 三种基础配方

基础 配方一：正方形花（8 个正方形，每次转 45°）

最基础的旋转对称练习——把正方形当作"花瓣"，每画一个就转 45°，共画 8 个，中心形成一个小八边形空隙。

import turtle as t

t.speed(0)          # 最快速度
t.bgcolor("#1a1a2e")   # 深色背景，让图案更突出
t.pensize(2)

for i in range(8):           # 画 8 个正方形
    for j in range(4):       # 每个正方形 4 条边
        t.forward(100)
        t.left(90)
    t.right(45)              # 关键！画完一个正方形后旋转 45°

t.hideturtle()
t.done()

📝 运行效果：8 个正方形从中心向四周散开，整体像一朵机械风格的几何花。试试把 8 改成 12，45° 改成 30°，看看会变成什么？

经典 配方二：圆形万花筒（36 个圆，每次转 10°）⭐ 最受欢迎！

这是最经典的万花筒效果：36 个彩色圆均匀分布在圆周上，每个颜色都不同，效果极其华丽。

import turtle as t

t.speed(0)
t.bgcolor("black")
t.pensize(2)

colors = ["red", "orange", "gold", "green",
          "cyan", "blue", "purple", "magenta"]

for i in range(36):          # 画 36 个圆
    t.color(colors[i % len(colors)])  # 循环取颜色
    t.circle(100)               # 画半径为100的圆
    t.right(10)                 # 旋转 10°（360÷36=10）

t.hideturtle()
t.done()

📝 运行效果：36 个彩色圆圈以中心为轴均匀排列，颜色每 8 个一轮循环。圆圈在中央交织重叠，形成密集华丽的万花筒纹理。运行这个代码时，通常会引发"哇——"的惊叹！

变体 配方三：三角形万花筒（36 个三角形，每次转 10°）

把圆换成三角形——效果完全不同，形成锐利的几何星芒图案。

import turtle as t

t.speed(0)

t.pensize(2)

t.hideturtle()
t.done()

📝 运行效果：三角形也一样可以形成美丽花纹！36 个三角形旋转叠加，形成锐利的星芒放射效果，与圆的柔和感完全不同。

进阶 配方四：渐变螺旋圆（20 个圆，越来越大，每次转 18°）

在颜色轮换的基础上，让圆的半径从 20 逐渐增大到 191，形成从中心向外螺旋扩展的华丽效果。

进阶 配方五：星星万花筒（18 颗五角星，每次转 20°，带填充）

用五角星代替基础图形，加上颜色填充——18 颗彩色星星均匀排列，像烟花绽放！

import turtle as t

t.speed(0)
t.bgcolor("black")
t.pensize(2)

colors = ["red", "orange", "yellow", "green",
          "cyan", "blue", "purple", "magenta"]

for i in range(18):            # 18 颗星星
    t.color(colors[i % 8])
    t.begin_fill()              # 开始填充
    for j in range(5):        # 五角星 5 个顶点
        t.forward(50)
        t.right(144)        # 五角星外角 = 144°
    t.end_fill()                # 结束填充
    t.right(20)              # 旋转 20°（360÷18=20）

t.hideturtle()
t.done()

📝 运行效果：18 颗彩色实心五角星呈圆形排列，每颗星一种颜色，像国庆烟花的定格画面！注意五角星的外角是 144°（不是 72°），这是画五角星的关键。

创意 配方六：圆方交替万花筒（36 次，圆和正方形轮流出现）

利用 i % 2 == 0 判断奇偶，让圆和正方形交替出现——层次加倍，丰富度翻倍！

import turtle as t

t.speed(0)
t.bgcolor("black")
t.pensize(2)

colors = ["red", "orange", "yellow", "green",

    else:                    # 奇数次：画正方形

            t.right(90)
    t.right(10)

t.hideturtle()
t.done()

📝 运行效果：18 个圆和 18 个正方形交替排列成一个完整的圆环，柔软的曲线和硬朗的直线交错，层次感极强——试试把正方形换成三角形？

🎨 创意代码示例 —— 花瓣、半圆与光芒

创意 花瓣花纹（18 片花瓣，用弧线组成）

用 t.circle(60, 90) 画弧线（90° 四分之一圆弧），两段弧线组成一片花瓣，18 片旋转排列。

import turtle as t

t.speed(0)
t.bgcolor("lightyellow")
t.pensize(2)

petal_colors = ["hotpink", "deeppink", "orchid",
                "violet", "plum", "mediumpurple"]

for i in range(18):                    # 18 片花瓣
    t.color(petal_colors[i % 6])  # 6 种粉色系轮换
    t.circle(60, 90)               # 第一段弧线（90度四分之一圆）
    t.left(90)
    t.circle(60, 90)               # 第二段弧线（返回）
    t.left(160)                     # 旋转准备下一片花瓣

t.hideturtle()
t.done()

📝 运行效果：18 片粉色系花瓣围成一朵盛开的粉色大花，弧线让花瓣看起来有自然的弯曲感，非常柔美！

创意 半圆花朵（12 片填充花瓣 + 金色花心）

用 t.circle(50, 180) 画半圆作为花瓣，加上 begin_fill() 填充颜色，最后画一个金色花心。

import turtle as t

t.speed(0)
t.bgcolor("lightcyan")
t.pensize(3)

colors = ["coral", "tomato", "salmon",
          "lightcoral", "indianred", "red"]

for i in range(12):               # 12 片花瓣
    t.color(colors[i % 6])
    t.begin_fill()
    t.circle(50, 180)             # 画一个半圆 = 一片花瓣
    t.end_fill()
    t.right(150)                  # 转向下一片花瓣的位置

# 画金色花心
t.penup(); t.goto(0, -15); t.pendown()
t.color("gold")
t.begin_fill()
t.circle(15)                    # 花心小圆
t.end_fill()

t.hideturtle()
t.done()

📝 运行效果：12 片红色系实心花瓣围成一圈，中央一个金色小圆心——像一朵盛开的山茶花！

方法一：颜色列表轮换（已学）

colors = ["#ff6b6b", "#feca57", "#48dbfb", "#ff9ff3"]

    # ...画图形...旋转...
B

方法二：RGB 颜色渐变（进阶）⭐ 实现丝滑过渡！

使用 screen.colormode(255) 启用 RGB 模式后，可以用三个整数 (0-255) 来表示颜色：t.pencolor(r, g, b)。在循环中逐步改变某个颜色分量，就能实现丝滑的渐变过渡！

import turtle as t

screen = t.Screen()
screen.bgcolor("black")
screen.colormode(255)   # 启用 RGB 颜色模式（关键！）

t.speed(0)
t.pensize(2)

for i in range(50):
    # 红色从 255 递减，蓝色从 0 递增 → 形成渐变
    red   = 255 - i * 5    # 红色越来越少
    blue  = i * 5           # 蓝色越来越多
    green = 100              # 绿色保持不变

    t.pencolor(red, green, blue)
    t.circle(100)
    t.right(7.2)         # 360 ÷ 50 = 7.2

t.hideturtle()
t.done()

运行效果：50 个圆从暖红渐变到冷蓝，色彩过渡丝滑自然，像极光一样绚丽！试试改变 green 的值或调整渐变速度（如 red = 255 - i * 3），探索不同的渐变效果。

📋 本课小结

✅ 学会了什么

🔢
旋转对称公式

旋转角度 = 360 ÷ 重复次数。次数越多，角度越小，图案越密集。掌握 4~50 次对应的旋转角度。

🔁
循环 + 旋转模式

for 循环中：画图形 → 旋转 → 再画 → 再旋转，图形自动绕圆周均匀分布。

🎨
颜色轮换 & RGB 渐变

颜色列表 + i % len(colors) 取余数，或用 colormode(255) 实现丝滑 RGB 渐变。

📐
动态大小变化

循环中逐步改变图形尺寸（如 radius = 20 + i * 9），产生螺旋扩展效果。

⭐
五角星等复杂图形

学会画五角星（5 条边，外角 144°），用 begin_fill/end_fill 填充，创造星星万花筒。

🔄
图形交替技法

用 i % 2 == 0 判断奇偶，在循环中交替绘制不同图形，层次更加丰富。

🌸
弧线花瓣技法

用 t.circle(r, 角度) 画弧线组成花瓣，配合 fill 填充，画出半圆花朵。

🌈
万花筒艺术创作

综合运用所有技巧——图形 + 旋转 + 颜色 + 大小 + 交替，创造独一无二的万花筒艺术作品。
