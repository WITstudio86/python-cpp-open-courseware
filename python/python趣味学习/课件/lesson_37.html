核心概念

📖 重点概念

01

旋转对称：360 ÷ 重复次数 = 旋转角度

旋转对称是自然界中最常见的对称形式之一。在 Turtle 绘图中，我们利用这个数学原理来生成美丽的花纹：

  • 画 4 个图形，每次旋转 360 ÷ 4 = 90° → 形成一个十字花
  • 画 6 个图形，每次旋转 360 ÷ 6 = 60° → 形成一个六瓣花
  • 画 8 个图形，每次旋转 360 ÷ 8 = 45° → 形成一个八瓣花
  • 画 36 个图形，每次旋转 360 ÷ 36 = 10° → 形成完整的万花筒

💡 关键：次数越多，每个图形之间的角度越小，花纹越密集、越华丽！

02

循环 + 旋转：for循环中画图后旋转固定角度

核心代码模式的「骨骼」只有一行：

for i in range(次数):
    # 1. 画出你要的图形（正方形、圆、三角形...）
    # 2. 右转 旋转角度
    t.right(旋转角度)

循环的每一次迭代：先画一个图形，然后旋转一个固定的角度，为下一次画图做准备。关键在于——画笔朝向在不断变化，图形自动分布在圆周上。

03

万花筒效果：多次重复叠加

万花筒（Kaleidoscope）的原理就是通过镜面反射产生对称重复图案。在 Turtle 中，我们通过多次重复绘制同一个图形来模拟这个效果：

  • 重复次数越多（如 36 次），图案越接近圆形排列
  • 每次旋转的角度 = 360 ÷ 次数，确保图形均匀分布
  • 如果旋转角度不能整除 360，图案会"螺旋"偏移，产生意想不到的动态美
04

渐变颜色：颜色列表轮换

Turtle 支持使用颜色名称（如 "red", "blue"）或十六进制颜色码（如 "#ff6b6b"）。我们可以把颜色存入列表，在循环中依次使用：

colors = ["#ff6b6b", "#feca57", "#48dbfb", "#ff9ff3"]
for i in range(36):
    t.color(colors[i % len(colors)])  # 取余数实现循环取色
    draw_circle()
    t.right(10)

i % len(colors) 是取余数运算：当 i 超过列表长度时自动回到开头，实现颜色无限循环轮换。

💻 核心代码讲解

配方一：正方形花（8 个正方形，每次转 45°）

这是最基础的旋转对称练习——把正方形当作"花瓣"，每画一个就转 45°，共画 8 个。

import turtle as t

t.speed(0)          # 最快速度
t.bgcolor("#1a1a2e")   # 深色背景，让图案更突出
t.pensize(2)

for i in range(8):           # 画 8 个正方形
    for j in range(4):       # 每个正方形 4 条边
        t.forward(100)
        t.left(90)
    t.right(45)              # 关键！画完一个正方形后旋转 45°

t.hideturtle()
t.done()

📝 运行效果：8 个正方形从中心向四周散开，中心形成一个小八边形空隙，每片"花瓣"是正方形，整体像一朵机械风格的几何花。

配方二：圆形万花筒（36 个圆，每次转 10°）—— 经典款！

这是最经典的万花筒效果：36 个圆均匀分布在圆周上，每个颜色都不同，效果极其华丽。

import turtle as t

t.speed(0)
t.bgcolor("#1a1a2e")
t.pensize(3)

colors = ["#ff6b6b", "#feca57", "#48dbfb",
          "#ff9ff3", "#54a0ff", "#5f27cd"]

for i in range(36):          # 画 36 个圆
    t.color(colors[i % len(colors)])  # 循环取颜色
    t.circle(100)               # 画半径为100的圆
    t.right(10)                 # 旋转 10°（360÷36=10）

t.hideturtle()
t.done()

📝 运行效果：36 个彩色圆圈以中心为轴均匀排列，颜色每 6 个一轮循环。圆圈在中央交织重叠，形成密集华丽的万花筒纹理，中心尤其精美。

配方三：三角形花瓣（6 个三角形，每次转 60°）

把正方形换成三角形，6 个三角形组成一朵六瓣花，是课堂练习的参考答案。

import turtle as t

t.speed(0)
t.bgcolor("#1a1a2e")
t.pensize(2)
t.color("#feca57")

for i in range(6):           # 6 片花瓣
    for j in range(3):       # 三角形 3 条边
        t.forward(120)
        t.left(120)
    t.right(60)              # 旋转 60°（360÷6=60）

t.hideturtle()
t.done()

任务：修改"正方形花"的代码，把重复次数改成 6，旋转角度改成 60°。
