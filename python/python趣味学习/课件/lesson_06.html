区分 int 和 float

第6节
重点概念

KEY CONCEPTS

重点概念

int（整数）

没有小数点的数字，如 1、99、-5、0。Python 中的整数可以无限大！2**100 能瞬间算出。

float（小数/浮点数）

带小数点的数字，如 3.14、0.5、-2.7、1.0。注意：7.0 也是 float，不是 int！除法 / 的结果永远是 float。

// 整除 和 % 取余

10 // 3 = 3（扔掉小数部分，只留整数商）；10 % 3 = 1（除完后剩下的余数）。n % 2 可判断奇偶：余1为奇数，余0为偶数。

** 幂运算

求一个数的几次方。2 ** 3 = 8（2的3次方），3 ** 2 = 9（3的平方），2 ** 10 = 1024。可以算出超级大的数字！

第6节
核心讲解

EXPLANATION

核心讲解：数字运算七法器

# 认识 int 和 float
print(type(10))     # <class 'int'>
print(type(3.14))   # <class 'float'>
print(10 / 5)       # 2.0 —— 除法结果永远是 float！

# 七种基本运算
print(10 + 3)    # 加法 → 13
print(10 - 3)    # 减法 → 7
print(10 * 3)    # 乘法 → 30
print(10 / 3)    # 除法 → 3.33333...
print(10 // 3)   # 整除 → 3（只留整数部分）
print(10 % 3)    # 取余 → 1（10÷3=3余1）
print(2 ** 10)   # 幂运算 → 1024

# 生活中的数学：分糖果
candies = 23
kids = 5
each = candies // kids   # 每人4颗
left = candies % kids    # 还剩3颗

# 判断奇偶数
n = 7
print(n % 2)  # 1 → 奇数！

# 运算优先级：先乘除后加减，括号最优先
print(2 + 3 * 4)     # 14（先3×4=12，再2+12）
print((2 + 3) * 4)   # 20（先2+3=5，再5×4）
提示： 算术运算符速记 —— + 加、- 减、* 乘、/ 除（得小数）、// 整除（得整数）、% 取余（剩多少）、** 幂（几次方）。// 和 % 是好朋友：17 // 5 = 3（商），17 % 5 = 2（余数）。
