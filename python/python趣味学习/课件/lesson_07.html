第7节
重点概念

KEY CONCEPTS

重点概念

字符串（string）

用引号括起来的一串字符序列。"Hello"、'你好'、"123"（引号里的数字也是字符串！）都是字符串

len() — 数字符个数

获取字符串中有多少个字符。空格和标点也算！len("Python 真好玩") 结果是 11

索引（index）

每个字符都有一个"座位号"，Python 从 0 开始数。第一个字符索引是 0，倒数第一个是 -1

切片（slice）

从字符串中切出一段。语法：[开始:结束]，包含开始不包含结束。[::-1] 可以倒过来！

第7节
核心讲解

EXPLANATION

核心讲解

# ===== 字符串的四种本领 =====
word = "Python"
# 1. len() —— 数字符个数
print(len(word))              # 6
# 2. 索引 —— 取单个字符（从0开始！）
print(word[0])               # P（第1个）
print(word[-1])              # n（倒数第1个，最方便！）
# 3. 切片 —— 切一段 [开始:结束]
print(word[0:3])             # "Pyt"（含0不含3）
print(word[3:])               # "hon"（省略结束=到末尾）
# 4. 步长切片 —— 跳跃取字
print(word[::2])             # "Pto"（每隔2个取一个）
print(word[::-1])            # "nohtyP"（倒序！）

# ===== 趣味应用 =====
name = "张三"
print(name[::-1])            # 三张（名字倒过来！）

phone = "13812345678"
hidden = phone[:3] + "****" + phone[7:]
print(hidden)              # 138****5678（隐藏中间4位）
提示： Python 索引从 0 开始，这是编程界的"老传统"！切片规则：包含开始索引，不包含结束索引。负数索引从右边开始数，-1 是最后一个。

课堂练习

PRACTICE

课堂练习

练习

  1. 基础索引：给字符串 s = "Hello Python"，用索引取出第一个字符、最后一个字符、第6个字符。输出结果并验证。
  2. 切片练习：给字符串 s = "我爱Python编程"，分别取出 "我爱"、"Python"、"编程" 三段，再用 [::-1] 把整句话倒过来输出。
  3. 挑战——回文检查器：让用户输入一个词，判断它正读和反读是否一样（如"上海自来水来自海上"）。提示：比较 s 和 s[::-1] 是否相等。
