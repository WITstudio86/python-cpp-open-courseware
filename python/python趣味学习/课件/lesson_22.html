重点概念

KEY CONCEPTS

重点概念

列表

像一个有很多格子的盒子，每个格子可以放一样东西。用方括号 [] 创建，元素之间用逗号隔开。

索引

列表中每个元素的"门牌号"，从 0 开始编号。fruits[0] 是第一个，fruits[-1] 是最后一个。

len()

告诉我们列表里装了多少东西。注意：有 4 个元素时，索引是 0/1/2/3，最后一个索引是 len(list)-1。

切片

用冒号取列表的一段。fruits[0:3] 取前 3 个，fruits[2:] 从第三个取到最后。规则：左闭右开。

CORE CONTENT

列表的创建与访问

# 创建列表
fruits = ["苹果", "香蕉", "橘子", "葡萄"]
scores = [95, 88, 92, 100, 76]
mixed = ["小明", 12, 1.55, True]  # 可以混合不同类型
empty = []  # 空列表
# 索引访问（索引从 0 开始！）
fruits = ["苹果", "香蕉", "橘子", "葡萄"]
# 索引:      0       1       2       3
# 倒数:     -4      -3      -2      -1

print(fruits[0])   # 苹果 —— 第一个
print(fruits[2])   # 橘子 —— 第三个
print(fruits[-1])  # 葡萄 —— 最后一个！
print(fruits[-2])  # 橘子 —— 倒数第二个
为什么从 0 开始？这是计算机的传统。5 个元素时索引是 0-4，最后一个元素是 fruits[len(fruits) - 1]，即 fruits[-1]。

EXERCISES

课堂练习

基础练习：创建一个包含你最喜欢的 5 种食物的列表，打印第一个、第三个和最后一个。
应用练习：创建班级名单（至少 4 人），用 len() 打印人数，用索引打印第一个和最后一个同学。
挑战练习：用 [-1]、[-2] 等负数索引从后往前打印列表元素。再用切片打印前两个和后两个。
# 列表切片（取一段）
fruits = ["苹果", "香蕉", "橘子", "葡萄"]
print(fruits[0:3])   # ['苹果', '香蕉', '橘子']
print(fruits[1:4])   # ['香蕉', '橘子', '葡萄']
print(fruits[2:])    # ['橘子', '葡萄']
print(fruits[:2])    # ['苹果', '香蕉']
