重点概念

KEY CONCEPTS

重点概念

综合运用

把前面学过的各个知识点串联起来，解决一个综合性的问题。真正的编程不只是测试一行代码，而是搭建完整的程序

程序结构

一个完整的程序通常包含"数据输入 → 数据处理 → 结果输出"三个部分，就像做菜：备食材 → 烹饪 → 装盘

用户交互流程

设计良好的对话程序应有清晰流程：打招呼 → 收集信息 → 做出回应 → 结束告别，让用户感觉在和真人聊天

代码调试与注释

程序长了 bug 更难找。学会用 print(type(变量)) 检查类型、用 # 分段注释、把大问题拆成小问题

EXPLANATION

迷你对话机器人 —— 完整代码

# ====== 迷你对话机器人「小P」======
import random

# ---------- 第1部分：开场介绍 ----------
print("=" * 45)
print("🤖 超级机器人「小P」上线啦！")
print("=" * 45)
print("小P：嗨！我是你的专属机器人小P！")

# ---------- 第2部分：询问姓名 ----------
name = input("小P：你叫什么名字呢？\n   你：")
print(f"小P：「{name}」—— 这名字真好听！")
print(f"小P：很高兴认识你，{name}！")

# ---------- 第3部分：询问年龄 ----------
age_str = input("小P：你今年几岁啦？\n   你：")
age = int(age_str)      # 关键！字符串 → 整数
birth_year = 2026 - age
print(f"小P：{age}岁！你大概在{birth_year}年出生~")

# 根据年龄做不同回应
if age < 8:
    print("小P：这么小就学编程，以后一定很厉害！")
elif age <= 12:
    print("小P：学编程的黄金年龄！你选对啦！👍")
else:
    print("小P：任何时候开始学编程都不晚！加油！")

# ---------- 第4部分：询问爱好 ----------
hobby = input("小P：你最喜欢做什么？\n   你：")
print(f"小P：{hobby}？你的爱好真不错！")

# ---------- 第5部分：询问食物 ----------
food = input("小P：你最喜欢吃什么？\n   你：")
food_lower = food.lower()   # 统一变小写，方便判断

if "冰淇淋" in food or "雪糕" in food:
    print("小P：冰淇淋！夏天吃太爽了！🍦")
elif "巧克力" in food:
    print("小P：巧克力甜甜的，心情变好！🍫")
elif "苹果" in food or "水果" in food:
    print("小P：爱吃水果！真是个健康的宝宝！🍎")
else:
    print(f"小P：{food} 听起来就很美味！")

# ---------- 第6部分：数学小游戏 ----------
a = random.randint(1, 50)
b = random.randint(1, 50)
print(f"小P：请听题：{a} + {b} = ？")
answer = int(input("   你："))
if answer == a + b:
    print("小P：✅ 完全正确！数学小天才！🏆")
else:
    print(f"小P：❌ 答案是{a + b}，下次加油！")

# ---------- 第7部分：讲笑话 ----------
jokes = [
    "为什么程序员总分不清万圣节和圣诞节？\n因为 Oct31 == Dec25！",
    "程序员最怕什么动物？—— Bug！",
    "为什么 Python 程序员喜欢蛇？—— 因为 Python 是大蟒蛇呀🐍",
]
print(f"小P（讲个笑话）：{random.choice(jokes)}")

# ---------- 第8部分：总结告别 ----------
print("=" * 45)
print(f"📋 姓名：{name} | 🎂 {age}岁 | 🎨 {hobby} | 🍽 {food}")
print("=" * 45)
for i in range(5, 0, -1):
    print(f"    {i}...")
print("小P：👋 拜拜！要继续好好学习 Python 哦！❤️")
提示： 这个机器人综合运用了 print()、input()、变量、f-string、int() 类型转换、算术运算、字符串方法 .lower()、if/elif/else 条件判断、random 模块、for 循环等几乎所有前9节的知识点！

  1. 基础 — 补全代码：以下半成品缺少 int()类型转换和 f-string 变量嵌入，请补全并成功运行：
    age = ___(input("你几岁？")) → 填 int；print(____) → 填 f"{name}今年{age}岁，喜欢吃{food}"
  2. 进阶 — 个性化改造：在基础机器人框架上，至少添加一个自己设计的创意功能。例如：增加"猜数字"小游戏、询问喜欢的颜色并做出回应、增加"心情检测"功能、增加"小计算器"功能
