KEY CONCEPTS

重点概念

Turtle 绘图基础

forward(距离) 前进、left(角度)/right(角度) 转向、circle(半径) 画圆、color() 设颜色、begin_fill()/end_fill() 填充。这些是画任何图形的基本积木。

函数封装绘图

def draw_house(t, x, y, wall_color) 把画房子的代码打包成一个"印章"函数。调用一次就画一栋房子，调用十次就画十栋——就像盖章一样方便！

坐标移动 .goto(x, y)

画布是一个坐标系：原点(0, 0)在中心，x轴左右、y轴上下。.goto(x, y)让海龟飞到指定位置，配合抬笔落笔实现"瞬移"。

抬笔/落笔

.penup() 抬起笔——海龟移动但不画线（飞着走）；.pendown() 落下笔——海龟移动时留下轨迹（画着走）。布局城市时：先 penup → goto → pendown → 开始画。

画房子 —— draw_house()

def draw_house(t, x, y, wall_color="#E8D5B7"):
    """画一栋房子：墙壁矩形 + 三角形屋顶 + 门 + 两扇窗户"""
    t.penup()
    t.goto(x, y)             # 飞到房子左下角
    t.pendown()

    # ① 画墙壁（矩形）
    t.fillcolor(wall_color)
    t.begin_fill()
    for _ in range(2):
        t.forward(120)
        t.left(90)
        t.forward(100)
        t.left(90)
    t.end_fill()

    # ② 画屋顶（三角形）
    t.fillcolor("#C4593F")
    t.begin_fill()
    for _ in range(3):
        t.forward(120)
        t.left(120)
    t.end_fill()

    # ③ 画门
    t.penup()
    t.goto(x + 45, y)
    t.pendown()
    t.fillcolor("#8B4513")
    t.begin_fill()
    for _ in range(2):
        t.forward(30)
        t.left(90)
        t.forward(50)
        t.left(90)
    t.end_fill()

    # ④ 画左窗户
    t.penup()
    t.goto(x + 15, y + 60)
    t.pendown()
    t.fillcolor("#87CEEB")
    t.begin_fill()
    for _ in range(4):
        t.forward(25)
        t.left(90)
    t.end_fill()

    # ⑤ 画右窗户
    t.penup()
    t.goto(x + 80, y + 60)
    t.pendown()
    t.fillcolor("#87CEEB")
    t.begin_fill()
    for _ in range(4):
        t.forward(25)
        t.left(90)
    t.end_fill()
关键步骤：① penup→goto→pendown 瞬移到指定位置 ② 矩形墙壁：2次循环，每次走120再转90，走100再转90 ③ 三角形屋顶：3次循环，每次走120转120（等边三角形）④ 门和窗户也是矩形，用相同的套路画在不同位置。

画树 —— draw_tree()

def draw_tree(t, x, y, scale=1.0):
    """画一棵树：棕色树干 + 绿色圆形树冠，scale 控制大小"""
    t.penup()
    t.goto(x, y)
    t.pendown()

    # 树干（矩形）
    t.fillcolor("#8B4513")
    t.begin_fill()
    for _ in range(2):
        t.forward(20 * scale)
        t.left(90)
        t.forward(60 * scale)
        t.left(90)
    t.end_fill()

    # 移到树冠位置
    t.penup()
    t.goto(x + 10 * scale, y + 60 * scale)
    t.pendown()

    # 树冠（圆形）
    t.fillcolor("#2D8B2D")
    t.begin_fill()
    t.circle(35 * scale)
    t.end_fill()

画太阳 —— draw_sun()

def draw_sun(t, x, y, radius=40):
    """画太阳：黄色圆形 + 12道光芒"""
    t.penup()
    t.goto(x, y - radius)    # circle()从底部开始画，所以往下移
    t.pendown()

    # 太阳圆盘
    t.fillcolor("#FFD700")
    t.pencolor("#FFD700")
    t.begin_fill()
    t.circle(radius)
    t.end_fill()

    # 光芒（12条射线）
    t.pencolor("#FFA500")
    t.pensize(3)
    for i in range(12):
        t.penup()
        t.goto(x, y)
        t.setheading(i * 30)   # 每条光芒间隔30度
        t.forward(radius + 5)
        t.pendown()
        t.forward(20)
    t.pensize(1)            # 恢复笔粗细

主程序 —— 组合成城市

import turtle

# ===== 上面三个函数定义放在这里 =====

screen = turtle.Screen()
screen.bgcolor("#87CEEB")        # 天空蓝背景
screen.title("我的城市")

t = turtle.Turtle()
t.speed(0)                     # 最快速度

# 城市规划：从左到右布局
draw_sun(t, 220, 160, 45)        # 右上角太阳
draw_house(t, -280, -120, "#E8D5B7") # 左1：米色房子
draw_house(t, -120, -120, "#D4A76A") # 左2：土黄房子
draw_house(t, 40, -120, "#C9A97A")   # 右1：浅棕房子
draw_tree(t, -320, -120, 0.7)        # 最左边小树
draw_tree(t, -180, -120, 0.9)        # 房子间中等树
draw_tree(t, 170, -120, 1.1)         # 最右边大树

t.hideturtle()
turtle.done()
城市规划法则：画布坐标系 (0,0) 在中心，x范围约-350到+350，y范围约-250到+250。先画远处的（太阳），再画近处的（房子和树）。函数封装让每栋房子只是"盖章"——改(x, y)就换位置，改wall_color就换颜色！
