重点概念

KEY CONCEPTS

重点概念

print() 函数

Python 中最常用的输出函数。括号里写什么，屏幕上就显示什么。理解为"让电脑说话"的按钮。

字符串

用引号（'单引号'或"双引号"）括起来的文字内容。Python 把字符串当作"文字"来处理，数字和算式不用加引号。

参数: sep 和 end

sep 控制多个内容之间的分隔符（默认空格）。end 控制输出后的结尾符（默认换行）。

\n（换行符）

一个特殊的字符，代表"换行"。反斜杠 + n，就像在字符串里按了一次回车键。可以在一行代码里控制多行输出。

CORE CONTENT

print() 的四大本领

本领一：输出文字（字符串）

print("你好，世界！")        # 双引号
print('Python真好玩！')      # 单引号也可以
print("我今年10岁了")        # 中文也没问题
关键规则：文字必须用引号包起来！不加引号 Python 会以为是变量名。中文、英文、数字、符号都可以放在引号里。

本领二：输出数字和算式

print(100)              # 直接输出数字
print(100 + 200)        # 输出计算结果：300
print(2 ** 100)         # 2的100次方——超大数字立刻出结果！

Python 不只是"复读机"，它还能真的算出来！算式写在 print() 里面，Python 会先算好结果再显示。

本领三：一次输出多个 + sep/end

# 逗号分隔——自动加空格
name = "小明"
print("我叫", name, "，今年10岁")
# 输出：我叫 小明 ，今年10岁

# sep 参数——自定义分隔符
print("苹果", "香蕉", "橘子", sep="、")
# 输出：苹果、香蕉、橘子

# end 参数——控制结尾（默认换行）
print("加载中", end="")
print(".", end="")
print(".", end="")
print(".")
# 输出：加载中...

本领四：控制换行（\n）

print("第一行\n第二行\n第三行")
# 输出：
# 第一行
# 第二行
# 第三行

# 一行代码画三角形！
print("    *\n   ***\n  *****\n *******\n*********")

SUMMARY

学会了什么？

核心要点

  • print() 可以输出文字（加引号）、数字、算式
  • 用逗号可以一次输出多个内容，默认用空格分隔
  • sep 参数改变分隔符，end 参数改变结尾符
  • \n 代表换行，就像按回车键
  • 用空格和字符组合，可以"画"出各种有趣图案

常见坑点提醒

  • 文字要加引号，数字和算式不用
  • 逗号是英文逗号，不是中文逗号
  • 引号是英文引号，不是中文引号
  • 括号也必须用英文的 ( )
