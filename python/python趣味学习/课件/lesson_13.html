重点概念

KEY CONCEPTS

重点概念

else

if 条件的"反面"。如果 if 条件成立执行 if 块，不成立就执行 else 块。else 后面不需要写条件。

二选一逻辑

if 和 else 配合，两条路必然走一条，不会同时走，也不会都不走。

else 没有条件

else 后面直接跟冒号，不能写条件表达式。这是初学者最容易犯的错误之一。

缩进规则不变

else 下面的代码也要缩进，且 else 必须和 if 在同一列对齐。

核心讲解

CORE CONTENT

if-else 基本结构

# if-else 语法骨架
if 条件:
    条件成立时执行这里
else:
    条件不成立时执行这里
关键点：else 后面没有条件、要加冒号、代码要缩进、if 和 else 要在同一列对齐。
# 示例：升级版及格判断器
score = 85
if score >= 60:
    print(f"分数：{score}，及格啦！🎉")
    print("送你一朵小红花🌺")
else:
    print(f"分数：{score}，没及格😢")
    print("别灰心，下次加油！💪")

print("程序结束")  # 不管及格不及格，都会执行
对比：两个 if vs if-else
用 if-else 只判断一次，效率更高，逻辑更清晰，不会出现两个 if 同时执行的错误。

EXERCISES

课堂练习

基础练习：写一个程序，判断一个数是否大于 100。如果大于就打印"很大！"，否则打印"不大。"
改造练习：把"高温警报"程序改成 if-else 版本 —— 如果温度 > 35，打印"太热了！"，否则打印"温度还行~"
挑战练习：写一个"周几判断器"—— 输入 1-7 的数字，判断是不是周末（6和7是周末，其他不是）。
# 偶数判断器
num = int(input("请输入一个数字："))
if num % 2 == 0:
    print(f"{num} 是偶数")
else:
    print(f"{num} 是奇数")

SUMMARY

学会了什么？

核心要点

  • else 是 if 的"另一半"，处理条件不成立的情况
  • if-else 是二选一：必定走一条路，也只走一条
  • else 后面不写条件，但要写冒号
  • else 要和 if 对齐（同一列）
  • if-else 比写两个 if 更清晰、更高效
