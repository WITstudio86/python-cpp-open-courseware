重点概念

KEY CONCEPTS

重点概念

if 语句

让程序"做判断"的语句。格式为 if 条件:，条件成立（True）就执行下面缩进的代码，不成立（False）就跳过

缩进（indent）

Python 的灵魂！if 下面要执行的代码必须缩进（通常 4 个空格或 1 个 Tab）。同一个 if 里的代码缩进必须对齐，否则 Python 会报错

冒号（:）

if 条件后面一定要加英文冒号 :，不能忘！忘记冒号是最常见的初学者错误，Python 会直接提示语法错误

条件表达式

if 后面跟的是一个能算出 True 或 False 的表达式，正是上节课学的比较运算符！如 score >= 60、age > 10

第12节
核心讲解

EXPLANATION

if 语句 —— 及格判断器

# ======== if 语句基本结构 ========
# if 条件:
#     条件成立时做的事情（注意前面缩进！）

# ----- 及格判断器 1.0 -----
score = 85
print("你的分数是：", score)

if score >= 60:                # 条件成立（True）
    print("🎉 及格啦！")        # 缩进4格，会执行
    print("继续努力哦！")      # 缩进4格，也会执行

print("判断结束~")            # 没缩进，不管条件如何都执行

# ----- 不及格的情况 -----
score2 = 55
print("\n你的分数是：", score2)

if score2 >= 60:               # 条件不成立（False）
    print("🎉 及格啦！")        # 不会执行！

print("判断结束~")            # 照样执行

# ----- 多个 if 各自判断 -----
age = 10
print(f"\n你今年 {age} 岁：")
if age >= 6:
    print("  → 可以上小学了")    # 10>=6，执行
if age >= 12:
    print("  → 可以上初中了")    # 10<12，不执行
if age >= 15:
    print("  → 可以上高中了")    # 10<15，不执行
if age >= 18:
    print("  → 成年了！")        # 10<18，不执行

# ----- ❌ 常见错误示范 -----
# 错误1：忘记冒号
# if score >= 60          # 缺少冒号！
#     print("及格")

# 错误2：忘记缩进
# if score >= 60:
# print("及格")            # 没有缩进！

# 错误3：缩进不一致
# if score >= 60:
#     print("及格")
#      print("很棒")        # 缩进不对齐！
提示： if 语句的三个关键 —— 关键字 if、条件后面的冒号 :、代码块的缩进，缺一不可！缩进是 Python 的灵魂，同一个 if 里面的代码要对齐，建议统一用 4 个空格

PRACTICE

课堂练习

练习

  1. 基础练习：修改"及格判断器"代码中的分数，分别试试 100 分、60 分、59 分、0 分，观察哪些分数会显示"及格啦！"。理解条件成立（True）和不成立（False）的区别
  2. 动手练习：写一个 if 语句，判断一个数字是否大于 10。如果大于 10，就打印"这个数大于10"。注意检查你的代码：有没有冒号？有没有缩进？条件表达式写对了吗？
  3. 挑战练习：写一个"高温警报"程序 —— 设定一个温度变量 temperature，如果温度超过 35 度，就打印"太热了，注意防暑！"。再试试 30 度、40 度不同情况，看看程序是否正确响应
