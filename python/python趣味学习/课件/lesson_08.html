第8节
重点概念

KEY CONCEPTS

重点概念

字符串拼接（+）和重复（*）

"Hello" + " World" 得到 "Hello World"（像把两节火车车厢连在一起）；"哈" * 5 得到 "哈哈哈哈哈"

字符串方法

字符串有很多"技能"，用法是 字符串.方法名()。例如 "hello".upper() 变成 "HELLO"。这些方法返回新字符串，原字符串不变！

f-string（格式字符串）

Python 3.6 引入的超级方便功能！字符串前加 f，在 {} 里直接嵌入变量或表达式。f"我叫{name}，今年{age}岁"

不可变性

字符串一旦创建就不能被修改。所有字符串方法都是返回一个新的字符串，就像重新抄一份时做了修改，原来的纸没变

【讲解】重点概念 本页要点（照着讲即可）： · KEY CONCEPTS · 字符串拼接（+）和重复（*） · "Hello" + " World" 得到 "Hello World"（像把两节火车车厢连在一起）；"哈" * 5 得到 "哈哈哈哈哈" · 字符串方法 · 字符串有很多"技能"，用法是 字符串.方法名()。例如 "hello".upper() 变成 "HELLO"。这些方法返回新字符串，原字符串不变！ · f-string（格式字符串） 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
第8节
核心讲解

EXPLANATION

核心讲解

# ===== 1. 拼接 + 和重复 * =====
print("你好" + "世界")          # 你好世界
print("=" * 30)              # ==============================（分隔线）
print("哈" * 5)               # 哈哈哈哈哈

# ===== 2. 大小写变换 =====
print("hello".upper())        # HELLO
print("HELLO".lower())        # hello
print("hello world".title())  # Hello World

# ===== 3. 清理和替换 =====
name = "   小明   "
print(name.strip())            # "小明"（去掉两端空格）
text = "我喜欢吃苹果"
print(text.replace("苹果", "香蕉")) # 我喜欢吃香蕉

# ===== 4. f-string —— 超级格式化工具 =====
name = "小明"; age = 10; score = 95
print(f"我叫{name}，今年{age}岁，考了{score}分")
print(f"明年我就{age + 1}岁了")    # {} 里可以写表达式！

# ===== 5. 奖状生成器（精简版）=====
winner = input("获奖人：")
award = input("奖项：").upper()  # 全大写更有气势！
print(f"🏆 恭喜 {winner} 获得「{award}」！🎉")
提示： 字符串 + 只能拼接字符串，不能和数字直接拼接！字符串方法返回新字符串，原字符串不会变。f-string 是拼接字符串的最佳方式，大括号 {} 里面可以写变量名，也可以写表达式！
【讲解】核心讲解 本页要点（照着讲即可）： · EXPLANATION 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
