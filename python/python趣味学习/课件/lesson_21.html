重点概念

KEY CONCEPTS

重点概念

双重循环（嵌套循环）

一个循环里面再放一个循环。外层走一步，内层走一轮。就像时钟 —— 时针走 1 格，分针走一整圈。

格式化打印

用 \t（制表符）和 :2d 来对齐输出，让乘法表的列整整齐齐。

内层循环依赖外层

乘法表中，第 i 行有 i 列。所以内层 range 的终点取决于外层变量：range(1, i+1)。

for 和 while 转换

任何 for 循环都能用 while 改写，反之亦然。掌握转换方法，灵活运用两种循环。

双重循环详解

CORE CONTENT

双重循环工作原理

# 理解双重循环的执行顺序
for i in range(1, 4):      # 外层循环：3 次
    for j in range(1, 3):  # 内层循环：2 次
        print(f"i={i}, j={j}")
    print("---")
# 输出：
# i=1, j=1
# i=1, j=2
# ---
# i=2, j=1
# i=2, j=2
# ---
# i=3, j=1
# i=3, j=2
# ---
乘法表规律：第1行1列，第2行2列，第3行3列，...第9行9列。所以第 i 行有 i 列，内层循环用 range(1, i+1)。

for 和 while 版本

TWO VERSIONS

for 版本 vs while 版本

# ======== for 版本 ========
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j:2d}", end="  ")
    print()
# ======== while 版本 ========
i = 1
while i <= 9:
    j = 1
    while j <= i:
        print(f"{j}×{i}={i*j:2d}", end="  ")
        j += 1
    print()
    i += 1
格式化技巧：:2d 让每个结果占 2 个字符宽，表格就对齐了。end=" " 控制打印不换行，用两个空格分隔。
