认识函数 & def 定义

为什么用函数？

  • 不重复写代码（写一次用多次）
  • 容易修改（改一处处处生效）
  • 代码更清晰（把复杂变简单）
def say_hello():
    print("你好！")
def print_line():
    print("=" * 30)
Unit 6
第 30-31 节

第 30-31 节

参数 & 返回值

def greet(name):              # 参数
    print(f"你好，{name}！")

def power(base, exp=2):      # 默认参数
    return base ** exp        # 返回值

def get_grade(score):         # return 提前退出
    if score >= 90: return "A"
    if score >= 80: return "B"
    return "C"
