变量 —— 贴标签的盒子

变量就像贴了标签的小盒子，你可以往里面放任何东西，还可以随时拿出来换新的。掌握了变量，你才能真正写出灵活有趣的程序！

第5节
教学目标

LEARNING OBJECTIVES

本节目标

理解变量的概念

变量就是一个有名字的"存储盒子"——标签是变量名（如 name、age），盒子里装的是数据（如"小明"、10）

掌握赋值操作

用等号 = 把数据"放"到变量里。从右往左读："把右边的值放进左边的盒子"，x = x + 1 是先取出再加1再放回

遵守命名规则

字母/数字/下划线，不能数字开头，不能用 Python 关键字（if、for、print 等），区分大小写

第5节
重点概念

KEY CONCEPTS

重点概念

变量（Variable）

贴了标签的盒子。标签是变量名，盒子里装数据。可以随时打开盒子看里面有什么，也可以换新的内容进去。标签不变，内容可变。

赋值（Assignment）

用 = 把数据放进变量。注意：= 不是"等于"，而是"把右边的值赋予左边"。方向是从右往左读。

变量名规则

只能用字母、数字和下划线 _，不能数字开头。大小写敏感（name 和 Name 是两个不同的盒子）。不能用 Python 关键字。

动态类型

Python 变量很灵活——同一个变量可以先装整数，再装字符串，再装小数。不需要提前声明"这个盒子只能装数字"。

第5节
核心讲解

EXPLANATION

核心讲解：变量 —— 编程的"记忆"

# 创建变量（贴标签、放东西）
name = "小明"       # 把"小明"放入变量 name
age = 10             # 把数字10放入变量 age
score = 95            # 把数字95放入变量 score

# 使用变量（打开盒子看看）
print("姓名：", name, "年龄：", age)

# 修改变量（换新内容进去）
age = age + 1        # 取出age(10)，加1得11，放回age
print("过了一年，年龄变为：", age)

# 交换两个变量的值 —— 经典小魔术
a = "苹果"
b = "香蕉"
temp = a    # 临时盒子暂存a
a = b        # b的内容放到a
b = temp    # 暂存的内容放到b
print("交换后：a =", a, ", b =", b)

# Python 酷炫写法：一行搞定交换！
a, b = b, a
提示： 取好名字比取短名字重要得多！用有意义的英文（如 student_name、math_score），多个单词用下划线连接。绝不要用 print、input、if 等关键字当变量名，否则会覆盖掉 Python 的内置功能！

课堂练习

练习

  1. 变量基础：创建 my_name、my_age、my_hobby 三个变量存入你的信息，用 print() 输出"我叫XXX，今年X岁，我喜欢XXX"，然后修改 my_age 为明年的年龄再输出。
  2. 交换小实验：有 cup1 = "可乐" 和 cup2 = "雪碧"，写代码交换两个杯子的内容（提示：需要一个临时变量 temp），交换后 cup1 应该是"雪碧"。
  3. 模拟购物（挑战）：创建 wallet = 100（钱包100元），pencil = 3（铅笔3元/支），notebook = 15（笔记本15元/本）。买5支铅笔和2本笔记本后，计算并输出剩余金额。
