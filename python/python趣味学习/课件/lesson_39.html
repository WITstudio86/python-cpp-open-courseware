重点概念

KEY CONCEPTS

重点概念

random.randint(a, b)

生成 a 到 b 之间的随机整数，包含两端。例如 random.randint(1, 6) 返回 1、2、3、4、5 或 6。

random.choice(列表)

从列表中随机选一个元素。例如 random.choice(["⚀","⚁","⚂","⚃","⚄","⚅"]) 随机返回一个骰子符号。

while 循环

条件为真就一直执行循环体。用 while True 创建无限循环，配合 break 或条件变量退出。

f-string 格式化

f"文字{变量}文字" 将变量值嵌入字符串，让输出更美观。变量会自动转成字符串。

CORE CONTENT

基础版骰子模拟器

# 骰子模拟器 —— 基础版
import random

playing = True
while playing:
    # 掷骰子
    dice = random.randint(1, 6)
    print(f"🎲 你掷出了：{dice} 点")

    # 是否继续？
    answer = input("再掷一次吗？(y/n): ")
    if answer == "n":
        playing = False
        print("再见！下次好运~")
    elif answer != "y":
        print("输入错误，请输入 y 或 n")
执行流程：import random → 设 playing = True → 进入 while 循环 → randint(1,6) 随机掷骰 → print 输出结果 → input 等待用户输入 → 判断 y/n 决定继续还是退出。

进阶技巧：骰子符号版

# 用骰子符号让输出更生动
dice_faces = ["⚀", "⚁", "⚂", "⚃", "⚄", "⚅"]
# 索引 0 对应 1 点，索引 5 对应 6 点

dice = random.randint(1, 6)
face = dice_faces[dice - 1]  # 减1是因为列表从0开始
print(f"🎲 你掷出了 {face} ({dice} 点)")

# 或者用 random.choice() 直接选
face = random.choice(dice_faces)
print(f"🎲 {face}")
两种方式对比：randint 方式可以拿到数字做计算，choice 方式更简洁但拿不到具体点数。需要比较点数大小时用 randint，只需要显示时用 choice。

# 提示：双骰子对决框架
dice1 = random.randint(1, 6)
dice2 = random.randint(1, 6)
total = dice1 + dice2
print(f"骰子1：{dice1}  骰子2：{dice2}  总点数：{total}")

if dice1 == dice2:
    print("🎉 豹子！")
elif total >= 8:
    print("🔺 大！")
else:
    print("🔻 小！")

提示：用 history = [] 初始化空列表，每次掷骰后用 history.append(dice) 记录，最后用 sum(history)/len(history) 算平均值。
