重点概念

KEY CONCEPTS

重点概念

编程

人类用计算机能听懂的语言，给计算机下命令，让它帮我们做事情。就像你写一份"任务清单"给机器人，机器人会按照清单一步一步完成任务。

程序

一串有序的指令集合，就像菜谱上的步骤，计算机按照步骤一条一条执行。

Python（蟒蛇）

一种非常流行的编程语言。名字来自创始人 Guido 喜欢的英国喜剧节目《Monty Python's Flying Circus》，所以 Logo 是两条可爱的蛇。

代码

你写在电脑上的那堆英文和符号，就是代码。代码是程序员跟计算机交流的语言。

核心讲解

CORE CONTENT

编程就像给机器人下指令

类比：泡奶茶的步骤
想象你有一个听话的小机器人，你想让它帮你泡一杯奶茶，你会怎么指挥它？
1. 走到厨房
2. 拿出一个杯子
3. 放进一个茶包
4. 加入热水（小心烫！）
5. 加入牛奶
6. 加入一勺糖
7. 搅拌均匀
8. 端过来给我

这就是一个最简单的"程序"！编程就是把你想让计算机做的事，拆成一小步一小步，然后用计算机理解的语言写出来。计算机虽然很厉害，但它其实很"笨"——它只会按照你写的指令一步一步做。

Python 能做什么？

制作游戏

用 Pygame 库制作小游戏，《文明》系列就用 Python 写了部分代码

建立网站

YouTube、Instagram、豆瓣等大型网站的后台都有 Python 的身影

人工智能（AI）

ChatGPT、AI 换脸等核心算法很多都用 Python 编写

数据分析 & 自动化

快速处理大量数据，自动重命名文件、发送邮件、填表格

看看 Python 代码长什么样？

# 让电脑跟我们打招呼
name = "小明"
age = 10
print("大家好！")
print("我叫", name)
print("我今年", age, "岁")

# 让电脑算一道数学题
result = 12345 * 67890
print("12345 × 67890 =", result)

Python 的代码读起来就像英语句子，这也就是为什么它特别适合初学者——因为它接近人类的自然语言！

EXERCISES

课堂练习

练习一：我是小小编程师

模仿"泡奶茶"的例子，写出另一个生活中的"程序步骤"。可以选择：早上起床到出门的过程、做一道鸡蛋炒饭的步骤、打电话叫外卖的流程。每组 3-4 个同学讨论，然后分享。（提示：步骤越具体越好！）

练习二：猜猜 Python 能做什么

老师给出场景，判断"这个能不能用 Python 做到？"

  • 控制红绿灯 —— 能！
  • 让汽车自动驾驶 —— 能！（结合 AI）
  • 做一个自动回复笑话的聊天机器人 —— 能！
  • 让电脑帮你洗衣服 —— 不能！（除非洗衣机装了芯片并连接电脑）
练习三：想象你的第一个 Python 项目

在纸上写下："如果我会 Python，我最想做一个什么东西？"—— 一个计算器？一个小游戏？一个能讲笑话的程序？一个画画程序？每个人至少想出一个，鼓励奇思妙想！

SUMMARY

学会了什么？

  • 编程就是给计算机写下一步一步的指令，让它完成特定的任务

  • Python 在游戏、网站、AI、数据分析、自动化等领域都有广泛应用
  • Python 代码读起来很像英语，写起来也不复杂
