核心概念

KEY CONCEPTS

石头剪刀布的四个核心概念

列表存选项

choices = ["石头", "剪刀", "布"] —— 用列表统一管理所有可选拳法，方便随机选择和判断。

random.choice()

从列表中"抽一个"：computer = random.choice(choices)。电脑每次随机出拳，保证游戏公平。

多分支判断

if-elif-else 覆盖所有情况：先判断平局，再判断玩家赢的三种情况，其余为电脑赢。

计分系统

两个变量 player_score 和 computer_score，用 while 循环控制：谁先到 2 分就结束。

判断逻辑要点：赢的规则只有三种——"石头赢剪刀"、"剪刀赢布"、"布赢石头"。其他情况：相同 = 平局，不满足赢 + 不相同 = 电脑赢。

胜负判断 · 计分循环

CORE TEACHING

胜负判断 + 三局两胜计分

# 1. 准备：列表 + 符号映射
import random

choices = ["石头", "剪刀", "布"]
emoji_map = {"石头": "🪨", "剪刀": "✂️", "布": "🧻"}

# 2. 玩家出拳
player = input("请出拳（石头/剪刀/布）：")
if player not in choices:
    print("输入无效，请重新输入！")
    continue

# 3. 电脑随机出拳
computer = random.choice(choices)
# 4. 判断输赢（核心逻辑）
if player == computer:
    result = "平局"
elif (player == "石头" and computer == "剪刀") or \
     (player == "剪刀" and computer == "布") or \
     (player == "布" and computer == "石头"):
    result = "玩家赢"
    player_score += 1
else:
    result = "电脑赢"
    computer_score += 1

# 5. 展示结果
print(f"\n你：{emoji_map[player]} {player}")
print(f"电脑：{emoji_map[computer]} {computer}")
print(f"👉 {result}！")
print(f"比分 → 你 {player_score} : {computer_score} 电脑\n")
三局两胜主循环：while player_score < 2 and computer_score < 2: —— 只要双方都没到 2 分，游戏就继续。先到 2 分的一方胜出！

挑战练习：作弊模式

让电脑看到玩家出拳后，总是出能赢的拳——但电脑有 30% 概率"手滑" 出反了反而输掉。

# 作弊逻辑：电脑根据 player 决定出什么
import random
if player == "石头":
    win_move = "布"     # 布赢石头
elif player == "剪刀":
    win_move = "石头"   # 石头赢剪刀
else:
    win_move = "剪刀"   # 剪刀赢布

# 70% 概率出赢招，30% 概率手滑出随机招
if random.random() < 0.7:
    computer = win_move
else:
    computer = random.choice(choices)  # 手滑了！
