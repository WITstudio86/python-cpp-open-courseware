重点概念

KEY CONCEPTS

重点概念

Python 解释器

Python 是"解释型"语言。解释器就像翻译官，你写一行 Python 代码，它就帮你翻译成电脑能懂的机器语言，然后立刻执行。

IDLE

Python 自带的编程环境（集成开发与学习环境），就像 Python 给你准备的"写作本"，你可以在里面写代码并马上看到运行结果。

交互模式

写完一行代码，按回车就立刻出结果。界面上有 >>> 提示符，像是在跟 Python 一对一聊天。

脚本模式

把多行代码写在 .py 文件里，然后按 F5 一次性全部运行。适合写完整的程序，代码可以保存下来反复使用。

安装 Python 与认识 IDLE

第一步：下载安装 Python
打开浏览器，访问 https://www.python.org，点击黄色按钮 "Download Python 3.x.x" 下载安装包。

macOS 安装要点

  • 双击 .pkg 文件，按向导一直点"继续"和"同意"
  • 安装完成，打开"终端"验证：python3 --version

Windows 安装要点

  • 双击 .exe 文件
  • 最重要！务必勾选 "Add Python 3.x to PATH"
  • 点击 "Install Now"，等待安装完成
  • 验证：Win + R 输入 cmd，输入 python --version

交互模式 vs 脚本模式

# 交互模式（>>>）—— 面对面聊天
>>> print("Hello!")
Hello!
>>> 3 + 5
8
>>> "python".upper()
'PYTHON'

适合快速测试想法、做计算

# 脚本模式——写好一起运行
# File → New File
# 写多行代码，按 F5 运行
print("Hello, World!")
print("这是我的第一个程序")
print("我好厉害！")

适合写完整程序、需要保存的代码

编程界的仪式：Hello, World!
学任何一门新语言，第一个程序都是输出 "Hello, World!"。从 1978 年的《C 程序设计语言》开始，这成了程序员们的"传统仪式"——用新语言跟世界打个招呼！
print("Hello, World!")
# 运行它！看到这行字，你就是 Python 程序员了！🎉

课堂练习

练习一：安装检查

打开 IDLE，在 >>> 后面输入 print("我成功了！")，如果输出"我成功了！"就举手告诉老师！

练习二：交互模式探索

在 IDLE 交互模式下尝试以下命令，记录每个输出结果：

# 试试看每个会输出什么？
>>> print(10 + 20 * 3)
>>> print("猫" + "狗")
>>> print("喵" * 5)
>>> print("哈" * 10)
>>> import this  # 显示 Python 之禅！
练习三：排错小能手

找出以下代码中的错误并改正：

# 每个都有错误，找出来！
print "你好"           # 错误：缺少什么？
print("你好"           # 错误：缺了什么符号？
pront("你好")         # 错误：函数名拼错
print（"你好"）        # 错误：中文括号！
Print("你好")         # 错误：首字母大写了

记住：报错不可怕！报错是 Python 在帮你找问题，就像老师用红笔圈出错别字一样。

常见问题速查表

macOS 无法打开 IDLE
系统设置 → 隐私与安全性 → 点击"仍要打开"
python 不是内部命令
重装 Python，务必勾选 "Add to PATH"
SyntaxError 语法错误
检查括号是否中文全角、引号是否配对、冒号是否英文
找不到保存的文件
建议统一保存到桌面，文件名用英文或拼音
