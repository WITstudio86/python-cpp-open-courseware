重点概念

KEY CONCEPTS

重点概念

while 循环

当条件成立时，不断重复执行。条件不成立就停止。while 后面跟条件表达式，每次循环前都会检查。

for vs while

知道循环次数用 for（跑 10 圈），不知道次数（满足条件才停）用 while（跑到累了为止）。

死循环

条件永远成立，循环停不下来。按 Ctrl+C 可以强制停止。循环体里一定要有改变条件的代码！

条件更新

循环体里要有改变条件的代码（如 i += 1），否则条件永远不变，就会死循环。

CORE CONTENT

while 循环语法与示例

# while 的基本骨架
while 条件:
    循环体（条件成立时执行）
# 条件不成立时，跳出循环

# 简单例子：从 1 数到 5
i = 1
while i <= 5:
    print(i)
    i += 1  # 重要！改变条件，否则死循环！
# 输出：1 2 3 4 5
执行流程：检查 i <= 5（1<=5 True）→ 执行循环体 i 变 2 → 检查（2<=5 True）→ 执行 i 变 3 → ... → 检查（6<=5 False）→ 停止！

典型场景

USE CASES

while 的典型使用场景

# 场景1：用户输入控制（不知道要输几次）
answer = ""
while answer != "yes":
    answer = input("你准备好了吗？(输入 yes 继续)：")

# 场景2：倒数计时器
import time
count = 10
while count > 0:
    print(f"  {count}...")
    time.sleep(1)
    count -= 1
print("🚀 发射！")

# 场景3：累加到超过某个值
total = 0
i = 1
while total < 100:
    total += i
    i += 1
print(f"加了 {i-1} 个数，总和 {total} 超过了 100")
for 和 while 转换：任何 for 循环都能用 while 改写，反之亦然。但选择合适的循环能让代码更清晰。

# 猜数字（while 版本）
import random
secret = random.randint(1, 100)
guess = 0
while guess != secret:
    guess = int(input("猜一个数字："))
    if guess > secret:
        print("大了！")
    elif guess < secret:
        print("小了！")
print("猜对了！")

SUMMARY

学会了什么？

核心要点

  • while 循环：条件成立就一直执行
  • for 知道次数，while 知道条件
  • 循环体内一定要改变条件，否则死循环！
  • while 特别适合"用户输入控制"和"不确定次数"的场景
  • 如果死循环了，按 Ctrl+C 强制停止
