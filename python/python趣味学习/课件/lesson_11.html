第11节
重点概念

KEY CONCEPTS

重点概念

比较运算符

用来比较两个值之间关系的符号，结果只有两种：成立（True）或不成立（False）。包含 > < == != >= <= 共 6 个

布尔值（bool）

只有 True 和 False 两种值的数据类型，就像开关只有"开"和"关"一样。比较结果可以存到变量里，后面判断条件时非常有用

== 和 !=

== 是判断相等（两个等号），= 是赋值（一个等号），千万不要搞混！!= 判断不相等。这是最容易出错的坑

字符串也能比较

字符串按照字母表的顺序从左到右逐个比较，"a" < "b" < "c"……"apple" < "banana"。注意大写和小写字母是不同的

第11节
核心讲解

EXPLANATION

比较运算符演示

# ======== 比较运算符大全 ========

# 1. 数字比较
print("10 > 5  的结果：", 10 > 5)     # True
print("3 > 8   的结果：", 3 > 8)      # False
print("5 < 10  的结果：", 5 < 10)     # True
print("7 == 7  的结果：", 7 == 7)     # True（两个等号！）
print("7 != 8  的结果：", 7 != 8)     # True
print("10 >= 10 的结果：", 10 >= 10)  # True（等于也算）
print("5 <= 3  的结果：", 5 <= 3)    # False

# 2. 用变量比较（比身高）
my_height = 145
your_height = 150
print("你比我高吗？", your_height > my_height)  # True
print("我们一样高吗？", my_height == your_height) # False

# 3. 字符串比较（按字母顺序）
print('"apple" < "banana"', "apple" < "banana")  # True
print('"Hello" == "hello"', "Hello" == "hello") # False！大小写不同

# 4. 判断及格（实际应用）
score = 85
print("及格了吗？（>=60）", score >= 60) # True

# 5. 比较结果可以存起来
is_pass = score >= 60        # 存 True
print("is_pass =", is_pass)      # True
print("is_pass 的类型：", type(is_pass)) # <class 'bool'>
提示： 最最容易犯的错 —— = 是一个等号（赋值），== 是两个等号（判断相等）！就像写作业时把"等于号"写成了"赋值号"，Python 会直接报错或给出意想不到的结果
