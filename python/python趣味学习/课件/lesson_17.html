重点概念

KEY CONCEPTS

三种 range() 用法

range(n)

生成 0, 1, 2, ..., n-1（共 n 个数字）。注意不包含 n！range(5) 生成 0 1 2 3 4。

range(start, stop)

生成 start, start+1, ..., stop-1。包含 start，不包含 stop。range(1, 11) 是 1 到 10。

range(start, stop, step)

以 step 为步长生成数字。step 可以是负数（倒着数）。range(10, 0, -1) 是 10 到 1。

左闭右开

左边端点包含，右边端点不包含。就像数学区间 [start, stop)。range(2, 7) 包含 2 但不包含 7。

核心讲解

CORE CONTENT

range() 实战示例

# 1. range(n)：0 到 n-1
print("range(5)：")
for i in range(5):
    print(i, end=" ")  # 输出: 0 1 2 3 4

# 2. range(start, stop)：start 到 stop-1
print("\nrange(2, 7)：")
for i in range(2, 7):
    print(i, end=" ")  # 输出: 2 3 4 5 6

# 3. range(start, stop, step)：带步长
print("\n0到10的偶数：")
for i in range(0, 11, 2):
    print(i, end=" ")  # 0 2 4 6 8 10

# 4. 倒着数：倒计时
print("\n倒计时：")
for i in range(10, 0, -1):
    print(i, end=" ")
print("发射！🚀")
口诀：range(n) 就是从 0 数到 n-1，一共 n 个数。为什么 range(1, 11) 才到 10？因为 stop 不包含！左闭右开是 Python 的约定。

# 倒计时发射
import time
for i in range(10, 0, -1):
    print(i)
    time.sleep(0.5)

SUMMARY

学会了什么？

核心要点

  • range(n)：0 到 n-1，共 n 个数
  • range(start, stop)：start 到 stop-1
  • range(start, stop, step)：带步长，step 可以是负数
  • 左闭右开：包含左边，不包含右边
