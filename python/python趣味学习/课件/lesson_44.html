KEY CONCEPTS

重点概念

列表+字典组合

[{question, options, answer, explanation}, ...] —— 列表里每个元素是一个字典，字典包含题目、选项、答案和解析。这是 Python 中最常用的结构化数据模式。

遍历出题

for i, q in enumerate(questions, 1) —— enumerate 同时获取索引和元素，第二个参数 1 让索引从 1 开始，方便显示"第N题"。

答案判断

input().strip().upper() —— 去除首尾空格并转大写，确保"A"、" a "、"a"都能正确匹配。容错处理让程序更友好。

计分反馈系统

答对加分 + 鼓励提示；答错告知正确答案 + 显示解析。配合 if-elif-else 评语系统，根据得分率给出不同等级的评价。

1. 题库数据结构

用列表包裹字典，每个字典代表一道题，包含题目、选项、答案和解析四个字段。

# 题库 —— 列表 + 字典组合
questions = [
    {
        "question": "Python 中用什么关键字定义函数？",
        "options": ["A. func", "B. define", "C. def", "D. function"],
        "answer": "C",
        "explanation": "Python 用 def 关键字定义函数，如 def hello():"
    },
    {
        "question": "列表 list 用什么符号创建？",
        "options": ["A. ()", "B. []", "C. {}", "D. <>"],
        "answer": "B",
        "explanation": "列表用方括号 [] 创建，如 my_list = [1, 2, 3]"
    },
    {
        "question": "print(type(3.14)) 的输出是什么？",
        "options": ["A. int", "B. float", "C. str", "D. bool"],
        "answer": "B",
        "explanation": "3.14 是小数，在 Python 中属于 float（浮点数）类型"
    },
    {
        "question": "range(5) 生成哪些数字？",
        "options": ["A. 1,2,3,4,5", "B. 0,1,2,3,4", "C. 0,1,2,3,4,5", "D. 1,2,3,4"],
        "answer": "B",
        "explanation": "range(5) 从 0 开始，到 5 结束（不含 5），即 0,1,2,3,4"
    },
    {
        "question": "dictionary.get('key', '默认值') 的作用？",
        "options": ["A. 删除 key", "B. 添加 key", "C. 安全获取值，key 不存在时返回默认值", "D. 修改 key 的名称"],
        "answer": "C",
        "explanation": "dict.get(key, default) 是安全取值方式，key 不存在时不会报错，而是返回默认值"
    }
]
数据结构要点：列表保证题目出题顺序，字典让每道题的信息结构化。你可以随时增删题目，只需在列表里添加/删除字典即可，循环逻辑完全不用改！

2. 出题、判断与计分逻辑

# 初始化
score = 0
wrong_list = []  # 错题本：记录答错的题目
total = len(questions)

# 逐题出题
for i, q in enumerate(questions, 1):
    print(f"\n📝 第{i}题（共{total}题）：{q['question']}")

    # 显示选项
    for opt in q['options']:
        print(f"    {opt}")

    # 获取用户答案并处理
    user = input("你的答案（A/B/C/D）：").strip().upper()

    # 判断对错
    if user == q['answer']:
        print("✅ 正确！太棒了！")
        score += 1
    elif user in ['A', 'B', 'C', 'D']:
        print(f"❌ 错误！正确答案是 {q['answer']}")
        print(f"💡 解析：{q['explanation']}")
        wrong_list.append(q)
    else:
        print("⚠️ 输入无效，请输入 A、B、C 或 D")
        print(f"💡 正确答案是 {q['answer']}：{q['explanation']}")

3. 评语系统

# 多级评语 —— 根据得分率给出个性化反馈
def get_comment(score, total):
    rate = score / total
    if rate == 1.0:
        return "🏆 满分学霸！你太厉害了，所有题目全对！"
    elif rate >= 0.8:
        return "👏 优秀！掌握得很扎实，继续保持！"
    elif rate >= 0.6:
        return "👍 良好！还有一点提升空间，看看错题本吧！"
    elif rate >= 0.4:
        return "📚 及格啦！建议重新复习错题相关知识点。"
    else:
        return "💪 别灰心！编程学习贵在坚持，多练几次就好了！"

# 最终结果展示
print("\n" + "=" * 30)
print(f"📊 答题结束！总分：{score}/{total}")
print(get_comment(score, total))

# 显示错题回顾
if wrong_list:
    print(f"\n📋 错题回顾（共{len(wrong_list)}题）：")
    for w in wrong_list:
        print(f"  · {w['question']}  → 答案：{w['answer']}")
else:
    print("\n🎉 没有错题，完美通关！")
执行流程总结：定义题库 → 初始化 score=0 → for 循环逐题出题 → input 获取答案 → strip().upper() 标准化 → if 判断对错并计分 → get_comment() 计算得分率生成评语 → 展示错题回顾。
