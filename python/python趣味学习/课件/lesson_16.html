重点概念

KEY CONCEPTS

重点概念

循环

让一段代码重复执行。就像跑步的"跑圈"，一圈又一圈。

for 循环

Python 中最常用的循环，用于逐个取出序列中的元素。for + 变量 + in + 序列 + 冒号。

遍历

逐个访问序列中的每一个元素。遍历字符串就是逐个取出每个字符。

循环体

for 下面缩进的代码块，每次循环都会执行一遍。缩进决定了哪些代码属于循环。

CORE CONTENT

for 循环基本语法

# 遍历字符串：逐个打印每个字
name = "小明爱编程"
for char in name:
    print(char)
# 输出：小 明 爱 编 程
结构解释：for（关键字）+ char（循环变量）+ in（关键字）+ name（被遍历的序列）+ :（冒号）+ 缩进的循环体。
# 遍历列表
fruits = ["苹果", "香蕉", "橘子", "葡萄"]
for fruit in fruits:
    print(f"我喜欢吃{fruit}！")
# 在循环中用 if 判断
numbers = [12, 7, 25, 8, 19, 3, 30]
for n in numbers:
    if n > 10:
        print(f"{n} 大于 10")
    else:
        print(f"{n} 不大于 10")
