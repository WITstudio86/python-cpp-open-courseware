重点概念

KEY CONCEPTS

重点概念

def 关键字

Python 里用来"定义"函数的关键字。def 是 define（定义）的缩写。看到 def，就知道后面在定义一个函数。

函数名命名规则

只能包含字母、数字、下划线(_)，不能以数字开头，不能是 Python 关键字（如 if、for、def 等）。推荐用小写字母 + 下划线（如 say_hello）。

定义 vs 调用

定义 = "写菜谱"（告诉电脑有这么一道菜）。调用 = "做菜"（让电脑真的去执行）。必须先定义，再调用！

缩进（Indent）规则

函数体（函数里面的代码）必须缩进！通常用 4 个空格。同一函数体内的代码，缩进必须一致。缩进结束 = 函数结束。

核心讲解

CORE CONTENT

def 语法骨架

# def 定义函数的基本骨架
def 函数名():
    # 函数体内的代码 —— 必须缩进！
    语句1
    语句2
    ...

# 调用函数 —— 在函数外面，不缩进
函数名()
记住：def 关键字 + 函数名 + 括号 + 冒号 → 换行 → 缩进 4 格 → 写函数体。函数体结束（不再缩进）后，写"函数名+括号"来调用！
定义和调用的比喻：def 就像在笔记本上写了一个"菜谱"（定义），写了不代表做了。只有用"函数名()"调用时，电脑才真正照着"菜谱"去执行！

代码演示

CODE DEMO

实用示例

# 示例1：问候函数 —— 最简单
def say_hello():
    print("你好！")
    print("欢迎来到 Python 的世界！")

# 调用函数（可以调好多次！）
say_hello()
say_hello()  # 再打一次招呼
# 示例2：打印分隔线 —— 避免重复劳动
def print_line():
    print("=" * 30)

def print_dashed():
    print("-" * 30)

# 需要分隔线时，调用即可！
print_line()
print("我的小程序")
print_line()
print("版本 1.0")
print_dashed()
# 示例3：画框函数 —— 函数可以调用函数
def draw_box():
    print_line()              # 函数里调用另一个函数！
    print("|  欢迎来到 Python！  |")
    print_line()

draw_box()
注意： draw_box() 调用了 print_line()，所以 print_line() 必须在 draw_box() 前面定义！先定义的函数，后面才能用。

命名规则详解

NAMING RULES

函数命名规则详解

合法命名

只能包含：字母（a-z, A-Z）、数字（0-9）、下划线（_）

不能以数字开头。

区分大小写：say_hello 和 Say_Hello 是两个不同的函数。

推荐风格：全小写，单词用下划线连接（snake_case）。

命名示例

# ✅ 合法的函数名
def greet(): ...
def say_hello(): ...
def print_line_2(): ...
def _helper(): ...

# ❌ 不合法的函数名
def 2times(): ...     # 不能数字开头
def say hello(): ...  # 不能有空格
def if(): ...         # 不能用关键字
def my-func(): ...    # 不能用连字符
起名小技巧：用"动词_名词"的格式，让别人一看就知道函数干吗的。比如 print_menu（打印菜单）、get_score（获取分数）、draw_star（画星星）。函数名就是函数的"自我介绍"！
