KEY CONCEPTS

重点概念

导入 turtle 模块

使用 import turtle 导入海龟绘图模块。

创建画笔对象

使用 t = turtle.Turtle() 创建一个 Turtle 对象（画笔）。

for 循环画多边形

使用 for i in range(n) 循环 n 次，每次画一条边。

360/n 公式

正 n 边形的每个外角 = 360 / n 度。每次循环转 360/n 度。

forward() 和 left()/right()

forward(n) 前进 n 像素，left(90) 左转 90 度，right(90) 右转 90 度。

CORE CONTENT

基础：Turtle 画图步骤

# 步骤 1：导入并创建画笔
import turtle
t = turtle.Turtle()
t.speed(5)  # 设置速度
# 步骤 2：画正三角形
for i in range(3):
    t.forward(100)
    t.left(120)
# 360 / 3 = 120 度，360 / 4 = 90 度
# 步骤 3：画正方形
for i in range(4):
    t.forward(100)
    t.right(90)
# 360 / 4 = 90 度
# 步骤 4：画正五边形
for i in range(5):
    t.forward(100)
    t.left(72)
# 360 / 5 = 72 度
# 步骤 5：画正六边形
for i in range(6):
    t.forward(100)
    t.right(60)
# 360 / 6 = 60 度
重点提示：使用 turtle.Turtle() 创建画笔对象，t.speed(0) 设置最快速度（瞬间完成），t.pencolor("blue") 设置画笔颜色为蓝色，t.pensize(2) 设置画笔粗细为 2 像素。
