重点概念

KEY CONCEPTS

模块与导入

模块（module）

一个 .py 文件就是一个模块。把相关函数写在一起，就做成了一个"工具箱"。例如 random.py、math.py。

import 模块名

导入整个模块，使用时需要加模块名前缀。如 import my_tools，调用：my_tools.add(3, 5)。

from...import

从模块中导入指定的函数，使用时不需要前缀。如 from my_tools import add, is_even，直接写 add(3, 5)。

__name__ 变量

每个 .py 文件都有一个内置变量 __name__。直接运行时为 "__main__"，被导入时为模块名。常用来写测试代码。

# ── 一、数学工具 ──
def add(a, b):
    return a + b

def is_even(n):
    """判断是否是偶数"""
    return n % 2 == 0

def average(numbers):
    """计算列表的平均数"""
    if len(numbers) == 0:
        return 0
    return sum(numbers) / len(numbers)

def is_prime(n):
    """判断质数：只能被 1 和自己整除"""
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

def factorial(n):
    """阶乘：5! = 5×4×3×2×1 = 120"""
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

# ── 二、字符串工具 ──
def is_palindrome(s):
    """回文判断：正读反读都一样，如 "上海自来水" """
    s = s.replace(" ", "")  # 去掉空格
    return s == s[::-1]

def count_char(s, ch):
    """统计某个字符出现次数"""
    return s.count(ch)

def reverse_string(s):
    """反转字符串"""
    return s[::-1]

def to_title(s):
    """首字母大写，如 'hello world' → 'Hello World'"""
    return s.title()

# ── 三、列表工具 ──
def find_max(lst):
    if len(lst) == 0: return None
    return max(lst)

def find_min(lst):
    if len(lst) == 0: return None
    return min(lst)

def remove_duplicates(lst):
    """去重：保留顺序，去掉重复"""
    result = []
    for item in lst:
        if item not in result:
            result.append(item)
    return result

def filter_even(lst):
    """筛选出列表中的所有偶数"""
    return [x for x in lst if x % 2 == 0]

# ── 四、字典工具 ──
def get_keys(d):
    """获取字典所有键"""
    return list(d.keys())

def get_values(d):
    """获取字典所有值"""
    return list(d.values())

def merge_dicts(d1, d2):
    """合并两个字典，重复键以 d2 为准"""
    result = d1.copy()
    result.update(d2)
    return result

def find_key_by_value(d, value):
    """根据值查找键（返回第一个匹配）"""
    for k, v in d.items():
        if v == value:
            return k
    return None

# ========== main.py（主程序）==========

import 的黄金法则

  • import 写在文件最上面，所有代码之前

  • 被 import 的文件名不能以数字开头
