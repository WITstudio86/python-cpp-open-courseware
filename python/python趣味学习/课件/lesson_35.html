重点概念

KEY CONCEPTS

认识 .circle() 函数

.circle(radius)

画一个整圆。radius 是半径，数字越大圆越大。
例如：t.circle(50) 画半径 50 的圆。

.circle(radius, angle)

画一段弧线。angle 表示画多少度。
180 = 半圆，90 = 四分之一圆。
例如：t.circle(60, 180) 画半圆。

画圆的方向

默认逆时针画圆。圆画在海龟前进方向的"左侧"。想要顺时针画，用负数半径：t.circle(-50)。

提笔移动：不画线

t.penup() 提起笔（移动不留痕迹）
t.pendown() 放下笔（移动就画线）
组合多个图形时必备！

画圆详解

CORE CONTENT 1

.circle(radius) —— 画整圆

import turtle
t = turtle.Turtle()
t.pensize(4)

# 画一个红色的大圆（半径 100）
t.color("red")
t.circle(100)

# 移到旁边，画一个蓝色的小圆（半径 50）
t.penup()
t.forward(180)
t.pendown()
t.color("blue")
t.circle(50)

# 再画一个填充颜色的圆
t.penup()
t.backward(50)
t.pendown()
t.color("orange")
t.begin_fill()
t.circle(30)
t.end_fill()

t.hideturtle()
turtle.done()
小贴士： t.circle(50) 中的 50 是半径，不是直径！半径 50 的圆，直径是 100。海龟的位置在圆的"边缘"上，圆画在海龟前进方向的左侧。

画弧线详解

CORE CONTENT 2

.circle(radius, angle) —— 画弧线

import turtle
t = turtle.Turtle()
t.pensize(4)

# 半圆：360° 的一半 = 180°
t.color("purple")
t.circle(60, 180)

# 四分之一圆：90°（直角弧线）
t.penup()
t.forward(140)
t.pendown()
t.color("green")
t.circle(60, 90)

# 小弧线：只画 60° 的一段
t.penup()
t.right(90)
t.forward(120)
t.left(90)
t.pendown()
t.color("red")
t.circle(40, 60)

# 反向弧线（顺时针）：用负数半径
t.penup()
t.forward(100)
t.pendown()
t.color("blue")
t.circle(-50, 180)

t.hideturtle()
turtle.done()

弧线口诀

radius 管大小，angle 管长短。
180 画半圆，90 画四分之一。
正半径 = 逆时针，负半径 = 顺时针。

什么时候用弧线？

画笑脸的嘴巴（半个圆）、画花瓣（短弧线）、画彩虹（多彩弧线）、画太阳的光芒……

FUN PROJECT 1

用圆和弧线画一个笑脸

用一个大圆做脸、两个小圆做眼睛、一段弧线做嘴巴，拼出一个可爱的笑脸！

import turtle
t = turtle.Turtle()
t.speed(5)
t.pensize(3)

# ① 画大脸（黄色填充圆，半径 100）
t.penup()
t.goto(0, -100)
t.pendown()
t.color("yellow")
t.begin_fill()
t.circle(100)
t.end_fill()

# ② 画左眼（小圆，半径 15）
t.penup()
t.goto(-40, 30)
t.pendown()
t.color("black")
t.begin_fill()
t.circle(15)
t.end_fill()

# ③ 画右眼
t.penup()
t.goto(40, 30)
t.pendown()
t.begin_fill()
t.circle(15)
t.end_fill()

# ④ 画微笑嘴巴（弧线：半径 45，画 120°）
t.penup()
t.goto(-35, -15)
t.pendown()
t.pensize(3)
t.setheading(-60)        # 调整方向
t.circle(45, 120)        # 画微笑弧线

t.hideturtle()
turtle.done()
关键技巧： 用 .goto(x, y) 把海龟移到指定坐标，用 penup()/pendown() 控制是否画线。setheading() 可以旋转海龟朝向，控制弧线的起始方向。

FUN PROJECT 2

用三个圆堆出一个雪人

三个大小不同的圆叠在一起就是雪人！再加上眼睛、鼻子和纽扣。

import turtle
t = turtle.Turtle()
t.speed(5)
t.pensize(3)

# ① 最下面的雪球（最大，半径 80）
t.penup()
t.goto(0, -140)
t.pendown()
t.color("lightblue")
t.begin_fill()
t.circle(80)
t.end_fill()

# ② 中间的雪球（中等，半径 60）
t.penup()
t.goto(0, 0)
t.pendown()
t.begin_fill()
t.circle(60)
t.end_fill()

# ③ 头部（最小，半径 40）
t.penup()
t.goto(0, 100)
t.pendown()
t.begin_fill()
t.circle(40)
t.end_fill()

# ④ 画眼睛和鼻子
t.penup()
t.color("black")
t.goto(-12, 130); t.dot(6)   # 左眼
t.goto(12, 130); t.dot(6)    # 右眼
t.goto(0, 115)
t.color("orange"); t.dot(8)        # 鼻子

# ⑤ 画纽扣
t.color("black")
t.goto(0, 75); t.dot(7)     # 上纽扣
t.goto(0, 50); t.dot(7)     # 下纽扣

t.hideturtle()
turtle.done()
