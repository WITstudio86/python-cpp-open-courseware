# Python 趣味学习 —— 48 节教学大纲

> **面向对象**：小学中高年级（10-12 岁）  
> **每节时长**：60 分钟（约 25-30 分钟讲解 + 25-30 分钟动手练习）  
> **教学理念**：趣味驱动、项目导向、螺旋上升、回避抽象

## 教学建议

### 时间分配（每节 60 分钟）

| 环节 | 时长 | 说明 |
|------|:----:|------|
| 回顾上节 | 5 分钟 | 提问或小练习快速复习 |
| 新课讲解 | 20-25 分钟 | 边讲边演示，多用比喻和可视化 |
| 动手练习 | 25-30 分钟 | 学生在电脑上实操，老师巡堂答疑 |
| 总结回顾 | 5 分钟 | 本节重点回顾，预告下节内容 |

### 教学 Tips

- **多用比喻**：变量像盒子，列表像抽屉柜，字典像通讯录，函数像榨汁机
- **允许犯错**：鼓励学生自己 debug，错误是最好的学习机会
- **即时代码演示**：每节课老师现场敲代码运行，不要只放 PPT
- **同伴互助**：做得快的学生帮助旁边的同学
- **作品展示**：单元项目完成后，花几分钟让学生互相展示作品
- **不要求背诵**：语法细节自然会记住，重点培养编程思维

### 建议的扩展方向（课程结束后）

- Python 海龟画图进阶（更复杂的动画和交互）
- Pygame Zero 入门（做真正的 2D 小游戏）
- 网络爬虫初探（用 requests 抓取网页信息）
- Micro:bit 硬件编程（用 Python 控制 LED、传感器）
- 参加青少年编程比赛（蓝桥杯、NOC 等）
