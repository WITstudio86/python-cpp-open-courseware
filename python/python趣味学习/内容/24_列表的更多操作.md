# 第24节：列表的更多操作

## 🎯 教学目标
- 学生能够使用 `.sort()` 和 `sorted()` 对列表进行排序
- 学生能够使用 `.reverse()` 反转列表顺序
- 学生能够使用 `in` 关键字判断元素是否在列表中
- 学生能够使用 `min()`、`max()`、`sum()` 进行数值统计
- 学生能够综合运用列表操作完成"成绩管理器"项目

## 📝 重点概念
- **sort() vs sorted()**：sort 是"就地修改原列表"，sorted 是"生成一个新列表"
- **reverse()**：把列表前后翻转
- **in 关键字**：判断某个东西"在不在"列表里
- **min/max/sum**：找最小、最大、求和，专门对数字列表用

### 步骤2：核心讲解（15-20分钟）

#### 2.1 排序：sort() 和 sorted()

```python
# sort()：直接修改原列表（原地排序）
nums = [3, 1, 4, 1, 5, 9, 2]
nums.sort()
print(nums)  # [1, 1, 2, 3, 4, 5, 9] —— 原列表被改变了

# sorted()：生成新列表，原列表不变
nums = [3, 1, 4, 1, 5, 9, 2]
new_nums = sorted(nums)
print("原列表：", nums)      # [3, 1, 4, 1, 5, 9, 2] —— 没变！
print("新列表：", new_nums)   # [1, 1, 2, 3, 4, 5, 9]
```

**降序排序**：

```python
nums = [3, 1, 4, 1, 5, 9, 2]
nums.sort(reverse=True)  # 从大到小
print(nums)  # [9, 5, 4, 3, 2, 1, 1]
```

**类比**：sort() 像在原来的纸面上直接涂改，sorted() 像复印一张再涂改，原稿还在。

#### 2.2 反转：reverse()

```python
fruits = ["苹果", "香蕉", "橘子"]
fruits.reverse()
print(fruits)  # ['橘子', '香蕉', '苹果']
```

**注意**：reverse() 不是排序，只是把顺序倒过来！

#### 2.3 判断存在：in 关键字

```python
students = ["小明", "小红", "小刚", "小丽"]

print("小明" in students)   # True —— 小明在名单里
print("小李" in students)   # False —— 小李不在

# 配合 if 使用
name = input("请输入要查找的名字：")
if name in students:
    print(name + " 在班级名单中！")
else:
    print(name + " 不在班级名单中。")
```

#### 2.4 数值统计：min()、max()、sum()

```python
scores = [95, 88, 92, 100, 76, 83]

print("最高分：", max(scores))  # 100
print("最低分：", min(scores))  # 76
print("总分：", sum(scores))    # 534
print("平均分：", sum(scores) / len(scores))  # 89.0
```

**注意**：这些函数只对数字列表有用，字符串列表也能用 min/max（按字母顺序）。

### 步骤3：动手演示（10分钟）


## 💻 代码示例

```python
# ========== 第24节：列表的更多操作 ==========

# --- 1. 排序：sort() vs sorted() ---
print("=== 排序 ===")

numbers = [5, 2, 8, 1, 9, 3]
print("原始：", numbers)

# sort()：原地排序（直接修改原列表）
numbers.sort()
print("sort() 后（升序）：", numbers)

numbers.sort(reverse=True)
print("sort(reverse=True)（降序）：", numbers)

# sorted()：生成新列表，原列表不变
original = [5, 2, 8, 1, 9, 3]
new_list = sorted(original)
print("\n原列表没变：", original)
print("sorted() 新列表：", new_list)

# 字符串也能排序（按字母顺序）
fruits = ["banana", "apple", "cherry", "date"]
fruits.sort()
print("水果按字母排序：", fruits)

# --- 2. 反转 ---
print("\n=== 反转 ===")

items = ["一", "二", "三", "四"]
print("原始：", items)
items.reverse()
print("反转后：", items)

# --- 3. in：判断存在 ---
print("\n=== in 判断 ===")

classmates = ["小明", "小红", "小刚", "小丽", "小华"]

print("小明在吗？", "小明" in classmates)
print("小李在吗？", "小李" in classmates)

# 配合 if 语句使用
name = "小红"
if name in classmates:
    print(f"✅ {name} 是我们班的同学！")
else:
    print(f"❌ {name} 不是我们班的同学。")

# --- 4. 数值统计 ---
print("\n=== 数值统计 ===")

scores = [95, 88, 92, 100, 76, 83, 91, 89]

print("成绩列表：", scores)
print("最高分：", max(scores))
print("最低分：", min(scores))
print("总分：", sum(scores))
average = sum(scores) / len(scores)
print(f"平均分：{average:.1f}")

# 统计及格人数
pass_count = 0
for s in scores:
    if s >= 60:
        pass_count += 1
print(f"及格人数：{pass_count}/{len(scores)}")

# --- 5. 综合项目：成绩管理器 ---
print("\n=== 📊 成绩管理器 ===")
print("-" * 30)

def show_stats(name, scores):
    """显示成绩统计信息"""
    print(f"\n📚 {name} 成绩报告")
    print(f"原始成绩：{scores}")
    print(f"最高分：{max(scores)}")
    print(f"最低分：{min(scores)}")
    print(f"总分：{sum(scores)}")
    print(f"平均分：{sum(scores)/len(scores):.1f}")
    print(f"及格人数：{sum(1 for s in scores if s >= 60)}")

# 语文成绩
chinese = [88, 92, 76, 95, 83, 90, 79, 94]
show_stats("语文", chinese)

# 排序后看排名
chinese_sorted = sorted(chinese, reverse=True)
print(f"\n语文成绩排名：{chinese_sorted}")
print(f"第一名：{chinese_sorted[0]} 分")
print(f"最后一名：{chinese_sorted[-1]} 分")
```
