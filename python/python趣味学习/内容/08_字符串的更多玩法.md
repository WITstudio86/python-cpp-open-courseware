# 第8节：字符串的更多玩法

## 教学目标
- 学生能够使用 `+` 拼接字符串和 `*` 重复字符串
- 学生能够使用 `.upper()`、`.lower()`、`.title()` 等方法改变字符串的大小写
- 学生能够使用 `.strip()`、`.replace()` 等方法清理和替换字符串内容
- 学生能够使用 f-string（格式字符串）将变量优雅地嵌入文本
- 学生能够综合运用字符串方法完成"奖状生成器"项目

## 重点概念
- **字符串拼接（+）**：用 `+` 把两个字符串首尾相连，形成一个新的字符串。就像把两节火车车厢连在一起。注意：只能字符串 + 字符串，不能字符串 + 数字（会报错！）。
- **字符串重复（*）**：用 `*` 让一个字符串重复指定次数。比如 `"哈" * 5` 得到 `"哈哈哈哈哈"`。
- **字符串方法**：字符串有很多"技能"，用法是 `字符串.方法名()`。例如 `"hello".upper()` 会变成 `"HELLO"`。这些方法不会改变原来的字符串，而是**返回一个新的字符串**。
- **f-string（格式字符串）**：Python 3.6 引入的超级方便的功能！在字符串前加一个 `f`，就可以在 `{}` 里直接嵌入变量。比如 `f"我叫{name}，今年{age}岁"`。
- **不可变性**：字符串一旦创建就不能被修改。所有的字符串方法都是返回一个**新的**字符串，原来的字符串不会变。这就像在一张写了字的纸上，你不能擦掉某个字，只能重新抄一份时做修改。

### 步骤2：核心讲解（15-20分钟）

#### 2.1 字符串拼接 `+` 和重复 `*`

**拼接 `+`：把两个字符串连在一起**

```python
a = "你好"
b = "世界"
print(a + b)           # 你好世界（连在一起，中间没有空格）
print(a + "，" + b)    # 你好，世界（手动加标点）
print(a + " " + b)     # 你好 世界（手动加空格）
```

**常见错误：字符串不能和数字直接拼接！**
```python
name = "小明"
age = 10
# print(name + "今年" + age + "岁")   ← 报错！age 是数字，不能 + 字符串
print(name + "今年" + str(age) + "岁")  # 正确！用 str() 把数字转成字符串
```

**重复 `*`：让字符串自我复制**

```python
print("哈" * 5)     # 哈哈哈哈哈
print("=" * 20)     # ==================== （做分隔线超好用！）
print("喵～" * 3)   # 喵～喵～喵～
print(">" * 10)     # >>>>>>>>>> （做箭头）
```

`字符串 * 数字` = 把字符串重复数字那么多遍。注意：只能是字符串乘以整数，不能是小数。

**拼接和重复组合使用：**
```python
# 画图案
print("* " * 5)      # * * * * * 
print(" *" * 5)      #  * * * * *
print("* " * 5)

# 做一条漂亮的标题线
title = " 欢迎来到 Python 世界 "
line = "=" * len(title)
print(line)
print(title)
print(line)
```

#### 2.2 字符串大小写变换

Python 的字符串有一些"变身"方法，可以改变字母的大小写。注意：这些方法**对中文字符无效（中文没有大小写）**。

**`.upper()` —— 全部变大写**
```python
print("hello".upper())        # HELLO
print("Python".upper())       # PYTHON
print("Hello World".upper())  # HELLO WORLD
```

**`.lower()` —— 全部变小写**
```python
print("HELLO".lower())        # hello
print("Python".lower())       # python
print("I AM A STUDENT".lower())  # i am a student
```

**`.title()` —— 每个单词首字母大写**
```python
print("hello world".title())          # Hello World
print("i love python".title())       # I Love Python
print("welcome to beijing".title())  # Welcome To Beijing
```

**`.capitalize()` —— 只有第一个字母大写**
```python
print("hello world".capitalize())    # Hello world（只有 H 大写）
```

**实际应用场景：**
```python
# 处理用户输入的大小写问题
answer = input("请输入 yes 或 no：")
if answer.lower() == "yes":     # 不管用户输入 YES、Yes、yEs，统统变小写再判断
    print("你选了是！")
elif answer.lower() == "no":
    print("你选了否！")
else:
    print("请输入 yes 或 no")

# 统一用户名格式
name = input("请输入姓名（英文）：")
print("标准格式：", name.title())    # 自动首字母大写
```

#### 2.3 清理和替换

**`.strip()` —— 去除字符串两端的空白字符（空格、换行等）**

```python
name = "   小明   "
print("[" + name + "]")          # [   小明   ]
print("[" + name.strip() + "]")  # [小明]  —— 两端的空格不见了！

# 注意：.strip() 只去掉两端的空格，中间的不动
text = "   Hello   World   "
print("[" + text.strip() + "]")  # [Hello   World] —— 中间空格保留！
```

`.strip()` 还可以去除指定字符：
```python
print("...Hello...".strip("."))  # Hello —— 去掉两端的点
print("xxxHelloxxx".strip("x"))  # Hello —— 去掉两端的 x
```

**兄弟方法：**
- `.lstrip()` —— 只去左边（left）
- `.rstrip()` —— 只去右边（right）

```python
text = "   Hello   "
print("[" + text.lstrip() + "]")  # [Hello   ] —— 只去了左边
print("[" + text.rstrip() + "]")  # [   Hello] —— 只去了右边
```

**`.replace()` —— 替换字符串中的内容**

```python
message = "我喜欢吃苹果，苹果很好吃"
print(message.replace("苹果", "香蕉"))
# 输出：我喜欢吃香蕉，香蕉很好吃

# 替换空格
text = "Hello World"
print(text.replace(" ", "_"))    # Hello_World

# 只替换前几次
text = "aaa aaa aaa"
print(text.replace("a", "b", 3)) # bbb aaa aaa —— 只替换了前3个 'a'
```

**`.replace()` 的语法：`字符串.replace(旧内容, 新内容, 替换次数)`**

第三个参数（替换次数）是可选的，不写就替换所有匹配的内容。

#### 2.4 f-string —— 超级方便的字符串格式化

这是 Python 3.6 开始支持的一个非常强大的功能，让字符串拼接变得超简单！

**传统方法（拼接）：**
```python
name = "小明"
age = 10
score = 95
print("我叫" + name + "，今年" + str(age) + "岁，考了" + str(score) + "分")
# 好麻烦！引号、加号、str() 转换，眼花缭乱！
```

**f-string 方法（推荐！）：**
```python
name = "小明"
age = 10
score = 95
print(f"我叫{name}，今年{age}岁，考了{score}分")
# 一行搞定！清晰又好看！
```

**f-string 的写法规则：**
1. 字符串前面加一个 `f`（可以是 `f"..."` 或 `f'...'`）
2. 在字符串里用 `{变量名}` 嵌入变量
3. `{}` 里面不只是变量名，还可以是表达式！

```python
a = 10
b = 20
print(f"{a} + {b} = {a + b}")  # 10 + 20 = 30 —— 大括号里可以直接计算！

name = "小明"
print(f"名字长度：{len(name)}")   # 名字长度：2

price = 12.5
count = 3
print(f"总价：{price * count}元")  # 总价：37.5元
```

**f-string 的妙用：**
```python
# 制作好看的对齐输出
name1 = "小明"
score1 = 95
name2 = "小红红"
score2 = 88
print(f"姓名    成绩")
print(f"{name1}    {score1}")
print(f"{name2}    {score2}")

# 在 f-string 里做计算
r = 5
print(f"半径{r}的圆的面积约等于{3.14 * r * r}")

# 多行信息
name = "小华"
age = 11
grade = "五年级"
hobby = "编程"
print(f"""
====================
   {name}同学的档案
====================
年龄：{age}岁
年级：{grade}
爱好：{hobby}
====================
""")
```

## 小结

**本节学了什么：**
- `+` 可以拼接字符串，`*` 可以重复字符串（做分隔线超好用）
- `.upper()` / `.lower()` / `.title()` 变换大小写（处理用户输入很实用）
- `.strip()` 去除两端空格，`.replace()` 替换文字内容
- f-string `f"文字{变量}文字"` 让字符串拼接变得超级简单
- 这些方法都不会改原字符串，而是返回新字符串（就像重新抄一份）
