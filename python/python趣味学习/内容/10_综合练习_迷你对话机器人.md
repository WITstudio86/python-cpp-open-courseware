# 第10节：综合练习 —— 迷你对话机器人

## 教学目标
- 学生能够综合运用前9节学过的知识：print、input、变量、数字运算、字符串操作、类型转换
- 学生能够独立设计一个简单的交互式程序
- 学生能够阅读和调试包含多步逻辑的代码
- 学生能够体验从需求到实现的完整编程流程

## 重点概念
- **综合运用**：把前面学的各个知识点串起来，做成一个完整的程序
- **程序流程**：一个程序就像一段对话，有问有答，有输入有输出，有计算有显示
- **程序结构**：一个完整的程序包含：开头问候 → 收集信息 → 处理信息 → 输出结果
- **调试思维**：当程序出问题时，学会用 print 检查变量值，逐行排查

### 步骤2：核心讲解——程序的设计与结构（15分钟）

#### 2.1 先设计，再写代码

在动手写代码之前，先规划清楚：

**对话机器人的流程设计：**
```
1. 打招呼，介绍自己
2. 问用户的名字
3. 问用户的年龄，算出生年份
4. 问用户喜欢的食物
5. 问用户喜欢的颜色
6. 问用户的爱好
7. 总结所有信息
8. 说再见
```

**数据设计——需要哪些变量？**
- name：名字（字符串）
- age：年龄（整数）
- birth_year：出生年份（整数）
- food：喜欢的食物（字符串）
- color：喜欢的颜色（字符串）
- hobby：爱好（字符串）

#### 2.2 分步实现

**第一步：打招呼和问名字**
```python
print("=" * 40)
print("🤖 你好！我是 Python 迷你对话机器人！")
print("=" * 40)

name = input("你叫什么名字？").strip().title()
print(f"🤖：{name}你好！很好听的名字！")
```

**第二步：问年龄并计算**
```python
age = int(input(f"{name}，你今年几岁了？"))
birth_year = 2024 - age
print(f"🤖：原来你{age}岁！那你是 {birth_year} 年左右出生的吧？")
```

**第三步：问喜好**
```python
food = input("你最喜欢的食物是什么？").strip()
print(f"🤖：{food}！听起来就很好吃！")

color = input("你最喜欢的颜色是什么？").strip()
print(f"🤖：{color}色很漂亮！")

hobby = input("你平时喜欢做什么？").strip()
print(f"🤖：{hobby}是个很棒的爱好！")
```

**第四步：总结输出**
```python
print("\n" + "=" * 40)
print("🤖：让我总结一下你的信息：")
print("=" * 40)
print(f"""
  📛 姓名：{name}
  🎂 年龄：{age}岁（约{birth_year}年出生）
  🍕 喜欢的食物：{food}
  🎨 喜欢的颜色：{color}
  ⚽ 爱好：{hobby}
""")
print("=" * 40)
print(f"🤖：很高兴和你聊天，{name}！下次见！👋")
```

### 步骤3：动手演示——完整项目（15分钟）

#### 版本1：基础对话机器人（逐行讲解）

带领学生一起输入以下完整代码，边写边解释：

```python
# ===== 迷你对话机器人 =====

print("=" * 40)
print("🤖 欢迎来到 Python 对话机器人！")
print("=" * 40)

# 第1步：打招呼
name = input("🤖：你好！你叫什么名字？\n👤：").strip().title()
print(f"🤖：{name}你好！很高兴认识你！\n")

# 第2步：问年龄
age = int(input(f"🤖：{name}，你今年几岁了？\n👤："))
birth_year = 2024 - age
print(f"🤖：{age}岁！那你大概出生在 {birth_year} 年~")
print(f"🤖：再过 {100 - age} 年你就100岁了！\n")

# 第3步：问喜好
food = input("🤖：你最喜欢吃什么？\n👤：").strip()
print(f"🤖：{food}！我也觉得{ food }很好吃！\n")

color = input("🤖：最喜欢的颜色是？\n👤：").strip()
print(f"🤖：{color}色呀，非常有品味！\n")

hobby = input("🤖：平时有什么爱好呢？\n👤：").strip()
print(f"🤖：{hobby}听起来很有趣！我也想试试！\n")

# 第4步：问梦想
dream = input("🤖：你长大以后想做什么？\n👤：").strip()
print(f"🤖：{dream}！加油，你一定可以的！\n")

# 第5步：总结
print("=" * 40)
print("🤖：好啦，让我总结一下你的信息：")
print("=" * 40)
print(f"""
  📛 姓名：{name}
  🎂 年龄：{age} 岁
  📅 大约 {birth_year} 年出生
  🍕 喜欢的食物：{food}
  🎨 喜欢的颜色：{color}
  ⚽ 爱好：{hobby}
  🌟 梦想：{dream}
""")
print("=" * 40)

# 第6步：趣味彩蛋
name_length = len(name)
name_reversed = name[::-1]
print(f"🤖：悄悄告诉你一个秘密——")
print(f"🤖：你的名字有 {name_length} 个字")
print(f"🤖：倒过来念是「{name_reversed}」，哈哈！\n")

print(f"🤖：很高兴和你聊天，{name}！")
print("🤖：祝你天天开心，学习进步！👋")
```

### 步骤4：课堂练习——DIY 自己的机器人（15分钟）

**练习1：改造机器人**
在基础版对话机器人的基础上：

**练习2：添加计算功能**
在对话中加一个"数学小挑战"，比如：
```python
a = random.randint(1, 20)
b = random.randint(1, 20)
user_answer = int(input(f"🤖：考你一个！{a} + {b} = ?"))
if user_answer == a + b:
    print("🤖：答对了！你好厉害！")
else:
    print(f"🤖：不对哦，答案是 {a + b}，再练练吧！")
```

**练习3：创意扩展**
