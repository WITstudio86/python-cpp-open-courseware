# 第35节：画圆和弧线

## 🎯 教学目标
- 学生能够使用 `.circle(radius)` 画完整圆形
- 学生能够使用 `.circle(radius, angle)` 画任意弧度的弧线
- 学生能够理解半径（radius）和角度（angle）参数的含义
- 学生能够组合圆形和弧线画出笑脸、雪人等有趣图案

## 📝 重点概念
- **半径（Radius）**：从圆心到圆上任意一点的距离。比如一个半径 50 的圆，直径就是 100。半径越大，圆越大
- **`.circle(radius)`**：让海龟画一个完整的圆。注意海龟"站"在圆的边缘上，而不是圆心。半径是正数时，圆心在海龟的左边；半径是负数时，圆心在海龟的右边
- **`.circle(radius, angle)`**：画一段弧线（圆的一部分）。第二个参数 `angle` 表示画多少度的弧。比如 `t.circle(50, 180)` 就是画一个半径为 50 的半圆
- **弧线**：圆的一部分。180° 是半圆，90° 是四分之一圆，270° 是四分之三圆

上节课我们画了正多边形，当边数越来越多（比如 36 条边），画出来的图形就越来越像一个圆。但每次都写循环来"近似圆"有点麻烦，对不对？

别担心，Python 的海龟早就想到了这一点！Turtle 库提供了一个超级方便的方法——`.circle()`，一行代码就能画出一个完美的圆！还能画出半圆、弯弯的弧线——就像我们画画时用圆规一样方便。

（在黑板上画一个笑脸简笔画，指着笑脸的圆脸、弯弯的眼睛、上扬的嘴巴）

大家看，一个笑脸其实就是一个大圆（脸）+ 两个小圆（眼睛）+ 一段弧线（嘴巴）。今天我们就用 `.circle()` 来一起画一个笑脸，好不好？

**互动**：生活中你还见过哪些东西是圆形的？太阳、车轮、披萨、硬币、篮球……没错，圆形无处不在！

### 步骤2：核心讲解（15-20分钟）

#### 2.1 认识 `.circle()`——海龟的"圆规"

`.circle()` 就像你给海龟一个虚拟的"圆规"，告诉它画多大的圆。

```python
t.circle(50)   # 画一个半径为 50 像素的圆
```

运行这行代码，你会看到海龟画出了一个漂亮的圆形。

**海龟站在哪里？**

一个重要的细节：海龟站在圆的**边缘**上，而不是圆心！想象海龟的嘴巴就是圆的起点，它沿着圆周走一圈回到原点。

**半径的正负号有讲究**：
- `t.circle(50)`：半径为正 → 圆心在海龟的**左边** → 海龟向左转弯画圆
- `t.circle(-50)`：半径为负 → 圆心在海龟的**右边** → 海龟向右转弯画圆

可以让学生试试看，两个圆有什么不同？

#### 2.2 画弧线：`.circle(radius, angle)`

弧线就是"不完整的圆"。`.circle()` 的第二个参数 `angle` 控制画多少度的弧：

```python
t.circle(50, 180)   # 半圆（180度），就像从圆上切了一半下来
t.circle(50, 90)    # 四分之一圆（90度），像一个弯弯的角
t.circle(50, 270)   # 四分之三圆（270度），像一个大大的"C"
t.circle(50, 360)   # 完整圆（360度），和 t.circle(50) 效果一样
```

**生活化比喻**：画弧线就像吃披萨。整个圆是一整个披萨，`angle=180` 就是吃掉了一半（剩半张），`angle=90` 就是吃了四分之三（只剩一角）。只不过海龟是从不吃的那一端开始画！

#### 2.3 半圆的妙用

半圆（angle=180）是最常用的弧线。不同的组合能画出不同的有趣图案：

- 两个半圆一上一下 → "8"字形或蝴蝶结
- 一个半圆在另一个半圆下方 → 一个可爱的"云朵"
- 半圆加上直线 → 一个拱门

#### 2.4 画笑脸的思路

我们来分析一下笑脸的组成部分：

1. **脸**：一个大圆，`t.circle(100)`，半径为 100
2. **左眼**：一个小圆，半径约 15，放在脸的左上方
3. **右眼**：另一个小圆，半径约 15，放在脸的右上方
4. **嘴巴**：一段弧线（半圆或更小的弧度），放在脸的下方

这些部件分散在画布的不同位置，所以我们需要用 `.penup()` 和 `.goto()` 来移动海龟，在各个位置分别画。

### 步骤3：动手演示（10分钟）

**演示1：画一个完整的圆**

```python
import turtle

screen = turtle.Screen()
screen.title("画圆演示")
screen.bgcolor("lightyellow")

t = turtle.Turtle()
t.shape("turtle")
t.pensize(3)
t.color("blue")

# 画一个半径100的圆
t.circle(100)

turtle.done()
```

让学生观察：海龟从圆的底部出发，逆时针画了一圈回到原点。

**演示2：画各种弧线**

在同一张画布上，从左到右依次画不同角度的弧线：

```python
# 半圆（180度）
t.penup()
t.goto(-200, 0)
t.pendown()
t.color("red")
t.circle(50, 180)

# 四分之一圆（90度）
t.penup()
t.goto(-80, 0)
t.pendown()
t.color("green")
t.circle(50, 90)

# 四分之三圆（270度）
t.penup()
t.goto(60, 0)
t.pendown()
t.color("purple")
t.circle(50, 270)
```

让学生观察区别。

**演示3：画一个简单的雪人**

雪人的结构（从上到下）：
- 一个小圆（头）：半径 30
- 一个中圆（身体上部分）：半径 50
- 一个大圆（身体下部分）：半径 70

老师边写代码边画，让学生看到雪人一步步成型。

```python
import turtle

screen = turtle.Screen()
screen.title("雪人")
screen.bgcolor("skyblue")

t = turtle.Turtle()
t.shape("turtle")
t.pensize(3)
t.color("black")
t.speed(5)

# 画雪人底部的大圆
t.penup()
t.goto(0, -140)    # 移到底部圆心的位置
t.pendown()
t.circle(70)        # 半径70，最大的圆

# 画中间的圆
t.penup()
t.goto(0, 0)
t.pendown()
t.circle(50)        # 半径50

# 画头部的小圆
t.penup()
t.goto(0, 100)
t.pendown()
t.circle(30)        # 半径30，最小的圆

t.hideturtle()
turtle.done()
```

## 💻 代码示例

### 示例1：完整笑脸

```python
# -*- coding: utf-8 -*-
"""
第35节：用 circle() 画一个可爱的笑脸
"""

import turtle

# ----- 设置画布 -----
screen = turtle.Screen()
screen.title("可爱的笑脸")
screen.bgcolor("lightyellow")

# ----- 创建海龟 -----
t = turtle.Turtle()
t.shape("turtle")
t.speed(5)

# ===== 1. 画圆脸 =====
t.penup()
t.goto(0, -120)         # 移到画脸的位置
t.pendown()
t.pensize(3)
t.color("black")         # 用黑色画脸的轮廓
t.fillcolor("yellow")    # 用黄色填充
t.begin_fill()           # 开始填充
t.circle(120)            # 画半径120的大圆
t.end_fill()             # 结束填充

# ===== 2. 画左眼 =====
t.penup()
t.goto(-45, 40)          # 移到左眼位置（脸的左上方）
t.pendown()
t.color("black")
t.fillcolor("black")
t.begin_fill()
t.circle(15)             # 画一个小圆作为眼睛
t.end_fill()

# ===== 3. 画右眼 =====
t.penup()
t.goto(45, 40)           # 移到右眼位置（脸的右上方）
t.pendown()
t.begin_fill()
t.circle(15)             # 同样大小的小圆
t.end_fill()

# ===== 4. 画微笑的嘴巴 =====
t.penup()
t.goto(-45, -20)         # 移到嘴巴的起始位置
t.pendown()
t.pensize(4)
t.color("red")
t.setheading(-60)        # 调整海龟朝向，让弧线方向正确
t.circle(50, 120)        # 画一段120度的弧线作为微笑

# ===== 5. 画两个小腮红 =====
t.penup()
t.goto(-75, 10)
t.pendown()
t.color("pink")
t.fillcolor("pink")
t.begin_fill()
t.circle(10)
t.end_fill()

t.penup()
t.goto(75, 10)
t.pendown()
t.begin_fill()
t.circle(10)
t.end_fill()

# ----- 隐藏海龟，完成 -----
t.hideturtle()
turtle.done()
```

### 示例2：可爱的雪人

```python
# -*- coding: utf-8 -*-
"""
用叠起来的圆画一个可爱的雪人
"""

import turtle

screen = turtle.Screen()
screen.title("下雪天的小雪人")
screen.bgcolor("skyblue")   # 天蓝色的背景

t = turtle.Turtle()
t.shape("turtle")
t.pensize(3)
t.speed(5)

# ----- 雪人下半身（最大的圆） -----
t.penup()
t.goto(0, -150)
t.pendown()
t.color("black")
t.fillcolor("white")
t.begin_fill()
t.circle(80)       # 半径80的圆
t.end_fill()

# ----- 雪人上半身（中等的圆） -----
t.penup()
t.goto(0, 10)
t.pendown()
t.begin_fill()
t.circle(60)       # 半径60的圆
t.end_fill()

# ----- 雪人的头（最小的圆） -----
t.penup()
t.goto(0, 130)
t.pendown()
t.begin_fill()
t.circle(40)       # 半径40的圆
t.end_fill()

# ----- 两只眼睛（小黑点） -----
t.color("black")
t.fillcolor("black")

# 左眼
t.penup()
t.goto(-15, 175)
t.pendown()
t.begin_fill()
t.circle(5)
t.end_fill()

# 右眼
t.penup()
t.goto(15, 175)
t.pendown()
t.begin_fill()
t.circle(5)
t.end_fill()

# ----- 鼻子（胡萝卜色的小三角形） -----
t.penup()
t.goto(0, 165)
t.pendown()
t.color("orange")
t.fillcolor("orange")
t.begin_fill()
t.setheading(0)         # 面朝右边
t.forward(25)
t.left(120)
t.forward(10)
t.left(120)
t.forward(25)
t.end_fill()

# ----- 围巾（红色线条） -----
t.penup()
t.goto(-55, 105)
t.pendown()
t.pensize(8)
t.color("red")
t.setheading(0)
t.forward(110)     # 横线

# 围巾垂下来的部分
t.penup()
t.goto(55, 105)
t.pendown()
t.setheading(-60)
t.forward(50)

# ----- 完成，隐藏海龟 -----
t.hideturtle()
turtle.done()
```

### 示例3：彩虹弧线

```python
# -*- coding: utf-8 -*-
"""
用不同颜色的弧线画一道彩虹
"""

import turtle

screen = turtle.Screen()
screen.title("彩虹")
screen.bgcolor("lightcyan")

t = turtle.Turtle()
t.shape("turtle")
t.pensize(12)    # 粗画笔，让彩虹更显眼
t.speed(8)

# 彩虹的七种颜色
rainbow_colors = ["red", "orange", "yellow", "green", 
                  "blue", "indigo", "purple"]

# 从外到内画7条半圆弧线
# 最外面的弧线半径最大，往内依次减小
for i, color in enumerate(rainbow_colors):
    t.penup()
    t.goto(0, -200 + i * 15)   # 每条弧线起点往下移一点
    t.pendown()
    t.color(color)
    t.setheading(-90)           # 面朝下方
    t.circle(200 - i * 20, 180) # 画半圆，半径递减

t.hideturtle()
turtle.done()
```

## 📋 小结

### 本节学了什么
- **`.circle(radius)`**：一行代码画完整圆形，radius 越大圆越大
- **`.circle(radius, angle)`**：画弧线，angle 控制弧度大小（180° 是半圆，90° 是四分之一圆）
- **半径正负**：正数圆心在左，负数圆心在右
- **组合创作**：用圆和弧线可以组合出笑脸、雪人、彩虹等有趣图案
- **`.fillcolor()`、`.begin_fill()`、`.end_fill()`**：给封闭图形填充颜色
