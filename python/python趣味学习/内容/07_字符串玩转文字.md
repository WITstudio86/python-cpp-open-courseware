# 第7节：字符串 —— 玩转文字

## 教学目标
- 学生能够理解字符串的概念，知道三种引号的用法
- 学生能够使用 len() 获取字符串长度
- 学生能够使用索引 [数字] 获取字符串中的单个字符
- 学生能够使用切片 [开始:结束] 截取字符串的一部分
- 学生能够理解"从0开始计数"这一编程惯例

## 重点概念
- **字符串（string）**：一串字符的序列。用引号括起来的任何内容都是字符串。例如 "Hello"、'你好'、"123"（注意：引号里的数字也是字符串！）
- **引号三种写法**：单引号 '...'、双引号 "..."、三引号 '''...''' 或 """..."""（三引号可以跨多行）
- **len()**：获取字符串中有多少个字符（空格和标点也算！）
- **索引（index）**：字符串中每个字符都有一个"座位号"。Python 从 0 开始数，所以第一个字符的索引是 0
- **切片（slice）**：从字符串中切出一段。写法：`字符串[开始索引:结束索引]`，注意包含开始，不包含结束

### 步骤2：核心讲解——字符串的三种本领（20分钟）

#### 2.1 什么是字符串？

字符串就是"一串字符"。任何用引号括起来的东西都是字符串：

```python
a = "Hello"          # 双引号
b = 'Python'         # 单引号
c = "123"            # 引号里的数字 = 字符串
d = "你好，世界！"    # 中文也行
e = "!@#$%^&*"       # 符号也行

print(type(a))       # <class 'str'> —— 都是 str 类型！
print(type(c))       # <class 'str'> —— "123" 是字符串，123 才是数字
```

**什么时候用哪种引号？**
```python
# 如果文字里有单引号，外面用双引号
print("I'm a student")       # 正确

# 如果文字里有双引号，外面用单引号
print('他说："你好"')         # 正确

# 如果要写很多行，用三引号
print('''静夜思
床前明月光
疑是地上霜''')
```

#### 2.2 len() —— 数数有几个字

```python
print(len("Hello"))          # 5
print(len("你好世界"))        # 4
print(len("Python 真好玩"))   # 11（空格也算！）
print(len(""))               # 0（空字符串）
```

**互动：** 让学生输入自己的名字，用 len() 看有几个字！

#### 2.3 索引 —— 每个字都有座位号

**重要规则：Python 从 0 开始数！**

```
字符串：  P  y  t  h  o  n
索引：   0  1  2  3  4  5
倒着数： -6 -5 -4 -3 -2 -1
```

```python
word = "Python"
print(word[0])     # P（第1个字符）
print(word[1])     # y（第2个字符）
print(word[5])     # n（最后1个字符）
print(word[-1])    # n（倒数第1个，最方便！）
print(word[-2])    # o（倒数第2个）
```

**常见错误：**
```python
word = "Python"
print(word[6])     # 错误！索引最大是 5（长度-1）
# IndexError: string index out of range
```

**为什么从0开始？**
这是一个编程界的"老传统"，几乎所有编程语言都这样！可以理解为：索引是你离起点的距离，第1个字离起点距离为0。

#### 2.4 切片 —— 切出一段文字

**语法：** `字符串[开始位置:结束位置]`
**规则：** 包含开始位置，**不包含**结束位置！

```python
word = "Python"
print(word[0:3])     # "Pyt" —— 取索引 0,1,2（不含索引3）
print(word[1:4])     # "yth" —— 取索引 1,2,3
print(word[2:5])     # "hon" —— 取索引 2,3,4
```

**记忆口诀：** `[开始:结束]` → 从"开始"拿，拿到"结束"之前停。

**省略写法（超实用！）：**
```python
word = "Python"
print(word[:3])      # "Pyt" —— 省略开始 = 从0开始
print(word[3:])      # "hon" —— 省略结束 = 取到末尾
print(word[:])       # "Python" —— 全部都取
print(word[::-1])    # "nohtyP" —— 倒过来！（步长为-1）
```

**步长切片：**
```python
word = "Python"
print(word[::2])     # "Pto" —— 每隔2个取一个
print(word[::3])     # "Ph" —— 每隔3个取一个
print(word[::-1])    # "nohtyP" —— 倒序！
print(word[::-2])    # "nhy" —— 倒序，每隔2个
```

### 步骤3：动手演示——文字魔法师（15分钟）

**演示1：提取姓名**
```python
full_name = "欧阳小明"
```

```python
if name == name[::-1]:
    print("哇！你的名字是回文！")
else:
    print("你的名字不是回文")
```

**演示3：隐藏手机号中间4位**


**演示4：截取古诗**

### 步骤5：总结（5分钟）

1. 字符串 = 一串字符，用引号括起来
2. len() = 数字符个数
3. 索引从 0 开始，`[n]` 取第 n+1 个字符
4. `[开始:结束]` 切一段，不含结束
5. `[::-1]` 可以倒过来！

## 代码示例

```python
# ===== 第7节：字符串 —— 玩转文字 =====

# ---------- 1. 创建字符串 ----------
s1 = "Hello"                    # 双引号
s2 = 'Python'                   # 单引号
s3 = "123"                      # 引号里的数字是字符串！
s4 = "你好，世界！"              # 中文
print("s1:", s1, "→ 类型:", type(s1))
print("s3:", s3, "→ 类型:", type(s3))
print("123（数字）→ 类型:", type(123))
print("注意："123"（引号里）和 123（无引号）类型不一样！")

# ---------- 2. len() —— 数字符个数 ----------
print("\n--- len() 数字符个数 ---")
print('"Hello" 有', len("Hello"), "个字符")
print('"你好世界" 有', len("你好世界"), "个字符")
print('"Python 真好玩" 有', len("Python 真好玩"), "个字符")
print('空格也算字符哦！')

name = input("\n你叫什么名字？ ")
print("你的名字有", len(name), "个字")

# ---------- 3. 索引 —— 每个字的座位号 ----------
print("\n--- 索引（从0开始！）---")
word = "Python"
print("字符串:", word)
print("索引 0:", word[0])       # P
print("索引 1:", word[1])       # y
print("索引 5:", word[5])       # n
print("索引 -1:", word[-1])     # n（倒数第一个）
print("索引 -2:", word[-2])     # o（倒数第二个）

# ---------- 4. 切片 —— 切出一段文字 ----------
print("\n--- 切片 [开始:结束] ---")
sentence = "我爱Python编程"
print("原文:", sentence)
print("[0:2] →", sentence[0:2])     # 我爱
print("[2:8] →", sentence[2:8])     # Python
print("[8:]  →", sentence[8:])      # 编程
print("[:2]  →", sentence[:2])      # 我爱
print("[::-1]→", sentence[::-1])    # 倒过来！

# ---------- 5. 步长切片 ----------
print("\n--- 步长切片 ---")
word = "Python"
print("每隔2个取一个:", word[::2])    # Pto
print("每隔3个取一个:", word[::3])    # Ph
print("倒序:", word[::-1])            # nohtyP
print("倒序每隔2个:", word[::-2])     # nhy

# ---------- 6. 趣味应用 ----------
print("\n--- 趣味应用 ---")

# 名字倒过来
name = "张三"
print(name, "倒过来是:", name[::-1])

# 提取姓和名
full_name = "欧阳小明"
surname = full_name[:2]       # 姓
given_name = full_name[2:]    # 名
print(full_name, "→ 姓:", surname, "名:", given_name)

# 隐藏手机号
phone = "13812345678"
hidden = phone[:3] + "****" + phone[7:]
print("手机号:", hidden)

# 截取古诗
poem = "床前明月光疑是地上霜"
print(poem) 
print("第一句:", poem[:5])
print("第二句:", poem[5:])
```

## 小结
- **本节学了什么**：
  - 字符串是引号里的文字，有单引号、双引号、三引号三种写法
  - len() 可以数字符个数，空格也算
  - 索引从 0 开始，用 [] 取单个字符
  - 切片 [开始:结束] 切一段，含开始不含结束
  - [::-1] 就可以反转字符串
  - 负数索引从右边开始数（-1是最后一个）
