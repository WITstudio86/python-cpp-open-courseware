## 📝 重点概念
- **random.randint(a, b)**：生成一个 a 到 b 之间（包含两端）的随机整数
- **import**：导入模块。`import random` 就是告诉 Python 我们要用随机数功能
- **and（与）**：两个条件都成立才为 True。比如 `score > 0 and score < 100`
- **or（或）**：两个条件只要有一个成立就为 True。比如 `answer == "y" or answer == "yes"`
- **not（非）**：取反。True 变 False，False 变 True。比如 `not is_pass`

### 步骤2：核心讲解（15-20分钟）

**1. 回顾条件判断（5分钟）**

快速回顾：
- if：判断一个条件
- if-else：二选一
- if-elif-else：多选一

**2. 随机数模块（5分钟）**

```python
import random  # 导入随机数模块

# 生成 1 到 100 之间的随机整数
secret = random.randint(1, 100)
print(secret)  # 每次运行结果可能不同
```

**3. 猜数字游戏核心逻辑（8分钟）**

```python
import random

# 1. 生成随机数
secret = random.randint(1, 100)

# 2. 让玩家猜
guess = int(input("请猜一个 1-100 之间的数字："))

# 3. 判断大小
if guess > secret:
    print("猜大了！")
elif guess < secret:
    print("猜小了！")
else:
    print("猜对了！")
```

**4. 轻量介绍 and/or/not（2分钟）**

```python
# and：两个条件都要成立
age = 12
print(age > 6 and age < 18)  # True（12岁在6-18之间）

# or：只要一个条件成立就行
day = "周六"
print(day == "周六" or day == "周日")  # True（是周末）

# not：取反
is_raining = False
print(not is_raining)  # True（没下雨）
```

### 步骤3：动手演示（10分钟）

逐步完善猜数字游戏，加入：

## 💻 代码示例

```python
import random

# 生成随机数
secret = random.randint(1, 100)
count = 0  # 记录猜的次数

print("=" * 40)
print("🎮 猜数字游戏")
print("电脑想好了一个 1-100 的数字，来猜吧！")
print("=" * 40)

while True:
    guess = int(input("请输入你猜的数字："))
    count += 1  # 次数+1

    # 判断输入是否合法
    if guess < 1 or guess > 100:
        print("请猜 1 到 100 之间的数字哦~")
        continue

    # 判断大小
    if guess > secret:
        print("📈 猜大了！再试试~")
    elif guess < secret:
        print("📉 猜小了！再试试~")
    else:
        print(f"🎉 猜对了！就是 {secret}！")
        print(f"你一共猜了 {count} 次！")
        if count <= 3:
            print("天才！这么快就猜中了！")
        elif count <= 7:
            print("不错哦，表现很好！")
        else:
            print("终于猜中了，下次加油！")
        break
```
