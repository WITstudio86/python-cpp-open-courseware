# 第28节：函数是什么？为什么要用函数？

## 🎯 教学目标
- 学生能够理解函数是"打包好的、可重复使用的代码块"
- 学生能够识别已经学过的内置函数：print()、input()、len()、max() 等
- 学生能够理解"不重复写代码"的价值（DRY 原则的直观理解）
- 学生能够用生活类比解释函数的概念

## 📝 重点概念
- **函数**：一段有名字的代码，可以反复使用，就像一台"榨汁机"
- **内置函数**：Python 自带的函数，如 print()、input()、len()
- **为什么用函数**：避免重复、便于修改、代码更清晰

### 步骤2：核心讲解（15-20分钟）

#### 2.1 为什么需要函数？—— 没有函数的痛苦

假设我们要多次打印一条分隔线：

```python
# 没有函数：每次都要写重复的代码
print("=" * 30)
print("第一部分")
print("=" * 30)

print("=" * 30)   # 重复了！
print("第二部分")
print("=" * 30)   # 又重复了！

print("=" * 30)   # 又又重复了！
print("第三部分")
print("=" * 30)   # 又又又重复了！
```

**问题**：
- 写了 6 遍 `print("=" * 30)`！
- 如果想把 `=` 改成 `-`，要改 6 个地方！

#### 2.2 有函数的优雅写法

```python
def print_line():
    """打印一条分隔线"""
    print("=" * 30)

# 使用函数——只需要一行！
print_line()
print("第一部分")
print_line()

print_line()
print("第二部分")
print_line()

print_line()
print("第三部分")
print_line()
```

**好处**：
- 只写了一行 `print_line()` 就完成分隔线
- 如果想把 `=` 改成 `-`，只需要改函数定义里的一个地方！
- 代码更清晰，别人一看就知道你在打印分隔线

#### 2.3 函数的三个关键部分

```
def 函数名():
    函数体（要执行的代码）
```

| 部分 | 说明 | 例子 |
|------|------|------|
| `def` | 关键字，告诉 Python "我要定义函数了" | `def` |
| 函数名 | 自己起的名字，跟变量命名规则一样 | `print_line` |
| `():` | 括号和冒号，必须有 | `():` |
| 函数体 | 缩进的代码，函数要做什么 | `print("=" * 30)` |

#### 2.4 现实生活中的函数类比

| 生活事物 | 输入 | 处理 | 输出 |
|----------|------|------|------|
| 榨汁机 | 水果 | 榨汁 | 果汁 |
| 微波炉 | 食物 + 时间 | 加热 | 热食物 |
| 自动售货机 | 钱 + 选择 | 出货 | 饮料 |
| 数学函数 f(x) = x * 2 | x | 乘 2 | 结果 |

"函数就是 Python 世界里的机器——给它输入，它给你输出。"

### 步骤3：动手演示（10分钟）

```python
# 我们来定义和使用第一个函数

def say_hello():
    """打招呼的函数"""
    print("你好呀！")
    print("欢迎来到 Python 的世界！")
    print("=" * 20)

# 调用函数
say_hello()
say_hello()  # 可以多次调用！
say_hello()  # 用几次都行

# 体验：修改一处，所有地方都变了
# 如果把 print("你好呀！") 改成 print("Hello!")
# 三个 say_hello() 的输出都会变！
```

**课堂互动**：让学生想一想，生活中还有哪些"函数"？（ATM 机、洗衣机、电饭煲...）

## 💻 代码示例

```python
# ========== 第28节：函数是什么？为什么要用函数？ ==========

# --- 1. 复习我们已经用过的内置函数 ---
print("\n=== Python 内置函数（老朋友！） ===")

# print() —— 显示信息
print("这行是用 print() 显示的")

# input() —— 获取用户输入
# name = input("你叫什么名字？")  # 运行时会等待输入
# print("你好，", name)

# len() —— 计算长度
fruits = ["苹果", "香蕉", "橘子"]
print(f"列表 fruits 有 {len(fruits)} 个元素")

# max() / min() / sum() —— 数值计算
scores = [85, 92, 78, 95]
print(f"最高分: {max(scores)}")
print(f"最低分: {min(scores)}")
print(f"总分: {sum(scores)}")

# type() —— 查看数据类型
print(f"fruits 的类型: {type(fruits)}")
print(f"scores 的类型: {type(scores)}")

# --- 2. 没有函数的痛苦 ---
print("\n=== 没有函数：重复代码 ===")

# 场景：打印一张成绩单的标题
print("=" * 30)
print("   语文成绩单")
print("=" * 30)
print("小明: 95 分")
print("小红: 88 分")
print("=" * 30)

print("=" * 30)  # 每次都要重复写
print("   数学成绩单")
print("=" * 30)
print("小明: 92 分")
print("小红: 90 分")
print("=" * 30)

# --- 3. 有函数的优雅写法 ---
print("\n=== 有函数：优雅简洁 ===")

def print_separator():
    """打印分隔线的函数"""
    print("=" * 30)

def print_title(title):
    """打印标题的函数"""
    print_separator()
    print(f"   {title}")
    print_separator()

# 看！简洁多了
print_title("语文成绩单")
print("小明: 95 分")
print("小红: 88 分")
print_separator()

print_title("数学成绩单")
print("小明: 92 分")
print("小红: 90 分")
print_separator()

# --- 4. 函数的类比 ---
print("\n=== 函数就像... ===")
print("🍹 榨汁机：丢水果进去 → 果汁出来")
print("🔥 微波炉：放食物进去 → 热菜出来")
print("🖨️ 打印机：给文件 → 打印出来的纸")
print("📏 len()：  给列表 → 列表的长度")
print("🖥️ print()：给文字 → 显示在屏幕上")

# --- 5. 练习：发现重复，创建函数 ---
print("\n=== 练习：找出重复代码 ===")

# 下面这段代码有大量重复，你能找到吗？
def greet():
    """简单问候函数"""
    print("-" * 20)
    print("欢迎使用本程序！")
    print("-" * 20)

greet()
print("这是程序的主体部分...")
greet()
print("程序即将结束...")
greet()
print("感谢使用，再见！")

# 思考：如果想把 "-" * 20 改成 "~" * 30，需要改几个地方？
# 答：只需要改 greet() 函数里的一行！
```
