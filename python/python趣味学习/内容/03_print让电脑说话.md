# 第3节：print() —— 让电脑说话

## 教学目标
- 学生能够熟练使用 print() 输出文字、数字和算式结果
- 学生能够理解 print() 的 sep 和 end 参数的基本用法
- 学生能够用 \n 换行符控制输出格式
- 学生能够用 print() 绘制简单的字符图案

## 重点概念
- **print() 函数**：Python 中最常用的输出函数。括号里写什么，电脑屏幕上就显示什么。可以理解为"让电脑说话"的按钮
- **字符串**：用引号（单引号或双引号）括起来的文字内容，比如 `"你好"`。Python 把字符串当作"文字"来处理
- **参数**：函数括号里传入的东西。print() 可以接收多个参数，用逗号隔开
- **\n（换行符）**：一个特殊的字符，代表"换行"的意思。反斜杠 + n，就像按了一次回车键
- **sep（分隔符）**：多个输出内容之间的分隔符号，默认是空格
- **end（结尾符）**：print() 输出完后的结尾符号，默认是换行

### 步骤2：核心讲解——print() 的四大本领（20分钟）

#### 本领一：输出文字（字符串）

```python
print("你好，世界！")        # 双引号
print('Python真好玩！')      # 单引号也可以
print("我今年10岁了")        # 中文也没问题
print("I love Python!")     # 英文也可以
```

**关键规则：**
- 文字必须用引号包起来（单引号或双引号都行）
- 不加引号的话，Python 会以为是变量名
- 中文、英文、数字、符号都可以放在引号里

**常见错误示范：**
```python
print(你好)    # 错误！Python 以为"你好"是变量名
print("你好")  # 正确！用引号包起来就变成文字了
```

#### 本领二：输出数字和算式

```python
print(100)          # 直接输出数字
print(100 + 200)    # 输出计算结果：300
print(3.14 * 10)    # 输出计算结果：31.4
```

**这说明什么？** Python 不只是个"复读机"，它还能真的**算出来**！你写一个算式在 print() 里面，Python 会先算好结果再显示。

**让学生惊叹的时刻：**
```python
print(2 ** 100)     # 2的100次方 —— 超大数字立刻出结果！
```

#### 本领三：一次输出多个东西（用逗号分隔）

```python
name = "小明"
age = 10
print("我叫", name, "，今年", age, "岁")
# 输出：我叫 小明 ，今年 10 岁
```

**逗号的作用：**
- 每两个内容之间用逗号隔开
- 屏幕上会自动在中间加一个空格
- 可以混搭文字、数字、变量

**sep 参数——自定义分隔符：**
```python
print("苹果", "香蕉", "橘子", sep="、")
# 输出：苹果、香蕉、橘子

print("2024", "01", "15", sep="-")
# 输出：2024-01-15
```

默认 sep=" "（空格），你可以改成任何符号！

#### 本领四：控制换行

**\n —— 在字符串中换行：**
```python
print("第一行\n第二行\n第三行")
# 输出：
# 第一行
# 第二行
# 第三行
```

**end 参数——改变结尾：**
print() 每次输出后默认会换行。如果你不想换行，可以用 end 参数：

```python
print("加载中", end="")
print(".", end="")
print(".", end="")
print(".")  
# 输出：加载中...
```

```python
print("星星", end="★")
print("月亮")
# 输出：星星★月亮
```

### 步骤5：总结与答疑（10分钟）

回顾本节内容：

**常见坑点提醒：**

## 代码示例

```python
# ===== 第3节：print() 的各种用法 =====

# ---------- 本领一：输出文字 ----------
print("你好，Python 世界！")
print('单引号也可以哦')
print("中文、English、123，什么都行！")

# ---------- 本领二：输出数字和算式 ----------
print(100)              # 直接输出数字
print(100 + 200)        # 电脑帮你算！输出 300
print(50 - 30)          # 减法
print(8 * 7)            # 乘法（注意：用 * 不是 ×）
print(100 / 5)          # 除法
print(2 ** 10)          # 2的10次方 = 1024

# ---------- 本领三：一次输出多个 ----------
name = "小明"
age = 10
print("我叫", name, "，今年", age, "岁")
# 逗号 = 空格分隔

# sep 参数 —— 自定义分隔符
print("苹果", "香蕉", "橘子", sep=" | ")

# end 参数 —— 自定义结尾（默认是换行）
print("第一句", end=" → ")
print("第二句", end=" → ")
print("第三句")

# ---------- 本领四：换行 ----------
print("第一行\n第二行\n第三行")
print("---分割线---")
print("窗前明月光\n疑是地上霜\n举头望明月\n低头思故乡")

# ===== 字符画创作 =====

print("\n===== 三角形 =====")
print("    *")
print("   ***")
print("  *****")
print(" *******")
print("*********")

print("\n===== 笑脸 =====")
print("  *****  ")
print(" *     * ")
print("*  O O  *")
print("*   ^   *")
print("* \___/ *")
print(" *     * ")
print("  *****  ")

print("\n===== 圣诞树 =====")
print("    ★")
print("   ***")
print("  *****")
print(" *******")

```
