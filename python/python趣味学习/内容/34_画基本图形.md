# 第34节：画基本图形

## 🎯 教学目标
- 学生能够理解"外角"的概念，掌握正多边形角度公式：外角 = 360 ÷ 边数
- 学生能够使用 for 循环简化重复代码，画出正方形、三角形、五边形、六边形
- 学生能够用变量控制边长，灵活改变图形大小
- 学生能够独立画出一个正三角形和一个正六边形

## 📝 重点概念
- **正多边形**：每条边一样长、每个角一样大的图形。比如正方形、正三角形（等边三角形）、正五边形、正六边形
- **外角**：海龟在画正多边形时，每画完一条边需要"转弯"的那个角度。想象你自己沿着正多边形的边走路——每走到一个顶点，你需要转身多少度才能继续沿着下一条边走？那个转身的角度就是外角
- **外角公式**：外角 = 360 ÷ 边数。因为转完一整圈是 360 度，走完所有边刚好转一圈（走回原来的方向），所以每条边转的角度就是 360 平均分给每条边
- **for 循环**：让一段代码重复执行指定的次数。比如 `for i in range(4):` 表示"把下面的代码重复做 4 遍"

### 步骤2：核心讲解（15-20分钟）

#### 2.1 循环魔法：for 循环

上节课我们画正方形写的是：

```python
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
t.forward(100)
t.right(90)
```

大家发现没有，`t.forward(100)` 和 `t.right(90)` 这两行重复了 4 次！在编程中，有一条非常重要的原则叫 **DRY**——Don't Repeat Yourself（不要重复自己）。如果一段代码要重复多次，我们就用**循环**来解决。

Python 中的 `for` 循环就像一个"复读机"：

```python
for i in range(4):     # "把下面的事情做4遍"
    t.forward(100)      # 每遍做：往前走100
    t.right(90)         # 然后右转90度
```

**生动的比喻**：`for` 循环像是一个跑步比赛的计数器。`range(4)` 就像裁判说"预备，跑！一共跑 4 圈"。变量 `i` 代表"当前是第几圈"，从 0 开始。所以 `i` 的值依次是 0、1、2、3，一共 4 次。

用循环改写后，画正方形的代码从 8 行变成 3 行，是不是清爽多了？

#### 2.2 角度公式：外角 = 360 ÷ 边数

这是本节课最重要的"秘密公式"！

想象你自己是一个小人，站在一个正多边形的边上往前走。每当走到一个顶点（拐角），你需要转身才能继续沿着下一条边走。这个"转身的角度"，就是**外角**。

（在黑板上画图演示：画一个正方形，标出小人转身的路径，让大家看到每次右转 90 度）

关键来了：**不管正多边形有几条边，你走完一整圈回到原点，总共转了 360 度**。

所以：**外角 = 360 ÷ 边数**

| 图形 | 边数 | 外角 | 计算过程 |
|------|------|------|----------|
| 正三角形 | 3 | 120° | 360 ÷ 3 = 120 |
| 正方形 | 4 | 90° | 360 ÷ 4 = 90 |
| 正五边形 | 5 | 72° | 360 ÷ 5 = 72 |
| 正六边形 | 6 | 60° | 360 ÷ 6 = 60 |
| 正八边形 | 8 | 45° | 360 ÷ 8 = 45 |
| 正十二边形 | 12 | 30° | 360 ÷ 12 = 30 |

**互动**：如果我让你画正十边形，外角是多少？（让学生回答：360 ÷ 10 = 36°）

#### 2.3 结合循环和角度公式

现在我们有了两个超级工具，画任何正多边形都变得超简单：

```python
边数 = 6          # 想画什么多边形？改这个数字就行
边长 = 100
外角 = 360 / 边数  # 自动算出外角

for i in range(边数):    # 循环"边数"次
    t.forward(边长)       # 画一条边
    t.right(外角)         # 转外角度数
```

这就是"通用多边形公式"！你只需改 `边数` 这个变量，就能画出任何正多边形：
- `边数 = 3` → 正三角形
- `边数 = 4` → 正方形
- `边数 = 5` → 正五边形
- `边数 = 6` → 正六边形
- `边数 = 100` → 近似圆形（因为边数越多，越接近圆）

### 步骤3：动手演示（10分钟）

老师依次演示以下图形，让学生观察不同边数对应的外角变化：

**演示1：正三角形**
```python
import turtle

screen = turtle.Screen()
screen.title("正三角形")
screen.bgcolor("lightyellow")

t = turtle.Turtle()
t.shape("turtle")
t.pensize(3)
t.color("red")

# 画正三角形：3条边，外角=360÷3=120°
sides = 3
length = 150
angle = 360 / sides

for i in range(sides):
    t.forward(length)
    t.right(angle)

turtle.done()
```

**关键观察**：画三角形时，海龟转了 120 度！这个角度比较大，是"钝角"（大于 90 度）。很多同学可能会以为三角形要转 60 度（因为三角形的内角是 60 度），但记住——海龟转的是**外角**，不是内角！

**演示2：正六边形**
```python
# 只需把 sides 改成 6
sides = 6
length = 80
angle = 360 / sides  # 360/6 = 60度

for i in range(sides):
    t.forward(length)
    t.right(angle)
```

让学生观察：六边形的外角（60°）比正方形的外角（90°）更小，所以六边形的拐弯"更缓和"。

**演示3：正三十六边形（近似圆形）**
```python
sides = 36
length = 20
angle = 360 / sides  # 360/36 = 10度，每次只转一点点！

for i in range(sides):
    t.forward(length)
    t.right(angle)
```

画出来几乎就是一个圆！让学生直观感受：边数越多 → 外角越小 → 图形越接近圆。

## 💻 代码示例

### 示例1：用循环画多个不同多边形

```python
# -*- coding: utf-8 -*-
"""
第34节：用循环和角度公式画各种正多边形
在一个画布上展示三角形、正方形、五边形、六边形
"""

import turtle

# ----- 画布设置 -----
screen = turtle.Screen()
screen.title("正多边形大集合")
screen.bgcolor("lightyellow")

# ----- 海龟设置 -----
t = turtle.Turtle()
t.shape("turtle")
t.pensize(3)
t.speed(5)  # 速度适中，既不太快也不太慢

# ----- 定义一个"画正多边形"的函数 -----
def draw_polygon(sides, length, color_name):
    """画一个正多边形
    参数：
        sides: 边数
        length: 边长
        color_name: 颜色名称（字符串）
    """
    t.color(color_name)         # 设置颜色
    angle = 360 / sides          # 计算外角
    
    # 写一个标签，说明这是什么图形
    t.penup()
    t.write(f"{sides}边形", font=("Arial", 12, "bold"))
    t.pendown()
    
    # 用循环画多边形
    for i in range(sides):
        t.forward(length)
        t.right(angle)

# ----- 从左到右画四个多边形 -----

# 1. 正三角形（最左边）
t.penup()
t.goto(-300, 0)     # 移到左边
t.pendown()
draw_polygon(3, 100, "red")

# 2. 正方形
t.penup()
t.goto(-130, 0)
t.pendown()
draw_polygon(4, 100, "blue")

# 3. 正五边形
t.penup()
t.goto(40, 0)
t.pendown()
draw_polygon(5, 80, "green")

# 4. 正六边形（最右边）
t.penup()
t.goto(200, 0)
t.pendown()
draw_polygon(6, 70, "purple")

# ----- 隐藏海龟，更好看 -----
t.hideturtle()

turtle.done()
```

### 示例2：从三角形到十二边形，一次性展示

```python
# -*- coding: utf-8 -*-
"""
画一排多边形：从三角形到十二边形
观察边数越多，图形越接近圆形
"""

import turtle

screen = turtle.Screen()
screen.title("从三角形到十二边形")
screen.bgcolor("lightcyan")

t = turtle.Turtle()
t.shape("turtle")
t.pensize(2)
t.speed(8)

# 颜色列表：每种多边形用一种颜色
colors = ["red", "orange", "gold", "green", 
          "blue", "purple", "hotpink", "brown", 
          "teal", "navy"]

# 从三角形（3条边）到十二边形（12条边）
for sides in range(3, 13):  # 3, 4, 5, ..., 12
    color_index = sides - 3   # 颜色索引从0开始
    t.color(colors[color_index])
    
    angle = 360 / sides       # 计算外角
    length = 50               # 统一边长50
    
    print(f"正在画{sides}边形，外角={angle}°")
    
    # 画当前多边形
    for i in range(sides):
        t.forward(length)
        t.right(angle)
    
    # 移动到下一个位置（往右移110像素）
    t.penup()
    t.forward(110)
    t.pendown()

t.hideturtle()
turtle.done()
```

### 示例3：画一个"俄罗斯方块"（由正方形和长方形组成）

```python
# -*- coding: utf-8 -*-
"""
用正方形和长方形组合，画一个"俄罗斯方块"的 T 形
"""

import turtle

screen = turtle.Screen()
screen.title("俄罗斯方块 - T形")
screen.bgcolor("black")  # 黑色背景，像游戏机屏幕

t = turtle.Turtle()
t.shape("turtle")
t.pensize(4)
t.color("cyan")   # 亮青色，在黑底上很明显
t.speed(3)

# 定义一个画正方形的函数
def square(size):
    for i in range(4):
        t.forward(size)
        t.right(90)

# 画 T 形俄罗斯方块
# T 形由 4 个小正方形组成：上面一排 3 个，中间下面 1 个
box_size = 40  # 每个小方块的边长

# 第一行：画3个正方形
for j in range(3):
    square(box_size)
    t.forward(box_size)  # 移到下一个方块的位置

# 回到中间位置画"T"的腿
t.penup()
t.goto(t.xcor() - 2 * box_size, t.ycor() - box_size)
t.pendown()
square(box_size)

t.hideturtle()
turtle.done()
```

## 📋 小结

### 本节学了什么
- **for 循环**：让代码重复执行 n 次，`for i in range(n):` 就是"做 n 遍"
- **外角公式**：外角 = 360 ÷ 边数，这是画正多边形的核心秘密
- **通用多边形代码**：只需改 `sides` 变量，就能画出任何正多边形
- **边数与外角的关系**：边数越多 → 外角越小 → 图形越接近圆形
- **代码 DRY 原则**：Don't Repeat Yourself，能用循环就不要手写重复代码
