# 第31节：返回值 —— 函数给你的结果

## 🎯 教学目标
- 学生能够理解 `return` 关键字的作用
- 学生能够区分有返回值和没有返回值的函数
- 学生能够用变量接收函数的返回值
- 学生能够编写带有 return 的实用函数

## 📝 重点概念
- **return**：函数把计算结果"交回来"给调用者
- **有返回值 vs 无返回值**：print 是显示出来，return 是把值给回来
- **接收返回值**：用变量接住函数的返回结果
- **return 终止函数**：return 后面的代码不会执行

## 📖 讲解内容

### 步骤1：引入（5分钟）

**类比：自动售货机**。

"上次我们说函数像榨汁机。今天升级到自动售货机。"

```
你投币 → 售货机处理 → 饮料掉出来
  输入      处理        输出（返回值！）
```

"你投了钱，售货机不只是'呼噜呼噜响一阵'，而是**把饮料给你**。这个'饮料'就是函数的**返回值**。"

**区分两种情况**：
```python
# 只做事，不返回（像电风扇——吹完就完了）
print("你好")       # 在屏幕上显示了，但没东西给你

# 做完事，返回结果（像自动售货机——给你一瓶饮料）
name = input("你叫什么？")  # 等着你输入，然后把你输入的内容给你
length = len([1, 2, 3])     # 算好长度，把数字 3 给你
```

### 步骤2：核心讲解（15-20分钟）

#### 2.1 认识 return

```python
def add(a, b):
    result = a + b
    return result  # 把结果"交回去"

# 用变量接收返回值
answer = add(3, 5)
print(answer)  # 8

# 也可以直接使用
print(add(10, 20))  # 30
```

**没有 return 的函数**：

```python
def add_and_print(a, b):
    print(a + b)  # 只是显示，没返回

result = add_and_print(3, 5)  # 屏幕显示 8
print(result)  # None —— 没有返回值！
```

#### 2.2 return 和 print 的区别（关键！）

这是学生最容易混淆的概念，需要反复强调。

```python
# print：在屏幕上显示（给"人"看的）
def show_score(name, score):
    print(f"{name}的成绩是{score}分")

# return：把值交回来（给"程序"用的）
def calculate_average(scores):
    total = sum(scores)
    avg = total / len(scores)
    return avg  # 返回给调用者

# 使用对比
show_score("小明", 95)  # 屏幕显示：小明的成绩是95分
# 但不能用这个结果做进一步计算！

avg_score = calculate_average([90, 85, 95, 88])
print(f"平均分是{avg_score}")
# 可以用 avg_score 继续做其他计算！
```

**什么时候用 print，什么时候用 return？**

| 场景 | 用什么 | 原因 |
|------|--------|------|
| 只需要显示给用户看 | print | 不需要结果 |
| 需要把结果用于后续计算 | return | 结果要给程序用 |
| 需要根据结果做判断 | return | if 判断需要值 |
| 调试时查看中间结果 | print | 临时查看 |

#### 2.3 return 会终止函数

```python
def check_age(age):
    if age < 0:
        return "年龄不能是负数！"  # 到这里就结束了
    if age < 18:
        return "未成年"            # 到这里就结束了
    return "已成年"                # 只有前面条件都不满足才到这里

print(check_age(-5))  # 年龄不能是负数！
print(check_age(12))  # 未成年
print(check_age(25))  # 已成年
```

**return 后面的代码不会执行！**

```python
def demo():
    print("这行会打印")
    return "结束了"
    print("这行永远不会打印！")  # ⚠️ 不会执行
```

#### 2.4 返回多个值

```python
def get_max_min(numbers):
    """返回最大值和最小值"""
    return max(numbers), min(numbers)

high, low = get_max_min([3, 1, 5, 2, 4])
print(f"最大：{high}，最小：{low}")  # 最大：5，最小：1
```

### 步骤3：动手演示（10分钟）

**演示 return 的威力**：

```python
# 没有 return：功能受限
def add_v1(a, b):
    print(a + b)          # 只能显示，没法参与运算

# 有 return：功能强大
def add_v2(a, b):
    return a + b

# add_v1 的结果没法继续使用
add_v1(3, 5)
# result = add_v1(3, 5) + 10  # ❌ 报错！NoneType

# add_v2 的结果可以继续运算
result = add_v2(3, 5) + 10
print(result)  # 18 —— 可以！

# 还可以链式调用
total = add_v2(add_v2(3, 5), add_v2(10, 20))
print(total)  # 38
```

## 💻 代码示例

```python
# ========== 第31节：返回值 —— 函数给你的结果 ==========

# --- 1. 认识 return ---
print("=== return 的基本用法 ===")

def add(a, b):
    """两个数相加，返回结果"""
    result = a + b
    return result

# 用变量接收返回值
sum_result = add(3, 5)
print(f"3 + 5 = {sum_result}")

# 直接使用返回值
print(f"10 + 20 = {add(10, 20)}")

# 返回值可以参与运算
total = add(1, 2) + add(3, 4)
print(f"(1+2) + (3+4) = {total}")

# --- 2. print 和 return 的区别 ---
print("\n=== print vs return（重要！）===")

# 用 print 的函数：只显示，不返回值
def show_add(a, b):
    print(f"{a} + {b} = {a + b}")  # 只打印

# 用 return 的函数：返回值，可以继续用
def calc_add(a, b):
    return a + b  # 返回结果

# 对比
print("--- show_add（用 print）---")
show_add(3, 5)  # 屏幕显示：3 + 5 = 8
r1 = show_add(3, 5)
print(f"show_add 的返回值：{r1}")  # None！没有返回值

print("--- calc_add（用 return）---")
r2 = calc_add(3, 5)
print(f"calc_add 的返回值：{r2}")  # 8！有返回值
print(f"可以用来算：{r2 * 2}")      # 16！可以继续用

# --- 3. return 会终止函数 ---
print("\n=== return 终止函数 ===")

def grade(score):
    """根据分数返回评级"""
    if score < 0 or score > 100:
        return "分数错误！"  # 函数在这里结束
    if score >= 90:
        return "优秀"
    if score >= 80:
        return "良好"
    if score >= 60:
        return "及格"
    return "不及格"

print(f"95 分：{grade(95)}")
print(f"85 分：{grade(85)}")
print(f"72 分：{grade(72)}")
print(f"55 分：{grade(55)}")
print(f"120 分：{grade(120)}")

# --- 4. 返回多个值 ---
print("\n=== 返回多个值 ===")

def get_stats(numbers):
    """返回列表的统计信息"""
    total = sum(numbers)
    average = total / len(numbers)
    maximum = max(numbers)
    minimum = min(numbers)
    return total, average, maximum, minimum

scores = [88, 92, 76, 95, 83]
t, a, hi, lo = get_stats(scores)
print(f"总分：{t}，平均：{a:.1f}，最高：{hi}，最低：{lo}")

# --- 5. 实用函数示例 ---
print("\n=== 实用函数 ===")

def is_even(number):
    """判断一个数是不是偶数"""
    return number % 2 == 0

def is_passing(score, pass_line=60):
    """判断成绩是否及格"""
    return score >= pass_line

def get_full_name(first_name, last_name):
    """拼接全名"""
    return f"{last_name}{first_name}"

def calculate_bmi(weight_kg, height_cm):
    """计算 BMI"""
    height_m = height_cm / 100
    bmi = weight_kg / (height_m ** 2)
    return round(bmi, 1)

# 测试
print(f"4 是偶数吗？{is_even(4)}")
print(f"7 是偶数吗？{is_even(7)}")

scores = [95, 58, 72, 88, 45]
pass_count = 0
for s in scores:
    if is_passing(s):
        pass_count += 1
print(f"及格人数：{pass_count}/{len(scores)}")

print(f"全名：{get_full_name('小明', '王')}")
print(f"BMI：{calculate_bmi(45, 155)}")

# --- 6. 综合项目：成绩分析器 ---
print("\n=== 📊 成绩分析器 ===")

def analyze_scores(scores):
    """分析成绩列表，返回完整的分析报告"""
    if len(scores) == 0:
        return "没有成绩数据"
    
    total = sum(scores)
    avg = total / len(scores)
    highest = max(scores)
    lowest = min(scores)
    pass_count = sum(1 for s in scores if s >= 60)
    excellent_count = sum(1 for s in scores if s >= 90)
    
    return {
        "总分": total,
        "平均分": round(avg, 1),
        "最高分": highest,
        "最低分": lowest,
        "及格人数": pass_count,
        "优秀人数": excellent_count,
        "总人数": len(scores)
    }

# 使用分析器
math_scores = [95, 88, 92, 76, 83, 90, 45, 100, 67, 82]
report = analyze_scores(math_scores)

print("数学成绩分析报告：")
print("=" * 20)
for key, value in report.items():
    print(f"  {key}：{value}")
```

## ✏️ 课堂练习

### 基础练习
1. **简单返回**：定义 `add(a, b)` 函数，用 return 返回两数之和。调用并打印结果。
2. **判断函数**：定义 `is_positive(n)` 函数，如果 n > 0 返回 True，否则返回 False。测试几个数字。
3. **return vs print**：把第 2 题的函数分别改成用 print 和用 return 的版本，说出它们的区别。

### 挑战练习
1. **成绩评级**：定义 `get_grade(score)` 函数，根据分数返回评级字符串（优秀、良好、及格、不及格），不要在里面用 print，只用 return。然后在外面打印评级。
2. **计算器升级**：把之前的加减乘除函数都加上 return，然后写一个 `calculate(a, operator, b)` 函数，根据 operator（"+"、"-"、"*"、"/"）返回对应的计算结果。
