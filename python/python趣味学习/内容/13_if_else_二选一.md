# 第13节：if-else —— 二选一

## 🎯 教学目标
- 学生能够理解 else 的作用：当 if 条件不成立时的"否则"分支
- 学生能够正确使用 if-else 结构做二选一的判断
- 学生能够独立完成"升级版及格判断器"项目

## 📝 重点概念
- **else**：if 条件的"反面"。如果 if 条件成立执行 if 块，不成立就执行 else 块
- **二选一逻辑**：if 和 else 配合，两条路必然走一条，不会同时走，也不会都不走
- **else 没有条件**：else 后面直接跟冒号，不需要写条件
- **缩进规则不变**：else 也要缩进的代码块

## 📖 讲解内容

### 步骤1：引入（5分钟）

**生活场景**：
"上节课我们学了 if，它就像妈妈说的'如果考试及格了，就带你去吃大餐'。"

"但生活中往往是这样：'如果考试及格了，就带你去吃大餐，否则就在家写作业。'"

"这里的'否则'就是今天要学的 else！if-else 让程序能处理两种情况：条件成立怎么办，不成立又怎么办。"

**互动**：让学生想生活中的"二选一"：
- 如果下雨，坐公交去学校，否则走路去
- 如果有零花钱，买零食，否则忍着
- 如果周末，睡懒觉，否则早起

### 步骤2：核心讲解（15-20分钟）

**1. if-else 基本结构（5分钟）**

```python
if 条件:
    条件成立时执行这里
else:
    条件不成立时执行这里
```

**关键点**：
- else 后面**没有条件**
- else 后面也要加**冒号**
- else 下面的代码也要**缩进**
- if 和 else 的缩进在**同一列**（对齐）

**2. 对比：用两个 if vs 用 if-else（5分钟）**

```python
# 方法1：用两个 if（不推荐，判断了两次）
score = 85
if score >= 60:
    print("及格")
if score < 60:
    print("不及格")

# 方法2：用 if-else（推荐，只判断一次）
score = 85
if score >= 60:
    print("及格")
else:
    print("不及格")
```

**为什么 if-else 更好？**
- 只判断一次，效率更高
- 逻辑更清晰：不是及格就是不及格
- 不会出错：两个 if 可能同时执行（如果条件写错了）

**3. if-else 的执行流程（5分钟）**

用流程图的方式讲解（可以在黑板上画）：

```
开始 → 判断条件 → True → 执行 if 块 → 结束
                  → False → 执行 else 块 → 结束
```

强调：**两条路必定走一条，也只走一条！**

**4. 常见错误（5分钟）**

```python
# ❌ 错误1：else 后面写了条件
if score >= 60:
    print("及格")
else score < 60:      # 错误！else 后面不能有条件
    print("不及格")

# ❌ 错误2：else 没对齐
if score >= 60:
    print("及格")
  else:               # 错误！else 要和 if 对齐
    print("不及格")

# ✅ 正确写法
if score >= 60:
    print("及格")
else:
    print("不及格")
```

### 步骤3：动手演示（10分钟）

**演示1：升级版及格判断器**

```python
score = 85
if score >= 60:
    print(f"你的分数是{score}分，及格啦！🎉")
    print("太棒了，给你一朵小红花🌺")
else:
    print(f"你的分数是{score}分，没及格😢")
    print("别灰心，下次加油！💪")
```

**演示2：偶数判断器**

```python
number = 7
if number % 2 == 0:
    print(f"{number} 是偶数")
else:
    print(f"{number} 是奇数")
```

**演示3：登录简化版**

```python
password = input("请输入密码：")
if password == "123456":
    print("密码正确，欢迎进入！")
else:
    print("密码错误，拒绝访问！")
```

## 💻 代码示例

```python
# ======== 第13节：if-else —— 二选一 ========

score = 85

# if-else 结构：条件成立走 if，不成立走 else
if score >= 60:
    print(f"分数：{score}，及格啦！🎉")
    print("送你一朵小红花🌺")
else:
    print(f"分数：{score}，没及格😢")
    print("别灰心，下次加油！💪")

print("程序结束")  # 不管及格不及格，都会执行

# 偶数判断
num = 7
if num % 2 == 0:
    print(f"{num}是偶数")
else:
    print(f"{num}是奇数")
```

## ✏️ 课堂练习

1. **基础练习**：写一个程序，判断一个数是否大于 100。如果大于就打印"很大！"，否则打印"不大。"
2. **改造练习**：把上节课的"高温警报"程序改成 if-else 版本——如果温度 > 35，打印"太热了！"，否则打印"温度还行~"
3. **挑战练习**：写一个"周几判断器"——输入 1-7 的数字，判断是不是周末（6和7是周末，其他不是）

## 📋 小结
- else 是 if 的"另一半"，处理条件不成立的情况
- if-else 是二选一：必定走一条路，也只走一条
- else 后面不写条件，但要写冒号
- else 要和 if 对齐（同一列）
- if-else 比写两个 if 更清晰、更高效
