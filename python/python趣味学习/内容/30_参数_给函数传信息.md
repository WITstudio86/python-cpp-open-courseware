# 第30节：参数 —— 给函数传信息

## 🎯 教学目标
- 学生能够理解形参和实参的概念
- 学生能够定义带有一个或多个参数的函数
- 学生能够正确调用带参数的函数并传入实参
- 学生能够理解和使用默认参数

## 📝 重点概念
- **参数（parameter）**：函数定义时小括号里的变量，是"占位符"
- **实参（argument）**：调用函数时传入的具体值
- **形参 vs 实参**：形参是"预留位置"，实参是"实际放进去的东西"
- **默认参数**：如果调用时没传值，就用默认值

## 📖 讲解内容

### 步骤1：引入（5分钟）

**类比**：榨汁机 2.0 版。

"上次我们做了一个只能打招呼的函数。但打招呼该打给谁呢？"

```python
# 这个函数只能打给"大家"，不够灵活
def say_hello():
    print("大家好！")

# 如果我想打给"小明"、"小红"、"王老师"呢？
# 难道要写三个函数？
```

"我们需要给函数开一个'窗口'，让外面的信息能传进来。这个'窗口'就叫**参数**！"

### 步骤2：核心讲解（15-20分钟）

#### 2.1 什么是参数？

```python
# 带参数的函数
def greet(name):          # name 是参数（形参）
    print(f"你好，{name}！")

# 调用时传入具体的值
greet("小明")   # "小明" 是实参 → 输出：你好，小明！
greet("小红")   # "小红" 是实参 → 输出：你好，小红！
greet("王老师")  # "王老师" 是实参 → 输出：你好，王老师！
```

**关键理解**：
- `name` 是**形参**（形式参数）—— 函数定义时的"占位符"
- `"小明"` 是**实参**（实际参数）—— 调用时真正传进去的值
- 形参就像电影院的"座位"，实参就像"坐上去的人"

#### 2.2 多个参数

```python
def greet(name, greeting):
    """用指定的问候语问候某人"""
    print(f"{greeting}，{name}！")

greet("小明", "早上好")   # 早上好，小明！
greet("小红", "生日快乐")  # 生日快乐，小红！
```

**注意**：参数的位置要对应！第一个实参给第一个形参，第二个实参给第二个形参。

#### 2.3 默认参数

```python
# greeting 有默认值 "你好"
def greet(name, greeting="你好"):
    print(f"{greeting}，{name}！")

greet("小明")                    # 你好，小明！（用了默认值）
greet("小红", "生日快乐")        # 生日快乐，小红！（覆盖了默认值）
greet("王老师", greeting="下午好") # 下午好，王老师！（指定参数名传值）
```

**规则**：有默认值的参数必须放在没有默认值的参数后面。

```python
# ✅ 正确
def greet(name, greeting="你好"):
    pass

# ❌ 错误
# def greet(greeting="你好", name):  # 默认参数不能在普通参数前面
#     pass
```

#### 2.4 什么时候用参数？什么时候用默认参数？

| 情况 | 做法 | 例子 |
|------|------|------|
| 每次都必须给的值 | 普通参数 | `name` — 必须知道打给谁 |
| 通常不变，偶尔要改 | 默认参数 | `greeting="你好"` — 通常说"你好" |

### 步骤3：动手演示（10分钟）

```python
# 演示1：从无参数改进到有参数
def print_line_v1():
    print("-" * 30)       # 只能打印 30 个横线

def print_line_v2(length):
    print("-" * length)   # 可以打印任意长度！

print_line_v2(10)   # 10 个横线
print_line_v2(30)   # 30 个横线
print_line_v2(50)   # 50 个横线

# 演示2：默认参数的威力
def print_line_v3(length=30, char="-"):
    print(char * length)

print_line_v3()              # 默认 30 个 '-'
print_line_v3(20)            # 20 个 '-'
print_line_v3(20, "=")       # 20 个 '='
print_line_v3(char="*")      # 30 个 '*'（length 用默认值）

# 演示3：实用的例子
def power(base, exp=2):
    """计算 base 的 exp 次方，默认为平方"""
    return base ** exp

print(power(3))      # 9（3 的平方，exp 默认 2）
print(power(3, 3))   # 27（3 的 3 次方）
```

## 💻 代码示例

```python
# ========== 第30节：参数 —— 给函数传信息 ==========

# --- 1. 从无参数到有参数 ---
print("=== 无参数 vs 有参数 ===")

# 无参数：每次只能做同样的事
def greet_everyone():
    print("大家好！")

greet_everyone()

# 有参数：可以针对不同的人
def greet(name):
    """向指定的人打招呼"""
    print(f"你好，{name}！")

greet("小明")
greet("小红")
greet("王老师")

# --- 2. 多个参数 ---
print("\n=== 多个参数 ===")

def introduce(name, age, hobby):
    """介绍一个人"""
    print(f"我叫{name}，今年{age}岁，喜欢{hobby}。")

introduce("小明", 12, "编程")
introduce("小红", 11, "画画")
introduce("小刚", 13, "踢足球")

# 参数顺序要对应！
introduce("编程", 12, "小明")  # 乱套了！

# --- 3. 实数计算的函数 ---
print("\n=== 实用的带参函数 ===")

def add(a, b):
    """两个数相加"""
    result = a + b
    print(f"{a} + {b} = {result}")

def multiply(a, b):
    """两个数相乘"""
    result = a * b
    print(f"{a} × {b} = {result}")

add(10, 20)
add(3.5, 6.5)
multiply(5, 6)
multiply(7, 8)

# --- 4. 默认参数 ---
print("\n=== 默认参数 ===")

def print_line(length=30, char="-"):
    """打印一条线，长度和字符都可以自定义"""
    print(char * length)

print_line()           # 默认：30 个 '-'
print_line(15)         # 15 个 '-'
print_line(20, "=")    # 20 个 '='
print_line(char="*")   # 30 个 '*'
print_line(char="~", length=40)  # 指定参数名可以不按顺序

# --- 5. 综合例子：灵活的打招呼 ---
print("\n=== 灵活的打招呼 ===")

def say_hello(name, greeting="你好", punctuation="！"):
    """灵活的打招呼函数"""
    print(f"{greeting}，{name}{punctuation}")

say_hello("小明")
say_hello("小红", "早上好")
say_hello("王老师", "下午好", "。")
say_hello("小李", punctuation="~")

# --- 6. 项目：制作一个成绩报告生成器 ---
print("\n=== 📊 成绩报告生成器 ===")

def print_report(name, score, subject="数学", max_score=100):
    """打印成绩报告"""
    print("-" * 30)
    print(f"  科目：{subject}")
    print(f"  姓名：{name}")
    print(f"  成绩：{score}/{max_score}")
    print(f"  百分比：{score/max_score*100:.1f}%")
    
    # 评级
    pct = score / max_score * 100
    if pct >= 90:
        grade = "优秀 🌟"
    elif pct >= 80:
        grade = "良好 👍"
    elif pct >= 60:
        grade = "及格"
    else:
        grade = "需要加油 💪"
    print(f"  评级：{grade}")
    print("-" * 30)

print_report("小明", 95)
print_report("小红", 82, "英语")
print_report("小刚", 65, "语文", 100)
print_report("小丽", 45, "数学", max_score=100)

# --- 7. 练习：temperature 转化器 ---
print("\n=== 🌡️ 温度转化器 ===")

def c_to_f(celsius):
    """摄氏度转华氏度"""
    f = celsius * 9 / 5 + 32
    return f

def f_to_c(fahrenheit):
    """华氏度转摄氏度"""
    c = (fahrenheit - 32) * 5 / 9
    return c

print(f"25°C = {c_to_f(25):.1f}°F")
print(f"98°F = {f_to_c(98):.1f}°C")
```

## ✏️ 课堂练习

### 基础练习
1. **打招呼函数**：定义一个 `greet(name)` 函数，接收一个名字参数，打印"你好，XXX！"。分别传入 3 个不同的名字调用它。
2. **乘法表函数**：定义一个 `multiplication(n)` 函数，接收一个数字 n，打印 n 的乘法表（1×n 到 9×n）。
3. **默认参数练习**：定义一个 `print_line(length=20, char='-')` 函数，测试不传参、只传 length、只传 char、两个都传的情况。

### 挑战练习
1. **分数评级**：定义 `get_grade(score, pass_score=60)` 函数，根据分数返回"优秀"（>=90）、"良好"（>=80）、"及格"（>=pass_score）、"不及格"。测试不同的分数和及格线。
2. **计算器**：定义四个函数 `add(a,b)`、`subtract(a,b)`、`multiply(a,b)`、`divide(a,b)`，然后用它们做一个简单的计算器。

## 📋 小结

### 本节学了什么
- **参数**让函数更灵活，能根据不同输入做不同的事
- **形参**是定义时的占位符，**实参**是调用时传入的具体值
- **多个参数**按位置对应
- **默认参数**给参数一个"后备值"，调用时可写可不写

### 记忆口诀
- "参数是窗口，信息往里走"
- "形参占位置，实参填内容"
- "默认参数有后备，不传就用默认值"
