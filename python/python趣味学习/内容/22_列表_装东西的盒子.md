# 第22节：列表 —— 一个装很多东西的盒子

## 🎯 教学目标
- 学生能够理解列表是用来存储多个数据的有序容器
- 学生能够使用 `[]` 创建包含数字、字符串或混合类型的列表
- 学生能够使用索引 `[0]` 和 `[-1]` 访问列表中的元素
- 学生能够使用 `len()` 获取列表的长度
- 学生能够将生活中的"清单"概念与列表对应起来

## 📝 重点概念
- **列表**：像一个有很多格子的盒子，每个格子可以放一样东西，格子从 0 开始编号
- **索引**：列表中每个元素的"门牌号"，从 0 开始，负数表示从后往前数
- **len()**：一个神奇的函数，可以告诉我们列表里装了多少东西

## 📖 讲解内容

### 步骤1：引入（5分钟）

**老师拿出一个盒子**（实物或图片），里面装着几样东西：铅笔、橡皮、尺子。

"大家看这个盒子，里面装了铅笔、橡皮、尺子。在 Python 里，也有一种'盒子'，可以装很多东西，而且装的东西可以是数字、文字，甚至是混合的！这个盒子就叫**列表（list）**。"

**生活中的列表例子**：
- 购物清单：["苹果", "香蕉", "牛奶", "面包"]
- 成绩单：[95, 88, 92, 100]
- 好友名单：["小明", "小红", "小刚"]

### 步骤2：核心讲解（15-20分钟）

#### 2.1 创建列表

```python
# 用方括号 [] 创建列表，元素之间用逗号隔开
fruits = ["苹果", "香蕉", "橘子", "葡萄"]
scores = [95, 88, 92, 100, 76]
mixed = ["小明", 12, 1.55, True]  # 可以混合不同类型
empty = []  # 空列表，先准备一个空盒子
```

**强调**：列表用方括号 `[]`，不是小括号，也不是大括号。

#### 2.2 访问列表元素 —— 索引

"列表里的每个东西都有编号，叫**索引**。注意：编号从 0 开始，不是从 1 开始！"

```
fruits = ["苹果", "香蕉", "橘子", "葡萄"]
索引:        0      1      2      3
倒数索引:    -4     -3     -2     -1
```

```python
fruits = ["苹果", "香蕉", "橘子", "葡萄"]

print(fruits[0])   # 苹果 —— 第一个
print(fruits[1])   # 香蕉 —— 第二个
print(fruits[-1])  # 葡萄 —— 最后一个！
print(fruits[-2])  # 橘子 —— 倒数第二个
```

**为什么从 0 开始**？简单解释：这是计算机的传统，就像楼房的"地面层"在有些国家叫 0 层。

#### 2.3 列表长度 —— len()

```python
fruits = ["苹果", "香蕉", "橘子", "葡萄"]
print(len(fruits))  # 4 —— 有 4 种水果

empty = []
print(len(empty))  # 0 —— 空盒子，什么都没有
```

**注意**：有 4 个元素，索引是 0、1、2、3。最后一个索引是 `len(列表) - 1`！

#### 2.4 切片（可选，视学生接受程度）

```python
fruits = ["苹果", "香蕉", "橘子", "葡萄"]

print(fruits[0:2])   # ['苹果', '香蕉'] —— 索引 0 和 1（不含 2）
print(fruits[1:3])   # ['香蕉', '橘子']
print(fruits[:2])    # ['苹果', '香蕉'] —— 从开头到索引 1
print(fruits[2:])    # ['橘子', '葡萄'] —— 从索引 2 到结尾
```

**记忆口诀**："左闭右开"——包含左边索引，不包含右边索引。

### 步骤3：动手演示（10分钟）

老师现场演示：

## 💻 代码示例

```python
# ========== 第22节：列表 —— 一个装很多东西的盒子 ==========

# --- 1. 创建列表 ---
print("=== 创建列表 ===")

# 字符串列表
fruits = ["苹果", "香蕉", "橘子", "葡萄", "西瓜"]
print("水果列表：", fruits)

# 数字列表
scores = [95, 88, 92, 100, 76]
print("成绩列表：", scores)

# 混合列表
student = ["小明", 12, 155.5, True]
print("学生信息：", student)

# 空列表
todo = []
print("待办事项（空的）：", todo)

# --- 2. 访问元素：索引 ---
print("\n=== 访问元素 ===")

fruits = ["苹果", "香蕉", "橘子", "葡萄", "西瓜"]
# 索引:      0      1      2      3      4
# 倒数:     -5     -4     -3     -2     -1

print("第一个水果：", fruits[0])    # 苹果
print("第三个水果：", fruits[2])    # 橘子
print("最后一个水果：", fruits[-1])  # 西瓜
print("倒数第二个水果：", fruits[-2]) # 葡萄

# --- 3. 列表长度 ---
print("\n=== 列表长度 ===")

print("水果列表有", len(fruits), "个元素")
print("成绩列表有", len(scores), "个元素")

# 注意：长度是 5，但最后一个索引是 4
print("最后一个水果（用 len 算）：", fruits[len(fruits) - 1])

# --- 4. 列表切片（取一段） ---
print("\n=== 列表切片 ===")

print("前 3 个水果：", fruits[0:3])   # ['苹果', '香蕉', '橘子']
print("第 2 到第 4 个：", fruits[1:4]) # ['香蕉', '橘子', '葡萄']
print("从第 3 个到最后：", fruits[2:]) # ['橘子', '葡萄', '西瓜']
print("前两个：", fruits[:2])         # ['苹果', '香蕉']

# --- 5. 遍历列表 ---
print("\n=== 遍历列表 ===")

print("我的购物清单：")
shopping = ["牛奶", "面包", "鸡蛋", "苹果"]
for item in shopping:
    print("  📦", item)
```

## ✏️ 课堂练习

### 基础练习
1. **创建自己的列表**：创建一个包含你最喜欢的 5 种食物的列表，然后打印第一个、第三个和最后一个。
2. **计算长度**：创建一个包含全班同学名字的列表（至少 4 个），用 `len()` 打印人数，然后用索引打印第一个同学和最后一个同学的名字。
3. **切片练习**：用上面的列表，打印"前两个同学"和"后两个同学"。

### 挑战练习
1. **倒数索引**：用 `[-1]`、`[-2]` 等负数索引，从后往前打印列表中的元素。
2. **用户输入建列表**：让用户输入 3 个喜欢的动物名称，存到列表中，然后打印出来。
3. **判断是否存在**：写一个程序，判断某个元素是否在列表中（提示：用 `in` 关键字，下节课会详细讲）。

## 📋 小结

### 本节学了什么
- **列表**是用 `[]` 创建的容器，可以装多个数据
- **索引**从 0 开始，`[0]` 是第一个，`[-1]` 是最后一个
- **len()** 告诉我们列表里有多少元素
- 列表可以**切片**取出一段

### 记忆口诀
- "一对方括号装万物，逗号分隔不迷路"
- "索引零起往前数，负一就是最末尾"
- "len 一问知多少，切片冒号取一段"
