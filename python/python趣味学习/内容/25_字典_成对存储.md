# 第25节：字典 —— 成对存储

## 🎯 教学目标
- 学生能够理解字典是"标签-内容"成对存储的数据结构
- 学生能够使用 `{}` 创建字典，理解 key: value 的对应关系
- 学生能够通过 key（键）访问、添加和修改字典中的 value（值）
- 学生能够完成"个人信息字典"和"迷你英汉词典"项目

## 📝 重点概念
- **字典**：像一个有标签的收纳盒，每个东西都贴了标签，靠标签来找东西
- **键（key）**：标签，必须是唯一的，通常用字符串
- **值（value）**：标签对应的内容，可以是任何类型
- **键值对（key-value pair）**：一个标签 + 它的内容 = 一对

## 📖 讲解内容

### 步骤1：引入（5分钟）

**实物演示**：拿出一个真实的字典（或英汉词典）。

"如果你要查 'apple' 的中文意思，你会怎么做？——翻字典，找 'apple' 这个词条，看它对应的解释。"

"Python 里的**字典（dict）**，就像一本真正的字典。每个词（key）对应一个解释（value）。"

**列表 vs 字典**：
- 列表：按位置找，第 0 个、第 1 个...（像储物柜，编号找）
- 字典：按标签找，"name"→"小明"（像字典，查词找）

### 步骤2：核心讲解（15-20分钟）

#### 2.1 创建字典

```python
# 空字典
empty = {}

# 个人信息字典
person = {
    "姓名": "小明",
    "年龄": 12,
    "爱好": "编程",
    "城市": "北京"
}

print(person)
# {'姓名': '小明', '年龄': 12, '爱好': '编程', '城市': '北京'}
```

**格式**：`{key1: value1, key2: value2, ...}`，用冒号连接键和值，逗号分隔每一对。

#### 2.2 通过键访问值

```python
person = {"姓名": "小明", "年龄": 12, "爱好": "编程"}

print(person["姓名"])   # 小明
print(person["年龄"])   # 12

# 用变量作为 key
key = "爱好"
print(person[key])      # 编程
```

**注意**：如果 key 不存在，用 `[]` 访问会报错！后面学 `.get()` 可以安全访问。

#### 2.3 添加和修改

```python
person = {"姓名": "小明", "年龄": 12}

# 添加新键值对
person["爱好"] = "编程"
person["城市"] = "北京"
print(person)
# {'姓名': '小明', '年龄': 12, '爱好': '编程', '城市': '北京'}

# 修改已有的值
person["年龄"] = 13  # 过生日了！
print(person["年龄"])  # 13
```

**规则**：如果 key 存在就修改，不存在就添加。非常直观！

### 步骤3：动手演示（10分钟）

**迷你英汉词典**：

```python
# 创建一个迷你英汉词典
dictionary = {
    "apple": "苹果",
    "banana": "香蕉",
    "cat": "猫",
    "dog": "狗",
    "hello": "你好"
}

# 查词
word = input("请输入要查的英文单词：")
if word in dictionary:
    print(f"{word} 的中文是：{dictionary[word]}")
else:
    print("抱歉，词典里还没有这个词。")

# 显示所有词条
print("\n词典里的所有词：")
for word in dictionary:
    print(f"  {word} -> {dictionary[word]}")
```

## 💻 代码示例

```python
# ========== 第25节：字典 —— 成对存储 ==========

# --- 1. 创建字典 ---
print("=== 创建字典 ===")

# 个人信息
me = {
    "名字": "小明",
    "年龄": 12,
    "年级": "五年级",
    "爱好": "编程",
    "喜欢的颜色": "蓝色"
}
print("我的信息：", me)

# 空字典
empty = {}
print("空字典：", empty)

# --- 2. 通过键访问值 ---
print("\n=== 通过键访问值 ===")

print("我的名字：", me["名字"])
print("我的年龄：", me["年龄"])
print("我的爱好：", me["爱好"])

# 用变量存放键
field = "年级"
print(f"我的{field}：", me[field])

# --- 3. 添加新的键值对 ---
print("\n=== 添加信息 ===")

me["宠物"] = "小猫"
me["梦想"] = "成为程序员"
print("添加后：", me)

# --- 4. 修改已有的值 ---
print("\n=== 修改信息 ===")

print("原来年龄：", me["年龄"])
me["年龄"] = 13  # 长大一岁
print("现在年龄：", me["年龄"])

me["爱好"] = "编程和画画"  # 爱好变多了
print("现在爱好：", me["爱好"])

# --- 5. 用 in 判断 key 是否存在 ---
print("\n=== 判断 key 是否存在 ===")

print("有'名字'吗？", "名字" in me)    # True
print("有'身高'吗？", "身高" in me)    # False

# --- 6. 项目：迷你英汉词典 ---
print("\n=== 📖 迷你英汉词典 ===")

dict_cn_en = {
    "apple": "苹果",
    "banana": "香蕉",
    "cat": "猫",
    "dog": "狗",
    "hello": "你好",
    "thank you": "谢谢",
    "goodbye": "再见",
    "book": "书",
    "water": "水",
    "sun": "太阳"
}

# 显示所有词条
print("词典内容：")
for en, cn in dict_cn_en.items():
    print(f"  {en:15s} → {cn}")

# 查词功能
print("\n--- 查词 ---")
while True:
    word = input("请输入英文单词（输入 q 退出）：").strip().lower()
    if word == "q":
        print("再见！")
        break
    if word in dict_cn_en:
        print(f"  📝 {word} = {dict_cn_en[word]}")
    else:
        print(f"  ❌ 词典中还没有「{word}」，你可以用 dict_cn_en['{word}'] = '中文' 来添加哦！")

# --- 7. 项目：个人信息卡片 ---
print("\n=== 🧑 个人信息卡片 ===")

card = {
    "姓名": "小明",
    "年龄": 12,
    "学校": "阳光小学",
    "班级": "五年级3班",
    "最喜欢的科目": "数学",
    "爱好": "编程"
}

print("=" * 30)
print("      个人信息卡片")
print("=" * 30)
for key, value in card.items():
    print(f"  {key}：{value}")
print("=" * 30)
```

## ✏️ 课堂练习

### 基础练习
1. **个人信息字典**：创建一个关于你自己的字典，包含姓名、年龄、班级、爱好。用 `[]` 访问并打印每一项。
2. **水果字典**：创建一个水果中英文对照字典（至少 5 个），让用户输入英文名，程序输出中文名。
3. **添加和修改**：在上面创建的个人信息字典中，添加"宠物"和"梦想"两项，然后修改"年龄"为今年的年龄。

### 挑战练习
1. **迷你词典升级**：在迷你英汉词典中，每次用户查一个不存在的词时，自动添加该词（让用户输入中文含义），实现"边查边学"。
2. **学习助手**：创建一个包含 5 道数学题（题目为 key，答案为 value）的字典，随机出一道题让用户回答，判断对错。

## 📋 小结

### 本节学了什么
- **字典**使用 `{}` 创建，每对数据用 `key: value` 表示
- 用 `字典[key]` 访问、添加、修改值
- 用 `in` 判断某个 key 是否在字典中
- 字典适合"名称→内容"这种查询场景

### 记忆口诀
- "花括号里放对子，冒号连接键和值"
- "方括号里写标签，要找的值在眼前"
- "有标签就修改，没标签就添加"
