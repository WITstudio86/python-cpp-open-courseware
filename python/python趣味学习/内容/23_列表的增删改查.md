# 第23节：列表的增删改查

## 🎯 教学目标
- 学生能够使用 `.append()` 向列表末尾添加元素
- 学生能够使用 `.insert()` 在指定位置插入元素
- 学生能够使用 `.remove()`、`del` 和 `.pop()` 删除元素
- 学生能够通过索引直接赋值来修改列表元素
- 学生能够综合运用增删改查完成"待办事项小程序"

## 📝 重点概念
- **增（append / insert）**：往列表里加东西，可以加到最后或指定位置
- **删（remove / del / pop）**：从列表里拿走东西，有不同方式
- **改（赋值）**：直接给某个位置换上新的东西
- **查（索引 / in）**：找到列表里的东西

## 📖 讲解内容

### 步骤1：引入（5分钟）

"上节课我们学会了创建列表和用索引访问元素。但这还不够——我们需要能**修改**列表。"

**类比**：列表就像一个可以重新整理的收纳盒。
- **增**：往盒子里放新东西
- **删**：把不要的东西拿出来扔掉
- **改**：把旧东西换成新东西  
- **查**：看看盒子里有什么、某个东西在不在

"今天我们就来学习列表的增删改查四招！"

### 步骤2：核心讲解（15-20分钟）

#### 2.1 增加元素

**方法一：append() —— 加到末尾**

```python
fruits = ["苹果", "香蕉"]
fruits.append("橘子")  # 在最后加上橘子
print(fruits)  # ['苹果', '香蕉', '橘子']

fruits.append("葡萄")
print(fruits)  # ['苹果', '香蕉', '橘子', '葡萄']
```

**方法二：insert() —— 插到指定位置**

```python
fruits = ["苹果", "香蕉", "橘子"]
fruits.insert(1, "西瓜")  # 在索引 1 的位置插入西瓜
print(fruits)  # ['苹果', '西瓜', '香蕉', '橘子']
#              索引 0    1      2      3
```

**记忆**：`append` = 追加到最后，`insert` = 插入到中间。

#### 2.2 删除元素

**方法一：remove() —— 按值删除**

```python
fruits = ["苹果", "香蕉", "橘子", "香蕉"]
fruits.remove("香蕉")  # 删除找到的第一个"香蕉"
print(fruits)  # ['苹果', '橘子', '香蕉']  —— 注意只删了第一个！
```

**方法二：pop() —— 按索引删除（并返回被删的值）**

```python
fruits = ["苹果", "香蕉", "橘子"]
removed = fruits.pop(1)  # 删除索引 1 的元素
print(removed)  # 香蕉 —— pop 会返回被删掉的东西
print(fruits)   # ['苹果', '橘子']

fruits.pop()  # 不写索引，默认删最后一个
print(fruits)  # ['苹果']
```

**方法三：del —— 按索引删除**

```python
fruits = ["苹果", "香蕉", "橘子"]
del fruits[0]  # 删除索引 0 的元素
print(fruits)  # ['香蕉', '橘子']
```

**三种删除的区别**：
| 方法 | 用法 | 特点 |
|------|------|------|
| remove(x) | 按值删 | 只删第一个匹配的 |
| pop(i) | 按索引删 | 会返回被删的值 |
| del list[i] | 按索引删 | 不返回值 |

#### 2.3 修改元素

```python
fruits = ["苹果", "香蕉", "橘子"]
fruits[1] = "草莓"  # 把索引 1 的"香蕉"改成"草莓"
print(fruits)  # ['苹果', '草莓', '橘子']
```

**简单直接**：就像换盒子里的东西，把旧的拿出来，新的放进去。

#### 2.4 查找元素

```python
fruits = ["苹果", "香蕉", "橘子"]

# 用索引访问
print(fruits[0])  # 苹果

# 用 in 判断是否存在
print("苹果" in fruits)   # True
print("西瓜" in fruits)   # False

# 用 index() 找位置
print(fruits.index("橘子"))  # 2 —— 橘子在索引 2
```

### 步骤3：动手演示（10分钟）

**待办事项小程序**：

```python
# 待办事项列表
todos = []

# 添加事项
todos.append("写作业")
todos.append("练钢琴")
todos.append("跑步")
print("当前待办：", todos)

# 完成一件事（删除）
todos.remove("练钢琴")
print("练钢琴完成！剩余：", todos)

# 插入紧急事项
todos.insert(0, "给奶奶打电话")  # 插到最前面
print("加入紧急事项：", todos)

# 修改事项
todos[1] = "写数学作业"
print("修改后：", todos)
```

## 💻 代码示例

```python
# ========== 第23节：列表的增删改查 ==========

# --- 1. 增加元素 ---
print("=== 增加元素 ===")

# append()：加到末尾
animals = ["猫", "狗"]
print("初始：", animals)
animals.append("兔子")
print("append 后：", animals)
animals.append("仓鼠")
print("再 append：", animals)

# insert()：插到指定位置
animals.insert(1, "鹦鹉")  # 在索引1（狗的前面）插入
print("insert 后：", animals)

# --- 2. 删除元素 ---
print("\n=== 删除元素 ===")

# remove()：按值删除
colors = ["红", "蓝", "绿", "蓝"]
print("初始：", colors)
colors.remove("蓝")  # 只删除第一个"蓝"
print("remove('蓝') 后：", colors)

# pop()：按索引删除，会返回被删的值
colors = ["红", "蓝", "绿"]
removed = colors.pop(1)
print("pop(1) 删掉了：", removed)
print("剩余：", colors)

# pop() 不写索引，删最后一个
last = colors.pop()
print("pop() 删掉了最后一个：", last)
print("剩余：", colors)

# del：直接删除
colors = ["红", "蓝", "绿"]
del colors[0]
print("del[0] 后：", colors)

# --- 3. 修改元素 ---
print("\n=== 修改元素 ===")

scores = [85, 90, 78, 92]
print("初始成绩：", scores)
scores[2] = 88  # 把索引2的78改成88
print("修改后：", scores)

# --- 4. 项目：待办事项小程序 ---
print("\n=== 📋 待办事项小程序 ===")

todos = []

# 添加待办
todos.append("写语文作业")
todos.append("复习英语单词")
todos.append("做数学练习")
print("我的待办事项：")
for i, task in enumerate(todos):
    print(f"  {i + 1}. {task}")

# 完成一件事
done = todos.pop(0)  # 完成第一件事
print(f"\n✅ 完成了：{done}")
print("剩余待办：", todos)

# 插入紧急事项
todos.insert(0, "给妈妈打电话")
print("\n⚠️ 加入紧急事项后：", todos)

# 修改一件事
todos[1] = "做数学试卷（加量了！）"
print("修改后：", todos)

print(f"\n还有 {len(todos)} 件事要做，加油！💪")
```

## ✏️ 课堂练习

### 基础练习
1. **购物清单增删**：创建一个购物清单，先 `append` 3 样东西，再 `insert` 1 样到最前面，然后用 `remove` 删掉 1 样，最后打印清单。
2. **成绩修改**：创建一个成绩列表 `[88, 92, 75, 96, 83]`，把不及格的 75 改成 80，打印修改后的列表。
3. **pop vs remove**：创建一个列表，分别用 `pop()`、`pop(0)`、`remove()` 删除元素，观察它们的不同。

### 挑战练习
1. **排队游戏**：创建一个队列 `["小明", "小红", "小刚", "小丽"]`，模拟"第一个人办完事离开（pop(0)）"，然后"新来一个人排队（append）"，重复 3 次，观察队列变化。
2. **去重小助手**：列表中有重复元素 `["苹果", "香蕉", "苹果", "橘子", "香蕉"]`，用学过的知识去掉所有"苹果"（提示：用 while 循环 + in 判断）。

## 📋 小结

### 本节学了什么
- **增**：`append(元素)` 加末尾，`insert(位置, 元素)` 插中间
- **删**：`remove(值)` 按值删，`pop(索引)` 按位删（可返回），`del 列表[索引]` 直接删
- **改**：`列表[索引] = 新值` 直接替换
- **查**：用索引访问，用 `in` 判断是否存在，用 `index()` 找位置

### 记忆口诀
- "append 末尾加，insert 中间插"
- "remove 按值删，pop 弹出来，del 直接杀"
- "索引赋值就能改，in 判断在不在"
