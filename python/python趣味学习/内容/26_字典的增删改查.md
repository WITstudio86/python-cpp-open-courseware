# 第26节：字典的增删改查

## 🎯 教学目标
- 学生能够向字典添加新键值对和修改已有值
- 学生能够使用 `del` 删除字典中的键值对
- 学生能够使用 `.get()` 方法安全地访问字典
- 学生能够使用 `.keys()`、`.values()`、`.items()` 遍历字典
- 学生能够完成"升级版英汉词典"项目

## 📝 重点概念
- **get() 安全访问**：用 `[]` 访问不存在的 key 会报错，用 `.get()` 可以安全访问，还能设置默认值
- **keys() / values() / items()**：三种遍历字典的方式，分别看标签、看内容、看全部
- **del 删除**：删除指定的键值对

## 📖 讲解内容

### 步骤1：引入（5分钟）

"上节课我们学会了创建字典和基本的访问。今天我们要让字典操作更灵活、更安全。"

**情景**：你做了一个英汉词典程序，用户输入一个词查询。但如果用户输入了一个不存在的词怎么办？程序会崩溃！

```python
dict_cn_en = {"apple": "苹果"}
print(dict_cn_en["banana"])  # KeyError! 程序崩溃！
```

"所以我们需要一种**安全**的访问方式——`.get()` 方法来拯救我们！"

### 步骤2：核心讲解（15-20分钟）

#### 2.1 添加和修改（复习+深入）

```python
student = {"姓名": "小明", "年龄": 12}

# 添加：key 不存在 → 添加
student["班级"] = "五年级"

# 修改：key 存在 → 修改
student["年龄"] = 13

print(student)  # {'姓名': '小明', '年龄': 13, '班级': '五年级'}
```

#### 2.2 删除键值对：del

```python
student = {"姓名": "小明", "年龄": 12, "班级": "五年级", "爱好": "编程"}

del student["爱好"]
print(student)  # {'姓名': '小明', '年龄': 12, '班级': '五年级'}

# 删除不存在的 key 会报错！
# del student["身高"]  # KeyError!
```

**安全删除**：删除前先判断 key 是否存在。

```python
key = "爱好"
if key in student:
    del student[key]
else:
    print(f"字典中没有 {key}")
```

#### 2.3 安全访问：get() 方法

```python
student = {"姓名": "小明", "年龄": 12}

# 方式一：[] 访问（不安全）
# print(student["身高"])  # 报错！KeyError

# 方式二：.get() 访问（安全）
print(student.get("身高"))          # None —— 没有就返回空
print(student.get("身高", "未知"))  # 未知 —— 没有就返回默认值
print(student.get("姓名", "未知"))  # 小明 —— 有就正常返回
```

**get(键, 默认值)**：如果键存在返回对应值，不存在返回默认值。

#### 2.4 遍历字典的三种方式

```python
student = {"姓名": "小明", "年龄": 12, "班级": "五年级"}

# 方式一：遍历所有的键（keys）
print("所有的键：")
for key in student.keys():
    print("  ", key)

# 方式二：遍历所有的值（values）
print("所有的值：")
for value in student.values():
    print("  ", value)

# 方式三：遍历键和值（items）—— 最常用！
print("全部信息：")
for key, value in student.items():
    print(f"  {key} -> {value}")
```

### 步骤3：动手演示（10分钟）

**升级版英汉词典**：

```python
# 升级版英汉词典
dict_cn_en = {
    "apple": "苹果",
    "banana": "香蕉",
    "cat": "猫"
}

while True:
    print("\n=== 英汉词典 ===")
    print("1. 查词")
    print("2. 添加新词")
    print("3. 删除词条")
    print("4. 显示所有词条")
    print("5. 退出")
    
    choice = input("请选择 (1-5): ")
    
    if choice == "1":
        word = input("输入英文单词: ")
        meaning = dict_cn_en.get(word, "词典中没有这个词")
        print(f"{word} = {meaning}")
    
    elif choice == "2":
        word = input("输入英文单词: ")
        meaning = input("输入中文含义: ")
        dict_cn_en[word] = meaning
        print("添加成功！")
    
    elif choice == "3":
        word = input("输入要删除的单词: ")
        if word in dict_cn_en:
            del dict_cn_en[word]
            print("删除成功！")
        else:
            print("词典中没有这个词！")
    
    elif choice == "4":
        for en, cn in dict_cn_en.items():
            print(f"  {en} → {cn}")
    
    elif choice == "5":
        print("再见！")
        break
```

## 💻 代码示例

```python
# ========== 第26节：字典的增删改查 ==========

# --- 1. 添加和修改 ---
print("=== 添加和修改 ===")

hero = {"名字": "钢铁侠", "能力": "飞行"}
print("初始：", hero)

# 添加新键值对
hero["武器"] = "掌心炮"
hero["队友"] = "蜘蛛侠"
print("添加后：", hero)

# 修改已有值
hero["能力"] = "超强飞行 + 战斗"
print("修改后：", hero)

# --- 2. 删除 ---
print("\n=== 删除键值对 ===")

hero = {"名字": "钢铁侠", "能力": "飞行", "武器": "掌心炮"}
print("初始：", hero)

del hero["武器"]
print("删除'武器'后：", hero)

# 安全删除
key_to_delete = "队友"
if key_to_delete in hero:
    del hero[key_to_delete]
    print(f"已删除 {key_to_delete}")
else:
    print(f"没有 {key_to_delete} 这个信息，无法删除")

# --- 3. .get() 安全访问 ---
print("\n=== .get() 安全访问 ===")

hero = {"名字": "钢铁侠", "能力": "飞行"}

# 访问存在的 key
print("名字：", hero.get("名字", "未知"))
print("能力：", hero.get("能力", "未知"))

# 访问不存在的 key
print("年龄：", hero.get("年龄", "保密"))    # 返回默认值
print("身高：", hero.get("身高"))             # 不写默认值返回 None

# --- 4. 遍历字典 ---
print("\n=== 遍历字典 ===")

student = {
    "姓名": "小明",
    "年龄": 12,
    "班级": "五年级3班",
    "爱好": "编程"
}

# 只遍历键
print("所有键：")
for k in student.keys():
    print(f"  - {k}")

# 只遍历值
print("所有值：")
for v in student.values():
    print(f"  - {v}")

# 遍历键和值（最常用）
print("完整信息：")
for k, v in student.items():
    print(f"  {k:10s} → {v}")

# --- 5. 综合项目：升级版英汉词典 ---
print("\n=== 📖 升级版英汉词典 ===")

dictionary = {
    "apple": "苹果",
    "banana": "香蕉",
    "cat": "猫",
    "dog": "狗",
    "hello": "你好",
    "book": "书"
}

while True:
    print("\n" + "=" * 30)
    print("   📖 我的英汉词典")
    print("=" * 30)
    print("  1. 📝 查单词")
    print("  2. ➕ 添加单词")
    print("  3. ➖ 删除单词")
    print("  4. 📋 查看所有单词")
    print("  5. 🚪 退出程序")
    print("=" * 30)
    
    choice = input("请选择 (1-5): ").strip()
    
    if choice == "1":
        word = input("输入要查的英文单词: ").strip().lower()
        meaning = dictionary.get(word)
        if meaning:
            print(f"✅ {word} = {meaning}")
        else:
            print(f"❌ 词典中还没有「{word}」")
    
    elif choice == "2":
        word = input("输入新英文单词: ").strip().lower()
        if word in dictionary:
            print(f"⚠️ 「{word}」已存在，意思是：{dictionary[word]}")
            confirm = input("要修改吗？(y/n): ").strip().lower()
            if confirm == "y":
                meaning = input("输入新的中文含义: ").strip()
                dictionary[word] = meaning
                print("✅ 修改成功！")
        else:
            meaning = input("输入中文含义: ").strip()
            dictionary[word] = meaning
            print("✅ 添加成功！")
    
    elif choice == "3":
        word = input("输入要删除的英文单词: ").strip().lower()
        if word in dictionary:
            del dictionary[word]
            print(f"✅ 已删除「{word}」")
        else:
            print(f"❌ 词典中没有「{word}」")
    
    elif choice == "4":
        if len(dictionary) == 0:
            print("词典为空，先添加一些单词吧！")
        else:
            print(f"\n共有 {len(dictionary)} 个词条：")
            print("-" * 20)
            for en, cn in dictionary.items():
                print(f"  📝 {en:15s} → {cn}")
    
    elif choice == "5":
        print("再见！👋")
        break
    
    else:
        print("输入有误，请输入 1-5 之间的数字。")

# --- 6. 练习：统计词频 ---
print("\n=== 📊 练习：投票统计 ===")

votes = {}  # 空的投票箱

# 模拟投票
candidates = ["小明", "小红", "小明", "小刚", "小红", "小明", "小丽", "小红", "小明"]
for name in candidates:
    if name in votes:
        votes[name] += 1
    else:
        votes[name] = 1

print("投票结果：")
for name, count in votes.items():
    print(f"  {name}: {count} 票")
```

## 📋 小结

### 本节学了什么
- **添加/修改**：`dict[key] = value`，key 存在则修改，不存在则添加
- **删除**：`del dict[key]`，建议先 `in` 判断再删除
- **安全访问**：`dict.get(key, default)` 不会报错，可设默认值
- **遍历**：`.keys()` 看键、`.values()` 看值、`.items()` 看全部

### 记忆口诀
- "赋值键值对，有则改无则添"
- "get 访问最安全，没有就回默认值"
- "keys 是标签，values 是内容，items 两者一起看"
