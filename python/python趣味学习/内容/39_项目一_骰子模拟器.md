## 🎯 教学目标
- 学生能够使用 `random.randint()` 和 `random.choice()` 生成随机数
- 学生能够使用 `while` 循环实现程序的持续运行与退出控制
- 学生能够使用字符串格式化 `f-string` 输出美观的结果
- 学生能够独立完成一个完整的骰子模拟器小项目

## 📝 重点概念
- **随机数（Random Number）**：计算机用数学算法生成的"假装随机"的数字，就像抽签一样不可预测
- **`random.randint(a, b)`**：生成 a 到 b 之间（包含两端）的随机整数，就像在一个范围内抽一张号码牌
- **`random.choice(列表)`**：从一个列表中随机挑选一个元素，就像闭着眼睛从盒子里摸一个东西
- **while 循环**：只要条件成立就一直重复执行，就像"不写完作业就不能玩游戏"
- **f-string 格式化**：用 `f"文字{变量}文字"` 的方式把变量优雅地嵌入到句子中

### 步骤2：核心讲解（15-20分钟）

#### 2.1 认识 random 模块

```python
import random  # 把"随机魔法袋"拿过来
```

`random.randint(a, b)` — "兰德因特"（随机整数）

想象你在玩一个抽奖箱，箱子里的号码从 a 到 b。`randint` 就是把手伸进去，摸出一个号码。

```python
number = random.randint(1, 6)  # 从1到6中随机抽一个数
print(number)  # 可能是 1、2、3、4、5 或 6，每次都不一样！
```

`random.choice(列表)` — "抽一个"

想象你有一个水果篮，里面有苹果、香蕉、橘子。`choice` 就是闭着眼睛从篮子里摸一个。

```python
fruits = ["苹果", "香蕉", "橘子"]
result = random.choice(fruits)
print(result)  # 随机打印苹果、香蕉或橘子中的某一个
```

#### 2.2 while 循环控制继续/退出

生活比喻：**while 循环就像自动门**。只要有人站在门前（条件为真），门就一直开着（循环一直转）；人走了（条件变为假），门就关了（循环结束）。

```python
playing = True  # 一扇"正在玩"的开关，一开始是开着的

while playing:  # 只要开关开着，就一直循环
    print("游戏进行中...")
    answer = input("还要继续吗？(y/n): ")
    if answer == "n":
        playing = False  # 把开关关上，循环就结束了

print("游戏结束，再见！")
```

关键要点：
- `while` 后面跟一个条件，条件为 `True` 就一直循环
- 循环体里面的代码要缩进（按 Tab 键或 4 个空格）
- 一定要有一个"退出机制"，否则就会变成"无限循环"，程序停不下来！

#### 2.3 f-string 字符串格式化

```python
name = "小明"
score = 6
print(f"恭喜{name}！你掷出了 {score} 点！")
# 输出：恭喜小明！你掷出了 6 点！
```

f-string 就像一个"填空模板"：
- 以字母 `f` 开头
- 花括号 `{}` 里面放变量名
- Python 会自动把变量的值填进去

## 💻 代码示例

### 基础版：简单的骰子模拟器

```python
"""
骰子模拟器 —— 基础版
作者：Python 小课堂
功能：输入"摇"掷骰子，输入"退出"结束游戏
"""

import random  # 导入随机数模块

# 打印欢迎界面
print("=" * 30)
print("      🎲 骰子模拟器 🎲")
print("=" * 30)
print("规则：输入'摇'掷骰子，输入'退出'结束游戏")

# 游戏主循环
playing = True  # 游戏开关，True 表示正在玩

while playing:
    # 获取用户输入
    user_input = input("\n👉 请输入指令：")
    
    # 判断用户想做什么
    if user_input == "摇":
        # 随机生成 1-6 之间的整数
        number = random.randint(1, 6)
        # 用 f-string 格式化输出结果
        print(f"🎲 你掷出了：{number} 点！")
        
        # 询问是否继续
        again = input("还摇吗？(y/n)：")
        if again.lower() == "n":
            playing = False  # 退出循环
            
    elif user_input == "退出":
        playing = False  # 退出循环
        
    else:
        print("❓ 输入有误，请输入'摇'或'退出'")

# 循环结束后打印告别语
print("\n感谢使用骰子模拟器，再见！👋")
```

### 进阶版：带统计功能的骰子模拟器

```python
"""
骰子模拟器 —— 进阶版
功能：掷骰子 + 统计记录 + 历史查看
"""

import random

# 欢迎界面
print("=" * 35)
print("       🎲 骰子模拟器（进阶版）🎲")
print("=" * 35)

# 用列表记录每次掷骰子的结果
history = []
# 骰子点数对应的符号
dice_faces = ["⚀", "⚁", "⚂", "⚃", "⚄", "⚅"]

playing = True

while playing:
    print("\n" + "-" * 25)
    print("菜单：")
    print("  1. 摇骰子")
    print("  2. 查看历史记录")
    print("  3. 退出")
    print("-" * 25)
    
    choice = input("请选择（1/2/3）：")
    
    if choice == "1":
        # 摇骰子
        number = random.randint(1, 6)
        history.append(number)  # 把结果加入历史记录
        print(f"🎲 {dice_faces[number - 1]} 掷出了：{number} 点！")
        print(f"📊 你已经摇了 {len(history)} 次骰子了")
        
    elif choice == "2":
        # 查看历史
        if len(history) == 0:
            print("📭 还没有摇过骰子哦，先去摇一摇吧！")
        else:
            print(f"📋 历史记录（共 {len(history)} 次）：")
            for i, result in enumerate(history, start=1):
                print(f"  第{i}次：{dice_faces[result - 1]} {result} 点")
            # 统计信息
            print(f"📊 平均点数：{sum(history) / len(history):.1f}")
            print(f"📊 最大点数：{max(history)}，最小点数：{min(history)}")
            
    elif choice == "3":
        print("感谢使用，再见！👋")
        playing = False
        
    else:
        print("❓ 输入错误，请输入 1、2 或 3")
```
