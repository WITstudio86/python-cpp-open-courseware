# 第16节：for 循环初步

## 🎯 教学目标
- 学生能够理解循环的概念：让程序重复执行一段代码
- 学生能够掌握 for 循环的基本语法
- 学生能够用 for 循环遍历字符串和列表

## 📝 重点概念
- **循环**：让一段代码重复执行。就像跑步的"跑圈"，一圈又一圈
- **for 循环**：Python 中最常用的循环，用于逐个取出序列中的元素
- **遍历**：逐个访问序列中的每一个元素。遍历字符串就是逐个取出每个字符
- **循环体**：for 下面缩进的代码块，每次循环都会执行一遍
- **循环变量**：每次循环时代表当前元素的变量，名字可以自己取

"再比如，妈妈让你把购物清单上的东西一个一个拿出来。你不会一次性全掏出来，而是一件一件拿。这也是循环！"

"Python 的 for 循环，就是帮我们一件一件处理数据的好帮手。"

**互动**：让同学举生活中的循环例子
- 一周七天，每天上学
- 吃饭一口一口吃
- 抄写生字，每个字写一行

### 步骤2：核心讲解（15-20分钟）

**1. for 循环基本语法（8分钟）**

```python
# 遍历字符串：逐个打印每个字
name = "小明爱编程"
for char in name:
    print(char)
# 输出：
# 小
# 明
# 爱
# 编
# 程
```

**结构解释**：
- `for`：关键字，表示"对于"
- `char`：循环变量（可以取任何名字），代表每次循环拿到的元素
- `in`：关键字，表示"在...里面"
- `name`：要被遍历的序列（字符串、列表等）
- `:`：冒号不能忘！
- 缩进的代码块：循环体，每次循环都执行

**2. 遍历字符串（5分钟）**

```python
# 例子1：逐个打印
word = "Hello"
for c in word:
    print(c)

# 例子2：打印带编号
word = "Python"
num = 1
for c in word:
    print(f"第{num}个字母：{c}")
    num += 1

# 例子3：打印每个字
sentence = "我爱编程"
for zi in sentence:
    print(f"→ {zi}")
```

**3. 遍历列表（5分钟）**

```python
# 遍历数字列表
scores = [95, 88, 76, 92, 100]
for s in scores:
    print(f"分数：{s}")
    if s >= 90:
        print("  → 优秀！")

# 遍历名字列表
friends = ["小明", "小红", "小刚", "小丽"]
for name in friends:
    print(f"你好，{name}！")
```

**4. 缩进规则（2分钟）**

```python
# ❌ 错误：没缩进
for x in "abc":
print(x)

# ❌ 错误：部分代码没缩进
for x in "abc":
    print("开始")
print(x)  # 这行没缩进，不在循环里

# ✅ 正确
for x in "abc":
    print("开始")
    print(x)
    print("结束")
```

### 步骤3：动手演示（10分钟）

**演示1：逐个打印名字**

```python
name = input("请输入你的名字：")
print(f"'{name}' 的每个字是：")
for zi in name:
    print(f"  → {zi}")
```

**演示2：遍历水果列表**

```python
fruits = ["苹果", "香蕉", "橘子", "葡萄", "西瓜"]
for fruit in fruits:
    print(f"我喜欢吃{fruit}！")
```

**演示3：在循环中用 if**

```python
numbers = [12, 7, 25, 8, 19, 3, 30]
for n in numbers:
    if n > 10:
        print(f"{n} 大于 10")
    else:
        print(f"{n} 不大于 10")
```

## ✏️ 课堂练习

1. **基础练习**：输入自己的名字，用 for 循环逐个打印名字的每个字
2. **应用练习**：创建一个颜色列表 ["红色", "蓝色", "绿色", "黄色"]，用 for 循环打印"XX 是我喜欢的颜色"
3. **挑战练习**：创建一个数字列表，用 for 循环找出里面所有的偶数并打印

## 📋 小结
- for 循环用来逐个处理序列中的元素
- for + 循环变量 + in + 序列 + 冒号，下面缩进写循环体
- 可以遍历字符串（逐字）、遍历列表（逐个元素）
- 循环体里面可以写任何代码，包括 if 判断
- 缩进决定了哪些代码属于循环

**下节预告**：for 循环需要一个好搭档——range()，它可以方便地生成一系列数字！
