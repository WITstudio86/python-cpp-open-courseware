# 第33节：认识 Turtle，让海龟动起来！

## 🎯 教学目标
- 学生能够说出 Turtle 库是什么，理解"海龟绘图"的基本概念
- 学生能够正确导入 turtle 模块并创建画布窗口
- 学生能够使用 `.forward()`、`.backward()`、`.right()`、`.left()` 控制海龟移动
- 学生能够使用 `.done()` 保持窗口不关闭
- 学生能够独立编写代码让海龟走一个正方形

## 📝 重点概念
- **Turtle（海龟绘图）**：Python 自带的一个绘图工具，想象你有一只小海龟，它嘴里叼着一支笔，你给它指令让它往前走、往后退、转弯，它就会在纸上画出线条来
- **画布（Canvas）**：海龟画画的那张"纸"，当你运行 turtle 程序时会自动弹出一个窗口，这就是画布
- **坐标和方向**：海龟一开始在画布的正中央，头朝右（东方向）。往前（forward）就是朝头的方向走，右转（right）就是顺时针旋转
- **像素（Pixel）**：电脑屏幕上距离的单位，forward(100) 就是往前走 100 个像素，大约是你屏幕上 2-3 厘米的距离

### 步骤2：核心讲解（15-20分钟）

#### 2.1 如何召唤小海龟

在 Python 中，Turtle 是一个内置库，也就是说你不需要额外安装，直接在代码里写 `import turtle` 就能召唤它了。

```python
import turtle  # 召唤小海龟！就像喊一声"小海龟，出来吧！"
```

运行这行代码后，什么也没发生？别急，这只是告诉 Python"我要用海龟了"，但还没让它做任何事情。

#### 2.2 创建画布——海龟的画画纸

光有海龟还不够，还需要一张纸让它画画，对吧？我们用 `.Screen()` 来设置画布：

```python
import turtle

screen = turtle.Screen()     # 创建一个画布，这就是海龟的画纸
screen.title("我的第一幅画")   # 给画纸起个名字，它会显示在窗口标题栏
screen.bgcolor("white")      # 把画纸涂成白色背景，当然你也可以选别的颜色
```

#### 2.3 看一看我们的小海龟

```python
t = turtle.Turtle()  # 创建一只海龟，取名叫 t
t.shape("turtle")    # 让它的样子变成一只真正的海龟形状（默认是一个小三角箭头）
```

现在运行代码，你应该能看到一个窗口弹出来，中间有一只小海龟！它正朝着右方（东方），等待着你的命令。

**比喻**：想象你有一只宠物海龟，它站在一张大白纸的正中央，头朝右边，嘴里叼着一支笔。接下来，你就要用代码来"指挥"这只海龟了。

#### 2.4 指挥海龟走路

海龟能听懂的四个基本命令：

| 命令 | 含义 | 类比 |
|------|------|------|
| `t.forward(距离)` | 朝头朝向的方向前进 | "小海龟，往前走 100 步！" |
| `t.backward(距离)` | 朝头朝向的反方向后退 | "小海龟，往后退 50 步！" |
| `t.right(角度)` | 向右转（顺时针） | "小海龟，向右转 90 度！" |
| `t.left(角度)` | 向左转（逆时针） | "小海龟，向左转 90 度！" |

**重要**：海龟"转弯"的时候只在原地转动方向，并不会一边走一边画线。只有前进或后退的时候才会留下线条。

#### 2.5 不让窗口消失

如果你直接运行 turtle 代码，画完后窗口可能会"闪一下"就消失了。我们需要在代码最后加上一句：

```python
turtle.done()  # 告诉程序："画完啦，但别关窗口，让我欣赏一下！"
```

加上这行代码后，窗口会一直保持打开状态，直到你手动点击关闭按钮。

### 步骤3：动手演示（10分钟）

老师现在来演示一下，让海龟画一个正方形。大家先想一想：正方形有几条边？（4 条）每个角是多少度？（90 度）

画正方形的思路：
1. 往前走一段距离（比如 100 像素），画第一条边
2. 向右转 90 度，让海龟面向下一条边的方向
3. 再往前走同样的距离，画第二条边
4. 再向右转 90 度
5. 重复以上步骤，直到走完四条边

**教师演示步骤**：
1. 打开 Python IDLE 或编辑器
2. 逐行输入代码，让学生观察每一步海龟的变化
3. 强调：海龟走完正方形后回到了起点，而且朝向也回到了原来的方向（朝右）

```python
import turtle

# 画布设置
screen = turtle.Screen()
screen.title("海龟画正方形")
screen.bgcolor("lightyellow")  # 淡黄色的画纸

# 创建海龟
t = turtle.Turtle()
t.shape("turtle")
t.pensize(3)       # 画笔粗一点，看得更清楚
t.color("blue")     # 用蓝色画

# 画正方形
t.forward(100)      # 第1条边：往前走100
t.right(90)         # 向右转90度
t.forward(100)      # 第2条边
t.right(90)
t.forward(100)      # 第3条边
t.right(90)
t.forward(100)      # 第4条边
t.right(90)

turtle.done()       # 保持窗口
```

提问学生：上面的代码里，`.right(90)` 出现了几次？（4次）`.forward(100)` 出现了几次？（4次）

## 💻 代码示例

### 示例1：基本移动演示

```python
# -*- coding: utf-8 -*-
"""
第33节：认识 Turtle，让海龟动起来
基本移动演示
"""

import turtle  # 召唤海龟模块

# ----- 设置画布 -----
screen = turtle.Screen()
screen.title("海龟基本移动演示")
screen.bgcolor("lightblue")  # 浅蓝色背景，像大海！

# ----- 创建小海龟 -----
t = turtle.Turtle()
t.shape("turtle")     # 让小海龟看起来像一只真的海龟
t.pensize(4)          # 画笔粗细设为4，线条清楚
t.color("darkgreen")   # 用深绿色画画

# ----- 指挥海龟走路 -----
print("小海龟开始走路啦！")

# 往前走100像素
t.forward(100)

# 向右转90度，再走50像素
t.right(90)
t.forward(50)

# 向左转90度，再走80像素
t.left(90)
t.forward(80)

# 后退100像素（头朝原来的方向，但是倒退走）
t.backward(100)

# 转半圈（180度）
t.right(180)
t.forward(150)

print("小海龟走完啦！")

# ----- 保持窗口 -----
turtle.done()
```

### 示例2：画正方形（带详细注释）

```python
# -*- coding: utf-8 -*-
"""
第33节：用 Turtle 画一个正方形
"""

import turtle

# 设置舞台
screen = turtle.Screen()
screen.title("海龟画正方形")
screen.bgcolor("mistyrose")  # 薄雾玫瑰色，很漂亮！

# 创造小海龟
t = turtle.Turtle()
t.shape("turtle")
t.pensize(3)
t.color("purple")   # 紫色画笔
t.speed(3)          # 速度设为3（1最慢，10最快），方便观察

# 画正方形啦！
# 正方形有4条边，每条边一样长，每个角90度
side_length = 120  # 用变量存储边长，方便修改

t.forward(side_length)   # 边1：朝右，走120
t.right(90)              # 右转，面朝下
t.forward(side_length)   # 边2：朝下，走120
t.right(90)              # 右转，面朝左
t.forward(side_length)   # 边3：朝左，走120
t.right(90)              # 右转，面朝上
t.forward(side_length)   # 边4：朝上，走120
t.right(90)              # 右转，回到最初面向（朝右）

# 完成啦！
# 在正方形中心写个标签
t.penup()                # 抬笔，不画线
t.goto(-40, -10)         # 移动到正方形内部
t.write("正方形", font=("Arial", 16, "bold"))  # 写上文字

turtle.done()
```

### 示例3：长方形挑战

```python
# -*- coding: utf-8 -*-
"""
画一个长方形
长方形的对边相等，相邻的边不一样长
"""

import turtle

screen = turtle.Screen()
screen.title("海龟画长方形")
screen.bgcolor("lightcyan")

t = turtle.Turtle()
t.shape("turtle")
t.pensize(3)
t.color("darkorange")

# 长方形的长是160，宽是80
length = 160  # 长边
width = 80    # 短边

# 画长方形：长-转-宽-转-长-转-宽-转
t.forward(length)   # 长边
t.right(90)
t.forward(width)    # 宽边
t.right(90)
t.forward(length)   # 长边
t.right(90)
t.forward(width)    # 宽边
t.right(90)

turtle.done()
```
