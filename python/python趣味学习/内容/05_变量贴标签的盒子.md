# 第5节：变量 —— 贴标签的盒子

## 教学目标
- 学生能够理解变量的概念：一个有名字的"存储盒子"
- 学生能够使用 `=` 进行赋值操作
- 学生能够遵守变量命名规则，区分好名字和坏名字
- 学生能够识别 Python 关键字，避免用关键字作为变量名
- 学生理解 Python 变量不需要声明类型，一个变量可以被赋值为不同类型的数据

## 重点概念
- **变量（Variable）**：变量就像一个贴了标签的盒子。标签就是变量名（比如 `name`、`age`），盒子里装的就是数据（比如 `"小明"`、`10`）。你可以随时打开盒子看看里面有什么，也可以把旧东西倒出来换新东西进去。
- **赋值（Assignment）**：用等号 `=` 把数据"放"到变量里。写法：`变量名 = 值`。注意：在编程里，`=` 不是"等于"的意思，而是"把右边的值放进左边的盒子"的意思。
- **变量名规则**：只能用字母、数字和下划线 `_`，而且不能以数字开头。大小写敏感（`name` 和 `Name` 是两个不同的盒子）。
- **关键字（Keyword）**：Python 保留了一些特殊的词（如 `if`、`for`、`while`、`print`、`input` 等），这些词有特殊用途，不能用来当变量名。
- **动态类型（Dynamic Typing）**：Python 的变量很灵活，同一个变量可以先装一个数字，再装一段文字，再装一个列表——不需要提前声明"这个盒子只能装数字"。

## 讲解内容

### 步骤1：引入（5分钟）

**实物演示（强烈建议！）：**

老师准备几个小纸盒和便利贴，演示变量的概念：

1. 拿一个空纸盒，在上面贴一张便利贴，写上 `name`
2. 往盒子里放一张纸条，上面写着"小明"
3. 告诉学生："这个盒子就叫 `name`，里面装的是 `"小明"`"
4. 再拿一张新纸条写上"小红"，把旧纸条拿出来，新纸条放进去
5. "瞧！`name` 这个盒子还是同一个盒子，但里面的内容变了！"

**代码类比：**
```python
name = "小明"    # 创建盒子"name"，放入"小明"
print(name)      # 打开盒子看看：小明
name = "小红"    # 换新的内容进去
print(name)      # 打开盒子再看看：变成了小红！
```

"这就是变量！一个贴了标签的盒子，标签不变，但里面的东西可以换。就像你的铅笔盒——今天装红笔，明天装蓝笔，但它永远是'你的铅笔盒'。"

### 步骤2：核心讲解（15-20分钟）

#### 2.1 变量是什么？为什么要用变量？

编程中经常需要"记住"一些信息。比如：
- 记住用户的名字
- 记住当前的分数
- 记住计算中的中间结果

如果没有变量，每次要用这些信息都得重新写一遍，非常麻烦。有了变量，存一次，用无数次。

**不用变量的世界（超级麻烦）：**
```python
print("小明")
print("小明")
print("小明")
# 如果想要改名字，三个地方都得改！
```

**有了变量的世界（轻松优雅）：**
```python
name = "小明"
print(name)
print(name)
print(name)
# 想改名字？只改一处就行！name = "小红"
```

#### 2.2 赋值：用 `=` 把东西放进盒子

在 Python 里，`=` 叫做**赋值运算符**。注意：它不是数学里的"等于号"，而是"把右边的值**赋予**左边"的意思。

**理解方向：永远从右往左读。**

```python
age = 10        # 读作："把数字 10 放到变量 age 里"
name = "小明"   # 读作："把文字 '小明' 放到变量 name 里"
score = 95      # 读作："把数字 95 放到变量 score 里"
```

**变量可以反复赋值：**
```python
x = 5
print(x)   # 输出：5
x = 10
print(x)   # 输出：10
x = x + 1
print(x)   # 输出：11 —— 先取出 x(10)，加 1 得 11，再放回 x
```

最后一行 `x = x + 1` 在数学里是"无解"的（一个数不可能等于自己加一），但在编程里非常常见！它的意思是：**把 x 盒子里的东西取出来，加上 1，再放回去。**

用盒子的比喻：你从标着 `x` 的盒子里拿出写着 10 的纸条，在旁边写上 11，然后把 11 放回盒子，撕掉旧的 10。

#### 2.3 变量命名规则

给变量取名就像给宠物起名字，有一定规矩，但也有很多自由。

**必须遵守的硬规则（违反会报错）：**

| 规则 | 正确示例 | 错误示例 | 原因 |
|------|----------|----------|------|
| 只能用字母、数字、下划线 `_` | `name`, `score1`, `my_age` | `my-name`, `姓名` | 连字符不行，中文字符不推荐（虽然 Python 3 支持但可能引起麻烦） |
| 不能以数字开头 | `age1`, `stu2` | `1age`, `2nd_place` | 以数字开头会让 Python 误以为是数字 |
| 区分大小写 | `Name`, `name`, `NAME` 是 **三个不同的变量** |
| 不能用 Python 关键字 | `student`, `my_if` | `if`, `for`, `print` | 这些词 Python 自己要用 |

**推荐的软规则（不遵守不会报错，但是好习惯）：**

1. **名字要有意义**：`age` 比 `a` 好，`student_name` 比 `sn` 好
2. **多个单词用下划线连接**：`my_score`（这叫蛇形命名法 snake_case）
3. **不要太长，也不要太短**：`s` 太短看不懂，`the_score_of_student_number_one` 太长打字累
4. **用英文或拼音**：`score` 或 `chengji` 都可以，但建议开始学着用英文

**好名字 vs 坏名字对比：**

```python
# 好名字 —— 一看就懂
student_name = "小明"
student_age = 10
math_score = 95
total_price = 128

# 坏名字 —— 猜不出啥意思
a = "小明"
b = 10
x1 = 95
tp = 128

# 更坏的 —— 莫名其妙
asdf = "小明"
qq = 10
```
#### 2.4 Python 变量不需要"声明类型"

在一些编程语言里，你创建一个变量时必须提前说好"这个盒子只能装整数"或"这个盒子只能装文字"。但 Python 不需要！

```python
x = 10           # x 现在是整数
print(x)         # 输出：10
x = "Hello"      # x 现在变成了字符串！完全没问题！
print(x)         # 输出：Hello
x = 3.14         # x 又变成了小数！Python 也不介意
print(x)         # 输出：3.14
```

**Python 的态度：** "你爱放什么放什么，我不管你。只要标签不重名就行。"

这叫做**动态类型**。优点是灵活方便，缺点是如果你不小心把数字变量改成了文字，可能导致后面的计算出错（需要自己注意）。

#### 2.5 Python 关键字 —— 这些词你不能用！

Python 有一些"保留字"，它们有特殊的语法功能，不能用来当变量名。如果硬要用，Python 会直接报错。

常见的 Python 关键字（不需要全部记住，知道有这回事就行）：

```
False, None, True, and, as, break, class, continue, def, 
elif, else, except, finally, for, from, if, import, in, 
is, lambda, not, or, pass, return, try, while, with
```

**特别注意**：`print`、`input`、`int`、`str`、`float`、`type` 虽然不是严格意义上的关键字，但它们是 Python 内置的函数名。如果你用它们当变量名，会"盖掉"原来的功能！

```python
# 危险操作！不要这样做！
print = "你好"      # 把 print 变成了一个普通变量！
print("Hello")      # 报错！因为 print 现在是一个字符串，不是函数了
```

如果不小心覆盖了，可以重启 IDLE 来恢复。

### 步骤3：动手演示（10分钟）

#### 演示1：变量的基本操作

```python
# 创建变量
name = "小华"
age = 11
height = 145.5
is_student = True    # True/False 是布尔值，后面会学

# 使用变量
print("姓名：", name)
print("年龄：", age)
print("身高：", height, "cm")

# 修改变量
age = age + 1        # 过了一年
print("过了一年，年龄变为：", age)

# 变量之间的赋值
new_name = name      # 把 name 盒子里的内容复制一份，放到 new_name 盒子里
print("new_name 里是：", new_name)
```

#### 演示2：变量交换 —— 经典小魔术

```python
# 交换两个变量的值 —— 就像左手和右手交换东西，需要第三只手帮忙
a = "苹果"
b = "香蕉"
print("交换前：a =", a, ", b =", b)

# 交换！
temp = a   # 第三只手临时拿着 a 的东西
a = b      # 把 b 的东西放到 a
b = temp   # 把临时拿着的放到 b

print("交换后：a =", a, ", b =", b)
```

（Python 其实有一个更酷的写法：`a, b = b, a`，一行搞定！可以给学得快的学生展示。）

#### 演示3：变量的命名验证

```python
# 在交互模式下测试哪些变量名合法
>>> my_name = "合法"     # ✓
>>> score1 = 100          # ✓
>>> _secret = "隐藏"      # ✓ 以下划线开头也可以
>>> 1st_place = "第一"    # ✗ 报错！不能以数字开头
>>> my-name = "连字符"    # ✗ 报错！减号不行
>>> if = 10               # ✗ 报错！if 是关键字
>>> print = "覆盖了"      # 不报错，但 print() 功能被破坏了！
```

## 代码示例

```python
# ========== 示例1：变量的基本操作 ==========
# 创建变量
player_name = "勇敢的小明"
player_health = 100
player_level = 1
player_gold = 50

# 打印玩家信息
print("=" * 30)
print("    🎮 游戏角色信息")
print("=" * 30)
print("角色名：", player_name)
print("生命值：", player_health)
print("等级：", player_level)
print("金币：", player_gold)

# 升级了！修改一些变量
player_level = player_level + 1     # 升了一级
player_health = player_health + 20  # 生命值增加
player_gold = player_gold + 100     # 获得金币奖励

print()
print("--- 升级后 ---")
print("等级：", player_level)
print("生命值：", player_health)
print("金币：", player_gold)

# ========== 示例2：变量交换的两种方法 ==========
a = "🍎苹果"
b = "🍌香蕉"
print("\n交换前：a =", a, ", b =", b)

# 方法一：使用临时变量（经典方法）
temp = a
a = b
b = temp
print("方法一交换后：a =", a, ", b =", b)

# 方法二：Python 特有的酷炫写法
a, b = b, a    # 一行搞定！
print("方法二再交换回来：a =", a, ", b =", b)

# ========== 示例3：好名字 vs 坏名字 ==========
# 好名字 —— 三个月后你还能看懂

english_exam_score = 92

# 计算总分和平均分
total_score = math_exam_score + english_exam_score

print("\n--- 成绩单 ---")
print("姓名：", student_name)
print("数学：", math_exam_score)
print("英语：", english_exam_score)
print("总分：", total_score)
print("平均分：", average_score)

# ========== 示例4：变量命名规则验证 ==========
print("\n--- 变量命名测试 ---")
# 合法变量名
player1 = "选手1号"
_hidden_treasure = "秘密宝藏"
score = 100
MAX_SIZE = 999      # 全大写通常表示"常量"（约定俗成，不会变的量）

print(player1, _hidden_treasure, score, MAX_SIZE)

# 如果取消下面任意一行的注释，就会报错：
# 2nd_player = "第二名"     # 不能以数字开头
```

## 小结

**本节学了什么：**
- 变量就像一个贴了标签的存储盒子，标签是变量名，盒子里装的是数据
- `=` 是赋值运算符，把右边的值放进左边的变量（从右往左读）
- 变量名规则：字母/数字/下划线，不能以数字开头，不能是 Python 关键字
- Python 是动态类型语言，变量不需要提前声明类型
- 取一个好名字（有意义、用下划线连接）比取一个短名字重要得多
- `x = x + 1` 这种写法在编程里很常见：取出、计算、放回
