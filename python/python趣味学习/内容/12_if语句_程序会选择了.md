# 第12节：if 语句 —— 程序会选择了

## 🎯 教学目标
- 学生能够理解 if 语句的作用：让程序根据条件做出选择
- 学生能够正确书写 if 语句的语法结构（if + 条件 + 冒号 + 缩进）
- 学生能够独立完成"及格判断器"小项目

## 📝 重点概念
- **if 语句**：让程序"做判断"的语句。如果条件成立，就执行里面的代码；不成立就跳过
- **缩进（indent）**：Python 的灵魂！if 下面要执行的代码必须缩进（通常 4 个空格或 1 个 Tab）
- **冒号**：if 条件后面一定要加冒号 `:`，不能忘！
- **条件**：if 后面跟的是一个能算出 True 或 False 的表达式（就是上节课学的比较运算符！）

## 📖 讲解内容

### 步骤1：引入（5分钟）

**故事引入**：
"想象一下，你早上起床，看看窗外——如果下雨，就带伞；如果不下雨，就不带伞。这就是生活中的'判断'。"

"再比如，妈妈跟你说：'如果考试及格了，就带你去吃大餐！'这里的'如果...就...'就是条件判断。"

"今天我们要学的 if 语句，就是让 Python 也学会'如果...就...'！"

**互动提问**：让学生说说生活中"如果...就..."的例子：
- 如果作业写完了，就可以玩游戏
- 如果肚子饿了，就去吃东西
- 如果红灯亮了，就要停下来

### 步骤2：核心讲解（15-20分钟）

**1. if 语句的基本结构（10分钟）**

在黑板上写出 if 语句的"骨架"：

```python
if 条件:
    要做的事情
```

三点必须记住：
- `if` 关键字
- 条件后面有**冒号** `:`
- 下面要执行的代码要**缩进**（前面空 4 格）

**错误的写法对比**：

```python
# ❌ 错误1：忘记冒号
if score >= 60
    print("及格啦！")

# ❌ 错误2：忘记缩进
if score >= 60:
print("及格啦！")

# ❌ 错误3：缩进不一致
if score >= 60:
  print("及格啦！")
   print("太棒了！")  # 缩进不对齐！

# ✅ 正确写法
if score >= 60:
    print("及格啦！")
    print("太棒了！")
```

**2. 条件来自上节课的比较运算（5分钟）**

```python
score = 85

# 条件就是比较运算的结果
if score >= 60:        # 85 >= 60 是 True，所以执行
    print("及格啦！")

score = 55
if score >= 60:        # 55 >= 60 是 False，所以跳过
    print("及格啦！")  # 这句话不会被执行
```

**3. if 里面可以写多行（3分钟）**

```python
if score >= 90:
    print("太厉害了！")
    print("你是学霸！")
    print("奖励一个🍦")
# 这三行都缩进了，条件成立时都会执行
```

**4. if 外面的代码不受影响（2分钟）**

```python
score = 55
if score >= 60:
    print("及格啦！")     # 不执行
print("程序结束")          # 不管条件成不成立，这句话都执行
```

### 步骤3：动手演示（10分钟）

**演示1：最简单的 if 语句**

```python
# 及格判断器 1.0
score = 75
if score >= 60:
    print("及格啦！")
    print("继续加油！")
```

**演示2：分数不够的情况**

```python
score = 55
if score >= 60:
    print("及格啦！")
print("不管怎样，程序结束了")
# 55 < 60，所以"及格啦"不会打印
# 但"程序结束了"会打印，因为它没有缩进
```

**演示3：条件判断猜谜**

```python
age = 10
if age >= 6:
    print("你可以上小学了！")
if age >= 12:
    print("你可以上初中了！")
if age >= 18:
    print("你成年了！")
# 10岁：只满足第一个条件，所以只打印第一句
```

## 💻 代码示例

```python
# ======== 第12节：if 语句 ========

# 基本结构：if 条件:
#              要做的事情（注意缩进！）

score = 85
print("你的分数是：", score)

# 判断是否及格
if score >= 60:
    print("🎉 及格啦！")      # 条件成立，会执行
    print("继续努力哦！")      # 条件成立，也会执行

print("判断结束~")             # 没缩进，不管条件如何都会执行

# 再试一个不及格的情况
score2 = 55
print("\n你的分数是：", score2)

if score2 >= 60:
    print("🎉 及格啦！")      # 条件不成立，不会执行

print("判断结束~")             # 照样执行

# 多个 if 各自判断
age = 10
print(f"\n你今年 {age} 岁：")
if age >= 6:
    print("  → 可以上小学了")
if age >= 12:
    print("  → 可以上初中了")
if age >= 15:
    print("  → 可以上高中了")
if age >= 18:
    print("  → 成年了！")
```

## ✏️ 课堂练习

1. **基础练习**：修改代码中的分数，试试 100 分、60 分、59 分、0 分，看看哪些会显示"及格啦"
2. **动手练习**：写一个 if 语句，判断一个数字是否大于 10。如果大于 10，就打印"这个数大于10"
3. **挑战练习**：写一个"高温警报"程序——如果温度超过 35 度，就打印"太热了，注意防暑！"

## 📋 小结
- if 语句让程序能"做选择"
- 三个关键：if 关键字、条件后面的冒号、代码块的缩进
- 缩进是 Python 的灵魂，同一个 if 里面的代码要对齐
- 条件成立就执行缩进代码，不成立就跳过
- if 外面的代码（不缩进的）永远都会执行

**下节预告**：现在程序只会说"如果...就..."，但生活中往往是"如果...就...否则..."，下一节学习 if-else！
