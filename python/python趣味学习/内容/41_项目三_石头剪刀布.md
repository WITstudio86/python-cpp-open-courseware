# 第41节：项目三 —— 石头剪刀布

## 🎯 教学目标
- 学生能够用列表存储多个选项并灵活使用
- 学生能够使用 `random.choice()` 让电脑随机出拳
- 学生能够用 `if-elif-else` 多分支结构判断输赢
- 学生能够设计和实现计分系统完成三局两胜

## 📝 重点概念
- **列表存选项**：把所有可能的选择放在一个列表里，就像把石头、剪刀、布三张牌放口袋里
- **`random.choice()`**：让电脑从选项中随机选一个，模拟"电脑出拳"
- **多分支判断**：用 `if-elif-else` 像树枝分叉一样，判断每一种可能的情况
- **计分系统**：用变量累计分数，判断谁先达到获胜条件

## 📖 讲解内容

- "如果让你跟电脑玩呢？电脑怎么'出拳'？" → 需要随机！
- "三局两胜是什么意思？" → 谁先赢两局谁就获胜

生活比喻：**判断输赢就像查一个"胜负对照表"**。你的出法和对手的出法一对，就知道结果。Python 的 `if-elif-else` 就是这个"自动查表员"。

还有另一个比喻：**电脑出拳就像抽奖**。把"石头"、"剪刀"、"布"三张纸条放进一个盒子里，电脑就是从盒子里抽一张——这就是 `random.choice()` 做的事情。

### 步骤2：核心讲解（15-20分钟）

#### 2.1 用列表存储选项

```python
# 石头剪刀布的三种选择
choices = ["石头", "剪刀", "布"]

# 列表索引
# choices[0] → "石头"
# choices[1] → "剪刀"
# choices[2] → "布"
```

为什么要用列表？因为：
1. 方便管理——所有选项集中在一起
2. 可以用 `random.choice()` 直接从中抽取
3. 以后想加选项（比如"石头剪刀布蜥蜴史波克"），只需要修改列表

#### 2.2 电脑随机出拳

```python
import random

choices = ["石头", "剪刀", "布"]
computer = random.choice(choices)  # 电脑随机选一个
print(f"电脑出了：{computer}")
```

#### 2.3 判断输赢的 if-elif 逻辑

这是本节最核心的部分！我们要梳理出所有可能的情况：

**梳理胜负关系**（用石头剪刀布的口诀）：
- 石头 赢 剪刀（石头砸坏剪刀）
- 剪刀 赢 布（剪刀剪碎布）
- 布 赢 石头（布包住石头）
- 相同则是平局

**转换为 if-elif 代码**：

```python
# player 是玩家出的，computer 是电脑出的
if player == computer:
    result = "平局"
elif (player == "石头" and computer == "剪刀") or \
     (player == "剪刀" and computer == "布") or \
     (player == "布" and computer == "石头"):
    result = "你赢了！"
else:
    result = "电脑赢了！"
```

思路解析：
- 第一层 if：先判断是不是平局（最简单的情况）
- 第二层 elif：判断玩家赢的三种情况（用 `or` 连接）
- 第三层 else：剩下的就是电脑赢（不用再写了，因为只有三种可能）

生活比喻：**if-elif-else 就像过安检**
- if：你的身份证和本人对上 → 通过（平局）
- elif：你有特殊通行证 → 走绿色通道（你赢）
- else：其他所有人 → 走普通通道（电脑赢）

#### 2.4 计分系统与三局两胜

```python
player_score = 0   # 玩家得分
computer_score = 0  # 电脑得分
round_num = 1      # 当前第几局

# 三局两胜：有人先拿到 2 分就结束
while player_score < 2 and computer_score < 2:
    print(f"\n===== 第 {round_num} 局 =====")
    
    # ... 出拳和判断逻辑 ...
    
    if result == "你赢了！":
        player_score += 1
    elif result == "电脑赢了！":
        computer_score += 1
    # 平局不计分
    
    print(f"当前比分 → 你 {player_score} : {computer_score} 电脑")
    round_num += 1

# 宣布最终结果
if player_score == 2:
    print("🏆 恭喜你赢得了比赛！")
else:
    print("😢 电脑赢得了比赛，下次加油！")
```

关键点：
- 条件是 `player_score < 2 and computer_score < 2`，意思是"双方都没到 2 分"
- 平局不计分，但要继续打
- 每局结束显示实时比分，增加紧张感

## 💻 代码示例

### 基础版：石头剪刀布（三局两胜）

```python
"""
石头剪刀布 —— 基础版
规则：三局两胜制
"""

import random

# ── 初始化 ──
choices = ["石头", "剪刀", "布"]
player_score = 0      # 玩家得分
computer_score = 0    # 电脑得分
round_num = 1         # 当前局数

# ── 欢迎界面 ──
print("=" * 35)
print("     ✊ 石头 ✌️ 剪刀 ✋ 布")
print("=" * 35)
print("🏆 三局两胜制！谁先赢两局谁就是冠军！\n")

# ── 主循环：有人拿到 2 分就结束 ──
while player_score < 2 and computer_score < 2:
    print(f"\n{'=' * 30}")
    print(f"        第 {round_num} 局")
    print(f"{'=' * 30}")
    print(f"📊 当前比分：你 {player_score} : {computer_score} 电脑")
    
    # 显示选择菜单
    print("\n请出拳：")
    print("  1️⃣  石头 ✊")
    print("  2️⃣  剪刀 ✌️")
    print("  3️⃣  布 ✋")
    
    # 获取玩家出拳
    player_choice = input("👉 请输入数字（1-3）：").strip()
    
    # 数字转文字
    if player_choice == "1":
        player = "石头"
    elif player_choice == "2":
        player = "剪刀"
    elif player_choice == "3":
        player = "布"
    else:
        print("⚠️  输入有误，默认出「石头」")
        player = "石头"
    
    # 电脑随机出拳
    computer = random.choice(choices)
    
    # 显示双方出拳
    emoji_map = {"石头": "✊", "剪刀": "✌️", "布": "✋"}
    print(f"\n你  {emoji_map[player]}  ←→  {emoji_map[computer]}  电脑")
    print(f"你出了「{player}」，电脑出了「{computer}」")
    
    # ── 判断输赢 ──
    if player == computer:
        result = "平局"
        print("\n🤝 平局！这局不算，重新来过！")
        
    elif (player == "石头" and computer == "剪刀") or \
         (player == "剪刀" and computer == "布") or \
         (player == "布" and computer == "石头"):
        result = "玩家赢"
        player_score += 1
        print("\n🎉 这局你赢了！厉害！")
        
    else:
        result = "电脑赢"
        computer_score += 1
        print("\n💻 这局电脑赢了，加油！")
    
    # 只有非平局才进入下一局计数
    if result != "平局":
        round_num += 1

# ── 比赛结束，宣布结果 ──
print("\n" + "=" * 35)
print("          🏆 比赛结束！🏆")
print("=" * 35)
print(f"📊 最终比分：你 {player_score} : {computer_score} 电脑")

if player_score == 2:
    print("\n🎊 恭喜你！你赢得了三局两胜的冠军！")
    print("   你是石头剪刀布之王！👑")
else:
    print("\n💻 电脑获得了胜利！")
    print("   别灰心，下次一定赢！💪")

print("\n感谢游玩，再见！👋")
```

### 进阶版：带历史记录和胜率统计

```python
"""
石头剪刀布 —— 进阶版
新增：历史记录、胜率统计、自定义局数
"""

import random

# 选项和符号
choices = ["石头", "剪刀", "布"]
emoji_map = {"石头": "✊", "剪刀": "✌️", "布": "✋"}

print("=" * 40)
print("      ✊ 石头 ✌️ 剪刀 ✋ 布（进阶版）")
print("=" * 40)

# 让玩家选择比赛模式
print("\n请选择模式：")
print("  1. 三局两胜")
print("  2. 五局三胜")
print("  3. 自定义局数")
mode = input("👉 请选择（1/2/3）：")

if mode == "1":
    max_rounds = 3
    win_need = 2
elif mode == "2":
    max_rounds = 5
    win_need = 3
elif mode == "3":
    max_rounds = int(input("请输入总局数："))
    win_need = max_rounds // 2 + 1  # 需要超过一半的胜利
    print(f"→ {max_rounds}局{win_need}胜制")
else:
    print("默认三局两胜")
    max_rounds = 3
    win_need = 2

# 初始化
player_score = 0
computer_score = 0
history = []  # 记录每局：(局号, 玩家出拳, 电脑出拳, 结果)

round_num = 1
while player_score < win_need and computer_score < win_need:
    print(f"\n{'─' * 30}")
    print(f"第 {round_num} 局 | 比分：你 {player_score} : {computer_score} 电脑")
    print(f"{'─' * 30}")
    
    # 玩家出拳
    print("1.石头✊  2.剪刀✌️  3.布✋")
    choice_input = input("👉 出拳（1-3）：").strip()
    
    choice_dict = {"1": "石头", "2": "剪刀", "3": "布"}
    player = choice_dict.get(choice_input, random.choice(choices))
    
    if choice_input not in choice_dict:
        print(f"⚠️  输入有误，随机帮你出了「{player}」")
    
    # 电脑出拳
    computer = random.choice(choices)
    
    # 显示
    print(f"\n你 {emoji_map[player]}  ←VS→  {emoji_map[computer]} 电脑")
    
    # 判断
    if player == computer:
        result = "平局"
        print("🤝 平局！")
    elif (player == "石头" and computer == "剪刀") or \
         (player == "剪刀" and computer == "布") or \
         (player == "布" and computer == "石头"):
        result = "你赢"
        player_score += 1
        print("🎉 你赢了！")
    else:
        result = "电脑赢"
        computer_score += 1
        print("💻 电脑赢了！")
    
    # 记录历史
    history.append({
        "局号": round_num,
        "玩家": player,
        "电脑": computer,
        "结果": result
    })
    
    if result != "平局":
        round_num += 1

# ── 比赛结束 ──
print("\n" + "=" * 40)
print("            🏆 比赛结束 🏆")
print("=" * 40)

# 宣布结果
if player_score > computer_score:
    print(f"\n🎊 你以 {player_score}:{computer_score} 赢得了比赛！你是冠军！👑")
else:
    print(f"\n💻 电脑以 {computer_score}:{player_score} 赢得了比赛！下次加油！💪")

# 显示历史记录
print("\n📋 比赛记录：")
print("─" * 35)
for record in history:
    print(f"  第{record['局号']}局：{record['玩家']} VS {record['电脑']} → {record['结果']}")

# 统计
total = len([h for h in history if h['结果'] != '平局'])
wins = player_score
win_rate = wins / total * 100 if total > 0 else 0
print(f"\n📊 胜率统计：{wins}胜/{total}场 = {win_rate:.1f}%")
```
