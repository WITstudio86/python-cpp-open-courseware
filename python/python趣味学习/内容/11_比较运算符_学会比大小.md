# 第11节：比较运算符 —— 学会比大小

## 🎯 教学目标
- 学生能够使用 >、<、==、!=、>=、<= 比较数字和字符串的大小
- 学生能够理解比较运算的结果是 True 或 False（布尔值）
- 学生能够将比较运算符应用到实际生活场景中（比身高、比年龄等）

## 📝 重点概念
- **比较运算符**：用来比较两个值之间关系的符号，结果只有两种：成立（True）或不成立（False）
- **布尔值（bool）**：只有 True 和 False 两种值，就像开关只有"开"和"关"一样
- **> 和 <**：大于和小于，记住"开口朝大数"
- **== 和 !=**：等于和不等于。注意！== 是判断相等，= 是赋值，不要搞混！
- **>= 和 <=**：大于等于和小于等于，满足其中一个条件就为 True
- **字符串也能比较**：字符串按照字母表的顺序比较，"a" < "b" < "c" ...，"apple" < "banana"

## 📖 讲解内容

### 步骤1：引入（5分钟）
**生活场景导入**：
"小明和小红在比身高。小明 145cm，小红 150cm。谁更高？"

让同学们在脑子里判断：145 > 150？不对。145 < 150？对！

"生活中我们经常做比较：比身高、比年龄、比分数、比价格。今天我们就来学习 Python 是怎么做比较的！"

在黑板上写下所有的比较运算符，让学生猜每个符号的意思：
- `>` 大于
- `<` 小于
- `==` 等于
- `!=` 不等于
- `>=` 大于等于
- `<=` 小于等于

### 步骤2：核心讲解（15-20分钟）

**1. 数字比较（8分钟）**

逐一演示每个运算符：

```python
# 大于
print(10 > 5)    # True
print(3 > 8)     # False

# 小于
print(5 < 10)    # True
print(10 < 3)    # False

# 等于（注意：是两个等号！）
print(7 == 7)    # True
print(7 == 8)    # False

# 不等于
print(7 != 8)    # True
print(7 != 7)    # False

# 大于等于
print(10 >= 10)  # True（等于也算！）
print(10 >= 5)   # True
print(5 >= 10)   # False

# 小于等于
print(5 <= 5)    # True
print(5 <= 10)   # True
print(10 <= 5)   # False
```

**重点强调**：
- `=` 是一个等号，用来赋值：`age = 12`
- `==` 是两个等号，用来判断相等：`age == 12`
- 这是一个超级容易犯的错误！就像你写作业时把"等于号"写成了"赋值号"

**2. 字符串比较（5分钟）**

```python
# 字符串按字母顺序比较
print("apple" < "banana")   # True（a 在 b 前面）
print("cat" > "dog")        # False（c 在 d 前面）
print("hello" == "hello")   # True（完全相同）
print("Hello" == "hello")   # False（大小写不同！）
print("abc" < "abd")        # True（前两个字母相同，c < d）
```

讲解要点：
- 字符串比较是从左到右逐个字符比较的
- 大写字母和小写字母是不同的
- 中文也能比较，但规则比较复杂，我们暂时不深入研究

**3. 比较运算的结果（2分钟）**

```python
# 比较的结果可以存到变量里
result = 15 > 10
print(result)          # True
print(type(result))    # <class 'bool'>

# 布尔值只有两种
is_pass = 85 >= 60
print(is_pass)         # True
```

### 步骤3：动手演示（10分钟）

**演示1：比身高**
```python
xiaoming_height = 145
xiaohong_height = 150

print("小明比小红高吗？", xiaoming_height > xiaohong_height)   # False
print("小红比小明高吗？", xiaohong_height > xiaoming_height)    # True
print("他们一样高吗？", xiaoming_height == xiaohong_height)     # False
```

**演示2：比年龄**
```python
my_age = 11
friend_age = 12

print("我比朋友大吗？", my_age > friend_age)
print("朋友比我大吗？", friend_age > my_age)
print("我们同岁吗？", my_age == friend_age)
print("我至少10岁了吗？", my_age >= 10)
```

**演示3：判断及格**
```python
score = 75
pass_line = 60
print("及格了吗？", score >= pass_line)  # True

score = 55
print("及格了吗？", score >= pass_line)  # False
```

**演示4：变量之间的比较**
```python
a = 20
b = 15
c = 20

print("a > b:", a > b)    # True
print("a < b:", a < b)    # False
print("a == c:", a == c)  # True
print("a != b:", a != b)  # True
```

## 💻 代码示例

```python
# ==================== 第11节：比较运算符 ====================
# 我们来学习 Python 怎么"比大小"

# 1. 数字比较
print("=== 数字比较 ===")
print("10 > 5  的结果是：", 10 > 5)    # True
print("3 > 8   的结果是：", 3 > 8)     # False
print("7 == 7  的结果是：", 7 == 7)    # True（注意：是两个等号！）
print("7 != 8  的结果是：", 7 != 8)    # True
print("10 >= 10 的结果是：", 10 >= 10) # True（等于也成立）
print("5 <= 3  的结果是：", 5 <= 3)    # False

# 2. 用变量比较
print("\n=== 变量比较 ===")
my_height = 145
your_height = 150
print("我的身高：", my_height, "cm")
print("你的身高：", your_height, "cm")
print("你比我高吗？", your_height > my_height)
print("我们一样高吗？", my_height == your_height)

# 3. 字符串比较
print("\n=== 字符串比较 ===")
print('"apple" < "banana" 的结果：', "apple" < "banana")
print('"hello" == "hello" 的结果：', "hello" == "hello")
print('"Hello" == "hello" 的结果：', "Hello" == "hello")  # 大小写不同

# 4. 判断及格的例子
score = 85
print("\n=== 判断及格 ===")
print("分数：", score)
print("及格了吗？（>=60）", score >= 60)

# 5. 把比较结果存起来
is_taller = your_height > my_height
print("\n比较结果可以存到变量里：")
print("is_taller =", is_taller)
print("is_taller 的类型是：", type(is_taller))
```

## ✏️ 课堂练习

1. **基础练习**：在 Python 中试一试，判断以下说法对不对（True 还是 False）：
   - 100 大于 99
   - 50 等于 50
   - 30 不等于 30
   - "cat" 小于 "dog"
   - 你的年龄大于等于 10

2. **应用练习**：小明数学考了 88 分，小红考了 92 分，小刚考了 88 分。请用 Python 判断：
   - 小红是不是考得最高？（提示：比较小红和小明，再比较小红和小刚）
   - 小明和小刚分数一样吗？

3. **挑战练习**：设定一个商品的价格是 50 元，你的零花钱是 35 元。请用 Python 判断你的钱够不够买这个商品。如果不够，还差多少钱？（提示：不够的情况可以用 `<` 判断，差多少钱用减法）

## 📋 小结
- 今天学了 6 个比较运算符：>、<、==、!=、>=、<=
- 比较的结果只有 True 或 False，这叫布尔值
- `==` 是判断相等（两个等号），`=` 是赋值（一个等号），千万别搞混！
- 字符串也能比较，按照字母顺序从左到右比
- 比较的结果可以存到变量里，后面判断条件时非常有用！
