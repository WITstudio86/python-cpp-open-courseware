# 第47节：综合闯关挑战（上）

## 🎯 教学目标
- 学生能够综合运用变量、条件判断、循环、列表、字符串等知识解决实际问题
- 学生能够将一个大问题拆解成小步骤，逐步完成编程任务
- 学生能够独立完成"数学计算关"和"密码破译关"的代码编写
- 学生能够在闯关中获得成就感，激发持续学习的兴趣

## 📝 重点概念
- **综合运用**：一个真实的问题往往需要多种编程知识配合才能解决，就像做菜需要多种食材和调料
- **问题拆解**：把大任务分成小步骤，逐个击破——这是程序员最重要的能力之一
- **关卡设计**：一个好的关卡有清晰的规则、明确的过关条件、合理的难度
- **用户交互**：程序不仅仅是计算，还要和用户"对话"——提示、反馈、表扬

### 步骤2：核心讲解（15-20分钟）

#### 2.1 关卡设计的思路

"每一个关卡都由以下要素组成："

| 要素 | 说明 | 例子 |
|------|------|------|
| 关卡名称 | 让人一看就想挑战 | "数学试炼场" |
| 关卡规则 | 玩家需要做什么 | "回答 5 道随机数学题" |
| 过关条件 | 怎样算通过 | "答对 3 题以上" |
| 失败提示 | 没过关怎么办 | "继续加油，再来一次！" |
| 过关奖励 | 通关后给什么 | "恭喜获得 ★ 智慧之星！" |

"我们写代码的时候，先想清楚这五个要素，再来写代码，就不会乱了。"

#### 2.2 地图总览：三大关卡

"来看看我们今天要攻克的三个关卡："

**第1关：数学试炼场**
- 用 `random.randint()` 随机生成数学题

**第2关：密码破译局**
- 给一段"加密"的文本
- 学生需要写代码把加密文本还原
- 涉及字符串切片、替换、遍历等操作
- 需要理解加密规则（比如凯撒密码的简化版）

**第3关：智慧大考验**
- 包含条件判断和循环的综合题
- 可能是一个"猜数字"游戏
- 或者一个需要分析数据的任务

"今天我们先攻克第1关和第2关，明天继续第3关！"

#### 2.3 第1关详解：数学试炼场

"这一关的思路很简单："

1. 电脑随机出 5 道数学题（加减乘除）
2. 玩家输入答案
3. 判断对错并计分
4. 最后统计总分，宣布结果

**需要注意的细节：**
- 除法题要确保能整除（避免出现小数，对小学生友好）
- 减法题要确保结果不为负数
- 给玩家一个友好的提示和反馈

**生活中的比喻：** 就像体育课上的投篮测试——老师给你 5 次投篮机会，命中 3 次就合格。我们的数学关也一样，5 道题答对 3 题就过关！

#### 2.4 第2关详解：密码破译局

"这一关非常有趣！想象你是一个小侦探，截获了一段敌人的秘密情报，但这段情报被加密了。你需要写代码来破译它！"

**加密规则说明：**
"我们用一种简单的加密方法：把每个字母往后移动 3 位。比如 A 变成 D，B 变成 E，...，X 变成 A（循环回来）。"

```

加密: KHOOR  (每个字母向后3位)

原文: PYTHON
加密: SBWKRQ
```

"玩家的任务：写一个循环，把加密文本中的每个字母向前移 3 位，还原出原文！"

```python
import random

def level_1_math_challenge():
    """第1关：数学试炼场"""
    print()
    print("=" * 50)
    print("  🧮 第1关：数学试炼场 🧮")
    print("  规则：回答5道随机数学题，答对3题即可过关！")
    print("=" * 50)
    print()
    
    score = 0  # 得分计数器
    total_questions = 5  # 总共5道题
    
    for i in range(1, total_questions + 1):
        # 随机生成题目
        a = random.randint(1, 100)
        b = random.randint(1, 100)
        op = random.choice(["+", "-", "*"])
        
        # 处理减法：确保结果不为负
        if op == "-" and b > a:
            a, b = b, a  # 交换，确保 a >= b
        
        # 处理乘法：数字小一点
        if op == "*":
            a = random.randint(1, 12)
            b = random.randint(1, 12)
        
        # 计算出正确答案
        if op == "+":
            correct_answer = a + b
        elif op == "-":
            correct_answer = a - b
        else:  # op == "*"
            correct_answer = a * b
        
        # 提问
        print(f"第{i}题：{a} {op} {b} = ?")
        user_answer = input("你的答案：")
        
        # 判断对错
        if user_answer.isdigit() or (user_answer.startswith("-") and user_answer[1:].isdigit()):
            user_answer = int(user_answer)
            if user_answer == correct_answer:
                print("  ✅ 正确！太棒了！")
                score += 1
            else:
                print(f"  ❌ 不对哦，正确答案是 {correct_answer}")
        else:
            print(f"  ❌ 请输入一个数字！正确答案是 {correct_answer}")
        
        print()
    
    # 宣布结果
    print("-" * 50)
    print(f"  你的得分：{score} / {total_questions}")
    
    if score >= 3:
        print("  🎉 恭喜过关！获得 ★ 智慧之星 ★")
        print("-" * 50)
        return True
    else:
        print("  😢 差一点点就过关了！再试一次吧！")
        print("-" * 50)
        return False
```

            else:
                base = ord('a')
            
            # 向前移3位（解密）
            original_code = ord(char) - base   # 得到 0-25 的编号

            decrypted += decrypted_char
        else:
            decrypted += char  # 空格和标点符号不变
