## 🎯 教学目标

- 学生能够独立完成"求和器"项目

## 📝 重点概念
- **累加器模式**：先准备一个变量（初始为 0），然后在循环中不断往上面加。就像存钱罐，每次往里面投币
- **计数器模式**：先准备一个变量（初始为 0），满足条件就 +1。就像计分板
- **字符串累加**：先准备一个空字符串 ""，在循环中不断拼接。就像串珠子
- **格式化打印**：用 `\t`（制表符）来对齐输出，让打印的内容整整齐齐

### 步骤2：核心讲解（15-20分钟）

**1. 累加器模式（5分钟）**

```python
# 求 1+2+3+4+5 的和
total = 0  # 先准备一个"存钱罐"
for i in range(1, 6):
    total = total + i  # 或者 total += i
    print(f"加了 {i}，现在总和是 {total}")
print(f"最终结果：{total}")
# 输出：最终结果：15
```

**执行过程追踪**：
```
第1次：total = 0 + 1 = 1
第2次：total = 1 + 2 = 3
第3次：total = 3 + 3 = 6
第4次：total = 6 + 4 = 10
第5次：total = 10 + 5 = 15
```

**2. 计数器模式（3分钟）**

```python
# 统计 1-50 中能被 7 整除的数有几个
count = 0  # 计数器，初始为 0
for i in range(1, 51):
    if i % 7 == 0:
        print(f"{i} 是 7 的倍数")
        count += 1  # 找到一个就 +1
print(f"1-50 中一共有 {count} 个 7 的倍数")
```

**3. 字符串累加模式（3分钟）**

```python
# 把名字的每个字用"~"连起来
name = "小明爱编程"
result = ""
for char in name:
    result = result + char + "~"
print(result)  # 小~明~爱~编~程~
```

**4. 打印九九乘法表（7分钟）**

```python
# 基础版：打印一列
for i in range(1, 10):
    print(f"3 × {i} = {3 * i}")

# 完整版：打印整个乘法表
for i in range(1, 10):        # 外层循环：行
    for j in range(1, i+1):   # 内层循环：列
        print(f"{j}×{i}={i*j}", end="\t")
    print()  # 一行结束，换行
```

**双重循环解释**：
- 外层循环控制"第几行"（乘数）
- 内层循环控制"这一行有几列"（被乘数）
- 第1行只有 1×1=1
- 第2行有 1×2=2, 2×2=4
- ...

### 步骤3：动手演示（10分钟）

**演示1：求和器**
让用户输入 n，自动计算 1+2+...+n 的和。

**演示2：求平均值**

**演示3：找最大/最小值**

## 💻 代码示例

```python
# 求和器
n = int(input("请输入 n："))
total = 0
for i in range(1, n+1):
    total += i
print(f"1+2+...+{n} = {total}")

# 乘法表
for i in range(1, 10):
    for j in range(1, i+1):
        print(f"{j}×{i}={i*j}", end="\t")
    print()
```

## 📋 小结
- 累加器模式：total = 0，循环中 total += 新数
- 计数器模式：count = 0，条件满足时 count += 1
- 字符串累加：result = ""，循环中 result += 新字符串
- 双重 for 循环可以做九九乘法表
- `\t` 是制表符，用来对齐输出
