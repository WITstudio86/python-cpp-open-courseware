# 第2节：搭建 Python 环境

## 教学目标
- 学生能够在自己的电脑上成功安装 Python
- 学生能够区分 IDLE 交互模式和脚本模式
- 学生能够成功运行第一行 Python 代码 `print("Hello, World!")`
- 学生了解常见的安装问题和解决方法

## 重点概念
- **Python 解释器**：Python 是一种"解释型"语言。解释器就像一位翻译官，你写一行 Python 代码，它就帮你翻译成电脑能懂的机器语言，然后立刻执行。不需要像有些语言那样先"编译"再运行。
- **IDLE**：Python 自带的编程环境，全称是 Integrated Development and Learning Environment（集成开发与学习环境）。它就像 Python 给你准备的"写作本"，你可以在里面写代码并马上看到运行结果。
- **交互模式（Interactive Mode）**：写完一行代码，按回车就立刻出结果。界面上有 `>>>` 提示符，像是在跟 Python 一对一聊天。
- **脚本模式（Script Mode）**：把很多行代码写在一个文件里（通常是 .py 文件），然后一次性全部运行。适合写长一点的程序。

### 步骤2：核心讲解（15-20分钟）

#### 2.1 安装 Python（分平台讲解）

##### macOS 用户安装步骤：

**方法一：从官网下载（推荐）**

1. 打开浏览器，访问 Python 官方网站：https://www.python.org
2. 点击页面中间的黄色按钮 **"Download Python 3.x.x"**（x 是版本号，数字越大越新）
3. 下载完成后，双击打开 `.pkg` 安装文件
4. 按照安装向导的提示，一直点"继续"和"同意"，直到安装完成
5. 安装完成后，系统可能会问你是否要删除安装文件，点"移到废纸篓"即可

**验证安装成功：**

打开"终端"应用（在"应用程序 → 实用工具"中找到 Terminal）：

```bash
python3 --version
```

如果看到类似 `Python 3.12.0` 的输出，说明安装成功！🎉

##### Windows 用户安装步骤：

1. 打开浏览器，访问 Python 官方网站：https://www.python.org
2. 点击 **"Download Python 3.x.x"**
3. 下载完成后，双击 `.exe` 文件
4. **最重要的一步**：在安装窗口的最底部，一定要勾选 **"Add Python 3.x to PATH"**（把 Python 添加到系统路径）！这一步非常关键，不勾选的话后面会很麻烦。
5. 点击 **"Install Now"**（立即安装）
6. 等待安装完成，点击 "Close"

**验证安装成功：**

按下键盘上的 `Win + R`，输入 `cmd` 并回车，打开命令提示符：

```bash
python --version
```

或

```bash
py --version
```

如果看到 Python 的版本号，说明成功！

#### 2.2 认识 IDLE —— Python 的"写作本"

安装 Python 时，会自动帮你装一个叫 **IDLE** 的软件。它长什么样子？

- 一个白色的窗口
- 有一些菜单栏（File、Edit、Shell、Debug 等）
- 窗口里有一行字：`Python 3.x.x ...`
- 下面有一个闪烁的光标，前面有 `>>>`

这个 `>>>` 就是 Python 在跟你说："我准备好了，请给我指令吧！"

#### 2.3 交互模式 vs 脚本模式

**交互模式（`>>>` 模式）：**

打开 IDLE，你会看到 `>>>` 提示符。在这里你可以一行一行地写代码，每次回车，Python 马上给你答案。

```python
>>> print("Hello!")
Hello!
>>> 3 + 5
8
>>> "python".upper()
'PYTHON'
```

这就像你在跟 Python 面对面聊天 —— 你问一句，它回一句。非常适合做实验、试代码。

**什么时候用交互模式？**
- 想快速测试一个想法
- 做简单的数学计算
- 不确定某行代码的效果，先试试看
- 查看某个函数的功能

**脚本模式（文件模式）：**

点击 IDLE 菜单栏的 **File → New File**，会打开一个新的白窗口。这就是脚本模式。在这里你可以写很多行代码，然后一次性运行。

在新窗口中输入：

```python
print("Hello, World!")
print("这是我的第一个 Python 程序。")
print("我好厉害！")
```

然后按 **F5**（或菜单 Run → Run Module），系统会让你保存文件（保存到桌面，命名为 `first_program.py`），保存后就会运行，结果会显示在交互窗口里。

**什么时候用脚本模式？**
- 写多行程序
- 写需要反复运行的程序
- 写需要保存下来的代码

#### 2.4 第一个程序：Hello, World!

在编程界有一个传统：学任何一门新语言，第一个程序都是让电脑输出 "Hello, World!"。

为什么是 "Hello, World!" 呢？这可以追溯到 1978 年，一本非常著名的编程书《C 程序设计语言》里，第一个示例程序就是输出 "Hello, World!"。从那以后，这成了程序员们的"仪式" —— 用新语言跟世界打个招呼！

来，让我们完成这个仪式：

```python
print("Hello, World!")
```

运行它！如果你看到屏幕上出现了 `Hello, World!`，恭喜你，从现在开始，你是一名 Python 程序员了！🎉

**演示 3：常见错误和解决方法**

老师故意写错代码，让学生看看错误信息长什么样：

```python
# 错误1：拼写错误
prit("Hello")  # 应该是 print，少了 n

# 错误2：中文标点
print（"你好"）  # 括号用了中文全角括号

# 错误3：引号不配对

# 错误4：大小写错误

```

讲解：**报错不可怕！** 报错是 Python 在帮你找问题，就像你写作文时老师用红笔圈出错别字一样。学会看报错信息，是成为优秀程序员的第一步。

## 常见问题与解决

| 问题 | 解决方法 |
|------|----------|
| macOS 打开 IDLE 时提示"无法验证开发者" | 在"系统设置 → 隐私与安全性"中点击"仍要打开" |
| Windows 命令行输入 python 显示"不是内部命令" | 重装 Python，一定要勾选 "Add to PATH" |
| IDLE 里没法输入中文 | 确认系统的输入法正在正常工作，可以先在记事本里打中文再粘贴 |
| 运行脚本时提示 SyntaxError（语法错误） | 检查括号是否是中文全角括号、引号是否配对、冒号是否是英文的 |
| 保存文件时忘记位置找不到了 | 建议统一保存到桌面，文件名用英文或拼音（不要含空格） |
