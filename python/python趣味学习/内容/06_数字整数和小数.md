# 第6节：数字 —— 整数和小数

## 教学目标
- 学生能够区分 int（整数）和 float（小数/浮点数）两种数字类型
- 学生能够使用 type() 函数查看数据的类型
- 学生能够熟练使用 Python 的算术运算符：+、-、*、/、//、%、**
- 学生能够用 Python 解决生活中的数学计算问题

## 重点概念
- **int（整数）**：没有小数点的数字，如 1、99、-5、0。Python 中的整数可以无限大！
- **float（小数/浮点数）**：带小数点的数字，如 3.14、0.5、-2.7、1.0
- **type() 函数**：查看一个数据是什么类型。例如 `type(10)` 返回 `<class 'int'>`
- **// 整除**：除法但只保留整数部分，扔掉小数部分。如 `10 // 3 = 3`
- **% 取余（取模）**：除法后剩下的余数。如 `10 % 3 = 1`（10除以3商3余1）
- **** 幂运算**：求一个数的几次方。如 `2 ** 10 = 1024`（2的10次方）

### 步骤2：核心讲解——数字的类型与运算（20分钟）

#### 2.1 int 和 float

```python
# 整数（int）—— 没有小数点
age = 10
students = 45
temperature = -5

# 小数（float）—— 有小数点
price = 3.50
pi = 3.14159
height = 1.45
```

**用 type() 查看类型：**
```python
print(type(10))      # <class 'int'>
print(type(3.14))    # <class 'float'>
print(type(7.0))     # <class 'float'> —— 注意：7.0 也是 float！
```

**重要发现：**
```python
print(10 / 5)        # 结果是 2.0（float！）
```
——在 Python 中，除法 / 的结果**永远是 float**，即使能整除！

#### 2.2 基本算术运算

| 运算符 | 含义 | 例子 | 结果 |
|--------|------|------|------|
| + | 加法 | 10 + 3 | 13 |
| - | 减法 | 10 - 3 | 7 |
| * | 乘法 | 10 * 3 | 30 |
| / | 除法 | 10 / 3 | 3.333... |
| // | 整除 | 10 // 3 | 3 |
| % | 取余 | 10 % 3 | 1 |
| ** | 幂运算 | 2 ** 10 | 1024 |

#### 2.3 整除（//）—— 扔掉小数部分

**生活场景：** 你有 10 元钱，每个包子 3 元，能买几个？
```python
print(10 // 3)    # 输出：3（只能买3个，剩下的钱不够买第4个）
```

**和普通除法的对比：**
```python
print(10 / 3)     # 3.3333333333333335
print(10 // 3)    # 3
```

#### 2.4 取余（%）—— 还剩多少？

**生活场景：** 10 元买包子（3元一个），买完还剩多少钱？
```python
print(10 % 3)     # 输出：1（还剩1元钱）
```

**更多例子：**
```python
print(17 % 5)     # 17 ÷ 5 = 3 余 2，结果：2
print(8 % 2)      # 8 ÷ 2 = 4 余 0，结果：0
print(15 % 4)     # 15 ÷ 4 = 3 余 3，结果：3
```

**奇偶判断：**
```python
print(7 % 2)      # 1 → 奇数的余数是1
print(8 % 2)      # 0 → 偶数的余数是0
```
任意整数 % 2，结果是 1 就是奇数，结果是 0 就是偶数！

#### 2.5 幂运算（**）—— 次方的魔法

```python
print(2 ** 3)     # 2的3次方 = 8
print(3 ** 2)     # 3的2次方（3的平方）= 9
print(10 ** 6)    # 10的6次方 = 1000000（一百万）
print(2 ** 10)    # 2的10次方 = 1024
```

#### 2.6 运算优先级

**和数学课一样：** 先乘除后加减，括号最优先！

```python
print(2 + 3 * 4)        # 3*4=12, 2+12=14
print((2 + 3) * 4)      # 2+3=5, 5*4=20
print(10 - 8 / 2)       # 8/2=4, 10-4=6.0
print((10 - 8) / 2)     # 10-8=2, 2/2=1.0
```

### 步骤5：总结与答疑（5分钟）

**核心回顾：**
- int 是整数，float 是小数
- / 总是返回 float，// 返回 int（整数部分）

- 运算优先级：括号 > 乘除 > 加减

## 代码示例

```python
# ===== 第6节：数字 —— 整数和小数 =====

# ---------- 1. 认识 int 和 float ----------
my_age = 11                   # 整数（int）
my_height = 1.45              # 小数（float）
print("年龄：", my_age, "  → 类型：", type(my_age))
print("身高：", my_height, "  → 类型：", type(my_height))

# ---------- 2. 基本运算 ----------
print("\n--- 四则运算 ---")
print("10 + 3 =", 10 + 3)
print("10 - 3 =", 10 - 3)
print("10 * 3 =", 10 * 3)
print("10 / 3 =", 10 / 3)      # 注意：除法总是小数

# ---------- 3. 整除和取余 ----------
print("\n--- 整除（//）和取余（%）---")
print("10 // 3 =", 10 // 3)    # 商
print("10 % 3 =", 10 % 3)      # 余数
print("17 ÷ 5 → 商", 17 // 5, "余", 17 % 5)

# ---------- 4. 幂运算 ----------
print("\n--- 幂运算（**）---")
print("2的3次方 =", 2 ** 3)
print("3的平方 =", 3 ** 2)
print("10的6次方 =", 10 ** 6)
print("2的100次方 =", 2 ** 100)  # 超大数字！

# ---------- 5. 奇偶判断 ----------
print("\n--- 判断奇偶数 ---")
number = 7
print(number, "÷ 2 的余数是", number % 2)
if number % 2 == 0:
    print(number, "是偶数")
else:
    print(number, "是奇数")

# ---------- 6. 生活中的数学 ----------
print("\n--- 班级平均分 ---")
chinese = 92
math = 88
english = 95
total = chinese + math + english
average = total / 3
print("语文:", chinese, "数学:", math, "英语:", english)
print("总分:", total, "平均分:", average)

print("\n--- 分糖果 ---")
candies = 23
kids = 5
each = candies // kids
left = candies % kids
print("有", candies, "颗糖，分给", kids, "个小朋友")
print("每人", each, "颗，还剩", left, "颗")

print("\n--- 购物找零 ---")
my_money = 100
book = 25.5
pen = 8.5 * 2
snack = 12
total_cost = book + pen + snack
change = my_money - total_cost
print("带了:", my_money, "元")
print("买了: 书", book, "元 + 笔", pen, "元 + 零食", snack, "元")
print("总花费:", total_cost, "元")
print("找零:", change, "元")

# ---------- 7. 面积计算 ----------
print("\n--- 面积计算 ---")
length = 8
width = 6
area = length * width
perimeter = (length + width) * 2
print("长方形长", length, "宽", width)
print("面积:", area, "平方米")
print("周长:", perimeter, "米")
```
