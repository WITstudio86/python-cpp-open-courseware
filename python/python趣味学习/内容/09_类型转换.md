# 第9节：类型转换

## 教学目标
- 学生能够理解 Python 中三种基本数据类型：str、int、float
- 学生能够使用 `str()`、`int()`、`float()` 进行类型之间的转换
- 学生能够理解为什么 `input()` 返回的字符串需要转换才能做数学运算
- 学生能够识别并解决常见的类型转换错误
- 学生能够独立完成"加法练习器"项目

## 重点概念
- **类型转换（Type Casting）**：把一个类型的数据变成另一个类型。比如把字符串 `"123"` 变成整数 `123`，或把整数 `456` 变成字符串 `"456"`。
- **str()**：把其他类型转成字符串。几乎任何东西都可以转成字符串。
- **int()**：把其他类型转成整数。比如 `int("123")` → `123`，`int(3.14)` → `3`（小数转整数会直接截掉小数部分，不是四舍五入！）。
- **float()**：把其他类型转成小数。比如 `float("3.14")` → `3.14`，`float(10)` → `10.0`。
- **类型不匹配错误（TypeError）**：当你试图对不兼容的类型做操作时（比如 `"我" + 10`），Python 会报 TypeError。这是初学者最常见的错误之一。

## 讲解内容

### 步骤1：引入（5分钟）

**开场故事：**

同学们，想象你有三种不同的积木：
- **文字积木**（字符串 str）：上面写着各种文字
- **整数积木**（int）：标准的正方块，上面标着数字
- **小数积木**（float）：和整数积木很像，但带一个小圆点

这三种积木虽然都是积木，但不能随便混在一起玩。比如你不能把"文字积木"和"整数积木"直接拼在一起——Python 会生气，报一个 TypeError！

但是，Python 给了我们三个"魔法机器"：
- `str()` 机器：把任何积木变成文字积木
- `int()` 机器：把合适的积木变成整数积木
- `float()` 机器：把合适的积木变成小数积木

今天我们就来学习使用这三台"魔法机器"，让不同类型的积木可以互相转换！

**热身—— 复习类型检查：**
```python
print(type("你好"))      # <class 'str'>
print(type(123))         # <class 'int'>
print(type(3.14))        # <class 'float'>
print(type("123"))       # <class 'str'>  —— 注意！带引号的数字是字符串
```

### 步骤2：核心讲解（15-20分钟）

#### 2.1 为什么需要类型转换？

**原因1：`input()` 永远返回字符串**

这是最重要、最常见的原因。回忆第4节课学的内容：

```python
age = input("请输入你的年龄：")  # 用户输入 10
print("你明年就", age + 1, "岁了")  # 报错！TypeError！
```

为什么会报错？因为 `input()` 拿到的 `"10"` 是字符串，而 `1` 是整数。字符串和整数不能直接相加。

**解决方法：用 `int()` 把字符串转成整数：**
```python
age = int(input("请输入你的年龄："))  # 用户输入 10 → 转成整数 10
print("你明年就", age + 1, "岁了")    # 正确输出：你明年就 11 岁了
```

**原因2：字符串拼接时混入数字**

```python
name = "小明"
score = 95
# print(name + "考了" + score + "分")  ← 报错！score 是整数，不能 + 字符串
print(name + "考了" + str(score) + "分")  # 正确！用 str() 把数字转成字符串
```

**原因3：整数和小数之间的转换**

```python
# 整数 → 小数（有时候需要精确的小数结果）
a = 10
b = 3
print(a / b)      # 3.3333333333333335 —— 除法自动得到 float
print(a // b)     # 3 —— 整除得到 int

# 如果想要精确的小数结果
print(float(a) / float(b))  # 效果和 a / b 一样

# 小数 → 整数（通常需要截断小数部分）
price = 3.14
print(int(price))  # 3 —— 注意！不是四舍五入，是直接砍掉小数
```

#### 2.2 str() —— 把任何东西变成文字

`str()` 是最"佛系"的转换函数，几乎什么都能转成字符串：

```python
print(str(123))          # "123" —— 数字变文字
print(str(3.14))         # "3.14" —— 小数变文字
print(str(True))         # "True" —— 布尔值变文字
print(str([1, 2, 3]))    # "[1, 2, 3]" —— 列表变文字（以后会学）

# 验证转换结果
print(type(str(123)))    # <class 'str'>
```

**`str()` 最常见的用法：拼接输出时把数字转成字符串**

```python
# 错误写法：
score = 95
print("你的分数是：" + score)   # TypeError！不能把 int 和 str 拼接

# 正确写法：
print("你的分数是：" + str(score))  # 正确！先把 score 变成字符串

# 但更推荐用 f-string：
print(f"你的分数是：{score}")       # 最推荐！f-string 自动处理类型转换
```

#### 2.3 int() —— 把东西变成整数

`int()` 可以把合适的内容转成整数：

**字符串 → 整数：**
```python
print(int("123"))    # 123 —— 字符串形式的整数可以转
print(int("-50"))    # -50 —— 负数也可以
# print(int("3.14"))  # 报错！"3.14" 不是纯整数格式，不能直接转
# print(int("你好"))  # 报错！文字无法转成数字
```

**规则：`int()` 只能转换"看起来像整数"的字符串。** 字符串里只能是数字（可以带正负号），不能有小数点、空格、文字。

**小数 → 整数（截断，不是四舍五入！）：**
```python
print(int(3.14))    # 3  —— 直接砍掉小数部分
print(int(9.99))    # 9  —— 不是 10！是直接砍掉，不是四舍五入
print(int(-3.14))   # -3 —— 负小数也是截断（向零取整）
print(int(0.99))    # 0
```

**重要提醒：`int()` 取整是"向零截断"，不是四舍五入！** 如果要四舍五入，需要用 `round()` 函数：

```python
print(round(3.14))   # 3 —— 四舍五入
print(round(9.99))   # 10 —— 四舍五入

# int() vs round() 的区别：
print(int(3.7))      # 3  —— 直接砍掉
print(round(3.7))    # 4  —— 四舍五入
```

**`int()` 的实用场景：**
```python
# 场景1：处理 input() 输入的数字
num = int(input("请输入一个整数："))
print("这个数的两倍是：", num * 2)

# 场景2：把字符串形式的数字转成真正的数字参与计算
score_str = "95"
score_int = int(score_str)
print("加分后：", score_int + 5)   # 100
```

#### 2.4 float() —— 把东西变成小数

`float()` 可以把合适的内容转成小数（浮点数）：

```python
# 整数 → 小数
print(float(10))       # 10.0
print(float(-99))      # -99.0
print(type(float(10))) # <class 'float'>

# 字符串 → 小数
print(float("3.14"))   # 3.14
print(float("10"))     # 10.0 —— "10"虽然是整数形式，float() 也能转
print(float("-0.5"))   # -0.5
# print(float("abc"))  # 报错！文字不能转
```

**`float()` 比 `int()` 更"宽容"一些：** 字符串 `"10"` 和 `"3.14"` 都能用 `float()` 转，但只有 `"10"` 能用 `int()` 转。

**`float()` 的实用场景：**
```python
# 处理带小数的用户输入
height = float(input("请输入你的身高（米）："))
weight = float(input("请输入你的体重（公斤）："))
bmi = weight / (height * height)
print(f"你的 BMI 指数是：{bmi:.1f}")

# 价格计算
price = float(input("请输入商品单价："))
count = int(input("请输入购买数量："))
total = price * count
print(f"总价：{total:.2f} 元")
```

#### 2.5 类型转换的"链条"

类型的"包容性"从大到小：
```
str ← float ← int
（字符串最包容，什么都能转成它；数字之间可以互相转）
```

**转换规则总结表：**

| 转换 | 函数 | 示例 | 结果 |
|------|------|------|------|
| 整数 → 字符串 | `str(123)` | `"123"` | ✓ |
| 小数 → 字符串 | `str(3.14)` | `"3.14"` | ✓ |
| 字符串 → 整数 | `int("123")` | `123` | ✓（字符串必须像整数） |
| 字符串 → 小数 | `float("3.14")` | `3.14` | ✓（字符串必须像数字） |
| 小数 → 整数 | `int(3.14)` | `3` | ✓（截断，不是四舍五入） |
| 整数 → 小数 | `float(10)` | `10.0` | ✓ |
| "3.14" → 整数 | `int("3.14")` | ❌ | 报错！字符串有小数点，不能直接转 int |

**如果字符串包含小数点，想转成整数怎么办？**
```python
# 两步走：先转 float，再转 int
s = "3.14"
num = int(float(s))   # float("3.14") = 3.14 → int(3.14) = 3
print(num)             # 3
```

#### 2.6 常见错误和调试

**错误1：TypeError —— 类型不匹配**
```python
print("我" + 10)          # TypeError: can only concatenate str (not "int") to str
# 翻译：只能把字符串拼到字符串上，不能拼整数
# 解决：print("我" + str(10))
```

**错误2：ValueError —— 转换的内容格式不对**
```python
int("abc")               # ValueError: invalid literal for int() with base 10: 'abc'
# 翻译：'abc' 不是合法的整数
int("3.14")              # ValueError: 字符串里有小数点，不能直接转 int
# 解决：int(float("3.14"))
```

**错误3：变量覆盖了内置函数**
```python
str = "你好"             # 把 str 变成了普通变量！
str(123)                 # TypeError: 'str' object is not callable
# 解决：不要用 str、int、float、print、input 等内置函数名做变量名！
```

## 代码示例

```python
# ========== 示例1：类型转换演示 ==========
print("--- 类型转换演示 ---")

# str() —— 万物皆可转字符串
print("str(123) =", str(123), "→ 类型：", type(str(123)))
print("str(3.14) =", str(3.14), "→ 类型：", type(str(3.14)))

# int() —— 转整数（注意截断！）
print("int('123') =", int("123"), "→ 类型：", type(int("123")))
print("int(3.14) =", int(3.14))
print("int(9.99) =", int(9.99), "  ← 注意！不是 10，是直接砍掉")
print("int(-3.14) =", int(-3.14))

# float() —— 转小数
print("float('3.14') =", float("3.14"), "→ 类型：", type(float("3.14")))
print("float(10) =", float(10))

# round() vs int() —— 关键区别
print("\nround(3.7) =", round(3.7), "  ← 四舍五入")
print("int(3.7) =", int(3.7), "    ← 直接砍掉")

# ========== 示例2：加法练习器（核心项目） ==========
print("\n" + "=" * 40)
print("       ➕ 加法练习器")
print("=" * 40)

import random  # 用来生成随机数

correct_count = 0  # 记录答对了几题
total_questions = 3  # 一共出几道题

for i in range(1, total_questions + 1):
    # 随机生成两个 1-99 之间的整数
    a = random.randint(1, 99)
    b = random.randint(1, 99)
    correct_answer = a + b
    
    print(f"\n第 {i} 题：{a} + {b} = ?")
    
    # 获取用户输入并转换成整数
    user_answer_str = input("你的答案是：")
    user_answer = int(user_answer_str)
    
    # 判断对错
    if user_answer == correct_answer:
        print("✅ 回答正确！太厉害了！")
        correct_count += 1
    else:
        print(f"❌ 不对哦，正确答案是 {correct_answer}")
        print(f"   你的答案是 {user_answer}，差了 {abs(correct_answer - user_answer)}")

# 输出成绩
print("\n" + "=" * 40)
print(f"🎉 练习结束！你答对了 {correct_count}/{total_questions} 题")
if correct_count == total_questions:
    print("满分！你是数学小天才！🏆")
elif correct_count >= total_questions // 2:
    print("不错哦，继续加油！💪")
else:
    print("还需要多练习哦，下次一定更好！📚")

# ========== 示例3：购物计算器 ==========
print("\n" + "=" * 40)
print("       🛒 购物计算器")
print("=" * 40)

# 用户输入价格和数量（必须用 float/int 转换！）
item_name = input("商品名称：")
price = float(input("单价（元）："))
count = int(input("购买数量："))

# 计算总价
total = price * count

# 输出小票
print(f"""
--- 购物小票 ---
商品：{item_name}
单价：{price:.2f} 元
数量：{count} 个
-------------------
总价：{total:.2f} 元
谢谢惠顾！
""")

# ========== 示例4：常见错误对比 ==========
print("\n--- 常见错误对比 ---")

# input 不转换的结果
num_str = input("\n请输入一个数字（看字符串拼接效果）：")
print("不转换 × 2 =", num_str * 2, "  ← 字符串重复，不是数学乘法！")

# input 转换后的结果  
num_int = int(num_str)
print("转换后 × 2 =", num_int * 2, "  ← 这才是数学乘法！")

# int 和 str 拼接的错误
name = "小明"
age = 10
# print(name + age)  # ← 这行会报错，先注释掉
print("正确拼接：", name + str(age))  # 正确做法
print("或用 f-string：", f"{name}{age}")  # 更推荐！
```

## 小结

**本节学了什么：**
- Python 有三种基本数据类型：str（字符串）、int（整数）、float（小数）
- `str()` 把任何东西变成字符串（最包容）
- `int()` 把字符串或小数变成整数（截断不是四舍五入）
- `float()` 把字符串或整数变成小数
- `input()` 拿到的永远是字符串，做数学计算前必须转换
- 类型不匹配会导致 TypeError 或 ValueError
- 变量名不要用内置函数名（str、int、float、print、input 等）

> **给老师的小贴士：**
> - `int()` 截断不是四舍五入这个知识点非常重要，是小学生容易栽跟头的地方。可以多做几个口头练习
> - `int("3.14")` 报错也是一个高频陷阱。让学生理解"两步走"策略：`int(float("3.14"))`
> - 加法练习器是本节的亮点项目，学生非常喜欢。可以让同桌互相出题挑战
> - 常见的学生错误：在已经用 `int(input(...))` 转换后，打印时又用 `str()` 转回去。虽然不会报错，但多余
> - 对于学得快的学生，可以介绍 `eval()` 函数（但提及有安全风险，不建议滥用）
> - 类型转换是编程中的基础技能，建议多出几个生活中的应用题（购物、分账、算平均数等）
