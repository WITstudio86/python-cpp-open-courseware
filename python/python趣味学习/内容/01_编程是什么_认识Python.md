# 第1节：编程是什么？认识 Python

## 教学目标
- 学生能够用自己的话解释"编程是什么"
- 学生能够说出 Python 的名字由来和至少 3 种 Python 的应用领域
- 学生能够对编程产生兴趣，愿意继续学习后续课程
- 学生能够理解"程序就是给计算机下指令"这一核心概念

## 重点概念
- **编程**：编程就是人类用计算机能听懂的语言，给计算机下命令，让它帮我们做事情。就像你写一份"任务清单"给机器人，机器人会按照清单一步一步完成任务。
- **程序**：一串有序的指令集合，就像菜谱上的步骤，计算机按照步骤执行。
- **Python（蟒蛇）**：一种非常流行的编程语言。虽然名字意思是"蟒蛇"，取名的创始人 Guido 其实是因为喜欢一个叫 Monty Python 的英国喜剧节目才取这个名字的。
- **代码**：你写在电脑上的那堆英文和符号，就是代码。代码是程序员跟计算机交流的语言。

## 讲解内容

### 步骤1：引入（5分钟）

**开场提问：**
同学们，你们平时用手机、平板、电脑吗？玩游戏吗？看动画吗？这些好玩的软件和游戏，你们知道是怎么做出来的吗？

**引导思考：**
比如你玩的《我的世界》，为什么里面的人物能走路、能盖房子？你刷的短视频，为什么能精确推送到你喜欢的类型？这一切的背后，都有一个"指挥官"在工作 —— 那就是**程序**。

而编写这些程序的人，叫做**程序员**。程序员用一种叫"编程语言"的工具来写程序。今天，我们就来认识全世界最火的编程语言之一 —— **Python**！

### 步骤2：核心讲解（15-20分钟）

#### 2.1 编程就像给机器人下指令

想象你有一个听话的小机器人。如果你想让它帮你泡一杯奶茶，你会怎么指挥它呢？

```
1. 走到厨房
2. 拿出一个杯子
3. 放进一个茶包
4. 加入热水（小心烫！）
5. 加入牛奶
6. 加入一勺糖
7. 搅拌均匀
8. 端过来给我
```

这就是一个最简单的"程序"！编程，就是把你想让计算机做的事，拆成一小步一小步，然后用计算机能理解的语言写出来。

计算机虽然很厉害，但它其实很"笨"—— 它只会按照你写的指令一步一步做，既不会自己多出主意，也不会偷懒。所以，程序员的责任就是：**把指令写得清清楚楚，一步都不能错**。

#### 2.2 Python 的名字从哪来？

有的同学可能会想："Python 不是大蟒蛇的意思吗？是不是因为写 Python 的代码像蛇一样灵活？"

哈哈，这确实是一个非常合理的猜测！但是真相更有趣：Python 的创始人叫 Guido van Rossum（我们亲切地称他为"龟叔"）。他在 1989 年圣诞节假期时想做一个有趣的项目，于是决定自己设计一门编程语言。

当时他特别喜欢英国的一个搞笑喜剧节目《Monty Python's Flying Circus》（蒙提·派森的飞行马戏团），于是就给这门语言取名为 **Python**。

所以，Python 的 Logo 是两条可爱的蛇互相缠绕，但名字其实来自一部喜剧！是不是很意外？😊

#### 2.3 Python 能做什么？

Python 就像瑞士军刀一样，几乎什么都能做。来看看这些酷炫的应用：

**（1）制作游戏**
Python 可以用来制作各种游戏。比如大家熟知的《文明》系列游戏就是用 Python 写的部分代码。你也可以用 Python 的 Pygame 库制作自己的小游戏。

**（2）建立网站**
全世界很多大型网站都用 Python。你们知道吗？Youtube、Instagram（国际版微信朋友圈）、豆瓣，它们的后台都有 Python 的身影。

**（3）人工智能（AI）**
这是最酷的部分！现在大家经常听说的"人工智能"、"AI 换脸"、"ChatGPT 聊天机器人"，它们的核心算法很多都是用 Python 写的。学会了 Python，你就能理解 AI 是怎么工作的，甚至能自己训练一个简单的 AI！

**（4）数据分析**
Python 能快速处理大量的数据。比如分析全校同学的考试成绩、统计你最喜欢的动画片的播放量，这些用 Python 几行代码就能搞定。

**（5）自动化办公**
有没有觉得反复做同一件事很烦？Python 可以帮你自动给 100 个文件重命名、自动发送邮件、自动填表格。

#### 2.4 看看 Python 代码长什么样？

现在，我来给大家展示一段真正的 Python 代码。不用紧张，你不需要现在就理解它！只是让大家看看，Python 代码长什么样，是什么感觉。

```python
# 这是一段 Python 代码 —— 让电脑跟我们打招呼
name = "小明"
age = 10
print("大家好！")
print("我叫", name)
print("我今年", age, "岁")
print("很高兴认识你们！")

# 让电脑算一道数学题
result = 12345 * 67890
print("12345 × 67890 =", result)
```

当这段代码运行时，电脑的屏幕上会出现：

```
大家好！
我叫 小明
我今年 10 岁
很高兴认识你们！
12345 × 67890 = 838102050
```

看，是不是跟写作文有点像？Python 的代码读起来就像英语句子一样，这也就是为什么 Python 特别适合初学者 —— 因为它**接近人类的自然语言**。

### 步骤3：动手演示（10分钟）

**演示 1：第一个 print 语句**

如果学生已经有环境（在第二节会正式搭建），可以演示：

```python
print("嗨，我会编程了！")
print("Python 真好玩")
print(1 + 2 + 3)
print("小狗" * 5)
```

让学生观察输出结果，尤其是最后一行 —— 字符串乘以数字会重复输出！这会让学生觉得很有趣。

**演示 2：展示一个有趣的小效果**

```python
# 用字符画一个爱心
print("  ***     ***  ")
print(" *****   ***** ")
print("******* *******")
print(" ************* ")
print("  ***********  ")
print("   *********   ")
print("    *******    ")
print("     *****     ")
print("      ***      ")
print("       *       ")
```

运行后屏幕上会出现一个由星号组成的爱心图案。这会让学生直观地感觉到：编程真的能"画"出东西来！

### 步骤4：课堂练习（15分钟）

#### 练习1：我是小小编程师（口头讨论）

请你模仿"泡奶茶"的例子，写出另一个生活中的"程序步骤"。可以选择：
- 早上起床到出门的过程
- 做一道鸡蛋炒饭的步骤
- 打电话叫外卖的流程

每组 3-4 个同学讨论，然后选出一位代表在班上分享。（提示：步骤越具体越好！比如"起床"不只是"起床"，而是"睁开眼睛 → 掀开被子 → 坐起来 → 双脚放到地面 → 站起来"）

#### 练习2：猜猜 Python 能做什么

老师给出一些场景，让学生举手判断"这个能不能用 Python 做到？"
- 控制红绿灯 （能！）
- 让汽车自动驾驶 （能！结合 AI）
- 做一个自动回复笑话的聊天机器人（能！）
- 让电脑帮你洗衣服（不能！编程只能控制电脑，不能控制物理世界的洗衣机，除非你给洗衣机装了芯片并连接电脑）

#### 练习3：想象你的第一个 Python 项目

在纸上写下："如果我会 Python，我最想做一个什么东西？"
- 一个计算器？
- 一个小游戏？
- 一个能讲笑话的程序？
- 一个画画程序？

每个人至少想出一个，鼓励奇思妙想！

### 步骤5：总结与答疑（10分钟）

回顾本节的核心内容：
1. 编程就是给计算机下指令，一步一步清清楚楚
2. Python 是一门简单好学的编程语言，名字来自一位喜剧人的灵感
3. Python 可以做游戏、网站、人工智能等很多很酷的事
4. 我们看到了一些 Python 代码，它看起来就像英语句子

## 代码示例

```python
# ========== 示例1：让电脑打招呼 ==========
print("=" * 30)
print("欢迎来到 Python 的世界！")
print("=" * 30)

# 让电脑输出一些信息
print("我的名字是：电脑小助手")
print("我最喜欢的数字是：", 42)
print("3 + 5 =", 3 + 5)

# ========== 示例2：字符笑脸 ==========
print("\n这是一个由字符组成的笑脸：")
print("  *****  ")
print(" *     * ")
print("*  O O  *")
print("*   ^   *")
print("*  \\_/  *")
print(" *     * ")
print("  *****  ")
print("\nPython 是不是很有趣？😊")

# ========== 示例3：用 print 探索 ==========
print("小狗小狗小狗小狗小狗")
# 和下面这句效果一样：
print("小狗" * 5)

print("\nPython 可以做超大的数学题：")
big_number = 999999 * 888888
print("999999 × 888888 =", big_number)
```

## 小结

**本节学了什么：**
- 编程就是给计算机写下一步一步的指令，让它完成特定的任务
- Python 是一门全球流行的编程语言，名字来自喜剧节目，Logo 是两条可爱的蛇
- Python 在游戏、网站、人工智能、数据分析、自动化等领域都有广泛应用
- 我们看了 Python 代码的样子 —— 它读起来很像英语，写起来也不复杂
