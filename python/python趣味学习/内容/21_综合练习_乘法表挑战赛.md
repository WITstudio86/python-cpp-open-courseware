- 学生能够用格式化打印实现对齐输出
- 学生能够用 for 和 while 两种方式分别实现九九乘法表

## 📝 重点概念
- **双重循环（嵌套循环）**：一个循环里面再放一个循环。外层走一步，内层走一轮
- **格式化打印**：用 `\t`（制表符）或字符串格式化来对齐输出
- **内层循环依赖外层**：乘法表中，第 i 行有 i 列，所以内层 range 的终点取决于外层变量
- **for 和 while 转换**：任何 for 循环都能用 while 改写，反之亦然

### 步骤2：核心讲解（15-20分钟）

**1. 回顾 for 循环和 range()（5分钟）**

快速回顾关键知识点：
- for 变量 in 序列：遍历
- range(1, 10)：生成 1 到 9
- range(1, i+1)：生成 1 到 i

**2. 双重循环详解（10分钟）**

```python
# 先理解简单的双重循环
for i in range(1, 4):      # 外层循环：3 次
    for j in range(1, 3):  # 内层循环：2 次
        print(f"i={i}, j={j}")
    print("---")
# 输出：
# i=1, j=1
# i=1, j=2
# ---
# i=2, j=1
# i=2, j=2
# ---
# i=3, j=1
# i=3, j=2
# ---
```

**规律**：外层走 1 步，内层走一整轮。就像时钟——时针走 1 格，分针走一整圈。

**3. 乘法表的逐行分析（5分钟）**

```
第1行：1×1=1                       （1 列）
第2行：1×2=2  2×2=4                （2 列）
第3行：1×3=3  2×3=6  3×3=9         （3 列）
...
第9行：1×9=9  2×9=18  ...  9×9=81  （9 列）
```

规律：第 i 行有 i 列！所以内层 range 是 `range(1, i+1)`

**演示3：格式化对齐技巧**
用 `:2d` 让每个结果占 2 个字符宽，这样表格就对齐了。

## 💻 代码示例

```python
# ======== for 版本 ========
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j:2d}", end="  ")
    print()

# ======== while 版本 ========
i = 1
while i <= 9:
    j = 1
    while j <= i:
        print(f"{j}×{i}={i*j:2d}", end="  ")
        j += 1
    print()
    i += 1
```
