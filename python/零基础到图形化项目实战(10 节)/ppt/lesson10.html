# PyInstaller 做了什么？
# 它把这三样东西打包在一起：

# 1. 你的 Python 源代码
# 2. Python 解释器（python.exe）
# 3. 所有依赖库（tkinter, ttk...）

# → 输出一个独立的 .exe 文件
# 对方不需要安装任何东西！
💡 类比： 就像你把菜谱、锅、食材全部塞进一个盒子，对方打开就能直接吃——不用自己买菜做饭。
第 10 课 · 打包发布
用对比的方式让学生理解打包的意义。核心概念：PyInstaller 把代码 + 解释器 + 依赖全部打包成一个独立文件。类比"便当盒"很形象。

安装 PyInstaller + 基本命令

📥 安装

# 打开终端，输入：
pip install pyinstaller

# 如果 pip 找不到：
# Windows: python -m pip install pyinstaller
# Mac:     python3 -m pip install pyinstaller

# 验证安装
pyinstaller --version
pip Python 的包管理器，用来安装第三方库

🚀 最简单的打包命令

# 单文件模式（最常用）
pyinstaller --onefile lesson9.py

# 推荐：带窗口模式 + 自定义名称
pyinstaller --onefile --windowed \
  --name="我的备忘录" lesson9.py
参数缩写说明
--onefile-F打包成单个文件
--windowed-w不显示终端黑窗口
--icon=...-i设置程序图标
--name="..."-n指定输出文件名
--add-data—附带数据文件
--clean—清理后重新打包
第 10 课 · 打包发布
pip 安装 PyInstaller 很简单。--onefile 和 --windowed 是两个最重要的参数。建议学生现场在终端里执行安装和打包，看到输出结果会很有成就感。

理解输出 + 数据文件路径

📁 输出结构


项目文件夹/
├── lesson9.py              ← 源代码
├── todos.txt               ← 数据文件
├── build/                  ← 临时文件（可删）
│   └── ...
├── dist/                   ← 🎉 最终输出！
│   └── 我的备忘录.exe   ← 你的程序！
└── 我的备忘录.spec          ← 配置文件
🎯 dist/ 文件夹里的就是成品，把它发给朋友就行了！

🗂️ 数据文件路径处理

import sys, os

def get_data_path(filename):
    """获取数据文件的正确路径"""
    if getattr(sys, 'frozen', False):
        # 打包后：在临时解压目录
        base_path = sys._MEIPASS
    else:
        # 开发时：在脚本所在目录
        base_path = os.path.dirname(
            os.path.abspath(__file__))
    return os.path.join(base_path, filename)

# 使用
DATA_FILE = get_data_path("todos.txt")
属性开发时打包后
sys.frozenFalseTrue
文件位置脚本目录sys._MEIPASS

⚠️ 常见问题

问题解决方案
杀毒软件报警正常！PyInstaller 打包的 exe 有时被误报，添加信任
文件太大正常！打包了 Python 解释器，通常 30-50MB
中文路径报错路径中不要有中文或空格，放英文目录
缺少 tkinter通常不会，PyInstaller 自动检测
运行时闪退先不加 --windowed，看终端报什么错

💻 写代码

创建打包脚本

为了方便以后重复打包，写一个脚本来自动化打包流程。

Windows — build.bat

@echo off
echo 🚀 开始打包备忘录...
pyinstaller --onefile --windowed ^
  --name="我的备忘录" --clean 备忘录.py
echo ✅ 打包完成！
echo 文件在 dist\ 文件夹中
pause

Mac / Linux — build.sh

#!/bin/bash
echo "🚀 开始打包备忘录..."
pyinstaller --onefile --windowed \
  --name="我的备忘录" --clean 备忘录.py
echo "✅ 打包完成！"
echo "文件在 dist/ 文件夹中"
💡 使用脚本的好处： 不用每次记长长的命令，双击运行脚本就完成打包。修改代码后重新打包也只需跑一下脚本。
第 10 课 · 打包发布
脚本虽然简单，但体现了"自动化"的思想。让学生养成"重复的事情写脚本"的好习惯。Windows 的 .bat 和 Mac/Linux 的 .sh 都要讲。
