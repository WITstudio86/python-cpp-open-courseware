📚 新知识

StringVar — tkinter 的双向绑定

之前获取输入框内容要调用 entry.get()。但如果想实时监听输入框的变化（比如输入即搜索），就需要 StringVar。

# 创建 tkinter 字符串变量
search_var = tk.StringVar()

# 绑定到 Entry 控件
entry = ttk.Entry(
    window,
    textvariable=search_var
)

# 读取值
print(search_var.get())  # 获取输入框内容

# 设置值（输入框会自动更新！）
search_var.set("新内容")

📐 双向绑定的含义

正向：Entry → StringVar

用户在输入框打字 → StringVar 的值自动更新

反向：StringVar → Entry

代码中 search_var.set("...") → 输入框自动显示新内容

textvariable 把 Entry 和 StringVar 绑在一起的参数
第 9 课 · 搜索与过滤
StringVar 是 tkinter 的变量系统核心。双向绑定意味着无论用户输入还是代码修改，两边始终保持同步。后面会看到，结合 trace 就能实现实时监听。

📚 新知识

trace — 实时监听变量变化

trace("w", callback) 是实现"输入即搜索"的关键！每当用户在搜索框输入一个字，回调函数就会被自动调用。

search_var = tk.StringVar()

def on_search_change(*args):
    """每次输入变化时自动调用"""
    keyword = search_var.get()
    print(f"搜索词变了：{keyword}")
    refresh_display()  # 刷新列表

# 绑定 trace：写模式，变量被修改时触发
search_var.trace("w", on_search_change)

# 用户每打一个字，on_search_change 就执行一次
模式说明使用场景
"w"变量被写入（修改）时触发实时搜索
"r"变量被读取时触发访问日志
"u"变量被删除时触发清理资源

🔗 完整链路

用户打字 → Entry 更新 → StringVar 变化 → trace("w") 触发 → refresh_display() 刷新列表

第 9 课 · 搜索与过滤
trace 是实现实时交互的核心。三个模式中 "w" 最常用。让学生理解完整的事件链路：用户动作 → 变量变化 → trace 触发 → 回调执行。这就是现代 UI 的响应式思维。

📚 新知识

过滤逻辑 + in 运算符

搜索/过滤的核心流程：原始数据 → 应用过滤条件 → 刷新显示

def refresh_display():
    keyword = search_var.get().strip().lower()
    cat_filter = filter_combo.get()

    listbox.delete(0, tk.END)  # 清空

    for todo in todos:
        # in 运算符：判断关键词是否出现
        text_match = (
            not keyword or
            keyword in todo["text"].lower()
        )
        # 类别匹配（全部 或 同类别）
        cat_match = (
            cat_filter == "全部 📋" or
            cat_filter == todo["category"]
        )

        if text_match and cat_match:
            # 显示这一条
            display = f"[{todo['category']}] {todo['text']}"
            listbox.insert(tk.END, display)

表达式结果

"Java" in "学Python编程"False
3 in [1, 2, 3, 4]True

💡 大小写不敏感： .lower() 把双方都转成小写再比较，所以搜"python"和"Python"效果一样。
⚠️ 过滤 vs 删除： 过滤后数据还在 todos 里，只是暂时不显示。删除是从数据中彻底移除。理解这一点非常重要！
第 9 课 · 搜索与过滤
过滤三步骤：清空旧显示 → 遍历判断 → 插入匹配项。in 运算符在 Python 中非常常用，字符串、列表、字典都能用。强调"过滤"和"删除"的区别——过滤只是视图变化，数据不变。

📚 新知识

反向匹配与边界处理

def find_todo_by_display(display_text):
    """根据 Listbox 中显示的文本，
       找到 todos 中对应的字典"""
    if not display_text or \
       display_text == "（无匹配结果）":
        return None
    for todo in todos:
        expected = f"[{todo['category']}] {todo['text']}"
        if expected == display_text:
            return todo
    return None

def get_selected_todo():
    """获取当前选中项对应的 todo 字典"""
    selected = listbox.curselection()
    if not selected:
        return None
    display_text = listbox.get(selected[0])
    return find_todo_by_display(display_text)

🛡️ 边界情况处理

情况处理方式
搜索框为空显示全部（不过滤）
搜索无结果灰色"（无匹配结果）"
过滤后删除从 todos 移除，刷新显示
过滤后标记完成更新 todos，保持过滤
过滤后添加加入 todos，匹配才显示
💡 核心原则： 所有修改数据的操作 → 改 todos → 调 refresh_display() 刷新视图。不要直接操作 Listbox！

完整过滤流程

def refresh_display():
    keyword = search_var.get().strip().lower()
    cat_filter = filter_combo.get()

    # 保存选中状态
    selected = listbox.curselection()
    sel_display = None
    if selected:
        sel_display = listbox.get(selected[0])

    listbox.delete(0, tk.END)

    for todo in todos:
        text_match = (
            not keyword or
            keyword in todo["text"].lower()
        )
        cat_match = (
            cat_filter == "全部 📋" or
            cat_filter == todo["category"]
        )

        if text_match and cat_match:
            display = f"[{todo['category']}] {todo['text']}"
            listbox.insert(tk.END, display)

            if todo["done"]:
                idx = listbox.size() - 1
                listbox.itemconfig(idx, fg="gray")
                listbox.itemconfig(idx, font=(
                    "微软雅黑",12,"overstrike"))

            if sel_display and display == sel_display:
                listbox.selection_set(
                    listbox.size() - 1)

    # 无结果提示
    if listbox.size() == 0 and todos:
        listbox.insert(tk.END, "（无匹配结果）")
        listbox.itemconfig(0, fg="#AAAAAA")

    update_status()

操作函数统一改写

所有操作函数统一使用 get_selected_todo() + refresh_display() 模式。

def toggle_done():
    todo = get_selected_todo()
    if not todo:
        return
    todo["done"] = not todo["done"]
    save_todos()
    refresh_display()  # 保持过滤状态

def delete_todo():
    todo = get_selected_todo()
    if not todo:
        messagebox.showwarning(
            "提示", "请先选择要删除的事项！")
        return
    result = messagebox.askyesno(
        "确认删除",
        f"确定要删除「{todo['text']}」吗？")
    if result:
        todos.remove(todo)
        save_todos()
        refresh_display()

def clear_all():
    if not todos:
        return
    if messagebox.askyesno("确认清空",
        "确定要清空所有待办吗？"):
        todos.clear()
        save_todos()
        refresh_display()

📐 统一模式

1. 获取数据

通过 get_selected_todo() 拿到对应的 todo 字典（不依赖索引）

2. 修改数据

直接修改 todos 列表中的字典，不碰 Listbox

3. 保存 + 刷新

save_todos() + refresh_display() — 数据和视图同步更新

🔑 快捷键： Ctrl+F 聚焦搜索框，Ctrl+L 清除搜索 — 提升操作效率。
