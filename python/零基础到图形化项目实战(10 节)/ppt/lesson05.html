📚 新知识

字典 dict — 键值对容器

列表用数字索引访问，字典用自定义名字（键 key）来访问数据（值 value）。

❌ 列表方式 — 得记住位置

student_list = ["小明", 12, "六年级"]
name = student_list[0]  # 得记住 0 是名字
age = student_list[1]   # 得记住 1 是年龄

✅ 字典方式 — 一看就懂！

student_dict = {
    "name": "小明",
    "age": 12,
    "grade": "六年级"
}
name = student_dict["name"]  # 清晰！
💡 类比：字典就像真正的字典📖。查"apple"（键）→ 找到"苹果"（值）。你不能用页码来查。
第 5 课 · 标记已完成
字典是本课最重要的新概念。用"真正的字典"做类比非常直观。要强调字典用花括号 {}、键值对用冒号分隔、访问用方括号 [key]。

for 循环 — 遍历数据

for + in 就是"对于……里面的每一个……"，每次从容器中取出一个元素。

# 遍历列表
fruits = ["苹果", "香蕉", "橘子"]
for fruit in fruits:
    print(f"我喜欢吃{fruit}")

# 输出：
# 我喜欢吃苹果
# 我喜欢吃香蕉
# 我喜欢吃橘子
# 遍历待办列表
todos = [
    {"text": "学Python", "done": False},
    {"text": "写作业", "done": True},
]

for item in todos:
    status = "✅" if item["done"] else "⬜"
    print(f"{status} {item['text']}")

# 输出：
# ⬜ 学Python
# ✅ 写作业
🔑 for 循环结构：for 临时变量 in 容器: → 要重复执行的代码（注意缩进！）

💻 核心逻辑

切换完成状态 — toggle_done()

def toggle_done():
    """切换选中事项的完成状态"""
    if listbox.size() == 0:
        return

    selected = listbox.curselection()
    if not selected:
        messagebox.showwarning("提示", "请先选择要标记的事项！")
        return

    index = selected[0]
    todo = todos[index]                     # 取出对应字典
    todo["done"] = not todo["done"]         # 翻转 True↔False

    # 根据新状态更新样式
    if todo["done"]:
        listbox.itemconfig(index, fg="gray")
        listbox.itemconfig(index, font=("微软雅黑", 12, "overstrike"))
    else:
        listbox.itemconfig(index, fg="black")
        listbox.itemconfig(index, font=("微软雅黑", 12))

    save_todos()  # 保存到文件
🔑 关键：操作后调用 save_todos() 保存状态，下次打开程序完成状态还在！

toggle_done 是本课的核心函数。三步走：检查有效性 → 翻转状态 → 更新样式。让学生理解"not todo["done"]"这句是最精妙的——一行代码实现切换。

数据同步 — 删/清也要更新

删除：同步移除

def delete_todo():
    # ... 检查 ...
    index = selected[0]
    todo = todos[index]

    result = messagebox.askyesno(
        "确认删除",
        f"确定删除「{todo['text']}」？")

    if result:
        listbox.delete(index)  # 删显示
        todos.pop(index)       # 删数据
        save_todos()

清空：同步清空

def clear_all():
    # ... 检查 ...
    result = messagebox.askyesno(
        "确认清空",
        f"共 {listbox.size()} 条，确定清空？")

    if result:
        listbox.delete(0, tk.END)  # 清显示
        todos.clear()              # 清数据
        save_todos()
⚠️ 黄金法则：修改 Listbox（显示）的同时，必须同步修改 todos（数据）！否则显示和数据会不一致。

# 第 5 课：标记已完成 — 样式变化与字典
import tkinter as tk
from tkinter import messagebox

window = tk.Tk()
window.title("我的备忘录")
window.geometry("450x600")

todos = []  # 存储待办字典的列表

# --- 文件操作 ---
DATA_FILE = "todos.txt"

def save_todos():
    with open(DATA_FILE, "w", encoding="utf-8") as f:
        for todo in todos:
            s = "1" if todo["done"] else "0"
            f.write(f"{s}|{todo['text']}\n")

# --- 界面创建（省略，同第 4 课）---
# title_label, input_frame, entry, buttons, listbox...

# --- 核心功能 ---
def add_todo():
    text = entry.get().strip()
    if text:
        todo = {"text": text, "done": False}
        todos.append(todo)
        listbox.insert(tk.END, text)
        entry.delete(0, tk.END)
        save_todos()

def toggle_done():
    if listbox.size() == 0: return
    selected = listbox.curselection()
    if not selected:
        messagebox.showwarning("提示", "请先选择！")
        return
    index = selected[0]
    todo = todos[index]
    todo["done"] = not todo["done"]
    if todo["done"]:
        listbox.itemconfig(index, fg="gray")
        listbox.itemconfig(index,
            font=("微软雅黑", 12, "overstrike"))
    else:
        listbox.itemconfig(index, fg="black")
        listbox.itemconfig(index,
            font=("微软雅黑", 12))
    save_todos()

# 双击切换
listbox.bind("<Double-1>", lambda e: toggle_done())

window.mainloop()
