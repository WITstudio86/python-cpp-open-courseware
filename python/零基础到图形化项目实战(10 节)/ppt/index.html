变量 — 给数据起个名字

变量就是给数据起的名字。想象一个贴了标签的盒子：标签是变量名，盒子里装的是数据。

name = "小明"
print(name)      # 输出：小明

age = 12
print(age)       # 输出：12

# 不用引号！print(变量名)
print("我叫" + name)
name变量名（自己起的）
=赋值符号，把右边的数据"装进"左边的变量
print(name)输出变量里的内容，不用加引号

📐 变量起名规则

✅ 允许的

my_name = "小华"
age = 12
hobby_1 = "编程"

❌ 不允许的

1name = "错误"  数字开头
print = "不行"  print 是关键字
my name = "不行"  不能有空格
⚠️ 注意： name 和 Name 是不同的变量，Python 区分大小写！
第 1 课 · 你好，Python！
变量是编程的核心概念。用"贴标签的盒子"做类比，学生容易理解。三个关键点：1) = 是赋值不是等于；2) print(变量名) 不用加引号；3) 起名规则要记住。让学生当场试试创建自己的变量。

tkinter — Python 的 GUI 积木

tkinter 是 Python 自带的一个库，专门用来创建图形用户界面（GUI）。

🧱

像搭积木

用 tkinter 可以搭建窗口、按钮、输入框、列表等界面元素。

📦

Python 自带

不需要额外安装！安装 Python 时就自带 tkinter。

🪟

真正的窗口

不是黑底白字的终端，而是可以拖拽、调整大小的窗口。

import tkinter as tk          # 导入 tkinter，简称为 tk

window = tk.Tk()              # 创建一个窗口对象
window.title("我的备忘录")      # 设置窗口标题
window.geometry("400x500")    # 设置窗口大小（宽x高）
window.mainloop()             # 让窗口一直运行
💡 类比： mainloop() 就像一个前台接待员，一直站在那里等着你操作窗口。没有它，窗口会"闪一下"就消失。
第 1 课 · 你好，Python！
tkinter 是本节课的重点。要让学生理解：1) import 是导入工具库；2) Tk() 创建窗口；3) title/geometry 设置属性；4) mainloop() 是事件循环，必须放最后。mainloop 的"前台接待员"类比很有效。

📚 新知识

逐行详解

import tkinter as tk

window = tk.Tk()
window.title("我的备忘录")
window.geometry("400x500")
window.mainloop()
代码解释
import tkinter as tk 导入 tkinter 库，as tk 给它起个简称，写代码更省事
window = tk.Tk() 创建窗口对象。Tk() 是 tkinter 的核心，表示"一个窗口"
window.title("…") 设置窗口顶部的标题文字
window.geometry("400x500") 设置宽和高。宽 400 像素、高 500 像素。注意中间是小写字母 x
window.mainloop() 关键的一行！让窗口保持运行，检测用户的点击和操作
🔑 两个关键点： ① geometry("400x500") 中间是小写字母 x，不是乘号 ×；② mainloop() 必须放在最后一行——它之后的代码不会立即执行。
第 1 课 · 你好，Python！
逐行讲解是最重要的环节。每行代码都要让学生理解。常见错误：geometry 里用了大写 X 或乘号 ×；mainloop 没有放最后。可以先让学生敲一遍代码，再讲解每行的含义。

# ============================================
# 第 1 课：你好，Python！— 第一个窗口
# ============================================

# --- 第一部分：print() 和变量 ---

# 让电脑说话
print("你好，Python！")
print("今天开始学编程！")

# 变量练习
my_name = "小明"
my_age = 12
my_hobby = "编程"

print("我叫" + my_name)
print("我今年" + str(my_age) + "岁")
print("我的爱好是" + my_hobby)

# --- 第二部分：创建第一个 GUI 窗口 ---

# 导入 tkinter 库
import tkinter as tk

# 创建主窗口（就像买了一个空画框）
window = tk.Tk()

# 设置窗口标题（给画框贴个标签）
window.title("我的备忘录")

# 设置窗口大小（宽x高，单位是像素）
window.geometry("400x500")

# 让窗口一直显示（事件循环，必须放最后）
window.mainloop()
第 1 课 · 你好，Python！
完整代码分为两部分：print() 和变量练习（热身），然后是 tkinter 窗口创建。注释很详细，学生可以直接复制运行。强调 str() 的作用——把数字转成字符串才能和文字拼接。
