什么是"控件"（Widget）？

控件就是窗口里的各种"零件"。你可以把窗口想象成一块画板，控件就是贴在上面的贴纸。

Button 按钮 — 可点击

# 创建按钮
btn = tk.Button(
    window,
    text="点击我！",
    font=("微软雅黑", 14),
    command=on_button_click,  # 点击后做什么
    bg="#4CAF50",
    fg="white"
)
btn.pack(pady=20)

Button 比 Label 多了最关键的参数 command——指定点击按钮后要执行的函数。

✅ 正确写法

command=say_hello

只写函数名，不加括号。点击时才执行。

❌ 错误写法

command=say_hello()

加了括号，创建按钮时就执行了，不是点击时执行！

⚠️ 牢记： command=函数名 千万不要加括号 ()！加了括号意思是"现在就执行"，而不是"等点击时再执行"。
第 2 课 · 按钮与交互
command 参数是初学者最容易犯错的地方。一定要反复强调"不加括号"。用"定义菜谱 vs 炒菜"的类比来解释：command=say_hello 是把菜谱交给按钮（等点击时炒菜），command=say_hello() 是当场就把菜炒了。

📚 新知识

pack() — 最简单的布局方式

规则：按照控件创建的先后顺序，从上到下依次堆叠。谁先 .pack() 谁就在上面。

label1.pack()   # 第 1 个，最上面
label2.pack()   # 第 2 个，中间
btn.pack()      # 第 3 个，最下面
参数说明取值示例
side靠哪边堆tk.TOP / tk.BOTTOM / tk.LEFT / tk.RIGHT
pady上下留空（像素）pady=15
padx左右留空（像素）padx=20
fill填满方向tk.X（横向）/ tk.Y / tk.BOTH
💡 类比： pack() 就像叠罗汉——先趴下的人在下面，后趴下的人在上面。先 .pack() 的控件在上面，后 .pack() 的在下面。
第 2 课 · 按钮与交互
pack() 是三种布局中最简单的，默认从上到下。pady 和 padx 控制间距，让控件不会挤在一起。fill=tk.X 可以让标签或按钮横向填满整个窗口宽度。后面还会学到 grid（表格布局）和 place（精确定位）。

📚 新知识

f-string — 优雅地嵌入变量

🎨 f-string — 把变量嵌入文字

name = "小明"
age = 12

# 旧方式（麻烦）
print("我叫" + name +
      "，今年" + str(age) + "岁")

# f-string（优雅）✅
print(f"我叫{name}，今年{age}岁")

# 花括号里还能计算
print(f"明年我{age + 1}岁")
💡 记忆口诀： f-string = f"文字{变量}"。字符串前面加 f，变量用 { } 包起来。花括号里还能写计算：f"明年我{age + 1}岁"。
第 2 课 · 按钮与交互
f-string 让字符串拼接变得超简单。对比旧方式（用 + 和 str()）和新方式（f"...{var}..."），学生一眼就能看出哪个更优雅。花括号里可以写表达式也是一个亮点，鼓励学生尝试 f"计算结果：{3 + 5}" 这类用法。

📚 新知识

def — 定义自己的函数

函数是一段有名字的代码，可以被重复调用。print() 是 Python 内置的函数，现在我们要自己定义函数。

📝 函数语法

# 定义函数
def say_hello():
    """文档字符串：说明函数作用"""
    print("你好！")
    print("按钮被点击了！")

# 调用函数
say_hello()  # 输出两行文字
📋

定义 = 写菜谱

def 只是记下来，还不执行。像写了一张菜谱放在抽屉里。

🍳

调用 = 炒菜

函数名() 是真正执行。拿出菜谱，下锅炒菜！

🔑 def 关键字

告诉 Python："我要定义一个函数了"。后面跟函数名和冒号。

📛 函数名规则

和变量名规则一样：字母、数字、下划线，不能数字开头。用有意义的名称，如 on_button_click。

⚠️ 缩进很重要

函数体（函数内部的代码）前面要有4 个空格的缩进。Python 靠缩进来识别代码块。

🔗 和 Button 的关联： command=函数名（不加括号！）——把函数"交给"按钮，等点击时才调用。
第 2 课 · 按钮与交互
def 是编程的基础概念。用"写菜谱 vs 炒菜"的类比非常有效——学生马上就能理解定义和调用的区别。强调函数名不加括号传给 command 是同一个道理：只给菜谱，不炒菜。缩进是 Python 的特色，要提醒学生函数体内的代码必须缩进 4 格。

# ============================================
# 第 2 课：Button 按钮、pack 布局和 f-string
# ============================================

import tkinter as tk

# --- 创建窗口 ---
window = tk.Tk()
window.title("我的备忘录")
window.geometry("400x500")

# --- 定义函数 ---

click_count = 0  # 计数器

def on_button_click():
    """按钮被点击时执行"""
    global click_count
    click_count = click_count + 1
    print(f"按钮被点击了！第 {click_count} 次")
    # 更新标签文字
    info_label.config(text=f"按钮已被点击 {click_count} 次")

# --- 创建控件 ---

# 1. 大标题标签
title_label = tk.Label(
    window,
    text="📝 我的备忘录",
    font=("微软雅黑", 20, "bold"),
    fg="#333333"
)
title_label.pack(pady=15)

# 2. 副标题标签
subtitle_label = tk.Label(
    window,
    text="用 Python 打造自己的专属工具！",
    font=("微软雅黑", 10),
    fg="#888888"
)
subtitle_label.pack(pady=5)

# 3. 点击按钮
btn = tk.Button(
    window,
    text="点击我！",
    font=("微软雅黑", 14),
    command=on_button_click,
    bg="#4CAF50",
    fg="white",
    padx=20,
    pady=10
)
btn.pack(pady=20)

# 4. 点击次数显示标签
info_label = tk.Label(
    window,
    text="还没有点击过",
    font=("微软雅黑", 12),
    fg="#666666"
)
info_label.pack(pady=10)

# 5. 退出按钮
quit_btn = tk.Button(
    window,
    text="退出程序",
    font=("微软雅黑", 10),
    command=window.destroy,
    bg="#f44336",
    fg="white"
)
quit_btn.pack(pady=30)

# 6. 底部说明
footer_label = tk.Label(
    window,
    text="第 2 课 · Button 与交互",
    font=("微软雅黑", 8),
    fg="#CCCCCC"
)
footer_label.pack(side=tk.BOTTOM, pady=10)

# --- 运行主循环 ---
window.mainloop()
