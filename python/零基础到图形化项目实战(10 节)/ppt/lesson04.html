📚 新知识

curselection() — 获取用户选中的项

curselection() 返回用户在 Listbox 中当前选中项的索引（位置编号）。

# 获取选中项的索引
selected = listbox.curselection()
print(selected)
# 如果选中了第 2 条，输出：(1,)

# 取出唯一的选中索引
if selected:
    index = selected[0]
    print(f"你选中了第 {index + 1} 条")
概念解释
curselection()返回元组，如 (1,)，不是单个数字
selected[0]用 [0] 取出元组里的索引值
if selected:判断是否有选中（空元组为 False）
index + 1索引从 0 开始，+1 得到人类习惯的第几条
为什么是元组？ Listbox 支持多选模式（按住 Ctrl 可多选），所以返回的是"所有选中项的集合"。本课只用单选，取 [0] 即可。
关键： curselection() 返回的是 元组 (索引,)，不是单个数字！记得用 selected[0] 取出来。
第 4 课 · 选中和删除
curselection 是今天的第一个新知识点。学生容易犯的错误是直接把返回值当数字用。要强调三点：1) 返回元组不是数字；2) 用 [0] 取出；3) 用 if selected 判断是否有选中。多选是额外知识，不要求掌握。

深入 if...else — 处理边界情况

好的程序要考虑到各种边界情况（edge case）。在删除功能中有三种可能：

情况应该怎么办？
✅ 用户选中了一条，点删除正常删除
⚠️ 用户没选中任何东西，点删除提示"请先选择要删除的事项"
⚠️ 列表是空的，点删除提示"列表为空"
 
def delete_todo():
    # 先判断列表是否为空
    if listbox.size() == 0:
        print("⚠️ 列表为空")
        return  # 提前结束函数

    # 再判断是否有选中项
    selected = listbox.curselection()
    if not selected:
        print("⚠️ 请先选择")
        return

    # 正常删除
    index = selected[0]
    listbox.delete(index)
    print("✅ 删除成功！")
return 的作用： 在函数中遇到 return，函数会立刻停止，后面的代码不再执行。这可以避免多层嵌套的 if，让代码更清晰。
第 4 课 · 选中和删除
if...else 的深入使用是编程思维的关键。让学生理解"提前 return"的写法——先处理特殊情况，符合条件就返回，最后才是正常逻辑。这种"卫语句"（guard clause）模式是专业程序员的常用写法。

📚 新知识

delete_todo — 三层判断流程图

delete_todo() 函数使用了三层判断来保证任何情况下都不会出错，这是一种专业的编程习惯。

🚪 进入 delete_todo()
↓
第 1 层：列表为空？
YES → 弹出警告 → return 结束
NO → 继续 ↓
↓
第 2 层：没选中？
YES → 弹出警告 → return 结束
NO → 继续 ↓
↓
第 3 层：确认删除？
NO（用户点"否"）→ 取消
YES（用户点"是"）→ ✅ 执行删除 
def delete_todo():
    """删除选中的待办事项"""
    # 第 1 层：列表为空？
    if listbox.size() == 0:
        messagebox.showwarning(
            "提示",
            "列表为空，没有可删除的事项！"
        )
        return  # ← 函数立刻停止！

    # 第 2 层：有没有选中？
    selected = listbox.curselection()
    if not selected:
        messagebox.showwarning(
            "提示",
            "请先选择要删除的事项！"
        )
        return  # ← 函数立刻停止！

    # 第 3 层：确认删除？
    index = selected[0]
    item_text = listbox.get(index)
    result = messagebox.askyesno(
        "确认删除",
        f"确定要删除「{item_text}」吗？"
    )

    if result:  # 用户点了"是"
        listbox.delete(index)
        messagebox.showinfo(
            "成功", f"已删除「{item_text}」"
        )
💡 编程思维： 这种"先检查特殊情况 → 提前 return → 最后才正常执行"的写法叫卫语句（Guard Clause），是专业程序员的常用模式。好处是代码扁平、易读、不易出错。
第 4 课 · 选中和删除
三层判断是本节课的核心编程思维。让学生理解：编程不只是"写出来"，更是"考虑周全"。提前 return 的模式避免了深层嵌套的 if，让代码像漏斗一样层层过滤异常情况。

messagebox — 弹出提示框

messagebox 是 tkinter 内置的弹窗模块，可以弹出信息提示、警告、确认对话框等。

from tkinter import messagebox
函数作用返回值
showinfo("标题","内容")信息提示"ok"
showwarning("标题","内容")警告提示"ok"
showerror("标题","内容")错误提示"ok"
askyesno("标题","问题")是/否确认True 或 False
askokcancel("标题","问题")确认/取消True 或 False
 
# 询问用户是否确认删除
result = messagebox.askyesno(
    "确认删除",
    "确定要删除这条待办事项吗？\n删除后无法恢复哦！"
)

if result:  # 用户点了"是"
    print("执行删除")
else:       # 用户点了"否"
    print("取消删除")
\n 是换行符，在弹窗文字中插入换行，让提示内容更易读。
第 4 课 · 选中和删除
messagebox 是让程序交互更友好的关键。表格中前三类是单向通知（用户只能点确定），后两类是双向确认（返回 True/False）。askyesno 在删除功能中最常用。让学生注意 import 这行必须加上。

Scrollbar — 添加滚动条

当待办事项很多时，需要一个滚动条来上下翻看。

# 创建滚动条
scrollbar = tk.Scrollbar(list_frame)
scrollbar.pack(side=tk.RIGHT, fill=tk.Y)

# 列表（绑定滚动条）
listbox = tk.Listbox(
    list_frame,
    yscrollcommand=scrollbar.set  # ①
)
listbox.pack(side=tk.LEFT,
             fill=tk.BOTH, expand=True)

# 滚动条拖动时更新列表视图
scrollbar.config(command=listbox.yview)  # ②

📐 布局说明

滚动条放右侧（side=tk.RIGHT），纵向填满（fill=tk.Y）；列表放左侧，填满剩余空间并随窗口扩展（expand=True）。

🔗 双向绑定

① 列表内容变化 → 自动通知滚动条
② 拖动滚动条 → 自动更新列表视图

必须双向绑定！ ① 和 ② 两行缺一不可，否则滚动条和列表无法联动。
第 4 课 · 选中和删除
滚动条的重点是双向绑定——这是学生最容易只写一半就出错的地方。用"绑绳子"的类比：两根绳子必须都系上，才能互相拉动。布局方面，可以理解为：滚动条贴在右边墙上，列表占据剩下的全部空间。

📚 新知识

lambda 匿名函数 + return 提前结束

⚡ lambda — 一行就能写的函数

lambda 是一种不需要名字的简短函数，特别适合传给 .bind() 这种需要函数但不想单独定义的地方。

# 普通函数（需要 4 行）
def on_enter(event):
    add_todo()

# lambda 函数（只需 1 行）✅
lambda event: add_todo()

语法：lambda 参数: 返回值

本课用法：

entry.bind("<Return>", lambda event: add_todo())
window.bind("<Delete>", lambda event: delete_todo())

🛑 return — 让函数立刻停止

在函数中遇到 return，函数会立刻停止，后面的代码不再执行。

def check_number(n):
    if n < 0:
        print("负数，不处理")
        return  # ← 函数在这里停止！
    # 后面的代码只在 n >= 0 时执行
    print(f"处理数字：{n}")

check_number(-5)  # 只输出：负数，不处理
check_number(10)  # 输出：处理数字：10
💡 关键区别：
return → 提前结束函数，后面的代码不执行（删除了就结束）
return 值 → 结束函数并返回一个值（如 return True）
第 4 课 · 选中和删除
lambda 和 return 是两个小而重要的知识点。lambda 让学生理解"函数可以没有名字"——在 bind() 场景中非常实用。return 在 delete_todo 中已经用了（提前退出），这里正式讲解它的作用。两者结合让学生理解函数式编程的简洁表达。

# ============================================
# 第 4 课：选中和删除
# ============================================

import tkinter as tk
from tkinter import messagebox

# ==================== 创建窗口 ====================

window = tk.Tk()
window.title("我的备忘录")
window.geometry("450x600")

# ==================== 标题区域 ====================

title_label = tk.Label(window, text="📝 我的备忘录",
    font=("微软雅黑", 20, "bold"), fg="#333333")
title_label.pack(pady=15)

subtitle_label = tk.Label(window,
    text="添加、删除、管理你的待办事项！",
    font=("微软雅黑", 10), fg="#888888")
subtitle_label.pack(pady=5)

# ==================== 输入区域 ====================

input_frame = tk.Frame(window)
input_frame.pack(pady=15)

entry = tk.Entry(input_frame, font=("微软雅黑", 13), width=22)
entry.pack(side=tk.LEFT, padx=(0, 3))

add_btn = tk.Button(input_frame, text="添加 ✅",
    font=("微软雅黑", 11), bg="#4CAF50", fg="white",
    padx=8, pady=5)
add_btn.pack(side=tk.LEFT, padx=(0, 3))

delete_btn = tk.Button(input_frame, text="删除 ❌",
    font=("微软雅黑", 11), bg="#f44336", fg="white",
    padx=8, pady=5)
delete_btn.pack(side=tk.LEFT)

# ==================== 列表 + 滚动条区域 ====================

list_label = tk.Label(window, text="📋 待办事项",
    font=("微软雅黑", 12, "bold"), fg="#555555")
list_label.pack(pady=(20, 5))

list_frame = tk.Frame(window)
list_frame.pack(pady=5, fill=tk.BOTH, expand=True, padx=20)

scrollbar = tk.Scrollbar(list_frame)
scrollbar.pack(side=tk.RIGHT, fill=tk.Y)

listbox = tk.Listbox(list_frame, font=("微软雅黑", 12),
    height=15, selectbackground="#C8E6C9",
    selectforeground="#333333",
    yscrollcommand=scrollbar.set)
listbox.pack(side=tk.LEFT, fill=tk.BOTH, expand=True)

scrollbar.config(command=listbox.yview)

# ==================== 底部按钮 ====================

clear_btn = tk.Button(window, text="清空全部 🗑️",
    font=("微软雅黑", 9), bg="#FF9800", fg="white",
    padx=10, pady=3)
clear_btn.pack(pady=5)

# ==================== 核心功能 ====================

def add_todo():
    """添加待办事项"""
    text = entry.get().strip()
    if text:
        listbox.insert(tk.END, text)
        entry.delete(0, tk.END)
        print(f"✅ 添加了：{text}")
    else:
        messagebox.showwarning("提示", "请输入待办事项！")

def delete_todo():
    """删除选中的待办事项"""
    if listbox.size() == 0:
        messagebox.showwarning("提示", "列表为空，没有可删除的事项！")
        return

    selected = listbox.curselection()
    if not selected:
        messagebox.showwarning("提示", "请先选择要删除的事项！")
        return

    index = selected[0]
    item_text = listbox.get(index)

    result = messagebox.askyesno(
        "确认删除",
        f"确定要删除「{item_text}」吗？\n删除后无法恢复哦！"
    )

    if result:
        listbox.delete(index)
        print(f"❌ 删除了：{item_text}")
        messagebox.showinfo("成功", f"已删除「{item_text}」")

def clear_all():
    """清空全部事项"""
    if listbox.size() == 0:
        messagebox.showwarning("提示", "列表已经是空的！")
        return

    result = messagebox.askyesno(
        "确认清空",
        f"列表中有 {listbox.size()} 条事项，确定全部清空吗？"
    )

    if result:
        listbox.delete(0, tk.END)
        print("🗑️ 已清空全部待办事项")

# 绑定按钮
add_btn.config(command=add_todo)
delete_btn.config(command=delete_todo)
clear_btn.config(command=clear_all)

# 绑定键盘事件
entry.bind("<Return>", lambda event: add_todo())
window.bind("<Delete>", lambda event: delete_todo())

# ==================== 运行 ====================

entry.focus()
window.mainloop()
