原生 tk 风格 vs ttk 主题

原生的 tkinter 控件风格比较老旧，看起来像 Windows 95 时代的界面。ttk（Tk themed widgets）是 tkinter 的"美化版"，自带现代主题。

from tkinter import ttk

# 原版 tkinter 按钮（老式风格）
old_btn = tk.Button(window, text="老式按钮")

# ttk 按钮（现代风格）✅
new_btn = ttk.Button(window, text="现代按钮")
原版 tkttk 版本说明
tk.Buttonttk.Button按钮
tk.Labelttk.Label标签
tk.Entryttk.Entry输入框
tk.Framettk.Frame框架
tk.Checkbuttonttk.Checkbutton复选框
tk.Radiobuttonttk.Radiobutton单选按钮
tk.Scrollbarttk.Scrollbar滚动条
—ttk.Combobox下拉框（独有！）
—ttk.Treeview树形表格（独有！）
⚠️ 注意： Listbox 和 Menu 没有 ttk 版本，仍用原版 tkinter。在我们的备忘录中，列表和菜单继续用 tk 原版。
第 8 课 · 美化界面
让学生对照左右两边理解：左边是代码，右边是控件对照表。大部分控件都有 ttk 版本，只有 Listbox 和 Menu 例外。Combobox 和 Treeview 是 ttk 独有的强大控件。

查看和切换主题

ttk 内置了多种主题，可以用 Style() 和 theme_use() 切换。

from tkinter import ttk

# 查看所有可用主题
print(ttk.Style().theme_names())
# 输出：('clam', 'alt', 'default',
#        'classic', 'vista', 'xpnative',
#        'aqua')

# 切换主题
style = ttk.Style()
style.theme_use("clam")  # 跨平台最好看的主题
theme_names() 列出系统所有可用主题
theme_use("clam") 切换到 clam 主题
🌟

clam 主题

跨平台最好看、最稳定的选择。Windows、Mac、Linux 都能用，外观一致。

🔄

其他主题

alt = 备选风格 / default = 默认 / classic = 经典 / vista = Windows Vista 风格 / aqua = Mac 风格

🔑 关键代码： 在创建任何 ttk 控件之前就设置主题，否则控件不会应用新主题。style = ttk.Style() 要写在 window = tk.Tk() 之后、其他控件之前。
第 8 课 · 美化界面
展示怎么查看主题列表和切换主题。clam 是我们推荐的主题。提醒学生主题设置必须在创建控件之前，否则不会生效。这是一个常见的坑。

grid 网格布局 — 精确定位

grid() 将窗口划分为行（row）和列（column）的网格，像 Excel 表格一样排列控件。

# pack：简单堆放（垂直排列）
label1.pack()
label2.pack()
label3.pack()

# grid：指定行列，精确摆放
label1.grid(row=0, column=0)   # 第1行，第1列
label2.grid(row=0, column=1)   # 第1行，第2列（水平！）
label3.grid(row=1, column=0)   # 第2行，第1列
label4.grid(row=1, column=1)   # 第2行，第2列
参数说明示例
row行号（从 0 开始）row=0
column列号（从 0 开始）column=1
sticky对齐方向 N/S/W/Esticky="w" = 左对齐
padx外部水平间距padx=10
pady外部垂直间距pady=5
ipadx内部水平填充ipadx=5
ipady内部垂直填充ipady=5
columnspan跨多列columnspan=2
rowspan跨多行rowspan=3
💡 sticky 方向用东西南北记： N(北) S(南) W(西) E(东) — sticky="w" 就是"靠西"=左对齐；组合用 sticky="nsew" = 上下左右全填满。
第 8 课 · 美化界面
grid 是本节课的重头戏。用对比的方式展示 pack 和 grid 的区别，让学生直观感受 grid 的精确性。参数表要有，但不用全记住——几个核心的（row, column, sticky, padx/pady, columnspan）就够用。

📚 新知识

三大布局方式 对比

tkinter 提供三种布局方式，各有适用场景。

布局原理优点缺点适合场景
pack()顺序堆放最简单控制力弱简单垂直排列
grid()网格定位精确控制稍复杂大部分情况（推荐）
place()绝对坐标完全自由缩放时出问题极少使用
⚠️ 重要规则： 在一个 Frame 内，不能混用 pack 和 grid！要么全部用 pack，要么全部用 grid。混用会导致程序卡死或控件不显示。
第 8 课 · 美化界面
三大布局对比是帮学生建立整体认知。强调 grid 是推荐的主力布局方法。混用 pack 和 grid 的规则一定要让学生记住——这是一个非常常见的错误。

ttk.Combobox — 下拉选择框

ttk.Combobox 是 ttk 独有的控件，提供一个带下拉选项的输入框，非常适合做"类别选择"。

from tkinter import ttk

# 创建下拉选择框
category_combo = ttk.Combobox(
    window,
    values=["学习", "生活", "娱乐", "其他"],
    state="readonly",        # 只读模式
    font=("微软雅黑", 11)
)

# 设置默认值
category_combo.set("学习")

# 获取当前选中的值
selected = category_combo.get()
print(selected)  # "学习"
参数说明
values=[...]下拉选项列表
state="readonly"只读，不允许自由输入
font=...字体设置
width=10宽度（字符数）
方法说明
.set("值")设置当前选中值
.get()获取当前选中值
.current(0)选中第 1 项（按索引）
💡 为什么用 state="readonly"？ 防止用户输入不在选项中的内容，保证数据的统一性。如果允许用户自己输入，去掉这个参数即可。
第 8 课 · 美化界面
Combobox 将用在备忘录的类别选择中。三个核心方法：set() 设默认值、get() 获取选中值、current() 按索引选中。state="readonly" 是推荐用法。

自定义 ttk 样式 — 像写 CSS

ttk 允许你自定义控件样式，类似网页开发中的 CSS。

style = ttk.Style()

# 自定义按钮样式
style.configure("Add.TButton",
    background="#4CAF50",
    foreground="white",
    font=("微软雅黑", 11),
    padding=8
)

# 使用自定义样式
add_btn = ttk.Button(
    window,
    text="添加 ✅",
    style="Add.TButton"
)

格式说明示例
"名称.类型"指定控件类型"Add.TButton"
"名称"通用样式"myStyle"
后缀对应控件

grid 布局逐行详解

# 让窗口可缩放时列表自动拉伸
window.grid_rowconfigure(4, weight=1)
window.grid_columnconfigure(0, weight=1)

# 标题（第 0 行）
title_label.grid(row=0, column=0,
    pady=(15,5), sticky="n")

# 副标题（第 1 行）
subtitle_label.grid(row=1, column=0,
    pady=(0,10), sticky="n")

# 输入区 Frame（第 2 行）
input_frame.grid(row=2, column=0,
    pady=10, padx=20, sticky="ew")

# 列表头（第 3 行）
header_frame.grid(row=3, column=0,
    pady=(15,0), padx=20, sticky="ew")

# 列表（第 4 行，weight=1 拉伸）
list_frame.grid(row=4, column=0,
    pady=5, padx=20, sticky="nsew")

# 状态栏（第 5 行）
status_frame.grid(row=5, column=0,
    pady=8, padx=20, sticky="ew")
行号内容说明
row=0标题大标题，居中
row=1副标题说明文字，居中
row=2输入区域Frame 套 Frame，嵌套布局
row=3列表头"待办列表"标签
row=4Listboxweight=1，可拉伸
row=5状态栏显示待办数量
🔑 weight 是什么？ grid_rowconfigure(4, weight=1) 设置第 4 行的"权重"为 1。当窗口被拉大时，权重高的行会得到更多空间。这就是列表能自动拉伸的秘密！
第 8 课 · 美化界面
用表格清晰展示网格中每一行放了什么。row=4（列表区）的 weight=1 是关键，让学生理解窗口缩放时列表自动变大的原理。input_frame 里面还有子 grid，展示 Frame 嵌套的用法。

💻 写代码

数据升级 + 文件格式

给每一条待办加上 category 类别字段，列表显示为 [类别] 内容 的格式。

# 新数据结构
todos = []
# 格式：[{"text": "内容", "done": False,
#          "category": "学习 📚"}, ...]

def add_todo():
    text = entry.get().strip()
    if text:
        category = category_combo.get()
        todo = {
            "text": text,
            "done": False,
            "category": category
        }
        todos.append(todo)
        display_text = f"[{category}] {text}"
        listbox.insert(tk.END, display_text)
# 保存格式：状态|类别|内容
def save_todos():
    with open(DATA_FILE, "w") as f:
        for todo in todos:
            s = "1" if todo["done"] else "0"
            c = todo.get("category", "其他 📌")
            f.write(f"{s}|{c}|{todo['text']}\n")

# 加载（兼容旧格式）
def load_todos():
    with open(DATA_FILE, "r") as f:
        for line in f:
            parts = line.strip().split("|")
            if len(parts) == 3:
                s, cat, text = parts
            elif len(parts) == 2:
                s, text = parts
                cat = "其他 📌"
💡 兼容旧数据： 用 len(parts) 判断是旧格式（2 字段）还是新格式（3 字段），确保之前保存的待办不会丢失。
第 8 课 · 美化界面
教学生：1) 字典新加字段很简单；2) 保存格式用 | 分隔是常见做法；3) 兼容旧数据是程序员的责任，不能升级后就丢了老用户的数据。这让升级更安全。
