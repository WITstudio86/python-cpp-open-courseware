📚 新知识

Menu — 创建菜单栏

菜单栏（Menu Bar）是桌面应用的标配——你见过的所有软件都有文件、编辑、视图、帮助这些菜单。

1

创建菜单栏

menubar = tk.Menu(window) — 创建一个空的菜单栏对象。

2

绑定到窗口

window.config(menu=menubar) — 把菜单栏挂到窗口顶部。

3

创建子菜单

file_menu = tk.Menu(menubar, tearoff=0) — 在菜单栏下创建下拉菜单。

4

挂载 + 添加命令

menubar.add_cascade(label="文件", menu=file_menu) + file_menu.add_command(label="导出", command=export)

5

添加分隔线

file_menu.add_separator() — 在菜单项之间加横线，分组更清晰。

🔑 别忘了 tearoff=0！ tkinter 默认菜单顶部有一条"撕裂线"虚线，点击后菜单会变成独立小窗口。这是 90 年代的老功能，用 tearoff=0 关掉它。
第7课 · 菜单栏和快捷键
创建菜单的 5 个步骤。tearoff=0 是 tkinter 的一个小怪癖，值得提醒。学生最容易忘记的是第 2 步 window.config(menu=menubar)——不写这行，菜单不会显示。第 4 步的 add_cascade 就像"文件夹"，add_command 就像"文件夹里的文件"。

📚 新知识

快捷键 — 键盘操作更高效

快捷键由两部分组成：菜单中显示的提示文字（accelerator）+ 实际的按键绑定（bind_all）。

# 菜单项 + 快捷键显示
file_menu.add_command(
    label="保存",
    accelerator="Ctrl+S",   # 仅显示文字
    command=save_todos
)

# 实际的快捷键绑定
window.bind_all("<Control-s>",
    lambda e: save_todos())
快捷键tkinter 写法
Ctrl+S<Control-s>
Ctrl+N<Control-n>
Ctrl+Q<Control-q>
Delete<Delete>
F5<F5>
Ctrl+Shift+S<Control-S>
大小写有区别！ <Control-s>（小写 s）= Ctrl+S；<Control-S>（大写 S）= Ctrl+Shift+S。字母的大小写决定了是否按 Shift！
⚡ bind vs bind_all： bind 只绑定到特定控件（如 Listbox），只有该控件获得焦点时才生效。bind_all 绑定到整个窗口，无论焦点在哪里都能触发。快捷键通常用 bind_all。
第7课 · 菜单栏和快捷键
学生常混淆的两点：1) accelerator 只是显示文字，不绑定功能；2) bind_all 才是真正让快捷键生效的。大小写区别是个容易踩的坑——Control-s 和 Control-S 完全不同。bind vs bind_all 的区别：bind 是局部绑定，bind_all 是全局绑定。

📚 新知识

右键弹出菜单 — 上下文菜单

在 Windows 资源管理器、VS Code 里右键都会弹出菜单——这叫上下文菜单（Context Menu）。

# ① 创建右键菜单
context_menu = tk.Menu(window, tearoff=0)
context_menu.add_command(label="标记完成", command=toggle_done)
context_menu.add_command(label="删除", command=delete_todo)
context_menu.add_separator()
context_menu.add_command(label="清空全部", command=clear_all)

# ② 绑定右键事件
def show_context_menu(event):
    context_menu.post(event.x_root, event.y_root)

listbox.bind("<Button-3>", show_context_menu)  # 右键

# ③ Mac 兼容：Control + 左键
listbox.bind("<Button-2>", show_context_menu)

🖱️ Button-3 = 右键

tkinter 中鼠标键的编号：
Button-1 = 左键
Button-2 = 中键 / Mac 右键
Button-3 = 右键

📍 屏幕坐标

event.x_root 和 event.y_root 是屏幕绝对坐标，不是窗口内的相对坐标。post() 需要屏幕坐标才能正确定位菜单。

坐标陷阱： event.x 和 event.y 是控件内的坐标，不能用！一定要用 event.x_root 和 event.y_root（带 _root 后缀的是屏幕坐标）。
第7课 · 菜单栏和快捷键
右键菜单的关键点：1) 创建方式和普通菜单一样；2) 用 post() 而不是 add_cascade 来显示；3) 坐标必须用 x_root / y_root；4) Mac 上 Button-2 是 Control+点击。让学生亲手试一下 x 和 x_root 的区别，加深理解。

代码重构 — 让程序更整洁

程序越来越长，需要把代码按功能分成函数。重构不改功能，只改结构。

❌ 重构前：面条代码

所有代码堆在一起，混作一团：窗口创建、功能函数、事件绑定……全部写在一个大块里。找东西像大海捞针，改一处怕碰坏十处。

✅ 重构后：模块化结构

文件操作：save_todos(), load_todos(), export_to_file()
核心功能：add_todo(), delete_todo(), toggle_done(), clear_all()
界面创建：create_widgets(), create_menus(), create_shortcuts()
主程序：main() 

# ==================== 主程序入口 ====================
def main():
    create_widgets()      # 创建所有控件
    create_menus()        # 创建菜单栏 + 右键菜单
    create_shortcuts()    # 绑定快捷键
    load_todos()          # 加载保存的待办事项
    window.mainloop()     # 显示窗口

# Python 标准写法：如果直接运行本文件，就执行 main()
if __name__ == "__main__":
    main()
💡 重构不是改功能，是改结构。 代码功能完全不变，但读起来清晰、改起来方便。就像整理房间——东西还是那些东西，但分类收纳后找什么都快。

def export_to_file():

    with open("备忘录_导出.txt", "w",
              encoding="utf-8") as f:

def create_menus():
    # ========== 菜单栏 ==========
    menubar = tk.Menu(window)
    window.config(menu=menubar)

    # 文件菜单
    file_menu = tk.Menu(menubar, tearoff=0)
    menubar.add_cascade(label="文件", menu=file_menu)
    file_menu.add_command(label="导出备忘录",
        accelerator="Ctrl+E", command=export_to_file)
    file_menu.add_separator()
    file_menu.add_command(label="退出",
        accelerator="Ctrl+Q", command=window.quit)

    # 操作菜单
    op_menu = tk.Menu(menubar, tearoff=0)
    menubar.add_cascade(label="操作", menu=op_menu)
    op_menu.add_command(label="添加待办",
        accelerator="Ctrl+N", command=add_todo)
    op_menu.add_command(label="标记完成/取消",
        accelerator="Ctrl+T", command=toggle_done)
    op_menu.add_command(label="删除选中",
        accelerator="Ctrl+D", command=delete_todo)
    op_menu.add_separator()
    op_menu.add_command(label="清空全部",
        command=clear_all)

    # 帮助菜单
    help_menu = tk.Menu(menubar, tearoff=0)
    menubar.add_cascade(label="帮助", menu=help_menu)
    help_menu.add_command(label="使用帮助",
        accelerator="F1", command=show_help)
    help_menu.add_command(label="关于",
        command=show_about)
    # ========== 右键菜单 ==========
    context_menu = tk.Menu(window,
                           tearoff=0)
    context_menu.add_command(
        label="✅ 标记完成/取消",
        command=toggle_done)
    context_menu.add_command(
        label="❌ 删除",
        command=delete_todo)
    context_menu.add_separator()
    context_menu.add_command(
        label="🗑️ 清空全部",
        command=clear_all)

    def show_context(event):
        context_menu.post(
            event.x_root, event.y_root)

    listbox.bind("<Button-3>",
                 show_context)
    listbox.bind("<Button-2>",
                 show_context)  # Mac

def create_shortcuts():
    """绑定全局快捷键"""
    # 使用 bind_all 让快捷键全局生效
    window.bind_all("<Control-n>",
        lambda e: add_todo())
    window.bind_all("<Control-d>",
        lambda e: delete_todo())
    window.bind_all("<Control-t>",
        lambda e: toggle_done())
    window.bind_all("<Control-s>",
        lambda e: save_todos())
    window.bind_all("<Control-e>",
        lambda e: export_to_file())
    window.bind_all("<Control-q>",
        lambda e: window.quit())
    window.bind_all("<F1>",
        lambda e: show_help())

    # Entry 的回车键（只绑定 Entry）
    entry.bind("<Return>",
        lambda e: add_todo())
def main():
    """主函数：组装并运行程序"""
    create_widgets()    # ① 创建界面
    create_menus()      # ② 创建菜单
    create_shortcuts()  # ③ 绑定快捷键
    load_todos()        # ④ 加载数据
    entry.focus()       # ⑤ 聚焦输入框
    window.mainloop()   # ⑥ 启动窗口

# ====== 程序入口 ======
if __name__ == "__main__":
    main()
🐍 if __name__ == '__main__' 是 Python 的常见模式。意思是"如果这个文件被直接运行，就执行 main()"。如果文件被其他代码 import 导入，则不会自动运行。这是写正式 Python 程序的好习惯。

bind_all 让快捷键全局生效——无论焦点在哪个控件上都能触发。Enter 键只绑定 Entry 是有意为之。main() 函数的 6 个步骤清晰展示了程序启动流程。if __name__ 模式是 Python 的标准写法，让学生养成这个习惯。

# ============================================
# 第 7 课：菜单栏和快捷键 — 最终版备忘录
# ============================================

import tkinter as tk
from tkinter import messagebox
import os

# ==================== 窗口 ====================
window = tk.Tk()
window.title("📝 我的备忘录")
window.geometry("480x640")
window.configure(bg="#f5f5f5")

# ==================== 数据结构 ====================
todos = []  # 每个元素是 {"text": "...", "done": False}

# ==================== 文件操作 ====================
TODO_FILE = "todos.txt"

def save_todos():
    with open(TODO_FILE, "w", encoding="utf-8") as f:
        for todo in todos:
            f.write(f"{todo['text']}|{todo['done']}\n")

def load_todos():
    if not os.path.exists(TODO_FILE):
        return
    with open(TODO_FILE, "r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            text, done_str = line.rsplit("|", 1)
            todos.append({"text": text, "done": done_str == "True"})
            listbox.insert(tk.END,
                ("✅ " if done_str == "True" else "⬜ ") + text)

def export_to_file():
    with open("备忘录_导出.txt", "w", encoding="utf-8") as f:
        f.write("📝 我的备忘录\n" + "=" * 30 + "\n\n")
        for i, todo in enumerate(todos, 1):
            f.write(f"{'✅' if todo['done'] else '⬜'} {i}. {todo['text']}\n")
        f.write(f"\n共 {len(todos)} 条待办事项\n")
    messagebox.showinfo("导出成功", "已导出为 备忘录_导出.txt！")

# ==================== 界面控件 ====================
title_label = tk.Label(window, text="📝 备忘录",
    font=("微软雅黑", 22, "bold"), fg="#333", bg="#f5f5f5")
entry = tk.Entry(window, font=("微软雅黑", 13), width=30)

btn_frame = tk.Frame(window, bg="#f5f5f5")
tk.Button(btn_frame, text="添加 ✅", bg="#4CAF50", fg="white",
    font=("微软雅黑", 11), padx=10, command=add_todo).pack(side=tk.LEFT, padx=3)
tk.Button(btn_frame, text="标记 ✔️", bg="#2196F3", fg="white",
    font=("微软雅黑", 11), padx=10, command=toggle_done).pack(side=tk.LEFT, padx=3)
tk.Button(btn_frame, text="删除 ❌", bg="#f44336", fg="white",
    font=("微软雅黑", 11), padx=10, command=delete_todo).pack(side=tk.LEFT, padx=3)

list_frame = tk.Frame(window, bg="#f5f5f5")
scrollbar = tk.Scrollbar(list_frame)
listbox = tk.Listbox(list_frame, font=("微软雅黑", 12),
    height=16, yscrollcommand=scrollbar.set,
    selectbackground="#C8E6C9", selectforeground="#333")
scrollbar.config(command=listbox.yview)

tk.Button(window, text="🗑️ 清空全部", bg="#FF9800", fg="white",
    font=("微软雅黑", 9), padx=12, command=clear_all).pack(pady=8)

def create_widgets():
    title_label.pack(pady=(15, 5))
    entry.pack(pady=10)
    btn_frame.pack(pady=5)
    list_frame.pack(pady=10, fill=tk.BOTH, expand=True, padx=20)
    scrollbar.pack(side=tk.RIGHT, fill=tk.Y)
    listbox.pack(side=tk.LEFT, fill=tk.BOTH, expand=True)

# ==================== 核心功能 ====================
def add_todo():
    text = entry.get().strip()
    if not text:
        messagebox.showwarning("提示", "请输入待办事项！")
        return
    todos.append({"text": text, "done": False})
    listbox.insert(tk.END, "⬜ " + text)
    entry.delete(0, tk.END)
    save_todos()

def delete_todo():
    if listbox.size() == 0:
        messagebox.showwarning("提示", "列表为空！")
        return
    sel = listbox.curselection()
    if not sel:
        messagebox.showwarning("提示", "请先选择要删除的事项！")
        return
    idx = sel[0]
    if messagebox.askyesno("确认删除",
        f"确定删除「{todos[idx]['text']}」吗？"):
        listbox.delete(idx)
        del todos[idx]
        save_todos()

def toggle_done():
    sel = listbox.curselection()
    if not sel:
        messagebox.showwarning("提示", "请先选择一条待办！")
        return
    idx = sel[0]
    todos[idx]["done"] = not todos[idx]["done"]
    prefix = "✅ " if todos[idx]["done"] else "⬜ "
    listbox.delete(idx)
    listbox.insert(idx, prefix + todos[idx]["text"])
    listbox.selection_set(idx)
    save_todos()

def clear_all():
    if listbox.size() == 0:
        messagebox.showwarning("提示", "列表已经是空的！")
        return
    if messagebox.askyesno("确认清空",
        f"列表中有 {listbox.size()} 条事项，确定全部清空吗？"):
        listbox.delete(0, tk.END)
        todos.clear()
        save_todos()

# ==================== 帮助/关于 ====================
def show_help():
    messagebox.showinfo("使用帮助",
        "⌨️ 快捷键：\nCtrl+N 添加 | Ctrl+D 删除\nCtrl+T 标记 | Ctrl+S 保存 | Ctrl+Q 退出\n\n🖱️ 右键列表弹出快捷菜单")

def show_about():
    messagebox.showinfo("关于", "备忘录 v1.0\nPython + tkinter\n第 7 课作品 🎉")

# ==================== 菜单 ====================

    window.config(menu=menubar)
    # 文件
    fm = tk.Menu(menubar, tearoff=0)
    menubar.add_cascade(label="文件", menu=fm)
    fm.add_command(label="导出备忘录", accelerator="Ctrl+E", command=export_to_file)
    fm.add_separator()
    fm.add_command(label="退出", accelerator="Ctrl+Q", command=window.quit)
    # 操作
    om = tk.Menu(menubar, tearoff=0)
    menubar.add_cascade(label="操作", menu=om)
    om.add_command(label="添加待办", accelerator="Ctrl+N", command=add_todo)
    om.add_command(label="标记完成/取消", accelerator="Ctrl+T", command=toggle_done)
    om.add_command(label="删除选中", accelerator="Ctrl+D", command=delete_todo)
    om.add_separator()
    om.add_command(label="清空全部", command=clear_all)
    # 帮助
    hm = tk.Menu(menubar, tearoff=0)

    hm.add_command(label="关于", command=show_about)

    cm = tk.Menu(window, tearoff=0)
    cm.add_command(label="✅ 标记完成/取消", command=toggle_done)
    cm.add_command(label="❌ 删除", command=delete_todo)
    cm.add_separator()
    cm.add_command(label="🗑️ 清空全部", command=clear_all)
    listbox.bind("<Button-3>", lambda e: cm.post(e.x_root, e.y_root))
    listbox.bind("<Button-2>", lambda e: cm.post(e.x_root, e.y_root))

# ==================== 快捷键 ====================
def create_shortcuts():
    window.bind_all("<Control-n>", lambda e: add_todo())
    window.bind_all("<Control-d>", lambda e: delete_todo())
    window.bind_all("<Control-t>", lambda e: toggle_done())
    window.bind_all("<Control-s>", lambda e: save_todos())
    window.bind_all("<Control-e>", lambda e: export_to_file())
    window.bind_all("<Control-q>", lambda e: window.quit())
    window.bind_all("<F1>", lambda e: show_help())
    entry.bind("<Return>", lambda e: add_todo())

# ==================== 主程序 ====================
def main():
    create_widgets()
    create_menus()
    create_shortcuts()
    load_todos()
    entry.focus()
    window.mainloop()

if __name__ == "__main__":
    main()
