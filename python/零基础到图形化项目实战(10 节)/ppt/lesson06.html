📚 新知识

为什么需要文件？

程序运行时，变量和列表存在内存（RAM）里 — 电一断，数据就没了。文件存在硬盘上 — 关机也不丢。

对比变量 / 列表文件
存储位置内存（RAM）硬盘（Disk）
速度极快较慢（但够用）
关程序后❌ 数据消失✅ 永久保存
关机后❌ 清空✅ 还在
容量较小（几 GB）很大（几百 GB / TB）
比喻草稿纸，用完就扔笔记本，写完保留
🧠

内存就像草稿纸

变量存在内存里，算完了、程序关了，纸就丢掉了。

💾

硬盘就像笔记本

文件存在硬盘里，翻开来就能看到以前记的东西。

📄

文件就是记录

把重要的数据写进文件，就等于在笔记本上记了一笔。

# 变量 — 程序关了就没有了
todos = ["学Python", "写作业", "做运动"]
print(todos)  # 程序运行时能看到
# 关闭程序 → 再打开 → todos 没了！

# 文件 — 关了也不丢
with open("todos.txt", "w") as f:
    f.write("学Python\n写作业\n做运动\n")
# 关闭程序 → 再打开 → todos.txt 还在！

📚 新知识

open() — 打开文件

操作文件的基本三步：打开 → 读写 → 关闭。open() 的第一个参数是文件路径，第二个是模式（mode）。

模式含义文件不存在文件已存在
"r"只读报错从头读
"w"只写创建新文件清空内容！
"a"追加创建新文件从末尾追加
"r+"读写报错从头读写
💡 记忆技巧： r = read（读）, w = write（写）, a = append（追加）, + = 读写 
# 写文件（三步走）
f = open("data.txt", "w", encoding="utf-8")
f.write("Hello, 文件！\n")
f.write("这是第二行\n")
f.close()  # 别忘了！
# 读文件（三步走）
f = open("data.txt", "r", encoding="utf-8")
content = f.read()
f.close()
print(content)
# Hello, 文件！
# 这是第二行
⚠️ 别忘了 .close()！ 不关闭文件，数据可能没真正写入硬盘，还会占用系统资源。每次打开文件，记得关闭它！
第6课 · 数据存文件
强调三步模式：打开 → 操作 → 关闭。模式表格让学生快速查阅，特别强调 "w" 会清空已有内容这个坑。encoding='utf-8' 确保中文正确，Windows 用户尤其重要。忘记 close() 是初学者最常见的错误。

with 语句 — 自动关闭文件

with 语句会在代码块执行完毕后自动关闭文件，即使出错也会关闭。从此告别 .close()！

❌ 旧方式（容易忘）

f = open("data.txt", "w", encoding="utf-8")
f.write("内容...\n")
# ... 如果这里出错 ...
f.close()  # 可能执行不到！

✅ with 方式（推荐）

with open("data.txt", "w", encoding="utf-8") as f:
    f.write("内容...\n")
    # ... 即使出错也没关系 ...
# 出了 with 块，文件自动关闭 ✓

with open(...) as f: 中的 as f 就是给文件对象起一个名字，让代码里用 f 来操作它。

返回整个文件的字符串，适合小文件

返回列表，每行是一个元素

.readline() — 读一行

每次调用读一行，需要时再读

🔄

for line in f — 推荐

逐行处理，内存友好，写法简洁

💡 as 的作用： as f 就是给打开的文件对象起个名字，和 import tkinter as tk 中的 as tk 一样 — 给一个东西起个短名字方便使用。

📚 新知识

split() 和 join() — 字符串与列表互转

这两个方法是互逆操作：split() 把字符串切分成列表，join() 把列表拼合成字符串。

🔪 split() — 字符串 → 列表

# 用逗号分割
s = "苹果,香蕉,橙子"
parts = s.split(",")
print(parts)
# ['苹果', '香蕉', '橙子']

# 用换行符分割
text = "第一行\n第二行\n第三行"
lines = text.split("\n")
print(lines)
# ['第一行', '第二行', '第三行']

# 用竖线分割
record = "1|学Python"
parts = record.split("|")
print(parts)
# ['1', '学Python']

🧩 join() — 列表 → 字符串

# 用逗号连接
items = ["苹果", "香蕉", "橙子"]
s = ",".join(items)
print(s)
# 苹果,香蕉,橙子

# 用换行符连接
lines = ["第一行", "第二行", "第三行"]
text = "\n".join(lines)
print(text)
# 第一行
# 第二行
# 第三行

# 用竖线连接（文件格式！）
status = "1"
content = "学Python"
record = "|".join([status, content])
print(record)
# 1|学Python
🔑 文件格式 = 约定好的分隔符： 我们用 | 分隔状态和内容，用 换行符 分隔每条记录。写文件用 join() 拼合，读文件用 split() 拆解，完美搭配！

split 和 join 是互逆操作，这是理解文件格式的关键。左右对照展示让学生直观感受两者的对称关系。强调 | 和换行两种分隔符在文件格式中的作用。

import os

def load_todos():
    """从文件加载所有待办"""
    if not os.path.exists(DATA_FILE):
        return  # 第一运行，还没文件

    with open(DATA_FILE, "r",
              encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            parts = line.split("|")
            status_str = parts[0]
            text = parts[1]
            status = (status_str == "1")
            todos.append({
                "done": status,
                "text": text
            })

每次操作后自动保存

只要数据变了，就立刻保存。这样即使程序崩溃，数据也不会丢。自动保存模式让用户完全无感。

✏️ 每个修改函数末尾加 save_todos()

def add_todo():
    text = entry.get().strip()
    if text:
        todo = {"done": False, "text": text}
        todos.append(todo)
        listbox.insert(tk.END, f"[ ] {text}")
        entry.delete(0, tk.END)
        save_todos()  # 保存！
        update_status()

def toggle_done():
    sel = listbox.curselection()
    if sel:
        i = sel[0]
        todo = todos[i]
        todo["done"] = not todo["done"]
        refresh_list()
        save_todos()  # 保存！

🔒 关闭窗口时保存 + 启动时加载

def on_closing():
    """窗口关闭时调用"""
    save_todos()   # 最后保一次
    window.destroy()

# 绑定关闭事件
window.protocol("WM_DELETE_WINDOW",
                on_closing)

# ====== 程序启动 ======
load_todos()         # 1. 先加载
for todo in todos:   # 2. 恢复到列表
    prefix = "✓" if todo["done"] else " "
    listbox.insert(tk.END,
                   f"[{prefix}] {todo['text']}")
update_status()      # 3. 更新状态栏
🔑 关键原则： 只要数据变了，就立刻保存。add_todo / toggle_done / delete_todo / clear_all — 每个函数的末尾都有 save_todos()。这样即使程序崩溃，数据也不会丢。
第6课 · 数据存文件
这是"自动保存"模式。学生应理解 save_todos() 在每个修改函数末尾都被调用。on_closing + protocol 绑定确保正常关闭时也保存。启动序列：先 load，再恢复列表，再更新状态。

import tkinter as tk
from tkinter import messagebox
import os  # ← 新增：检查文件是否存在

# 全局变量
DATA_FILE = "todos.txt"  # ← 新增
todos = []

# ====== 文件操作（新增）====== #
def save_todos():
    with open(DATA_FILE, "w",
              encoding="utf-8") as f:
        for todo in todos:
            s = "1" if todo["done"] else "0"
            f.write(f"{s}|{todo['text']}\n")

def load_todos():
    if not os.path.exists(DATA_FILE):
        return
    with open(DATA_FILE, "r",
              encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            parts = line.split("|")
            todos.append({
                "done": parts[0] == "1",
                "text": parts[1]
            })

# ====== 功能函数（修改）====== #
def add_todo():
    text = entry.get().strip()

def toggle_done():
    sel = listbox.curselection()
    if sel:
        i = sel[0]
        todos[i]["done"] = not todos[i]["done"]
        refresh_list()
        save_todos()  # ← 新增

def delete_todo():
    sel = listbox.curselection()
    if sel and messagebox.askyesno(
        "确认", "确定要删除吗？"):
        del todos[sel[0]]
        refresh_list()
        save_todos()  # ← 新增

def clear_all():
    if todos and messagebox.askyesno(
        "确认", "清空所有待办？"):
        todos.clear()
        refresh_list()

def on_closing():  # ← 新增
