📚 新知识

Entry 输入框 — 让用户打字

Entry 是一个单行文本输入框。用户可以点击它，然后用键盘输入文字。

entry = tk.Entry(
    window,
    font=("微软雅黑", 13),
    width=25
)
entry.pack()

# 获取输入内容
text = entry.get()

# 清空输入框
entry.delete(0, tk.END)
方法作用
.get() 获取输入框里的文字
.delete(0, END) 清空输入框，删除所有文字
.insert(0, "...") 在开头插入文字

delete(0, tk.END) 参数详解：

0 — 从第 0 个字符开始（即开头）
tk.END — 到最后一个字符（即末尾）
合起来：从头删到尾 = 全部清空

💡 类比： Entry 就像一张便利贴。`.get()` 是读上面的内容，`.delete(0, END)` 是把便利贴撕掉换新的。
第 3 课 · 输入文字吧
Entry 是第一个需要理解"方法"概念的控件——.get() 读取、.delete() 清空、.insert() 写入。delete(0, tk.END) 的参数容易让人困惑：0 是起始位置，tk.END 是结束位置，合起来就是全部删除。让学生当场试试每个方法。

📚 新知识

Listbox 列表框 — 显示一列内容

Listbox 是一个可滚动的列表，可以显示多条内容，用户可以选中其中某一项。

listbox = tk.Listbox(
    window,
    font=("微软雅黑", 12),
    height=15,
    width=40
)
listbox.pack()

# 在末尾添加一条
listbox.insert(tk.END, "学Python")

# 获取共有几条
count = listbox.size()

# 获取第 0 条内容
item = listbox.get(0)
方法作用
.insert(END, x) 在末尾添加一条内容
.delete(索引) 删除指定位置的一条
.size() 获取当前共有几条
.get(索引) 获取指定位置的内容

📏 索引（index）从 0 开始：

位置 0 → 第一条数据
位置 1 → 第二条数据
位置 2 → 第三条数据

💡 注意： tk.END 是一个特殊常量，表示"列表末尾"。listbox.insert(tk.END, "学Python") 的意思就是"在列表末尾插入一条"。
第 3 课 · 输入文字吧
Listbox 的方法和 Entry 很相似：都有 .insert() 和 .delete()，但 Listbox 多了 .size() 统计条数。索引从 0 开始是编程的通用规则，需要强调。tk.END 常量很实用——我们通常不需要知道列表里到底有几条，直接用 tk.END 就能加到末尾。

list 列表 — Python 的 数据容器

列表（list） 是 Python 中最常用的数据容器，可以按顺序存放多个数据。

# 创建一个列表
todos = ["学Python", "写作业", "做运动"]

# 列表操作
todos.append("学吉他")    # 添加元素
first = todos[0]          # 访问第 1 个
second = todos[1]         # 访问第 2 个
count = len(todos)        # 获取长度 → 4

# 列表可以混合不同类型
mixed = ["文字", 123, True, 3.14]

操作语法
创建列表todos = [...]
添加元素.append(x)
访问第 i 个todos[i]
获取长度len(todos)
💡 类比： 列表就像购物清单 📋——一行一行写，有顺序，可以随时加新东西。

if 条件判断 — 让程序学会"思考"

📝 if/else 语法

if 条件:
    条件成立时执行的代码
else:
    条件不成立时执行的代码
age = 15

if age >= 18:
    print("你是成年人")
else:
    print("你是未成年人")
# 本课的应用：判断输入是否为空
text = entry.get()
if text:        # 如果文字非空
    listbox.insert(tk.END, text)
else:
    print("请输入内容！")
💡 在 Python 中，空字符串 "" 被视为 False，非空字符串被视为 True。所以 if text: 就是在判断"输入了东西吗？"

🔢 比较运算符

运算符含义示例
==等于5 == 5 → True
!=不等于5 != 3 → True
>大于10 > 3 → True
<小于3 < 10 → True
>=大于等于10 >= 10 → True
<=小于等于3 <= 5 → True
⚠️ 重要区分：
== 两个等号 → 判断"等于"
= 一个等号 → 赋值（把右边装进左边）
第 3 课 · 输入文字吧
if 判断是编程的核心逻辑。两个关键点：1) == 和 = 的区别——这是初学者最常见的错误；2) Python 中空字符串是 False，所以 if text: 可以简洁地判断非空。让学生当场用 if 写几个判断练习。

Frame 容器 + 项目框架

Frame 是一个看不见的盒子，可以把多个控件装在一起，方便整体布局。

🔲 为什么需要 Frame？

水平排列

Entry 和 Button 默认是上下排列，用 Frame + side=tk.LEFT 可以让它们左右并排

整体控制

把一组相关控件装进 Frame，可以统一调整它们的位置（pady 等）

代码整洁

逻辑分组让代码更好读、更好改

# 创建 Frame 容器
input_frame = tk.Frame(window)
input_frame.pack(pady=15)

# 输入框 — 放在 Frame 左边
entry = tk.Entry(
    input_frame,              # 父容器是 Frame！
    font=("微软雅黑", 13),
    width=25
)
entry.pack(side=tk.LEFT, padx=(0, 5))

# 添加按钮 — 放在 Frame 右边
add_btn = tk.Button(
    input_frame,              # 父容器也是 Frame！
    text="添加 ✅",
    font=("微软雅黑", 12),
    bg="#4CAF50",
    fg="white"
)
add_btn.pack(side=tk.LEFT)
第 3 课 · 输入文字吧
Frame 是一个容易被忽视但很实用的控件。它本身的"不可见"特性正好用来做布局容器。关键概念：Entry 和 Button 的父容器从 window 变成了 input_frame——这意味着它们是 Frame 的"孩子"，在 Frame 内部用 side=LEFT 水平排列。

# ============================================
# 第 3 课：Entry 输入框和 Listbox 列表
# ============================================

import tkinter as tk

# ==================== 创建窗口 ====================

window = tk.Tk()
window.title("我的备忘录")
window.geometry("400x550")

# ==================== 标题区域 ====================

title_label = tk.Label(
    window,
    text="📝 我的备忘录",
    font=("微软雅黑", 20, "bold"),
    fg="#333333"
)
title_label.pack(pady=15)

subtitle_label = tk.Label(
    window,
    text="输入待办事项，点击添加吧！",
    font=("微软雅黑", 10),
    fg="#888888"
)
subtitle_label.pack(pady=5)

# ==================== 输入区域 ====================

input_frame = tk.Frame(window)
input_frame.pack(pady=15)

entry = tk.Entry(
    input_frame,
    font=("微软雅黑", 13),
    width=25
)
entry.pack(side=tk.LEFT, padx=(0, 5))

add_btn = tk.Button(
    input_frame,
    text="添加 ✅",
    font=("微软雅黑", 12),
    bg="#4CAF50",
    fg="white",
    padx=10,
    pady=5
)
add_btn.pack(side=tk.LEFT)

# ==================== 列表区域 ====================

list_label = tk.Label(
    window,
    text="📋 待办事项",
    font=("微软雅黑", 12, "bold"),
    fg="#555555"
)
list_label.pack(pady=(20, 5))

listbox = tk.Listbox(
    window,
    font=("微软雅黑", 12),
    height=15,
    width=40,
    selectbackground="#C8E6C9",
    selectforeground="#333333"
)
listbox.pack(pady=5)

# ==================== 核心功能 ====================

def add_todo():
    """获取输入框内容，添加到列表中"""
    text = entry.get().strip()      # 获取并清理文字

    if text:
        listbox.insert(tk.END, text)   # 添加到列表框
        entry.delete(0, tk.END)        # 清空输入框
        print(f"✅ 添加了：{text}")
    else:
        print("⚠️ 请输入待办事项！")

add_btn.config(command=add_todo)        # 绑定按钮点击

def on_enter_press(event):              # 绑定回车键
    add_todo()

entry.bind("<Return>", on_enter_press)

# ==================== 运行 ====================

entry.focus()           # 光标默认停在输入框
window.mainloop()
第 3 课 · 输入文字吧
完整代码分为 5 个区域：窗口、标题、输入、列表、核心功能。结构清晰，注释详细。关键点：add_todo() 函数的流程是 get → strip → if 判断 → insert/delete；add_btn.config(command=add_todo) 把函数绑定到按钮；entry.bind 绑定回车键。
