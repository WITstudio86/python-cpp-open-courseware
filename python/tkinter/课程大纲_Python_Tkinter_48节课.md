# Python Tkinter 课程大纲（48 节课）

> 适用对象：中小学生 / 编程入门者  
> 课程形式：线下兴趣班 / 社团（每节 60-90 分钟）  
> 前置要求：已掌握 Python 基础语法（变量、循环、条件判断、函数）  
> 核心理念：做中学 —— 每节课以一个小成品收尾

---

## 课程框架

| 阶段 | 课时 | 核心理念 | 节奏 |
|------|------|----------|------|
| 一：控件入门 | 第 1-18 节 | 每节课认识 1-2 个控件，以小成品收尾 | 一课一得 |
| 二：项目实战 | 第 19-36 节 | 每 2 节课完成一个完整小项目 | 两课一项目 |
| 三：综合进阶 | 第 37-48 节 | 稍大的综合性项目 + 课程总结 | 多课一项目 |

---

## 阶段一：控件入门（第 1-18 节）

### 第 1 节 · 认识 tkinter —— 创建你的第一个窗口
- 导入 tkinter，创建窗口对象
- 设置窗口标题、大小、背景色
- 理解 `mainloop()` —— 窗口为什么不会一闪而过
- **成品**：一个属于自己的窗口

### 第 2 节 · Label 标签 —— 在窗口上显示文字
- Label 的字体、颜色、对齐方式
- 用变量控制文本内容
- **成品**：一个"电子公告牌"

### 第 3 节 · Button 按钮 —— 让程序"听"你的指令
- 按钮创建与样式
- `command` 事件绑定
- 点击计数、切换文字
- **成品**："点我计数"小工具

### 第 4 节 · Entry 输入框 —— 让用户输入信息
- 单行文本输入
- `get()` 获取内容、`delete()` 清空
- **成品**："名字生成器"（输入 → 组合输出）

### 第 5 节 · 综合小练 —— 打招呼机器人
- 综合 Label + Button + Entry
- 输入名字 → 点击按钮 → 弹出个性化问候
- 练习控件之间的协同工作
- **成品**：会打招呼的小程序

### 第 6 节 · Frame 框架 + pack 布局（上）
- Frame 容器的概念 —— "一个装控件的盒子"
- 用 `pack()` 排列控件
- 理解父子关系
- **成品**："个人信息卡"（结构化布局）

### 第 7 节 · pack 布局（下）+ grid 布局入门
- pack 的 `side`、`anchor`、`fill`、`expand`
- grid 的行列概念（`row`、`column`）
- 两种布局方式对比
- **成品**：用两种布局做同一个界面

### 第 8 节 · grid 布局实战 —— 计算器界面
- 用 grid 精确排布按钮
- `columnspan`、`rowspan` 跨列跨行
- 只做界面，不做逻辑
- **成品**：计算器按钮面板

### 第 9 节 · Radiobutton + Checkbutton —— 选择题与多选
- Radiobutton 单选按钮（互斥选择）
- Checkbutton 复选框（多选）
- 绑定变量（`IntVar`、`StringVar`）
- **成品**："喜好收集器"

### 第 10 节 · 小项目 —— 趣味问答小测验
- 综合 grid 布局 + Radiobutton + Button
- 3 道选择题，选完出分
- 理解条件判断与界面联动
- **成品**：自动评分的知识测验

### 第 11 节 · Listbox 列表框 —— 展示和选择列表项
- 添加、删除、获取选中项
- 滚动条搭配使用
- **成品**："愿望清单"管理器

### 第 12 节 · Combobox 下拉框 —— 节省空间的选择器
- ttk 主题控件介绍
- 下拉选择城市 / 颜色 / 字体
- Combobox 与 Listbox 的区别与应用场景
- **成品**："个性名片生成器"

### 第 13 节 · Scale 滑块 + Spinbox 数字选择
- Scale 滑块：调节音量 / 大小 / 速度
- Spinbox 数字微调：选择数量 / 年龄
- `from_`、`to`、`resolution` 等参数
- **成品**："调色板"（RGB 三滑块调色）

### 第 14 节 · Text 文本框 —— 多行文本输入
- 插入文本、读取内容、清空
- 与 Entry 的区别
- 滚动条搭配
- **成品**："迷你记事本"

### 第 15 节 · Canvas 画布（上）—— 画图形
- Canvas 坐标系理解
- 画线段、矩形、椭圆、多边形
- 设置颜色、线宽、填充
- **成品**："几何图形画廊"

### 第 16 节 · Canvas 画布（下）—— 画图小工具
- 鼠标事件绑定（`<B1-Motion>`）
- 用鼠标拖动画线 / 画圆
- **成品**："涂鸦板"

### 第 17 节 · Menu 菜单栏 + Messagebox 弹窗
- 顶部菜单栏、右键菜单
- `messagebox` 的四种弹窗：信息、警告、确认、错误
- **成品**："带菜单的记事本"（壳子）

### 第 18 节 · 阶段综合 —— 个人信息小管家
- 综合应用阶段一所学控件
- Label + Entry + Radiobutton + Checkbutton + Combobox + Button
- 填完信息 → 汇总展示
- **成品**：一本"电子手账"

## 阶段二：项目实战（第 19-36 节）

> 每个项目 2 节课，第 1 节实现核心功能，第 2 节完善美化

### 第 19-20 节 · 项目 1：电子时钟

| 节次 | 内容 |
|------|------|
| 19 | 获取系统时间、用 Label 显示、`after()` 每秒刷新 |
| 20 | 美化界面：自定义字体、背景/文字颜色切换、12/24 小时制开关 |

### 第 21-22 节 · 项目 2：简易计算器

| 节次 | 内容 |
|------|------|
| 21 | 数字输入与运算符按钮、实现加减乘除逻辑 |
| 22 | 连续运算、清除（C）/ 退格（←）、键盘按键绑定 |

### 第 23-24 节 · 项目 3：猜数字游戏

| 节次 | 内容 |
|------|------|
| 23 | `random` 生成随机数、输入猜测、反馈"大了"/"小了" |
| 24 | 计次器、排行榜（记录最少步数）、重玩按钮 |

### 第 25-26 节 · 项目 4：待办事项清单

| 节次 | 内容 |
|------|------|
| 25 | 添加/删除任务、Listbox 展示、防重复添加 |
| 26 | 标记完成（勾选/划掉效果）、保存到 txt 文件、启动时加载恢复 |

### 第 27-28 节 · 项目 5：电子相册

| 节次 | 内容 |
|------|------|
| 27 | 用 PIL 加载本地图片、Label 显示、上下翻页浏览 |
| 28 | 缩略图预览、图片缩放适应窗口、幻灯片自动播放 |

### 第 29-30 节 · 项目 6：天气预报查询

| 节次 | 内容 |
|------|------|
| 29 | 用 Entry 输入城市名、`requests` 调用免费天气 API、解析 JSON |
| 30 | 美化展示（温度/天气/风向）、天气图标、多城市切换、错误处理 |

### 第 31-32 节 · 项目 7：单词记忆卡

| 节次 | 内容 |
|------|------|
| 31 | 随机显示单词、点击"翻面"看释义、下一词 |
| 32 | 分类词库（动物/水果/颜色）、已掌握/未掌握标记、学习统计 |

### 第 33-34 节 · 项目 8：迷你画图板

| 节次 | 内容 |
|------|------|
| 33 | 铅笔、直线、矩形工具切换（RadioButton 选工具） |
| 34 | 颜色选择器、橡皮擦、清空画布、保存为 PNG 图片 |

### 第 35-36 节 · 项目 9：密码管理器

| 节次 | 内容 |
|------|------|
| 35 | 账号/密码录入界面、简单加密（base64）、存储到 JSON 文件 |
| 36 | 列表查看所有账号、搜索过滤、复制密码到剪贴板 |

## 阶段三：综合进阶（第 37-48 节）

### 第 37-38 节 · 项目 10：贪吃蛇游戏

| 节次 | 内容 |
|------|------|
| 37 | Canvas 绘制蛇身、键盘方向控制、`after()` 定时移动 |
| 38 | 食物随机生成、得分系统、撞墙/撞自己判定、重新开始 |

### 第 39-40 节 · 项目 11：倒计时番茄钟

| 节次 | 内容 |
|------|------|
| 39 | 设定工作/休息时间、进度条可视化（Canvas 画弧）、开始/暂停/重置 |
| 40 | 任务名称记录、完成提示音、统计今日番茄数、历史记录 |

### 第 41-43 节 · 项目 12：班级通讯录

| 节次 | 内容 |
|------|------|
| 41 | 多信息录入（姓名/电话/QQ/备注）、Treeview 表格展示 |
| 42 | 搜索过滤、双击编辑、删除确认弹窗 |
| 43 | 数据 JSON 持久化、导入/导出 CSV 文件 |

### 第 44-46 节 · 项目 13：打字速度测试

| 节次 | 内容 |
|------|------|
| 44 | 随机范文显示、用户打字区、实时对比高亮正确/错误字符 |
| 45 | 倒计时模式、统计 WPM（字/分钟）、准确率 |
| 46 | 历史成绩记录、排行榜、难度选择（短文/中/长） |

### 第 47 节 · tkinter 进阶主题
- ttk 主题美化（`ttk.Style`）
- 设置窗口图标（`.ico`）
- `pyinstaller` 打包成 exe 文件简要演示
- 分享一些好用的第三方 tkinter 扩展库

### 第 48 节 · 自由创作 + 作品展
- 自选主题，综合运用所学知识做一个自己的小作品
- 课堂展示分享，互相试玩、交流
- 课程总结与回顾
