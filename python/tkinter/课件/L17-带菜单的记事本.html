五步搭菜单

Menu → config → 下拉菜单 → 命令 → cascade

新控件

Menu —— 专业软件的"灵魂"

菜单是一个三层结构：总菜单栏 → 下拉菜单 → 菜单项。就像文件夹套文件夹一样！

# 第1步：创建总菜单栏（容器）
menubar = tk.Menu(root)
root.config(menu=menubar)           # 挂到窗口上！

# 第2步：创建下拉菜单（tearoff=False 禁止拖出）
file_menu = tk.Menu(menubar, tearoff=False)

# 第3步：添加菜单项
file_menu.add_command(label="新建", command=new_file)
file_menu.add_command(label="打开", command=open_file)
file_menu.add_separator()            # 分隔线！
file_menu.add_command(label="退出", command=quit_app)

# 第4步：挂到菜单栏
menubar.add_cascade(label="文件", menu=file_menu)
🔑 最容易忘的一行：root.config(menu=menubar) —— 忘了这行，菜单栏不会显示！
【讲解】Menu —— 专业软件的"灵魂" 结合讲义《创建一个独立的 Menu 作为右键菜单》强调： · popup_menu = tk.Menu(root, tearoff=False) · popup_menu.add_command(label="剪切", command=cut_text) · popup_menu.add_command(label="复制", command=copy_text) · popup_menu.add_command(label="粘贴", command=paste_text) 幻灯片上可见要点： · 创建菜单栏 Menu · add_command / add_separator · 右键弹出菜单 post() · messagebox 对话框 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

post() 用屏幕坐标，不是控件坐标！

进阶技巧

右键菜单 + 四种对话框

# 右键菜单绑定
def show_popup(event):
    popup_menu.post(event.x_root, event.y_root)

text_area.bind("<Button-3>", show_popup)

# messagebox 使用
from tkinter import messagebox
result = messagebox.askyesno("退出", "确定退出？")
if result:
    root.quit()
💡 记住：event.x（控件内坐标）≠ event.x_root（屏幕坐标）。post() 需要屏幕坐标！
showinfo / showwarning / showerror / askyesno 四种对话框应对不同场景。

完整代码

记事本的代码结构

# 1. 导入并创建窗口
import tkinter as tk
from tkinter import messagebox
root = tk.Tk()
root.title("记事本")
root.geometry("600x450")

# 2. 创建菜单栏 + 三个下拉菜单
menubar = tk.Menu(root)
root.config(menu=menubar)
file_menu = tk.Menu(menubar, tearoff=False)
file_menu.add_command(label="新建", command=new_file)
file_menu.add_separator()
file_menu.add_command(label="退出", command=quit_app)
menubar.add_cascade(label="文件", menu=file_menu)

# 3. 右键菜单 + Text 编辑区
popup_menu = tk.Menu(root, tearoff=False)
text_area.bind("<Button-3>", show_popup)
text_area = tk.Text(root, wrap="word")
text_area.pack(fill="both", expand=True)

root.mainloop()

⚠️ accelerator="Ctrl+N" 只是在菜单上显示快捷键提示，并不会真正绑定快捷键——真正的快捷键需要另外用 root.bind() 绑定。

【讲解】记事本的代码结构 本页要点（照着讲即可）： · 创建菜单栏 Menu · add_command / add_separator · 右键弹出菜单 post() · messagebox 对话框 · 菜单栏 → 右键菜单 → Text → 对话框 · 完整代码 代码页节奏：先读懂输入输出 → 再走主流程 → 最后点出易错点（边界/类型/下标）。 可让学生预测下一行输出，再运行对照。
