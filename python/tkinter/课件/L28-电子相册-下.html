关键技巧

列表 · 索引 · % 取余

核心逻辑

列表 + 索引 = 翻页

photos = [img1, img2, img3, img4, img5]  # 图片列表
current_index = 0                         # 当前索引

def next_photo():
    global current_index
    current_index = (current_index + 1) % len(photos)
    # % 取余数：在最后一张 +1 回到 0
    show_photo()

def prev_photo():
    global current_index
    current_index = (current_index - 1) % len(photos)
    # -1 % 5 = 4，从第一张直接跳到第五张
    show_photo()
🔑 取余 % 的妙用：(idx + 1) % n 让索引在 0 到 n-1 之间循环，永远不会越界！

after() 语法

after(毫秒, 函数)

核心技巧

after() —— tkinter 的定时器

让函数每隔一段时间自动执行，实现轮播效果。

def auto_play():
    if playing:
        next_photo()
        root.after(2000, auto_play)  # 2秒后再次调用自己

# 开始播放
playing = True
auto_play()

# 停止播放 → 设 playing = False，不再安排 after

⏱️ after(ms, func)

ms 毫秒后执行 func。1000 毫秒 = 1 秒。

🛑 after_cancel(job_id)

取消一个已安排的定时任务，传入 after 的返回值。

thumbnail()

等比缩放，不变形

锦上添花

缩略图预览条

用 thumbnail() 生成小图，点击缩略图跳到对应大图。

for i, photo in enumerate(photos):
    thumb = photo.copy()
    thumb.thumbnail((80, 55))        # 等比缩放到 80x55 以内
    tk_thumb = ImageTk.PhotoImage(thumb)

    btn = tk.Button(thumb_frame, image=tk_thumb,
                    command=lambda idx=i: jump_to(idx))
    btn.image = tk_thumb               # 保存引用！
    btn.pack(side=tk.LEFT, padx=4)
⚠️ lambda 闭包陷阱：必须写 lambda idx=i: jump_to(idx)，不能写 lambda: jump_to(i)。否则所有按钮都会跳到循环结束时的 i 值！
