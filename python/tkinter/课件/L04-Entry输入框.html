创建输入框 —— Entry

Entry 是让用户 输入文字 的控件，和网页上的输入框一样。

import tkinter as tk

name_entry = tk.Entry(
    root,
    font=("微软雅黑", 16),   # 字体和大小
    width=20,               # 宽度
    bd=2, relief="solid",
    justify="center"
)
name_entry.pack(pady=10)
name_entry.insert(0, "在这里输入你的名字")

常用参数

font 字体 | width 宽度 | bd 边框 | relief 样式 | justify 对齐

get() —— 读取用户输入

get() 方法让你读取输入框里的文字内容。

def generate():
    # get() 读取输入框内容
    name = name_entry.get()

    if name and name != "在这里输入你的名字":
        result.config(text=f"你好，{name}！🎉")
    else:
        result.config(text="⚠️ 请先输入你的名字哦～")

get() 的行为

返回输入框中的文字（字符串）
空输入框返回 ""（空字符串）

何时调用

通常在按钮的回调函数中调用
用户在按钮点击时读取最新的输入

索引说明

0 = 第一个字符
tk.END = 末尾

delete() 和 insert() —— 清空与插入

# 清空输入框
name_entry.delete(0, tk.END)

# 从头删到尾
#   (0, tk.END) = 全部清空
清空按钮的常用写法
entry.delete(0, tk.END) 
# 插入文字
name_entry.insert(0, "请输入...")

# insert(位置, 文字)
#   0 = 插入到最前面
#   tk.END = 追加到末尾
小技巧
先在 insert() 前调用 delete() 清空，避免文字重复堆积。

show 参数 —— 蜜码模式

通过 show 参数可以让输入框显示掩码字符，常见于蜜码输入。

# show 参数 —— 蜜码模式
pwd_entry = tk.Entry(
    root,
    font=("微软雅黑", 14),
    show="●"  # 输入时显示 ● 而不是真实字符
)
pwd_entry.pack(pady=10)
也可以试试： 把 show 改成 "*" 或 "#"，体验不同的蜜码掩码效果。
