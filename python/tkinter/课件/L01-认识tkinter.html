改错时刻

这三处最容易错

❌ geometry("500*400")

✅ geometry("500x400")
中间必须是英文字母 x。

❌ print(“你好”)

✅ print("你好")
中文引号不是 Python 字符串，一运行就语法错误。

❌ mainloop() 写在创建控件之前

✅ mainloop() 放在最后一行
写在它后面的代码不会执行。
