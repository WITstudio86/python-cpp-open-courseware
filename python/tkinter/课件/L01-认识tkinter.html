新概念

什么是 tkinter？

tkinter 是 Python 自带的图形界面工具包。装了 Python 就有 tkinter，不需要额外安装。

🐍 以前的黑窗口

print() 输出在命令行里，黑底白字，只能用键盘交互。

🪟 现在的图形窗口

可以放按钮、输入框、图片……用户用鼠标点击就能操作！

💡 记住：所有 tkinter 程序都从 Tk() 开始，到 mainloop() 结束。这是固定套路！

四步法

导入 → 创建 → 设置 → 启动

写代码

四步创建一个窗口

# 第1步：导入 tkinter
import tkinter as tk
# 第2步：创建窗口
root = tk.Tk()
# 第3步：设置窗口属性
root.title("我的第一个窗口")
root.geometry("500x400")
root.configure(bg="#e8f5e9")
# 第4步：启动主循环（必须最后！）
root.mainloop()

⚠️ mainloop() 一定要放在代码最后一行！它后面的代码不会执行。
