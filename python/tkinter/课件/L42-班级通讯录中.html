关键概念

detach · reattach · KeyRelease

核心功能①

Treeview 实时搜索过滤

原理：遍历每一行 → 检查关键字是否在数据中 → detach（隐藏）或 reattach（显示）

def search_items():
    keyword = search_entry.get().strip().lower()
    for item in tree.get_children():
        values = tree.item(item, "values")
        row_text = " ".join(values).lower()
        if keyword == "" or keyword in row_text:
            tree.reattach(item, "", tk.END)  # 显示
        else:
            tree.detach(item)               # 隐藏

# 绑定：每输入一个字就触发搜索
search_entry.bind("<KeyRelease>", lambda e: search_items())
💡 重点：detach() 只是暂时隐藏，数据还在；delete() 才是彻底删除！

messagebox.askyesno

核心功能③

删除确认弹窗

直接删除太危险！用 messagebox.askyesno 弹出确认框。

from tkinter import messagebox

def delete_selected():
    selected = tree.selection()
    if not selected:
        messagebox.showwarning("提示", "请先选择联系人")
        return
    name = tree.item(selected[0], "values")[0]
    result = messagebox.askyesno("确认删除",
        f"确定要删除「{name}」吗？\n此操作不可撤销！")
    if result:
        tree.delete(selected[0])

⚡ askyesno 返回 True（是）或 False（否），非常直观！
