模块一 · 输入与提醒

Entry 输入 + 响铃提醒

Entry 像一张"填空题纸条"，用户填任务名；完成后 root.bell() "叮"一声。

📝 创建输入框

task_entry = tk.Entry(root, width=22,
                           font=("微软雅黑", 14))
task_entry.insert(0, "例如：背古诗")
# 获取用户输入
name = task_entry.get().strip()

🔔 播放提示音

root.bell()                    # 1. tkinter 自带响铃
import winsound                # 2. Windows 蜂鸣
winsound.Beep(1000, 500)
💡 .strip() 别忘：用户可能不小心打了空格。" 背单词 ".strip() → "背单词"

模块二三 · 统计与切换

番茄数统计 + 按钮状态切换

today_count = 0  # 全局变量记录番茄数

def time_up():
    global today_count
    today_count += 1
    count_label.config(text=f"🍅 今日番茄：{today_count} 个")
    root.bell()

# 按钮状态切换：运行中禁用开始，启用暂停
start_btn.config(state="disabled")
pause_btn.config(state="normal")

🍅 番茄计数器

每完成一个番茄 today_count += 1，Label 实时更新，成就感满满！

🎮 按钮状态机

运行→开始禁用暂停启用 / 暂停→变"继续" / 空闲→恢复初始
