卡片式布局 —— 信息分区

把不同信息放进不同的「卡片」(Frame)，视觉上清晰分明。

# 湿度卡片
humidity_card = tk.Frame(root, bg="white",
                          relief="solid", bd=1,
                          padx=25, pady=15)

humidity_label = tk.Label(humidity_card,
    text="💧 湿度\n60%",
    font=("微软雅黑", 14), bg="white",
    fg="#3498db")  # 蓝色

📏 padx / pady

Frame 的内边距，让内容不贴边。

🎨 颜色编码

温度=橙色、湿度=蓝色、风速=绿色，一眼能分辨。

😊 Emoji 对照函数

def get_emoji(desc):
    if "晴" in desc: return "☀️"
    if "云" in desc: return "⛅"
    if "雨" in desc: return "🌧️"
    if "雪" in desc: return "❄️"
    return "🌤️"

🔢 超大温度显示

temp_label = tk.Label(root,
    text="25°C",
    font=("微软雅黑", 52, "bold"),
    fg="#e67e22")  # 52号字!
💡 设计原则：温度是最重要的信息，用最大字号 + 醒目颜色（橙色）让它成为视觉焦点。

便捷功能

Listbox 多城市快速切换

cities = ["北京","上海","广州","深圳","杭州","Tokyo"]

city_listbox = tk.Listbox(root, height=4, ...)
for c in cities:
    city_listbox.insert(tk.END, c)

def on_city_select(event):
    sel = city_listbox.curselection()
    if sel:
        city = city_listbox.get(sel[0])
        entry.delete(0, tk.END)
        entry.insert(0, city)
        search(city)  # 自动查询!

city_listbox.bind("<<ListboxSelect>>", on_city_select)
🚀 一键查询：绑定 <<ListboxSelect>> 事件，选中城市后自动填入输入框并查询，省去点击按钮的步骤。
