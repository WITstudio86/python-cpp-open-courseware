新概念

grid() 网格布局

把窗口想象成一张表格，每个控件放在第几行（row）第几列（column），就能精确排列。

📐 pack() 布局

简单堆叠：上下左右排列，适合简单界面。

📊 grid() 布局

表格排布：行+列精确定位，适合表单和选择题。

# grid 常用参数
label.grid(row=0, column=0, columnspan=4, sticky="w")
# row=行号  column=列号（都从0开始）
# columnspan=跨几列  sticky=对齐方向(N/S/E/W)

Radiobutton 单选按钮

# 1. 创建一个 StringVar 存储用户选择
var = tk.StringVar(value="")

# 2. 创建 4 个 Radiobutton，共享同一个 variable
for option in ["A", "B", "C", "D"]:
    tk.Radiobutton(root, text=option,
                    variable=var,     # 同一组用同一个变量
                    value=option      # 选中时 var 被设成这个值
                    ).grid(...)

# 3. 获取用户选择
answer = var.get()  # 返回 "A" / "B" / "C" / "D"
💡 关键点：同一道题的 Radiobutton 必须共享同一个 variable，这样才能自动互斥！不同的题用不同的 variable。
