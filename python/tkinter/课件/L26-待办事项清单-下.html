关键方法

itemconfig() · curselection() · get()

功能 1

标记完成 —— 划掉已完成任务

选中一条任务，点「标记完成」，前面加上 ✓ 前缀，文字变灰色。

def mark_done():
    selection = listbox.curselection()    # 获取选中索引
    if selection:
        i = selection[0]
        task = listbox.get(i)
        if not task.startswith("✓ "):
            listbox.delete(i)              # 删掉旧的
            listbox.insert(i, "✓ " + task)  # 插入新的
            listbox.itemconfig(i, fg="gray")  # 变灰色
💡 小技巧：先 delete 再 insert，相当于"原地替换"。itemconfig 只改样式不改内容。

功能 2+3

保存 & 加载 —— 数据不会丢

💾 保存到文件

def save_tasks():
    with open("tasks.txt","w",
              encoding="utf-8") as f:
        for task in listbox.get(0,tk.END):
            f.write(task + "\n")

📂 启动时加载

def load_tasks():
    try:
        with open("tasks.txt","r",
                  encoding="utf-8") as f:
            for line in f.readlines():
                task = line.strip()
                if task:
                    listbox.insert(tk.END,task)
    except FileNotFoundError:
        pass
⚠️ 重要：encoding="utf-8" 不能省！否则中文会乱码。try...except 让程序首次运行不报错。

功能 4

关闭窗口时自动保存

不用手动点「保存」，关窗口时自动存！

def on_closing():
    save_tasks()          # 先保存
    root.destroy()        # 再关闭

root.protocol("WM_DELETE_WINDOW", on_closing)
🔗 protocol()：可以拦截窗口事件。WM_DELETE_WINDOW 就是"用户点了关闭按钮"这个事件。我们把它重新指向 on_closing 函数，先保存再关闭。
