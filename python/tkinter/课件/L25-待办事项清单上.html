关键概念

新控件

Listbox 列表控件 —— 你的第一条数据列表

Listbox 像一个容器，可以装好多条文字。用户可以点击选中任何一条，也可以新增或删除。

# 创建 Listbox
listbox = tk.Listbox(root, width=40, height=12,
    font=("Microsoft YaHei", 13),
    bg="#ffffff", fg="#2c3e50",
    selectbackground="#aed6f1")
listbox.pack()

📥 insert(tk.END, "内容")

把新项目添加到列表末尾，END = 最后面。

🗑 delete(索引)

删除指定位置。delete(0, tk.END) 可清空整个列表。

👆 curselection()

返回选中项的索引元组，要用 [0] 取出。没选则返回 ()，必须先 if selected: 判断。

📖 get(0, tk.END)

获取列表中所有项目，常用于"检查是否重复"。

核心技巧

三个函数搞定全部操作

核心功能

添加 + 删除 + 防重复 —— 三大核心函数

下面三个函数加起来不到 25 行，但已经能让你的待办清单"活"起来！

# ① 添加任务（含重复检查）
def add_task():
    task = entry.get().strip()                    # 获取并去空格
    if not task:                           # 空白 = 忽略
        return
    all_tasks = listbox.get(0, tk.END)      # 检查是否重复
    if task in all_tasks:
        result_label.config(text="⚠️ 重复！")
        return
    listbox.insert(tk.END, task)            # 添加到列表
    entry.delete(0, tk.END)                  # 清空输入框
    result_label.config(text="✅ 已添加！")

# ② 删除任务
def delete_task():
    selected = listbox.curselection()         # 获取选中索引元组
    if selected:
        listbox.delete(selected[0])            # 删除选中项
        result_label.config(text="🗑️ 已删除")

✅ add_task() 三步走

① 验证非空 → ② 检查是否重复 → ③ insert 进 Listbox，再清空 Entry。

🗑 delete_task() 两步走

① curselection() 取索引 → ② if 判断后 delete(索引)。
