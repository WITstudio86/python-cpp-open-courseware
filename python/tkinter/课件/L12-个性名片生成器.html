新控件

ttk.Combobox —— 下拉选择框

Combobox 是一个下拉选择框：点击它会出现一个列表，用户可以从中选择一项。它比手动输入更规范、更方便！

📦 导入方式

from tkinter import ttk
ttk 是 tkinter 的主题子模块，提供了更好看的控件。

🔧 关键参数

values=[] 设置选项列表
state="readonly" 禁止用户自己输入

# 创建 Combobox
from tkinter import ttk

combo = ttk.Combobox(root,
    values=["小明", "小红", "小刚"],
    state="readonly")          # 只能选，不能输入
combo.current(0)                  # 默认选中第0项
combo.pack()

# 获取用户选中的值
result = combo.get()             # 返回字符串，如 "小明"
💡 对比：Combobox 适合有限选项的场景（名字、年龄、城市），Entry 适合自由输入的场景（姓名、密码）。

事件名称

<<ComboboxSelected>>

事件绑定

监听用户的选择

当用户在 Combobox 中做出选择时，tkinter 会触发 <<ComboboxSelected>> 事件。用 bind() 方法可以"监听"这个事件，自动执行我们写好的函数。

# 定义回调函数（event 参数必须有）
def on_select(event):
    choice = combo.get()
    label.config(text=f"你选了：{choice}")

# 绑定事件：选择改变时自动调用 on_select
combo.bind("<<ComboboxSelected>>", on_select)
⚠️ 注意三点：
① 事件名是 双尖括号：<<ComboboxSelected>>
② 回调函数需要接收一个 event 参数
③ bind 里写函数名，不要加括号：on_select 而不是 on_select()

写代码

完整流程

# 第1步：创建三个下拉框
name_cb = ttk.Combobox(root, values=["小明","小红","小刚"], state="readonly")
age_cb = ttk.Combobox(root, values=["8岁","9岁","10岁"], state="readonly")
hobby_cb = ttk.Combobox(root, values=["编程","画画","足球"], state="readonly")

# 第2步：绑定事件，自动更新预览
name_cb.bind("<<ComboboxSelected>>", update_card)
age_cb.bind("<<ComboboxSelected>>", update_card)
hobby_cb.bind("<<ComboboxSelected>>", update_card)

# 第3步：点击按钮，生成最终名片
btn = tk.Button(root, text="生成名片", command=generate_card)

🎯 核心思路：Combobox 负责"选择"，Label 负责"展示"，bind 事件负责"联动"。
