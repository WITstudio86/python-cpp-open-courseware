知识点 1-2

Entry 输入 + after() 倒计时

用户输入分钟数 → 转成总秒数 → 每秒 after(1000, countdown) 调用自己减 1 秒。

entry = tk.Entry(root, font=("Arial", 16),
                  width=4, justify="center")
entry.insert(0, "25")
def start_timer():
    global total_seconds
    minutes = int(entry.get())  # 转数字
    total_seconds = minutes * 60
    countdown()
def countdown():
    global total_seconds
    if total_seconds > 0:
        total_seconds -= 1
        update_display()
        root.after(1000, countdown)
⚠️ 注意：entry.get() 返回的是字符串，必须用 int() 转成数字才能计算！

知识点 3-4

Canvas 画弧 + MM:SS 显示

arc = canvas.create_arc(
    40, 40, 260, 260,
    start=90, extent=359.9,
    outline="#ff6b6b", width=22,
    style="arc")
# 动态更新弧度
canvas.itemconfig(arc,
    extent=359.9 * 剩余比例)
m = total_seconds // 60
s = total_seconds % 60
time_str = f"{m:02d}:{s:02d}"
# Label 叠在 Canvas 中心
time_label = tk.Label(canvas,
    text=time_str, font=(...))
canvas.create_window(
    150, 150, window=time_label)

💡 extent=359.9 而非 360——360° 会被 tkinter 当成空弧！
