新概念

Entry 输入框 + Listbox 列表框

⌨️ Entry 输入框

单行文本输入，用户可以在里面打字。.get() 获取文字，.delete() 清空。

📋 Listbox 列表框

显示多条数据，用户可以点击选中。insert() 添加，delete() 删除。

# Entry：创建输入框
entry = tk.Entry(root, width=30)
entry.pack()

# 获取输入 → 添加到 Listbox
text = entry.get()
listbox.insert(tk.END, text)   # 加到末尾
entry.delete(0, tk.END)      # 清空输入框
【讲解】Entry 输入框 + Listbox 列表框 结合讲义《知识点 1：Entry 输入框》强调： · Entry 是单行文本输入框，用户可以在里面输入文字。 幻灯片上可见要点： · 创建 Entry 输入框 · 创建 Listbox 列表框 · 用 insert() 和 delete() 操作列表 · 用 Scrollbar 实现滚动 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

写代码

Scrollbar 滚动条 + 删除选中

# Scrollbar 与 Listbox 双向绑定
scrollbar = tk.Scrollbar(root)
listbox = tk.Listbox(root, yscrollcommand=scrollbar.set)
scrollbar.config(command=listbox.yview)

# 删除选中的项
def delete_selected():
    selected = listbox.curselection()  # 返回元组
    if selected:
        listbox.delete(selected[0])   # 删除第一个选中的
⚠️ 注意：curselection() 返回的是元组（如 (2,)），必须用 [0] 取出索引。没选中时返回空元组 ()。
【讲解】Scrollbar 滚动条 + 删除选中 结合讲义《知识点 3：Scrollbar 滚动条》强调： · 当 Listbox 中的内容太多、超出可视区域时，需要配合 Scrollbar 使用。 幻灯片上可见要点： · 创建 Entry 输入框 · 创建 Listbox 列表框 · 用 insert() 和 delete() 操作列表 · 用 Scrollbar 实现滚动 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
