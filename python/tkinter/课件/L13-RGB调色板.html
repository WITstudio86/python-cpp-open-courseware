新控件

Scale —— 滑动条

Scale 是一个滑动条控件，用户可以拖动滑块在指定范围内选择一个数值。command 回调会在拖动时实时触发。

# 创建 Scale 滑块
def on_slide(val):
    # val 是当前滑块值（字符串类型）
    print(f"当前值：{val}")

scale = tk.Scale(root,
    from_=0,              # 最小值（注意下划线！）
    to=255,                # 最大值
    orient=tk.HORIZONTAL,  # 横向滑动
    length=300,             # 轨道长度（像素）
    command=on_slide)      # 拖动时实时调用
scale.set(128)          # 设置初始值
scale.get()              # 获取当前值

🔴 RGB 颜色模型

R(红) + G(绿) + B(蓝)
每个通道 0~255 级
3 个通道 → 1670 万色

⚠️ from_ 的下划线

from 是 Python 关键字
所以参数名写成 from_
这是固定写法，不能省略！

Spinbox —— 数字微调框

Spinbox 是一个带上下箭头的数字输入框。点击箭头微调数值，也可以直接输入精确值。和 Scale 搭配使用：一个粗调、一个精调！

# 创建 Spinbox 数字微调框
spin = tk.Spinbox(root,
    from_=0,              # 最小值
    to=255,               # 最大值
    increment=1,          # 每次点击变化的步长
    width=5,               # 输入框宽度
    command=on_spin)       # 点击箭头时调用

# 设置初始值
spin.delete(0, tk.END)
spin.insert(0, "128")
🔗 联动技巧：在回调函数中同时更新 Scale 和 Spinbox，让两个控件始终保持同步。
Scale 适合拖动粗调；Spinbox 适合精确微调。

写代码

实时颜色更新的秘密

# 核心函数：读取 RGB 值，更新预览区
def update_color(*args):
    r = red_scale.get()
    g = green_scale.get()
    b = blue_scale.get()

    # 转成十六进制颜色码，如 R=255,G=128,B=0 → "#ff8000"
    hex_color = f"#{r:02x}{g:02x}{b:02x}"

    # 更新预览区背景色 + 数值标签
    color_preview.config(bg=hex_color)
    rgb_label.config(text=f"R:{r} G:{g} B:{b}\n{hex_color}")

    # 同步 Spinbox 数字框
    red_spin.delete(0, tk.END)
    red_spin.insert(0, str(r))

💡 f"{r:02x}" 是 f-string 格式化——把整数 r 转成 2 位十六进制小写字符串（如 255 → "ff"）。
