新概念

Canvas 坐标系统

Canvas 画布有自己的坐标系统，原点 (0,0) 在左上角——这和数学课本里的坐标系不一样！

📐 数学坐标系

原点在左下角，Y 轴向上增大。这是我们习惯的坐标系。

💻 屏幕坐标系

原点在左上角，Y 轴向下增大。这是所有计算机绘图的规则。

💡 记住口诀：左上角是 (0,0)，向右 X 变大，向下 Y 变大。所有 Canvas 绘图都基于这个规则！
【讲解】Canvas 坐标系统 结合讲义《知识点 1：Canvas 坐标系统》强调： · Canvas（画布）是 tkinter 的**绘图控件**。它有一个自己的坐标系统： · (0,0) ──────────────────── X 轴（向右增加） · │ (50, 50) · │ (350, 250) · Y 轴（向下增加） 幻灯片上可见要点： · 理解 Canvas 坐标系统 · 学会画直线和矩形 · 学会画椭圆、圆和多边形 · 掌握颜色填充和线条样式 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

Canvas 五大绘图方法

# 创建画布：宽500，高400，白色背景
c = tk.Canvas(root, width=500, height=400, bg="white")
c.pack()

c.create_line(30,60, 470,60, fill="orange", width=4)               # 直线
c.create_rectangle(30,100,130,200, fill="lightblue")                # 矩形
c.create_oval(170,100,300,200, fill="lightgreen")                   # 椭圆
c.create_oval(340,110,420,190, fill="pink")                         # 正圆（正方形外接矩形）
c.create_polygon(230,280, 80,380, 380,380, fill="yellow")       # 三角形
c.create_text(250,25, text="🎨 画廊", font=("微软雅黑",22,"bold")) # 文字
【讲解】Canvas 五大绘图方法 结合讲义《知识点 1：Canvas 坐标系统》强调： · Canvas（画布）是 tkinter 的**绘图控件**。它有一个自己的坐标系统： · (0,0) ──────────────────── X 轴（向右增加） · │ (50, 50) · │ (350, 250) · Y 轴（向下增加） 幻灯片上可见要点： · 理解 Canvas 坐标系统 · 学会画直线和矩形 · 学会画椭圆、圆和多边形 · 掌握颜色填充和线条样式 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
