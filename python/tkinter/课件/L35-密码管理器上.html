新知识

Entry 输入框 & base64 加密

📝 Entry 单行输入

.get() 取文字、.delete(0,END) 清空、show="*" 密码模式。与 Label 搭配制作表单。

🔑 base64 暗号

base64 把明文变成一串乱码。加密：b64encode()；解密：b64decode()。虽不是真正加密，但对初学者够用。

import base64

# 加密：明文 → 密文（encode→加密→decode）
pwd = "mypassword123"
encoded = base64.b64encode(pwd.encode("utf-8")).decode("utf-8")

# 解密：密文 → 明文
decoded = base64.b64decode(encoded.encode("utf-8")).decode("utf-8")

# Entry 密码模式
pwd_entry = tk.Entry(root, show="*", width=30)

新知识

用 JSON 文件永久保存数据

JSON 是一种轻量数据格式，Python 的 json 模块可以轻松把字典/列表存到文件，关掉程序后数据还在！

📥 写入文件 dump

json.dump(data, f, ensure_ascii=False, indent=2) —— 把数据存成排版漂亮的 JSON 文件。

📤 读取文件 load

json.load(f) 读取文件并还原为 Python 列表/字典。记得处理 FileNotFoundError。

import json, os

# 保存数据（ensure_ascii=False 保证中文可读）
data = [{"site":"bilibili.com", "user":"xm", "pwd":"bXlwYXNz"}]
with open("passwords.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# 读取数据（文件不存在就返回空列表）
if os.path.exists("passwords.json"):
    with open("passwords.json", "r", encoding="utf-8") as f:
        data = json.load(f)
else:
    data = []
