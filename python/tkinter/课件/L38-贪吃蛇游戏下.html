知识点 1-2

随机食物 + 吃食物变长

每次被吃掉后，食物随机出现在新位置；蛇头碰到食物时 不删尾巴，蛇就多一节！

import random
food_x = random.randint(0, 29) * 20
food_y = random.randint(0, 29) * 20
# 移动并判断吃食物
snake.insert(0, new_head)
if snake[0] == (food_x, food_y):  # 吃到了
    score += 10
    create_food()
else:
    snake.pop()  # 没吃到→保持原长
🐍 变长的秘密：snake.pop() 删掉尾巴。吃到食物时 跳过这行，尾部保留 → 身体多一节！
【讲解】随机食物 + 吃食物变长 本页要点（照着讲即可）： · 随机生成食物 random · 吃食物变长 & 加分 · 撞墙 / 撞自己判定 · 游戏结束 & 重新开始 · random · eat_food · snake.pop() · 变长技巧 · 知识点 1-2 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

def check_collision(x, y):
    # 撞墙？
    if x<0 or x>=600 or \
       y<0 or y>=600:
        return True
    # 撞自己？
    if (x, y) in snake[1:]:
        return True
    return False
💥 Game Over → 重新开始：停止 after() 循环 → 显示"游戏结束"文字 → 点"重新开始"按钮重置所有变量。
