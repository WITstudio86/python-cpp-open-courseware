config() —— 动态修改控件

config() 方法让你在程序运行后动态修改控件属性，这是实现互动效果的核心！

# 在按钮回调中，用 config() 更新 Label 的文字
def say_hello():
    name = name_entry.get().strip()
    if name:
        reply.config(
            text=f"你好，{name}！很高兴认识你！😊"
        )
    else:
        reply.config(text="你还没告诉我你的名字呢！😅")

config() 可以修改哪些属性？

text 文字 | fg 颜色 | bg 背景 | font 字体 | state 状态

互动程序的核心模式

理解了 config() 之后，来看看互动程序的完整流程：

互动程序的核心模式
用户输入 → 点击按钮 → 回调函数中读取输入 → 用 config() 更新界面 → 用户看到反馈

这个模式适用于所有互动程序

无论是打招呼机器人、计算器、还是聊天程序，核心都是这个循环：监听用户操作 → 读取数据 → 更新界面 → 等待下一次操作

组装机器人 —— 完整代码

title = tk.Label(root, text="🤖 打招呼机器人",
    font=("微软雅黑", 22, "bold"))
title.pack(pady=20)

prompt = tk.Label(root, text="机器人：你叫什么名字呀？")
prompt.pack(pady=10)
name_entry = tk.Entry(root, font=("微软雅黑", 15), width=20)
name_entry.pack(pady=5)
reply = tk.Label(root, text="", font=("微软雅黑", 16, "bold"))
reply.pack(pady=15)

def say_hello():
    name = name_entry.get().strip()
    if name:
        reply.config(text=f"你好，{name}！😊")

tk.Button(root, text="👋 打招呼！",
    command=say_hello, bg="#0097a7",
    fg="white").pack(pady=5)
