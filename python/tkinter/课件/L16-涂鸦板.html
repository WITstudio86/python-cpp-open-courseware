新控件

Canvas —— 可以画画的"画布"

Canvas 是 tkinter 的绘图区域，可以在上面画线、画圆、画矩形……涂鸦板的核心就是一张白色的 Canvas！

📐 创建画布

canvas = tk.Canvas(root, width=500, height=400, bg="white")

⭕ 画一个圆

canvas.create_oval(x1, y1, x2, y2, fill="red")
给外接矩形的左上角和右下角坐标

# Canvas 的坐标系：原点 (0,0) 在左上角
# x 轴：从左到右增大
# y 轴：从上到下增大
canvas.create_oval(10, 10, 50, 50, fill="red")
#       左上角(10,10)    右下角(50,50)  → 直径40的红色圆
💡 记忆：create_oval 的四个参数是"外接矩形"的坐标。如果宽=高，就是正圆；宽≠高，就是椭圆。

核心知识点

鼠标事件 —— 让程序"感知"你的鼠标

tkinter 用 bind() 方法把鼠标操作和函数"绑"在一起。当事件发生时，自动调用函数。

🖱️ 三个常用事件

<B1-Motion> ：按住左键拖动
<Button-1> ：按下左键
<ButtonRelease-1> ：松开左键

📍 获取鼠标坐标

event.x ：鼠标在画布上的水平位置
event.y ：鼠标在画布上的垂直位置
坐标原点 (0, 0) 在画布左上角 

def draw(event):
    # event 是 tkinter 自动传入的事件对象
    r = brush_size / 2
    canvas.create_oval(
        event.x - r, event.y - r, # 以鼠标为中心
        event.x + r, event.y + r,
        fill=brush_color
    )

canvas.bind("<B1-Motion>", draw)  # 绑定！

完整代码

涂鸦板的代码结构

# 1. 导入并创建窗口
import tkinter as tk
root = tk.Tk()
root.title("涂鸦板")
root.geometry("550x550")

# 2. 画布 + 鼠标事件绑定
canvas = tk.Canvas(root, width=500, height=400, bg="white")
canvas.pack()

def draw(event):
    r = brush_size / 2
    canvas.create_oval(event.x-r, event.y-r, event.x+r, event.y+r,
                     fill=brush_color, outline=brush_color)
canvas.bind("<B1-Motion>", draw)

# 3. 颜色按钮（lambda c=color 捕获当前值） + 清除按钮
for text, color in colors:
    btn.command = lambda c=color: change_color(c)

root.mainloop()

⚠️ 颜色按钮的 lambda c=color: 非常关键——必须用默认参数"捕获"当前循环值，否则所有按钮都会指向最后一个颜色！
