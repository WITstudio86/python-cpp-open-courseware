新概念

random.randint() 生成随机数

Python 内置的 random 模块可以生成随机数。每次运行程序，结果都不一样！

import random

# randint(a, b)：随机返回 a~b 之间的整数（包含 a 和 b）
secret = random.randint(1, 100)   # 1~100 之间的随机整数
print(secret)                     # 调试用，正式游戏要隐藏这行！

🎲 randint(a, b) 包含两端

从 a 到 b 之间随机挑一个整数，1 和 100 都有可能！
randint(0, 1) 像抛硬币，randint(1, 10) 从 1~10 随机挑。

🎰 choice(列表) 随机选一个

从列表中随机选一个元素：random.choice(["苹果","香蕉","橘子"])
每次运行可能结果不同！

核心逻辑

判断大小并给出反馈

游戏的核心就是一个 if-elif-else 判断：玩家的数字比秘密数字大还是小？

def guess():
    # ① 从输入框获取文字，转成整数
    user_num = int(entry.get())

    # ② 比较大小，更新 Label 提示
    if user_num > secret:
        result_label.config(text="📉 太大了！再猜小一点")
    elif user_num < secret:
        result_label.config(text="📈 太小了！再猜大一点")
    else:
        result_label.config(text="🎉 恭喜你猜对了！")

📥 获取输入 + 🔄 类型转换

entry.get() 获取输入的字符串，用 int() 转成整数才能比较大小。用 try-except 防止 "abc" 崩溃。

🔀 if-elif-else + 📢 反馈

三种情况分别处理：大于 → "太大了"、小于 → "太小了"、等于 → "恭喜"。用 config(text=...) 即时更新 Label。
