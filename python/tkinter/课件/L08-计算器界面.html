title = tk.Label(
    root,
    text="🔢 计算器",
    font=("微软雅黑", 16, "bold"),
    fg="#ffffff",
    bg="#263238"
)
title.grid(row=0, column=0, columnspan=4, pady=(10, 5))

display = tk.Label(
    root,
    text="0",
    font=("Consolas", 28, "bold"),
    fg="#ffffff",
    bg="#37474f",

    pady=15,
    relief="sunken",
    bd=3
)

    row=1, column=0,
    columnspan=4,    # ← 跨 4 列！
    sticky="nsew",   # ← 填满整个格子

)

改错时刻

这三处最容易错

❌ geometry("500*400")

✅ geometry("500x400")
中间必须是英文字母 x。

❌ print(“你好”)

✅ print("你好")
中文引号不是 Python 字符串，一运行就语法错误。

❌ mainloop() 写在创建控件之前

✅ mainloop() 放在最后一行
写在它后面的代码不会执行。
