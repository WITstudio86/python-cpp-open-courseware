grid 精确定位

将窗口划分为网格，通过 row（行）和 column（列）放置组件。

基本语法

widget.grid(row=0, column=0)
widget.grid(row=1, column=2)

行号和列号都从 0 开始。例如：

btn_7.grid(row=3, column=0)
btn_9.grid(row=3, column=2)
注意：同一容器中 grid 和 pack 不能混用！

columnspan 和 rowspan —— 跨行跨列

columnspan（跨列）

让组件横向占据多列宽度

# 显示屏横跨 4 列
display.grid(
    row=1, column=0,
    columnspan=4
)

适用场景：显示区域、标题栏、"0" 键等

rowspan（跨行）

让组件纵向占据多行高度

# 等号按钮跨 2 行
btn_eq.grid(
    row=5, column=3,
    rowspan=2
)

适用场景：等号键、合并单元格等

【讲解】columnspan 和 rowspan —— 跨行跨列 结合讲义《2. columnspan —— 跨多列》强调： · 让一个组件占据多列的宽度，适用于显示区域、标题栏等需要更大空间的元素。 · display.grid(row=0, column=0, columnspan=4) # 横跨 4 列 · 在计算器中，显示屏需要占据整个宽度，所以设置 columnspan=4 横跨 4 列。 幻灯片上可见要点： · grid 精确定位 · columnspan / rowspan · sticky 对齐方式 · 搭建计算器面板 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

sticky —— 让按钮填满格子

sticky 控制组件在格子内的对齐方向，用方位字母组合

sticky 参数对照表

sticky="n"   # 靠上（北 North）
sticky="s"   # 靠下（南 South）
sticky="w"   # 靠左（西 West）
sticky="e"   # 靠右（东 East）
sticky="nsew" # 四边填满
sticky="ew"   # 水平填满
sticky="ns"   # 垂直填满

计算器中的 sticky 应用

display.grid(row=1, column=0, columnspan=4, sticky="nsew")
tk.Button(root, text="7", ...).grid(row=3, column=0, sticky="nsew")
关键配合：sticky="nsew" 只是"想要填满"，还需配合 grid_rowconfigure(weight=1) 才能真正拉伸！

【讲解】sticky —— 让按钮填满格子 结合讲义《4. sticky —— 对齐方式》强调： · sticky 控制组件在分配到的格子内的对齐方式，取值基于方位： · btn.grid(row=1, column=0, sticky="nsew") # 按钮填满格子 · display.grid(row=0, column=0, sticky="ew") # 只在水平方向填满 · 注意： sticky="nsew" 只是让组件"想要"填满格子。格子本身是否足够大，还取决于 grid_rowconfigure 和 grid_columnconfigure 的 weight 设置。 幻灯片上可见要点： · grid 精确定位 · columnspan / rowspan · sticky 对齐方式 · 搭建计算器面板 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
