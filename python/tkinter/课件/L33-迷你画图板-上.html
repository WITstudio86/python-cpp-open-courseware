🖼️ Canvas 画布

canvas = tk.Canvas(root,
    width=650, height=400,
    bg="white")
canvas.pack()

# 画线：起点→终点
canvas.create_line(
    x1,y1, x2,y2,
    fill="black", width=2)

🔘 Radiobutton

tool = tk.StringVar(
    value="pencil")

tk.Radiobutton(root,
    text="✏️ 铅笔",
    variable=tool,
    value="pencil")

tk.Radiobutton(root,
    text="📏 直线",
    variable=tool,
    value="line")

三事件

按下 → 拖拽 → 释放

核心机制

鼠标三事件 —— 按下、拖拽、释放

事件绑定触发时机
按下<Button-1>按下鼠标左键
拖拽<B1-Motion>按住左键移动
释放<ButtonRelease-1>松开鼠标左键
canvas.bind("<Button-1>", on_press)
canvas.bind("<B1-Motion>", on_drag)
canvas.bind("<ButtonRelease-1>", on_release)

def on_drag(event):
    # event.x, event.y = 鼠标在 Canvas 上的坐标
    canvas.create_line(last_x, last_y,
                        event.x, event.y)

区别

工具原理

铅笔 vs 直线 —— 两种画法

✏️ 铅笔 = 连点成线

拖拽时不断在「上一个位置 → 当前位置」之间画小线段。大量小线段连起来就像自由涂鸦。

capstyle=tk.ROUND 圆头线端更流畅

📏 直线 = 两点一线

按下记录起点，拖拽时显示灰色预览虚线（dash），释放时删除预览、画真正的实线。

预览线用 dash=(4,4) 做虚线效果

🔀 关键：根据 tool.get() 的值，在同一个 on_press/on_drag/on_release 中走不同的分支逻辑。
