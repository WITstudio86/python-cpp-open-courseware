JSON 数据持久化

JSON 是通用的数据交换格式，Python 自带 json 模块。

📥 保存到文件

data = [{"name":"张三","phone":"138","note":"同桌"}]
with open("contacts.json","w") as f:
    json.dump(data, f,
        ensure_ascii=False,
        indent=2)

📤 从文件读取

with open("contacts.json","r") as f:
    data = json.load(f)
for contact in data:
    tree.insert("", tk.END,
        values=(contact["name"], ...))
💡 ensure_ascii=False 让中文正常显示；indent=2 让文件格式美观易读。

CSV 导入导出

CSV 是 Excel 能直接打开的表格格式，用 csv 模块 + filedialog 实现。

file_path = filedialog.asksaveasfilename(  # 导出
    defaultextension=".csv", filetypes=[("CSV文件","*.csv")])
with open(file_path, "w", newline="", encoding="utf-8-sig") as f:
    writer = csv.writer(f)
    writer.writerow(["姓名", "电话", "备注"])
    for item in tree.get_children():
        writer.writerow(tree.item(item, "values"))
# 导入用 csv.reader，类似上述
💡 utf-8-sig 带 BOM 头，让 Excel 正确识别中文，不会乱码！
