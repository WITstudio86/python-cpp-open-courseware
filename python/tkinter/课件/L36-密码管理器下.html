新控件

Listbox —— 可滚动的名单列表

Listbox 就像一个可滚动的小本子，每行写一条记录，用户可以点击选中。

# 创建 Listbox
listbox = tk.Listbox(root, width=35, height=12,
                       font=("微软雅黑", 11),
                       selectbackground="#4a90d9")

# 添加数据：tk.END 表示追加到末尾
listbox.insert(tk.END, "🌐 百度 — admin")
listbox.insert(tk.END, "🌐 淘宝 — user123")

# 获取选中的项
selected = listbox.curselection()  # 返回 (0,) 或空元组
if selected:
    text = listbox.get(selected[0])
💡 记忆技巧：Listbox 像 Python 的列表，行号从 0 开始。用 curselection() 问"你选了哪一行？"

两个利器

KeyRelease 事件 · clipboard_append

新技能

搜索过滤 + 复制到剪贴板

🔍 搜索过滤四步法

① 获取关键词 → search_entry.get()
② 清空列表 → listbox.delete(0, END)
③ 遍历匹配 → if keyword in site
④ 重新填入 → listbox.insert(END, ...)

📋 复制到剪贴板

先清空 → root.clipboard_clear()
再写入 → root.clipboard_append(密码)
⚠️ 必须先 clear！append 是追加模式。 

# 绑定搜索：每次按键松开就过滤
search_entry.bind("<KeyRelease>", filter_list)

# 复制密码到剪贴板（必须先 clear 再 append！）
root.clipboard_clear()
root.clipboard_append(password)
