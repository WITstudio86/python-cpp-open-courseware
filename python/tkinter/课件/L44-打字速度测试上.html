text_label = tk.Label(root,

input_text = tk.Text(root,
    font=("微软雅黑", 18),
    height=4, width=50,
    wrap="word")  # 按词换行

核心功能

实时逐字对比高亮

用 Text 的 tag 机制给文字上色：打对 → 绿色，打错 → 红色。

input_text.tag_config("correct", foreground="#2e7d32")
input_text.tag_config("wrong", foreground="#c62828", background="#ffebee")
def check_typing(event=None):  # 每次按键后对比
    user_text = input_text.get("1.0", tk.END).rstrip("\n")
    for i, char in enumerate(user_text):
        pos = f"1.{i}"
        if i < len(current_text) and char == current_text[i]:
            input_text.tag_add("correct", pos)  # 绿色
        else:
            input_text.tag_add("wrong", pos)   # 红色
💡 Text 索引格式："1.0" = 第1行第0个字符，"1.5" = 第1行第5个字符。

tag_config 可以做什么？

🎨 不只是颜色

foreground、background、font、underline 等任意样式均可设置。

📍 索引方式

"1.0"=第1行0字符，"2.5"=第2行5字符，tk.END=末尾。

🔧 常用操作

tag_add 标记 → tag_remove 清除 → tag_delete 删除。
