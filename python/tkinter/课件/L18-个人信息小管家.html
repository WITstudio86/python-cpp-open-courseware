单选共享一个变量 value 区分；多选各自绑定 BooleanVar

tk.Radiobutton(root, variable=v, value=1)
tk.Checkbutton(root, variable=bv)

📁 Combobox · 下拉框 + 🔳 Button · 按钮

下拉框点击展开选一项（来自 ttk）；按钮点击触发动作

ttk.Combobox(root, values=[...])
tk.Button(root, text="提交", command=fn)

🧩 表单创建核心代码

# 1. 定义变量 —— 控件和 Python 之间的桥梁
import tkinter as tk
from tkinter import ttk

name_var = tk.StringVar()        # 姓名
gender_var = tk.IntVar(value=1)    # 性别: 1=男, 0=女
hobby_var = tk.BooleanVar()      # 爱好
grade_var = tk.StringVar()       # 年级

# 2. 创建表单控件
tk.Entry(root, textvariable=name_var)
tk.Radiobutton(root, variable=gender_var, value=1)  # 男
tk.Radiobutton(root, variable=gender_var, value=0)  # 女
tk.Checkbutton(root, variable=hobby_var)
ttk.Combobox(root, textvariable=grade_var,
               values=["三年级","四年级"])

# 3. 提交按钮：读取所有值、汇总显示
def submit():
    name = name_var.get()
    gender = "男" if gender_var.get() == 1 else "女"
    grade = grade_var.get()
    result_label.config(text=f"汇总: {name}...")
💡 核心要点： StringVar / IntVar / BooleanVar 是控件和代码之间的桥梁。用 .get() 读取，用 .set() 写入，用 .config(text=...) 更新 Label 显示。
