界面升级

ttk 主题美化

ttk（themed tk）是 tkinter 的"美化版"——同样功能，更好看。

🎨 切换主题

style = ttk.Style()
style.theme_use("clam")
# macOS: aqua | Win: vista/xpnative
# 跨平台: clam/alt

🎨 自定义样式

style.configure("TButton",
    font=("微软雅黑",12),
    padding=10)
style.configure("My.TLabel",
    font=("",48,"bold"),
    foreground="#e91e63")
💡 子样式命名规则："Name.TWidgetType" → 如 "Timer.TLabel" 只影响指定了这个名称的 Label。

分享与发布

窗口图标 + pyinstaller 打包

🪟 设置窗口图标

# 方式一：ico 文件
root.iconbitmap("icon.ico")
# 方式二：png/gif 文件（跨平台）
img = tk.PhotoImage(file="icon.png")
root.iconphoto(True, img)

📦 pyinstaller 打包成 exe

pip install pyinstaller

pyinstaller --onefile --windowed \
    --name "番茄钟" main.py

# --onefile 单个文件  --windowed 不显示黑窗口
# 输出: dist/番茄钟.exe
