什么是 Frame？—— 收纳盒概念

Frame 就像一个收纳盒，你可以把控件放进去，分门别类地管理它们。

没有 Frame

所有控件直接放在 root 上，像散落一地的文具 —— 乱糟糟！

有了 Frame

不同区域的控件放在各自的 Frame 里，像分类好的收纳盒 —— 整整齐齐！

创建 Frame —— 代码示例

# 创建一个 Frame —— 控件的"收纳盒"
my_frame = tk.Frame(
    root,                  # 父容器（谁装这个 Frame）
    bg="#ffffff",           # 背景颜色
    relief="groove",         # 边框样式：groove/ridge/solid/sunken/flat
    bd=3,                   # 边框宽度（像素）
    padx=20,                # 内部左右留白
    pady=15                  # 内部上下留白
)
my_frame.pack(pady=10, padx=30)
小提示： Frame 本身是看不见的（除非设置了 bg 和 relief），它只是一个"容器"。设置 bg 和 relief 可以帮助你看清它的边界。

pack() —— 让控件排队

pack() 是最简单的布局方法。默认情况下，控件会从上到下一个接一个地堆叠。

# pack() 基础用法 —— 默认从上到下排列
tk.Button(root, text="第 1 个").pack()
tk.Button(root, text="第 2 个").pack()
tk.Button(root, text="第 3 个").pack()

# 带间距的 pack
label.pack(pady=10)           # 上下各留 10px 间距
frame.pack(padx=30, pady=10) # 左右 30px，上下 10px

# fill 填充 —— 让控件填满整行
frame.pack(fill="x")            # 横向填满父容器

pady / padx

外部间距：控件与周围其他东西之间的距离。放在 pack() 的参数里。

padx / pady（Frame）

内部间距：Frame 边框和内部控件之间的距离。放在 Frame() 的参数里。

父子关系 —— 谁是谁的爸爸

在 tkinter 中，每个控件创建时都要指定它的"爸爸"（父容器）。

# root 是"爷爷"（主窗口）
root = tk.Tk()

# frame 的爸爸是 root
frame = tk.Frame(root)

# label1 的爸爸是 frame（不是 root！）
label1 = tk.Label(frame, text="我在 Frame 里")

# label2 的爸爸是 root
label2 = tk.Label(root, text="我在主窗口里")

判断方法

看 tk.Label(xxx, ...) 的第一个参数 —— 那个就是 parent（爸爸）！

常见错误

第 6 课 总结

Frame 框架

用收纳盒整理你的界面

1. Frame 概念

Frame 是控件的"收纳盒"，用 tk.Frame(root) 创建，通过 bg、relief、bd、padx、pady 设置外观

2. 创建 Frame

tk.Frame(root, bg=..., relief=..., bd=..., padx=..., pady=...) 创建容器，然后 .pack() 放上去

3. pack() 布局

控件默认从上到下堆叠，用 pady/padx 控制间距，fill="x" 让 Frame 横向填满

4. 父子关系

创建控件的第一个参数就是 parent —— "谁把我装起来，谁就是我的爸爸"
