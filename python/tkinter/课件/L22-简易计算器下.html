三个核心函数

clear · backspace · calculate

核心功能

C 清除 + ← 退格 + eval 求值

计算器的三个核心操作，用三个函数实现。

# ① C 按钮：一键清空
def clear():
    entry_var.set("")

# ② ← 按钮：删除最后一个字符
def backspace():
    current = entry_var.get()
    entry_var.set(current[:-1])      # 切片去尾

# ③ = 按钮：计算表达式结果
def calculate():
    try:
        result = eval(entry_var.get())  # 把字符串当代码执行
        entry_var.set(str(result))
    except:
        entry_var.set("错误")

🧹 clear() + ⌫ backspace()

set("") 一键清空；[:-1] 切片去掉最后一个字符，空字符串也不报错。

🧠 eval() + 🛡️ try-except

把 "2+3*4" 当成代码执行得 14。用 try-except 兜底，表达式出问题显示"错误"而不是崩溃。

键盘交互

键盘按键绑定 —— bind()

不用鼠标也能操作计算器！按下键盘，tkinter 能"听"到并响应。

root.bind("<Key>", key_press)      # 绑定所有按键

def key_press(event):
    key = event.char              # 可打印字符（如 "1"、"+"）

    if key in "0123456789+-*/.=":
        if key == "=":
            calculate()
        else:
            click(key)
    elif event.keysym == "Return":   # 回车 → =
        calculate()
    elif event.keysym == "BackSpace": # 退格 → ←
        backspace()
    elif event.keysym == "Escape":    # ESC → C
        clear()
💡 关键区别：event.char 用于普通按键（数字、字母），返回字符本身。但回车、退格等特殊按键没有字符，要用 event.keysym 获取按键名称。两者搭配，覆盖所有按键！
