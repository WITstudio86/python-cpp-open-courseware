新概念

计数器 + 排行榜

添加两个全局变量，让游戏更有挑战性！

# —— 全局变量：初始化 ——
count = 0            # 记录本次猜测次数
best_score = 999     # 最佳纪录（初始设很大，保证第一次就能破纪录）

def guess():
    global count, best_score
    count += 1
    count_label.config(text=f"已猜次数: {count}")
    # ... 拿到用户输入、比较大小 ...

    if guess_num == secret:
        if count < best_score:
            best_score = count
            best_label.config(text=f"🏆 最佳纪录: {best_score} 步")
💡 记住：global 关键字告诉 Python"这个变量是外面那个全局的，不是函数里面新创建的"。忘了写 global，修改不会生效！

reset() —— 重新开始函数

按下按钮，一切从头来，但最佳纪录保留！

# reset() — 重置游戏状态，但最佳纪录保留
def reset():
    global secret, count
    secret = random.randint(1, 100)     # 新随机数
    count = 0                               # 计数器归零
    count_label.config(text="已猜次数: 0")
    result_label.config(text="新游戏开始！请输入你的猜测")
    entry.delete(0, tk.END)               # 清空输入框

reset_btn = tk.Button(root, text="🔄 重新开始",
                        command=reset, bg="#e65100", fg="white")
💡 思考：reset() 为什么不重置 best_score？因为最佳纪录是"历史最好成绩"，应该一直保留，让小朋友不断挑战自己！

总结 · 第 24 节

你学会了…

✓ 计数器 count

用全局变量 count 记录猜测次数，每次 guess() 中 count += 1。

✓ 最佳纪录 best_score

猜对时比较 count 和 best_score，更小就更新纪录并刷新 Label。

✓ global 关键字

在函数内修改全局变量，必须用 global 声明，否则会被当成局部变量。

✓ 重新开始 reset()

重置 secret、count、显示文字、输入框；best_score 保留不动。
