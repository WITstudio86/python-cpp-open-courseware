def flip():

    if is_front:

        is_front = True

改错时刻

这三处最容易错

❌ command=say_hello()

✅ command=say_hello
加了括号，函数会立刻执行，点击时反而不动。

❌ geometry("500*400")

✅ geometry("500x400")
中间必须是英文字母 x。

❌ 函数里直接 count += 1

✅ 先写 global count
漏了 global，改不到外面的变量。

这一步运行后记住的坑
创建主窗口标题栏换成了这一步写的文字。窗口大小写成 "宽x高"，中间是英文字母 x，不是星号。
功能函数窗口还能打开。绿底这些新行已经出现在窗口里。函数里要改外面的变量，第一行先写 global。漏了会报 UnboundLocalError。
