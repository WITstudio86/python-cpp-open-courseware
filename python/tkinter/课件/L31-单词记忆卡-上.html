数据结构

字典 dict —— 单词和释义的完美搭档

word_dict = {
    "apple": "苹果 🍎",
    "book": "书 📖",
    "elephant": "大象 🐘",
    "ocean": "海洋 🌊",
}                                  # 键: 值

print(word_dict["apple"])           # → 苹果 🍎
words = list(word_dict.keys())      # 获取所有单词
💡 为什么用字典？字典的「键 → 值」查询非常快，而且天然适合"英文 → 中文"这种一一对应关系。

状态变量

核心逻辑

随机抽词 + 翻面显示

🎲 随机抽一张卡

import random
word = random.choice(
    list(word_dict.keys()))
meaning = word_dict[word]

🔄 翻面切换

def flip():
    global is_front
    if is_front:
        label.config(text=meaning)
        is_front = False
    else:
        label.config(text=word)
        is_front = True
🃏 翻面原理：根本不需要两张卡片！就是一个 Label 根据 is_front 显示不同文字，外加按钮文字变化。
