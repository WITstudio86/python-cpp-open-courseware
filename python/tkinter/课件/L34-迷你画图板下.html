选颜色 & 橡皮擦

🎨 颜色选择器

colorchooser.askcolor() 弹出系统颜色面板，返回 ((R,G,B), "#hex") 元组。用户取消则返回 (None, None)。

🧹 橡皮擦原理

把画笔颜色设成和画布背景一样（通常是白色），继续画就能"盖住"原来的线条——视觉上就是擦除了！

from tkinter import colorchooser

def choose_color():
    result = colorchooser.askcolor(color="#000000")
    if result[1] is not None:        # 用户没点取消
        global current_color
        current_color = result[1]          # 取十六进制值

def use_eraser():
    global current_color
    current_color = "#ffffff"         # 白色 = 橡皮擦
    # 背景不是白色？把颜色改成 canvas["bg"] 即可

新功能

清空画布 & 保存 PNG

🗑 一键清空

canvas.delete("all") 删除画布上所有图形，干净利落！

💾 保存为 PNG

用 Pillow 的 ImageGrab.grab() 截取画布区域，再 .save() 成 PNG 图片。

from PIL import ImageGrab          # 需要 pip install Pillow

def clear_canvas():
    canvas.delete("all")             # 删除全部画布内容

def save_image():
    x = canvas.winfo_rootx()          # 画布屏幕坐标
    y = canvas.winfo_rooty()
    w = x + canvas.winfo_width()
    h = y + canvas.winfo_height()
    img = ImageGrab.grab(bbox=(x, y, w, h))
    img.save("my_drawing.png", "PNG")
    # 没装 Pillow？用 postscript 代替
【讲解】清空画布 & 保存 PNG 结合讲义《知识点 3：清空画布 Canvas.delete("all")》强调： · Canvas 有一个超级方便的方法：delete("all")，可以一次性删掉画布上的**所有**东西（所有线条、图形、文字……）。 · def clear_canvas(): · canvas.delete("all") # 一键清空！ · delete() 方法其实可以更精细： · delete("all") —— 删除全部 幻灯片上可见要点： · colorchooser 颜色选择器 · 橡皮擦（白色画笔覆盖） · 清空画布 delete("all") · 保存为 PNG 图片 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
