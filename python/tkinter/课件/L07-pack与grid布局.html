pack 进阶 —— side / anchor

上一节只用到了默认的 pack()。现在来解锁更强大的控制参数！

side —— 排列方向

"top" 上方（默认）| "bottom" 下方
"left" 左侧 | "right" 右侧

# 四个按钮贴四个边
btn1.pack(side="top", fill="x")
btn2.pack(side="left", fill="y")
btn3.pack(side="right", fill="y")
btn4.pack(side="bottom", fill="x")

anchor —— 对齐方向

"n"/"s" 上/下 | "w"/"e" 左/右
"nw" 左上 | "center" 居中

# anchor 控制对齐
label.pack(anchor="w")      # 左对齐
btn.pack(anchor="ne")        # 右上角

pack 进阶 —— fill / expand

fill 让控件填满分配空间，expand 让控件吃掉多余空间。

fill + expand

fill="x" 横向填满 | fill="y" 纵向填满
fill="both" 双向填满
expand=True 吃掉多余空间

记忆技巧： 上北下南左西右东 —— n=上、s=下、w=左、e=右、nw=左上、ne=右上、sw=左下、se=右下

grid 入门 —— 像 Excel 一样排布

如果 pack 是"排队放东西"，grid 就是"在表格里放东西"——每个控件都有它自己的行和列！

# grid 用 row 和 column 定位
btn = tk.Button(root, text="(0,0)")
btn.grid(row=0, column=0)

btn2 = tk.Button(root, text="(0,1)")
btn2.grid(row=0, column=1)

btn3 = tk.Button(root, text="(1,0)")
btn3.grid(row=1, column=0)

坐标系统

   column=0  column=1  column=2
row=0 (0,0) | (0,1) | (0,2)
row=1 (1,0) | (1,1) | (1,2)
row=2 (2,0) | (2,1) | (2,2)

row 和 column 都从 0 开始，和 Python 列表索引一样！

pack vs grid —— 什么时候用哪个？

pack —— 适合简单排列

排列方式从上到下 / 从左到右"堆积"
适用场景简单纵向/横向排列、工具栏、卡片
学习难度简单，容易上手
灵活性灵活但有局限

grid —— 适合表格排布

排列方式按行和列的"表格"排列
适用场景九宫格、计算器、表单、表格
学习难度稍复杂，需要规划行列
灵活性精确但需预先规划

布局选择技巧

知道了两种布局的特点，来看看如何根据需求选择：

选择口诀： 简单的上下或左右排列 → pack；需要做表格、九宫格、计算器 → grid。不同 Frame 可以各自选择不同的布局方式！

实例对比：同一个界面，两种写法

pack 方式

label.pack() → Frame.pack(pady=10) → Frame.pack(pady=10) → Button.pack(side="left")

grid 方式

label.grid(row=0) → Frame.grid(row=1) → Frame.grid(row=2) → Button.grid(row=3, column=0/1/2)

第 7 课 总结

pack 进阶 + grid 入门

掌握两种布局，界面安排游刃有余

1. pack 进阶参数

side 控制排列方向（top/bottom/left/right），anchor 控制对齐（n/s/w/e/nw/...），fill 控制填充（x/y/both），expand 控制扩展

2. grid 行列布局

.grid(row=..., column=...) 像 Excel 一样定位控件，行和列编号都从 0 开始，用 padx/pady 控制间距，sticky 控制对齐

3. pack vs grid

pack 适合简单排列，grid 适合表格排布。同一 Frame 内只能选一种布局，但不同 Frame 可以不同

4. 选择技巧

简单纵向/横向排列用 pack，九宫格/计算器/表单用 grid。记住：外层和里层可以用不同布局方式
