画布与蛇身

Canvas 画布 + 列表存储蛇身坐标

Canvas 的坐标系很特别：左上角是 (0, 0)，x 往右增加，y 往下增加。

🎨 绘制蛇身矩形

左上角 (x, y) 到右下角 (x+20, y+20)
每一节就是一个 20x20 的小方块
蛇头颜色亮，身体颜色深

📋 列表存储蛇身坐标

snake_body = [
  (200,200), ← 蛇头
  (180,200), ← 第2节
  (160,200) ← 蛇尾
] 

# 画一节蛇身
canvas.create_rectangle(
    x, y, x + 20, y + 20,  # 左上角 → 右下角
    fill="#00ff88",               # 填充色
    outline="#00aa55",             # 边框色
    tag="snake"                    # 打标签，方便删除
)

💡 打 tag="snake" 标签，用 canvas.delete("snake") 一键清掉蛇身重画。

两个引擎

键盘事件 · 定时器循环

让蛇动起来

键盘控制方向 + after() 定时移动

蛇的"灵魂"由两个部分组成：键盘事件决定走哪边，after() 定时器负责不停移动。

⌨️ 键盘控制方向

def change_dir(event):
    key = event.keysym
    if key == "Up" and dir != "Down":
        dir = "Up"

root.bind("<Key>", change_dir)

⚠️ 必须防止反向：向右走时不能按左！

⏱️ after() 游戏循环

def game_loop():
    move_snake()              # 移动
    root.after(150, game_loop) # 再来

150ms = 每秒约 6.7 帧，眼睛刚好看到连续动画！

🧠 核心算法：snake_body = [new_head] + snake_body[:-1] —— 新蛇头加到最前面，旧尾巴被切掉。这就是蛇"移动"的全部秘密！

💡 after(150, game_loop) 里的 game_loop 后面没有括号——这是"把函数交给 after，让它到时候再调用"，而不是"立刻执行"。
