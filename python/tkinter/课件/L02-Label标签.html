基础用法

创建你的第一个 Label

Label 是 tkinter 里最常用、最简单的控件。它像一个文字贴纸，贴在窗口上给你看。

# 创建一个 Label
label = tk.Label(
    root,                           # 贴在哪个窗口上
    text="你好，世界！"             # 要显示的文字
)
label.pack()                         # 把 Label 放进窗口

root

Label 的"家"——贴在哪个窗口上。

text

Label 上显示的文字内容。

【讲解】创建你的第一个 Label 结合讲义《第 1 步：创建你的第一个 Label》强调： · label = tk.Label(root, text="你好，世界！") · label.pack() · root 是 Label 的"家"——也就是它贴在哪个窗口上 · text="..." 是 Label 上显示的文字 · .pack() 是把 Label "打包"放进窗口里（后面会学更多布局方式） 幻灯片上可见要点： · 创建 Label 显示文字 · 设置字体、颜色、大小 · 对齐方式与自动换行 · 用 StringVar 动态控制文字 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

# 设置字体、颜色、背景
label = tk.Label(
    root,
    text="Hello, Tkinter!",

排版控制

对齐与换行

文字长了怎么办？三个参数帮你搞定排版。

# justify: 多行文字之间的对齐
# wraplength: 超过多少像素自动换行
# anchor: 文字在 Label 里的位置（方位）
label = tk.Label(
    root,
    text="这是一段很长的文字，"
         "会自动换行显示。",
    justify="left",       # left / center / right
    wraplength=300,        # 超过 300px 自动换行
    anchor="w"            # w=左 n=上 e=右 s=下 center=居中
)
💡 小技巧：anchor 用方位首字母 —— north（北/上）、south（南/下）、west（西/左）、east（东/右）。组合起来用："nw" 就是左上角！
【讲解】对齐与换行 结合讲义《第 3 步：对齐与换行》强调： · 有时候文字很长，需要换行显示；或者你想让文字靠左、居中、靠右。 · label = tk.Label( · root, · text="这是一段很长的文字，\n它会在窗口里换行显示。", · font=("微软雅黑", 12), 幻灯片上可见要点： · 创建 Label 显示文字 · 设置字体、颜色、大小 · 对齐方式与自动换行 · 用 StringVar 动态控制文字 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

关键区别

text 写死 · textvariable 动态

进阶技巧

让文字动起来 —— StringVar

StringVar 像一个魔术盒子——你改变盒子里的内容，Label 上的文字就自动跟着变！

# 第一步：创建一个 StringVar
var_text = tk.StringVar()
var_text.set("初始文字")       # .set() 设置内容

# 第二步：用 textvariable 绑定（不是 text！）
label = tk.Label(root, textvariable=var_text)

# 第三步：改变变量的值，Label 自动更新！
var_text.set("✅ 文字变啦！")   # Label 立刻更新
⚠️ 注意：text 和 textvariable 只能二选一！用 textvariable 才能动态改变，用 text 的话字就写死了。
【讲解】让文字动起来 —— StringVar 结合讲义《第 4 步：让文字"活"起来 —— StringVar》强调： · 前面的 Label 文字写死就不能变了。如果想**动态改变** Label 上的文字怎么办？用 StringVar！ · StringVar 就像一个**可以变魔术的盒子**——你改变盒子里的内容，Label 上的文字会自动跟着变！ 幻灯片上可见要点： · 创建 Label 显示文字 · 设置字体、颜色、大小 · 对齐方式与自动换行 · 用 StringVar 动态控制文字 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。
