核心功能①

JSON 历史成绩保存

每次测试结束自动保存成绩到 typing_history.json，包含日期、WPM、准确率、难度。

record = {
    "date": datetime.now().strftime("%Y-%m-%d %H:%M"),
    "wpm": wpm,
    "accuracy": accuracy,
    "difficulty": diff_name
}
history.append(record)
history.sort(key=lambda x: x["wpm"], reverse=True)
history = history[:20]  # 只保留前 20 条
💡 排序技巧：sort(key=lambda x: x["wpm"], reverse=True) 按 WPM 从高到低排列。

核心功能③

Radiobutton 难度选择

用 Radiobutton + StringVar 实现三档难度切换。

difficulty = tk.StringVar(value="medium")

tk.Radiobutton(root, text="🌱 短文", variable=difficulty, value="easy")
tk.Radiobutton(root, text="🌿 中文", variable=difficulty, value="medium")
tk.Radiobutton(root, text="🌳 长文", variable=difficulty, value="hard")

def get_sample():
    diff = difficulty.get()  # 获取当前选中的值
