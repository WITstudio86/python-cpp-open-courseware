核心功能①

after() 倒计时

after(毫秒, 函数) 是 tkinter 的定时器——在指定毫秒后执行一次函数。要循环？在函数里再调用 after！

time_left = 60

def update_timer():
    global time_left
    if time_left > 0:
        time_left -= 1
        timer_label.config(text=f"剩余：{time_left}秒")
        root.after(1000, update_timer)  # 1秒后再调自己
    else:
        show_result()  # 时间到！显示成绩
💡 技巧：开始前 input_text.config(state="disabled") 禁止输入；开始后再 config(state="normal") 启用。

📊 WPM 公式

elapsed = 60 - time_left
correct = sum(
  1 for i,ch in enumerate(user)
  if i<len(ref) and ch==ref[i])
wpm = (correct / elapsed) * 60
return round(wpm, 1)

if len(user_text) == 0:
    return 0  # 防止除以0
accuracy = (correct
    / len(user_text)) * 100
return round(accuracy, 1)

核心功能③

成绩弹窗展示

时间到后弹出 Toplevel 成绩窗口，显示 WPM、准确率和趣味评价。

def show_result():
    result_win = tk.Toplevel(root)
    result_win.grab_set()
    tk.Label(result_win, text=f"速度：{wpm} 字/分钟").pack()
    tk.Label(result_win, text=f"准确率：{accuracy}%").pack()
    # 趣味评价
    if wpm >= 60 and accuracy >= 95: grade = "🌟 打字高手！"
    elif wpm >= 30: grade = "👍 不错哦！"
    else: grade = "💪 多多练习！"
    tk.Label(result_win, text=grade).pack()
