def check_typing(event=None):
    """实时逐字对比：正确的字变绿，错误的字变红"""
    user_text = input_text.get("1.0", tk.END).rstrip("\n")

    # 清除之前的高亮
    input_text.tag_remove("correct", "1.0", tk.END)
    input_text.tag_remove("wrong", "1.0", tk.END)

    # 逐字对比
    for i, char in enumerate(user_text):
        pos = f"1.{i}"
        if i < len(current_text) and char == current_text[i]:
            input_text.tag_add("correct", pos)
        else:
            input_text.tag_add("wrong", pos)


input_text.bind("<KeyRelease>", check_typing)

root.mainloop()

这三处最容易错

❌ command=say_hello()

✅ command=say_hello
加了括号，函数会立刻执行，点击时反而不动。

❌ geometry("500*400")

✅ geometry("500x400")
中间必须是英文字母 x。

❌ 函数里直接 count += 1

✅ 先写 global count
漏了 global，改不到外面的变量。

这一步运行后记住的坑
创建窗口标题栏换成了这一步写的文字。窗口大小写成 "宽x高"，中间是英文字母 x，不是星号。
顶部信息栏控件排队出现在窗口里，不再叠在同一个点。同一个父容器里不要又 pack 又 grid，否则会直接报错。
打字输入区域出现一块能写很多行的文本框。bind 的事件名要带尖括号，例如 "<Return>"、"<Button-1>"。
倒计时不用不停点击，画面或数字会自己更新。函数里要改外面的变量，第一行先写 global。漏了会报 UnboundLocalError。
统计计算窗口还能打开。绿底这些新行已经出现在窗口里。def 下面的函数体必须缩进。少缩进一格，运行就会报错。
显示成绩标题栏换成了这一步写的文字。command 后面写函数名，不要加括号。加了括号会马上执行。
