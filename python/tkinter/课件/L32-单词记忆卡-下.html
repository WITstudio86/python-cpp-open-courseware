嵌套字典 + OptionMenu 选择分类

word_bank = {
    "🐾 动物": {"cat":"猫", "dog":"狗", ...},
    "🍎 水果": {"apple":"苹果", "banana":"香蕉", ...},
    "🏫 学校": {"book":"书", "pen":"笔", ...},
}

category_var = tk.StringVar()
category_var.trace("w", change_category)  # 监听变化

menu = tk.OptionMenu(root, category_var, *word_bank.keys())
🔗 trace("w", callback)：当 category_var 的值发生变化时，自动调用 change_category 函数，重置统计数据。

掌握标记 + 实时统计

📋 两个列表跟踪

mastered = []     # 已掌握
unmastered = []   # 未掌握

def mark(t):
    if t == "mastered":
        mastered.append(word)
        if word in unmastered:
            unmastered.remove(word)

📊 实时统计

total = len(word_list)
learned = len(mastered)
percent = learned / total * 100

label.config(
    text=f"已掌握 {learned}/
           {total} ({percent}%)")
🎯 统计的意义：给学生正向反馈，让学习进度可视化。看到百分比上升会很有成就感！

智能复习

只复习未掌握的单词

review_var = tk.StringVar(value="all")

def next_card():
    if review_var.get() == "unmastered" and unmastered:
        pool = [w for w in unmastered
                if w in current_word_list]
    else:
        pool = current_word_list  # 全部

    word = random.choice(pool)
🧠 学习策略：先全部浏览一遍 → 标记掌握/未掌握 → 切换到「只复习未掌握」→ 逐个攻克！
