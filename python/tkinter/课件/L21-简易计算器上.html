grid 网格布局

把窗口想象成一个表格，每个控件放到第几行、第几列。

计算器按钮布局

│  C   │  ←   │      │  /   │ row=1
├──────┼──────┼──────┼──────┤
│  7   │  8   │  9   │  *   │ row=2
├──────┼──────┼──────┼──────┤

col=0  col=1  col=2  col=3

关键参数

参数说明
row=第几行（从 0 开始）
column=第几列（从 0 开始）
columnspan=跨几列（如 Entry 跨 4 列）
sticky=对齐方向（N/S/E/W）
padx/pady外边距
💡 记住：Entry 放在 row=0，使用 columnspan=4 横跨整行；按钮从 row=1 开始，每行 4 列。

知识点 2 + 3

lambda 传参 + 数字拼接

lambda：延迟执行的包装盒

# ❌ 错误：创建按钮时就执行了！
btn = tk.Button(root, text="1",
               command=click("1"))

# ✅ 正确：用 lambda 包一层
btn = tk.Button(root, text="1",
               command=lambda: click("1"))

lambda 就是"延迟包装盒"——把函数调用装好，等点击时才打开执行。

StringVar + Entry 数字拼接

entry_var = tk.StringVar()

entry = tk.Entry(root,
    textvariable=entry_var,
    state="readonly")

def click(key):
    cur = entry_var.get()
    entry_var.set(cur + key)

点 "1" → "1" · 点 "2" → "12" · 点 "+" → "12+" · 点 "3" → "12+3"

⚠️ 循环中创建按钮要注意：使用 lambda n=num: click(str(n)) 来"固定"当前循环变量的值，否则所有按钮都共用最后一个值！
