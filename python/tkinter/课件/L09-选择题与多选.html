Radiobutton —— 单选题

一组互斥选项，绑定到同一个变量，同时只能选中一个

核心代码

# 1. 创建变量
gender_var = tk.StringVar(value="")

# 2. 创建单选按钮组（注意：variable 相同！）
tk.Radiobutton(root, text="男生",
    variable=gender_var, value="男生")
tk.Radiobutton(root, text="女生",
    variable=gender_var, value="女生")
tk.Radiobutton(root, text="保密",
    variable=gender_var, value="保密")

# 3. 读取选中值
result = gender_var.get()  # → "男生" / "女生" / "保密"
关键规则：同一组 Radiobutton 必须绑定 同一个 variable，选中时 variable 被赋值为对应的 value！

Checkbutton —— 多选题

独立的勾选项，每个需要自己的变量，可以同时选中多个

核心代码

# 每个选项需要独立的 IntVar
hobby1_var = tk.IntVar(value=0)
hobby2_var = tk.IntVar(value=0)

tk.Checkbutton(root, text="玩游戏",
    variable=hobby1_var, onvalue=1, offvalue=0)
tk.Checkbutton(root, text="阅读",
    variable=hobby2_var, onvalue=1, offvalue=0)

# 读取选中状态
if hobby1_var.get() == 1:
    print("选中了玩游戏")

onvalue / offvalue

控制勾选/取消时变量的值，默认为 1 和 0

独立变量

与 Radiobutton 不同，每个 Checkbutton 必须用独立变量

IntVar / StringVar —— 绑定变量

Tkinter 的特殊变量，自动同步组件和代码中的值

Tkinter 变量类型

# StringVar —— 存字符串
name = tk.StringVar(value="小明")
name.get()     # → "小明"
name.set("小红")  # 修改为"小红"
              
# IntVar —— 存整数
count = tk.IntVar(value=0)
count.get()    # → 0
count.set(10)  # 修改为 10

IntVar / StringVar —— 用途与优势

用途对照表

# Radiobutton → StringVar / IntVar
gender_var = tk.StringVar()    # 存储选中文本

# Checkbutton → IntVar / BooleanVar
hobby_var = tk.IntVar()        # 0/1 表示未选/选中

# Entry / Label → StringVar
text_var = tk.StringVar()      # 存储输入/显示的文本
核心优势：变量值改变 → 组件自动更新，不需要手动操作组件！
