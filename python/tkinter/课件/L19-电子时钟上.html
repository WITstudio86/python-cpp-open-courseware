新模块

time 模块 & strftime() 格式化时间

time.strftime() 把电脑时间变成你想要的样子。格式码用 % 开头，比如 %H = 小时，%M = 分钟。

import time

# 获取当前时间，按格式转成字符串
now = time.strftime("%H:%M:%S")    # → "14:30:25"
today = time.strftime("%Y-%m-%d")  # → "2026-06-27"
格式码含义示例
%H小时（24时制）00~23
%I小时（12时制）01~12
%M分钟00~59
%S秒00~59
%pAM / PM上午/下午
格式码含义示例
%Y四位年份2026
%m月份（数字）01~12
%d日期01~31
%A星期（全称）Monday
%a星期（缩写）Mon

核心技术

after() —— 让时钟"跳起来" 🔄

after() 是 tkinter 的定时器：在指定时间后执行一个函数。在函数内部再次调用 after()，就能形成无限循环！

# 创建时间显示的 Label（等宽字体 + 大字号 + 电子表配色）
time_label = tk.Label(root,
    text="00:00:00",
    font=("Consolas", 48, "bold"),
    fg="#00ff00",       # 亮绿色文字
    bg="#1a1a1a"         # 深色背景
)
time_label.pack(expand=True)

def update_time():
    # ① 获取当前系统时间
    now = time.strftime("%H:%M:%S")

    # ② 更新 Label 文字
    time_label.config(text=now)

    # ③ 1秒后再次调用自己 → 形成循环！
    root.after(1000, update_time)

# 先手动调用一次，启动循环
update_time()

⏱️ after(毫秒, 函数名)

1000 毫秒 = 1 秒。第二个参数只写函数名，不加括号！

🔁 自己调用自己

在 update_time() 里面写 after()，让它每隔 1 秒再执行一次。
