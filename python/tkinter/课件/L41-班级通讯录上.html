新控件

Treeview —— tkinter 里的 Excel

ttk.Treeview 是 tkinter 主题扩展中的表格控件，能展示、选中、滚动多行数据。

from tkinter import ttk
# 1. 创建表格（定义 4 列）
tree = ttk.Treeview(root, columns=("name", "phone", "qq", "note"), show="headings")
# 2. 设置表头和列宽
tree.heading("name", text="姓名")
tree.heading("phone", text="电话")
tree.column("name", width=100)
tree.column("phone", width=130)
⚠️ 注意区分：columns 里的是内部列名（代码用），heading(text=) 里的是显示名（用户看到）。show="headings" 是表格模式的关键！

数据操作

insert() 插入 + 多 Entry 表单

📥 插入数据 insert()

# 语法：insert(父节点, 位置, values=元组)
tree.insert("", tk.END,
          values=("张三", "13800001111",
                  "12345678", "同桌"))

# 删除选中行
selected = tree.selection()
for item in selected:
    tree.delete(item)

📝 多 Entry 表单

def add_contact():
    name = name_entry.get().strip()
    phone = phone_entry.get().strip()
    qq = qq_entry.get().strip()
    note = note_entry.get().strip()
    if name == "": return
    tree.insert("", tk.END,
              values=(name, phone, qq, note))

💡 values 元组的顺序必须和 columns 定义的顺序完全一致，否则数据会对错列！
