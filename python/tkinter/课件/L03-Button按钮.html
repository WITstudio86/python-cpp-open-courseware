基础用法

创建你的第一个按钮

Button 是 tkinter 里第一个能交互的控件。你点它一下，它就执行一段代码！

# 1. 先定义"点击后做什么"的函数
def say_hello():
    print("你好！你点击了按钮！")

# 2. 创建按钮，绑定函数
btn = tk.Button(
    root,
    text="点我！",         # 按钮上显示的文字
    command=say_hello       # 点击后调用的函数
)
btn.pack()
⚠️ 关键：command=say_hello 不要加括号 ()！加了括号会在创建按钮时立刻执行，而不是等点击才执行。

新概念

global · config() · f-string

核心逻辑

点击计数 —— 让按钮记住点了多少次

count = 0  # 全局变量：记录点击次数

def add_count():
    global count           # 声明要修改全局变量
    count += 1             # 次数 +1
    count_label.config(      # config() 更新 Label
        text=f"点击次数：{count}"
    )
    if count >= 10:       # 超过10次变橙色
        count_label.config(fg="#e65100")

🌍 global

函数里要修改函数外定义的变量，必须用 global 声明。

🔧 config()

动态修改控件的属性（文字、颜色、大小……），不需要重新创建控件。

进阶技巧

切换文字 —— 一个按钮两种身份

这是 UI 里最经典的模式之一：Toggle（切换）。按钮每点一次就在"开"和"关"之间切换。

is_on = False

def toggle():
    global is_on
    is_on = not is_on
    if is_on:
        btn.config(text="🔴 已开启", bg="#ef5350")
    else:
        btn.config(text="🟢 已关闭", bg="#66bb6a")
💡 核心思路：用一个变量记住"当前状态"，每次点击翻转它，然后根据状态 config() 更新按钮的外观。这个模式在游戏、设置界面里到处可见！
