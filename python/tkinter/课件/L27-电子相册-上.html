新工具

Pillow —— Python 的图片处理神器

tkinter 本身只能显示 GIF 图片。要显示 JPG、PNG 等格式，需要 Pillow 帮忙。

📦 安装

终端输入：pip install Pillow
Mac/Linux 可能用 pip3

📥 导入

from PIL import Image, ImageTk
注意是大写 PIL，不是 pillow

💡 PIL 历史：PIL 是 Python Imaging Library 的缩写。后来项目改名 Pillow，但导入时还是写 from PIL。
【讲解】Pillow —— Python 的图片处理神器 结合讲义《知识点 1：安装 Pillow 库》强调： · tkinter 本身只能显示少数几种格式的图片（比如 GIF），功能很有限。我们需要一个强大的帮手 —— **Pillow**。 · Pillow 是 Python 最流行的图片处理库，原名 PIL（Python Imaging Library），后来改叫 Pillow。 · 安装方法： · 打开终端（命令行），输入： · pip install Pillow 幻灯片上可见要点： · 安装 Pillow 库 · 加载图片 Image.open() · 转换 ImageTk.PhotoImage · Label 显示图片 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

三步法

加载 → 转换 → 显示

核心流程

三步显示一张图片

# 第1步：加载图片
img = Image.open("photo.jpg")

# 第2步：转换成 tkinter 格式
tk_img = ImageTk.PhotoImage(img)

# 第3步：用 Label 显示
label = tk.Label(root, image=tk_img)
label.image = tk_img   # ⚠️ 必须保存引用！
label.pack()
⚠️ 关键陷阱：label.image = tk_img 绝不能省略！Python 的垃圾回收机制会清除没有引用的图片，导致 Label 里一片空白。
【讲解】三步显示一张图片 本页要点（照着讲即可）： · 安装 Pillow 库 · 加载图片 Image.open() · 转换 ImageTk.PhotoImage · Label 显示图片 · resize 缩放图片 · 加载 → 转换 → 显示 讲解时放慢关键术语；用 1 个生活类比 + 1 个反例加深印象。

进阶技巧

缩放图片 + 占位图生成

📏 缩放 resize()

img = Image.open("big.jpg")
img = img.resize((400,300))
# 元组：(宽, 高)

🎨 生成占位图

img = Image.new(
    "RGB", (400,300),
    "#4A90D9")
# 不需要真实文件!
📸 占位图的好处：代码不依赖外部文件，任何电脑上都能直接运行。下节课我们再接入真实图片。
