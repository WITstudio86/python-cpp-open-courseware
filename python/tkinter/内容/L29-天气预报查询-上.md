## 知识点讲解

### 什么是 API？
API（Application Programming Interface）是"应用程序编程接口"。通俗地说，**API 就是网络上的一个数据服务** —— 你发送请求，它返回数据。

就像去餐厅点菜：你（程序）看菜单（API 文档），告诉服务员（发送请求）你要什么，厨房（服务器）做好后端给你（返回数据）。

天气 API 就是：你告诉它城市名，它告诉你天气！

### 知识点 2：调用 wttr.in 天气 API

[wttr.in](https://wttr.in) 是一个免费、无需注册的天气 API，使用超级简单：

```
https://wttr.in/城市名?format=j1
```

- `城市名`：支持中文（北京、上海）和英文（Beijing、London）
- `?format=j1`：要求返回 JSON 格式（结构化数据）

```python
import requests

city = "Beijing"
url = f"https://wttr.in/{city}?format=j1"

response = requests.get(url)  # 发送 GET 请求
print(response.status_code)   # 200 表示成功
```

### 知识点 3：解析 JSON 数据

API 返回的 JSON 数据是一个多层嵌套的字典结构：

```python
data = response.json()  # 把 JSON 字符串转成 Python 字典

# 逐层取出需要的信息
current = data["current_condition"][0]  # 当前天气
temp = current["temp_C"]                 # 温度（摄氏度）
humidity = current["humidity"]           # 湿度
weather_desc = current["weatherDesc"][0]["value"]  # 天气描述
wind_speed = current["windspeedKmph"]    # 风速
feels_like = current["FeelsLikeC"]       # 体感温度
```

**JSON 结构图解**：

```
data
└── current_condition (列表)
    └── [0] (字典)
        ├── temp_C → "25"
        ├── humidity → "60"
        ├── weatherDesc (列表)
        │   └── [0] (字典)
        │       └── value → "晴"
        ├── windspeedKmph → "15"
        └── FeelsLikeC → "23"
```

### 知识点 5：错误处理 —— 网络不可用时怎么办

网络编程最怕"网络不通"。我们必须做好错误处理：

```python
import requests

def get_weather(city):
    try:
        url = f"https://wttr.in/{city}?format=j1"
        response = requests.get(url, timeout=5)  # 5 秒超时
        response.raise_for_status()  # 如果状态码不是 200，抛出异常
        return response.json()
    except requests.exceptions.ConnectionError:
        # 网络连接失败
        return {"error": "网络连接失败，请检查网络"}
    except requests.exceptions.Timeout:
        # 请求超时
        return {"error": "请求超时，请稍后再试"}
    except Exception as e:
        return {"error": f"查询失败：{e}"}
```

## 完整代码

```python
import tkinter as tk
import requests

# ========================================
# 第 29 节：项目 6 — 天气预报查询（上）
# ========================================

root = tk.Tk()
root.title("天气预报查询 🌤️")
root.geometry("450x450")
root.configure(bg="#e8f4fd")

def get_weather(city):
    """调用 wttr.in API 获取天气数据"""
    try:
        url = f"https://wttr.in/{city}?format=j1"
        response = requests.get(url, timeout=5)
        response.raise_for_status()
        return response.json()
    except requests.exceptions.ConnectionError:
        return None
    except:
        return None

def search():
    """查询天气并显示结果"""
    city = entry.get().strip()
    if not city:
        result_label.config(text="请输入城市名！", fg="red")
        return

    result_label.config(text="查询中...", fg="gray")
    root.update()  # 立即更新界面

    data = get_weather(city)
    if data is None:
        result_label.config(text="❌ 网络连接失败，请检查网络", fg="red")
        return

    try:
        current = data["current_condition"][0]
        temp = current["temp_C"]
        desc = current["weatherDesc"][0]["value"]
        humidity = current["humidity"]
        wind = current["windspeedKmph"]
        feels = current["FeelsLikeC"]

        result = (
            f"🏙️ 城市：{city}\n"
            f"🌡️ 温度：{temp}°C（体感 {feels}°C）\n"
            f"☁️ 天气：{desc}\n"
            f"💧 湿度：{humidity}%\n"
            f"💨 风速：{wind} km/h"
        )
        result_label.config(text=result, fg="#2a5a7a")
    except:
        result_label.config(text="❌ 未找到该城市，请检查城市名", fg="red")

# ===== 界面布局 =====

tk.Label(root, text="🌤️ 天气预报", font=("微软雅黑", 22, "bold"),
         bg="#e8f4fd", fg="#1a3a5a").pack(pady=20)

tk.Label(root, text="输入城市名（中文或英文）：",
         font=("微软雅黑", 12), bg="#e8f4fd").pack()

entry = tk.Entry(root, font=("微软雅黑", 14), width=20, justify="center")
entry.pack(pady=10)
entry.bind("<Return>", lambda e: search())

tk.Button(root, text="🔍 查询天气", command=search,
          font=("微软雅黑", 13), bg="#4a90d9", fg="white",
          padx=20, pady=5).pack(pady=10)

result_label = tk.Label(root, text="", font=("微软雅黑", 13),
                        bg="#e8f4fd", fg="#2a5a7a", justify=tk.LEFT)
result_label.pack(pady=20)

root.mainloop()
```

## 小贴士
- 🌐 `requests.get()` 是 HTTP GET 请求，大多数 API 都用这种方式获取数据
- ⏱️ 一定要设 `timeout`！否则网络不通时程序会一直卡住
- 🔍 `response.json()` 把 JSON 字符串自动转成 Python 字典，非常方便
- 🛡️ `try...except` 是网络编程的标配 —— 网络随时可能出问题
- 📖 wttr.in 不需要 API Key，非常适合学习和测试
- 🚫 如果学校网络屏蔽了 wttr.in，可以试试 `https://api.open-meteo.com`（另一个免费天气 API）
