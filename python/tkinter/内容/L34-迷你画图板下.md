## 知识点讲解

### 知识点 1：颜色选择器 colorchooser.askcolor()

`colorchooser` 是 tkinter 的一个子模块，专门用来弹出"选颜色"对话框。点击后会弹出一个系统自带的颜色窗口，用户可以自由选择颜色，选中后返回颜色的十六进制值。

```python
from tkinter import colorchooser

# 弹出颜色选择器，并获取用户选的颜色
color = colorchooser.askcolor()
print(color)  # 返回类似 ( (255, 0, 0), "#ff0000" )，是元组！
```

`askcolor()` 的返回值是一个**二元组**：
- 第一个元素：RGB 元组，如 `(255, 0, 0)`
- 第二个元素：十六进制字符串，如 `"#ff0000"`
- 如果用户点了"取消"，返回值是 `(None, None)`

**实际使用：**

```python
def choose_color():
    result = colorchooser.askcolor()
    if result[1] is not None:  # 用户没有点取消
        global current_color
        current_color = result[1]  # 用十六进制值
        color_btn.configure(bg=current_color)  # 按钮也变成这个颜色
```

`askcolor()` 还可以设置默认颜色：

```python
colorchooser.askcolor(color="#ff0000")   # 打开时默认选红色
colorchooser.askcolor(title="选个颜色吧")  # 自定义对话框标题
```

| 参数 | 说明 | 例子 |
|------|------|------|
| `color` | 默认选中的颜色 | `color="#00ff00"` |
| `title` | 对话框标题 | `title="选择画笔颜色"` |

### 知识点 2：橡皮擦 —— 用白色画笔覆盖

橡皮擦的原理其实**超级简单**：就是把画笔颜色换成白色（和画布背景一样），然后继续画。因为画布底色是白的，所以白色画上去就像"擦掉"了一样！

```python
def use_eraser():
    global current_color
    current_color = "#ffffff"  # 白色 = 橡皮擦
    color_btn.configure(bg="#ffffff")  # 按钮也变白
```

> 有没有"真橡皮擦"？有的！如果想让橡皮擦真的**删除**线条，而不是覆盖白色，可以用到更高级的 Canvas 图元操作。但对于初学者来说，"白色覆盖法"已经足够好用了！

> 那如果画布背景不是白色怎么办？可以把 `current_color` 设成和画布 `bg` 一样的颜色就好啦！

### 知识点 3：清空画布 Canvas.delete("all")

`Canvas` 有一个超级方便的方法：`delete("all")`，可以一次性删掉画布上的**所有**东西（所有线条、图形、文字……）。

```python
def clear_canvas():
    canvas.delete("all")  # 一键清空！
```

`delete()` 方法其实可以更精细：
- `delete("all")` —— 删除全部
- `delete(item_id)` —— 删除某一个指定的图形
- `delete("line")` —— 删除所有线条
- `delete("oval")` —— 删除所有圆形/椭圆

但我们画图板直接用 `delete("all")` 就够了，干净利落！

### 知识点 4：保存画布为 PNG 图片

把画布上的画保存成 PNG 图片，有两种常用方法：

#### 方法 A：使用 Pillow (PIL) 的 ImageGrab（推荐 ✅）

需要先安装 Pillow 库：`pip install Pillow`

```python
from PIL import ImageGrab

def save_image():
    # 先获取画布在屏幕上的左上角坐标
    x = canvas.winfo_rootx()
    y = canvas.winfo_rooty()
    w = canvas.winfo_width()
    h = canvas.winfo_height()
    
    # 截取屏幕区域
    img = ImageGrab.grab(bbox=(x, y, x+w, y+h))
    
    # 保存为 PNG
    img.save("my_drawing.png", "PNG")
```

`ImageGrab.grab(bbox=(左, 上, 右, 下))` 抓取屏幕上指定矩形区域的图像。`winfo_rootx()` 和 `winfo_rooty()` 用来获取画布在屏幕上的绝对坐标。

#### 方法 B：使用 Canvas 自带的 postscript（备选）

不需要安装任何额外库，但保存的是 PostScript 格式（.ps），需要用其他工具转 PNG。

```python
def save_as_ps():
    canvas.postscript(file="my_drawing.ps")
```

不过 `.ps` 文件不是常见的图片格式，用起来不太方便。所以**推荐使用方法 A（ImageGrab）**。

> 如果你的电脑上还没有安装 Pillow，可以在终端运行：`pip install Pillow`

### 知识点 5：画笔粗细调节

在画图板里再加一个"画笔粗细"的功能，让线条可以粗可以细。用 `Scale` 滑块来实现：

```python
pen_size = tk.Scale(
    root, from_=1, to=10,         # 范围：1~10
    orient="horizontal",           # 横向滑块
    label="画笔粗细",              # 标签文字
    length=150                     # 滑条长度
)
```

在画线时，用 `pen_size.get()` 获取当前粗细值，然后用这个值来计算圆的大小：

```python
def draw(event):
    r = pen_size.get()  # 当前画笔粗细
    x, y = event.x, event.y
    canvas.create_oval(x - r, y - r, x + r, y + r,
                       fill=current_color, outline=current_color)
```

## 完整代码

```python
import tkinter as tk
from tkinter import colorchooser

# ========================================
# 第 34 节：迷你画图板（下）
# 知识点：颜色选择器 + 橡皮擦 + 清空画布 + 保存图片
# ========================================

# 尝试导入 Pillow（用于保存 PNG）
try:
    from PIL import ImageGrab
    has_pil = True
except ImportError:
    has_pil = False

# ---------- 全局变量 ----------
current_color = "#000000"  # 当前画笔颜色，默认黑色

# ---------- 主窗口 ----------
root = tk.Tk()
root.title("迷你画图板")
root.geometry("800x600")

# ---------- 工具栏 ----------
toolbar = tk.Frame(root, bg="#e0e0e0", height=50)
toolbar.pack(side="top", fill="x")

# 颜色选择按钮
color_btn = tk.Button(toolbar, text="🎨 选颜色",
                      command=lambda: choose_color(),
                      bg=current_color, fg="white" if current_color == "#000000" else "black",
                      font=("Microsoft YaHei", 10))
color_btn.pack(side="left", padx=5, pady=8)

# 橡皮擦按钮
eraser_btn = tk.Button(toolbar, text="🧹 橡皮擦",
                       command=use_eraser,
                       font=("Microsoft YaHei", 10))
eraser_btn.pack(side="left", padx=5, pady=8)

# 清空画布按钮
clear_btn = tk.Button(toolbar, text="🗑 清空",
                      command=lambda: canvas.delete("all"),
                      font=("Microsoft YaHei", 10))
clear_btn.pack(side="left", padx=5, pady=8)

# 画布粗细滑块
pen_size = tk.Scale(toolbar, from_=1, to=10, orient="horizontal",
                    label="画笔粗细", length=120)
pen_size.set(2)  # 默认粗细为 2
pen_size.pack(side="left", padx=10, pady=5)

# 保存按钮
def save_canvas():
    if has_pil:
        x = root.winfo_rootx() + canvas.winfo_x()
        y = root.winfo_rooty() + canvas.winfo_y()
        w = x + canvas.winfo_width()
        h = y + canvas.winfo_height()
        img = ImageGrab.grab(bbox=(x, y, w, h))
        img.save("my_drawing.png", "PNG")
        print("已保存为 my_drawing.png ✅")
    else:
        canvas.postscript(file="my_drawing.ps")
        print("Pillow 未安装，已保存为 my_drawing.ps（可用在线工具转 PNG）")

save_btn = tk.Button(toolbar, text="💾 保存",
                     command=save_canvas,
                     font=("Microsoft YaHei", 10))
save_btn.pack(side="left", padx=5, pady=8)

# ---------- 画布 ----------
canvas = tk.Canvas(root, bg="white", cursor="pencil")
canvas.pack(fill="both", expand=True)

# ---------- 画图函数 ----------
def choose_color():
    """弹出颜色选择器，更新画笔颜色"""
    global current_color
    result = colorchooser.askcolor(color=current_color, title="选择画笔颜色")
    if result[1] is not None:
        current_color = result[1]
        color_btn.configure(bg=current_color)
        # 根据颜色亮度自动调整按钮文字颜色
        r, g, b = result[0]
        brightness = (r * 299 + g * 587 + b * 114) / 1000
        color_btn.configure(fg="white" if brightness < 128 else "black")

def use_eraser():
    """切换到橡皮擦模式（白色画笔）"""
    global current_color
    current_color = "#ffffff"
    color_btn.configure(bg="#ffffff", fg="black")

def draw(event):
    """在画布上画圆点（模拟画笔）"""
    r = pen_size.get()
    x, y = event.x, event.y
    canvas.create_oval(x - r, y - r, x + r, y + r,
                       fill=current_color, outline=current_color)

# 绑定鼠标拖拽事件
canvas.bind("<B1-Motion>", draw)

root.mainloop()
```

## 小贴士
- `colorchooser.askcolor()` 返回 `(RGB元组, 十六进制)`，如果用户取消，两个值都是 `None`——记得判断！
- 橡皮擦的"白色覆盖法"只是一个视觉技巧，它并没有真的删除线条。如果要保存为透明背景的 PNG，白色擦痕会露馅哦！
- `canvas.delete("all")` 删掉就没了，没有办法撤销，清空前可以提示一下用户。
- `ImageGrab` 需要 `pip install Pillow`，如果安装报错可以先跳过这个功能，课后慢慢装。
- 颜色按钮的文字颜色可以根据背景明暗自动切换，这样不管选什么颜色都能看清按钮上的字。
