# 第 1 节 · 认识 tkinter —— 创建你的第一个窗口

## 学习目标
- 了解什么是 tkinter（Python 自带的图形界面工具包）
- 学会创建窗口对象并设置标题、大小、背景色
- 理解 `mainloop()` 的作用 —— 为什么窗口不会一闪而过

## 本节课成品
一个属于你自己的窗口，有标题、有颜色、有固定大小。

---

## 知识点讲解

### 什么是 tkinter？
tkinter 是 Python 自带的一个**图形界面（GUI）工具包**。你之前写的 Python 程序都在黑色的命令行里运行，而用了 tkinter，你就可以做出**有窗口、有按钮、有输入框**的桌面程序了！

不需要额外安装，Python 装好就有 tkinter。

### 第 1 步：导入 tkinter

```python
import tkinter as tk
```

`as tk` 是取一个小名，后面写起来更短。

### 第 2 步：创建窗口

```python
root = tk.Tk()
```

`Tk()` 创建了一个窗口对象，我们把它存在 `root` 变量里。`root` 就是"根窗口"的意思——后面所有控件都要放在这个窗口里。

### 第 3 步：设置窗口属性

```python
root.title("我的第一个窗口")   # 窗口标题栏文字
root.geometry("500x400")       # 窗口大小：宽500像素，高400像素
root.configure(bg="#e8f5e9")   # 背景颜色：浅绿色
```

| 方法 | 作用 | 例子 |
|------|------|------|
| `.title("文字")` | 设置标题栏文字 | `root.title("计算器")` |
| `.geometry("宽x高")` | 设置窗口大小 | `root.geometry("600x400")` |
| `.configure(bg="颜色")` | 设置背景色 | `root.configure(bg="lightblue")` |

### 颜色怎么表示？
- **颜色名字**：`"red"`、`"lightblue"`、`"yellow"`
- **十六进制**：`"#e8f5e9"`（更精确，设计师常用）

### 第 4 步：启动窗口

```python
root.mainloop()
```

**`mainloop()` 是最重要的一行！** 它让窗口一直显示，并持续监听你的操作（鼠标点击、键盘输入等）。如果没有这一行，窗口会一闪而过就消失了。

可以把 `mainloop()` 理解成一个**无限循环**——它会一直运行，直到你点击关闭按钮。

---

## 完整代码

```python
import tkinter as tk

# 1. 创建窗口
root = tk.Tk()

# 2. 设置窗口
root.title("我的第一个窗口")
root.geometry("500x400")
root.configure(bg="#e8f5e9")

# 3. 启动窗口（必须放在最后！）
root.mainloop()
```

## 小贴士
- `mainloop()` 一定要放在代码的最后一行
- 窗口大小用 `"宽x高"` 格式，中间是小写字母 `x`
- 这节课的代码很简单，但它是**所有 tkinter 程序的骨架**——后面每一节课都是在这个骨架上添加控件！
