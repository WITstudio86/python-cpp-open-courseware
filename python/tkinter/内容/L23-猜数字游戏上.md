## 知识点讲解

### 知识点 1：random.randint() 生成随机数

Python 内置的 `random` 模块可以帮我们生成随机数。`randint(a, b)` 会随机返回 a 到 b 之间的一个整数（**包含 a 和 b**）。

```python
import random

# 生成 1~100 之间的随机整数
secret = random.randint(1, 100)
print(secret)  # 调试用，正式游戏要隐藏这行！
```

> `random.randint(1, 100)` 的意思是：在 1、2、3、……、100 这 100 个数字里随机挑一个。每次运行程序，挑到的数字都不一样！

**常用的 random 方法一览：**

| 方法 | 含义 | 示例 |
|------|------|------|
| `random.randint(1, 10)` | 1~10 之间的随机整数 | 3、7、10 都有可能 |
| `random.randint(0, 1)` | 0 或 1（像抛硬币） | 0 或 1 |
| `random.choice(["苹果","香蕉","橘子"])` | 从列表中随机选一个 | 每次不一样 |

### 知识点 2：获取 Entry 输入并比较

游戏的核心逻辑：玩家在 Entry 输入框里输入一个数字，点击按钮后，程序把这个数字和秘密数字比较。

```python
def guess():
    user_num = int(entry.get())  # 从输入框获取文字，转成整数

    if user_num > secret:
        result_label.config(text="📉 太大了！再猜小一点")
    elif user_num < secret:
        result_label.config(text="📈 太小了！再猜大一点")
    else:
        result_label.config(text="🎉 恭喜你猜对了！")
```

> `entry.get()` 返回的是**字符串**，不能直接和数字比较！必须用 `int()` 把字符串转成整数。如果用户输入的不是数字（比如输入了 "abc"），`int()` 会报错——所以最好加上 `try-except` 来保护程序。

### 知识点 3：游戏流程设计

整个游戏的流程是这样的：

```
程序启动 → 生成随机数（藏在后台）
   ↓
玩家在 Entry 里输入猜测 → 点击"猜！"按钮
   ↓
程序比较：太大？太小？刚好？
   ↓
用 Label 显示提示文字
   ↓
（如果猜对了 → 显示庆祝信息）
```

## 完整代码

```python
import tkinter as tk
import random

# ========================================
# 第 23 节：项目3 —— 猜数字游戏（上）
# 知识点：random.randint、Entry、if-elif-else、Label 反馈
# ========================================

# ---------- 游戏初始化 ----------
secret = random.randint(1, 100)  # 生成 1~100 的秘密数字

# ---------- 创建窗口 ----------
root = tk.Tk()
root.title("猜数字游戏")
root.geometry("450x350")
root.configure(bg="#f5f0e8")

# ---------- 标题 ----------
title_label = tk.Label(root, text="🔢 猜数字游戏",
                       font=("微软雅黑", 22, "bold"),
                       bg="#f5f0e8", fg="#5a3e2b")
title_label.pack(pady=20)

# ---------- 提示说明 ----------
hint_label = tk.Label(root, text="我心里想了一个 1~100 的数字，你猜猜看？",
                      font=("微软雅黑", 13),
                      bg="#f5f0e8", fg="#666666")
hint_label.pack(pady=(0, 15))

# ---------- 输入区域 ----------
entry = tk.Entry(root, font=("微软雅黑", 18), width=8,
                 justify="center")  # 文字居中
entry.pack(pady=5)
entry.focus()  # 让输入框自动获得焦点，不用鼠标点就能输入

# ---------- 结果反馈 Label ----------
result_label = tk.Label(root, text="👆 在上面输入数字，点按钮开始！",
                         font=("微软雅黑", 14),
                         bg="#f5f0e8", fg="#2d7d6e")
result_label.pack(pady=15)

# ---------- 猜数字的核心函数 ----------
def guess():
    """获取玩家输入，与秘密数字比较，给出反馈"""
    # ① 获取用户输入，用 try-except 防止输入非数字时崩溃
    try:
        user_num = int(entry.get())
    except ValueError:
        result_label.config(text="⚠️ 请输入一个有效的数字！", fg="#c4593f")
        return

    # ② 检查数字范围
    if user_num < 1 or user_num > 100:
        result_label.config(text="⚠️ 请输入 1~100 之间的数字！", fg="#c4593f")
        return

    # ③ 比较大小，给出反馈
    if user_num > secret:
        result_label.config(text=f"📉 {user_num} 太大了！再猜小一点", fg="#d88a3a")
    elif user_num < secret:
        result_label.config(text=f"📈 {user_num} 太小了！再猜大一点", fg="#2d7d6e")
    else:
        result_label.config(text=f"🎉 恭喜你猜对了！答案就是 {secret}！", fg="#2d7d6e")

    # ④ 清空输入框，方便下一次输入
    entry.delete(0, "end")
    entry.focus()

# ---------- 按钮 ----------
guess_btn = tk.Button(root, text="🎯 猜！", command=guess,
                      font=("微软雅黑", 14, "bold"),
                      bg="#2d7d6e", fg="#ffffff",
                      width=10, cursor="hand2")
guess_btn.pack(pady=10)

# ---------- 绑定回车键（按回车也能触发猜测） ----------
root.bind("<Return>", lambda event: guess())

# ---------- 启动主循环 ----------
root.mainloop()
```

## 小贴士
- `random.randint(a, b)` **包含 a 和 b**，所以 `randint(1, 10)` 可能出现 1，也可能出现 10
- `entry.get()` 返回的是**字符串**，一定要用 `int()` 转换成整数才能和秘密数字比较
- 用 `try-except ValueError` 包裹 `int()` 转换，防止用户输入 "abc" 这样的非数字内容导致程序崩溃
- `entry.delete(0, "end")` 可以在猜完之后清空输入框，让玩家直接输入下一次猜测
- `root.bind("<Return>", ...)` 可以绑定回车键，按回车也能触发猜测，不用每次都去点按钮
- 下节预告：我们会给游戏加上**猜测次数统计**、**重新开始按钮**，甚至做一个**排行榜**，让猜数字游戏变得更完整！
