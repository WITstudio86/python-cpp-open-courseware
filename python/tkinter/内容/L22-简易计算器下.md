## 知识点讲解

### 知识点 1：C 清除 和 ← 退格

这两个功能是每个计算器的"标配"。C（Clear）一键清空所有内容，←（Backspace）退格删掉最后一个字符。

```python
def clear():
    """C 按钮：清空所有内容"""
    entry_var.set("")  # 把 Entry 的 StringVar 设为空字符串

def backspace():
    """← 按钮：删除最后一个字符"""
    current = entry_var.get()      # 获取当前显示的内容
    entry_var.set(current[:-1])    # 切片：去掉最后一个字符
```

> 💡 **语法提示**：`current[:-1]` 是 Python 的字符串切片，`:-1` 表示"从开头取到倒数第二个字符"，也就是去掉最末尾的那个字符。如果字符串已经是空的，`[:-1]` 仍然是空字符串，不会报错。

### 知识点 2：连续运算

"连续运算"是指：输入 `1 + 2 =` 得到结果 `3` 之后，可以直接继续输入 `+ 5 =` 得到 `8`。不需要重新开始。

实现的方法很简单：**算完之后不要清空 Entry，而是把结果留在里面**，用户继续按键就自然拼接上去了。

```python
def click(key):
    """按钮点击：把 key 追加到表达式末尾"""
    current = entry_var.get()
    entry_var.set(current + str(key))
```

因为 Entry 里始终是"字符串表达式"（比如 `"1+2"` → `"3"` → `"3+5"`），只要用户继续输入，字符串就会不断拼接，eval() 一次性就能算出整个表达式的结果，不需要额外的累加器。

### 知识点 3：eval() 安全使用

`eval()` 是 Python 内置函数，它能把一个**字符串**当成 Python 代码来执行。在计算器中，我们用它来"算出"表达式的结果。

```python
def calculate():
    """= 按钮：计算表达式的结果"""
    try:
        result = eval(entry_var.get())   # 把输入框里的字符串当成算术表达式计算
        entry_var.set(str(result))       # 把结果写回输入框
    except:
        entry_var.set("错误")            # 如果表达式不合法（比如 "1++2"），显示错误
```

> ⚠️ **eval() 的安全说明**：`eval()` 非常强大，可以执行任何 Python 代码。在计算器中，因为我们自己控制输入内容（只有数字和运算符），所以是安全的。但在开发真正的应用程序时，**永远不要**把用户随意输入的字符串直接传给 `eval()`——那可能会执行恶意代码！在我们的课程中，仅限计算器场景使用。

> 💡 **try-except 的作用**：如果计算器遇到无法计算的表达式（比如除以 0、连续两个运算符等），Python 会"报错"并崩溃。用 `try-except` 包裹后，出错时不崩溃，而是显示"错误"——让用户知道格式不对，然后按 C 清除重新来。

### 知识点 4：键盘按键绑定

除了用鼠标点按钮，计算器还应该支持键盘输入——直接按键盘上的数字和运算符就能操作，这才是真正的"好用"！

tkinter 用 `bind()` 方法来绑定键盘事件：

```python
root.bind("<Key>", key_press)  # 绑定所有按键事件

def key_press(event):
    """处理键盘按键"""
    key = event.char  # event.char 是按键对应的字符

    if key in "0123456789+-*/.=":
        # 数字、运算符、小数点或等号 → 和点击按钮一样处理
        if key == "=":
            calculate()
        else:
            click(key)
    elif event.keysym == "Return":    # 回车键 → 等于 =
        calculate()
    elif event.keysym == "BackSpace": # 退格键 → ←
        backspace()
    elif event.keysym == "Escape":    # ESC 键 → C
        clear()
```

| 事件绑定 | 触发条件 |
|----------|----------|
| `<Key>` | 键盘上任意按键按下 |
| `event.char` | 按键对应的可打印字符（如 `"1"`、`"+"`、`"a"`） |
| `event.keysym` | 按键的名称（如 `"Return"` 回车、`"BackSpace"` 退格、`"Escape"` ESC） |

> 💡 **注意区分**：普通按键（数字、字母）用 `event.char` 获取字符；特殊按键（回车、退格、ESC）没有字符，要用 `event.keysym` 获取按键名称。

## 完整代码

```python
import tkinter as tk

# ========================================
# 第 22 节：项目2 —— 简易计算器（下）
# 知识点：连续运算、C/←功能、eval()、键盘绑定 bind()
# ========================================

# ---------- 创建窗口 ----------
root = tk.Tk()
root.title("简易计算器")
root.geometry("350x450")
root.configure(bg="#2c3e50")
root.resizable(False, False)  # 固定窗口大小

# ---------- 输入框（显示表达式和结果）----------
entry_var = tk.StringVar()
entry_var.set("")

entry = tk.Entry(
    root,
    textvariable=entry_var,         # 绑定 StringVar
    font=("Consolas", 24),          # 等宽大字体
    justify="right",                # 右对齐（像真正的计算器）
    state="readonly",               # 只读，防止用户直接在输入框里打字
    readonlybackground="#ecf0f1",   # 只读时的背景色
    fg="#2c3e50"                    # 文字颜色
)
entry.grid(row=0, column=0, columnspan=4, padx=10, pady=15, sticky="nsew")

# ---------- 按钮数据 ----------
# 格式：(文字, 行, 列, 列跨度)
buttons = [
    ("C", 1, 0, 1), ("←", 1, 1, 1), ("/", 1, 2, 1), ("*", 1, 3, 1),
    ("7", 2, 0, 1), ("8", 2, 1, 1), ("9", 2, 2, 1), ("-", 2, 3, 1),
    ("4", 3, 0, 1), ("5", 3, 1, 1), ("6", 3, 2, 1), ("+", 3, 3, 1),
    ("1", 4, 0, 1), ("2", 4, 1, 1), ("3", 4, 2, 1),
    ("0", 5, 0, 1), (".", 5, 1, 1), ("=", 5, 2, 2),
]

# ---------- 按钮回调函数 ----------
def click(key):
    """普通按键：把字符追加到表达式末尾"""
    current = entry_var.get()
    entry_var.set(current + str(key))

def clear():
    """C 按钮：清空输入框"""
    entry_var.set("")

def backspace():
    """← 按钮：删除最后一个字符"""
    current = entry_var.get()
    entry_var.set(current[:-1])

def calculate():
    """= 按钮：用 eval() 计算表达式结果"""
    try:
        result = eval(entry_var.get())
        entry_var.set(str(result))
    except:
        entry_var.set("错误")

# ---------- 创建按钮 ----------
for (text, row, col, colspan) in buttons:
    # 判断按钮类型，决定回调函数
    if text == "C":
        cmd = clear
    elif text == "←":
        cmd = backspace
    elif text == "=":
        cmd = calculate
    else:
        # lambda 传参：把按钮上的文字传给 click 函数
        cmd = lambda t=text: click(t)

    btn = tk.Button(
        root,
        text=text,
        font=("Consolas", 16, "bold"),
        width=5,
        height=2,
        command=cmd,
        bg="#34495e",          # 默认背景色
        fg="white",            # 文字颜色
        activebackground="#1abc9c",  # 按下时的背景色
        relief="flat",         # 扁平风格
        bd=1
    )
    btn.grid(row=row, column=col, columnspan=colspan, padx=2, pady=2, sticky="nsew")

    # 把 = 号按钮标成特殊颜色
    if text == "=":
        btn.configure(bg="#e67e22", activebackground="#d35400")

# ---------- 键盘按键绑定 ----------
def key_press(event):
    """处理键盘输入"""
    key = event.char  # 可打印字符

    if key in "0123456789+-*/.=":
        # 数字、运算符、小数点或等号
        if key == "=":
            calculate()
        else:
            click(key)
    elif event.keysym == "Return":    # 回车键 → 等于
        calculate()
    elif event.keysym == "BackSpace": # 退格键 → ←
        backspace()
    elif event.keysym == "Escape":    # ESC 键 → C
        clear()

# 绑定所有按键事件到 root 窗口
root.bind("<Key>", key_press)

# ---------- 设置行和列的权重（让按钮随窗口均匀分布）----------
for i in range(6):     # 6 行（0~5）
    root.grid_rowconfigure(i, weight=1)
for j in range(4):     # 4 列（0~3）
    root.grid_columnconfigure(j, weight=1)

# ---------- 启动窗口主循环 ----------
root.mainloop()
```

## 小贴士
- `eval()` 是把字符串当 Python 代码来执行——它能算 `2+3*4`，知道先乘除后加减
- `try-except` 是"安全网"——出了问题不会崩溃，而是优雅地显示"错误"
- `bind()` 的 `<Key>` 能捕获所有键盘按键，但要用 `event.keysym` 区分特殊键（如回车、退格）
- `current[:-1]` 的切片语法在字符串为空时也不会报错——返回的仍然是空字符串
- 输入框的 `state="readonly"` 阻止用户直接在输入框里打字——这样所有输入都经过我们的 `click()` 函数，能更好地控制
