# 第 10 节 · 趣味问答小测验

## 学习目标
- 学会使用 `grid()` 网格布局来排列控件
- 学会使用 `Radiobutton`（单选按钮）制作选择题
- 学会使用 `messagebox` 弹出消息框显示结果
- 综合运用 Button、Label、Radiobutton 制作一个自动评分小测验

## 本节课成品
一个包含 3 道选择题的趣味问答小测验，点击"提交答案"后自动评分，弹出成绩对话框！

---

## 知识点讲解

### 知识点 1：grid() 网格布局

`grid()` 是一种表格式的布局方式，把窗口想象成一个由**行（row）和列（column）**组成的网格，控件放在第几行第几列。

```python
# 语法：控件.grid(row=行号, column=列号, sticky=对齐方向)
label.grid(row=0, column=0, columnspan=2)  # columnspan 表示跨多列
button.grid(row=5, column=1, sticky="w")   # sticky: N/S/E/W 方向对齐
```

| 参数 | 说明 | 例子 |
|------|------|------|
| `row` | 行号（从 0 开始） | `row=1` |
| `column` | 列号（从 0 开始） | `column=0` |
| `columnspan` | 跨几列 | `columnspan=3` |
| `sticky` | 对齐方向 | `sticky="w"`（左对齐） |
| `padx` / `pady` | 外边距 | `padx=10, pady=5` |

### 知识点 2：Radiobutton 单选按钮

`Radiobutton` 可以让用户在多个选项中选择一个。同一道题的选项要用同一个 `variable`（变量）来分组，这样选一个，其他的自动取消。

```python
# 创建 Radiobutton
var = tk.StringVar(value="")  # 存储选中值的变量，初始为空

tk.Radiobutton(root, text="选项 A", variable=var, value="A").grid(row=0, column=0)
tk.Radiobutton(root, text="选项 B", variable=var, value="B").grid(row=0, column=1)
```

- `variable`：同一个变量名的 Radiobutton 属于同一组
- `value`：选中这个选项时，variable 会被设置成这个值
- 同一组的 Radiobutton 自动互斥

### 知识点 3：messagebox 消息框

`messagebox` 可以弹出一个小窗口显示信息，是 `tkinter` 的子模块，需要单独导入。

```python
from tkinter import messagebox

# 显示信息框
messagebox.showinfo("标题", "要显示的文字内容")
```

## 完整代码

```python
import tkinter as tk
from tkinter import messagebox

# ========================================
# 第 10 节：趣味问答小测验
# ========================================

root = tk.Tk()
root.title("趣味问答小测验")
root.geometry("500x450")
root.configure(bg="#f5f0ff")  # 浅紫色背景

# ---------- 题目和选项数据 ----------
# 每道题是一个字典：question 是题目，options 是 4 个选项，answer 是正确答案
questions = [
    {
        "question": "1. Python 中创建 tkinter 窗口使用什么方法？",
        "options": ["A. Tk()", "B. Window()", "C. Screen()", "D. Frame()"],
        "answer": "A"
    },
    {
        "question": "2. 下面哪个方法用来设置窗口标题？",
        "options": ["A. name()", "B. title()", "C. header()", "D. label()"],
        "answer": "B"
    },
    {
        "question": "3. mainloop() 的作用是什么？",
        "options": ["A. 关闭窗口", "B. 设置窗口大小", "C. 让窗口持续显示", "D. 创建按钮"],
        "answer": "C"
    }
]

# ---------- 存储每道题用户选择的变量 ----------
vars_list = []  # 存放每道题对应的 StringVar

# ---------- 用 grid 布局逐题放置 ----------
for i, q in enumerate(questions):
    # 题目文字（跨 4 列显示，因为每题有 4 个选项）
    q_label = tk.Label(root, text=q["question"],
                       font=("Microsoft YaHei", 13, "bold"),
                       bg="#f5f0ff", fg="#333333",
                       anchor="w", justify="left")
    q_label.grid(row=i * 2, column=0, columnspan=4,
                 sticky="w", padx=30, pady=(15, 5))

    # 为这道题创建一个 StringVar，并存入列表
    var = tk.StringVar(value="")  # 默认不选中任何选项
    vars_list.append(var)

    # 4 个选项按钮放在下一行
    for j, option in enumerate(q["options"]):
        rb = tk.Radiobutton(root, text=option,
                            variable=var, value=option[0],  # 取选项首字母 A/B/C/D 作为值
                            font=("Microsoft YaHei", 11),
                            bg="#f5f0ff", fg="#555555",
                            selectcolor="#d5c8f0",
                            anchor="w")
        rb.grid(row=i * 2 + 1, column=j,
                sticky="w", padx=(30 if j == 0 else 5, 5), pady=5)

# ---------- 提交按钮 ----------
def submit():
    """检查答案并计算得分"""
    score = 0
    for i, q in enumerate(questions):
        if vars_list[i].get() == q["answer"]:
            score += 1

    # 弹窗显示成绩
    total = len(questions)
    messagebox.showinfo(
        "测验结果",
        f"你答对了 {score} / {total} 题！\n\n"
        + ("太棒了，全部正确！🎉" if score == total else
           f"不错哦，对了 {score} 题，继续加油！💪")
    )


submit_btn = tk.Button(root, text="📝 提交答案",
                       command=submit,
                       font=("Microsoft YaHei", 14, "bold"),
                       bg="#7c4dff", fg="white",
                       activebackground="#651fff",
                       relief="flat", padx=30, pady=8,
                       cursor="hand2")
submit_btn.grid(row=len(questions) * 2, column=0, columnspan=4,
                pady=30)

# 提示文字
tip = tk.Label(root, text="💡 选好答案后点击「提交答案」查看得分",
               font=("Microsoft YaHei", 10),
               bg="#f5f0ff", fg="#888888")
tip.grid(row=len(questions) * 2 + 1, column=0, columnspan=4, pady=(0, 10))

root.mainloop()
```

## 小贴士
- `grid()` 的行号列号都从 0 开始，不要搞混
- 同一道题的 Radiobutton 必须共享同一个 `variable`，否则不能互斥
- `messagebox.showinfo()` 是**阻塞**的——弹出后，必须点确定才能继续操作主窗口
- `columnspan` 可以让一个控件跨越多列，适合标题和按钮
