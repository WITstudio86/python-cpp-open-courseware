## 知识点讲解

### 知识点 1：Canvas —— 我们的画布

`Canvas` 是 tkinter 里的"画板"，你可以在上面画线条、矩形、圆形、文字……游戏画面通常就是在 Canvas 上绘制的。

```python
# 创建画布
canvas = tk.Canvas(root, width=400, height=400,
                   bg="#16213e",          # 画布背景色
                   highlightthickness=0)   # 去掉边框
canvas.pack()

# 画一个矩形
canvas.create_rectangle(10, 20, 30, 40,   # 左上角坐标(10,20)，右下角坐标(30,40)
                        fill="#00ff88",   # 填充颜色
                        outline="")       # 无边框
```

| 方法 | 说明 | 例子 |
|------|------|------|
| `create_rectangle(x1,y1,x2,y2)` | 画矩形 | 四个坐标：左上角和右下角 |
| `create_oval(x1,y1,x2,y2)` | 画椭圆/圆形 | 坐标含义同矩形 |
| `create_line(x1,y1,x2,y2)` | 画线段 | 可以连接多个点 |
| `create_text(x, y, text="...")` | 写文字 | 在画布上写字 |
| `delete("标签名")` | 删除带标签的图形 | `canvas.delete("snake")` |
| `delete("all")` | 清空整个画布 | 慎用！ |

> 🎨 **坐标系统**：Canvas 的左上角是 `(0, 0)`，x 向右增加，y 向下增加。这和我们数学课上的坐标系不一样哦！

### 知识点 2：用列表存蛇身坐标

贪吃蛇的身体是一节一节连在一起的，我们可以用一个**列表**来存储每一节的坐标：

```python
# 蛇身的每一节是一个 (x, y) 元组
# 列表的第 0 项是蛇头，最后一项是蛇尾
snake_body = [(200, 200),   # 蛇头
              (190, 200),   # 第 2 节
              (180, 200)]   # 蛇尾

# 每个小格子的大小（像素）
cell_size = 10
```

**蛇怎么"移动"呢？** 其实就是一个数学操作：

```
新的蛇头坐标 = 旧蛇头坐标 + 方向偏移
新蛇身 = [新蛇头] + 旧蛇身[:-1]（去掉最后一节尾巴）
```

```python
def move_snake():
    """让蛇向前移动一格"""
    global snake_body

    # 1. 获取蛇头坐标
    head_x, head_y = snake_body[0]

    # 2. 根据方向计算新蛇头的位置
    if direction == "Right":
        head_x += cell_size
    elif direction == "Left":
        head_x -= cell_size
    elif direction == "Up":
        head_y -= cell_size
    elif direction == "Down":
        head_y += cell_size

    # 3. 新蛇身 = 新蛇头 + 旧蛇身的前面部分（去掉尾巴）
    new_head = (head_x, head_y)
    snake_body = [new_head] + snake_body[:-1]

    # 4. 重新绘制蛇
    draw_snake()
```

> 🧠 **为什么去掉最后一项？** 因为蛇向前移动时，后面的每一节都跟到前一节的位置，最后一节原来的位置就空出来了。去掉最后一节 + 在最前面加新头 = 蛇向前移动了一格！

### 知识点 3：键盘控制方向 —— `bind("<Key>")`

tkinter 可以用 `bind()` 方法监听键盘按键事件：

```python
def change_direction(event):
    """根据按下的方向键，改变蛇的前进方向"""
    global direction
    key = event.keysym  # 获取按下的键名，如 "Up", "Down", "Left", "Right"

    # 不能反向：如果蛇正往右走，不能立刻按左
    if key == "Up" and direction != "Down":
        direction = "Up"
    elif key == "Down" and direction != "Up":
        direction = "Down"
    elif key == "Left" and direction != "Right":
        direction = "Left"
    elif key == "Right" and direction != "Left":
        direction = "Right"

# 绑定键盘事件到窗口
root.bind("<Key>", change_direction)
```

| 绑定方式 | 说明 | 触发时机 |
|----------|------|----------|
| `bind("<Key>")` | 绑定所有按键 | 按下任意键 |
| `bind("<Up>")` | 绑定上方向键 | 按下 ↑ |
| `bind("<Down>")` | 绑定下方向键 | 按下 ↓ |
| `bind("<Left>")` | 绑定左方向键 | 按下 ← |
| `bind("<Right>")` | 绑定右方向键 | 按下 → |
| `bind("<space>")` | 绑定空格键 | 按下空格 |
| `bind("<Return>")` | 绑定回车键 | 按下 Enter |

> ⚠️ **重要规则**：蛇不能原地掉头！如果蛇正在向右走，按左键应该被忽略，否则蛇会"撞到自己"。代码里用 `direction != "Right"` 来防止这种情况。

### 知识点 4：让蛇动起来 —— `after()` 定时器

如果只调用一次 `move_snake()`，蛇只会移动一格就停了。我们需要让它**一直自动移动**——这就需要 `after()` 定时器了。

```python
def game_loop():
    """游戏主循环：移动蛇 + 重绘 + 定时再调用自己"""
    move_snake()                  # 移动蛇
    root.after(150, game_loop)    # 150 毫秒后再调用一次

# 启动游戏循环
game_loop()
```

`after()` 的格式：
```python
控件.after(毫秒, 函数名)
```

**意思是：** 等待指定的毫秒数之后，自动调用那个函数。注意函数名后面**不加括号**！

| 毫秒数 | 效果 |
|--------|------|
| `50` | 非常快（每秒 20 格） |
| `100` | 快（每秒 10 格） |
| `150` | 适中（每秒约 6.7 格） |
| `300` | 慢（每秒约 3.3 格） |

> 🎮 **游戏循环的原理**：`game_loop()` 调用自己，自己里面又设置 150ms 后再调用自己……这样就形成了一个"永不停歇的循环"。这就像动画片的每一帧——连续播放就动起来了！

## 完整代码

```python
import tkinter as tk

# ========================================
# 第 37 节：贪吃蛇游戏（上）—— 会移动的蛇
# 知识点：Canvas 绘制 + 键盘事件 + after() 定时器 + 列表存坐标
# ========================================

# 游戏配置
CELL_SIZE = 20          # 每节蛇身的大小（像素）
CANVAS_WIDTH = 400      # 画布宽度
CANVAS_HEIGHT = 400     # 画布高度
INITIAL_SPEED = 150     # 初始移动速度（毫秒），越小越快

# 1. 创建主窗口
root = tk.Tk()
root.title("🐍 贪吃蛇游戏")
root.geometry("500x550")
root.configure(bg="#1a1a2e")     # 深色背景
root.resizable(False, False)     # 禁止调整窗口大小

# 2. 标题标签
title_label = tk.Label(root, text="🐍 贪吃蛇游戏",
                       font=("微软雅黑", 18, "bold"),
                       bg="#1a1a2e", fg="#00ff88")
title_label.pack(pady=(15, 5))

# 3. 创建画布
canvas = tk.Canvas(root,
                   width=CANVAS_WIDTH,
                   height=CANVAS_HEIGHT,
                   bg="#16213e",             # 深蓝色画布背景
                   highlightthickness=0)      # 去掉边框
canvas.pack(pady=10)

# 4. 蛇的数据
#    蛇身的每一节是一个 (x, y) 坐标元组
#    列表第 0 项是蛇头，最后一项是蛇尾
snake_body = [
    (200, 200),   # 蛇头
    (180, 200),   # 第 2 节
    (160, 200),   # 第 3 节
    (140, 200),   # 蛇尾
]
direction = "Right"     # 初始方向：向右
score = 0               # 得分


def draw_snake():
    """在画布上绘制蛇身（先清空再重画）"""
    # 先删除画布上旧的蛇身（用 tag 标记）
    canvas.delete("snake")

    # 逐节绘制蛇身矩形
    for i, segment in enumerate(snake_body):
        x, y = segment
        color = "#00ff88" if i == 0 else "#00cc66"  # 蛇头亮绿色，身体深一点

        canvas.create_rectangle(
            x, y,                         # 左上角坐标
            x + CELL_SIZE, y + CELL_SIZE, # 右下角坐标
            fill=color,                   # 填充颜色
            outline="#00aa55",            # 边框颜色
            tag="snake"                   # 打上标签，方便统一删除
        )


def move_snake():
    """
    让蛇向前移动一格
    核心算法：新蛇头 = 旧蛇头 + 方向偏移
             新蛇身 = [新蛇头] + 旧蛇身[:-1]
    """
    global snake_body, score

    # 获取当前蛇头坐标
    head_x, head_y = snake_body[0]

    # 根据方向计算新蛇头的坐标
    if direction == "Right":
        head_x += CELL_SIZE
    elif direction == "Left":
        head_x -= CELL_SIZE
    elif direction == "Up":
        head_y -= CELL_SIZE
    elif direction == "Down":
        head_y += CELL_SIZE

    # 穿墙处理：蛇头移出画布后，从对面出现
    if head_x >= CANVAS_WIDTH:
        head_x = 0
    elif head_x < 0:
        head_x = CANVAS_WIDTH - CELL_SIZE
    if head_y >= CANVAS_HEIGHT:
        head_y = 0
    elif head_y < 0:
        head_y = CANVAS_HEIGHT - CELL_SIZE

    # 构造新蛇身
    new_head = (head_x, head_y)
    snake_body = [new_head] + snake_body[:-1]  # 加新头，去旧尾

    # 检查蛇头是否撞到自己身体
    if new_head in snake_body[1:]:
        game_over()
        return

    # 重新绘制蛇
    draw_snake()

    # 更新得分显示
    score_label.config(text=f"得分：{score}　　方向：{direction}")


def change_direction(event):
    """
    键盘事件处理：根据按键改变蛇的方向
    防止"反向操作"——蛇不能原地掉头
    """
    global direction
    key = event.keysym  # 获取按下的键名，如 "Right"

    # 判断合法性：不能反向
    if key == "Up" and direction != "Down":
        direction = "Up"
    elif key == "Down" and direction != "Up":
        direction = "Down"
    elif key == "Left" and direction != "Right":
        direction = "Left"
    elif key == "Right" and direction != "Left":
        direction = "Right"


def game_loop():
    """
    游戏主循环——"心跳"
    每隔一段时间移动蛇并刷新画面，形成连续动画
    """
    move_snake()
    # 150 毫秒后再调用自己一次，形成持续循环
    root.after(INITIAL_SPEED, game_loop)


def game_over():
    """游戏结束：在画布上显示结束文字"""
    canvas.create_text(
        CANVAS_WIDTH // 2, CANVAS_HEIGHT // 2,
        text="游戏结束！\n按 R 键重新开始",
        font=("微软雅黑", 24, "bold"),
        fill="#ff4444",
        justify="center",
        tag="gameover"
    )


def restart(event=None):
    """重新开始游戏（按 R 键触发）"""
    global snake_body, direction, score

    # 重置蛇身（回到初始位置）
    snake_body = [(200, 200), (180, 200), (160, 200), (140, 200)]
    direction = "Right"
    score = 0

    # 清除游戏结束的文字
    canvas.delete("gameover")

    # 重新绘制蛇
    draw_snake()
    score_label.config(text=f"得分：{score}　　方向：{direction}")


# 5. 绑定键盘事件
root.bind("<Key>", change_direction)    # 上下左右方向键
root.bind("<r>", restart)               # 小写 r 键
root.bind("<R>", restart)               # 大写 R 键

# 6. 得分和方向显示
score_label = tk.Label(root, text=f"得分：{score}　　方向：{direction}",
                       font=("微软雅黑", 13),
                       bg="#1a1a2e", fg="#cccccc")
score_label.pack(pady=5)

# 7. 操作提示
tip_label = tk.Label(root,
                     text="↑ ↓ ← → 控制方向　｜　R 键重新开始",
                     font=("微软雅黑", 10),
                     bg="#1a1a2e", fg="#666688")
tip_label.pack(pady=(0, 10))

# 8. 初始绘制蛇（程序启动时画一次）
draw_snake()

# 9. 启动游戏循环（开始移动！）
game_loop()

# 10. 启动主循环
root.mainloop()
```

## 小贴士
- Canvas 的坐标原点在**左上角**，x 向右增加，y 向下增加。要记住这个"反直觉"的坐标系！
- `after()` 设置的函数名后面**不能加括号**！`root.after(150, game_loop)` 而不是 `root.after(150, game_loop())`
- 蛇身移动的核心算法：`snake_body = [new_head] + snake_body[:-1]` ——这是整个游戏最关键的一行代码
- 方向键的 `keysym` 值是 `"Up"`, `"Down"`, `"Left"`, `"Right"`，首字母大写
- 让蛇"穿墙"的处理是在 `move_snake()` 里判断坐标是否越界，然后重置到对面
