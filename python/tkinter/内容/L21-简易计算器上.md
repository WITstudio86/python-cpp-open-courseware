## 知识点讲解

### 知识点 1：grid 网格布局——让按钮排成计算器模样

普通的计算器按钮是 4 列排列的。`grid()` 通过 `row`（行）和 `column`（列）把按钮放到精确的位置，就像在表格里填格子。

```
┌──────────┬──────────┬──────────┬──────────┐
│    C     │    ←     │          │    /     │  ← row=1
├──────────┼──────────┼──────────┼──────────┤
│    7     │    8     │    9     │    *     │  ← row=2
├──────────┼──────────┼──────────┼──────────┤
│    4     │    5     │    6     │    -     │  ← row=3
├──────────┼──────────┼──────────┼──────────┤
│    1     │    2     │    3     │    +     │  ← row=4
├──────────┼──────────┼──────────┼──────────┤
│    0     │    .     │     =     │          │  ← row=5
└──────────┴──────────┴──────────┴──────────┘
  col=0      col=1      col=2      col=3
```

```python
# 每个按钮放在第几行、第几列
btn_7.grid(row=2, column=0)
btn_8.grid(row=2, column=1)
btn_9.grid(row=2, column=2)
btn_mul.grid(row=2, column=3)  # 乘法按钮
```

- `columnspan`：让一个控件跨越多列。比如顶部的输入框横跨 4 列
- `sticky`：控制控件在网格格子里向哪个方向拉伸（N/S/E/W）

### 知识点 2：lambda 给按钮传参数

按钮的 `command` 需要的是一个**函数**。如果我们想给函数传入参数（比如点击的是哪个数字），不能直接写 `command=click("1")`——这样代码一运行，`click("1")` 会**立刻执行**，而不是等点击才执行。

```python
# ❌ 错误：click("1") 在创建按钮时就执行了！
btn = tk.Button(root, text="1", command=click("1"))

# ✅ 正确：用 lambda 包一层，点击时才执行
btn = tk.Button(root, text="1", command=lambda: click("1"))
```

`lambda` 就像一个"延迟包装盒"——把要执行的函数和参数打包好，等到用户点击按钮时才打开执行。

**lambda 语法：**
```python
lambda: 函数名(参数)          # 无参数版本也可以：lambda: 执行语句
```

### 知识点 3：数字拼接——把每次点击"连起来"显示

你想按了 "1"，再按 "2"，屏幕上显示 "12"——这就是**字符串拼接**。

```python
# 用 StringVar 和 Entry 配合
entry_var = tk.StringVar()          # 创建一个能自动更新的字符串变量

entry = tk.Entry(root, textvariable=entry_var, state="readonly")
# textvariable：让 Entry 的内容和 entry_var 绑定，修改变量 = 修改显示
# state="readonly"：不让用户用键盘输入，只能通过按钮点击来"输入"

def click(key):
    """拼接数字/符号到条目中"""
    current = entry_var.get()       # 获取当前显示的字符串
    entry_var.set(current + key)    # 在后面追加新字符，再显示回去
```

| 操作 | entry_var 的值变化 |
|------|-------------------|
| 初始 | `""`（空） |
| 点 "1" | `"1"` |
| 点 "2" | `"12"` |
| 点 "+" | `"12+"` |
| 点 "3" | `"12+3"` |

## 完整代码

```python
import tkinter as tk

# ========================================
# 第 21 节：项目2 - 简易计算器（上）
# 知识点：grid 布局 + lambda 传参 + StringVar 拼接
# ========================================

# 1. 创建主窗口
root = tk.Tk()
root.title("简易计算器")
root.geometry("350x420")
root.configure(bg="#f0f4f8")

# 2. 创建 StringVar，绑定输入框
entry_var = tk.StringVar()

entry = tk.Entry(
    root,
    textvariable=entry_var,          # 绑定变量
    font=("Arial", 22),
    justify="right",                 # 文字右对齐
    state="readonly",                # 禁止键盘输入
    readonlybackground="white",
    relief="flat",
    bd=10
)
entry.grid(row=0, column=0, columnspan=4,
           sticky="ew", padx=10, pady=(15, 8))

# 3. 定义按钮回调
def click(key):
    """拼接字符到显示屏"""
    current = entry_var.get()
    entry_var.set(current + key)

def clear():
    """清空显示屏"""
    entry_var.set("")

# 4. 创建按钮
# 第 1 行：C、←、（空）、/
btn_c = tk.Button(root, text="C", font=("Arial", 15), bg="#ff6b6b", fg="white",
                  command=clear, width=5, height=2)
btn_c.grid(row=1, column=0, padx=3, pady=3)

btn_back = tk.Button(root, text="←", font=("Arial", 15), bg="#ffd93d",
                     command=lambda: entry_var.set(entry_var.get()[:-1]),
                     width=5, height=2)
btn_back.grid(row=1, column=1, padx=3, pady=3)

btn_div = tk.Button(root, text="/", font=("Arial", 15), bg="#6c5ce7", fg="white",
                    command=lambda: click("/"), width=5, height=2)
btn_div.grid(row=1, column=3, padx=3, pady=3)

# 第 2 行：7、8、9、*
for i, num in enumerate([7, 8, 9]):
    btn = tk.Button(root, text=str(num), font=("Arial", 15),
                    command=lambda n=num: click(str(n)),
                    width=5, height=2)
    btn.grid(row=2, column=i, padx=3, pady=3)

btn_mul = tk.Button(root, text="*", font=("Arial", 15), bg="#6c5ce7", fg="white",
                    command=lambda: click("*"), width=5, height=2)
btn_mul.grid(row=2, column=3, padx=3, pady=3)

# 第 3 行：4、5、6、-
for i, num in enumerate([4, 5, 6]):
    btn = tk.Button(root, text=str(num), font=("Arial", 15),
                    command=lambda n=num: click(str(n)),
                    width=5, height=2)
    btn.grid(row=3, column=i, padx=3, pady=3)

btn_sub = tk.Button(root, text="-", font=("Arial", 15), bg="#6c5ce7", fg="white",
                    command=lambda: click("-"), width=5, height=2)
btn_sub.grid(row=3, column=3, padx=3, pady=3)

# 第 4 行：1、2、3、+
for i, num in enumerate([1, 2, 3]):
    btn = tk.Button(root, text=str(num), font=("Arial", 15),
                    command=lambda n=num: click(str(n)),
                    width=5, height=2)
    btn.grid(row=4, column=i, padx=3, pady=3)

btn_add = tk.Button(root, text="+", font=("Arial", 15), bg="#6c5ce7", fg="white",
                    command=lambda: click("+"), width=5, height=2)
btn_add.grid(row=4, column=3, padx=3, pady=3)

# 第 5 行：0、.、=
btn_0 = tk.Button(root, text="0", font=("Arial", 15),
                  command=lambda: click("0"), width=12, height=2)
btn_0.grid(row=5, column=0, columnspan=2, padx=3, pady=3)

btn_dot = tk.Button(root, text=".", font=("Arial", 15),
                    command=lambda: click("."), width=5, height=2)
btn_dot.grid(row=5, column=2, padx=3, pady=3)

btn_eq = tk.Button(root, text="=", font=("Arial", 15), bg="#00b894", fg="white",
                   command=lambda: click("="), width=5, height=2)
btn_eq.grid(row=5, column=3, padx=3, pady=3)

# 5. 启动主循环
root.mainloop()
```

## 小贴士
- `lambda` 就像一个"延迟执行"的包装盒，把函数调用装起来，等点击时才打开
- 循环中创建按钮时，要用 `lambda n=num: click(str(n))` 来"固定"参数值，否则所有按钮会共用循环的最后一个值
- `state="readonly"` 的 Entry 不会出现闪烁光标，看起来更像计算器屏幕
- `columnspan` 可以让一个控件跨越多列，非常适合顶部的显示屏和底部的 0 按钮
- `entry_var.get()[:-1]` 是 Python 的切片操作，取到倒数第二位，实现"删除最后一个字符"
