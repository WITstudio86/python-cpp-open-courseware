## 知识点讲解

### 知识点 1：Text 控件 —— 多行文本框

之前我们学过 Entry（单行输入框），而 **Text** 是它的"升级版"——它可以容纳**多行文字**，就像 Windows 的记事本一样。

```python
import tkinter as tk

root = tk.Tk()
root.title("Text 控件演示")
root.geometry("400x300")

# 创建一个 Text 控件
text = tk.Text(root, width=40, height=10)  # 宽40字符，高10行
text.pack(padx=10, pady=10)

root.mainloop()
```

### Text vs Entry 对比表

| 特性 | Entry | Text |
|------|-------|------|
| 行数 | 只能单行 | 支持多行 |
| 内容读写 | `.get()` | `.get("1.0", "end-1c")` |
| 插入文字 | `.insert(0, "文字")` | `.insert("1.0", "文字")` |
| 清空内容 | `.delete(0, "end")` | `.delete("1.0", "end")` |
| 滚动条 | 不需要 | 经常需要 |
| 适用场景 | 用户名、密码、搜索框 | 编辑器、聊天记录、日志 |

### 知识点 2：Text 控件的索引系统

Text 控件使用**行列坐标**来定位文字位置，格式是 `"行.列"`：

```python
# 索引说明（从 1 开始，不是 0！）
text.insert("1.0", "第一行开头")     # 第 1 行，第 0 列
text.insert("2.5", "第二行第5列")   # 第 2 行，第 5 列
text.insert("end", "追加到末尾")    # "end" 表示文字末尾

# 读取全部内容
content = text.get("1.0", "end-1c")  # 从第1行第0列，到末尾去掉最后的换行符

# 清空全部内容
text.delete("1.0", "end")
```

**为什么要用 `"end-1c"` 而不是 `"end"`？**

`text.get("1.0", "end")` 会在最后多出一个换行符 `\n`。`"end-1c"` 的意思是"end 的位置再减 1 个字符"，去掉那个多余的换行符。

| 特殊索引 | 含义 |
|----------|------|
| `"1.0"` | 第 1 行第 0 列（文字最开头） |
| `"end"` | 文字末尾之后的位置 |
| `"end-1c"` | 文字末尾往前 1 个字符 |
| `"insert"` | 光标当前所在的位置 |

### 知识点 3：Scrollbar 滚动条

当 Text 控件里的文字超出可视范围时，就需要**滚动条**来上下翻看。滚动条必须和 Text 控件**双向绑定**：

```python
import tkinter as tk

root = tk.Tk()
root.title("带滚动条的 Text")
root.geometry("400x300")

# 创建一个 Frame 来容纳 Text 和 Scrollbar
frame = tk.Frame(root)
frame.pack(fill="both", expand=True, padx=10, pady=10)

# 创建滚动条（放在右边）
scrollbar = tk.Scrollbar(frame)
scrollbar.pack(side="right", fill="y")

# 创建 Text 控件
text = tk.Text(frame, width=40, height=10,
               yscrollcommand=scrollbar.set)  # 让滚动条跟着文字走
text.pack(side="left", fill="both", expand=True)

# 让滚动条能控制 Text 的滚动
scrollbar.config(command=text.yview)

root.mainloop()
```

**关键配置：**
- `text` 的 `yscrollcommand=scrollbar.set`：文字内容变化时通知滚动条
- `scrollbar` 的 `command=text.yview`：拖动滚动条时控制文字显示
- 这两行是**双向绑定**，必须同时设置才能正常工作！

### 知识点 4：insert、get、delete 三大方法

```python
import tkinter as tk

root = tk.Tk()
root.title("Text 三大方法")

text = tk.Text(root, width=40, height=10)
text.pack(padx=10, pady=10)

# 1. insert —— 插入文字
text.insert("1.0", "你好，这是第 1 行！\n")      # 在第1行开头插入
text.insert("end", "这是用 end 追加的行\n")       # 在末尾追加
text.insert("2.3", "[插入的文字]")                # 在第2行第3列插入

# 2. get —— 读取文字
def read_content():
    content = text.get("1.0", "end-1c")  # 读取全部内容
    print("文本框内容为：")
    print(content)

# 3. delete —— 删除文字
def clear_content():
    text.delete("1.0", "end")  # 清空全部内容

tk.Button(root, text="读取内容", command=read_content).pack(side="left", padx=10)
tk.Button(root, text="清空", command=clear_content).pack(side="left", padx=10)

root.mainloop()
```

**需要注意：**
- `insert()` 插入的位置用 `"行.列"` 的格式
- `get()` 需要指定起点和终点两个位置
- `delete()` 也是指定起点和终点，删除这个范围内的所有文字

## 完整代码

```python
import tkinter as tk

# ========================================
# 第 14 节：迷你记事本
# ========================================

# 创建主窗口
root = tk.Tk()
root.title("迷你记事本")
root.geometry("500x400")

# ----- 多行文本框 + 滚动条 -----
# 用 Frame 把 Text 和 Scrollbar 组合在一起
frame = tk.Frame(root)
frame.pack(fill="both", expand=True, padx=10, pady=(10, 5))

# 滚动条（放在右边，撑满高度）
scrollbar = tk.Scrollbar(frame)
scrollbar.pack(side="right", fill="y")

# 多行文本框
text = tk.Text(frame, font=("微软雅黑", 12),
               yscrollcommand=scrollbar.set)  # 文字滚动时同步滚动条
text.pack(side="left", fill="both", expand=True)

# 让滚动条能控制文本框的滚动（双向绑定）
scrollbar.config(command=text.yview)

# ----- 按钮区域 -----
btn_frame = tk.Frame(root)
btn_frame.pack(fill="x", padx=10, pady=5)

# 插入演示文字的功能
def insert_demo():
    """在文本框中插入一条演示文字"""
    text.insert("end", "这是一条新记录...\n")

# 清空功能
def clear_text():
    """清空文本框的全部内容"""
    text.delete("1.0", "end")

# 读取功能
def read_text():
    """读取文本框的全部内容并打印到控制台"""
    content = text.get("1.0", "end-1c")
    print("=" * 30)
    print("📝 记事本内容：")
    print(content)
    print("=" * 30)

# 创建三个按钮
tk.Button(btn_frame, text="✏️ 添加一行", command=insert_demo,
          bg="#e8f5e9", font=("微软雅黑", 10)).pack(side="left", padx=5)
tk.Button(btn_frame, text="📖 读取内容", command=read_text,
          bg="#e3f2fd", font=("微软雅黑", 10)).pack(side="left", padx=5)
tk.Button(btn_frame, text="🗑️ 清空", command=clear_text,
          bg="#fce4ec", font=("微软雅黑", 10)).pack(side="left", padx=5)

# 提示标签
tip = tk.Label(root, text="💡 提示：点击「读取内容」后，查看 Python 控制台输出",
               fg="#888888", font=("微软雅黑", 9))
tip.pack(pady=(0, 8))

# 启动主循环
root.mainloop()
```

## 小贴士
- Text 控件的行列索引**从 1 开始**（第 1 行、第 1 列），和 Python 列表的索引习惯不同，注意不要搞混！
- `"end-1c"` 是一个常用的技巧，用于去掉 `get()` 末尾多余的换行符
- 滚动条和 Text 的**双向绑定**是固定套路：`yscrollcommand` + `command`，缺一不可
- Text 控件可以设置 `state="disabled"` 让它变成只读模式（禁止用户编辑）
- 如果想让字体等宽（方便做代码编辑器），可以使用 `font=("Consolas", 12)` 或 `font=("Courier New", 12)`
