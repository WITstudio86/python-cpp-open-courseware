## 知识点讲解

### Canvas 是什么？
Canvas（画布）是 tkinter 的绘图区域，你可以在上面画线、画矩形、画圆、写字……就像一块真正的画布！

```python
canvas = tk.Canvas(root, width=600, height=400, bg="white")
canvas.pack()
```

Canvas 的坐标系：左上角是 (0, 0)，向右 x 增加，向下 y 增加。

### 知识点 1：Radiobutton 切换工具

Radiobutton 是「单选按钮」—— 一组按钮中只能选中一个。非常适合用来切换工具！

```python
tool = tk.StringVar(value="pencil")  # 默认选中铅笔

tk.Radiobutton(root, text="✏️ 铅笔", variable=tool,
               value="pencil", bg="white").pack()
tk.Radiobutton(root, text="📏 直线", variable=tool,
               value="line", bg="white").pack()
```

- 所有 Radiobutton 共享同一个 `variable`
- 选中的 Radiobutton 会把它的 `value` 赋给 `variable`
- `tool.get()` 可以获取当前选中的工具类型

### 知识点 2：Canvas 鼠标事件

Canvas 支持三种最常用的鼠标事件：

| 事件 | 绑定方式 | 触发时机 |
|------|----------|----------|
| 鼠标按下 | `<Button-1>` | 按下鼠标左键 |
| 鼠标拖拽 | `<B1-Motion>` | 按住左键移动 |
| 鼠标释放 | `<ButtonRelease-1>` | 松开鼠标左键 |

事件绑定的回调函数会收到一个 event 对象，包含鼠标坐标：

```python
def on_press(event):
    print(f"鼠标按下在: ({event.x}, {event.y})")

def on_drag(event):
    print(f"鼠标拖到: ({event.x}, {event.y})")

def on_release(event):
    print(f"鼠标释放在: ({event.x}, {event.y})")

canvas.bind("<Button-1>", on_press)
canvas.bind("<B1-Motion>", on_drag)
canvas.bind("<ButtonRelease-1>", on_release)
```

### 知识点 3：铅笔工具 —— create_line 跟随鼠标

铅笔工具的核心思路：在鼠标按下到释放的整个过程中，持续在鼠标经过的位置画小线段。

```python
last_x, last_y = None, None  # 上一个点的坐标

def on_press(event):
    global last_x, last_y
    last_x, last_y = event.x, event.y  # 记录起点

def on_drag(event):
    global last_x, last_y
    if last_x is not None:
        # 从上一点到当前点画一条小线段
        canvas.create_line(last_x, last_y, event.x, event.y,
                          fill="black", width=2)
        last_x, last_y = event.x, event.y  # 更新上一个点

def on_release(event):
    global last_x, last_y
    last_x, last_y = None, None  # 重置
```

**为什么用 `create_line` 画铅笔？** 鼠标移动很快时，两次事件之间有一段距离。如果把从「上一个位置」到「当前位置」之间连上线，就能形成连续的笔迹。

### 知识点 4：直线工具 —— 按下和释放两点连线

直线工具更简单：按下时记录起点，释放时从起点画到终点。

```python
start_x, start_y = None, None
preview_line = None  # 预览线（拖动时显示）

def on_press(event):
    global start_x, start_y
    start_x, start_y = event.x, event.y

def on_drag(event):
    global preview_line
    # 删除旧的预览线
    if preview_line:
        canvas.delete(preview_line)
    # 画一条新的预览线（虚线效果）
    preview_line = canvas.create_line(
        start_x, start_y, event.x, event.y,
        fill="gray", dash=(4, 4)  # 虚线
    )

def on_release(event):
    global preview_line
    # 删除预览线
    if preview_line:
        canvas.delete(preview_line)
        preview_line = None
    # 画真正的直线
    canvas.create_line(start_x, start_y, event.x, event.y,
                      fill="black", width=2)
```

### 知识点 5：根据 tool 变量分发逻辑

把铅笔和直线的逻辑整合到一个事件处理函数里：

```python
def on_press(event):
    global last_x, last_y, start_x, start_y
    if tool.get() == "pencil":
        last_x, last_y = event.x, event.y
    elif tool.get() == "line":
        start_x, start_y = event.x, event.y

def on_drag(event):
    if tool.get() == "pencil":
        # 铅笔逻辑
        ...
    elif tool.get() == "line":
        # 直线预览逻辑
        ...

def on_release(event):
    if tool.get() == "pencil":
        # 铅笔重置
        ...
    elif tool.get() == "line":
        # 直线完成
        ...
```

## 完整代码

```python
import tkinter as tk

# ========================================
# 第 33 节：项目 8 — 迷你画图板（铅笔 + 直线）
# ========================================

root = tk.Tk()
root.title("迷你画图板 🎨")
root.geometry("700x550")
root.configure(bg="#f0f0f0")

# ===== 状态变量 =====
tool = tk.StringVar(value="pencil")
color = "black"
line_width = 2

# 铅笔用
last_x, last_y = None, None

# 直线用
start_x, start_y = None, None
preview_line = None

# ===== 事件处理 =====
def on_press(event):
    global last_x, last_y, start_x, start_y
    if tool.get() == "pencil":
        last_x, last_y = event.x, event.y
    elif tool.get() == "line":
        start_x, start_y = event.x, event.y

def on_drag(event):
    global last_x, last_y, preview_line
    if tool.get() == "pencil":
        if last_x is not None:
            canvas.create_line(last_x, last_y, event.x, event.y,
                              fill=color, width=line_width,
                              capstyle=tk.ROUND)  # 圆头线端
            last_x, last_y = event.x, event.y
    elif tool.get() == "line":
        if preview_line:
            canvas.delete(preview_line)
        preview_line = canvas.create_line(
            start_x, start_y, event.x, event.y,
            fill="gray", dash=(4, 4), width=1
        )

def on_release(event):
    global last_x, last_y, preview_line
    if tool.get() == "pencil":
        last_x, last_y = None, None
    elif tool.get() == "line":
        if preview_line:
            canvas.delete(preview_line)
            preview_line = None
        canvas.create_line(start_x, start_y, event.x, event.y,
                          fill=color, width=line_width)

def clear_canvas():
    canvas.delete("all")

# ===== 界面布局 =====

# 标题
tk.Label(root, text="🎨 迷你画图板", font=("微软雅黑", 18, "bold"),
         bg="#f0f0f0", fg="#333").pack(pady=(15,5))

# 工具栏
toolbar = tk.Frame(root, bg="#e0e0e0", relief="solid", bd=1)
toolbar.pack(fill=tk.X, padx=10, pady=5)

tk.Label(toolbar, text="工具：", font=("微软雅黑", 12),
         bg="#e0e0e0").pack(side=tk.LEFT, padx=(10,5))

tk.Radiobutton(toolbar, text="✏️ 铅笔", variable=tool,
               value="pencil", bg="#e0e0e0",
               font=("微软雅黑", 11)).pack(side=tk.LEFT, padx=5)

tk.Radiobutton(toolbar, text="📏 直线", variable=tool,
               value="line", bg="#e0e0e0",
               font=("微软雅黑", 11)).pack(side=tk.LEFT, padx=5)

tk.Button(toolbar, text="🗑️ 清空", command=clear_canvas,
          font=("微软雅黑", 11), bg="#e07060", fg="white",
          relief="flat", padx=15).pack(side=tk.RIGHT, padx=10)

# 画布
canvas = tk.Canvas(root, width=650, height=400, bg="white",
                   relief="solid", bd=1, cursor="crosshair")
canvas.pack(padx=10, pady=10)

# 绑定鼠标事件
canvas.bind("<Button-1>", on_press)
canvas.bind("<B1-Motion>", on_drag)
canvas.bind("<ButtonRelease-1>", on_release)

# 底部提示
tk.Label(root, text="💡 提示：铅笔 = 自由涂鸦 | 直线 = 点击拖拽画直线",
         font=("微软雅黑", 10), bg="#f0f0f0", fg="#999").pack(pady=10)

root.mainloop()
```

## 小贴士
- 🎯 Canvas 的坐标原点在左上角，x 向右增加，y 向下增加
- 🖱️ `event.x` 和 `event.y` 是相对 Canvas 的坐标，非常方便
- ✏️ 铅笔原理 = 把鼠标经过的轨迹拆成很多小线段，用 create_line 连接
- 📏 直线预览用灰色虚线（dash=(4,4)），释放后画真正的黑色实线
- 🔄 `capstyle=tk.ROUND` 让线端变圆，铅笔笔迹更流畅
- ⚠️ 注意区分 `canvas.delete("all")`（删所有）和 `canvas.delete(id)`（删指定图形）
