你输入名字，机器人就会热情地跟你打招呼！还可以随机换一句问候语，点击"清空"一键还原。

---

## 知识点讲解 📖

### 1. 温故知新 —— 三个好朋友

在我们搭建机器人之前，先来回顾一下三个已经学过的控件：

| 控件 | 作用 | 创建方法 | 关键方法 |
|------|------|----------|----------|
| **Label** | 显示文字 | `tk.Label(root, text="...")` | `config(text="...")` 修改文字 |
| **Button** | 按钮，点击执行命令 | `tk.Button(root, text="...", command=fn)` | `command` 参数绑定回调函数 |
| **Entry** | 输入框，让用户输入文字 | `tk.Entry(root, font=..., width=...)` | `get()` 读取、`delete()` 清空、`insert()` 插入 |

> 💡 这三个控件是 Tkinter **最基础、最常用**的控件，学会了它们，你就能做出大部分简单的互动程序了！

---

### 2. config() —— 动态修改控件

`config()` 方法可以**在程序运行后**动态修改控件的属性。这在互动程序中非常重要！

```python
# 创建时设置属性
label = tk.Label(root, text="初始文字", fg="blue")
label.pack()

# 运行时用 config() 修改
label.config(text="你好，小明！", fg="red", font=("微软雅黑", 20))
```

**可以修改的属性非常多：**
- `text` —— 文字内容
- `fg` / `bg` —— 前景色 / 背景色
- `font` —— 字体
- `state` —— 状态（`"normal"` / `"disabled"`）

> 💡 在回调函数中调用 `config()`，就可以实现"用户点击按钮 → 界面内容发生变化"的效果，这就是互动程序的核心！

### 3. 组装机器人 —— 完整代码

下面就是打招呼机器人的完整代码。仔细看，你会发现它就是 Label + Button + Entry 的组合！

```python
import tkinter as tk

# ========================================
# 第 5 节：综合小练 —— 打招呼机器人
# ========================================

root = tk.Tk()
root.title("打招呼机器人 🤖")
root.geometry("500x450")
root.configure(bg="#e0f7fa")

# --- 标题 Label ---
title = tk.Label(
    root,
    text="🤖 打招呼机器人",
    font=("微软雅黑", 22, "bold"),
    fg="#006064",
    bg="#e0f7fa"
)
title.pack(pady=20)

# --- 机器人头像（用大号 emoji Label 代替）---
avatar = tk.Label(
    root,
    text="🤖",
    font=("微软雅黑", 60),
    bg="#e0f7fa"
)
avatar.pack(pady=5)

# --- 提示 ---
prompt = tk.Label(
    root,
    text="机器人：你叫什么名字呀？",
    font=("微软雅黑", 14),
    fg="#00838f",
    bg="#e0f7fa"
)
prompt.pack(pady=10)

# --- 输入框 ---
name_entry = tk.Entry(
    root,
    font=("微软雅黑", 15),
    width=20,
    justify="center",
    bd=2,
    relief="solid"
)
name_entry.pack(pady=5)

# --- 回复显示 Label（动态更新） ---
reply = tk.Label(
    root,
    text="",
    font=("微软雅黑", 16, "bold"),
    fg="#004d40",
    bg="#e0f7fa",
    wraplength=380
)
reply.pack(pady=15)

# --- 打招呼按钮 ---
def say_hello():
    """读取名字，更新回复"""
    name = name_entry.get().strip()
    if name:
        reply.config(text=f"你好，{name}！很高兴认识你！😊\n今天过得怎么样呀～")
    else:
        reply.config(text="你还没告诉我你的名字呢！😅")

hello_btn = tk.Button(
    root,
    text="👋 打招呼！",
    command=say_hello,
    font=("微软雅黑", 14, "bold"),
    bg="#0097a7",
    fg="white",
    activebackground="#00838f",
    padx=25,
    pady=8
)
hello_btn.pack(pady=5)

# --- 换一句按钮 ---
import random
greetings = [
    "嘿，{name}！今天也要加油哦 💪",
    "{name}同学，准备好学编程了吗？🚀",
    "哇，{name}！这名字真好听～",
    "{name}，你今天看起来精神很好！✨"
]

def random_greet():
    """随机选一句问候语"""
    name = name_entry.get().strip()
    if name:
        msg = random.choice(greetings).format(name=name)
        reply.config(text=msg)
    else:
        reply.config(text="先输入名字再点我嘛～")

random_btn = tk.Button(
    root,
    text="🎲 换一句",
    command=random_greet,
    font=("微软雅黑", 12),
    bg="#4dd0e1",
    fg="white",
    padx=15,
    pady=5
)
random_btn.pack(pady=5)

# --- 清空按钮 ---
def clear_all():
    """清空输入框和回复"""
    name_entry.delete(0, tk.END)
    reply.config(text="")

clear_btn = tk.Button(
    root,
    text="🗑️ 清空",
    command=clear_all,
    font=("微软雅黑", 11),
    bg="#b2ebf2",
    fg="#006064",
    padx=12,
    pady=3
)
clear_btn.pack(pady=3)

# --- 底部签名 ---
footer = tk.Label(
    root,
    text="—— 由你亲手打造的第一个互动程序 💻",
    font=("微软雅黑", 10, "italic"),
    fg="#80deea",
    bg="#e0f7fa"
)
footer.pack(side="bottom", pady=10)

root.mainloop()
```

## 代码结构分析 🔍

这个机器人的结构非常清晰，我们来拆解一下：

```
打招呼机器人
├── 🤖 标题 Label        —— 显示程序名字
├── 🤖 头像 Label        —— 用大号 emoji 做装饰
├── 提示 Label            —— 机器人"说话"，引导用户输入
├── 输入框 Entry          —— 接收用户的名字
├── 回复 Label            —— 动态显示机器人的回复（config 更新）
├── 👋 打招呼按钮          —— 读取名字，更新回复 Label
├── 🎲 换一句按钮          —— 随机选取问候语，更新回复 Label
├── 🗑️ 清空按钮            —— 清空输入框 + 清空回复 Label
└── 底部签名 Label        —— 装饰性文字
```

> 💡 **关键观察**：这个程序用了 6 个 Label、3 个 Button、1 个 Entry。不同类型控件各司其职，配合 config() 实现互动！

## 小贴士 💡

- **config() 是万能的**：绝大多数控件属性都可以在程序运行时用 `config()` 修改。`text`、`fg`、`bg`、`font`、`state`……试一试你就知道了！

- **.strip() 是个好习惯**：从 Entry 中 `get()` 出来的文字可能带有多余的空格，用 `.strip()` 可以去除首尾空格，让判断更准确。

- **wraplength 参数**：Label 的 `wraplength` 参数可以设置文字自动换行的宽度。当回复内容较长时，这个参数很有用。

- **模块化思维**：注意代码中每个功能（打招呼、随机换句、清空）都有独立的函数。这样代码清晰好维护，也是编程的好习惯！
