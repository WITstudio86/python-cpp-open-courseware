## 知识点讲解

### 知识点1：导入 ttk 模块

ttk 是 tkinter 的"主题版"子模块，提供了一些更好看的控件。Combobox（下拉选择框）就是 ttk 里的。

```python
from tkinter import ttk
```

导入后，用 `ttk.Combobox(...)` 来创建下拉选择框。它比普通 tkinter 控件更好看，而且支持下拉列表。

### 知识点2：创建 Combobox 下拉选择框

```python
# 创建 Combobox
combo = ttk.Combobox(root, values=["选项1", "选项2", "选项3"])
combo.current(0)   # 默认选中第 0 项
combo.pack()
```

| 参数 | 说明 | 例子 |
|------|------|------|
| `values` | 下拉选项列表 | `values=["小明", "小红", "小刚"]` |
| `state` | 是否可编辑 | `"readonly"` 表示只能选不能改 |
| `.current(n)` | 设置默认选中第 n 项 | `combo.current(0)` |
| `.get()` | 获取当前选中的值 | `combo.get()` |

### 知识点3：绑定 `<<ComboboxSelected>>` 事件

当用户在下拉框中做出选择时，tkinter 会触发一个叫做 `<<ComboboxSelected>>` 的事件。我们可以通过 `bind()` 方法来"监听"这个事件，让程序自动执行某个函数。

```python
def on_select(event):
    # 当用户选择了新的选项时，这个函数会被调用
    selected = combo.get()
    label.config(text=f"你选择了：{selected}")

# 绑定事件：当选择改变时，自动调用 on_select 函数
combo.bind("<<ComboboxSelected>>", on_select)
```

**事件绑定的格式：**
```python
控件.bind("事件名称", 函数名)
```

**注意：** 函数名后面不要加括号！`on_select` 而不是 `on_select()`。

## 完整代码

```python
import tkinter as tk
from tkinter import ttk

# ========================================
# 第 12 节：个性名片生成器
# ========================================

root = tk.Tk()
root.title("个性名片生成器")
root.geometry("450x450")
root.configure(bg="#f5f0e8")

# ---------- 标题 ----------
title_label = tk.Label(root, text="🎨 个性名片生成器", font=("微软雅黑", 20, "bold"),
                       bg="#f5f0e8", fg="#5a3e2b")
title_label.pack(pady=15)

# ---------- 选择区域 ----------
# 名字选择
tk.Label(root, text="📛 选择名字：", font=("微软雅黑", 13),
         bg="#f5f0e8", fg="#5a3e2b").pack(pady=(10, 0))
name_combo = ttk.Combobox(root, values=["小明", "小红", "小刚", "小丽", "小华"],
                          state="readonly", font=("微软雅黑", 12), width=15)
name_combo.current(0)  # 默认选中第一个
name_combo.pack(pady=5)

# 年龄选择
tk.Label(root, text="🎂 选择年龄：", font=("微软雅黑", 13),
         bg="#f5f0e8", fg="#5a3e2b").pack(pady=(10, 0))
age_combo = ttk.Combobox(root, values=["8岁", "9岁", "10岁", "11岁", "12岁", "13岁"],
                         state="readonly", font=("微软雅黑", 12), width=15)
age_combo.current(2)  # 默认选中 "10岁"
age_combo.pack(pady=5)

# 爱好选择
tk.Label(root, text="⚽ 选择爱好：", font=("微软雅黑", 13),
         bg="#f5f0e8", fg="#5a3e2b").pack(pady=(10, 0))
hobby_combo = ttk.Combobox(root, values=["编程 💻", "画画 🎨", "足球 ⚽",
                                          "阅读 📚", "弹琴 🎹", "跳舞 💃"],
                           state="readonly", font=("微软雅黑", 12), width=15)
hobby_combo.current(0)  # 默认选中第一个
hobby_combo.pack(pady=5)


# ---------- 更新名片预览的函数 ----------
def update_card(event=None):
    """当下拉框选择改变时，自动更新名片预览"""
    name = name_combo.get()
    age = age_combo.get()
    hobby = hobby_combo.get()
    card_display.config(text=f"姓名：{name}\n年龄：{age}\n爱好：{hobby}")


# ---------- 生成名片的函数 ----------
def generate_card():
    """点击按钮时，生成最终名片"""
    name = name_combo.get()
    age = age_combo.get()
    hobby = hobby_combo.get()
    # 更新名片显示区域
    card_display.config(
        text=f"┌──────────────────┐\n"
             f"│   🌟 我的名片 🌟   │\n"
             f"│                  │\n"
             f"│  姓名：{name}    │\n"
             f"│  年龄：{age}      │\n"
             f"│  爱好：{hobby}    │\n"
             f"│                  │\n"
             f"└──────────────────┘"
    )


# 绑定事件：当下拉框选择改变时自动更新预览
name_combo.bind("<<ComboboxSelected>>", update_card)
age_combo.bind("<<ComboboxSelected>>", update_card)
hobby_combo.bind("<<ComboboxSelected>>", update_card)

# ---------- 名片预览区域 ----------
card_display = tk.Label(root, text="请选择信息后点击"生成名片"",
                        font=("微软雅黑", 13), bg="#fff8e7", fg="#5a3e2b",
                        width=30, height=8, relief="ridge", bd=2,
                        justify="left", anchor="nw")
card_display.pack(pady=15)

# ---------- 生成按钮 ----------
btn = tk.Button(root, text="🎫 生成名片", font=("微软雅黑", 14, "bold"),
                bg="#5a3e2b", fg="white", padx=20, pady=6,
                cursor="hand2", command=generate_card)
btn.pack(pady=10)

# 启动窗口
root.mainloop()
```

## 小贴士
- `Combobox` 需要 `from tkinter import ttk`，不能只用 `import tkinter as tk`
- `state="readonly"` 可以防止用户在下拉框中随意输入，保证数据格式统一
- `<<ComboboxSelected>>` 是固定的双尖括号事件名，注意大小写
- `bind()` 绑定的函数名后面**不要加括号**
- 如果函数需要在 bind 调用时也接收 event 参数，可以写成 `def func(event=None):`，这样按钮的 `command=func` 也能正常工作
