# 第 17 节 · 带菜单的记事本

## 知识点讲解

### 知识点 1：创建菜单栏

tkinter 的菜单是一个树状结构：先创建一个**总菜单栏**，再往里面添加**下拉菜单**，最后向下拉菜单里添加**菜单项**。

```python
# 第 1 步：创建总菜单栏
menubar = tk.Menu(root)

# 第 2 步：将菜单栏挂载到窗口上
root.config(menu=menubar)

# 第 3 步：创建下拉菜单（tearoff=False 禁止菜单被拖出来）
file_menu = tk.Menu(menubar, tearoff=False)

# 第 4 步：向下拉菜单添加命令
file_menu.add_command(label="新建", command=new_file)    # 添加一个菜单项
file_menu.add_separator()                                 # 添加分隔线
file_menu.add_command(label="退出", command=root.quit)

# 第 5 步：将下拉菜单添加到菜单栏
menubar.add_cascade(label="文件", menu=file_menu)
```

| 方法 | 说明 | 例子 |
|------|------|------|
| `tk.Menu(root)` | 创建总菜单栏 | `menubar = tk.Menu(root)` |
| `tk.Menu(menubar, tearoff=False)` | 创建下拉菜单 | `file_menu = tk.Menu(menubar, tearoff=False)` |
| `.add_command(label, command)` | 添加可点击的菜单项 | `file_menu.add_command(label="新建", command=new_file)` |
| `.add_separator()` | 添加分隔线（用于分组） | `file_menu.add_separator()` |
| `.add_cascade(label, menu)` | 将下拉菜单挂到菜单栏 | `menubar.add_cascade(label="文件", menu=file_menu)` |
| `root.config(menu=menubar)` | 把菜单栏装到窗口上 | `root.config(menu=menubar)` |

> **tearoff 是什么？** 如果 `tearoff=True`（默认值），菜单顶部会出现一条虚线，点击后菜单会被"撕下来"变成一个独立小窗口。通常我们设 `tearoff=False` 禁用它。

### 知识点 2：右键弹出菜单（上下文菜单）

除了窗口顶部的菜单栏，还可以创建**右键弹出菜单**——在鼠标右键点击的位置弹出一个菜单。

```python
# 创建一个独立的 Menu 作为右键菜单
popup_menu = tk.Menu(root, tearoff=False)
popup_menu.add_command(label="剪切", command=cut_text)
popup_menu.add_command(label="复制", command=copy_text)
popup_menu.add_command(label="粘贴", command=paste_text)

# 绑定鼠标右键事件
def show_popup(event):
    """在鼠标右键点击的位置弹出菜单"""
    popup_menu.post(event.x_root, event.y_root)

# 将右键事件绑定到控件上
text_area.bind("<Button-3>", show_popup)  # Button-3 = 鼠标右键
```

| 要点 | 说明 |
|------|------|
| `event.x_root` | 鼠标在**屏幕**上的绝对 x 坐标（不是控件内部坐标！） |
| `event.y_root` | 鼠标在**屏幕**上的绝对 y 坐标 |
| `post(x, y)` | 在屏幕坐标 `(x, y)` 处弹出菜单 |
| `<Button-3>` | 鼠标右键（Button-1 左键，Button-2 中键，Button-3 右键） |

> **event.x vs event.x_root**：`event.x` 是相对于控件的坐标，`event.x_root` 是相对于整个屏幕的坐标。`post()` 需要屏幕坐标，所以用 `event.x_root` / `event.y_root`。

### 知识点 3：messagebox 四种对话框

`messagebox` 是 `tkinter` 的子模块，需要单独导入。它提供了多种弹出对话框，用于不同场景。

```python
from tkinter import messagebox

# ① 信息提示框 —— 告诉用户一条消息
messagebox.showinfo("标题", "这是一条普通信息。")

# ② 警告框 —— 提醒用户注意
messagebox.showwarning("标题", "这是一条警告！")

# ③ 错误框 —— 告诉用户出错了
messagebox.showerror("标题", "发生错误了！")

# ④ 确认对话框 —— 让用户选择"是"或"否"，返回 True/False
result = messagebox.askyesno("标题", "确定要退出吗？")
if result:          # 用户点击了"是"
    root.quit()
```

| 对话框 | 用途 | 按钮 | 返回值 |
|--------|------|------|--------|
| `showinfo()` | 显示普通信息 | 确定 | `"ok"` |
| `showwarning()` | 显示警告信息 | 确定 | `"ok"` |
| `showerror()` | 显示错误信息 | 确定 | `"ok"` |
| `askyesno()` | 确认/取消 | 是 / 否 | `True` 或 `False` |

### 知识点 4：Text 多行文本框

`Text` 控件是一个可以输入多行文字的编辑区域，非常适合做记事本的主体。

```python
text_area = tk.Text(root, wrap="word", font=("Microsoft YaHei", 12))
text_area.pack(fill="both", expand=True)
```

- `wrap="word"`：按单词换行（不会在单词中间断开）
- `fill="both", expand=True`：让文本框填满整个窗口的可用空间
- `insert("1.0", "文字")`：在第 1 行第 0 列插入文字（行号从 1 开始，列号从 0 开始）
- `delete("1.0", "end")`：删除所有文字

## 完整代码

```python
import tkinter as tk
from tkinter import messagebox

# ========================================
# 第 17 节：带菜单的记事本
# ========================================

root = tk.Tk()
root.title("记事本")
root.geometry("600x450")
root.configure(bg="#f5f5f5")

# ========== 一、创建顶部菜单栏 ==========

# 第 1 步：创建总菜单栏（Menu 作为容器）
menubar = tk.Menu(root)

# 第 2 步：将菜单栏挂载到窗口（这一步很关键！）
root.config(menu=menubar)

# ---------- "文件" 菜单 ----------
# tearoff=False：禁止菜单被拖出来变成独立窗口
file_menu = tk.Menu(menubar, tearoff=False)

def new_file():
    """新建文件 —— 弹出确认对话框"""
    result = messagebox.askyesno("新建文件", "当前内容未保存，确定要新建吗？")
    if result:
        text_area.delete("1.0", "end")  # 清空文本框

def open_file():
    """打开文件 —— 提示功能（暂无实际打开功能）"""
    messagebox.showinfo("打开文件", "打开文件功能需要文件对话框，暂未实现。")

def save_file():
    """保存文件 —— 提示功能（暂无实际保存功能）"""
    messagebox.showinfo("保存文件", "保存文件功能需要文件对话框，暂未实现。")

def quit_app():
    """退出程序 —— 弹出确认对话框"""
    result = messagebox.askyesno("退出", "确定要退出记事本吗？")
    if result:
        root.quit()  # 关闭程序

# add_command：添加菜单项
# label=显示文字，command=点击执行的函数，accelerator=快捷键提示（仅显示，不绑定）
file_menu.add_command(label="新建", command=new_file, accelerator="Ctrl+N")
file_menu.add_command(label="打开", command=open_file, accelerator="Ctrl+O")
file_menu.add_command(label="保存", command=save_file, accelerator="Ctrl+S")
file_menu.add_separator()  # 分隔线 —— 将"退出"和其他选项分开
file_menu.add_command(label="退出", command=quit_app, accelerator="Ctrl+Q")

# ---------- "编辑" 菜单 ----------
edit_menu = tk.Menu(menubar, tearoff=False)

def cut_text():
    """剪切 —— 提示功能"""
    messagebox.showinfo("剪切", "请先用鼠标选中文字，然后使用 Ctrl+X 剪切。")

def copy_text():
    """复制 —— 提示功能"""
    messagebox.showinfo("复制", "请先用鼠标选中文字，然后使用 Ctrl+C 复制。")

def paste_text():
    """粘贴 —— 提示功能"""
    messagebox.showinfo("粘贴", "请先复制文字，然后使用 Ctrl+V 粘贴。")

edit_menu.add_command(label="剪切", command=cut_text, accelerator="Ctrl+X")
edit_menu.add_command(label="复制", command=copy_text, accelerator="Ctrl+C")
edit_menu.add_command(label="粘贴", command=paste_text, accelerator="Ctrl+V")

# ---------- "帮助" 菜单 ----------
help_menu = tk.Menu(menubar, tearoff=False)

def show_about():
    """显示"关于"对话框"""
    messagebox.showinfo(
        "关于记事本",
        "简易记事本 v1.0\n\n"
        "用 Python + tkinter 制作\n\n"
        "祝贺你完成了 Tkinter 系列课程的全部内容！🎉"
    )

help_menu.add_command(label="关于", command=show_about)

# 将下拉菜单添加到菜单栏
# add_cascade 将下拉菜单"挂"到菜单栏上
menubar.add_cascade(label="文件", menu=file_menu)
menubar.add_cascade(label="编辑", menu=edit_menu)
menubar.add_cascade(label="帮助", menu=help_menu)

# ========== 二、创建右键弹出菜单 ==========

# 右键菜单是一个独立的 Menu 对象
popup_menu = tk.Menu(root, tearoff=False)

# 给右键菜单添加编辑功能（和顶部"编辑"菜单相同的功能）
popup_menu.add_command(label="剪切", command=cut_text)
popup_menu.add_command(label="复制", command=copy_text)
popup_menu.add_command(label="粘贴", command=paste_text)
popup_menu.add_separator()
popup_menu.add_command(label="全选",
                       command=lambda: messagebox.showinfo("全选", "使用 Ctrl+A 全选。"))

def show_popup(event):
    """
    在鼠标右键点击的位置弹出菜单
    event.x_root / event.y_root 是鼠标在屏幕上的绝对坐标
    post() 方法在指定坐标显示菜单
    """
    popup_menu.post(event.x_root, event.y_root)

# ========== 三、文本编辑区域 ==========

# Text 是多行文本编辑控件，适合做记事本的主体
# wrap="word" 按单词换行，避免在单词中间断开
text_area = tk.Text(root, wrap="word",
                    font=("Microsoft YaHei", 12),
                    bg="white", fg="#333333",
                    insertbackground="#333333",  # 光标颜色
                    padx=10, pady=10)            # 内边距
text_area.pack(fill="both", expand=True, padx=10, pady=10)

# 插入初始提示文字
text_area.insert("1.0", "欢迎使用简易记事本！\n\n在这里输入你的文字吧～\n\n💡 试试右键点击编辑区域，会有惊喜哦！")

# 将右键弹出事件绑定到 Text 控件
# <Button-3> 表示按下鼠标右键
text_area.bind("<Button-3>", show_popup)

root.mainloop()
```

## 小贴士
- `root.config(menu=menubar)` 是把菜单装到窗口的关键步骤，忘了这行菜单就不会显示
- `tearoff=False` 是个好习惯，否则菜单顶部会出现一条虚线，误点后会"撕下"菜单
- `post(x, y)` 需要的是**屏幕坐标**，所以用 `event.x_root` / `event.y_root`，而不是 `event.x` / `event.y`
- `accelerator` 参数只是在菜单项右边**显示**快捷键提示文字，并不会真正绑定快捷键——真正的快捷键需要另外用 `bind()` 绑定
- `add_separator()` 添加的分隔线用于将相关功能分组，让菜单看起来更清晰
