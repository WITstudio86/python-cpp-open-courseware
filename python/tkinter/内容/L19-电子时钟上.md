## 知识点讲解

### 知识点 1：time 模块 —— 获取系统时间

Python 有一个内置的 `time` 模块，可以获取电脑的当前系统时间。不需要安装，直接 `import` 就能用。

```python
import time

# time.time() 返回从 1970年1月1日 到现在的秒数（时间戳）
timestamp = time.time()
print(timestamp)  # 类似 1751023456.789

# 我们一般不需要时间戳，而是想要"可读"的时间，所以要用 strftime()
```

时间戳就像一个"秒表"，从 1970 年开始计算秒数——这个数字对人来说很难读，所以 Python 提供了 `strftime()` 来把它转成我们能看懂的时间格式。

### 知识点 2：strftime() —— 格式化时间 ⏰

`strftime()` 是 **str**ing **f**ormat **time**（字符串格式化时间）的缩写。它可以按照你指定的格式，把时间变成漂亮的字符串。

```python
import time

# 语法：time.strftime(格式字符串)
current_time = time.strftime("%H:%M:%S")   # 时:分:秒 → 例如 "14:30:25"
current_date = time.strftime("%Y-%m-%d")   # 年-月-日 → 例如 "2026-06-27"
full_format = time.strftime("%Y年%m月%d日 %H:%M:%S")  # 混合格式
```

| 格式码 | 含义 | 示例 |
|--------|------|------|
| `%H` | 小时（24 小时制） | 00 ~ 23 |
| `%I` | 小时（12 小时制） | 01 ~ 12 |
| `%M` | 分钟 | 00 ~ 59 |
| `%S` | 秒 | 00 ~ 59 |
| `%Y` | 四位年份 | 2026 |
| `%m` | 月份 | 01 ~ 12 |
| `%d` | 日期 | 01 ~ 31 |
| `%A` | 星期（英文全称） | Monday |
| `%a` | 星期（英文缩写） | Mon |
| `%p` | AM / PM | AM 或 PM |

> 💡 **小技巧**：`%H` 和 `%I` 的区别——`%H` 是 24 小时制（下午 2 点 = 14），`%I` 是 12 小时制（下午 2 点 = 02），通常电子时钟用 `%H`。

### 知识点 3：用 Label 显示时间

把 `strftime()` 得到的字符串放到一个 `Label` 里，用**大字体**显示，就是一个电子时钟的外观！

```python
import tkinter as tk

time_label = tk.Label(root, text="00:00:00",
                      font=("Consolas", 48),  # 等宽字体，48号大小
                      fg="#00ff00",           # 绿色文字（像电子表！）
                      bg="#1a1a1a")           # 深色背景
time_label.pack()
```

> 🎨 **为什么用 Consolas 字体？** Consolas 是等宽字体，每个数字宽度一样，时间跳动时数字不会左右晃动，看起来更稳定、更像真正的电子表。当然，你也可以用 `"Microsoft YaHei"` 或 `"Arial"`。

### 知识点 4：after() —— 让时间"跳起来" 🔄

这是本节课**最核心**的知识点！如果只设置一次 `Label` 的文本，时间就停在那里不动了。我们需要每隔 1 秒重新获取一次时间，更新 `Label`。

`after()` 是 tkinter 提供的一个定时器方法：**"在 XXX 毫秒之后，执行某个函数"**。

```python
# 语法：root.after(毫秒数, 要调用的函数名)
root.after(1000, update_time)  # 1000毫秒 = 1秒后，调用 update_time 函数
```

巧妙的地方在于：**在 `update_time()` 函数内部再次调用 `after()`**，这样它就会不断地每隔 1 秒调用自己，形成一个"自己调用自己"的循环！

```python
def update_time():
    # ① 获取当前时间
    current = time.strftime("%H:%M:%S")
    # ② 更新 Label 的文字
    time_label.config(text=current)
    # ③ 1 秒后再次调用自己（形成循环！）
    root.after(1000, update_time)
```

> ⚠️ **注意**：`after()` 不会阻塞程序！它只是"预约"一个未来的任务，然后程序继续往下运行。这和 `time.sleep()` 完全不同——用 `sleep()` 会让整个窗口卡住！

## 完整代码

```python
import tkinter as tk
import time

# ========================================
# 第 19 节：项目1 —— 电子时钟（上）
# 知识点：time 模块、strftime、Label 显示、after() 定时刷新
# ========================================

# ---------- 创建窗口 ----------
root = tk.Tk()
root.title("电子时钟")
root.geometry("400x200")
root.configure(bg="#1a1a1a")  # 深色背景，像电子表

# ---------- 创建时间显示的 Label ----------
time_label = tk.Label(
    root,
    text="00:00:00",                # 初始显示
    font=("Consolas", 48, "bold"),  # 等宽大字体
    fg="#00ff00",                   # 亮绿色文字（电子表风格）
    bg="#1a1a1a"                    # 深色背景
)
time_label.pack(expand=True)        # expand=True 让它在窗口里居中

# ---------- 定义刷新时间的函数 ----------
def update_time():
    """获取当前时间并更新 Label，然后 1 秒后再次调用自己"""
    # ① 获取当前时间，格式化为 "时:分:秒"
    current_time = time.strftime("%H:%M:%S")
    
    # ② 更新 Label 显示的文字
    time_label.config(text=current_time)
    
    # ③ 1 秒（1000 毫秒）后，再次调用 update_time 函数
    #    这样就能形成一个持续的循环：每秒刷新一次！
    root.after(1000, update_time)

# ---------- 启动时钟 ----------
update_time()  # 第一次手动调用，之后 after() 会自动循环

# ---------- 启动窗口主循环 ----------
root.mainloop()
```

## 小贴士
- `after()` 的参数单位是**毫秒**，1000 毫秒 = 1 秒，不要写错
- `after()` 的第二个参数是**函数名**，不要加括号！`after(1000, update_time)` 正确，`after(1000, update_time())` 错误
- `time.strftime()` 的格式码是大小写敏感的：`%H` 和 `%h` 不一样，拿不准时查上面的表格
- 电子时钟的"跳动感"来自 `after()` 每隔 1 秒刷新一次，如果你把 1000 改成 100，它就会每秒刷新 10 次，像个秒表一样飞快
