## 知识点讲解

### 知识点 1：美化界面 —— 大字体 + 前景色/背景色

要让时钟好看，第一步就是**放大字体**！tkinter 的 `Label` 支持 `font` 参数来设置字体：

```python
# font 参数：('字体名', 字号, '样式')
time_label = tk.Label(root, font=("Consolas", 72, "bold"))
```

常用等宽字体（数字宽度一致，时钟显示整齐）：
- Windows：`"Consolas"`, `"Courier New"`
- macOS：`"Menlo"`, `"SF Mono"`, `"Consolas"`
- 跨平台安全选择：`"Consolas"`, `"Courier"`

同时可以用 `fg`（foreground，前景色/文字颜色）和 `bg`（background，背景色）来美化：

```python
time_label = tk.Label(root,
                      text="00:00:00",
                      font=("Consolas", 72, "bold"),
                      fg="#00FF00",      # 亮绿色文字
                      bg="#1a1a2e")      # 深色背景
```

**配色小技巧**：深色背景 + 亮色文字 = 满满的"科技感"，就像科幻电影里的时钟一样！

### 知识点 2：颜色切换按钮

接下来我们给时钟加一个功能：点击按钮，时钟的颜色会变。怎么实现呢？

**思路**：准备一个颜色列表，用一个变量记住当前是第几种颜色。每次点击按钮，变量 +1，取列表里下一个颜色，设置 Label 的 `fg`。

```python
# 颜色列表
colors = ["#00FF00", "#FF6B6B", "#4ECDC4", "#FFE66D"]
color_index = 0  # 当前颜色在列表中的位置

def change_color():
    global color_index
    color_index = (color_index + 1) % len(colors)  # 循环取下一个
    time_label.config(fg=colors[color_index])

cycle_btn = tk.Button(root, text="🎨 切换颜色", command=change_color)
```

**关键语法**：`color_index = (color_index + 1) % len(colors)`

这里用到了**取余（%）**运算，当 `color_index` 走到最后一个时，`+1` 再取余就会回到 0，实现循环！

| 当前 index | +1 | % 4 的结果 | 效果 |
|-----------|-----|-----------|------|
| 0 | 1 | 1 | 下一个颜色 |
| 1 | 2 | 2 | 下一个颜色 |
| 2 | 3 | 3 | 下一个颜色 |
| 3 | 4 | 0 | 回到第一个！ |

### 知识点 3：12/24 小时制切换

`time.strftime()` 里有两个不同的格式符号来表示小时：

| 格式符 | 含义 | 例子（下午 3 点） |
|--------|------|------------------|
| `%H` | 24 小时制 | `15` |
| `%I` | 12 小时制 | `03` |

所以我们要做的是：用一个变量存当前模式，每次 `update_time()` 时根据模式选不同的格式符。

用 `IntVar` 配合 `Checkbutton` 或一个普通 Button 来切换模式：

```python
is_24h = tk.IntVar(value=1)  # 1 = 24小时制，0 = 12小时制

def toggle_mode():
    """切换 12/24 小时制"""
    is_24h.set(1 - is_24h.get())  # 0 变 1，1 变 0

    # 更新按钮文字
    if is_24h.get():
        toggle_btn.config(text="24 小时制")
    else:
        toggle_btn.config(text="12 小时制")

def update_time():
    now = time.strftime("%H:%M:%S" if is_24h.get() else "%I:%M:%S")
    time_label.config(text=now)
    root.after(1000, update_time)
```

**IntVar 是什么？**
- `IntVar` 是 tkinter 中的一个"整数变量"，可以用 `.get()` 读值，`.set()` 改值
- 它的好处是：配合 Checkbutton 或 Radiobutton 可以自动绑定（本节课用 Button 手动改更灵活）

`1 - is_24h.get()` 这个小技巧很巧妙：当值是 1 时算出 0，是 0 时算出 1——完美切换！

### 知识点 4：显示日期

一个完整的电子时钟当然要有日期！做法很简单：再加一个 `Label`，用不同的格式符显示日期。

`time.strftime()` 的日期格式符：

| 格式符 | 含义 | 例子 |
|--------|------|------|
| `%Y` | 四位年份 | `2026` |
| `%m` | 两位月份 | `06` |
| `%d` | 两位日期 | `27` |
| `%A` | 星期（英文全名） | `Friday` |
| `%a` | 星期（英文缩写） | `Fri` |
| `%B` | 月份（英文全名） | `June` |

```python
date_str = time.strftime("%Y年%m月%d日 %A")
date_label.config(text=date_str)
```

把日期更新也放进 `update_time()` 函数里，这样日期和时钟一起每秒刷新（日期虽然一天才变一次，但一起刷新代码更简单）。

## 完整代码

```python
import tkinter as tk
import time

# ========================================
# 第 20 节：项目1 · 电子时钟（下）
# ========================================

root = tk.Tk()
root.title("电子时钟")
root.geometry("500x350")
root.configure(bg="#1a1a2e")  # 深色背景，科技感

# ---------- 颜色列表 ----------
colors = ["#00FF00", "#FF6B6B", "#4ECDC4", "#FFE66D"]
color_index = 0

# ---------- 时制模式（1=24小时，0=12小时）----------
is_24h = tk.IntVar(value=1)

# ---------- 时间 Label ----------
time_label = tk.Label(
    root,
    text="00:00:00",
    font=("Consolas", 72, "bold"),
    fg=colors[color_index],
    bg="#1a1a2e"
)
time_label.pack(pady=(40, 10))

# ---------- 日期 Label ----------
date_label = tk.Label(
    root,
    text="",
    font=("Microsoft YaHei", 16),
    fg="#8a8aaa",
    bg="#1a1a2e"
)
date_label.pack(pady=(0, 15))

# ---------- 时间更新函数 ----------
def update_time():
    """每秒更新时间和日期"""
    # 根据模式选择小时格式
    hour_format = "%H" if is_24h.get() else "%I"
    time_str = time.strftime(f"{hour_format}:%M:%S")
    time_label.config(text=time_str)

    # 更新日期
    date_str = time.strftime("%Y年%m月%d日 %A")
    date_label.config(text=date_str)

    root.after(1000, update_time)

# ---------- 切换颜色 ----------
def change_color():
    """循环切换到下一个颜色"""
    global color_index
    color_index = (color_index + 1) % len(colors)
    time_label.config(fg=colors[color_index])

cycle_btn = tk.Button(
    root,
    text="🎨 切换颜色",
    command=change_color,
    font=("Microsoft YaHei", 12),
    bg="#16213e",
    fg="#e0e0e0",
    activebackground="#0f3460",
    relief="flat",
    padx=20, pady=8,
    cursor="hand2"
)
cycle_btn.pack(pady=(5, 5))

# ---------- 切换 12/24 小时制 ----------
def toggle_mode():
    """切换 12/24 小时制"""
    is_24h.set(1 - is_24h.get())
    if is_24h.get():
        toggle_btn.config(text="当前：24 小时制")
    else:
        toggle_btn.config(text="当前：12 小时制")

toggle_btn = tk.Button(
    root,
    text="当前：24 小时制",
    command=toggle_mode,
    font=("Microsoft YaHei", 12),
    bg="#16213e",
    fg="#e0e0e0",
    activebackground="#0f3460",
    relief="flat",
    padx=20, pady=8,
    cursor="hand2"
)
toggle_btn.pack(pady=(5, 10))

# ---------- 启动 ----------
update_time()
root.mainloop()
```

## 小贴士
- `after(1000, update_time)` 的 1000 单位是**毫秒**，1000 毫秒 = 1 秒。改成 500 就是半秒刷新一次（看起来更流畅但更吃资源）
- `%I` 显示的是 12 小时制，会显示 `01~12`（半夜 12 点显示 12，中午 12 点也显示 12）。如果需要区分上午/下午，可以加 `%p`（显示 AM/PM）
- `config()` 方法可以修改控件已有的属性，比重新创建控件高效得多
- 颜色用十六进制表示最灵活，网上搜"color picker"就能找到取色工具
