## 知识点回顾：你学到了什么？

让我们来盘点一下，这 48 节课你掌握了哪些技能！

### 基础控件

| 控件 | 你会用它做什么？ |
|------|------------------|
| `Label` | 显示文字、标题、提示信息 |
| `Button` | 点击触发动作 |
| `Entry` | 单行文字输入（名字、密码等） |
| `Text` | 多行文字输入和显示 |
| `Checkbutton` | 多选选项 |
| `Radiobutton` | 单选选项 |
| `Listbox` | 列表显示、排行榜 |
| `Combobox` | 下拉选择框 |
| `Scale` | 滑动条调节数值 |
| `Spinbox` | 数字增减选择 |
| `Canvas` | 画图、动画 |
| `Treeview` | 表格数据展示 |

### 布局管理

| 技能 | 说明 |
|------|------|
| `pack()` | 上下堆叠布局 |
| `grid()` | 行列网格布局 |
| `Frame` | 容器，分组管理控件 |

### 事件与交互

| 技能 | 说明 |
|------|------|
| `command=` | 按钮点击回调 |
| `.bind("<事件>", func)` | 键盘、鼠标事件绑定 |
| `after(ms, func)` | 定时器、动画循环 |

### 弹窗与对话框

| 技能 | 说明 |
|------|------|
| `messagebox` | 信息提示、确认弹窗、警告 |
| `filedialog` | 打开文件、保存文件对话框 |
| `Toplevel` | 创建子窗口 |

### 数据与文件

| 技能 | 说明 |
|------|------|
| `json` | 数据保存和加载 |
| `csv` | 表格数据导入导出 |
| `random` | 随机选择、抽签 |
| `datetime` | 时间日期处理 |

### 进阶技能

| 技能 | 说明 |
|------|------|
| `ttk.Style` | 主题美化、自定义样式 |
| `tag_config` | Text 控件文字着色 |
| `StringVar` / `IntVar` | 控件变量绑定 |

## 创作方向推荐

### 🎮 方向 1：小游戏
- **猜数字**：程序随机一个数，用户猜，给出"大了/小了"提示
- **石头剪刀布**：和电脑对战，统计胜负
- **反应速度测试**：屏幕变色后最快点击
- **记忆翻牌**：Canvas 画格子，翻牌配对

### 🛠️ 方向 2：实用工具
- **个人日记本**：写日记、保存、查看历史
- **课程表**：Treeview 显示一周课程
- **倒计时器**：设定目标日期，显示还剩多少天
- **单位换算器**：厘米/英寸、摄氏度/华氏度等转换

### 🎨 方向 3：创意作品
- **电子画板**：Canvas 上自由画画，可选颜色和笔刷大小
- **心情日记**：选 emoji + 写一句话，保存当天心情
- **抽签/点名器**：输入名单，随机抽取
- **电子宠物**：一个简单的养成游戏

### 📚 方向 4：学习工具
- **单词本**：添加单词和释义，随机测试
- **口算练习**：随机出题，计时答题，统计分数
- **知识问答**：题库问答，计分排名

## 创作步骤

1. **选题**：从上面推荐的方向中选一个，或者自己想一个
2. **设计**：画一个草图——窗口里放什么控件？怎么布局？
3. **编码**：一步步实现功能，先做出基本版，再逐步完善
4. **美化**：调调颜色、字体，让作品更好看
5. **展示**：给大家演示你的作品，说说你的创意

## 作品展示环节

展示时可以说说：
- 你的作品叫什么名字？
- 它有什么功能？
- 你用了哪些学过的控件？
- 最让你骄傲的地方是什么？
- 遇到了什么困难？怎么解决的？

## 小贴士
- **从简单开始**：先做一个能跑的基本版，再慢慢加功能
- **不必完美**：有 bug 很正常，这正是学习的过程
- **参考之前代码**：前面 47 节课的代码都是你的"武器库"
- **善用搜索**：遇到不会的，搜索"tkinter 如何 xxx"
- **享受创作**：这是你展示自己的舞台，做出你喜欢的东西就好！
