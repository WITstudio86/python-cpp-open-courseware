## 知识点讲解

### 知识点 1：Listbox 列表控件

`Listbox` 是一个可以显示多条数据的列表控件，用户可以点击选中某一项。

```python
# 创建 Listbox
listbox = tk.Listbox(root, width=40, height=10)
listbox.pack()
```

Listbox 常用方法：

| 方法 | 作用 | 例子 |
|------|------|------|
| `.insert(tk.END, "内容")` | 添加到末尾 | `listbox.insert(tk.END, "写作业")` |
| `.delete(tk.ANCHOR)` | 删除选中项 | `listbox.delete(tk.ANCHOR)` |
| `.get(0, tk.END)` | 获取所有项 | `listbox.get(0, tk.END)` |
| `.curselection()` | 获取选中项索引 | `listbox.curselection()` |
| `.delete(0, tk.END)` | 清空全部 | `listbox.delete(0, tk.END)` |

### 知识点 2：添加任务

从 Entry 获取用户输入，验证不为空后插入 Listbox，再清空输入框。

```python
def add_task():
    task = entry.get().strip()       # 获取输入，去掉首尾空格
    if task == "":                    # 不能添加空白
        return
    listbox.insert(tk.END, task)      # 添加到列表末尾
    entry.delete(0, tk.END)            # 清空输入框
```

**重点讲解**：
- `.strip()` 去掉首尾空格，防止用户只输入空格
- 空字符串检查：`if task == ""` 是简化写法，也可以用 `if not task`
- `tk.END` 是一个特殊常量，表示"末尾"
- 添加完后清空 Entry，方便继续输入下一个任务

### 知识点 3：删除任务

使用 `curselection()` 获取用户选中的那一项，然后用 `delete()` 删掉它。

```python
def delete_task():
    selected = listbox.curselection()  # 获取选中项的索引（返回元组）
    if selected:                        # 如果有选中项
        listbox.delete(selected[0])     # 删除第一个选中的项（用索引[0]）
```

**重点讲解**：
- `curselection()` 返回的是**元组**，例如 `(2,)`，需要 `[0]` 取出第一个元素
- 如果什么也没选，返回空元组 `()`，直接 `delete()` 会报错，所以必须先 `if selected:` 判断
- 另一种写法：`listbox.delete(tk.ANCHOR)`，可以直接删除选中的那一项（更简洁但灵活度稍低）

### 知识点 4：防止重复添加

在添加之前，先用 `listbox.get(0, tk.END)` 获取所有已有任务，检查是否已存在。

```python
def add_task():
    task = entry.get().strip()
    if not task:
        return

    # 获取 Listbox 中所有已有任务
    all_tasks = listbox.get(0, tk.END)
    if task in all_tasks:
        result_label.config(text="⚠️ 这个任务已经存在！")
        return

    listbox.insert(tk.END, task)
    entry.delete(0, tk.END)
    result_label.config(text="✅ 任务已添加！")
```

**重点讲解**：
- `listbox.get(0, tk.END)` 获取从第 0 项到末尾的所有内容，返回一个元组
- `task in all_tasks` 用 `in` 运算符检查任务是否已在列表中
- 用一个小 Label 给用户反馈："已存在" 或 "已添加"
- 如果重复，`return` 直接退出函数，不执行后面的添加操作

## 完整代码

```python
import tkinter as tk

# ========================================
# 第 25 节：项目4 — 待办事项清单（上）
# 知识点：Listbox · Entry · 添加 · 删除 · 防重复
# ========================================

root = tk.Tk()
root.title("待办事项清单")
root.geometry("450x450")
root.configure(bg="#f0f4f8")  # 浅蓝灰背景

# ---------- 标题 ----------
title_label = tk.Label(root, text="📋 我的待办事项",
                       font=("Microsoft YaHei", 20, "bold"),
                       bg="#f0f4f8", fg="#2c3e50")
title_label.pack(pady=15)

# ---------- 输入区域 ----------
input_frame = tk.Frame(root, bg="#f0f4f8")
input_frame.pack(pady=10)

entry = tk.Entry(input_frame, width=35,
                 font=("Microsoft YaHei", 13))
entry.pack(side=tk.LEFT, padx=(0, 8))
entry.focus_set()  # 自动获得焦点，打开就能打字

def add_task():
    """添加新任务（含重复检查）"""
    task = entry.get().strip()           # 获取输入，去掉首尾空格
    if not task:                          # 空内容不添加
        return

    # 检查是否重复
    all_tasks = listbox.get(0, tk.END)     # 获取列表中的所有任务
    if task in all_tasks:
        result_label.config(text="⚠️ 这个任务已经存在！", fg="#e74c3c")
        return

    listbox.insert(tk.END, task)           # 添加到列表末尾
    entry.delete(0, tk.END)                # 清空输入框
    result_label.config(text="✅ 任务已添加！", fg="#27ae60")

add_btn = tk.Button(input_frame, text="➕ 添加",
                    command=add_task,
                    font=("Microsoft YaHei", 12, "bold"),
                    bg="#3498db", fg="white",
                    activebackground="#2980b9",
                    relief="flat", padx=18, pady=6,
                    cursor="hand2")
add_btn.pack(side=tk.LEFT)

# 按回车键也能添加
root.bind("<Return>", lambda event: add_task())

# ---------- 删除按钮 ----------
def delete_task():
    """删除选中的任务"""
    selected = listbox.curselection()      # 获取选中项的索引元组
    if selected:                            # 如果有选中项
        listbox.delete(selected[0])          # 删除第一个选中的项
        result_label.config(text="🗑️ 任务已删除", fg="#7f8c8d")

delete_btn = tk.Button(root, text="🗑 删除",
                       command=delete_task,
                       font=("Microsoft YaHei", 12, "bold"),
                       bg="#e74c3c", fg="white",
                       activebackground="#c0392b",
                       relief="flat", padx=18, pady=6,
                       cursor="hand2")
delete_btn.pack(pady=(0, 10))

# ---------- 任务列表 ----------
listbox = tk.Listbox(root,
                     width=40, height=12,
                     font=("Microsoft YaHei", 13),
                     bg="#ffffff", fg="#2c3e50",
                     selectbackground="#aed6f1",   # 选中项背景：浅蓝
                     selectforeground="#2c3e50")    # 选中项文字
listbox.pack(pady=5)

# ---------- 状态提示 ----------
result_label = tk.Label(root, text="",
                        font=("Microsoft YaHei", 11),
                        bg="#f0f4f8", fg="#7f8c8d")
result_label.pack(pady=5)

root.mainloop()
```

## 小贴士
- `listbox.curselection()` 返回的是**元组**，要用 `[0]` 取出第一个索引
- `END` 表示列表末尾，`ANCHOR` 表示选中项
- 字符串 `.strip()` 可以去掉首尾空格
- `listbox.get(0, tk.END)` 获取所有项，返回的是一个元组
- 删除前先判断是否选中，避免空删导致闪退
- `entry.focus_set()` 让输入框自动获得焦点，打开程序就能直接打字
