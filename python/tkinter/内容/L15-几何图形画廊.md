## 知识点讲解

### 知识点 1：Canvas 坐标系统

Canvas（画布）是 tkinter 的**绘图控件**。它有一个自己的坐标系统：

```
  (0,0) ──────────────────── X 轴（向右增加）
    │
    │     (50, 50)
    │        ●
    │
    │                   (350, 250)
    │                       ●
    Y 轴（向下增加）
```

**关键规则：**
- 原点 `(0, 0)` 在画布的**左上角**
- X 坐标**向右**增大（和数学一样）
- Y 坐标**向下**增大（和数学相反！）

```python
import tkinter as tk

root = tk.Tk()
root.title("Canvas 坐标演示")

# 创建画布：宽 500，高 400，白色背景
canvas = tk.Canvas(root, width=500, height=400, bg="white")
canvas.pack()

# 在坐标 (250, 200) 处画一个红色圆点
canvas.create_oval(245, 195, 255, 205, fill="red")

root.mainloop()
```

### 知识点 2：create_line —— 画直线

```python
# 画一条从 (x1, y1) 到 (x2, y2) 的直线
canvas.create_line(x1, y1, x2, y2, 参数...)
```

**示例：**
```python
import tkinter as tk

root = tk.Tk()
root.title("画直线")

canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

# 一条普通直线
canvas.create_line(50, 50, 350, 50)

# 红色加粗的斜线
canvas.create_line(50, 80, 350, 250, fill="red", width=4)

# 虚线
canvas.create_line(50, 150, 350, 150, fill="blue", width=2, dash=(5, 3))

root.mainloop()
```

**常用参数：**

| 参数 | 含义 | 示例 |
|------|------|------|
| `fill` | 线条颜色 | `fill="red"` |
| `width` | 线条粗细（像素） | `width=3` |
| `dash` | 虚线样式 | `dash=(5, 3)` 表示 5px 实线 + 3px 空白 |

### 知识点 3：create_rectangle —— 画矩形

```python
# 需要两个对角点的坐标：左上角 (x1, y1) 和 右下角 (x2, y2)
canvas.create_rectangle(x1, y1, x2, y2, 参数...)
```

**示例：**
```python
import tkinter as tk

root = tk.Tk()
root.title("画矩形")

canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

# 只有边框的矩形（不填充）
canvas.create_rectangle(50, 50, 200, 150, outline="blue", width=3)

# 有填充色的矩形
canvas.create_rectangle(250, 50, 350, 150, fill="orange", outline="red", width=2)

root.mainloop()
```

**常用参数：**

| 参数 | 含义 | 示例 |
|------|------|------|
| `fill` | 填充颜色 | `fill="yellow"` |
| `outline` | 边框颜色 | `outline="black"` |
| `width` | 边框粗细 | `width=2` |

### 知识点 4：create_oval —— 画椭圆 / 圆形

```python
# 和矩形一样，也是用左上角和右下角来定义一个"包围盒子"
# 椭圆就画在这个盒子里
canvas.create_oval(x1, y1, x2, y2, 参数...)
```

**画圆形的技巧：** 让包围盒子是正方形，画出来的就是**正圆**！

```python
import tkinter as tk

root = tk.Tk()
root.title("画椭圆和圆")

canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

# 椭圆（包围盒子是长方形）
canvas.create_oval(30, 30, 180, 120, fill="lightblue", outline="blue", width=2)

# 正圆（包围盒子是正方形 → 宽 = 高）
# 左上角 (250, 30)，右下角 (350, 130) → 宽 100，高 100 → 正方形 → 正圆！
canvas.create_oval(250, 30, 350, 130, fill="pink", outline="red", width=2)

root.mainloop()
```

**规律总结：**

| 形状 | 条件 |
|------|------|
| 椭圆 | 包围盒子的**宽 != 高** |
| 正圆 | 包围盒子的**宽 == 高** |

### 知识点 5：create_polygon —— 画多边形

```python
# 给出多边形的所有顶点坐标，依次连接
canvas.create_polygon(x1, y1, x2, y2, x3, y3, ..., 参数...)
```

**示例 —— 画三角形：**
```python
import tkinter as tk

root = tk.Tk()
root.title("画三角形")

canvas = tk.Canvas(root, width=400, height=300, bg="white")
canvas.pack()

# 三角形：三个顶点按顺序连接
canvas.create_polygon(200, 50,    # 顶点 1（上）
                      50, 200,    # 顶点 2（左下）
                      350, 200,   # 顶点 3（右下）
                      fill="yellow", outline="green", width=3)

root.mainloop()
```

**多边形的顶点是自动闭合的**——最后一个点会自动连回第一个点。

### 知识点 6：create_text —— 在画布上写字

```python
canvas.create_text(x, y, text="文字内容", 参数...)
```

**示例：**
```python
import tkinter as tk

root = tk.Tk()
root.title("画布上的文字")

canvas = tk.Canvas(root, width=400, height=200, bg="white")
canvas.pack()

# 在画布中央显示标题
canvas.create_text(200, 50, text="🖼️ 几何图形画廊",
                   font=("微软雅黑", 24, "bold"), fill="darkblue")

# 显示作者署名
canvas.create_text(200, 150, text="—— 用 Python 代码画画",
                   font=("微软雅黑", 14), fill="gray")

root.mainloop()
```

## 完整代码

```python
import tkinter as tk

# ========================================
# 第 15 节：几何图形画廊
# ========================================

# 创建主窗口
root = tk.Tk()
root.title("几何图形画廊")
root.geometry("550x500")

# 创建画布：宽 500，高 400，白色背景
canvas = tk.Canvas(root, width=500, height=400, bg="white")
canvas.pack(pady=20)

# ---------- 1. 标题文字 ----------
canvas.create_text(250, 25, text="🎨 几何图形画廊",
                   font=("微软雅黑", 22, "bold"), fill="darkblue")

# ---------- 2. 画直线 ----------
# 从 (30, 70) 到 (470, 70) 的水平线
canvas.create_line(30, 60, 470, 60, fill="gray", width=1, dash=(3, 5))
# 橘色斜线（加粗）
canvas.create_line(30, 60, 250, 180, fill="orange", width=4)
# 标签
canvas.create_text(50, 80, text="📏 直线",
                   font=("微软雅黑", 10), fill="gray", anchor="w")

# ---------- 3. 画矩形 ----------
canvas.create_rectangle(30, 100, 130, 200,  # 左上角 → 右下角
                        fill="lightblue", outline="darkblue", width=2)
canvas.create_text(80, 220, text="矩形",
                   font=("微软雅黑", 10), fill="gray")

# ---------- 4. 画椭圆 ----------
# 包围盒子：左上角 (170, 100)，右下角 (300, 200)
canvas.create_oval(170, 100, 300, 200,
                   fill="lightgreen", outline="darkgreen", width=2)
canvas.create_text(235, 220, text="椭圆",
                   font=("微软雅黑", 10), fill="gray")

# ---------- 5. 画圆形（正圆） ----------
# 包围盒子是正方形（宽 == 高 = 80）
canvas.create_oval(340, 110, 420, 190,
                   fill="pink", outline="red", width=3)
canvas.create_text(380, 220, text="圆形",
                   font=("微软雅黑", 10), fill="gray")

# ---------- 6. 画三角形（多边形） ----------
# 三个顶点：顶部、左下、右下
canvas.create_polygon(230, 280,   # 顶
                      80, 380,    # 左下
                      380, 380,   # 右下
                      fill="yellow", outline="orange", width=3)
canvas.create_text(230, 400, text="三角形（多边形）",
                   font=("微软雅黑", 10), fill="gray")

# ---------- 7. 画出坐标点标注 ----------
# 在几个关键位置画小圆点，帮助理解坐标
canvas.create_oval(26, 56, 34, 64, fill="red")       # (30, 60)
canvas.create_text(45, 55, text="(30, 60)",
                   font=("微软雅黑", 8), fill="red", anchor="w")

canvas.create_oval(246, 176, 254, 184, fill="red")   # (250, 180)
canvas.create_text(260, 175, text="(250, 180)",
                   font=("微软雅黑", 8), fill="red", anchor="w")

# ---------- 8. 底部说明 ----------
canvas.create_text(250, 390, text="💡 Canvas 坐标原点在左上角，X 向右增大，Y 向下增大",
                   font=("微软雅黑", 10), fill="#888888")

# 启动主循环
root.mainloop()
```

## 小贴士
- Canvas 坐标系的原点 `(0, 0)` 在左上角，**Y 轴是向下的**，这和数学课本里的坐标系不一样，要特别注意！
- 画椭圆和圆形都用 `create_oval`，区别在于包围盒子是长方形还是正方形
- `fill` 是填充色，`outline` 是边框色，两者可以同时设置
- 多边形的顶点坐标要**按顺序**写，Canvas 会依次连接它们并自动闭合
- Canvas 还有很多高级功能：画弧线（`create_arc`）、加载图片（`create_image`）、响应鼠标点击等，后面会学到
