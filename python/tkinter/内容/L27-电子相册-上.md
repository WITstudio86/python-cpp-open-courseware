## 知识点讲解

### 为什么要学图片处理？
前面几节课我们一直在跟文字打交道 —— 标签、按钮、输入框、列表…… 但一个好的程序也需要「看得见」！这节课开始，我们来学怎么在 tkinter 窗口中显示图片。

### 知识点 1：安装 Pillow 库

tkinter 本身只能显示少数几种格式的图片（比如 GIF），功能很有限。我们需要一个强大的帮手 —— **Pillow**。

Pillow 是 Python 最流行的图片处理库，原名 PIL（Python Imaging Library），后来改叫 Pillow。

**安装方法**：

打开终端（命令行），输入：

```bash
pip install Pillow
```

如果用的是 Mac / Linux，可能需要：

```bash
pip3 install Pillow
```

安装完成后，我们来验证一下：

```python
from PIL import Image, ImageTk
print("Pillow 安装成功！")
```

如果不报错，就说明安装好了！

### 知识点 2：加载图片 —— Image.open()

```python
from PIL import Image, ImageTk

# 加载一张图片
img = Image.open("photo.jpg")  # 替换成你的图片路径
```

`Image.open()` 返回一个 Image 对象，里面包含了图片的所有信息（宽、高、颜色等）。

**但是！** 这个 Image 对象不能直接放到 tkinter 窗口里。tkinter 不认识 PIL 的 Image 格式。我们需要「翻译」一下。

### 知识点 3：转换为 tkinter 格式 —— ImageTk.PhotoImage

```python
from PIL import Image, ImageTk

img = Image.open("photo.jpg")
tk_img = ImageTk.PhotoImage(img)  # 转换成 tkinter 能识别的格式
```

`ImageTk.PhotoImage()` 把 PIL 的 Image 对象「翻译」成了 tkinter 能用的图片对象。现在就可以放到 Label 里了！

### 知识点 4：用 Label 显示图片

还记得 Label 吗？它不仅能显示文字，还能显示图片！

```python
label = tk.Label(root, image=tk_img)
label.pack()
```

**重要提醒**：必须把 PhotoImage 对象保存在一个变量里（比如 `label.image = tk_img`），否则图片会被垃圾回收机制清除，导致不显示！

```python
label = tk.Label(root, image=tk_img)
label.image = tk_img  # 保存引用，防止被回收！
label.pack()
```

### 知识点 5：缩放图片 —— resize()

图片太大怎么办？用 `resize()` 缩小它！

```python
img = Image.open("photo.jpg")
img = img.resize((400, 300))  # 缩放到 400x300 像素
# 注意：resize 的参数是一个元组 (宽, 高)
```

更好的做法 —— 按比例缩放，保留原图的宽高比：

```python
def resize_image(img, max_width, max_height):
    """等比例缩放图片，不超过最大宽高"""
    w, h = img.size  # 获取原图宽高
    ratio = min(max_width / w, max_height / h)  # 计算缩放比例
    new_w = int(w * ratio)
    new_h = int(h * ratio)
    return img.resize((new_w, new_h))
```

### 知识点 6：不依赖真实文件 —— 生成占位图片

如果手头没有图片文件，或者想让程序在任何电脑上都能运行，我们可以用 Pillow 自己生成一张纯色图片：

```python
from PIL import Image, ImageTk, ImageDraw

# 创建一张 400x300 的蓝色图片
img = Image.new("RGB", (400, 300), color="#4A90D9")

# 在图片上画一些装饰
draw = ImageDraw.Draw(img)
draw.rectangle([50, 50, 350, 250], outline="white", width=3)
draw.text((120, 130), "📷 我的相册", fill="white")

tk_img = ImageTk.PhotoImage(img)
```

## 完整代码

```python
import tkinter as tk
from PIL import Image, ImageTk, ImageDraw

# ========================================
# 第 27 节：项目 5 — 电子相册（上）
# ========================================

root = tk.Tk()
root.title("电子相册 📸")
root.geometry("550x500")
root.configure(bg="#2c2c2c")  # 深色背景，像相册的底色

# --- 生成一张占位图片（不依赖真实文件）---
img = Image.new("RGB", (450, 300), color="#4A90D9")
draw = ImageDraw.Draw(img)
# 画一个白色边框
draw.rectangle([5, 5, 444, 294], outline="white", width=2)
# 画装饰线
draw.line([(50, 80), (400, 80)], fill="white", width=1)
draw.line([(50, 220), (400, 220)], fill="white", width=1)
# 写文字
draw.text((120, 120), "📷 我的电子相册", fill="white")
draw.text((145, 160), "第 1 张", fill="#DDDDDD")

# 转换成 tkinter 格式
tk_img = ImageTk.PhotoImage(img)

# 用 Label 显示图片
img_label = tk.Label(root, image=tk_img, bg="#2c2c2c")
img_label.image = tk_img  # 保存引用！
img_label.pack(pady=30)

# 标题
title_label = tk.Label(root, text="我的电子相册",
                       font=("微软雅黑", 20, "bold"),
                       fg="white", bg="#2c2c2c")
title_label.pack(pady=10)

root.mainloop()
```

## 小贴士
- 🖼️ `label.image = tk_img` 这一行非常重要！忘记写的话图片不会显示。
- 📏 `resize()` 的参数是 `(宽, 高)`，别搞反了。
- 🎨 这节课我们用了占位图片，好处是代码可以在任何电脑上运行，不用找图片文件。
- 📦 确认 Pillow 已安装：在终端输入 `pip list | grep Pillow`，能看到版本号就对了。
