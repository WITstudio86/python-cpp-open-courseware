# 第 11 节 · 愿望清单管理器

## 学习目标
- 学会使用 `Entry` 输入框来接收用户输入
- 学会使用 `Listbox` 列表框来展示和管理数据列表
- 学会使用 `insert()` 添加列表项、`delete()` 删除列表项
- 学会使用 `curselection()` 获取当前选中的项
- 学会使用 `Scrollbar` 滚动条配合 Listbox 使用

## 本节课成品
一个愿望清单管理器：输入愿望后点击添加，选中愿望后可以删除，列表太长时自动出现滚动条！

## 知识点讲解

### 知识点 1：Entry 输入框

`Entry` 是单行文本输入框，用户可以在里面输入文字。

```python
# 创建输入框
entry = tk.Entry(root, width=30, font=("Microsoft YaHei", 12))
entry.pack(pady=10)

# 获取输入框中的文字
text = entry.get()

# 清空输入框
entry.delete(0, tk.END)

# 插入默认文字
entry.insert(0, "请输入...")
```

| 方法 | 作用 | 例子 |
|------|------|------|
| `.get()` | 获取输入框中的文字 | `entry.get()` |
| `.delete(0, tk.END)` | 清空输入框 | `entry.delete(0, tk.END)` |
| `.insert(0, "文字")` | 在开头插入文字 | `entry.insert(0, "你好")` |

### 知识点 2：Listbox 列表框

`Listbox` 是一个可以显示多条数据的列表控件，用户可以点击选中某一项。

```python
# 创建 Listbox
listbox = tk.Listbox(root, width=40, height=10, font=("Microsoft YaHei", 12))
listbox.pack(pady=10)

# 添加项目（添加到末尾）
listbox.insert(tk.END, "要添加的内容")

# 删除项目（删除指定索引的项）
listbox.delete(index)

# 获取当前选中的项的索引
selected = listbox.curselection()
```

| 方法 | 作用 | 例子 |
|------|------|------|
| `.insert(tk.END, item)` | 在末尾添加一项 | `listbox.insert(tk.END, "学 Python")` |
| `.delete(index)` | 删除指定索引的项 | `listbox.delete(0)` |
| `.curselection()` | 获取选中项的索引元组 | `listbox.curselection()[0]` |
| `.size()` | 获取列表项总数 | `listbox.size()` |

**重要：** `curselection()` 返回的是一个**元组**，即使只选了一项，也要用 `[0]` 取第一个元素。

### 知识点 3：Scrollbar 滚动条

当 Listbox 中的内容太多、超出可视区域时，需要配合 `Scrollbar` 使用。

```python
# 创建滚动条
scrollbar = tk.Scrollbar(root)
scrollbar.pack(side=tk.RIGHT, fill=tk.Y)

# 创建 Listbox，并与滚动条关联
listbox = tk.Listbox(root, yscrollcommand=scrollbar.set)
listbox.pack(side=tk.LEFT, fill=tk.BOTH, expand=True)

# 滚动条也与 Listbox 关联
scrollbar.config(command=listbox.yview)
```

双向绑定是关键：
- `listbox` 的 `yscrollcommand` → `scrollbar.set`：Listbox 告诉滚动条"内容有多少"
- `scrollbar` 的 `command` → `listbox.yview`：滚动条拖动时告诉 Listbox"显示哪里"

## 完整代码

```python
import tkinter as tk

# ========================================
# 第 11 节：愿望清单管理器
# ========================================

root = tk.Tk()
root.title("愿望清单管理器")
root.geometry("450x400")
root.configure(bg="#fff8e1")  # 暖黄色背景

# ---------- 标题 ----------
title_label = tk.Label(root, text="🌟 我的愿望清单",
                       font=("Microsoft YaHei", 18, "bold"),
                       bg="#fff8e1", fg="#e65100")
title_label.pack(pady=(15, 5))

# ---------- 输入区域 ----------
input_frame = tk.Frame(root, bg="#fff8e1")
input_frame.pack(pady=10)

entry = tk.Entry(input_frame, width=30,
                 font=("Microsoft YaHei", 12))
entry.pack(side=tk.LEFT, padx=(0, 8))
entry.focus_set()  # 让输入框自动获得焦点

def add_wish():
    """添加愿望到列表"""
    text = entry.get().strip()      # 获取输入并去掉首尾空格
    if text:                         # 如果不为空
        listbox.insert(tk.END, text) # 添加到 Listbox 末尾
        entry.delete(0, tk.END)      # 清空输入框
    else:
        # 输入为空时不做任何操作
        pass

add_btn = tk.Button(input_frame, text="➕ 添加",
                    command=add_wish,
                    font=("Microsoft YaHei", 11, "bold"),
                    bg="#ff9800", fg="white",
                    activebackground="#f57c00",
                    relief="flat", padx=15, pady=4,
                    cursor="hand2")
add_btn.pack(side=tk.LEFT)

# 按回车键也能添加
root.bind("<Return>", lambda event: add_wish())

# ---------- 列表区域（Listbox + Scrollbar） ----------
list_frame = tk.Frame(root, bg="#fff8e1")
list_frame.pack(pady=10, fill=tk.BOTH, expand=True, padx=30)

# 创建滚动条
scrollbar = tk.Scrollbar(list_frame)
scrollbar.pack(side=tk.RIGHT, fill=tk.Y)

# 创建 Listbox，并与滚动条绑定
listbox = tk.Listbox(list_frame,
                     width=35, height=10,
                     font=("Microsoft YaHei", 12),
                     bg="#ffffff", fg="#333333",
                     selectbackground="#ffcc80",  # 选中项的背景色
                     selectforeground="#333333",  # 选中项的文字色
                     yscrollcommand=scrollbar.set)
listbox.pack(side=tk.LEFT, fill=tk.BOTH, expand=True)

# 滚动条与 Listbox 关联（双向绑定）
scrollbar.config(command=listbox.yview)

# ---------- 删除按钮 ----------
def delete_wish():
    """删除选中的愿望"""
    selected = listbox.curselection()  # 获取选中项的索引元组
    if selected:                        # 如果有选中的项
        listbox.delete(selected[0])     # 删除第一个选中的项

delete_btn = tk.Button(root, text="🗑️ 删除选中",
                       command=delete_wish,
                       font=("Microsoft YaHei", 11, "bold"),
                       bg="#f44336", fg="white",
                       activebackground="#d32f2f",
                       relief="flat", padx=15, pady=6,
                       cursor="hand2")
delete_btn.pack(pady=(0, 15))

root.mainloop()
```

## 小贴士
- `curselection()` 返回的是**元组**，用 `selected[0]` 取出第一个元素
- Listbox 和 Scrollbar 需要**双向绑定**才能正常工作
- 用 `.strip()` 去掉输入的首尾空格，避免添加空内容
- 按回车键也能添加，用 `root.bind("<Return>", ...)` 实现
- `focus_set()` 让输入框自动获得焦点，打开程序就能直接打字
