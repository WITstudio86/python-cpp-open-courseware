## 本节课成品 + 上一节衔接
上一节做出来的猜数字游戏已经可以玩起来了：输入数字、点"猜！"按钮、看到"大了"或"小了"的提示。但这节要让它更好玩——记录你猜了几次，看能不能破纪录！

这一节课加上去的是：
- 一个"已猜次数"计数器，每次猜数字就 +1
- 一个"最佳纪录"排行榜，猜对时自动更新最低步数
- 一个"重新开始"按钮，点一下就重置所有状态，开始新的一局

## 知识点讲解

### 知识点 1：猜测次数计数器

一个"全局变量" `count` = 0，每次调用 `guess()` 时 `count += 1`，然后更新 Label 显示。

```python
count = 0  # 全局变量，记录已经猜了多少次

def guess():
    global count          # 告诉 Python：我要修改外面的 count
    count += 1            # 次数 +1
    count_label.config(text=f"已猜次数: {count}")
    # 接着是比对 secret 的逻辑……
```

### 知识点 2：最低步数排行榜

用一个变量 `best_score` 保存"最好的成绩"。初始值设一个大数（比如 999），这样第一次猜对就能打破纪录。

```python
best_score = 999  # 初始化最佳成绩为一个很大的数

def guess():
    global count, best_score
    # ……（拿到用户输入，和 secret 比较）……
    if guess_num == secret:            # 如果猜对了
        if count < best_score:         # 看看是不是比之前更少
            best_score = count         # 是的话，更新纪录
            best_label.config(text=f"🏆 最佳纪录: {best_score} 步")
        result_label.config(text=f"恭喜你猜对了！用了 {count} 次")
```

### 知识点 3：重新开始按钮

`reset()` 函数的作用是"把一切恢复成刚打开程序的样子"——生成新的随机数、计数器归零、清空输入框和提示文字。

```python
def reset():
    global secret, count
    secret = random.randint(1, 100)    # 重新生成一个 1~100 的随机数
    count = 0                          # 次数归零
    count_label.config(text="已猜次数: 0")
    result_label.config(text="新游戏开始！请输入你的猜测")
    entry.delete(0, tk.END)            # 清空输入框
```

> **小提醒**：`reset()` 不需要动 `best_score`——最佳纪录应该保留下来，让小朋友一直挑战！

## 完整代码

下面是带计数器、排行榜和重新开始按钮的完整猜数字游戏：

```python
import tkinter as tk
import random

# ========== 全局变量 ==========
secret = random.randint(1, 100)
count = 0
best_score = 999  # 很大，保证第一次猜对就能成为最佳纪录

# ========== 窗口设置 ==========
root = tk.Tk()
root.title("猜数字游戏 2.0")
root.geometry("450x400")
root.configure(bg="#f0f7ff")

# ========== 标题 ==========
title_label = tk.Label(
    root, text="🎯 猜数字游戏",
    font=("Microsoft YaHei", 22, "bold"),
    bg="#f0f7ff", fg="#1a237e"
)
title_label.pack(pady=15)

# ========== 提示标签 ==========
result_label = tk.Label(
    root, text="我想了一个 1~100 之间的数字，猜猜看！",
    font=("Microsoft YaHei", 13),
    bg="#f0f7ff", fg="#333333",
    wraplength=380
)
result_label.pack(pady=5)

# ========== 计数显示 ==========
count_label = tk.Label(
    root, text="已猜次数: 0",
    font=("Microsoft YaHei", 13),
    bg="#f0f7ff", fg="#555555"
)
count_label.pack(pady=5)

# ========== 最佳纪录显示 ==========
best_label = tk.Label(
    root, text="🏆 最佳纪录: ---",
    font=("Microsoft YaHei", 13, "bold"),
    bg="#f0f7ff", fg="#e65100"
)
best_label.pack(pady=5)

# ========== 输入框 ==========
entry = tk.Entry(
    root,
    font=("Microsoft YaHei", 16),
    justify="center",
    width=10
)
entry.pack(pady=10)

# ========== 猜测函数 ==========
def guess():
    global count, best_score

    user_input = entry.get()
    if user_input == "":
        result_label.config(text="请输入一个数字！")
        return

    try:
        guess_num = int(user_input)
    except ValueError:
        result_label.config(text="请输入有效的整数！")
        return

    count += 1
    count_label.config(text=f"已猜次数: {count}")

    if guess_num < secret:
        result_label.config(text=f"{guess_num} 太小了，再大一点！")
    elif guess_num > secret:
        result_label.config(text=f"{guess_num} 太大了，再小一点！")
    else:
        # 猜对了！
        result_label.config(text=f"🎉 恭喜！{secret} 就是正确答案！用了 {count} 次")
        if count < best_score:
            best_score = count
            best_label.config(text=f"🏆 最佳纪录: {best_score} 步")
        else:
            best_label.config(text=f"🏆 最佳纪录: {best_score} 步（本次 {count} 步，未破纪录）")

# ========== 重置函数 ==========
def reset():
    global secret, count
    secret = random.randint(1, 100)
    count = 0
    count_label.config(text="已猜次数: 0")
    result_label.config(text="新游戏开始！请输入你的猜测")
    entry.delete(0, tk.END)

# ========== 按钮区域 ==========
btn_frame = tk.Frame(root, bg="#f0f7ff")
btn_frame.pack(pady=15)

guess_btn = tk.Button(
    btn_frame, text="🔍 猜！", command=guess,
    font=("Microsoft YaHei", 14, "bold"),
    bg="#283593", fg="white",
    activebackground="#1a237e",
    relief="flat", padx=20, pady=6,
    cursor="hand2"
)
guess_btn.pack(side="left", padx=10)

reset_btn = tk.Button(
    btn_frame, text="🔄 重新开始", command=reset,
    font=("Microsoft YaHei", 14, "bold"),
    bg="#e65100", fg="white",
    activebackground="#bf360c",
    relief="flat", padx=20, pady=6,
    cursor="hand2"
)
reset_btn.pack(side="left", padx=10)

# ========== 绑定回车键 ==========
root.bind("<Return>", lambda event: guess())

# ========== 启动主循环 ==========
root.mainloop()
```

## 小贴士
- `global` 关键字：在函数内部修改全局变量时**必须**使用，否则 Python 会把它当成函数内的局部变量
- 重置游戏时别忘了重置所有状态：`secret`、`count`、`entry` 里的文字、`result_label` 的提示
- `best_score` 不需要在重置时修改，这样玩家的最佳纪录才能一直保留
- 用 `try...except ValueError` 处理用户输入非数字的情况，避免程序崩溃
