## 本节课成品

## 知识点讲解

### 知识点 1：Canvas 画布

Canvas（画布）是 tkinter 中的绘图区域，可以在上面画线、圆、矩形等图形。涂鸦板的核心就是一个白色的 Canvas。

```python
# 创建画布：宽 500，高 400，白色背景
canvas = tk.Canvas(root, width=500, height=400, bg="white")
canvas.pack()
```

| 参数 | 说明 |
|------|------|
| `width` | 画布宽度（像素） |
| `height` | 画布高度（像素） |
| `bg` | 背景颜色 |

### 知识点 2：鼠标事件绑定

tkinter 可以监听鼠标操作，通过 `bind()` 方法绑定事件处理函数。这是涂鸦板实现交互的关键！

```python
# 语法：canvas.bind("<事件名称>", 处理函数)
canvas.bind("<B1-Motion>", draw)       # 按住鼠标左键拖动 → 画线
canvas.bind("<Button-1>", start_draw)  # 按下鼠标左键（可选的起始动作）
canvas.bind("<ButtonRelease-1>", stop_draw)  # 松开鼠标左键（可选的结束动作）
```

| 事件名称 | 含义 | 什么时候触发？ |
|----------|------|----------------|
| `<B1-Motion>` | 鼠标左键拖拽 | 按住左键不放并移动鼠标 |
| `<Button-1>` | 按下鼠标左键 | 按下左键的瞬间 |
| `<ButtonRelease-1>` | 松开鼠标左键 | 松开左键的瞬间 |
| `<Button-3>` | 按下鼠标右键 | 按下右键的瞬间 |

> **记忆技巧**：`B1` = Button 1（左键），`B3` = Button 3（右键）。Motion = 移动。

### 知识点 3：event.x 和 event.y —— 鼠标在哪里？

当鼠标事件触发时，tkinter 会自动传入一个 `event` 对象，里面包含了鼠标的位置信息。

```python
def draw(event):
    # event.x：鼠标在画布上的水平坐标（从左到右，0 → 越大）
    # event.y：鼠标在画布上的垂直坐标（从上到下，0 → 越大）
    print(f"鼠标在：x={event.x}, y={event.y}")
```

- `event.x`：鼠标距离画布**左边缘**的像素数
- `event.y`：鼠标距离画布**上边缘**的像素数
- 画布的坐标原点 `(0, 0)` 在**左上角**

### 知识点 4：create_oval 画圆点模拟画笔

涂鸦的原理很简单：在鼠标拖动的路径上，连续画很多小圆点，它们连起来就形成了一条线！这就像印章一样，一路盖过去。

```python
def draw(event):
    r = brush_size / 2  # 半径 = 画笔大小的一半
    canvas.create_oval(
        event.x - r, event.y - r,  # 左上角坐标
        event.x + r, event.y + r,  # 右下角坐标
        fill=brush_color,           # 填充颜色
        outline=brush_color         # 边框颜色（和填充色一样）
    )
```

`create_oval(x1, y1, x2, y2)` 画一个椭圆：
- `(x1, y1)` 是椭圆**外接矩形**的左上角
- `(x2, y2)` 是椭圆外接矩形的右下角
- 如果 `x2 - x1` 等于 `y2 - y1`，椭圆就是**正圆**

## 完整代码

```python
import tkinter as tk

# ========================================
# 第 16 节：涂鸦板 —— 用鼠标画出你的作品
# ========================================

root = tk.Tk()
root.title("涂鸦板")
root.geometry("550x550")
root.configure(bg="#f0f0f0")

# ---------- 画笔设置 ----------
brush_color = "black"   # 当前画笔颜色，默认黑色
brush_size = 4          # 当前画笔大小（直径，单位：像素）

# ---------- 创建画布 ----------
# Canvas 是 tkinter 的绘图区域，可以在上面画圆、线、矩形等
canvas = tk.Canvas(root, width=500, height=400, bg="white",
                   highlightthickness=1, highlightbackground="#cccccc")
canvas.pack(pady=(10, 5))

# ---------- 鼠标事件处理 ----------
def draw(event):
    """
    鼠标拖拽时的绘图函数
    当用户按住鼠标左键并在画布上移动时，tkinter 会自动调用此函数
    event 参数包含鼠标坐标：event.x（水平位置）、event.y（垂直位置）
    """
    r = brush_size / 2  # 圆的半径 = 画笔大小的一半
    # create_oval 画一个填充的圆来模拟画笔笔触
    canvas.create_oval(
        event.x - r, event.y - r,  # 左上角
        event.x + r, event.y + r,  # 右下角
        fill=brush_color,           # 填充颜色
        outline=brush_color         # 边框颜色
    )

# 绑定 <B1-Motion> 事件：按住鼠标左键并移动时，调用 draw 函数
# B1 = 鼠标左键（Button 1），Motion = 移动
canvas.bind("<B1-Motion>", draw)

# ---------- 控制按钮区域 ----------
control_frame = tk.Frame(root, bg="#f0f0f0")
control_frame.pack(pady=5)

def clear_canvas():
    """清除画布上绘制的所有内容"""
    canvas.delete("all")  # delete("all") 一次性删除所有图形

clear_btn = tk.Button(control_frame, text="🧹 清除画布",
                      command=clear_canvas,
                      font=("Microsoft YaHei", 11),
                      bg="#ff6b6b", fg="white",
                      activebackground="#ee5a5a",
                      relief="flat", padx=15, pady=5,
                      cursor="hand2")
clear_btn.grid(row=0, column=0, padx=10)

# ---------- 颜色选择区域 ----------
color_frame = tk.Frame(root, bg="#f0f0f0")
color_frame.pack(pady=5)

tk.Label(color_frame, text="🎨 画笔颜色：", font=("Microsoft YaHei", 11),
         bg="#f0f0f0", fg="#333333").grid(row=0, column=0, padx=(0, 5))

# 颜色列表：(按钮显示文字, 实际颜色值)
colors = [
    ("⚫ 黑", "black"), ("🔴 红", "red"), ("🔵 蓝", "blue"),
    ("🟢 绿", "green"), ("🟠 橙", "orange"), ("🟣 紫", "purple")
]

def change_color(color):
    """切换画笔颜色"""
    global brush_color
    brush_color = color

# 为每种颜色创建一个按钮
for i, (text, color) in enumerate(colors):
    # lambda c=color: change_color(c)
    # 必须用 c=color 捕获当前值，否则所有按钮都会指向循环最后的颜色
    btn = tk.Button(color_frame, text=text,
                    command=lambda c=color: change_color(c),
                    font=("Microsoft YaHei", 10),
                    bg="#ffffff", fg="#333333",
                    relief="flat", padx=8, pady=3,
                    cursor="hand2")
    btn.grid(row=0, column=i+1, padx=3)

# ---------- 画笔大小调整区域 ----------
size_frame = tk.Frame(root, bg="#f0f0f0")
size_frame.pack(pady=5)

tk.Label(size_frame, text="✏️ 画笔大小：", font=("Microsoft YaHei", 11),
         bg="#f0f0f0", fg="#333333").grid(row=0, column=0, padx=(0, 5))

# 显示当前画笔大小的标签
size_label = tk.Label(size_frame, text=str(brush_size),
                      font=("Microsoft YaHei", 12, "bold"),
                      bg="#ffffff", fg="#333333",
                      width=3, relief="groove")
size_label.grid(row=0, column=1, padx=5)

def increase_size():
    """增大画笔尺寸"""
    global brush_size
    if brush_size < 20:  # 限制最大尺寸
        brush_size += 2
        size_label.config(text=str(brush_size))

def decrease_size():
    """减小画笔尺寸"""
    global brush_size
    if brush_size > 2:  # 限制最小尺寸
        brush_size -= 2
        size_label.config(text=str(brush_size))

small_btn = tk.Button(size_frame, text="➖ 变小",
                      command=decrease_size,
                      font=("Microsoft YaHei", 10),
                      bg="#ffffff", fg="#333333",
                      relief="flat", padx=10, pady=3,
                      cursor="hand2")
small_btn.grid(row=0, column=2, padx=5)

big_btn = tk.Button(size_frame, text="➕ 变大",
                    command=increase_size,
                    font=("Microsoft YaHei", 10),
                    bg="#ffffff", fg="#333333",
                    relief="flat", padx=10, pady=3,
                    cursor="hand2")
big_btn.grid(row=0, column=3, padx=5)

root.mainloop()
```

## 小贴士
- `bind()` 绑定的函数会自动接收一个 `event` 参数，定义函数时一定要写 `def draw(event):`，不能漏掉 `event`
- `create_oval` 的四个坐标顺序是：**左上角 x、左上角 y、右下角 x、右下角 y**
- `lambda c=color: change_color(c)` 中的 `c=color` 非常关键——这叫"默认参数捕获"，否则循环里所有按钮都会用最后一个颜色值
- Canvas 的坐标原点 `(0, 0)` 在左上角，x 向右增大，y 向下增大
- 如果画线不流畅，可以减小画笔大小，或者加快鼠标移动速度
