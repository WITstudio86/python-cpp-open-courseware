## 知识点讲解

### 知识点 1：Listbox —— 展示账号列表

`Listbox` 就像一个**可滚动的名单列表**，适合展示多条数据。每个账号显示为一行，用户可以点击选中。

```python
# 创建一个 Listbox
listbox = tk.Listbox(root, width=30, height=15,
                     font=("微软雅黑", 11),
                     bg="white", fg="#333333",
                     selectbackground="#4a90d9")  # 选中项的背景色
listbox.pack()

# 往 Listbox 里添加数据
listbox.insert(tk.END, "🌐 百度 - admin")
listbox.insert(tk.END, "🌐 淘宝 - user123")

# 获取当前选中项的索引
selected = listbox.curselection()  # 返回元组，如 (0,)

# 获取选中项的文字内容
if selected:
    index = selected[0]
    text = listbox.get(index)
```

| 方法 | 说明 | 例子 |
|------|------|------|
| `.insert(tk.END, 文字)` | 在末尾添加一行 | `listbox.insert(tk.END, "百度")` |
| `.delete(索引)` | 删除指定行 | `listbox.delete(0)` |
| `.delete(0, tk.END)` | 清空全部内容 | 一键清空！ |
| `.curselection()` | 获取选中项的索引 | 返回 `(1,)` 表示第 2 行被选中 |
| `.get(索引)` | 获取某行的文字 | `listbox.get(0)` |
| `.size()` | 获取总行数 | `listbox.size()` |

> 🧠 **小记忆**：Listbox 的行号从 0 开始，和列表索引一样！

### 知识点 2：搜索过滤 —— 快速找到账号

当账号多了以后，一个个翻很麻烦。我们可以加一个搜索框，输入关键词后只显示匹配的账号。

**实现思路：**
1. 监听搜索框的输入变化（绑定 `<KeyRelease>` 事件）
2. 获取输入的关键词
3. 遍历所有账号，找到匹配的
4. 清空 Listbox，只显示匹配的结果

```python
def search_accounts(event=None):
    """根据搜索框的关键词过滤账号列表"""
    keyword = search_entry.get().lower()  # 获取关键词并转小写
    
    # 清空 Listbox
    listbox.delete(0, tk.END)
    
    # 遍历所有账号，只显示匹配的
    for i, acc in enumerate(accounts):
        if keyword in acc["site"].lower():  # 网站名包含关键词？
            display_text = f"🌐 {acc['site']} - {acc['username']}"
            listbox.insert(tk.END, display_text)

# 绑定事件：每次按键松开时触发搜索
search_entry.bind("<KeyRelease>", search_accounts)
```

- `event=None` 是为了让这个函数也能被按钮的 `command` 调用（按钮调用时不传 event 参数）
- `.lower()` 转小写是为了实现**不区分大小写**的搜索

### 知识点 3：复制密码到剪贴板 —— `clipboard_append()`

tkinter 提供了一个超方便的方法，能把文字直接复制到系统的剪贴板：

```python
# 把文字复制到剪贴板
root.clipboard_append("要复制的文字")

# 复制完成后清空剪贴板（可选）
root.clipboard_clear()
```

**使用示例：**

```python
def copy_password():
    """复制当前选中账号的密码到剪贴板"""
    selected = listbox.curselection()
    if not selected:
        messagebox.showwarning("提示", "请先选择一个账号！")
        return
    
    index = selected[0]
    account = accounts[index]  # 获取对应的账号数据
    password = account["password"]
    
    # 复制密码到剪贴板
    root.clipboard_clear()         # 先清空剪贴板
    root.clipboard_append(password) # 再写入密码
    
    # 给用户一个提示
    status_label.config(text=f"✅ 密码已复制到剪贴板！（{account['site']}）")
```

> ⚠️ **注意**：`clipboard_append()` 是**追加**模式，所以通常先 `clipboard_clear()` 再 `clipboard_append()`，确保剪贴板里只有我们想要的内容。

## 小贴士
- `Listbox` 的 `curselection()` 返回的是**选中项的索引元组**，需要取 `[0]` 才能拿到索引值
- `clipboard_append()` 是**追加**模式，所以一般先 `clipboard_clear()` 清空再追加
- 搜索过滤的关键思路：**遍历全部数据 → 判断是否匹配 → 重新填充 Listbox**
- 搜索框绑定 `<KeyRelease>` 而不是 `<Key>`，因为 `<KeyRelease>` 在按键松开后触发，此时输入框中的文字已经更新好了
- 左侧面板（添加账号）和右侧面板（账号列表）用了 `pack(side="left")` 和 `pack(side="right")` 实现左右分栏，这是 tkinter 里做双栏布局的常用技巧
- 如果你想让密码管理器更加安全，可以考虑使用 `base64` 或简单的凯撒密码对存储的密码加密（课后可以去搜索了解一下！）
