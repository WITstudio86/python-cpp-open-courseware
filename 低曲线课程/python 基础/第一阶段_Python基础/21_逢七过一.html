第 2 部分

游戏规则：逢七过一

我们经常会和小伙伴们玩一些数字游戏，这次我们一起来玩一个有趣的数字游戏吧。它就是：逢七过一。

即在一定的数字范围内，由一个人说出一个起始数字，然后其他参与者依次往下说，说到七的倍数的那个人需要示意跳过，如果说出来了，则为失败。
  • 首先我们需要规定一个游戏范围：1 ~ 99
  • 开始数字也要规定一下：大于 0 且小于 10 的整数
  • 每个人依次说出下一个数字，但是 7 的倍数的数字要 pass 哦
💡 同学们了解完规则之后可以试着玩一下。
第 2 部分

逢七过一（程序版）

第一步我们需要使用输入指令确定开始数字：

number = input("请输入开始数字：")
number = int(number)

确定了开始数字之后，我们接下来就要使用 for 循环进行依次输出。因为我们之前已经确定了是 1 ~ 99，所以现在我们循环的程序如下：

for x in range(number, 100):
    print(x)

接下来如果循环到的数字为七的倍数则跳过。七的倍数的判断是：x % 7 == 0。那么该如何跳过呢？

第 2 部分

continue：跳过当前这一次

continue：跳过当前循环进程，进行下次循环。
此时完整程序如下：
number = input("请输入开始数字：")
number = int(number)
for x in range(number, 100):
    if x % 7 == 0:
        continue
    else:
        print(x)
运行结果（输入 1，横向节选）
1 2 3 4 5 6 8 9 10 11 12 13 15 16 17 18 ……
第 3 部分

逢七过一（进阶版）

我们的进阶版就是：不只是七的倍数要跳过了，带七的也要跳过。所以现在的规则是：

  1. 开始数字是大于 0 小于 10 的整数；
  2. 游戏数字最多到 99；
  3. 凡是 7 的倍数或者带 7 的数字就直接跳过。

那接下来我们怎么判定这个数字是否带数字 7 呢？首先我们需要单独取出个位数和十位数。

第 3 部分

最终完整程序

number = input("请输入开始数字：")
number = int(number)
for x in range(number, 100):
    if x % 7 == 0:
        continue
    elif x // 10 == 7 or x % 10 == 7:
        continue
    else:
        print(x)

第 3 部分

思考题 · 参考答案

number = input("请输入开始数字：")
number = int(number)
for x in range(number, 100):
    if x % 7 == 0 or x % 10 == 7 or x // 10 == 7:
        continue
    print(x)
运行结果（输入 1，横向节选）
1 2 3 4 5 6 8 9 10 11 12 13 15 16 18 19 20 22 23 24 ……
💡 用 or 把“7 的倍数”和“带 7”两个条件合并成一个 if，结果和原来完全相同；条件不成立时直接 print(x)，也不需要 else 了。
