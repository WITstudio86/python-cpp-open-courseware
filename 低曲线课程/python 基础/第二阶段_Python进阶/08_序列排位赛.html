青铜 · 题目二：最后一个单词 · 解题

  • 用 split("*") 按 * 分割，会出现空字符串

白银 · 题目一：神秘的咒语

【题目描述】蓝宝学会了一个神秘的咒语 f，能把两个相同长度且由小写字母组成的字符串 s1, s2 转换成另一个字符串 g，其中 g 的第 i 个字符等于 s1 的第 i 个字符和 s2 的第 i 个字符的最小值：g[i] = min(s1[i], s2[i])。例如：f("ab", "ba") = "aa"，f("nzwzl", "zizez") = "niwel"。现在有两个字符串 x, y，请输出任何一个满足 f(x, z) = y 的字符串 z。如果找不到，则输出 -1。
【输入描述】第一行：一个数字，表示 x 和 y 的长度。第二行：字符串 x。第三行：字符串 y。
【输出描述】输出一行，为符合条件的字符串。如果没有，则输出 -1。【样例输入】
2
ab
aa
【样例输出】
ba（答案不唯一）
第 2 部分

白银 · 题目一：神秘的咒语 · 解题

  • 如果某一位 y[i] > x[i]，min 不可能得到 y[i] → 输出 -1
  • 否则 z 的这一位取 y[i] 就满足 min(x[i], y[i]) = y[i]
代码
n = int(input())
x = input()
y = input()
ok = True
for i in range(n):
    if y[i] > x[i]:
        ok = False
if ok:
    print(y)
else:
    print(-1)

白银 · 题目二：种花 · 解题

  • 在花坛两头各补一个 0，方便判断边界
  • 从左到右：自己、左边、右边都是 0 → 种下（改成 1），计数 +1
代码
flower = [0] + list(map(int, input().split(","))) + [0]
n = int(input())
cnt = 0
for i in range(1, len(flower) - 1):
    if flower[i-1] == 0 and flower[i] == 0 and flower[i+1] == 0:
        flower[i] = 1
        cnt += 1

黄金段位：采购文具

【题目描述】蓝宝作为班级班长，现在要为同学们采购文具了！文具单价为：笔记本 7 元；笔 4 元；橡皮 3 元。蓝宝手里有 n 元班费，假如笔记本、笔、橡皮的订购数量分别为 a, b, c。他采购的原则依次如下：① n 元班费必须正好用光，即 7a + 4b + 3c = n；② 在满足以上条件情况下，成套的数量尽可能大，即 a, b, c 中的最小值尽可能大；③ 在满足以上条件情况下，物品的总数尽可能大，即 a + b + c 尽可能大。请你帮助蓝宝找到满足条件的最优方案。说明：若存在方案，则最优方案唯一。
【输入描述】输入一行，为一个整数，代表班费数量 n。
【输出描述】输出一行。如果问题无解，请输出 -1。否则输出 a, b, c，用空格隔开。【样例输入】
34
——
18
——
2
【样例输出】
2 2 4
——
1 2 1
——
-1
第 3 部分

黄金段位：采购文具 · 解题

  • 枚举 a、b，算出 c：剩下的钱必须能被 3 整除
  • 用元组 (min(a,b,c), a+b+c) 比大小：先比第一项，再比第二项
代码
n = int(input())
best = None
for a in range(n // 7 + 1):
    for b in range((n - 7*a) // 4 + 1):
        rest = n - 7*a - 4*b
        if rest % 3 == 0:
            c = rest // 3
            key = (min(a, b, c), a + b + c)
            if best is None or key > best[0]:
                best = (key, a, b, c)
if best is None:
    print(-1)
else:
    print(best[1], best[2], best[3])
运行结果（样例 1）
34
2 2 4

第 4 部分

铂金段位 · 解题

  • 用长度 26 的列表 cnt 统计 A～Z 的次数
  • 从最高的高度往下，一行一行输出
  • 这一列的次数 ≥ 当前高度 → 打印 *
  • rstrip() 去掉行末多余空格
代码
lines = [input() for i in range(4)]
cnt = [0] * 26
for s in lines:
    for ch in s:
        if 'A' <= ch <= 'Z':
            cnt[ord(ch) - 65] += 1
for h in range(max(cnt), 0, -1):
    row = ''
    for i in range(26):
        row += '* ' if cnt[i] >= h else '  '
    print(row.rstrip())
print(' '.join(chr(65 + i) for i in range(26)))

钻石段位：三数之和

【题目描述】老师给了小蓝一组数字，让小蓝判断这组数字中是否存在三个数字 a, b, c，使得 a + b + c = 0。小蓝百思不得其解，于是来求助你，请你帮助小蓝一起找出所有和为 0 且不重复的三个数字。注意：每三个数字作为一组，存储在同一列表中；所有组数字小列表都存储在一个大列表中。每组数字之间不能重复，如：3, 2, 1 和 1, 2, 3 属于重复组。
【输入描述】输入一行，是老师给小蓝的一组数字，数字之间用逗号隔开。
【输出描述】输出一行，是嵌套列表类型。【样例输入】
-1,0,1,2,-1,-4
0
-5,5,0,5,1,-1,2,-2,0
【样例输出】
[[-1, -1, 2], [-1, 0, 1]]
[]
[[-5, 0, 5], [-2, 0, 2], [-1, 0, 1]]
第 5 部分

钻石段位：三数之和 · 解题

  • 先 sort() 排序，三个数也按从小到大取 → 方便去重
  • 三重循环 i < j < k，和为 0 且不在结果中才加入
代码
nums = list(map(int, input().split(",")))
nums.sort()
res = []
n = len(nums)
for i in range(n):
    for j in range(i + 1, n):
        for k in range(j + 1, n):
            if nums[i] + nums[j] + nums[k] == 0:
                g = [nums[i], nums[j], nums[k]]
                if g not in res:
                    res.append(g)
print(res)
运行结果（样例 3）
-5,5,0,5,1,-1,2,-2,0
[[-5, 0, 5], [-2, 0, 2], [-1, 0, 1]]

参考答案
nums = list(map(int, input().split(",")))
m = max(nums)
idx = nums.index(m)
ok = True
for x in nums:
    if x != m and m < 2 * x:
        ok = False
if ok:
    print(idx)
else:
    print(-1)

三、黄金段位

黄金段位：采购文具

【题目描述】蓝宝作为班级班长，现在要为同学们采购文具了！文具单价为：笔记本 7 元；笔 4 元；橡皮 3 元。蓝宝手里有 n 元班费，假如笔记本、笔、橡皮的订购数量分别为 a, b, c。他采购的原则依次如下：① n 元班费必须正好用光，即 7a + 4b + 3c = n；② 在满足以上条件情况下，成套的数量尽可能大，即 a, b, c 中的最小值尽可能大；③ 在满足以上条件情况下，物品的总数尽可能大，即 a + b + c 尽可能大。请你帮助蓝宝找到满足条件的最优方案。说明：若存在方案，则最优方案唯一。
【输入描述】输入一行，为一个整数，代表班费数量 n。
【输出描述】输出一行。如果问题无解，请输出 -1。否则输出 a, b, c，用空格隔开。【样例输入】
34
——
18
——
2
【样例输出】
2 2 4
——
1 2 1
——
-1

黄金段位：采购文具 · 解题思路与参考代码

  • 枚举 a、b，算出 c：剩下的钱必须能被 3 整除
  • 用元组 (min(a,b,c), a+b+c) 比大小：先比第一项，再比第二项
n = int(input())
best = None
for a in range(n // 7 + 1):
    for b in range((n - 7*a) // 4 + 1):
        rest = n - 7*a - 4*b
        if rest % 3 == 0:
            c = rest // 3
            key = (min(a, b, c), a + b + c)
            if best is None or key > best[0]:
                best = (key, a, b, c)
if best is None:
    print(-1)
else:
    print(best[1], best[2], best[3])

铂金段位 · 解题思路与参考代码

  • 用长度 26 的列表 cnt 统计 A～Z 的次数
  • 从最高的高度往下，一行一行输出
  • 这一列的次数 ≥ 当前高度 → 打印 *
  • rstrip() 去掉行末多余空格
lines = [input() for i in range(4)]
cnt = [0] * 26
for s in lines:
    for ch in s:
        if 'A' <= ch <= 'Z':
            cnt[ord(ch) - 65] += 1
for h in range(max(cnt), 0, -1):
    row = ''
    for i in range(26):
        row += '* ' if cnt[i] >= h else '  '
    print(row.rstrip())
print(' '.join(chr(65 + i) for i in range(26)))

五、钻石段位

钻石段位：三数之和

【题目描述】老师给了小蓝一组数字，让小蓝判断这组数字中是否存在三个数字 a, b, c，使得 a + b + c = 0。小蓝百思不得其解，于是来求助你，请你帮助小蓝一起找出所有和为 0 且不重复的三个数字。注意：每三个数字作为一组，存储在同一列表中；所有组数字小列表都存储在一个大列表中。每组数字之间不能重复，如：3, 2, 1 和 1, 2, 3 属于重复组。
【输入描述】输入一行，是老师给小蓝的一组数字，数字之间用逗号隔开。
【输出描述】输出一行，是嵌套列表类型。【样例输入】
-1,0,1,2,-1,-4
0
-5,5,0,5,1,-1,2,-2,0
【样例输出】
[[-1, -1, 2], [-1, 0, 1]]
[]
[[-5, 0, 5], [-2, 0, 2], [-1, 0, 1]]

钻石段位：三数之和 · 解题思路与参考代码

  • 先 sort() 排序，三个数也按从小到大取 → 方便去重
  • 三重循环 i < j < k，和为 0 且不在结果中才加入
nums = list(map(int, input().split(",")))
nums.sort()
res = []
n = len(nums)
for i in range(n):
    for j in range(i + 1, n):
        for k in range(j + 1, n):
            if nums[i] + nums[j] + nums[k] == 0:
                g = [nums[i], nums[j], nums[k]]
                if g not in res:
                    res.append(g)
print(res)
