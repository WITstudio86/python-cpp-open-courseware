元组

  • 元组（tuple）与列表类似：也是由一系列按照特定顺序排列的元素组成

import turtle
pen = turtle.Turtle()
pen.color("red", "yellow")
pen.begin_fill()
for i in range(5):
    pen.forward(200)
    pen.right(144)
pen.end_fill()
turtle.done()

import turtle
pen = turtle.Turtle()
