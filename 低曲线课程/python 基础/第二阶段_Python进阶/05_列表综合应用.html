第 1 部分

列表切片

格式：列表名[起始位置:结束位置:步长]

  • 从起始位置开始取，取到结束位置的前一个（不包括结束位置）
  • 起始位置不写 → 从头开始；结束位置不写 → 取到最后
代码
lst = ['a','b','c','d','e','f','g','h','i','j','k']
print(lst[2:5])
print(lst[:3])
print(lst[8:])
print(lst[-3:-1])
运行结果
['c', 'd', 'e']
['a', 'b', 'c']
['i', 'j', 'k']
['i', 'j']
第 2 部分

切片的步长

代码
lst = ['a','b','c','d','e','f','g','h','i','j','k']
print(lst[1:8:2])
print(lst[::3])
print(lst[-2:-7:-2])
运行结果
['b', 'd', 'f', 'h']
['a', 'd', 'g', 'j']
['j', 'h', 'f']
第 2 部分

切片复制列表

代码
a = [1, 2, 3]
b = a[:]
b.append(4)
print(a)
print(b)
运行结果
[1, 2, 3]
[1, 2, 3, 4]
💡 a[:] 切出整个列表，得到一个新的列表，修改 b 不会影响 a。

第 4 部分

提取嵌套列表中指定位置元素

嵌套列表名[索引1][索引2]

  • 索引 1 —— 第几个小列表
  • 索引 2 —— 该小列表中第几个元素
代码
stu = [['zhang',90],['li',100],['wang',88]]
for s in stu:
    print(s[0], s[1])
运行结果
zhang 90
li 100
wang 88

包头不包尾不包括结束位置
步长每隔几个取一个；负数从右往左
运算符len() · + 组合 · * 重复 · in
嵌套列表列表中含有多个小列表
取元素名[索引1][索引2]

一、列表切片（一）

列表切片

格式：列表名[起始位置:结束位置:步长]

  • 从起始位置开始取，取到结束位置的前一个（不包括结束位置）
  • 起始位置不写 → 从头开始；结束位置不写 → 取到最后
lst = ['a','b','c','d','e','f','g','h','i','j','k']
