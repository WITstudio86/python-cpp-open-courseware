第 1 部分

列表介绍

  • 列表（list）是 Python 中最常用的数据类型
  • 用 [ ] 中括号表示，每个元素之间用逗号隔开
  • 列表中的元素可以是不同数据类型，如数字与字符串混搭的列表
lst = [1, 2, 3, 'py', '列表', '~']
📋
第 2 部分

列表创建

写法说明
lst = list()创建空列表
lst = []创建空列表
lst = [1, 2, 3]创建非空列表
lst = list(range())用 range 函数创建
第 2 部分

用 range 函数创建列表

代码
lst = list(range(3))
print(lst)
lst = list(range(0, 3))
print(lst)
lst = list(range(0, 3, 2))
print(lst)
运行结果
[0, 1, 2]
[0, 1, 2]
[0, 2]
💡 range(开始, 结束, 步长)：从“开始”数到“结束”的前一个数，不包括结束值。

列表的索引及查询

通过列表名 + 索引获取某个元素：lst[索引]

代码
lst = [1,2,3,'py','列表','~']

print(lst[3])
print(lst[-1])
print(lst[-2])
运行结果

第 4 部分

列表输出：print() 与索引

① 直接输出列表

② 用索引输出元素

代码
lst = ['a','b','c','d','e','f','g']
print(lst)
运行结果
['a', 'b', 'c', 'd', 'e', 'f', 'g']

lst = ['a','b','c','d','e','f','g']

第 4 部分

③ 使用循环遍历列表

a) for 循环遍历

b) while 循环遍历

代码
lst = ['python','is','good']
for i in lst:
    print(i)
运行结果
python
is
good
代码
lst = ['python','is','good']
i = 0
while i < len(lst):
    print(lst[i])
    i += 1
运行结果
python
is
good
第 5 部分

列表新增：append()

append() 在列表末尾添加元素

代码
colors = ['red','green','blue','yellow']
colors.append('pink')
colors.append(1234)
print(colors)
运行结果
['red', 'green', 'blue', 'yellow', 'pink', 1234]
第 5 部分

列表新增：extend() 和 insert()

extend() 在末尾添加列表

insert() 在列表中插入元素

代码
a = [1,2]
b = [3,4]
a.extend(b)
print(a)
运行结果
[1, 2, 3, 4]
代码
a = [5,7,9]
a.insert(1,3)
print(a)
运行结果
[5, 3, 7, 9]
💡 insert(位置, 元素)：把元素插到这个索引位置，后面的元素往后挪。
第 5 部分

通过索引修改列表元素

列表名[索引] = 新值：把这个位置上的元素换成新值

代码
colors = ['red','green','blue']
colors[1] = 'pink'
colors[-1] = 'black'
print(colors)
运行结果
['red', 'pink', 'black']
第 5 部分

列表 + 循环：统计与求和

代码
lst = [2, 3, 2, 5]
cnt = 0
total = 0
for x in lst:
    if x == 2:
        cnt += 1
    total += x
print(cnt, total)
运行结果
2 12

【题目描述】输出一个整数序列中与指定数字相同的数的个数。
【输入描述】输入包含三行：第一行为 N，表示整数序列的长度（N ≤ 100）；第二行为 N 个整数，整数之间以一个空格分开；第三行包含一个整数，为指定的整数 m。
【输出描述】输出为 N 个数中与 m 相同的数的个数，若没有相同的，输出 0。【样例输入】
3
2 3 2
2

2

【题目描述】输出一个整数数列中不与整数 m 相同的数字之和。
【输入描述】输入分为三行：第一行为 N（N 为接下来数的个数，N ≤ 100）；第二行为 N 个整数，数与数之间以一个空格分开；第三行为 1 个整数 m，表示要比较的数。
【输出描述】输出为 N 个数中不与 m 相同的数字之和。【样例输入】
3

练习二 · 参考答案

参考答案
n = int(input())
lst = input().split()
m = int(input())
total = 0
for x in lst:
    if int(x) != m:
        total += int(x)
print(total)
