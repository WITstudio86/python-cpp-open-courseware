第 1 部分

认识元组

  1. 元组（tuple）与列表类似：也是由一系列按照特定顺序排列的元素组成
  2. 元组是不可变的，也被称为“不可变的列表”
  3. 元组的所有元素都是放在一对小括号 () 中
  4. 两个相邻元素之间使用逗号 , 分割
第 1 部分

元组与列表的区别

列表 list元组 tuple
符号中括号 [ ]小括号 ( )
能否修改可以增、删、改不可变：不能增、删、改元素
相同点有顺序、可以用索引、可以遍历有顺序、可以用索引、可以遍历
代码
tup = (1, 2, 3)
tup[0] = 9
运行结果（报错）
TypeError: 'tuple' object does not support item assignment
第 2 部分

创建空元组

代码
tup1 = ()
print(tup1)
tup1 = tuple()
print(tup1)
运行结果
()
()
💡 空元组：一对空的小括号 ()，或者 tuple()。
第 2 部分

创建非空元组

代码
tup1 = (1, 2, 3)
print(tup1)
tup1 = tuple(range(1, 10, 2))
print(tup1)

print(tup2)
tup3 = tuple([1,2,3])
print(tup3)

第 2 部分

创建元组注意事项

代码

print(type(tup1))
tup2 = (50,)
print(type(tup2))
运行结果
<class 'int'>
<class 'tuple'>
⚠️ 只有一个元素的元组，后面一定要加逗号：(50,)；(50) 只是整数 50。
第 3 部分

元组索引及输出

① print 输出 / ③ 索引输出
tup = ('a','b','c','d')
print(tup)
print(tup[1], tup[-1])
运行结果
('a', 'b', 'c', 'd')
b d
② for 循环遍历
tup = ('a','b','c','d')
for x in tup:
    print(x, end=' ')
运行结果
a b c d
第 4 部分

查找元组内容

  • in、not in：判断元素在不在元组中
  • index()：查找元素的位置
  • count()：统计元素出现的次数
代码
color = ('red','blue','yellow','pink','black','white')
x = 'black'
if x in color:
    n = color.index(x)
    c = color.count(x)
    print(n, c)
print('green' not in color)
运行结果
4 1
True
第 5 部分

元组合并和删除

  • 合并：使用加号 +
  • 删除：del 删除整个元组
合并
name = ("小蓝","小桥","杯杯")
score = (100, 88, 90)
tup = name + score
print(tup)
运行结果
('小蓝', '小桥', '杯杯', 100, 88, 90)
删除整个元组
tup = (1, 2, 3)
del tup
print(tup)
运行结果
NameError: name 'tup' is not defined

  3. 下面代码的输出是什么？
    t = (3, 1, 3, 2)

  4. 下面代码的输出是什么？

  5. 元组能用 del 删除单个元素吗？
第 6 部分

课堂小测验 · 参考答案

  1. 元组不可变（不能增删改元素），用小括号；列表可变，用中括号
  2. (5,)
  3. 2 3
  4. (1, 2, 3)
  5. 不能，del 只能删除整个元组
