第 1 部分

关于 d.keys() 和 d.values() 的说明

  • d.keys() 和 d.values() 都不是列表类型
  • 如果需要转换成列表类型，可以用 list() 转换
代码
d = {'数学':98, '语文':100, '英语':95}
print(d.keys())
print(list(d.keys()))
print(list(d.values()))
运行结果
dict_keys(['数学', '语文', '英语'])
['数学', '语文', '英语']
[98, 100, 95]
第 2 部分

遍历字典项：单变量

代码
d = {'数学':98, '语文':100, '英语':95}
for i in d.items():
    print(i)

('数学', 98)
('语文', 100)
('英语', 95)
💡 d.items() 得到每一个“键值对”，每一项是一个元组 (键, 值)。
第 2 部分

遍历键值对：双变量

代码
d = {'数学':'98', '语文':'100'}
for k,v in d.items():
    print(k+':'+v)
运行结果
数学:98
语文:100
⚠️ 讲义写法 k+':'+v 要求值也是字符串；值是数字时可以写 print(k, v) 或 print(k+':'+str(v))。

【题目描述】输入一串英文字母，找到它的第一个不重复的字母，并输出它的索引。如果不存在，则输出 -1。【样例输入】
hellohomework
——

【样例输出】
7
——

练习

练习一 · 参考答案

参考答案
s = input()
cnt = {}
for c in s:
    cnt[c] = cnt.get(c, 0) + 1
ans = -1
for i in range(len(s)):
    if cnt[s[i]] == 1:
        ans = i
        break
print(ans)

练习二

编写程序，实现以下功能：
  1. 系统随机生成 50 个整数，范围为 20～100（包含 20 和 100）。
  2. 请按照从小到大的顺序在一行内输出这 50 个整数，整数间用空格隔开。
  3. 统计每个整数出现的次数，找到出现次数最多的那个整数，并输出。
练习

练习二 · 参考答案

参考答案
import random
lst = [random.randint(20, 100) for i in range(50)]
lst.sort()
print(' '.join(str(x) for x in lst))
cnt = {}
for x in lst:
    cnt[x] = cnt.get(x, 0) + 1
best = lst[0]
for k, v in cnt.items():
    if v > cnt[best]:
        best = k
print(best)
💡 数据是随机的，每次结果不同；出现次数并列最多时，输出较小的那个即可
