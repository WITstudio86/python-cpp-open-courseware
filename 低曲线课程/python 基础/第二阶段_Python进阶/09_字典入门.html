第 2 部分

字典格式

d = { key1 : value1 , key2 : value2 }

符号说明

  • 使用大括号 { } 表示字典
  • 逗号 , 分割每组数据
  • 冒号 : 表示每组数据间的对应关系

键值说明

  • 冒号之前的 —— 键 —— 用 key 表示
  • 冒号之后的 —— 值 —— 用 value 表示
  • 每组数据 —— 键值对

键 key值 value
是否唯一唯一：同一个字典里不能重复不需要唯一
类型不可变的：如字符串、元组、数字可以是任何数据类型

查字典时，我们通过一个字找到它的解释。Python 里也有“字典”，每组数据都有一种对应关系。这节课我们来认识字典。

本节课目标：认识字典；掌握字典的格式及创建；掌握访问字典值的方法。

一、认识字典

  • 与列表类似，字典也可以存储多组数据
  • 与生活中的字典类似，Python 的字典中的每组数据内也有一种对应关系

二、字典格式

d = { key1 : value1 , key2 : value2 }

符号说明

  1. 使用大括号（{ }）表示字典
  2. 逗号（,）分割每组数据
  3. 冒号（:）表示每组数据间的对应关系

键值说明

  1. 冒号（:）之前的 -- 键 -- 用 key 表示
  2. 冒号（:）之后的 -- 值 -- 用 value 表示
  3. 每组数据 -- 键值对

键值对比

键 key值 value
是否唯一唯一：同一个字典里不能重复不需要唯一
类型不可变的：如字符串、元组、数字可以是任何数据类型
d = {'a': 1, 'b': 2, 'b': '3'}
print(d)
运行结果
{'a': 1, 'b': '3'}

三、字典的创建方法

方法 1：使用赋值运算符直接创建

dict1 = {}
print(dict1)
dict1 = {'黄瓜':'3元', '西红柿':'5元',
         '白菜':'2元', '小葱':'1元',
         '土豆':'3元'}
print(dict1)
运行结果
{}
{'黄瓜': '3元', '西红柿': '5元', '白菜': '2元', '小葱': '1元', '土豆': '3元'}

方法 2：使用 dict() 创建 · 方法一

lst1 = [1,2,3]
lst2 = ['a','b','c']
dict1 = dict(zip(lst1,lst2))
print(dict1)
运行结果
{1: 'a', 2: 'b', 3: 'c'}
  • zip() —— 将多个列表/元组对应位置的元素合成元组
  • dict() —— 将用 zip() 转换后的数据转换成字典

方法 2：使用 dict() 创建 · 方法二

dict2 = dict(a=1, b=2, c=3)
print(dict2)
dict3 = dict()
print(dict3)
运行结果
{'a': 1, 'b': 2, 'c': 3}
{}

💡 使用 name=value 的形式传入；dict() 不写参数得到空字典。

四、访问字典

方法一：把键(key)放入熟悉的方括号([ ])中，就可以访问字典。语法：字典名[键]

方法二：通过 get(key) 方法访问其值。语法：字典名.get(键)

d = {'Name':'Zara', 'Age':7, 'Class':'First'}
print(d['Name'])
print(d.get('Name'))
print(d.get('Age'))
运行结果
Zara
Zara
7

字典访问与序列访问的区别

序列（列表等）字典
用什么访问lst[索引]，索引是位置编号d[键]，用键来找值
找不到时IndexErrord[键] 报 KeyError；get() 返回 None
d = {'Name':'Zara', 'Age':7}
print(d.get('Sex'))
print(d['Sex'])
运行结果
None
KeyError: 'Sex'
