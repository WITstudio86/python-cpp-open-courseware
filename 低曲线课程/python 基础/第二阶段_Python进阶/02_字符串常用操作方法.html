第 1 部分

find() 和 index()

  • find()：检测字符串中是否包含某子字符串。包含 → 结果为子字符串第一次出现时的索引；不包含 → 结果为 -1
  • rfind()：检测子字符串最后一次出现的索引
  • index()、rindex() 与 find()、rfind() 功能及用法类似，唯一不同：子字符串不存在时会抛出异常
第 1 部分

查找示例

代码
str1 = "This is an apple"
p1 = str1.find("i")
p2 = str1.rfind("i")
print(p1, p2)
p1 = str1.index("a")
p2 = str1.rindex("a")
print(p1, p2)
n = str1.count("p")
print(n)
p1 = str1.find("pear")
print(p1)
运行结果
2 5
8 11
2
-1
第 1 部分

find() 与 index() 的区别

代码
str1 = "This is an apple"
print(str1.find("pear"))
print(str1.index("pear"))
运行结果
-1
ValueError: substring not found
方法找到找不到
find() / rfind()返回索引返回 -1
index() / rindex()返回索引抛出异常 ValueError
第 2 部分

split() 分割

split() 函数用于拆分字符串，通过指定分隔符分割字符串，结果为分割后的字符串列表（list）。

代码
s = "apple,banana,pear"
print(s.split(","))
t = "I love Python"
print(t.split())
print(s.rsplit(",", 1))
运行结果
['apple', 'banana', 'pear']
['I', 'love', 'Python']
['apple,banana', 'pear']
💡 split() 括号里不写分隔符时，按空格分割；rsplit(分隔符, 次数) 从右边开始分割。
第 2 部分

split() 和 input() 的不解之缘

input() 得到的是一整行字符串，用 split() 就能把用户输入的多个数据一次拆开。

代码
s = input("请输入三个名字：")
names = s.split()
print(names)
print(names[0])
运行结果
请输入三个名字：小蓝 小明 小红
['小蓝', '小明', '小红']
小蓝
第 2 部分

输入两个数并求和

代码
a, b = input("请输入两个数：").split()
print(int(a) + int(b))
运行结果
请输入两个数：3 5
8
⚠️ split() 分出来的仍然是字符串，要计算时先用 int() 转换成整数。
第 3 部分

join() 合并

join() 方法用来拼接字符串，在相邻的字符串之间插入指定字符，从而得到新字符串。

代码
lst = ['hello','python','world']
print('~'.join(lst))
print('-'.join(lst))
print(''.join(lst))
运行结果
hello~python~world
hello-python-world
hellopythonworld
第 4 部分

字符串大小写转换

代码
s = "hello PYTHON world"
print(s.lower())
print(s.upper())
print(s.capitalize())
print(s.title())
print(s.swapcase())
运行结果

HELLO PYTHON WORLD
Hello python world
Hello Python World
HELLO python WORLD
第 4 部分

大小写方法一览

方法作用"hello PYTHON" 的结果
lower()将字符串内字母转换成小写hello python
upper()将字符串内字母转换成大写HELLO PYTHON
capitalize()将字符串首字母转换成大写Hello python
title()将字符串内每个单词首字母转换成大写Hello Python
swapcase()将字符串内字母的大小写互换HELLO python
