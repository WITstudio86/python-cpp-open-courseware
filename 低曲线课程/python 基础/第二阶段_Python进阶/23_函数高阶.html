第 1 部分

闭包

  • 闭包，又称闭包函数或者闭合函数
  • 和前面讲的嵌套函数类似，不同之处在于：闭包中外部函数返回的不是一个具体的值，而是一个函数
  • 一般情况下，返回的函数会赋值给一个变量，这个变量可以在后面被继续执行调用
第 1 部分

闭包示例

代码
def fun(y):
    def indef(x):
        return x ** y
    return indef

a = fun(2)
b = fun(3)
print(a(2))
print(b(2))
运行结果
4
8
第 1 部分

闭包的好处

当需要多次调用该函数时，如果将那些额外工作的代码放在外部函数，就可以减少多次调用导致的不必要开销，提高程序的运行效率。

代码
a = fun(2)
for i in range(1, 6):
    print(a(i), end=" ")
运行结果
1 4 9 16 25
第 2 部分

lambda 表达式

  • lambda 表达式：用于定义一个简单的函数，又称匿名函数
  • 常用来表示内部仅包含 1 行表达式的函数
  • 如果一个函数的函数体仅有 1 行表达式，则该函数就可以用 lambda 表达式来代替
代码
name = lambda [list]: 表达式
  • 定义 lambda 表达式，必须使用 lambda 关键字
  • [list] 作为可选参数，等同于定义函数时指定的参数列表
  • name 为该表达式的名称
第 2 部分

普通函数 vs lambda

普通函数
def add(x, y):
    return x + y

print(add(3, 4))
运行结果
7
lambda
add = lambda x, y: x + y

print(add(3, 4))
运行结果
7
第 2 部分

lambda 的两个优势

  • 对于单行函数，使用 lambda 表达式可以省去定义函数的过程，让代码更加简洁
  • 对于不需要多次复用的函数，使用 lambda 表达式可以在用完之后立即释放，提高程序执行的性能
代码
nums = [3, -8, 5, -1]
nums.sort(key=lambda x: abs(x))
print(nums)

sq = lambda n: n * n
print(sq(9))
运行结果
[-1, 3, 5, -8]
81
第 3 部分

值传递的传递机制

  • 值传递，本质是将实参值复制一份，将其副本传给形参
  • 采用值传递方式的函数中，无论其内部对参数值进行如何修改，都不会影响函数外部的实参
代码
def demo(a, b):
    a, b = b, a
    print("demo里:", a, b)

a = 6
b = 9
demo(a, b)
print("外部:", a, b)
运行结果
demo里: 9 6
外部: 6 9
第 3 部分

值传递的实质

当系统开始执行函数时，系统对形参执行初始化，就是把实参变量的值赋给函数的形参变量，在函数中操作的并不是实际的实参变量。

💡 主内存中的 a、b 和 demo 中的 a、b 是两套“箱子”。就像把一幅画复印一份给同学，同学在复印件上怎么涂改，你的原件都不会变。
第 4 部分

引用传递的传递机制

  • 实参是可变对象（列表、字典）→ 引用传递
  • 修改函数内的值，会导致函数外的值随之改变
代码
def swap(dw):
    t = dw["a"]
    dw["a"] = dw["b"]
    dw["b"] = t
    print("swap里:", dw)

dw = {"a": 6, "b": 9}
swap(dw)
print("外部:", dw)
运行结果
swap里: {'a': 9, 'b': 6}
外部: {'a': 9, 'b': 6}
第 4 部分

引用传递的实质

引用传递时，复制给形参的是引用（地址），实参和形参指向同一个对象。通过形参修改对象里的内容，实参看到的也是修改后的内容。

💡 主内存中的 dw 和 swap 中的 dw 是两个变量，但都指向同一组装着 a:6、b:9 的“箱子”。

练习

练习三 · 参考答案

参考答案
def odd_sum(lst):
    s = 0
    for i in range(1, len(lst), 2):
        s += lst[i]
    return s

print(odd_sum([1, 2, 3, 4, 5]))
💡 例：[1,2,3,4,5] 奇数索引 1、3 的元素 2+4=6；也可写 sum(lst[1::2])
