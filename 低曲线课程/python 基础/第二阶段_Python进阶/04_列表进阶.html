第 1 部分

方法一：remove()

remove(元素)：按元素的值删除（删除第一个匹配的元素）

代码
colors = ['red','blue','green','pink']
colors.remove('blue')
print(colors)
运行结果
['red', 'green', 'pink']
第 1 部分

方法二：pop()

pop(索引)：按索引删除；不写索引时删除最后一个元素

代码
colors = ['red','blue','green','pink']
colors.pop(2)
print(colors)
colors.pop()
print(colors)
运行结果
['red', 'blue', 'pink']
['red', 'blue']
第 1 部分

方法三：del

del 列表[索引] 或 del 列表[开始:结束]：删除一个或一段元素（不包括结束位置）

代码
colors = ['red','blue','green','pink']
del colors[1:3]
print(colors)
运行结果
['red', 'pink']
方法按什么删除
remove()按元素的值
pop()按索引（默认最后一个）
del按索引或一段范围
第 2 部分

列表搜索：元素是否在列表中

代码
lst = [2, 3, 4, '编程', 'good', '!']
if 'good' in lst:
    print('在列表中')
else:
    print('不在列表中')
运行结果
在列表中
💡 元素 in 列表：在 → True；不在 → False。可以和 if 结合使用。
第 2 部分

列表搜索：元素在列表的哪个位置

代码
lst = [2, 3, 4, '编程', 'good', '!']
n = lst.index('good')
print(n)
运行结果
4
⚠️ index() 找不到元素时会报错 ValueError，可以先用 in 判断。
第 3 部分

列表统计及最值

  • count()：统计列表中某元素出现次数
  • max() min()：取列表中的最大值、最小值
代码
lst = [3, 8, 1, 8, 5]
print(lst.count(8))
print(max(lst))
print(min(lst))
print(sum(lst))
运行结果
2
8
1
25
第 4 部分

列表排序及倒置

  • 使用 sort() 对列表进行排序（默认从小到大）
  • 使用 reverse() 对列表进行倒置 / 反转
代码
lst = [3, 8, 1, 5]
lst.sort()
print(lst)
lst.sort(reverse=True)
print(lst)
lst = [3, 8, 1, 5]
lst.reverse()
print(lst)
运行结果
[1, 3, 5, 8]
[8, 5, 3, 1]
[5, 1, 8, 3]
第 5 部分

列表推导式

代码
lst = [x**2 for x in range(1,10) if x>2]
print(lst)
运行结果
[9, 16, 25, 36, 49, 64, 81]
第 5 部分

推导式和 for 循环对比

for 循环写法
lst = []
for x in range(1,10):
    if x > 2:
        lst.append(x**2)
print(lst)
运行结果
[9, 16, 25, 36, 49, 64, 81]
推导式写法
lst = [x**2 for x in range(1,10) if x>2]
print(lst)
print([c.upper() for c in 'abc'])
运行结果
[9, 16, 25, 36, 49, 64, 81]
['A', 'B', 'C']
