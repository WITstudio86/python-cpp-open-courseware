查找系列 find

函数功能
find(x, pos)从 pos 往后找 x 首次出现的位置
rfind(x, pos)从 pos 往前找
find_first_of(串)找第一个属于该串中任一字符的位置
find_last_of(串)从后往前找
find_first_not_of(串)找第一个不属于该串的字符
find_last_not_of(串)从后往前找不属于的
💡 找不到时返回 string::npos，判断写 if (s.find(x) == string::npos)。

第 4 部分

成绩排序

按分数从高到低排序，分数相同的按名字字典序从小到大。

  • 结构体没有默认的比较规则，sort 必须传入 cmp
  • string 可以直接用 < 比较字典序，比 strcmp 方便
第 4 部分

成绩排序（上）

程序（上）
#include<iostream>
#include<string>
#include<algorithm>
using namespace std;
struct Student
{
    int score;
    string name;
} a[100];
bool cmp(Student x, Student y)
{
    if (x.score != y.score)
        return x.score > y.score;
    return x.name < y.name;
}
int main()

子串出现次数：输入字符串 s 和 t，统计 t 在 s 中出现的次数（不重叠）。

练习

练习二 · 参考答案

参考程序
#include<iostream>
#include<string>
using namespace std;
int main()
{
    string s, t;
    cin >> s >> t;
    int cnt = 0, p = s.find(t);
（续）
    while (p != (int)string::npos)
    {
        cnt++;
        p = s.find(t, p + t.length());
    }
    cout << cnt;
    return 0;
}
运行结果
输入：abababa aba
输出：
2
💡 每次从上一次结尾的下一位置接着找，就不会重叠。

九、成绩排序

按分数从高到低排序，分数相同的按名字字典序从小到大。

  • 结构体没有默认的比较规则，sort 必须传入 cmp
  • string 可以直接用 < 比较字典序，比 strcmp 方便
#include<iostream>
#include<string>
#include<algorithm>
using namespace std;
struct Student
{
    int score;
    string name;
} a[100];
bool cmp(Student x, Student y)
{
    if (x.score != y.score)
        return x.score > y.score;
    return x.name < y.name;
}
int main()
{
    int n;
    cin >> n;
    for (int i = 0; i < n; i++)
        cin >> a[i].name >> a[i].score;
    sort(a, a + n, cmp);
    for (int i = 0; i < n; i++)
        cout << a[i].name << ' ' << a[i].score << endl;
    return 0;
}

4
Xiaozhi 396
Xiaohui 405
Xiaocong 399
Xiaoming 396
输出：
Xiaohui 405
Xiaocong 399
Xiaoming 396
Xiaozhi 396
