# 无人机地震救援 — Scratch 3 互动小程序设计文档

**日期：** 2026-07-08
**类型：** Scratch 3 项目 (.sb3)
**预计时长：** 3-5 分钟

---

## 1. 项目概述

一个面向科普展示的 Scratch 3 互动小程序，以**四川山区地震**为背景，玩家操控无人机执行搜索与救援任务，通过轻度操作推进故事，体验无人机在灾害救援中的重要作用。

### 1.1 目标用户
通用科普展示，偏教育和故事体验，不限年龄段。

### 1.2 核心体验
- 故事驱动，沉浸式体验灾区救援
- 轻度操作（方向键 + 空格键），不打断叙事节奏
- 丰富的动画、音效营造氛围
- 传播"科技向善"的理念

---

## 2. 场景流程

```
开始界面 → 地震发生 → 山区搜索 → 物资投送 → 结算界面
 (15s)      (20s)      (60s)      (45s)      (20s)
```

### 场景 1：开始界面
- **画面**：群山环绕，夕阳色调，无人机停在发射台上
- **标题**：「无人机地震救援行动」
- **副标题**：「四川山区 · 6.8级地震」
- **按钮**：点击「🚀 开始救援任务」进入
- **音乐**：平静但略带紧张感的背景音乐

### 场景 2：地震发生
- **动画**：画面抖动 → 房屋摇晃 → 山坡滑坡 → 道路断裂 → 尘烟升起
- **音效**：轰隆声 → 警报声 → 逐渐寂静
- **文案**：底部滚动字幕，交代背景
- **过渡**：自动进入场景 3

### 场景 3：无人机出发 + 山区搜索
- **操作**：方向键 ↑↓←→ 操控无人机
- **画面**：俯瞰山区废墟，3 处位置有求救信号（挥动手臂/SOS标志/敲击波纹）
- **反馈**：靠近幸存者时心跳波纹 + 侦测音
- **目标**：飞近 3 个幸存者位置完成侦测
- **提示**：屏幕上方操作提示文字

### 场景 4：物资投送
- **操作**：空格键投送急救包
- **画面**：无人机悬停，急救包下降动画
- **目标**：对 3 处已侦测位置投送物资
- **反馈**：✅ 标记 + 文字提示 + 音效
- **过渡**：全部投送完成 → 结算界面

### 场景 5：结算界面
- **画面**：夕阳，无人机返航，救援车队抵达
- **数据**：搜索区域、物资投送、幸存者获救、星级评级
- **文案**：「每一次飞行，都是生命的希望」
- **按钮**：「🔄 再次出发」重新开始

## 3. Scratch 技术实现

### 3.1 角色（Sprites）设计
| 角色 | 用途 | 造型数 |
|------|------|--------|
| Drone（无人机） | 玩家操控对象 | 2（正常/投送） |
| Survivor（幸存者） | 搜寻目标 ×3 | 2（隐藏/呼救） |
| House（房屋） | 背景装饰/可倒塌 | 2（完整/倒塌） |
| Mountain（山体） | 背景装饰 | 1 |
| Supply（急救包） | 投送物 | 1 |
| StartButton | 开始按钮 | 1 |
| UI_Overlay | 提示/HUD/结算面板 | 多个造型 |

### 3.2 背景（Backdrops）
| 背景 | 场景 |
|------|------|
| TitleScreen | 开始界面 |
| VillageBefore | 地震前的宁静山村 |
| VillageAfter | 地震后的废墟俯瞰 |
| RescueComplete | 结算画面 |

### 3.3 核心逻辑
- **场景切换**：通过广播消息（`broadcast "scene_1"` 等）驱动场景流转
- **无人机移动**：`when key pressed` 事件控制 x/y 坐标，每次步进 5-8 像素，带惯性缓动
- **侦测机制**：无人机与幸存者距离 < 60 像素时触发"发现"判定，播放侦测动画
- **投送机制**：无人机需在已侦测幸存者 80 像素范围内，按空格键触发投送
- **碰撞边界**：无人机 x: -220~220, y: -160~160 可飞行范围
- **状态管理**：用变量 `scene`（当前场景编号）、`found`（已侦测数 0-3）、`delivered`（已投送数 0-3）、`timer`（用时秒数）管理进度
- **重新开始**：点击「再次出发」后重置所有变量，广播 `scene_1`

### 3.4 音效设计
| 音效 | 场景 | 类型 |
|------|------|------|
| 背景音乐（紧张） | 场景 1-2 | BGM |
| 背景音乐（希望） | 场景 3-4 | BGM |
| 地震轰隆声 | 场景 2 | SFX |
| 警报声 | 场景 2 | SFX |
| 无人机飞行声 | 场景 3-4 | 循环 SFX |
| 侦测到生命信号 | 场景 3 | SFX |
| 投送成功音效 | 场景 4 | SFX |
| 结算完成音效 | 场景 5 | SFX |

### 3.5 .sb3 文件生成方式
使用 Python 脚本，构建 Scratch 3 的 `project.json` 结构，打包为 .sb3（ZIP 格式）。所有视觉资源使用 Scratch 矢量图形（SVG 格式内嵌在 JSON 中），音效使用 Scratch 内置音效库或程序化生成。

## 4. 界面视觉风格

### 4.1 色彩方案
- **主色调**：暖橙/夕阳色（救援希望感）+ 灰褐（废墟）
- **无人机**：白色/橙色，醒目
- **UI 元素**：半透明深色面板 + 白色文字
- **成功反馈**：绿色 ✅
- **警告/紧急**：红色闪烁

### 4.2 字体与排版
- Scratch 像素字体风格
- 标题大字醒目，正文小字清晰
- 中文文案，简洁有力
